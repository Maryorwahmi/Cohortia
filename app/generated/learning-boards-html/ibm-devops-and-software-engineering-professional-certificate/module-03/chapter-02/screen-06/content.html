Core Concept
CALMS — five pillars
Culture
Trust, blameless post-mortems, and shared responsibility so teams learn from incidents instead of assigning blame.
Automation
Automate builds, tests, deployments, and provisioning to reduce error-prone manual steps and speed delivery.
Lean
Focus work on customer value and remove waste such as long manual approvals or redundant checks.
Measurement
Use metrics like deployment frequency and mean time to recovery to guide improvement experiments.
Sharing
Document practices, share runbooks and post-incident learning across teams to accelerate collective knowledge.
Practical checklist
  1. 1. Identify cultural blockers to collaboration.
  2. 2. List repetitive tasks to automate first.
  3. 3. Map value stream to spot waste.
  4. 4. Choose 1–2 metrics to track and experiment against.
  5. 5. Set up a sharing rhythm for learning.
Key Takeaway

Treat CALMS as a balanced evaluation. Neglecting any pillar weakens outcomes.
