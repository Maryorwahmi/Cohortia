Public, Private, Hybrid
Understand ownership, control, and use-case fit.
Public cloud
Provider-owned resources available over the internet. Good for elasticity and lower ops burden.
Private cloud
Dedicated to one organization, offering stronger control and compliance boundaries.
Hybrid cloud
Combines public and private to balance security with elastic capacity for peaks.
Key Takeaway

Pick a deployment model by mapping compliance needs, control expectations, and traffic patterns to the model's strengths.

Example
Keep sensitive financial data in a private cloud while sending stateless web servers to a public cloud during peaks to reduce cost and preserve control.
Misconception
Hybrid is not a free pass to ignore network or identity integration; secure patterns and data movement policies are required.
