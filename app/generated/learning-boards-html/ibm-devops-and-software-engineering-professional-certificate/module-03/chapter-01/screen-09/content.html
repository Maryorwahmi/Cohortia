Module 3 › Chapter 3.1 › Infrastructure as a Service (IaaS)
IaaS — raw building blocks
Virtual servers, storage, and networking you configure and manage.
What you manage
Operating system, runtime, middleware, applications, and data.
What the provider manages
Virtualization, physical servers, storage hardware, and basic networking.
Concrete example
Deploying a virtual server and managed block storage to run a custom database cluster.
Key Takeaway

Choose IaaS when you need control over OS and runtime or must migrate legacy apps that expect full server access.

When to pick IaaS
  • Custom OS configurations
  • Specialized runtime requirements
  • Lift-and-shift migrations
Misconception
IaaS is not always the most complex option; it trades convenience for flexibility and control.
