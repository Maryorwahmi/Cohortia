Module 3 › Chapter 3.3 › Polyglot Persistence and Programming
Definition
Database per service and language diversity

Each microservice owns its data and may use the storage and programming language that best fit its needs. This increases autonomy but requires deliberate integration patterns.

Example: Catalog
Uses a document store for flexible product attributes.
Example: Orders
Uses a relational database to support transactions.
Practical Notes
  • Different data stores suit different access and consistency needs.
  • Polyglot approaches require clear APIs and data replication strategies for cross-service queries.
  • Eventual consistency and messaging are common tools to keep services in sync.
Misconception
Using different technologies does not remove the need for careful integration and consistency planning across services.
