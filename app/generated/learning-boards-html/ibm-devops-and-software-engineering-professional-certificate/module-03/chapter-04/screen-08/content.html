Build, Tag, and Run an Image
Essential docker build and run workflow
Steps
  1. Build: docker build -t my-python-app .
  2. Run: docker run -p 8000:8000 my-python-app
  3. Stop: docker stop container_id
  4. Remove: docker rm container_id
Tagging
Use -t to assign a human-readable name and optional version tag like my-app:1.0 for registry pushes.
Practical example
# Build image in project folder
docker build -t hello-docker-app .

# Run container and map port 5000
docker run -p 5000:5000 hello-docker-app
Common mistake
Not mapping the port with -p means the service remains inaccessible from the host even if it listens inside the container.
Key Takeaway

The build/run cycle is simple but critical: always tag builds, map ports, and stop/remove containers to keep your environment clean.
