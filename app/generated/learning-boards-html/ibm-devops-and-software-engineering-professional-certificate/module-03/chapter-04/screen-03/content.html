Module 4 › Chapter 3.4 › Hands-on Skills
Practical Objectives
Build, run, inspect, and clean up containers
Skills you'll practice
  • Build - docker build -t your-name .
  • Run - docker run -p host:container image
  • Manage - docker ps, stop, rm, rmi
  • Optimize - use .dockerignore and layer ordering
Why clean-up matters
Dangling images and stopped containers consume disk. Regular cleanup keeps developer machines and CI nodes fast and predictable.
