Essential Docker CLI Commands
Inspect and manage images and containers
List & Inspect
  • docker images — list local images
  • docker ps — list running containers (use -a for all)
  • docker logs <id> — view container output
Control & Cleanup
  • docker stop <id> — stop container
  • docker rm <id> — remove stopped container
  • docker rmi <image> — remove image
Practical cleanup
Before removing things in bulk, inspect their IDs. Use docker system df to review disk usage and docker image prune or docker container prune for safe pruning of unused objects.
Key Takeaway

Regularly inspect and prune unused containers and images to prevent disk growth and maintain fast CI runners.
