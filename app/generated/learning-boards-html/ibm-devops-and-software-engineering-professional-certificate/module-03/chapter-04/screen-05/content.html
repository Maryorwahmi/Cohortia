What is Docker?
A platform for packaging, running, and sharing containerized applications
Docker wraps an application and its dependencies into an immutable image. That image is a portable bundle you can run as a container anywhere Docker is installed. The Docker CLI is used to build images, run containers, tag images, and push or pull from registries.
Platform features
  • Build images from Dockerfiles
  • Run containers with resource isolation
  • Store and share images via registries
Ecosystem
  • Docker Hub and private registries
  • Integration with CI tools
  • Container orchestration support
Common misconception
Docker is not only a packaging format; it is also a runtime and workflow tool that you use daily during development and in CI pipelines.
Concrete example
Write a Dockerfile for a Python app, build an image, run it; the same image runs identically on your CI runner and in production.
Key Takeaway

Docker makes builds reproducible and deployments consistent across environments.
