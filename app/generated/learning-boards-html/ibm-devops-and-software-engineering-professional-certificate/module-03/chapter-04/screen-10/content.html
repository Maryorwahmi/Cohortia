Port Mapping and Accessibility
Make container ports reachable from the host
EXPOSE is documentation and does not publish a port to the host. To publish, run the container with -p hostPort:containerPort. Also ensure your application binds to 0.0.0.0 so it accepts external connections rather than binding only to localhost inside the container.
Example
# Run and map port 5000
docker run -p 5000:5000 hello-docker-app

# Application inside container should bind to 0.0.0.0
app.run(host='0.0.0.0', port=5000)
Troubleshooting checklist
  • Is the container running? docker ps
  • Did you map the port with -p?
  • Does the app bind to 0.0.0.0, not localhost?
Misconception
EXPOSE alone does not publish ports. It only documents container intent.
Key Takeaway

Map container ports to host ports and ensure the application listens on the container network interface so the service is reachable externally.
