Images, Containers, and Dockerfiles
Recipe, blueprint, and running instance
Dockerfile
A plain text file describing image construction steps. Each instruction creates a layer and contributes to the final image.
Analogy
Recipe that produces a baked image; layers are steps like mixing, baking, and glazing.
Image and Container
An image is the immutable artifact built from a Dockerfile. A container is a running instance of that image with isolated runtime state.
Practical note
Deleting a container does not remove the image. Use docker rmi to remove unused images after cleanup.
Layering tip
Place commands that change less frequently higher in the Dockerfile so Docker can reuse cached layers and speed builds. For example, install dependencies before copying frequently changing source files.
Key Takeaway

Dockerfile builds images; images are immutable templates; containers are running instances—order your instructions for caching.
