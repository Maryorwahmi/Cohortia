Process Flow
Branch commands you need
A short flow of operations that keeps your branch work predictable and safe.
1
Inspect branches
git branch
2
Create and switch
git switch -c feature/add-logging
3
Switch without creating
git switch main
4
Delete local branch
git branch -d feature/old
Example workflow
List branches, create-and-switch to feature/add-logging, make commits, switch back to main, merge the feature branch when ready.
Common mistake
Forgetting to switch to a newly created branch. Use create-and-switch to avoid it.
Key Takeaway

Prefer the create-and-switch command to reduce accidental commits on main and keep your branch lifecycle simple.
