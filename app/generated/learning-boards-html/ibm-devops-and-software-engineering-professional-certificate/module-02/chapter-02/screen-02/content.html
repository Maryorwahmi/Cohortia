Module 2 › Chapter 2.2 › Learning Objectives
01
Understand branching

Define a branch as an independent line of development that isolates work. Practice creating and switching branches so you can experiment without affecting main.

VERIFIED COMPETENCY MILESTONE
02
Create & switch branches

Use branch commands to create, list, and switch safely. Learn modern alternatives for switching that reduce accidental file restore operations.

VERIFIED COMPETENCY MILESTONE
03
Perform merges

Integrate branches and recognize fast-forward versus three-way merges. Practice finishing merges and testing after integration to catch regressions early.

VERIFIED COMPETENCY MILESTONE
04
Resolve conflicts

Identify conflict markers and follow a safe resolution workflow: edit carefully, stage the resolved files, and commit the result. Always test after resolving.

VERIFIED COMPETENCY MILESTONE
