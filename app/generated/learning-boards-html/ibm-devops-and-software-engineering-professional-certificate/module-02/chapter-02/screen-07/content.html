Definition
What causes a merge conflict?
Conflicts happen when Git can't automatically decide which change to keep for the same lines in a file.
  • Same lines changed differently across branches triggers a conflict.
  • Git marks conflicts and pauses the merge until you resolve them.
  • After resolution, stage the files and commit to finish the merge.

Resolution checklist
  1. Edit file to combine changes and remove markers.
  2. Stage resolved files with the add command.
  3. Commit to complete the merge and run tests.
Common mistake
Forgetting to stage resolved files before committing leaves the merge incomplete. Always run status to confirm.
Key Takeaway

Conflicts are normal. Treat them as prompts to make intentional decisions about combined code and verify with tests.
