Practice lab overview
A 15-minute walkthrough will guide you from branch creation to conflict resolution using a small Python example. This strengthens muscle memory for the commands and the conflict workflow.
Lab steps
  1. Start with a clean repo and initial commit.
  2. Create a feature branch and modify a file.
  3. Switch back to main and make a conflicting change.
  4. Merge the feature branch into main and resolve conflicts.
Team tip
Pull or merge main into your feature branch regularly to reduce big conflicts later. Keep commits focused and test after merges.
