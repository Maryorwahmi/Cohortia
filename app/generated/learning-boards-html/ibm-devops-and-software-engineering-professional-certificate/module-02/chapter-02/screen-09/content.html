Merge resolution workflow
A concrete checklist to finish merges safely when conflicts appear.
1. Try the merge and observe Git output
Git will stop and mark files when automatic merge fails.
2. Run git status
Find files listed as unmerged so you know where to edit.
3. Edit conflicted files and remove markers
Combine both intentions when possible and keep the code functional.
4. Stage and commit
git add each file, then commit with a message explaining the resolution.
Tip
Use git status often and run tests before and after merges to catch regressions early.
Pro tip
If a conflict is large, consider discussing it with the other author before choosing a resolution to preserve intent.
Key Takeaway

Follow the checklist to resolve conflicts reliably: identify, edit, stage, commit, and verify.
