What .git stores
Blobs, trees, and commits form the object model Git uses to store snapshots and history.
Blob
Contains the raw content of a file. Two identical files share the same blob object, saving space.
Tree
Represents a directory, pointing to blobs and other trees to reconstruct a file tree.
Commit
A snapshot referencing a tree plus metadata and parent links that form the commit graph.
DAG idea
Commits form a directed acyclic graph by linking to parents. This enables traversal, branching, and merges.
Misconception
Commits are not line-by-line diffs. They store a snapshot reference and object links, which makes many operations efficient.
