git status
$ git status
On branch main
Changes not staged for commit:
  modified: app.py
Untracked files:
  new_file.txt
Status summarizes the working directory and staging area so you can act confidently.
git log
$ git log --oneline --graph
* a1b2c3d (HEAD → main) feat: Add farewell function
* 9e8f7g6 feat: Initial commit with a simple greeting function
Use log flags for compact visualization. If you need file-level differences, run diff between commits or between working tree and HEAD.
