Module 2 › Chapter 2.1 › Key Concepts
Version Control System
A system that records changes to files so you can recover versions and track authorship.
Distributed Model
Every clone holds full history, enabling offline work and resilience against server downtime.
Staging Area
An intermediate buffer that lets you prepare exactly what will go into the next commit.
Summary takeaway

Adopt the habit: run status, stage intentionally, commit with clear messages, and inspect the log to maintain a useful history.
