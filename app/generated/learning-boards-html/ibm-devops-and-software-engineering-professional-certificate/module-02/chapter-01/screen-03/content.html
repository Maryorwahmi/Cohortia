Practical Skills and Terminal Habits
Good habits that make Git easy in daily work
Status

Run status frequently to see which files are modified or staged. It prevents accidental commits of unexpected files.

Staging

Stage only related changes so commits are focused. Selective staging helps reviewers and future debugging.

Commit messages

Write short what and why messages. Vague messages like "updates" are hard to follow later.

Safety note

Never commit API keys or passwords. These can be pushed later and exposed. Use environment variables or secure config instead.

Pro tip

Small, frequent commits with clear messages make it easier to bisect problems and revert safely when needed.
