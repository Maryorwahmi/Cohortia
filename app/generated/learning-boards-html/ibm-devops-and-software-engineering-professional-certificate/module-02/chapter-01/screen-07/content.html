Configuration
Set your name and email to associate identity with commits.
Example commands
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

mkdir my_devops_project
cd my_devops_project
git init
Note: init creates the .git folder; files remain untracked until you add them.
Why it matters

Identity links authors to code and audit logs. Initializing prepares the repository mechanics so commits can be recorded safely and consistently.

Key takeaway
Configure once, init per project, then stage to start saving snapshots of your work.
