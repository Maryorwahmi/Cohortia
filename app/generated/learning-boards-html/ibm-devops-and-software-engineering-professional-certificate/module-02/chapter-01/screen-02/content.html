Learning Objectives
What you will be able to do after this chapter
Bloom: Learn → Understand → Apply → Master
01
Explain VCS purpose

Describe how a VCS records file changes and supports collaboration. You will connect the idea to recovering lost work and tracing regressions.

Mnemonic: Timeline Venn — changes over time
VERIFIED COMPETENCY MILESTONE
02
Differentiate CVCS and DVCS

Compare a central server model to Git’s distributed approach and explain resilience and offline access. Understand when each model may be used.

Mnemonic: Server vs. Mirror
VERIFIED COMPETENCY MILESTONE
03
Configure and initialize Git

Set global identity and create a repository with an initialization command so Git can start recording snapshots locally.

Mnemonic: identity → .git
VERIFIED COMPETENCY MILESTONE
04
Stage, commit, inspect history

Use the staging area to prepare changes, commit with clear messages, and read history to understand past changes and authorship.

Mnemonic: Stage → Commit → Log
VERIFIED COMPETENCY MILESTONE
