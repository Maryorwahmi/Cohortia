Working Directory, Staging Area, and Local Repository
How changes flow from edit to recorded snapshot
Working Directory

Editable files on your filesystem. Changes here are not yet recorded by Git.

Staging Area

A buffer where you prepare the next commit. Stage only the changes that belong together.

Local Repository

Committed snapshots stored locally. Each commit includes metadata and links to parents forming history.

Concrete scenario
Update a function and a documentation file. Stage the function change alone for a focused commit, then stage the doc change separately.
Common mistake
Committing everything at once creates noisy history and makes locating regressions harder.
