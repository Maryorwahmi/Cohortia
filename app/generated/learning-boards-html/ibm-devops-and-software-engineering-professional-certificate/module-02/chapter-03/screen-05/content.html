Module 3 › Chapter 2.3 › Connecting a Local Repo to GitHub
Step-by-step commands
Follow these exact commands in your terminal to register and upload your history.
git remote add origin https://github.com/your-username/devops-project-repo.git
git branch -M main
git push -u origin main
If git push fails due to permissions, configure SSH keys or a Personal Access Token with write access to the repository and try again.

Key Takeaway

git push -u origin main both uploads commits and sets the upstream so future push/pull is easier.
