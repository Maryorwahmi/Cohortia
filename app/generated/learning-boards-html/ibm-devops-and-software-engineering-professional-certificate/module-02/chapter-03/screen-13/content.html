Module 3 › Chapter 2.3 › Terminal Demo: Full Live Coding Flow
Start here in terminal
cd my_devops_project
git remote add origin https://github.com/your-username/devops-project-repo.git
git branch -M main
git push -u origin main
Pause and verify the repo on GitHub before cloning. Confirm remote mapping with git remote -v.
Clone and change
cd ..
git clone https://github.com/your-username/devops-project-repo.git devops-project-clone
cd devops-project-clone
# edit app.py
git add app.py
git commit -m "feat: Add new feature from cloned repository"
git push
Returning to original repo, git pull will bring the new commit into your local main branch.
Key Takeaway

Run the demo step-by-step and confirm state with git remote -v and git log; this helps you see how commits flow through origin to other local copies.
