Working with Remote Repositories and GitHub
Connect local work to a shared remote, exchange commits, and run reviews with Pull Requests.
Why this chapter matters
Collaboration and CI depend on a reliable remote where code is shared and automated checks run.
What you'll do
Create a GitHub repo, link origin, push with upstream, clone as another developer, and pull updates to sync work.
Explore Key Topics
Remotes & GitHub
Add a remote, set origin, and understand the central shared repository.
Push, Fetch, Pull
Push uploads commits, fetch pulls metadata, and pull merges into your branch.
Clone & PRs
Clone creates a local copy. Pull Requests let teams review and merge changes.
