Module 3 › Chapter 2.3 › Authentication and Permissions
SSH keys
Install a public key on GitHub and keep the private key on your machine or agent. SSH avoids typing credentials repeatedly.
Personal Access Tokens
Use tokens with HTTPS to authenticate. Give tokens minimal scopes and rotate them if needed.
Practical checks
  • Confirm git remote -v shows the intended URL scheme (SSH vs HTTPS).
  • Test git push to a small change to verify access before big pushes.
  • Use tokens with minimal permission scopes for automated systems.
Common mistake

Using a token with broad permissions increases risk. Restrict and rotate credentials regularly.
