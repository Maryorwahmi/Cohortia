Module 3 › Chapter 2.3 › Hands-on Activity
Step sequence
  1. Create a new empty repo on GitHub named devops-project-repo.
  2. In my_devops_project: git remote add origin <URL>, git branch -M main, git push -u origin main.
  3. Go up one level and git clone <URL> devops-project-clone, edit app.py, commit, and push.
  4. Back in the original folder run git pull to receive the change.
Terminal checklist
# in my_devops_project
git remote add origin https://github.com/your-username/devops-project-repo.git
git branch -M main
git push -u origin main

# simulate another dev
cd ..
git clone https://github.com/your-username/devops-project-repo.git devops-project-clone
cd devops-project-clone
# edit app.py, then:
git add app.py
git commit -m "feat: Add new feature from cloned repository"
git push

# back in original repo
git pull
Key Takeaway

Try the full cycle to see how commits flow from one local copy to the remote and back into another local copy via clone and pull.
