Module 3 › Chapter 2.3 › Key Concepts
Remote Repository
A hosted copy on GitHub that multiple collaborators use to share code and trigger CI.
git push
Uploads local commits to the remote. Use -u to set upstream tracking once.
git clone
Creates a local copy with the remote origin already configured.
Summary

These core commands and concepts are the minimum you need to collaborate using GitHub: add a remote, push your commits, clone when joining a project, and use Pull Requests to request review.
