Module 5 › Chapter 5.3 › stop / restart
Commands & behavior
$ docker stop my-flask-web-app
# sends SIGTERM, waits for graceful shutdown

$ docker kill my-flask-web-app
# sends SIGKILL immediately

$ docker start my-flask-web-app
# starts an existing stopped container

$ docker restart my-flask-web-app
# stop then start in one command
Checks and tips
  • If stop doesn't work, check logs for shutdown errors before using kill.
  • Restart preserves the container's identity and any attached volumes; it does not recreate an instance from the image.
  • To permanently get rid of an instance use docker rm after stopping.
Mistake to avoid: using kill as the default stop mechanism. Save kill for stuck processes only.
