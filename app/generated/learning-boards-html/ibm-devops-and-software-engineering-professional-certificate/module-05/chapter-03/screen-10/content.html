Module 5 › Chapter 5.3 › docker exec
Usage
$ docker exec -it my-flask-web-app bash
# interactive shell inside container

$ docker exec -it my-flask-web-app sh
# fallback if bash is not available

# inside the container
# ls -l /app
# exit
Safety & tips
Avoid making persistent changes inside containers used as ephemeral instances. Prefer rebuilding the image for long-term changes. Use exec for inspection and one-off fixes during development.
Misconception: exec requires restart. It does not: exec runs commands inside the running container without restarting it.
