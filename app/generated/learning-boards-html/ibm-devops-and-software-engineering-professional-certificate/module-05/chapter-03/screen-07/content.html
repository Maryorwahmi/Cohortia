Module 5 › Chapter 5.3 › docker logs
Commands
$ docker logs my-flask-web-app
# show recent output

$ docker logs -f my-flask-web-app
# follow logs in real time (Ctrl+C to stop following)
Following logs is helpful when you trigger requests from a browser or an API client and want to observe resulting output live.
When to use exec
If logs indicate missing files or failing processes, run docker exec -it bash to peek into the filesystem and run diagnostics. Logs and exec together provide fast root-cause analysis.
Misconception: logs always contain full context. Some runtime issues require interactive inspection inside the container.
