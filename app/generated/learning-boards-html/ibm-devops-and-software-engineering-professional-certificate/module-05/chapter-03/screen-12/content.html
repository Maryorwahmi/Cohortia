Module 5 › Chapter 5.3 › docker inspect
Example output snippet
$ docker inspect my-flask-web-app
[
  {
    "Id": "4f3b2c9c1e2a...",
    "Name": "/my-flask-web-app",
    "NetworkSettings": {
      "Ports": {"5000/tcp":[{"HostIp":"0.0.0.0","HostPort":"8000"}]}
    }
  }
]
Inspect the Ports and NetworkSettings sections to confirm mapping and container IP. Use this data when diagnosing access problems or verifying environment variables passed at runtime.
When to inspect
  • When docker ps shows a running container but the service is unreachable.
  • When automation populates environment variables and you want to verify they are present at runtime.
  • When port mappings appear different than expected.
Pro tip: pipe inspect to a JSON parser or use --format to extract specific fields for automation checks.
