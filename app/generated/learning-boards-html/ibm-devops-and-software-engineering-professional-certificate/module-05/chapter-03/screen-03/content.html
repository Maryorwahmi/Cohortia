Module 5 › Chapter 5.3 › Learning Objectives
Objective details
  • Interpret output: Recognize running vs exited containers, and read port mappings like 0.0.0.0:8000->5000/tcp to verify access.
  • Run modes: Foreground runs block your terminal; detached runs use -d so services run in the background with a printed container ID.
  • Debugging: Use docker logs -f to stream logs and docker exec -it to open a shell for interactive checks.
  • Cleaning: Remove stopped containers with docker rm and reclaim resources with docker container prune when appropriate.
Micro-mnemonics
PS = present state; PS -A = all states
RUN in foreground = stream output; RUN -D = free terminal
LOGS = read output; EXEC = go inside
