Managing Docker Containers
Control lifecycle, read logs, run commands inside containers, and expose services safely.

This lesson focuses on the practical CLI operations you will use every day. Expect concrete commands, examples using a Flask app image, and safety tips to avoid common mistakes like port conflicts and abandoned containers.

You will practice starting containers detached, following logs in real time, entering a running container to inspect files, and cleaning up stopped containers to reclaim resources.
