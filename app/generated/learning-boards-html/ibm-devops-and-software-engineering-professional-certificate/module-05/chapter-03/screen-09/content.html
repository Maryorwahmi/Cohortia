Module 5 › Chapter 5.3 › Remove & prune
Commands
$ docker stop my-flask-web-app
$ docker rm my-flask-web-app

# Force remove (not recommended unless necessary)
$ docker rm -f my-flask-web-app

# Remove all stopped containers
$ docker container prune
When to prune
Prune after a development session or CI run when you have many exited containers. Be cautious on shared hosts; pruning removes stopped containers globally.
Pro tip: run docker ps -a before pruning to review what will be removed, preventing accidental deletion of valuable stopped containers.
