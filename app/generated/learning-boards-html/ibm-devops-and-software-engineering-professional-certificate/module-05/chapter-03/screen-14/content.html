Module 5 › Chapter 5.3 › Key Concepts
Container Lifecycle
Created → running → stopped → removed. Commands act on specific states.
Run & Expose
Use -d for detached runs and -p host:container to make services reachable.
Logs & Inspect
docker logs and docker inspect provide runtime visibility and configuration details.
Summary Takeaway

Manage containers with a repeatable workflow: observe with ps, read logs, inspect metadata, exec when needed, and clean up stopped containers.
