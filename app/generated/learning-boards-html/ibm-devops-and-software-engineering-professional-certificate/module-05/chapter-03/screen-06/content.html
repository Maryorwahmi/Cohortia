Module 5 › Chapter 5.3 › docker run
Run examples
$ docker run my-flask-app:1.0
# Runs in foreground; terminal is attached to container output.

$ docker run -d -p 8000:5000 --name my-flask-web-app my-flask-app:1.0
# Runs in background and maps host port 8000 to container 5000.
Use --name to simplify later commands like docker logs my-flask-web-app or docker exec -it my-flask-web-app bash.
Common mistakes & checks
  • Forgetting -d: your terminal will be blocked until the container exits.
  • Forgetting -p: service may be running but not reachable from host.
  • Not naming containers: harder to reference by ID later.
Try it: start detached, run docker ps, and then docker logs to ensure the server started successfully.
