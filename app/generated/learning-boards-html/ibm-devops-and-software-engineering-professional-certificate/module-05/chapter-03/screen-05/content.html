Module 5 › Chapter 5.3 › docker ps
Command & output
$ docker ps
CONTAINER ID   IMAGE                 COMMAND                  CREATED       STATUS       PORTS                    NAMES
4f3b2c9c1e2a   my-flask-app:1.0      "python app.py"         2 minutes ago Up 2 minutes 0.0.0.0:8000->5000/tcp  my-flask-web-app
Notice the Ports column: host port 8000 is forwarded to container port 5000. If a container is not listed, run docker ps -a to see exited entries.
Quick checklist
  • Use docker ps to find running containers.
  • Use docker ps -a to include exited containers for debugging.
  • Confirm port mappings show host:container relationships.
  • If missing, re-run with -p host:container to expose the service.
Misconception: docker ps shows every container. It only shows running ones unless you add -a.
