Module 5 › Chapter 5.3 › Port mapping
Example
$ docker run -d -p 8000:5000 --name my-flask-web-app my-flask-app:1.0
# Host port 8000 forwards to container port 5000

# Then open http://localhost:8000 in your browser
If the browser can't reach the app, confirm the mapping with docker ps and check for port conflicts on the host.
Troubleshooting
  • Use docker ps to verify the Ports column shows the expected mapping.
  • If Docker errors on run, another process may be using the host port — choose a different host port or stop that process.
  • Remember internal container port must match the service's listening port.
Misconception: mapping a port exposes all container services. It only forwards traffic to the specified container port.
