Module 5 › Chapter 5.3 › Troubleshooting checklist
Checklist
  1. docker ps -a — find running and stopped containers.
  2. docker logs -f <name> — observe output while exercising the app.
  3. docker inspect <name> — confirm ports and env settings.
  4. docker exec -it <name> bash — interactively inspect the filesystem.
Common issues
Port conflict: choose a different host port or stop the conflicting process.
Orphaned containers: remove stopped instances to free space.
Overuse of kill: prefer stop to allow graceful shutdowns.
Pro tip: include --name when running containers to make these commands easier and less error-prone.
