Start long-lived services with -d and expose them using -p host:container to reach them from your browser.
VERIFIED COMPETENCY MILESTONE
03
Inspect and debug
Stream logs and run an interactive shell inside a container to diagnose problems in its environment.
VERIFIED COMPETENCY MILESTONE
04
Clean up safely
Remove stopped containers and prune unused resources to avoid disk and memory waste.
VERIFIED COMPETENCY MILESTONE
How to practice
Use the sample Flask image my-flask-app:1.0. Start it in detached mode with a mapped port, check logs, exec into it to list files, then stop and remove it. Repeat these steps until they feel routine.
Try mapping to an uncommon host port first to avoid conflicts, for example map 8000 to 5000.
Prefer docker stop for graceful shutdowns; use docker kill only if stop fails.
