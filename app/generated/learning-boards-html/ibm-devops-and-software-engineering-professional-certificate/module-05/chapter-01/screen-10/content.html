Module 5 › Chapter 5.1 › Installing Docker Desktop
Process

Install steps

  1. Download the Docker Desktop installer for your OS.
  2. Run the installer and follow on-screen instructions.
  3. Start Docker Desktop and confirm the daemon is running.
Notes
Windows
Often uses WSL 2 for the Linux environment.
macOS
Uses a lightweight VM layer for the Docker Engine.
Pitfall
If Docker Desktop is not running, docker CLI commands will not connect to the daemon.
Key Takeaway

Use the Desktop bundle to get the engine, CLI, Compose, and optional Kubernetes for local development; always start Desktop to run Docker commands.
