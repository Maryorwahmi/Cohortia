Module 5 › Chapter 5.1 › Isolation: How Containers Share the Host Kernel
Definition

Isolation model

Containers separate filesystem, process, and network while sharing the host kernel for system calls and resource management.

What is isolated?
Filesystem, processes, and network namespaces.
What is shared?
The host operating system kernel and low-level resources.
Misconception
Containers do not provide separate kernels. If you need complete kernel isolation, a virtual machine is required.
Practical example
Example scenario
Two containers run different versions of a library inside their isolated filesystems; they call the same kernel for system operations and therefore start quickly and use fewer resources than running two full VMs.
Key Takeaway

Container isolation works at the application level while sharing kernel-level services, enabling high density and fast startup.
