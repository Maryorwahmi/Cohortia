Architecture

Docker Engine components

Daemon (dockerd)
Runs on the host and manages images, containers, networks and storage.
CLI (docker)
User-facing command-line client that talks to the daemon via an API.
REST API
Programmatic interface used by tools and the CLI to control the daemon.
Lifecycle example
Command flow
CLI → REST API → Daemon. The daemon pulls images from Docker Hub if not present locally, then creates and runs containers.
Key Takeaway

When you run Docker commands, the CLI requests are handled by the daemon which performs the runtime actions and stores state.
