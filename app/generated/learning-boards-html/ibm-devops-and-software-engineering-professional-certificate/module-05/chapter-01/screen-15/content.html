Module 5 › Chapter 5.1 › Key Concepts
Containerization
Portable packaging of app and dependencies for consistent runs.
Shared kernel
Containers share the host OS kernel but keep isolated file systems and processes.
Docker Engine
Daemon + CLI + REST API that manage images and containers.
Takeaway

Use Docker to create immutable image artifacts, run containers for consistent environments, and verify your setup with the provided commands before building images of your own.
