Module 5 › Chapter 5.1 › Verify Installation with docker --version and docker info
Command

docker --version

Shows the Docker client version and, when configured, server details if the daemon responds.

docker --version
# Example output:
# Docker version 20.10.x, build abcdef
Command

docker info

Provides detailed daemon state: number of containers, images, and driver details. Use it to confirm the daemon is up.

docker info
# Shows Containers: X
# Images: Y
# Server Version: 20.10.x
# ...
Troubleshoot
If docker info fails, ensure Docker Desktop is running and check permission/socket issues or proxy network settings.
