Terminal Demo
Follow these exact commands in your terminal to verify Docker and run the hello-world container. Each command provides immediate feedback about the client, the daemon, or the container lifecycle.
docker --version
docker info
docker run hello-world
docker ps -a
docker images
Expected observations
docker --version
Shows the client version and confirms CLI is installed.
docker info
Reports daemon status; confirms engine is running.
docker run hello-world
Prints a confirmation message and exits.
Key Takeaway

These simple terminal checks validate your install and the core Docker lifecycle of pulling, creating, and running containers.
