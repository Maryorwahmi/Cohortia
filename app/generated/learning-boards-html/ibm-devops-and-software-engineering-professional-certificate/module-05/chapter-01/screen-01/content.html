Visual concept
A container is a portable package that shares a host kernel but keeps its own file system and process space.
Analogy: a container is like an apartment in a building. It shares the building's foundation and utilities but remains an isolated living space. This yields faster startup and more efficient resource use compared to a full house, which represents a VM.
Quick start strip
When you install Docker Desktop and run a container like hello-world, the client pulls an image, the daemon creates a container, the container prints output and exits. That verifies your environment.
Estimated first-run time: seconds to minutes depending on network.
