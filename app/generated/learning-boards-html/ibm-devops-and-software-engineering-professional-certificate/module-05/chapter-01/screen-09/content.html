Module 5 › Chapter 5.1 › Docker Hub: Registry for Images
Definition

Docker Hub and registries

A registry stores images so they can be shared and retrieved. Docker Hub is the default public registry used to publish and pull images.

Public vs private
Public registries host community images; private registries store company images securely.
Pulling images
If an image is not local, the daemon pulls it from the registry when requested.
Example
hello-world pull
When you run hello-world for the first time, the daemon pulls the image from Docker Hub and then runs it locally to show output.
Key Takeaway

Registries are central stores for image artifacts; Docker Hub is the common public registry used for discovery and sharing.
