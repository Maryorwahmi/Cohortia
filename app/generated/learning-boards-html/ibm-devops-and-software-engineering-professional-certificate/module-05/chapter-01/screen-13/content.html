Module 5 › Chapter 5.1 › Troubleshooting: Daemon, Proxy, and Common Issues
Common problems
  • Docker Desktop not started → CLI cannot reach daemon.
  • Network or proxy blocking registry pulls.
  • Expecting container file changes to persist to the image.
Quick checks
Confirm Desktop is running, run docker info, and retry the pull. If blocked, verify proxy settings or network rules.
Persistence patterns
Use volumes
Mount host storage or named volumes to persist data outside the container's writable layer.
Build a new image
Commit changes into a new image for reproducible state.
Key Takeaway

Most first-run issues are resolved by ensuring the daemon is running and verifying network access for image pulls; persist important data with volumes or images.
