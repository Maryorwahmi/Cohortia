Module 5 › Chapter 5.1 › Docker Images and Containers
Definition

Images and containers explained

Docker image
A read-only template bundling code, runtime, libraries, and config.
Container
A runnable instance with a writable layer on top of the image.
Practical note
To persist changes, use volumes or build a new image from modified files.
Example workflow
Build → Run
Create an image with your app and dependencies, then create containers from that image for testing, CI, or production deployment.
Key Takeaway

Treat images as immutable artifacts and containers as ephemeral runtime instances created from those artifacts.
