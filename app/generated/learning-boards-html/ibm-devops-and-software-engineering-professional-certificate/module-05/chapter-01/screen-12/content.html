Module 5 › Chapter 5.1 › Run hello-world: Pull, Create, Run, Output
Command

docker run hello-world

This command demonstrates pulling an image, creating a container, running it, and observing output.

docker run hello-world
# Output: a confirmation message that Docker is working
After the run
Inspect
Use docker ps -a to see the container listed with status Exited.
List images
Use docker images to confirm the hello-world image is stored locally.
Pitfall
If the daemon is stopped, the run will fail before pulling or creating a container.
Key Takeaway

hello-world demonstrates the full image-to-container workflow and is a trusted first smoke test for Docker installations.
