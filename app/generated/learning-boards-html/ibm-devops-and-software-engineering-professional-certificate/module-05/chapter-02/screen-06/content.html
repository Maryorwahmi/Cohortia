Step-by-step pattern
1. FROM
Choose a base image, e.g., python:3.9-slim-buster. Smaller images reduce final size.
2. WORKDIR
Set the working directory to keep subsequent commands consistent, e.g., WORKDIR /app.
3. COPY + RUN
COPY requirements.txt then RUN pip install to cache dependencies, then COPY the rest of the source.
Runtime instructions
EXPOSE
Documents which port the container listens on (no host publish).
CMD
Provides defaults for the container's runtime command. It can be overridden at run time.
ENTRYPOINT
Defines the executable for the container. CMD can supply default arguments to ENTRYPOINT.
Pro tip
Use JSON array form for CMD and ENTRYPOINT to avoid shell parsing differences, for example: CMD ["python", "app.py"].
