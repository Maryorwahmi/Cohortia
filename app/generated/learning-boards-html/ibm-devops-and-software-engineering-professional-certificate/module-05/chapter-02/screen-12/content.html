Module 5 › Chapter 5.2 › Multi-stage builds
Example pattern
# Stage 1: builder
FROM openjdk:17-jdk-slim AS builder
WORKDIR /app
COPY . .
RUN ./gradlew build

# Stage 2: runtime
FROM openjdk:17-jre-slim
WORKDIR /app
COPY --from=builder /app/build/libs/*.jar app.jar
ENTRYPOINT ["java", "-jar", "app.jar"]
This copies only the compiled jar into a slim runtime image, removing build tools used in the first stage and keeping the final image small.
