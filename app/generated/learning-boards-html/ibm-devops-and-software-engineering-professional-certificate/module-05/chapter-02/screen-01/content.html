Images, Layers, and Dockerfiles

Images are layered read-only templates. Dockerfiles declare the steps that create those layers so builds are repeatable and cache-friendly.

In this lesson
  • How each Dockerfile instruction creates a layer and affects cache behavior.
  • Common Dockerfile instructions: FROM, WORKDIR, COPY, RUN, EXPOSE, CMD, ENTRYPOINT.
  • Practical Flask example: writing a Dockerfile, building with docker build, and running a container with port mapping.
Why this matters

Reliable, fast image builds let you move an application from developer machines to CI and production with fewer surprises.
