Module 5 › Chapter 5.2 › docker build & context
Build command
docker build -t my-flask-app:1.0 .
The dot at the end is the build context. Docker will upload the context to the daemon, so keep it minimal.
.dockerignore
__pycache__/
*.pyc
.git/
.venv/
Exclude build artifacts and local files to reduce the context and avoid leaking secrets.
Common mistake

Running docker build without the correct context or forgetting .dockerignore leads to missing files or huge uploads to the daemon.
