Module 5 › Chapter 5.2 › Build, run, test
Terminal Steps
mkdir my-flask-app
cd my-flask-app
# add app.py and requirements.txt and Dockerfile
docker build -t my-flask-app:1.0 .
docker images
docker run -p 8000:5000 my-flask-app:1.0
# open http://localhost:8000
Validation and tips
  • Verify the image appears in docker images after successful build.
  • Map ports carefully: docker run -p hostPort:containerPort.
  • Use .dockerignore to speed builds and avoid leaking files.
Mistake to avoid: forgetting the trailing dot in docker build means Docker can't find the Dockerfile context and will fail or build an empty context.
