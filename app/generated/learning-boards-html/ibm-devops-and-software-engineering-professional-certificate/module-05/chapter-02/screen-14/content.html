Module 5 › Chapter 5.2 › Key Concepts
Docker Image
A read-only, layered template that contains runtime, libraries, and app code.
Dockerfile
A text recipe of instructions that Docker runs to build an image, producing layers.
Layer Cache
Each instruction often creates a layer; Docker reuses unchanged layers to speed rebuilds.
Summary Takeaway

Plan Dockerfiles to protect cache, keep contexts small, and use multi-stage builds to produce secure, lightweight images ready for deployment.
