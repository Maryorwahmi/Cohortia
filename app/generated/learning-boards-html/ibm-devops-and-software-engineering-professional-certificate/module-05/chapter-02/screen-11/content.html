Module 5 › Chapter 5.2 › Optimizing builds
Practical rules
  • Use specific base images (e.g., python:3.9-slim-buster) to reduce size and ensure consistency.
  • Copy dependency files first and run installs before copying app code to preserve cache.
  • Combine RUN commands to minimize layer count and handle cleanup in the same step.
.dockerignore and multi-stage
Use .dockerignore to keep the build context small. For heavy builds, use multi-stage builds: compile in a builder stage and copy only results into a tiny runtime image.
Example: combine package install and cleanup RUN apt-get update && apt-get install -y build-essential \ && rm -rf /var/lib/apt/lists/*
Common mistake

Leaving large files in the build context or copying unnecessary files into the image bakes extra weight into every image you build.
