Module 5 › Chapter 5.2 › What is a Docker image?
Definition

A read-only template that contains runtime, libraries, configuration, and application code. It is built in layers where each instruction adds a layer.

Layers and caching
  • Each Dockerfile instruction typically creates a layer.
  • Docker caches unchanged layers to speed rebuilds.
  • Place stable instructions earlier to maximize cache reuse.
Key Takeaway

Design Dockerfiles so frequently changed content is added late to protect cached layers and speed builds.

Concrete example
Example: Python base image
Start from python:3.9-slim-buster as a base and add your app. The base provides interpreter and libraries; your COPY adds the application layer on top.
Common misconception

An image is not a container. Modifying an image requires rebuilding; containers are writable instances with an ephemeral writable layer on top.

Check your understanding
If your code changes frequently, should you copy it before or after installing dependencies? Think about which approach preserves cache for the dependency layer.
