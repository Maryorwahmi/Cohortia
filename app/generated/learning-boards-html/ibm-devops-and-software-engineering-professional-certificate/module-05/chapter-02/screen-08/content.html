Dockerfile
# Dockerfile
FROM python:3.9-slim-buster
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "app.py"]
Why copy requirements first?
It allows Docker to cache the pip install layer when your code changes but requirements do not.
Build context warning
Remember to run: docker build -t my-flask-app:1.0 . — the dot specifies the build context.
