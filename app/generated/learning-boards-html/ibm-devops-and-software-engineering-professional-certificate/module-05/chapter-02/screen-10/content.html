Module 5 › Chapter 5.2 › CMD vs ENTRYPOINT
ENTRYPOINT
Sets the container's executable. Not easily overridden, ideal for images that must always run a particular program or wrapper.
ENTRYPOINT ["/usr/local/bin/my-entrypoint"]
CMD
Provides defaults or arguments that can be overridden by docker run. Use JSON form to avoid shell differences.
CMD ["python", "app.py"]
When to use each

Use ENTRYPOINT for opinionated, non-overridable executables; use CMD for sensible, overridable defaults or arguments.
