Module 5 › Chapter 5.4 › Bind Mounts vs Volumes
Bind mounts
Mount a host directory into the container. Perfect for development workflows that need immediate reflection of host changes.
- Immediate reflection of file edits on host.
- Tightly coupled to host directory paths; less portable.
- Be careful with sensitive host directories.
Example:
docker run -d -p 3000:3000 -v /home/user/my-node-app:/app my-node-app-image
Volumes
Managed by Docker, better for production data, easier to back up and migrate, and often better cross-platform performance.
- Managed lifecycle independent of containers.
- Easy to share between containers safely.
- Recommended for databases and logs.
Decision rule

Bind mounts for development speed; volumes for production durability and manageability.
