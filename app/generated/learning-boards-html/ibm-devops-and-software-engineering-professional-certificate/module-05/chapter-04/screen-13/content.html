Module 5 › Chapter 5.4 › PostgreSQL Activity
Activity steps (visual commands)
# 1 Create a custom network
docker network create my-db-network

# 2 Create a named volume
docker volume create pg-data

# 3 Run PostgreSQL with network and volume
docker run -d \
  --name my-postgres-db \
  --network my-db-network \
  -p 5432:5432 \
  -e POSTGRES_DB=mydb \
  -e POSTGRES_USER=user \
  -e POSTGRES_PASSWORD=password \
  -v pg-data:/var/lib/postgresql/data \
  postgres:13-alpine

# 4 Verify
docker network inspect my-db-network
docker volume inspect pg-data

# 5 Test connectivity from a temporary container
docker run --rm --network my-db-network alpine ping my-postgres-db
If you see the database listed in the network inspect and the volume mounted at the expected container path, the setup is correct. Recreate the container using the same volume to confirm data persistence.
Common checks
  • Confirm the container name appears under the network’s containers in the inspect output.
  • Confirm the volume inspect shows that Docker manages pg-data.
  • If ping fails, ensure both containers are on the same network and that no firewall blocks ICMP locally.
Result

A PostgreSQL container with persistent storage accessible by containers on the same custom network.
