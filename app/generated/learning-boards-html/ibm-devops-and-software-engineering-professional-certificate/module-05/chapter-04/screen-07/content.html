Automatic DNS in custom networks
Containers connected to the same custom bridge can resolve each other by container name.
Definition
Embedded DNS maps container names to their current IP addresses within the network, enabling name-based calls.
Concrete example
A web app can reach its database via the hostname database instead of an IP, so redeploys don’t break configuration.
Checks and troubleshooting
Ensure same custom network
Inspect DNS entries via container tools (nslookup or ping)
Remember: overlay networks needed for multi-host discovery
Key Takeaway

Leverage automatic DNS on custom bridges to simplify service configurations and reduce fragile IP dependencies.
