Practice tasks and safety checks
Run these verification steps to build confidence and avoid common mistakes.
Network check
Create a network, connect containers, then inspect it to confirm both appear.
VERIFIED COMPETENCY MILESTONE
Volume persistence
Attach a named volume to a database, remove the container, and recreate it to see the data persist.
VERIFIED COMPETENCY MILESTONE
Bind mount dev
Mount a host project folder during development and edit files to observe live updates inside the container.
VERIFIED COMPETENCY MILESTONE
Common mistake

Running containers on different networks causes name resolution failure. Always ensure communicating containers share the same custom bridge.

Pro tip

Use descriptive network and volume names so inspection output is easy to scan later.
