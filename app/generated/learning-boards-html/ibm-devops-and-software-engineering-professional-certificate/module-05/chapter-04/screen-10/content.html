Module 5 › Chapter 5.4 › Volumes: Create & Attach
Step-by-step commands
# Create a named volume
docker volume create pg-data

# Run PostgreSQL with the volume mounted
docker run -d \
  --name my-postgres-db \
  --network my-db-network \
  -p 5432:5432 \
  -e POSTGRES_DB=mydb \
  -e POSTGRES_USER=user \
  -e POSTGRES_PASSWORD=password \
  -v pg-data:/var/lib/postgresql/data \
  postgres:13-alpine
Inspect the volume and network to confirm the database container is connected and the volume is mounted to the expected path.
Verification
- Use docker volume inspect pg-data to see mount details.
- Use docker network inspect to confirm the container is listed in the network.
- Remove and recreate the container with the same volume to verify persistence.
Key Takeaway

Volumes keep data independently of containers. Use inspect and reuse the named volume to restore data after recreation.
