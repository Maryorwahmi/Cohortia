Module 5 › Chapter 5.4 › Attach Running Containers
Minimal-downtime flow
  1. Create the network if missing.
  2. Run docker network connect to attach a running container.
  3. Verify with docker network inspect and use a temporary container to test name resolution.
If connecting fails or services misbehave, consider a brief restart with explicit network flags to ensure a clean configuration, but try network connect first to reduce disruption.
Commands (visual only)
# Create network if needed
docker network create my-app-network

# Connect running containers with minimal downtime
docker network connect my-app-network web-app
docker network connect my-app-network api-service

# Test from a temporary container
docker run --rm --network my-app-network alpine ping api-service
Common issue

If name resolution still fails, inspect whether the containers have correct aliases or restart them to reinitialize network settings.
