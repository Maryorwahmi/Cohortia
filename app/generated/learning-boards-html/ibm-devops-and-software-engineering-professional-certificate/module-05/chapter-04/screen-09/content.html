What is a Docker volume?
A named storage area managed by Docker, stored on the host, that persists beyond container lifecycle.
- Persist data independent of a container’s writable layer.
- Managed via Docker CLI and API for backups and migrations.
- Safe to share among containers and often stable in performance.
Usage

Attach a named volume to a database container to keep data after container replacement.

Advantages & notes
  • Easier to back up or migrate than bind mounts.
  • Can be initialized with image data at first use.
  • Better cross-platform behavior on macOS and Windows.
Create and attach example:
docker volume create my-data

docker run -d --name my-db -v my-data:/var/lib/mysql mysql:8.0
