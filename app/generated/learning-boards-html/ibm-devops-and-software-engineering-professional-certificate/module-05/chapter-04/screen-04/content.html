What is the default bridge?
A preconfigured network Docker creates so containers have IPs and can be exposed with port mapping.
- Containers get isolated IP addresses on the bridge.
- Host accesses container services via mapped ports.
- Container name resolution is limited compared to custom networks.
- Suitable for simple tests but not for multi-service architectures needing name resolution.
Example
Run a single web container and map port 80 to the host. The host can open the site, but other containers may not resolve it by name on the default bridge.
Key Takeaway

Use the default bridge for small quick tests; create a custom bridge when you need reliable container name resolution and isolation.
