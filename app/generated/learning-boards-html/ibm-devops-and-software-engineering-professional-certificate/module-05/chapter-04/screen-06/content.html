Module 5 › Chapter 5.4 › Create Custom Bridge
Three-step process
  1. Create the network with a descriptive name.
  2. Run or connect containers using the network flag.
  3. Inspect the network to verify containers and DNS names.
Remember: creating a custom network does not expose ports to the host automatically; you still need to map ports if you want host access.
Checklist
Name network clearly
Attach containers on start
Inspect after connect
Map ports if host access needed
Command examples (visual only)
# Create a user bridge network
docker network create my-app-network

# Run containers attached to the custom network
docker run -d --name web-app --network my-app-network -p 80:80 my-web-app-image
docker run -d --name database --network my-app-network my-database-image

# Verify the network and containers
docker network inspect my-app-network
Key Takeaway

A custom bridge gives you automatic name resolution and isolation — use it to simplify multi-container communication.
