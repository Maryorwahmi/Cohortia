Process Flow Terminal demo steps 
$ cd my-flask-app
# start in detached mode so terminal is free
$ docker compose up -d
# confirm services are running
$ docker compose ps
# tail logs for web
$ docker compose logs -f web
# visit http://localhost:8000 to confirm the app responds
# when done, stop and remove containers/networks
$ docker compose down
# to remove named volumes as well:
$ docker compose down -v
Checklist & tips
  • Confirm the compose file is at the project root so compose auto-discovers it.
  • If a host port is busy, change the left side of a mapping, for example 8001:5000.
  • Use compose logs service-name to narrow troubleshooting to a single service.
Pro tip

When developing, bind mount your code so edits show immediately without rebuilding the image each time.
