Architecture Networks & discovery
User-defined networks
Define a network in the compose file and add it to services so they can resolve one another by name: http://db:5432 for Postgres, for example.
Why not rely only on host ports?
Host ports expose services to the host. Internal service-to-service communication should use the compose network and service names.
Concrete example
In the example compose file, both web and db are attached to app-network, allowing the web service to use DATABASE_URL pointing to db:5432.
Key Takeaway

Networks are the glue that makes inter-service DNS and communication work inside a Compose stack.
