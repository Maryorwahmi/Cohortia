Docker Compose for Multi-Container Applications
Define services, networks, and volumes once. Run your whole stack with a single command.

This chapter teaches how to model an application stack as code using a docker-compose.yml file. You will see how services map to containers, how to choose between using a pre-built image or building from a Dockerfile, and why networks and volumes matter for connectivity and persistence.

Compose is especially helpful in development and CI: it standardizes local environments so what runs on your laptop can be reproduced in CI pipelines and single-host deployments. We'll use a Flask plus PostgreSQL example as a running walkthrough.
