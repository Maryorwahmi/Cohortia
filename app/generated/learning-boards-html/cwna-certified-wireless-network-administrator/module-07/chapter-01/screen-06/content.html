IEEE and the 802.11 Working Group
The standards body that defines PHY and MAC behavior for WLANs.
Standards vs implementation
Standards describe expected radio and frame behaviors; vendors implement those behaviors in chips and firmware.
Practical uses
  • Use IEEE documents to compare protocol features and capabilities.
  • Reference amendments to understand device limits and supported features.
Concrete example
When a vendor lists a device as supporting a specific 802.11 amendment, you can expect certain PHY rates and MAC features to be present; use the standard to confirm expected behaviors.
Common misconception
Confusing standards with enforcement or certification. The IEEE defines the technical specification; regulators and certification bodies play distinct roles.
Key takeaway
Use IEEE standards as the technical reference when troubleshooting features and interoperability questions.
