Module 7 › Chapter 7.4 › Common Mistakes
Top mistakes
  • Mounting high-gain antennas where beams cross public walkways without checking exclusion distances.
  • Assuming structural mounting equals proper grounding without continuity tests.
  • Using indoor cable or mismatched PoE hardware for outdoor, high-power installs.
  • Installing arrestors but not bonding them to the main ground.
Avoidance strategy
Implement a pre-install checklist and post-install verification tests, and insist on manufacturer exclusion-distance evidence.
Warning

Appearance is not proof of safety. Always perform electrical tests and document results.

Key Takeaway

Checklists, tests, and documentation reduce human error and liability.
