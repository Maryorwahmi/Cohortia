Module 7 › Chapter 7.6 › Passive Recon
Kismet workflow (simulated)
Start with a monitor interface and launch Kismet. Observe SSIDs, BSSIDs, channels, clients, and security types. Look for probe requests that may reveal hidden SSIDs when clients attempt to connect.
Expected outputs
  • SSID and BSSID list
  • Channel and signal strength
  • Security type (Open, WEP, WPA2, WPA3)
  • Client MAC addresses and probe requests
Concrete example

In a simulated lab, Kismet shows a network with SSID hidden; when a phone probes, Kismet logs the SSID string. Record the event, but do not probe that network unless authorized.

Misconception check

Passive does not equal permission-free. Treat captured client identifiers sensitively and follow the agreed evidence retention rules.

Key Takeaway

Use passive scanning to build a safe inventory of wireless assets before any active tests.
