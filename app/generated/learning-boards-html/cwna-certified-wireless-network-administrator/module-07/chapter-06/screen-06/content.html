Module 7 › Chapter 7.6 › Pentest Tools

Tool roles

Kismet — passive reconnaissance
Detects networks and clients with minimal transmission. Good first step to map the environment.
Aircrack-ng — capture, injection, cracking
Includes airmon-ng, airodump-ng, aireplay-ng, and aircrack-ng for active tests and offline cracking.
Wireshark — deep analysis
Inspect 802.11 frames, view authentication sequences, and find misconfigurations.
Kali Linux — toolkit platform
A bundled distribution for lab and controlled pentests that includes these tools.
Hardware note

A compatible wireless adapter that supports monitor mode and packet injection is required for many active tasks. Verify driver support and regulator settings before a test.

Example commands
sudo airmon-ng check kill
sudo airmon-ng start wlan0
sudo airodump-ng wlan0mon
Key Takeaway

Match tools to tasks: discover first, capture when authorized, and analyze captures thoroughly.
