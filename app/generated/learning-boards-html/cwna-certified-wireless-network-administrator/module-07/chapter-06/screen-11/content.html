Dictionary vs Brute-force

Dictionary attacks test common or targeted wordlists. Brute-force attempts all combinations and is viable only for short passphrases. WPS attacks target protocol flaws to obtain keys faster.
Dictionary
Fast against common passphrases; requires relevant wordlists.
Brute-force
Time-consuming and often impractical for long keys.
WPS attacks

WPS PIN vulnerabilities let attackers recover credentials faster on susceptible devices. Check and report WPS status and recommend disabling it if found enabled.

Example note

In a test, a captured handshake was cracked in 18 minutes using a curated wordlist. Recommendation: enforce passphrases of 20+ random characters and rotate keys.

Key Takeaway

When passphrases crack quickly, the real fix is policy and configuration, not more testing.
