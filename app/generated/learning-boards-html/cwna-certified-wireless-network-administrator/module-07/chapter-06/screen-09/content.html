Module 7 › Chapter 7.6 › Deauthentication

Why deauth?

To cause a client to reauthenticate so you can capture the 4-way handshake for offline analysis. Use this only under written approval.

Example command (simulated)
sudo aireplay-ng --deauth 5 -a 00:11:22:33:44:55 -c AA:BB:CC:DD:EE:FF wlan0mon
Limit the number of frames and the duration. If critical services are present, do not use deauth without explicit technical approval and testing windows.
Misconceptions
  • Deauth is a harmless test — false: it can disrupt services and must be controlled.
  • Captured handshake equals cracked key — not necessarily; cracking may fail.
Evidence to record
  • Time and target BSSID
  • Client MAC observed
  • Commands used and number of frames sent
Key Takeaway

Deauth is effective but intrusive; use only in scope and with safety controls.
