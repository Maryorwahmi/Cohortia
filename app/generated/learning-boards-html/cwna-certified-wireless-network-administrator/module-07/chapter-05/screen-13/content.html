Change Title: Implement New IoT SSID for Corporate WLAN

Change Description:
This change involves adding a new SSID, "IoT-Devices," to our existing wireless network infrastructure. The purpose is to segregate IoT traffic onto VLAN 100 using WPA3-Personal and firewall rules that limit access to necessary external services.

Impact Analysis:
Expected impact is minimal. There is a low risk of transient disruption during configuration. Schedule during off-peak hours.
Implementation, verification, and rollback items should be enumerated in the ticket and referenced by engineers performing the change.
Implementation Plan — Controller snippet
/* Conceptual commands for controller configuration */
config wlan create 10 IoT-Devices IoT-Devices
config wlan security wpa3 akm psk enable 10
config wlan security wpa3 psk set-key ascii <strong_passphrase> 10
config wlan interface 10 vlan 100
config wlan enable 10

/* Firewall: create rule to restrict VLAN 100 to necessary external services and block internal corporate subnets. */
Verification Plan
  • Confirm SSID broadcasts and WPA3-Personal authentication.
  • Verify test device receives DHCP from VLAN 100 scope.
  • Confirm firewall rules allow required external services and block corporate resources.
  • Monitor existing SSIDs for degradation for one hour post-change.
Rollback: disable SSID 10, revert VLAN 100 and firewall changes, and restore previous DHCP scope if needed.
