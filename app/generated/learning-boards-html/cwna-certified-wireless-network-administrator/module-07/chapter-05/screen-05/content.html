Definition Logical Network Diagrams
Map traffic, not floors
Show VLANs, SSIDs, authentication, and firewall relationships.
Essential layers
  1. SSID to VLAN mapping with tags.
  2. Subnet ranges and gateway IPs.
  3. Authentication services and RADIUS IPs.
  4. Firewall rules that affect wireless VLANs.
  5. Inter-VLAN routing and ACLs relevant to wireless users.
Pro tip
Maintain a "detailed" and a "summary" logical diagram. Use the summary for quick orientation and the detailed for troubleshooting.
Example scenario
A guest client associates to "Guest-SSID". The diagram shows that the SSID maps to VLAN 300, which has a DHCP scope and firewall rules that allow only internet egress. If a client receives an address on VLAN 200 instead, the diagram immediately points to a misapplied VLAN assignment on the controller or switch port.

Key Takeaway

Logical diagrams answer policy and flow questions quickly. Keep them versioned and cross-linked to config records.
