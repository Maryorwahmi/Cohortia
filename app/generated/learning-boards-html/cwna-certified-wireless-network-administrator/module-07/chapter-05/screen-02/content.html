Learning Objectives
Skills and measurable outcomes for this lesson
Bloom
Learn → Understand → Apply → Master
Progression from comprehension to applied competence.
01
Explain documentation value
Describe how records support design, troubleshooting, and audits. You will practice framing documentation as institutional knowledge that outlives any single administrator.
VERIFIED COMPETENCY MILESTONE
02
Build diagram artifacts
Create logical and physical diagrams, showing how VLANs and AP placement affect performance. You'll learn what to include and why each element matters.
VERIFIED COMPETENCY MILESTONE
03
Define WLAN policies
Draft AUP, access control, onboarding, and incident response policies that reduce risk and clarify responsibilities for users and administrators.
VERIFIED COMPETENCY MILESTONE
04
Apply change management
Prepare change requests with impact analysis, verification and rollback steps. We'll practice a sample change for adding an IoT SSID.
VERIFIED COMPETENCY MILESTONE
