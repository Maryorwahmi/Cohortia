Module 07 › Chapter 7.3 › 802.1X, RADIUS, and authentication architecture
Why 802.1X matters

It provides per-user and per-device authentication, enabling accountability and fine-grained access control required by regulators.

Concrete Example
Staff devices authenticate to RADIUS using certificates; RADIUS logs identify the device and user for audits.
Common Misconception
Using a shared PSK is often easier but it removes user-level accountability and complicates revocation.
Architecture Notes
  • APs act as pass-throughs for authentication to RADIUS.
  • RADIUS checks credentials against a central directory and returns an acceptance or rejection.
  • Enable accounting to record session start, stop, and accounting attributes for audits.
Key Takeaway

Centralized authentication and logs are essential evidence that users and devices were properly authorized and tracked.
