Module 7 › Chapter 7.7 › Ethical responsibilities
Core Concept

Authority, trust, and duty

Administrators must protect user privacy and system reliability because they control sensitive access and tools. This responsibility extends beyond technical fixes into policy and communication.

Definition card: Access creates obligation to prevent misuse of data and tools.
Example card: Viewing logs to troubleshoot is allowed; storing or sharing user browsing history without authorization is not.
Misconception card: 'If I can see it, it's OK to use' — this violates privacy and often policy.
Key Takeaway

Treat access as a privilege. Document actions and seek authorization for intrusive monitoring.

Definition
Scope of duty
Secure configurations, protect logs, avoid unauthorized monitoring, and ensure availability.
Concrete example
If a user is suspected of policy violation, follow documented steps: get HR or legal approval before deep inspection.
Practical steps
  • Use least privilege and role separation.
  • Log and justify privileged actions.
  • Apply strong security controls as an ethical baseline.
