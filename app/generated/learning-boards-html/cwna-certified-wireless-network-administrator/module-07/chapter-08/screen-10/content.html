Architecture

A minimal lab you can repeat

Design labs that let you test configuration, troubleshooting, and packet analysis.

Core components
  • One AP (physical or virtual)
  • RADIUS server (RADIUS on Raspberry Pi or VM)
  • Client device for packet captures
Extension ideas
  • Add a second AP for roaming tests
  • Introduce a repeater or mesh node for backhaul testing
  • Use a spectrum analyzer to simulate interference
Fault injection checklist
  • Use wrong RADIUS secret to observe authentication failures
  • Change EAP type on client to produce EAP mismatch
  • Lower AP transmit power to test coverage-related roaming
Example Lab Notes
# Lab: 802.1X test
RADIUS: 192.168.100.10
Shared secret: secret123
Client: laptop with packet capture
Test: attempt connection, capture EAP exchange, verify Access-Accept
Pitfall
Using too many variables in one test makes root cause unclear. Change one parameter at a time.
Key Takeaway

Document lab steps and results so tests are repeatable and demonstrable to employers.
