Module 1 › Chapter 1.3 › Hands‑On Activity
Activity Steps
  1. Identify topology: check for SSID and whether a central AP exists.
  2. Find BSSID: use system commands or Wi‑Fi menus to read the AP radio MAC.
  3. Walk the space: observe whether the same SSID persists while BSSID changes to detect an ESS.
  4. Classify AP: inspect management UI or documentation for standalone, controller, or cloud clues.
Example commands
Windows: netsh wlan show interfaces
macOS: hold Option and click the Wi‑Fi icon to reveal BSSID.
Linux: use iw dev wlan0 link or iwconfig on older systems.
Reflection

Record SSID, BSSID, whether multiple APs share the SSID, and whether APs are standalone or managed. Sketch a simple diagram showing clients, APs, and the wired DS.
