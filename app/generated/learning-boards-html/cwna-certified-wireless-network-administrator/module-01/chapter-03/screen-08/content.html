Module 1 › Chapter 1.3 › AP Architectures
Standalone AP
Individually configured devices for small networks.

Simple to deploy for one or a few APs. Administration is manual per device.

Example: a home router/AP combo managed via its web UI.

Controller‑Based
Centralized management for many APs using a Wireless LAN Controller.

Offers centralized policies, firmware updates, and coordinated RF optimization.

Example: enterprise networks using lightweight APs with a WLC for scale.

Cloud‑Managed
Controller functionality hosted in the cloud for distributed sites.

Central control without on‑site controller hardware; good for branch offices and managed services.

Example: multiple retail locations managed from a single cloud portal.

Decision checklist
Consider number of APs, administrative resources, required features like RF optimization and guest management, and whether a cloud model simplifies operations across many sites.
