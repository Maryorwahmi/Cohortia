Module 1 › Chapter 1.3 › Ad‑Hoc Mode
Definition
An Independent Basic Service Set where peers communicate directly.

Ad‑Hoc networks let devices talk directly without an AP. They are quick to set up for temporary tasks but lack centralized security and management.

Example: two laptops create a direct Wi‑Fi link to share a folder; neither device acts as a managed AP.

Misconception: Ad‑Hoc does not provide seamless roaming or easy wired network access the way Infrastructure mode does.

Common mistake

Using Ad‑Hoc for many users expecting stable coverage and centralized security.

Analogy
Ad‑Hoc is like two people passing notes at a table; it works for a while but isn’t a managed classroom with a teacher coordinating the class.
Key Takeaway

Ad‑Hoc (IBSS) is simple and transient. Use it for quick peer links, not for managed or large environments.
