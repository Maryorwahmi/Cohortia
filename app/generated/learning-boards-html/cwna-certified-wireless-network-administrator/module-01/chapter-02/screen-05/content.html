Definition › dBm and Practical Values
dBm: power relative to 1 mW

Because it is absolute, dBm lets you compare transmitter settings, cable loss, and measured RSSI values directly.

0 dBm
Equals 1 milliwatt of power.
Typical Tx
Client ~15 dBm; AP ~20 dBm (example values in many specifications).
Interpreting RSSI
  • -60 dBm: strong/good
  • -75 dBm: usable but weaker
  • -90 dBm: typically too weak for reliable connectivity
Practical example
Measurement scenario

A client reports -72 dBm, then moves closer and reads -69 dBm. That 3 dB improvement means the received power doubled.

Misconception

Do not add dBm and dBi without context — dBi is antenna gain relative to an isotropic radiator and must be applied correctly in link budgets.

Key Takeaway

Use dBm for absolute power readings and to validate regulatory and performance constraints.
