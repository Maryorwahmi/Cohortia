Definition › Antenna Gain: dBi and dBd
Understand the reference

dBi is relative to an ideal isotropic radiator; dBd is relative to a practical dipole antenna. Convert by adding 2.14 dB to dBd to get dBi.

0 dBd
Equals 2.14 dBi (gain of a half‑wave dipole).
Practical effect
Higher antenna gain narrows beamwidth, extends range, and changes the coverage shape indoors.
Example card
Link planning

If a vendor lists antenna gain as 6 dBd, convert to dBi by adding 2.14 dB to get 8.14 dBi before using in the link budget.

Common mistake

Forgetting to convert dBd to dBi can misstate expected coverage and received power.

Key Takeaway

Always confirm the gain reference and convert dBd to dBi (add 2.14 dB) before using the value in calculations.
