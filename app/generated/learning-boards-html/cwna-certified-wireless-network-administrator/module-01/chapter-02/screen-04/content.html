Definition › Decibels and Logarithmic Ratios
dB: a ratio, not an absolute

Decibels convert multiplicative relationships into additive ones. Use them to combine amplifier gains, cable loss, and antenna gain cleanly.

Quick reference
  • +3 dB ≈ double the power
  • +10 dB ≈ ten times the power
  • dB itself is a ratio; pair with dBm for absolute power.
Common misconception

Treating dB as absolute. Always check whether values are relative (dB) or absolute (dBm).

Pro tip

Add dB values for gains and subtract for losses to get net change across a path.

Visual cards — interpret ratios
dB (ratio)
Logarithmic unit for power or amplitude ratios.
dBm (absolute)
Power relative to 1 mW. For example, 0 dBm = 1 mW.
Why it matters
Using dB arithmetic avoids multiplying small decimals and large numbers and makes link budget math intuitive.
Key Takeaway

Use dB to add gains and subtract losses; use dBm when you need an absolute power reference.
