RSSI formula

Use the provided formula to sum transmitter power and gains, subtract losses and path loss to get RSSI in dBm.

RSSI (dBm) = Tx Power (dBm)
  + Tx Antenna Gain (dBi)
  - Tx Cable Loss (dB)
  - FSPL (dB)
  + Rx Antenna Gain (dBi)
  - Rx Cable Loss (dB)

Example values:
  17 dBm + 5 dBi - 2 dB - 90 dB + 8 dBi - 3 dB
  = ? dBm (Estimated RSSI)
Calculation steps
  1. Start with Tx Power: 17 dBm
  2. Add Tx antenna gain: +5 dBi
  3. Subtract Tx cable loss: -2 dB
  4. Subtract FSPL: -90 dB
  5. Add Rx antenna gain: +8 dBi
  6. Subtract Rx cable loss: -3 dB
Worked numeric result
Apply the values

Summing the given terms produces: 17 + 5 - 2 - 90 + 8 - 3 = -65 dBm estimated RSSI. Negative values are expected for received signals.

What if distance doubles?

If FSPL increases by 6 dB, RSSI drops by 6 dB. Doubling distance often yields ~6 dB additional loss in many simplified models.

Key Takeaway

Use the link budget to predict RSSI and decide whether to change antennas, reduce cable loss, or shorten distance.
