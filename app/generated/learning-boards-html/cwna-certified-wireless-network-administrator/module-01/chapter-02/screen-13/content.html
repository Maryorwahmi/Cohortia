Hands-on Activity › Link Budget Calculation
Scenario values
  • Tx Power: 17 dBm
  • Tx Antenna Gain: +5 dBi
  • Tx Cable Loss: -2 dB
  • Free Space Path Loss: -90 dB
  • Rx Antenna Gain: +8 dBi
  • Rx Cable Loss: -3 dB
Computation:
  17 + 5 - 2 - 90 + 8 - 3 = -65 dBm (Estimated RSSI)

Self-check:
  - Is the RSSI negative? Yes, expected.
  - Would doubling distance likely make RSSI worse? Yes, usually by about 6 dB additional loss in simple models.
Interpretation card
Is -65 dBm acceptable?

Often yes for general data, but voice, low-latency or high-throughput applications may prefer stronger RSSI. Use application needs to judge adequacy.

Adjustment ideas

Improve cable loss, choose higher-gain antennas, shorten distance, or add APs rather than ramping transmit power indiscriminately.

Key Takeaway

The link budget turns component specs into an estimated RSSI so you can make targeted decisions about antennas, cables, and AP placement.
