Steps to gather network details
Run the platform command, observe PHY or Radio type, note SSID, BSSID, Channel, and infer operating band and likely amendment.
Windows
netsh wlan show networks mode=bssid
macOS
Hold Option and click Wi‑Fi icon → check PHY Mode and Channel
Or use Wireless Diagnostics → Window → Scan
Linux
iwlist scan
Example interpretation
If PHY Mode reads 802.11ac and channel is 36, the network is likely 5 GHz operating with ac features. If PHY Mode reads 802.11n and channel is 6, it’s likely 2.4 GHz n operation.
Key Takeaway
Practice these checks on at least three networks to build intuition about local spectrum use and dominant standards.
