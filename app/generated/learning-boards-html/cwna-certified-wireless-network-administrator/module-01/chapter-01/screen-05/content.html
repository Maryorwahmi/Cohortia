Module 1 › Chapter 1.1 › Modulation
What is modulation?
Encoding data by varying amplitude, frequency, or phase of a carrier wave so receivers can recover symbols.
OFDM
Divides a channel into narrow subcarriers which are modulated independently to improve efficiency and handle multipath.
QAM (constellation)
Higher‑order QAM packs more bits per symbol but needs better signal quality (higher SNR).
Concrete example
A 20 MHz channel using OFDM may contain dozens of subcarriers; each subcarrier can use different QAM levels. In a clean environment a receiver might decode 256‑QAM or 1024‑QAM; in a noisy area it will fall back to lower QAM with stronger coding.
Misconception
Assuming higher modulation always improves throughput. It can fail if signal quality is insufficient, causing retransmissions and lower net throughput.
Key Takeaway
Modulation controls spectral efficiency and robustness; choose technologies that match expected signal conditions.
