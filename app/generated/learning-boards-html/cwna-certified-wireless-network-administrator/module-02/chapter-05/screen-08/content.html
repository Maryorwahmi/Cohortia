Module 3 › Chapter 2.5 › WLC & CAPWAP
Wireless LAN Controller
Central device managing multiple lightweight APs and enforcing consistent policies.
Capabilities
  • Discover and provision APs
  • Push security and firmware updates
  • Coordinate RF settings, load balancing, and roaming
CAPWAP
Control and Provisioning of Wireless Access Points is a protocol used by lightweight APs to receive control-plane instructions from the WLC.
Key takeaway
WLCs simplify large-scale WLAN management and enable consistent security and roaming across many APs.
Deployment options
WLCs can be physical appliances, virtual machines, or cloud-managed services depending on vendor and operational needs.
Example
A university uses a virtual WLC cluster to manage hundreds of campus APs, pushing consistent authentication and roaming settings.
Misconception check
A WLC reduces per-AP configuration but does not eliminate the need to plan physical placement and wired capacity.
