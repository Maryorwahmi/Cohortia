Ad-hoc (IBSS)
Peer-to-peer wireless network with no central AP
Definition
Devices communicate directly. Each device handles its own security and associations.
Concrete example
Two laptops share a large file in a park using a temporary ad-hoc connection.
Common misconception
Ad-hoc can use encryption, but it lacks centralized policy and auditability, making it risky for persistent use.
Key takeaway
Use ad-hoc for quick, temporary peer tasks. Avoid for managed environments that require centralized security.
At-a-glance
Scale: very small • Management: none • Wired connectivity: no • Use case: temporary file sharing or gaming
Scenario
If you need fast peer sharing and no IT overhead, ad-hoc is simple. For longer-term or larger groups, prefer infrastructure.
Check your understanding
  • Can ad-hoc devices authenticate centrally? No.
  • Is roaming between ad-hoc groups seamless? No.
