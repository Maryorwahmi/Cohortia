Mesh Topology
APs form a mesh cloud, forwarding traffic across wireless backhaul links.
When to use mesh
Areas that are hard to wire, outdoor coverage, or temporary expansions where running Ethernet is costly.
Planning process
  1. Identify gateway location and intended coverage.
  2. Choose nodes with dedicated backhaul radios if possible.
  3. Minimize wireless hops and monitor link quality.
Performance note
Shared radios for access and backhaul reduce capacity. Design to avoid multi-hop traffic on the same channel where possible.
Key takeaway
Mesh adds flexibility and redundancy; plan backhaul radios, hop count, and placement to preserve performance.
Example scenario
A warehouse with obstructions where running cables is difficult. Mesh nodes provide coverage and multiple paths to a gateway.
Misconception check
Mesh is not a plug-and-forget replacement for wired backhaul; it trades simplicity for potential latency and capacity reductions without careful design.
Quick checklist
  • Is there a wired gateway or dedicated backhaul?
  • How many hops will client traffic traverse?
  • Do APs support separate backhaul radios?
