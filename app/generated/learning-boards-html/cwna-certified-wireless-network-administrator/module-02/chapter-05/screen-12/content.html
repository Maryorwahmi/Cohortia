WLAN Component Matching — Scenarios
Choose the best component or topology and explain trade-offs.
Need 1: 200 employees across three floors
Recommended: Controller-based APs with a WLC. Why: centralized management, automated RF and load balancing, consistent security and roaming across floors.
Need 2: Connect remote building
Recommended: Point-to-point wireless bridge. Why: transparent Layer 2 connectivity that preserves VLANs without running new cable.
Need 3: Quick file share in a park
Recommended: Ad-hoc (IBSS). Why: temporary peer-to-peer link with minimal configuration for immediate sharing.
Need 4: Backyard patio extension
Recommended: Repeater/extender for low cost; accept bandwidth loss. Alternative: wired AP or mesh with dedicated backhaul if throughput matters.
Reflection
When you recommend a design, always state the operational trade-offs: coverage, latency, management overhead, and security implications.
