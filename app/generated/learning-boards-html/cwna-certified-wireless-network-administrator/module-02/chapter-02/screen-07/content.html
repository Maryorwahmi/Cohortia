FHSS and DSSS
Early methods for resisting interference
FHSS: hops rapidly across channels to avoid narrowband noise but is inefficient for high throughput.
DSSS: spreads each bit with a chipping code to add redundancy and resist interference; used in 802.11b.
Example

FHSS is robust where narrowband interferers appear unpredictably. DSSS trades bandwidth for resilience via redundant chips per bit.

OFDM and OFDMA
Modern methods for high rates and dense use
OFDM: divides a stream into many orthogonal subcarriers, each robust to multipath and easier to equalize.
OFDMA: in 802.11ax, allows the channel to be divided among users so multiple clients transmit simultaneously on different subcarriers.
Key Takeaway

OFDM/OFDMA are the foundation of modern Wi‑Fi performance, especially where multipath and many clients coexist.
