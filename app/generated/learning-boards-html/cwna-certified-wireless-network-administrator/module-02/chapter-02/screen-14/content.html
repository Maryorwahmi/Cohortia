Module 2 › Chapter 2.2 › Key Concepts
PHY Layer
Translates bits to radio and sets symbol structure.
Modulation
BPSK, QPSK, QAM — bits per symbol set rate and noise tolerance.
Key Trade-off
More bits per symbol = higher rate, lower robustness.
Summary takeaway

Use modulation and PHY metrics as primary indicators when assessing link performance and design choices.
