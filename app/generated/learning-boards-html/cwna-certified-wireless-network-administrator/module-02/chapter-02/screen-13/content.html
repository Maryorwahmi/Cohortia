Module 2 › Chapter 2.2 › Client Capability
Match AP features to clients
Inventory client PHY support before relying on AP features
MU‑MIMO
AP can transmit to multiple clients simultaneously only when clients support MU‑MIMO.
256‑QAM
A client must support 256‑QAM and have high SNR to use this modulation.
OFDMA
Requires both AP and client support to gain multi-user efficiency benefits.
Operational advice

When you see poor client performance, check supported PHY features and observed modulation counts before changing AP settings. Design for the capabilities your devices actually have.
