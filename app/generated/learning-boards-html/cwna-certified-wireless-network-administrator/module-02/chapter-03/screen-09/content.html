Module 2 › Chapter 2.3 › RTS/CTS vs Hidden Nodes
How RTS/CTS works
Step 1: Sender issues RTS with duration.
Step 2: AP replies with CTS and duration.
Step 3: Stations hearing either frame set NAV and defer.
Example capture
RTS → CTS → Data → ACK indicates a protected handshake; NAV timers on listeners reflect the reserved airtime.
Tradeoffs
  • Benefit: prevents collisions when hidden nodes or long frames exist.
  • Cost: extra RTS/CTS frames consume airtime and add latency for every protected transaction.
  • Recommendation: enable selectively where captures or performance indicate hidden node collisions or costly retransmits.
Key Takeaway

Use RTS/CTS to protect long transmissions and mitigate hidden nodes, but avoid blanket activation without evidence.
