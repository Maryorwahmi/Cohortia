Module 2 › Chapter 2.3 › DCF vs PCF
Distributed Coordination Function (DCF)

Mandatory contention access using CSMA/CA. Each station independently senses and backs off; this decentralization scales well for typical WLANs.

When DCF fits
General purpose WLANs with diverse clients and traffic patterns; works with QoS extensions for prioritized access.
Point Coordination Function (PCF)

Optional polling by a point coordinator to create contention‑free periods. Eliminates contention but is rarely supported or used in modern deployments.

Why PCF is rare
Complexity and limited vendor support make PCF uncommon in commercial Wi‑Fi products.
Key Takeaway

Expect DCF and QoS extensions to be the practical mechanisms for most networks; PCF exists but is rarely used.
