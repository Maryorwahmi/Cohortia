Physical vs Virtual carrier sense
Physical: Detect energy, preamble, or a frame on the channel and defer.
Virtual (NAV): Read duration values from frames to set a local timer that prevents transmissions for that period.
Example flow
RTS from client → stations hearing RTS set NAV → AP replies CTS → stations hearing CTS set NAV → data exchange completes under reservation.
Why NAV matters

Without NAV, nodes that cannot hear transmitting devices might still start their own transmissions, causing collisions at a shared receiver. NAV provides a virtual agreement to remain silent.

Concrete impact
NAV reduces collisions caused by hidden nodes and supports controlled medium reservations for longer transmissions.
Misunderstanding
Relying only on physical sensing fails in the presence of spatially separated nodes; NAV extends awareness beyond what the radio physically hears.
