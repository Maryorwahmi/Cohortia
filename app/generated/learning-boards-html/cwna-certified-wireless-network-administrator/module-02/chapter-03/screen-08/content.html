How backoff works
Select a random slot: pick a number from [0..CW].
Decrement while idle: only when channel is free.
If collision detected: increase CW and retry.
Example
Under heavy load, doubling the contention window range decreases collision probability by spreading choices across more slots.
Practical notes
  • Backoff trades short idle time for fewer retransmissions.
  • Adaptive window growth stabilizes the network under contention.
  • Mis-tuning window sizes can either raise collisions or increase idle airtime.
Key Takeaway

Random backoff and adaptive contention windows are essential to converting contention into orderly, successful transmissions.
