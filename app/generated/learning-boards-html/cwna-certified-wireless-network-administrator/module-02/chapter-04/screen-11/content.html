Consistent security across an ESS
Authentication and encryption settings must be harmonized to allow smooth, secure roaming.
Why consistency matters
Clients expect the same authentication method when moving; mismatches cause reconnects or denials.
Management tools
Controllers and centralized DHCP/VLAN mapping help preserve session continuity and policy during roaming.
Key Takeaway

Security and VLAN consistency across the DS is required for both secure access and reliable roaming.

Concrete example
If one AP uses enterprise RADIUS and another uses a different method, a roaming client will lose session continuity. Central configuration avoids this issue.
Misconception
Same SSID indicates consistent security. It does not; verify auth and VLAN mapping across APs and the DS.
