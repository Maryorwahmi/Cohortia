Module 2 › Chapter 2.4 › ESS and ESSID
Extended Service Set (ESS)
A collection of infrastructure BSSs that share an ESSID and a Distribution System.
ESSID
The SSID shared by all BSSs in the ESS; used by clients to identify the broader network.
Distribution System (DS)
Backbone that carries inter‑AP traffic and connects the ESS to wired resources.
Seamless roaming
Client retains IP and session as it moves between APs tied into the DS.
Example
Campus APs wired into a VLAN and controller so users can move building to building without reauthenticating.
Misconception
Same SSID alone does not guarantee roaming; DS wiring and controller settings are required.
How frames move
  1. Client sends frame to its associated AP.
  2. AP forwards across the DS to the destination AP when needed.
  3. Destination AP transmits to the receiving client.
Key Takeaway

ESS = multiple APs + DS; ESSID is the shared network name that hides per‑AP BSS boundaries for users.
