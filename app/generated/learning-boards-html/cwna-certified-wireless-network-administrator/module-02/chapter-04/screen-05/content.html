Module 2 › Chapter 2.4 › IBSS vs Infrastructure
Independent BSS (IBSS)
Peer‑to‑peer ad‑hoc network without an AP.
Definition
Two or more clients communicate directly, with a locally generated BSSID.
When to use
Temporary, small peer tasks like quick file transfers or emergency links.
Limitation
No central management, no wired network access, poor scalability.
Infrastructure BSS
AP coordinates access and connects clients to a distribution system.
Definition
Clients associate to an AP which supplies the BSSID and forwards frames via the DS.
When to use
Managed networks, enterprises, and any site needing wired resources or centralized policy.
Pro tip
Infrastructure mode lets you control authentication, QoS, and roaming behavior centrally.
