Module 4 › Chapter 4.4 › Hands‑on: Device Checks
Windows example
netsh wlan show drivers
Look for fields like "Radio types supported" or explicit mentions of "WPA3" in the driver output to confirm support.
macOS
Open System Information → Wi‑Fi and inspect supported PHY modes and security protocols.
Router checks
Log into the router, open Wireless Security and check for options named "WPA3‑Personal", "WPA3‑Enterprise", or "WPA2/WPA3 Mixed Mode". If present, note firmware version and document the setting names.
Testing tip
Create a lab SSID with WPA3 enabled and attempt connections with a verified WPA3 client to confirm end‑to‑end support.
Key Takeaway

A command or menu label is a good sign, but always validate with a live connection to confirm full interoperability.
