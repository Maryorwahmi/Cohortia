Module 4 › Chapter 4.4 › Activity
Task steps
  1. Collect device details: model, OS, wireless driver/firmware versions.
  2. Run verification commands or OS tools to find WPA3 support indicators.
  3. Log into router and inspect Wireless Security for WPA3 options and firmware.
  4. Create a test SSID with WPA3 enabled and validate connections with supported clients.
  5. Document failures and plan updates or segmentation for legacy clients.
Testing rule
Always use test SSIDs and have a rollback plan before changing production Wi‑Fi settings.
Outcome
A documented inventory and a validated test connection give you the evidence needed to schedule a safe migration to WPA3.
