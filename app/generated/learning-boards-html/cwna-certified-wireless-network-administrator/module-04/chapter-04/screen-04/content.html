Module 4 › Chapter 4.4 › WPA2 Vulnerability
Definition

Offline dictionary attack on WPA2

A passive capture of the four‑way handshake allows an attacker to verify passphrase guesses offline without interacting with the AP or client.

Why it matters: attackers can brute force at their own pace, potentially recovering passphrases and decrypting recorded traffic.
Common misconception: handshake integrity alone stops guessing — it does not when verification can be done offline.
Key takeaway

Preventing offline verification of guesses is the primary design goal that led to adopting SAE in WPA3‑Personal.

Concrete example
Imagine a cafe Wi‑Fi where an attacker records a customer's connection. With the WPA2 handshake captured, they can later run password lists and GPU‑accelerated cracking tools to try guesses until they find a match. The attacker needs no further network access to verify each guess.
Impact: recovered passphrases allow decryption of previously recorded sessions and may expose sensitive data.
Mitigation goal: eliminate the ability to verify guesses using only captured handshakes.
