Definition
WEP: why it failed
RC4 + 24‑bit IV + static PSK produced repeated keystreams and weak integrity.
Key points:
  • 24‑bit IV repeats quickly on busy networks, enabling keystream reuse.
  • RC4 as a stream cipher requires unique nonces; reuse leaks key material.
  • CRC‑32 integrity is linear and cannot prevent deliberate frame tampering.
Concrete example
Imagine capturing thousands of frames on a cafe AP: repeated IVs show the same RC4 keystream segments. Tools can analyze those repeats to reconstruct the key and decrypt traffic.
Common mistake
Assuming hiding an SSID or disabling broadcasts prevents key recovery — it doesn't stop IV reuse or statistical attacks.
Key Takeaway
Key Takeaway

WEP’s cryptographic design and IV handling allow easy key recovery; do not use WEP.
