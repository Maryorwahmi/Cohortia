Architecture
WPA2‑Personal: PSK → Handshake → Session keys
Components:
  • Pre‑Shared Key (PSK) — passphrase held on AP and clients.
  • Four‑way handshake — derives per‑session keys from PSK and nonces.
  • Pairwise transient keys — used with AES‑CCMP for frame protection.
Concrete example
An attacker captures the four‑way handshake when a client connects. With the handshake stored offline, they can test passphrases until the derived keys match, recovering the correct PSK if it is weak.
Misconception
WPA2‑PSK does not make offline cracking impossible; it shifts the burden to choosing a strong, unguessable passphrase.
Key Takeaway

PSK-based security relies on the strength of the passphrase; the handshake design is secure but cannot protect a weak password from offline attacks.
