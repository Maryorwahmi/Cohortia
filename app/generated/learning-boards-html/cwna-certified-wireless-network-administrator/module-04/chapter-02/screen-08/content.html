Definition
WPA2: AES‑CCMP
AES‑CCMP combines:
  • Counter Mode (CTR) for confidentiality.
  • CBC‑MAC style authentication for integrity.
  • Authenticated encryption to prevent tampering and replay.
Concrete example
With AES‑CCMP, even a large capture of frames does not reveal useful keystream reuse; each frame's encryption and authentication are robust, so offline keyless analysis is impractical.
Why mode matters
AES must be used with a secure authenticated mode like CCMP; raw AES without proper mode and integrity would not meet the same security properties.
Key Takeaway

WPA2’s AES‑CCMP delivers authenticated encryption and is the recommended cipher for WPA2 Personal when paired with a strong PSK.
