Assessment Idea
Practice: choose the strongest configuration
Checklist for answers:
  • Is AES‑CCMP selected as the cipher?
  • Is the mode WPA2‑PSK (Personal) explicitly chosen?
  • Is the passphrase length and complexity sufficient?
  • Are admin credentials and mixed modes addressed?
Sample question breakdown
Which is best: WPA2‑PSK + AES‑CCMP + 20‑char passphrase? Yes — this gives robust cipher mode and a strong PSK resisting offline attacks.
Trap answer
Options that use TKIP, WEP, or short passphrases are weaker even if they include a passphrase conditionally.
Key Takeaway

Use a structured checklist to select secure options: cipher, mode, and PSK strength determine overall security.
