Comparison
WEP vs WPA (TKIP)
WEP
  • RC4 with static key
  • 24‑bit IV, frequent reuse
  • Weak CRC integrity
WPA (TKIP)
  • Per‑packet key mixing and 48‑bit IV
  • Sequence counter to prevent replay
  • MIC (Michael) for stronger integrity
Practical note
TKIP was a compatibility solution: it improved real‑world security for older hardware but did not match AES‑CCMP's cryptographic strength.
Concrete example
A vendor released a firmware update implementing TKIP and Michael. Devices previously susceptible to quick WEP cracking now required far more complex attacks, often making casual attackers move on. However, because RC4 remained, determined attackers still found weaknesses over time.
Misconception
Assuming WPA with TKIP equals modern AES security is incorrect; it was an interim mitigation, not the final solution.
Key Takeaway

WPA bridged WEP’s gaps with per‑packet keys and integrity, but TKIP’s reliance on RC4 left it weaker than AES‑CCMP.
