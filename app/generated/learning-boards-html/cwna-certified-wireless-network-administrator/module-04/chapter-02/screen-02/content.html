Learning Objectives
Understand design failures, protocol fixes, and secure PSK practices.
Bloom: Learn → Understand → Apply → Master
01
Explain WEP’s weaknesses
Describe the IV reuse problem and its cryptographic consequences. You will see how repeated IVs lead to keystream recovery and rapid key cracking.
VERIFIED COMPETENCY MILESTONE
02
Describe WPA (TKIP & MIC)
Explain how TKIP added per‑packet keying, a larger IV, and a sequence counter, and how MIC addressed tampering risks.
VERIFIED COMPETENCY MILESTONE
03
Explain WPA2‑PSK and AES‑CCMP
Understand how AES‑CCMP provides both confidentiality and integrity and how the PSK feeds the handshake to create session keys.
VERIFIED COMPETENCY MILESTONE
04
Manage PSKs securely
Apply best practices: long, random passphrases, periodic rotation after device loss, and avoiding defaults to reduce offline cracking risk.
VERIFIED COMPETENCY MILESTONE
