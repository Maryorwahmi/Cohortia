Terminal commands
Example scanning commands to run locally. These are illustrative; use the command appropriate for your OS and adapter.
C:\> netsh wlan show networks mode=bssid
SSID 1 : CorpWiFi
    Network type            : Infrastructure
    Authentication          : WPA2-Personal
    BSSID 1                 : 00:11:22:33:44:55
         Signal             : 78%
    BSSID 2                 : 66:77:88:99:AA:BB
         Signal             : 20%

$ sudo iwlist wlan0 scan
          Cell 01 - Address: 00:11:22:33:44:55
                    ESSID:"CorpWiFi"
                    Channel:6
                    Quality=70/70  Signal level=-40 dBm
          Cell 02 - Address: 66:77:88:99:AA:BB
                    ESSID:"CorpWiFi"
                    Channel:1
                    Quality=10/70  Signal level=-90 dBm
How to read these results
  • Compare each BSSID to your authorized AP inventory.
  • Note channels and signal; a weak signal with the same SSID may indicate a remote evil twin.
  • Check authentication: open or WEP is immediate risk.
Scenario & reflection

If your scan shows multiple BSSIDs for an expected SSID, validate each MAC against inventory and consult switch port mapping. If an AP is unknown, isolate its uplink, inform users, and consider rotating keys if compromise is likely.

Common mistakes

Trusting SSID names alone or ignoring security settings. Always verify BSSIDs and encryption types before concluding an AP is trusted.

Key Takeaway

A simple scan yields valuable signals. Use BSSID, channel, signal, and security to spot anomalies and escalate appropriately.
