Module 4 › Chapter 4.1 › Eavesdropping
Definition

Passive sniffing of wireless frames

Capture of over-the-air frames without transmitting — requires only a listening radio and appropriate software or driver mode.

Mitigations
  • Strong WPA2/WPA3 encryption with robust key management.
  • Application-layer TLS for end-to-end confidentiality.
  • Avoid weak shared passwords and default keys.
Misconception

If clients connect using a password, traffic is safe — false if the encryption or key is weak or compromised. Always validate cipher suites and key strength.

Concrete example

A café patron in monitor mode captures frames. They find an open SSID with HTTP traffic and extract submitted form data. If the same user had used TLS, the data would remain protected even if captured.

Check your network

Verify the observed SSID uses WPA2/WPA3 and strong cipher suites. If an AP advertises open or WEP, treat it as high risk.

Key Takeaway

Prevent passive capture with strong, modern encryption and application-layer protections.

Pro tip

When auditing, note the cipher and key length advertised by APs. Weak ciphers or legacy modes are immediate remediation items.
