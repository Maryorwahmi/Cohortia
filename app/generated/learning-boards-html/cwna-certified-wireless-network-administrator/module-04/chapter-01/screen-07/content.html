Module 4 › Chapter 4.1 › Evil Twin
Comparison
Legitimate AP
  • Known BSSID in inventory
  • Consistent channels and signal patterns
  • Managed configuration and monitoring
Evil Twin
  • Different BSSID yet same SSID
  • Unusual channel or intermittent signal
  • Unaudited or unmanaged device
Detection steps

Check BSSID against the authorized list, inspect the AP's security settings, and look for correlated deauthentication events that might force reconnections.

Concrete example

An attacker sets up an AP named 'CorpWiFi' in the office lobby. Several users reconnect and later report credential theft. Investigation shows two BSSIDs advertising the same SSID; one matched inventory, the other did not.

Response
  1. Inform users and advise disconnection from the suspected AP.
  2. Physically locate and disable the malicious transmitter if possible.
  3. Rotate keys or credentials if compromise is suspected.
Misconception

Clients automatically choose the secure AP — false. Clients may connect to any AP that appears acceptable, so detection and user guidance are necessary.
