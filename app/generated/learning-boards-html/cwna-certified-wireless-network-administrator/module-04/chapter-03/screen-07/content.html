What PEAP does
TLS tunnel protecting inner authentication
  • Server presents a certificate; client validates CA and optionally server name.
  • After tunnel creation, an inner method such as MSCHAPv2 carries user credentials securely.
  • Client certificates are usually not required, easing deployment.
Example
A corporate laptop uses PEAP with stored domain credentials; the server certificate prevents credential interception during the login exchange.
Operational note
Ensure clients trust the CA that issued the RADIUS server certificate and enable server name checking when possible.
Common mistake

Disabling server certificate validation undermines the TLS tunnel and exposes user credentials to rogue servers.

Key Takeaway

PEAP offers strong protection for passwords without requiring client certificates, provided the client validates the server certificate.
