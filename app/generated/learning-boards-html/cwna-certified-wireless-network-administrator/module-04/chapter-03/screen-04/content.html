Module 4 › Chapter 4.3 › Why Enterprise WPA/WPA2
Definition
PSK vs Enterprise
  • PSK: single shared passphrase; simple but not scalable.
  • Enterprise: 802.1X with per-user authentication; dynamic session keys and centralized control.
  • Practical effect: single compromised credential no longer exposes all users.
Analogy
Think of PSK as one key that opens every office door; enterprise authentication is like unique badges for each employee that can be deactivated individually.
Example
In a 500-person company, a PSK compromise forces a network-wide password change. With 802.1X, revoke one account on RADIUS and issue a new certificate or credential only for that user.
Impact
Reduced blast radius for a compromise.
Trade-off
Higher operational setup and certificate or credential management.
Key Takeaway

Enterprise mode provides per-user keys and centralized control, making it the appropriate choice for networks that need scalable security and revocation capability.
