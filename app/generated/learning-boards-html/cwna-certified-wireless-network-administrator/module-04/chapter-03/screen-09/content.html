Module 4 › Chapter 4.3 › EAP-TTLS
Flexible inner authentication
Server certificate creates TLS tunnel; inner methods inside the tunnel can vary, allowing deployment flexibility.
  • Often used where client certificates are optional or not available.
  • Server presents certificate; client validates CA trust before inner exchange.
  • Supports multiple inner methods, enabling broader client compatibility.
Deployment notes
Carefully select inner methods and enforce server certificate validation to protect credentials inside the tunnel.
Example
A mixed-device environment where older endpoints use password-based inner auth while managed devices use stronger methods.
Misconception
Assuming inner authentication is secure without server validation. The tunnel must be verified by clients to protect credentials.
Key Takeaway

EAP-TTLS gives more flexibility for inner authentication methods but still relies on server certificates and client validation to be secure.
