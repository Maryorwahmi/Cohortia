Module 4 › Chapter 4.3 › Three 802.1X Roles
Supplicant
Client device with 802.1X client software that provides identity and completes EAP authentication.
Authenticator
Access point or switch that relays EAP messages and enforces access control based on the authentication server's response.
Authentication Server (RADIUS)
Central server that verifies credentials, applies policies, and supplies session keys that the authenticator uses for encryption.
Process Flow
1. Association and Identity
Supplicant joins SSID; authenticator asks for identity with EAP-Request/Identity.
2. Relay to RADIUS
Authenticator forwards identity to the authentication server to begin the EAP conversation.
3. Authorization
RADIUS decides accept or reject and can instruct the authenticator to install per-session encryption keys.
Key Takeaway

Clear separation of roles simplifies security: clients prove identity, APs enforce gatekeeping, RADIUS makes the trust decision.
