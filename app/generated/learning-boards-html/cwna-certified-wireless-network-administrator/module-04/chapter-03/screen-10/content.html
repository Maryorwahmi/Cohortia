Module 4 › Chapter 4.3 › Certificate Management
Why certificates matter
Certificates bind an identity to a public key and allow clients to verify the RADIUS server and, in EAP-TLS, the client device itself.
  • Server certificates prevent rogue RADIUS servers from harvesting credentials.
  • Client certificates allow device-level authentication that is hard to share or spoof.
  • PKI is required to manage these certificates at scale.
Example
A lost device's certificate is revoked so the device cannot authenticate even if the password or other factors are available.
Operational checklist
  • Distribute trusted root CAs to clients before enabling server validation.
  • Plan automated certificate enrollment and renewal.
  • Implement revocation checking and monitoring to avoid expired or revoked certificates causing outages.
Common mistake

Using self-signed server certificates without deploying the signing root to clients, leading administrators to disable validation and exposing credentials to attack.
