Module 4 › Chapter 4.3 › Client Hands-on
Activity steps
  1. Open Control Panel → Network and Sharing Center.
  2. Set up a manual wireless profile with WPA2-Enterprise and AES.
  3. Change connection settings → Security tab → inspect EAP methods.
  4. Open PEAP settings: check 'Validate server certificate', CA list, and inner auth.
Reflection prompt
Which CA roots appear on your client and how would you provision additional trust anchors for managed devices?
Concrete example
Creating the dummy profile shows the exact options your users will encounter and the checks that prevent rogue server attacks.
Key Takeaway

Client inspection reveals configuration gaps early so you can design provisioning that enforces server validation and correct inner methods.
