Module 4 › Chapter 4.3 › Client Configuration
Windows example
Create a manual SSID with WPA2-Enterprise and AES. Under security settings, review the Network authentication method and PEAP settings.
Control Panel → Network and Sharing Center
→ Set up a new connection or network
→ Manually connect to a wireless network
• SSID: EnterpriseNet
• Security type: WPA2-Enterprise
• Encryption: AES
→ Change connection settings → Security tab
• Network authentication method: Protected EAP (PEAP)
• Settings: Validate server certificate, Trusted CA, Inner auth: MSCHAPv2
Practice tip
Use device management to push CA trust anchors and EAP profiles to avoid manual mistakes.
What to check
  • Is 'Validate server certificate' enabled and a CA selected?
  • Is the server hostname constrained so clients accept only the intended RADIUS name?
  • Which inner authentication method is selected inside PEAP or TTLS?
Key Takeaway

Inspect and enforce server validation on clients and provision trusted roots centrally to prevent credential exposure.
