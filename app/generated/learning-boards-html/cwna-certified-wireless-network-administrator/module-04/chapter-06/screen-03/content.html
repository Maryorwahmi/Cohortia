Skill checks and validation

VLAN & DHCP
Confirm guest VLAN uses a separate DHCP scope and gateway. A correct lease proves logical separation.
Firewall Rules
Verify outbound-only access and explicit denies to internal ranges. Allow rules should be narrow by port.
Client Isolation
Ensure guest clients cannot reach each other to reduce lateral attacks between visitors.
Quick verification exercise
  1. Connect a test device to the guest SSID and confirm the IP is in the guest DHCP range.
  2. Attempt to ping a known internal IP; it should fail if firewall rules are correct.
  3. Try browsing to an external website; access should succeed only to allowed ports.
