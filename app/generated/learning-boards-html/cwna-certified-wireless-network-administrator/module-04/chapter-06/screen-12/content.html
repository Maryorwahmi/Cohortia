Review Guest Configuration

Use the following conceptual checklist when reviewing a guest network:
  • SSID mapped to a dedicated VLAN ID.
  • Separate DHCP scope for guest VLAN.
  • Firewall rules: allow outbound internet ports only; explicit deny internal ranges.
  • Client isolation enabled.
  • Captive portal tied to guest VLAN policies, not bypassing filters.
Scenario reflection
If any check fails, prioritize separation of network resources first, then review portal and rate limits. Shared PSKs should be replaced with per-session methods when possible.
Key Takeaway
Isolation is verified by configuration and test: distinct VLAN and DHCP plus firewall denies demonstrate proper separation.
