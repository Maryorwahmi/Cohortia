Architecture

Segmentation Pattern

Typical VLAN layout:
  • VLAN 100 — Corporate: 802.1X, internal servers permitted.
  • VLAN 10 — Guest: captive portal, DHCP scope separate, outbound-only firewall.
  • VLAN 200 — IoT: limited access to cloud endpoints, no access to corporate LAN.
Common mistake
Allowing shared services like DHCP on multiple VLANs without controls can break isolation.
Example ACLs
Guest VLAN -> deny 10.0.0.0/8 Guest VLAN -> permit 0.0.0.0/0 ports 80,443,53 Management VLAN -> permit only admin network to controller ports
Key Takeaway
Enforced policies are as important as logical separation. Test and document ACLs to verify boundaries.
