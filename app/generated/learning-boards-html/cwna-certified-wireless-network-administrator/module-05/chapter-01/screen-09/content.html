Module 5 › Chapter 5.1 › Design Specification
Translate requirements into specs
Create acceptance criteria, channel plans, and validation steps.
Example mapping
Requirement: VoWi‑Fi in exam rooms → Spec: RSSI ≥ -67 dBm and SNR ≥ 25 dB, roaming latency <50 ms.
Capacity spec
Requirement: 50 concurrent streaming clients → Spec: 250 Mbps aggregate and AP count justification with uplink capacity.
Validation
Pilot test checklist, site survey pass/fail, and stakeholder sign-off on acceptance metrics.
AP Placement & Channel Table
Include a simple table in the design document listing AP location, channel, and target transmit power so installers have clear instructions tied to specs.
Key Takeaway
Design documents must enable verification: clear, numeric criteria linked to tests and evidence.
