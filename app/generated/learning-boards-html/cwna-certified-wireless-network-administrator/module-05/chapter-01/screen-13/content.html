Calculation Walkthrough
Turn user counts and per-user needs into AP and uplink decisions.
Step-by-step
  1. Estimate concurrent active users for the area.
  2. Multiply by per-user Mbps to get aggregate throughput.
  3. Add overhead margin for contention and protocol inefficiency.
  4. Select AP count based on tested real-world AP throughput and plan uplink capacity accordingly.
Concrete example
// Conference room example
users = 50
per_user_mbps = 5
aggregate = users * per_user_mbps  // 250 Mbps
overhead_margin = 1.3              // 30% margin
required_capacity = aggregate * overhead_margin // 325 Mbps
ap_effective_throughput = 100     // measured per-AP in this environment
ap_needed = ceil(required_capacity / ap_effective_throughput) // 4 APs
Key Takeaway
Always base AP counts on measured or vendor-validated effective throughput and include overhead so the deployed network meets real demands.
