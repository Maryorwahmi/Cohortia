Module 5 › Chapter 5.5 › Configuring the Survey Client
Step-by-step
  1. 1. Attach and verify the external Wi‑Fi adapter and drivers.
  2. 2. Configure SSID and exact security settings that production clients use.
  3. 3. Obtain IP via DHCP or assign correct static IP and confirm reachability to test server.
  4. 4. Confirm survey software will associate continuously and record AP associations.
  5. 5. Verify AP channel and transmit power match design settings.
Mnemonic: Adapter → Authenticate → Address → Associate → Validate
Why each step matters
  • Driver/adaptor: ensures correct transmit/receive behavior and channel support.
  • Security parity: authentication and keying affect roam and throughput results.
  • IP reachability: needed for iPerf to a wired server and for real application tests.
  • AP settings: test results reflect the final deployment only if AP power and channels are set as designed.
Common mistake
Testing with a different security profile or without a wired test server yields invalid throughput results.
