Learning Objectives

Build practical competence in configuring active surveys and interpreting their results.

01
Distinguish active vs passive surveys

Explain the distinct purpose of active surveys and why they measure user experience not just RF conditions. This prevents relying on RSSI alone when validating designs.

Verified competency milestone
02
Configure survey client

Set up the laptop and external adapter to associate to the target SSID, use production security, and obtain an IP via DHCP or static assignment to run realistic tests.

Verified competency milestone
03
Measure and interpret KPIs

Record throughput, retransmissions, roaming latency, jitter and packet loss and use them to find capacity and interference problems that RSSI would miss.

Verified competency milestone
04
Evaluate roaming and application tests

Analyze roaming behavior for sticky client issues and run application-specific flows like VoIP or streaming to validate QoS and performance.

Verified competency milestone
