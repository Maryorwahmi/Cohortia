Module 5 › Chapter 5.5 › Running Throughput Tests with iPerf
Example commands (illustrative)
# On wired test server
iperf3 -s

# On survey laptop (download test)
iperf3 -c 10.0.0.5 -t 60

# On survey laptop (upload test)
iperf3 -c 10.0.0.5 -t 60 -R
Note: run both directions and record average Mbps and retransmission indicators from the survey tool.
Interpreting results
  • If measured throughput meets or exceeds design targets, the space likely passes capacity requirements.
  • If throughput is low but retransmissions are high, investigate RF interference or AP density.
  • If upload is poor but download is fine, consider asymmetric congestion or AP configuration issues.
Pitfall
No wired test server means you cannot isolate wireless throughput from upstream bottlenecks; results will be unreliable.
