Module 5 › Chapter 5.5 › Application-Specific Testing
Why test applications?

Applications have different sensitivities. Real-time apps need low jitter and roaming tolerance; bulk transfers need sustained throughput. Test each with representative traffic.

VoIP: monitor jitter and packet loss during calls.
Video: confirm sustained bitrate and buffering behavior.
Special apps: run the exact application, e.g., medical imaging, to validate performance.
Example checklist
  • Define pass/fail criteria for each application.
  • Run test flows while walking typical user paths.
  • Record objective KPIs and subjective user experience notes.
If app fails but bandwidth looks ok
Suspect jitter, packet loss, or uplink asymmetry. Correlate with retransmissions and roaming events for root cause.
