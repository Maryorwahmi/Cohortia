Survey script
  1. Verify adapter and drivers; connect to production SSID and security.
  2. Confirm IP and reachability to wired test server.
  3. Run iPerf download and upload tests (60 seconds each).
  4. Execute application-specific flow (VoIP call, video stream, or file transfer).
  5. Perform roaming walk, recording handoffs and latency.
  6. Collect at least ten samples per representative path.
  7. Document AP settings and environment; save logs and traces.
Key Takeaway
A reproducible checklist ensures objective, repeatable validation and credible before-and-after comparisons.
