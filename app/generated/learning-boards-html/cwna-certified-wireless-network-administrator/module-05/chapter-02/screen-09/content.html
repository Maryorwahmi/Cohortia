Module 5 › Chapter 5.2 › Survey software and quick analyzer apps
Software Tools

From CAD import to heatmap export

Full survey suites let you model, measure, and produce the reports installers need — mobile apps are helpful but limited.

Core features
Floor plan import, wall/material drawing, virtual AP placement, passive/active data logging, heatmap generation, and report export.
Mobile analyzer apps
Quick visibility into RSSI, channels, and SSIDs; best for spot checks and troubleshooting but not full surveys.
Practical checklist
  • Verify floor plan scale before importing.
  • Document antenna orientation and adapter model for reproducibility.
  • Capture spectrum screenshots and attach them to location notes.
Example output
Heatmaps layered by RSSI or SNR, AP placement export, and a PDF report that lists assumptions and recommended cabling routes.
Key Takeaway

Use mobile apps for quick checks; use survey software for accurate measurements, mapping, and formal deliverables.
