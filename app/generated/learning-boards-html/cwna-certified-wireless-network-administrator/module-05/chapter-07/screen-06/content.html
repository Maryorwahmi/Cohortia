Module 6 › Chapter 5.7 › Client Density Calculations

Calculation flow

  1. Estimate peak active clients in the space.
  2. Pick expected per-client throughput (Mbps).
  3. Compute aggregate throughput (clients × Mbps).
  4. Divide by usable AP throughput to find AP count and add headroom.
Worked example
500 users × 2 Mbps = 1000 Mbps aggregate. If each AP can reliably serve 150 Mbps usable, you need about seven APs, plus headroom and channel planning to avoid contention.
Design note

Advertised PHY rates are not usable throughput. Build calculations on conservative usable throughput values.

Concrete example card
# Example (conceptual)
clients = 500
per_client_mbps = 2
aggregate = clients * per_client_mbps  # 1000 Mbps
usable_per_ap = 150  # conservative estimate
ap_count = ceil(aggregate / usable_per_ap)  # ~7 APs + headroom
This pseudocode shows the math flow. In practice you round up, add margin for retransmissions and management frames, and map AP counts to physical mounting positions and channel plans.
Common Mistake
Using PHY rates as usable capacity leads to under-provisioning. Always use conservative usable throughput numbers.
