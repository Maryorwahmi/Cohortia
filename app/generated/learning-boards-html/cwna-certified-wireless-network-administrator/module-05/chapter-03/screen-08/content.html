Module 5 › Chapter 5.3 › Virtual AP Placement — Coverage
Core Concept

Coverage-driven AP placement

Place APs to meet a minimum RSSI target across the area and iterate based on heatmap feedback.

Action steps
  1. Set a minimum RSSI target for the site.
  2. Place APs and generate an RSSI heatmap.
  3. Move or add APs where heatmap shows values below the target.
  4. Re-run heatmap until coverage target is met with moderate overlap.
Misconception

Boosting power is not a universal fix. It can increase co-channel interference and reduce overall performance if not paired with placement adjustments.

Example

If a classroom shows RSSI below the target, place an additional AP nearer to the classroom or move the original AP to a more central position, rather than simply increasing transmit power.

Key Takeaway

Target RSSI first, then iterate AP placement and power. Validate with SNR and throughput heatmaps afterward.
