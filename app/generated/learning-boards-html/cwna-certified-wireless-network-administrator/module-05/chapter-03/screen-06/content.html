Definition

Material Attenuation

Assign dB losses to represent how materials reduce signal strength and shape coverage.

Common values
  • Drywall partition (5 GHz): ~3–5 dB
  • Thick concrete wall: ~10–15 dB
  • Metallic obstructions (elevator, shelving): much higher loss—treat with caution
Modeling tips
  • Use the software library but customize values if local construction differs.
  • Draw walls, doors, and windows so their locations affect heatmaps correctly.
Pitfall

Treating all partitions the same will produce misleading coverage. Validate high-loss features like shear walls or large metal objects in your model.

Example

In the sample office scenario use 12 dB for exterior concrete walls and 4 dB for interior drywall partitions to see how these losses change predicted RSSI across rooms.

Key Takeaway

Material values are a major input — get them right or validate them physically when possible.
