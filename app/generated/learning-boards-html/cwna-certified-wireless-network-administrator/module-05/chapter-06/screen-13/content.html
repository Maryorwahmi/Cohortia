Module 5 › Chapter 5.6 › Key Concepts
Post‑Survey Analysis
Interpreting collected data to identify root causes and guide design changes.
Site Survey Report
A structured document containing findings, recommendations, proposed design and BoM.
Actionable Recommendations
Specific steps tied to data with expected outcomes and priorities.
Summary Takeaway

Always link recommendations to measured evidence, present paired heatmaps for context, and include a BoM plus monitoring plan so implementations are verifiable and sustainable.
