Reassociation flow
  1. Client detects a better AP and sends Reassociation Request to the new AP including previous AP ID.
  2. New AP may query old AP via the distribution system to transfer buffered frames and context.
  3. New AP replies with Reassociation Response with status and new AID.
Example
A video call continues smoothly when the new AP pulls buffered packets and maintains QoS mapping. If contexts differ, you'll notice packet loss or reauthentication delays.
Diagnostics
If roaming fails, compare security IEs, check AID assignment behavior, and confirm distribution system connectivity between APs.
Key Takeaway

Reassociation reduces interruption during roaming by transferring association context, but infrastructure compatibility is required for best results.
