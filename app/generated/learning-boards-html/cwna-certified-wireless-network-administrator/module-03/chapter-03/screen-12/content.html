Module 3 › Chapter 3.3 › Wireshark Capture
Steps
  1. Enable monitor mode and lock the adapter to a channel.
  2. Start capture and let beacons accumulate for several intervals.
  3. Generate probe activity by toggling Wi‑Fi on a client device if needed.
  4. Stop capture and apply display filters to isolate management frames.
Useful display filters
wlan.fc.type == 0
wlan.mgt.subtype == 8   # Beacon
wlan.mgt.subtype == 5   # Probe Response
wlan.mgt.subtype == 4   # Probe Request
wlan.mgt.subtype == 11  # Authentication
wlan.mgt.subtype == 0   # Association Request
wlan.mgt.subtype == 1   # Association Response
wlan.mgt.subtype == 12  # Deauthentication
wlan.mgt.subtype == 10  # Disassociation
Example exercise
Capture for two minutes on channel 6 with Wireshark, then filter for Probe Requests and look at the SSID field in each request to see directed probes from clients.
Common mistake
Using a channel-hopping capture without sufficient dwell time causes missed frames. Lock to one channel for reliable captures.
Key Takeaway

Monitor mode plus targeted filters reveal the management frame exchanges needed for troubleshooting and security analysis.
