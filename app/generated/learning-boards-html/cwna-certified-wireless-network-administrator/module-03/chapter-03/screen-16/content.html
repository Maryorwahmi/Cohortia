Module 3 › Chapter 3.3 › Quick Reference
Inspect management IEs
SSID, rates, channel, and security fields often reveal the root cause of failures.
Prefer passive for power
Active probes are faster but increase transmit activity and may leak SSID interests.
Know disconnect types
Disassoc = graceful leave. Deauth = full teardown and possible attack vector if unprotected.
Final Reflection
When a client fails to connect, locate the first management frame with an error or unexpected content — that's usually your starting point.
