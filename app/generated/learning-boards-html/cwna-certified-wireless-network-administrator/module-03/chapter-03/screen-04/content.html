Module 3 › Chapter 3.3 › Beacon Frames
Definition
What a Beacon contains
  • SSID: the network name advertised to passive scanners.
  • Supported Rates: the physical rates the AP accepts.
  • Channel Info & Timestamp: used for synchronization and channel assignment.
  • Security Capabilities: WPA2/WPA3 flags shown as IEs.
Practical example
If a Beacon shows WPA2-only but a client requires WPA3, the client will not proceed. Or if the supported rates omit a rate the client needs, association may fail.
Key Takeaway

Beacons are authoritative for passive discovery; inspect their IEs first when diagnosing client compatibility and configuration errors.

Annoted IE view
IE: SSID
Visible name or null if hidden.
IE: Supported Rates
Lists allowed PHY rates; clients use this to choose rates during association.
IE: Security
Flags indicating WPA/WPA2/WPA3 support. Mismatch here is a common failure point.
Common mistake: hiding an SSID removes it from Beacons but does not stop active probes. Hidden networks can cause client instability.
