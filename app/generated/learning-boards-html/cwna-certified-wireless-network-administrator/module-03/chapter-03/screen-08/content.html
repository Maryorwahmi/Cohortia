Module 3 › Chapter 3.3 › Association & AID
Association Request
Client advertises its capabilities: supported rates, QoS, and power save preferences. This lets the AP decide whether to accept and allocate resources.
If rejected, the Association Response contains a status code explaining the reason.
Association Response & AID
If accepted, the AP supplies an AID. This 16‑bit value is used for tracking, buffered delivery, and power save operations.
Example
In a failing connection, look for an Association Response status code other than success. Then compare the client's requested rates and the AP's supported rates to find mismatches.
Key Takeaway

Association makes the client a tracked station in the BSS and provides an AID used for resource mapping and power management.
