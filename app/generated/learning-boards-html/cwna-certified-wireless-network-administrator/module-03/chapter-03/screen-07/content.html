Module 3 › Chapter 3.3 › Authentication
Open System Authentication
Two‑step exchange: Authentication Request followed by Authentication Response. It simply confirms MAC‑layer identity and readiness to proceed to association.
Open System does not authenticate credentials. Expect a separate 4‑way handshake for cryptographic key establishment after association in WPA networks.
Shared Key (Deprecated)
Uses a challenge/response based on a pre‑shared key. Vulnerable to attack and rarely used in modern deployments.
Diagnostic tips
  • Check Authentication Transaction Sequence Number to see exchange progress.
  • Look at Algorithm Number to determine Open vs Shared Key.
  • Failure here halts association; determine whether MAC filtering or policy is rejecting the client.
Key Takeaway

MAC authentication is a necessary handoff to association and higher-layer security, but it is not the primary mechanism for credential verification or encryption.
