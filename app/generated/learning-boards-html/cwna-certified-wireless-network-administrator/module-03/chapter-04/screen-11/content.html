Module 3 › Chapter 3.4 › Capturing with Wireshark
Quick filters
wlan.fc.type == 1        // show control frames only
wlan.fc.type_subtype == 0x1b  // RTS
wlan.fc.type_subtype == 0x1c  // CTS
wlan.fc.type_subtype == 0x1d  // ACK
wlan.fc.type_subtype == 0x1a  // PS-Poll
Procedure: enable monitor mode, capture on AP channel, generate traffic or lower RTS Threshold to force handshakes, then inspect Duration and retry counters.
Concrete steps
  1. Put NIC into monitor mode on the AP channel.
  2. Start capture and initiate a large transfer or lower RTS Threshold.
  3. Stop capture after 1–2 minutes and apply filters above.
  4. Inspect Duration fields and search for missing ACKs and retries.
Common-mistake
Using a non‑capable adapter or wrong channel — you must capture where the AP and clients operate and support monitor mode for control frames to be visible.
