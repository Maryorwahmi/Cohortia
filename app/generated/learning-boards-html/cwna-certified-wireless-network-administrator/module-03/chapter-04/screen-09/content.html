Module 3 › Chapter 3.4 › Block ACK
Aggregated acknowledgement
One Block ACK replaces many individual ACKs and indicates received sequence ranges.
  • • Reduces the number of SIFS intervals and ACK frames.
  • • Works well with aggregated data frames to save airtime.
  • • Sender retransmits only the frames flagged as missing.
Key Takeaway: On high‑throughput links, Block ACK improves efficiency by batching feedback.
Concrete scenario
During a bulk transfer with frame aggregation, the receiver returns a Block ACK listing which sequence numbers were received. The sender then retransmits any missing pieces, reducing per‑frame overhead.
Misconception
Believing Block ACK eliminates retransmissions. It actually makes retransmissions more selective and efficient, but the MAC retry logic still applies.
