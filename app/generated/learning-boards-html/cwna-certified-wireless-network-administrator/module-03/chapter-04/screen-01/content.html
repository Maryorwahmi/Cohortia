802.11 Control Frames
Coordination, reliability, and power save signaling that make wireless shared media work.
In this lesson you'll learn the roles of RTS/CTS, ACK, PS-Poll, and Block ACK, see practical capture filters, and learn when to enable each mechanism to improve reliability and efficiency.
Control frames at a glance
Short, prioritized, and designed for timing and coordination.
RTS / CTS — reserve medium using duration fields
ACK — immediate confirmation after SIFS
PS-Poll — client requests buffered frames to save power
