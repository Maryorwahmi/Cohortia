Core concept

What are Data Frames?

Data frames carry MSDUs from higher layers. Subtypes include generic Data, QoS Data, and Null Function frames used for power saving.

Example
A VoIP packet is sent in QoS Data frames mapped to AC_VO so it receives higher priority than a background download.
Key Takeaway

QoS-aware frames include a QoS Control field that signals priority and mapping to queues.
