Comparison

AC_VO vs AC_VI vs AC_BE vs AC_BK

AC_VO (Voice)
Shortest AIFS, smallest contention window; highest priority for low-latency traffic.
AC_VI (Video)
High priority with some tolerance for bursts and throughput.
AC_BE (Best Effort)
Default for web and normal application traffic; balanced parameters.
AC_BK (Background)
Lowest priority, intended for bulk transfers and non-time-sensitive flows.
Concrete example
During a video meeting, audio packets are mapped to AC_VO and video frames to AC_VI. A scheduled backup uses AC_BK. The EDCA parameters ensure audio gets earlier access and fewer collisions than the backup traffic.
Key Takeaway

ACs assign relative priority by tuning AIFS and contention windows. Correct classification is essential for QoS to produce real benefits.
