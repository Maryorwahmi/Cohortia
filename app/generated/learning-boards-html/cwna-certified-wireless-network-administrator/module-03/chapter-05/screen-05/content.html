Module 4 › Chapter 3.5 › QoS Control Field
Core idea

Two bytes that guide priority

The QoS Control field contains TID and other flags used by WMM to queue frames appropriately and support features like block acknowledgements.

TID mapping
TID values map to ACs. Common practice: 6–7 → Voice, 4–5 → Video, 0–3 → Best Effort/Background.
Practical check
In a capture, expand QoS Control to find TID; this confirms marking at the MAC layer.
Concrete example
Imagine a conferencing app marking packets for low latency. Those packets reach the NIC, which sets TID. The QoS Control field in each QoS Data frame carries the TID so the AP can enqueue frames into AC_VO and give them shorter wait times under EDCA.
Misconception
Marking must be end‑to‑end. If the client or driver fails to set TID, the AP cannot guess intent, and traffic may be treated as Best Effort.
Key Takeaway

QoS Control's TID is the wire-level tag that lets MAC queues and EDCA differentiate traffic; verify it in captures when diagnosing QoS behavior.
