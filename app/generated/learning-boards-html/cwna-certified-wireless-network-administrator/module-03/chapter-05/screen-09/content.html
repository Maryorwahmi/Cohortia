Module 4 › Chapter 3.5 › Wireshark Walkthrough
Procedure

Capture and filter

  1. Enable monitor mode and capture on the AP's channel.
  2. Generate mixed traffic: voice/video, web, and a file download.
  3. Apply display filter: wlan.fc.type_subtype == 0x28 or wlan.data.qos.
  4. Inspect QoS Control in Packet Details to read TID and AC mapping.
Tip
When possible, capture near the client to see TXOP bursts clearly; remote captures may interleave other traffic.
Example Filter
wlan.fc.type_subtype == 0x28 wlan.data.qos
Key Takeaway

Wire-level inspection of QoS Control is the reliable method to confirm traffic classification and observe TXOP behavior.
