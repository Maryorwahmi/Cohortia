Core Concept

802.11 Data Frame Subtypes

Data carries higher-layer payloads. Subtypes allow signaling and priority without reinventing frame structure.

Data
Standard frame for carrying MSDU for most traffic.
QoS Data
Includes QoS Control field: signals TID/AC for priority handling.
Null Function (No Data)
No payload; used for power management signaling.
Example
Scenario: VoIP call and scheduled backup
The VoIP packets are sent in QoS Data frames marked for AC_VO. The backup job sends large data frames as Best Effort or Background. This separation lets voice win contention more often.
Key Takeaway

Subtypes allow signaling and priority without changing the payload's content; QoS Data frames enable priority handling for time-sensitive traffic.

Common mistake
Assuming QoS magically adds bandwidth; it prioritizes only when capacity is shared.
