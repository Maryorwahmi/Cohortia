Module 4 › Chapter 3.5 › Key Concepts
Data Frames
Frames that carry MSDU; subtypes include QoS Data and Null Function.
QoS Control Field
Two bytes carrying TID and flags to map traffic to AC queues.
Access Categories
AC_VO, AC_VI, AC_BE, AC_BK — different AIFS and CW values for priority.
EDCA
Per‑AC AIFS and contention windows control relative access probability.
TXOP
A time window for consecutive frames after winning contention.
Troubleshooting
Verify WMM on both ends and inspect TID in captures; QoS cannot create bandwidth.
