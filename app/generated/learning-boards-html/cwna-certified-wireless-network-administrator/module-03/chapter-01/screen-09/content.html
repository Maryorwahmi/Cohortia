Address Field Roles
RA, TA, DA, SA explained
Core Concept
This card describes the intended role of each 802.11 address. RA is the immediate receiver, TA is the immediate sender. DA and SA identify the final destination and original source of the MSDU. Address 4 only appears in WDS cases. Use To DS and From DS bits to interpret these fields correctly across client-to-AP and AP-to-client frames.
Concrete Example
STA -> AP -> Wired Server: To DS = 1. Address 1 = AP (RA), Address 2 = STA (TA), Address 3 = Server (DA). The AP will then create a frame toward the wired network and later a frame from the DS back to a STA will set From DS = 1, shifting address roles.
Mnemonic: RA/TA = immediate receiver/sender; DA/SA = final destination/original source.
Address Mapping Scenarios
Client -> AP (To DS = 1)
Address1: AP (RA), Address2: STA (TA), Address3: Final DA (wired server)
AP -> Client (From DS = 1)
Address1: STA (RA), Address2: AP (TA), Address3: Original SA (server)
WDS / AP-to-AP
Address4 is used to preserve original source when frames traverse multiple APs.
Key Takeaway

Always read To DS and From DS before assigning meaning to Address fields. Address 1 and 2 are immediate recipient and sender; Address 3 and 4 depend on DS bits and WDS use.
