Module 3 › Chapter 3.1 › Key Concepts
FCS
CRC error detection; no ACK implies retransmission.
Duration / NAV
Virtual carrier sense that reserves the medium for a time window.
CSMA/CA
IFS rules, NAV, and randomized backoff coordinate medium access.
Final Tip

When diagnosing wireless failures, first check integrity (FCS/retries), then reservations (Duration/NAV), and finally contention (IFS/backoff metrics) for a quick root cause direction.
