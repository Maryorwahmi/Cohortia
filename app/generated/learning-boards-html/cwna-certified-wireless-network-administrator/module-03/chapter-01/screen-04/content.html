Module 3 › Chapter 3.1 › MAC vs LLC
Definition
LLC and MAC roles

LLC provides a consistent interface to the network layer and handles basic link services. The MAC formats frames, enforces medium access, and supports retransmission and sequencing for wireless links.

LLC
Multiplexing & flow control
Keeps higher layers unaware of MAC specifics so IP and others behave the same across links.
MAC
Medium access & framing
Implements CSMA/CA behaviors, headers, NAV, fragmentation, and retries needed for radio links.
Process example
Walkthrough: a host sends an IP packet. The LLC accepts it and hands an MSDU to the MAC. The MAC creates an MPDU by adding header fields and FCS, sets Duration for NAV when needed, and follows DCF/DCF timers to transmit.
Concrete example

A web page request becomes an MSDU. The MAC fragments it if large, adds sequence numbers, and sends MPDUs until the server response arrives.

Common misconception

The MAC is more than a header adder. It enforces access rules and handles retransmissions and fragmentation that directly affect performance.

Key Takeaway

LLC standardizes service to upper layers; the MAC implements wireless behaviors and framing that make reliable communication possible over the air.
