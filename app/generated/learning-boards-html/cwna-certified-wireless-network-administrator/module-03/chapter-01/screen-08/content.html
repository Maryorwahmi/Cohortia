Module 3 › Chapter 3.1 › Duration / Sequence
Process
Setting NAV with Duration
  1. Sender transmits a frame with Duration indicating how long the exchange will take.
  2. Nearby stations read Duration and set their Network Allocation Vector (NAV) to that value.
  3. Stations with NAV active treat the medium as busy and defer transmissions even if the physical channel appears idle.
  4. The receiver responds (ACK or CTS) after a SIFS. NAV ensures hidden nodes do not interfere during this sequence.
Sequence Control

Sequence Number increments for each new MSDU. Fragment Number increments for each fragment of the same MSDU. Use both to reassemble data and detect duplicates or retransmissions.

Example
You capture a data frame with Duration = 300. Clients that receive it set NAV for 300 microseconds. When the ACK arrives after SIFS, NAV expires and backoff resumes.
Troubleshooting tip

If you see repeated Sequence Numbers and no ACK, expect retransmissions; inspect Fragment Numbers to see if fragments are lost or misordered.

Misconception check

Duration isn't always a simple reservation in management frames. Check frame type before interpreting it strictly as microseconds reserved.

Key Takeaway

Use Duration to understand NAV-based reservations and Sequence Control to track fragments and retransmissions; both are essential when interpreting captures and diagnosing lost frames.
