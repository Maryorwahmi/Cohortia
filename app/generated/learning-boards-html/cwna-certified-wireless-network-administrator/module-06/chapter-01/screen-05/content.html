Architecture

OSI as a troubleshooting map

Layer 1 – Physical
Signal, interference, cabling, power, PoE.
Layer 2 – Data Link
Association, authentication, MAC filters, VLAN membership.
Layer 3 – Network
IP addressing, DHCP, routing, gateway reachability.
Pass/Fail tests
  • Ping gateway to verify Layer 3 reachability.
  • Check association logs for Layer 2 authentication failures.
  • Measure RSSI and noise for Layer 1 signal issues.
Concrete example
A client associates but cannot reach internal servers. Check DHCP lease and route first; if IP and gateway are correct, the issue is likely beyond Layer 3. Don’t change channels until you’ve eliminated IP issues.
Key Takeaway

Use OSI layers to order your checks and create unambiguous pass/fail tests at each step.
