Definition

Structured troubleshooting

A repeatable sequence of evidence gathering, targeted tests, and single-variable changes to find a root cause efficiently.

Why it matters
Prevents wasted effort and accidental outages from multiple simultaneous changes.
Common misconception
More tools or more changes do not guarantee faster fixes; targeted reasoning does.
Concrete example
User: "Can browse internet but cannot access internal file shares." Test sequence: 1) ping default gateway, 2) ping internal server, 3) check client IP and route. This sequence quickly shows whether the problem sits between the client and gateway or beyond it.
Key Takeaway
Start with facts, test decisively, and log results so your next action is informed.
Try this
Before changing AP settings, run a single runbook: question list, ping gateway, ping server, confirm IP, document.
