Module 6 › Chapter 6.1 › Information Gathering
Checklist

Questions to ask

  • Who is affected? Single user or many?
  • What exactly is not working? App, file share, internet?
  • When did it start and was anything changed recently?
  • Are there error messages or screenshots you can capture?
Tools and logs
Capture ipconfig/ifconfig, ping, traceroute outputs and controller/AP logs with timestamps. These reproducible artifacts let you verify whether a change improved the situation.
Scenario grounding
If browsing external sites works but internal resources fail, ask whether DNS, routing, or ACLs are different for internal addresses and gather the client’s IP and gateway info immediately.
Key Takeaway

Capture facts first. Well‑formed evidence prevents wasted changes and lets you test one hypothesis at a time.
