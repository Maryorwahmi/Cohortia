Template

Simple log format

Timestamp:
Who reported, brief symptom, scope (single user, AP, site).
Tests run:
Commands and key outputs, e.g., ping gateway success/fail.
Change:
What was changed and why; rollback steps.
Result:
Outcome and follow-up actions.
Example
2023-10-26 10:30 - User: no internal resources. ipconfig shows IP 192.168.1.45. Ping gateway 192.168.1.1 OK. Ping 8.8.8.8 failed. Suspect upstream. No config changes made.
Change discipline
Make one change at a time, record it, and observe effect before making another change. This isolates cause and prevents cascading issues.
Key Takeaway

Clear logs and one‑change discipline make troubleshooting reproducible and safe.
