Core Concept

Advanced Display Filters

Construct boolean filters to isolate retries, client traffic, or frames with specific information elements.

Filter example
wlan.fc.retry == 1 && wlan.addr == 00:11:22:33:44:55

This shows frames marked as retries that are either to or from the specified client MAC address. Add BSSID or time constraints to narrow the scope.

Pro tip

Use parentheses when combining multiple boolean clauses to ensure operator precedence is explicit.

Common mistake

Relying on a single field without cross-checking BSSID or time range can produce false leads from unrelated traffic.

Concrete Example
Scenario: A client is reporting poor throughput. You suspect many retransmissions from that client. Start a capture, then run an initial filter to show retries and the client MAC. If you see many retry frames with small inter-frame spacing, suspect RF interference or a poor SNR. Confirm by collecting an active throughput test and a spot survey in the same area.
Supporting steps
  • Capture for a representative interval including the client's activity.
  • Apply a retry filter plus the client's MAC to reduce noise.
  • Check expert information for retransmission and malformed packet counts.
  • Correlate findings with a site survey in the affected area.
Key Takeaway

Write filters that directly answer your investigative question, then iterate by adding constraints to exclude unrelated traffic.
