Module 7 › Chapter 6.7 › Key Concepts
Passive Site Survey
Listen-only surveys that reveal coverage, noise floor, and AP presence without associating clients.
Network Baseline
A reference snapshot of normal RF and performance metrics that helps you detect meaningful deviations.
WIPS
Continuously monitors the radio spectrum, detects threats, and provides logs for security response and troubleshooting.
Final takeaway

Combine RF observation, client validation, and baseline-driven monitoring with disciplined change control to keep WLANs reliable and secure.
