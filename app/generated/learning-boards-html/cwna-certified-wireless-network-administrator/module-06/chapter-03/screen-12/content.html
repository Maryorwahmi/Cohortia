Core Concept

MAC filtering explained

MAC filters allow or deny devices by hardware address. They are easy to mismanage and can silently block legitimate clients.

Troubleshooting steps
  • Confirm MAC filtering is enabled on the AP
  • Verify the client's MAC address and compare with the allow list
  • Check AP logs for explicit denial entries
Example
A new laptop repeatedly fails to associate. AP logs show a policy deny for the laptop's MAC. Adding the MAC to the allow list resolves the issue.
Best practice
Prefer 802.1X for stronger access control; if using MAC filters, maintain a clear allow-list process.
Warning
Do not rely on MAC filtering for security, since MAC addresses can be spoofed.
