Module 6 › Chapter 6.3 › PSK vs 802.1X
Comparison

PSK networks

PSK networks rely on a shared passphrase. Failed authentication usually means the client has an incorrect key or the AP's key was changed without updating clients.
Checks for PSK failures
  • Confirm PSK spelling and case on the client
  • Capture EAPOL frames for mismatched key exchanges
Comparison

802.1X Enterprise

Enterprise authentication uses EAP methods and a RADIUS server. Failures can be due to credentials, RADIUS reachability, certificate validation, or supplicant misconfiguration.
Checks for 802.1X failures
  • Capture EAPOL frames and look for EAP-Failure
  • Check RADIUS server logs and network reachability
  • Validate client EAP type and certificate trust chain
Example
Laptop associates but fails during EAP; RADIUS logs show invalid credentials for that user.
Misconception
Assuming AP is at fault when the server or client supplicant is misconfigured.
