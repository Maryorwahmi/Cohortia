Module 6 › Chapter 6.3 › Association Sequence
Process

Association frames and checks

Frame sequence to capture
  • Probe/Beacon (discovery)
  • Association Request (client)
  • Association Response (AP) — inspect status code
Immediate checks
  • Validate SSID and hidden SSID configuration
  • Confirm AP client limit and MAC filter allow list
  • Correlate AP logs and capture timestamps
Key Takeaway

Read association response codes first to avoid unnecessary time spent on authentication or radio fixes.

Annotated Example Capture
Frame 1: Probe Request (Client) - SSID: SecureCorp
Frame 2: Probe Response (AP) - SSID: SecureCorp
Frame 3: Association Request (Client) - SSID: SecureCorp
Frame 4: Association Response (AP) - Status: 17 (Assoc denied; AP policy)
Status codes guide the next step. Here, the AP denied association for policy reasons; check MAC filtering or AP configuration.
Scenario
Phone cannot join; capture shows association responses with non‑zero status. AP logs confirm MAC filtering is enabled.
Pitfall
Mistaking a policy denial for a radio failure. Always check management responses first.
