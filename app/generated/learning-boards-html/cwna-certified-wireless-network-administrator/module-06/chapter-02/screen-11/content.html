Module 6 › Chapter 6.2 › Measurement Tools
Quick OS checks
Use built‑in commands to capture RSSI quickly for a client or interface.
Windows: netsh wlan show interfaces macOS: /System/Library/PrivateFrameworks/Apple80211.framework/Resources/airport -I
These commands give quick signal readings. They do not replace a spectrum analyzer for noise floor measurement.
Spectrum tools
Use a dedicated spectrum analyzer or a Wi‑Fi adapter in monitor mode and software to visualize all RF energy, including non‑Wi‑Fi sources.
Practical Tip
Start with OS commands to map trouble spots, then bring a spectrum analyzer to those spots to identify the actual interference source.
