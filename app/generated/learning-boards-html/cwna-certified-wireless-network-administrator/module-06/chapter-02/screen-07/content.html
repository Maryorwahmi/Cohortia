Module 6 › Chapter 6.2 › SNR
Definition
Signal‑to‑Noise Ratio
SNR = RSSI minus Noise Floor. Higher values mean the signal is easier to decode relative to background noise.
Good: ≥ 25 dB
Poor: ≤ 10–15 dB
Worked example
If RSSI = -72 dBm and noise floor = -85 dBm, SNR = 13 dB — marginal. If the noise floor were -95 dBm instead, SNR = 23 dB — acceptable.
Misconception
A single device's RSSI does not reflect the environment; SNR shows whether the signal exceeds background energy sufficiently.
Key Takeaway
Use SNR thresholds to decide if a client location is viable or if action is needed.
