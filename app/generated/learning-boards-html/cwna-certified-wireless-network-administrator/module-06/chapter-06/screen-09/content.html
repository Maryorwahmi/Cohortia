Module 6 › Chapter 6.6 › Frame Aggregation
A‑MSDU
Aggregates multiple Layer‑3 MSDUs into a single Layer‑2 frame, saving MAC header overhead for many small payloads.
A‑MPDU
Aggregates multiple MPDUs into a single transmission, reducing preamble and interframe spacing overhead. Each MPDU can be retransmitted independently.
When aggregation helps
  • Applications with many small packets (e.g., chat, small HTTP requests).
  • Bulk transfers where throughput matters more than minimal per‑packet latency.
Caveat: for time‑sensitive flows, configure aggregation limits and use QoS to minimize serialization delays for high‑priority packets.
