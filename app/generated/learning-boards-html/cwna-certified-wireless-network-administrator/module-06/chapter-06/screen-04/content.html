Module 6 › Chapter 6.6 › Optimization vs Troubleshooting
Definition
Optimization: controlled adjustments to improve performance after the network is stable. Troubleshooting: identifying and fixing faults that prevent normal operation.
Example baseline
  • Median throughput per AP at peak hour.
  • Client counts per AP and airtime usage percentage.
  • Retry rate and jitter for voice flows.
Key Takeaway

Always measure before you change. Single‑variable changes make results interpretable.

Process mnemonic
Measure
Collect baseline metrics for comparison.
Change
Adjust one setting at a time.
Validate
Measure again and compare with baseline.
Common mistake: making multiple changes after a performance complaint. That prevents clear attribution and can waste time reversing changes. Pro tip: document the exact time and values changed so you can roll back if needed.
