Definition

Transport layer checks

Confirm whether a service is running and bound to the expected port. If not, network troubleshooting is premature.

C:\> netstat -an | find "LISTENING"
  TCP    0.0.0.0:80       0.0.0.0:0      LISTENING
  TCP    0.0.0.0:443      0.0.0.0:0      LISTENING
If these entries are missing, the web service isn't listening on the default ports. Start or configure the application appropriately before modifying network policies.
Example
A server administrator sees no listener on port 445 but clients cannot access SMB shares. After starting the SMB service, netstat shows port 445 listening and clients can connect. The root cause was the service state, not the network.
Check list
  • Use netstat to confirm listeners
  • If listening, verify host firewall allows the port
  • If not listening, start or reconfigure the service
Misconception

Don't assume a network block when the server application is stopped or bound to a different port.
