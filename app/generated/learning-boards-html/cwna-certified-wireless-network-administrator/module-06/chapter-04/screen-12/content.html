Lab Scenario

Client connected but cannot browse

Follow the guided terminal steps, observe output, and decide which next command narrows the fault.

Task steps you'll perform:
  • Run ipconfig /all and interpret the IP details
  • Ping gateway and external IPs
  • Run nslookup against configured and public DNS
  • Use tracert to find dropped hops
Terminal examples
C:\> ipconfig /all
C:\> ipconfig /release
C:\> ipconfig /renew
C:\> ping 192.168.1.1
C:\> ping 8.8.8.8
C:\> nslookup intranet.corp 192.168.1.10
C:\> nslookup intranet.corp 8.8.8.8
C:\> tracert intranet.corp
At each command output, determine whether the result rules out a layer. This is the same workflow you will apply on real networks to reduce time-to-resolution.
