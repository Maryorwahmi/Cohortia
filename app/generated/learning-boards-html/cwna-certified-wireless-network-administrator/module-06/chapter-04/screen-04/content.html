Definition

Layer 3 essentials

IP address, subnet mask, default gateway, and DNS server addresses form the fundamental configuration a client needs to communicate beyond the wireless link.

IP Address
Identifies the client on the network.
Subnet Mask
Defines local network boundaries.
Default Gateway
Where traffic goes to reach other networks.
Key Takeaway

Always confirm a valid IP, mask, gateway, and DNS before moving on to higher-layer checks.

Analogy
Think of IP as a postal address. If the street number, city, or postal code is wrong you may never receive mail. The gateway is like the post office for sending mail to other cities; DNS is an address book that maps names to addresses.
Common misconception
Believing that association to Wi‑Fi implies full network service is the most frequent mistake. Association only confirms L1 and L2; L3/L4 must still be validated.
Scenario
User can ping internal devices but not access a cloud application
This suggests local IP and gateway are correct but DNS or gateway routing to the internet may be failing. Run nslookup and ping external IP to separate DNS from routing issues.
