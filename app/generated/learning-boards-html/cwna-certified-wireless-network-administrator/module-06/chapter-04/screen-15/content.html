Module 06 › Chapter 6.4 › Quick Reference
DHCP / APIPA
APIPA points to DHCP negotiation failure. Check DHCP server, relay, and firewall rules for UDP 67/68.
DNS
Test DNS with nslookup and a public resolver to distinguish server failures from routing problems.
Routing & ACLs
Ping and traceroute reveal where connectivity stops; if service ports fail, check ACLs and firewall logs and verify the service is listening.
Final takeaway

Use the small repeatable sequence: confirm IP, test gateway and external IP, validate DNS, then check service ports and policies. This sequence finds most Layer 3 and 4 problems.
