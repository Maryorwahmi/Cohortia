Module 06 › Chapter 6.4 › Key Concepts
DHCP / APIPA
DHCP assigns addresses. APIPA (169.254.x.x) indicates DHCP negotiation failed and points to server, relay, or firewall issues.
DNS
Names must resolve to IPs. Use nslookup or dig and test against a known resolver when diagnosing name resolution failures.
Gateway & Routing
Ping the default gateway and then external IPs. Use traceroute to locate where packets are dropped or blocked.
Firewall / ACL
If ping works but a service port is blocked, check firewall rules and ACLs on clients, WLAN controllers, and network devices.
Transport Layer
Use netstat to see if applications are listening on the expected TCP/UDP ports before assuming a network block.
Command-line tools
ipconfig/ifconfig, ping, nslookup/dig, traceroute/tracert, and netstat form the core toolkit for diagnosing Layers 3 and 4.
Summary takeaway

Follow a small repeatable sequence: validate IP, test DNS, confirm gateway and upstream reachability, then verify service ports and firewall policies.
