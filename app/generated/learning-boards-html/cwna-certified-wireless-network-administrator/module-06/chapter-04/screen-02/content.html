Learning Objectives

Build reliable diagnostic steps across IP, DNS, routing, and port policies for wireless clients.

Bloom's Taxonomy
Learn
Understand
Apply
Master
01
Diagnose IP & DHCP

Read the client's IP configuration, identify APIPA addresses, and determine whether DHCP server, scope, or relay issues are the cause. Recognizing APIPA saves time by directing you immediately to DHCP troubleshooting steps.

VERIFIED COMPETENCY MILESTONE
02
Troubleshoot DNS resolution

Use nslookup or dig to verify whether names resolve and whether configured DNS servers are reachable. Testing against a known resolver helps separate DNS from routing problems.

VERIFIED COMPETENCY MILESTONE
03
Find routing & gateway issues

Confirm reachability to the default gateway and upstream IPs with ping and traceroute. These checks distinguish local routing faults from upstream provider or router failure.

VERIFIED COMPETENCY MILESTONE
04
Understand firewall & ACL impact

Determine if traffic is being blocked by client or network firewalls and ACLs. If ping works but a service port is closed, logs and port checks help identify policy blocks.
