Comparison

ICMP reachability vs Service accessibility

ICMP reachability
Shows that network path exists but doesn't confirm application ports are open.
Service accessibility
Requires successful TCP or UDP connections to the specific port; failures often indicate firewall or ACL rules.
Example scenario
User can ping a file server (ICMP) but cannot access SMB shares. SMB uses TCP ports 139 and 445. If pings succeed but connections to these ports fail, check host-based firewall, network firewall rules, and WLAN ACLs that may restrict SMB traffic from wireless clients.
Pro Tip
Use logs where possible. Firewalls often log denied sessions and specify source, destination, and port, which accelerates root cause identification.
Common mistake

Assuming ICMP indicates full service access. Always test the actual application port or consult firewall logs.
