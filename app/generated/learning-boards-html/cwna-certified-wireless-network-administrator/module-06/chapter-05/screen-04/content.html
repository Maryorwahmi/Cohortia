Module 06 › Chapter 6.5 › Troubleshooting Process
Process Flow

Client → AP → RADIUS

Step 1: Client checks
Confirm SSID, security type, PSK spelling or 802.1X profile, and check supplicant logs for EAP method and certificate errors.
Step 2: AP and reachability
Inspect AP association attempts, validate AP-to-RADIUS connectivity (ping/traceroute), and confirm UDP ports 1812/1813 are open.
Step 3: RADIUS logs
Read detailed deny reasons, check shared secret, policies, and certificate validation notes. Logs often tell you the exact cause.
Key Takeaway

A disciplined order of checks avoids wasted effort and keeps production security intact.

Checklist

Verification and tools

What to verify
  • Exact PSK string and case sensitivity
  • 802.1X EAP type and inner method
  • AP RADIUS client configuration and shared secret
  • UDP 1812/1813 firewall rules
Tools to use
  • Event Viewer / supplicant logs
  • AP and controller logs
  • RADIUS server logs
  • Wireshark for EAPOL and EAP exchanges
Common misconception
People often assume the AP is at fault when a client fails. In many cases the client profile or the RADIUS policy is the root cause. Follow the process to avoid incorrect changes to infrastructure settings.
