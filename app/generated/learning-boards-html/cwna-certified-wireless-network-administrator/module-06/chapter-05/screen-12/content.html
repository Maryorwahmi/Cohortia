Activity

Step-by-step troubleshooting plan

Step 1: Client-side
Verify SSID, EAP method, inner method, and collect supplicant or Event Viewer logs for exact errors.
Step 2: AP/controller
Check for forwarded authentication requests, timeouts, and reachability errors from the AP to the RADIUS server.
Step 3: RADIUS server
Read event logs for deny reasons: shared secret mismatch, policy denied, certificate failures, or invalid credentials.
Step 4: Capture
Capture EAPOL frames to see whether the 4‑way handshake or EAP exchange fails and correlate timestamps with logs.
Step 5: Remediate
Apply the fix based on evidence: correct PSK, fix shared secret, update policy, or renew certificates. Document changes and notify stakeholders.
Tools & logs
  • Supplicant/Event Viewer
  • AP/controller syslogs
  • RADIUS event logs
  • Wireshark EAPOL traces
Safety note

Do not disable security in production as a troubleshooting shortcut. Use test segments and change control to avoid exposure.
