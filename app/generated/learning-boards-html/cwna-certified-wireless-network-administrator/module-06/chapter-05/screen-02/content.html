Learning Objectives

A focused set of skills for diagnosing security-related wireless failures.

Bloom: Learn → Understand → Apply → Master
01
Diagnose PSK failures

Verify pre-shared keys and profile spelling, check case and special characters, and re-create profile when corrupted. Verifying PSKs prevents avoidable lockouts and wasted escalation.

VERIFIED COMPETENCY MILESTONE
02
Troubleshoot 802.1X and RADIUS

Check credentials, shared secrets, ports, server reachability, and RADIUS policies. These checks isolate authentication failures in enterprise deployments.

VERIFIED COMPETENCY MILESTONE
03
Detect rogue APs

Use WIPS and site surveys to find unauthorized APs, then locate and remove or reconfigure them to prevent network compromise.

VERIFIED COMPETENCY MILESTONE
04
Resolve client misconfigs

Update drivers, recreate profiles, and check supplicant settings to restore secure connectivity without compromising policies.

VERIFIED COMPETENCY MILESTONE
