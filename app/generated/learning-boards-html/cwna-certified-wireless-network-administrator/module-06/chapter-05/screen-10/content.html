Module 06 › Chapter 6.5 › Rogue AP Detection
Definition

Detecting and mitigating rogue access points

A rogue AP is any unauthorized access point connected to or broadcasting within your environment. Detection uses WIPS, surveys, or APs listening for other APs on the wired network.

Detection methods
  • WIPS alerts and classification
  • Site survey tools showing SSID, BSSID, and signal strength
  • Controller-based rogue detection on the wired fabric
Mitigation
  • Locate physically using directional antenna or walk tests
  • Disconnect wired rogues or correct soft-rogue configs
  • Follow security incident response for malicious devices
Scenario card
A WIPS alert shows a strong signal BSSID with the corporate SSID on a floor where no AP is authorized. Using a portable analyzer and directional antenna the security team locates the device in a conference room. It was an employee-plugged AP. The device is removed and the wired port is locked down.
Key Takeaway

Rogue APs create immediate risk; locate, isolate, and remediate quickly while preserving evidence for security investigation.
