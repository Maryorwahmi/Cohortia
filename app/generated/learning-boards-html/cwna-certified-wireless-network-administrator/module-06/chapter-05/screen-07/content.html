Module 06 › Chapter 6.5 › RADIUS Connectivity
Process

Verify network and secret

Confirm AP-to-RADIUS network path, UDP ports, and the exact shared secret to ensure authentication traffic is delivered and accepted.

Connectivity checks
  • Ping and traceroute from AP to RADIUS
  • Confirm firewall allows UDP 1812 and 1813
  • Check NAT and ACLs that could drop UDP
Shared secret validation
Copy the secret from server config to AP using a secure channel. Avoid manual typing if possible to prevent encoding or invisible-character errors.
Concrete checklist
  1. Run ping and traceroute; note hops and latency.
  2. From firewall logs, confirm UDP 1812/1813 are allowed.
  3. Temporarily enable debug logging on RADIUS for a test user.
  4. Copy shared secret securely and retry authentication.
Misconception

A successful ping proves IP reachability but not that UDP packets flow correctly; never replace UDP checks with pings alone.
