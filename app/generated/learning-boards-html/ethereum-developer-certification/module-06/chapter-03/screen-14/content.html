Starter code: VulnerableWallet.sol
Deploy locally, simulate an attacker, then apply the secure pattern.
Vulnerable withdraw (excerpt)
function withdraw() public {
  uint256 amount = balances[msg.sender];
  require(amount > 0, "No balance to withdraw");

  // Vulnerable point: Ether transfer BEFORE balance update
  (bool success, ) = msg.sender.call{value: amount}("");
  require(success, "Transfer failed");

  balances[msg.sender] = 0; // Balance updated AFTER transfer
}
Secure fix (excerpt)
function withdraw() public {
  uint256 amount = balances[msg.sender];
  require(amount > 0, "No balance to withdraw");

  // Effects first: update state
  balances[msg.sender] = 0;

  // Interactions last
  (bool success, ) = msg.sender.call{value: amount}("");
  require(success, "Transfer failed");
}
Lab checklist
Deploy VulnerableWallet, write an attacker contract using receive/fallback to re-enter, confirm the drain occurs, then deploy SecureWallet and confirm the attack fails. Add unit tests that assert final balances match expectations.
