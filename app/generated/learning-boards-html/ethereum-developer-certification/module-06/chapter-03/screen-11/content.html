Module 6 › Chapter 6.3 › Denial of Service
Two common DoS types
Unbounded loops and revert-on-send receivers both cause service interruptions.
Example: unbounded loop
A payout function loops through an ever-growing array; gas grows and eventually the function no longer fits in a block.
Example: revert receiver
Sending Ether to all recipients can be blocked if one recipient is a malicious contract that always reverts.
Defensive patterns
  • Use pull payments so users claim their own funds individually.
  • Paginate operations to limit per-transaction gas use.
  • Keep gas-costly state updates out of user-facing loops where possible.
Check

Audit loops and external sends; convert push payments to pull when appropriate.
