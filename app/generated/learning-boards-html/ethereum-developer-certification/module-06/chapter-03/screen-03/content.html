Hands-on outcomes
From exploit to fix: deploy, attack, patch, and verify.
Deploy Locally
Use Hardhat to run a local network and deploy the provided vulnerable contract for experimentation.
Simulate Attack
Write an attacker contract that calls back during a withdrawal to drain funds and observe behavior.
Fix & Verify
Apply CEI or reentrancy guards, then run unit tests and static analysis to confirm the fix.
