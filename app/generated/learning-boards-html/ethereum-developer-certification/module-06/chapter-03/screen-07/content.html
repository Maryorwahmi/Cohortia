ReentrancyGuard explained
A simple state flag prevents nested entries to the same function.
modifier nonReentrant() {
  require(status != ENTERED, "reentrant");
  status = ENTERED;
  _;
  status = NOT_ENTERED;
}
When to use
Use a guard where state spans multiple calls or where external callbacks are unavoidable.
Transfer, send, call
Do not assume gas-limited transfers are a complete protection.
Practical note
Using low-level call requires careful handling of the boolean return and explicit state ordering.
Misconception
Believing transfer prevents reentrancy can lead to complacency; network changes or gas repricing can invalidate assumptions.
