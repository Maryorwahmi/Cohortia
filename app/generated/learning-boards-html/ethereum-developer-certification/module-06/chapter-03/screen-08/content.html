Module 6 › Chapter 6.3 › Integer Safety
Overflow and underflow
Default arithmetic now reverts; unchecked sections remain risky.
Concrete example
If a uint8 at 255 increments under 0.8.0, the operation reverts instead of wrapping. In unchecked blocks or casts this protection may be bypassed.
Key Takeaway

Prefer default safe arithmetic and add tests that exercise boundary values; avoid unchecked optimizations unless necessary and reviewed.

Checklist
  • Search for unchecked blocks and review the need for each.
  • Review type casts from larger to smaller integers.
  • Add boundary tests for min/max values.
Misconception
Assuming new compiler defaults eliminate every numeric bug can leave unchecked optimizations undiscovered.
