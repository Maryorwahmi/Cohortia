Module 6 › Chapter 6.5 › Security & Best Practices
Security Architecture
Combine programmatic controls and human approvals to protect assets and upgrade paths.
High Priority
Timelock
Enforces delay before execution so the community can react to approved proposals.
Multi-sig
Requires multiple human approvals for sensitive fund movements and emergency interventions.
Role Management
Grant minimal permissions and rotate or revoke deployer privileges as decentralization matures.
Audits & Tests
Audit governance and treasury contracts; simulate malicious proposals in tests.
Scenario: Malicious Proposal
If a malicious proposal attempts to drain funds, a properly configured timelock and an active multisig can pause or reverse execution paths. For higher assurance, require multi-sig execution for treasury transfers while leaving on-chain governance for protocol parameter changes.
Checklist
  • • Grant and test PROPOSER/EXECUTOR roles explicitly.
  • • Set a reasonable timelock delay for treasury actions.
  • • Use multisig for key treasury contracts and emergency recovery.
  • • Run audits and propose bug-bounty programs.
Key Takeaway
Treat governance contracts like production infrastructure: plan for compromise, add human checks, and test failures.
