Public vs External
External functions accept calldata and avoid copying arrays into memory. Public functions copy calldata to memory, which costs gas when arrays are large.
Concrete example
If your contract has function process(uint256[] calldata items) external, it will avoid memory copying that a public counter-part would incur.
Supporting tips
  • Use external for array-heavy public API calls to reduce copies.
  • Mark internal helpers private/internal for compiler optimizations.
  • Measure gas to confirm the benefit for your call patterns.
