Module 6 › Chapter 6.1 › External calls
Practical guidance
  • Specify gas limits when calling other contracts to avoid forwarding unnecessary gas.
  • Treat external calls as potential reentrancy vectors and test carefully.
  • Handle return values and errors explicitly to avoid unexpected failures.
Concrete detail
Example: call{gas: 20000}(...) forwards a bounded amount of gas. Only forward what the callee needs and prefer minimal dependencies for critical state changes.
Pro Tip

If possible, perform critical state changes before external calls, then emit events rather than relying on external confirmations.
