Module 6 › Chapter 6.1 › Loop optimization
Step-by-step refactor
  1. Identify unbounded loops over storage arrays.
  2. Consider externalizing work: let users claim or process items incrementally.
  3. Cache array length to a local variable once before the loop.
  4. Load each element into memory once per iteration and access fields from memory.
Concrete example
Instead of myArray[i].field inside the loop, do Struct memory item = myArray[i]; then use item.field to avoid repeated sloads.
Common mistakes
  • Leaving loops unbounded and assuming gas will always be sufficient.
  • Repeatedly reading from storage instead of caching into memory.
  • Using heavy computations inside loops without testing on realistic sizes.
