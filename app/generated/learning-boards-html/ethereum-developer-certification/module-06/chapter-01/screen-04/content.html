Module 6 › Chapter 6.1 › Gas basics
Core definition

Gas is the unit of computational effort. Cost equals gasUsed times gasPrice. You control gasUsed through code design.

Example: Replacing a storage write with a memory variable for a temporary value reduces gasUsed.
Misconception: Optimizing only gasPrice creates no guarantees. GasUsed reduction benefits every user regardless of price.
Key Takeaway

Design contracts to minimize gasUsed; the network will handle gasPrice.

Supporting points
  • gasPrice is external; gasUsed is code-dependent.
  • Storage writes (sstore) are the most expensive operations.
  • Small per-call savings add up across many transactions.
Concrete scenario
A marketplace with thousands of sales per day benefits more from lower gasUsed per sale than from chasing low gasPrice windows.
