Module 6 › Chapter 6.1 › Short-circuiting
Pattern

Write conditionals so cheap checks or checks likely to be false come first to prevent expensive subsequent evaluations.

Example
Use require(msg.sender == owner && amount > 0) when owner check is often false, avoiding amount evaluation in that case.
Why it helps
  • Skips expensive code paths when earlier checks fail.
  • Reduces gasUsed by avoiding unnecessary evaluations.
  • Requires careful ordering to preserve logic and security.
