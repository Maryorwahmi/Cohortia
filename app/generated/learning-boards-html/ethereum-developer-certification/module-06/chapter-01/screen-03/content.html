Measurement workflow
  1. Baseline: record gasUsed for target functions using a gas profiler.
  2. Refactor: apply one targeted change, for example caching storage reads.
  3. Retest: compare gasUsed and verify behavior remains correct.
  4. Accept or revert: keep only changes with measurable benefit.
Do not merge optimizations without tests and measurement.
