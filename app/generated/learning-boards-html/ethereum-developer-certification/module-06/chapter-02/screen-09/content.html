Definition

What is storage collision?

It occurs when a new implementation changes variable ordering, causing reads and writes to map to the wrong storage slots in the proxy.

Example variable ordering
// V1
uint256 public x;
bool public flag;

// V2 (incorrect)
bool public flag;
uint256 public x; // now maps to a different storage slot
Mitigations
  • Use a reserved __gap array to keep slots available for future variables.
  • Keep a strict ordering policy and document slot usage per version.
  • Use OpenZeppelin’s storage layout checks and upgrade testing tools before upgrading on mainnet.
Common mistake

Assuming adding a few variables is safe. Even small changes can shift slots and corrupt critical data. Always check layout compatibility.
