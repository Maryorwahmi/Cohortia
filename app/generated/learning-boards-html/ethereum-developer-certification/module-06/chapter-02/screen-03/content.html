Module 6 › Chapter 6.2 › Practice Objectives
Local deployment checklist
  • Initialize Hardhat and install OpenZeppelin upgrades plugin.
  • Deploy UUPS proxy and note both proxy and implementation addresses.
  • Call initializer via proxy exactly once.
Verification checklist
  • After upgrade, call new functions and getVersion to confirm logic changed.
  • Check balances and storage slots to confirm data persisted.
  • Review storage layout compatibility using __gap and OpenZeppelin reports.
Assessment idea
Deploy and upgrade a token
Complete the hands-on activity provided in this chapter, then submit a brief verification log showing proxy and implementation addresses and a recorded getVersion result after upgrade.
