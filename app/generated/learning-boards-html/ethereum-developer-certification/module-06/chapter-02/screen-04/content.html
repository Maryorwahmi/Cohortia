Core Concept

Definition

Immutability prevents changes to deployed contract code. Upgradeability keeps state stable while swapping logic.

Concrete example
A deployed token with stored balances can receive a new implementation that adds a burn function while balances remain in the proxy.
Misconception
Upgrading logic does not rewrite past transactions or on-chain history; it only changes the active code that processes new calls.
Visual: state vs logic
State
Balances, allowances, configuration stored in the proxy contract's storage slots.
Logic
Implementation contracts contain business logic that can be replaced if stored data layout is preserved.
Key takeaway
Upgradeability trades a single immutable code object for a controlled indirection that keeps storage stable while allowing logic evolution.
