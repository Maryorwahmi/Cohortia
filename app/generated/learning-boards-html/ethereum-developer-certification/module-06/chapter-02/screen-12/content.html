Module 6 › Chapter 6.2 › Key Concepts
Immutability
Deployed code cannot be changed on-chain.
Upgradeable Smart Contract
Pattern separating state and logic so logic can be upgraded while preserving state.
Proxy Contract
User-facing contract that stores state and forwards calls to an implementation.
Summary

Keep these terms clear: immutability motivates proxies, proxies hold state, implementations provide logic, and delegatecall ties them together.
