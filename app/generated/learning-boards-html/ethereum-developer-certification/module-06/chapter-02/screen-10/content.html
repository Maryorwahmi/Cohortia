Process Flow

Initialization steps

  1. Deploy implementation contract (constructor runs here).
  2. Deploy proxy pointing to implementation address.
  3. Call initializer on the proxy to set state in proxy storage.
  4. Lock initializer with Initializable modifiers to avoid multiple runs.
Code pattern
function initialize(string memory name, string memory symbol) public initializer {
  __ERC20_init(name, symbol);
  __Ownable_init();
  __UUPSUpgradeable_init();
}
Gotcha
Constructors on implementation do not initialize proxy state. Always call initializer through proxy and protect it with initializer modifiers.
Pro tip

Use reinitializer with a version number only when adding new state in a patch so initialization remains controlled and auditable.
