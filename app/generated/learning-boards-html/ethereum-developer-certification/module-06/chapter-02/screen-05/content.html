Definition

What delegatecall does

  • Executes code of the implementation contract.
  • Uses the proxy’s storage, keeping state persistent across upgrades.
  • Preserves msg.sender and msg.value so access checks see the original caller.
Concrete example
An implementation increment function that increases a value variable will change the proxy’s storage slot for value when invoked through delegatecall.
Pitfall
Because the implementation writes into the proxy’s storage, variable ordering must remain consistent across upgrades to avoid collisions.
Call flow visual
User
Sends tx to proxy address with calldata for a function.
Proxy
Forwards calldata with delegatecall to implementation; retains storage and msg.sender.
Implementation
Runs logic using proxy’s storage and returns result to proxy which returns to user.
Check your understanding
Why must initializers be called through the proxy rather than on the implementation contract directly? Because the constructor is not executed in proxy context; only calls executed through delegatecall affect proxy storage.
