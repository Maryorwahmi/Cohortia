Module 6 › Chapter 6.4 › Decision Checklist
Checklist
  • Finality needs: instant vs delayed withdrawals?
  • Cost: can you tolerate proof-generation overhead?
  • Compatibility: must you run existing EVM contracts unchanged?
  • Trust: acceptable sequencer/bridge custody models?
  • Tooling & ecosystem maturity for development and audits.
Quick mapping
If you need low fees and can accept delayed exits: optimistic rollups. If you need quick finality and stronger cryptographic guarantees: ZK-rollups. If throughput is paramount and a separate validator set is acceptable: sidechains.
