Module 6 › Chapter 6.4 › Optimistic Rollups
Core definition
Optimistic rollups post transaction data to L1 and assume batches are valid. A challenge period allows anyone to submit a fraud proof if they detect an incorrect state transition.
Example scenario
Trader withdraws after off-chain trades. Withdrawal completes only after the challenge period expires, ensuring no fraud proof is outstanding.
Notes & risks
  • Lower proof cost: no heavy cryptographic proofs each batch.
  • Withdrawal delay: challenge windows add latency for exits.
  • Reliance on watchers: third parties must monitor and submit fraud proofs when needed.
Misconception

Optimistic does not mean unverified. It means verification is delayed and reactive via fraud proofs.
