Module 5 › Chapter 5.2 › Key Concepts
Injected Provider
window.ethereum injected by browser wallets like MetaMask to route requests and sign transactions.
eth_requestAccounts
The method to prompt the user to share account addresses; returns an array when accepted.
accountsChanged
An event fired by the provider when the active user account changes; update app state on receipt.
Summary Takeaway

Detect the provider, request accounts, and subscribe to account changes to maintain a robust DApp connection.
