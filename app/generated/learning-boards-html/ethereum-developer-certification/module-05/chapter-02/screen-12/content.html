Module 5 › Chapter 5.2 › Security
Principles
  • Never request or store private keys in the DApp.
  • Always use provider signing flows for transactions and messages.
  • Validate all user inputs and transaction parameters before passing them to the wallet.
Practical checks
If a user changes account during transaction construction, cancel or rebuild the transaction to ensure the signer is correct.
Misconception
Thinking that obtaining the user's address grants you signing authority. Addresses are public; signing is always controlled by the wallet.
Key Takeaway

Trust the wallet for key management and signing. Validate payloads and handle account changes to avoid accidental signatures.
