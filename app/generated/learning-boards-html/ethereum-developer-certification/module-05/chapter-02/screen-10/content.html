Module 5 › Chapter 5.2 › Switching networks
Suggested flow
Prompt user then call switch
Explain why you need the switch, then call wallet_switchEthereumChain to request it programmatically.
await window.ethereum.request({
  method: 'wallet_switchEthereumChain',
  params: [{ chainId: web3.utils.toHex(requiredChainId) }],
});
Error handling
Handle 4001: user rejected; 4902: network not found in wallet. Offer instructions to add the network manually if needed.
UX tip
Ask the user first before triggering the wallet pop-up and explain the change to avoid unexpected interruptions.
Key Takeaway

Programmatic network switch requests improve UX, but always catch errors and provide clear guidance for manual steps when necessary.
