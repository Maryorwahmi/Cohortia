Event
accountsChanged handler
The provider emits an array of addresses; update your selectedAccount and refresh user-specific data like balances and permissions.
window.ethereum.on('accountsChanged', (newAccounts) => {
  if (newAccounts.length === 0) {
    // User disconnected or locked wallet
  } else {
    selectedAccount = newAccounts[0];
    // Refresh balances, re-run user-specific queries
  }
});
UX and pitfalls

Do not reload the page for simple account changes. Update local state and refresh the parts of the UI that rely on the account. Remove duplicate listeners to avoid double updates during testing.

Scenario
If the user switches to another account, balances and permissions may change. Your DApp should fetch fresh balances and re-check any account-linked authorizations.
Key Takeaway

Subscribe to accountsChanged and treat an empty array as a disconnect. Refresh only what’s necessary to preserve a smooth UX.
