Connecting to Ethereum Networks and Wallets

Learn the canonical patterns to detect an injected provider, request permission to use the user's account, initialize Web3.js, and respond to account and network changes.

In this lesson
Detect provider, connect accounts, and stay network-safe.
Why it matters
Wallets sign transactions; correct network and account state is critical for safety and correct contract interactions.
Explore Key Topics
Provider Detection
Confirm window.ethereum and guide users to install MetaMask when absent.
Account Access
Use eth_requestAccounts and handle user acceptance or rejection.
Network Management
Check chainId, suggest wallet_switchEthereumChain, and react to chainChanged events.
Visual concept
Provider injected into the page routes requests to the user's wallet for signing and account access.
