Module 5 › Chapter 5.2 › Initializing Web3
Architecture
Provider → Web3 → Contracts
Web3 should be instantiated with window.ethereum so contract calls and transaction signing use the user's wallet session and permissions.
Example initialization
// After user grants accounts
web3 = new Web3(window.ethereum);
const networkId = await web3.eth.net.getId();
// Or using provider
const chainIdHex = await window.ethereum.request({ method: 'eth_chainId' });
const chainId = parseInt(chainIdHex, 16);
Practical note

Use the chainId to guard contract interactions against accidental cross-chain transactions. When the chain changes, re-create contract instances so addresses and ABI bindings are consistent with the new network.

Common mistake
Caching contract instances across network changes. Reinitialize contracts after chainChanged.
Key Takeaway

Initialize web3 with the provider and immediately confirm the chainId; rebuild network-dependent objects after any network change.
