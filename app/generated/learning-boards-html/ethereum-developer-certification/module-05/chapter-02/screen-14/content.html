Module 5 › Chapter 5.2 › Troubleshooting checklist
Provider detection
Confirm window.ethereum exists; fall back to a read-only RPC if necessary.
Permission flow
Await eth_requestAccounts and handle code 4001 for rejections.
Network verification
Parse eth_chainId hex and compare to requiredChainId before contract calls.
Event listeners
Ensure listeners are registered once and update state on accountsChanged and chainChanged.
Contract reinit
Recreate contract instances after network changes to align addresses and on-chain state.
Security checks
Never request private keys; validate payloads before sending to wallet for signing.
