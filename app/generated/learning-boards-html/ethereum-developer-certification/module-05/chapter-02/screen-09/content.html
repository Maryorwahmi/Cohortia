Common chainIds
Mainnet — chainId: 1
The production Ethereum network.
Sepolia — chainId: 11155111
A common testnet for contract testing and staging.
Local dev — chainId: 1337
Local networks (Ganache) or custom IDs for development.
Checking the chain
const currentChainHex = await window.ethereum.request({ method: 'eth_chainId' });
const currentChainId = parseInt(currentChainHex, 16);
if (currentChainId !== requiredChainId) {
  // prompt switch
}
Always parse the hex chainId when reading from the provider and compare to the numeric requiredChainId stored in configuration.
Key Takeaway

Treat chainId as authoritative for network checks; do not assume identical addresses across networks.
