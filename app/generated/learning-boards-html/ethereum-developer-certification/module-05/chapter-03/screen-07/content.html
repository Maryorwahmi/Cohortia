Module 5 › Chapter 5.3 › Calling .call()
Process

Three-step read-only call

1. Ensure Contract is loaded
Do not call methods before new web3.eth.Contract(...) has completed.
2. Use .methods and call()
Example: await simpleStorageContract.methods.getNumber().call();
3. Await and render
Update DOM elements with the resolved value and handle errors.
Concrete example
// call a view function
const storedNumber = await simpleStorageContract.methods.getNumber().call();
document.getElementById('displayNumber').textContent = storedNumber;
Misconception
.call() does not and cannot modify contract state. To change state you must send a transaction with .send() and pay gas.
Key takeaway
Use .call() for reads, await the result, and update your UI without creating transactions.
