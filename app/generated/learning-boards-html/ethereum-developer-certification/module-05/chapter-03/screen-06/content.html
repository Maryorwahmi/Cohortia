Code Walkthrough

Create the Contract instance

const simpleStorageABI = [ /* your ABI JSON array */ ];
const simpleStorageContractAddress = '0xYourDeployedContractAddressHere';
let simpleStorageContract;

async function loadContract() {
  if (!web3) {
    console.error('Web3 not initialized');
    return;
  }
  simpleStorageContract = new web3.eth.Contract(simpleStorageABI, simpleStorageContractAddress);
  console.log('Contract instance loaded:', simpleStorageContract);
}
Tip
Load the contract after wallet connection so web3 is ready.
Pitfall
Referencing .methods before initialization returns undefined behavior.
How it works
  • ABI tells Web3 how to encode function calls.
  • Address tells Web3 where to send encoded messages.
  • The Contract object exposes .methods.() to call functions.
Key takeaway
Instantiate after web3 is available and keep ABI/address in your frontend config.
