Verified Competency Milestones

Small tasks you can complete now to prove understanding.

Milestone 1
Inspect ABI JSON
Open the compiler output and verify functions like getNumber and add appear with correct inputs and stateMutability.
Milestone 2
Capture contract address
After deployment, paste the address into app.js and verify it matches the receipt or explorer output.
Milestone 3
Call view/pure functions
Run getNumber().call() and add(5,7).call() and confirm console logs show resolved values.
Milestone 4
Update UI with values
Wire the DOM to show storedNumber and sum, and add a refresh action that re-fetches using .call() without sending a transaction.
