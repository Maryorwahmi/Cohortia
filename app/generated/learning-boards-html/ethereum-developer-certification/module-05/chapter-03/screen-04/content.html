Definition

Application Binary Interface

A machine-readable JSON array that lists a contract's public functions, inputs, outputs, and mutability so tooling like Web3.js can interact with it.

Example
An ABI entry for add shows it accepts two uint256 inputs and returns a uint256; Web3 uses that to encode parameters and decode the sum.
Mnemonic
ABI = function map; think of it as the contract's public API schema.
Why this matters
  • Web3.js relies on the ABI to form method calls and decode returned values.
  • A mismatched ABI can cause cryptic errors or incorrect return parsing.
  • Keep the ABI in your frontend build artifacts and update it when you recompile contracts.
Common mistake
Using an ABI from a different contract version. Even minor signature changes break call encoding.
Key takeaway
Always ship and reference the ABI that matches your deployed contract bytecode.
