Practice questions

Q1: How to get an ERC-20 balance?
Answer: Provide the ERC-20 ABI, deployed address, and the user's account. Instantiate new web3.eth.Contract(abi,address) and call tokenContract.methods.balanceOf(account).call(), then convert raw units to human-readable value by applying decimals or fromWei.
Q2: Seeing [object Promise] from a call?
Answer: You forgot await. Use const val = await contract.methods.myBigNumber().call(); and if the value is large convert with BigInt(val) or web3.utils.toBN(val) for arithmetic.
Key takeaway
These checks confirm you can locate a contract, execute read-only calls, and handle numeric return types safely for display and computation.
