Common mistakes and how to avoid them

Wrong ABI or Address
Double-check the ABI version and the deployment address and network before calling.
Forgetting await
Always await .call() or use .then(); otherwise you work with a Promise object, not the value.
Misinterpreting return types
uint256 often arrives as a string; convert with BN/BigInt when needed.
Using .call() for writes
.call() cannot change state. Use .send() with gas for transactions.
No error handling
Wrap calls in try/catch and show user-friendly messages on failure.
Key takeaway
Follow the checklist: ABI/address, await, numeric handling, and error management for reliable reads.
