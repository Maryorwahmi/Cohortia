Module 5 › Chapter 5.3 › view vs pure vs transactions
Comparison
view
Reads state, cannot modify it, use .call(), no gas when called externally.
pure
Only computes from inputs, does not read state, use .call(), gas-free externally.
state-changing
Modifies contract storage, requires transaction with .send(), consumes gas and needs mining.
Concrete examples
  • getNumber() — view — call with .call()
  • add(5,7) — pure — call with .call()
  • setNumber(7) — nonpayable — use .send() and pay gas
Key takeaway
Distinguish read-only functions from state-changers; pick .call() for queries and .send() for writes.
