ABI + Address
The minimal pair to build a contract instance.
Use .call()
For view and pure functions; await Promises.
Handle numbers
Treat uint256 as strings; use BN/BigInt and unit conversion when needed.
Final thought
Read-only calls let your UI reflect real blockchain state instantly and without gas. Getting ABI, address, awaiting calls, and handling numeric types correctly makes that possible.
