Returned integers as strings

Web3.js returns large integers as strings to avoid JavaScript precision loss. Convert depending on expected size and use-case.

Small number
parseInt(storedNumber, 10) is fine for values well within Number.MAX_SAFE_INTEGER.
Large number
Use web3.utils.toBN(value) or BigInt(value) for precise arithmetic.
Token decimals
If a balance uses 18 decimals, apply web3.utils.fromWei(rawBalance, 'ether') for user-friendly display.
Code examples
// small number
const n = parseInt(storedNumber, 10);

// big number with BN
const bn = web3.utils.toBN(storedNumber);

// display wei as ether
const readable = web3.utils.fromWei(rawBalance, 'ether');
Key takeaway
Do not coerce large uint256 values to Number; use BN or BigInt and convert units when needed for display.
