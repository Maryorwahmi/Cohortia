Orientation

You'll follow a small live-coding flow: compile SimpleStorage, obtain ABI and address, instantiate the contract in app.js, then call getNumber and add using .call(). We'll also show how to safely convert returned values for display.

Why it matters
Read operations power UI data: balances, metadata, and game state without costing gas.
Common error
Using the wrong ABI or forgetting await will cause confusing errors or unresolved Promises.
