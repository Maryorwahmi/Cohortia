Module 5 › Chapter 5.1 › Common Errors & Security
Async bug
Omitting await causes unresolved Promises. Always await or chain .then to access values.
Provider misconfig
Wrong RPC URL or node offline results in connection refusals. Double-check the endpoint and node status.
Exposing secrets
Never embed private keys or secret project IDs in client-side bundles. Use server proxies or env variables.
Signing transactions
Use MetaMask/injected providers for user signing. Server-side signing is for backend flows under your control.
Test environment
Develop against Ganache or public testnets before interacting with mainnet to avoid real costs and risks.
Pro tip
Add explicit error messages and retry logic around network calls to make debugging faster for both devs and users.
