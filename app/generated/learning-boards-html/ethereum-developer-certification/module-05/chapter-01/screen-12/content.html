Module 5 › Chapter 5.1 › Contract Interaction
Create and use a contract
const contract = new web3.eth.Contract(abi, contractAddress);

// Read-only call
const value = await contract.methods.someView().call();

// State-changing transaction
await contract.methods.changeState(42).send({ from: accountAddress });
Use .call for view functions and .send for transactions that modify state. Ensure ABI and address are correct.
Signing
Injected wallets sign transactions in the browser. For backend signing, keep private keys on the server and never expose them to clients.
Gas & value
When sending a transaction, specify gas and value if required. Check account balance before sending to avoid failures.
Key Takeaway

Differentiate read-only .call() from state-changing .send(), and ensure your provider supports signing for transactions.
