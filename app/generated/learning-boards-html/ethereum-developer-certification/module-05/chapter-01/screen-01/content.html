Introduction to DApps and Web3.js
How frontends communicate with Ethereum and why that matters for DApp design.

A DApp combines a familiar web frontend with smart-contract logic on-chain. Web3.js is the client library that lets JavaScript call contract methods, query blocks, and submit transactions through an Ethereum node. This chapter gives you the setup, sample code, and essential provider choices for early DApp development.

In this lesson
You will set up a Node project, install Web3.js, connect to a Ganache node, and verify results using getBlockNumber and getAccounts. We emphasize provider types and correct async patterns.
