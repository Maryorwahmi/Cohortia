Web3.js — client library
Provides APIs for accounts, transactions, contracts, and events.
  • Converts JavaScript calls into JSON-RPC requests the node can execute.
  • Returns asynchronous Promises for most operations.
  • Works with multiple provider types depending on your environment.
Practical example
Install with npm and create a new Web3 instance pointing to a node URL to start making calls.
Quick reference
Common methods you will use:
  • web3.eth.getBlockNumber() — fetch the latest block.
  • web3.eth.getAccounts() — list available accounts.
  • web3.eth.getBalance(address) — get an account balance.
Common pitfall
Assuming synchronous return values. Always await Promises or use .then to access values.
