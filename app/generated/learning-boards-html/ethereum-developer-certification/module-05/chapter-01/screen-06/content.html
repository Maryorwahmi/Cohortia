Module 5 › Chapter 5.1 › Install Web3.js and Initialize
Project setup steps
Create a reproducible environment for your DApp with npm.
Terminal steps
npm init -y
npm install web3
These commands create package.json and add Web3 as a dependency. Confirm package.json lists web3 under dependencies.
Why npm?
npm ensures consistent versions across environments and makes it easy to bundle Web3 into your frontend build.
Verification
Run a quick script that requires Web3 and calls getBlockNumber to ensure connectivity.
Common mistake
Skipping verification or using mismatched package versions can cause runtime errors later in development.
