Module 5 › Chapter 5.1 › Async Operations & Promises
Pattern: async/await
async function fetchData() {
  try {
    const block = await web3.eth.getBlockNumber();
    console.log('Block:', block);
  } catch (err) {
    console.error('Network error:', err.message);
  }
}
Wrap awaits in try/catch to handle network failures gracefully. Use loading indicators in the UI while promises resolve.
Common mistake
Calling web3.eth.getBlockNumber() without await returns a Promise object, causing code that expects a number to break or display incorrect values.
Key Takeaway

Treat Web3.js calls as asynchronous and design your UI to handle loading, success, and error states clearly.

Check your understanding
How would you prevent a user from sending a transaction before accounts are loaded? Think about disabled buttons and account-ready flags.
