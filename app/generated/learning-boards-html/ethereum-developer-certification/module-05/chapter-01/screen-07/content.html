Module 5 › Chapter 5.1 › Initialize Web3.js
Minimal connect.js
Run with node connect.js after installing web3 and running Ganache.
const Web3 = require('web3');
const web3 = new Web3('http://localhost:8545');

async function getBlockNumber() {
  try {
    const blockNumber = await web3.eth.getBlockNumber();
    console.log('Current block number:', blockNumber);

    const accounts = await web3.eth.getAccounts();
    console.log('Available accounts:', accounts);
  } catch (error) {
    console.error('Error connecting to Ethereum:', error.message);
  }
}

getBlockNumber();
This code shows the pattern: create Web3, await calls in an async function, catch errors to diagnose connectivity problems.
Explanation
  • Require or import Web3 depending on environment.
  • Pass a provider URL to the constructor to connect to your node.
  • Wrap calls in async functions and handle promise rejections.
Key Takeaway

A working Web3 instance plus successful getBlockNumber and getAccounts calls confirm a valid provider connection.
