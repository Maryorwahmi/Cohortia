Module 6 › Chapter 5.5 › What is an Ethereum Event?
Definition

Event as a log entry

Events are emitted during transaction execution and stored in the receipt. They are searchable and efficient for notifying off-chain clients.

Analogy
Think of events as a printed receipt attached to a transaction: the official record for interested watchers, but not the contract's internal storage.
Concrete example
A Transfer event tells wallets when to update balances without asking the contract repeatedly.
Key Takeaway

Use events to build reactive UIs, but query contract state when you need authoritative values.

Quick notes
  • Events are cheaper than storage reads when used for notifications.
  • Nodes can index parameters marked indexed for fast lookup.
  • Event logs appear in transaction receipts and include block and tx metadata.
Common misconception
Do not assume logs are canonical state. If app logic depends on exact values, read the contract directly after an event.
