Module 6 › Chapter 5.5 › Key Concepts
Ethereum Event
A log entry emitted by a contract that external clients can listen to for on-chain activity.
indexed
Mark parameters as indexed to allow node-level filtering by those values.
fromBlock & filter
Use fromBlock to control event range and filter indexed fields to receive relevant results only.
Summary

Events make DApps reactive. Design event schemas and subscription patterns intentionally to keep your application responsive and stable.
