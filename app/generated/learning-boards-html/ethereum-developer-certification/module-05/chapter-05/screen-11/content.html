Module 6 › Chapter 5.5 › Subscribe & Update UI
Activity steps
  1. Confirm SimpleStorage includes event NumberChanged and emits it in setNumber.
  2. Add an eventLog element in index.html to show incoming events and a displayNumber element to show the stored number.
  3. After contract is loaded, call subscribeToContractEvents which registers NumberChanged with fromBlock: 'latest'.
  4. In on('data') parse event.returnValues, update displayNumber, and prepend a log entry showing setter and blockNumber.
  5. Implement on('changed') to flag removed events and on('error') to report provider issues.
  6. Track subscription and unsubscribe when the UI component unmounts or on page unload.
Example snippet
// inside subscribeToContractEvents()
simpleStorageContract.events.NumberChanged({ fromBlock: 'latest' })
  .on('data', (event) => { /* update DOM and eventLog */ })
  .on('changed', (event) => { /* handle reorg */ })
  .on('error', (err) => { /* log error */ });
Key Takeaway

Follow these steps to make a live, event-driven UI and avoid common operational mistakes like missing unsubscribes or unspecified fromBlock.
