Module 6 › Chapter 5.5 › fromBlock & History
When to use fromBlock
If you only need new events, use fromBlock: 'latest' to avoid fetching large histories. If you need past events, request a bounded range and paginate results.
Example: listen to new events
simpleStorageContract.events.NumberChanged({ fromBlock: 'latest' })
Loading historical events
Use getPastEvents with explicit fromBlock and toBlock; show a progress indicator and consider caching results to avoid repeat loads.
Key Takeaway

Avoid unspecified fromBlock to prevent heavy historical fetches; be deliberate about history vs live listening.
