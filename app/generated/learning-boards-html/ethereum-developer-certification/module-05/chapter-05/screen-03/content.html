05. Manage subscriptions

Unsubscribe when listeners are no longer needed. Track subscription objects and remove listeners to avoid memory leaks and redundant events.

VERIFIED COMPETENCY MILESTONE
06. Choose provider

Use a WebSocket provider for push-based real-time updates whenever possible. Use HTTP only for occasional or short requests to nodes.

VERIFIED COMPETENCY MILESTONE
07. Handle reorgs

Listen for on('changed') to detect events removed by a chain reorganization. Avoid assuming a single event is final without confirmations where necessary.

VERIFIED COMPETENCY MILESTONE
08. Performance and history

Specify fromBlock: 'latest' to avoid fetching all historical logs at startup. Load older events incrementally only when requested.
