Module 6 › Chapter 5.5 › Filtering & Indexed Params
Indexed vs non-indexed
Indexed parameters are placed into topics and allow node-level filtering. Non-indexed parameters are part of the event data but cannot be efficiently filtered by the node.
Example signature
event NumberChanged(address indexed setter, uint256 oldNumber, uint256 newNumber);
Filter usage
simpleStorageContract.events.NumberChanged({ fromBlock: 'latest', filter: { setter: currentAccount } })
Two-panel comparison
Filtered
Client receives only matching events. Lower network and processing cost.
Unfiltered
Client must handle many events and perform client-side filtering, causing cost and latency.
Key Takeaway

Index the fields you will commonly filter on to let nodes return concise, relevant feeds to your DApp.
