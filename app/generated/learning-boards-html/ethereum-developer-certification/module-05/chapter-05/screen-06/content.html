Module 6 › Chapter 5.5 › Subscribe with Web3.js
Subscription snippet
// Assuming simpleStorageContract is initialized
simpleStorageContract.events.NumberChanged({
  fromBlock: 'latest' // only new events
})
.on('data', (event) => {
  // event.returnValues contains setter, oldNumber, newNumber
  const { setter, oldNumber, newNumber } = event.returnValues;
  console.log('NumberChanged', setter, oldNumber, newNumber);
  document.getElementById('displayNumber').textContent = newNumber;
})
.on('changed', (event) => {
  console.warn('Event removed by reorg', event);
})
.on('error', (error, receipt) => {
  console.error('Subscription error', error, receipt);
});
This pattern wires the data callback to update UI state immediately when new events arrive.
Explanation & checklist
  • Ensure contract instance is ready before subscribing.
  • Set fromBlock: 'latest' to avoid fetching history at startup unless needed.
  • Use filter for indexed params to reduce noise and network load.
  • Handle changed to detect reorgs and error to log provider issues.
Pro tip
If you need historical events for a timeline, fetch them separately with getPastEvents and present them lazily to avoid blocking initialization.
