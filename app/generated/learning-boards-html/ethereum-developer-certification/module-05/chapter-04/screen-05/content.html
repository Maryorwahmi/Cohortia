Module 5 › Chapter 5.4 › Transaction Parameters
Parameter breakdown
from
The signing address. Must be the connected wallet account used to pay gas.
value
Amount of Ether to send in wei. Use web3.utils.toWei('0.5', 'ether').
gas / gasLimit
Maximum gas units allowed. If too low the transaction fails; unused gas is refunded.
gasPrice / EIP-1559
Legacy gasPrice or EIP-1559 fields: maxFeePerGas and maxPriorityFeePerGas for modern networks.
Practical example
const tx = {
  from: currentAccount,
  value: web3.utils.toWei('0.1', 'ether'),
  gas: Math.floor(estimate * 1.2)
};
await contract.methods.deposit().send(tx);
Common mistakes
  • Specifying value in Ether instead of wei.
  • Failing to set from, causing provider rejection.
  • Not matching fee fields to the network’s fee model.
Tip

Detect the network type and choose gasPrice or EIP-1559 fields so MetaMask shows sensible defaults to the user.
