Module 5 › Chapter 5.4 › Practice Objectives
What to implement
  • Input validation: ensure positive numeric values and clear errors to users.
  • Gas estimation: call contract.methods.setNumber(...).estimateGas and add ~20% buffer.
  • Send transaction: include from and gas in the parameters; await the receipt and refresh UI.
  • Error handling: detect code 4001 and inspect error messages for insufficient funds or revert reasons.
VERIFIED COMPETENCY MILESTONE
A user can set a new number, confirm the MetaMask popup, and see the updated stored value after the transaction is mined.
