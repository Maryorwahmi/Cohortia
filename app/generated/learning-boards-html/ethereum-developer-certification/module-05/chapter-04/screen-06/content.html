Module 5 › Chapter 5.4 › Gas Estimation
Step-by-step
  1. Call estimateGas with the same from and parameters you will use.
  2. If estimate succeeds, compute a buffer: Math.floor(estimate * 1.2).
  3. Convert the estimated gas into an Ether cost for user display using gasPrice or estimated EIP-1559 fees.
  4. Include the buffered gas in the send parameters to reduce out-of-gas failures.
Example
const estimate = await simpleStorageContract.methods.setNumber(newNumber).estimateGas({ from: currentAccount });
const gasLimit = Math.floor(estimate * 1.2);
await simpleStorageContract.methods.setNumber(newNumber).send({ from: currentAccount, gas: gasLimit });
Pitfalls & UX
  • estimateGas can throw if the call would revert; do not prompt MetaMask then.
  • Large buffers avoid fails but set unrealistic caps; keep them conservative.
  • Show the estimated cost in ETH so users understand the charge.
Key Takeaway

Estimate gas, add a small buffer, and handle estimate failures before requesting a wallet signature.
