Preflight checklist
  • Ensure wallet is connected and currentAccount is set.
  • Fetch balance: web3.eth.getBalance(currentAccount) and show it.
  • Estimate gas for the exact call and compute total estimated cost.
  • Show a confirmation summary with estimated ETH cost and action description.
Developer note
Log detailed error info to the console and present human-friendly guidance in the UI to help non-technical users recover.
Do not
  • Never expose or transmit private keys from the browser.
  • Don't show raw stack traces to users — provide actionable steps instead.
Key Takeaway

Design preflight checks and clear confirmation screens. Keep users informed about cost and safety, and never handle keys yourself.
