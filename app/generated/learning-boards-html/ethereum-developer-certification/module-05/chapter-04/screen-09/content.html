Module 5 › Chapter 5.4 › Error Handling
Error types
User rejection (4001)
Handle calmly, show retry option and explain what the user rejected.
Insufficient funds
Preflight check account balance against estimated gas + value and warn before prompting.
Out of gas
Avoid by estimating gas; if it happens, report a clear failure message.
Reverted transactions
Detect via receipt.status and show possible reasons; log revert messages for debugging.
Handling pattern
  1. Preflight: validate input and check balance.
  2. Estimate gas and compute cost for display.
  3. Try send; catch errors and branch on error.code or message.
  4. On receipt, verify status and update UI or display revert info.
Example catch
try {
  const receipt = await method.send(tx);
} catch (error) {
  if (error.code === 4001) { /* user rejected */ }
  else if (error.message.includes('insufficient funds')) { /* warn user */ }
  else { /* log and show fallback */ }
}
