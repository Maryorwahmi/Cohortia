Module 5 › Chapter 5.4 › Call vs Send
Definition

A call executes locally and returns values without creating a transaction. A send constructs a signed transaction that is broadcast and mined, modifying state and consuming gas.

Example: Read
const value = await simpleStorageContract.methods.getStoredNumber().call();
console.log(value); // free
Example: Write
await simpleStorageContract.methods.setNumber(42).send({ from: currentAccount });
// costs gas, requires signature
Why it matters
  • Cost: calls are free; sends consume Ether as gas.
  • Identity: sends need the sender's account to sign the transaction.
  • Timing: sends require time to be mined; UI should show pending and confirmed states.
Key Takeaway

Use calls for reads and sends only when you need to change on-chain data. Always inform the user about gas and confirmation time.
