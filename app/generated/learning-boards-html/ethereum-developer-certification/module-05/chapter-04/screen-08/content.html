Module 5 › Chapter 5.4 › Transaction Receipt
Receipt snapshot and meaning
{
  transactionHash: '0xabc...',
  blockNumber: 12345,
  gasUsed: 21000,
  status: true
}
Use transactionHash for references, status to check success, and gasUsed to audit costs. After receipt, refresh on-chain reads to reflect the new state in your UI.
Best practices
  • Show the hash immediately so users can track the transaction externally.
  • Wait for receipt.status === true before claiming success in your UI.
  • Consider waiting for additional confirmations if you need stronger finality guarantees.
Key Takeaway

Receipts are the definitive on-chain result. Use them to verify success, show hashes, and refresh your UI after confirmation.
