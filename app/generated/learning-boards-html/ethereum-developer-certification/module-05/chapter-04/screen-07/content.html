Module 5 › Chapter 5.4 › MetaMask Flow
Typical sequence
  1. Prepare tx parameters and estimate gas.
  2. Call contract.methods.fn(...).send(tx) and wait for wallet popup.
  3. User approves: transaction broadcasts and returns a receipt when mined.
  4. User rejects: provider throws error with code 4001 — handle gracefully.
Code example
try {
  const receipt = await simpleStorageContract.methods.setNumber(newNumber).send({ from: currentAccount, gas: gasLimit });
  console.log('Mined:', receipt.transactionHash);
} catch (error) {
  if (error.code === 4001) {
    console.log('User rejected the transaction');
  } else {
    console.error('Transaction error', error);
  }
}
UX recommendations
  • Show a clear pending state after user confirms.
  • Display transactionHash and let users copy or view details externally.
  • Handle user rejection without alarming language; offer retry guidance.
Misconception

Do not assume the wallet will auto-cancel or auto-retry for failures. Your app must detect and report outcomes clearly.
