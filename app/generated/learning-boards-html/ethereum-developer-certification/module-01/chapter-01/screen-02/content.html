How we'll practice
A short lab will run a Python script that creates three blocks and shows how changing one block alters its hash and breaks the chain. This reinforces hashing, previous-hash linking, and immutability by observation.
Assessment idea
  • Explain whether a central server system is truly decentralized using core principles.
  • Interpret a mismatch between a block's previous-hash and the actual hash of its predecessor.
