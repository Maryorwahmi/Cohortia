Module 1 › Chapter 1.1 › Assessment idea
Question 1
A project claims decentralization but uses a single private server to validate transactions. Is it decentralized?
Answer reasoning: No. Decentralization requires distributed validation and storage across independent nodes. A single validating server creates a central point of control and failure, allowing censorship or ledger alteration by its operator.
Question 2
You find a block whose previous-hash does not match the prior block's hash. What does that mean?
Answer reasoning: A mismatch indicates the chain link is broken. Either a block was tampered with or an invalid block was inserted. Nodes reject such blocks because cryptographic linking verifies consistency across history.
Key Takeaway
Assess claims by tracing control, copies, and hash links rather than accepting labels alone.
