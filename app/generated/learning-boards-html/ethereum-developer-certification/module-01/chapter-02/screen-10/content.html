Code › Bytecode & Deployment
From source to bytecode to execution
Deployment stores bytecode; calls execute that code on the EVM.
// Conceptual flow
// 1. Write smart contract source
// 2. Compile -> bytecode
// 3. Deploy transaction stores bytecode in a contract account
// 4. Calls run bytecode on the EVM, consuming gas
// Note: EVM executes bytecode deterministically on every node
Deployment cost note
Storing code increases gas used during deployment. Minimize unnecessary code and use lightweight initialization where possible.
Key Takeaway

Bytecode is the runtime artifact; plan for deployment costs and immutability when releasing contracts.

Misconception
Source code publication is for humans. The network executes compiled bytecode only.
Concrete example
A token deploy stores balance mapping logic; calls to transfer update those mappings deterministically through bytecode execution.
