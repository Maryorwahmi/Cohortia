Definition › Ethereum Accounts
Account hierarchy and control
Two account types with different controllers and permissions.
EOA: controlled by a private key; can sign transactions and pay gas.
Contract Account: controlled by code; no private key; executes when called.
Interactions: EOAs call contracts, contracts call other contracts, and both can hold Ether.
Concrete scenario
You sign a transaction with your wallet (EOA) to call a DeFi contract (contract account) to swap tokens. Your EOA pays gas and the contract executes the swap logic.
Security note
Protect private keys for EOAs and audit contract code for contract accounts. Each has a different threat model.
Common Mistake

Assuming a contract account is a 'wallet' you can control like an EOA. Contract behavior depends solely on code logic.

Key Takeaway

Design clear boundaries: which actions require human signing and which run autonomously in contract logic.
