Smart Contract — definition and implications
Self-executing program stored on-chain that enforces terms without a third party.
Immutable once deployed unless upgrade patterns are used.
Every on-chain operation consumes gas and costs Ether.
Can interact with EOAs and other contracts through messages and calls.
Requires careful testing and audits because code becomes policy.
Concrete example: Freelancer payout
Client deposits funds to the contract. When verification is set true, the contract releases the funds to the freelancer automatically, removing reliance on a trusted escrow agent.
Why this matters
Smart contracts enable dApps, decentralize control, and let value flow without intermediaries.
Key Takeaway

Use smart contracts for on-chain enforcement, but plan upgrades and off-chain checks for real-world data.

Misconception
A smart contract is not a legal contract by itself; it is a technical mechanism that enforces coded rules.
