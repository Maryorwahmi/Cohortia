Process › Block Explorer Walkthrough
Inspect blocks, transactions, and contracts
A step-by-step exercise to build intuition from live data.
Step 1 — Latest blocks
Observe block height, timestamp, transactions, gas used, and parent hash to follow chain progression.
Step 2 — Transaction details
Open a transaction to view status, hash, from/to, value, gas used, and gas price.
Step 3 — Inspect a contract
If verified, read public functions and try reading values via 'Read Contract' to see transparency in action.
Common Pitfall

Confusing gas limit with gas used. Gas limit is a cap you set; gas used is what the transaction actually consumed.

Key Takeaway

Regularly inspect transactions and contracts to validate expected behaviour and to estimate real costs.
