Module 2 › Chapter 1.3 › Yarn and Global npm Permissions
Definition
Yarn as an alternative and permission handling

Yarn provides an alternative package management workflow, but both npm and yarn install packages from the registry for project use. Handling permission errors properly keeps your environment secure and predictable.

Safe fix example
npm config set prefix '~/.npm-global'
# Then add ~/.npm-global/bin to your PATH in your shell profile
This moves global installs to a user-owned folder so you don't need elevated privileges.
Why this matters
  • Using sudo for npm can change ownership of files and break environment consistency.
  • Project-local devDependencies are reproducible and avoid global pollution.
  • Configuring a user prefix makes global CLI tools available without admin rights.
Common mistake
Immediately re-running an install with sudo instead of fixing the prefix, which hides the underlying configuration issue.
