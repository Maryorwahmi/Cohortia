Start the local node to expose an RPC

Run a dedicated node terminal so it listens on the default RPC URL and prints accounts with private keys for import into MetaMask.

Example output (abbreviated)
HardhatNetworkProvider -> Listening on http://127.0.0.1:8545
Accounts:
0x90f8bf6a479f320ead074411a4b0e7944ea8c9c1 (10000 ETH)
Private Key: 0xac0974... (copy to import)
The node prints many accounts; copy a private key to import into your wallet for testing.
Practical advice
  • Keep the node terminal open while interacting from MetaMask or scripts so the RPC remains available.
  • Don’t share these keys outside your local environment; they are for local testing only.
  • If the chain resets, the accounts and funds reset too; use persistent providers if you need long-lived state.
Common mistake
Importing a private key into MetaMask while the node is not running or pointing MetaMask to the wrong RPC URL, which results in a network connection error.
