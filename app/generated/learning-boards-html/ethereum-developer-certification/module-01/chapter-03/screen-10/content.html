Module 2 › Chapter 1.3 › Initialize a Hardhat Project — Guided Walkthrough
Terminal demo
Create directory and init
mkdir my-first-hardhat-project
cd my-first-hardhat-project
npm init -y
Install Hardhat and initialize
npm install --save-dev hardhat
npx hardhat
# choose 'Create a JavaScript project' and accept defaults
Start the local node
npx hardhat node
Expected result

The node terminal lists 20 accounts with private keys and large test balances. Use one private key to import an account into MetaMask, which will then display the test Ether on the Hardhat Local network.

Key Takeaway

Following this flow yields a reproducible, local development environment ready for contract compilation, deployment, and testing.
