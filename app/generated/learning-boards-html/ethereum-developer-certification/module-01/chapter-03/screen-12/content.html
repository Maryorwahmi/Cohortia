Common mistakes
Permission error on npm install
Fix by setting npm prefix to a user-owned directory or use project-local devDependencies; avoid sudo.
MetaMask shows network error
Confirm the node is running and the RPC URL and Chain ID match exactly in MetaMask settings.
Imported key shows no funds
Ensure you imported a private key printed by the running local node and that MetaMask is pointed to the same local network.
Chain state resets unexpectedly
Remember in-memory networks reset on restart; use persistent nodes if you need state preserved across sessions.
Quick troubleshooting checklist
  1. Is the local node terminal running and listening?
  2. Does MetaMask have the exact RPC URL and Chain ID?
  3. Did you import a private key printed by the running node?
  4. Are you avoiding sudo for npm installs?
