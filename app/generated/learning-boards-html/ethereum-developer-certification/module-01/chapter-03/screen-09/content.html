Module 2 › Chapter 1.3 › Install and Configure MetaMask
Create or Import
Set up a wallet and secure the seed phrase

Follow MetaMask prompts to create a wallet or import one. Write your seed phrase on paper and store it safely; never share it. For local testing prefer a test account or import a private key from the local node output.

Importing a private key
Open account menu, choose Import Account, select Private Key, paste the private key copied from your local node, and import to see test Ether in MetaMask.
