Module 2 › Chapter 1.3 › RPC URL and Chain ID
Definition
How wallets and nodes connect

The RPC URL is the HTTP endpoint where a node accepts JSON-RPC requests. The Chain ID is a numeric network identifier used to ensure transactions are bound to the right chain and to prevent replay attacks across networks.

Common local values
RPC URL: http://127.0.0.1:8545
Chain ID: 31337
Troubleshoot
If MetaMask shows "Network Error", ensure the node is running and that the RPC URL and Chain ID match exactly.
Check your understanding
  • Why does a mismatched Chain ID cause errors? Because signatures include the Chain ID to prevent replay across networks.
  • How do you confirm the RPC is listening? Look for a listening message in the node terminal for the configured URL and port.
