Definition
What Node and npm do for Ethereum developers

Node provides the runtime for development tools. npm and yarn install packages such as compilers, linters, and Hardhat itself. Without them you cannot easily add or run the JavaScript-based tooling that supports smart contract workflows.

Concrete example
node -v
npm -v
npm init -y
npm install --save-dev hardhat
Run these commands to confirm Node and npm and to install Hardhat as a dev dependency.
Common mistake
Using sudo to install global packages which can create permission and security issues later.
Pro tip
If you see permission errors, configure npm to use a user-owned global directory instead of using elevated permissions.
Why this matters
  • Tooling packages are published to the npm registry and installed via npm or yarn.
  • Hardhat, Truffle, and other utilities depend on Node to run their CLI tasks and test runners.
  • Version mismatches can produce confusing errors; always verify versions before continuing.

Why is Node required for Hardhat?
Hardhat distributes its CLI and plugins as JavaScript packages that run on Node's runtime.
