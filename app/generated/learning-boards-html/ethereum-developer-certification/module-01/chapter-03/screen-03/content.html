Verification steps
Avoid using sudo for npm
Configure npm prefix to a user-owned directory to prevent permission errors when installing global packages.
Check local node output
When you run the local node, copy a private key from the listed accounts and import it into MetaMask for test Ether.
Secure seed phrase
Write your MetaMask seed phrase offline and never share it. For local testing use generated test keys instead of real wallets.
Choose GUI or CLI
Pick Ganache for a GUI with quick visuals or Hardhat Network for an integrated, scriptable in-memory environment.
Mini-mnemonic
"Install — Start — Connect — Test"
Follow these steps each time you set up a project so your development flow is predictable and debuggable.
