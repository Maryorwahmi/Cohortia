Module 2 › Chapter 1.3 › Install and Initialize Hardhat
Step-by-step
1. Create project folder
mkdir my-ethereum-project
cd my-ethereum-project
2. Initialize Node project
npm init -y
3. Install Hardhat locally
npm install --save-dev hardhat
4. Run Hardhat initializer
npx hardhat
Choose create a JavaScript project and accept defaults to scaffold files.
Why this matters

This sequence creates package.json, hardhat.config.js, and folders such as contracts, scripts, and test so compilation and tests are organized and reproducible across machines.

Key takeaway
Install Hardhat as a devDependency and use npx so the project binary is consistent for all contributors.
Common mistake
Installing Hardhat globally and expecting the same behavior across developer machines; local installs preserve reproducibility.
