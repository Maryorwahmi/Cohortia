Module 3 › Chapter 3.2 › Error Handling
require
Validate inputs and expected conditions early. If the check fails, revert and return unused gas.
Example: require(balances[msg.sender] >= _amount, 'Insufficient balance');
revert · assert
Use revert for complex conditional exits; use assert only for invariants. If assert fails, it signals a critical bug and consumes all gas.
Misuse: using assert for normal input validation can make ordinary errors costly and opaque.
Key Takeaway

Choose require/revert for expected checks with messages and assert only for never-fail invariants.
