Module 3 › Chapter 3.2 › Conditionals
Definition
if / else if / else
Evaluate boolean expressions so only eligible code paths run. Use require when a condition must hold before proceeding.
Example: require caller is owner before updating a protected variable.
Common mistake: relying on silent fall-through when a condition is false, leading to skipped state updates.
Key Takeaway

Write explicit checks and clear error messages so the contract state is always predictable after condition evaluation.

Concrete Example
// guard an action
if (msg.sender == owner) {
  value = _newValue;
} else {
  revert('Not authorized');
}
This pattern ensures only the owner can mutate state and provides a clear revert message when the check fails.
Check Your Understanding
What would happen if you omitted the revert and left the branch empty? Consider how the contract state and caller expectations change.
