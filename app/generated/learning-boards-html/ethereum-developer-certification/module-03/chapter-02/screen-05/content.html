Module 3 › Chapter 3.2 › Loops & Gas
Definition
for and while
Repeat code blocks but remember each iteration costs gas. Always bound iterations or avoid them on large datasets.
Safety pattern: require the loop limit is less than or equal to the array length before iterating.
Misconception: looping off-chain is the same. On-chain loops still incur gas and can fail if large.
Code Example
function processNumbers(uint _limit) public view returns (uint sum) {
    require(_limit <= numbers.length, "Limit exceeds array size");
    for (uint i = 0; i < _limit; i++) {
      sum += numbers[i];
    }
    return sum;
}
This example enforces a limit, but still runs one iteration per item. For large arrays, prefer alternative designs such as pagination or pull-based claiming.
