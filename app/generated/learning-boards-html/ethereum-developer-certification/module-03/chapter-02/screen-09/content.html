Module 3 › Chapter 3.2 › Payable
Concept
public payable
A payable function receives Ether via the transaction. Use msg.value to inspect the amount and update balances only after validation.
function deposit() public payable {
  // msg.value is the Ether sent
  // update balances[msg.sender] += msg.value;
}
Common pitfall
If not marked payable, any Ether sent reverts. If unchecked, malicious actors could force unexpected state changes with value-bearing calls.
