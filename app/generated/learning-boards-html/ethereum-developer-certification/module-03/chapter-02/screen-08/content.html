What they mean
view · pure · payable
Use view for read-only state access; pure for functions that only use inputs; and payable when the function must accept Ether with the call. Validate msg.value when taking Ether.
Example: function multiply(uint a, uint b) public pure returns (uint) { return a * b; }
Example: function deposit() public payable { /* msg.value contains the Ether sent */ }
Quick Check
If a function does not touch state and returns a value computed only from inputs, mark it pure. If it reads state but doesn't change it, mark it view.
