Module 3 › Chapter 3.2 › Visibility
Public vs External
Public
Callable both externally and internally. Use when internal calls are needed.
External
Callable only from outside the contract; often more gas-efficient for external-only interfaces.
Private vs Internal
Private
Only callable within the same contract; not visible to inheriting contracts.
Internal
Callable within the contract and by derived contracts; useful for reusable helpers.
Example Decision
If a function exists only to provide an API for users, prefer external; if it is a helper for derived contracts, prefer internal.
