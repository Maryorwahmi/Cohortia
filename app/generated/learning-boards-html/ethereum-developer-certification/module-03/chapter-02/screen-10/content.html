Module 3 › Chapter 3.2 › Modifiers
Syntax
modifier onlyOwner() { require(msg.sender == owner, 'Caller is not the owner'); _; }
The underscore indicates where the modified function's code will execute. Modifiers can be stacked to run multiple checks in order.
Applied Example
modifier greaterThanZero(uint _amount) {
  require(_amount > 0, 'Amount must be greater than zero');
  _;
}

function setValue(uint256 _newValue) public onlyOwner greaterThanZero(_newValue) {
  value = _newValue;
}
Stacking enforces owner and amount checks before the state change. Place fast, cheap checks first to fail early.
