Module 3 › Chapter 3.2 › Best Practices
Avoid these common mistakes
  • Unbounded loops: Can cause out-of-gas failures; redesign long iterations into smaller operations.
  • Overexposed visibility: Public where internal or private is intended increases risk.
  • Misused assert: Use it only for invariants, not for normal input validation.
  • Missing payable: Forgetting payable on functions that receive Ether will cause reverts.
Action Items
Write unit tests for owner and unauthorized flows.
Prefer fail-fast require checks with messages.
Limit loop size and avoid state-changing mass-ops in one transaction.
