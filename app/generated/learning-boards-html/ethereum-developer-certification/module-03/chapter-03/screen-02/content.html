Module 3 › Chapter 3.3 › Learning Objectives
01
Events
Declare and emit searchable events

You will learn to declare events with indexed parameters and emit them to the transaction logs. This matters because logs are cheaper than storage and enable efficient off‑chain monitoring.

VERIFIED COMPETENCY MILESTONE
02
Inheritance
Implement contract inheritance

You will use the is keyword, understand virtual and override, and correctly chain parent constructors. This reduces duplication and clarifies ownership of state and behavior.

VERIFIED COMPETENCY MILESTONE
03
Abstract & Interface
Differentiate blueprints

You will know when to provide partial implementations with abstract contracts and when to declare pure interfaces as strict contracts of behavior without state.

VERIFIED COMPETENCY MILESTONE
04
Libraries
Integrate and extend types

You will use libraries for code reuse and apply using for to extend primitive types, while recognizing delegatecall and audit considerations for public library calls.
