Hierarchy

is, virtual, override

Parents expose behavior and state; children inherit and may override where marked virtual. Explicit override pairs prevent accidental changes.

Pattern
contract Parent {
  function greet() public virtual returns (string memory) {
    return "hello";
  }
}

contract Child is Parent {
  function greet() public override returns (string memory) {
    return "hello from child";
  }
}
Constructor chaining

If a parent expects constructor arguments, the child must call it in its constructor header. This ensures parent state is initialized predictably and avoids uninitialized variables that can lead to security issues.

Example

constructor(string memory _name) Parent(_name) { ... } will pass arguments to the Parent constructor and initialize its state.

Common mistake

Forgetting to call a required parent constructor leaves the parent state defaulted and can break invariants. Always check parent constructors when inheriting.

Key Takeaway

Make inheritance explicit: mark overridable functions and call parent constructors with required arguments to maintain invariants.
