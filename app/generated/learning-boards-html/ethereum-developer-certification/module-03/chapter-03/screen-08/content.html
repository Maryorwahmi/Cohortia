Module 3 › Chapter 3.3 › Multiple inheritance
Process

Resolve conflicts and call parent constructors

Rule of thumb
  • List parents from most derived to most base.
  • Override functions with ambiguous signatures in the child.
  • Explicitly call parent constructors with required args.
Example override
contract A { function foo() public virtual returns (string memory) { return "A"; } }
contract B { function foo() public virtual returns (string memory) { return "B"; } }
contract C is A, B {
  function foo() public override(A, B) returns (string memory) {
    return B.foo(); // explicit resolution
  }
}
Checklist

Before deploying, verify parent constructor calls, explicit overrides exist for overlapping functions, and unit tests cover inherited behavior across the hierarchy.
