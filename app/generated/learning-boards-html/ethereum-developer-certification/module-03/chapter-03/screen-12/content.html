Module 3 › Chapter 3.3 › Key Concepts
Events
Emit logs for off‑chain monitoring; index up to three fields for filtering.
Inheritance
Use is, virtual, override, and call parent constructors to share logic safely.
Libraries
Centralize audited utilities; prefer internal embedding to avoid delegatecall risks.
Bottom line

Design: store what contracts need to read, emit what external tools need to index, inherit to reuse behavior, and use libraries for audited utilities.
