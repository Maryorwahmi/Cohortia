Module 3 › Chapter 3.3 › Events: declare and emit
Definition

Event declaration and emission

Declare an event with the event keyword and emit it where state changes occur. Indexed parameters make logs searchable by node providers and frontends.

Example declaration
event Transfer(address indexed from, address indexed to, uint256 amount);

// Emitting the event
emit Transfer(msg.sender, _recipient, _value);
When to emit

Emit on value transfers, role changes, configuration changes, and other auditable events.

Common mistake

Expecting events to be readable by other contracts. Events are off‑chain artifacts and should not be used for on‑chain control flow.

Concrete scenario

Token transfer logging

A token contract emits Transfer whenever tokens move. A wallet or analytics service filters Transfer by the recipient address to show incoming transactions without scanning all transactions.

Check your understanding
  • Why make fields indexed? — To let providers filter logs efficiently without full scans.
  • How many indexed params? — Up to three; choose the most queryable fields.
Key Takeaway

Use events to provide auditable, searchable history for off‑chain apps. Do not depend on them for on‑chain state.
