Module 4 › Chapter 3.4 › Checks-Effects-Interactions
Pattern
1. CHECKS

Validate inputs and state conditions using require statements. Example: require(balances[msg.sender] >= amount).

2. EFFECTS

Update internal state immediately. Example: balances[msg.sender] -= amount.

3. INTERACTIONS

Make external calls only after state is safe. Example: (bool success, ) = payable(msg.sender).call{value: amount}("");

Key Takeaway

Apply this order in every state-changing function that performs external calls.

Secure withdraw example
// Secure pattern in withdraw
require(balances[msg.sender] >= _amount, "Insufficient balance");
balances[msg.sender] -= _amount; // EFFECTS
(bool success, ) = payable(msg.sender).call{value: _amount}(""); // INTERACTIONS
require(success, "Transfer failed");
When to add ReentrancyGuard

As an extra layer, nonReentrant prevents reentry by locking the function during execution; combine it with the pattern for defense in depth.
