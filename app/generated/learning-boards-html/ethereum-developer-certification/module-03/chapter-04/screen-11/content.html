Module 4 › Chapter 3.4 › Best Practices & Tools
Checklist
External Calls

Treat as untrusted, isolate, and follow Checks-Effects-Interactions.

Gas & Loops

Avoid unbounded loops and prefer pull payments or batching.

Arithmetic

Use compiler checks or SafeMath for older compilers; test boundary cases.

Fallbacks

Keep fallback minimal; avoid complex state changes.

Testing & Tools

Write unit and integration tests, fuzz test edge cases, and run Slither and MythX to detect common issues automatically.

Hands-on lab

Follow the guided Remix demo: deploy VulnerableBank, deploy Attacker, observe the drain, then deploy SecureBank and verify the attack fails.

Key Takeaway

Combine patterns, tests, and tools — no single technique is sufficient on its own.
