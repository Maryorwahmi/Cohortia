Module 4 › Chapter 3.4 › Access Control & Visibility
Pattern
modifier onlyOwner() {
  require(msg.sender == owner, "Only owner can call this");
  _;
}

function sensitiveAction() public onlyOwner {
  // privileged logic
}
Concrete example

Protect all administrators and upgrade functions with role checks and include tests that call them from unauthorized addresses.

Common mistakes
  • Leaving functions public without guards because they appear unreachable.
  • Using tx.origin for authorization instead of msg.sender.
  • Failing to test negative cases for unauthorized callers.
Pro Tip

Adopt role-based libraries from trusted sources and write unit tests that attempt forbidden actions to ensure they revert cleanly.
