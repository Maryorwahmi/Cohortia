Warning
Integer overflow & underflow
Illustration
uint8 public x = 255;
function increment() public {
  x++; // prior to 0.8.0 this wraps to 0; in 0.8+ this reverts
}

Test these boundaries and be explicit about expected behavior on overflows.

Why it matters

Silent wrapping can be exploited to change balances or counters unexpectedly. Reverts on modern compilers add safety, but your logic must still handle possible errors.

Practical mitigation

Use Solidity 0.8+ checks, or explicit guarded arithmetic for older code; reason about value ranges and include tests for edge cases.
