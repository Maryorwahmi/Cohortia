Practice Plan
Short demos and a guided lab for each objective
File structure demo

Write a file with pragma solidity ^0.8.0 and a contract block. Compile and confirm the compiler version match prevents surprises.

Types demo

Declare uint, address, bool, enum, struct, array, mapping. Observe defaults and storage vs memory effects.

Scope demo

Use state and local variables and inspect msg.sender, msg.value, and block.timestamp during calls.

Operators demo

Try arithmetic, comparisons, and logical operations. Test integer division and an intentional overflow in a controlled way.
