Implementation notes
  • Use require(msg.sender == owner, "Only owner can set balances"); to restrict writes.
  • Update the mapping with userBalances[_user] = _amount; in setBalance.
  • Return userBalances[_user] in a public view getBalance function.
Testing checklist
  1. Deploy and confirm owner equals deployer address.
  2. Call setBalance as owner and verify getBalance returns the value.
  3. Call setBalance from another account and confirm the require blocks it.
Key Takeaway

This activity ties mappings, state, constructors, and access checks into a single practical contract suitable for quick tests.
