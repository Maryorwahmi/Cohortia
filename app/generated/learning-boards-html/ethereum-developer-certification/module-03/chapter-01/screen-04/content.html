Core Concept
Pragma and contract
Pin the compiler and encapsulate persistent state
Definition

The pragma declares which compiler versions are acceptable. The contract keyword creates a named container that stores state and functions. Together they form the file's execution boundary.

Common misconception

Assuming any compiler will work. Incompatible compiler versions can change semantics and break contracts unexpectedly.

Practical tip

Use a pragma range that matches your toolchain and test with the compiler version you plan to deploy with.

Key Takeaway

Pragma prevents accidental incompatibility; the contract is the persistent object you design and secure.

Example
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Example {
  address public owner;
  uint256 public counter;

  constructor() {
    owner = msg.sender;
    counter = 0;
  }
}
This example pins the compiler and defines a contract with persistent state: owner and counter. The constructor sets the deployer as owner using the global msg.sender.
