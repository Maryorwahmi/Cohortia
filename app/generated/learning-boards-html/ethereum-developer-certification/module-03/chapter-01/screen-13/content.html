Best Practice
Design & Pitfalls
Gas-aware storage

Minimize state writes; prefer local variables for transient computation and remove unnecessary stored fields.

Mappings vs arrays

Use mappings for O(1) lookups. If you need enumeration, maintain an index array but be aware of write-time costs.

Testing edge cases

Include tests for overflow, division by zero, and permission checks to detect logical errors early.

Concrete scenario

If you store a full user profile on-chain for each user, writes will be expensive. Store only what you need and consider off-chain storage for large blobs.

Key Takeaway

Good design balances correctness, gas cost, and clarity — choose types and storage deliberately and test extreme cases.
