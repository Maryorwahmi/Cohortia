Definition
Value Types
Directly stored, copied on assignment
Examples
  • bool — true or false
  • uint / int — unsigned or signed integers (default uint256)
  • address / bytes — address and fixed-size bytes types
  • enum — named finite set of constants
Behavior

Assigning copies the value. Value types are gas-efficient for small fixed-size data and predictable in memory.

Concrete example
uint256 public counter = 0;
bool public isActive = true;
enum Status { Pending, Approved, Rejected }
Status public currentStatus = Status.Pending;
address public owner;

These declarations create persistent slots on chain holding fixed-size values. Changing a local copy doesn't change the stored state unless you write back to it.

Common misconception

Confusing addresses with address payable. A plain address cannot receive Ether directly; address payable is required to transfer value.
