Operators in practice
function performCalculations(uint _a, uint _b) public pure returns (uint sum, uint product, bool isEqual) {
  uint localResult = _a + _b; // Local variable
  sum = localResult;
  product = _a * _b;
  isEqual = (_a == _b);
  // Note: integer division truncates. 5 / 2 = 2
  return (sum, product, isEqual);
}
Explanation
  • Addition and multiplication behave as expected for integers.
  • Division drops any fraction; use scaled integers for decimals.
  • Equality checks return boolean values used in require statements.
Practical note

To represent fractional values, use fixed-point techniques like storing cents or wei, not floating types.

Common Mistake

Expecting decimal division on uint types. This leads to incorrect financial calculations if not handled explicitly.
