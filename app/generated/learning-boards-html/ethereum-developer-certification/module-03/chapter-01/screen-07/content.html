Variable Scopes
Decide where data should live: state, local, or read from globals.
State variable example

uint256 public counter = 0; // persisted on chain and readable via an autogenerated getter

Local variable example

function add(uint a, uint b) public pure returns (uint) { uint result = a + b; return result; } // result exists only during execution

Globals you will use
  • msg.sender — caller's address
  • msg.value — Ether sent with the call
  • block.timestamp — current block time
  • gasleft() — remaining gas
Common Mistake

Putting transient computation into state variables increases gas costs and persists unnecessary data on-chain.
