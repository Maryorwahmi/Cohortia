Comparison
address vs address payable
Example
function sendEther(address payable _recipient) public payable {
  require(msg.value > 0, "Must send Ether");
  _recipient.transfer(msg.value);
}

// Assigning owner in constructor
owner = payable(msg.sender);

The example shows an address payable parameter used for transfer and the casting of msg.sender to address payable in the constructor.

Practical guidance
  • Use address payable where you will transfer Ether.
  • Keep plain address for identities that do not handle funds.
  • Cast with payable(...) when assigning from msg.sender or a plain address.
Common Mistake

Expecting transfer on a plain address to work. Always ensure the variable is address payable when performing transfers.
