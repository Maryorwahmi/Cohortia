Definition
Reference Types
Structs, arrays, and mappings reference storage addresses and require careful handling.
Struct example
struct Product {
  uint productId;
  string name;
  uint price;
  bool inStock;
}
Product public myProduct;

A struct groups related fields into a single type stored in contract storage.

Array and mapping examples
uint[] public productIds;       // dynamic array
mapping(address => uint) public balances; // mapping

Arrays provide ordered lists; mappings provide constant-time lookup but are not iterable by design.

Practical note

Use mappings for user balances and lookups. If you need to iterate, maintain a separate array of keys and consider gas costs for writes.

Common Mistake

Expecting mappings to be iterable. They are optimized for lookups, not enumeration.
