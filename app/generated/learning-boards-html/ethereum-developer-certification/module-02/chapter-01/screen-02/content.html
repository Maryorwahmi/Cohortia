Learning Objectives
Progress from install to running a local Hardhat node and interpreting compilation artifacts.
Learn → Understand → Apply → Master
01
Install & initialize Hardhat
Install Node and Hardhat, run npm init and npx hardhat to create a working project. Verified competency: run the init flow without errors.
Mnemonic: terminal → project.json → node_modules
VERIFIED COMPETENCY MILESTONE
02
Understand project layout and config
Identify contracts, scripts, test folders and how hardhat.config.js controls compiler and networks. Verified competency: explain a config entry for the compiler.
Mnemonic: folders = responsibilities
VERIFIED COMPETENCY MILESTONE
03
Compile and read artifacts
Run npx hardhat compile to produce ABI and bytecode artifacts and understand their purpose. Verified competency: locate ABI JSON for a compiled contract.
Mnemonic: code → compile → ABI
VERIFIED COMPETENCY MILESTONE
04
Run a local Hardhat Network
Start npx hardhat node, use pre-funded accounts for testing, and iterate rapidly. Verified competency: start the node and view listed accounts.
Mnemonic: local node = fast loops
VERIFIED COMPETENCY MILESTONE
