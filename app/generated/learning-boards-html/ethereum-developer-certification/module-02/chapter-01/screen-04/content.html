Module 2 › Chapter 2.1 › What is Hardhat?
Definition
Hardhat is a development environment for compiling, deploying, testing, and debugging smart contracts. It combines a compiler interface, task runner, plugin system, and a local blockchain.
Feature: built-in local blockchain for fast iteration
Feature: plugin ecosystem and ethers.js integration
Feature: deterministic accounts and easy scripting
Analogy
Hardhat is like a local test lab: you write code, run experiments instantly, and examine results without touching the public network.
Concrete example
Write a simple contract, run npx hardhat compile, and use the produced ABI to call functions from a script—no Ether required.
Key Takeaway

Hardhat accelerates iteration by combining compilation, local chain simulation, and test automation in one tool.
