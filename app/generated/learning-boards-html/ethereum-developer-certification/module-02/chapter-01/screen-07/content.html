Sample contract
This example demonstrates a basic contract with a constructor and a setter function. Compile it with npx hardhat compile.
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract MyContract {
  string public greeting;

  constructor(string memory _greeting) {
    greeting = _greeting;
  }

  function setGreeting(string memory _newGreeting) public {
    greeting = _newGreeting;
  }
}
Compile command
npx hardhat compile
Artifacts explained
  • ABI: JSON array describing functions and events for external interaction.
  • Bytecode: Deployable EVM machine code created by the compiler.
  • Location: artifacts/contracts/MyContract.sol/MyContract.json
Key Takeaway

Use the ABI to call contract functions and the bytecode to deploy—the artifacts bridge your source to the blockchain.
