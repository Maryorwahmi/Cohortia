Run the initializer
Example interactive call: npx hardhat init and choose the basic sample project to get started quickly.
npx hardhat init
# Choose: Create a basic sample project
# Files added: contracts/, scripts/, test/, hardhat.config.js
  • The sample project includes a sample contract and a test to compile and run immediately.
  • hardhat.config.js sets the compiler and can include plugins and network settings.
  • If you prefer a minimal start, choose an empty config and add files manually.
Directory snapshot
contracts/ — Solidity files like Lock.sol
scripts/ — deployment and interaction scripts
test/ — automated tests
hardhat.config.js — compiler and network settings
