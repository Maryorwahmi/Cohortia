Module 2 › Chapter 2.1 › Activity Walkthrough
Terminal sequence
mkdir my-first-hardhat-project && cd my-first-hardhat-project
npm init -y
npm install --save-dev hardhat
npx hardhat init   # choose basic sample project
npx hardhat compile
  • Confirm package.json includes hardhat under devDependencies.
  • Open artifacts/contracts to find the compiled contract JSON file.
  • Start npx hardhat node in a separate terminal to see accounts and interact with deployments.
Example verification
After compile, open artifacts/contracts/Lock.sol/Lock.json and locate the abi and bytecode properties to confirm success.
Key Takeaway

Follow the terminal steps and use the artifacts and node output as immediate verification points for a successful setup.
