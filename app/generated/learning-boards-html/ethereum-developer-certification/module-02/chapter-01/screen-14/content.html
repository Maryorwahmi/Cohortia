Module 2 › Chapter 2.1 › Key Concepts
Hardhat
A modular environment for compiling, testing, and running a local blockchain.
Artifacts
ABI and bytecode produced by compilation; they bridge code and the EVM.
Hardhat Network
A local ephemeral blockchain with pre-funded deterministic accounts for testing.
Summary
Master the install, init, compile, and node flow to iterate quickly. Use artifacts to deploy and test, and add plugins when you need more automation.
