Installation steps
Follow these shell commands to create a reproducible project.
mkdir my-first-hardhat-project
cd my-first-hardhat-project
npm init -y
npm install --save-dev hardhat
  • npm init creates package.json that records devDependencies.
  • Installing hardhat locally keeps the project self-contained.
  • Use npx to run Hardhat commands from the local node_modules folder.
Concrete example
After installation, package.json will include a devDependencies entry for hardhat. You can now run npx hardhat to initialize or compile.
Common mistake: skipping npm install or using a different package manager without verifying devDependencies.
Key Takeaway

Install Hardhat locally and confirm package.json lists it under devDependencies to ensure consistent behavior.
