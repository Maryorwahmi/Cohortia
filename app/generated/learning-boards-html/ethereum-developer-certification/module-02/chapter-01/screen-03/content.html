Hands-on verification points
Each milestone below maps to the activity steps so you can confirm success as you go.
01. package.json has hardhat
02. contracts/ contains sample contract
03. artifacts/ has Contract.json
04. hardhat node lists accounts
Tip
If compilation fails, check your solidity pragma matches the configured compiler version in hardhat.config.js.
Misconception
Pre-funded accounts are for local testing only and do not correspond to real mainnet funds.
Mnemonic
Init → Install → Compile → Node. Repeat for each new project.
