Start a local node
Run npx hardhat node to launch an in-memory blockchain and view pre-funded accounts.
npx hardhat node
# Output: Listing accounts with addresses and private keys
  • Transactions are processed instantly and the chain resets on restart.
  • Accounts are deterministic for reproducible tests.
  • Never use these keys outside a local development environment.
Practical scenario
Deploy your compiled contract using the provided first account. Confirm deployment by calling a read function like greeting to verify state. Repeatable because the node resets each run.
Warning

These accounts are for development only; do not treat printed private keys as secure credentials.
