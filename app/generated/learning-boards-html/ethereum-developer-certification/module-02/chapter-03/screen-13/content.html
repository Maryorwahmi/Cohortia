Activity Hands-on: MyContract
Steps
  1. Create test/MyContract.test.js from the example.
  2. Write tests for initial greeting and owner update.
  3. Run npx hardhat test and observe results.
  4. Add owner and onlyOwner in the contract and emit GreetingChanged.
  5. Uncomment or add revert and event tests, rerun until all pass.
Challenge goal
Modify MyContract so tests that assert revert for a non-owner and emission of GreetingChanged both pass. This validates both access control and observable signals for frontends.
Try this
After completing the challenge, consider how you would test a contract that manages token transfers and allowances — what additional edge cases would you add?
