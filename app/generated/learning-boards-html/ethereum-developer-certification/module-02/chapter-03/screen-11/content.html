Warning Common Mistakes
Forget await
Always await deployment and tx calls to avoid race conditions and false test passes.
Insufficient revert tests
Test that unauthorized actions fail with the expected revert message to ensure access control works.
Missing edge cases
Include zero, maximum, and empty inputs to catch boundary errors early.
Checklist
  • Await promises
  • Test success and failure paths
  • Include event and balance checks
  • Use fixtures for isolation
Pro tip
Use tests as documentation. If a test fails, it should tell you what contract behavior changed and why that matters.
