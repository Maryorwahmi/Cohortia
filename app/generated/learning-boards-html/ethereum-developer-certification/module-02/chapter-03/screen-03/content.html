Assessment checks
  • Confirm initial greeting equals expected string using expect equality.
  • Assert owner can update greeting and state persists after transaction.
  • Simulate non-owner and assert a revert with the expected revert message.
  • Use loadFixture and measure reduced test run time in repeated suites.
Mnemonic
Think: Arrange, Act, Assert. Arrange state with fixtures, Act by calling contract functions, Assert outcomes with Waffle matchers and Chai expectations.
