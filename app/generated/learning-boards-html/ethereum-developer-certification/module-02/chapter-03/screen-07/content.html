Module 3 › Chapter 2.3 › Fixtures and loadFixture
Fixture code (concept)
async function deployMyContractFixture() {
  [owner, addr1, addr2] = await ethers.getSigners();
  MyContract = await ethers.getContractFactory("MyContract");
  myContract = await MyContract.deploy("Initial Greeting");
  await myContract.deployed();
  return { myContract, owner, addr1, addr2 };
}

// In beforeEach:
({ myContract, owner, addr1, addr2 } = await loadFixture(deployMyContractFixture));
Notes & pitfalls
  • Run the fixture once per suite; loadFixture will reuse a saved snapshot.
  • Always reassign returned objects in beforeEach to avoid stale references.
  • Do not mutate global shared state outside the fixture; keep state local to the returned objects.
