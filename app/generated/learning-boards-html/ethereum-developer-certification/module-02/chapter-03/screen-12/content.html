Module 3 › Chapter 2.3 › Running tests
Command
$ npx hardhat test
Hardhat will compile if needed, launch a local in-memory network, and run Mocha tests. Read failing assertions and stack traces to locate the line and reason for failure.
Debugging steps
  1. Reproduce failing transaction in a small script or console.
  2. Inspect contract state before and after the call.
  3. Check signer addresses and awaited promises.
  4. Refactor test or contract as needed, then rerun.
