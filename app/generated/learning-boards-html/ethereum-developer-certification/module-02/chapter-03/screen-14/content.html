Performance Scaling tests with fixtures
Timeline
1. Run fixture to deploy contracts and prepare state.
2. Hardhat takes a snapshot of the network state.
3. For each test, loadFixture reverts to the snapshot and reassigns returned variables.
Create multiple fixtures for different starting scenarios. Use loadFixture for suites that share a heavy setup to save time and keep tests isolated.
Measure impact
Before: redeploy in every beforeEach. After: deploy once and snapshot. Expect large savings on suites with many tests.
