Module 3 › Chapter 2.3 › Organizing tests
Pattern
  1. describe to group related behavior
  2. beforeEach to prepare a clean starting state
  3. it for a single assertion or closely related assertions
Tip: Keep each it focused so failures point to a single cause.
Example hooks
beforeEach(async function () {
  ({ myContract, owner, addr1 } = await deployMyContractFixture());
});

it("Should set the right greeting", async function () {
  expect(await myContract.greeting()).to.equal("Initial Greeting");
});
