Module 3 › Chapter 2.3 › Hardhat + Mocha + Chai + Waffle
Stack components
  • Hardhat: local network, compilation, and ethers helpers.
  • Mocha: test runner to group suites and cases with describe and it.
  • Chai: expressive assertions like expect(value).to.equal(expected).
  • Waffle: Chai matchers for reverts, events, and balance changes.
Practical note

Use Waffle matchers for concise checks. For example, to assert a revert with a message, use the provided matcher rather than manual try-catch checks, which are more verbose and error-prone.
