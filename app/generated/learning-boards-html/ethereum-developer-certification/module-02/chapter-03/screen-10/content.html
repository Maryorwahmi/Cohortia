Module 3 › Chapter 2.3 › Testing events & balances
Event test pattern
await expect(myContract.connect(owner).setGreeting(newGreeting))
  .to.emit(myContract, "GreetingChanged")
  .withArgs(owner.address, newGreeting);
Ensure the event exists in the contract or update the contract and test together.
Balance change pattern
await expect(() => contract.connect(addr1).deposit({ value: parseEther("1.0") }))
  .to.changeEtherBalance(addr1, parseEther("-1.0"));
Always use the correct signer and await the transaction; parseEther helper gives consistent units.
