Module 3 › Chapter 2.3 › Why testing is critical
Definition

Testing smart contracts means validating both intended behavior and failure modes under controlled simulated blockchain state before any deployment.

Common misconception

Relying only on frontend tests or manual checks is insufficient because on-chain logic must be proven under isolated state and with precise assertions about reverts and events.

Example scenario
Test a greeting contract: verify greeting after deployment, test owner updates greeting, assert unauthorized updates revert. Also test edge cases like empty strings or very long input if the contract must handle them.
Key Takeaway

Design tests to protect assets and permissions. Always assert failure cases as well as success cases.
