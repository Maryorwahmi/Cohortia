Testing Smart Contracts with Hardhat and Waffle
An applied walkthrough: organize tests, assert behavior, use fixtures, and check reverts and events.
In this lesson

Learn Mocha/Chai basics in Hardhat, use Waffle matchers to assert reverts and events, and apply loadFixture for fast isolated test runs.

Why it matters

Because contracts are public and immutable, tests are your main defense against costly mistakes and security regressions.

Explore Key Topics
Test Structure
Use describe, it, and hooks for clear organization and repeatable setup.
Waffle Matchers
Assert reverts, events, and balance changes with concise matchers.
Fixtures & Performance
Snapshot once, revert between tests to keep speed and isolation.
Visual Concept
Think of your test suite as a safety net: fixtures take a snapshot, each test runs against a fresh copy, and matchers check expected outcomes like reverts or emitted events.
