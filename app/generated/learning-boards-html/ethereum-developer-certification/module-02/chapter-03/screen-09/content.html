Module 3 › Chapter 2.3 › Chai vs Waffle
Chai (value checks)
  • expect(value).to.equal(expected) — state or return values
  • Readable for plain unit assertions not tied to transaction metadata
Waffle matchers (transactional)
  • to.be.revertedWith — assert a revert with message
  • to.emit — assert an event and optionally its arguments
  • to.changeEtherBalance — assert Ether balance deltas
Example contrast
Prefer to.be.revertedWith for clear failure assertions instead of manual try-catch and checking error strings, which tends to be noisy and brittle.
