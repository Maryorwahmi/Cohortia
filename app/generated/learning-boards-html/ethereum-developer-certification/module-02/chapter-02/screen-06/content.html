Module 2 › Chapter 2.2 › Signers: authorizing state changes
What a Signer is

A Signer represents an account that can sign transactions. It is required to modify blockchain state.

Browser Signer
MetaMask injects a web signer that Ethers.js can use for user-initiated transactions.
Script Signer
A Wallet with a private key used in backend or Hardhat scripts to sign transactions programmatically.
Misconception
Calling a state-changing method returns a tx response, not the updated value. You must wait for the transaction to be mined to read the new state.
Concrete example

In a Hardhat script you often destructure the first signer: const [deployer] = await hre.ethers.getSigners(); then use deployer when deploying or sending transactions.

Key takeaway

Treat Signers as the entity that turns your intent into signed transactions; manage private keys securely and avoid hardcoding them.
