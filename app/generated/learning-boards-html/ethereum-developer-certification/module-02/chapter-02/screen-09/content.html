Module 2 › Chapter 2.2 › ContractFactory & Deploying
Steps to deploy
  1. Get ContractFactory: const MyContract = await hre.ethers.getContractFactory('MyContract');
  2. Get deployer: const [deployer] = await hre.ethers.getSigners();
  3. Deploy: const myContract = await MyContract.deploy('Hello');
  4. Await confirmation: await myContract.deployed(); then read myContract.address.
Warning
Omitting await myContract.deployed() may cause later calls to fail because the contract address is not yet confirmed on chain.
Example — initial greeting

Deploy MyContract with an initial message, then log the address. This address is used to construct Contract instances for later reads and writes.

// Deploy pattern (visual)
const MyContract = await hre.ethers.getContractFactory("MyContract");
const [deployer] = await hre.ethers.getSigners();
const myContract = await MyContract.deploy("Hello, Cohortia!");
await myContract.deployed();
console.log("MyContract deployed to:", myContract.address);
Key takeaway

Follow the factory → deploy → deployed pattern to obtain a confirmed deployed contract address for further interactions.
