Module 2 › Chapter 2.2 › View vs State-Changing Functions
View (read-only)

No gas, no signature required. Use smells like greeting(). Good for dashboards and frequent reads.

Example
const msg = await myContract.greeting(); // returns string immediately
State-changing (write)

Requires a Signer, costs gas, returns a transaction response that must be mined before state changes are visible.

Example
const tx = await myContract.setGreeting('Hi'); await tx.wait(); // wait for confirmation
Tip for UI
Show transaction pending state after sending a transaction and refresh view data only after tx.wait() completes to avoid showing stale state.
