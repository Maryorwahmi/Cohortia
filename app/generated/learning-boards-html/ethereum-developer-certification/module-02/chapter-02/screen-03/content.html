How you will prove your skill

Each objective includes a small verification step you can run locally.

Run
npx hardhat node and npx hardhat run scripts/deploy.js to observe terminal output.
Verify
Confirm the deployed address and printed greeting values before and after setGreeting.
Secure
Use env variables for keys and avoid hardcoding secrets in scripts.
Milestone check

Successful output shows deployer address, deployed contract address, initial greeting, and updated greeting after tx.wait() completes.
