Activity: Deploy and interact

Follow these steps in separate terminals as described to verify the full flow.

  1. Ensure contracts/MyContract.sol exists from the previous chapter.
  2. Compile: npx hardhat compile
  3. Start node: npx hardhat node
  4. Run script: npx hardhat run scripts/deploy.js
  5. Observe: deployer address, deployed address, greeting before and after setGreeting.
Challenge
Add another setGreeting call and verify the final greeting to practice chaining transactions.
Security
Never hardcode production private keys. Use env variables for secrets and local accounts for development.
Why it matters

Running the activity builds confidence in correct deployment and interaction patterns you will reuse in tests and front-end integrations.
