Module 2 › Chapter 2.2 › What is Ethers.js?
Definition & purpose

Ethers.js is a JavaScript library for interacting with Ethereum. It focuses on clarity and security for both scripts and browser-based dApps.

Provider
Read-only network interface to fetch blocks and call view functions.
Signer / Wallet
Holds keys or connects to MetaMask to sign transactions that change state.
Contract
An ABI-bound object that exposes contract functions as methods.
Key Takeaway

Ethers.js unifies reading and writing interactions using clear abstractions you will use throughout this chapter.

Concrete example

To show a greeting on a page you might create a Provider and a Contract. For a user action that updates the greeting, you would obtain a Signer and call the contract method which returns a transaction object to await.

Analogy
Provider = eyes, Signer = hands, Contract = appliance with buttons. Eyes can read the state; hands must press the buttons to change it.
Common mistake
Confusing a Provider for a Signer and attempting to send a transaction with no signing authority.
