Provider essentials

Providers let you call view functions and query network state without signing. They are ideal for dashboards and read-only scripts.

JsonRpcProvider
Connects to a local node such as Hardhat Network; useful for development and testing.
Infura / Public providers
Connect to public networks, but be aware of rate limits and configuration differences.
Misconception
A Provider cannot sign transactions. Attempting to submit a state change without a Signer will fail.
Example scenario

In a Hardhat script you can rely on the HRE-injected provider to call greeting() on your deployed contract. The call returns the string immediately and does not cost gas.

// Example: read-only call (conceptual)
const provider = hre.ethers.provider; // injected by Hardhat
const contract = new hre.ethers.Contract(address, abi, provider);
const message = await contract.greeting();
console.log(message);
Key takeaway

Use Providers for reads and the HRE provider during local scripting for convenience and correct network targeting.
