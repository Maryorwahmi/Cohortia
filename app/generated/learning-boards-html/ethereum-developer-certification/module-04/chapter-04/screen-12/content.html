Common mistakes
  • Insufficient testnet Ether in the deployer account.
  • Typing mistakes in RPC URL or private key.
  • Committing .env to version control.
  • Wrong or missing constructor arguments during verification.
  • Deploying to the wrong network (mainnet vs testnet).
Safety checklist
  1. Confirm deployer address and balance in logs.
  2. Keep .env in .gitignore and rotate keys if exposed.
  3. Use a minimal-fund deployer for testnets; hardware wallets for mainnet.
  4. Double-check --network before running deployment commands.
Urgent warning

Accidentally deploying to mainnet can have irreversible financial consequences; verify every step for production deployments.
