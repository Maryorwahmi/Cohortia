Module 5 › Chapter 4.4 › Verifying Contracts
Verification command
# Example verify command
npx hardhat verify --network sepolia 0xAbCd...1234 1000000

Include constructor arguments after the address in the same order and type used during deployment. If there are no constructor arguments, omit them.

Troubleshooting
  • Confirm solidity version and optimizer settings match your build.
  • Double-check constructor argument types and order.
  • Ensure ETHERSCAN_API_KEY is set in .env and referenced in hardhat.config.js.
Result

A successful verification shows source on the explorer and an interface to interact with contract functions publicly.
