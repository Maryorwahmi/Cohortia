.env example
# .env
SEPOLIA_RPC_URL="https://eth-sepolia.g.alchemy.com/v2/YOUR_ALCHEMY_KEY"
PRIVATE_KEY="YOUR_METAMASK_PRIVATE_KEY_HERE"
ETHERSCAN_API_KEY="YOUR_ETHERSCAN_API_KEY"
If exposed
  1. Move funds to a new account immediately.
  2. Rotate API keys and remove the file from repo history.
  3. Update .gitignore and future-proof your workflow.
Best practices
  • Use a dedicated deployer account with limited funds for testnets.
  • Validate that environment variables are present at runtime and fail with clear errors.
  • For mainnet deployments prefer hardware wallets or secure key management systems.
Pro tip

Log the deployer address and balance at the start of your script to confirm the correct account is used and funded.
