Module 5 › Chapter 4.4 › Running Deployment Commands
Common commands
# Local Hardhat Network
npx hardhat run scripts/deploy.js

# Sepolia testnet
npx hardhat run scripts/deploy.js --network sepolia
Checklist before running
  • SEPOLIA_RPC_URL and PRIVATE_KEY set in .env
  • Deployer funded with testnet Ether
  • Correct network specified with --network
Diagnostics

Inspect console logs for the deployer address, account balance, submitted transaction hash, and the final contract address. These values help you trace and verify the deployment flow.

Common error

Authentication or RPC errors often mean the RPC URL or private key is incorrect or the provider is rate-limiting requests.
