Module 5 › Chapter 4.4 › What Deploying a Contract Means
Definition

Deployment packages compiled bytecode into a signed transaction so the blockchain can create a contract account at an address.

Concrete Example

Deploying a Counter contract returns an address. You then call functions by sending transactions to that address.

Common Misconception

Deployment is not free or reversible on public networks. Treat deployed contracts as immutable artifacts.

Why it matters

Only deployed contracts can be used by end users and other contracts; deployment is the gateway to real usage and audits.

Key Takeaway

Deployment makes a contract addressable and permanent on the chosen network; choose your network carefully.

Annotated Flow
1
Compile
Solidity source to bytecode and ABI.
2
Create transaction
Include bytecode and constructor args in the deploy transaction.
3
Sign & send
Use private key to sign; network processes the transaction and assigns an address.
4
Confirm
After confirmations, the contract is live and callable at its address.
