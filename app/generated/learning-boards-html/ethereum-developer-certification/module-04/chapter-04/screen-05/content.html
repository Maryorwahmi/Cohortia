Module 5 › Chapter 4.4 › Local Development Networks
Why use a local network?

They are fast, resettable, and free, allowing rapid coding and testing without external dependencies.

Features
  • Instant mining and confirmations
  • Unlimited test Ether for accounts
  • Snapshot and reset capabilities
Example

Hardhat spins up an in-memory node when you run tests, letting you run thousands of transactions quickly.

Misconception

Local network performance and absence of external traffic can hide issues that appear on public testnets.

Key Takeaway

Start locally for speed and control, then stage on a public testnet to validate under real conditions.

Practical tips
Tip

Use snapshots to revert to a clean state between tests, ensuring deterministic test results.

Try this

Run npx hardhat node to run a local RPC that your frontend can connect to for integration testing.
