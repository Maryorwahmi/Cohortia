Practical Skills

These objectives help you run deployments with confidence and auditability.

Skill
Secure environment variable setup

Create a .env with RPC URL and private key, add .env to .gitignore to prevent leaks.

Skill
Confirm deployer funding

Log deployer address and balance in your script to avoid insufficient testnet Ether during deployment.

Skill
Run targeted deployments

Use npx hardhat run scripts/yourScript.js --network sepolia to move from local to public staging.

Skill
Verify deployed contracts

Use npx hardhat verify and include constructor arguments exactly as used during deployment to publish source.
