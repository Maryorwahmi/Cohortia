Deploy Wallet — Step checklist
  1. Create a .env with SEPOLIA_RPC_URL and PRIVATE_KEY and add .env to .gitignore.
  2. Fund your deployer address with Sepolia testnet Ether from a faucet.
  3. Update hardhat.config.js to read values from process.env and add sepolia network with chainId 11155111.
  4. Write scripts/deployWallet.js, log deployer address and balance, deploy Wallet, and await deployed.
  5. Run npx hardhat run scripts/deployWallet.js --network sepolia and copy the contract address.
  6. Verify: npx hardhat verify --network sepolia [constructor args].
Hint

If Wallet has no constructor args, omit them in the verify command. If it does, pass them in exact order and type.

Why this helps

Following the checklist reduces risk and makes results reproducible for reviewers and auditors.
