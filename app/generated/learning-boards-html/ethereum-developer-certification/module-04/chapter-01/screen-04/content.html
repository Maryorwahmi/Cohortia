Module 4 › Chapter 4.1 › Initialize Hardhat
Quick process
Step 1
npm init -y
Creates package.json for dev dependencies and scripts.
Step 2
npm install --save-dev hardhat
Installs Hardhat locally so the project is portable.
Step 3
npx hardhat
Choose Create a JavaScript or TypeScript project to scaffold contracts and tests.
Tip: keep Hardhat as a dev dependency to avoid environment mismatches between collaborators.
Terminal check
$ npm init -y
$ npm install --save-dev hardhat
$ npx hardhat
# select "Create a JavaScript project"
$ npx hardhat test
Expected output
Hardhat runs the test runner and reports zero or more passing tests. This confirms the environment is configured.
Key Takeaway

A reproducible Hardhat setup prevents environment issues and is the foundation for reliable tests.
