Common matchers
to.equal(value)
Asserts that a returned value equals the expected scalar or BigNumber converted in tests.
to.be.revertedWith(message)
Asserts a transaction reverts and optionally matches the revert message string to ensure specific guards triggered.
to.emit(contract, event)
Asserts that a transaction emitted a particular event. You can chain argument checks for event parameters.
Examples
// equality
expect(await counter.getCount()).to.equal(0);

// revert check
await expect(counter.decrement()).to.be.revertedWith("Count cannot go below zero");

// event check (example pattern)
// await expect(tx).to.emit(contract, "ValueChanged").withArgs(expected);
When writing tests, pick the matcher that best communicates the contract invariant you want to guarantee. Tests that mirror contract intent are easier to maintain and catch regressions earlier.
Key Takeaway

Matchers let your tests express contract intention—assert values, emitted events, and guarded failures explicitly.
