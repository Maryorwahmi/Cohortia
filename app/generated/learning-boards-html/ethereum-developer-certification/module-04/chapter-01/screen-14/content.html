Module 4 › Chapter 4.1 › Key Concepts
Hardhat
A development environment that compiles, deploys, and runs tests locally.
Waffle
Adds matchers to assert values, events, and revert messages in smart contract tests.
ethers.js
Library for deploying contracts, sending transactions, and managing signers in tests.
Summary: Use Hardhat for the environment, ethers for interactions, and Waffle for clear assertions. Practice these together with Counter and Wallet examples to build dependable test suites.
