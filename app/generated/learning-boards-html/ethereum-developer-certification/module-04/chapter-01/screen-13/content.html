Troubleshooting checklist
Check awaits
Ensure you await contract.deploy(), tx.wait(), and any function calls that change state before asserting results.
Verify signers
Use contract.connect(signer) to call functions from the intended account; incorrect signers can cause permission errors.
Confirm fresh state
Deploy in beforeEach to avoid test order dependencies and flakiness.
Match revert messages
If using to.be.revertedWith, ensure the string matches the contract's require message exactly.
When tests fail persistently, simplify the failing case into a single test that reproduces the issue. This helps identify whether the problem is the test, the contract, or the test environment. Over time you will recognize patterns and fix the root cause more quickly.
