Assessment snippet
Which matcher verifies a non-owner cannot call an owner-only function?
// Example answer pattern
await expect(
  myContract.connect(nonOwner).transferFunds(to, amount)
).to.be.revertedWith("Only owner can transfer");
This answer shows the key pieces: use getSigners to obtain nonOwner, connect the contract to that signer, and assert the call reverts with the expected message. That combination tests access control succinctly.
Key Takeaway

Tests that combine signers and revert matchers directly validate access control and improve contract safety.
