Pattern

Simulating actors with signers

// Example usage
const [owner, buyer, attacker] = await ethers.getSigners();
// Deploy as owner
// Transfer tokens from owner to sale contract
await token.connect(owner).transfer(tokenSale.address, supply);
// Buyer purchases
await tokenSale.connect(buyer).buyTokens({ value: purchaseValue });
// Unauthorized actor tries admin action
await expect(tokenSale.connect(attacker).adminOnlyAction()).to.be.revertedWith("Not authorized");
Explanation
  • Use getSigners() to obtain accounts for tests and assign them roles by name in the test scope.
  • Always call contract.connect(signer) to make a transaction originate from that signer.
  • Match signer.address in withArgs to assert event payloads precisely.
Pro Tip

Name signers in beforeEach for clarity: owner, buyer, seller, attacker. Clear naming reduces accidental signer mixups.
