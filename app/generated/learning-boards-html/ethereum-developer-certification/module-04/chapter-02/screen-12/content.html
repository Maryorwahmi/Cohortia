Common Mistake
Missing setup for token supply
Ensure TokenSale holds tokens or the tests transfer tokens during setup.
Not asserting events
Include to.emit and withArgs to validate the contract's external signals.
Wrong signer in calls
Use contract.connect(signer) to represent different actors accurately.
Remedies
  • Arrange state explicitly in beforeEach and document why transfers or approvals are necessary.
  • Assert events for all externally important actions so front-ends are protected.
  • Isolate time changes and always mine a block after increasing time.
  • Use Hardhat for iteration and a public testnet for final verification.
Key Takeaway

A short checklist fixes most advanced test failures: arrange state, assert events, use correct signers, and control chain time.
