Time manipulation example
const { network } = require("hardhat");

it("Should allow withdrawal after time lock", async function () {
  const ONE_DAY_IN_SECS = 24 * 60 * 60;
  await expect(lockContract.withdraw()).to.be.revertedWith("Lock not expired");

  await network.provider.send("evm_increaseTime", [ONE_DAY_IN_SECS + 1]);
  await network.provider.send("evm_mine");

  await expect(lockContract.withdraw()).to.not.be.reverted;
});
Explanation & pitfalls
  • evm_increaseTime changes the internal timestamp; evm_mine creates a block using that new time.
  • Always mine a block after increasing time; without mining, tests won't see the updated block timestamp.
  • Use precise second calculations and document the time constants in tests for readability.
Pro Tip

Encapsulate time helpers in a test util so tests read clearly: fastForward(seconds) wrapping both calls reduces mistakes.
