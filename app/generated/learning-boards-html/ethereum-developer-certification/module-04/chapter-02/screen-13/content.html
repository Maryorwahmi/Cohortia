Lab Steps
  1. Create contracts/ files from starter code and implement TokenSale.buyTokens as payable and emitting TokensPurchased.
  2. In beforeEach transfer a supply of tokens to tokenSale.address so purchases succeed.
  3. Write tests for successful purchase asserting event and balances.
  4. Add tests for insufficient tokens and insufficient Ether that assert reverts.
  5. Challenge: implement refund() in TokenSale with safety checks and write tests that verify it returns Ether and tokens safely.

Testing tips
  • Use BigNumber arithmetic and ethers.utils for conversions between Wei and token units.
  • Assert events for both purchase and refund actions if you add a refund event.
  • Keep tests atomic: each it block should test one behavior and arrange its own preconditions.
Pro Tip

Use Hardhat's network.provider.send to snapshot and revert state between complex steps if you need isolated checkpoints during the lab.
