Hardhat Features
  • Speed & Isolation: Each test run gets a fresh, fast chain.
  • console.log in Solidity: Print values from contracts to the test log for debugging.
  • Impersonation: Act as any address to simulate privileged operations.
  • State control: Increase time or mine blocks to test time-dependent logic.
Example: console.log

You can add console.log calls in Solidity and see their output in the Hardhat test terminal. This is especially helpful for complex revert reasons or intermediate values in multi-contract flows.

Misconception

Hardhat Network is not a perfect replica of a public testnet. It's a simulation optimized for reproducible logic testing; final tests on public testnets remain important.
