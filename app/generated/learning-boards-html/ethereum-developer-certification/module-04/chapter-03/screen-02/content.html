Learning Objectives
Skills you'll practice and why they matter.
Bloom: Learn → Understand → Apply → Master
01
Add runtime logs
Use Hardhat's console dot log to print inputs and intermediate values during test runs. This gives quick evidence of where logic diverges without changing test files.
VERIFIED COMPETENCY MILESTONE
02
Read traces & stacks
Interpret a transaction trace to see internal calls and the exact failing contract in a call chain. Stack traces show the function sequence at failure time.
VERIFIED COMPETENCY MILESTONE
03
Step through with debugger
Set breakpoints and inspect local variables and storage to see the exact state at each instruction during a transaction replay.
VERIFIED COMPETENCY MILESTONE
04
Measure gas usage
Run tests with a gas reporter to identify functions that cost the most gas and prioritize optimization for user savings.
