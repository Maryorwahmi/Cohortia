Module 4 › Chapter 4.3 › Hardhat Debugger
How to invoke
Insert a debugger statement in your test or run Hardhat in debug mode to replay a failing transaction and pause execution.
What you can inspect
  • Local variables and function arguments
  • Contract storage slots and mappings
  • Call stack and active frames
Practical tip
Use the debugger when you must inspect raw storage or verify that a computation produced an unexpected intermediate value, such as a Panic code from arithmetic.
Terminal command
npx hardhat test --network hardhat --debug
Misconception
Expecting IDE-like UX. The Hardhat debugger is command-line focused and reveals EVM-level state rather than a polished source-level inspector.
Key Takeaway

Use the debugger for deep inspection when logs and traces don't expose the root cause; it's best for storage and local variable checks.
