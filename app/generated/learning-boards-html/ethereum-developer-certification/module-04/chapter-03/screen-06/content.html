Module 4 › Chapter 4.3 › Using console.log to find a bug
Step-by-step process
Repeatable pattern to discover the root cause using console logs.
1. Reproduce
Run the failing test to confirm the revert and capture the message.
2. Log inputs
Add prints for sender, recipient, and amount to see what the function receives.
3. Log state
Print balances and any intermediate variables used in checks.
4. Interpret
Compare printed values with expectations to identify where logic diverges.
5. Fix & Verify
Implement the correction, run full tests, and enable gas reporting if relevant.
Concrete scenario
In VulnerableToken the require checks the recipient balance instead of the sender's. Printing balances shows the mismatch immediately and points to the line to change.
Key Takeaway

A short reproduce-log-interpret cycle usually reveals the misplaced condition quickly; keep logs focused and minimal.
