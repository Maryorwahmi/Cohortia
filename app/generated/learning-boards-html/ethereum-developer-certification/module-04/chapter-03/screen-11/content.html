Terminal-first walkthrough
Commands, expected outputs, and verification steps for the VulnerableToken lab.
Step
  1. Run npx hardhat test and confirm a failing transfer test.
  2. Edit the transfer function and add console prints for caller, recipient, and sender balance.
  3. Re-run tests and read printed values to see which balance is being compared.
  4. Fix the require to check the sender's balance, save, and run tests again.
  5. Run the full suite and enable gas reporting to verify cost.
Expected terminal snippet
Transfer initiated by: 0xAbc...
Transferring to: 0xDef... Amount: 50
Sender balance before: 100
Error: Insufficient sender balance
Verification
After the fix, the failing test passes and the terminal no longer shows the erroneous require. Run the gas reporter to check function costs.
Challenge
Find an off-by-one bug in a small helper contract using the same print-interpret-fix loop.
