Module 4 › Chapter 4.3 › Trace vs Stack
Transaction Trace
Shows all internal calls, value movements, and low-level operations performed during a transaction.
  • Useful across multi-contract interactions to locate which contract changed state.
  • Does not always show high-level variable names; pair with logs or debugger for clarity.
Stack Trace
Lists active function frames and the sequence of function calls at the point of failure.
  • Helps identify the source line and function where a revert was triggered.
  • Best when you already suspect a contract and need the exact failing frame.
Key Takeaway

Traces show the full call path. Stacks show the active function chain at failure. Use both together for multi-contract bugs.
