Module 07 › Chapter 7.1 › Key Concepts
STA is exhaustive
Mathematically checks all paths; use it with simulation for correctness plus timing safety.
Timing equation
T_clock ≥ T_co + T_logic + T_setup + T_skew; slack measures margin.
SDC constraints
create_clock, set_input_delay, set_output_delay, set_false_path, set_multicycle_path.
Summary takeaway: express realistic clocks and I/O timing, run STA, inspect slack and critical paths, then iterate on RTL or constraints until timing is clean.
