Module 07 › Chapter 7.1 › Clock Skew
What is clock skew?
The difference in clock edge arrival times between registers due to routing or distribution network variation.
Effects
  • Positive skew reduces available time, hurting setup checks.
  • Negative skew can reduce hold margin, creating hold risks.
Clock uncertainty
Timing jitter and other non-deterministic effects modeled with set_clock_uncertainty to add margin to setup checks.
Example

Using set_clock_uncertainty -setup 0.200 models 0.2 ns uncertainty that reduces reported slack and encourages safer timing decisions.

Pro tip
Include clock uncertainty conservatively early, then tune once silicon or implementation timing is measured.
Why it matters
Without skew and uncertainty, timing reports can be overly optimistic and miss real failures.
Check
If slack is marginal, inspect skew values in the timing report before deciding on fixes.
