Module 07 › Chapter 7.1 › Timing Equation
The equation
T_clock ≥ T_co + T_logic + T_setup + T_skew
Components explained
  • T_co — clock-to-Q delay of the launching flip-flop.
  • T_logic — combinational propagation through LUTs and routing.
  • T_setup — data stable before the capture clock edge.
  • T_skew — clock arrival differences between registers.
Slack = Data Required Time − Data Arrival Time
Worked example
Target clock: 50 MHz → T_clock = 20 ns. If T_co = 0.2 ns, T_setup = 0.1 ns and T_logic = 15 ns, then required = 0.2 + 15 + 0.1 = 15.3 ns. Slack = 20 − 15.3 = 4.7 ns (positive).
Check your thinking
Try this

If a path reports −2 ns slack, what must you change: reduce T_logic, reduce skew, or increase T_clock? Consider which is feasible for your design.

Misconception
Treating T_co as negligible. Even small flip-flop delays matter when pushing frequency.
Pro tip
Estimate worst-case path with the equation before running timing tools to guide where to optimize.
Why it matters
The equation directly gives maximum clock frequency and informs pipelining decisions.
