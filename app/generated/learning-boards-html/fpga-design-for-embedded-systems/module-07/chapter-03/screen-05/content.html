Module 8 › Chapter 7.3 › Pipelined Multiplier
Code example (multi-stage pipelined multiplier)
<module> pipelined_multiplier (
    input  wire        clk,
    input  wire [15:0] a, b,
    output reg  [31:0] product
);
    reg [15:0] a_reg, b_reg;
    reg [31:0] partial1, partial2;

    always @(posedge clk) begin
        // Stage 1: Register inputs
        a_reg <= a;
        b_reg <= b;

        // Stage 2: Partial product
        partial1 <= a_reg * b_reg;

        // Stage 3: Intermediate buffer
        partial2 <= partial1;

        // Stage 4: Output register
        product <= partial2;
    end
endmodule
Note: escape characters shown for clarity; in actual Verilog use the normal symbols. Use non-blocking assignments to move data forward on clock edges.
Example explanation
Inputs are captured in stage 1 so combinational multiply is between registers. Each subsequent stage buffers results until the final output register presents the product after pipeline latency.
Trade-offs and checks
  • Latency increases in cycles; calculate latency = number of stages.
  • Throughput becomes one result per clock after pipeline fill.
  • Measure routing delay — it can dominate a stage and require rebalancing.
Common mistake
Placing registers without balancing stage delay can leave one slow stage that still limits fmax. Use retiming and further decomposition when needed.
Key Takeaway

Implement pipelines with balanced stages and verify timing reports; registers move data while enabling higher clocks.
