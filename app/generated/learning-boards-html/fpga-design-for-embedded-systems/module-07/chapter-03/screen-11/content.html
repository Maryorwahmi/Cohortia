Module 8 › Chapter 7.3 › Other Optimization Techniques
State encoding
One-hot reduces next-state logic complexity using more flip-flops and often gives faster state machines when FSM size is small. Binary/Gray use fewer flip-flops but increase combinational logic.
Logic duplication
Duplicate high-fanout nets near sinks to reduce routing delay. It consumes extra logic but can resolve timing for congested routes.
Physical synthesis
Tool-driven netlist changes during place-and-route can reduce timing issues that appear only after routing congestion is known.
Memory inference
Use clocked array patterns so the tool implements BRAM blocks instead of LUT RAM, saving logic and improving access performance.
Practical guidance
Pick the technique that directly addresses the bottleneck identified in timing or resource reports. Combine methods judiciously and re-measure after each change.
