Module 8 › Chapter 7.3 › Design Constraints
Constraint types
  • Clock frequency targets — tell the tool your desired period.
  • Multicycle paths — declare paths that can take multiple cycles.
  • False path or max delay constraints — exclude or bound paths not used for timing.
Practical tip
Set realistic clock targets and add multicycle paths where system timing allows it. This prevents the tool from wasting effort on unimportant paths.
Example workflow
  1. Run synthesis and identify critical timing paths.
  2. Decide which paths require single-cycle timing.
  3. Add clock and multicycle constraints accordingly and resynthesize.
Warning
Over-constraining can harm optimization. Use precise, minimal constraints and iterate with timing reports.
Key Takeaway

Constraints are instructions for the tool. Use them to express real timing intent and let the synthesizer focus on meaningful improvements.
