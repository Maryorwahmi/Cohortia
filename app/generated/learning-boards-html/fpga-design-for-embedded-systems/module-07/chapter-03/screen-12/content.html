Module 8 › Chapter 7.3 › Pipeline Lab
Step-by-step lab plan
  1. Synthesize and simulate baseline combinational 16-bit adder; record fmax and resources.
  2. Design a 4-stage pipeline: split adder logic, add registers, and implement stage transfers.
  3. Synthesize pipelined design, record fmax, resources, and latency in cycles.
  4. Compare throughput: results per second = fmax / cycles per result after pipeline fill.
  5. Write a report with code, tables, and analysis of trade-offs.
Measurement checklist
Collect resource counts (LEs, DSPs, BRAMs), fmax, latency in cycles, and simulated throughput for both designs.
Example report items
  • Verilog code for baseline and pipelined versions.
  • Resource usage table and timing comparison with fmax values.
  • Latency and throughput calculation: cycles per result and results per second.
Common pitfall
Assuming pipelining will always reduce power. More registers and higher clock frequency can increase dynamic power; include power estimates in your report if possible.
Key Takeaway

This lab combines design, synthesis, and measurement to practice trade-off decisions and reporting for optimization tasks.
