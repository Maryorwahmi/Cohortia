Module 8 › Chapter 7.3 › Stage Balancing & Retiming
Step-by-step: balance stages
  1. Estimate delay for each combinational block in the path.
  2. Group logic into stages with similar summed delay.
  3. Insert registers between stages and re-synthesize to measure fmax.
  4. If a stage remains slow, consider retiming or further decomposition.
Misconception
Simply adding registers can make routing delay the dominant bottleneck. Always verify with post-route timing to ensure real-world stage balance.
What retiming does
Retiming moves registers across combinational nodes to reduce the maximum combinational delay in any stage. It keeps functional behavior but can change where values are sampled. Tools like Quartus have a "Perform gate-level register retiming" option to enable this automatic step during synthesis.
Quick checklist
  • Measure stage delays in timing reports.
  • Try logical splitting where routing is light.
  • Enable retiming if tool supports it and verify functional sampling points.
Key Takeaway

Balancing and retiming are complementary: balance logic first, then use retiming to fix physical imbalances exposed after routing.
