Practical steps
  1. Identify bottleneck from timing report.
  2. Pick one targeted optimization and apply it.
  3. Synthesize, measure, and record changes.
  4. If unresolved, try the next targeted technique.
Key Takeaway

Iterative, measured changes produce reliable optimization results; avoid simultaneous large changes that obscure cause and effect.
