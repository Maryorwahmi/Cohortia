Two-FF synchronizer module

A minimal synthesizable module that you can drop into the destination domain.

module synchronizer (
  input  wire clk_dest,    // Destination clock domain
  input  wire async_in,    // Asynchronous input
  output wire sync_out     // Synchronized output
);
  reg sync_ff1, sync_ff2;

  always @(posedge clk_dest) begin
    sync_ff1 <= async_in;
    sync_ff2 <= sync_ff1;
  end

  assign sync_out = sync_ff2;
endmodule
Simulation advice
Randomize the async toggle time relative to clk_dest to stress the synchronizer and inspect the waveform for any unstable samples.
Synthesis note
Ensure synthesis does not optimize away the chain; keep the registers visible to the tools and constrain timing if needed.
Example
Drive async_in with a toggle generator that flips at random times; observe sync_out stable after two destination clock edges.
Misconception
This does not guarantee zero probability of failure; it reduces the probability to a small number determined by device characteristics and clock rate.
Key Takeaway

Use the two-FF module as a standard building block for single-bit asynchronous inputs in destination clock domains.
