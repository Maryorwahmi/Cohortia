Pattern

Request / Acknowledge

Sender asserts request when data is valid. Receiver synchronizes, captures data, then asserts acknowledge. Sender waits for acknowledge before changing data.

• Synchronize control lines with two-FF chains.
• Data remains stable until handshake completes, preserving coherence.
• Best for low-rate or control transfers where latency is acceptable.
Example
A configuration register write from a slow control CPU to a faster datapath: CPU asserts request and holds value; datapath acknowledges after capture.
Practical note
Handshakes simplify reasoning and formal checks but may constrain throughput; pick FIFO if high throughput and buffering are required.
