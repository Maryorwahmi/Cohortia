In this lesson

We will define metastability, walk through synchronizer patterns, explore single-bit versus multi-bit crossings, and cover Gray code, FIFOs, and handshakes used in FPGA CDC problems.

Coming up

Quick takeaway

Treat every asynchronous crossing as a potential metastability source and use a verified synchronization strategy matched to the signal width and timing needs.

Explore Key Topics
Metastability
A flip-flop can be driven into an undefined output when sampling an input that changes near the clock edge.
Single-bit synchronizers
Two-flip-flop chains dramatically reduce the chance a metastable state propagates into logic.
Multi-bit transfers
Use Gray code, FIFOs, or handshakes to keep wide data coherent across clock boundaries.
