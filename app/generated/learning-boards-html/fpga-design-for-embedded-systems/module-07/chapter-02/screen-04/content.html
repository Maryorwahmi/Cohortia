Module 7 › Chapter 7.2 › What is Metastability?
Definition

Metastability explained

When a flip-flop samples a changing input during its timing window, it may produce an indeterminate output voltage that resolves unpredictably. This is a fundamental sampling artifact.

Concrete example
A button toggled near a clock edge can cause the sampled output to hover; if downstream logic reads it immediately, the system may behave incorrectly.
Common misconception
Metastability can be made arbitrarily rare but not eliminated. Slowing clocks or adding delay does not guarantee safety.
Why it matters
Unresolved metastability can propagate errors, cause state machine corruption, or create intermittent, hard-to-reproduce failures in FPGA systems.
Analogy

Ball-on-ridge metaphor

Imagine a ball balanced on a ridge between two valleys. A tiny difference determines which valley it falls into, and the time to fall is variable. That uncertainty mirrors a flip-flop in a metastable state.

Key Takeaway

Always assume asynchronous inputs can cause metastability and plan for resynchronization before using the signal.
