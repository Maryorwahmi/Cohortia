Module 7 › Chapter 7.2 › CDC Verification

Find and fix CDC violations

Run static CDC analysis and stress simulations. Treat tool warnings as actionable design items to inspect and resolve.

Static CDC tools
Tools flag unsynchronized crossings for review. Use reports to prioritize fixes.
Directed simulation
Randomize toggle timing, run multiple seeds, and inspect waveforms to see metastability resolve or fail.
Fix patterns
Add synchronizers, use FIFO/handshake redesigns, or document safe exceptions with constraints.
Common pitfall

Assuming clock phases or placement will always align; placement, routing, and post-fit timing can change relative arrival times and reintroduce issues.
