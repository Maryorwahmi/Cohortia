Identify CDC

Map clocks and crossings

List all clock domains, then enumerate signals crossing between them. Flag single-bit and multi-bit crossings for different handling.

• Peripheral interrupts to CPU domain — single-bit flag.
• Pixel or audio buses between controllers — multi-bit data.
• External asynchronous events like buttons or sensors — treat as asynchronous inputs.
Why it matters

Unsynchronized crossings can cause intermittent, data-corrupting failures that are timing dependent and hard to reproduce. Proper CDC handling prevents these failures.

Checklist
Map domains, mark crossings, pick patterns (sync, FIFO, handshake), simulate, and run CDC analysis tools.
