Module 7 › Chapter 7.2 › Gray Code Counters
Definition

Gray code for counters

Encode the counter so only one bit flips per increment. Synchronize each Gray bit and decode back to binary at the destination.

Example
A 4-bit counter sequence like 0111 → 1000 in binary is multiple-bit change. In Gray code the same step changes only one bit, avoiding inconsistent samples.
Workflow
  1. Generate counter in source domain as Gray code.
  2. Synchronize each Gray bit with two-FF synchronizers in destination domain.
  3. Convert synchronized Gray code back to binary in destination domain.
When to use
Best for counters and indices where single-bit transitions preserve correctness. Not suitable for arbitrary simultaneous multi-bit data updates.
