Module 7 › Chapter 7.2 › Dual-Clock FIFO
Architecture

Write side / Read side isolation

Writes happen under the source clock and reads under the destination clock. Memory banks do not require per-bit synchronization; instead pointers are synchronized across domains.

• Use Gray code for pointers to avoid multi-bit pointer metastability.
• Synchronize read pointer to write side and write pointer to read side using two-FFs.
• Protect empty/full flags with synchronized copies.
Example
A video frame producer running at one clock writes pixel blocks into a FIFO while a display controller running at another clock reads them at its own rate, preserving order and preventing tearing due to partial words.
Design tip
Choose FIFO depth based on worst-case burst sizes and clock rate differences; test pointer wrap-around and full/empty corner cases in simulation.
