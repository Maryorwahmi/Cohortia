Module 7 › Chapter 7.2 › Single-bit vs Multi-bit
Single-bit

Flags, interrupts, enables

Use two-FF synchronizers. Receiver sees either old or new value with predictable latency. Low hardware cost and minimal complexity.

Multi-bit

Buses, counters, data words

Avoid simple per-bit synchronizers. Without word-level coordination, the receiver can see inconsistent values that never existed in the source.

Solutions at a glance
Gray Code
Good for counters; only one bit changes per increment so single-bit sync suffices.
Dual-clock FIFO
Stores full words and synchronizes pointers, preserving order and coherence for streams.
Handshake
Request/acknowledge ensures sender holds data until the receiver accepts it, at low hardware cost but slower throughput.
