Module 7 › Chapter 7.2 › Hands-on Lab

Lab steps

  1. Write two-FF synchronizer module and 4-bit Gray counter in source domain.
  2. Create testbench: Gray counter at 50 MHz, sampling domain at 100 MHz.
  3. Randomize phase of the Gray counter to stress metastability and capture waveforms.
  4. Decode synchronized Gray to binary and compare against expected sequence with latency accounted for.
  5. Implement a small dual-clock FIFO and test burst write/read, pointer sync, and full/empty conditions.
  6. Run CDC analysis and resolve any reported violations.
Expected result
Synchronized Gray values show only single-bit changes and decoded binary matches source after synchronization latency.
Verification evidence
Waveforms, CSV of decoded counts, and CDC tool reports document correctness.
