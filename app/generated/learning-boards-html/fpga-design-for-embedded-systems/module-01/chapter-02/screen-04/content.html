Module 1 › Chapter 1.2 › Microcontrollers
Definition

Small, integrated computers for control

They combine CPU, flash, RAM and I/O to run software for sensing, actuation and simple user interfaces.

  • • Very low per-unit cost and short development cycles.
  • • Ideal for sensor reading, display driving, and motor control.
  • • Not designed for massive parallel data paths or cycle-exact hardware pipelines.
Key Takeaway

Use microcontrollers when cost and simple control logic dominate and hardware parallelism is not required.

Concrete Example
Arduino-style sensor controller

A small board reading temperature, updating a display, and sounding a buzzer. Low cost and fast to iterate in software.

Common Mistake

Believing a faster CPU can match FPGA parallelism. Software runs sequentially on cores and cannot reproduce many true simultaneous hardware paths.

Try this

If your design needs fewer than a handful of control tasks and low I/O throughput, prototype on a microcontroller for quick results.
