Module 1 › Chapter 1.2 › CPLDs
Definition

Small, non-volatile programmable logic

Simpler interconnect and flash configuration make CPLDs suited to glue logic and functions that must be ready immediately at power-on.

  • • Deterministic pin-to-pin delays for reliable startup behavior.
  • • Lower gate density than FPGAs; cost-effective for small designs.
  • • Typical uses: address decoding, bus arbitration, power sequencing.
Key Takeaway

Use a CPLD for small, instant-on hardware control where predictable timing is required.

Concrete Example
GAL16V8 decoding and enable logic

Use a CPLD to decode address ranges and drive chip select lines that must behave correctly at power-up without configuration delay.

Misconception

Assuming a CPLD is simply a tiny FPGA. Instead, treat it as deterministic glue logic with non-volatile configuration rather than a high-density programmable fabric.

Try this

If your design needs instant-on behavior and less than a thousand gates, evaluate a CPLD before moving to FPGA complexity.
