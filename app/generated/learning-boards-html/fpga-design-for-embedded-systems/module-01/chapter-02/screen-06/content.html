Module 1 › Chapter 1.2 › FPGAs
Core Concept

Reconfigurable fabric for parallel hardware

You implement custom logic networks and pipelines that run in parallel and deliver deterministic hardware timing.

  • • High flexibility and logic capacity for algorithm prototyping.
  • • Faster time-to-market and lower upfront NRE than ASICs.
  • • Higher per-unit cost and often higher power than ASICs.
Key Takeaway

Choose FPGAs for rapid algorithm changes and hardware parallelism when NRE must stay low and iteration speed is key.

Concrete Example
Camera image processor prototype

An FPGA prototype allows weekly algorithm updates during development before committing to expensive silicon masks.

Common Mistake

Thinking FPGA equals slow. Often FPGAs outperform sequential software due to parallel pipelines, but they usually cannot match ASIC power efficiency in high volumes.

Pro Tip

Prototype on FPGA to validate algorithms, then evaluate ASIC migration when production volumes and fixed requirements justify NRE.
