Module 2 › Chapter 1.3 › High-Level Synthesis and Design Flow Changes
Concept

HLS shifts abstraction upward

HLS compiles higher-level algorithmic descriptions into hardware implementations, enabling faster development of compute kernels that use DSPs and block RAMs.

Example flow
  1. 1. Describe the algorithm in a C-like style, emphasizing streaming and loops.
  2. 2. Apply pragmas to direct unrolling, pipelining, and resource mapping.
  3. 3. Compile with HLS to generate RTL and map to DSP and memory blocks.
Concrete example

An FIR filter described in high-level code can be compiled into pipelined multiply-accumulate stages that map to DSP blocks and block RAM buffers.

Misconception
HLS makes hardware optimal automatically. In reality, HLS needs designer guidance to meet tight area or timing goals.
Key Takeaway

Use HLS to raise productivity for algorithmic kernels, but keep fabric resource budgets and manual optimizations in mind for best results.
