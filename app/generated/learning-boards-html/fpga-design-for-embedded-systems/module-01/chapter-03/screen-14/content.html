Module 2 › Chapter 1.3 › Key Concepts
Lineage
PROM → PAL → CPLD → FPGA: each step improved efficiency, reprogrammability or routing flexibility.
FPGA Insight
Ross Freeman’s array plus routing model enabled scalable, general-purpose reconfigurable hardware.
Generations
From LUTs to embedded memory, DSP, hard processors and AI accelerators—vendors added capabilities across generations.
Summary Takeaway

Know the lineage, the FPGA routing insight, and how generations map to capabilities. Those three guide effective device selection and architecture trade-offs.
