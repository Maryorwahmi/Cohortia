Process Flow

EEPROM-based reprogrammability

Altera’s CPLDs used erasable programmable interconnects so chips could be updated electrically. This delivered stable, non-volatile configuration useful for control tasks and production hardware.

• Non-volatile configuration avoids external boot memories.
• Predictable startup behavior suits power controllers and sequencers.
• Macrocells and grouped logic simplify timing analysis.
Concrete example
Use a CPLD for a board’s reset and power sequencing so the control logic is present immediately at power-up without external configuration steps.
Comparison
CPLD: non-volatile, deterministic interconnect. Early FPGA: volatile configuration, flexible routing and scalable CLB arrays. Choose CPLD for stable control logic; choose FPGA for flexible, high-density logic and heavy parallelism.
Common mistake
Treating CPLDs as miniature FPGAs. Their architecture and use cases differ: CPLDs prioritize startup stability and simpler interconnects.
Key Takeaway

CPLDs filled the practical niche of non-volatile, reprogrammable glue logic before FPGAs became dense and connected enough to subsume many roles.
