Module 2 › Chapter 1.3 › Xilinx and the FPGA Breakthrough
Core Idea

Two-dimensional CLB array + routing

The FPGA decoupled function mapping from fixed tables by offering many small logic blocks and a programmable routing fabric connecting neighbors. This allowed general reconfiguration and parallel placements of logic.

• XC2064 was the first Xilinx FPGA with 64 configurable logic blocks on a 2.5 µm process.
• Routing fabric provides arbitrary local interconnects and scalability.
• Enables design reuse and spatial parallelism for signal processing.
Example
Map a small FIR filter across nearby CLBs to implement a pipeline; the routing fabric connects taps without fixed truth-table growth.
Misconception

Do not view FPGAs as merely larger PALs. The routing concept makes them general spatial computing fabrics, not just bigger programmable gates.

Why engineers care
Routing plus CLBs lets designers trade place-and-route decisions for algorithmic parallelism and reusability across projects.
