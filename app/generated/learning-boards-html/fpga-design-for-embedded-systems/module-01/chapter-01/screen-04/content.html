FPGA structural components
An FPGA fabric contains three building blocks that determine capability and design choices.
Programmable Logic Blocks
Implement lookup tables, flip-flops, and small memories used to build combinational and sequential logic.
Routing Network
Configurable interconnects that connect logic blocks into larger functional units.
I/O Cells
Programmable pins for interfacing with sensors, converters, and external buses.
Concrete example
Imagine configuring a data-path that multiplies and accumulates signals for a filter. The logic blocks implement the multiply-add units, routing wires connect these units into a pipeline, and I/O cells bring sample data in and out. Load the bitstream and the FPGA functions like a hardware filter.
Key takeaway: Hardware-as-configuration leads to parallel, low-latency operation.
Common mistake: Treating FPGA code like sequential software leads to incorrect expectations about debugging and performance.
