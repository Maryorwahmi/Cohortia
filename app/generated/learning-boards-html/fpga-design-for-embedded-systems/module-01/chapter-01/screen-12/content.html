Processor approach
Software loops, reused arithmetic units, dependent on memory and cache. Latency and throughput vary with load and scheduling.
Concrete scenario: a single-threaded FFT loop iterates across samples using a few ALUs and memory reads.
FPGA approach
Pipelined butterflies and dedicated multipliers stream data so the design can emit a transform result every clock cycle after pipeline fill.
Example card: 1,024-point FFT implemented as hardware pipeline yields steady high throughput with deterministic latency.
Takeaway
Choose an FPGA when consistent streaming throughput and deterministic latency for transforms matter more than development simplicity or lowest unit power.
