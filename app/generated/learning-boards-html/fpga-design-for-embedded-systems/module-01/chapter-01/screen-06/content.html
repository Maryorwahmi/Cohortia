Design steps
  1. Design: Describe hardware with HDL or high-level tools.
  2. Synthesis: Convert behavior into logic elements and registers.
  3. Place & Route: Assign elements and route signals for timing.
  4. Bitstream: Generate the configuration file to program the FPGA.
Pro-tip: Early timing constraints guide placement and reduce later iterations.
Concrete example
If you design a pipelined multiplier, synthesis decides how many lookup tables are needed, place-and-route determines where those LUTs sit relative to routing channels, and timing analysis shows whether your pipeline meets the clock rate. If not, you adjust registers or pipeline depth and iterate.
Key takeaway: Toolflow reveals hardware trade-offs; iteration reduces timing violations.
Common mistake: Expecting software-style debugging to find timing errors instead of inspecting timing reports.
