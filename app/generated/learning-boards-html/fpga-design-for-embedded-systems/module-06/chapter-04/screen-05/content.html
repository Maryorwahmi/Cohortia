Module 7 › Chapter 6.4 › ModelSim Overview
ModelSim‑Intel FPGA
Advanced simulator for Verilog and VHDL with breakpoints, signal tracing, and coverage.
Waveform tools
Zoom, measure time between edges, change radix, and save waveform layouts for reuse.
Breakpoints
Pause simulation at a code location to inspect variables and step through actions.
Transcript
See $display and $monitor output from testbenches to log behavior during runs.
Coverage & tracing
Collect code coverage to measure verification completeness and find untested branches.
Concrete example
A self‑checking Verilog testbench can assert conditions and print a pass/fail line in the transcript; ModelSim captures that output and lets you pause where failures occur.
Key Takeaway

ModelSim is the tool for automated, deep verification and debugging across languages and mixed designs.

Quick tips
  • Add important internal signals to the waveform early so you can inspect them after each run.
  • Save waveform setups as a .do file to reproduce the same view on future runs.
  • Use $display or $monitor in your testbench to provide human‑readable traces in the Transcript window.
