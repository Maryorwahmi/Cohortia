Module 7 › Chapter 6.4 › Waveform Viewer
Waveform capabilities
Zoom & Cursors
Zoom in to a transition, place two cursors, and read the time delta to quantify latency.
Radix control
Right‑click a signal to change display to decimal, hex, or binary for easier interpretation.
Grouping
Group related signals into a bus to reduce clutter while keeping logical relationships visible.
Save layout
Save waveform configurations as a .do so the same view can be restored for future runs or by teammates.
Concrete example

Add the state register and output signal for the sequence detector. Set state to binary, output to decimal, zoom to the cycle where detection happens, and measure the time between input arrival and output assertion.

Common mistake
Adding every internal signal produces clutter. Instead group and save a focused layout for the specific check you're performing.
Key Takeaway

Use measurement and radix tools to turn visual inspection into quantitative verification steps you can reproduce.
