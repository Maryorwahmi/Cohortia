Module 7 › Chapter 6.4 › Launch ModelSim
Step-by-step
  1. Add your testbench file to the Quartus project so it is part of the compile context.
  2. Open Assignments → Settings → EDA Tool Settings → Simulation and set the tool to ModelSim‑Intel FPGA.
  3. Choose Verilog or VHDL as the format based on your sources.
  4. Use Tools → Run Simulation Tool → RTL Simulation. Quartus compiles and launches ModelSim automatically.
Pro Tip

Keep testbenches in the project so the compile order remains consistent across runs and between team members.

Visual checklist
Compile success
Quartus compiles and ModelSim will show compiled units in the Objects window.
Testbench loaded
Confirm the testbench appears and you can drag signals into the waveform viewer.
Common mistake
Forgetting to add the testbench to the project or selecting the wrong HDL format prevents ModelSim from compiling the testbench correctly.
