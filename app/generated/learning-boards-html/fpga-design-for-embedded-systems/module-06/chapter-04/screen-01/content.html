Simulation with ModelSim and Quartus Prime
Validate design behavior before programming the FPGA and choose the right simulator for the task.

Simulation saves debugging hours by letting you inspect internal signals, measure timing, and verify state transitions without hardware.

ModelSim is the full tool for self‑checking testbenches and coverage. The Quartus Simulator is faster for quick checks and uses the Vector Waveform File editor for manual input waveforms.

In this lesson
Launch ModelSim, use waveforms, debug with breakpoints, and run VWF checks.
