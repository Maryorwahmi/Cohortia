Example .do snippets
Use these commands to control simulation timing and reproduce the same waveform view.
# Example do file commands (ModelSim)
# run until testbench completes
run -all

# or run for a measured time
run 1000 ns

# You can also use $display in the testbench to print to the Transcript window
Why script runs?

Scripts make runs repeatable, ensure the same signals and radix settings are loaded, and allow regression suites to execute identical checks without manual steps.

Practical example
After confirming correct state transitions for the sequence detector, save the waveform layout and include a run 1000 ns line in your .do so anyone can reproduce the exact check.
Key Takeaway

Automate runs with .do files to make verification repeatable and shareable across your team.
