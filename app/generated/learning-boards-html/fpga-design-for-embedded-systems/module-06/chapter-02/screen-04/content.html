Module 6 › Chapter 6.2 › Create Project
Steps
  1. Open File → New Project Wizard and choose the project directory and name.
  2. Add existing Verilog or VHDL source files, or create new ones with File → New.
  3. Select target device family and part number for your board.
  4. Choose EDA tool support for simulation, e.g., ModelSim‑Intel FPGA.
  5. Finish to generate .qpf and .qsf files in the project folder.
Example file names
C:\FPGA_Projects\BlinkLED\BlinkLED.qpf and BlinkLED.qsf and src\counter.v
Visual checks
Confirm project files
Verify .qpf and .qsf exist in the folder and your .v or .vhd sources are visible under Project → Add/Remove Files.
Common mistake
Adding a file with the wrong extension or a missing save causes "file not found" during synthesis.
Key Takeaway
Key Takeaway

Create the project early, ensure sources are saved with proper extensions, and confirm .qpf/.qsf presence to avoid compilation interruptions.
