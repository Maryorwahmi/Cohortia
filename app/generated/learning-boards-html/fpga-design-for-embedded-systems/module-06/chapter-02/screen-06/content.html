Module 6 › Chapter 6.2 › Device Selection
Why part number matters
The exact part number determines the FPGA's logic and I/O resources. For DE10‑Lite use MAX 10 > 10M50DAF484C7G so pin names and resource limits match board documentation.
Comparison
Correct part
Matches board schematics and pin names, accurate resource counts.
Wrong/Generic part
Pin mismatches and incorrect fitter behavior; programming may fail.
Practical steps
  1. When creating the project, choose Device > Family: MAX 10 and select 10M50DAF484C7G.
  2. Confirm pin names in the Pin Planner match the DE10‑Lite user manual.
  3. If you change device later, revalidate all pin assignments and recompile.
Key Takeaway

Pick the exact MAX 10 part for DE10‑Lite at project setup so the toolchain uses the correct resource and pin definitions throughout the flow.
