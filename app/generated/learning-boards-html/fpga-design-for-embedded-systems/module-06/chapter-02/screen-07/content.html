Module 6 › Chapter 6.2 › Compilation Flow
Stages
Analysis & Synthesis: Converts HDL to a generic netlist and reports initial resource counts.
Fitter: Places logic into device resources, routes signals, and reports utilization and fmax.
Assembler: Generates the .sof file for programming the FPGA.
Timing Analyzer: Runs static timing analysis across clock domains and reports slack and violations.
Example outcome
Flow Summary: logic elements and registers used. Fitter Summary: resource distribution and estimated fmax. Timing Analyzer: per‑domain timing and slack values.
Reading reports
  • Look for resource counts exceeding device capacity or unusually high usage percentages.
  • Check fmax for the clock domains and compare with your system requirements.
  • Address negative slack in Timing Analyzer before programming the board.
Key Takeaway

Treat compilation as an analyzable pipeline: use each report to find and fix issues rather than guessing why a design fails on hardware.
