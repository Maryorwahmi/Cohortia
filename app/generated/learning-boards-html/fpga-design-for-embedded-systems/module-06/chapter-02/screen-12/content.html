Module 6 › Chapter 6.2 › Program FPGA
Programmer steps
  1. Connect DE10‑Lite via USB and open Tools → Programmer.
  2. Click Hardware Setup, select USB‑Blaster, then Auto Detect.
  3. Right‑click device → Change File and select the .sof from output_files.
  4. Check Program/Configure and click Start to download bitstream.
File types
Use .sof for immediate volatile configuration. Use .pof to program on‑chip flash when a persistent configuration is required.
Validation
After programming, verify the design runs: for the counter example, LEDs should increment in binary and KEY reset should clear the counter.
Key Takeaway

Programming completes the cycle. Confirm USB‑Blaster connectivity and choose .sof for testing, .pof for permanent flash programming when needed.
