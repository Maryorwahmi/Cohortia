Pin Planner steps
  1. Open Assignments → Pin Planner and locate your module port names.
  2. Double‑click the Location column and enter the PIN name from the board schematic, e.g., PIN_A8 for LED0.
  3. Save assignments to update the project's .qsf file.
  4. Optionally script assignments with Tcl for repeatability.
Example Tcl
set_location_assignment PIN_A8 -to LED[0]
set_location_assignment PIN_A9 -to LED[1]
set_location_assignment PIN_A10 -to LED[2]
set_location_assignment PIN_A11 -to LED[3]
set_location_assignment PIN_A12 -to LED[4]
set_location_assignment PIN_A13 -to LED[5]
set_location_assignment PIN_A14 -to LED[6]
set_location_assignment PIN_A15 -to LED[7]
set_location_assignment PIN_B8 -to KEY[0]
set_location_assignment PIN_B9 -to KEY[1]
set_location_assignment PIN_P11 -to CLK
Validation
After assigning pins, open Chip Planner to verify the pins are placed in the expected I/O banks and check for conflicts or bank voltage mismatches.
Key Takeaway

Pin assignments are a hardware mapping. Always confirm assignments against the board's documentation and save them in the .qsf or via a Tcl script for reproducibility.
