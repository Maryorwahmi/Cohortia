Module 6 › Chapter 6.2 › HDL Sources
Editor & workflow
Create a new Verilog or VHDL file, save it inside the project folder, and add it to the project. Always save before compilation and confirm the file is listed under Project → Add/Remove Files in Project.
Example Verilog
module counter(
  input clk,
  input rst,
  output reg [3:0] q
);

always @(posedge clk or posedge rst) begin
  if (rst)
    q <= 4'd0;
  else
    q <= q + 4'd1;
end

endmodule
Practical notes
  • Save files with correct extensions: .v for Verilog, .vhd for VHDL.
  • Add sources to the project; unsaved edits are not part of compilation.
  • Use Analysis & Synthesis as a quick syntax check before full build.
Common mistake
Forgetting to add the saved file to the project causes a silent omission: the design compiles without your new module or uses an old version.
Key Takeaway
Key Takeaway

Edit, save, and confirm source registration in the project to ensure your latest RTL is what Quartus compiles.
