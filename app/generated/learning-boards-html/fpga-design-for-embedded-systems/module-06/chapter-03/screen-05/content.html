Module 6 › Chapter 6.3 › Using the RTL Viewer
Definition
RTL Viewer: Verify synthesized netlist
Use it to confirm synthesis interpreted your HDL correctly and to find inferred structures like latches or counters.
Step-by-step
  1. 1. Compile through Analysis & Synthesis.
  2. 2. Open Tools → Netlist Viewers → RTL Viewer.
  3. 3. Navigate hierarchy, double-click to open submodules.
  4. 4. Zoom and click wires to trace signal paths.
  5. 5. Note any inferred latches, counters, or missing flip-flops.
Example
A priority encoder should show multiplexers; a latch indicates an incomplete combinational assignment.
Common mistake
Forgetting default assignments in combinational blocks causes inferred latches.
Annotated RTL checklist
Trace a signal from input A to output Z and note the types of primitives encountered: gate, mux, adder, flip-flop.
If you see unexpected state-holding elements, inspect always blocks and case statements to ensure full coverage of assignments.
After changes, re-run synthesis and confirm the RTL now matches expected hardware constructs.
