Module 6 › Chapter 6.3 › Key Concepts
RTL Viewer
Generic netlist for logical verification and detecting inferred latches.
Technology Map Viewer
Mapped netlist showing LEs, DSP, memory and LUT internals for resource analysis.
Chip Planner
Physical placement, routing, and congestion view used for timing fixes and manual placement.
Summary Takeaway

Combine RTL, mapping, and physical views to move from diagnosis to measured optimization: small changes validated across viewers lead to reliable improvements.
