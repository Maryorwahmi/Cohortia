Module 6 › Chapter 6.3 › Common RTL issues
Core Concept
Detect and fix RTL problems
Use the RTL Viewer to find inferred latches, counters, and incorrect registers and correct the HDL accordingly.
Inferred latch: add default assignment in combinational blocks or complete case branches.
Unexpected counter: check arithmetic inside always blocks and ensure intended register behavior.
Missing flip-flop: verify clock edge and synchronous assignments to produce registers.
Example scenario
Given a combinational mux whose output retains previous value, the RTL Viewer shows a latch. The fix is to assign the output in every conditional branch or provide a default at the start of the combinational block.
Pro tip: add explicit default assignments to avoid accidental latches.
Check your clocking: inconsistent edges silently change registers into combinational elements.
