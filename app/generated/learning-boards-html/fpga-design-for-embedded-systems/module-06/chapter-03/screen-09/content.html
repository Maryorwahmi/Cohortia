Key Takeaway

Resource numbers identify when to change device size, add pipelining, or target DSPs for arithmetic-heavy designs.

Practical interpretations
If LEs are near capacity, plan for a larger device or prioritise reduction of logic through refactoring.
If DSPs are scarce but multipliers are implemented with LUTs, refactor code or use synthesis directives to prefer DSP inference.
Per-region imbalance often causes routing congestion; consider floorplanning or redistributing logic.
