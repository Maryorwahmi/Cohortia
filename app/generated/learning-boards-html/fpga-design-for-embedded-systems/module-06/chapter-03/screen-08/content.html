Zoom in: inspect routing lines and how carries or critical paths are physically connected; note long wires or detours.
Search nodes: find the physical location of a logic element by name to correlate with mapped resources and the report.
Key Takeaway

Chip Planner turns resource counts into spatial decisions: placement matters for timing and congestion and should guide optimization choices.
