Module 6 › Chapter 6.3 › Optimization strategies
Process Flow
Optimize using viewer evidence
Pick a single hypothesis, apply a small change, and re-measure through viewers and the report.
Pipeline long combinational paths when Map Viewer shows long LUT chains or report shows low register usage relative to LUTs.
Switch multipliers to DSPs if Map Viewer shows LUT-based multiplication and DSPs are available.
Floorplan or manually place critical logic if the Chip Planner shows per-region saturation or routing congestion.
Example iteration
Add a pipeline register to shorten a critical path, re-synthesize, confirm registers in RTL Viewer, check reduced LUT chains in Map Viewer, and verify shorter routed wires in Chip Planner.
Avoid large-scale rewrites without intermediate checks. Each small change should be validated by the viewers so you know it had the intended effect.
