Module 6 › Chapter 6.3 › Reading mapped primitives
Process Flow
Inspect LEs, LUT contents, and carry chains
Click mapped primitives to view LUT truth table, flip-flop config, and connections. This tells you how logic was implemented on silicon.
Check if arithmetic units used DSPs. If not, quantify LUT cost and consider guidance to use DSPs for multipliers.
Inspect register packing: many registers in few LEs indicates efficient packing. Low register count with high LUTs suggests heavy combinational logic.
Look for contiguous carry chains for efficient adders. Broken chains may indicate suboptimal placement or synthesis choices.
Note LUT contents to detect synthesized state machines or large truth tables that might be simplified or implemented differently.
Quick example
A multiply that consumes several LUTs likely should be redirected to a DSP block. Use synthesis attributes or coding patterns that infer DSPs, then re-check the Map Viewer.
Key Takeaway

Reading primitive internals guides decisions to change coding style, add constraints, or apply floorplanning to improve performance.
