Learning Objectives
Progress from verification to optimization using Quartus viewers and reports.
Bloom: Learn → Understand → Apply → Master
01
Verify logical structure
Use the RTL Viewer to confirm synthesis produced the expected gates and flip-flops. This prevents logic bugs from propagating to later stages.
VERIFIED COMPETENCY MILESTONE
02
Analyze mapped resources
Inspect LEs, DSPs, memory blocks and understand where heavy usage occurs to guide redesign or primitive selection.
VERIFIED COMPETENCY MILESTONE
03
Interpret resource report
Read the Compilation Report to quantify LEs, registers, memory and DSP usage and decide on device sizing or optimization steps.
VERIFIED COMPETENCY MILESTONE
04
Inspect physical placement
Use the Chip Planner to find routing congestion, verify critical path routing, and perform strategic manual placement when needed.
VERIFIED COMPETENCY MILESTONE
