RTL Best Practices
  • Use synchronous resets and explicit widths for counters and registers.
  • Modularize: separate timing, data-path, and control logic.
  • Favor registers over inferred latches; latches are often unintended.
  • Comment and name signals for synthesis report traceability.
Example Module
A baud generator module produces a tick every N system clocks; a shift-register module samples serial bits synchronously to avoid metastability.
Common Mistakes
Mixing testbench constructs into RTL, using inferred latches through incomplete assignments, and leaving wide combinational logic without pipelining can all create synthesis headaches and timing overloads.
Pro tip
Write small modules and verify them independently. Smaller scope is easier to simulate and isolate when reports show resource or timing issues.
