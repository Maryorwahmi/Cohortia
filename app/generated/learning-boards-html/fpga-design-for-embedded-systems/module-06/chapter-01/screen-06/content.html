Module 6 › Chapter 6.1 › Functional Simulation
What it checks
  • State machine transitions and outputs for given inputs.
  • Data-path correctness: counters, arithmetic, shifts.
  • Interface handshakes and FIFO behavior.
Testbench Example
Drive serial stream at nominal timing units, check FIFO write/read sequences, and assert expected bytes appear in order.
Limitations
Functional simulation does not simulate actual propagation or routing delays, nor setup/hold violations. It often misses cross-clock issues unless those are explicitly modelled in the testbench.
Misconception
Passing functional simulation means hardware is bug-free. It does not; plan for timing analysis and post-fit simulation for that assurance.
