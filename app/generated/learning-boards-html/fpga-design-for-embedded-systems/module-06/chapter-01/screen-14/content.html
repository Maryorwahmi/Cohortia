Module 6 › Chapter 6.1 › Key Concepts
Design Flow
Specification → RTL → simulate → synthesize → place-and-route → timing analysis → bitstream.
Simulation Types
Functional sim checks logic only; timing sim uses post-fit delays to find setup/hold and glitch issues.
Quartus Files
Keep .qsf and .sdc with sources; verify .sof/.pof names and check assembler and timing logs before programming.
Summary Takeaway

Treat the flow as a series of verifiable handoffs. Use each report and file to narrow root causes quickly and keep artifacts under version control for reproducibility.
