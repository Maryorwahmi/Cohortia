Core Skills Practice
Follow the hands-on activity to exercise each skill: project setup, RTL, simulation, compile, timing check, and programming.
RTL Style
Modular design, descriptive names, and synthesizable constructs reduce surprises during synthesis.
Constraints
Define clocks and I/O timing in an .sdc to allow accurate STA checks.
Simulation
Functional tests catch logic bugs; timing sims reveal delay-induced behavior.
Bitstream
Generate .sof/.pof, program the board, and verify with real IO and measurement tools.
Quick Checklist
  1. Create project and add HDL files.
  2. Add .sdc constraints and pin assignments.
  3. Run functional simulation and fix logic bugs.
  4. Compile, inspect reports, and generate .sof.
Misconception: skipping constraints may make STA pass trivially or fail to catch important path issues.
