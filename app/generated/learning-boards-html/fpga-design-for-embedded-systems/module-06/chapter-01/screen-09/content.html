Module 6 › Chapter 6.1 › Static Timing Analysis
Key STA Concepts
  • Compute delay and slack for every timing path.
  • Identify worst negative slack and path endpoints.
  • Use reports to determine whether to change RTL, add pipelines, or adjust constraints.
Example Fix
Add a register in a long combinational chain between the sampler and FIFO write to break the path and restore positive slack.
Reading a timing report
Focus on worst-case path, net names, and gate or routing delay contributors. Trace signals back to RTL to find the structural cause.
Misconception: a faster device always fixes slack. It can, but better first to optimize logic or insert pipeline stages to reduce power and resource use before moving to a larger device.
