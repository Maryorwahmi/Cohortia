What to specify
  • Inputs/outputs with voltages and pin constraints.
  • Clock frequencies and phase relationships.
  • Performance targets and power/area limits.
  • Failure modes and acceptable latencies.
Example: UART Receiver
115200 baud, 8 data bits, store bytes in FIFO, system clock 50 MHz, output on parallel bus.
Architecture sketch
Receiver
Sample, decode, shift
FIFO
Store bytes, handshake
Bus Interface
Output to parallel bus
Misconception: a short informal spec is fine. In practice, ambiguous clock or interface definitions lead to mismatched constraints and difficult timing bugs. Add at least one timing constraint per clock and list critical I/O paths explicitly.
Check: write a test case that pulses the serial input at the required baud and verifies the FIFO output byte sequence.
