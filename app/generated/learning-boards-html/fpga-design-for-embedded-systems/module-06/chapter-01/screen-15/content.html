Module 6 › Chapter 6.1 › Quick Reminders
Formal Specs
Define clocks, I/O, and tests so verification and constraints map directly to requirements.
Simulations
Run functional sims first; run timing sims for critical or high-speed paths before hardware testing.
File Management
Commit .qsf and .sdc and archive assembler logs so builds are reproducible across teams and time.
Final thought: treat each step as a contract. If a later stage fails, the contract tells you which artifact to inspect first.
