Module 4 › Chapter 4.3 › Sequence detector
Design steps
  1. Draw the state diagram representing partial matches of 1011, including overlapping matches.
  2. Assign localparam encodings to the four states and declare state and next_state regs.
  3. Implement state register with always @(posedge clk) and a synchronous reset.
  4. Implement combinational next‑state and detected logic in always @(*) using a case statement.
  5. Simulate with the provided input stream and verify detected pulses align with pattern endings.
Overlap caution
Ensure transitions preserve partial matches so overlapping patterns like 10111 will detect successive occurrences correctly.
Testbench scenario
Feed bits: 0,1,0,1,1,0,1,1,0 and step the clock. Expect detected to pulse for the clock cycles that complete the '1011' sequence.
Common mistake
Not handling overlapping sequences so the FSM misses successive detections.
Key Takeaway

Translate your state diagram into a state register and combinational next‑state logic, then simulate the exact input stream to confirm pulses occur at the expected cycles.
