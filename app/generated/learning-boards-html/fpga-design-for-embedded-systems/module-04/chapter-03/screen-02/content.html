Learning Objectives
Four verified competencies to practice and test
01
Describe synchronous blocks
Use always @(posedge clk) and non‑blocking assignment to infer flip‑flops and model simultaneous updates in hardware.
VERIFIED COMPETENCY MILESTONE
02
Implement registers and counters
Build enabled registers and synchronous counters and verify behavior under enable and reset conditions.
VERIFIED COMPETENCY MILESTONE
03
Design FSMs
Use two‑block or three‑block styles to structure state registers, next‑state logic, and outputs for clarity and correctness.
VERIFIED COMPETENCY MILESTONE
04
Choose Moore or Mealy
Understand outputs that depend on state only or on state and inputs, and trade state count for output timing.
VERIFIED COMPETENCY MILESTONE
