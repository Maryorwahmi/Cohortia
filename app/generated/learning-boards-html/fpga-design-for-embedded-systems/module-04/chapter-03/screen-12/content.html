Module 4 › Chapter 4.3 › Assessment
Assessment prompts
Combine conceptual questions with small refactor tasks.
Question 1
Explain why non‑blocking assignments should be used in sequential always blocks and give an example where mixing blocking breaks intended behavior.
Question 2
Contrast synchronous and asynchronous resets and describe a scenario where synchronous reset is preferred in FPGA design.
Practical task
Refactor a design that gates the clock for enabling into one that uses an en signal inside always @(posedge clk).
Rubric hints
  • Look for explanation of simultaneous updates for <=.
  • For reset, expect timing and release considerations in the answer.
  • Refactor should preserve functionality and avoid clock gating at RTL.
Key Takeaway

Good assessments combine explanation, prediction, and a small code rewrite so learners demonstrate both understanding and practical skill.
