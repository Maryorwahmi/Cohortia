Module 4 › Chapter 4.3 › Key Concepts
Clocked always block
Use always @(posedge clk) to infer flip‑flops and capture signals on rising edges.
Non‑blocking assignment
Use <= inside clocked blocks so all registers update simultaneously and match hardware.
Reset and enables
Prefer synchronous reset inside the clocked block and express enables inside registers rather than gating the clock.
Takeaway
These patterns form the foundation for predictable, synthesizeable sequential designs: use clocked blocks, non‑blocking assignment, clear FSM structure, and module-local state encodings with localparam.
