Module 4 › Chapter 4.3 › Clocked always block
What it means
The block executes at each rising clock edge and infers flip‑flops for reg assignments.
Concrete example
// D flip-flop
always @(posedge clk) begin
  q <= d;
end
Simulate toggling d while clock runs and observe q update only when clock rises.
Common misconception
Order of non‑blocking assignments does not create sequential delays; all left‑hand sides update together at the end of the time step.
Pro tip

Use clocked always blocks consistently for all state registers so timing is uniform across the design.

Teaching visual
Simulated waveform scenario
Clock rising edges capture d into q. Toggling d between edges does not affect q until the next edge.
Try: toggle d and step the clock to observe capture.
Why this matches hardware
Flip‑flops in FPGAs latch inputs on the clock edge. Modeling that behavior in Verilog using always @(posedge clk) ensures simulation maps to silicon.
Closing thought: How does simultaneous update simplify next‑state computation?
Key Takeaway
Use always @(posedge clk) to model flip‑flop capture; expect simultaneous updates when using non‑blocking assignments.
