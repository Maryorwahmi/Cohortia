Module 4 › Chapter 4.3 › Moore vs Mealy
Moore machine
Outputs are functions of state only and therefore change on the clock edge when state changes.
Advantage
Predictable synchronous outputs that are easier to interface and time with other modules.
Example
Traffic light outputs assigned from state values so lights update only when state changes on the clock.
Mealy machine
Outputs are functions of state and inputs and can change immediately when inputs change.
Tradeoff
Fewer states possible but outputs may be asynchronous relative to the clock and require synchronization at interfaces.
Practice suggestion
Convert a Moore FSM to Mealy for a single-output timing improvement and then simulate to see how the output timing shifts relative to the clock.
Key Takeaway

Choose Moore when output stability and synchronous timing matter. Choose Mealy to reduce state count but account for asynchronous output changes.
