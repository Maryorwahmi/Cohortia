Objective checks
Concrete validation steps to prove each skill
Clocked block check
  • Write a D flip‑flop module with q <= d in always @(posedge clk).
  • Simulate a toggle on d and observe q changing only with clock edges.
Register & enable check
  • Create an 8‑bit register with an enable input.
  • Verify q holds when enable is low and updates when it is high on a clock edge.
Counter & reset check
  • Implement an 8‑bit counter with synchronous reset.
  • Assert reset and confirm count returns to zero synchronously.
FSM behavior check
  • Simulate the traffic light FSM and verify the light encoding per state transitions driven by timer_done.
  • Implement the sequence detector and confirm detected pulses in the specified input stream.
Mnemonic
SYN — Synchronous logic updates on the clock edge; use non‑blocking assignment to synchronize multiple registers.
Key Takeaway

Turn objectives into small simulation tests. If a signal changes off the clock, recheck your coding style and assignment types.
