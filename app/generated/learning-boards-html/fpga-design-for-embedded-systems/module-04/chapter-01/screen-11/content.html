mux2 Parameterized
Create a SELECTED bus using a parameter for width and a continuous assignment for selection.
module mux2 #(parameter WIDTH = 8) (
  input  wire [WIDTH-1:0] A,
  input  wire [WIDTH-1:0] B,
  input  wire             SEL,
  output wire [WIDTH-1:0] Y
);
  assign Y = SEL ? B : A;
endmodule
Simulation Steps
  1. Instantiate mux2 in a top-level module with 8-bit inputs.
  2. Create a testbench that toggles inputs and the select line.
  3. Run the waveform and verify Y follows A or B per SEL.
Check
Confirm no width mismatches and that the output does not store a previous value when SEL changes; it should update combinationally.
Key Takeaway

Parameterize widths and verify selection behavior in a simulator to confirm combinational logic correctness.
