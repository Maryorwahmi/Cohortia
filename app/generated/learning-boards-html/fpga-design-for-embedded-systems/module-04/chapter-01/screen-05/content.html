and_gate module
A compact example showing ports and a continuous assignment.
module and_gate (
  input  wire A,
  input  wire B,
  output wire Y
);
  assign Y = A & B;
endmodule
  • input and output declare direction and appear on the module interface.
  • wire indicates a continuous net suitable for assign or module outputs.
  • assign establishes a combinational relationship that updates continuously.
Practical Notes
When you change a bus width, update both the module declaration and all instantiations. Named port association helps avoid mistakes.
Example Instantiation
and_gate u_and (.A(a_sig), .B(b_sig), .Y(out_sig));
Key Takeaway

Declare clear port directions, prefer named connections, and keep net widths consistent across instances.
