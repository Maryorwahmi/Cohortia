01. Explain Verilog
VERIFIED COMPETENCY MILESTONE
Describe Verilog's origin, its role as an HDL, and how statements map to hardware. This helps you reason about parallel hardware behavior.
Mnemonic: timeline from simulation to synthesis
02. Write Modules & Ports
VERIFIED COMPETENCY MILESTONE
Declare inputs and outputs, use assign for combinational logic, and structure a module for reuse. This ensures correct interfaces for synthesis.
Mnemonic: chip outline with labelled pins
03. Wire vs Reg
VERIFIED COMPETENCY MILESTONE
Choose wire for continuous connections and reg for procedural storage. Avoid driving a reg with a continuous assign to prevent synthesis errors.
Mnemonic: wire as line, reg as boxed register
04. Vectors & Parameters
VERIFIED COMPETENCY MILESTONE
Declare bit-widths for buses and use parameters to make modules configurable so the same code scales to different widths.
Mnemonic: parallel wires labelled from MSB to LSB
