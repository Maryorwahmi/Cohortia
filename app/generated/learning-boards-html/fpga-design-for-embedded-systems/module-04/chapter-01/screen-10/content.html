Architecture
Module Hierarchy
Top-level modules connect submodules and expose the system interface.
  • Declare internal wires and tie them to child ports explicitly.
  • Keep port directions and widths consistent across levels.
  • Document each module's responsibility to avoid overlapping ownership.
Concrete Scenario
A top module instantiates an adder and a multiplexer. The adder output ties to the multiplexer input through a declared wire and the multiplexer select is driven by a controller signal.
Checklist
Ensure ports are declared, wires are created for interconnects, and parameter overrides are applied where needed.
Key Takeaway

Organize code by clear module responsibilities and explicit top-level wiring to keep designs verifiable and maintainable.
