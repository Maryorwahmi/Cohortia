Module 4 › Chapter 4.1 › Key Concepts
Hardware Description
Verilog describes nets, gates, and storage that exist concurrently on hardware.
Module Interface
Modules define inputs and outputs; named port association reduces instantiation errors.
wire vs reg
wire for continuous nets, reg for procedural variables used in always blocks; context decides storage.
Takeaway

Think of Verilog statements as hardware declarations. Use parameters and vectors to make modules reusable and test them with simulation waveforms.
