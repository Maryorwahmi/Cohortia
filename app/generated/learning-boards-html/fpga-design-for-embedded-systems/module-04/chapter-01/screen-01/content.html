Concept Map
Modules are reusable; ports form the external interface; wires connect instances; regs store values in procedural blocks.
Module
Self-contained hardware block with ports and behavior.
Port
Directioned input or output connecting modules.
Wire
Continuous connection driven by assign or module outputs.
Reg
Holds value in procedural blocks like an always block.
Explore Key Topics
Module & Ports
Define a hardware interface and internal behavior. Modules are the building blocks you will reuse across designs.
Wire vs Reg
Wires are driven continuously; regs hold values inside procedural logic. Confusing the two causes synthesis issues.
Parameters & Vectors
Parameters make modules configurable; vectors let you group parallel bits for buses and arithmetic.
