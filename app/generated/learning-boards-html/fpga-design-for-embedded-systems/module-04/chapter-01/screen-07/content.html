Definition
Vectors
Declare multiple bits as a single signal for buses and arithmetic.
wire [3:0] data;
// data[2] accesses a single bit
// data[3:1] accesses a slice
  • Specify most significant index first, then least significant.
  • Use vectors for arithmetic operands and bus transfers.
  • Check index bounds to avoid width mismatches.
Concrete Example
Adding two vectors produces a wider result. The carry may extend the sum's width by one bit.
wire [7:0] A, B;
wire [7:0] SUM;
wire COUT;
assign {COUT, SUM} = A + B;
Note
The concatenation braces capture carry and sum into a wider vector connection.
Key Takeaway

Vectors group bits into buses; always confirm widths and use slices to access subfields cleanly.
