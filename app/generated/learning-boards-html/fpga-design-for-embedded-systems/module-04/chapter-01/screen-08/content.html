Parameterize a module
Declare parameters to size ports and enable overrides at instantiation.
module adder #(parameter WIDTH = 8) (
  input  wire [WIDTH-1:0] A,
  input  wire [WIDTH-1:0] B,
  output wire [WIDTH-1:0] SUM,
  output wire             COUT
);
  assign {COUT, SUM} = A + B;
endmodule
  • Parameters are set at compile/instantiate time, not runtime.
  • Use them to size vectors and tune behavior consistently.
  • Override with the parameter list when instantiating to change width.
Instantiation Example
Override the WIDTH to create a different adder variant without editing the module code.
adder #(16) my_adder (.A(a), .B(b), .SUM(sum), .COUT(cout));
Practice
Instantiate with different WIDTH values and check that SUM and COUT have the expected bit widths in simulation.
Key Takeaway

Parameters enable scalable, reusable modules. Always verify matching widths when overriding parameters.
