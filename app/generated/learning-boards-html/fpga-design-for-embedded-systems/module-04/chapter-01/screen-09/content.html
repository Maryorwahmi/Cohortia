Top-level instantiation
Use named association to connect instance ports to signals clearly.
module top (
  input  wire [3:0] a,
  input  wire [3:0] b,
  output wire [4:0] result
);
  wire cout;
  adder #(4) u1 (.A(a), .B(b), .SUM(result[3:0]), .COUT(cout));
  assign result[4] = cout;
endmodule
Practical Tips
Name-based connections make it obvious which signal maps to which port. This is important when multiple similarly-typed buses exist.
Warning
Positional association can silently miswire signals if the module's port order changes. Use named association to prevent this.
Key Takeaway

Instantiating modules with explicit named ports increases clarity and reduces bugs when ports or widths change.
