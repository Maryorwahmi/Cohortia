Definition

Self-checking testbenches

Use procedural comparisons and system tasks to print PASS or ERROR so tests can be run unattended and evaluated automatically.

Example pattern
initial begin
  a = 5; b = 3; #10;
  if (sum !== 8) begin
    $display("ERROR: Test 1 failed! Expected 8, got %d", sum);
    $stop;
  end else $display("PASS: Test 1");
end
Pitfall

Using exact equality can fail on uninitialized values. Use the appropriate comparison operator and initialize inputs explicitly to avoid spurious failures.

Practical tip

Combine pass/fail prints with waveform captures so a failing test includes both a console message and the timeline needed for root-cause analysis.
