Practice Tasks

Each objective should be proven with a specific deliverable and a waveform snapshot in ModelSim.

Deliverable: Testbench file

Provide a testbench that instantiates the DUT, drives inputs as reg, and connects outputs as wire. Demonstrate all needed test vectors and include finish logic.

Deliverable: Clock and reset waveforms

Include a clock generator with a known period and a reset sequence that shows asserted then deasserted timing in the waveform viewer.

Deliverable: Self-checking outputs

Add if statements that compare expected values and call display to mark PASS or ERROR for each case.

Checklist
  • Timescale directive present and correct.
  • Clock has expected period and is stable.
  • Reset asserted long enough for initialization.
