Core Concept

Simulation system tasks

System tasks give you runtime visibility. Use them to log events, detect failures, and control simulation flow for debugging or automated testing.

Examples
$display("Time=%0t | A=%b B=%b | Y=%b", $time, a, b, y);
$monitor("...", ...);
$stop; // pause
$finish; // end
When to use each

Use display for targeted messages, monitor for continuous change logging, stop for interactive debugging, and finish for clean automated test termination.

Action

Always include identifying context in messages such as test case number and time so logs are useful when tests run unattended.
