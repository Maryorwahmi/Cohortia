Learning Objectives
Bloom's mini-bar: Learn → Understand → Apply → Master
01
Write a Verilog testbench

Create a top-level module that instantiates the DUT and uses internal signals to drive inputs and observe outputs. This prevents logic bugs before hardware testing.

VERIFIED COMPETENCY MILESTONE
02
Generate clock and reset

Use an always toggle or a forever loop to create a clock. Sequence reset with a short delay so your DUT initializes predictably on simulation start.

VERIFIED COMPETENCY MILESTONE
03
Use initial blocks and stimulus

Apply timed stimulus with delays and display statements to exercise behavior and print results. Understand how the timescale directive sets the meaning of delays.

VERIFIED COMPETENCY MILESTONE
04
Interpret ModelSim waveforms

Add internal signals to the waveform viewer, zoom to edges, and measure timing to find root causes when outputs differ from expectations.

VERIFIED COMPETENCY MILESTONE
Mnemonic
Think: DUT + Stimulus + Observe = Verified Design. The three parts are small, composable, and reusable across modules.
Quick tip
Label internal signals clearly so you can quickly add them to ModelSim's waveform and trace their behavior when debugging.
