Process Flow

ModelSim workflow

Create project and add files
Include your Verilog source and testbench files before compiling.
Compile and load testbench
Fix any compile errors, then run the testbench top-level in the simulator.
Add signals to waveform
Include clocks, reset, internal registers, and DUT outputs for inspection.
Practical tip

Save a waveform layout that contains your common signals so you can re-open the same view for each test run.

Debug flow

If a result is incorrect, add internal signals to the waveform and trace the hierarchy to locate where the value diverges from expectation.
