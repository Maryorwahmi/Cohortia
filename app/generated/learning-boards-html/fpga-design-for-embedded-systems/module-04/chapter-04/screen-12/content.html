Process Flow

Debugging strategy

Step-by-step
  1. Re-run the test to reproduce the failure deterministically.
  2. Add proximate internal signals to the waveform.
  3. Measure timing and identify the first divergence from expected values.
  4. Trace hierarchy to the responsible module and fix logic or timing.
Example

If an ALU output is wrong, add opcode, operand registers, and internal flags to verify whether the opcode decoding or arithmetic path is producing the incorrect result.

Practical tip

Save waveform configurations used during debugging so you can quickly reopen the same view when re-running tests after fixes.
