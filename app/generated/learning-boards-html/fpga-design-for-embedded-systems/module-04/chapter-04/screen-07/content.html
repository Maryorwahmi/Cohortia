Reset generation

Use an initial block to assert and later deassert reset with a clear, documented delay. This ensures repeatable startup behavior in simulation.

Example
initial begin
  rst = 1;        // assert reset
  #20 rst = 0;    // deassert after 20 ns
end
Common mistake

Too-short reset pulses can leave registers in unknown states. Make sure the reset covers at least one clock edge when registers sample on the clock edge.

Scenario

For an asynchronous reset, check signals immediately after the reset edge; for synchronous resets, check after the subsequent clock edge.
