Definition

Timescale and initial blocks

The timescale directive maps numeric delay values to real time. Use initial blocks to sequence test vectors using delays that the timescale resolves into real simulation time.

Common pattern
`timescale 1ns / 1ps
initial begin
  a = 0; b = 0; #10; // wait 10 ns
  a = 0; b = 1; #10;
  a = 1; b = 0; #10;
  a = 1; b = 1; #10;
  #10; $finish;
end
Why it matters

Deterministic delays let you reproduce failures reliably and measure the time between events such as reset deassertion and first valid output.

Pitfall

Don't assume `#10` models propagation delay inside synthesized hardware. Testbench delays only schedule simulation events and do not change synthesis results.

Pro tip

Use $monitor with $time to print time-stamped messages that confirm when vectors were applied relative to your timescale settings.
