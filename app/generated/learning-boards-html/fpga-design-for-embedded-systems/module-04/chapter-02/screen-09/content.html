Module 4 › Chapter 4.2 › Conditional operator and multiplexers
Quick pattern
// 2-to-1 mux
assign z = sel ? b : c;

// nested for 4-to-1 (readability caution)
assign y = sel[1] ? (sel[0] ? d : c) : (sel[0] ? b : a);
The conditional operator is combinational. For many conditions or when you must set flags in addition to outputs, use an always case block instead.
Example scenario

Use ? : for selecting between two ALU inputs for a small datapath mux. If you need to implement a full opcode table that sets result, carry, and zero flags, prefer a combinational case block to keep assignments explicit and avoid errors.

Pro tip: replace deeply nested conditionals with a case for clarity and easier verification.
Key Takeaway

? : is perfect for compact 2-to-1 muxes. Use case/if-else when selection grows or multiple outputs are set.
