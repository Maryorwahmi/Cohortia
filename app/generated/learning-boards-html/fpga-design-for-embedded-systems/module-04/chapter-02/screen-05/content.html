Code panel
// Bitwise and reduction examples
assign and_result  = a & b;        // per-bit AND
assign xor_parity  = ^data;        // reduction XOR -> parity
assign all_ones    = &a;          // reduction AND -> all bits set

// Concatenation and sign extension
assign extended    = {{8{a[7]}}, a}; // replicate sign bit then append
assign {cout,sum}  = a + b + cin;    // capture carry-out with concatenation
Explanation and notes
  • Bitwise ops apply per-bit and synthesize to arrays of gates.
  • Reduction ops collapse a vector to one bit, useful for parity or detect-all-ones.
  • Concatenation assembles wider vectors; replication is handy for sign extension.
  • Avoid non-power-of-two division in combinational paths when possible; prefer shifts for powers of two.
Pro tip: use concatenation to capture both result and carry-out in one expression for clean wiring.
Key Takeaway

Bitwise and reduction operators are the heart of gate-level combinational design; concatenation and replication let you sculpt vectors and sign-extend safely.
