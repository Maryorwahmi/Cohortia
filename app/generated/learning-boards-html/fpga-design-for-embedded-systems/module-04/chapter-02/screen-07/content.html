Module 4 › Chapter 4.2 › Designing a safe combinational case block
Numbered process
  1. Start with default assignments for every output to a safe known value.
  2. Write a case or if-else structure that covers every possible input or opcode value.
  3. Assign every output inside every branch so no path leaves signals unassigned.
  4. Include a default branch in case statements to handle unexpected values.
  5. Simulate exhaustive input combinations relevant to functionality to catch missing assignments.
Example default: y = 4'b0000; before case(opcode) ... endcase
Concrete scenario

Design an ALU: default result = 4'b0000 and zero flag = 0; then for each opcode assign result and zero. This prevents latches and guarantees combinational behavior across all opcode values.

Common mistake: forgetting to set flags in a branch. If you set result but not zero, the synthesizer may infer storage for the flag.
Key Takeaway

Always provide defaults and fully cover case branches when implementing combinational selection logic to avoid inferred latches.
