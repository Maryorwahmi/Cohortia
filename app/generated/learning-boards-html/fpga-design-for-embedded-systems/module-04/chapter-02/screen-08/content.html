Module 4 › Chapter 4.2 › Blocking vs. non-blocking
Two styles
Blocking (combinational)
Use equals for ordered, stepwise combinational calculations inside always @(*) blocks.
Non-blocking (sequential)
Use non-blocking for clocked always blocks to update registers simultaneously at clock edge.
Concrete example
always @(*) begin
  temp = a + b;      // blocking: temp available next line
  y    = temp ^ c;   // uses computed temp directly
end

// Clocked sequential style uses non-blocking:
always @(posedge clk) begin
  q <= d;            // non-blocking: all RHS sampled then LHS updated
end
Key Takeaway

Follow the rule: blocking for combinational always @(*), non-blocking for sequential clocked blocks to avoid unintended behavior.
