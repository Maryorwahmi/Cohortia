Module 4 › Chapter 4.2 › Designing a 4-bit ALU
Starter template (combinational case)
always @(*) begin
  // defaults
  result = 4'b0000;
  carry  = 0;
  zero   = 0;

  case (opcode)
    3'b000: {carry,result} = a + b; // addition
    3'b001: result = a - b;         // subtraction
    3'b010: result = a & b;         // AND
    3'b011: result = a | b;         // OR
    3'b100: result = a ^ b;         // XOR
    3'b101: result = ~a;            // NOT A
    3'b110: result = a << 1;        // shift left
    3'b111: result = a >> 1;        // shift right
    default: begin result = 4'b0000; carry = 0; end
  endcase

  zero = (result == 0);
end
Verification plan
  1. Write a testbench that applies the same operands for all 8 opcodes.
  2. Log result, carry and zero for each opcode and compare to expected values.
  3. Inspect waveforms to confirm outputs change combinationally when inputs change.
  4. Synthesize and view resource usage to ensure no inferred latches.
Pro tip: use concatenation to capture carry-out from additions: {carry, result} = a + b;
Key Takeaway

This ALU exercise ties together assign, always @(*), operator selection, defaulting and simulation verification — a practical synthesis-ready task.
