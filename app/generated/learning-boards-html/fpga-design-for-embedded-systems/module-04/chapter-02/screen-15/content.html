Assignment styles
Blocking for combinational, non-blocking for sequential.
Mux patterns
Use ? : for simple muxes; use case for many outputs or complex selection.
Avoid latches
Default outputs and cover all branches to prevent inferred storage elements.
Final tip

Before synthesizing, run a quick checklist: assign vs always, blocking vs non-blocking, defaults and coverage, operator cost — then simulate all key input vectors.
