Learn

Read examples of assign and simple conditional operators, run a short simulation to see immediate output updates. This builds basic fluency with syntax and behavior.

Milestone: sample waveform shows output following inputs.
Understand

Study always @(*) semantics, latch inference causes, and default assignments. Recognize how a missing assignment maps to a storage element during synthesis.

Milestone: explain why a missing else creates a latch.
Apply

Implement a multiplexer both as a conditional operator and as an always case block. Verify that both are synthesizable and functionally equivalent in simulation.

Milestone: simulation matches for all select values.
Master

Design a 4-bit ALU using a combinational case statement, synthesize it, and inspect the Technology Map Viewer to confirm resource mapping and absence of latches.

Milestone: synthesis without inferred latches and full testbench coverage.
