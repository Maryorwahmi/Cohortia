Module 4 › Chapter 4.2 › Combinational procedural blocks
Pattern
always @(*) begin
  // default prevents inferred latches
  y = 4'b0000;
  case (sel)
    2'b00: y = a;
    2'b01: y = b;
    2'b10: y = c;
    2'b11: y = d;
  endcase
end
This structure is synthesizable because every path assigns y, and at-star ensures the block re-evaluates when any input used inside changes.
Explanatory bullets
  • always @(*) creates a combinational process re-evaluated on input changes.
  • Default assignments at the top of the block avoid latch inference.
  • Use case or if-else for clearer multi-way selection than nested expressions.
  • Procedural style allows temporaries and clearer step-by-step logic.
Pro tip: place all default assignments together so it's obvious what initial values are before branching.
Key Takeaway

always @(*) is your go-to for multi-statement combinational logic; prevent latches by assigning outputs on every path.
