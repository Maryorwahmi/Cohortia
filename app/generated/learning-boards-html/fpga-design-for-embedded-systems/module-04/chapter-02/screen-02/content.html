Learning Objectives
Grow from understanding syntax to writing synthesizable combinational modules
01
Continuous assignment

Use assign to connect expressions to wires for simple gates and small muxes. This matters for clear, gate-like code that synthesizes predictably.

Mnemonic: wiring diagram card
VERIFIED COMPETENCY MILESTONE
02
Combinational always @(*)

Write always @(*) blocks for multi-way selection and ALUs. Always ensure every output is driven on every path to avoid latches.

Mnemonic: control-flow timeline
VERIFIED COMPETENCY MILESTONE
03
Operators and expressions

Apply arithmetic, bitwise, logical, reduction, comparison, shift and concatenation operators correctly and understand resource costs.

Mnemonic: operator grouping venn
VERIFIED COMPETENCY MILESTONE
04
Avoid common mistakes

Prevent inferred latches by defaulting outputs or covering branches, and use at-star to avoid missing sensitivity items.

Mnemonic: checklist icon
