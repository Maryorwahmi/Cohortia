Module 4 › Chapter 4.2 › Continuous assignment with assign
Definition

A continuous assignment connects an expression to a net so the output follows immediately when inputs change. It models wires and gates.

Code example
// Basic gates
assign y1 = a & b;        // AND
assign y2 = a | b;        // OR
assign y3 = a ^ b;        // XOR
assign y4 = ~a;           // NOT

// Wider logic
assign y  = (a & b) | (c & d);  // sum of products
assign z  = sel ? b : c;        // 2-to-1 mux
Pro tip: keep expressions short for clarity.
Mistake: using reg target with assign — use wire for assign targets.
Why this pattern matters
  • Maps directly to gates for predictable synthesis.
  • Updates continuously: no implicit sequencing or storage.
  • Ideal for small multiplexers via the conditional operator.
  • Use wire-type targets and avoid long, nested expressions.
Key Takeaway

assign is a continuous connection: prefer it for simple gate-like logic and short muxes implemented with ? :.

Concrete example
A mod-2 parity bit: assign parity = ^data; Here ^data is a reduction XOR producing a single-bit parity result immediately when data changes.
