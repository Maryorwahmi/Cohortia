Learning Objectives

Skills you'll demonstrate by the end of this chapter.

Bloom: Learn → Understand → Apply → Master
01
Distinguish
Soft vs. hard cores
Explain how soft cores map to LUTs and flip-flops, while hard cores are fixed silicon. This matters for customization and area use.
VERIFIED COMPETENCY MILESTONE
02
Describe
NIOS II architecture
Outline core types, optional caches, and how peripherals connect via the Avalon memory-mapped interface.
VERIFIED COMPETENCY MILESTONE
03
Explain
Trade-offs
Compare performance, power, flexibility, area, and cost so you can recommend a processor for given constraints.
VERIFIED COMPETENCY MILESTONE
04
Identify
Appropriate applications
Recognize when to use soft cores for control logic and when a hard-core ARM is required for high-performance OSs and multimedia.
VERIFIED COMPETENCY MILESTONE
Each objective links conceptually to a hands-on activity: compare NIOS II/f to an ARM core, map peripherals over Avalon, and write a one-page recommendation for three example systems.
