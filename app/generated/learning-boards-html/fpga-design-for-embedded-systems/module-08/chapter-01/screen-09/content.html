Module 08 › Chapter 8.1 › Avalon Interface
Concept

Avalon is a memory-mapped interconnect used by NIOS II systems to access memory and peripherals through addressable registers.

Peripherals
UART, SPI, I2C, timers, GPIO and custom IP are mapped into the processor address space for simple register access.
Programming model
Firmware reads and writes to peripheral registers using normal memory operations, making software simple to write and reason about.
Misconception
Avalon is a hardware bus, not a software API; it exposes registers that firmware manipulates using standard memory access.
Annotated example
Scenario
A NIOS II writes a control register to start a custom accelerator and polls a status register over Avalon to detect completion, while another peripheral sends serial telemetry over UART.
Considerations
  • Address map planning
  • Bus width and throughput
  • Arbitration and master contention
Why it matters
Clear mapping simplifies firmware and enables tight hardware-software integration for deterministic control.
Key Takeaway

Avalon exposes peripherals as memory-mapped registers, making hardware accessible through simple firmware reads and writes.
