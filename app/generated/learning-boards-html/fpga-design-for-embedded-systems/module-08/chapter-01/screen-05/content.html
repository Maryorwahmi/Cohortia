Module 08 › Chapter 8.1 › Soft-Core Choices
NIOS II
Configurable Intel soft core
32-bit RISC with three core profiles, optional caches, and connects via Avalon. Good vendor integration for peripherals.
MicroBlaze
Xilinx soft core
Similar configurable features and cache options. Fits into Xilinx Vivado IP ecosystem for rapid SoC assembly.
RISC-V soft cores
Open-source alternatives
Range from very small to feature-rich. Flexible ISA and freedom to add custom instructions without royalties.
Decision factors
  • Toolchain and IP availability (vendor support vs open-source)
  • Licensing constraints and customization needs
  • Resource usage and performance targets
Concrete scenario
If you need vendor IP and fast integration with FPGA tools, choose NIOS II or MicroBlaze. If you need ISA-level customization or minimal licensing, consider a RISC-V core.
