Module 08 › Chapter 8.1 › Hard-Core Definition
Definition & Examples

A fixed, silicon-implemented processor on the FPGA die. Examples include ARM Cortex-A9 and Cortex-A53 used in SoC-class FPGAs.

Benefits
Higher clock rates, lower per-megahertz power, and a mature software ecosystem for OSs and tools.
Limitations
Less ISA-level customization; the core is fixed though you can still attach accelerators in the fabric.
Misconception
A hard core does not prevent hardware customization elsewhere on the chip; it complements the FPGA fabric for balanced designs.
Key Takeaway

Choose a hard-core when you need OS support, high performance, and low per-MHz power for complex software stacks.

Concrete scenario
Video processing and Linux
For running OpenCV on Linux with hardware floating-point and pipelined memory subsystems, a hard-core ARM with MMU and caches is typically required to meet performance and software compatibility needs.
Pros
  • High clock capability
  • Robust software tooling
Cons
  • Less ISA-level customization
  • Higher device cost
Remember: a hard-core processor pairs well with FPGA accelerators, giving the best of both software ecosystem maturity and hardware performance.
