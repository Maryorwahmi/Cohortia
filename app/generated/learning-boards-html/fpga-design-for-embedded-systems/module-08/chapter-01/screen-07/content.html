Module 08 › Chapter 8.1 › Trade-Offs
Five dimensions to compare
  • Performance: hard cores usually higher clocks and throughput.
  • Power: hard cores are more energy-efficient per MHz.
  • Flexibility: soft cores allow ISA and peripheral customization.
  • Area: soft cores consume FPGA fabric which limits other logic.
  • Cost: dedicated-processor FPGAs tend to be pricier.
Example
For a 10-year battery IoT node, energy per operation and sleep behavior dominate; a low-power hard core or ultra-small soft core designed for low active duty may be best.
Decision matrix (how to use)
  1. List your workload metrics: required cycles per second, memory footprint, and latency bounds.
  2. Score each dimension for soft and hard cores relative to your metrics.
  3. Weight dimensions (for instance, power might be 0.4 for battery devices).
  4. Compute weighted scores and choose the higher-scoring option.
Takeaway

A numeric matrix keeps the decision objective and highlights trade-offs that a single metric would miss.
