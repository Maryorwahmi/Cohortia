Module 08 › Chapter 8.1 › Soft-Core Definition
Definition

A processor described in HDL and synthesized into FPGA logic. It is flexible and customizable but constrained by fabric timing and area.

Structure
Built from LUTs, flip-flops and routing. Optional caches and custom instructions consume logic resources.
Typical uses
Control loops, peripheral management, glue logic, and systems where custom hardware coexists with firmware.
Misconception
A soft core is not always cheaper or as fast as a hard core; customization consumes area and can increase power per MHz.
Key Takeaway

Soft cores give control and customization at the cost of slower clock rates and FPGA area usage.

Concrete example
NIOS II-e for motor control
A minimal NIOS II economy core, with no caches and no hardware divide, can run a tight PID loop at 1 kHz while leaving fabric resources free for PWM and sensor logic.
Pros
  • Highly customizable
  • Single-chip integration with custom logic
Cons
  • Lower max clock
  • Consumes FPGA area and power
A practical check: count the logic you need for your soft core and peripherals before committing—resource usage directly affects feasibility.
