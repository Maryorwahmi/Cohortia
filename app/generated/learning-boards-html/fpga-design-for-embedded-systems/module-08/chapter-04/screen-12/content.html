Module 9 › Chapter 8.4 › Key Concepts
BSP generation
Generate BSP from Qsys so headers and linker scripts match hardware.
HAL / IOWR / IORD
Use HAL macros with base symbols from system.h rather than literal addresses.
JTAG Debugging
Use the JTAG debugger to step, set breakpoints, and inspect variables on the FPGA.
Summary takeaway
Treat the BSP as authoritative, use HAL macros for portability, and rely on JTAG to validate runtime behavior between your C code and Qsys peripherals.
