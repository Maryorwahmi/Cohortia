Core Concept

Board Support Package

A generated collection of headers, drivers, HAL, newlib, and linker scripts that match your Qsys system.
HAL
C functions and macros to access UART, GPIO, timers without raw addresses.
Device drivers
Peripheral-specific code produced for the components present in Qsys.
Linker script
Defines memory regions for code and data based on on-chip memory or external SDRAM.
system.h
Generated header with base address macros like PIO_LED_BASE used by HAL macros.
Practical example: LED PIO
/* system.h contains: */
#define PIO_LED_BASE 0x00001000

/* HAL write uses the base symbol: */
IOWR_ALTERA_AVALON_PIO_DATA(PIO_LED_BASE, 0xFF);
Regenerate BSP
When you add or remove peripherals in Qsys, regenerate the BSP so system.h and the linker script remain correct for your software build.
Key Takeaway
Treat the BSP as the authoritative mapping of hardware to software interfaces; it prevents hardcoded-address bugs.
