Definition

Linker script and memory regions

The BSP supplies a linker script that assigns program and data sections to on-chip memory or external SDRAM defined in Qsys.

  • .text: program code
  • .data and .bss: initialized and zeroed data
  • heap and stack: runtime allocations and call frames
Practical advice
If your binary grows beyond on-chip memory, add SDRAM to Qsys and regenerate the BSP so the linker script can place large regions into SDRAM. Inspect the map file to confirm placements.
Common mistake

Declaring large static buffers without configuring sufficient RAM leads to runtime crashes. Check linker output and memory addresses in the debugger to confirm placement.
