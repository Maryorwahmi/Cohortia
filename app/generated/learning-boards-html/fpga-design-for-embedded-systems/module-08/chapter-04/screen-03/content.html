Learning Objectives
Link each objective to a practical action you will perform in a lab.
01
Edit, build, and step through C code
You will set breakpoints and inspect variables during a live run on the FPGA to validate logic and timing assumptions.
VERIFIED COMPETENCY MILESTONE
02
Map software to memory correctly
Use the BSP linker script to place code and data in on-chip memory or external SDRAM as your project scales.
VERIFIED COMPETENCY MILESTONE
03
Use HAL macros safely
Call the provided macros rather than raw addresses to make code robust when the hardware layout changes.
VERIFIED COMPETENCY MILESTONE
04
Verify interactions with JTAG
Set a breakpoint inside a button handler and inspect the GPIO register value when the button is pressed to confirm hardware-software integration.
VERIFIED COMPETENCY MILESTONE
