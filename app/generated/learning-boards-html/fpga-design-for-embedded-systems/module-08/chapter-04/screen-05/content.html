Definition

IOWR and IORD macros

Macros provided by the HAL that wrap reads and writes to peripheral registers using generated base address symbols.

IOWR_ALTERA_AVALON_PIO_DATA(PIO_LED_BASE, value); // write LED data
alt_u32 status = IORD_ALTERA_AVALON_TIMER_STATUS(TIMER_BASE); // read timer
Misconception: using literal addresses seems faster but produces brittle code. The HAL macros are compiler-friendly and portable when BSP regenerates system.h.
Practical mapping
system.h
Contains macros like PIO_LED_BASE defined to the peripheral's base address assigned by Qsys.
#include "system.h"

/* use generated base symbol, not a literal */
IOWR_ALTERA_AVALON_PIO_DATA(PIO_LED_BASE, 0xFF);
Quick Check
If you move a peripheral in Qsys and forget to regenerate the BSP, compilation may still succeed but runtime reads/writes target the wrong address. Regenerate BSP and rebuild.
