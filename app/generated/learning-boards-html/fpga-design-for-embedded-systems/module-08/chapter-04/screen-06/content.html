Code Walkthrough
Blink LED
#include <unistd.h>
#include "system.h"
#include "altera_avalon_pio_regs.h"

int main(void) {
  alt_u32 led_pattern = 0x01;

  while (1) {
    IOWR_ALTERA_AVALON_PIO_DATA(PIO_LED_BASE, led_pattern);
    usleep(500000);  /* 500 ms */

    led_pattern = led_pattern << 1;
    if (led_pattern == 0)
      led_pattern = 0x01;
  }
  return 0;
}
Annotations
  • Include system.h: supplies PIO_LED_BASE, TIMER_BASE and other base address macros generated by the BSP.
  • IOWR macro: writes a value to the LED PIO register using the HAL-provided macro.
  • usleep: provided by the BSP/newlib integration and uses the system timer implementation.
  • Pattern logic: shifting and wrap-around produce a chasing LED effect; inspect led_pattern with JTAG to verify behavior.
Key Takeaway

This simple program demonstrates how BSP headers, HAL macros, and timer functions integrate to control hardware without magic addresses.
