Learning Objectives
Learn the toolchain, BSP structure, HAL API usage, and how to run and debug code on the FPGA.
01
Write, compile, and debug with NIOS II SBT
Use the Eclipse-based SBT to edit C code, run the cross compiler, and connect the JTAG debugger. This shortens edit-compile-run cycles so you can iterate fast on hardware-focused software.
VERIFIED COMPETENCY MILESTONE
02
Understand the BSP and its contents
Recognize HAL, newlib, device drivers, the linker script, and generated headers. Know why regenerating BSP after Qsys changes keeps code trustworthy.
VERIFIED COMPETENCY MILESTONE
03
Use HAL API for UART, GPIO, timer
Call HAL functions and macros such as IOWR/IORD to interact with peripherals without knowing raw addresses. This increases portability across Qsys designs.
VERIFIED COMPETENCY MILESTONE
04
Download, run and debug via JTAG
Use a USB-Blaster to download code to the FPGA, set breakpoints, step, and inspect registers and memory to diagnose runtime behavior during development.
VERIFIED COMPETENCY MILESTONE
