Module 9 › Chapter 8.4 › Hands-on Activity
Steps
  1. Add a pushbutton PIO in Qsys and regenerate the system file.
  2. In NIOS II SBT, regenerate the BSP so system.h contains PIO_BUTTON_BASE.
  3. Write code to read the button and toggle led_pattern; call the print function when pressed.
  4. Download program via JTAG and use a breakpoint inside the handler to inspect the GPIO register value.
Example snippet
/* Read button and toggle */
alt_u32 btn = IORD_ALTERA_AVALON_PIO_DATA(PIO_BUTTON_BASE);
if (btn) {
  /* toggle pattern and print */
  printf("Button pressed!
");
}
Use the debugger to pause when the printf is called and verify that the button register holds the expected bit pattern.
