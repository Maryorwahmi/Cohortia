Comparison

JTAG UART vs STDOUT UART

JTAG UART: connected via the JTAG debugger, convenient for development, appears in the Eclipse console.
STDOUT UART: a physical UART wired to a host serial port or USB-UART, useful for standalone operation after debugging.
Confirm which UART the BSP designates for stdout; the BSP controls routing so your print calls work as expected.
Example
In your button-lab, call the print function when a press is detected: "Button pressed!" If the JTAG UART is present, this message appears in the Eclipse console when you run the program under the debugger.
Practical note
If you see no output, check that a UART device exists in Qsys and that the BSP was regenerated after adding it. Also verify the Eclipse console is set to read the correct UART stream.
