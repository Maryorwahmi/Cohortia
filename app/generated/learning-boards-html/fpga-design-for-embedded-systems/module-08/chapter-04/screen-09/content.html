Module 9 › Chapter 8.4 › JTAG Debugging
Steps
  1. Connect USB-Blaster: attach the cable to the DE10-Lite board and your workstation.
  2. Start debugger: use the SBT Eclipse debugger to download and run your program on the FPGA.
  3. Set breakpoints: pause execution at a code line of interest and inspect variables or memory.
  4. Step and resume: step line-by-line or resume to observe peripheral interactions in real time.
When inspecting variables, confirm types match driver expectations and watch for volatile-qualified registers which can change outside the CPU.
Example
Set a breakpoint in a button press handler. Press the hardware pushbutton and the debugger will pause at the handler so you can inspect the GPIO data register and the led_pattern variable value to confirm correct behavior.
Watchout
Remember that stepping through code changes timing; bugs that depend on precise timing may not appear when stopped and stepped, so supplement with logging via UART when needed.
