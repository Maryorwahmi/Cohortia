Hands-on Activity Browse and generate IP
Practical tasks and checkpoints
Task list
  1. Open Quartus Prime IP Catalog and locate entries: UART, SPI, I2C, DDR3 Controller, PCIe Gen3 x8, FFT, FIR, NIOS II.
  2. Write a one-sentence description for each IP core you find.
  3. Choose one IP (suggested: UART) and configure parameters like baud rate and parity.
  4. Generate the IP instance and inspect the generated files for instantiation templates and simulation models.
  5. Run the included example design or simulation to validate functionality.
  6. Document your verification steps and justify the choice of parameters in one paragraph.
Checkpoints
  • Instantiation template identified.
  • Simulation model file found.
  • Example project or testbench runs succesfully.
  • Written justification and short validation notes.
