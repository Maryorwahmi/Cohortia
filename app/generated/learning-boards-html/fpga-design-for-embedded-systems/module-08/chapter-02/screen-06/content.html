Definition Soft IP
HDL sources and portability
Soft IP arrives as HDL source code you can synthesize for different FPGA targets. This makes it ideal when you need to adapt or understand the implementation details.
  • Customizable: edit parameters or integrate company-specific features.
  • Portable across vendors when written in standard HDL.
  • Performance depends on synthesis and device resources.
Example
A soft UART controller provided in Verilog that you adapt to add parity modes or custom FIFO behavior before synthesis for your target FPGA.
Practical note
When using soft IP, run synthesis and timing analysis early to reveal whether performance targets are reachable on your chosen FPGA.
