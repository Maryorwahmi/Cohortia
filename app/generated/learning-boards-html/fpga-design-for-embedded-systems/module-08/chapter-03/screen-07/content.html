Comparison

Core types at a glance

Economy
Lowest resource usage; suitable for simple control code; typically no caches.
Standard
Middle ground with instruction cache options to speed code fetches.
Fast
Highest performance, supports instruction and data caches; best for compute-intensive code.
Configuration details
JTAG debug module
Enable to allow source-level debugging using the USB-Blaster. Useful while developing firmware.
Custom instructions
Add hardware-accelerated operations when a computation is a hot spot; adds HDL work to integrate.
Cache trade-offs
Caches increase performance but complicate determinism. If code fits in on-chip RAM, caches may be unnecessary.
Pro tip

Start with Economy or Standard during bring-up. Enable Fast and caches after verifying functional correctness to measure performance gains.
