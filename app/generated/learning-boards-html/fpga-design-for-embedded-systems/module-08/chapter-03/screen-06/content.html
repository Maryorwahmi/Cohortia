Definition

Avalon Memory-Mapped Interface

A synchronous bus protocol for read and write transactions between masters and slaves, with optional flow control via waitrequest.

Core signals
  • address: target register or memory location
  • read / write: transaction type
  • writedata / readdata: payload
  • waitrequest: slave-driven flow control
Example
NIOS II writes to UART transmit register; the interconnect routes it and the UART responds when ready, possibly using waitrequest cycles.
Misconception

Avalon does not guarantee single-cycle access; waitrequest lets slaves stall transactions which the interconnect supports.

Transaction flow
Visualizing a typical read transaction helps embed the signals into your mental model.
Read sequence (conceptual)
  1. Master asserts address and read
  2. Interconnect decodes address and routes to slave
  3. Slave may assert waitrequest until data ready
  4. Slave places readdata, deasserts waitrequest
  5. Interconnect returns data to master
Why it matters
Knowing how waitrequest affects timing informs where to place time-critical code and when on-chip memory is preferable for deterministic access.
