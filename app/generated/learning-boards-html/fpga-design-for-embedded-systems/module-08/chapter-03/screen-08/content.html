Definition

On-chip memory characteristics

Implemented in FPGA block RAMs, on-chip memory is low-latency and deterministic, ideal for storing code and small datastructures.

Size selection
Choose enough space for code and stack. Example: 64 KB is sufficient for simple embedded demos and Hello, World programs.
Type
RAM for read/write program/data regions; ROM when storing fixed tables or boot code.
Key Takeaway

On-chip memory simplifies design and speeds access, but plan capacity carefully and move large data to external memory when needed.

Practical example
For the lab, configure a 64 KB on-chip RAM to hold program code and small data structures. This allows deterministic execution and easy bring-up without an external controller.
Why not always use external SDRAM?
External memory needs a controller, pins, and may introduce variable latency and waitstates. It is necessary for large applications but overkill for tiny demos.
Benefit
Deterministic access time
Limitation
Limited capacity vs external SDRAM
