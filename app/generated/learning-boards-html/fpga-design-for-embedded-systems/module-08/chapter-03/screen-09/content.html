Peripherals

UART, Timer, GPIO settings

UART
Set baud (e.g., 115200), data bits, parity, and stop bits. Software writes transmit bytes to the TX register defined by the base address.
Timer
Choose number of timers and resolution; timers are used for delays, timeouts, and periodic interrupts that the software handles.
GPIO
Specify input/output bit width. Example: an 8-bit output drives eight LEDs; toggle bits to blink LEDs from firmware.
Software implication
Use generated header constants for base addresses and offsets to access peripheral registers. This avoids hard-coded addresses and eases portability.
Concrete example
Configure UART at 115200, add an 8-bit GPIO for LEDs, and a timer with a 1 ms resolution for blinking logic in firmware.
Common mistake

Mismatched UART settings between firmware and terminal produce unreadable output; verify baud and parity on both ends.
