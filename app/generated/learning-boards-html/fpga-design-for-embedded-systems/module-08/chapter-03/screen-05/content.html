Process

Platform Designer workflow

1. Open Platform Designer
Tools → Platform Designer in Quartus Prime.
2. Add processor and memory
Add a NIOS II core and an on-chip RAM sized for your application, e.g., 64 KB for small demos.
3. Add peripherals and connect
Include UART, timer, and GPIO. Connect via Avalon MM and assign base addresses.
4. Generate system
This step produces HDL, instantiation templates, and C headers with base addresses.
5. Instantiate in top-level design
Use the generated module name and wire its ports to board pins for UART and GPIO.
6. Build embedded software
Use the NIOS II SBT or Eclipse to create a C project that uses generated header files for peripheral addresses.
7. Program and test
Program FPGA, run the program, and verify UART output and GPIO behavior like LED blinking.
Common mistake

Overlapping base addresses cause peripherals not to respond; always review the address map before generation.
