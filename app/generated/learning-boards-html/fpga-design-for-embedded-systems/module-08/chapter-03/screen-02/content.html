Add NIOS II, memory, and peripherals

Place processor, RAM, UART, timer, and GPIO in Platform Designer to form the system. This matters because visual assembly speeds iteration and avoids manual bus wiring.

02
Explain Avalon Memory-Mapped behavior

Describe address, read/write, data, and waitrequest signals and how transactions move through the interconnect fabric. This helps you diagnose latency and bus conflicts.

VERIFIED COMPETENCY MILESTONE
03
Configure the NIOS II core

Choose core type, caches, and debug options to balance performance and resources. This affects code speed, debug capability, and FPGA utilization.

VERIFIED COMPETENCY MILESTONE
04
Generate HDL and integrate into Quartus

Produce the system files, instantiate the top-level module, and build a software image that uses generated headers. This completes the hardware-software flow.
