Architecture

Interconnect fabric roles

Address decoding
Routes each address to its peripheral using the base address and offsets you assigned in Platform Designer.
Arbitration
If multiple masters exist, the fabric decides which master accesses a slave at a time to avoid bus conflicts.
Flow control
Waitrequest is passed to masters when a slave needs to stall, ensuring correct timing across devices.
Memory map example
Platform Designer generates a unified address map; typical assignments might place UART at 0x00001000 and timer at 0x00002000. Confirm these values in the GUI and generated headers.
Troubleshooting tip
If a peripheral doesn't respond, check for address overlap and inspect waitrequest behavior in the generated HDL or with simulation tools.
Reflective question

How will you validate that each peripheral's base address is unique and correct before generating HDL?
