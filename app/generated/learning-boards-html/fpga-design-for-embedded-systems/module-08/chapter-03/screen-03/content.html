Objective Context

This screen ties each objective to the hands-on activity: a NIOS II/f core, 64 KB on-chip RAM, one UART at 115200 baud, a timer, and an 8-bit GPIO for LEDs.

01 — Assemble components

Practical tip: place processor and RAM first so address map defaults are easier to manage. This reduces mistakes when assigning peripheral addresses later.

02 — Understand Avalon transactions

Remember: read/write, address, data, and waitrequest are essential signals your software's register access relies on.

VERIFIED COMPETENCY MILESTONE
03 — Configure core options

Choose Economy for resource-savings, Fast for cache and performance; enable JTAG debug if you need step debugging via USB-Blaster.

04 — Generate and integrate HDL

After generation, instantiate the system module in your top-level Verilog and map UART and GPIO pins to the board connectors for testing.
