Software build and example

Include the generated header with base address constants and use them to access peripheral registers in C. The SBT for Eclipse integrates these headers into your project automatically.
Example snippet (conceptual)
/* Pseudocode using generated base address macros */
#define UART_BASE 0x00001000
#define UART_TX   (UART_BASE + 0x00)
#define GPIO_BASE 0x00003000

/* Send a character */
*((volatile unsigned int *)UART_TX) = 'H';

/* Toggle LEDs */
*((volatile unsigned int *)GPIO_BASE) ^= 0x01;
Use real generated macros from the Platform Designer headers in your project rather than these placeholders.
Lab flow summary
  1. Generate system and headers
  2. Create NIOS II C project in SBT for Eclipse
  3. Use headers to access UART and GPIO
  4. Build, program FPGA, and observe UART output and LEDs
Test checklist

Confirm UART settings in terminal, verify pin assignments for UART and GPIO, and ensure the firmware uses the generated header constants.
