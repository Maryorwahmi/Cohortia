Lab Walkthrough

Build the demo SoC and run Hello, World

Step sequence
  1. Create Platform Designer system and add NIOS II/f.
  2. Add 64 KB on-chip RAM, UART, timer, and 8-bit GPIO.
  3. Connect Avalon interfaces and assign base addresses.
  4. Generate system and headers, then instantiate in top-level Verilog.
  5. Build firmware using generated headers and program FPGA.
  6. Open terminal at 115200 and verify UART output and LED blink.
Common pitfalls
Pin mismatches, overlapping addresses, and wrong UART settings are the most frequent causes of failure during testing.
Concrete checks
  • Confirm generated header lists the expected base addresses.
  • Ensure top-level instantiation wires ports to correct board pins.
  • Verify terminal baud and parity match UART configuration.
Try this

After successful bring-up, change GPIO width or timer resolution and regenerate the system to see how headers and HDL adapt.
