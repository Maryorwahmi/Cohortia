Code pattern
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;
use IEEE.NUMERIC_STD.ALL;

process
begin
  a <= "0101"; b <= "0011"; wait for 10 ns;  -- apply vectors and wait
  assert (sum = "1000" and cout = '0') report "Test 1 failed!" severity error;
  ...
  report "All tests completed!";
  wait;  -- suspend forever
end process;
This panel shows the typical sequencing: assign, wait, assert, repeat, then wait to end.
Explanation bullets
  • Use wait for to advance simulation time by explicit nanoseconds.
  • Sequence of assignments acts like a test script for the DUT.
  • Conclude with wait; so the stimulus stops and does not repeat.
  • For sequential DUTs, align stimulus timing with clock edges for determinism.
Example
Apply 0101 and 0011, wait 10 ns, expect sum 1000 and carry 0.
