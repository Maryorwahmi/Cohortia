Module 05 › Chapter 5.3 › Key Concepts
Testbench entity
An entity without ports used only for simulation and verification.
Timing control
Use wait for for delays and wait to suspend a process forever at test end.
Assertions
assert with report and severity makes tests self-checking and suitable for regression.
Summary takeaway

Design your testbench as a small, repeatable test program with deterministic timing, clear checks, and readable output for efficient verification in ModelSim.
