Module 05 › Chapter 5.3 › Reset Generation
Reset snippet
process
begin
  rst <= '1';
  wait for 20 ns;
  rst <= '0';
  wait;
end process;
This pattern asserts reset for a defined interval and then releases it once before suspending.
Notes & tips
  • Align reset deassertion with clock edges for synchronous designs.
  • Use wait to suspend the reset process after the one-time sequence.
  • Document reset polarity and duration so tests are repeatable.
