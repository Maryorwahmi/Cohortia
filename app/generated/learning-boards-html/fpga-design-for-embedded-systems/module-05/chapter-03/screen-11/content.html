Quick workflow
  1. Compile DUT and testbench files into the work library.
  2. Load the testbench simulation in ModelSim.
  3. Add signals and enumerated types to the waveform.
  4. Run simulation and watch assertions or transcript output.
Why enumerated types help
When states are declared as enumerations, ModelSim displays state names in the waveform. This is far easier to interpret than numeric codes and speeds debugging of FSMs.
Remember to add the enumerated signal to the waveform so that textual labels appear during the run.
