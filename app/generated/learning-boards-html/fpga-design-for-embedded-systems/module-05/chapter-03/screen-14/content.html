Module 05 › Chapter 5.3 › Common Mistakes
Checklist
  • Mirror DUT types (unsigned vs std_logic_vector).
  • Terminate stimulus with wait; to avoid repeats.
  • Align serial updates to clock edges for FSMs.
  • Write descriptive report messages for asserts.
  • Add enums to waveform for readable state names.
Quick fixes
If an assert fails: check the transcript message, verify applied vectors and waits, and ensure the bench and DUT types match.
Key Takeaway
A short checklist makes debugging systematic and efficient instead of trial and error.
