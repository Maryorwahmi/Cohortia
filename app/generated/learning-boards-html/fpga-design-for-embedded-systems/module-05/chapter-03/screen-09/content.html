Module 05 › Chapter 5.3 › Instantiation Comparison
Direct entity instantiation
uut: entity work.adder generic map (WIDTH => 4) port map (A => a, B => b, SUM => sum, COUT => cout);
Use this when the entity is present and you prefer explicit, modern syntax.
Component instantiation
Declare component in the architecture, then instantiate it. Useful for top-down development when the entity source might be compiled later.
Tip: component declarations must match the eventual entity interfaces exactly to avoid mismatches at link time.
Practical rule
Choose direct instantiation for simplicity; choose component style when compiling testbenches early in a top-down flow.
