Module 05 › Chapter 5.3 › Assertions & Reports
How it works
assert (condition) report "message" severity error; will evaluate the condition and, on failure, print the message and mark the simulation according to severity.
Severity choices: note, warning, error, failure. Use error for failing functional checks in tests.
Include test identifiers in messages to trace failing vectors across runs.
Example message
Failure example
assert (sum = "0000" and cout = '1') report "Test 2 failed!" severity error;
Tip: use concise, unique messages so log search and automated parsers can detect failing tests quickly.
