Module 6 › Chapter 5.4 › Hands-on Activity
Task steps
  1. Translate the Verilog module interface to a VHDL entity with explicit port types and widths.
  2. Implement the ALU behavior in a VHDL architecture, using explicit conversions where needed.
  3. Write a VHDL testbench that exercises all operations and uses enumerated types for control signals when appropriate.
  4. Run simulations and document where type conversions or resizing were necessary.
  5. Write a one-page summary comparing lines of code, readability, and which language helped catch errors earlier.
Concrete hints
When porting, explicitly document each conversion and test the ALU outputs for width and sign handling. Use enumerated control signals to label operations in waveforms for faster debugging.
Key Takeaway

This exercise exposes type-system differences and shows how explicit conversions help prevent subtle runtime mismatches.
