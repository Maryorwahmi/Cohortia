Module 6 › Chapter 5.4 › Type Systems
Definition
Weak typing vs strong typing
Weak typing allows implicit conversions and silent truncation. Strong typing requires explicit conversions and resizing.
Verilog (weak)
Connections between wires and registers often happen without explicit casts. Watch for silent width changes.
VHDL (strong)
Port and signal types must match, or you must call conversion and resize routines to make intent explicit.
Concrete scenario
Imagine connecting a 4-bit result to an 8-bit bus. In a weakly typed language, bits may be dropped silently; in a strongly typed language, the compiler forces you to express whether to sign-extend, zero-extend, or resize explicitly.
Misconception
Strong typing only slows you. In practice it reduces debugging time by surfacing errors earlier in the flow.
Check
Before committing code, scan assignments for width and type mismatches. If converting, add explicit conversions or resizing functions.
