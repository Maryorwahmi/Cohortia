Module 6 › Chapter 5.4 › Common Misconceptions
Frequent pitfalls
Be aware of assumptions that hide errors or slow integration.
  • Thinking one language yields better hardware by default.
  • Assuming port type equivalence across languages without checking signedness.
  • Ignoring enumerated types and making waveforms hard to read.
  • Not following a wrapper checklist for mixed-language IP.
Mitigations
Adopt short integration checklists, require explicit conversions in code reviews, and use enumerated types for state machines to speed debugging.
Pro tip
Create template wrappers for common IP to ensure consistent type and polarity mappings across projects.
