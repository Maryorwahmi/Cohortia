Module 6 › Chapter 5.4 › Mixed-Language Design
Process
Instantiate across languages
Declare a compatible component or module signature and verify widths and directions before instantiation.
Step 1
Create a wrapper that explicitly declares ports and types to mirror the external IP.
Step 2
Test the wrapper in isolation with a minimal testbench before integrating into the full design.
Step 3
Confirm signedness, bit widths, and reset polarity match expected behavior.
Concrete code example
The chapter shows a VHDL component declaration matching a Verilog module's ports: clk, rst, an 8-bit input, and an 8-bit output. The tool links them when the project is elaborated.
Pitfall
Assuming type equivalence without a wrapper. Always verify mapping for signed versus unsigned vectors and any required conversions.
