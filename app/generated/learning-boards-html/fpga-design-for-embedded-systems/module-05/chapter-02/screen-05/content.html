Definition
Simple concurrent assignment
A concise way to express combinational gates and direct relationships between signals.
Concrete example
Y <= A and B;  -- updates when A or B changes
This is functionally equivalent to a gate: Y = A & B in other languages. Check waveforms to confirm immediate recomputation.
Example: Conditional select
A readable multiplexer using conditional assignment.
Y <= A when SEL = "00" else  B when SEL = "01" else  C when SEL = "10" else  D;
Misconception
Concurrent is not sequential: do not rely on ordering or process triggers to evaluate these statements.
Check
Run a simulation and toggle SEL and inputs to confirm the output switches immediately without a clock edge.
