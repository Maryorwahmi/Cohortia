Clocked process and rising_edge
Sequential updates occur on clock edges; use rising_edge for clarity and safety.
process (clk) begin  if rising_edge(clk) then   if rst = '1' then    q <= (others => '0');   elsif en = '1' then    q <= d;   end if;  end if; end process;
Explanation & tips
  • Place synchronous reset inside rising_edge to have reset sampled by the clock.
  • Use others => '0' to initialize vectors concisely during reset.
  • Signals assigned inside the clocked branch update after the process finishes, modeling registers.
Misconception
Using clk'event and clk = '1' is less explicit and more error prone than rising_edge.
Key Takeaway

Use rising_edge for edge detection and put resets and enables inside the edge branch to create reliable registers.
