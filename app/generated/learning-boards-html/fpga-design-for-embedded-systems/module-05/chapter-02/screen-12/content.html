Sequence detector plan
Break the FSM into clear states representing matched prefixes and test with a simple bench that applies bits over time.
State enumeration sample
type state_type is (S0, S1, S10, S101, S_MATCH); signal state, next_state : state_type;
Testbench checklist
  • Drive clock and apply the input sequence, including overlapping patterns, and observe state name changes.
  • Verify outputs assert when the final pattern is recognized and that resets return to initial state.
  • Compare readability versus Verilog and note where enumeration helped.
Reflection
When you finish, ask: did enumerated names make the waveform easier to understand and did signals update only at clock edges?
