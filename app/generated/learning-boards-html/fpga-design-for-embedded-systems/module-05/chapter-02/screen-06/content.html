Process Flow
Combinational processes
Use processes when procedural clarity is needed; the sensitivity list drives execution.
Example
process (A, B, SEL) begin  if SEL = "00" then   Y <= A;  elsif SEL = "01" then   Y <= B;  else   Y <= D;  end if; end process;
Explanation bullets
  • A process with a full sensitivity list is equivalent to combinational concurrent assignments.
  • Missing an input can create a latch; list every read signal explicitly.
  • Use variables inside the process for intermediate values but remember their immediate update semantics.
Common mistake
Copying a sequential process into combinational context without updating sensitivity lists leads to mismatch between simulation and synthesis.
Key Takeaway

Always keep sensitivity lists complete for combinational processes to avoid unintended storage elements.
