Definition
Counters and numeric types
Use unsigned for arithmetic and initialize with others => '0' during reset.
process (clk) begin  if rising_edge(clk) then   if rst = '1' then    count <= (others => '0');   elsif en = '1' then    count <= count + 1;   end if;  end if; end process;
Explanation
  • Declare count as unsigned to use + without conversions.
  • If you must use std_logic_vector, perform conversions with to_unsigned or to_integer carefully.
  • Decide width based on wrap-around and overflow needs.
Pro tip
Favor numeric types for arithmetic; explicit conversions are clearer and safer for synthesis.
