Definition
Signals vs Variables
Different update timing and scope make each appropriate for different tasks inside a process.
process (clk) variable temp : unsigned(7 downto 0); begin  if rising_edge(clk) then   temp := a + b;   sum <= temp;  end if; end process;
Here temp updates immediately and sum is scheduled, matching register behavior at the process boundary.
Explanation & pitfalls
  • Use variables for intermediate calculations where immediate feedback matters inside the process.
  • Avoid expecting signals to have their new value until after the process completes; this leads to logic bugs.
  • Signals create visible communication across processes and must be used for registers and outputs.
Common mistake
Confusing variable and signal timing inside a clocked process and relying on immediate signal changes within the same process.
