Core Concept
Concurrent signal assignments
Declarative expressions that map to combinational hardware. They are evaluated continuously as inputs change and do not represent sequential steps.
  • Conditional signal assignment: readable multiplexer style with when/else chains.
  • Selected signal assignment: compact case-style selection with with ... select.
  • Always ensure the assignment covers all choices to avoid unintended latches.
Example
Y <= A when SEL = "00" else B when SEL = "01" else C when SEL = "10" else D;
Key Takeaway

Prefer concurrent conditional/select assignments to express multiplexers and combinational mapping clearly and synthesizably.

Why this matters
Combinational logic described concurrently is easier to reason about and maps predictably to gates. Simulation shows signals update as soon as inputs change, without waiting for a procedural step.
Common mistake
Using incomplete conditional coverage or mixing sequential intent into concurrent assignments can synthesize latches or create mismatches with simulation.
Pro tip
When designing multiplexers, prefer the selected form for clarity when selecting many cases from a vector selector.
