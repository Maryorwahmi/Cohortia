Architecture
FSM pattern with enumeration
Define states with an enum and split register and next-state logic for clarity and simulation friendliness.
Example types
type state_type is (GREEN, YELLOW, RED); signal state, next_state : state_type;
Next-state process
List state and inputs in the sensitivity list and use case statements to assign next_state.
process (state, timer_done) begin  case state is   when GREEN =>    if timer_done = '1' then next_state <= YELLOW; else next_state <= GREEN;    end if;   when others =>    next_state <= GREEN;  end case; end process;
Why enumerate?
Enumerated states improve readability, allow named states in waveforms, and let synthesis assign efficient encodings automatically.
