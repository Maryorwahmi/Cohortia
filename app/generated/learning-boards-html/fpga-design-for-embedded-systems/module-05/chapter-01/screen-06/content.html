STD_LOGIC and the 9-value model
Use the STD_LOGIC_1164 package to get robust signal behavior in simulation and tri-state modeling.
0: logic zero
1: logic one
Z: high impedance
X: unknown
U: uninitialized
- and weaker drive states
Practical note: declare libraries at the top of your file so types are visible to entities and architectures. For arithmetic, import IEEE.NUMERIC_STD and choose unsigned or signed explicitly.
Concrete example
A bus declared as std_logic_vector(7 downto 0) can show unknown bits during reset, making initialization errors visible in the waveform.
Common misconception
Do not use std_logic_vector directly for arithmetic; convert to unsigned or signed before adding.
Key Takeaway

Use std_logic for realistic simulation and NUMERIC_STD for arithmetic with explicit conversions.
