Generic adder pattern
Declare WIDTH as a generic and size ports and internal signals from it.
entity adder is
  generic(WIDTH : integer := 8);
  port(
    A : in unsigned(WIDTH-1 downto 0);
    B : in unsigned(WIDTH-1 downto 0);
    SUM : out unsigned(WIDTH-1 downto 0);
    COUT : out std_logic
  );
end entity adder;
Instantiation example
Override WIDTH with a generic map when connecting this component in a higher-level design.
Key Takeaway

Generics keep your entities flexible and reduce duplicated code across different bit widths.
