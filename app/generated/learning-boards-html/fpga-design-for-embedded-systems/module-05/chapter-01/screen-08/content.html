Typical file header
Import standard packages to enable std_logic types and numeric operations.
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;
use IEEE.NUMERIC_STD.ALL;
These statements are required for std_logic, std_logic_vector, unsigned, and signed types.
Code structure
Entity first, then architecture. Declare generics in the entity so implementations can use them.
Concrete example
An adder uses WIDTH generic in the entity and a temp signal sized WIDTH downto 0 in the architecture to capture carry.
Misconception
Skipping numeric library declarations will prevent arithmetic operations from compiling.
