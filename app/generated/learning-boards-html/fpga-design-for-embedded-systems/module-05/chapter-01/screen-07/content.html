Module 5 › Chapter 5.1 › Comparison
std_logic_vector
A vector of std_logic bits. No numeric semantics by default.
Use when you need bit-level control or bus wiring. Convert to numeric types for arithmetic.
unsigned / signed (NUMERIC_STD)
Provide numeric interpretation for arithmetic and comparisons.
Use unsigned for non-negative arithmetic. Use signed for two's complement where negatives matter.
Example
Add two 8-bit unsigned vectors directly after declaring them as unsigned types.
Mistake
Trying to use '+' on std_logic_vector without conversion causes an error or unexpected behavior.
Key Takeaway

Pick numeric types for arithmetic and keep std_logic_vector for bit manipulation and interconnects.
