Module 5 › Chapter 5.1 › Hands-on Activity
Task outline
Write a 2-to-1 multiplexer entity and architecture using a WIDTH generic and simulate it at two widths.
Steps: 1) Declare libraries. 2) Create entity with generic WIDTH. 3) Implement architecture using concurrent assignment or a process. 4) Instantiate in a top-level design and override WIDTH. 5) Simulate waveforms.
Outcome

A reusable multiplexer that you can test at 8 and 16 bits, and a verified waveform showing correct selection behavior.

Common mistakes to check
  • Mismatched WIDTH expressions between instance and signal
  • Forgetting to import NUMERIC_STD when doing arithmetic
  • Reading uninitialized signals showing 'U' in waveforms
Pro tip
Prefer downto for vectors to keep MSB on the left and make slices predictable across modules.
