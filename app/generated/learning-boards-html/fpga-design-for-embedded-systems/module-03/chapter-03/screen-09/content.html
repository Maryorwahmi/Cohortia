Module 4 › Chapter 3.3 › RTL Viewer vs Technology Map Viewer
RTL Viewer
Shows the generic netlist from synthesis: gates, multiplexers, and inferred flip-flops. Useful for verifying how HDL was interpreted.
Use case
Confirm registers and check for unintended latches or incorrect behavioral inference.
Technology Map Viewer
Shows actual LUT instances, CLB registers, and carry chains after mapping to device primitives.
Use case
Count LUTs, identify carry chains, and verify register placement for timing analysis.
Workflow tip

If timing or resource counts surprise you, locate the path in a timing report, inspect the RTL netlist to find the logical source, then open the Technology Map Viewer to see the mapped LUTs and registers to guide optimization.
