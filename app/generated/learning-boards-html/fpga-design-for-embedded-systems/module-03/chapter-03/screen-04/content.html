Process

From code to gates

Synthesis infers logic elements and clocked registers without yet considering device primitives. The output is a generic netlist you can inspect.

Example netlist view
// Synthesis inferred gates
// AND gate for A and B
// OR gate combining two ANDs
// D flip-flop inferred from rising-edge block
Misconception
Synthesis preserves behavior; it will not silently change a latch to a flip-flop unless your code signals a clocked transfer.
Pro tip
Write explicit combinational statements and explicit clocked blocks to avoid unintended latches.
Why this matters
  • Netlist shows the actual logical elements the mapper will pack into LUTs.
  • Inspecting the RTL Viewer verifies your HDL was interpreted correctly.
  • Identifies unintended inferred latches or missing registers early.
Key Takeaway

Synthesis creates the intermediate gate-level netlist used by technology mapping to allocate FPGA primitives.
