HDL patterns that help
  • Use arithmetic operators so adders map to carry chains.
  • Factor common subexpressions to reduce distinct inputs to a LUT.
  • Add pipeline registers to split long combinational paths and reduce routing delay.
Common misconceptions

Believing the mapper always finds the globally optimal packing. In practice, small code rewrites and constraints help the mapper produce better results.

Pro tip

Iterate: synthesize after changes and compare the Technology Map Viewer to confirm improvements.
