Module 4 › Chapter 3.3 › Placement and Routing
What happens next

Placement assigns mapped LUTs and registers to physical CLBs; routing connects nets. These steps affect timing even after mapping looks correct.

Practical checks
  • Run post-route timing analysis to find critical nets introduced by routing.
  • Inspect placed instances in the technology map to see physical grouping.
  • Consider pipelining or constraints when routing delay is too high.
Why this matters

Even an optimal mapping can fail timing if placement scatters critical path elements or routing uses long nets. Mapping is necessary but not sufficient for timing closure.

Common mistake

Assuming mapped LUT count guarantees timing. Only post-placement timing reports confirm critical path delays after routing.
