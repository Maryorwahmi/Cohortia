Module 3 › Chapter 3.2 › D Flip-Flop
Behavior
Captures D at the active clock edge and holds it until the next capture. Changes between edges are ignored.
Concrete example: A single-bit write-enable register stores a status flag at each rising clock edge when clock enable is asserted.
FPGA controls: clock enable, synchronous reset, asynchronous reset, and preset affect when and how the stored bit changes.
Misconception: The D input is not sampled continuously; only the value around the edge is relevant.
Key Takeaway

D flip-flops are the standard memory primitive; design decisions like enabling and resets determine write behavior in hardware.

Example: Register as 8 D flip-flops
An 8-bit register is eight D flip-flops that share a clock. On a rising edge, each D is captured and the 8-bit value becomes stable on outputs until the next edge.
Scenario: pipeline freeze
Use clock enable to prevent capturing new data, which effectively stalls the pipeline without gating the global clock and avoiding timing hazards.
Check your understanding
If you need to synchronously clear a register at the next edge, use synchronous reset; asynchronous resets change the value immediately and can violate synchronous assumptions if used carelessly.
