Design steps
Create an N-stage shift register, invert the last stage, and feed it into the first. Simulate to observe the 2N-state sequence.
Step: Draw state diagram showing transitions for each clock pulse.
Step: Write Verilog assigning next state as concat of internal bits and inverted last bit.
Step: Simulate and count distinct states to verify 2N behavior.
Concrete example: 4-bit Johnson
With N=4 you will see eight unique states. Decoding specific patterns can be simpler than decoding a binary counter for certain applications like LED sequences or detector windows.
Comparison
Johnson: 2N states, simple shift feedback. Binary: 2^N states, more complex decoding for some patterns. Choose based on state count and decoder complexity.
