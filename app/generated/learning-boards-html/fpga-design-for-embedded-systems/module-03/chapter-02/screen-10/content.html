Module 3 › Chapter 3.2 › Timing Parameters
Key Definitions
Setup time (tsu): D must be stable for this minimum before the clock edge.
Hold time (th): D must remain stable for this minimum after the clock edge.
Clock-to-Q (tco): Delay until Q is valid after the clock edge.
Interpretation
Together these define when inputs must be stable and when outputs become usable. Violations lead to metastability or incorrect captures.
Worked calculation
Given tco, tpd, and tsu, compute minimum T_clock: T_clock > tco + tpd + tsu. For instance, if tco=3 ns, tpd=8 ns, tsu=2 ns, then T_clock > 13 ns so f_max ≈ 76.9 MHz. Running faster risks violating setup and producing metastability.
Misconception
Only looking at combinational delay ignores tco, which can make downstream registers sample invalid data if tco is long.
Try this
Compute the clock limit for several paths in your design. If a path is too slow, add registers to split combinational delay and recompute.
Real measurement: tools and timing reports provide tco and tpd estimates post-synthesis to guide clock choices and register placement.
