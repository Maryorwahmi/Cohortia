Module 3 › Chapter 3.2 › Sequential vs Combinational Logic
Definition
Sequential logic uses stored state in addition to inputs to determine outputs. Memory elements update on a clock edge.
Example: A single flip-flop remembers whether an event occurred last cycle so the circuit can react differently this cycle.
Misconception: Registers are not wires. They only change value at clock edges, so timing rather than connectivity controls behavior.
Why it matters: State allows counters, pipelined datapaths, and finite state machines needed for protocols and control logic.
Key Takeaway

Decide which signals require memory; converting combinational logic into sequential stages changes timing and resource use.

Illustration: pipeline stage cards
Register
Stores a value on a clock edge. Output drives combinational logic until next clock.
Combinational Logic
Performs operations on values from registers; its propagation delay affects clock period.
Concrete scenario: a multiply-accumulate datapath split across two pipeline stages uses registers to hold intermediate results. This reduces logic depth per cycle, letting the design run at a higher clock frequency while preserving correctness—if timing for each stage meets setup and hold constraints.
