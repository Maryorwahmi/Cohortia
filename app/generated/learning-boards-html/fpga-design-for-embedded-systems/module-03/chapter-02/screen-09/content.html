Module 3 › Chapter 3.2 › Shift Registers: SIPO & PISO
Patterns
SIPO: serial input, parallel output. PISO: parallel input, serial output. Both implement shifting by wiring Q to the next D in series.
Use case: UART receiver uses SIPO to collect bits into a byte.
Use case: SPI master uses PISO to send a register's bits serially over MOSI.
Variation: Johnson counter feeds inverted last bit back to first to create 2N states and simple decoding.
Concrete example
Implement an 8-bit SIPO: on each clock capture the incoming serial bit into the least-significant stage and shift older bits up. After eight clocks, the parallel outputs present the full byte.
Misconception
Shifting is not instantaneous across stages; each clock moves bits one position and timing must ensure data is stable at capture windows.
Try this
Design a PISO to load a byte and shift it out, then simulate to verify bit order and clock alignment for the receiving device.
Real-world connection: shift registers map directly to serial interfaces on embedded boards and are simple to test with LEDs or logic analyzers.
