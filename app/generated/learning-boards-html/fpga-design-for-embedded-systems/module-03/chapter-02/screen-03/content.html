Apply & Verify
Each objective includes a small verification task you can run in simulation or on hardware to confirm behavior and timing.
Register in HDL
Write a clocked always block to make an 8-bit register and inspect Q on rising edges.
Counter simulation
Run a 4-bit binary counter and verify sequence and rollover behavior.
Shift register test
Test SIPO by shifting in bits and reading parallel outputs after N clocks.
Timing calculation
Compute T_clock from tco, tpd, and tsu using example numbers to find f_max.
Each verification milestone helps confirm synthesis results and timing closure on FPGA toolchains.
Teaching mnemonic
Remember: flip-flops capture, registers group, counters sequence, shift registers move, and timing constrains the clock. Practice each step in simulation to see how violations appear as incorrect or metastable outputs.
