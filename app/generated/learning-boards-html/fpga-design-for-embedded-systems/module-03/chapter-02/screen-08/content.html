Counting Process
Each clock edge updates the stored value according to increment/decrement logic implemented in combinational logic feeding D inputs.
Step 1: Flip-flops hold current count.
Step 2: Combinational logic computes next value (e.g., add 1).
Step 3: On clock edge D captures the next value and becomes the new count.
Key Takeaway

Synchronous counters update all bits at once; modulo counters need detection and reset or conditional next-state logic.

Concrete example: 4-bit modulo-10 counter
Detect binary 1010 and force next state to 0000. Implement this detection combinationally and feed the D inputs so the counter wraps on the next clock.
Misconception
Ripple counters are asynchronous between bits and can cause transient incorrect values during toggling; synchronous counters avoid this by computing the full next state for all bits simultaneously.
