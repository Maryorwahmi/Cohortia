3-to-8 decoder
Three binary inputs select one of eight outputs. Useful for chip-select and address decoding in memory systems.
Priority encoder
When multiple inputs may be active, a priority encoder returns the code of the highest-priority active input for arbitration.
Concrete application
Use a decoder to enable a single memory bank. Use a priority encoder in an interrupt controller to report the highest-priority source.
