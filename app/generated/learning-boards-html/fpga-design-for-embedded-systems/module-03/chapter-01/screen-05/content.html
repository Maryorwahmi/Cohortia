Module 3 › Chapter 3.1 › Logic Gates
Gate list
AND — outputs high only if all inputs are high.
OR — outputs high if any input is high.
NOT — inverts input.
XOR — outputs high when inputs differ (parity).
NAND / NOR — complements of AND and OR; useful for universal implementations.
Truth table example
XOR truth table for A,B: 00→0, 01→1, 10→1, 11→0. Use this to derive sum in a half-adder.
Concrete example — half-adder
Sum = A XOR B. Carry = A AND B. Use these two gates to add single-bit numbers without carry-in.
Misconception check
XOR is not a noisy OR; it encodes parity. Confusing them leads to incorrect adder logic.
