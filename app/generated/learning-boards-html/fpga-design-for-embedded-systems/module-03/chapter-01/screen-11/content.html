Module 3 › Chapter 3.1 › Multiplexers
2-to-1 MUX
Y = (D0 AND NOT S) OR (D1 AND S). Use select lines to forward one input to output.
4-to-1 as universal mapper
Map function outputs to D0..D3 and use two select lines to implement any function of three variables. This is the basis for LUT logic.
Concrete example
Given a truth table, assign outputs to MUX data inputs so the correct output is selected by the selects. This reduces complex logic to structured multiplexing.
