Module 3 › Chapter 3.1 › 4-bit Adder/Subtractor
Design idea
Use full-adders with B XOR M to conditionally invert B. Set initial carry-in to M to implement two's complement subtraction.
Check
Simulate cases for M=0 (addition) and M=1 (subtraction). Watch for correct borrow behavior reflected in the carry-out bit.
Starter Verilog (behavioral)
Place this code in a file and simulate. The syntax expresses intent so synthesis will use carry primitives when available.
module addsub4(input [3:0] A, input [3:0] B, input M, output [3:0] S, output Cout);
  wire [3:0] B_xor;
  assign B_xor = B ^ {4{M}}; // invert B when M=1
  assign {Cout, S} = A + B_xor + M; // carry-in equals M for two's complement
endmodule
Pro-tip
Write arithmetic as expressions so synthesis recognizes adder patterns and uses fast carry-chain hardware rather than arbitrary LUT networks.
