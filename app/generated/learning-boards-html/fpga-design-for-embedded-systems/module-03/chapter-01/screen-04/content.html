Module 3 › Chapter 3.1 › Combinational Logic
Definition
A combinational circuit's outputs depend only on its current inputs. No storage elements, no memory of past values.
Properties
  • Deterministic mapping from inputs to outputs
  • No internal state or clocking required
  • Implemented as LUT functions in FPGA synthesis
Common misconception
Registers are not combinational; mixing them up can cause timing errors and incorrect synthesis assumptions.
Concrete example
A 2-to-1 multiplexer selects D0 or D1 based on S. The output at any moment equals the selected input; no history is considered.
Key Takeaway

Plan combinational outputs to be stable before clocked sampling to avoid glitches and timing violations.

Truth table

Why it matters
Combinational clarity helps synthesis and verification. When you separate combinational and sequential logic cleanly, timing closure becomes easier and resource usage is more predictable.
