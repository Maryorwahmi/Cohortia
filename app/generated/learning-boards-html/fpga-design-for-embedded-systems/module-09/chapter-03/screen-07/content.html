Module 9 › Chapter 9.3 › FIR Filter
Hardware FIR
Implement a 16-tap multiply-accumulate engine with fixed coefficients. Use shift-and-add or DSP blocks depending on available FPGA resources.
Pipeline
Break the MAC into stages to meet a 50 MHz constraint if needed. Pipelining increases throughput but adds latency.
Integration
Provide an Avalon slave that accepts blocks of samples or a streaming interface with ready/valid semantics. The NIOS II triggers a block run and reads outputs afterward.
Example Use
Trigger capture → move 256 samples into FIR → read 256 filtered outputs → send results to PC via UART.
