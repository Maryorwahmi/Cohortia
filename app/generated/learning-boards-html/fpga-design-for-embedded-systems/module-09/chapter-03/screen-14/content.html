Module 9 › Chapter 9.3 › Key Concepts
System Specification

Define interfaces, rates, buffer sizes, trigger rules, and deliverables before coding.

Hardware–Software Partitioning

Choose hardware for deterministic throughput, software for flexibility and fast iteration.

Verification & Documentation

ModelSim waveforms, Quartus timing, logic analyzer captures, terminal logs, and a demo video form the submission evidence.

Summary

A reproducible, well-documented design that balances hardware performance and software flexibility is the capstone goal.
