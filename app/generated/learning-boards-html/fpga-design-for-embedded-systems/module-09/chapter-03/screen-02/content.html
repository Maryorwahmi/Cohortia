System Design from Spec

Write a clear specification with block diagrams and performance targets. This skill ensures your system meets sample rates and capture sizes required for the oscilloscope project.

Qsys & IP Integration

Assemble NIOS II, ADC IP, UART, timers, GPIO, BRAM, and custom Avalon peripherals. Proper base-address and bus connections avoid runtime errors and ease software porting.

Verified competency milestone
03
Custom RTL & Verification

Implement adc_interface, circular_buffer, and fir_filter in Verilog, and verify each with ModelSim testbenches to prove correct behavior before synthesis.

Verified competency milestone
04
Software & Documentation

Write the NIOS II C application to manage acquisition, handle UART commands, and document the full project with diagrams, test results, and a demo video for grading.

Verified competency milestone
