Example Bug: Latch Inference
module mystery (
  input wire [3:0] a, b,
  input wire sel,
  output reg [3:0] y
);
  always @(*) begin
    if (sel)
      y = a; // Missing else causes latch inference
  end
endmodule
Fix: add an else or default assignment to avoid unintended latches.
Example Bug: Blocking in Sequential
always @(posedge clk) begin
  if (rst)
    count = 8'b0; // Use non-blocking <= for registers

    count = count + 1;
end
