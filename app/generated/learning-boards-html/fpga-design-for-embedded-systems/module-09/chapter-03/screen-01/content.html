Capstone: Build a Complete FPGA Embedded System

Design a digital oscilloscope: sample, buffer, filter, and stream. Combine NIOS II software with custom Verilog peripherals to demonstrate hardware-software co-design.

In this lesson
System spec, Qsys, Verilog, C, verification, demo.
Core focus
Hardware-software partitioning for real-time sampling.
Outcome
Working FPGA demo and a graded project report.
Explore Key Topics
System Spec
Define block diagrams, interfaces, and sample rates for a 1 MSPS ADC and 256-sample capture.
Qsys & IP
Integrate NIOS II, UART, ADC IP, timers, GPIO, and custom Avalon peripherals.
Verification
Use ModelSim testbenches, JTAG debugging, and logic analysis to prove behavior.
Visual Concept
NIOS II
Control, configuration, UART
Custom Verilog
ADC interface, circular buffer, FIR
Peripherals
UART, Timer, GPIO, BRAM
Deliverable
Working project, ModelSim testbenches, Quartus timing reports, demo video, and a written project report for grading.
