Architecture
Core Qsys Components
  • NIOS II/f with JTAG debug module.
  • 64 KB on-chip memory for program/data.
  • 8 KB dual-port BRAM used as ADC sample buffer.
  • MAX 10 ADC IP core connected to analog input.
  • UART IP (115200) to USB-UART bridge.
  • Timer IP for periodic interrupts; GPIO for buttons and LEDs.
  • Custom FIR peripheral connected via Avalon bus.
Integration Tips
Assign non-overlapping base addresses, connect IRQ lines for timer and UART if used, and validate clock and reset routing. Export the BSP and test UART early.
Quick Test
After Qsys generation, build the BSP and run a simple UART echo or status print to confirm system connectivity before adding custom RTL.
