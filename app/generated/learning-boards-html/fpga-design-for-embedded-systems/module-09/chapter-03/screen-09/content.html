Process Flow
1. Specification
Block diagrams and constraints.
2. Qsys
Assemble IP and addresses.
3. RTL
Verilog modules and testbenches.
4. Integration
Top-level and pin assignments.
5. Synthesis
Compile in Quartus and check timing.
6. Software
BSP and NIOS II application.
7. HW-SW Integration
JTAG load and run.
8. Test & Debug
Logic analyzer and terminal verification.
9. Documentation
Report, code listings, and demo video.
