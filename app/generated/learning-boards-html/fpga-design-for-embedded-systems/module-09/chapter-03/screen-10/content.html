Module 9 › Chapter 9.3 › Hardware vs Software
Hardware
  • ADC interface with precise sampling timing.
  • Circular buffer in BRAM for fast concurrent access.
  • FIR filter when per-sample latency and throughput are critical.
Software
  • UI handling, UART command parsing, and display formatting.
  • Non-critical DSP or configuration changes that benefit from flexibility.
  • Test and calibration routines that you will iterate in the field.
Decision Heuristic
If a function must process every sample at full rate, prioritize hardware. If it benefits from quick code changes, keep it in software.
