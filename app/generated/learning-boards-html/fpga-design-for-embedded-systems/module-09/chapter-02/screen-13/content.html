Module 9 › Chapter 9.2 › Lab Activity
Simulation Steps
  1. Simulate PWM with boundary duty values (0, mid, max) and measure high-time.
  2. Simulate ADC read/write sequence and duty register update transactions.
  3. Add assertions for duty register width and PWM frequency stability.
On-Board Checks
  • Observe LED brightness versus potentiometer position.
  • Confirm smooth brightness changes; add software smoothing if needed.
  • Measure PWM on an oscilloscope if available to confirm frequency and duty accuracy.
Key Takeaway

Start with thorough simulation, then perform controlled board tests. Synchronize register writes and limit update rates to prevent glitches.
