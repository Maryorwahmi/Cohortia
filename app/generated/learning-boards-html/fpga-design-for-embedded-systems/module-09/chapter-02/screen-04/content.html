Module 9 › Chapter 9.2 › FIR Definition
Formal Definition
y[n] = b[0]*x[n] + b[1]*x[n-1] + ... + b[N-1]*x[n-(N-1)]
Key points: finite memory N, coefficients b[k], linear convolution. The filter is linear and time-invariant for fixed coefficients.
Example
A 16-tap low-pass with 16-bit coefficients multiplies each of 16 delayed samples and sums them, yielding a 32-bit accumulator to avoid overflow.
Common misconception
Unrolling the loop does not change correctness: it only changes latency and throughput characteristics; careful fixed-point scaling is still required.
Concrete Design Elements
  • Delay line: shift register holding last N samples.
  • Parallel multipliers: one per tap, ideally mapped to DSP blocks.
  • Adder tree: reduces N products to a single sum with pipeline stages.
Key Takeaway

An FPGA implements the same FIR math but can produce a new output every clock cycle when multipliers and adders are instantiated in parallel and pipelined.
