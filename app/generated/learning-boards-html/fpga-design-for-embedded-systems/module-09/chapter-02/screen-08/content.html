Module 9 › Chapter 9.2 › Encoder Decoding
Verilog Snippet
module quadrature_decoder (
  input wire clk,
  input wire a,
  input wire b,
  output reg signed [31:0] position
);
  reg a_prev, b_prev;
  wire a_rising = a && !a_prev;

  always @(posedge clk) begin
    a_prev <= a;
    b_prev <= b;
    if (a_rising) begin
      if (b)
        position <= position + 1;
      else
        position <= position - 1;
    end
  end
endmodule
This example updates position on A rising edges and uses B to determine direction. Synchronize 'a' and 'b' into the 'clk' domain before this logic.
Design Notes
  • Use double-register synchronization for asynchronous inputs.
  • Decide whether to count on both edges for higher resolution.
  • Test with synthetic A/B waveforms at worst-case encoder speed to confirm no missed edges.
Common Mistake
Failing to synchronize encoder signals can cause metastability and incorrect counts.
