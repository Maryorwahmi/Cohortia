Module 9 › Chapter 9.2 › PID in Hardware
PID Equations (conceptual)
error = setpoint - measured
integral = integral + error * dt
derivative = (error - previous_error) / dt
output = Kp*error + Ki*integral + Kd*derivative
Implement multiplies with DSPs or shift/adds; run this loop every control tick in hardware for deterministic timing.
Practical Considerations
  • Limit integral to prevent windup; implement clamping logic in the accumulator.
  • Filter derivative input to reduce high-frequency noise amplification.
  • Select dt consistently with control loop clock; use fixed-point scaling with headroom.
Key Takeaway

A hardware PID gives fast, deterministic updates. Protect accumulators, manage fixed-point math, and filter derivatives to maintain stability.
