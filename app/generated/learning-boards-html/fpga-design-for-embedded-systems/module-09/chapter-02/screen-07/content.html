Verilog Pattern
module pwm_generator (
  input wire clk,
  input wire [15:0] duty_cycle,
  output reg pwm_out
);
  reg [15:0] counter;
  always @(posedge clk) begin
    counter <= counter + 1'b1;
    pwm_out <= (counter < duty_cycle);
  end
endmodule
This produces duty resolution of 16 bits. Frequency equals clk / 65536.
Design Trade-offs
  • Higher resolution increases step fidelity but lowers PWM frequency for fixed clock.
  • For visible LEDs, maintain frequency above human flicker; for motors, choose frequency to minimize audible noise and ensure smooth torque.
  • Use clock domain crossing carefully if driving external timers or peripherals at different clocks.
Key Takeaway

PWM is simple to implement in hardware; choose counter width and clock to match the resolution and frequency your system needs.
