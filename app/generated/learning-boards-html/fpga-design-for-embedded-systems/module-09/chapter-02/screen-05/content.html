// Delay line and product generation (excerpt)
module fir_filter (
  input wire clk,
  input wire signed [15:0] x,
  output reg signed [31:0] y
);
  parameter N = 16;
  reg signed [15:0] delay_line [0:N-1];
  wire signed [31:0] products [0:N-1];
  wire signed [15:0] coeff [0:N-1];

  always @(posedge clk) begin
    delay_line[0] <= x;
    for (integer i = 1; i < N; i = i + 1)
      delay_line[i] <= delay_line[i-1];
  end

  genvar i;
  generate
    for (i = 0; i < N; i = i + 1) begin : mult_gen
      assign products[i] = delay_line[i] * coeff[i];
    end
  endgenerate

  // Adder tree and output register omitted
endmodule
This example shows the delay line and parametric product generation. Synthesis maps the乘 products to DSP blocks when available.
Design Notes
  • Use DSP blocks for each multiplier to save LUTs and achieve higher clock rates.
  • Pipeline the adder tree: add registers between reduction stages to meet timing.
  • Watch bit widths: multiply 16-bit by 16-bit to get 32-bit products and sized accumulator.
Key Takeaway

Unroll the tap loop into parallel hardware, but pipeline the adder tree to keep a high clock rate and one-sample-per-cycle throughput.
