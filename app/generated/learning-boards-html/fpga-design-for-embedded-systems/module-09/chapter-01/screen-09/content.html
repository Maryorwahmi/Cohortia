MAX 10 Embedded ADC
IP configuration and reading values in software.
C Software Example
alt_u32 adc_value = IORD(ADC_BASE, 0);  // Read channel 0
float voltage = (adc_value / 4095.0) * 3.3;  // Convert to voltage
Explanation
The ADC returns a 12-bit count. Divide by 4095.0 to get a normalized value, then multiply by the reference voltage to obtain the measured voltage.
Concrete Example
If adc_value is 2048 on a 3.3V reference, the computed voltage is about 1.65 volts. Use this to calibrate sensors or drive decisions in your logic or software.
Key Takeaway

Configure the ADC IP, read channel counts, and convert to voltage in software. Confirm single-ended/differential modes for correct wiring.
