Module 9 › Verification
Design → Testbench → Hardware
A minimal verification flow for protocol controllers.
Step-by-step
  1. Define module interface and clock domain.
  2. Implement logic: shift registers, counters, state machines.
  3. Write testbench with edge timing checks and error cases.
  4. Synthesize and run a small on-board test like UART echo.
Concrete Lab
Implement UART at 115200 baud with a 50 MHz clock. Write a testbench verifying bit timing then program DE10-Lite and confirm echo via PC terminal.
Common Mistake
Neglecting edge cases like framing errors or simultaneous accesses. Add test vectors to cover these scenarios early.
Key Takeaway

A disciplined testbench and a small in-hardware check reduce debugging time and increase confidence in your controller modules.
