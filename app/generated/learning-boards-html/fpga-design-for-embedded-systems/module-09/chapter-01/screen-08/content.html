Module 9 › SDRAM
External SDRAM via IP
Connect controller IP to processor buses for large off-chip memory.
Architecture Overview
  • SDRAM controller handles refresh, row/column commands, and burst transfers.
  • Expose an Avalon or similar bus to the processor for easy reads/writes.
  • Check timing constraints and pin mapping against board documentation.
Concrete Example
Use Quartus SDRAM IP to connect the DE10-Lite 64 MB SDRAM to NIOS II. Perform a simple DMA or burst read to move large buffers between SDRAM and BRAM-backed peripherals.
Integration Checklist
  • Match SDRAM timing parameters in IP configuration.
  • Assign pins as the board schematic requires.
  • Run a memory test from software to confirm read/write and burst behavior.
Key Takeaway

Rely on proven SDRAM IP and validate the integration with software memory tests rather than reimplementing low-level timing logic.
