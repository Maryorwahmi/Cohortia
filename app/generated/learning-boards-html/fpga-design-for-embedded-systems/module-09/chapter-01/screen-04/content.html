GPIO Controller in Verilog
Register mapping example and synchronization note.
Verilog Example
<!-- Verilog: gpio_controller -->
module gpio_controller (
  input  wire        clk,
  input  wire        wr_en,
  input  wire [7:0]  wr_data,
  output reg  [7:0]  gpio_out,
  input  wire [1:0]  gpio_in,
  output reg  [1:0]  gpio_in_reg
);
  always @(posedge clk) begin
    if (wr_en)
      gpio_out <= wr_data;
    gpio_in_reg <= gpio_in;
  end
endmodule
Explanation
  • gpio_out stores the 8-bit LED pattern when wr_en is asserted.
  • gpio_in_reg samples asynchronous buttons at clock edges; add extra sync registers on noisy inputs.
  • Map these signals to board pin constraints in the .qsf or pin planner.
Concrete Example
On DE10-Lite, write 0xFF to gpio_out to light all 8 LEDs. Press a button and observe gpio_in_reg update in simulation before hardware check.
Key Takeaway

GPIO is simple but requires clocked sampling and synchronization for reliable input handling.
