UART: transmitter & receiver
Baud generator plus shift registers form a UART controller.

module uart_tx (
  input  wire        clk,
  input  wire        tx_start,
  input  wire [7:0]  tx_data,
  output reg         tx_busy,
  output reg         tx_serial
);
  // Baud rate counter and shift register logic
  // load tx_data, append stop bit, shift out at baud clock
endmodule
What to verify
  • Start bit is logic 0 and spans one full baud period.
  • Each data bit is sampled at the baud mid-point for stability.
  • Stop bit is logic 1; missing stop bits indicate framing errors.
Concrete Example
Connect FPGA UART to a PC terminal. Send an ASCII character from the PC. The FPGA should receive the frame, reconstruct the byte, and optionally echo it back.
Common Mistake

Miscalculating the baud divider causes bit drift and framing errors. Always verify divider math for your clock domain.
