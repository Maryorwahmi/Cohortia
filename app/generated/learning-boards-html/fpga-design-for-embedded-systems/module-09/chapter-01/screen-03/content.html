Practical Skills to Verify on Hardware
Create testbenches, exercise timing edges, and run small on-board tests that demonstrate real signals and data flow.
Testbench: UART Echo
Verify start bit detection, bit timing at 115200 baud for a 50 MHz clock, and correct data bits. Simulation should show a received byte being re-transmitted.
Verified Competency Milestone
ADC & Voltage Conversion
Read 12-bit ADC counts, compute voltage in software, and confirm with a potentiometer. Expect 4096 levels across the reference voltage.
Verified Competency Milestone
BRAM Inference
Infer a small dual-port memory from RTL for low-latency buffers. Check the RTL viewer to confirm M9K or equivalent block instantiation.
Verified Competency Milestone
SDRAM via IP
Use the Quartus SDRAM IP controller for refresh and bursts. Validate memory transfers from software running on NIOS II when possible.
Verified Competency Milestone
