Module 9 › BRAM
BRAM Inference
Describe memory behavior in RTL and let the synthesizer infer block RAM.
Verilog Pattern
reg [7:0] memory [0:1023];  // 1K x 8 RAM

always @(posedge clk) begin
  if (we)
    memory[addr] <= wr_data;
  rd_data <= memory[addr];
end
Explanation
A clocked array with conditional writes is the canonical pattern that synthesis tools detect and map to BRAM blocks. Use separate read or registered read styles depending on latency needs.
Concrete Example
Use a 1K x 8 BRAM as a small packet FIFO or coefficient table. Validate via RTL Viewer to ensure an M9K/M10K block is used.
Key Takeaway

Describe behavior clearly in RTL and confirm the synthesizer’s mapping to the expected physical memory block.
