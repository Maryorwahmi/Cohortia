2-input XOR truth table
00 → 0
01 → 1
10 → 1
11 → 0
These four stored bits fill a 2-input LUT's SRAM. The inputs address the correct row to produce the XOR result.
4-input XOR as a tree
Compute X1 = A XOR B, X2 = C XOR D, then F = X1 XOR X2. Each 2-input XOR is one LUT, so the tree uses three LUTs.
Key Takeaway

Map functions by counting input coverage and let synthesis pack small logic into available LUT widths. For a 4-input XOR, three 2-input XOR primitives are commonly used in a tree.

Quick practice
Draw the truth table for A XOR B XOR C and map how many 2-input XORs you need when forming a balanced tree. Notice how grouping affects depth and number of LUTs.
