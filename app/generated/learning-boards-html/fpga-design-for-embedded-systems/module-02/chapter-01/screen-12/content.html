Module 2 › Chapter 2.1 › Hard Blocks
Block RAM (BRAM)
Dedicated memory blocks for FIFOs, buffers, and large lookup tables that are more efficient than LUT-built memory.
DSP blocks
Pre-designed multipliers and accumulators optimized for fast arithmetic and reduce fabric usage for heavy math.
PLLs & Transceivers
Clock synthesis and high-speed serial links are hardened to meet timing and signal integrity requirements.
When to use them
If your design requires large memory, intensive DSP operations, or reliable high-speed IO, prefer hard blocks because they save LUT resources and improve performance and timing predictability.
