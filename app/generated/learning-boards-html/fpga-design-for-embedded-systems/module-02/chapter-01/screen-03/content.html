Module 2 › Chapter 2.1 › Learning Objectives
01 — LUT mnemonic
Memory table with address inputs
Draw a 16-row table for a 4-input LUT and mark the output bits for a simple function to see how the LUT stores the truth table directly.
02 — CLB mnemonic
Toolbox: LUT, flip-flop, carry chain
Label each item in a CLB sketch and note when the LUT output goes straight to routing or into the flip-flop for registered outputs.
03 — Interconnect mnemonic
City grid: local streets and highways
Trace a signal across the grid, counting switch matrices it crosses to appreciate added delay and area cost.
04 — Switch matrix task
Intersection as programmable switch
Sketch two intersecting routing channels and mark switch settings that connect a source wire to a destination to see how routing choices are configured.
