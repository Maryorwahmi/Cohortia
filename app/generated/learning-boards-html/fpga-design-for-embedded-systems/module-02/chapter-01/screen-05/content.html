Architecture snapshot
SRAM cells store one bit per input vector; a multiplexer tree selects the stored bit based on input signals.
SRAM array: 2^n bits
Multiplexer decoder
Address inputs
Single output bit
Practical note: changing one SRAM cell changes output for only one input combination — this is the essence of programmability.
Concrete mapping example
A 4-input function requires 16 SRAM bits. The inputs A,B,C,D form a 4-bit address. The LUT multiplexer routes the accessed SRAM cell to the output. No gate restructuring is necessary.
Common misconception

A LUT is not a fixed network of gates; it's programmed by writing memory bits, then the multiplexer returns the stored value for given inputs.
