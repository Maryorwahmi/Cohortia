Module 2 › Chapter 2.1 › Function Count
Counting idea
Each of the 2^n input combinations maps to a stored bit. Every different assignment of those bits defines a distinct Boolean function.
Formula: functions = 2^(2^n)
Example: n = 4 → 2^(2^4) = 2^16 = 65,536 possible functions for a 4-input LUT.
Practical implications
  • Large function space gives LUT power to implement arbitrary logic patterns.
  • But supporting many inputs grows memory size exponentially, so vendors limit input width.
  • Complex functions with many inputs are split across multiple LUTs in synthesis.
Misconception check

Don't confuse number of input combinations (2^n) with number of possible functions (2^(2^n)).
