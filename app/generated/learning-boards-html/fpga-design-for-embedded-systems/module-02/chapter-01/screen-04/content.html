Module 2 › Chapter 2.1 › LUT: Truth table
Definition
A small SRAM-based table where input bits address stored outputs.
Key points
  • For n inputs the LUT has 2^n stored entries.
  • Inputs act as the address to select the output bit.
  • LUTs are universal: any combinational function of the inputs can be stored.
  • A LUT is implemented as SRAM cells feeding a multiplexer network.
Key Takeaway

Think of the LUT as a programmable truth table: inputs choose the stored output rather than composing fixed gates.

Concrete example
F = (A AND B) OR (C AND D) implemented in a 4-input LUT. The synthesis tool computes the 16 output bits and stores them in the SRAM cells. At runtime A,B,C,D address the correct stored bit.
2-input XOR truth table (mapping exercise)
Inputs: A,B. Rows: 00→0, 01→1, 10→1, 11→0. These four bits fill a 2-input LUT's memory.
Common misconception: a LUT is not a fixed gate network. It stores output values for each input combination, so complex functions are just different stored patterns, not new wiring.
