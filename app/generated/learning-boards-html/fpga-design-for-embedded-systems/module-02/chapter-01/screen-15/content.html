Module 2 › Chapter 2.1 › Quick Reference
LUT = Truth Table
Inputs index stored bits; change SRAM to change the function.
CLB = LUT + FF + Carry
Use FFs to break paths; use carry for fast adds.
Interconnect = Routing Fabric
Routing hops and switch matrices set most of the delay budget.
One-line summary
When optimizing, count LUT inputs, place registers to shorten paths, and minimize switch-matrix crossings for critical nets.
