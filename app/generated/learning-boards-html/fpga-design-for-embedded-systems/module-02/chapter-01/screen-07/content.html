CLB components
  • LUTs: compute combinational outputs.
  • D flip-flops: store state for sequential logic.
  • Carry chain: fast path for arithmetic carry propagation.
  • Output mux: selects registered or combinational output.
  • Control signals: clock, enable, async set/reset.
Understanding which output the mux chooses and when to register results is central to placement and timing decisions.
Concrete scenario
Suppose you compute next_state in the LUT and want it stored on the clock edge. Route the LUT output into the CLB flip-flop. The flip-flop output then drives downstream routing. This pattern separates combinational computation from state storage.
Misconception

The LUT does not provide storage by itself; flip-flops in the CLB provide the register semantics.
