Module 2 › Chapter 2.1 › Combinational vs Sequential
When to use combinational output
Use when the value is purely a combinational result and does not need to be sampled on a clock edge.
Direct routing reduces latency but increases combinational path length for timing analysis.
When to register (sequential)
Route the LUT output into the flip-flop when you need synchronous sampling, state storage, or shorter timing segments between registers.
Key Takeaway

Strategic registering reduces critical path length and helps meet timing, even though it introduces one-cycle latency.
