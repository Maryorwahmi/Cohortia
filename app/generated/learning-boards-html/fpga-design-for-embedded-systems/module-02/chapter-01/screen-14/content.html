Module 2 › Chapter 2.1 › Key Concepts
Look-Up Table (LUT)
Stores the truth table in SRAM; inputs select the stored output bit, enabling arbitrary combinational functions.
Configurable Logic Block
Combines LUTs, flip-flops, and carry chains; supports both combinational outputs and registered state.
Programmable Interconnect
Routing channels and switch matrices connect blocks; routing choices and wire lengths dominate area and delay.
Summary takeaway
Remember these three building blocks when optimizing designs: store complex logic in LUTs, use CLB registers to manage timing, and reduce routing distance to improve clock speed.
