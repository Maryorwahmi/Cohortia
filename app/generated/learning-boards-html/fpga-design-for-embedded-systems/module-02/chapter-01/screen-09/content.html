Module 2 › Chapter 2.1 › Carry Chain
What it is
A hardware path optimized for carrying the arithmetic carry signal between adjacent bit-slices, avoiding full routing overhead.
Low delay links
Local routing inside CLB
Used for adders and MACs
Example: synthesis maps adder bits to adjacent slices and uses the carry chain so carries propagate quickly from bit 0 up to bit n with minimal extra switching delay.
Misconception
Not all inter-CLB connections are equal: carry chains are intentionally faster and specialized for arithmetic paths.
Key Takeaway

Use vendor carry-chain primitives when you need high-performance adds rather than relying on general routing between LUTs.
