Module 2 › Chapter 2.2 › Security and integrity
Threats and mitigations
  • Interception: External bitstream copies can be read if unencrypted.
  • Tampering: Unauthorized modification risks corrupted or malicious logic.
  • Mitigations: Bitstream encryption, authentication, and secure key storage.
Comparison by technology
SRAM: Requires encryption when using external storage.
FLASH: Internal storage reduces exposure, but secure update paths are needed.
Anti-fuse: High protection against reverse-engineering; no serial bitstream to intercept.
Key takeaway
Design bitstream storage and update procedures consistent with your system's security requirements; encryption and CRC complement each other.
