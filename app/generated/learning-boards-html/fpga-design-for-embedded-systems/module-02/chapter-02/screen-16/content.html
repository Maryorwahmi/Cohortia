Module 2 › Chapter 2.2 › Key Concepts — Quick Reference
Flexibility
SRAM: unlimited reprogramming, needs external storage and a reload step.
Instant-on
FLASH: internal storage and immediate operation, but limited rewrite cycles.
Permanence
Anti-fuse: permanent programming for the highest reliability and security.
Final reminder
Document your priorities — reprogramming cadence, startup latency, and reliability — then select the configuration technology that aligns with them.
