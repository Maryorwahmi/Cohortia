Module 3 › Chapter 2.3 › Datasheet Comparison
Build the comparison table
  1. Open each device datasheet and record LUT/LE counts, total BRAM (Kb), DSP blocks, I/O count, ADC presence, PLLs, and cost.
  2. Normalize units so memory is comparable (kilobits).
  3. Create a side-by-side table and mark which device meets each project requirement.
Projects
(1) 32-tap FIR at 100 MHz — emphasize DSP count. (2) UART-to-SPI bridge — minimal logic and I/O. (3) 4K video pipeline — emphasize memory and transceivers.
Example table (format)
Create columns: Field, MAX 10 (10M50...), Artix-7 (XC7A35T), Meets FIR?, Meets UART?, Meets 4K?
Key Takeaway

A careful datasheet comparison makes device trade-offs explicit and supports justified device selections for each project.
