Module 3 › Chapter 2.3 › AMD / Xilinx Families
Family highlights
Artix-7
Low-cost, low-power; used on Basys 3 and Nexys A7 development boards for learning and entry projects.
Kintex-7
Mid-range performance with high-speed transceivers for 10G Ethernet and software-defined radio.
Virtex
High-end parts with the fastest transceivers and highest logic density for demanding applications.
SoC and adaptive platforms
Zynq-7000 integrates FPGA fabric with a dual-core ARM Cortex-A9 for embedded OS and tight hardware-software designs. Zynq UltraScale+ adds more CPU cores, real-time processors, and GPU for machine vision. Versal is an adaptive compute acceleration platform combining scalar engines, FPGA fabric, and AI engines for heterogeneous acceleration.
Practical contrast
Use Zynq families when you need a hard on-chip processor; choose Artix or Kintex when you only need fabric and I/O or high-speed serial links.
Key Takeaway

Select Zynq for system-on-chip convenience and Versal for heterogeneous acceleration; pick Artix for cost-focused learning boards.
