Module 5 › Chapter 5.2 › Assembling the role
Step-by-step
  1. Create defaults/main.yml for tunable options.
  2. Add templates/nginx.conf.j2 and files/index.html.
  3. Write tasks/main.yml to install package, template config, copy file, and start service.
  4. Define handlers/main.yml and notify from template task.
  5. Test with a small playbook and inspect rendered files on the host.
Example playbook: deploy_nginx.yml
# deploy_nginx.yml
---
- name: Deploy Nginx web server using a role
  hosts: your_target_server
  become: true
  roles:
    - my_webserver_role
Key Takeaway

Integrate pieces in order and validate by running the role; confirm templates render and handlers only execute after real changes.
