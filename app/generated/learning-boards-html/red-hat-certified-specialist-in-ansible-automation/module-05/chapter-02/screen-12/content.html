Terminal steps (editor)
$ mkdir -p my_webserver_role/{defaults,vars,tasks,handlers,templates,files}
$ vim my_webserver_role/defaults/main.yml   # add nginx_port, nginx_root_dir
$ vim my_webserver_role/files/index.html    # add static HTML
$ vim my_webserver_role/templates/nginx.conf.j2  # add template using {{ nginx_port }}
$ vim my_webserver_role/handlers/main.yml   # add Restart Nginx handler
$ vim my_webserver_role/tasks/main.yml      # add install, template with notify, copy, service
Run the playbook
$ ansible-playbook deploy_nginx.yml -i inventory.ini
# First run: template changed -> handler runs
# Second run: no changes -> handler not run
Checks to observe
  • First run shows package install, file copy, and handler execution if template changed.
  • Second run should show no changes and no handler execution when files match.
  • Override nginx_port in a playbook to see template re-render and handler triggering.
Reflect

This demo shows the practical value of idempotency and notify-driven handlers for safe automation.
