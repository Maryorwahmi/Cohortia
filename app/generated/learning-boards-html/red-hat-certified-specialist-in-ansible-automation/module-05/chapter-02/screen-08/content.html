When to use files/

Put assets that do not require variable substitution, like plain HTML pages, scripts, or binaries, in files/ and use the copy module to deploy them.

Common mistake

Expecting Jinja2 to render inside files/. The copy module will not process templates.

Example: files/index.html
<!DOCTYPE html>
<html>
<head>
    <title>Welcome to Cohortia Nginx!</title>
</head>
<body>
    <h1>Hello from your Cohortia Nginx server!</h1>
</body>
</html>
Key Takeaway

If a file should be copied exactly as authored, place it in files/ and use ansible.builtin.copy.
