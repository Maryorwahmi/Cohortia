Why templates

Templates allow files to be generated with variables and logic, so a single template can serve multiple environments or hosts.

Design tips
  • Keep templates readable and well-documented
  • Avoid deep logic; prefer precomputed variables in vars or tasks
Example: nginx.conf.j2
# my_webserver_role/templates/nginx.conf.j2
user  nginx;
worker_processes  auto;

error_log  /var/log/nginx/error.log warn;
pid        /var/run/nginx.pid;

events {
    worker_connections  1024;
}

http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;

    server {
        listen       {{ nginx_port }}; # Using a variable from defaults/
        server_name  localhost;

        location / {
            root   {{ nginx_root_dir }}; # Using a variable from defaults/
            index  index.html index.htm;
        }
    }
}
Key Takeaway

Templates let you produce per-host files from a single source, keeping roles flexible and maintainable.
