Module 5 › Chapter 5.2 › Copy vs Template
Copy (files/)
  • Use for static text files, scripts, and binaries (no rendering)
  • Deployed with ansible.builtin.copy
Mistake to avoid

Putting a Jinja2 template in files/ and expecting rendering.

Template (templates/)
  • Use for dynamic configuration that requires variables or conditionals
  • Deployed with ansible.builtin.template and rendered via Jinja2
Pro tip

Keep template logic small; compute complex values in tasks or vars to keep templates readable.

Quick checks
If you need variables or conditionals, put the file in templates/ and use template. If the file is identical for all hosts, use files/ and copy.
