How handlers work
  1. A task runs and reports whether it changed the system.
  2. If the task has notify and changed, the handler is queued for that host.
  3. Handlers run after tasks complete for the host, once per unique handler name.
Pro tip

Name handlers clearly and keep their actions minimal so rollbacks and debugging remain simple.

Example: handlers/main.yml
# my_webserver_role/handlers/main.yml
---
- name: Restart Nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
Key Takeaway

Handlers let you defer and consolidate actions such as restarts. They only run if a notifier reports a change.
