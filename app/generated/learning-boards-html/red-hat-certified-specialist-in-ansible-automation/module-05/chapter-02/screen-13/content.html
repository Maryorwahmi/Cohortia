Troubleshoot › Chapter 5.2 › Common mistakes
Frequent issues
  • Jinja2 in files/ leading to unrendered templates on nodes.
  • Placing user-tunable options in vars/main.yml making them hard to override.
  • Assuming handlers run immediately; they run after tasks and only if a change occurred.
Quick diagnostics

Run the playbook with -v, inspect the changed status, view the target file, and add debug tasks to print variables.

Example debug task
- name: Debug nginx_port
  ansible.builtin.debug:
    var: nginx_port
Check

If the value printed isn't what you expect, inspect inventory, group_vars, host_vars, and role vars to find the source.
