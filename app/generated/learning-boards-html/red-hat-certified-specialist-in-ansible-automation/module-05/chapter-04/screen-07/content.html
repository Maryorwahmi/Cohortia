Definition
Role-level conditional execution
Use when on a role to avoid loading or executing it unless necessary.
Why use this
  • Skip expensive operations when not required.
  • Keep playbooks clearer by enabling features declaratively.
  • Prevent role tasks from running on inappropriate hosts.
Example: conditional role invocation
- name: Deploy application conditionally
  hosts: webservers
  become: true
  vars:
    deploy_app: true
  roles:
    - role: app_deploy
      when: deploy_app
If deploy_app is false or undefined, the app_deploy role is skipped entirely. This is a clean way to gate large changes without modifying the role itself.
Key Takeaway

Use role-level when to conditionally include roles and avoid unnecessary task evaluation.
