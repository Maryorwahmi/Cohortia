Definition
pre_tasks and post_tasks
Global hooks that run before and after roles and main tasks to prepare or finalize the environment.
Use cases
  • Configure package repos or install prerequisites before roles run.
  • Collect artifacts or cleanup temporary credentials after roles finish.
  • Run health checks before teardown steps.
Example pattern
Keep these sections concise and idempotent. They should not duplicate role responsibilities but can ensure prerequisites or collect results across roles.
Key Takeaway

Use lifecycle hooks to orchestrate global setup and cleanup, keeping roles focused on their own concerns.
