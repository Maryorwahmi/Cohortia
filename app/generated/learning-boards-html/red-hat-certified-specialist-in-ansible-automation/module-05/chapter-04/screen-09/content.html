Include role in a loop
Runtime inclusion supports per-item configuration and dynamic counts.
Best practices
  • Use explicit loop_var to avoid variable collisions.
  • Keep the role idempotent so repeated includes are safe.
  • Test with representative loop items in a dry-run scenario first.
Practical looped include
- name: Dynamically include a role based on a loop
  ansible.builtin.include_role:
    name: config_app
  loop:
    - app_name: frontend
      app_port: 80
    - app_name: backend
      app_port: 8080
  loop_control:
    loop_var: current_app
  vars:
    app_name: "{{ current_app.app_name }}"
    app_port: "{{ current_app.app_port }}"
Each iteration runs the role with the variables set from the current loop item. This pattern is commonly used to deploy or configure multiple applications using one reusable role.
