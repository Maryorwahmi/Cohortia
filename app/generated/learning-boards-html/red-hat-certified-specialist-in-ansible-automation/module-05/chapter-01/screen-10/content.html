Declare dependencies and metadata

meta/main.yml (example)
---
role_name: nginx_webserver
galaxy_info:
  author: Example Author
  license: MIT
dependencies:
  - { role: common, some_var: true }
  - { role: firewall }
Why dependencies matter
  • Ensure prerequisites are applied automatically.
  • Document assumptions for future users of the role.
  • Allow roles to be shared through repositories or Galaxy with clear metadata.
Common mistake

Hiding prerequisite tasks in external playbooks makes roles fragile. Declare dependencies explicitly so the role is self-describing.
