Static and dynamic assets

files/ (static)

Copy assets exactly as they are. Ideal for scripts, static HTML, images, or compiled binaries that must not change.

Example: files/index.html served as-is by the webserver.
templates/ (dynamic)

Render with Jinja2 to substitute variables or include conditional logic. Use this for configuration files that vary per host or environment.

Example: templates/nginx.conf.j2 that uses a variable for the upstream server list.
Practical tip

If you need any host-specific data injected into the file, prefer templates. Templates avoid brittle replacements after copying.

Misconception

Templates are not slower to use; they are the correct tool when content depends on variables. Use files only for truly static content.
