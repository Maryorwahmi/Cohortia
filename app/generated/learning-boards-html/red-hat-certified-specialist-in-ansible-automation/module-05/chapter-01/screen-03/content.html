Module 5 › Chapter 5.1 › How we'll practice
Bloom: Apply → Master
Practice plan
  1. Run the init command to scaffold a role.
  2. Inspect tasks/main.yml and add a simple debug task.
  3. Create test playbook that includes the role and run it locally.
  4. Try overriding a default to see precedence.
Concrete example
Run: ansible-galaxy init my_first_webserver_role, then open tasks/main.yml and add a debug task that prints a welcome message. Create test_role.yml that invokes the role and run ansible-playbook.
Quick tip

Use gather_facts:false and connection:local for fast iteration when testing roles locally.
