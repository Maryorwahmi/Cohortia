Three essential reminders

Structure
Use the standard role layout so Ansible and your teammates can find each artifact.
Variables
defaults for overrides; vars for internal logic. Respect precedence to avoid surprises.
Assets
Use templates for dynamic content and files for static assets to reduce brittle post-deploy edits.
Try this

Run ansible-galaxy init, add a debug task, and run a playbook that lists your role to confirm everything is wired up.
