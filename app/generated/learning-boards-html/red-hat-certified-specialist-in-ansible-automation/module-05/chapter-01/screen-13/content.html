Module 5 › Chapter 5.1 › Why modularity and reusability matter

How roles support scaling automation and team collaboration

Modularity

Break systems into focused roles so each change targets a single concern and is easy to reason about.

Reusability

Reuse a role across multiple projects instead of duplicating tasks, reducing bugs and effort.

Maintainability

Fix or improve a component in one place and have all consumers benefit instantly.

Scenario

If you have an urgent security fix for Nginx, update the webserver role and redeploy roles in each environment, rather than hunting the same task across many playbooks.
