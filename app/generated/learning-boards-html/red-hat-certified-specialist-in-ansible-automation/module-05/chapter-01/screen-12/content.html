Module 5 › Chapter 5.1 › Initialize your first role

A step-by-step walkthrough of ansible-galaxy init and the test flow

Terminal steps
# create the role scaffold
ansible-galaxy init my_first_webserver_role

# add a debug task to tasks/main.yml
# create a test playbook
ansible-playbook test_role.yml
Use connection: local and gather_facts: false in the test playbook to iterate quickly.
Example task to add
- name: Display a welcome message from the role
  ansible.builtin.debug:
    msg: "Hello from my_first_webserver_role!"
Key takeaway

A quick scaffold-and-test cycle helps you validate role structure before adding production changes.
