Sequencing and deferred actions

tasks/main.yml (excerpt)
- name: Deploy nginx configuration
  template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
  notify: Restart Nginx
handlers/main.yml (excerpt)
- name: Restart Nginx
  service:
    name: nginx
    state: restarted
Explanation
  • Notify names link tasks to handlers by a descriptive string.
  • Handlers run at the end of the current play for the host, avoiding multiple restarts.
  • Handlers colocated with tasks keep role behavior encapsulated and easier to maintain.
Common mistake

Defining handlers in a different role or playbook can lead to missed notifications. Keep related handlers inside the same role.
