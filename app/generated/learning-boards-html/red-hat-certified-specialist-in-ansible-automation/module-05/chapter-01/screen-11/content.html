Module 5 › Chapter 5.1 › Calling a role from a playbook

Implicit inclusion and a minimal test playbook

test_role.yml
---
- name: Test my_first_webserver_role
  hosts: localhost
  connection: local
  gather_facts: false
  roles:
    - my_first_webserver_role
Run ansible-playbook test_role.yml to validate the role executes and prints any debug or results your tasks produce.
Checkpoints
  • Ensure role folder is in roles/ or in a path Ansible can find.
  • Confirm tasks/main.yml contains the debug task you added.
  • Use connection: local for quick validation loops.
Key Takeaway

Ansible's implicit file discovery means your playbook lists role names, and the role structure supplies the rest.
