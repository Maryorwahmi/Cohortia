Module 5 › Chapter 5.1 › What is an Ansible Role?

A self-contained unit of automation with inputs and outputs

Definition & analogy

A role packages all automation relating to one concern so you can invoke it like a reusable function. It carries tasks, handlers, variables, files, templates, and metadata that document behavior and dependencies.

Concrete example
The nginx_webserver role installs Nginx, places a rendered configuration from templates/nginx.conf.j2, copies a static index.html from files, and notifies handlers to restart Nginx when changes occur.
Role contents
  • tasks/ – the main automation logic, usually main.yml.
  • handlers/ – deferred actions run when notified.
  • defaults/ – lowest precedence default variables.
  • vars/ – higher precedence role variables for internal use.
  • files/ – static files copied verbatim.
  • templates/ – Jinja2 templates rendered with variables.
  • meta/ – metadata and role dependencies.
Common mistake

Placing dynamic files in files/ instead of templates/ prevents variable substitution. Use templates when content must render with host-specific data.
