Example requirements.yml
# requirements.yml
---
- src: geerlingguy.nginx
  version: "4.0.0"
- src: https://github.com/your_org/custom_role.git
  scm: git
  version: "v1.2.0"
Install with: ansible-galaxy install -r requirements.yml -p ./roles. Commit requirements.yml to source control so collaborators and CI reproduce the same role set.
Best practices
  • Pin versions for production environments.
  • Install into project ./roles to keep the project self-contained.
  • Run smoke tests after installation to detect incompatibilities.
Common misconception
requirements.yml does not automatically secure or validate roles; you still must review code and run checks like ansible-lint.
