Module 5 › Chapter 5.3 › ansible-galaxy CLI
Terminal demo snippets
# Search for roles related to nginx
ansible-galaxy search nginx

# Install a role into the project roles folder and pin a version
ansible-galaxy install geerlingguy.nginx,version=4.0.0 -p ./roles

# Install multiple roles from a requirements.yml
ansible-galaxy install -r requirements.yml -p ./roles
Tip: Use project-local installs so the repository contains a record of required roles and your CI can install them reproducibly.
What to inspect after install
  • Role directory layout: tasks, handlers, defaults, meta.
  • meta/main.yml for license, platforms, and any built-in dependencies.
  • README and examples to understand configuration variables.
Key Takeaway
Search, install into ./roles, pin versions, and always review role content before trusting it.
