Module 5 › Chapter 5.3 › Passing Variables
How it looks in meta/main.yml
dependencies:
  - role: java_runtime
    java_version: 11
  - role: firewall_config
    firewall_ports:
      - 8080
      - 8443
These variables are set for the dependent role execution. They do not automatically change your role's internal variables unless referenced explicitly.
Practical notes
  • Document the reason for passing variables to a dependency.
  • Test the dependency with the provided variables in a sandbox.
  • Understand variable precedence to avoid surprises.
Key Takeaway
Passing variables to dependencies lets you configure third-party roles without modifying them.
