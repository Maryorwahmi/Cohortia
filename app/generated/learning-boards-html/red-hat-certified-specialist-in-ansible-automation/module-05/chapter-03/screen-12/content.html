Module 5 › Chapter 5.3 › Activity
Step A — requirements.yml
# requirements.yml
---
- src: geerlingguy.users
  version: "5.0.0"
Install: ansible-galaxy install -r requirements.yml -p ./roles
Step B — playbook
# manage_users.yml
---
- name: Configure users using geerlingguy.users
  hosts: localhost
  become: true
  vars:
    users:
      - name: cohortia_admin
        groups: "sudo,docker"
      - name: dev_user
        groups: "users"
  roles:
    - role: geerlingguy.users
Verification
Run ansible-playbook manage_users.yml against a safe test host and verify user creation, for example by checking system accounts. This confirms the role behaves as expected in your environment.
