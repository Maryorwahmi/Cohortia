Module 5 › Chapter 5.3 › Vetting Roles
Checklist for vetting
  • Read README and meta/main.yml for license and supported platforms.
  • Inspect tasks, handlers, and defaults for unexpected commands.
  • Run ansible-lint against the role code.
  • Test in an isolated VM or container before production.
Safety recommendations
Prefer roles with active maintainers, clear documentation, and explicit licensing. Use Ansible Vault for secrets and run roles with least privileges necessary during testing.
