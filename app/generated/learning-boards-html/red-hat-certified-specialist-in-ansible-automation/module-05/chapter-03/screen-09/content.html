Module 5 › Chapter 5.3 › Playbook Integration
Example playbook
# deploy_app.yml
---
- name: Deploy a web application
  hosts: webservers
  become: true
  vars:
    app_port: 8080
  roles:
    - common_os_config
    - geerlingguy.nginx
    - my_app_deployment
Note: If geerlingguy.nginx declares dependencies, they run before its tasks. Pass variables at the play or role level to tune behavior.
Checklist before production
  • Review role README and defaults.
  • Run in a test inventory and confirm outputs.
  • Pin versions and update requirements.yml as needed.
