Module 5 › Chapter 5.3 › Install Location
Project-local (recommended)
  • Install: ansible-galaxy install geerlingguy.nginx -p ./roles
  • Keeps roles coupled to the project and its requirements.yml.
  • Works well with CI and reproducible setups.
Global (convenience)
  • Installs to a central user roles directory.
  • Can cause version conflicts across projects.
  • Useful for quick tests but not recommended for production projects.
Practical checklist
Commit requirements.yml
Install with -p ./roles in CI
Review role sources before use
