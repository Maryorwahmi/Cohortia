Module 5 › Chapter 5.3 › Circular Dependencies
Why cycles fail
Ansible must determine an order to apply roles. If dependencies form a cycle, there is no valid order and the run fails. Detect cycles early during development.
Example problem
Role A depends on Role B; Role B depends on Role A. Neither can run first, so Ansible cannot proceed.
Refactor pattern
  • Extract shared setup into base roles like common_os_config.
  • Make both roles depend on the base role rather than each other.
  • Keep role responsibilities focused and documented.
