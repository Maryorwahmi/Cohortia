Module 5 › Chapter 5.3 › Role Dependencies
Definition and purpose
A role lists roles it depends on so Ansible runs those first and prepares the environment predictably.
  • Prevents repeating prerequisite role lists across multiple playbooks.
  • Controls execution order so foundational tasks run first.
  • Helps avoid failures caused by missing prerequisites.
Key Takeaway

Declare dependencies once in meta/main.yml so roles stay focused and reliable across playbooks.

Concrete example
A webserver role needs base OS configuration and user accounts defined first. Declare those dependencies to guarantee the right order.
YAML snippet
# webserver/meta/main.yml
---
# ... galaxy_info omitted ...
dependencies:
  - role: common_os_config
    common_os_config_firewall_enabled: true
  - role: user_management
    user_management_users:
      - name: webadmin
        groups: sudo
        state: present
Common mistake
Avoid circular dependencies; they create unsatisfiable execution orders and cause failures.
