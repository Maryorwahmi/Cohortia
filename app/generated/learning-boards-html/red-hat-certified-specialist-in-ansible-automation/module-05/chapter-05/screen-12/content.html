Module 6 › Chapter 5.5 › Version Control
Recommended workflow
  1. Create a feature branch and implement changes.
  2. Run ansible-lint and tests locally or via CI.
  3. Merge when checks pass and create a release tag for stable versions.
Tagging and changelog
Tag like v1.0.0 and include a changelog note describing fixes or breaking changes. Consumers should pin tags in their playbooks to guarantee reproducible deployments.
Key Takeaway
Version control plus tags and tests give your roles a predictable lifecycle and enable safe rollbacks.
