Ansible Vault
ansible-vault create vars/secrets.yml
ansible-vault encrypt_string --vault-id @prompt 'my_secret' --name 'db_password'
Document how to provide the vault password in CI and during local runs.
Least privilege & validation
  • - Use become only where required and favor become_user to limit scope.
  • - Add input validation tasks for complex inputs to avoid unexpected behavior.
  • - Rotate and audit secrets stored in encrypted files and version control.
Common mistake
Hardcoding credentials or granting global root privileges increases attack surface and complicates audits.
