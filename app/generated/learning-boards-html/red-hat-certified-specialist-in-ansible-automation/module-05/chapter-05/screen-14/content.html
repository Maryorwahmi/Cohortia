Module 6 › Chapter 5.5 › Key Concepts
Idempotency
Repeat runs result in the same final state; use state-aware modules and guards.
Modularity
One role, one responsibility to simplify testing and reuse.
Naming & Variables
Prefix variables, document defaults, and avoid vars for consumer-configurable values.
Summary Takeaway

Adopt idempotency, SRP, clear naming, documentation, linting, testing, versioning, and secure secret handling for dependable roles.
