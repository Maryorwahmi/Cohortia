Quick verification checklist
  • - Run the role on a disposable host.
  • - Check service status and configuration files.
  • - Confirm network endpoints respond as expected.
  • - Re-run the role to confirm idempotency.
Examples of quick probes
Use small checks such as checking for a file marker, running systemctl status for a service, and using curl to confirm an HTTP endpoint is reachable.
Pro tip
Automate these quick probes in a small script so reviewers can reproduce verification steps easily.
