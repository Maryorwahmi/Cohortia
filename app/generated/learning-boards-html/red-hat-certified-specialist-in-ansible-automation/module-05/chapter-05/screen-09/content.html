Module 6 › Chapter 5.5 › ansible-lint
Run ansible-lint
ansible-lint my_webserver_role/
Fix rules such as: using modules instead of command, avoiding hardcoded credentials, and documenting variables.
Workflow integration
  • - Add ansible-lint to pre-commit hooks or CI pipelines.
  • - Create a project ruleset for team conventions.
  • - Address warnings before merging and tagging releases.
Key Takeaway
Linting is a small investment that prevents brittle roles and enforces consistent practices across teams.
