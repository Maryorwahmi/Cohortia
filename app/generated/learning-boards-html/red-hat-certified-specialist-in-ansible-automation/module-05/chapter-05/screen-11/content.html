What Molecule does
  • - Provision ephemeral instances (Docker, Vagrant, cloud).
  • - Apply the role under test in a controlled environment.
  • - Run assertions (Testinfra or simple shell checks) to validate state.
Starter scenario
Use Docker with a minimal distro, apply your role, then assert that a package is installed and a service is active. Run this scenario locally and in CI.
Misconception
Molecule is not a replacement for manual verification; it automates repeatable integration checks that complement manual testing.
