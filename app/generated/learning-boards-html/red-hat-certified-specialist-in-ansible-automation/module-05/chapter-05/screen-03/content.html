Documentation & meta
Create a README with purpose, variables, example playbook, and supported platforms. Add meta/main.yml for author, license, and dependencies so automation tools and humans can read role metadata.
Example fragment
# README excerpt
# Variables: nginx_http_port (default 80)
# Example: include_role: name: install_nginx
Version control
Use Git branches for development and tag releases like v1.0.0 to mark stable role versions for consumption.
Security & verification
Use Ansible Vault for secrets and run manual checks on a test VM or container to confirm expected service state, file contents, and network behavior.
Practice: create a small test VM, run the role twice, confirm no unexpected changes on the second run.
