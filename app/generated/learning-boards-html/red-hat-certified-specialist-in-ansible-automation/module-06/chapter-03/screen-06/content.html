Module 6 › Chapter 6.3 › Variable semantics
Original target variables

inventory_hostname and ansible_host refer to the host the play is iterating over. Use these to refer to the subject of the task: the server you intend to manage or register in external systems.

Use case
Register the original host IP with DNS using ansible_host inside a delegated DNS update task.
Delegated host variable

ansible_delegated_host tells you where the delegated task actually executed. Use it to log or conditionalize behavior that depends on the executor host.

Use case
If you need to record which management node performed an API call, capture ansible_delegated_host in the result or log output.
Scenario
A play iterates webservers. A task delegates a DNS update to dns_host. To add the webserver IP, refer to ansible_host of the original; to note which dns_host executed it, read ansible_delegated_host. Mixing these up will register the wrong host in DNS or misattribute actions in logs.
Key Takeaway

Keep subject and executor variables separate: subject uses inventory variables, executor uses ansible_delegated_host.
