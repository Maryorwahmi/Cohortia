Module 6 › Chapter 6.3 › run_once behavior
What run_once does

When you set run_once: true on a task, Ansible will run that task only once for the current batch of hosts. If your play targets many hosts in one batch, it runs on the first host in the batch. Combined with delegate_to you can control both who is the subject and who executes the action.

Use case
Generate a unique deployment id on the control node once, register it, and share it with all hosts.
Subtlety
If you use serial or batching, the 'first host' can change. For guaranteed host identity, combine run_once with delegate_to: specific_host.
Concrete example
Create a deployment ID on localhost with run_once: true and set it as a fact so all hosts share the same id.
Key Takeaway

run_once is for one-time operations, but ordering and batching determine which host executes it.
