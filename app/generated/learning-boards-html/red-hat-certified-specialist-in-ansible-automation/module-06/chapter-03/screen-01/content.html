Delegated Execution, Local Actions, and Run Once
Why moving where a task executes gives you central control and safer orchestration.
In this lesson
How to use delegate_to, run_once, and localhost actions to centralize steps like builds, notifications, and API calls.
Why it matters
Orchestration often needs a single authoritative executor. Delegation provides that without changing the play's target list.
Quick orientation

Delegation changes where a single task runs. run_once limits execution to one host. delegate_to: localhost runs a task on your control node so it can access local tools and files.

Visual concept
Centralize, delegate, distribute
Concept cards
Delegate specific tasks to a host that can perform them, such as a management server with cloud SDKs.
Run_once coordinates one-off steps like schema creation or a notification after a multi-host deployment.
Run local build steps on the control node using delegate_to: localhost, then distribute artifacts to many targets.
