Module 6 › Chapter 6.3 › Build then distribute
Step-by-step
1
Create temp dir on controller
2
Build/package artifact locally
3
Ensure remote deploy dirs
4
Copy artifact to each host
5
Unarchive and install
6
Notify + cleanup on controller
Why this order
Create artifacts first to ensure deterministic content; distribute after to avoid inconsistent builds across hosts.
Misconception
Do not assume a delegated local task will automatically propagate remote facts. Gather and pass values as needed.
Check
Verify the artifact path and that the copy used the registered path from the controller, not a relative remote path.
