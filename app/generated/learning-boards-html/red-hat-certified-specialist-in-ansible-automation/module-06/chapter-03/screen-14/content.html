Module 6 › Chapter 6.3 › Key Concepts
Delegated Execution
Run a task on a host other than the play's target to access needed tools or networks.
run_once
Limit a task to a single execution per batch; ordering and serial affect which host runs it.
Control-node actions
Use delegate_to: localhost for local builds and scripts, but secure and clean controller state.
Takeaway

Use delegation and run_once to centralize steps without changing the play's intent; keep variables and security clear.
