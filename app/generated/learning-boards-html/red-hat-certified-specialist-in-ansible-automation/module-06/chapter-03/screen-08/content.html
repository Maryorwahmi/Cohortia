Module 6 › Chapter 6.3 › localhost execution
delegate_to: localhost

This is the preferred form to run tasks on the control node. It is explicit and consistent with other delegate_to usage, making playbooks easier to read and maintain.

Use cases
Local builds, packaging, interacting with local cloud CLIs, and centralized notifications.
local_action

local_action is an older shorthand equivalent to delegate_to: localhost, but the latter is clearer. Prefer delegate_to for consistency.

Security note
Tasks running on the controller can access local secrets. Clean up temporary files and minimize sensitive operations on the control node when possible.
Practical tip
Combine delegate_to: localhost with run_once: true when you want a single controller-side action during a multi-host run, for example creating a build artifact only once.
