Module 6 › Chapter 6.3 › Starter playbook walkthrough
Key task sequence
  1. Create build dir on control node with delegate_to: localhost and run_once: true so the directory exists only once.
  2. Simulate package creation on the controller, also delegated and run once, registering the package path.
  3. Ensure remote deployment directory exists on each webserver, run per-host.
  4. Copy package from controller path to each webserver and unarchive remotely.
  5. Send a centralized notification from the controller using delegate_to: localhost and run_once to avoid duplicate alerts.
  6. Clean up local temporary artifacts on the controller using delegate_to: localhost and run_once.
Starter snippet
---
- name: Delegated Deployment Workflow
  hosts: webservers
  gather_facts: no

  tasks:
    - name: Create local build directory on control node
      ansible.builtin.file:
        path: "/tmp/app_build_{{ ansible_date_time.iso8601_basic_short }}"
        state: directory
        mode: '0755'
      delegate_to: localhost
      run_once: true
      register: build_dir_result

    - name: Simulate application build and package creation on control node
      ansible.builtin.copy:
        content: "This is the application content for version 1.0
"
        dest: "{{ build_dir_result.path }}/app_package.tar.gz"
      delegate_to: localhost
      run_once: true
      when: build_dir_result.changed
Reader note
This snippet shows how delegate_to and run_once centralize build steps while the play remains targeted at webservers.
