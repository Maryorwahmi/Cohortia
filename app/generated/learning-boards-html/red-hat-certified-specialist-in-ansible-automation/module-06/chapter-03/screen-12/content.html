Module 6 › Chapter 6.3 › Hands-on validation
Validation checklist
  1. Confirm temporary build directory exists on the controller and path is registered.
  2. Confirm package file was created in the registered path on the controller.
  3. On each webserver verify /opt/app_deploy exists with correct ownership and mode.
  4. Validate the package was copied to /opt/app_deploy on each host.
  5. Check that unarchive produced expected files and contents on a sample host.
  6. Observe a single controller-side notification indicating deployment completion.
  7. Confirm the controller temporary directory was cleaned up when appropriate.
Quick test commands
On controller: list the build directory. On a webserver: list /opt/app_deploy and inspect package contents. These manual checks validate delegation behavior.
Key Takeaway

Map playbook steps to concrete verifications on both controller and remote hosts to confirm delegation worked as intended.
