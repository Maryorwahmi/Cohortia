Applied Objectives
Concrete tasks aligned to the hands-on activity
Create local build artifacts
Run a local file creation step on the control node, then register its path for later use.
Distribute and unarchive
Copy the package from the controller to each webserver and unarchive remotely using remote_src when appropriate.
Central notification and cleanup
Trigger a single final notification from the controller and remove temporary build directories when done.
