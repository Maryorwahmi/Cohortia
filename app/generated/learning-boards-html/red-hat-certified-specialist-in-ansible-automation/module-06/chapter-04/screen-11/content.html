Module 6 › Chapter 6.4 › Vault in CI/CD
Pipeline pattern
# CI step (conceptual)
echo "$VAULT_SECRET" > /tmp/vault_pass
chmod 600 /tmp/vault_pass
ansible-playbook -i inventory deploy.yml --vault-password-file /tmp/vault_pass
rm -f /tmp/vault_pass
Security notes
  • Use the CI system's secret store to hold the vault password.
  • Write it to a temporary file with strict permissions at runtime only.
  • Ensure logs do not reveal the secret or the temporary file contents.
Common mistake

Committing a script that contains the secret value or leaving the temporary file after the run. Both expose your secret.
