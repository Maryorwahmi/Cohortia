Why Vault matters

Keep secrets with playbooks safely under version control. Use Vault when credentials must travel with your repo but remain unreadable.

AES256 encryption
CI/CD compatible
Use case
Store DB credentials

Keep database passwords in group_vars/all/vault.yml and decrypt at runtime.

Safety note
Never commit password files

Password files must stay out of source control and have strict permissions.

In this lesson
Command patterns, playbook integration, password delivery options, rekey, and team workflows.
Concept Map
Vault File
Encrypted YAML with $ANSIBLE_VAULT header.
Playbook
References variables that Ansible decrypts at runtime.
Password Store
File, env var, or vault-id for automated use.
Common Mistake
Committing plain-text or password files.
