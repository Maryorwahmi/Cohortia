Module 6 › Chapter 6.4 › Team Workflows
Layout pattern

Use group_vars//vault.yml for environment-scoped secrets. Use vault-ids like prod@/path/to/prod_pass.txt to match password files to environments.

Document ownership and rotate when team members change roles.

Pro tip

Assign a single team owner for production vaults and require review and rotation on staff or access changes.

Practical example

Production: group_vars/production/vault.yml encrypted with prod vault password file. Development: group_vars/development/vault.yml encrypted with a separate file. Use --vault-id to select which password to use during runs.

Common mistake

Using one password across dev and prod increases blast radius. Separate passwords by environment to improve safety.
