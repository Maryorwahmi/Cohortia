Module 6 › Chapter 6.4 › Common Mistakes
Quick checks
  • Search commits for plain-text patterns before push.
  • Verify presence of $ANSIBLE_VAULT header after encryption.
  • Confirm chmod 600 on any vault password file used in automation.
Mitigation steps

• Use CI pre-checks to prevent plaintext secrets from entering the repo.

• Adopt separate vault passwords and rotate them when access changes.

• Make ephemeral password files in CI and delete them after the run.

Key Takeaway

Combine procedural controls, file permissions, and automation checks to avoid common vault mistakes.
