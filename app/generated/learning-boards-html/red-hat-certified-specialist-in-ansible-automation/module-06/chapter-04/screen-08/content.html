Starter commands
# Create project structure
mkdir -p my_project/group_vars/all

# Create a new vaulted file
ansible-vault create my_project/group_vars/all/secrets.yml

# Example contents inside the vaulted editor
# ---
# db_root_password: "MySuperSecretDBPass123"
# app_api_key: "AppKey_XYZ_456"

# Create a vault password file and restrict it
echo "cohortia_vault_pass" > ~/my_vault_pass.txt
chmod 600 ~/my_vault_pass.txt

# Run playbook with the password file
ansible-playbook -i my_project/inventory my_project/deploy_app.yml --vault-password-file ~/my_vault_pass.txt
Checks and safety
  • Confirm secrets.yml shows $ANSIBLE_VAULT header by running cat.
  • Do not commit the vault password file to version control.
  • If you decrypt for editing, re-encrypt or delete the plaintext file immediately.
Key Takeaway

Follow the lab steps to see how playbooks consume vaulted variables while files remain encrypted on disk.
