Module 6 › Chapter 6.4 › Team & CI/CD Objectives
01
Separate environment vaults

Use different vault files or vault-ids for production and development to limit blast radius of a leak.

VERIFIED COMPETENCY MILESTONE
02
Rotate and rekey

Use ansible-vault rekey to change passwords on vaulted files after role changes or a compromise.

VERIFIED COMPETENCY MILESTONE
03
Secure password storage

Keep vault password files outside repos and set strict file permissions. Prefer CI secret stores for automation.

VERIFIED COMPETENCY MILESTONE
04
Verify encryption

Confirm files show an $ANSIBLE_VAULT header and unreadable content to avoid accidental plaintext commits.
