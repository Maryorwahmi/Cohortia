Module 6 › Chapter 6.4 › What is Ansible Vault?
Definition

A tool to encrypt files used by Ansible, typically YAML variable files. Encrypted files include an $ANSIBLE_VAULT header and unreadable content.

Why use it
Keep secrets with playbooks without exposing values in plain text.
Not a secret manager
Vault protects files, but does not offer audit logs or remote rotation APIs like dedicated secret stores.
Key Takeaway

Use Vault to keep secret variables encrypted with your playbooks; pair it with secure password handling for automation.

Concrete example
# group_vars/all/vault.yml (encrypted after create)
---
db_password: "super_secret_db_password"
api_key: "highly_confidential_api_key_123"
Common misconception

Treating Vault as a replacement for secret management systems. Vault is file encryption for Ansible workloads and should be part of a broader secret strategy.
