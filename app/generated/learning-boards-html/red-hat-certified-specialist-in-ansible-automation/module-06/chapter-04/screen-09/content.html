Module 6 › Chapter 6.4 › Best Practices
Operational checklist
  1. Keep password files out of version control and use strict permissions.
  2. Encrypt only secrets, not whole playbooks or public configs.
  3. Use separate vaults or vault-ids per environment.
  4. Plan and document vault password rotation using rekey.
  5. Avoid leaving decrypted files on disk; delete or re-encrypt immediately.
Concrete safety notes

• Do not include vault password files in your Git repo. Keep them in a secure location.

• Prefer injecting secrets from your CI/CD secret store at runtime rather than storing them in build artifacts.

• Check that vaulted files have an $ANSIBLE_VAULT header after encryption to avoid accidental plaintext commits.

Key Takeaway

Operational discipline around password storage and rotation is as important as encryption itself.
