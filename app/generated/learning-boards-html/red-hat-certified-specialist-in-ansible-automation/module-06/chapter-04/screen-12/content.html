Module 6 › Chapter 6.4 › Rekey & Rotation
When to rekey
  • After a suspected password compromise.
  • When an employee with access leaves.
  • As part of a scheduled rotation cadence.
Coordination steps

Plan how new passwords reach pipelines and authorized humans. Test decryption with the new password before retiring the old one.

Command example
# Rekey a file interactively
ansible-vault rekey group_vars/all/vault.yml

# Rekey with specified vault-id files
ansible-vault rekey --vault-id old@old_pass.txt --new-vault-id new@new_pass.txt group_vars/all/vault.yml
Key Takeaway

Rekey safely and coordinate updates to any systems that need the new password before completing rotation.
