Module 6 › Chapter 6.4 › Vaulted Variables
How Ansible finds vaulted files
  • Place vaulted files in group_vars/ or host_vars/ or include via vars_files.
  • Ansible will attempt decryption during a run if a password is supplied.
  • Tasks and templates reference variables normally; no special syntax required.
Example playbook use
---
- name: Deploy application with vaulted secrets
  hosts: webservers
  become: yes

  tasks:
    - name: Configure database connection
      ansible.builtin.template:
        src: templates/db_config.j2
        dest: /etc/app/db_config.conf
        mode: '0600'
Template example
# templates/db_config.j2
DATABASE_HOST={{ db_host }}
DATABASE_USER={{ db_user }}
DATABASE_PASSWORD={{ db_password }}
API_KEY={{ api_key }}
Misconception

You do not need to decrypt files manually. Provide the vault password at runtime and Ansible will decrypt values for the playbook.

Key Takeaway

Vaulted variables are transparent to playbooks once the password is available; treat them like normal variables in tasks and templates.
