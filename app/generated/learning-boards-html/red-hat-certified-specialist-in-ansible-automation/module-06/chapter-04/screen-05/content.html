Module 6 › Chapter 6.4 › Vault Commands
Command quick reference
ansible-vault create & edit
Create and modify vaulted files through your editor; prompts for a password when creating.
ansible-vault view
Show decrypted contents in terminal for inspection without re-saving.
ansible-vault encrypt / decrypt
Encrypt an existing file or decrypt it back to plain text. Decrypt with caution.
ansible-vault rekey
Change the password protecting a vaulted file to support rotation.
Key takeaway
Practice these commands on a test project so you are confident that edit re-encrypts and rekey rotates safely.
Terminal demo snippets
# Create a new vaulted file
ansible-vault create my_project/group_vars/all/secrets.yml

# Encrypt an existing file
ansible-vault encrypt /tmp/private_key.txt

# Rekey an existing vault
ansible-vault rekey group_vars/all/vault.yml
Common mistake

Running decrypt without removing the plaintext file afterward exposes secrets. Always delete or re-encrypt temporary plaintext files immediately.
