Module 6 › Chapter 6.5 › Strategy plugins and async/poll
Comparison

linear vs free

linear
Runs a task on all hosts, waits for completion, then continues. Predictable ordering, good for dependent tasks.
free
Each host proceeds independently. Faster for uneven host speeds, but can complicate ordering and dependencies.
Async Example
- name: Start a long-running backup
  ansible.builtin.command: /usr/local/bin/long_backup_script.sh
  async: 3600
  poll: 15
  register: backup_job

- name: Check async status
  ansible.builtin.async_status:
    jid: "{{ backup_job.ansible_job_id }}"
  register: job_result
  until: job_result.finished
  retries: 40
  delay: 15
Pitfall
Using free without reviewing task dependencies may break orchestration assumptions.
Pro tip
Use async for long tasks, then poll or use callbacks to confirm completion when needed.
Check
Decide if a task must block the run or can be backgrounded with async to improve throughput.
