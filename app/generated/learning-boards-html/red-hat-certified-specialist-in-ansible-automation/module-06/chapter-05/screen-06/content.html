Module 6 › Chapter 6.5 › Debug & failed_when
Usage Pattern
Register → Inspect → Decide
  • Register the result of a shell/command task with register: name.
  • Use debug: var=registered_var or debug: msg to print focused data.
  • Apply failed_when to convert acceptable exit codes into success conditions.
Guarded debug
Use when conditions to run debug only under a verbosity or debug flag to avoid leaking sensitive values in normal runs.
Concrete code example
This example demonstrates registering a grep command and using failed_when to accept a return code of 1.
 - name: Check for a non-existent pattern in /etc/passwd (will return rc=1)
   ansible.builtin.shell: grep -q "non_existent_pattern_12345" /etc/passwd
   register: grep_result
   # Accept rc==1 as success because not finding the pattern is expected
   failed_when: grep_result.rc != 1

 - name: Debug grep result
   ansible.builtin.debug:
     msg: "Grep RC={{ grep_result.rc }}, stdout='{{ grep_result.stdout }}'"
   when: grep_result is defined
Key Takeaway

Use register and debug to inspect live values, and employ failed_when to codify acceptable non-zero results so playbooks continue when appropriate.
