Module 6 › Chapter 6.5 › Tuning forks and parallelism
Core Concept

Forks control concurrency

Configure forks in ansible.cfg or use -f to tune how many hosts are contacted simultaneously. Test and monitor when changing it.

Example
# Temporary on command line
ansible-playbook -f 30 site.yml

# Persistent in ansible.cfg
[defaults]
forks = 30
Key Takeaway

Tune forks by measuring execution time and control-node load. Highest safe forks wins.

Process Flow

How forks affect task execution

Control node
Spawns N forks. Each fork opens SSH connections to a subset of hosts and runs tasks concurrently. Monitor CPU, disk, and open file descriptors.
Remote hosts
Handle concurrent incoming SSH sessions. Too many parallel sessions may cause high load on slow hosts or network saturation.
Pitfall
Blindly increasing forks can cause resource exhaustion and more failures.
Pro tip
Profile runs with incremental changes and keep a documented safe range for your inventory.
Check
Use system tools to check CPU and socket counts while a playbook runs at higher forks.
