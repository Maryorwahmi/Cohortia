Module 6 › Chapter 6.5 › Prefer idempotent modules and profile tasks
Comparison

Module vs shell

Idempotent module
Only changes when the desired state differs from current state, minimizing remote work and errors.
Shell/command
Runs every time unless you add checks. Easier to write quickly, but costlier at scale.
Profiling

Use the profile_tasks callback

Enable profile_tasks to get a breakdown of task durations. Focus optimization where the most time is consumed.

# enable profile_tasks in ansible.cfg
[callback_profile_tasks]
# plugin enabled via callback_plugins or ANSIBLE_CALLBACK_PLUGINS
Pitfall
Optimizing arbitrary tasks without profiling wastes time.
Action
Replace shell with modules, then profile to verify improvement.
Key Takeaway

Idempotent modules and profiling yield the best performance wins. Measure first, change second.
