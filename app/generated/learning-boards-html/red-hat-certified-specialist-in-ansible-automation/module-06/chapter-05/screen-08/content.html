Module 6 › Chapter 6.5 › Performance
Comparison
Settings to consider
forks
Controls parallel SSH connections. Increase for large inventories but test for control-node resource limits.
pipelining
Reduces SSH overhead by executing more over a single connection; requires non-interactive sudo configuration.
fact_caching
Store facts to avoid repeated gathering. Effective when host facts are relatively static between runs.
Concrete config example
An example ansible.cfg snippet shown below configures jsonfile fact caching for 24 hours. Use it with gather_facts: no in plays where fresh facts aren’t required.
[defaults]
fact_caching = jsonfile
fact_caching_connection = /tmp/ansible_facts_cache
fact_caching_timeout = 86400 # Cache for 24 hours
Key Takeaway

Make changes incrementally and measure impact. Use caching and pipelining where applicable and avoid blindly increasing forks without profiling.
