Module 6 › Chapter 6.5 › Verbose Output
Process
Choose verbosity to match the problem
-v: Basic task flow and short outputs.
-vv: Connection and host negotiation details.
-vvv: Module arguments and returned data—best for most debugging.
-vvvv: Full SSH protocol traces—use only for deep connectivity issues.
Pro tip
Start with -v, then escalate. Use -vvv when you need to inspect what the module actually received after templating.
Concrete example
If a shell task using templated variables fails, run with -vvv to see the rendered command string, the module arguments, and the captured stdout and stderr. This often shows missing quotes or an empty variable directly.
Misconception

More verbosity is not always better. It can obscure relevant lines and expose sensitive data. Use the minimal level that reveals the needed information.
