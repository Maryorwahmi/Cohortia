Code Walkthrough

ansible.cfg fact_caching example

# ansible.cfg
[defaults]
fact_caching = jsonfile
fact_caching_connection = /tmp/ansible_facts_cache
fact_caching_timeout = 86400
# Cache facts for 24 hours
Store the cache in a shared backend for multiple control nodes, or use jsonfile for a single control node. Choose a timeout that balances freshness and speed.
Playbook change
- name: Example play using cached facts
  hosts: web
  gather_facts: no
  tasks:
    - name: Use cached fact value
      debug:
        msg: "Cached ansible_facts are available when needed"
When to use caching
  • Large inventories where facts change rarely.
  • Repeated runs where gather_facts dominates runtime.
  • When a shared cache backend is available for multiple control nodes.
Common mistake
Enabling fact_caching but still setting gather_facts: yes for every play negates the benefit.
