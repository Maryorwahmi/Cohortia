Module 6 › Chapter 6.2 › Learning Objectives — Practical Outcomes
Objective verification steps
Short lab checks tied to each objective to confirm competency.
Conditionals
Create tasks with when: ansible_os_family == 'RedHat' and run playbook against a mixed inventory to confirm selective execution.
Loops
Use loop over a list of dictionaries, then inspect item structure with a debug task to confirm fields like item.name and item.groups.
Templating
Render motd.j2 using template and verify ansible_date_time.iso8601 appears and conditional text varies by OS family.
Safety checks
Run ansible-playbook --syntax-check and ansible-lint. Use vault or hashed secrets instead of raw passwords in templates.
How to show mastery
  1. Run the provided playbook against a Red Hat host and a Debian host and observe differing task execution.
  2. Inspect /etc/motd on each host to confirm conditional templating and interface listing.
  3. Demonstrate the use of default and is defined in your template to avoid missing values.
