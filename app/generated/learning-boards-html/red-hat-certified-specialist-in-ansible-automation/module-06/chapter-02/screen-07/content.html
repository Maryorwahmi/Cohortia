Module 6 › Chapter 6.2 › Iterating dictionaries: dict2items and with_dict
Why normalize a dict
Normalization creates a consistent item structure so subsequent tasks can rely on item.key and item.value. It also enables sorting and filtering before iteration.
When to sort:

If the order of operations matters, convert and sort the list to avoid unpredictable iteration ordering across Python versions or Ansible runs.

Example conversion
- name: Convert mapping to items
  set_fact:
    users_list: "{{ users_map | dict2items }}"

- name: Create users from mapping
  ansible.builtin.user:
    name: "{{ item.key }}"
    state: "{{ item.value.state | default('present') }}"
    groups: "{{ item.value.groups | default([]) | join(',') }}"
  loop: "{{ users_list }}"
This approach uses item.key for the username and item.value for properties, keeping semantics explicit.
Common misconception

Don't assume dict iteration preserves a desired order; if you need stability, convert and sort explicitly before looping.
