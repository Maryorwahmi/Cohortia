Module 6 › Chapter 6.2 › Legacy constructs vs modern usage
Side-by-side
Legacy
with_items and with_dict existed for simple loops but inconsistent item shapes could surprise maintainers.
Modern
Use loop with dict2items to produce predictable item.key and item.value. One construct covers many cases.
Refactor pattern
  1. Run current playbook with debug to inspect item shape.
  2. Replace with loop and dict2items, keeping the same assertions.
  3. Run ansible-playbook --syntax-check and test in a safe environment.
Key Takeaway

Standardize on loop and explicit conversions for clearer, maintainable playbooks that behave predictably across runs.
