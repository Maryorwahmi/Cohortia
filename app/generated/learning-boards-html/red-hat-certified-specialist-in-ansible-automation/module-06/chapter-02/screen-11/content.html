Module 6 › Chapter 6.2 › Common pitfalls and troubleshooting
Quick checklist
  • Run ansible-playbook --syntax-check and ansible-lint early.
  • Use debug tasks to inspect item and rendered templates in a dry-run.
  • Precompute complex expressions in vars to make when clauses readable.
  • Vault or hash secrets; never render raw secrets into logs or public files.
Troubleshooting snippet
- name: Debug item shape
  debug:
    var: item
  loop: '{{ managed_users }}'

- name: Render template to temporary file for inspection
  ansible.builtin.template:
    src: motd.j2
    dest: '/tmp/motd.rendered.{{ inventory_hostname }}'
    mode: '0644'
  check_mode: yes
Render to a temporary file first or run in check mode to inspect output before changing system files.
