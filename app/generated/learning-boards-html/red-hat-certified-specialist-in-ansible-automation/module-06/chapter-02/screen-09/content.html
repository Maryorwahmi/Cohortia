Module 6 › Chapter 6.2 › Templating with template module
What to remember about rendering
  • Templates render on the control node during the template task.
  • Ensure variables and facts are available before the template task runs.
  • Guard undefined variables with default or is defined to prevent render errors.
Security

Avoid exposing secrets in rendered files or logs. Use vaulted variables or hashes when templates must include sensitive data.

motd.j2 example
# /etc/motd - Generated by Ansible
---------------------------------------------------
Date: {{ ansible_date_time.iso8601 }}
Hostname: {{ inventory_hostname }}

{% raw %}{% if ansible_os_family == 'RedHat' %}{% endraw %}
Welcome to a Red Hat-based system!
{% raw %}{% else %}{% endraw %}
Welcome to a Linux system!
{% raw %}{% endif %}{% endraw %}

Network Interfaces:
{% raw %}{% for interface in ansible_interfaces %}{% endraw %}
  - {{ interface }}
{% raw %}{% endfor %}{% endraw %}
---------------------------------------------------
This template demonstrates conditional blocks, loops, and the use of a fact-based timestamp for reproducible output.
