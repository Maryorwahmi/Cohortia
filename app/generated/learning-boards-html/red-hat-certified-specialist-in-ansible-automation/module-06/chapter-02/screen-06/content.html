Module 6 › Chapter 6.2 › Looping over a list of user dictionaries
Explanation
When items are dictionaries, access fields directly. Use filters to supply reasonable defaults and to convert lists to module-friendly formats.
Checklist before running:
  • Debug item to confirm structure if unsure.
  • Use default for optional fields like shell or groups.
  • Prefer append: yes when adding groups to avoid overwrite.
Key Takeaway

Always normalize and inspect data shape; handle missing keys with default and format list fields for the module's expectations.

Example playbook snippet
- name: Manage multiple users
  ansible.builtin.user:
    name: "{{ item.name }}"
    state: "{{ item.state | default('present') }}"
    groups: "{{ item.groups | default([]) | join(',') }}"
    shell: "{{ item.shell | default('/bin/bash') }}"
  loop:
    - { name: 'devuser1', groups: ['developers', 'sudo'], state: 'present', shell: '/bin/zsh' }
    - { name: 'opsuser', groups: ['ops', 'sudo'], state: 'present' }
    - { name: 'guestuser', groups: [], state: 'absent' }
Add a preceding debug task if you want to inspect item before applying changes: use debug: var=item or debug: msg='{{ item }}'.
