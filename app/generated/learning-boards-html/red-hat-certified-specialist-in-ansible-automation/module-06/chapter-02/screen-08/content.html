Common filters
  • default: provide fallback values when undefined.
  • join: convert lists to strings for modules requiring comma-separated values.
  • int and upper: cast and format values.
  • to_nice_json: produce readable JSON for debug or files.
Useful tests
  • is defined: guard access to variables that may not be present.
  • is none: detect explicit null values.
  • is string: confirm expected types before formatting.
Template example
{{ "{{ app_port | default(8080) | int }}" }}
This pattern provides a fallback and ensures the value is an integer for configuration files.
Misconception

Assuming filters run on the remote host. Templates render on the control node during the template task, so be mindful of available facts and secrets.
