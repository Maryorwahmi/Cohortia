Step-by-step loop process
  1. Decide the data shape: list of values, list of dicts, or a dict.
  2. Normalize a dict into items with dict2items when needed.
  3. Use loop to iterate; inspect item with debug to confirm structure.
  4. Access item fields directly when iterating dictionaries, e.g., item.name.
Pro tip
Use loop_control.label to provide a readable label in task output when item is complex.
Example converting a dict
- name: Iterate firewall rules stored in a dict
  set_fact:
    fw_rules: "{{ my_rules_dict | dict2items }}"

- name: Apply firewall rules
  ansible.builtin.firewalld:
    service: "{{ item.key }}"
    state: "{{ item.value.state }}"
  loop: "{{ fw_rules }}"
dict2items produces a list of key/value objects so item.key and item.value are available consistently.
Key Takeaway

Prefer loop and convert dictionaries to items so item access stays predictable and safe.
