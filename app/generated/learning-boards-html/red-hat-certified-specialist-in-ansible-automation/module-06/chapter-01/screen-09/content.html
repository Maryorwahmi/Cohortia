Module 6 › Chapter 6.1 › Handlers & Listen
Pattern
Define handlers once and have them listen to multiple notify names to avoid duplication.
- Notify different events from multiple tasks.
- A handler with listen reacts to any of those names.
- Handlers run once per play unless forced, reducing repeated restarts.
Concrete example
handlers:
  - name: restart web service
    ansible.builtin.service: name: httpd state: restarted
    listen: "restart web service"
  - name: log deployment event
    ansible.builtin.debug: msg: "Deployment logged"
    listen: "log deployment event"
Pro tip: centralize restart logic and use notify names that describe intent, not implementation details.
