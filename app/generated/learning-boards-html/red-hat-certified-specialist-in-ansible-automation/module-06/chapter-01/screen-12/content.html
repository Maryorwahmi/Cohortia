Module 6 › Chapter 6.1 › Testing error handling
Test plan
  1. Run with valid inputs; confirm normal flow and handlers.
  2. Run with missing source to trigger rescue; verify rescue actions.
  3. Inspect register variables to assert conditions.
  4. Automate these scenarios in CI to prevent regressions.
Failure simulation hints
  • Delete the local source file to simulate missing control node artifact.
  • Use an invalid URL to trigger download status checks.
  • Make rescue and always idempotent so repeated test runs are safe.
Common pitfall: rescue tasks that assume variables set by block tasks. Guard or set defaults before rescue.
