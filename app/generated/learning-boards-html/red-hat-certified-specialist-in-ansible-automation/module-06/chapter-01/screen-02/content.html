Learning Objectives
Skills to practice and verify
Bloom: Learn → Understand → Apply → Master
01
Implement block, rescue, always
Group tasks for controlled execution and add recovery and guaranteed cleanup steps so partial failures don’t leave systems inconsistent.
VERIFIED COMPETENCY MILESTONE
02
Use ignore_errors carefully
Bypass a task failure when it’s expected, but know the risk of masking real issues; prefer explicit conditions when possible.
VERIFIED COMPETENCY MILESTONE
03
Define failed_when
Create Jinja2 conditions to mark tasks failed only when your custom criteria match task output, improving accuracy.
VERIFIED COMPETENCY MILESTONE
04
Control changed_when
Report meaningful changes by evaluating task output, preserving idempotency and clean reporting for audits.
VERIFIED COMPETENCY MILESTONE
