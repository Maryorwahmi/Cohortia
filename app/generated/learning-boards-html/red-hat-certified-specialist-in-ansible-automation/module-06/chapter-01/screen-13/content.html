Module 6 › Chapter 6.1 › Hands-on activity
Scenario
Copy a config file with rollback and guaranteed cleanup.
Starter steps
  1. Create source file on localhost or remove it to simulate failure.
  2. Use a block to copy the file and register the result.
  3. Add failed_when using a stat on the control node to detect missing source.
  4. In rescue, debug and remove destination file with ignore_errors.
  5. In always, delegate cleanup of the temp log to localhost.
Testing checklist
  • Run playbook with source present and confirm success path.
  • Remove source and run again to trigger rescue and check always.
  • Verify handlers were notified only when appropriate.
Reflection: Did your rescue tasks make safe assumptions about variables or files? If so, make them more defensive and idempotent.
