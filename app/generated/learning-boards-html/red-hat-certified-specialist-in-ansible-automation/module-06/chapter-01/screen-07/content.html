Module 6 › Chapter 6.1 › failed_when
How to use
Register a result, then evaluate fields in failed_when to mark failure precisely.
- Check result.stdout, result.rc, or result.stderr.
- Guard against undefined fields using default filters.
- Explain why default exit code behavior is overridden with a comment.
Concrete example
# After registering download_result
failed_when: download_result.status != 200 or download_result.status is not defined
# Or for a script which prints SUCCESS on stdout when rc != 0
failed_when: "'SUCCESS' not in result.stdout"
Misconception: failed_when is a safety net — it's a deliberate override and must be precise to avoid masking errors.
