Distinguish command and shell

Understand when a shell is necessary and the security implications of running through a shell.

ansible.builtin.command
Runs an executable directly, without shell processing. Safer and preferred for simple commands.
Example: running a simple check that does not require pipes or redirection.
ansible.builtin.shell
Runs through a shell so you can use expansion, pipes, and redirects. Use carefully and sanitize variables.
Example: a command that needs a pipe or environment expansion.
Common mistake
Overusing shell for tasks covered by modules reduces idempotency and increases risk. Prefer dedicated modules when available.
