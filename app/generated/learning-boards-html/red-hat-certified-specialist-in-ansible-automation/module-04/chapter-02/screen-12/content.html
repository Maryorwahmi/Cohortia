Module 4 › Chapter 4.2 › Hands-on Nginx
Starter Playbook
---
- name: Setup Nginx web server
  hosts: webservers
  become: yes
  tasks:
    - name: Install Nginx package
      ansible.builtin.package:
        name: nginx
        state: present

    - name: Ensure Nginx service is running and enabled
      ansible.builtin.systemd:
        name: nginx
        state: started
        enabled: yes

    - name: Copy custom index.html
      ansible.builtin.copy:
        src: files/index.html
        dest: /usr/share/nginx/html/index.html
        owner: nginx
        group: nginx
        mode: '0644'
Files directory
Place index.html under files/ next to this playbook. Contents can be <h1>Hello from Ansible Nginx!</h1>.
Run and verify
Run ansible-playbook and confirm changed vs ok, then check the server in a browser.
Extend
Later swap copy for template to render host-specific content with Jinja2.
