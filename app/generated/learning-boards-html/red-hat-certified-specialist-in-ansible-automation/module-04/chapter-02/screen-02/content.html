Learning Objectives

Learn, understand, apply, and verify core system modules that produce idempotent results.

Learn → Understand → Apply → Master
01
Manage packages with package
Use ansible.builtin.package to install, remove, or update packages across apt, yum, dnf, and zypper.
Mnemonic: one module, many managers.
VERIFIED COMPETENCY MILESTONE
02
Control services with service & systemd
Ensure start, stop, restart, and enable behavior using the module that matches the host's init system.
Mnemonic: runtime vs boot control.
VERIFIED COMPETENCY MILESTONE
03
Manage users and groups
Create, modify, or remove accounts with explicit uid, home, shell, and group attributes using user and group modules.
Mnemonic: identity as code.
VERIFIED COMPETENCY MILESTONE
04
Files, copy, and template
Use file for permissions and directories, copy for static assets, and template with Jinja2 for dynamic, host-specific files.
Mnemonic: static, state, or render.
VERIFIED COMPETENCY MILESTONE
