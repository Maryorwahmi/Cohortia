Question 1

Create /opt/appdata with 0770 ownership

Best task uses file with path: /opt/appdata state: directory owner: appuser group: appgroup mode: '0770'. This single, idempotent task sets desired state and permissions.
- name: Create appdata directory
  ansible.builtin.file:
    path: /opt/appdata
    state: directory
    owner: appuser
    group: appgroup
    mode: '0770'
Question 2

Deploy motd including hostname

Use template to render Jinja2 variables like {{'{{ ansible_hostname }}'}} so each host receives a personalized motd. Copy cannot insert variables; shell is less maintainable.
- name: Deploy dynamic motd
  ansible.builtin.template:
    src: templates/motd.j2
    dest: /etc/motd
Answer rationale
Choose modules that express desired state. This makes automation repeatable and reduces manual maintenance across many hosts.
