Module 4 › Chapter 4.2 › Command vs Shell
ansible.builtin.command

Execute a program directly without shell processing. Safer for simple tasks.

# Example: a simple command
- name: List /tmp directory
  ansible.builtin.command:
    cmd: ls -la /tmp
ansible.builtin.shell

Runs through a shell, enabling pipes, redirects, and expansions. Use carefully and sanitize inputs.

# Example: using a pipe requires shell
- name: Count lines in a log
  ansible.builtin.shell:
    cmd: cat /var/log/myapp.log | wc -l
Warning
Running shell with unsanitized variables can lead to injection. Prefer modules for idempotency and safety.
