Module 4 › Chapter 4.2 › Copy vs Template
ansible.builtin.copy

Copy a static file from the control node to the managed node. Good for distributing images, HTML, or fixed configuration files.

- name: Copy custom index.html
  ansible.builtin.copy:
    src: files/index.html
    dest: /usr/share/nginx/html/index.html
    owner: nginx
    group: nginx
    mode: '0644'
ansible.builtin.template

Render a Jinja2 template on the control node and deploy the result. Use when content needs variables like hostnames or environment values.

- name: Deploy templated Nginx configuration
  ansible.builtin.template:
    src: templates/nginx.conf.j2
    dest: /etc/nginx/nginx.conf
    owner: root
    group: root
    mode: '0644'
Misconception
Avoid using shell to create files with variables. Templates are more maintainable and idempotent than manual echo or heredoc commands run via shell.
