Module 4 › Chapter 4.2 › User & Group Management
ansible.builtin.user

Manage user accounts

- name: Create a new deployment user
  ansible.builtin.user:
    name: deployuser
    uid: 2001
    group: developers
    home: /home/deployuser
    shell: /bin/bash
    state: present
Confirm created user properties with inventory facts or getent on the managed node after running the playbook.
ansible.builtin.group

Manage groups

- name: Ensure 'developers' group exists
  ansible.builtin.group:
    name: developers
    gid: 5000
    state: present
Groups let you assign permissions and keep user memberships consistent across hosts. Verify gid and members when auditing systems.
