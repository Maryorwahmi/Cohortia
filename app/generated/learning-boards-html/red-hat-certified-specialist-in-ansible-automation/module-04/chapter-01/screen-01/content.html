Task example
 - name: Ensure Apache HTTP Server is installed
   ansible.builtin.package:
     name: httpd
     state: present
A single, idempotent step: install a package if missing.
Play header
 - name: Configure a basic web server
   hosts: webservers
   become: yes
   tasks: ...
Defines who to run against and whether to elevate privileges.
Key Takeaway

A playbook sequences named tasks that call modules with arguments. Clear names, small tasks, and idempotent modules make automation safe and debuggable.
