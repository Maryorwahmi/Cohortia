Module 4 › Chapter 4.1 › Apache example walkthrough
Play snippet
---
- name: Configure a basic web server
  hosts: webservers
  become: yes
  tasks:
    - name: Ensure Apache HTTP Server is installed
      ansible.builtin.package:
        name: httpd
        state: present

    - name: Ensure Apache HTTP Server is running and enabled
      ansible.builtin.service:
        name: httpd
        state: started
        enabled: yes
Explanation
  • hosts limits execution to the webservers group.
  • become elevates privileges for package and service operations.
  • The package task ensures binary presence; service task manages runtime and boot state.
Misconception
Combining install and start in a single shell task loses idempotency and hides which part failed. Use modules instead.
Key Takeaway

Read playbooks as intent: header sets scope and privileges; tasks express single logical changes that are safe to run repeatedly.
