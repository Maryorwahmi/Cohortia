Architecture

Play → Hosts → Become → Vars → Tasks

Each play establishes the context for a set of tasks to run against chosen hosts with defined privileges and variables.

hosts
Select target group or hostnames.
become
Enable privilege escalation for tasks that need it.
vars
Define reusable values to avoid hard-coding.
tasks
Ordered list of task definitions executed sequentially.
Guided example
---
- name: Configure a basic web server
  hosts: webservers
  become: yes
  vars:
    web_pkg: httpd
  tasks:
    - name: Install web package
      ansible.builtin.package:
        name: "{{ web_pkg }}"
        state: present
This shows how vars parameterize tasks and become elevates privileges where required.
Why it matters

Grouping context via plays reduces duplication, clarifies scope, and ensures the right privileges and variables are applied consistently.
