Module 4 › Chapter 4.1 › Quick assessment
Question 1
What happens if a service task specifies state: started and the service is already running?
Answer: Ansible reports no change because the module detects the current state; this is idempotency in action.
Question 2
Which module and arguments best ensure a user exists with a given UID?
Answer: The ansible.builtin.user module with name and uid and state=present arguments. This module manages user attributes idempotently and is preferred over raw useradd commands.
Key Takeaway

Practice reasoning about modules, arguments, privileges, and idempotency to choose the right action in a playbook.
