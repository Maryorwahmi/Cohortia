Module 4 › Chapter 4.1 › Build first_playbook.yml
Starter code
---
- name: Basic system setup and message display
  hosts: all
  become: yes
  tasks:
    - name: Install the 'tree' package
      ansible.builtin.package:
        name: tree
        state: present

    - name: Display confirmation message
      ansible.builtin.debug:
        msg: "Tree package installation checked!"
Explanation
  1. hosts: all targets the inventory set you run against.
  2. become: yes elevates privileges so package management succeeds.
  3. Two tasks separate state change from reporting.
Try this safely
Run against a development inventory, confirm the package install, and expand gradually to more hosts after verifying behavior.
Key Takeaway

Start small: a two-task playbook shows the flow of install then verify and helps you observe changed versus unchanged outcomes.
