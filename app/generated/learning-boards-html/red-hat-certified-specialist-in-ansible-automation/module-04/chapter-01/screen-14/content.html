Module 4 › Chapter 4.1 › Key Concepts
Task
A single action with name, module, and arguments.
Playbook
YAML list of plays that target hosts and contain tasks.
Module
Reusable action provider that implements checks and idempotency.
Summary takeaway
Design playbooks with clear names, focused tasks, modules for idempotency, and vars for reuse to build safe, repeatable automation.
