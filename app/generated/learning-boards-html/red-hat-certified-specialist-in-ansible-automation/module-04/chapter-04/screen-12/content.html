Module 5 › Chapter 4.4 › Debugging Handlers
Troubleshooting steps
Verify changed
Confirm the notifying task reported changed=true; only those trigger notify.
Check names
Ensure the notify string matches the handler's name exactly, including case and spacing.
Confirm scope
Handlers must be defined or imported in the same play or role context to be available for notification.
Watch timing
Remember handlers run at the end of the tasks section; use flush_handlers only when necessary.
Pro tip
Run with -vvv to inspect notifications and handler execution order to pinpoint where the flow breaks.
