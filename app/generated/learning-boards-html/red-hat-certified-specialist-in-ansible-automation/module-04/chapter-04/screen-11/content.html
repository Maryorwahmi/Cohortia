Wait for service readiness

Place a wait_for task after your change/handler sequence or conditionally run it when a restart occurred.

- name: Wait for database to be available after restart
  ansible.builtin.wait_for:
    port: 5432 # PostgreSQL default port
    host: "{{ inventory_hostname }}"
    delay: 5
    timeout: 60
    state: started
  delegate_to: localhost
  when: database_restart_handler_result is changed
Notes
Use delegate_to when checking remote ports from the control node. Adjust timeout and delay to match expected start times.
Key Takeaway

A wait_for check after a handler makes the flow safer by ensuring a restarted service is actually accepting connections.
