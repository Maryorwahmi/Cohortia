Definition
The register Keyword
Capture task output into a host-scoped variable for later use in conditions or debugging.
Example: register and use rc
- name: Check if devuser1 exists
  ansible.builtin.command: id -u devuser1
  register: devuser1_check
  ignore_errors: yes

- name: Debug if devuser1 was found
  ansible.builtin.debug:
    msg: "devuser1 exists on this system."
  when: devuser1_check.rc == 0
This registers the command result and uses its rc key to decide whether devuser1 exists.
Inspection
Always print registered variables with debug var: before using nested keys. For stat, check config_file_status.stat.exists. For command, check rc and stdout.
Pro tip

Use ignore_errors when a check may fail but you still want to inspect rc and continue; handle real failures with failed_when when appropriate.
