Host Scope and Variable Visibility
Understand where a variable lives and how to share or aggregate values across hosts.
Pattern: run_once + set_fact to aggregate
- name: Collect a value on all hosts (example)
  ansible.builtin.shell: echo hello
  register: hello_out

- name: Aggregate results (run once on controller)
  run_once: true
  ansible.builtin.set_fact:
    all_hello_results: "{{ groups['all'] | map('extract', hostvars, 'hello_out') | list }}"
This sketch shows retrieving hostvars and building a list; inspect hostvars structure and be careful with missing keys.
Note
Access to hostvars allows aggregation, but you must guard against hosts that did not run a task or where the variable is undefined. Use default filters and validation.
Key Takeaway

Plan for host-scoped state: register is local, aggregate explicitly when you need a global view.
