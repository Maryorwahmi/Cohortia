Definition
Loops in Ansible
Run the same task for each item in a list and use item to access each entry’s data.
Simple list example
- name: Install a list of common packages
  ansible.builtin.package:
    name: "{{ item }}"
    state: present
  loop:
    - git
    - vim
    - htop
This runs the package task three times, once per package name available as item.
List of dictionaries
- name: Create multiple users
  ansible.builtin.user:
    name: "{{ item.name }}"
    uid: "{{ item.uid }}"
    group: "{{ item.group }}"
    state: present
  loop:
    - { name: 'alice', uid: 2001, group: 'developers' }
    - { name: 'bob', uid: 2002, group: 'developers' }
    - { name: 'charlie', uid: 2003, group: 'admins' }
Access item.name, item.uid, and item.group for each iteration to supply module parameters.
Key Takeaway

Prefer loop over with_items, and remember looped tasks produce per-item results. Use register carefully if you need aggregated outcomes.
