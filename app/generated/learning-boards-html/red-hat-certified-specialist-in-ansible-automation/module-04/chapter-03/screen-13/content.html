Common Mistakes
Pitfalls and Remedies
Type mismatches
Always coerce types when comparing. Example remedy: (ansible_distribution_major_version | default('0') | int) == 20.
Host-scoped registers
Do not reference a registered variable from a different host. Use run_once and set_fact to share aggregate results if needed.
Loop vs single result
Registering a loop returns a results list. Inspect indices or filter items; do not assume a single scalar value.
Quick Checklist
Debug variables, guard with default, coerce types, prefer failed_when, and design for host scope before running large plays.
