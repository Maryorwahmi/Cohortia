Example: register with loop
- name: Create/manage users from list
  ansible.builtin.user:
    name: "{{ item.name }}"
    uid: "{{ item.uid }}"
    group: "{{ item.group }}"
    state: present
    shell: /bin/bash
  loop: "{{ users_to_manage }}"
  register: user_creation_results

- name: Debug user creation results
  ansible.builtin.debug:
    var: user_creation_results
The debug output will show user_creation_results.results, an array where each element corresponds to one loop iteration. Inspect changed flags and rc values to determine per-user outcomes.
Tips
  • If you need a single aggregated value, consider post-processing the results with set_fact and filters.
  • To check if any iteration failed, filter user_creation_results.results by rc != 0 or failed == true.
Common mistake
Expecting register to contain a single stdout when the task was looped. Always explore results list entries.
