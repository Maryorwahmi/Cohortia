Target Playbook
dynamic_users.yml will ensure groups exist, loop through users_to_manage to create users, register a check for devuser1, and conditionally debug if devuser1 exists.
Milestone: Run the playbook and confirm debug output prints the existence message for devuser1.
Common Pitfalls
  • Using a registered variable from another host in a when condition.
  • Comparing numbers and strings without consistent quoting in Jinja2.
  • Overusing ignore_errors instead of targeted failed_when checks.
