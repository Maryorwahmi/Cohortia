Learning Objectives
Progress from understanding conditionals and loops to applying them in a dynamic playbook and verifying results with debug statements.
Learn → Understand → Apply → Master
01
Use when to run tasks conditionally
Write Jinja2 conditions that rely on gathered facts or registered outputs so tasks run only when appropriate. This reduces unnecessary changes and avoids errors on incompatible hosts.
Mnemonic: if this, then run
VERIFIED COMPETENCY MILESTONE
02
Iterate with loop / with_items
Use loop to run a task once per item in a list or dictionary. The current item is available as item, letting you map multiple inputs to one task cleanly and idempotently.
Mnemonic: repeat with item
VERIFIED COMPETENCY MILESTONE
03
Capture task output with register
Store a task's result in a host-scoped variable and inspect keys like rc, stdout, and changed to make later decisions or debug behavior.
Mnemonic: save the result
VERIFIED COMPETENCY MILESTONE
04
Use debug and basic error handling
Print variables with ansible.builtin.debug and control failure with ignore_errors or failed_when so runs behave predictably and you can troubleshoot quickly.
Mnemonic: print and protect
VERIFIED COMPETENCY MILESTONE
