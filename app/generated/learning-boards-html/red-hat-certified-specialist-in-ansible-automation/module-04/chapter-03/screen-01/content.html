Conditional Logic and Loops in Tasks
Make playbooks dynamic by using when, loop, and register so tasks run only when needed, and so you can inspect and react to task results reliably.
Interactive 16:9 Masterclass
Concept Map
when — conditional execution driven by facts or previous task results.
loop — iterate over lists or dictionaries using item for current values.
register + debug — capture and inspect task outputs to inform decisions.
Explore Key Topics
when: evaluate Jinja2 expressions to decide if a task should run.
loop: repeat tasks with lists or dicts and use item to access properties.
register & debug: store results and print them to verify behavior.
