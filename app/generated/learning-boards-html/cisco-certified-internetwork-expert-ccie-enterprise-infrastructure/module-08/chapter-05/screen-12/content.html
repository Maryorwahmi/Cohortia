Module 08 › Chapter 8.5 › Key Concepts
DHCP Snooping
Filters DHCP replies and creates the binding database used for validation.
Dynamic ARP Inspection
Validates ARP against bindings to prevent ARP spoofing; static hosts need manual bindings.
IP Source Guard & Port Security
Enforce source IP/MAC and limit learned MAC addresses to stop spoofing and flooding.
Takeaway
Treat DHCP Snooping as the foundational step, verify bindings, then enable DAI and IPSG, and finally tighten with Port Security while monitoring violation behavior.
