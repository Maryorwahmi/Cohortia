Module 08 › Chapter 8.5 › Common Mistakes
Mistake
Uplink not trusted
Symptom: no bindings, DHCP failures. Fix: mark uplink with ip dhcp snooping trust and ip arp inspection trust, then re-test DHCP.
Mistake
Static IPs without bindings
Symptom: static hosts blocked by DAI/IPSG. Fix: add ip dhcp snooping binding entries for static hosts or create trusted static ARP entries.
Mistake
Aggressive violation mode
Symptom: ports shut and outages. Fix: use restrict for production, monitor counters, and reserve shutdown for controlled environments.
Action checklist
  • Confirm trusted ports and binding entries before enabling DAI/IPSG.
  • Add static bindings for devices with fixed IPs.
  • Choose port-security violation modes that match your operational tolerance and monitor logs.
  • Apply DHCP rate limits only on untrusted access ports.
