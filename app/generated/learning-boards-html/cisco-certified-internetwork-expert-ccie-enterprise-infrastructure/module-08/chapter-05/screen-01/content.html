Layer 2 Threat Mitigation Techniques

Learn the set of access-layer defenses on Cisco Catalyst switches that block rogue DHCP servers, ARP poisoning, IP/MAC spoofing, and MAC table exhaustion. We'll connect commands to outcomes so you can both configure and verify safely.

In this lesson
Practical CLI workflow, binding database, trust model, and verification
Coming up
DHCP Snooping
Filters DHCP replies and builds a binding database used by other security features.
Dynamic ARP Inspection
Validates ARP packets against the DHCP snooping database to block ARP spoofing.
IP Source Guard & Port Security
Enforce IP/MAC bindings and limit MAC learning to stop spoofing and flooding.
Practical outcome

You will be able to configure and verify protections on an access port and reason about trusted vs untrusted uplinks.

Quick tip
Always mark uplinks to DHCP servers and other infrastructure as trusted. Missing a trusted port is the most common cause of failed deployments.
