Module 08 › Chapter 8.5 › Learning Objectives
01
Explain Layer 2 vulnerabilities
Describe ARP spoofing, DHCP spoofing, and MAC flooding and their practical impact on traffic integrity and availability.
Mnemonic: attacker tricks = false bindings
VERIFIED COMPETENCY MILESTONE
02
Configure DHCP Snooping
Enable globally and per VLAN, mark trusted ports, and optionally rate-limit DHCP on access ports to prevent starvation.
Mnemonic: build the binding database
VERIFIED COMPETENCY MILESTONE
03
Implement Dynamic ARP Inspection
Use DAI to validate ARP replies and requests against the DHCP Snooping database so forged ARP entries are dropped.
Mnemonic: ARP checks against known bindings
VERIFIED COMPETENCY MILESTONE
04
Deploy IP Source Guard
Enforce that a port only forwards traffic if the source IP and MAC match entries in the binding database, preventing spoofing.
Mnemonic: port-level source filters
VERIFIED COMPETENCY MILESTONE
