Module 08 › Chapter 8.5 › Binding Database & Rate Limits
Binding record fields
  • Client MAC address
  • IP address and lease time
  • VLAN and interface where the lease was observed
  • Binding type (DHCP learned or static)
Use the binding data to validate ARP and to create static entries for devices that use fixed IPs.
Rate limiting DHCP messages
Apply ip dhcp snooping limit rate on untrusted access ports to defend against DHCP starvation attempts. Typical values for single-host access ports are 10–20 messages per second; tune based on renewal behavior in your network.
Operational note
Rate limiting must be applied only to untrusted ports. Do not enable on uplinks to servers, or you could throttle legitimate DHCP traffic.
Check your understanding
After enabling DHCP Snooping, run show ip dhcp snooping binding and confirm the client MAC and IP appear for the expected interface. If static IP hosts exist, add static bindings manually so enforcement features will allow their traffic.
Key Takeaway

The binding database is the single source of truth for later ARP and source checks; populate and verify it before turning on enforcement.
