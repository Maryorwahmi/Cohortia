Optional: rate limit DHCP on untrusted port interface GigabitEthernet1/0/1 ip dhcp snooping limit rate 15
Keep the binding database visible with show ip dhcp snooping binding to confirm clients obtained addresses via the trusted server.
How it helps
  • Blocks DHCP server replies on untrusted ports so rogue servers cannot provide malicious configuration.
  • Builds a binding table mapping MAC, IP, VLAN, interface, and lease time for each DHCP client.
  • Provides the authoritative data other features use to validate ARP and source addresses.
Common mistake
Forgetting to mark the DHCP server uplink as trusted will block legitimate DHCP replies. Verify trusted ports after configuration.
Key Takeaway

DHCP Snooping must be enabled and properly trusted before enabling DAI or IPSG, because they rely on its binding database.
