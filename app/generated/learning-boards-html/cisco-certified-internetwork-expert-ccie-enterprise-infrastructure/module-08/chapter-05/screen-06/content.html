Module 08 › Chapter 8.5 › Dynamic ARP Inspection (DAI)
What DAI checks
  • Validates ARP requests and replies against DHCP Snooping bindings
  • Can validate source MAC, destination MAC, and IP fields
  • Drops ARP packets with mappings that do not match bindings
Enable with ip arp inspection vlan & mark trusted ports with ip arp inspection trust for uplinks and inter-switch links.
Example
Client MAC 00AA.00BB.00CC gets 10.0.10.5 via DHCP. DAI will drop ARP packets that claim 10.0.10.5 from any other MAC address.
Common misconception
DAI does not automatically know about static IP assignments; you must create static DHCP bindings or configure static ARP entries so DAI can validate those hosts.
Key Takeaway

Enable DHCP Snooping first. DAI uses that table to stop forged ARP and requires manual bindings for static hosts.
