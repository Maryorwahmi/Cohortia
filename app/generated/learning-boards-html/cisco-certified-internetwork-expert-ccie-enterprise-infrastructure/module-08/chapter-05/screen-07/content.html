Module 08 › Chapter 8.5 › IP Source Guard
Modes and behavior
  • IP-only: verifies only the source IP matches the binding
  • IP-MAC: verifies both IP and MAC; stronger protection
  • Works per access port and creates an implicit port ACL based on bindings
Command example: ip verify source port-security on the interface. Ensure DHCP Snooping bindings exist for DHCP clients; add static bindings for fixed-IP devices.
Example scenario
A workstation that obtained 10.0.10.5 via DHCP is allowed. If an attacker plugs in and spoofs 10.0.10.5 from a different MAC, IPSG drops the spoofed traffic because it doesn't match the binding for that interface.
Remember: add static bindings for servers or devices using static IPs so they pass IPSG checks.
Key Takeaway

IPSG is a per-port defense that stops hosts from claiming IP/MAC identities they do not own. Validate bindings and add static entries before enforcement.
