Module 08 › Chapter 8.5 › Port Security
Configuration pattern
interface GigabitEthernet1/0/1 switchport mode access switchport access vlan 10 switchport port-security switchport port-security maximum 2 switchport port-security mac-address sticky switchport port-security violation restrict
Sticky mode simplifies device onboarding. Consider restrict for production to avoid accidental outages from shutdown mode.
Violation mode comparison
  • Shutdown: disables the port on violation (most secure)
  • Restrict: drops violating traffic and increments counters (recommended for production)
  • Protect: drops violating traffic silently without counters
Why it matters
By limiting MAC learning on an access port you reduce the attack surface for MAC flooding. Combined with DHCP Snooping and IPSG, Port Security ensures only expected endpoints can transmit and limits attacker identity spoofing.
