Process Flow
Define Exporter, Monitor, and Apply to Interface
From exporter to interface: ensure delivery and activation of flow data.
Exporter + Monitor snippet
flow exporter FNF_EXPORTER
 destination 192.168.10.30
 transport udp 2055
 source GigabitEthernet0/0/0
!
flow monitor FNF_MONITOR
 record FNF_SECURITY_RECORD
 exporter FNF_EXPORTER
 cache timeout active 60
!
interface GigabitEthernet0/0/1
 ip flow monitor FNF_MONITOR input
 ip flow monitor FNF_MONITOR output
Verification commands
  • show flow monitor FNF_MONITOR cache
  • show flow monitor FNF_MONITOR statistics
  • confirm collector is receiving exported records
Operational notes
Use a loopback as exporter source for consistent source IPs, and ensure the loopback is routable to the collector.
Re-use exporters for multiple monitors if they share the same destination to reduce config duplication.
Monitor CPU and memory after enabling; scale slowly across interfaces.
Key Takeaway

Confirm both device-side statistics and collector ingestion before scaling FNF across many interfaces.
