Core Concept
What is IP SLA?
Active probes that simulate traffic to measure service health and performance.
Operation types
  • ICMP Echo: round-trip time and packet loss.
  • UDP Jitter: one-way delay, jitter, loss for VoIP checks.
  • TCP Connect: time to establish a TCP connection to a port.
  • HTTP GET: web server response time.
Use the operation type that most closely simulates the service you want to protect. An ICMP probe measures reachability but may not expose application-level issues that a TCP connect or HTTP GET would reveal.
Best practice
Choose probe frequency and timeout that represent the service without overloading the device. Integrate with tracking to create automated routing or alerting behavior when a probe fails.
Key Takeaway

IP SLA provides a synthetic check of service health that can drive automated network decisions when configured with tracking objects.
