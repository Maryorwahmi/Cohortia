Configure IP SLA and Schedule It
An ICMP example and verification steps.
Configuration example
ip sla 10
 icmp-echo 192.168.1.100 source-interface Loopback0
 timeout 2000
 frequency 5
!
ip sla schedule 10 life forever start-time now
Verification
  • show ip sla summary
  • show ip sla detail 10
Operational guidance
Use Loopback0 as the source for consistent probe source addresses and to simplify routing to the monitored destination.
A reasonable frequency (for example 5 seconds) balances timeliness and device load; adjust for your environment.
Confirm the monitored destination is representative of the service you care about — the probe should indicate the true user experience.
Key Takeaway

A scheduled IP SLA operation provides continuous performance metrics you can use for alerting and automated responses.
