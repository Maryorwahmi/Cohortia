Key Concepts — FNF Essentials
Three compact concept cards to recall the FNF architecture.
Flexible NetFlow (FNF)
Customizable technology to collect and export flow telemetry for visibility and security analysis.
Flow Record
Defines keys and non-keys to capture the exact fields required for analysis.
Flow Exporter
Specifies where to send NetFlow data and which interface to use as the packet source.
Summary
Design records for the detection goals, verify exporters and monitor performance, and scale telemetry cautiously.
