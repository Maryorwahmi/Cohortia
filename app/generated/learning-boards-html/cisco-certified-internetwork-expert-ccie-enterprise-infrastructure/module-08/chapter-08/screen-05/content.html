Definition
FNF Components: Record, Exporter, Monitor
Three distinct layers let you control what to collect, where to send it, and how it runs on the device.
Component Overview
Flow Record: Defines keys (e.g., IPv4 source/destination, ports) and non-keys (counters, TCP flags).
Flow Exporter: Destination IP, transport UDP port, and source interface for NetFlow packets.
Flow Monitor: Associates a record and exporter and manages the flow cache for export.
Operational tip
Apply monitors to only the interfaces you need and use short cache timeouts for security-focused export rates.
Combined configuration pattern
flow record FNF_SECURITY_RECORD
 record FNF_SECURITY_RECORD
  match ipv4 protocol
  match ipv4 source address
  match ipv4 destination address
  match transport source-port
  match transport destination-port
  collect transport tcp flags
  collect counter bytes long
  collect counter packets long
!
flow exporter FNF_EXPORTER
 destination 192.168.10.30
 transport udp 2055
 source GigabitEthernet0/0/0
!
flow monitor FNF_MONITOR
 record FNF_SECURITY_RECORD
 exporter FNF_EXPORTER
 cache timeout active 60
!
interface GigabitEthernet0/0/1
 ip flow monitor FNF_MONITOR input
 ip flow monitor FNF_MONITOR output
Verify
Use show flow monitor <name> cache and statistics to validate collection and export.
Watchout
Avoid wide application on many interfaces; monitor device CPU and memory after enabling.
