Configure a Security-Focused Flow Record
A step-by-step code walkthrough to capture attacker-revealing fields.
Configuration snippet
flow record FNF_SECURITY_RECORD
 match ipv4 protocol
 match ipv4 source address
 match ipv4 destination address
 match transport source-port
 match transport destination-port
 collect transport tcp flags
 collect counter bytes long
 collect counter packets long
Why each field:
  • Protocol identifies UDP vs TCP floods or ICMP probes.
  • Addresses and ports pinpoint target servers and services.
  • TCP flags reveal incomplete handshakes or suspicious flag combos.
  • Counters show volume and connection rates for DoS detection.
Practical checklist
Apply to only internal interfaces you monitor for threats.
Set cache timeout to balance detection speed with resource use.
Avoid overly broad records that include rare fields unless required for a use case.
Key Takeaway

A focused flow record provides the best signal-to-noise ratio for security detection while protecting device resources.
