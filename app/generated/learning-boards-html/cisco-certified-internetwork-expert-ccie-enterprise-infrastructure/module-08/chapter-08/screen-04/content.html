Core Concept
What is Flexible NetFlow (FNF)?
Customizable flow telemetry for deep network visibility.
Definition & why it matters

Flexible NetFlow allows you to define records of key and non-key fields. Keys identify unique flows; non-keys add counters and context. This tailoring helps you capture only the telemetry you need to detect security patterns without excessive overhead.

Analogy
Think of FNF as choosing which camera angles and sensors you want in a security room. Too many feeds overload operators; the right feeds show the incident clearly.
Common misconception
More fields automatically equals better detection. Not true — collect what you need and monitor resource usage.
Concrete example: security record
flow record FNF_SECURITY_RECORD
 match ipv4 protocol
 match ipv4 source address
 match ipv4 destination address
 match transport source-port
 match transport destination-port
 collect transport tcp flags
 collect counter bytes long
 collect counter packets long
Use
Detect floods, scanning, and TCP-flag anomalies.
Monitor
Verify flow cache and exporter counters after enabling.
Key Takeaway

Define minimal, security-focused records and scale only after validating resource impact.
