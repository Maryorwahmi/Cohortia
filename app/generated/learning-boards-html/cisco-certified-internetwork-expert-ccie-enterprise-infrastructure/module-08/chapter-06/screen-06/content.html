Module 8 › Chapter 8.6 › Create Zones & Assign Interfaces
CLI Walkthrough
Execute these steps on R1 to create WAN, LAN, and DMZ zones and assign interfaces.
Commands
enable
configure terminal

zone security WAN
zone security LAN
zone security DMZ

interface GigabitEthernet0/0/0
 description WAN_Interface
 ip address 203.0.113.1 255.255.255.252
 zone-member security WAN
 no shutdown

interface GigabitEthernet0/0/1
 description LAN_Interface
 ip address 192.168.1.1 255.255.255.0
 zone-member security LAN
 no shutdown

interface GigabitEthernet0/0/2
 description DMZ_Interface
 ip address 172.16.1.1 255.255.255.0
 zone-member security DMZ
 no shutdown
Verification
Run the show commands below to confirm correct assignments and readiness before applying policies.
show zone security
show zone-pair security
Pro tip
Assign and verify interfaces first. Misassigned or missing zone-members cause later policies to have no effect and are a frequent troubleshooting source.
