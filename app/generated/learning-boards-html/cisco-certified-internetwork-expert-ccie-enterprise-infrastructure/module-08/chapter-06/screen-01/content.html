Cisco IOS Zone-Based Firewall
Policy-driven firewall on IOS XE routers using zones, zone-pairs, class-maps, and policy-maps.
Interactive 16:9 Masterclass

You'll learn to structure policies by grouping interfaces into zones and applying MQC policy-maps between those zones. That pattern enforces directional control and enables stateful inspection using the inspect action so return traffic is allowed without extra ACLs.

We will also cover common pitfalls such as forgetting the self zone, leaving interfaces unassigned, and using pass instead of inspect for TCP traffic. A hands-on CLI configuration ties these ideas together.

In this lesson
Zones, zone-pairs, MQC objects, stateful inspect, common mistakes, lab configuration.
