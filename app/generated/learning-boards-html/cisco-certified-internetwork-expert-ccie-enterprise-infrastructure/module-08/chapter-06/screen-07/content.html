Class-Maps: Match Criteria
Class-maps select traffic; they do not apply actions themselves.
Example class-map
class-map type inspect match-any LAN_TO_WAN_CM
 match protocol http
 match protocol https
 match protocol dns
Notes & common pitfalls
  • Use match-any to capture any of several protocols.
  • Class-maps should be precise to avoid broad matches that capture unrelated traffic.
  • Order of classes matters in the policy-map, not inside a class-map.
Test traffic
Generate HTTP or DNS queries from test hosts and confirm matches with show policy-map type inspect zone-pair output.
Misconception
Class-maps do not implicitly permit traffic; they only label it for policy action.
Key Takeaway

Build class-maps to precisely identify traffic and prefer match-any for common protocol groups you intend to inspect.
