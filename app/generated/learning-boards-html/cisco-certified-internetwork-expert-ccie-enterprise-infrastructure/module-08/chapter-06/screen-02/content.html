Learning Objectives
Bloom progression: Learn → Understand → Apply → Master
01
Explain ZBFW architecture
Describe zones, zone-pairs, class- and policy-maps and why implicit deny between zones improves security. This helps you choose correct enforcement points in network design.
VERIFIED COMPETENCY MILESTONE
02
Assign interfaces to zones
Configure zone security and zone-member assignments, ensuring each interface is in one zone and verifying with show commands to avoid accidental traffic loss.
VERIFIED COMPETENCY MILESTONE
03
Create MQC class- & policy-maps
Match protocols or ACLs with class-maps and define inspect, pass, or drop actions in policy-maps. Ordering matters; place specific matches before general ones.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot and verify
Use show zone, show zone-pair, show policy-map type inspect, and show ip inspect sessions plus debug when needed to confirm expected behavior and resolve one-way flows.
VERIFIED COMPETENCY MILESTONE
