Quick Reference: 3 Core Concepts
Zone
Logical grouping of interfaces representing a security domain.
Zone-Pair
Declares source→destination direction where policies are enforced.
Inspect
Stateful action that tracks sessions and permits legitimate return traffic.
Takeaway
Use zones to express intent, MQC objects to implement it, and inspect to simplify return-traffic handling while relying on explicit zone-pairs to allow flows.
