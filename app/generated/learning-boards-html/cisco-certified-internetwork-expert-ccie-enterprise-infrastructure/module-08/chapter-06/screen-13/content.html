Common Mistakes & Preventive Checks
A short checklist to avoid the most frequent errors when deploying ZBFW.
Forgot self zone
Create zone-pairs involving self if router-originated or destined traffic must be allowed from other zones.
Unassigned interfaces
Ensure every interface that should participate in policies has zone-member security configured.
Implicit deny surprise
Remember: inter-zone traffic must be permitted explicitly; do not assume it flows by default.
Inspect vs Pass error
Use inspect for TCP/UDP where stateful return traffic is required; pass is stateless.
Quick Checklist

After changes: check zones, zone-pairs, policy attachments, class hit counts, and inspect sessions; test client traffic for expected flows.
