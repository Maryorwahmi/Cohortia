MQC Workflow for ZBFW
Stepwise process to build and attach inspection policies.
Step 1
Define class-map
Match protocols or ACLs to classify traffic.
Step 2
Create policy-map
Attach inspect, pass, or drop actions per class.
Step 3
Define zone-pair
Declare source and destination zones for the policy.
Step 4
Attach service-policy
Apply the policy-map to the zone-pair to enforce it.
Concrete CLI snippet
class-map type inspect match-any LAN_TO_WAN_CM
 match protocol http
 match protocol https
 match protocol dns

policy-map type inspect LAN_TO_WAN_PM
 class type inspect LAN_TO_WAN_CM
  inspect
Verification
show policy-map type inspect zone-pair and show ip inspect sessions.
Misconception
Applying an ACL directly to an interface is not the same as attaching an MQC policy to a zone-pair; ZBFW enforces inter-zone behavior via zone-pair policies.
