05
Implement stateful inspect
Use inspect in policy-maps for TCP and UDP to track sessions so return traffic is automatically permitted for established flows. This simplifies ACL management and reduces errors.

06
Handle the self zone
Recognize that traffic to or from the router is represented by the self zone. Create explicit zone-pairs to permit management access when needed.
VERIFIED COMPETENCY MILESTONE
07
Class-map matching
Choose match-any for protocol lists like HTTP/HTTPS/DNS. Order and specificity matter inside policy-maps to avoid unintended matches.

08
Verify with show/debug
Run show zone security, show policy-map type inspect, and show ip inspect sessions to confirm policies and active sessions. Use debug when deeper packet-level insight is required.
