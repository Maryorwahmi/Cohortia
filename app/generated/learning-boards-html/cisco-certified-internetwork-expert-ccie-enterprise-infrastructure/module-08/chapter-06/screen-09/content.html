Define Zone-Pairs & Attach Policies
Zone-pairs make direction explicit and are where you apply service-policy.
Example commands
zone-pair security LAN_TO_WAN source LAN destination WAN
 service-policy type inspect LAN_TO_WAN_PM

zone-pair security WAN_TO_DMZ source WAN destination DMZ
 service-policy type inspect WAN_TO_DMZ_PM
Important notes
  • Zone-pairs are directional; define both directions if bidirectional policies are needed.
  • Attaching a policy without proper class-maps results in no matches and ineffective policies.
  • Verify attached policy-map hit counts to confirm traffic matching.
Verification
show zone-pair security and show policy-map type inspect zone-pair <name> for details and counters.
Misconception
Zone-pairs are not symmetric; allowing A→B does not permit B→A unless a separate zone-pair exists.
