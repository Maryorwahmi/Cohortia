Troubleshooting Checklist
Step-by-step verification and targeted debug guidance.
Verification commands
show zone security
show zone-pair security
show policy-map type inspect zone-pair LAN_TO_WAN
show ip inspect sessions
Debugging
Use debug zone for packet processing logs but limit duration and output to avoid flooding device logs.
Common scenarios
  • Zero-hit counters: misconfigured class-match or wrong order in policy-map.
  • One-way traffic: used pass instead of inspect for TCP.
  • Management unreachable: missing zone-pair to self zone.
Key Takeaway

Follow the verification sequence and use debug selectively to map observed drops back to MQC objects responsible for decisioning.
