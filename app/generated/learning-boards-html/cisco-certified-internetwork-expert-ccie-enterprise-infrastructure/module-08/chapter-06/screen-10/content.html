Comparison: ZBFW and Traditional ACLs
Understand where each approach is appropriate and why ZBFW is preferred for directional, stateful policies.
Traditional ACLs
  • Stateless: evaluate packets independently.
  • Applied per-interface.
  • Return traffic often requires explicit permits.
ZBFW
  • Stateful when using inspect: tracks sessions and permits return traffic.
  • Policy-driven with zones and zone-pairs.
  • Implicit deny between zones improves security posture.
Migration tip
Map existing ACL intent to class-maps and policy-maps, test incrementally, and always verify with show commands.
