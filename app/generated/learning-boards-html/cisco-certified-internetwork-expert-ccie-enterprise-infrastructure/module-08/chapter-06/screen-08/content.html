Policy-Maps: Actions Explained
Choose actions based on whether you need stateful behavior.
Inspect
Stateful. Tracks TCP handshakes and allows return traffic for established sessions.
Pass
Permit without state tracking. Use for simple, connectionless flows where state is not required.
Drop
Explicitly deny matched traffic.
CLI example
policy-map type inspect LAN_TO_WAN_PM
 class type inspect LAN_TO_WAN_CM
  inspect
Verification
show ip inspect sessions shows tracked sessions created by inspect.
Common mistake
Using pass for TCP services without additional return permissions often yields one-way communication.
