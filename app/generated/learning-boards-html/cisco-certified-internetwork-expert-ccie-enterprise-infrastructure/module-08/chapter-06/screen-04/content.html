Module 8 › Chapter 8.6 › Security Zones
Definition & behavior
Zones group interfaces and set the default security posture between those groups.

Implicit deny between zones: Without a zone-pair policy, traffic that tries to flow from one zone to another is dropped.

Implicit permit within a zone: Interfaces in the same zone can communicate without policies.

Assigned interfaces only: Unassigned interfaces do not participate in zoned traffic and can cause unexpected drops.

Example
LAN initiates HTTP to WAN; LAN-to-WAN inspect permits session and return traffic.
Common mistake
Forgetting to assign an interface to a zone causes it to be excluded from zone-pair policies.
Key Takeaway

Design zones first, assign every interface, and rely on implicit deny between zones to reduce attack surface.

Quick reference: zone commands
zone security WAN
zone security LAN
zone security DMZ

interface GigabitEthernet0/0/0
 zone-member security WAN
