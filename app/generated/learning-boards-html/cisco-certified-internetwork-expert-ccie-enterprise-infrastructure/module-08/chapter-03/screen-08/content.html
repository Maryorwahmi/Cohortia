Apply the policy to the control-plane

Use control-plane service-policy input and then use show policy-map control-plane for verification.

control-plane
 service-policy input PM_CONTROL_PLANE
What to inspect
  • Matched packets per class
  • Policed or dropped packet counts
  • Whether drops align with expected test events or real spikes
Example output (abstracted)
Policy Map PM_CONTROL_PLANE
 Class CM_SSH
  packets: 1200, drops: 2
 Class CM_OSPF
  packets: 4500, drops: 0
 Class CM_DEFAULT_CP
  packets: 7000, drops: 120
Interpretation
Non-zero drops in the default class suggest unknown control-plane traffic is being limited; evaluate whether those packets are malicious or legitimate before changing policies.
