Module 08 › Chapter 8.3 › Management Plane Protection
Definition

What MPP enforces

MPP defines which interfaces may deliver management protocols to the control plane, preventing management traffic on unintended interfaces.

control-plane host
 management-interface GigabitEthernet0/0/0 allow ssh snmp
 management-interface Vlan10 allow ssh http
Safety note
Ensure console or out-of-band access is available before tightening MPP to avoid administrative lockout.
Quick checklist
  • List management protocols required by operations.
  • Identify trusted management interfaces and VLANs.
  • Apply management-interface allow entries for each.
  • Test access and keep a rollback path.
Example
Only allow SSH and SNMP on a dedicated out-of-band GigabitEthernet port to reduce exposure from in-band data traffic.
