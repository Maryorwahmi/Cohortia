Module 08 › Chapter 8.3 › Class-maps & ACLs
How to

Create ACLs for control-plane traffic

Target management and routing flows with precise ACL entries. Consider source restrictions for SSH to limit admin subnets.

ip access-list extended COPP_SSH
 permit tcp any any eq 22
ip access-list extended COPP_OSPF
 permit ospf any any
Class-maps
Reference ACLs inside class-maps so the policy-map can apply policing per named class.
class-map match-any CM_SSH
 match access-group name COPP_SSH
class-map match-any CM_OSPF
 match access-group name COPP_OSPF
class-map CM_DEFAULT_CP
 match default-class
Practical notes
  • Use descriptive names to make audits easier.
  • Prefer match access-group name so you can reuse ACLs across policies.
  • Keep a default-class to ensure unknown traffic is controlled.
Misconfiguration risk
A broad ACL that permits any source for SSH increases attack surface. Scope ACLs to admin IP ranges when possible.
Quick example
If admins use an out-of-band network, restrict COPP_SSH to that source subnet to reduce risk from the data plane.
