Module 08 › Chapter 8.3 › Attack Simulation
Simulation steps
  1. Ensure lab or maintenance environment and console access.
  2. From a test host, generate a high-rate packet stream targeting the router's control-plane IP.
  3. On the router, run show policy-map control-plane while the test runs.
  4. Observe which classes show matched packets and drops, and monitor CPU and adjacency state.
Expected result
Abusive traffic should be dropped or policed while critical classes remain within their allowed rates, preserving adjacencies and management sessions.
Observability
Key places to watch: show policy-map control-plane counters, CPU utilization, and routing adjacency states. If adjacencies drop, policing is too strict for routing classes.
Mitigation beyond CoPP
If attacks persist, upstream filtering or ACLs at edge devices can reduce incoming abusive traffic before it reaches the router.
