Module 8 › Chapter 8.4 › Combined Deployment
Step-by-step
  1. Define time-range objects for BUSINESS_HOURS and any maintenance windows.
  2. Create extended ACLs with time-range references for scheduled denies, ensuring denies appear before general permits.
  3. Define INSIDE_OUT with reflect entries for session groups and apply it out on the WAN interface.
  4. Create OUTSIDE_IN and include evaluate names to accept reflected return traffic; apply it in on the WAN interface.
  5. Enable uRPF on LAN interfaces: strict if symmetry is guaranteed, loose otherwise.
  6. Validate with show access-lists, show time-range, show ip interface, and test clients during and outside business hours.
Scenario snippet

Block outbound HTTP/HTTPS to 10.0.0.0/8 during BUSINESS_HOURS, allow only reflexive return traffic, and enable uRPF strict on Gi0/0/1.

Rollback tip

Have the previous ACL and no-U RPF commands ready to revert quickly if you see unexpected drops during testing.

Key Takeaway

Plan, stage, and verify each change. Combined policies harden the data plane but require careful testing to avoid collateral impact.
