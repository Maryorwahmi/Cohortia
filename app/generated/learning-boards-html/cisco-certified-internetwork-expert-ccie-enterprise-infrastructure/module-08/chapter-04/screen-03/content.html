Practice & Verification

Hands-on checks that prevent misconfiguration and service loss.

Tools: show / debug / test clients
ACL verification

Use show access-lists and show ip access-lists to confirm ordering, matches, and counters.

Reflexive checks

Initiate outbound sessions, then observe dynamically created inbound entries to ensure only legitimate return flows are allowed.

uRPF diagnostics

Confirm ip verify unicast reverse-path status with show ip interface and correlate with routing table lookups to detect asymmetry.
