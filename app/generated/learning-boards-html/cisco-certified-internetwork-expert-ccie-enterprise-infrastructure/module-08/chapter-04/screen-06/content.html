Module 8 › Chapter 8.4 › Reflexive ACLs
Pattern

Reflect on outbound, reference inbound

Outbound ACL entries with reflect create temporary inbound entries that allow return traffic only for initiated sessions.

ip access-list extended INSIDE_OUT
 permit ip 192.168.1.0 0.0.0.255 any reflect WEB_SESSION
 permit ip any any
!
ip access-list extended OUTSIDE_IN
 evaluate WEB_SESSION
 permit icmp any any echo-reply
 deny ip any any log
How to apply
  • Apply INSIDE_OUT on the outbound interface (out).
  • Apply OUTSIDE_IN on the inbound interface (in) and include evaluate WEB_SESSION.
  • Watch dynamic entries with show ip access-lists after initiating sessions.
Misconception

Reflexive ACLs are not a replacement for a stateful firewall for complex application inspection; they are a router-based method to allow return traffic while blocking unsolicited inbound flows.

Key Takeaway

Use reflexive ACLs to permit return traffic for outbound-initiated sessions and avoid broad static inbound permits.
