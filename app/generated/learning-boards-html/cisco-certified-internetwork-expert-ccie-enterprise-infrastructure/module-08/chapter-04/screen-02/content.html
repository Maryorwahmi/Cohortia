Learning Objectives

Master targeted ACLs, reflexive session filtering, and uRPF deployment decisions.

Bloom: Learn → Understand → Apply → Master
01
Advanced extended ACLs

Write granular rules matching IPs, ports and protocols to permit and deny specific traffic for policy enforcement.

VERIFIED COMPETENCY MILESTONE
02
Time-based ACLs

Create time-range objects and reference them so rules apply only during defined business hours or maintenance windows.

VERIFIED COMPETENCY MILESTONE
03
Reflexive ACLs

Use reflect entries to dynamically allow return traffic only for sessions initiated from the inside network.

VERIFIED COMPETENCY MILESTONE
04
uRPF modes and deployment

Configure strict and loose uRPF, choose the correct mode for asymmetric routing, and verify behavior with show/debug commands.
