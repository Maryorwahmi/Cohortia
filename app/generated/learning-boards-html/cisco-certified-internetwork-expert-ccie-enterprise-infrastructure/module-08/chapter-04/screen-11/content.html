! R1 Configuration (lab example)
enable
configure terminal

! Define time-range
time-range BUSINESS_HOURS
 periodic weekdays 09:00 to 17:00

! Time-based ACL to block placeholder social media (10.0.0.0/8)
ip access-list extended BLOCK_SOCIAL
 deny tcp 192.168.1.0 0.0.0.255 10.0.0.0 0.255.255.255 eq 80 time-range BUSINESS_HOURS
 deny tcp 192.168.1.0 0.0.0.255 10.0.0.0 0.255.255.255 eq 443 time-range BUSINESS_HOURS
 permit ip any any

! Reflexive ACLs
ip access-list extended INSIDE_OUT
 permit ip 192.168.1.0 0.0.0.255 any reflect WEB_SESSION
 permit ip any any

ip access-list extended OUTSIDE_IN
 evaluate WEB_SESSION
 permit icmp any any echo-reply
 deny ip any any log

! Interfaces
interface GigabitEthernet0/0/0
 description WAN_Interface
 ip address  255.255.255.252
 ip access-group OUTSIDE_IN in
 ip access-group INSIDE_OUT out
 no shutdown

interface GigabitEthernet0/0/1
 description LAN_Interface
 ip address 192.168.1.1 255.255.255.0
 ip access-group BLOCK_SOCIAL out
 ip verify unicast reverse-path
 no shutdown

end
write memory
Test checklist
  • Confirm time-range with show time-range.
  • Test client access to 10.0.0.1 during business hours (should be blocked).
  • Initiate outbound session and run show ip access-lists OUTSIDE_IN to view WEB_SESSION.
  • Verify uRPF with show ip interface GigabitEthernet0/0/1.
Note

Replace placeholder addresses with real IPs in production and schedule maintenance windows for testing.

Key Takeaway

Follow the checklist and validate each control with show commands and test traffic before trusting policies in production.
