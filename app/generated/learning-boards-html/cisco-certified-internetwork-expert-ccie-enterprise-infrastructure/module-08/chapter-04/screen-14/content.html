Module 8 › Chapter 8.4 › Key Concepts
ACL Ordering
ACLs are top-down; specific denies must come before broad permits.
Reflexive ACLs
Reflect creates temporary inbound permits for return traffic initiated from inside.
uRPF Modes
Strict checks interface symmetry; loose checks for routability only.
Summary

Combine schedule-aware ACLs, reflexive session permits, and uRPF checks for layered data plane protection — but always test, verify, and monitor.
