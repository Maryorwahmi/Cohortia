Module 8 › Chapter 8.4 › Data Plane Basics
Definition

What the data plane does

The data plane forwards packets and enforces per-packet ACLs. It is distinct from the control plane, which maintains routing and device state.

Operational note

ACLs are processed top-down on the data plane. The first matching rule determines the packet fate.

Common Mistake

Placing a broad permit before specific denies can nullify security intent and allow malicious traffic through.

Analogy

Security checkpoint

Think of ACLs as a checkpoint at the door of a building. Every person is checked against ordered rules; the first rule that applies decides the outcome.

Key Takeaway

Design ACLs carefully, test them, and verify behavior after deployment to avoid accidental service disruption.
