Module 8 › Chapter 8.4 › uRPF Modes
Strict Mode

ip verify unicast reverse-path

Checks that the routing entry for the source IP uses the same interface the packet arrived on. Best for stub networks.

Pros
  • Strong anti-spoof protection.
  • Blocks off-path forged sources.
Loose Mode

ip verify unicast reverse-path any

Only checks if a route exists for the source IP anywhere in the routing table. Suitable for multi-homed or asymmetric routes.

Pros
  • Works with asymmetric routing.
  • Provides basic anti-spoof protection without strict interface matching.
Deployment advice

Validate routing symmetry before enabling strict mode. When unsure, start with loose mode and monitor drops while you investigate routes.

Key Takeaway

Mode selection depends on topology: strict for symmetric, loose for asymmetric, always test and monitor after change.
