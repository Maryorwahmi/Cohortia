Diagnostic Sequence
  1. show ip interface <intf> | include uRPF — confirm uRPF status.
  2. show ip route <source-ip> — find route and outgoing interface for source.
  3. show access-lists — check ACL counters and matching entries.
  4. show time-range — validate scheduled objects and device clock.
  5. Use controlled debug if needed: debug ip packet with filters in lab only.
Common resolutions
  • Switch uRPF to loose mode for asymmetric routing.
  • Reorder ACLs to ensure specific denies are evaluated first.
  • Ensure NTP sync for correct time-range evaluation.
Safety tip

When using debug commands, scope them to affected addresses or use a lab to avoid overwhelming production routers.

Key Takeaway

Systematically correlate uRPF checks, routing information, and ACL counters to find and fix drops efficiently.
