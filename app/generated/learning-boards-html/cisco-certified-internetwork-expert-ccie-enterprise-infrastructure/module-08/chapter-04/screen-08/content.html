What uRPF does

Anti-spoofing by route verification

uRPF checks the routing table for the packet's source IP; if no route exists, or if strict-mode requires the incoming interface to match the route and it doesn't, the packet is dropped.

Why it matters

Many amplification and reflection attacks rely on forged source addresses; uRPF stops these by ensuring the source is routable and originates from a valid path.

Key Commands

ip verify unicast reverse-path ip verify unicast reverse-path any show ip interface & include uRPF

Common Pitfall

Applying strict uRPF on interfaces with asymmetrical routing will drop legitimate traffic; validate routing symmetry before enabling strict mode.

Key Takeaway

Choose uRPF mode based on your topology: strict for symmetrical, loose for asymmetric or multi-homed networks.
