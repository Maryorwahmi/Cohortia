Module 8 › Chapter 8.4 › Reflexive CLI Walkthrough
CLI Example
ip access-list extended INSIDE_OUT
 permit ip 192.168.1.0 0.0.0.255 any reflect WEB_SESSION
 permit ip any any
!
ip access-list extended OUTSIDE_IN
 evaluate WEB_SESSION
 permit icmp any any echo-reply
 deny ip any any log
!
interface GigabitEthernet0/0/0
 ip access-group OUTSIDE_IN in
 ip access-group INSIDE_OUT out
Verification steps
  1. Initiate a connection from inside to outside.
  2. Run show ip access-lists OUTSIDE_IN to confirm dynamic entries.
  3. Check counters to ensure matches and correct aging behavior.
Troubleshoot

If return traffic is blocked, confirm reflect names and ACL directions; missing evaluate or wrong interface application are common causes.

Key Takeaway

Observe dynamic entries after traffic initiation to validate reflexive ACL behavior before trusting the ACL in production.
