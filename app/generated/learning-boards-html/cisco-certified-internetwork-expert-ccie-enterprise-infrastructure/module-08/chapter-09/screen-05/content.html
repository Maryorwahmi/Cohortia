Module 9 › Chapter 8.9 › TrustSec Workflow
Process

Authentication → Tag → Enforce

  1. 802.1X authenticates the client at the access device.
  2. Access device forwards authentication to ISE.
  3. ISE assigns SGT and returns it to the device.
  4. Devices carry or exchange SGTs; enforcement applies SGACLs.
Example scenario

User authenticates, ISE labels them as Employees, SGACLs allow access to approved services while blocking others.

SXP vs Inline Tagging
Inline Tagging

Newer devices insert SGTs directly into headers for direct enforcement.

SXP

SXP shares SGT-to-IP mappings between devices that cannot carry tags inline so enforcement is still possible.

Key Takeaway

Map authentication, tagging, and enforcement end-to-end to ensure policies follow identity, not IPs.
