Module 9 › Chapter 8.9 › MACsec Overview
Definition

MACsec — IEEE 802.1AE

Provides hop-by-hop encryption and integrity for Ethernet frames between directly connected devices. Protects payload confidentiality and prevents tampering and replay attacks on the link.

When to use

Use on sensitive trunk or uplink links, or between switches and routers where physical security is a risk.

Limitation

MACsec secures links but does not replace end-to-end encryption at higher layers when needed.

Key terms
  • CAK — Connectivity Association Key
  • SAK — Security Association Key
  • MKA — MACsec Key Agreement
