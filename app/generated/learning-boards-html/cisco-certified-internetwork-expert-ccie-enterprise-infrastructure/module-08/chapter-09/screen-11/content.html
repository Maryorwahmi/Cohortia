Module 9 › Chapter 8.9 › MACsec Lab

Lab objective

Secure GigabitEthernet1/0/1 between two Catalyst 9300 switches using MACsec with a pre-shared key.

Steps
  1. Create key chain MACSEC_KEYCHAIN with key 0 and key-string.
  2. Create mka policy MY_MKA_POLICY and set key-server priority.
  3. Configure interface as trunk, apply mka pre-shared-key and mka policy, enable macsec.
  4. Save configuration and verify.

Reference CLI

enable
configure terminal

! Step 1: Create key chain
key chain MACSEC_KEYCHAIN
 key 0
  key-string CiscoMACsec123

! Step 2: Create MKA policy
mka policy MY_MKA_POLICY
 key-server priority 100

! Step 3: Configure interface
interface GigabitEthernet1/0/1
 description Link to peer (MACsec Enabled)
 switchport mode trunk
 mka pre-shared-key key-chain MACSEC_KEYCHAIN
 mka policy MY_MKA_POLICY
 macsec
 no shutdown

end
write memory
Pro tip

Mirror the configuration exactly on both ends. Use show commands right after configuring to confirm MKA sessions and MACsec status.
