Module 9 › Chapter 8.9 › MACsec Keying

CAK → SAK

The CAK is a shared secret used to derive SAKs. SAKs are the operational keys that encrypt and authenticate frames on the link.

MKA

MKA negotiates and manages keys. It can run over 802.1X to leverage device authentication before key agreement.

Key Takeaway

Use dynamic MKA with 802.1X in production for secure key lifecycle; static keys are acceptable for controlled lab scenarios.

Example CLI (pre-shared key)

key chain MACSEC_PSK_KEY
 key 0
  key-string 7 <encrypted_key_string>
!
mka policy MY_MACSEC_POLICY
 key-server priority 100
!
interface GigabitEthernet1/0/1
 mka pre-shared-key key-chain MACSEC_PSK_KEY
 mka policy MY_MACSEC_POLICY
 macsec
Ensure both ends use identical key chains and MKA policies or the session will not form.
