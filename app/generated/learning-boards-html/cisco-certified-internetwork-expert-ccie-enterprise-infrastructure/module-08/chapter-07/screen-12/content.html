R1 Configuration (Steps)
enable
configure terminal

! SSHv2
hostname R1
ip domain name cohortia.local
crypto key generate rsa modulus 2048
ip ssh version 2
ip ssh authentication-retries 3
ip ssh timeout 120

! Local admin
username admin privilege 15 secret CiscoSecure!

! VTY
line vty 0 4
 transport input ssh
 login local

! SNMPv3
snmp-server view ALL_MIB iso included
snmp-server group MONITOR_GROUP v3 priv read ALL_MIB
snmp-server user monitor_user MONITOR_GROUP v3 auth sha AuthPass123 priv aes 128 PrivPass123

! NTP auth
ntp authentication-key 1 md5 NTPKey456
ntp authenticate
ntp trusted-key 1
ntp server 10.0.0.1 key 1

! Logging
interface Loopback0
 ip address 1.1.1.1 255.255.255.255
 no shutdown
!
logging host 192.168.10.20
logging source-interface Loopback0
logging trap informational

end
write memory
Verification Checklist
  • show ip ssh → confirm version and timeouts
  • show crypto key mypubkey rsa → confirm key present
  • Attempt SSH login using the admin account
  • show snmp user / show snmp group → confirm auth/priv
  • show ntp associations detail → confirm authenticated association
  • Verify syslog messages arrive at 192.168.10.20 from 1.1.1.1
