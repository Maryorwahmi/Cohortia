Module 8 › Chapter 8.7 › Key Concepts
SSH
Encrypted protocol for secure remote access and command-line operations.
SCP / SFTP
SSH-backed file transfer methods; SCP for simple copies, SFTP for advanced file ops.
SNMPv3
Provides authentication, privacy, and access control for network monitoring.
Summary

Secure transports, strong authentication, and least-privilege access form the core of management-plane security.
