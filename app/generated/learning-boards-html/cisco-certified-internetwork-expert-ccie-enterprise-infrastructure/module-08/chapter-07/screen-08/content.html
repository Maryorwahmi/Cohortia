Module 8 › Chapter 8.7 › SNMPv3 Configuration
Commands
snmp-server view MY_VIEW iso included
snmp-server group MY_GROUP v3 priv read MY_VIEW write MY_VIEW
snmp-server user admin_snmp MY_GROUP v3 auth sha CohortiaAuthPass priv aes 128 CohortiaPrivPass
Each line: view limits MIB; group sets v3 security level and maps view; user binds credentials and methods.
Verification
Run show snmp user and show snmp group. From an SNMP manager, poll a known OID under the allowed view using the configured auth and priv credentials.
Misconfiguration risk: creating a view that includes sensitive MIB objects or using weak privacy algorithms reduces the benefits of SNMPv3.
