Module 8 › Chapter 8.7 › Configure SSHv2
Step-by-step
  1. Set hostname and ip domain-name.
  2. Generate RSA keys: crypto key generate rsa modulus 2048.
  3. Enable SSHv2: ip ssh version 2.
  4. Tune: ip ssh authentication-retries and ip ssh timeout.
  5. Configure line vty 0 4 transport input ssh and authentication method.
  6. Create a local admin user or configure AAA with fallback.
Safety tip: Always verify you have a local account with privilege 15 before enforcing AAA or disabling other transports.
Configuration Example
hostname R1
ip domain name cohortia.local
crypto key generate rsa modulus 2048
ip ssh version 2
ip ssh authentication-retries 2
ip ssh timeout 60
!
line vty 0 4
 transport input ssh
 login local
Run show ip ssh and show crypto key mypubkey rsa to confirm.
