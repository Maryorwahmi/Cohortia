Common Verification Commands
SSH: show ip ssh, show crypto key mypubkey rsa
SNMP: show snmp user, show snmp group
NTP: show ntp associations detail
Syslog: confirm messages on server and check source-interface config
These checks validate both security parameters and operational connectivity. Always perform a test access and a read-only polling action after configuration.
Common Mistakes to Watch For
  • Generating RSA keys without hostname/domain set
  • Removing the only local admin before AAA is ready
  • Failing to configure NTP authentication keys on both peers
  • Not specifying a stable source-interface for syslog
