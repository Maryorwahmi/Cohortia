Module 8 › Chapter 8.7 › Secure Syslog
Key Steps
  • Choose secure transport (TLS or SSH if supported) and port.
  • Set logging host and transport parameters.
  • Specify logging source-interface, preferably a loopback.
  • Ensure server-side authentication and certificates if using TLS.
Example Snippet
interface Loopback0
 ip address 1.1.1.1 255.255.255.255
 no shutdown
!
logging host 192.168.10.20
logging source-interface Loopback0
logging trap informational
Confirm messages on the server and check that the source IP matches the loopback address to ensure reliable forwarding and correlation.
