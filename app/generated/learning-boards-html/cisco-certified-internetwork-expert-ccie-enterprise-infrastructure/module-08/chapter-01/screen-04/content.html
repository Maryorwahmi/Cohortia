Authentication, Authorization, Accounting
A concise definition and real-world relevance for network control and audit.
Authentication
Verify identity using credentials or certificates. Example: a TACACS+ server validates an admin's username and password or a RADIUS server validates a user's supplicant credentials for 802.1X.
Authorization
Decide permitted actions and assign network policies like VLANs or command sets. Example: send a vendor-specific attribute for VLAN assignment after RADIUS authentication.
Accounting
Record who did what and when for audits and incident response. Example: TACACS+ logs of command executions tied to a username.
Key Takeaway

Treat AAA as an integrated control plane: authentication is not enough unless accompanied by precise authorization and reliable accounting.

Analogy
Think of AAA like a building: authentication is checking ID at the door, authorization is which rooms you're allowed to enter, and accounting is the security camera logs that record where you went.
Common misconception
Assuming authentication fixes all security problems. Without granular authorization and accounting, you cannot enforce least privilege or conduct audits effectively.
