Authentication flow
A practical outline of messages and responsibilities in a working 802.1X deployment.
Step 1 — Supplicant
Client sends EAP start, challenging the switch to authenticate the session.
Step 2 — Switch (authenticator)
Switch forwards EAP messages to the RADIUS server and enforces port control based on responses.
Step 3 — ISE (RADIUS)
ISE validates the identity source and returns attributes such as VLAN, ACLs, or a reject.
Configuration hints
  • Switch ports: authentication port-control auto
  • Ensure RADIUS server entries and shared secrets match
  • Validate AD integration and ISE authorization rules
Troubleshoot
If VLAN assignment fails, check that ISE is sending the correct vendor-specific attributes and that the switch accepts them.
