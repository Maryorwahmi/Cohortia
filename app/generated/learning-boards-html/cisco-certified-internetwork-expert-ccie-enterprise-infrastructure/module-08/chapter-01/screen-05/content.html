Module 8 › Chapter 8.1 › Comparison
TACACS+
Cisco proprietary; full packet encryption; separates AAA functions for fine-grained administrative control.
When to use
Device administrative access and command authorization in multi-admin environments.
Strengths
  • Granular exec and command authorization
  • Entire packet encryption
  • Clear audit trail for admin commands
RADIUS
Open standard; combines authentication and authorization; encrypts only the password field; excels at attribute-driven network policy.
When to use
802.1X port authentication, wireless access, and dynamic VLAN/QoS assignment through attributes.
Strengths
  • Wide vendor support
  • Rich attribute-value pairs for dynamic policy
  • Commonly integrates with ISE and AD
Concrete example
A router uses TACACS+ to verify and authorize an admin's enable-level commands while a switch uses RADIUS to assign a wireless user to VLAN 20 based on a RADIUS attribute returned by ISE.
Common mistake
Assuming one protocol fits all. Deploy each protocol where its strengths align with the requirement: TACACS+ for admin control, RADIUS for network access policies.
