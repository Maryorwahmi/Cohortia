Starter configuration (lab)
! R1 Configuration
enable
configure terminal

aaa new-model

tacacs-server host 192.168.10.10 key Cisco123

aaa authentication login TAC_LOCAL_AUTH group tacacs+ local

line console 0
 login authentication TAC_LOCAL_AUTH
line vty 0 4
 login authentication TAC_LOCAL_AUTH

aaa authorization exec TAC_AUTHZ group tacacs+ local
aaa authorization commands 15 TAC_AUTHZ group tacacs+ local

line vty 0 4
 authorization exec TAC_AUTHZ
 authorization commands 15 TAC_AUTHZ

username admin_local privilege 15 secret cohortia

end
write memory
Verification steps: 1) Create a TACACS+ user on the server and test login. 2) Disable TACACS+ connectivity and authenticate with admin_local to confirm fallback. 3) Check logs on both device and server to confirm accounting and command records.
Simulate failure
Block reachability to 192.168.10.10 or stop the TACACS+ service, then attempt remote login. The device should fall back to local authentication if configured correctly.
Common mistake
Forgetting to add the local user or applying the method list incorrectly will prevent fallback and may lock you out.
