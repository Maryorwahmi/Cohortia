Module 8 › Chapter 8.1 › Troubleshooting
Supplicant checks
  • Is 802.1X enabled on the client?
  • Correct EAP method selected?
  • Client credentials valid and not expired?
Certificate checks
  • Does client trust the RADIUS server CA?
  • Are server certificates valid and not expired?
  • Check chain and CRL/OCSP if used
Attribute delivery
  • Is ISE sending Vendor-Specific Attributes for VLAN?
  • Does the switch accept and map those attributes?
  • Test with a simple static profile first
Debug pattern
Start with the supplicant, then the switch, then the RADIUS/ISE logs. Reproduce the failure with a known-good test user and a minimal policy to narrow the source of the problem.
