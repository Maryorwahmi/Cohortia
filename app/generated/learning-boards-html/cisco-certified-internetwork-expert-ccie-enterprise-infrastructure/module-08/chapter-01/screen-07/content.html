Ordered method lists
A clear example shows ordering and the intended fallback behavior.
aaa authentication login TAC_LOCAL_AUTH group tacacs+ local aaa authorization exec TAC_AUTHZ group tacacs+ local aaa authorization commands 15 TAC_AUTHZ group tacacs+ local
Test process: connect to console and apply method list, then restart or block TACACS+ connectivity and confirm local user can still authenticate. Repeat the test on VTY after console validation.
Checklist
  • Validate aaa new-model is enabled.
  • Synchronize shared secrets exactly.
  • Apply and test on console before remote lines.
  • Simulate server failure to verify fallback.
Common pitfall
Relying on a default or global method list without lab testing can leave you without remote access when servers fail.
