Module 8 › Chapter 8.1 › Learning Objectives
01
Differentiate TACACS+ and RADIUS

Understand protocol differences, encryption scope, and use cases so you select the correct tool for admin or network access. This prevents misapplied policies and strengthens security posture.

Verified competency milestone
02
Configure TACACS+ on IOS XE

Create method lists, define TACACS+ hosts, and set local fallbacks so devices remain manageable even if the server fails. Exact command order matters to avoid lockout during rollout.

Verified competency milestone
03
Implement 802.1X with RADIUS and ISE

Configure switch ports and ISE policies so authenticated users receive the correct VLAN and service policies. Test supplicant behavior and certificate chains in a lab before production.

Verified competency milestone
04
Troubleshoot and secure AAA deployments

Identify shared secret mismatches, server reachability problems, and supplicant certificate issues. Implement redundant servers and logging to reduce service interruption and security gaps.

Verified competency milestone
