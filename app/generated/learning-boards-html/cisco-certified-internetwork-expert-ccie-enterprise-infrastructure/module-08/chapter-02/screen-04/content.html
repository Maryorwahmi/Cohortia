Module 8 › Chapter 8.2 › 802.1X Overview
Definition

Port-based access control

802.1X keeps a port unauthorized by default. Only EAP traffic is allowed until the authentication server accepts the supplicant.

Example
A visitor laptop remains blocked until credentials are validated, then is placed into a guest VLAN if authorized.
Common misconception
802.1X is not only for wired ports; wireless controllers and VPN gateways often act as authenticators using the same flow.
Key Takeaway

802.1X moves trust from physical connection to authenticated identity and enables policy-based authorization.

How it works
Deny by default
Ports block regular traffic until authentication succeeds.
RADIUS attributes
Access-Accept may include VLAN, ACL, or QoS attributes to enforce policy.
Fallback planning
Plan guest VLANs and highly available RADIUS servers to avoid service disruption.
Think: how would deny-by-default change onboarding for unmanaged devices?
