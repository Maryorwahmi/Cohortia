Module 8 › Chapter 8.2 › Troubleshooting
Stepwise checklist
  1. Verify supplicant EAP type and credentials or certificates.
  2. Check switch session with show authentication sessions interface & show dot1x all.
  3. Confirm RADIUS Access-Request receipt and shared secret match.
  4. Inspect server logs for Access-Accept/Reject reasons and returned attributes.
Useful commands
show dot1x all, show authentication sessions interface <if> details, debug dot1x all (use in maintenance), and server-side RADIUS logs.
Common root causes
  • Supplicant disabled or wrong EAP type.
  • Incorrect RADIUS shared secret or missing server client entry.
  • Switch misconfigured port mode (not access) or missing dot1x system-auth-control.
Practical tip
Always confirm the supplicant attempts authentication before using noisy debugging; this saves time and reduces disruption.
Safety note

Use debug commands carefully in production. Prefer log collection and server-side traces during live troubleshooting.
