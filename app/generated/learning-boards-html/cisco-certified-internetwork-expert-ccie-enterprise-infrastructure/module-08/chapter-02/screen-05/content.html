Module 8 › Chapter 8.2 › 802.1X Roles
Roles
Supplicant
Client device running the 802.1X client.
Authenticator
Switch or WLC that places the port in unauthorized/authorized states and forwards EAP to RADIUS.
Auth Server
RADIUS server validates credentials and returns Access-Accept or Access-Reject with attributes.
Practical example
Laptop supplicant sends identity, authenticator forwards a RADIUS Access-Request, server returns Access-Accept assigning VLAN 200.
Why boundaries matter

Knowing which component performs verification, enforcement, and policy lets you target checks quickly during incidents.

Misstep to avoid
Treating the switch as the policy engine instead of the authenticator leads to misconfigured authorization attributes on Access-Accept.
