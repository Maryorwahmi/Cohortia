Module 8 › Chapter 8.2 › Host-Mode Options
multi-host
Allows multiple devices after the first authenticates. Simpler but only the initial device is authenticated; subsequent endpoints inherit access.
Use when device authentication per client is not required.
multi-auth
Authenticates each device individually so every endpoint has its own session and authorization attributes.
Use when per-device accountability is required.
multi-domain
Designed for IP phone + PC scenarios; separates voice and data domains and applies appropriate VLANs after authentication.
Common in deployments that support phones and PCs together.
Configuration reminder

Ensure switchport mode access is used. For voice+PC use switchport voice vlan and authentication host-mode multi-domain to separate domains and authorization outcomes.
