Module 8 › Chapter 8.2 › Switch Configuration
Global steps
  • Enable AAA: allow RADIUS integration with local commands.
  • Register RADIUS server: provide IP, ports, and shared key.
  • Enable dot1x: dot1x system-auth-control to handle 802.1X sessions.
Port setup
Configure access mode, set data and voice VLANs, and enable authentication port-control auto. Choose host-mode per use case.
Plan: test one port before rolling out to ensure fallback and guest VLANs behave correctly.
Example CLI snippets
aaa new-model
radius server RADIUS_SERVER_1
 address ipv4 192.168.10.11 auth-port 1812 acct-port 1813
 key Cohortia123
!
aaa group server radius RADIUS_GROUP
 server name RADIUS_SERVER_1
!
aaa authentication dot1x default group RADIUS_GROUP
aaa authorization network default group RADIUS_GROUP

dot1x system-auth-control
Validation
Use show dot1x all and show authentication sessions interface GigabitEthernet1/0/1 details to confirm behavior.
