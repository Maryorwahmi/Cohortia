Module 7 › Chapter 7.2 › List Keys & Presence
List key rule

Every list entry identified by a key must include the key leaf in the payload so the device knows which instance you mean.

Presence containers

Presence indicates the container's existence carries meaning. Create the container in your payload to signal intent to enable the feature.

Defaults and omission

Defaults are applied by the device when you omit a leaf. Don’t rely on a default if you require a specific behavior — set it explicitly.

Concrete example
{
  "interface": [{
    "name": "GigabitEthernet0/1",
    "ipv4": {"address":"192.0.2.10","netmask":"255.255.255.0"}
  }]
}
