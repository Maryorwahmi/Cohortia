Module 7 › Chapter 7.2 › Config vs Operational State
Config true (writable)

These nodes represent configuration you can change with NETCONF or RESTCONF. Prepare payloads that target these nodes for automated changes.

Config false (read-only)

Operational state populated by the device. Use these nodes for monitoring or verification but do not attempt to write them.

Practical guidance
  • Inspect model attributes to distinguish writable nodes from state-only nodes.
  • Separate automation into write flows (config true) and read-only monitoring flows (config false).
  • Validate payloads against the model to avoid writing to state-only nodes.
