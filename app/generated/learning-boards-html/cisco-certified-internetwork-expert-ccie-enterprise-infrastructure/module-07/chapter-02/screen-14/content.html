Module 7 › Chapter 7.2 › Key Concepts
Data Model
A formal schema defining organization, types and constraints for configuration and state.
YANG
The language used to write models that describe configuration, state, RPCs and notifications.
Module
A top-level unit containing schema nodes and a namespace to avoid naming conflicts.
Summary

Keep these three concepts at hand when you inspect models: the model is the contract, YANG is the language, and module packages schema elements with a namespace and revision.
