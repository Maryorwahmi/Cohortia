Module 7 › Chapter 7.2 › Example: example-interface.yang
Module excerpt
module example-interface {
  namespace "urn:example:interface";
  prefix "ex-if";

  container interfaces {
    list interface {
      key "name";

      leaf name {
        type string;
      }

      leaf description {
        type string;
        mandatory false;
      }

      container ipv4 {
        presence "IPv4 is enabled on this interface.";

        leaf address {
          type string;
        }
        leaf netmask {
          type string;
        }
      }

      leaf enabled {
        type boolean;
        default true;
      }
    }
  }
}
Walkthrough notes
  • module header: check namespace and revision before use.
  • list interface: key "name" means each entry must include that leaf.
  • ipv4 presence: the container's presence carries meaning; its children are relevant only when present.
  • enabled default: if omitted, device treats it as true unless explicitly set otherwise.
Example

To create an interface with IPv4, include list key name and the ipv4/address and netmask leaves inside that list entry.
