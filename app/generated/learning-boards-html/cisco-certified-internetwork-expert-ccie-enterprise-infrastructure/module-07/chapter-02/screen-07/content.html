Module 7 › Chapter 7.2 › Core Building Blocks
Container

Groups related child nodes. No value itself; acts like a folder in the schema tree.

List

A sequence of entries keyed by one or more leaves. Map to arrays of objects in JSON with each object containing the key field.

Leaf / Leaf-list

Leaves hold single typed values. Leaf-lists hold repeated typed values such as multiple DNS servers.

Types and attributes

Types constrain allowed values. Attributes such as presence, mandatory, default and config guide validation and behavior.

Example mapping

A YANG list named vlan keyed by id becomes JSON: {"vlan": [{"id":10,...},{"id":20,...}]}. Always place the key leaf in each list object.
