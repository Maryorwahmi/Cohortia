Data Models and YANG
Structured schemas for configuration and state; a reliable bridge to automation.
Orientation

You will learn why data models replace brittle CLI parsing, how YANG describes hierarchies of containers, lists and leaves, and how to use tools to validate and explore models before building API payloads.

What you'll do

Read a YANG module, identify containers and list keys, run a pyang tree view, and craft a JSON payload for a VLAN list. These are practical skills you can apply to device APIs.

Explore Key Topics
Data Models
Formal schemas that define types, constraints, and relationships so automation can validate inputs.
YANG Language
Human-readable, tree-structured definitions for modules, containers, lists, and leaves.
Tools
Use validators like pyang to inspect tree views and catch model errors before runtime.
Visual Concept
Module
Top-level schema unit with namespace
Container
Groups related nodes, like a folder
Leaf
A single typed value, like name or address
Quick start
Start by reading a model and running a validator. The rest of this lesson breaks that workflow into small, practical steps so you can practice safely on real device models.
