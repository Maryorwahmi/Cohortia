Module 7 › Chapter 7.2 › Activity: Explore VLAN Model
Steps
  1. Download cisco-ios-xe-vlan.yang from the vendor model set.
  2. Install pyang: pip install pyang.
  3. Run: pyang -f tree cisco-ios-xe-vlan.yang and inspect vlan list and key.
Assessment example

To configure VLANs 10, 20 and 30 based on a list keyed by id, represent each VLAN as a separate list object containing its id and optional leaves, like this:

{
  "vlan": [
    {"id": 10, "name": "Users"},
    {"id": 20, "name": "Servers"},
    {"id": 30, "name": "Guests"}
  ]
}
