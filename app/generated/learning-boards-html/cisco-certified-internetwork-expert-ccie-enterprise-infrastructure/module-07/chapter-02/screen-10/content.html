Module 7 › Chapter 7.2 › Using pyang
Install and run
pip install pyang
pyang -f tree cisco-ios-xe-vlan.yang

The command renders a concise tree so you can find lists, keys and leaves quickly.

Inspecting output
module: Cisco-IOS-XE-vlan
  +--rw vlan-list
     +--rw vlan* [id]
        +--rw id         uint16
        +--rw name?      string
        +--rw state?     enumeration

Search this output for the list name and key to determine how to construct payloads.
