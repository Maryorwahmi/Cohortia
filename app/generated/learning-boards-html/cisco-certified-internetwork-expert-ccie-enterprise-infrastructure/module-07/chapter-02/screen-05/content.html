Module 7 › Chapter 7.2 › What is YANG?
Language purpose

Describe configuration, state, RPCs and notifications in a tree structure. YANG provides constraints, types and documentation strings to make models machine-actionable.

Key properties
  • Human-readable, IETF-standard language for network schemas.
  • Separates schema from encoding; models map to XML/JSON payloads.
  • Supports types, derived types, presence, defaults and constraints.
Misconception

YANG is not an API or encoding. It's the schema used to validate and generate API payloads.

Practical example

A YANG interface list keyed by name lets automation iterate over each interface instance to set description, IPs, or administrative state. The model documents valid types and defaults so your code can prepare correct values.

Check your understanding

When you open a model, ask: does this node have children (container/list) or a value (leaf)? Is the list keyed, and what is the key leaf used to identify instances?
