Module 07 › Chapter 7.6 › Gather Facts
Playbook example
---
- name: Gather facts from Cisco IOS devices
  hosts: ios_devices
  gather_facts: no
  connection: network_cli

  tasks:
    - name: Get device facts
      cisco.ios.ios_facts:
        gather_subset:
          - all
      register: device_facts

    - name: Print collected facts
      ansible.builtin.debug:
        var: device_facts
Run: ansible-playbook -i inventory.ini gather_facts.yml. The registered variable contains nested keys you can reference in later tasks.
Notes & tips
  • Use gather_subset to limit returned data and speed up collection.
  • Inspect device_facts to make runtime decisions in playbooks.
  • Avoid assuming facts always exist; verify keys before using them.
Misconception: network facts are identical to system facts. Use network modules rather than relying on default host facts for network devices.
Key Takeaway

Collect facts before changing state. Facts enable safe conditions and prevent applying incompatible configs to devices.
