Ansible for Network Automation

Use agentless playbooks, modules, and Jinja2 templates to manage Cisco IOS and IOS XE devices reliably. Focus on safe, idempotent changes and repeatable operations.

In this lesson
Set up a control node, author inventory and playbooks, run ios_facts and ios_config, and render Jinja2 templates for device-specific configuration.
Why it matters
Automation reduces manual error and lets you apply consistent configurations at scale while preserving the ability to test changes before applying them.
Audience
Network engineers familiar with IOS command line who want to build repeatable automation with Ansible and Jinja2 templates.
Safety
Use check mode and vault for secrets. Always test playbooks in a lab before production runs.
Explore Key Topics
Inventory & Connection
Map hostnames to IPs and set ansible_connection and ansible_become for privilege escalation.
cisco.ios Modules
Use ios_facts and ios_config to gather data and push changes idempotently.
Jinja2 Templates
Render device-specific configs from one template, substituting variables per host.
Visual Concept
Control Node
Runs playbooks, stores roles and templates
Managed Nodes
Cisco IOS / IOS XE devices via SSH or network_cli
Playbooks describe desired state. Modules like cisco.ios.ios_config implement changes. Templates provide dynamic config. Inventories list targets.
Quick start
Install Ansible in a Python virtualenv, install cisco.ios collection, create inventory.ini, then run an example playbook like gather_facts.yml.
