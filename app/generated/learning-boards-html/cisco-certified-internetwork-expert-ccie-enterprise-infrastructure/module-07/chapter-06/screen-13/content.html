Module 07 › Chapter 7.6 › Mistakes & Safety
Frequent errors
  • Inventory typos: verify ansible_host and ansible_network_os values.
  • Missing ansible_become or enable password for config modules.
  • Hardcoded credentials: use Ansible Vault instead.
  • Assuming check mode fully simulates every module's behavior.
Safety practices
  • Use --check and --diff for previews.
  • Keep playbooks and inventories in Git for auditing and rollback.
  • Use save_when carefully; consider separate save tasks under change control.
  • Test playbooks in an isolated lab before production runs.
Pro tip: Add a verification task after config changes to run a show command and assert expected lines are present. This creates an automated safety net.
Key Takeaway

Adopt clear inventory practices, enable privilege escalation, vault secrets, test with check/diff, and verify changes to minimize risk when automating network devices.
