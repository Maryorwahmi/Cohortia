Module 07 › Chapter 7.6 › Testing & Diff
Commands to preview changes
Run the playbook in dry-run and request diffs to see what lines would be added, removed, or changed.
ansible-playbook -i inventory.ini playbook.yml --check --diff
Use these flags as a mandatory pre-commit step for configuration changes. Flag limitations: some modules cannot fully emulate actions in check mode, so follow up with lab verification.
Common misconceptions
  • Don't assume --check perfectly predicts every module's result; it is a helpful preview but not a guarantee.
  • --diff shows differences in text form; understand context to avoid accidental removals of related lines.
Integration idea: add check mode and diff into CI so every merge request must pass a simulated run against a lab inventory before approval.
Key Takeaway

Preview changes with --check and --diff, but always validate in a lab. Use diffs to review the exact commands Ansible intends to send.
