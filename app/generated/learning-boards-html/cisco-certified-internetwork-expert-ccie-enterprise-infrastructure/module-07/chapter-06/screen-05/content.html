Module 07 › Chapter 7.6 › Control Node Setup
Process
Create a reproducible Ansible environment
Recommended commands (run on control node): 
python3 -m venv ansible_env
source ansible_env/bin/activate
pip install ansible
ansible-galaxy collection install cisco.ios
  • Verify installation with ansible --version.
  • Check collections with ansible-galaxy collection list.
  • Place playbooks, inventory, and templates in a project directory tracked by Git.
Why it matters
A controlled environment avoids version drift and makes automation reproducible for teammates. Collections provide device-aware logic so you use modules that understand network device behavior and responses.
Pro tip: Use a requirements.yml to pin collection versions for predictable installs in CI and across team members.
Key Takeaway

Isolate Ansible with a virtualenv, install cisco.ios, and track your project in version control for repeatable automation.
