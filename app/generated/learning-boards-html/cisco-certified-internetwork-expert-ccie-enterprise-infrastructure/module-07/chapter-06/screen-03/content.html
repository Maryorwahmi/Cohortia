How objectives map to practice

Each item below shows a task you can run to verify competency and a short mnemonic to remember it by.

Inventory Check
Create inventory.ini and run a ping-like playbook or ansible-inventory --list to confirm connectivity. Mnemonic: map → ping → connect.
VERIFIED COMPETENCY MILESTONE
Gather Facts
Run gather_facts.yml and inspect device_facts. Mnemonic: snapshot the device state before changes.
VERIFIED COMPETENCY MILESTONE
Template Apply
Use a Jinja2 template with ios_config src to render per host and save. Mnemonic: one template, many devices.
