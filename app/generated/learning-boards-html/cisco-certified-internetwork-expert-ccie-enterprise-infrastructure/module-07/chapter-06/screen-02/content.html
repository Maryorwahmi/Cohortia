Learning Objectives

These objectives are mapped to verified milestones so you can measure progress as you automate devices.

01
Explain Ansible architecture
Describe control node, managed nodes, inventory, modules, playbooks, and roles, and why each exists.
VERIFIED COMPETENCY MILESTONE
02
Set up control node & inventory
Create a virtualenv, install Ansible, and author inventory.ini with ansible_connection and privilege variables for IOS devices.
VERIFIED COMPETENCY MILESTONE
03
Write and run playbooks
Use cisco.ios modules to gather facts and push config. Understand idempotency and save_when parameters.
VERIFIED COMPETENCY MILESTONE
04
Use Jinja2 for templates
Render device-specific interfaces, banners, and loopbacks from a single template and variables defined per host.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master
