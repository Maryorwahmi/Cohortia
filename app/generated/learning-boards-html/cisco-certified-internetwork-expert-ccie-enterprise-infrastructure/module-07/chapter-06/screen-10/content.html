Module 07 › Chapter 7.6 › Apply Template
Playbook example
---
- name: Configure interfaces using Jinja2 template
  hosts: R1
  gather_facts: no
  connection: network_cli

  vars:
    interface_name: Loopback10
    ip_address: 10.10.10.1
    netmask: 255.255.255.255

  tasks:
    - name: Apply interface configuration from template
      cisco.ios.ios_config:
        src: interface_config.j2
        save_when: always
      register: interface_config_result

    - name: Print interface configuration result
      ansible.builtin.debug:
        var: interface_config_result
Run with ansible-playbook -i inventory.ini template_config.yml and inspect the debug output to confirm the lines applied.
Verification
After applying the template, run ios_command to execute "show ip interface brief | include Loopback" and verify the newly configured loopback appears. Combine this into the playbook for automated verification.
Tip: Use loop in playbooks to render the same template multiple times with different vars when configuring many interfaces.
Key Takeaway

Templates plus loops let you scale configuration while maintaining a single source of truth. Always verify rendered output before applying in production.
