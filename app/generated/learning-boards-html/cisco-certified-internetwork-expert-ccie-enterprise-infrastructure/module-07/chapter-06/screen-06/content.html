Module 07 › Chapter 7.6 › Inventory for IOS
INI Inventory Example
[ios_devices]
R1 ansible_host=192.168.1.101 ansible_user=admin ansible_password=cisco ansible_network_os=ios
SW1 ansible_host=192.168.1.102 ansible_user=admin ansible_password=cisco ansible_network_os=ios

[all:vars]
ansible_connection=network_cli
ansible_become=yes
ansible_become_method=enable
ansible_become_password=enable_password
Use group variables for settings that apply to many devices and host vars for exceptions. Replace passwords with vaulted variables in production.
Common pitfalls
  • Typos in variable names cause connection failures. Verify spelling exactly.
  • Hardcoding secrets is unsafe; use Ansible Vault instead.
  • Ensure SSH is enabled and correct credentials are used for enable mode when needed.
Check: run ansible-inventory --list -i inventory.ini to see how Ansible parses your file before running playbooks.
Why it matters

A correct inventory is the foundation of reliable automation; small mistakes here prevent playbooks from reaching devices or escalating to the right privilege level.
