Template example
interface {{ interface_name }}
 description Configured by Ansible for {{ inventory_hostname }}
 ip address {{ ip_address }} {{ netmask }}
 no shutdown
Store this file under templates/ and reference it from a playbook with src: interface_config.j2 so Ansible renders variables before pushing configuration.
Guidance
  • Keep templates simple and test rendered output with debug or template lookup.
  • Use descriptive variable names and group related variables in host_vars or group_vars.
  • Use loops for repeated structures and conditionals for optional commands.
Pro tip: Render templates locally with the lookup('template') helper during development to inspect output without connecting to devices.
Key Takeaway

Templates reduce duplication and centralize logic. Always preview rendered templates before applying them to production devices.
