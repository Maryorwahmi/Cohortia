Activity

Conceptual steps to collect and visualize telemetry

1. Device configuration
Enable telemetry, define sensor-group for interface statistics, set destination and subscription with sample-interval.
2. Collector setup
Configure Telegraf gNMI input to bind to the port and authenticate devices; configure InfluxDB output.
3. Time-series database
Run InfluxDB, create database, and set retention and downsampling policies for high-frequency data.
4. Visualization
Add InfluxDB as a Grafana datasource and create a panel that charts in-octets/out-octets for your interface.
Reflection
Which metric would you start with and at what sample interval to balance fidelity and resource usage for a production uplink?
Key Takeaway

Start small, validate device load and network use, then iterate subscriptions and retention to scale telemetry safely.
