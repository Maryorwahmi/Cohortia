Module 8 › Chapter 7.8 › GPB vs JSON vs XML
Data Formats

Protocol Buffers, JSON, XML

GPB
Binary, compact, requires .proto schema.
JSON
Human readable, larger payloads, broad tooling support.
XML
Readable but verbose; common with NETCONF.
Concrete example
Compare bytes on the wire for a one-second stream of interface stats encoded as GPB vs JSON to choose the right encoding for high-volume streams.
Misconception
Choosing JSON solely for readability without accounting for high ingest rates can lead to increased storage and parsing load.
Key Takeaway

Pick GPB for high-frequency, high-volume telemetry; use JSON or XML when human-readability or compatibility outweighs performance.
