Module 8 › Chapter 7.8 › SNMP vs Streaming
Comparison

Polling snapshots

Periodic SNMP polls return MIB values on demand. Simple, but limited in timeliness and granularity.
  • Scalability: Polling thousands of devices often increases traffic and CPU load.
  • Granularity: Polling interval determines visibility; sub-minute events can be missed.
  • Timeliness: Data can be stale by the time it is collected and processed.
Concrete example
A five-minute poll misses a 20-second microburst that a one-second telemetry stream would capture as multiple high-resolution samples.
Core Concept

Streaming telemetry

Devices push selected YANG-path-based data continuously to a collector. This is efficient and near real time when encoded with GPB or JSON.

Key Takeaway

Streaming telemetry provides timelier, higher-resolution data than SNMP polling, but it requires planning for data volume and retention.
