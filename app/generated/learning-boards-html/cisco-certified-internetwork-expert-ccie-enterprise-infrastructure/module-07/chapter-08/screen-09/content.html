Conceptual gNMI subscription

This conceptual snippet illustrates the connect, subscribe, and receive loop you'll implement with production client libraries.
# Conceptual gNMI subscribe (simplified and conceptual)
from gnmi import gnmi_pb2, gnmi_pb2_grpc
import grpc
import time

TARGET_IP = "192.168.1.101"
TARGET_PORT = 50051
USERNAME = "admin"
PASSWORD = "cisco"
INTERFACE_STATS_PATH = "/interfaces/interface[name='GigabitEthernet1']/state/statistics"

def subscribe_to_telemetry():
  channel = grpc.secure_channel(f"{TARGET_IP}:{TARGET_PORT}", grpc.ssl_channel_credentials())
  stub = gnmi_pb2_grpc.gNMIStub(channel)

  subscribe_request = gnmi_pb2.SubscribeRequest()
  subscribe_request.subscribe.mode = gnmi_pb2.SubscriptionList.STREAM
  subscribe_request.subscribe.encoding = gnmi_pb2.Encoding.JSON_IETF
  subscribe_request.subscribe.subscription.add(
    path=gnmi_pb2.Path(elem=[gnmi_pb2.PathElem(name=e) for e in INTERFACE_STATS_PATH.strip('/').split('/')]),
    mode=gnmi_pb2.SubscriptionMode.SAMPLE,
    sample_interval=1000000000
  )

  metadata = [('username', USERNAME), ('password', PASSWORD)]

  for response in stub.Subscribe(subscribe_request, metadata=metadata):
    if response.update:
      # Parse response.update.update[0].val.json_ietf_val or proto_bytes
      pass
    time.sleep(0.1)
Example detail
The sample interval in this snippet is 1 second (expressed in nanoseconds) to capture high-frequency interface metrics.
Caution
This code omits TLS cert handling, reconnection and robust parsing—add those in production clients.
Key Takeaway

The subscribe flow is connect, build subscription list, receive updates, parse encoding, and persist. Harden each step before production use.
