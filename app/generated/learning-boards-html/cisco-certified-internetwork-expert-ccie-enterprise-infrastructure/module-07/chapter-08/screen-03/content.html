Learning Objectives — Applied Skills

Four short, verifiable demonstrations map each objective to a practical activity you can perform.
01 — Experiment
Compare polling vs streaming
Run SNMP polls at longer intervals and a one-second telemetry stream, then capture where polling misses transient spikes.
02 — Report
Demonstrate benefits with a case
Use high-granularity metrics to correlate performance events and create a troubleshooting timeline.
03 — Protocol Mapping
Map YANG paths and encodings
Show how a gNMI subscription references a YANG path and how GPB vs JSON affects payload parsing or size.
04 — Architecture Sketch
Design a simple pipeline
Sketch device → collector → broker → TSDB → Grafana and justify choices for buffering and storage.
