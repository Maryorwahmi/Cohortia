Core Concept

Streaming Telemetry — definition & benefits

Devices continuously publish configured YANG-path data to a collector at chosen intervals and encodings.
Real-time visibility
Higher granularity
Scalable publishes
Operational example
Stream interface in-octets every second for a critical uplink to detect short-lived congestion events and correlate with CPU usage.
Common misconception
Streaming always increases network load. Reality: choose paths and efficient encodings like GPB to control bandwidth and parsing cost.
Key Takeaway

Use streaming telemetry when you need sub-minute fidelity and proactive analytics; design subscriptions to balance fidelity and resource usage.
