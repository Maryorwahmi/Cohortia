Module 7 › Chapter 7.1 › Branch Onboarding
Activity: Identify automation candidates
Tasks
  • VLAN 100 creation on Core-SW1 and Core-SW2
  • Assign Gi1/0/1-5 to VLAN 100 on Branch-ACC-SW1
  • Configure subinterface Gi0/0/1.100 with IP and DHCP on Branch-RTR1
  • Verify connectivity to 10.10.10.10
Automation suggestions
Use Ansible playbooks for VLAN and interface templates; Python or Netmiko for ad-hoc verification and parsing; parameterize VLAN ID, interface ranges, and IP addresses.
CLI examples
configure terminal
vlan 100
name Branch_Users
end
write memory

configure terminal
interface range GigabitEthernet1/0/1 - 5
switchport mode access
switchport access vlan 100
no shutdown
end
write memory

configure terminal
interface GigabitEthernet0/0/1.100
encapsulation dot1Q 100
ip address 192.168.100.1 255.255.255.0
no shutdown
ip dhcp pool BRANCH_USERS_POOL
network 192.168.100.0 255.255.255.0
default-router 192.168.100.1
end
write memory

ping 10.10.10.10
show ip interface brief
show vlan brief
Key Takeaway
Parameterize and template repetitive blocks, keep automation code in Git, secure credentials, and test changes in a lab before production.
