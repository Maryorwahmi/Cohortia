Orchestration: a workflow approach
1
Define steps
Example sequence for branch onboarding:
  1. Provision VLAN on core switches.
  2. Configure access ports on branch switches.
  3. Apply subinterface and DHCP on router.
  4. Run connectivity and policy checks.
Dependences
Ensure upstream devices are configured before downstream steps run.
Rollback
Design rollbacks so failed executions don’t leave partial, inconsistent state.
Visibility
Orchestration records each step and outcome to support retries and audits.
Analogy
Orchestration is like a conductor coordinating musicians so the whole piece runs in order and recovers from mistakes.
