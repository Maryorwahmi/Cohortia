Module 7 › Chapter 7.1 › CLI vs API
Manual CLI
Definition
Human-driven configuration using device consoles or SSH sessions and typed commands.
Pain points
  • Prone to typing errors and inconsistencies between devices.
  • Hard to track changes without disciplined records.
  • Slow at scale for frequent operations.
When to use
One-off troubleshooting and exploratory tasks where speed of thinking matters most.
Programmatic Management
Definition
Use of APIs, data models, and code to apply and verify network state across many devices.
Advantages
  • Consistent application of templates and parameters.
  • Structured responses allow reliable parsing and validation.
  • Enables testing, versioning, and rollback.
Misconception
APIs don’t replace expertise: they require correct logic and validation to avoid scaling mistakes.
