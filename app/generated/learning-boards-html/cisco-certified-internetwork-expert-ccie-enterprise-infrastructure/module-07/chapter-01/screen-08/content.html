Module 7 › Chapter 7.1 › APIs
NETCONF
Uses XML over secure sessions and works closely with YANG models to provide structured configuration and state operations.
RESTCONF
Provides a RESTful interface over HTTP to access configuration and operational data, often returning JSON or XML.
Practical tip
Authenticate API calls securely and test responses against expected data models in a lab before production.
Misconception
APIs eliminate need for network knowledge — they actually require accurate models and operator understanding to avoid automating errors.
Check
Verify the API endpoints on your devices in a lab by issuing read calls and confirming the returned JSON/XML matches expected YANG-derived structures.
