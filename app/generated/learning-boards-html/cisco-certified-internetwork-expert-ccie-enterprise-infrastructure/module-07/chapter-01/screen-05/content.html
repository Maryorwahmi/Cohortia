Software-Defined Networking
Core idea
Decouple control plane from data plane so centralized controllers can program forwarding behavior.
Concrete example
A controller pushes ACLs to multiple switches to enforce a security policy consistently across all sites.
Misconception
SDN doesn’t eliminate device configuration entirely; it abstracts and automates it from a central policy layer.
Why it matters
Faster, consistent policy changes; easier verification and rollback at scale.
Analogy
Think of SDN as a traffic manager that tells many traffic lights when to change, instead of adjusting each light individually.
Key Takeaway
Centralized decisions make coordinated changes safer and faster.
