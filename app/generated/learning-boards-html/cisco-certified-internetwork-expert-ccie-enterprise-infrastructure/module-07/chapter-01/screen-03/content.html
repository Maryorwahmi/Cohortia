Practice-focused Objectives
Identify candidates
Find tasks that repeat often and accept parameters like VLAN ID or IP address.
Choose tools
Match tasks to tools: scripting for small jobs, Ansible for configuration templates, orchestration for multi-step flows.
Version control
Treat automation like software: use Git to track, review, and roll back changes.
Test & rollback
Validate in lab environments and design rollback procedures before production runs.
Try this
List three repetitive tasks in your network and pick one to automate first; note parameters and safety checks required.
