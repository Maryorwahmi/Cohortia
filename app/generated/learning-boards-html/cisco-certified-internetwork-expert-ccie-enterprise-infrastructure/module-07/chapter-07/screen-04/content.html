Module 7 › Chapter 7.7 › Automation vs Orchestration
Definition & Core Claim

Automation: run a task or ordered sequence on a device. Orchestration: coordinate many automated tasks across devices and systems to deliver a service with resource and transaction management.

Automation example: Ansible playbook that configures an interface IP on a router.
Orchestration example: NSO translating a "VPN for Branch" model into configs on multiple devices with atomic commit.
Common misconception

Running many automation scripts does not equal orchestration because scripts lack a single transactional context and centralized resource management.

Key Takeaway

Use scripts for isolated tasks; use orchestration when you need atomic, multi-device service delivery and resource tracking.

Comparison Diagram
Automation
  • Executes device commands
  • Good for single-device fixes
  • Minimal transaction support
Example: interface IP change
Orchestration
  • Coordinates multiple tasks
  • Service modeling and resource allocation
  • Transaction management and rollback
Example: "VPN for Branch X" across routers and firewalls
Concrete example: fail-safe change
