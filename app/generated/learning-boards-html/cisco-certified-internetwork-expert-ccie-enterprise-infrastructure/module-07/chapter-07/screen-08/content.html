Module 7 › Chapter 7.7 › CD: Staging to Production
CD Stage Sequence
Staging/Pre-Production Deployment: mirror tests and integration checks.
Approval Gate: manual review for critical or high-impact changes.
Production Deployment: orchestrated, transactional apply using NSO or mature playbooks.
Post-Deployment Verification: automated health checks and telemetry validation.
Monitoring & Rollback: automated triggers or manual steps to revert if anomalies are detected.
Concrete example

After CI and lab tests validate an OSPF change, deploy to staging, run integration tests, then request approval. On approval, orchestrate a transactional deploy and run adjacency checks immediately after.

Misconception

Treating CD as instant production push without staging or approval increases outage risk, especially for multi-device changes.

Key Takeaway

Combine automation with appropriate approval and verification steps to safely deploy network changes at scale.
