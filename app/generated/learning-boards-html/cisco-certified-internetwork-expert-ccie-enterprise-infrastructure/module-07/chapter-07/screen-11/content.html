Module 7 › Chapter 7.7 › Rollback & Safety
Rollback mechanisms
Pre-change Snapshot: capture running-config of affected devices.
NSO Transactional Rollback: automatic reversion if commit fails.
Ansible backup: modules can save pre-change configs for restore.
Git Revert + CD: revert artifacts and re-run deployment to restore config.
Example rollback flow

Detect failure via post-deploy verification, trigger NSO rollback or apply stored snapshots with Ansible, then validate restoration using monitoring and pyATS checks.

Misconception

Relying solely on manual console fixes or informal backups increases recovery time and risk. Automate snapshot capture and test rollback procedures in lab environments.

Key Takeaway

Design and test rollback mechanisms as part of the pipeline; transactional orchestration and snapshots are complementary safeguards.
