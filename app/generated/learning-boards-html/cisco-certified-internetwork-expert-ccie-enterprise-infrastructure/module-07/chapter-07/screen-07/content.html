CI Stage Cards
Version Control: keep templates, playbooks and models in Git for traceability.
Linting & Syntax: ansible-lint, yamllint, pylint, pyang for fast feedback.
Render & Validate: produce final configs using sample data and run basic checks.
Idempotency: run playbooks in dry-run to verify repeatable behavior.
Lab Deployment & Tests: deploy to isolated lab and run connectivity and routing checks with pyATS.
Example pipeline step
# Example dry-run check
ansible-playbook site.yml --check --diff
# Linting examples: yamllint, ansible-lint, pylint
Common mistake

Skipping lab deployment and relying solely on linting leads to functional bugs: syntax may be correct but behavior can still break routing or adjacencies.

Key Takeaway

CI turns configuration changes into testable artifacts and prevents regressions before they reach staging or production.
