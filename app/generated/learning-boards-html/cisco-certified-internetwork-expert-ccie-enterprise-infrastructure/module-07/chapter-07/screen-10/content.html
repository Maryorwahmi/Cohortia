Activity checklist
  1. Trigger: push template or playbook to Git main branch.
  2. CI: yamllint, ansible-lint, pylint, pyang.
  3. Render: Jinja2 rendering with sample device vars and validation.
  4. Dry-run: ansible-playbook --check --diff for idempotency.
  5. Lab deploy: run pyATS tests for OSPF adjacency and routes.
  6. Approval: manual gate before production deploy.
  7. Deploy: NSO or Ansible with backups/transaction support.
  8. Verify & Monitor: post-deploy tests and telemetry checks; rollback if needed.

Common pitfall

Assuming dry-run guarantees production success. Dry-run checks syntax and planned changes, but lab functional tests are required to validate behavior in a network topology.

Key Takeaway

Follow the checklist and ensure snapshots and transactional rollback paths are in place before production deployment.
