Module 7 › Chapter 7.7 › Platform Capabilities
Platform features explained
Centralized Control: single pane for multi-vendor operations
Service Modeling: express services with YANG-like models, independent of device CLI
Resource Management: track and allocate IPs, VLANs and other resources
Transaction Management: atomic apply and rollback across devices
Closed-Loop Automation: monitoring feeds remediation actions when intent drifts
Example

Provisioning a branch VPN: model specifies endpoints and policies; platform reserves IPs, renders configs for routers and firewalls, commits transactionally and runs verification tests to ensure service is up.

Annotation Cards
Why transactions matter

They prevent partial service application across devices and reduce inconsistent states that cause outages.

Misconception check

Orchestration does not remove the need for thorough testing; it amplifies the impact if models are wrong, so tests are critical.

Key Takeaway

Orchestration provides the scaffolding to manage complex, multi-device services safely, but it relies on validated models and proper tests.
