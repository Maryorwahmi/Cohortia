Practical behaviours for safe automation

These checks reduce risk when your scripts change device state repeatedly or at scale.

Namespace & Keys

Confirm the XML xmlns or JSON YANG prefix matches the device model and include list keys like interface name in the payload to target the correct resource.

Error Handling

Use exception handling for NETCONF RPC errors and requests.raise_for_status for RESTCONF. Log and fail fast to prevent silent misconfigurations.

Idempotency

Retrieve current state, compare to desired state, then apply changes only if necessary. Prefer PATCH/PUT and default_operation='merge' where appropriate.

Transactions

For multi-step NETCONF changes, lock the datastore and use the candidate/commit pattern to ensure atomic application or roll back on failure.
