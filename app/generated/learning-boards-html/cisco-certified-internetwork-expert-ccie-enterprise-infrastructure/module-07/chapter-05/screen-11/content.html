Module 7 › Chapter 7.5 › Common Mistakes
Checklist of common issues
  • Wrong namespace in XML filter or payload — confirm URIs exactly as device advertises.
  • Missing list key in payload — include the 'name' when updating an interface list entry.
  • Disabled SSL or hostkey verification in production — always enable certificate validation.
  • No verification step after apply — always re-get and compare to confirm the change.
  • Poor error handling — log reply.xml or response.text and use raise_for_status for RESTCONF.
Debugging tips
Print or log the raw XML/JSON, examine namespace URIs, and compare against the YANG model. For RESTCONF, inspect the request URI and payload to ensure the keys are present.
Quick safety rule

Test destructive operations on a non-production device and use candidate/commit when making multi-step changes.
