restconf_vlan.py (key excerpt)
VLAN_CONFIG_PAYLOAD_PATCH = {
  "Cisco-IOS-XE-native:vlan-list": [
    {"id": 201, "name": "Automation_VLAN_RESTCONF"}
  ]
}

response = requests.patch(VLAN_LIST_URI, auth=(USER, PASS), headers=HEADERS, data=json.dumps(VLAN_CONFIG_PAYLOAD_PATCH), verify=False)
response.raise_for_status()

response = requests.get(VLAN_201_URI, auth=(USER, PASS), headers=HEADERS, verify=False)
response.raise_for_status()
print(response.json())
PATCH the vlan-list container to add or update VLAN 201, then GET the specific VLAN URI to verify the name field matches the desired value.
Notes

Include the id key in the payload array for list entries. Check HTTP responses and use raise_for_status to flag any validation errors returned by the device.

Key Takeaway

RESTCONF changes are HTTP-native; use PATCH with keys for idempotent list updates and verify with GET. Handle errors and certificate validation carefully.
