Module 7 › Chapter 7.5 › NETCONF with ncclient
Code example
<from ncclient import manager>
<HOST = os.getenv("NETCONF_HOST", "192.168.1.101")>
<with manager.connect(host=HOST, port=830, username=USER, password=PASS, hostkey_verify=False, device_params={'name':'iosxe'}) as m:>
  <netconf_reply = m.get_config(source='running', filter=GET_CONFIG_FILTER)>
  <print(netconf_reply.data_xml)>
This snippet opens a session, requests a filtered configuration, and prints the XML reply. Use logging in real scripts rather than print.
What to watch for
  • Confirm device_params matches vendor (e.g., 'iosxe').
  • Use explicit XML filters scoped to the YANG model to reduce reply size.
  • Do not assume CLI-like text; inspect the XML structure before parsing.
Example scenario

Retrieve GigabitEthernet1's configuration, parse its description, and log it for verification. This approach avoids fragile CLI parsing and uses the authoritative data model instead.

Key Takeaway

NETCONF returns structured XML; open a session, retrieve a filtered subtree, inspect data_xml, and then parse with namespace-aware tools.
