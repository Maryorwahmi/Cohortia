Parsing snippet
root = ET.fromstring(netconf_reply.data_xml)
namespaces = {'native': 'http://cisco.com/ns/yang/Cisco-IOS-XE-native'}
desc = root.find(".//native:GigabitEthernet/native:description", namespaces)
if desc is not None:
  print("Description:", desc.text)
else:
  print("No description found")
This code registers a prefix and uses it in a namespaced XPath to find the description element reliably.
Common misconceptions
  • Assuming element names without namespace will match.
  • Using naive string searches on XML instead of proper parsing.
  • Not handling absent elements gracefully, leading to attribute errors.
Example walkthrough

Print netconf_reply.data_xml, copy the namespace URI shown in the root element, create a mapping like {'native': ''}, and then query using the prefixed path. This process avoids silent misses when elements have namespaces.

Key Takeaway

Namespace-aware parsing is essential to extract values from NETCONF replies; confirm URIs and use a namespace dict for XPath calls.
