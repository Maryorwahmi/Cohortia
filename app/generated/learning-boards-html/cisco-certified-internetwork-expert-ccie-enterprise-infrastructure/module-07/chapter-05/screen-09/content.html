Module 7 › Chapter 7.5 › JSON handling
Inspect then extract
current = response.json()
iface = current.get('Cisco-IOS-XE-native:GigabitEthernet')
description = iface.get('description') if iface else None
if description:
  print('Description:', description)
else:
  print('No description')
This pattern prevents exceptions and works across devices that may omit optional fields.
Tips
  • Print the full JSON once to learn its nesting and prefixes.
  • Use .get with default values to avoid exceptions.
  • Validate expected keys before using them in comparisons.
Key Takeaway

Treat RESTCONF JSON as a nested structure mirroring YANG; inspect, then access safely with .get and include keys in payloads when updating lists.
