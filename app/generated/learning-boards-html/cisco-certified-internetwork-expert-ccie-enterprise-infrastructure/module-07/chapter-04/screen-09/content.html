Module 07 › Chapter 7.4 › Apply Configuration
Safe apply workflow
  1. Collect current state with show commands.
  2. Prepare a concise, idempotent list of config lines.
  3. Apply with send_config_set and capture the output.
  4. Verify with a targeted show run command for the changed object.
  5. Persist with write memory or a save function.
Common mistake
Forgetting to save to startup-config so changes are lost after a reboot.
Code example
config_commands = [
  "interface Loopback100",
  "description Test Loopback from Netmiko",
  "ip address 10.10.10.1 255.255.255.255",
  "no shutdown"
]
output = net_connect.send_config_set(config_commands)
print(output)
# Verify
verify_output = net_connect.send_command("show run interface Loopback100")
print(verify_output)
# Save
net_connect.send_command("write memory")
Idempotency
Design config commands so re-applying them has no further effect to avoid drift.
Audit
Log both the apply output and verification output so you can trace what changed.
Lab tip
Test changes on a single device or virtual lab before scaling to many devices.
