Module 07 › Chapter 7.4 › ConnectHandler
Pattern explanation

The ConnectHandler context manager opens and closes connections cleanly, avoiding resource leaks. The device dictionary centralizes parameters and can reference environment variables for credentials to improve security.

Common misconception
Closing a connection manually is error-prone; prefer the with-context so connections close even when exceptions occur.
Code (safe pattern)
from netmiko import ConnectHandler
import os

device = {
  "device_type": "cisco_ios",
  "host": os.getenv("NET_HOST", "192.168.1.1"),
  "username": os.getenv("NET_USERNAME", "admin"),
  "password": os.getenv("NET_PASSWORD", "cisco"),
  "port": 22,
  "secret": os.getenv("NET_SECRET", "enable_password"),
}

with ConnectHandler(**device) as net_connect:
  output = net_connect.send_command("show ip interface brief")
  print(output)
Example
Use environment variables to avoid committing credentials to source control.
Check
Validate host reachability before attempting many connections to speed troubleshooting.
Tip
Use net_connect.find_prompt() to confirm you're in the expected CLI mode before sending config commands.
