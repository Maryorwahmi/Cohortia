Module 07 › Chapter 7.4 › Install & Verify
Step-by-step
  1. Activate your virtual environment so pip targets it.
  2. Run pip install netmiko inside the activated venv.
  3. Verify with pip list or run a one-line import test in python.
  4. Capture versions with pip freeze > requirements.txt for reproducibility.
Pro tip
Test import in the same shell where you activated the venv to confirm the environment is active.
Common mistake
Using system python or pip by accident; the installed package won’t be available inside your venv shell.
Command examples
# Inside your activated virtual environment
pip install netmiko

# Quick import check
python -c "from netmiko import ConnectHandler; print('netmiko ok')"

# Freeze versions
pip freeze > requirements.txt
Key Takeaway

Install netmiko in the active venv and verify the package is importable before proceeding to device connections.
