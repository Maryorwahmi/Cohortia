Module 07 › Chapter 7.4 › Logging
Why logging matters

Logs provide timestamps, context, and severity levels so you can audit runs, debug failures, and operate automation at scale. They are essential for reliable maintenance and incident response.

Recommendation
Log device attempts, commands sent, verification results, and exception stack traces. Keep logs separate from user-facing console prints.
Logging template
import logging

logging.basicConfig(
  filename='netauto.log',
  level=logging.INFO,
  format='%(asctime)s - %(levelname)s - %(message)s'
)

logging.info(f"Attempting to connect to {device['host']}")
Rotation
Use rotating file handlers if your automation produces large logs over time.
Context
Include device hostnames or IPs and command identifiers in each log entry for later filtering.
Debugging
Reserve debug logs for development; avoid verbose logs in production runs unless troubleshooting.
