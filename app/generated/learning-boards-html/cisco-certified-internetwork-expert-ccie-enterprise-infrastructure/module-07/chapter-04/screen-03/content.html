Module 07 › Chapter 7.4 › Verification Tasks
Task Cards
01 Environment
Run the python -m venv command and activate the environment, then install netmiko and confirm the package list shows netmiko only for that venv.
02 Imports
Create a quick script that imports paramiko and netmiko and runs a minimal connect handler to catch import errors or missing dependencies.
03 Run & Gather
Use the ConnectHandler template to run show version and write the output to a file; verify file contents match expected device output format.
04 Apply & Save
Apply a small loopback config with send_config_set, verify with show run, and issue write memory to make the change persistent for reboot.
Quick mnemonic
Run, Verify, Persist, Log — a short lab checklist to keep automation safe and repeatable.
Micro-checklist
  • Use environment variables for credentials
  • Start with show commands only
  • Test one device at a time
  • Log success and failure to a file
