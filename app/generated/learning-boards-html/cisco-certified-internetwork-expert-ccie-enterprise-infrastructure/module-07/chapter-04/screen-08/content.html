Module 07 › Chapter 7.4 › Collecting Output
Why collect raw output

Storing raw command output creates an auditable record and lets you iterate on parsing without reconnecting to devices. It's a robust practice for inventory and troubleshooting workflows.

Best practice
Name files consistently and keep raw outputs immutable. Parse in a separate step using a parser library so errors in parsing don't require a fresh device connection.
Example loop
commands = ["show version", "show ip interface brief"]
for cmd in commands:
  output = net_connect.send_command(cmd)
  filename = f"{device_name}_{cmd.replace(' ', '_')}.txt"
  with open(filename, "w") as f:
    f.write(output)
Common issue
Parsing raw CLI directly in the connection loop couples collection and parsing and makes retries awkward.
Pro tip
Save raw files, then write a separate parser script using TextFSM or genie to convert text to structured data.
Verification
After collecting, open one file to confirm output completeness and absence of unexpected banners.
