Module 07 › Chapter 7.4 › paramiko vs netmiko
Paramiko (low-level)
  • Implements SSHv2 transport and channels.
  • Gives raw control over authentication and key exchange.
  • Requires manual handling of CLI prompts, pagination, and send/receive loops.
Use when
You need custom SSH behavior or to implement an SSH server or nonstandard transport.
Netmiko (higher-level)
  • Built on paramiko, but handles device CLI differences and pagination.
  • Provides ConnectHandler, send_command, and send_config_set helpers.
  • Simplifies multi-vendor CLI automation workflows.
Use when
You need to run show commands or push configurations across standard network devices efficiently.
Misconception
Netmiko is not a separate protocol; it reuses paramiko for SSH transport.
Practical tip
Start with netmiko for CLI scripts; keep paramiko knowledge if you need custom SSH control later.
Example
Use netmiko's send_config_set to push a list of interface commands without manual prompt handling.
