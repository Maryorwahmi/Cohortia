Module 07 › Chapter 7.4 › Security
Key security practices
  • Never hardcode credentials; use os.getenv or a secret manager.
  • Enable SSH host key verification to avoid MITM risks.
  • Grant minimal privileges needed for automation users and use enable secrets when required.
  • Test in lab and audit logs before production use.
Common mistake
Hardcoding credentials into scripts and committing them to source control exposes devices to compromise.
Environment variable example
import os
host = os.getenv("NET_HOST")
username = os.getenv("NET_USERNAME")
password = os.getenv("NET_PASSWORD")
For production, replace environment variables with a secure vault and control access explicitly.
Why it matters

Secure credential handling and SSH verification prevent unauthorized access and ensure your automation is trustworthy.
