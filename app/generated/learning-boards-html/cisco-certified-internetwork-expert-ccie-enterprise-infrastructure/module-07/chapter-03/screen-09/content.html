Module 7 › Chapter 7.3 › NETCONF vs RESTCONF
Feature Comparison
TransportNETCONF: SSH (port 830) · RESTCONF: HTTPS (port 443)
EncodingNETCONF: XML · RESTCONF: JSON (commonly)
OperationsNETCONF: RPCs (get-config, edit-config) · RESTCONF: HTTP verbs (GET, PATCH)
TransactionsNETCONF: strong transactional features · RESTCONF: less inherent transaction support
Use Cases
  • NETCONF: multi-step configuration changes, scripted commits, and devices requiring transaction safety.
  • RESTCONF: web applications, monitoring dashboards, and quick integrations with existing REST tooling.
Pro-tip: Evaluate your automation pipeline and choose the protocol that matches the expected failure modes and integration patterns.
