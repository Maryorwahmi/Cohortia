NETCONF edit-config (XML)
<rpc message-id="101" xmlns="urn:ietf:params:xml:ns:netconf:base:1.0">
  <edit-config>
    <target>
      <running/>
    </target>
    <config>
      <native xmlns="http://cisco.com/ns/yang/Cisco-IOS-XE-native">
        <interface>
          <GigabitEthernet>
            <name>1</name>
            <description>Configured by NETCONF</description>
          </GigabitEthernet>
        </interface>
      </native>
    </config>
  </edit-config>
</rpc>
Tip: copy the xmlns URI from server capabilities to avoid mismatch errors.
Why xmlns matters
  • It binds elements to a YANG module URI.
  • Devices validate payloads against that module.
  • Incorrect namespaces lead to semantic errors despite valid XML.
Common mistake: using a module prefix without the matching xmlns, or assuming a default namespace will be applied.
