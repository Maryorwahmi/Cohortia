Module 7 › Chapter 7.3 › Errors & Safety
Common Failure Modes
  • Wrong xmlns or module prefix — device returns invalid element.
  • Missing list keys — RESTCONF URIs must include keys for list entries.
  • Using PUT when PATCH was intended — accidental data loss.
  • Hardcoded credentials or disabled verification — security risk.
Mitigation Patterns
  • Check capabilities and use namespace URIs from the device.
  • Design scripts to be idempotent using merge or PATCH.
  • Always validate changes with a subsequent read operation.
  • Handle NETCONF XML errors and RESTCONF HTTP codes programmatically.
Pro-tip

In tests use explicit validation steps and create rollback paths such as discard-changes or copy-config backups to recover from failed updates.
