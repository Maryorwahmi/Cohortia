Module 7 › Chapter 7.3 › Learning Objectives
01
Explain NETCONF architecture
Describe sessions, capability exchange, RPCs, and why NETCONF uses XML over SSH. This builds a basis for transactional changes.
VERIFIED COMPETENCY MILESTONE
02
Describe NETCONF operations
Understand get-config, edit-config, get, lock/unlock, commit, discard-changes, and copy-config and when to use each.
VERIFIED COMPETENCY MILESTONE
03
Understand RESTCONF principles
Learn URI mapping to YANG nodes, HTTP verbs, and JSON payloads for resource-oriented configuration and state queries.
VERIFIED COMPETENCY MILESTONE
04
Perform basic interactions
Use curl for RESTCONF and understand the conceptual use of ncclient for NETCONF to get interface configuration and apply simple updates.
VERIFIED COMPETENCY MILESTONE
