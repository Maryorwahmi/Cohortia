Module 7 › Chapter 7.3 › RESTCONF URIs & Methods
URI Example
https://<device-ip>/restconf/data/Cisco-IOS-XE-native:native/interface/GigabitEthernet=1/description
This URI targets the description leaf for GigabitEthernet with key 1 in the native module.
HTTP Methods
  • GET — read configuration or state
  • POST — create new list entries
  • PUT — replace entire resource
  • PATCH — partial update (preferred for single-field changes)
  • DELETE — remove resource
Design guidance
Prefer PATCH for small updates. When using PUT, be aware it can wipe unspecified fields. Always include the list key in the URI to target the intended entry.
Misconception: RESTCONF is always safer than NETCONF. It is easier for web integrations, but does not inherently provide the same transactional guarantees as NETCONF.
