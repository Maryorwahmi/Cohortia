RESTCONF GET (example)
curl -k -X GET -u 'admin:password' -H 'Accept: application/yang-data+json' \
https://<device-ip>/restconf/data/Cisco-IOS-XE-native:native/interface
Inspect the JSON array for GigabitEthernet entries and note the key used to identify the interface. Use that key in the PATCH URI or JSON body when updating.
NETCONF get-config (concept)
Use ncclient.get_config with a filter that selects the native interface container. Parse the XML response while paying attention to namespaces.
