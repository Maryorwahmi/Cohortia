Module 7 › Chapter 7.3 › NETCONF Operations
Primary RPCs
<get-config>
Retrieve a configuration datastore, e.g., running or startup.
<get>
Retrieve both configuration and operational state data.
<edit-config>
Modify a datastore using merge, replace, create, delete, or remove.
<copy-config>
Copy content between datastores, useful for backups or promotion.
Locking & Transactions
lock/unlock prevent concurrent modifications. commit and discard-changes apply or remove pending edits when candidate datastore support exists.
Example sequence: lock running, edit-config, commit, unlock. If commit detects an error, discard-changes cleans the candidate state.
Key Takeaway

Treat NETCONF operations as transactional steps and build automation around lock/edit/commit patterns to preserve configuration integrity.
