Streamlined Configuration & Rollback Lab
Follow these exact steps in the lab environment to practice safe changes and recovery.
Step 1 — Configure Access Ports
interface range GigabitEthernet0/1 - 24
 switchport mode access
 switchport access vlan 100
 spanning-tree portfast
 spanning-tree bpduguard enable
 description ACCESS_PORT_VLAN_100
Verify with do show run interface range Gi0/1 - 24 or do show ip interface brief.
Step 2 — Object Group & ACL
object-group network INTERNAL_SERVERS
 host 192.168.10.10
 host 192.168.10.11
!
ip access-list extended SERVER_ACCESS
 permit tcp any object-group INTERNAL_SERVERS eq 80
Verify object-group and ACL with do show commands.
Step 3 — Save & Test Rollback
copy running-config flash:initial_config.txt
!
interface GigabitEthernet0/1
 no switchport access vlan 100
!
configure replace flash:initial_config.txt
Confirm the prompt and re-verify the interface VLAN assignment after replace.
Key Takeaway
Practice the full cycle so recovery steps are muscle memory during high-pressure lab time.
