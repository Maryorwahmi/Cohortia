Safety › Chapter 11.6 › Debug & Heavy Commands
Use debug sparingly
Excessive debug output can overload CPU and cause device instability; always scope and monitor.
Guidelines
  • Use filters or access-lists with debug to reduce output.
  • Monitor CPU and memory while debugging.
  • Be prepared to disable debug immediately if device health degrades.
Practical check
If you must debug in an exam, do so in short bursts, capture output, and then disable it to preserve device stability.
