Module 11 › Chapter 11.6 › Interface Range
Step-by-step
  1. Identify exact interface numbering and confirm contiguity.
  2. Prepare or select a tested template for the intended settings.
  3. Enter interface range and paste the template lines.
  4. Verify immediately with a do show command.
  5. Save or archive the configuration once verified.
Common-mistake
Specifying an incorrect range or forgetting to verify can apply an undesired configuration to many ports at once.
Example and verification
interface range GigabitEthernet0/1 - 24
 switchport mode access
 switchport access vlan 100
 spanning-tree portfast
 spanning-tree bpduguard enable
 description ACCESS_PORT_VLAN_100
!
! Verification (run while still in config mode):
Router(config-if-range)# do show ip interface brief
Verification
Use do show ip interface brief to confirm interface assignment and status before saving.
Pro tip
Combine interface range with descriptive text to ease future audits.
