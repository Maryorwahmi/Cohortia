Module 11 › Chapter 11.6 › configure replace
How it works
configure replace loads a saved configuration file, shows the differences relative to running-config, and asks for confirmation before applying an atomic replacement. If the replacement causes failure, the device can roll back.
Procedure: save a known-good running-config to flash, review the file in an editor if needed, then run configure replace flash:filename and inspect the preview before confirming.
Example command
copy running-config flash:my_safe_config.txt
!
configure replace flash:my_safe_config.txt
Before running, review the saved file and ensure it contains only desired settings. During replace the system will present a diff and prompt for confirmation.
