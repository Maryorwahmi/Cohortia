Module 11 › Chapter 11.6 › Safe Workflow
Workflow Steps
  1. Develop and test templates in a sandbox.
  2. Apply to a small subset using interface range or selective pastes.
  3. Verify immediately with do show commands.
  4. Snapshot running-config to flash and ensure archives are current.
  5. Use configure replace for wide changes with preview and rollback ready.
Scenario example
You're applying BGP policy changes across routers. Save a manual copy to flash:previous_bgp.txt, apply on one router, verify routes, then run configure replace on others. If a router loses routes you can revert quickly.
Key Takeaway
Combine templates and verification with archives and atomic replace to minimize blast radius and speed recovery.
