Module 11 › Chapter 11.6 › Object Groups
Definition & Rationale
Group related IPs or ports under a single name and reference that name in policies to centralize changes.
Benefits
  • Single update point for many ACLs or NAT entries.
  • Cleaner and more readable ACL definitions.
  • Faster policy changes in lab and production.
Example object-group
object-group network INTERNAL_SERVERS
 host 192.168.10.10
 host 192.168.10.11
!
ip access-list extended SERVER_ACCESS
 permit tcp any object-group INTERNAL_SERVERS eq 80
Verification
Use do show run | section object-group to confirm the group and its members.
Analogy
Think of an object group as a contact group in an address book that you can reference from many messages.
