Module 11 › Chapter 11.6 › do show
Purpose and behavior
The do prefix runs exec-mode show commands while you remain in configuration mode, enabling immediate verification after changes.
Use do show to confirm interface status, ACL entries, or running configuration sections without leaving the mode where you're making changes. This reduces mode-switch mistakes and streamlines edits.
Misconception
Using do show is different output than show. Reality: it returns equivalent information and is safe to use for verification.
Usage example
Router(config-if)# ip address 10.0.0.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# do show ip interface brief
Pro tip
Run do show run | section interface to inspect only relevant configuration blocks after applying templates.
Check
Verify status and description fields to ensure the template applied correctly.
