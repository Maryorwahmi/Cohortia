Learning Objectives
Learn the commands and workflows that make configuration repeatable, verifiable, and recoverable.
01
Templates & Ranges
Create repeatable blocks and apply to many interfaces to reduce errors and speed configuration. Verified competency: configure 24 access ports for VLAN 100 in under two minutes.
VERIFIED COMPETENCY MILESTONE
02
Object Groups
Group IPs and ports into named objects to simplify ACLs and NAT entries. Verified competency: create an object-group and reference it in an ACL.
VERIFIED COMPETENCY MILESTONE
03
Immediate Verification
Use the do prefix to run show commands without leaving config mode to confirm connectivity and status. Verified competency: run show ip interface brief from config-if.
VERIFIED COMPETENCY MILESTONE
04
Archive & Replace
Automate config snapshots and use configure replace for atomic rollbacks. Verified competency: restore a saved config after an intentional mistake.
VERIFIED COMPETENCY MILESTONE
