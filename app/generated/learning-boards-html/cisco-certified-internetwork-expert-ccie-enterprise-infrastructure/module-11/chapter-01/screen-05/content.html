Process

Read → Plan → Implement → Verify

1. Read the task

Identify exact requirements and success criteria before touching devices.

2. Plan minimal changes

Design a smallest-impact approach that meets the requirement.

3. Implement and verify

Apply configuration then use show commands to confirm state.

Concrete Example
Connect OSPF neighbor and verify

After configuring interfaces and OSPF, use show ip ospf neighbor and show ip route to confirm adjacency and learned routes. Then run an end-to-end ping to validate reachability.

Key Takeaway

Verify immediately after each change. This habit prevents cascading errors and saves time during operate checks.

Common Mistake

Batching many unrelated changes before verification causes difficult-to-isolate failures in later modules.
