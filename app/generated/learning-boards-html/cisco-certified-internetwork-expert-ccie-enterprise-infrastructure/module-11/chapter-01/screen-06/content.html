Starter Templates
! Router 1 Configuration Template
hostname R1
!
interface Loopback0
 ip address 1.1.1.1 255.255.255.255
!
interface Serial0/0/0
 ip address 10.0.0.1 255.255.255.252
 clock rate 2000000
 encapsulation ppp
!
router ospf 1
 network 1.1.1.1 0.0.0.0 area 0
 network 10.0.0.0 0.0.0.3 area 0
!
end

! Router 2 Configuration Template
hostname R2
!
interface Loopback0
 ip address 2.2.2.2 255.255.255.255
!
interface Serial0/0/0
 ip address 10.0.0.2 255.255.255.252
 encapsulation ppp
!
router ospf 1
 network 2.2.2.2 0.0.0.0 area 0
 network 10.0.0.0 0.0.0.3 area 0
!
end
Verification Commands
show ip interface brief — quick interface status and IPs
show ip ospf neighbor — confirm OSPF adjacency is FULL
show ip route — confirm learned and static routes
Example Task

After applying templates, verify neighbors are FULL and ping 2.2.2.2 from R1. Record outputs to verify normal patterns for success.

Pro Tip

Use show running-config to confirm that intended commands were saved and applied. This prevents surprises during Operate & Optimize.

Key Takeaway

Hands-on repetition of the CLI templates and verification commands builds speed and confidence for the Deploy module.
