Module 11 › Chapter 11.1 › Familiarization Exercise
Exercise checklist
  1. Configure Router 1 and Router 2 using the templates.
  2. Run show ip interface brief on both routers to confirm IPs.
  3. Run show ip ospf neighbor to verify adjacency is FULL.
  4. Run show ip route and ping the remote loopback addresses.
  5. If a step fails, compare interface IPs and network statements to find mismatches.
# Quick verification commands show ip interface brief show ip ospf neighbor show ip route ping show running-config | section ospf
Example result

A successful run shows FULL adjacency in show ip ospf neighbor and learned routes in show ip route. End-to-end pings should succeed to verify reachability.

Common Mistake

Mismatched network statements or interface IPs prevent adjacency. Verify both sides' interfaces and OSPF network statements first.

Key Takeaway

Build a short, repeatable verification checklist you run after each configuration change during the exam.
