Module 11 › Chapter 11.8 › Timeboxing
Setup checklist
  • Quiet room, single-screen layout or dual as exam allows.
  • Allowed documentation only; block general internet if practicing honesty.
  • Visible, single countdown timer with section markers.
Example timebox
Design 2h | Deploy 3h | Operate & Optimize 3h. Within Deploy, set 15–30 minute limits for high-risk configurations with a 10-minute forced verification point.
Verification passes
Every 60–90 minutes, run quick checks: routing adjacency, core reachability, and policy application. These passes catch regressions early.
Common mistakes
  • Thinking more time will always fix a stuck task; it often wastes hours.
  • Skipping verification after a fix due to fear of losing time.
  • Failing to record how long each task took, losing the data you need to improve.
Concrete prompt
During your next mock, pick one recurring problem and set a 20-minute box. If you don't progress, move on and note why in your post-mortem.
