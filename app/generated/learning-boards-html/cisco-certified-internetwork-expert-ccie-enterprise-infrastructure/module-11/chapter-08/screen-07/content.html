Module 11 › Chapter 11.8 › Self-Assessment
Task-by-task scoring
Create rows for each task: description, points available, points earned, root cause, time spent, action item.
Error categories
Knowledge Gap — needs theory review
Configuration Error — typo or wrong syntax
Troubleshooting — missed verification commands
Time Management — exceeded timebox
Action mapping
For each error category attach a single remediation: a 2-hour focused lab, a read-and-summarize task, or a troubleshooting drill.
Quick metric
Track 'tasks failed per mock' and 'timebox breaches per mock' to measure behavioral change.
