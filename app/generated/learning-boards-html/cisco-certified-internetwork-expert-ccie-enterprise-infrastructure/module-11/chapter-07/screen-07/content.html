Module 11 › Chapter 11.7 › Advanced Platform Features
Features
  • Snapshotting: Save and restore known good states before risky changes.
  • External connectivity: Use NAT or isolated bridges when your lab needs internet services.
  • Custom images: Import qcow2 or other VM images to include Linux hosts, firewalls, or vendor VMs.
  • Automation APIs: Script lab deployment and configuration to repeat scenarios reliably.
Concrete example
Import a Linux qcow2 image into EVE‑NG, connect it to a switch SVI, configure a small DHCP and DNS service, then snapshot. Break the DNS config and restore to the snapshot to validate your revert process.
Pro tip: limit external connectivity to a single NAT interface and use firewall rules so your lab cannot expose internal services to the wider network.
Key Takeaway

Advanced features increase realism and repeatability but require careful isolation and good snapshot habits.
