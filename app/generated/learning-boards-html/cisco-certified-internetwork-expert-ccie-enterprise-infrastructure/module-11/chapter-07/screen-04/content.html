Module 11 › Chapter 11.7 › Overview of Emulation Platforms
Definition

What an emulator provides

A platform that runs real vendor images so behavior matches physical devices. Fidelity, image support, and integration options differ between platforms.

Cisco Modeling Labs (CML)
Official images, high fidelity, well suited to SD‑WAN and Catalyst 9000V labs. Resource intensive but highly accurate.
EVE‑NG
Multi‑vendor support and easy qcow2 import. Good for heterogeneous enterprise scenarios and automation integration.
GNS3
Open source, integrates with external hypervisors and physical gear. Useful for mixed virtual/physical testbeds.
Concrete example
Build the same SD‑WAN mini topology in CML and EVE‑NG, run the same configuration on each, and compare how the control plane and device images behave when you change policy. Note any differences in CLI commands or feature availability. That informs which platform you trust for SD‑WAN exam practice.
Common mistake
Assuming GNS3 is always cheaper or always easier. Setup complexity varies with image types and whether you need external hypervisors or vendor licensing.
Key Takeaway
Key Takeaway

Match platform choice to the technologies you must test: fidelity for Cisco‑specific stacks, flexibility for multi‑vendor labs.
