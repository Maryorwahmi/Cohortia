Module 11 › Chapter 11.7 › Scaling Labs and Troubleshooting
Scaling checklist
  • Use hierarchical naming for nodes and interfaces.
  • Maintain a consistent address plan across modules.
  • Document redistribution points and inter‑module dependencies.
Troubleshooting workflow
  1. Isolate the problem by powering off unrelated nodes.
  2. Run baseline checks: pings, route tables, adjacency status.
  3. Use packet capture on the suspected link and revert to a snapshot if needed.
Key Takeaway

Order and documentation matter more than raw device count when scaling labs and debugging issues.
