Process

Modular topology workflow

  1. Identify blueprint section: OSPF area types, BGP scenarios, SD‑WAN control plane items.
  2. Design a module: core routing block, edge block, SD‑WAN controllers. Document IPs and test cases.
  3. Test independently: Verify module behavior with simple test scripts or pings.
  4. Assemble and verify: Combine modules and test cross‑module behaviors like redistribution.
Concrete scenario
Start with a three‑router OSPF core to verify adjacency and area placement. Next, add a BGP edge module and test route export into OSPF using controlled redistribution points. Document each step so you can recreate the topology quickly in another emulator.
Pro tip
Name modules clearly and keep interface addressing consistent to simplify merging modules later.
Key Takeaway

Modular blocks let you grow complexity predictably and debug modules independently before combining them.
