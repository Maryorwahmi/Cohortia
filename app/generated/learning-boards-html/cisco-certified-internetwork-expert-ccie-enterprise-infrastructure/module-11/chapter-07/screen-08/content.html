Module 11 › Chapter 11.7 › Build a Multi‑Vendor Lab (Walkthrough)
Step‑by‑step
  1. Create a new lab project in your platform of choice.
  2. Add two Cisco IOS XE routers, one Catalyst/vIOS‑L2 switch, and one Linux host VM.
  3. Connect R1–R2 (Gigabit), R1–SW1 trunk, and SW1–Linux host access port.
  4. Start devices and assign IPs; configure OSPF Area 0 on R1, R2, and the SVI if available.
  5. Configure Linux IP and default gateway; verify pings to R2 loopback and snapshot the lab.
Why snapshot now: after verified connectivity you can test destructive changes and revert without rebuilding.
Example configs
# R1/R2 basic interface config
interface GigabitEthernet0/0
 ip address 10.0.0.1 255.255.255.0
 no shutdown

# SW1 SVI and port config
interface Vlan10
 ip address 10.0.0.254 255.255.255.0
 no shutdown
!
interface GigabitEthernet0/1
 switchport mode trunk
!
interface GigabitEthernet0/2
 switchport mode access
 switchport access vlan 20

# Linux host example (Ubuntu)
sudo ip address add 10.0.0.10/24 dev eth0
sudo ip route add default via 10.0.0.254
Adapt these snippets to the specific images and CLI variations your emulator provides.
