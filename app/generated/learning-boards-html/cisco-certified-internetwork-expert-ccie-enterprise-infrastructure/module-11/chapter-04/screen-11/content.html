Routine

Verify with the same checks

After a fix, re-run the show commands that helped diagnose the problem to confirm the device now reports expected state. This provides objective proof of repair.

Verification examples
  • OSPF fix → show ip ospf neighbor shows FULL
  • Route appears → show ip route shows the network
  • VLAN fix → show vlan brief and show interfaces trunk confirm membership
Documentation template
Use a short template you can jot down: Hypothesis; Commands run; Config changes applied; Verification commands and results. Even minimal notes help rollback and explanation under time pressure.
Key Takeaway
Verification plus documentation preserves evidence of repair and protects you from accidental regressions in later steps.
