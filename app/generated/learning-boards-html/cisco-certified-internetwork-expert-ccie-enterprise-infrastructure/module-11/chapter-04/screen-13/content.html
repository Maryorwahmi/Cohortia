Question 1

Diagnosing EIGRP adjacency failure

Best sequence: show ip eigrp interfaces, show ip eigrp neighbors, show ip interface brief. This confirms the protocol runs on the correct interfaces, neighbor formation, and interface state.
Answer
Select show ip eigrp interfaces; show ip eigrp neighbors; show ip interface brief — these target the problem directly.
Question 2

Safest way to see BGP updates

Use a neighbor-filtered debug with direction to limit output, for example debug ip bgp updates <neighbor_ip> in. Avoid debug all.
Rationale
Filters and direction reduce volume and CPU impact while giving focused insight into update processing.
