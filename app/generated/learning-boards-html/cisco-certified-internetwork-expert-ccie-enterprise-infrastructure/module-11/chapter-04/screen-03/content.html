Module 11 › Chapter 11.4 › Learning Objectives — expanded
01

Choose the right methodology

Practice bottom-up for link and VLAN faults; practice top-down when an application is failing but ping is OK; use divide-and-conquer to split complex topologies into testable segments.

Venn: symptom vs suspected layer
VERIFIED COMPETENCY MILESTONE
02

Assemble a show command toolkit

Memorize and chain commands for interfaces, VLANs, routing, protocol neighbors and security checks to quickly isolate state without wide changes.

Timeline: check physical → data link → network
VERIFIED COMPETENCY MILESTONE
03

Practice safe debugging

Use filtered debug commands and narrow qualifiers such as a neighbor IP. Always disable debug immediately after capturing necessary information.

Mnemonic: narrow first
VERIFIED COMPETENCY MILESTONE
04

Verify and document every fix

Confirm the fix using the same show outputs used to diagnose, and record the hypothesis, commands and configuration changes for rollback or explanation.

Visual: note → test → confirm
