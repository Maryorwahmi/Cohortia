Module 11 › Chapter 11.4 › Fault Isolation Lab Walkthrough
Topology
R1 (Loopback0 1.1.1.1) — Gi0/1 — SW1 (Vlan10 SVI 10.0.0.254) — Gi0/1 — R2 (Loopback0 2.2.2.2) with OSPF Area 0 configured on R1, R2 and SW1.
Diagnosis steps
  1. Run show ip interface brief on R1, R2, SW1 to confirm admin/up and IPs.
  2. Run show interfaces Gi0/1 status and show vlan brief on SW1 to confirm VLAN assignments.
  3. Check OSPF with show ip ospf neighbor on all three devices.
  4. If adjacencies missing, check network statements and interface OSPF settings on routers and SVIs.
  5. If needed, run a filtered debug such as debug ip ospf hello <neighbor_ip> and then undebug all after capture.
Command examples
! On R1/R2
show ip interface brief
show ip route
show ip ospf neighbor

! On SW1
show vlan brief
show interfaces trunk
show ip interface brief

! If debugging
debug ip ospf hello 10.0.0.1
undebug all
Key Takeaway
Follow a short, repeatable sequence of checks and keep notes so you can verify that the ping from R1 to 2.2.2.2 now succeeds and document the steps you took.
