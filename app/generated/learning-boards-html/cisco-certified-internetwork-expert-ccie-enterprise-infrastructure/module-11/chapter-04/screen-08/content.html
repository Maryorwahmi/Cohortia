Module 11 › Chapter 11.4 › Essential show Commands
Overview

Show commands to memorize

Memorize and chain these commands so you can move from physical to protocol checks without guessing which to run next.

Categories
  • General connectivity: ping, traceroute, show cdp neighbors detail, show lldp neighbors detail
  • Interface status: show ip interface brief, show interfaces <type/num> status, show interfaces <type/num> counters
  • Routing: show ip route, show ip protocols, show ip ospf neighbor
  • Switching: show vlan brief, show interfaces trunk, show spanning-tree active
  • Security: show ip access-lists, show run | section access-list
Command walkthrough
! Interface and link checks
show ip interface brief
show interfaces GigabitEthernet0/1 status
show interfaces GigabitEthernet0/1 counters

! Routing and protocol state
show ip route
show ip protocols
show ip ospf neighbor
show ip eigrp neighbors

! Switching and VLANs
show vlan brief
show interfaces trunk
show spanning-tree active

! Security and NAT
show ip access-lists
show run | section access-list
show ip nat translations
Key Takeaway

Chain show commands from low-level interface checks to high-level protocol state to form a clear operational picture before making config changes.
