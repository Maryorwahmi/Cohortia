Module 11 › Chapter 11.3 › Timeboxing
Process Steps
  1. Quickly scan all tasks in the section and mark estimated complexity.
  2. Allocate baseline minutes per task based on remaining section time.
  3. Set the timer, start work, and note the expiry time for each timebox.
  4. If no progress at expiry, save config, log attempts, and move on.
  5. Reserve a final pass window for revisits of incomplete tasks.
Concrete example
Four-hour Deploy → 20 tasks → ~12 minutes average. Quick-wins get 6–8 minutes; medium tasks 12–20 minutes; reserve 30–45 minutes at end for complex revisits.
Key Takeaway

A timebox is a decision tool: it forces efficient trade-offs and protects section-wide points.
