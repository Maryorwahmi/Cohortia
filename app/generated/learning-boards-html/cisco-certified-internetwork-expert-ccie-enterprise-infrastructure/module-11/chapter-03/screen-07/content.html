Common show commands
show ip interface brief
show ip route
show ip protocols
show ip nat translations
show ip nat statistics
show crypto isakmp sa
show crypto ipsec sa
Use these after relevant changes. Keep output short and focused: search for expected networks, active translations, and established tunnels.
Debug caution
If you must use debug, apply specific filters and immediately disable debug with undebug all when complete to avoid CPU and output overload.
Concrete example
After configuring NAT, run show ip nat translations and show ip nat statistics to ensure translations exist and counters increment. If absent, verify ACLs and mapped interfaces before deep debugging.
Key Takeaway
A quick verification step saves far more time than extended debugging later.
