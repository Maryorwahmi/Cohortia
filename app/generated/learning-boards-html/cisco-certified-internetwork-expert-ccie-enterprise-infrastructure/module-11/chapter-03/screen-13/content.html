Configuration snippets
! R1 Interface configuration example
interface GigabitEthernet0/0
 ip address 10.0.0.1 255.255.255.0
 no shutdown

! OSPF configuration example
router ospf 1
 network 10.0.0.0 0.0.0.255 area 0

! Static route example
ip route 192.168.1.0 255.255.255.0 10.0.0.2

! ACL example
ip access-list standard TELNET_DENY
 deny   10.0.0.0 0.0.0.255
 permit any
Verification map
Interface: show ip interface brief → ping neighbor
OSPF: show ip ospf neighbor → show ip route
Static route: show ip route → traceroute to endpoint
ACL: show access-lists → test permitted/denied traffic
Key Takeaway
Keep a small verification map by task so you never skip the decisive checks that confirm success.
