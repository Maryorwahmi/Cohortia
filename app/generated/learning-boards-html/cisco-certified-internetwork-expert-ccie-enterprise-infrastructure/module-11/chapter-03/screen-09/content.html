Module 11 › Chapter 11.3 › Debugging
Compare approaches
Targeted Debug
Filtered, short capture, hypothesis-driven, undebug all immediately after capture.
Indiscriminate Debug
Global debug for long periods; floods console, obscures signals, wastes time.
Practical filter tip
If debugging OSPF, target messages for the specific neighbor IP and limit duration to capture initial exchanges only.
Example
You see missing routes in show ip route. Use show ip ospf neighbor and show ip ospf interface first. If those suggest neighbor packets are missing, run a tightly scoped debug for the neighbor and capture a few messages, then undebug all.
Key Takeaway
Use debug with a question in mind, filters in place, and a strict stop time.
