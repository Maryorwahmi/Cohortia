Dependency architecture
Map tasks as parent and child. Parents are foundational items like addressing, link states, and routing adjacency. Children include redistribution, VPNs, and higher-level policies.
Parent
Interface up, IP addressing
Middle
Routing adjacency, learned routes
Child
NAT, QoS, VPNs, redistribution
Practical check
If a child task fails, always return to parent checks before deep debugging: interfaces, adjacency, and routing table contents.
Example
Do not configure route redistribution before verifying that the routing domain forms adjacencies and the expected networks are visible in show ip route.
Key Takeaway
Verifying parents first prevents cascading issues that cost many minutes to untangle.
