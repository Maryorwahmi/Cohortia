Module 11 › Chapter 11.5 › Documentation Types
Definition & roles
Configuration Guide

Step sequences, recommended settings, and verification commands for implementing features on a platform.

Command Reference

Authoritative syntax, parameters, and usage notes for every command available in an OS version.

Troubleshooting Guide

Structured diagnostics and symptom-to-fix mappings for operational issues.

Design Guide

Architectural recommendations and trade-offs for building resilient, scalable solutions.

Practical example

If you need the exact argument order for a BGP attribute, open the command reference. If you need how to sequence BGP neighbors and route policies for a platform, consult the product configuration guide. When the device shows an unexpected neighbor state, consult the troubleshooting guide for the symptom flow.

Misconception

Assuming generic examples apply across platforms. Always verify platform and OS version on the document header before applying configuration lines.

Key Takeaway

Pick the document by question: syntax → command reference, steps → configuration guide, failures → troubleshooting, architecture → design guide.
