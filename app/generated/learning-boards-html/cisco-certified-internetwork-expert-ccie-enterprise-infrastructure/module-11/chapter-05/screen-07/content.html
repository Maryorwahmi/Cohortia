Entry anatomy
  • Syntax: the exact command structure with optional tokens.
  • Parameters: explanations and accepted values for each token.
  • Defaults: what the device assumes when you omit a parameter.
  • Platform notes: supported platforms and version differences.
Practical guidance

When you see two similar commands, open both entries and compare parameter effects and default values. Use the entry that lists your OS version and model to avoid surprises.

Misconception

Assuming a command does the same on all platforms. Always check platform/version notes in the entry header.

Key Takeaway

When in doubt about syntax or defaults, the command reference is the definitive source to consult before applying configuration in the lab.
