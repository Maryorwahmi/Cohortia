Expected adapted configuration
# Example adapted PAT configuration
ip access-list standard NAT_ACL
 permit 192.168.1.0 0.0.0.255
!
interface GigabitEthernet0/1
 ip address 192.168.1.1 255.255.255.0
 ip nat inside
!
interface GigabitEthernet0/2
 ip address 203.0.113.1 255.255.255.0
 ip nat outside
!
ip nat inside source list NAT_ACL interface GigabitEthernet0/2 overload
This snippet shows the adapted values for a lab where GigabitEthernet0/1 is the inside interface and GigabitEthernet0/2 holds the public IP. Note the ACL, interface assignments, and the NAT overload statement.
Verification steps
  1. Confirm ACL entries match the internal subnet.
  2. Check interfaces have the ip nat inside/outside keywords.
  3. Run translation and session commands to confirm overload behavior.
Common mistake

Forgetting to apply ip nat inside to the correct interface or mismatching the ACL network will prevent translations and appear like NAT failure.
