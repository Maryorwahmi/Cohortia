Mini timeline for a lookup
  1. Identify document type (config guide/command ref/troubleshooting).
  2. Search with a precise phrase and platform filter.
  3. Jump to the table of contents or use find to reach the exact section.
  4. Annotate the example, apply adapted lines, and run verification commands.
Checkpoint

Aim to complete this timeline in under three minutes for routine tasks; longer for complex features but always time-boxed.

Personal cheatsheet

Keep one page with your topology mapping: interface names, IP pools, AS numbers, and common ACL names. This avoids re-deriving values during timed lookups.
