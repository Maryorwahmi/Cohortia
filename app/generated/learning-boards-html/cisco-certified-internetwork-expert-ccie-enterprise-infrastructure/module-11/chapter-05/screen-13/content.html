Module 11 › Chapter 11.5 › Self Assessment
Timed challenge
Task steps
  1. Locate the authoritative document for the feature.
  2. Extract and annotate the configuration example.
  3. Adapt the example to the provided topology.
  4. Apply and run verification commands.
Reflection prompts
  • How long did each phase take?
  • What required the most cross-document lookup?
  • Which verification command gave the clearest evidence of success?
Goal

Reduce your locate-adapt-verify cycle time through targeted practice until it becomes a fast, repeatable reflex in mock labs.
