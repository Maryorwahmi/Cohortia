Module 11 › Chapter 11.9 › Progress Over Perfection
Task hierarchy
Core connectivity → Required services → Refinements.
Core: ensure interfaces and routing are verified; test reachability between required endpoints.
Services: configure essential services or policies that earn points.
Refinement: optimization or non-critical polishing only if time allows.
Rules of thumb
  • Set a hard time cap per task. If unresolved, save and move to the next.
  • When stuck, pick verification commands that prove partial correctness and return later.
  • Keep a visible list of remaining tasks and their relative point value.
Example: spend 10 minutes on a complex ACL issue; if not resolved, verify and document current behavior and continue to the next high-value task.
Key Takeaway

Time is the scarce resource; protect it by prioritizing verification and high-value tasks first.
