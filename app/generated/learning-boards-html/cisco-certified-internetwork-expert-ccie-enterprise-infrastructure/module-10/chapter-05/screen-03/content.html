DNA Center
Use onboarding logs, fabric inventory, and policy deployment status to correlate device state and policy health.
Mnemonic
Underlay → Control → Overlay → Policy. Run checks in that order to avoid wasted changes.
Practical tip
Always document outputs and baseline healthy-state outputs in a lab. When you act, prefer incremental, reversible changes.
VERIFIED COMPETENCY MILESTONE
Interpret a set of CLI outputs and identify whether the root cause is underlay, control, overlay, or policy.
