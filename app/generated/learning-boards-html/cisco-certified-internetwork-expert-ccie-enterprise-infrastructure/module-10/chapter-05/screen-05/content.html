Module 10 › Chapter 10.5 › SD‑WAN Control Plane
Process Flow
Control plane validation steps
  1. Confirm underlay reachability to vSmart and vBond with ping/traceroute.
  2. Run show control connections to check session states and endpoints.
  3. Verify device certificates with show certificate installed.
  4. If needed, run debug control connections to capture negotiation traces.
  5. Check orchestrator connectivity with show orchestrator connections and review vManage/vBond logs.
Terminal examples
> show control connections
vSmart: 10.5.0.2   Status: up   Last change: 00:05:12
vBond: 10.5.0.3    Status: up

> show certificate installed
Device cert: valid, expires in 45 days
CA trustpoint: established
Common mistake
Assuming ping implies control plane success. You can reach an IP but still fail TLS authentication due to expired certificates.
