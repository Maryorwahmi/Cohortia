Module 10 › Chapter 10.5 › Underlay vs Overlay
Definition
Underlay and Overlay
Underlay: the routed IP network. Overlay: the SD‑WAN or SD‑Access encapsulation and control elements that run on top.
Check 1: Ping controllers and peers to confirm reachability.
Check 2: show ip route to make sure next hops exist and are stable.
Check 3: Inspect ACLs and firewall rules that may block DTLS/TLS, IPsec, or BFD ports.
Terminal example
> ping 10.0.0.5
Sending 5, 100-byte ICMP Echos to 10.0.0.5, timeout 2 seconds:
Success rate is 100 percent (5/5)

> show ip route
Codes: C - connected, S - static, O - OSPF
C 10.0.0.0/24 is directly connected, GigabitEthernet0/0
O 10.1.0.0/24 [110/20] via 10.0.0.1, 00:01:23, GigabitEthernet0/0
Key Takeaway
Start with simple reachability and routing checks. Resolve underlay faults before changing overlay policies or certificates.
