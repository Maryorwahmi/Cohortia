Core Concept

Transform-sets & Crypto ACLs

Phase 2 requires both matching transform-sets and correct ACL definitions for interesting traffic. Either can prevent data SAs.

Diagnostic steps
  • Confirm Phase 1 is UP.
  • Run show crypto ipsec sa and check pkts encaps/decaps.
  • Verify the access-list referenced by the crypto map matches local and remote subnets.
  • Ensure transform-set algorithms are identical on both peers.
Concrete example and check

If show crypto isakmp sa shows QM_IDLE but show crypto ipsec sa shows no active SA, send a ping that should match the crypto ACL. Then re-run show crypto ipsec sa to see if pkts encaps increments. If it does not, review the ACL and the transform-set on both routers.

Key Takeaway

A ping that should be encrypted is a quick litmus test for whether your crypto ACL is recognized as interesting traffic.

Common mistake

Forgetting that NAT applied before encryption changes packet addresses and may prevent matching the crypto ACL.
