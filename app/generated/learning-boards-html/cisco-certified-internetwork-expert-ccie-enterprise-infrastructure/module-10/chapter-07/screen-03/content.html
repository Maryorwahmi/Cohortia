Diagnostics & Commands

Become fluent with show and debug commands, and adopt a safe debugging workflow.

Show commands
  • show crypto isakmp sa / show crypto ikev2 sa — Phase 1 status
  • show crypto ipsec sa — Phase 2 counters and SA state
  • show dmvpn / show ip nhrp — NHRP state and mappings
Debug commands
  • debug crypto isakmp / ikev2 — negotiation messages (use with caution)
  • debug crypto ipsec — Phase 2 negotiation details
  • debug nhrp — DMVPN NHRP registration troubleshooting
Safety habits
  • Run show first to isolate the problem domain.
  • Use targeted debug filters and monitor impact.
  • Have a rollback and avoid global clears in production unless planned.
