Module 10 › Chapter 10.7 › Common Phase 1 failures and fixes
Core Concept

Phase 1 failure modes

Mismatched parameters

Verify encryption, hash, DH group, and lifetime. A single mismatch prevents Phase 1 SAs from forming.

PSK mismatch

Pre-shared key strings must be identical. If they differ, authentication will fail and negotiation aborts.

Reachability & ports

Confirm UDP 500 and 4500 are allowed and that routing to the peer's outside interface works.

Concrete diagnostic steps
  1. Ping the peer public IP and verify routing.
  2. Run show crypto isakmp sa — expect UP or QM_IDLE for a healthy Phase 1.
  3. If missing, enable debug crypto isakmp briefly on the rejecting peer and observe the authentication error.
Misconception

Believing transform-sets cause Phase 1 failures. Transform-sets are Phase 2 objects and will not prevent Phase 1 from establishing.

Key Takeaway

Isolate Phase 1 first; fix PSK and parameter mismatches before investigating Phase 2.
