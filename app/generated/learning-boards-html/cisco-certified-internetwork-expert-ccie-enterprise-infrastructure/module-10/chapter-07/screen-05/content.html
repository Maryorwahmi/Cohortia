Module 10 › Chapter 10.7 › Using show and debug safely
Process Flow

Show → Interpret → Debug → Fix → Verify

Essential show commands
  • show crypto isakmp sa / show crypto ikev2 sa
  • show crypto ipsec sa — pkts encaps/decaps
  • show crypto map — crypto ACL references
  • show access-lists — hit counts and matching
Key warning

Run debug sparingly and during a maintenance window if possible. Target the protocol and stop the debug as soon as you capture relevant messages.

Terminal demo panel
! On Router A
show crypto isakmp sa
show crypto ipsec sa
show crypto map
show access-lists

! Use debug only after isolation:
debug crypto isakmp
debug crypto ipsec
Concrete example

If show crypto isakmp sa shows no entry, don't run debug crypto ipsec. First, confirm UDP port reachability or PSK correctness.

Key Takeaway

A reproducible sequence reduces noise and leads you to the root cause quicker than blind debugging.
