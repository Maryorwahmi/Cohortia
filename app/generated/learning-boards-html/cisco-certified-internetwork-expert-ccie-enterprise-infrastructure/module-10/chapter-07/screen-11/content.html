Module 10 › Chapter 10.7 › NAT interactions with VPNs

Why NAT can break VPNs

If translation happens before encryption, the crypto ACL may not match the translated packet and the tunnel will not carry the intended traffic.

Practical checks
  • show ip nat translations — inspect active translations
  • review ip nat inside/outside interface assignments
  • confirm the ACL used by ip nat inside source matches original internal addresses
Concrete example

If 10.1.1.0/24 is translated to a public IP before the crypto ACL runs, pinging the remote protected subnet will not be encrypted. To correct this, add a nat exemption — for example nat 0 with an ACL matching 10.1.1.0/24 to the remote 10.2.2.0/24 — so that traffic destined for the tunnel bypasses NAT.

Key Takeaway

Always exempt VPN traffic from NAT when the translation would occur before the crypto pipeline inspects it.
