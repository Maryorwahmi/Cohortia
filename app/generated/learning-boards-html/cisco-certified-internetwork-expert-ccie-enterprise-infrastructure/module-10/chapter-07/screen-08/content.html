Core Concept

NHRP registrations and mappings

NHRP resolves private tunnel IPs to outer NBMA addresses so spokes can form direct tunnels when allowed.

Hub configuration essentials
  • ip nhrp network-id
  • ip nhrp map multicast dynamic
  • ip nhrp map [spoke_ip] [spoke_nbma_ip] entries as needed
Spoke configuration essentials
  • ip nhrp network-id
  • ip nhrp nhs [hub_ip]
  • ip nhrp map [hub_ip] [hub_nbma_ip]
Troubleshooting checklist
  • Use show dmvpn to view tunnel status and NHRP mappings.
  • Use show ip nhrp to inspect the NHRP cache on spokes and hub.
  • Enable debug nhrp when registrations or mapping resolution fail.
Concrete scenario

Spoke A cannot reach Spoke B. Both have valid hub registrations. Verify whether the hub has ip nhrp redirect enabled and whether spokes have ip nhrp shortcut configured to accept and act on redirects for direct tunnels.
