Module 10 › Chapter 10.2 › What you'll be able to do
Objective drills
Use show interface counters errors to detect physical-layer issues such as CRC or input drops and map them to cabling or duplex problems.
Enable focused debug such as debug ip ospf adjacency to capture neighbor state changes without overwhelming the CPU.
Capture only host and port pairs with tcpdump, save to a pcap, and open in Wireshark for protocol-level inspection.
Configure syslog servers and SNMP trap destinations to build a historical timeline that supports root cause analysis.
Mnemonic
Think: Observe, Narrow, Capture, Correlate — Observe state, Narrow scope, Capture packets, Correlate with logs for timely root cause.
Safety reminder
Always ensure console or out-of-band access before enabling intensive debug, and run `no debug all` when finished.
