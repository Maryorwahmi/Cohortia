Module 10 › Chapter 10.2 › Workflow & Timeline
Step-by-step workflow
  1. Collect baseline: show interface, show ip route, show processes cpu; note time.
  2. Form hypothesis and choose narrow debug and capture filters.
  3. Start capture with a count or time limit; start debug if needed.
  4. Stop debug and capture; save output with clear timestamps and device names.
  5. Correlate syslog and SNMP traps to build the incident timeline and conclude root cause.
Example timeline
10:30:00 — `show interface` shows rising CRC errors. 10:30:01 — `debug ip ospf adjacency` reports neighbor down. 10:30:02 — tcpdump shows TCP retransmissions to server. Correlate and conclude physical link issue.
