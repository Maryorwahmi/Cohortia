Module 10 › Chapter 10.2 › Advanced show Commands
Definition
What advanced show commands reveal
Advanced show commands expose interface counters, protocol-specific tables, and control-plane state that basic summaries miss.
Command example
show interface GigabitEthernet0/1 counters errors
Why it helps
Shows CRC, input errors, and drops to pinpoint physical or link-layer issues.
Key Takeaway

Start with the most specific show command that answers the diagnostic question; record timestamps or clear counters for fresh measurements.

Procedure + Example
show interface GigabitEthernet0/1
  Hardware is Gigabit Ethernet, address is 001b.21a5.6c01
  Internet address is 10.0.0.1/24
  Last input 00:00:12, output 00:00:04, output hang never
  5 minute input rate 5000 bits/sec, 10 packets/sec
  5 minute output rate 1000 bits/sec, 5 packets/sec
  0 input errors, 12 CRC, 0 frame, 0 overrun, 0 ignored
  3 output errors, 2 collisions
Interpretation
CRC errors with zero input errors suggests physical-layer corruption; check fiber/cable and SFPs.
Common mistake
Reading counters without noting time can confuse intermittent and persistent issues; clear counters before a test when possible.
Question to check understanding
If you see rising output errors but no interface flaps, what physical or configuration areas do you inspect first?
