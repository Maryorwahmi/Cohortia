Module 10 › Chapter 10.2 › Advanced ping & traceroute
Advanced ping examples
ping 172.16.1.100 source GigabitEthernet0/1 repeat 10 size 1400
ping 10.0.0.1 timeout 2
Use source selection to force the test out a specific interface and repeated pings to observe intermittent loss patterns.
Limitation
ICMP filtering or device priority changes can cause traceroute results to omit hops or misrepresent latency.
Traceroute and service checks
Traceroute maps hops; telnet tests TCP port connectivity and SSH tests service availability.
Example
If traceroute stops at a firewall, run `telnet 192.0.2.10 80` to verify whether HTTP is blocked or whether ICMP is filtered only.
Common misconception
Assuming traceroute always shows firewall blocks; some devices silently drop ICMP while allowing TCP traffic.
Key Takeaway
Combine source-bound pings, traceroute, and port tests to differentiate between path problems and service-level filtering.
