Module 10 › Chapter 10.2 › Debug: OSPF vs BGP
OSPF debugging
Use narrow commands to watch neighbor transitions.
debug ip ospf adjacency
%OSPF-5-ADJCHG: Nbr 10.0.0.2 on Gi0/1 from LOADING to FULL
%OSPF-5-ADJCHG: Nbr 10.0.0.2 on Gi0/1 from FULL to DOWN
This output shows exact neighbor state transitions, which helps confirm whether adjacency flaps explain route instability.
BGP debugging
Choose between events and updates depending on whether you need session or routing detail.
debug ip bgp events
% BGP-5-ADJCHANGE: neighbor 192.0.2.2 down: hold timer expired

debug ip bgp updates
% BGP-6-ADVERTISE: sent to neighbor 192.0.2.2 prefix 203.0.113.0/24
When to use events
Track session transitions and negotiation issues.
When to use updates
Investigate route advertisements and withdrawals.
Avoid
Running all BGP debug types together on production peers; it often floods consoles and CPU.
