Module 10 › Chapter 10.2 › Telnet vs SSH
Telnet as a port tester
Quickly confirm whether a TCP listener on a given port is reachable.
R# telnet 192.168.1.100 80
Trying 192.168.1.100...
Connected to 192.168.1.100.
SSH for secure access
Use SSH to log into devices securely and run further diagnostics when you need command access.
When telnet is insufficient
If telnet shows an open port but the application reports errors, use SSH to run captures or check application logs on the host.
Misconception check
Telnet confirms TCP-level reachability only; it does not validate application protocol correctness or authentication behavior.
