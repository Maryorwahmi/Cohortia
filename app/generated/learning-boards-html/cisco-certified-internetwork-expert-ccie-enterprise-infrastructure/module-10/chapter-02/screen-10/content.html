R1# terminal monitor

%OSPF-5-ADJCHG: Nbr 10.0.0.2 on Gi0/1 from LOADING to FULL

Run only the specific adjacency debug to minimize impact; log outputs for correlation with captures.
R2 — tcpdump capture
# tcpdump -i GigabitEthernet0/1 host 172.16.1.100 and port 80 -c 5
10:30:01.123456 IP 192.168.10.5.54321 > 172.16.1.100.80: Flags [S]
10:30:01.123500 IP 172.16.1.100.80 > 192.168.10.5.54321: Flags [S.]
10:30:01.123600 IP 192.168.10.5.54321 > 172.16.1.100.80: Flags [.]
The SYN, SYN-ACK, ACK sequence followed by pushed data confirms the HTTP connection was established and data flowed.
