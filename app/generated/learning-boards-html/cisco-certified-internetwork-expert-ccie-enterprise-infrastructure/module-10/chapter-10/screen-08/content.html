Module 11 › Chapter 10.10 › Eradication & Recovery
Steps to Eradicate
  1. Confirm root cause with evidence and timeline.
  2. Implement the permanent fix in a controlled environment or single device.
  3. Run post-fix validation: routing tables, connectivity, performance metrics.
Concrete Example
Remove incorrect route redistribution, verify route tables converge, and run traffic tests before declaring recovery complete.
Recovery Checklist
  • Bring services back progressively using rollback controls.
  • Monitor for a defined observation period to ensure stability.
  • Notify stakeholders with resolution details and any remaining work.
Key Takeaway

Permanent fixes must be verified in a controlled way and observed over time to ensure eradication succeeded.
