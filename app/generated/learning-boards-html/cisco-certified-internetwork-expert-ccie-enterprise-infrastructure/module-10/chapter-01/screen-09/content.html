Module 10 › Chapter 10.1 › Structured Troubleshooting Steps
A repeatable sequence
Define

Write the symptom, scope, users affected, and when it started.

Gather

Collect show outputs, logs, ping/traceroute results, and performance data.

Analyze

Look for anomalies, missing routes, or error counters that point to cause.

Hypothesize

Create testable theories about the root cause.

Test

Run targeted diagnostics to confirm or reject hypotheses.

Verify

Confirm the original symptom is resolved and no new issues exist.

Document

Record the problem statement, collected evidence, hypotheses, test results, the implemented fix, verification steps, and a rollback plan for future reference.

Pro tip: keep a troubleshooting template with fields for each step to speed incident response.
