Bottom-Up

Start at Layer 1 and move up

Check physical connectivity first, then Layer 2 MAC/VLAN, then Layer 3 addressing and routing.

Concrete example
A rack-wide loss of connectivity often starts with link or power checks; verifying physical state quickly narrows the fault domain.
When it excels
Effective for suspected cabling, port, or switch hardware problems.
Misconception
A verified link does not guarantee correct VLAN or ACL behavior; check those next if traffic is still blocked.
Step checklist
  1. Verify physical link lights and cabling continuity.
  2. Check interface status and errors with show interfaces.
  3. Confirm MAC address learning and VLAN assignment.
  4. Verify IP addressing and routing tables.
Key Takeaway

When infrastructure is suspect, validate the lowest layers first but escalate checks when higher-layer evidence appears.
