Module 10 › Chapter 10.1 › Workstation to Web Server Walkthrough
Scenario steps
Workstation checks
ping 127.0.0.1
ping 10.1.1.50
ping [workstation_default_gateway_IP]
traceroute 192.168.100.10

Confirm local IP and gateway reachability before moving to network devices.

Access switch checks
show interface status
show mac address-table interface [interface_id]
show vlan brief

Verify port up, correct VLAN, and MAC learning for the workstation and gateway.

Distribution router checks
show ip interface brief
show ip route 192.168.100.10
ping 192.168.100.10 source [distribution_router_interface_ip]
traceroute 192.168.100.10

If route is missing, hypothesis might be a routing protocol or route redistribution issue.

Core router checks
show ip interface brief
show ip route 192.168.100.10
ping 192.168.100.10 source [core_router_interface_ip]

Confirm core reachability; if core reaches the server then the problem is likely downstream of distribution.

Key Takeaway

Follow the hop-by-hop tests and only run device-level show commands on the first device where connectivity fails.
