OSI Model Checklist
Layer 1
Physical: cables, transceivers, link lights, interface errors.
Layer 2
Data link: VLAN membership, spanning tree, MAC address tables.
Layer 3
Network: IP addressing, routing tables, next-hop reachability.
Layer 4
Transport: TCP/UDP ports, session establishment, retransmissions.
Layers 5–7
Session, presentation, application: authentication, application logs, port services.
Use case
When you want a complete checklist to ensure nothing is missed during incident response or post-incident review.
Key Takeaway

Treat the OSI layers as a verification checklist; use it to confirm each domain works before moving to the next.
