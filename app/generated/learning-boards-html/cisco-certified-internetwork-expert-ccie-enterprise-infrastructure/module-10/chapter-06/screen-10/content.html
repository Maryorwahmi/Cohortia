Core Concept › NTP Troubleshooting
Commands to inspect
show ntp status
show ntp associations detail
ntp server 172.16.1.20
debug ntp packet
debug ntp control
Look for Clock is synchronized in show ntp status and check offset/delay values in associations to ensure acceptable time alignment.
Practical checks
If the server is reachable but the client refuses to sync, check for ntp authenticate with mismatched keys, or examine stratum differences and network latency that keep offset high.
Concrete example
BR1 configured ntp server 172.16.1.20 but show ntp status did not show Clock is synchronized. After verifying reachability and keys, the admin corrected the key ID and the clock synchronized.
Common-mistake

Assuming reachability is sufficient. Authentication key mismatch or excessive offset can prevent sync even when the server is reachable.
