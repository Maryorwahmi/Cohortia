Definition › Cisco DNS Commands
Commands to verify
ip domain-lookup
ip name-server 172.16.1.10
show hosts
debug domain
nslookup www.example.com 172.16.1.10
Run nslookup against the DNS server IP to check authoritative answers and to separate router issues from DNS server problems.
Supporting explanation
If ip domain-lookup is disabled, the router will not attempt name resolution. Ensure ip name-server list is current and reachable from the router.
Concrete example
On BR1, ip name-server 172.16.1.10 ensures the router and any forwarded lookups use the data center DNS. If that server is unreachable, client nslookups will fail even if DHCP provided the correct address.
Key Takeaway

Use router-level commands to confirm name resolution is correct and test with direct nslookup calls to isolate server vs network issues.
