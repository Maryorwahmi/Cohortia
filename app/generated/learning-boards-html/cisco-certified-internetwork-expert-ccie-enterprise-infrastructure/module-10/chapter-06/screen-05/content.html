Definition › DHCP Troubleshooting
Client checks
Ensure DHCP is enabled on the host, interface is up, and the client can broadcast. If static works but DHCP does not, the client config or network path is suspect.
Server checks
Confirm pool, default-router, DNS, and free addresses with show ip dhcp pool and show ip dhcp binding; check server reachability with ping.
Relay agent
Validate ip helper-address on the correct SVI or interface and ensure UDP ports 67/68 are permitted through ACLs.
Concrete example
If VLAN 10 clients do not get addresses, check the Vlan10 SVI config. Missing ip helper-address is a frequent culprit when the DHCP server is on another subnet.
Common-mistake
Configuring helper-address on the wrong interface or forgetting to add it entirely causes Discover messages to never reach the server.
Key Takeaway

Think in client, relay, server steps and test each with show/debug commands to isolate the failure domain.
