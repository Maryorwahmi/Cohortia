Recommended debug commands
debug ip dhcp relay
debug ip dhcp server packet
debug domain
debug ntp packet
debug aaa authentication
debug radius
Enable one debug at a time, reproduce the issue, capture output to a log, then disable immediately.
Capture strategy
Use the console or a logging host to store debug output. Limit debug session length, and redact or protect any sensitive information found in older debug formats.
Misconception
Debug is not a monitoring substitute. Continuous debug can impact device performance and expose sensitive data.
Pro tip

Practice debug scenarios in a lab to become efficient at enabling, reproducing, and disabling individual debug commands.
