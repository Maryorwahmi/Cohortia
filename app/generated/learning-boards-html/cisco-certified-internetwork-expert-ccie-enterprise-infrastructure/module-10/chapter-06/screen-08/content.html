Definition › DNS Troubleshooting
Client-side checks
Confirm client has correct DNS server IPs, can ping the server, and run nslookup to verify resolution or error messages.
Server-side checks
Ensure DNS service is listening on port 53, zones contain the expected records, and the server can resolve upstream names if recursive queries are required.
Network path
Look for firewall or ACL blocks on UDP/TCP 53. Also verify that intermediate devices do not accidentally redirect or filter DNS traffic.
Concrete example
Clients receive DNS server 172.16.1.10 via DHCP but nslookup to that IP times out. A firewall was blocking UDP 53 between the branch and the server.
Key Takeaway

Use nslookup against a specific DNS server to separate client configuration issues from server or path problems.
