Process Flow › Branch Office Lab
Given scenario
VLAN 10 clients not receiving DHCP. DHCP and DNS servers are at 172.16.1.10. NTP server is 172.16.1.20. Use BR1 to triage and fix.
Follow reachability → config → show → debug sequence for each service and verify each remediation step with show commands.
Commands to run on BR1
! Check interface for helper
show running-config interface Vlan10

! If missing, configure helper
interface Vlan10
 ip helper-address 172.16.1.10
!
! Debug relay to observe DHCP
debug ip dhcp relay

! DNS checks
ip domain-lookup
ip name-server 172.16.1.10
nslookup www.example.com 172.16.1.10

! NTP configure and verify
ntp server 172.16.1.20
show ntp status
show ntp associations detail
Expected verification: DHCP relays seen in the debug output, nslookup returns the A record, and show ntp status reports Clock is synchronized.
Key Takeaway

Apply the same checklist across DHCP, DNS, and NTP: reachability, correct config, server state, and targeted debug.
