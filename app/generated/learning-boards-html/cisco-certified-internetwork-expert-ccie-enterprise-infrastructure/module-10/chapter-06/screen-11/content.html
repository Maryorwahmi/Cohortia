Core Concept › AAA Troubleshooting
Component checks
  • Ping the AAA server from the device to check basic reachability.
  • Verify shared secrets match on both sides for RADIUS/TACACS+.
  • Confirm aaa new-model is enabled and method lists are applied correctly.
Commands
test aaa group radius [username] [password] and debug aaa authentication are primary tools for validation.
Concrete scenario
If users cannot log in with RADIUS, verify the radius-server host entry and shared secret, test with test aaa group radius, and consult server logs. If the device lacks a local fallback in the method list, restore console access before changing AAA.
Safety note
Always keep local authentication reachable or console access during AAA changes to avoid being locked out of devices.
