Summary › What to Remember
Ping first
Start with simple reachability checks to eliminate routing and ACL issues before changing service configs.
Check ports
Verify service ports are permitted: DHCP 67/68, DNS 53, NTP 123, RADIUS/TACACS ports as required.
Safe debug & changes
Keep console access and a local authentication fallback, and run debug commands briefly to capture evidence without disruption.
Final takeaway

A calm, methodical approach combined with the right show/debug commands keeps services reliable and reduces incident impact.
