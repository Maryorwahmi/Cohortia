Process Flow › DHCP Server Commands
When to run these
Run show ip dhcp pool to confirm pool parameters, then show ip dhcp binding to check lease assignments. Use show ip dhcp conflict if duplicates are suspected.
Supporting points
  • Pool misconfiguration can set the wrong default-router or DNS.
  • Bindings show MAC-to-IP mapping; absence indicates the server never assigned a lease.
  • Conflicts can prevent assignment even when addresses appear available.
Command examples
show ip dhcp pool
show ip dhcp binding
show ip dhcp conflict
show ip dhcp server statistics
show running-config interface Vlan10
Use these in order: pool → binding → conflict → server stats. If the pool shows few free addresses, investigate exclusions or scope errors.
Common-mistake

Assuming the server is reachable; always ping the server from the gateway before deeper server checks.
