Core Concept › DHCP Relay Agent
What to verify
Ping the DHCP server from the SVI, confirm the helper address on that interface, and check ACLs for UDP 67/68.
Quick checklist
  • show running-config interface Vlan10
  • ping 172.16.1.10 source Vlan10
  • debug ip dhcp relay
Example scenario
VLAN 10 clients cannot obtain leases. show running-config shows no ip helper-address on Vlan10. Adding ip helper-address 172.16.1.10 and testing with debug ip dhcp relay shows Discover forwarded and leases issue.
Pro tip
If multiple helper-address entries are needed for different servers, list them explicitly. Verify reachability to each before assuming relay is fault-free.
