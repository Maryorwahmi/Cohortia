Definition

Root bridge and port roles

The root bridge is the topology reference. Port roles decide which interfaces forward and which block to prevent loops.

Port roles
  • Root — the best path from a switch to the root bridge, should be forwarding.
  • Designated — forwards on a LAN segment toward non-root devices.
  • Alternate/Blocked — non-forwarding to prevent loops.
Example CLI
SW# show spanning-tree vlan 10
VLAN010
  Root ID    Priority    32769
  Root Port  Gi0/2
  Interface Gi0/1  Role Desg  State Forwarding
  Interface Gi0/2  Role Root  State Forwarding
If the root ID is not your intended switch, confirm priority settings and accidental connections that might have promoted another device.
Pro Tip

Set explicit bridge priority on intended root switches and document it to avoid accidental root election.
