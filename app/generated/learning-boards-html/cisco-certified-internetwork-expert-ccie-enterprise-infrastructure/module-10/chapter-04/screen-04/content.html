Module 10 › Chapter 10.4 › VLAN Mismatch and Trunk Diagnostics
Definition

VLAN mismatch

A mismatch occurs when VLAN membership or allowed VLAN lists differ between connected switches, preventing frames from reaching the intended segment.

Checklist
  • Run show vlan brief on both switches to confirm VLAN exists.
  • Run show interface Gi0/1 switchport to see access VLAN or trunk allowed list.
  • Run show interfaces trunk to confirm native VLAN and allowed VLANs.
  • Prefer switchport mode trunk over dynamic DTP in production.
Example CLI checks
SW1# show vlan brief
VLAN Name                             Status    Ports
10   SALES                            active    Gi0/3, Gi0/4

SW2# show vlan brief
VLAN Name                             Status    Ports
1    default                          active    Gi0/1
If VLAN 10 is absent from SW2, traffic will not be forwarded even if the link is up.
Key Takeaway

Always verify VLAN existence and trunk native/allowed VLANs on both ends before assuming connectivity.
