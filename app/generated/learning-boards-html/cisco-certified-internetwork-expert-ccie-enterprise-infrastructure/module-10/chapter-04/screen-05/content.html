Module 10 › Chapter 10.4 › Native VLAN Mismatch
Process

Diagnose native VLAN mismatch

  1. Run show interfaces trunk on both switches and compare the Native VLAN entry.
  2. Run show interface GiX/Y switchport to see if native VLAN was set per-interface.
  3. Check show spanning-tree vlan [vlan] to observe BPDU behavior and port roles.
  4. If mismatch exists, plan to align native VLANs explicitly and verify STP after change.
Example output
SW1# show interfaces trunk
Port        Mode         Encapsulation  Status        Native VLAN
Gi0/1       on           802.1q         trunking      1

SW2# show interfaces trunk
Port        Mode         Encapsulation  Status        Native VLAN
Gi0/1       on           802.1q         trunking      10
Native mismatch shown above means untagged frames are treated differently. BPDUs may not be compared correctly across the link.
Common Mistake

Assuming native VLAN affects only user traffic. It also affects control plane like BPDU exchange and CDP.
