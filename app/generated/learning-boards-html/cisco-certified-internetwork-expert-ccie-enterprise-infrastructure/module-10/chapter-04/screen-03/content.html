Module 10 › Chapter 10.4 › Learning Objectives
Command fluency
  • show vlan brief — confirms VLAN presence and membership.
  • show interface switchport — reveals access VLAN, trunk mode, native VLAN.
  • show interfaces trunk — lists native VLAN and allowed VLANs across trunks.
  • show spanning-tree vlan [id] — displays root, port roles, and port states per VLAN.
  • show etherchannel summary — indicates bundle formation and protocol.
Safety checklist
Avoid disabling STP in production; test changes on spare links first.
Enable BPDU Guard on PortFast access ports to prevent accidental switches.
Explicitly set trunk mode to avoid DTP surprises in production.
