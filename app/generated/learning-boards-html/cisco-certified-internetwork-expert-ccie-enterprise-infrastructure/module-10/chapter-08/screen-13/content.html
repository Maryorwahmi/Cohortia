Module 10 › Chapter 10.8 › IGMP Snooping

Switch-level checks

Confirm snooping groups, querier presence, and port membership so multicast is forwarded only to interested ports.

show ip igmp snooping groups
VLAN 10: 239.1.1.1 -> Gi1/0/5 (receiver), Gi1/0/6 (receiver)
show ip igmp snooping
Querier 10.0.0.254 on VLAN 10
Troubleshoot

If receivers are not getting traffic, confirm both the router OIL and the switch forwarding table include the receiver port. Refresh snooping state by toggling IGMP or re-querying if necessary.

Example
Scenario
Switch shows group but port is missing; the router shows OIL includes the downstream link. Fix the snooping database or the querier so the switch builds the correct port mapping.
Key Takeaway

Ensure both L2 and L3 state match. IGMP snooping without a querier or with stale entries can cause missing downstream delivery.
