Module 10 › Chapter 10.8 › PIM Adjacency

Neighbor checks

Confirm that PIM mode is enabled and that control-plane packets are not filtered by ACLs or firewalls.

show ip pim neighbor
ping 10.0.0.2
show running-config interface GigabitEthernet0/1
Common issue

PIM hellos blocked by ACLs are a frequent cause. Inspect access-lists applied to interfaces that might match 224.0.0.13 or protocol 103 traffic.

Example
Scenario
No PIM neighbors on a distribution interface. Fixed by adding ip pim sparse-mode on the interface and permitting protocol 103 in the interface ACL.
Key Takeaway

PIM adjacency depends on control-plane reachability. Fix ACLs and ensure matching PIM modes before investigating deeper.
