Process

Policing checks

Read police counters and compare them to measured throughput; confirm units and burst parameters to avoid unintended drops.

Class-map: Video
 Match: dscp af41
  police: 5000000 bps, 62500 bytes burst
  conformed 1500 packets, exceeded 2000 packets, violated 1500 packets, dropped 1500
Misconception

Assuming police rate mismatches are always classification errors. If counters show exceed/violate, policing is active even if classification is correct.

Example
Scenario
Video policed to 5 Mbps but drops occur. Check if rate entered as bytes per second or bits per second and inspect burst size versus microburst pattern.
Key Takeaway

Policing is immediate and can drop microbursts. Verify rate units, burst, and direction before tuning queues.
