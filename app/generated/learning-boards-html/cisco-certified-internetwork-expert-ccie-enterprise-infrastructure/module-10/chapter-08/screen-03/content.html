Multicast Objectives

Targeted checks for PIM, RP, mroute, and IGMP snooping.

Learn → Understand → Apply → Master
05
Verify PIM Neighbor Formation

Use show ip pim neighbor and check hello reachability and mode mismatches; PIM hellos use 224.0.0.13 and protocol 103.

Mnemonic: Hello → Neighbor
Verified Competency Milestone
06
Confirm RP and mroute State

Check show ip pim rp-mapping and show ip mroute to ensure the RP and incoming interface are correct for the group.

Mnemonic: RP → Route
Verified Competency Milestone
07
Find RPF Failures

Use show ip mroute and debug ip pim rpf to locate RPF failures often caused by asymmetric unicast routes.

Mnemonic: RPF → Path
Verified Competency Milestone
08
Check IGMP Snooping and Switch State

Confirm switch-level snooping groups and the querier to ensure proper L2 forwarding to receivers.

Mnemonic: Snooping → Forward
Verified Competency Milestone
