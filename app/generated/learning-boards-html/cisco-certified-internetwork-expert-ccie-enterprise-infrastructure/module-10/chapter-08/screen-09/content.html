Gathering evidence

Use show policy-map interface as the first step. Only escalate to debug with filters and short windows.

! Primary checks
show policy-map interface GigabitEthernet0/1 output
show interfaces GigabitEthernet0/1 counters

! Targeted debug (use briefly)
debug policy-map class Video
! stop after a short period
undebug all
Checklist
  • Confirm match counts first.
  • Inspect police and queue counters next.
  • Run packet capture for DSCP verification.
  • If needed, run a targeted debug with tight filters.
Example
! Show output showing active police drops
Class-map: Video
  police: 5000000 bps
  conformed 1200, exceeded 5000, dropped 5000
Key Takeaway

Use show outputs to justify the need for debug. When you debug, use filters and short windows to avoid impact.
