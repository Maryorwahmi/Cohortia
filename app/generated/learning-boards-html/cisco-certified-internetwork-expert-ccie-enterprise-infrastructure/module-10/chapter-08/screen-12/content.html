RP and mroute checks

Confirm RP mapping, registration state, and examine mroute entries for IIF and OIL details to detect RPF issues.

show ip pim rp-mapping
show ip pim rp 10.0.0.1 group 239.1.1.1
show ip mroute 239.1.1.1
show ip route 192.168.1.100  ! check route to source
Common root cause

RPF failure due to asymmetric unicast routing or a missing route to the source. Fix the unicast path, then multicast forwarding will follow.

Example output
show ip mroute 239.1.1.1
  Incoming interface: Null, RPF check failed
  Outgoing interface list: Gi0/2, Gi0/3
Key Takeaway

If mroute shows RPF failure, inspect the unicast route to the source first. Correct unicast routing before changing multicast configs.
