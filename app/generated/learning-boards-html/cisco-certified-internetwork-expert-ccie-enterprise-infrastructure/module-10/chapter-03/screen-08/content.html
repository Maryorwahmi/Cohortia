Module 10 › Chapter 10.3 › Using show and debug safely

Safe command pattern

  1. Collect state with show commands to narrow the scope.
  2. Plan a short debug window and notify stakeholders.
  3. Run scoped debug or interface-specific debug and capture output.
  4. Stop debug immediately and verify CPU and protocol health.
Example sequence
show ip interface brief
show ip ospf interface Gig0/0
debug ip ospf hello (short duration)
no debug all
show ip ospf neighbor
Risk controls
  • Use maintenance windows when possible.
  • Limit debug to specific interface or neighbor.
  • Monitor CPU and have console access ready.
Final check

After debug, confirm normal CPU and stable neighbor states before declaring the issue resolved.
