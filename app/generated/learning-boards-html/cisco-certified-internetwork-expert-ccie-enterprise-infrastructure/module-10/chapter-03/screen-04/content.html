Module 10 › Chapter 10.3 › OSPF adjacency formation
Definition

OSPF adjacency is when two routers form neighbor states and exchange LSAs to build a shared link-state database.

Common checks
  • Interface state and IP reachability (show ip interface brief).
  • OSPF area and network type (show ip ospf interface).
  • Hello/dead timer alignment and authentication settings.
  • ACLs or multicast blocking that drop 224.0.0.5 packets.
Concrete example
RouterA# show ip ospf interface Gig0/0
  Hello 10, Dead 40, Network Type BROADCAST
RouterB# show ip ospf interface Gig0/0
  Hello 1, Dead 4, Network Type BROADCAST

Mismatch: adjust RouterB hello to 10 to match RouterA.
Debug and verification

Use focused debug commands and verify LSA exchange after adjacency forms.

Scoped debug

debug ip ospf hello — watch hellos; debug ip ospf adjacency — track state transitions. Use filters and limit to maintenance windows on production routers.

Key Takeaway

Small parameter mismatches are the most common root cause. Fix parameters, verify LSA presence with show ip ospf database, then confirm route visibility.
