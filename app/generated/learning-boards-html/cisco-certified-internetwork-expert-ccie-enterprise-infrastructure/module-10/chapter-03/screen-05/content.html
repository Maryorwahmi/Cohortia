Module 10 › Chapter 10.3 › Diagnosing OSPF route advertisement failures
Step-by-step
  1. show ip route ospf — confirm missing prefix.
  2. show ip ospf database — verify LSA exists in the area on all routers.
  3. Check redistribution and subnets keyword if route originated elsewhere.
  4. Inspect filters: distribute-lists, route-maps, area policies.
  5. Use debug ip ospf lsa with filters in a lab to watch LSA creation and flooding.
Example CLI snippets
show ip route ospf
show ip ospf database | include 10.10.0.0
show ip protocols
show run | section router ospf
debug ip ospf lsa
Takeaway

Work backwards from route absence to LSDB and configuration; redistribution and filtering are frequent causes.
