Module 10 › Chapter 10.3 › Route redistribution pitfalls and prevention
Best practices
  • Tag routes at origin of redistribution.
  • Use route-maps to limit which prefixes are redistributed.
  • Set administrative distance or metrics when needed to influence selection.
  • Avoid mutual redistribution without tags or filters.
CLI checks
show run | section router
show route-map
show ip route
show ip route ospf
show ip route eigrp
Example

When redistributing EIGRP into OSPF, tag EIGRP-injected routes with tag 200, then filter tag 200 on OSPF-to-EIGRP redistribution to avoid loops.
