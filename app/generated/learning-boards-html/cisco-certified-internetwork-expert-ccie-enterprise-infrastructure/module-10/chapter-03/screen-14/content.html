Module 10 › Chapter 10.3 › Key Concepts
OSPF Adjacency
Adjacency requires matching timers, network type, area ID, and authentication to exchange LSAs.
EIGRP Neighbor & SIA
Neighbors need matching AS and reachability; SIA means queries await replies and indicates reachability/filter issues.
BGP Peering
BGP depends on TCP on port 179; Active/Connect usually indicate TCP path problems like ACLs or wrong neighbor IPs.
Summary

Use the checklist: interface reachability, neighbor state, protocol-specific parameters, database inspection, then scoped debug and safe validation.
