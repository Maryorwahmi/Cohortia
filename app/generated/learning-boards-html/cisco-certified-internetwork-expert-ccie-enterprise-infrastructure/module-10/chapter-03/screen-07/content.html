Module 10 › Chapter 10.3 › EIGRP Stuck-In-Active (SIA) diagnosis
Symptoms
  • Routes in topology stuck in Active state.
  • Repeated queries with no replies recorded.
  • Potential route removal from routing table after timeout.
Commands
show ip eigrp topology active
debug eigrp packets query
show ip eigrp neighbors
Example scenario

R2 queries for 192.168.1.0. R3 receives query but has an ACL configured that drops EIGRP packets from R2. No reply is sent; R2 lists the route as Active and may remove it after the timer expires.

Common mistake

Raising timers without fixing filtering or reachability masks the issue and allows intermittent failures to persist undetected.

Check

After fixes, confirm show ip eigrp topology no longer shows Active entries and that routes are present in show ip route.
