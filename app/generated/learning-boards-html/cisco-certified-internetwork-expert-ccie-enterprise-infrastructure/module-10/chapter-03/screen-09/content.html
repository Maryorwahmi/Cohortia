Module 10 › Chapter 10.3 › BGP neighbor states and TCP reliance
State meanings
Connect / Active

TCP has not completed; often indicates network or ACL issues blocking port 179.

OpenSent

BGP OPEN message was sent; waiting for OPEN from peer.

Established

Peers exchange updates; check advertised and received routes and attributes.

Example command
show ip bgp summary
telnet 10.0.0.4 179
show ip bgp neighbors 10.0.0.4 advertised-routes
Checklist
  1. Confirm IP reachability to neighbor.
  2. Test TCP 179 from the router to peer.
  3. Check ACLs and firewall policies along path.
  4. Review neighbor configuration and AS numbers.
