Module 10 › Chapter 10.9 › NETCONF / RESTCONF
Connection Checks
  • Confirm NETCONF port 830 or RESTCONF HTTPS port 443 is accessible.
  • Verify credentials and transport security (SSH/HTTPS).
  • Use device debug netconf or debug restconf to inspect incoming requests if available.
YANG Validation
Use schema validators to ensure mandatory leaves are present and that types match. Save request/response pairs for troubleshooting.
Quick Mapping
HTTP 400 = malformed payload; 404 = wrong endpoint; 405 = wrong method; rpc-error = YANG/model violation.
