Process: Verify and elevate
Follow these numbered steps to confirm command execution capability and fix privilege issues.
1. Confirm prompt and mode
Print the session prompt to see if you are in user or enable mode. Example prompt differences are usually visible as '>' vs '#'.
2. Escalate if necessary
Use the enable command with the secret or Netmiko's enable method so privileged commands return expected outputs.
3. Disable paging
Send terminal length 0 or equivalent to avoid paged output breaking parsing logic.
Pro Tip
Add a single line to print the prompt and the first 200 characters of output to quickly determine if privilege or paging caused the issue.
Example Output Signs
  • Prompt ends with > — likely user mode, not privileged.
  • Command returns "Invalid input" — syntax or wrong platform CLI.
  • Partial output with "--More--" — pagination is enabled.
prompt = net_connect.find_prompt()
print("Prompt seen:", prompt)
raw = net_connect.send_command('show running-config', expect_string=r'#')
print(raw[:200])
