Module 10 › Chapter 10.9 › Verification Steps
Python Script Checks
  • Can the host ping the device and SSH to port 22?
  • Reproduce connection with ssh client to confirm credentials.
  • Enable logging and print command outputs before parsing.
Ansible Validation
  • Use ansible-inventory --list -y to inspect parsed inventory.
  • Run playbook with -vvv for detailed connection output.
  • Use ansible-lint to catch YAML and module misuse.
NETCONF / RESTCONF
  • Validate XML/JSON payloads against the YANG model.
  • Check port 830 for NETCONF and 443 for RESTCONF.
  • Use device debug tools to inspect incoming RPCs.
