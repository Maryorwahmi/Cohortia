Module 10 › Chapter 10.9 › Ansible Inventory
Definition
Inventory is the mapping of hostnames to addresses and variables. It controls how Ansible targets managed devices and supplies module parameters.
  • Check ansible-inventory --list -y to see parsed data.
  • Confirm ansible_host, ansible_user, ansible_password, ansible_network_os variables.
  • Watch for precedence issues with group_vars and host_vars.
Example Debug Run
Run a simple ping-like check with -vvv to see exactly which host and IP the control node is trying to reach.
ansible-inventory --list -y
ansible -m ping network_group -vvv
Key Takeaway
Inventory problems are among the fastest to fix once you inspect the parsed output. Never assume a host is included — verify.
