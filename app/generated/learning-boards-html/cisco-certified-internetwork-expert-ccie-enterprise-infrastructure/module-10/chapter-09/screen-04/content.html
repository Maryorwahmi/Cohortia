Module 10 › Chapter 10.9 › Python Debugging
Definition
Identify and fix errors in scripts that use Netmiko or NAPALM to interact with devices. Focus on connectivity, authentication, command execution, and parsing.
  • Connectivity: ping, SSH port, firewalls.
  • Credentials: username, password, enable secret.
  • Parsing: textfsm/genie expectations vs actual output.
Common Mistakes
Hardcoding wrong credentials, wrong device_type, and trusting a parser without verifying raw CLI output.
Key Takeaway

Always reproduce the connection manually, then add logging and exception handling to the script so failures are informative.

Example: Netmiko Authentication Exception
from netmiko import ConnectHandler
from netmiko.exceptions import NetmikoAuthenticationException, NetmikoTimeoutException

device = {
  "device_type": "cisco_ios",
  "host": "192.168.1.1",
  "username": "admin",
  "password": "wrong_password",
  "secret": "enable_password"
}

try:
  net_connect = ConnectHandler(**device)
  output = net_connect.send_command("show ip interface brief")
  print(output)
  net_connect.disconnect()
except NetmikoAuthenticationException:
  print("Authentication failed! Check username, password, or enable password.")
except NetmikoTimeoutException:
  print("Connection timed out! Check host reachability or SSH service.")
except Exception as e:
  print(f"An unexpected error occurred: {e}")
Checklist to run now
  • Ping the device and try an SSH connection from the script host.
  • Verify username/password and device_type in the script dictionary.
  • Use try-except to log exception type and message for faster triage.
Misconception
Assuming a parsing error means connectivity; always inspect the raw output first before adjusting parsers.
