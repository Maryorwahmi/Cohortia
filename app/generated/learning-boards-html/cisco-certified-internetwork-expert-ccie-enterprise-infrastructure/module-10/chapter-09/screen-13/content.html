Structured Logging Pattern
Include these fields: timestamp, host, action, module, input parameters, result or exception, and request/response snapshots when applicable.
{
  "time": "2023-01-01T12:00:00Z",
  "host": "192.168.1.1",
  "action": "send_command: show ip interface brief",
  "result": "AuthenticationException",
  "details": "Authentication failed for user admin"
}
Policies to apply
  • Fail fast on unexpected errors and log context.
  • Use retry with exponential backoff for transient network issues only.
  • Protect destructive tasks with check_mode or explicit confirmation.
Key Takeaway
Good logging and error classification turn incidents into fast fixes. Avoid hiding exceptions and protect destructive operations with dry-run modes.
