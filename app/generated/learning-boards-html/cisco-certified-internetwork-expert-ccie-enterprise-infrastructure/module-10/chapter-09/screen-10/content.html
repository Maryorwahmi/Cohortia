Module 10 › Chapter 10.9 › Controller APIs
Inspecting HTTP Calls
Capture full headers and bodies. For Python use requests with logging enabled; for quick checks use curl -v to view the handshake and response codes.
curl -v -X POST "https://controller/api/auth" -d '{"username":"user","password":"pass"}'
# then inspect headers and token expiry
Common Errors
401/403 = auth problem; 400 = bad payload; 404 = wrong endpoint; 405 = wrong method. Check headers such as Content-Type and Authorization first.
Example: Token Handling
Implement token refresh and log token expiration. If a token expires mid-run, code should obtain a new token and retry operations instead of failing silently.
Key Takeaway
When debugging HTTP 401 errors, check token creation, token expiration, and the Authorization header for correct format before changing payloads.
