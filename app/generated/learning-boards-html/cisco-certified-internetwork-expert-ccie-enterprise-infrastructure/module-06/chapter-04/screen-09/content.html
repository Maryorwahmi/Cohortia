Process › Routing over GRE/IPsec

Enable OSPF

Add the tunnel network and local internal networks to OSPF on each router so routes flow over the tunnel.

• Example: router ospf 1 then network 10.255.255.0 0.0.0.3 area 0 and local internal networks.
• Verify adjacency: show ip ospf neighbor.
• Verify learned routes: show ip route ospf.
Troubleshooting hints
  • • If adjacency fails, ping the remote tunnel IP to confirm GRE is up.
  • • If GRE is up but OSPF fails, check IPsec SAs and interesting-traffic ACLs when using crypto maps.
  • • Confirm that OSPF is enabled on the tunnel interface, not only on the physical.
Key Takeaway

Treat the tunnel as the OSPF adjacency link. GRE carries the protocol; IPsec secures it—both must be functioning for routing to work.
