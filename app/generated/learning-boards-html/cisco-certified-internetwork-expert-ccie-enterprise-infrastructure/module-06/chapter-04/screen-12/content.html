Lab Walkthrough › Configure and Verify

Stepwise checklist

  1. Ensure IKEv2 and COHORTIA_IPSEC_PROFILE are on both routers.
  2. Configure Tunnel0 on R1 and R2 with /30 tunnel IPs and MTU/MSS tuning.
  3. Apply crypto ipsec profile to the tunnel interface.
  4. Enable OSPF on the tunnel and advertise internal networks.
  5. Verify adjacency and SAs, then ping internal hosts.

Starter template (R1 hub)

interface Tunnel0
 ip address 10.255.255.1 255.255.255.252
 ip mtu 1400
 ip tcp adjust-mss 1360
 tunnel source GigabitEthernet0/1
 tunnel destination 203.0.113.2
 tunnel mode gre ip
 crypto ipsec profile COHORTIA_IPSEC_PROFILE

router ospf 1
 network 10.255.255.0 0.0.0.3 area 0
 network 192.168.1.0 0.0.0.255 area 0
Key Takeaway

Perform and verify each stage of the lab: reachability, tunnel creation, IPsec binding, routing, and end-to-end tests—address MTU early.
