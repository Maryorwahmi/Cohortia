Troubleshooting › Layered approach

Diagnostic flow

  1. Confirm IP reachability between tunnel endpoints (ping/traceroute).
  2. Check GRE tunnel state and ping remote tunnel IP.
  3. Verify routing and OSPF adjacency.
  4. Validate IPsec SAs and peer state.
  5. Investigate MTU-related fragmentation if performance issues persist.
Quick commands
• ping to public peer
• show interface tunnel 0
• show ip ospf neighbor
• show crypto ipsec sa
• debug ip icmp (for fragmentation clues)
