Definition › GRE Tunnel Interface

Create the tunnel

Assign a /30 to the tunnel for a point-to-point link, set source and destination to public addresses, and set tunnel mode gre ip so routing protocols can run over it.

interface Tunnel0
 ip address 10.255.255.1 255.255.255.252
 ip mtu 1400
 ip tcp adjust-mss 1360
 tunnel source GigabitEthernet0/1
 tunnel destination 203.0.113.2
 tunnel mode gre ip
Explainer bullets
  • • The tunnel IP is used by routing protocols as the peer address for adjacency.
  • • ip mtu and ip tcp adjust-mss help prevent fragmentation after GRE and IPsec overhead are added.
  • • Ensure the tunnel source selection matches the actual egress used to reach the peer to avoid asymmetric routing problems.
Key Takeaway

Configure the tunnel like a physical P2P link, and tune MTU/MSS early to avoid later performance issues.
