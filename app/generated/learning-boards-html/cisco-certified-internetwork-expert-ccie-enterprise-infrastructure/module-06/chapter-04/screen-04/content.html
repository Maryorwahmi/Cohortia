Core Concept › Why GRE is needed

The problem GRE solves

IPsec selects traffic by ACLs and generally supports unicast. It does not transport multicast or broadcast essential for routing protocols. GRE encapsulates those packets inside an IP header so they can traverse an IP-only path.

Concrete example
Two routers form OSPF adjacency using GRE tunnel addresses on a /30; OSPF's multicast hellos are encapsulated and then encrypted by IPsec.
Common misconception
Assuming IPsec alone will carry multicast is incorrect; GRE provides the multicast-capable virtual link.
Key Takeaway

Use GRE when you need multicast or non-IP protocols across a secure VPN; apply IPsec to secure the GRE payload.

Analogy

Think of GRE as an envelope that can hold many types of letters, including multicast letters; IPsec is the lock on the envelope that keeps it safe during transit.

Supporting bullets
  • • GRE creates a point-to-point tunnel interface that looks like a physical link to routing protocols.
  • • GRE encapsulates packet payloads so they can traverse an IP path unchanged.
  • • IPsec can then encrypt the entire GRE packet to provide confidentiality and integrity.
