Key Concepts › What to Remember
Generic Routing Encapsulation
Encapsulates multicast, broadcast, and non-IP protocols inside IP so they can traverse IP networks.
GRE over IPsec
GRE provides routable overlay; IPsec encrypts the GRE packets to form a secure overlay network.
Tunnel Interface
Logical interface representing the GRE link where routing and MTU tuning are applied.
Summary

Remember the separation of roles: GRE enables routing capability; IPsec provides security. Tune MTU and MSS to keep performance healthy.
