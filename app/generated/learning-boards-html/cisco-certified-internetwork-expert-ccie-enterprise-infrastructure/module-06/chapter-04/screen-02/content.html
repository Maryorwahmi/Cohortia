Learning Objectives

These objectives align with common deployment tasks and troubleshooting steps for GRE over IPsec.

01
Explain why GRE is needed

Describe why IPsec alone cannot carry multicast or non-IP traffic and how GRE enables dynamic routing across VPNs.

VERIFIED COMPETENCY MILESTONE
02
Configure a GRE tunnel

Create tunnel interface, set addresses, tunnel source/destination, and enable tunnel mode gre ip for a point-to-point link.

VERIFIED COMPETENCY MILESTONE
03
Secure GRE with IPsec

Apply IPsec via crypto map or an IPsec profile so all GRE packets are encrypted between endpoints.

VERIFIED COMPETENCY MILESTONE
04
Troubleshoot and tune MTU

Validate reachability, GRE state, routing, IPsec SAs, and adjust ip mtu and ip tcp adjust-mss to avoid fragmentation.

VERIFIED COMPETENCY MILESTONE
