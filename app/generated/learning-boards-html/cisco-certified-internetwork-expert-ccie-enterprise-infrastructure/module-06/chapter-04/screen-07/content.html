Process Flow › Configure GRE then IPsec
  1. Verify IP reachability between public IPs with ping and traceroute.
  2. Configure tunnel interface with /30, tunnel source/destination, and tunnel mode gre ip.
  3. Tune ip mtu and ip tcp adjust-mss on the tunnel to prevent fragmentation.
  4. Secure the GRE tunnel with an ipsec profile or crypto map and appropriate transform-set.
  5. Enable OSPF or another routing protocol on the tunnel and advertise internal networks.
  6. Verify show interface tunnel, show ip ospf neighbor, show crypto ipsec sa.
Example verification commands
• show interface tunnel 0 — check tunnel state and MTU.
• show ip ospf neighbor — confirm adjacency over the tunnel.
• show crypto ipsec sa — validate SAs are established and packets are encrypted.
Key Takeaway

Follow the sequence to avoid chasing symptoms: reachability, tunnel, security, routing, verify, tune.
