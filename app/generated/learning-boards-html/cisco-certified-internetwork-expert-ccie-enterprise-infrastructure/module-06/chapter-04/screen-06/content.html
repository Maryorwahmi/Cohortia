Comparison › Crypto Map vs IPsec Profile
Crypto Map (traditional)
Applied to the physical interface. Requires an interesting-traffic ACL that matches GRE endpoint addresses. Works with older IKE versions and legacy deployments.
  • • Define transform-set and crypto map.
  • • Apply crypto map to physical outbound interface.
  • • ACL must permit traffic between tunnel source and destination.
IPsec Profile (recommended)
Apply the crypto ipsec profile to the tunnel interface, link it to an IKEv2 profile and transform-set. Cleaner mapping between logical tunnel and security.
  • • Create crypto ipsec profile referencing transform-set and IKEv2 profile.
  • • Apply the profile on the tunnel interface.
  • • Avoid ACL trickiness; ties security to the logical interface.
Practical note

If you use IKEv2, prefer an ipsec profile on the tunnel for cleaner configuration and easier troubleshooting. If constrained by legacy gear, use crypto maps and ensure ACLs match tunnel endpoints.
