Module 6 › Chapter 6.4 › Skills and Verification

Practical Tasks

  • • Create tunnel interface and assign /30 tunnel IPs for a point-to-point link.
  • • Set tunnel source and destination to the routers' reachable public IP addresses.
  • • Apply crypto ipsec profile directly to tunnel or use crypto map on the physical interface.
  • • Enable OSPF on the tunnel and advertise local networks.
VERIFIED COMPETENCY MILESTONE

Checks & Misconceptions

• Check physical reachability first. No IP connectivity means GRE cannot form.
• If OSPF adjacency fails, confirm multicast traffic is encapsulated by GRE and permitted by IPsec ACLs.
• Remember to tune ip mtu and ip tcp adjust-mss to avoid fragmentation after encapsulation and encryption.
