Key Concepts: Part 1

Essential terms and definitions from this chapter.

Remote Access VPN

A VPN type that connects individual remote users to a corporate network.

Cisco AnyConnect

A unified security agent providing VPN, web security, and other endpoint security features.

SSL VPN (TLS VPN)

A VPN type that uses the SSL/TLS protocol over TCP port 443, making it firewall-friendly.

Summary Takeaway

Remote Access VPNs, powered by Cisco AnyConnect and often utilizing SSL/TLS, are fundamental for providing secure and flexible connectivity to individual remote users.
