Configuring SSL Trustpoint and Gateway

Essential steps for server identity and external access.

Configuration Snippets

! Assume a valid identity certificate (e.g., from a CA) is installed as 'MY_ROUTER_CERT'
! crypto pki trustpoint MY_TRUSTPOINT
!  enrollment terminal
!  revocation-check crl
!  exit
! crypto pki enroll MY_TRUSTPOINT

! Define IP Address Pool for VPN Clients
ip local pool VPN_POOL 172.16.100.1-172.16.100.254

! Enable WebVPN and define Gateway
webvpn gateway MY_WEBVPN_GATEWAY
 hostname router.cohortia.com
 ip address 198.51.100.1 port 443
 ssl trustpoint MY_TRUSTPOINT
 inservice
  • The `ssl trustpoint` command links the gateway to the router's identity certificate.
  • `hostname` in the gateway must match the certificate's Common Name (CN).
Key Takeaway

Properly configuring the SSL trustpoint and webvpn gateway ensures secure server identity and establishes the public entry point for AnyConnect clients.
