IPsec›What IPsec Provides
Security services
  • Confidentiality: payload encryption so only authorized peers read the data.
  • Integrity: hashing ensures packets were not altered in transit.
  • Authenticity: verifies the identity of the sending peer before accepting traffic.
  • Anti-replay: sequence numbers and windows discard replayed packets.
Protocol roles
AH
Integrity, authentication, optional anti-replay; no encryption.
ESP
Encryption for confidentiality plus integrity and authentication features; most common for VPNs.
Common misconception

ESP alone usually satisfies confidentiality and integrity needs; AH is rarely used for modern VPNs because it lacks encryption.

Why Layer 3 matters
IPsec protects IP traffic regardless of applications, making it broad but also requiring layered controls.
Key Takeaway
Map each security requirement to AH or ESP and use ESP for encrypted VPN traffic.
