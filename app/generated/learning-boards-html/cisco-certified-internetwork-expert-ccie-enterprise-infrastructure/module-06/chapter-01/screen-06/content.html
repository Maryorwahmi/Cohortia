Core Concept›AH vs ESP & Modes
Protocol comparison
AH
Integrity, authentication, optional anti-replay; no encryption.
ESP
Encryption plus integrity and authentication; most widely used for VPNs.
Modes
Transport mode
Protects only the payload; used for host-to-host encryption.
Tunnel mode
Encapsulates the full original packet with a new header; used for site-to-site VPNs.
Concrete example
A VPN between two sites uses ESP in tunnel mode so internal IP addresses remain private and the entire packet is encrypted across the internet.
Common mistake

Choosing transport mode for a site-to-site deployment will fail to protect the original IP header and may expose internal addressing.

Key Takeaway
ESP + Tunnel mode = standard site-to-site VPN setup for confidentiality and header protection.
