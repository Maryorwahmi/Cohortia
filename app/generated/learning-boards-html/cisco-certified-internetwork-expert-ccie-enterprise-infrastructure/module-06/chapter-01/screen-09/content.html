Phase 2 responsibilities
Negotiate IPsec SAs: choose ESP or AH, set encryption and hash for the data channel, set SA lifetime, and define proxy identities for interesting traffic.
Perfect Forward Secrecy
PFS forces a new Diffie-Hellman exchange to create unique keys for each SA so compromising one key does not affect others.
Practical note

Enable PFS when you require strong forward secrecy; ensure both peers are configured with the same DH group to avoid negotiation failures.

Example SA
ESP: AES-256, SHA-256-HMAC, tunnel mode, PFS group 14, lifetime 3600s; ACLs define the protected source/destination subnets.
Check your understanding
If an SA fails to form for expected traffic, verify proxy identities and whether PFS settings match on both peers.
