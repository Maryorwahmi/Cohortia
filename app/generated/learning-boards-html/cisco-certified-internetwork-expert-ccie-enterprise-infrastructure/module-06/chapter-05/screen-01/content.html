Dynamic Multipoint VPN

A practical pattern for connecting many branch sites to a hub with secure, on-demand spoke-to-spoke tunnels.

In this lesson
How mGRE, NHRP, and IPsec work together to deliver scalable VPNs and how phases change routing behavior.
Practical demo
Step-by-step hub and spoke configuration using IKEv2/IPsec and EIGRP over the DMVPN tunnel network.
What you'll practice
NHRP registration checks, verifying IPsec SAs, and validating dynamic spoke-to-spoke tunnels with pings.
Explore Key Topics
mGRE
Single logical tunnel that terminates multiple spokes; avoids many point-to-point tunnels.
NHRP
Maps tunnel IPs to public IPs so spokes can form direct shortcuts on demand.
IPsec
Use a reusable IPsec profile with IKEv2 and an ESP transform to secure GRE traffic across the internet.
Architecture snapshot
Hub (NHRP Server)
Single mGRE interface, NHRP mappings, IPsec profile applied.
Spokes (NHRP Clients)
Register tunnel IPs and learn other spokes' public IPs via the hub.
Routing
EIGRP or OSPF run over the tunnel; multicast mapping is important for OSPF on NBMA clouds.
