NHRP essentials
ip nhrp network-id, ip nhrp nhs, and ip nhrp map commands must be correct for registration and resolution.
IPsec checks
Use show crypto ikev2 sa and show crypto ipsec sa; expect ephemeral SAs after spoke-to-spoke pings.
MTU & MSS
Set ip mtu 1400 and ip tcp adjust-mss 1360 on tunnel interfaces to avoid fragmentation with GRE+IPsec.
Final tip

When troubleshooting, follow the logical order: IP reachability, NHRP registration, IPsec SAs, then routing. This finds root causes faster than random changes.
