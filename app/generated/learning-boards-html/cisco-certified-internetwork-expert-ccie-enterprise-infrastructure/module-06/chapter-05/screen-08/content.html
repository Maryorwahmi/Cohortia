Phase 1
Hub-and-spoke only
All traffic, including spoke-to-spoke, traverses the hub. No shortcuts are formed. Simple to configure but not optimal for spoke-to-spoke bandwidth.
Phase 2
Dynamic shortcuts
Spokes can build direct tunnels after NHRP resolution. Routing remains hub-centric unless additional steps are taken to advertise routes differently.
Phase 3
Optimal spoke-to-spoke routing
Uses NHRP Redirect and Shortcut so spokes can learn routes directly and avoid hub involvement for routing decisions. Best for large-scale deployments with careful route planning.
Design note

Phase choice affects not just tunnel creation but also how routing protocols converge. Use Phase 3 for scale and performance, but ensure the hub performs appropriate summarization or route manipulation to avoid loops.
