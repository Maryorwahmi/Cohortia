Process Flow

NHRP registration and resolution

1. Spoke registers
Spoke sends its tunnel IP and public IP to the hub (NHS) with ip nhrp nhs configured.
2. Query for destination
When a spoke needs another spoke, it queries the NHS for the other spoke's public IP.
3. Direct tunnel formed
Spoke builds a GRE-over-IPsec tunnel to the returned public IP and traffic flows directly.
Example

R2 registers 172.16.0.2 → 203.0.113.2 with R1. When R2 pings 172.16.0.3, R1 replies with 203.0.113.3 so R2 can build a direct tunnel to R3.

Verification
  • show ip nhrp on hub — lists registered spokes
  • show ip nhrp on spoke — shows NHS and mappings
Misconception check

NHRP does not advertise routing prefixes; it only maps tunnel addresses to public addresses. Routing remains the job of EIGRP or OSPF.
