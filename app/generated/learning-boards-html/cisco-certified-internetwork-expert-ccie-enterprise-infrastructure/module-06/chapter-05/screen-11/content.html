NHRP Redirect & Shortcut

Hub can inform spokes of better next-hops and enable spokes to learn routes directly, preventing hub hairpinning after the first packet.

Design caution

Ensure the hub's route advertisements are arranged so redirects don't create routing loops; summarization and route selection matter.

When to use

Use Phase 3 for large-scale DMVPNs where spoke-to-spoke communications are frequent and hub load must be minimized.

Misconception check

Phase 3 is not automatically safe for all routing designs; validate route advertisements and summarization plans in the lab to avoid loops.
