Hub configuration snippet

interface Tunnel0
 ip address 172.16.0.1 255.255.255.0
 ip mtu 1400
 ip tcp adjust-mss 1360
 no ip redirects
 ip nhrp network-id 100
 ip nhrp map multicast dynamic
 tunnel source GigabitEthernet0/1
 tunnel mode gre multipoint
 crypto ipsec profile COHORTIA_IPSEC_PROFILE

router eigrp 1
 network 172.16.0.0 0.0.0.255
 network 192.168.1.0 0.0.0.255
 no auto-summary
This snippet ties MTU settings, NHRP server attributes, the mGRE interface, and an IPsec profile together, then advertises the DMVPN tunnel network into EIGRP.
Explanation
  • ip nhrp network-id 100 — shared cloud identifier
  • ip nhrp map multicast dynamic — support multicast routing
  • crypto ipsec profile — secures all spoke connections
Verify
Use show ip nhrp, show crypto ikev2 sa, show crypto ipsec sa, and show ip eigrp neighbors to validate operation.
