Spoke configuration snippet

interface Tunnel0
 ip address 172.16.0.2 255.255.255.0
 ip mtu 1400
 ip tcp adjust-mss 1360
 no ip redirects
 ip nhrp network-id 100
 ip nhrp nhs 172.16.0.1
 ip nhrp map 172.16.0.1 198.51.100.1
 ip nhrp map multicast 198.51.100.1
 tunnel source GigabitEthernet0/1
 tunnel destination 198.51.100.1
 tunnel mode gre multipoint
 crypto ipsec profile COHORTIA_IPSEC_PROFILE

router eigrp 1
 network 172.16.0.0 0.0.0.255
 network 10.0.0.0 0.0.0.255
 no auto-summary
This spoke snippet registers its tunnel address with the hub and maps the hub's tunnel IP to the hub's public IP so initial registration and multicast mapping succeed.
Troubleshooting steps
  1. Confirm public IP connectivity to hub.
  2. Check show ip nhrp for registrations.
  3. Verify show crypto ikev2 sa and show crypto ipsec sa.
  4. Validate routing adjacencies (show ip eigrp neighbors).
Common fixes
  • Correct ip nhrp network-id mismatches.
  • Open UDP 500/4500 on firewalls if NAT-T is present.
  • Adjust MTU/MSS to avoid fragmentation for GRE over IPsec.
