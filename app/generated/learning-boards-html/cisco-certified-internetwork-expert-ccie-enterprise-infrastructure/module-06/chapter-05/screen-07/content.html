IPsec profile fundamentals

Use a crypto ipsec profile referencing an IKEv2 profile so the tunnel interface can accept IPsec SAs from any spoke without per-peer crypto maps.

Operational checklist
  • Define IKEv2 profile and transform-set first.
  • Create an ipsec profile that points to the IKEv2 profile.
  • Apply crypto ipsec profile COHORTIA_IPSEC_PROFILE to Tunnel0.
Verification commands
show crypto ikev2 sa — IKEv2 control plane state
show crypto ipsec sa — ESP data-plane SAs
NAT and ports

Ensure UDP 500 and UDP 4500 are allowed when NAT traversal is required; otherwise peer negotiation may fail.
