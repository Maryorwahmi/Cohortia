Definition

Multipoint GRE interface

A logical tunnel interface configured to accept GRE traffic from many peers instead of a single destination.

Practical settings
  • tunnel mode gre multipoint
  • ip mtu 1400 and ip tcp adjust-mss 1360 to avoid fragmentation
  • apply a crypto ipsec profile to the tunnel interface
Operator tip

Ensure the hub's physical interface and CPU can handle aggregated encapsulation and IPsec processing when many spokes are active.

mGRE behavior visualized
Think of the mGRE interface as a virtual LAN where every spoke has a tunnel IP. The hub accepts packets from any spoke and forwards logically based on routing or NHRP resolution.
Common mistake

Forgetting MTU adjustments for GRE over IPsec leads to intermittent application problems. Always set ip mtu and adjust MSS on the tunnel interface.
