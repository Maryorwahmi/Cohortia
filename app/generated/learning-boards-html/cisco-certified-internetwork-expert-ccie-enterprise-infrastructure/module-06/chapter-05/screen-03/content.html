Hands-on Lab Checklist

Scenario summary
  • R1 Hub public 198.51.100.1, tunnel 172.16.0.1
  • R2 Spoke1 public 203.0.113.2, tunnel 172.16.0.2
  • R3 Spoke2 public 203.0.113.3, tunnel 172.16.0.3
  • Use COHORTIA_IPSEC_PROFILE and IKEv2 profile from prior chapters
Verification commands
show ip nhrp — confirm registrations
show crypto ikev2 sa / show crypto ipsec sa — confirm SAs
show ip eigrp neighbors or show ip ospf neighbor — confirm routing
Common checklist errors
  • Mismatched ip nhrp network-id between hub and spokes.
  • Missing ip nhrp nhs on spokes so they don't register.
  • Firewall rules blocking UDP 500 or UDP 4500 when NAT-T is used.
  • MTU/MSS not adjusted for GRE over IPsec causing fragmentation.
