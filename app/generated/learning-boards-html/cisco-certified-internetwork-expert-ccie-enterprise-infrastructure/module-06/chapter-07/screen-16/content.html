Quick Reference
Three operational checks to run during deployment.
Check certificates
Validate CN matches gateway hostname and browser trust chains before blaming portal logic.
Verify backend reachability
Confirm DNS and routing from the headend to internal servers for each published resource.
Match model to use case
Use WebVPN for browser-only workflows; use AnyConnect for full network protocol needs.
One-line checklist

Certificate OK → Authentication OK → Portal loads → Click published resource → show webvpn session all.
