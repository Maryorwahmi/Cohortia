Lab Skills and Verification
Concrete tasks you will perform and how to confirm success.
Practice tasks: create user, configure gateway and context, publish resources, validate with browser, and use show/debug commands.
Verification Steps
  1. Create local user and password on R1 and confirm with show running-config | include username.
  2. Bind the trustpoint to a webvpn gateway and ensure the CN matches the URL users will visit.
  3. Enable webvpn on the outside interface and test portal access from a remote browser to the public IP.
  4. Click a URL-list item and confirm the internal server responds via the VPN device proxy.
Commands to Know
show webvpn session all
debug webvpn
debug aaa authentication
Pro Tip
When the portal loads but published applications fail, verify DNS and routing from the VPN headend to each internal host before suspecting the portal configuration.
