Troubleshooting Steps
  1. Validate gateway certificate CN and browser trust.
  2. Verify authentication backend and credentials; check debug aaa authentication.
  3. Confirm the portal loads; ensure webvpn is applied to the interface.
  4. Check resource reachability from the router and the correctness of URL or file paths.
Useful Commands
show webvpn session all
debug webvpn
debug aaa authentication
show running-config | section webvpn
These commands let you inspect session state, monitor portal activity in real time, and confirm the portal configuration is present in running-config.
