  functions url-list-enabled
  functions file-access-enabled
  url-list MY_INTERNAL_WEB_APPS
  file-access-list MY_FILE_ACCESS

  exit

file-access-list MY_FILE_ACCESS

Verification & Tests
  1. From a remote browser, go to https://198.51.100.1 and log in as webuser. Click Internal Wiki.
  2. On the router run show webvpn session all to confirm session and proxy mappings.
  3. If you see Page Not Found, run ping and traceroute from the router to the internal host and verify DNS resolution.
Key Takeaway

Testing both portal login and backend connectivity ensures that both TLS and resource reachability are validated for successful WebVPN access.
