Example CLI
webvpn context MY_WEBVPN_CONTEXT
 gateway MY_WEBVPN_GATEWAY
 ssl authenticate verify all
 policy group MY_WEB_POLICY
  functions url-list-enabled
  functions file-access-enabled
  functions application-access-enabled
  url-list MY_INTERNAL_WEB_APPS
  file-access-list MY_FILE_ACCESS
  application-access-list MY_APP_ACCESS
  authentication local
  exit
 default-group-policy MY_WEB_POLICY
 inservice
Ensure the lists referenced here are defined elsewhere in configuration as shown in later screens.
Publish and Test
After authentication using the chosen method, users will see the portal links defined by the url-list and file-access-list. Test each link to confirm the device proxies correctly to internal servers.
Common Mistake

If lists are not referenced in the policy group, users will authenticate but see no resources. Verify those references exist under the policy block.
