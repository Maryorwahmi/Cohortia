Learning Objectives
Practical skills you will verify during the lab.
Bloom: Learn → Understand → Apply → Master
01
Explain TLS principles
Describe the handshake, public key authentication, and symmetric session keys so you can reason about certificate and handshake failures. Example: recognizing a CN mismatch causes browser warnings that block portal trust.
VERIFIED COMPETENCY MILESTONE
02
Differentiate client models
Contrast AnyConnect-style client-based VPNs that provide full tunnel network access with clientless WebVPN portals that give browser-based resource access. Example: decide when contractors only need portal links vs when staff need Layer 3 tunneling.
VERIFIED COMPETENCY MILESTONE
03
Build a WebVPN portal
Configure webvpn gateway, assign an SSL trustpoint, create a webvpn context, and publish URL and file-access lists. Example: publish an internal wiki link and test access from a remote browser.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot WebVPN access
Diagnose certificate validation, authentication sources, portal loading, and application access. Example: use debug webvpn and show webvpn session all to confirm active sessions and proxy reachability.
VERIFIED COMPETENCY MILESTONE
