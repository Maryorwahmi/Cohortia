Architecture Map
webvpn gateway
Public hostname/IP and SSL trustpoint binding; listens on port 443.
SSL trustpoint
Identity certificate for the gateway used by client browsers to validate the portal.
webvpn context
Portal content, authentication and resource lists.
policy group
Enables URL lists, file access, application access; assigned as default-group-policy.
Concrete configuration idea
Define the gateway with hostname and trustpoint, create a webvpn context that references the gateway, enable functions in a policy group, and apply the webvpn command to the external interface so the gateway is reachable from the Internet.
Common Mistake

Not applying 'webvpn' to the external interface leaves the gateway non-operational even if the gateway and trustpoint exist in configuration.
