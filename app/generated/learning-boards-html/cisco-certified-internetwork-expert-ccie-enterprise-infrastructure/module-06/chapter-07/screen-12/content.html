Authentication Options
  • Local — simple, useful for lab or small groups.
  • RADIUS/TACACS+ — scalable centralized authentication for production.
Example
Inside webvpn context set authentication local or reference AAA servers for RADIUS. Use test accounts to validate policy group behavior before wide rollout.
Trustpoint and Certificate
Bind the trustpoint to the gateway. Ensure the certificate CN equals the URL user will open. Use CA-signed certs in production to avoid browser trust steps.
Common Problem

Certificate CN mismatch produces browser warnings that block portal login. Verify CN and gateway hostname carefully.
