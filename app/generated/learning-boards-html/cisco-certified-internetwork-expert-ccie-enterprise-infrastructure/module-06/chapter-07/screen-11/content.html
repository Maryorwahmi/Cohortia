Application Access Example
application-access-list MY_APP_ACCESS
 application-access-list-item "RDP to Dev Server" host 192.168.1.50 protocol tcp port 3389
 application-access-list-item "SSH to Router" host 192.168.1.1 protocol tcp port 22
Port forwarding proxies specific ports through the headend. Be mindful of browser plugin requirements for seamless operation.
File Access Example
file-access-list MY_FILE_ACCESS
 file-access-list-item "Public Docs" "//fileserver.cohortia.local/public"
Validate SMB/CIFS connectivity from the router to the fileserver and correct share syntax to ensure users can browse and download content.
Browser compatibility note

Modern browsers deprecate Java/ActiveX; expect reduced support for automatic port-forwarding helpers. Where possible prefer URL and file lists or instruct users on manual connection methods for non-web protocols.
