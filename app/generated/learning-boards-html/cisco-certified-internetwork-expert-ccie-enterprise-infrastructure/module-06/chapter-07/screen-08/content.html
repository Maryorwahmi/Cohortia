Example CLI
webvpn gateway MY_WEBVPN_GATEWAY
 hostname webvpn.cohortia.com
 ip address 198.51.100.1 port 443
 ssl trustpoint MY_TRUSTPOINT
 inservice

interface GigabitEthernet0/1
 ip address 198.51.100.1 255.255.255.0
 webvpn
Keep the hostname used by clients consistent with the certificate CN. If they use the IP directly, the CN must match the IP or clients will receive warnings.
Verification
  • From a remote browser, navigate to the gateway URL and confirm certificate CN and trust chain.
  • Use show running-config | section webvpn to confirm gateway and trustpoint are present and inservice.
Lab note
If using a self-signed trustpoint 'MY_TRUSTPOINT' for lab work, ensure the client trusts the certificate or be prepared to accept the browser warning during testing.
