Keyring: peer authentication storage
Store a pre-shared key per peer address so authentication is deterministic during IKEv2 negotiation.
Why explicit peer addresses matter
The router selects the key that matches the peer's address. Use exact addresses to avoid ambiguous matches and failed auth.
IKEv2 profile role
The profile links policy and keyring, and sets local/remote identity for the IKE exchange so the correct proposal is used.
Concrete configuration snippet
crypto ikev2 keyring MY_IKEV2_KEYRING
 peer BRANCH_ROUTER_PEER
  address 203.0.113.2
  pre-shared-key CohortiaVPN!23

crypto ikev2 profile MY_IKEV2_PROFILE
 match identity remote address 203.0.113.2 255.255.255.255
 authentication local pre-share
 authentication remote pre-share
 keyring local MY_IKEV2_KEYRING
Misconfiguration
Using a different pre-shared key on the remote peer will prevent Phase 1 authentication and stop the tunnel from forming.
