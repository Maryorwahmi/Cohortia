Module 6 › Chapter 6.2 › IPsec Phase 2
Transform-set: what it controls
Choose ESP, encryption and integrity algorithms, and set tunnel mode for site-to-site encapsulation.
When to enable PFS
Enable PFS if policy requires that Phase 2 keys are derived independently using a DH exchange to protect past and future sessions.
Operational impact
PFS adds CPU for DH in Phase 2. Balance security needs against device capacity and choose appropriate DH groups.
Concrete configuration
crypto ipsec transform-set MY_TRANSFORM_SET esp-aes 256 esp-sha256-hmac
 mode tunnel

crypto ipsec profile MY_IPSEC_PROFILE
 set transform-set MY_TRANSFORM_SET
 set ikev2-profile MY_IKEV2_PROFILE
 set pfs group 14
Key Takeaway
Link transform-set to an ipsec profile and enable PFS for stronger session key isolation when policy demands it.
