Troubleshooting checklist
  1. Confirm Phase 1: show crypto ikev2 sa; if not READY, debug crypto ikev2.
  2. Confirm Phase 2: show crypto ipsec sa; if absent, check ACLs and transform-sets.
  3. Check keyring peer addresses and pre-shared keys for exact matches.
  4. If NAT exists, verify external IP visibility and enable NAT-T as needed.
Common pitfalls
Wrong ACL orientation, mismatched DH group, different pre-shared key text, or unhandled NAT that changes peer IPs.
NAT considerations
If NAT occurs before encryption, peer addresses seen by routers will differ from configured keyring addresses. Use NAT-T to encapsulate IPsec in UDP for compatibility with NAT devices.
Tip
When troubleshooting NAT issues, capture packets at the edge to verify which IPs are visible and adjust keyring or enable NAT-T accordingly.
