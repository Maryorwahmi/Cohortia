Module 6 › Chapter 6.2 › Interesting Traffic
Create and mirror the ACL that triggers Phase 2
The ACL needs to match the traffic you want to protect; use extended ACLs that explicitly permit local-to-remote IP subnets.
Orientation matters
On each router, the ACL must use the router's local network as the source and the remote network as the destination.
Troubleshooting hint
If IKEv2 is READY but no IPsec SAs exist, review the ACLs first before diving into deeper debug outputs.
Example ACLs
ip access-list extended VPN_TRAFFIC
 permit ip 192.168.1.0 0.0.0.255 10.0.0.0 0.0.0.255

! On the branch
ip access-list extended VPN_TRAFFIC
 permit ip 10.0.0.0 0.0.0.255 192.168.1.0 0.0.0.255
Common mistake
Using wildcard or reversed networks in the ACL so intended traffic never matches and Phase 2 never begins.
