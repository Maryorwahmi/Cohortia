Module 6 › Chapter 6.2 › Apply IPsec
Profile-based (recommended for IKEv2)
Apply crypto ipsec profile to the outbound interface; the profile references transform-set and IKEv2 profile objects.
Pros: cleaner object binding, easier to manage PFS and IKEv2 integration.
Cons: older devices may not support profile objects.
Crypto map-based (legacy)
Tie peer, ACL, and transform-set in a crypto map entry and apply the map to the interface.
Pros: widely supported and explicit behavior.
Cons: more verbose and less modular than profiles.
Example (apply profile)
interface GigabitEthernet0/1
crypto ipsec profile MY_IPSEC_PROFILE
Example (crypto map)
crypto map VPNMAP 10 ipsec-isakmp
set peer 203.0.113.2
match address VPN_TRAFFIC
Key Takeaway
Apply the chosen method to the interface that sends traffic toward the untrusted network so encryption can occur.
