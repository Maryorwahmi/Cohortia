Module 6 › Chapter 6.3 › Routing & Policies

Routing checks

  • Confirm routes for remote networks exist and point to the tunnel.
  • Verify dynamic routing sessions across the tunnel or static routes are correct.
  • Check return path reachability so replies traverse the tunnel back to the origin.

Policy and ACL checks

  • Validate interesting traffic ACLs precisely match source/destination networks intended for encryption.
  • Ensure firewalls allow UDP 500, UDP 4500, and ESP protocol 50 where required.
  • Confirm policy evaluation order relative to the crypto engine for inbound/outbound directions.
Diagnostic step

Use debug ip packet detail to see if packets reach the crypto engine. Compare packet counters in show crypto ipsec sa detail to confirm encryption/decryption counts.

Key Takeaway

Tunnel presence is necessary but not sufficient — routes and security policies must be aligned so traffic actually traverses the crypto engine.
