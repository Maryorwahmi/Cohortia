Module 6 › Chapter 6.3 › Show & Debug Commands

Useful show commands

show crypto ikev2 sa detail
show crypto ipsec sa detail
show crypto isakmp sa

Look for UDP 4500 entries, DPD probes, SA lifetimes, and packet counters to confirm encapsulation and activity.

Targeted debug workflow

debug crypto ikev2 condition peer 203.0.113.2
debug crypto ipsec
debug crypto engine
debug ip packet detail

Use condition peer to limit output to the peer's negotiation and avoid overwhelming logs during incident analysis.

Concrete example

If you see messages about UDP 4500 being unreachable, verify NAT devices and ACLs. If authentication fails, recheck pre‑shared keys or certificate trust chains.

Key Takeaway

Use a show-first, debug-second approach. Prefer conditional debugs to focus on the peer and capture output to logs for post‑incident analysis.
