Module 6 › Chapter 6.3 › Perfect Forward Secrecy

What is PFS?

A cryptographic practice that forces each Phase 2 SA to use a fresh DH exchange so keys are independent across sessions.

• Prevents a single compromised key from decrypting other SAs negotiated under the same Phase 1 material.
• Configured per IPsec profile with set pfs group <group>; both peers must match the group.
• Choose higher groups for stronger security (balance with CPU impact).
Example

Use set pfs group 14 in the crypto ipsec profile to require group 14 for Phase 2 exchanges.

Key Takeaway

PFS is a small runtime cost for a major security improvement: it isolates the impact of any single key compromise.

Configuration snippet

crypto ipsec profile COHORTIA_IPSEC_PROFILE
 set pfs group 14
Misconception

PFS does not change how routing or ACLs behave; it only changes key derivation for Phase 2 SAs.

Why enable PFS

In high‑security deployments, PFS should be enabled to minimize the blast radius of key exposure.
