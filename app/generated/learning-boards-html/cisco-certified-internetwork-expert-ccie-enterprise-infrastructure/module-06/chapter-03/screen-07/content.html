Module 6 › Chapter 6.3 › NAT‑T

Why NAT breaks IPsec

IPsec integrity checks include parts of the IP header. When NAT modifies those headers, ESP integrity fails unless the packet is encapsulated.

• NAT‑T wraps IKE and ESP inside UDP, typically using port 4500.
• The NAT device changes only the outer UDP/IP header, leaving the inner ESP packet untouched.
• If UDP 4500 is blocked, the tunnel cannot traverse the NAT and will fail to establish.
Operational check

Look for UDP 4500 in show crypto ikev2 sa detail and show crypto ipsec sa to confirm NAT‑T is in use.

Common troubleshooting items

  • ACLs or firewall rules blocking UDP 4500 or UDP 500.
  • Incorrect peer address when a NAT device changes the public IP—update keyrings and profiles.
  • Expect to see NAT‑T entries in show output; their absence indicates NAT traversal failed.
Key Takeaway

Allow UDP 4500 and update peer identities when NAT changes the visible public IP. NAT‑T preserves IPsec across translation.
