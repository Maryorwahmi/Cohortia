Module 6 › Chapter 6.3 › Key Concepts
Dead Peer Detection (DPD)
Probes tear down SAs for non‑responsive peers to prevent traffic black holes.
Perfect Forward Secrecy (PFS)
Fresh DH for each Phase 2 SA prevents widespread compromise from a single key leak.
NAT Traversal (NAT‑T)
Encapsulates IPsec in UDP 4500 so NAT devices can translate outer headers safely.
Summary

Enable DPD and PFS, allow UDP 4500 for NAT‑T, and use targeted show and debug commands to maintain secure and resilient IPsec tunnels.
