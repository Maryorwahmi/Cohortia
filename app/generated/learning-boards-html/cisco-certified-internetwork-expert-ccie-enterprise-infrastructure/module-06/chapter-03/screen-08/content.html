R3 NAT configuration (example)

interface GigabitEthernet0/1
 ip address 10.0.0.1 255.255.255.0
 ip nat inside
interface GigabitEthernet0/2
 ip address 203.0.113.2 255.255.255.0
 ip nat outside
ip nat inside source list 1 interface GigabitEthernet0/2 overload
access-list 1 permit ip 10.0.0.0 0.0.0.255 any
This PAT example overloads R3's outside interface and allows R2 to appear from R3's 203.0.113.2 address to R1.

Update R1 peer address

crypto ikev2 keyring COHORTIA_KEYRING
 peer R2_BRANCH
  address 203.0.113.2
  pre-shared-key CohortiaVPN!23

crypto ikev2 profile COHORTIA_IKEV2_PROFILE
 match identity remote address 203.0.113.2 255.255.255.255
After updating the keyring and profile, initiate traffic and verify UDP 4500 presence in show outputs.
Key Takeaway

When a peer is behind NAT, the visible public IP becomes the NAT device. Update peer configs and allow UDP 4500 so NAT‑T can function.
