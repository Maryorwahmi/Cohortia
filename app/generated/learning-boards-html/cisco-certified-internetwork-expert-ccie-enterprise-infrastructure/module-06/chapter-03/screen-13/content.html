Module 6 › Chapter 6.3 › Troubleshooting Checklist

Repeatable diagnostic flow

1. Check status

show crypto ikev2 sa detail; show crypto ipsec sa detail

2. Auth & params

Verify pre‑shared keys, certs, proposals, and PFS groups

3. NAT checks

Confirm UDP 4500 and NAT device mappings; update peer address if needed

4. Routing & ACLs

Ensure routes and interesting‑traffic ACLs are correct for both directions

5. Targeted debugs

Use debug crypto ikev2 condition peer and debug crypto ipsec for focused output

6. Capture & analyze

Save debug output to logs and compare messages with known failure patterns

Key Takeaway

Work top-down: status → auth/params → NAT → routing/policies → targeted debugs. Capture logs and test failover in controlled windows.
