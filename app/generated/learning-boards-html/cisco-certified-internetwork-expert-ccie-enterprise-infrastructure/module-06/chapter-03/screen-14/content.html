Module 6 › Chapter 6.3 › Lab: Verify DPD / PFS / NAT‑T

Task sequence

  1. Enable DPD and PFS on both peers (apply to profiles).
  2. Insert NAT router and configure PAT for the branch IP.
  3. Update remote peer address in keyring/profile to NAT outside IP.
  4. Initiate traffic and verify with show commands for DPD probes and UDP 4500.
  5. If failure occurs, run conditional debugs and capture the key failure line.

Verification & challenge

Verification commands:
show crypto ikev2 sa detail
show crypto ipsec sa detail
debug crypto ikev2 condition peer 203.0.113.2
debug crypto ipsec
Challenge: find the debug line that shows a DPD probe timeout or that UDP 4500 is being blocked. Correct the ACL or update the peer entry, reinitiate traffic, and confirm the show output now includes UDP 4500 and DPD probes.
Key Takeaway

The lab converts configuration into observable behavior. Use show commands first, then targeted debugs to find the exact failure line and verify fixes.
