Module 7 › Chapter 6.8 › R1 Configuration
Code template (R1)
! Assume IKEv2 and IPsec profiles are configured
interface Tunnel10
 ip address 10.255.255.4 255.255.255.252
 ip mtu 1400
 ip tcp adjust-mss 1360
 tunnel source GigabitEthernet0/1 ! R1's public IP 198.51.100.1
 tunnel destination 203.0.113.1
 tunnel mode gre ip
 crypto ipsec profile COHORTIA_IPSEC_PROFILE_R1R3
 ip ospf cost 10

router ospf 1
 network 10.255.255.4 0.0.0.3 area 0
 network 192.168.1.0 0.0.0.255 area 0
Explanation
  • MTU 1400 and MSS 1360 reduce fragmentation when GRE and IPsec add headers.
  • OSPF networks include the tunnel and internal LAN to advertise routes across the VPN.
  • IPsec profile attaches configured crypto parameters and policies to the tunnel.
Lab tip
Verify with show crypto ipsec sa, show ip ospf neighbor, and traceroute to confirm path preference before failing the primary tunnel.
