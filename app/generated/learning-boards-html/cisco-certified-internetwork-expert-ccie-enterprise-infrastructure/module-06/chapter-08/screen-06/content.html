Module 7 › Chapter 6.8 › Redundant VPN Tunnels
Design pattern
  1. Provision two independent IPsec tunnels using different public endpoints or ISPs.
  2. Terminating tunnels on separate routers to avoid a single device failure.
  3. Run OSPF or another dynamic routing protocol over the tunnels.
  4. Adjust costs to prefer the primary tunnel and keep the secondary as backup.
Concrete example

R1<->R3 is Tunnel10 with OSPF cost 10. R2<->R4 is Tunnel20 with OSPF cost 20. OSPF prefers Tunnel10; when it fails, routes switch to Tunnel20 automatically.

Operational checks
Verify OSPF adjacencies, monitor SA lifetimes, and test failover by shutting down a tunnel interface and observing reconvergence.
Pitfall
If you rely only on static routes, failover will not be automatic; dynamic routing is the mechanism that reroutes traffic to the backup path.
