Module 7 › Chapter 6.8 › Lab Walkthrough
Step-by-step
  1. Configure Tunnel10 on R1 and R3; apply crypto profile and set ip ospf cost 10.
  2. Configure Tunnel20 on R2 and R4; apply crypto profile and set ip ospf cost 20.
  3. Verify OSPF adjacencies: show ip ospf neighbor on each router.
  4. Confirm routes: show ip route and traceroute from a host behind the hub to the branch host.
  5. Simulate failure: shutdown R1's public interface or Tunnel10, then observe OSPF reconvergence.
  6. Re-verify traceroute and show crypto ipsec sa to confirm traffic via the backup tunnel.
  7. Bring interface back up and confirm return to primary path.
Common mistake
Not setting different OSPF costs or forgetting DPD/NAT-T makes failover slower or unpredictable.
Pro tip
Measure outage duration by running continuous pings from a host and capturing timestamps during the simulated failure and recovery.
