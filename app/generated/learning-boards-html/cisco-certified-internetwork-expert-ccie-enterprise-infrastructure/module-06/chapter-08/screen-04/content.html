Module 7 › Chapter 6.8 › High Availability (HA) for VPNs
Definition

HA means continuous operation despite failures, achieved via redundancy and synchronization.

Layers of redundancy
  • Physical links and diverse ISPs to avoid shared failures.
  • Device redundancy (HSRP/VRRP) for default gateway continuity.
  • Redundant tunnels between sites or headends for path diversity.
Concrete example
Two hub routers run HSRP; each hub pairs with a different branch tunnel so if one hub fails, OSPF reroutes across the alternate tunnel and HSRP provides a stable gateway.
Misconception
Standby hardware alone is insufficient unless VPN state is synchronized or peers can reconnect quickly.
Analogy & Takeaway

Think of HA as both spare parts and a recovery procedure: you need a backup component and a practiced way to bring traffic onto it with minimal service interruption.

Key Takeaway

Design for state preservation or fast reconnection and validate with tests that simulate realistic failures.

Check your understanding
After you design redundancy, plan a test that measures reconnection time for remote access clients and route convergence time for site-to-site tunnels.
