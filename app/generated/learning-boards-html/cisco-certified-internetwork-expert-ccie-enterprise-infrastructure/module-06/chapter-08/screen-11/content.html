Module 7 › Chapter 6.8 › Troubleshooting Methodology
Stepwise method
  1. Check physical interfaces and link state; confirm HSRP/VRRP and interface tracking.
  2. Isolate control plane: inspect IKE state with show crypto ikev2 sa.
  3. Isolate data plane: inspect IPsec SAs with show crypto ipsec sa and packet counters.
  4. Check routing: verify OSPF adjacency and route table changes after failure.
  5. Verify state synchronization if HA is enabled and review syslog entries for failover events.
Misconception
Assuming the first visible symptom is the root cause; follow the method to find the originating layer.
Commands to know
show crypto ikev2 sa, show crypto ipsec sa, show ip ospf neighbor, show ip route, and targeted debug with filters.
