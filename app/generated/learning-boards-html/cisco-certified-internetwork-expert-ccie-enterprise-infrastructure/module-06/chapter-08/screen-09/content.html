Module 7 › Chapter 6.8 › Site vs Remote Redundancy
Site-to-Site
  • Dual tunnels between sites with different ISPs or devices.
  • Dynamic routing (OSPF) provides automatic reroute on tunnel failure.
  • Focus on path diversity and route convergence time.
Example
Tunnels R1–R3 (cost 10) and R2–R4 (cost 20) prefer Tunnel10 and fail over via OSPF when it fails.
Remote Access
  • Multiple headends behind a load balancer or DNS entries for availability.
  • Centralized AAA and MFA scale authentication and improve security.
  • Focus on session persistence, client retry lists, and licensing for concurrent users.
Pitfall
Treating load balancing as a substitute for routing redundancy can leave you exposed to path failures outside the load balancer’s visibility.
