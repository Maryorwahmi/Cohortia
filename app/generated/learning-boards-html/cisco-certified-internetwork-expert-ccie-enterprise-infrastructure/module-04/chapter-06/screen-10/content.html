Module 4 › Chapter 4.6 › IoT / OT Segmentation
Protecting IoT and OT
Use dedicated VNs and SGACLs to enforce the principle of least privilege for constrained devices.
Segmentation pattern
Create separate VNs for device groups (sensors, controllers) and server endpoints, then allow only required ports between them.
Authentication
Use ISE policies suitable for devices: certificate-based, MAC authentication, or pre-shared onboarding with limited rights.
Operational checks
Regularly review SGACLs and run sensors' communication tests to ensure no unintended access exists.
Concrete example
Configure 'HVAC_Sensors_VN' to only allow communication to 'HVAC_Server_VN' on the port and protocol required for telemetry; deny all other flows.
