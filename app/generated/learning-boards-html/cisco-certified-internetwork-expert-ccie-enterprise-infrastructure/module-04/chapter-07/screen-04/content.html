Core Concept

What Assurance provides

Assurance aggregates telemetry into health scores, client views, path traces, and application experience metrics so you can detect and localize issues faster.

Network Health Dashboard
Overall device, client, and app health with alerts prioritized by impact.
Client 360
Detailed client session view including auth events, SGT, and association history.
Path Trace
End‑to‑end path simulation showing hops, SGTs, and where policy is applied.
Supporting view
Example: Application slowdown
Assurance flags rising latency for a business app. You open Application Experience, see affected clients, then use Path Trace to see whether the path or a SGACL is responsible.
Quick CLI confirmations
Confirm underlay reachability
show ip ospf neighbor
show ip route ospf
ping <RLOC_IP>
traceroute <RLOC_IP>
Confirm LISP mappings
show lisp site <site_name> detail
show lisp eid-table vlan <VLAN_ID> summary
show lisp map-cache <EID>
Key Takeaway

Assurance tells you where to look; CLI confirms what you need to fix.
