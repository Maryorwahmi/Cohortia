Learning Objectives

From monitoring to policy validation — measurable skills for troubleshooting SD‑Access.
Bloom: Learn → Understand → Apply → Master
01
Utilize DNA Center Assurance
Use dashboards and telemetry to detect device, client, and application issues; this helps you catch problems before users call.
VERIFIED COMPETENCY MILESTONE
02
Perform basic troubleshooting
Execute a structured underlay→control→data→policy sequence for common SD‑Access problems to narrow fault domains quickly.
VERIFIED COMPETENCY MILESTONE
03
Interpret core show commands
Read outputs such as `show lisp map-cache` and OSPF neighbor tables to confirm EID registration and underlay reachability.
VERIFIED COMPETENCY MILESTONE
04
Use Client 360 and Path Trace
Drill into a client session and run end‑to‑end traces to find where policy or connectivity fails and confirm policy enforcement decisions.
VERIFIED COMPETENCY MILESTONE
