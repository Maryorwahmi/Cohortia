Module 5 › Chapter 4.7 › Underlay Troubleshooting
Definition

Verify OSPF and IP reachability

Confirm physical links, IGP adjacency, and route visibility so RLOCs can be reached by fabric nodes.

Key CLI commands
show ip ospf neighbor
show ip route ospf
ping <RLOC_IP> size 1500
task: traceroute <RLOC_IP>
Concrete example
MTU diagnosis
If small pings succeed but larger pings fail, measure MTU along the path. VXLAN adds overhead; verify that each underlay hop supports at least 1550 bytes to avoid fragmentation and dropped tunneled traffic.
ping 10.255.255.2 size 1500
if fragmentation: show interface GigabitEthernet1/0/1 | include MTU
Common Mistake

Assuming that a single short ping verifies VXLAN reachability. Always test with an MTU‑sized packet representative of encapsulated traffic.
