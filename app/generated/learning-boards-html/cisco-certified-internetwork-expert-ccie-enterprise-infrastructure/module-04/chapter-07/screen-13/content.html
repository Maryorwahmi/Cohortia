Source: 192.168.1.10 (SGT 10 — Employees) Destination: 192.168.2.20 (SGT 30 — Servers) Policy Applied: "Employees to Servers" Result: DENY (TCP 80, 443)
Diagnose

1) Immediate problem: no LISP map-cache entry for the server. 2) Ultimate reason: Path Trace shows SGACL denied the ports. 3) Next step: check ISE Live Logs for the SGACL and verify FabricEdge2 has registered the server EID.

Recommended troubleshooting actions
  • Confirm server EID registration on the Fabric Control Plane Node and FabricEdge2.
  • Check ISE Live Logs for the client and review the Employees→Servers SGACL.
  • If SGACL is intentional, adjust policy or create an exception after security review; otherwise fix registration or control plane reachability.
