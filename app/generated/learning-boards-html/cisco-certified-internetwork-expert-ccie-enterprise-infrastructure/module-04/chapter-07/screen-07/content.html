Control Plane

EID to RLOC mapping verification

Check registrations on the control plane and map-cache entries on edge nodes to confirm endpoint reachability across sites.

Useful commands
show lisp site <site_name> detail
show lisp eid-table vlan <VLAN_ID> summary
show lisp map-cache <EID>
Scenario
Map‑cache shows no mapping
When `show lisp map-cache 192.168.2.20` returns no mapping, verify that the Fabric Control Plane Node is reachable and that the endpoint registered its EID. Check DHCP and EID registration events on the control plane node.
Common Mistake

Assuming the endpoint moved instantly updates all map caches. There can be delays or failures caused by DHCP or control plane reachability issues.
