Data Plane

Confirm VTEP, VNI, and MTU

Check tunnel interfaces and VNI bindings; ensure the underlay accommodates VXLAN overhead to avoid dropped encapsulated packets.

Commands to run
show interface tunnel 1
show vxlan vni
show platform software fed active fnf flow
show ip traffic
Example
MTU failure pattern
Large packets fail while small packets pass. Use a ping with increased size to confirm. If encapsulated packets are fragmented or dropped, increase MTU or enable jumbo frames consistently across the underlay.
Common Mistake

Only checking VNI binding without validating MTU will miss a frequent cause of VXLAN packet loss.
