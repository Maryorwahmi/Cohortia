Architecture

Logstash → Elasticsearch → Kibana

Separate responsibilities: transform, store & index, explore.

Logstash
Ingests syslog, parses fields, enriches events, forwards structured data to the index.
Elasticsearch
Distributed, RESTful search engine that indexes documents for fast, scalable queries.
Kibana
Exploration UI for creating dashboards, searches, and drilldowns into indexed logs.
Operational example
Use case
Track top 10 devices producing error or critical syslog messages and drill into message text across devices.
Common mistake
Indexing raw, unparsed logs causes inefficient indices and slow searches; parse useful fields before indexing where possible.
Checklist
  • Plan indices and retention
  • Normalize important fields during ingestion
  • Size Elasticsearch for indexing throughput
