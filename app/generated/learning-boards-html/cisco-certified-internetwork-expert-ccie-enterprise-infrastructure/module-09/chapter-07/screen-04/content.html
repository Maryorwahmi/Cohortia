Core Concept

Analytics vs. Visualization

Analytics structures and queries data; visualization communicates the result so engineers can act quickly.

  • Choose storage by data type: logs vs metrics.
  • Design retention and indexing to keep queries fast.
  • Build dashboards that answer operational questions, not dashboards for their own sake.
Key Takeaway

Select storage and visualization patterns that serve the precise question you need to answer in an incident.

Example
Network Overview — Interface bytes (mock)
Metric
bytes_in / bytes_out
Query
mean(bytes_in) grouped by interface and host
Visualization
Time-series line graph with legend
Misconception
Dashboards alone fix incidents. In fact, dashboards must be fed by the right model and queries to be useful.
