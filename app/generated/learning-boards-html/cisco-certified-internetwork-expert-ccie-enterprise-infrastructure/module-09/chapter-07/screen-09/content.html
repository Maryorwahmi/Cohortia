Module 9 › Chapter 9.7 › Time-Series DBs
InfluxDB

Write-friendly TSDB with InfluxQL

Optimized for high write rates and timestamped point queries; uses a SQL-like language for aggregation.

Works well when you push metrics via HTTP writes or Telegraf agents.
Good choice for labs and straightforward integration with Grafana.
Prometheus

Pull model, built-in TSDB, PromQL

Scrapes targets and stores metrics locally; PromQL provides powerful time-series functions.

Best when targets can expose metrics endpoints and scraping is acceptable.
Often paired with Grafana for dashboards and alerting rules.
Practical note
TSDB choice affects ingestion model, query language, and storage behavior. Test typical write rates and query patterns before committing to a production architecture.
