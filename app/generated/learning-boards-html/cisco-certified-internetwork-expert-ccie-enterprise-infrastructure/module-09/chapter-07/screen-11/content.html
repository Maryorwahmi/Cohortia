Data Injection

Simulate interface stats with curl

# Replace  with your InfluxDB host (localhost if same machine)
curl -i -XPOST "http://:8086/write?db=network_metrics" --data-binary 'interface_stats,host=router1,interface=Gi0/1 bytes_in=1000,bytes_out=500'
sleep 5
curl -i -XPOST "http://:8086/write?db=network_metrics" --data-binary 'interface_stats,host=router1,interface=Gi0/1 bytes_in=1200,bytes_out=600'
Grafana datasource
Add InfluxDB as NetworkMetrics, set URL to http://localhost:8086 and Database to network_metrics, then Save & Test.
Create a new dashboard
Add panel → select NetworkMetrics → paste the InfluxQL queries for bytes_in and bytes_out → choose Graph visualization → Apply and Save dashboard.
