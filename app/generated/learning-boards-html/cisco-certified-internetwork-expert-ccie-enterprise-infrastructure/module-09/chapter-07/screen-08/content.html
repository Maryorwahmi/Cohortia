InfluxQL example for interface stats

Use mean aggregation and group by host and interface to render per-interface lines.

SELECT mean("bytes_in") FROM "interface_stats"
  WHERE $timeFilter
  GROUP BY time($__interval), "host", "interface"
  fill(null)

SELECT mean("bytes_out") FROM "interface_stats"
  WHERE $timeFilter
  GROUP BY time($__interval), "host", "interface"
  fill(null)
Notes
  • Use $__interval to match panel granularity to the time range.
  • Group by host and interface so the legend explains each series.
  • Use fill(null) to avoid suggesting data where none exists.
