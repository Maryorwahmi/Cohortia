Module 9 › Chapter 9.5 › Telemetry Subscription
Example config
telemetry ietf subscription MY_SUBSCRIPTION
 encoding encode-kvgpb
 filter xpath /interfaces-state/interface/statistics
 stream cisco-push
 update-policy periodic 1000
 receiver ip address 192.168.1.40 57000 protocol grpc-tcp
Replace the receiver IP with your collector address and tune update-policy to manage load.
What each line does
  • encoding: serialization format for the payload.
  • filter xpath: YANG path selecting the subtree to stream.
  • stream: push mechanism used by IOS XE.
  • update-policy: periodic or on-change timing.
  • receiver: collector IP and transport protocol.
Verification command
show telemetry ietf subscription MY_SUBSCRIPTION
Look for State: Connected or Active and a Last-sent-time to confirm successful streaming.
