Module 9 › Chapter 9.5 › Learning Objectives
Objective
Validate and troubleshoot

Run show commands to confirm subscription state, check collector reachability with basic network tools, and reason about resource tradeoffs when choosing update frequency.

VERIFIED COMPETENCY MILESTONE
Why this matters
Without verification you can't trust streaming data for automation. A disconnected collector, wrong XPath, or firewall rules will silently break your data pipeline.
Mnemonic
Think: Configure → Subscribe → Verify → Monitor (CSV-M).
