Module 9 › Chapter 9.5 › Verification
Lab checklist
  1. Enable gRPC and confirm with show grpc.
  2. Create subscription and run show telemetry ietf subscription NAME.
  3. On the collector, run tcpdump on the configured port to see connection attempts.
  4. Validate YANG paths to avoid empty subscriptions.
  5. Monitor device CPU and bandwidth while streaming.
Example verification commands
show grpc
show telemetry ietf subscription INTERFACE_STATS_SUB
sudo tcpdump -i  port 57000
Use these outputs to determine whether the subscription state is Active and whether the router is initiating connections to the collector.
