Module 9 › Chapter 9.5 › Common Mistakes
Incorrect YANG Path
Typos yield empty streams. Verify using model-aware commands before relying on the subscription.
Firewall / Connectivity
Collector ports must be open. Use tcpdump to see connection attempts from the router.
Collector Availability
Routers buffer then drop data if the collector is down; design redundancy for critical streams.
Resource Impact
High-frequency streams increase CPU and bandwidth; tune update policies and filter scope.
Security
Use TLS and authentication for gRPC in production. Lab testing may omit TLS but do not do so in production.
Deployment Tip
Start small, verify paths and connectivity, then scale update frequency and device count once the pipeline is validated.
