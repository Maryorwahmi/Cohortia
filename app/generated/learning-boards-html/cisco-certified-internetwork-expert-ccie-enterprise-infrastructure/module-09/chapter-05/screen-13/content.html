Step-by-step
  1. On router: configure terminal → grpc → port 57000 → no shutdown.
  2. Create subscription with encoding encode-kvgpb and filter /interfaces-state/interface/statistics.
  3. Set update-policy periodic 5000 for initial testing.
  4. On collector: open port 57000 and run tcpdump to observe connections.
  5. Verify with show telemetry ietf subscription NAME and monitor resources.
Pro tip

Start with longer intervals, verify correctness, then gradually reduce update-policy interval while observing CPU and bandwidth.
