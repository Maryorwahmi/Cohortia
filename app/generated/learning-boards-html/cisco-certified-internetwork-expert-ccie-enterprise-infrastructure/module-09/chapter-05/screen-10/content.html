Collector responsibilities
  • Accept gRPC connections from routers (server role in push model).
  • Decode Protobuf payloads using schemas derived from YANG.
  • Store, analyze, or forward telemetry updates.
Conceptual Python notes

A full solution needs a .proto file and generated server stubs. For verification you can first confirm network connectivity with tcpdump to see SYNs from the router to the collector port.

Troubleshooting hint
If the router's subscription shows Disconnected, confirm collector reachability, open port on firewall, and that a gRPC server is listening. If buffering occurs, plan collector redundancy to avoid drops.
