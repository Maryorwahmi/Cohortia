Module 9 › Chapter 9.5 › Transports
NETCONF
  • XML encoding over SSH.
  • Transaction semantics for configuration.
  • Supports operational retrieval and notifications.
Best when you need transactional config changes and established XML tooling.
gRPC + Protobuf
  • Binary Protobuf encoding, HTTP/2 transport.
  • Native streaming patterns and high efficiency.
  • Common choice for high-frequency telemetry on IOS XE.
Best when you need efficient, streaming transport for high-granularity telemetry.
Decision rule

Use NETCONF for configuration and when XML/SSH is required. Use gRPC when you need efficient streaming telemetry and Protobuf serialization.
