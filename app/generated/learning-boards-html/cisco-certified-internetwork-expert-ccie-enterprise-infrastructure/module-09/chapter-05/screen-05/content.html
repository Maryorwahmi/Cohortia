Module 9 › Chapter 9.5 › Streaming Telemetry
Definition

Streaming telemetry is a push-based method where devices proactively send structured operational data to a collector on change or at configured intervals. It is model-driven using YANG.

Key properties
  • Push-based delivery for near real-time visibility.
  • YANG-modeled payloads for consistent parsing.
  • Supports on-change and periodic update policies.
Analogy

Think of streaming telemetry as subscribing to a data feed for each device. Instead of asking for a weather snapshot every hour, you get a live feed of temperature updates when they change.

Key Takeaway

Streaming telemetry provides timely, structured updates that support automation and analytics when paired with YANG models and proper update policies.

Concrete example

Stream interface statistics at 1 second intervals to capture microbursts and short-lived packet drops, then feed those series into analytics for anomaly detection.
