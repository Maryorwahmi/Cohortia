Architecture Overview

Components of Flexible NetFlow

Customizing flow records for granular data collection on Cisco IOS XE

1. Flow Record

Defines what information constitutes a "flow" (match fields) and what additional data to collect (collect fields).

2. Flow Monitor

Applies the flow record, defines cache parameters (e.g., active/inactive timeouts), and specifies the exporter.

3. Flow Exporter

Defines the destination (collector IP and port) and the export format (NetFlow v9 or IPFIX) for the flow records.

Key Takeaway

Flexible NetFlow's modular design, comprising Flow Records, Flow Monitors, and Flow Exporters, enables precise customization of traffic data collection and export for advanced network analysis.
