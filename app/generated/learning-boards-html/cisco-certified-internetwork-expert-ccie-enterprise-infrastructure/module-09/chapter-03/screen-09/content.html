Core Concept

Understanding Network Traffic Flows with NetFlow

From Cisco's NetFlow to the IPFIX standard for detailed traffic visibility

What is NetFlow?

NetFlow, originally developed by Cisco, collects and exports detailed information about network traffic flows. It's crucial for understanding network usage patterns.

Definition: Flow

A 'flow' is a unidirectional sequence of packets between a source and destination, sharing common characteristics like IP addresses, ports, and protocol.

Key Flow Characteristics

  • •Source IP Address
  • •Destination IP Address
  • •Source Port
  • •Destination Port
  • •Protocol (e.g., TCP, UDP)
  • •Type of Service (ToS)
  • •Input Interface
IPFIX: The Standard

IPFIX (IP Flow Information Export) is an IETF standard based on NetFlow v9, offering greater flexibility and extensibility for flow data.

Key Takeaway

NetFlow and IPFIX provide granular visibility into network traffic by defining and collecting data on 'flows' – unidirectional packet sequences with shared characteristics – enabling detailed analysis of network communication.
