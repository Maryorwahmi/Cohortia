Configuration Guide

Applying Flow Monitors to Interfaces

Activating traffic analysis on network interfaces for comprehensive visibility

3. Define a Flow Monitor
flow monitor MY_FLOW_MONITOR
 description Monitor for MY_FLOW_RECORD
 record MY_FLOW_RECORD
 exporter MY_FLOW_EXPORTER
 cache timeout active 60   ! Export active flows every 60 seconds
 cache timeout inactive 15 ! Export inactive flows after 15 seconds
4. Apply the Flow Monitor to an interface
interface GigabitEthernet2
 ip flow monitor MY_FLOW_MONITOR input
 ip flow monitor MY_FLOW_MONITOR output
Key Takeaway

Flow Monitors link records and exporters, managing the flow cache. Crucially, they must be explicitly applied to network interfaces (input/output) to activate NetFlow data collection and export for traffic analysis.
