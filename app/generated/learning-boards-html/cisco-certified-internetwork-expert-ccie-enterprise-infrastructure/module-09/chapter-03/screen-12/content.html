Defining Flow Records and Exporters

Specifying what data to collect and where to send it for traffic analysis

1. Define a Flow Record
flow record MY_FLOW_RECORD
 description Record for basic traffic monitoring
 match ipv4 protocol
 match ipv4 source address
 match ipv4 destination address
 match transport source-port
 match transport destination-port
 collect interface input
 collect interface output
 collect counter bytes
 collect counter packets
 collect timestamp sys-uptime first
 collect timestamp sys-uptime last
2. Define a Flow Exporter
flow exporter MY_FLOW_EXPORTER
 destination 192.168.1.30  ! IP of NetFlow collector
 source GigabitEthernet1   ! Source interface for export packets
 transport udp 2055        ! UDP port for export (default 2055)
 template data timeout 60  ! How often to send template records
Key Takeaway

Flow Records precisely define the traffic data to be collected, while Flow Exporters specify the destination and format for sending this data to a NetFlow collector, forming the foundation of Flexible NetFlow configuration.
