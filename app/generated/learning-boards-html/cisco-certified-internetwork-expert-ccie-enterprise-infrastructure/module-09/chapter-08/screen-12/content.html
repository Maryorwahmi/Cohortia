Simulation Script (simplified)
import subprocess
import os

ROUTER_IP = "192.168.1.10"
INTERFACE_TO_CLEAR = "GigabitEthernet0/1"

def check_for_high_errors(interface):
  print(f"Simulating check for high errors on {interface}...")
  return True

def trigger_ansible_remediation(interface):
  print(f"Triggering Ansible remediation for {interface}...")
  ansible_command = [
    "ansible-playbook",
    "clear_counters.yml",
    "-i", "inventory.ini",
    "--extra-vars", f"interface_name={interface}",
    "--limit", "router1",
  ]
  os.environ['ANSIBLE_PASSWORD'] = 'cisco'
  subprocess.run(ansible_command)

if __name__ == "__main__":
  if check_for_high_errors(INTERFACE_TO_CLEAR):
    trigger_ansible_remediation(INTERFACE_TO_CLEAR)
Replace hardcoded password with Vault or secrets manager for real deployments. Test in lab before production.
Step-by-step Lab Tasks
  1. Enable SSH and confirm connectivity to the router.
  2. Create inventory.ini and clear_counters.yml on the Ansible host.
  3. Run the Python simulation and observe playbook output.
  4. Verify on router with show interface that counters are cleared.
Common Mistake: forgetting to set ansible_user or ANSIBLE_PASSWORD. That causes authentication failures, so verify credentials before triggering the playbook.
