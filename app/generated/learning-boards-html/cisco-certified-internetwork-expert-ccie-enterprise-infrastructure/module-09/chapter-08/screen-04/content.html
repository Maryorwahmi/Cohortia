Module 9 › Chapter 9.8 › Event-Driven Automation
Definition
Automation initiated by telemetry or analytics events that meet defined conditions.
Design Patterns
  • Precise event definitions and thresholds.
  • Suppression windows to avoid flapping on transient spikes.
  • Safety gates for human approval in early phases.
Concrete Example
If an interface's utilization stays above 90% for three consecutive five-minute samples, trigger a scripted QoS reprioritization or spin up an SD-WAN path if available.
Key Takeaway

Event-driven automation reduces response time but requires careful event design, noise suppression, and safety gates to be trustworthy.

Visual: Event to Action Flow
Telemetry Stream → Analyzer detects threshold breach
Event Generated → Event Broker or Alerting System
Orchestrator receives event → Runs remediation script or playbook
Verification → Confirm state; escalate or continue automated steps
Common mistake: treating a single spike as an event without suppression, causing unnecessary or harmful actions.
