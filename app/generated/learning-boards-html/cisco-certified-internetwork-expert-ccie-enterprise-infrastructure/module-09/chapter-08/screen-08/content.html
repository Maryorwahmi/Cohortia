Module 9 › Chapter 9.8 › Triggering Actions
Execution Pattern
1) Retrieve telemetry. 2) Decide remediation. 3) Execute via appropriate protocol. 4) Verify outcome.
Netmiko/Paramiko: CLI via SSH
ncclient: NETCONF edits
requests: RESTCONF or Orchestrator APIs
Ansible: idempotent playbooks run over SSH
Design for retries, timeouts, and non-blocking execution so the system can monitor progress separately from the command execution.
Concrete Scenario
If high errors are detected on multiple routers, an orchestrator can run an Ansible playbook targeting those hosts; each play should be idempotent, and the orchestrator should gather results and initiate verification sampling.
Checklist
  • Use env vars or vault for credentials.
  • Design playbooks to be idempotent.
  • Limit concurrency and implement rate limiting.
Key Takeaway

Choose the right protocol and make actions safe and repeatable. Decouple execution from verification for robust automation.
