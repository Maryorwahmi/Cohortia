Module 9 › Chapter 9.8 › Verification & Rollback
Verification Steps
  • Sample telemetry after remediation for a sufficient window.
  • Run show commands to validate device state where appropriate.
  • Compare against baseline or expected thresholds and record results.
Rollback Design
Before changing configuration, snapshot prior state and store it securely. Have explicit rollback tasks that restore that state or safely revert changes. Log all rollback actions for audit and post-mortem analysis.
Idempotency
Design tasks so repeated runs do not create duplicate effects. Use module semantics (e.g., Ansible network modules) that enforce desired state.
Pro Tip
Automate snapshots of critical state before changes and keep them immutable so you can reconstruct previous conditions for rollback testing.
Common Mistake

Assuming a single revert command returns the network to a safe state. Test rollback sequences under different failure modes in a lab.
