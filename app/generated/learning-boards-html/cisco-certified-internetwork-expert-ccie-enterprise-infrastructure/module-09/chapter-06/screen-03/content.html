Task checklist
  1. Search for a client by MAC, IP, or username in Assurance.
  2. Open Client 360 and inspect connectivity, events, and application metrics.
  3. Run Path Trace to an application server and inspect hop details.
  4. Compare sensor synthetic results with real client telemetry to detect regressions.
Quick scenario
A user reports intermittent slow application performance. Use Client 360 to check signal and events, then run a Path Trace to the app server. If hop data shows high latency on a link, escalate to the device owner; if ACL denies appear, verify access policies.
VERIFIED COMPETENCY MILESTONE
You will be evaluated on choosing the correct root-cause action based on Client 360 and Path Trace evidence, not on guessing from a single metric.
