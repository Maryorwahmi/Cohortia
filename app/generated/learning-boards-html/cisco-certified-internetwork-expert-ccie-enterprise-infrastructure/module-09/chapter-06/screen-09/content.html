Module 9 › Chapter 9.6 › Activity: Client 360 & Path Trace
Step-by-step checklist
  1. Open Assurance dashboard and note red/yellow areas.
  2. Search Clients and open Client 360 for the target MAC.
  3. Review connectivity history, auth, and application metrics.
  4. Launch Path Trace to the application server and inspect hop data.
  5. Document the hop with evidence and propose the least disruptive fix.
Example audit note
Client MAC: 00:11:22:33:44:55
Observed: association retries at 10:02-10:05
Client Health: 45 (degraded)
AP retries: high
Switch int Gi1/0/24 CRC errors: rising
Path Trace: no ACL denies; last hop shows retransmits
Action: schedule access-switch port repair and verify cabling
Pro Tip
Capture evidence and preferred remediation in the ticket so the fix is targeted and auditable.
