Module 10 › Chapter 9.9 › Establishing Baselines & Anomaly Detection
Baseline Principles
Collect representative samples across hours and days, include seasonal and business cycles, and store at resolutions that support detection.
Dynamic Thresholds
Use analytics to learn expected ranges and trigger alerts on deviations rather than fixed static limits that generate false positives.
Tune Alerts
Engage teams to set alert severity and ensure every alert maps to an actionable response to reduce fatigue.
Example
Track historical IP SLA RTT for a WAN link to detect gradual increases. An ML model flags sustained deviation from baseline, prompting preemptive investigation before user impact.
Common Mistake
Treating baselines as static. Network usage and applications evolve; baselines must be refreshed and recalibrated regularly.
Key Takeaway

Baselines plus dynamic detection let you spot deviations early and reduce false alarms when tuning is part of operations.
