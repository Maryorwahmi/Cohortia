Module 10 › Chapter 9.9 › Activity: Simulated Incident
Scenario Recap
IP SLA alert: RTT > 200ms and 5% packet loss for 5 minutes. Users report slow apps. You have dashboard access to IP SLA, interfaces, syslog, and NetFlow.
Task Steps
  1. Confirm IP SLA spike and note timestamps.
  2. Check interface counters and errors on the relevant link.
  3. Search syslog for link and routing events at those times.
  4. Inspect NetFlow for traffic interruption or rogue flows.
Expected Correlated Output
IP SLA spike aligns with interface down/up messages and OSPF adjacency changes in syslog, an interim drop in interface bytes, and a NetFlow volume drop during the outage window.
Key Takeaway

Practice aligning timestamps across telemetry sources; accurate RCA depends on synchronized data and moving between top-down and bottom-up perspectives.
