Learning Objectives
Progress through these verified milestones to demonstrate hands-on competency with IP SLA.
01
Explain IP SLA purpose
Describe why active, synthetic testing complements SNMP and NetFlow and when to use IP SLA for user-centric measurements.
Verified Competency Milestone
02
Configure probe types
Create ICMP Echo, UDP Jitter, and HTTP operations and tune threshold, timeout, and frequency to reflect service needs.
Verified Competency Milestone
03
Implement reactions and alerts
Use reaction-configuration to send traps or logs after consecutive violations, and understand action types like trapOnly and log.
Verified Competency Milestone
04
Integrate with tracking and routing
Tie an IP SLA operation to a track object and use it with static or routing policies to trigger failover when performance drops.
Verified Competency Milestone
