Configure IP SLA and Track-Based Failover
Follow these steps on R1 to monitor a primary path and fail over to a backup.
Step-by-step (R1)
  1. Enter global configuration mode.
  2. Configure ip sla 1 with icmp-echo to the primary interface and schedule it.
  3. Create track 1 ip sla 1 reachability and set optional delay up/down.
  4. Configure primary static route referencing track 1 and a floating backup with higher AD.
  5. Save the configuration and verify with show commands.
Verification & expected behavior
After simulating a failure on the primary, the track should transition Down and the primary route should be withdrawn, allowing the floating route to be used. Restoring the primary should return the track to Up and reinstall the primary route.
Key Takeaway

This lab demonstrates how IP SLA probes, track objects, and static routes work together to provide automated, performance-aware failover.
