Configuration
HTTP Get/Post Operations
Use HTTP probes to validate web service responsiveness from the network.
Example HTTP Get
! IP SLA HTTP Get Configuration
ip sla 3
 http get http://www.example.com/index.html source-ip 192.168.1.1
 threshold 1000        ! Alert if response time exceeds 1000ms
 frequency 60          ! Run every 60 seconds
ip sla schedule 3 life forever start-time now
Use for availability and response time checks. Avoid complex authentication flows with IP SLA HTTP operations.
When to use
  • Public web endpoints and simple internal web services.
  • When you need application-level response time rather than raw RTT.
  • Not ideal for pages requiring login or complex state.
Key Takeaway

Use HTTP probes to monitor web service responsiveness, and keep probe frequency low for external sites to avoid load and false positives.
