Integration
IP SLA + Track Objects + Static Routes
Make routing decisions based on probe results to achieve automated failover.
Configuration pattern
! Configure IP SLA operation (example)
ip sla 10
 icmp-echo 10.0.0.1 source-interface GigabitEthernet0/1
 threshold 500
 timeout 2000
 frequency 5
ip sla schedule 10 life forever start-time now

! Create a track object to monitor IP SLA 10
track 1 ip sla 10 reachability
! Optional delay to avoid flapping
track 1 delay up 10 down 10

! Use the track with a primary static route
ip route 2.2.2.2 255.255.255.255 192.168.12.2 track 1
! Floating backup with higher administrative distance
ip route 2.2.2.2 255.255.255.255 192.168.22.2 100
Verification
After simulating a failure on the primary, confirm show ip sla statistics, show track 1, and show ip route 2.2.2.2 to observe the track going down and the backup route being used.
Key Takeaway

Track objects bridge IP SLA probes and routing policy, enabling robust, automated failover behavior when performance or reachability degrades.
