UDP Jitter Operation
Designed to test real-time media quality — requires responder on Cisco targets.
Source router configuration
! IP SLA UDP Jitter Configuration (Source Router)
ip sla 2
 udp-jitter 10.0.0.2 16384 source-ip 192.168.1.1 source-port 16384
 threshold 100         ! Alert if jitter exceeds 100ms
 num-packets 10        ! Send 10 packets per operation
 interval 20           ! Packet interval of 20ms
 frequency 10          ! Run every 10 seconds
ip sla schedule 2 life forever start-time now
Target responder
! IP SLA Responder Configuration (Target Router)
ip sla responder
Enabling the responder allows the target to reply correctly to jitter probes so the source can compute jitter and loss.
Key Takeaway

UDP Jitter is the right probe for real-time applications; always enable the responder on Cisco targets and verify results with statistics commands.
