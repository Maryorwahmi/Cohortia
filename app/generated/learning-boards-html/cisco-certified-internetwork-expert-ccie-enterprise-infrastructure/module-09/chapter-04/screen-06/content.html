ICMP Echo Operation
Create, tune, and schedule a basic RTT probe.
Example configuration
! IP SLA ICMP Echo Configuration
ip sla 1
 icmp-echo 10.0.0.1 source-interface GigabitEthernet0/1
 threshold 500         ! Alert if RTT exceeds 500ms
 timeout 2000          ! Wait 2 seconds for a reply
 frequency 5           ! Run every 5 seconds
ip sla schedule 1 life forever start-time now
Schedule keeps the probe running continuously. Adjust frequency and threshold based on baseline measurements.
Verification commands
Use these to confirm activity and metrics.
show ip sla summary
show ip sla statistics 1
Key Takeaway

ICMP Echo is a quick, low-complexity probe for reachability and RTT, but pair it with other probes when you need application-level insight.
