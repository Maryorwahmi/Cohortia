Reaction Triggers and Alerts
Define how the system notifies operators when probes exceed thresholds.
Configure reaction
! Configure a reaction to operation 1 (ICMP Echo)
ip sla reaction-configuration 1 react rtt threshold-type consecutive 3 action-type trapOnly
! trapOnly sends an SNMP trap. log writes to syslog. trapAndLog does both.
Practical note
Use consecutive counts to avoid flapping alerts from transient issues.
Misconception
Reactions notify; they do not automatically change routing. Use track objects for that purpose.
Outcome
After the configured consecutive violations, the system will send the chosen notification, enabling automation or operator action.
Key Takeaway

Use reaction-configuration for notifications and pair with tracking objects to perform state-based failover or routing changes.
