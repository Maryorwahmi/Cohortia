Interpreting IP SLA Statistics
Read status and metrics to decide on remediation or failover.
Common commands
show ip sla summary
show ip sla statistics 1
show track 1
show ip route 2.2.2.2
How to read results
Look for Active status, average/min/max RTT, jitter and loss fields for UDP Jitter, and recent timeouts. Correlate with track state and routing table entries to confirm whether automatic failover behaved as expected.
Key Takeaway

Use CLI statistics plus trend data to make confident decisions; allow probes a short warm-up time before acting on transient anomalies.
