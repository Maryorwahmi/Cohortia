Skills and Verification
Complete these tasks and use the verification commands listed to prove behavior.
Configure & schedule
Create ip sla, set target and source, tune threshold/timeout/frequency, schedule life forever start-time now.
Mnemonic: schedule-now, probe-continuously.
Verify status
Use show ip sla summary and show ip sla statistics <id> to read Active/Timeout and metric values.
Mnemonic: summary then detail.
Track & route
Create track <n> ip sla <id> reachability and attach to primary static route; add floating backup with higher AD.
Mnemonic: track protects route.
Safety checks
Avoid excessive frequency, enable responder when needed, and set thresholds using baseline measurements to prevent false positives.
