Module 9 › Chapter 9.2 › Configure SNMPv2c on IOS XE
Key steps
  1. Create an ACL that permits only your NMS IP.
  2. Define a read-only community string tied to the ACL.
  3. Optionally define a read-write community only with strict ACLs.
  4. Configure the NMS host and enable traps for events you care about.
Example caveat
If a device must use v2c due to legacy constraints, ensure ACLs, rotate communities, and avoid giving RW access unless absolutely necessary.
Configuration example
! SNMPv2c Configuration Example
! Define a read-only community string "public_ro" and restrict access to NMS at 192.168.1.10
access-list 99 permit 192.168.1.10
snmp-server community public_ro RO 99
! Define a read-write community string "private_rw" (use with extreme caution and strong ACLs)
! snmp-server community private_rw RW 99
! Define a host to send traps to (NMS at 192.168.1.10, using community "public_ro")
snmp-server host 192.168.1.10 version 2c public_ro
! Enable specific traps (e.g., link status changes)
snmp-server enable traps snmp linkup linkdown
Common Mistake

Using default community names or missing ACLs exposes devices. Always test access from the permitted NMS IP to confirm restrictions.
