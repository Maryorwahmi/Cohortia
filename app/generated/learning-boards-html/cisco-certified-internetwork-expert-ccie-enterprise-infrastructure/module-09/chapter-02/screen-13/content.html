Assessment Q1 — Secure choice
A network needs authentication and encryption for management traffic. The secure selection is SNMPv3 with authPriv because it provides both hashing-based authentication and encryption for the payload.
Assessment Q2 — Missing traps
If traps are not received, confirm the device has traps enabled for the event type and that the snmp-server host statement points to the correct NMS IP and version. Also check ACLs preventing delivery.
Troubleshooting checklist
  1. Verify ACL permits the management station IP.
  2. Confirm the user belongs to the correct group with the appropriate view.
  3. Check algorithm support on both device and NMS.
  4. Test trap/inform delivery and NMS acknowledgments.
