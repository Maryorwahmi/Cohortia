Module 9 › Chapter 9.2 › Common Mistakes and Best Practices
Common mistakes
  • Using default community strings.
  • Not applying ACLs to restrict SNMP access.
  • Relying on v2c in environments that require confidentiality.
  • Over-polling legacy devices and causing CPU spikes.
Best practices
  • Use SNMPv3 authPriv for sensitive management traffic.
  • Bind community strings to strict ACLs and rotate them.
  • Limit views to only necessary OIDs for each user.
  • Audit SNMP configurations and logs regularly.
Key Takeaway

Combine secure configuration with operational discipline: restrict, audit, test, and document.
