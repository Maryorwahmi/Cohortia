Module 9 › Chapter 9.2 › Learning Objectives — Practical Outcomes
Lab validation steps
  1. Configure SNMPv3 user with authPriv and verify using snmpwalk from an NMS.
  2. Create an ACL to restrict SNMP and observe access denied when the NMS IP is not permitted.
  3. Enable traps and generate an interface down event to confirm delivery.
  4. Measure device CPU while polling to avoid over-polling issues on older hardware.
Operational best practices
  • Prefer SNMPv3 with authPriv for sensitive segments.
  • Never use default community strings; rotate them regularly.
  • Use informs for critical, reliable notifications despite higher overhead.
  • Audit SNMP configs and ACLs periodically.
Verification tip
Document your test results: the snmpwalk output, trap receipts, and CPU measurements. These artifacts prove both correct configuration and acceptable operational impact.
