Module 9 › Chapter 9.2 › SNMP Architecture and Roles
Concept cards
Network Management Station (Manager)
Queries agents, receives traps/informs
Agent
Runs on device, exposes MIB variables and sends notifications
MIB
Hierarchical schema of managed objects
OID
Numeric address of a managed object in the MIB tree
Example — querying system info
A manager can request the system subtree. That returns values such as description and name. The numeric OID corresponds to a human-friendly label in the MIB, so tools will display readable names. Use MIBs to find the correct OID for any metric you need to monitor.
Common misconception
SNMP is not only polling. Agents can send traps or informs to proactively report events. Design alerts around a mix of polling for periodic metrics and notifications for events.
Key Takeaway

Map monitoring requirements to MIB objects and choose polling or notifications based on timeliness and device impact.
