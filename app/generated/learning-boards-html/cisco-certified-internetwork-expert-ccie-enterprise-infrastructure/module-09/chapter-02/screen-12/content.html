Module 9 › Chapter 9.2 › Lab Walkthrough: Configure and Verify SNMPv3
Router steps
  1. snmp-server view ALL-MIBs internet included.
  2. snmp-server group SECURE-GROUP v3 auth priv read ALL-MIBs write ALL-MIBs notify ALL-MIBs.
  3. snmp-server user NMS_USER SECURE-GROUP v3 auth sha MyAuthPass123 priv aes128 MyPrivPass456.
  4. Create ACL permitting the NMS IP and bind as needed.
  5. snmp-server host traps version 3 priv NMS_USER and enable traps you need.
NMS verification
From your NMS host, run an snmpwalk command with version 3, the user, the authentication algorithm, the auth password, the privacy algorithm, the priv password, and the authPriv security level. Confirm the system subtree returns expected values. If not, re-check ACLs, group membership, and algorithm support.
snmpwalk -v 3 -u NMS_USER -a SHA -A MyAuthPass123 -x AES -X MyPrivPass456 -l authPriv <ROUTER_IP> 1.3.6.1.2.1.1
Replace placeholders with your actual IPs and passwords before running the command.
