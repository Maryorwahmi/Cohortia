Module 9 › Chapter 9.2 › SNMPv3 Security Model
Security components
Authentication: Verifies sender identity and integrity using hashing.
Privacy: Encrypts payload to prevent eavesdropping.
Message integrity: Ensures the message was not altered in transit.
Security levels
authPriv — Authentication and encryption. Recommended.
authNoPriv — Authentication only. Less protective.
noAuthNoPriv — Neither auth nor privacy. Not recommended for sensitive networks.
Operational note
When configuring SNMPv3, define a view to limit OIDs, create a group bound to that view with the desired security level, and then create a user in the group with both authentication and privacy credentials. Verify with your NMS and record algorithm support and credential rotation timelines.
