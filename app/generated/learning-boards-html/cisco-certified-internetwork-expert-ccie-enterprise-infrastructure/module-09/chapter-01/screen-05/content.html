Module 9 › Chapter 9.1 › What is Telemetry?
Definition
Automated, structured streaming of device state
Telemetry provides continuous streams of interface counters, CPU/memory metrics, routing events, syslog messages, and flow data. Model-driven telemetry standardizes field names and structure so analytics can correlate across devices consistently.
Structured Streams
YANG/OpenConfig models for consistent fields.
High Granularity
Frequent metrics capture transient issues.
Multiple Types
Counters, logs, flows each provide different insight.
Concrete example
A router streams per-interface byte and packet counters every 10 seconds via gRPC using OpenConfig models. Those counters are timestamped and stored in a time-series database for real-time dashboards and historical trend analysis.
Misconception
Telemetry is not just faster polling; it standardizes structure and push-based delivery so analytics can correlate and automate on reliable fields.
