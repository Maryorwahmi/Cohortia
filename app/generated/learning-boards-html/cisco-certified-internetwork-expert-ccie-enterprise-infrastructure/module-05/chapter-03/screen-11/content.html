Common Mistakes

Typical NAT/PAT configuration errors

A prioritized checklist to find the usual faults quickly.

1. Interface flags missing
If ip nat inside/outside is not applied exactly where needed, translation won't occur.
2. Wrong ACL
ACLs for dynamic NAT/PAT must match the internal source addresses. Typos or wrong masks exclude traffic.
3. Pool exhaustion
Dynamic NAT pools can run out of addresses during heavy load; monitor with show ip nat statistics.
4. PAT misuse
Expect PAT to support outbound sessions only. For externally initiated connections to an internal host, create a static NAT entry.
5. Asymmetric routing
If return traffic is routed through a different device, the NAT state won't match and sessions will fail.
