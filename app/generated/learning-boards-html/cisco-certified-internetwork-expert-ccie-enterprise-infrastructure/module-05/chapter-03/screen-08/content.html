Lab: Configure NAT and PAT for 192.168.1.0/24

Follow these exact IOS commands to set up the scenario.

Interface setup
R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 203.0.113.1 255.255.255.248
R1(config-if)# ip nat outside
R1(config-if)# no shutdown

R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# ip nat inside
R1(config-if)# no shutdown
Static NAT for web server
R1(config)# ip nat inside source static 192.168.1.100 203.0.113.2
PAT for internal hosts
R1(config)# access-list 1 permit 192.168.1.0 0.0.0.255
R1(config)# ip nat inside source list 1 interface GigabitEthernet0/0 overload
Verification checklist
  • From 192.168.1.50 ping an external IP like 8.8.8.8 and then run show ip nat translations.
  • From an external host attempt to reach 203.0.113.2 to confirm static NAT reaches 192.168.1.100.
  • If testing again, clear translations with clear ip nat translation * and re-initiate traffic.
