Configuring Static NAT on a Cisco Router

Follow the sequence: interfaces → flags → static mapping → verify.

Interface configuration
R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 203.0.113.1 255.255.255.248
R1(config-if)# ip nat outside
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# ip nat inside
R1(config-if)# no shutdown
Marking interfaces correctly ensures the router knows which side is private and which is public for translation decisions.
Static mapping
R1(config)# ip nat inside source static 192.168.1.100 203.0.113.2
This command binds the internal server to the specified public IP. External clients use 203.0.113.2 to reach the internal server.
Key Takeaway

Static NAT provides predictable inbound reachability but consumes a public IP per service.

Verification commands
Use show ip nat translations to see the static mapping and show ip nat statistics for counters. If access fails, confirm the server has the correct default gateway pointing at the NAT router and that ACLs or firewall rules aren’t blocking traffic.
