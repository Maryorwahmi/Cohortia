Configuring PAT (NAT Overload)

Create an ACL, apply NAT with overload, and verify translations using show commands.

ACL defining internal hosts
R1(config)# access-list 1 permit 192.168.1.0 0.0.0.255
This ACL selects which internal source addresses are eligible for PAT translation.
Apply PAT using overload
R1(config)# ip nat inside source list 1 interface GigabitEthernet0/0 overload
The router uses the outside interface IP as the shared public address and assigns translated source ports per session.
Interpretation

In show ip nat translations, you will see entries with the same inside global IP but different source port numbers. This confirms PAT is multiplexing sessions correctly. If sessions fail, confirm the ACL, interface flags, and that the outside interface IP is the intended public address to use for translation.
