Definition

Translation Terms: Inside/Outside Local/Global

Use consistent terminology when inspecting NAT tables and communicating with teammates.

Inside Local
Private IP assigned to an internal host before translation, such as 192.168.1.50.
Inside Global
Public IP visible to external networks after translation. With PAT many inside locals may share one inside global.
Outside Local / Outside Global
Names for external hosts as seen from each side; often the outside global is the external host's real public IP on the internet.
Example output interpretation
Pro Inside global      Inside local       Outside local      Outside global
--- 203.0.113.1:50000  192.168.1.10:12345  1.1.1.1:80         1.1.1.1:80
This indicates an inside local 192.168.1.10 translated to inside global 203.0.113.1 using port 50000 to reach outside 1.1.1.1:80.
