What to Remember

Key Concepts

Three compact concept cards to carry forward.

NAT
Remaps IP addresses so private hosts can use public resources without unique public addresses per device.
PAT
Allows many private hosts to share one public IP by translating source ports; ideal for outbound client access.
Verification
Use show ip nat translations and show ip nat statistics; check interface flags and ACLs when translations are missing.
Summary Takeaway

Select static NAT for inbound services, PAT for outbound scale, verify via show commands, and always confirm interface and ACL configuration when troubleshooting.
