Module 5 › Chapter 5.3 › Verification
Verification Steps
  • Confirm ip nat inside and ip nat outside are configured on the correct interfaces.
  • Check that access-lists include only the internal addresses meant to be translated for dynamic NAT/PAT.
  • Use show ip nat translations to see active mappings and identify inside local→inside global relationships.
  • Use show ip nat statistics to inspect pool usage and hit/miss counters.
Mnemonic
Think: Interfaces → Access-list → Mapping → Show. This order catches the most common misconfigurations quickly.
Common Mistake
Applying PAT alone does not permit inbound connections to an internal server; a static one-to-one mapping is required for external-initiated access.
