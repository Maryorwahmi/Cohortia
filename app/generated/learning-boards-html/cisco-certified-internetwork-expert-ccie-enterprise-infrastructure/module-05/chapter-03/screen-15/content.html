What to Remember

A concise checklist before you commit configuration changes.

Interface flags
Confirm ip nat inside/outside are set on the correct interfaces to enable translation.
Mapping choice
Use static NAT for inbound services and PAT for outbound scale; use dynamic NAT when you have a controlled public IP pool.
Verify & Troubleshoot
Check show ip nat translations, show ip nat statistics, ACLs, and routing symmetry when troubleshooting.
Final Takeaway

NAT and PAT are practical tools for IPv4 conservation and connectivity. Choose the right mapping, verify translations, and remember NAT is not a replacement for proper security controls.
