Assessment scenarios and sample questions

Practice diagnosing common NAT situations and writing configuration commands.

Sample question 1
External users cannot reach an internal FTP server while internal hosts use PAT successfully. Which change fixes inbound access?
Answer: Add a static NAT mapping for the FTP server, because PAT does not provide inbound host reachability.
Practical task
Configure a router to map 192.168.1.100 to 203.0.113.2, enable PAT for the 192.168.1.0/24 network using 203.0.113.1, and demonstrate verification using show ip nat translations.
