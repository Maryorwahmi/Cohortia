Learning Objectives
Master these skills and verify a competency milestone for each.
Bloom
Learn → Understand → Apply → Master
01 · Explain necessity
Describe why NAT/PAT are used in IPv4
You will explain private ranges, address conservation, and how NAT hides internal topology. This skill matters because it frames design decisions about public IP allocation and security.
VERIFIED COMPETENCY MILESTONE
02 · Differentiate
Static NAT vs Dynamic NAT vs PAT
You will list use cases for one-to-one, pool-based, and port-overload translations and recognize their operational trade-offs.
VERIFIED COMPETENCY MILESTONE
03 · Configure Static NAT
Create a static mapping for an internal server
You will configure ip nat inside/outside and ip nat inside source static private public so external clients can reach an internal web server.
VERIFIED COMPETENCY MILESTONE
04 · Implement PAT
Configure NAT overload for many hosts
You will build an access list for internal hosts and apply ip nat inside source list X interface Gi0/0 overload to enable many-to-one translations.
VERIFIED COMPETENCY MILESTONE
