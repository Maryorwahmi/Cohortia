Interpreting show ip nat translations and statistics

Learn to read entries and diagnose common causes of failed translations.

Example output
Pro Inside global      Inside local       Outside local      Outside global
--- 203.0.113.1:50000  192.168.1.10:12345  1.1.1.1:80         1.1.1.1:80
--- 203.0.113.2        192.168.1.100       ---                ---
Above: first line is a PAT entry mapping with ports; second line is a static mapping for a server.
Common checks
  • Confirm ip nat inside/outside on correct interfaces.
  • Verify ACLs include intended internal addresses for dynamic NAT/PAT.
  • Use show ip route and confirm symmetric routing to avoid broken NAT sessions.
  • Clear translations when re-testing to observe fresh behavior.
Pro tip
When diagnosing application failures that expect a consistent source IP, consider whether PAT’s shared inside global is appropriate or whether a static NAT is required for predictable behavior.
