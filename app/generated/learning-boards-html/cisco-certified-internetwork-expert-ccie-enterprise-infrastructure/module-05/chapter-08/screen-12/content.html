Module 6 › Chapter 5.8 › Verification
Key commands
show ip igmp groups
show ip pim neighbor
show ip pim rp mapping
show ip mroute
ping 239.1.1.1 (from a host to generate traffic)
Follow the sequence: IGMP → PIM neighbors → RP mapping → multicast route entries to pinpoint failures quickly.
Reading show ip mroute
Look for incoming interface alignment with the unicast RPF and outgoing interface list. Presence of (*,G) denotes RP-based forwarding; (S,G) denotes a source-specific path.
Concrete example

If show ip mroute shows (*,G) but not (S,G) and the receiver expects direct source delivery, allow time or trigger SPT switchover by generating traffic so last-hop router can join toward the source.
