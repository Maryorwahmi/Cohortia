Module 6 › Chapter 5.8 › Applied Tasks
Tasks you'll perform
  1. Enable PIM sparse-mode on interfaces and confirm adjacency.
  2. Configure static RP mapping using ip pim rp-address and group-list.
  3. Verify membership with show ip igmp groups and route entries with show ip mroute.
  4. Triage failures by checking RP reachability, ACLs, and RPF failures.
Quick mnemonic
JOIN — IGMP tells routers who joined; PIM JOINS build trees toward the RP or source.
Verification

Key commands: show ip igmp groups, show ip pim neighbor, show ip pim rp mapping, show ip mroute.
