How PIM uses routing

PIM consults the unicast routing table to find the reverse path to a multicast source or to the Rendezvous Point. That path determines the interface used for RPF checks and the direction of Join messages. If the unicast route is missing or incorrect, multicast packets will fail RPF and be dropped.

Practical tip
Always verify unicast reachability to the source and RP with show ip route or your IGP tools before diving into PIM-specific checks.
Diagnostic steps
  • Confirm unicast route to source or RP exists.
  • Verify PIM adjacency: show ip pim neighbor.
  • Check multicast routing table entries with show ip mroute.
Misconception

PIM will not repair broken unicast routing. If the IP paths are wrong, multicast will silently fail RPF checks.
