Common IOS commands
R1(config)# interface Loopback0
R1(config-if)# ip address 1.1.1.1 255.255.255.255
R1(config-if)# ip pim sparse-mode
R1(config-if)# exit

R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 10.0.0.1 255.255.255.0
R1(config-if)# ip pim sparse-mode
R1(config-if)# no shut

R1(config)# access-list 1 permit 239.1.1.1
R1(config)# ip pim rp-address 1.1.1.1 group-list 1
Use group-list ACLs to limit which groups a static RP serves. Static RP mappings are deterministic and useful for lab scenarios.
Checklist
  • Enable ip pim sparse-mode on each participating interface.
  • Create ACL permitting group(s) for group-list.
  • Configure ip pim rp-address with the RP IP and group-list.
  • Verify with show ip pim rp mapping.
