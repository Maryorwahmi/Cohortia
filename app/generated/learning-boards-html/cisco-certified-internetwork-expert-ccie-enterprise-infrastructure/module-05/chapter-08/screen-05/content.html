Module 6 › Chapter 5.8 › IGMP Membership
How it works
  • Host sends IGMP Membership Report to join a group.
  • Router (querier) records the interface as having listeners and forwards group traffic there.
  • Querier sends periodic IGMP Queries; absence of replies causes state removal.
IGMP versions
IGMPv3 supports Source-Specific Multicast, letting hosts request traffic from particular sources.
Troubleshooting checklist
  1. Confirm the router sees memberships: show ip igmp groups.
  2. Check switch IGMP snooping and querier operation if present.
  3. Verify hosts actually send reports and the network does not filter IGMP messages.
Concrete example

If a receiver joins 239.1.1.1 but show ip igmp groups on the router shows no membership, the router will not forward traffic even though the host sent a join — check switch snooping or UDP filters.
