Module 6 › Chapter 5.8 › Hands-on Activity
Step sequence
  1. Configure R1 Loopback0: ip address 1.1.1.1/32 and ip pim sparse-mode.
  2. Enable ip pim sparse-mode on all router interfaces involved.
  3. Create ACL permitting 239.1.1.1 and set ip pim rp-address 1.1.1.1 group-list 1 on R1, R2, R3.
  4. On R3 enable IGMP join (or have a host join the group).
  5. Generate source traffic and verify with show commands.
Verification targets
  • show ip igmp groups shows membership on R3.
  • show ip pim neighbor shows adjacency among PIM routers.
  • show ip pim rp mapping shows RP 1.1.1.1 for group 239.1.1.1.
  • show ip mroute displays (*,G) then (S,G) during switchover.
Lab reflection

This activity ties configuration to observable forwarding state. If any verification step fails, retrace the checklist starting with unicast reachability to the RP.
