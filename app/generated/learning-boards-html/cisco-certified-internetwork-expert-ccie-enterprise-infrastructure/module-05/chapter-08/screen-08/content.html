Module 6 › Chapter 5.8 › SPT & RPT
Distribution entries
Routers create (*,G) entries for the RP-based shared tree and (S,G) entries for source-specific shortest-path distribution. Entries appear in the multicast routing table as traffic flows and joins are received.
(*,G)
Shared tree rooted at the RP; any-source delivery via RP for group G.
(S,G)
Source tree from S to receivers; built when last-hop routers switch to SPT for efficiency.
Concrete check

Use show ip mroute to observe (*,G) and (S,G) entries; their presence tells you whether traffic flows via the RP or directly from the source.

Example decision

If latency matters, last-hop routers will switch to (S,G) after initially receiving via (*,G). If you prefer consistent RP-based traffic for simpler troubleshooting, limit SPT switchovers by policy.

Key Takeaway

Understand both entry types to interpret multicast routing tables and predict traffic paths during design and troubleshooting.
