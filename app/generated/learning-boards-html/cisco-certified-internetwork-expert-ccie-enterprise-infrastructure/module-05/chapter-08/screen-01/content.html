Membership, Routing, Trees
IGMP
Hosts report group membership to the local router. Querier polls to keep state fresh.
PIM
Builds distribution trees using unicast routing for reverse path checks and forwarding decisions.
SPT vs RPT
Source trees give shortest path routes; shared trees use an RP for initial delivery.
Verification
Use show ip igmp groups, show ip pim neighbor, and show ip mroute to inspect state.
Key Takeaway

Multicast pairs host-driven IGMP membership with router-managed PIM trees. PIM-SM and a reachable RP are essential for scalable delivery.
