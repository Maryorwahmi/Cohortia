Commands & Verification
Config Pattern
class-map → policy-map (police or shape) → service-policy on interface.
Policing Command
police rate <bits-per-second> conform-action transmit exceed-action drop
Shaping Command
shape average <rate> (optionally with Bc/Be) and apply outbound.
Final Tip
Build small lab tests, measure with show policy-map interface, and tune CIR and burst parameters using real traffic patterns to ensure policies behave as intended.
