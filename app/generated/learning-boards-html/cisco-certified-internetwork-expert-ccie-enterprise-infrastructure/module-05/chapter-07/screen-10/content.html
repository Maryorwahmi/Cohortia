Verification show policy-map interface
Sample command and output
show policy-map interface GigabitEthernet0/0 input
  Class ALL_TRAFFIC
    policer stats: conform 12000 exceed 450
show policy-map interface GigabitEthernet0/1 output
  Class ALL_TRAFFIC
    queue depth 120 drops 5
Interpretation: exceed counts show policing action. queue drops show shaper buffer overflow.
Troubleshooting checklist
  1. Confirm policy applied on correct interface and direction.
  2. Compare counters while generating controlled traffic.
  3. Adjust CIR, Bc/Be or buffer based on observed exceed or drops.
Testing with traffic generators is the most reliable way to validate your settings.
