Core Concept Policing — immediate enforcement
Token-bucket policing

Tokens are added at the CIR. A packet consumes tokens equal to its size. If tokens are insufficient, the packet is either dropped or re-marked according to exceed-action.

Key Behavior
Stateless, no buffering, immediate loss or remark on exceed.
Example
An ISP policing customer inbound to 5 Mbps and dropping any excess to protect the provider network.
Common mistake
Applying policing in the wrong direction or expecting it to buffer bursts will cause surprises.
Configuration example
policy-map POLICE_INBOUND
 class CRITICAL_DATA
  police rate 1000000 conform-action transmit exceed-action drop
interface GigabitEthernet0/0
 service-policy input POLICE_INBOUND
Note: rate is in bits-per-second. conform-action transmit leaves packets alone; exceed-action can drop or set-dscp-transmit.
Key Takeaway

Use policing when you must enforce a strict bandwidth ceiling with immediate action on excess traffic.
