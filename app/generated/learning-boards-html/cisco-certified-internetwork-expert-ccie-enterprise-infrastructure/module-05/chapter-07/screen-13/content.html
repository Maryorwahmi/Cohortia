Design Consideration Decision framework
Framework steps
  1. Identify objective: protect or conform.
  2. Choose enforcement point: inbound for policing, outbound for shaping.
  3. Assess application latency vs loss sensitivity.
  4. Plan verification tests and metrics to observe.
Hybrid example
You might police a branch class to protect the data center, while shaping aggregate outbound traffic to the ISP to avoid penalties. Use per-class policies where needed.
Key Takeaway

Apply the right tool at the right point and verify with controlled tests to ensure your policy matches expected traffic behavior.
