Configuration Policing policy-map walkthrough
Starter commands
R1(config)# class-map match-all ALL_TRAFFIC
R1(config-cmap)# match any
R1(config-cmap)# exit

R1(config)# policy-map POLICE_INBOUND_5M
R1(config-pmap)# class ALL_TRAFFIC
R1(config-pmap-c)# police rate 5000000 conform-action transmit exceed-action drop
R1(config-pmap-c)# exit

R1(config)# interface GigabitEthernet0/0
R1(config-if)# service-policy input POLICE_INBOUND_5M
R1(config-if)# no shut
This example polices inbound traffic to 5 Mbps and drops any exceed traffic immediately.
Explanation
  • class-map identifies traffic to which policing applies.
  • police rate sets token arrival rate (CIR) in bps.
  • conform-action and exceed-action determine fate when tokens are or are not available.
  • Apply with service-policy input for inbound policing where you see the traffic first.
Pro Tip

If downstream devices expect marked traffic, prefer remarking over dropping to preserve sessions but avoid congestion.
