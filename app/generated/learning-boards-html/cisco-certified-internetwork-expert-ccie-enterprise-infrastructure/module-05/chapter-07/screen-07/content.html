Core Concept Shaping — buffer and pace
Shaping behavior

Shaping queues excess packets and sends them at the average configured rate. It is stateful because it requires buffers and queue management.

Benefit
Prevents packet loss for short bursts and helps meet SLAs to upstream providers.
Cost
Adds latency due to buffering; insufficient buffers still cause drops.
Configuration example
policy-map SHAPE_OUTBOUND
 class ALL_TRAFFIC
  shape average 1000000
interface GigabitEthernet0/1
 service-policy output SHAPE_OUTBOUND
shape average instructs the router to pace outgoing packets to an average rate; burst allowances are calculated from the CIR unless explicitly set.
Key Takeaway

Use shaping when you need to avoid packet loss and can tolerate small, controlled delay.
