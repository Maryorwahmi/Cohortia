Definition

HSRP fundamentals

HSRP designates an active router to forward for a virtual IP while standby routers take over if that active fails.

Priority: Higher priority wins the active role; default tie-breaker is IP address.
Preempt: When enabled, a higher priority router will take back active role after recovery.
Interface tracking: Decrements priority based on interface status so failover follows link health.
Example
HSRP uses a virtual MAC like 0000.0C07.ACxx where xx is the group number.
Common mistake
Not enabling preempt leaves a recovered higher‑priority router passive until manual intervention.
Verification
Show command
Use show standby brief to view HSRP groups, active/standby roles and virtual IPs.
Quick checklist
  • Confirm matching HSRP group numbers and virtual IP on both routers.
  • Verify priorities and that preempt is configured where expected.
  • Check interface tracking entries to ensure they decrement priority appropriately.
