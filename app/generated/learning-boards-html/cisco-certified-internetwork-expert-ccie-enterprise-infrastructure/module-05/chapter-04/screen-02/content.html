01
Explain gateway single point of failure

Describe how a failed gateway disrupts all subnet hosts and why a virtual router prevents that outage. Verify by noting that hosts keep the same default gateway IP after failover.

VERIFIED COMPETENCY MILESTONE
02
Differentiate HSRP, VRRP, GLBP

Compare active/standby and active/active load balancing, vendor scope, virtual MAC usage, and typical use cases for each protocol.

VERIFIED COMPETENCY MILESTONE
03
Configure HSRP active/standby

Set virtual IP and priority, enable preempt, and use interface tracking to influence role election in response to link failures.

VERIFIED COMPETENCY MILESTONE
04
Implement VRRP as an open standard

Create VRRP groups with master/backup roles, configure priority and preemption, and understand the difference that allows the master to use its physical IP.
