HSRP configuration example

This code block shows the exact commands used on an interface to enable HSRP group 1 with tracking and preemption.

interface GigabitEthernet0/1
 ip address 192.168.1.10 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 120
 standby 1 preempt
 standby 1 track GigabitEthernet0/0 20
Explanation: The physical IP is assigned first, then the virtual IP with group 1. Priority and preempt control election behavior; tracking decrements priority by 20 if the specified interface fails.
Verify: Run show standby brief to confirm active/standby roles and the virtual MAC format 0000.0C07.ACxx.
Notes & Tips
Preempt: Enable where you want the intended primary to become active automatically after recovery.
Tracking: Use to avoid having a router act as gateway when its path to upstream is down.
Hell o messages: HSRP uses UDP 1985; ensure network devices do not block these messages.
Key Takeaway

Use priority, preempt and interface tracking together to achieve predictable, link-aware failover for HSRP.
