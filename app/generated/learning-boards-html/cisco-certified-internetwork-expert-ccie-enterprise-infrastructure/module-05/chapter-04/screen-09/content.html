GLBP architecture and operation

GLBP elects an AVG that assigns virtual MACs to AVFs so multiple routers forward for the same virtual IP.

AVG
Answers ARP for the virtual IP and assigns virtual MACs to AVFs.
AVF
Forwards traffic for its assigned virtual MAC; multiple AVFs can be active concurrently.
Load balancing
AVG can distribute MAC assignments round‑robin, weighted, or host‑dependent to balance client load.
Operational notes
Single virtual IP: Clients use the same gateway IP but learn different MACs, enabling active‑active forwarding.
Verification: show glbp brief and show glbp <group> detail show AVG, AVF and MAC assignments.
Use case: Ideal when you want to maximize gateway capacity and avoid idle standby routers.
Key Takeaway

GLBP allows multiple routers to actively forward for the same virtual IP by assigning distinct virtual MACs to clients.
