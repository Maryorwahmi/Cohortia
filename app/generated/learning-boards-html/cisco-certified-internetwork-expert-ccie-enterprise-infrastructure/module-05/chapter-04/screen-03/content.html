Learning Objectives — Part II
Practical configuration, troubleshooting, and lab verification milestones
01
Configure GLBP for load balancing

Set the virtual IP, enable preempt, choose load balancing method, and verify AVG and AVF roles so traffic uses multiple routers actively.

VERIFIED COMPETENCY MILESTONE
02
Troubleshoot FHRP issues

Identify blocked hellos, authentication mismatches, missing preemption, and unintended tracking behavior with the provided show commands.

VERIFIED COMPETENCY MILESTONE
03
Verify group state and roles

Use show standby brief, show vrrp brief, and show glbp brief to confirm active/master/AVG and AVF status after configuration and during tests.

VERIFIED COMPETENCY MILESTONE
04
Perform failover and observe behavior

Simulate failures and verify preemption, interface tracking effects, and GLBP MAC assignment changes to ensure continuous client connectivity.

VERIFIED COMPETENCY MILESTONE
