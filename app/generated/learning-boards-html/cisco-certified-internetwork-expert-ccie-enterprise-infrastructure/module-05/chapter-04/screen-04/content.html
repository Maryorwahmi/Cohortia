Core Concept

Why a virtual gateway matters

A virtual router reduces outage risk by keeping a stable gateway identity that can be assumed by another router without host changes.

  • Transparent failover: hosts keep the same gateway IP and MAC.
  • Switches continue L2 forwarding using the virtual MAC, avoiding re-ARP storms.
  • Misconception: FHRP does not move host IPs; it moves gateway ownership between routers.
Example
Router A fails; Router B takes the virtual MAC and virtual IP. Clients continue without change.
Key Takeaway
Virtual gateways preserve connectivity and simplify host configuration during outages.

Operational Tip
Always verify forwarding and the virtual MAC on the switch MAC table after configuration to confirm transparent failover.
