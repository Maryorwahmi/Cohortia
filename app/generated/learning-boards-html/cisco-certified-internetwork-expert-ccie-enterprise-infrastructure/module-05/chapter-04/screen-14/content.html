Module 5 › Chapter 5.4 › Key Concepts
FHRP
Protocols that provide default gateway redundancy to eliminate a single point of failure.
Virtual IP Address
A logical gateway IP shared by group members that hosts use as their default gateway.
Virtual MAC Address
A logical MAC used by the virtual router so switches forward traffic correctly during failover.
Summary

These three concepts form the L3 and L2 basis of FHRP behavior; validating both layers is required to confirm resilient gateway operation.
