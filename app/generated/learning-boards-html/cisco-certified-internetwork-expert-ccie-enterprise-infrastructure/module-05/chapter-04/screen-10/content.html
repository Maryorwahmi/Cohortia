GLBP configuration example

Configure the interface, add the glbp group and virtual IP, set priority and preempt, then select a load‑balancing mode.

interface GigabitEthernet0/1
 ip address 192.168.1.10 255.255.255.0
 glbp 1 ip 192.168.1.1
 glbp 1 priority 120
 glbp 1 preempt
 glbp 1 load-balancing round-robin
Verify: show glbp brief to see AVG/AVF roles and virtual MAC assignments.
Tip: To observe distribution, generate traffic from multiple client MAC addresses and inspect show glbp <group> detail.
Troubleshooting
Missing preempt: AVG roles may not return automatically if preempt is not configured.
Mode mismatch: Ensure load-balancing method is compatible across group members to avoid uneven client distribution.
ARP observation: Verify clients learn different virtual MACs for the same virtual IP during distribution tests.
Key Takeaway

GLBP lets you use all gateway routers actively; verify MAC distribution to confirm load balancing is working as expected.
