Definition

VRRP configuration example

Example VRRP commands to create group 1 with a virtual IP and preemption enabled.

interface GigabitEthernet0/1
 ip address 192.168.1.10 255.255.255.0
 vrrp 1 ip 192.168.1.1
 vrrp 1 priority 120
 vrrp 1 preempt
Verify: show vrrp brief shows group, virtual IP, and master/backup roles.
Tip: When using VRRP in multi‑vendor environments, confirm hello intervals and timers match availability targets.
Notes
Authentication: If configured, ensure all VRRP routers share the same key to avoid group formation failures.
IP use: VRRP master may still use its physical IP for local traffic, which can simplify designs where the gateway should also be reachable by its own IP.
Key Takeaway

Use VRRP where open standard behavior and multi-vendor compatibility are required, and always verify timers and hello traffic.
