HSRP
Cisco proprietary active/standby protocol with virtual MAC 0000.0C07.ACxx.
VRRP
Open standard master/backup protocol using 0000.5E00.01xx virtual MAC format; good for multi‑vendor networks.
GLBP
Cisco proprietary active‑active gateway load balancing using an AVG and multiple virtual MACs for a single IP.
Summary takeaway

Pick the protocol that fits vendor constraints and performance needs, enable preempt and tracking where appropriate, and always verify using the show commands after any change.
