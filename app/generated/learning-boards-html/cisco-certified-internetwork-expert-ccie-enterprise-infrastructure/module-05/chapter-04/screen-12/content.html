Hands-on Activity

Lab scenario: Configure R1 and R2

Starter configurations for R1 and R2 covering HSRP, VRRP and GLBP according to the lab instructions.

R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip address 192.168.1.10 255.255.255.0
R1(config-if)# standby 1 ip 192.168.1.254
R1(config-if)# standby 1 priority 110
R1(config-if)# standby 1 preempt
R1(config-if)# vrrp 2 ip 192.168.1.253
R1(config-if)# vrrp 2 priority 90
R1(config-if)# vrrp 2 preempt
R1(config-if)# glbp 3 ip 192.168.1.252
R1(config-if)# glbp 3 priority 110
R1(config-if)# glbp 3 preempt
R1(config-if)# glbp 3 load-balancing round-robin
R2(config)# interface GigabitEthernet0/1
R2(config-if)# ip address 192.168.1.20 255.255.255.0
R2(config-if)# standby 1 ip 192.168.1.254
R2(config-if)# standby 1 priority 100
R2(config-if)# standby 1 preempt
R2(config-if)# vrrp 2 ip 192.168.1.253
R2(config-if)# vrrp 2 priority 110
R2(config-if)# vrrp 2 preempt
R2(config-if)# glbp 3 ip 192.168.1.252
R2(config-if)# glbp 3 priority 100
R2(config-if)# glbp 3 preempt
R2(config-if)# glbp 3 load-balancing round-robin
Verification checklist
  • Run show standby brief on R1 and R2 to confirm HSRP group 1 active/standby and virtual IP 192.168.1.254.
  • Run show vrrp brief to confirm VRRP group 2 master/backup for virtual IP 192.168.1.253.
  • Run show glbp brief and show glbp 3 detail to observe AVG, AVFs and virtual MAC assignments for 192.168.1.252.
  • Simulate failures by shutting the client interface on R1 and observe failover and then recovery with preemption enabled.
Why this matters

Combining HSRP, VRRP, and GLBP knowledge prepares you to design resilient gateways and validate their operation via practical lab steps.
