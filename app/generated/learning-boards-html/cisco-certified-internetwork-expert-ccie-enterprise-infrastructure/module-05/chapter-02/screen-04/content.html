Module 5 › Chapter 5.2 › What DHCP Does
Definition and Role
DHCP assigns addresses, masks, gateways, DNS, and lease information from a central service.
Why it matters
  • Automates IP provisioning at scale and prevents duplicate addresses.
  • Ensures consistent gateway and DNS settings across clients.
  • Simplifies moves, adds, and changes for end-user devices.
Concrete example
When a laptop joins VLAN 20 it broadcasts Discover. A server responds with an Offer containing an IP, and the machine completes the DORA flow to obtain its lease.
Common misconceptions
  • DHCP is not only for IPs — it also supplies gateway, DNS, and lease data.
  • DHCP does not cross routers by default; relay is required for different subnets.
  • Simply enabling a pool does not guarantee clients will get addresses if the pool network is wrong or the interface is down.
Key Takeaway

Treat DHCP as the authoritative source of dynamic host settings and protect static infrastructure by excluding their addresses from pools.
