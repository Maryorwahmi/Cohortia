Module 5 › Chapter 5.2 › Relay Nuances
What ip helper forwards
By default several UDP ports are forwarded. Review and restrict these if you want only DHCP traffic relayed.
! Example: forward only DHCP (bootps/bootpc)
R2(config)# no ip forward-protocol udp 69
R2(config)# no ip forward-protocol udp 137
! etc. Remove unwanted defaults, keep 67 and 68 for DHCP
Check your platform defaults and explicitly remove or add protocols so only required services cross subnet boundaries.
Source context and pool selection
Relays include information about where the request originated, so the server can choose the right pool. Ensure the relay presents the correct interface IP as the source for proper pool selection.
Misconception
ip helper-address simply forwards DHCP — it also forwards other UDP protocols unless you explicitly control them.
Key Takeaway
Audit and limit forwarded UDP protocols so relays only convey necessary traffic to centralized services.
