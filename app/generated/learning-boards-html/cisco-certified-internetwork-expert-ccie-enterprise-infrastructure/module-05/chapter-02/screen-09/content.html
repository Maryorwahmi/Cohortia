Module 5 › Chapter 5.2 › DHCP Relay
Enable relay with ip helper-address
Add the helper on the interface that receives client broadcasts, pointing to the DHCP server.
R2(config)# interface Vlan20
R2(config-if)# ip address 192.168.20.2 255.255.255.0
R2(config-if)# ip helper-address 192.168.20.1
This relays broadcasts from VLAN20 to the server at 192.168.20.1. If helper is missing, Discover messages never reach the server and no binding is created.
Relay behavior and protocol forwarding
By default ip helper-address forwards several UDP services. If you only want DHCP, consider restricting forwarded protocols with ip forward-protocol or access-control methods to reduce attack surface.
Misconception
The helper address translates broadcasts to unicast — it does not act as a DHCP server and cannot allocate addresses itself unless configured as one.
Key Takeaway
Place ip helper-address on the correct client-facing interface so DHCP Discover messages reach the server across subnets.
