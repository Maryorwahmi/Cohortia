Hands-on verification
Commands you'll use to confirm behavior and bindings.
show ip dhcp binding
Lists active leases and client MAC/IP mappings on the DHCP server.
show ip dhcp snooping binding
Shows the snooping table with VLAN, MAC, IP, and interface — useful on switches running snooping.
show ip dhcp snooping statistics
Displays dropped packets and server-response-on-untrusted-port counters to detect rogue offers.
Avoid these common mistakes
  • Mismatched network/mask in pool definitions prevents leases for that subnet.
  • Forgetting excluded-address results in conflicts with static infrastructure addresses.
  • Enabling snooping but trusting an incorrect port lets rogue servers answer clients.
Competency
Be ready to deploy, verify, and troubleshoot DHCP in a VLAN-based enterprise network.
