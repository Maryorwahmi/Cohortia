Module 5 › Chapter 5.2 › Excluded Addresses
Exclusion strategy
Reserve space for infrastructure: SVIs, servers, printers, and management IPs.
Example commands
R1(config)# ip dhcp excluded-address 192.168.10.1
R1(config)# ip dhcp excluded-address 192.168.20.1
After exclusions, define pools and check that all static addresses fall inside the excluded ranges. If you add a server later, remember to add its IP to the excluded list before assigning it statically.
Naming and mask consistency
  • Name pools descriptively for easier troubleshooting and documentation.
  • Ensure the network and mask match the served VLAN; mismatches are frequent causes of failure.
  • Document excluded IP ranges and review them during change control.
Misconception
Excluding addresses does not expand the pool's usable range — it simply reserves specified addresses from allocation.
Key Takeaway
Plan exclusions with your IP addressing policy to prevent accidental conflicts and ensure reliable device connectivity.
