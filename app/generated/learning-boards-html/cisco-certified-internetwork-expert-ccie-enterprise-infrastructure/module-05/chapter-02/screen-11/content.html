Module 5 › Chapter 5.2 › DHCP Snooping
What snooping protects
Prevents rogue DHCP servers from offering addresses and helps enforce IP/MAC consistency.
How it works
  • Inspect DHCP messages passing through the switch.
  • Drop DHCP server messages on untrusted ports.
  • Record bindings in a local database for other security features.
Design considerations
  • Enable snooping globally and per-VLAN to scope protection.
  • Mark server-facing interfaces as trusted to allow Offers and Acks through.
  • Combine with ARP inspection and IP source guard for robust security.
Misconception
Enabling snooping globally without VLAN configuration or trusting the server port can block legitimate DHCP traffic.
Key Takeaway
Snooping both blocks rogue servers and builds the binding table that other L2 protections rely on.
