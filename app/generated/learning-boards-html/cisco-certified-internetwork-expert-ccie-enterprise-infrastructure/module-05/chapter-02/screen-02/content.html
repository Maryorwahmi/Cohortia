Learning Objectives
Bloom progression: Learn → Understand → Apply → Master
01
Explain DHCP & DORA
Describe the Discover, Offer, Request, Acknowledge handshake and why it conserves addresses.
VERIFIED COMPETENCY MILESTONE
02
Configure IOS DHCP Server
Create pools, exclude addresses, set default-router, DNS, and lease times for production use.
VERIFIED COMPETENCY MILESTONE
03
Implement DHCP Relay
Enable ip helper-address to forward client broadcasts to a remote DHCP server across subnets.
VERIFIED COMPETENCY MILESTONE
04
Configure DHCP Snooping
Protect the LAN by enabling snooping, trusting server ports, and checking the binding database.
VERIFIED COMPETENCY MILESTONE
How these objectives fit together
You will first build conceptual understanding of DHCP messages, then apply IOS commands to create pools. Once you can assign addresses locally, you'll extend the design across VLANs using relay and secure the deployment with snooping. Together these skills let you run a central DHCP service safely.
Mnemonic
DORA → POOL → RELAY → SNOOP (think: handshake, address source, forward, protect).
Apply
In the lab, configure R1 as a server, R2 as relay, enable snooping, and verify bindings with show commands.
