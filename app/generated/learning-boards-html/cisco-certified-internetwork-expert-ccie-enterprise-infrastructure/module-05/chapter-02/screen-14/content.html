Module 5 › Chapter 5.2 › Lab Walkthrough
Step-by-step checklist
  1. On R1: configure interface Vlan10 and Vlan20 with IPs and no shutdown.
  2. On R1: exclude interface IPs and create two DHCP pools with network, default-router, and dns-server.
  3. On R2: configure Vlan interfaces and apply ip helper-address on Vlan20 pointing to R1.
  4. On R2: enable ip dhcp snooping and specify VLANs; trust the port to R1 and apply rate limits on access ports.
  5. Connect clients, restart networking, and verify with show ip dhcp binding and show ip dhcp snooping binding/statistics.
Expected verification outputs
Binding outputs should list client MACs and assigned IPs from the correct pool. Snooping statistics should show zero legitimate server drops and no server responses on untrusted ports unless a rogue attempt occurs.
Key Takeaway
Perform the lab in the sequence given: server config, relay, snooping, then verification — this reduces debugging steps.
