Module 5 › Chapter 5.2 › Snooping Configuration
Example configuration
Enable snooping, scope VLANs, and trust the server-facing port.
R2(config)# ip dhcp snooping
R2(config)# ip dhcp snooping vlan 10,20
R2(config)# interface GigabitEthernet0/1
R2(config-if)# ip dhcp snooping trust
R2(config-if)# exit
R2(config)# interface GigabitEthernet0/2
R2(config-if)# ip dhcp snooping limit rate 100
After enabling read the snooping table and check statistics to confirm legitimate Offers are passing and rogue responses are blocked.
Verification commands
  • show ip dhcp snooping binding — displays VLAN, MAC, IP, lease, and port.
  • show ip dhcp snooping statistics — shows counts of dropped server responses and bad packets.
Misconception
Trusting a port simply allows server responses through; misplacing a trusted designation on a client port can enable rogue servers.
Key Takeaway
Enable snooping per VLAN, trust only server links, and use binding verification to confirm correct assignments and drops.
