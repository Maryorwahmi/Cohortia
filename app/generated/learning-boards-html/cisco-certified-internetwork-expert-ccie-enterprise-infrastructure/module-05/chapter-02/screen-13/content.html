Module 5 › Chapter 5.2 › Verification
Server-side checks
Use server show commands to confirm leases and pool activity.
! On the DHCP server
show ip dhcp binding

! On a switch with snooping
show ip dhcp snooping binding
show ip dhcp snooping statistics
If show ip dhcp binding is empty, check the DORA path: VLAN membership, interface status, helper address, and pool definitions.
Relay and client checks
  • Ensure helper-address is on the same interface that receives client broadcasts.
  • Ping the DHCP server from the relay to validate connectivity.
  • On clients, confirm received gateway and DNS settings to isolate routing or name-resolution issues.
Misconception
Seeing an IP on a client doesn't guarantee correct routing — check default-router and ping the gateway to verify reachability.
Key Takeaway
Work from L1/L2 up: interface and VLAN, helper configuration for relay, pool correctness on the server, then binding verification.
