Module 5 › Chapter 5.2 › DHCP Options
Common pool options
Set gateway, DNS, and lease time inside each pool so clients receive consistent parameters.
ip dhcp pool DHCP_POOL_VLAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8
 lease 8
Adjust lease times for device churn. Short leases are useful in dynamic labs; longer leases reduce DHCP traffic in stable production environments.
Validation and pitfalls
  • Test that clients receive the default-router and can ping the gateway.
  • Check DNS resolution from the client when DNS servers are assigned by DHCP.
  • Remember that an incorrect default-router prevents inter-subnet communication even if the client has a valid IP.
Key Takeaway
Options configure client behavior; mismatches produce reachable-but-isolated hosts or broken name resolution.
