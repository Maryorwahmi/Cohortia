Module 5 › Chapter 5.2 › DORA Process
DORA: step-by-step
1. Discover
Client broadcasts a Discover when it has no IP or lease; server addresses are unknown at this point.
2. Offer
Server replies with a proposed IP and options. Multiple offers are possible.
3. Request
Client selects an offer and requests the IP; this notifies other servers to withdraw competing offers.
4. Acknowledge
Server confirms the lease with an Acknowledgement and provides lease duration and options.
Example and checks
Example: a phone in VLAN 10 does Discover → receives Offer for 192.168.10.45 → sends Request → receives Acknowledge with 24-hour lease. If show ip dhcp binding shows nothing, verify broadcasts reach the server and that the server's pool matches the client's VLAN network.
Misconception
An Offer does not create a binding until the server sends the Acknowledge; treat Offers as provisional.
Key Takeaway
DORA must complete end-to-end; interruption at any step prevents an address assignment.
