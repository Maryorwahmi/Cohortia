Configuration NTP server and ntp master
NTP server roles and fallback
How to publish time and when to use ntp master.
Terminal example
R1(config)# interface Loopback0
R1(config-if)# ip address 10.0.0.1 255.255.255.255
R1(config-if)# exit
R1(config)# ntp server 162.159.200.123 key 1 source Loopback0
R1(config)# ntp master 8

!-- The master command sets an authoritative stratum if no upstream sync exists
Use ntp master only when you need a fallback and understand the risk of serving local clock time.
Server checklist
  • Sync server to reliable upstream sources.
  • Set loopback as source for stable identity.
  • Reserve ntp master for fallback; choose a conservative stratum.
