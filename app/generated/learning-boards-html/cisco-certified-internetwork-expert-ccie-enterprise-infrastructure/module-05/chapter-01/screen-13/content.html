Best Practices Do vs Don't
Best practices and pitfalls
Follow these rules to keep time trustworthy.
Do
  • Use loopback interfaces as source addresses.
  • Configure multiple upstream servers from different providers.
  • Enable NTP authentication and manage keys carefully.
  • Integrate NTP status into monitoring and alerts.
Don't
  • Point every client directly to public NTP servers.
  • Use ntp master as a permanent authoritative source without upstream sync.
  • Forget ntp authenticate when using keyed associations.
  • Rely on a single server without redundancy.
Pro tip
Keep key rotation and monitoring processes documented so authentication issues are resolved quickly and safely.
