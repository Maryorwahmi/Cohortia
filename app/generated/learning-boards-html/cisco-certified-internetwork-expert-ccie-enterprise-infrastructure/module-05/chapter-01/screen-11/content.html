Troubleshooting Common NTP issues
Resolution checklist
1. Reachability
Ping the server and verify routing. No IP reachability means no NTP.
2. UDP 123
Ensure firewalls and ACLs permit UDP port 123 end-to-end.
3. Authentication
Check key IDs, ntp authenticate, and trusted-key alignment on both sides.
4. Server health
Verify the upstream server itself is synchronized and stable.
5. Source IP
Use loopback as source for stable identity in ACLs and auth.
6. Fallback caution
Avoid ntp master unless you can tolerate the local clock being authoritative.
