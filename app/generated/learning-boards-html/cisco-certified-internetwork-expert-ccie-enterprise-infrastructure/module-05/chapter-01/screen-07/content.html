Configuration NTP client on IOS
NTP client commands
Define server, set source, and verify sync.
Terminal example
R1(config)# interface Loopback0
R1(config-if)# ip address 10.0.0.1 255.255.255.255
R1(config-if)# exit
R1(config)# ntp server 192.168.1.10 prefer
R1(config)# ntp server 192.168.1.11

!-- Verify after a few minutes
R1# show ntp status
R1# show ntp associations
Notes: use a loopback for consistent source IP. The prefer keyword favors a server when multiple are present.
Quick checklist
  • Define at least two servers for redundancy.
  • Set a stable source interface when using ACLs or authentication.
  • Verify with show commands periodically.
