Verification show commands
Interpreting show ntp status and associations
What to check and what common flags mean.
Example outputs
!-- show ntp status
Clock is synchronized, stratum 2, reference is 162.159.200.123

!-- show ntp associations
     address         ref clock     st  when  poll reach  delay  offset   disp
*~162.159.200.123  .GPS.           1   27    64   377   0.123  -0.002  0.045
Asterisk indicates the selected source. Reach value counts recent successful polls. Invalid states indicate authentication or config mismatches.
Troubleshooting hints
  • Ping the server and test UDP path if reach is low.
  • Check key IDs and ntp authenticate when associations show invalid.
  • Monitor stratum and offset to ensure acceptable accuracy.
