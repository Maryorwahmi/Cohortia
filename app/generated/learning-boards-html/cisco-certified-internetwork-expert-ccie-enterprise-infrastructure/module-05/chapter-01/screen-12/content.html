Lab Walkthrough R1, R2, R3 configuration
Hands-on configuration sequence
Follow these commands on each router exactly.
R1 (server) example
R1(config)# interface Loopback0
R1(config-if)# ip address 10.0.0.1 255.255.255.255
R1(config-if)# exit
R1(config)# ntp authentication-key 1 md5 cohortia123
R1(config)# ntp authenticate
R1(config)# ntp trusted-key 1
R1(config)# ntp server 162.159.200.123 key 1 source Loopback0
R1(config)# ntp master 8
Wait a few minutes and run show ntp status to verify R1 syncs to the public source.
R2 / R3 (clients)
!-- On R2 and R3
ntp authentication-key 1 md5 cohortia123
ntp authenticate
ntp trusted-key 1
ntp server 10.0.0.1 key 1
Verify with show ntp associations and show ntp status. If invalid, re-check key and ntp authenticate.
