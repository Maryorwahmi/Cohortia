CBWFQ: classes, policy maps, guarantees
Define class maps to match DSCP, ports, or other criteria; in the policy map give each class a bandwidth guarantee.
  • • Classes receive a configured minimum bandwidth when congested.
  • • Excess capacity is shared proportionally among classes.
  • • Unmatched traffic goes to class-default.
Configuration example
policy-map CONGESTION_POLICY
 class VOICE_TRAFFIC
  bandwidth 128  # Guaranteed 128 kbps
 class VIDEO_TRAFFIC
  bandwidth 512  # Guaranteed 512 kbps
 class class-default
  fair-queue
This policy-map guarantees minima for voice and video and uses fair-queueing for remaining traffic. Remember to apply the policy to an interface output and set the interface bandwidth so QoS calculations are correct.
Key Takeaway

CBWFQ lets you express minimum guarantees per class; plan allocations to avoid over-commit.
