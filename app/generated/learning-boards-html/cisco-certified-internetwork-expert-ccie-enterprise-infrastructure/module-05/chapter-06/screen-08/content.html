Purpose
Low Latency Queuing (LLQ)
Provides a priority queue for delay-sensitive traffic so packets are forwarded first, minimizing latency and jitter.
  • • Priority queue is strict: it is always serviced before other queues.
  • • Configure a rate limit to prevent starvation of other traffic.
  • • Excess priority traffic above the limit is dropped to protect the network.
Example
In a policy-map you might configure:
policy-map CONGESTION_POLICY
 class VOICE_TRAFFIC
  priority 128  # Voice gets strict priority, up to 128 kbps
 class VIDEO_TRAFFIC
  bandwidth 512
 class class-default
  fair-queue
This ensures voice uses the priority queue but is limited so other classes still receive service.
