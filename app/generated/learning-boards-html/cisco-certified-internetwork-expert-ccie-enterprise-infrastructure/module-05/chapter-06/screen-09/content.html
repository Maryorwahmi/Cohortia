Common mistakes
  1. Omitting or setting the priority rate too high.
  2. Allocating guaranteed bandwidth that exceeds link capacity.
  3. Failing to classify traffic correctly, leaving voice in class-default.
  4. Applying different queuing strategies inconsistently across the network.
Checklist
A disciplined verification sequence helps catch problems early.
  • • Confirm DSCP markings on packets before classification.
  • • Set interface bandwidth to the actual link rate.
  • • Apply policy and run mixed-load tests (voice + bulk data).
  • • Use show policy-map interface to inspect queue stats and drops.
