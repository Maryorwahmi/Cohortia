FIFO
First-In, First-Out
Packets forwarded in arrival order. When queues fill, new packets are dropped until space frees.
  • • Simple to implement and low processing cost.
  • • Poor for mixed workloads; can starve real-time traffic.
  • • Tail drop may cause bursty retransmits in TCP flows.
Analogy: a single checkout line where one slow customer delays everyone.
WFQ
Weighted Fair Queuing
Identifies flows and gives each its own queue, then services queues in a weighted round-robin. Weights can reflect DSCP or IP Precedence.
  • • Prevents a single flow from monopolizing the link.
  • • Provides proportional fairness, not strict bandwidth guarantees.
  • • Works automatically without manual classes.
Pro tip

WFQ is a good default for mixed TCP-dominated flows, but if voice needs absolute protection, move to CBWFQ + LLQ.
