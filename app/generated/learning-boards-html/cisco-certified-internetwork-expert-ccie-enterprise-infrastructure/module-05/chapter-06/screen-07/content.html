Step 1
Define class-maps
R1(config)# class-map match-all VOICE_TRAFFIC
R1(config-cmap)# match ip dscp ef
R1(config-cmap)# exit

R1(config)# class-map match-all VIDEO_TRAFFIC
R1(config-cmap)# match ip dscp af41
R1(config-cmap)# exit

R1(config)# class-map match-all DATA_TRAFFIC
R1(config-cmap)# match ip dscp af21
R1(config-cmap)# exit
Match traffic that has already been marked. Correct matching is essential to ensure classes receive their guarantees.
Step 2
Create and apply policy-map
R1(config)# policy-map WAN_QOS_POLICY
R1(config-pmap)# class VOICE_TRAFFIC
R1(config-pmap-c)# bandwidth 128
R1(config-pmap-c)# exit
R1(config-pmap)# class VIDEO_TRAFFIC
R1(config-pmap-c)# bandwidth 512
R1(config-pmap-c)# exit
R1(config-pmap)# class class-default
R1(config-pmap-c)# fair-queue
R1(config-pmap-c)# random-detect dscp-based
R1(config-pmap-c)# exit
Apply the policy to the interface and set the interface bandwidth so the router knows the true link speed.
