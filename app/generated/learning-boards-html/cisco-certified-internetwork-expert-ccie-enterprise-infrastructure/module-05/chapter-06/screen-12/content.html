Scenario
WAN 1 Mbps — Voice 256k, Video 512k, Data 128k
Follow the configuration steps and be careful with the priority rate and interface bandwidth setting.
R1(config)# policy-map WAN_QOS_POLICY
 R1(config-pmap)# class VOICE_TRAFFIC
 R1(config-pmap-c)# priority 256
 R1(config-pmap-c)# exit
 R1(config-pmap)# class VIDEO_TRAFFIC
 R1(config-pmap-c)# bandwidth 512
 R1(config-pmap-c)# exit
 R1(config-pmap)# class DATA_TRAFFIC
 R1(config-pmap-c)# bandwidth 128
 R1(config-pmap-c)# exit
 R1(config-pmap)# class class-default
 R1(config-pmap-c)# fair-queue
 R1(config-pmap-c)# random-detect dscp-based
 R1(config-pmap-c)# exit
Apply
Set interface bandwidth and attach policy:
R1(config)# interface GigabitEthernet0/0
R1(config-if)# bandwidth 1000
R1(config-if)# service-policy output WAN_QOS_POLICY
R1(config-if)# no shut
Verification
Use the show commands and run mixed-load tests to confirm voice latency and drops for class-default are acceptable.
