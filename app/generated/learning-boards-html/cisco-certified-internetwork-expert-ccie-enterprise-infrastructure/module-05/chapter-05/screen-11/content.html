Module 5 › Chapter 5.5 › Edge vs Core
Process

Edge: classify and mark

Mark packets close to their source where you have context about the user and application.

Core: enforce simple PHBs
Core routers should rely on DSCP values and apply mapped queues or drop policies. Avoid per-flow state in the core to preserve scalability.
Operational checklist
  • Document DSCP-to-queue mappings across devices.
  • Apply marking uniformly at access/edge devices.
  • Use simple PHBs in core for fast forwarding.
Misconception

Applying classification only in the core or relying on core devices for deep inspection will reduce scalability and increase state management overhead.
