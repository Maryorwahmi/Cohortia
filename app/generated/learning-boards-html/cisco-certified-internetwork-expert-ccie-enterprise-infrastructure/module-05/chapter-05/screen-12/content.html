Troubleshooting

If classes show zero matches...

  1. Confirm service-policy is applied to the correct interface and direction.
  2. Ensure NBAR is enabled and protocol packs are current.
  3. Validate ACLs against live traffic addresses and ports.
  4. Capture packets and inspect the DSCP field to confirm marking.
Verification commands
show policy-map interface GigabitEthernet0/1 output show ip nbar protocol-discovery interface GigabitEthernet0/1 Use packet capture to check the DSCP value in the IP header.
Performance check
Create controlled load and observe voice/video quality and packet counters to validate the real impact of your QoS policy.
Key takeaway

Systematic verification avoids false assumptions. Confirm matches, confirm markings, and confirm user experience under load.
