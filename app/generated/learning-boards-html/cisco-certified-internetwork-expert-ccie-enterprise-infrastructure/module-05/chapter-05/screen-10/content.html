Module 5 › Chapter 5.5 › DSCP vs IP Precedence
Definition

DSCP: fine-grained marking

Use DSCP for internal classification and mapping to PHBs. It allows EF, AF, and custom mappings for flexible policies.

EF (Expedited Forwarding)
Typical use: voice RTP for low-latency, low-jitter forwarding.
AF (Assured Forwarding)
Used for prioritized data with different drop precedence levels.
Practical mapping
Voice → EF. SIP signaling → CS3. HTTP → AF21 in the chapter exercise. These mappings should match queuing and policing configurations.
Reality check
DSCP values are respected inside managed networks. Over the public internet, markings may be rewritten or ignored, so plan for domain boundaries.
Key takeaway

Choose DSCP for granular control in enterprise networks and map values consistently to enforcement policies.
