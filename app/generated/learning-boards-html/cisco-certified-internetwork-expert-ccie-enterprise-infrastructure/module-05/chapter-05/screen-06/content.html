Module 5 › Chapter 5.5 › Classification & Marking
Definition

Classify then mark

Classification groups packets. Marking encodes that group into the packet header so PHBs can be applied downstream.

DSCP (6 bits)
64 values. Examples: EF for voice, AF for assured forwarding.
IP Precedence (3 bits)
Legacy 8-value field in IPv4 ToS. Still seen in some deployments.
Concrete example
Mark RTP with EF so network devices use low-latency queues and reduce jitter for voice calls.
Common mistake
Applying different markings at different points in the network creates unpredictable PHB behavior. Keep marking consistent and edge-based.
Key takeaway

DSCP is the preferred marking mechanism; apply it consistently at the edge so core routers can make fast forwarding decisions.
