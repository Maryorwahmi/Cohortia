Process Flow

From match to class

  1. Enable NBAR discovery if you need application recognition.
  2. Create ACLs to match straightforward criteria like IP and ports.
  3. Build class maps that reference ACLs or NBAR protocol names.
  4. Apply class maps in policy maps to mark or shape traffic.
ACLs
Simple, efficient matches based on IP, ports, and protocol. Use for stable, deterministic flows.
NBAR
Deep packet inspection and application recognition. Use when apps use dynamic ports or need signature-based detection.
Class Maps
Group multiple match criteria into a named class for the policy map to act on.
Misconception

Relying only on ACLs in modern networks often fails to identify application traffic accurately because apps may use non-standard ports; combine ACLs with NBAR where needed.
