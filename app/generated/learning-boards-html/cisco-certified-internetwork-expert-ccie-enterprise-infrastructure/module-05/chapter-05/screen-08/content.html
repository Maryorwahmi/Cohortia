Mark voice traffic as EF

Enable NBAR discovery, match RTP, set DSCP to EF, and apply the policy on the interface in output direction.

! Example: Classify voice traffic and mark it as EF
ip nbar protocol-discovery

class-map match-all VOICE_TRAFFIC
 match protocol rtp

policy-map MARK_VOICE
 class VOICE_TRAFFIC
  set ip dscp ef

interface GigabitEthernet0/0
 service-policy output MARK_VOICE
Why this matters
Setting ip dscp ef signals low-latency treatment downstream. Without it, devices cannot apply expedited queues.
Common mistake
Forgetting to enable NBAR or using an outdated protocol pack will make match protocol rtp return zero matches.
Key takeaway

Use MQC consistently: class-map for matches, policy-map for actions, and apply service-policy at the edge in output when marking before packets leave the router.
