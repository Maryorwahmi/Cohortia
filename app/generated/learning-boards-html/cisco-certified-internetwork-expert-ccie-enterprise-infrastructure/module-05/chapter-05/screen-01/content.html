Chapter preview

You will learn classification methods, how to mark packets using DSCP and IP Precedence, and how to apply these markings with Cisco's MQC framework so routers and switches apply per-hop behaviors consistently.

Key takeaway

Start QoS at the network edge: classify and mark packets close to the source so core devices can make fast, stateless forwarding decisions.
