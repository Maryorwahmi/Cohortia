Deploying and Activating Custom Rules

Installing plugins and activating rules in Quality Profiles

Step 1

Place Plugin JAR

Copy the compiled custom rule plugin (.jar file) to the extensions/plugins directory on your SonarQube server.

Important Note

Ensure the plugin is compatible with your SonarQube server version.

Step 2

Restart SonarQube Server

A server restart is required for SonarQube to discover and load the newly added custom rule plugin.

Why Restart?

The server needs to re-initialize its plugin registry to make new rules available for use.

Step 3

Activate in Quality Profile

Navigate to your Quality Profile in SonarQube and activate the newly available custom rules, just like any other rule.

Custom Profile

Consider creating a dedicated Quality Profile for your custom rules and organizational standards.

Key Takeaway

Deploying custom rules involves placing the plugin JAR in the SonarQube server's plugin directory, restarting the server, and then activating the rules within the desired Quality Profiles.
