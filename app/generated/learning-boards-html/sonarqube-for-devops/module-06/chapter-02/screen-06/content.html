What is an AST?

An Abstract Syntax Tree (AST) is a tree representation of the abstract syntactic structure of source code, used by the rule engine for analysis.

Rule Logic

Each rule is a piece of logic that inspects the AST for specific patterns or anti-patterns, such as naming conventions or security vulnerabilities.

Example

A rule might detect if a variable is declared but never used by traversing the AST to find its definition and subsequent references.

Key Takeaway

The SonarQube rule engine leverages Abstract Syntax Trees (ASTs) to systematically apply rules, enabling deep and accurate static code analysis for issue detection.
