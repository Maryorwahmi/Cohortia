Chapter Review

Key Concepts: Maintenance Fundamentals

Essential terms and ideas for keeping SonarQube running smoothly.

Backup and Restore

Creating copies of SonarQube's database and data directory for recovery in case of data loss or system failure.

Minor Upgrade

An upgrade within the same major SonarQube version (e.g., 9.x to 9.y), typically involving fewer breaking changes.

Major Upgrade

An upgrade to a new major SonarQube version (e.g., 8.x to 9.x), often involving significant changes and requiring more careful planning.

Summary Takeaway

Proactive backup strategies and a clear understanding of upgrade types are fundamental for maintaining a stable and up-to-date SonarQube instance.
