Upgrade Best Practices

Strategic Planning for Major SonarQube Upgrades

Ensuring a smooth transition to new major versions

Test on a Separate Instance

Always perform major upgrades on a non-production test instance first to catch issues early.

Consult Official Upgrade Guides

These guides contain critical, version-specific instructions and prerequisites for a successful upgrade.

Never Skip Versions

Upgrade incrementally (e.g., 7.x → 8.x → 9.x). Skipping versions can lead to irreversible database corruption.

Key Takeaway

A new instance strategy with database restore is often the safest approach for major upgrades, providing a clean slate and rollback option.

Major Upgrade Flow
1Provision New Instance

Set up a fresh SonarQube instance with the target version.

↓
2Restore Database Backup

Restore your existing database backup to the new instance's database.

↓
3Copy Compatible Plugins

Install only plugins compatible with the new SonarQube version.

↓
4Start & Verify

Start the new instance and thoroughly verify its functionality and data.
