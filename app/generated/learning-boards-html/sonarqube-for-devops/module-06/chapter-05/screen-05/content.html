Backup Strategy: Database and Data Directory

Identifying critical components for a full SonarQube recovery

Database: The Core

Contains all analysis results, project configurations, users, and permissions. Essential for historical data and system state.

Data Directory: Search Indexes

Located at SONARQUBE_HOME/data, it stores Elasticsearch search indexes and other internal data. Critical for search functionality and faster recovery.

Key Takeaway

A complete SonarQube backup requires both the database and the SONARQUBE_HOME/data directory to ensure full data integrity and functionality.

SonarQube's Critical Data Stores
SonarQube Database
  • Analysis results & metrics
  • Project configurations
  • User accounts & permissions
+
SONARQUBE_HOME/data Directory
  • Elasticsearch search indexes
  • Internal caches & temporary files
