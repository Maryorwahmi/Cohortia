Practical Application

Configuring a Custom Quality Gate and Profile

A hands-on walkthrough of SonarQube administration

01

Create Custom Quality Profile

Navigate to 'Quality Profiles', click 'Create', name it 'MyCompany Java Profile', select 'Java' and 'Sonar Way' as parent. Customize rules by activating/deactivating specific ones like 'Methods should not have too many parameters' (java:S107).

02

Create Custom Quality Gate

Go to 'Quality Gates', click 'Create', name it 'MyCompany Stricter Gate'. Add conditions 'On New Code': 'Reliability Rating is greater than A', 'Security Rating is greater than A', 'Maintainability Rating is greater than A', and 'Coverage is less than 70%' (to fail if below 70%).

03

Associate with Project

In your project's 'Administration' settings, change the Java Quality Profile to 'MyCompany Java Profile' and the Quality Gate to 'MyCompany Stricter Gate'.

04

Re-run Analysis

Trigger a new SonarQube analysis for your chosen project to observe how the new Quality Profile and Quality Gate conditions impact the project's status.

Key Takeaway

This activity demonstrates how to tailor SonarQube's enforcement to your specific project needs, ensuring relevant and effective quality checks.
