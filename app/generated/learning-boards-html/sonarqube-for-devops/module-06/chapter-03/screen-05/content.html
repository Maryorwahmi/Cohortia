Project Configuration Errors

Resolving sonar.projectKey and source path issues.

sonar.projectKey

Must be unique and contain only alphanumeric characters, -, _, ., or :. An invalid key will halt analysis.

sonar.sources / sonar.tests

Define paths to your source code and test files. These paths are relative to the scanner's execution directory. Incorrect paths mean the scanner can't find code to analyze.

sonar.java.binaries

For Java projects, this must point to the compiled .class files, not the source folders. Misconfiguration leads to incomplete analysis.

Key Takeaway

Accurate project key and source path definitions are fundamental for successful scanner execution and accurate analysis.

Example: sonar-project.properties
# Valid project key
sonar.projectKey=my-java-app

# Invalid project key (contains spaces)
# sonar.projectKey=my project key with spaces

# Source directories relative to project root
sonar.sources=src/main/java
sonar.tests=src/test/java

# Compiled binaries for Java
sonar.java.binaries=target/classes

Ensure paths are correct and the project key adheres to naming conventions.

Common Mistake

Using a sonar.projectKey like 'My Project' with spaces will cause an error. Always use valid characters as specified in the documentation.
