Navigating Proxy Settings

Configuring proxies for both SonarScanner and SonarQube Server.

SonarScanner Proxy Configuration

If the scanner is behind a proxy, it needs to be configured to reach the SonarQube server or external SCMs.

Example: SONAR_SCANNER_OPTS
export SONAR_SCANNER_OPTS="-Dhttp.proxyHost=myproxy.com -Dhttp.proxyPort=8080 -Dhttps.proxyHost=myproxy.com -Dhttps.proxyPort=8080"
Key Takeaway

Correct proxy configuration is essential for SonarQube components to communicate through corporate firewalls.

SonarQube Server Proxy Configuration

The SonarQube server might need proxy settings to reach external services, such as for plugin updates or license validation.

Example: sonar.properties
# Web proxy for outbound connections
http.proxyHost=myproxy.com
http.proxyPort=8080
https.proxyHost=myproxy.com
https.proxyPort=8080

Common Mistake

Forgetting to configure both HTTP and HTTPS proxy settings, or not including authentication details if required by your proxy server.
