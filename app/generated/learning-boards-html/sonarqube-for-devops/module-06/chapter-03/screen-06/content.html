Memory and Network Challenges

Addressing OutOfMemoryError and connectivity problems.

Insufficient Memory (OutOfMemoryError)

For large projects, the SonarScanner might run out of memory. This manifests as an OutOfMemoryError in the scanner's console output.

Solution: Increase SONAR_SCANNER_OPTS
export SONAR_SCANNER_OPTS="-Xmx1024m -XX:MaxPermSize=512m"
Key Takeaway

Increase scanner memory for large projects; verify network access to the SonarQube server.

Network Connectivity Issues

The scanner cannot reach the SonarQube server. This can be due to incorrect sonar.host.url, firewall blocks, or proxy misconfigurations.

Troubleshooting Steps:
  • Verify sonar.host.url is correct.
  • Check firewall rules between scanner and server.
  • Test network reachability (e.g., ping, telnet).
  • Ensure proxy settings are configured if behind a corporate firewall.

Example Scenario

A CI/CD pipeline job fails with 'Connection refused' when trying to connect to http://localhost:9000. This indicates the SonarQube server is either not running or a firewall is blocking the connection on port 9000.
