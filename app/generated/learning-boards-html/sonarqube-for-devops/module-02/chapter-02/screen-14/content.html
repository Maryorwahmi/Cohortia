Chapter Summary
Key Concepts: Core Metrics
Essential terms for understanding code quality.
Reliability

Rating indicating the likelihood of software failure, based on bugs.

Security

Rating indicating software's resistance to attacks, based on vulnerabilities.

Maintainability

Rating indicating how easy code is to understand, modify, and extend.

Bug

A confirmed error in the code that causes incorrect behavior.

Vulnerability

A security flaw in the code that could be exploited by attackers.

Code Smell

A symptom of poor design or implementation that makes code harder to maintain.

Summary Takeaway

SonarQube's core metrics provide a holistic view of code health, guiding developers to build more reliable, secure, and maintainable software.
