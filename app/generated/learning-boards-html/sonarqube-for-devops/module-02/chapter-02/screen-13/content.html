Hands-on Activity
Exploring a Sample Project and Managing Issues
Practical steps to interact with SonarQube reports.
Step 1
Access & Navigate Dashboard

Access a SonarQube instance with a pre-analyzed project. Observe overall ratings and 'New Code' vs. 'Overall Code' sections.

Step 2
Explore Measures Tab

Look at historical data for various metrics to see how Bugs, Vulnerabilities, or Code Smells have changed over time.

Step 3
Filter & Interact with Issues

In the 'Issues' tab, filter by type/severity. Click an issue, assign it to yourself, add a comment, and practice marking as 'False Positive' or 'Won't Fix' with justification.

Step 4
Explore Code Tab

Browse the source code and see how issues are highlighted directly within the files, providing immediate context.

Key Takeaway

This activity provides practical experience in interpreting SonarQube reports and managing the lifecycle of identified issues, crucial for real-world application.
