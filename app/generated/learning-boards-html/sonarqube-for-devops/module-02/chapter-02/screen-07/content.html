Security Hotspots
Code requiring manual security review.
What are Hotspots?

Pieces of code that *might* be security-sensitive and require a manual review by a human expert.

  • •Not automatically classified as vulnerabilities.
  • •Static analysis cannot definitively confirm exploitability.
  • •Act as a prompt for thorough manual audit.
Example: Sensitive Data Handling

A function that encrypts user passwords might be flagged as a hotspot, requiring a manual check to ensure best practices are followed.

Hotspot vs. Vulnerability

A vulnerability is a confirmed security flaw, while a hotspot is a potential risk needing human judgment.

  • •Hotspots do not automatically fail Quality Gates for vulnerabilities.
  • •Manual review is essential to confirm or dismiss.
  • •Prioritize review for critical areas.
Misconception

Assuming a Security Hotspot is a confirmed vulnerability. It's a flag for human review, not an automatic exploit risk.

Key Takeaway

Security Hotspots are critical areas that demand manual security review to prevent potential vulnerabilities from becoming real exploits.
