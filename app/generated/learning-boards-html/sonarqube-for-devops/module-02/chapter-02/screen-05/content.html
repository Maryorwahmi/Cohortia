Core Metrics
Bugs and Vulnerabilities
Identifying critical errors and security flaws.
Bugs

Definite errors in your code that lead to unexpected behavior or crashes. SonarQube identifies these with high confidence.

  • •Directly impacts Reliability rating.
  • •Top priority for fixing.
  • •Example: Unhandled exceptions, logical errors.
Example: Bug

A division by zero error in a calculation function is a bug that will cause an application crash, directly affecting reliability.

Vulnerabilities

Security flaws that could be exploited by attackers, leading to data breaches or unauthorized access.

  • •Directly affects Security rating.
  • •Often mapped to CWE/OWASP Top 10.
  • •Example: SQL Injection, Cross-Site Scripting (XSS).
Example: Vulnerability

An unvalidated user input used in a database query can lead to an SQL injection, compromising data security.

Key Takeaway

Bugs and vulnerabilities are critical issues that must be addressed promptly to ensure application stability and security.
