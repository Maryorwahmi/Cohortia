Code Quality Metrics
Duplication and Coverage
Measuring code reuse and test effectiveness.
Duplication

Measures the percentage of identical lines of code. High duplication is a major code smell.

  • •Increases maintenance effort.
  • •Leads to potential inconsistencies and errors.
  • •Example: Copy-pasted utility functions.
Example: Duplicated Logic

Two different modules implementing the exact same data validation logic, leading to redundant code and increased maintenance.

Coverage

Indicates the percentage of source code executed by automated tests.

  • •High coverage (e.g., 80%+) indicates robust testing.
  • •Crucial input for Quality Gates, especially for new code.
  • •Doesn't guarantee test quality, but ensures execution.
Example: Low Coverage

A critical business logic function has only 10% test coverage, meaning most of its paths are untested and prone to undetected bugs.

Key Takeaway

Minimizing duplication and maximizing test coverage are essential practices for creating maintainable, robust, and reliable software.
