UI Navigation
Navigating the SonarQube UI
Exploring the Measures, Issues, and Code tabs.
Measures Tab

Offers a historical view of all metrics, allowing you to track trends over time.

  • •Monitor evolution of code quality.
  • •Identify improvements or regressions.
Issues Tab

Where developers spend significant time, filtering and managing identified code quality issues.

  • •Filter by type, severity, assignee, file.
  • •Assign, comment, and change status.
Code Tab

Allows you to browse the source code directly within SonarQube, with issues highlighted inline.

  • •Locate and understand issue context.
  • •Streamlines the remediation process.
Key Takeaway

The SonarQube UI provides powerful navigation tools across Measures, Issues, and Code tabs to enable comprehensive analysis and efficient issue management.
