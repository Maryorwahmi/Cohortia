Key Concepts (Continued)

More essential terms to remember

Rule

A specific pattern or condition that SonarQube checks for in the code to identify issues (bugs, vulnerabilities, code smells).

Severity

The level of impact or importance assigned to a rule or an issue (e.g., Blocker, Critical, Major, Minor, Info).

Technical Debt

The implied cost of additional rework caused by choosing an easy but limited solution now instead of a better approach.

Shift-Left

The practice of moving quality assurance and testing activities earlier in the software development lifecycle to catch issues sooner.

Chapter Summary

Rules define checks, Severity categorizes impact, Technical Debt represents future costs, and Shift-Left is the strategy to integrate quality early in development.
