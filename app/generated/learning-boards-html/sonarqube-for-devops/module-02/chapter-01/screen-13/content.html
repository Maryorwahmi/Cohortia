Hands-on Activity

Customizing Profiles and Creating Gates

A guided walkthrough to tailor SonarQube's enforcement mechanisms.

1

Create Quality Profile

Navigate to 'Quality Profiles', click 'Create', and name your new profile (e.g., MyCustomJavaProfile).

2

Customize Rules

Activate/deactivate rules and adjust severity (e.g., 'S116' to Critical, deactivate 'S1118').

3

Create Quality Gate

Go to 'Quality Gates', click 'Create', and name it (e.g., DevOpsStrictGate).

4

Add Conditions

Add 'on New Code' conditions: new_bugs > 0 (set to 0), new_coverage < 80% (set to 80).

5

Assign to Project

Assign your new Quality Profile and Gate to an existing or new dummy project.

Why This Matters

This activity provides direct experience in tailoring SonarQube's enforcement mechanisms, allowing you to implement precise quality controls that align with your team's specific development and compliance needs. It bridges the gap between theory and practical application.

Pro-Tip

Always test your new Quality Gates and Profiles on a non-critical project or a feature branch first to ensure they behave as expected before applying them to main development branches.

Key Takeaway

Hands-on configuration of Quality Profiles and Gates is essential for effectively tailoring SonarQube to enforce project-specific code quality standards.
