Key Concepts

Essential terms from this chapter

CI/CD Pipeline

An automated process for building, testing, and deploying software.

SonarQube Scanner CLI

The command-line interface tool used to execute SonarQube analyses.

`sonar-scanner`

The command used to invoke the SonarQube Scanner CLI for initiating an analysis.

Summary Takeaway

Automating code quality checks through CI/CD pipelines using the SonarQube Scanner CLI is fundamental for modern DevOps practices.
