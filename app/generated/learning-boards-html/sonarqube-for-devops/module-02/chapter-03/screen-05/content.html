The Universal SonarQube Scanner CLI

Your Gateway to Automated Analysis

Command-Line Tool

A standalone executable that initiates SonarQube analysis.

CI/CD Agnostic

Can be run on any build agent or CI/CD runner, offering broad compatibility.

Configurable

Properties can be passed via command-line arguments or a sonar-project.properties file.

Key Takeaway

The SonarQube Scanner CLI is the foundational tool for automating code analysis, offering flexibility and consistency across diverse CI/CD environments.

SonarQube Scanner CLI in Action

sonar-scanner \
  -Dsonar.projectKey=my-app \
  -Dsonar.sources=. \
  -Dsonar.host.url=http://localhost:9000 \
  -Dsonar.token=YOUR_TOKEN
