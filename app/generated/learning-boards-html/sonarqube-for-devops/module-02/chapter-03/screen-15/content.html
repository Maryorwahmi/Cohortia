Key Concepts Continued

Reinforcing core SonarQube properties

Project & Sources

sonar.projectKey uniquely identifies the project, and sonar.sources specifies the code path for analysis.

Host URL & Token

sonar.host.url points to the server, and sonar.token provides secure authentication for uploading results.

Quality Gate Wait & Build-Breaking

sonar.qualitygate.wait=true makes the pipeline fail if the Quality Gate is not 'GREEN', enforcing quality standards.

Summary Takeaway

Properly configuring project identification, secure authentication, and explicit Quality Gate enforcement are critical for effective and reliable automated SonarQube integration in CI/CD.
