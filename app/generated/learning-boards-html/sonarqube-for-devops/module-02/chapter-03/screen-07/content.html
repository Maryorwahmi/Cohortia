Authentication and Quality Gate Enforcement

Securing Scans and Blocking Bad Code

sonar.token

An authentication token for secure communication with the SonarQube server. Essential for uploading analysis results securely.

sonar.qualitygate.wait=true

Instructs the scanner to wait for the Quality Gate status and fail the pipeline step if the Quality Gate is not 'GREEN'.

Language-Specific Properties

Properties like sonar.java.binaries (for Java) or sonar.python.version (for Python) are often needed to provide context for language-specific analysis.

Key Takeaway

Securely managing sonar.token and utilizing sonar.qualitygate.wait=true are paramount for both the security and effective enforcement of quality standards in your CI/CD pipeline.
