Core Properties for SonarQube Scans

Identifying Your Project and Server

sonar.projectKey

A unique identifier for your project in SonarQube. Ensures analysis results are linked to the correct project dashboard.

sonar.sources

The file path to the source code directory that SonarQube should analyze. Critical for the scanner to locate your codebase.

sonar.host.url

The full URL of your SonarQube server. Directs the scanner where to upload the analysis results.

Key Takeaway

Accurate configuration of sonar.projectKey, sonar.sources, and sonar.host.url is fundamental for connecting your code to the correct SonarQube project and server.
