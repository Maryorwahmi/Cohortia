Writing Your Custom Rule Logic

Traversing the AST to identify specific code patterns.

AST Traversal

Implement logic to navigate the Abstract Syntax Tree, inspecting nodes and their relationships.

Language-Specific APIs

Utilize APIs like SonarJava, SonarJS, or SonarPython to access and manipulate AST nodes.

Issue Reporting

When a pattern is detected, the rule reports an issue with a descriptive message and location.

Conceptual Rule Structure
public class MyCustomRule extends BaseTreeVisitor {
  @Override
  public void visitMethodInvocation(MethodInvocationTree tree) {
    // Logic to inspect method calls
    if (isForbiddenMethod(tree)) {
      // context.reportIssue(this, tree, "Forbidden method call");
    }
    super.visitMethodInvocation(tree);
  }
  // ... other visit methods for different AST nodes
}
Key Takeaway

Writing custom rule logic involves extending a visitor class and implementing methods to inspect specific AST nodes for desired patterns.
