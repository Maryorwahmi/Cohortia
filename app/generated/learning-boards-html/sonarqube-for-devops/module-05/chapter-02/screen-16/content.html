Key Concepts: Part 2

Tools and components for custom plugin development.

SonarJava API

Libraries provided by SonarSource for plugin developers to access and traverse the AST for specific languages (e.g., Java).

Sensor

A component within a SonarQube plugin responsible for collecting data (e.g., code coverage, external metrics) during analysis.

Plugin Lifecycle

The complete process from developing a custom plugin to its deployment, activation, and ongoing management on the SonarQube server.

Summary Takeaway

Language-specific APIs and Sensors are key components that enable custom rule development and comprehensive data collection within the SonarQube plugin lifecycle.
