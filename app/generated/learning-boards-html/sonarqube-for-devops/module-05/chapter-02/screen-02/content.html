Learning Objectives: Part 1

Develop a foundational understanding of SonarQube's extensibility.

LearnUnderstandApplyMaster
Competency Milestones
01

Understand SonarQube Architecture

Grasp the core components and extension points that enable custom rule development. This knowledge is key to identifying where your custom logic can integrate.

VERIFIED COMPETENCY MILESTONE
02

Identify Custom Rule Scenarios

Recognize situations where built-in rules are insufficient for enforcing specific coding standards. This helps you decide when custom development is the right path.

VERIFIED COMPETENCY MILESTONE
03

Leverage Abstract Syntax Trees (ASTs)

Understand how SonarQube parses code into ASTs and how custom rules traverse them. This is the technical foundation for writing effective rules.

VERIFIED COMPETENCY MILESTONE
04

Grasp Plugin Lifecycle

Follow a custom plugin from development through deployment and activation on the SonarQube server. This provides a complete operational view.

VERIFIED COMPETENCY MILESTONE
