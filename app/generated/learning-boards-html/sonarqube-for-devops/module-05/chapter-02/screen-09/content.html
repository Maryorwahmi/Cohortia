Packaging and Deploying Your Plugin

Transforming your code into a deployable SonarQube extension.

Maven Packaging

Compile your code and package it into a .jar file using Maven's build process.

Server Deployment

Copy the generated .jar file to the SonarQube server's extensions/plugins directory.

SonarQube Restart

A server restart is required for SonarQube to detect and load the newly deployed plugin.

Activation Flow
1.

Build JAR with Maven

2.

Copy to extensions/plugins

3.

Restart SonarQube Server

4.

Navigate to Administration > Quality Profiles

5.

Find and Activate Custom Rules

Key Takeaway

Proper packaging, deployment to the server's plugin directory, and activation in Quality Profiles are essential for custom rules to become active in SonarQube.
