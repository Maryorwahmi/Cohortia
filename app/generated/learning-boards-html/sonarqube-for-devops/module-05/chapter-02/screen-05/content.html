Abstract Syntax Tree (AST)

The core data structure for SonarQube's static analysis.

Code Representation

A tree structure where each node represents a construct in the source code (e.g., class, method, statement).

Static Analysis Engine

SonarQube's rules engine traverses the AST to identify code patterns or anti-patterns.

Custom Rule Interaction

When writing custom rules, you implement logic to traverse the AST and look for specific patterns.

Example: Java Code to AST
public class MyClass {
  public void myMethod() {
    int x = 10;
    if (x > 5) {
      System.out.println("Hello");
    }
  }
}
Key Takeaway

The AST transforms raw code into a structured, analyzable format, making complex static analysis possible for both built-in and custom rules.
