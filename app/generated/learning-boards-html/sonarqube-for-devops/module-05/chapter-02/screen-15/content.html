Key Concepts: Part 1

Essential terms for extending SonarQube.

Abstract Syntax Tree (AST)

A tree representation of the abstract syntactic structure of source code, used by SonarQube's analysis engine.

SonarQube Plugin

A JAR file containing custom rules, sensors, or other extensions deployed to a SonarQube server.

Custom Rule

A user-defined static analysis rule implemented within a SonarQube plugin to detect specific coding patterns.

Summary Takeaway

Custom rules, packaged in plugins, leverage the AST to extend SonarQube's analysis beyond its built-in capabilities, enforcing unique organizational standards.
