Fetching Quality Gate Status for a Project

Retrieve Real-time Quality Health with the API

Why Fetch Status?

Display real-time quality gate status on custom dashboards or trigger actions in external systems.

Endpoint Used

/api/qualitygates/project_status requires projectKey as a parameter.

Interpreting Output

The JSON output's projectStatus.status indicates 'OK' or 'ERROR', with details on failing conditions.

# Replace with your SonarQube host, project key, and API token
SONAR_HOST="http://localhost:9000"
PROJECT_KEY="my-java-project"
API_TOKEN="YOUR_API_TOKEN"

curl -s -u "${API_TOKEN}:" \
"${SONAR_HOST}/api/qualitygates/project_status?projectKey=${PROJECT_KEY}" | jq .
Key Takeaway

Programmatically fetching Quality Gate status is crucial for integrating real-time quality insights into external systems.
