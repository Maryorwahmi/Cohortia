Custom Reporting and Data Export

Pulling Raw Metrics for Advanced Analysis

Why Export Data?

Build custom reports, integrate with Business Intelligence (BI) tools, or perform advanced analysis beyond built-in capabilities.

Step 1: Discover Metrics

Use /api/metrics/search to get a list of all available metric keys (e.g., bugs, vulnerabilities, coverage).

Step 2: Fetch Measures

Use /api/measures/component with component (project key) and metricKeys to retrieve specific values.

SONAR_HOST="http://localhost:9000"
PROJECT_KEY="my-java-project"
API_TOKEN="YOUR_API_TOKEN"

# Fetch all available metrics
METRICS=$(curl -s -u "${API_TOKEN}:" \
"${SONAR_HOST}/api/metrics/search" | jq -r '.metrics[].key' | tr ' ' ',')

# Fetch measures for the project
curl -s -u "${API_TOKEN}:" \
"${SONAR_HOST}/api/measures/component?component=${PROJECT_KEY}&metricKeys=${METRICS}" | jq .
Key Takeaway

The two-step process of discovering metrics and fetching measures provides granular control for custom data export.
