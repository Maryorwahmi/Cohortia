Practical Example

Retrieving a List of Issues for a Project

Filtering and Exporting SonarQube Issues

Why Fetch Issues?

Integrate SonarQube issues into custom reports, project management tools, or trigger actions.

Endpoint & Parameters

/api/issues/search allows filtering by projectKeys, statuses, severities, and more.

Pagination Note

For large datasets, results are paginated; you'll need to iterate through pages to retrieve all issues.

SONAR_HOST="http://localhost:9000"
PROJECT_KEY="my-java-project"
API_TOKEN="YOUR_API_TOKEN"

curl -s -u "${API_TOKEN}:" \
"${SONAR_HOST}/api/issues/search?projectKeys=${PROJECT_KEY}&statuses=OPEN&severities=BLOCKER,CRITICAL" | jq .
Key Takeaway

The /api/issues/search endpoint provides flexible filtering to extract specific issue data for various integration needs.
