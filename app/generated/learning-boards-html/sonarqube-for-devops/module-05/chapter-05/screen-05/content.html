Secure Access with API Tokens

Authenticating Programmatic Requests to SonarQube

API Token Role

A secure, revocable string used to authenticate programmatic requests to the SonarQube Web API.

Authentication Flow

Generate a token in SonarQube, then pass it with each API call, typically in the Authorization header.

Security Best Practice

Always use environment variables or a secrets management system; never hardcode tokens directly in scripts.

Token Usage Example
# Using curl with API Token
SONAR_HOST="http://localhost:9000"
API_TOKEN="YOUR_API_TOKEN"

# Pass token as username, empty password
curl -s -u "${API_TOKEN}:" \
"${SONAR_HOST}/api/projects/search"

This example shows how to pass the API token securely using the -u flag in curl, treating the token as the username with an empty password.

Key Takeaway

API tokens are essential for secure programmatic access; always protect them like passwords and use environment variables.
