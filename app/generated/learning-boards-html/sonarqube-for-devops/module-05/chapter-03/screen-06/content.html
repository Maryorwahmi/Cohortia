Enterprise Integration

LDAP: Centralized User Management

Integrating SonarQube with your directory services

Single Source of Truth

Users log in with existing corporate credentials, centralizing identity management.

Shadow User Accounts

SonarQube creates a local representation of the user upon first login, synchronizing attributes.

Automated Group Sync

Optionally synchronize group memberships, simplifying permission assignment.

Key Takeaway

LDAP integration streamlines user management and enhances security by leveraging your existing corporate directory for authentication.

LDAP Configuration Overview
1. LDAP Server URL

Specify the address of your LDAP or Active Directory server (e.g., ldap://your-ldap-server:389).

2. Base DNs

Define the base distinguished names for user and group searches (e.g., ou=users,dc=example,dc=com).

3. User Search Filters

Configure filters to locate users within the directory (e.g., (&(objectClass=inetOrgPerson)(uid={login}))).

4. Bind Account (Optional)

Provide a service account (DN and password) for SonarQube to bind to LDAP and perform searches.

Common Misconception: SonarQube does not store LDAP user passwords. It delegates authentication to the LDAP server, only storing a local 'shadow' account for user attributes and permissions.
