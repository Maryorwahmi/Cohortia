SAML & OAuth: Seamless SSO

Integrating with modern identity providers and SCM platforms

SAML (Security Assertion Markup Language)

An XML-based standard for Single Sign-On (SSO) with enterprise identity providers.

  • Integrates with Okta, Azure AD, Keycloak.
  • Users authenticate once with their SSO provider.
  • Seamless access to SonarQube without re-entering credentials.
Example: Your company uses Okta for all application logins. SAML allows developers to access SonarQube directly from their Okta dashboard.

OAuth (Open Authorization)

An open standard for access delegation, used for authentication with SCM platforms.

  • Supports GitHub, GitLab, Bitbucket, Azure DevOps.
  • Simplifies login for developers already using these services.
  • Leverages existing SCM platform credentials.
Example: Developers can log into SonarQube using their GitHub account, avoiding a separate login.
Key Takeaway

SAML and OAuth integrations provide seamless SSO, enhancing user experience and centralizing authentication with modern identity and SCM providers.
