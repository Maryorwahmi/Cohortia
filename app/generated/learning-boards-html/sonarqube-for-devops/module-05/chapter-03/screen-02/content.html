Learning Objectives

What you'll achieve in this chapter

LearnUnderstandApplyMaster
01

Understand SonarQube Security

Grasp why securing your SonarQube instance and its data is critical. Recognize the risks of unauthorized access and misconfigured permissions.

VERIFIED COMPETENCY MILESTONE
02

Configure User Authentication

Learn to set up authentication using internal directories, LDAP, and SAML. Integrate SonarQube with your existing identity providers.

VERIFIED COMPETENCY MILESTONE
03

Manage Roles and Groups

Master the creation and management of roles and groups to effectively control user permissions across your SonarQube instance.

VERIFIED COMPETENCY MILESTONE
04

Identify Best Practices

Learn best practices for managing both project-level and global permissions, ensuring a secure and efficient access control model.

VERIFIED COMPETENCY MILESTONE
