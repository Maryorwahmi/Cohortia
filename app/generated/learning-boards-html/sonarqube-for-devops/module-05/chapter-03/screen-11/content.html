Automation Security

API Tokens for CI/CD Integration

Secure programmatic access to SonarQube

Password Alternative

Replaces user passwords for automated interactions, reducing security risks.

User-Specific Permissions

Tokens inherit the permissions of the user who generated them.

Revocable Control

Tokens can be revoked instantly from the SonarQube UI if compromised or no longer needed.

Key Takeaway

Always use API tokens instead of user passwords for CI/CD and automated SonarQube interactions to enhance security and control.

Using API Tokens in SonarScanner
sonar-scanner \
  -Dsonar.projectKey=my-java-project \
  -Dsonar.sources=. \
  -Dsonar.host.url=http://localhost:9000 \
  -Dsonar.login=YOUR_API_TOKEN
Important Note:

Replace YOUR_API_TOKEN with an actual token. Never hardcode tokens directly into scripts or commit them to version control.

Generation: Users can generate tokens from 'My Account > Security' in SonarQube. Admins can generate for other users.
