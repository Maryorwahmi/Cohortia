Permission Scopes

Global vs. Project Roles

Understanding the two levels of access control

Global Roles

Permissions that apply across the entire SonarQube instance.

  • Administer System: Full control over SonarQube.
  • Administer Quality Gates & Profiles: Manage global quality standards.
  • Create Projects: Ability to initiate new projects.
  • Browse: View all projects and analysis results.
Configuration: Administration > Security > Global Permissions

Project Roles

Permissions specific to a single SonarQube project.

  • Administer: Manage settings, quality gate for a specific project.
  • Browse: View analysis results for that project.
  • Code Viewer: Inspect source code within the project.
  • Issue Admin: Manage issues within the project.
Configuration: Project Settings > Permissions
Key Takeaway

Assign global roles sparingly; most users should have 'Browse' globally, with specific project permissions granted at the project level for granular control.
