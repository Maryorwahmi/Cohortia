Key Concepts: Permissions & Automation

Advanced security terms for SonarQube

SAML

An XML-based standard for exchanging authentication and authorization data between an identity provider and a service provider.

Global Permissions

Permissions that apply across the entire SonarQube instance, such as "Administer System" or "Create Projects."

Project Permissions

Permissions that are specific to a single SonarQube project, such as "Administer" or "Browse" for that project.

API Token

A secure, revocable token used for programmatic access to the SonarQube API, replacing username/password for automation.

Summary Takeaway

SAML enables SSO, global and project permissions provide layered access control, and API tokens secure automation workflows.
