Authorization Fundamentals

Controlling User Actions: Roles & Groups

Defining what authenticated users can do in SonarQube

Groups Simplify Management

Organize users into logical groups (e.g., Developers, Project Leads) to assign permissions collectively.

Roles Define Permissions

Predefined sets of permissions that dictate what actions a user or group can perform.

Global vs. Project Scope

Roles can apply across the entire SonarQube instance or be specific to individual projects.

Key Takeaway

Leverage groups and roles to implement a clear, scalable, and secure authorization model, ensuring users only have necessary access.

Authorization Hierarchy
SonarQube Instance

Top-level control

Groups

Global Roles

Analogy: Think of groups as departments in a company, and roles as job titles within those departments, each with specific responsibilities and access levels.
