Authentication Basics

Verifying User Identity

Exploring SonarQube's authentication methods

Internal User Directory

SonarQube's default method, storing user credentials in its own database. Simple for small teams but lacks enterprise integration.

  • Manual user management.
  • No integration with existing identity providers.
  • Suitable for initial setup or very small teams.
Example: A small startup with 5 developers might use this initially for quick setup.

External Authentication

Integrates with existing identity providers for centralized user management and Single Sign-On (SSO).

  • LDAP/Active Directory for enterprise environments.
  • SAML for SSO providers (Okta, Azure AD).
  • OAuth for SCM platforms (GitHub, GitLab).
Example: A large corporation uses LDAP to manage all employee logins, including SonarQube.
Key Takeaway

Choosing the right authentication method is crucial for balancing security, administrative overhead, and user experience in SonarQube.
