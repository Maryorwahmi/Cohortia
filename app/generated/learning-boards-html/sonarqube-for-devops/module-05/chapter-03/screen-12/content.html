Security Best Practices

Avoiding Common Security Mistakes

Safeguarding your SonarQube environment

Over-privileging Users

Granting excessive permissions, especially 'Administer System', increases risk.

Neglecting Groups

Managing permissions for individual users is inefficient and error-prone; always use groups.

Synchronization Failures

Forgetting to synchronize LDAP/SAML group changes can lead to outdated permissions.

Key Takeaway

Proactively address common security pitfalls by adhering to least privilege, leveraging groups, ensuring synchronization, and securely managing API tokens.

Critical Security Vulnerability
Hardcoding API Tokens

Directly embedding API tokens in scripts or committing them to version control is a severe security risk.

  • Exposure Risk: Tokens can be easily discovered.
  • Full Access: Compromised tokens grant full programmatic access.
  • Lack of Control: Difficult to revoke quickly if exposed.
Secure Alternative: Use environment variables or a secrets management system (e.g., HashiCorp Vault, AWS Secrets Manager) to inject API tokens at runtime in CI/CD pipelines. Revoke compromised tokens immediately.
