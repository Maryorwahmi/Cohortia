SonarQube Server HA: Community Edition Strategy
Implementing an active-passive setup with shared storage for resilience.
Key Components of Active-Passive HA
  • Shared Storage: For the data directory (Elasticsearch indices, plugins).
  • Load Balancer: Directs traffic to the active SonarQube server.
  • Multiple App Servers: One active, others passive, ready to take over.
  • Careful Orchestration: Ensures only one instance writes to shared storage at a time.
Key Takeaway

For SonarQube Community Edition, an active-passive HA setup with shared storage and a load balancer is the recommended approach, requiring careful management to prevent data corruption.
