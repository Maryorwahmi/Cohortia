Database Best Practices
Selecting the Optimal Database for SonarQube
Evaluating supported databases and avoiding pitfalls for production environments.
Supported Production Databases
PostgreSQL

Highly recommended for its performance, reliability, and open-source nature. Excellent for analytical workloads.

Microsoft SQL Server

Fully supported and a strong option for organizations within the Microsoft ecosystem.

Database to Avoid (Production)
Embedded H2 Database

Strictly for evaluation only. Lacks robustness, scalability, and HA features for production. Will lead to performance issues and data integrity risks.

Key Takeaway

Always use PostgreSQL or MS SQL Server for production SonarQube instances. Never use the embedded H2 database for anything beyond initial evaluation.
