Core Concept

What are Quality Profiles?

Quality Profiles define which static analysis rules are active during analysis.

Key Aspects of Quality Profiles

  • •**Rule Collection:** A set of static analysis rules for a language.
  • •**Language Specific:** Profiles are tailored per programming language.
  • •**Customizable:** Allows activation/deactivation and configuration of rules.
  • •**Default Profiles:** SonarQube provides 'Sonar Way' profiles as a baseline.
Key Takeaway

Quality Profiles are the rulebooks that dictate how SonarQube analyzes your code, offering granular control over which quality and security checks are performed.

Analogy: The Code Rulebook

Think of a Quality Profile as a comprehensive rulebook for your code. Just as a style guide dictates formatting and best practices for writing, a Quality Profile defines the specific static analysis rules that SonarQube will apply to your codebase. You can customize this rulebook to match your team's unique coding conventions, project requirements, and desired level of strictness.

Example: Customizing for Specific Conventions

Your team might have a specific convention, such as allowing empty methods for certain design patterns, which a default SonarQube rule might flag as an issue. With Quality Profiles, you can create a custom profile, inherit from a base profile like 'Sonar Way,' and then deactivate that specific rule ('S1186 - Methods should not be empty'). This ensures that SonarQube's analysis aligns with your team's agreed-upon practices, preventing false positives and maintaining developer trust in the tool.
