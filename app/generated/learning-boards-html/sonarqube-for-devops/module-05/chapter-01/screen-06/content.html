Managing Quality Gates in SonarQube UI

Navigate the SonarQube interface to create and assign Quality Gates.

Key Management Actions

  • •**Access:** Go to Administration > Quality Gates.
  • •**Create/Duplicate:** Start new gates or copy existing ones.
  • •**Assign:** Associate one Quality Gate per project.
  • •**Add Conditions:** Define metrics and thresholds (e.g., 'Bugs on New Code > 0').
Key Takeaway

Effective Quality Gate management involves careful configuration and assignment, ensuring conditions are challenging but achievable to foster continuous improvement.

Step-by-Step: Creating a Quality Gate

1

Navigate to **Administration > Quality Gates** in the SonarQube UI.

2

Click the **'Create'** button to define a new Quality Gate and give it a descriptive name.

3

Add conditions based on relevant metrics, ensuring they apply **'on New Code'** for focused enforcement.

4

Finally, assign your newly created Quality Gate to the desired project via **Project Settings > Quality Gate**.
