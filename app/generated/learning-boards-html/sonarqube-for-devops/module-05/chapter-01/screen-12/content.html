Synergy

Quality Gates and Profiles: A Powerful Partnership

Understand how these two features work together for comprehensive quality enforcement.

Interconnected Roles

  • •**Quality Profile:** Defines the 'rules of the game' (what constitutes an issue).
  • •**Quality Gate:** Defines the 'scorecard' (pass/fail criteria based on rules).
  • •**Automated Enforcement:** Together, they provide a robust, automated quality framework.
  • •**Consistent Standards:** Ensures high quality and reliability across all projects.
Key Takeaway

The combined power of Quality Gates and Quality Profiles creates a comprehensive and automated system for enforcing code quality, crucial for modern DevOps practices.

How They Work Together

1. Quality Profile Defines Rules

Specifies which static analysis rules are active and how they are configured.

2. Analysis Generates Metrics

SonarQube runs analysis based on the active rules, generating quality metrics.

3. Quality Gate Evaluates Metrics

Compares analysis results against its conditions to determine pass/fail status.
