Creating and Customizing Quality Profiles

Tailor your code analysis rules by creating and modifying profiles.

Key Customization Options

  • •**Inherit from Parent:** Start with a base profile (e.g., 'Sonar Way').
  • •**Activate/Deactivate Rules:** Enable or disable specific checks.
  • •**Change Severity:** Adjust the criticality of a rule.
  • •**Custom Parameters:** Configure rule-specific settings (e.g., max line length).
Key Takeaway

Custom Quality Profiles allow fine-grained control over SonarQube's analysis, ensuring it aligns with your team's specific coding standards and project needs.

Step-by-Step: Customizing a Profile

1

Navigate to **Administration > Quality Profiles**.

2

Click **'Create'** to make a new profile, inheriting from a relevant parent profile (e.g., 'Sonar Way' for Java).

3

Browse or search for rules, then **activate/deactivate** or **change severity** as needed.

4

Optionally, configure **custom parameters** for rules that support them (e.g., maximum line length).
