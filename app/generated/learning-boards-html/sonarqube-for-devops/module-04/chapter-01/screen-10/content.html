pipeline {
    agent any
    stages {
        // ... previous stages (Checkout, Build and SonarQube Analysis) ...
        stage('Quality Gate Check') {
            steps {
                script {
                    timeout(time: 5, unit: 'MINUTES') { // Give SonarQube time to process
                        def qg = waitForQualityGate()
                        if (qg.status != 'OK') {
                            error "Pipeline failed due to Quality Gate status: ${qg.status}"
                        }
                    }
                }
            }
        }
    }
}
Quality Gate Enforcement

Implementing Quality Gate Checks in Your Pipeline

Using waitForQualityGate() to ensure code quality standards are met.

What is waitForQualityGate()?

A Jenkins Pipeline step that polls SonarQube for analysis status and Quality Gate results.

Enforcing Quality Standards

If the Quality Gate status is not 'OK', the pipeline fails, preventing low-quality code deployment.

Immediate Feedback

Provides instant feedback on code quality, aligning with DevOps principles of continuous improvement.

Key Takeaway

The waitForQualityGate() step is vital for automating quality enforcement, ensuring that only code meeting defined standards progresses through your CI/CD pipeline.
