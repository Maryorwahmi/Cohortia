pipeline {
    agent any
    tools {
        // Ensure Maven is installed and configured in Jenkins Global Tool Configuration
        maven 'M3'
    }
    environment {
        // Define SONAR_PROJECT_KEY if not in sonar-project.properties
        // SONAR_PROJECT_KEY = 'my-java-app' 
        // SONAR_PROJECT_NAME = 'My Java Application'
    }
    stages {
        stage('Checkout') {
            steps {
                git branch: 'main', url: 'https://github.com/your-org/your-repo.git'
            }
        }
        stage('Build and SonarQube Analysis') {
            steps {
                script {
                    // This step uses the SonarQube server configured in Jenkins
                    // and injects the SONAR_AUTH_TOKEN from the specified credential ID.
                    withSonarQubeEnv('My SonarQube Server') { // Name of the SonarQube server configured in Jenkins
                        sh "mvn clean install sonar:sonar -Dsonar.projectKey=my-java-app -Dsonar.projectName='My Java Application'"
                    }
                }
            }
        }
    }
}
Practical Application

Building a SonarQube-Integrated Jenkinsfile

Stages for Checkout and Build in a Java Maven project.

Checkout Stage

Uses the git step to clone the source code repository, ensuring the latest code is available for analysis.

Build & Analysis Stage

Wraps Maven's clean install sonar:sonar command with withSonarQubeEnv to build the project and trigger SonarQube analysis.

Project Properties

-Dsonar.projectKey and -Dsonar.projectName are passed to identify the project in SonarQube.

Key Takeaway

The 'Build and SonarQube Analysis' stage combines code compilation with automated quality scanning, leveraging withSonarQubeEnv for secure and efficient integration.
