The Three Core SonarQube Tasks

01

SonarQubePrepare@5

Sets up environment variables and configuration for the SonarQube Scanner. Must run before the project build.

02

SonarQubeAnalyze@5

Executes the SonarQube Scanner. Must run after the project has been built.

03

SonarQubePublish@5

Queries Quality Gate status and publishes to Azure DevOps. (Covered next)

Key Takeaway

The SonarQubePrepare task is crucial for setting up the analysis environment and must always precede your project's build step.
