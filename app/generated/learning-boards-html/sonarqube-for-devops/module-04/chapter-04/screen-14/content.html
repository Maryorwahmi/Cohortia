Key Concepts

Reinforcing your understanding of SonarQube pipeline tasks.

SonarQubePrepare@5

An Azure DevOps task that initializes the SonarQube analysis configuration, setting up the scanner environment.

SonarQubeAnalyze@5

An Azure DevOps task that executes the SonarQube Scanner, performing the actual static code analysis.

SonarQubePublish@5

An Azure DevOps task that retrieves and publishes the SonarQube Quality Gate status, potentially failing the pipeline.

Key Takeaway

The Prepare, Analyze, and Publish tasks are the core components for integrating SonarQube analysis and quality gate enforcement within Azure DevOps pipelines.
