Key Concepts

Essential terms and ideas from this chapter.

Azure DevOps Pipelines

Microsoft's CI/CD service for automating builds, tests, and deployments, crucial for modern software delivery.

SonarQube Extension

An extension from the Visual Studio Marketplace that adds SonarQube-specific tasks to Azure DevOps pipelines.

SonarQube Service Connection

A secure connection configured in Azure DevOps to allow pipelines to interact with a SonarQube server.

Key Takeaway

Azure DevOps Pipelines, the SonarQube Extension, and the SonarQube Service Connection are the foundational elements for integrating automated code quality into your CI/CD workflows.
