Queries Quality Gate status and publishes to Azure DevOps. Can fail the pipeline.

pollingTimeoutSec: Prevents premature pipeline termination.
Key Takeaway

The SonarQubePublish task is vital for enforcing quality standards by failing the pipeline if the Quality Gate is not met, using pollingTimeoutSec to ensure sufficient waiting time.
