Why Pull Request Analysis?

Targeted Feedback

Analyzes only the new code introduced in the pull request.

PR Decoration

Adds comments and status updates directly to the Azure DevOps PR interface.

Prevent Issues Early

Catch and fix bugs/vulnerabilities before merging to main.

Key Takeaway

Pull Request analysis with SonarQube provides early, targeted feedback on new code changes, enhancing code review and preventing issues from entering the main codebase.

Configuring PR Analysis

- task: SonarQubePrepare@5
  displayName: 'Prepare SonarQube Analysis'
  inputs:
    SonarQube: 'My SonarQube Server'
    projectKey: '$(sonarProjectKey)'
    projectName: '$(sonarProjectName)'
    projectVersion: '1.0.$(Build.BuildId)'
    scanMode: 'CLI'
    extraProperties: |
      sonar.pullrequest.key=$(System.PullRequest.PullRequestId)
      sonar.pullrequest.branch=$(System.PullRequest.SourceBranch)
      sonar.pullrequest.base=$(System.PullRequest.TargetBranch)
      sonar.pullrequest.github.repository=$(Build.Repository.Name) # If using GitHub
