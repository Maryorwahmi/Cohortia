Why Install the Extension?

Enables SonarQube Tasks

Provides the necessary build/release tasks for SonarQube integration.

Seamless Integration

Allows Azure DevOps to understand and execute SonarQube commands.

Key Takeaway

Installing the SonarQube extension from the Visual Studio Marketplace is the foundational step to enable SonarQube tasks in your Azure DevOps pipelines.

Installation Steps

01

Navigate to Organization Settings

Go to your Azure DevOps organization settings.

02

Access Extensions

Select 'Extensions' then 'Browse marketplace'.

03

Search & Install

Search for 'SonarQube' and install the official extension.
