YAML Pipeline Tasks

- task: SonarQubePrepare@5
  displayName: 'Prepare SonarQube Analysis'
  inputs:
    SonarQube: 'My SonarQube Server'
    projectKey: '$(sonarProjectKey)'
    projectName: '$(sonarProjectName)'
    projectVersion: '1.0.$(Build.BuildId)'

- task: DotNetCoreCLI@2
  displayName: 'Build Project'
  inputs:
    command: 'build'
    projects: '**/*.csproj'

- task: DotNetCoreCLI@2
  displayName: 'Run Tests'
  inputs:
    command: 'test'
    projects: '**/*.csproj'

- task: SonarQubeAnalyze@5
  displayName: 'Run SonarQube Analysis'

- task: SonarQubePublish@5
  displayName: 'Publish Quality Gate Result'
  inputs:
    pollingTimeoutSec: '300'

Task Roles & Importance

Prepare Analysis

SonarQubePrepare configures the scanner with server details and project metadata.

Build & Test

DotNetCoreCLI tasks compile code and run tests, providing artifacts for analysis.

Analyze & Publish

SonarQubeAnalyze runs the scanner, and SonarQubePublish enforces the Quality Gate.

Key Takeaway

Each SonarQube task, along with standard build and test steps, plays a critical role in a well-orchestrated pipeline to ensure continuous code quality and enforcement.
