Preparing Your Environment for Analysis

Checkout, Java Setup, and SonarQube Cache

Essential Setup Steps

  • •
    `actions/checkout@v3`: Fetches your repository code. fetch-depth: 0 is vital for full Git history, enabling accurate SonarQube branch/PR analysis.
  • •
    `actions/setup-java@v3`: Configures the Java Development Kit (JDK) environment, necessary for Java projects and the SonarQube Scanner.
  • •
    `actions/cache@v3`: Caches SonarQube-related packages and dependencies, significantly speeding up subsequent workflow runs.
Key Takeaway

Properly configure your GitHub Actions environment with actions/checkout@v3 (with fetch-depth: 0), actions/setup-java, and actions/cache for efficient SonarQube analysis.

.github/workflows/sonarqube.ymlYAML
jobs:
  build_and_analyze:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
        with:
          fetch-depth: 0 # Required for SonarQube's branch/PR analysis

      - name: Set up JDK 11
        uses: actions/setup-java@v3
        with:
          java-version: '11'
          distribution: 'temurin'
          cache: maven

      - name: Cache SonarQube packages
        uses: actions/cache@v3
        with:
          path: ~/.sonar/cache
          key: ${{ runner.os }}-sonar
          restore-keys: ${{ runner.os }}-sonar

These steps ensure your code and environment are ready for SonarQube.
