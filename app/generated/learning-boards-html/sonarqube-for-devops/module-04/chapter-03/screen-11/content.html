Troubleshooting

Avoiding Pitfalls in SonarQube Workflows

Diagnosing Common Integration Issues

Key Troubleshooting Areas

  • •
    Git History: Ensure actions/checkout@v3 uses fetch-depth: 0 for complete analysis.
  • •
    Secrets: Verify SONAR_TOKEN and SONAR_HOST_URL are correct and properly referenced.
  • •
    PR Decoration: Confirm GITHUB_TOKEN is passed and SonarQube server has GitHub integration configured.
  • •
    Workflow Logs: Utilize the GitHub Actions 'Actions' tab for detailed debugging output.
Key Takeaway

Avoid fetch-depth: 0 omission, incorrect secrets, and missing GITHUB_TOKEN for PR decoration. Use GitHub Actions logs for effective debugging.

Common Mistakes & Solutions

Mistake: Missing fetch-depth: 0

Impact: Incomplete branch/PR analysis, missing new code detection.

Solution: Add with: fetch-depth: 0 to actions/checkout.

Mistake: Incorrect SonarQube Secrets

Impact: Authentication failures, scanner cannot connect to server.

Solution: Verify SONAR_TOKEN and SONAR_HOST_URL in GitHub Secrets and workflow.

Mistake: PR Decoration Not Working

Impact: No comments/status checks on GitHub Pull Requests.

Solution: Ensure GITHUB_TOKEN is passed and SonarQube server is configured for GitHub integration.
