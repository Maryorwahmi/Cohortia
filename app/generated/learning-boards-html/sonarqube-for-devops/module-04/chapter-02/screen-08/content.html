Executing the SonarQube Scan Command

Understanding sonar-scanner Parameters and Project Identification

sonar-scanner Command Example
sonar-scanner \
  -Dsonar.projectKey=$SONAR_PROJECT_KEY \
  -Dsonar.projectName="$SONAR_PROJECT_NAME" \
  -Dsonar.sources=. \
  -Dsonar.host.url=$SONAR_HOST_URL \
  -Dsonar.login=$SONAR_TOKEN \
  -Dsonar.sourceEncoding=UTF-8 \
  -Dsonar.javascript.lcov.reportPaths=coverage/lcov.info

Project Identification

-Dsonar.projectKey (unique ID) and -Dsonar.projectName (display name) are essential for SonarQube to correctly identify and group analysis results.

Credential Injection

$SONAR_HOST_URL and $SONAR_TOKEN are automatically injected from GitLab CI/CD variables, providing secure access to the SonarQube server.

sonar-project.properties

Many -D flags can be omitted if a sonar-project.properties file exists in the repository root, centralizing project-specific configurations.

Key Takeaway

The sonar-scanner command uses -D flags for configuration, with project keys and secure variables being critical for accurate analysis reporting.
