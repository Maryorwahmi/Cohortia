Troubleshooting Common SonarQube Integration Issues

Diagnosing and Resolving Pipeline Failures

Incorrect CI/CD Variables

**Issue:** Authentication failures due to misspelled SONAR_HOST_URL or SONAR_TOKEN, or variables not marked 'Protected'/'Masked'.
**Resolution:** Verify variable names, scope (project-level), and security settings in GitLab CI/CD variables.

Docker Image Dependencies

**Issue:** sonar-scanner fails because Java Runtime Environment (JRE) is missing in the Docker image.
**Resolution:** Install Java (e.g., apk add openjdk11) or use a custom image with Java and scanner pre-installed.

Project Key Mismatch

**Issue:** Analysis results are not associated with the correct project on SonarQube server.
**Resolution:** Ensure sonar.projectKey in .gitlab-ci.yml (or sonar-project.properties) exactly matches the key on SonarQube.

Key Takeaway

Always review GitLab job logs for direct feedback, and systematically check CI/CD variables, Docker image dependencies, and project key consistency to resolve SonarQube integration issues.
