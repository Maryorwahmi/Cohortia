Defining SonarQube Properties in pom.xml

Configure essential SonarQube properties within your Maven project's pom.xml to control analysis behavior and server connection.

Key Properties Explained
  • sonar.projectKey: Unique identifier for your project on SonarQube.
  • sonar.host.url: URL of your SonarQube server instance.
  • sonar.login: Authentication token for connecting to SonarQube (use environment variables in CI/CD).
  • sonar.java.binaries: Path to compiled Java bytecode for accurate analysis.
Security Alert

Never hardcode sonar.login (authentication token) directly in pom.xml for production environments. Always use secure environment variables in CI/CD pipelines.

pom.xml Properties Example

<project>
    <!-- ... -->
    <properties>
        <sonar.projectKey>my-maven-project</sonar.projectKey>
        <sonar.organization>my-organization-id</sonar.organization>
        <sonar.host.url>http://localhost:9000</sonar.host.url>
        <sonar.login>YOUR_SONARQUBE_TOKEN</sonar.login>
        <sonar.java.binaries>target/classes</sonar.java.binaries>
    </properties>
    <!-- ... -->
</project>
