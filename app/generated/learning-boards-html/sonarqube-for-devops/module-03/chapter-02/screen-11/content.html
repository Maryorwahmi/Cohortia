Key SonarQube Configuration Parameters

These properties are crucial for correctly identifying your project, connecting to the SonarQube server, and ensuring accurate analysis.

sonar.projectKey

A unique identifier for your project on the SonarQube server. Essential for associating analysis results.

sonar.host.url

The URL of your SonarQube server instance (e.g., http://localhost:9000). Crucial for scanner connectivity.

sonar.login

The authentication token used to connect to the SonarQube server. Must be kept secure and passed via environment variables in CI/CD.

sonar.projectVersion

The version of the project being analyzed. Useful for tracking changes and historical analysis across releases.

sonar.java.binaries

Path to the directory containing compiled Java bytecode. Absolutely essential for accurate and deep static analysis of Java code.

sonar.sources / sonar.tests

Comma-separated lists of paths to source and test code directories. Often auto-detected by plugins but can be specified explicitly.

Key Takeaway

Correctly configuring these essential properties is fundamental for SonarQube to accurately identify your project, connect to the server, and perform a comprehensive code analysis.
