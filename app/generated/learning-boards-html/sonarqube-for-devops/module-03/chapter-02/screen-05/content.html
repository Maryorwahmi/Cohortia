Introducing the sonar-maven-plugin

The sonar-maven-plugin is the official plugin for integrating SonarQube analysis into Maven-based Java projects.

Key Aspects
  • Official Integration: Provided by SonarSource for seamless Maven compatibility.
  • Dynamic Resolution: Often resolved by Maven without explicit pom.xml declaration.
  • sonar:sonar Goal: The primary command to trigger analysis.
  • Data Collection: Gathers source code, compiled classes, and project metadata.
Key Takeaway

The sonar-maven-plugin simplifies SonarQube integration by allowing Maven to manage the analysis process, typically invoked via the sonar:sonar goal.

Maven Plugin Declaration (Optional)

<project>
    <!-- ... -->
    <build>
        <plugins>
            <plugin>
                <groupId>org.sonarsource.scanner.maven</groupId>
                <artifactId>sonar-maven-plugin</artifactId>
                <version>3.9.1.2184</version> <!-- Use latest -->
            </plugin>
        </plugins>
    </build>
    <!-- ... -->
</project>
Goal Explained

The sonar:sonar goal is the command that triggers the SonarQube analysis. It can be run directly from the command line, often without needing explicit plugin declaration in pom.xml.
