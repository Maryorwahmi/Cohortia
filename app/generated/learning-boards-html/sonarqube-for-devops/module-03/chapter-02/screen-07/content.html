Running SonarQube Analysis with Maven

Execute the mvn clean install sonar:sonar command to trigger SonarQube analysis for your Maven project.

Command Breakdown
  • clean: Removes previous build artifacts.
  • install: Compiles, tests, and packages the project, generating necessary binaries.
  • sonar:sonar: Invokes the SonarQube analysis plugin.
  • -Dproperty=value: Overrides or sets SonarQube properties on the fly.
Key Takeaway

Always run clean install before sonar:sonar to ensure a complete build and accurate analysis. Use -D flags for secure property management in CI/CD.

Maven Analysis Command

mvn clean install sonar:sonar \ 
    -Dsonar.projectKey=my-maven-project \ 
    -Dsonar.host.url=http://localhost:9000 \ 
    -Dsonar.login=YOUR_SONARQUBE_TOKEN
CI/CD Best Practice

In a CI/CD pipeline, YOUR_SONARQUBE_TOKEN should be passed as a secure environment variable, not hardcoded, to protect sensitive credentials.
