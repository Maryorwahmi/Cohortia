Key Concepts

Here are the most important ideas from this chapter:

Maven Plugin

The sonar-maven-plugin is the official plugin for integrating SonarQube analysis into Maven-based Java projects.

Gradle Plugin

The sonarqube-gradle-plugin is the official plugin for integrating SonarQube analysis into Gradle-based Java projects.

sonar:sonar Goal

The specific Maven goal executed to trigger a SonarQube analysis from the command line.

Chapter Summary

Integrating SonarQube with Maven and Gradle via their respective plugins enables automated code quality checks, making quality an inherent part of your build process.
