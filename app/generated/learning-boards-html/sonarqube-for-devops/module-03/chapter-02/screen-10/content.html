Running SonarQube Analysis with Gradle

Execute the gradle clean build sonarqube command to trigger SonarQube analysis for your Gradle project.

Command Breakdown
  • clean: Clears the build directory.
  • build: Compiles, tests, and packages the project.
  • sonarqube: Executes the SonarQube analysis task.
  • -Dproperty=value: Overrides or sets SonarQube properties from the command line.
Key Takeaway

Ensure clean build is executed before the sonarqube task to provide all necessary compiled artifacts for a complete analysis. Command-line properties are ideal for CI/CD.

Gradle Analysis Command

gradle clean build sonarqube \ 
    -Dsonar.projectKey=my-gradle-project \ 
    -Dsonar.host.url=http://localhost:9000 \ 
    -Dsonar.login=YOUR_SONARQUBE_TOKEN
CI/CD Best Practice

Similar to Maven, pass YOUR_SONARQUBE_TOKEN as a secure environment variable in CI/CD to prevent hardcoding sensitive information.
