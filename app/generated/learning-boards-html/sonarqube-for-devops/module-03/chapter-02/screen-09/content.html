Configuring SonarQube Properties in build.gradle

Define SonarQube properties within the sonarqube block in your Gradle project's build.gradle file.

Property Configuration
  • Properties are set within the sonarqube { properties { ... } } block.
  • Use property "key", "value" syntax.
  • Essential properties include sonar.projectKey, sonar.host.url, and sonar.login.
  • For multi-module projects, specific source/binary paths might be needed.
Security Best Practice

Always retrieve sonar.login from an environment variable (e.g., System.getenv("SONAR_TOKEN")) in build.gradle for production builds.

build.gradle Properties Example

sonarqube {
    properties {
        property "sonar.projectKey", "my-gradle-project"
        property "sonar.organization", "my-organization-id"
        property "sonar.host.url", "http://localhost:9000"
        property "sonar.login", "YOUR_SONARQUBE_TOKEN"
        // property "sonar.sources", "src/main/java"
        // property "sonar.java.binaries", "build/classes/java/main"
    }
}
