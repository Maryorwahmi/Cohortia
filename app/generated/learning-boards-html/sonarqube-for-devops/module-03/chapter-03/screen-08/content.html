.NET Analysis Step 3

Finalizing .NET Analysis: dotnet sonarscanner end

Sending Collected Data to the SonarQube Server

dotnet sonarscanner end /d:sonar.login="YOUR_SONARQUBE_TOKEN"
Remember to pass the login token again for authentication.

Purpose of 'End' Command

Concludes the analysis, packages all collected data, and securely sends it to the SonarQube server for processing and display.

Common Mistakes to Avoid

  • Forgetting the `begin` or `end` step.
  • Not performing a full `dotnet build` in between.
  • Missing `sonar.login` token on the `end` command.
Key Takeaway

The `end` command is crucial for finalizing the analysis and transmitting data. Ensure all three steps of the 'begin-build-end' sequence are correctly executed.
