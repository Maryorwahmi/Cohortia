Node.js Analysis Execution

Executing SonarScanner CLI for Node.js Projects

Ensuring Pre-Analysis Steps for Comprehensive Metrics

# 1. Ensure dependencies are installed
npm install

# 2. Generate tests and coverage reports (e.g., LCOV)
npm test -- --coverage

# 3. Run the SonarScanner CLI
sonar-scanner \
    -Dsonar.projectKey=my-nodejs-project \
    -Dsonar.host.url="http://localhost:9000" \
    -Dsonar.login="YOUR_SONARQUBE_TOKEN"

Pre-Analysis Steps are Critical

Before running `sonar-scanner`, ensure all dependencies are installed and, crucially, that code coverage and test reports are generated in the expected formats.

Common Pitfalls

  • Not generating coverage reports (e.g., LCOV).
  • Incorrect paths for `sonar.javascript.lcov.reportPaths` in `sonar-project.properties`.
  • Forgetting to install `sonar-scanner` CLI or add it to PATH.
Key Takeaway

Successful Node.js analysis with SonarQube depends heavily on correctly executing pre-analysis steps, especially generating comprehensive test and coverage reports.
