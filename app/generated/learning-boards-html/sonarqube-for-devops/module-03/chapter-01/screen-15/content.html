Key Concepts

Advanced Terms for Quality Enforcement

Quality Profile

A collection of static analysis rules that SonarQube applies to a project, defining its coding standards.

Technical Debt

The implied cost of additional rework caused by choosing an easy but limited solution now instead of a better approach.

Feedback Loop

The cycle of providing information back to developers about their code changes, enabling them to make rapid improvements.

Summary Takeaway

Quality Profiles define coding standards, Technical Debt quantifies rework, and rapid Feedback Loops drive continuous improvement in DevOps.
