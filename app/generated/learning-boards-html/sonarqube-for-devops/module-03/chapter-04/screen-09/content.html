GitHub Integration

Step 3: Project-Level PR Decoration Settings

Enabling Decoration for Specific Projects

Navigate to Project Settings

For the desired SonarQube project, go to Project Settings > General Settings > Pull Request.

Select GitHub Configuration

Choose the GitHub configuration you previously created (e.g., 'MyGitHub') from the dropdown menu.

Enter Repository Identifier

Provide the GitHub repository in owner/repo-name format (e.g., my-org/my-project) and enable 'Pull Request decoration'.

Key Takeaway

Project-level configuration links a specific SonarQube project to its GitHub repository and activates PR decoration, making it visible in the SCM.

Project Settings Flow
1. Select ProjectFrom SonarQube dashboard
2. Project SettingsTop right corner
3. General Settings > Pull RequestLeft sidebar
4. Configure & EnableSelect config, add repo ID, check box

Misconception: A common mistake is forgetting to enable 'Pull Request decoration' at the project level, even after global configuration.
