GitHub Integration

Step 1: Generating a GitHub Personal Access Token (PAT)

Granting SonarQube Access to Your Repository

What is a PAT?

A Personal Access Token is a secure credential that allows applications like SonarQube to authenticate and interact with your GitHub account on your behalf.

Required Scopes

For private repositories, use the repo scope. For public repositories, the public_repo scope is sufficient. These grant SonarQube permission to read and write PR comments/statuses.

Security Best Practice

Always generate PATs with the minimum necessary permissions and store them securely, typically in your CI/CD system's secret management.

Key Takeaway

A GitHub PAT with correct scopes is the foundational credential for SonarQube to interact with your repositories and decorate Pull Requests.

GitHub PAT Generation Steps
1. Navigate to GitHub Settings
2. Developer Settings > Personal Access Tokens
3. Generate New Token (Classic)
4. Select `repo` or `public_repo` Scope
