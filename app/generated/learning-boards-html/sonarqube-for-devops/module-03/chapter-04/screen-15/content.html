Key Concepts

SonarQube Properties and Quality Gates

sonar.pullrequest.key

A SonarQube property identifying the unique ID of the Pull Request being analyzed.

sonar.pullrequest.branch

A SonarQube property specifying the source branch of the Pull Request.

sonar.pullrequest.base

A SonarQube property specifying the target (base) branch of the Pull Request, used for comparing changes.

Summary Takeaway

The sonar.pullrequest.* properties are vital for contextual analysis, while Quality Gate Status Checks enforce code quality standards before merging.
