Common SCM Integration and PR Decoration Issues

Diagnosing and Resolving Problems

Common Mistakes

Incorrect SCM Token Permissions

PATs (e.g., GitHub, GitLab) lacking sufficient scope to read repo info and post comments/statuses.

Missing `sonar.pullrequest.*` Properties

Failure to pass sonar.pullrequest.key, .branch, or .base to the scanner in the CI pipeline.

Incorrect Repository/Project Identifier

Mismatch between SonarQube project settings and the actual SCM repository identifier (e.g., owner/repo or numeric ID).

Troubleshooting Checklist
1. Verify SCM Token Permissions
2. Check CI Pipeline Variables
3. Confirm SonarQube Project Settings
4. Network Connectivity & SonarQube Version
Key Takeaway

Most integration issues stem from incorrect permissions, missing CI properties, or misconfigured project identifiers; a systematic check resolves them.
