Integration Mechanics

How SonarQube Communicates with SCMs

API Tokens and Webhooks for Seamless Interaction

API Tokens

SonarQube uses Personal Access Tokens (PATs) from SCMs to authenticate and interact with their APIs, enabling it to post comments and status updates.

CI Pipeline Trigger

When a PR is opened or updated, the CI pipeline is triggered to run a SonarQube analysis on the PR's specific branch.

Post-Analysis Feedback

After analysis, SonarQube uses the SCM API to post comments, update status checks, and report the Quality Gate status directly to the PR.

Key Takeaway

SonarQube integrates with SCMs via API tokens and CI pipeline triggers to embed analysis results directly into PRs, closing the feedback loop.
