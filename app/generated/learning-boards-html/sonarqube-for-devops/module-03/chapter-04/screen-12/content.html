PR Decoration in Action

What Developers See: Feedback on Your Pull Request

Real-time Quality Insights in Your SCM

Overall Quality Gate Status

A clear pass/fail status directly on the PR, often as a required status check that can block merges.

Comments on New Issues

SonarQube adds comments directly to the relevant lines of code in the PR's file changes if new issues are introduced.

Summary Comment

A concise summary of the analysis, including metrics for new code, is often added as a single comment to the PR.

Key Takeaway

PR decoration provides comprehensive, in-context feedback directly on the SCM interface, making code quality issues immediately visible and actionable for developers.
