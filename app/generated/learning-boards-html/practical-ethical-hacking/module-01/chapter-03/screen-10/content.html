Removing Files and Directories

rm and the Importance of Extreme Caution

rm: Remove Files

Deletes specified files. Simple for single files, but powerful with options.

-r: Recursive Deletion

Required to delete directories and their entire contents. Use with extreme care.

-f: Force Deletion

Bypasses confirmation prompts, making deletion immediate and irreversible. Highly dangerous.

Key Takeaway

Always double-check rm commands, especially with -r and -f, as deletions are permanent and can lead to system-wide data loss if misused.

kali@kali:~$
# Create a dummy file and directory
touch delete_me.txt
mkdir empty_dir
mkdir -p full_dir/subdir
touch full_dir/subdir/file.txt

# Delete a single file
rm delete_me.txt

# Attempt to delete a non-empty directory (will fail without -r)
rm full_dir
# Expected output: rm: cannot remove 'full_dir': Is a directory

# Delete a directory and its contents recursively
rm -r empty_dir
rm -r full_dir

# DANGER: NEVER RUN THIS ON A LIVE SYSTEM OR WITHOUT UNDERSTANDING
# rm -rf /
Critical Warning: `rm -rf /`

Executing rm -rf / will attempt to delete your entire Linux filesystem. This command is extremely destructive and should NEVER be run unless you fully understand the consequences and accept complete data loss.
