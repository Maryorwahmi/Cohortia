Your Network Identity

Inspecting Interfaces and Testing Connectivity

ip a: IP Address Information

Displays network interface details, including IP addresses, MAC addresses, and interface status. Replaces ifconfig.

ping: Test Network Connectivity

Sends ICMP echo requests to a host to check if it's reachable and measure round-trip time.

Key Takeaway

ip a and ping are fundamental for initial network reconnaissance, allowing you to identify your own network configuration and verify connectivity to target systems.

kali@kali:~$
# Display network interface information
ip a
# Example output (showing IP for eth0):
# 2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 ...
#     inet 192.168.56.102/24 brd 192.168.56.255 scope global dynamic eth0

# Test connectivity to a target host
ping 192.168.56.101
# Expected output:
# PING 192.168.56.101 (192.168.56.101) 56(84) bytes of data.
# 64 bytes from 192.168.56.101: icmp_seq=1 ttl=64 time=0.500 ms
# ^C
# --- 192.168.56.101 ping statistics ---
# 2 packets transmitted, 2 received, 0% packet loss, time 1001ms
Pro Tip: Continuous Ping

On Linux, ping runs indefinitely until stopped with Ctrl+C. On Windows, use ping -t for continuous ping.
