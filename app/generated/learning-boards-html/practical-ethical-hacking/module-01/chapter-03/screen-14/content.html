Network Analysis

What's Listening on the Network?

Uncovering Active Connections with netstat

netstat: Network Statistics

Displays network connections, routing tables, and interface statistics.

-tulnp Flags Explained

-t (TCP), -u (UDP), -l (listening), -n (numerical), -p (process ID/name).

Key Takeaway

netstat -tulnp is a powerful command for identifying active network services and their associated processes, crucial for understanding a system's attack surface.

kali@kali:~$
# Show listening TCP/UDP ports and programs
sudo netstat -tulnp
# Example output (truncated):
# Proto Recv-Q Send-Q Local Address           Foreign Address         State       PID/Program name
# tcp        0      0 0.0.0.0:22              0.0.0.0:*               LISTEN      1234/sshd
# tcp        0      0 127.0.0.1:631           0.0.0.0:*               LISTEN      5678/cupsd
# udp        0      0 0.0.0.0:68              0.0.0.0:*                           910/dhclient
Common Use Case: Identifying Open Ports

Ethical hackers use netstat to quickly identify open ports and the services running on them, which can indicate potential vulnerabilities or misconfigurations.
