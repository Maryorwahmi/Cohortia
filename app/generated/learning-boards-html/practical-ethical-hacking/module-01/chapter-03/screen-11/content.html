Who Can Do What?

Controlling File Access with chmod

Permissions: Read, Write, Execute

r (read), w (write), x (execute) define actions. Represented by 4, 2, 1 respectively.

Categories: Owner, Group, Others

Permissions are set independently for the file's owner, its assigned group, and all other users.

chmod: Change File Mode

Modifies file permissions using symbolic (e.g., +x) or octal (e.g., 755) notation.

Key Takeaway

chmod is essential for managing file access, ensuring proper security and functionality by controlling who can read, write, or execute files.

kali@kali:~$
# Create a dummy script
touch myfile.sh

# Check initial permissions
ls -l myfile.sh
# Expected output: -rw-r--r-- 1 kali kali 0 Apr 14 10:00 myfile.sh
# (Owner: read/write, Group: read, Others: read)

# Make the script executable for owner, group, and others
chmod 755 myfile.sh
ls -l myfile.sh
# Expected output: -rwxr-xr-x 1 kali kali 0 Apr 14 10:00 myfile.sh
# (Owner: rwx, Group: rx, Others: rx)

# Remove write permission for group and others
chmod 744 myfile.sh
ls -l myfile.sh
# Expected output: -rwxr--r-- 1 kali kali 0 Apr 14 10:00 myfile.sh
Pro Tip: Symbolic Mode

Instead of octal, you can use symbolic mode: chmod u+x myfile.sh (add execute for user), chmod go-w myfile.sh (remove write for group/others).
