What's in the Directory?

Using ls to List Files and Directories

ls: List Directory Contents

Displays files and subdirectories in the current location. Simple and quick overview.

ls -l: Long Listing Format

Provides detailed information: permissions, owner, group, size, and modification date.

ls -a: Show All Files

Includes hidden files (those starting with a dot), which are often configuration files.

Key Takeaway

The ls command, especially with -l and -a flags, is indispensable for understanding the contents and attributes of any directory.

kali@kali:~$
# List files in current directory
ls
# Example output:
# Documents Downloads Pictures

# Long listing format
ls -l
# Example output:
# drwxr-xr-x 2 kali kali 4096 Apr 14 10:00 Documents
# -rw-r--r-- 1 kali kali 100 Apr 14 10:00 myfile.txt

# Show hidden files
ls -a
# Example output:
# . .. .bashrc .config Documents

# Combine flags for detailed view
ls -la /home/kali
# Example output:
# drwxr-xr-x 2 kali kali 4096 Apr 14 10:00 .ssh
Pro Tip: Recursive Listing

Use ls -R to list the contents of directories and their subdirectories recursively. Be cautious in large directories!
