System Management

Controlling Your Kali Environment

Package, Process, and Manual Management

apt: Package Management

Installs, updates, and removes software on Debian-based systems like Kali. Use update, upgrade, install.

ps aux & kill: Process Control

ps aux lists all running processes; kill <PID> terminates a process by its ID.

man: Manual Pages

Provides detailed documentation and usage instructions for almost any Linux command.

Key Takeaway

These commands provide comprehensive control over your Kali Linux system, from managing software and processes to accessing detailed command documentation.

kali@kali:~$
# Update package lists
sudo apt update

# Install a new package (e.g., Nmap)
sudo apt install nmap

# List all running processes and filter for Firefox
ps aux | grep firefox
# Example output: kali      12345  0.5  2.0 123456 78900 ?        Sl   10:00   0:05 /usr/lib/firefox/firefox

# Kill a process (replace 12345 with actual PID)
kill 12345

# View manual page for 'ls' command
man ls
# (Press 'q' to quit man page)
Pro Tip: `kill -9` for Stubborn Processes

If a process doesn't respond to a regular kill command, kill -9 <PID> sends a forceful signal that cannot be ignored, terminating the process immediately.
