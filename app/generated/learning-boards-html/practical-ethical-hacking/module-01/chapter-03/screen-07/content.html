Peeking Inside Files

cat and less for Displaying File Contents

cat: Display Entire File

Outputs the full content of a file to standard output. Best for small files.

less: View File Page by Page

Allows interactive viewing of large files, with scrolling, searching, and navigation. Press 'q' to quit.

Key Takeaway

Use cat for quick views of small files and less for interactive, paginated exploration of larger files, especially logs or configuration data.

kali@kali:~$
# Display content of /etc/hosts
cat /etc/hosts
# Example output:
# 127.0.0.1       localhost
# 127.0.1.1       kali

# View a large log file interactively
less /var/log/syslog
# (Inside less, press 'q' to quit)
# (Type '/' then search term, e.g., /error, then Enter to search)

# Example of searching within less:
# /Failed password
# (Press 'n' for next match, 'N' for previous)
Pro Tip: Combining Commands

You can pipe the output of one command into another. For example, cat largefile.txt | less achieves the same as less largefile.txt.
