Organizing Your Workspace

Copying and Moving Files and Directories

cp: Copy Files and Directories

Duplicates a source file or directory to a specified destination. Use -r for directories.

mv: Move or Rename Files and Directories

Moves a file/directory to a new location or renames it. The original is removed.

Key Takeaway

cp and mv are fundamental for organizing your files, whether for backups, restructuring, or renaming, ensuring an efficient workflow.

kali@kali:~$
# Create a dummy file
touch my_script.sh

# Copy file to /tmp directory
cp my_script.sh /tmp/
ls /tmp/
# Expected output: my_script.sh (among others)

# Rename the file
mv my_script.sh old_script.sh
ls
# Expected output: old_script.sh

# Move a directory (requires -r)
mkdir my_tools
cp -r my_tools /opt/
ls /opt/
# Expected output: my_tools (among others)
Common Mistake: Forgetting -r

When copying directories, always remember the -r (recursive) flag. Without it, cp will fail to copy directory contents.
