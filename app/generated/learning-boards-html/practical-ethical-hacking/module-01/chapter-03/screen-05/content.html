Filesystem Basics

Knowing Your Location

pwd and cd for Directory Traversal

pwd: Print Working Directory

Displays the full path of your current location in the filesystem hierarchy. Essential for orientation.

cd: Change Directory

Allows you to move between directories. Use .. for parent, ~ for home, or a full path.

Key Takeaway

Mastering pwd and cd provides the fundamental ability to navigate the Linux filesystem, a core skill for any command-line user.

kali@kali:~$
# Check current directory
pwd
# Expected output: /home/kali

# Move to a specific path
cd /usr/share/wordlists
pwd
# Expected output: /usr/share/wordlists

# Move up one level
cd ..
pwd
# Expected output: /usr/share

# Go to home directory
cd ~
pwd
# Expected output: /home/kali
Common Mistake: Relative vs. Absolute Paths

Remember that paths starting with / are absolute (from root), while others are relative (from current directory). Using the wrong type can lead to 'No such file or directory' errors.
