Scanning: Discovering Live Targets

Actively interacting with the target to map network services.

What is Scanning?

The phase where the ethical hacker actively interacts with the target to identify live hosts, open ports, and running services. It's about mapping the network's active components.

Key Tools & Techniques

Tools like Nmap are essential for port scanning, identifying operating systems, and detecting service versions. This provides a detailed inventory of network assets.

Example Scan Output
# Nmap scan results for a target
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.2p1
80/tcp open  http    Apache httpd 2.4.41
443/tcp open  https   Apache httpd 2.4.41

This output shows open ports and services, indicating potential entry points.

Misconception Check

Scanning is not about breaking in; it's about mapping the target's exposed surface. Aggressive or unauthorized scanning can be detected and may violate the Rules of Engagement.

Key Takeaway

Scanning is the active phase of discovering live hosts, open ports, and services, providing a detailed technical inventory for further assessment.
