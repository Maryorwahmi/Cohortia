Enumeration: Detailed Information Extraction

Intrusively gathering specifics about services, users, and shares.

What is Enumeration?

A more intrusive information gathering phase where detailed data about specific services, user accounts, groups, and network shares is extracted from the target.

Common Protocols & Data

Often involves querying protocols like SMB (Server Message Block), SNMP (Simple Network Management Protocol), or LDAP (Lightweight Directory Access Protocol) to find user lists, shared directories, and system configurations.

Example: Active Directory Enumeration

An ethical hacker uses a tool to query a Windows domain controller, revealing a list of valid usernames and their associated groups. This information can then be used for password guessing or social engineering.

Pro Tip

Always cross-reference enumerated data with reconnaissance findings. Discrepancies can sometimes indicate hidden systems or misconfigurations that might be exploitable.

Key Takeaway

Enumeration is the deep dive into specific services to extract detailed configuration, user, and share information, crucial for identifying precise attack vectors.
