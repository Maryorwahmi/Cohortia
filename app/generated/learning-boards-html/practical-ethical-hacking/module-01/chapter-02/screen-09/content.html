What is Metasploitable 2?

  • Intentionally Vulnerable: Designed with numerous security flaws for educational purposes.
  • Linux-based: A lightweight Linux distribution, making it easy to run.
  • Training Focus: Ideal for practicing various exploitation techniques, from web vulnerabilities to network services.
  • Pre-built Image: Often comes as a ready-to-import VM appliance (.ova or .vmdk).
Alternative Target

Consider a Windows Server with Active Directory for practicing enterprise-level attacks.
