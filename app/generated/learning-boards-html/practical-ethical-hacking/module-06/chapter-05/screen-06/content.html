Tooling & Mitigation

Kerberoasting: Practical Tools and Defenses

Using Impacket and Hashcat, and implementing strong passwords for service accounts.

Ticket Request: Tools like Impacket's getTGT.py or Rubeus are used to request service tickets for SPNs.

Offline Cracking: Hashcat or John the Ripper are used to brute-force the extracted NTLM hashes.

Mitigation: Enforce strong, long, and unique passwords for all service accounts to prevent cracking.

Key Takeaway

Effective Kerberoasting defense relies on robust password policies for service accounts and regular auditing of SPNs.

Terminal Demo: Extracting SPN Hashes

Using Impacket's GetUserSPNs.py

impacket-GetUserSPNs -dc-ip 192.168.1.10 domain.local/user1:Password123! -request

# Expected Output (truncated)
$krb5tgs$23$*svc_sql$domain.local*MSSQLSvc/sql.domain.local:1433*...
...
Hash for svc_sql extracted.

This command requests service tickets for all SPNs associated with user accounts. The output will contain the Kerberos service tickets (TGS-REPs) in a format suitable for offline cracking, typically starting with $krb5tgs$.

Safety Note

Always perform these actions in a controlled lab environment. Using these tools on unauthorized networks is illegal and unethical.
