Tooling & Mitigation

AS-REP Roasting: Practical Tools and Defenses

Using Impacket's getNPUsers.py and enforcing preauthentication for all users.

Hash Extraction: Impacket's getNPUsers.py is the primary tool for identifying and extracting AS-REP hashes.

Offline Cracking: Captured hashes are cracked offline using tools like Hashcat or John the Ripper.

Mitigation: Ensure Kerberos preauthentication is enabled for all user accounts unless absolutely necessary.

Key Takeaway

Proactive auditing and enabling preauthentication are simple yet effective defenses against AS-REP Roasting attacks.

Terminal Demo: Identifying AS-REP Roasting Targets

Using Impacket's getNPUsers.py

impacket-getNPUsers -dc-ip 192.168.1.10 domain.local/ -no-pass

# Expected Output (truncated)
$krb5asrep$23$user_no_preauth@DOMAIN.LOCAL:hash_value...
...
Hash for user_no_preauth extracted.

This command identifies users with disabled preauthentication and extracts their TGT hashes. The -no-pass flag indicates that no password is required for the initial request, as this is the vulnerability being exploited.

Safety Note

Always perform these actions in a controlled lab environment. Unauthorized use of these tools is illegal and unethical.
