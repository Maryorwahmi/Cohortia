Silver Ticket Attacks: Service-Specific Forgery

Forging Kerberos service tickets (TGS) for specific service access without DC interaction.

Forging TGS: Involves creating a fake Kerberos Service Ticket (TGS) for a specific service (e.g., CIFS).

Service Account Hash: Requires the NTLM hash of the specific service account running the target service.

Targeted Access: Grants access to that particular service as any user, without needing to interact with the Domain Controller.

Key Takeaway

Silver Ticket attacks provide targeted access to specific services by forging TGS tickets using the service account's NTLM hash.

Example Scenario

Accessing a Specific File Share

An attacker compromises a server and extracts the NTLM hash of the 'svc_fileserver' account, which runs the CIFS service for a critical file share. Using Mimikatz, they forge a Silver Ticket for the CIFS service. This ticket allows them to access the file share as any user, including a domain administrator, without needing to authenticate through the Domain Controller. This is highly effective for gaining access to specific high-value data or resources without raising broader domain alerts.

Golden vs. Silver

The key distinction is scope: Golden Tickets grant full domain control, while Silver Tickets grant access to a specific service. Both require specific account NTLM hashes.
