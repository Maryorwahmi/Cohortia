Golden Ticket Attacks: Forging Domain Control

Achieving full domain administrative privileges with a forged Kerberos TGT.

Forging TGTs: Involves creating a fake Kerberos Ticket Granting Ticket for any user, including the krbtgt account.

krbtgt Hash: Requires the NTLM hash of the krbtgt account, the Kerberos service account, for full domain control.

Arbitrary Privileges: Grants the attacker arbitrary privileges, allowing impersonation of any user, including domain administrators.

Key Takeaway

Golden Ticket attacks provide full, persistent domain control by forging TGTs using the critical krbtgt account hash.

Example Scenario

The Ultimate Domain Takeover

After compromising a Domain Controller and extracting the krbtgt account's NTLM hash, an attacker uses Mimikatz to create a Golden Ticket. This ticket allows them to impersonate any user, such as the 'Administrator' account, and access any resource in the domain with full administrative rights, even if the actual Administrator's password is changed. This access can persist for a very long time, making it incredibly difficult to detect and remediate without a full domain rebuild.

Prerequisite

Golden Ticket attacks typically require the NTLM hash of the krbtgt account, which is usually obtained after initial compromise and privilege escalation to a Domain Controller.
