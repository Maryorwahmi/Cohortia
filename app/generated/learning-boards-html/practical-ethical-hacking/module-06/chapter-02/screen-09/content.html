What is CSRF?

Cross-Site Request Forgery (CSRF) is an attack that tricks a victim into submitting a malicious request to a web application where they are currently authenticated. The attack exploits the trust a website has in a user's browser.

  • •
    Exploits Browser Trust: Leverages the browser's automatic inclusion of session cookies.
  • •
    Authenticated Victim: Requires the victim to be logged into the target site.
  • •
    Unintended Actions: Tricks the user into performing actions they didn't intend.
Key Takeaway

CSRF attacks are dangerous because they bypass user consent by leveraging existing authentication, making forged requests appear legitimate to the server.

How CSRF Works

  • Attacker Crafts Request: Creates a malicious request (e.g., fund transfer).
  • Victim Visits Malicious Site: Attacker embeds the request on a site the victim visits.
  • Browser Sends Cookies: Victim's browser automatically sends valid session cookies.
  • Server Processes Request: Target site processes the request as legitimate.

XSS vs. CSRF

While both are 'cross-site' attacks, XSS injects malicious scripts into a trusted website, exploiting the user's trust in the site. CSRF tricks the user's browser into sending unauthorized requests to a trusted site, exploiting the site's trust in the browser.

Common Mistake

Confusing XSS and CSRF. Remember: XSS is about injecting code, CSRF is about forging requests.
