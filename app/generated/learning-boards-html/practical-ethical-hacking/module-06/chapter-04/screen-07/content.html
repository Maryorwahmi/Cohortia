Initial Network Scanning with Nmap

Your Swiss Army Knife for AD Service Discovery

Nmap Overview

A powerful, open-source network scanner used for host discovery, port scanning, and OS/service detection.

Key Flags for AD

-sC (default scripts) and -sV (version detection) are crucial for detailed AD service identification.

AD-Related Ports

Look for 53 (DNS), 88 (Kerberos), 135 (RPC), 389 (LDAP), 445 (SMB), 636 (LDAPS), 3268/3269 (Global Catalog).

Nmap Scan Example

nmap -sC -sV -p 53,88,135,139,389,445,464,593,636,3268,3269 192.168.1.100

Expected Output Snippet:

PORT      STATE SERVICE VERSION
53/tcp    open  domain  Microsoft Windows DNS
88/tcp    open  kerberos-sec Microsoft Windows Kerberos
135/tcp   open  msrpc   Microsoft Windows RPC
389/tcp   open  ldap    Microsoft Windows AD LDAP
445/tcp   open  microsoft-ds Windows Server (R) 2016 microsoft-ds
Key Takeaway

Nmap helps identify Domain Controllers by revealing open AD-specific ports and services, guiding further enumeration.
