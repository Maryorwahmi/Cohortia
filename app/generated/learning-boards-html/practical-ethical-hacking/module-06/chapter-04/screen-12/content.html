Introducing BloodHound: Visualizing Attack Paths

Mapping Complex AD Relationships for Privilege Escalation

What is BloodHound?

A single-page JavaScript web application that visualizes Active Directory relationships to identify attack paths.

SharpHound Ingestor

A C# executable that collects data (users, groups, computers, GPOs) from AD for BloodHound's analysis.

Key Benefit

Transforms raw AD data into a graphical representation, revealing complex privilege escalation paths to domain dominance.

BloodHound's Data Flow

Active Directory Environment
SharpHound (Data Collection)
BloodHound (Visualization & Analysis)
Key Takeaway

BloodHound provides invaluable visual insights into AD attack paths, making complex privilege escalation scenarios clear.
