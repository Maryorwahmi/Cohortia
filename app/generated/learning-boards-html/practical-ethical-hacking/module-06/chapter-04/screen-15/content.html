Key Concepts

Protocols, Phases, and Advanced Tools

Group Policy Object (GPO)

A collection of settings defining user and computer behavior in an AD environment.

Reconnaissance

The initial phase of penetration testing, focused on gathering information about the target.

Enumeration

The process of extracting specific details about a system, such as users, groups, shares, and services.

SMB

Server Message Block, a network file sharing protocol used by Windows, often a source of enumeration data.

LDAP

Lightweight Directory Access Protocol, used for accessing and maintaining distributed directory information services.

BloodHound/SharpHound

Tools for visualizing and identifying complex attack paths within an Active Directory environment.

Summary Takeaway

From policy enforcement with GPOs to advanced attack path visualization with BloodHound, these concepts and tools are vital for comprehensive AD security assessment.
