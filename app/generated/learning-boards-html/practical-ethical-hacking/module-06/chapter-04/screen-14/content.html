Key Concepts

Essential Terms to Remember

Active Directory (AD)

A directory service by Microsoft for Windows domain networks, storing information about network resources.

Domain Controller (DC)

A server running AD DS that manages user authentication and network access within an AD domain.

Organizational Unit (OU)

A container within AD that holds users, groups, computers, and other OUs, used for applying Group Policy Objects.

Summary Takeaway

Active Directory's core components—AD itself, Domain Controllers, and Organizational Units—form the hierarchical foundation of Windows enterprise networks, crucial for managing resources and security.
