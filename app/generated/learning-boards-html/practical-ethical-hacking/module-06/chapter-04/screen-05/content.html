Active Directory's Hierarchical Structure

Domain Controllers, OUs, and Group Policies

Domain Controller (DC)

A server running AD DS, storing the AD database, authenticating users, and enforcing security policies. The core of the domain.

Organizational Unit (OU)

Logical containers within a domain that hold users, groups, and computers, allowing for targeted policy application.

Group Policy Object (GPO)

A collection of settings that define the behavior and security configurations for users and computers within an OU or domain.
