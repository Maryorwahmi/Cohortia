LDAP Enumeration Techniques

Querying the Active Directory Database Directly

LDAP Protocol

Lightweight Directory Access Protocol (LDAP) is used to query and modify directory services like Active Directory.

Tools for LDAP

ldapsearch (Linux) and Nmap scripts (e.g., ldap-search) are common for direct AD queries.

Targeted Queries

Search for specific attributes like user descriptions, service accounts, or computers in particular OUs.

LDAP Query Example (ldapsearch)

ldapsearch -x -h 192.168.1.100 -b "DC=example,DC=com" "(objectClass=user)" sAMAccountName description

Expected Output Snippet:

# john.doe, Users, example.com
dn: CN=john.doe,CN=Users,DC=example,DC=com
sAMAccountName: john.doe
description: Standard user account

# svc_web, Service Accounts, example.com
dn: CN=svc_web,OU=Service Accounts,DC=example,DC=com
sAMAccountName: svc_web
description: Web Application Service Account
Key Takeaway

LDAP enumeration provides direct access to AD data, enabling highly targeted information gathering for subsequent attacks.
