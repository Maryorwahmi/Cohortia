Understanding Active Directory Fundamentals

The Central Database for Windows Networks

Definition

Active Directory (AD) is a directory service developed by Microsoft for Windows domain networks, storing information about network resources like users, computers, and groups.

Core Purpose

Provides centralized authentication, authorization, and management of network resources and security policies across an enterprise.

Why it Matters to Hackers

Compromising AD often grants control over the entire Windows-based network, making it a primary target for privilege escalation.

AD's Role in an Enterprise

User & Identity Management: Stores user accounts, passwords, and security attributes.

Resource Access Control: Manages permissions for files, folders, applications, and devices.

Security Policy Enforcement: Applies Group Policy Objects (GPOs) to users and computers.

Key Takeaway

AD is more than just a user database; it's the central control system for Windows network security and access.
