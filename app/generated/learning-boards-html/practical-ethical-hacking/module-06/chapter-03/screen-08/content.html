Authorization Bypass

Missing Function Level Access Control

Unprotected Administrative and Privileged Functions

The Vulnerability

Applications fail to verify if a user is authorized to access a specific function or resource, often relying on client-side UI hiding.

  • •**Client-Side Reliance:** Hiding buttons, not enforcing server-side.
  • •**Direct Endpoint Access:** Attacker finds and calls hidden APIs.
  • •**Consequence:** Regular users performing admin actions.
Example Scenario

A non-admin user directly accesses /admin/deleteUser?id=5 and successfully deletes a user.

Vulnerable Admin Endpoint (Node.js)app.js
const express = require('express');
const app = express();

// ... (authentication middleware)

app.get('/admin/deleteUser', (req, res) => {
  // NO authorization check here!
  const userIdToDelete = req.query.id;
  // In a real app, this would delete from DB
  console.log(`User ${userIdToDelete} deleted.`);
  res.send(`User ${userIdToDelete} has been deleted.`);
});

// Attacker calls: GET /admin/deleteUser?id=5
// without being an admin.
Mitigation

Implement explicit server-side authorization checks for all sensitive functions and API endpoints.

Key Takeaway

Never rely on client-side controls for security. All function-level access must be strictly enforced on the server.
