File Inclusion Vulnerabilities

Local File Inclusion (LFI)

Reading Sensitive Files from the Server's File System

LFI Explained

LFI allows attackers to include files from the local server's file system by manipulating user-supplied input without proper validation.

  • •**Local File Access:** Reading files already on the server.
  • •**Directory Traversal:** Using `../` to navigate file system.
  • •**Null Byte (%00):** Often used to truncate file extensions.
Impact

Disclosure of sensitive system files (e.g., /etc/passwd, configuration files, source code).

LFI Vulnerable PHP Codeinclude.php
<?php
  // Vulnerable code: appends '.php' without validation
  $file = $_GET['page'];
  include($file . '.php');
?>

// Attacker's Request:
// GET /include.php?page=../../../../etc/passwd%00

// Server interprets as:
// include('../../../../etc/passwd');

// Expected Output (if successful):
// root:x:0:0:root:/root:/bin/bash
// daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
// ... (contents of /etc/passwd)
Mitigation

Strict input validation: whitelist allowed file names, disallow directory traversal characters (.., /), and sanitize all user input.

Key Takeaway

LFI allows reading arbitrary local files by manipulating the path in an include function, often requiring a null byte to bypass extensions.
