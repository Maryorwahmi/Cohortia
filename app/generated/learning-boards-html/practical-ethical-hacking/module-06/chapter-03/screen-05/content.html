Authentication Flaws

Brute-Force Attacks

Systematically Guessing Credentials to Gain Access

The Attack Mechanism

Attackers try numerous password combinations until the correct one is found. This is often automated and targets login forms.

  • •**Systematic Guessing:** Trying all possibilities.
  • •**Automated Tools:** Burp Suite Intruder, Hydra.
  • •**Target:** Login forms, API keys, encryption keys.
Common Mistake

Using weak, predictable, or reused passwords across multiple services.

Vulnerable Login Form (PHP)login.php
<?php
  if (isset($_POST['username']) && isset($_POST['password'])) {
    $username = $_POST['username'];
    $password = $_POST['password'];

    // NO rate limiting, NO CAPTCHA, NO account lockout
    if ($username === 'admin' && $password === 'password123') {
      echo "<p style='color: green;'>Login successful!</p>";
    } else {
      echo "<p style='color: red;'>Invalid credentials.</p>";
    }
  }
?>
<form method="POST">
  <input type="text" name="username" placeholder="Username">
  <input type="password" name="password" placeholder="Password">
  <button type="submit">Login</button>
</form>
Mitigation

Implement rate limiting, account lockout policies, and CAPTCHAs to prevent automated attempts.

Key Takeaway

Brute-force attacks exploit the absence of protective measures, highlighting the need for robust login security beyond just strong passwords.
