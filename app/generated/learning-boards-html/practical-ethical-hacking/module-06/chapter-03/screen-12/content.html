Preventing File Inclusion Vulnerabilities

Robust Input Validation and Server Configuration

Input Validation

Never trust user input that determines which files are included. Implement strict validation to prevent malicious file paths.

  • •**Whitelisting:** Only allow a predefined set of safe file names.
  • •**Disallow Traversal:** Block `../` and `/` characters in input.
  • •**Sanitize Input:** Remove or encode dangerous characters.
Example

If page can only be 'home' or 'about', explicitly check if ($page == 'home' || $page == 'about').

Secure PHP Includesecure_include.php
<?php
  $allowed_pages = ['home', 'about', 'contact'];
  $requested_page = $_GET['page'];

  if (in_array($requested_page, $allowed_pages)) {
    include($requested_page . '.php');
  } else {
    // Log attempt and show error or default page
    error_log("Invalid page request: " . $requested_page);
    include('error.php');
  }
?>

// Server Configuration (php.ini):
// allow_url_fopen = Off
// allow_url_include = Off
Server Configuration

Disable remote file inclusion (e.g., allow_url_include=Off in PHP) to prevent fetching files from external URLs.

Key Takeaway

A combination of strict input validation and secure server configuration is essential to effectively prevent both LFI and RFI vulnerabilities.
