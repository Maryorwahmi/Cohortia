Burp Suite Proxy Workflow

01
Configure Browser Proxy
Set your browser's proxy settings to Burp Suite's listener (e.g., 127.0.0.1:8080).
02
Activate Intercept
In Burp Suite's Proxy tab, ensure 'Intercept is on' to capture traffic.
03
Browse & Intercept
Navigate to the target web application in your browser; Burp Suite will capture requests.
04
Inspect & Modify
Examine the request details and alter parameters, headers, or body as needed.
05
Forward & Observe
Send the modified request to the server and analyze the application's response.

Example: Modifying a Login Request

Intercepting a POST request for a login form and changing the username parameter.

Safety Note

Always ensure you have explicit permission before testing any system. Unauthorized hacking is illegal.

Key Takeaway

Burp Suite's proxy allows granular control over web traffic, enabling precise testing for vulnerabilities like SQLi and XSS.
