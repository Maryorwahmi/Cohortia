Core Concept

Web Application Architecture

Understanding Client-Server Interaction and Protocols

Key Components
  • Client (Browser): Initiates requests for web resources.
  • Server: Processes requests, hosts application logic.
  • Database: Stores and retrieves application data.
  • HTTP/HTTPS: Protocols for secure data exchange.
Concrete Example

When you type a URL, your browser (client) sends an HTTP request to the web server. The server fetches the page from its files or a database and sends an HTTP response back to your browser, which then renders the page.

Key Takeaway

The client-server model and communication protocols define the attack surface of web applications.
