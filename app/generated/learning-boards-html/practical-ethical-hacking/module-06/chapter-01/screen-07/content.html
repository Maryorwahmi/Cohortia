SQL Injection (SQLi) Explained

Manipulating Database Queries with Malicious Input

Vulnerable Login Query:
$username = $_POST['username'];$password = $_POST['password'];$sql = "SELECT * FROM users WHERE username = '$username' AND password = '$password'";
Attacker Input (Username Field):
' OR '1'='1
Resulting Malicious Query:
SELECT * FROM users WHERE username = '' OR '1'='1' AND password = '$password'

How SQLi Works

Attackers inject SQL code into input fields, which then becomes part of the database query. This alters the query's logic, allowing unauthorized access or data manipulation.

Impact of SQLi
  • Authentication bypass
  • Data exfiltration (stealing sensitive data)
  • Data modification or deletion
  • Remote code execution (in some cases)
Key Takeaway

SQLi exploits applications that build SQL queries dynamically from user input without proper sanitization, leading to critical security breaches.
