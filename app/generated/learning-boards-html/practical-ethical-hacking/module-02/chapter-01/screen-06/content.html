Tool Spotlight

WHOIS Protocol: Domain Registration Details

Querying public databases for domain information

Information Revealed by WHOIS

  • •Registrant Details: Name, organization, contact information.
  • •Registration Dates: Creation, expiration, and last updated dates.
  • •Nameservers: Servers authoritative for the domain (e.g., ns1.example.com).
  • •Registrar: The company through which the domain was registered.
Key Takeaway

WHOIS provides foundational domain ownership and infrastructure details, even if some data is obscured by privacy services.

WHOIS Query Example

$ whois scanme.nmap.org

   Domain Name: SCANME.NMAP.ORG
   Registry Domain ID: D12345678-LROR
   Registrar WHOIS Server: whois.example.com
   Registrar URL: http://www.example.com
   Updated Date: 2023-01-15T10:00:00Z
   Creation Date: 2000-01-01T00:00:00Z
   Registry Expiry Date: 2025-01-01T00:00:00Z
   Registrar: Example Registrar, Inc.
   Registrar IANA ID: 999
   Domain Status: clientTransferProhibited https://icann.org/epp#clientTransferProhibited
   Name Server: NS1.EXAMPLE.COM
   Name Server: NS2.EXAMPLE.COM
   DNSSEC: unsigned
   URL of the ICANN WHOIS Data Problem Reporting System: http://wdprs.internic.net/

>>> Last update of WHOIS database: 2024-03-01T12:00:00Z <<<
Pro Tip

Even if registrant details are private, nameserver information can often reveal the hosting provider or related entities, providing new leads.
