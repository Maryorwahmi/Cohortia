Passive DNS Enumeration

Mapping network infrastructure without direct queries

Key Aspects of Passive DNS

  • •No Direct Target Interaction: Queries public DNS resolvers, not target's servers.
  • •Leverages Cached Records: Uses publicly available DNS data.
  • •Tools: dig and nslookup are primary utilities.
  • •Goal: Map network infrastructure and identify services.
Key Takeaway

Passive DNS enumeration provides a stealthy way to gather extensive network information from public caches.

DNS Query Example (MX Record)

$ dig @8.8.8.8 scanme.nmap.org MX

; <<>> DiG 9.10.6 <<>> @8.8.8.8 scanme.nmap.org MX
; (1 server found)
;; global options: +cmd
;; Got answer:
;; ->>HEADER<<- opcode: QUERY, status: NOERROR, id: 12345
;; flags: qr rd ra; QUERY: 1, ANSWER: 1, AUTHORITY: 0, ADDITIONAL: 1

;; QUESTION SECTION:
;scanme.nmap.org.               IN      MX

;; ANSWER SECTION:
scanme.nmap.org.        3600    IN      MX      10 mail.scanme.nmap.org.

;; Query time: 30 msec
;; SERVER: 8.8.8.8#53(8.8.8.8)
;; WHEN: Fri Mar 01 12:00:00 UTC 2024
;; MSG SIZE  rcvd: 70
Pro Tip

Querying MX records can reveal email servers, which might be running specific software with known vulnerabilities.
