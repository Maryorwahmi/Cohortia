Shodan: The Search Engine for Devices

Discovering internet-connected devices and services

What Shodan Indexes

  • •Servers: Web servers (Apache, Nginx), database servers.
  • •Network Devices: Routers, firewalls, switches.
  • •IoT Devices: Webcams, smart devices, industrial control systems.
  • •Information: Services running, geographic location, known vulnerabilities.
Key Takeaway

Shodan offers a unique, device-centric view of the internet, revealing exposed services and potential vulnerabilities.

Shodan Search Example

// Find Apache web servers in the US on port 8080
apache country:"US" port:8080

// Search for webcams with default passwords
webcam has_screenshot:true password:"admin"

// Discover MySQL databases exposed to the internet
mysql port:3306

// Find devices running specific industrial control systems
modbus country:"DE"
Ethical Boundary

Discovering a device on Shodan does not grant permission to interact with it; always obtain explicit authorization.
