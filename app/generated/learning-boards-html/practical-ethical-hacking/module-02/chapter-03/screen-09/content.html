FOCA: Metadata Extraction from Documents

Uncovering Valuable Clues Embedded in Public Files

What is Metadata?

Data that describes other data, often embedded within files (e.g., author, creation date, software used, internal paths).

FOCA's Role

A tool designed to download and analyze documents from a target's website, extracting and presenting embedded metadata in a structured format.

Key Takeaway

Metadata extraction provides unique insights into a target's internal environment, revealing details not found through other reconnaissance methods.

Document Metadata Flow
1

Organization publishes documents (PDF, DOCX) online.

2

FOCA downloads and analyzes these public documents.

3

Embedded metadata (author, software, paths) is extracted.

4

Valuable internal clues are revealed for reconnaissance.
