Connect Scan (`-sT`): The Full TCP Handshake

When Stealth is Not the Primary Concern

terminal
# Basic Connect scan on common ports (1-1024) of a target
nmap -sT -p 1-1024 scanme.nmap.org

# Example Output for an open port:
PORT   STATE SERVICE
22/tcp open  ssh

# Example Output for a closed port:
PORT   STATE SERVICE
80/tcp closed http

# Example Output for a filtered port:
PORT   STATE SERVICE
443/tcp filtered https
Key Takeaway

Connect scans are less stealthy due to completing the TCP handshake, but they are reliable when SYN scans are blocked.

How it Works

  • •Nmap sends a SYN packet.
  • •Target responds with SYN/ACK if port is open.
  • •Nmap sends ACK, completing the three-way handshake.

Advantages

  • •Works reliably even when SYN scans are blocked.
  • •Does not require raw packet access (can run as non-root).

Considerations

  • •Easily detectable and logged by target systems and firewalls.
  • •Higher risk of triggering IDS/IPS alerts.
