SYN Scan (`-sS`): The Stealthy Half-Open Approach

Identifying Open Ports Without Completing the Handshake

terminal
# Basic SYN scan on common ports (1-1024) of a target
nmap -sS -p 1-1024 scanme.nmap.org

# Example Output for an open port:
PORT   STATE SERVICE
22/tcp open  ssh

# Example Output for a closed port:
PORT   STATE SERVICE
80/tcp closed http

# Example Output for a filtered port:
PORT   STATE SERVICE
443/tcp filtered https
Key Takeaway

SYN scans are stealthier by avoiding a full TCP handshake, making them harder for basic firewalls to log.

How it Works

  • •Nmap sends a SYN packet to the target port.
  • •If open, target responds with SYN/ACK.
  • •Nmap sends RST (Reset) instead of ACK, preventing full connection.

Advantages

  • •Less detectable by firewalls and IDS/IPS compared to Connect scans.
  • •Efficient for quickly identifying open ports.

Considerations

  • •Requires raw packet access (often root privileges).
  • •Can still be detected by advanced security systems.
