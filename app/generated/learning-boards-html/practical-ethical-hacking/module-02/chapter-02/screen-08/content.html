UDP Scan (`-sU`): Probing Connectionless Services

Identifying Open UDP Ports, a Slower but Necessary Scan

terminal
# UDP scan on common UDP ports (DNS, SNMP, NTP)
nmap -sU -p 53,161,123 scanme.nmap.org

# Example Output for an open port:
PORT    STATE SERVICE
53/udp  open  domain

# Example Output for a closed port:
PORT    STATE SERVICE
161/udp closed snmp

# Example Output for a filtered port:
PORT    STATE SERVICE
123/udp open|filtered ntp
Key Takeaway

UDP scans are essential for connectionless services but are slower and less reliable due to the nature of UDP responses.

How it Works

  • •Nmap sends a UDP packet to the target port.
  • •ICMP port unreachable error indicates a closed port.
  • •No response typically means open or filtered.

Challenges

  • •Slower due to retransmissions and timeouts.
  • •Less reliable; no response is ambiguous (open or filtered).
  • •Firewalls can easily drop UDP packets without response.

Pro Tip

  • •Combine with `-sV` for service version detection to get more definitive results.
