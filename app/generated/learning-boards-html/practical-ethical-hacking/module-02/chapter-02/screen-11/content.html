Netcat (`nc`): The Networking Swiss Army Knife

A Versatile Utility for Basic Port Connectivity Testing

terminal
# Test TCP connectivity to port 80 and 443
nc -zv scanme.nmap.org 80 443

# Example Output for open ports:
Connection to scanme.nmap.org 80 port [tcp/http] succeeded!
Connection to scanme.nmap.org 443 port [tcp/https] succeeded!

# Example Output for a closed port:
nc -zv scanme.nmap.org 10000
nc: connect to scanme.nmap.org port 10000 (tcp) failed: Connection refused
Key Takeaway

Netcat provides a quick and simple way to test port connectivity and verify if a service is listening on a specific port.

What is Netcat?

  • •Simple Unix utility for reading/writing data across network connections.
  • •Supports both TCP and UDP protocols.
  • •Often called the "Swiss Army knife" of networking.

Reconnaissance Use Cases

  • •Quickly test if a specific port is open and listening.
  • •Verify firewall rules from a specific source.
  • •Establish simple client-server connections for data transfer.

Pro Tip

  • •Use `-zv` for verbose zero-I/O mode, ideal for port scanning without sending data.
