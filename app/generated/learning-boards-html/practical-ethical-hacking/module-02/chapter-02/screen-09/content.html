Nmap Advanced Feature

Service Version Detection (`-sV`)

Uncovering the Exact Applications and Their Versions

terminal
# SYN scan with service version detection on a target
nmap -sS -sV scanme.nmap.org

# Example Output:
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 6.6.1p1 Ubuntu 2ubuntu2.8 (Ubuntu Linux; protocol 2.0)
80/tcp open  http    Apache httpd 2.4.7 ((Ubuntu))
443/tcp open https   Apache httpd 2.4.7 ((Ubuntu))

# Note: The 'VERSION' column provides detailed software information.
Key Takeaway

Service version detection provides critical information for identifying known vulnerabilities associated with specific software versions.

Why it Matters

  • •Specific software versions often have publicly known vulnerabilities.
  • •Allows cross-referencing with vulnerability databases (e.g., CVE).
  • •Narrows down potential attack vectors significantly.

How Nmap Detects

  • •Sends various protocol-specific probes to open ports.
  • •Analyzes service banners and responses to identify software.
  • •Compares responses against a database of known service signatures.

Pro Tip

  • •Always combine `-sV` with a port scan (`-sS`, `-sT`) for maximum effectiveness.
