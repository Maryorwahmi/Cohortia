Identifying Live Hosts with Nmap

Mapping Active Devices on Your Target Network

Host Discovery (`-sn`)

  • **Purpose:** Identify which hosts are alive and reachable on a network.
  • **Techniques:** Uses ICMP echo requests (ping), TCP SYN to common ports (80, 443), or ARP requests.
  • **Benefit:** Narrows down targets for more intensive port scanning, reducing network noise.
Example: Host Discovery Command
nmap -sn 192.168.1.0/24

This command scans the entire 192.168.1.0/24 subnet to identify all active hosts without performing any port scans.

Why it Matters

  • **Efficiency:** Avoids wasting time scanning inactive hosts.
  • **Reduced Noise:** Minimizes network traffic by only probing for host presence.
  • **Foundation:** Provides a list of live targets for subsequent, more detailed port scans.
Key Takeaway

Host discovery with `nmap -sn` is a crucial first step to efficiently identify active systems on a network before proceeding with detailed port scanning.
