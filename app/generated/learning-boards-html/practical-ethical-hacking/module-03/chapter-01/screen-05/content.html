Nmap: The Network Mapper

Introducing Nmap and Port States

What is Nmap?

  • **Network Mapper:** A powerful, open-source utility for network discovery and security auditing.
  • **Versatile:** Performs host discovery, port scanning, OS detection, and service version detection.
  • **Essential Tool:** The go-to tool for ethical hackers to map network infrastructure.

Understanding Port States

  • **Open:** An application is actively listening for connections.
  • **Closed:** No application is listening, but the host is reachable.
  • **Filtered:** A firewall or network device is blocking the probe.
Nmap Command Example
nmap -sS 192.168.1.100

This command initiates a SYN scan against the target IP address 192.168.1.100, a common first step to quickly identify open TCP ports.

Key Takeaway

Nmap is the foundational tool for network scanning, providing insights into port states (open, closed, filtered) which are critical for identifying potential vulnerabilities.
