Reliable TCP Connect Scan

Completing the Handshake for Guaranteed Port State Detection

How TCP Connect Scan Works (`-sT`)

  • **Full Handshake:** Performs a complete TCP three-way handshake (SYN, SYN/ACK, ACK).
  • **Open Port:** Connection successfully established.
  • **Closed Port:** Target responds with RST.
  • **Reliability:** More reliable than SYN scan, especially when raw packet access is restricted.

Disadvantages

  • **Noisier:** More likely to be logged by target systems and firewalls due to full connection.
  • **Slower:** Involves more network traffic and overhead compared to SYN scans.
  • **Less Stealthy:** Easier to detect by security monitoring tools.
Key Takeaway

The TCP Connect scan (`-sT`) provides reliable port state detection by completing the full TCP handshake, but it is 'noisier' and more easily detected than a SYN scan.
