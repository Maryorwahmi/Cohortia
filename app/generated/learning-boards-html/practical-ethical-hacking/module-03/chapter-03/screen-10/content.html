Querying All Records

Beyond Zone Transfers

  • •Use dig any <domain.com> to retrieve all available record types.
  • •Look for A (hostnames), MX (mail servers), NS (name servers), SOA (start of authority).
  • •Each record type provides clues about the target's infrastructure.
  • •Combine these insights to build a comprehensive network map.
Key Takeaway

Even without zone transfers, comprehensive DNS queries and subdomain brute-forcing can reveal hidden hosts and expand your attack surface.

Command: Query All Records
# Query for all record types for a domain
dig any <DOMAIN.COM>

# Example Output (truncated):
# <DOMAIN.COM>.         3600    IN      A       192.0.2.1
# <DOMAIN.COM>.         3600    IN      MX      10 mail.<DOMAIN.COM>.
# <DOMAIN.COM>.         3600    IN      NS      ns1.<DOMAIN.COM>.
# <DOMAIN.COM>.         3600    IN      SOA     ns1.<DOMAIN.COM>. hostmaster.<DOMAIN.COM>. ...

# Conceptual Command: Subdomain Brute-forcing
# gobuster dns -d <DOMAIN.COM> -w /path/to/wordlist.txt
Tool Highlight

Tools like gobuster or wfuzz are excellent for automated subdomain brute-forcing using wordlists.
