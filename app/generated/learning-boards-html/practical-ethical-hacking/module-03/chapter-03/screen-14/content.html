Key Concepts

Essential terms to remember

Enumeration

The process of extracting detailed information from identified open services, such as user accounts, share names, and system configurations.

SMB

Server Message Block, a network file sharing protocol primarily used by Windows systems for file and printer sharing.

DNS

Domain Name System, a hierarchical and decentralized naming system for computers, services, or any resource connected to a network.

Summary Takeaway

These foundational concepts are critical for understanding how to gather detailed intelligence and map target network infrastructures effectively.
