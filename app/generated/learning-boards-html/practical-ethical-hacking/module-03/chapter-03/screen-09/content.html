Tool: dig

How to Attempt a Zone Transfer

  • •dig is a command-line tool for querying DNS name servers.
  • •The AXFR query type is used to request a full zone transfer.
  • •You need the target domain and the IP of its DNS server.
  • •A successful transfer provides a complete list of all DNS records.
Key Takeaway

A successful dig AXFR command indicates a critical DNS misconfiguration, providing a full network map to an attacker.

Command: Attempt Zone Transfer
# Replace <DNS_SERVER_IP> and <DOMAIN.COM>
dig axfr @<DNS_SERVER_IP> <DOMAIN.COM>

# Example of SUCCESSFUL output (truncated):
# ; <<>> DiG 9.16.1-Ubuntu <<>> axfr @192.168.1.1 <DOMAIN.COM>
# ; (1 server found)
# ;; global options: +cmd
# <DOMAIN.COM>.         86400   IN      SOA     ns1.<DOMAIN.COM>. hostmaster.<DOMAIN.COM>. ...
# www.<DOMAIN.COM>.      3600    IN      A       192.168.1.10
# mail.<DOMAIN.COM>.     3600    IN      A       192.168.1.11
# dev.<DOMAIN.COM>.      3600    IN      A       192.168.1.12
# internal-app.<DOMAIN.COM>. 3600 IN      A       192.168.1.13

# Example of FAILED output:
# ;; WARNING: Zone transfer of '<DOMAIN.COM>' failed: REFUSED
Practical Tip

If a direct zone transfer fails, try querying common record types or brute-forcing subdomains for more information.
