Share Discovery

Why Shares Matter

  • •Share names often indicate sensitive data (e.g., 'HR_Docs', 'Finance').
  • •Misconfigured shares can allow unauthorized access to files.
  • •Password policies reveal strength requirements, aiding brute-force efforts.
  • •enum4linux -S lists available shares and their descriptions.
Key Takeaway

Enumerating SMB shares and policies provides critical context for identifying data exposure and informing credential attack strategies.

Command: List Shares
enum4linux -S <TARGET_IP>

# Example Output:
# =========================================
# |    Shares on <TARGET_IP> (via srvinfo)   |
# =========================================
# Sharename       Type      Comment
# ---------       ----      -------
# IPC$            Disk      Remote IPC
# ADMIN$          Disk      Remote Admin
# C$              Disk      Default share
# HR_Docs         Disk      Human Resources Documents
# Public          Disk      Publicly accessible files
Real-world Connection

Discovering a share named 'HR_Docs' with weak permissions could lead to unauthorized access to employee data.
