Core Concept: DNS

What is DNS Enumeration?

  • •DNS translates domain names to IP addresses, revealing network structure.
  • •Enumeration queries DNS to find subdomains, hosts, and mail servers.
  • •Tools like dig and nslookup are fundamental for this process.
  • •Goal: Create a comprehensive map of the target's online presence.
Key Takeaway

DNS enumeration, particularly through zone transfers, can provide a complete blueprint of a target's network infrastructure.

Zone Transfer (AXFR)

The Zone Transfer Vulnerability

  • •A DNS server transfers its entire database of records for a domain.
  • •Intended for legitimate synchronization between DNS servers.
  • •Misconfiguration: Allowing unauthorized zone transfers.
  • •Impact: Attacker gets a complete map of all subdomains, hosts, and IPs.
Security Risk

An unsecured zone transfer is a critical misconfiguration, providing attackers with a full network blueprint.
