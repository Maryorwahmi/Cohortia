Nmap Feature

Service Version Detection (-sV)

Identifying the applications behind open ports

How it Works
  • Nmap sends specific probes to open ports.
  • Analyzes service responses for application details.
  • Identifies name, version, and sometimes OS/device type.
  • Crucial for targeted vulnerability research.
Key Takeaway

The -sV flag provides precise service version details, transforming raw port data into actionable intelligence for vulnerability analysis.

Terminal Output Example
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.2p1 Ubuntu 4ubuntu0.3 (Ubuntu Linux; protocol 2.0)
80/tcp open  http    Apache httpd 2.4.41 ((Ubuntu))
443/tcp open  ssl/http Apache httpd 2.4.41 ((Ubuntu))
3306/tcp open  mysql   MySQL 8.0.21-0ubuntu0.20.04.4
Concrete Example

Running nmap -sV <target_IP> might reveal 'OpenSSH 8.2p1 Ubuntu 4ubuntu0.3'. This tells you not just that SSH is open, but the exact version and even the underlying OS, allowing you to search for CVEs specific to OpenSSH 8.2p1.
