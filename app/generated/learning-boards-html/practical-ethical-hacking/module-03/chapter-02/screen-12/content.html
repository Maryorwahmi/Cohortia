Advanced Nmap Scanning: Service & OS Detection

Practical application of -sV and -O flags

Instructions
  • Ensure Kali Linux and target VM are running.
  • Identify target VM's IP address.
  • Open a terminal in Kali.
  • Execute the Nmap command below.
  • Analyze the output for detailed service and OS information.
Key Takeaway

Using -sV and -O flags provides critical, actionable intelligence about target services and operating systems, essential for vulnerability assessment.

Code Template/Commands
# Replace <TARGET_IP> with the actual IP address.

# Step 1: Perform Service Version and OS Detection
nmap -sS -sV -O <TARGET_IP> -oN advanced_scan_results.txt

# Step 2: View and analyze the results
cat advanced_scan_results.txt
Pro-Tip

Always save your Nmap output using flags like -oN (normal) or -oX (XML) for easy review, parsing, and integration into reporting tools later.
