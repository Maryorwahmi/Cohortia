Nmap Power-Up

Nmap Scripting Engine (NSE)

Extending Nmap's capabilities with Lua scripts

Key Aspects
  • Uses Lua scripts for automation.
  • Performs advanced discovery and vulnerability checks.
  • Thousands of community-contributed scripts.
  • Scripts are categorized by purpose (e.g., `auth`, `vuln`).
Key Takeaway

NSE transforms Nmap into a highly versatile and extensible tool, enabling automated, targeted, and complex network tasks through community-driven scripts.

NSE Script Categories
auth

Authentication checks

vuln

Vulnerability detection

discovery

Information gathering

brute

Brute-force attacks

dos

Denial of Service

safe

Non-disruptive scripts

Concrete Example

To find common web directories, you can use nmap -p 80 --script http-enum <target>. This single command leverages an NSE script to perform a task that would otherwise require manual enumeration or other tools.
