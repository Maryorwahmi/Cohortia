Nmap Feature

OS Detection (-O)

Fingerprinting the target's operating system

How it Works
  • Analyzes TCP/IP stack characteristics (window size, options).
  • Compares responses to a database of known OS fingerprints.
  • Provides a strong hint about the target's environment.
  • Guides further enumeration and exploitation.
Key Takeaway

OS detection with -O provides critical environmental context, influencing your vulnerability assessment and exploitation strategies.

Terminal Output Example
OS: Linux 2.6.X|3.X (Linux kernel 2.6.32 - 3.10)
OS CPE: cpe:/o:linux:linux_kernel:2.6.32
OS details: Linux 2.6.32 - 3.10
Network Distance: 1 hop
Service Info: OS: Linux; CPE: cpe:/o:linux:linux_kernel

OS detection performed. Please report any incorrect results at https://nmap.org/submit/.
Nmap done: 1 IP address (1 host up) scanned in 10.23 seconds
Concrete Example

If Nmap detects 'Linux 2.6.32 - 3.10', you know to focus on Linux-specific vulnerabilities and tools, rather than wasting time on Windows exploits. This significantly narrows down your attack surface.
