Essential Privilege Escalation Terms
Reinforcing Core Ideas
Privilege Escalation

The process of gaining higher-level access to a system than initially obtained, typically from a regular user to root or administrator.

SUID/SGID

Special permission bits that allow an executable file to run with the permissions of its owner (SUID) or group (SGID) rather than the user executing it.

Kernel Exploit

A vulnerability in the operating system's core (kernel) that can be exploited to gain elevated privileges, often root, but with significant risks of system instability.

Summary Takeaway

Mastering privilege escalation involves understanding how to leverage special permissions like SUID/SGID and identifying critical vulnerabilities in the kernel to gain full system control.
