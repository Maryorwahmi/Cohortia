Enumerating Sudo Permissions
Using sudo -l to Discover Opportunities
# Command to list sudo permissions
sudo -l
# Example output indicating NOPASSWD
User user is not allowed to run sudo on target-vm. This incident will be reported.
Matching Defaults entries for user on target-vm:
    env_reset, mail_badpass, secure_path=/usr/local/sbin
    :/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/snap/bin
User user may run the following commands on target-vm:
    (ALL) NOPASSWD: /usr/bin/vim
Key Takeaway

Always run sudo -l to identify commands executable as root without a password, as these are prime targets for immediate privilege escalation.

Interpreting Output
  • Look for lines starting with (ALL) NOPASSWD:.
  • The command listed after NOPASSWD: can be run as root without a password.
  • Even if not NOPASSWD, knowing what commands can be run as root is valuable.
Example Scenario

If sudo -l shows (ALL) NOPASSWD: /usr/bin/less, you can run sudo less and then type !/bin/bash inside less to get a root shell.
