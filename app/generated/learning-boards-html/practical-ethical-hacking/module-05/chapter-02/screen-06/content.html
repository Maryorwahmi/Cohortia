Discovering SUID/SGID Files
Using the find Command for Enumeration
# Command to find SUID binaries
find / -perm -u=s -type f 2>/dev/null
# Or using numeric permissions
find / -perm -4000 -type f 2>/dev/null
Key Takeaway

The find command with -perm -u=s (or -4000) and -type f is the standard way to enumerate SUID binaries, filtering errors for clean output.

Command Breakdown
  • find /: Starts the search from the root directory.
  • -perm -u=s: Searches for files with the SUID bit set for the owner.
  • -perm -4000: Numeric equivalent for the SUID bit.
  • -type f: Restricts the search to regular files only.
  • 2>/dev/null: Redirects standard error (e.g., permission denied messages) to /dev/null to keep the output clean.
Example Output

You might see entries like /usr/bin/passwd, /usr/bin/mount, or potentially less common binaries like /usr/bin/nmap if misconfigured. Each entry is a potential target.
