Misusing SUID/SGID Binaries
Turning Legitimate Tools into Root Shells
Common Vulnerable Binaries
  • nmap (older versions with interactive mode)
  • find (with -exec option)
  • vim, less, more, nano (allowing shell escapes)
  • Any SUID binary that can execute external commands.
Exploitation Principle

The goal is to find a way for the SUID program to execute an arbitrary command or spawn a shell, inheriting the owner's (e.g., root's) privileges.

Resource: GTFOBins

GTFOBins (gtfobins.github.io) is an invaluable resource that documents how to exploit various Unix binaries, including SUID/SGID ones, to achieve privilege escalation.

→ Consult GTFOBins for specific techniques
Key Takeaway

Always check GTFOBins for known exploitation methods once you've identified a potentially vulnerable SUID binary, as many common tools have documented misuse cases.
