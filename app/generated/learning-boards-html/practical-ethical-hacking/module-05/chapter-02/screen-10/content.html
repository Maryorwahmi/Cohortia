Gaining Root with Sudo
Leveraging sudo Allowed Commands for Shell Escapes
The Shell Escape Principle

Many interactive programs (like text editors or pagers) allow you to execute external shell commands from within their interface. When run with sudo, these commands inherit root privileges.

Example: vim Exploitation
  • Execute: sudo vim
  • Inside vim, type: :!/bin/bash
  • Press Enter to spawn a root shell.
Other Exploitable Utilities

Similar shell escape techniques exist for less, more, find, nano, and man when they are allowed to run with sudo NOPASSWD. Always consult GTFOBins for specific commands.

→ GTFOBins is your go-to resource
Key Takeaway

Leveraging shell escape features within sudo NOPASSWD commands is a highly effective way to gain a root shell, making tools like vim powerful escalation vectors.
