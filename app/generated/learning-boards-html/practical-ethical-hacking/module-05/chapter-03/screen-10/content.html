Discovery Technique

Querying Service Permissions

Using `sc qc` and `icacls` to check service configurations

Tools for Inspection

  • •
    `sc qc `: Queries service configuration (binary path, run account).
  • •
    `icacls `: Displays and modifies file/directory ACLs.
  • •
    `accesschk.exe`: Sysinternals tool for comprehensive permission checks.

Example: Checking Permissions

# Query service config
sc qc "Vulnerable Service"

# Check permissions on its binary
icacls "C:\Program Files\Vulnerable App\service.exe"
Key Takeaway

Look for 'Write' or 'Modify' permissions for 'Everyone' or 'Authenticated Users' on high-privilege service binaries.

Service Permission Audit Flow

List Services

Identify services of interest

Query Service Config (`sc qc`)

Get binary path and run account

Check File/Directory ACLs (`icacls`)

Determine write permissions

Exploit if Weak ACLs Found

Replace binary and restart service
