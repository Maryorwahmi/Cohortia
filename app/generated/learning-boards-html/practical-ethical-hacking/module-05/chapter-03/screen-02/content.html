Learning Objectives

What you'll achieve by the end of this chapter

LearnUnderstandApplyMaster
01

Understand Privilege Models

Grasp the differences in privilege models between Linux and Windows, including SIDs and ACLs. This is foundational for understanding Windows security contexts.

VERIFIED COMPETENCY MILESTONE
02

Identify Misconfigurations

Pinpoint common Windows misconfigurations and vulnerabilities that pave the way for privilege escalation. This includes weak service permissions and unquoted paths.

VERIFIED COMPETENCY MILESTONE
03

Utilize Built-in Commands

Leverage native Windows commands and PowerShell scripts to effectively discover privilege escalation paths. This includes tools like `systeminfo` and `wmic`.

VERIFIED COMPETENCY MILESTONE
04

Explain Service Exploits

Articulate how to exploit unquoted service paths and various service misconfigurations to gain elevated privileges. This is a common and effective technique.

VERIFIED COMPETENCY MILESTONE
