Core Concept

Windows Privilege Model

Understanding SIDs, ACLs, and the SYSTEM Account

Key Components

  • •
    Security Identifiers (SIDs): Unique values identifying users, groups, and security principals.
  • •
    Access Control Lists (ACLs): Define permissions on objects (files, registry keys) based on SIDs.
  • •
    SYSTEM Account: The most powerful local account, with extensive control over the OS.

Example: Weak ACLs

Imagine a service running as SYSTEM, but its executable file has weak ACLs allowing a standard user to modify it. An attacker could replace the legitimate executable with a malicious one, gaining SYSTEM privileges when the service restarts.

Pro Tip

Always check file and directory permissions for services running with high privileges.
