Service Vulnerabilities

Service Misconfigurations: Weak ACLs

Exploiting weak permissions on service executables

The Misconfiguration

  • •
    Service runs with high privileges (e.g., SYSTEM).
  • •
    Executable file or its directory has weak ACLs.
  • •
    Low-privileged user can modify or replace the executable.

Exploitation Scenario

An attacker replaces a legitimate service executable with a malicious reverse shell. When the service restarts, the reverse shell executes with SYSTEM privileges, granting the attacker full control.

Key Takeaway

Always check permissions on service binaries and their containing directories, especially for services running as SYSTEM.

Weak ACLs Attack Flow

Identify High-Privilege Service

e.g., runs as SYSTEM

Check ACLs on Executable/Directory

Look for write permissions for low-privileged users

Replace Executable with Payload

Inject malicious code

Restart Service

Execute payload with SYSTEM privileges
