Key Concepts: Part 1

Fundamental definitions for network traversal

Lateral Movement

Moving from one compromised system to another within the same network segment or directly accessible segments.

Pivoting

Using a compromised host as an intermediary to access otherwise unreachable network segments or internal systems.

Pass-the-Hash (PtH)

A lateral movement technique using an NTLM hash to authenticate to Windows systems without the cleartext password.

Summary Takeaway

Lateral movement and pivoting are essential post-exploitation techniques, with PtH being a key method for credential-based lateral access.
