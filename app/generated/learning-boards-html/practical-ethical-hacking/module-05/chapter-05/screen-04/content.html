Module 6›Chapter 5.5›Lateral Movement vs. Pivoting

Lateral Movement

The process of moving from one compromised system to another within the same network segment or across directly accessible segments.

  • **Goal:** Expand foothold within reachable network areas.
  • **Scope:** Directly accessible hosts.
  • **Analogy:** Moving between rooms on the same floor.
  • **Example:** Accessing another workstation on the same subnet after compromising the first.
Key Characteristic

Relies on direct network connectivity between the compromised host and the target system.

Pivoting

Using a compromised host as a relay or jump box to access otherwise unreachable network segments or internal systems.

  • **Goal:** Access isolated or segmented network zones.
  • **Scope:** Unreachable hosts via an intermediary.
  • **Analogy:** Using a secret passage to access a different, isolated section of a building.
  • **Example:** Using a DMZ web server to reach an internal database server.
Key Characteristic

Establishes a tunnel or proxy through the pivot host to bypass network segmentation.

Key Takeaway

Lateral movement expands access within reachable networks, while pivoting bridges gaps to isolated network segments using a compromised host as a relay.
