What is a Pivot Point?

A pivot point is a compromised host that serves as an intermediary to route traffic from your attacking machine to otherwise unreachable network segments.

  • **Necessity:** Used when direct access to a target network is blocked (e.g., by firewalls).
  • **Function:** Acts as a relay, forwarding your network traffic.
  • **Location:** Often a server in a DMZ or an internal workstation with dual-homed network interfaces.
Why it Matters

Pivoting is essential for deep network penetration, allowing you to bypass segmentation and reach high-value targets in isolated internal networks.

Key Takeaway

A pivot point is a compromised system that acts as a bridge, enabling access to otherwise isolated internal network segments from an external attacking machine.
