Module 6›Chapter 5.5›Initial Network Enumeration

Windows Enumeration

# List accessible machines/shares in domain/workgroup
net view /domain
net view

# List local shares on current host
net share

# Example Output:
# Server Name            Remark
# --------------------------------------------------------------------------
# \\SERVER01             File Server
# \\WORKSTATION02        User Workstation
# The command completed successfully.
Purpose

Identify other Windows hosts and shared resources that can be accessed directly from the current compromised system.

Linux Enumeration

# Enumerate SMB shares on a target IP
smbclient -L //<TARGET_IP>

# Example:
smbclient -L //192.168.1.105

# Example Output:
# Sharename       Type      Comment
# ---------       ----      -------
# IPC$            IPC       Remote IPC
# ADMIN$          Disk      Remote Admin
# Users           Disk      User Home Directories
# The command completed successfully.
Purpose

Discover SMB shares on Linux or Windows targets from a Linux compromised host, often revealing potential data or access points.

Key Takeaway

Effective network enumeration is the foundation of lateral movement, providing a roadmap of accessible systems and resources within the network.
