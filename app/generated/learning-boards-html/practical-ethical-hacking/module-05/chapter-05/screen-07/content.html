Pass-the-Ticket (PtT)

Pass-the-Ticket (PtT) is a lateral movement technique that leverages stolen Kerberos tickets to authenticate to other systems within an Active Directory domain.

  • **Mechanism:** Kerberos tickets are session tokens that prove authentication.
  • **Vulnerability:** Tickets can be extracted from memory (e.g., with Mimikatz).
  • **Advantage:** Allows authentication to Kerberos-enabled services without needing passwords or hashes.
How it Works

An attacker injects a stolen Kerberos ticket into their current session, allowing them to impersonate the legitimate user and access resources.

RDP & SSH Hopping

If credentials (passwords or SSH keys) for another machine are found, direct remote access protocols like RDP or SSH can be used for lateral movement.

  • **RDP (Windows):** Use mstsc to connect to another Windows machine.
  • **SSH (Linux):** Use ssh user@target_ip to connect to another Linux machine.
  • **Advantage:** Simple and direct if valid credentials are available.
Example

After compromising Host A and finding credentials for Host B, simply SSH or RDP directly from Host A to Host B.

Key Takeaway

PtT exploits Kerberos tickets for authentication, while RDP/SSH hopping provides direct access when cleartext credentials or keys are available, both facilitating lateral movement.
