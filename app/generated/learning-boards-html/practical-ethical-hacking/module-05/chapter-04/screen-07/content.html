Linux Persistence

Advanced Linux Persistence Techniques

Exploring startup scripts, backdoored binaries, and rootkits.

Startup Scripts

  • Modify files like /etc/rc.local, systemd units, or init.d scripts.
  • Payload executes automatically on system boot.
  • Detection: Reviewing system startup configurations and logs.

Backdoored Binaries

  • Replace legitimate utilities (e.g., su, login) with malicious versions.
  • Payload runs before the original function, providing stealthy access.
  • High risk of system instability and detection via file integrity checks.
Key Takeaway

While powerful, advanced Linux persistence methods often carry higher risks of detection or system instability compared to simpler techniques.

Startup Scripts

Injecting payloads into system initialization files for execution on boot.

Backdoored Binaries

Replacing core system executables with malicious versions that also run a payload.

Rootkits

Sophisticated tools designed to hide their presence and provide backdoor access, often complex to implement.
