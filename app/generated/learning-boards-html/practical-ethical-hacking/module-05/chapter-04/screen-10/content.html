Windows Persistence

Stealthy Windows Persistence

Startup folders, services, WMI, and Sticky Keys backdoor.

Startup Folders

  • Place executables in C:\ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp.
  • Simple, but easily discoverable by users or security tools.

Malicious Services

  • Use sc create to register a new service that runs your payload.
  • Runs in the background, often with high privileges, and can start automatically.
Key Takeaway

Windows offers a spectrum of persistence methods, from simple startup entries to advanced, event-driven WMI techniques, each with varying levels of stealth and complexity.

WMI Event Subscriptions

Event-driven persistence that triggers code execution based on specific system events, making it very stealthy.

Sticky Keys / Utilman Backdoor

Replacing accessibility tools with cmd.exe for SYSTEM shell access from the login screen.
