Key Concepts

Essential Terms to Remember

Persistence

The ability to maintain access to a compromised system across reboots, loss of initial shells, or patching of original vulnerabilities.

SSH Public Key Persistence

Installing an attacker's public SSH key on a target Linux system to allow passwordless SSH login.

Cron Job Persistence

Scheduling malicious commands or scripts to run at regular intervals on Linux systems using the cron daemon.

Summary Takeaway

Linux persistence relies on leveraging built-in system functionalities like SSH for remote access and cron for automated task execution to maintain a foothold.
