Key Concepts

Essential Terms to Remember

Registry Run Keys

Windows registry entries that automatically execute programs when a user logs on or the system starts.

Scheduled Tasks (Windows)

Using the schtasks utility to create automated tasks that execute payloads at specific times or events.

WMI Event Subscriptions

A stealthy Windows persistence method that triggers code execution based on system events using Windows Management Instrumentation.

Summary Takeaway

Windows persistence leverages built-in features like the registry, task scheduler, and WMI to ensure payloads execute reliably and often stealthily.
