Locating Sensitive Files on Linux

The file system is a rich source of sensitive information, including credentials, API keys, and configuration data. Knowing where to look is key.

  • •
    /etc: System-wide configuration files (e.g., /etc/passwd, /etc/sudoers).
  • •
    /var/log: System and application log files, sometimes containing sensitive data.
  • •
    /home/<user>/.ssh: User SSH keys, potentially granting access to other systems.
  • •
    /var/www/html: Web server files, often containing web application credentials.
  • •
    /opt or /usr/local: Installed applications that might have their own config files.
Key Takeaway

Targeted file system exploration using commands like find is highly effective for uncovering credentials and critical configuration data.

Terminal Demo: Linux File Search

user@target:~$ find /etc -name "*.conf" 2>/dev/null
/etc/apache2/apache2.conf
/etc/mysql/mysql.conf.d/mysqld.cnf
/etc/ssh/sshd_config
/etc/sudoers.d/user_sudo.conf

user@target:~$ find /home -name "id_rsa" 2>/dev/null
/home/user/.ssh/id_rsa

user@target:~$ grep -r "password" /var/www/html 2>/dev/null
/var/www/html/config.php:$db_password = 'SuperSecretPassword123';
Example Context

Finding id_rsa in a user's .ssh directory could lead to SSH access to other systems, while a password in config.php is a direct credential leak.
