User & Process Enumeration

Discovering Linux Users and Running Processes

Identifying local user accounts and active processes helps uncover potential privilege escalation vectors and suspicious activity.

  • •
    cat /etc/passwd: Lists local user accounts, their UIDs, GIDs, home directories, and shells.
  • •
    cat /etc/shadow: (Requires root) Contains hashed passwords for local users.
  • •
    ps aux: Displays all running processes, including user, PID, CPU/memory usage, and command.
  • •
    Privilege Escalation: Look for processes running as root or unusual applications that might be vulnerable.
Key Takeaway

Enumerating users and processes provides insight into system activity and potential weak points for privilege escalation or maintaining access.

Terminal Demo: Linux Users & Processes

user@target:~$ cat /etc/passwd

Pro Tip

Look for unusual processes running as 'root' or other privileged users, as these could be custom applications with vulnerabilities or even backdoors.
