Network Reconnaissance

Mapping Linux Network Interfaces and Routes

Understanding the network configuration is vital for lateral movement and discovering other connected systems within the target network.

  • •
    ip a (or ifconfig): Lists all network interfaces and their associated IP addresses.
  • •
    ip r (or route -n): Displays the routing table, showing how the system communicates with other networks.
  • •
    netstat -tulnp: Shows listening ports, established connections, and the process IDs (PIDs) owning them.
  • •
    Lateral Movement: Routing tables and active connections reveal paths to other internal systems.
Key Takeaway

Thorough network enumeration provides a roadmap for expanding your access within the network and identifying valuable targets or services.

    inet 127.0.0.1/8 scope host lo

    inet 192.168.1.100/24 brd 192.168.1.255 scope global dynamic eth0

Example Context

netstat -tulnp showing a MySQL server listening on 127.0.0.1:3306 indicates a local database that might contain sensitive data.
