Initial Access

Confirming Privileges on Windows

On Windows, understanding your current user and group memberships is key to assessing your capabilities and planning next steps.

  • •
    whoami: Displays the current user and domain, e.g., DOMAIN\user.
  • •
    whoami /groups: Lists all security groups the user belongs to, including critical ones like 'Administrators'.
  • •
    Administrator Access: Membership in the 'Administrators' group grants significant control over the system.
  • •
    Domain Context: Helps identify if the machine is part of a larger Active Directory environment.
Key Takeaway

Knowing your Windows user and group context is essential for identifying potential privilege escalation paths and understanding the scope of your access.

Terminal Demo: Windows Privilege Check

C:\Users\user> whoami
computername\user

C:\Users\user> whoami /groups
...
Group Name:   BUILTIN\Administrators
Type:         Alias
SID:          S-1-5-32-544
Attributes:   Mandatory group, Enabled by default, Enabled group
...

C:\Users\Administrator> whoami
computername\administrator
Example Context

If whoami /groups shows 'BUILTIN\Administrators', you have local administrative privileges, opening many doors for further actions.
