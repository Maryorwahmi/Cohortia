Network Reconnaissance

Mapping Windows Network Details

On Windows, understanding network interfaces, IP addresses, and active connections is crucial for identifying lateral movement opportunities.

  • •
    ipconfig /all: Provides detailed network configuration for all adapters, including IP, MAC, DNS, and DHCP info.
  • •
    netstat -ano: Displays all active TCP connections and listening ports, along with the Process ID (PID) for each.
  • •
    PID Correlation: The PID allows you to identify the specific process owning a connection, revealing its purpose.
  • •
    Lateral Movement: Active connections to other internal systems are prime targets for pivoting.
Key Takeaway

Detailed network information on Windows, especially active connections and their associated processes, provides clear pathways for expanding your access within the network.
