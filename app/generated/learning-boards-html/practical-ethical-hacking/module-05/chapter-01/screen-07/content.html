System Enumeration

Identifying Linux System Details

Understanding the operating system, kernel version, and hostname is vital for identifying potential vulnerabilities and tailoring your attacks.

  • •
    uname -a: Provides kernel name, network node hostname, kernel release, kernel version, machine hardware name, and operating system.
  • •
    cat /etc/os-release: Displays distribution-specific information like name, version, and ID.
  • •
    hostname: Shows the system's network name.
  • •
    Kernel Version: Critical for finding kernel exploits.
Key Takeaway

Detailed system information helps in identifying specific vulnerabilities, especially kernel exploits, and understanding the target's role in the network.

Terminal Demo: Linux System Info

user@target:~$ uname -a
Linux target 5.4.0-42-generic #46-Ubuntu SMP Fri Jul 10 00:24:02 UTC 2020 x86_64 x86_64 x86_64 GNU/Linux

user@target:~$ cat /etc/os-release
NAME="Ubuntu"
VERSION="20.04 LTS (Focal Fossa)"
ID=ubuntu
ID_LIKE=debian
PRETTY_NAME="Ubuntu 20.04 LTS"
VERSION_ID="20.04"
...

user@target:~$ hostname
target
Pro Tip

The kernel version from uname -a is a prime candidate for searching public exploit databases like Exploit-DB for known kernel vulnerabilities.
