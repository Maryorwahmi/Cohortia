Performing Initial Post-Exploitation Tasks

Learn to gather system information and navigate the file system using Meterpreter's core commands.

Meterpreter Command Walkthrough

meterpreter > sysinfo
Computer : METASPLOITABLE
OS : Linux Metasploitable 2.6.24-16-server #1 SMP Thu Apr 10 13:23:42 UTC 2008 i686
Architecture : i686
System Language : en_US
Meterpreter : i686/linux

meterpreter > getuid
Server username: uid=0(root) gid=0(root) groups=0(root)

meterpreter > pwd
/usr/share/metasploit-framework

meterpreter > ls
... (directory contents) ...

Understanding `sysinfo`

The sysinfo command provides crucial details about the target's operating system, architecture, and uptime. This helps in identifying further vulnerabilities or compatible tools.

Checking Privileges with `getuid`

getuid reveals the current user ID and group IDs. This is vital for understanding your access level and determining if privilege escalation is necessary.

Key Takeaway

Mastering basic Meterpreter commands like sysinfo, getuid, ls, and pwd is fundamental for effective post-exploitation reconnaissance.
