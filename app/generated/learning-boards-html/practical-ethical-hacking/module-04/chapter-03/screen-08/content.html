Execution & Access

Launching the Exploit and Gaining a Shell

From vulnerability to initial command-line access.

What Happens Next?
  • Metasploit sends crafted data to target.
  • Payload executes on the vulnerable service.
  • Reverse connection established to attacker.
  • Basic command shell is granted.
Key Takeaway

A successful exploit grants a basic command shell, providing initial access but often with limited capabilities, setting the stage for further post-exploitation.

Shell Limitations

Basic shells often lack advanced features like tab completion, easy file transfer, or direct process manipulation, highlighting the need for session upgrades.
