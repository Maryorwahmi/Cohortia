Vulnerability

A weakness or flaw in a system's design, implementation, or operation that could be exploited. It's the 'unlocked door'.

Passive State

Exploit

A piece of software or method that takes advantage of a specific vulnerability. It's the 'key' or 'technique' to open the door.

Active Tool

Payload

The malicious code or action executed on the target system after a successful exploit. It's 'what you do' once inside the door.

Desired Outcome

Concrete Example: Web Server Attack

A web server has an outdated software version (Vulnerability). An attacker uses a known script that sends a specially crafted request to trigger a buffer overflow (Exploit). This allows them to execute a command that creates a new administrator user (Payload).

Key Takeaway

Understanding the distinct roles of vulnerabilities, exploits, and payloads is crucial for dissecting and constructing effective attack chains in ethical hacking.
