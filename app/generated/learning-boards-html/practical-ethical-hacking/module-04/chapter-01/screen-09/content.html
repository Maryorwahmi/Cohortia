Command Usage

The `search` Command

The `search` command allows you to find Metasploit modules (exploits, payloads, auxiliary) based on keywords, CVE IDs, or platform specifics. It's your first step to finding a relevant tool.

  • •Keyword Matching: Search by service name, vulnerability type, or software.
  • •Filtering: Use `type:exploit` or `platform:windows` for refined results.
  • •Efficiency: Quickly narrows down thousands of modules.
Key Takeaway

Mastering the `search` command is essential for efficiently locating the correct Metasploit module to match your identified target vulnerabilities.

Example: Targeted Search

If you know a target is running `vsftpd` version 2.3.4, searching for `vsftpd` will quickly reveal the `exploit/unix/ftp/vsftpd_234_backdoor` module, which is exactly what you need to investigate further.
