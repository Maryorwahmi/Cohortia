Command Workflow

`use`, `show options`, `set`

These commands are fundamental for preparing an exploit: `use` to select, `show options` to inspect, and `set` to configure parameters like target and listener IPs.

  • •`use [module_path]`: Loads the specified exploit module.
  • •`show options`: Displays all configurable options for the loaded module.
  • •`set [option] [value]`: Assigns a value to a specific option.
Key Takeaway

Accurate configuration of exploit options, especially `RHOSTS` and `LHOST`, is paramount for successful exploitation and establishing a connection.

Example: Setting `LHOST`

For payloads that require a connection back to your machine (like a reverse shell), you'd also use `set LHOST [your_ip_address]` to tell the payload where to connect.
