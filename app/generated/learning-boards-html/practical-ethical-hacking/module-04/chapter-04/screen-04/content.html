Core Concept

What is Privilege Escalation?

The process of gaining higher-level access rights on a system than initially obtained, typically moving from a standard user to an administrator (Windows) or root (Linux).

Why it Matters
  • Full System Exploration: Access restricted files and directories.
  • Data Exfiltration: Retrieve sensitive information that was previously inaccessible.
  • Persistence: Establish more robust and stealthy backdoors.
  • Impact Demonstration: Show the true severity of an initial compromise to stakeholders.

Key Takeaway

Privilege escalation is a critical post-exploitation step, transforming limited access into comprehensive control, vital for demonstrating true security impact.
