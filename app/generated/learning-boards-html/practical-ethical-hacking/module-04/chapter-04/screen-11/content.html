PowerUp.ps1: Your Windows Ally

A powerful PowerShell script (part of PowerSploit) that identifies common Windows privilege escalation vectors.

  • Detects unquoted service paths.
  • Identifies vulnerable service permissions.
  • Scans for insecure registry settings.
Example Use

Import-Module .\PowerUp.ps1; Invoke-AllChecks will run all checks and report findings.

PowerUp.ps1 Capabilities
Unquoted Service Paths
Vulnerable Service Permissions
Insecure Registry Settings
Key Takeaway

PowerUp.ps1 is an indispensable tool for automating the discovery of Windows privilege escalation vulnerabilities.
