Objective

Locating SUID Binaries

On a vulnerable Linux VM, identify SUID binaries as a precursor to researching potential privilege escalation vectors.

  • Gain a low-privileged shell on a target VM (e.g., Metasploitable2).
  • Use the find command to locate SUID-enabled executables.
  • Look for unusual or vulnerable binaries in the output.
Why it Matters

Identifying SUID binaries helps pinpoint programs that run with elevated privileges, making them prime targets for exploitation.

Command Example
find / -perm -4000 -type f 2>/dev/null

This command searches the entire filesystem for files with the SUID bit set, redirecting errors to null for clean output.

Key Takeaway

The find command with -perm -4000 is your primary tool for discovering SUID binaries on Linux systems.
