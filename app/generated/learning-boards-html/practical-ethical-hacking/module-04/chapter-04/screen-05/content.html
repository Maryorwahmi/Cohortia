Main Privilege Escalation Categories

Privilege escalation techniques can be broadly categorized based on the type of vulnerability they exploit.

Key Categories
  • Kernel Vulnerabilities: Exploiting flaws in the OS core.
  • Misconfigurations: Insecure settings in services or systems.
  • Weak File Permissions: Exploiting improper access controls.
  • Password Reuse/Defaults: Leveraging compromised or default credentials.

Key Takeaway

Privilege escalation vulnerabilities span kernel flaws, system misconfigurations, and weak access controls, often simpler than perceived.
