Comparison

Logical View

Describe components by responsibility and the data they share.

User Management — identity, authentication, profile data.
Photo Upload — validation, storage interface, upload API.
Feed Generation — ranking, aggregation, personalization logic.
Social Interaction — likes, comments, follow graph management.
Misconception

Do not include deployment details or infrastructure in the logical view. Save those for the physical view to keep responsibilities clear.

Example component descriptions
Feed Generation
Responsibility:
Aggregate posts, rank items, and produce paginated feeds for users. Does not manage physical storage or CDN config.
Photo Upload
Responsibility:
Validate content, create metadata records, and hand off to object storage. Does not process feed ranking.
Developer prompt
Write one‑sentence contracts
For each component write: "This component owns X and must not do Y." Use those sentences to drive interface boundaries and tests.
