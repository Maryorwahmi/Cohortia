Essential Elements

Core elements

A compact set of items keeps documentation useful and maintainable.

  • Architectural goals & constraints — what problems and limits guide design.
  • ADRs — decision, alternatives, rationale, and consequences.
  • Quality attribute scenarios — concrete cases for performance, availability, and security.
  • Glossary — shared terms and acronyms to avoid ambiguous language.
Practical example
Photo Sharing App index
Goals: support millions of users; ADRs: S3 vs object store; Scenarios: peak concurrent uploads; Glossary: feed window, CDN edge.
Maintenance tip
Keep the ledger concise
Record why a decision was made and where detailed implementation docs live, then schedule regular ADR reviews.
Avoid over-documenting

If every low‑level change gets recorded, documentation becomes heavy and falls out of date. Focus on decisions and scenarios that matter.
