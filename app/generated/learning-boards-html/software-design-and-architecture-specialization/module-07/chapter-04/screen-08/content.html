Module 7 › Chapter 7.4 › Prototypes
Definition
Working vertical slices for risky areas

Use prototypes to validate feasibility, performance, and integration of critical components.

Prototype example
Build a message queue integration vertical slice to measure latency and failure behavior under representative load.
Scope guidance
  • Keep scope narrow and time-boxed.
  • Define success criteria up front.
  • Label artifacts as experimental results, not production code.
Benefits
Concrete evidence, early discovery of integration problems, informed decision-making.
Risks
Confusing prototype for final code and underestimating production engineering effort.
Key takeaway
Use prototypes to inform decisions and pair them with governance and automated checks later.
