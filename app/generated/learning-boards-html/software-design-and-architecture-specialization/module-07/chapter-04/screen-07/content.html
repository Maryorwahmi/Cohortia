What to model
Queues, resources, and workloads

Represent components, service latencies, concurrency limits, and arrival patterns to predict system behavior.

Steps
  1. Define scope and metrics.
  2. Create model of components and interactions.
  3. Run scenarios and analyze trends.
  4. Validate assumptions with small-scale data.
Example
A queuing model predicts that adding worker threads past a threshold yields diminishing latency improvements due to database connection limits.
Strengths
Explore scenarios early with low build cost.
Limitations
Results depend on model fidelity and workload assumptions.
Key takeaway
Use simulations to narrow options, then validate selected designs with prototypes or measurements.
