Architect's Practices

Lead by example: consistently record ADRs and keep diagram definitions in the repo.

Provide templates and tool choices so contributors spend less time deciding how to document.

Integrate documentation checks into reviews and set lightweight standards for when updates are required.

Practical Milestones
  • Template for ADRs with fields for context, decision, consequences, and alternatives.
  • Place diagram definition files in code folders and link them from ADRs or README files.
  • Make a pull-request checklist item to update docs if the change affects architecture or deployment.
Verified Competency Milestone
Successfully link an architectural change to an ADR and a rendered diagram in a pull request.
