PlantUML snippet (store as .puml)
@startuml actor "Client" as client boundary "API Gateway" as api_gateway control "User Service" as user_service database "User DB" as user_db control "Product Service" as product_service database "Product DB" as product_db client -> api_gateway : Request api_gateway --> user_service : Authenticate user_service --> user_db : Query User user_service --> api_gateway : Auth Token api_gateway --> product_service : Get Products product_service --> product_db : Query Products product_service --> api_gateway : Product Data api_gateway --> client : Response @enduml
Place this file next to the code that defines service interfaces. When a related change is submitted, update the .puml in the same pull request so reviewers see both code and diagram diffs.
Practical notes
  • CI can run PlantUML to render images automatically and publish them to the docs portal.
  • Diffs of .puml files are readable and make review straightforward.
  • Keep naming conventions and directories consistent so artifacts are easy to find.
Key Takeaway

Text-based diagram definitions let you version, diff, and automate visuals alongside code changes.
