Scenario Walkthrough
Probe architecture behavior and document findings
Ask concrete questions about data paths, error handling, and timing budgets. Sketch component interactions for clarity. Use the approach inventory to focus the inquiry.
What to record
  • Architectural Risks
  • Sensitivity Points
  • Trade-offs
Recorded finding: Risk
Single centralized queue creates single point of failure for availability.
Recorded finding: Sensitivity
Broker latency is a sensitivity point influencing end-to-end latency under load.
Recorded finding: Trade-off
Introducing end-to-end encryption improves security but increases processing latency.
Pro Tip
Frame questions that reveal assumptions and measures, not opinions.
Watchout
Avoid long technical debates; capture the assumption and move to the next scenario if necessary.
Check
After each walkthrough, ask whether findings should be prioritized for mitigation or investigation.
