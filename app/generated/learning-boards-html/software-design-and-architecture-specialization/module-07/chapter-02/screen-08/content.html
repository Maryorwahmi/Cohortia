Module 7 › Chapter 7.2 › Authentication Scenario
Filled template
Source: Unauthorized external attacker
Stimulus: 100 login attempts within 10 seconds using various credentials
Artifact: User Authentication Service
Environment: Production, normal load
Response: Detect brute-force pattern and temporarily block attacker's IP for 5 minutes
Response Measure: Less than 1% legitimate user impact; attacker prevented for block duration
Design probes
Which design elements satisfy detection and blocking with this response measure? Consider rate limiting, IDS rules, and logging for forensics.
Architecture implications
  • Rate limiting at edge vs service-level limits affects false positive rates and legitimate user impact.
  • Blocking by IP requires consideration of NAT, proxies, and legitimate shared addresses.
  • Logging and monitoring must support detection within the time window.
Key Takeaway

A structured scenario connects concrete requirements to architectural questions and measurable acceptance criteria.
