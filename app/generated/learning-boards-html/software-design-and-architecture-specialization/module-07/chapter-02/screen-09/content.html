Module 7 › Chapter 7.2 › Scenario Comparison
Operational
Tests everyday correctness and user experience under normal load.
Example
Dashboard renders within target latency.
Growth
Tests adaptability to increased load or new features without major redesign.
Example
Support 50% more concurrent users in six months.
Exploratory
Tests failure modes and stress conditions to ensure resilience.
Example
Automatic failover within 30 seconds after DB failure.
Practical guidance
Include at least one scenario of each type in a QAW. Evaluate proposed designs against each scenario to reveal hidden trade-offs like latency vs consistency or flexibility vs complexity.
