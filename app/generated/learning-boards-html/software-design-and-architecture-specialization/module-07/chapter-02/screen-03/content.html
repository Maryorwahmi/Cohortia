Write Structured Scenarios
Use the six-part template to make responses measurable and testable. Each field answers a clear question: who triggers it, what happens, which component is involved, where it occurs, how the system should react, and how success is measured.
Mnemonic
Source, Stimulus, Artifact, Environment, Response, Response Measure — S-S-A-E-R-M.
Practice Task
Draft one operational and one exploratory scenario for a system you know using the template, then add measurable response measures.
Prioritize & Probe
After scenarios are collected in a QAW, rank them by impact and likelihood to focus evaluation. Use each scenario to generate questions about the architecture: which components must change, where are single points of failure, and what trade-offs arise between attributes.
Why it helps
Prioritization ensures limited design time addresses the most important concerns first, revealing critical trade-offs early.
Competency
You can convert scenarios into architecture probes and list the elements to evaluate for each scenario.
