Module 7 › Chapter 7.2 › Scenario Structure
Six fields
  • Source: who or what initiates the action.
  • Stimulus: the triggering event.
  • Artifact: the component or subsystem involved.
  • Environment: conditions under which the stimulus occurs.
  • Response: how the system reacts.
  • Response Measure: quantifiable success criteria.
Example field
Response Measure might be a recovery time objective or a percentage of successful requests, which makes acceptance testable.
Practice card
Fill the six fields for a single scenario. If any field is missing or imprecise, iterate until you have a measurable response measure and clear environment definition.
Common error
Skipping environment or using vague measures like "fast" rather than a numeric target.
Pro tip
Prefer percentages and time bounds (e.g., 99.5% requests under 300 ms) to make testing straightforward.
