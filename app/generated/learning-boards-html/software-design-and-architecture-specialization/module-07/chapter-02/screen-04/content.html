Module 7 › Chapter 7.2 › What Is a Quality Attribute?
Definition
A non-functional characteristic that defines the system's quality, such as performance, security, availability, scalability, maintainability, usability, and deployability.
Concrete example
"95% of dashboard views render within 200 milliseconds during normal load." This turns performance into a measurable expectation.
Common misconception
Treating attributes as vague desires like "must be secure" without specifying how to measure or detect success.
Why it matters
Measurable quality attributes enable objective evaluation and reveal architectural trade-offs early.
Attribute cards
Performance
Response time, throughput.
Security
Authentication, authorization, data privacy.
Availability
Uptime, fault tolerance.
Scalability
Handle increased load.
Key Takeaway

Translate non-functional wishes into measurable goals to guide design and evaluation.
