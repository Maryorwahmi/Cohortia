Module 7 › Chapter 7.2 › Probe Architecture
Probe checklist
  • Which components handle the stimulus and response?
  • Are there single points of failure or capacity limits?
  • What trade-offs arise between consistency, latency, and availability?
  • What patterns (caching, replication, sharding) might satisfy the scenario?
Example probe
Scenario: confirmation displayed within 500 milliseconds. Questions: does the current data path include blocking calls to external services? Can we cache or precompute responses? Will caching affect consistency for concurrent orders?
Action
Document sensitivities, propose mitigations, and set measurable acceptance criteria for each mitigation.
