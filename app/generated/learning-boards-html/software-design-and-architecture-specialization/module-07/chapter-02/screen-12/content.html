Module 7 › Chapter 7.2 › Crafting Scenarios
Activity instructions
  1. Choose two quality attributes critical to a real-time trading platform.
  2. For each attribute, write one operational, one growth, and one exploratory scenario using the six-field template.
  3. Give numeric response measures and environment details for each scenario.
  4. Prioritize the scenarios and list three architecture probes for the top two.
Example (Operational)
Source: Logged-in trader. Stimulus: Place buy order. Artifact: Order Processing Service. Environment: Normal market hours. Response: Order validated and confirmed. Response Measure: Confirmation displayed within 500 ms and acknowledged by exchange within 1 second.
Example (Growth)
Scenario: Support 50% increase in concurrent orders within six months without major redesign; measure by peak throughput and queue lengths under load tests.
Example (Exploratory)
Scenario: Primary matching engine fails; system reroutes to standby within 30 seconds with no order loss; measure by lost-order count = 0 and failover <= 30s.
