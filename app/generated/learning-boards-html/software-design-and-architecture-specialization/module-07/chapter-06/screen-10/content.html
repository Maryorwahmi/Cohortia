Scaffold and commit
Create an ADR with a standard header, fill sections, and commit to docs/arch/decisions to keep the reasoning with code.
Example file path: docs/arch/decisions/0001-use-kafka-for-notifications.md
Workflow tips
  • Run scaffolding when the decision is made.
  • Include the ADR in the pull request for reviewers.
  • Create a new ADR to supersede an old one rather than editing historical reasoning away.
Why this helps
Standardized ADR files make it easier for readers to find reasoning and for automation to list or index decisions.
