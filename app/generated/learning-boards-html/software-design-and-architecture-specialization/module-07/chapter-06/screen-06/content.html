Module 07 › Chapter 7.6 › Which decisions need ADRs?
Decision filters
Use quick filters to decide if an ADR is warranted.
Impact
Does the decision affect many teams, releases, or operational processes?
Reversibility
Is reversing this decision costly or risky? If yes, document it.
Assumptions
Does the decision rely on assumptions that may change? Capture them explicitly.
Examples that need ADRs
  • Choosing microservices vs monolith
  • Selecting a core messaging system (Kafka vs RabbitMQ)
  • Authentication and authorization strategy
  • Primary data storage technology
Common mistake
Documenting too many trivial choices dilutes the value of ADRs and creates maintenance burden.
