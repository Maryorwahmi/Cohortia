Definition Feature stores & data versioning
Feature engineering as infrastructure
Treat features and datasets as managed artifacts to ensure consistency and reproducibility.
Concrete example
A user average purchase value computed once and exposed for both training and online inference avoids skew and reduces duplication.
Common pitfall
Ad-hoc feature code across services causes subtle differences and production regressions.
Operational practices
  • Feature contracts and schemas
  • API-backed feature serving for online inference
  • Dataset snapshots and version tags for training runs
Key Takeaway

Manage features and datasets centrally to reduce skew and enable reproducible model development and audits.

Scenario
When a source field changes, versioned datasets and feature store contracts let you detect the impact before deploying a new model.
Checklist
Define schemas, snapshot datasets per run, and expose features via stable APIs for online inference.
