Definition Monitoring & retraining
Detect drift and decide when to retrain
Combine statistical tests and business metrics to detect when models lose effectiveness.
What to monitor
  • Model metrics: accuracy, precision, recall, CTR
  • Data drift: statistical tests on feature distributions
  • Operational metrics: latency, errors, resource usage
Retraining options
Scheduled, triggered by performance, or hybrid approaches depending on cost and business impact.
Concrete example
Trigger retraining when click-through rate drops more than a defined percentage versus baseline, otherwise run weekly retraining to capture slow trends.
Key Takeaway

Monitoring must include business metrics as well as statistical tests; use those signals to decide retraining frequency.

Alert triggers
Examples: >5% drop in CTR, statistical shift in input distribution, or rising error rates at the prediction endpoint.
Misconception
Operational metrics don't reveal relevance; a healthy server can still deliver poor recommendations if the model drifts.
