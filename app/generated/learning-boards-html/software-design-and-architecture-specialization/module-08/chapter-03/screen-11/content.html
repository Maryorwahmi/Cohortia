Hands-on Activity

Design the image pipeline

1. Trigger
Object creation event from storage containing bucket and key.
2. Functions
  • ImageProcessorFunction: generate thumbnail and medium images.
  • MetadataUpdaterFunction: record processing results in a database.
3. Storage
Originals in original-images, thumbnails in my-app-thumbnails, medium in my-app-medium-images.
4. Cold-start strategy: use provisioned concurrency for real-time user flows or accept slight delays for background processing.
Key Takeaway

Split responsibilities, use external stores for durability, and select cold-start mitigations based on latency needs.

Workflow outline
  1. User uploads image to original-images bucket.
  2. Storage emits ObjectCreated event with bucket and key.
  3. ImageProcessorFunction downloads image and generates variants.
  4. Function uploads thumbnails and medium images to respective buckets.
  5. MetadataUpdaterFunction stores metadata in the database and emits completion.
Check your design
Which steps need immediate response and which can be deferred? That choice determines provisioning and cost.
