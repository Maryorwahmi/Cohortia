Module 08 › Chapter 8.3 › Quick Reference
Event-driven
Functions run in response to events like HTTP, storage, queue, or timer triggers.
Stateless
Keep session or durable data in external stores to support scaling.
Mitigate cold starts
Use small packages, lazy init, or provisioned concurrency for latency-critical paths.
One-line decision check
Is the work short, event-triggered, and decomposable? If yes, serverless likely fits; if no, consider other compute models.
