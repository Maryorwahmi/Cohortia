Use Cases

Where FaaS excels

Event-driven data processing — image resizing, stream transforms.
Backend APIs — single-endpoint functions behind an API gateway.
Scheduled tasks — daily reports, cron-like jobs without servers.
Glue and integrations — transform and forward events between services.
Design note
Favor many small functions each with a single responsibility rather than one large monolith function.
Scenario cards
Image processing pipeline
Upload triggers a function to generate thumbnails and a separate function to update metadata.
Mobile backend API
Endpoints implemented as small functions with an API Gateway handling auth and routing.
Scheduled backups
Timer-triggered functions perform periodic maintenance without persistent servers.
Key Takeaway

Match workloads that are short-lived, event-driven, and decomposable to serverless functions for best results.
