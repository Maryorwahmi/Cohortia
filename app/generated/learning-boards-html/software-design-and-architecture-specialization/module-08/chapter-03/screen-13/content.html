Module 08 › Chapter 8.3 › Key Concepts
Serverless Computing
Provider-managed servers, you run code without provisioning machines.
Stateless Function
Do not store persistent state in functions; use external databases, storage, or caches.
Pay-per-execution
Billing is based on the compute time and number of invocations, not idle servers.
Summary
Use serverless for short, event-driven tasks that benefit from automatic scaling and pay-per-use, and design with statelessness, observability, and cold-start mitigations in mind.
