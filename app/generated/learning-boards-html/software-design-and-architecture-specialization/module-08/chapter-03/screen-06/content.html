Architecture

Stateless functions and state placement

Stateless functions enable the provider to scale and recycle execution environments. Store durable state externally and treat local memory as ephemeral.

Where to store state
  • Object storage for files and blobs.
  • Managed NoSQL/SQL databases for structured state.
  • Managed caches for short-term performance needs.
Connection patterns
Reuse client instances across invocations if the runtime permits to reduce connection overhead, but always design for possible restarts.
Concrete example: image processor reads original from object storage, writes thumbnails back, and stores metadata in a database.
Key Takeaway

Treat functions as ephemeral workers; put persistence in external services and design for failure and retries.
