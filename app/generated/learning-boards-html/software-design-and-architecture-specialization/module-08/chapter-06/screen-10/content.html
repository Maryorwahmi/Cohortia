From SLIs to Alerts
Choose SLIs that reflect customer experience, set SLOs, and base paging alerts on SLO burn or clear user impact thresholds.
Example alert for TransactionService
SLI: transaction_success_rate. Threshold: < 99.5% over a 5-minute rolling window. Severity: Critical. Channels: PagerDuty + Slack.
Prioritization & Tuning
  • Suppress transient blips with short waiting windows
  • Use severity labels to route notifications
  • Include context links to dashboards, recent traces, and logs
Key Takeaway

Design alerts from SLOs and include context so responders can act quickly and avoid alert fatigue.
