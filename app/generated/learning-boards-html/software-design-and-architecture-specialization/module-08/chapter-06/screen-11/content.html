Module 8 › Chapter 8.6 › Instrumentation Practices
Standardization
Use a shared instrumentation library and a consistent logging schema so data joins across services are reliable.
Cardinality pattern
Keep metrics labels controlled. Put high-cardinality values into traces and logs, not into metric labels.
Pitfalls
  • Inconsistent field naming
  • Logging secrets or PII
  • Alerts on internal-only metrics
Key Takeaway

Make instrumentation a shared platform concern, not an individual project task, to ensure consistent, useful observability.
