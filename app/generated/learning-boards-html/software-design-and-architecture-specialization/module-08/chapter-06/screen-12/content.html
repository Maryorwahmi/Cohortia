2. Tracing scenario
Describe a slow transfer: a single trace_id shows long child span in AccountService indicating a database lock; follow trace to logs for transaction_id to find the root cause.
3. Logging template
Enforce JSON logs with timestamp, level, service_name, trace_id, span_id, user_id, transaction_id, message. Exclude PII.
Alert sample
SLI: transaction_success_rate. Alert: transaction_failure_rate > 0.5% over 5m. Channels: PagerDuty + Slack.
