Module 8 › Chapter 8.6 › Assessment
Sample questions
Use scenario-based items that require selecting the best observability pillar and explaining the investigative steps: detect → isolate → diagnose.
Question 1: If intermittent failures occur while CPU and memory look normal, which pillar helps you understand why? Correct: Logging. Explanation: logs contain error messages and stack traces.
Question 2: For tracing slow multi-service operations, which tool fits? Correct: Distributed tracing (e.g., Jaeger/OpenTelemetry).
Scoring tips
  • Require justification, not only selection
  • Ask for concrete steps to pivot from metric to trace to log
  • Include a short design task for an SLO and alert
Key Takeaway

Good assessments validate practical ability to detect incidents and navigate to root cause using the three pillars together.
