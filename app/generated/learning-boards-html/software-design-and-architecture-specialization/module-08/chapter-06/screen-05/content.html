Module 8 › Chapter 8.6 › Three Pillars
Metrics
Numerical time-series used for trends, thresholds and SLIs. Examples: request rate, error rate, latency.
RED / USE / Golden Signals
  • RED: Rate, Errors, Duration
  • USE: Utilization, Saturation, Errors
Tracing
Spans and traces show the end-to-end path of a request across services, revealing where time is spent and where errors occurred.
Trace context: trace_id, span_id
Ensure consistent propagation across HTTP calls and messaging systems.
Logging
Timestamped messages providing contextual clues. Structured logs (JSON) make search and correlation easier, and should include trace identifiers.
Best practice: structured logs with trace_id
Avoid logging sensitive data and include business context like userId or transactionId.
Concrete example
A payment flow: metrics indicate an increased error rate, tracing reveals the external provider span timing out, and logs with trace_id show the provider error code and transaction id for investigation.
Key Takeaway

Use all three pillars together to detect, locate, and explain incidents quickly.
