Module 08 › Chapter 8.4 › Event Types

Domain Event

Scoped

Represents a fact within a bounded context. Useful for internal business invariants and richer domain semantics.

Design tip
Include fields that support local decisions, but keep private details out of integration events.
Example
OrderCreated with domain-specific timestamps and internal approval flags used only by OrderService.

Integration Event

Cross-service

Shared across services. Keep payloads minimal and include correlation metadata for tracing and replay.

Example schema (conceptual)
{
  "eventType": "OrderPlaced",
  "data": { "orderId": "ORD-2023-001", "userId": "USER-456", "items": [{"productId":"PROD-123","quantity":1}] },
  "metadata": { "correlationId": "xyz-123" }
}
Common pitfall
Adding internal fields to integration events couples consumers to producer internals and increases schema churn.
