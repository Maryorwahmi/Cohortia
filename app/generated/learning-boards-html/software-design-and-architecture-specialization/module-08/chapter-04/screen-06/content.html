Module 08 › Chapter 8.4 › Publish-Subscribe

Pattern steps

1
Produce event
Service emits an immutable event describing what happened.
2
Publish to topic
Event is sent to a broker or streaming topic for subscribers.
3
Consume
Multiple services subscribe and process the event independently.
Ordering & delivery
Decide if message ordering is required and select infrastructure and partitioning accordingly. Plan for at-least-once and idempotency.
E-commerce example
Topic: order_events
Subscribers: InventoryService, ShippingService, NotificationService, AnalyticsService. Each reacts to OrderPlaced to perform its task without direct calls.
Common mistake
Expecting a single transactional operation across all consumers. Instead, design reconciliation and UX that handle eventual consistency.
