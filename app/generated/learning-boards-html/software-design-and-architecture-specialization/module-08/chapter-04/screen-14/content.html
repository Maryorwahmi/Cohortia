Module 08 › Chapter 8.4 › Key Concepts
Event-Driven Architecture
Components communicate by publishing and consuming events to stay loosely coupled.
Event
An immutable record of something that happened; include minimal data and metadata for tracing.
Publish-Subscribe
One producer publishes; multiple consumers subscribe and react independently.
Summary

Use events as facts, pick patterns to meet replay and query needs, and design consumers for idempotency and resilience.
