1. Core Event

Event Name: OrderPlaced
{
  "eventType": "OrderPlaced",
  "timestamp": "ISO8601",
  "data": { "orderId": "ORD-...", "userId": "USER-...", "items": [{"productId":"PROD-...","quantity":1}], "shippingAddress": "...", "totalAmount": 99.99 },
  "metadata": { "correlationId": "..." }
}
Keep the structure minimal and include correlation metadata for tracing and safe reprocessing.

2. Consumers & Flow

InventoryService: decrement stock (idempotent).
ShippingService: create shipment record and schedule pickup.
NotificationService: send confirmation email.
AnalyticsService: record sale for reporting and dashboards.
Key Tip

Make consumers idempotent and plan DLQs and monitoring before production traffic arrives.
