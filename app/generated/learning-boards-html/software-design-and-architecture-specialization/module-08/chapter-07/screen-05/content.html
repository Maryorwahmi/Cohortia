Module 8 › Chapter 8.7 › CI/CD Pipeline
Pipeline Steps
1. Code & Merge
Small PRs, fast feedback, and automated unit tests.
2. Build & Test
Create deterministic artifacts and run integration tests.
3. Package
Immutable container images or artifacts with version tags.
4. Deploy
Staged rollouts, health checks and rollback capabilities.
Architectural requirements
  • Modularity and clear module boundaries for fast unit tests and isolated changes.
  • Immutable deployment artifacts so production versions are reproducible.
  • Externalized configuration to keep builds environment-agnostic.
  • Health and readiness checks to enable safe rollout and rollback behavior.
Concrete Example
Package each microservice as a versioned container image. CI builds and pushes tagged images that CD deploys to staging for validation.
Common Mistake
Coupling CI tests to slow integration steps. Keep fast validations in CI and move heavier tests to later stages.
