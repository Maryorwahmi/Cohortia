Module 8 › Chapter 8.7 › Automate Toil
Identify toil
  1. Manual scaling and capacity changes.
  2. Ad-hoc recovery actions that are repeated on incidents.
  3. One-off scripts for configuration changes.
Design goal
Expose operational controls as APIs and make operations idempotent to enable safe automation.
Concrete example
Provide a management endpoint or platform API to change consumer group configurations and scale consumers based on queue length. Automate this through pipeline or controller logic.
Common Mistake
Automating fragile manual processes without tests. Automation must be covered by validation and rollback plans.
