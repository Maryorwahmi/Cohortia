Module 08 › Chapter 8.2 › Key Concepts
Microservice
Autonomous, single capability, owned data and lifecycle.
Polyglot Persistence
Each service chooses the datastore that fits its workload and access patterns.
API Gateway
Single client entry point for routing and cross-cutting policies.
Summary

Balance autonomy with operational discipline: own data, instrument thoroughly, and migrate incrementally when moving from a monolith to microservices.
