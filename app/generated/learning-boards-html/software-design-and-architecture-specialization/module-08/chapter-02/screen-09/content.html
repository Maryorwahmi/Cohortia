Module 08 › Chapter 8.2 › API Gateway
Gateway routing (conceptual)
routes:
  - path: /products/*
    service: product-catalog-service
    methods: [GET, POST, PUT, DELETE]
    authentication: true
    rate_limit: 100/minute
  - path: /orders/*
    service: order-management-service
    methods: [GET, POST]
    authentication: true
    rate_limit: 50/minute
  - path: /users/login
    service: user-auth-service
    methods: [POST]
    authentication: false
Responsibilities
  • Routing and path-based forwarding
  • Authentication and authorization enforcement
  • Rate limiting, caching, and TLS termination
Pitfall

Do not implement complex business logic in the gateway; it should remain a thin layer for cross-cutting concerns.

Key Takeaway

Use the gateway to protect and simplify access to services while keeping business logic inside services.
