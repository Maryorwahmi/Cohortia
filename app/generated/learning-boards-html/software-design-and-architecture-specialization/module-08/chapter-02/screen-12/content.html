Compensation example

If payment fails after reserve, a compensating action from the order service will cancel the reserve and mark the order failed, ensuring system consistency over time.

Implementation notes
  • Ensure message delivery guarantees and idempotent handlers.
  • Model compensating transactions explicitly.
  • Record saga state for visibility and retries.
Key Takeaway

Sagas and eventual consistency let you coordinate multi-service transactions without global locks, but they require explicit compensation and observability.
