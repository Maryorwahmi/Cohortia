Module 08 › Chapter 8.1 › Decision Matrix Activity
Template
Create columns for Factor, Monolith Score (1–5), Microservice Score (1–5), and Justification. Fill each row with a reasoned score tied to your project constraints.
  1. Factor: Initial development speed — Monolith 4, Microservice 2 — justification: fewer pipelines and single codebase.
  2. Factor: Scalability needs — Monolith 2, Microservice 5 — justification: targeted scaling for hotspots.
  3. Factor: Operational overhead — Monolith 4, Microservice 2 — justification: fewer services means less tracing and orchestration initially.
Reflection

Record which assumptions would change scores: rapid user growth, added DevOps headcount, or a regulatory need for isolation can shift the balance toward microservices.

Key Takeaway

Use the matrix to justify a time-boxed choice and include a clear extraction plan so architecture can evolve safely with the product.
