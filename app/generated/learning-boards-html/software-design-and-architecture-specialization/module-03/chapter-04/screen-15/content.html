Module 3 › Chapter 3.4 › Key Concepts
Target Interface
The interface the client expects to call.
Adaptee
An existing class with a different interface that needs translation.
Adapter
Implements the target and delegates to the adaptee, translating calls when necessary.
Component
The interface or abstract class that supports decorators and concrete components.
Decorator
A wrapper that conforms to the component interface and adds responsibilities dynamically.
Dynamic Responsibility Assignment
The ability to add or remove features from individual instances at runtime via decorators.
Summary
These terms let you describe architecture choices clearly and choose patterns that preserve reuse and flexibility.
