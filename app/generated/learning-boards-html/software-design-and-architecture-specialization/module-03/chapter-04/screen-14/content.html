Module 3 › Chapter 3.4 › Key Concepts
Adapter Pattern
Converts an existing class's interface into the interface clients expect.
Decorator Pattern
Wraps components to add responsibilities dynamically without changing the class.
Decision Rule
Change interface → Adapter. Change per-instance behavior → Decorator.
Quick Summary
Use adapters to bridge interfaces and decorators to compose behavior at runtime. Keep responsibilities separated for maintainable systems.
