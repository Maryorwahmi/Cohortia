# Adapter implements target and wraps adaptee
class PaymentGatewayAdapter(NewPaymentProcessor):
    def __init__(self, old_gateway):
        self._old_gateway = old_gateway

    def make_payment(self, amount, currency):
        # translate currency to legacy code and call adaptee
        currency_code_map = {"USD": "840", "EUR": "978"}
        legacy_code = currency_code_map.get(currency.upper(), "UNKNOWN")
        return self._old_gateway.process_payment_legacy(amount, legacy_code)

# Client uses adapter as if it were a NewPaymentProcessor
Concrete Example
Mapping USD to a legacy numeric code and delegating preserves the old gateway's logic while the client uses the new API.
Edge Case
Handle unknown currencies explicitly to avoid surprising the client with an adaptee failure.
Testing & Best Practices
  • Keep translation logic inside the adapter.
  • Write unit tests with mocked adaptee to verify mappings.
  • Log translation failures and return clear errors to the client.
Try this
Swap the adaptee instance at runtime to integrate a newer gateway without changing client code.
