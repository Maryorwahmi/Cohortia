Architecture
When to choose each pattern
Adapter — Typical Scenarios
  • Integrating legacy or third-party libraries with a new interface.
  • Refactoring to a new API while preserving old implementations.
  • Providing a compatibility layer during migration.
Decorator — Typical Scenarios
  • Adding features like encryption, compression, or UI modifiers per instance.
  • Composing responsibilities dynamically at runtime.
  • Avoiding explosion of subclasses for feature combinations.
Pro Tip
Keep adapters responsible for translation only and decorators for behavior only; mixing responsibilities creates maintenance overhead.
