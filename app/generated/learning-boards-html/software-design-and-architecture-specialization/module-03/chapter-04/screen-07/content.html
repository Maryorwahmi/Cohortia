Core Concept
Decorator pattern
Wrap a component to add behavior dynamically, preserving the common interface.
  • Avoids class explosion from many feature combinations.
  • Supports per-instance feature composition at runtime.
  • Each decorator delegates then augments behavior.
Key Takeaway

Decorator composes features around objects so you can combine behavior flexibly.

Coffee Example (structure)
# Component Interface
class Coffee:
    def get_cost(self): pass
    def get_description(self): pass

# Concrete Component
class SimpleCoffee(Coffee): ...

# Decorator
class CoffeeDecorator(Coffee):
    def __init__(self, decorated):
        self._decorated = decorated

# Concrete Decorator
class MilkDecorator(CoffeeDecorator):
    def get_cost(self): return self._decorated.get_cost() + 1.5
    def get_description(self): return self._decorated.get_description() + ", with Milk"
Concrete Example
Wrap a SimpleCoffee with MilkDecorator and then SugarDecorator to build a customized drink at runtime.
Contrast
Inheritance would require one subclass per combination, which scales poorly.
