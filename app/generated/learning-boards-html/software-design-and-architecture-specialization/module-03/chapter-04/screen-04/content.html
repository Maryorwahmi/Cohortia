Core Concept
Adapter pattern explained
Translate a target interface into calls the adaptee understands, without editing the adaptee.
Definition
Converts one interface into another expected by the client.
When to use
Integrating legacy or third-party code with a new system interface.
Common mistake
Modifying the adaptee instead of creating an adapter.
Key Takeaway

Adapter preserves existing implementations by translating interfaces at the boundary.

Object Adapter Example (code snippet)
# Adaptee
class OldPaymentGateway:
    def process_payment_legacy(self, amount, currency_code):
        print("Old Payment Gateway: Processing", amount, currency_code)
        return True

# Target Interface
class NewPaymentProcessor:
    def make_payment(self, amount, currency):
        raise NotImplementedError

# Adapter uses composition to wrap adaptee and translate calls to legacy format
Concrete Example
Adapter maps currency codes like USD to legacy numeric codes and delegates processing to the old gateway.
Misconception
Adapters do not add behavior; they translate interfaces. Use decorators for behavior changes.
