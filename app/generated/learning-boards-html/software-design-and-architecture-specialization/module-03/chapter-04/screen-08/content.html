Process Flow
Design and layer decorators
Step 1 — Define Component
Declare the interface clients use so decorators and components match it.
Step 2 — Implement Base
Provide a concrete component like FileDataSource that reads raw data.
Step 3 — Create Decorator
Abstract decorator holds a reference to a component and forwards calls.
Step 4 — Add Small Decorators
Implement single-purpose decorators such as encryption or compression and layer them.
Example
EncryptionDecorator reverses text returned by any DataSource to simulate encryption.
Pro Tip
Keep decorators small and composable for easier testing and reuse.
Common Mistake
Packing multiple unrelated responsibilities into one decorator makes layering fragile.
