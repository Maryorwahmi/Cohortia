Code Walkthrough
GUIFactory with multiple products
# Abstract Product A
class Button:
    def render(self):
        raise NotImplementedError

# Concrete A
class WindowsButton(Button):
    def render(self):
        return "Rendering a Windows button."

class MacButton(Button):
    def render(self):
        return "Rendering a Mac button."

# Abstract Product B
class Checkbox:
    def paint(self):
        raise NotImplementedError

# Concrete B
class WindowsCheckbox(Checkbox):
    def paint(self):
        return "Painting a Windows checkbox."

class MacCheckbox(Checkbox):
    def paint(self):
        return "Painting a Mac checkbox."

# Abstract Factory
class GUIFactory:
    def create_button(self) -> Button:
        raise NotImplementedError
    def create_checkbox(self) -> Checkbox:
        raise NotImplementedError
Concrete factories
WindowsGUIFactory returns WindowsButton and WindowsCheckbox; MacGUIFactory returns MacButton and MacCheckbox. The client uses only abstract interfaces.
Misconception
Believing Abstract Factory removes all change costs. Adding new product types requires edits to the factory interface and all concrete factories.
