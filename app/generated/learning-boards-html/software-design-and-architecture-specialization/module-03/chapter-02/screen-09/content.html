Module 3 › Chapter 3.2 › Abstract Factory
Definition
Abstract Factory: product families
An abstract factory declares creation methods for each product in a family. Concrete factories return matching product instances for that family.
Concrete example
GUIFactory with create_button and create_checkbox; WindowsGUIFactory returns WindowsButton and WindowsCheckbox ensuring compatibility.
Trade-off
Easy to add new families, harder to add new product types because the abstract factory interface must change and all concrete factories must be updated.
Check
If switching theme requires replacing multiple component types at once, Abstract Factory is a good fit. If you add product types often, reconsider.
