Module 3 › Chapter 3.2 › Factory Method
Definition
Factory Method: intent and structure
Declare a creation method and defer the instantiation to subclasses. Use when subclasses should determine the concrete product.
Pattern parts
Abstract Product, Concrete Products, Abstract Creator, Concrete Creators that override the factory method.
Misconception
Don't substitute a static helper for true Factory Method; inheritance provides extensibility the static helper cannot.
Code Walkthrough
# Abstract Product
class Button:
    def render(self):
        raise NotImplementedError

# Concrete Products
class WindowsButton(Button):
    def render(self):
        return "Rendering a Windows button."

class MacButton(Button):
    def render(self):
        return "Rendering a Mac button."

# Abstract Creator
class UIFactory:
    def create_button(self):
        raise NotImplementedError

    def display_dialog(self):
        button = self.create_button()
        return f"Dialog with: {button.render()}"
The creator exposes display_dialog which uses the factory method. Concrete creators implement create_button to return platform-specific products.
