Crafting Objects Flexibly
Factory Method and Abstract Factory patterns for decoupled creation and consistent product families.
In this lesson you will understand intent, structure, and trade-offs, and implement examples for UI and document conversion.
Why this matters
When client code directly instantiates concrete classes, every change ripples across the codebase. Encapsulating creation keeps code open for extension and closed for modification.
Factory Method
Subclasses decide which product to create; use for single product variants.
Abstract Factory
Creates families of related products so components remain compatible.
Hands-on
Implement a document converter using the Factory Method starter code.
