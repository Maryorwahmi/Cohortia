Key Concepts
Compact reminders to guide design decisions
Factory Method
Subclasses decide which concrete product to create for one product type.
Abstract Factory
Creates families of related products so components are compatible within a family.
Open/Closed
Use factories to add variants or families without modifying client code when possible.
Summary takeaway

Choose Factory Method for single-product variant extensibility and Abstract Factory for creating consistent families; always program to abstract interfaces to protect clients from change.
