Module 3 › Chapter 3.2 › Implementing Factory Method
Process Flow
Steps to implement
1. Define Product
Declare the abstract product interface used by clients.
2. Concrete Products
Implement each variant of the product interface.
3. Abstract Creator
Declare the factory method and higher-level operations that use it.
4. Concrete Creators
Override the factory method to return concrete products.
5. Client Update
Make clients depend on the creator and product abstractions only.
Concrete example
UIFactory declares create_button; WindowsUIFactory returns WindowsButton; application calls display_dialog and remains unaware of concrete button types.
Common mistake
Returning concrete product types from public APIs or leaking constructors into clients undermines the pattern.
Check
Can you add a new creator subclass for a new variant without changing any client files?
