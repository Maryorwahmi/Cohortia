Decision Guide
Which pattern fits your need?
Factory Method
Use when you need subclasses to decide which concrete product to create for a single product type.
Abstract Factory
Use when you need to create a family of related products that must be compatible with each other.
Checklist
Does the client require a full set of compatible components? Choose Abstract Factory. Do you only vary one component type and expect new variants? Choose Factory Method.
Concrete scenario
For a game that creates enemy types by level, Factory Method fits. For a UI toolkit that must provide matching controls for a theme, Abstract Factory fits.
Misconception
Both patterns are not interchangeable; they solve related but distinct problems of creation scope — single product vs family.
