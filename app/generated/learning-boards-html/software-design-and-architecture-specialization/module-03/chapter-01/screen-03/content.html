Apply theory to a multi-threaded Logger activity and evaluate design trade-offs.

Code Analysis

Read the provided Python starter, predict race conditions, and annotate where locks are required.

Concurrent Testing

Run threads that obtain the Singleton and write to a log, observe whether lines interleave or the instance is duplicated.

Design Reflection

Decide whether global access via a Singleton or explicit dependency injection best serves maintainability and testability.

Mnemonic

Remember: Single instance = central resource; locks = safe creation; consider alternatives to avoid hidden global state.
