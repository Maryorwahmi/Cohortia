Thread-Safe Code
import threading

class ThreadSafeConfigurationManager:
    _instance = None
    _lock = threading.Lock()
    _initialized = False

    def __new__(cls):
        with cls._lock:
            if cls._instance is None:
                cls._instance = super(ThreadSafeConfigurationManager, cls).__new__(cls)
        return cls._instance

    def __init__(self):
        with ThreadSafeConfigurationManager._lock:
            if not ThreadSafeConfigurationManager._initialized:
                self.settings = {}
                self.settings['log_level'] = 'INFO'
                ThreadSafeConfigurationManager._initialized = True
Explanation
What changed

A class-level lock ensures only one thread may create or initialize the instance at once.

Testing tip

Spawn multiple threads that obtain the manager and print instance ids. They should all match, and settings should reflect updates consistently.

Misconception

Do not rely on interpreter-specific locking semantics; explicit locks make your intent clear and portable.

Key Takeaway

Protect both creation and initialization with locks to avoid duplicate instances and inconsistent state under concurrency.
