class ConfigurationManager:
    _instance = None
    _initialized = False

    def __new__(cls):
        if cls._instance is None:
            # Create and store the single instance
            cls._instance = super(ConfigurationManager, cls).__new__(cls)
        return cls._instance

    def __init__(self):
        if not ConfigurationManager._initialized:
            # Heavy initialization happens once
            self.settings = {}
            self.settings['log_level'] = 'INFO'
            ConfigurationManager._initialized = True

    def get_setting(self, key):
        return self.settings.get(key)
Explanation
Definition

__new__ controls creation; __init__ performs initialization. Use a stored instance and an initialized flag to avoid repeated heavy setup.

Example

Requesting the ConfigurationManager twice returns the same object; changing a setting through one reference is visible from the other.

Pitfall

Without the initialization guard, repeated instantiation calls would re-run setup and may overwrite runtime changes.

Key Takeaway

Use creation control plus an initialization guard to ensure one-time setup and a single shared instance.
