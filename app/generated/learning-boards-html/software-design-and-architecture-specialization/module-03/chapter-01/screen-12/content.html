Module 3›Chapter 3.1›Logger Activity Guidance
Activity Steps
  1. Inspect starter code and locate TODOs for creation, initialization, and log.
  2. Add a class-level lock to guard instance creation in the creation method.
  3. Guard initialization with the same lock so the file handle opens once.
  4. Use a separate file lock inside the log method to serialize writes and flush after each write.
  5. Launch multiple threads to write lines and verify the final file contents are consistent.
Example Check

Run five threads, each writes ten lines. Confirm the log file contains fifty well-formed, timestamped entries with no partial lines.

Reflection Prompt

Would explicit dependency passing of a logger to worker functions simplify testing? If so, why did you still choose the Singleton approach here?
