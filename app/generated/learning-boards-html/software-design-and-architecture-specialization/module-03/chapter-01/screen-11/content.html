Comparison

Singleton vs Explicit Dependency

Singleton
  • Easy global access
  • Hidden coupling
  • Harder to substitute in tests
Explicit Dependency Passing
  • Dependencies are visible
  • Easy to mock or swap
  • Better modularity
When to choose explicit

Prefer explicit passing if testing, reuse, or multiple instances are likely requirements.

Quick Heuristic

Ask: could I ever reasonably need two instances or a mock during tests? If yes, avoid Singleton.

Warning

Overusing Singletons degenerates into global state, which increases coupling and reduces testability.
