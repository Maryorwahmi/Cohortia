Practice Tasks
  1. Implement DeliciousPizzaBuilder with chaining and get_pizza.
  2. Write assertions that toppings are preserved and defaults applied.
  3. Create a PdfReportBuilder that formats sections consistently.
  4. Optionally implement a Director for standard configurations.
Common Pitfalls
Forgetting to return the builder breaks fluent calls.
Exposing partially built product allows invalid usage before completion.
Using Builder for trivial objects adds unnecessary complexity.
