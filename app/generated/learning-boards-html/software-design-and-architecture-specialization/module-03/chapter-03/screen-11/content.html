Starter code excerpt
# Product: Pizza
class Pizza:
    def __init__(self, size="medium", crust="thin"):
        self.size = size
        self.crust = crust
        self.toppings = []

    def add_topping(self, topping):
        self.toppings.append(topping)

    def __str__(self):
        return f"Size: {self.size}, Crust: {self.crust}, Toppings: {', '.join(self.toppings) or 'None'}"

# Builder skeleton
class PizzaBuilder:
    def __init__(self):
        self.pizza = Pizza()
    def set_size(self, size): raise NotImplementedError
    def add_topping(self, topping): raise NotImplementedError
    def get_pizza(self): return self.pizza
Implementation checklist
  • Return self from each method.
  • Keep Pizza passive; do not add assembly logic there.
  • get_pizza returns the completed Pizza.
Key Takeaway

Follow these mapping rules and tests will confirm your builder keeps products consistent and readable.
