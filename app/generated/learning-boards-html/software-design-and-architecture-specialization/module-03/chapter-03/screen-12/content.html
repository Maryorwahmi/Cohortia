Module 3 › Chapter 3.3 › Pitfalls and safeguards
Common mistakes
  • Not returning the builder instance (breaks chaining).
  • Returning or exposing the internal product early.
  • Using Builder for trivial configuration.
  • Putting assembly logic inside Product.
Safeguards
Validate required state inside get_pizza and raise meaningful errors.
Return copies if early inspection is necessary to avoid mutation issues.
Prefer Director for repeated sequences to keep client code clean.
Test idea: assert get_pizza raises when a mandatory field is missing and assert defaults apply when omitted.
