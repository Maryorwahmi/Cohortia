Module 3 › Chapter 3.3 › Pizza Builder Design
Product shape
  • size — small, medium, large (default medium)
  • crust — thin or thick (default thin)
  • sauce — tomato or pesto (default tomato)
  • cheese — mozzarella, feta, etc. (default mozzarella)
  • toppings — ordered list of strings
Builder interface
set_size, set_crust, set_sauce, set_cheese, add_topping, get_pizza
Constraints & Tests
Verify defaults when omitted.
Ensure toppings order is preserved.
Ensure get_pizza returns a complete, consistent object.
