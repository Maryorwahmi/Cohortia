Module 3 › Chapter 3.3 › Fluent API and readability
Readable chains
Chaining turns multiple calls into a single readable expression and reduces parameter-order errors. Keep method names descriptive and singular in purpose.
Example (pseudo-call)
builder.set_size("large").set_crust("thick").add_topping("pepperoni").get_pizza()
Validation strategy
Decide whether to validate incrementally or at retrieval. For critical combinations, perform checks in get_pizza and raise errors if required parts are missing.
Tip: If client code requires many conditional steps, provide helper recipes or a Director to keep chains concise and expressive.
