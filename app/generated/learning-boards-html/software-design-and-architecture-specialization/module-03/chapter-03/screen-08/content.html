Module 3 › Chapter 3.3 › Builder vs Factory
Factory patterns
Choose when the primary decision is which concrete type to create. Factories return a ready object based on type selection or family constraints.
Example
Abstract Factory returns related UI components that belong to the same family, such as HTML widgets.
Builder pattern
Choose when constructing one product requires many optional parts or ordering rules. Builder assembles a product in steps and returns it when complete.
Example
Report or Pizza object with many configurable parts and multiple representations like PDF or HTML.
Quick Decision

Ask: Are we choosing a type or assembling a complex instance? Type -> Factory. Assembly -> Builder.
