Module 3 › Chapter 3.3 › Assessment: VM configuration
Scenario

You are configuring virtual machines that vary by CPU, RAM, disks, OS, and network interfaces. Some options are optional and ordering matters when provisioning several resources.

Why Builder fits
Step-by-step construction, validation before retrieval, and multiple configurations of the same VM type mapped cleanly to Builder.
Why not Factory
Factory chooses types. Use it when you need different VM classes, not when building different configurations of a common VM product.
Assessment Answer

Builder — it manages complex, option-rich construction and enforces correctness before the object is used.
