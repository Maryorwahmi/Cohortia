Skills & Pitfalls
Implement safely; avoid anti-patterns
Practical focus
Objective: Implement Composite
Build Component, Leaf, and Composite classes. Ensure operations like display and get_size recurse correctly without type checks.
VERIFIED COMPETENCY MILESTONE
Objective: Implement Facade
Create a Facade that sequences subsystem calls and keeps client code concise. Decide what to expose and what to keep private.
VERIFIED COMPETENCY MILESTONE
Common Pitfalls
  • Putting composite-only or leaf-only operations on the shared interface.
  • Letting a facade become a god object that duplicates subsystem responsibilities.
  • Hiding too much behind a facade so testing and customization become difficult.
