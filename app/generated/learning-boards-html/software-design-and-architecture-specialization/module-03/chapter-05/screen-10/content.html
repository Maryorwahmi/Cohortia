Module 4 › Chapter 3.5 › Facade vs Adapter vs Decorator
Facade
Provides a simple, high‑level API for a complex subsystem by orchestrating multiple classes.
Adapter
Converts one interface into another so a class can be used where a different interface is expected.
Decorator
Wraps an object to add responsibilities dynamically without changing its interface.
Intent
Simplify many classes for clients.
Intent
Make incompatible interfaces work together.
Intent
Add behavior to an individual object.
Key Takeaway

Choose the pattern that matches the problem intent. Misapplied patterns increase complexity rather than reduce it.
