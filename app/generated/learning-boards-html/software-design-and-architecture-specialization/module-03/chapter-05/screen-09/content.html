Module 4 › Chapter 3.5 › Composite Operations
Typical operation sequence
1. Create
Initialize composites with empty children lists and leaves with their data.
2. Add/Remove
Attach and detach children via composite-only methods to maintain invariants.
3. Traverse
Call operations that recurse through children and aggregate or format results.
Example run
root = Directory("root")
root.add(File("doc", 10))
sub = Directory("src")
sub.add(File("main", 50))
root.add(sub)
root.display()  # Shows nested structure
print(root.get_size())  # Sums sizes recursively
Pitfall: Circular references
Moving a subtree without removing it from its old parent can create cycles and break traversal. Ensure removal before reparenting or implement safe move operations.
Key Takeaway

Design add/remove carefully and make traversal robust. Correct ownership semantics prevent subtle bugs.
