Module 4 › Chapter 3.5 › Facade — Core
Roles
Facade: a single class exposing high‑level methods. Subsystem classes: the components the facade delegates to. Clients: call the facade for common tasks and optionally interact directly with subsystems when needed.
Design guidance: name facade methods for whole tasks, keep orchestration in the facade, and avoid re‑exposing every subsystem method unless necessary.
Why it matters
Facades reduce client complexity and help maintain a stable API when subsystems evolve.
Example: Home Theater
A watch_movie method dims lights, powers projector, configures amplifier, and starts the player. The client calls one method, the facade handles the sequence.
Facade snippet
class HomeTheaterFacade:
    def __init__(self, projector, amplifier, bluray, lights):
        self._projector = projector
        self._amplifier = amplifier
        self._bluray = bluray
        self._lights = lights

    def watch_movie(self, movie_title):
        self._lights.dim(10)
        self._projector.on()
        self._projector.wide_screen_mode()
        self._amplifier.on()
        self._amplifier.set_source("BluRay")
        self._amplifier.set_volume(5)
        self._bluray.on()
        self._bluray.play(movie_title)
