Module 4 › Chapter 3.5 › Composite — Core
Component
Abstract interface for shared operations such as display and get_size. Keep it minimal.
Leaf
Concrete objects with no children. Implement shared operations returning their own data.
Composite
Containers that manage children and delegate operations to them, aggregating results.
Misconception
Do not place add/remove on the Component unless every component must support it. Prefer putting management methods on Composite.
Concrete example: File system
Files are leaves that report their own size. Directories are composites that sum child sizes and display structure recursively.
Python: component signatures
class FileSystemComponent:
    def __init__(self, name):
        self.name = name

    def display(self, indent=""):
        raise NotImplementedError

    def get_size(self):
        raise NotImplementedError
Key Takeaway

Separate responsibilities: shared operations in Component; child management in Composite to avoid interface bloat.
