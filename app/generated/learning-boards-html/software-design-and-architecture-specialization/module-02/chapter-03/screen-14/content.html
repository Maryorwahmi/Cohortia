Question 1
Penguin inherits Bird but can't fly and throws an error when fly is called. Which principle is violated and why?
Correct: LSP. Penguin does not preserve the behavioral contract expected of Bird; refactor using IFlyable or change the abstraction.
Question 2
A DataReader must implement dummy transform and write methods because of a single IDataProcessor interface. Which principle is violated and how to fix it?
Correct: ISP. Split into IDataReader, IDataTransformer, IDataWriter so each client implements only what it needs.
Final tip

Use tests that express client expectations as your contract documents; they make LSP and ISP violations visible and safe to refactor.
