Activity: Multi-functional Printer System
You will implement printer interfaces and demonstrate both principles with short code examples and client usage scenarios.
1. LSP scenario
Ensure PhotoPrinter does not refuse generic document prints or change semantics expected by Printer clients.
2. ISP scenario
Refactor IMultiFunction into IPrinter, IScanner, IFaxMachine and wire clients to narrow interfaces.
Assessment: Two multiple-choice questions ask you to identify LSP and ISP violations and justify refactors.
Competency check
Can you: detect violations, propose an interface split, and implement a safe subclass or composite?
Hint: Always prefer keeping client expectations intact and avoid adding methods that force dummy implementations.
