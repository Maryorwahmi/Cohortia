Preconditions, postconditions, invariants
  • Precondition: what the caller must ensure before calling.
  • Postcondition: what the method guarantees after it returns.
  • Invariant: state that must always hold for the object.
Example
If a method promises non-null results, a subtype returning null weakens the postcondition and breaks substitutability.
Practice prompt
For a public method in a class you maintain, write a one-line precondition and postcondition. Use tests to assert them. When refactoring a subtype, run those tests first to detect contract changes early.
