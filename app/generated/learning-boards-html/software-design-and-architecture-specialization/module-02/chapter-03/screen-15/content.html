Module 2 › Chapter 2.3 › Key Concepts
Liskov Substitution Principle
Subtypes must honor behavioral contracts so clients remain correct when objects are substituted.
Behavioral Contract
Document preconditions, postconditions, and invariants. Use tests as executable contracts.
Interface Segregation Principle
Prefer small, cohesive interfaces so classes aren’t forced to implement irrelevant methods.
Takeaway

Design by promises and roles. Preserve behavior for substitutability and split interfaces by meaningful capabilities.
