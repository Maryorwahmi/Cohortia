Fat interface (conceptual)
IWorker with multiple unrelated methods forces irrelevant implementations.
class IWorker:
    def work(self): pass
    def eat(self): pass
    def sleep(self): pass
    def manage_team(self): pass
Role-specific interfaces
Split into cohesive capabilities so implementers take only what they need.
class IWorkable: def work(self): pass
class IEatable: def eat(self): pass
class ISleepable: def sleep(self): pass
class IManageable: def manage_team(self): pass
Clients should be updated to depend on IWorkable when they only need the work method.
