Module 3 › Chapter 2.5 › Activity: Implement a user registration module
Starter steps
  1. Write validate_username, validate_password_complexity, validate_email functions and unit tests for them.
  2. Implement register_user_defensively that uses these validators and returns clear errors on failure.
  3. Create a User class that asserts invariants in the constructor and that change_password asserts preconditions and postconditions.
  4. Write tests that deliberately violate boundary input and internal assertions to observe both failure modes.
Starter code hints
# Use regex for username and email
# Use searches for password complexity
# Hash password before creating User object
# User.__init__ uses assertions for invariants
Key Takeaway

This activity reinforces where to defend and where to assert, and how tests reveal both run-time resilience and developer bugs.
