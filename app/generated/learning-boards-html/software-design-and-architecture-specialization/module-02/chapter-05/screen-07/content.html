Code (simulated terminal view)
class BankAccount:
    def __init__(self, initial_balance: float):
        assert initial_balance >= 0, "Invariant violation: Initial balance cannot be negative."
        self._balance = initial_balance

    def deposit(self, amount: float):
        # Precondition
        assert amount > 0, "Precondition violation: Deposit amount must be positive."
        old_balance = self._balance
        self._balance += amount
        # Postcondition
        assert self._balance == old_balance + amount, "Postcondition violation: Balance not updated correctly."
        # Invariant
        assert self._balance >= 0, "Invariant violation: Balance became negative after deposit."

    def withdraw(self, amount: float):
        assert amount > 0, "Precondition violation: Withdrawal amount must be positive."
        assert self._balance >= amount, "Precondition violation: Insufficient funds."
        old_balance = self._balance
        self._balance -= amount
        assert self._balance == old_balance - amount, "Postcondition violation: Balance not updated correctly."
Developer workflow
  • Enable assertions during development and include tests that violate contracts to confirm failures.
  • Use clear assertion messages that indicate whether the caller or supplier is at fault.
  • Document contracts in method docstrings so callers understand their responsibilities.
Safety note

Because assertions may be disabled in production, do not rely on them alone to guard against malicious or untrusted input.
