Module 3 › Chapter 2.5 › Objectives — skills we'll practice
Skills to Practice
Assertions and invariants
Implement pre and post checks in methods and ensure object state invariants are maintained after operations.
Input validation and error handling
Build defensive validators for username, password, and email with clear error messages or safe defaults.
Design judgment
Decide where to apply DbC versus defensive techniques and justify your choices in code reviews.
Verification
You'll verify contracts by running tests that intentionally violate preconditions and observe assertion failures. You'll verify defenses by feeding malformed inputs and confirming the code returns safe defaults or clear errors instead of crashing.
Key Takeaway

Practice both: contracts to catch developer errors, defenses to survive external faults.
