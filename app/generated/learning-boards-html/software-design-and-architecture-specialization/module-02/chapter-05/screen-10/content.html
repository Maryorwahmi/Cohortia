Module 3 › Chapter 2.5 › Where to apply DbC vs Defensive Programming
Layered architecture pattern
Boundary layer
Validate inputs, parse JSON, check types, log and return meaningful errors to callers.
Service layer
Assume inputs are validated; use contracts to assert invariants and method postconditions during development.
Internal libraries
Apply DbC to document responsibilities between cooperating modules owned by the same team.
Avoid duplication
Do not revalidate the same property at every internal call; validate once at the boundary and assert contracts inside.
Use both
A hybrid approach gives both precise debugging and runtime resilience when applied in the proper layers.
