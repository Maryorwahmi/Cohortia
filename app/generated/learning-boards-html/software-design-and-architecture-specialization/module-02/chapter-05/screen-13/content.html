Module 3 › Chapter 2.5 › Assessment and reflection
Practice questions
1. For calculate_discount(price, percentage), list preconditions and postconditions that express correctness and prevent developer errors.
2. Given a public JSON API, explain why defensive programming at the entry point is safer than relying on contracts.
3. Identify one function in your code you would convert to a contract-checked implementation and one you would harden with defensive validation. Explain briefly.
Scoring hints
  • Good answers list clear numeric and type checks for preconditions.
  • Strong responses explain ownership: who fixes a violation and why.
  • Excellent responses propose unit tests for both assertion failures and defensive validation failures.
Key Takeaway

Use these assessment questions to check that you can both design contracts and apply defensive checks where needed.
