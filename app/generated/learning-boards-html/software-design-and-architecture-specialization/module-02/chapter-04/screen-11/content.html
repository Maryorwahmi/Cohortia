Hands-on: Refactor NotificationService
Turn a DIP violation into a flexible design using constructor injection.
Step 1 — Identify
Find the class that creates EmailSender directly. That is the DIP violation to remove.
Step 2 — Define abstraction
Create INotificationSender with a send(message) method and use it as the contract.
Step 3 — Implement
Implement EmailSender and SMSSender that conform to INotificationSender.
Step 4 — Inject
Modify NotificationService to accept INotificationSender via the constructor and use it to send messages.
Try this

For tests, inject a stub sender that records messages. Assert the NotificationService calls send with expected content rather than verifying delivery.
