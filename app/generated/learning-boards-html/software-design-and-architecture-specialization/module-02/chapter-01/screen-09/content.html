Module 2 › Chapter 2.1 › PaymentMethod architecture — base class and subclasses
Abstract base: PaymentMethod
Defines process_payment(amount) as the required operation; clients depend only on this contract.
CreditCardPayment
Encapsulates card details privately and implements process_payment to simulate gateway steps, returning success or failure.
PayPalPayment
Stores an email internally and validates it in process_payment before simulating a PayPal call.
Key Takeaway

Abstract contracts plus encapsulated implementations produce a clear, extensible payment architecture.
