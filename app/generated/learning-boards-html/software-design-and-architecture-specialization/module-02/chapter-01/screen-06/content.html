Module 2 › Chapter 2.1 › Polymorphism — Many forms, one interface
Definition and benefit

Polymorphism enables code that operates on a shared behavior rather than concrete types, increasing extensibility.

Concrete example
A function accepts a Shape and calls calculate_area; Circle and Rectangle implement their own calculation and both work.
Misconception
Polymorphism does not require inheritance in Python — method presence is what matters.
Key Takeaway

Build to expected behaviors so new types integrate with existing code without modification.

Duck typing in Python
# Conceptual sketchdef use_shape(s): area = s.calculate_area() print(f"Area: {area}")class Circle: def calculate_area(self): return 3.14 * (5 ** 2)class Rectangle: def calculate_area(self): return 4 * 5use_shape(Circle())use_shape(Rectangle())
Neither Circle nor Rectangle need a common base type here; as long as they implement calculate_area, the use_shape function works.
Check
If a new shape misses calculate_area or uses a different signature, what will you do to enforce a consistent contract?
