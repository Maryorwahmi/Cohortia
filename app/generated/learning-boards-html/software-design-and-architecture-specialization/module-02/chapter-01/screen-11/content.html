Module 2 › Chapter 2.1 › Demonstrating polymorphism in the payment demo
Client usage
payments = [CreditCardPayment('1234-...3456','12/25','123'), PayPalPayment('user@example.com')] for method in payments: success = method.process_payment(100.50) if not success: print('Payment failed, handle retry or log')
This code treats each method as implementing the same behavior. The loop is independent of concrete classes and remains unchanged when new types are added.
Example terminal output
Processing $100.50 via Credit Card 3456... Credit Card payment successful. Processing $100.50 via PayPal account user@example.com... PayPal payment successful.
