Step 1 — Define abstract base
Create PaymentMethod with abstract process_payment(amount).
Step 2 — Implement subclasses
Implement CreditCardPayment and PayPalPayment, keep sensitive attributes private, and implement process_payment.
Step 3 — Demonstrate polymorphism
Create a list of payment objects and iterate, calling process_payment on each without branching.
Key Takeaway

A small, well-structured example is the fastest way to exercise and verify OOP principles in practice.

Starter checklist
  • Create the PaymentMethod abstract class and declare process_payment.
  • Implement CreditCardPayment and PayPalPayment, ensure private attributes and simple validation.
  • Write tests that call process_payment on a list of different methods and assert expected results.
Reflection
Would adding a new provider require changing client code? If yes, revisit your abstraction and interfaces.
