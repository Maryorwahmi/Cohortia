Module 2 › Chapter 2.2 › DiscountCalculator
OCP Violation (concept)
def calculate_discount(customer, amount):
    if customer.type == 'Standard':
        return amount * 0.05
    elif customer.type == 'Premium':
        return amount * 0.10
    elif customer.type == 'VIP':
        return amount * 0.15
Each new type forces edits to this function, which is brittle and violates OCP.
Polymorphic alternative
Define a Customer interface with get_discount_rate, then implement concrete customers. The calculator simply calls customer.get_discount_rate and multiplies the amount.
Key Takeaway

Replace type-checked conditionals with a polymorphic contract to keep calculation code stable as types evolve.
