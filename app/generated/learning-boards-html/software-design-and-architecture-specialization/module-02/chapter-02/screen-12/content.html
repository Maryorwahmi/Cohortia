Module 2 › Chapter 2.2 › Customer Abstraction
Abstract base
Define Customer with a single method like get_discount_rate. Keep the contract small and focused on the varying behavior.
Concrete types
Implement StandardCustomer, PremiumCustomer, and VIPCustomer. Each returns its rate without changing the calculator.
Calculator stability
DiscountCalculator simply calls customer.get_discount_rate and multiplies the amount. It never needs modification when types change.
Key Takeaway

Use small abstractions at variation points and implement new variants as new types to preserve stability.
