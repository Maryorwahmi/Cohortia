Module 2 › Chapter 2.2 › ReportExporter
Pattern overview
The exporter interface isolates format-specific logic. The generator provides data and relies on exporter.export to produce output.
Benefits
New formats require new exporter classes; the generator code remains unchanged and safe.
Conceptual snippet
class ReportExporter:  # abstract
    def export(self, data): pass

class PdfReportExporter(ReportExporter):
    def export(self, data): ...

class ReportGenerator:
    def __init__(self, exporter):
        self.exporter = exporter
    def generate(self, data):
        return self.exporter.export(data)
This composition satisfies OCP and keeps responsibilities separated.
