Module 2 › Chapter 2.2 › ReportGenerator Violation
Example (conceptual)
class ReportGenerator:
    def generate(self):
        data = self._query_database()
        report = self._format_pdf(data)
        self._send_email(report)
This triple responsibility binds unrelated changes to a single class. Tests must mock multiple concerns and refactors are riskier.
Refactor plan
  1. Extract data access to ReportDataFetcher with a clear API.
  2. Extract formatting to ReportFormatter with export method.
  3. Extract delivery into ReportSender or EmailService.
  4. Make the orchestrator compose those collaborators and delegate.
Key Takeaway

Refactor by responsibility, not by method. Define clear contracts between components.
