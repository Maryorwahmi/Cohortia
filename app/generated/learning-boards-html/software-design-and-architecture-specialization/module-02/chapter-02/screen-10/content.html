Module 2 › Chapter 2.2 › Open/Closed Principle
Definition & Mechanism
Open for extension, closed for modification. Use abstract interfaces and polymorphism as mechanisms to extend behavior without changing existing code.
When to apply
Apply OCP where features evolve frequently or where making changes has high risk. Avoid premature abstraction for rare changes.
Concrete contrast
Contrast a DiscountCalculator with if/else logic for types versus one that delegates to polymorphic customer objects that supply a discount rate.
Key Takeaway

Design contracts at boundaries likely to change and implement new behavior by adding new types rather than modifying existing ones.
