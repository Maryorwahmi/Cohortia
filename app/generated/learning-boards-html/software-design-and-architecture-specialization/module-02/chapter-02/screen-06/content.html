Component Boxes
ReportDataFetcher
Encapsulates queries and mapping. Only changes when the schema or source changes.
ReportFormatter
Accepts data and renders PDF, CSV, or other formats. New formats are new implementations.
ReportSender
Delivers output to email, storage, or stream. Implementations vary by destination.
Orchestration & Contracts
The orchestrator composes fetcher, formatter, and sender. Define small interfaces like fetch(), format(data), send(output) so collaborators are swappable and testable.
Concrete benefit

When a new report format arrives, add a formatter class; when storage changes, update only the sender. The orchestrator stays unchanged.
