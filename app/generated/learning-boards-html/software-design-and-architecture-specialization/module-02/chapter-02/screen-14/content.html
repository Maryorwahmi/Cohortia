Module 2 › Chapter 2.2 › SRP + OCP
Staged approach
  1. Identify responsibilities and extract focused collaborators.
  2. Write tests for the extracted collaborator to validate behavior.
  3. Introduce an interface if multiple implementations are likely.
  4. Compose collaborators in a coordinator that remains stable.
Tradeoffs & checklist
  • Does the change reduce the number of files you edit for a single feature change?
  • Can collaborators be tested independently?
  • Is the abstraction minimal and intention-revealing?
Key Takeaway

Use SRP to create focused components and OCP to protect variation points — evolve your design in small, testable steps.
