Module 4 › Chapter 4.1 › Strategy Pattern
Pattern structure
  • • Strategy Interface: declares the method clients use to run an algorithm.
  • • Concrete Strategies: implement the interface with specific algorithms.
  • • Context: holds a reference to a Strategy and delegates execution.
When to use: multiple algorithms for the same task, need to swap behaviors at runtime, or to remove large conditional blocks that select behavior.
Mini example
Think of a text formatter interface with three implementations: plain, uppercase, and lowercase. The editor delegates formatting to the strategy rather than switching on a type code. Add a new formatter, like reverse text, by creating another strategy class without touching the editor.
Key Takeaway

Strategy decouples the 'what' from the 'how'—clients request work and strategies provide implementations.
