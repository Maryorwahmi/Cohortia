Strategy Interface
Declare the single method clients call. Keep it minimal to avoid overburdening implementers.
Concrete Strategies
Each class implements the interface with a specific algorithm. They should be cohesive and testable in isolation.
Context
Holds a reference to the Strategy interface and delegates execution. It should not know concrete types.
Pro Tip
Inject strategies via constructor for immutability, and provide a setter when runtime switching is required.
Common Mistake
Make sure your interface isn't a grab-bag of unrelated methods; that signals poor separation of concerns.
Check Your Understanding
If adding a new algorithm requires editing Context, Strategy is not applied correctly. Why?
