Module 4 › Chapter 4.1 › Switch vs Strategy
If-else / switch approach
Centralized branching: add another branch for each new algorithm. Problems: violates Open/Closed Principle and hurts readability.
Example smell: a long method where each branch contains distinct algorithmic logic and the method grows with new requirements.
Strategy approach
Extract an interface and move each branch into a concrete strategy class. The client delegates to the strategy instead of branching.
Key Takeaway

Strategy replaces branching with polymorphism, improving extensibility and testability.
