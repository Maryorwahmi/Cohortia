Module 4 › Chapter 4.1 › TextFormatter Example
Strategy Interface (visual)
public interface TextFormatter {
    String format(String text);
}
Concrete Strategies (visual)
public class PlainTextFormatter implements TextFormatter {
    @Override
    public String format(String text) { return text; }
}

public class UpperCaseFormatter implements TextFormatter {
    @Override
    public String format(String text) { return text.toUpperCase(); }
}

public class LowerCaseFormatter implements TextFormatter {
    @Override
    public String format(String text) { return text.toLowerCase(); }
}
Concrete example
Use PlainTextFormatter for raw output, UpperCaseFormatter for emphasis, and LowerCaseFormatter when normalizing input for comparisons. Each strategy is a single responsibility.
Key Takeaway

Small, focused strategy classes keep algorithms isolated and swapable without changing clients.
