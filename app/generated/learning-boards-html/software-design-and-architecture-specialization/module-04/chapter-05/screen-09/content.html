Producer behavior
A producer creates an item, logs it, and calls the queue insertion operation. If the queue is full, the call blocks until consumers free space. Sleep calls simulate upload or production time.
// Conceptual flow
for i in 1..N:
  produce item
  log "produced"
  queue.put(item) // blocks if full
  sleep(random)
Consumer behavior
A consumer calls the queue removal operation. If the queue is empty, the call blocks until a producer inserts an item. Sleep calls simulate processing time.
// Conceptual flow
for i in 1..N:
  item = queue.take() // blocks if empty
  log "consumed"
  sleep(random)
Queue capacity: tunes backpressure
Blocking semantics: safe implicit synchronization
Observation: logs reveal when threads block and why
