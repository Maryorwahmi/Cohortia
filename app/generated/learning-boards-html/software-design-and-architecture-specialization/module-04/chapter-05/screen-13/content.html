Module 4 › Chapter 4.5 › ProducerConsumerDemo Walkthrough
Main behavior
Shared queue capacity is small so blocking occurs. Threads start, run their loops, and the main thread joins them for demo completion.
Look for: queue.put blocks when full; queue.take blocks when empty; Thread.sleep exaggerates timing to make blocking visible.
Experiment ideas
Increase producer sleep to slow production, decrease consumer sleep to process faster, or change queue capacity to observe different regimes.
If producers block frequently, consider increasing consumers or reducing production rate.
If consumers idle often, consider lowering queue capacity or adding producers.
Key Takeaway

Reading runtime logs is the fastest way to see how queue operations coordinate producers and consumers in practice.
