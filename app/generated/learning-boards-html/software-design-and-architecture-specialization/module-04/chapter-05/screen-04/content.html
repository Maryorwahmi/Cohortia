Module 4 › Chapter 4.5 › What is Concurrency?
Definition and benefits
Concurrency allows independent tasks to execute at overlapping times, improving responsiveness and throughput when used correctly.
Responsiveness: keep UI threads free
Throughput: parallelize CPU-bound work
Utilization: overlap I/O with computation
Example
Run two threads incrementing a shared counter; if you expect N increments but see fewer, timing interleaving has caused a race.
Common misconception
More threads always improve performance. In truth, contention and coordination overhead can negate benefits.
When to prefer concurrency: long-running I/O, independent tasks, or multiple CPU cores.
When to prefer simplicity: tightly coupled state or when synchronization cost outweighs gains.
Key Takeaway

Concurrency is powerful but requires deliberate coordination for shared mutable state to remain correct.
