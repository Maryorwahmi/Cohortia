Module 4 › Chapter 4.4 › Pattern Structure
Context
MediaPlayer (example)

Holds a reference to the current state and delegates requests such as play, pause, stop to that state. It exposes setState so states can trigger transitions.

Why this helps
Context becomes simpler, with no branching on state values.
State Interface
PlayerState

Defines operations all concrete states must implement, like play(MediaPlayer), pause(MediaPlayer), stop(MediaPlayer). Keeps concrete states interchangeable.

Test tip
Mock the context when unit testing state behavior to verify transitions without full system setup.
Concrete States
PlayingState, PausedState, StoppedState

Implement concrete behavior. They may call context.setState(new OtherState()) to change behavior in response to events.

Pitfall
Avoid placing broad application logic in state classes; keep state classes focused on state-specific behavior and small transitions.
