Module 4 › Chapter 4.4 › Logger Chain
Code Snippet
abstract class Logger { protected LogLevel level; protected Logger nextLogger; public Logger(LogLevel level){ this.level = level; } public void setNextLogger(Logger next){ this.nextLogger = next; } public void logMessage(LogLevel lvl, String msg){ if(this.level.ordinal() <= lvl.ordinal()){ write(msg); } if(nextLogger != null){ nextLogger.logMessage(lvl, msg); } } protected abstract void write(String message); }
Runtime Example
Expected console output
Console Log: This is an information.
Console Log: This is a debug level information.\nFile Log: This is a debug level information.
Console Log: This is an error level information.\nFile Log: This is an error level information.\nEmail Alert: This is an error level information.
Debugging tip
If a handler never runs, verify its level ordinal and confirm it is linked into the chain with setNextLogger.
