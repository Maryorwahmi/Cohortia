Starter Template
class PurchaseRequest { private double amount; private String description; private String status = "Pending"; public PurchaseRequest(double amount, String description){ this.amount = amount; this.description = description; } public double getAmount(){ return amount; } public String getDescription(){ return description; } public String getStatus(){ return status; } public void setStatus(String s){ this.status = s; } } interface ApprovalHandler { void setNextHandler(ApprovalHandler h); void processRequest(PurchaseRequest req); }
Guidance & Tests
Edge cases to test
  • Amount exactly 1000 should be approved by Department Manager per spec.
  • Amount 5000 should be approved by Department Manager if inclusive, otherwise by CEO; clarify boundaries.
  • Requests under 1000 handled by Team Lead.
Debug tip
Log which handler received the request and its decision to approve or forward to diagnose misrouted approvals.
