Core Idea

Chain of Responsibility

Handlers are linked. Each handler either processes the request or delegates it to the next handler.

Example: Logging chain
ConsoleLogger handles INFO+, FileLogger handles DEBUG+, EmailLogger handles ERROR+. A log request flows along the chain and each capable logger writes the message.
Pitfall
Chains that do not handle a request should either reject it or provide a default handler to avoid silent failures.
Analogy

Customer support tiers

A support ticket first goes to Tier 1. If unresolved, it moves to Tier 2, then Tier 3. Each tier decides to resolve or escalate.

Design tip
Define clear responsibilities for each handler and document when handlers should pass requests onward to maintain observability.
