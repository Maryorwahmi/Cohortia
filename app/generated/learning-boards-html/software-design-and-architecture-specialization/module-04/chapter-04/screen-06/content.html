// State interface
interface PlayerState {
void play(MediaPlayer player);
void pause(MediaPlayer player);
void stop(MediaPlayer player);
}
// Example: PlayingState
class PlayingState implements PlayerState {
public void play(MediaPlayer p){ System.out.println("Already playing."); }
public void pause(MediaPlayer p){ System.out.println("Pausing media."); p.setState(new PausedState()); }
public void stop(MediaPlayer p){ System.out.println("Stopping media."); p.setState(new StoppedState()); }
}
Runtime & Testing
Console trace (example)
Starting media from beginning. Media Player state changed to: PlayingState
Pausing media. Media Player state changed to: PausedState
Testing suggestion
Write a unit test that calls play on a MediaPlayer in StoppedState and asserts that the new state is PlayingState and that the correct message is produced or side effects occur.
Common misconception
Don't conflate state classes with strategy classes; states often manage transitions between each other instead of being stateless strategies.
