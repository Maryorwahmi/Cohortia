Iterator and Template Method Patterns

Understand how to traverse collections without leaking structure, and how to fix algorithm flow while letting subclasses fill in steps.

What you'll learn
Build a custom iterator in Java and create template methods that enforce algorithm structure.
Why it matters
These patterns reduce coupling and make it easier to extend behavior safely without changing existing clients.
