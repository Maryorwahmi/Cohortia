BookShelf API
  • constructor(int maxSize): allocate backing array
  • addBook(String): append if space available
  • getBookAt(int): internal access for iterator
  • getLength(): number of stored items
  • createIterator(): returns a CustomIterator
Design note
Prefer createIterator as the only traversal entry point. Avoid exposing the backing array via public getters.
Illustrative code
class BookShelf implements CustomAggregate<String> {
  private String[] books; private int last = 0;
  public BookShelf(int maxSize){ this.books = new String[maxSize]; }
  public void addBook(String book){ if(last < books.length) books[last++] = book; else System.err.println("BookShelf is full!"); }
  public String getBookAt(int index){ return books[index]; }
  public int getLength(){ return last; }
  public CustomIterator<String> createIterator(){ return new BookShelfIterator(this.books); }
}
If thread-safety is required, consider returning an iterator that checks a modification count or use defensive copying depending on performance trade-offs.
