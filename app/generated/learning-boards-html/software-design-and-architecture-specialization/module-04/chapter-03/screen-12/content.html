Module 4 › Chapter 4.3 › Pattern Comparison
Iterator
  • Goal: uniform traversal without exposing internals
  • Key parts: Iterator + ConcreteIterator + Aggregate
  • Use when collections vary in representation
Template Method
  • Goal: fix algorithm order while varying steps
  • Key parts: Abstract class with template method and hooks
  • Use when a high-level process is constant across variants
Combined usage

When a template method needs to operate on a collection, have it obtain an iterator from the aggregate, then call abstract processing steps for each element. This keeps traversal and processing concerns separated and extensible.
