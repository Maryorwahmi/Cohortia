Module 4 › Chapter 4.3 › Template Method
Pattern idea

Algorithm skeleton with customizable steps

Define prepareBeverage as final so the order is enforced. Subclasses implement brew and addCondiments to vary results.

Hook methods
Hooks provide optional customization. They can have default implementations so subclasses may override them if needed.
Example summary
BeverageMaker.prepareBeverage calls boilWater, brew, pourInCup, addCondiments in that order. CoffeeMaker implements brew and addCondiments differently than TeaMaker, but both follow the same sequence.
Key takeaway

Use Template Method to enforce consistent algorithm order while allowing subclasses to supply the variable pieces.
