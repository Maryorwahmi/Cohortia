Module 4 › Chapter 4.3 › BookShelfIterator
Essential behavior
  • Keep a reference to the aggregate's data or a snapshot.
  • Maintain a position index that starts at zero.
  • hasNext compares position against available elements.
  • next checks hasNext, returns element, then advances position.
Error handling
Callers should use hasNext before next. If next is called without elements remaining, throw NoSuchElementException to make misuse obvious.
Iterator code
class BookShelfIterator implements CustomIterator<String> {
  private String[] books; private int position = 0;
  public BookShelfIterator(String[] books){ this.books = books; }
  public boolean hasNext(){ return position < books.length && books[position] != null; }
  public String next(){ if(!hasNext()) throw new java.util.NoSuchElementException(); return books[position++]; }
}
Tip: if the collection tracks the number of valid entries, pass that into the iterator to avoid checking for nulls at each step.
