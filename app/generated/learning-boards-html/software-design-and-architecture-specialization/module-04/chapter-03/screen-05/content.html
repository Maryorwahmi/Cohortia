Module 4 › Chapter 4.3 › Iterator Participants
Participant Summary
  • Iterator: declares hasNext and next.
  • ConcreteIterator: implements traversal and tracks position.
  • Aggregate: declares createIterator.
  • ConcreteAggregate: returns an appropriate iterator instance.
Practical notes
Design your ConcreteIterator to hold minimal state and not expose internal collection fields. If you need different traversal orders, implement different ConcreteIterator classes rather than adding traversal logic to the collection itself.
Example Assembly
BookShelf (ConcreteAggregate)
Stores titles and returns a BookShelfIterator via createIterator.
BookShelfIterator (ConcreteIterator)
Holds internal array and index; implements hasNext and next.
Pro tip

When you need fail-fast behavior, have the iterator capture a modification count and compare it during traversal to detect concurrent modifications.
