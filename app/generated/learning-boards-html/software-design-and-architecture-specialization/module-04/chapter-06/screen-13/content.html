Module 5 › Chapter 4.6 › Hands-on: WebServer Thread Pool
HttpRequestHandler (template)
class HttpRequestHandler implements Runnable{
  private int requestId; public HttpRequestHandler(int id){this.requestId=id;}
  @Override public void run(){
    System.out.println(Thread.currentThread().getName()+" handling request ID: "+requestId+" - START");
    try{ Thread.sleep(new Random().nextInt(800)+200); }
    catch(InterruptedException e){ Thread.currentThread().interrupt(); System.out.println(Thread.currentThread().getName()+" interrupted for request: "+requestId); }
    System.out.println(Thread.currentThread().getName()+" handling request ID: "+requestId+" - END");
  }
}
Main flow
ExecutorService executor = Executors.newFixedThreadPool(5);
for (int i=1;i<=20;i++){
  executor.submit(new HttpRequestHandler(i));
  Thread.sleep(50); // simulate arrival
}
executor.shutdown();
if (!executor.awaitTermination(10, TimeUnit.SECONDS)) executor.shutdownNow();
Observation
Confirm active thread count never exceeds pool size and queued tasks process as threads become available.
Key Takeaway
This lab shows practical benefits of pools and the importance of handling interrupts for graceful shutdown.
