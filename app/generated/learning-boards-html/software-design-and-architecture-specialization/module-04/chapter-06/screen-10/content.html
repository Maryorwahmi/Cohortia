Module 5 › Chapter 4.6 › Graceful shutdown
Shutdown sequence
executor.shutdown();
if (!executor.awaitTermination(5, TimeUnit.SECONDS)){
  executor.shutdownNow();
}
// handle InterruptedException by calling executor.shutdownNow() and restoring interrupt
This sequence ensures orderly completion when possible, with a forced fallback when tasks refuse to finish.
Practical tips
  • Choose awaitTermination timeout based on expected task durations and SLAs.
  • Design tasks to honor interrupts so shutdownNow can stop them quickly.
  • Log and possibly retry tasks returned by shutdownNow to avoid data loss.
Key Takeaway

Always coordinate pool shutdown with task interrupt handling and chosen timeouts to avoid hanging or data loss.
