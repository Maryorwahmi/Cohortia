01
Limitations of synchronized

Identify when synchronized causes unnecessary serialization in read-heavy access patterns and why that reduces responsiveness. You will connect the cost to concrete UI scenarios like dashboards with many display readers.

02
Reader-Writer Lock benefits

Explain how allowing multiple concurrent readers while granting exclusive access to writers increases throughput for read-heavy shared structures and still preserves data integrity.

VERIFIED COMPETENCY MILESTONE
03
Implement ReentrantReadWriteLock

Acquire readLock for reads and writeLock for updates, always releasing locks in finally blocks. You will practice safe patterns to avoid deadlocks and missed unlocks.

VERIFIED COMPETENCY MILESTONE
04
Thread Pool purpose

Describe how reusing worker threads reduces creation overhead and bounds concurrency to protect memory and CPU, improving stability for high-request workloads.
