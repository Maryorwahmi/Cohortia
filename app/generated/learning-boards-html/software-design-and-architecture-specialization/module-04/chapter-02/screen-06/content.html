Module 4 › Chapter 4.2 › Observer Pitfalls
Lifecycle • Performance • Correctness
Common mistakes
  • Not unregistering observers, causing memory leaks.
  • Allowing cascading updates that lead to unexpected state changes.
  • Synchronous heavy work on notification thread, blocking important tasks.
Best practices
Unregister observers on teardown, use weak references if appropriate, snapshot lists for safe iteration, and batch or offload heavy work.

Pro Tip

Favor clear contracts: observers should expect only well-defined event payloads so unexpected side effects are minimized.
