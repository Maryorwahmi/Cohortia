Module 4 › Chapter 4.2 › TextEditor Commands
Execute • Undo
Receiver: TextEditorReceiver
Holds content and implements open, save, copy, paste. Commands call these methods; the receiver keeps domain logic centralized.
Undo policy
Decide per-command how to undo. For Open, store previous content. For Save, you may log a warning if undo is not supported in the simple model.
// Command interface
interface EditorCommand { 
  void execute();
  void undo();
}

// OpenCommand saves state, executes open, and can undo
class OpenCommand implements EditorCommand {
  private TextEditorReceiver editor;
  private String previousContent;
  public OpenCommand(TextEditorReceiver editor) { this.editor = editor; }
  public void execute() {
    previousContent = editor.getContent();
    editor.open();
  }
  public void undo() {
    editor.setContent(previousContent);
  }
}
Try this

Execute OpenCommand, then call undo to see previous content restored. Consider what state must be saved for more complex operations.
