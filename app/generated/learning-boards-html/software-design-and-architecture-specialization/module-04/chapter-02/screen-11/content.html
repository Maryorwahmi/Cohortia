RemoteControl • Receivers • Undo
Step-by-step
  1. Define Command interface with execute()
  2. Create Light and Stereo receivers with on/off and setVolume
  3. Implement concrete commands that hold a receiver reference
  4. Configure RemoteControl slots and test pressOn/pressOff
  5. Add undo by storing last executed command and calling undo()
Example template
// RemoteControl holds command arrays
class RemoteControl { 
  private Command[] onCommands;
  private Command[] offCommands;
  private Command undoCommand;
  // setCommand, pressOnButton, pressOffButton, pressUndoButton
}
Testing checklist

Assign commands to slots, press buttons, verify device output, then press undo to confirm restored state where supported.
