Module 4 › Chapter 4.2 › Command Roles
Client • Invoker • Command • Receiver
Client

Constructs concrete commands and binds them to receivers. It configures invokers, deciding what command goes in which slot.

Invoker
Holds references to commands and triggers their execute method. Examples: a menu, a button, a scheduler.
Concrete Command & Receiver

Concrete commands store any state needed for execution and undo, then call the appropriate receiver methods to do the work. The receiver encapsulates domain behavior.

Design note

Keep commands thin: complex business rules belong in receivers. Only keep undo state that is strictly necessary.
