Key classes
  • StockObserver: update(String symbol, double price)
  • StockSubject: registerObserver, removeObserver, notifyObservers
  • StockMarket: concrete subject, keeps list and calls notify when setPrice changes
Practical tips
Only notify on actual change. Iterate over a copy of the observer list to avoid concurrent modification if observers unregister during notify.
// Observer Interface
interface StockObserver { 
  void update(String stockSymbol, double price);
}

// Subject: register/remove/notify
interface StockSubject {
  void registerObserver(StockObserver o);
  void removeObserver(StockObserver o);
  void notifyObservers();
}

// Key: notify only when price changed
class StockMarket implements StockSubject {
  private List<StockObserver> observers = new ArrayList<>();
  private double price;
  public void setPrice(double newPrice) {
    if (this.price != newPrice) {
      this.price = newPrice;
      notifyObservers();
    }
  }
  // register/remove/notify implementations omitted for brevity
}

Register two displays, setPrice twice, remove one, then setPrice again to confirm only the remaining observer reacts.
