Module 5 › Chapter 5.5 › C4 model levels
Levels
  • Context: System boundary and external actors.
  • Container: Deployable units and comms.
  • Component: Internal components of a container.
  • Code (optional): Classes and modules, often tool-generated.
Practice prompt
Draft a C4 context and container diagram in text for a photo sharing app: identify users, external services, and containers like web app, API, database, and storage. Keep it concise and link to an ADR that explains storage choices.
Key Takeaway

C4’s progressive zoom helps audiences find the right level of detail without overload.
