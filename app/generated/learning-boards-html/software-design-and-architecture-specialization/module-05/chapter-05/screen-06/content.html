Module 5 › Chapter 5.5 › Architectural Views — Overview
Views and their purpose
Logical View: Functional decomposition and component responsibilities.
Process View: Runtime behavior, concurrency and message flows.
Deployment View: Mapping of components to infrastructure, containers, and network.
Development View: Module structure, libraries, and build boundaries.
Example: latency investigation
When investigating latency, start with the Process View to see message sequencing, then inspect the Deployment View to find network hops and resource placement. Developers may then consult the Logical View for algorithmic hotspots. Linking these views with ADRs that recorded past scaling decisions helps interpret trade-offs.
Checklist
  • - Create focused diagrams per stakeholder.
  • - Keep diagrams short; use links to deeper context.
  • - Store artifacts in version control with ADRs.
