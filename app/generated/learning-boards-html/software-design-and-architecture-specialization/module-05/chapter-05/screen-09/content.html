Module 5 › Chapter 5.5 › Deployment and Physical Views
What to include
Nodes, containers, cloud instances, load balancers, storage services, and network connections. Indicate co-location and resilience measures like autoscaling and failover groups.
Operations benefit
Deployers can plan capacity and understand fault domains.
Record choices
Link ADRs for instance sizing and managed services.
Concrete scenario
When moving to a managed database, document the network rules, backup schedules, and expected throughput. An ADR should explain trade-offs, operational constraints, and rollback paths.
Misconception
Don’t mix deployment topology with logical responsibilities; keep them separate artifacts linked by references.
