Module 5 › Chapter 5.5 › UML vs C4
UML
A rich notation with many diagram types suitable for precise engineering needs, such as detailed class or sequence specifications.
When to use
When you need formal, detailed diagrams for engineering contracts or interfaces.
C4 model
A simple, layered approach (Context, Container, Component, Code) that progressively zooms and is easier for diverse audiences to understand.
When to use
For onboarding, system overviews, and when you want consistent abstraction across artifacts.
