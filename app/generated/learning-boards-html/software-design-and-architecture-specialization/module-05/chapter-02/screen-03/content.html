Practice tasks

Work through three scenarios and map them to Monolithic, Layered, or Client-Server. Provide a short justification referencing trade-offs like deployment overhead, separation of concerns, and network constraints.

Use the provided Python example to trace a request from presentation to data access and note where business rules belong.

Scenario practice
Match a small internal tool to a monolith, a banking system to layered, and a mobile app + backend to client-server.
Assessment preview
  1. Multiple choice: reason about scaling and monolith disadvantages.
  2. Short answer: where does a tax rule change live in layered architecture?
  3. Practical: trace the request flow in the Python example and annotate responsibilities.
Common pitfalls to spot
  • Layer leakage: higher layer knowing internal data structures of a lower layer.
  • Monolith scaling: scaling the whole app for a single hot feature.
  • Client-server neglect: not handling network failures or authentication properly.
