Code panels (illustrative)
Data Access
class UserRepository:\n def __init__(self, db_connection):\n self.db = db_connection\n def get_user_by_id(self, user_id):\n print("DAL: Fetching user", user_id)
Business Logic
class UserService:\n def __init__(self, user_repo):\n self.user_repo = user_repo\n def get_user_profile(self, user_id):\n user = self.user_repo.get_user_by_id(user_id)
Presentation
@app.route('/users/')\ndef get_user(user_id):\n user_profile = user_service.get_user_profile(user_id)\n return jsonify(user_profile)
Trace example

GET request arrives at the route. The route calls UserService.get_user_profile. The service calls UserRepository.get_user_by_id. The repository returns raw data. The service applies business rules and returns a decorated object to the route. The route formats JSON for the client.

Pro-tip

Write unit tests for each layer: mock the layer below to verify responsibilities in isolation.
