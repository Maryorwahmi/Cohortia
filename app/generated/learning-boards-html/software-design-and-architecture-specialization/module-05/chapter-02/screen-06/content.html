Deployment Flow
1
Build single artifact
Compile or package the entire application for deployment.
2
Deploy replicas
Add identical instances to handle load, which duplicates all components.
3
Scale cost
You pay for full-app replication even if only a subsystem needs capacity.
Concrete example

If image uploads are slow under heavy demand, spinning up more Flask app instances increases upload throughput but also duplicates unrelated traffic and memory usage for other features.

Misconception

Modular code inside a monolith equals independent deployment. It does not. Deployment boundaries determine how you scale and update components.
