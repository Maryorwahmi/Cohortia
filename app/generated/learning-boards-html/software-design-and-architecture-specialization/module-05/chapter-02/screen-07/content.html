Module 5 › Chapter 5.2 › Layered Architecture
Typical layers
Presentation
Handles user interaction, routes, input validation, and presentation format.
Business Logic
Encapsulates core rules, orchestrates operations, and enforces invariants like tax calculations or authorization rules.
Data Access
Manages persistence and database queries through repositories or DAOs.
Benefits
  • Improved maintainability through separation of concerns.
  • Easier unit testing of isolated layers.
  • Ability to swap implementations inside a layer with minimal impact.
Pitfall: Layer leakage

When the presentation layer depends on the internal schema of the data access layer, you've broken layering. Keep interfaces narrow and responsibilities clear.
