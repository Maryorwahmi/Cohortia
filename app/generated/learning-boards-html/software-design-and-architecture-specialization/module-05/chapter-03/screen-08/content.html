Simplified broker pseudocode
class MessageBroker:
    def __init__(self):
        self.subscribers = {}

    def publish(self, event_type, payload):
        print('Broker: publishing', event_type)
        for callback in self.subscribers.get(event_type, []):
            try:
                callback(payload)
            except Exception:
                print('Broker: consumer error')

    def subscribe(self, event_type, callback):
        self.subscribers.setdefault(event_type, []).append(callback)
What to notice
  • Producers publish and do not need to know who consumes.
  • Subscribers register callbacks and react asynchronously relative to the producer.
  • Broker delivery must handle exceptions and consider persistence for durability.
Example
Order Service publishes OrderCreated; Inventory decrements stock and Notification sends email, both via callbacks registered earlier.
Key takeaway
A broker decouples services but requires attention to delivery guarantees and error handling.
Common mistake
Synchronous broker callbacks that block the publisher path. Consider async queues for scale.
Pro tip
Make consumers idempotent and log event processing so you can replay or reconcile if needed.
