Module 5 › Chapter 5.1 › Architecture vs Software Design
Comparison

Scope and focus

Architecture
Decides major components, interactions, and system-wide qualities such as scalability and reliability.
Design
Defines internal structures, algorithms, and the concrete implementation within components.
Concrete scenario
If authentication is placed in its own service (architecture), the design later specifies token format, encryption method, and API contract inside that service.
Key Takeaway

Keep strategic questions and implementation questions separate: it reduces rework and improves team coordination.

Misconception check
Avoid jumping to design choices during architecture reviews. Debate interfaces and boundaries first, then defer implementation specifics to design sessions.
Practice
Take an architectural decision and list three design decisions that would follow. This helps preserve focus and shows the separation clearly.
