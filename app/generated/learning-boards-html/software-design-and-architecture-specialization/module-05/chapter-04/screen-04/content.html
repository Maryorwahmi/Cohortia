Module 5 › Chapter 5.4 › Performance
Definition

Latency, throughput, response time

Latency is delay per operation. Throughput is work per time. Response time is full duration for a request to finish.

Common levers
  • Algorithms and data structures
  • Caching and indexing
  • Network topology and connection reuse
Example

A price API uses an in-memory cache and connection pool to meet a 20 millisecond latency target. Cache invalidation and consistency must be managed.

Key Takeaway

Measure first. Optimize the actual bottleneck with focused levers like caching, not premature broad changes.

Annotated Diagram
Request path
  1. Client sends request
  2. Load balancer forwards
  3. Service checks cache
  4. Cache miss hits DB
Measurements
  • Latency p50, p95, p99
  • Throughput: requests per second
  • Tail latency matters for user experience
Common mistake

Optimizing without targets or measuring the wrong metric. Example: tuning average latency while ignoring p99 tail spikes that degrade user experience.
