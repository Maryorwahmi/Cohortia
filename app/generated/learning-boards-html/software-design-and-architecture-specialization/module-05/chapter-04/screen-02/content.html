Learning Objectives

Build definitional clarity and decision-making skills for non-functional requirements.

01
Define core NFRs

State precise definitions for performance, scalability, and security and explain why metrics like latency and throughput matter. Practice using a single example to show the difference between latency and throughput.

VERIFIED COMPETENCY MILESTONE
02
Understand maintainability and reliability

Explain modifiability, testability, availability, and fault tolerance and how architecture patterns influence them. Use a small example describing a layered application versus a microservice setup.

VERIFIED COMPETENCY MILESTONE
03
Analyze trade-offs

Identify conflicts such as performance versus security or scalability versus consistency, and describe mitigations like selective encryption or eventual consistency patterns.

VERIFIED COMPETENCY MILESTONE
04
Map choices to qualities

Given architectural options, argue which qualities are strengthened or weakened and propose practical trade-offs aligned to business priorities.
