Module 5 › Chapter 5.4 › Measuring Performance
Process

Define SLOs and test

  1. Pick SLOs: p50, p95, p99 latency and throughput targets.
  2. Gather telemetry under realistic load and production data shapes.
  3. Profile hotspots and identify network/database hops.
  4. Run targeted optimizations and re-measure impact.
Scenario

Payment gateway sets p95 under 100 ms. Testing reveals database index miss; adding the index drops p95 to 60 ms under test load.

Visual checklist
Telemetry
  • Latency percentiles
  • Request rate
  • Error rate
Testing
  • Realistic load
  • Data shape matching
  • Spike and soak tests
Common mistake

Relying on synthetic microbenchmarks that don’t model concurrency, network latency, or real data distributions. Always validate with production-like tests.
