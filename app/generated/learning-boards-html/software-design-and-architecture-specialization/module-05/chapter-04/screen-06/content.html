Comparison

Vertical vs Horizontal

Vertical (Scale Up)
  • Increase resources of one node
  • Limited by hardware
  • Simpler operations
Horizontal (Scale Out)
  • Add more instances
  • Enables elasticity
  • Requires distribution and coordination
Example

A stateless API scales horizontally behind a load balancer. A stateful database often needs sharding to scale horizontally, which adds consistency trade-offs.

Architectural patterns
Stateless services

Enable any instance to serve requests, simplifying horizontal scaling and load distribution.

Distributed datastore

Sharding and replication improve capacity but require careful consistency and recovery planning.

Message queues

Decouple producers and consumers to smooth bursts and enable independent scaling of workloads.
