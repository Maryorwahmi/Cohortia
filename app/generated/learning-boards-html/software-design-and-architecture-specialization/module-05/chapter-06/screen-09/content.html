Step-by-step analysis
  1. Name the architectural approach and assumptions.
  2. Select a prioritized scenario from the utility tree.
  3. Run a thought experiment: predict behavior and measurable effects.
  4. Document where it supports or fails the scenario.
  5. Identify sensitivity points and record trade-offs.
Example
Centralized video server under 10x growth: single I/O/database bottleneck, high network egress, increased latency. Sensitivity: central storage choice.
Documenting trade-offs
For each approach, list benefits and costs. Example: CDN improves scale and latency but increases operational complexity and cost.
Misconception
Don't assume a single metric like latency describes all risks. Analyze each scenario for its specific measures.
