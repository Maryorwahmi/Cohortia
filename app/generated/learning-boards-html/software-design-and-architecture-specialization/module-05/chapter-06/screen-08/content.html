Module 6 › Chapter 5.6 › Scenario Types
Four scenario types
  • Use Case: Normal user interaction with acceptance criteria.
  • Growth: Scale targets like 10x users or peak traffic spikes.
  • Change: Adding features or components without full redeploy.
  • Failure: How the system behaves when components fail.
Writing strong scenarios
Include actor, trigger, and measurable acceptance criteria. Avoid vague goals.
Examples
Use: "A user logs in and opens dashboard within 2 seconds."
Growth: "10x concurrent viewers during a live event within 12 months."
Change: "Add a new payment gateway without redeploying the core service."
Failure: "Database primary fails; reads continue for 5 minutes."
Check your scenarios
Are they measurable, time-bounded, and tied to a quality attribute? If not, refine them now.
