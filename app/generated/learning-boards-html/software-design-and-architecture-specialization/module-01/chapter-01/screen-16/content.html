Module 1 › Chapter 1.1 › More Key Concepts
Scalability
Capability to handle growth by design choices that isolate bottlenecks.
Extensibility
Ability to add features without modifying stable code, often via extension points.
Reusability
Designing components with small, stable interfaces so they can be reused across contexts.
Final takeaway

Use these qualities to guide practical refactors: pick one, design a small change, and measure the benefit.
