Module 1 › Chapter 1.1 › Extensibility & Reusability
Extensibility
Add features through small extension points rather than changing core logic.
Example: plugin interface for new data sources so core ingestion remains unchanged.
Reusability
Expose a focused API so components can be dropped into different projects with minimal glue.
Example: a parser that outputs a standard format usable by many pipelines.
Design trade-off
Avoid premature generalization. Start with clear uses, then add extension points where patterns emerge.
