High coupling: construction inside the class
// High Coupling Example (C#)
public class PaymentGateway
{
    public bool ProcessPayment(decimal amount)
    {
        Console.WriteLine($"Processing payment of {amount:C} via concrete PaymentGateway.");
        return true;
    }
}

public class OrderProcessor
{
    private PaymentGateway _gateway; // Direct dependency on concrete class

    public OrderProcessor()
    {
        _gateway = new PaymentGateway(); // Tightly coupled: creates its dependency
    }

    public void PlaceOrder(decimal amount)
    {
        Console.WriteLine("Order placed. Initiating payment...");
        if (_gateway.ProcessPayment(amount)) { Console.WriteLine("Payment successful."); }
    }
}
Consequence
OrderProcessor must be edited to change payment providers and is hard to unit test.
Quick fix
Extract an IPaymentGateway interface and inject it via the constructor.
Analogy
Constructing collaborators is like welding parts together — hard to separate later.
Key Takeaway
Prefer composition by injection rather than internal construction to lower coupling.
