Common mitigations

Short patterns you can apply immediately to reduce these coupling forms.

External
Adapter pattern: convert OS or vendor APIs to a small, stable internal interface.
Control
Replace flags with strategy or command objects so behavior choices are explicit and testable.
Stamp
Create minimal DTOs that expose only required fields instead of passing full domain objects.
Example
Switching a payment API behind a PaymentAdapter lets you change providers without touching business logic.
Mistake
Passing a full User object everywhere because it's easy today couples modules to evolving user fields.
