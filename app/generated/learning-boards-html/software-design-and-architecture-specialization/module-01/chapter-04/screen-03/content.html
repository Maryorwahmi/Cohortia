Practical Outcomes

Concrete tasks and signs you can act on right away.

Refactor task
Extract an IEmailSender and inject it into NotificationService so tests can provide doubles.
Smell detector
Look for global state, many cross-module edits, and flag-based control passing as coupling indicators.
Tradeoff guide
Balance the cost of extra interfaces with the value of easier testing and safer changes.
Key Takeaway

Start with the smallest dependency that blocks testing or frequent changes and decouple it first.
