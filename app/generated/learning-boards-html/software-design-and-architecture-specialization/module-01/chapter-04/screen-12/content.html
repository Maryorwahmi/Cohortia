Refactor plan

A sequence of small, test-backed steps to decouple NotificationService.

Step 1
Create IEmailSender with SendEmail(recipient, subject, body).
Step 2
Make EmailSender implement IEmailSender.
Step 3
Add SmsSender implementing IEmailSender for demonstration purposes.
Step 4
Refactor NotificationService to accept IEmailSender via constructor and remove internal creation.
Testing advice
Write a unit test that injects a mock IEmailSender and asserts the SendEmail contract is invoked with expected parameters.
Common mistake
Avoid extracting a huge interface that includes methods not needed by NotificationService.
Key Takeaway

Make the smallest abstraction that supports testing and swapping implementations without leaking details.
