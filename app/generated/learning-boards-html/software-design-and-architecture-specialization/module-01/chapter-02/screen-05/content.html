Abstraction in Code
IVehicle shows how callers use a contract without knowing implementation.
Interface and implementations
// C# style (illustrative)
public interface IVehicle { void Start(); void Stop(); void Drive(double distance); }

public class Car : IVehicle {
  public void Start() { Console.WriteLine("Car engine started."); }
  public void Stop() { Console.WriteLine("Car engine stopped."); }
  public void Drive(double distance) { Console.WriteLine($"Car drove {distance} km."); }
}

public class Bicycle : IVehicle { /* similar with bicycle messages */ }
Caller example: Driver.Operate accepts IVehicle, calls Start, Drive, Stop. No type checks required.
Misconception: Including implementation details in an interface tightens coupling.
Visual: Contract vs Implementations
Contract: Start · Drive · Stop
Car implementation: engine start, fuel check, drive logic
Bicycle implementation: balance, pedal start, drive logic
