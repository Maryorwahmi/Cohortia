Common Mistakes
Anti-Patterns and Misuses
Recognize patterns that weaken design.
Exposing mutable internal state breaks encapsulation and lets callers create invalid objects.
Fat interfaces force implementations to implement unrelated behavior and increase coupling.
Premature abstraction creates unstable contracts that change often and cost maintenance.
Mitigation strategies
  • Return immutable copies or read-only views for collections.
  • Keep interfaces focused on one cohesive responsibility.
  • Delay abstraction until behaviors are understood; prefer concrete classes during discovery.
Pro tip: Add tests that intentionally try to break invariants to verify encapsulation.
