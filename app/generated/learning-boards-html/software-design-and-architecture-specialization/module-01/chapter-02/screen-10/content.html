Architecture
Abstraction in Subsystems
Design interfaces that let subsystems evolve independently.
Example: ImageProcessor and Filters
Define an IFilter with apply(image). Implement GrayscaleFilter, SepiaFilter, BlurFilter and pass them to ImageProcessor.
Benefit: Extensibility — add new filters without changing the processor.
Misconception: Exposing algorithm parameters as part of the interface ties implementation to consumers.
Practical checklist
  • Does the interface express a single responsibility?
  • Can you add an implementation without editing callers?
  • Can you mock the implementation for tests easily?
Key Takeaway
Design interfaces around behavior, then encapsulate the state that supports that behavior inside implementations.
