Module 1 › Chapter 1.2 › Practical Steps
Abstraction checkpoint
Define an IVehicle or abstract Vehicle with start, stop, drive. Implement Car and Bicycle. Call them via the interface and add a new type to confirm callers need no change.
Mnemonic: Contract first, implementation later.
Milestone: Running example that prints behavior for two types.
Encapsulation checkpoint
Refactor a class to make sensitive fields private. Add deposit/withdraw or getters/setters with validation. Provide tests that attempt invalid operations and expect failures.
Mnemonic: Guard your invariants with methods.
Milestone: Tests confirm negative deposits are rejected and withdrawals prevent negative balance.
