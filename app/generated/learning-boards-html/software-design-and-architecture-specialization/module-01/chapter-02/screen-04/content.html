Core Concept
What is Abstraction?
Model behavior, hide implementation.
Definition
Focus on what an object does and omit internal details from the public contract.
Analogy
Driving a car: controls are the abstraction; the engine is hidden implementation.
Common misconception
Naming methods or copying code into a base class is not abstraction unless it captures shared essential behavior.
Key Takeaway

A good abstraction lets callers depend on behavior, not on a concrete implementation.

Concrete example (interface)
// C# style interface example
public interface IVehicle
{
    void Start();
    void Stop();
    void Drive(double distance);
}
The IVehicle contract names the essential behaviors. Implementations provide specific logic without changing callers that use IVehicle.
Best practice: Keep interfaces focused and meaningful.
Anti-pattern: Interface with many unrelated methods.
