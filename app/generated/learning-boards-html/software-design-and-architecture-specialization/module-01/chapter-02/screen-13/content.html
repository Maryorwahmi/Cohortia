Module 1 › Chapter 1.2 › Key Concepts
Abstraction
Define behavior contracts so callers depend on what an object does, not how it does it.
Encapsulation
Bundle data and methods, hide internals, and enforce validation through public methods.
Information Hiding
Expose only the necessary surface; keep implementation details private to reduce coupling.
Summary
Design contracts for behavior and hide the rest. Use tests that try to break invariants to confirm encapsulation works.
