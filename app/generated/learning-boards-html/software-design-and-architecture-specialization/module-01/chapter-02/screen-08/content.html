Definition
BankAccount Example
Private balance with validated deposit and withdraw preserves correctness.
Python example
class BankAccount:
    def __init__(self, initial_balance):
        if initial_balance < 0:
            raise ValueError("Initial balance cannot be negative.")
        self.__balance = initial_balance

    def deposit(self, amount):
        if amount <= 0:
            print("Deposit amount must be positive.")
            return
        self.__balance += amount

    def withdraw(self, amount):
        if amount > 0 and self.__balance >= amount:
            self.__balance -= amount
            return True
        print("Invalid withdrawal or insufficient funds.")
        return False

    def get_balance(self):
        return self.__balance
This design centralizes validation and makes the object's behavior predictable under test.
Example Scenario
An external module attempts to withdraw more than the balance. The withdraw method prevents the change and logs or returns failure, keeping state consistent.
Common mistake: Making balance public and relying on callers to behave.
Pro tip: Write tests that try invalid operations to ensure encapsulation holds.
