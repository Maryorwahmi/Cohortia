Abstraction vs Encapsulation
Understand the goal of each and how they complement.
Abstraction
Define a contract of behavior. Example: IVehicle declares Start/Drive/Stop.
Encapsulation
Hide internal state and allow access only through validated methods. Example: BankAccount with private balance.
Pitfall
Mixing them up can either leak implementation or hide needed behaviors.
Illustration: Vehicle + Account
Abstraction: Caller depends on IVehicle, not Car or Bicycle.
Encapsulation: BankAccount methods control balance mutations.
Combined: An abstract repository exposes save/load; the repository's internal cache is encapsulated.
