Filters and Accounts
When combined, abstraction and encapsulation produce modular, safe systems.
ImageProcessor depends on IFilter (abstraction). Filters encapsulate buffers and parameters so processing is safe.
Repository interface hides storage details; concrete repositories encapsulate caching and transaction semantics.
Integration tip: Use mocks for orchestration tests and real implementations for invariant tests.
Scenario
Suppose you need a new storage engine. Because callers depend on IRepository, you can add a new concrete repository that encapsulates its caching without changing callers.
Misconception: Hiding everything makes debugging impossible. Balance encapsulation with clear diagnostics and public read methods where appropriate.
