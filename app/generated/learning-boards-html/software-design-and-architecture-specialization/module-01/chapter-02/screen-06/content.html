Core Concept
What is Encapsulation?
Bundle data and behavior; hide internals to protect integrity.
Definition and purpose
Encapsulation prevents external code from putting an object into invalid states by exposing limited, validated methods.
Benefit: Protect invariants and reduce coupling.
Pitfall: Public fields and unvalidated setters lead to bugs and tight coupling.
Code example: BankAccount (Python)
class BankAccount:
    def __init__(self, initial_balance):
        if initial_balance < 0:
            raise ValueError("Initial balance cannot be negative.")
        self.__balance = initial_balance

    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount

    def withdraw(self, amount):
        if amount > 0 and self.__balance >= amount:
            self.__balance -= amount

    def get_balance(self):
        return self.__balance
Private attribute naming (double underscore in Python) hides the balance. Public methods include validation to keep the object consistent.
