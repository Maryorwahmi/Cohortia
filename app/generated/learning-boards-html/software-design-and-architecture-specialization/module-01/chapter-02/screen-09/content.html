Process Flow
Refactor to Encapsulate
A four-step approach to protect internal state.
Step 1 — Test current behavior
Write tests that set invalid ages and toggle admin directly to show existing failures.
Step 2 — Make fields private
Rename age and is_admin to private attributes and add methods set_age, promote_to_admin, demote_from_admin.
Step 3 — Validate in methods
Ensure set_age checks positive integer and methods enforce business rules.
Step 4 — Run tests and update callers
Confirm tests pass and minimally change code that used the public fields.
Starter code hint
The starter UserProfile sets username, email, age, is_admin publicly. Convert age and is_admin to private fields and add safe methods. Test invalid ages and direct modifications to confirm encapsulation.
Pro tip: Prefer expressive methods over generic setters to document intent.
Watch out: Returning mutable objects directly can leak internal state.
