Module 1 › Chapter 1.3 › Refactor UserManager
Identify responsibilities
Read the method and list each distinct concern.
  1. Authenticate user credentials.
  2. Authorize access to a resource.
  3. Log success or failure.
  4. Update the user's last login timestamp.
Goal
Move each responsibility into a focused module and keep the coordinator simple.
Suggested components
Examples of focused modules to introduce.
Authenticator
Authorizer
UserActivityLogger
UserRepository (last-login update)
Orchestrate these from a coordinator that calls each module in sequence and handles error responses without implementing authentication or authorization logic itself.
