Module 1 › Chapter 1.3 › Learning Objectives
Practice & Assessment
Refactor, test, and justify your choices.
Exercise
Refactor UserManager
Split authentication, authorization, and logging into focused components and orchestrate them from a coordinator.
Assessment
Explain cohesion level
Describe why the original class shows low cohesion and how the refactor improves maintainability.
Success criteria
Focused tests
Tests target one responsibility per component, limiting external dependencies for each test.
Tip
When in doubt, ask: how many reasons are there to change this module? If more than one, consider splitting.
