Module 1 › Chapter 1.3 › What to Remember
Toolbox
If you cannot state a single purpose for a module, it feels like a junk drawer and should be reorganized.
Single Responsibility
Limit reasons for change. One module, one reason.
Focused Tests
Write unit tests that exercise one responsibility with minimal external setup.
Final prompt

Pick one class in your codebase and try to state its single responsibility in one sentence. If you cannot, plan a focused refactor.
