Module 1 › Chapter 1.3 › Key Concepts
Modularity
Decompose systems into independent modules with clear interfaces.
Cohesion
Keep internal elements focused on a single purpose for easier maintenance.
SRP
Each module should have one and only one reason to change.
Summary takeaway

Aim for a system of many cohesive modules connected by small, stable interfaces to make software easier to test, reuse, and evolve.
