Overview
Common Quality Attributes
Performance
Response time, throughput, latency percentiles.
Scalability
Horizontal and vertical strategies to handle growth.
Security
Encryption, authentication, vulnerability management.
Maintainability
Modularity, testability, code clarity and change speed.
Reliability & Availability
Correct operation over time and percent uptime targets.
Usability, Portability, Testability, Recoverability
Other important attributes that map to user satisfaction and operational practices.
Quick reference
Metric examples
  • Response time percentiles (p95, p99)
  • Throughput (transactions/sec)
  • Availability (%) and MTBF
  • Test coverage, mean time to recover
Prioritization tip
Rank QAs by business impact, then convert the top ones into SMART targets before design work begins.
Key Takeaway

Create a shortlist of critical QAs early; they will guide architecture and testing.
