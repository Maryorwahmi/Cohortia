Security Focus
Specifying Security QAs
Make security measurable by naming controls and audits. Encryption standards, access models, and required testing all belong in a SMART statement.
Example SMART statement
"All sensitive documents shall be encrypted at rest using AES-256, in transit using TLS 1.2+, and the system shall pass an annual penetration test with zero critical vulnerabilities."
Design elements
  • Authentication and authorization model (least privilege)
  • Key and secrets management
  • Vulnerability scanning and incident response
  • Logging and monitoring for suspicious activity
Common misconception
Assuming encryption alone is sufficient. Security requires layered controls and validation processes.
Key Takeaway

Spell out controls and audits so security can be validated, not assumed.
