Definition
Reliability
Ability to perform required functions under stated conditions for a specified period. Measured by MTBF and error rates.
Design practices
Automated testing, defensive coding, graceful error handling, and monitoring for early detection.
Definition
Availability
Percentage of time the system is operational and accessible. Achieved with redundancy, replication, and automated failover.
Example target
"Maintain 99.99% availability for core API endpoints, excluding scheduled maintenance."
Key Takeaway

Plan for both reliability and availability: automated recovery reduces downtime and improves both measures when designed together.
