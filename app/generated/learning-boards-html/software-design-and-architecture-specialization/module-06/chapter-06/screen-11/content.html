Hierarchy
Maintainability
Modular code, clear interfaces, and coding standards lower the cost of change and improve comprehension by new developers.
Measure
Cyclomatic complexity, code churn, and onboarding time for new developers.
Testability & Portability
Design for automated tests, mocks, and isolated components. Use containers and clear dependency management to support portability.
Example QA
"Core modules shall maintain at least 80% unit test coverage and be packaged as container images with documented build steps."
Pitfall
Focusing only on shipping features can create brittle code that slows future delivery.
Key Takeaway

Build for change: testability and portability are practical investments that keep architecture adaptable and cost-effective.
