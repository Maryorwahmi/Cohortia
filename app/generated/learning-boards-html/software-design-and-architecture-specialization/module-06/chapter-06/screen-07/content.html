Process Flow
Specifying Performance
1. Choose operation and load
Pick a user-visible operation and a realistic concurrent user profile.
2. Select percentiles and thresholds
Use p95, p99 rather than averages and specify thresholds under the chosen load.
3. Design and run tests
Create load tests that mirror production behavior and measure the selected percentiles.
4. Act on results
If tests fail, consider caching, batching, horizontal scaling, or asynchronous processing.
Concrete example
SMART performance statement
"Login requests shall complete within 500 milliseconds for 95% of requests under a sustained load of 1,000 concurrent users."
Common mistakes
  • Relying on average latency instead of percentiles.
  • Testing without realistic user behavior or data sizes.
Key Takeaway

Measure percentiles under realistic load, then use results to guide caching and scaling choices.
