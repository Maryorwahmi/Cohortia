Module 6 › Chapter 6.5 › Space-Based Architecture
SBA concept
SBA distributes processing and stores data in-memory across processing units so requests are handled locally, avoiding a central database bottleneck.
When to use SBA
High throughput, predictable low latency, continuous availability despite node failures.
Analogy
Local library branches each keep copies of popular books instead of everyone requesting a single central copy.
Trade-offs
SBA requires complex replication logic and more memory resources. It is not a general-purpose default but excels for demanding transactional workloads.
Misconception
SBA does not eliminate consistency concerns; it shifts them into replication and conflict resolution strategies.
Example
Online betting platforms distribute bets across PUs so state is local and processing is near-instant.
