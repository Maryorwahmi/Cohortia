Module 6 › Chapter 6.5 › Practice & Assessment
Lab Walkthrough
Design a serverless image resizer using a cloud object store trigger, a function for resizing, and persistent storage for results. Include validation and error routing for invalid images.
Step 1 — Event Source
An object-created event triggers the function when a new image is uploaded.
Step 2 — FaaS
Function downloads, resizes, and stores resized images.
Follow the starter template to document the architecture and error handling choices.
Assessment
Two scenario questions test selection and justification skills: one for spiky, unpredictable traffic; one for high-throughput, low-latency transactions.
Scoring Rubric
Choices are evaluated by matching non-functional needs and operational complexity to the pattern's strengths and weaknesses.
Deliverable
A short architecture diagram and a one-paragraph justification for the selected pattern.
