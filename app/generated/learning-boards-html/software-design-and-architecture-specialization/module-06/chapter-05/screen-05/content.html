FaaS Execution Steps
1. Event
Trigger: HTTP request, object upload, or queue message starts the flow.
2. Initialize & Execute
Provider starts runtime if needed, loads function code, and runs handler logic.
3. Scale & Bill
Platform auto-scales concurrent invocations; billing is per-invocation and compute time.
Remember limits: execution timeouts, memory caps, and cold-start latency.
Example & Guidance
Image resize on upload: upload triggers the function which creates thumbnails and stores them. For user-facing endpoints, watch cold starts; for batch processing, serverless is ideal.
Common misconception
Auto-scaling always solves latency. Cold starts and initialization can add unpredictable delay to the first request.
