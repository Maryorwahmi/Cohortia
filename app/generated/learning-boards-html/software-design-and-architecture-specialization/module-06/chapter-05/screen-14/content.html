Module 6 › Chapter 6.5 › Operational Guidance
Serverless ops
Instrument tracing, centralized logs, and metrics for cold starts, errors, and durations. Configure DLQs and function retries. Test event-driven flows regularly.
Monitoring targets
Invocation rate, error rate, duration, and cold-start frequency.
SBA ops
Monitor memory usage, replication lag, messaging latency, and PU health. Plan runbooks for adding PUs and handling replica failover.
Chaos tests
Simulate PU failures and verify replica takeover and data integrity under load.
