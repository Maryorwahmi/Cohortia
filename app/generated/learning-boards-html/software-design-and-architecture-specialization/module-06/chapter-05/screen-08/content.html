Module 6 › Chapter 6.5 › Challenges of Serverless
Key challenges
  • Cold starts — initialization latency for rarely used functions.
  • Vendor lock-in — proprietary services make migration costly.
  • Execution limits — time, memory, and disk constraints restrict workloads.
  • Observability — distributed functions need centralized tracing and logging.
Example & Mitigation
If a function faces cold starts on a user-critical path, either move that path to a low-latency service or implement a strategy to keep the runtime warm. For vendor lock-in, prefer standard APIs or plan for adapter layers.
Pitfall
Ignoring limits when designing for heavy data processing can lead to failed invocations.
Check
List functions that require long execution or large memory. Those likely do not belong in FaaS.
