Module 6 › Chapter 6.5 › Lab: Image Resizer
Architecture Template
Use an object-created event as the trigger, a function to process images, and separate storage for originals and resized outputs. Include monitoring and error routing.
Event Source
Object-created events on a raw-images bucket trigger processing.
FaaS Component
ImageResizerFunction downloads, resizes using a library, and uploads results to separate buckets.
Storage
raw-images-bucket for originals; thumbnails, medium, and large buckets or folders for outputs.
Error Handling
Validate format, use a dead-letter queue for invalid events, and enable retries and alerts for processing failures.
Practical checks
Confirm function memory and timeout settings match expected image sizes. Add logging to capture object keys and processing durations. Configure alarms on function errors and DLQ rates.
