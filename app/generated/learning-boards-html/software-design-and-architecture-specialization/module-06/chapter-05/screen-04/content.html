Module 6 › Chapter 6.5 › What is Serverless?
Definition & Models
Serverless removes server provisioning concerns from developers. FaaS runs short functions on demand. BaaS provides managed services like authentication or storage.
FaaS — Triggers & Functions
Write a function that executes on events such as HTTP requests or storage uploads. Pay only while code runs.
BaaS — Managed Backends
Use third-party services for auth, databases, or storage without managing servers yourself.
Key Takeaway

Serverless shifts operational burden to the provider but requires external state management and attention to execution limits.

Concrete example: Image Resizer
An object-created event triggers a function which downloads the image, creates thumbnails, and stores results. Billing is per invocation and per compute time used.
Common misconception
Serverless means no servers. Reality: servers exist but are managed by the cloud provider.
Pro tip
Estimate invocation patterns: serverless is cost-effective for variable or intermittent loads but may be costly for sustained high-volume workloads.
