Processing Units (PUs)
PUs are self-contained nodes that run business logic and host an in-memory data grid. They are the basic unit of scaling and fault isolation in SBA.
In-Memory Data Grid
Stores data in RAM and replicates it to other PUs for availability and speed.
Messaging Grid
Enables communication and coordination between PUs and external systems.
Design decisions
Choose partitioning keys to shard data evenly, decide replica count for fault tolerance, and plan routing so requests hit the PU with local data when possible.
Example
A leaderboard shards players by region; each PU keeps regional standings in memory and accepts updates with minimal cross-node communication.
Checklist
Partition strategy, replica levels, failover behavior, memory sizing, and monitoring setup.
