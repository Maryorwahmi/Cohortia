Module 6 › Chapter 6.2 › Layer Skipping Fix
Anti-Pattern
// Controller directly calls repository
public class AccountController {
  private final AccountRepository repo; // direct dependency
  // uses repo.query(...) to build view
}
This introduces tight coupling and test difficulty.
Corrected Design
// Controller calls service only
public class AccountController {
  private final AccountService service; // depends on service interface
}

// Service composes repository calls
public class AccountService {
  private final AccountRepository repo;
  // service returns AccountSummary DTOs
}
Service returns domain DTOs so controllers remain storage-agnostic.
