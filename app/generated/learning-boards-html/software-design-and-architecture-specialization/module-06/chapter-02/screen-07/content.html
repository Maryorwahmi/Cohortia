Module 6 › Chapter 6.2 › Anti-Patterns
Layer Skipping
Higher layers directly access much lower layers, bypassing intended interfaces. This couples unrelated concerns.
Example
A UI controller calling repository queries directly instead of using a service.
Leaky Abstraction
Layer interfaces revealing storage-specific details force higher layers to know about lower-layer internals.
Fix
Return domain objects and hide database constructs behind repository interfaces or DTO mappers.
Practical Controls
Add static analysis rules to detect imports from presentation packages into data packages. Include contract tests that validate the behavior exposed at each layer boundary.
