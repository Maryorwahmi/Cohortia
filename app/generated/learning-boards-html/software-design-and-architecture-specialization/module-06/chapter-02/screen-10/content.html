Layer Roles with Annotations
@Controller
Maps to Presentation Layer: handles requests and responses.
@Service
Maps to Business Layer: orchestrates use cases and enforces rules.
@Repository
Maps to Data Access Layer: hides persistence details behind an interface.
Code Example (illustrative)
// Controller handles request
@Controller
public class TransferController {
  private final TransferService service;
  // constructor omitted
}

// Service orchestrates business rules
@Service
public class TransferService {
  private final AccountRepository repo;
  // business methods validate and call repo
}

// Repository hides persistence details
@Repository
public interface AccountRepository {
  // repository methods for debit and credit
}
Note: interfaces and directional calls keep layers decoupled and replaceable.
