Module 6 › Chapter 6.2 › Fund Transfer Flow
Sequence Steps
  1. 1. User initiates transfer on mobile app with amount, source, and destination.
  2. 2. Mobile app validates input locally and checks cached balance.
  3. 3. Mobile app sends POST /transfer to Backend API with request payload.
  4. 4. Backend authenticates request and authorizes the operation.
  5. 5. Backend executes business logic: check balance, debit source, credit destination.
  6. 6. Backend updates the database and ensures atomic success or rollback.
  7. 7. Backend responds with confirmation; mobile app displays success and updates cache.
Design Notes
Always re-validate on the server. Use transactions to keep accounts consistent and return clear error codes for authorization or insufficient funds.
