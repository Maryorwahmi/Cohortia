Use the objectives as checkpoints
  • • Map components to Presentation, Business, and Data Access layers and note dependencies.
  • • Run quick code reviews to find direct references from UI to persistence code.
  • • Draft a client-server sequence for a feature to place authentication and validation responsibilities.
  • • Prototype a thin and a thick client variant and compare deployment effort and responsiveness.
Mnemonic
Think: Separate, Verify, Place, Compare — separate layers, verify boundaries, place logic intentionally, compare client choices.
