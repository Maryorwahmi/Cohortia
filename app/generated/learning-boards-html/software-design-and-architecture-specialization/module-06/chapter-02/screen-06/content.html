Module 6 › Chapter 6.2 › Performance Costs
Measure Hops
Instrument requests at layer boundaries to observe how many round trips a user action triggers.
Batching
Combine multiple data requests into a single operation where it makes sense.
Caching
Cache results at the layer appropriate for freshness and consistency needs.
Move Logic
Move assembly work into the business layer to reduce cross-layer chattiness.
Example Scenario
A view requires data from three different queries. Instead of the controller calling repositories sequentially, introduce a service method that fetches and composes the data in a single call, reducing round trips and latency.
