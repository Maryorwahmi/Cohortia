Performance: goals and common tactics
Responsiveness, throughput, and resource efficiency.
Definition and tactics
  • Caching: keep hot data in memory or CDN to reduce repeated work and I/O.
  • Load balancing: distribute requests to avoid bottlenecks and improve throughput.
  • Asynchronous processing: use queues for long tasks so APIs remain responsive.
  • Database optimization: index and tune queries to lower data access latency.
Concrete example
A report request enqueues a job and returns immediately. A worker generates the report and signals completion, improving perceived response time.
Common mistake

Applying caching without invalidation or profiling first can hide real problems and introduce stale data issues.
