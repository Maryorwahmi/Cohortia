Module 6›Chapter 6.4›Example Service Endpoints
Catalog (Product) Service
GET /books            // list books
GET /books/{bookId}    // retrieve book details
POST /books            // add book (admin)
PUT /books/{bookId}/stock // update stock level
Design these APIs to be stable and versioned when changing request/response shapes.
Inventory Service
POST /inventory/reserve    // reserve items for an order
POST /inventory/release    // release reserved items
GET /inventory/{sku}       // get current stock
Use event-driven patterns to decouple reservation from ordering when latency allows. Ensure idempotency for retry safety.
