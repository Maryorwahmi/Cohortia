Flow: User action → API call → orchestration → domain validation → persistence. Each step delegates to the next and avoids direct cross-layer calls.
Anti-pattern: Layer skipping
When the UI accesses storage directly, you create dependencies that make future changes, testing, and reasoning harder.
Concrete example
Presentation validates input, application checks session, business decides eligibility, data access persists the cart entry. The sequence keeps responsibilities isolated.
Key Takeaway

Keep the layer sequence intact to protect domain logic from storage and UI concerns and to make testing straightforward.
