Module 6 › Chapter 6.1 › Presentation Layer — Responsibilities
Primary duties
  • Render UI and present data to users.
  • Capture user input and perform UI-level validation.
  • Call application-layer APIs to perform operations.
Example: A React component validates a form and calls an API; domain rules run elsewhere.
What to avoid
Embedding business validations or direct database calls in the UI creates duplication and tight coupling, and makes testing and replacement harder.
Key Takeaway

Keep UI concerns localized and delegate domain decisions to the application or business layer to preserve modularity.
