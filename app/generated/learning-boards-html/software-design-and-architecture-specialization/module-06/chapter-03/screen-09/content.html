Core API elements
  • Registration API: how plugins declare identity and capabilities.
  • Lifecycle hooks: init, start, stop, dispose.
  • Capability discovery: how core finds and routes requests to plugins.
Versioning and compatibility

Use semantic versioning and document breaking changes. Provide a compatibility matrix and migration guidance for plugin authors to avoid frequent core changes.

Example: plugin manifest
A plugin manifest declares id, version, requiredCoreVersion, capabilities, and entry points. The core validates manifest before loading and can refuse or sandbox plugins that violate policies.
Pitfall
Making the core too feature-rich to accommodate plugins creates coupling. Keep the core minimal and stable.
