Event schema (visual)
{
  "eventId": "UUID",
  "eventType": "OrderCreated",
  "timestamp": "2023-08-01T12:34:56Z",
  "payload": {
    "orderId": "ORD-123",
    "customerId": "C-456",
    "items": [{"productId":"P-1","quantity":2,"pricePerUnit":10.00}],
    "totalAmount": 20.00,
    "shippingAddress": {"street":"...","city":"...","zip":"..."}
  },
  "source": "OrderService"
}
Use a concise payload with only the fields consumers need. Avoid embedding large unrelated objects that increase message size unnecessarily.
Subscriber pseudocode (concept)
function handleOrderCreated(event):
  if eventIdExists(event.eventId):
    return
  begin transaction:
    for item in event.payload.items:
      if not reserveInventory(item.productId, item.quantity):
        publishEvent("InventoryReservationFailed", ...)
        rollback
        return
    markEventProcessed(event.eventId)
  commit
  publishEvent("InventoryReserved", ...)
Ensure marking the event processed and inventory reservation are atomic, or use a single upsert so retries do not duplicate work.
