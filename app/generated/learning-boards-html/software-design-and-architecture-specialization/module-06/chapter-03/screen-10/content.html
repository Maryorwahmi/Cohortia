Decision factors
Event-Driven Architecture
  • Strengths: loose coupling, scalability, resilience.
  • Constraints: eventual consistency, complex tracing.
  • Use cases: streaming, IoT, large distributed systems.
Microkernel Architecture
  • Strengths: extensibility, plugin ecosystems, customization.
  • Constraints: careful API design and compatibility management.
  • Use cases: IDEs, extensible servers, platforms with third-party plugins.
Hybrid: combine EDA for cross-service messaging and microkernel internals where plugin extensibility is needed.
Question: Are you optimizing for distribution or for feature growth?
Warning: mixing patterns without clear boundaries increases complexity.
