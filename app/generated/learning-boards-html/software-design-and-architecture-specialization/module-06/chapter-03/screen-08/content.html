Core responsibilities
  • Provide minimal runtime and lifecycle management for plugins.
  • Offer communication primitives and shared services like logging and configuration.
  • Enforce plugin contracts and version compatibility rules.
Plugin characteristics

Plugins are independent components that implement specific features and register with the core via the extension API. They should declare capabilities and lifecycle hooks such as init, start, stop, and dispose.

Concrete example: IDE plugins

A core editor provides text rendering and project management while language support, debuggers, and formatters are plugins. Users choose which plugins to install. Plugins follow a documented API so the core can load them safely and observe resource limits.

Misconception
Plugins are not toys. They must adhere to security, performance, and compatibility constraints. The core must validate and sandbox plugins where appropriate.
