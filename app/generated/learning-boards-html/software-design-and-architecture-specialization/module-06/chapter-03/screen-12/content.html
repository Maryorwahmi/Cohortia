Module 6 › Chapter 6.3 › Plugin Safety
Security practices
  • Validate and sign plugin packages before loading.
  • Use capability-based access instead of broad privileges.
  • Run plugins with least privilege in separate processes if possible.
Resource management

Monitor memory and CPU per-plugin, enforce quotas, and provide graceful degradation or restarts for problematic plugins.

Developer contract

Require plugins to declare capabilities, required core version, and resource needs in a manifest. The core uses this to validate and sandbox plugins safely.

Pitfall
Allowing plugins to access broad internals without validation risks security and reliability. Design clear boundaries instead.
