Module 6 › Chapter 6.3 › Contrast
EDA (How components talk)
Producers and consumers communicate via events across services. Scale is a primary goal; eventual consistency is accepted.
Microkernel (How system grows)
A stable core exposes extension points so plugins add features inside a product. Extensibility and maintainability are primary goals.
Add analytics consumer by subscribing to events (EDA)
Add new language support as a plugin (Microkernel)
Combine: core provides plugin API and plugins communicate via internal events
