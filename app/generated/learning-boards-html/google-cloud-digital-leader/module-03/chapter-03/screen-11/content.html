Analyzing Public Data: Top Names in California

A guided walkthrough of querying a public dataset.

BigQuery Console QueryPublic Dataset: USA Names
SELECT
    name,
    SUM(number) AS total_births
FROM
    `bigquery-public-data.usa_names.usa_names`
WHERE
    state = 'CA'
    AND gender = 'F'
    AND year = 2000
GROUP BY
    name
ORDER BY
    total_births DESC
LIMIT 5;
Key Takeaway

BigQuery enables rapid analysis of large public datasets using standard SQL, allowing you to quickly extract specific insights and trends with efficient filtering and aggregation.

Steps to Query Public Data

  • Open Google Cloud Console and navigate to BigQuery.
  • Click 'ADD DATA' -> 'Explore public datasets'.
  • Search for 'USA Names' and view the dataset.
  • Open a new query tab and construct your SQL query.
  • Run the query and observe the results.
