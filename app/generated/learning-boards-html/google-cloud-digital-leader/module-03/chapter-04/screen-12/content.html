Key Concepts

Essential ideas to remember from this chapter.

Batch & Streaming Processing

Differentiate between processing data in large groups (batch) versus continuously as it arrives (streaming).

Cloud Pub/Sub

Google Cloud's fully managed, asynchronous messaging service for real-time data ingestion and event delivery.

Dataflow

Google Cloud's fully managed service for executing Apache Beam pipelines, enabling unified batch and stream data processing.

Summary Takeaway

Mastering the distinction between batch and streaming, along with the capabilities of Pub/Sub and Dataflow, is crucial for building modern, responsive data architectures on Google Cloud.
