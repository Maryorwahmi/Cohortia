Module 5›Chapter 5.2›Service Accounts

Identity for Automated Workloads

A special type of Google account used by applications, VMs, or automated processes to make authorized API calls to GCP services.

  • Not tied to a human user
  • Acts as an identity for code or infrastructure

Assigned IAM Roles

Service accounts can be assigned IAM roles just like human users, inheriting permissions to access specific GCP resources.

  • Each has a unique email address
  • Permissions are inherited by the application/VM

Secure Programmatic Access

Provides a secure and auditable way for automated systems to access necessary resources without managing user credentials.

  • Essential for automation and CI/CD pipelines
  • Reduces human error in access management
Key Takeaway

Service accounts are crucial for enabling secure, automated interactions between your applications and Google Cloud services.

Example

A Compute Engine VM needs to write logs to Cloud Logging. Assign a service account to the VM and grant it the Logging Writer role.
