Policy in Practice

Common Organization Policy Constraints

Guardrails for security, compliance, and operational consistency.

Restrict Resource Locations

Enforce that resources are deployed only in specific geographical regions (e.g., us-east1) for data residency.

Constraint: gcp.resourceLocations

Disable External IPs for VMs

Enhance network security by preventing Compute Engine VMs from having public IP addresses.

Constraint: compute.vmExternalIpAccess

Prevent Public Storage Access

Enforce uniform bucket-level access to prevent accidental public exposure of Cloud Storage buckets.

Constraint: storage.uniformBucketLevelAccess

Restrict Allowed API Services

Control which Google Cloud API services can be enabled within specific projects or folders.

Constraint: serviceusage.apiServices
Key Takeaway

Organization Policies provide granular control over resource configurations, acting as critical guardrails for security, compliance, and operational consistency.
