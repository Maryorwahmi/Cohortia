Audit Log Details

Understanding Admin Activity and Data Access Logs

Differentiating between configuration changes and data interactions.

Admin Activity Logs

Record operations that modify the configuration or metadata of resources (e.g., creating a VM, changing IAM policy). These are always enabled and retained.

  • •Crucial for tracking administrative changes.
  • •Provides accountability for resource management.
Key Takeaway

Admin Activity Logs are always on for configuration changes, while Data Access Logs require explicit enablement for user data interactions due to volume and cost.

Data Access Logs

Records User Data Access

Operations that access user-provided data (e.g., reading from Cloud Storage, querying BigQuery).

  • •Disabled by default due to volume and potential cost.
  • •Must be explicitly enabled for compliance/security needs.
Important Note

Enabling Data Access Logs can generate significant volume and incur costs, so activate them judiciously based on your specific requirements.
