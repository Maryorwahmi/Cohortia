Securing Data in Motion and at Rest

Encryption At Rest

Protects data when it is stored in persistent storage, such as databases, object storage buckets, or disk volumes. This prevents unauthorized access even if the underlying storage media is compromised.

Example: Data in Cloud Storage buckets or Compute Engine persistent disks is encrypted.

Encryption In Transit

Protects data as it moves between different locations, such as between your on-premises network and GCP, or between different GCP services. This prevents eavesdropping and man-in-the-middle attacks.

Example: Data moving via TLS/SSL between your browser and a GCP web application.

Key Takeaway

Both encryption at rest and in transit are critical layers of defense, protecting data in its stationary and mobile states.
