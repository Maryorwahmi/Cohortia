Migration Strategies

The "6 Rs" of Cloud Migration

A Framework for Strategic Application Movement

01

Rehost

Move applications as-is to the cloud. Fastest initial migration.

02

Replatform

Minor cloud-specific optimizations without core architecture changes.

03

Refactor

Significantly modify architecture to leverage cloud-native capabilities.

04

Repurchase

Replace existing applications with new cloud-native SaaS solutions.

05

Retain

Keep certain applications on-premises due to specific constraints.

06

Retire

Decommission applications that are no longer needed or used.

Key Takeaway

The '6 Rs' offer distinct strategies for migrating applications to the cloud, balancing effort, cost, and cloud-native optimization.
