Migration Strategy 1/6

Rehost: The "Lift and Shift" Approach

Moving Applications As-Is to the Cloud

Definition

Moving applications from on-premises to the cloud without significant changes to their core architecture or code.

Key Benefit

Often the fastest initial migration strategy, reducing immediate data center costs and operational overhead.

GCP Tools

Google Cloud Migrate for Anthos and VMs (formerly Migrate for Compute Engine) automates VM migration to Compute Engine.

Key Takeaway

Rehosting moves applications to the cloud with minimal changes, offering the fastest initial migration but often requiring further optimization later.
