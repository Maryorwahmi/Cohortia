Core Cloud Concepts: Definitions & Models

Reviewing IaaS, PaaS, SaaS, Shared Responsibility, and IAM fundamentals.

Cloud Service Models

IaaS (Compute Engine): Virtualized computing resources; user manages OS, apps, data.

PaaS (App Engine): Platform for developing/running apps; provider manages infra, OS, runtime.

SaaS (Gmail/Workspace): Software applications delivered over internet; provider manages entire stack.

Key Security & Access Concepts

Shared Responsibility Model

Google Cloud secures of the cloud (infra), customer secures in the cloud (data, apps, config).

Identity and Access Management (IAM)

Controls who can do what on which resources, enforcing the principle of least privilege.

VM vs. Container

VMs (Compute Engine) offer full OS control; Containers (Cloud Run) offer serverless, managed execution for stateless apps.

Key Takeaway

A strong grasp of cloud service models, security responsibilities, and access management is fundamental to effective cloud leadership.
