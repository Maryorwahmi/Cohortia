Testing and Cleaning Up Your Cloud Function

Verifying functionality and managing resources

Testing the Function
# After deployment, copy the httpsTrigger.url from the output.

# Test 1 (basic GET request in browser):
Open the URL in your web browser.
Expected: "Hello from Cloud Function!"

# Test 2 (GET with query parameter):
Append ?name=Cohortia to the URL.
Example: https://us-central1-[YOUR_PROJECT_ID].cloudfunctions.net/helloHttp?name=Cohortia
Expected: "Hello Cohortia!"

# Test 3 (POST request using curl in Cloud Shell):
curl -X POST -H "Content-Type:application/json" -d '{"name":"GCP User"}' [YOUR_FUNCTION_URL]
Expected: "Hello GCP User!"
Key Takeaway

Thoroughly test your deployed Cloud Function using various methods (GET, POST) to ensure it handles different inputs correctly, then clean up resources to manage costs.

Cleaning Up Resources
# Clean up (optional but recommended to avoid charges):
gcloud functions delete helloHttp --region us-central1 --quiet
Important Reminder

Always clean up resources after hands-on activities to prevent unexpected billing. The `--quiet` flag bypasses confirmation prompts.
