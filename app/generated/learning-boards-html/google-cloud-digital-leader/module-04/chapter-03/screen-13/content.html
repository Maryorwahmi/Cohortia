Deploying a Cloud Function: Part 2

Defining dependencies and executing the deployment command

package.json (Dependencies)
{
  "name": "hello-http-function",
  "version": "1.0.0",
  "description": "A simple HTTP Cloud Function",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "dependencies": {
    "@google-cloud/functions-framework": "^3.0.0"
  },
  "devDependencies": {},
  "engines": {
    "node": "16"
  }
}
Key Takeaway

The `package.json` defines function dependencies, and the `gcloud functions deploy` command initiates the serverless deployment, specifying runtime, trigger, and entry point.

Deployment Command
gcloud functions deploy helloHttp \
    --runtime nodejs16 \
    --trigger-http \
    --allow-unauthenticated \
    --entry-point helloHttp \
    --region us-central1 \
    --project=[YOUR_PROJECT_ID]
Important Note

Remember to replace `[YOUR_PROJECT_ID]` with your actual Google Cloud Project ID before running the deployment command.
