Step 1: Open Cloud Shell

Navigate to the Google Cloud Console and open Cloud Shell, an interactive shell environment for GCP.

# In Google Cloud Console, click the Cloud Shell icon

Step 2: Create a Compute Engine Instance

Use the gcloud CLI to create a new VM instance with a startup script to install Apache.

gcloud compute instances create my-web-server \
    --project=[YOUR_PROJECT_ID] \
    --zone=us-central1-a \
    --machine-type=e2-medium \
    --image-family=debian-11 \
    --image-project=debian-cloud \
    --tags=http-server \
    --metadata=startup-script="#! /bin/bash
        sudo apt-get update
        sudo apt-get install -y apache2
        sudo systemctl enable apache2
        sudo systemctl start apache2
        echo '<!doctype html><html><body><h1>Hello from Compute Engine!</h1></body></html>' | sudo tee /var/www/html/index.html"
Command Breakdown
  • --project: Your Google Cloud Project ID.
  • --zone: The geographical zone for your VM.
  • --machine-type: Defines CPU and memory (e.g., e2-medium).
  • --image-family / --image-project: Specifies the OS image (e.g., Debian 11).
  • --tags: Applies network tags for firewall rules.
  • --metadata=startup-script: Executes a script upon VM startup for automated setup.
Key Takeaway

Startup scripts are powerful for automating initial VM configuration, allowing for consistent and repeatable deployments.
