Migration Strategies

The 5 Rs: Rehost and Replatform

Moving to the cloud with minimal or some cloud-native optimizations.

1 Rehost (Lift and Shift)

Move an application to the cloud without significant changes. Often involves migrating virtual machines to Compute Engine. It's the fastest way to get to the cloud but offers the least cloud-native benefits.

2 Replatform (Lift and Reshape)

Make some cloud optimizations to the application to take advantage of managed services, without changing the core architecture. Example: moving a database to Cloud SQL.

Migration Spectrum: Effort vs. Cloud Benefits
Rehost Replatform Refactor
Less Cloud-Native Benefits <---> More Cloud-Native Benefits

Each strategy offers a different balance between migration effort and the depth of cloud integration.

Key Takeaway

Rehost is fast but offers minimal cloud benefits; Replatform adds some cloud-native optimizations with managed services.

Consideration

While quick, rehosting may not fully address underlying architectural issues or maximize cloud cost savings.
