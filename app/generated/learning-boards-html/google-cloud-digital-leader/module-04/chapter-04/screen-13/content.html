Key Concepts: Migration & Architecture

Essential terms for modernizing applications on Google Cloud.

Application Modernization

The process of updating existing software to newer computing approaches, including new languages, frameworks, databases, and infrastructure platforms (like cloud).

Rehost (Lift and Shift)

A migration strategy where applications are moved to the cloud without significant changes to their architecture.

Refactor/Re-architect

A migration strategy involving significant changes to an application's architecture to leverage cloud-native capabilities, often breaking monoliths into microservices.

Summary Takeaway

Modernization involves various strategies, from simple rehosting to complex re-architecting, each offering different levels of cloud integration and benefits.
