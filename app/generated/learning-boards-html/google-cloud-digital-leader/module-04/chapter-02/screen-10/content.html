Deploying Containerized Apps to Cloud Run

A streamlined path from code to production

Cloud Shell Terminal
user@cloudshell:~$ gcloud services enable artifactregistry.googleapis.com
user@cloudshell:~$ gcloud artifacts repositories create my-repo --repository-format=docker --location=us-central1 --description="Docker repository"
user@cloudshell:~$ gcloud auth configure-docker us-central1-docker.pkg.dev
user@cloudshell:~$ docker build -t us-central1-docker.pkg.dev/[YOUR_PROJECT_ID]/my-repo/cloud-run-hello:v1 .
... (build output) ...
user@cloudshell:~$ docker push us-central1-docker.pkg.dev/[YOUR_PROJECT_ID]/my-repo/cloud-run-hello:v1
... (push output) ...
user@cloudshell:~$ gcloud run deploy cloud-run-hello \
--image us-central1-docker.pkg.dev/[YOUR_PROJECT_ID]/my-repo/cloud-run-hello:v1 \
--platform managed \
--region us-central1 \
--allow-unauthenticated \
--project=[YOUR_PROJECT_ID]
... (deployment output, URL provided) ...

1. Code & Dockerfile

Write your application code and define its container image using a Dockerfile.

2. Build & Push Image

Build the Docker image and push it to Google Artifact Registry for secure storage.

3. Deploy to Cloud Run

Use a simple `gcloud` command to deploy your containerized application to Cloud Run.

4. Auto-Scaling & Access

Cloud Run automatically scales your app and provides a public URL for access.

Key Takeaway

Cloud Run simplifies container deployment to a few commands, handling all infrastructure and scaling automatically, enabling rapid iteration and cost efficiency.
