Key Concepts

Here are the essential terms and ideas from this chapter.

Persistent Disk

Durable block storage attached to VM instances, independent of the VM's lifecycle, ensuring data persistence.

Image

A template used to create VM instances, containing an operating system and potentially pre-installed software.

Snapshot

A point-in-time backup of a persistent disk, used for data recovery and efficient migration.

Summary Takeaway

Persistent disks provide durable storage, images standardize VM deployments, and snapshots ensure robust data backup and recovery strategies.
