More Memory, Less vCPUs

High-Memory machine types, such as n2-highmem, are configured with a significantly higher amount of memory relative to their vCPUs. This design prioritizes RAM capacity.

  • Memory-Bound: Optimized for tasks that are limited by available RAM.
  • Data-Intensive: Ideal for applications that load large datasets into memory.
  • Reduced I/O: Minimizes disk I/O, improving performance for memory-heavy tasks.
Example Instance

An n2-highmem-8 instance with 8 vCPUs and 64 GB of memory, perfect for a large in-memory database.

Suitable Workloads

These machine types are essential for applications where large amounts of data need to be accessed and processed quickly in memory.

  • In-Memory Databases: Such as Redis or large analytical databases.
  • Data Analytics: Processing extensive datasets for insights.
  • Machine Learning: Training models that require large datasets in RAM.
  • Genomics/Bioinformatics: Memory-intensive computational biology tasks.
Key Takeaway

High-Memory machine types are crucial for applications that are memory-bound, providing the necessary RAM to prevent performance bottlenecks and ensure efficient data processing.
