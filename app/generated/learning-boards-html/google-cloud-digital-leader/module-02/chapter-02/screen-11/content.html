Shared Physical Core

Shared-Core machine types, like e2-micro and e2-small, are cost-effective options where multiple VM instances share a single physical CPU core.

  • Cost-Effective: Lowest cost option for minimal resource needs.
  • Resource Sharing: CPU resources are time-sliced among multiple VMs.
  • Variable Performance: Performance can fluctuate based on core utilization.
Example Instance

An e2-micro instance with 2 vCPUs (shared) and 1 GB of memory, ideal for a personal blog or small dev server.

Suitable Workloads

These machine types are best suited for non-critical applications with low and intermittent resource demands, where cost is a primary concern.

  • Development Environments: Non-production coding and testing.
  • Small Websites/Blogs: Low-traffic personal or informational sites.
  • Microservices: Services with infrequent or bursty requests.
  • Proof-of-Concept: Experimentation and learning environments.
Key Takeaway

Shared-Core machine types offer a highly cost-effective solution for small, non-critical workloads, trading dedicated performance for significant budget savings.
