Images: VM Templates

Images are templates used to create new VM instances. They contain an operating system and can include pre-installed software, enabling standardized deployments.

  • Public Images: Provided by Google for various OS (Debian, Ubuntu, Windows).
  • Custom Images: Create from your configured VMs for consistent environments.
  • Fast Deployment: Accelerates provisioning of new instances.
Use Case

Deploying a fleet of web servers, all starting with the same OS and web server software pre-installed.

Snapshots: Disk Backups

Snapshots are point-in-time backups of your persistent disks. They are incremental, storing only changed data blocks, making them efficient for backups and disaster recovery.

  • Incremental: Only new or changed data is stored, saving space.
  • Disaster Recovery: Quickly restore disks to a previous state.
  • Data Migration: Easily move disk data between regions or projects.
Key Takeaway

Images provide standardized VM templates for efficient deployment, while snapshots offer incremental, cost-effective backups crucial for data recovery and migration strategies.
