Key Concepts

Here are the essential terms and ideas from this chapter.

Compute Engine (GCE)

Google Cloud's Infrastructure-as-a-Service (IaaS) offering for running virtual machines on Google's global infrastructure.

VM Instance

A virtual machine running on Google Cloud, comprising vCPUs, memory, a boot disk, and network interfaces.

Machine Type

A predefined or custom configuration of vCPUs and memory for a VM instance, optimized for different workloads.

Summary Takeaway

GCE provides flexible VM instances with customizable machine types, forming the core of Google Cloud's IaaS offering.
