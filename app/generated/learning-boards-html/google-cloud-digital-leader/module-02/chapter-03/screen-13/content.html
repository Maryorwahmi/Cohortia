Key Concepts

What to Remember

Virtual Private Cloud (VPC)

A global, software-defined network providing private connectivity for your Google Cloud resources.

Subnet

A regional segment of a VPC network with a defined IP address range, used for resource organization and isolation.

Firewall Rule

A rule that allows or denies network traffic to or from Google Cloud resources based on protocol, port, source, and destination.

These three components—VPC, Subnets, and Firewall Rules—form the essential building blocks for secure and scalable networking in Google Cloud.
