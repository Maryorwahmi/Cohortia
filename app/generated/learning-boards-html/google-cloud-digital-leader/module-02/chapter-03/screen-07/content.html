Flexible Subnet Management

Auto-mode vs. Custom-mode VPCs

VPC Subnet Modes

Auto-mode VPC

  • Automatically creates subnets in each region.
  • Good for quick starts and simple deployments.
  • Less control over IP ranges.

Custom-mode VPC

  • You manually define all subnets and IP ranges.
  • Offers complete control and flexibility.
  • Recommended for production and complex environments.
Terminal Demo: Creating a Custom VPC and Subnet
# 1. Create a custom VPC network
gcloud compute networks create my-custom-vpc \
    --subnet-mode=custom \
    --description="My custom VPC for web apps"

# 2. Create a subnet within the custom VPC
gcloud compute networks subnets create my-subnet-us-east1 \
    --network=my-custom-vpc \
    --region=us-east1 \
    --range=10.0.1.0/24

This command sequence first creates a VPC named my-custom-vpc configured for manual subnet creation. Then, it defines a subnet named my-subnet-us-east1 within that VPC, assigning it to the us-east1 region with a specific IP range. This gives you precise control over your network's structure.

Key Takeaway

Custom-mode VPCs provide granular control over subnet creation and IP address allocation, enabling precise network design for specific architectural needs.
