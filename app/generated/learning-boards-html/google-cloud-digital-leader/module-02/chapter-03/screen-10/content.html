Configuring Firewall Rules for Web Servers

Securing Your Applications

Scenario: Public Web Server

  • Goal: Allow inbound HTTP (port 80) and HTTPS (port 443) traffic.
  • Source: From anywhere on the internet (0.0.0.0/0).
  • Target: Instances with the network tag webserver.
Terminal Demo: Creating a Web Server Firewall Rule
gcloud compute firewall-rules create allow-http-webservers \
    --network=my-vpc-network \
    --allow=tcp:80,tcp:443 \
    --source-ranges=0.0.0.0/0 \
    --target-tags=webserver \
    --description="Allow HTTP and HTTPS to web servers"

This command creates an ingress firewall rule named allow-http-webservers. It applies to my-vpc-network, allowing TCP traffic on ports 80 and 443 from any IP address (0.0.0.0/0) to instances that have the webserver network tag. This is a common and necessary configuration for public-facing web applications.

Key Takeaway

Custom firewall rules are essential to enable specific application traffic, like HTTP/HTTPS for web servers, while maintaining network security.
