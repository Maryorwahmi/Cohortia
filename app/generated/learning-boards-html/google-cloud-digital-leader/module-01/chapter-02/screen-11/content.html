Storing Your Data: Object and Block Storage

Scalable and durable options for various data types.

Key Takeaway

GCP offers Cloud Storage for scalable object storage of unstructured data and Persistent Disk for high-performance block storage attached to VMs, catering to diverse data needs.

Pro-Tip

Choose Cloud Storage for static assets, backups, and archives. Use Persistent Disk for OS volumes, databases, and applications requiring file system access.

Cloud Storage (Object Storage)

Highly scalable, durable, and cost-effective for unstructured data like images, videos, and backups. Offers different storage classes.

Persistent Disk (Block Storage)

Block storage for Compute Engine VMs, similar to a traditional hard drive. Offers various performance tiers and dynamic resizing for OS and application data.

Data Access Patterns

Choose based on whether your data needs file system access (block) or is accessed as discrete objects (object).
