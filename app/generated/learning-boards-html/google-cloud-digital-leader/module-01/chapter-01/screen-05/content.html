NIST Essentials

On-Demand Self-Service

Users can provision computing capabilities without human interaction from the service provider.

Example

A developer instantly deploys a new virtual server via a web portal for testing.

Broad Network Access

Capabilities are accessed over the network through standard mechanisms, available from various client platforms.

Example

Accessing cloud applications from a laptop, tablet, or smartphone from any location.
