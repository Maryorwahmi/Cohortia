Key-Value Store

What are Mappings?

Mappings are hash tables that store key-value pairs, providing efficient data retrieval based on a unique key.

mapping(address => uint) public balances;
mapping(uint => string) public names;

function setBalance(address _user, uint _amount) public {
    balances[_user] = _amount;
}

Constant-Time Lookups: Very efficient for retrieving values by key.

Not Iterable: Cannot directly loop through keys or values.

Key and Value Types

Flexible Associations

Key Types

Must be a value type (e.g., address, uint, bytes32).

Value Types

Can be any type, including other mappings or structs.

Pro-Tip

For iterable mappings, combine them with an array to store keys, allowing you to retrieve all entries when needed.

Key Takeaway

Mappings are essential for efficient key-value data storage in Solidity, offering fast lookups but requiring careful design if iteration is needed.
