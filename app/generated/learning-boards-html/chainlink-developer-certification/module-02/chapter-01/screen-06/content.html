Definition

What are Value Types?

Value types directly store their data. When assigned or passed as arguments, a complete copy of the data is made, ensuring independence.

uint256 myNumber = 100;
bool isActive = true;
address ownerAddress = 0x...;
bytes32 dataHash = 0x...;
Direct Storage

The variable holds the actual data, not a reference.

Copy-by-Value

Assignments create independent copies, preventing unintended side effects.

Common Value Types

Examples and Use Cases

uint / int

Unsigned/signed integers (e.g., uint256 for token balances).

bool

Boolean values (true/false for flags).

address

20-byte Ethereum addresses (for user accounts or other contracts).

bytesN

Fixed-size byte arrays (e.g., bytes32 for hashes).

Key Takeaway

Value types are fundamental for storing simple, independent data points in Solidity, always creating a copy upon assignment.
