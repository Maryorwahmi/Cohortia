Gas Optimization

Defining State Interaction

State mutability specifiers control how functions interact with the contract's state, impacting gas costs and security.

view

Reads state, but cannot modify it. Free off-chain calls.

pure

Cannot read or modify state. Always free off-chain calls.

payable

Can receive Ether. Can also modify state.

Code Example

Applying Mutability

contract MutabilityExample {
    uint256 public storedValue;

    function setValue(uint256 _newValue) public {
        storedValue = _newValue;
    }

    function getValue() public view returns (uint256) {
        return storedValue;
    }

    function calculateSum(uint256 a, uint256 b) public pure returns (uint256) {
        return a + b;
    }

    function depositEther() public payable {}
}
Key Takeaway

Correctly applying state mutability specifiers is essential for optimizing gas costs, enhancing security, and clearly defining function behavior.
