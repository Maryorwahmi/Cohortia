Access Control

Understanding Visibility

Visibility specifiers define the accessibility of state variables and functions, dictating who can interact with them.

public

Accessible from inside and outside the contract. Auto-generates getter for state variables.

private

Only accessible from within the defining contract.

internal

Accessible from within the contract and derived contracts.

external

Only callable from outside the contract (for functions).

Code Example

Applying Visibility

contract AccessControl {
    uint256 public publicVar;
    uint256 private privateVar;
    uint256 internal internalVar;

    function setPublic(uint256 _val) public {
        publicVar = _val;
    }

    function getPrivate() internal view returns (uint256) {
        return privateVar;
    }
}
Key Takeaway

Careful use of visibility specifiers is paramount for smart contract security, preventing unauthorized access and ensuring proper function execution.
