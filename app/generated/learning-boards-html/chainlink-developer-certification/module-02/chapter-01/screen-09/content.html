Collections

Arrays: Ordered Lists

Arrays store a sequence of elements of the same type. They can be fixed-size or dynamic.

uint[] public dynamicArray; // Dynamic array
uint[5] public fixedArray; // Fixed-size array

function addNumber(uint _num) public {
    dynamicArray.push(_num);
}

Dynamic Sizing: Flexible arrays can grow or shrink.

Fixed Sizing: Size determined at compile time, efficient for known limits.

Custom Structures

Structs: Grouping Data

Structs allow you to define custom data types by grouping variables of different types together.

struct Product {
    uint productId;
    string memory name;
    uint price;
    bool available;
}

Product public myProduct;

Logical Grouping: Keeps related data together for better organization.

Enhanced Readability: Improves code clarity and maintainability.

Key Takeaway

Arrays manage collections of similar data, while structs group diverse, related data into custom types, both crucial for complex contract state.
