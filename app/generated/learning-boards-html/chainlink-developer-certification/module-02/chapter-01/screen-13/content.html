The SimpleStorage Contract

This contract demonstrates basic state variable declaration and functions for setting and retrieving a number, showcasing visibility and state mutability.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleStorage {
    // State variable to store a number
    uint256 public storedNumber; // 'public' creates a getter

    // Function to set the stored number
    function setNumber(uint256 _newNumber) public {
        storedNumber = _newNumber; // Modifies state
    }

    // Function to retrieve the stored number
    function getNumber() public view returns (uint256) {
        return storedNumber;
    }

    // A pure function that doesn't read or modify state
    function addTwoNumbers(uint256 a, uint256 b) public pure returns (uint256) {
        return a + b;
    }
}
Key Learnings

Concepts in Action

State Variables: storedNumber persists on the blockchain.

Visibility: public allows external interaction and auto-getter.

State Mutability: setNumber modifies, getNumber views, addTwoNumbers is pure.

Key Takeaway

The SimpleStorage contract is a foundational example demonstrating how state variables, visibility, and state mutability work together in a functional smart contract.
