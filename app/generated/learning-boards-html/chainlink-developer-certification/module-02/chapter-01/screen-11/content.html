Core Logic

Defining Contract Actions

Functions are the executable blocks of code that define how a smart contract behaves and interacts with its state.

contract MyContract {
    uint256 public myNumber;

    function setNumber(uint256 _newNumber) public {
        myNumber = _newNumber;
    }

    function getNumber() public view returns (uint256) {
        return myNumber;
    }
}

State Modification: Functions can change the persistent data on the blockchain.

Read-Only Operations: Functions can also retrieve state without altering it.

Key Considerations

Visibility and Mutability

Visibility

Controls who can call the function (e.g., public, private).

State Mutability

Defines how the function interacts with the contract's state (e.g., view, pure, payable).

Common Mistake

Forgetting view or pure for functions that don't modify state leads to higher, unnecessary gas costs for users.

Key Takeaway

Functions are the core logic of smart contracts, and their visibility and state mutability are critical for security and gas efficiency.
