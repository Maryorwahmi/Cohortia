Definition

What are Reference Types?

Reference types store the location (a reference) of the data, not the data itself. Assignments create pointers to the same data.

uint[] public dynamicArray;
struct User { address userAddress; }
mapping(address => uint) public balances;
Indirect Storage

Variables point to where the data is stored.

Copy-by-Reference

Assignments share the same underlying data, changes are reflected everywhere.

Data Locations

Where Data Resides

memory

Temporary storage for function execution; data is discarded after the function call.

storage

Persistent storage on the blockchain for state variables; data persists across transactions.

calldata

Read-only, immutable area for external function arguments; data is temporary and cannot be modified.

Key Takeaway

Reference types require explicit data locations and are crucial for managing complex data structures and their persistence on the blockchain.
