Pitfall 1

Complex Inheritance Hierarchies

  • Deep or convoluted inheritance chains become hard to manage and debug.
  • Can lead to unexpected behavior and increased complexity.
Pitfall 2

Misusing `virtual` / `override`

  • Forgetting `virtual` in parent or `override` in child causes compilation errors.
  • Lack of clarity can lead to unintended function calls.
Pitfall 3

Stateful Libraries

  • Libraries are designed to be stateless; attempting to store state will fail or lead to unexpected behavior.
  • Violates the core principle of library design.
Best Practice 1

Keep Inheritance Simple

  • Favor shallower inheritance trees.
  • Use composition over inheritance when appropriate for complex relationships.
Best Practice 2

Explicit Keyword Usage

  • Always use `virtual` and `override` explicitly to define intended behavior.
  • Improves code clarity and reduces errors.
Chainlink Relevance

Events & Libraries for Oracles

  • Events are critical for monitoring oracle responses.
  • Libraries can encapsulate common data parsing or request formatting logic for Chainlink interactions.
