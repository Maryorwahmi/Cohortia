`virtual` and `override` Example
// Parent contract
contract Animal {
    function makeSound() public virtual pure returns (string memory) {
        return "Generic animal sound";
    }
}

// Child contract overriding makeSound
contract Dog is Animal {
    function makeSound() public override pure returns (string memory) {
        return "Woof!";
    }
}

// Another child contract
contract Cat is Animal {
    function makeSound() public override pure returns (string memory) {
        return "Meow!";
    }
}
Key Takeaway

`virtual` and `override` keywords enable child contracts to customize inherited functions, providing specialized implementations while maintaining a clear inheritance hierarchy.

`virtual` Keyword

Enabling Overriding in Parent

  • Marks a function in a parent contract as eligible for overriding.
  • Without `virtual`, child contracts cannot provide their own implementation.
`override` Keyword

Implementing in Child

  • Explicitly states that a function in a child contract is overriding a parent function.
  • Required for clarity and to prevent accidental overriding.
Common Pitfall

Missing Keywords

Forgetting `virtual` in the parent or `override` in the child will result in compilation errors, as Solidity enforces explicit intent for method overriding.
