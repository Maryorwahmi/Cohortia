Core Concept

What is Inheritance?

Inheritance allows a contract to derive properties (state variables) and behaviors (functions) from another contract, promoting code reusability and modularity.

Syntax

Using the `is` Keyword

  • Specify inheritance with `contract ChildContract is ParentContract { ... }`.
  • Child contract gains access to parent's `public` and `internal` members.
  • `private` members are not inherited.
Benefit

Reduced Code Duplication

By inheriting common functionality, you avoid writing the same code multiple times, which saves development time, reduces errors, and simplifies maintenance.

Inheritance Example
// Parent contract
contract BaseContract {
    uint256 public value = 10;
    function getValue() public view returns (uint256) {
        return value;
    }
}

// Child contract inheriting from BaseContract
contract DerivedContract is BaseContract {
    // DerivedContract now has 'value' state variable
    // and 'getValue()' function
    function getDerivedValue() public view returns (uint256) {
        return getValue() * 2;
    }
}
Key Takeaway

Inheritance allows contracts to build upon existing functionality, using the `is` keyword to create a hierarchy of reusable code.
