`indexed` Keyword in Action
contract Token {
    // Declare an event with indexed parameters
    event Transfer(address indexed from, address indexed to, uint256 value);

    mapping(address => uint256) public balances;

    function transfer(address _to, uint256 _amount) public {
        require(balances[msg.sender] >= _amount, "Insufficient balance");
        balances[msg.sender] -= _amount;
        balances[_to] += _amount;
        // Emit the event
        emit Transfer(msg.sender, _to, _amount);
    }
}
Key Takeaway

`indexed` parameters are crucial for efficient filtering of event logs, allowing DApps to quickly find relevant transactions without scanning all data.

Purpose

Enabling Searchable Logs

  • `indexed` parameters are stored in topics, making them searchable.
  • Off-chain tools can filter events by these indexed values.
  • Up to 3 `indexed` parameters per event (plus event signature).
Benefit

Improved DApp Performance

Efficient filtering reduces the data off-chain applications need to process, leading to faster updates and a more responsive user experience. This is vital for real-time data display.

Important Note

Off-Chain Only Access

While `indexed` parameters are great for off-chain searching, their values are not directly accessible from within the smart contract itself. They are primarily for external consumption.
