`Ownable` Contract Example
// Parent contract
contract Ownable {
    address public owner;
    event OwnershipTransferred(address indexed previousOwner, address indexed newOwner);

    constructor() {
        owner = msg.sender;
    }

    modifier onlyOwner() {
        require(msg.sender == owner, "Caller is not the owner");
        _;
    }

    function transferOwnership(address _newOwner) public onlyOwner {
        require(_newOwner != address(0), "New owner is the zero address");
        emit OwnershipTransferred(owner, _newOwner);
        owner = _newOwner;
    }
}

// Child contract inheriting from Ownable
contract MyContract is Ownable {
    // MyContract now has 'owner', 'onlyOwner' modifier, and 'transferOwnership' function
    function doSomethingRestricted() public onlyOwner {
        // ... restricted logic
    }
}
Key Takeaway

The `Ownable` pattern demonstrates how inheritance provides reusable access control, securing contract functions with minimal code duplication.

`owner` State Variable

Tracking Contract Ownership

  • Stores the address of the contract's current owner.
  • Set during contract deployment in the constructor.
`onlyOwner` Modifier

Restricting Function Access

  • Ensures only the `owner` can call functions marked with this modifier.
  • Reverts if `msg.sender` is not the owner.
`transferOwnership` Function

Secure Ownership Transfer

  • Allows the current owner to transfer ownership to a new address.
  • Emits an `OwnershipTransferred` event for transparency.
