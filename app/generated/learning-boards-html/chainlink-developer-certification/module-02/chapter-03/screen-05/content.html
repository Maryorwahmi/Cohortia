Solidity Event Example
contract Token {
    // Declare an event
    event Transfer(address indexed from, address indexed to, uint256 value);

    mapping(address => uint256) public balances;

    function transfer(address _to, uint256 _amount) public {
        require(balances[msg.sender] >= _amount, "Insufficient balance");
        balances[msg.sender] -= _amount;
        balances[_to] += _amount;
        // Emit the event
        emit Transfer(msg.sender, _to, _amount);
    }
}
Key Takeaway

Events are declared with `event` and triggered with `emit` to create an auditable log of contract activity, vital for off-chain applications.

Declaration

Using the `event` Keyword

  • Define the event's name and its parameters.
  • Parameters specify the data to be logged.
  • Example: `event Transfer(address from, address to, uint256 value);`
Emission

Triggering with `emit`

  • Use `emit EventName(param1, param2, ...);` to trigger the event.
  • This writes the event data to the transaction log.
  • Essential for signaling important state changes.
Common Mistake

Forgetting to Emit Events

Not emitting events for critical state changes makes it difficult for off-chain applications to react to contract activity, leading to poor user experience and integration challenges.
