Key Concepts

Essential Terms to Remember for Structured Contracts

Event

A mechanism in Solidity to log information on the blockchain, allowing off-chain applications to react to contract activity efficiently.

`emit`

The keyword used to trigger an event, logging its data to the transaction receipt for off-chain monitoring.

`indexed`

A keyword used with event parameters to make them searchable and filterable in transaction logs by off-chain applications.

Inheritance

A feature allowing a contract to derive properties and behaviors from another contract using the `is` keyword, promoting code reusability.

`virtual` / `override`

Keywords used for defining functions that can be overridden and for explicitly overriding functions in child contracts, respectively.

Summary Takeaway

Events provide crucial off-chain communication, while inheritance enables robust, reusable contract structures through explicit method overriding.
