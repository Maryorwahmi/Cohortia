Definition

What is a Solidity Library?

  • Stateless utility contract, cannot have state variables (except `immutable`/`constant`).
  • Cannot receive Ether or be destroyed.
  • Contains pure or view functions for common operations.
Gas Efficiency

`DELEGATECALL` Mechanism

  • Library code is deployed once.
  • Functions execute in the context of the calling contract via `DELEGATECALL`.
  • Reduces deployment gas costs and contract size by avoiding code duplication.
Use Cases

Modular Utility Functions

  • Common mathematical operations (e.g., safe math).
  • String manipulation, complex data structure logic.
  • Encapsulating shared, stateless logic.
Example Library: `MathUtils`
// Example Library
library MathUtils {
    function add(uint256 a, uint256 b) internal pure returns (uint256) {
        return a + b;
    }

    function subtract(uint256 a, uint256 b) internal pure returns (uint256) {
        require(b <= a, "Subtraction overflow");
        return a - b;
    }
}
Key Takeaway

Libraries offer a gas-efficient way to reuse stateless utility functions across multiple contracts, promoting modularity and reducing deployment costs.
