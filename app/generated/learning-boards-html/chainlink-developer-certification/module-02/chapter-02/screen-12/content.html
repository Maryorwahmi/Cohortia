Access Control

Reusable Access Control with Modifiers

Implementing onlyAdmin and similar patterns to restrict function execution.

1. Define Modifier

Create a modifier (e.g., onlyAdmin) with a require check and _; placeholder.

2. Apply to Function

Attach the modifier to function declarations that need the access control.

3. Execution Flow

Modifier's logic runs first; if successful, the function body executes where _; is placed.

// Example: onlyAdmin Modifier
contract AdminControlled {
    address public admin;

    constructor(address _admin) {
        admin = _admin;
    }

    modifier onlyAdmin() {
        require(msg.sender == admin, "Caller is not the admin.");
        _; // Function body inserted here
    }

    function pauseContract() public onlyAdmin {
        // Logic to pause the contract
    }

    function unpauseContract() public onlyAdmin {
        // Logic to unpause the contract
    }
}
Centralizing access control logic with modifiers enhances security and reusability.
Key Takeaway

Function modifiers are essential for enforcing consistent access control and pre-conditions, making contracts more secure and easier to manage.
