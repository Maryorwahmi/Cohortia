Error Handling

assert() for Critical Bugs

Ensuring internal contract integrity and detecting severe logic flaws.

Purpose: Internal Invariants

Used to check conditions that should *never* be false, indicating a critical bug in the contract's logic. Not for user input validation.

Gas Consumption: All Remaining Gas

If assert() fails, it consumes all remaining gas, making it more expensive than require() or revert() on failure.

Key Takeaway

Use assert() only for internal consistency checks; for external input or pre-conditions, prefer require() or revert() to save gas on failure.
