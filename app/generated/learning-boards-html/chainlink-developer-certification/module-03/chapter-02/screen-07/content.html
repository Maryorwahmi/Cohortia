Anatomy of a Price Consumer Contract

Setting up your contract to receive price data from Chainlink.

PriceConsumerV3 Constructor
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.19;

import "@chainlink/contracts/src/v0.8/interfaces/AggregatorV3Interface.sol";

contract PriceConsumerV3 {
    AggregatorV3Interface internal priceFeed;

    // Constructor initializes the priceFeed with the correct Chainlink Data Feed address.
    // For Sepolia ETH/USD, this is 0x694AA1769357215Ee4f0fFfE86eBc454f87d25Dc
    constructor(address _priceFeedAddress) {
        priceFeed = AggregatorV3Interface(_priceFeedAddress);
    }

    // ... other functions will go here
}

Connecting to the Data Feed

The constructor takes the Data Feed address and creates an instance of the AggregatorV3Interface.

  • _priceFeedAddress is passed during contract deployment.
  • priceFeed becomes the gateway to Chainlink's oracle.
  • Establishes a direct, secure link to the price data.
Key Takeaway

The contract's constructor is vital for initializing the AggregatorV3Interface with the correct Chainlink Data Feed address.
