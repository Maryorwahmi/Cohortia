Retrieving the Latest Price Data

Calling latestRoundData() to fetch current market prices.

getLatestPrice() Implementation
contract PriceConsumerV3 {
    AggregatorV3Interface internal priceFeed;
    // ... constructor

    /**
     * @dev Returns the latest price of the asset pair.
     * The price is returned as an integer, scaled by the 'decimals' value.
     */
    function getLatestPrice() public view returns (int256) {
        // latestRoundData() returns 5 values
        ( 
            uint80 roundId,
            int256 price,
            uint256 startedAt,
            uint256 updatedAt,
            uint80 answeredInRound
        ) = priceFeed.latestRoundData();
        
        // For now, we focus on the 'price' value.
        return price;
    }
}

The latestRoundData() Call

This function is the core mechanism for fetching the most recent aggregated data from the Chainlink oracle network.

  • Returns five values, with price being the primary focus.
  • It's a view function, meaning it's gas-free for external calls.
  • Provides real-time market data for your dApp's logic.
Key Takeaway

getLatestPrice() leverages priceFeed.latestRoundData() to securely retrieve the current aggregated price from Chainlink.
