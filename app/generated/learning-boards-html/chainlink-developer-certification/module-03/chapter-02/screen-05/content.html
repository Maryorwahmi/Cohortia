Locating the Right Data Feed Address

Ensuring your contract connects to the correct price source.

The Importance of Specificity

Each Chainlink Data Feed has a unique address for a specific asset pair (e.g., ETH/USD) and blockchain network (e.g., Sepolia).

  • Using the wrong address leads to errors or incorrect data.
  • Addresses are not interchangeable across networks or assets.
  • Crucial for the security and accuracy of your dApp.
Common Mistake

Copying an address from a different network (e.g., Mainnet ETH/USD for Sepolia) will cause your contract to fail or fetch invalid data.

Official Source: data.chain.link

Chainlink's official documentation portal provides a comprehensive and up-to-date list of all Data Feed addresses.

  • Navigate to data.chain.link.
  • Select your target network (e.g., Sepolia).
  • Find the desired asset pair (e.g., ETH/USD).
  • Copy the exact AggregatorV3 proxy contract address.
Example

Sepolia ETH/USD Data Feed Address: 0x694AA1769357215Ee4f0fFfE86eBc454f87d25Dc

Key Takeaway

Always verify Data Feed addresses on data.chain.link for the correct network and asset pair to ensure data integrity.
