Scaling Price Data with decimals()

Avoiding common pitfalls in price interpretation.

getDecimals() Function
contract PriceConsumerV3 {
    // ... other functions

    /**
     * @dev Returns the number of decimal places the price feed uses.
     * Essential for correctly interpreting the raw price value.
     */
    function getDecimals() public view returns (uint8) {
        return priceFeed.decimals();
    }
}
Common Mistake

Directly using the raw integer price without scaling by decimals() will lead to incorrect calculations and financial errors.

The Scaling Formula

Human-readable Price = Raw Price / (10 ^ decimals)

Example Calculation

Raw Price: 195000000000
Decimals: 8
Actual Price: 195000000000 / 10^8 = 1950.00

Key Takeaway

Always query decimals() and use it to scale the raw integer price to its human-readable value, ensuring accuracy.
