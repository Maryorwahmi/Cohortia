OCR: Efficiency Through Off-Chain Consensus

Comparing Data Submission Methods

Traditional Method (Individual Submissions)

  • •Each oracle node submits its data individually to the aggregator contract.
  • •Results in many on-chain transactions for each data update.
  • •Can be gas-intensive and less scalable, especially with many nodes.
Example: 20 nodes = 20 on-chain transactions per update.

Off-chain Reporting (OCR)

  • •Nodes reach consensus and aggregate data *off-chain*.
  • •A single, cryptographically signed report is submitted on-chain by one node.
  • •Significantly reduces gas costs and improves scalability for frequent updates.
Example: 20 nodes = 1 on-chain transaction per update.
Key Takeaway

OCR is a major advancement, making Chainlink Data Feeds far more gas-efficient and scalable than older methods.
