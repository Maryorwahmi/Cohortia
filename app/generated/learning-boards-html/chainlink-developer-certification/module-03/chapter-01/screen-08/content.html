Aggregator Contracts: On-Chain Consensus

Consolidating Data On-Chain for Smart Contracts

On-Chain Data Destination

These are smart contracts that receive data submissions from multiple Chainlink nodes.

Data Aggregation Logic

They process submissions, typically by taking a median, to produce a single, reliable data point.

Single Source of Truth

The aggregated value is stored and made available for other smart contracts to read, ensuring data integrity.

The On-Chain Vault

Aggregator contracts are the secure, on-chain repository for validated real-world data.

Example: An aggregator contract receives 7 reports for ETH/USD, calculates the median, and stores it.
Key Takeaway

Aggregator Contracts ensure data reliability by consolidating and validating multiple oracle reports on-chain.
