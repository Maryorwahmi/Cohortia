Process Flow

The Data Journey: Off-Chain to On-Chain

From Real World to Smart Contract

01

Off-chain Data Sources

External APIs, exchanges, and data providers hold real-world information.

02

Chainlink Nodes Fetch

Independent nodes query diverse off-chain sources for raw data.

03

DONs Aggregate & Validate

Nodes in a DON process data and reach consensus on the correct value.

04

Aggregator Contract Stores

The validated data is submitted to an on-chain contract, which stores the aggregated value.

Key Takeaway

The Chainlink data flow ensures secure, reliable, and decentralized delivery of off-chain data to smart contracts.
