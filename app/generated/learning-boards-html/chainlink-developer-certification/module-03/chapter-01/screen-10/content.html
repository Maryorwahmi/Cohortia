Off-chain Reporting (OCR) Explained

Optimizing Data Delivery and Reducing Gas Costs

Off-Chain Consensus

Nodes in a DON reach agreement on data values off-chain before submitting.

Single Signed Report

Only one cryptographically signed report, containing aggregated data, is submitted on-chain.

Reduced Gas Costs

Dramatically cuts down on the number of on-chain transactions, making data feeds more efficient.

Smart Efficiency

OCR streamlines data submission, making Chainlink Data Feeds more scalable and cost-effective.

Example: Instead of 10 nodes each sending a transaction, OCR enables one transaction for the aggregated data.
Key Takeaway

OCR significantly reduces gas costs and improves scalability by moving data aggregation off-chain.
