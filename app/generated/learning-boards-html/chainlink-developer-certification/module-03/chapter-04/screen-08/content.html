Increasing Robustness with Multiple Data Feeds

Strategies for enhanced fault tolerance and reliability

Averaging Multiple Feeds

Fetch prices from two or more independent feeds for the same asset and take an average or median. This smooths out minor discrepancies.

Example: Query ETH/USD from Feed A and Feed B, then use the median price.

Fallback Mechanisms

Designate a primary feed and a secondary fallback feed, only querying the latter if the primary fails or returns stale data.

Example: Switch to a backup LINK/USD feed if the main one is unresponsive.
Key Takeaway

While adding complexity and gas cost, multiple feeds significantly enhance dApp resilience, especially for high-stakes applications.
