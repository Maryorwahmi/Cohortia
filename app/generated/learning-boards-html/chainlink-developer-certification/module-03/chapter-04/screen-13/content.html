Historical Data Retrieval with getRoundData()

Accessing past price data on-chain

Beyond Latest Price

While latestRoundData() gives current price, getRoundData(uint80 _roundId) allows retrieval of historical data for a specific round.

Function Signature

function getRoundData(uint80 _roundId) public view returns (uint80 roundId, int256 price, uint256 startedAt, uint256 updatedAt, uint80 answeredInRound)

Example Use

Verify the price at which a past transaction occurred, such as a loan liquidation or a collateral check.

Key Input

The _roundId parameter is crucial; it specifies which historical data point you want to retrieve. You need to know the specific round ID.

Key Takeaway

getRoundData() unlocks the ability to build dApps with auditing, analytics, and time-weighted average price capabilities.
