The Role of updatedAt

updatedAt is a timestamp indicating when the price was last recorded. It's your primary defense against using stale data.

Timestamp of Last Update

Records the exact time the price was written to the aggregator contract.

Defining Staleness

What's 'too old' depends on your dApp's risk profile and asset volatility.

STALE_DATA_THRESHOLD

A contract-defined maximum acceptable age for data, typically in seconds.

Staleness Check Logic
uint256 public constant STALE_DATA_THRESHOLD = 5 * 60; // 5 minutes

require(
    block.timestamp - updatedAt <= STALE_DATA_THRESHOLD,
    "Stale data: Price too old."
);

Explanation: This check ensures the time elapsed since the last update (`block.timestamp - updatedAt`) does not exceed your defined threshold. If it does, the transaction reverts, preventing the use of stale data.

Key Takeaway

Always implement a STALE_DATA_THRESHOLD check using updatedAt to prevent using outdated prices.
