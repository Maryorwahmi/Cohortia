Introducing RobustPriceConsumerV3

This enhanced contract adds critical checks to ensure data freshness and validity, building on the basic PriceConsumerV3.

Enhanced Security

Integrates `require` statements to validate data before use, preventing exploits.

Configurable Threshold

Uses a `STALE_DATA_THRESHOLD` constant for flexible data freshness requirements.

Defensive Programming

Adds sanity checks like `price > 0` for robust error handling.
