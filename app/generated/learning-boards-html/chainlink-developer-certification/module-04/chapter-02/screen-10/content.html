Receiving Randomness

Implementing fulfillRandomWords

The callback function that delivers and processes your cryptographically secure random numbers.

    /**
     * @dev Callback function called by the VRF Coordinator when the random words are fulfilled.
     * This function MUST be implemented by your contract.
     * @param requestId The ID of the request being fulfilled.
     * @param randomWords An array of the random words generated.
     */
    function fulfillRandomWords(
        uint256 requestId,
        uint256[] memory randomWords
    ) internal override {
        // Ensure this requestId was indeed from our contract
        require(s_requests[requestId] != address(0), "Request not found");

        s_randomWords = randomWords; // Store the random words
        delete s_requests[requestId]; // Clean up the request tracking
        emit RequestFulfilled(requestId, randomWords);

        // Here you would typically use the randomWords for your dApp's logic
        // For example, picking a lottery winner, assigning NFT traits, etc.
    }
Callback Mechanism

This function is invoked by the VRF Coordinator after random numbers are generated and verified off-chain.

Parameters Received

It receives the requestId (for tracking) and an array of randomWords (the actual random values).

dApp Logic Integration

Inside this function, you implement your dApp's logic, utilizing the received random numbers for outcomes like lottery winners or NFT traits.

Key Takeaway

fulfillRandomWords is where verifiable randomness becomes actionable, making it crucial for the integrity and functionality of your dApp's random outcomes.
