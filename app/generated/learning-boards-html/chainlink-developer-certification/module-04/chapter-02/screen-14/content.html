Chapter Review

Key Concepts

Essential terms and ideas from this chapter.

VRF Coordinator UI

The web interface for managing VRF v2 subscriptions, funding, and consumer contract authorization.

Subscription ID

A unique identifier for a VRF v2 subscription, acting as a shared LINK balance for multiple consumer contracts.

VRFConsumerBaseV2.sol

An abstract Solidity contract that consumer contracts must inherit from to interact with the VRF v2 Coordinator.

Summary Takeaway

Mastering the VRF Coordinator UI, understanding your Subscription ID, and inheriting from VRFConsumerBaseV2.sol are the foundational steps for integrating Chainlink VRF v2.
