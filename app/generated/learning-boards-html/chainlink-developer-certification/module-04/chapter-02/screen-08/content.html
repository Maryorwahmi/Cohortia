Initiating Randomness

Implementing requestRandomWords

How your dApp asks the Chainlink VRF Coordinator for random numbers.

    /**
     * @dev Requests a random word from Chainlink VRF.
     * @param _requester The address that initiated this request (for tracking).
     */
    function requestRandomWords(address _requester) public returns (uint256 requestId) {
        // Will revert if subscription is not funded or consumer is not added
        requestId = i_vrfCoordinator.requestRandomWords(
            i_keyHash,
            i_subscriptionId,
            3, // requestConfirmations: how many blocks to wait for confirmation
            CALLBACK_GAS_LIMIT,
            NUM_WORDS
        );
        s_requests[requestId] = _requester;
        s_lastRequestId = requestId;
        emit RequestSent(requestId, NUM_WORDS);
        return requestId;
    }
Function Purpose

This public function is called by your dApp to send a request for random numbers to the Chainlink VRF Coordinator.

Interaction Point

It interacts with the i_vrfCoordinator contract, passing all necessary parameters for the VRF request.

Returns Request ID

The function returns a unique requestId, which is crucial for tracking the asynchronous fulfillment of the request.

Key Takeaway

requestRandomWords is the trigger for verifiable randomness, but it's an asynchronous call that requires proper subscription setup and funding to succeed.
