Learning Objectives

By the end of this chapter, you will be able to:

LearnUnderstandApplyMaster
01

Configure VRF Subscription

Learn to set up and fund a Chainlink VRF v2 subscription using the Coordinator UI on a testnet. This ensures your dApp has the necessary LINK tokens to cover request costs.

VERIFIED COMPETENCY MILESTONE
02

Integrate VRFConsumerBaseV2

Integrate the `VRFConsumerBaseV2` contract into your custom Solidity smart contract. This provides the essential framework for VRF interaction.

VERIFIED COMPETENCY MILESTONE
03

Implement requestRandomWords

Implement the `requestRandomWords` function to initiate a VRF request with appropriate parameters. This is how your contract asks for randomness.

VERIFIED COMPETENCY MILESTONE
04

Manage CallbackGasLimit

Understand and manage gas considerations, specifically `callbackGasLimit`, for successful VRF fulfillment. This is critical to avoid failed transactions.
