Insecure On-Chain Randomness

Exploring the vulnerabilities of using block data for "random" numbers.

Why On-Chain Data Fails

  • Public Visibility: All blockchain data is transparent and accessible to everyone.
  • Predictability: Future block properties can often be estimated or influenced.
  • Deterministic Hashing: Hashing public data always yields the same result for the same inputs.
  • Pseudo-Randomness: Appears random but lacks true unpredictability and security.
Key Takeaway

Relying on on-chain data for randomness creates predictable outcomes, making dApps vulnerable to manipulation and exploitation.

Concrete Example

A lottery using block.timestamp can be exploited if a user simulates the outcome and only participates when it's favorable.
