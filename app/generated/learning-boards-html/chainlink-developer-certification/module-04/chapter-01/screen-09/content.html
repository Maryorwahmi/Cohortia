Process Flow

Fulfilling the Randomness Request

How the oracle delivers a verifiable random number.

1

Oracle Node Detects

Monitors for VRF request events on-chain.

  • Picks up request
  • Initiates off-chain work
Key Takeaway

The oracle generates a random number and cryptographic proof off-chain for delivery.

2

Generates Randomness + Proof

Off-chain, using a cryptographically secure algorithm.

  • True unpredictability
  • Mathematical verification
Verification is Key

The proof ensures the random number is unbiased and untampered.

3

Fulfillment Transaction

Oracle sends random number + proof back to your contract.

  • Calls fulfillRandomWords
  • Contract verifies proof
Asynchronous Pattern

This two-step process is necessary for off-chain computation.
