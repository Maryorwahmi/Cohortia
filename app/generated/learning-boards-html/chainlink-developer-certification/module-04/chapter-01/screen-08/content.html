Process Flow

Requesting Randomness

The first step: your smart contract asks for a random value.

1

Your Smart Contract

Calls the Chainlink VRF Coordinator contract.

  • Specifies keyHash
  • Includes subscriptionId
Key Takeaway

The request is an on-chain transaction that triggers an event for off-chain oracle monitoring.

2

VRF Coordinator Contract

Receives the request and emits an event.

  • Manages subscriptions
  • Monitored by oracles
Analogy

Like placing an order at a restaurant; the kitchen (oracle) picks it up.

3

Off-Chain Oracle Network

Monitors for VRF request events.

  • Detects request
  • Prepares for fulfillment
Important Note

Off-chain computation cannot directly return values in the same transaction.
