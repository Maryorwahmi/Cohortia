Miner Extractable Value (MEV) & Front-Running

How malicious actors can manipulate on-chain randomness.

Miner Extractable Value (MEV)

  • Miner Control: Miners can influence transaction order and block properties like block.timestamp.
  • Outcome Manipulation: They can calculate pseudo-random outcomes and 're-roll' blocks until favorable.
  • Compromised Fairness: Directly undermines the integrity of dApps relying on insecure randomness.
Key Takeaway

MEV and front-running transform pseudo-randomness into a predictable exploit, leading to unfair outcomes and loss of trust.

Front-Running & User Prediction

  • Mempool Observation: Users can see pending transactions and their potential outcomes.
  • Outcome Simulation: Local simulation allows prediction of 'random' numbers before transaction submission.
  • Strategic Submission: Users only send transactions if the predicted outcome is favorable, gaining an unfair advantage.
Common Misconception

Hashing many variables together does NOT make the outcome truly random if the inputs are predictable or manipulable.
