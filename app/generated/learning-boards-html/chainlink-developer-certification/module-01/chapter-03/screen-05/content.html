Decentralizing the Oracle Problem

How Chainlink ensures data reliability and tamper-resistance.

01

Request Data

A smart contract on a blockchain initiates a request for external data.

02

Multiple Nodes Respond

A Decentralized Oracle Network (DON) of independent Chainlink nodes receives the request.

03

Fetch & Aggregate

Each node fetches data from various off-chain sources, then their responses are aggregated and validated.

04

Submit Aggregated Result

A single, validated, and aggregated result is submitted back to the requesting smart contract on-chain.

Example Scenario

Imagine a DeFi lending protocol needing the ETH/USD price. Instead of one source, a Chainlink DON queries multiple exchanges, averages the prices, and delivers a robust, tamper-proof value.

Key Takeaway

Chainlink's decentralization and aggregation process ensures that smart contracts receive highly reliable and secure off-chain data, mitigating risks of manipulation or downtime.
