Data Providers & Smart Contract Consumers

The sources of truth and the users of Chainlink's services.

Data Providers

External sources of raw data, such as Bloomberg, AccuWeather, or CoinGecko APIs. Chainlink nodes query these providers.

Smart Contract Consumers

Smart contracts on various blockchains (e.g., Ethereum, Polygon) that request and utilize data from Chainlink DONs.

Example Scenario

A decentralized insurance contract might use a weather data provider via Chainlink to verify rainfall amounts for crop insurance claims, with the contract itself being the consumer.

Key Takeaway

The Chainlink ecosystem connects external data sources with on-chain smart contracts through a network of incentivized nodes, creating a complete data pipeline.
