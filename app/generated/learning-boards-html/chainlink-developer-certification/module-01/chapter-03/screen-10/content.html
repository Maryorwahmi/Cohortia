Chainlink Data Feeds in Action

Consuming real-time price data in Solidity.

Decentralized Price Oracles

Continuously updated price feeds aggregated from multiple Chainlink nodes and data providers, ensuring robustness.

Tamper-Resistant & Reliable

Reduces risk of single points of failure, data manipulation, or downtime, critical for DeFi applications.

Key Takeaway

Chainlink Data Feeds provide a secure and reliable way for smart contracts to access real-world price data, essential for building robust DeFi applications.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

import "@chainlink/contracts/src/v0.8/interfaces/AggregatorV3Interface.sol";

contract PriceConsumerV3 {
    AggregatorV3Interface internal priceFeed;

    // The address of the Price Feed contract on the specific network
    // For example, ETH/USD on Sepolia Testnet: 0x694AA176BF26fEaBcBC8767832Bdfd23cdbc402d
    constructor(address _priceFeedAddress) {
        priceFeed = AggregatorV3Interface(_priceFeedAddress);
    }

    function getLatestPrice() public view returns (int) {
        // latestRoundData returns (roundId, answer, startedAt, updatedAt, answeredInRound)
        (
            uint80 roundID,
            int price,
            uint startedAt,
            uint timeStamp,
            uint80 answeredInRound
        ) = priceFeed.latestRoundData();
        // Price is typically returned with 8 decimal places for ETH/USD
        return price;
    }
}
Code Insight

The AggregatorV3Interface is a standard Chainlink interface, simplifying how smart contracts consume aggregated data from Data Feeds.
