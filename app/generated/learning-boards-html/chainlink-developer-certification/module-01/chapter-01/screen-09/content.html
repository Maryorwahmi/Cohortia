Simple Smart Contract Walkthrough

Examining a basic Solidity contract for setting and retrieving a greeting.

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleGreeting {
    string public currentGreeting;

    constructor(string memory _initialGreeting) {
        currentGreeting = _initialGreeting;
    }

    function setGreeting(string memory _newGreeting) public {
        currentGreeting = _newGreeting;
    }

    function getGreeting() public view returns (string memory) {
        return currentGreeting;
    }
}

`currentGreeting` State

A public string variable that stores the current greeting, visible to all on the blockchain.

`setGreeting` Function

Allows any user to update the `currentGreeting` value, with the change recorded immutably.

Pro-Tip

The `view` keyword in `getGreeting` indicates that the function does not modify the blockchain state, making it a 'read-only' operation that costs no gas to execute.

Key Takeaway

This simple Solidity contract demonstrates how smart contracts store data and execute logic immutably on a decentralized network, forming the basis of dApps.
