Oracle Categories

Inbound, Outbound, and Computable Oracles

Specialized roles for diverse smart contract needs

Inbound Oracles

Bring data *from* the off-chain world *to* the blockchain. This is the most common use case, enabling smart contracts to react to external events.

Outbound Oracles

Allow smart contracts to send data or commands *to* the off-chain world. This enables real-world actions triggered by on-chain logic.

Computable Oracles

Perform off-chain computations based on smart contract requests, then return only the result. Ideal for complex, resource-intensive calculations.

Key Takeaway

These specialized oracle types expand the capabilities of smart contracts, allowing them to not only consume external data but also trigger real-world actions and perform complex off-chain computations efficiently.
