Module 4 › Chapter 4.1 › Create Multi-region Trail
Step-by-step
  1. Create or select an S3 bucket, enable encryption and versioning.
  2. Create an IAM role allowing CloudTrail to publish to CloudWatch Logs.
  3. Run the create-trail command with the multi-region flag and include global events.
  4. Enable log file validation and verify delivery to S3 and CloudWatch Logs.
CLI Example
aws cloudtrail create-trail \
  --name my-security-trail \
  --s3-bucket-name my-cloudtrail-log-bucket-12345 \
  --is-multi-region-trail \
  --include-global-service-events \
  --cloud-watch-logs-log-group-arn arn:aws:logs:us-east-1:123456789012:log-group:my-cloudtrail-log-group \
  --cloud-watch-logs-role-arn arn:aws:iam::123456789012:role/CloudTrailCloudWatchLogsRole \
  --enable-log-file-validation
Notes & verification
  • Verify S3 bucket policy grants cloudtrail.amazonaws.com PutObject and GetBucketAcl with the correct resource path.
  • Confirm CloudTrail status shows multi-region and log file validation enabled.
  • After test actions in multiple regions, search the centralized S3 prefix or CloudWatch Logs for the expected events.
Key Takeaway
A single multi-region trail simplifies audits by collecting events from every region and global services into one secured destination.
