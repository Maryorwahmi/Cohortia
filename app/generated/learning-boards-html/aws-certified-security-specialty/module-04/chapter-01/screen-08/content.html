Module 4 › Chapter 4.1 › Metric Filter
CLI example
Create a metric filter that looks for ConsoleLogin with a failed authentication error message and emits a metric value of 1 per match.
aws logs put-metric-filter \
  --log-group-name my-cloudtrail-log-group \
  --filter-name FailedConsoleLoginAttempts \
  --filter-pattern "{ ($.eventName = \"ConsoleLogin\") && ($.errorMessage = \"Failed authentication\") }" \
  --metric-transformations metricName=FailedLoginCount,metricNamespace=CloudTrailSecurity,metricValue=1
Notes & testing
  • Use exact JSON field names from CloudTrail events when writing the filter pattern.
  • After creating the filter, reproduce a failed login and check CloudWatch metrics in the CloudTrailSecurity namespace.
  • If the metric does not appear, inspect the raw log event to confirm the field and value you matched are present.
Key Takeaway
Always validate metric filters with a test event so you know the metric is produced before attaching alarms.
