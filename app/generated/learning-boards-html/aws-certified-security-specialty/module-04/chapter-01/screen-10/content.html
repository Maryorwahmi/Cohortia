Module 4 › Chapter 4.1 › Hands-on
Step checklist
  1. Create S3 bucket, enable SSE and versioning, and attach bucket policy for CloudTrail write access.
  2. Create CloudTrailCloudWatchLogsRole with the required managed policy.
  3. Create a multi-region trail and enable log file validation.
  4. Create CloudWatch Logs metric filters for your chosen events.
  5. Create CloudWatch Alarms and subscribe an SNS topic to deliver notifications.
  6. Test by producing a failing event and confirm notification delivery and log file presence in S3.
Example bucket policy snippet
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AWSCloudTrailWrite",
      "Effect": "Allow",
      "Principal": {"Service": "cloudtrail.amazonaws.com"},
      "Action": "s3:PutObject",
      "Resource": "arn:aws:s3:::yourname-cloudtrail-logs-12345/AWSLogs/your-account-id/*",
      "Condition": {"StringEquals": {"s3:x-amz-acl": "bucket-owner-full-control"}}
    }
  ]
}
Replace bucket name and account ID with your values. This snippet ensures CloudTrail can put objects with the required ACL.
