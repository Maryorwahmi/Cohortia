Module 4 › Chapter 4.1 › Secure S3
Policy essentials
  • Grant cloudtrail.amazonaws.com s3:PutObject on the AWSLogs prefix with condition s3:x-amz-acl = bucket-owner-full-control.
  • Limit read/list permissions to a small set of security principals or auditor roles.
  • Disable public access and block ACLs where possible.
Storage controls
Enable SSE-S3 or SSE-KMS and enable bucket versioning to allow recovery from deletions.
Integrity validation
Enable CloudTrail log file integrity validation. This produces a digest signed with an AWS-managed key and lets you demonstrate that delivered log files were not altered after delivery. Use this alongside S3 versioning and encryption to meet non-repudiation requirements.
Common mistake
Relying on ACLs or wide IAM read permissions makes logs easy to access but increases the attack surface for log tampering or accidental deletion.
Key Takeaway
Combine restrictive policies, encryption, versioning, and integrity validation to protect logs as forensic evidence.
