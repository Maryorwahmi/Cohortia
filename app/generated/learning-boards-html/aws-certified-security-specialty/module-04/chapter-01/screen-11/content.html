Module 4 › Chapter 4.1 › CloudTrail vs CloudWatch
CloudTrail (Audit)
  • Records API calls, request and response elements, and caller identity.
  • Delivers to S3 for archive and to CloudWatch Logs for monitoring.
  • Supports log file integrity validation for non-repudiation.
CloudWatch Logs (Monitoring)
  • Aggregates logs from many sources and supports metric filters and alarms.
  • Enables near real-time detection and notifications via SNS.
  • Charges for ingestion and retention — use retention policies to control costs.
Design guidance
Archive full event streams to S3 with encryption and versioning. Send a targeted subset to CloudWatch Logs for metric extraction and alarms. This split gives you durable evidence and operational detection without excessive cost.
