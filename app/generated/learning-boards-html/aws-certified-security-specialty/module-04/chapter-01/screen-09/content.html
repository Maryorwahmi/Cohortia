CLI Alarm Example
aws cloudwatch put-metric-alarm \
  --alarm-name HighFailedConsoleLoginAlarm \
  --metric-name FailedLoginCount \
  --namespace CloudTrailSecurity \
  --statistic Sum \
  --period 300 \
  --threshold 5 \
  --comparison-operator GreaterThanOrEqualToThreshold \
  --evaluation-periods 1 \
  --alarm-actions arn:aws:sns:us-east-1:123456789012:my-security-notifications-topic \
  --treat-missing-data notBreaching
This alarm triggers when the sum of FailedLoginCount in a 5-minute window reaches 5 or more and publishes to the SNS topic for notifications.
Design guidance
  • Choose an appropriate statistic (Sum, Average) based on the metric meaning.
  • Use evaluation periods to avoid flapping and tune thresholds to your environment.
  • Route alerts to an SNS topic that integrates with your incident response tools or team emails.
Pitfall
Creating many broad alarms causes alert fatigue. Prioritize high-confidence, high-impact alarms.
