Module 4 › Chapter 4.1 › CloudTrail Records
Event structure
  • Actor: identity of caller (user, role, or service).
  • Action: API call name and request parameters.
  • Context: source IP, user agent, and AWS region.
  • Outcome: response elements and error codes.
Example
DeleteBucketPolicy event shows caller ARN, bucket name, time stamp, and success/failure result — a direct record for investigation.
Why it matters
These fields let you reconstruct who did what and whether the action was allowed. They support compliance, troubleshooting, and attribution when incidents occur.
Key Takeaway
CloudTrail gives you the raw facts. Deliver and protect those facts to ensure they remain trustworthy for audits.
Common mistake
Enabling CloudTrail in a single region leaves you blind to events in other regions and to global service events unless explicitly included.
