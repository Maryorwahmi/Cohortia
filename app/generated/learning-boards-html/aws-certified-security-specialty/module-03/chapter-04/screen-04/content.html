Definition

What SSL/TLS protects

TLS ensures data confidentiality, integrity, and authentication between endpoints using symmetric encryption negotiated via asymmetric keys. It prevents passive eavesdropping and many active tampering attacks.

Concrete example: A browser opens HTTPS to a domain; TLS encrypts requests and responses so network sniffers see only ciphertext.
Common misconception: TLS termination at a load balancer equals insecure backend traffic — not necessarily; you can re-encrypt to backends for end-to-end protection.
Why it matters: Protects user credentials, session cookies, and API payloads from network attackers.
Deployment Patterns
ALB Termination
ALB handles TLS using an ACM certificate; backends receive decrypted traffic unless re-encryption is configured.
End-to-End Encryption
ALB terminates and then establishes TLS to backend targets, preserving encryption across the entire path.
Key Takeaway

Decide on termination by balancing performance and the requirement that backends never see plaintext.
