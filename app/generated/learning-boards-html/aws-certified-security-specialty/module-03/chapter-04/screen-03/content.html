Module 4 › Chapter 3.4 › Learning Objectives — Applied
Outcomes

From setup to secure architecture

We will validate both configuration correctness and architectural trade-offs. You will confirm domain validation, certificate issuance, ALB listener configuration, and secure DNS updates. You will also evaluate when to offload TLS versus when to preserve end-to-end encryption to meet compliance or privacy constraints.

Hands-on checkpoints include successful issuance of a public ACM certificate, attaching it to an ALB HTTPS listener, creating a redirect from HTTP to HTTPS, and testing the browser connection. For internal services, you will see the reasoning for using ACM Private CA to issue certificates trusted only inside your organization.

Assessment Focus
  • Correctly associate ACM certificates with AWS services.
  • Demonstrate VPN IPsec tunnel setup concepts and when to layer IPsec over Direct Connect.
  • Explain client-side encryption key responsibilities and recoverability risks.
