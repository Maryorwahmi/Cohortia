Module 4 › Chapter 3.4 › Client-side Encryption
Concept

Encrypt before you send

Client-side encryption means the client encrypts objects before upload, so intermediaries never see plaintext. Management of keys, rotation, and backups is your responsibility.

Example: Use the S3 Encryption Client to encrypt an object with a client-managed master key prior to upload.
Risk: Losing the master key leads to unrecoverable data.
Code example (illustrative)
// Pseudocode using an S3 encryption client
const envelopeKey = getClientMasterKey();
const encrypted = encryptWithKey(envelopeKey, plaintextData);
s3.putObject({ Bucket: 'my-bucket', Key: 'secret.txt', Body: encrypted });
This pseudocode shows the client encrypting data before calling the storage API. TLS still protects the upload channel; client-side encryption ensures AWS sees only ciphertext.
Key Takeaway

Client-side encryption gives strong source protection but carries key management responsibility — plan for rotation and backups.
