Module 4 › Chapter 3.4 › ACM → ALB Walkthrough
Checklist
  1. Request public certificate in ACM; include yourdomain.com and *.yourdomain.com if needed.
  2. Choose DNS validation and create Route 53 records automatically if possible.
  3. Wait for status to become Issued.
  4. Create ALB; add HTTPS listener on 443 and select ACM certificate.
  5. Configure target group, security groups, and optional HTTP->HTTPS redirect rule.
  6. Update DNS to point domain to ALB and test HTTPS in a browser.
Validation & Troubleshooting
DNS propagation delays can cause validation failures. Confirm the exact CNAME values and that TTL has elapsed.
Security groups: ensure ALB allows inbound on 80 and 443 and targets accept traffic from the ALB security group.
Key Takeaway

Follow the sequence and check DNS and security groups first when tests fail. Automate the process with infrastructure as code to avoid manual errors.
