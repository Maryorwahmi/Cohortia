Architecture

TLS termination with ALB and certificate association

Attach an issued ACM certificate to an ALB HTTPS listener to enable TLS for your domain. ALB handles TLS handshakes and can offload CPU from application servers.

Remember to configure security groups: ALB must allow inbound on 443 and target instances must accept traffic from the ALB security group.

Example workflow
Issue ACM cert → Create ALB → Add HTTPS listener port 443 → Choose certificate from ACM → Configure target group.
Pitfall
Public ACM certificates cannot be exported for use outside integrated services. Use ACM Private CA or an external CA for non-integrated servers.
Diagram (abstract)
Client ↔ ALB (ACM cert) — TLS
ALB ↔ Backend — HTTP or TLS depending on re-encryption
Key Takeaway

Using ACM with ALB simplifies TLS; decide whether backends should receive plaintext or TLS based on trust and compliance.
