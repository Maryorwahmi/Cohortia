Module 4 › Chapter 3.4 › Certificate Mistakes
Top mistakes
  • Expired certificates: causes outages; rely on ACM to auto-renew public certs.
  • Incorrect domain validation: DNS errors delay issuance; automate with Route 53.
  • Mixed content: HTTPS pages loading HTTP assets trigger browser warnings; serve all assets securely.
  • Weak cipher suites: configure modern TLS ciphers on ALB and servers.
Detection & mitigation
Monitor certificate expiration dates and set alerts. Use automated DNS validation to reduce human error. Use site scans to detect mixed content and fix asset URLs. Harden TLS settings on load balancers to prefer forward-secure ciphers.
Key Takeaway

Combine automation, monitoring, and secure defaults to reduce certificate-related outages and vulnerabilities.
