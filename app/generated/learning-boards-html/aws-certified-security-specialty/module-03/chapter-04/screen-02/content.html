Objective Details
Each objective includes a short lab or configuration walkthrough to practice provisioning certificates and validating HTTPS.
We will highlight common pitfalls like trying to export ACM public certificates and mixed content on secure pages.
Objective assessments will test both configuration steps and conceptual choices, such as when to use private vs public CAs.
