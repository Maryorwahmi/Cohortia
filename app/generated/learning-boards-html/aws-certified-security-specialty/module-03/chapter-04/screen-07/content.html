Module 4 › Chapter 3.4 › ACM Issuance Process
Step-by-step
1. Request a public certificate
Add domain names and optional wildcards.
2. Choose validation method
DNS (recommended) or email validation.
3. Add validation records
Let ACM create Route 53 records or add CNAMEs manually.
4. Wait for status 'Issued'
Attach certificate to AWS services when issued.
Practical tips

Use DNS validation and Route 53 automation to avoid manual DNS errors. Confirm TTL and propagation. If validation fails, check the exact CNAME values and ensure no conflicting records exist.

Example: ACM provides a CNAME for _abcde.yourdomain.com pointing to a CA validation target — create that exact record.
Key Takeaway

Automate validation through Route 53 when possible to speed issuance and reduce manual errors.
