Module 4 › Chapter 3.4 › ACM Service Integrations
Integrations
Elastic Load Balancing
Attach ACM certs to ALB listeners for HTTPS termination.
Amazon CloudFront
Use ACM public certificates for custom domains on distributions; region-specific constraints apply.
API Gateway
Associate ACM certificates with custom domain names to secure APIs with HTTPS.
Other services
Many AWS services like AppSync integrate with ACM for TLS on custom endpoints.
Practical note
Centralize certificate management with ACM to reduce configuration errors and benefit from automatic renewals. Validate service-specific requirements such as regional constraints for CloudFront certificates.
Key Takeaway

Integrating ACM with AWS services simplifies TLS deployment and lifecycle management across your stack.
