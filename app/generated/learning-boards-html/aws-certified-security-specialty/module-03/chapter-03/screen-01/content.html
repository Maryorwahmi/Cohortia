Encryption for Data at Rest
Understand S3 SSE options, EBS/RDS/DynamoDB encryption, and cross-region key considerations.

This chapter shows how AWS services encrypt stored data and how key ownership affects control and auditability. We'll compare the three S3 server-side encryption modes, cover enabling encryption for volumes and databases, and walk through replication and snapshot scenarios where key choice matters.

Practical focus: pick the right key type, ensure key policies allow required principals, and test access to avoid surprises such as AccessDenied when kms:Decrypt is missing.
