KMS Policies, IAM, Grants
Align KMS key policies with IAM and use grants for scoped permissions.
KMS key policy role
Primary controller for who can use and manage the key.
IAM relationship
IAM grants allow principals to call KMS APIs but are ineffective if the key policy blocks access.
Use grants
Grants are useful for temporary, auditable access without widely changing key policies.
Concrete example
Allowing S3 uploads with a CMK.
Add s3.amazonaws.com to the CMK key policy and grant the uploader role kms:GenerateDataKey. After configuration, upload an object and check CloudTrail for GenerateDataKey events to confirm the flow.
Pro Tip

When rotating keys or transferring ownership, use snapshot copy and re-encrypt; update key policies and create grants to prevent disruptions.
