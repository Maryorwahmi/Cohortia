Module 3 › Chapter 3.3 › EBS Encryption
EBS Encryption — Definition
Volumes, snapshots, and derived volumes follow encryption state governed by KMS keys.
Transparent encryption
Once enabled, encryption and decryption are handled for you; applications do not need modifications.
Snapshot inheritance
Snapshots of encrypted volumes remain encrypted. Copying allows re-encryption with a new key.
Key choice
Use account AWS managed key for simplicity or CMK for audit and finer access control.
Key Takeaway

To change encryption or key owner, copy snapshots and choose the new KMS key during the copy operation.

Scenario — migrating an unencrypted volume
You must convert to encryption without in-place toggles.
Steps: create a snapshot of the unencrypted volume, copy that snapshot and enable encryption during the copy step by selecting a CMK, then create a new encrypted volume from the encrypted snapshot and attach it to your instance.
Common Mistake

Trying to enable encryption on an existing unencrypted volume directly instead of using the snapshot-copy workflow.
