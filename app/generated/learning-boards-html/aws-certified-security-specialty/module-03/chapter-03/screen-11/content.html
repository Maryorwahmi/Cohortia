Configure bucket default SSE-KMS
Follow these steps and verify with an under-permissioned user.
1. Create CMK
Create a Customer Managed Key and add the uploader role and s3.amazonaws.com to the key policy with kms:GenerateDataKey and kms:Decrypt.
2. Set bucket default encryption
In bucket properties choose Server-side encryption with AWS KMS and select your CMK.
3. Upload & verify
Upload a file and check object Properties to confirm AWS-KMS and your CMK are listed.
Test: missing kms:Decrypt
Create an IAM user with s3:GetObject but without kms:Decrypt and attempt a download.
aws s3 cp s3://my-secure-data-bucket/testfile.txt ./downloaded_file.txt --profile unauthorized-user
Expected result

An AccessDenied error occurs because the user lacks kms:Decrypt on the CMK even though they have s3:GetObject.
