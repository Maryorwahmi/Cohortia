Learning Objectives
Part 1 — configuration and verification skills
Bloom: Learn → Understand → Apply → Master
01
Implement S3 SSE modes
Configure SSE-S3, SSE-KMS, or SSE-C depending on control and audit requirements. Practice setting bucket default encryption and headers when uploading objects.
VERIFIED COMPETENCY MILESTONE
02
Configure EBS encryption
Enable encryption when creating volumes, choose AWS or CMK, and understand how snapshots inherit encryption and can be re-encrypted during copy.
VERIFIED COMPETENCY MILESTONE
03
Enable RDS encryption
Create encrypted instances using KMS; plan snapshot copy/restore for existing unencrypted DBs because encryption cannot be toggled in place.
VERIFIED COMPETENCY MILESTONE
04
Manage DynamoDB keys
Choose between AWS owned, AWS managed, and Customer Managed Keys for tables according to compliance and audit needs.
VERIFIED COMPETENCY MILESTONE
Each milestone includes a configuration and a verification step to ensure encrypted data remains accessible to allowed principals and unreadable to unauthorized actors.
