Process Flow

Deploying a Web ACL safely

Follow a conservative sequence to avoid blocking legitimate traffic while gaining protection visibility.

1. Create Web ACL
Name it clearly and select the region matching your ALB.
2. Add Managed Rule Group (COUNT)
Add AWSManagedRulesCommonRuleSet and set action to COUNT to observe matches only.
3. Add Custom IP Set & Rule
Create BlockBadIPs and add a test IP. Create a rule to BLOCK that IP with higher priority.
4. Associate with ALB and Monitor
Check WAF metrics, ALB logs, and CloudWatch for COUNT matches and blocked events.
5. Validate and Enforce
Once validated, change safe managed rules to BLOCK and keep targeted IP blocks enabled.
Example Scenario
You add a test proxy IP to BlockBadIPs, attempt access from that proxy, and confirm the ALB returns a blocked response while legitimate users remain unaffected. Observe COUNT hits in the WAF metrics to tune rules.
Misconception Check
COUNT mode is not enforcement. It is a measurement tool—do not assume it blocks traffic until you set BLOCK.
