Hands-on Activity

Implement WAF Protection and Analyze VPC Flow Logs

Follow the checklist to protect an ALB-backed web app safely and verify behavior using flow logs and WAF metrics.

Checklist
  1. Enable VPC Flow Logs: Filter = All, Destination = CloudWatch Logs, create log group.
  2. Create Web ACL MyWebAppProtection, add AWSManagedRulesCommonRuleSet in COUNT mode.
  3. Create IP set BlockBadIPs with a controlled test IP and add a BLOCK rule.
  4. Associate Web ACL with ALB and monitor metrics/logs.
  5. Run test requests from the blocked IP and review flow logs and WAF COUNT hits.
Expected Outcome
The test IP is blocked by the IP-set rule; managed rule matches appear as COUNT hits. Flow logs show REJECT for blocked sessions and provide session metadata for follow-up.
Key Takeaway

The safe cycle is observe, tune, then enforce to avoid unintended outages while improving protection.
