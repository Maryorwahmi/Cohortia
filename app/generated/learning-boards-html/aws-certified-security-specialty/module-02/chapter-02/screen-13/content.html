Common mistakes and assessment scenarios

Learn the common pitfalls and how to reason through exam-style questions and real incidents.

Danger: BLOCK without COUNT
Switching to BLOCK prematurely can create denial-of-service for legitimate users.
Scope Errors in Firewall Manager
Overly broad selectors apply policies to unintended resources—use tags or account lists for precision.
Misreading Shield capabilities
Shield Standard is baseline; Advanced adds DRT access and cost protection—choose based on risk tolerance.
Assessment Tip
When questions ask for guaranteed uptime and DRT access during DDoS, the correct response is Shield Advanced. When central deployment is required across accounts, choose Firewall Manager.
Self-check

Explain how you'd validate a new managed rule group before switching it to BLOCK and which logs you would consult to confirm no false positives.
