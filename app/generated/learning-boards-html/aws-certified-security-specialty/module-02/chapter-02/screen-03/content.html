Lesson Roadmap

We'll move from comparison to hands-on configuration, then to logs, central policy, and detection scenarios.

Compare
WAF vs Shield Standard vs Shield Advanced.
Configure
Create a Web ACL, add managed rules and an IP block in COUNT mode.
Observe
Enable VPC Flow Logs and query traffic with CloudWatch Logs Insights.
Centralize
Use Firewall Manager to apply consistent WAF and firewall policies across accounts in an organization.
Detect
Use GuardDuty’s VPC and DNS analysis to generate prioritized findings and integrate with Security Hub or SIEM.
Key Takeaway

A predictable structure—compare, configure, observe, centralize, detect—helps build a repeatable security posture.
