Learning Objectives

A progressive set of skills from configuration to detection and centralized management.

Bloom: Learn → Understand → Apply → Master
01
Implement AWS WAF
Create and test Web ACLs with managed rules and an IP-set block. Practice COUNT mode before enforcing.
VERIFIED COMPETENCY MILESTONE
02
Choose Shield strategy
Compare Standard vs Advanced and select Advanced when DDoS cost protection and DRT access are required.
VERIFIED COMPETENCY MILESTONE
03
Centralize with Firewall Manager
Deploy consistent WAF, Shield, and firewall rules across accounts to reduce drift and errors.
VERIFIED COMPETENCY MILESTONE
04
Monitor and detect
Enable VPC Flow Logs, query traffic patterns, and use GuardDuty findings to prioritize incidents.
VERIFIED COMPETENCY MILESTONE
