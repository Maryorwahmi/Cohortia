Module 02 › Chapter 2.2 › GuardDuty Findings
Definition

Amazon GuardDuty: network-focused findings

GuardDuty uses ML and threat intelligence to analyze flow, DNS, and CloudTrail data and surface prioritized alerts for investigation.

Example Findings
PenTest:EC2/PortScan, Backdoor:EC2/C&CActivity—each points to network-level suspicious behavior.
Integration
Forward findings to Security Hub or a SIEM for central incident management and automated responses.
Investigation Pattern
Use GuardDuty to prioritize. For a PortScan finding, identify the instance, check flow logs for connection patterns, and inspect running processes and open sockets on the instance.
Key Takeaway

GuardDuty reduces triage time by surfacing notable network anomalies; treat findings as starting points for deeper log and host investigation.
