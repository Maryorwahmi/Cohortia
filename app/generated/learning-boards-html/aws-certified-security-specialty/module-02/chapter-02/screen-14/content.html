Key Concepts — Part 1

Three compact concept cards to remember core roles.

AWS WAF
Web application firewall that blocks common web exploits using rule groups.
AWS Shield
Shield Standard is baseline DDoS protection; Advanced adds visibility, cost protection, and DRT access.
Firewall Manager
Centralized service to deploy and enforce security policies across accounts and resources.
Summary

These services form the prevention and policy layer of a layered AWS network security posture.
