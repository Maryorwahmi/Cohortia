Definition

VPC Flow Logs: what they record and why they matter

Flow logs record session metadata for traffic to and from network interfaces, enabling security and compliance analysis.

Fields captured
Source/destination IP, ports, protocol, packets, bytes, start/end, action (ACCEPT/REJECT), interface IDs.
Destinations
Publish to CloudWatch Logs for quick queries or to S3 for longer-term storage and Athena analysis.
Limitations
Flow logs do not contain packet payloads; they provide metadata for session-level analysis only.
Example Investigation
If you see many REJECTed outbound connections from a private subnet to unknown IPs, follow up by identifying the instance, checking processes and open sockets, and correlating with GuardDuty findings.
Key Takeaway

VPC Flow Logs are essential for detecting suspicious session patterns; pair them with GuardDuty for prioritized alerts.

Common Mistake
Expecting payload data from flow logs. Use other tools for packet capture when payloads are required and authorized.
