Module 02 › Chapter 2.2 › Flow Logs & Queries
Process

Enable VPC Flow Logs and query with CloudWatch Logs Insights

Set the flow log filter to All, send to CloudWatch, verify role permissions, then query to find REJECTs or test-IP activity.

Steps
  1. Create flow log for the VPC with Filter = All, Destination = CloudWatch Logs.
  2. Create/choose an IAM role with publish permissions.
  3. Wait for streams, then use Logs Insights to query records.
Example CloudWatch Logs Insights Query
fields @timestamp, @message
| filter logStatus = "OK" and action = "REJECT"
| parse @message "* * * * * * * * * * * * * * * * * *" as version, account, interfaceid, srcaddr, dstaddr, srcport, dstport, protocol, packets, bytes, start, end, action, logstatus, vpc_id, subnet_id, instance_id, tcp_flags, type, pkts_src_to_dst, pkts_dst_to_src, bytes_src_to_dst, bytes_dst_to_src
| filter srcaddr = '1.1.1.1'
| sort @timestamp desc
Replace the test IP with your bad IP. The parse step maps fields from the raw flow log message for filtering.
Key Takeaway

Validate that streams appear in CloudWatch before relying on queries. Ensure IAM role and Filter settings are correct.
