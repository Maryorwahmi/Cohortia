Architecture

Putting it together: layered defense architecture

Each service fills a different role—use them together to cover application threats, DDoS, policy scale, visibility, and detection.

Application Layer: WAF
Network/Transport: Shield Standard/Advanced
Scale & Policy: Firewall Manager
Visibility: VPC Flow Logs
Detection: GuardDuty
Practical Scenario
Protect an ALB with a Web ACL, enable Shield Advanced for your critical endpoints, enforce policies via Firewall Manager, enable flow logs to CloudWatch, and monitor GuardDuty findings to trigger investigations.
Key Takeaway

A layered approach reduces single-point failures. Each service should be part of a coordinated security plan, not used in isolation.
