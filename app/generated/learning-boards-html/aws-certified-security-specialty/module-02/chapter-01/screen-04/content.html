Module 2 › Chapter 2.1 › What is a VPC?
Definition

Virtual Private Cloud

A logically isolated network in AWS where you control IP ranges, subnets, and routing.

Analogy
Treat the VPC like your private rack space in a cloud data center — you decide who can cross the perimeter.
Concrete example
Public subnet hosts a load balancer routed through an Internet Gateway; private subnet hosts databases with no default route to the Internet Gateway.
Common misconception
Resources in a VPC are not automatically private. A route to an Internet Gateway makes a subnet public.
Key Takeaway

Design subnets and routes deliberately: decide which workloads should be reachable from the internet and which should use private endpoints or NAT for outbound needs.

Topology Example
Public Subnet
Internet Gateway attached; used for load balancers.
Private Subnet
No IGW route; outbound via NAT or VPC Endpoint.
Gateway Endpoint
Routes S3 traffic privately via route table target.
