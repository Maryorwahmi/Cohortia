Module 2 › Chapter 2.1 › Security Groups vs NACLs
Security Groups

Stateful, instance-level

  • Define allowed inbound and outbound traffic; implicit deny otherwise.
  • Return traffic is allowed automatically because they are stateful.
  • Cannot explicitly deny traffic.
Use case
Restrict SSH, HTTPS, or inter-tier traffic to specific sources or security groups.
Network ACLs

Stateless, subnet-level

  • Process rules by number; stop at the first match.
  • Support explicit ALLOW and DENY rules.
  • Both inbound and outbound must be allowed for a connection to succeed.
Use case
Block malicious IP ranges at the subnet edge or enforce subnet-wide policies.
Quick decision guide
If you need per-instance control
Use Security Groups
If you need explicit denies
Use NACLs at the subnet boundary
Always remember
Combine both for layered security
