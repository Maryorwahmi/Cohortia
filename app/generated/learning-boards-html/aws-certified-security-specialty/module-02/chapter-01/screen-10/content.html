Module 2 › Chapter 2.1 › Gateway Endpoint & Route Table
What you configure

Create Gateway Endpoint and associate route tables

Select service: S3 (Gateway). Choose your VPC and pick the route tables used by private subnets. The route table receives an entry pointing S3 prefix list to the endpoint target.
Verification steps
  1. Confirm a new route exists for the S3 prefix list pointing to the endpoint.
  2. Launch an EC2 in the private subnet with outbound HTTPS allowed.
  3. From the instance, run a test like aws s3 ls to ensure access without IGW or NAT.
Command example
# From a private instance with proper IAM role:
aws s3 ls

# Expected: list of buckets if endpoint and permissions are correct
If the command fails, check the route table for the S3 prefix list entry, the endpoint association, and the instance's IAM role and Security Group egress rules.
Key Takeaway

A Gateway Endpoint adds a route table target for S3; verify with route table inspection and an in-subnet S3 API call.
