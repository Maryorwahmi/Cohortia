Internet Gateway (IGW)

Public ingress and egress

Attach to your VPC and add a route for 0.0.0.0/0 in public subnet route tables. Use for load balancers and public services.

Example
Public web servers receive traffic through IGW routes and public IP addresses.
NAT Gateway

Outbound-only internet access

Deployed in public subnets; private subnet route tables send outbound traffic to NAT so instances can access the internet without public IPs.

Operational note
NAT incurs hourly and data costs. Use VPC Endpoints for AWS service access where possible to avoid NAT charges and reduce exposure.
Key Takeaway

Choose IGW only for public-facing subnets and use NAT or endpoints for private subnet outbound needs to maintain isolation.
