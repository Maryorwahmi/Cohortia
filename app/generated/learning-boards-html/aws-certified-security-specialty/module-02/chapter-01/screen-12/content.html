Module 2 › Chapter 2.1 › DNS & Route 53 Resolver
Default behavior

VPC DNS resolver

AWS provides a default resolver for name lookups. Use it for typical service discovery and internal DNS names.

When to add Route 53 Resolver
If you need two-way DNS forwarding to on-premises or centralized DNS filtering, create Resolver Endpoints to forward queries.
Concrete example
Forward internal queries for legacy.example.local from the VPC to your on-premises DNS via a Route 53 Resolver endpoint so applications can resolve legacy hostnames.
Operational note
DNS changes require coordination with routing and firewall rules — resolution alone won't open traffic paths.
Key Takeaway

Use Route 53 Resolver Endpoints to centralize DNS policies and enable two-way resolution with on-premises networks while keeping network controls intact.
