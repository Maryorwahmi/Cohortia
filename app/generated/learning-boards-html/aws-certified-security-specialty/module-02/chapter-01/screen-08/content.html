Types

Gateway vs Interface

Gateway Endpoint
Used for S3 and DynamoDB; add as a route table target; no data plane charges for the endpoint itself.
Interface Endpoint (PrivateLink)
Creates an ENI in your subnet for private IP access to supported services; may incur charges.
Example
A private EC2 instance uploads logs to S3 via a Gateway Endpoint without touching the public internet.
Decision factors
  • Supported service: Gateway only for S3/DynamoDB.
  • Cost: Gateway endpoints are free; Interface endpoints may have hourly and data costs.
  • Network design: Interface endpoints create ENIs and can be placed in private subnets.
Key Takeaway

Use Gateway Endpoints for S3/DynamoDB to reduce internet exposure and NAT cost; use Interface Endpoints for other services when private connectivity is required.
