Learning Objectives

Progress from understanding to verified competency using Bloom-aligned milestones.

Learn → Understand → Apply → Master
01
Describe VPC building blocks
Label each component — subnets, IGW, route tables, endpoints — and explain their relationships.
VERIFIED COMPETENCY MILESTONE
02
Configure Security Groups
Implement least-privilege instance policies, e.g., SSH from a management IP only.
VERIFIED COMPETENCY MILESTONE
03
Design strict NACLs
Create ordered allow/deny rules and explicitly allow ephemeral outbound ports for return traffic.
VERIFIED COMPETENCY MILESTONE
04
Use VPC Endpoints
Add Gateway or Interface Endpoints so service traffic remains on the AWS network and avoids the internet.
VERIFIED COMPETENCY MILESTONE
