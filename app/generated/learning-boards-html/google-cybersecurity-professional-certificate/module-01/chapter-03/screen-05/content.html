Module 2 › Chapter 1.3 › Ethical vs Malicious
Ethical Hacking
Permission, scope, documentation, and remediation-focused reporting.
Example: Authorized penetration test on a web app, signed scope, result is a prioritized remediation report.
Process: request permission → define scope → run tests → document findings → hand off fixes.
Benefit: helps organizations find and fix vulnerabilities before they are exploited.
Malicious Hacking
No consent, harmful intent, and illegal activity leading to data loss or disruption.
Example: Unauthorised scanning and data exfiltration; attackers profit or damage systems.
Consequence: legal penalties, harm to users, and severe organizational damage.
Misconception: possessing offensive tools is not proof of wrongdoing; context and authorization matter.
