Definition
Malware: Types and Goals
Understand indicators and the appropriate response per type.
Virus
Attaches to files and spreads when files are shared.
Worm
Self-replicates across networks without user action.
Trojan
Masks as legitimate software to create a backdoor or install other tools.
Ransomware
Encrypts data and demands a ransom for decryption keys.
Spyware
Covertly collects information and sends it to an attacker.
Common Mistake
Relying only on signature-based antivirus misses novel or obfuscated malware; use layered detection and backups.
Concrete Scenario
An employee opens an attachment and files begin encrypting with a ransom note.
Immediate Response
Isolate the infected host, take backups offline, and start recovery procedures.
Prevention
Restrict execution policies, maintain up-to-date backups, and enforce least privilege.
Hunt & Detection
Look for unusual file changes, abnormal outbound connections, and sudden encryption events in logs.
Key Takeaway

Pair user awareness with layered controls and reliable backups to mitigate malware impact.
