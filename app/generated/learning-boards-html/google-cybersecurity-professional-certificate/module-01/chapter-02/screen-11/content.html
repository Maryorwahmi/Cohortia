Starter commands
Create users, directories, and set ownership and permissions.
# 1. Create users
sudo useradd -m dev_user
sudo useradd -m db_admin
sudo useradd -m sys_admin

# 2. Create directories (if they don't exist)
sudo mkdir -p /var/www/html
sudo mkdir -p /var/lib/mysql

# 3. Apply ownership and permissions (Least Privilege)
# Web app: only dev_user and sys_admin modify
sudo chown dev_user:dev_user /var/www/html
sudo chmod 750 /var/www/html

# Database: only db_admin and sys_admin modify
sudo chown db_admin:db_admin /var/lib/mysql
sudo chmod 750 /var/lib/mysql

# 4. Verify: switch accounts and test write access
Explanation
The chown commands set clear ownership. Permission 750 allows the owner full rights, group read/execute, and denies others. This enforces least privilege while allowing sys_admin to intervene when needed.
How this enforces separation
Different accounts own different resources, so no single developer can change the database files and no DBA can overwrite application code without additional privilege.
Common mistake
Avoid using 777 which grants write permissions to everyone and destroys least privilege protections.
