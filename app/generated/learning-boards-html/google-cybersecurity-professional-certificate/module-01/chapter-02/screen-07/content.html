What is defense-in-depth?
Layer multiple, diverse controls to increase detection and resilience.
Layering uses different control families: network, host, identity, and process controls.
Diversity matters: don’t stack identical controls that fail the same way.
Monitoring and logging let later controls detect breaches missed by earlier ones.
Analogy
A castle with multiple walls, moats and internal guards forces attackers to overcome several different defenses.
Layer examples
  • Perimeter firewall + internal segmentation
  • IDS/monitoring + EDR on endpoints
  • Encryption + strict access controls + user training
Pro tip

Select complementary controls across categories and ensure teams can detect and act when inner controls trigger alerts.
