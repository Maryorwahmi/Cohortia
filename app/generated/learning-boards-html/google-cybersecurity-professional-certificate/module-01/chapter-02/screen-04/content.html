Confidentiality explained
Encryption, access control, and authentication
Encryption protects data at rest and in transit; TLS secures web traffic and disk encryption secures files.
Access controls and MFA limit who can use keys or view decrypted data.
Weak passwords or exposed keys negate encryption benefits.
Concrete example
Store configuration files with strict ownership and encrypt backups. Enforce TLS for all external services.
Common mistake
Relying solely on encryption without protecting keys or user credentials.
Quick checks
  • Verify TLS is enforced for services that handle sensitive data.
  • Confirm secrets are stored with restricted owners and not world-readable.
  • Check that MFA is enabled for privileged accounts.
Key Takeaway

Encryption secures data but only when paired with strong access controls and credential protection.
