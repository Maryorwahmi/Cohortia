Comparison › Firewall Types
Packet-Filtering
Inspects headers only. Fast. Stateless.
Strengths
  • Speed and simplicity
Limitations
  • No connection context; can be bypassed by fragmented attacks
Stateful Inspection
Tracks active connections in a state table to allow legitimate responses.
Example
Internal user requests a webpage; the returning response is allowed because the session exists in the state table.
Application-Layer (NGFW)
Inspects application payloads to block malicious content and enforce protocol rules.
Capabilities
  • URL filtering, file-type blocking, payload inspection
  • Detects protocol-specific attacks such as injection patterns
Tradeoffs
  • Higher latency and complexity; careful tuning required
Concrete Example
Block SSH from the internet with a packet filter; allow HTTP but inspect traffic for malicious payloads with an NGFW.
Key Takeaway

Choose the firewall type that matches your need for speed, context, and content inspection, and avoid overly permissive rules.
