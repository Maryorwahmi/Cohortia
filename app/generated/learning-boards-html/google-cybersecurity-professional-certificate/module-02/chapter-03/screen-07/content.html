Definition › Virtual Private Networks
VPNs secure remote connections
Create encrypted tunnels so data cannot be easily read or tampered with on transit.
Common protocols
IPsec and SSL/TLS are typical protocols used to establish and secure VPN tunnels.
When to use
  • Remote user access over untrusted networks
  • Site-to-site links between branch offices
  • Administrative access to management networks
Misconception
A VPN secures the link but does not automatically protect the remote endpoint from malware or misconfiguration.
Scenario
A user on public Wi-Fi establishes an IPsec tunnel to the corporate gateway, then accesses internal file shares. The tunnel keeps the traffic encrypted from eavesdroppers.
Key Takeaway

Use VPNs to protect data in transit, and pair them with strong authentication and endpoint controls.
