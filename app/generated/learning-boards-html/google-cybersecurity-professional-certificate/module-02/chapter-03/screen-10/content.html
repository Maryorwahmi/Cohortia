Step-by-step UFW commands
Run these on a Linux VM where you have console access for recovery if needed.
sudo ufw enable
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow http
sudo ufw allow https
sudo ufw allow from YOUR_WORKSTATION_IP to any port 22
sudo ufw status verbose
Safety note
Confirm console access before adding restrictive SSH rules to avoid locking yourself out.
Test plan
From your allowed IP, verify SSH connects; from a different IP, confirm SSH is blocked; verify web pages are accessible from any browser.
Explanation of each command
  • Enable turns the firewall on.
  • Default deny incoming sets a secure baseline.
  • Allow rules open only required services and specific admin IPs.
Troubleshooting
If locked out, use the provider console, emergency access, or revert rules from a management interface.
