Process Flow › IDS & IPS
Intrusion Detection System (IDS)
Monitors traffic or system logs and alerts on suspicious patterns or anomalies.
  • Passive: does not block traffic.
  • Useful for historical analysis and forensic data.
  • Relies on signatures and anomaly models.
Example
Detecting multiple failed logins from one IP and creating an alert for analysts.
Intrusion Prevention System (IPS)
Inline device that can block, drop, or reset malicious traffic automatically.
  • Active: takes immediate action to stop attacks.
  • Placement inline introduces potential service risk.
  • Must be tuned to reduce false positives.
Key Takeaway
Use IDS for monitoring and investigation; place IPS inline where real-time blocking is required and you can manage risk.
