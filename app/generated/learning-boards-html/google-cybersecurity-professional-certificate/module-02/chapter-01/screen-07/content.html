ALE calculation
Translate expected loss into annual terms to compare against control costs.
# Definitions
SLE = Single Loss Expectancy (cost per incident)
ARO = Annualized Rate of Occurrence (events per year)
ALE = SLE * ARO

# Example
SLE = $50,000
ARO = 0.5  # once every two years
ALE = $50,000 * 0.5
ALE = $25,000
Tip: Document assumptions. If ARO is uncertain, use conservative and optimistic estimates to show a range of ALEs for decision makers.
When to use quantitative analysis
  • When you need to compare control cost to expected annual loss.
  • For high-value assets where investment decisions require monetary justification.
  • To model residual risk after mitigation controls are applied.
Common mistake

Waiting for exact numbers. Use reasonable estimates, then update ALE as monitoring yields better data.

Key Takeaway

Quantitative assessment connects risk to dollars. Use it when financial justification is required; otherwise, start qualitatively.
