Module 2 › Chapter 2.1 › Risk Register Activity
Scenario
Cloud-hosted customer database with unpatched OS and default admin passwords.
Register template
Asset: Customer Database
Threat: Malicious actors targeting e-commerce
Vulnerability: Unpatched OS / weak admin passwords
Example register entries
Risk 1
Unauthorized access due to unpatched OS. Likelihood: High. Impact: High. Treatment: Mitigation — patching, vulnerability scans. Owner: Ops. Review: 2 weeks.
Risk 2
Admin account compromise from default passwords. Likelihood: Medium. Impact: High. Treatment: Mitigation — rotate credentials, enforce MFA. Consider Transfer — insurance for residual financial exposure. Owner: IT Security.
Key Takeaway

Turn inventory into a documented register with owners, controls, and review dates. This makes risk management a repeatable process.
