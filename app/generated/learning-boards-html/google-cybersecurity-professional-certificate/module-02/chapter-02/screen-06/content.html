Module 2 › Chapter 2.2 › Device Comparison
Router

Forwards packets between distinct networks by IP. Use for subnet isolation and network ACLs; place it at perimeter points for broad network filtering.

Switch

Connects devices within a LAN using MAC addresses. Secure with VLANs and port-based controls to reduce ARP spoofing and unauthorized access.

Access Point

Provides wireless connectivity; requires strong encryption and monitoring to prevent rogue APs and session hijacking.

Modem

Bridges the local network to the ISP. Protect by ensuring management interfaces are not exposed publicly and by checking firmware updates.

Concrete scenario

An attacker plugs into an open switch port that lacks port security, obtains an IP address, and begins scanning other hosts. Solution: implement port security and network segmentation.

Common-mistake

Assuming devices provide more inspection than they do. Routers and switches forward by different attributes; choose controls accordingly.
