Module 2 › Chapter 2.2 › Sniffing vs Spoofing
Packet Sniffing

Passive capture of network traffic; effective when traffic is unencrypted. Defend by encrypting sensitive traffic and using secure Wi-Fi configurations.

Scenario
An attacker on a public Wi-Fi captures HTTP requests and reads credentials. HTTPS prevents this by encrypting payloads.
IP Spoofing

Falsifying source IP to impersonate a host or hide origin. Limit spoofing by using egress filtering and network path controls.

Investigator note
Look for mismatched ARP entries or source addresses that don't belong to the expected subnet as indicators of spoofing attempts.
