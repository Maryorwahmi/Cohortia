Terminal demo
Network information gathering
ip addr
Shows interfaces and assigned IP addresses. Use it to confirm which networks a host is connected to and to spot unexpected interfaces.
netstat -tuln
Lists listening TCP/UDP ports and associated addresses numerically. Useful to find unauthorized open services.
ping / traceroute
Test reachability and view the path packets take; traceroute helps locate network hops and possible routing anomalies.
nslookup
Query DNS to resolve names to IP addresses and spot suspicious DNS responses that could indicate spoofing.
Why practice
From output to decision

Interpreting command output is the bridge between detection and immediate response: isolate, collect, or block. Practice makes that decision faster and more accurate.
