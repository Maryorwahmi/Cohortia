Simplified layers

Focus on four layers to place security controls accurately and to reason about what an attacker can access when intercepting traffic.

Application (HTTP/HTTPS)
Controls: application firewalls, TLS encryption, input validation.
Transport (TCP/UDP)
Controls: port filtering, rate limiting, connection tracking.
Network (IP)
Controls: routing policies, ACLs, IP filtering.
Data Link (Frames, MAC)
Controls: VLANs, switch port security, MAC filtering.
Explanation cards
  • Application controls understand content and can block malicious inputs that network-layer controls cannot.
  • Transport-layer controls focus on ports and reliable delivery features used by applications.
  • Network-layer controls are fast and scalable but cannot validate application semantics.
Pro tip

Combine layer controls: use IP filtering to reduce attack surface and application inspection to stop malicious content.
