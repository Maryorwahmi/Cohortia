Module 2 › Chapter 2.2 › Key Concepts
Layered Model
Map controls to Application, Transport, Network and Data Link to know what each control can inspect or protect.
Devices & Roles
Routers route by IP, switches by MAC, access points handle wireless, and modems bridge to the ISP—each has security implications.
Protocols to know
TCP/IP for transport and addressing, DNS for name resolution, and HTTPS for encrypted web traffic.
Summary takeaway

Secure by layers: limit what each device can see, encrypt sensitive payloads, validate DNS and monitor traffic to detect flooding, sniffing or spoofing quickly.
