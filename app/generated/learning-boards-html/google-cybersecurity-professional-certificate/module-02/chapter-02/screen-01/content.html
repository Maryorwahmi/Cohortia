Network Security Fundamentals and Common Threats

Build a mental model of how networks move data, where security controls belong, and how attackers exploit weak points. We'll ground ideas with common protocols and a short terminal demo you can repeat.

Why this matters

Most defensive decisions—filtering, logging, encryption—depend on knowing where data travels and how attackers intercept or overwhelm those paths.

Concept map
Traffic, Devices, Protocols
Packets carry payload and headers used for routing and delivery.
Routers forward between networks; switches forward inside a LAN.
Threats exploit cleartext, weak filters, and misconfigured routing or DNS.
Quick start
Follow the layer

As you learn each device or protocol, ask: which layer does it live on, what data does it see, and what controls can block or detect misuse?
