DNS (Domain Name System)

Transforms domain names into IP addresses; a poisoned DNS response can redirect users to malicious servers.

Practical
Validate DNS responses with trusted resolvers, and monitor for unexpected IP changes for critical domains.
HTTP vs HTTPS

HTTP is unencrypted; HTTPS uses TLS to encrypt the entire application payload so eavesdroppers cannot read or alter content.

Example
If DNS is poisoned, HTTPS still protects content unless the attacker can present a valid certificate. Combined DNS validation and HTTPS is strongest.
