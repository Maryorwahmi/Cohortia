Module 2 › Chapter 2.2 › Firewalls
Definition

Packet filters, stateful inspection, and application controls

Firewalls enforce policies that allow or deny traffic. Use stateful rules to permit legitimate return traffic, and application inspection to understand payloads and block malicious content.

Example
Block public SSH at the perimeter, require VPN for administrative access, and apply host-based firewall rules inside the network to prevent lateral movement.
Practical tips
  • Follow least privilege: only allow the specific IPs and ports required.
  • Log denied traffic and review for indicators of scanning or DDoS attempts.
  • Use stateful inspection to avoid overly permissive reply rules.
Common mistake

Relying on a single perimeter firewall while leaving hosts with permissive local rules. Defense in depth is required.
