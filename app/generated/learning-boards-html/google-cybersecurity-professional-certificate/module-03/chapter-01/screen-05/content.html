Definition
File permissions & ownership
Understand the permission string, what each triad means, and how ownership affects access.
Permission string example: -rwxr-xr-- <— file type, owner, group, others
Octal example: 6 4 4 means owner read/write, group read, others read.
Misconception: execute permission on a directory allows traversal, not executing a file inside.
Commands and check
# inspect permissions and ownership
ls -l /etc/sensitive_config
# set owner-only read/write (recommended for sensitive files)
# sudo chmod 600 /etc/sensitive_config
# change owner to root if needed
# sudo chown root:root /etc/sensitive_config
# verify
ls -l /etc/sensitive_config
Key Takeaway

Use chmod to restrict permissions to the minimum needed, and use chown to set correct ownership.
