Hands-on Activity
Investigate suspicious_auth.log
Follow a safe sequence: copy, search, count, extract unique IPs, and then secure permissions.
Preserve: copy the original log to /tmp before analysis.
Search: find "Failed password" lines to focus on failed login attempts.
Secure: set permission so only owner can read/write when finished.
Terminal walkthrough
# copy the supplied file for analysis
cp suspicious_auth.log /tmp/suspicious_auth.log.copy
# find all failed password lines
grep "Failed password" /tmp/suspicious_auth.log.copy
# count how many times user1 failed
grep "Failed password" /tmp/suspicious_auth.log.copy | grep "user1" | wc -l
# list unique source IPs
grep "Failed password" /tmp/suspicious_auth.log.copy | awk '{print $11}' | sort | uniq
# restrict permissions to owner read/write
chmod 600 suspicious_auth.log
# verify
ls -l suspicious_auth.log
Key Takeaway

Always analyze a copy and secure the original with owner-only permissions to protect evidence.
