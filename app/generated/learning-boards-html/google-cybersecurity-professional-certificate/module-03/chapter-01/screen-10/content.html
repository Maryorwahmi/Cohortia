Common Mistakes
rm -rf and permissions errors
Understand the failure modes and adopt verification steps to avoid them.
rm -rf: dangerous when combined with incorrect path or root privileges; always preview with ls first.
World-writable files: allow any user to inject content; avoid 666 or 777 unless explicitly required in a controlled context.
Fixes and commands
# preview before delete
ls -l /path/to/target
# backup instead of deleting
cp -r /path/to/target /tmp/target-backup
# correct permissions for a sensitive file
sudo chmod 600 /etc/sensitive_config
# set ownership to root
sudo chown root:root /etc/sensitive_config
Reminder: document destructive steps and preserve originals when possible.
