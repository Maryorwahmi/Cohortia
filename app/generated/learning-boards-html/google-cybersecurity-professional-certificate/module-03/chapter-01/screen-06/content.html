Process Flow
ps aux and top
Capture a snapshot or monitor processes live to identify anomalies and resource abuse.
Snapshot: ps aux shows user, pid, %CPU, %MEM, and command; useful for searching unusual entries.
Live: top displays a dynamic, sorted list so you can observe spikes or resource changes.
Misconception: A familiar binary name does not guarantee safety; check its full path and owner.
Terminal examples
# static snapshot of all processes
ps aux | grep sshd
# live monitor sorted by CPU
top
# examine a suspicious pid for its command line and parent
ps -o pid,ppid,user,cmd -p 1234
Tip: note pid and parent before stopping
Pro tip: check binary path with ls -l /proc/<pid>/exe
