Learning Objectives
Build practical command-line skills used for investigation and system hardening.
Learn Understand Apply Master
01
Navigate the file system
Use pwd, cd, and ls to find files and verify timestamps. This helps you locate logs and binaries quickly during investigations.
Verified Competency Milestone
02
Inspect and set permissions
Read ls -l output and use chmod/chown to enforce least privilege for sensitive files and directories.
Verified Competency Milestone
03
Monitor processes & network
Use ps aux, top, and ss or netstat to identify unfamiliar processes and unexpected listening ports during triage.
Verified Competency Milestone
04
Analyze logs with text tools
Use cat, less, grep, and tail to extract failed login attempts and other indicators of compromise from log files.
Verified Competency Milestone
