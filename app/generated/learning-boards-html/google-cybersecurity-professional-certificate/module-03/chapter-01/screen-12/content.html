Core Concept
Least privilege & hardening
Only grant the permissions required for operation and document every hardening step.
Checklist: verify owner, assess group access, remove world-writable flags, and inspect setuid bits.
Operational caution: plan ownership and permission changes to avoid service disruption.
Commands to check and set
# show ownership and permissions
ls -l /etc/sensitive_config
# set owner and restrictive permissions
sudo chown root:root /etc/sensitive_config
sudo chmod 600 /etc/sensitive_config
Key practice: document the before/after state and reason for changes in your incident log.
