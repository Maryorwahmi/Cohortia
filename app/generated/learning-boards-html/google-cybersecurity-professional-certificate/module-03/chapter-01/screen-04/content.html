Core Concept
File system navigation
Commands to locate, inspect, and safely handle files during an investigation.
Key checks: Verify print working directory and use ls -l to inspect metadata before action.
Safer edits: Copy a file to /tmp before editing to preserve the original for evidence.
Common mistake: Running recursive remove without confirming path can delete critical system files.
Key Takeaway

Always verify location and create backups before modifying or deleting files.

Terminal examples
# show where you are
pwd
# move to system logs
cd /var/log
# list with details
ls -l
# create a scratch file and a backup
touch notes.txt
cp /etc/important.conf /tmp/important.conf.bak
# move or rename safely
mv /tmp/important.conf.bak ./backup-2023-01-01.conf
# never run recursive remove without checking the path
# rm -rf /path/to/target  <-- dangerous
Safety: preview with ls -l
Practice: use non-prod copies
