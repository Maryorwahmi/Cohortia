Filtering logs with pipes
Combine tail, grep, and other tools to extract indicators like failed authentication attempts.
Example: follow auth log and filter for failed password messages to detect an attack in real time.
Evidence: redirect filtered output to a file you preserve for later analysis and chain commands with pipes for speed.
Pitfall: Grepping large files without limiting scope can overload a terminal; use targeted patterns and time windows.
Terminal examples
# view entire file (small files only)
cat /var/log/auth.log
# page through a large file
less /var/log/auth.log
# search for failed password lines
grep "Failed password" /var/log/auth.log
# monitor new entries and filter in real-time
tail -f /var/log/auth.log | grep "Failed password"
Tip: save filtered output for evidence
Pro tip: use exact phrases to avoid false matches
