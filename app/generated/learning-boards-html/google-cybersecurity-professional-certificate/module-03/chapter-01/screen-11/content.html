Core Concept
Pipelines for analysis
Chain tools to filter, extract, and summarize log data into evidence you can act on and preserve.
Pattern: grep → awk → sort → uniq -c → sort -nr to count and rank values.
Evidence: redirect final output to a file and record the command used to generate it.
Misconception: compact pipelines are efficient but should be documented for reproducibility.
Example pipeline
# count failed login attempts per source IP
grep "Failed password" /tmp/suspicious_auth.log.copy | awk '{print $11}' | sort | uniq -c | sort -nr
# save the result for reporting
grep "Failed password" /tmp/suspicious_auth.log.copy | awk '{print $11}' | sort | uniq -c | sort -nr > /tmp/failed-ip-counts.txt
Tip: include the exact command in your incident note for reproducibility
