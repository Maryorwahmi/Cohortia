Module 4 › Chapter 4.2 › Essential pdb commands
Command cheatsheet
  • n — next: run current line and stop at the next line in this function.
  • s — step: execute and step into called functions.
  • c — continue: resume until a breakpoint or program end.
  • b — breakpoint: set a pause at a file:line or function.
  • p — print: evaluate an expression in the current scope.
  • l — list: show source around the current line.
  • w — where: show the stack trace for context.
Example terminal
(Pdb) n # next
(Pdb) s # step into
(Pdb) p variable # print value
(Pdb) b script.py:23 # set breakpoint
Use these commands in combination. For example, set a breakpoint at a suspicious function, continue to reach it, then step inside to inspect values line by line.
Key Takeaway

Master a few commands and you can inspect any runtime state. Remember the difference between next and step.
