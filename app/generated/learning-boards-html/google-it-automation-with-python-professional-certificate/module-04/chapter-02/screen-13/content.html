Common mistakes
  • Randomly changing many lines without a hypothesis.
  • Relying only on prints in complex code paths.
  • Not verifying external state like permissions or current directory.
Warning
Guessing fixes can introduce regressions. Always verify a hypothesis with a small test before wide changes.
Environment checklist
  • Confirm the working directory and the full paths you use.
  • Check file and directory permissions for the user running the script.
  • Verify network endpoints or services are reachable for networked scripts.
  • Ensure you are not accidentally operating on a directory rather than a file.
Pro tip

Add guard clauses and explicit checks so your automation fails fast with a clear message rather than performing dangerous operations silently.
