Tasks and verification

Small exercises that confirm each objective.
Practical checks
Print task
Add diagnostics before and after a transformation and run the script once. Confirm prints show expected values.
Milestone: you can demonstrate the failing value and the corrected value in output.
Debugger task
Insert a trace, step into a suspicious function, and print variables to confirm their state at runtime.
Milestone: you can show a step-by-step inspection that isolates the root cause.
Choice task
Describe when a print is sufficient versus when a debugger is needed, and apply the chosen method.
Milestone: written rationale plus proof of technique applied to a sample script.
Workflow task
Follow the reproduce-isolate-hypothesize-test-fix-verify steps on a given bug and report the fix and test evidence.
Milestone: successful test run after fix with no regression on a quick smoke test.
