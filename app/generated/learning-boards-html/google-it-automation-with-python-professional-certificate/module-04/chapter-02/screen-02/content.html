Learning Objectives

Practical, verifiable skills for debugging Python automation.
Bloom: Learn → Understand → Apply → Master
01
Use the print function strategically
Place prints to reveal values and program flow at critical checkpoints so you can confirm or disprove assumptions quickly.
Mnemonic: checkpoint prints
Verified Competency Milestone
02
Understand what a debugger does
Know that a debugger pauses execution, reveals stack context, and lets you evaluate expressions interactively without changing code permanently.
Mnemonic: pause, probe, proceed
Verified Competency Milestone
03
Operate pdb to step and inspect
Use set_trace to start, then use next, step, print, and list to navigate and inspect program state.
Mnemonic: n, s, p, l
Verified Competency Milestone
04
Apply a systematic debugging workflow
Reproduce, isolate, hypothesize, test, fix, and verify so fixes are reliable and testable in automation environments.
Mnemonic: R I H T F V
Verified Competency Milestone
