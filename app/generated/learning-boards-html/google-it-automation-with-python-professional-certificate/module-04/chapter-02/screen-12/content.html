import os

def rename_files_in_directory(directory_path):
    print(f"Attempting to rename files in: {directory_path}")
    if not os.path.isdir(directory_path):
        print(f"Error: Directory '{directory_path}' does not exist.")
        return

    for filename in os.listdir(directory_path):
        old_filepath = os.path.join(directory_path, filename)
        if os.path.isfile(old_filepath):
            new_filename = filename.lower().replace(" ", "_").replace("-", "_")
            new_filepath = os.path.join(directory_path, new_filename)
            os.rename(old_filepath, new_filepath)
            print(f"Renamed '{filename}' to '{new_filename}'")
        else:
            print(f"Skipping non-file: {filename}")
Debugging steps
  1. Insert a debugger trace inside the loop before os.rename.
  2. Print filename, old_filepath, new_filename, and new_filepath to inspect differences.
  3. Check isfile to avoid renaming directories.
  4. Only call rename if old_filepath != new_filepath.
This isolates both logic and environment problems: identical paths and directory entries. After fixing, rerun and confirm the final file list matches expectations.
Key Takeaway

Pause and inspect path values. Only perform filesystem changes once you're sure the source and destination differ and the entry is a file.
