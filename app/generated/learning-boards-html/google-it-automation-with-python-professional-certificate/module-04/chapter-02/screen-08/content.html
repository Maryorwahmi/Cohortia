How to start
You can run your script under the debugger or insert a trace call where you want execution to pause. The trace is often written as a small import and a call to start the interactive prompt at a known point.
Practical tip
Place the trace at the start of a suspected function to step through only the problematic section and avoid irrelevant output.
Terminal demo style
# Example: insert a trace
import pdb

pdb.set_trace()  # starts interactive debugging at this point
When the code reaches the trace, you'll see a prompt where you can use simple single-letter commands to navigate and inspect variables.
Key Takeaway

pdb provides pause, step, inspect, and continue — all from a terminal prompt so you can explore program state interactively.
