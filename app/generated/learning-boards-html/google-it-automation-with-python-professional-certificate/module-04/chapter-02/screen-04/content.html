Module 4 › Chapter 4.2 › What is debugging?
Definition

Debugging

An investigative process to identify, analyze, and remove errors from programs. It combines code inspection and environment checks to find root causes.

Analogy
Think of a bug like a broken step in a recipe; you test steps until you find the step that changes the outcome.
Common misconception
Not all bugs are syntax errors. Many are logical or environment-based, so purely fixing code without checking inputs and environment can miss the cause.
Practical steps
Reproduce the bug
Create a minimal run that reliably shows the incorrect behavior. This makes testing and iteration faster.
Isolate and hypothesize
Narrow to a function or loop, then guess the likely cause based on evidence.
Test and verify
Make a small change that tests your hypothesis, rerun, and confirm the fix. Add a test or assertion when possible.
Key Takeaway

Debugging is structured investigation: reproduce the issue, gather evidence, form a hypothesis, test, and verify a safe fix.
