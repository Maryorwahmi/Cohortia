Process

Strategic print placement

  • Print inputs at function entry to confirm what the function receives.
  • Print loop items to see iteration order and skipped values.
  • Print just before risky operations to show preconditions for an action.
  • Use concise tags like DEBUG: so you can search or filter logs easily.
Pro tip
If your script runs in production or cron, write debug output to logs with a flag rather than leaving prints that always run.
Example
def calculate_disk_usage(filesize_bytes):
    total_size = 0
    for size in filesize_bytes:
        print("DEBUG: Processing size:", size)
        total_size += size
    print("DEBUG: Total size before conversion:", total_size)
    return total_size / (1024 * 1024)
This shows how prints document both per-item state and an aggregate before conversion. If a non-integer appears, the debug prints reveal it immediately.
Key Takeaway

Prints are a first-line, low-friction way to observe values. Use them for quick checks and remove or gate them after use.
