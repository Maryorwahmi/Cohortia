Process Flow
Steps to capture a profile
  1. Run your script under the profiler to record execution statistics.
  2. Save the profiler's output to a file for later analysis.
  3. Load the saved data in a stats tool and sort by cumulative time for top contributors.
Saving a profile file lets you analyze, filter, and compare results without re-running expensive data generation repeatedly.
Visual: saved profile
File: profile_output.prof — open in a stats session to sort and inspect cumulative times and call relationships.
Why save files?
Profile files enable reproducible analysis and comparison across changes or environments, and let you share results with teammates for collaborative diagnosis.
