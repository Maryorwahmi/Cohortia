Process Flow
Terminal steps (visual)
1. Run the script under the debugger module so it starts paused or ready to accept breakpoints. 2. Set a breakpoint at the suspected line and add an expression that must be true for the breakpoint to trigger. 3. Continue execution and let the runtime stop when the condition happens. 4. Inspect locals and call stack, then modify variables if needed. 5. Clear breakpoints and re-run to confirm the fix.
Keep conditions explicit and avoid using undefined variables inside the condition. When in doubt, test the expression in a REPL with similar local values to ensure correctness.

Pro tip
If a condition rarely triggers during short runs, craft a test case with representative data to reproduce it reliably during development.
