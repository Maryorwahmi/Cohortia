def expensive_calculation(n):
 
    sum_val = 0
 
    for i in range(n):
 
        for j in range(n):
 
            sum_val += i * j
 
    return sum_val
This function's runtime grows roughly with the square of n, so increasing n by a factor of two increases work by about four times.
Profiling result (visual)
After running the profiler, expensive_calculation appears at top of cumulative time. That confirms it as the primary optimization target.
Optimization tip
Consider algorithmic approaches, vectorized operations, or reducing n before tuning inner loops for micro-optimizations.
