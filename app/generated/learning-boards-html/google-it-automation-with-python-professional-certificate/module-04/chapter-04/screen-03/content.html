Practice: Conditional Breakpoints
Run a looped script, set a condition that represents the bug state, and confirm the debugger pauses exactly when expected. This demonstrates precision in diagnosing rare issues.
Verification
Re-run the script and show that the breakpoint only triggers when the condition is met.
Practice: Profiling and Analysis
Run the profiler on a script with an intentionally expensive function, save the results, and load them in a stats viewer to inspect sorted cumulative time.
Verification
Show the top functions by cumulative time and identify the bottleneck for targeted optimization.
