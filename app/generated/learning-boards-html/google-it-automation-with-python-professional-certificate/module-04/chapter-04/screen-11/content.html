Module 5 › Chapter 4.4 › Profile the Report Generator
Hands-on Activity
Activity steps
  1. Run the report generator to observe baseline runtime.
  2. Run the profiler on the same workload and save results.
  3. Load the saved profile in a stats session and sort by cumulative time.
  4. Identify the function with the highest cumtime and propose a small change.
  5. Apply the change, re-run the profiler, and compare results.
Scenario details
The example script simulates per-record work including a small sleep and a heavy list comprehension for high-value records. Those operations are likely the bottleneck in cumulative time.
Reflection
After your change, did cumulative time drop for the same function? If not, re-check callers and callees to trace the real hotspot.
