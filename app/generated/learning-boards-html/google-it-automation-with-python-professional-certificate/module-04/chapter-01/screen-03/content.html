06
Skip bad lines while logging

When processing files, convert lines inside a try-except and report which lines were skipped, while still computing results from valid lines.

07
Avoid broad except without logging

Catching all exceptions silently makes debugging harder; log or re-raise unexpected exceptions so they can be diagnosed later.

08
Use finally for cleanup

Always release resources such as files or network connections in finally blocks so cleanup happens even when errors occur.
