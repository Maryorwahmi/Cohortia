Module 4 › Chapter 4.1 › SyntaxError
Definition

When Python can't parse your code

SyntaxErrors occur before execution. They point to malformed statements that don’t follow Python grammar rules.

Common causes
  • Missing colon after if/for/while/def
  • Unmatched parentheses, brackets, or braces
  • Incorrect indentation or stray characters
Misconception

The caret in the error output shows where parsing failed, but the real mistake may be earlier in the line. Check nearby tokens and prior lines when unsure.

Example — Interpreter output
if True
    print("This will cause a SyntaxError")

# Traceback shows file, line, and a caret pointing near the issue.
Fix strategy

Correct the missing colon and re-run to reveal any further issues.

Why it matters

Scripts won’t start until syntax is valid, so resolving these first lets you test runtime behavior.
