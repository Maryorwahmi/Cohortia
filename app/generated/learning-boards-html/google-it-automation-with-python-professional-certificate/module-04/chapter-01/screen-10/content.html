Code Walkthrough
# Try to parse input and divide
try:
    number = int(input_value)
    result = 10 / number
except ValueError:
    print("Invalid input. Enter an integer.")
except ZeroDivisionError:
    print("Cannot divide by zero.")
else:
    print("Operation successful.")
finally:
    print("Cleanup actions run always.")
Note: the else block runs only when no exception occurred; use it to keep success logic separate from error handling.
Bulleted Guidance
  • Catch specific errors first, then broader ones only if needed for logging.
  • Use finally for cleanup that must run regardless of success or failure.
  • Keep except blocks small and purposeful — print or log informative context.
Pro-tip: include the filename or variable value in logs to speed debugging when exceptions happen in automation.
