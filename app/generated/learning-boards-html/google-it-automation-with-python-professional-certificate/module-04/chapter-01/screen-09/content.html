Module 4 › Chapter 4.1 › FileNotFoundError
Practical handling

Detect missing files and decide fallback behavior

Decide whether the missing file is fatal or optional. Log the filename and context when it’s missing so maintainers can act.

Check for empty filename before opening. Use try-except to catch FileNotFoundError and provide a clear message or fallback.
Starter code snippet
with open("non_existent_file.txt", "r") as f:
    content = f.read()

# This raises FileNotFoundError if the file does not exist.
Action

Wrap file opens in try-except and log the filename when missing.

Why it matters

Automation should either recover from missing data or alert operators with precise context.
