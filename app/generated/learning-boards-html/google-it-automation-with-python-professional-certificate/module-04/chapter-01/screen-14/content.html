Module 4 › Chapter 4.1 › Key Concepts
SyntaxError

A parsing error that prevents the program from running until fixed.

Runtime Exception

An error raised during execution indicating an unexpected condition.

Traceback

The call stack report that shows where an exception occurred and the sequence of calls leading to it.

Summary

Use these terms to quickly diagnose issues: identify the error type, read the traceback bottom-up, and choose a targeted handling strategy.
