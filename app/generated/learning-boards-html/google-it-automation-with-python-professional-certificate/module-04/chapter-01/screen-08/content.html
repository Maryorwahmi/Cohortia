Module 4 › Chapter 4.1 › Index & Zero Division
IndexError

Sequence index out of range

Accessing an index beyond the sequence length triggers IndexError. Use length checks or safe iteration.

Fixes: iterate with for-in, use enumerate, validate index against len(sequence).
ZeroDivisionError

Division by zero

Attempting to divide by zero raises this error. Always check denominators before division.

Fixes: guard denominators, skip invalid records, or supply default behavior and log the choice.
Example

A list with three items has valid indexes 0–2. Index 3 raises IndexError.

Scenario

Computing average where the sample count is zero needs a guard to avoid ZeroDivisionError.

Takeaway

Defensive checks are essential in automation where input diversity is expected.
