Module 4 › Chapter 4.1 › NameError vs KeyError
NameError

Missing identifier in scope

Occurs when code references a variable or function that isn’t defined or imported. Often a typo or missing initialization.

Fixes: check spelling, confirm assignment/order of statements, ensure required imports are present.
KeyError

Missing key in a dictionary

Raised when a dictionary lookup uses a key that doesn't exist. Common when parsing data or reading configs.

Fixes: use dict.get with a default, check for the key with in, or validate input before lookup.
Example — NameError

Referencing an unassigned variable triggers NameError. Initialize variables before use.

Example — KeyError

Looking up a missing key in parsed JSON triggers KeyError; prefer safe access patterns.

Takeaway

Resolve NameError by fixing code, resolve KeyError by validating data or using defaults.
