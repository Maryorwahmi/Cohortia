Module 4 › Chapter 4.1 › TypeError vs ValueError
TypeError

Operation on an inappropriate type

Raised when an operation or function is not supported for the given object type.

Example: attempting to add a string and an integer. Convert types or adjust the operation.
ValueError

Correct type, unacceptable value

Raised when a function receives an argument of the right type but with an inappropriate value.

Example: converting the string "hello" to an integer. Validate input before conversion.
Fix pattern

Validate values early, convert types explicitly, and handle specific exceptions to give helpful feedback.

Pitfall

Catching broad exceptions hides whether an error is a type or a value issue. Log details when catching broadly.

Takeaway

Choose whether to sanitize inputs or enforce strict types based on who owns the data and expected invariants.
