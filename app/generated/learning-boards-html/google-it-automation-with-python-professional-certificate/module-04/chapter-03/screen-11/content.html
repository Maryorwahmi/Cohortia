Module 4 › Chapter 4.3 › Integrate logging
Step sequence
  1. Define the policy for levels and destinations.
  2. Configure logger, handlers, and formatters at script start.
  3. Replace prints with logger calls at appropriate levels.
  4. Log exceptions with traceback in except blocks.
  5. Set up rotating handlers for long running scripts.
Concrete example
At program start: configure the root logger and handlers. In each function, use a named logger with __name__ so you see module context in logs. When an exception occurs, log with exc_info to preserve stack trace.
Key Takeaway

Integrate logging early; it pays off when you need to investigate runs you were not watching live.
