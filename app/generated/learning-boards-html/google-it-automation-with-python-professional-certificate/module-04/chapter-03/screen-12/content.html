Module 4 › Chapter 4.3 › Activity
Starter checklist
  • Configure logging.basicConfig with FileHandler and StreamHandler.
  • Set root level to DEBUG and stream handler level to INFO.
  • Use a verbose file formatter including time, name, level, function, and line.
  • Log exceptions with exc_info enabled.
  • Run tests that trigger warning and error scenarios and inspect the file.
Verification steps
Run the script once with the normal environment and once forcing a missing file or invalid host. Confirm: console shows info and error messages; health_check.log contains debug lines and full tracebacks for exceptions.
Note

Do not place secrets in log messages. If a message contains sensitive data, redact before logging.
