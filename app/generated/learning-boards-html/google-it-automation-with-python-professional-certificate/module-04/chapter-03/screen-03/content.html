Module 4 › Chapter 4.3 › Practice & Application
Activity overview
Refactor the health check script to use logging. File logs capture debug; console logs show info and above. Include timestamps and tracebacks for exceptions.
Deliverable
A configured health_check.log containing debug and above, console output limited to info and above, and exceptions logged with traceback.
Verification
Run the script with an invalid file path or unreachable host and confirm error and traceback appear in the file and error appears on console.
Teaching tip
Start with basic configuration to get immediate value, then add more complex handlers like rotating files when needed. Use named loggers per module for targeted control.
