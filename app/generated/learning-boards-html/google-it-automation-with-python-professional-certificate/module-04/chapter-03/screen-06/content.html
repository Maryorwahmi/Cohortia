Module 4 › Chapter 4.3 › Logger, Handler, Formatter
Logger
Creates log records and exposes the level methods. Named loggers allow per-module configuration and easier filtering.
Handler
Routes records to destinations like console, files, or rotating files. Handlers can set their own level and filters.
Formatter
Defines the textual layout of a record using specifiers for time, name, level, function, line, and message.
Example configuration idea
# Send DEBUG to file with rich detail, INFO to console compact format
This lets you preserve full diagnostics while keeping operational console output readable. If you later add a remote handler you reuse the same formatter or design a new one for machine parsing.
Pro tip

Use named loggers per module so libraries and your application can be tuned independently.

Mistake

Attaching the same handler to multiple loggers without considering levels can duplicate output.
