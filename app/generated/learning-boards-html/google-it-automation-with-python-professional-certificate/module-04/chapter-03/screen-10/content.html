Module 4 › Chapter 4.3 › Common mistakes
Mistake vs Fix
No logging configured → Configure root logger and handlers explicitly
Using print → Replace with logger.debug or logger.info depending on severity
Too much debug in production → Use environments to set lower minimum in production
Unrotated large log files → Use RotatingFileHandler or TimedRotatingFileHandler
Catching exceptions without exc_info → Log with exc_info=True
Concrete scenario
A long running cron job filled disk because logs were never rotated. Solution: add a rotating file handler that keeps a fixed number of backups and prevents disk exhaustion while retaining recent history for investigation.
Check

Do you have a rotation strategy for any script that runs frequently? If not, add one before deployment.
