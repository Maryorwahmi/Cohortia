Module 4 › Chapter 4.3 › Logging exceptions
Why include tracebacks
Tracebacks show the call stack and exact lines that led to an exception. Without them you often only see the final message and must guess the cause.
Example usage
try:    ...except FileNotFoundError as e:    logger.error('Configuration missing', exc_info=True)
Common mistake
Catching broad exceptions without logging exc_info loses the traceback and makes it hard to find the root cause later.
Practical tip
Log context with the exception for clarity. For example mention which configuration file or host failed so the traceback is easier to interpret.
Key Takeaway

Always include exception tracebacks in error logs to enable reliable post mortem debugging of unattended scripts.
