Module 4 › Chapter 4.3 › Configure basic logging
Starter snippet
import logging import sys logging.basicConfig( level=logging.DEBUG, format='%(asctime)s - %(name)s - %(levelname)s - %(message)s', handlers=[logging.FileHandler('health_check.log'), logging.StreamHandler(sys.stdout)] ) # Set console to INFO only for operator view for handler in logging.root.handlers: if isinstance(handler, logging.StreamHandler): handler.setLevel(logging.INFO)
This pattern configures the root logger to capture debug but then raises the stream handler threshold to info so the file keeps everything while the console remains readable.
Why adjust handler levels
Handlers can filter records independently so you can route verbose messages to files and concise messages to operators. This avoids changing logging calls across the codebase.
Common mistake
Relying on basic configuration without checking handler levels can leave your console noisier than you expect or your file missing debug messages.
Key Takeaway

Set the root minimum to capture desired levels and tune handlers to direct the right information to each destination.
