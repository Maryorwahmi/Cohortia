Module 4 › Chapter 4.3 › Key Concepts
Structured Logging
Logs are persistent records with severity and context so you can investigate past runs.
Severity Levels
DEBUG, INFO, WARNING, ERROR, CRITICAL guide filtering and actionability of events.
Handlers & Format
Handlers route to file or console; formatters include timestamp, source and line so logs are traceable.
Final takeaway

Make the file your detailed archive, keep console concise, log exceptions with tracebacks, and rotate files for long running jobs.
