Module 4 › Chapter 4.3 › Formatting log messages
Common format specifiers
  • asctime: Human readable creation time of the record.
  • name: Logger name, usually the module name.
  • levelname: The textual logging level.
  • funcName and lineno: Where in the code the call was made.
  • message: The user supplied message.
Verbose file format example
%(asctime)s - %(name)s - %(levelname)s - %(funcName)s - Line %(lineno)d - %(message)s
Console compact format
%(asctime)s - %(levelname)s - %(message)s
Best practice

Balance information and readability. Keep sensitive data out of logs and prefer structured fields for parsing if needed later.
