02 Use logging levels
Apply DEBUG, INFO, WARNING, ERROR, CRITICAL appropriately to avoid noisy logs and surface real issues.
VERIFIED COMPETENCY MILESTONE
03 Format for context
Include timestamp, logger name, function, and line number so logs point to the code and time of the event.
VERIFIED COMPETENCY MILESTONE
04 Integrate into scripts
Make sure exceptions include tracebacks and that logs persist to files for post mortem analysis.

Mnemonic
