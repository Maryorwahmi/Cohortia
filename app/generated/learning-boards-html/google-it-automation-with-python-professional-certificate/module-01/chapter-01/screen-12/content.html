Module 1 › Chapter 1.1 › Booleans & Conditions
Examples
service_active = True
is_critical = False
# comparisons
is_large = ram_gb > 8  # evaluates to True or False
Store boolean results from comparisons so that downstream logic can act on them, for example to trigger alerts or start services.
Concrete scenario
Set service_active to True when a service is running. Later automation can check this flag to decide whether to restart or leave the service alone.
Misconception
Avoid using string values like 'True' as stand-ins for booleans. They are text and won’t behave correctly in logical tests.
