Module 1 › Chapter 1.1 › Variables & Naming
Definition & Rules
  • Create a variable with equals: server_name = "webserver01".
  • Use snake_case for readability: total_ram_mb.
  • Names must start with a letter or underscore; avoid starting with a number.
  • Don’t use Python keywords as variable names; they have reserved meaning.
Example
hostname = "prod-web-01"
cpu_cores = 8
ram_gb = 16.5
service_active = True
Misconception
Using short or ambiguous names may seem quicker but makes scripts fragile when shared. Descriptive names save time during debugging and code review.
