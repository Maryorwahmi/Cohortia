Code Walkthrough
# hello.py
print("Hello, Cohortia!")

# run in terminal
# $ python3 hello.py
# Output: Hello, Cohortia!
This small program shows that the interpreter executes the file and the print function writes to standard output. Use this method to inspect variables and confirm calculations while you build automation logic.
Example: debugging a value
count = 5
print(f"Current count: {count}")
# Output: Current count: 5
Print statements give immediate feedback. They are not a replacement for logging in production, but they are invaluable when learning or diagnosing scripts on a machine.
Check your understanding
If you edit a script but the console shows old output, you likely ran a different file or need to save changes. Confirm the file name and working directory before running.
