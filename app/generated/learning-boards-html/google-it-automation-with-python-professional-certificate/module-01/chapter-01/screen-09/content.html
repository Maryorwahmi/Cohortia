Conversion example
ram_gb = 16.5
# convert to MB
total_ram_mb = ram_gb * 1024  # 16896.0
The result is a float. If you need an integer number of megabytes, wrap the expression in an int conversion, understanding it truncates the decimal part.
Practical note
When reporting capacities, presenting a rounded value with formatting often improves readability for operators reading logs or dashboards.
Misconception
Floats are not exact for all decimals. For resource summaries this is usually acceptable, but do not rely on floats for precise financial or currency calculations without appropriate types.
