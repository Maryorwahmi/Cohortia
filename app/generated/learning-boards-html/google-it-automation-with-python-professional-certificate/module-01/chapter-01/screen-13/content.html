Common conversions
# convert types
num_str = "5"
num = int(num_str)     # 5
flt = float("3.14")   # 3.14
text = str(10)         # "10"

# avoid TypeError
message = "Users: " + str(5)
# or use f-strings
message = f"Users: {5}"
Convert inputs and computed values where necessary, and prefer formatted strings for clear output that avoids conversion noise.
Hands-on check
In the system_info script, multiply ram_gb by 1024 to get megabytes and embed the result in an f-string to print the summary without type errors.
Common mistake
Attempting to add a number to a string will raise TypeError. Fix it by converting or using a formatted string literal.
