Type Comparison
Integer (int)
Whole numbers for counts and IDs, e.g., 8.
Float (float)
Decimal numbers for measurements, e.g., 16.5.
String (str)
Text for names, addresses, and messages.
Boolean (bool)
True or False flags for conditions.
Example Mappings
  • cpu_cores → int
  • ram_gb → float
  • hostname, ip_address → str
  • service_active → bool
Warning

Mixing types in operations without conversion often raises TypeError. Convert explicitly to combine numbers and text safely.
