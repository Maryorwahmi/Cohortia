Module 1 › Chapter 1.1 › Install and Verify Python
Process Flow
  1. Download and install the latest Python 3 for your OS.
  2. On Windows enable Add to PATH during installation.
  3. Open a terminal and run python3 --version to verify.
  4. Create a file named hello.py with a print statement and run python3 hello.py.
Common mistake

If the terminal returns an error, either the PATH was not set or the system defaults to a different Python version; re-run the installer or use python3 explicitly.

Terminal Demo
$ python3 --version
Python 3.10.8

$ echo 'print("Hello, Cohortia!")' > hello.py
$ python3 hello.py
Hello, Cohortia!
This demonstrates both verification and script execution. Seeing the interpreter version and the printed output means your environment is set up properly for later automation tasks.
Why it matters

Automation scripts run on the interpreter. Confirming the correct interpreter avoids failures during deployment and ensures compatibility with language features like formatted string literals introduced in Python 3.6.
