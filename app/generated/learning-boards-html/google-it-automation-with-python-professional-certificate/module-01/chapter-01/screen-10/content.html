String examples
single = 'hello'
double = "world"
multiline = """line1
line2"""
escape = "First line\nSecond line"
concat = "Host: " + "prod-web-01"
Use escapes for special characters and be mindful when composing strings with other types.
Practical tip
Prefer formatted strings to concatenate text and values; they are clearer and reduce conversion mistakes.
Example
hostname = "prod-web-01"
print("Connecting to " + hostname)
# Better:
print(f"Connecting to {hostname}")
