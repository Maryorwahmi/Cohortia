Module 1 › Chapter 1.1 › F-Strings
Examples
hostname = "prod-web-01"
ip_address = "192.168.1.100"
print(f"User connected to {hostname} at {ip_address}")

# embed expressions
ram_gb = 16.5
total_ram_mb = ram_gb * 1024
print(f"RAM: {total_ram_mb} MB")
F-strings reduce boilerplate and make it harder to forget conversions when combining text and values.
Compatibility note
F-strings require Python 3.6 or newer. Verify your interpreter before using them to avoid syntax errors on older versions.
Practice
Rewrite concatenated messages using f-strings and observe how the code becomes clearer and less error-prone.
