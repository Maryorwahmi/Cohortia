Hands-on scenario

Create a file named system_info.py that defines variables for hostname, ip_address, cpu_cores, ram_gb, and service_active. Then compute total RAM in megabytes and print a formatted summary using a formatted string.

Starter Code
# system_info.py
hostname = "prod-web-01"
ip_address = "192.168.1.100"
cpu_cores = 8
ram_gb = 16.5
service_active = True

total_ram_mb = ram_gb * 1024
print(f"Host {hostname} ({ip_address}) — {cpu_cores} cores, {total_ram_mb} MB RAM, service active: {service_active}")
Teaching tips
  • Keep values typed correctly: integers for counts, floats for fractional RAM, strings for addresses.
  • Use clear variable names so logs are easy to scan in automation runs.
  • Convert before combining values to avoid runtime type errors.
Key Takeaway

A simple, typed data model and formatted output make automation scripts reliable and easy to read.
