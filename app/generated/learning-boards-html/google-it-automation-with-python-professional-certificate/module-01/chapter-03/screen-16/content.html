Module 2 › Chapter 1.3 › Final Reminders
Single Responsibility
One function, one job. This keeps code clear and testable.
Explicit Interface
Use parameters and return values instead of implicit global state.
Document & Test
Docstrings and small tests protect your refactors and help teammates.
Reflect: what single change could make your next script easier to understand and reuse? Try writing one docstring, one test, or one refactor and observe the difference.
