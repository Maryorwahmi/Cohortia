Module 2 › Chapter 1.3 › DRY & Refactoring
From Repetition to Functions
Turn repeated actions into one parameterized function.
Before: repeated blocks
If code to check app.log and server.log repeats with only filename changes, maintenance becomes error prone.
After: single function
Create check_and_print(filepath, label) to accept differences and centralize logic, logging, and error handling.
Key Takeaway

Refactor duplicates into focused, parameterized functions. This reduces bugs and simplifies updates.
