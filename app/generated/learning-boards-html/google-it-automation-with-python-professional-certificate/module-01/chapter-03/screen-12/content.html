Common Mistakes and Fixes
Recognize NameError, import mistakes, and hidden global side effects early to keep scripts reliable.
NameError: accessing a local variable. Fix: return the value and use it in the caller.
Missing import: ensure modules are imported before use to avoid runtime errors.
Global side effects: prefer explicit returns to mutate state predictably.
Practical habit
Write a small test that runs each function with typical and edge inputs. Tests quickly reveal scope and import issues and help you fix mistakes before deployment.
