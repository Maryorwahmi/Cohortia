Code Walkthrough
def calculate_disk_space_gb(total_mb, used_mb):
    """Calculates available disk space in GB."""
    available_mb = total_mb - used_mb
    available_gb = available_mb / 1024
    return available_gb

# Usage
# free_space = calculate_disk_space_gb(102400, 51200)
# print(f"Free disk space: {free_space:.2f} GB")
Notes: total_mb and used_mb are parameters. The function returns a numeric value so callers can format or test it.
Teaching Points
  • Parameters define the inputs your function expects; name them clearly.
  • Arguments are the actual values you pass when calling the function.
  • Use return to pass results back; avoid relying on side effects or globals.
Example scenario: calculate free space then alert if below threshold.
Misconception: Returning None means the function failed. None may be intentional; check the docstring.
Key Takeaway

Design functions to take inputs and return results for predictable composition and testing.
