Definition
Docstring: embedded documentation
Use triple quotes right after the function to describe its behavior and interface. This helps users and tooling understand expected use.
Start with a one-line summary, then list Args and Returns.
Tip: include types and any side effects so callers handle the function correctly.
Misconception: comments replace docstrings. Docstrings are discoverable via help tools; comments are not.
