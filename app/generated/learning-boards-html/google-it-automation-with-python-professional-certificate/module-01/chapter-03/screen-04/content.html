Module 2 › Chapter 1.3 › What is a Function?
Definition
Function: named, reusable block
Functions package logic so you avoid repeating code. They accept inputs and optionally return results. Use them to make intent explicit and behavior testable.
Analogy: A function is like a small machine that takes parts and returns an assembled piece.
Concrete example: A formatter that builds a timestamped log line.
Common mistake: Duplicating logic across scripts instead of parameterizing a single function.
Code Example (visual)
def greet_user(username):
    """Prints a personalized greeting message."""
    print(f"Hello, {username}! Welcome to the system.")

# Call the function
# greet_user("Alice")
# greet_user("Bob")
Example notes: username is a parameter; calling supplies an argument. This separates printing logic from the rest of your program.
Key Takeaway

Name small tasks with functions to make intent explicit and reuse trivial across scripts.
