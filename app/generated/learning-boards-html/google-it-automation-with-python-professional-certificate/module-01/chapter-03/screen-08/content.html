Module 2 › Chapter 1.3 › Modules & Import
Definition
Module: a .py file of related code
Import a module to access its definitions. Use module_name.function_name() for clarity and to avoid collisions.
Prefer import module_name to keep namespaces explicit.
If you only need one function, consider from module import name carefully.
Standard Library Examples
import os
import sys

current_directory = os.getcwd()
files = os.listdir('.')
print(f"Current working directory: {current_directory}")
print(f"Files: {files}")
print(f"Python version: {sys.version}")
Notes: os provides file and directory utilities; sys exposes interpreter information and command-line arguments.
