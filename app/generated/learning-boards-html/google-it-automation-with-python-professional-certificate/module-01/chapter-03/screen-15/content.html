Module 2 › Chapter 1.3 › Key Concepts
Function
A named, reusable block that performs one task and optionally returns a result.
Scope
Local variables live inside functions; prefer explicit passing and returning over globals.
Docstring
Document purpose, arguments, and return values so others can use your functions correctly.
Module
A file containing related functions; import it to reuse across scripts.
os & sys
Use os for file and path utilities and sys for interpreter information and command-line arguments.
DRY
Follow Don't Repeat Yourself by refactoring duplicates into parameterized functions.
Final thought: pick one repeated task in your scripts and refactor it into a function with a docstring and unit test to see immediate benefits.
