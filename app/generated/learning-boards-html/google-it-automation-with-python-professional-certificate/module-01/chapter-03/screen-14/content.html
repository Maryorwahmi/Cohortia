Module 2 › Chapter 1.3 › Project Structure
Main Script + Utility Modules
Keep orchestration separate from implementation to simplify reuse.
log_utils.py
Contains check_file_exists and read_log_content with docstrings and no side-effectful execution at import time.
main.py
Imports log_utils, sets log_file_name, and prints results. Keeps user interaction and orchestration here.
tests/
Small tests for functions that validate true and false cases and guard refactoring.
Key Takeaway

Organize code by responsibility: utility modules implement behavior; the main script orchestrates and handles user-facing concerns.
