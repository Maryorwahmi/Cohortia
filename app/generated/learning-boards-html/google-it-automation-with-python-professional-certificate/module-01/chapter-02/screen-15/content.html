Logical Operators
and, or, not — combine and negate Boolean tests to create complex conditions.
Loops
for iterates items; while repeats while a condition holds. Use counters and flags to ensure termination.
Break & Continue
break stops the loop; continue skips to the next iteration. Use them to optimize processing and handle special cases.
Final thought

Keep these definitions handy. Predict loop exits and branch behavior before running scripts to reduce surprises in automation.
