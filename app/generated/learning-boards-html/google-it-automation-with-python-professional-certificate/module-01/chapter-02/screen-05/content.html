Module 1 › Chapter 1.2 › If / Elif / Else
What it does
Branch execution into alternative blocks depending on Boolean tests. Use elif for multiple tests and else for a final fallback.
Common mistake
Mismatched indentation that changes which lines are inside the conditional, causing logic errors or syntax exceptions.
Example outcome
Service 'running' prints a healthy message; 'stopped' triggers restart logic; unknown states are logged by else.
Code walkthrough (visual)
# Conceptual snippet shown for reading
service_status = "running"
if service_status == "running":
    print("Service is healthy.")
elif service_status == "stopped":
    print("Service is stopped. Attempting restart...")
else:
    print("Unknown service status.")
Notice how each block is defined by indentation. Omitting the else leaves unknown states unhandled, which may hide issues in automation.
