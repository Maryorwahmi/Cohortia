Module 1 › Chapter 1.2 › For Loops
When to use
Use for loops to process every item in a collection, such as all partitions or all log files returned from a directory listing.
Range note
range(stop) generates numbers 0 through stop minus one. Use start, stop, step for more control.
Common mistake
Altering the list you iterate over can skip items. Instead, build a new list of results.
Example patterns
Iterate server names to run checks. Use range when you need a specific number of attempts, like five retries.
Iterate list
for server in servers: process server
Iterate count
for i in range(5): attempt operation five times
Key Takeaway

Choose direct iteration for collections and range for counted repetitions. Watch range boundaries to avoid off-by-one errors.
