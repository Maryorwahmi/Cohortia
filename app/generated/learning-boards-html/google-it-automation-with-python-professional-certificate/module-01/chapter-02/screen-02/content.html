Module 1 › Chapter 1.2 › Learning Objectives
01
Construct conditional statements
Use if, elif, else to run code based on tests and system state.
You will practice writing branches that handle service states and fall through to safe defaults when no condition matches. This skill prevents inappropriate actions during automation failures.
VERIFIED COMPETENCY MILESTONE
02
Utilize comparison operators
Apply equals, not-equals, and relational comparisons to form Boolean tests.
You will learn how comparisons return True or False and how that output drives decisions, for example checking whether disk usage is above a threshold before alerting.
VERIFIED COMPETENCY MILESTONE
03
Apply logical operators
Combine and negate tests with and, or, not for precise conditions.
You will compose conditions like checking both role and active status before granting access. We will also clarify operator precedence to avoid mistakes.
VERIFIED COMPETENCY MILESTONE
04
Implement for loops
Iterate lists, strings, and ranges to process items systematically.
You will iterate server lists, generate repeated attempts, and use range to count attempts. Practice avoids off-by-one errors with range sequences.
VERIFIED COMPETENCY MILESTONE
