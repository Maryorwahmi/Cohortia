Module 1 › Chapter 1.2 › Comparison Operators
Key operators
  • == equal to
  • != not equal to
  • <, >, <=, >= relational comparisons
Practical tip
Always ensure types match before comparing. Converting strings that represent numbers prevents surprising False outcomes.
Misconception
Confusing assignment and equality tests leads to logic errors. In conditionals, you must use the equality operator to compare values.
Concrete example
Check disk usage: if usage > threshold then alert; if usage == threshold then warn; else mark OK. This precise ordering handles boundary behavior cleanly.
Boundary check
Decide whether equal-to or greater-than triggers alert based on policy.
Type safety
Convert percent strings to numbers before comparing to avoid False results.
Key Takeaway

Choose the right comparison operator and handle equality boundaries deliberately to avoid off-by-one surprises in automation.
