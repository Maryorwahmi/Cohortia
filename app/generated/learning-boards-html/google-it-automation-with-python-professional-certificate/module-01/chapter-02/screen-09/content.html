Module 1 › Chapter 1.2 › While Loops
When to choose while
Use while when repetition depends on a condition that changes at runtime, like waiting for a network connection to succeed.
Safety guard
Include a counter or state change inside the loop and a max attempts limit to prevent infinite loops.
Logging tip
Log each attempt to aid debugging when loops fail to exit as expected.
Example pattern
Retrying a connection up to three times: attempt, check success, set flag or increment attempts. Break early on success, or report failure after max attempts.
Failure handling
After the max attempts, perform cleanup or escalate the error instead of looping forever.
Break usage
Use break to exit immediately when the success condition is met inside the while loop.
Key Takeaway

Plan how the loop condition will change. Add limits and logging so your while loops are both useful and safe in automation.
