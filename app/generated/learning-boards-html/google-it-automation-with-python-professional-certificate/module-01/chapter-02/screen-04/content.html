Module 1 › Chapter 1.2 › What is Control Flow?
Core idea
Control flow defines how a program chooses actions and repeats them. Branching handles alternatives; loops handle repetition.
Bullets
  • Conditionals execute blocks when a test is True.
  • Comparisons produce Boolean True/False values.
  • Logical operators combine tests for precise decisions.
  • Loops repeat actions until a condition changes or a limit is reached.
Key Takeaway

Control flow connects decisions and repetition to make automation responsive and efficient.

Example: Disk check scenario
Visual starter shows: a list of partitions iterated by a loop, each compared to a threshold, and a conditional that prints Alert, Warning, or OK based on the comparison result.
# Visual starter (conceptual)
partitions = [("C:", 75), ("D:", 90), ("/var", 82)]
for partition, usage in partitions:
    if usage > threshold:
        alert
    elif usage == threshold:
        warn
    else:
        ok
Misconception: indentation is optional — in Python, it determines the execution blocks, so keep it consistent to preserve control flow.
