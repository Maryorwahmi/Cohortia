Module 1 › Chapter 1.2 › Common Mistakes
Indentation
Consistent four-space indentation prevents IndentationError and ensures blocks belong together as intended.
Operator precedence
and binds tighter than or; use parentheses to make intent clear and avoid logic bugs.
Range boundaries
range(stop) goes to stop minus one. Check start and stop values to avoid off-by-one errors.
Infinite loops
Ensure while conditions can become False by updating state or using a counter with a max attempts limit.
Modifying iterables
Avoid changing a list you're iterating over; instead, build a new list of results to keep behavior predictable.
Nested break handling
Remember that break exits only the current loop; use flags or refactor when you need to stop multiple levels.
Key Takeaway

Adopt clear habits: consistent indentation, parentheses for complex logic, counters for while loops, and non-destructive iteration patterns.
