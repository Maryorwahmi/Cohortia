Module 5 › Chapter 5.1 › Inventory Example
Inventory snippet
[webservers] web1 ansible_host=your_managed_node_ip ansible_user=your_ssh_user [all:vars] ansible_python_interpreter=/usr/bin/python3
This pattern defines a webservers group with a host alias and global variables to ensure Python 3 is used on all hosts.
Explanation
  • Group: [webservers] groups related hosts for easy targeting.
  • Host alias: web1 is a label that maps to a real IP or hostname.
  • All:vars: sets global variables like the Python interpreter path.
Connectivity test
Run an Ansible ping module against the webservers group to confirm SSH connectivity and configuration.
