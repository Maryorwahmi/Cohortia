Components
Control node and managed nodes
  • Control node: where Ansible runs and where playbooks are executed.
  • Managed nodes: servers reached over SSH to apply tasks.
  • Inventory: lists and groups the managed nodes.
Practical note
As long as managed hosts have SSH and a Python interpreter, Ansible can run tasks without additional agents, which simplifies scaling.
Security tip
Control access to the control node and rely on SSH key management and host hardening to protect automation privileges.
