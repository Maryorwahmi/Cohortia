Module 5 › Chapter 5.1 › Key Concepts
Configuration Management
Maintain systems in a desired, consistent state across many machines.
Infrastructure as Code
Manage configuration via versioned, machine-readable files for review and rollback.
Idempotency
Design operations so multiple runs produce the same final state as a single run.
Summary
Combine the right tools with review, testing, and process discipline to make automation safe and reliable.
