Module 5 › Chapter 5.1 › Common Challenges
Configuration drift
Manual edits after automation causes divergence. Fix: enforce the automation and capture changes in playbooks.
Lack of testing
Skipping staging tests risks outages. Fix: validate playbooks in a safe environment before production runs.
Non-idempotent tasks
Commands that run unconditionally create side effects. Fix: use checks and idempotent modules to ensure repeatable results.
Process matters
Combine CM tools with version control, peer review, and testing to avoid human errors and make automation trustworthy.
