Module 5 › Chapter 5.1 › Ansible Workflow
1
Inventory
Define hosts and groups to target machines consistently.
2
Playbooks
Write YAML tasks that declare the desired state of a system.
3
Execute
Run playbooks from the control node; Ansible connects over SSH and applies tasks.
4
Verify
Check results and logs; successful idempotent runs may report no changes if systems already match the desired state.
