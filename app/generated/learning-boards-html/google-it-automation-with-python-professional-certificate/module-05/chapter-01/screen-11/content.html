Module 5 › Chapter 5.1 › Idempotency
Definition
Same result, many runs

Idempotency ensures running a task multiple times yields the same final state without producing unintended changes on subsequent runs.

Concrete example
Requesting that nginx be installed will either leave it installed or install it once, but will not reinstall it repeatedly.
Common pitfall
Avoid tasks that append blindly or run unconditional commands. Use checks and idempotent modules instead.
Key Takeaway

Idempotent tasks make frequent enforcement safe and predictable.
