Module 5 › Chapter 5.1 › Manual vs Automated
Manual administration
Characteristics
  • One-off SSH commands and manual edits per host.
  • High risk of configuration drift across many machines.
  • Slow to scale and harder to reproduce for recovery.
Pitfall
Manual fixes create divergence from your intended state unless they are captured back into automation.
Configuration management
Characteristics
  • Define desired state once and apply it to many hosts.
  • Reduces human error, supports faster deployments, and aids recovery.
  • Encourages testing and idempotent tasks for safety.
Key Takeaway

Use CM to make environment behavior predictable and recoverable at scale.
