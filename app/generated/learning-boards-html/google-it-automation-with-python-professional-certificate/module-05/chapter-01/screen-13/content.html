Module 5 › Chapter 5.1 › Hands-on Activity
Install Ansible
On Ubuntu/Debian: run sudo apt update then install the ansible package. On CentOS/RHEL: enable EPEL and install ansible. Verify with ansible --version to confirm the control node is ready.
Inventory file pattern
[webservers] web1 ansible_host=your_managed_node_ip ansible_user=your_ssh_user [all:vars] ansible_python_interpreter=/usr/bin/python3
Test connectivity
Run a ping module against the webservers group to confirm SSH and Python access. If it fails, check SSH keys, network rules, and the inventory entries.
Key Takeaway

A working control node and verified inventory are the foundation for safe automation.
