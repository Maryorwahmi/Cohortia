Module 5 › Chapter 5.3 › Best Practices
Practical rules
  • One responsibility per role.
  • Defaults for overridable settings, inventory for environment values.
  • Encrypt secrets with Ansible Vault, do not commit them in plaintext.
Testing and debugging
Run roles in a development inventory, verify idempotency by re-running, and use verbosity to inspect variable values and task decisions.
Common mistakes
Misplacing variables, not encrypting secrets, or forgetting to use notify with configuration changes are frequent issues. Fix them with small tests and clear conventions.
Key Takeaway

Adopt conventions for variable placement, protect secrets, and test roles before production use to ensure safe automation.
