Key Concepts — Part 1
Role
A self-contained directory structure for related tasks and files.
Variable
A named value used to parameterize playbooks and templates with clear precedence.
Jinja2 Templating
Templates embed variables and produce customized config files when rendered.
Summary
Use roles to organize, variables to configure, templates to render, and handlers to react efficiently. These patterns reduce duplication and keep automation predictable.
