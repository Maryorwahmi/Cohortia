Module 5 › Chapter 5.3 › Variable Precedence
Quick precedence guide
  1. Extra vars (highest)
  2. Play vars
  3. Host vars / inventory
  4. Role vars
  5. defaults/main.yml (lowest)
Example
If defaults set nginx_port to 80, and inventory sets it to 8080, the inventory value applies.
Debugging tip
Use ansible-playbook with increased verbosity to see which variable values are applied, and check group_vars, host_vars, and extra-vars when values conflict.
Common mistake
Assuming defaults are immutable. Defaults are intentionally overrideable; place environment-specific values higher in precedence.
Key Takeaway

Place values where the intended override behavior is clear, and document conventions for your team.
