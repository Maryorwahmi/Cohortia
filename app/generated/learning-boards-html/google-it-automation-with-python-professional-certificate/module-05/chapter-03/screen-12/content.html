Handler pattern
# task that changes config
- name: Configure Nginx default site
  ansible.builtin.template:
    src: default.conf.j2
    dest: /etc/nginx/sites-available/default
  notify: restart nginx

# roles/nginx/handlers/main.yml
- name: restart nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
Why handlers matter
They prevent unnecessary or repeated service restarts by running once at the end of the play only if a notifying task reported a change.
Misconception
Handlers do not run immediately after notify. They are queued and run at the end, ensuring consolidated actions.
Try this

Make a harmless change in the template, run the playbook, and observe that the handler runs once at the end only when the template changed.
