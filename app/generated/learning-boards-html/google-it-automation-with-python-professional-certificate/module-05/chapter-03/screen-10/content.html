Template example
server {
    listen {{ nginx_port }};
    server_name {{ inventory_hostname }};

    root {{ nginx_root_dir }};
    index index.html index.htm;

    location / {
        try_files $uri $uri/ =404;
    }
}
This template uses variables for port and root and a built-in variable for server name, producing a host-specific server block.
Rendering with template module
When Ansible runs the template module, it replaces placeholders with variable values and copies the rendered file to the destination on the managed host.
Misconception
Templates do not execute code on the managed host. Rendering happens on the control node and produces a plain text file transferred to the host.
Key Takeaway

Keep template logic minimal and test rendered output to ensure variables substitute as expected.
