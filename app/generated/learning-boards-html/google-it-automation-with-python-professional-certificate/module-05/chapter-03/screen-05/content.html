Module 5 › Chapter 5.3 › Role Structure
Role folder purpose
tasks/
Sequence of steps to configure the component. This is the role's core logic.
handlers/
Tasks that run when notified, typically to restart or reload services.
templates/
Jinja2 templates rendered per host, used with the template module to create config files.
vars/ and defaults/
defaults/ holds low-priority defaults; vars/ holds higher-priority role variables. Prefer defaults for user-overridable settings.
Practical example
# roles/nginx/defaults/main.yml
nginx_port: 80
nginx_root_dir: /var/www/html

# roles/nginx/vars/main.yml
# Use vars for values you don't expect to override often
Misconception
Putting secrets directly in vars/main.yml is risky. Instead, use Ansible Vault to encrypt sensitive variable files before committing.
Why it matters

A predictable role layout speeds onboarding and debugging, and supports environment-specific overrides without changing role internals.
