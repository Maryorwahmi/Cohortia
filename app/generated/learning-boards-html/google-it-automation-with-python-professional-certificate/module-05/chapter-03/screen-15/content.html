Key Concepts — Part 2
Template Module
Renders templates locally and copies only when the rendered file differs from the remote file.
Handler
Triggered by notify, handlers run at the end of the play and execute once to perform reactions like restarts.
Variable Precedence
When the same variable exists in multiple places, Ansible applies a strict order to choose the effective value.
Final reminder
Design roles clearly, mark where variables should be set, render templates carefully, and use handlers to keep services synchronized only when changes occur.
