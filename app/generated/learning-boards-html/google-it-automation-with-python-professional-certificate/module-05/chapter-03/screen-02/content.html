Learning Objectives
Progress from understanding roles to applying templates and handlers.
Learn → Understand → Apply → Master
01
Organize code with Roles
Create a standardized directory with tasks, handlers, templates, and vars so related logic is collocated and reusable. This reduces duplication and makes sharing roles across projects straightforward.
Mnemonic: Think of a role as a self-contained micro-playbook.
VERIFIED COMPETENCY MILESTONE
02
Define and scope Variables
Use variables to parameterize ports, paths, and versions. Choose defaults for general settings and place environment-specific values in inventory or higher-precedence locations.
Mnemonic: Defaults then override.
VERIFIED COMPETENCY MILESTONE
03
Implement Jinja2 Templates
Author templates with placeholders for variables. Render them with the template module so each host gets a tailored configuration file.
Mnemonic: Variables in, rendered file out.
VERIFIED COMPETENCY MILESTONE
04
Use Handlers for efficiency
Notify handlers from tasks that change configuration so services restart only when necessary. Handlers run at the end of a play and are idempotent by design.
Mnemonic: Notify, then act once.
VERIFIED COMPETENCY MILESTONE
