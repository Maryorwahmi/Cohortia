Template module steps
1. Render
Jinja2 template is rendered locally using variables.
2. Compare
Ansible checks whether the rendered file differs from the remote file.
3. Copy
If different, the file is copied and change is reported, potentially notifying handlers.
Because Ansible compares before copying, templates are idempotent and only cause changes when content truly differs. This behavior is what lets notify and handlers prevent unnecessary restarts.
Practical check
Change nginx_port in defaults to 8080, run the playbook, and watch whether the template task reports a change and whether the handler restarts the service once.
Key Takeaway

Template module renders then applies only if needed, enabling efficient, idempotent configuration management.
