What is a Role?
A role is a directory with a fixed layout that holds tasks, handlers, templates, variables, and defaults for a specific responsibility.
Why use roles
  • Collocates all files for a component for clarity and reuse.
  • Makes playbooks shorter and easier to read.
  • Enables sharing roles across projects or teams.
Common misconception
Some think roles add unnecessary layers. In practice roles reduce duplication and make maintenance safer as projects grow.
Key Takeaway

Adopt one responsibility per role. Roles are the primary unit of reuse and clarity in Ansible projects.

Role directory example
roles/
└── nginx/
    ├── tasks/
    │   └── main.yml
    ├── handlers/
    │   └── main.yml
    ├── templates/
    │   └── nginx.conf.j2
    ├── vars/
    │   └── main.yml
    └── defaults/
        └── main.yml
Concrete example
Refactor a flat playbook so that installing Nginx and deploying site files move into roles/nginx/tasks/main.yml. The main playbook then lists the role name only.
