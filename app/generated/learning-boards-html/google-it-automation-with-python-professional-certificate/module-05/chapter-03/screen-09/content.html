Module 5 › Chapter 5.3 › Variables in Tasks
Task example
- name: Ensure Nginx listens on specified port
  ansible.builtin.lineinfile:
    path: /etc/nginx/sites-available/default
    regexp: 'listen {{ nginx_port }};'
    line: '    listen {{ nginx_port }};'
    state: present
  notify: restart nginx
This task uses the nginx_port variable and notifies a handler when it changes the file. The handler then restarts the service once per play if needed.
Handler example
- name: restart nginx
  ansible.builtin.service:
    name: nginx
    state: restarted
Common mistake
Forgetting to add notify means the service will not restart automatically after config changes, which can leave servers running stale configurations.
Key Takeaway

Always pair tasks that change configuration with notify to trigger handlers and keep services in sync.
