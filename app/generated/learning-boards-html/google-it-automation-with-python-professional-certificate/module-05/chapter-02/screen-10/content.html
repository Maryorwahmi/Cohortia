Module 5 › Chapter 5.2 › Run & interpret
Typical command
ansible-playbook -i inventory.ini install_nginx.yml
Watch each host and each task for statuses that tell you whether the desired state was already present or required a change. Use verbosity flags to get more detail if needed.
Output semantics
ok: desired state matched. changed: Ansible altered the remote state. failed: task could not complete—investigate permissions, paths, or module usage.
Verify deployment
After a successful run, open the managed host IP in a browser to confirm the custom index page was deployed and the Nginx service is running.
Troubleshooting
If a task fails, test it in isolation, inspect the managed node logs, and re-run the playbook after fixing the root cause. Incremental testing saves time.
