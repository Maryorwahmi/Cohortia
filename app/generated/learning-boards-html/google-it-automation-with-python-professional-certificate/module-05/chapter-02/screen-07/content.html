    - name: Ensure Nginx service is running and enabled
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: yes

    - name: Copy a custom index.html file
      ansible.builtin.copy:
        src: files/index.html
        dest: /var/www/html/index.html
        owner: www-data
        group: www-data
        mode: '0644'
Concrete example
Place index.html in a files directory next to the playbook, then run the playbook to deploy that page to all hosts in webservers.
Why update cache first?
Refreshing the apt cache reduces package resolution errors and ensures the control node installs the latest available package metadata during the same run.
Pro tip
Run small playbook fragments first. If a copy task fails, file ownership or the destination path is often the issue—check permissions on the target directory.
