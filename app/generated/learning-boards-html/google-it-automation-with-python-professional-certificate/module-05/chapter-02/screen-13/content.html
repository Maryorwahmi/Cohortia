Module 5 › Chapter 5.2 › Assessment: ok vs changed
Question
If a service is already stopped and you run a task to stop it, what will Ansible report and why?
Correct answer
ok, because the desired state already exists and idempotent modules avoid unnecessary changes.
Fixing permission errors
If installs fail due to permissions, add become: true and configure passwordless sudo for the ansible_user on the managed node, then re-run the playbook.
