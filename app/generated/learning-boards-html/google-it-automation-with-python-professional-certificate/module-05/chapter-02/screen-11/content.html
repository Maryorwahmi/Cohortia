Module 5 › Chapter 5.2 › Activity: deploy Nginx
Lab steps
  1. Confirm inventory.ini lists your managed VM with ansible_host and ansible_user.
  2. Create a files directory and add index.html with simple HTML content.
  3. Create install_nginx.yml with become: true and tasks using apt, service, and copy.
  4. Run ansible-playbook -i inventory.ini install_nginx.yml and read output.
  5. Open the managed host IP in a browser to confirm the deployed page.
Verification checklist
Successful run shows changed for installs, ok for unchanged tasks, and the browser loads the custom index page. If not, check become and SSH connectivity.
index.html example
<!DOCTYPE html>
<html>
<head>
  <title>Welcome to Cohortia!</title>
</head>
<body>
  <h1>Hello from Ansible!</h1>
</body>
</html>
Key Takeaway
This activity converts inventory and playbook theory into a working example that you can reuse for future deployments.
