Learning Objectives
From inventory syntax to running playbooks and understanding privilege escalation.
01
Construct an inventory
Create a static INI-like inventory with groups and host variables so Ansible knows which machines to manage.
VERIFIED COMPETENCY MILESTONE
02
Write a playbook
Author a YAML playbook with plays that target groups and list ordered tasks to perform on those hosts.
VERIFIED COMPETENCY MILESTONE
03
Use core modules
Practice ping, apt, service, and copy to check connectivity, install packages, manage services, and move files.
VERIFIED COMPETENCY MILESTONE
04
Run and interpret playbooks
Execute ansible-playbook with an inventory and read ok/changed/failed results; understand become for escalation.
VERIFIED COMPETENCY MILESTONE
Bloom's taxonomy
Learn → Identify inventory elements and modules.
Understand → Read playbook structure and become behavior.
Apply → Write a simple playbook and run it.
Master → Create idempotent tasks and automate deployments reliably.
