Module 5 › Chapter 5.2 › Playbook structure
Playbook main elements
  • plays: top-level items that target hosts and include tasks.
  • hosts: a group or host pattern that the play will run against.
  • become: enables privilege escalation for tasks that need root access.
  • tasks: ordered steps that call modules with parameters.
Misconception
Playbooks are not imperative scripts. They declare desired state and rely on modules to make minimal changes.
Example: install_nginx.yml
---
- name: Install and configure Nginx web server
  hosts: webservers
  become: true
  tasks:
    - name: Update apt cache
      ansible.builtin.apt:
        update_cache: yes

    - name: Install Nginx package
      ansible.builtin.apt:
        name: nginx
        state: present
Key Takeaway
Structure plays logically, name tasks clearly, and prefer small tasks so results are easy to read and debug.
