Module 5 › Chapter 5.2 › Grouping hosts & vars
Group design pattern
Use meaningful group names and avoid mixing unrelated services in the same group. Groups simplify play targeting and reduce duplication in playbooks.
webservers
databases
staging
Variable scope
  • host vars: specific to a single host line.
  • group vars: apply to a named group only.
  • all:vars: global defaults for every host in the inventory.
Security note
Avoid storing secrets in plain inventory files. Use Ansible Vault or external dynamic inventory sources for sensitive data.
Example
[webservers]
web1 ansible_host=192.168.1.10 ansible_user=ubuntu

[all:vars]
ansible_python_interpreter=/usr/bin/python3
Key Takeaway
Organize hosts into groups and set sensible defaults in all:vars to simplify playbook targeting and behavior.
