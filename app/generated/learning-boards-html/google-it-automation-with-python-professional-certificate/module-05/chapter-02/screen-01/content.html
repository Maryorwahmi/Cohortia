Automating with Ansible: Playbooks and Inventory
Define which machines to manage and what actions to run, then deploy reliably across groups.
What you'll practice
Create an INI-style inventory, write a YAML playbook with tasks using apt, service, and copy modules, and run ansible-playbook to deploy Nginx.
Why it matters
With inventory and playbooks you replace one-off manual steps with repeatable, auditable automation that scales across many servers.
Explore Key Topics
Inventory: hosts & groups
Group hosts logically and attach variables like ansible_user or ansible_host.
Playbooks: plays & tasks
Write plays that target groups and list tasks that call modules for actions.
Privilege & testing
Use become for escalation and test tasks incrementally to avoid surprises.
Visual concept
Inventory: webservers, databases, all:vars
Playbook: hosts, become, tasks
Result: idempotent deployments, ok/changed output
Quick example
[webservers]
web1 ansible_host=192.168.1.10 ansible_user=ubuntu

[all:vars]
ansible_python_interpreter=/usr/bin/python3
