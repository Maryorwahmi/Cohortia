Module 5 › Chapter 5.2 › Common modules
ping
Non-destructive connectivity check to confirm Ansible can reach a host and run Python.
apt
Manage Debian packages. Use update_cache before installs and specify state: present for idempotency.
service
Start, stop, or enable services. Specify state and enabled to control runtime and boot behavior.
copy
Transfer files from the control node to a managed node and set owner, group, and mode for permissions.
Key Takeaway
Modules are idempotent when designed correctly: they report ok when no change was needed and changed only when they altered the remote state. Use that to design safe automation.
