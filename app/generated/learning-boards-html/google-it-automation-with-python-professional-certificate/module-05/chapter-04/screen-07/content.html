Module 5 › Chapter 5.4 › Infrastructure as Code
Definition

Infrastructure as Code

Machine-readable files that declare resources and desired topology, stored in version control and applied by automation tools.

Benefits
  • Consistency across environments
  • Fast, repeatable provisioning
Practices
  • Version control IaC files
  • Review and test changes
Example
A Terraform file that creates a network, subnets, and an instance. Run apply to create all resources reproducibly.
Misconception
IaC is only for large systems. Even small projects gain repeatability and version history.
