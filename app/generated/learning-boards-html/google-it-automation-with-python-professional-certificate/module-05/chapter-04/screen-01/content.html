IaaS
Raw virtual machines and networks you manage.
Example: launching a VM to host a web server.
PaaS / SaaS
Managed platforms or fully hosted apps with less operational work.
Example: deploying app code to a managed runtime.
IaC
Write infrastructure declarations or scripts, store them in Git.
Example: Terraform file that creates networks and instances.
Why this matters
Repeatability reduces manual errors and shortens time to deploy.
