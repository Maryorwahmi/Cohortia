Module 5 › Chapter 5.4 › Pitfalls
Cost surprises
Tag resources, enable budgets and alerts, and schedule shutdowns for non-production environments.
Security gaps
Apply least-privilege IAM, avoid wide-scoped service accounts, and encrypt secrets.
No version control
Keep IaC in Git and require reviews and CI checks for changes to avoid accidental misconfigurations.
Practical checklist
  • Tag and budget resources
  • Require CI plan checks on pull requests
  • Limit permissions for automation accounts
