Module 5 › Chapter 5.4 › IaC Best Practices
Version control & CI
Keep IaC in Git and run planning and lint checks in CI to catch risky changes before apply.
Least privilege
Grant automation only the permissions it needs and rotate keys and credentials regularly.
Testing & rollback
Test in staging and have clear rollback steps or state snapshots before applying to production.
Cost monitoring
Set budgets and alerts for unexpected spend; tag resources for clear billing reports.
Key Takeaway
Treat infrastructure changes with the same controls you use for application code: review, test, and monitor.
