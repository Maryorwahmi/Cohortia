Module 5 › Chapter 5.4 › Key Concepts
Cloud Computing
On-demand delivery of compute and services, enabling flexible scale and managed operations.
Service Models
IaaS for control, PaaS for app focus, SaaS for consuming finished software.
Infrastructure as Code
Define infrastructure as code for repeatability, reviewability, and automation.
Takeaway
Pick tools and practices that align with team needs, and treat infrastructure changes with the same discipline as application code.
