Module 5 › Chapter 5.4 › Declarative vs Imperative
Declarative

Describe the desired state

You declare what you want and the tool computes changes to match the current state.

Example tools: Terraform, CloudFormation. Benefit: idempotency and easier state reconciliation.
Imperative

List the steps

You write specific commands or API calls in a sequence to reach the result.

Example methods: Python SDK scripts, procedural Ansible playbooks for provisioning. Benefit: fine-grained control.
When to choose declarative
Complex, multi-resource state you want to track and update predictably.
When to choose imperative
Custom workflows or procedural logic that require explicit sequencing.
