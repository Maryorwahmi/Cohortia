Module 5 › Chapter 5.4 › Terraform vs SDKs
Terraform (declarative)
# Example: resource declaration resource "google_compute_instance" "web" { name = "web-vm" machine_type = "e2-medium" # network, disk, and metadata declarations }
Plan shows what will change before apply. Good for multi-resource state tracking.
Python SDK (imperative)
# Example: create instance via SDK client.insert_instance(project, zone, instance_body) # handle response and retries in code
Scripts give control over flow and error handling, and integrate with other Python logic.
When to use Terraform
Multi-resource orchestration, provider portability, and state tracking.
When to use SDKs
Custom workflows, conditional logic, or when embedding in application scripts.
Pro tip
Use both: Terraform for core infra and SDKs for dynamic, operational tasks.
