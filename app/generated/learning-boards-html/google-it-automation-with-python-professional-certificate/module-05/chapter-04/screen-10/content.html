Module 5 › Chapter 5.4 › IaC Tools
Terraform
Declarative, provider-agnostic language and state management for multi-cloud orchestration.
CloudFormation / Deployment Manager
Provider-native declarative tools that integrate deeply with services and features.
Ansible / Chef / Puppet
Configuration and provisioning tools that can act imperatively or declaratively depending on use.
Python SDKs
boto3, google client libraries: imperative programmatic control suitable for custom workflows.
Where they fit
Use declarative for infra layout; SDKs for orchestration and operational tasks.
Best practice
Store IaC in version control and review changes like application code.
