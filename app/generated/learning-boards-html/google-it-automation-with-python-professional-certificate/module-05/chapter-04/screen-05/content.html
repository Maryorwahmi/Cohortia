Module 5 › Chapter 5.4 › IaaS vs PaaS vs SaaS
IaaS

Raw infrastructure

Rent VMs, storage, and networks. You handle OS, apps, and data.

Example: launching a virtual machine to host a web server and managing patches.
PaaS

Managed platform

Provider manages runtime and middleware so you can deploy application code.

Example: deploying an app to a managed runtime that auto-scales.
SaaS

Hosted application

Use software delivered over the internet. Provider manages everything.

Example: using an email or CRM application without managing servers.
Decision checklist
  • Do you need OS-level control? Choose IaaS.
  • Do you want to focus on code, not ops? Choose PaaS.
  • Do you only need an application? Use SaaS.
