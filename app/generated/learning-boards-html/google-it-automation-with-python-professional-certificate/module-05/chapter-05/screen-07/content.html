Example script (excerpt)
from google.cloud import compute_v1

def list_all_instances(project_id: str, zone: str) -> None:
    instance_client = compute_v1.InstancesClient()
    request = compute_v1.ListInstancesRequest(project=project_id, zone=zone)
    response = instance_client.list(request=request)
    print(f"VM instances in project '{project_id}', zone '{zone}':")
    if not response.items:
        print("No instances found.")
        return

    for instance in response.items:
        print(f"  - Name: {instance.name}, Status: {instance.status}, Machine Type: {instance.machine_type.split('/')[-1]}")
Run with your project and zone to validate credentials and network access. This non-destructive check is useful before any create or delete operation.
Explanation bullets
  • InstancesClient().list returns an iterable response containing instance items.
  • Always check for empty results to avoid unnecessary iterations.
  • Parse the machine_type self link to display the short machine type name.
Common-mistake
Using wrong project or zone values causes confusing empty results; validate those before running scripts that change resources.
Key Takeaway

Use listing scripts as your first verification step to confirm credentials and target scope before creating or deleting VMs.
