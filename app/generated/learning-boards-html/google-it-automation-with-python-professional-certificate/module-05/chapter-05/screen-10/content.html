Comparison Local vs Production Auth
Local (gcloud ADC)
  • Easy developer setup via gcloud auth application-default login.
  • Suitable for testing and interactive development.
  • Not ideal for unattended production automation.
Example: Run gcloud auth application-default login once and your interpreter picks up credentials automatically.
Production (Service Account)
  • Attach service account to VM or workload for managed credentials.
  • Centralized permission control and easier rotation.
  • Grant minimal roles to follow least-privilege principles.
Example: Assign a compute.instanceAdmin or a narrower custom role only if your script creates instances; otherwise grant viewer or custom minimal rights.
Misconception
User account credentials are not a replacement for service accounts in automated production systems because they are harder to rotate and manage securely.
