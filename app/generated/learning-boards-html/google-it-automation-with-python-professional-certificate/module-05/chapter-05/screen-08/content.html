Code Walkthrough create_vm.py
Key snippet
# get image and build disk
image_response = image_client.get_from_family(project="debian-cloud", family="debian-11")
source_image = image_response.self_link

disk_config = compute_v1.AttachedDisk(auto_delete=True, boot=True, type_=compute_v1.AttachedDisk.Type.PERSISTENT, initialize_params=compute_v1.AttachedDiskInitializeParams(source_image=source_image, disk_size_gb="20"))

instance = compute_v1.Instance(name=instance_name, machine_type=f"zones/{zone}/machineTypes/{machine_type}", disks=[disk_config], network_interfaces=[network_interface], metadata=compute_v1.Metadata(items=[compute_v1.Metadata.Items(key="startup-script", value="# startup...")]))

operation = instance_client.insert(request=request)
operation.wait()
if operation.error:
    print("Error creating instance")
else:
    print("Instance created")
The startup script runs when the instance boots and can install services like nginx automatically.
Explanation
  • Get the latest image from a family to avoid pinning an outdated image.
  • Define disk type and size explicitly for reproducible instances.
  • Use metadata to supply startup actions for initial configuration.
  • Call operation.wait to block until provisioning completes, then fetch details.
Common-mistake
Skipping operation.wait often leads to empty or provisional state when you try to read instance fields immediately after insert.
Key Takeaway

Compose instance configuration fully, run insert, then wait for the operation to ensure the VM is ready for verification or connections.
