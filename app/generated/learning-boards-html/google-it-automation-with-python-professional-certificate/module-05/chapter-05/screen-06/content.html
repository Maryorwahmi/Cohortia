Core Concept Application Default Credentials
ADC lookup order
  1. 1. Environment variable GOOGLE_APPLICATION_CREDENTIALS → service account key file.
  2. 2. gcloud auth application-default login credentials.
  3. 3. Service account attached to the VM when running on GCP.
Concrete example
Run gcloud auth application-default login on your laptop to let the Python client pick up your credentials for development tests.
Best practices
  • Avoid embedding service account keys in source control or local project folders.
  • For production, attach a service account to the VM and grant only needed permissions.
  • Use environment variables or secret managers for transient credentials when necessary.
Key Takeaway

ADC simplifies development; prefer managed service accounts on VMs for secure, automated production authentication.
