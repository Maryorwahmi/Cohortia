Core Concept Security & least-privilege
Practical rules
  • Never commit credentials or service account keys to source control.
  • Use ADC and attached service accounts where possible.
  • Create minimal custom roles for automation tasks and avoid owner/editor roles.
  • Log operations and check for operation.error after waiting for long-running tasks.
Concrete mitigation
Use a secret manager or environment variable for transient credentials; prefer attached service accounts for long-lived automated workloads.
Example
A listing script needs only read permissions, so assign a minimal custom role rather than broad compute admin rights.
Key Takeaway

Design automation with security in mind: manage credentials centrally, and grant only the permissions necessary for each script.
