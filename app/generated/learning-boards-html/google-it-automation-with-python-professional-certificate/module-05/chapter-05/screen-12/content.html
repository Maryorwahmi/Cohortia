Process Flow Hands-on Activity
Activity steps
1. Setup
Create directory, python3 -m venv env, activate, pip install google-cloud-compute.
2. Authenticate
Run gcloud auth application-default login for local testing or use a service account on VMs.
3. List
Run list_vms.py with your project and zone to verify the environment.
4. Create
Run create_vm.py, wait for operation.wait, record the instance name and IP.
5. Verify
Re-run list_vms.py, check Console, or SSH to confirm services like nginx are running.
6. Delete
Run delete_vm.py with exact instance name, wait, then list to confirm removal.
Checklist
Enable Compute Engine API, use correct project and zone, avoid hardcoded secrets, and always verify deletion to prevent unexpected billing.
