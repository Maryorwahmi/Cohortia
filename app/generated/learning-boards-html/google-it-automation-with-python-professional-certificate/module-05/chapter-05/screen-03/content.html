Mapping objectives to tasks
Follow the hands-on activity to practice each objective. The activity walks you through commands and scripts so you can verify results in your project.
  • Install in a virtual environment to reproduce dependencies.
  • Authenticate with ADC for local and VM-based runs.
  • Use list, insert, and delete API calls to manage VM lifecycle.
Key Takeaway

Turn each objective into a repeatable command or script, then verify and clean up resources to avoid unexpected costs.
