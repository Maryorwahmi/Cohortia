Translate objectives into tasks

Four applied checkpoints you can test in a short script.

Task
Create processed folder

Use a safe create that does not error when the folder already exists, and verify it after creation.

Task
Generate and read dummy logs

Write test log files, read them line by line to count events, and print a concise summary.

Task
Move processed files

After counting lines, move files into the processed folder so repeated runs skip them safely.

Task
Handle errors and permissions

Catch file-not-found and permission errors to produce clear messages instead of unhandled exceptions.
