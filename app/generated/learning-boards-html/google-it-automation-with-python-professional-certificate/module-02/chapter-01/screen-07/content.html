Module 2 › Chapter 2.1 › os vs pathlib
os / os.path (string API)
import os file_path = os.path.join('data','log.txt') if os.path.exists(file_path): print('exists')

Pros: familiar, low-level controls. Cons: manual string handling and less chaining.

pathlib (object API)
from pathlib import Path p = Path('data') / 'log.txt' if p.exists(): print('exists')

Pros: readable chaining and convenience methods. Cons: slightly different API when mixing with os utilities.

Practical choice

If you maintain old scripts, os functions may already be present. For new automation scripts, pathlib often reduces boilerplate and mistakes.
