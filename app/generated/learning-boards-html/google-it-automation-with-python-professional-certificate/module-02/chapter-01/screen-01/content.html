Paths
Windows uses backslashes, Unix-like systems use forward slashes. Use join functions to avoid platform bugs.
APIs
os and pathlib both provide functions to list, create, rename, and delete files safely.
Quick example
dir = Path('reports') ; dir.mkdir(exist_ok=True) ; dir / 'summary.txt'
