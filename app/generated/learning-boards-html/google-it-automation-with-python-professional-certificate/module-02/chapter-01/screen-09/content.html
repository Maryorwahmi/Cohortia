Guidelines

Error handling and cleanup

  • • Catch specific exceptions like FileNotFoundError and PermissionError and provide actionable messages.
  • • Use context managers to guarantee files are closed even when exceptions occur.
  • • Validate that a path is within an expected directory to avoid accidental deletes.
  • • Avoid broad except clauses; log unexpected exceptions for debugging.
Pro tip

When moving files, consider atomic replaces or temporary names so partially written files are not mistaken for complete ones.

Example
try: with open('data.txt','r') as f: process(f) except FileNotFoundError: print('File missing: check path') except PermissionError: print('Permission denied: run with appropriate rights')
Misconception: Catching everything hides logic errors. Be specific and log unexpected errors for later inspection.
