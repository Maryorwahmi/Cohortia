Reference

Common equivalents

Join paths
os.path.join(a,b) — Path(a) / b
Check exists
os.path.exists(path) — Path(path).exists()
Create dir
os.mkdir(name) — Path(name).mkdir(exist_ok=True)
Remove file
os.remove(file) — Path(file).unlink()
Use this mapping as a quick translator when reading examples or porting scripts between styles. When in doubt, choose the API that most clearly communicates intent in your team.
