Module 2 › Chapter 2.1 › Using the os module
Process Flow

Check → Act → Verify

1. Check existence

Use os.path.exists or os.path.isdir to confirm before creating or deleting.

2. Perform operation

Use os.mkdir, os.remove, or os.rename after confirmation. Expect exceptions for permissions or non-empty directories.

3. Verify and handle errors

Wrap critical calls in try/except blocks and provide clear error handling for FileNotFoundError and PermissionError.

Key Takeaway

Follow a check-act-verify pattern to avoid destructive or ambiguous file system actions.

Code Example
import os dir_name = "temp_data" file_name = "report.txt" file_path = os.path.join(dir_name, file_name) if not os.path.exists(dir_name): os.mkdir(dir_name) with open(file_path, 'w') as f: f.write("First line.\n") # later cleanup os.remove(file_path) os.rmdir(dir_name)
Note: os.path.join avoids separator mistakes and os.remove requires a file path, not a directory.
