Starter Code Guide

Step-by-step

Step 1 — Create folder

Use Path('logs_processed').mkdir(exist_ok=True) to avoid errors if the folder already exists.

Step 2 — Generate logs

Open each dummy file in write mode and write a few lines. Use meaningful messages so you can confirm output.

Step 3 — Process files

For each file, check exists, open in read mode, count lines by iterating, then close.

Step 4 — Move to archive

After closing, use Path.rename to move the file into logs_processed. Confirm by listing the folder.

# Starter snippet (conceptual) processed_dir = Path('logs_processed') processed_dir.mkdir(exist_ok=True) for name in ['app_log_1.txt','app_log_2.txt','app_log_3.txt']: with open(name,'w') as f: f.write('A log entry.\n') # process: open, count, then move
