Learning Objectives

Four practical skills to use in automation scripts

Learn → Understand → Apply → Master
01
Recognize file path types

Identify absolute versus relative paths and how separators differ across systems. This prevents accidental writes in the wrong folder.

VERIFIED COMPETENCY MILESTONE
02
Use the os module

List directories, create and remove folders, and manipulate file names safely using os and os.path functions for portability.

VERIFIED COMPETENCY MILESTONE
03
Read and write files safely

Use context managers to open files for reading, writing, or appending so resources are released even if an error occurs.

VERIFIED COMPETENCY MILESTONE
04
Adopt pathlib patterns

Prefer Path objects for clearer path joining and operations; this reduces string manipulation errors in automation scripts.

VERIFIED COMPETENCY MILESTONE
