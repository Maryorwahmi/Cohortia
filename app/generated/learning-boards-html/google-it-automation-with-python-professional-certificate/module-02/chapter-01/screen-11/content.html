Checklist

Common mistakes and fixes

  • • Forgetting to close files — always use with to guarantee closure.
  • • Wrong working directory — convert to absolute paths or compute script directory when necessary.
  • • Permission errors — catch PermissionError and explain required privileges to the user.
  • • Removing non-empty directories — check contents first or clean files before removing.
  • • Manual string joins — prefer os.path.join or Path objects to ensure portability.
Pro tip

Use temporary directories for tests so you can validate logic without risking production data.
