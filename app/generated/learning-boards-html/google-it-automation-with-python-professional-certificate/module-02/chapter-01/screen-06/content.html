Module 2 › Chapter 2.1 › Reading and writing with open()
Definition

open, modes, and with

Choose 'r', 'w', 'a', 'x', and 'b' appropriately, and prefer the with statement to close files automatically.

Read strategies

Use the file iterator for line-at-a-time processing to avoid memory spikes for large files.

Write strategies

When writing structured data, convert non-strings first and consider newline handling explicitly to keep files consistent.

Key Takeaway

Context managers reduce leaks; streaming lines is memory efficient; pick the correct mode for your intent.

Live Example
# Write with open('sample.txt', 'w') as f: f.write('Line one.\n') f.write('Line two.\n') # Read and count count = 0 with open('sample.txt', 'r') as f: for _ in f: count += 1 print('Lines:', count)
Misconception: Closing is optional. In practice, forgetting to close can leave file descriptors open and delay writes reaching disk.
