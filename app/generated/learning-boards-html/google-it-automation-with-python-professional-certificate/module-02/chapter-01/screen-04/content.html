Definition

Absolute vs Relative

Absolute paths start at the filesystem root and are unambiguous. Relative paths depend on the process's current working directory and are more portable if used intentionally.

Mnemonic: Anchor vs Map

Think of absolute as an anchor to the filesystem root, and relative as a local map from your current position.

Check existence

Always verify a path exists before reading or removing. Use exists functions to avoid runtime errors.

Key Takeaway

Be explicit about path types and use library helpers to build portable paths.

Example & Pitfall
# Problematic string join folder = "reports" file = "summary.txt" path = folder + "/" + file # Might break on Windows or double slash # Safer using join or Path object # os.path.join(folder, file) # Path(folder) / file

Misconception: Assuming string concatenation works across platforms. Use join functions to avoid that trap.
