Module 2 › Chapter 2.1 › Automating a log processing workflow
Architecture

Setup → Process → Archive

Setup

Create processed folder and verify permissions.

Process

Open each file, count lines, and collect metrics safely.

Archive

Move processed files to the archive folder after closing them.

Concrete example

Generate three dummy logs, iterate over them, count lines by streaming, print the count, then move each to logs_processed. Do not keep files open while moving.

Key Takeaway

Separate concerns: setup, processing, archive. Close resources before moving and plan for retries if needed.

Scenario Card
You run a nightly job that processes server logs and archives them. If the job fails halfway, it should resume without reprocessing archives. Use existence checks and atomic moves to accomplish this.
Common mistake
Attempting to move an open file causes errors on some systems. Always close first.
