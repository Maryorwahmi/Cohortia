Module 2 › Chapter 2.2 › Key Concepts
Process
A running program exposing stdout, stderr, and an exit code to automation.
subprocess.run()
High-level function returning a CompletedProcess with returncode, stdout, and stderr.
capture_output & text
Capture stdout/stderr and decode them as strings for parsing and logging.
Summary takeaway: prefer argument lists, capture outputs, use check=True when you need fail-fast behavior, and avoid shell=True unless necessary and safe.
