Managing Processes and External Commands
Run programs, capture output, and handle failures from Python for safer automation.
This lesson emphasizes subprocess.run as the high-level, recommended API. You will practice capturing text output, checking return codes, and deciding when shell behavior is required.
Process
An executing program. Python can start a new one and read its output.
subprocess
Python's module for spawning processes and collecting return codes, stdout, and stderr.
Security
Using the shell can be powerful but introduces injection risks if inputs are untrusted.
