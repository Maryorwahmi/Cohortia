Module 2 › Chapter 2.2 › Key Concepts
CompletedProcess
Result object with returncode, stdout, and stderr from subprocess.run.
returncode
Integer status where zero usually means success and non-zero indicates error conditions.
CalledProcessError
Exception raised when check=True and a process exits non-zero; includes return code and stderr.
Final takeaway: use the subprocess API intentionally, capture outputs for clarity, and make failure handling explicit to build dependable automation.
