Module 2 › Chapter 2.2 › CalledProcessError & FileNotFoundError
CalledProcessError
Raised when check=True and the command returns a non-zero exit. It includes the return code and any captured stderr. Use it to present actionable diagnostics.
FileNotFoundError
Raised when the executable is not found in PATH. Handle it by instructing operators to install the tool or by providing a fallback implementation.
Supporting cards
Don't catch Exception broadly — you'll lose helpful error details.
Log stderr and returncode so you can debug failed runs later.
If a tool is optional, provide a graceful fallback on FileNotFoundError.
Key Takeaway

Handle CalledProcessError and FileNotFoundError explicitly and include stderr in logs for effective debugging.
