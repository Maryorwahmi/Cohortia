Module 2 › Chapter 2.2 › Using subprocess.run()
Code walkthrough (illustrative)
import subprocess # Run a program and capture text output result = subprocess.run(['ls', '-l'], capture_output=True, text=True) print(result.returncode) print(result.stdout)
This pattern gives you return code and decoded stdout. Use check=True to convert non-zero codes into CalledProcessError you can catch.
Key Takeaway

Make outputs inspectable by capturing them and decide on failure handling using return codes or check=True.

Supporting notes
  • capture_output=True captures both stdout and stderr into result.stdout and result.stderr.
  • text=True decodes bytes to str for easier parsing and logging.
  • check=True raises CalledProcessError on a non-zero exit, enabling structured exception handling.
Common mistake
Not using text=True and then failing to decode bytes can lead to confusing binary output. Also, never trust captured stdout when returncode is non-zero.
