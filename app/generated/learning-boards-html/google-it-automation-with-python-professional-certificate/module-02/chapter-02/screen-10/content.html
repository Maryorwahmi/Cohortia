Module 2 › Chapter 2.2 › When to use shell=True
Comparison: list vs shell string
List form: ['ls','-l'] — no shell, safer, recommended.
Shell string: 'ls -l | grep file' — supports pipes and redirects but uses the shell.
Concrete example
A fixed, trusted pipeline may be simplest with shell=True, but if any part includes user input, construct commands as lists or use Popen to pipe processes directly to avoid injections.
Security guidance
  • Prefer argument lists for safety.
  • If shell=True is necessary, sanitize every variable and avoid concatenating untrusted strings.
  • When piping, prefer connecting processes with Popen rather than using a shell when inputs are untrusted.
Warning

Using shell=True with untrusted input can execute arbitrary shell commands. Treat it cautiously.
