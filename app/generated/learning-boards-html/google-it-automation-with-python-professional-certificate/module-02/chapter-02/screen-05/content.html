What subprocess gives you
  • Spawn processes and wait for completion with structured results.
  • Capture stdout and stderr, and decode output to text.
  • Choose list arguments to avoid shell interpretation and injection risks.
CompletedProcess
The object returned by subprocess.run containing returncode, stdout, and stderr when requested.
Concrete example
Call subprocess.run(['ls','-l'], capture_output=True, text=True). The result.stdout contains the directory listing as a string, and result.returncode tells success or failure.
Common mistake
Assuming subprocess.run will parse pipes when given a single string. Pipes require a shell or explicit piping with Popen; passing a list runs the executable directly with no shell operators.
Pro tip

For most automation tasks use subprocess.run with a list of arguments and capture_output to make the result inspectable and testable.
