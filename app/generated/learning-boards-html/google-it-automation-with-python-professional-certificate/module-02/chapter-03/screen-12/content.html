Application › Logging & Exposure
What to log
Log environment presence, OS name, and non-sensitive diagnostics. Never print secrets.
Example
if os.environ.get('DATABASE_URL'): logger.info('DATABASE_URL is set') else: logger.warning('DATABASE_URL missing')
Risks
Logs can persist or be visible to others; avoid storing credentials or verbose system dumps in production logs.
Misconception
Assuming only you can see process output. On shared machines, others may access logs and process information depending on permissions.
Key Takeaway
Design diagnostics to confirm configuration without exposing secrets, and follow operational controls for log retention and access.
