Starter Code
import os
import platform

def configure_application():
    app_environment = os.environ.get('APP_ENV', 'development')
    print(f"Application is running in '{app_environment}' environment.")

    os_name = platform.system()
    print(f"Detected Operating System: {os_name}")

    if os_name == "Linux":
        print("Applying Linux-specific configurations and optimizations.")
    elif os_name == "Windows":
        print("Applying Windows-specific configurations.")
    else:
        print(f"Running on '{os_name}'. Using generic configurations.")

    cpu_cores = os.cpu_count()
    if cpu_cores:
        print(f"Available CPU Cores: {cpu_cores}")
    else:
        print("Could not determine CPU core count.")

    # Optional: set DEBUG_MODE when app_environment is 'development'
    pass
Implementation notes
  • Replace pass with os.environ['DEBUG_MODE'] = 'True' when in development.
  • Test by setting APP_ENV in your shell before running the script.
  • Guard platform-specific calls with hasattr to maintain portability.
Key Takeaway
Implement the optional DEBUG_MODE assignment, validate behavior under different APP_ENV values, and avoid leaving placeholder pass statements in starter code.
