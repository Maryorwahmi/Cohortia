Practice & Safety
Simple local tests and security checks to validate your scripts.
Bloom: Apply → Master
Safe retrieval
Always use os.environ.get with a default when a variable is optional to prevent exceptions during runs.
Temporary scope
Assignments affect only the running process and any children; they do not change the parent shell environment.
Platform checks
Use platform.system and hasattr checks for OS-specific functions like getuid to keep code cross-platform.
Secrets & .env
For local dev, load env vars from a .env file with a loader. Never commit secrets to source control.
