Process › Cross-platform guards
Recognize platform-only calls
Unix-specific calls include os.getuid and os.geteuid. On Windows these attributes are absent.
Safe pattern
if hasattr(os, 'getuid'): print(os.getuid()) else: print('User ID not available (Windows)')
Concrete example
Use platform.system to branch between Windows and Linux commands. For user ID, check for attribute presence before calling.
Misconception
Assuming os.name and platform.system are identical. They differ in format and intent; choose the one that fits your check.
Key Takeaway
Protect platform-specific calls with hasattr or try-except and provide clear fallbacks to keep scripts portable.
