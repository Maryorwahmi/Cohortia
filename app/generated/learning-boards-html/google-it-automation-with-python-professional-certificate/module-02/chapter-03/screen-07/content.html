Definition › System Info Modules
os module
Provides os.name, cpu_count, getcwd, and some platform-specific calls like getuid on Unix.
Useful calls
  • os.name — quick OS family indicator
  • os.cpu_count() — number of logical processors
  • os.getcwd() — current working directory
platform & socket
platform gives human-readable system strings; socket returns network identity like hostname.
Useful calls
  • platform.system(), platform.release(), platform.machine()
  • socket.gethostname() — returns the host name
Example
Use platform.system() to choose the correct network command for the host OS.
Misconception
Don’t assume every function exists everywhere. Guard Unix-specific calls with hasattr before calling on Windows.
Key Takeaway
Combine os, platform, and socket to detect environment and adapt behavior, while using conditional checks for cross-platform compatibility.
