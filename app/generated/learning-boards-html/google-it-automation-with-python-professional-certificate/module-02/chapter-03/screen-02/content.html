Learning Objectives
Build accurate, portable, and secure automation using environment and system data.
Bloom: Learn → Understand → Apply → Master
01
Explain environment variables
Define how named OS values pass configuration to processes and why that avoids hardcoding.
Mnemonic: sticky notes attached to a running process.
VERIFIED COMPETENCY MILESTONE
02
Manipulate os.environ
Access, set, or delete variables using the dictionary-like os.environ safely with get and defaults.
Mnemonic: treat it like a configuration dictionary.
VERIFIED COMPETENCY MILESTONE
03
Retrieve system information
Use platform, os, and socket to get OS, release, CPU count, and hostname for adaptive behavior.
Mnemonic: ask the machine what it is and how powerful it is.
VERIFIED COMPETENCY MILESTONE
04
Use env vars for config & security
Keep secrets out of source code and write portable scripts across dev, test, and prod environments.
Mnemonic: environment-specific settings, not source changes.
