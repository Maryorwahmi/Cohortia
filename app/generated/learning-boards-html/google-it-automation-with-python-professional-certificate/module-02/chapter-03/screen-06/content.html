Comparison › get() vs direct
Direct Access
os.environ['KEY'] — raises KeyError if missing. Use when absence should stop execution and trigger explicit error handling.
When to use
Required configuration like DB connection mode where missing value is critical.
Safe Get
os.environ.get('KEY', 'default') — returns default when missing. Use for optional flags and graceful defaults.
When to use
Optional settings such as feature toggles, debug flags, or environment indicators.
Example
app_env = os.environ.get('APP_ENV', 'development')
Misconception
Using get for required secrets can hide misconfiguration if you silently accept defaults.
Key Takeaway
Pick the access method to match whether a value is optional or required, and validate required values explicitly.
