Environment Variables & System Info
Learn to read and use OS-provided settings to make scripts portable, secure, and adaptive across environments.
Practical: Use os.environ.get to avoid crashes and keep secrets out of source code.
Adaptive: Query platform.system and os.cpu_count to choose commands and worker counts.
In this lesson
Read, set, and remove variables with os.environ. Safely fetch values, handle missing keys, and use platform and socket to detect OS and hostname.
