Core Concept › Environment Variables
What they are
Named values provided by the OS. Use them to pass configuration and secrets into processes without changing code.
Common examples
  • PATH — where executables are located.
  • HOME / USERPROFILE — user home directory.
  • Custom keys like APP_ENV or API_KEY for configuration.
Analogy
Think of each variable as a sticky note attached to a running process containing a piece of configuration.
Key Takeaway
Keep environment-specific values outside code. Read them at runtime to make scripts portable and secure.
Concrete Example
Store an API key or set APP_ENV to switch behavior between development and production. The script reads the variable and chooses configuration accordingly.
Misconception
Setting os.environ in a script does not update the shell that launched it. Changes are temporary for the process and its children only.
Try this
Before running a script, set APP_ENV in your shell and observe how the script chooses config. Then run without APP_ENV to confirm your default handling works.
