Process Flow › Adaptive script flow
Step-by-step
  1. Read APP_ENV with os.environ.get and set a development default.
  2. Detect OS using platform.system to pick platform-specific commands.
  3. Read os.cpu_count and compute worker processes with a safe fallback.
  4. Optionally set DEBUG_MODE for development runs and spawn child processes that inherit it.
Concrete Scenario
A deploy script checks APP_ENV and if production spawns N workers equal to cpu_count; if development, it enables verbose logging and runs fewer workers locally.
Pitfall to avoid
os.cpu_count may return None on some environments. Always check and provide a safe default like 1 or 2.
Key Takeaway

Structure scripts to read env vars and system info first, validate values, then branch to environment-specific behavior for predictable automation.
