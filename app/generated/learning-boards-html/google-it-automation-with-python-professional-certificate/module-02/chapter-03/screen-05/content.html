Process › os.environ operations
Dictionary-like access
Read, set, and delete keys. Prefer get for optional values to avoid KeyError.
Common patterns
  • value = os.environ.get('MY_VAR', 'default')
  • os.environ['MODE'] = 'development' # local to process
  • if 'MY_VAR' in os.environ: del os.environ['MY_VAR']
Common mistake
Assuming assignment persists after the script ends or that parent shells will see the change.
Code Walkthrough
import os
print(os.environ.get('APP_ENV', 'development'))
os.environ['DEBUG_MODE'] = 'True'
# child processes inherit DEBUG_MODE
if 'MY_VAR' in os.environ:
    del os.environ['MY_VAR']
This snippet demonstrates safe retrieval with a default, temporary assignment, and guarded deletion. Remember that get returns None or default when missing and prevents exceptions.
Key Takeaway

Always validate critical env vars and use os.environ.get for optional settings; assignments are process-scoped.
