Definition › Security & Portability
Why env vars for secrets?
They keep credentials out of code and allow different values per environment without code changes.
Practical steps
  • Do not commit .env files. Add them to version control ignore lists.
  • Use environment variables on servers and inject secrets securely via deployment pipelines.
  • Avoid printing secrets in logs or error messages.
Concrete Example
Set DATABASE_URL differently on staging and production. The same code reads the variable and connects appropriately.
Misconception
Environment variables are not a silver bullet; they require operational controls and should not be exposed via careless logging.
Key Takeaway
Use env vars for configuration and secrets, but protect them operationally and validate their presence before critical steps.
