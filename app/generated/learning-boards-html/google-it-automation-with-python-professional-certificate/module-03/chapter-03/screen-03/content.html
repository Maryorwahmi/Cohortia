Module 3 › Chapter 3.3 › Learning Objectives
05 — Pull changes
Fetch and merge remote updates to keep your local branch current.
Example: after a teammate edits a script on GitHub, you run the pull command to integrate their edit into your local files before you begin work.
VERIFIED COMPETENCY MILESTONE
06 — Clone existing repo
Create a complete local copy with history and an origin remote already configured.
Example: cloning a teammate's automation repository into a fresh folder to begin contributing immediately.
VERIFIED COMPETENCY MILESTONE
07 — Verify remotes and branch
Use remote listing and branch checks to avoid accidental pushes to the wrong branch.
Mnemonic: quick 'verify' checklist before pushing to prevent mistakes.
VERIFIED COMPETENCY MILESTONE
08 — Use a Personal Access Token
Authenticate securely from the command line using a PAT instead of a password.
Example: generating a token in your account settings and using it when prompted for credentials during a push.
VERIFIED COMPETENCY MILESTONE
