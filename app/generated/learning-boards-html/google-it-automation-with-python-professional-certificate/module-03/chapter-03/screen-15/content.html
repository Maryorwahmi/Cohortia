Module 3 › Chapter 3.3 › Key Concepts
git push / git pull
Send and receive commits. Pull is fetch plus merge; push uploads your commits to the remote.
git clone
Get a complete local copy with full history and origin set for immediate work.
Authentication & Safety
Use personal access tokens for CLI auth and avoid committing sensitive data, which is hard to remove from history.
Final takeaway

Adopt pull-first habits, verify remotes, and use secure authentication to collaborate safely and effectively on GitHub.
