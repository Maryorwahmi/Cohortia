Module 3 › Chapter 3.3 › Clone Repository
Command example
# Clone the repository into a new folder
git clone https://github.com/your-username/my-automation-scripts.git
# Then change into it
cd my-automation-scripts
After cloning, the origin remote is already set and you can begin working immediately. Check the remote with git remote -v and confirm the files and history are present with git log or by listing files.
Practical notes
Use clone when you do not yet have a local copy. It is the quickest way to obtain the full project and its history. If you only need to inspect changes without creating a working copy, you might instead browse on GitHub or fetch into an existing repo.
Key Takeaway

Cloning creates a ready-to-work local repository with origin set, making contribution immediate.
