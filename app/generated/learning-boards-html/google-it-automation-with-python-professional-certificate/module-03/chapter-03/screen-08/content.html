Module 3 › Chapter 3.3 › Pull Changes
Command summary
# Pull changes from origin main
# After setting upstream, simply:
git pull
# Or explicitly:
git pull origin main
If the remote has commits your local branch lacks, pull downloads and merges them. If conflicts occur, Git will stop and let you resolve them before completing the merge.
Example & common practice
Example: a teammate commits a fix on GitHub. Before you start a new feature, run git pull so your base contains the fix. This habit reduces merge conflicts and duplicated work.
When to use fetch
If you want to inspect remote changes before integrating, run git fetch and then review before merging.
Common mistake
Skipping pull and then pushing can create conflicts or rejected pushes. Pull first to stay in sync.
