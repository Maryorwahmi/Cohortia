Timeline: Simple collaboration rhythm
1. Pull
Get the latest changes so your base is current.
2. Edit & Commit
Make small, focused commits with clear messages.
3. Pull Again If Needed
Integrate recent upstream work before pushing.
4. Push
Upload commits once everything is merged and tested.
This rhythm keeps changes small and reviews easier. If conflicts arise during pull, resolve them locally, test, then push the resolved commit. Small, frequent updates are easier for teams to review and merge.
