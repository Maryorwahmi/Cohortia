Steps to create an empty repo
  1. Sign in to GitHub and choose New repository.
  2. Give a meaningful name like my-automation-scripts.
  3. Choose Public or Private depending on sharing needs.
  4. Do not initialize with README or .gitignore for this exercise.
  5. Click Create repository and copy the displayed remote URL.
Tip: If you plan to push an existing local repo, leave the remote empty to avoid initial commit conflicts. The remote URL is the only thing you need next in the terminal to link the two repositories.

Common mistake

Initializing the GitHub repo with a commit when your local repo already has commits can require extra merging. Start empty to simplify your first push.
