Why PATs matter
Personal access tokens replace passwords for command-line access. They allow you to grant only the permissions needed and to revoke access without changing your web password. When Git asks for credentials during a push or pull, use a token if passwords are not accepted.
Example
During git push, provide your GitHub username and paste the PAT in the password prompt. If the token is valid and has repo scope, the push completes.
Troubleshooting
If you get an authentication error, check token validity and scopes, update saved credentials, or regenerate a new token. Avoid sharing tokens or embedding them in code. Use built-in credential helpers to cache tokens securely on your machine.
Common mistake
Attempting to use a web password for CLI operations may fail; generate and use a personal access token instead.
