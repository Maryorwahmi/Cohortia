Module 3 › Chapter 3.3 › Connect Local to Remote
Terminal steps (conceptual)
# In your local project folder
cd python_automation_project
# Add the remote named 'origin'
git remote add origin https://github.com/your-username/my-automation-scripts.git
# Verify that 'origin' was added
git remote -v
Notes: The add-remote command only records the remote name and URL. It does not upload files. Use the verify command to ensure both fetch and push URLs are present and correct.
Key Takeaway

Confirm the origin URL before pushing so you send commits to the intended repository.

Example & common mistakes
Concrete example: after running add-remote and verifying, you'll see two lines showing origin for fetch and push both pointing to your-username/my-automation-scripts.git. Mistake to avoid: adding a wrong URL or adding a remote when you intended to rename the existing remote — check names with git remote show.
Pro tip
Copy the URL directly from GitHub to avoid typos and choose HTTPS or SSH depending on your authentication setup.
Misconception
Adding a remote uploads nothing; you still need to push commits to populate the remote repository.
