Collaborating with GitHub
Share, sync, and manage your automation scripts with remote repositories

This lesson shows the journey from a local Git repository to a shared remote on GitHub. You will practice creating a repo, linking it as 'origin', pushing your commits, pulling updates made by others, and cloning a whole project to another location. These steps form the collaboration loop that keeps teams coordinated.
