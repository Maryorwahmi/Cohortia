Module 3 › Chapter 3.1 › Git states
Definition
Working Directory
Editable files on disk where you make changes to automation code.
Example: editing a Python script to add error handling.
Staging Area
A selective snapshot you assemble with git add before committing.
Example: staging only the script change and leaving unrelated edits unstaged.
Repository
The recorded commit history stored in Git's metadata after you commit.
Example: a commit that documents why the logging change was made.
Practical tip
Use the staging area to craft commits that are logical and focused, which makes history easier to understand.
Common mistake

Assuming commit includes all edits; remember to stage explicitly the files you want recorded.
