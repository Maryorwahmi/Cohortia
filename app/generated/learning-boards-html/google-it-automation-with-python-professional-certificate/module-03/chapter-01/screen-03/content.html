Practice plan
A short, repeatable sequence to install Git and create your first commit.
Install & configure
Install Git for your platform and set your user name and email so commits are attributed.
Initialize repository
Create a project folder and initialize with a repository marker so Git can track history.
Stage and commit
Add changed files to the staging area and commit with a descriptive message.
Quick checklist
  • Install Git for your OS
  • Configure user name and email
  • Run init, status, add, commit, and log
Verified Milestone
A recorded initial commit in your local repository.
