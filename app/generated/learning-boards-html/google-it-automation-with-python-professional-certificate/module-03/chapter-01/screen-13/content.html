Assessment Idea

Why did git commit report "nothing to commit"?

Analyze the situation and check the staging area with status before committing.
Correct answer
The new file was not added to the staging area, so commit had nothing to record. Use staging first.
Why this matters
Understanding staging prevents confusion and ensures intended changes are included in history.
Practice check

Create a file, run status, add it, run status again, then commit and verify with the log command.
