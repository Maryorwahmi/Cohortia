Module 3 › Chapter 3.1 › Activity: First commit
Step-by-step
  1. Create a project directory and change into it.
  2. Initialize the repository so Git can track files.
  3. Create the Python script that checks disk space and save it.
  4. Run status to see the file as untracked, then stage the file.
  5. Commit the staged file with a descriptive message and verify with a log.
Expected outcome
An initial commit recorded in your local repository, visible with the short log command.
mkdir python_automation_project cd python_automation_project git init # Create my_script.py with the provided content and save it # Check status to see untracked files git status # Stage and commit git add my_script.py git commit -m "Initial commit: Added a Python script to check disk space" # Verify git log --oneline
Follow this exact sequence to verify you can record and inspect changes. If status shows nothing to commit, confirm you staged the file first.
Key Takeaway

Complete the sequence init, add, commit to record your first repository snapshot and verify with log.
