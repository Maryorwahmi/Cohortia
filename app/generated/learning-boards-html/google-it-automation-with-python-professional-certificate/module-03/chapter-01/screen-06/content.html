Install and configure Git

Install with your OS package manager or installer, then set a global name and email so commits are attributed.
Why this matters
Commits include author metadata. Setting a clear name and email makes history useful when you inspect or share it.
Common mistake
Skipping configuration leads to anonymous or machine-based authorship, which makes collaboration confusing.
Terminal demo (visual)
# Example commands shown for reference # For Debian/Ubuntu sudo apt update sudo apt install git # For macOS with Homebrew brew install git # Configure identity git config --global user.name "Your Name" git config --global user.email "your.email@example.com"
Note: These commands are visual examples you will repeat in your environment. The configuration with the global flag applies to all repositories on your machine unless overridden locally.
Key Takeaway

Install and immediately set a recognizable name and email so your commits are traceable.
