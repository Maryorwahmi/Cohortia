Module 3 › Chapter 3.1 › Initialize a repository
Definition

Initialize a repository

Create the .git metadata so your directory is tracked by Git.
mkdir my_automation_scripts cd my_automation_scripts git init # A hidden .git directory is created to store history and metadata
After initialization, run status to see which files are untracked. Remember, init prepares tracking but does not record the first snapshot until you add and commit.
Key Takeaway

Init sets up Git's metadata; you still need to stage and commit to record your files.

Example scenario
You create a folder for Python automation scripts and initialize Git so every future change can be recorded. If you forget to init and try to commit, Git will report there is no repository.
Common mistake
Running commit commands before git init leads to errors; initialize first in the correct directory.
