Common Mistakes
Forgetting git add
Commits only include staged changes. Stage intentionally before committing to avoid surprises.
Vague commit messages
Write messages that explain why the change exists, not just what changed.
Committing secrets
Never commit API keys or passwords. Use environment variables or secure storage.
Other tips
Initialize in the correct directory and avoid adding large binaries directly to the repository.
Key Takeaway

Simple habits prevent common errors: stage, write clear messages, and keep secrets out of commits.
