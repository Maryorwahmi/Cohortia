Module 3 › Chapter 3.1 › Key Concepts
Version Control
Record file changes over time so you can revert and inspect history.
CVCS vs DVCS
Centralized uses one server; distributed stores a full history on each client for resilience.
Staging Area
A temporary area for preparing snapshots before committing them to history.
Summary Takeaway
Use Git to capture meaningful snapshots of your automation work, configure identity, and stage deliberately to keep history useful and recoverable.
