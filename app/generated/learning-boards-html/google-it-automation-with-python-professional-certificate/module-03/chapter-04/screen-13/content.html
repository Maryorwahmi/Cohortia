Correct resolution sequence
  1. Open conflicted files and inspect markers.
  2. Edit to combine or choose changes and remove markers.
  3. Run quick local tests to validate behavior.
  4. Stage resolved files with git add.
  5. Commit the merge with a message describing the resolution.
.gitignore choices
  • __pycache__/ and *.pyc for byte-code.
  • .venv/ or venv/ for virtual environments.
  • logs/ and *.log for generated logs.
  • config.ini and .env for sensitive local configuration.
