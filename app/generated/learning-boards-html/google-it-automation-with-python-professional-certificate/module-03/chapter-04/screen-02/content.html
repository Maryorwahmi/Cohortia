Learning Objectives
Build practical habits for merging, conflict resolution, ignoring files, and tagging releases.
Learn
Understand
Apply
Master
01
Merge branches

Use git switch, git pull, and git merge to combine a feature branch into main while keeping history intact.

Mnemonic: Flow Forward
VERIFIED COMPETENCY MILESTONE
02
Resolve merge conflicts

Recognize conflict markers, choose or combine changes, stage resolved files, and finish the merge commit.

Mnemonic: Clean the Markers
VERIFIED COMPETENCY MILESTONE
03
Use .gitignore

Declare patterns for byte-code, virtual environments, editor files, logs, and sensitive configs so they are not tracked.

Mnemonic: Ignore the noise
VERIFIED COMPETENCY MILESTONE
04
Tag release points

Create lightweight or annotated tags and push them to remote to mark release commits for deployments.

Mnemonic: Pin the Moment
VERIFIED COMPETENCY MILESTONE
Competency checklist
  • Switch and pull latest main before merging.
  • Resolve conflicts, stage, and commit the merge.
  • Create and commit a .gitignore covering venv, caches, and config files.
  • Create a tag and push tags to remote for releases.
Complete the hands-on activity to verify each milestone.
