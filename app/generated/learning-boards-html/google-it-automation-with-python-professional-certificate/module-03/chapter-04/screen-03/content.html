Module 4 › Chapter 3.4 › Assessment Targets
Lab deliverables
  1. Create feature branch and commit the utility script.
  2. Create a conflicting change on main and commit.
  3. Merge feature into main, resolve conflict, stage and commit the resolution.
  4. Add and commit a .gitignore that ignores config.ini and virtual envs.
  5. Create an annotated tag and push tags to origin.
Common pitfalls to avoid
  • Committing local credentials or config files before adding them to .gitignore.
  • Rewriting shared history with a rebase on a branch already pushed to remote.
  • Making very large commits that mix unrelated changes.
