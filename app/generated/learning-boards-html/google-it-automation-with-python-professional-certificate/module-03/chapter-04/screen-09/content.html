Module 4 › Chapter 3.4 › Feature Branch Workflow
Workflow hierarchy
Main / Develop
Stable branch that should be deployable. Only merge reviewed and tested changes here.
Feature Branches
Create per feature or bugfix. Commit frequently and push for backup.
Pull Request / Merge Request
Use PRs for code review, automated tests, and discussion before merging into main.
Quick rules
  • Keep commits small and focused.
  • Pull regularly to reduce conflicts.
  • Use descriptive commit messages with the intention behind the change.
