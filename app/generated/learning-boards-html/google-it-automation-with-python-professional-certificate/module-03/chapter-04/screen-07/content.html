Example .gitignore for Python
# Byte-code files
__pycache__/
*.pyc

# Virtual environments
.venv/
venv/

# Editor/IDE
.vscode/
.idea/

# OS files
.DS_Store
Thumbs.db

# Sensitive credentials
config.ini
.env
Commit this file so the same ignore rules apply to everyone on the project. If a sensitive file was already committed, address it separately; adding to .gitignore alone won't remove existing history.
Quick test

After creating .gitignore, create a dummy config.ini and run git status. The file should not appear as untracked. If it does, check for path mismatches.

Warning

If sensitive data was committed previously, you must remove it from the repository history or rotate credentials. .gitignore does not retroactively remove files.
