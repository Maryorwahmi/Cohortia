Module 3 › Chapter 3.2 › Quick Checks
Check status
Run git status and a concise git log --oneline --graph to confirm branch and commit state before changes.
Amend carefully
Only amend commits that have not been pushed to remotes. For shared commits, prefer new commits or a clear remediation plan.
Branch habit
Create focused feature branches, name them descriptively, and switch with git switch -c to work safely in isolation.
Final reflection
Adopt short, repeated checks before rewriting history. These small steps protect your work and your teammates' workflow.
