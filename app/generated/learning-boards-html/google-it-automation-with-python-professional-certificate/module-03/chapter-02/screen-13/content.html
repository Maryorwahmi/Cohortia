Module 3 › Chapter 3.2 › Key Concepts
git restore
Explicitly discard working edits or unstage files. Use --staged to move staged changes back to working files.
git commit --amend
Replace the last commit with a new one. Safe for local fixes, risky for commits already pushed to remotes.
Branching
Work on isolated timelines. Use descriptive names and switch with git switch -c to create and move in one step.
Summary
Use restore to undo, amend to correct unshared commits, and branches to isolate features. Always verify repository state before rewriting history.
