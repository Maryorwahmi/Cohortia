Module 3 › Chapter 3.2 › git log
Terminal demo (visual)
$ git log --oneline --graph
* 9f8a3b2 Add logging to disk check
* 6c4d2e1 Initial commit: project scaffold
This compact graph quickly shows recent commits and a visual branch history marker. For details, request the patch to see code changes.
Key Takeaway

Start with a compact graph to locate the relevant commit, then view the patch when you need exact lines changed.

Options explained
  • --oneline
    Shows one compact line per commit with a shortened hash and message for quick scanning.
  • --graph
    Draws a simple ASCII tree to reveal branch and merge structure when history diverges.
  • -p
    Shows patch details for each commit so you can inspect added or removed lines to diagnose bugs.
Concrete scenario
When a test fails, use a compact graph to find recent commits touching the module, then run the patch view on those commits to identify the offending change.
