Learning Objectives

Progress from reading history to safely adjusting the most recent commit.

Bloom: Learn → Understand → Apply → Master
01
Navigate commit history
Learn to use git log and its flags to interpret commits, dates, authors, and messages for debugging and audits.
Mnemonic: timeline snapshot
VERIFIED COMPETENCY MILESTONE
02
Understand .git internals
Identify HEAD, objects, refs, config, and hooks, and why editing these files manually is unsafe.
Mnemonic: hidden locker
VERIFIED COMPETENCY MILESTONE
03
Write effective commit messages
Practice short subject lines and optional detailed bodies that explain why a change was made.
Mnemonic: subject + body
VERIFIED COMPETENCY MILESTONE
04
Know when to rewrite history safely
Recognize the risk of amending shared commits and prefer local fixes before pushing to a remote.
Mnemonic: local only
VERIFIED COMPETENCY MILESTONE
