Attachment Example
from email.mime.application import MIMEApplication
from email.mime.multipart import MIMEMultipart

msg = MIMEMultipart()
msg['Subject'] = 'Daily Report'

with open('daily_report.txt', 'rb') as f:
  part = MIMEApplication(f.read(), Name='daily_report.txt')
  part['Content-Disposition'] = 'attachment; filename="daily_report.txt"'
  msg.attach(part)
Common Mistake
Opening binary files in text mode can corrupt attachments, especially across platforms. Always use 'rb'.
Key Takeaway

Attach files as MIME parts from binary reads and verify delivery in a test inbox.
