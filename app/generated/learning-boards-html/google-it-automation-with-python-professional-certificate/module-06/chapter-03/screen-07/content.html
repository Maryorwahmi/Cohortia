Module 6 › Chapter 6.3 › Multipart Messages
What to include
  • Plain-text part for basic clients.
  • HTML part for richer formatting.
  • Attachments added as separate MIME parts with appropriate Content-Disposition.
Order matters: attach the plain-text first, then HTML, so clients can choose the best option.
Analogy
Think of MIMEMultipart as an envelope containing multiple formats of the same letter and files tucked inside. Recipients pick the format their mail reader understands.
Key Takeaway

Provide both plain and HTML alternatives, and attach files as separate MIME parts opened in binary mode.
