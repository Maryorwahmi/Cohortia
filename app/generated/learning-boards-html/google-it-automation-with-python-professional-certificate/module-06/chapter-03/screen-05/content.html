Module 6 › Chapter 6.3 › Secure Connection
Connection Steps
1. Decide port and mode: 465 for SSL, 587 for starttls.
2. If using starttls, call starttls() before login.
3. Read credentials from environment variables.
4. Catch authentication and network errors and avoid revealing secrets in logs.
Code Snippet
import os
import smtplib
from smtplib import SMTP_SSL

password = os.environ.get('EMAIL_APP_PASSWORD')
server = SMTP_SSL('smtp.gmail.com', 465)
server.login('your_email@example.com', password)
# send messages
server.quit()
Open credentials via environment variables and avoid printing them. If login fails, check the port and whether an app-specific password is required.
