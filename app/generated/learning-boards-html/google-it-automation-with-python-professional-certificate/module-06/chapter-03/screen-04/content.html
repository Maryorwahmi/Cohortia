Module 6 › Chapter 6.3 › SMTP Basics
Definition

SMTP is the protocol used to submit and transfer email messages. smtplib is the Python module that opens a network connection, authenticates, and issues SMTP commands to send a message programmatically.

Quick bullets
  • Use SMTP_SSL for an SSL-wrapped connection.
  • Use starttls() to upgrade a plain connection to TLS.
  • Need server address, port, email, and a password or token.
Key Takeaway

SMTP is the transport; smtplib is your script's client. Always choose encrypted transport before authenticating.

Concrete Example
import smtplib
server = smtplib.SMTP_SSL('smtp.gmail.com', 465)
server.login('your_email@example.com', 'APP_PASSWORD')
# later: server.send_message(msg)
server.quit()
Misconception: using a regular account password is discouraged. Prefer an application-specific password or token for automated access.
