Complete Example
from email.mime.multipart import MIMEMultipart
from email.mime.text import MIMEText
from email.mime.application import MIMEApplication
import smtplib
import os

msg = MIMEMultipart('mixed')
msg['Subject'] = 'Daily Report'
msg['From'] = 'monitor@example.com'
msg['To'] = 'admin@example.com'

alt = MIMEMultipart('alternative')
alt.attach(MIMEText('Text summary of the report','plain'))
alt.attach(MIMEText('
Report
All checks OK
','html'))
msg.attach(alt)

with open('daily_report.txt','rb') as f:
  part = MIMEApplication(f.read(), Name='daily_report.txt')
  part['Content-Disposition'] = 'attachment; filename="daily_report.txt"'
  msg.attach(part)

with smtplib.SMTP_SSL('smtp.gmail.com',465) as server:
  server.login('monitor@example.com', os.environ.get('EMAIL_APP_PASSWORD'))
  server.send_message(msg)
Checkpoints
  • Alternative parts first, attachments last.
  • Open attachments in 'rb' and set filename in Content-Disposition.
  • Read credentials from environment variables.
Key Takeaway

Follow the composition order and secure credentials; verify the message and attachment in a test inbox.
