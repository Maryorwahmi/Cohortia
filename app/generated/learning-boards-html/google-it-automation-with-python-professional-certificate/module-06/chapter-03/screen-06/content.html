Module 6 › Chapter 6.3 › Plain-text Email
Example Code
from email.mime.text import MIMEText
import smtplib

msg = MIMEText('Daily system status: all checks passed')
msg['Subject'] = 'Daily Report'
msg['From'] = 'monitor@example.com'
msg['To'] = 'admin@example.com'

with smtplib.SMTP_SSL('smtp.gmail.com', 465) as server:
  server.login('monitor@example.com', 'APP_PASSWORD')
  server.send_message(msg)
Bullets
  • Use MIMEText for clear text body content.
  • Set Subject, From, and To headers explicitly.
  • Use context managers to ensure server.quit() runs.
Key Takeaway

Start with plain-text emails for reliability and testability before adding HTML and attachments.
