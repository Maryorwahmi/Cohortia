Module 6 › Chapter 6.3 › Activity Walkthrough
Step-by-step
  1. Create daily_report.txt with system info.
  2. Build MIMEMultipart message with plain and HTML parts.
  3. Attach the report opened in 'rb' as MIMEApplication.
  4. Send via SMTP_SSL or starttls, reading password from environment.
  5. Post a concise JSON to a webhook URL using requests.post and log the response.
Starter Hints
Use os.environ.get for passwords, test locally with dummy URLs, and verify the inbox rather than assuming success.
Try This

After sending, download the attachment and open it to confirm the file was not corrupted by encoding or mode mistakes.
