Module 06 › Chapter 6.1 › Practice Targets
Practice: Filter CSV logs

Read a system_events.csv, filter for level equal to ERROR, and confirm the output contains only the matched rows. This mirrors log processing tasks in automation.

Practice: Use JSON config

Load config.json to get output paths and options such as whether to create an XML export. This shows how JSON configuration drives script behavior without changing code.

Practice: Write safe CSV output

Write the filtered rows with csv.writer and newline handling so other programs can import the result without extra blank lines or quoting errors.

Practice: Optional XML export

If configured, convert the filtered rows into a simple XML tree and write it with ElementTree. This demonstrates transforming between flat and hierarchical formats.
