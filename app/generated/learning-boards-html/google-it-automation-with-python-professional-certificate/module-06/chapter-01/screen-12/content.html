Module 06 › Chapter 6.1 › Format Comparison
CSV
Best for tabular exports, spreadsheets, and simple logs. Very interoperable but limited to flat rows.
JSON
Ideal for API payloads and configs. Maps naturally to Python dicts and lists and supports nested structures.
XML
Used where schemas, attributes, or namespaces matter. More verbose and sometimes required by legacy systems.
Decision checklist
  • Who consumes the data? Choose the format they accept.
  • Does data require nesting or typed values? Favor JSON for most cases.
  • Is strict schema validation required? Consider XML and a validation tool.
