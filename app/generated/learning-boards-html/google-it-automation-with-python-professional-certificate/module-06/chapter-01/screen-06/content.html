Module 06 › Chapter 6.1 › Writing CSV
Starter pattern
os.makedirs(config['output_dir'], exist_ok=True)
with open(out_path, 'w', newline='') as csvfile:
    writer = csv.DictWriter(csvfile, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(filtered_rows)
This pattern ensures directory existence, header row, and correct newline handling on write.
Tips & gotchas
  • Always call writeheader when using DictWriter so consumer tools see column names.
  • Let the writer quote fields that need quoting; avoid manual quoting in your data.
  • Choose delimiter/dialect to match the target environment's expectations.
Key Takeaway
Use DictWriter and newline='' to produce CSVs that other programs can import reliably.
