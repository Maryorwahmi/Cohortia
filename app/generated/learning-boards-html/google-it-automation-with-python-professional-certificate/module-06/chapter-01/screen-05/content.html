Module 06 › Chapter 6.1 › Reading CSV
Pattern: Using DictReader
with open('system_events.csv', 'r', newline='') as f:
    reader = csv.DictReader(f)
    for row in reader:
        if row['level'] == 'ERROR':
            # process error row
            pass
DictReader maps headers to values so you can write clearer filtering logic than indexing lists.
Common issues & fixes
  • Extra blank rows: ensure newline='' when opening files for csv.
  • Wrong delimiter: pass delimiter or register a dialect for tabs/semicolons.
  • Type conversion: csv returns strings; parse timestamps or numbers after reading.
Misconception
csv will not validate schema; it only parses text. Validation and type conversion are your responsibility after parsing.
