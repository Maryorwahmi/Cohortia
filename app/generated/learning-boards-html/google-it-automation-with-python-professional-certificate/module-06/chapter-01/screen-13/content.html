Checklist for reliable scripts
  • Open CSV files with newline=''.
  • Catch JSONDecodeError and ET.ParseError for external input.
  • Validate presence of required keys or headers before using them.
  • Keep format choices in config, not hard-coded paths or delimiters.
Pro tip
When transforming between formats, first normalize data into well-typed Python structures (e.g., parsed timestamps) before serializing. This keeps transformation logic clear and testable.
Key Takeaway
Defensive parsing and clear conversions prevent many integration bugs in automation scripts.
