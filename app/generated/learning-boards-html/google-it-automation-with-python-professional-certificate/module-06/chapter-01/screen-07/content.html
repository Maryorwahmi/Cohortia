Module 06 › Chapter 6.1 › JSON Structure
Example JSON config
{
  "output_dir": "processed_logs",
  "error_log_filename": "error_events.csv",
  "output_xml": true,
  "xml_log_filename": "error_events.xml"
}
This maps to a dictionary with string keys and boolean value, which your script reads to decide behavior.
Best practices
  • Use json.load to read files and json.dump to write files with indentation for readability.
  • Wrap parsing in try-except to catch malformed JSON and handle it gracefully.
  • Prefer JSON for structured config and API payloads because of native type mapping to Python.
Misconception
JSON parsers will not invent missing keys; validate presence of required keys after parsing to avoid KeyError in your script.
