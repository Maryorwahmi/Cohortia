Module 06 › Chapter 6.1 › JSON I/O
Code pattern
try:
    with open('config.json') as f:
        config = json.load(f)
except json.JSONDecodeError:
    # handle malformed config
    config = {'output_dir':'processed_logs', 'error_log_filename':'error_events.csv'}
This fallback ensures automation continues with sane defaults if parsing fails.
Tips
  • Prefer explicit error handling for external JSON to avoid crashes in automation pipelines.
  • When writing config files for humans, pass indent=2 to json.dump for readability.
  • Remember json.load expects a text file opened in default encoding unless otherwise specified.
