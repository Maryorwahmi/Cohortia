What CSV looks like
timestamp,level,message
2023-10-26 10:00:01,INFO,User 'admin' logged in
2023-10-26 10:00:10,ERROR,"Failed to connect, retrying later"
Notice quoted field with embedded comma. A naive split would break this record; use a CSV parser to keep fields intact.
When to use CSV
Exports, simple logs, spreadsheet interchange, and quick data dumps between tools.
Common mistake
Splitting lines on commas manually and losing quoted fields or embedded newlines.
Practical tips
  • Open files with newline set to an empty string when using csv to avoid extra blank rows.
  • Use csv.DictReader when you prefer keyed access by header names.
  • Specify a dialect or delimiter when files use tabs or semicolons instead of commas.
Key Takeaway
CSV is simple and ubiquitous, but robust parsing requires the csv module to handle quoting and delimiters correctly.
