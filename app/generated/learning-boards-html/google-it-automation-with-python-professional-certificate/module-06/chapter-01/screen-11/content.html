Step-by-step plan
  1. Load config.json with json.load inside a try-except to handle malformed files.
  2. Create the output directory with os.makedirs(..., exist_ok=True).
  3. Open system_events.csv with newline='' and use csv.DictReader to read rows.
  4. Filter rows where row['level'] == 'ERROR' and collect matches.
  5. Write filtered rows to the configured CSV file using csv.DictWriter and writeheader.
  6. If output_xml is true, build a simple ElementTree and write the XML file.
