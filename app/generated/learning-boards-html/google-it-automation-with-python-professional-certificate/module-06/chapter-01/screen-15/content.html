Module 06 › Chapter 6.1 › What to Remember
CSV
Flat tables, use csv module and handle newline and quoting correctly.
JSON
Structured mappings and arrays; use json.load/dump and catch decode errors.
XML
Hierarchies and attributes; ElementTree parses to a navigable element tree.
Summary Takeaway
Match data shape to format, use the right built-in module, and program defensively against malformed or unexpected input.
