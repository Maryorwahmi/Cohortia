Code walkthrough
Starter pattern for POST with a timeout and error handling.
import requests

api_url = "https://api.example.com/items"
payload = {"name": "New Item", "quantity": 10}

try:
  response = requests.post(api_url, json=payload, timeout=5)
  response.raise_for_status()
  print("Item created", response.status_code)
  data = response.json()
  print("Response data:", data)
except requests.exceptions.Timeout:
  print("The request timed out after 5 seconds.")
except requests.exceptions.RequestException as e:
  print("An error occurred:", e)
Explanation & bullets
  • The json parameter serializes the payload and sets Content-Type automatically.
  • timeout prevents indefinite blocking of your script when the server is slow.
  • response.raise_for_status raises for 4xx and 5xx responses so errors surface immediately.
  • Always handle requests.exceptions.RequestException as a catch-all for network errors.
Key Takeaway

Use the json argument for payloads, set timeouts, and call raise_for_status to make failures explicit.
