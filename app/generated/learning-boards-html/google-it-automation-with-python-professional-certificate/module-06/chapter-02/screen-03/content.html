Outcomes you can demonstrate
  • Fetch and parse JSON from a public API and iterate through returned items.
  • Create or update resources by sending JSON payloads with the json parameter.
  • Detect and handle HTTP errors using status codes and raise_for_status.
  • Protect credentials and use timeouts to keep automation resilient.
Quick mnemonic
Request → Check → Parse → Store. Always check the status first.
