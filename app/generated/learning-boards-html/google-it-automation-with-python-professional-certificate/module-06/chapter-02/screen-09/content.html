Authentication patterns
API keys: token sent in Authorization header or a custom header, often Bearer tokens.
Basic auth: username and password encoded; use requests' auth helper for convenience.
Secure storage
Store keys outside code using environment variables or secure config. Load them at runtime to avoid accidental exposure in version control.
Example header
Set headers = {'Authorization': 'Bearer YOUR_API_KEY'} and pass headers=headers to requests calls. Replace YOUR_API_KEY with the value read from an environment variable at runtime.
Common Mistake

Hardcoding API keys in scripts exposes them to anyone with repository access. Use environment variables or secrets managers instead.
