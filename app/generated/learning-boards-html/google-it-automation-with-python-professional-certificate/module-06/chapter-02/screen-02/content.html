01
HTTP Methods & Semantics
Explain what GET, POST, PUT and DELETE do and pick the correct verb for each API action.
Mnemonic: Think of REST verbs as CRUD mapped to retrieval, creation, update, and removal.
VERIFIED COMPETENCY MILESTONE
02
requests Library Usage
Use requests.get/post/put/delete with json parameter and timeouts to interact with APIs safely.
Mnemonic: json param handles serialization and Content-Type for you.
VERIFIED COMPETENCY MILESTONE
03
Responses & Status Codes
Read status_code, headers, and parse JSON with response.json(); use raise_for_status to detect errors programmatically.
Mnemonic: 2xx success, 4xx client, 5xx server.
VERIFIED COMPETENCY MILESTONE
04
Authentication & Robustness
Apply API keys, basic auth, timeouts, and session objects while avoiding hardcoded secrets.
Mnemonic: credentials in environment, not in code.
