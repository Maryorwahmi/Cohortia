When to use Session
Persist common headers like Authorization across many calls.
Maintain cookies for workflows that require stateful interactions.
Benefit from connection pooling to reduce repeated TCP setup costs.
Example pattern
Create session = requests.Session(); session.headers.update({'Authorization': token}); then use session.get/post for the sequence of calls.
Cautions
  • Do not reuse a single session across unrelated workflows that require different credentials.
  • Be explicit about closing sessions to free resources in long-running processes.
Key Takeaway

Sessions centralize shared settings and improve performance. Use them for related groups of requests to the same service.
