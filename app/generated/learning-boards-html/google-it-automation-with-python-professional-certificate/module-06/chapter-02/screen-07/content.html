Response anatomy
Status code: three-digit outcome like 200, 201, 404, 500.
Headers: key-value metadata; Content-Type indicates JSON vs HTML.
Body: the payload; often JSON when working with APIs.
Quick validation steps
  1. Check response.status_code or call raise_for_status.
  2. Confirm Content-Type includes application/json before calling response.json().
  3. Validate the data structure matches expectations (list vs dict and required keys).
Example scenario
You GET /users and receive 200 with Content-Type application/json. Call response.json(), inspect first element to confirm it has name and email keys before using them.
Common Mistake

Calling response.json() without checking Content-Type can raise exceptions if the server returned HTML or an empty body.
