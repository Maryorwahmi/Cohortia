Common errors
  • Authentication missing or invalid → 401/403.
  • Using wrong HTTP verb → unexpected resource behavior.
  • No timeout set → scripts hang indefinitely on network issues.
  • Parsing non-JSON bodies → JSON decoding errors.
Troubleshooting checklist
  1. Confirm request headers and payload match API docs.
  2. Check response.status_code and response.text for error messages.
  3. Replicate the call with curl or Postman to isolate client code issues.
  4. If transient, add limited retries with backoff and logging.
Pro Tip

Log the request.headers and response.status_code during development, but remember to redact secrets before saving logs to long-lived storage.
