Debugging checklist

  1. Reproduce the issue on a tiny sample.
  2. Run a dry-run that prints planned file operations without changing files.
  3. Test regex stepwise; use findall to inspect matches.
  4. Log exceptions with stack traces and include path info for failing files.
Pro tip: add a --dry-run flag to scripts so you can preview moves and renames safely before applying them.
Example: dry-run pattern
Print intended rename operations before calling shutil.move.
for name in os.listdir('logs'):
  if 'app' in name and name.endswith('.log'):
    new_name = name.replace('.log', '_processed.log')
    print('Would rename', name, '->', new_name)  # dry-run
    # when satisfied: shutil.move(src, dst)
Key Takeaway

A dry-run and small tests reduce the risk of destructive mistakes when scripts run unattended.
