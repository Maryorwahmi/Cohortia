Avoid greedy captures

Greedy: .* Non-greedy: .*? — choose non-greedy when you want the smallest sensible match between delimiters.
Example: pattern r"'(.*)'" on "'a' and 'b'" captures "a' and 'b" unless you use r"'(.+?)'" instead.
Escape dot: use \., not ., when matching a literal period in an IP address or filename.
Try this example
import re
s = "'first' and 'second'
print(re.findall(r"'(.*)'", s))    # greedy -> ['first' and 'second']
print(re.findall(r"'(.+?)'", s))   # non-greedy -> ['first', 'second']
