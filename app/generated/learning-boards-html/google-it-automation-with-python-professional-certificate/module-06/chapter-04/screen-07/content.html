Process Flow

Archive creation steps

  • Choose format (zip, tar) and base name.
  • Ensure permissions and unique output name.
  • Call shutil.make_archive and catch exceptions.
  • Verify the archive exists and move it to storage or upload.
Example
import shutil

# Create a zip archive of 'logs'
archive = shutil.make_archive('logs_backup', 'zip', 'logs')
print('Archive created at', archive)
Pro tip: write archives to a temporary folder and only move to the final location after verifying size and existence.
Check: if archive size is unexpectedly small, inspect the logs for skipped or unreadable files.
