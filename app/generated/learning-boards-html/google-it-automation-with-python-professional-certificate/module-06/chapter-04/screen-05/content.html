Process Flow

Safe copy pattern

  1. Verify source exists with os.path.exists or os.path.isfile.
  2. Check destination: does it exist? decide overwrite vs unique name.
  3. Attempt shutil.copy or shutil.copytree inside try/except to catch IO/OSError.
  4. On failure, log the exception and revert any partial changes if needed.
Misconception: copytree merges into an existing folder. It does not; handle the destination first.
Pro tip: to avoid collisions, append datetime strings to destination names.
Example: safe recursive copy
import os
import shutil
from datetime import datetime

src = 'my_logs'
dst = 'my_logs_backup'
if os.path.exists(dst):
  dst = f"{dst}_{datetime.now().strftime('%Y%m%d%H%M%S')}"

try:
  shutil.copytree(src, dst)
  print('Copied to', dst)
except (IOError, OSError) as e:
  print('Copy failed:', e)
