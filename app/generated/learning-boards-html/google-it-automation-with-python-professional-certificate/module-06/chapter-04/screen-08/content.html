Regex essentials

  • Dot matches any character except newline.
  • * zero or more, + one or more, ? zero or one.
  • [] define a character set, () capture groups.
  • Use raw strings: r"pattern" to avoid double escaping backslashes.
Core functions
re.search, re.match, re.findall, re.sub — choose based on whether you need the first match, anchored match, all matches, or replacements.
import re
text = "[2023-10-26 10:00:10] ERROR: Failed to connect"
# find the timestamp
pattern = r"\[\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}\]"
print(re.findall(pattern, text))
Key Takeaway

Regex is a small syntax but powerful; learn a few metacharacters and the re API to handle most log parsing tasks.
