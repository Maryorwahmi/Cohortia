Definition

shutil.move behavior

Move attempts a rename first. If that fails because source and destination are on different filesystems, it falls back to copying and deleting the source.

Example failure mode: interrupted copy to network share can leave partial destination and unchanged source.
Mitigation: copy, verify checksum, then remove original to avoid unintended data loss.
Quick detection
You can check device IDs using os.stat on both paths and compare st_dev; if they differ, a cross-filesystem move will trigger a copy.
import os

def is_cross_filesystem(src, dst):
  return os.stat(src).st_dev != os.stat(os.path.dirname(dst)).st_dev
Common Mistake

Assuming move is instantaneous and atomic. Always plan for the copying fallback and handle errors.
