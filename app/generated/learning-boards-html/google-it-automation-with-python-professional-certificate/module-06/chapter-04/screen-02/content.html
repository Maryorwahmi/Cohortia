Learning Objectives
Learn the concrete skills that make file automation and log parsing reliable and repeatable.
01
Copy and archive directories
Use shutil.copy, copytree, and make_archive to create backups and deployment packages. This ensures metadata and common errors are handled.
Mnemonic: folder → duplicate → zip
VERIFIED COMPETENCY MILESTONE
02
Move and rename files safely
Use shutil.move with existence checks and exception handling to avoid data loss during renames or cross-filesystem transfers.
Mnemonic: check → move → confirm
VERIFIED COMPETENCY MILESTONE
03
Understand regex essentials
Learn metacharacters, groups, and raw strings so patterns are accurate and maintainable when parsing text.
Mnemonic: dot, star, group
VERIFIED COMPETENCY MILESTONE
04
Apply regex to logs and renames
Use re.search, findall, and sub in scripts to extract timestamps, error messages, and to perform bulk renames using patterns.
Mnemonic: find → extract → replace
VERIFIED COMPETENCY MILESTONE
