Core Concept

Shutil: higher-level file operations

Shutil wraps common file-system tasks so your automation can be shorter and safer than manual copying or walking directories.

shutil.copy(src, dst) — copy a file and preserve metadata where possible.
shutil.copytree(src, dst) — recursively copy an entire directory tree.
shutil.move(src, dst) — move or rename; handles cross-filesystem moves by copying then removing.
shutil.make_archive(base_name, format, root_dir) — create zip or tar archives.
Key Takeaway

Shutil reduces boilerplate for common file operations but does not replace the need for checks and exception handling.

Concrete example
Create a zip archive of a logs folder for nightly backup.
import shutil

# make a zip archive of the 'logs' directory
archive_path = shutil.make_archive('logs_backup', 'zip', 'logs')
print('Created archive:', archive_path)
Common mistake: calling copytree when the destination already exists. copytree will raise an error unless you handle or remove the target first.
Pro tip: check os.path.exists(target) before calling a write operation to avoid accidental overwrites.
