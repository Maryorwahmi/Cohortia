Comparison

Which re function to use?

re.search — first occurrence anywhere in the string.
re.match — match only at the start of the string.
re.findall — return all non-overlapping matches as a list.
re.sub — replace matching substrings with a replacement.
Examples
import re
line = "[2023-10-26 10:00:10] ERROR: Failed to connect"
print(re.search(r"ERROR", line))    # finds ERROR anywhere
print(re.match(r"\[\d{4}", line))  # matches if line starts with [YYYY
print(re.findall(r"\d{2}:\d{2}:\d{2}", line))  # all timestamps
print(re.sub(r"'prod_db'", "''", line))  # redact literal
Common Mistake

Using match when the pattern might appear later in the string. Use search for anywhere matches.
