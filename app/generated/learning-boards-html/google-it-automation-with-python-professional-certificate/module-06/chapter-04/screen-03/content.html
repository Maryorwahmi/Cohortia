Extended Objectives
Guardrails and debugging techniques make your automation trustworthy.
Existence checks & exception handling
Always check paths with os.path.exists and wrap shutil calls in try/except to catch IOError or OSError. This prevents unexpected failures and supports retries or safe logging.
Mnemonic: check -> try -> log
VERIFIED COMPETENCY MILESTONE
Incremental regex building
Start with a simple pattern and add groups or quantifiers stepwise. Use raw strings to avoid double-escaping and test against representative samples.
Mnemonic: small → test → expand
VERIFIED COMPETENCY MILESTONE
Rename safely with patterns
When renaming by pattern, preview matches first, then perform moves. Adding a processed suffix helps prevent repeated processing.
Mnemonic: preview → rename → confirm
VERIFIED COMPETENCY MILESTONE
Archiving for rollback
Use make_archive to produce a zip or tar that can be restored. Always keep a copy until you confirm downstream steps completed successfully.
Mnemonic: backup → run → remove
