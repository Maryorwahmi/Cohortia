Log Levels (brief)
  1. DEBUG — detailed diagnostic information
  2. INFO — routine messages that confirm things are working
  3. WARNING — an indication of something unexpected
  4. ERROR — serious problem preventing an operation
  5. CRITICAL — severe error causing premature termination
Handler Example
# console: INFO (or DEBUG if verbose)
console_handler.setLevel(logging.DEBUG if verbose else logging.INFO)
# file: INFO always
file_handler.setLevel(logging.INFO)
Design handlers to capture the right detail level for each audience: operators on console, auditors in files.
