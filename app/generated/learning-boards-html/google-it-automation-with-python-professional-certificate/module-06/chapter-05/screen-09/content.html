Cron Example
# Run daily at 3:30 AM
30 3 * * * /usr/bin/python3 /opt/scripts/backup_data.py --source /var/www/html --destination /mnt/backups/daily/ >> /var/log/backup_data.log 2>&1
Note the use of full paths and output redirection to capture both stdout and stderr.
Windows Task Scheduler
Task Scheduler can call a Python interpreter with similar flags or run a batch file. Ensure the account running the task has access to required files and network resources.
Checklist
Use absolute paths, test the scheduled environment, redirect output to a log file, and ensure required virtualenv or system packages are available to the scheduler’s runtime.
