Module 6 › Chapter 6.5 › Learning Objectives
Log Levels
Understand when to use DEBUG for detailed traces, INFO for normal operations, and ERROR or CRITICAL for failures that need attention. Configure handlers so that debug-level traces go to files while console remains concise.
Dependency Pinning
Generate requirements.txt with pip freeze to capture exact package versions so deployments are reproducible across environments.
Git Workflow
Commit early, use branches for features, and pull the stable version in production. This gives a history and rollback capability when changes introduce regressions.
Scheduling Considerations
When scheduling, ensure the environment has correct permissions and dependencies, and redirect stdout and stderr to log files so cron or Task Scheduler runs are auditable.
