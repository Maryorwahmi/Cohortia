Module 6 › Chapter 6.5 › Hands-on Activity
Starter Steps
  1. Create health_check.py with main() and guard.
  2. Add argparse flags for --verbose and --log-file.
  3. Implement setup_logging to add console and file handlers.
  4. Simulate checks and log INFO, DEBUG, and ERROR messages.
Expected Console & File Output
INFO: Starting system health check.
INFO: CPU usage: 20% (OK)
ERROR: Disk space on /var/log is critically low (95% used)!
INFO: Health check completed.
After verifying, create a crontab entry that runs the script and appends output to a persistent log file.
