Module 6 › Chapter 6.5 › Scheduler Environment
Checklist for Scheduled Jobs
  • Use full path to Python interpreter and script
  • Activate virtual environment if required
  • Ensure scheduler user has necessary permissions
  • Redirect stdout and stderr to a log file
Example Cron Command
/usr/bin/python3 /opt/scripts/health_check.py --log-file /var/log/health_check.log >> /var/log/health_check.log 2>&1
