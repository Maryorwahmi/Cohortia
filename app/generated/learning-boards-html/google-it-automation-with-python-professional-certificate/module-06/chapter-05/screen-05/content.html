Typical Arguments
  • --verbose — boolean flag to enable DEBUG logging
  • --log-file — path to write logs (default: health_check.log)
  • positional filename — file to process when required
Pro Tip
Provide helpful help text and sensible defaults so scheduled runs and human operators use the same interface.
Example: parser snippet
parser = argparse.ArgumentParser(description="Perform a system health check.")
parser.add_argument("--verbose", action="store_true", help="Enable verbose (DEBUG) logging to console.")
parser.add_argument("--log-file", default="health_check.log", help="Path to the log file.")
args = parser.parse_args()
Example Command
python3 health_check.py --verbose --log-file /var/log/health.log
Misconception
Don't hardcode file paths; flags allow different environments to reuse the same script safely.
