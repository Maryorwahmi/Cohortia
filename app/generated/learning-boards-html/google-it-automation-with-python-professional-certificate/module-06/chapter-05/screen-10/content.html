Module 6 › Chapter 6.5 › requirements.txt
Create requirements.txt
Run pip freeze > requirements.txt to capture the exact package versions used during development. Commit this file to your repository so deployments can reproduce the same environment.
Install on target
On the target machine, create a virtualenv or use the system Python, then run pip install -r requirements.txt. Verify that packages installed successfully before scheduling the script.
Note
Even if your script uses only built-in modules, include a minimal requirements.txt to document that choice and future dependencies.
