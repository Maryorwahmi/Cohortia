Standard Layout Pattern
  • main.py — entry point that parses args and calls main()
  • lib/ — reusable functions and business logic
  • config/ — configuration files and environment settings
  • logs/ — persistent log files written by logging handlers
Why this helps
It separates concerns so tests can import functions without executing the script, and deployment scripts can call main() programmatically.
Example: main guard
def main():
  # orchestrate checks and logging
  perform_health_check()

if __name__ == "__main__":
  main()
Example
Import lib.perform_health_check in tests without running main.
Misconception
Putting all logic in top-level script code makes testing and reuse difficult.
