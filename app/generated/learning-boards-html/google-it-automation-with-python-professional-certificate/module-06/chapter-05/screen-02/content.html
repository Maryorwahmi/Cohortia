01
Organize Project Structure
Break scripts into main, lib, config, and logs. This improves testability and reuse.
VERIFIED COMPETENCY MILESTONE
02
Accept Command-Line Arguments
Use argparse to provide flags, defaults, and help text so users run scripts flexibly.
VERIFIED COMPETENCY MILESTONE
03
Implement Robust Logging
Configure levels and handlers to write consistent timestamps and messages to files and console.
VERIFIED COMPETENCY MILESTONE
04
Schedule and Deploy
Create cron or Task Scheduler entries, manage dependencies with requirements.txt, and use Git for versioning.
VERIFIED COMPETENCY MILESTONE
Objective Details
  • Organize code into an entrypoint and reusable libraries so tests can import logic instead of running the script.
  • Use argparse to define typed flags, defaults, and helpful usage messages for administrators.
  • Replace prints with logging to capture severity, timestamps, and to separate console and file outputs.
  • Use requirements.txt to capture exact package versions and Git to manage changes and rollbacks during deployments.
Assessment Hint
You will verify competency by creating a script that accepts flags, logs actions to a file, and can be scheduled with a cron entry.
