Deployment Steps (recommended)
  1. Develop in a feature branch and write tests for logic files in lib/
  2. Merge to stable after testing and code review
  3. On the server, pull the stable branch and run pip install -r requirements.txt
  4. Restart scheduled jobs or ensure cron/Task Scheduler points to the updated script
Why branches
Isolate work and avoid unstable code on production.
Pitfall
Direct edits on production make history unclear and rollbacks harder.
