Key Concepts: Network Structure and Frame Types

Essential building blocks for Wi-Fi analysis

Basic Service Set (BSS)

An AP and its associated clients, identified by a unique BSSID (AP's MAC address).

Extended Service Set (ESS)

Multiple BSSs grouped together, sharing the same SSID (network name) for seamless roaming.

802.11 Frames

Basic units of Wi-Fi communication, categorized as Management, Control, and Data frames.

Summary Takeaway

Understanding the fundamental network structures like BSS and ESS, along with the distinct roles of Management, Control, and Data frames, is paramount for effective wireless analysis and troubleshooting.
