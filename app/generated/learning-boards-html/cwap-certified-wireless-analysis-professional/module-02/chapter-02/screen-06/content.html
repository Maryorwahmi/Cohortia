Definition

Beacon Frames: The Network's Lighthouse

How Access Points Announce Their Presence and Capabilities

Periodic Broadcasts

Sent by APs at regular intervals to advertise network availability.

Key Information

Contains SSID, supported data rates, security settings (WPA2/WPA3), and channel information.

Passive Scanning

Clients listen for beacons to build a list of available networks without actively transmitting.

BEACON CONTENT

SSID

Network Name

Data Rates

Supported Speeds

Security

Encryption Type

Key Takeaway

Beacon frames are the primary mechanism for APs to advertise their presence and capabilities, allowing clients to passively discover available Wi-Fi networks.
