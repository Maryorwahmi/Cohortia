Core Concept

Association: Establishing the Data Link

Connecting the Client to the Access Point for Data Exchange

Logical Link Creation

Establishes a dedicated communication channel for data exchange between client and AP.

Client Capabilities

Client sends its supported data rates, QoS capabilities, and encryption ciphers to the AP.

Association ID (AID)

AP assigns a unique identifier to the client upon successful association for management.

ASSOCIATION FLOW

Client: Assoc Request

Details capabilities.

AP: Assoc Response

Status code & AID.

Key Takeaway

Association is the final step in establishing a data link, where client capabilities are exchanged, and the AP assigns a unique Association ID (AID).
