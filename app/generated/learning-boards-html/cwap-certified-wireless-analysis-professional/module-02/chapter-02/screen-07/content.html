Active Discovery: Probe Requests and Responses

Clients Actively Searching for Networks and Their Implications

Probe Request

Sent by a client to actively search for a specific SSID or to discover all available networks (wildcard).

  • Can specify an SSID (e.g., "MyHomeNetwork")
  • Can be a wildcard (null SSID) to discover all
Privacy Concern

Probe requests can reveal a client's connection history, allowing malicious actors to track device movements and discover hidden SSIDs.

Probe Response

Sent by an AP in direct reply to a Probe Request, containing network information similar to a beacon frame.

  • Direct reply to client's query
  • Includes SSID, data rates, security capabilities
Key Takeaway

Probe requests and responses facilitate active network discovery, but their broadcast nature can expose client connection history and hidden SSIDs, raising privacy concerns.
