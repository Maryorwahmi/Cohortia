Wireshark Lab: Tracing a Client Connection

Identifying the Full 802.11 Connection Flow in a Capture

Connection Sequence Steps

  • **Capture/Load Traffic:** Start with a `.pcap` file showing a client connecting.
  • **Filter Management Frames:** Apply `wlan.fc.type == 0` and sort by time.
  • **Identify Beacons:** Locate AP broadcasts, note SSID, channel, security.
  • **Find Probes:** Observe client Probe Requests and AP Probe Responses.
  • **Examine Authentication:** Identify Auth Request/Response, check algorithm.
  • **Analyze Association:** Locate Assoc Request/Response, check capabilities, status, AID.
Key Takeaway

Chronologically analyzing management frames in Wireshark provides a clear picture of the 802.11 connection process, enabling precise troubleshooting.

Analyzing Frame Details

  • **Expand Layers:** In Wireshark, expand "IEEE 802.11 wireless LAN" and the specific frame type.
  • **Information Elements (IEs):** Examine IEs like SSID Parameter Set, Supported Rates, RSN Information (for security), and Capability Information.
  • **Status Codes:** For Association Responses, check the status code for reasons of failure.
Common Mistake

Overlooking the distinction between 802.11 authentication and higher-layer network access authentication can lead to misdiagnosis of connectivity issues.
