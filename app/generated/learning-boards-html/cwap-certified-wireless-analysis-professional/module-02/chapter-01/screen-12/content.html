ToDS and FromDS Flags: Pinpointing Frame Direction

Interpreting the critical flags that indicate a frame's path relative to the Distribution System.

ToDS (To Distribution System)

When ToDS is 1, the frame is destined for the wired network via the Access Point (client to AP).

FromDS (From Distribution System)

When FromDS is 1, the frame originated from the wired network and is sent wirelessly to a client (AP to client).

Context is Key

These flags are crucial for correctly interpreting the roles of MAC addresses and the overall flow of traffic.

Key Takeaway

ToDS and FromDS flags are indispensable for accurately determining the direction and context of 802.11 frames in a BSS or ESS.

Interpreting ToDS and FromDS Flags
ToDS = 0, FromDS = 0IBSS (Ad-Hoc) or Management/Control Frames
ToDS = 1, FromDS = 0Client to AP (Uplink)
ToDS = 0, FromDS = 1AP to Client (Downlink)
ToDS = 1, FromDS = 1WDS (Wireless Distribution System)
Example: Client Uploading a File

A data frame from a client uploading a file to a server would have ToDS=1, FromDS=0, indicating it's going to the AP.
