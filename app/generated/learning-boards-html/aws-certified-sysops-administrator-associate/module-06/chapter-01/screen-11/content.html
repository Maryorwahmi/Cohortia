Module 6 › Chapter 6.1 › Mistakes & Best Practices
Common mistakes
  • Using root for daily tasks or storing root access keys.
  • Attaching AdministratorAccess where narrow policies suffice.
  • Embedding long-lived keys on instances instead of using roles.
  • Not enforcing MFA for privileged users.
Best practices
  • Create an administrative IAM user and secure the root account with MFA.
  • Use roles for services, groups for users, and customer-managed policies for reuse.
  • Rotate keys and monitor CloudTrail for unusual behavior.
Pro tip
Automate policy reviews and use IAM Access Analyzer to detect unintended access. Treat IAM as config that must be maintained, not set-and-forget.
Common mistake alert
Avoid attaching wide policies like s3:* or AdministratorAccess for convenience; they expand attack surface and complicate investigations.
