Concept Map
Identities
User: named identity with credentials
Group: collection of users
Role: assumable identity for temporary permissions
Policies & Practices
Policies express allowed or denied actions on resources. Best practices include MFA, least privilege, roles for services, and groups for admin ease.
Quick Reference
Root user
Avoid daily use; enable MFA and protect credentials.
Roles for services
Preferred over embedded keys for EC2, Lambda, and ECS.
