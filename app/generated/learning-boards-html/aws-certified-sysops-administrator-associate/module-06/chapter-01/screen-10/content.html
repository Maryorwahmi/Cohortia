Module 6 › Chapter 6.1 › MFA
Why MFA matters
It prevents single-credential compromise from resulting in account takeover, especially for highly privileged accounts.
Enable MFA on the root account immediately. Enforce MFA for administrative roles and sensitive API calls. Consider using MFA as a condition in policies so certain actions require a second factor even for authenticated users.
Example
Require MFA to delete production resources by adding an MFA condition to the policy that denies actions unless MFA is present.
Recovery planning
Have documented device recovery processes to avoid lockout while keeping security controls intact.
Quick actions
  • Enable root MFA now.
  • Require MFA for admin users and roles.
  • Add MFA condition to sensitive policies where possible.
Key Takeaway

MFA significantly reduces the attack surface for privileged accounts; enable it and include it in policy conditions for critical operations.
