Definition

IAM User explained

An IAM user is a named account for a person or external service. It can hold a console password and access keys for programmatic access. Best practice: prefer MFA and rotate keys.

Concrete example
A developer account with console access and membership in a group that grants EC2 management rights. The user has MFA enabled and keys rotated monthly.
Common misconception
Treating users as the default for automated services. Instead, use roles for AWS services to avoid long-lived credentials on instances.
Key Takeaway

Use IAM users for people or external systems; enforce MFA, rotate keys, and minimize privileges.

Credential Examples
Console password: human access Programmatic keys: access key ID + secret access key Rotate keys: replace old keys and remove unused ones
Quick checklist
  • Enable MFA for user accounts.
  • Attach permissions via groups, not directly.
  • Avoid embedding keys on EC2; use roles instead.
Mnemonic
User = Person. Remember: users represent named human or external identities.
