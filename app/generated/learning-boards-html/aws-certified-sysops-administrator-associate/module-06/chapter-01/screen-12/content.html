Module 6 › Chapter 6.1 › Hands-on: EC2 Role for S3
Terminal steps (conceptual)
Follow these steps and substitute your unique bucket name where needed. The commands below are the exact sequence used in the activity description.
# 1. Create S3 bucket and upload a test file
aws s3 mb s3://my-sysops-app-data-unique-name-123 --region us-east-1
echo "Hello from S3!" > index.html
aws s3 cp index.html s3://my-sysops-app-data-unique-name-123/

# 2. Policy json (s3-readonly-policy.json)
{ "Version": "2012-10-17", "Statement": [ { "Effect": "Allow", "Action": [ "s3:GetObject", "s3:ListBucket" ], "Resource": [ "arn:aws:s3:::my-sysops-app-data-unique-name-123", "arn:aws:s3:::my-sysops-app-data-unique-name-123/*" ] } ] }

# 3. Create policy via CLI
aws iam create-policy --policy-name S3AppReadOnlyPolicy --policy-document file://s3-readonly-policy.json

# 4. Trust policy for EC2 (ec2-trust-policy.json)
{ "Version": "2012-10-17", "Statement": [ { "Effect": "Allow", "Principal": { "Service": "ec2.amazonaws.com" }, "Action": "sts:AssumeRole" } ] }

# 5. Create role and attach policy
aws iam create-role --role-name EC2S3ReaderRole --assume-role-policy-document file://ec2-trust-policy.json
aws iam attach-role-policy --role-name EC2S3ReaderRole --policy-arn arn:aws:iam::YOUR_ACCOUNT_ID:policy/S3AppReadOnlyPolicy

# 6. Launch EC2 and select EC2S3ReaderRole

# 7. On the instance, test access
aws s3 ls s3://my-sysops-app-data-unique-name-123/
aws s3 cp s3://my-sysops-app-data-unique-name-123/index.html .
# This should fail:
aws s3 ls
Remember to replace YOUR_ACCOUNT_ID and use a globally unique bucket name. After testing, remove any temporary resources and confirm the role’s policy grants only the required actions.
Example explanation
The created role allows EC2 instances to obtain temporary credentials and read objects from only the specified bucket. Attempts to list all buckets should fail because the policy does not grant s3:ListAllMyBuckets.
Key Takeaway

Use a role with a narrowly scoped policy to avoid long-lived keys on instances; test that only the intended bucket is accessible.
