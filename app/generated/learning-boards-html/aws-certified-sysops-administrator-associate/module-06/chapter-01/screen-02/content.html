Module 6 › Chapter 6.1 › Learning Objectives
01
Describe IAM core components
Define users, groups, roles, and policies and explain how they map to people, teams, services, and resources. This matters because accurate mapping prevents unintended access via misapplied permissions.
VERIFIED COMPETENCY MILESTONE
02
Differentiate policy types
Identify identity-based, resource-based, AWS managed, customer managed, and inline policies and pick the right attachment point for your use case to simplify audits.
VERIFIED COMPETENCY MILESTONE
03
Implement least privilege
Apply the least privilege principle by scoping actions and resources narrowly. Example: grant only s3:GetObject on a single bucket rather than broad s3:* permissions.
VERIFIED COMPETENCY MILESTONE
04
Enable MFA and avoid root misuse
Configure MFA for root and privileged IAM users and adopt roles for automation. This reduces risk from compromised passwords or leaked keys.
VERIFIED COMPETENCY MILESTONE
