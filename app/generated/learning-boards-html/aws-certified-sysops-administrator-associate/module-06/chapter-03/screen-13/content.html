Module 6 › Chapter 6.3 › Mistakes & Practices
Hardcoding secrets

Never store credentials in source or images. Retrieve secrets at runtime from Secrets Manager or Parameter Store.

Overly broad key policies

Grant only required KMS actions and keep key policies granular to reduce blast radius.

Assuming encryption is enough

Combine encryption with access control, rotation, and audit logging to meet security objectives.

Practical checklist
  • Automate CMK and bucket creation in IaC.
  • Grant least-privilege KMS access to application roles.
  • Use Secrets Manager for rotating credentials where supported.
  • Script validation and audit checks against CloudTrail.
