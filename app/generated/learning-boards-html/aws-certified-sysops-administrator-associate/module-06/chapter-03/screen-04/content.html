Module 6 › Chapter 6.3 › Client vs Server Encryption
Definition

Client-side encryption

Encrypt data before sending it to AWS. You manage keys and encryption lifecycle.

Concrete example: Encrypt artifacts in a CI pipeline before uploading to S3 so only your application can decrypt them.
Common mistake: Assuming encryption removes the need for strict key storage and rotation.
Key takeaway: You gain control but inherit full operational responsibility.
Definition

Server-side encryption

AWS service encrypts data before persisting it. Options include SSE-S3, SSE-KMS, SSE-C depending on how you supply keys.

Concrete example: Enable default SSE-KMS on an S3 bucket to have objects encrypted with a KMS CMK automatically.
Misconception: Server-side encryption alone prevents unauthorized reads. Access to the object and KMS key must still be controlled.
Key takeaway: Easier to operate but you must manage IAM and key policies.
