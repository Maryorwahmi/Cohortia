Module 6 › Chapter 6.3 › Rotation & Access Control
Rotation

Enable automatic rotation for customer-managed symmetric CMKs to update cryptographic material annually. Understand this updates future operations while keeping existing data decryptable via retained material.

Benefit: Reduces the risk window if key material is exposed.
Misconception: Rotation re-encrypts all data immediately. It does not.
Access Control
  • Use KMS key policies to set resource-level grants.
  • Use IAM identity policies to permit specific KMS actions like kms:GenerateDataKey.
  • Audit with CloudTrail to see who used your keys and when.
