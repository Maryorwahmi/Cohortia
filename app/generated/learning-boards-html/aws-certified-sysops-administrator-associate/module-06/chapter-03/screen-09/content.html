RDS encryption rules
  • Encryption must be enabled at instance creation.
  • Encrypted instances have encrypted backups, snapshots, and read replicas.
  • To migrate from unencrypted to encrypted, snapshot, copy with encryption enabled, and restore.
Scenario
You have a production database that must be encrypted for compliance. Plan deployment pipelines to create encrypted instances to avoid snapshot-and-restore migration work.
