Module 6 › Chapter 6.3 › Secrets Manager vs Parameter Store
AWS Secrets Manager

Secrets with rotation

Designed to store credentials and supports automatic rotation for supported databases and services. Integrates with IAM for access control.

Example
Create a secret for a DB password and enable rotation so credentials change automatically on schedule.
Parameter Store

Hierarchical configuration & encrypted parameters

Store configuration values and encrypted parameters using KMS. Good for non-rotating secrets and hierarchical app settings.

Example
Store API endpoints and feature flags, or encrypted parameters for values rotated outside the service.
