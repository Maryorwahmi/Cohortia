Module 6 › Chapter 6.3 › Hands-on Activity
Activity Steps
  1. Create a KMS CMK and alias; note the ARN.
  2. Create an S3 bucket and enable default SSE-KMS with the CMK ARN.
  3. Upload a file and verify encryption metadata.
  4. Create a secret in Secrets Manager and retrieve it via the CLI.
  5. Enable rotation if the secret type is supported, and validate rotation events.
Starter CLI snippets
aws kms create-key --description "KMS key for S3 bucket encryption"
aws kms create-alias --alias-name alias/MyS3EncryptionKey --target-key-id YOUR_KMS_KEY_ID

aws s3api put-bucket-encryption --bucket my-kms-encrypted-data-unique-name-123 \
  --server-side-encryption-configuration '{"Rules":[{"ApplyServerSideEncryptionByDefault":{"SSEAlgorithm":"aws:kms","KMSMasterKeyID":"arn:aws:kms:YOUR_REGION:YOUR_ACCOUNT_ID:key/YOUR_KMS_KEY_ID"}}]}'

aws secretsmanager create-secret --name "MyApplicationDBPassword" --description "Database password for MyApplication" --secret-string '{"username":"dbuser","password":"SuperSecurePassword!23"}'
