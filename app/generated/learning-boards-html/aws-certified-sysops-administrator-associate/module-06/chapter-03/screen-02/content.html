Learning Objectives

Four measurable skills to practice and verify.

Learn → Understand → Apply → Master
01
Differentiate client vs server encryption

Recognize who manages keys and where encryption occurs. Example: encrypt before upload versus relying on S3 to encrypt on write.

VERIFIED COMPETENCY MILESTONE
02
Explain AWS KMS roles and integration

Describe CMKs, symmetric vs asymmetric keys, and how services request data keys from KMS for encryption and decryption.

VERIFIED COMPETENCY MILESTONE
03
Implement server-side encryption

Enable default SSE-KMS or SSE-S3 on S3, enable EBS and RDS encryption at creation, and verify encryption of snapshots and backups.

VERIFIED COMPETENCY MILESTONE
04
Use Secrets Manager and Parameter Store

Store credentials and configuration securely. Choose Secrets Manager for rotating credentials and Parameter Store for hierarchical configuration values.

VERIFIED COMPETENCY MILESTONE
