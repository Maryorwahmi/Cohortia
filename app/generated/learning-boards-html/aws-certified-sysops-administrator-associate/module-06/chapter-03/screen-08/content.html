Module 6 › Chapter 6.3 › EBS Encryption
Steps
  1. Create volumes with encryption enabled or enable default encryption for the region.
  2. Use encrypted snapshots to create new volumes; encryption will be preserved.
  3. To encrypt an existing unencrypted volume, create a snapshot and then copy it while enabling encryption.
Key Takeaway

Encryption travels with snapshots and volumes. Plan defaults so new resources are encrypted automatically.

Checks & Missteps
  • Verify snapshots are encrypted and the KMS key ID associated with them.
  • Do not assume an unencrypted snapshot can be retrofitted without creating an encrypted copy.
  • Control who can copy snapshots; copying can change encryption settings if allowed by policy.
