Validation checklist

KMS key creation

Create CMK, assign alias, and confirm key ARN. Ensure the key policy allows intended principals.

S3 default encryption

Enable bucket default SSE-KMS and upload an object to verify the x-amz-server-side-encryption header or console property.

EBS / RDS checks

Confirm encrypted snapshots, backups, read replicas, and that new volumes honor encryption by default.

Practice these steps until you can script them, then include them in CI or daily checks.
