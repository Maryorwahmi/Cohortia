Module 6 › Chapter 6.3 › SSE Options
SSE-S3

S3-managed keys

AWS manages keys and rotation. Good for many compliance needs when key control is not required.

SSE-KMS

KMS-managed keys

Use a CMK in KMS. Gain auditing, access control, and optional automatic rotation of symmetric keys.

SSE-C

Customer-provided keys

You supply the encryption key with each request. AWS does not store the key. High control, high responsibility.

Decision points
  • Need audit logs and fine-grained key access → choose SSE-KMS.
  • Want simple encryption with no key management → SSE-S3 is fine.
  • Need absolute control of key material → SSE-C but plan key rotation and secure distribution.
