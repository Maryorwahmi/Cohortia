Module 6 › Chapter 6.5 › Incident Response
Four-step workflow
1. Detection — GuardDuty creates a finding.
2. Notification — EventBridge rule routes events.
3. Alerting — SNS notifies teams by email, SMS or pager.
4. Remediation — Lambda executes pre-approved actions if safe.
Concrete example
Compromised instance flow
GuardDuty finding → EventBridge rule (filters high severity) → SNS alerts on-call → Lambda creates EBS snapshot, modifies SG to isolate instance, and stops it with logs for review.
Key Takeaway

Design workflows with gates and reversible steps. Automate to reduce response time but always include human review for high-impact operations.
