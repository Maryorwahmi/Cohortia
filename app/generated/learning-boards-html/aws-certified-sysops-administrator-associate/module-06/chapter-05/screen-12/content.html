Remediation checklist
  • Confirm the finding's resource and severity before acting.
  • Enforce sandbox or test tags for automatic actions.
  • Create snapshots and log metadata for forensic needs.
  • Provide rollback steps and metrics for success/failure.
Small code example (conceptual)
def handler(event, context):
  # Validate severity and resource tag
  finding = event['detail']
  if finding['severity'] < 6:
    return 'Ignored: low severity'
  # Check for test account tag
  if not is_test_resource(finding['resource']):
    return 'Requires manual review'
  snapshot_volume(finding['resource'])
  isolate_instance(finding['resource'])
  log_action(finding)
Precautions
  • Use least-privilege IAM roles for Lambda.
  • Include dry-run modes and manual gates for production.
  • Test thoroughly in sandbox accounts with representative data.
Pro tip

Design small, single-purpose remediations that are auditable and reversible. Monitor their metrics and failures closely.
