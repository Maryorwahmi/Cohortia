Module 6 › Chapter 6.5 › EventBridge & SNS
Routing pattern
GuardDuty → EventBridge (rule filters by type/severity) → SNS topic → On-call notifications
Filtering tips
  • Filter on severity thresholds to reduce noise.
  • Use detail-type and resource identifiers to route by team ownership.
  • Fan-out to multiple targets for parallel handling.
Alert message content
Include finding summary, severity, resource ARNs, timestamps, and suggested next steps. Provide direct links to runbooks and include forensic snapshot references if taken automatically.
Key Takeaway

EventBridge and SNS provide reliable delivery and filtering. Use them to balance automation with human oversight and to ensure auditable notification trails.
