Module 6 › Chapter 6.5 › Shared Responsibility
AWS responsibilities
  • Physical security, host infrastructure, and foundational services.
  • Service availability and data center controls.
Customer responsibilities
  • Resource configuration (EC2, S3, IAM), detection enablement, and incident response.
  • Runbooks, remediation testing, and forensic preservation.
Proactive operational habits
  • Regularly review GuardDuty and Security Hub findings and tune rules.
  • Run tabletop exercises for incident response paths and automated remediation.
  • Keep Config rules current and audit non-compliant histories frequently.
Key Takeaway

Detection tools are powerful but require operational commitment: tune, review, test, and update your response plans regularly.
