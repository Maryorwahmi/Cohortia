Module 6 › Chapter 6.5 › GuardDuty
What GuardDuty analyzes
  • VPC Flow Logs — network traffic patterns and unusual flows.
  • CloudTrail management and S3 data events — API calls and object access.
  • DNS logs — suspicious domain lookups or exfiltration signals.
Sample findings
Compromised EC2 performing cryptomining
Unauthorized S3 access or exposed bucket
API calls from unusual geographical locations
Why agentless matters

Agentless detection reduces operational effort and speeds rollout across accounts because you do not need to install and maintain agents on every host. GuardDuty evaluates central logs and telemetry instead.

Triage advice
  • Check resource identifiers and timestamps on the finding.
  • Correlate with Config and CloudTrail records for recent configuration changes and API activity.
  • Use severity and type to decide containment steps and escalation.
Key Takeaway

Treat GuardDuty findings as prioritized leads. Use them to guide investigation and, when validated, to trigger notifications or remediation flows.
