Module 6 › Chapter 6.5 › Practice & Safety
Practice actions
  1. Enable GuardDuty and view sample findings to learn fields and severities.
  2. Enable Security Hub and check aggregation and mapped standards.
  3. Create an AWS Config rule and wait for evaluation of existing resources.
  4. Generate a test non-compliant resource and observe the alerts.
Safety checklist
  • Run tests in isolated accounts or with tagged test resources.
  • Limit automated actions to reversible steps in early tests.
  • Document triggers and have rollback plans for any Lambda remediation.
  • Log all actions and preserve forensic snapshots when isolating resources.
Note

Automated remediation is powerful but must be bounded by severity and safety checks. Treat automation as a way to buy time for humans, not to replace them entirely.
