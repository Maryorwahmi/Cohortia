Module 6 › Chapter 6.4 › AWS WAF
Definition

AWS WAF

Web Application Firewall that evaluates HTTP requests against rules and Web ACLs to block common application-layer attacks.

Example rule
Block requests with SQL injection signatures or enforce a rate limit on suspicious IP addresses to reduce automated abuse.
Deployment targets
CloudFront, ALB, API Gateway, AppSync.
Why it matters
Application-layer attacks bypass network filters; WAF inspects request content to block them before they reach backends.
Key Takeaway
Use WAF for application-layer defenses and tune rules to balance protection and false positives.
