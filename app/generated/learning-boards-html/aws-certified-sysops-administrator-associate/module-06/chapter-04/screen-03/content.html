Practice & Monitoring Objectives

Concrete operational steps to validate your network security posture.

Deploy and Secure an EC2 Web Server

Launch an instance in a public subnet, attach a Security Group with SSH and HTTP rules, and verify only required ports are open.

VERIFIED COMPETENCY MILESTONE
Configure a Custom NACL

Add ordered allow/deny rules and explicitly include ephemeral ports for return traffic so stateful behavior is preserved across the layer boundary.

VERIFIED COMPETENCY MILESTONE
Enable and Analyze Flow Logs

Send VPC Flow Logs to CloudWatch, search for REJECT entries, and confirm whether security groups or NACLs are blocking expected traffic.

VERIFIED COMPETENCY MILESTONE
Private Connectivity & Central Policy

Practice using Gateway Endpoints, Interface Endpoints, and Firewall Manager to keep traffic private and enforce consistent rules at scale.
