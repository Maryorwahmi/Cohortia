Network Security in AWS

Practical controls and monitoring patterns every SysOps administrator should master.

Interactive 16:9 Masterclass
In this lesson
Instance & subnet controls, monitoring, web protection, private connectivity, and central policy.
Why it matters
Correct placement of controls preserves availability while limiting attack surface.
Start here

Begin by mapping which resources need instance-level controls and which protections can be applied at subnet or edge layers. Use flow logs early to validate rules.

Concept map
Security Groups — stateful instance firewall
NACLs — stateless subnet filters
VPC Flow Logs — capture ACCEPT/REJECT
These layers combine with WAF, Shield, Endpoints, and Firewall Manager for defense in depth.
Explore Key Topics
Security Groups vs NACLs — instance vs subnet controls and stateful vs stateless behavior.
VPC Flow Logs — use them to find rejects and confirm allowed flows.
WAF, Shield, Endpoints — protect web apps and keep traffic off the public internet.
