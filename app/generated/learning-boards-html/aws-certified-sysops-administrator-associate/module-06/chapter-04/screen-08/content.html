Install and start Apache (Amazon Linux 2)

Run these commands after SSHing into your EC2 instance. They update packages, install the web server, start it, and create a test index page.

<!-- Run on the EC2 instance shell -->
sudo yum update -y
sudo yum install -y httpd
sudo systemctl start httpd
sudo systemctl enable httpd
echo "<h1>Hello from my secure EC2!</h1>" | sudo tee /var/www/html/index.html

# Test from your laptop
curl http://<EC2_PUBLIC_IP>/
If curl returns the page, HTTP is allowed. If SSH fails, check Security Group and NACL rules and inspect VPC Flow Logs for REJECT entries indicating which layer blocked traffic.
Example
Attach WebServerSG that allows SSH from your IP and HTTP from 0.0.0.0/0. Use a NACL that permits inbound 80 and 22 and outbound ephemeral ports.
Key Takeaway
Basic installation plus network rule confirmation is an effective first-step health check for network security in AWS.
