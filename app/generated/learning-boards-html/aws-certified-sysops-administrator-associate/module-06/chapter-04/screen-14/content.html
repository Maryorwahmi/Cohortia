Module 6 › Chapter 6.4 › Key Concepts
Security Group
Instance-level, stateful firewall with allow-only rules to enforce least privilege.
Network ACL (NACL)
Stateless subnet filters supporting Allow and Deny, evaluated by rule number; return traffic must be allowed explicitly.
VPC Flow Logs
Records traffic to/from ENIs showing source/destination and ACCEPT or REJECT for troubleshooting and audit.
Summary takeaway
Apply layered controls: use Security Groups for fine-grained access, NACLs for perimeter denies, and Flow Logs to diagnose why traffic fails.
