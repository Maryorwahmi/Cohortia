Module 6 › Chapter 6.4 › Key Concepts
AWS WAF
Application-layer filtering for HTTP/HTTPS to block SQLi, XSS, and other request-based attacks.
AWS Shield
Managed DDoS protections: Standard for baseline, Advanced for higher visibility and response support.
VPC Endpoints & PrivateLink
Gateway endpoints for S3/DynamoDB and interface endpoints via PrivateLink to access services privately.
Summary takeaway
Map protections to the correct layer: use network controls, application inspection, private endpoints, and centralized policy to maintain a secure, scalable environment.
