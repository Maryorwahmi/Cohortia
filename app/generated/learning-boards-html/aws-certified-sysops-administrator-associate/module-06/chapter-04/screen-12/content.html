Architecture

Gateway Endpoint (S3/DynamoDB)

A gateway object you target in a route table so traffic to supported services stays within AWS and does not require an internet path.

Example
Create a Gateway Endpoint for S3 and update private subnet route tables so EC2 instances retrieve objects without NAT or internet gateway.
Architecture

Interface Endpoint & PrivateLink

Creates ENIs with private IPs in your subnets to access supported AWS services or partner services without traversing the public internet.

Example
Consume a SaaS API via PrivateLink. The provider exposes a service endpoint; you create an interface endpoint that appears as a private IP in your VPC.
Security tip
Protect interface endpoints with Security Groups and apply endpoint policies to restrict access.
When to use
Gateway endpoints for S3/DynamoDB; Interface endpoints for other services and PrivateLink integrations.
Key Takeaway
Endpoints keep traffic private and simplify architectures, but still require access controls at the ENI level.
