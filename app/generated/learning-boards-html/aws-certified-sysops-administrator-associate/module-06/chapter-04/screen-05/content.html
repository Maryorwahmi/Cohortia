Module 6 › Chapter 6.4 › Network ACLs
Definition

Network Access Control Lists (NACLs)

Stateless filters attached to subnets that evaluate numbered rules in order. They can explicitly allow or deny traffic.

Key behaviors
  • Stateless: return traffic must be explicitly allowed.
  • Both Allow and Deny rules are supported, evaluated by rule number.
  • Default NACL allows all; custom NACL denies unless allowed.
Example rules
Rule 100: Allow TCP 80 from 0.0.0.0/0
Rule 110: Allow TCP 22 from 203.0.113.0/32
Rule 120: Allow TCP 1024-65535 from 0.0.0.0/0 (ephemeral)
Common mistake
Forgetting to allow ephemeral ports for outbound return traffic, causing SSH or HTTP sessions to fail despite allowed inbound rules.
Key Takeaway

Use NACLs for coarse-grained subnet boundaries and always add return rules for stateless behavior.

Ordered evaluation
NACLs evaluate from lowest rule number to highest. If a deny matches early, later allows are not considered. Design rules deliberately and test by generating traffic and inspecting flow logs for REJECT entries.
