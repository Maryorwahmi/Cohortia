Module 6 › Chapter 6.4 › SG vs NACL
Comparison

Security Groups

  • Stateful, allow-only rules.
  • Applied to ENIs or resources like EC2, RDS, ALB.
  • Best for least-privilege, service-level policies.
Use-case: Allow database access only from application servers by referencing a security group.
Comparison

Network ACLs

  • Stateless; explicit return rules required.
  • Supports Allow and Deny; ordered by rule number.
  • Applied to subnets; good for perimeter filtering.
Use-case: Block traffic from a malicious CIDR across the entire subnet before it reaches instances.
Rule of thumb
Security Groups first for service control; NACLs for broader network-level denies.
Pitfall
Assuming NACL return traffic is automatic; forgetting ephemeral port rules is the top cause of failures.
Check
Use VPC Flow Logs to find whether a Security Group or NACL caused a REJECT and act accordingly.
