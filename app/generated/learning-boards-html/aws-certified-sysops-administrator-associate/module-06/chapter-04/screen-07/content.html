Module 6 › Chapter 6.4 › Ephemeral Ports

Design NACL rules for return traffic

Follow this troubleshooting and design process when connections fail.

Step 1: Reproduce
Perform the failing operation so logs contain the relevant tuples.
Step 2: Inspect Flow Logs
Search for REJECT records, noting source/destination IPs and ports to identify which layer blocked the traffic.
Step 3: Update NACL
Add outbound rule allowing ephemeral range 1024-65535 or the needed narrower range for return traffic.
Concrete example
Inbound rule: Allow TCP 22 from 198.51.100.5/32. Outbound rule: Allow TCP 1024-65535 to 198.51.100.5/32 so SSH return packets are permitted.
Misconception
Believing allowing port 22 outbound is sufficient. The server replies from an ephemeral port, and that port must be allowed in the NACL.
Key Takeaway

Stateless NACLs require explicit return rules; plan for ephemeral ports and confirm behavior with flow logs.
