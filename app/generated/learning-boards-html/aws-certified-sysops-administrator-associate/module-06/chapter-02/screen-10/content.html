Module 6 › Chapter 6.2 › Auditing Tools
IAM Access Analyzer
Analyzes resource-based policies mathematically to report resources shared with external principals. Use it to detect public or cross-account access you did not intend.
  • Run after policy changes or regularly in CI/CD.
  • Remediate findings by tightening resource policies or adding conditions.
IAM Credential Report
Generate the CSV to inspect password last used, access key last used, and MFA status across users. This helps you find stale credentials and users missing MFA.
Commands
Generate and retrieve the report, then open the CSV to review each user's credential health.
Practical sequence
1) Run Access Analyzer for external sharing. 2) Generate credential report to find stale keys. 3) Prioritize remediation: external exposures first, then stale keys and missing MFA.
