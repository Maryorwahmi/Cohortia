Learning Objectives

Master the tools and patterns that make security continuous and automated.

01
Implement patch management
Create patch baselines and scheduled patching with Patch Manager to keep EC2 instances current and reduce exposure to known vulnerabilities.
Verified competency milestone
02
Use Amazon Inspector
Run automated scans for EC2 and container images, review prioritized findings, and plan remediation steps.
Verified competency milestone
03
Configure Config automated remediation
Detect non-compliance and trigger safe, tested remediation using Systems Manager Automation or Lambda.
Verified competency milestone
04
Design EventBridge+Lambda automations
Create event-driven responses for incidents, ensure least privilege, and implement robust logging and error handling.
Verified competency milestone
