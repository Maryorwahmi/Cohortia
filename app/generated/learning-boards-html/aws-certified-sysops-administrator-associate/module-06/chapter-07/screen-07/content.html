EventBridge and Lambda Architecture

Create event-driven remediations for incidents and scheduled housekeeping tasks.

Event sources
  • GuardDuty findings
  • AWS Config rule non-compliance
  • CloudTrail or CloudWatch alarms
  • Scheduled cron rules for housekeeping
Event routing
EventBridge rules pattern-match events and route them to Lambda with filtering and transformation if needed.
Remediation targets
Lambda functions execute targeted changes: isolate instances, rotate keys, tighten security groups, or call Systems Manager runbooks.
Event: GuardDuty high severity
EventBridge rule matches
Lambda isolates instance and snapshots
Design suggestions: make Lambda idempotent, log every action, use narrow IAM policies, and consider human approvals for high-impact fixes.
