Practice Scenarios

Question 1
Which service automates approved patches across EC2 instances and supports patch baselines for dev vs prod?
Answer: AWS Systems Manager Patch Manager. Remember to test patches in staging and schedule maintenance windows.
Question 2
Which combination allows Config to detect a violation and then correct it automatically?
Answer: AWS Config paired with Systems Manager Automation or AWS Lambda for automated remediation. Limit role permissions and test carefully.
Reflect: for each answer, name the testing, logging, and IAM practices you would apply.
