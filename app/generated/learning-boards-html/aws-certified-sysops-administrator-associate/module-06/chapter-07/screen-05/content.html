Amazon Inspector: Assess and Prioritize

Automate vulnerability scans and feed prioritized findings into your remediation pipeline.

What Inspector does
  • Scans EC2 instances (agent-based) and ECR images (image analysis).
  • Produces prioritized findings by severity so teams can triage.
  • Integrates with pipeline and ticket systems for remediation tracking.
Concrete workflow
Trigger image scans on push to ECR. If Inspector reports high severity, stop the image promotion and create a remediation ticket. For EC2, run scheduled scans and inspect agent reports.
Common misconception
Inspector findings are signals, not automatic fixes. Verify exploitability and prioritize remediation according to your environment and threat model.
High: Remote code execution in library X — urgent triage
Medium: Outdated dependency — plan patching
Low: Informational exposure — monitor
