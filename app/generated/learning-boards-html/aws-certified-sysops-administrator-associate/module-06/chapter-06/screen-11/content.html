Module 6 › Chapter 6.6 › AWS Audit Manager Overview
What Audit Manager does
Collects evidence automatically from CloudTrail, Config, and Security Hub and maps items to compliance framework controls.
Example
Collects CloudTrail events that show changes to IAM policies and associates them with a control requiring administrative change logging.
Limitations and best practice
Audit Manager automates collection but does not configure your services. Ensure CloudTrail, Config, and monitoring are enabled with the proper scope so Audit Manager has the evidence it needs.
Key Takeaway
Audit Manager streamlines audit preparation by gathering evidence and mapping it to controls, but it depends on correct configuration of the underlying AWS services.
