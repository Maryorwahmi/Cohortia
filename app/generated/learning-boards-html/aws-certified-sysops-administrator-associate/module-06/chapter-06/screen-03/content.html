Module 6 › Chapter 6.6 › Learning Objectives
Practical tasks
  1. Create encrypted S3 bucket with tight access controls to store CloudTrail logs.
  2. Create a multi-region CloudTrail trail delivering to S3 and CloudWatch Logs.
  3. Create CloudWatch Metric Filter and Alarm for root user activity and unauthorized API calls.
  4. Test by performing a root action and confirm logs, metric increments, and SNS notifications.
Why we test this
Testing confirms the entire pipeline: recording, delivery, indexing, detection, notification, and evidence retention. Auditors expect demonstrable proof and you must show both configuration and execution.
