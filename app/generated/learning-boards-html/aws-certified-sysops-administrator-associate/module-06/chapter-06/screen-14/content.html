Module 6 › Chapter 6.6 › Hands-on Activity: Root User Alarm
Steps (summary)
  1. Create metric filter in the CloudTrail log group using the root pattern.
  2. Map filter to metric namespace CloudTrailMetrics, name RootUserActivity.
  3. Create alarm when RootUserActivity > 0 and attach SNS topic for notifications.
  4. Test with a safe root action and confirm SNS email receipt.
Tip and cleanup
Record timestamps and sample events as evidence. If this was a test, delete the metric filter, alarm, SNS topic, and any temporary trail or S3 resources you created to avoid ongoing costs.
