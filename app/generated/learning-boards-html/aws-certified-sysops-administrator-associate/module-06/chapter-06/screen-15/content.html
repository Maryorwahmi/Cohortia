Module 6 › Chapter 6.6 › Key Concepts
AWS CloudTrail
Records API calls with identity, time, source IP, parameters, and responses for audits.
CloudTrail Trails
Control which events are logged and deliver logs to S3 and CloudWatch Logs.
CloudWatch Filters
Metric filters and alarms let you detect root activity and unauthorized operations in near real time.
Summary Takeaway

Configure multi-region trails to a centralized, encrypted bucket and stream to CloudWatch for alerts. Use Audit Manager to gather evidence and always validate the end-to-end pipeline to remain audit-ready.
