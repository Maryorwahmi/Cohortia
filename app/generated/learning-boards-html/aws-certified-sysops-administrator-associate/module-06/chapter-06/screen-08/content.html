Module 6 › Chapter 6.6 › CloudWatch Metric Filters and Alarms
Root user metric filter
{ ($.userIdentity.type = "Root") && ($.userIdentity.userName = "root") && ($.eventType != "AwsServiceEvent") }
Create a metric named RootUserActivity and an alarm that triggers when the count is greater than zero.
Unauthorized calls filter
{ ($.errorCode = "*UnauthorizedOperation") || ($.errorCode = "AccessDenied*") }
Use this to detect repeated access-denied errors that may indicate an attack or misconfigured policies.
Alarm configuration guidance
Create alarms with a static threshold greater than zero for sensitive metrics, and configure SNS topics for notifications. For noisy patterns, consider anomaly detection or additional filters to reduce false positives.
Testing tip
After setting an alarm, trigger a safe root action and confirm the alarm transitions to ALARM and an SNS email arrives. This validates the full alerting pipeline.
Key Takeaway
Metric filters convert log patterns into measurable metrics so you can alert and automate responses to security-relevant events.
