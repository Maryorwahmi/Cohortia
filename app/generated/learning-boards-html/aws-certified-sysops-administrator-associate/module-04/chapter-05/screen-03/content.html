Module 4 › Chapter 4.5 › Objectives — Lab
Lab outcomes to validate
Concrete checks you will perform in the walkthrough
Fleet Manager
Confirm the instance appears as managed; missing role or agent prevents this.
Run Command
Run AWS-RunShellScript to install httpd and verify the index page loads.
Parameter Store
Create a SecureString and retrieve it with the AWS CLI using with-decryption.
Session Manager
Open a session and run a diagnostic command; confirm logs to CloudWatch or S3.
Clean up
Delete the SecureString and optionally stop or remove the web server to avoid lingering resources.
