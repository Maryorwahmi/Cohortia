Create a SecureString
Use a hierarchical name and choose KMS encryption.
  1. Open Systems Manager → Parameter Store → Create parameter.
  2. Name: /my-app/db-connection-string; Type: SecureString.
  3. Choose KMS key source and enter the connection string value.
  4. Click Create parameter and note the name for retrieval.
Remember: plan for rotation and least-privilege access to decrypted values.
Retrieve with AWS CLI
aws ssm get-parameter --name /my-app/db-connection-string --with-decryption
Common error
If you see an access denied error, check that the caller's role has KMS decrypt permissions for the key used by SecureString.
