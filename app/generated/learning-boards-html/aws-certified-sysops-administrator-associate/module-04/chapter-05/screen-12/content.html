Where to send SSM output
CloudWatch Logs for fast search; S3 for durable archives.
  • Run Command: choose output options when running documents.
  • Session Manager: enable session logging to CloudWatch or S3.
  • Ensure IAM permissions let SSM write to chosen destinations.
Key Takeaway

Explicitly configure output and storage for Run Command and Session Manager to meet audit and troubleshooting needs.

Practical checklist
  • Create CloudWatch log groups and S3 buckets with proper encryption and lifecycle policies.
  • Grant SSM permission to write logs and objects.
  • Configure Run Command and Session Manager to use these destinations.
Misconception
SSM will not archive outputs by default; you must enable and configure the targets and retain policies to meet compliance requirements.
