Avoid these common mistakes
Practical checks to keep SSM reliable and secure
Missing IAM role
Agent without AmazonSSMManagedInstanceCore means instance will not be manageable.
Unencrypted secrets
Use SecureString with KMS instead of plain Strings for credentials.
No logging configured
Enable CloudWatch or S3 output for run and session logs for auditing.
Non-idempotent documents
Design documents to be safe for repeated scheduled execution by State Manager.
Tag instances and target associations by tag or resource group to scale management and reduce accidental targeting mistakes.
Pro tip

Automate checks: include a Step in your provisioning pipeline to validate the SSM Agent and instance profile before an instance becomes production-ready.
