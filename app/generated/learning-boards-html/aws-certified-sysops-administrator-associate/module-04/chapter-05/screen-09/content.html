Module 4 › Chapter 4.5 › Session Manager
Session Manager benefits
No SSH keys, no inbound ports, full session logs available.
Security
Outbound agent connections remove the need for inbound access rules.
Auditing
Send session logs to CloudWatch or S3 to maintain an audit trail of commands and output.
Requirements
SSM Agent installed and AmazonSSMManagedInstanceCore attached to the instance role.
Key Takeaway

Session Manager replaces bastion hosts for shell access while giving you an auditable record of activity.

Concrete scenario
Troubleshoot a production instance without opening SSH: start a Session Manager session, run diagnostic commands, and review the session log in CloudWatch.
Misconception
Session Manager does not remove the need for proper IAM controls; enforce least privilege and logging to avoid misuse.
