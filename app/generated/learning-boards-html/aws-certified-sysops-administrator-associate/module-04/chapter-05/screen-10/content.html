Module 4 › Chapter 4.5 › Install Apache — Lab
Step-by-step
  1. Verify instance appears as managed in Fleet Manager.
  2. Select Run Command and choose AWS-RunShellScript.
  3. Paste and run the provided script on your instance target.
  4. Monitor command status and inspect output; wait for Success.
  5. Open the instance public IP in a browser to verify the page.
Tip: If running across many instances, consider sending output to S3 for organized logs.
Script to run (paste into AWS-RunShellScript)
sudo yum update -y
sudo yum install -y httpd
sudo systemctl start httpd
sudo systemctl enable httpd
echo "<h1>Hello from SSM Run Command!</h1>" | sudo tee /var/www/html/index.html
Verification
When the command shows Success, visit the public IP of your instance to see the deployed index page and confirm the operation.
