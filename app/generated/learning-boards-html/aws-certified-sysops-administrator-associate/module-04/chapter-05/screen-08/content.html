Module 4 › Chapter 4.5 › Parameter Store
Parameter types
String · StringList · SecureString
String
Plain configuration values that are not sensitive.
StringList
Comma-separated lists that your application expects in order.
SecureString
Encrypted values using KMS; used for secrets like DB credentials.
Key Takeaway

Always use SecureString for sensitive data and control KMS permissions carefully.

Concrete example
Create /my-app/db-connection-string as a SecureString with your account’s KMS key. An application using the instance role with decrypt permission can call the SSM API to fetch the decrypted value at runtime.
CLI retrieval example
aws ssm get-parameter --name /my-app/db-connection-string --with-decryption
Note: Ensure callers have KMS decrypt permission for SecureString retrieval.
