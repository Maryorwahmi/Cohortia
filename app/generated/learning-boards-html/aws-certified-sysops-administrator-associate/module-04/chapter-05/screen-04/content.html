Module 4 › Chapter 4.5 › What is SSM?
Definition
SSM is a suite of capabilities for operational management across cloud and on-premises resources.
Control plane
Centralizes Run Command, State Manager, Parameter Store, and Session Manager.
Operational benefits
Automates patching, configuration, and auditing to reduce manual errors.
Integration
Works with IAM, CloudWatch, S3, and KMS for permissions, logging, and encryption.
Key Takeaway

SSM reduces the need for SSH and enables repeatable, auditable system operations at scale.

Analogy
Think of SSM as a remote operations console for your fleet. Instead of visiting each machine, you issue verified commands and policies from a single, auditable place.
Concrete example
Use Run Command to install httpd on many instances and confirm output. Use Parameter Store to place the database URL rather than embedding it in application code.
Misconception
SSM does not replace IAM; it relies on instance profiles and IAM policies to authorize actions.
