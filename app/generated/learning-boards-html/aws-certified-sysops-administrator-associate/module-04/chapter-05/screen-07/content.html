State Manager workflow
Association = SSM document + targets + schedule
Schedule an association
Choose targets by tag, resource group, or Auto Scaling group and set a cron-like schedule.
Compliance reporting
State Manager reports success or failure so you can detect drifted instances.
Idempotence
Design documents so repeated runs are safe and predictable.
Key Takeaway

State Manager enforces and reports on desired state so teams can automate compliance at scale.

Process steps
1. Create or select an SSM document (for example, AWS-RunPatchBaseline)
2. Choose targets by tag, resource group, or ASG
3. Set a schedule and execution options
4. Monitor compliance results and remediate failures
Concrete example
Schedule a monthly AWS-RunPatchBaseline association to apply security patches to instances tagged with environment:production and check compliance reports for any failures.
