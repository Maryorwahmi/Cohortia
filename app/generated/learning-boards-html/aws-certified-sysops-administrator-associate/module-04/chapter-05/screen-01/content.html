Why this matters

Managing hundreds of instances manually is error-prone. SSM centralizes tasks, enforces configuration, and logs actions so teams can operate reliably and securely without opening inbound management ports.

Common mistake

Forgetting to attach the AmazonSSMManagedInstanceCore policy prevents instances from showing as managed—SSM Agent alone is not sufficient.

Explore key topics

Open auditable shell sessions without inbound ports or SSH keys, improving security posture.

Quick start tip
Confirm the SSM Agent is installed and the instance role has AmazonSSMManagedInstanceCore before expecting an instance to be manageable.
