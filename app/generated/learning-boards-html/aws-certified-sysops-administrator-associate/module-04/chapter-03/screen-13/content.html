Module 4 › Chapter 4.3 › Lab: In-place Deployment
Step-by-step checklist
1. IAM Role
Create CodeDeployServiceRole and attach AWSCodeDeployRole.
2. Prepare bundle
index.html, appspec.yml, scripts/, chmod +x, zip at the correct level.
3. Upload
aws s3 cp my-web-app.zip s3://your-bucket/
4. Agent
Install and verify CodeDeploy agent on EC2, include in user-data for ASG.
5. Deployment Group
Create group targeting instance tag and choose in-place strategy.
6. Deploy & Verify
Start deployment and check instance public IP when succeeded.
