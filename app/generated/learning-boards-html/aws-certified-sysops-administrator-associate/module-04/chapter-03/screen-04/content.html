Module 4 › Chapter 4.3 › What is AWS CodeDeploy?
Core idea
CodeDeploy automates file distribution and lifecycle hooks so deployments are deterministic.
• It accepts a revision from S3 or GitHub and installs it on targets.
• Lifecycle hooks run scripts at stages such as BeforeInstall and ValidateService.
• It supports EC2, Lambda, Fargate, and on-premises targets, enabling consistent flows.
Analogy: Deployment as a Scripted Recipe
Think of CodeDeploy as a kitchen where the recipe is the AppSpec file and the revision is the set of ingredients. The agent follows the recipe steps on every target so each server serves the same dish.
Example
A static site revision provides index.html and a script. AppSpec hooks install the web server, copy files, and start the service. CodeDeploy reports events for each hook so you can see success or failure per step.
Key Takeaway

CodeDeploy enforces a repeatable, scripted deployment process across diverse compute targets, reducing manual error.
