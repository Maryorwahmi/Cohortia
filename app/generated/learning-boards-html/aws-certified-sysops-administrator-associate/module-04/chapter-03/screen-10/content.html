Module 4 › Chapter 4.3 › Create Application & Group
Quick process
  1. Create an IAM role for CodeDeploy (attach AWSCodeDeployRole managed policy).
  2. Create the CodeDeploy Application and choose the compute platform.
  3. Create a Deployment Group: choose targets by tag or Auto Scaling group, select deployment type and configuration, and pick the service role.
  4. Optionally disable load balancer settings for simple demos; enable for production traffic shifting.
Confirm that instances have the expected tags and an instance profile that grants access to S3 if needed. If a deployment cannot reach instances, verify tag matching and agent health.
