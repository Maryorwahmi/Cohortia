Module 4 › Chapter 4.3 › Agent Installation
Install & verify
Run the installer and confirm the agent is active. For Auto Scaling, include the commands in user-data so new instances are ready.
If the agent service fails to start, check /var/log/aws/codedeploy-agent/codedeploy-agent.log for startup errors and ensure required packages like ruby are available.
Example install commands
sudo yum update -y
sudo yum install -y ruby
sudo yum install -y wget
cd /home/ec2-user
wget https://aws-codedeploy-us-east-1.s3.us-east-1.amazonaws.com/latest/install
chmod +x ./install
sudo ./install auto
sudo service codedeploy-agent status
Adjust the wget URL to the region where your instances run. Confirm agent status before creating a deployment.
