Module 4 › Chapter 4.3 › Components
Component roles
Application
Logical container for deployment groups and revisions.
Deployment Group
Defines targets, deployment type, and the service role for actions.
Revision
The zipped bundle in S3 or GitHub with code, config, and AppSpec.
CodeDeploy Agent
Runs on hosts, downloads revisions, and executes lifecycle hooks locally.
Common misconception
Some assume the service alone performs installs; actually, the agent executes scripts on the host. If the agent is not running or scripts are missing, the deployment will fail.
Concrete example
For a web app: Application = MyWebApp, Deployment Group = MyWebApp-Dev targeting EC2 instances with Name tag 'dev', Revision = my-web-app.zip in S3, Agent = running on each EC2 instance pulling the revision and running install/start scripts.
Key Takeaway

Map each component to your release process so roles and permissions are clear before you deploy.
