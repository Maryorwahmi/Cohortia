Automating Deployments with AWS CodeDeploy
Make releases repeatable and safe using revisions, AppSpec hooks, and deployment groups.
This chapter shows you how to prepare a revision bundle, author an AppSpec file, install the CodeDeploy agent on EC2, choose a deployment strategy, and diagnose failures with logs. Practical commands and example scripts are provided so you can run a real in-place deployment during a lab session.
