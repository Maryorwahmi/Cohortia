Module 4 › Chapter 4.3 › Remember
1. Validate AppSpec
Ensure paths are relative and scripts are executable before zipping.
2. Verify Agent
Confirm the agent is installed and running; include installation in user-data for Auto Scaling.
3. Use logs
Check CodeDeploy Events and agent logs to find failing hooks and script output.
Final thought

Automation reduces human error, but correct configuration and log-based troubleshooting make automation reliable.
