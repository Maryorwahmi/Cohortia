Module 4 › Chapter 4.3 › Troubleshoot
Diagnosis flow
  1. Open the CodeDeploy console Events and find the failed lifecycle event.
  2. SSH into the target EC2 instance and check /var/log/aws/codedeploy-agent/codedeploy-agent.log.
  3. Open deployment logs under /opt/codedeploy-agent/deployment-root/deployment-logs/ to view stdout/stderr from scripts.
  4. Fix the failing script, permissions, or instance role and retry the deployment.
Example log excerpt
[ERROR] /opt/codedeploy-agent/deployment-root/XYZ/scripts/install_dependencies.sh: line 12: yum: command not found Script failed with exit code 127
This shows a missing package manager binary or PATH issue. The log pinpoints the script and the failing command so you can correct the script or environment.
