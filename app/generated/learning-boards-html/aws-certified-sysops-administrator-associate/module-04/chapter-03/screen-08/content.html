Module 4 › Chapter 4.3 › Prepare bundle
Folder layout
Keep appspec.yml at the bundle root. Put scripts in a scripts/ directory and assets at the root or nested as declared.
  • Ensure scripts include a shebang (#!/bin/bash) and are executable.
  • Zip the directory so appspec.yml is directly inside the zip root, not within an extra parent folder.
  • Validate by unzipping locally and checking relative paths before uploading.
Example files
index.html
<!DOCTYPE html>
<html>
<head>
    <title>My CodeDeploy App</title>
</head>
<body>
    <h1>Hello from CodeDeploy!</h1>
    <p>This page was deployed using AWS CodeDeploy.</p>
</body>
</html>
install_httpd.sh and start_httpd.sh should include package installation and service enable commands. Make them executable before packaging.
