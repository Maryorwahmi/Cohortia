Module 4 › Chapter 4.3 › Package & Deploy
Commands
Zip from the parent of my-web-app so the appspec.yml sits at the zip root, then upload the zip to S3 and create the deployment.
zip -r my-web-app.zip my-web-app/
aws s3 cp my-web-app.zip s3://your-unique-codedeploy-bucket/my-web-app.zip
In the console, create a deployment for the application and deployment group, selecting the S3 revision location. Monitor events to observe each lifecycle hook execution.
Verification
After a successful deployment, visit the instance public IP and confirm the index.html content. Use the CodeDeploy console Events and the agent logs for further details if something fails.
