Module 5 › Chapter 4.6 › EventBridge Architecture
Event sources

AWS services, scheduled cron rules, or custom application events feed EventBridge.

Rules

Define matching criteria or schedules. Rules pick targets and can filter event content before delivery.

Targets

Targets receive the event. Lambda is a common target for operational actions.

Architecture snapshot
Source emits event or schedule
EventBridge rule matches and routes
Lambda executes, calls AWS APIs, logs to CloudWatch
Common pitfall
Forget to attach the Lambda as a target or misconfigure event patterns and the function will never be invoked even though the rule exists.
Key Takeaway

Use EventBridge to reliably schedule or route events to Lambda, keeping producers and consumers decoupled.
