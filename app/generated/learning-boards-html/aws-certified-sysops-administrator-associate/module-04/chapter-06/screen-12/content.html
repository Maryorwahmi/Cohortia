Module 5 › Chapter 4.6 › Hands-on Activity
Lab steps
  1. Create IAM role LambdaEC2ControlRole with logs and ec2 start/stop permissions.
  2. Create StopMyEC2Instance Lambda, set INSTANCE_ID, paste stop handler, deploy.
  3. Test manually and confirm logs and instance state change.
  4. Create StartMyEC2Instance Lambda with start_instances call and test.
  5. Create EventBridge rules for each function using cron expressions.
Safety note

Only stop instances you own for testing. Use tags or a sandbox account for lab work to avoid impacting production.

Test idea
Use a short cron like every 5 minutes to validate scheduling behavior quickly, then switch to daily times.
Key Takeaway

Validate each deployment step with manual tests and CloudWatch Logs before trusting scheduled runs.
