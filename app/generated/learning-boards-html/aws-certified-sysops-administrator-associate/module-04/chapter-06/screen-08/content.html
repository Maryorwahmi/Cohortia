Complete sample handler
import boto3
import os
import json

ec2 = boto3.client('ec2')

def lambda_handler(event, context):
  print('Received event: ' + json.dumps(event))
  instance_id = os.environ.get('INSTANCE_ID')

  if not instance_id:
    print('Error: INSTANCE_ID environment variable not set.')
    return { 'statusCode': 400, 'body': json.dumps('Instance ID not provided.') }

  try:
    response = ec2.stop_instances(InstanceIds=[instance_id], DryRun=False)
    print('Successfully initiated stop for instance ' + instance_id + '. Response: ' + json.dumps(response))
    return { 'statusCode': 200, 'body': json.dumps('Successfully stopped instance ' + instance_id) }
  except Exception as e:
    print('Error stopping instance ' + instance_id + ': ' + str(e))
    return { 'statusCode': 500, 'body': json.dumps('Error stopping instance ' + str(e)) }
Line-by-line notes
  • Import boto3 and create an EC2 client to call the API.
  • Read INSTANCE_ID from environment to avoid hardcoding.
  • Print the event to surface invocation details in CloudWatch.
  • Wrap API calls in try-except and log exceptions for troubleshooting.
Pro Tip
Use environment variables for IDs during testing, then move to tag-based discovery for production to handle multiple resources.
Key Takeaway

The minimal handler demonstrates configuration via env vars, API calls with Boto3, and basic logging and error handling for CloudWatch visibility.
