Error handling

Wrap API calls in try-except, log the exception with context, and return a non-200 status so calling systems can detect failure.

Troubleshooting workflow
  • Invoke manually and observe CloudWatch Logs for prints and tracebacks.
  • Check IAM role for missing permissions when you see AccessDenied errors.
  • Use short test schedules to reproduce timing-sensitive issues.
Key Takeaway

Good logging and explicit exception handling are essential; they make automation observable and debuggable.
