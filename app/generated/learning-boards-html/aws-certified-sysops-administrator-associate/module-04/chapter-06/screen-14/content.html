Module 5 › Chapter 4.6 › Key Concepts
AWS Lambda
Serverless compute that runs code in response to events or schedules.
EventBridge
Serverless event bus for scheduled and event-pattern rules that route to targets like Lambda.
Observability & IAM
Use CloudWatch Logs and least-privilege IAM roles to maintain safe, auditable automation.
Summary Takeaway

Automate repeatable operational tasks with EventBridge-triggered Lambdas, grant minimal permissions, and verify behavior through logs and tests.
