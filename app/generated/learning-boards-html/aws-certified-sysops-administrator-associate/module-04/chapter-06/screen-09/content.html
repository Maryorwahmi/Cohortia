Module 5 › Chapter 4.6 › Deploying the Lambda
Step-by-step checklist
  1. Create Lambda with Python runtime and function name.
  2. Create or attach an IAM role with ec2:StopInstances (or Start) and CloudWatch Logs permissions.
  3. Add environment variable INSTANCE_ID and paste code.
  4. Deploy and run a manual test invocation, then inspect CloudWatch Logs.
  5. Create EventBridge rule and attach Lambda as target for scheduled runs.
Common mistake

Not granting logs permissions prevents CloudWatch entries from appearing and makes debugging difficult. Always include logs:CreateLogGroup, logs:CreateLogStream, and logs:PutLogEvents.

Example
Role: LambdaEC2ControlRole with policies for ec2:StartInstances and ec2:StopInstances and CloudWatch Logs access.
Key Takeaway

Follow a deploy checklist and test manually before scheduling to reduce surprises when automation runs unattended.
