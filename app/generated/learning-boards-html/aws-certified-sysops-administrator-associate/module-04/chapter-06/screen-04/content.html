Module 5 › Chapter 4.6 › What is AWS Lambda?
Definition & benefits
  • Runs code on demand without managing servers.
  • Costs scale with invocation time; ideal for occasional automation.
  • Built-in integration with EventBridge and CloudWatch for triggers and logs.
Common misconception

Lambda is not only for web APIs. It is equally useful for scheduled and event-driven operational tasks like backups or instance lifecycle changes.

Key Takeaway

Use Lambda to run focused automation with minimal maintenance and cost when tasks are intermittent or event-driven.
