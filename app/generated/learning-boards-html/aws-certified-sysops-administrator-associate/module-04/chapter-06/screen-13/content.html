Module 5 › Chapter 4.6 › Common Mistakes
Permissions

Missing ec2:StopInstances or logs permissions cause API failures or silent lack of logs. Inspect CloudWatch for AccessDenied errors.

Rule configuration

Event pattern errors or forgetting to add the target will prevent invocation even if the rule exists.

Missing logs

If CloudWatch shows no output, ensure the role includes logs:CreateLogGroup, logs:CreateLogStream, and logs:PutLogEvents.

Quick triage
  1. Run function manually.
  2. Check CloudWatch Logs for errors.
  3. Verify role policies and EventBridge rule targets.
