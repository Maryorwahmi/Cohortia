Module 5 › Chapter 4.6 › Learning Objectives
01
Understand Lambda for automation
Learn what serverless execution provides and why it suits operational tasks.

You will be able to describe Lambda's serverless model, including pay-per-invocation and short-lived functions. This matters because small automation tasks no longer need a dedicated server, reducing cost and operational overhead.

Mnemonic: small plug-in functions

02
Identify automation scenarios
Recognize tasks that benefit from event-driven or scheduled automation.

You will list real scenarios—cost-saving stop/start, scheduled snapshots, security remediations, and resource cleanup—and explain why they are good fits for Lambda. This helps prioritize which tasks to automate first.

Mnemonic: checklist of repeats
VERIFIED COMPETENCY MILESTONE
03
Configure EventBridge rules
Create schedule or event-driven rules and attach Lambda targets.

You will set up cron-like scheduled rules and event pattern rules that match AWS service events. This enables predictable invocation and immediate reaction to service events without polling.

Mnemonic: rule → match → invoke
VERIFIED COMPETENCY MILESTONE
04
Write a Python Lambda for EC2 control
Build and deploy a function that starts or stops an instance using Boto3 and environment variables.

You will author the basic handler that reads an INSTANCE_ID environment variable, calls the EC2 API, and returns success or error. This covers the key elements needed to deploy safe automation.

Mnemonic: config by env var
