Module 4 › Chapter 4.4 › Tool Roles
Orchestration Architecture
SC
AWS CodeCommit — Source
A managed Git store that holds your application code and buildspec files. Acts as the reliable source for pipeline triggers.
CB
AWS CodeBuild — Build & Test
Runs build containers, executes install/test/build commands, and uploads artifacts to S3 for downstream stages.
CP
AWS CodePipeline — Orchestration
Defines stages and actions, passes artifacts, and monitors pipeline execution with automatic stops on failures.
Artifact Flow
Source code → CodeBuild executes buildspec → artifacts stored in S3 → CodePipeline moves artifacts to Deploy stage. Each arrow indicates an action producing an output artifact used by the next action.
Misconfiguration to Avoid
A frequent error is forgetting to include artifacts in the buildspec artifact section, resulting in empty output passed to downstream stages.
Key Takeaway

Treat each service as a single responsibility: source, build, and orchestrate. Correctly defining artifacts lets the pipeline move work forward without surprises.
