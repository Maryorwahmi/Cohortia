Typical Failures
  • buildspec YAML errors: Use a YAML linter; small indentation mistakes break parsing.
  • Artifacts empty: Wrong base-directory or files pattern causes empty S3 uploads.
  • Permission denied: Missing S3 or CodeCommit permissions on the service role.
  • Missing dependencies: Install required packages in the install phase to avoid runtime errors.
Quick Debug
Re-run a failing build manually, read logs for the failing command, and fix buildspec entries. Then retry the pipeline when the build succeeds.
Key Takeaway

Logs and S3 artifact inspection are your fastest path to the root cause. Iterate on buildspec and role policies until runs succeed consistently.
