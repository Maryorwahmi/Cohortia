Module 4 › Chapter 4.4 › Hands-on Checklist
Checklist
  1. Create CodeCommit repository and clone locally.
  2. Add index.html and buildspec.yml at repo root; commit and push.
  3. Create IAM role for CodeBuild with S3 and CodeCommit permissions.
  4. Create CodeBuild project using the repository and buildspec.
  5. Create CodePipeline linking source, build, and deploy stages.
  6. Push a change and observe an automatic pipeline execution.
Validation Steps
Confirm the artifact appears in S3 after CodeBuild completes.
Verify CodePipeline shows a successful execution through Deploy stage.
Open your deployment target and confirm the updated content is live after pipeline success.
Key Takeaway

A concise checklist helps prevent omissions. Verify artifacts and permissions before assuming a pipeline error is a build problem.
