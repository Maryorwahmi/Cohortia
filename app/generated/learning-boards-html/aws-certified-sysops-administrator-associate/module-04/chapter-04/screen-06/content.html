Module 4 › Chapter 4.4 › buildspec.yml
Structure & Phases
  • version: Buildspec format version.
  • phases: install, pre_build, build, post_build — sequence of commands executed by CodeBuild.
  • artifacts: Files and base-directory to pass to the next pipeline stage.
Why this matters
A mis-specified artifacts section leads to empty downstream payloads. Missing install commands cause builds to fail due to absent dependencies.
Example buildspec.yml
version: 0.2

phases:
  install:
    runtime-versions:
      nodejs: 18
    commands:
      - echo Installing dependencies...
      - npm install
  pre_build:
    commands:
      - echo Running tests...
      - npm test
  build:
    commands:
      - echo Building application...
      - npm run build
  post_build:
    commands:
      - echo Packaging artifacts...
artifacts:
  files:
    - '**/*'
  base-directory: build
Check your build
Run a test build and read logs: confirm install outputs, test pass/fail lines, and that the expected files appear in the build output. If artifacts are missing, re-check base-directory and file patterns.
Key Takeaway

A proper buildspec makes builds reproducible. Validate phases and artifact paths in a test build before wiring the pipeline to production stages.
