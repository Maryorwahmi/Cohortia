Competency Checks
  • • Create and push to a CodeCommit repo and confirm the commit appears in the repository history.
  • • Run a CodeBuild build and review logs to ensure install, test, and build phases completed.
  • • Verify artifacts in S3 and that CodePipeline passes them between stages.
  • • Trigger a pipeline by pushing a small change and confirm the new content is deployed.
Quick Tip
When a build fails, immediately open the CodeBuild logs. Most failures come from the install or build commands defined in the buildspec file.
