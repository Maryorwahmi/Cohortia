CLI Steps
aws codecommit create-repository --repository-name MySimpleWebAppRepo --repository-description "My simple web app"
# Then clone, add files, commit and push using configured Git credentials
Troubleshooting tip
If your push is rejected, confirm Git credentials for CodeCommit are configured and that your IAM user has permissions for the repository.
