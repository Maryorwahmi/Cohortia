Module 4 › Chapter 4.4 › IAM Roles
Role Responsibilities
  • CodeBuild role: Pull source, read secrets if needed, write artifacts to S3, push images to ECR if applicable.
  • CodePipeline role: Read source, access artifact store, invoke build and deploy actions.
Debugging Permissions
When a stage fails with AccessDenied, inspect the service role attached to that action and check if required policies (S3, CodeCommit, CodeBuild invocation) are present.
Practical Tip
For initial setup, attach managed policies to accelerate testing. After successful runs, reduce permissions to only the necessary S3 prefixes, repository ARNs, and specific deploy actions.
Key Takeaway

Service roles are the plumbing of pipelines. Review roles when a stage reports an access error and tighten permissions once functionality is verified.
