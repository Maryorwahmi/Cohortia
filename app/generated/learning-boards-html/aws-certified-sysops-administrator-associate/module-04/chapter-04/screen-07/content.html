Module 4 › Chapter 4.4 › Pipeline Steps
Step-by-Step
1. Source
Create CodeCommit repo and push code including buildspec.yml. This is the pipeline trigger.
2. Build
Create CodeBuild project that consumes the repo and uploads artifacts to S3 according to buildspec artifacts section.
3. Deploy
Add a deploy action such as CodeDeploy to update your target environment with the artifact.
CLI Example
aws codecommit create-repository --repository-name MySimpleWebAppRepo --repository-description "My simple web app"
After creating a repository, clone it, add your files, commit, and push to trigger the pipeline flow.
Common Mistake
Forgetting to include buildspec.yml at the repository root or mis-setting artifact paths will stop the pipeline because downstream actions have nothing to consume.
Key Takeaway

Follow the source, build, deploy sequence and verify artifacts and IAM roles before expecting a successful end-to-end run.
