Troubleshooting Checklist
  1. Open CodePipeline to find the failing stage and action details.
  2. Open the corresponding CodeBuild build and read the full logs to identify failing phase and commands.
  3. Check the S3 artifact bucket to confirm the expected files were uploaded after the build.
  4. If AccessDenied appears, inspect the IAM role attached to the failing action for missing permissions.
Practice
When a failure occurs, run the same revision in CodeBuild directly. This isolates build commands from pipeline orchestration and clarifies whether the issue is build logic or pipeline configuration.
Log Focus
Check the install phase first for missing dependencies, then build phase for compile errors, and post-build for packaging problems.
Key Takeaway

Use logs and artifact inspection to narrow issues quickly. Re-run builds in CodeBuild to isolate and fix failing commands before adjusting pipeline wiring.
