What Are Artifacts?

Outputs of builds or tests that are consumed by later stages, such as zip bundles, compiled binaries, or static site files.

CodeBuild uploads artifacts to an S3 artifact bucket which CodePipeline references for downstream actions.

Verification
After a build, check the artifact bucket in S3 to confirm the expected archive or files exist. Then confirm the pipeline used that artifact version in the next stage.
Common Error
If artifacts.files uses an incorrect pattern, the artifact will be empty. If base-directory is wrong, CodeBuild will upload the wrong folder. Both lead to downstream failures.
Permissions
Ensure CodeBuild and CodePipeline service roles can read and write to the artifact S3 bucket. Lack of permissions will cause stage failures even if the build succeeds locally.
