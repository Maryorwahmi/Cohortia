Module 4 › Chapter 4.4 › Key Concepts
Continuous Integration
Automated builds and tests on frequent merges to give fast feedback and reduce integration defects.
Continuous Delivery
Ensure builds are packaged and ready for release so deployment can be routine and low-risk.
Artifacts & Roles
Artifacts flow via S3 and service roles must be correctly scoped so stages can read and write necessary data.
Summary Takeaway
Combine reproducible buildspec files, correct artifact configuration, and proper IAM roles to build a reliable CI/CD pipeline that surfaces problems early and deploys with confidence.
