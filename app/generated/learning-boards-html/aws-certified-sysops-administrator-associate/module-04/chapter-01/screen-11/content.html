Events list contains timestamped entries for each resource action and includes error text and the logical ID when failures occur.
Concrete example
If ImageId is invalid, Events will show an error like 'InvalidAMIID.NotFound' with the resource logical ID. CloudFormation then rolls back successfully created resources.
Why this matters
Understanding these states prevents misinterpreting a failed stack as a successful partial deploy and helps you plan fixes and retries safely.
Pro tip
Use the Events tab first, then read the resource-specific error and logical ID to search documentation or adjust the template.
