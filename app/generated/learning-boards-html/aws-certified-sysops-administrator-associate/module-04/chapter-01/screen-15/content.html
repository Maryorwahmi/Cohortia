Module 4 › Chapter 4.1 › Key Concepts
Resource
A declared AWS entity in a template with a logical ID, Type, and Properties.
Stack
A deployed instance of a template; manage resources as a single unit.
Change Set
A preview of proposed stack changes so you can confirm impact before execution.
Final takeaway

Use clear Resources, manage deployments as Stacks, and always preview updates with Change Sets to keep infrastructure predictable and auditable.
