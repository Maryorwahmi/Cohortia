Module 4 › Chapter 4.1 › S3 Hands-on
Starter template
AWSTemplateFormatVersion: '2010-09-09'
Description: CloudFormation template to create a private S3 bucket.

Resources:
  MySecureS3Bucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName:  # MUST BE GLOBALLY UNIQUE
      PublicAccessBlockConfiguration:
        BlockPublicAcls: true
        IgnorePublicAcls: true
        BlockPublicPolicy: true
        RestrictPublicBuckets: true
      Tags:
        - Key: Project
          Value: MySysOpsProject
Activity steps
  1. Replace the placeholder bucket name with a globally unique name.
  2. Save as s3-bucket-stack.yaml and validate the YAML syntax.
  3. Create the stack via Console or aws cloudformation create-stack.
  4. Verify Public Access Block and Tags in the S3 console.
  5. Delete the stack to clean up.
Why this matters
Encoding public-access blocking in templates enforces security consistently across environments.
