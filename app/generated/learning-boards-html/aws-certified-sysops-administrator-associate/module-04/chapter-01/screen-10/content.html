Module 4 › Chapter 4.1 › AWS CLI Deployment
Example CLI commands
aws cloudformation create-stack \
  --stack-name MyFirstEC2Stack \
  --template-body file://my-ec2-stack.yaml \
  --capabilities CAPABILITY_IAM
Use describe-stacks or describe-stack-events to inspect status and events after issuing the create command.
Automation notes
  • Validate templates before creating stacks to catch syntax errors.
  • Use change sets in CI to preview the impact of updates.
  • Handle asynchronous status by polling Events until completion.
Misconception
create-stack does not block; it starts the operation and returns while CloudFormation proceeds in the background.
