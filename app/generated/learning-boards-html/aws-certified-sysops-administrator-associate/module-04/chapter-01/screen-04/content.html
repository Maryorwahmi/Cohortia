Module 4 › Chapter 4.1 › Manual vs IaC
Manual Provisioning
Clicking through the Console to create each resource. Fast for one-off tasks but error-prone and hard to reproduce.
Risks
  • Configuration drift across environments
  • Missing tags or inconsistent properties
  • No easy version history
Concrete example
Ten manually created EC2 instances may use different AMIs or instance types depending on who clicked the Console, leading to hard-to-reproduce bugs.
Infrastructure as Code
A template file declares resources and properties, enabling version control, automation, and repeatable deployments.
Benefits
  • Repeatable, auditable deployments
  • Automatable with CI/CD and CLI
  • Safe updates via change sets
Concrete example
One YAML template launches identical EC2 instances across dev, test, and prod with the same AMI, tags, and key pair.
Key takeaway
Convert repetitive manual steps into templates to prevent drift and enable automation.
Common misconception
IaC is not just for large infra; small infra benefits immediately from reproducibility.
