Module 4 › Chapter 4.1 › Console Deployment
Console steps
  1. Open CloudFormation and choose Create stack.
  2. Upload template file or paste the template body.
  3. Provide a stack name and fill Parameters like KeyName.
  4. Acknowledge IAM capabilities if required and create the stack.
  5. Monitor the Events tab for progress and errors.
What to watch for
Check that Parameters are valid, ensure AMI and KeyName exist in your region, and review IAM acknowledgments if your template creates roles or policies.
Concrete example
Uploading my-ec2-stack.yaml and setting KeyName=my-ssh-key will create a stack named MyFirstEC2Stack. Watch Events for CREATE_IN_PROGRESS then CREATE_COMPLETE.
Common error
Wrong AMI or missing KeyName will produce an error referencing the logical ID in Events and trigger a rollback.
Tip
Use the Console to validate and learn lifecycle events before scripting the CLI process.
Check
After CREATE_COMPLETE, view Outputs to retrieve values like instance IDs or bucket names.
