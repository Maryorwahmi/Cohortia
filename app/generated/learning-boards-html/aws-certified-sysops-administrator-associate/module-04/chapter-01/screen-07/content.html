YAML template example
Save this file as my-ec2-stack.yaml and replace the placeholder ImageId and KeyName with values valid for your region and account.
AWSTemplateFormatVersion: '2010-09-09'
Description: A simple CloudFormation template to launch an EC2 instance.

Resources:
  MyWebServer:
    Type: AWS::EC2::Instance
    Properties:
      ImageId: ami-0abcdef1234567890 # Replace with a valid Amazon Linux 2 AMI ID for your region
      InstanceType: t2.micro
      KeyName: my-ssh-key # Replace with an existing EC2 Key Pair name
      Tags:
        - Key: Name
          Value: MyCloudFormationInstance
        - Key: Environment
          Value: Development
Walkthrough notes
  • AWSTemplateFormatVersion and Description are metadata but helpful for clarity.
  • Resources is mandatory; each resource needs a logical ID and Type.
  • Properties configure the resource; missing required properties cause failures.
  • Replace ImageId and KeyName before deploying; these are common sources of errors.
Pro tip
Parameterize ImageId and KeyName to reuse the template across regions and accounts.
