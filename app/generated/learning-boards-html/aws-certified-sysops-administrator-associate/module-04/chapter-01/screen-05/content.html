Core concepts architecture
Template
A YAML or JSON file that declares resources, properties, and optional metadata.
Stack
A deployed instance of a template representing a collection of provisioned resources.
Change Set
A preview of proposed updates that shows additions, modifications, and deletions before execution.
Logical ID & Resource Type
Logical IDs uniquely identify resources inside a template. Resource Type (for example AWS::EC2::Instance) determines the kind of AWS resource created.
Concrete example
Change set shows that updating InstanceType leads to a replacement for certain instance configurations. Reviewing the change set clarifies whether data loss or downtime may occur.
Why this matters
Knowing these elements helps you design safe updates and understand how CloudFormation maps template lines to real resources.
Key takeaway
Review change sets before applying updates to reduce risk.
Common misconception
Updates are not always destructive; change sets tell you whether replacement is required.
