Module 4 › Chapter 4.1 › Key Concepts
Infrastructure as Code (IaC)
Manage infrastructure through versioned template files rather than manual clicks.
AWS CloudFormation
Service that provisions and manages AWS resources from templates as stacks.
Template
A YAML or JSON file that declares Resources, Parameters, and Outputs for your stack.
Summary takeaway

Start with small, validated templates, parameterize region-specific values, and use change sets plus Events to deploy safely and troubleshoot quickly.
