Module 4 › Chapter 4.1 › ImageId, KeyName & Tags
ImageId (AMI)
AMIs are region-specific. If you reference an AMI that doesn't exist in your region, stack creation will fail and CloudFormation will attempt to roll back.
Mitigation
Use Parameters or Mappings to supply region-specific AMI IDs at deploy time.
KeyName (SSH access)
KeyName must exist in the account and region. Without it you cannot SSH into instances and some templates may fail if they depend on a valid key pair.
Pro tip
Parameterize KeyName so deployments prompt for an existing key or use a known value from CI/CD settings.
Tags — small but powerful
Tags are not cosmetic. Use them consistently to identify environment, project, and cost center so automation and billing tools can operate reliably.
Example
Tags: Environment=Development, Project=MySysOpsProject
Common misconception
Tags only affect display; in reality they are vital for automation, billing, and policies.
