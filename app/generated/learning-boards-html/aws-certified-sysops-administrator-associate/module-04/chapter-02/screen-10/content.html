Fn::Join

Join concatenates a list with a delimiter. Use it for predictable concatenation where elements are already separate values.

!Join ["-", ["app","web","01"]]  # app-web-01
When to prefer Join
When you have a list of known parts and want a fixed delimiter. It is explicit and easy to read.
Fn::Sub

Sub performs inline variable substitution. It’s useful for composing names using parameters and resource attributes without separate list management.

!Sub "MyInstance-${InstanceType}-${AWS::StackName}"
Common mistake
Overusing substitution for very long expressions reduces readability. Prefer clear, documented patterns or outputs to inspect composed values.
Key Takeaway
Use Join for explicit concatenation and Sub for inline templates. Keep strings simple and well-documented so generated names remain debuggable.
