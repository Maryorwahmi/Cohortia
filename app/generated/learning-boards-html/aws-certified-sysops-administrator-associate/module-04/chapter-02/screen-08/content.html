What Outputs do

Outputs provide a documented contract for other stacks and for operators. Exporting allows cross-stack consumption via ImportValue.

Outputs:
  VPCId:
    Description: The ID of the VPC
    Value: !Ref MyVPC
    Export:
      Name: MyNetworkStack-VPCId
The ApplicationStack can then use Fn::ImportValue MyNetworkStack-VPCId to reference the VPC. This keeps stack boundaries clear and allows independent updates of each stack so long as exported names remain stable.
Best practices & warnings
Best practice
Export only stable, necessary values and use descriptive export names to avoid collisions.
Warning
Exported names are global per account and region. Deleting or renaming exports can break dependent stacks—plan changes carefully.
Check your understanding
How would you expose a subnet ID for multiple application stacks while avoiding name collisions? Use a well-scoped export name and document the contract in the network stack.
