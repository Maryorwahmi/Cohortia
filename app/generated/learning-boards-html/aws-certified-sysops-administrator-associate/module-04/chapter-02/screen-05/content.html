Module 4 › Chapter 4.2 › Parameterized EC2
Starter template (refactor target)
AWSTemplateFormatVersion: '2010-09-09'
Description: A parameterized CloudFormation template to launch an EC2 instance.

Parameters:
  InstanceTypeParameter:
    Type: String
    Default: t2.micro
    AllowedValues:
      - t2.micro
      - t2.small
      - t2.medium
    Description: Choose an EC2 instance type.
  KeyNameParameter:
    Type: AWS::EC2::KeyPair::KeyName
    Description: Name of an existing EC2 KeyPair to enable SSH access.
  AMIIdParameter:
    Type: AWS::EC2::Image::Id
    Description: The ID of the AMI for the EC2 instance.
    Default: ami-0abcdef1234567890
Replace the placeholder AMI default with a region-specific AMI before deploying. Use Ref to plug these values into resource properties.
Outputs & CLI steps
Outputs:
  InstanceId:
    Description: The ID of the EC2 instance.
    Value: !Ref MyWebServer
  PublicIp:
    Description: The Public IP address of the EC2 instance.
    Value: !GetAtt MyWebServer.PublicIp
Deploy with the CLI by providing KeyName and optional overrides for InstanceType. After CREATE_COMPLETE, call describe-stacks and query Outputs to retrieve InstanceId and PublicIp programmatically for automation or verification.
Example CLI call
aws cloudformation create-stack --stack-name MyParamEC2 \
  --template-body file://parameterized-ec2-stack.yaml \
  --parameters ParameterKey=KeyNameParameter,ParameterValue=your-key-name \
               ParameterKey=InstanceTypeParameter,ParameterValue=t2.small
Pro tip
Define clear Output names and stable Export names when other stacks depend on them to avoid brittle imports.
