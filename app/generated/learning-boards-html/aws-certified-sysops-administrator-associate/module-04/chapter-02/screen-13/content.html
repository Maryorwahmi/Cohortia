Create and deploy
Save the parameterized template as parameterized-ec2-stack.yaml, making sure the AMI default matches your region. Then run the create-stack command passing KeyName and optionally InstanceType to test different sizes.
aws cloudformation create-stack \
  --stack-name MyParameterizedEC2Stack \
  --template-body file://parameterized-ec2-stack.yaml \
  --parameters ParameterKey=KeyNameParameter,ParameterValue=your-key-name \
               ParameterKey=InstanceTypeParameter,ParameterValue=t2.small \
  --capabilities CAPABILITY_IAM
Verify outputs and clean up
After CREATE_COMPLETE, retrieve outputs to find InstanceId and PublicIp. Use describe-stacks and query the Outputs array. When finished, delete the stack to remove resources and prevent charges.
aws cloudformation describe-stacks \
  --stack-name MyParameterizedEC2Stack \
  --query "Stacks[0].Outputs"

aws cloudformation delete-stack --stack-name MyParameterizedEC2Stack
Safety note
Always validate AMI defaults and review AllowedValues to avoid accidental large or incompatible resource creation.
