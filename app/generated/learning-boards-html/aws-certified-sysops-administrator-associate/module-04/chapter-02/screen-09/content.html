Ref

Ref returns the parameter value or a resource’s primary physical ID. Use it for InstanceType parameters or to output an instance ID.

InstanceType: !Ref InstanceTypeParameter
InstanceIdOutput:
  Value: !Ref MyWebServer
Misconception
Ref does not return arbitrary attributes. For attributes like PublicIp, use Fn::GetAtt.
Fn::GetAtt

GetAtt retrieves a named attribute from a resource after it exists. For instances, common attributes include PublicIp and PrivateIp.

PublicIpOutput:
  Value: !GetAtt MyWebServer.PublicIp
  Description: The public IP assigned after provisioning.
When building outputs or composing values for other resources, choose the function that returns the precise value you need. Consult resource attribute docs to know which attributes are supported by GetAtt.
