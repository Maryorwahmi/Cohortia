Module 1 › Chapter 1.1 › Cost & Scaling
Strategies
  • Autoscaling to match capacity to demand
  • Right-size instances and use spot where appropriate
  • Tag resources for cost allocation
Concrete example
An autoscaled frontend cluster uses small instances with a scaling policy based on request rate, while a baseline database uses reserved capacity for predictable workloads.
Misconception
Assuming higher availability always requires prohibitive cost. Thoughtful use of elasticity reduces expense while preserving uptime.
