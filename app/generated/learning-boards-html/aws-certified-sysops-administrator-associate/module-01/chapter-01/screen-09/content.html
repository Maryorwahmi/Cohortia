Configure the CLI
Use the configuration command to set credentials and default region. Prefer IAM roles or temporary credentials for security.
Example commands
aws configure
aws sts get-caller-identity
aws s3 ls
aws ec2 describe-regions --query "Regions[].RegionName" --output text
Concrete lab guidance
In the hands-on activity, you will configure the CLI and run the get-caller-identity and s3 listing commands to practice safe verification.
Misconception
Do not assume configure stores credentials securely by default. Use the credential helper or role-based access and avoid sharing keys.
Try this

Run get-caller-identity to verify your active credentials and region context before issuing other commands.
