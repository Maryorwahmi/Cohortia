What are Edge Locations?
Distributed Points of Presence used to cache content and serve it with lower latency to end users.
When to use them
  • Deliver static assets such as images, scripts, and stylesheets
  • Reduce latency for a global user base
  • Improve DNS resolution speed for global users
Concrete example
Host a static website on S3 and configure the distribution service to cache assets at Edge Locations. Users retrieve cached copies quickly from a nearby edge node.
Misconception
Edge Locations are not a substitute for Regions when you need data residency or durable primary storage.
Key Takeaway

Use Edge Locations to improve perceived performance for users; manage origin storage separately.
