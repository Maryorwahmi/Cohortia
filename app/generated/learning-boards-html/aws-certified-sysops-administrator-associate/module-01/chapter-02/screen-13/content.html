Module 1 › Chapter 1.2 › Common mistakes & best practices
Common mistakes
  • Open SSH to 0.0.0.0/0
  • Using On‑Demand for predictable long-running services
  • Terminating without snapshots
Best practices
  • Restrict Security Groups and use key pairs securely
  • Pick Reserved or Spot based on workload profile
  • Automate with AMIs and infrastructure templates
Operational checklist

Tag instances for ownership, review CloudWatch before resizing, and snapshot volumes before termination to prevent data loss.

Key Takeaway

Operational discipline—restrictive defaults, metric-driven decisions, and backups—reduces incidents and unnecessary costs.
