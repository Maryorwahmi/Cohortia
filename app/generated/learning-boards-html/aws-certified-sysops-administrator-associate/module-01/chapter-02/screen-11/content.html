Module 1 › Chapter 1.2 › Stop, start, reboot, and terminate
Stop

Shuts down instance compute; EBS volumes persist and you keep paying for storage. Use when you want to pause compute but keep data.

Start

Starts a previously stopped instance, restoring compute with the same attached volumes and configuration.

Reboot

Performs an operating system restart without changing instance identity or attached EBS volumes. Use for transient issues.

Terminate

Deletes the instance permanently and usually removes root EBS volumes. Snapshot before terminating to preserve data.

Key Takeaway

Use stop for temporary pauses and snapshot before termination to avoid data loss. Choose actions deliberately to control charges and preserve data.
