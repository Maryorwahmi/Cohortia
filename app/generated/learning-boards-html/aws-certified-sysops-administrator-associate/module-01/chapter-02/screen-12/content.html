Module 1 › Chapter 1.2 › Lab: Launching and securing a web server
Activity steps (condensed)
  1. Create key pair my-sysops-key and save .pem.
  2. chmod 400 on the .pem locally.
  3. Launch Amazon Linux 2023 t2.micro with webserver-sg.
  4. SSH and run a system update, then exit.
  5. Stop and then terminate after backup confirmation.
Command reference
chmod 400 /path/to/my-sysops-key.pem
ssh -i /path/to/my-sysops-key.pem ec2-user@<YourInstancePublicDNSorIP>
# In instance: sudo dnf update -y  (Amazon Linux 2023)
Safety note

Before terminating an instance, snapshot any EBS volumes that contain important data. Termination often removes the root volume permanently.

Key Takeaway

This practice sequence builds muscle memory for secure launches and safe teardowns—an essential SysOps habit.
