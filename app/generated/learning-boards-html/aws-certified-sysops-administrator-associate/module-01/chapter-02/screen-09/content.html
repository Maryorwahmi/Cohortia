SSH to Linux (example)
chmod 400 /path/to/my-sysops-key.pem
ssh -i /path/to/my-sysops-key.pem ec2-user@<YourInstancePublicIP>

Replace the path and public IP. If permission errors persist, confirm the .pem file owner and restrictive permissions.

Windows RDP flow

Use the key pair to decrypt the administrator password in the Console, then use that password with an RDP client to connect to the instance. Confirm RDP port 3389 is allowed from your IP.

Check

If you cannot connect: verify Security Group inbound rules, correct username, and private key permissions before troubleshooting deeper.
