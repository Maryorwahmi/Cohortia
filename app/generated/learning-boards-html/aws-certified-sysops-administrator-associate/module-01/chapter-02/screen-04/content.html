EC2 instance: a virtual server

A virtual machine that you configure with an AMI, instance type, storage, and network settings for running workloads in AWS.

What you manage
  • Instance type (CPU, memory, network)
  • AMIs and attached EBS volumes
  • Security Groups and key pairs for access
Concrete example

Launch an Amazon Linux AMI on t2.micro with an 8 GiB root volume, a security group allowing HTTP and SSH from controlled sources, and a key pair for SSH access.

Key Takeaway

Treat EC2 instances as replaceable compute units; automate creation with AMIs and back up data to avoid loss when instances are terminated.

Misconception

Do not assume an instance is permanent. Termination can delete attached EBS volumes unless configured otherwise, so rely on snapshots for critical data.

Why this matters

Understanding that instances are virtual and replaceable leads to better automation, backups, and cost decisions—core SysOps responsibilities.
