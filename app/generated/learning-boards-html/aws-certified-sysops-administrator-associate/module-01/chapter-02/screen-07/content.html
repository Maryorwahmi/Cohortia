Module 1 › Chapter 1.2 › Launching an EC2 instance
Step-by-step checklist
  1. Choose AMI (software template).
  2. Select instance type (t2.micro for free tier test).
  3. Configure network: VPC, subnet, public IP.
  4. Create Security Group: allow only required ports.
  5. Choose key pair and storage size, then launch.
Concrete example

Launch an Amazon Linux 2023 AMI on t2.micro with a webserver-sg that allows HTTP from anywhere and SSH from your IP, and key pair my-sysops-key.

Common mistake

Leaving SSH open (0.0.0.0/0) is an avoidable risk. Instead, restrict SSH access to your public IP or use bastion hosts and session managers.

Key Takeaway

Follow the checklist each time to ensure instances are secure, networked correctly, and reproducible via AMIs.
