Metrics to monitor
  • CPUUtilization
  • NetworkIn / NetworkOut
  • Disk I/O and status checks
CLI example
aws cloudwatch get-metric-statistics \
  --namespace AWS/EC2 \
  --metric-name CPUUtilization \
  --dimensions Name=InstanceId,Value=i-0abcdef1234567890 \
  --start-time 2023-01-01T00:00:00Z \
  --end-time 2023-01-01T01:00:00Z \
  --period 3600 \
  --statistic Average
Misconception

Do not rely on a single metric like CPU alone. Combine CPU, network, and disk metrics to understand true bottlenecks before resizing.

Key Takeaway

Collect and review multiple metrics over time, then set alarms to notify or trigger automated actions when thresholds are breached.
