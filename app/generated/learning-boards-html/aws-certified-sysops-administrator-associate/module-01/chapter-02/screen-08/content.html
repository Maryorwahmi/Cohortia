Module 1 › Chapter 1.2 › Security Groups and Key Pairs
Security Group basics

Stateful instance-level firewall. Define inbound rules for required ports and restrict source IP ranges to minimize attack surface.

Key Pair basics

Public key stored in AWS, private key (.pem) kept locally for SSH authentication. Protect private key with strict file permissions.

Concrete practice

Create webserver-sg: allow HTTP/HTTPS from 0.0.0.0/0 and SSH from your office IP. Generate my-sysops-key and run chmod 400 locally before SSHing.

Common mistake

Sharing or misplacing private keys or opening SSH to the world are frequent security failures. Use strict rules and key management.
