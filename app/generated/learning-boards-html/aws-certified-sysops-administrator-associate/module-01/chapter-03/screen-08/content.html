Lifecycle rule example
ArchiveAfter30Days
Scope: Apply to all objects. Transition to Standard-IA after 30 days. Transition to Glacier after 90 days. Expire after 3650 days (7 years) if needed.
Scoped rule with tags
Use tags like "retention:7years" to apply rules only to compliance datasets while leaving other objects on faster tiers.
Practice
Create the ArchiveAfter30Days lifecycle rule in a test bucket. Monitor transition logs and note the storage class change in object metadata.
Quick facts
  • Lifecycle can transition or expire objects automatically.
  • Use tags or prefixes to target specific datasets.
  • Test in a non-production bucket to estimate retrieval cost.
Why it matters

Automating tiering and expiry prevents manual maintenance and ensures cost-effective retention aligned to business rules.
