Module 1 › Chapter 1.3 › EBS Snapshots
Steps
  1. Identify the Volume ID from the EC2 instance's Storage tab.
  2. From the Volumes view, select the volume and choose Create snapshot.
  3. Provide a description and create; monitor the snapshot state in Snapshots.
  4. To restore in another AZ, copy the snapshot or create volume from snapshot in the target AZ.
For database consistency, consider stopping writes or freezing IO before snapshotting when possible.
CLI Example
aws ec2 create-snapshot --volume-id vol-0abcdef1234567890 --description "Snapshot for my-instance-root-volume"
Practice prompt
Create a snapshot of a test volume and then create a new volume from it in a different AZ to verify the copy and restore process.
Snapshot properties
  • Snapshots are incremental and stored on S3.
  • New volumes created from snapshots are full-sized and can be attached like any other EBS volume.
