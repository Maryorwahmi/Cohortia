Module 1 › Chapter 1.3 › Create S3 Bucket
Steps
  1. Open S3 and choose Create bucket. Pick a globally unique name that reflects purpose and date.
  2. Select the AWS Region where the bucket will live; objects remain in that Region.
  3. Keep Object Ownership as 'ACLs disabled' and enable Block Public Access settings.
  4. Upload an object from Console or use the CLI command to copy a file programmatically.
  5. Verify object metadata, ownership, and any attached tags or policies.
Mnemonic
Name • Region • Ownership • BlockPublic • Verify
CLI Example
aws s3 cp hello.txt s3://my-sysops-data-20231027-1234/hello.txt
Example verification
After upload, inspect the object in Console to confirm encryption, ownership and that Block Public Access prevented accidental public ACLs.
Gotcha
A globally unique name collision will cause bucket creation to fail; choose a timestamped suffix to avoid this.
