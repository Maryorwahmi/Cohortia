Explore Key Topics
S3: Object Storage
Durable, scalable for static assets, backups, and archives.
Lifecycle Policies
Automate tiering and expiration to control costs.
EBS: Block Storage
Low-latency volumes for OS mounts and databases; snapshots for backups.

S3 — object storage
Highly durable, region-scoped buckets for static or archival data.
EBS — block storage
Attached to a single EC2 in an AZ for low-latency block access.
Quick tip
If you need boot volumes or transactional databases, prefer EBS. For scalable storage of files, backups, or archives, choose S3 and automate lifecycle rules.
