EBS Encryption
Enable encryption when creating a volume. Snapshots created from encrypted volumes remain encrypted. Use KMS-managed keys to control access and rotation policies.
S3 Encryption
Use server-side encryption options and enforce encryption via bucket policy to ensure new objects are protected by default.
Operational checklist
  • Enable encryption by default for new EBS volumes and S3 buckets.
  • Audit existing snapshots and objects for encryption gaps.
  • Use least-privilege IAM roles and scoped bucket policies.
  • Keep Block Public Access enabled unless explicitly required.
Why it matters

Encryption reduces risk if access controls fail, and combined with least privilege provides layered defense for stored data.
