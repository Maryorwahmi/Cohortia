Practical checkpoints

Each card links objectives to a small lab-style verification you can perform.

01 — Lifecycle rule task
Create a rule to transition objects after 30 days and expire after 90 days to confirm automated tiering and retention.
VERIFIED COMPETENCY MILESTONE
02 — Snapshot task
Create and view an EBS snapshot; understand incremental behavior and the snapshot state lifecycle.
VERIFIED COMPETENCY MILESTONE
03 — Security check
Verify Block Public Access settings and review a bucket policy to apply least privilege.
VERIFIED COMPETENCY MILESTONE
04 — Durability assessment
Compare S3 regional durability with EBS AZ-scoped replication and plan a backup model for each.
VERIFIED COMPETENCY MILESTONE
