Module 1 › Chapter 1.3 › EBS — block storage
Definition

EBS volume essentials

Volumes attach to a single EC2 instance in the same Availability Zone and provide block-level access for boot volumes and databases.

  • Use for OS disks, transactional databases, and low-latency applications.
  • Volumes replicate within the AZ to tolerate hardware failure but are AZ-scoped.
  • Use snapshots for cross-AZ or cross-Region recovery.
Key takeaway

Choose EBS for workloads needing direct block access and quick IO; plan snapshots for AZ independence.

Operational example
Attach a gp3 volume as a boot disk for a web server. For a PostgreSQL instance, choose Provisioned IOPS SSD to meet sustained IOPS requirements and create regular snapshots for backups.
Misconception
Do not assume EBS volumes are automatically available across AZs; use snapshots and AMIs to move data between AZs or Regions.
