Module 2 › Chapter 1.4 › Troubleshooting Checklist
Checklist steps
  1. 1) Verify Security Group inbound/outbound rules.
  2. 2) Inspect NACL inbound/outbound rules and rule order.
  3. 3) Confirm route table entries and targets (IGW or NAT).
  4. 4) Check instance OS firewall and DNS resolution.
Follow this order to minimize configuration changes while isolating the fault.
Run inside an instance
$ traceroute example.com
