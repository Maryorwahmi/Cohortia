Module 2 › Chapter 1.4 › Subnets & Availability Zones
Design Process
  1. 1) Pick a VPC CIDR block that supports required hosts.
  2. 2) Decide tiers: public load balancers, app servers, private DBs.
  3. 3) Allocate subnets per AZ for each tier for redundancy.
  4. 4) Associate route tables and gateways according to access needs.
Common mistake

Placing all subnets in one AZ removes the benefit of AZ fault isolation.

Example allocation

VPC: 10.0.0.0/16

AZ-a: 10.0.1.0/24 public, 10.0.11.0/24 private

AZ-b: 10.0.2.0/24 public, 10.0.12.0/24 private

Scenario
Three-tier app with load balancer in public subnets and DB in private subnets across AZs.
Check
Ensure each private subnet uses a route to a NAT Gateway for outbound updates.
