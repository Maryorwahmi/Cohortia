Module 2 › Chapter 1.4 › Key Concepts — Part 2
Internet Gateway (IGW)
A VPC component that enables communication between the VPC and the internet.
NAT Gateway
Provides outbound internet access for private subnets while preventing inbound initiation.
Security Group & NACL
Security Groups are stateful instance filters; NACLs are stateless subnet filters processed by rule order.
Final takeaway

Correct routing plus layered firewall controls and appropriate IP addressing form the foundation for secure, reliable VPC design and predictable troubleshooting.
