Module 2 › Chapter 1.4 › Security Groups vs NACLs
Security Groups
  • Instance-level firewall.
  • Stateful: return traffic allowed automatically.
  • Use for tight port/source restrictions per instance.
Best practice: least privilege; allow only needed ports and CIDR ranges.
Network ACLs (NACLs)
  • Subnet-level firewall.
  • Stateless: explicit return rules required.
  • Rules processed by number order and can DENY traffic.
Use-case: block malicious IP ranges before traffic reaches instances.
Example
Allow inbound HTTP in SG for a web server; use a NACL to deny a known attacker IP for the entire subnet.
Misconfiguration
A deny rule in a NACL placed before allow rules can block traffic even when SGs allow it.
