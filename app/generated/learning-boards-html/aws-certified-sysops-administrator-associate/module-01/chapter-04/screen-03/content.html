Trace a packet mnemonic
  1. CIDR — confirm address belongs to your VPC range.
  2. Subnet — identify AZ and subnet type.
  3. Route — check 0.0.0.0/0 target.
  4. Firewall — validate SG and NACL allow flows.
Checklist for troubleshooting
  • Step 1: Validate Security Group inbound/outbound rules.
  • Step 2: Inspect NACL rules and rule order for denies.
  • Step 3: Confirm route table entries for IGW or NAT Gateway.
  • Step 4: Check instance OS firewall and DNS resolution.
Verification tip
Run a traceroute from the instance and use the checklist to identify where traffic is dropped.
