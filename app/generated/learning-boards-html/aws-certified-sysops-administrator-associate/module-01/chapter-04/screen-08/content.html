Module 2 › Chapter 1.4 › NAT Gateway & Private Access
How NAT works

NAT translates private IPs to a public IP for outbound connections while blocking inbound connection initiation from the internet.

Placement
Deploy the NAT Gateway in a public subnet that routes to the IGW.
Route
Private subnet route: 0.0.0.0/0 → nat-abcdef
Scenario
A database server in a private subnet needs package updates. Configure its route table to point default traffic to the NAT Gateway so it can fetch updates without a public IP.
Misconfiguration risk

Placing a NAT Gateway in a private subnet or forgetting the public subnet’s IGW route prevents translation and breaks outbound connectivity.
