Private vs Public

Private IPs come from the VPC CIDR and are only reachable inside the VPC. Public or Elastic IPs provide internet reachability when combined with route table entries to an IGW.

Elastic IP example
Allocate an Elastic IP and associate it with a network interface to give a persistent public address to an instance that must be reachable over time.
Scenario
A web server must be contactable by clients. Assign a public IP or EIP and use a route table pointing to the IGW to expose it. For a backend server that only needs updates, keep it private and use NAT for outbound access.
Key Takeaway

Both IP assignment and routing must be correct for external reachability; missing either breaks access.
