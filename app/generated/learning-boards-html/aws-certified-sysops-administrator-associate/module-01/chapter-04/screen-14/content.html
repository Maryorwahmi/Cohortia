Virtual Private Cloud (VPC)
A logically isolated virtual network within the AWS Cloud for launching resources.
Subnet
A range of IP addresses in a VPC that resides in a single Availability Zone.
Public Subnet
A subnet whose route table sends default traffic to an Internet Gateway, enabling public reachability.
Summary

These terms form the baseline vocabulary for designing VPC layouts, assigning addresses, and deciding exposure of resources.
