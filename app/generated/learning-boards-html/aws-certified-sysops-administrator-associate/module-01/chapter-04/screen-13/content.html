Module 2 › Chapter 1.4 › Common Connectivity Issues
Issue catalog
  • Incorrect Security Group rules blocking ports.
  • Stateless NACL denies or missing return entries.
  • Route table missing IGW or NAT entries.
  • Wrong subnet placement for public access.
  • DNS resolution problems inside the VPC.
Detection & fix
Follow the diagnostic order: Security Groups → NACLs → Route Tables → Instance firewall → DNS. Make one change at a time and re-test to isolate effects.
Pro tip

Use traceroute and simple port checks to see where traffic is dropped before changing firewall rules.
