Route table basics

Route tables contain destination prefixes and targets. A subnet’s associated route table controls traffic for that subnet.

# Example route table entries
Destination      Target
10.0.0.0/16      local
0.0.0.0/0         igw-12345678
Operational example
Create a public route table with 0.0.0.0/0 → IGW, associate it with public subnets. Private subnets use route tables pointing to a NAT Gateway instead.
Key Takeaway

Always confirm the route table association for a subnet when debugging unexpected internet exposure or loss of connectivity.
