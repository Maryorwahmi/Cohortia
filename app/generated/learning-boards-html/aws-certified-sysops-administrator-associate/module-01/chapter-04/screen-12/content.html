Module 2 › Chapter 1.4 › Activity: Examine Default VPC
Step-by-step
  1. Open VPCs and note the default VPC CIDR block.
  2. Check Subnets and confirm their Availability Zones.
  3. Inspect Route Tables for 0.0.0.0/0 → igw- entries and associations.
  4. Find Internet Gateways attached to your default VPC.
  5. Compare Security Groups and NACLs for a selected subnet.
Reflection
If a private instance needs updates, plan a NAT Gateway in a public subnet and update the private subnet’s route table to point to the NAT target.
Use this routine to connect console observations to architectural intent during audits.
