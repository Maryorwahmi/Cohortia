Module 8 › Chapter 7.7 › Backup and Restore — implementation details
Implementation checklist
  • Configure AWS Backup plans for EC2, EBS, RDS, and DynamoDB with cross‑region copies where needed.
  • Enable S3 cross‑region replication for critical buckets and test object restoration.
  • Automate AMI creation and cross‑region copy for application servers.
  • Document runbook steps to launch instances from AMIs and restore volumes and databases.
  • Schedule periodic restore tests and validate application endpoints.
Scenario
If us-east-1 fails, execute automation to copy AMIs to the DR region, launch instances, restore DB from snapshot, and update Route 53 failover records.
Common-mistake
Outdated backups
Backups without restore tests or old retention policies can be useless in a real incident.
Key Takeaway

Backups must be automated, cross‑region, and regularly restored to be trusted at incident time.
