Module 8 › Chapter 7.7 › Pilot Light and Warm Standby patterns
Pilot Light
Minimal running resources and replicated data in DR region. Scale up when needed.
  • Keep core services and data copies ready.
  • Automate expansion with CloudFormation templates.
  • Lower cost than Warm Standby but longer scale‑up time.
Example
Store AMIs and snapshots in the DR region and run lightweight control plane components that can launch full stacks on demand.
Warm Standby
A small, running environment that can scale to handle production load rapidly.
  • Maintain ASG at reduced capacity with AMIs copied to the DR region.
  • Keep database replicas synchronized and ready to promote.
  • Faster RTO but higher ongoing cost than Pilot Light.
Operational tip
Automate scaling steps and pre-validate configuration differences between regions, such as VPC CIDRs and subnet mappings.
