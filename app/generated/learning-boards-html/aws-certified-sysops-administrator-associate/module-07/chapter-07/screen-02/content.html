Learning Objectives
Skills to document, implement, and validate DR plans on AWS.
Bloom: Learn → Understand → Apply → Master
01
Design a comprehensive DR plan
Write scope, roles, runbooks, and communication protocols that map to RTO/RPO.
Verified Competency Milestone
02
Implement DR strategies with AWS
Apply Backup and Restore, Pilot Light, Warm Standby, or Active/Active with service-level details.
Verified Competency Milestone
03
Automate runbooks and recovery steps
Use Systems Manager Automation, CloudFormation, and backups to reduce manual effort and RTO.
Verified Competency Milestone
04
Plan and execute DR testing
Define tabletop, simulated failover, and full drill schedules and verification steps.
Verified Competency Milestone
