Module 8 › Chapter 7.7 › Network Cutover and Route 53 Failover
Cutover checklist
  1. Validate DR ALB and instance health checks and security groups.
  2. Reduce DNS TTL in advance if possible to speed propagation.
  3. Update Route 53 failover records or change routing policy to direct traffic to DR endpoints.
  4. Run smoke tests, end‑to‑end flows, and monitor logs and metrics.
  5. If verification fails, execute the rollback DNS plan and investigate.
Example
Use Route 53 weighted or failover records to move traffic to the DR ALB, then confirm user transactions complete and latency is acceptable.
Common-mistake
Ignoring caches
Client DNS caching and CDN caches can delay traffic redirection; plan for this in tests.
Key Takeaway

Plan DNS changes and health checks carefully, and include rollback entries to revert if required.
