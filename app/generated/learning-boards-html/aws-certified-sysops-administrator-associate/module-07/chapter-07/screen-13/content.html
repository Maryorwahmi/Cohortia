Module 8 › Chapter 7.7 › AWS Resilience Hub and Fault Injection
Assessment workflow
  1. Define application and its components in Resilience Hub.
  2. Set RTO/RPO targets for the application.
  3. Run an assessment to get a resilience score and recommendations.
  4. Implement remediations and re‑assess to track improvements.
Using FIS
Integrate Fault Injection Simulator to schedule controlled experiments and validate runbooks under fault conditions.
Practical tips
Continuous use
Make assessments part of change control to catch regressions early.
Key Takeaway

Resilience Hub gives a consistent way to measure and improve application resilience and link tests to remediation actions.
