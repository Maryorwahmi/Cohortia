01 — Health check creation
Create an HTTP health check pointing to the ALB and a specific path like /index.html. Avoid checking only TCP or ICMP.
VERIFIED COMPETENCY MILESTONE
02 — Failover records
Create primary and secondary record sets; attach the health check to the primary so Route 53 can fail over automatically.
VERIFIED COMPETENCY MILESTONE
03 — Routing policies
Try weighted routing for gradual rollouts and latency routing to prefer lower-latency regions for users.
VERIFIED COMPETENCY MILESTONE
04 — TTL testing
Lower TTLs like 60 or 30 seconds speed visible failover, but increase DNS query volume. Measure with dig or nslookup.
