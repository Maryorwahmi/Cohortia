Hands-on Activity

Configure Route 53 Failover for Two ALBs

Step-by-step
  1. Create a hosted zone for your domain if needed.
  2. Create PrimaryALBHealthCheck: protocol HTTP, domain = primary ALB DNS, path = /index.html, fast interval for quicker detection.
  3. Create Primary record: name app, type A, alias to ALB in us-east-1, routing policy = Failover, record type = Primary, associate the health check, TTL = 60.
  4. Create Secondary record: same name app, type A, alias to ALB in us-west-2, routing policy = Failover, record type = Secondary, TTL = 60.
  5. Test: resolve app.yourdomain, simulate primary failure, watch health check become unhealthy, and re-resolve after TTL to confirm secondary answers.
Checks & pitfalls
  • Ensure the health check path returns success only when the app is healthy.
  • Avoid very high TTLs when you need fast failover.
  • Optionally create a health check for the secondary to detect its problems too.
Key Takeaway

Follow the lab steps exactly, then simulate failure to confirm both the health check and TTL behave as expected.
