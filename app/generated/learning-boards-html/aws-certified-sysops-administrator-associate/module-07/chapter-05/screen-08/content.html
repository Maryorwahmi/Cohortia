CLI Example: Creating Failover Record Sets

Below is the conceptual CLI snippet from the chapter. It shows creating a primary record set with a HealthCheckId and a secondary record set intended as standby.

# Create a primary record set
aws route53 change-resource-record-sets \
    --hosted-zone-id Zxxxxxxxxxxxxxx \
    --change-batch '{
        "Changes": [
            {
                "Action": "CREATE",
                "ResourceRecordSet": {
                    "Name": "app.example.com.",
                    "Type": "A",
                    "SetIdentifier": "Primary",
                    "Weight": 100,
                    "Region": "us-east-1",
                    "HealthCheckId": "hc-0abcdef1234567890",
                    "ResourceRecords": [
                        {"Value": "alb-primary-us-east-1.elb.amazonaws.com"}
                    ]
                }
            }
        ]
    }'

# Create a secondary (failover) record set
aws route53 change-resource-record-sets \
    --hosted-zone-id Zxxxxxxxxxxxxxx \
    --change-batch '{
        "Changes": [
            {
                "Action": "CREATE",
                "ResourceRecordSet": {
                    "Name": "app.example.com.",
                    "Type": "A",
                    "SetIdentifier": "Secondary",
                    "Weight": 0,
                    "Region": "us-west-2",
                    "HealthCheckId": "hc-0fedcba9876543210",
                    "ResourceRecords": [
                        {"Value": "alb-secondary-us-west-2.elb.amazonaws.com"}
                    ]
                }
            }
        ]
    }'
Annotations
  • HealthCheckId: ties the primary record to a check so Route 53 can evaluate health.
  • SetIdentifier: a unique label for the record set version.
  • Weight: used for traffic distribution, not the primary mechanism for failover.
  • Region: indicates the AWS region of the resource; useful for latency and management.
Key Takeaway

Use failover routing and attach a HealthCheckId to the primary record; weight is for distribution, not failover control.
