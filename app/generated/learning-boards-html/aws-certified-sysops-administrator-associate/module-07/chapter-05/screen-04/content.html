Core Concept

What is Amazon Route 53?

Route 53 is a DNS web service that couples resolution with health checks and advanced routing policies so DNS can be used for high availability and disaster recovery.

Key behaviors
  • Responds to DNS queries for your hosted zones.
  • Performs health checks and marks endpoints healthy or unhealthy.
  • Supports routing policies that change answers based on health or rules.
Concrete example
app.example.com maps to an ALB in us-east-1 while healthy, and to an ALB in us-west-2 when the primary fails.
Common misconception
DNS is not passive here; Route 53 actively changes answers based on health checks and configured policies.
Key Takeaway

Think of Route 53 as DNS with a heartbeat: health checks are the heartbeat that drives routing decisions.

Visual: role of health checks in DNS
Probe types
HTTP, HTTPS, TCP probes confirm endpoint behavior.
Health state
Route 53 marks endpoints healthy/unhealthy and uses that state in routing policies.
Routing action
If primary is unhealthy, Route 53 returns the secondary record as the answer.
