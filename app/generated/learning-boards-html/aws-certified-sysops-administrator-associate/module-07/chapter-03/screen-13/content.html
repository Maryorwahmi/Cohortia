S3 Versioning steps
Create bucket, enable Versioning under Properties, upload log.txt, upload a changed log.txt, then toggle "Show versions" in the console to examine object history.
Verification & Notes
  • Confirm DLM policy has enabled state and check the preview of affected resources.
  • Validate snapshot restore by creating a volume and checking file system integrity.
  • Check S3 versions appear and practice restoring an older version to a working key.
Key Takeaway
Use the CLI for quick snapshots, DLM for regular automation, and S3 Versioning to protect mutable objects — always verify restores end‑to‑end.
