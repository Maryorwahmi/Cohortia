Verification Checklist
  • Confirm scheduled EBS snapshots appear in the console and can be used to create a volume.
  • Perform an RDS failover test and measure failover time and data consistency.
  • Enable S3 Versioning and upload modified files to confirm historic versions exist.
  • Create an AWS Backup plan that includes lifecycle transition to archive and perform a restore test.
Operational Tips
- Use tags to target resources accurately and avoid accidental snapshot churn.
- Schedule verification tests during a low‑risk maintenance window and document results.
- Align retention counts with compliance; shorter retention saves cost but increases risk.
Scenario Mnemonic
Tag → Snapshot
Tag volumes you want included so DLM only snapshots intended disks.
Version → Recover
Enable Versioning early for buckets that hold mutable data to allow object rollback.
Plan → Test
Define retention, then run restore tests regularly to prove SLAs are met.
