Module 7 › Chapter 7.3 › AWS Backup Architecture
Core components
Backup plan
Schedules, backup window, retention rules, lifecycle transitions.
Resource assignment
Select resources by tags or explicit resource ARN lists.
Backup vault
Encrypted vaults store backups and control access policies and logging.
Restore management
Track restore jobs, test restores, and capture audit trails for compliance.
Example Plan
Daily snapshots for tagged EBS volumes, weekly RDS backups, and lifecycle to move older backups to Glacier after 30 days.
Operational checks
  • Confirm region and service support for each resource type.
  • Verify IAM roles for backup operations and vault encryption configuration.
  • Schedule periodic restore tests and record recovery outcomes.
Key Takeaway
AWS Backup coordinates multi‑service backups, reducing operational complexity and improving auditability when properly configured.
