Module 7 › Chapter 7.6 › Learning Objectives
Practice tasks
  1. Write a hypothesis with measurable success criteria and recovery time.
  2. Design a minimal FIS template that targets a small percentage of instances.
  3. Define CloudWatch-based stop conditions to halt experiments automatically.
  4. Run experiments in staging, validate alerts, then scale cautiously.
Checklist before you run
  • Monitoring covers the experiment metrics and targets.
  • Runbooks and on-call staff are informed and prepared.
  • Stop conditions are defined and tested for responsiveness.
  • Permissioned IAM role exists for FIS actions.
