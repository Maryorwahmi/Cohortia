Module 7 › Chapter 7.6 › Circuit Breaker
Definition

A mechanism that monitors calls to an external dependency and stops attempting calls when the dependency is unhealthy to prevent cascading failures.

States
  • Closed: calls pass normally.
  • Open: calls fail immediately to conserve resources.
  • Half-open: test calls to probe recovery.
Configuration knobs
Sliding window failure threshold, timeout, cooldown period, and probe size for half-open checks.
Example
If payment API times out repeatedly, open the breaker so checkout returns a friendly message and retries later.
Illustration & Explanation
Failure Flow
Repeated failures → open breaker → fast failure responses → recovery probe.
Monitoring
Emit events when state changes and alert on sustained open state so engineers can investigate.
Key Takeaway

Circuit breakers reduce blast radius and conserve resources; always pair them with observability and alerts.
