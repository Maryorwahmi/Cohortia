Module 7 › Chapter 7.6 › Pattern Comparison
Retry
Use for transient errors
Short-lived network glitches or momentary service hiccups. Use exponential backoff and jitter.
Circuit Breaker
Use for persistent failures
When a dependency is repeatedly failing or timing out, fail fast to conserve resources and probe recovery later.
Bulkhead
Use for resource isolation
Prevent resource exhaustion by partitioning threads, queues, or containers for non-critical workloads.
Practical scenario
If a payment API intermittently times out, start with retries and backoff. If timeouts persist, introduce a circuit breaker. If analytics calls consume threads, add bulkheads to preserve the payment path.
