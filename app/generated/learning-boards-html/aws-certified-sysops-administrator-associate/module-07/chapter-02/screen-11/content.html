Architecture Summary
ALB routes traffic to an ASG-backed set of EC2 instances in multiple AZs. ELB health checks ensure traffic only goes to healthy targets and ASG replaces unhealthy instances.
ALB (HTTP/HTTPS)
Target Group
Auto Scaling Group
When a target fails the ALB check, ALB drops it and ASG can be configured to terminate and replace it, restoring capacity across AZs.
Scenario checklist
  • ALB spans multiple public subnets (one per AZ).
  • ASG spans private subnets in the same AZs.
  • Health check path responds quickly and indicates application readiness.
Key Takeaway

Combine multi-AZ placement, ALB routing, and ASG replacement to maintain availability and automate recovery when instances fail.
