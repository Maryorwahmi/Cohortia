Learning Objectives
Learn the design and operational skills needed to keep EC2 applications available and healthy.
01
Design Multi-AZ deployments
Place instances in multiple Availability Zones to remove a single data center as a single point of failure. This matters for resilience when an AZ becomes unreachable.
VERIFIED COMPETENCY MILESTONE
02
Configure Auto Scaling Groups
Define min, max, and desired capacity and use scaling policies so fleets respond to load or failures automatically. This ensures consistent capacity and lowers manual work during incidents.
VERIFIED COMPETENCY MILESTONE
03
Implement Elastic Load Balancing
Choose the appropriate ELB type and register targets across AZs so traffic stays routed to healthy instances during AZ outages and traffic spikes.
VERIFIED COMPETENCY MILESTONE
04
Understand and configure health checks
Use ELB and ASG health checks to detect application-level failures and trigger instance replacement. Good checks validate the application, not just the OS.
VERIFIED COMPETENCY MILESTONE
