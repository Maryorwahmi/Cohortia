Module 7 › Chapter 7.2 › Hands-on Activity
Activity steps
  1. Create an Application Load Balancer across at least two public subnets in different AZs.
  2. Create a target group for HTTP:80 and set health check path to /index.html.
  3. Create a launch template with user data to install and start Apache.
  4. Create an Auto Scaling Group, attach it to the target group, and set health-check-type to ELB.
  5. Verify the ALB DNS returns the index page, then terminate one instance to watch ASG replace it.
CLI snippet (create ASG)
# Create Auto Scaling Group using existing launch template and target group
aws autoscaling create-auto-scaling-group \
  --auto-scaling-group-name MyWebServerASG \
  --launch-template LaunchTemplateName=MyWebServerLaunchTemplate,Version='$Latest' \
  --min-size 2 \
  --max-size 5 \
  --desired-capacity 2 \
  --vpc-zone-identifier "subnet-0abcdef...,subnet-0fedcba..." \
  --health-check-type ELB \
  --health-check-grace-period 300 \
  --target-group-arns "arn:aws:elasticloadbalancing:...:targetgroup/MyTargetGroup/..."
This command shows how the ASG uses a launch template, spans subnets, and relies on ELB health checks to maintain desired capacity.
