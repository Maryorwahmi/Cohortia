Launch Template + User Data
Store instance configuration and a small boot script to install and start your service at launch.
Why it matters: Bootstrapped instances become productive immediately, enabling faster replacement by ASG.
Misconception: Avoid long-running tasks in user data that delay health checks and block scaling.
Set a health-check grace period so your user data can finish before health evaluation begins.
User data example
#!/bin/bash
yum update -y
yum install -y httpd
systemctl start httpd
systemctl enable httpd
echo "<h1>Hello from my Highly Available Web Server!</h1>" > /var/www/html/index.html
This script installs and starts Apache then writes a simple index page. Keep scripts idempotent and lightweight.
