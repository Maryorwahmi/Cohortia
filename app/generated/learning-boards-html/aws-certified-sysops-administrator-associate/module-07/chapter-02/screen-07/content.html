Application Load Balancer (ALB)
Best for HTTP/HTTPS, content-based routing, host and path rules, and metrics at request level.
Use when you need Layer 7 features and application-aware routing.
Network Load Balancer (NLB)
Best for millions of requests, very low latency, TCP/UDP/TLS protocols, and static IP requirements.
Use when raw performance and static IP addresses matter more than request routing.
Gateway Load Balancer (GLB)
Designed to deploy and scale third-party virtual appliances like firewalls and intrusion detection systems.
Use when you need a transparent gateway for virtual network appliances.
Example decision
For a web application serving HTTP content across AZs, choose ALB to leverage path-based routing and ALB health checks. Register the ASG targets in the ALB target group so the ASG can use ELB health checks if configured.
