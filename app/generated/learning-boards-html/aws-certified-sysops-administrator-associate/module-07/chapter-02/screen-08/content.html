Target Groups & ELB
A target group collects endpoints and exposes a health check that the load balancer uses to route traffic to healthy targets only.
  • Registration: ASGs attached to a target group register instances automatically when they launch.
  • Health driven: ALB marks unhealthy targets and stops sending traffic to them.
  • ASG integration: If ASG uses ELB health checks, an unhealthy target can be terminated and replaced.
Example configuration
Create a target group for HTTP on port 80, set health check path to /status or /index.html, and attach the ASG to this target group. Ensure the ASG's VPC subnets span multiple AZs so targets appear in each AZ.
Key Takeaway

Use target groups as the integration point between ELB and ASG to enable automatic registration and health-aware replacement of instances.
