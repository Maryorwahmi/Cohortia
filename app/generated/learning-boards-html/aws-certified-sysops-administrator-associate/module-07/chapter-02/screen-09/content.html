ELB and ASG Health Checks
Health checks are the linking mechanism for traffic routing and instance lifecycle management.
  • ELB checks: HTTP GET or TCP probes to validate target readiness.
  • ASG checks: EC2 status checks by default, but can use ELB results for app-level decisions.
  • Flow: ELB marks unhealthy → ASG replaces instance if configured to use ELB checks.
Best practices
  1. Use an application endpoint like /health that checks runtime dependencies.
  2. Keep checks lightweight to avoid added load or security issues.
  3. Tune health thresholds and grace period to avoid false positives during boot.
Common Mistake

Checking only instance running state or probing heavy operations can hide real failures or cause unnecessary churn. Prefer a quick, representative endpoint.
