Design health checks
Keep checks quick, representative, and safe. Avoid heavy operations that add load or risk security exposure.
Lightweight endpoint: /health that confirms basic dependencies.
Grace period: Allow user data to finish before health evaluation.
Thresholds: Set consecutive success/failure counts to avoid flapping.
Example
If boot takes around 120 seconds for your AMI, set a health-check grace period of 300 seconds. Use health-check interval and unhealthy thresholds that tolerate brief network hiccups.
Quick checklist
  • Make the health endpoint fast and idempotent.
  • Observe real boot times and tune grace period accordingly.
  • Avoid checks that perform heavy database queries on every probe.
