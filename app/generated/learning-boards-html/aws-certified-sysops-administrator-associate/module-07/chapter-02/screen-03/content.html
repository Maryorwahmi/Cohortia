Skills You'll Demonstrate
Concrete lab checks that prove the architecture is highly available and self-healing.
01
Confirm Multi-AZ launches
Verify that instances are placed in at least two different Availability Zones to remove single AZ failure risk.
VERIFIED COMPETENCY MILESTONE
02
Trigger ASG self-healing
Manually terminate an instance and observe the ASG launching a replacement to maintain desired capacity.
VERIFIED COMPETENCY MILESTONE
03
Validate ALB health checks
Confirm the ALB marks instances healthy only when the application endpoint responds, not merely when the OS is running.
VERIFIED COMPETENCY MILESTONE
04
Use launch templates with user data
Bootstrap servers at launch to install web servers and a health endpoint so instances serve traffic immediately when ready.
VERIFIED COMPETENCY MILESTONE
