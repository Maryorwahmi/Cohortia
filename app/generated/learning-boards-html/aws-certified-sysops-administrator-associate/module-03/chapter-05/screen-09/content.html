Module 4 › Chapter 3.5 › CloudFront Mistakes

Common mistakes

OAC misconfigured: Either bucket left public or CloudFront blocked.
Cache headers missing: Cache-Control absent or incorrect causes stale data or no caching.
Registrar not updated: Hosted zone NS records not set at registrar prevents domain resolution.
Certificate region issue: Custom SSL misplacement prevents secure custom domain use with CloudFront.
Troubleshooting checklist
  1. Attempt a direct S3 object fetch; expect denial when OAC is correct.
  2. Fetch the same object through CloudFront; verify it returns and is cached.
  3. Check response headers for Cache-Control and age values to understand caching behavior.
  4. Verify Route 53 Alias record and name-server delegation at your registrar.
Pro tip

When updating many files, prefer versioned filenames to avoid bulk invalidations and reduce risk of origin overload.
