Freshness vs Performance

Choose TTLs and invalidation strategies based on asset update frequency and user impact.

Long TTL
Use for static, versioned assets. Reduces origin load and speeds delivery.
Short TTL
Use for content that changes frequently or is user-specific.
Invalidation
Immediate removal of cached objects; use sparingly and prefer versioning.
Example classifications
  • Logo image: long TTL + versioned filename.
  • Main page HTML: short TTL or cache-control sensitive to updates.
  • User dashboard API: no-cache or very short TTL, forward authorization headers.
Key Takeaway

Classify assets by update frequency and use versioning to minimize invalidations while maximizing performance.
