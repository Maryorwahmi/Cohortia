Static assets and bucket configuration

Upload your static files, keep the bucket private, and plan to use Origin Access Control to permit only CloudFront to read objects.

Why not enable static website hosting?

Static website hosting exposes public URLs that bypass CloudFront; to enforce CDN behavior and TLS, leave hosting off and use OAC.

Example index.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Hello from CloudFront</title>
  </head>
  <body>
    <h1>Hello from CloudFront!</h1>
  </body>
</html>
Upload this index.html as the default root object and confirm it renders via CloudFront once the distribution is deployed.
Pro tip

Use versioned filenames for assets to avoid frequent invalidations when updating static files.
