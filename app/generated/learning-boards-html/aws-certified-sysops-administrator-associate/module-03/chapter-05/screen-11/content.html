A, CNAME, and Alias

Choose the record type that fits your target and whether apex routing is required.

A / AAAA
Map a name to IPv4 or IPv6 addresses directly.
CNAME
Alias a subdomain to another domain name; cannot be used at the zone apex.
Alias (AWS)
Acts like a CNAME but can be used at the zone apex and points directly to AWS resources such as CloudFront.
Practical example
To use yourdomain.com as the primary site and point it at a CloudFront distribution, create an Alias A record at the zone apex that routes to the distribution. CNAME would not be valid at the apex.
Key Takeaway

Use Alias records for apex routing to AWS endpoints; prefer Alias for CloudFront integrations.
