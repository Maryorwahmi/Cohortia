Module 4 › Chapter 3.5 › Practical Reminders
Secure origin
Use Origin Access Control and a strict bucket policy so only CloudFront reads S3 objects.
Cache policy
Set TTLs by asset type and prefer versioned assets to limit invalidations.
DNS delegation
Create a hosted zone, update registrar NS records, and use Alias records to map apex to CloudFront.
Final Thought

These three rules help you deploy secure and high-performance static websites globally. Test each step to be confident in production behavior.
