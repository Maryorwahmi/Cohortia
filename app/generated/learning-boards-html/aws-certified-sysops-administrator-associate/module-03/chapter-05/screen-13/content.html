Deploy a static site: high-level steps

1. Upload to S3
Create bucket named www.yourdomain.com, upload index.html, keep bucket private, do not enable static website hosting.
2. Create CloudFront
Select S3 origin, create OAC, set viewer protocol to redirect to HTTPS, set default root object to index.html.
3. Apply bucket policy
Copy CloudFront’s suggested policy into your S3 bucket to allow only the OAC to get objects.
4. Route 53 hosted zone
Create hosted zone, copy NS records to your registrar, and wait for delegation.
5. Alias record
Create an Alias A record for www.yourdomain.com pointing to the CloudFront distribution.
6. Test & verify
Open https://www.yourdomain.com and confirm the content. Try a direct S3 object URL — it should be denied.
Key Takeaway

Complete each step and verify both CDN delivery and origin protection to ensure a secure, global static site deployment.
