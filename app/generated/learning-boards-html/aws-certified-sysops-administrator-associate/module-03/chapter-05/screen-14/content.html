Module 4 › Chapter 3.5 › Key Concepts
CloudFront
Global CDN that caches content at edge locations to reduce latency and origin load.
Origin Access Control
Restricts S3 access so objects are only retrievable by CloudFront.
Route 53
DNS service for domain registration, hosted zones, records, and routing policies to control traffic.
Summary
CloudFront and Route 53 together enable secure, fast, and globally routed delivery of web content. Verify deployments by testing direct origin access, CDN responses, and DNS delegation.
