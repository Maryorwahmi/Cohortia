Learning Objectives

Skills you will demonstrate by the end of the chapter

Bloom: Learn → Understand → Apply → Master
01
Explain CloudFront benefits

Describe why caching at edge locations reduces latency and protects origin servers, and identify when a CDN is appropriate for your application.

Verified competency milestone
02
Configure CloudFront & OAC

Set up a distribution with an S3 origin, create Origin Access Control, and update the S3 bucket policy so objects are served only via CloudFront.

Verified competency milestone
03
Describe Route 53 fundamentals

Explain hosted zones, record sets, NS delegation, and why Route 53 provides reliable DNS routing for internet applications.

Verified competency milestone
04
Manage routing policies

Create simple, weighted, and latency-based routing records; use health checks and failover records to improve availability and testing scenarios.

Verified competency milestone
