Module 3 › Chapter 3.2 › Common Mistakes & Best Practices
Mistake: Broad SSH access
Opening SSH to the world creates unnecessary attack surface.
Mistake: Forgetting ephemeral rules
Stateless NACLs require both inbound and outbound rules for successful two-way connections.
Practice: Least privilege
Grant only necessary ports and sources, and use security group references for internal services.
Operational guidance
  • Document rule changes and include rollback steps.
  • Audit rules regularly and remove stale entries.
  • During troubleshooting, make minimal and reversible changes.
Key Takeaway
Well-documented, minimal rules across Security Groups and NACLs keep systems secure and reliable.
