Module 3 › Chapter 3.2 › Network ACLs
Definition & Behavior

Stateless subnet filter

Network ACLs require explicit rules for both directions. Rule order is critical and denies can be added to block ranges at subnet scale.

Allow and Deny
NACLs can explicitly deny traffic, making them useful for blocking known bad IPs.
Rule ordering
Rules are evaluated from the lowest number upward; the first match is applied.
Example: ephemeral ports
If inbound port 80 is allowed, you must also add outbound allow for ephemeral 1024-65535 so the server can send responses to clients' ephemeral ports.
Configuration tips
  • Start with explicit allow rules and keep a final deny-all rule.
  • Use low-numbered rules for broad denies you want to match first.
  • Remember to add matching outbound rules for return traffic in stateless systems.
Pitfall

Failing to allow ephemeral ranges outbound will cause successful incoming connections to hang because responses are blocked at the subnet boundary.

Key Takeaway

Use NACLs for explicit subnet-wide denies and broad filtering, and always account for stateless return rules.
