Pattern: Roles + Subnet Filter
  • Assign WebTierSG to web instances allowing HTTP and limited SSH.
  • Assign DatabaseSG to database instances allowing DB ports only from WebTierSG.
  • Attach a NACL to the public subnet to deny known malicious CIDRs and allow required service and ephemeral ranges.
Practical example
If an attacker IP is discovered, add a deny rule in the NACL to block that CIDR for the whole subnet. Security Groups still manage legitimate instance-level access.
Benefit
Defense in depth: even if an SG is mis-applied, the NACL can stop broad threats.
Caution
Avoid duplicative complex rules across layers; document intent to prevent operational errors.
Key Takeaway
Layered controls work best when each layer has a single clear purpose: instance allow vs subnet block.
