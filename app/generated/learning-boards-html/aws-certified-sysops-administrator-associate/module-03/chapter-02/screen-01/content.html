Security Groups & Network ACLs

Stateful instance-level controls meet stateless subnet filters. Learn when each is the right tool and how they work together to protect VPC resources.

In this lesson
Compare behaviors • Configure rules • Troubleshoot connectivity
Instance-level
Security Groups protect individual instances and resources.
Subnet-level
Network ACLs filter traffic in and out of subnets and support explicit denies.
Layered defence
Combine allow-only Security Groups with allow/deny NACLs for broad blocking rules.
Visual Overview
How they relate
Security Groups: stateful, instance. Network ACLs: stateless, subnet. Use both for defence in depth.
Explore Key Topics
Security Groups — instance rules, stateful responses, no explicit deny.
Network ACLs — subnet filters, stateless, explicit allow/deny, rule order matters.
Troubleshooting — ephemeral ports, rule order, and least privilege practice stop most issues.
