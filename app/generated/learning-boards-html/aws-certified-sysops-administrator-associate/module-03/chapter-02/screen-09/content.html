User data script (bash)
#!/bin/bash
yum update -y
yum install -y nginx
systemctl start nginx
systemctl enable nginx
echo "<h1>Hello from WebInstanceWithSG!</h1>" > /usr/share/nginx/html/index.html
Verification commands (SSH)
# Check nginx status
sudo systemctl status nginx

# Confirm port listening
sudo ss -tuln | grep :80
Troubleshooting hints
  • Confirm Security Group inbound allows port 80 from the client source.
  • Check NACL inbound for port 80 and NACL outbound for ephemeral 1024-65535.
  • Verify instance has a public IP and auto-assign is enabled on the subnet.
Key Takeaway
Bootstrapping with user data speeds validation, but always verify both SG and NACL rules when connectivity fails.
