Module 3 › Chapter 3.2 › Diagnosing Connectivity
Step-by-step diagnosis
1. Service health

Confirm the process is running and listening on the expected port.

2. Security Group rules

Verify inbound rules allow the port and correct CIDR. Check all attached SGs and combined effects.

3. Network ACL rules

Inspect inbound and outbound rules, ephemeral ranges, and rule order for explicit denies.

4. Routing & IP

Ensure route tables and internet gateway exist and the instance has a public IP if needed.

5. Test and revert

Make minimal rule changes to test, then harden rules back to least privilege once validated.

Scenario
If SSH works but HTTP times out, check Security Group for port 80, then the NACL inbound for port 80 and outbound for ephemeral ports. Often ephemeral outbound is missing.
