Module 3 › Chapter 3.2 › Key Concepts
Security Group
Instance-level, stateful firewall that allows traffic you explicitly permit.
Network ACL
Subnet-level, stateless filter with ordered rules and explicit allow/deny capability.
Ephemeral Ports
Short-lived client ports (commonly 1024–65535) that must be allowed for return traffic in stateless NACLs.
Takeaway
Use Security Groups for day-to-day instance security and add NACLs for explicit subnet-level blocks; always account for return traffic with stateless filters.
