Module 3 › Chapter 3.2 › Practice Tasks
Task 1 — Security Group and Instance

Create WebTierSG with SSH restricted to your IP and HTTP open, launch an EC2 instance, install a web server, and verify the public IP serves the page.

Task 2 — Network ACL for Public Subnet

Create PublicSubnetNACL, add allow rules for SSH and HTTP and allow ephemeral ranges, then associate it with the public subnet and test connectivity.

Task 3 — Observe and Troubleshoot

Deny HTTP in the NACL to see immediate impact, then follow the checklist: SG inbound, NACL inbound, NACL outbound ephemeral ports, and rule numbering.

Quick Checklist
  • 1. Security Group inbound allows service port from expected source.
  • 2. Network ACL inbound allows the same port for the subnet.
  • 3. Network ACL outbound allows ephemeral range for return traffic.
  • 4. Rule numbers evaluated low-to-high; first match applies.
