Module 3 › Chapter 3.3 › Quick Reference
NAT Gateway
Outbound internet for private subnets; requires Elastic IP and correct route table association.
VPC Endpoint
Gateway for S3/DynamoDB, Interface for PrivateLink services. Secure with endpoint policies and SGs.
VPC Peering
Direct VPC-to-VPC routing; ensure no CIDR overlap and update both sides' route tables.
Fast takeaway

Plan CIDRs, place NATs in public subnets, choose endpoint types by service, and always validate routes and security rules when connectivity fails.
