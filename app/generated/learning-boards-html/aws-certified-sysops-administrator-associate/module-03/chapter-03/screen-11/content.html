Module 3 › Chapter 3.3 › Lab Walkthrough
Lab steps (summary)
  1. Create private subnet in the same AZ as your public subnet.
  2. Allocate Elastic IP and create NAT Gateway in the public subnet.
  3. Create a private route table and route 0.0.0.0/0 to the NAT Gateway.
  4. Launch EC2 into private subnet without public IP and test via bastion host.
  5. Create an S3 Gateway Endpoint and associate it with the private route table.
  6. Verify aws s3 ls and package updates from the private instance.
Terminal-style commands you will use
Examples you will run in the lab: 
# From bastion
ssh ec2-user@10.100.3.10
# On private instance
ping -c 3 google.com
sudo yum update -y
aws s3 ls

# Console actions: Create NAT GW, add route 0.0.0.0/0 -> nat-0abc, create endpoint com.amazonaws.us-east-1.s3 and associate PrivateRT
If aws s3 ls fails, re-check the S3 Gateway Endpoint route association and the private route table ordering.
