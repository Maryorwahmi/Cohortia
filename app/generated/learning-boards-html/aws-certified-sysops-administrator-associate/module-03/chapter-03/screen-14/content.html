Module 3 › Chapter 3.3 › Key Concepts
NAT Gateway
Provides outbound internet access for private instances while blocking inbound initiation.
VPC Endpoint
Private connectivity to AWS services; Gateway for S3/DynamoDB, Interface via PrivateLink for other services.
VPC Peering
Private routing between two VPCs; requires non-overlapping CIDRs and reciprocal route updates.
Summary takeaway

Combine NAT, endpoints, and peering appropriately: deploy NATs for general internet needs, use Gateway Endpoints for S3/DynamoDB to avoid NAT, and peer VPCs for private resource sharing while guarding against CIDR overlap.
