Module 3 › Chapter 3.3 › Deploying a NAT Gateway
Step-by-step
1. Allocate Elastic IP
Reserve a public Elastic IP that the NAT Gateway will use as its source address.
2. Create NAT Gateway
Place it in a public subnet that has an Internet Gateway and choose the allocated Elastic IP.
3. Update route table
Edit private route tables: 0.0.0.0/0 → NAT Gateway ID.
4. Test from private instance
SSH via bastion host, run ping or package update commands to confirm outbound access.

HA recommendation
Deploy a NAT Gateway per Availability Zone and configure private subnets to use the NAT in their AZ to avoid single-AZ failure impact.
