Module 3 › Chapter 3.3 › Troubleshooting Connectivity
Checklist to resolve failures
Routes
Verify route tables and associations for NAT and Gateway endpoints.
NAT placement
Ensure NAT is in a public subnet with IGW access.
Security Groups
For Interface Endpoints, allow traffic to ENI SGs; check instance SGs too.
Endpoint policies
Confirm endpoint policy allows the desired actions.
CIDR overlap
Ensure peered VPCs have non-overlapping CIDRs.
NACLs
Remember they are stateless; allow both directions as needed.
Quick verification commands: 
ping -c 3 8.8.8.8
curl -v https://example.com
aws s3 ls
