Module 3 › Chapter 3.3 › VPC Endpoints — why they matter
Two endpoint types
Gateway Endpoint: Route-table target for S3 and DynamoDB; add a route so service traffic uses the endpoint.
Interface Endpoint: PrivateLink-based ENIs in your subnets with security groups; used by many AWS services and partner services.
Endpoint policy tip
Attach a restrictive endpoint policy to control which principals and actions can use the endpoint and reduce over-broad access.
Concrete example
Create an S3 Gateway Endpoint and associate it with the private route table. After association, aws s3 ls from a private instance works without using NAT. This is cheaper and more secure when only S3 access is required.
Common pitfalls
  • For Interface Endpoints, forget to allow traffic from your subnet to the endpoint ENIs in Security Groups.
  • Failing to attach a restrictive endpoint policy can result in unintended access paths.
