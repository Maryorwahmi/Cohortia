Endpoint policy essentials
Attach a policy to control which principals can use the endpoint and which actions are allowed. This is a fine-grained access control layer in addition to IAM and security groups.
Example
An S3 endpoint policy that allows GetObject only on a specific bucket prefix reduces accidental data exposure from inside the VPC.
Security groups and ENIs
For Interface Endpoints, ensure Security Groups attached to the ENIs permit traffic from your application subnets. Without these rules DNS resolution will succeed but connections fail at the network layer.
Troubleshooting checklist: 
1. Check endpoint type (Gateway vs Interface)
2. For Gateway: verify route table association
3. For Interface: check ENI Security Groups
4. Confirm Network ACLs allow return traffic
5. Verify endpoint policy allows the requested action
