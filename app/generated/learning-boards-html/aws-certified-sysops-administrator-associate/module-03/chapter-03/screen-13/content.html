Module 3 › Chapter 3.3 › Choosing between NAT, Endpoint, Peering
NAT Gateway
Best when instances need general internet access for updates or external APIs. Prevents inbound initiation.
S3 Gateway Endpoint
Best when only S3 access is required. Saves NAT costs and keeps traffic inside AWS.
Interface Endpoint
Use for PrivateLink-enabled services and partner APIs; secure with SGs and endpoint policies.
VPC Peering
Connect two VPCs privately for resource sharing. Plan non-overlapping CIDRs and reciprocal route updates. For many VPCs consider Transit Gateway.
