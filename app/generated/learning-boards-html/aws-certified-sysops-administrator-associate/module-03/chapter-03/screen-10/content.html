Module 3 › Chapter 3.3 › Establishing VPC Peering
Step-by-step checklist
  1. Create peering request in requester VPC and send to target VPC.
  2. Target VPC owner accepts the peering request.
  3. Update both VPC route tables to route remote CIDR via the peering connection.
  4. Adjust Security Groups and NACLs to permit the intended traffic.
  5. Perform connectivity tests and application-level checks.
Command and verification example
Verification from an instance: 
# From instance in VPC-A
ping -c 3 10.100.1.10
# From instance in VPC-B
curl -v http://10.0.2.5:8080
If ping fails but routes look correct, ensure Security Groups allow the protocols and that CIDRs do not overlap.
