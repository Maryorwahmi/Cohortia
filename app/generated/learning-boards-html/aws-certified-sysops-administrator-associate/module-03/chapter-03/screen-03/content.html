Module 3 › Chapter 3.3 › Lab Objectives
01 — Build the network
Create a private subnet, a public subnet with an Internet Gateway, and a NAT Gateway in the public subnet with an Elastic IP.
02 — Route and test
Attach routes so the private subnet sends 0.0.0.0/0 to the NAT Gateway, launch a private EC2 instance, and verify outbound connectivity through a bastion host.
03 — Add S3 Gateway Endpoint
Create an S3 Gateway Endpoint and associate it with the private route table to allow S3 access without NAT.
04 — Verify and troubleshoot
Run package updates and aws s3 ls, and if something fails, check route tables, endpoint associations, SGs, and NAT placement.
