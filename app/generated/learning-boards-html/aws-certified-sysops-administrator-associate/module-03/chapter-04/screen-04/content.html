What is Elastic Load Balancing (ELB)?

Distributing Traffic for Scalability and Resilience

ELB: The Traffic Orchestrator

Elastic Load Balancing (ELB) is an AWS service that automatically distributes incoming application traffic across multiple targets, such as EC2 instances, containers, and IP addresses, in one or more Availability Zones. It acts as a single point of contact for clients, ensuring efficient traffic flow.

Enhanced Fault Tolerance

ELB detects unhealthy targets and routes traffic only to healthy ones, preventing service disruptions.

Improved Scalability

Dynamically add or remove targets to handle fluctuating traffic demands without manual intervention.

Enhanced Security

Provides a single, managed entry point, simplifying security group configurations and access control.
