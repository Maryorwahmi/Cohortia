Gateway Load Balancer (GLB)

Simplifying Network Virtual Appliance Management

Layer 3 Transparency

GLBs operate at the network layer (Layer 3), acting as a transparent network gateway. They simplify the insertion of third-party network virtual appliances into the network path.

Virtual Appliance Integration

Seamlessly integrates firewalls, intrusion detection/prevention systems, and deep packet inspection systems.

Scalable Security

Distributes traffic to a fleet of virtual appliances, allowing them to scale independently.

Transparent Insertion

Acts as a transparent gateway, ensuring traffic flows through appliances without altering network topology.
