Target Groups and Health Checks

Ensuring Healthy Application Backends

Target Groups: The Backend Pool

A target group routes requests to one or more registered targets (e.g., EC2 instances) using a specified protocol and port. It's the destination for traffic defined by listener rules.

Logical Grouping

Organizes targets that serve the same function, allowing load balancers to distribute traffic efficiently.

Health Checks

Monitors the health of registered targets, automatically removing unhealthy ones from rotation.

High Availability

Ensures traffic is only sent to functional instances, significantly improving application resilience.
