Application Load Balancer (ALB)

Intelligent Routing for Web Applications

Layer 7 Capabilities

ALBs operate at the application layer (Layer 7), allowing them to inspect the content of HTTP/HTTPS requests. This enables advanced routing decisions based on various request attributes.

Content-Based Routing

Route requests based on URL path, host header, query string, or HTTP method.

Microservices & Containers

Ideal for routing traffic to different services within a microservices architecture or containerized applications.

HTTP/2 & WebSockets Support

Native support for modern web protocols, enhancing performance and real-time communication.
