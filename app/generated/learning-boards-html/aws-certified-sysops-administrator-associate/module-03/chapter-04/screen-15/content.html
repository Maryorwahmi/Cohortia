Chapter 3.4 Review

Key Concepts

Configuration and Operational Elements

Gateway Load Balancer (GLB)

Layer 3 load balancer for deploying and managing virtual network appliances.

Listener

Checks for client connection requests using a configured protocol and port.

Target Group

Logical grouping of targets (e.g., EC2 instances) that a load balancer routes requests to.

Summary Takeaway

Listeners, target groups, and health checks are the core components for defining how ELB receives, routes, and monitors traffic to ensure application health and availability.
