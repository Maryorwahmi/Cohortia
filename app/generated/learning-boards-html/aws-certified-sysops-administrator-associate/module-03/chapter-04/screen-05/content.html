ELB Types

Choosing the Right Load Balancer

Understanding ALB, NLB, and GLB

Application Load Balancer (ALB)

Layer 7 (HTTP/HTTPS)

Ideal for web applications, microservices, and container-based workloads. Offers advanced content-based routing.

Use Case

Routing traffic to different services based on URL path.

Network Load Balancer (NLB)

Layer 4 (TCP/UDP/TLS)

Designed for extreme performance, ultra-low latency, and high throughput. Handles millions of requests per second.

Use Case

Real-time gaming, IoT, or high-performance computing.

Gateway Load Balancer (GLB)

Layer 3 (Network)

Used for deploying, scaling, and managing third-party network virtual appliances (e.g., firewalls).

Use Case

Inserting firewalls or IDS/IPS into network traffic path.
