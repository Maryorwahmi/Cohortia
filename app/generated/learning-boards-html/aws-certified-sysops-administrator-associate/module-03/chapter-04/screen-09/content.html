ELB Listeners and Rules

Defining How Traffic is Received and Routed

The Role of Listeners

A listener is a process that checks for connection requests from clients, using the protocol and port that you configure. It's the entry point for traffic into your load balancer.

Protocol & Port

Listeners are configured with a specific protocol (e.g., HTTP, HTTPS, TCP) and port (e.g., 80, 443).

Routing Logic

Each listener has rules that define how incoming requests are routed to target groups.

Content-Based Rules (ALB)

ALBs can use conditions like URL path or host headers to route requests to different target groups.
