Network Load Balancer (NLB)

Extreme Performance for Latency-Sensitive Workloads

Layer 4 Efficiency

NLBs operate at the transport layer (Layer 4), focusing on TCP, UDP, and TLS traffic. They do not inspect content, allowing for ultra-low latency and high throughput by simply forwarding requests.

Ultra-Low Latency

Designed for applications requiring minimal delay, handling millions of requests per second with extreme efficiency.

Static IP Addresses

Supports static IP addresses for the load balancer, useful for firewall whitelisting and specific integrations.

High-Throughput Workloads

Ideal for applications that require processing a massive volume of data with minimal processing overhead.
