ELB and Security Group Configuration

Securing Traffic Flow to Backend Instances

The Security Group Connection

Security Groups act as virtual firewalls for your instances. Correctly configuring them to allow traffic from your load balancer is crucial for both connectivity and security.

ALB Security Group Reference

For ALBs, allow inbound traffic on instance SGs from the ALB's Security Group ID for best practice.

NLB Subnet CIDR

For NLBs, allow inbound traffic from the NLB's subnet CIDR range in your instance Security Groups.

Common Misconfiguration

Forgetting to update instance SGs can lead to health check failures and unreachable applications.
