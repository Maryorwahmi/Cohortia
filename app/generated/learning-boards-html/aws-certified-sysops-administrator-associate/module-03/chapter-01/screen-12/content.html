Hands-on Activity › Create VPC & Public Subnets
Condensed step list
  1. Create VPC with IPv4 CIDR 10.100.0.0/16.
  2. Create PublicSubnet-AZ1 10.100.1.0/24 and PublicSubnet-AZ2 10.100.2.0/24; enable auto-assign public IPv4.
  3. Create and attach an Internet Gateway to the VPC.
  4. Create a public route table: add route 0.0.0.0/0 → IGW, then associate both public subnets.
  5. Launch EC2 in a public subnet with user data to start a web server and security group allowing HTTP/SSH for testing.
Key Takeaway

Follow the sequence and verify each network piece before moving to the next to avoid common setup errors.
