Comparison › Common Misconfigurations
Configuration
  • IGW not attached to VPC.
  • Route table missing 0.0.0.0/0 → IGW.
  • Subnet not associated with public route table.
  • No public IP on the instance.
Security & Overlap
  • Security group blocking inbound or outbound traffic.
  • Overlapping CIDR with on-prem or other VPCs causing routing conflicts.
  • NAT or gateway misconfiguration for private outbound traffic.
Troubleshoot flow

Check IGW attachment → verify public route → confirm subnet association → confirm public IP → review security group. This ordered checklist resolves most connectivity issues quickly.
