Definition › Public vs Private Subnets
Public subnet
Has a route to an Internet Gateway and typically contains resources that must be reachable from the internet.
Example: Web servers with public IPs and a route 0.0.0.0/0 → IGW.
Common error: Instances lack connectivity when the IGW is not attached or when the public route is missing.
Private subnet
No direct route to an Internet Gateway; outbound internet access usually requires a NAT Gateway or instance.
Example: Databases and backend services that should not be directly reachable from the internet.
Why it matters: Privatizing sensitive workloads reduces attack surface and keeps direct inbound access blocked by routing.
Pro Tip

Verify the route table association for each subnet; a missing association is a frequent cause of unexpected private behavior.
