VPC — definition and purpose
A logically isolated virtual network where you control IP addressing, subnets, and routing.
Key points
  • CIDR block defines the VPC address space (for example, 10.0.0.0/16).
  • Subnets segment the address space and are bound to individual Availability Zones.
  • Route tables and gateways control connectivity to the internet and other networks.
Key Takeaway

Treat a VPC as your private network in AWS; design its CIDR carefully and segment by subnet and AZ for isolation and resilience.

Analogy
If AWS is a city, a VPC is your fenced property. You decide the address numbering, who can enter, and how streets connect to the outside world.
Concrete example
Choose 10.0.0.0/16 for a VPC. Then create frontend subnet 10.0.1.0/24 and backend subnet 10.0.2.0/24 in different AZs for separation and fault tolerance.
Common misconception
The default VPC is not always sufficient for production: custom VPCs allow precise IP planning and security configuration.
