Definition › Internet Gateway
Internet Gateway — two roles
  • Target for internet-bound routes in route tables.
  • Performs NAT for instances with public IPv4 addresses so they can communicate over the internet.
Operational checks: Is the IGW attached? Does the public route table include 0.0.0.0/0 → IGW? Is the subnet associated with that route table?
Common error: IGW created but not attached, or route table missing the 0.0.0.0/0 entry.
Quick example
Create MySysOpsVPC-IGW, attach to MySysOpsVPC, and set 0.0.0.0/0 route in MySysOpsVPC-PublicRT to that IGW.
Key Takeaway

An IGW must be attached and referenced by a public route for instances to reach or be reached from the internet.
