Learning Objectives
Learn the essential skills to design and verify a basic VPC.
Bloom: Learn → Understand → Apply → Master
01
Explain core VPC components
Describe VPC, subnets, route tables, and Internet Gateway and why each matters for isolation and connectivity.
VERIFIED COMPETENCY MILESTONE
02
Design public and private subnets
Plan subnet CIDRs and AZ mapping to support availability and secure internet access patterns.
VERIFIED COMPETENCY MILESTONE
03
Configure CIDR blocks
Choose appropriate prefix lengths, balance capacity with avoidable overlap for peering or VPNs.
VERIFIED COMPETENCY MILESTONE
04
Launch an EC2 in a public subnet
Deploy a simple web server using user data and verify public IP connectivity.
VERIFIED COMPETENCY MILESTONE
