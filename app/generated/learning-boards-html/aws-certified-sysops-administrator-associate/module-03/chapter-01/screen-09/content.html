Process Flow › Route Tables & Associations
Routes control traffic
Each route maps a destination CIDR to a target like an IGW or NAT.
Common routes: 0.0.0.0/0 → IGW for public subnets; 0.0.0.0/0 → NAT for private outbound.
Troubleshoot: If internet access fails, verify IGW attachment, route entry existence, and subnet association.
Example checklist
  1. Confirm IGW is attached to the VPC.
  2. Confirm public route table has 0.0.0.0/0 → IGW.
  3. Ensure subnet is associated with the public route table.
  4. Confirm instance has a public IPv4 address and security group allows required traffic.
Key Takeaway

Explicit route table associations and correct targets are required for the connectivity you expect.
