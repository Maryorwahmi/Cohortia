What to Remember
CIDR Planning
Select a VPC prefix that supports growth and avoids overlap with systems you’ll connect to.
Routing & IGW
Ensure 0.0.0.0/0 points to an attached IGW for public subnets to be internet-accessible.
Verification Flow
Check IGW attach → route table → subnet association → public IP → security group.
Final takeaway

Design deliberately, verify methodically, and document CIDR and subnet assignments to keep cloud networks reliable and auditable.
