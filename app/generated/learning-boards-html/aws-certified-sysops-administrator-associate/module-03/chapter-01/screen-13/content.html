Lab Walkthrough › EC2 Network Settings
Network decisions at launch
  • VPC: MySysOpsVPC
  • Subnet: MySysOpsVPC-PublicSubnet-AZ1
  • Auto-assign public IP: Enabled (or request public IP)
  • Security group: allow HTTP (80) from 0.0.0.0/0 and SSH from your IP
Verification steps
After launch, copy Public IPv4 and open it in a browser. If unreachable, validate the route table, IGW attachment, public IP presence, and security group rules.
Common mistake

Forgetting to enable public IP assignment or associating the subnet with the public route table will leave the instance unreachable despite correct security group settings.
