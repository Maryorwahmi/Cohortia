Module 5 › Chapter 5.3 › Modify EBS volumes
Modify without detaching
Submit a modification, then rescan and extend file system inside the OS.
Example CLI step
# Modify a gp3 volume to increase IOPS
aws ec2 modify-volume --volume-id vol-0fedcba9876543210 --iops 5000 --size 100
OS steps after modification
  • Rescan the block device so the OS sees the new size.
  • Use xfs_growfs or resize2fs to grow the filesystem to the new capacity.
  • Verify with lsblk and df -h that space is available.
Pro tip
Snapshot before large modifications so you can restore if an unexpected issue occurs during the change.
