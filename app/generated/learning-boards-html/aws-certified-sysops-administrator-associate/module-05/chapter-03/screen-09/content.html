Module 5 › Chapter 5.3 › Attach, format, mount
CLI & OS walkthrough
Follow these commands exactly and verify device names with lsblk before formatting.
# Create a volume (example)
aws ec2 create-volume --availability-zone us-east-1a --size 100 --volume-type gp3 --tag-specifications 'ResourceType=volume,Tags=[{Key=Name,Value=my-data-volume}]'

# Attach the volume (replace IDs)
aws ec2 attach-volume --instance-id i-0abcdef1234567890 --volume-id vol-0fedcba9876543210 --device /dev/sdh

# On the instance:
lsblk
sudo mkfs -t xfs /dev/sdh
sudo mkdir /data
sudo mount /dev/sdh /data
sudo touch /data/testfile.txt
# Add to fstab for persistence
echo "/dev/sdh /data xfs defaults,nofail 0 2" | sudo tee -a /etc/fstab
Validation steps
  • Confirm device presence with lsblk and dmesg if necessary.
  • Verify mount with df -h and create a test file to confirm write access.
  • If NVMe devices are used, map NVMe device names to volume IDs before formatting.
Common mistake
Formatting the wrong device can destroy data. Always confirm the correct device mapping before mkfs.
