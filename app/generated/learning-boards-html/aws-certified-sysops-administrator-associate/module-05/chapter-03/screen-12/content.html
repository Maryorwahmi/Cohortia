Module 5 › Chapter 5.3 › Fast Snapshot Restore (FSR)
What FSR does
FSR pre-provisions snapshot data in the target Availability Zone so volumes created from the snapshot are immediately fully performant.
Key constraints: enabled per-snapshot per-AZ and incurs additional cost. Use for critical recovery points where RTO matters.
Recovery workflow
  1. Take a snapshot of the volume.
  2. Copy snapshot to target AZ/region if needed.
  3. Enable FSR for the snapshot in the target AZ.
  4. Create a new volume from the FSR-enabled snapshot for immediate full performance.
Use case
For a 500 GiB database that must be recovered within minutes and at full performance, enable FSR on the snapshot in the recovery AZ to meet a tight RTO.
