Module 5 › Chapter 5.3 › EBS Snapshots
Incremental backup model
Only changed blocks since the last snapshot are stored, optimizing storage and snapshot time.
Cross-region and restore
You can copy snapshots across regions to enable cross-region recovery and create volumes from snapshots for restore or cloning.
CLI example
# Create a snapshot
aws ec2 create-snapshot --volume-id vol-0fedcba9876543210 --description "Backup of my data volume" --tag-specifications 'ResourceType=snapshot,Tags=[{Key=Name,Value=my-data-backup}]'

# Create a new volume from a snapshot
aws ec2 create-volume --availability-zone us-east-1a --snapshot-id snap-0123456789abcdef0 --volume-type gp3 --size 100
Operational note
Restored volumes may be slow to reach full performance because blocks are fetched on first access — consider FSR for rapid full-performance restores.
