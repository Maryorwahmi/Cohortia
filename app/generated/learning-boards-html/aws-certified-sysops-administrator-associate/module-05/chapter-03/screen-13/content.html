Module 5 › Chapter 5.3 › Monitor EBS with CloudWatch
Essential metrics
  • VolumeReadBytes / VolumeWriteBytes — throughput in bytes.
  • VolumeReadOps / VolumeWriteOps — number of I/O operations.
  • VolumeQueueLength — number of I/O requests waiting; sustained high values indicate bottlenecks.
  • BurstBalance — remaining I/O credits for gp2; zero means throttling.
Example alarm strategy
Create alarms for sustained VolumeQueueLength above a threshold, and for BurstBalance below a low threshold on gp2 volumes. Correlate with application latency metrics before performing changes.
Check your understanding
If you see high queue length and low throughput, what remediation would you consider: change volume type, increase IOPS, or distribute load? All three may be valid; choose after profiling.
