Module 5 › Chapter 5.3 › EBS Volume Types Overview
gp2 / gp3
Balanced, general-purpose SSDs. Use for boot volumes, dev/test, and interactive apps. gp3 separates IOPS and throughput from size for better cost control.
io1 / io2 (Block Express)
Provisioned IOPS SSDs for databases and latency-sensitive workloads. Provision required IOPS explicitly; io2 Block Express supports the highest IOPS and durability.
st1 / sc1
st1 is throughput-optimized HDD for streaming large sequential workloads. sc1 is cold HDD for lower-cost, infrequently accessed data.
Operational guidance
  • Profile I/O: measure IOPS and throughput before choosing a type.
  • Avoid gp2 for databases that need consistent high IOPS; choose io1/io2 instead.
  • Use st1 for large sequential workloads like data warehouses or ETL pipelines.
Concrete example
For a transactional database with predictable high IOPS, choose io2 and provision the IOPS you need; for a web server boot disk, gp3 is usually sufficient.
