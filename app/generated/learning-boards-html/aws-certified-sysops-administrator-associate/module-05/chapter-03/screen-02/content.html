Learning Objectives
Learn the practical skills needed to manage EBS for EC2 applications
01
Select EBS volume types

Understand gp2/gp3, io1/io2, st1, and sc1 and choose the best fit for IOPS, throughput, and cost.

Venn: performance vs cost
VERIFIED COMPETENCY MILESTONE
02
Attach, detach, and modify volumes

Perform operational volume tasks, and resize or change performance parameters without detaching when possible.

Timeline: attach → format → mount
VERIFIED COMPETENCY MILESTONE
03
Snapshots and restores

Create incremental snapshots, restore volumes from them, and copy snapshots for cross-region recovery.

Mnemonic: incremental deltas
VERIFIED COMPETENCY MILESTONE
04
Enable Fast Snapshot Restore

Pre-provision snapshot data in the target AZ to restore volumes at full performance immediately when needed.

Checklist: snapshot → FSR → restore
