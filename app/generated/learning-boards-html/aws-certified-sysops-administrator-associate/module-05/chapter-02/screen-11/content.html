Module 5 › Chapter 5.2 › Object Lock Modes
Governance mode
Allows users with special permissions to override retention. Useful when you need protection but occasional administrative flexibility.
When to choose
Internal policies where overrides by designated personnel are permissible and you need protection against accidental deletion.
Compliance mode
Prevents any user, including root, from altering or deleting the object until retention expires. Use when law requires absolute immutability.
When to choose
Legal or regulatory obligations that explicitly prohibit any modification or deletion during the retention period.
Operational warning
You cannot enable Object Lock on an existing bucket. Create buckets with Object Lock from the start if compliance is required.
