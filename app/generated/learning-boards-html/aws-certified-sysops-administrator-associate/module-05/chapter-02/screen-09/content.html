Retrieval types
  • Expedited: fastest, costliest — use for urgent restores when RTO is very short.
  • Standard: balanced time and cost for typical restores.
  • Bulk: cheapest per GB but slowest — suitable for large, non-urgent restores.
  • Deep Archive: retrieval typically within 12 hours; plan ahead for restores.
Example tradeoff
If a dataset needs to be restored within 30 minutes for an incident, expedited retrieval is appropriate despite higher cost. If it is used once a year for audits, Deep Archive with planned restores is best for cost savings.
Practical tip
Calculate expected restore frequency and multiply by retrieval cost to compare with ongoing storage savings before moving objects to archive classes.
