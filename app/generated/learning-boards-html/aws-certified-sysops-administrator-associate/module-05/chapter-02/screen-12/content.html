Module 5 › Chapter 5.2 › Object Lock CLI
CLI example (visual)
aws s3api put-object \
  --bucket my-compliance-bucket \
  --key sensitive-document.pdf \
  --body sensitive-document.pdf \
  --object-lock-mode COMPLIANCE \
  --object-lock-retain-until-date 2025-12-31T00:00:00Z
Explanation
Provide the bucket name, object key, file body, lock mode, and the retain-until timestamp. The bucket must have Object Lock enabled during creation.
Key Takeaway

Run the CLI with correct retention mode and ISO timestamp, then verify the object's retention metadata in the console or via the API.

Preconditions
Bucket created with Object Lock enabled and versioning. Ensure your CLI user has s3:PutObjectRetention and related permissions.
Misstep to avoid
Do not attempt to enable Object Lock on an existing bucket; create the bucket with Object Lock enabled if immutability is required.
