Module 5 › Chapter 5.2 › CRR Setup
Step-by-step
1. Enable Versioning
Turn on versioning for both source and destination buckets; replication depends on versions.
2. Create Replication Rule
Select all objects or a specific prefix/tag. Name the rule and enable it.
3. Configure IAM Role
Allow S3 to assume a role to perform replication; AWS can auto-create this role.
4. Plan Encryption
If using KMS, ensure keys are accessible in both regions or re-encrypt as needed.
Concrete scenario
You enable versioning on prod-configs-us and prod-configs-eu, create a replication rule for prefix config/, and allow AWS to create the replication role. Test by uploading a new config and watching it appear in the destination.
Visual checklist
Versioning: Enabled
Replication rule: Enabled
IAM role: Exists
Encryption: Reviewed
Common misconception
Assuming replication will begin immediately and copy everything. Replication copies new objects after the rule is active; existing objects require a separate operation.
