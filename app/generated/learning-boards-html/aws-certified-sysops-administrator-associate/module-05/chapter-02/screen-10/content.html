Module 5 › Chapter 5.2 › Object Lock
What Object Lock does
  • Enables WORM protection so objects cannot be deleted or altered for the retention period.
  • Supports retention periods per object or default retention per bucket.
  • Supports legal holds that remain until explicitly removed.
Example
Upload regulatory records with Compliance mode retention to ensure no user can delete them for the required period.
Operational constraints
Object Lock must be enabled at bucket creation and cannot be added to an existing bucket. Plan retention windows carefully because Compliance mode cannot be overridden.
Misconception
Assuming Governance mode is as strong as Compliance mode. Governance mode allows privileged users to override the lock, so it does not meet requirements that forbid any deletion by any user.
