Module 5 › Chapter 5.5 › Storage Gateway vs DataSync
Storage Gateway
Ongoing hybrid access for apps using NFS, SMB, or iSCSI with local caching and S3 durability.
  • File Gateway for file shares.
  • Volume Gateway for block volumes and snapshots.
  • Tape Gateway for virtual tape workflows.
DataSync
Agent-based transfers optimized for speed, integrity, and automation when moving large datasets to or between AWS services.
  • Ideal for migrations and replications.
  • Handles retries, integrity checks, and scheduling.
Key Takeaway

Often you will use DataSync for an initial bulk move and Storage Gateway for steady-state hybrid access and protocol compatibility.
