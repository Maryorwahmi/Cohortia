Module 5 › Chapter 5.5 › Deploying a File Gateway
Quick checklist
  1. Provision VM on supported hypervisor or EC2 and allocate network access.
  2. Attach local disks for cache and upload buffer (150 GiB recommended for testing).
  3. Register gateway in the Storage Gateway console using VM IP.
  4. Create an SMB or NFS file share pointing to an S3 bucket backend.
  5. Mount the share and verify S3 object creation.
Network and security
Open ports 80 and 443 and the applicable file protocol ports from clients to the gateway. Configure IAM roles allowing S3 access for the gateway.
Common mistake

Insufficient cache or blocked network ports are frequent causes of deployment failure. Validate both before creating shares.
