Module 5 › Chapter 5.5 › Volume Gateway Comparison
Cached Volumes
Primary data in S3; local cache for hot blocks.
  • Cost-effective for large datasets.
  • Provision local storage only for cache.
  • Good when apps access a subset of data.
Stored Volumes
Primary data on-premises; snapshots uploaded to S3.
  • Low-latency access to full dataset locally.
  • Use snapshots for durable backups in S3.
  • Appropriate when on-premises performance is critical.
Common mistakes
Under-provisioning cache for Cached mode, expecting immediate synchronization, or not scheduling regular snapshot verification for Stored mode.
Key Takeaway

Match mode to access patterns: cached for cloud-first datasets, stored when full local copies are required.
