Module 5 › Chapter 5.5 › What is Storage Gateway
Storage Gateway architecture
An on-premises appliance that caches and translates protocol calls to durable AWS storage.
File Gateway
Exposes NFS/SMB and stores objects in S3 while caching hot files locally.
Volume Gateway
Exposes iSCSI volumes. Cached mode keeps primary data in S3 with local cache; Stored mode keeps primary on-prem and snapshots to S3.
Tape Gateway
Provides a VTL for existing backup software, storing virtual tapes in S3 and Glacier for archival.
Operational considerations
  • Ensure network connectivity and required ports are open for gateway communication with AWS.
  • Allocate sufficient local disk for cache and upload buffer; insufficient cache degrades performance.
  • Configure IAM roles and security groups so the gateway can write to S3 and create snapshots.
Key Takeaway

Storage Gateway preserves compatibility and performance by exposing familiar endpoints and caching hot data while making cloud storage the durable backend.
