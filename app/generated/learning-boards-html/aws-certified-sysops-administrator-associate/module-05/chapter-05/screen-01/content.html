AWS Storage Gateway and DataSync
Hybrid access patterns and fast transfer workflows for on-premises data

In this chapter you will compare ongoing hybrid storage access with a purpose-built transfer service. Both reduce operational load while preserving application compatibility.

File Gateway
NFS/SMB shares backed by S3; good for file server replacement.
Volume Gateway
iSCSI volumes; cached or stored modes for different latency and durability needs.
DataSync
Agent-driven migrations and replications with integrity checks and scheduling.
