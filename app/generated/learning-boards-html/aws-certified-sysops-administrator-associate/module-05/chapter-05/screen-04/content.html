Module 5 › Chapter 5.5 › Hybrid Cloud Storage Challenges
What is at stake

Maintaining application compatibility, predictable latency, and durable backups while reducing on-premises operational burden.

Protocol compatibility
Keep NFS, SMB, and iSCSI endpoints so applications need no change.
Local performance
Use local cache to reduce latency for hot data.
Durability and archival
Store objects in S3 and archive to Glacier via lifecycle policies.
Illustrative scenarios
Replace file server
Use File Gateway to present SMB and back data to S3; users continue using mapped drives.
Migrate archives
Use DataSync to move large NFS exports into S3 with integrity checks and scheduling.
Key Takeaway

Decide between hybrid access (Storage Gateway) and accelerated transfer (DataSync) based on access patterns and migration timing.
