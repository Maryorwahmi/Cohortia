Mount example (Windows)
Use the native net use command to map an SMB share provided by the gateway.
# From Command Prompt or PowerShell
net use Z: \\<FileGatewayIP>\sharename

# Then create a file in the share, for example:
# Save a file named onprem-test.txt to the mapped Z: drive
After creating the file, open the S3 console and navigate to the backend bucket to confirm the object exists. Monitor upload buffer and cache metrics to ensure uploads proceed.
Linux mount tip
Install cifs-utils and mount with options matching the gateway configuration. Guest access simplifies the test but use Active Directory in production.
Key Takeaway

Mount and write a file, then verify the corresponding S3 object to validate File Gateway functionality and permissions.
