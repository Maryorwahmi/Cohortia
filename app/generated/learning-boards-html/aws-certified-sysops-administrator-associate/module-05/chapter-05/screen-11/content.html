Module 5 › Chapter 5.5 › AWS DataSync Overview
What DataSync provides
Agent-based transfers, accelerated protocol, integrity checks, task scheduling, and detailed monitoring for large data movements.
Sources
NFS, SMB, self-managed object stores, HDFS.
Destinations
Amazon S3, EFS, FSx for Windows File Server.
DataSync reduces operational complexity for migrations by handling retries, parallelism, and integrity checks. Use CloudWatch and the DataSync console to monitor task progress and error detail.
Key Takeaway

Choose DataSync for high-volume, integrity-checked transfers; choose Storage Gateway when you need continuous hybrid access with protocol endpoints.
