Module 5 › Chapter 5.5 › Key Concepts
AWS Storage Gateway
Hybrid appliance exposing NFS, SMB, or iSCSI and caching hot data while storing durable data in S3.
File, Volume, Tape
File Gateway for S3 objects, Volume Gateway for iSCSI volumes, Tape Gateway for VTL archival workflows.
AWS DataSync
Agent-driven, accelerated transfers that handle scheduling, retries, and integrity checks for large data moves.
Summary

Use Storage Gateway for protocol compatibility and ongoing hybrid access; use DataSync for high-speed migrations and replication.
