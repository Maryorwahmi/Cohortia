Module 5 › Chapter 5.4 › Decision Guide
Decision rules
  • Protocol-first: SMB/NTFS/AD → FSx for Windows.
  • Parallel HPC throughput → FSx for Lustre with optional S3 linking.
  • Linux shared access, elastic growth → EFS with elastic throughput.
Common operational mistakes
  • Using EFS for Windows SMB workloads and losing NTFS semantics.
  • Creating mount targets only in one AZ and suffering availability issues.
  • Confusing performance and throughput modes when tuning for latency vs aggregate throughput.
Try this
Before migrating, validate file semantics and measure throughput using a test cluster that resembles production concurrency to avoid surprises.
