Module 5 › Chapter 5.4 › FSx for Lustre
Core capabilities
  • Parallel file system tuned for massive throughput and low latency.
  • Supports scratch and persistent file systems for different lifecycles.
  • Optional native integration with S3 for staging and exporting data.
Concrete scenario
A distributed training cluster stages terabytes of images in S3, links an FSx Lustre file system to that bucket, processes data with many GPU instances for fast I/O, then writes the trained model back to S3.
Misconception
Assuming EFS can replace Lustre for HPC workloads. EFS does not provide the same parallel I/O characteristics and peak throughput as Lustre.
Key Takeaway

Use FSx for Lustre when job completion time depends on very high aggregate throughput and low-latency parallel reads and writes.
