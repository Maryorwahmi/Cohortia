Module 5 › Chapter 5.4 › Mount Targets & Network
Network integration pattern
A mount target is an IP endpoint in a subnet that allows EC2 instances in the same VPC to access the file system via NFSv4. Create one per AZ used by clients for high availability.
Operational steps
  • Create mount targets in each subnet/AZ used by clients.
  • Attach security groups that allow inbound NFS (2049) from client SGs.
  • Use Direct Connect or VPN for on-premises NFS mounts into the VPC.
Example
Two web servers in separate AZs each mount the EFS file system via the local mount target. This prevents cross-AZ traffic and keeps availability local to each AZ.
Checklist
  • Mount targets created in all required AZs.
  • Security groups allow NFS access only to intended clients.
  • Install amazon-efs-utils on Linux clients and verify TLS mount option if required.
Key Takeaway

Mount targets and security groups are the network control points for EFS; distribute mount targets across AZs and lock down access to client security groups.
