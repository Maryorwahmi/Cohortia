Module 5 › Chapter 5.4 › Mount Demo
Terminal commands (visual)
The block below contains the sequence: install utilities, create mount point, mount with TLS, and add to /etc/fstab for persistence. Use your file system ID in place of the example ID.
# Install NFS and EFS utilities
sudo yum install -y amazon-efs-utils nfs-utils

# Create a mount point
sudo mkdir /mnt/efs

# Mount EFS using the EFS mount helper (replace fs-abcdef1234567890)
sudo mount -t efs -o tls fs-abcdef1234567890:/ /mnt/efs

# Verify the mount
df -h /mnt/efs

# Add to /etc/fstab for persistent mounting
echo "fs-abcdef1234567890:/ /mnt/efs efs _netdev,tls 0 0" | sudo tee -a /etc/fstab
Example verification
On Instance A write a file into /mnt/efs and on Instance B cat that file to confirm shared visibility across mounts.
Common mistake
If you omit _netdev in /etc/fstab, the mount can fail at boot because networking is not available yet when mount attempts run.
Quick pro tip
Use the EFS DNS name or mount helper for automated regional endpoint resolution and TLS by default when available.
Key Takeaway

Follow the install, mount, verify, and persist sequence to ensure reliable, shared mounts across EC2 instances.
