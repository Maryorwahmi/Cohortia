Module 5 › Chapter 5.4 › EFS Defined
Core definition
A fully managed, elastic NFS file system that scales automatically and supports multi-AZ mounts for Linux clients.
Concrete example
An autoscaling fleet of web servers mounts a single EFS file system for a shared document root so uploads and static assets are consistent across instances.
Misconception
EFS is not block storage like EBS; it’s file-level storage over NFS. Treat it as a shared namespace for many clients.
Security and integration
  • Use VPC security groups on mount targets to control NFS access.
  • Use EFS access points for application-scoped access control.
  • On-premises access is possible via Direct Connect or VPN with NFSv4.
Operational tip
Create mount targets in each AZ used by clients to reduce cross-AZ network hops and improve availability.
Key Takeaway

EFS is ideal for multi-instance Linux workloads that need a shared file namespace and elastic storage scaling.
