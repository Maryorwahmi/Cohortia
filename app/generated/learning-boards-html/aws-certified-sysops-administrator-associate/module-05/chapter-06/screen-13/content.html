Module 5 › Chapter 5.6 › Activity Walkthrough
Lab steps
  1. Tag EC2 and RDS with Environment=Production and Application=CriticalApp.
  2. Create CriticalAppBackupPlan with a daily rule at 05:00 UTC and 90-day retention.
  3. Add a copy action to eu-west-1 with 180-day retention.
  4. Assign resources by tag and ensure IAM role permissions exist.
  5. Create an on-demand backup and monitor the Jobs page, then verify recovery points in primary and secondary vaults.
  6. Restore to a test environment and validate data integrity and restore time.
Expected outcome
You will have automated daily backups for EC2 and RDS, cross-region copies to eu-west-1, and a verified restore procedure into a non-production environment.
Key Takeaway

Practice both the configuration and the restore. Verification proves your plan works and meets RTO expectations.
