Module 5 › Chapter 5.6 › Backup Plan Components
Process: Build a backup plan
1
Define backup rule
Set schedule, start and completion windows and retention baseline to meet RPO.
2
Configure lifecycle
Move older backups to cold storage and set delete age for compliance.
3
Add copy actions
Replicate recovery points to another region or vault for DR isolation.
4
Assign resources and tags
Select resources by tag or ARN so the plan automatically protects matching resources.
Example rule
DailySnapshot — schedule: daily at 05:00 UTC; StartWindow: 60 min; CompletionWindow: 120 min; MoveToColdStorage: 30 days; DeleteAfter: 365 days; Cross-region copy retention: 730 days.
Key Takeaway

Translate RPO to schedule frequency and retention to lifecycle days. Always verify copy actions are configured when DR is required.
