Design and implement backup strategies
Create backup plans, rules, and lifecycles to protect multi-service environments. Verified milestone: create a plan that backs up EC2 and RDS daily.

Assign EBS, RDS, and EFS resources by tag and copy recovery points to a secondary region for DR. Milestone: cross-region copy to eu-west-1.
VERIFIED COMPETENCY MILESTONE
03
Define and apply RPO & RTO
Work with stakeholders to choose acceptable data loss and restore windows that drive backup cadence and recovery approaches.
VERIFIED COMPETENCY MILESTONE
04
Develop and test data recovery procedures
Restore into a test environment, verify integrity, and measure actual RTO. Milestone: successful full-stack restore runbook.
