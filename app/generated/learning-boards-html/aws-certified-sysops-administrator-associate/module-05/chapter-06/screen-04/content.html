Module 5 › Chapter 5.6 › AWS Backup Overview
Definition

AWS Backup is a managed service that centralizes backup scheduling, retention, lifecycle transitions and cross-region copy for supported AWS resources and Storage Gateway.

Why centralize?
  • Consistent policy enforcement across resource types.
  • Easier auditing and tag-based resource selection.
  • Built-in lifecycle and cross-region copy capabilities.
Concrete example
A single plan named DailyProdBackup captures EC2 and RDS daily snapshots and copies them to a DR region for extended retention.
How a backup plan is structured
Components
Backup rule: schedule, start/completion windows
Lifecycle: move to cold storage, delete
Copy actions: cross-region vault copies
Resource assignments: tags or ARNs
Key takeaway

Centralizing reduces operational overhead and ensures uniform retention and DR behavior across services.
