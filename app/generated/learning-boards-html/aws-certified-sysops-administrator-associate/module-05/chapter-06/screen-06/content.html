Resource selection patterns
  • Tag-based selection by key/value (recommended for scale).
  • Explicit ARN selection for one-off resources.
  • Combine with IAM role that grants necessary backup permissions.
Scenario
Tag resources: Environment=Production, Application=CriticalApp. Assign resources to the CriticalAppBackupPlan using those tags so new resources are protected automatically.

Key Takeaway

Tag resources early and use tag-based assignments for scalable backup coverage and easier compliance reporting.
