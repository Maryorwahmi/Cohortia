Module 5 › Chapter 5.6 › Snapshot vs App-Consistent
Crash-consistent snapshot

Captures disk blocks at a point in time. Fast and often sufficient for stateless services, but may require recovery steps for databases.

Application-consistent backup

Coordinates with the application (for example, using VSS) to flush and quiesce data, producing a recovery point that preserves transactional integrity.

Concrete scenario
For SQL Server on Windows, enable WindowsVSS in the backup plan's advanced settings so the database engine flushes transactions before snapshot creation. This prevents corrupted restores and reduces manual recovery work.
Common mistake

Assuming snapshots guarantee application consistency. Verify and enable application-level options when transactional integrity is required.
