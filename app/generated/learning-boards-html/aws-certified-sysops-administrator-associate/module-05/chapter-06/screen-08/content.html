Module 5 › Chapter 5.6 › Backup Plan Example
Conceptual plan (read-only)
{
  "BackupPlanName": "DailyProdBackup",
  "Rules": [
    {
      "RuleName": "DailySnapshot",
      "TargetBackupVaultName": "Default",
      "ScheduleExpression": "cron(0 5 ? * * *)",
      "StartWindowMinutes": 60,
      "CompletionWindowMinutes": 120,
      "Lifecycle": {
        "MoveToColdStorageAfterDays": 30,
        "DeleteAfterDays": 365
      },
      "CopyActions": [
        {
          "DestinationBackupVaultArn": "arn:aws:backup:eu-west-1:123456789012:backup-vault:DRVault",
          "Lifecycle": { "DeleteAfterDays": 730 }
        }
      ]
    }
  ],
  "AdvancedBackupSettings": [
    { "ResourceType": "EC2", "BackupOptions": { "WindowsVSS": "enabled" } }
  ]
}
Notes and mapping
  • ScheduleExpression: controls RPO via frequency.
  • Lifecycle: balances cost and retention for compliance.
  • CopyActions: essential for cross-region DR copies.
  • AdvancedBackupSettings: use for application-consistency like VSS.
Key Takeaway

Use plan fields to match business RPO/RTO and retention. Ensure copy ARNs and role permissions exist before enabling copies.
