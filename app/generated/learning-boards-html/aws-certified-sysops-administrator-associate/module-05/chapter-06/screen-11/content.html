Module 5 › Chapter 5.6 › Recovery Testing
Test procedure
  1. Restore EC2/EBS volumes or instances from a chosen recovery point.
  2. Restore RDS snapshot to a new DB instance and verify data.
  3. Restore EFS and validate file integrity and permissions.
  4. Run application-level checks and record total time to readiness.
Example verification
Compare restored dataset checksums, run smoke tests, and verify dependent services can connect. Log timings for each step to identify bottlenecks.
Key Takeaway

Documented, repeatable restore drills convert theoretical RTO into verified recovery times and reveal hidden issues.
