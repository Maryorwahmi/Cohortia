Practice tasks

Follow these verified steps to complete the hands-on activity and confirm competency.

Task
Create a private bucket

Name must be globally unique. Keep "Block all public access" enabled unless you have a documented need to disable it.

Task
Enable versioning

Versioning preserves prior object states. Remember it increases storage cost; plan lifecycle rules for old versions.

Task
Add lifecycle rules

Transition current versions to Standard-IA after 30 days, expire current versions after 365 days, and clean noncurrent versions after 90 days.

Pro Tip

Test access with the AWS CLI to confirm the bucket is private before sending real logs. Use a dummy file for verification.

Common Mistake

Relying only on ACLs for control. Prefer bucket policies and IAM for auditable, centralized permissions.
