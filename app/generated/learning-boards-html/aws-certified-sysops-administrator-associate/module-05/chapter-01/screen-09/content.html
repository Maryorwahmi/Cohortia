Architecture

S3 Monitoring Tools

Combine multiple signals: aggregated metrics for trends, detailed request logs for audits, and events for automation.

Storage Lens: organization-wide visibility and recommendations to optimize cost and data protection.
Access logs: server access logging captures request-level detail and should be delivered to a separate, lifecycle-managed bucket.
Events: S3 events integrated with Lambda/SNS enable real-time automation like validation or alerts on object changes.
Example integrations
  • Access logs → Athena queries for monthly audit reports.
  • Object-created event → Lambda validates file format and tags the object.
  • Object-deleted event → SNS alert for potential unintended deletion.
Operational note

Store access logs in a separate bucket and apply lifecycle rules to prevent unbounded growth and maintain auditability.
