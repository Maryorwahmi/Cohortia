Module 5 › Chapter 5.1 › Hands-on Activity

Activity steps

Step 1
Create bucket with unique name; choose region and keep Block all public access enabled.
Step 2
Enable versioning in the bucket properties to preserve object revisions.
Step 3
Create lifecycle rule: transition current -> Standard-IA after 30 days; expire current after 365 days; delete non-current versions after 90 days.
Verification
# Upload a test object
aws s3 cp test-log.txt s3://my-sysops-app-logs-yourid/test-log.txt
# Anonymous GET should be denied; authenticated ls should succeed
aws s3 ls s3://my-sysops-app-logs-yourid
Expected Outcome

Private bucket with lifecycle-managed transitions and versioning, and automatic cleanup of old versions.

Common Mistake

Not enabling non-current version expiration after enabling versioning, which can lead to unexpected storage growth.
