Module 5 › Chapter 5.1 › Bucket Policy Walkthrough
Code
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowSpecificIAMRoleReadAccess",
      "Effect": "Allow",
      "Principal": {
        "AWS": "arn:aws:iam::123456789012:role/MyApplicationRole"
      },
      "Action": [
        "s3:GetObject",
        "s3:GetObjectVersion"
      ],
      "Resource": "arn:aws:s3:::my-sysops-bucket/*"
    },
    {
      "Sid": "DenyPublicWriteAccess",
      "Effect": "Deny",
      "Principal": "*",
      "Action": [
        "s3:PutObject",
        "s3:DeleteObject"
      ],
      "Resource": "arn:aws:s3:::my-sysops-bucket/*",
      "Condition": {
        "Bool": {
          "aws:SecureTransport": "false"
        }
      }
    }
  ]
}
Allow stmt
Gives a specific role read access to all objects in the bucket. Use role ARNs for clarity.
Deny stmt
Prevents public write and delete actions unless requests use HTTPS. Deny overrides allow.
Operational note
Test policies in a staging environment and use tools like AWS Config to audit changes.
