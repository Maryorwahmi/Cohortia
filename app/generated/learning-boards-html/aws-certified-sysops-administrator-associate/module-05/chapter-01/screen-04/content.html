Definition

Buckets and Objects

Buckets hold objects in a specific region. Objects include the data, a key, and metadata. Changes behave like new uploads unless versioning is enabled.

Bucket name and region
Bucket names are global; data is stored in the bucket's selected region. Choose the region for latency, cost, and compliance.
Object immutability
Updating an object replaces it. With versioning, each change becomes a new version with a unique version ID.
Object URL
Each object can be addressed via an HTTP/S URL, but permission controls determine whether it's reachable.
Key Takeaway

Plan bucket names and regions before using them; objects are managed by key and can be recovered when versioning is used.

Concrete example

Logs for European users

If primary users are in Europe, choose eu-central-1 for lower latency and possible data residency alignment.

Commands to create a bucket (example)
aws s3api create-bucket --bucket my-sysops-app-logs-123 --region eu-central-1
Misconception

Bucket names are not private to your account; they are global. Attempting to reuse a name will fail.
