Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Configure buckets & objects

Select region, define a unique name, and set default controls. This skill ensures correct placement and discoverability of data.

VERIFIED COMPETENCY MILESTONE
02
Implement bucket policies & ACLs

Write and apply JSON bucket policies for fine-grained permissions and understand when ACLs are acceptable.

VERIFIED COMPETENCY MILESTONE
03
Apply lifecycle policies

Create rules to transition objects to cheaper classes and to expire them for retention compliance and cost savings.

VERIFIED COMPETENCY MILESTONE
04
Use versioning & monitoring

Enable versioning to recover from accidental deletes, and use Storage Lens and access logs to audit activity and costs.

VERIFIED COMPETENCY MILESTONE
