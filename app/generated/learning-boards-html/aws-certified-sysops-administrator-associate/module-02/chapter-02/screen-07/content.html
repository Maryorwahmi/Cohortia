# Look for permission denied or parse errors
Troubleshooting flow
1 — Process check
Is the agent running and healthy?
2 — Agent logs
Read the agent log for errors about credentials or parsing.
3 — IAM role
Ensure the instance role contains the necessary logs permissions.
4 — File paths
Confirm the files exist and the agent can read them.
Pro tip
Simulate a log write and watch the agent log to see delivery attempts, which isolates parsing vs permission issues.
