Module 2 › Chapter 2.2 › Metric Filters
Pattern → Metric
Define filter patterns, set namespace and metric name, and emit values on matches.
Example filter pattern
Filter pattern: [ip, user, request, status_code=5*, size]
Metric namespace: MyApplicationMetrics
Metric name: 5xxErrorCount
Metric value: 1
Behavior
  • Each matching event emits the metric value chosen.
  • Metrics are created in the specified namespace and available like other CloudWatch metrics.
  • Metric filters are evaluated per log group.
Practical notes
Test patterns
Validate patterns with sample log events before creating alarms to avoid noisy alerts.
Scope
Filters apply to a single log group; use separate filters for different groups as needed.
Check your understanding
Why create a metric filter rather than just searching logs? Because numeric metrics can be graphed, alerted on, and integrated into alarms.
