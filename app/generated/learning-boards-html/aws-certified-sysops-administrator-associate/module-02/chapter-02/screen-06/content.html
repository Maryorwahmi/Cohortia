Install and configure
A terminal-first walkthrough for configuring the agent to send Apache access logs.
Terminal — install and start
sudo yum update -y
sudo yum install -y amazon-cloudwatch-agent
# fetch or create config and then start the agent
sudo /opt/aws/amazon-cloudwatch-agent/bin/amazon-cloudwatch-agent-ctl -a fetch-config -m ec2 -c file:/opt/aws/amazon-cloudwatch-agent/bin/config.json -s
Agent config (excerpt)
{
  "logs": {
    "logs_collected": {
      "files": {
        "collect_list": [
          {
            "file_path": "/var/log/httpd/access_log",
            "log_group_name": "/aws/httpd/access",
            "log_stream_name": "{instance_id}",
            "timestamp_format": "%d/%b/%Y:%H:%M:%S %z"
          }
        ]
      }
    }
  }
}
Example
Configure the agent with /var/log/httpd/access_log and name the stream by instance ID so each host's traffic is isolated for analysis.
Troubleshooting & tips
Check agent logs
Look at /opt/aws/amazon-cloudwatch-agent/logs/amazon-cloudwatch-agent.log for permission or parsing errors.
IAM role needs
Grant logs:CreateLogGroup, logs:CreateLogStream, and logs:PutLogEvents to the instance role.
Common mistake
Pointing to the wrong file path or missing timestamp_format causes parsing issues and dropped events.
Check your understanding
If logs don't appear, what three places do you check? (agent log, IAM role, config file paths)
