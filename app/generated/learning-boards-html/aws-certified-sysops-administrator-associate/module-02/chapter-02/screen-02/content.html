Learning Objectives
Learn, understand, apply, and validate log collection, metric extraction, and event routing.
01 — Explain architecture
Describe log groups, streams, and retention settings and why they matter for access and cost.
Mnemonic: group streams → apply retention once
VERIFIED COMPETENCY MILESTONE
02 — Configure CloudWatch Agent
Create and use agent JSON to collect logs from files and send them to a log group and stream.
Mnemonic: config.json → log group → instance-id stream
VERIFIED COMPETENCY MILESTONE
03 — Create metric filters
Use filter patterns to emit custom metrics like counts of "ERROR" or 5xx responses.
Mnemonic: pattern → namespace → metric name
VERIFIED COMPETENCY MILESTONE
04 — Author EventBridge rules
Write event patterns to match service events or scheduled cron expressions and route them to targets.
Mnemonic: source → detail-type → detail filters
VERIFIED COMPETENCY MILESTONE
