EventBridge building blocks
Events, buses, rules, patterns, and targets work together to build event-driven automation.
Event
A JSON payload that describes a state change or custom occurrence.
Rule
Matches events using an event pattern and forwards them to targets.
Target
An AWS service or resource invoked when a rule matches an event.
Example rule
Pattern to match EC2 stopped
{
  "source": ["aws.ec2"],
  "detail-type": ["EC2 Instance State-change Notification"],
  "detail": { "state": ["stopped"] }
}
Target example
Send to an SNS topic to notify admins or a Lambda to trigger cleanup.
Misconception
EventBridge does not read log files directly; it routes events emitted by services, scheduled rules, or custom PutEvents calls.
