Comparison
Session Manager vs SSH
Session Manager
No inbound ports, IAM-based access, session logs to CloudWatch/S3, browser-based shell.
SSH
Key management, open ports or bastion hosts, familiar tooling for tunnels and SCP.
Misconception: Session Manager lacks shell features — it provides a standard shell and supports common admin commands.
Concrete scenario
A production incident occurs: use Session Manager to open an auditable shell, gather diagnostics, and attach commands to an OpsItem. This avoids exposing a public SSH port and creates an audit record for compliance.
Key Takeaway

Session Manager is the preferred production access method when security and auditability matter most.
