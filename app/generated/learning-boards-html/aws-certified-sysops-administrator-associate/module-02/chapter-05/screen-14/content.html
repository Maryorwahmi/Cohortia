Lab Walkthrough
Start a Session and Run Diagnostics
Terminal-first steps to verify access and collect outputs.
Step 1 — Verify Agent
sudo systemctl status amazon-ssm-agent
# start if needed
sudo systemctl start amazon-ssm-agent
Step 2 — Start Session
In Systems Manager console, choose Session Manager → Start session → select instance → Start session. Run commands like df -h and ps aux | grep httpd.
Step 3 — Run Command
# In Run Command choose AWS-RunShellScript and use commands:
df -h
echo "Disk usage collected successfully."
Step 4 — Review Logs
Check Session history and Command Output tabs or the configured S3/CloudWatch destinations to confirm the outputs were captured.
Key Takeaway

Follow these verification steps to ensure your environment is ready for secure, auditable troubleshooting and automation.
