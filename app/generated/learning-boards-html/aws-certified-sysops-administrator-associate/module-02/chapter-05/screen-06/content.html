Interactive Access
Session Manager
Start secure, auditable interactive shells without SSH.
  • Use IAM to grant session permissions — no SSH keys to manage.
  • Session data is logged to CloudWatch Logs or S3 for auditing.
  • Works with EC2 and on-premises servers that run the SSM Agent.
Common Mistake

Assuming Session Manager bypasses IAM. It enforces IAM for who can start sessions and which instances are available.

Guided terminal example
# Example interactive checks you might run after connecting via Session Manager
ls -l /
df -h
ps aux | grep httpd
# then exit the session with the exit command and review Session history in Systems Manager
Key Takeaway

Session Manager simplifies access and gives a complete audit trail of interactive troubleshooting steps.
