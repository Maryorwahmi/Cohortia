Core Concept
What is AWS Systems Manager?
A consolidated suite for managing tasks like access, remote execution, patching, and aggregated operational insights.
  • SSM Agent connects managed instances to the service and enables commands and sessions.
  • SSM provides multiple capabilities: Session Manager, Run Command, Patch Manager, Explorer, and OpsCenter.
  • Outputs and logs can be sent to CloudWatch Logs or S3 for auditing and analysis.
Key Takeaway

SSM centralizes operational actions and visibility so you can automate and audit at scale.

Term cards
SSM Agent
Installed on hosts; required to run commands and sessions.
Session Manager
Interactive, auditable shell access without SSH.
Run Command
Execute scripts or commands across many instances.
Patch Manager
Scan and apply patches using baselines and windows.
Common misconception: SSM replaces CloudWatch for monitoring. It does not — it complements monitoring by enabling remediation and access tied to monitoring signals.
