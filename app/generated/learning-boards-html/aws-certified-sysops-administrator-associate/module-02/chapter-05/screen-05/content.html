Prerequisite
SSM Agent and IAM Role
Confirm these before relying on SSM features.
  • SSM Agent must be installed and running on each managed instance.
  • Instance role should include AmazonSSMManagedInstanceCore or equivalent permissions.
  • Without either, the instance will not register as a managed instance and features will fail silently.
Check example: sudo systemctl status amazon-ssm-agent — start it if stopped.
Concrete example
sudo systemctl status amazon-ssm-agent
# if inactive
sudo systemctl start amazon-ssm-agent
# verify in Systems Manager Fleet Manager that the instance appears as a managed instance
Key Takeaway

Provision instances so the agent and role are present to avoid manual remediation later.
