Maintenance
Patch Manager
Scan instances, apply patches via baselines, and schedule work in maintenance windows.
  • Define a patch baseline to approve or reject updates.
  • Use AWS-RunPatchBaseline to perform patching operations.
  • Schedule maintenance windows to limit disruption during patching.
Example
Create a baseline that approves security updates only, then apply it during a nightly maintenance window to update servers with minimal impact.
Key Takeaway

Automate patching with baselines and windows to reduce manual effort and maintain compliance.
