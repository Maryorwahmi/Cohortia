Remote Execution
Run Command
Use SSM Documents to run scripts across selected targets and gather output for auditing.
  • Use built-in documents like AWS-RunShellScript for shell commands.
  • Configure output destinations: CloudWatch Logs or S3 for later review.
  • Always test commands on a small subset before large rollouts.
Command example
# Example Run Command content for AWS-RunShellScript
commands:
  - df -h
  - echo "Disk usage collected successfully."
# Target: manually selected instances
# Output: optionally to an S3 bucket or CloudWatch Logs
Key Takeaway

Use Run Command for controlled, auditable execution and configure outputs for later analysis.
