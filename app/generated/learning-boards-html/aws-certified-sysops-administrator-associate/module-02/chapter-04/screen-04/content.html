Explanation
  • Alarms publish state changes to a topic that fans out messages to subscribers.
  • Create topics by severity to route alerts appropriately and avoid alert fatigue.
  • Always test subscriptions and confirm message formats before using automation.
Concrete example
Create an alarm for EC2 CPUUtilization. Configure its action to publish to EC2RemediationTopic. Subscribe an operations email and a Lambda function to that topic to both notify staff and trigger automated remediation.
Common mistake
Forgetting to confirm email subscriptions or assuming the topic will retry indefinitely. Test delivery and include retries if necessary.
Key Takeaway

SNS decouples alarms from responders, allowing both human and automated subscribers to react without tight coupling.
