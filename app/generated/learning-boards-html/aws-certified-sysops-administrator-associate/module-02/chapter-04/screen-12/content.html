Module 2 › Chapter 2.4 › Lab Walkthrough
Step checklist
  1. Prepare EC2 instance with the required IAM role and CloudWatch agent.
  2. Create SNS topic EC2RemediationTopic and confirm an email subscription.
  3. Create Lambda RebootEC2Instance with Python 3.9 and attach minimal reboot permission.
  4. Add SNS topic as a trigger to the Lambda.
  5. Create CloudWatch Alarm for CPUUtilization and set action to publish to the SNS topic.
  6. Test by stressing CPU and observe SNS, Lambda logs, and EC2 reboot sequence.
Commands and checks
SSH into the instance and run a CPU stress command like stress-ng to trigger high CPU for testing. Check your email for SNS messages and CloudWatch Logs for Lambda invocation records. Verify instance state transitions during reboot.
Key Takeaway
Test thoroughly in non-production and increase datapoints or cooldowns before promoting automation to production.
