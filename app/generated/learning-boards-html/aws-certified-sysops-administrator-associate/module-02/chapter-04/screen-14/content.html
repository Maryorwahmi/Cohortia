Module 2 › Chapter 2.4 › Key Concepts
Amazon SNS
A topic-based messaging service used to fan out alarm notifications to many subscribers.
AWS Lambda
Serverless compute that runs remediation code in response to events like SNS messages.
Amazon SQS
Durable queueing service that buffers messages and enables controlled processing and retries.
Summary
Combine notification, buffering, and safe execution patterns to build self-healing systems. Test carefully and use least-privilege permissions.
