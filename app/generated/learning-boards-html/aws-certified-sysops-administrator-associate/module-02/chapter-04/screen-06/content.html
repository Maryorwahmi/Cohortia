Module 2 › Chapter 2.4 › Lambda Remediation
Architecture
SNS or SQS delivers the alarm payload; Lambda processes the message, calls AWS APIs, and writes logs. Design for retries, errors, and idempotence.
Idempotence: make state changes reversible or detectable so multiple runs are harmless.
Least privilege: grant only the permissions required to act.
Logging: include clear messages and correlation identifiers for auditing.
Concrete example
A Lambda function uses the AWS SDK to call reboot_instances for a specific instance ID extracted from the SNS message. The function logs receipt and action, and handles exceptions by recording failures to CloudWatch Logs or a dead-letter queue.
Common mistake
Not making the function idempotent or giving it overly broad IAM permissions. Both increase risk in production.
