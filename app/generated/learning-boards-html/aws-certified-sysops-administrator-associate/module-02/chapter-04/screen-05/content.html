Module 2 › Chapter 2.4 › SNS Topic Design
Compare topics by purpose
CriticalAlerts — immediate on-call paging. Use SMS and Lambda subscribers for fast action.
WarningAlerts — informational. Use email and dashboards to avoid noise.
RemediationTopic — triggers Lambda and SQS for automated workflows.
Subscription trade-offs
  • Email: human-readable, requires confirmation.
  • SMS: immediate but short payloads and cost considerations.
  • SQS: durable buffering and retry management for automated consumers.
  • Lambda: immediate automated action but ensure idempotence and permissions.
Pro tip
Document expected message structure and test parsing in each consumer to avoid runtime errors.
