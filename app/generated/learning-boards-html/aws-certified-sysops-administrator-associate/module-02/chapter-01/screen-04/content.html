Module 2 › Chapter 2.1 › What is a Metric?
Definition
A time-ordered set of numeric data points representing a monitored variable, emitted by AWS services or custom sources.
Key points
  • Namespaces group metrics (e.g., AWS/EC2).
  • Dimensions add context (e.g., InstanceId, Application).
  • Choose actionable metrics to drive alerts and automation.
Key Takeaway
Metrics enable automated detection and concise dashboards. Pick metrics that lead to clear actions.
Example: EC2 CPUUtilization
EC2 publishes CPUUtilization under the AWS/EC2 namespace. Common dimensions include InstanceId and ImageId. You can graph the metric over time, apply statistics like Average or Maximum, and use it to trigger alarms when sustained high CPU is detected.
Metric anatomy
Namespace: AWS/EC2
Metric name: CPUUtilization
Dimension: InstanceId=i-0123456789
Common misconception
Logs are not metrics. Use logs to extract patterns and create metric filters when you need numeric counts from log lines.
Why it matters
Time-series metrics power automated alerts and dashboards that help you detect performance regressions and capacity issues before customers notice.
