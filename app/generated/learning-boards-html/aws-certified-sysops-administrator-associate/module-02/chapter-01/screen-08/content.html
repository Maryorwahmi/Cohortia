AWS CLI example
aws cloudwatch put-metric-data \ --namespace "MyApplication" \ --metric-name "FailedLogins" \ --dimensions InstanceId=i-0123456789,Application=WebApp1 \ --value 1 \ --unit Count
Replace the InstanceId placeholder with your instance ID. After running the command, wait a few minutes and check Metrics → All metrics → MyApplication in the CloudWatch console.
CloudWatch Agent
Install the CloudWatch Agent to collect system metrics and push metrics on a schedule. Use the agent for continuous metrics and the CLI for ad-hoc emits.
Validation & cost note
Verify the metric appears and is graphed. Custom metrics have costs, so batch emissions and choose sensible publish intervals. Use dimensions to avoid duplicate metric series.
Quick test
Publish a single data point and check the console before automating frequent publishes. This prevents accidental cost and cardinality issues.
Key Takeaway
CLI is ideal for ad-hoc metrics; the agent or SDKs are better for continuous telemetry. Always validate visibility and cardinality.
