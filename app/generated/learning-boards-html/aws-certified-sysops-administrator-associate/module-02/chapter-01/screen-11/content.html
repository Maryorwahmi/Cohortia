Module 2 › Chapter 2.1 › Alarm Actions & SNS
Step 1
Create an SNS topic and add subscriptions (email, SMS, HTTP). Confirm subscriptions before attaching to alarms.
Step 2
Create or edit the CloudWatch alarm and add the SNS topic as the In alarm action.
Step 3
Test the alarm in a non-production environment. Use separate SNS topics for test and production to avoid noisy production alerts.
Automated actions and safety
Auto Scaling actions can be triggered by alarms, and alarms can stop or terminate instances. Because these are destructive, protect production by testing and adding safeguards like lifecycle hooks or review gates.
Permission note
Ensure CloudWatch has permission to publish to the SNS topic and the topic allows the necessary principals to subscribe and receive messages.
