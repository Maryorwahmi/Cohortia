Module 2 › Chapter 2.3 › What CloudTrail Records
Definition
CloudTrail event model
An event captures the actor, action, target resource, time, and invocation context for API calls.
Who: identity used
When: timestamp and region
What: API name and parameters
Where/how: source IP, user agent
Concrete example
When an operator calls RunInstances, CloudTrail delivers a RunInstances event to your S3 bucket. That event includes the caller identity, EC2 parameters, and a timestamp used for audit and investigation.
Common misconception
CloudWatch logs operational metrics and application logs; CloudTrail specifically captures API interactions and should be your source for who-did-what evidence.
Key Takeaway

CloudTrail events are authoritative audit records of API calls; configure delivery to S3 for persistence and integrity checks.
