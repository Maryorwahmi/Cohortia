Module 2 › Chapter 2.3 › Config Rules
AWS Managed Rules
Predefined rules like s3-bucket-public-read-prohibited or ec2-instance-no-public-ip. Enable quickly for standard best practices.
Custom Rules (Lambda)
Author a Lambda function to evaluate resource state against custom criteria, such as required tags or company-specific settings.
Practical guidance
  • Start with managed rules for baseline controls.
  • Add custom rules only when needed to enforce specific policies, like tag presence.
  • Prioritize rules by security impact and plan remediation actions for NON_COMPLIANT items.
