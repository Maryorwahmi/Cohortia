Module 2 › Chapter 2.3 › Event delivery
Process
Trail → S3 → (optional) CloudWatch Logs
  1. Create a trail and set S3 bucket for delivery.
  2. Enable log file integrity validation to detect tampering.
  3. Choose CloudWatch Logs if you need real‑time alerting and analysis.
  4. Select data events only for specific high‑value resources.
Practical example
Create a trail named MyAuditTrail, send logs to my-audit-trail-logs S3 bucket, enable integrity validation, and optionally stream management events to CloudWatch for alerts.
Why both?
S3 archives an authoritative record for audits; CloudWatch makes it possible to react quickly to suspicious API activity.
Warning

Streamed logs to CloudWatch do not replace the need for the S3 audit bucket and integrity validation required by many compliance frameworks.
