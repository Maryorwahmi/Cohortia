Module 2 › Chapter 2.3 › Create & Test Trail
Quick process
  1. Create trail named MyAuditTrail and choose S3 bucket for storage.
  2. Enable log file integrity validation.
  3. Optionally enable CloudWatch Logs streaming for alerts.
  4. Keep data events off unless you need object‑level auditing.
Verification
Stop an EC2 instance and create an S3 bucket, then check Event history for StopInstances and CreateBucket entries.
Terminal-style demonstration
aws> create-trail --name MyAuditTrail --s3-bucket my-audit-trail-logs aws> enable-log-integrity-validation --trail-name MyAuditTrail # perform StopInstances in console # perform CreateBucket in console # then check CloudTrail Event history for events
Key Takeaway

A create‑and‑verify cycle confirms your trail is recording management events and delivering them for audit use.
