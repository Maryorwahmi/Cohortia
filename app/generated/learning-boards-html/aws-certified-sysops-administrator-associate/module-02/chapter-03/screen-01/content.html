We will show how events flow from API calls into CloudTrail, how Config records configuration snapshots over time, and how rules convert configuration data into compliance signals.

Concept map
Immutable event delivery to S3, optional CloudWatch stream, and Config’s resource timeline feeding rules and remediation.
CloudTrail
Records API calls; events go to an S3 bucket and can stream to CloudWatch Logs for alerting.
AWS Config
Records configuration items over time and evaluates resources against rules to mark compliance.
Integrity
Log file integrity validation uses hashing and signing to detect tampering after delivery to S3.
Rules & Remediation
Managed and custom rules evaluate resources and can trigger alerts or automated fixes.
Tip
Start with management events and add data events only for high‑value resources to balance cost with visibility.
