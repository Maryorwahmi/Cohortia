Lambda-backed Config rule (concept)
Pattern: receive configuration item, evaluate tag presence, return compliance result.
# PSEUDOCODE: Lambda handler for tag check def handler(event, context): cfg_item = event['configurationItem'] tags = cfg_item.get('tags', {}) if tags.get('Project') == 'Alpha': return {'compliance_type': 'COMPLIANT'} else: return {'compliance_type': 'NON_COMPLIANT', 'annotation': 'Missing Project: Alpha tag'}
Example
Use this rule to continuously ensure new and existing EC2 instances carry the Project: Alpha tag.
Misconception
Don't assume tags applied by launch automation cannot be removed later; continuous evaluation captures drift.
Key Takeaway

Custom rules let you enforce policies that are unique to your organization; tie NON_COMPLIANT findings to remediation where possible.
