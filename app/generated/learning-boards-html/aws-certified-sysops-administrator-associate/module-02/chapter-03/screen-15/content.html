Key Concepts
Three compact cards to anchor the main ideas.
CloudTrail
Records API calls to an S3 bucket and optionally streams to CloudWatch Logs for alerts.
AWS Config
Records configuration items over time and evaluates resources against rules.
Rules & Remediation
Managed rules for common controls; custom Lambda rules for organization policies. Act on NON_COMPLIANT findings.
Summary takeaway
Use CloudTrail for action-level evidence and Config for state-level evaluation. Together they provide the data and signals you need to detect, investigate, and remediate compliance issues.
