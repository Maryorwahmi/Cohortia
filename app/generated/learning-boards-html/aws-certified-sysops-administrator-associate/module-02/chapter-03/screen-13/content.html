Module 2 › Chapter 2.3 › Remediation
Remediation workflow
NON_COMPLIANT → Notify → Triage → Remediate (automated or manual) → Record action.
Notify
Use SNS topics to route findings to owners and ticketing systems.
Automate
Use Systems Manager or Lambda for tested remediation steps on low-risk issues.
Record
Log remediation actions back into S3 or ticketing to preserve evidence for audits.
Caution

Automatically changing settings in production can cause outages. Limit automation to safe, reversible actions and test thoroughly.
