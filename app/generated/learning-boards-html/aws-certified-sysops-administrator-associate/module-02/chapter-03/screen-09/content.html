AWS Config architecture
Recorder → Configuration Items → S3 & SNS for history and notifications.
Resource discovery
Enable recorder and choose to record all resources. Config then inventories resource types and begins producing configuration items.
Configuration items
Each change produces a configuration item capturing the resource state at that time. These items build the timeline used for troubleshooting.
Example
Find the security group change that preceded an EC2 failure by inspecting the Config timeline for that instance.
Tip
Deliver configuration history to a secure S3 bucket and optionally create an SNS topic to receive change notifications.
Key Takeaway

Config’s recorded configuration items give you a chronological record of resource states to support diagnostics, forensics, and compliance evidence.
