Module 2 › Chapter 2.3 › Enable Config & Rule
Recorder setup
  • Select "Record all resources" for broad visibility.
  • Create or choose an S3 bucket for configuration history.
  • Optionally define an SNS topic for notifications.
  • Confirm IAM role permissions for Config delivery.
Add managed rule
Search for s3-bucket-public-read-prohibited and add it. Wait for the rule to evaluate your S3 buckets and report COMPLIANT or NON_COMPLIANT.
Testing steps
  1. Make a test bucket publicly readable (for testing only).
  2. Observe NON_COMPLIANT in Config rules after evaluation.
  3. Revert public access immediately to restore security.
