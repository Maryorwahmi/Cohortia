Module 2 › Chapter 2.3 › Management vs Data
Management Events
Control plane operations
Examples: RunInstances, CreateBucket, AttachRolePolicy. Enabled by default on trails and useful for auditing changes to resources and permissions.
Data Events
Resource-level access
Examples: GetObject/PutObject for S3, InvokeFunction for Lambda. Not enabled by default due to volume and cost; enable for high‑value resources only.
Example scenario
To audit a sensitive bucket named sensitive-customer-data for every GetObject and PutObject, configure data events for that bucket specifically and keep management events on to capture policy changes.
Misconception: "Enable data events for all buckets"
Recommended: Enable data events only for designated sensitive buckets.
