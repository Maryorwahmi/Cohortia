Learning Objectives
Clear outcomes you can verify in the hands‑on lab.
Learn → Understand → Apply → Master
01
Explain CloudTrail’s role
Define how CloudTrail captures API calls and why this audit trail matters for accountability and investigations. Mnemonic: Who‑What‑When.
VERIFIED COMPETENCY MILESTONE
02
Differentiate event types
Distinguish management events from data events and decide when to enable data events for specific resources. Mnemonic: Management = control plane, Data = resource plane.
VERIFIED COMPETENCY MILESTONE
03
Use AWS Config for history
Describe how Config records configuration items over time and stores the resource timeline for troubleshooting. Mnemonic: Time machine for resources.
VERIFIED COMPETENCY MILESTONE
04
Implement Config rules
Enable managed rules and author Lambda‑backed custom rules for policies important to your org, then act on NON_COMPLIANT resources.
VERIFIED COMPETENCY MILESTONE
