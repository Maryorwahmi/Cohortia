Module 8 › Chapter 8.8 › What is the Framework?
Definition and intent

The framework organizes best practices into pillars and provides questions to assess risk and prioritize improvements.

Key idea
Continuous review, not a one‑time checklist. Reviews surface HRIs and MRIs for prioritized action.
Concrete example
Using tags and cost allocation to attribute spend and create accountability across teams.
Misconception
Treating the framework as a compliance checkbox instead of an iterative improvement process.
Key Takeaway

Use pillars to guide focused reviews that produce measurable improvement plans, then iterate.

How a review looks
Define a workload, select pillars, answer questions, and review the tool's prioritized improvement plan with HRIs and MRIs.
Quick checklist
  • Define workload and scope.
  • Select Cost Optimization and Performance Efficiency pillars.
  • Answer questions honestly to surface risks.
  • Translate improvement steps into owner tasks.
Example report excerpt
Workload: MyWebAppReview
Pillars: Cost Optimization, Performance Efficiency
Findings: 2 HRIs, 4 MRIs
