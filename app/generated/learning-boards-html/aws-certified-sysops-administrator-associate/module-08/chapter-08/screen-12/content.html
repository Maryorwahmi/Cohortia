Module 8 › Chapter 8.8 › Performance Patterns
Three patterns to apply
Democratize: enable teams with managed services like Aurora Serverless so they can focus on features.
Go global: deploy across regions and AZs to meet latency objectives for distributed users.
Experiment: run short tests with different instance types or caching strategies to find the best configuration.
Plan an experiment with clear success metrics—latency, error rate, and cost. Keep it small, measurable, and reversible.
Key Takeaway

Use managed services, global deployment, and frequent experiments to evolve a performant, efficient architecture over time.

Example experiment
Swap a relational read pattern to a managed cache and measure latency and cost for the peak hour. Roll back if no improvement.
Misconception: experiments must be large. Small, focused trials often produce clear evidence for broader change.
