Mock review steps
1. Define workload: name, owner, scope.
2. Start review: select Cost Optimization and Performance Efficiency.
3. Answer questions honestly for each pillar to surface risks.
4. Save, view the improvement plan, and note HRIs and MRIs.
Translate recommended actions into prioritized tasks with owners and measurable success criteria, such as percent cost reduction or latency improvement.
Key Takeaway

Use the tool regularly to track progress. An improvement plan is a living document you act on and re‑review over time.

Sample review answers
Example: "We have some cost visibility but no formal process" or "Tags exist but are inconsistently applied." These answers lead to targeted recommendations.
Misconception: the tool replaces judgement. It surfaces risks and recommendations; you still prioritize and add operational context.
