Competency Checkpoints
1. Cost alternative proposal
Propose replacing a fixed EC2 with a consumption model and explain cost vs operational tradeoffs.
VERIFIED COMPETENCY MILESTONE
2. Performance deployment plan
Describe when to use serverless or global regions to reduce latency and how to measure impact.
VERIFIED COMPETENCY MILESTONE
3. Mock Well‑Architected review
Start a review, answer cost and performance questions, and note HRIs and MRIs.
VERIFIED COMPETENCY MILESTONE
4. Improvement plan action
Translate a recommended improvement into a prioritized operational task with owners and estimates.
VERIFIED COMPETENCY MILESTONE
Use these checkpoints as guided practice during the hands‑on mock review later. Each milestone ties to a principle from the chapter and to measurable work you can present to stakeholders.
