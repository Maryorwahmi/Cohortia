Module 8 › Chapter 8.1 › Cost Explorer Workflow
Step-by-step
  1. Select a date range (last 3 months is common).
  2. Group by Service, Usage Type, or Tag depending on the question.
  3. Apply filters (Region, Linked Account, Project tag).
  4. Check the forecast to project future spend.
Best practice
Use tags to make reports actionable. Save views you will check weekly to spot trends early.
Example
Group by Usage Type and filter to your primary region to find whether a spike is due to instance hours, network transfer, or storage requests.
Refresh note
Cost Explorer data may lag by up to 24 hours; do not expect real-time billing updates.
Key Takeaway

Combine grouping and tags to turn raw spend into actionable insights and save repeating views for monitoring.
