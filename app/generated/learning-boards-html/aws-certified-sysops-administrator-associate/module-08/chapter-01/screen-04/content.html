Module 8 › Chapter 8.1 › How AWS Calculates Costs
Core definition
Pricing is usage-based and varies by service. Track the primary billing metric for each service to predict charges.
Service examples
EC2
Instance type + hours
S3
Storage GB, transfer, requests
Lambda
Invocations + duration
Create a quick mapping table for your account listing common services and their billing metrics so you can estimate the impact of any configuration change.
Concrete example
An always-on small instance will cost proportional to hours. By contrast, a high-volume serverless function can cost more through many short invocations if duration is high.
Common mistake
Assuming a service is free or inexpensive without checking its specific pricing and your projected usage.
Key Takeaway

Map services to billing metrics and use tags to attribute costs. Measurement is the basis for any optimization.
