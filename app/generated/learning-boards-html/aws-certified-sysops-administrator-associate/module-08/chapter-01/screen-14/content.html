Module 8 › Chapter 8.1 › Assessment & Reflection
Exercise 1 — Find a spike
Use Cost Explorer to select the last week, group by Usage Type, and filter by Region to find the largest recent change. Record your steps and findings.
Exercise 2 — Create a budget
Create a monthly cost budget scoped to EC2 in a dev account, set alerts at 80% and 100%, and optionally test an action in a sandbox.
Reflection prompt
Which tagging or reporting change would make the next investigation faster? Consider enforcing one tag and creating a saved Cost Explorer view for it.
Key Takeaway

Active practice—finding spikes and creating budgets—builds the skills needed to manage and prevent unexpected costs.
