Module 8 › Chapter 8.1 › Budget Setup Walkthrough
Checklist
  1. Open Billing > Budgets and click Create budget.
  2. Select Cost budget and name it clearly (MonthlyEC2Budget).
  3. Set Period to Monthly and Budget amount to a small test value.
  4. Add filter: Service → Amazon Elastic Compute Cloud (EC2).
  5. Configure alerts at 80% and 100% and add email or SNS.
Verification
After creation, watch the Budgets dashboard and Cost Explorer to confirm the budget is monitoring the expected EC2 charges. Adjust filters if results don't match expectations.
Common pitfall
Not adding a service or tag filter makes the budget too broad and reduces its usefulness for targeted remediation.
Try this
Create a test budget, trigger the 80% alert by lowering the amount, and confirm you receive the notification before adding automated actions.
