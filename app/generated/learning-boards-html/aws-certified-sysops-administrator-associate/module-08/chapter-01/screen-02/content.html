Learning Objectives
Bloom levels: Learn → Understand → Apply → Master
01
Explain billing structure

Identify how usage metrics map to charges for EC2, S3, and Lambda. Understanding this is essential to detect unexpected cost drivers.

VERIFIED COMPETENCY MILESTONE
02
Use the Billing Dashboard

Interpret estimated charges and recent invoices so you can quickly spot and investigate anomalies in your account.

VERIFIED COMPETENCY MILESTONE
03
Analyze with Cost Explorer

Create reports, apply filters and groupings, and use forecasting to predict future spend and identify persistent drivers.

VERIFIED COMPETENCY MILESTONE
04
Configure Budgets & Organizations

Set cost and usage budgets, attach actions for remediation, and use Organizations to consolidate billing across accounts.

VERIFIED COMPETENCY MILESTONE
