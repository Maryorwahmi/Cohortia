Comparison

Noisy alarm vs tuned alarm

Noisy Alarm
Short period, 1/1 datapoint, low threshold. Triggers on transient spikes, creates noise.
Tuned Alarm
Period and datapoints matched to traffic patterns, threshold set above baseline. Reliable and actionable.
Rule of thumb: test alarms in a staging environment with aggressive settings, observe behavior in production with conservative settings, then iterate. Use composite alarms to suppress noisy contributors when a higher-level signal is already triggered.
Example
An EC2 alarm configuration for production:
Metric: CPUUtilization • Statistic: Average • Period: 5 minutes • Threshold: 80 • Datapoints: 3/3
If immediate detection is required, lower datapoint count for a test alarm, but expect more false positives. Tune using historical data where possible.
Key Takeaway

Choose sensitivity that matches operational needs, and use composite alarms and automation to reduce human fatigue.
