Module 8 › Chapter 8.5 › AWS X-Ray
Definition

X-Ray traces requests end-to-end

It records segments for service calls and shows a service map that highlights latency and error rates between components.
What you learn
Per-request timing, slow segments, and error origins across services.
Misconception
Tracing is not a replacement for metrics; it is the tool to use after a metric signals an anomaly.
Example
View a sample service map showing API Gateway → Lambda → RDS. One Lambda segment shows high latency. Inspect trace details to find the slow database call within the Lambda segment.
Integration
Use X-Ray SDK in application code or X-Ray agents where supported. Consider sampling to control trace volume.
Key Takeaway

Use X-Ray to convert an aggregated alert into a traceable request path and identify the slowest segment.
