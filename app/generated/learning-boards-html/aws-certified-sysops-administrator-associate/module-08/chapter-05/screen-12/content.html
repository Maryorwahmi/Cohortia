Reachability vs Flow Logs

Reachability Analyzer
Simulate network paths and discover which component blocks traffic.
Network Access Analyzer
Detect unintended network access or overly permissive rules.
Flow Logs
Observe actual traffic to identify rejects or bandwidth issues.
Scenario
If an instance cannot reach an external service, start with Reachability Analyzer to see the intended path and blocking components, then check Flow Logs to confirm whether traffic is observed or rejected at the interface.
Key Takeaway
Combine visual path tools for configuration checks with Flow Logs for runtime verification to get a full network story.
