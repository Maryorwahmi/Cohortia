Labable outcomes

Each outcome maps to a concrete task you can test in a lab environment to prove competency.

Metric selection
Identify the key metric for the service and explain why it matters to performance diagnosis.
Dashboard design
Show correlated widgets: ALB latency + EC2 CPU + RDS connections + queue depth.
Alarm tuning
Choose period and datapoints to avoid flapping while catching real issues.
Tracing & flow logs
Instrument X-Ray and query VPC Flow Logs for REJECT actions and high bandwidth flows.
Milestone
Create MyWebAppPerformanceDashboard with CPU and Network widgets, configure HighCPU alarm with SNS, and demonstrate an X-Ray trace that highlights a slow DB call.
