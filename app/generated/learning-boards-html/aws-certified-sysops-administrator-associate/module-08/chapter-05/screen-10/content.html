Module 8 › Chapter 8.5 › VPC Flow Logs
Definition

Flow Logs record IP traffic metadata

They capture fields like src/dst IP, ports, protocol, bytes, packets, and action (ACCEPT/REJECT). Useful for connectivity and bandwidth troubleshooting.
Use cases
  • Find security group or NACL blocks
  • Identify high-volume IPs or ports
  • Detect unusual outbound connections
Query Example
fields @timestamp, @message
| filter action = 'REJECT'
| sort @timestamp desc
| limit 20
Publish Flow Logs to CloudWatch Logs to run quick queries, or to S3 and use Athena for larger forensic searches.
Key Takeaway

Use Flow Logs to determine whether problems are network-level before modifying application code or scaling compute.
