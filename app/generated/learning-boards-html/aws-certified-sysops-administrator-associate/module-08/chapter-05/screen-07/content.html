Create SNS topic and alarm via CLI

# Create SNS topic
aws sns create-topic --name MySysOpsAlertsTopic

# Subscribe email (requires confirmation)
aws sns subscribe --topic-arn arn:aws:sns:... --protocol email --notification-endpoint you@example.com

# Create CloudWatch alarm for EC2 CPU
aws cloudwatch put-metric-alarm \
  --alarm-name HighCPU_t3medium \
  --metric-name CPUUtilization \
  --namespace AWS/EC2 \
  --statistic Average \
  --period 300 \
  --threshold 80 \
  --comparison-operator GreaterThanOrEqualToThreshold \
  --evaluation-periods 3 \
  --alarm-actions arn:aws:sns:... \
  --dimensions Name=InstanceId,Value=i-0123456789abcdef0
Explanation
This sequence creates a topic, subscribes an email that requires confirmation, and then creates an alarm referencing that SNS topic. The evaluation periods and threshold determine sensitivity.
Test tip
Generate load in staging with a stress tool to observe metric response and alarm firing.
Permissions
Ensure your IAM principal has sns:CreateTopic, sns:Subscribe, cloudwatch:PutMetricAlarm permissions.
Key Takeaway

Automate alarm creation so thresholds and actions are consistent and testable across environments.
