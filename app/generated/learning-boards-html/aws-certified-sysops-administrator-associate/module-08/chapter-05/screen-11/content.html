Module 8 › Chapter 8.5 › Troubleshooting Workflow
Process

Step-by-step troubleshooting

1
Observe
Start with dashboards or alerts describing the symptom.
2
Correlate
Find metrics that move together to narrow suspected components.
3
Trace
Use X-Ray for per-request timing to find the slow segment.
4
Verify
Confirm with Flow Logs and logs before applying a fix.
Scenario
Users report intermittent high latency. Dashboard shows ALB latency spikes and increased RDS read latency. Use X-Ray to trace requests and find slow DB calls. Query Flow Logs to rule out network drops between app and DB.
Misconception
Scaling compute without root cause analysis may mask problems and increase costs; always identify the underlying bottleneck first.
Key Takeaway

Use an observability-first process: observe the symptom, correlate metrics, trace requests, and verify with network logs before remediating.
