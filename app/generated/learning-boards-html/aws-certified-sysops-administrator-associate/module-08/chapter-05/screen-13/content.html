Starter commands

sudo yum update -y sudo amazon-linux-extras install nginx1 -y sudo systemctl start nginx sudo systemctl enable nginx # Install stress tool sudo yum install stress -y # Run CPU stress (stop with Ctrl+C) stress -c 4
These commands launch Nginx and create CPU load for testing. Use a staging instance to avoid impacting production.

Dashboard & Alarm checklist

  • Create MyWebAppPerformanceDashboard and add CPU and Network widgets
  • Create SNS topic and confirm email subscription
  • Create CloudWatch alarm: CPUUtilization, Average, period 5m, threshold 80, evaluation 1/1 for test
  • Generate load and confirm alarm fires and email is received
Key Takeaway

A controlled lab shows how dashboards and alarms behave; use staging tests to tune production thresholds safely.
