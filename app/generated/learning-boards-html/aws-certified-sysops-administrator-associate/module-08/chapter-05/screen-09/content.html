Module 8 › Chapter 8.5 › Instrumenting X-Ray
Architecture Pattern

Propagate traces across components

Key steps: enable tracing at entry points, record segments for operations, add subsegments for external calls, and forward trace headers between services.
Lambda
Enable active tracing or add SDK to record segments and annotations.
EC2 / Containers
Run the X-Ray daemon and instrument app code with the SDK.
Concrete Example
API Gateway receives the request, passes trace header to Lambda; Lambda records a DB subsegment for a query. In X-Ray, the trace shows API Gateway → Lambda → RDS with timings for each segment.
Key Takeaway
Trace propagation is essential: without trace headers you cannot assemble the full request path across services.
