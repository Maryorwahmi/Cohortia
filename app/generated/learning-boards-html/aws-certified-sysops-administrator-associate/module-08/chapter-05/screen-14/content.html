Module 8 › Chapter 8.5 › Key Concepts
Amazon CloudWatch
Collects metrics, logs, and events across AWS for performance visibility.
AWS X-Ray
Provides end-to-end tracing to identify slow segments in distributed applications.
VPC Flow Logs
Capture IP traffic metadata to diagnose rejected traffic and bandwidth issues.
Summary
Combine these tools in a workflow: observe metrics, correlate on dashboards, trace requests for per-request insight, and verify network behavior with Flow Logs.
