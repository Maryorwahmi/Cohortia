Comparison Standard-IA vs One Zone-IA

Standard-IA

Lower storage price than Standard; higher retrieval fees. Multi-AZ durability suitable for backups and audit data where loss is unacceptable.
  • Use for infrequent reads that still need multi-AZ redundancy.
  • Good for audit logs and disaster recovery copies.

One Zone-IA

Cheaper than Standard-IA but stores data in a single AZ. Appropriate for reproducible data and secondary backups.
  • Good for non-critical secondary copies.
  • Not suitable for compliance datasets that require high durability.
Common mistake

Choosing One Zone-IA for primary or irreplaceable data risks data loss if the AZ fails; always align durability requirements to the storage class selected.
