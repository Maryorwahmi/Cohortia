Core Concept Intelligent-Tiering

How it works

  • Monitors access patterns per object.
  • After 30 days of no access, moves to infrequent access tier.
  • Moves back to frequent tier on access.
  • Optional archive tier available for deeper savings.
Cost note: monitoring fees apply per object; weigh against expected savings for each object population.

Example & Misconception

Example: telemetry files of unknown future value—Intelligent-Tiering removes manual classification. Misconception: it's cheaper for every workload. If patterns are stable and predictable, rule-based lifecycle transitions may be cheaper than per-object monitoring charges.

Pro tip

Compare estimated monitoring fees against projected storage savings before enabling on large object counts.
