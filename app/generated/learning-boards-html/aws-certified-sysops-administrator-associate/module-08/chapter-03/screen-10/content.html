Process Flow Lifecycle policies

Lifecycle rule elements

  • Scope: bucket-wide, prefix, or tags.
  • Conditions: object age, creation date, or lifecycle transitions.
  • Actions: transition to a class or expire/delete objects.
Rule tip: use prefixes like logs/ or backups/ to treat object classes differently in the same bucket.

Example policy (conceptual)

Transition objects to Standard-IA after 30 days, transition to Glacier Flexible Retrieval after 90 days, and expire after 3650 days (7 years). Apply this rule to the prefix logs/ to keep other data untouched.
