Module 8 › Chapter 8.7 › AWS Resource Groups
What Resource Groups do
Group resources with tag filters to see consolidated metrics and run automations across the set.
Creation flow
Choose tag-based grouping and provide a name, e.g., MyDevelopmentWebApp with filters Environment=Development AND Project=MyWebApp.
Uses
View aggregated CloudWatch metrics, run automation scripts, and apply role-based permissions to the group.
Practical example
Create MyDevelopmentWebApp and inspect the Metrics tab to compare CPU across all tagged EC2 instances in the group.
Key Takeaway

Resource Groups make tag-driven operations easier; they are an operational companion to cost allocation tags.
