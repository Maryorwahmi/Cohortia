Module 8 › Chapter 8.7 › Tag Limits
Limits and trade-offs
Most resources support about 50 tags. Use that headroom wisely by prioritizing stable, high-value keys.
When to avoid extra tags
If a tag changes frequently, it may fragment reporting. Choose keys with stable values.
Choosing the compact set
Prioritize environment, project, owner, and cost center for cost allocation and governance.
Example guideline
Document a tag dictionary with allowed values for each key to avoid inconsistent vocabularies.
Key Takeaway

Respect tag limits and keep a small, stable set of keys to maintain clear and useful billing groups.
