Assessment scenarios
Use these questions to validate practical understanding and governance readiness.
Scenario 1
Goal: attribute spending by department and environment across accounts. Most important actions: enable AWS Config rules for tagging and activate those tags as Cost Allocation Tags in Billing.
Scenario 2
Goal: view consolidated CloudWatch metrics for all resources of Project Alpha owned by Jane Doe. Best service: AWS Resource Groups filtered by Project:Alpha and Owner:JaneDoe.
Governance recommendations
Automate tagging at provisioning, audit with Config and Tag Editor, and use a remediation workflow for non-compliant resources.
Key Takeaway

Assess tag coverage, enforcement, and activation as part of your rollout. Correct common mistakes like inconsistent naming and missing automation.
