Module 8 › Chapter 8.7 › Tags: Key-Value Metadata
What are tags?

Key-value pairs attached to resources, used for categorization, billing, and automation across AWS services.

Common tag keys
Environment, Project, Owner, CostCenter, Application
Naming guidance
Use consistent casing and separators. The chapter recommends lowercase and hyphens to avoid duplicates.
Limit note
Most resources allow up to 50 tags. Select a minimal set focused on reporting needs.
Example — production web app
Environment: production
Project: web-portal
Owner: team-frontend
Misconception check
Resource names are not structured metadata for billing; tags are. Tools like Cost Explorer rely on activated tag keys, not names.
Key Takeaway

Choose a small set of standardized tag keys and apply them reliably at provisioning.
