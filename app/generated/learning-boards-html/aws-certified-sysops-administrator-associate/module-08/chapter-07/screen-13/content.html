Three-step lab
A concise checklist to connect tagging with billing and groups.
Step 1 — Tag an EC2
Select an instance and add tags: Environment=Development, Project=MyWebApp. Or launch a t3.micro for testing.
Step 2 — Activate keys
Billing Dashboard → Cost Allocation Tags. Activate Environment and Project. Expect up to 24 hours for Cost Explorer.
Step 3 — Create Resource Group
Resource Groups & Tag Editor → Create a tag-based group named MyDevelopmentWebApp with the same filters.
Validation
Ensure the instance appears in the group's resource list and check CloudWatch Metrics to see consolidated data across the group.
Key Takeaway

Following these steps ties a tagged resource to billing and monitoring, making cost and performance visible to stakeholders.
