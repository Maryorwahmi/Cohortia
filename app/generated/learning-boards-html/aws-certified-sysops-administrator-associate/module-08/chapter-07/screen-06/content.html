Module 8 › Chapter 8.7 › Activate Cost Allocation Tags
Activation process
Steps to make tags available in billing tools and reports.
Step-by-step
  1. Ensure resources are tagged with the desired keys and values.
  2. Open the Billing Dashboard and choose Cost Allocation Tags.
  3. Find your user-defined tag keys (for example Environment and Project) and select them.
  4. Click Activate and wait; tag data is processed and can take up to 24 hours to appear.
Example output
After activation, Cost Explorer shows grouping options for the activated keys so finance can filter costs by Project or Environment.
Operational note
Because activation is delayed, coordinate with finance before reporting windows. Activation is per key and must be repeated for new keys.
Key Takeaway

Activating tags connects tagging to billing. Plan activation and communicate the processing delay to stakeholders.
