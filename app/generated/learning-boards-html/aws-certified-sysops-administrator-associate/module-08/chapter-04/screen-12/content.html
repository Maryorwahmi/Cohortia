Module 8 › Chapter 8.4 › Hands-on Activity
Activity: analyze an RDS instance and a DynamoDB table
RDS console checks
1. Open RDS instance → Monitoring
2. Record: CPUUtilization, FreeableMemory, DatabaseConnections, ReadIOPS, WriteIOPS
3. Note storage type and provisioned IOPS
4. Check Multi-AZ setting and backups
DynamoDB console checks
1. Open table → Capacity and Metrics
2. Record: ConsumedReadCapacityUnits, ConsumedWriteCapacityUnits
3. Check capacity mode: Provisioned vs On-Demand
4. Inspect TTL and DAX settings
Fill a short findings table: metric, observed value, recommended action. Make one conservative change in a maintenance window and monitor for 24–72 hours to validate.
Key Takeaway

A structured checklist reduces guesswork and ensures safe, reversible cost optimizations.
