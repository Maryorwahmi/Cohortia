Practical cost reductions
Item sizing
Store only necessary attributes to reduce RCU/WCU consumption and storage costs. Replace embedded large blobs with object references stored in cheaper object storage if appropriate.
TTL
Use TTL to automatically delete expired items such as session data to reduce storage and future read costs.
Standard-IA
For long-term, rarely accessed tables, Standard-IA lowers storage costs but increases per-read/write costs. Use for archival data.
DAX
Use DAX for read-heavy workloads to reduce RCUs and improve latency via a managed in-memory cache.
Caution
TTL helps storage but deletion behavior and eventual cleanup should be tested to understand billing impact for your pattern.
Key Takeaway

Combine compact item design, TTL, and caching to lower both storage and RCU/WCU costs for DynamoDB tables.
