Module 8 › Chapter 8.2 › Compute Optimizer
What it does

Aggregates recent usage and recommends instance families and sizes, flagging under- and over-provisioned instances.

Recommendation types: Overprovisioned, Underprovisioned, Optimized.
Include CPU, memory, network, and storage in evaluation.
Use recommendations as input to a controlled test and validation procedure.
Example recommendation
Compute Optimizer suggests m5.large → t3.large with estimated monthly savings, but notes potential performance impact under heavy I/O bursts.
Misconception
Treating recommendations as requirements. Always validate with a pilot because sporadic spikes may be missed.
Key Takeaway

Compute Optimizer speeds discovery of candidates, but verification testing preserves performance reliability.
