Stop/Terminate Policy
Define which non-production instances can be stopped nightly. Implement an automated scheduler or a small Lambda to enforce the policy.
Policy example: Stop dev instances at 7pm, start at 7am weekdays.
Tooling: Scheduled Lambda or an instance scheduler to apply tags and rules.
Burstable Instances (T-family)
T-family provides baseline CPU and credits for short bursts. Best when average CPU is low and spikes are brief.
Confirm memory and I/O needs before migrating.
Test under load to ensure credits sustain expected peaks.
Key Takeaway

Simple automation plus the right instance family can deliver repeated savings with low operational risk.
