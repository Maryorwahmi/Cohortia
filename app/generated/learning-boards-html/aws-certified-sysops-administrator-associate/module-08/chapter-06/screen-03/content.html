Module 8 › Chapter 8.6 › Lab & Assessment
Hands-on Lab
Create a Python Lambda, run tests at 128, 256, 512 MB, and record billed durations in CloudWatch Logs.
  • Deploy the sample function and run repeated test invocations.
  • Observe how duration changes with memory allocations and choose a cost-effective size.
  • Conceptually create a Fargate task to inspect vCPU and memory fields without deploying.
Assessment Idea
Scenario-based multiple choice questions that test memory + Provisioned Concurrency and Fargate sizing decisions.
Why this matters
These exercises teach you to choose practical, measurable changes that reduce cost without harming latency or reliability.
