Module 8 › Chapter 8.6 › Cold Starts
What is a cold start?
An execution environment is created and initialization code runs before the handler, increasing duration.
  • Occurs when scaling out or after idle periods.
  • Initialization tasks and large dependencies increase the penalty.
  • Warm invocations reuse environments and avoid the penalty.
Mitigation and measurement
Minimize package size, move initialization outside the handler, and run repeated tests that include bursts to observe cold-start frequency.
When to use Provisioned Concurrency
For latency-sensitive functions with consistent, high-volume invocations where cold starts harm user experience.
Key Takeaway

Treat cold starts as a measurable performance factor and reduce initialization cost rather than guessing.
