Sample function (deploy and test)
import time
import json

def lambda_handler(event, context):
  start_time = time.time()
  # Simulate some CPU-intensive work or memory allocation
  data = [i*i for i in range(100000)]  # Adjust range for more or less memory/CPU
  time.sleep(0.5)  # Simulate some I/O or waiting
  end_time = time.time()
  duration = (end_time - start_time) * 1000  # in ms
  print(f"Function executed in {duration:.2f} ms")
  return {
    'statusCode': 200,
    'body': json.dumps(f'Hello from Lambda! Duration: {duration:.2f} ms')
  }
Note: keep cold-start-sensitive initialization outside the handler for fair duration comparisons.
Experiment steps
  1. Set memory to 128 MB, run 10 test invocations, record billed durations in CloudWatch Logs.
  2. Repeat at 256 MB and 512 MB. Compute average billed duration at each size.
  3. Calculate billed GB-ms: (memory in GB) × (average billed ms). Compare to find the lowest value.
Key Takeaway
A higher memory can lower total cost if it reduces duration proportionally.
Common mistake
Trusting a single invocation or ignoring cold-start variability.
