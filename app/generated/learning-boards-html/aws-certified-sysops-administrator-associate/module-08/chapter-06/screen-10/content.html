Module 8 › Chapter 8.6 › Fargate Right-Sizing
Steps to right-size
  1. Observe real CPU and memory metrics under representative load.
  2. Set minimal vCPU and memory that meet performance targets.
  3. Configure ECS Service Auto Scaling to adjust task count horizontally.
  4. Use Compute Savings Plans if you have stable baseline spend.
Example scenario
A microservice shows 25% CPU and 150MB memory on average; set task to 0.5 vCPU and 256 MB, then scale tasks horizontally during peaks.
Key Takeaway
Right-size per task and rely on autoscaling for burst capacity to minimize idle cost.
Pitfall
Over-provisioning each task to avoid occasional spikes multiplies cost immediately.
