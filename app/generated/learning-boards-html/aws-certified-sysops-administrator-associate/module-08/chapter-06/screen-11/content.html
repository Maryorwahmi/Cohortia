Module 8 › Chapter 8.6 › EKS Costs
Cost components
  • Control plane: fixed hourly fee per cluster.
  • Worker nodes: EC2 instances subject to right-sizing, Spot, RIs, Savings Plans.
  • Managed Node Groups reduce operational overhead and integrate with Auto Scaling.
Consider shared clusters to amortize control plane cost and apply labels for cost allocation to map spend to teams or applications.
When to use Fargate for EKS
Run pods on Fargate for simplified node management; follow Fargate sizing and cost guidelines for those pods.
Key Takeaway
EKS costs include a fixed control plane fee plus worker node costs; design clusters with those trade-offs in mind.
