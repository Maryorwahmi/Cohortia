Module 8 › Chapter 8.6 › Monitor & Iterate
Continuous optimization checklist
  • Collect CloudWatch metrics for duration, concurrency, CPU, and memory.
  • Create dashboards linking scaling events to cost changes.
  • Run small experiments when changing memory, concurrency, or task sizes.
  • Use labels and cost tags to allocate spend in shared environments.
  • Review Provisioned Concurrency and reserved capacity periodically for relevance.
  • Avoid defaulting to large allocations without measurement.
Action for this week
Pick one critical function or Fargate task and run a size-impact experiment. Track one metric and report back the cost difference.
