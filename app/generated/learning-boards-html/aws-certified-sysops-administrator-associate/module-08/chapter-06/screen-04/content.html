Module 8 › Chapter 8.6 › Lambda Pricing
Definition
Lambda billing equals requests plus billed duration × memory allocation.
  • Requests: charged per invocation.
  • Duration: measured in milliseconds per invocation.
  • Memory allocation: affects both price and CPU performance.
Key Takeaway

Measure billed GB-ms across memory sizes to choose the most cost-effective setting.

Practical example & experiment
Run the sample function at 128, 256, 512 MB and record billed duration from CloudWatch Logs. Compute GB-ms per invocation to compare cost.
Common misconception
Lower memory always reduces cost. Not true if duration increases significantly.
Pro tip
Run short load tests that mimic production paths to measure realistic durations.
