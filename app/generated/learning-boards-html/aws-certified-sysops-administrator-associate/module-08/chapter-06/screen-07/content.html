Module 8 › Chapter 8.6 › Concurrency Controls
Key terms
  • Reserved concurrency: guarantees capacity or sets a maximum for a function.
  • Account concurrency: the total concurrency across functions in an account/region.
  • Throttling: when requests exceed available concurrency and are rejected or retried.
Decision flow
  1. Identify critical functions that must always run. Reserve minimal concurrency for them.
  2. Identify non-critical functions and set maximum concurrency to prevent runaway costs.
  3. Test behavior under load to observe throttling, retries, and user impact.
Pro tip
Use CloudWatch concurrency metrics to set realistic reserved values based on observed peak usage.
Pitfall
Setting reserved concurrency to zero will stop the function from executing.
