Module 8 › Chapter 8.6 › Key Concepts
Lambda Memory Allocation
Memory affects cost and CPU; test multiple sizes and compute GB-ms to find the best setting.
Provisioned Concurrency
Eliminates most cold starts but incurs continuous cost; use it selectively for critical endpoints.
Fargate Billing
Fargate bills per vCPU and memory per second; right-size tasks and use autoscaling to avoid paying for idle capacity.
Consolidated takeaway: prefer data-driven adjustments. Monitor, run small experiments, and scale/purchase capacity where the workload pattern supports it.
