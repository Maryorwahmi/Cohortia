Module 2 › Chapter 1.3 › Practice Steps
Hands-on checklist
  1. Index a document with PUT and an explicit _id; check the response.
  2. Index another document with POST and note the auto-generated _id.
  3. GET the document by its _id and inspect _source.
  4. Run a URI q search for a simple field match.
  5. Run a Query DSL match and a range query and compare hits.
Tip: Use a small index name like movies or products to avoid accidental conflicts.
Starter curl examples
Use these as templates in your terminal or Kibana Dev Tools.
curl -X PUT "localhost:9200/products/_doc/1?pretty" -H 'Content-Type: application/json' -d'
{
  "name": "Laptop Pro X",
  "price": 1200.00,
  "category": "Electronics"
}'

curl -X POST "localhost:9200/products/_doc?pretty" -H 'Content-Type: application/json' -d'
{
  "name": "Wireless Mouse",
  "price": 25.99,
  "category": "Electronics"
}'
