Module 2 › Chapter 1.3 › RESTful API
Definition

Elasticsearch is accessed over HTTP. Use methods like GET, PUT, POST and DELETE, and pass data as JSON. This consistent interface makes it easy to script and integrate.

Why it matters
  • Language-agnostic access: any environment that speaks HTTP/JSON can use Elasticsearch.
  • Responses include metadata you can inspect and automate against, like _version.
  • Familiar tools like curl and Kibana Dev Tools are sufficient for many tasks.
Common mistake
Omitting Content-Type: application/json in curl requests often breaks parsing. Always set it when sending JSON bodies.
Concrete example
curl -X PUT "localhost:9200/products/_doc/1?pretty" -H 'Content-Type: application/json' -d'
{
  "name": "Laptop Pro X",
  "price": 1200.00,
  "category": "Electronics"
}'
Key Takeaway

Treat Elasticsearch operations as JSON-over-HTTP. Correct headers and methods matter.
