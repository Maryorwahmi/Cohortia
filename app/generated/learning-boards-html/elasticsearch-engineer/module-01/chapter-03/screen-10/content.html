Module 2 › Chapter 1.3 › URI Search (q)
Example URI searches
# All documents
curl -X GET "localhost:9200/products/_search?pretty"

# name contains Laptop
curl -X GET "localhost:9200/products/_search?q=name:Laptop&pretty"

# price between 10 and 50
curl -X GET "localhost:9200/products/_search?q=price:[10 TO 50]&pretty"
Limitations & tip
  • q is quick but limited for complex boolean logic or nested conditions.
  • Default operator between terms is OR; use + for AND or switch to Query DSL for clearer logic.
  • Prefer Query DSL for production features requiring precision and stability.
Why it matters

q is fast for exploration, but understanding its semantics prevents surprising results in your application.
