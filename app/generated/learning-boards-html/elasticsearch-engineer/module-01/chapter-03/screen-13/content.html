Module 2 › Chapter 1.3 › Safety & Best Practices
Formatting & headers
  • Always set Content-Type: application/json for JSON bodies.
  • Use single quotes around JSON in curl to reduce shell interpolation errors.
  • Check responses for errors and inspect _version when updating documents.
Security & validation
  • Do not expose raw _search endpoints to untrusted input without validation.
  • Sanitize and limit complex queries to prevent resource exhaustion.
  • Use authentication and request limits in production environments.
Pro tip

Treat user input as untrusted and validate fields before inserting into Query DSL structures.
