Indexing & Searching with the REST API

Start by using curl or the Kibana Dev Tools console to add JSON documents, fetch them by ID, and run quick searches. We'll keep examples small and repeatable so you can try them locally.

In this lesson
Index documents, retrieve by _id, run q searches, and start using Query DSL
Why it matters
These operations let you store and find data quickly; they are the backbone of search-driven features.
Quick tip
Always set Content-Type: application/json in curl requests to avoid parsing errors.
Concept map
Index → Retrieve → Search → Query DSL
Index
Store JSON documents and update the inverted index so fields become searchable.
Search
Run URI q searches for quick checks or Query DSL for precision and power.
Explore Key Topics
Indexing with PUT
Specify an _id to keep external identifiers in sync.
Auto-generated IDs
Use POST to let Elasticsearch assign unique IDs.
Query DSL
JSON-based queries like match and range for richer searches.
