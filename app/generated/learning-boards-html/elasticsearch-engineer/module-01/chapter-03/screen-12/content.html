Module 2 › Chapter 1.3 › Search Response
Typical response fields
  • hits.total — total number of matching documents.
  • hits.hits[] — array of matching documents returned for this query.
  • Each hit: _index, _id, _score, and _source (the original document).
Important notes
  • Total is not the page size; use size and from to control returned documents.
  • Max_score shows the highest relevance score in this result set.
  • Use _source for display and further application logic — it is the canonical stored JSON.
Key Takeaway

Understand hits, total and _score to correctly interpret both the quantity and relevance of search results.
