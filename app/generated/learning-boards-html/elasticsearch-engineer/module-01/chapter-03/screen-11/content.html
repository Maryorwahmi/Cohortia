Module 2 › Chapter 1.3 › Query DSL
Match query example
curl -X GET "localhost:9200/products/_search?pretty" -H 'Content-Type: application/json' -d'
{
  "query": {
    "match": { "name": "Laptop" }
  }
}'
Range query example
curl -X GET "localhost:9200/products/_search?pretty" -H 'Content-Type: application/json' -d'
{
  "query": {
    "range": { "price": { "gte": 10, "lte": 50 } }
  }
}'
Combined example (bool)
{
  "query": {
    "bool": {
      "must": [
        { "range": { "year": { "gt": 2000 } } },
        { "match": { "title": "fiction" } }
      ]
    }
  }
}
Key Takeaway

Query DSL takes a little more structure but enables powerful, composable searches necessary in production systems.
