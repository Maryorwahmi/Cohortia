Module 2 › Chapter 1.3 › Retrieve by ID
GET example
curl -X GET "localhost:9200/products/_doc/1?pretty"
If found, the response includes _source with your original JSON and metadata to verify index and version.
Usage notes
  • GET by id is a precise, non-scored lookup — use it when you know the document ID.
  • 404 Not Found means no document exists at that index/id pair.
  • Use search endpoints if you need to find documents by content rather than id.
Key Takeaway

Use GET by id for exact retrievals and to inspect the stored _source and metadata fields like _version.
