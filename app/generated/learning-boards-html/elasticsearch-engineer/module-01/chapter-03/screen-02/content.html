Learning Objectives
Skills to practice in the Kibana Dev Tools console and with curl.
Bloom
Learn → Understand → Apply → Master
01
Use the REST API
Explain and use HTTP verbs and JSON with curl or Kibana Dev Tools. This matters because the REST interface makes Elasticsearch accessible from many environments.
Verified competency milestone
02
Index documents
Index with either a specified _id or allow auto-generated IDs. This matters for syncing with external systems that already have identifiers.
Verified competency milestone
03
Retrieve by ID
Fetch a single document using its unique identifier and interpret the response fields like _index, _id and _version.
Verified competency milestone
04
Search: q & Query DSL
Run quick URI q searches and learn the Query DSL for match and range queries when you need expressive results.
Verified competency milestone
