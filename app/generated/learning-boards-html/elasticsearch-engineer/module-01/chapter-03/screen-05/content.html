What indexing does
  • Stores the full JSON document as _source so you can retrieve the original content.
  • Updates the inverted index and other structures to make fields searchable and filterable.
  • Returns metadata like _index, _id and _version so you can track persistence and updates.
Design implication: include fields you will search and filter on to get meaningful index structures.
Example document
{
  "name": "Wireless Mouse",
  "description": "Ergonomic wireless mouse with customizable buttons.",
  "price": 25.99,
  "category": "Electronics",
  "in_stock": true
}
Key Takeaway

Indexing both stores the original JSON and prepares searchable structures; plan fields to support your queries.
