Module 2 › Chapter 1.3 › Key Concepts
RESTful API
Use HTTP verbs and JSON to access cluster functionality; set headers correctly.
Indexing & _id
Index with PUT to specify _id or POST to auto-generate IDs depending on your needs.
URI q vs Query DSL
Use q for quick checks; use Query DSL for composable, production-ready queries like match and range.
Summary takeaway
Practice indexing, retrieval, and both q and Query DSL searches so you can confidently store and find data in Elasticsearch.
