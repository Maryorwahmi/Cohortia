Ports to know
9200 — HTTP REST API for queries, used by curl and Kibana Dev Tools.
9300 — Transport port for inter-node communication and some clients.
Docker mapping example
Use -p 9200:9200 to forward host traffic to the container's port.
Container networking tip
Containers on the same Docker network can reach each other by name, which simplifies Kibana configuration when both run in Docker.
Mistake to avoid
Running without -p 9200:9200 leads to 'connection refused' from the host even though the service runs inside the container.
Key Takeaway

Map 9200 for HTTP access and use container names for inter-container communication inside Docker networks.
