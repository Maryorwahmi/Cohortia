Module 1 › Chapter 1.2 › Verify Elasticsearch is running
Commands
docker ps

docker logs elasticsearch-node

curl -X GET "localhost:9200"
Run these in sequence: check running containers, inspect logs for startup progress, then query the HTTP API to confirm a JSON response.
Example response
{
  "name" : "elasticsearch-node",
  "cluster_name" : "docker-cluster",
  "version" : { "number" : "8.10.2" },
  "tagline" : "You Know, for Search"
}
Troubleshoot
If curl returns connection refused, verify -p 9200:9200 was used and Docker Desktop is running.
Key Takeaway

Confirm service availability with docker ps, docker logs, and a curl request to the HTTP API.
