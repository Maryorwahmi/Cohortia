Module 1 › Chapter 1.2 › Kibana Dev Tools
Try these requests in Dev Tools
GET /_cluster/health

GET /_nodes

GET /_cluster/stats
Execute each request and inspect the JSON response to learn where status, node names, and statistics appear.
Concrete example
GET /_cluster/health should show number_of_nodes: 1 for a single-node cluster and status typically green or yellow depending on replicas.
Misconception
Expecting green with replicas on a single node is incorrect; replicas need additional nodes to allocate.
Key Takeaway

Use these three Dev Tools queries to confirm cluster health and discover node-level metadata during your lab.
