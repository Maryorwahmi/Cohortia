Module 1 › Chapter 1.2 › Common mistakes
Symptoms & fixes
  • Connection refused: Verify -p 9200:9200 and that Docker Desktop is running.
  • Node not ready: Ensure -e "discovery.type=single-node" is present so the cluster can form.
  • Kibana can't connect: Confirm Elasticsearch HTTP API responds before starting Kibana or restart Kibana.
Diagnostic workflow
1) docker ps 2) docker logs elasticsearch-node 3) curl -X GET "localhost:9200"
Key Takeaway

Follow a short diagnostic sequence to find and fix the most common local setup issues quickly.
