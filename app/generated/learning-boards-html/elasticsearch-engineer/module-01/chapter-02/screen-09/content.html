Module 1 › Chapter 1.2 › Start Kibana
Kibana command
docker run -p 5601:5601 -e "ELASTICSEARCH_HOSTS=http://elasticsearch-node:9200" --name kibana-node -d docker.elastic.co/kibana/kibana:8.10.2
Open http://localhost:5601 in your browser after Kibana starts to access Dev Tools.
Version compatibility
Keep Kibana and Elasticsearch on the same major and minor version to avoid API mismatches and UI errors.
Startup tip
If Kibana doesn't connect immediately, wait for Elasticsearch to be ready and retry; Kibana will retry on its own but user confirmation speeds debugging.
Key Takeaway

Use ELASTICSEARCH_HOSTS to point Kibana to your Elasticsearch container and keep versions aligned for compatibility.
