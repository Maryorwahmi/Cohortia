Module 1 › Chapter 1.2 › Security: local vs production
Local lab
xpack.security.enabled=false simplifies access so learners can focus on APIs and queries without credentials.
Example
Works when containers are isolated and not reachable by other hosts.
Production
Enable X-Pack security, configure users, service tokens, and TLS to protect data and administrative operations.
Warning
Never leave security disabled on networks or production systems.
Key Takeaway

Use security disabled only in ephemeral, local labs. For any networked or production deployment, enable and configure security appropriately.
