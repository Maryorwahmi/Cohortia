Module 1 › Chapter 1.2 › Run Elasticsearch
Command (copy-paste into your terminal)
docker run -p 9200:9200 -p 9300:9300 -e "discovery.type=single-node" -e "xpack.security.enabled=false" -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" --name elasticsearch-node -d docker.elastic.co/elasticsearch/elasticsearch:8.10.2
Wait a minute after starting; check readiness with docker ps and then curl to confirm the HTTP API responds.
Breakdown
  • -p 9200:9200 exposes Elasticsearch HTTP API to your host.
  • discovery.type=single-node tells the node to form a single-node cluster for development.
  • xpack.security.enabled=false disables auth for local testing only.
  • ES_JAVA_OPTS limits JVM heap to avoid starving your host.
Common mistake
Omitting port mapping yields a running container that is not reachable from your host.
Key Takeaway

Use the pinned image and exact flags to ensure a reliable local Elasticsearch start.
