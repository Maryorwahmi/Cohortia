Module 1 › Chapter 1.2 › Key environment variables
Definitions
discovery.type=single-node
Forces the node to form a single-node cluster and bypass distributed discovery, enabling immediate readiness in a development environment.
xpack.security.enabled=false
Disables authentication and TLS so you can interact without credentials while working in an isolated lab.
ES_JAVA_OPTS
Passes JVM flags like -Xms and -Xmx to bound heap memory, which helps avoid OOMs on a developer machine.
Concrete example
Use -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" to limit the JVM heap to 512MB on low-memory machines.
Misconception
Disabling security is safe by default. It is only safe in isolated, non-networked local labs; do not do this in production.
Key Takeaway

Set discovery, security, and JVM options deliberately to control readiness, safety, and memory usage.
