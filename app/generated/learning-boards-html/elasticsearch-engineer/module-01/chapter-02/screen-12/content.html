Module 1 › Chapter 1.2 › Stop & Clean Up
Lifecycle commands
docker stop elasticsearch-node kibana-node
docker rm elasticsearch-node kibana-node  # optional: remove containers
Stopping releases ports and CPU; removing deletes container metadata but not images unless you remove them separately.
Why remove?
Removing helps avoid future name collisions and keeps docker ps clean when returning to fresh experiments.
Key Takeaway

Always stop containers when finished, and remove them when you want a clean slate for the next lab.
