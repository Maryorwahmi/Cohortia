Scenario

Node failure and replica promotion

Distribute primaries and replicas across nodes so that a single node failure does not remove both copies of a shard.
When a node fails, the cluster master elects replicas to be promoted to primaries to maintain availability.
Replicas also handle read requests, so they increase search throughput even when no failure occurs.
Mini exercise
Draw three nodes, label primaries P0 and P1 and replicas R0 and R1. Remove Node 1 and identify which replicas become primaries. This reinforces automatic promotion behavior.
Operational tip
Use allocation awareness to keep replicas in different failure domains, reducing correlated failure risk.
