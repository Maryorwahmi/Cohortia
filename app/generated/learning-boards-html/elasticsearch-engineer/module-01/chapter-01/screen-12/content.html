Module 1 › Chapter 1.1 › Indices & Documents
Hierarchy

Index → Document → _id

Indices group related documents and define how data is stored and queried.
Each document has a unique _id that enables idempotent updates and direct retrieval.
Documents are distributed across shards but remain addressable via index and _id.
Best practices
  • Use predictable index naming for time-series data to simplify retention.
  • Supply stable IDs when writing from systems that may retry to avoid duplicates.
  • Plan shard counts per index according to expected size and query needs.
