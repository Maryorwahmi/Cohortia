Definition

Purpose of Elasticsearch

A distributed engine optimized for search and analytics on semi-structured and unstructured data.

Use case: Product search
Fuzzy matching, relevance, facets for categories and filters on large catalogs.
Use case: Log analytics
Index streaming logs to search events, compute aggregations, and populate dashboards.
Use case: Security & observability
High-volume event indexing used for incident detection and forensic search.
Misconceptions
Common mistake
Treating Elasticsearch as the authoritative transactional store. It is optimized for searching and analytics, not for transactional integrity.
Contrast
Unlike relational DBs it favors flexible schema and search speed; unlike some NoSQL stores its indexing is specialized for text and aggregations.
Example scenario
An online store indexes product titles, descriptions, and attributes into Elasticsearch to provide instant search results and aggregation filters while keeping order transactions in a relational database for durability.
