Code example
{
  "title": "Waterproof Hiking Jacket",
  "sku": "HJ-12345",
  "description": "A breathable, waterproof jacket designed for multi-day hikes.",
  "price": 129.99,
  "tags": ["outdoor", "jacket", "waterproof"]
}
Illustrative mapping
title: text (analyzed) — good for full-text search
sku: keyword — exact matches and aggregations
description: text (analyzed)
price: double — numeric operations and range queries
Practical tip
If you change a mapping, you must reindex data for the new mapping to take effect. Plan mapping decisions early.
