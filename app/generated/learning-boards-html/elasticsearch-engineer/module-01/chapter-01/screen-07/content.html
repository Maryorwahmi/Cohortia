Module 1 › Chapter 1.1 › Indexing & Search Flow
Process

Document → Tokens → Inverted Index → Search

1. Document received and parsed as JSON; mapping rules applied to each field.
2. Text fields are analyzed and tokenized into terms; terms are normalized for consistent matching.
3. Terms are added to the inverted index with document references and positions.
4. Search queries are analyzed and matched against the inverted index; results are scored and returned.
Example
Indexing: { title: "waterproof hiking jacket" } → tokens: waterproof, hiking, jacket. Searching "hiking jacket" matches those tokens and returns the document with a relevance score.
Performance note
Lucene writes immutable segments that are merged in the background. This has implications for resource planning during heavy indexing.
