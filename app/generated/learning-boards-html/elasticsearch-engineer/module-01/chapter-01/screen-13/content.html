Activity

Visualize shard placement

Step 1
Draw cluster box and three nodes: Node 1, Node 2, Node 3.
Step 2
Place P0 on Node 1, R0 on Node 2. Place P1 on Node 2, R1 on Node 1. Leave Node 3 empty.
Reflection
If Node 1 fails, which shards remain? Which replicas are promoted?
Outcome
Replica R0 on Node 2 becomes the primary for shard 0; the index remains available assuming sufficient remaining nodes.
Tip
Use allocation awareness to avoid placing primaries and replicas in the same failure domain.
