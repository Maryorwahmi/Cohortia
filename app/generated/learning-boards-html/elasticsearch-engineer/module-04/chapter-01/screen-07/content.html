Observing Dynamic Mapping

How Elasticsearch Infers Field Types

PUT /my_blog_posts/_doc/1
{
  "title": "Introduction to Elasticsearch Mapping",
  "author": "Jane Doe",
  "publish_date": "2023-10-26",
  "views": 1500
}
Index a document into a new index.
Key Takeaway

Elasticsearch automatically infers field types for new fields, simplifying initial data ingestion but requiring careful validation.

Expected Inferred Types

  • title: text (for full-text search) with a keyword sub-field (for exact matching).
  • author: text (for full-text search) with a keyword sub-field.
  • publish_date: date (for date range queries and sorting).
  • views: long (for numerical operations and sorting).

To Verify:

After indexing, you can use GET /my_blog_posts/_mapping to retrieve and examine the dynamically generated mapping.
