Mapping Types

Dynamic Mapping Fundamentals

Elasticsearch's Automatic Type Inference

Schema-on-the-Fly

Dynamic mapping allows Elasticsearch to automatically infer the data types of new fields when documents are indexed without a predefined schema.

How Inference Works

  • Elasticsearch examines the value of a new field.
  • It applies a set of rules to determine the most likely data type.
  • For example, numbers become long, strings become text (often with a keyword sub-field), and ISO 8601 strings become date.
Key Takeaway

Dynamic mapping is convenient for rapid development and flexible schemas, automatically inferring types based on indexed data.

Convenience for Developers

Dynamic mapping significantly speeds up initial development by removing the need to define every field upfront. This is ideal for prototyping or exploring new datasets.

Example: User Profile Data

If users can add arbitrary tags or custom fields to their profiles, dynamic mapping allows these new fields to be indexed without requiring a schema update every time.
