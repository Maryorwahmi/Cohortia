Avoiding text/keyword Misconfiguration

Leveraging Sub-fields for Dual Functionality

The Problem

Incorrect Type Selection

  • Using text for IDs: Cannot reliably filter or aggregate.
  • Using keyword for descriptions: No relevant full-text search.
The Solution: Sub-fields

Dual Functionality with .raw

Map a field as text for full-text search, and add a keyword sub-field for exact matches and aggregations.

Practical Benefit

This approach allows you to search for "headphones" in product_name and filter by exact "Wireless Bluetooth Headphones" using product_name.raw.

Code Example: Sub-field Mapping
PUT /product_catalog
{
  "mappings": {
    "properties": {
      "product_name": {
        "type": "text",
        "fields": {
          "raw": {
            "type": "keyword"
          }
        }
      },
      "description": {
        "type": "text",
        "analyzer": "english"
      }
    }
  }
}
This mapping allows full-text search on product_name and exact matching on product_name.raw.
Key Takeaway

Always consider using sub-fields for textual data that requires both flexible full-text search and precise exact-value operations.
