The text Field: Full-Text Search

Enabling Relevant Search with Analysis

Analysis Process

How Text Fields are Processed

  1. Tokenization: Breaks text into individual words.
  2. Lowercasing: Converts all characters to lowercase.
  3. Stemming: Reduces words to their root form (e.g., 'running' to 'run').
  4. Stop Word Removal: Eliminates common, less meaningful words (e.g., 'the', 'a').
Concrete Example

If a document contains "The quick brown foxes are running," a text field would index tokens like "quick", "brown", "fox", "run". Searching for "foxes" or "ran" would still match.
