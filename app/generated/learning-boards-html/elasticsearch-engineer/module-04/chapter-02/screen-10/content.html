Numeric Types: Floating-Point Precision

Understanding double, float, half_float, and scaled_float

Floating-Point Types

Standard vs. Scaled

  • double (64-bit): High precision, standard float.
  • float (32-bit): Standard precision float.
  • half_float (16-bit): Lower precision, saves space.
  • scaled_float: Stored as long, scaled by a factor.
Scaled Float Example

To store 19.99 with a scaling_factor of 100, Elasticsearch internally stores it as 1999, avoiding floating-point inaccuracies.

scaled_float for Financial Data

High Precision, No Inaccuracies

scaled_float is ideal for monetary values and other data requiring exact decimal precision, preventing common floating-point errors.

"price": { "type": "scaled_float", "scaling_factor": 100 }
Key Takeaway

For critical numerical data like prices, scaled_float offers a robust solution to maintain precision and avoid floating-point arithmetic issues.
