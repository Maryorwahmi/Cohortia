Performing Geo-Queries

Finding data by distance, bounding box, or complex polygon shapes.

Querying `geo_point`

Once mapped as `geo_point`, you can perform powerful geo-queries to search based on spatial relationships.

`geo_distance`

Find documents within a specified distance of a central point.

`geo_bounding_box`

Find documents within a rectangular area defined by two corners.

`geo_polygon`

Find documents within an arbitrary polygon defined by a series of points.

Key Takeaway

Elasticsearch's geo-queries provide powerful tools for spatial analysis, enabling precise location-based search functionalities.

Example: `geo_distance` Query
GET/stores/_search
{
  "query": {
    "geo_distance": {
      "distance": "10km",
      "location": {
        "lat": 34.052235,
        "lon": -118.243683
      }
    }
  }
}
Pro Tip

Always specify units for distance (e.g., `km`, `mi`) in `geo_distance` queries to ensure correct interpretation.
