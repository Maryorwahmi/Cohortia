Storing Geographical Data with `geo_point`

Enabling location-based search capabilities for your applications.

Purpose

The `geo_point` data type is specifically designed for storing geographical coordinates (latitude and longitude), essential for location-based search.

Location-Based Apps

Ideal for finding nearby places, tracking assets, or analyzing spatial data.

Flexible Formats

Supports `[lon, lat]`, `"lat,lon"`, or `{"lat": lat, "lon": lon}`.

Key Takeaway

The `geo_point` type is fundamental for any application requiring efficient storage and querying of geographical coordinates.

Example: `geo_point` Mapping and Indexing
PUT/stores/_mapping
{
  "properties": {
    "name": { "type": "text" },
    "location": { "type": "geo_point" }
  }
}
PUT/stores/_doc/1
{
  "name": "Coffee Shop",
  "location": { "lat": 34.0522, "lon": -118.2437 }
}
Common Mistake

Swapping latitude and longitude values. Latitude ranges from -90 to +90, longitude from -180 to +180. Always double-check your order!
