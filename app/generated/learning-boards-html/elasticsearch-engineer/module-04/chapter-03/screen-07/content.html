False Positives from Flattening

Why standard `object` mapping can lead to incorrect search results.

The Problematic Query

If you search for documents where `features.name` is "Processor" AND `features.value` is "16GB", a standard `object` mapping might incorrectly match the "Laptop" document.

Misleading Matches

The query matches because both 'Processor' and '16GB' exist in the flattened fields, not because they are a linked pair.

Loss of Precision

The query lacks the precision to enforce that both conditions must be met within the *same* feature object.

Key Takeaway

The flattening problem can lead to false positives, where documents are matched incorrectly because the relationships between fields in an array of objects are not preserved.

Demonstration: Incorrect Query Match
GET/my_products/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "features.name": "Processor" } },
        { "match": { "features.value": "16GB" } }
      ]
    }
  }
}
Potential Incorrect Match
// This query would match the Laptop document
// even though 'Processor' is linked to 'Intel i7'
// and 'RAM' is linked to '16GB'.
// The relationship is lost.
