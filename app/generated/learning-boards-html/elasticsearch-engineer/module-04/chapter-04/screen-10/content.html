Adapting Mappings with Dynamic Templates

Defining rules for fields based on their name or data type.

What are Dynamic Templates?

Dynamic templates are rules within an index template that define how Elasticsearch should dynamically map fields based on their name or data type.

  • Purpose: Combine flexibility of dynamic mapping with control of explicit mapping.
  • Use Case: Map all fields ending with _id as keyword fields automatically.
Why Use Them?

Dynamic templates are ideal for evolving schemas or when you have many fields that follow a consistent naming convention but don't want to explicitly define each one. They reduce boilerplate and ensure consistency.

Key Takeaway

Dynamic templates offer a powerful way to apply mapping rules automatically to fields that match specific patterns, providing both flexibility and control over your schema.

Example: Dynamic template for '_id' fields
"dynamic_templates": [{  "strings_as_keywords": {    "match": "*_id",    "match_mapping_type": "string",    "mapping": {      "type": "keyword"    }  }}]
Explanation:
  • Any string field whose name ends with _id (e.g., user_id, order_id) will automatically be mapped as a keyword.
  • This prevents them from being mapped as text by default, which is often undesirable for ID fields.
