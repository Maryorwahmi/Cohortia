Normalizers for Exact Matching

Ensuring consistent, case-insensitive keyword searches.

What is a Normalizer?

A normalizer is similar to an analyzer but is designed for keyword fields. It transforms the field's value into a consistent, single token for exact matching.

  • Purpose: Achieve case-insensitive exact matching, remove special characters, etc.
  • Key Difference: Unlike analyzers, normalizers always produce a single token.
Practical Use Case

If you index "Apple" and "apple" into a tag_name field with a lowercase normalizer, both will be stored and searched as "apple", ensuring consistent exact matches.

Key Takeaway

Normalizers are crucial for standardizing keyword fields, enabling reliable exact matching regardless of input variations like casing.

Example: Custom lowercase normalizer
PUT /my_tags/_settings{  "analysis": {    "normalizer": {      "lowercase_normalizer": {        "type": "custom",        "char_filter": [],        "filter": ["lowercase"]      }    }  }}
Applying the normalizer to a field:
PUT /my_tags/_mapping{  "properties": {    "tag_name": {      "type": "keyword",      "normalizer": "lowercase_normalizer"    }  }}
