Step 2 & 3: Creating an Index and Indexing a Document

Observing automatic mapping application and dynamic field handling.

Automatic Template Application

When you create an index matching the user_logs-* pattern, the user_logs_template is automatically applied, inheriting all its settings and mappings.

  • Consistency: Ensures all daily log indices have the same structure.
  • Efficiency: No need to manually define mappings for each new index.
Dynamic Field Handling

The session_id field, not explicitly defined, will be mapped as a keyword due to the dynamic template rule for strings, showcasing flexibility.

Key Takeaway

Index templates automate mapping application, and dynamic templates provide intelligent default mappings for new fields, simplifying schema management.
