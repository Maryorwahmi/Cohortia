Core Concept

The Document: Elasticsearch's Fundamental Unit

Self-contained JSON records with unique identifiers.

What is a Document?

A document is the basic unit of information in Elasticsearch. It's a single, self-contained record, similar to a row in a relational database, but stored as a flexible JSON object.

  • JSON Object: Allows for schema-flexible data storage.
  • Unique Identifier (`_id`): Ensures each document can be uniquely addressed.
  • Original Source (`_source`): Contains the full JSON object as indexed.
Key Takeaway

Elasticsearch documents are flexible JSON objects, each with a unique ID, forming the basic unit of data storage and interaction.

product_document.json
{
  "_id": "PROD-001",
  "_index": "products",
  "_score": 1.0,
  "_source": {
    "product_id": "P-1001",
    "name": "Wireless Ergonomic Mouse",
    "description": "Comfortable mouse for extended use.",
    "price": 29.99,
    "category": "Electronics",
    "available": true,
    "tags": ["ergonomic", "wireless", "peripheral"],
    "manufacturer": {
      "name": "TechGear Inc.",
      "country": "USA"
    }
  }
}
Example Scenario

Imagine a product catalog. Each product, with its ID, name, description, price, and category, is stored as a single, self-contained JSON document in Elasticsearch. This allows for easy indexing and retrieval of all product details.
