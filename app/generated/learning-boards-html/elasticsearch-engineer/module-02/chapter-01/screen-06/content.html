Core Concept

Mapping: Defining Your Data's Schema

How Elasticsearch understands and processes your document fields.

What is Mapping?

Mapping is the schema definition for fields within your documents. It dictates the data type, how fields are indexed, and how they are stored, essential for accurate search and analysis.

  • Data Type Definition: Specifies if a field is text, numeric, date, etc.
  • Indexing Behavior: Controls how field values are processed for search.
  • Crucial for Queries: Ensures correct search, sorting, and aggregations.
Key Takeaway

Mapping is Elasticsearch's schema, defining how data is typed and indexed, critical for search accuracy and performance.

Mapping Approaches
Dynamic Mapping

Elasticsearch infers data types on first document index. Convenient for prototyping, but can lead to unexpected types.

Risk: Inconsistent Types
Explicit Mapping

Manually define schema before indexing. Provides precise control, ensuring data consistency and optimal performance.

Benefit: Precise Control
Common Misconception

Relying solely on dynamic mapping for production can lead to fields being incorrectly mapped (e.g., a product ID as 'text' instead of 'keyword'), causing search issues.
