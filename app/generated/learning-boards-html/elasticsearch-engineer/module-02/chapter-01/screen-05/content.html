Core Concept

Indices: Logical Collections of Documents

Organizing related data for efficient search and scalability.

Index Definition

An index is a logical namespace in Elasticsearch where you store collections of documents that are related to each other. It's a primary unit of data organization.

  • Logical Partition: Groups documents by purpose or domain.
  • Scalability: Distributed across physical shards for performance.
  • Query Target: Search operations typically target one or more indices.
Key Takeaway

Indices are logical containers for related documents, providing a scalable and organized way to manage data in Elasticsearch.
