Hands-on Challenge

Designing a 'Books' Index Mapping

Applying explicit mapping to a real-world scenario.

Activity: Create a 'books' index

Define an explicit mapping for the following fields in a new Elasticsearch index named books:

  • title: Searchable as full text.
  • author: Full text search, also exact matching/aggregations (multi-fields).
  • isbn: Exact keyword for unique identification.
  • publication_date: A date field.
  • price: A floating-point number.
  • genre: A keyword field for categorization.
  • pages: An integer number.
Key Takeaway

Successfully designing an explicit mapping for a complex dataset like 'books' demonstrates mastery of Elasticsearch data types and multi-field capabilities.

Starter code for 'books' index
curl -X PUT "localhost:9200/books?pretty" -H 'Content-Type: application/json' -d'{
  "settings": {
    "number_of_shards": 1,
    "number_of_replicas": 0
  },
  "mappings": {
    "properties": {
      "title": {
        "type": "text"
      },
      "author": {
        "type": "text",
        "fields": {
          "keyword": {
            "type": "keyword"
          }
        }
      },
      "isbn": {
        "type": "keyword"
      },
      "publication_date": {
        "type": "date",
        "format": "yyyy-MM-dd||yyyy/MM/dd"
      },
      "price": {
        "type": "float"
      },
      "genre": {
        "type": "keyword"
      },
      "pages": {
        "type": "integer"
      }
    }
  }
}'
Pro-Tip: Multi-Fields

For fields like 'author' that need both full-text search and exact matching, use a multi-field approach. Define the main field as text and add a sub-field (e.g., author.keyword) as keyword.
