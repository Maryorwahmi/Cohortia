Key Concepts

Recap of Essential Elasticsearch Terms

Document

The basic unit of information in Elasticsearch, a JSON object with an _id and _source.

Index

A logical collection of documents with similar characteristics, analogous to a database.

Mapping

The schema definition for fields within an index, dictating data types and how fields are indexed.

Dynamic Mapping

Elasticsearch's automatic inference of field data types when a document is indexed without a predefined schema.

Chapter Summary

Documents are JSON records, indices are their logical containers, and mapping defines their schema, with explicit mapping providing precise control over data types and indexing behavior.
