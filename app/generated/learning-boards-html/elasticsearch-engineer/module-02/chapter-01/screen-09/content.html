Data Types

Numeric, Date, Boolean, and Object Types

Structuring diverse data for powerful queries and analysis.

Numeric Types

long, integer, float, double. For numerical values, ranges, sorting, and mathematical operations.

Use Case: Price, Quantity

Date Type

Stores dates and times. Supports various formats for time-based queries and aggregations.

Use Case: Created_at, Event_date

Boolean Type

Stores true or false values. Ideal for flags or binary states.

Use Case: Is_available, Is_active

Geo_point Type

Stores latitude and longitude coordinates. Enables geospatial queries.

Use Case: Store Location, User Position

Object Type

Used for nested JSON objects. Allows structuring complex data within a document.

Use Case: Manufacturer Details, Address
Why it matters

Choosing the correct data type is crucial for efficient indexing, accurate search results, and effective aggregations. Misuse can lead to performance issues and incorrect query outcomes.
