The Power of Explicit Mapping

Taking control of your data's structure for optimal results.

Why Explicit Mapping?
  • Precise Control: Define exact data types and indexing behavior.
  • Data Consistency: Ensures all documents conform to a predictable schema.
  • Optimal Performance: Tailor indexing for specific search and aggregation needs.
  • Avoids Surprises: Prevents incorrect type inference from dynamic mapping.
Key Takeaway

Explicit mapping provides precise control over data types and indexing, ensuring consistency and optimizing search performance in production systems.

Multi-Field Example: Product Name
"product_name": {
"type": "text",
"fields": {
"keyword": {
"type": "keyword"
}
}
}
Full-Text Search

product_name (type: text) for analyzed, tokenized search (e.g., 'wireless mouse').

Exact Match & Aggregation

product_name.keyword (type: keyword) for exact matching and aggregations (e.g., 'Wireless Ergonomic Mouse').
