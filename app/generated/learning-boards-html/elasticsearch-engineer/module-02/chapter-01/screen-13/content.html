Key Concepts

Understanding Data Types for Effective Search

Explicit Mapping

Manually defining data types and properties for fields in an index, offering precise control.

Text Data Type

Used for full-text search, where content is analyzed (tokenized, stemmed).

Keyword Data Type

Used for exact-value matching, sorting, and aggregations; content is treated as a single, unanalyzed token.

Numeric & Date Types

For numerical values (long, float, etc.) and dates/times, enabling ranges, math, and time-based queries.

Chapter Summary

Explicit mapping is key for control, while understanding text, keyword, numeric, and date types ensures accurate and efficient data handling in Elasticsearch.
