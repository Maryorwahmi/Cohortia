Building an Index with cURL and Explicit Mapping

A step-by-step guide to defining your data schema.

Command Breakdown
  • curl -X PUT "localhost:9200/products?pretty": Sends a PUT request to create the 'products' index.
  • -H 'Content-Type: application/json': Specifies the request body format.
  • -d'{}': Contains the JSON payload for index settings and mappings.
Key Takeaway

Using cURL to create an index with explicit mapping provides granular control over your data's schema, ensuring optimal indexing and search behavior.

Create 'products' index with explicit mapping
curl -X PUT "localhost:9200/products?pretty" -H 'Content-Type: application/json' -d'{
  "settings": {
    "number_of_shards": 1,
    "number_of_replicas": 0
  },
  "mappings": {
    "properties": {
      "name": {
        "type": "text"
      },
      "description": {
        "type": "text",
        "analyzer": "english"
      },
      "category": {
        "type": "keyword"
      },
      "sku": {
        "type": "keyword"
      },
      "price": {
        "type": "float"
      },
      "available": {
        "type": "boolean"
      },
      "created_at": {
        "type": "date",
        "format": "yyyy-MM-dd HH:mm:ss||yyyy-MM-dd||epoch_millis"
      }
    }
  }
}'
Field Explanations

name, description: text for full-text search. category, sku: keyword for exact matching. price: float for numerical operations. available: boolean. created_at: date with multiple formats.
