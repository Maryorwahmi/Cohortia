Targeted Field Updates with _update API

Modifying specific fields using the doc approach.

# Partial update using the 'doc' approach
# Only update the 'price' and 'available' fields for product_101
curl -X POST "localhost:9200/products/_update/product_101?pretty" -H 'Content-Type: application/json' -d'
{
  "doc": {
    "price": 59.99,
    "available": false
  }
}
'
# Expected Response Snippet:
{
  "_index": "products",
  "_id": "product_101",
  "_version": 3, # Version increments
  "result": "updated",
  "_shards": {
    "total": 2,
    "successful": 1,
    "failed": 0
  }
}
How it Works

The `_update` API fetches the existing document, merges the provided `doc` object, and then re-indexes the modified document.

Efficiency Gain

Reduces network payload by only sending changed fields, making it more efficient than full document replacement for minor updates.

Use Case

Ideal for updating a small number of fields, like a product's price or availability status, without touching other data.

Key Takeaway

Use the `_update` API with `doc` for simple, efficient partial updates to specific fields.
