Deleting Individual Documents

The straightforward way to remove a single document by its _id.

# Delete a single document by its ID
curl -X DELETE "localhost:9200/products/_doc/product_105?pretty"
# Expected Response:
{
  "_index": "products",
  "_id": "product_105",
  "_version": 1, # Version increments to mark as deleted
  "result": "deleted",
  "_shards": {
    "total": 2,
    "successful": 1,
    "failed": 0
  },
  "_seq_no": 6,
  "_primary_term": 1
}
Method

Use the `DELETE` HTTP method targeting the specific document endpoint: `DELETE /<index>/_doc/<id>`.

Internal Process

Elasticsearch marks the document as deleted internally; it's not immediately removed from disk but will be during segment merges.

Version Increment

The document's `_version` increments, reflecting its new 'deleted' state, similar to an update operation.

Key Takeaway

Deleting by `_id` is precise and immediate for single documents, marking them for eventual physical removal.
