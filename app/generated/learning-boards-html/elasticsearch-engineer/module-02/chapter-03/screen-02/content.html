01

Perform Document Updates

Learn to execute both full document replacements by re-indexing and efficient partial updates using the `_update` API. This skill ensures your data remains current without unnecessary overhead.

VERIFIED COMPETENCY MILESTONE
02

Implement Optimistic Concurrency

Apply `if_seq_no` and `if_primary_term` to prevent 'lost updates' in concurrent environments. This ensures data integrity by only updating the version of the document you expect.
