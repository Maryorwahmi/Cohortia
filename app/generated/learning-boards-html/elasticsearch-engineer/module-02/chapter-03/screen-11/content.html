Bulk Deletion with _delete_by_query

Removing multiple documents based on specific criteria.

# Example: Delete all products from the 'Electronics' category that are not available
# IMPORTANT: Always test your query with _search first!
# curl -X GET "localhost:9200/products/_search?pretty" -H 'Content-Type: application/json' -d'
# {
#   "query": {
#     "bool": {
#       "must": [
#         { "match": { "category.keyword": "Electronics" } },
#         { "match": { "available": false } }
#       ]
#     }
#   }
# }
# '
# Now, execute the _delete_by_query (without safety params for now)
curl -X POST "localhost:9200/products/_delete_by_query?pretty" -H 'Content-Type: application/json' -d'
{
  "query": {
    "bool": {
      "must": [
        { "match": { "category.keyword": "Electronics" } },
        { "match": { "available": false } }
      ]
    }
  }
}
'
Query-Based Deletion

Deletes all documents that match the specified query criteria, similar to a `DELETE WHERE` clause.

Use Cases

Ideal for data retention policies (e.g., deleting old logs) or bulk cleanup of specific data subsets.

Asynchronous Operation

Returns a `task_id` for monitoring, allowing the operation to run in the background without blocking.

Key Takeaway

`_delete_by_query` is powerful for mass deletions but requires careful query construction and safety measures.
