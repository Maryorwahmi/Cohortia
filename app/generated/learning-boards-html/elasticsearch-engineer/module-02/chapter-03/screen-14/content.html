Key Concepts: Updates

Essential terms for managing document modifications.

Full Document Replacement

Updating a document by re-indexing the entire document using `PUT /<index>/_doc/<id>`.

Partial Document Update

Modifying specific fields using the `_update` API (`POST /<index>/_update/<id>`) with either a `doc` object or a `script`.

`script` in `_update`

A Painless script used for complex, programmatic updates to document fields, accessing `ctx._source`.

Key Takeaway

Efficient updates range from full replacements to granular, scripted modifications, always considering data integrity.
