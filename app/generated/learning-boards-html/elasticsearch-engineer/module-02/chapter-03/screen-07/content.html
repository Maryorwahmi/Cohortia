Dynamic Updates Using Painless Scripts

Performing complex modifications with the script approach.

# Partial update using a 'script'
# Increment the price by 10% for product_101
curl -X POST "localhost:9200/products/_update/product_101?pretty" -H 'Content-Type: application/json' -d'
{
  "script": {
    "source": "ctx._source.price *= params.factor",
    "lang": "painless",
    "params": {
      "factor": 1.10
    }
  }
}
'
# Expected Response Snippet:
{
  "_index": "products",
  "_id": "product_101",
  "_version": 4, # Version increments again
  "result": "updated",
  "_shards": {
    "total": 2,
    "successful": 1,
    "failed": 0
  }
}
Painless Scripting

Elasticsearch's default scripting language, designed for security and performance, used for complex updates.

`ctx._source` Access

Within a script, `ctx._source` provides direct access to the document's fields, allowing for read and write operations.

Dynamic Logic

Enables calculations, conditional updates, and dynamic addition/removal of fields, all server-side.

Key Takeaway

Use `script` in `_update` for powerful, programmatic, and atomic modifications to your documents.
