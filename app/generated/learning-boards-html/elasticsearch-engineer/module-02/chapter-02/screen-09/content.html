API Format
Decoding the Bulk API's NDJSON Format
Action metadata and document source lines working together.
NDJSON Structure
  • Not a single JSON object, but multiple JSON objects.
  • Each JSON object is on its own line, separated by a newline character.
  • Alternates between 'action metadata' and 'document source' lines.
Key Takeaway

The Bulk API uses a specific NDJSON format where each operation is defined by an action metadata line followed by its corresponding document source line.

Line Types Explained
  • Action Metadata Line: Specifies the operation (index, create, update, delete) and target (_index, _id).
  • Document Source Line: Contains the actual JSON content for the document being indexed or updated.
Example: Bulk API NDJSON Structure
curl -X POST "localhost:9200/_bulk?pretty" \
  -H 'Content-Type: application/json' -d'
{"index": {"_index": "products", "_id": "product_103"}}
{"name": "USB-C Hub", "description": "Multi-port USB-C adapter."}
{"create": {"_index": "products", "_id": "product_104"}}
{"name": "Gaming Headset", "description": "Immersive sound for gamers."}
{"index": {"_index": "products"}}
{"name": "Webcam 1080p", "description": "Full HD webcam for video calls."}
'
Structure Breakdown:
  • Line 1: index action for product_103
  • Line 2: Document content for product_103
  • Line 3: create action for product_104
  • Line 4: Document content for product_104
  • Line 5: index action (auto-ID)
  • Line 6: Document content for auto-ID document
