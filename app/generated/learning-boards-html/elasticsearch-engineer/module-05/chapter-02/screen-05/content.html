Sum Aggregation Explained

The sum aggregation calculates the total sum of numeric values for a specified field across all documents within the aggregation's scope.

  • •Requires a numeric field type (e.g., long, float).
  • •Ideal for calculating total revenue, total quantity, or cumulative scores.
  • •Returns a single value field in the response.
Use Case Example

To find the total revenue generated from all orders, you would apply a sum aggregation on the order_total field.

Key Takeaway

Use sum to get the grand total of any numeric metric, but always verify the field type.

Code Example: Summing Order Totals

GET /orders/_search
{
  "size": 0,
  "aggs": {
    "total_revenue": {
      "sum": {
        "field": "order_total"
      }
    }
  }
}

Expected Output Excerpt

"aggregations": {
  "total_revenue": {
    "value": 123456.78
  }
}
