Key Concepts: Core Metrics

Essential metric aggregations for quantitative analysis.

Metric Aggregations

Compute a single metric (e.g., sum, average) over a set of documents for quantitative analysis.

Sum & Avg Aggregations

Calculate the total sum and arithmetic mean of numeric field values across documents.

Min & Max Aggregations

Find the minimum and maximum numeric values for a field, useful for identifying extremes.

Summary Takeaway

These core metric aggregations are fundamental for extracting basic statistical insights and understanding the quantitative aspects of your data.
