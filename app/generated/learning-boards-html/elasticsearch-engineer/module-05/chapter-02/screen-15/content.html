Key Concepts: Advanced Metrics & Best Practices

Beyond the basics: counting non-nulls, combined queries, and unique values.

Value Count

Counts documents with a non-null value for a field, useful for data completeness.

Stats Aggregation

A convenience aggregation for computing min, max, avg, sum, and count in one request.

Cardinality Aggregation

Estimates the number of unique values for a field, efficient for large datasets.

Summary Takeaway

Beyond basic metrics, `value_count`, `stats`, and `cardinality` provide powerful, efficient ways to analyze data completeness and uniqueness, while always remembering the numeric field requirement.
