The Numeric Field Requirement

Metric aggregations like sum, avg, min, and max are designed exclusively for numeric fields.

  • •Target fields must be mapped as long, integer, float, double, etc.
  • •date fields can be used for min/max to find earliest/latest dates.
  • •Attempting to aggregate on text or keyword fields will result in errors or null values.
Common Mistake

Trying to calculate the sum of a customer_id.keyword field will fail because it's not a numeric type. Always check your field mappings!

Key Takeaway

Always verify that your target field is numeric before applying arithmetic metric aggregations.

Example: Incorrect Field Type

GET /orders/_search
{
  "size": 0,
  "aggs": {
    "sum_customer_ids": {
      "sum": {
        "field": "customer_id.keyword" // This will fail!
      }
    }
  }
}

Resolution: Correct Mapping

PUT /my_index
{
  "mappings": {
    "properties": {
      "numeric_field": {
        "type": "long" // Ensure numeric type
      }
    }
  }
}
