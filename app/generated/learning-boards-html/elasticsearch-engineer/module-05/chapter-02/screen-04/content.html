Defining Metric Aggregations

Metric aggregations are a type of Elasticsearch aggregation designed to calculate single metrics across a set of documents. They are the primary tools for quantitative analysis.

  • •Focus on single numerical results (e.g., sum, average, min, max).
  • •Provide quick statistical summaries of numerical data.
  • •Essential for dashboards, reports, and data exploration.
Analogy

Think of them like the 'SUM', 'AVG', 'MIN', or 'MAX' functions in a spreadsheet, but applied across thousands or millions of documents in your index.

Key Takeaway

Metric aggregations are your go-to for extracting concise statistical summaries from large datasets.

How They Work

Input: Documents with Numeric Fields

e.g., order_total, temperature, price.

Process: Apply Aggregation Function

sum, avg, min, max, value_count.

Output: Single Metric Value

e.g., total_revenue: 12345.67.
