Stats Aggregation Explained

The stats aggregation is a convenience aggregation that computes min, max, avg, sum, and count (equivalent to value_count) all at once for a given numeric field.

  • •Simplifies queries by bundling common metrics.
  • •Often more efficient than running five separate metric aggregations.
  • •Provides a quick, comprehensive statistical summary.
Practical Use

Use stats when you need a full statistical overview of a numeric field, like `order_total`, in a single, concise response.

Key Takeaway

stats is your shortcut for getting a complete set of basic metrics for a numeric field with minimal effort.

Code Example: Using Stats Aggregation

GET /orders/_search
{
  "size": 0,
  "aggs": {
    "order_value_stats": {
      "stats": {
        "field": "order_total"
      }
    }
  }
}

Expected Output Excerpt

"aggregations": {
  "order_value_stats": {
    "count": 1500,
    "min": 10.00,
    "max": 999.99,
    "avg": 123.45,
    "sum": 123456.78
  }
}
