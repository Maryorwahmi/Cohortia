Why Combine Aggregations?

Combining multiple metric aggregations in a single request allows for a comprehensive statistical overview with just one query.

  • •Efficiency: Reduces network round trips and processing overhead.
  • •Completeness: Provides a holistic view of data characteristics.
  • •Simplicity: Consolidates related analytical tasks into one request.
Practical Benefit

Instead of running five separate queries for sum, avg, min, max, and value_count, you can get all these results in one optimized request.

Key Takeaway

Combine aggregations to efficiently retrieve multiple statistical insights in a single, powerful query.

Code Example: Multiple Metrics

GET /orders/_search
{
  "size": 0,
  "aggs": {
    "total_revenue": {
      "sum": { "field": "order_total" }
    },
    "average_order_value": {
      "avg": { "field": "order_total" }
    },
    "lowest_order_value": {
      "min": { "field": "order_total" }
    },
    "highest_order_value": {
      "max": { "field": "order_total" }
    }
  }
}

Expected Output Excerpt

"aggregations": {
  "total_revenue": { "value": ... },
  "average_order_value": { "value": ... },
  "lowest_order_value": { "value": ... },
  "highest_order_value": { "value": ... }
}
