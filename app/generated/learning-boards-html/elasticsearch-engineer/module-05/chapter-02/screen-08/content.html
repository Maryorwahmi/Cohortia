Value Count Aggregation Explained

The value_count aggregation counts the number of documents that have a non-null value for a specified field.

  • •Distinguishes from the total document count (`_count`).
  • •Useful for understanding data completeness or field presence.
  • •Can be applied to any field type, not just numeric.
Use Case Example

To find out how many orders actually have an order_total recorded, you would use value_count on the order_total field.

Key Takeaway

Use value_count to assess the completeness of a specific field across your documents.

Code Example: Counting Orders with Totals

GET /orders/_search
{
  "size": 0,
  "aggs": {
    "orders_with_total": {
      "value_count": {
        "field": "order_total"
      }
    }
  }
}

Expected Output Excerpt

"aggregations": {
  "orders_with_total": {
    "value": 1500
  }
}
