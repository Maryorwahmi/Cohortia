Min & Max Aggregations Explained

The min and max aggregations find the minimum and maximum numeric values, respectively, for a specified field.

  • •min identifies the lowest value (e.g., lowest price, earliest date).
  • •max identifies the highest value (e.g., highest price, latest date).
  • •Both are crucial for understanding data ranges and identifying outliers.
Use Case Example

To find the lowest and highest order values in your sales data, you would apply min and max aggregations on the order_total field.

Key Takeaway

Use min and max to quickly identify the extreme values within your numeric datasets.

Code Example: Min & Max Order Values

GET /orders/_search
{
  "size": 0,
  "aggs": {
    "lowest_order_value": {
      "min": {
        "field": "order_total"
      }
    },
    "highest_order_value": {
      "max": {
        "field": "order_total"
      }
    }
  }
}

Expected Output Excerpt

"aggregations": {
  "lowest_order_value": { "value": 10.00 },
  "highest_order_value": { "value": 999.99 }
}
