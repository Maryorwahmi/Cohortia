Bucket Type 3

`date_histogram` Aggregation

Groups documents into fixed time intervals based on a date field, ideal for time-series analysis.

Time-Series Data: Indispensable for trend analysis, monitoring, and visualizing data over time (e.g., daily, weekly, monthly).

`fixed_interval` / `calendar_interval`: Key parameters to define the duration of each time bucket (e.g., "1d", "1h", "1M").

Nesting: Supports nesting metric aggregations to calculate statistics for each time bucket.

Key Takeaway

`date_histogram` is crucial for time-series analysis, grouping documents into consistent time intervals to reveal trends and patterns.

Example: Daily Orders Over Time
GET /orders/_search
{
  "size": 0,
  "aggs": {
    "orders_over_time": {
      "date_histogram": {
        "field": "order_date",
        "fixed_interval": "1d",
        "format": "yyyy-MM-dd"
      }
    }
  }
}
