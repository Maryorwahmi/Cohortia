Practical Application

`date_histogram` with Nested Metrics

Calculate statistics for documents within fixed time intervals, like daily revenue.

`fixed_interval`: Defines consistent, non-overlapping time buckets (e.g., "1d" for daily).

`format`: Specifies the output format for date keys, improving readability (e.g., "yyyy-MM-dd").

Nested Metrics: Calculate `sum` or `avg` of fields like `order_total` within each daily bucket.

Key Takeaway

`date_histogram` with nested metrics provides a powerful way to track and visualize time-based trends, like daily revenue, for informed decision-making.

Code Example: Daily Revenue Calculation
GET /orders/_search
{
  "size": 0,
  "aggs": {
    "orders_over_time": {
      "date_histogram": {
        "field": "order_date",
        "fixed_interval": "1d",
        "format": "yyyy-MM-dd"
      },
      "aggs": {
        "daily_revenue": {
          "sum": { "field": "order_total" }
        }
      }
    }
  }
}
