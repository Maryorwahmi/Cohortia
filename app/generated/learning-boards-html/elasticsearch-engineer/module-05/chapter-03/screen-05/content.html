Bucket Type 1

`terms` Aggregation: Group by Exact Values

Groups documents by the unique, exact values of a field, creating a bucket for each distinct term.

Use Cases: Ideal for categorical data like product categories, user roles, country codes, or status types.

Crucial for Strings: Always use a .keyword field for string fields to ensure exact matching of the entire string.

Nesting: Supports nesting metric aggregations to get statistics for each unique group.

Key Takeaway

Use `terms` for categorical grouping, always with `.keyword` for string fields, to get accurate counts and enable per-category metrics.

Example: Grouping Product Categories
GET /orders/_search
{
  "size": 0,
  "aggs": {
    "products_by_category": {
      "terms": {
        "field": "product_category.keyword",
        "size": 5
      }
    }
  }
}
Output Structure (Simplified)

"buckets": [

{ "key": "Electronics", "doc_count": 120 },

{ "key": "Apparel", "doc_count": 85 },

{ "key": "Books", "doc_count": 60 }

]
