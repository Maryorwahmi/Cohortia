Common Pitfalls

Avoiding Aggregation Mistakes

Understand common errors to ensure your aggregations are accurate and performant.

Missing `.keyword`: Forgetting to use `.keyword` on string fields for `terms` aggregation leads to incorrect grouping due to text analysis.

Incorrect `date_histogram` Interval: Using too small an interval on large datasets can create too many buckets, causing performance issues.

High Cardinality `terms` Fields: Fields with millions of unique values can lead to slow queries or memory limits; consider `size` or `composite` aggregation.

Key Takeaway

Always use `.keyword` for `terms` on string fields, choose `date_histogram` intervals wisely, and be mindful of high cardinality to ensure efficient and accurate aggregations.

Best Practices for Aggregation Design
Map String Fields as `keyword`

Ensure string fields intended for exact matching are mapped as `keyword` type to prevent analysis issues.

Choose `interval` Wisely

Select `fixed_interval` or `calendar_interval` appropriate for your data volume and desired granularity.

Manage `size` for `terms`

Limit the number of buckets for high-cardinality fields to prevent performance bottlenecks.
