`terms` Aggregation with Nested Metrics

Calculate per-group statistics and control the number and order of buckets.

`size` Parameter: Limits the number of top buckets returned (e.g., top 5 categories).

`order` Parameter: Sorts buckets by their document count or a nested metric (e.g., `_count: "desc"`).

Nested Metrics: Apply `sum`, `avg`, `min`, `max` to each bucket for detailed statistics.

Key Takeaway

Combine `terms` with `size`, `order`, and nested metrics to extract targeted, sorted, and statistically rich insights from categorical data.

Code Example: Top 5 Categories by Sales
GET /orders/_search
{
  "size": 0,
  "aggs": {
    "products_by_category": {
      "terms": {
        "field": "product_category.keyword",
        "size": 5,
        "order": { "_count": "desc" }
      },
      "aggs": {
        "total_sales_per_category": {
          "sum": { "field": "order_total" }
        },
        "average_sales_per_category": {
          "avg": { "field": "order_total" }
        }
      }
    }
  }
}
