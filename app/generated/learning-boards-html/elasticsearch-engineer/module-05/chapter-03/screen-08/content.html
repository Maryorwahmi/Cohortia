`range` Aggregation with Nested Metrics

Calculate statistics for documents within custom numeric or date ranges.

Defining Ranges: Use `ranges` array with `to` (exclusive) and `from` (inclusive) for precise boundaries.

Nested Metrics: Apply `avg`, `sum`, etc., within each range to get specific statistics for that segment.

Example: Grouping orders by price tiers to find the average order total in each tier.

Key Takeaway

`range` aggregation with nested metrics provides granular insights into data distribution across custom-defined intervals, like average sales per price bracket.

Code Example: Average Order Total by Price Range
GET /orders/_search
{
  "size": 0,
  "aggs": {
    "orders_by_price_range": {
      "range": {
        "field": "order_total",
        "ranges": [
          { "to": 50.0 },
          { "from": 50.0, "to": 100.0 },
          { "from": 100.0 }
        ]
      },
      "aggs": {
        "average_total_in_range": {
          "avg": { "field": "order_total" }
        }
      }
    }
  }
}
