Bucket Type 2

`range` Aggregation: Custom Intervals

Allows you to define custom ranges for numeric or date fields and group documents into those ranges.

Flexible Binning: Useful for creating histograms with predefined bins, such as price tiers or age groups.

`from` (inclusive) & `to` (exclusive): Each range is defined by these values, allowing precise control over bucket boundaries.

Nesting: Supports nesting metric aggregations to calculate statistics within each defined range.

Key Takeaway

Use `range` aggregation to define custom, non-overlapping intervals for numeric or date fields, enabling precise data segmentation.

Example: Price Tiers for Orders
GET /orders/_search
{
  "size": 0,
  "aggs": {
    "orders_by_price_range": {
      "range": {
        "field": "order_total",
        "ranges": [
          { "to": 50.0 },
          { "from": 50.0, "to": 100.0 },
          { "from": 100.0 }
        ]
      }
    }
  }
}
Output Structure (Simplified)

"buckets": [

{ "key": "*-50.0", "doc_count": 200 },

{ "key": "50.0-100.0", "doc_count": 150 },

{ "key": "100.0-*", "doc_count": 80 }
