Aggregation Query Structure

Aggregations are part of the standard _search endpoint request.

GET /your_index/_search
{
  "size": 0, // Optional: no search hits
  "aggs": { // The aggregation block
    "your_agg_name": { // Your chosen name
      "agg_type": { // Type of aggregation (e.g., terms, avg)
        "field": "your_field" // Field to operate on
      }
    }
  }
}
`_search` Endpoint

All aggregation queries are sent to the standard search endpoint.

`aggs` Block

The main section where all aggregation definitions reside.

Named Aggregations

Each aggregation needs a unique, descriptive name for identification.

Key Takeaway

Aggregation queries are structured within the `aggs` block of a `_search` request, allowing for named, type-specific analytical operations.
