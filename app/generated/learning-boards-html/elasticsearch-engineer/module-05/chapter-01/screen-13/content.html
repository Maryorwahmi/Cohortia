`text` Field Behavior

Analyzed for full-text search, broken into terms.

"description": {
  "type": "text"
}
  • Aggregating on `text` yields fragmented results.
  • Groups by individual words, not full phrases.

`keyword` Field Behavior

Treated as a single, unanalyzed token for exact matching.

"category": {
  "type": "text",
  "fields": {
    "keyword": {
      "type": "keyword"
    }
  }
}
  • Ideal for categorical grouping and sorting.
  • Ensures accurate grouping by full string value.
Key Takeaway

Always use the `.keyword` sub-field or ensure your field is mapped as `keyword` when performing aggregations on string fields for accurate grouping.
