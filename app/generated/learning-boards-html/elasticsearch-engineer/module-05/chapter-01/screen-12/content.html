Example: Products by Category

Count the number of products in each unique category.

GET /products/_search
{
  "size": 0,
  "aggs": {
    "products_by_category": {
      "terms": {
        "field": "category.keyword"
      }
    }
  }
}
`size: 0`

Ensures only aggregation results are returned, optimizing performance.

`products_by_category`

The custom name for this specific aggregation.

`terms` Aggregation

A bucket aggregation type used for grouping by exact field values.

Key Takeaway

A `terms` aggregation on a `keyword` field is a fundamental way to group and count documents by categorical values, providing immediate data summaries.
