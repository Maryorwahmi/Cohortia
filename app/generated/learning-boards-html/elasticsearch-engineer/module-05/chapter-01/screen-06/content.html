Module 5.1›Chapter 5.1›Metric vs. Bucket Aggregations

Metric Aggregations

Compute statistics over a set of documents, returning a single value or set of values.

Calculate numerical statistics.

Examples: sum, avg, min, max, cardinality.

Bucket Aggregations

Group documents into categories or 'buckets' based on specific criteria.

Categorize documents.

Examples: terms, range, date_histogram.

Key Takeaway

Metric aggregations compute statistics, while bucket aggregations group documents, forming the core of Elasticsearch's analytical capabilities.
