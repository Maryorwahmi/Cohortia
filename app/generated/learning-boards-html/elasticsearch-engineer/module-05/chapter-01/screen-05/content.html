Module 5.1›Chapter 5.1›The GROUP BY of Elasticsearch

SQL Approach

Uses GROUP BY with aggregate functions.

SELECT category, COUNT(*), SUM(price)
FROM products
GROUP BY category;
  • Groups rows by common values.
  • Calculates statistics per group.

Elasticsearch Aggregations

Uses bucket and metric aggregations.

"aggs": {
  "products_by_category": {
    "terms": { "field": "category.keyword" },
    "aggs": {
      "total_price": { "sum": { "field": "price" } }
    }
  }
}
  • Groups documents into 'buckets'.
  • Applies metrics within each bucket.
Key Takeaway

Aggregations provide a powerful, distributed equivalent to SQL's GROUP BY and aggregate functions, enabling complex data analysis.
