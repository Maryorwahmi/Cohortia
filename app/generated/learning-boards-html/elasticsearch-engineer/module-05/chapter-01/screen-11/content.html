Query with `size: 0`

Returns only aggregation results, no search hits.

GET /products/_search
{
  "size": 0,
  "aggs": {
    "products_by_category": {
      "terms": { "field": "category.keyword" }
    }
  }
}
Improved Performance

Reduces processing overhead and network traffic.

Focused Results

Ensures the response contains only the analytical summaries you need.

Avoids Unnecessary Data

Prevents fetching and formatting of individual documents when not required.

Key Takeaway

Always use `"size": 0` in aggregation queries when you only need the aggregated results to optimize performance and reduce overhead.
