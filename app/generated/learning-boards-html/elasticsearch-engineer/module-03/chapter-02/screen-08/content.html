Query Type

The range Query: Numerical Filtering

Filtering documents based on numerical values within a specified range.

Range Operators
  • gt: Greater Than (exclusive)
  • gte: Greater Than or Equal To (inclusive)
  • lt: Less Than (exclusive)
  • lte: Less Than or Equal To (inclusive)
Key Takeaway

Use range with numerical fields to define precise upper and lower bounds for your search criteria.

Kibana Dev ToolsGET /products/_search
{
  "query": {
    "range": {
      "price": {
        "gte": 50, // Price >= 50
        "lte": 100  // Price <= 100
      }
    }
  }
}
Example Scenario

Find products with a price between $50 and $100, inclusive.

Important Note

Ensure the field is mapped as a numerical type (e.g., float, integer) for correct range comparisons.
