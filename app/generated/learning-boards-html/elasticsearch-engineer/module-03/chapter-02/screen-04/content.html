Core Concept

Full-Text vs. Term-Level Queries

Understanding the fundamental difference in how Elasticsearch processes your search terms.

Key Distinction
  • Analysis: Full-text queries analyze the query string; term-level queries do not.
  • Matching: Full-text matches based on analyzed tokens; term-level matches exact terms.
  • Field Types: Full-text for `text` fields; term-level for `keyword`, `numeric`, `date`, `boolean`.
  • Purpose: Full-text for relevance search; term-level for precise filtering.
Key Takeaway

Always consider the field's mapping type and whether analysis is desired before choosing your query type.

VS
Analyzed Input

Query string processed (tokenized, stemmed).

Exact Input

Query string used as-is, no analysis.

Relevance Scoring

Matches based on term frequency, position.

Binary Matching

Document either contains term or not.

Example:

match on 'quick brown fox' vs. term on 'Electronics'.
