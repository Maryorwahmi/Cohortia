Advanced Filtering

Combining Term-Level Queries

Leveraging bool queries to combine term and range for complex filtering logic.

The `bool` Query
  • Acts as a compound query, combining other queries.
  • `filter` clause: Matches documents without affecting relevance score, optimized for speed.
  • Ideal for combining multiple exact-match conditions.
  • Ensures all specified conditions are met for the results.
Key Takeaway

Use a bool query with filter clauses to combine multiple term-level conditions for precise, unscored results.

Kibana Dev ToolsGET /users/_search
{
  "query": {
    "bool": {
      "filter": [
        { "term": { "status": "active" } }, // Active users
        {
          "range": {
            "last_login": {
              "gte": "2023-10-01T00:00:00",
              "lte": "2023-10-31T23:59:59" // Logged in October 2023
            }
          }
        }
      ]
    }
  }
}
Example Scenario

Find all users who are "active" AND logged in during October 2023.

Why `filter`?

Using filter is efficient because it bypasses relevance scoring, which is often unnecessary for exact filtering conditions.
