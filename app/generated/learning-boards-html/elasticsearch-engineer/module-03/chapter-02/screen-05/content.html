Query Type

The term Query

Finding documents with an exact, unanalyzed term in a specific field.

How it Works
  • Takes an exact term as input.
  • Performs no text analysis on the query string.
  • Searches for documents where the field contains that precise term.
  • Ideal for `keyword`, `numeric`, `date`, `boolean` field types.
Key Takeaway

Use term when you need to match a value exactly as it was indexed, without any linguistic processing.

Kibana Dev ToolsGET /products/_search
{
  "query": {
    "term": {
      "product_id": "XYZ-789" // Exact match for this ID
    }
  }
}
Example Scenario

Find a product with the exact ID "XYZ-789" in a product_id field mapped as keyword.

Pro Tip

Always verify the field's mapping type. For exact matches on text that might be analyzed, consider using a .keyword subfield.
