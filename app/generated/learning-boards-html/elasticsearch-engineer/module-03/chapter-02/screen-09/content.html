Query Type

The range Query: Date Filtering

Filtering documents based on date and time values within a specified period.

Date Range Considerations
  • Uses `gt`, `gte`, `lt`, `lte` operators.
  • Supports various date formats, but ISO 8601 (`YYYY-MM-DD`) is recommended.
  • Crucial for time-series data, event logs, and content publication dates.
  • Be mindful of time zones if your data requires it.
Key Takeaway

For date filtering, use range with consistent date formats and be aware of time zone implications.

Kibana Dev ToolsGET /products/_search
{
  "query": {
    "range": {
      "published_date": {
        "gte": "2023-01-01" // Published on or after Jan 1, 2023
      }
    }
  }
}
Example Scenario

Find products with a published_date on or after January 1, 2023.

Common Mistake

Using an incorrect or inconsistent date format can lead to parsing errors or unexpected results. Always validate your date strings.
