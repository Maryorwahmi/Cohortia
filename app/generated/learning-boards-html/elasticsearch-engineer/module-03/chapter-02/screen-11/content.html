Indexing Sample Product Data

Setting up an ecommerce index with appropriate mappings for term-level queries.

Mapping Strategy
  • product_name: text (for full-text search)
  • category: keyword (for exact filtering)
  • price: float (for numerical ranges)
  • in_stock: boolean (for exact boolean matches)
  • release_date: date (for date ranges)
Key Takeaway

Proper field mapping is the foundation for effective term-level queries; it dictates how Elasticsearch stores and searches your data.

Kibana Dev ToolsPUT /ecommerce
{
  "settings": { "number_of_shards": 1, "number_of_replicas": 0 },
  "mappings": {
    "properties": {
      "product_name": { "type": "text" },
      "category": { "type": "keyword" },
      "price": { "type": "float" },
      "in_stock": { "type": "boolean" },
      "release_date": { "type": "date" }
    }
  }
}

PUT /ecommerce/_doc/1
{ "product_name": "Laptop Pro X", "category": "Electronics", "price": 1200.50, "in_stock": true, "release_date": "2023-01-15" }

PUT /ecommerce/_doc/2
{ "product_name": "Wireless Mouse", "category": "Electronics", "price": 25.00, "in_stock": true, "release_date": "2023-02-01" }

POST /ecommerce/_refresh // Make documents searchable immediately
Action

Execute these commands in Kibana Dev Tools to create the index and populate it with initial data.
