Query Type

The terms Query

Searching for documents where a field contains any of a list of exact values.

Key Features
  • Accepts an array of exact terms.
  • Returns documents where the field matches ANY of the provided terms.
  • No analysis performed on the query terms.
  • Excellent for multi-select filters (e.g., categories, statuses).
Key Takeaway

Use terms when you need to find documents that match any of several specific, unanalyzed values.

Kibana Dev ToolsGET /products/_search
{
  "query": {
    "terms": {
      "category.keyword": [ // Querying a keyword subfield
        "Electronics",
        "Apparel"
      ]
    }
  }
}
Example Scenario

Find all products belonging to either the "Electronics" OR "Apparel" categories.

Best Practice

Always use .keyword subfields for exact matching on text-like data to ensure no unexpected analysis occurs.
