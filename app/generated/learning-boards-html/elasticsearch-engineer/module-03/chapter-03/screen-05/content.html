`bool` Clause Deep Dive

`must`: Essential Matches

Documents *must* satisfy these conditions and contribute to relevance.

All Queries Must Match

Acts as a logical AND; all sub-queries must be true for a document to be included.

Contributes to Relevance Score

Matching documents receive a higher `_score`, indicating greater relevance.

Key Takeaway

Use `must` for conditions that are absolutely required and should influence the document's ranking.

GET /products/_search
{
  "query": {
    "bool": {
      "must": [
        {
          "match": {
            "description": "laptop"
          }
        },
        {
          "term": {
            "in_stock": true
          }
        }
      ]
    }
  }
}

Example Scenario

Find products where the description *must* contain "laptop" AND the `in_stock` field *must* be `true`. Both conditions are mandatory and contribute to the product's relevance score.
