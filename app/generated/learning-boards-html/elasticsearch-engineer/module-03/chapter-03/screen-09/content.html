Practical Application

E-commerce Search Scenario

Combining `must`, `filter`, `should`, `must_not` for 'gaming laptops'.

User Requirements

Find "gaming laptops" that are "in stock", "priced under $2000", "not from 'Acme' brand", and *prefer* products "on sale".

Why `bool` is Key

Allows precise control over inclusion, exclusion, and relevance boosting for each condition.

Key Takeaway

Complex user needs require the `bool` query to combine multiple logical conditions effectively.

GET /products/_search
{
  "query": {
    "bool": {
      "must": [
        // Core requirements that must match and score
      ],
      "filter": [
        // Hard requirements that must match, but don't score (cached)
      ],
      "should": [
        // Preferences that boost score if matched
      ],
      "must_not": [
        // Conditions that must NOT match (exclude documents)
      ]
    }
  }
}
