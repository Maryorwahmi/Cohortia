`bool` Clause Deep Dive

`filter`: Non-Scoring Requirements

Hard conditions that don't affect relevance but boost performance.

No Relevance Score Contribution

Acts as a binary 'yes/no' check; matching documents get no score boost from the filter itself.

Often Cached for Performance

Elasticsearch can cache filter results, leading to significant speed improvements for repeated queries.

Key Takeaway

Use `filter` for strict inclusion/exclusion criteria that don't need to influence scoring, especially for performance-critical queries.

GET /products/_search
{
  "query": {
    "bool": {
      "filter": [
        {
          "term": {
            "category.keyword": "Electronics"
          }
        },
        {
          "range": {
            "price": {
              "gte": 500,
              "lte": 1500
            }
          }
        }
      ]
    }
  }
}

Example Scenario

Find products that *must* be in the "Electronics" category AND have a `price` between $500 and $1500. These conditions are hard requirements but do not affect the relevance score.
