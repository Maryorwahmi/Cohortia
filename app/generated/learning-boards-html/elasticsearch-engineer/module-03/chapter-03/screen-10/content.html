Core Requirements: `must` and `filter`

Implementing essential conditions for 'gaming laptop' and price/stock.

`must`: 'gaming laptop'

Ensures documents contain these terms and contributes to their relevance score.

`filter`: 'in stock' & 'price < $2000'

Hard requirements that don't score but benefit from caching for performance.

Key Takeaway

Strategically place conditions in `must` for scoring relevance and in `filter` for non-scoring, cached performance.

GET /products/_search
{
  "query": {
    "bool": {
      "must": [
        {
          "match": {
            "description": "gaming laptop"
          }
        }
      ],
      "filter": [
        {
          "term": {
            "in_stock": true
          }
        },
        {
          "range": {
            "price": {
              "lt": 2000
            }
          }
        }
      ],
      "should": [],
      "must_not": []
    }
  }
}
