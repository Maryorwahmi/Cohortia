`bool` Clause Deep Dive

`should`: Influencing Relevance

Conditions that boost score, becoming optional with `must` or `filter`.

Boosts Relevance Score

Documents matching `should` clauses receive a higher `_score`, making them more prominent.

Conditional Requirement

Optional if `must` or `filter` are present; otherwise, at least one `should` must match.

Key Takeaway

Use `should` for conditions that are desirable but not mandatory, to influence ranking without strict inclusion.

GET /products/_search
{
  "query": {
    "bool": {
      "should": [
        {
          "match": {
            "tags": "sale"
          }
        },
        {
          "match": {
            "promotions": "discount"
          }
        }
      ],
      "minimum_should_match": 1
    }
  }
}

Example Scenario

Find products that *should* contain "sale" in their tags OR "discount" in their promotions. Matching either condition will boost the document's score. `minimum_should_match: 1` ensures at least one must match if no other clauses are present.
