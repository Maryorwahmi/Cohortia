Key Concepts

Essential ideas from this chapter

operator parameter

A match query parameter that specifies whether all (AND) or any (OR, default) of the analyzed query terms must be present.

Relevance Scoring

The process by which Elasticsearch assigns a score (_score) to each matching document, indicating how well it matches the query.

Match Phrase

A query type for finding exact sequences of words, distinct from the default `match` query behavior.

Summary Takeaway

Controlling the operator parameter allows for precise search results, and understanding relevance scoring helps interpret the quality of matches.
