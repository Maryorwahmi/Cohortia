Implementing operator: "AND" for Focused Results

Ensuring all query terms are present in the document.

Scenario Refinement

We want to find products where the description contains all analyzed terms from "blue running shoes".

How it Changes Matching

A document must contain 'blue' AND 'run' AND 'shoe' (after analysis) to be considered a match, leading to much more precise results.

Key Takeaway

The operator: "AND" parameter is essential for highly specific searches, ensuring that all keywords contribute to the match criteria.

Kibana Dev ToolsQuery with AND
GET /products/_search
{
  "query": {
    "match": {
      "description": {
        "query": "blue running shoes",
        "operator": "AND"
      }
    }
  }
}
This query requires all analyzed terms ('blue', 'run', 'shoe') to be present in the 'description' field.
Expected Match Example

Only documents like "Our new line of blue running shoes" would match.
