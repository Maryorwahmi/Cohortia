Introducing the match Query for Full-Text Search

Your primary tool for intelligent full-text search.

What it Does

The match query is designed for full-text search, finding documents where a specified field contains words or phrases from your query string.

Key Feature: Automatic Analysis

It automatically applies the same text analysis (tokenization, lowercasing, stemming) to your query string as was applied to the indexed documents, ensuring relevant matches.

Key Takeaway

The match query is essential for natural language searches, intelligently bridging the gap between user input and indexed content.
