match Query in Action: A Product Search Example

Searching for "blue running shoes" in product descriptions.

Scenario

Find products related to "blue running shoes" in an e-commerce index.

How it Works

Elasticsearch analyzes the query string using the field's analyzer, then searches for documents containing any of the resulting terms.

Key Takeaway

The match query is powerful because it intelligently processes your search terms, allowing for flexible matching against analyzed document content.

Kibana Dev ToolsQuery
GET /products/_search
{
  "query": {
    "match": {
      "description": "blue running shoes"
    }
  }
}
This query searches the 'description' field for the terms 'blue', 'running', or 'shoes' (after analysis).
Expected Match Example

A document with "Our new line of blue athletic shoes" would match.
