Anatomy of a Search Request

Every search uses a query object to define logic.

The Search Endpoint

All search requests target the /_search endpoint, often scoped to a specific index (e.g., /products/_search).

The Query Object

The request body contains a query object, which is the root for all your search criteria and clauses.

Key Takeaway

Understanding the basic GET /<index>/_search structure with a JSON query object is fundamental for all Elasticsearch searches.

Request StructureJSON
GET /your_index/_search
{
  "query": {
    "<query_clause_type>": {
      "<field_name>": "<search_term>"
    }
  }
}
This template shows the basic structure for any search request.
Example: Simple Query
GET /products/_search
{
  "query": {
    "match": {
      "name": "laptop"
    }
  }
