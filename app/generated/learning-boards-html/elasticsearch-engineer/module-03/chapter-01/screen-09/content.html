The Default OR Operator: Broadening Your Search

match queries find documents containing any analyzed term.

How `OR` Works

If your query string analyzes into multiple terms (e.g., A, B, C), a document matches if it contains A OR B OR C.

Benefit: Broad Relevance

This behavior is ideal for general searches where you want to retrieve documents that are broadly related to your query terms, even if not all terms are present.

Key Takeaway

The default OR operator makes match queries flexible and forgiving, suitable for exploratory search, but requires awareness to avoid misinterpreting results.

Default `OR` Logic

Query: "quick brown fox"
Analyzed Terms: [quick, brown, fox]
Doc 1: "quick jump"
Doc 2: "brown dog"
Doc 3: "red fox"
All documents containing at least one term will match.
