Unveiling Score Calculation with `_explain`

Understanding Why a Document Received a Particular Score

What it Does

Provides a detailed, hierarchical breakdown of how a document's `_score` was calculated for a given query.

How to Use

Append `?explain=true` to a search request or use the dedicated `GET /<index>/_explain/<id>` endpoint.

Key Takeaway

`_explain` is essential for debugging and fine-tuning relevance, offering transparency into Elasticsearch's scoring logic.

Input

GET /products/_search?explain=true

GET /products/_explain/123

Output

Detailed `_score` breakdown for each document.

  • Term Frequency (tf)
  • Inverse Document Frequency (idf)
  • Field Length Norms
  • Query Boosts
