Explaining a Document's Score

A Step-by-Step Look at Score Calculation for a Specific Document

  • First, run your search query to identify documents of interest.

  • Then, use the `_explain` endpoint with the document ID and the *exact same query*.

  • This reveals a detailed breakdown of how the `_score` was calculated.

Key Takeaway

The `_explain` endpoint is crucial for targeted debugging, allowing you to understand individual document scores and validate relevance strategies.

# Step 1: Run a query to find documentsGET /products/_search{  "query": {    "match": {      "description": "fast laptop"    }  }}# Step 2: Explain a specific document's score (replace <index_name> and <document_id>)GET /<index_name>/_explain/<document_id>{  "query": {    "match": {      "description": "fast laptop"    }  }}
