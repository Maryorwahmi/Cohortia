Boosting Specific Product Tags

Prioritizing 'Premium' and 'High-Performance' Items

  • The `must` clause ensures core matches (e.g., "gaming laptop") are always present.

  • `should` clauses with `boost` elevate documents matching specific, desirable tags.

  • Higher `boost` values (e.g., 3.0 for "premium") lead to significantly higher `_score` contributions.

Key Takeaway

Boosting within `should` clauses is a powerful way to prioritize specific attributes, directly influencing search result order and user experience.

GET /products/_search{  "query": {    "bool": {      "must": [        {          "match": {            "description": "gaming laptop"          }        }      ],      "should": [        {          "match": {            "tags": {              "query": "premium",              "boost": 3.0 // Significantly increase score for 'premium'            }          }        },        {          "match": {            "tags": {              "query": "high-performance",              "boost": 2.0 // Increase score for 'high-performance'            }          }        }      ]    }  }}
