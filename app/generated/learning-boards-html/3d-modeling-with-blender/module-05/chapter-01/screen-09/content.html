Power and Color — process

Start with moderate values, preview the render, and adjust power in small steps. Use color to support mood, not to hide lighting problems.

Step-by-step
  1. Set a baseline power for your key light.
  2. Preview in Rendered viewport from the camera and assess contrast.
  3. Tune color subtly to support scene temperature.
  4. If clipping occurs, reduce power before changing color.
Example values
Key: Sun Strength 3, Angle 5° — sets main shape and shadow direction.
Fill: Area Power 100W, Size 2m — softens shadows without flattening form.
Rim: Point Power 50W, Radius 0.1m — adds separation and highlight along edges.
Key Takeaway

Power defines exposure; color defines temperature. Adjust both incrementally while previewing renders.
