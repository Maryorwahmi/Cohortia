Module 05 › Chapter 5.1 › Three-Point Lighting
Step-by-step
  1. Delete default cube and add your prop or Suzanne mesh.
  2. Add a Plane and scale it for a simple ground.
  3. Add Sun Light as Key: Strength 3, Angle 5°; orient for main shape.
  4. Add Area Light as Fill: Power 100W, Size 2m opposite Key.
  5. Add Point Light as Rim: Power 50W, Radius 0.1m behind the subject.
  6. Switch to Rendered viewport and iterate values while viewing through camera.
Notes and checks
  • Keep Fill weaker than Key to maintain modeling contrast.
  • Use Rim to separate foreground from background subtly.
  • Adjust color to suggest time of day or atmosphere.
Key Takeaway

A simple three-point setup gives control over form, shadow balance, and subject separation — a great starting point for many scenes.
