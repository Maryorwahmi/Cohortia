Activity — HDRI + Three-Point Lighting for a Character Bust

Follow the sequence to create a balanced, realistic portrait render using environment and studio lighting.

Step-by-step checklist
1. Open Blender. Replace default cube with a character bust and add a Plane as ground.
2. World Properties → Surface → Environment Texture → Open .hdr. Set Strength to 0.5–0.8.
3. Shader Editor (World): add Texture Coordinate (Generated) → Mapping → Environment Texture. Rotate Z to orient HDRI.
4. Add Area Light (Key): Power 500W, Size 1m, position above and to one side.
5. Add Area Light (Fill): Power 200W, Size 1.5m, opposite Key and slightly lower.
6. Add Point Light (Back): Power 100W, Radius 0.1m, behind and above for rim.
7. Use Rendered viewport and adjust HDRI strength and light powers until balance is achieved.
8. For Eevee: add Irradiance Volume and Reflection Probes, then Bake Indirect Lighting.
Expected outcome
A bust with defined form, subtle shadows, and realistic reflections driven by the HDRI.
Troubleshoot
If shadows are too dark, increase Fill power or rely on HDRI strength; if highlights blow out, reduce HDRI strength or exposure.
Analogy
Think of the HDRI as the room’s ambient light and the three lights as studio lamps that shape your subject within that room.
Key Takeaway

Combine HDRI for environment and three lights for sculpting. Bake probes for Eevee when real-time performance is required.
