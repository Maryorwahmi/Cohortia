Baking steps
  1. Prepare low-poly mesh with clean UVs and a new image to bake to.
  2. Duplicate or reference the high-poly model as the bake source.
  3. Select Bake type: Normal, Ambient Occlusion, Diffuse, or Combined.
  4. Run bake and save resulting textures into your asset folder.
Key Takeaway

Bake detail into textures to reduce shader and polygon cost while preserving visual fidelity.

Texture resolution guidance
Use 1K–2K for props and 4K for hero assets visible up-close. Match resolution to screen size and game engine limits.
Concrete Example
Bake normal and AO from a sculpted bust to a low-poly mesh and use those maps in the material for real-time presentation.
Common Mistake
Baking without tidy UVs can produce seams and wasted texture space; always check UV packing before baking.
