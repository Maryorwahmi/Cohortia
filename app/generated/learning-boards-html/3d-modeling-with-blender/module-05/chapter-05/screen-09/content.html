Module 6 › Chapter 5.5 › Scene Complexity
Steps to reduce complexity
  • Identify distant/irrelevant meshes and decimate them or replace with billboards.
  • Use linked duplicates (instances) for repeated items to share mesh data.
  • Keep subdivision low in viewport and higher for final render, or use adaptive subdivision.
  • Disable camera visibility for objects not contributing to the frame.
Key Takeaway

Trim geometry cost by decimating duplicates, using instances, and managing subdivision levels.

Concrete Example
Duplicate a high-poly prop, apply Decimate to the duplicate at 0.5 for background use, and disable rendering of the original when not visible.
Pro Tip
Use Alt‑D for linked duplicates to reduce memory; Shift‑D creates full, independent copies which increase memory usage.
Common Mistake
Forgetting to update or swap duplicates before rendering can leave high-poly meshes active, resulting in slow renders.
