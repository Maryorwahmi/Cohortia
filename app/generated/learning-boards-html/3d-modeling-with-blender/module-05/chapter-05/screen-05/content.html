Module 6 › Chapter 5.5 › Output Folder & File Format
Essential choices
Frame Range
Set Start and End frames for animations. For stills, render current frame only.
Output Folder
Create a dedicated folder for renders to avoid confusion and accidental cleanup.
File Formats
PNG for stills/transparency, OpenEXR for HDR/compositing, JPEG for web, FFmpeg for direct video.
Why use image sequences?
If your computer crashes during a long render, only a few frames are lost. Image sequences are resumable and easier to debug per-frame issues.
When to use OpenEXR
OpenEXR preserves high dynamic range and float precision, which is valuable for color grading and compositing without clipping highlights.
Key Takeaway

Set a project output folder and prefer image sequences for animations; choose formats by compositing needs.
