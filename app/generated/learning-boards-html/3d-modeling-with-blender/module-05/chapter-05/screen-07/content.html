Common Passes
Diffuse
Base color without direct lighting contributions.
Normal
Per-pixel orientation useful for relighting and baking.
Z-Depth
Distance from camera for depth-based effects like fog and DOF.
AO
Ambient occlusion to darken contact areas in compositing.
Glossy / Specular
Reflection highlights separated for precise control.
Direct / Indirect Light
Separate lighting contributions for nuanced edits.
Practice & Example
Enable Diffuse Indirect and Normal passes for a character bust. Use the Normal pass to soften reflections without re-rendering the scene.
Misconception
Some artists think passes always cost much more time. In many cases passes are generated alongside the main render with minimal overhead and large compositing benefits.
Key Takeaway

Use passes to localize changes in compositing and avoid expensive re-renders.
