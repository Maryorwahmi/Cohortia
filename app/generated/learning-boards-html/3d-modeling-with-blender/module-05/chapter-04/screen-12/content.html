Module 5 › Chapter 5.4 › Key Concepts
Rendering Engine
Software that turns 3D scene data into a final image by computing light interactions.
Eevee
Real-time rasterization with approximations and baked probes, optimized for speed and interactivity.
Cycles
Path tracing engine that simulates physical light bounces for photoreal results at higher render cost.
Summary

Match engine choice to the project's speed, fidelity, and hardware constraints. Use hybrid tactics like baking in Cycles for use in Eevee or game engines when needed.
