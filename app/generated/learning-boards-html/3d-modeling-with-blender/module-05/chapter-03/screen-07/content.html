Module 05 › Chapter 5.3 › Depth of Field and F-Stop
Definition

Depth of Field (DoF)

A range of distances that appear in focus. Use Focus Object or Focus Distance and control blur via F-Stop.

How to enable
In the camera's Object Data Properties check Depth of Field, assign a Focus Object or set Focus Distance, and adjust F-Stop.
Misuse Warning
Excessive DoF can make scenes read like miniatures; balance blur to keep context when needed.
Concrete Example
For a head portrait: enable DoF, set Focus Object to the head or an empty at eye level, then try F-Stop 2.8 for a soft background and 8 for more environment detail.
Check Your Understanding
How does lowering F-Stop affect the sharp plane, and why might you avoid a very low F-Stop for product renders?
Key Takeaway
F-Stop and focus distance shape clarity. Use DoF to guide attention but preserve necessary context for your scene's purpose.
