Module 05 › Chapter 5.3 › Active Camera & Scene Management
Definition

Active Camera

The active camera is the object Blender uses to render the scene. Setting it correctly ensures the intended composition and optical settings are applied during render.

Practical Steps
  1. Select the camera and press Ctrl+Numpad 0 to make it active.
  2. Or in Scene Properties choose the camera from the Camera dropdown.
  3. Name cameras clearly and store render cameras in a collection.
Common Mistake
Rendering with an unintended camera because it was neither named nor set active.
Example Scenario
You have an overhead camera for environment renders and a portrait camera for a character shot. Name them cam_env and cam_portrait. Before rendering the portrait, select cam_portrait and press Ctrl+Numpad 0. Preview with Numpad 0 to confirm the view and the focal length are correct.
Key Takeaway
Set and verify the active camera and use naming conventions to prevent render surprises.
Pro Tip
Use collections to hide non-render cameras when preparing final output, making it easier to choose the correct one.
