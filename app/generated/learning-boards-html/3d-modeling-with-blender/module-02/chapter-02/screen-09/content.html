Individual Origins
Each selection rotates/scales on its own pivot.
Example
Scale many staves to bow them independently while the group remains in place.
Bounding Box Center
Use the selection's axis-aligned bounding box center as pivot.
Example
Scale an array of objects outward from the box center to grow a grid uniformly.
Common mistake
If each element moves independently when you wanted a single center, you likely have Individual Origins selected by accident.
