Module 2 › Chapter 2.2 › Transformation Orientation
Global
World-aligned axes
Use Global when you need transformations that align to the scene coordinate system. It is predictable and consistent across objects.
Example
Move a roof section along the scene X axis to align with neighboring buildings.
Local
Component or object-aligned axes
Use Local to move a face along its normal or rotate an element according to its own orientation. This is invaluable on angled surfaces.
Quick check
If you expect motion along a face's outward direction, switch to Local; if motion is scene-global, stay with Global.
Misconception
Local always equals object rotation — not quite. In Edit Mode Local often aligns to selection or active element orientation. Verify the selected orientation before committing a transform.
