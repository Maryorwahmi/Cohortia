Module 2 › Chapter 2.2 › Terrain Hill Activity
Step-by-step checklist
  1. Add a Plane and Subdivide with 20–30 cuts.
  2. Enter Edit Mode and select a central vertex.
  3. Press O to enable Proportional Editing and pick Smooth falloff.
  4. Press G then Z and use the mouse wheel to set the radius and lift the hill.
  5. Create a crater by moving another vertex downwards with proportional editing.
Try variations
Switch falloff types to see differences and experiment with Individual Origins on a row of vertices for independent scaling.
Example operator panel notes
