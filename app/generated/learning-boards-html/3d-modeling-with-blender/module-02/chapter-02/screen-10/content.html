Module 2 › Chapter 2.2 › 3D Cursor Pivot
How to use
  1. Place the 3D Cursor at the intended pivot location (Shift + Right-Click by default).
  2. Select the 3D Cursor pivot mode from the viewport header.
  3. Start the transform and the action will use the cursor as center.
Example
Rotate a panel around an external hinge by placing the cursor at the hinge, then rotating the panel to simulate opening.
Common pitfalls
  • Forgetting to move the cursor after a specialized edit. It remains in place until changed.
  • Assuming the cursor snaps automatically to geometry; it must be placed deliberately.
Key Takeaway

Use the 3D Cursor for custom pivots that other built-in pivots cannot provide.
