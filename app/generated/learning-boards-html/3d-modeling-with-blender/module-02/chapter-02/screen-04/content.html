Module 2 › Chapter 2.2 › Move / Rotate / Scale
Definition
Transform tools in Edit Mode

Move (G): grab and translate selected components. Constrain with axis keys.

Rotate (R): rotate selection around the current pivot.

Scale (S): scale selection relative to pivot; axis constraints apply.

Example
Select vertices around an eye and use S to scale them inward to deepen the socket; use G then Z to move inward on the Z-axis for finer control.
Key Takeaway

Transformations apply only to selected components, so plan selections to prevent unwanted distortion.

Annotated steps
Move (Translate)
  • Press the G key to grab selection.
  • Press X / Y / Z to constrain to an axis.
  • Confirm or press Esc to cancel.
Scale & Rotate
  • S scales relative to pivot; use axis keys to scale on one axis.
  • R rotates around pivot; use an axis key to lock rotation axis.
Practical tip
When moving connected vertices expect adjacent faces to stretch; undo and adjust selection if topology looks wrong.
