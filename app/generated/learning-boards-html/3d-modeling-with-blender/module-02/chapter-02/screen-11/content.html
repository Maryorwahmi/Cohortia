Module 2 › Chapter 2.2 › Proportional Editing
Toggle and control
Toggle with the O key. Start a transform, then use the mouse wheel to adjust the radius interactively.
Falloff types
  • Smooth — natural curves for organic shapes.
  • Sphere — rounded influence similar to Smooth.
  • Sharp / Linear — for tighter, more defined influence.
Practical example
On a subdivided plane, select one vertex, enable proportional editing, and lift it up while scrolling to expand the radius. Observe how the surrounding vertices rise with a soft falloff to form a hill.
Common mistake
Leaving proportional editing enabled will change unrelated parts of the mesh. Confirm the icon state before performing precise edits.
Key Takeaway

Proportional editing lets one edit affect many vertices smoothly; pick falloff and radius to match the desired organic effect.
