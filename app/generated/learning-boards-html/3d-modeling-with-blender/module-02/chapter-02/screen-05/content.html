Step-by-step
How to constrain a transform
  1. Start a transform: press G, R, or S.
  2. Press X, Y, or Z to lock to that axis.
  3. Use Shift + axis to exclude an axis when scaling.
  4. Combine with orientation choices for local alignment.
Scenario
Widen a belt but preserve thickness: select belt vertices, press S then Shift Z to scale across the belt plane only.
Visual cues
World (Global) axis
X / Y / Z lock to world axes
Predictable for grid-aligned edits
Local axis
Axes align to selection or object
Use for angled geometry
Common mistake
Forgetting which orientation is active. If a constrained move yields unexpected direction, check the transformation orientation setting.
