Process Flow

How to enter and confirm mode

Step 1 — Select object
Click the object in Object Mode so it becomes active.
Step 2 — Enter Edit Mode
Press Tab or choose Edit Mode from the mode dropdown.
Step 3 — Choose selection type
Press 1 for vertices, 2 for edges, 3 for faces. Confirm the overlay highlights the chosen components.
Example scenario
You want to shape a character's mouth: enter Edit Mode, use Vertex Mode to shift corner points, Edge Mode to adjust the lip crease, and Face Mode to extrude the inner lip surface. Switching modes lets each change remain controlled and predictable.
Pro tip

Use the viewport header mode icons as a visual confirmation after pressing 1, 2, or 3 to avoid editing in the wrong mode.

Misconception
Confusing Tab with object selection: Tab toggles editing state; it does not change the selection type. Always verify selection mode separately.
