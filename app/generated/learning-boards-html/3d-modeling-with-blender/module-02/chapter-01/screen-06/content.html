Comparison

Vertex • Edge • Face

Vertex Mode
Point edits, precise curvature adjustments, merging and snapping vertices.
Edge Mode
Topology flow, loop selection, edge sliding and adding supporting edges for creases.
Face Mode
Surface-level edits like extrude, inset, and face deletion or filling.
Concrete example
To refine a helmet ridge: in Edge Mode select an edge loop and add a supporting edge for a sharp profile. Then return to Vertex Mode to nudge vertices for asymmetry. Use Face Mode if you need to extrude a visor from the surface.
Common mistake

Editing in the wrong mode causes surprising selections. Always confirm the current selection type before large edits.

Key Takeaway

Pick the mode that maps directly to the change you want to make — that reduces errors and cleanup work.
