Module 2 › Chapter 2.1 › Linked Select
Process

Select mesh islands with L

When to use it
When an object contains multiple disconnected parts and you want to act on one island only.
How it works
Select a component on the island and press L to select every element connected to it.
Concrete example
Add a second UV Sphere while in Edit Mode so you have two islands. Select one vertex on the first sphere and press L. The entire first sphere becomes selected, showing how Linked Select isolates connected parts quickly.
Common pitfall

Expecting L to find visually similar parts across different islands. It only follows connectivity, not matching geometry.

Key Takeaway
Use Linked Select to operate on a whole connected piece quickly and avoid editing neighboring islands accidentally.
