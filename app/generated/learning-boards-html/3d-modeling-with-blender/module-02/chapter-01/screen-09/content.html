Module 2 › Chapter 2.1 › Shortcuts
Definition

Select All and deselect patterns

A — Select all
Press A to select everything in the current mode.
A again / Alt + A — Deselect
Press A twice or Alt + A to clear the selection.
Loop & ring
Alt + Click for edge loops, Ctrl + Alt + Click for edge rings — powerful for topology edits.
Example
On a subdivided plane, press A to select everything. Then press A twice to clear. Use Box Select to choose a quadrant. This sequence prevents accidental lingering selections and speeds isolated edits.
Common mistake

Forgetting to clear selection before a focused edit leads to unintended transformations. Always confirm no undesired components are selected.

Key Takeaway

Master A and loop selection shortcuts to speed bulk and topology-specific edits while avoiding mistakes.
