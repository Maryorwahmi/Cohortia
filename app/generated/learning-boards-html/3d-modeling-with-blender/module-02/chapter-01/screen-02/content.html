Learning Objectives

From recognizing mesh anatomy to using linked selections, build practical selection skills for modeling.

01
Identify mesh components

Define vertices, edges, and faces and explain their roles in shaping models. Practice by inspecting a UV Sphere.

Mnemonic: Think corner, connector, surface.
VERIFIED COMPETENCY MILESTONE
02
Navigate Edit Mode

Enter Edit Mode, use Tab and the mode dropdown, and move between selection modes with 1, 2, 3 hotkeys.

Mnemonic: Tab toggles; 1-2-3 pick the component type.
VERIFIED COMPETENCY MILESTONE
03
Use selection tools

Apply Box, Circle, Lasso and Linked Select to target groups or islands of components quickly and reliably.

Mnemonic: Box for blocks, Circle for paint, Lasso for freehand, L for linked islands.
VERIFIED COMPETENCY MILESTONE
04
Model cleanly with selection

Recognize how selection affects topology and deformation, and avoid editing the wrong component type by double-checking your mode.

Mnemonic: Selection shapes topology; keep it clean.
VERIFIED COMPETENCY MILESTONE
