Selection Tools

Box, Circle, and Lasso

Box Select — B
Draws a rectangle to grab everything inside. Use for predictable, blocky regions.
Circle Select — C
Paint selections with an adjustable brush. Great for organic regions and fine control.
Lasso Select — Ctrl + drag
Freehand selection for irregular shapes and precision areas.
Example workflow
To isolate the top of a UV Sphere: use Box Select for the hemisphere, then refine with Circle Select to remove stray vertices. If a region is irregular, trace it with Lasso Select. Always verify selection mode first to ensure you pick vertices, edges, or faces as intended.
Pro tip

Use Circle Select with a reduced brush size to refine edges after a coarse Box Select; it blends speed and precision.

Misconception
Assuming selection tools auto-switch modes. They operate in the current selection mode; change modes if you need a different component type.
