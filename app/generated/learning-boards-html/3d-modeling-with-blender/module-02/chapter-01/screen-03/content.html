Practice & Verification

Short tasks that convert objectives into demonstrable skills you can check in Blender right away.

Component check
  • Open a UV Sphere, enter Edit Mode, and identify one vertex, one edge, one face.
  • Confirm each by selecting it in its respective mode.
Mode toggle check
  • Press Tab, then 1, 2, 3 to switch selection modes and explain when to use each.
  • Describe a task best done in each mode.
Selection tools check
  • Use Box, Circle, and Lasso to select a hemisphere; use L to select linked islands.
  • Confirm the selection matches your intent.
Topology check
  • Inspect an edge loop for clean flow and decide if it needs rerouting for deformation or UVs.
