Topology tools

Edge loop and edge ring selection

Alt + Left-Click — Edge loop
Selects a continuous loop of edges following face flow for topology edits.
Ctrl + Alt + Left-Click — Edge ring
Selects parallel edges across a set of faces to adjust width or density.
Example
To prepare a character joint for deformation, select loops around the joint and add supporting edges. Use edge rings when you need to thicken or thin parallel geometry uniformly.
Common mistake

Selecting a ring when you intended a loop will change the wrong set of edges. Verify selection before committing to topology changes.

Key Takeaway

Loops shape deformation; rings manage parallel geometry. Choose the pattern that matches your topology goal.
