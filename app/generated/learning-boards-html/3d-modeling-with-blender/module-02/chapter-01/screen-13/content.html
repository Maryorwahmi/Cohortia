Task prompts

Choose selection mode and tool

Task 1
Select top faces of a subdivided plane to extrude upward. Recommend Face Mode + Box/Circle Select and explain why.
Task 2
Select the head island in a single object containing many parts. Recommend Linked Select and explain why.
Task 3
Sharpen an edge loop around a panel. Recommend Edge Mode + Alt + Click and supporting edge insertion, explain topology reasons.
Scoring hint

Score by correctness and by whether the explanation includes topology impact and why alternatives would be less suitable.
