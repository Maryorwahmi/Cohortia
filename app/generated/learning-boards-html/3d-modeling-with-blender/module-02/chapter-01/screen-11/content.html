Hands-on steps

Explore selection on a UV Sphere

Step 1
File → New → General. Delete default cube. Add → Mesh → UV Sphere.
Step 2
Press Tab to enter Edit Mode. Press 1 for Vertex Mode and practice single and Box Selects.
Step 3
Press 2 and use Alt + Click to select edge loops. Press 3 to select faces and try Circle Select.
Step 4
Deselect everything with A twice, then select one component and press L to see Linked Select in action.
Concrete results
You should be able to isolate loops, paint-select faces, and select islands with confidence. Repeat these short drills until the hotkeys and patterns become second nature.
Key Takeaway

Short, repeated practice on primitives builds reliable selection habits you can apply to complex models.
