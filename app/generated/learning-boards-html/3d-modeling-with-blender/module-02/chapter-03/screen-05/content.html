Module 3 › Chapter 2.3 › Extrude Variations
Modes

Region, Manifold, Along Normals

Extrude Region
Pulls faces along an average normal — ideal for planar areas and simple panels.
Extrude Manifold
Attempts to maintain manifold topology by merging or dissolving intersecting geometry. Great for clean cuts and extensions.
Extrude Along Normals
Moves each selected face along its own normal to add consistent thickness on curved or angled surfaces.
Tip: try each mode on a small area before applying broadly, and inspect intersections immediately after.
Practical example
For a spaceship hull with angled panels, use Extrude Along Normals to add thickness so each panel keeps the same offset regardless of orientation. For a clean doorway cut, try Extrude Manifold to avoid internal faces at the intersection.
Misconception
Manifold extrusion fixes all geometry problems. It helps but complex intersections may still need manual cleanup.
Check
After extrusion, inspect normals and use selection tools to look for internal or overlapping faces.
