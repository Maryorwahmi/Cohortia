Module 3 › Chapter 2.3 › Inset + Extrude Workflow
Step-by-step

Make a recessed panel and a raised button

1. Select a face
Choose the face where the panel will sit.
2. Press Inset (I)
Drag inward to create the panel boundary. Confirm.
3. Extrude inward
Extrude the inset face slightly inward to recess the panel.
4. Inset center for button
Inset the recessed face to make a smaller area for a button.
5. Extrude outwards
Extrude the smaller face outward to create a raised button.
6. Verify geometry
Merge duplicates, check normals, and confirm smooth shading if desired.
Key Takeaway

Small, repeatable steps create robust detail: inset to define, extrude to form depth, verify to keep topology clean.
