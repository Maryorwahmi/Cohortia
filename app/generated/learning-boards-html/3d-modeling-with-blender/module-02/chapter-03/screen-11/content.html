Module 3 › Chapter 2.3 › Sci‑Fi Crate — Activity
Activity

Model a simple sci-fi crate

Starter steps
  1. New file: keep the default cube and enter Edit Mode.
  2. Select a face and press Inset; drag inward to form panel border.
  3. With the inset face active, press Extrude and move inward to recess.
Button and bevel
  1. Inset the recessed panel center for a button and extrude outwards to raise it.
  2. Select silhouette edges and press Bevel; drag and use the scroll wheel to set 3–4 segments.
  3. Merge duplicates, exit Edit Mode, and apply Smooth Shading to inspect highlights.
Key Takeaway

This exercise combines inset, extrude, and bevel into a repeatable process that produces readable, performance-aware detail for game props.
