Practice & Verification

Concrete tests to confirm each skill
Bloom → Apply / Master
Extrude Test
Create a raised panel from a cube face and ensure no overlapping or zero-length extrusions remain. Use Merge by Distance to fix any duplicates.
Extrude Variations Test
Apply manifold extrusion on intersecting geometry and extrude along normals on angled faces; confirm thickness and no internal faces.
Inset Test
Inset a face, extrude the inset to create a recessed panel, and inspect edge flow for clean topology.
Bevel Test
Bevel main silhouette edges with 3–4 segments and apply smooth shading to check highlight behavior without overloading polys.
