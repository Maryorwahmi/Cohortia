Architecture

Where and how much to bevel

Step: Identify edges
Pick silhouette and highlight edges first; ignore interior flat surfaces.
Step: Set width & segments
Start small. One segment for chamfer, 3–5 for roundness depending on camera distance.
Step: Inspect with shading
Use smooth shading to preview highlights and confirm the bevel reads well.
Consider: Topology impact
Bevels add loops and can create poles. Add supporting loops if needed for deformation or UVs.
Performance tradeoff
If geometry budget is tight, use fewer segments and rely on normal maps for fine rounding.
Pitfall
Avoid mass beveling followed by decimation. It damages UV islands and animation topology.
