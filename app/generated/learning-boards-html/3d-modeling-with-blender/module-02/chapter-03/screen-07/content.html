Inset Faces (I)

Inset creates a new internal face by scaling inward while adding perimeter geometry — great for panels, frames, and recessed details.

Region vs Individual
Region insets keep continuity around a selection; individual insets apply to each face separately.
Common usage
Create panels, window recesses, or a base for a raised button by insetting then extruding.
Example workflow
Select a face, press the inset key, drag inward to set border width, then extrude the inner face inward or outward for recessed or raised detail.
Misconception
Inset always preserves quads. In practice, topology may produce triangles or ngons; plan edge flow accordingly.
Pro tip
If you need clean quads, add supporting loops or adjust nearby edges before insetting large face groups.
