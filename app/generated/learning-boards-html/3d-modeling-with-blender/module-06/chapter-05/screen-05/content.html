Process Flow

Turn Actions into exportable NLA strips

  1. Select the Action in the Action Editor and make sure its frame range matches the animation loop or clip.
  2. Use the 'Push Down' action to create an NLA strip from the Action.
  3. Open the NLA Editor, rename the strip (for example: Walk, Idle, Jump).
  4. Adjust start/end frames and enable looping or scaling as needed.
  5. When exporting, enable 'Bake Animation' and 'NLA Strips' to export strips as separate clips.
Common Mistake
Relying solely on 'All Actions' without using NLA can lead to unnamed or overlapping clips. Use NLA for clarity and control.
