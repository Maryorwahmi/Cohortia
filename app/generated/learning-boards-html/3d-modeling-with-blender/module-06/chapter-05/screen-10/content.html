Module 6 › Chapter 6.5 › Missing animations checklist
1. Verify the clip exists
Open the Action Editor or NLA and confirm the action or strip is present and named.
2. Exporter options
For FBX, check NLA Strips vs All Actions. For GLTF, ensure Animation is checked.
3. Selection and limits
Did you export Selected Objects? Are frame start/end correct for the clip?
4. Bake procedural motion
IK, drivers, and constraints must be baked to keyframes for engines to play them.
Quick reproduction test
  1. Save your .blend. Push the action to NLA if applicable.
  2. Select Armature + Mesh, export small range to FBX/GLTF with animation enabled.
  3. Open the exported file in a lightweight viewer or import into the engine to confirm clip presence.
Common mistake

Exporting without selection or with the wrong action source often leads to no animation data in the file.

Key takeaway

Run the checklist in order: clip, exporter options, selection, bake, frames, and test import.
