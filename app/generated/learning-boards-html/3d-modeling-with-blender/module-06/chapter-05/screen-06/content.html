Module 6 › Chapter 6.5 › Baking animation
Definition

Bake procedural motion into explicit keyframes

Baking evaluates all constraints and drivers and records the resulting transforms as keyframes per frame or per sampling interval.

When to bake
  • When your rig uses IK, drivers, or constraints the engine won't run.
  • Before exporting clips you need to guarantee playback fidelity.
Export checkbox
Enable 'Bake Animation' and set the start/end frames. Choose 'NLA Strips' if strips contain your actions.
Concrete example

Bake a 24–48 frame walk cycle: set Bake Animation start and end to the loop frames, check NLA Strips if you pushed the Action down, then export. The FBX will include explicit keys so the engine shows the exact walk pose every frame.

Pro Tip
Bake only the necessary frame range and bones to limit keyframe count, then optimize curves if needed.
Common Mistake
Forgetting to set the correct start/end frames will bake extra motion or exclude part of the clip.
Quick Bake Checklist
  • Confirm action range matches the intended clip.
  • Push Actions to NLA if you want named strips exported.
  • Enable 'Bake Animation' in export and set Start/End frames.
  • Optionally simplify curves after baking to reduce keyframes.
