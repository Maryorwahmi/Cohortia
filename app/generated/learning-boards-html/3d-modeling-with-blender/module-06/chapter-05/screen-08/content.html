Module 6 › Chapter 6.5 › Export an animated character to FBX
Hands-on Activity

Export a walk cycle as SK_Character_Walk.fbx

Preparation

Open the file with your rigged character and ensure the walk Action is active and loop-ready.

NLA Push

In the Action Editor press Push Down to create an NLA strip, rename it to 'Walk', and set start/end frames for the loop.

Export Settings (core)
  • Path Mode: Copy; Limit To: Selected Objects; Object Types: Armature, Mesh
  • Transform: FBX All; Forward: -Z Forward; Up: Y Up
  • Geometry: Apply Modifiers; Armature: Uncheck Add Leaf Bones; Check Only Deform Bones
  • Bake Animation: Check Bake Animation; Check NLA Strips; Uncheck All Actions unless needed; Set Start/End to clip frames
Verify
Import SK_Character_Walk.fbx into your engine and confirm a named clip 'Walk' exists and plays with correct deformation. If not, check bake range, transforms, and bone roll.
Quick Troubleshoot Cards
Missing Animation
Check that Bake Animation is enabled and NLA Strips is checked if you pushed the action down.
Deformation Issues
Apply armature transforms, confirm Only Deform Bones is checked, and inspect bone rolls for inconsistencies.
Scale & Orientation
Use FBX All scaling, set Forward to -Z and Up to Y, and apply transforms before export.
