Module 6 › Chapter 6.5 › Troubleshooting & testing
1. Import check

Load the exported file into your engine or a viewer and confirm that all expected clips are listed and named correctly.

2. Deformation check

Play clips and test key poses to ensure skinning and bone mapping match Blender's preview.

3. Performance check

Profile or visually inspect for excessive keyframes, too many bones, or unexpected file size increases.

Final takeaway

Small, frequent tests and clear file naming are the best defenses against long debugging sessions later.
