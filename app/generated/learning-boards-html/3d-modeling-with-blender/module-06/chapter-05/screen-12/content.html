Reduce keyframe count
Graph Editor
  1. Trim animation to the minimal frame range required for the clip.
  2. Use curve interpolation to smooth motion instead of dense sampling.
  3. Use the Decimate Keyframes or Clean Keyframes scripts to remove redundant points.
  4. If baking, choose an appropriate sample rate; higher rates increase size.
Scale and modifiers
  • Apply object scale so the export reads consistent units in the engine.
  • Apply or include modifiers intentionally; unapplied modifiers can hide deformation differences.
  • Combine small animated objects where practical to reduce per-object overhead.
Example: simplifying a walk cycle

A walk cycle sampled at 60 fps yields many keyframes. By using curve smoothing and keeping only key poses plus a few in-betweens, you can reduce keyframes by 60–80% without losing perceived fidelity. Export the clip and test it in-engine to confirm the result.
