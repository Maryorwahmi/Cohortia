Module 6 › Chapter 6.5 › FBX animation export settings
Comparison

Important FBX options

Add Leaf Bones
Adds extra bones at chain ends — usually unwanted. Keep it unchecked unless your engine requires leaf bones.
Only Deform Bones
Export only bones that influence the mesh to reduce clutter and file size. Generally recommended.
Bake Animation
Must be checked for rigs with IK, constraints, or drivers. Converts procedural motion to keyframes.
NLA Strips vs All Actions
NLA Strips exports named strips; All Actions exports every action in the file. Use NLA for control and clarity.
Practical export checklist
  • Path Mode: Copy (embed textures if needed)
  • Limit To: Selected Objects; Object Types: Armature and Mesh
  • Transform: FBX All, Forward: -Z Forward, Up: Y Up
  • Geometry: Apply Modifiers; Armature: Uncheck Add Leaf Bones; Check Only Deform Bones
  • Bake Animation: Check Bake Animation; Check NLA Strips; Uncheck All Actions unless needed
Concrete Example
Export a walk cycle as SK_Character_Walk.fbx with the above settings. Verify the imported clip name and playback in your engine to confirm success.
