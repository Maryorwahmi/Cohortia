Module 6 › Chapter 6.5 › Export → Test → Iterate
Pre-export checklist
Save
  • Save incremental .blend: name_v01.blend
  • Verify action names and push to NLA as needed
  • Select armature + meshes to export
Export settings to confirm
  1. Transform: Apply Scalings, Forward/Up axes per engine
  2. Armature: Only Deform Bones ✓ ; Add Leaf Bones ✕
  3. Bake Animation: enabled if IK/drivers are used; set NLA Strips / All Actions appropriately
Import test routine
  1. Import into a fresh scene in your target engine or a viewer.
  2. Confirm skeleton matches bind pose and armature orientation.
  3. Open animation clips list and play each named clip; check timing and deformation.
  4. Note any mismatches and revert to saved .blend to iterate.
Pro tip

Keep a minimal test scene in your engine with a debug mesh and a rig to quickly validate clips and reduce iteration time.

Key takeaway

A short save-export-test loop is more productive than long modeling sessions without frequent checks.
