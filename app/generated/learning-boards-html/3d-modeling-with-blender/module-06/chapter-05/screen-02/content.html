Learning Objectives

Master the practical steps for exporting animated characters: from organizing clips to baking and exporting with the right FBX/GLTF options.

01
Organize Actions with NLA

Push each animation into the NLA editor as a named strip so it becomes a discrete clip the engine can reference. This keeps clips modular and avoids accidental overwrites.

VERIFIED COMPETENCY MILESTONE
02
Bake Complex Rigs

Convert IK, drivers, and constraints into keyframes so engines that lack Blender-specific features still reproduce the motion. Baking produces explicit keyframes per frame range.

VERIFIED COMPETENCY MILESTONE
03
Configure FBX Export

Set armature options like 'Only Deform Bones' and disable 'Add Leaf Bones', enable 'Bake Animation' and choose NLA Strips to export named clips correctly.

VERIFIED COMPETENCY MILESTONE
04
Test & Troubleshoot

Run quick imports into your target engine to verify playback, check transforms, and correct scale or bone orientation issues before committing long work sessions.

VERIFIED COMPETENCY MILESTONE
Bloom's Path
Learn → Understand → Apply → Master
Start by identifying actions, move to organizing in the NLA, then practice baking and export, and finally master engine testing loops.
Mnemonic
Think: Actions → Strips → Bake → Export (ASBE). It helps you remember the workflow when preparing clips for engines.
