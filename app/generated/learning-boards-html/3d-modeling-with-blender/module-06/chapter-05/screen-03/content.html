Skills & Safety

Small habits avoid export failures. Apply transforms, use clear naming, and save before export so you can test and iterate without losing progress.

05
Test Imports in Engine

Do quick imports after export to verify clip names, playback, and deformation. Early testing prevents wasted animation work.

VERIFIED COMPETENCY MILESTONE
06
Apply Armature Transforms

Before exporting, apply all transforms to the armature to avoid orientation and scale errors in the game engine.

VERIFIED COMPETENCY MILESTONE
07
Clear Naming & Ranges

Give actions and strips meaningful names and set bake start/end frames so each exported clip contains only the intended motion.

VERIFIED COMPETENCY MILESTONE
08
Save Before Export

Always save your Blender file before exporting. If export yields unexpected results, you can revert quickly and try different settings.

VERIFIED COMPETENCY MILESTONE
Why it matters
Small mistakes like unapplied transforms or ambiguous names are the most frequent causes of broken imports. These habits reduce iteration time and protect your work.
Mnemonic
Save, Name, Apply, Test — the four quick checks before every export.
