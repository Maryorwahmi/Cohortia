Module 6 › Chapter 6.5 › Key Concepts
NLA & Actions

Organize distinct animations as Actions and push them to NLA strips so each becomes a named clip for export.

Bake Animation

Bake converts IK, drivers, and constraints into explicit keyframes so game engines can reproduce the motion.

Armature Settings

Prefer Only Deform Bones and uncheck Add Leaf Bones for cleaner rig exports; match axis settings to the engine.

Summary

Organize, bake, and configure armature options before exporting. These three steps prevent most animation export failures.
