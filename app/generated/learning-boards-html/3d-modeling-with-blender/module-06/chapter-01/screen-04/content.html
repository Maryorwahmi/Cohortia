Module 6 › Chapter 6.1 › What is a Keyframe?
Core Concept

Keyframe — a snapshot in time

A marker that stores an object's property values at a specific frame so Blender can interpolate between keys.

Analogy: Keyframes are punctuation marks for motion — use them to define the important beats.
Concrete example
Set Z-location key at frame 1 (Z=2), set another at frame 20 (Z=0). Playback reveals the fall created by interpolation.
Key Takeaway

Keyframes are minimal: pick only what you need to describe motion concisely.

Common mistake

Over-keying every frame makes later timing edits tedious and unpredictable.

Visualized steps
Select object Move playhead to frame 1 Transform object (e.g., move Z to 2) Press I → choose 'Location' to insert keyframe Move playhead to frame 20 Move object to Z=0 Press I → choose 'Location'
