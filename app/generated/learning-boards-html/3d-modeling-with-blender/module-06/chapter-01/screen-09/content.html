Dope Sheet overview

A timeline view that lists keyframes per object and property, enabling batch edits to timing and rhythm.

Select and move
Select a group of keys and press G to reposition them in time across the scene.
Scale timing
Press S to compress or expand keys' spacing, effectively changing speed for the selection.
Concrete example
Select all Z-location keys for the ball, press S and type 0.8 to tighten timing for a faster bounce sequence.
Misconception
Assuming a single edit affects only one object; Dope Sheet edits can impact multiple objects simultaneously if selected.
Key Takeaway

Use the Dope Sheet for global timing edits like moving or scaling groups of keys to change rhythm quickly.

Pro tip

After bulk edits, scrub or play back immediately to catch any unintended timing shifts.
