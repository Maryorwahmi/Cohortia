Learning Objectives

Practical abilities you'll practice and verify.

Learn → Understand → Apply → Master
01
Grasp keyframe principles
Define poses at frames and use interpolation to create continuous motion. This matters because planning key poses helps you design timing and intent from the start.
Mnemonic: think of keyframes as punctuation for motion.
VERIFIED COMPETENCY MILESTONE
02
Use Timeline and Dope Sheet
Scrub the playhead, set frames, and adjust groups of keyframes to refine timing across your scene.
Mnemonic: Timeline = playback, Dope Sheet = timing workshop.
VERIFIED COMPETENCY MILESTONE
03
Set and manage transform keyframes
Insert, move, and delete Location, Rotation, and Scale keys so poses persist exactly where you expect them.
Mnemonic: Loc, Rot, Scale — capture full transform with one key.
VERIFIED COMPETENCY MILESTONE
04
Choose interpolation types
Select Linear, Constant, Bezier, or others to change motion feel from mechanical to organic.
Mnemonic: Linear = steady, Bezier = natural easing.
VERIFIED COMPETENCY MILESTONE
