Module 6 › Chapter 6.1 › Inserting and Managing Keyframes
Definition

Insert, update, and delete keys

Capture transforms at frames. Update keys by inserting on the same frame, delete keys to remove unwanted poses.

Example sequence: Select object Move playhead to frame 1 Transform object to pose A Press 'I' → choose 'Location' to insert Move to frame 20 Transform to pose B Press 'I' → choose 'Location' Select key → Delete to remove unwanted pose
Supporting notes
  • Use LocRotScale to record all three transforms when you need a full-pose snapshot.
  • If you want to change a key's value, be sure the playhead is on the keyframe so insertion updates the key.
  • Deleting a key restores the interpolation between the remaining keys; this can be useful for simplification.
Key Takeaway

Insert keys deliberately and update on-frame keys to avoid accidental duplicates.

Common mistake

Moving the object off-frame then inserting creates a key at the wrong time; confirm the playhead first.
