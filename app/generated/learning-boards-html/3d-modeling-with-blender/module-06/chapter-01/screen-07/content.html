Comparison

Linear vs Constant vs Bezier

Linear
Constant speed between keys. Use for mechanical, even motion.
Constant
Hold until the next key, then snap. Useful for instant changes or discrete states.
Bezier
Smooth ease-in/ease-out curves for organic motion. Preferred for lifelike animation.
Practical example
Create two keys for X position and test each interpolation. Linear = steady slide. Bezier = slide with easing. Constant = step change.
Misconception
Assuming one interpolation fits all motions. Instead, match interpolation to the physical or stylistic intent of the action.
Key Takeaway

Interpolation shapes speed. Swap types to test different emotional or physical readings of motion.

Pro tip

Use Bezier for natural motion and linear for mechanical motion. Tune Bezier handles for precise easing.
