Module 6 › Chapter 6.3 › Origin Point
What it is
Origin point = runtime pivot
The origin defines rotation, scaling center, and spawn location in the engine. Place it where the object naturally pivots or touches geometry.
Door
Origin at hinge for correct rotation.
Crate
Origin at bottom center so it sits on surfaces and rotates around its base if needed.
Character
Origin at feet or root bone to preserve animation and spawn placement.
How to set origin
  1. Position the 3D cursor where the pivot should be (Shift + S or manually).
  2. Choose Object > Set Origin > Origin to 3D Cursor, or Origin to Geometry to center on mesh volume.
  3. Test rotation and placement, then apply transforms if required.
Common mistake
Leaving origins off-center so objects rotate through space or float when placed in the engine.
Key Takeaway
Always set the origin to the functional pivot before exporting.
