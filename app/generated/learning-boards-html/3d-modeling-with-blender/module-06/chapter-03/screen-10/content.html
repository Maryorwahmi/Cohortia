Module 6 › Chapter 6.3 › Prepare Crate — Lab
Lab Steps
1
Model a crate
Add loop cuts and extrude faces to suggest planks; this gives high-poly detail to bake later.
2
Preview Decimate
Add Decimate modifier, set Ratio ~0.5 to preview. Keep a backup before applying.
3
Apply transforms
Move to X=5 Y=0 Z=0, rotate Z 45°, scale 2, then Ctrl + A > All Transforms.
4
Set origin
Use Origin to Geometry then set Origin to 3D Cursor after aligning the cursor at the crate base.
5
Rename & Units
Rename to SM_Crate_Wooden and set Scene Units to Centimeters with Unit Scale 0.01 for Unreal or adjust per engine.
6
Export & test
Export as FBX or glTF and import into the engine to verify scale, pivot, and material slots.
Safety & verification
Save a high-poly working file before applying destructive modifiers. Regularly export small tests to check scaling and origin behavior early in the pipeline.
Key Takeaway
A repeatable checklist prevents late-game surprises: model, preview optimizations, bake transforms, set origin, rename, set units, export and test.
