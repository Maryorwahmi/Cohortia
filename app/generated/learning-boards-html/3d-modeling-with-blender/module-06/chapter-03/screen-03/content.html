Practice Steps — Lab Checklist
A guided sequence you can follow with a single prop.
Create & add detail
Make a cube-based crate with a few loop cuts and extrusions to have modest geometry to optimize.
Optimize (Decimate)
Add a Decimate modifier at 0.5 or 0.3 to preview reduction. Don’t apply until you keep a backup.
Apply transforms
Move, rotate, scale as needed then use Ctrl + A > All Transforms to bake values into mesh data.
Set origin
Place the origin at the base for props; use Object > Set Origin > Origin to Geometry or Origin to 3D Cursor.
Rename
Use prefixes like SM_Crate_Wooden and MAT_Wood_Oak so assets are clear in the engine.
Units
Match Scene Properties > Units to your engine: meters for Unity, centimeters for Unreal, or set export scale accordingly.
