Learning Objectives
Learn, understand, apply, and verify essential export skills.
01
Model Optimization
Reduce polygon count and bake details so models render fast without losing perceived detail.
Mnemonic: budget pie — split detail across LOD and normal maps.
VERIFIED COMPETENCY MILESTONE
02
Apply Transforms & Origins
Bake location, rotation, and scale into mesh data and set the origin to the intended pivot point for correct runtime behavior.
Mnemonic: anchor point — origin equals pivot in-engine.
VERIFIED COMPETENCY MILESTONE
03
Naming Conventions
Use prefixes like SM_, SK_, MAT_, TEX_ so assets are immediately identifiable and sortable in engine editors.
Mnemonic: prefix = role.
VERIFIED COMPETENCY MILESTONE
04
Units & PBR Setup
Match Blender units to the engine and use Principled BSDF with standard maps so materials convert predictably.
Mnemonic: units match scale, PBR matches look.
VERIFIED COMPETENCY MILESTONE
