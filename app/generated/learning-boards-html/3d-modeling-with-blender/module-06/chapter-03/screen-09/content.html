Module 6 › Chapter 6.3 › PBR Materials
PBR inputs
  • Base Color (albedo)
  • Metallic
  • Roughness
  • Normal map
  • Ambient Occlusion
Use Principled BSDF to map these textures directly. Bake procedural effects to images when preparing for export.
Baking guidance
Bake normal maps from high-poly detail, flatten procedural roughness to a roughness map image, and pack textures or ensure correct file paths for export.
Common mistake
Relying on node setups that engines cannot read; always bake to images or use engine shader equivalents.
Example
Convert a worn wood shader into Base Color, Normal, and Roughness textures. Assign them to Principled BSDF and export with the FBX or glTF so the engine receives standard PBR maps.
