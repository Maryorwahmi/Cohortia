Module 6 › Chapter 6.3 › Apply Transforms
Claim
Applying transforms ensures consistent scale and pivot
Ctrl + A › All Transforms bakes object-level changes into vertex data so the mesh imports with the intended orientation and size.
Concrete example
You scaled a crate by 2 and rotated it 45 degrees. After applying transforms, its transform properties read 0,0,0 position, 0,0,0 rotation, and 1,1,1 scale while visually unchanged.
Pro tip
Apply transforms before rigging or exporting multiple objects to avoid scale inheritance issues and inconsistent animations.
Step-by-step
  1. Place and scale your object as desired.
  2. Confirm visual placement in the viewport and object properties.
  3. Press Ctrl + A then choose All Transforms to bake into mesh data.
  4. Verify object properties now show Location 0, Rotation 0, Scale 1 and the mesh still looks correct.
Common mistake
Skipping this step and relying on export scale often results in inconsistent sizes, broken physics, or incorrect animation pivots in the engine.
