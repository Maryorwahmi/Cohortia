Prefix conventions
Common useful prefixes:
  • SM_ — static meshes (props, environment)
  • SK_ — skeletal meshes (animated characters)
  • MAT_ — materials
  • TEX_ — textures and image maps
Example
SM_Crate_Wooden, MAT_Wood_Oak, TEX_Wood_Oak_NRM
Suffixes & variants
Use _LOD0, _LOD1, or _COLL to indicate level-of-detail or collision meshes. This identifies behavior and automates import rules.
Common mistake
Using default Blender names like Cube.001 makes large scenes hard to manage and breaks automated pipelines.
Project tip
Agree on naming rules at project start and include them in an asset checklist so everyone follows the same conventions and automation works predictably.
