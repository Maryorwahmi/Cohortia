Module 6 › Chapter 6.3 › Units & Scale
Quick chart
Unity convention: 1 unit = 1 meter. Keep Blender Length = Meters, Unit Scale = 1.0 for predictable imports.
Unreal convention: 1 unit = 1 centimeter. Set Blender Length = Centimeters and Unit Scale = 0.01 for closer parity.
Export-time scale: available but less reliable when many assets must remain consistent across a project.
Concrete example
If a 2-meter tall tree is modeled with Blender meters but imported into an engine that expects centimeters without scaling, the tree appears 200 cm vs 20000 cm mismatch. Align units to avoid this error.
Checklist
  • Decide target engine early.
  • Set Scene Properties & Units accordingly.
  • Export a test object and confirm dimensions in-engine.
