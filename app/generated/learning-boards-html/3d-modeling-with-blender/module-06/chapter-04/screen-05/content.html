Process Flow

FBX Export Steps

  1. Select your mesh objects and enable Selected Objects in export.
  2. Set Object Types → Mesh to ensure only geometry exports.
  3. Transform → Apply Scalings: use FBX All or Units Scale for consistent size.
  4. Set Forward/Up to match the target engine (example: -Z / Y for Unity).
  5. Geometry → Apply Modifiers if you need modifier results baked into the mesh.
  6. Path Mode → Copy and Embed Textures to include images in the FBX.
Key Takeaway

FBX export has many toggles; use Selected Objects and match axes and scale for predictable imports.

Transform settings
Apply Scalings and Forward/Up axes control orientation and size. Mismatches cause sideways or flipped imports.
Geometry
Apply Modifiers to bake changes. If left unapplied, the engine receives the pre-modifier mesh.
Textures
Use Path Mode Copy and Embed to include textures in the FBX. Otherwise pack your .blend first.
Common mistake
Forgetting Selected Objects exports the entire scene, including cameras and lights.
