Module 6 › Chapter 6.4 › Normals & Shading
Core Concept

Normals matter for correct shading

Flipped normals or inconsistent smoothing often cause the worst-looking shading in game engines.

  • Enable Face Orientation to spot flipped faces (red = inside).
  • In Edit Mode select all and press Shift + N to recalculate outward normals.
  • Use auto-smooth for hard edges or manually split normals where necessary.
Common misconception

Smoothing groups alone do not fix an inverted normal. The face orientation must be corrected first.

Practical example
If a part of your mesh appears dark or disappears in the engine, check normals. Recalculate and re-export to confirm the fix.
Key Takeaway

Normals fixed in Blender usually solve shading artifacts after import. Do this before export to save time.
