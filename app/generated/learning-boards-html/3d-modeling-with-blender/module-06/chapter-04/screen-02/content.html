Learning Objectives

Skills to master for reliable game exports

Bloom: Learn → Understand → Apply → Master
01
Identify FBX vs glTF
Explain each format's strengths and choose the right one for your engine or pipeline. This matters because picking the wrong format can force extra conversion work.
Mnemonic: File type decision tree
VERIFIED COMPETENCY MILESTONE
02
Configure export settings
Set Selected Objects, axes, scale, and embedding to match your engine. Accurate settings prevent orientation and size issues on import.
Mnemonic: S.A.S.E — Selected, Axes, Scale, Embed
VERIFIED COMPETENCY MILESTONE
03
Troubleshoot common issues
Find and fix missing textures, incorrect normals, and scale mismatch by following targeted checks before export.
Mnemonic: T.M.N — Textures, Modifiers, Normals
VERIFIED COMPETENCY MILESTONE
04
Perform a successful export
Execute a full export workflow and import into a game engine to verify orientation, pivot, and material fidelity.
Mnemonic: Export → Import → Verify
VERIFIED COMPETENCY MILESTONE
