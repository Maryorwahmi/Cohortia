Repeatable export checklist

Follow this sequence to reduce surprises after import.

1. Clean Scene
Delete unused objects or export Selected Objects only.
2. Apply Transforms
Ctrl + A: Location, Rotation, Scale.
3. Set Origin
Place the origin where the engine should use the pivot.
4. Normals
Recalculate with Shift + N and check Face Orientation.
5. Materials
Use Principled BSDF; pack or embed textures.
6. Modifiers
Apply or enable Apply Modifiers on export.
7. Export Settings
Set axes, scale, Path Mode, and embed textures as needed.
8. Test Import
Import into engine and verify scale, orientation, pivot, and materials.
9. Iterate
Adjust the relevant step and re-export until correct.
Key Takeaway

A concise, ordered checklist prevents repeated trial-and-error and speeds up your export workflow.
