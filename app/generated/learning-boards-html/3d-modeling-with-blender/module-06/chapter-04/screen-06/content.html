Definition

glTF formats and PBR materials

Know whether to export .glb or .gltf and how to preserve Principled materials for real-time use.

.glb
Single-file binary containing meshes and textures. Best for portability and web viewers.
.gltf
JSON file with separate binary and image files. Useful if you need to post-process textures separately.
Practical checklist
  • Choose .glb for single-file delivery; .gltf if you require external images.
  • Enable PBR Materials so Principled BSDF nodes map to glTF PBR workflow.
  • Pack or ensure image paths are correct before export to avoid missing textures.
Key Takeaway

For most web and runtime cases, .glb simplifies asset management and preserves PBR textures when exported correctly.
