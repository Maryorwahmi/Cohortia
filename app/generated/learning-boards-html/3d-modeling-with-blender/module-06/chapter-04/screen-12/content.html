Hands-on: Export SM_Crate_Wooden

Follow these exact steps to produce a Unity-friendly FBX of the prepared crate.

Preparation
  • Select SM_Crate_Wooden only.
  • Ctrl + A → Apply Location, Rotation, Scale.
  • Recalculate normals (Shift + N) and set origin at base if required.
Export settings
  • File → Export → FBX (.fbx)
  • Selected Objects: checked; Object Types: Mesh
  • Transform: Apply Scalings = FBX All; Forward = -Z; Up = Y
  • Geometry: Apply Modifiers if needed
  • Path Mode: Copy, Embed Textures: checked
After export
Import SM_Crate_Wooden.fbx into your engine and verify: 1) the crate faces upright and not rotated, 2) pivot is correct, 3) PBR textures look correct. If scale or orientation is off, adjust the scale factor or axes and re-export.
Key Takeaway

Follow a consistent prep and export sequence and test imports immediately to confirm asset fidelity.
