Troubleshooting

Fix the usual export failures

  • Missing textures: pack .blend or embed images during export.
  • Scale errors: verify unit settings and export scale; try example scale values and re-import.
  • Wrong orientation: adjust Forward/Up mapping to match the engine.
  • Shading artifacts: check normals and smoothing groups.
Practical debugging flow
  1. Export a simple textured cube and import it into the engine.
  2. If cube looks correct, focus on the model-specific steps (normals, modifiers, origin).
  3. Change one exporter option at a time and re-import to find the cause.
Key Takeaway

A systematic, one-change-at-a-time approach shortens debug time and reveals which specific setting causes the problem.
