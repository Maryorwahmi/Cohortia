Process Flow

Apply transforms and modifiers

Bake transforms and modifier results so the exporter writes the intended mesh geometry.

  1. Select your object and use Ctrl + A → All Transforms to apply location, rotation and scale.
  2. Decide whether modifiers should be permanent. If so, Apply them or enable Apply Modifiers during export.
  3. Re-check pivot and origin after applying transforms; adjust origin if needed before exporting.
Example
A mirrored table exported without applying Mirror shows half the geometry in the engine. Applying the modifier before export resolves the missing half.
Key Takeaway

Apply transforms to freeze scale/rotation and apply modifiers to bake geometry so the export matches your final model.
