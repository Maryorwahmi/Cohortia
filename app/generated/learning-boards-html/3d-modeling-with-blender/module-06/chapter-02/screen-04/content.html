Core Concept
Graph Editor Fundamentals
F-curves map frames to values so you can shape timing and spacing.
What to read:
  • Curve = property value over time; keyframes are control points.
  • Slope indicates velocity: steep = fast, flat = pause.
  • Handles control acceleration and deceleration between keys.
Concrete example
If a jump looks robotic, open Z-Location curve and lengthen handles at the apex to add ease-in and ease-out, creating a natural hang time.
Key Takeaway

Reading and shaping curve slopes gives you direct control over motion speed and feel.

Annotated F-curve view
Common mistake
Only moving keyframes in the Timeline without adjusting handles leaves motion speed unchanged between keys.
Pro tip
Isolate a single channel (Z-Location, for example) to focus on one physical dimension at a time.
