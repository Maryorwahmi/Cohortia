Comparison
Constant vs Linear vs Make Cyclic
Constant
Holds final value. Use when animation ends and you want a static result.
Linear
Continues the slope beyond keys. Useful for ongoing drift or projected motion.
Make Cyclic
Loops the curve for seamless repetition like a walk cycle or idle breath.
Practical examples
Camera hold
Use Constant after a final frame to keep framing locked for a cut-away shot.
Projectile motion
Use Linear to allow continued movement if the rest of the scene expects drift.
Walk cycles
Use Make Cyclic so stride frames repeat seamlessly in a game loop.
Mistake to avoid
Applying Linear when you intended a loop will cause cumulative drift and visual errors.
