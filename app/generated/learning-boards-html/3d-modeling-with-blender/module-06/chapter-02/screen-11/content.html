Definition
Animation Modifiers
Layer procedural effects onto F-curves to add variation or constraints.
Common modifiers:
  • Noise — adds random jitter for organic variation.
  • Limits — clamps values within a range to prevent extremes.
  • Envelope — reshapes curve amplitude across a region.
Practical tips
Camera shake
Add Noise to location channels and reduce strength for subtle handheld feel.
Flicker light
Use Noise on intensity curve with small scale for fast flicker.
Limit values
Apply Limits when exporting to engines that require safe bounds.
Performance note
Complex modifiers may affect runtime export or playback; test in target engine.
Try this

Add a Noise modifier to a camera location curve and tweak strength and scale. Observe motion with and without the modifier to compare.
