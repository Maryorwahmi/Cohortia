Module 6 › Chapter 6.2 › Pendulum Exercise
Hands-on Activity
Build a swinging pendulum
Steps
  1. Add pivot cube, rod with origin at top, and sphere weight.
  2. Parent weight → rod, then rod → pivot using Object (Keep Transform).
  3. Key rotate rod at frames 1, 20, 40 and play.
  4. Open Graph Editor, set interpolation to Bezier and lengthen horizontal handles at peaks.
Tip: extending horizontal handles at peaks creates hang time; shortening them around the midpoint increases swing speed through the bottom.
Guided refinement
Before
Linear keys create uniform speed; motion feels mechanical.
After
Bezier handles lengthened at peaks produce natural slowing and acceleration.
Optional modifier
Add subtle Noise to the weight for small, realistic jitter if desired.
Common error
Moving keys instead of handles changes timing but not the acceleration curve.
Key Takeaway

Combine parenting for structure and F-curve shaping for feel — both are required for believable motion.
