Core Concept
Simple armature workflow
Create bones, parent meshes to bones, and animate in Pose Mode for articulated movement.
Step-by-step:
  1. Add Armature → Single Bone.
  2. In Edit Mode duplicate and position bones to match parts.
  3. Select mesh, Shift+Select armature, enter Pose Mode, select bone, Ctrl+P → Bone.
  4. Animate in Pose Mode; mesh follows bone transforms.
Architecture diagram (conceptual)
Bone chain example:
Upper arm bone
Parents forearm bone; drives upper arm mesh.
Forearm bone
Child of upper arm; parents hand bone.
Hand bone
Drives the hand mesh or tool.
Misconception
Bone parenting whole objects is not the same as skinning for deformation. Use binding and weights for mesh deformation.
