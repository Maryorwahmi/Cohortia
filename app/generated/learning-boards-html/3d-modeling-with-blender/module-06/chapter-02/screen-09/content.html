Process Flow
Step-by-step parenting
  1. Select the child object you want to be driven.
  2. Shift+Select the parent object that will drive transforms.
  3. Press Ctrl+P and choose 'Object (Keep Transform)' to preserve pose.
  4. Test by transforming the parent; fix jumps by applying transforms or undoing parenting.
Debug tip
Create a helper empty at the child's origin and parent the child to it for safe offset edits and easier troubleshooting.
Troubleshooting checklist
  • Did a child jump after parenting? Check selection order and Apply Transforms.
  • Is a child not following? Confirm parenting link and object mode vs pose mode.
  • Need independent movement? Animate child local channels instead of parent channels.
Misconception
Parenting binds geometry for deformation. It does not skin a mesh; that requires armature parenting or weight painting.
Quick test
After parenting, rotate the parent 90 degrees; if children follow logically, hierarchy is correct.
