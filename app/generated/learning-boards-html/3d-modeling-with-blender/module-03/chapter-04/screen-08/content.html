Module 4 › Chapter 3.4 › Extruding & Beveling
Core controls
  • Extrude: pushes the curve along its normal to add thickness.
  • Bevel Depth: gives the curve a rounded cross-section.
  • Bevel Object: use a second curve to define a custom profile.
Practical tip
Use a small circle as a bevel object for uniform pipes; change the circle to alter cross-section without touching the path curve.
Concrete example
Create a curved rail: draw a profile circle, set it as Bevel Object on the path curve, and adjust resolution for a smooth result. Convert to mesh when you need polygon edits.
Common mistake
Too low resolution yields faceted results; too high resolution creates excessive polygons. Balance for the target platform.
Key takeaway
Bevel objects let you separate profile design from the path, enabling precise, repeatable cross-sections controlled independently of the path curve.
