Module 4 › Chapter 3.4 › Bezier Curves
How handles work
Each control point has handles that shape the tangent and strength of the curve at that point. Handle length affects curvature tightness; direction affects the tangent. Handle types like 'aligned' keep both handles colinear for smooth joins, while 'free' lets each handle move independently for sharper transitions.
Practical tip
Use automatic handles to get smooth flows quickly, then switch a point to aligned or free when you need precise control at a corner or junction.
Concrete example
Model a rope by placing four control points along the planned path. Set handles to aligned and tweak lengths to smooth the curve. Add a circle as a bevel object to give the rope a round cross-section.
Common mistake
Treating handles as final geometry. Handles influence interpolation only; they won’t become mesh vertices until you convert the curve and apply modifiers.
Key takeaway
Practice handle types and lengths; predictable handle use makes complex organic shapes quick and reliable to model.
