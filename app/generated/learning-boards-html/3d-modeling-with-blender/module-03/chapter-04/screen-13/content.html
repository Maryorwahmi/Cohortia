Core parameters
  • Count: explicit number of points along a curve.
  • Density: points per area for surface distributions.
  • Random Value: produces randomized numeric attributes for scale/rotation.
Practical tip
Combine Random Value with a Clamp or Map Range to keep variation within acceptable limits and avoid overlap at high densities.
Concrete example
On a path, set Count to 30 for posts, then add Random Value to scale between 0.95 and 1.1. If posts overlap, reduce Count or tighten the random range.
Common mistake
Increasing density without checking scale and collisions leads to clipping and unrealistic clusters. Use masks or collision avoidance logic when necessary.
Key takeaway
Control distribution and variation separately, then combine them with masks for precise, non-destructive adjustments.
