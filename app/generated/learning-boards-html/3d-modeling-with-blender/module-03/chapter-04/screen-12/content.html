Module 4 › Chapter 3.4 › Procedural Fence
Step-by-step (short)
1. Add Bezier Curve and shape the fence path.
2. Add a Cylinder and scale as a fence post.
3. Select curve → Geometry Nodes → New node tree.
4. Add: Curve to Points → Instance on Points; connect cylinder as instance.
5. Adjust Count on Curve to Points for spacing.
6. Add Random Value → connect to instance scale or rotation for variation.
7. Create rail with another curve; use Extrude or Bevel to give thickness.
8. Convert to mesh when satisfied and check topology.
This workflow keeps posts and rails editable through curve and node controls; tweak the count or random range to iterate quickly.
Concrete example
Use Count = 20 for moderate spacing, Random Value scale between 0.9 and 1.1 to avoid uniform posts, and set rail extrusion to visually connect posts without overlaps.
Common mistake
Not testing converted mesh early. Convert a copy and verify topology so you can adjust curve resolution before finalizing.
Key takeaway
This hands-on activity demonstrates how curves and nodes combine to create editable, procedural structures suitable for fast iteration.
