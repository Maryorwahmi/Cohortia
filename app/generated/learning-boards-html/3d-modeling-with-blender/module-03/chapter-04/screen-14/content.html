Module 4 › Chapter 3.4 › Best Practices
Node hygiene
  • Group nodes into named frames for clarity.
  • Label important parameters and leave short comments.
  • Keep source meshes simple and with applied scale and origin.
Export checklist
Duplicate your procedural object and convert the copy to mesh. Check normals, topology, and UVs before export. Test the exported file in the target environment.
Concrete example
Add frames named 'points', 'instances', and 'variation'. Save a blend with both the procedural and converted mesh so you can iterate and revert easily.
Common mistake
Converting the only copy and losing the procedural graph. Always keep an editable source to avoid rework.
Key takeaway
Organized node trees and a disciplined export checklist reduce surprises and make collaboration easier when handing assets to other team members.
