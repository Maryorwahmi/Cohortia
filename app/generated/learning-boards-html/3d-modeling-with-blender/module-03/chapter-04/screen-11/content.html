Module 4 › Chapter 3.4 › Essential Node Chain
Node sequence
Group Input (Geometry)
  → Distribute Points on Faces / Curve to Points
  → Random Value (scale, rotation)
  → Instance on Points (Instance: your mesh)
  → Group Output (Geometry)
This sequence generates points, randomizes attributes, places instances, and returns the final geometry. Use attribute fields to connect random values to scale or rotation slots.
Concrete example
On a plane, distribute 800 points, instance a rock mesh, randomize scale between 0.7 and 1.2, and rotate slightly on the Z axis to break repetition.
Common mistake
Expecting unique mesh data per instance. Instances reference a single source mesh; change the source to update all instances, or convert instances to real geometry if you need unique meshes per object.
Key takeaway
This simple chain is highly reusable — once comfortable, you can layer more logic like attribute masks, collision avoidance, or falloff controls.
