Module 4 › Chapter 3.4 › Curves as Paths
One-sentence recipe
Create a curve, add a Follow Path constraint to an object, and animate the evaluation time to move the object along the curve. Use axis options to correct orientation.
Step highlights
  • Create a Bezier curve and shape it to the required path.
  • Add a Follow Path constraint or use the path animation option on the object.
  • Adjust axis and up-vector settings to align orientation; use an additional constraint if necessary.
Concrete example
Animate a camera along a curved rail by applying a Follow Path constraint and keyframing the offset or evaluation time for smooth cinematic motion.
Common mistake
Forgetting to correct the forward/up axis. If objects twist or face the wrong way, add a track constraint or adjust the axis inside the path settings.
Key takeaway
Curves let you control motion and placement predictably; use them to keep animated paths and instanced placements editable and precise.
