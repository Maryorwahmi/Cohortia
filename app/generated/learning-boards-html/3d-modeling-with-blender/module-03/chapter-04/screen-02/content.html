Learning Objectives
These objectives map to practice milestones so you can test your skills as you go.
01
Differentiate Bezier vs NURBS
Explain the control handles and practical uses of each curve type for artistic versus technical models. Verified competency milestone: identify a use case and justify the curve choice.
02
Create 3D geometry from curves
Use extrude, bevel depth, or a bevel object to add volume. Milestone: create a pipe or rail with a circular profile using bevel depth or a circle as a profile.
03
Convert curves to mesh for export
Understand why game engines need mesh data and how to perform a safe conversion. Milestone: convert a curve object and verify normals and topology before export.
04
Build basic Geometry Nodes setups
Scatter and vary instances with distribute points and random value nodes. Milestone: create a node tree that places fence posts along a curve with size variation.
