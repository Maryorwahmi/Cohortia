Architecture

Snapping settings

Set Snap Target to Face and enable Project Individual Elements to snap new vertices onto the sculpt surface during creation.

Why Face projection?
Faces provide accurate surface projection for new vertices instead of snapping to existing vertices or edges.
Project Individual Elements
Enables each extruded element to be projected separately rather than as a group, avoiding intersection errors.
Architecture

Shrinkwrap configuration

Add Shrinkwrap to the low-poly object, set Target to the high-poly sculpt, Mode to Project, and enable both axes for two-sided projection.

Project Mode
Projects vertices along a chosen axis to the target surface; use with care near thin geometry.
Enable both axes
Checking Negative and Positive lets projection approach from both sides, avoiding missed projection on complex regions.
Common Mistake

Forgetting Shrinkwrap or using Auto-merge can leave vertices slightly offset, causing errors in normal map baking and UV seams.
