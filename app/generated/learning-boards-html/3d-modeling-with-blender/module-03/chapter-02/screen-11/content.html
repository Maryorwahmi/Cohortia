Retopology Lab: step sequence

Complete these tasks in your Blender file to retopologize a simple head sculpt.

Starter
# In Blender (conceptual steps shown)
Add Plane → Scale → Move in front of sculpt
Edit Mode: Delete 3 verts → Place single vert on nose bridge
Snapping
Enable Snapping → Target: Face → Project Individual Elements ON
Extrude with Ctrl+right-click to place vertices that adhere to the sculpt surface.
Shrinkwrap
Object Mode → Add Shrinkwrap modifier → Target = high-poly sculpt → Mode = Project → Enable Negative & Positive axes
Verify
Check even quads, remove pinches, and bake a quick normal map to validate detail transfer.
Common Pitfall
Skipping loop planning results in poor deformation even if the mesh sits perfectly on the sculpt.
