Step-by-step Retopology

A concise lab plan to build a low-poly mesh that tightly follows a sculpted head.

1. Preparation
Make the high-poly visible, add a Plane, scale down, position it in front of the sculpt.
2. Start with one vertex
In Edit Mode, delete three vertices, move the remaining vertex to a feature like the nose bridge to anchor your loops.
3. Enable snapping
Turn on Snapping, set to Face, and enable Project Individual Elements so created vertices stick to the sculpt surface.
4. Extrude and build loops
Use Ctrl + right-click to extrude and trace edge loops that follow eyes, mouth, and joint contours.
5. Apply Shrinkwrap
Add Shrinkwrap to the low-poly, set Target to the sculpt, Mode to Project, and enable Positive and Negative axes.
6. Refine and check
Even out quad distribution and correct pinching before baking normals and unwrapping UVs.
Common mistake
Building loops without planning deformation leads to poor animation results; always design loops around joints and facial features.
