Module 3 › Chapter 3.3 › Troubleshooting Shading and Topology
Problem → Fix
Odd highlights or faceting
Recalculate normals, add small bevels, or insert support loops to improve edge flow.
N‑gons after Boolean
If you must apply, retopologize into quads or add edge loops; otherwise keep Boolean live and adjust cutters.
Scale or non‑manifold geometry
Apply scale and ensure cutters are manifold; non‑manifold meshes produce unpredictable Boolean results.
Quick Check

Disable modifiers one at a time to see which introduces artifacts, then focus fixes on that stage.

Clean‑up Strategy
1) Isolate modifier causing issue. 2) If Boolean, try adjusting cutter, apply scale, or repair topology. 3) Use minor bevels/support loops to mask small shading problems. 4) Apply only when necessary.
Remember: applying modifiers commits topology — plan clean‑up before applying.
