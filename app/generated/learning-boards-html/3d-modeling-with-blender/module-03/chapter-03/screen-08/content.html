Module 3 › Chapter 3.3 › Mirror and Array: Time‑saving Symmetry and Repetition
Architecture
Origins, clipping, offsets, and patterns

Place object origin on the symmetry axis before using Mirror. Use clipping to prevent vertices crossing the plane. For Array, set relative offsets or constant distances and combine with rotation for radial patterns.

Example
Create a corner bolt, add Array to duplicate along an edge, then Boolean the main crate to create bolt indentations.
Misconception
Mirroring after Booleans can duplicate cutter artifacts; plan whether to mirror early or mirror later depending on the desired effect.
Key Takeaway

Set origins and offsets deliberately to make mirrored and arrayed details behave predictably with later modifiers.

Step Cards
1. Position origin on axis; enable Mirror clipping.
2. Model half, check seam, adjust vertex positions.
3. Create a detail object, add Array, set offset to desired spacing.
4. Combine Arrayed objects as Boolean cutters if you need patterned cutouts.
