Learning Objectives

Develop modifier skills you can use repeatedly in hard‑surface projects.

01
Non‑destructive Workflow
Use modifiers so operations remain editable and reversible. This preserves iteration speed when designs change.
Mnemonic: overlapping transparent layers
VERIFIED COMPETENCY MILESTONE
02
Boolean Operations
Perform union, intersect, and difference with separate cutter objects for precise cutouts that remain adjustable.
Mnemonic: cutter object sits next to target
VERIFIED COMPETENCY MILESTONE
03
Bevel Control
Add realistic edge chamfers with amount, segments, and limit method to avoid shading artifacts and control highlights.
Mnemonic: soft edge band
VERIFIED COMPETENCY MILESTONE
04
Subdivision & Support Loops
Use Subdivision Surface with nearby control loops to sharpen edges while keeping smooth surfaces.
Mnemonic: pinch loops near edges
