Module 3 › Chapter 3.3 › Sci‑Fi Crate — Arrays, Details, Subdivision
Steps
Create detail object → Array it → Use Arrayed objects as Boolean cutters → Add Subdivision and support loops.
Example: array a corner rivet along an edge and use difference to engrave multiple holes in one modifier operation.
Tip: use relative offset or constant offset parameters to mathematically place repeated items.
Key Takeaway

Arrays plus Booleans make patterned details efficient; add subdivision only where smoothness is needed and control edges with support loops.

Scenario Card
You need ten vents along a panel. Model one vent, array it with the proper offset, then use the array as a Boolean cutter — all vents update by changing the single source object.
Consider polygon budget: use baked normals instead of subdivision when targeting low‑poly engines.
Document applied modifiers and why you applied them before final export.
