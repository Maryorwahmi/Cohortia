Module 3 › Chapter 3.3 › Sci‑Fi Crate — Setup and Mirror
Steps
  1. Start with default cube; reset transforms if needed.
  2. Place origin on symmetry axis.
  3. Add Mirror modifier and enable Clipping.
  4. Delete half the cube in Edit Mode to rely on the Mirror.
Tip: Keep base geometry low‑poly and quad‑based so later modifiers behave predictably.
Key Takeaway

Set up symmetry and origins first so all future edits mirror cleanly and reduce duplicated effort.

Scenario Card
Imagine the crate needs a centered latch and mirrored vent panels. By mirroring early, you only position the latch once and both sides update automatically.
Avoid scaling non‑uniformly before adding modifiers.
Model detail objects separately for later Array or Boolean use.
