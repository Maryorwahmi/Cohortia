Dyntopo explained

Dyntopo dynamically adds or removes triangles while sculpting so geometry is created where brush strokes demand it. This removes the need to pre-subdivide a mesh.

Detail Size: governs triangle scale. Start coarse for blocking, reduce for fine work.
Performance: smaller detail increases polycount. Monitor the status bar to avoid slowdowns.
Misconception: Dyntopo will always create perfect topology; it creates useful geometry for sculpting but not production topology for deformation—retopologize when required.
Key Takeaway

Use Dyntopo to sculpt forms from simple bases, but scale detail consciously to balance visual quality and performance.

Quick Dyntopo checklist
  • Activate Dyntopo from the Sculpt header.
  • Set Detail Size for current stage: coarse → medium → fine.
  • Use larger brushes for silhouette, small brushes for detail.
  • Watch polycount in Blender’s status bar.
Concrete example
Start with a sphere. Enable Dyntopo and set Detail Size to around 10–15 for rough blocking. Pull volumes with Draw, then reduce Detail Size for cracks and fine surface variation.
Common mistake
Choosing a small Detail Size at the beginning creates dense meshes before primary structure is finished. Begin coarse and refine.
