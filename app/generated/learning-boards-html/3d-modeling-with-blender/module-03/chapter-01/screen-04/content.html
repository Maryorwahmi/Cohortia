Module 3 › Chapter 3.1 › What is Sculpt Mode?
Core idea

Sculpt Mode gives you brushes that behave like clay tools. Use broad strokes to shape silhouette then refine planes and surface detail.

Analogy: Digital clay — push and pull mass rather than moving vertices.
When to use: character heads, creatures, rocks, and natural shapes where organic flow matters.
Misconception: You do not need a high-poly base if you use Dyntopo; start simple and let topology follow form.
Key Takeaway

Sculpt Mode prioritizes visual form and silhouette. Use it to iterate shape quickly before fixing topology for production.

Sculpting example: creature head
Start with a sphere. Use large Draw or Clay Strips to block the skull and jaw. Reduce brush size to carve cheek and brow planes. Smooth frequently to blend planes before adding fine detail.
Checklist: Getting started
  • Switch to Sculpting workspace.
  • Choose a brush and set an appropriate size.
  • Enable Dyntopo if you need adaptive topology.
  • Work large-to-small: silhouette → planes → fine detail.
