Module 3 › Chapter 3.1 › Mesh Density
Why density matters

High triangle counts slow viewport responsiveness and increase runtime cost in games. Dyntopo can generate dense geometry quickly if uncontrolled.

Practical rule: larger Dyntopo detail for blocking; progressively reduce for targeted fine work.
Measure: use Blender’s status bar to track polycount and pause to simplify if counts spike.
Key Takeaway

Balance local detail with overall performance. Bake micro-detail into textures when mesh density is not feasible.

Comparison
Dense mesh: true vertex detail but costlier. Normal map: cheaper at runtime but needs clean topology for baking.
Concrete tip
If polycount spikes, increase Dyntopo Detail Size slightly and smooth the area to reduce subdivisions, then continue refining selectively.
Misconception
More triangles do not always mean better visual fidelity. Strategic detail placement matters more than uniform density.
