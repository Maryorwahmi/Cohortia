Module 3 › Chapter 3.1 › Sculpt → Game Asset
Pipeline overview

Sculpt high-frequency detail on a high-poly mesh, then retopologize or bake detail into normal maps for a low-poly game model. Sculpting captures visual data; optimization makes it usable in production.

Retopology: create clean, deformable geometry for animation and efficient shading.
Baking: transfer surface detail into textures such as normal and displacement maps.
Key Takeaway

Sculpt for appearance and form; plan retopology and baking to preserve fidelity while meeting runtime budgets.

Concrete scenario
Sculpt a head; bake pores and small wrinkles into normal maps; retopologize the base mesh for mouth and eyelids to animate correctly.
Performance note
Target specific density in deformation areas and use texture baking for micro-detail to keep polygon budgets reasonable.
Misconception
High-poly sculpt is rarely final geometry in game pipelines; it’s a visual reference to be optimized.
