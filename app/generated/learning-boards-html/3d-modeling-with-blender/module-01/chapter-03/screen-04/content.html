What is a primitive?
A mesh generated with preset topology and adjustable parameters, used as a starting shape for modeling.
Cube
Simple six-faced block ideal for blocking volumes.
UV Sphere
Segments and rings control smoothness and polycount.
Cylinder
Vertices determine roundness; useful for limbs, columns, pipes.
Key Takeaway

Primitives are inexpensive starting points. Keep resolutions low for blocking and performance-sensitive work.

Concrete example
Create a UV Sphere with 16 segments and 8 rings to block a low-poly ball, then raise segments when you need smoother shading for presentation renders.
Common mistake
Using default high-resolution primitives for blocking leads to wasted polygons and longer edit times. Adjust parameters early using the redo panel.
