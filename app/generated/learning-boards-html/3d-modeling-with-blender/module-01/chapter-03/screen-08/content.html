Core Action › Delete objects
How to delete safely
Select, press Delete or X, then confirm the prompt. Use save and collections to guard against accidental loss.
Quick checklist
  • Confirm exactly which objects are selected.
  • Save (Ctrl+S) before major deletions.
  • Consider hiding into a collection instead of deleting if unsure.
Key Takeaway

Use confirmation and saving to prevent accidental loss, and prefer collection hiding when unsure.

Concrete scenario
Before deleting many props, create a 'Backup' collection and move items there. If you need them back, toggle visibility rather than recreate them.
