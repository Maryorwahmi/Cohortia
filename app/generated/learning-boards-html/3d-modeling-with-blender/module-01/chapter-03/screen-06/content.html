Definition › 3D Cursor
What the 3D Cursor does
It defines spawn location for newly added objects, enabling precise placement without extra translation steps.
Practical tip
Move the cursor before adding to place an object exactly where you need it for blocking or alignment.
Example
Set cursor at the center of a doorway, then add a cylinder to place a column without manual movement.
Key Takeaway

Using the 3D Cursor for precise spawn placement removes redundant transforms and speeds up blocking tasks.

Common misconception
New objects always appear at origin. In fact, they spawn at the 3D Cursor, which may be anywhere in the scene.
Check your understanding
Try moving the 3D Cursor to a corner and adding a plane. Did it appear at the cursor location? If not, what step might you have missed?
