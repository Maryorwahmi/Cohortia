Step-by-step walkthrough
Follow these steps in Blender to practice all chapter skills in one short flow.
  1. Delete the default cube: select it, press X, then Delete to confirm.
  2. Add a UV Sphere: Shift+A > Mesh > UV Sphere. In the Add panel set Segments = 16, Rings = 8.
  3. Add a Cylinder: Shift+A > Mesh > Cylinder. Set Vertices = 12 and Radius = 0.5 in the Add panel.
  4. Add a Plane: Shift+A > Mesh > Plane. Select it and press S then 10 then Enter to scale.
  5. Position objects: select sphere, press G then Z and move it to sit on the plane; repeat for cylinder.
  6. Practice Undo/Redo: move the sphere, then press Ctrl+Z to undo and Shift+Ctrl+Z to redo.
  7. Create collections: in the Outliner, right-click and choose New Collection. Name one 'Ground' and one 'Props'.
  8. Move objects into collections: select the Plane, press M and choose 'Ground'; select sphere and cylinder, press M and choose 'Props'.
Key Takeaway

This flow ties adding, adjusting, deleting, undoing, and organizing into a repeatable practice for efficient modeling.

Quick tips
  • Always inspect the Add panel before performing another action.
  • Use collections to hide groups while you focus on others.
  • Save before big deletions to create a fallback.
Reflection
