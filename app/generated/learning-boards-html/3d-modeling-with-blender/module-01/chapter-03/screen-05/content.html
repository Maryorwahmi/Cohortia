Process Flow › Add primitives
Two ways to add
Use the top Add menu or the Shift+A hotkey radial menu for faster placement.
Top Add menu
Discoverable and explicit: Add > Mesh > Cube.
Shift+A radial
Fast radial menu under cursor for quick blocking.
Mini procedure
  1. Position the 3D Cursor where you want the object to appear.
  2. Press Shift+A for the radial menu and pick Mesh > Cube (or use Add > Mesh).
  3. Check the Adjust Last Operation panel to tweak parameters immediately.
Concrete example
Place the 3D Cursor at a doorway and use Shift+A to instantly add a prop at that location. No later move needed.
Common mistake
Assuming new objects always appear at origin. If the cursor moved, your object will spawn at the cursor instead.
Try this
Practice adding three primitives with Shift+A while keeping the 3D Cursor in a fixed spot to see consistent placement.
