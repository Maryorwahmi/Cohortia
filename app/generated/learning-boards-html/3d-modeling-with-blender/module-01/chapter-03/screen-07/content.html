Process Flow › Adjust Last Operation
Use the redo panel right after adding
The panel is temporary and controls parameters like segments, rings, vertices, radius and size.
Step-by-step
  1. Add a primitive with Shift+A or Add > Mesh.
  2. Immediately look for the Add ... panel in the bottom-left (Adjust Last Operation).
  3. Change segments, rings, vertices, radius, or other fields as needed.
  4. Click in the viewport or perform another action to finalize the values.
Example
Add a UV Sphere, set segments to 16 and rings to 8 to reduce polygon count for a low-poly game asset.
Common mistake
Waiting until after other edits to change resolution forces a rebuild or extra edits later.
Key Takeaway

Set mesh resolution during creation via the Adjust Last Operation panel to save time and control performance.

Visual cue
Look for the small panel labeled Add <Primitive> in the bottom-left right after creation.
