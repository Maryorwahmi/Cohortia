Module 1 › Chapter 1.1 › Activity: Explore the Default Scene
Guided practice
Steps
  1. Select the Cube and press Numpad period to frame.
  2. Orbit with MMB, keeping the cube centered.
  3. Pan with Shift+MMB and reposition the view.
  4. Zoom with Wheel and with Ctrl+MMB for precision.
  5. Click the View Gizmo to snap orthographic.
  6. Press N to open the Sidebar and read coordinates.
  7. Cycle shading modes to inspect topology and materials.
Practice tips
  • Repeat the sequence three times to build motor memory.
  • Always frame the object before long orbiting sessions.
  • Use Material Preview when checking textures; use Rendered only for final validation.
Mini-challenge
Without using keyboard labels, center the cube, snap to right orthographic with the View Gizmo, and enter an exact X coordinate in the N-panel. This proves precision control.
