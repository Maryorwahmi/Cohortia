Module 1 › Chapter 1.1 › The N-panel (Sidebar) for Precision
What the N-panel contains
Location, rotation, scale, and tool options for the selected object. It’s editable, so you can type exact values to place objects with numerical precision.
Use case
Set exact coordinates when assets must match a grid or meet game-engine constraints.
Practical tip
After moving an object, open N and copy the numeric values before duplicating—this avoids small drift errors.
Example
Place a prop at exact coordinates for a game level by typing the values into the N-panel, ensuring consistent alignment across assets.
Key Takeaway

Use the N-panel to make numerical edits that provide repeatable, accurate placement for modeling and export.
