Practical Checks for Practice
Interface
Name the Viewport and two adjacent panels. Open the Outliner to find objects.
Navigation
Select the cube and press period on the Numpad to frame it, then orbit smoothly using MMB.
Shading
Cycle shading modes and explain one reason to use each mode during modeling.
Mini checklist
  1. Select object → press Numpad period to frame.
  2. Orbit with MMB; pan with Shift+MMB; zoom with wheel.
  3. Open N-panel and read location values.
Verification tip
If you accidentally lose the object, press Home to frame all or use Shift+C then select and frame.
