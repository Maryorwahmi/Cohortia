Snap Types

Pick the right snap for the job

  • Increment: snap to grid steps for consistent spacing.
  • Vertex: align to vertices for exact joins.
  • Edge / Face: place objects flush against surfaces.
Workflow Note

Turn snapping on when you need it, and use Ctrl during a transform for a one-off snap without changing the persistent state.

Example

When connecting modular walls, enable Vertex snapping so corners lock together precisely, preventing gaps that can break collision in a game engine.

Key Takeaway

Choose the snap target that matches the alignment task and toggle snapping deliberately to avoid unexpected jumps.

Check

If objects jump while transforming, verify whether snapping is on and which snap type is selected.
