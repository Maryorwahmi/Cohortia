Hotkeys Cheat Sheet
Movement
G: Grab/Move · G then X/Y/Z to constrain
Rotate
R: Rotate · R then X/Y/Z for axis
Scale
S: Scale · S then axis for one-axis
Selection
Left-click, Shift+Left-click, A, Alt+A, Box/Circle/Lasso
Cursor & Origin
Shift+Right-click to move cursor · Shift+S to reset · Object > Set Origin
Snapping
Magnet icon or hold Ctrl during transform; choose Increment or Vertex as needed
Practice Checklist
  1. Select the Cube and confirm the orange outline.
  2. Move with G then X/Y/Z, rotate with R then an axis, scale with S.
  3. Place the 3D Cursor and set origin, then test rotation pivot.
  4. Enable snapping and test Increment and Vertex modes.
