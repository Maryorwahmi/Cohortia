Learning Objectives

Skill goals that prepare you for modeling and game-ready asset placement.

Bloom: Learn → Understand → Apply → Master
01
Select single & multiple objects

Learn click, Shift-click, A and deselect to manage selections quickly. This matters for grouping and editing assets efficiently.

VERIFIED COMPETENCY MILESTONE
02
Understand the 3D Cursor

Move the cursor with Shift+Right-click and use it to place new objects or as a transformation pivot for precision workflows.

VERIFIED COMPETENCY MILESTONE
03
Use Move, Rotate, Scale tools

Operate transformations with gizmos or G, R, S hotkeys and apply axis constraints for accurate edits.

VERIFIED COMPETENCY MILESTONE
04
Set origin & use snapping

Place origin for predictable pivot behavior and enable vertex or grid snapping to align pieces precisely.

VERIFIED COMPETENCY MILESTONE
