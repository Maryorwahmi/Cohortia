Rotate Mechanics

R hotkey and gizmo circles

  • Press R to rotate. Use colored circles to rotate around specific axes.
  • The outer white circle rotates relative to the view plane for intuitive adjustments.
  • Rotation always occurs around the object's origin; set it deliberately for correct behavior.
Common Mistake

Rotating before adjusting the origin leads to unexpected motion. If rotation looks wrong, check the origin position first.

Example

For a hinged door, move the 3D Cursor to the hinge, set origin to cursor, then press R and rotate about the correct pivot so the door swings naturally.

Key Takeaway

Set the origin before rotating to make the motion predictable and suited to the object's function.

Check

If rotation seems strange, ask: where is the origin located relative to the geometry?
