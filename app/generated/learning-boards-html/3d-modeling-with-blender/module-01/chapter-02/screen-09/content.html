Scaling Modes

Uniform and axis-specific scaling

  • Press S to scale uniformly. Drag to resize proportionally.
  • Press S then X/Y/Z to restrict scaling to an axis. Use Shift+Axis to exclude an axis.
  • Gizmo cubes indicate axis handles; the center circle is uniform scale.
Common Mistake

Non-uniform scaling can distort UVs and create issues in game physics. Reset scale or apply transforms when needed before export.

Example

Scale a crate uniformly with S to keep textures consistent. If you stretch only X, the wood grain will look distorted and may tile oddly in a game engine.

Key Takeaway

Prefer uniform scaling for assets; use axis scaling only when you intend to alter proportions for design reasons.

Pro Tip

If you must non-uniform scale, consider applying scale transforms before exporting so downstream tools receive uniform transforms.
