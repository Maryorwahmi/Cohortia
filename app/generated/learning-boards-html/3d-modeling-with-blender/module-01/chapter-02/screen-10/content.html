What is the Origin?

Pivot that controls transforms

The origin is a pivot point. Use Object > Set Origin to move it to the 3D Cursor or to the geometry. It determines where rotations and scales occur.

Usage

Place the origin to match functional parts of the model, such as hinges or attachment points, for correct behavior in animation or game logic.

Example

After moving a lamp model away from origin, use Object > Set Origin > Origin to Geometry to center the pivot at the lamp's visual center for symmetric rotations.

Key Takeaway

The origin does not move geometry by itself; it controls the center for transforms. Set it intentionally for predictable results.

Try this

Move the 3D Cursor to a hinge point, then set Origin to 3D Cursor and rotate to confirm hinge behavior.
