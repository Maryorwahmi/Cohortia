Selection Tools

Add, All, and Visual Selection

  • Shift + Left-click: Add objects to selection one by one.
  • A: Select all. Alt + A: Deselect all.
  • Box Select: Drag to select by rectangle; Circle Select (C): paint select; Lasso: freehand region.
Misconception

These tools select object origins, not visible pixels; overlapping objects can hide origins. Orbit the view if selection seems wrong.

Example

To move all props in a room, use Box Select to capture them, then press G to move the group while maintaining layout relationships.

Key Takeaway

Combine additive clicks with region tools to select exactly the objects you need in complex scenes.

Try this

Use Circle Select to quickly collect scattered props, then deselect any extras with Shift-click.
