Definition

Selecting objects with Left-click

Selection marks which object will receive edits. The orange outline shows the active selection and ensures transformations apply to the intended target.

Quick checks
  • Left-click to select. Orange outline appears.
  • Click empty space or press Alt+A to deselect all.
  • Use Preferences if you prefer right-click selection.
Common Mistake

Confusing selection contexts: selecting in Object Mode differs from Edit Mode vertex selections. Confirm the mode before editing.

Example Scenario

You imported a character and want to move only a hat. Left-click the hat, confirm the orange outline, then use Move. If the outline is missing, transformations will affect the wrong object.

Key Takeaway

Always confirm selection visually before performing transforms to avoid accidental edits.
