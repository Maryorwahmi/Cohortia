Practice & Assessment Milestones

Concrete checks to ensure each objective is met during the lab.

Checklist: Select → Cursor → Transform → Snap
Selection Verification
  • Confirm orange outline on selected object.
  • Use A to select all and Alt+A to deselect all.
  • Collect groups using Shift+Left-click and Box Select.
VERIFIED COMPETENCY MILESTONE
Cursor & Origin Checks
  • Move cursor with Shift+Right-click and reset with Shift+S.
  • Set origin to 3D Cursor and rotate to confirm pivot behavior.
VERIFIED COMPETENCY MILESTONE
Transform Accuracy
  • G, R, S with axis constraints (G then X/Y/Z) for precision.
  • Use gizmo arrows or circles for visual control when needed.
VERIFIED COMPETENCY MILESTONE
Snapping Practice
  • Enable the magnet for Increment snapping and test vertex snapping for exact joins.
  • Hold Ctrl while transforming to temporarily enable snapping.
VERIFIED COMPETENCY MILESTONE
