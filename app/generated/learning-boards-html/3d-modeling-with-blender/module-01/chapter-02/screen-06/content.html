What is the 3D Cursor?

Placement and pivot control

Move the cursor with Shift+Right-click. Reset with Shift+S → Cursor to World Origin. New objects appear at the cursor and you can set an origin to the cursor for pivoted transforms.

Practical Use

Place the cursor at a hinge point, set origin to cursor, then rotate the object to behave like a real hinge.

Example

To create a lamp at a precise spot, move the cursor to that spot and add the lamp; it appears exactly where you placed the cursor.

Key Takeaway

Use the cursor to control where things are created and to define non-standard pivots for predictable transforms.

Common Mistake

Assuming the cursor selects objects. It only sets positions and potential pivot points.
