Module 4 › Chapter 4.3 › Crate lab
Step sequence
  1. Add Cube and apply transforms (Ctrl + A > Scale/Rotation).
  2. Enter Edit Mode, Edge Select: mark top and bottom face loops and one vertical back seam (Ctrl + E > Mark Seam).
  3. Select all faces and press U > Unwrap.
  4. In UV Editor, arrange six rectangular islands inside 0‑1 and check stretch with overlay.
  5. Assign a grid texture in Shader Editor and connect UV coordinates to test alignment.
Example command list
Object Mode: Ctrl + A > Scale
Edit Mode: Tab
Mark Seams: Edge select > Ctrl + E > Mark Seam
Unwrap: A > U > Unwrap
UV transforms: G, R, S
Test texture: use grid image via Image Texture node
Key Takeaway
Iterate: mark seams, unwrap, check stretch, and refine until islands are paintable and distortion‑free.
