Preparation steps
A reliable unwrap follows a short checklist to avoid distortion and surprises.
  1. Apply Scale and Rotation in Object Mode (Ctrl + A > Scale / Rotation).
  2. Enter Edit Mode (Tab) and switch a pane to UV Editor.
  3. Select faces or edges you plan to unwrap and preview in the UV Editor.
  4. Use Display Stretch to detect where seams or different methods are needed.
Common mistake

Not applying scale causes unpredictable island sizing and hidden stretching after unwrap.

Quick reference
Apply transforms: Ctrl + A > Scale / Rotation
Enter Edit Mode: Tab
Open UV Editor: change a window to "UV Editor"
Unwrap menu: U > choose method
Key Takeaway
Preparation reduces trial and error. Always fix transforms and preview UVs before committing to seams.
