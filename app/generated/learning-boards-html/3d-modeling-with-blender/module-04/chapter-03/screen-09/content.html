Module 4 › Chapter 4.3 › Common issues
Problem → Diagnosis → Fix
Stretching
Diagnose with Display Stretch; fix by adding seams or redistributing UV area to match surface area.
Overlapping UVs
Diagnose by selecting islands and checking for stacked outlines; fix by moving or repacking islands or intentionally mirror only where suitable.
Too many seams
Diagnose when islands are highly fragmented; fix by removing seams on visible faces and rejoining islands for painting convenience.
Unapplied transforms
Apply Scale/Rotation in Object Mode before unwrapping to prevent unexpected island scaling.
Quick check
Run the stretch overlay, inspect the 0‑1 packing, and confirm texel density with a grid texture to identify issues quickly.
