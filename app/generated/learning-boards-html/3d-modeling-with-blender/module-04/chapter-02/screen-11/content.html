Module 04 › Chapter 4.2 › Roughness maps & Color Space
Data maps need Non-Color
Roughness maps are numeric; do not color-manage them.
Steps

Add Image Texture → Open roughness image → set Color Space to Non-Color → connect Color → Principled Roughness.

Why it matters

Non-Color prevents color management from changing pixel values, ensuring predictable material response to light.

Example outcome

When correctly set to Non-Color, your roughness map produces stable highlights and reflections across the model.

Key Takeaway

Treat maps containing numeric data as Non-Color to avoid incorrect shading due to color management.
