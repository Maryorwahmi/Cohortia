Module 04 › Chapter 4.2 › Texture Coordinate → Mapping → Image Texture
Chain nodes to control placement
Step 1

Add Texture Coordinate node and choose an output (Generated, Object, or UV).

Step 2

Add Mapping node and connect the Texture Coordinate output to Mapping Vector.

Step 3

Connect Mapping Vector → Image Texture Vector so transforms affect sampling.

Example

Set Mapping Scale X:2 Y:2 to make the wood grain repeat twice across the face, increasing tiling without changing geometry.

Key Takeaway

Mapping transforms coordinates before sampling, enabling translation, rotation, and scale of textures independent of the mesh.

Troubleshoot
  • If Mapping seems ignored, confirm the Vector input of Image Texture is connected.
  • Mapping does not change UVs; it only transforms coordinates passed to the texture.
