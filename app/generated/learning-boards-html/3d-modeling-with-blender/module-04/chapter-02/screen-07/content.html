Generated • Object • UV
When to use each coordinate type
Generated

Auto coordinates from the object's bounding box. Fast for tests and procedural textures, but prone to stretching on irregular shapes.

Object

Uses the object's local space. More consistent when scale is applied; good for projection effects and some procedural setups.

UV

A manual 2D map you unwrap for precise control. Essential for game assets, atlasing, and avoiding any stretching.

Practical note

Use Generated/Object for quick iterations. For final game assets, plan and create UVs to control texture placement precisely.
