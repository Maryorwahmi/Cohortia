Module 04 › Chapter 4.2 › Loading an Image Texture
Add and connect Image Texture
# Node steps (visual equivalent in Shader Editor)
1. Add → Texture → Image Texture
2. Click Open and choose wood.png
3. Connect Image Texture Color → Principled BSDF Base Color
4. If needed: Image Texture Alpha → Principled BSDF Alpha
5. If using Alpha: set Material Settings → Blend Mode to Alpha Hashed or Alpha Blend
Concrete example

Load a wood grain PNG and connect Color. The crate will show grain and color; connect Alpha for sticker cutouts.

Common mistake

If transparency appears black, check both the Alpha connection and the material's Blend Mode setting.

Visual check

Preview in Material Preview mode and toggle the Alpha connection to verify transparency behaves as expected.

Key Takeaway

Loading and connecting an Image Texture immediately affects appearance; Alpha needs a blend mode to render correctly.
