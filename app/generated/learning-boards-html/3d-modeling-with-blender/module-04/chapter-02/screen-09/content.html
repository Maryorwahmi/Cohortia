Module 04 › Chapter 4.2 › Texturing a crate
Hands-on: crate texturing
Step 1 — Prepare mesh

Add Cube, scale Z to 0.8 to form a crate shape, add a new material in the Shader Editor.

Step 2 — Add Image Texture

Add Image Texture, Open wood image, connect Color → Base Color. Preview updates in Material Preview.

Step 3 — Add Mapping

Add Texture Coordinate and Mapping. Connect Object → Mapping → Image Texture Vector. Set Scale X:2 Y:2 Z:2 to tile.

Step 4 — Roughness map

Add second Image Texture as Roughness, set Color Space to Non-Color, and connect to Principled Roughness for realistic shading.

Example result

A low-poly crate rendered with a wood color texture and a roughness map will show believable surface detail and correct light response without adding polygons.

Key Takeaway

Follow the node chain and set image color spaces correctly to get both color and material response right in one material.
