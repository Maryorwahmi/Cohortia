Color and Alpha explained
Color output

Provides RGB pattern and color. Connect to Base Color to paint the surface.

Alpha output

Provides transparency information. For correct display, connect to Alpha and set Material Blend Mode appropriately.

Example

A fence PNG with alpha will use Color for visible wood and Alpha for gaps; set Blend Mode to reveal the holes.

Key Takeaway

Treat Color as visible image data and Alpha as transparency; set blend modes and color spaces correctly for intended results.

Pro tip

Inspect your image file to confirm it contains an alpha channel before wiring Alpha. If it doesn't, Alpha output will be empty.
