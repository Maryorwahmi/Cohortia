Location • Rotation • Scale
How each control changes texture sampling
Location

Translate the texture across the surface. Use it to align patterns or position decals precisely.

Rotation

Rotate sampling around axes. Rotate Z by 90 degrees to change orientation without editing UVs.

Scale

Increase values to tile more frequently. Example: Scale X:2 Y:2 makes wood grain repeat twice across a face.

Performance note

If scaling creates blur, the source texture may be too low resolution for the desired tiling; consider higher resolution or adjust texel density in UVs.

Key Takeaway

Mapping lets you transform texture placement quickly; scale affects repetition, not image detail.
