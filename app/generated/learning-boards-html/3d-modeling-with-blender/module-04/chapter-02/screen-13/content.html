Resolution & texel density
Match texture detail to asset importance and screen size
Guidelines
  • Choose resolution by maximum on-screen size and asset importance.
  • Keep texel density consistent across related assets to avoid visual mismatch.
  • Use atlases to combine small parts into one texture and reduce draw calls.
Warning

Using unnecessarily large textures increases memory and can kill performance on target devices.

Key Takeaway

Optimize resolution for visual necessity; use mapping and UVs to manage repetition without wasting memory.
