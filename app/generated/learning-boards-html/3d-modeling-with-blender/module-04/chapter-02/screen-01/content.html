Applying and Manipulating Basic Textures
Learn how to load image textures, map them onto models, and control placement for game-ready assets.
Interactive 16:9 Masterclass
Why this matters

Textures let you add surface detail without extra polygons, essential for optimized game assets.

What you'll do

Load an Image Texture, route Color and Alpha, and control placement using Mapping and Texture Coordinates.

Quick node chain
Image Texture (Color, Alpha)  -->  Principled BSDF (Base Color, Alpha)
Texture Coordinate (Object/UV) --> Mapping --> Image Texture (Vector)
Roughness map (Non-Color)      -->  Principled BSDF (Roughness)
Visual concept
Material + Texture

Material defines wood. Image texture adds grain, knots and color variation to make one plank unique.

Coordinate chain

Texture Coordinate feeds Mapping which transforms the image placement before it reaches the texture node.

Explore Key Topics
Image Texture: Load an image file and connect Color to Base Color for instant surface detail.
Texture Coordinates: Choose Generated, Object, or UV to control how the image wraps.
Mapping Node: Translate, rotate, and scale the texture coordinates to adjust placement.
