Practical checkpoints
Checkpoint 1 — Load and preview

Load an Image Texture and connect Color to Base Color. Verify the model updates in Material Preview.

Checkpoint 2 — Alpha transparency

Connect Alpha to Principled BSDF and change Blend Mode to Alpha Hashed or Alpha Blend to display cutouts properly.

Checkpoint 3 — Mapping control

Chain Texture Coordinate → Mapping → Image Texture and adjust Scale to change repetition without editing UVs.

Checkpoint 4 — Data maps

Add a Roughness image and set its Color Space to Non-Color so Blender treats it as numeric data instead of color.

Key Takeaway

Checkpoint mastery means your textures load correctly, transform predictably, and use appropriate color spaces for data maps.
