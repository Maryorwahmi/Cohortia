Module 5 › Chapter 4.4 › Image Texture Prep
Steps

Create and save a paintable image

  1. Open Shader Editor, add an Image Texture node and click New if no image exists.
  2. Set resolution (e.g., 2048x2048), name it clearly, and choose a base color if desired.
  3. Connect the Image Texture node to the Base Color of your material.
  4. Open the UV Editor and choose Image → Save As to write the file to disk immediately.
Concrete example
Create crate_basecolor_paint at 2048x2048 and save it to your project folder before the first stroke.
Warning
Not saving the image means your painting exists only in memory and will be lost when Blender closes.
Checklist
  • Name the image clearly and include resolution in the filename if helpful.
  • Save to disk immediately and periodically while painting.
  • Confirm the image is selected as the active paint slot in the Tools panel.
Key Takeaway
Never rely on the .blend save for painted images; always write your image files to disk explicitly.
