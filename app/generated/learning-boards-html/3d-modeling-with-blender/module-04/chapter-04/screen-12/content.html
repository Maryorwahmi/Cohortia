Module 5 › Chapter 4.4 › Common Mistakes
Major mistakes
  • Unsaved textures: Always use Image → Save As and save frequently.
  • Wrong paint slot: Confirm active image node in the Tools panel before strokes.
  • Overlapping UVs: Overlaps mirror paint and prevent unique details.
  • Inconsistent texel density: Use Average Island Scale to normalize before packing.
Practical safety: before long sessions, save your image, save a backup .blend copy, and verify slots and UV uniqueness.
Quick recovery
- Save images frequently (Alt + S in UV Editor).
- Keep incremental backups of your project folder.
- Export flattened copies for engine import while keeping editable layers.
Final warning
Losing painted images is common but avoidable; save images and back up before major changes.
