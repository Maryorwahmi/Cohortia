Module 5 › Chapter 4.4 › 3D vs 2D
3D Painting

Intuitive surface strokes

  • Paint directly on the model; brushes follow curvature.
  • Best for broad wear, dirt, and soft transitions.
  • Quick feedback in the scene context.
Example: Use 3D to add grime along the bottom edges of a crate so it reads naturally from all angles.
2D UV Painting

Pixel-accurate control

  • Paint on the flattened UV map for crisp edges.
  • Best for decals, logos, and seam cleanup.
  • Useful when exact pixel placement matters.
Example: Place a painted brand logo on a single crate face by drawing it directly on the UV island for that face.
Key Takeaway
Combine both methods: block broad strokes in 3D, refine and place precise details in the UV Editor for the best results.
