Module 5 › Chapter 4.4 › UV Layouts
Definition

What a UV layout does

A UV layout unfolds the 3D surface into flat islands inside the 0-1 square so a 2D image can paint color and detail onto the model.

Why it matters
Good layouts avoid stretching, allow predictable painting, and enable efficient use of texture pixels.
Concrete example
If a character's face island is too small, facial details will blur. Increase its island scale or allocate more UV space.
Key takeaway
Match UV scale to importance; pack carefully to maximize useful pixels without overlaps.
Visual guide
Packing trade-off
  • Tighter packing uses more pixels but must keep islands non-overlapping.
  • Some larger islands should be reserved for high-detail surfaces.
  • Manual rotation and scaling help fit difficult shapes.
Common misconception
Packing alone does not guarantee visual consistency. Always normalize texel density first so islands represent surface area fairly.
