Module 5 › Chapter 4.4 › Layering
Approach

Simulate layers with images and Mix nodes

  1. Create separate images for base, dirt, decals, etc.
  2. In the Shader Editor, chain Image Texture nodes through Mix RGB nodes to blend them.
  3. Paint on each image independently as needed and keep a flattened composite backup for export.
Example
Use a separate 'dirt' image to add grime. If you need to adjust intensity, tweak the Mix factor instead of repainting.
Pitfall
Painting without selecting the right image node overwrites another layer. Confirm the active slot before painting.
Checklist
  • Name each image by purpose: base, dirt, decals.
  • Keep a final flattened copy for engine export.
  • Use Mix node factors to tune layer influence non-destructively.
Key Takeaway
Layer by image and blend with Mix nodes so edits stay localized and reversible.
