Module 5 › Chapter 4.4 › Texture Paint Mode
Quick start

Access brushes and paint controls

  • Switch object mode to Texture Paint with the object selected.
  • Open the Tools panel to pick Draw, Blur, Smear, etc.
  • Use F to change brush radius and Shift + F to change strength in real time.
  • Ensure the active image slot is the one you want to modify.
3D vs 2D
Paint in 3D for organic strokes, switch to UV Editor to place precise decals or correct seams.
Tip
Use mirrored painting cautiously; overlapping UVs will mirror strokes to all overlapped regions.
Brush controls
- F : change radius
- Shift + F : change strength
- Color picker: sample from viewport or UV Editor
Key Takeaway
Master F and Shift + F and confirm the active image slot to paint confidently and avoid accidental strokes.
