Step-by-step

Straighten an island

  1. Select the island or specific vertices you want to align in the UV Editor.
  2. Use W > Align Auto or press S then X (or Y) then 0 while holding Shift to snap to an axis.
  3. Rotate (R) so the island's main direction is horizontal or vertical for predictable painting.
  4. Check the 3D Viewport for stretching and adjust vertices if necessary.
Concrete example
Straighten a crate plank edge so wood grain brushes run parallel and details tile cleanly.
Pro tip
Only straighten sections that are physically straight. Keep organic curves unaltered to avoid stretching artifacts.
Visual checklist
  • Select vertices, align, scale axis = 0, rotate island.
  • Preview in 3D, look for seams and stretching, iteratively tweak.
  • Don't over-constrain curved geometry; preserve form where needed.
Key Takeaway
Use axis-constrained scaling and align tools to make predictable islands that simplify painting and text placement.
