Refine UV layouts

Straighten and align islands, then pack them to maximize 0-1 space. This reduces texture waste and eases painting work.

Understand texel density

Measure and equalize pixels per unit so all model parts render at similar sharpness in-game.

Verified Competency Milestone

Prepare image textures

Create and assign an image texture to Base Color, set resolution, and save the image to disk before painting.

Verified Competency Milestone

Use Texture Paint

Paint directly in the 3D Viewport or on the UV map, adjust brushes and strength, and use multiple image slots for non-destructive layering.
