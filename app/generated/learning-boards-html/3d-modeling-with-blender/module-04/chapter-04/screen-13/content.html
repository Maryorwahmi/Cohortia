Module 5 › Chapter 4.4 › Crate Painting Activity
Steps
  1. Ensure an Image Texture is connected to Base Color; create crate_basecolor_paint at 2048x2048 and save.
  2. Switch to Texture Paint mode and select the Draw brush.
  3. Use a darker color for grime along edges; adjust F and Shift + F for size and strength.
  4. Use lighter, low-strength strokes for subtle highlights and scratches.
  5. Switch to the UV Editor for precise logo placement or seam fixes.
  6. Save the image frequently and export a flattened copy for the engine while keeping editable images for future edits.
Example settings
- Grime: Radius ~ 80 px, Strength 0.4
- Scratches: Radius ~ 12 px, Strength 0.2, light color
- Save image: Image → Save or Alt + S in UV Editor
Key Takeaway
Practice a cycle: create, save, paint, save, and export. This keeps work safe and iterative.
