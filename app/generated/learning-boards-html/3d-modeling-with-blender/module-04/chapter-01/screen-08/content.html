Module 4 › Chapter 4.1 › Brushed Metal
Quick steps
  1. Duplicate the sphere and create a new material.
  2. Set Base Color to dark grey (Hex: #333333).
  3. Set Metallic = 1.
  4. Set Roughness ≈ 0.6; add directional normal map for brushed streaks if needed.
Example: outcome
A kitchen appliance or metal trim reads as metal primarily because of environment reflections. The base color tints those reflections subtly.
Warning

Do not use intermediate metallic values for metals; set metallic to 1 for realistic metal response.
