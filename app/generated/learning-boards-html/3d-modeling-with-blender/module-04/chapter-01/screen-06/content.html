Parameter comparison
Base Color
Primary tint; usually fed by an image texture for detail.
Metallic
0 for dielectrics, 1 for metals. Avoid mid-values for realistic metals.
Specular
Intensity of highlights; often left near default for non-metals in PBR.
Roughness
0 = mirror, 1 = fully diffuse. Controls sharpness and spread of reflections.
Concrete examples
  • • Polished plastic: Base Color bright, Metallic 0, Roughness ~0.2.
  • • Brushed metal: Base Color dark grey, Metallic 1, Roughness ~0.6.
  • • Rough stone: Base Color brown-grey, Metallic 0, Roughness ~0.8.
Key Takeaway

Tweak Roughness first for finish, set Metallic as a class, and use Base Color textures for detail.
