Module 4 › Chapter 4.1 › Polished Plastic
Step-by-step
1. Add a UV Sphere (Shift + A → Mesh → UV Sphere).
2. Open Shader Editor and click New.
3. Set Base Color to blue (Hex: #0000FF).
4. Set Metallic = 0.
5. Set Roughness = 0.2.
6. View in Material Preview mode and rotate the light.
This exact sequence trains the feel of how Roughness alters reflection sharpness while Metallic changes reflection type.
Example: outcome
A polished toy car or plastic helmet typically uses these settings: non-metallic base with low roughness to show clear reflections without being mirror-like.
Common mistake

Raising Metallic to make highlights brighter converts the object into metal; avoid that when making paint or plastic.
