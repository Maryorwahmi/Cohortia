Node architecture
Material Output receives shader results. Principled BSDF is the main node that computes appearance.
# Example node chain (conceptual)
Image Texture -> Base Color (Principled BSDF)
Principled BSDF -> Surface (Material Output)
# For normal detail:
Normal Map -> Normal (Principled BSDF)
Tip: Use Image Texture nodes for maps and group repeated node setups into node groups to keep graphs tidy and efficient for export.
Common mistakes
  • • Editing a different material slot than the selected object — always verify the active material.
  • • Overcomplicating node graphs for realtime assets — aim for simplicity and texture-driven variation.
  • • Forgetting Material Output — disconnected nodes render nothing.
Pro tip

Group reusable node patterns and name your node groups for quick reuse across assets.
