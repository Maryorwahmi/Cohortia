Key Metrics

Measuring Performance: Latency and Throughput

Understanding how quickly and how much your service delivers

Latency

The time it takes for a request to return a response. It's a direct measure of how responsive your service feels to users.

  • HTTP Request Latency: Time for a web request to complete.
  • Database Query Latency: Time for a database operation to finish.
  • Percentiles (p90, p99): Crucial for understanding the experience of the majority of users, not just the average.
Example

99% of API calls complete within 200ms.

Throughput

The number of requests successfully processed per unit of time. It indicates the capacity and processing power of your service.

  • Requests Per Second (RPS): How many user requests the service handles.
  • Transactions Per Minute: For transactional systems, how many operations are completed.
  • Data Processed Per Hour: Relevant for batch processing or data pipelines.
Example

Service processes 10,000 requests per second.

Key Takeaway

Latency and Throughput are fundamental SLIs that quantify how fast and how much a service delivers, directly impacting user perception and system capacity.
