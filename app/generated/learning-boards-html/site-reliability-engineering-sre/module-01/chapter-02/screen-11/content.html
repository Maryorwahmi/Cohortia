SLIs, SLOs, and Error Budgets in Action

Applying the pillars to a critical login service

SLI: Login Service

Metric: Percentage of successful login attempts.

This directly measures the user's ability to access their account, a critical user journey.

SLO: Login Success

Target: 99.95% of login attempts must be successful over a 7-day rolling window.

A high, yet achievable, target for a critical user interaction.

Error Budget: Login Failures

Allowed: 0.05% of login attempts can fail.

For 1 million attempts/week, this allows 500 failed attempts. Exceeding this triggers reliability focus.

Key Takeaway

This example demonstrates how SLIs, SLOs, and Error Budgets provide a clear, actionable framework for managing the reliability of critical services like user login.
