Key Distinction

Automation vs. Mechanization

Intelligent Systems vs. Human-Driven Scripts

True Automation

Involves building intelligent systems that can make decisions, self-heal, and operate autonomously within predefined parameters.

  • System detects issue and acts.
  • Minimal to no human intervention.

Example: An auto-rollback system detects a failed deployment and reverts to the previous stable version without human input.

Mere Mechanization

Simply replaces human muscle with machine power, but still requires human oversight and decision-making for every step.

  • Human initiates and monitors.
  • Script runs only when explicitly told.

Example: A script that restarts a server, but only when an SRE manually executes it after an alert.

Key Takeaway

SRE aims for true automation, where systems operate autonomously, rather than mere mechanization which still relies on human oversight for routine tasks.
