Applying the Golden Signals: Triage Path

Systematically checking signals during an incident

01Is Latency High?

Users experiencing slowness is a primary symptom. Check response times for successful requests.

02Is Traffic Abnormal?

Look for unusual spikes (potential attack/viral) or drops (upstream failure/connectivity issue).

03Are Errors Increasing?

Check the rate of server-side failures (5xx errors, exceptions) to see if the service is failing requests.

04Is the System Saturated?

Assess resource utilization (CPU, memory, I/O) to determine if capacity limits are being reached.

Incident Triage Flow
Alert Triggered / User Report
Check Latency
Check Traffic
Check Errors

Formulate Hypothesis
Key Takeaway

This systematic approach helps quickly narrow down potential problem areas and guides effective incident response.
