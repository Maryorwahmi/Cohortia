Golden Signal 1

Latency: Measuring Responsiveness

The time it takes for a request to be serviced

Definition

The duration from when a request is sent to when a response is received. Focus on successful requests.

Example Measurement

http_request_duration_seconds_bucket (Prometheus histogram) or request.duration (OpenTelemetry span attribute).

Common Mistake

Only monitoring average latency. This hides severe issues for a significant portion of users. Always use percentiles (p90, p99).

Key Takeaway

Percentiles reveal the true user experience, especially for those at the 'tail end' experiencing significant delays.
