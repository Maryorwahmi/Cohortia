Saturation: Measuring Fullness

How close your system is to its capacity limits

Definition

A measure of resource utilization, indicating how close a system is to its maximum capacity.

Example Measurement

CPU utilization (node_cpu_seconds_total), memory usage, disk I/O, connection pool usage.

Common Mistake

Only looking at average utilization or not identifying the true bottleneck resource (e.g., CPU vs. database connections).

Saturation Impact
CPU Utilization75%
Memory Usage60%
Disk I/O95%
Key Takeaway

High saturation, especially on a bottleneck resource, is a strong predictor of impending latency and error increases.
