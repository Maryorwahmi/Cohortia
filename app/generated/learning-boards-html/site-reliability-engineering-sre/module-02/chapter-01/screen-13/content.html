Key Concepts: Reinforcing Your Understanding

Essential Terms for SRE Success

Monitoring

Collecting predefined data to track system health against known thresholds. Focuses on "known unknowns."

Observability

Inferring internal system state from external data to debug novel problems. Focuses on "unknown unknowns."

Telemetry Data

The raw data (metrics, logs, traces) emitted by a system that enables both monitoring and observability.

Chapter Summary

Monitoring and observability are distinct yet complementary SRE practices, both powered by comprehensive telemetry data.
