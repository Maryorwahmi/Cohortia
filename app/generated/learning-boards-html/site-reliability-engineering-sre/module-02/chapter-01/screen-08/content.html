TELEMETRY TYPE

Metrics: Tracking Trends and Performance

Numerical Data Collected Over Time

Definition

Numerical measurements collected over time, typically aggregated, representing a specific aspect of system performance or health.

Examples

CPU utilization, memory usage, request latency, error rates, active user counts. Ideal for dashboards and alerts.

Metrics in Action

Track API request rates over time to identify peak loads or sudden drops in traffic.

Common Mistake: Cardinality Explosion

Attaching too many unique labels to metrics can overwhelm monitoring systems, slowing queries and consuming excessive storage.

Key Takeaway

Metrics provide a high-level, efficient view of system health, but require careful design to avoid performance issues.
