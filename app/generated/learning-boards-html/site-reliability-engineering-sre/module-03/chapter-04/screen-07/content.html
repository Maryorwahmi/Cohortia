Fundamental Principle

The Golden Rule of Alerting

Alert only when immediate human action is required.

What is an Alert?

An alert is a notification indicating a system problem that specifically requires immediate human intervention to resolve or investigate.

The Golden Rule

If a human needs to do something right now, ALERT.

Otherwise, DON'T.

Consequence

Ignoring the golden rule leads to alert fatigue, where engineers become desensitized and miss critical alerts.

Understanding Alert Fatigue

Alert fatigue is a state where engineers are overwhelmed by an excessive volume of non-actionable or low-priority notifications, causing them to ignore alerts and potentially miss critical incidents.

Example: Non-Actionable Alert

An alert for 'CPU usage > 80%' that fires frequently but doesn't indicate user impact or require immediate action. This is noise, not a critical alert.

Key Takeaway

Every alert should justify waking someone up; if it doesn't, it's contributing to alert fatigue.
