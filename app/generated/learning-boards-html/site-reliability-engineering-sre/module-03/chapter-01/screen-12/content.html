Defining SLIs & SLOs for an E-commerce Product Page (Part 1)

Identifying critical user actions and brainstorming potential SLIs.

1. Critical User Actions (PDP)

  • Viewing product details: Essential for browsing and decision-making.
  • Adding product to cart: Direct path to conversion and revenue.
  • Viewing product images/videos: Enhances user engagement.
  • Reading customer reviews: Influences purchase decisions.
Key Takeaway

Prioritize user actions that directly impact the core business function or user satisfaction.

2. Brainstormed SLIs

  • Latency for initial page load: Time to render the HTML document.
  • Latency for API calls: Time to fetch product data (e.g., `/api/products/{id}`).
  • Error rate for initial page load: Percentage of 5xx errors for the PDP.
  • Error rate for 'Add to Cart' API: Percentage of 5xx errors for `/api/cart/add`.
Pro-Tip

When brainstorming SLIs, consider the 'golden signals' (Latency, Traffic, Errors, Saturation) for each critical user action.
