Defining SLIs & SLOs for an E-commerce Product Page (Part 2)

Proposing specific SLOs and formulating a mock monitoring query.

3. Proposed SLOs

  • Initial Page Load Latency: P90 latency < 500ms over a 7-day rolling window. (Justification: Quick browsing).
  • Add to Cart Error Rate: < 0.05% 5xx errors over a 30-day rolling window. (Justification: Critical conversion step).
Key Takeaway

SLOs should be specific, measurable, achievable, relevant, and time-bound (SMART).

4. Mock Monitoring Query (Prometheus-like)
# Calculate rate of 5xx errors for add-to-cart API
sum(rate(http_requests_total{job="product-service", path="/api/cart/add", status_code=~"5..", method="POST"}[5m]))
/
# Divide by total rate of add-to-cart API calls
sum(rate(http_requests_total{job="product-service", path="/api/cart/add", method="POST"}[5m]))
* 100
Query Purpose

This query provides the real-time percentage of 5xx errors for the 'Add to Cart' API, allowing you to track the SLI against its defined SLO.
