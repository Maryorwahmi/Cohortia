Core Concept

What are Service Level Indicators (SLIs)?

Quantitative measures of service performance from a user's perspective.

Definition

An SLI is a quantitative measure of some aspect of the service you provide, directly reflecting the user experience. It's a metric that tells you how well your service is performing from the perspective of the end-user.

  • Must be **measurable** and **unambiguous**.
  • Must directly reflect **user experience**.
  • Avoid internal system metrics as primary SLIs.
Key Takeaway

Good SLIs are user-centric, quantifiable, and provide clear insight into how users perceive service quality.

Examples of Good SLIs

  • Latency: How quickly a server responds to a user request (e.g., page load time, API response time).
  • Error Rate: The percentage of requests that result in an error (e.g., HTTP 5xx errors, failed transactions).
  • Throughput: The number of successful requests handled per unit of time (e.g., requests per second).
  • Availability: The percentage of time a service is operational and accessible to users.
Scenario

For an online streaming service, a good SLI would be 'time to start video playback' or 'percentage of buffering events', as these directly impact the viewer's experience.
