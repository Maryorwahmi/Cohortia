Definition

What is an Error Budget?

Translating SLOs into a quantifiable allowance for unreliability.

Error Budget Defined

The maximum acceptable amount of unreliability for a service over a specific period, directly derived from its Service Level Objective (SLO).

Key Characteristic

It's a finite, quantifiable resource, not an abstract goal. It represents 'bad' performance you can tolerate.

Purpose

Transforms reliability targets into a concrete allowance, enabling data-driven decisions about risk and feature development.

SLO to Error Budget

From target to allowance

Service Level Objective (SLO)

e.g., 99.9% Availability

Error Budget

e.g., 0.1% Unavailability

Example

If SLO is 99.9% availability, the error budget is 0.1% of total time or requests.
