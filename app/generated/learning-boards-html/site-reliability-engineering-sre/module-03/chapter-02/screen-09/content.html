Critical State

When the Error Budget Depletes

Shifting focus from new features to critical reliability work.

Budget Status: Depleted

  • •Allowable unreliability has been fully consumed.
  • •Service is failing users against its stated SLO.
  • •Requires immediate and decisive action.
Key Takeaway

Depletion triggers a mandatory shift to reliability work, driven by data, not subjective opinion.

Mandatory Actions

  • •Pause new feature development.
  • •Dedicate resources to fixing reliability issues.
  • •Improve testing and deployment processes.
Example Scenario

If budget is spent in week one, all efforts shift to stability, delaying a planned feature launch.
