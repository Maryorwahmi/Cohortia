Calculating Error Budgets: Request-Based SLOs

Deriving allowable failed requests from success rate targets.

Error Budget Formula

Error Budget = (100% - SLO Percentage) * Total Requests

Key Insight

This calculation provides a clear, absolute number of allowed failed requests, making it easy to track and manage.

Pro-Tip

Ensure your 'Total Requests' period aligns with your SLO's defined window (e.g., daily, weekly, monthly).

Code Walkthrough
# Example: 99.99% Success Rate SLO for 10M requests/day

SLO_PERCENTAGE = 99.99
TOTAL_REQUESTS_PER_DAY = 10_000_000

# Calculate error budget percentage
ERROR_BUDGET_PERCENTAGE = (100 - SLO_PERCENTAGE) / 100
# ERROR_BUDGET_PERCENTAGE = (100 - 99.99) / 100 = 0.0001

# Calculate allowed failed requests per day
ALLOWED_FAILED_REQUESTS = ERROR_BUDGET_PERCENTAGE * TOTAL_REQUESTS_PER_DAY
# ALLOWED_FAILED_REQUESTS = 0.0001 * 10_000_000 = 1000

print(f"Allowed failed requests per day: {ALLOWED_FAILED_REQUESTS:.0f}")
# Output: Allowed failed requests per day: 1000
