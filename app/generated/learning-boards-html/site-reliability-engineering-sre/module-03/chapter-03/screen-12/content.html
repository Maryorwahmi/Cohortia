Continuous Improvement

From Lessons to Action Items

Translating postmortem insights into concrete, measurable tasks.

Good Action Item (SMART)

  • Specific: Implement automated database schema migration tests.
  • Measurable: Achieve 95% test coverage for schema changes.
  • Achievable: Team has resources and skills.
  • Relevant: Directly addresses a root cause.
  • Time-bound: Complete by end of next sprint.

Bad Action Item (Vague)

  • Improve database migration process.
  • Be more careful next time.
  • Fix the bug.
  • Increase testing.
  • Review documentation.
What are Action Items?

Specific, measurable tasks derived from postmortems to prevent recurrence or improve future incident response.

SMART Criteria
  • Specific
  • Measurable
  • Achievable
  • Relevant
  • Time-bound
Key Takeaway

Actionable, SMART improvements are the tangible outcome of effective postmortems, driving real-world changes for resilience.
