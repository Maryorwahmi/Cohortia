Module 4›Chapter 4.5›Terraform Workflow
Step 1

`terraform init`

Initializes the working directory and downloads provider plugins.

Step 2

`terraform plan`

Shows proposed changes to match desired state (safety net).

Step 3

`terraform apply`

Executes the planned changes to provision infrastructure.

Key Concept: Idempotency

Terraform operations are idempotent, meaning applying the same configuration multiple times will yield the same result without unintended side effects, only making necessary changes.

Key Concept: State Management

Terraform maintains a state file to map real-world resources to your configuration, allowing it to track changes and manage resource lifecycles effectively.

Key Takeaway

The Terraform workflow of `init`, `plan`, and `apply` provides a controlled, idempotent, and stateful mechanism for provisioning and managing infrastructure, with `plan` acting as a critical safety review step.
