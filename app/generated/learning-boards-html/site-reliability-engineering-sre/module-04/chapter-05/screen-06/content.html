Terraform Configuration (main.tf)
# main.tf

resource "aws_instance" "web_server" {
  ami           = "ami-0abcdef1234567890" # Example AMI ID
  instance_type = "t2.micro"
  key_name      = "my-ssh-key"
  tags = {
    Name        = "MyWebServer"
    Environment = "Dev"
  }
}
Understanding the Code
  • •`resource` Block: Declares an infrastructure object (e.g., `aws_instance`).
  • •Provider & Type: `aws_instance` specifies an EC2 instance within AWS.
  • •Local Name: `web_server` is a unique identifier within your Terraform configuration.
  • •Attributes: `ami`, `instance_type`, `key_name`, and `tags` define the desired properties of the instance.
Key Concept: Desired State

Terraform's declarative nature means you define the end state you want, and Terraform handles the steps to get there, making infrastructure management predictable.

Key Takeaway

Terraform uses a declarative language (HCL) to define infrastructure resources, allowing SREs to specify the desired state of their cloud environment rather than imperative step-by-step commands.
