Building a Diagnostic Script: Setup & Basic Info

Capturing uptime, disk, and memory usage for my-critical-service

#!/bin/bash

SERVICE_NAME="my-critical-service"
LOG_FILE="/var/log/${SERVICE_NAME}.log"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
OUTPUT_DIR="/tmp/service_diagnostics_${TIMESTAMP}"

echo "Starting diagnostics for ${SERVICE_NAME}..."

# 1. Create output directory
mkdir -p "${OUTPUT_DIR}"
if [ $? -ne 0 ]; then
    echo "Error: Could not create output directory ${OUTPUT_DIR}. Exiting."
    exit 1
fi
echo "Diagnostic output will be stored in: ${OUTPUT_DIR}"

# 2. Capture system uptime
echo "--- System Uptime ---" > "${OUTPUT_DIR}/uptime.txt"
uptime >> "${OUTPUT_DIR}/uptime.txt"

# 3. Capture disk usage
echo "--- Disk Usage ---" > "${OUTPUT_DIR}/disk_usage.txt"
df -h >> "${OUTPUT_DIR}/disk_usage.txt"

# 4. Capture memory usage
echo "--- Memory Usage ---" > "${OUTPUT_DIR}/memory_usage.txt"
free -h >> "${OUTPUT_DIR}/memory_usage.txt"

# TODO: Add commands for processes and service status in the next steps

echo "Diagnostics complete. Review files in ${OUTPUT_DIR}."
diagnose_critical_service.sh
Lab Steps (Part 1)
  • •**Initialize Script:** Define service name, log path, and create a timestamped output directory.
  • •**Capture Uptime:** Use uptime to get system uptime.
  • •**Check Disk Usage:** Use df -h for human-readable disk space.
  • •**Monitor Memory:** Use free -h for human-readable memory stats.
Key Learning

A well-structured diagnostic script begins with clear setup and captures foundational system health metrics, providing immediate context for any incident.

Action
