Module 4›Chapter 3›Continuous Delivery vs. Continuous Deployment

Continuous Delivery (CD)

Ensures software is always in a deployable state, ready for manual release to production at any time.

Key Characteristic

Automated build, test, and packaging into a deployable artifact.

Deployment Trigger

Manual decision to release to production.

SRE Implication

Provides control and flexibility, but still requires human oversight for final release.

Key Takeaway

CD means 'ready to deploy at any time' with a human trigger, balancing automation with control.

Continuous Deployment

Every change that passes all automated tests and quality gates is automatically deployed to production.

Key Characteristic

Full automation from code commit to production release.

Deployment Trigger

Automated upon successful completion of all pipeline stages.

SRE Implication

Minimizes lead time, maximizes frequency, but demands extreme confidence in automation and monitoring.

Key Takeaway

Continuous Deployment means 'automatically deployed every time,' requiring robust testing and monitoring.
