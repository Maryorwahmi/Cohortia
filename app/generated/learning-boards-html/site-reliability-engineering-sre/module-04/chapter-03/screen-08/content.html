Building and Testing with CI

Automating Docker image creation and running comprehensive unit and integration tests.

Build Image Job

Uses Docker-in-Docker to build and push a versioned Docker image to a registry, ensuring artifact readiness.

Unit & Integration Tests

Executes pytest for both unit and integration tests, validating code functionality and inter-component interactions.

Dependency Management

The needs keyword ensures tests run in a specific order, guaranteeing foundational checks pass before advanced ones.

Key Takeaway

Robust build and test stages are the backbone of CI, providing early feedback and high-quality artifacts for SREs.

.gitlab-ci.yml (Build & Test Stages)
stages:
  - build
  - test

build_image:
  stage: build
  image: docker:latest
  services:
    - docker:dind
  script:
    - docker build -t $DOCKER_REGISTRY/$DOCKER_IMAGE_NAME:$CI_COMMIT_SHORT_SHA .
    - docker push $DOCKER_REGISTRY/$DOCKER_IMAGE_NAME:$CI_COMMIT_SHORT_SHA
  only:
    - main
    - merge_requests

unit_test:
  stage: test
  image: python:3.9-slim-buster
  script:
    - pip install -r requirements.txt
    - pytest tests/unit/
  only:
    - main
    - merge_requests

integration_test:
  stage: test
  image: python:3.9-slim-buster
  script:
    - pip install -r requirements.txt
    - pytest tests/integration/
  needs: ["unit_test"]
  only:
    - main
