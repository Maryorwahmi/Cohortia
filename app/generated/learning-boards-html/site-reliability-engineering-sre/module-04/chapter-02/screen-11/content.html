Variables and Jinja2 Templates

Parameterize your playbooks for greater adaptability.

playbook.yml
- name: Configure Nginx with custom port
  hosts: webservers
  vars:
    nginx_port: 8080 # Default port
  tasks:
    - name: Ensure Nginx is installed
      ansible.builtin.apt:
        name: nginx
        state: present
      when: ansible_os_family == "Debian"

    - name: Create custom Nginx config with variable port
      ansible.builtin.template: # Use template module for variables in files
        src: templates/nginx.conf.j2
        dest: /etc/nginx/nginx.conf
        owner: root
        group: root
        mode: '0644'
      notify: Restart Nginx

Jinja2 Template Example

Jinja2 is a templating language used to embed variables and logic into text files. Template files typically have a .j2 extension.

templates/nginx.conf.j2
server {
    listen {{ nginx_port }};
    server_name localhost;
    # ... other config
}

vars: Defines playbook-specific variables like nginx_port.

template module: Processes Jinja2 templates, replacing {{ nginx_port }} with its value.

Key Takeaway

Variables make playbooks dynamic and reusable, while the template module with Jinja2 allows embedding these variables into configuration files.
