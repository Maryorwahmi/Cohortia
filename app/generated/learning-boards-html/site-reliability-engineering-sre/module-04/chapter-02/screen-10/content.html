Conditional Logic and Event-Driven Actions

Make playbooks smarter with when statements and handlers.

Conditional Execution with when

The when statement allows a task to run only if a specified condition is true. This is useful for OS-specific tasks or environment-specific configurations.

Example

when: ansible_os_family == "Debian"

This task will only execute if the managed node's operating system family is Debian (e.g., Ubuntu).

Key Takeaway

when statements provide dynamic control over task execution, while handlers ensure services are only restarted when configuration changes necessitate it.

Event-Driven Actions with Handlers

Handlers are tasks that only run when explicitly 'notified' by another task. They are typically used for service restarts or other actions that depend on a change occurring.

How it works

1. Task changes a file:

notify: Restart Nginx is added to the copy task.

2. Handler is triggered:

If the copy task makes a change, the Restart Nginx handler (defined in the handlers section) will run.

Common Mistake

Forgetting to define the handler in the handlers section, or misspelling the handler name in the notify directive, leading to silent failures.
