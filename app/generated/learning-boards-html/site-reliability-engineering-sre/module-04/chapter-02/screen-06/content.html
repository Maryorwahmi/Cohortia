Organizing Your Infrastructure with Inventory

Group and manage your servers effectively using inventory files.

What is an Inventory File?

The inventory file (e.g., hosts or inventory.ini) lists the managed nodes (target hosts) that Ansible will configure. It allows you to organize these nodes into logical groups.

Benefits
  • Target specific sets of servers for tasks.
  • Define host-specific or group-specific variables.
  • Centralize host information for clarity.
Key Takeaway

A well-structured inventory is essential for scalable Ansible automation, enabling precise targeting and variable management across your infrastructure.

inventory.ini
[webservers]
web1.example.com
web2.example.com

[databases]
db1.example.com
db2.example.com

[all:vars]
ansible_user=ubuntu
ansible_ssh_private_key_file=~/.ssh/id_rsa

Groups: [webservers] and [databases] define logical collections of hosts.

Host Entries: List individual server hostnames or IP addresses.

Group Variables: [all:vars] sets default SSH connection parameters for all hosts.

Common Mistake

Forgetting to specify ansible_user or ansible_ssh_private_key_file, leading to SSH connection failures when Ansible tries to connect to managed nodes.
