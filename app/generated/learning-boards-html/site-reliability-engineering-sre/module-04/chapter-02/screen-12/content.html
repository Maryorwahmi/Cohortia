Streamlining Tasks with Loops

Execute a single task for multiple items in a list.

playbook.yml (snippet)
- name: Install multiple packages
  ansible.builtin.apt:
    name: {{ item }}
    state: present
  loop:
    - htop
    - git
    - curl

How Loops Work

The loop keyword allows a task to iterate over a list of items. For each item, the task is executed, with {{ item }} representing the current item in the iteration.

Benefits
  • Reduces playbook code duplication.
  • Improves readability and maintainability.
  • Simplifies managing lists of similar resources.
Key Takeaway

Ansible loops enable efficient execution of a single task across multiple items, significantly reducing playbook verbosity and improving maintainability.
