First Playbook: Installing Nginx

Walk through a basic playbook to install and run a web server.

nginx_config.yml
---
- name: Configure Nginx web servers
  hosts: webservers
  become: yes # Run tasks with sudo/root privileges

  tasks:
    - name: Ensure Nginx is installed
      ansible.builtin.apt:
        name: nginx
        state: present
      when: ansible_os_family == "Debian" # Conditional for Debian-based systems

    - name: Ensure Nginx service is running and enabled
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: yes

    - name: Copy custom Nginx configuration
      ansible.builtin.copy:
        src: files/nginx.conf
        dest: /etc/nginx/nginx.conf
        owner: root
        group: root
        mode: '0644'
      notify: Restart Nginx # Trigger handler if config changes

  handlers:
    - name: Restart Nginx
      ansible.builtin.service:
        name: nginx
        state: restarted

Key Playbook Directives

name: Play Description

A descriptive name for the play, making it easy to understand its purpose.

hosts: Target Selection

Specifies which hosts from the inventory this play applies to. Can be a group name, a single host, or a pattern.

become: yes: Privilege Escalation

Instructs Ansible to run tasks with elevated privileges (e.g., sudo or root), essential for system-level changes.

Key Takeaway

Ansible playbooks define automation tasks using YAML, targeting specific hosts with hosts and escalating privileges with become: yes for system-level changes.
