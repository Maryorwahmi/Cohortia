Chaos Experiment Types

Resource Exhaustion

Testing system performance under contention

CPU Saturation

Inject high CPU usage to test how services perform under heavy computation and if auto-scaling responds.

Memory Leaks

Simulate memory leaks to observe system behavior as available RAM diminishes and OOM killers activate.

Disk I/O Saturation

Inject high disk I/O to test how services handle slow storage and if caching layers mitigate impact.

Key Takeaway

Resource exhaustion experiments are crucial for validating system resilience under load and ensuring auto-scaling mechanisms function effectively to prevent performance degradation.
