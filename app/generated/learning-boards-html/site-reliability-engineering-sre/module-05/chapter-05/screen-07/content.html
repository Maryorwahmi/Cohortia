Testing System Availability

Simulating network partitions and service crashes.

Network Partition

Simulates a network split preventing certain services from communicating.

  • Tests ability to operate in degraded mode or failover.
  • Reveals how systems handle isolated components.
  • Example: Blocking traffic between a web server and its database.
Why it matters

Ensures your system can continue functioning, even partially, during network outages.

Service Failure/Crash

Randomly terminates instances of a service or entire hosts.

  • Validates load balancer health checks and failover.
  • Tests service discovery and auto-recovery mechanisms.
  • Example: Killing a web server process unexpectedly.
Why it matters

Confirms your system can automatically recover from unexpected component failures without manual intervention.

Key Takeaway

These experiments are crucial for validating a system's ability to maintain availability and recover from critical component failures.
