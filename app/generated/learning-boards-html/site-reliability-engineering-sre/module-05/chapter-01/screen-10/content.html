SRE Framework

Service Level Indicators (SLIs)

Quantifying service performance with precise, measurable definitions

Definition

An SLI is a carefully defined quantitative measure of some aspect of the level of service that is provided (e.g., success rate, latency percentile).

The 'What' to Measure

SLIs are the raw data points that directly reflect user experience and system health. They must be unambiguous and observable.

Key Takeaway

SLIs are the foundation for objective performance assessment, providing clear, measurable data points that define service quality.

Examples of Service Level Indicators
Success Rate

Percentage of successful HTTP requests (e.g., 2xx responses) out of total requests.

Latency Percentile

P99 latency for HTTP GET requests to a specific API endpoint, like /api/v1/data.

Availability

Percentage of time a service is operational and reachable by users.

Misconception

An SLI is not a target; it's a measurement. The target comes next with SLOs.
