Chapter Summary

Key Concepts: Core Metrics

Essential terms for SRE performance management

Latency

The time delay between a request and its response, indicating system responsiveness.

Throughput

The rate at which a system processes requests or data over a given period.

Utilization

The percentage of time a resource (CPU, memory, network) is actively being used.

Summary Takeaway

Understanding these core metrics is fundamental for diagnosing system health and ensuring a reliable, high-performing service for users.
