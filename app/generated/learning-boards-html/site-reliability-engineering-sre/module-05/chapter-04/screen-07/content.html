Trace ID and Span ID

Linking Operations Across Services

Trace ID

A unique identifier that links all spans belonging to a single end-to-end request or transaction across all services involved. It's the master key for the entire journey.

Span ID & Parent Span ID

The Span ID uniquely identifies an individual operation within a trace. The Parent Span ID links a child span to its immediate parent, establishing the hierarchical relationship.

Common Mistake

Not propagating trace context (Trace ID, Span ID) across service boundaries. This breaks the end-to-end view, making it impossible to correlate operations.

Trace ID: abc-123
Span: Service A (Span ID: s1)
Span: Service B (Span ID: s2, Parent ID: s1)
Span: Database (Span ID: s3, Parent ID: s2)
