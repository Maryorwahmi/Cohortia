Key Concepts: Part 1

Essential Terms for Tracing

Distributed Tracing

Monitors requests across distributed systems, providing an end-to-end view of execution paths.

Span

A single operation within a trace, representing a unit of work with start/end times and attributes.

Trace ID

A unique identifier linking all spans belonging to a single request across multiple services.

OpenTelemetry

An open-source framework for instrumenting applications to generate traces, metrics, and logs.

Summary Takeaway

Distributed tracing provides the 'where' of performance issues by mapping request flows using spans and unique trace IDs, often implemented via OpenTelemetry.
