Spans: The Building Blocks of a Trace

Representing Individual Operations

What is a Span?

A span is a single operation within a trace, representing a logical unit of work with a defined start and end time. It's the fundamental building block that captures the execution details.

  • •Name: Describes the operation (e.g., 'authenticateUser', 'queryDatabase').
  • •Start/End Time: Defines the duration of the operation.
  • •Attributes (Tags): Key-value pairs providing additional context (e.g., 'http.method', 'db.statement', 'user.id').
  • •Hierarchy: Spans can have parent-child relationships, forming a tree structure.
Key Takeaway

Spans are the granular records of work, providing detailed timing and context for each step in a distributed request.

Parent Span: Process Order (150ms)
Child Span: Validate User (20ms)
Child Span: Update Inventory (50ms)
Child Span: Charge Payment (80ms)

Example Attributes:

  • http.method: POST
  • user.id: 12345
  • db.table: orders
