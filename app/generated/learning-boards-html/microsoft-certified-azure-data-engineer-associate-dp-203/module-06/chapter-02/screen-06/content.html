Python producer (async) — key sections
import asyncio
from azure.eventhub.aio import EventHubProducerClient
from azure.eventhub import EventData
import json, random, datetime

EVENT_HUB_CONNECTION_STR = "Endpoint=sb://<your-namespace>.servicebus.windows.net/;SharedAccessKeyName=RootManageSharedAccessKey;SharedAccessKey=<your-key>"
EVENT_HUB_NAME = "telemetry-events"

async def run():
  producer = EventHubProducerClient.from_connection_string(
    conn_str=EVENT_HUB_CONNECTION_STR,
    eventhub_name=EVENT_HUB_NAME
  )
  async with producer:
    for i in range(10):
      device_id = f"device-{random.randint(1,3)}"
      event_payload = {
        "deviceId": device_id,
        "temperature": round(random.uniform(20.0,30.0),2),
        "timestamp": datetime.datetime.now(datetime.timezone.utc).isoformat()
      }
      event_data = EventData(json.dumps(event_payload))
      event_data.properties = {"partition_key": device_id}
      event_batch = await producer.create_batch()
      event_batch.add(event_data)
      await producer.send_batch(event_batch)
      await asyncio.sleep(1)

if __name__ == "__main__":
  asyncio.run(run())
This snippet shows serializing a payload to JSON, creating EventData, setting a partition key, batching, and sending. Adapt the batch loop to add multiple events per batch for higher throughput.
Notes & example
  • Set partition_key to deviceId to preserve ordering per device.
  • Send multiple EventData items in one batch to reduce RPC overhead.
  • Handle retries and backoff in production to manage transient failures.
Common mistake
Sending many single‑event sends increases overhead and reduces throughput. Batch related events where possible.
