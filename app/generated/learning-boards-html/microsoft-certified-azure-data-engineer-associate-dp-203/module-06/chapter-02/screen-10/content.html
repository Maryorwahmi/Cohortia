Capture configuration
Choose a Storage account and container, then select Avro or Parquet. Configure a capture window by time or size; when the trigger fires, a file is written automatically.
Why use Capture
Capture removes operational overhead required to build a custom archival consumer and guarantees raw event retention for batch processing.
Notes & misconception
Capture is an archival mechanism; it does not replace real-time consumers for analytics. Use Capture for raw data retention and a consumer for real-time processing.
Practical note
Files written by Capture are structured for downstream batch jobs. Choose Avro if you need schema evolution support, or Parquet for columnar analytics performance.
