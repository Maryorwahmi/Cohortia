Module 6 › Chapter 6.2 › Create Namespace & Event Hub
Step-by-step portal flow
  1. Create a resource group or reuse an existing one, then create an Event Hubs namespace.
  2. Choose pricing/throughput units appropriate for expected ingress.
  3. Create an Event Hub inside the namespace and set partition count.
  4. Under Shared access policies, copy the connection string for producers/consumers.
  5. Create a Storage account and container for checkpoint blobs used by consumers.
Why it matters
Partitions determine how many consumers can process in parallel and which events remain ordered. Choosing them correctly avoids costly migrations later.

Common misconception
Partitions are not elastic. You cannot change partition count after creating the Event Hub. Instead, plan ahead or create a new Event Hub and migrate data if scale needs grow.
