Consumer example (concept)
from azure.eventhub.aio import EventHubConsumerClient
from azure.eventhub.extensions.checkpointstoreblobaio import BlobCheckpointStore

# Create BlobCheckpointStore from storage connection
checkpoint_store = BlobCheckpointStore.from_connection_string(
  AZURE_STORAGE_CONNECTION_STR,
  BLOB_CONTAINER_NAME
)

client = EventHubConsumerClient.from_connection_string(
  conn_str=EVENT_HUB_CONNECTION_STR,
  consumer_group=CONSUMER_GROUP,
  eventhub_name=EVENT_HUB_NAME,
  checkpoint_store=checkpoint_store
)

async def on_event(partition_context, event):
  # inspect event body and properties, then conditionally checkpoint
  await partition_context.update_checkpoint(event)

async with client:
  await client.receive(on_event=on_event, starting_position="-1")
This pattern uses BlobCheckpointStore so offsets are durable. EventProcessorClient builds on this to handle partition load balancing when multiple instances run concurrently.
Tips
  • Checkpoint after successful, idempotent processing or every N events.
  • Use consumer groups to isolate different consumer applications.
  • Monitor partition ownership and lag to detect imbalances.
