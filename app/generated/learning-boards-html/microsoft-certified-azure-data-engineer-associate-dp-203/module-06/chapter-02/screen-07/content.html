Module 6 › Chapter 6.2 › Partition Key
What partition keys do
A partition key groups related events and routes them to the same partition so their relative order is preserved. The Event Hubs service hashes the key to pick a partition.
Concrete example
If device A sends events with partition key deviceA, those events will land in the same partition and consumers reading that partition will see them in order.
Misconception & planning
Partition keys do not guarantee ordering across different keys or across partitions. Also you cannot change partition count after creation. Plan keys and partition count with parallelism and ordering requirements in mind.
Key Takeaway
Use deviceId or another stable identifier as the partition key to maintain per-device ordering; size partitions to support expected parallel consumers.
