Module 6 › Chapter 6.2 › Quick Reference
Batch
Aggregate events into batches to improve throughput and lower latency of network calls.
Partition Key
Use a stable key like deviceId to keep per‑device ordering inside a partition.
Checkpoint
Persist offsets in Blob storage; use EventProcessorClient to enable automatic rebalancing and recovery.
Quick Action

Start with a secure connection pattern, implement batching and partition keys, add checkpointing, then optionally enable Capture for archival.
