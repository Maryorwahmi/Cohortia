Learning Objectives
Four practical milestones to guide your hands-on work and assessments.
01
Portal setup
Create an Event Hubs namespace and Event Hub so producers and consumers have an endpoint. This matters because correct configuration controls scale and throughput.
Verified competency milestone
02
Producer patterns
Send EventData in batches and use partition keys to ensure ordering for related streams, improving throughput and consistency.
Verified competency milestone
03
Consumer reliability
Implement checkpointing with BlobCheckpointStore or EventProcessorClient so consumers resume from the last processed offset after failure.
Verified competency milestone
04
Capture & archiving
Enable Event Hubs Capture to write event batches to Blob or ADLS Gen2 in Avro or Parquet, ensuring raw data is retained for batch analytics.
Verified competency milestone
