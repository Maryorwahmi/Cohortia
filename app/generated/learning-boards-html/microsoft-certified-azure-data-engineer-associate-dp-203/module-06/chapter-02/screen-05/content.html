Connection string essentials
The connection string contains the service endpoint and a shared access key. For production use least privilege policies and never hardcode the connection string in source control.
Secure storage options
  • Azure Key Vault: store and rotate keys, retrieve at runtime.
  • Managed Identity: avoid secrets by using Azure AD tokens when supported by your SDK.
  • Scoped SAS policies: grant only Send or Listen as needed.
Key Takeaway
Protect connection strings with Key Vault or managed identities and use least privilege for access policies.
Quick example: secret retrieval (concept)
# Application retrieves secret from Key Vault once at startup, then constructs EventHubProducerClient with it.
Misconception
Using RootManageSharedAccessKey everywhere is common in quick demos, but it grants management-level permissions. Prefer separate Send and Listen policies in production.
