Module 6 › Chapter 6.1 › Event Hubs Capture
What it does
Automatically writes event batches to Blob Storage or Data Lake Gen2. Useful for archival, auditing, and batch reprocessing.
Configuration
Choose destination, file format, and capture window. Ensure storage account permissions and lifecycle policies are set for long-term retention.
When to use
  • When you need a reliable archive of raw events for audits or batch analytics.
  • To implement a lambda pattern with both real-time and batch consumers.
  • When you want to avoid building a separate archival consumer service.
Key takeaway
Capture simplifies archival and replay by delivering event data to storage without extra consumer code, but it is not a replacement for custom enrichment or format-specific pipelines.
