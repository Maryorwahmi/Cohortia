Module 6 › Chapter 6.1 › Business Value
Why stream?
  1. Low-latency detection and reaction to events.
  2. Support for high-rate, continuous data such as IoT telemetry and clickstreams.
  3. Enables real-time personalization and monitoring.
Concrete example
A fleet of sensors sends telemetry each second; streaming allows immediate alerts for anomalies while older data is archived for trend analysis.
Trade-offs
  • Ordering guarantees can be harder to manage across partitions.
  • Stateful processing requires careful fault-tolerance and checkpoints.
  • Design must include replay and archival strategies for correctness and auditing.
Key takeaway
Stream processing is chosen for speed and immediacy; pair it with archival storage when you need both live reaction and later analysis.
