Module 6 › Chapter 6.1 › Best Practices
Common mistakes
  • Choosing a low-cardinality partition key and creating hot partitions.
  • Using the default consumer group for unrelated consumers.
  • Under-provisioning throughput units leading to throttling.
Recommended actions
  • Pick high-cardinality keys or shard identifiers to spread load.
  • Create separate consumer groups per application and monitor offsets.
  • Test peak load, instrument metrics, and scale throughput units as needed.
Key takeaway
Proactive partitioning, consumer group separation, and capacity planning prevent the most common production failures.
