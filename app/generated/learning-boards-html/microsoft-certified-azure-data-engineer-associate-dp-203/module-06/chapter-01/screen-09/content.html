Module 6 › Chapter 6.1 › Consumer Groups
Role
A consumer group gives an independent cursor into the stream so multiple applications can each read all events without interfering.
Scenario
AppA (3 instances) and AppB (2 instances) should use separate consumer groups so each app gets the full stream and shares partitions within its group.
Scaling notes
  • Parallelism within a consumer group is limited by partition count.
  • Create a dedicated consumer group per independent application.
  • Monitor offsets and lag to ensure consumers keep up.
Key takeaway
Separate consumer groups for separate applications and size partitions to match per-group parallelism requirements.
