Design end-to-end real-time pipelines
Map producers into Event Hubs, design hot/cold branching, and ensure data reaches both dashboards and archival stores without loss. This skill helps you align architecture to SLAs and analytics needs.

02
Implement Lambda Architecture on Azure
Separate a low-latency speed layer and a durable batch layer using Event Hubs, Stream Analytics, and Synapse. This reduces missed alerts while retaining raw data for deep analysis.
VERIFIED COMPETENCY MILESTONE
03
Model streaming data for lakes & warehouses
Choose time-based partitioning, columnar formats, and plan for schema evolution so analytics remain fast and maintainable as data changes.
VERIFIED COMPETENCY MILESTONE
04
Configure outputs for dashboards & analytical stores
Ensure outputs are idempotent, support UPSERT patterns, and route real-time aggregates to dashboards while sending raw events to ADLS Gen2 for batch processing.
