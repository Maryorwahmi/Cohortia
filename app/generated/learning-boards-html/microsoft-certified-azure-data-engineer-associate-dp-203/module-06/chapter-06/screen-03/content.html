Objective Check: Hot vs Cold Routing
Design rules so events are both processed in-stream for alerts and reliably archived via Event Hubs Capture. This avoids data loss while meeting latency needs.
Mnemonic: Branch = Speed + Archive
Objective Check: Format & Partition
Choose Parquet/Avro for capture and partition by year/month/day/hour to speed queries and manage lifecycle.
Mnemonic: Time folders prune faster
Objective Check: Schema Evolution
Adopt formats and tools that support schema changes, and ensure streaming outputs align with target schemas to avoid pipeline failures.
Mnemonic: Evolve, don't break
Objective Check: Idempotent Writes
Design unique keys and UPSERT logic so repeated processing does not create duplicates after restarts.
Mnemonic: Same input → same final state
