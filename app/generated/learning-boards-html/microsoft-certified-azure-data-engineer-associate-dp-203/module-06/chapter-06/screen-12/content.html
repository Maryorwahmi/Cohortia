Reference Joins • Watermarks
Reference data joins
Use ASA for small, infrequently changing reference sets. Use Spark for larger reference data or when enrichment requires complex joins.
Practical Pattern
Load reference data into memory or a small table and refresh it at controlled intervals to keep streaming joins efficient.
Late-arriving events
Use watermarking to limit how long the system retains state for windows, balancing correctness and resource constraints.
Operational Note
Record both event time and ingestion time so you can detect and correct late events in batch processes.
