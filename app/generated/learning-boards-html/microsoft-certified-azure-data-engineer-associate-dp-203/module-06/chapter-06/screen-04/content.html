Core Concept
Architecture • Lambda Pattern
Lambda Architecture Flow
A single ingestion stream splits into a hot path for immediate results and a cold path for archival and batch processing.
Event Hubs — Ingestion
Buffer high-throughput producers, preserve event order per partition, and decouple producers from downstream consumers.
Hot Path — Stream Analytics / Synapse Spark
Low-latency aggregations and alerts; choose ASA for SQL-like transforms, Spark for complex stateful logic or ML.
Cold Path — Event Hubs Capture → ADLS Gen2
Archive raw events for reprocessing, compliance, and batch ML pipelines in Synapse.
Key Takeaway

A reliable pipeline gives you both quick operational insights and a durable raw event store for reprocessing.

Example End-to-End Flow
Producers → Event Hubs. Hot Path: Event Hubs → Stream Analytics → Power BI or Azure SQL. Cold Path: Event Hubs Capture → ADLS Gen2 → Synapse Spark → Synapse SQL Pool → BI tools.
Scenario
Telemetry monitoring for an IoT fleet
Hot path provides minute-level health alerts. Cold path stores raw telemetry for nightly re-processing and model retraining.
Common Mistake
Relying only on hot results without archiving raw events prevents later correction or compliance audits.
Pro Tip
Design the pipeline so capture always writes raw events before downstream destructive transformations run.
