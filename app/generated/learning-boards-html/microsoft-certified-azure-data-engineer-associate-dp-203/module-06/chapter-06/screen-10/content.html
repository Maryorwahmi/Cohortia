Data Modeling
Formats • Schema Evolution
Format tradeoffs
Parquet: columnar, efficient for analytics. Avro: row-structured with embedded schema, efficient for capture and transport.
Practical Rule
Capture to Avro or Parquet; transform to Parquet-backed Delta in curated zone for analytics and schema enforcement.
Common Mistake
Leaving schema-less JSON in raw files makes analytic queries fragile and slow.
Schema Evolution Practices
  • Use formats that support schema evolution (Avro/Parquet).
  • Implement schema checks in ETL to detect breaking changes early.
  • Use Delta Lake features for controlled schema evolution and enforcement in curated tables.
Key Takeaway

Adopt a format and a migration plan so producers can evolve schemas without breaking consumers.
