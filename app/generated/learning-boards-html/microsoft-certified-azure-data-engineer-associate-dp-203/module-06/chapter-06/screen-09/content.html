Storage Design
ADLS Gen2 • Raw & Curated Zones
Raw vs Curated
Raw zone stores Capture files untouched. Curated zone contains Delta tables produced by Spark after cleansing, enrichment, and schema validation.
Partition Example
output/{year}/{month}/{day}/{hour}/data.parquet — this enables efficient time-range queries and retention policies.
Design Note
Avoid extremely fine-grained partitions that create many small files; compact files regularly in the curated zone.
Operational Advice
  • Document partition schemes in a data catalog.
  • Choose partition keys that match query predicates (time is common for telemetry).
  • Use Delta Lake for schema enforcement and transactional writes to the curated zone.
Key Takeaway

Time-based partitions and a clear raw/curated separation make both ingestion and analytics predictable and performant.
