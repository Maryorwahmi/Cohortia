Cold Path
Event Hubs Capture • ADLS Gen2
Configuring Capture
Turn on Capture, select a storage account and container, choose Avro or Parquet, and set a time or size window to balance latency and file size.
Example File Path
telemetry/{Namespace}/{EventHub}/{PartitionId}/{Year}/{Month}/{Day}/{Hour}/data.avro
Pitfall
Using inconsistent naming or no time partitions makes discovery and pruning inefficient for batch jobs.
Processing Cold Path Data
Spark jobs read captured Avro/Parquet files, clean and enrich them, then write curated data into Delta Lake in ADLS Gen2 for analytical queries.
Key Takeaway
Capture creates durable raw archives. Design folder paths and formats to make downstream batch processing efficient and repeatable.
