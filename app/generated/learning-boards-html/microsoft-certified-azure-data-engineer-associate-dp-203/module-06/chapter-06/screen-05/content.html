Ingestion Layer
Event Hubs • Capture
Event Hubs — Key Responsibilities
  • High-throughput ingestion with partitioning for parallel reads.
  • Decoupling producers and consumers to isolate spikes.
  • Support for Event Hubs Capture to write raw events to ADLS Gen2.
Design Tip
Choose partition keys that keep order where necessary but distribute load broadly to avoid hot partitions.
Event Hubs Capture Example
Capture writes files to ADLS Gen2 using a predictable folder scheme so batch jobs can discover and process raw events.
telemetry/{Namespace}/{EventHub}/{PartitionId}/{Year}/{Month}/{Day}/{Hour}/data.avro
Common Mistake
Not configuring Capture with a stable file naming pattern makes discovery and downstream batch processing brittle.
