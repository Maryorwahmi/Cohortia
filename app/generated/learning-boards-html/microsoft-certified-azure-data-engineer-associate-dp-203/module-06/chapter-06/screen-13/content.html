Process Flow
Sinks • Dashboards • Analytics
Dashboard outputs
Emit short-window aggregates to Power BI or operational DBs so teams have near-real-time visibility. Keep these aggregates lightweight and focused on operational actions.
Example
Compute a 1-minute failure rate and push to Power BI for an on-call dashboard that triggers alerts.
Analytical sinks
Load curated Delta tables into Synapse SQL Pools for high-performance reporting and historical analysis. Use batch jobs to reshape raw capture data into analytics-ready schemas.
Key Takeaway

Design separate sinks for operational dashboards and for analytical stores, and ensure both have schema and idempotency guarantees.
