Hot Path
Stream Analytics • Low-latency Aggregation
When to pick ASA
  • SQL-like windowed aggregations and simple joins against small reference sets.
  • Direct outputs to Power BI or Azure SQL for real-time dashboards.
  • Lightweight transforms with minimal operational overhead.
Example
Compute a 1-minute average of sensor readings and push to Power BI for near-real-time visualization.
ASA Considerations
Plan outputs carefully: align ASA output schema with the target store and ensure downstream writes are resilient to restarts.
Common Misconception
ASA cannot join to reference data—ASA supports reference joins but they work best with small, slowly changing sets.
Key Takeaway
Use ASA for fast, SQL-driven transforms and route operational metrics directly to dashboards or operational databases.
