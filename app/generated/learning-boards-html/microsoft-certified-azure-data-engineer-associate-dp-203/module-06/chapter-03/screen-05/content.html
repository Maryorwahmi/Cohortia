Module 6 › Chapter 6.3 › Job Topology
Inputs
Event Hubs, IoT Hub, Blob/ADLS Gen2 as sources or reference data.
Event Hubs
High-throughput device and application events; common choice for telemetry ingestion.
IoT Hub
Device-aware ingestion with device identities and management features.
Blob / ADLS Gen2
Reference or cold data used to enrich or join streaming events.
Query & Outputs
Write SAQL queries and choose where processed data lands.
Query (SAQL)
Temporal windowing, filters, joins, and pattern detection to express streaming logic.
Outputs
Power BI, Blob/ADLS, SQL Database, Event Hubs, Service Bus, Cosmos DB, or Azure Functions.
Concrete scenario

Join device metadata stored in Blob with live telemetry from Event Hubs to produce enriched records sent to SQL Database for reporting.
