Common inputs
Event Hubs, IoT Hub, Blob/ADLS Gen2

Use Event Hubs for raw high-throughput streams. Use IoT Hub when device management and identities matter. Use Blob/ADLS for reference data or cold path processing.

Give each input a clear alias; the SAQL query references these aliases directly.

Set serialization to match your events, typically JSON with UTF-8 encoding.

Practical checklist
  • Choose the correct Event Hub and consumer group for parallel reads.
  • Verify JSON schema and field names against your SAQL query.
  • Sample incoming events to catch serialization mismatches early.
Example input setup
Input Alias: TelemetryInput • Source: Event Hub 'telemetry-events' • Serialization: JSON • Encoding: UTF-8 • Consumer Group: analytics-app-group
Common mistake

Using the default consumer group for multiple consumers can lead to conflicting offsets; create a dedicated consumer group for analytics.
