Module 6 › Chapter 6.3 › Configuring Outputs
Common outputs
Power BI, Blob/ADLS, SQL Database, Event Hubs, Service Bus, Cosmos DB, Azure Functions.
Power BI
Real-time dashboards and visualizations.
Blob / ADLS Gen2
Archive processed data or store snapshots for cold analysis.
Azure Functions
Invoke custom logic or alerts from processed events.
Practical tips
  • Set JSON serialization and encoding consistently between ASA outputs and downstream consumers.
  • For Blob outputs, configure path patterns and write batching (minimum rows or max time) to balance latency and cost.
  • Validate that the chosen sink handles peak write throughput to avoid backpressure.
Concrete example

Send aggregated telemetry to Power BI for visualization and store the same aggregates to Blob with a path pattern like output/{date}/{time} for archival and auditing.
