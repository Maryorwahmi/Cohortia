Module 6 › Chapter 6.3 › Serverless & SUs
Serverless model
No VMs to manage; define processing capacity using Streaming Units.

SUs represent compute and memory available to your job and are adjustable to match throughput.

Azure manages infrastructure and scaling details while you focus on query logic.

Monitoring checklist
  • Observe SU utilization during representative load tests.
  • Monitor job lag and throughput metrics to detect backpressure.
  • Adjust SUs to avoid throttling while minimizing cost.
Pro tip

Start with a small number of SUs for testing, observe behavior, then increase only as needed to meet latency targets.
