Query example
This query computes average temperature per device every minute using a tumbling window.
SELECT
  DeviceId,
  AVG(temperature) AS AvgTemp,
  System.Timestamp() AS WindowEnd
INTO
  ProcessedOutputBlob
FROM
  TelemetryInput
GROUP BY
  DeviceId,
  TUMBLINGWINDOW(minute, 1)

Here TelemetryInput is the Event Hub input alias, and ProcessedOutputBlob is a Blob or ADLS output. System.Timestamp provides the window timestamp for downstream context.

Why this matters
Aggregating into windows reduces downstream data volume, stabilizes metrics, and makes dashboards more responsive.
Misconception check
Don't assume tumbling windows tolerate late arrivals automatically; consider event time and allowed lateness in production designs.
Key Takeaway

Use tumbling windows for fixed interval summaries; choose timestamps carefully to maintain correctness.
