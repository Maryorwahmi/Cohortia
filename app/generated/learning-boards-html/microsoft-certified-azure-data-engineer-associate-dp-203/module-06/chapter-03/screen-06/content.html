Module 6 › Chapter 6.3 › SAQL
What SAQL gives you
Windowing, temporal joins, pattern detection, and familiar SQL syntax.

Use tumbling windows for fixed, non-overlapping intervals and hopping windows when you need overlapping intervals.

Join streaming data with static reference data for enrichment, or join two streams for correlating event sources.

Consider event time semantics and late-arriving events when you define windowing behavior to preserve correctness.

Design considerations
  • Choose the timestamp field used for windowing and ensure clocks are aligned.
  • Decide how to handle late data — stateful windows may need extra allowances.
  • Hopping windows produce overlapping results; tumbling windows do not.
Example use
Compute rolling metrics, detect patterns of events, and enrich streams for downstream storage or alerts.
Common mistake

Using ingestion time rather than event time for windowing can lead to incorrect groupings when events arrive late or out of order.
