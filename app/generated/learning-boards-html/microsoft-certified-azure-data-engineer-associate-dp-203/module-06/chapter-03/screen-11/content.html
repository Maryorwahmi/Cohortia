Module 6 › Chapter 6.3 › Hands-on: Create Job
Lab checklist
A guided sequence to set up an ASA job and validate it.
Step 1 — Prerequisites
Event Hubs namespace, Event Hub, Storage account with container.
Step 2 — Create job
Create Stream Analytics job, select resource group and set SUs to 1 for tests.
Step 3 — Add input
Add Event Hub input alias TelemetryInput, choose consumer group, set JSON/UTF-8.
Step 4 — Add output
Add Blob output alias ProcessedOutputBlob, select container, set path pattern and batching.
Step 5 — Write query
Compose SAQL to filter and aggregate, reference input and output aliases.
Step 6 — Test & monitor
Run job, sample outputs, check SU utilization and job lag metrics.
Why it matters

Following the configure-test-monitor cycle ensures your ASA job processes events correctly and scales reliably under real traffic.
