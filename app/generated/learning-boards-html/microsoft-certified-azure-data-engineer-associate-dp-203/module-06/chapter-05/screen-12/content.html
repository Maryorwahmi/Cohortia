Module 6 › Chapter 6.5 › Checkpointing
What is checkpointing?
Checkpointing persists offsets, aggregation state, and query progress into durable storage so a query can resume after a failure without reprocessing or losing data.
Ensure the checkpoint path points to ADLS Gen2 or another fault-tolerant store and is accessible by the Spark pool.
Example & caution
Example option: .option("checkpointLocation", "/delta/checkpoints/avg_temp"). Caution: checkpointing helps Spark recover, but sinks must support idempotent or transactional writes for full exactly-once guarantees.
Question: After a restart, what two components are necessary for correct recovery? (Answer: checkpoint metadata and sink idempotency/transaction semantics.)
