Module 6 › Chapter 6.5 › Event Hubs connector
Configuration snippet (concept)
eh_conf = {
  'eventhubs.connectionString': '<encrypted-connection-string>',
  'eventhubs.consumerGroup': '$Default',
  'eventhubs.eventHubName': 'telemetry-events',
  'eventhubs.startingPosition': '-1'
}
Ensure the connection string is encrypted or retrieved from Key Vault. Use a distinct consumer group per application.
Practical checks
  • Confirm Event Hub partitions and set Spark parallelism to read across them.
  • Test startingPosition during development and switch to latest for production runs to avoid replaying old data unintentionally.
  • Validate consumer group offsets after a restart to ensure correct resume behavior.
