Module 6 › Chapter 6.5 › Lab walkthrough
Notebook step highlights
  1. Attach the notebook to your Synapse Spark pool.
  2. Connector ensure the Event Hubs connector is installed or available on the pool.
  3. Secrets retrieve connection string from Key Vault or managed identity.
  4. Schema define StructType for incoming JSON.
  5. Read with readStream, parse the body, and select fields.
  6. Aggregate with withWatermark and window to compute one-minute averages.
  7. Checkpoint set checkpointLocation in ADLS Gen2 before starting the query.
  8. Sink write to Delta or use foreachBatch for JDBC sinks, then test restart recovery.
Common mistakes
  • Hardcoding secrets in notebook cells.
  • Omitting checkpointLocation before starting the query.
  • Using arrival time instead of event-time for windowing.
Pro tip: run the query to console first to validate parsing before switching to production sinks.
