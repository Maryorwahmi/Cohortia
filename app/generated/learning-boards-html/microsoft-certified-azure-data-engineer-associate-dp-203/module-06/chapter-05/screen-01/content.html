Real-time analytics with Synapse Spark
A practical, code-first path for large-scale, stateful stream processing.

When your processing needs custom logic, model scoring, or complex stateful joins, Spark Structured Streaming inside Synapse lets you code in PySpark and connect to Delta Lake and ML libraries.

Key operational patterns include configuring a Spark pool, using the Event Hubs connector, defining a schema for incoming JSON, applying watermarks for late data, and checkpointing state in ADLS Gen2.

We will walk through code examples, ingestion, windowed aggregations, and sinks so you can run a notebook-based streaming job in a Synapse workspace.
