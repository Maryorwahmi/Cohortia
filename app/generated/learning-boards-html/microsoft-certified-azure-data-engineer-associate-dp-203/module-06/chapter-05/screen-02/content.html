Module 6 › Chapter 6.5 › Learning Objectives
01
Compare ASA vs Spark
Understand trade-offs between a managed SQL-style engine and a code-first Spark pipeline.
You will learn to match workload complexity, language needs, and operational tolerance to the right service. For example, choose ASA for simple streaming aggregations and Spark when you need custom logic or model scoring.
VERIFIED COMPETENCY MILESTONE
02
Provision Spark pool
Configure node sizes, autoscale, and session settings for streaming workloads in Synapse.
You will know which pool settings affect latency, parallelism, and cost. This matters because under-provisioned pools can cause backpressure, and over-provisioning increases cost.
VERIFIED COMPETENCY MILESTONE
03
Ingest from Event Hubs
Use the Spark Event Hubs connector with secure connection strings and consumer groups.
You will practice configuring starting positions and consumer groups, and learn to secure secrets with Key Vault or managed identities instead of hardcoding them.
VERIFIED COMPETENCY MILESTONE
04
Transform and sink
Apply windowed aggregations, watermarks, and write to Delta Lake or databases using foreachBatch.
You will understand when to use append versus update modes, checkpointing paths, and how foreachBatch allows transactional writes to sinks without a streaming connector.
VERIFIED COMPETENCY MILESTONE
