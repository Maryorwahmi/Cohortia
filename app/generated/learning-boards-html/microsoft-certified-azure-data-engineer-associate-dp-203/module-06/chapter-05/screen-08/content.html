Why explicit schema
Explicit schemas prevent parsing errors, ensure predictable column types, and act as a contract with event producers. They reduce surprises during long-running streaming jobs.
Analogy: schema is like a phone number format. If some senders change format unexpectedly, downstream systems fail unless you define and validate the expected shape.
Example StructType
json_schema = StructType([
  StructField("deviceId", StringType(), True),
  StructField("temperature", DoubleType(), True),
  StructField("humidity", DoubleType(), True),
  StructField("timestamp", StringType(), True)
])
Tip: version and document the schema so producers and consumers remain aligned.
