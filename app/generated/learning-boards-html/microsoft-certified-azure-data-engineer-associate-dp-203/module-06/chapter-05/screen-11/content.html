Pattern for JDBC writes
query = windowed_avg_df.writeStream
  .foreachBatch(lambda df, epoch_id: df.write.jdbc(url=jdbc_url, table="RealtimeDeviceAverages", mode="append", properties=jdbc_properties))
  .outputMode("update")
  .option("checkpointLocation", "/delta/checkpoints/sql_sink")
  .start()
Use foreachBatch to apply upsert logic or batch-specific transforms before writing to relational systems.
Operational tips
  • Ensure JDBC driver is available in the Spark pool.
  • Manage retries and idempotency to handle transient failures.
  • Monitor batch sizes to avoid database throttling.
Common mistake: treating foreachBatch like a single-record writer. It runs per micro-batch and should use batch writes for efficiency.
