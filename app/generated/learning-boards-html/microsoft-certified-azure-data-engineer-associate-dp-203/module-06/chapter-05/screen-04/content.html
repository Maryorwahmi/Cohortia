Azure Stream Analytics
Managed, SQL-like stream processing.
  • Pros: serverless, low ops, quick to set up for dashboards and simple joins.
  • Cons: limited language support and less flexible for custom code or ML.
  • When to use: simple aggregations, event filtering, and time-windowed metrics for real-time dashboards.
Misconception: managed always means cheaper. Evaluate workload size and transformation complexity.
Spark Structured Streaming (Synapse)
Code-first streaming using Spark in a Synapse Spark pool.
  • Pros: supports Python/Scala/Java/.NET, deep Delta Lake and ML integration, great for complex stateful logic.
  • Cons: more operational setup, requires Spark expertise, manage pool configuration.
  • When to use: stateful aggregations, model scoring per event, large-scale pipelines, and reuse of Spark libraries.
Real example: sessionization and per-event ML inference at scale typically favors Spark Structured Streaming.
