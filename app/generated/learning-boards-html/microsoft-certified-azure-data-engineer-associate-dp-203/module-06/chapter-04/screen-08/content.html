SLIDINGWINDOW example
Event-driven counts for immediate detection
SELECT
    System.Timestamp AS WindowEnd,
    COUNT(*) AS EventCount
FROM
    TelemetryInput TIMESTAMP BY EventEnqueuedUtcTime
GROUP BY
    SLIDINGWINDOW(second, 10)
HAVING
    EventCount > 50
Use case
Detect traffic spikes or rapid sequences like error bursts within short intervals.
Misconception
Don't confuse sliding with tumbling. Sliding outputs more frequently and is event-driven, not fixed-tick.
Key Takeaway
Choose sliding windows when you need immediate, event-driven detection of changing conditions.
