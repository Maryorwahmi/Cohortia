Safe casting pattern
Filter invalid conversions before aggregation
SELECT
  deviceId,
  CAST(temperature AS float) AS TemperatureFloat
FROM
  TelemetryInput
WHERE
  TRY_CAST(temperature AS float) IS NOT NULL
Why TRY_CAST first?
TRY_CAST avoids exceptions by returning NULL for bad values so you can explicitly filter them out.
Watch out
Replacing NULLs with defaults can bias aggregates. Prefer filtering or logging invalid rows for investigation.
Key Takeaway

Always validate conversions with TRY_CAST before aggregating; treat converted NULLs explicitly rather than hiding them.
