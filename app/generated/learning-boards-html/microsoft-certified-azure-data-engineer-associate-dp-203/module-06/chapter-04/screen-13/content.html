Module 06 › Chapter 6.4 › Best practices
Production checklist
Operational practices to keep streaming jobs reliable
Simplify logic
Break complex queries into smaller jobs if joins or windowing cause large state.
Timestamp accuracy
Always TIMESTAMP BY the most reliable event time field to avoid mis-assigned windows.
Monitor resources
Watch SU utilization, job lateness, and output rates; tune windows and joins accordingly.
Handle late events
Tune allowed lateness or use session windows. Be aware increased tolerance raises state requirements.
Key Takeaway
Design for observability: test, monitor SU, and iterate on window sizes and joins to stay within resource limits.
