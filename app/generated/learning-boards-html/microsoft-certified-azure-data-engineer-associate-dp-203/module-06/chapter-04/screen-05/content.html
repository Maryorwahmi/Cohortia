Module 06 › Chapter 6.4 › Windowing fundamentals
Why windows matter
Windows turn infinite streams into bounded groups for aggregation and pattern detection.
Window types — quick map
  • Tumbling: fixed, non-overlapping. One event belongs to exactly one window.
  • Hopping: fixed size but overlapping; hops forward by a period for moving averages.
  • Sliding: outputs when events enter or exit, good for burst detection.
  • Session: groups events into sessions separated by gaps beyond a timeout.
Analytic examples
Periodic reports: Tumbling windows for hourly metrics.
Moving average: Hopping window, e.g., 5-minute window every minute.
Burst detection: Sliding window to alert on sudden surges of events.
Sessionization: Session windows to assemble user activity with gaps.
Misconception
Window choice is not just technical. Choose it to match the business question and latency requirements.
Key Takeaway
Map your analytic goal to the right window type before tuning sizes or hop intervals.
