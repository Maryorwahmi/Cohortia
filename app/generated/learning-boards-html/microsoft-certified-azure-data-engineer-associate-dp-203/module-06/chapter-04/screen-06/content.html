TUMBLINGWINDOW example
Fixed, contiguous buckets for periodic metrics
SELECT
    System.Timestamp AS WindowEnd,
    deviceId,
    AVG(TRY_CAST(temperature AS float)) AS AverageTemperature
FROM
    TelemetryInput TIMESTAMP BY EventEnqueuedUtcTime
GROUP BY
    deviceId,
    TUMBLINGWINDOW(minute, 5)
Outcome
Every five minutes you'll get one aggregate per device with WindowEnd indicating the interval end.
Pitfall
Very small tumbling windows increase output frequency and SU usage; choose size to balance latency and compute.
Quick checklist
  • Confirm TIMESTAMP BY points to the correct field.
  • Decide window size by reporting cadence and latency needs.
  • Test with sample input to ensure expected assignment to windows.
Key Takeaway

Tumbling windows are predictable and easy to reason about; use them when you need periodic summaries.
