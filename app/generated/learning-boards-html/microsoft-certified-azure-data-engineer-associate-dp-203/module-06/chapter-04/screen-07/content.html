HOPPINGWINDOW pattern
Overlapping windows for regular rolling summaries
SELECT
    System.Timestamp AS WindowEnd,
    AVG(TRY_CAST(temperature AS float)) AS MovingAverageTemperature
FROM
    TelemetryInput TIMESTAMP BY EventEnqueuedUtcTime
GROUP BY
    HOPPINGWINDOW(minute, 5, 1)
When to use
Dashboards needing frequent refreshed trends, where each update uses multiple minutes of history.
Performance note
Overlapping windows increase SU usage. Measure and adjust hop size to control output volume.
Key Takeaway
Hopping windows trade extra compute for smoother, more frequent insights.
