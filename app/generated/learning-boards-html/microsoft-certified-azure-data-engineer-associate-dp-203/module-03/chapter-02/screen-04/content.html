Core Concept

What is ADLS Gen2?

A capability set on StorageV2 that adds a hierarchical namespace for directories and files plus POSIX-like ACLs for fine-grained security.

Analogy
Think of Blob Storage as a warehouse of crates. Enabling HNS gives you labeled shelving and aisles so workers can find and move groups of crates fast.
Common misconception
ADLS Gen2 is a separate product. In reality it is StorageV2 with the HNS feature enabled.
Visual: definition + properties
Properties
  • Hierarchical namespace for directories and files
  • POSIX-like ACLs for fine-grained access
  • Built on StorageV2: durability and scale
Why it matters
  • Fast directory listing and deletes
  • Atomic renames needed by Spark/Hadoop
  • Fine-grained file permission model
Example
A Spark job writes to /staging/job123 then atomically renames to /processed/job123. HNS enables this rename to be efficient and reliable.
Key Takeaway
Enable HNS for analytics workloads and combine RBAC with ACLs for security.
