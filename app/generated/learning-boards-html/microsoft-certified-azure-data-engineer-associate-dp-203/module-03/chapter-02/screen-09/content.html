Create storage account with HNS

Run these CLI steps to create a StorageV2 account with hierarchical namespace enabled.

# Define variables
RESOURCE_GROUP="my-adlsgen2-rg"
STORAGE_ACCOUNT_NAME="myadlsgen2account12345"
LOCATION="eastus"

# Create resource group
az group create --name $RESOURCE_GROUP --location $LOCATION

# Create StorageV2 account with hierarchical namespace
az storage account create \
  --name $STORAGE_ACCOUNT_NAME \
  --resource-group $RESOURCE_GROUP \
  --location $LOCATION \
  --sku Standard_LRS \
  --kind StorageV2 \
  --hns true
Notes
Storage account name must be globally unique. The --hns true flag is the essential toggle to enable ADLS Gen2 features.
Common mistake
Creating a general purpose account without setting kind to StorageV2 or forgetting the hns flag will not provide HNS features.
Key Takeaway
Use --kind StorageV2 and --hns true when creating the account to enable ADLS Gen2 capabilities.
