Issue & Remedy

Small File Problem

Each small file increases metadata operations and task overhead in distributed engines. Jobs can become I/O-bound on metadata rather than data reads.

Use columnar formats like Parquet and compact small files into larger ones during batch windows to minimize overhead.

Recommendation
Target file sizes between 256MB and 1GB, depending on read patterns and cluster configuration.
Key Takeaway
Avoid many tiny files; choose columnar formats and include compaction steps to aggregate small files.
