Module 3 › Chapter 3.2 › Hands-on Outcomes
Practical CLI milestones
  • • Create StorageV2 with HNS enabled.
  • • Create a file system and nested directories.
  • • Upload data to a partitioned path and list the directory contents.
  • • Set and verify POSIX-like ACLs for users or service principals.
Assessment hint
Show the CLI output that contains the ACL entry and the account name to demonstrate competency.
When you practice, remember to use Azure AD identities for ACLs, not storage account keys for day-to-day permission assignments in production.
