Best Practice

Folder and Partition Strategy

  • /raw for ingested data, /processed for ETL outputs, /curated for consumable datasets.
  • Date partitioning example: /year=2023/month=10/day=26/ so queries scan only relevant partitions.
  • Use Parquet or ORC for columnar storage and compression to speed reads and reduce costs.
  • Aim for file sizes around 256MB to 1GB to avoid the small file problem.
Example layout
/raw/sourceA/year=2023/month=10/
Why it matters
Query engines prune partitions by path. Well-designed partitions reduce scanned data and cost.
Key Takeaway
Structure folders around how consumers filter data and target larger file sizes for efficiency.
