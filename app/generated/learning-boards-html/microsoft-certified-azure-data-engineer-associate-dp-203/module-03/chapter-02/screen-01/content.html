Azure Data Lake Storage Gen2

Combine Blob Storage scale with a hierarchical file system and POSIX-like ACLs to run analytics at scale, avoid metadata bottlenecks, and secure files and folders precisely.

Core idea
StorageV2 + HNS
Enable the hierarchical namespace flag when creating a StorageV2 account to get ADLS Gen2 capabilities. This unlocks directory and file semantics for analytics engines.
Explore Key Topics
HNS
True directories and files for fast listings and atomic operations.
ACLs
POSIX-like ACLs for fine-grained control on files and folders.
Partitioning
Logical folders and date partitions to speed queries and reduce costs.
Coming up
CLI steps to create ADLS Gen2, create file systems, upload files, and set ACLs, plus best practices for file format and sizes.
