Definition

POSIX-like ACLs

ACL entries map an Azure AD identity to permissions: read (r), write (w), execute (x). Use default ACLs to inherit permissions to new children.

Why execute matters
Without execute on a directory, users cannot traverse into child folders even if they have read on a child file.
Example ACL entry
user:01234567-89ab-cdef-0123-456789abcdef:rwx
group:89abcdef-0123-4567-89ab-cdef01234567:r-x
default:group:89abcdef-0123-4567-89ab-cdef01234567:r-x
First line grants a user read, write, execute on the object. Default entries ensure inheritance.
Common mistake
Granting permissions only with RBAC and not configuring ACLs on directories, leaving files inaccessible at runtime.
Key Takeaway
Use Azure AD identities and default ACLs to ensure predictable access across new and existing files.
