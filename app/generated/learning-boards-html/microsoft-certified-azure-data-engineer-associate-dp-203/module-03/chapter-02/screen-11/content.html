ACL Commands
# Get your signed-in user object ID
USER_OBJECT_ID=$(az ad signed-in-user show --query id --output tsv)

echo "Your User Object ID: $USER_OBJECT_ID"

# Grant read and execute permissions to a directory
TARGET_DIR="raw/marketing"
az storage fs access set \
  --acl "user:$USER_OBJECT_ID:r-x" \
  --path $TARGET_DIR \
  --file-system $FILE_SYSTEM_NAME \
  --account-name $STORAGE_ACCOUNT_NAME \
  --account-key $STORAGE_ACCOUNT_KEY

# Verify ACLs
az storage fs access show \
  --path $TARGET_DIR \
  --file-system $FILE_SYSTEM_NAME \
  --account-name $STORAGE_ACCOUNT_NAME \
  --account-key $STORAGE_ACCOUNT_KEY
Important
Use Azure AD object IDs for ACLs. Prefer groups or service principals for scalable permission management.
Common mistake
Missing execute on directories blocks access even when file ACLs permit read.
Key Takeaway
After setting ACLs, verify them and use defaults for predictable inheritance on new objects.
