Module 3 › Chapter 3.4 › Assessment
Sample questions
Question
Store user preferences for millions of users used by userId.
Answer: Table Storage
PartitionKey: userId; RowKey: 'preferences'. Point query on userId is efficient and cheap.
Question
Decouple ingestion from long-running processing and ensure retry on failure.
Answer: Queue Storage
Visibility timeout ensures message reprocessing if consumer fails to delete it.
Key Takeaway
Answer assessment items by describing how keys or queue features satisfy the required access pattern and failure semantics.
