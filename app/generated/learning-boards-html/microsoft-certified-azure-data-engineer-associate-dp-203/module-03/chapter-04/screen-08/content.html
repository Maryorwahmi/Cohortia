Module 3 › Chapter 3.4 › Queue SDK
Example flow
Create or get a queue, send messages, peek for visibility, receive with timeout, process, and delete. Use visibility timeout tuned to processing duration.
Pro tip
Track DequeueCount to identify poison messages and implement dead-lettering logic outside the queue when needed.
Python snippet
from azure.storage.queue import QueueServiceClient

# Initialize
queue_service = QueueServiceClient.from_connection_string(conn_str=CONNECT_STR)
queue_client = queue_service.get_queue_client(queue="orderqueue")
queue_client.create_queue()

# Send messages
queue_client.send_message("Order_101_Processed")

# Peek
peeked = queue_client.peek_messages(max_messages=5)
for m in peeked:
  print(m.content)

# Receive and delete
messages = queue_client.receive_messages(messages_per_page=1, visibility_timeout=30)
for msg in messages:
  # process payload
  queue_client.delete_message(msg.id, msg.pop_receipt)
Key Takeaway
Implement idempotent processing and tune visibility timeout to avoid duplicate work while allowing recovery on failure.
