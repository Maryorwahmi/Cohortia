Module 3 › Chapter 3.4 › Table CRUD
Walkthrough
Initialization, insert/upsert, query, update, delete
Initialization
Create a TableServiceClient from a connection string and then get_table_client for your table name.
Insert / Upsert
Use upsert_entity to avoid separate insert/replace logic in simple flows.
Querying
Use get_entity for point queries and query_entities for partition or filtered reads.
Example Python snippet
from azure.data.tables import TableServiceClient, TableEntity

# Assume CONNECT_STR is set as shown earlier
table_service = TableServiceClient.from_connection_string(conn_str=CONNECT_STR)
table_client = table_service.get_table_client(table_name="SensorReadings")

# Upsert entities
entity = TableEntity(PartitionKey="SensorA", RowKey="20231026_001", Temperature=25.5, Humidity=60)
table_client.upsert_entity(entity=entity)

# Point query
entity = table_client.get_entity(partition_key="SensorA", row_key="20231026_001")
print(entity.get('Temperature'))

# Update (merge)
update = TableEntity(PartitionKey="SensorA", RowKey="20231026_001", Status="Online")
table_client.update_entity(entity=update)

# Delete
table_client.delete_entity(partition_key="SensorB", row_key="20231026_001")
Key Takeaway
Practice these calls in a sandbox and handle exceptions for idempotent creation and transient failures.
