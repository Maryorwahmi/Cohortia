Learning Objectives
Four skill-focused milestones you can verify
01
Explain Table entity model
Describe PartitionKey and RowKey, and why point queries are the most efficient. Useful for modeling user preferences and telemetry.
VERIFIED COMPETENCY MILESTONE
02
Design keys for performance
Create PartitionKey/RowKey strategies to favor point and partition queries and avoid cross-partition scans.
VERIFIED COMPETENCY MILESTONE
03
Implement queue message flows
Enqueue, peek, receive with visibility timeout, and delete; ensure idempotent processing when retries occur.
VERIFIED COMPETENCY MILESTONE
04
Choose cost-effective services
Recognize when Table and Queue meet scale and cost needs versus heavier services like a relational database.
