Module 3 › Chapter 3.4 › IoT pipeline
Pattern
Devices enqueue messages → Workers process → Table stores entities
Decoupling
Producer and consumer scale independently; queue buffers load spikes.
Durability
Processed data is stored in Table Storage for query and analysis.
Blob for large payloads
If messages exceed limits, store payload in Blob and put reference in the queue message.
Responsibilities
  1. Producer: send small message or blob reference
  2. Worker: receive, process, upsert entity, delete message
  3. Table: durable store for processed entities and queries
Key Takeaway
Use the pattern to scale ingestion, ensure retries, and keep tables optimized for queries you need.
