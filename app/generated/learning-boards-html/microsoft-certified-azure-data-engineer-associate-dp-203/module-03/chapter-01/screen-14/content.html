Module 3 › Chapter 3.1 › Hands-on: Create, Upload, and Generate a SAS
Activity steps
  1. Set up environment: az login and pip install azure-storage-blob.
  2. Create resource group and storage account via az group create and az storage account create.
  3. Retrieve an account key and create a container with az storage container create.
  4. Upload sales.csv using the Python snippet; verify the blob name appears in container listing.
  5. Generate a read-only SAS token for the blob with a short expiry and test the URL in a browser.
  6. Clean up with az group delete when finished.
Validation checks
  • Can you list the blob with az storage blob list?
  • Does the SAS URL open the file content in the browser?
  • Is the SAS expiry time short enough for your use case?
Key Takeaway

This activity demonstrates the create-upload-serve loop and highlights secure temporary access patterns using SAS.
