Module 3 › Chapter 3.1 › Storage Account, Containers, and Blob Organization
Hierarchy

Account → Container → Blob

Containers: use separate containers for raw, processed, and logs to simplify access control and lifecycle rules.
Blob naming: include source and date partitions in names to support partitioned queries and parallel processing.
Documentation: publish naming and retention policies so pipeline owners follow conventions.
Concrete naming example
raw/sensorA/2023/10/01/part-000.csv — this supports efficient listing by date and source and makes lifecycle rules straightforward to target.
Key Takeaway

Consistent container and blob naming enables automation, secure scoping, and cost control for your data lake.
