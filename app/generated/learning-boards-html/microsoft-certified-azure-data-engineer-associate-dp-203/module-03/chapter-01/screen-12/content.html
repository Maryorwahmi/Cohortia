Module 3 › Chapter 3.1 › Managed Identities and Secure Authentication
Pattern

Assign identity, grant RBAC, use token

Step 1: Enable a system-assigned or user-assigned identity on the Azure resource.
Step 2: Grant the identity a Storage Blob Data role scoped to the container or storage account.
Step 3: Let the resource obtain a token and call Blob Storage without keys in code.
Concrete example
Assign a managed identity to a data factory pipeline, then grant that identity contributor access to a container so the pipeline can write transformation outputs without storing credentials.
Note
Managed identities work only for Azure resources. For external clients, combine SAS tokens with secure distribution and short expiries.
