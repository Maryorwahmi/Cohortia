Module 3 › Chapter 3.1 › Learning Objectives — Applied Skills
01
Create Storage Accounts & Containers
Use the CLI to provision a storage account and container with chosen SKU and kind, important for redundancy and access patterns.
Mnemonic: "Account first, container next."
02
Upload with Python SDK
Programmatically upload files and use blob paths to create virtual directories that help organize data for processing pipelines.
Mnemonic: "Path-based order."
03
Generate Short-Lived SAS
Produce time-limited, scoped tokens for third-party tools so you never expose account keys in production systems.
Mnemonic: "Token, scope, expire."
04
Use Managed Identities
Assign identities to Azure resources to authenticate to Blob Storage without credentials in code, improving security and rotation.
Mnemonic: "Identity, not keys."
How to practice
  1. Create a trial resource group and storage account via CLI.
  2. Upload a small CSV using the provided Python snippet.
  3. Generate a short SAS and verify browser access.
