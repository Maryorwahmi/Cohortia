Module 3 › Chapter 3.1 › Lifecycle Management Policies
Process

Create rules that move or delete data

Example policy
If blob name starts with "raw/" and age > 30 days → move to Cool. If age > 365 days → move to Archive. If tag "temp:true" exists and age > 7 days → delete.
Testing approach
Apply on a small container, wait one policy cycle, and verify transitions and access latency before enabling org-wide rules.
Practical tips
  • Use blob index tags to selectively manage objects without changing names.
  • Keep archive windows long enough to avoid repeated rehydration costs.
  • Monitor lifecycle actions to detect unexpected deletions or transitions.
