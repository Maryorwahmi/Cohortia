Module 3 › Chapter 3.1 › Blob Types: Block, Page, and Append
Comparison

Block vs Page vs Append

Block Blob
Large file uploads, parallel block commits, ideal for data lake files and streaming large datasets.
Page Blob
Random read/write at 512-byte page granularity; used for VM virtual hard drives, not general data lake files.
Append Blob
Append-only writes, ideal for logging where new records are continuously added to the end.
Example scenarios
  • Nightly parquet outputs from ETL → use block blobs for parallel upload and efficient reads.
  • Streaming application logs → use append blobs to avoid concurrent writes conflicts.
  • VM disk images → use page blobs for random I/O patterns needed by virtual machines.
Misconception
Choosing page blobs for general file storage because of perceived performance; page blobs are specialized and more expensive for non-VM scenarios.
Key Takeaway

Pick the blob type that matches your read/write pattern: block for files, append for logs, page for VM disks.
