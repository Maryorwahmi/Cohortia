Module 3 › Chapter 3.1 › Generating SAS Tokens with Azure CLI
CLI snippet
BLOB_SAS_TOKEN=$(az storage blob generate-sas \
  --account-name $STORAGE_ACCOUNT_NAME \
  --container-name $CONTAINER_NAME \
  --name $blob_name \
  --permissions r \
  --expiry $(date -u -d "30 minutes" '+%Y-%m-%dT%H:%MZ') \
  --output tsv \
  --account-key $STORAGE_ACCOUNT_KEY)

BLOB_URL="https://$STORAGE_ACCOUNT_NAME.blob.core.windows.net/$CONTAINER_NAME/$blob_name?$BLOB_SAS_TOKEN"
echo "Access URL with SAS: $BLOB_URL"
The command returns a token string you append to the blob URL. Do not hardcode the token; generate it programmatically when needed and give it minimal permissions.
Permissions quick guide
  • r = read
  • w = write
  • d = delete
  • l = list
Test the URL in a browser to verify correct scope and that denied operations return access errors. Revoke access by regenerating account keys or deleting the resource.
