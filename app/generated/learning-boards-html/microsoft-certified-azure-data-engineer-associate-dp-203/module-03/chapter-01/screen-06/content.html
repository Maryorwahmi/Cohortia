Process Flow

Designing a tier lifecycle

Hot
Frequent access; lower access costs, higher storage cost. Use for newly ingested data and active processing.
Cool
Infrequent access; lower storage, higher access cost; suitable for data retained for weeks or months.
Archive
Rare access; lowest storage cost, highest retrieval cost and latency; use for long-term retention.
Lifecycle example
  1. Ingest raw files into Hot for 7 days while processing runs.
  2. After 30 days, transition processed outputs to Cool for analytics that run monthly.
  3. After 365 days, transition to Archive for compliance retention.
Checklist
  • Measure current read/write frequency before choosing a tier.
  • Set lifecycle rules with safety windows to avoid premature archival.
  • Monitor retrieval costs after moving to Cool or Archive.
Pitfall
Archiving data that will be queried occasionally leads to long waits and high retrieval charges. Consider Cool as an intermediate step.
