Module 3 › Chapter 3.3 › Multi-model APIs
SQL (Core) API
Flexible JSON documents and SQL-like queries. Often the recommended default for document workloads needing expressive queries.
MongoDB API
Wire-protocol compatible with Mongo drivers and tools. Good for teams that want existing drivers to work without major code changes.
Cassandra API
Best for wide-column models and workloads tuned for Cassandra-style data access patterns.
Gremlin (Graph)
Graph traversals and relationship-centric queries for social, recommendation, or network analysis use cases.
Concrete decision guide
  • If you need expressive document queries, choose SQL API.
  • If you require Mongo driver compatibility, choose MongoDB API.
  • If you have graph queries, choose Gremlin.
Performance note
Performance differences between APIs are minor compared to the impact of partitioning, RU provisioning, and query efficiency. Design for access patterns first.
