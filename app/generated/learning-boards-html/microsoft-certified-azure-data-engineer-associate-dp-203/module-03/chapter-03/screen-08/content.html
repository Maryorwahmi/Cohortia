Module 3 › Chapter 3.3 › Request Units (RUs)
What RUs measure

RUs abstract the CPU, I/O, and memory required for operations. The same RU bill applies regardless of API. Track RU usage per operation by inspecting the x-ms-request-charge response header.

Cheap
Point reads by id and partition key, small upserts.
Expensive
Cross-partition queries and complex aggregations across many items.
Optimization strategies
  • Use point reads with id and partition_key where possible.
  • Design queries to be single-partition to reduce RU cost.
  • Adjust indexing to exclude unused paths.
  • Consider autoscale to match variable demand.
Practical hint
Measure RU cost in development and compare point reads vs cross-partition queries to quantify savings when changing partition keys or query patterns.
Key Takeaway

RU awareness is essential for cost control. Profile queries and choose partitioning and indexing to minimize RU consumption.
