Module 3 › Chapter 3.3 › Partitioning
Key concepts
Logical partitions group items with the same partition key value. Physical partitions are the service-managed resources that store and serve multiple logical partitions. Throughput and storage scale by spreading logical partitions across physical partitions.
Good partition key traits
  • High cardinality so values are well distributed.
  • Used frequently in queries to allow single-partition operations.
  • Distributes writes evenly to avoid hotspots.
Example
For a social app, /userId is a strong partition key for posts because queries usually request posts for a single user and userIds are highly selective.
Pitfall
Choosing a low-cardinality key like /country when most traffic targets a single country causes hot partitions and throttling.
Key Takeaway

Align partition keys with access patterns and cardinality. Use synthetic keys when needed to spread load.
