Multi-model support

Cosmos DB supports the SQL (Core) API, MongoDB API, Cassandra API, Gremlin API, and Table API. This lets you choose the data model and tooling that best fits your application while using the same globally distributed platform.

SQL API
Document queries and flexible schema.
MongoDB API
Compatibility with Mongo drivers.
Gremlin
Graph workloads and traversals.
Global distribution

Replicate your data to any number of Azure regions. This reduces read latency for regional users and provides automatic failover for high availability. Replication is configured at the account level and is transparent to the APIs.

Concrete example
A gaming backend serving European and Asian players replicates data to West Europe and Southeast Asia regions. Players see faster leaderboards and player profiles because reads hit the nearest replica. Writes are replicated according to the chosen consistency level.
Common misconception
Replicating data does not eliminate the need for good partitioning and proper consistency selection. Poor partition keys or an overly strict consistency policy can still cause high latency or throttling despite global replication.
Key Takeaway

Cosmos DB pairs flexible APIs with global distribution, but design choices like partition keys and consistency determine real-world performance.
