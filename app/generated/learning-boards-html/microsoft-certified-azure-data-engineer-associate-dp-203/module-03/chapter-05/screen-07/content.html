Core Concept › Azure AI Search — core components
Search Service
Managed instance that hosts indexes and runs queries.
Data Source
A connector to your data: blob storage, ADLS Gen2, SQL, or Cosmos DB.
Indexer
Automated crawler that extracts and pushes content to an index on a schedule.
Skillset
AI enrichments like OCR and entity recognition applied during indexing.
Index
Schema of searchable fields and attributes that power queries and facets.
Query
Full-text and filtered requests that retrieve matching documents from the index.
Example scenario
Use an indexer to crawl ADLS Gen2, apply OCR to PDFs in a skillset to populate the content field, then run a filterable search for "sales report" and facet by author.
