Process Flow › Designing a search index
Index fields and attributes
Choose the types and flags that match queries: searchable, filterable, sortable, facetable, and retrievable.
id — key, filterable
title — searchable, sortable
content — searchable, analyzer applied
document_type — filterable, facetable
Best practices
  • Start small with essential searchable fields and expand as query patterns emerge.
  • Use analyzers for language-specific tokenization when needed.
  • Schedule indexers to match acceptable data staleness.
Check your understanding

If users often search by author and date range, ensure those fields are filterable and consider faceting on author for exploration.
