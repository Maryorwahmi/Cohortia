Process Flow › Basic Redis operations in Python
Code example
Use the official redis client and TLS for Azure Cache for Redis. The code below demonstrates the common calls you'll use in a small script.
import os
import redis

# Configuration
REDIS_HOST = os.environ.get('REDIS_HOST', 'your-redis-cache.redis.cache.windows.net')
REDIS_PORT = int(os.environ.get('REDIS_PORT', 6380))
REDIS_PASSWORD = os.environ.get('REDIS_PASSWORD', 'YOUR_REDIS_PRIMARY_KEY')

try:
  r = redis.StrictRedis(host=REDIS_HOST,
                        port=REDIS_PORT,
                        password=REDIS_PASSWORD,
                        ssl=True)

  # Set and get
  r.set('product:101', 'Laptop Pro X')
  product_name = r.get('product:101')
  if product_name:
    print('Retrieved product: ', product_name.decode('utf-8'))

  # Set with expiration
  r.setex('temp_report:123', 60, 'Report content')

  # Check existence and delete
  if r.exists('temp_report:123'):
    r.delete('product:101')

except Exception as e:
  print('Error connecting or operating with Redis:', e)
Explanation and best practices
  • Always use secure credentials and TLS for production connections.
  • Use setex for predictable expiration and explicit deletes after source updates.
  • Keep keys small and named consistently for easy invalidation.
Key Takeaway

A few Redis commands cover most caching needs: set, get, setex, exists, and delete. Protect keys and credentials.

Misconception
Expiry is exact to the second; build tolerant checks and do not depend on millisecond-level expiry alignment.
