Hands-on (Conceptual) › Azure AI Search: CLI setup and index JSON
Conceptual CLI sequence
# Create resource group and service
az group create --name my-search-rg --location eastus
az search service create --name myaisearchservice123 --resource-group my-search-rg --location eastus --sku Free

# Get admin key
az search admin-key show --service-name myaisearchservice123 --resource-group my-search-rg --query primaryKey --output tsv
