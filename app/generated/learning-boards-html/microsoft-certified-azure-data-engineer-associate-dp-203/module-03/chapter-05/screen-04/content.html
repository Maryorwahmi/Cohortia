Core Concept › What is Azure Cache for Redis?
Definition and structures
Redis is a managed, in-memory key-value store supporting strings, hashes, lists, sets, and sorted sets. That variety supports caching, queues, and ranked data models.
Strings — simple key/value pairs for JSON blobs or small values
Hashes — group fields under one key, like a lightweight document
Lists/Sets — support queues, unique membership, and pipelines
Key Takeaway
Choose Redis when sub-millisecond access to frequently used data or short-lived state is required.
Concrete example
Imagine a daily analytics report computed by a pipeline. Store the result in Redis under a date-key and serve it to the dashboard to avoid recomputation. Thousands of concurrent users will read directly from memory.
Pro Tip
Use namespaced keys like report:20231026 to simplify invalidation and debugging.
Common mistake
Treating Redis as the single source of truth; ensure critical data is stored durably elsewhere.
