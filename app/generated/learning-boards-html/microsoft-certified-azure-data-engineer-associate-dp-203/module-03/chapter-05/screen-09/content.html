Definition › Indexer and skillset pipeline
Pipeline stages
  1. Extract: indexer reads files and metadata from the data source.
  2. Enrich: skillset runs OCR or entity recognition to add searchable text.
  3. Load: enriched documents are mapped into index fields.
Test small batches to confirm extraction and enrichment before scheduling large runs.
Concrete example
Crawl an ADLS Gen2 container of PDFs, run OCR to extract content into a 'content' field, detect language, and index authors into a 'author' field for faceting.
Common mistake
Running indexers too frequently without need increases cost and can overload your search service.
Pro Tip
Validate enriched fields using a small sample run before enabling the indexer on the full dataset.
