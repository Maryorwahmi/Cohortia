Practice › Choosing between Redis and Search
Checklist questions
  • Are reads far more frequent than writes?
  • Do you need full-text search across documents?
  • What freshness SLA is acceptable for your users?
  • What are memory and indexing cost estimates?
Hybrid pattern example
Cache the top N search results in Redis for very hot queries while keeping the source of truth in the search index. Invalidate cache after indexer runs or when content changes.
Common mistake
Caching search results without an invalidation plan leads to stale suggestions and a confusing user experience.
