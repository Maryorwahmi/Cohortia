CSV, Parquet, JSON
Choose format settings and schema strategy
CSV / DelimitedText
Requires columnDelimiter and firstRowAsHeader flags. Schema is not embedded.
Tip: import schema for type safety and to detect header mismatches early.
Parquet
Columnar, self-describing format with embedded schema and efficient column reads.
Use Parquet when you need performant reads and reliable typed schema in pipelines.
JSON
Flexible and may contain nested objects; may require flattening.
If you need relational sinks, map or flatten nested JSON before writing to tables.
Example scenario

You have a daily CSV export. Define a DelimitedText dataset with firstRowAsHeader true and import schema so your downstream transformations work with strong types. For compact analytics tables, convert CSV to Parquet and reference Parquet datasets for reads.
