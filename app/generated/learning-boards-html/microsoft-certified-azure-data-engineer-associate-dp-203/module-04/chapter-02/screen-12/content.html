Azure SQL table datasets
Reference schema and table name; preview rows to validate.
Relational datasets can leave the schema empty so ADF queries the database for metadata, or you can explicitly import the schema into the dataset for stronger type guarantees. Network controls like firewalls and private endpoints must allow the Integration Runtime to reach the server. When mapping columns in a copy activity, prefer explicit mappings to avoid implicit conversions that can cause truncation or format errors.
Tip
Preview table rows in the studio after creating the dataset to confirm connectivity and expected columns.
Example Dataset JSON for a table
{
  "name": "CustomerTableDataset",
  "properties": {
    "linkedServiceName": { "referenceName": "AzureSqlDatabase_LS", "type": "LinkedServiceReference" },
    "type": "AzureSqlTable",
    "typeProperties": { "schema": "dbo", "table": "Customers" },
    "schema": []
  }
}
Watch out

If your database requires specific IP ranges or private link, configure firewall rules or the correct Integration Runtime to avoid connectivity failures.
