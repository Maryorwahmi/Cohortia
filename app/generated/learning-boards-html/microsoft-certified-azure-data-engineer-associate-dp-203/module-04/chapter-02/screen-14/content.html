Key Concepts
Linked Service
Connection and auth metadata for a store or compute.
Dataset
Points to specific files or tables and defines format and schema.
Managed Identity
Preferred Azure auth; grant roles to ADF's identity instead of storing secrets.
Summary

Map each source to a connector, secure it with the proper auth pattern, and point datasets precisely to files or tables. Validate with Test connection and dataset preview before running pipelines.
