Module 4 › Chapter 4.2 › Common Linked Service types
Connector comparison
Match the store to the right Linked Service type
Azure Blob / ADLS Gen2
File-based formats, container and folder path, supports managed identity.
Format settings: delimiters, header row, encoding. Use AutoResolveIntegrationRuntime for Azure resources.
Azure SQL / Synapse
Relational connector; specify server, database, schema, and table.
Schema often acquired from the database; firewall rules or managed VNet may affect access.
SFTP / HTTP / REST
Non-Azure endpoints; may require service credentials or Key Vault secrets.
Often used with Self-Hosted Integration Runtime if behind corporate networks.
On-premises SQL Server
Requires Self-Hosted Integration Runtime and proper network access to the database.
Common pitfall: selecting Azure IR for on-prem sources causes connectivity failures.
Practical mapping

Inventory each source: store type, network reachability, and desired auth. Map each to a connector type and Integration Runtime before creating Linked Services to avoid rework.
