Troubleshooting Linked Services & Datasets
A short diagnostic checklist to resolve common failures
Step 1 — Test connection
Run Test connection to reveal auth or network issues quickly.
Step 2 — Check IAM and Key Vault
Confirm the managed identity or service principal has required roles; confirm Key Vault Get permission.
Step 3 — Integration Runtime
Ensure Self-Hosted IR for on-prem sources; Azure IR for cloud targets unless using managed VNet.
Step 4 — Dataset preview
Preview rows, validate delimiters, header flags, and encoding. Check file paths and case-sensitivity.
Example fix

If Test connection fails with a 403, grant the ADF managed identity Storage Blob Data Contributor on the storage account, then retry. If dataset preview fails because of incorrect delimiter, update the columnDelimiter and re-preview.
