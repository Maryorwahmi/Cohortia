Expression Example
TotalRevenue = Quantity * Price
-- If Quantity may be a string:
TotalRevenue = toDecimal(Quantity) * Price
-- Null-safe example:
TotalRevenue = iif(isNull(Quantity) || isNull(Price), 0, toDecimal(Quantity) * Price)
Use the expression builder to test results. Always inspect types when errors occur in Derived Column transformations.
Select Usage
Use Select to rename fields to friendly names, drop internal join keys, and reorder columns for consistent sink mapping. It keeps sink mappings simple and predictable.
