Module 4 › Chapter 4.5 › What are Mapping Data Flows?
Definition

Visual pipelines executed on Spark

Mapping Data Flows translate a designer-built graph into Spark jobs. They give you transformations like joins, derived columns, and aggregations in a drag-and-drop canvas while ADF manages the cluster lifecycle.

When to use
Complex transformations at scale without managing compute.
Common misconception
Visual doesn't mean low power; it's Spark under the covers, so you must tune runtime.
Key Takeaway

Use Data Flows to build scalable ETL visually, but plan for partitioning and compute sizing to avoid surprises.

Concrete Example
Join sales Parquet with product SQL, compute revenue, write to Synapse
