Example sequence

Join sales and products, Derived Column to compute revenue, Select to drop unneeded fields, then Aggregate to group by date and product for reporting.

Pro Tip

Run Filters and Selects early to reduce data volume before joins or aggregates. Cache lookup streams if reused to avoid repeated reads.

Common Mistake

Placing expensive joins before filtering leads to larger shuffle and slower performance.
