Module 4 › Chapter 4.5 › Debug & Monitor
Interactive Debug
Turn on Data Flow debug to start a Spark cluster for previews. Use Data Preview to validate sample rows and the Inspect tab to check schema before publishing.
Keep TTL for the debug cluster to avoid repeated startup time during development.
Monitor & Tune
After running a pipeline, use the Monitor tab and Data Flow details view to inspect per-transformation metrics, rows processed, and runtime. Use this data to pick compute type and core count and address skew or slow stages.
Check Your Understanding

If a Derived Column fails on type conversion, preview the input rows at that step to find the offending values and correct the expression.
