Join Comparison
Inner: returns only matching rows. Use when both sources are required for result.
Left: keeps all left rows; adds right-side columns when present. Use to preserve master record stream.
Full: returns all rows from both sides. Use when you need unmatched rows from either side.
Always validate row counts in Data Preview after the join to catch unintended filters or mismatched key types.
Lookup Pattern
Use Lookup to enrich a stream with values from a smaller table. Enable caching for frequently reused lookup streams to avoid extra reads and improve performance.
Common Mistake

Mismatched key types between streams (string vs numeric) silently reduce matches; cast types explicitly before joining.
