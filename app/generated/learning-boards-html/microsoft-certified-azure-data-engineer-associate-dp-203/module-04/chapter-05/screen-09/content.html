Aggregate Example
Group by SaleDate and ProductName. Aggregates: SumRevenue = sum(TotalRevenue), TotalQuantity = sum(Quantity). Use coalesce to handle null TotalRevenue.
Tip: Reduce rows with filters before aggregate to minimize shuffle cost.
Alter Row & Reshape
Use Alter Row to tag rows for insert or update so sinks can execute upserts. Use Flatten for JSON arrays and Pivot when reshaping time-series into columns for reporting.
Key Takeaway

Reshape and summarize only after required fields exist; mark rows explicitly for sink policies to avoid unintended deletes or updates.
