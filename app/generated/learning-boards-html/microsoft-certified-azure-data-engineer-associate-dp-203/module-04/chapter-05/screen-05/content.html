Source Configuration

Dataset, Linked Service, Format

A dataset defines where and how a source is read. For files set delimiter, header, and compression. For databases, set the table and schema mapping so types flow into transformations predictably.

Sampling & Debug
Enable sampling to preview without full cluster runs during development.
Source Filters
Apply row filters early to reduce volume for expensive downstream transforms.
Schemas
Prefer explicit schema in production to avoid runtime surprises.
Concrete Scenario
SalesSource and ProductSource

SalesSource dataset: rawdata/sales_transactions.csv, DelimitedText, header row true. ProductSource dataset: rawdata/products.csv, DelimitedText, explicit column types for Price as decimal.

Mnemonic: Name your stream clearly and set schema at the dataset level for stability.
Common Mistake

Relying on inference for production datasets can lead to type mismatch errors later in Derived Column or Aggregate steps.
