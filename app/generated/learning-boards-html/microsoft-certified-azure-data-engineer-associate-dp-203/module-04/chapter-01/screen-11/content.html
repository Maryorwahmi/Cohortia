Definition

Azure-SSIS Integration Runtime

Managed cluster of VMs for executing SSIS packages in Azure, enabling lift-and-shift migrations.

Run existing SSIS packages without rewriting.
Integrate with ADF pipelines to schedule or orchestrate package runs.
Useful for preserving complex legacy ETL logic during cloud migration.
Example & Guidance
Example
Deploy SSIS packages to Azure-SSIS IR and call them from ADF to preserve existing ETL flows.
Consideration
Evaluate modernization versus lift-and-shift; some SSIS packages may be better reimplemented using native ADF or Spark.
Reflect: Which SSIS packages are short-term candidates for lift-and-shift, and which should you plan to modernize?
