Comparison

Integration Runtimes

Azure Integration Runtime
Serverless, managed compute for cloud-to-cloud movement and Data Flows.
Self-Hosted Integration Runtime
Installed on-prem or on a VM to access private networks and firewalled resources.
Azure-SSIS Integration Runtime
Managed cluster for running SSIS packages in Azure for lift-and-shift scenarios.
Use Cases & Pitfalls
Use Case
Azure IR for cloud stores; SHIR for on-prem sources; SSIS IR for existing SSIS workloads.
Common Misconception
Assuming Azure IR can reach private on-prem resources without a Self-Hosted runtime leads to connection failures.
