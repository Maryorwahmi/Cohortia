Definition

Activities: Data movement, transform, control flow

Each activity is a discrete operation you include in a pipeline to move or process data or control execution flow.

Copy Activity • move data between stores
Data Flow • code-free transformations
Databricks Notebook • Spark-based transforms
Stored Procedure • run SQL on target DB
ForEach / If Condition • control flow
Lookup / Wait • configuration and timing
Example & Takeaway
Example
Copy CSV to lake, Data Flow to normalize and convert to Parquet, then load to Synapse.
Common Mistake
Choosing Data Flow for extremely large, specialized transforms without benchmarking may be costly or slower than Spark/SQL options.
Reflect: For a heavy join and windowing operation on terabytes, would you choose Data Flow or a dedicated Spark cluster?
