Process Flow

Pipelines in ADF

Author sequences of activities, add conditions and loops, and parameterize for reuse.

01 • Define inputs and parameters for the pipeline to accept file paths, dates, or flags.
02 • Add activities such as Copy, Data Flow, or Notebook and sequence them with dependencies.
03 • Add control flow like If Condition and ForEach for branching and iteration.
04 • Publish, trigger, and monitor the pipeline runs regularly.
Key Takeaway

Parameterize pipelines and design idempotent steps so runs are repeatable and easier to debug.

Concrete Example
Daily Retail Ingestion Pipeline
Parameters: processingDate. Steps: copy on-prem sales to lake, copy clickstream from Blob, run Data Flow to join and clean, load to Synapse.
Misconception check: pipelines are not always one-to-one with jobs. Prefer modular pipelines and reuse activities where possible.
