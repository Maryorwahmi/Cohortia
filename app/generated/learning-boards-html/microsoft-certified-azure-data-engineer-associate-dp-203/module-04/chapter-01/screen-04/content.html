Core Concept

What is Azure Data Factory?

A managed ETL/ELT and orchestration service that connects, moves, and schedules data workflows at scale.

Definition: Orchestrator that sequences activities and dispatches compute for transforms.
Example: Retailer joins on-prem sales with cloud clickstream and loads curated output to Synapse.
Misconception: ADF is not a data store; it coordinates other storage and compute services.
Key Takeaway

Use ADF to orchestrate movement and transforms, not to persist long-term data. Choose storage and compute according to scale and latency needs.
