Definition

Datasets: What and Where

Named references that specify object location, format, and schema on top of linked services.

CSV file: path, delimiter, column definitions
Parquet dataset: folder path and partitioning
SQL table dataset: table name and column mapping
Example & Tip
Example
A CSV dataset points to 'sales/{year}/{month}' path with schema fields: orderId, productId, amount.
Common Mistake
Misdefined schema causes data type errors; validate format and sample rows when creating datasets.
Reflect: Can you parameterize your datasets to support partitioned loads by date or customer segment?
