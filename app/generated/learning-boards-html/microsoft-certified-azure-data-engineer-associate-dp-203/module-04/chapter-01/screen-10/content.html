Comparison

Azure IR vs Self-Hosted IR

Azure IR • managed, serverless, cloud-to-cloud
Self-Hosted IR • installed on-prem or VM, accesses private networks
Security: Azure-managed vs customer-managed machines
Network: public clouds vs outbound-only tunnel for SHIR
Scenario
On-Prem SQL to Cloud Lake
Use Self-Hosted IR installed behind the corporate firewall to copy transactional data securely to Azure Data Lake.
Pitfall
Expecting Azure IR to reach private endpoints results in connection failures; validate your topology first.
Reflect: Run a small connectivity test with your chosen IR before scheduling full loads.
