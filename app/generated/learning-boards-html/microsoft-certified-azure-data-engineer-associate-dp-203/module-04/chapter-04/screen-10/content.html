Architecture

Distributed vs lightweight compute

Decision
Databricks Notebook
Best for large transformations, parsing nested JSON, or heavy aggregations with Spark.
Azure Function
Best for small code tasks: notifications, enrichment lookups, or API orchestrations.
Operational notes
  • Grant ADF permissions to submit Databricks jobs or invoke Functions.
  • Make functions idempotent for safe retries.
  • Use cluster sizing and job scheduling for Databricks cost control.
Common mistake
Choosing Functions for heavy data work that should run on Spark; this causes timeouts and scaling issues.
