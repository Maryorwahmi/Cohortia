Module 4 › Chapter 4.4 › Transformation Activities
Stored Procedure
Run existing relational logic in Azure SQL or Synapse. Good for set-based cleansing and merges.
Databricks Notebook
Run Spark notebooks for big data transforms, schema flattening, or machine learning preparation.
Azure Function
Invoke small custom code for notifications, lookups, or lightweight API interactions.
Example: sales pipeline
Copy raw CSV to staging, then call a stored procedure named usp_ProcessSalesData passing the target table name to perform validation and merge into production tables.
