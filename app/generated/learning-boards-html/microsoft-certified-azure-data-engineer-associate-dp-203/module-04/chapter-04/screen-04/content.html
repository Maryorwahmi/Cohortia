Core Concept

What control flow does

Control flow activities determine the pipeline execution order, branching, and iteration. They orchestrate work but do not perform heavy data transformation themselves.

Common activities
  • ForEach: iterate over an array.
  • If Condition: true/false branching.
  • Switch: select among multiple cases.
  • Lookup: retrieve arrays or single rows for decisions.
Common mistake
Using control flow to attempt data transformation. If you need to change formats or process records, call a transformation activity instead.
Illustration: orchestration cards
Lookup
Returns a list of file names or control table rows used to drive loops.
ForEach
Iterates over Lookup output and runs inner activities for each item.
If / Switch
Selects a path based on boolean checks or multiple case values.
Example scenario
Lookup returns two sales files; ForEach copies each one to staging; If Condition checks validation results before running a stored procedure.
Key Takeaway
Use control flow for ordering and decision-making, and pair it with transformation activities for data processing.
