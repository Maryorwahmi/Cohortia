Pipeline parameter example
pipeline().parameters.LoadDate
activity('LookupActivity').output.firstRow.TableName
Use these expressions in activity properties to make them dynamic. For example, pass TableToLoad into a Stored Procedure activity as a parameter value so the same pipeline processes different targets.
Practical tips
  • Preview dynamic content to validate expression results.
  • Use variables for counters inside ForEach or for building temporary strings.
  • Make sure parameter names match exactly in expressions to avoid evaluation errors.
Key Takeaway
Parameters and variables reduce duplication and increase pipeline reusability; validate expressions carefully before running production jobs.
