Module 4 › Chapter 4.4 › If vs Switch
If Condition

Boolean branching

Use when you evaluate a true/false expression. Ideal for validation checks and simple gating.

Simple
Example: if validationResult is true then run Stored Procedure else send notification via Web Activity.
Switch

Multi-case routing

Use when an expression can take multiple named values and each value requires a different path.

Multi-case
Example: DataSourceType equals 'SQL', 'Blob', or 'API' and each case runs a tailored ingest branch.
Design tip
Avoid nesting many If Conditions; prefer Switch for clarity. Put shared preprocessing outside the Switch to avoid duplication unless each case requires unique steps.
