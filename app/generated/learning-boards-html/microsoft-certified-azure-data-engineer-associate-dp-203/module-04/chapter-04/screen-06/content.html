What Lookup returns

Lookup can return a single row or an array. When it returns an array, ForEach can iterate its entries. Preview the output to confirm the property names you will reference.

Sample Lookup output (simplified)
[
  { "name": "sales_20231026.csv" },
  { "name": "sales_20231027.csv" }
]
This array gives ForEach two items; inside the loop use an expression to read the current file name and pass it to Copy.
Practical checks
  • Preview Lookup in Studio to confirm fields like name or FileName exist.
  • Validate linked service permissions to avoid empty results.
  • Guard against empty arrays with an If Condition or an error path.
Common mistake
Assuming Lookup returns a non-empty array; always validate or add fallbacks.
