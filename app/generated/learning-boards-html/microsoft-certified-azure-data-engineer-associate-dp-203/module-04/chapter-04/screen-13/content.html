Module 4 › Chapter 4.4 › Key Concepts
ForEach
Iterate over arrays and run child activities per item.
Lookup
Retrieve rows or file lists that drive pipeline decisions.
If / Switch
If for boolean checks, Switch for many-case routing.
Takeaway
Orchestrate with control flow, transform with the right compute, and use Lookup plus ForEach as a foundational pattern for multi-file ingestion.
