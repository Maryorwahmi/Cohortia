Create staging table (example)
CREATE TABLE [dbo].[DailySalesStaging] (
  [ID] INT,
  [Product] NVARCHAR(100),
  [Quantity] INT,
  [FileName] NVARCHAR(255) -- To track source file
);
After the table exists, configure a sink dataset pointing to this table and use Copy activity's Additional columns feature to add FileName with value item().name.
Stored procedure call (concept)
Configure the Stored Procedure activity to call usp_ProcessSalesData and pass the table name or other parameters so the database executes cleansing and merges. Ensure linked service permissions allow execution.
Pipeline sequence
  1. GetSalesFiles (Lookup) returns file list
  2. IterateSalesFiles (ForEach) uses output value as items
  3. Inside ForEach: CopyCurrentSalesFile writes into DailySalesStaging
  4. After ForEach: Stored Procedure activity runs usp_ProcessSalesData
Key Takeaway
Keep ingestion and transformation responsibilities separated and validate permissions before triggering the pipeline.
