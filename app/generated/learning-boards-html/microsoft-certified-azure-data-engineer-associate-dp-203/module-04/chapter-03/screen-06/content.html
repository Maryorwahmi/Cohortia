Configuring the Source

The source tab defines where to read data and how to interpret it, via dataset and format settings.

  • • Select the Source dataset that references a Linked Service for authentication and path information.
  • • Choose file path type: file path in dataset, folder, or wildcard to capture multiple files.
  • • For relational sources, specify a query to limit rows and reduce transfer volume.
  • • Set format-specific options, e.g., first row as header for CSV to avoid importing headers as data.
  • • Use recursive option when you need to read subfolders, aware of increased file counts.
Common mistake

Misconfiguring header row handling causes header lines to be treated as data or lost during ingestion.

Practical examples
Wildcard file copy
Use wildcardFileName: sales_data_*.csv and wildcardFolderPath: raw/sales to copy many files matching a pattern.
Relational query
Use a SQL statement like SELECT ID, Name FROM dbo.Customers WHERE City='New York' to limit rows at source.
Recursive folder read
Enable recursion to include files in subfolders; check file counts before copying to avoid surprises.
Tip: preview source dataset content before running a full copy to confirm header, delimiter, and field ordering assumptions.
