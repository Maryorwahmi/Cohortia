Comparison

Automatic mapping vs Manual mapping

Automatic mapping
ADF matches columns by name and maps types when obvious. Good for identical schemas and fast setup.
Manual mapping
Explicitly map source columns to sink columns, specify conversions, and remove unwanted columns.
When to use each
Use automatic mapping for identical schemas; use manual mapping when names or types differ or when conversions are required.
Pro tip

Always test mappings with sample rows to catch conversion errors before processing full volumes.

Concrete example
Scenario
Source: Product_ID (string). Sink: ProductID (int). Map and set a conversion from string to integer.
Actions to take
Import schemas, add mapping entry Product_ID → ProductID, and verify conversion on a test run.
Common error
If conversion fails, check for non-numeric values in Product_ID or adjust mapping to cleanse or skip invalid rows.
