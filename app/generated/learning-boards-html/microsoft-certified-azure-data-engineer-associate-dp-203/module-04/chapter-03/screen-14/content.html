Key Concepts

Three concise reminders to guide your pipelines.

Copy Activity
Primary ADF activity for efficient data movement across many connectors.
Mapping
Import or define mappings and conversions to align source columns with sink schema.
Performance
Tune DIUs, parallel copies and staging while monitoring metrics to find bottlenecks.
Summary takeaway
Configure carefully, validate mappings with sample runs, and tune incrementally using Monitor metrics for reliable, efficient data movement.
