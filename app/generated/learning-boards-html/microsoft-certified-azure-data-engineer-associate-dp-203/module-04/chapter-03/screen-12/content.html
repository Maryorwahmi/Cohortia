Hands-on Activity

Copy Blob CSV → Azure SQL

1. Prereqs: Blob Linked Service and Azure SQL Linked Service, plus table created with the DDL.
2. Author: New pipeline, drag "Copy data" activity, name it CopySampleCsvData.
3. Source: Select SampleCsvDataset. Verify file path and header option.
4. Sink: Select StagingSampleDataTable. Set Table option to None and Pre-copy script TRUNCATE TABLE [dbo].[Staging_SampleData];
5. Mapping: Import schemas and verify ID, Name, City map correctly.
6. Publish and Trigger. Monitor the activity run and then query the target table to confirm results.
Remember to check SQL firewall settings to allow service access; this is a frequent source of connectivity errors during testing.
Verification steps
Monitor metrics
Check data read/written, rows copied, duration and DIU usage for performance and correctness.
Validate target
Run SELECT * FROM [dbo].[Staging_SampleData]; to ensure rows and columns loaded as expected.
