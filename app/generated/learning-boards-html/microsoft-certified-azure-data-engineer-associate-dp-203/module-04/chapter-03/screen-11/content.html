Performance

DIUs, Parallel Copies, Staging

• DIUs: compute units for the activity. More DIUs increase throughput at higher cost.
• Parallel copies: number of concurrent connections to source and sink. Useful for many small files or parallel-friendly sources.
• Staging: copy to an intermediate store first, then bulk-load into the warehouse for higher performance.
• File sizing: fewer large files perform better for bulk loads than many tiny files due to overhead per file.
Rule of thumb

Tune one parameter at a time and compare runs to find the real bottleneck — source, sink, or network.

Quick tuning checklist
  • • Start with default DIUs and parallelCopies.
  • • Run small test, note throughput and DIU usage.
  • • Increase DIUs incrementally and re-measure.
  • • If many small files, try increasing parallelCopies or consolidating files.
  • • For warehouses, enable staging to Blob Storage for bulk loading.
