Common Pitfalls

Frequent error sources

  • • Header misconfiguration: firstRowAsHeader wrong causes header rows to appear as data or to be dropped.
  • • Schema mismatch: conversion failures or missing columns cause activity errors.
  • • Connectivity/firewall: database access denied manifests as connection errors.
  • • Performance guessing: changing DIUs without diagnosing the real bottleneck can waste cost.
  • • Too many small files: overhead causes slow transfers; consider consolidation.
Suggested troubleshooting steps
Preview & import
Preview source rows and import schemas to detect header and type issues before copying large volumes.
Small test run
Run a sample copy and inspect rows and logs to confirm mapping and connectivity.
Use logs
Enable copy activity logs for detailed error messages to guide fixes.
