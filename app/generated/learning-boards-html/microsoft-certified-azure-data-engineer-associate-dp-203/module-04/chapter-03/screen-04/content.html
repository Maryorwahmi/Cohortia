Core Concept

What is the Copy Activity?

ADF's Copy Activity moves data from a source dataset to a sink dataset, supporting many connectors and light conversions.

S
Definition
Reads from a source store and writes to a sink store with optional mapping and conversions.
M
When to use
Best for bulk and file-to-table or table-to-table moves where complex row transformations are not required.
X
Common misconception
Copy Activity is not intended for deep transformations; prefer Data Flow when you need complex logic.
Key Takeaway

Copy Activity is the efficient, reliable way to move data between datasets while handling basic mappings and conversions.

Supported connectors & example
File stores
Azure Blob, ADLS Gen2, SFTP — useful for CSV, JSON and parquet files.
Relational stores
Azure SQL Database, Synapse, on-prem SQL Server — useful for table loads with pre-copy scripts.
Hybrid
Self-Hosted Integration Runtime supports on-premises sources when needed.
Example scenario
Copying sales CSV files from ADLS Gen2 into a staging table in Azure SQL to prepare for analytics.
