Process Flow

Pipeline canvas — single Copy Activity

1
Author: new pipeline
Create and name a pipeline to host activities and parameters.
2
Add Copy Activity
Drag the Copy Data activity onto the canvas and open its properties.
3
Configure Source & Sink
Select datasets, set file path or query options, and choose write behavior or pre-copy scripts for the sink.
4
Mapping and validation
Import schemas, adjust mappings, and validate data types to avoid conversion errors during copy.
Key Takeaway

Follow a simple author → configure → map → test cycle to produce reliable copy pipelines.
