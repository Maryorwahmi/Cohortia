Learning Objectives

What you will be able to do after this chapter

01
Design and implement Copy pipelines

Create a pipeline with a Copy Activity that moves data between datasets. This skill is foundational for ingestion workflows.

VERIFIED COMPETENCY MILESTONE
02
Configure source and sink properties

Set dataset references, file path options, queries, pre-copy scripts and write behaviors so data lands where you expect.

VERIFIED COMPETENCY MILESTONE
03
Apply schema and data type mapping

Import schemas and explicitly map mismatched names or types so conversions succeed during the copy operation.

VERIFIED COMPETENCY MILESTONE
04
Monitor runs and interpret metrics

Read data read/written, throughput, duration and DIU usage to validate success and diagnose failures or bottlenecks.

VERIFIED COMPETENCY MILESTONE
