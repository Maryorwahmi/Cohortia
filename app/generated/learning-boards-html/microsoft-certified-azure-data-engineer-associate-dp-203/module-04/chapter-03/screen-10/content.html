Interpreting activity metrics

• Data read / written: absolute size transferred. Use this to validate expected volume.
• Rows read / written: row counts confirm completeness when size alone is misleading.
• Throughput (MB/s): transfer rate that DIUs and parallelism affect directly.
• DIU usage: compute consumed by the Copy Activity; higher DIUs generally increase throughput.
• Error details: schema mismatches and conversion failures are common and reported here.
Check this first

If rows are fewer than expected, verify source filters, wildcard paths, and header settings before assuming a pipeline error.
