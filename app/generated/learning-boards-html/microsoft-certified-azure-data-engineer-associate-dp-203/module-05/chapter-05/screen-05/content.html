Process Flow
Micro-batch steps
  1. Files are dropped into the landing directory on ADLS Gen2.
  2. Auto Loader discovers new files incrementally and hands paths to Spark.
  3. Spark runs a micro-batch: readStream, transformations, aggregations.
  4. Results are written to Delta or another sink; checkpoint is updated.
Design considerations
  • Choose checkpointLocation on durable storage like ADLS Gen2.
  • Set trigger interval based on file arrival rate and processing time.
  • Pick an outputMode compatible with your aggregation logic.

Common mistake

Key Takeaway

Micro-batch pipelines let you process files incrementally; planning triggers, output modes, and checkpointing is essential for correctness and durability.
