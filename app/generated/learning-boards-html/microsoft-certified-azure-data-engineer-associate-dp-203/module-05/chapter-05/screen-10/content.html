Definition
What the checkpoint contains
  • Offsets and progress per micro-batch.
  • Schema metadata for Auto Loader schemaLocation.
  • State for aggregations and windowed operations.
Store checkpointLocation on durable ADLS Gen2 storage. Use a dedicated folder per streaming query to avoid conflicts.
Concrete example
Set checkpoint_location = "/mnt/datalake/checkpoints/sales_stream_checkpoint". After a short run you will see metadata files and a schema folder under that path.
Misconception
Checkpointing is optional — it's mandatory for correct restart and exactly-once guarantees in most streaming jobs.
Key Takeaway

Always configure a durable checkpointLocation and verify that progress files are being written during test runs to ensure fault tolerance.
