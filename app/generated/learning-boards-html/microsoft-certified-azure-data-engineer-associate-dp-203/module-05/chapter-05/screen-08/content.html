Comparison
Append
Writes only newly-produced rows. Good for file sinks where each micro-batch adds new records.
Best when you are not updating previous keys.
Complete
Writes the entire result table every trigger. Useful for aggregated snapshots but heavier on sink.
Use for groupBy aggregations that update prior keys.
Update
Writes only rows that changed since the last trigger. Often limited by sink semantics and requirements.
Choose when supported and when you need incremental updates of stateful results.
Concrete example
If you compute daily totals by product category and need the full snapshot each minute for downstream dashboards, complete mode gives a full view. If you only append raw event rows to a Delta raw table, append mode is best.
Misconception
Append is always cheaper — append can be wrong when prior rows must change as new data arrives.
Key Takeaway

Match outputMode to the computation and sink. Aggregations often need complete or update; simple inserts can use append.
