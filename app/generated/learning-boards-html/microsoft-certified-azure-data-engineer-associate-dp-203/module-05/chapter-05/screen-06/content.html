Auto Loader usage pattern
streaming_df = spark.readStream.format("cloudFiles") \
  .option("cloudFiles.format", "csv") \
  .option("cloudFiles.schemaLocation", f"{checkpoint_location}/schema") \
  .option("header", "true") \
  .schema(sales_schema) \
  .load(input_path)

# Add processing time column
processed = streaming_df.withColumn("ProcessingTimestamp", current_timestamp())
Note: use an explicit schema for production and set cloudFiles.schemaLocation to a durable subdirectory under your checkpointLocation.
Practical example
If your landing zone receives dozens of files per minute, Auto Loader avoids repeated expensive directory listings and supports schema evolution when configured with a schema location.
Example scenario
Sensor CSV files are dropped periodically; Auto Loader fetches new files and Spark runs a micro-batch to append them into a raw Delta table.
Misconception
Auto Loader changes how data is parsed — false. Parsing is done by Spark; Auto Loader optimizes discovery and handing off files.
Key Takeaway

Prefer cloudFiles (Auto Loader) for scalable file discovery and set an explicit schema with a schemaLocation under a durable checkpoint path.
