Delta write pattern
query = daily_summary_df.writeStream \
  .format("delta") \
  .outputMode("complete") \
  .option("checkpointLocation", checkpoint_location) \
  .trigger(processingTime="1 minute") \
  .toTable("daily_sales_summary")

# Alternatively, for an unmanaged table or path:
# .start(output_delta_path)
Choose .toTable for managed tables that appear in the metastore; use .start(path) to manage files directly.
Key Takeaway

Delta offers durable, transactional writes for streams, but you must choose output mode and checkpointing to keep results correct and efficient.

Managed vs Unmanaged
Managed tables live in the metastore and are convenient for queries; unmanaged tables let you control physical layout and paths.
Example pattern
Raw records -> raw Delta (append). Aggregates -> curated Delta (complete) on a slower trigger.
Mistake
Using ephemeral storage for checkpointLocation or mixing outputMode incompatible with sink can cause data duplication or lost updates.
