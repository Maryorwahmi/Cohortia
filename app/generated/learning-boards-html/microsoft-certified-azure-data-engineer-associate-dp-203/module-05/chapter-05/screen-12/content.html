Hands-on Activity
Lab checklist
  1. Create input_path, checkpoint_location, and output_delta_path on the mount.
  2. Define an explicit schema for incoming CSVs.
  3. Simulate initial file using dbutils.fs.put to input_path.
  4. Create streaming_df with spark.readStream.format("cloudFiles") and cloudFiles.schemaLocation set to checkpoint/schema.
  5. Add ProcessingTimestamp and derived fields.
  6. Write with format("delta"), .option("checkpointLocation", checkpoint_location), .outputMode("append"), .trigger(processingTime="30 seconds").
  7. Start the query, add a second file, stop and verify Delta output as batch.
