Timeline
Trigger options
  • processingTime: run every N interval (e.g., "1 minute").
  • once: run a single micro-batch and stop.
  • continuous: low-latency mode (specialized, not common for file sources).
Start with a conservative interval and monitor; adjust as you observe average batch durations and throughput.
Practical tuning checklist
  1. Measure average processing time for a micro-batch.
  2. Set trigger greater than or equal to average processing time.
  3. Monitor scheduling lag and backlog in Spark UI and Azure Monitor.
Example
If average batch completes in 20 seconds, start with processingTime="30 seconds" to leave buffer for variability.
Key Takeaway

Trigger intervals balance latency and system stability; tune based on measured micro-batch duration and arrival patterns.
