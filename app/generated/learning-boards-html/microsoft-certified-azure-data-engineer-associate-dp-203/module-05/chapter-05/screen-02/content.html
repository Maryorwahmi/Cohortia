Learning Objectives
Master the practical steps for converting batch file ingestion into safe, repeatable micro-batch streams.
Bloom: Learn → Understand → Apply → Master
01
Explain Structured Streaming
Describe Structured Streaming's micro-batch model and how it leverages the DataFrame API for incremental processing. VERIFIED COMPETENCY MILESTONE
Mnemonic: think of a timer that runs a small batch every few minutes, applying the same batch logic each time.
02
Differentiate sources and sinks
Identify when a file directory is a streaming source and when a sink supports append or complete writes. VERIFIED COMPETENCY MILESTONE
Mnemonic: source vs sink like faucet and bucket — where data comes from and where it lands.
03
Implement streaming job
Use spark.readStream with cloudFiles or CSV/Parquet formats, set schema, and run a micro-batch ingestion. VERIFIED COMPETENCY MILESTONE
Mnemonic: code-first — a few lines turn your batch logic into a stream.
04
Configure checkpointing
Place checkpointLocation on durable storage like ADLS Gen2 to ensure fault tolerance and avoid duplicates. VERIFIED COMPETENCY MILESTONE
Mnemonic: checkpoint is the stream's memory, store it durably.
