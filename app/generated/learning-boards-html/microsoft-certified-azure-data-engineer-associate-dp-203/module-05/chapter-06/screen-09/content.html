Module 6 › Chapter 5.6 › Cluster Sizing
Cluster configuration decisions

Autoscaling reduces cost while handling peak demand. Job clusters are preferred for production because they are ephemeral and isolate runs. Choose VM types by workload: memory-optimized for heavy aggregations and compute-optimized for CPU-bound tasks.

Practical checklist
  • Enable autoscaling to adapt to variable load.
  • Run representative tests and observe executor CPU and memory.
  • Adjust instance type and number of cores to eliminate the bottleneck.
Misconception
Bigger machines are not always better. Many smaller executors can improve parallelism and reduce shuffle contention, depending on your workload.
Key Takeaway

Test with realistic data, tune cores and instance types, and use autoscaling and job clusters to balance cost and performance.
