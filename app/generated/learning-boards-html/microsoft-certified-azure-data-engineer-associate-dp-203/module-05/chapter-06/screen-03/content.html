Practice verification
Four short experiments to confirm competency
Monitor: Find a stage hotspot
Run a job, open the Spark UI, go to Stages, and note a stage with high task duration variance.
OOM: Reproduce and mitigate
Trigger a memory failure with a wide aggregation, then try increasing executor memory or repartitioning and compare results.
Skew: Observe and salt
Run the skewed aggregation provided, watch long tasks, add salting, and measure the change in stage duration.
Ops: Job cluster & idempotency
Deploy a parameterized notebook to a job cluster, verify it starts and terminates, and test retries produce no duplicate outputs.
Quick checklist
  • Record baseline stage and task durations in the Spark UI.
  • Change one variable at a time (memory, partitions, or strategy).
  • Rerun and compare executor and shuffle metrics.
  • Document the outcome and roll the fix to production only after verification.
