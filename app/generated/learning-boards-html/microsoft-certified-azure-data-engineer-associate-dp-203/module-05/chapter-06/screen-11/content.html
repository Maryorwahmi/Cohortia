Partitioning and Delta optimizations
Partitioning
Choose coarse-grained partition columns aligned with query predicates, such as year/month/day, to enable predicate pushdown and reduce data scanned.
Z-ordering
Use OPTIMIZE ... ZORDER BY on frequently filtered or joined columns to collocate related data and improve data skipping.
File-size management
After many small file writes, run OPTIMIZE to compact files. Small files create high task overhead and can hurt performance.
Key Takeaway

Partition for query patterns, compact small files, and use Z-ordering on columns that benefit repeated filters or joins.
