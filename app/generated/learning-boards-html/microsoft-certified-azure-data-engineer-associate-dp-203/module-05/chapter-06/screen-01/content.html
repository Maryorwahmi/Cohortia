Why it matters

Small hotspots can delay full stages and increase cost; focused fixes reduce runtime and make pipelines reliable.

Quick orientation
  • Databricks UI gives runs, logs, and links to the Spark UI.
  • Spark UI exposes Jobs, Stages, Tasks, Executors, and SQL plans for diagnosis.
  • Troubleshooting focuses on OOM, skew, and excessive shuffles.
