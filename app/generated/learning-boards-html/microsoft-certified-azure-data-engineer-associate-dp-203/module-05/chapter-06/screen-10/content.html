Important Spark properties
spark.sql.shuffle.partitions
Set to 2–4x total CPU cores to balance parallelism and task overhead.
spark.memory.fraction
Controls fraction of heap for execution and storage. Tune when caching or heavy aggregation requires more space.
I/O cache
Enable Databricks I/O cache for repeated reads from cloud storage to reduce latency.
Practical advice
  • Adjust shuffle partitions following changes in cluster core count.
  • Prefer built-in Spark SQL functions instead of Python UDFs to avoid cross-language overhead.
  • Iteratively tune and re-measure using Spark UI metrics; avoid extreme values without evidence.
