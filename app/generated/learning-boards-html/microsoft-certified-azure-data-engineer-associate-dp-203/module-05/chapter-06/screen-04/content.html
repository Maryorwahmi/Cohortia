Key Takeaway

Spark UI — where to look
Jobs
Overview of jobs and associated stages with durations.
Stages
Find stages with large shuffle read/write and task duration variance.
Tasks
Inspect per-task execution times, input/output sizes, and failure traces.
Executors
See CPU, memory, and storage per executor to detect OOM candidates.
Interpreting a slow aggregation
  • Look for a stage whose tasks have a long tail in duration — that often signals skew.
  • Open the Executors tab: if a few executors have much higher memory use or frequent GC, consider memory or partition changes.
  • If SQL plan shows wide transformations, minimize shuffles or use broadcast joins where appropriate.
