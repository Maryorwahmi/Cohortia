Module 6 › Chapter 5.6 › Security Considerations
Secure by design
Access control
Use Azure AD for user and group management; restrict who can create or manage clusters.
Secrets
Use Databricks Secrets backed by Azure Key Vault and organize secrets into scopes with limited access.
Network
Deploy with VNet injection for private connectivity and apply NSG rules to limit traffic as needed.
Operational guidance
  • Prefer managed identities or service principals for programmatic ADLS access with least privilege.
  • Never hardcode credentials in notebooks; use secrets and test scope access by identity.
  • Validate security measures by confirming required resource access for scheduled jobs and notebooks.
