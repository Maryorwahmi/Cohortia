Module 5 › Chapter 5.3 › Key Concepts
Window Functions
Compute per-row analytics with partitionBy and orderBy without collapsing rows.
UDFs
Custom logic in Python; watch serialization costs and prefer Pandas UDFs for throughput.
Broadcast Variables
Send small, read-only tables to all executors once to avoid shuffle for joins.
Summary

Choose the right tool: windows for row-level analytics, Pandas UDFs rather than Python UDFs when possible, and broadcasts to prevent expensive shuffles.
