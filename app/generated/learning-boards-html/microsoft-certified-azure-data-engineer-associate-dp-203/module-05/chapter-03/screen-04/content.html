What a window function does
A window applies a function across rows related to the current row without aggregating them away.
Key properties
  • partitionBy defines grouping (e.g., DeviceID, Category)
  • orderBy defines sequence inside each partition
  • rowsBetween or rangeBetween constrain the frame for moving averages or running totals
Common mistake
Assuming window operations never shuffle. Large partitions or orderBy across wide data can cause shuffles and heavy network I/O.
Key takeaway
Use windows for per-row time-aware analytics; be mindful of partition size and ordering to avoid costly shuffles.

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, sum, rank, lag
from pyspark.sql.window import Window

# dummy sales data
window_spec = Window.partitionBy('Category').orderBy('SaleDate')

# running total
df_running_total = df_sales.withColumn('RunningTotal', sum('Amount').over(window_spec))

# rank within category
df_ranked = df_sales.withColumn('Rank', rank().over(window_spec))

# previous row value
df_lag = df_sales.withColumn('PrevDayAmount', lag('Amount', 1).over(window_spec))

# show results
df_running_total.show()
Example scenario
Given daily sales per category, compute a running total per category and use lag to compare today's sale to yesterday's sale for the same category.
