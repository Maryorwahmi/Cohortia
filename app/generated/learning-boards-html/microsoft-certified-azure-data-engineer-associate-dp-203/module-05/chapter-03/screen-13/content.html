Module 5 › Chapter 5.3 › repartition vs coalesce
repartition()
Performs a full shuffle to create evenly balanced partitions; use when increasing partitions or rebalancing.
coalesce()
Reduces partition count without a full shuffle; fast but may leave partitions unevenly sized.
Example commands
print(f'Original partitions: {df_sales.rdd.getNumPartitions()}')
df_repartitioned = df_sales.repartition(8)
print(f'Repartitioned to: {df_repartitioned.rdd.getNumPartitions()}')
df_coalesced = df_repartitioned.coalesce(4)
print(f'Coalesced to: {df_coalesced.rdd.getNumPartitions()}')
