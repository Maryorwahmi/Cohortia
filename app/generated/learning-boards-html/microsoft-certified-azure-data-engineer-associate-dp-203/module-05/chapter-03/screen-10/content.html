Module 5 › Chapter 5.3 › Accumulators
When to use
Counting bad rows, tracking processed row totals, or simple sums for diagnostics during a job run.
Caveats
  • Not for correctness-critical results
  • May be impacted by speculative tasks
  • Best for lightweight monitoring and debugging
Example
Create an accumulator on the driver, add 1 in tasks for each bad row, and read the final count after a job finishes to estimate data quality issues.
