Module 5 › Chapter 5.3 › Caching & Persistence
Cache example
# cache the DataFrame
df_sales.cache()
# trigger caching
df_sales.count()
# use cached data
df_sales.filter(col('Amount') > 100).show()
# unpersist when done
df_sales.unpersist()
Common mistake
Caching many large DataFrames or forgetting to unpersist can exhaust memory and slow the cluster.
When to cache
  • Iterative algorithms reading the same DataFrame multiple times
  • Expensive lineage you don’t want to recompute
  • Intermediate data reused across downstream stages
Key Takeaway

Cache intentionally, measure the memory impact, and unpersist when unnecessary to keep cluster resources healthy.
