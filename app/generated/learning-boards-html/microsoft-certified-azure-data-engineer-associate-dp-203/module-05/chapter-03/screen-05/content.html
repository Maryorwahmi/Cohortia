Module 5 › Chapter 5.3 › Window Frames
rowsBetween example
Use rowsBetween(-2, 0) for a 3-row moving window: exact number of preceding rows regardless of date gaps.
rangeBetween example
Use rangeBetween when the order column is numeric or timestamp and you want a time-range window, such as last 72 hours.
Misconception
rowsBetween does not know about calendar dates. For irregularly sampled data, rowsBetween(-2, 0) may span multiple days.
Code: three-day moving average
from pyspark.sql.window import Window
from pyspark.sql.functions import avg

window_spec = Window.partitionBy('DeviceID').orderBy('ReadingDate').rowsBetween(-2, 0)
df_with_avg = df_sensor_readings.withColumn('ThreeDayMovingAvgTemp', avg('Temperature').over(window_spec))
df_with_avg.show()
Example
DeviceA with readings on consecutive days: the moving average for day three includes readings from days one, two, and three when using rowsBetween(-2, 0).
