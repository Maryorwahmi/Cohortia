What happens during a shuffle
  1. Serialize and write partitions to local disk
  2. Transfer partitions over the network to target executors
  3. Deserialize and process incoming data
How to reduce shuffle
  • Broadcast small tables to avoid shuffle joins
  • Apply filters before wide transformations
  • Use partitioning or bucketing for frequent join keys
Rule of thumb
Aim for 2–4 tasks per CPU core; increasing partitions helps parallelism but can increase scheduling overhead if overdone.
