Module 5 › Chapter 5.3 › User-Defined Functions
Python UDF example
from pyspark.sql.functions import udf
from pyspark.sql.types import StringType

def categorize_amount(amount):
  if amount < 100:
    return 'Low'
  elif 100 <= amount < 200:
    return 'Medium'
  else:
    return 'High'

categorize_amount_udf = udf(categorize_amount, StringType())
df_categorized = df_sales.withColumn('AmountCategory', categorize_amount_udf(col('Amount')))
df_categorized.show()
Misconception
Assuming Python UDFs are fine at any scale. The overhead of crossing JVM⇄Python repeatedly can be orders of magnitude slower on big data.
When to use UDFs
  • When logic cannot be expressed with built-in functions
  • For small datasets or one-off transformations
  • Prefer Pandas UDFs for high-volume row-wise custom logic
Example takeaway
If a function will be called millions of times, measure both Python UDF and Pandas UDF implementations and default to vectorized options where they exist.
