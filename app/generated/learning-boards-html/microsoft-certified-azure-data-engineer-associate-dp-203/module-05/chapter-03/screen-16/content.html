Module 5 › Chapter 5.3 › Key Concepts
Caching
Cache only when a DataFrame will be reused; unpersist promptly to avoid memory pressure.
Shuffle
Shuffles cost disk, network, and serialization; minimize them with broadcast joins and early filters.
Partitioning
Tune partition counts relative to cluster cores and workload: 2–4 tasks per core is a practical starting point.
Final takeaway

Combine correct transformations with sensible resource-aware tuning: windows for analytics, broadcasts to avoid shuffles, and caching to speed reuse — measure to be sure.
