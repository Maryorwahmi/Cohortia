Module 5 › Chapter 5.4 › Delta Read/Write
Write a Delta table
# Writing a DataFrame to ADLS Gen2 as a Delta table
delta_path = f"{mount_point}/curated/sales_delta_table"
df_sales.write.format("delta").mode("overwrite").save(delta_path)

# Reading from a Delta table
df_delta_read = spark.read.format("delta").load(delta_path)
df_delta_read.show(5)
Always verify the table contents after writing and keep a test snapshot before overwriting in production.
Example checks
  • Confirm expected row counts and schema fields after write.
  • Check delta table history with deltaTable.history() during development.
  • Use partitioning to keep file sizes manageable for OPTIMIZE later.
Key Takeaway

Delta format adds a transaction log. Use the delta read/write pattern consistently to preserve versioning and atomicity.
