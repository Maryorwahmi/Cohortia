Module 5 › Chapter 5.4 › Security Model
Service Principal
  • Requires tenant ID, client ID, and client secret.
  • Flexible across automation and scripts, but secret must be managed.
  • Store secret in Databricks Secrets and Key Vault for safety.
Managed Identity
  • Azure-managed credential associated with the workspace or compute.
  • No client secret to rotate; easier lifecycle management.
  • Grant roles directly to the managed identity with least privilege.
Operational advice

Document role assignments and prefer managed identities where possible. If using service principals, use secrets stored in Databricks Secrets backed by Azure Key Vault.
