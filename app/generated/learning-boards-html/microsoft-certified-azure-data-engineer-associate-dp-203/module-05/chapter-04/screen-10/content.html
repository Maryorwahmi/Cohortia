How to read a previous version
# Read a previous version by number
df_version_0 = spark.read.format("delta").option("versionAsOf", 0).load(delta_path)
df_version_0.orderBy("DeviceID", "ReadingDate").show()

# Or by timestamp
# df_ts = spark.read.format("delta").option("timestampAsOf", "2023-01-06T12:00:00").load(delta_path)
Operational notes
  • Use deltaTable.history() to find version numbers and commit timestamps.
  • Don't rely on time travel if VACUUM has removed older files or retention checks are disabled.
  • Document versions used in experiments to ensure reproducibility.
Why it matters

Time travel enables audits and safe rollbacks, reducing recovery time after accidental updates.
