Module 5 › Chapter 5.4 › Best Practices
Do
  • Use Databricks Secrets and Key Vault for credentials.
  • Test MERGE on staging with known data.
  • Schedule OPTIMIZE and use ZORDER for hot columns.
Don't
  • Hardcode service principal secrets in notebooks.
  • Run VACUUM with zero-hour retention in production.
  • Ignore audit columns and version checks before merges.
Final Tip

Automate maintenance during off-peak hours, keep logs for audits, and use retention policies aligned to business recovery needs.
