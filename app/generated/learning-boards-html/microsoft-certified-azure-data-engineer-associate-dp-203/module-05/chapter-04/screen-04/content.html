Module 5 › Chapter 5.4 › What is ADLS Gen2
Definition

ADLS Gen2 combines blob storage with a hierarchical file system to support scalable analytics. It enables folder semantics and efficient file operations for large datasets used by Spark.

Analogy

Think of ADLS Gen2 as a warehouse with labeled shelves and bins instead of a single bulk pile. Proper labeling lets workers find and process only relevant items fast.

Key Takeaway

Use hierarchical organization and partitioning in ADLS Gen2 to improve Spark pruning and read performance.

How it affects ETL
  • Well-partitioned Parquet in ADLS Gen2 reduces data scanned by queries.
  • Hierarchical namespace enables efficient file listing and deletes at scale.
  • Role-based access control secures sensitive datasets without duplicating data.
Common mistake
Treating ADLS Gen2 as a flat blob store and dumping raw files without partitioning leads to poor performance for downstream Spark jobs.
