Module 5 › Chapter 5.4 › Parquet and CSV I/O
Parquet example
# Writing as Parquet
df_sales.write.mode("overwrite").parquet(f"{mount_point}/raw/sales_data_parquet")

# Reading Parquet
df_read_parquet = spark.read.parquet(f"{mount_point}/raw/sales_data_parquet")
df_read_parquet.show(5)
Why Parquet?
  • Columnar storage reduces I/O for selected columns.
  • Stores schema and supports predicate pushdown.
  • Compresses efficiently to save storage and network time.
CSV example and cautions
# Writing CSV
df_sales.write.mode("overwrite").csv(f"{mount_point}/raw/sales_data_csv", header=True)

# Reading CSV with schema (preferred)
df_read_csv = spark.read.csv(f"{mount_point}/raw/sales_data_csv", header=True, inferSchema=True)
df_read_csv.show(5)
Tip: For large datasets, provide an explicit schema to avoid expensive inference and inconsistent types.
Key Takeaway

Use Parquet for production datasets. Use CSV for small, ad-hoc loads and always validate schemas before production writes.
