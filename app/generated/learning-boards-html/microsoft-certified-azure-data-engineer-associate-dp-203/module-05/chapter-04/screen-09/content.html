MERGE example
from delta.tables import DeltaTable
from pyspark.sql.functions import current_timestamp

# Prepare updates_df as shown in the chapter
updates_df = spark.createDataFrame(updates_data, ["DeviceID", "ReadingDate", "Temperature"]).withColumn("ReadingDate", to_date(col("ReadingDate"), "yyyy-MM-dd"))

deltaTable = DeltaTable.forPath(spark, delta_path)

deltaTable.alias("target").merge(
    updates_df.alias("source"),
    "target.DeviceID = source.DeviceID AND target.ReadingDate = source.ReadingDate"
).whenMatchedUpdate(set = {
    "Temperature": "source.Temperature",
    "LastUpdated": current_timestamp()
}).whenNotMatchedInsert(values = {
    "DeviceID": "source.DeviceID",
    "ReadingDate": "source.ReadingDate",
    "Temperature": "source.Temperature",
    "LastUpdated": current_timestamp()
}).execute()
Checks and validations
  • Run the merge on a small test partition first.
  • Confirm before/after row counts and sample updated rows by ordering on keys.
  • Include audit columns to track the timing and origin of changes.
Common mistake

Executing MERGE without constraints or tests can accidentally overwrite rows. Always stage merges and validate results.
