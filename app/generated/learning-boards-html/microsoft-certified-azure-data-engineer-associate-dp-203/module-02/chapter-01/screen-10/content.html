Definition
Connect with Azure Data Studio
Authenticate with SQL Login and verify connectivity with a simple query.
-- After connecting, run this to verify the engine
SELECT @@VERSION;
Troubleshooting checklist
  • Confirm the server FQDN matches the portal value.
  • Ensure your client IP is permitted by the firewall rule.
  • Verify the admin username and password are correct and not expired.
Concrete example
Suppose the portal shows dp203-sqlserver.database.windows.net as the server. Use that as the server string and SQL Login credentials to connect. If SELECT @@VERSION; returns a value, your connection is validated.
Pro Tip
For production, prefer private endpoints or Managed Instance inside a VNet to avoid public exposure entirely.
Key Takeaway

Successful connection proves correct provisioning and networking; tighten access before promoting to production.
