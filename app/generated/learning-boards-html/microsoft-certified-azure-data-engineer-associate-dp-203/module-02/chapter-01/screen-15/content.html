Key Concepts — Quick Reference
Short definitions for review before practice.
DTU
A blended measure of CPU, memory, and I/O for simpler sizing of small workloads.
Logical SQL Server
A management boundary in Azure that holds databases, firewall rules, and server-level settings.
VNet Integration
Deploying resources into a Virtual Network for private IPs and network controls, central to Managed Instance.
Final takeaway

Keep these terms handy when sizing, grouping, and securing relational workloads in Azure.
