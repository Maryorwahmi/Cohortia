Definition
Azure SQL Database
A fully managed PaaS database engine for modern cloud applications.
Single Database
Isolated database for a single application or tenant with independent resources.
Elastic Pool
Multiple databases share a pool of resources to smooth utilization and cost.
Hyperscale
Scale storage and compute independently for very large databases.
Key Takeaway

Pick the deployment model based on tenancy and scale needs; Hyperscale is for very large growth.

Feature and usage bullets
  • Managed backups, automated patching, and built-in high availability reduce operational overhead.
  • Choose DTU for simpler, smaller workloads or vCore to independently size compute and storage for predictable performance.
  • Elastic Pools are effective when many databases have variable usage patterns.
  • Hyperscale supports rapid growth and very large datasets well beyond typical single database limits.
Concrete example
A SaaS team uses elastic pools to host dozens of small tenant databases and scales a top customer's database to Hyperscale as it grows beyond 10 TB.
Common mistake
Attempting a straight lift-and-shift of an on-premises instance with instance-level dependencies into a single database without refactoring.
