Process Flow › Provisioning

Step-by-step

  1. Create Synapse workspace and attach Data Lake Storage Gen2 with a filesystem.
  2. Specify subscription, resource group, workspace name, and admin credentials.
  3. Enable managed virtual network and set networking defaults for lab access.
  4. After workspace deploys, open Analytics pools and create a new dedicated SQL Pool.
  5. Choose a DWU level (example: DW100c) and create the pool; wait for provisioning.
Practical tip: start small for development, scale up for performance tests, and pause compute when idle to save cost.

Lab checkpoint

After creating the pool, confirm connectivity and that the SQL endpoint appears in the workspace. Then create a small staging table and run a simple query to validate execution.

Expected result
A provisioned SQL Pool ready to accept T-SQL and perform parallel queries according to its DWU allocation.
Key Takeaway

Provisioning is a reproducible checklist: workspace, attach storage, create pool, choose DWU, verify connectivity.
