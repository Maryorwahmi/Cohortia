Practice & Lab Focus

Clear, repeatable lab steps give you confidence making distribution and indexing decisions in production scenarios.

01 Provision Workspace
Create a workspace, attach Data Lake Storage Gen2, specify admin credentials, and enable managed virtual network for lab networking.
VERIFIED COMPETENCY MILESTONE
02 Create SQL Pool
From the Synapse workspace, create a dedicated SQL Pool, choose a DWU level like DW100c for cost-effective testing, then wait for provisioning.
VERIFIED COMPETENCY MILESTONE
03 Table Design
Create staging, fact, and dimension tables using Round Robin, Hash, and Replicated distributions and apply clustered columnstore to large facts.
VERIFIED COMPETENCY MILESTONE
04 Validate & Iterate
Run representative queries, inspect data movement and skew, and redistribute or change distribution keys if bottlenecks appear.
VERIFIED COMPETENCY MILESTONE
