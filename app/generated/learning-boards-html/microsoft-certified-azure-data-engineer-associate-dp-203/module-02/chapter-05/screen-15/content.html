What to Remember › Quick Reference
Distribution
Hash for keyed joins, Round Robin for staging, Replicate for small dims.
Indexing
Clustered columnstore for large facts; avoid frequent single-row updates.
Operations
Scale DWUs for load windows, pause when idle, and monitor for skew and shuffles.
Final thought
Good distribution and indexing decisions amplify the value of any compute you allocate; start with design, then tune DWUs and operations.
