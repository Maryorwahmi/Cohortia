This course uses concise examples and a practical lab to help you make distribution and indexing choices that minimize data movement and maximize query performance. You'll practice creating tables with different distributions and learn when to use a clustered columnstore index. Keep an eye on data skew and treat SQL Pool as an analytical engine, not an OLTP server.
