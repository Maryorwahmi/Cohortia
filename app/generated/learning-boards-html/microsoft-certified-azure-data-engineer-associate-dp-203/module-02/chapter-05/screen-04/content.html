Core Concept › What is SQL Pool?

Definition and Components

  • Control Node: Optimizes and coordinates parallel queries.
  • Compute Nodes: Store and process data partitions in parallel.
  • Storage: Decoupled Azure storage that holds persisted data.
Analogy
Think of the control node as an orchestra conductor and compute nodes as sections of musicians. The conductor assigns parts, and each section plays its piece in parallel to produce the full performance.

Why this matters

Large scans and aggregations are expensive on single-node systems because all data and work sit on one instance. SQL Pool parallelizes work across nodes so large reads and joins run far more efficiently.

Separating storage from compute lets you scale or pause compute independently, helping manage cost while keeping data available in Azure storage.

Common misconception

Do not treat SQL Pool as an OLTP database. It is optimized for batch analytics, not high-concurrency transactional workloads.

Key Takeaway

SQL Pool is an MPP analytics engine: control node coordinates, compute nodes store and compute, and storage is decoupled for flexibility.
