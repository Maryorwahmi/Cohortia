DWU fundamentals

DWUs combine compute, memory, and I/O. Higher DWUs give more parallelism and capacity to process large workloads faster. Use small DWUs for dev and scale up for production ETL or heavy queries.

Pausing the pool stops compute charges and preserves storage, which is useful for cost control in non-production environments.

Practical checklist

  • Start with DW100c for lab testing; scale up for load windows.
  • Schedule pause when idle to save compute cost in dev.
  • Pair scaling with distribution and columnstore optimizations to use resources effectively.
Key Takeaway

Scale DWUs to meet performance needs, pause to save cost, but always design tables so the compute you pay for is used efficiently.
