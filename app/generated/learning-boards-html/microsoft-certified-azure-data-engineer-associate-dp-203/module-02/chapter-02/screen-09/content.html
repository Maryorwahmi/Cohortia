Module 2 › Chapter 2.2 › Constraints
Primary Key
Uniquely identifies rows; often used as clustered index for fast lookups.
Foreign Key
Enforces referential integrity between tables to prevent orphaned rows.
Unique / Check / Default
Unique prevents duplicates; Check enforces domain rules; Default supplies values when none provided.
Practical guidance
Use constraints to make your schema self-validating. In ETL scenarios, plan constraint enforcement and batch operations so loads are efficient while integrity is preserved.
