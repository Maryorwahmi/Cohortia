Module 2 › Chapter 2.2 › Indexing Examples
Good index
Composite index on (DateKey, ProductKey) for date-and-product filters; narrow and selective, improves seeks.
Bad index
Index on a low-selectivity flag or on a very wide NVARCHAR column that repeats values; offers little benefit while increasing write cost.
Maintenance
Monitor fragmentation and rebuild or reorganize as needed. Schedule maintenance windows based on load patterns.
Filtered indexes
Use filtered indexes to index a subset of rows (for example, only current records), reducing index size and maintenance cost.
