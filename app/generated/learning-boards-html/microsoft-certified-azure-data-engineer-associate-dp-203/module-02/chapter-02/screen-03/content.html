Hands-on skills

Run the provided T-SQL, insert sample rows, and use SELECT and execution plans to confirm choices.

Starter checklist
  • Create Dim and Fact tables with surrogate primary keys.
  • Add non-clustered indexes on frequent filters and joins.
  • Insert representative sample data and run typical queries.
  • Measure reads, writes, and check query plans to validate improvements.
Quick tip
When testing, mimic peak load and realistic row counts so index and type choices reflect production behavior.
