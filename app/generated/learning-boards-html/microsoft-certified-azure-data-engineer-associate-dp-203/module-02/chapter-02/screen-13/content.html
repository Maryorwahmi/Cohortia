Test checklist
  1. Generate representative data shapes and volumes.
  2. Run typical and worst-case queries and capture plans.
  3. Measure logical reads, CPU, and execution time before/after changes.
  4. Simulate concurrent load to surface contention issues.
Interpreting results
Look for reduced scans, lower logical reads, and acceptable write latency. If a change improves one metric but degrades a critical one, iterate until trade-offs align with requirements.
Documentation: keep test scripts and results so future teams can reproduce and reason about the design.
