Module 3 › Chapter 2.4 › Engine Comparison
Summary matrix
PostgreSQL
Advanced types, JSONB, geospatial, extensibility. Suited for analytics and flexible-schema apps.
MySQL
Widely used in web stacks. Strong connector ecosystem and common in e-commerce and CMS workloads.
MariaDB
MySQL-compatible with additional engines and optimizers; currently Single Server on Azure.
Concrete example
If your app stores geospatial locations and runs spatial queries, PostgreSQL with PostGIS is often the best match. If you run a PHP CMS with many third-party plugins, MySQL compatibility and connector availability matter more. For an existing MariaDB analytic workload that uses ColumnStore, MariaDB Single Server may suffice.
Common misconception
Assuming engines are drop-in replacements. In practice, extensions, default parameters, and storage engines can change behavior and performance.
Key Takeaway

Choose by feature set first, then ensure the Azure deployment model supports your availability and network needs.
