Module 3 › Chapter 2.4 › psql Validation
Connection pattern
Use the admin account to validate connectivity, then create least-privilege users for applications. Confirm private DNS resolution from the client VM.
Checklist
  • Install client packages on the VM.
  • Run psql to the server FQDN and supply admin credentials.
  • Create a test table, insert rows, select, and exit cleanly.
Example session
psql -h <your_pg_server_name>.postgres.database.azure.com -U pgadmin -d postgres
Password: ********
postgres= > CREATE TABLE products (product_id SERIAL PRIMARY KEY, product_name VARCHAR(100), price DECIMAL(10,2));
postgres= > INSERT INTO products (product_name, price) VALUES ('Mouse', 25.50);
postgres= > SELECT * FROM products;
 product_id | product_name | price 
------------+--------------+-------
          1 | Mouse        | 25.50
(1 row)
postgres= > \q
Finish by creating an application-specific user with limited privileges instead of using admin in production.
