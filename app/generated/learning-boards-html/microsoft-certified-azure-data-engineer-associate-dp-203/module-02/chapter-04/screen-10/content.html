Module 3 › Chapter 2.4 › Deploy & Connect
Provisioning checklist
  • Create VNet and delegated subnet for the database.
  • Provision PostgreSQL Flexible Server with Private access and admin credentials.
  • Create a Linux VM in same VNet for client validation.
  • Install client and connect using admin account to run validation SQL.
Concrete verification
Create a products table, insert sample rows, and run a SELECT to confirm the database accepts DDL and DML from the private client.
Terminal demo steps
sudo apt update
sudo apt install postgresql-client -y

psql -h <your_pg_server_name>.postgres.database.azure.com -U pgadmin -d postgres

-- At the postgres prompt
CREATE TABLE products (
  product_id SERIAL PRIMARY KEY,
  product_name VARCHAR(100) NOT NULL,
  price DECIMAL(10, 2) NOT NULL
);
INSERT INTO products (product_name, price) VALUES ('Laptop', 1200.00);
SELECT * FROM products;
\q
Note: perform these commands from the VM that is inside the same VNet so DNS resolves the private endpoint correctly.
