Learning Objectives
Understand, secure, deploy, and manage open-source relational databases on Azure.
01
Differentiate engines
Recognize when PostgreSQL, MySQL, or MariaDB is the best fit for a workload and why that choice matters for features and extensibility.
VERIFIED COMPETENCY MILESTONE
02
Explain Flexible Server
Describe Flexible Server benefits: zone-redundant high availability, finer parameter control, and VNet integration for private access.
VERIFIED COMPETENCY MILESTONE
03
Configure network security
Set firewall rules, prefer VNet integration or Private Link, and avoid opening broad public ranges during tests.
VERIFIED COMPETENCY MILESTONE
04
Connect and validate
Use standard clients to connect, run simple DDL and DML, and verify that backups and restore settings meet recovery needs.
VERIFIED COMPETENCY MILESTONE

Mnemonic
Think Engine → Deployment → Network → Validate. This order minimizes exposure and ensures recoverability.
