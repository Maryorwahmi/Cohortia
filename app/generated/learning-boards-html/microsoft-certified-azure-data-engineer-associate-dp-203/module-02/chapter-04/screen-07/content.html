Module 3 › Chapter 2.4 › MariaDB Overview
Key points
  • MariaDB on Azure is provided as Single Server today.
  • Single Server lacks Flexible Server's zone redundancy and VNet injection; use Private Link or service endpoints for private connectivity.
  • Retain MariaDB when you need ColumnStore or MariaDB-specific optimizers, but plan for networking and availability constraints.
Scenario
Keep MariaDB for workloads tightly coupled to its engines, and design compensating measures for high availability and private network access.
