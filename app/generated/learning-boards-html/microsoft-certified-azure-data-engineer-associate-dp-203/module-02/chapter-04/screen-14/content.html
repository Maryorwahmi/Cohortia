Module 3 › Chapter 2.4 › Checklist
Availability
Prefer Flexible Server with zone redundancy for production availability.
Network Security
Use VNet integration or Private Link and avoid permissive firewall rules.
Backups
Test PITR restores and confirm retention windows match recovery needs.
Scaling
Monitor before scaling. Optimize queries and indexes to reduce unnecessary cost.
Access Control
Create least-privilege users for applications; avoid using admin accounts for app access.
Migration
Validate compatibility of extensions, parameters, and storage engines before cutover.
