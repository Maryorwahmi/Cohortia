Azure Database for PostgreSQL
Managed PaaS with Single and Flexible Server; choose Flexible for private networking and HA.
Azure Database for MySQL
Available in Single and Flexible Server; Flexible Server supports VNet integration and finer control.
Azure Database for MariaDB
Managed PaaS currently available as Single Server; plan network and HA workarounds if needed.
Summary
Match engine capabilities to workload requirements, prefer Flexible Server for production needs, and secure connectivity with VNet or Private Link.
