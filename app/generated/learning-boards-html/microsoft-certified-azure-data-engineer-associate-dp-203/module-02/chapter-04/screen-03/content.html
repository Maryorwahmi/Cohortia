05 • Monitor and Scale
Use Azure Monitor metrics to watch CPU, memory, and I/O. Scale compute tiers only when monitoring shows sustained pressure.
06 • Backups and PITR
Understand automatic backups, retention windows, and how to perform a point-in-time restore to an earlier state.
07 • Avoid common mistakes
Never leave a test server open with permissive firewall ranges. Start small to avoid unnecessary cost and then scale.
08 • Migration checks
Run compatibility tests for extensions, storage engines, and server parameters before migrating production workloads.
Verified Competency
Be able to monitor metrics, perform a point-in-time restore, and demonstrate a secure VNet-based connection to a Flexible Server.
