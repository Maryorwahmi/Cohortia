Module 2 › Chapter 2.3 › Hands-on: Simulated BULK INSERT
Steps to simulate a bulk load
  1. Ensure the database and target table exist
  2. Create or truncate a staging table
  3. Insert multiple rows in a single statement to simulate a file load
  4. Validate staging rows with queries
  5. MERGE into production tables inside a transaction
Safety note
For Azure SQL Database, real BULK INSERT requires blob storage access. This simulation teaches process and validation without external file setup.
Example SQL (simulated bulk insert)
USE mydataengdb;
GO

-- Drop and re-create DimProduct for a clean start
IF OBJECT_ID('DimProduct', 'U') IS NOT NULL DROP TABLE DimProduct;
GO

CREATE TABLE DimProduct (
    ProductKey INT IDENTITY(1,1) PRIMARY KEY,
    ProductID NVARCHAR(50) NOT NULL UNIQUE,
    ProductName NVARCHAR(255) NOT NULL,
    Category NVARCHAR(100)
);
GO

-- Simulate bulk insert by inserting multiple rows at once
INSERT INTO DimProduct (ProductID, ProductName, Category) VALUES
('P001', 'Laptop X1', 'Electronics'),
('P002', 'Monitor Ultra', 'Electronics'),
('P003', 'Webcam HD', 'Accessories'),
('P004', 'Gaming Keyboard', 'Accessories');
GO

-- Verify the inserted data
SELECT * FROM DimProduct;
