Where bcp fits
Client-side bulk copy for scripted, scheduled, or legacy workflows. Useful for producing files or ingesting from files when server-side access is limited.
Scenarios
  • Exporting snapshots to files for transfer
  • Importing prepared files into staging via automation
  • Complementing tools like ADF and SSIS in migration paths
Best practices
  • Log and checkpoint transfers for retries
  • Validate schema and sample rows after import
  • Combine with secure copy to blob storage for Azure consumption
Pro tip
Use bcp in a script that produces compressed files and then upload to Blob Storage for ADF or BULK INSERT to consume.
