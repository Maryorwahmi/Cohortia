Lift-and-shift pattern
Deploy existing SSIS projects to an SSIS catalog in Azure SQL or Managed Instance and execute them using an SSIS Integration Runtime in ADF.
Benefits
  • Preserves complex business logic
  • Reduces rewrite effort for hybrid connectivity
Considerations
  • Review external dependencies like file paths and drivers
  • Plan credential and network configurations for on-premises access
Decision checklist
  1. Is rewriting costlier than lift-and-shift?
  2. Does the package rely on local resources?
  3. Can you instrument monitoring in ADF?
