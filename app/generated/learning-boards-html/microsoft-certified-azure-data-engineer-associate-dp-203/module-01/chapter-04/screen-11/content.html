Module 2 › Chapter 1.4 › Medallion Architecture
Bronze, Silver, Gold
A layered folder approach that simplifies processing, lineage, and access control
Bronze — Raw
Raw, immutable data exactly as ingested. Example path: /raw/source_system/entity/year/month/day/file.csv
Silver — Cleaned
Standardized and enriched data ready for analytics. Example path: /conformed/entity/date
Gold — Curated
Aggregated, business-ready datasets for reporting and ML. Example path: /gold/entity
Key Takeaway

Separate layers clarify ownership, simplify lineage, and make it easier to apply RBAC and ACLs correctly across production and analytical users.
