RBAC and ACLs — complementary controls
Design access by combining broad roles with file-level permissions.
Role-Based Access Control (RBAC)
  • Grants broad permissions at account or container scope.
  • Assigned to Azure AD users, groups, or service principals.
  • Examples: Storage Blob Data Contributor, Storage Blob Data Reader.
Access Control Lists (ACLs)
  • POSIX-style permissions at the file and directory level (read, write, execute).
  • Applied to named users or groups to enforce fine-grained control.
  • Useful for separating team access within the same filesystem.
Concrete scenario
Grant a data engineering service principal contributor RBAC for broad write operations, then give an analytics group read and execute ACLs only on their analysis folder to restrict their ability to alter raw data.
