Activity: Create ADLS Gen2 and Set ACLs (Conceptual)
Follow these conceptual steps before running a live lab.
Step-by-step
  1. Create resource group: az group create.
  2. Create StorageV2 with --enable-hierarchical-namespace true.
  3. Create filesystem: az storage fs create --name datalake-root.
  4. Create directory: az storage fs directory create --name sales_data.
  5. Get AAD group object ID and set ACLs with az storage fs access set.
Validation & Cleanup
Validate by listing and reading as a group member. Ensure execute permission is included for traversal.
Clean up with az group delete if this was a temporary demo.
Key Takeaway

Walk through creation, permission assignment, and validation to ensure your ADLS Gen2 configuration enforces intended access patterns before production use.
