ACL command structure and example
Example ACL syntax and practical notes for setting folder permissions.
ACL Syntax
# Conceptual ACL command (do not run with placeholder IDs)
az storage fs access set \
  --file-system datalake-root \
  --path sales_data \
  --acl "user::$AAD_GROUP_OBJECT_ID:r-x" \
  --account-name ADLS_ACCOUNT_NAME
The entry user::ID:r-x grants read and execute for the named user or group; execute is needed to traverse directories.
Practical Tips
  • Always use real AAD object IDs when applying ACLs; placeholders won’t work.
  • Test permissions by listing and reading files as a member of the targeted group.
  • Remember RBAC can grant broader rights that supersede ACL restrictions.
Key Takeaway

ACLs provide folder-level control; include execute permission when you want users to traverse directories, and combine ACLs with RBAC for complete governance.
