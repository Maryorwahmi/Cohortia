Dual-Protocol Access & HDFS Compatibility
Coexistence of blob and file APIs eases migration and tool integration.
How it works
  • Data is stored once; both blob and file APIs operate on the same underlying storage and metadata.
  • HDFS-compatible clients see a file system and can perform directory and permission operations similar to HDFS.
  • Blob tools can continue to manage objects without requiring a migration rewrite.
Example
A Hadoop job can read a path using file-system semantics while a backup tool can copy blobs using blob APIs to the same account.
Key Takeaway

Dual-protocol access reduces migration friction and allows you to use the best tool for each job without duplicate storage.
