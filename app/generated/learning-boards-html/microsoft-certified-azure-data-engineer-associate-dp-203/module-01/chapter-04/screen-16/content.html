Module 2 › Chapter 1.4 › Key Concepts — Part 2
StorageV2
The storage account kind that supports ADLS Gen2 when hierarchical namespace is enabled.
RBAC
Use for broad role assignment to identities across scopes such as accounts and containers.
ACLs
Fine-grained, POSIX-like permissions applied at the file and directory level to control access precisely.
Final Takeaway

Enable hierarchical namespace on StorageV2, combine RBAC and ACLs, and apply medallion layering to create secure, performant, and manageable ADLS Gen2 data lakes.
