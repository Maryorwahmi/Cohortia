Create StorageV2 and enable Hierarchical namespace
A quick CLI example shows the exact flag that turns on ADLS Gen2 capabilities.
Process Steps
  1. Create a resource group.
  2. Create a StorageV2 account and set --enable-hierarchical-namespace true.
  3. Create a filesystem and directories inside it.
  4. Verify directory operations such as rename are metadata operations.
Note: choose a unique storage account name and appropriate SKU for your workload.
CLI Example
# Create a resource group
az group create --name ADLSGen2DemoRG --location eastus

# Create an ADLS Gen2 enabled storage account
az storage account create \
  --name adlsgen2demostore$(openssl rand -hex 4) \
  --resource-group ADLSGen2DemoRG \
  --location eastus \
  --sku Standard_LRS \
  --kind StorageV2 \
  --enable-hierarchical-namespace true
Key Takeaway

The --enable-hierarchical-namespace flag on StorageV2 is the single setting that transforms a storage account into an ADLS Gen2-capable account, enabling file-system operations for analytics tools.
