Create a filesystem and a directory
Conceptual commands you'll use after enabling hierarchical namespace
Commands
# Create filesystem (container)
az storage fs create \
  --name datalake-root \
  --account-name ADLS_ACCOUNT_NAME

# Create directory within the filesystem
az storage fs directory create \
  --name sales_data \
  --file-system datalake-root \
  --account-name ADLS_ACCOUNT_NAME
Replace ADLS_ACCOUNT_NAME and path names with your environment values. Ensure the account has hierarchical namespace enabled.
Checks & Notes
  • Verify the directory exists with a list command and that file creation is possible.
  • ACLs require the path to exist; set permissions after creating directories.
  • Consider naming conventions that include source, entity, and date for downstream processing.
Key Takeaway

Use the az storage fs and az storage fs directory commands to provision data lake filesystems and directories; validate path semantics before applying ACLs.
