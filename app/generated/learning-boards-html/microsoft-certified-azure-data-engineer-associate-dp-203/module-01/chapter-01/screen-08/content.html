Processing & Transformation
Match processing engines to batch, interactive, and streaming needs
Azure Databricks
Spark-based, ideal for large ETL jobs and interactive notebooks for data science.
Azure Synapse
Distributed SQL and integrated analytics for warehousing and BI workloads.
Stream Analytics
Real-time, windowed aggregation with low-code query semantics.
Concrete Example
Use Databricks for multi-terabyte nightly ETL and interactive notebooks; use Synapse to serve query-optimized tables to many BI users.
Key Takeaway

Processing choice should weigh volume, concurrency, and expected query patterns, not only familiarity.
