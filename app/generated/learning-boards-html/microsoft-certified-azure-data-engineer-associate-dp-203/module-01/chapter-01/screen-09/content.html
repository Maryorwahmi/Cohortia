Module 1 › Chapter 1.1 › ETL vs ELT
ETL
Extract, Transform, Load — transform before loading.

Use ETL when targets require curated data or cannot handle heavy transformations. It centralizes transformation before storage.

Example
Pre-transform nightly sales data and then load into a reporting database.
ELT
Extract, Load, Transform — load raw data first then transform using scalable compute.

ELT preserves raw data and leverages powerful processing engines to transform data in place. It helps with lineage and reprocessing.

Example
Load raw events to ADLS Gen2, then run Databricks jobs to produce curated tables.
Misconception

ELT is not careless: it preserves originals and can reduce movement, but requires transform compute and governance of raw data.
