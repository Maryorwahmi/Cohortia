Guided Portal Walkthrough
Locate the primary data services and review key overview pages without creating resources
Step-by-step
  1. Sign in to the Azure Portal and use the top search box.
  2. Search for: Storage accounts; open a storage account and observe hierarchical namespace options for ADLS Gen2.
  3. Search for: Azure SQL Database and Azure Synapse Analytics; open the overview pages and note performance or capacity settings.
  4. Search for: Azure Databricks, Azure Data Factory, Event Hubs, IoT Hub and inspect the service overviews.
  5. Open Resource groups to see logical organization and Cost Management to review spending summaries.
What to observe
Which services show built-in metrics on the overview page?
Does the storage account show hierarchical namespace enabled?
What configuration options affect cost directly?
Concrete Example
When viewing a storage account, find the Data Lake Storage Gen2 setting and the Access Control (IAM) pane to see how AAD roles are assigned.
Key Takeaway

Knowing where service settings and metrics live in the portal speeds configuration and troubleshooting later in hands-on labs.
