Ingestion Patterns
Select the right service by asking scale, latency, and device questions.
Azure Data Factory
Batch orchestration and ETL/ELT with many connectors and scheduling.
Event Hubs
High-throughput streaming for telemetry and event ingestion.
IoT Hub
Device-oriented ingestion with device identity and management.
Concrete Example
Nightly sales export: Data Factory. Millions of sensor events: Event Hubs. Device fleet with commands: IoT Hub.
Decision Checklist
Throughput & Latency
If continuous high throughput is required, prefer Event Hubs.
Scheduling & Connectors
If many source connectors and schedules are needed, Data Factory is ideal.
Device Management
If you need device twin and direct methods, choose IoT Hub.
Key Takeaway

Match the ingest service to the workload rather than forcing a single tool for all inputs.
