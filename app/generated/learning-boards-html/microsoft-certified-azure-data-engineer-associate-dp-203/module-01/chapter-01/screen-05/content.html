Data Lifecycle Timeline
A timeline of ingest, store, process, and consume with service examples
Ingest
Batch or streaming capture. Tools: Data Factory, Event Hubs, IoT Hub.
Store
Raw landing in ADLS Gen2; structured in Azure SQL or Synapse.
Process
Transform with Databricks, Synapse, or Stream Analytics depending on latency.
Consume
Power BI, ML models, or downstream services use curated outputs.
Concrete Example
Device telemetry → Event Hubs (ingest) → ADLS Gen2 (raw) → Databricks (transform) → Synapse tables (curated) → Power BI dashboards (consume).
Misconception
Treating stages as independent leads to rework. Decisions at ingest affect storage and processing cost and complexity.
Key Takeaway

Design the pipeline end-to-end with future consumers in mind; preserve raw data to enable reprocessing.
