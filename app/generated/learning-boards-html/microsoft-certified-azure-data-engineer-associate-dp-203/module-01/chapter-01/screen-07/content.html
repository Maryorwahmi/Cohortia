Module 1 › Chapter 1.1 › Storage Options
Storage Comparison
Pick storage by structure, scale, and access pattern
ADLS Gen2 / Blob
Raw and large-scale files for analytics. Hierarchical namespace in ADLS Gen2 improves performance for big data tools.
Azure SQL
Relational OLTP workloads with low-latency transactions and structured schema.
Cosmos DB
Globally distributed, low-latency, schema-flexible operations for application backends.
Azure Synapse Analytics
Distributed SQL engine for data warehousing and integrated analytics at scale.
Concrete Example
Store petabytes of raw IoT files in ADLS Gen2 for Databricks processing; load curated, structured tables into Synapse for BI.
Key Takeaway

Selecting appropriate storage reduces cost and improves processing performance; avoid forcing all data into a relational store.
