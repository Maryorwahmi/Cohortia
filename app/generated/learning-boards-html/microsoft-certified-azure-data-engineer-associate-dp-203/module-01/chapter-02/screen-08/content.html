Module 1 › Chapter 1.2 › Access Tiers: Hot, Cool, Archive
Hot
Optimized for frequent access. Lowest access cost, higher storage price. Use for active analytics and frequently read content.
Cool
For infrequently accessed data stored for at least 30 days. Lower storage cost, higher access cost. Good for short-term backups.
Archive
Lowest storage cost, highest retrieval cost and latency. Use for long-term archives where retrieval in hours is acceptable.
Lifecycle example
Automate transitions: Hot → Cool after 30 days → Archive after one year for long-term cost savings while keeping recent data hot.
Key Takeaway

Tiers let you align storage cost to access patterns. Use lifecycle rules to automate transitions and avoid manual rehydration surprises.
