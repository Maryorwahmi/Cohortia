Account types
General-purpose v2 (GPv2) supports blobs, files, queues, tables and access tiers and is the typical default. Premium block blob accounts are specialized for high-performance block blob workloads.
Example decision
If you run interactive workloads that require sub-10 millisecond reads at scale from block blobs, evaluate Premium block blob accounts. Otherwise, GPv2 is usually sufficient.
Operational checklist
  • Measure IOPS and throughput before choosing Premium.
  • Check regional availability and cost implications for the chosen account type.
  • Consider lifecycle, tiering, and redundancy in the account configuration.
Key Takeaway

Choose the account to match performance needs. Default to GPv2 for flexibility; reserve Premium for measured high-performance needs.
