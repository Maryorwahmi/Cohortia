Module 1 › Chapter 1.2 › Azure Files and Azure Disks
Azure Files
Managed SMB shares for shared access across machines, ideal for lift-and-shift and shared configuration stores.
Example
A legacy application expecting a network drive can mount an Azure Files share with minimal changes.
Azure Disks
Attachable, persistent block storage for VMs used as OS or data disks with predictable latency and IOPS.
Example
A database on a VM requires a disk with consistent IOPS; use Azure Disks for predictable performance.
Common pitfall
Choosing Azure Files for a VM boot or OS disk does not provide attach semantics; you must use Azure Disks for OS volumes.
Key Takeaway

Use Files for shared network storage; use Disks for attachable VM volumes. Match semantics to application expectations.
