Module 1 › Chapter 1.2 › Page and Append Blobs
Page blob (random write)
Designed for random read/write at page granularity. Primary use: VHDs for virtual machines where sectors are updated in place.
Example
A VM OS disk requires low-latency random writes; a page blob stores the VHD with appropriate semantics.
Append blob (append-only)
Optimized for append operations; ideal for logs, audit trails, and sequential event streams where data is only added to the end.
Example
Collecting server logs in an append blob avoids the cost and complexity of rewriting files for each new entry.
Common mistake
Using block blobs and rewriting files for append workloads increases operations and cost. Choose append blobs for logging patterns.
Key Takeaway

Match the blob type to the write pattern: random writes need page blobs; append-only streams need append blobs.
