Blob types and when to use them
Block blob
Optimized for large file uploads and general object storage; most data lakes and media use block blobs.
Page blob
Supports random read/write operations at page granularity; used for VHDs and persistent VM disks.
Append blob
Optimized for append operations; ideal for logs and audit trails where data is continually appended.
Example scenario
A streaming telemetry application appends events continuously; append blobs let you add entries without rewriting entire files, reducing write operations and cost.
Operational notes
  • Block blobs support parallel block uploads for high throughput and efficient large-file transfer.
  • Page blobs allow random writes but are billed differently than block blobs and are optimized for VM scenarios.
  • Append blobs are append-only; they are not designed for arbitrary overwrites.
Key Takeaway

Choose a blob type that matches your read/write characteristics. Matching reduces operations, cost, and latency.
