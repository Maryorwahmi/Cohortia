Learning Objectives

Learn, understand, apply, and master key Blob Storage tasks.

Bloom: Learn → Understand → Apply → Master
01
Create storage accounts & containers

Use the Azure Portal and the Azure CLI to create resource groups, storage accounts and containers for pipelines. Automation supports repeatable deployments.

Verified competency milestone
02
Perform blob operations

Upload, list, download and delete blobs using CLI and tools. These operations form the core of ingestion and retrieval workflows.

Verified competency milestone
03
Manage lifecycle policies

Define rules that move older objects to Cool or Archive tiers or delete them, reducing long-term storage cost.

Verified competency milestone
04
Secure access with SAS

Grant least-privilege, time-limited access with Shared Access Signatures and prefer user delegation SAS when possible.

Verified competency milestone
