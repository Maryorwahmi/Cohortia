Definition

Account keys vs Shared Access Signatures

Account keys grant full control; SAS grants limited, time-bound permissions to specific resources.

Storage Account Access Keys
Two keys that grant admin-level access across the entire storage account. Keep them secret and rotate regularly.
Shared Access Signature (SAS)
A URI that grants scoped permissions for a specified period. Use for delegated access without exposing account keys.
Concrete example
For a vendor needing read-only listing for 48 hours, generate a user delegation SAS scoped to the container instead of sharing an account key. This gives least privilege and an expiry date.
Why prefer User Delegation SAS
It is secured by Azure AD credentials and provides improved auditability and rotation compared to account-key-based SAS.
Common mistake
Creating a long-lived SAS with broad permissions. Always scope and expire tokens appropriately.
Key Takeaway

Prefer SAS and user delegation SAS for scoped, auditable access; treat account keys as root credentials to protect and rotate.
