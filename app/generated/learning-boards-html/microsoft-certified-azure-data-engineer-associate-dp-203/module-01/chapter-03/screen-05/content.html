Choose the right interface

Each interface supports different workflows. Match tool to task: manual configuration, development, or automation.

Azure Portal
Quick visual configuration and lifecycle policy editing. Use for inspection and manual adjustments.
Storage Explorer
Desktop browsing with drag-and-drop. Good for local development and inspection of blob contents.
Azure CLI / PowerShell
Preferred for scripting, automation, and pipeline integration. Repeatable and CI/CD friendly.
SDKs
Use when embedding storage operations in applications. Handle retries, chunking, and advanced logic programmatically.
Practical tip
Test in the Portal or Storage Explorer, capture the equivalent CLI commands, then script them for automation. This gives you speed and repeatability together.
Example workflow
Create a container in the Portal to verify settings, then run the az storage container create command in your CI script for consistent environments.
