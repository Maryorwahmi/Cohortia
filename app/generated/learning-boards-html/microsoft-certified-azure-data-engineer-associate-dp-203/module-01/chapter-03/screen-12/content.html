Hands-on Activity

Manage blobs with the Azure CLI

Define variables, create resources, upload a file, verify, and clean up. This sequence demonstrates the typical pipeline lifecycle.

Activity script (example)
RESOURCE_GROUP="BlobDemoRG"
LOCATION="eastus"
STORAGE_ACCOUNT_NAME="blobdemostorage$(openssl rand -hex 4)"
CONTAINER_NAME="my-first-container"
LOCAL_FILE="sample_data.txt"
BLOB_NAME="my_uploaded_file.txt"

# Create resources
az group create --name $RESOURCE_GROUP --location $LOCATION
az storage account create --name $STORAGE_ACCOUNT_NAME --resource-group $RESOURCE_GROUP --location $LOCATION --sku Standard_LRS --kind StorageV2
az storage container create --name $CONTAINER_NAME --account-name $STORAGE_ACCOUNT_NAME --public-access off

# Upload and list
az storage blob upload --container-name $CONTAINER_NAME --file $LOCAL_FILE --name $BLOB_NAME --account-name $STORAGE_ACCOUNT_NAME
az storage blob list --container-name $CONTAINER_NAME --account-name $STORAGE_ACCOUNT_NAME --output table

# Cleanup
az group delete --name $RESOURCE_GROUP --yes --no-wait
Verification: Confirm blob appears in list and can be downloaded to verify contents.
Caution: Use disposable resource groups for labs and initiate cleanup to avoid charges.
Key Takeaway

Automate the workflow but always include verification and cleanup steps; this keeps labs low-cost and repeatable.
