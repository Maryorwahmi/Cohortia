Working with Azure Blob Storage

Create and manage storage accounts, containers, and blobs; automate lifecycle rules to reduce cost; and grant secure, time-limited access with SAS.

In this lesson
Create accounts and containers with the Azure CLI and run common blob operations.
Coming up
Define lifecycle rules to move cold data to Cool or Archive tiers.
Security
Prefer user delegation SAS, rotate keys, and avoid hardcoding secrets.
Concept map
Terminal-first layout
Container
Logical grouping of blobs. Think folder-like boundaries inside a storage account.
Blob
An object stored inside a container: files, logs, and data artifacts.
Lifecycle
Rules to tier or delete blobs automatically to optimize cost.
Access
SAS tokens for scoped access; account keys for full admin control — treat keys like root secrets.
Tip: practice the CLI commands in a disposable resource group and clean up when finished.
