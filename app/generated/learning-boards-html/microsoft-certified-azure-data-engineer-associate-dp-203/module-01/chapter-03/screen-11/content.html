Best Practices

Least privilege, rotation, and safe storage of secrets

Adopt managed identities and Azure Key Vault, rotate keys, and avoid embedding secrets in code or configuration files.
- Store account keys in Key Vault and use access policies to control retrieval.
- Prefer user delegation SAS for application-level access when Azure AD is available.
- Use short-lived SAS tokens and restrict permissions to read only when possible.
Common mistakes
  • Hardcoding account keys into scripts or repos.
  • Generating SAS without expiry or with excessive permissions.
  • Not using --public-access off when storing sensitive data.
Quick mitigation
Use Key Vault and managed identities, enforce short SAS lifetimes, and audit SAS creation and usage.
Key Takeaway

Treat account keys as root credentials, prefer Azure AD-backed SAS, and automate rotations and audits to reduce risk.
