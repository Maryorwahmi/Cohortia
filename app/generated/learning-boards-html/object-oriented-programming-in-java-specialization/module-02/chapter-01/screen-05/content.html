Syntax

Class declaration pattern

class Book extends LibraryItem {
  String author;
  int pageCount;

  public Book(String title, String itemID, String author, int pageCount) {
    super(title, itemID);
    this.author = author;
    this.pageCount = pageCount;
  }

  public void displayBookDetails() {
    System.out.println("Book Title: " + getTitle());
  }
}
The extends clause expresses the is-a relationship and makes inherited members available to the subclass.
Process
1
Declare extends
Write class Sub extends Super in the class header.
2
Use inherited members
Call methods or use protected fields from the subclass without redefining them.
3
Override when needed
Provide a new implementation if the subclass must change behavior.
Common mistake

Don't use extends to copy shared code if the relationship is not an is-a. That leads to rigid designs.
