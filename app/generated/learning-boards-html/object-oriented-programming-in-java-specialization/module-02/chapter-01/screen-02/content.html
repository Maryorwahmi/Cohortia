Learning Objectives

Master the essentials of extends, super, and appropriate inheritance design.

Bloom: Learn → Understand → Apply → Master
01
Explain inheritance

Define inheritance and describe its benefits for reuse and hierarchy. You'll be able to say what passes from parent to child in concrete terms.

Mnemonic: family tree Venn showing shared traits
VERIFIED COMPETENCY MILESTONE
02
Use extends

Implement the extends keyword to create a subclass. Practice making a clear is-a relationship so behavior is inherited correctly.

Mnemonic: chain link icon — classes connected
VERIFIED COMPETENCY MILESTONE
03
Apply super correctly

Use super() to call superclass constructors and super.field or super.method to reference the immediate superclass when needed.

Mnemonic: upward arrow showing constructor flow
VERIFIED COMPETENCY MILESTONE
04
Choose inheritance wisely

Identify scenarios where inheritance fits and avoid using it for has-a relationships; favor composition when an object contains another.

Mnemonic: is-a vs has-a two-column check
