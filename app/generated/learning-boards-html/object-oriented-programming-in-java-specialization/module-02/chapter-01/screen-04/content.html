Module 2 › Chapter 2.1 › What is inheritance?
Definition

Inheritance explained

A subclass gets fields and methods from a superclass, forming an is-a relationship and enabling code reuse and clearer hierarchies.

Why it matters
  • Reduce duplication by implementing behavior once in the superclass.
  • Create logical hierarchies that reflect domain models.
  • Allow polymorphic use of objects that share a common base.
Key Takeaway

Use inheritance for true is-a relationships to share behavior and state safely.

Analogy & Example
Family tree analogy

Child classes inherit common traits from parent classes, but can add or override methods.

Concrete code idea

LibraryItem defines borrowItem and returnItem once. Book reuses these and adds author and pageCount.

Quick check

Ask: does X truly is-a Y? If yes, inheritance helps. If not, prefer composition where an object has another object as a field.
