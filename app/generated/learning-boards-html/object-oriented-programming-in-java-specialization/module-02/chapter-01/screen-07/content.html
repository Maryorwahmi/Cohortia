Module 2 › Chapter 2.1 › Constructors and super()
Rule

Superclass constructor runs first

Always ensure the superclass is initialized before subclass-specific fields are set; use super(...) to pass required values if the superclass has no default constructor.

public class LibraryItem {
  public LibraryItem(String title, String itemID) { ... }
}

public class Book extends LibraryItem {
  public Book(String title, String itemID, String author, int pageCount) {
    super(title, itemID);
    // subclass fields initialized here
  }
}
Pro tip

If you see a compile error about missing constructor calls, check whether the superclass lacks a no-argument constructor and add an explicit super call.

Step-by-step
1
Create superclass constructor
Define required arguments that initialize shared state.
2
Call super from the subclass
Place super(...) as the first statement in the subclass constructor to pass values up.
3
Initialize subclass fields
After super returns, set subclass-specific state.
