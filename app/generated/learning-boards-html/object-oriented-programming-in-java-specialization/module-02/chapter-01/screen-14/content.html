Module 2 › Chapter 2.1 › Key Concepts
Inheritance (is-a)
A subclass reuses behavior and state from a superclass when it represents a specialization.
extends & super
Use extends to declare inheritance and super to call the superclass constructor or reference its members.
Visibility rules
Public and protected members are available to subclasses; private members require accessors to be used.
Takeaway
Inheritance simplifies reuse when used for true specialization; always manage constructors and visibility deliberately.
