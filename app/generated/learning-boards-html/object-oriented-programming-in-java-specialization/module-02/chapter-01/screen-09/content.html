Module 2 › Chapter 2.1 › Is-a vs Has-a
Inheritance (Is-a)

Example: Book is a LibraryItem.

Use inheritance when a subclass can substitute for its superclass and shares behavior conceptually.

Composition (Has-a)

Example: Car has an Engine.

Prefer composition when one class should own or encapsulate another without implying a subtype relationship.

Checklist to choose
  • Can the subclass be used where the superclass is expected? If yes, consider inheritance.
  • Does the relationship represent ownership rather than specialization? If yes, use composition.
