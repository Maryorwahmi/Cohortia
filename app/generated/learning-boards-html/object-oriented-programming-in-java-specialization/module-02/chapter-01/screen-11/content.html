Starter code
class Shape {
    String color;

    public Shape(String color) {
        this.color = color;
    }

    public void displayColor() {
        System.out.println("Shape color: " + this.color);
    }
}

// Create Circle and Rectangle that extend Shape
Use super(color) in each subclass constructor and implement calculateArea.
Success criteria
  • Circle and Rectangle call super(color) first in their constructors.
  • calculateArea returns correct numeric values for test inputs.
  • displayColor prints the color from the Shape superclass.
