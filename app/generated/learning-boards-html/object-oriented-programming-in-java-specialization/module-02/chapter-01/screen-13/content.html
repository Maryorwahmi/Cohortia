Module 2 › Chapter 2.1 › When to extend
Practical scenarios
Domain modeling
When types are natural specializations of a shared concept, centralize shared behavior in the superclass.
Code reuse
When multiple types use identical operations, inheritance avoids duplication.
Polymorphism
When you will treat different concrete types through a common superclass reference.
Key Takeaway

Adopt inheritance when specialization and substitution are natural; otherwise favor composition for flexibility.
