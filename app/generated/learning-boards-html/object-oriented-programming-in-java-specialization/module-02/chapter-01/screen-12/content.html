Module 2 › Chapter 2.1 › super() initialization
Scenario

When a superclass only provides a constructor with parameters, subclasses must call super with appropriate arguments to initialize inherited state.

Why this matters
  • Ensures superclass fields are initialized before subclass code runs.
  • Avoids compile-time errors about missing constructor calls.
  • Keeps object initialization predictable across the hierarchy.
Common multiple-choice trap

Options that assign superclass private fields directly or attempt to call the superclass constructor like a method are incorrect. Use super(arguments) as the constructor call.
