Two quick questions

Q1: Read-only Numbers
Which parameter accepts List<Integer> and List<Double> and lets you read Number values?
Answer: List<? extends Number>
Explanation: Upper-bound allows reading as Number but prevents adding.
Q2: Adding Integers
Which signature allows adding Integer to List<Number> or List<Object>?
Answer: public static <T> void fillList(List<? super T> list, T element)
Explanation: Lower-bound allows list to accept T values across supertypes.
Quick reflection

Answering these questions by focusing on whether the parameter produces or consumes will make your wildcard choices consistent and safe.
