Using ? extends T

Use when the list produces values your method will read as T.
public static void printNumbers(List<? extends Number> list) {
  for (Number n : list) {
    System.out.print(n + " ");
  }
  // list.add(new Integer(10)); // Compile-time error
  System.out.println();
}

List<Integer> ints = List.of(1,2,3);
List<Double> dbls = List.of(1.1,2.2);
printNumbers(ints);   // OK
printNumbers(dbls);   // OK
Example insight
Because the exact subtype is unknown, the compiler forbids additions. The list is trusted for read operations where Number is the minimal common type.
Misconception: ? extends Number allows adding Number values. Not true. Adding would break lists parameterized with a stricter subtype.
Takeaway
Key Takeaway

Use ? extends T when the method treats the argument as a producer of T values; avoid add() on such lists.
