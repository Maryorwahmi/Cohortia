Module 5 › Chapter 5.2 › Key Concepts
Generic Method
Method declares <T> before the return type so one method handles many types safely.
Type Inference
Compiler usually infers method type arguments from actual parameters, keeping calls concise.
Wildcard ?
Represents an unknown element type; List<?> is read-only for typed adds.
? extends T
Use for producers: safe to read T, not safe to add typed elements.
? super T
Use for consumers: safe to add T, retrievals are Object without casts.
PECS
Producer Extends, Consumer Super — a quick rule to pick bounds based on intent.
Summary

Use method-level generics for reusable utilities. Use bounded wildcards and PECS to design safe APIs that read or write collections as intended.
