Learning Objectives

Understand the skills you'll practice and why they matter.
01
Design generic methods
Write methods that declare their own type parameters to avoid overloads and make utilities reusable across types. This reduces duplication and preserves compile-time checks.
VERIFIED COMPETENCY MILESTONE
02
Use type inference
Rely on the compiler to infer method type parameters from invocation arguments, which simplifies calls while preserving types. Know when to specify types explicitly for ambiguous calls.
VERIFIED COMPETENCY MILESTONE
03
Apply bounded wildcards
Choose ? extends T when you need to read T instances, and ? super T when you will add T instances. This choice enforces safe usage patterns with collections.
VERIFIED COMPETENCY MILESTONE
04
Avoid common pitfalls
Recognize errors such as adding to an upper-bounded list, creating arrays of T, or using raw types. These mistakes lead to compile-time failures or unsafe casts.
VERIFIED COMPETENCY MILESTONE
