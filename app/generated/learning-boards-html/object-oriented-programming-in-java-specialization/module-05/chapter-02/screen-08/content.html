Using ? super T

Use when your method intends to add T instances into the collection; the collection consumes T values.
public static void addIntegers(List<? super Integer> list) {
  list.add(1);
  list.add(2);
  // Integer i = list.get(0); // Compile-time error
  Object o = list.get(0); // OK
}

List<Number> numbers = new ArrayList<>();
addIntegers(numbers); // Works
Concrete explanation
Because the list could be a supertype, the most specific type you can assume when retrieving is Object. Adding is safe for T values and subtypes of T.
Misconception: ? super Integer lets you read Integers without a cast. Not guaranteed; retrieved values are typed as Object unless you cast.
Quick check
If you mainly write into a collection, prefer ? super T so callers can pass broader destination types.
