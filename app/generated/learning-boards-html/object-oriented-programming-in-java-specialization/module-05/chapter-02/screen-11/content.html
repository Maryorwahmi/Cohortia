copyList implementation

Apply PECS: source produces, destination consumes.
public static <T> void copyList(List<? extends T> source, List<? super T> destination) {
  for (T element : source) {
    destination.add(element);
  }
}

// Usage:
List<Number> destination = new ArrayList<>();
List<Integer> source = List.of(1,2,3);
copyList(source, destination); // destination now contains 1,2,3
Why it works
The source yields T elements; the destination accepts T or any supertype, so each element can be added without violating type rules.
Misconception: swapping bounds will fail. If you declared destination as ? extends T, you could not call add(element) safely.
Key Takeaway

The copyList signature captures data flow: read from extends, write to super, and preserve type safety across different list types.
