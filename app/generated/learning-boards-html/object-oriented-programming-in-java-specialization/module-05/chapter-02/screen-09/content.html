Core Concept

PECS: Producer Extends, Consumer Super

A mental model to pick ? extends or ? super based on whether the parameter supplies or accepts values.
Producer (read)
Use List<? extends T> when you only need to extract T values from the collection.
Example: source for copyList — you iterate and take elements out.
Consumer (write)
Use List<? super T> when you will add T values into the collection.
Example: destination for copyList — you add elements into it.
Key Takeaway

PECS gives a one-sentence decision rule: if the parameter produces T use extends; if it consumes T use super.
