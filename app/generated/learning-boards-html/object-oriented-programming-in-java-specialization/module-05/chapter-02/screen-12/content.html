Example

fillList signature

When you want to add an element into a caller-provided collection, list should be declared with ? super T.
public static <T> void fillList(List<? super T> list, T element) {
  list.add(element);
}

List<Number> nums = new ArrayList<>();
fillList(nums, 42); // OK: Integer is a T compatible with Number
When not to use
If you need to read back an element as T, prefer List<T> because wildcard retrieval yields Object and requires casts.
Use fillList for builders, initializers, or API entry points that push items into a caller-supplied collection.
