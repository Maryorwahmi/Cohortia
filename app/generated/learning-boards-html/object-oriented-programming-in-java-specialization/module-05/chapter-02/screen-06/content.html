Unbounded wildcard vs raw and concrete types

List<?> means "some specific but unknown element type." You can read as Object but cannot add typed elements. Raw types (List) lose compile-time checks and should be avoided.
Use case: a logger that prints any list contents—you only need to iterate and treat each item as Object.
Pitfall: trying to add an Integer to List<?> is a compile-time error because the specific element type is unknown.
Concrete example
public static void printAnyList(List<?> list) {
  for (Object o : list) {
    System.out.print(o + " ");
  }
  System.out.println();
}

// Can call with List<Integer>, List<String>, etc.
Key takeaway
Key Takeaway

Use List<?> for read-only utilities that accept any element type; do not use it when you need to add typed elements.
