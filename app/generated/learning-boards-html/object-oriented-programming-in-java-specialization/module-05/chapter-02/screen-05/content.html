Definition

Compiler type inference

The compiler binds a method type parameter from the argument types at the call site so you typically omit explicit type arguments.
Integer[] ints = {1,2,3};
String[] strs = {"A","B"};
Double[] dbls = {1.1,2.2};

// Compiler infers T as Integer, String, Double respectively
printArray(ints);
printArray(strs);
printArray(dbls);

// Explicit type argument (rarely needed):
GenericMethodExample.<Integer>printArray(ints);
Concrete example
Type inference keeps calls short. Use explicit type parameters only when the compiler cannot deduce the type or when you want to force a specific parameterization.
Misconception
Inference is not dynamic typing. The chosen type is used for compile-time checks; generic information is erased at runtime, but you still get compile-time guarantees.
Check your understanding
If a method returns a value whose type cannot be inferred, consider supplying an explicit type argument to guide the compiler.
