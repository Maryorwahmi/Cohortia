Common Pitfall

Why add() fails on ? extends

Because the list could be a subtype-specific list, adding would risk inserting an incompatible subtype. The compiler prevents it.
Example: list.add(new Integer(10)) is a compile-time error when list is List<? extends Number> because the exact element type might be Double.
Common Pitfall

Why reads from ? super are Object

If the collection is declared as ? super T, it could be List<Object> or List<Number>, so the only safe retrieval type is Object without a cast.
If you need to both add and read a specific type, avoid conflicting wildcards; prefer concrete parameterized types or split responsibilities into separate methods.
Key Takeaway

When uncertain, ask whether the method will write or read; the answer tells you which wildcard is safe. For mixed read/write, use concrete types or separate APIs.
