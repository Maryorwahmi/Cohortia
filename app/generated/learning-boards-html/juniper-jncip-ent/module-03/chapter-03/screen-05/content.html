BGP Attribute Deep Dive

Local Preference: Influencing Outbound Traffic

An IBGP Attribute for Internal Path Selection

IBGP Only

Exchanged only among IBGP peers within the same Autonomous System (AS).

Outbound Traffic

Primary function is to influence how your AS sends traffic to external destinations.

Higher is Preferred

Routers prefer paths with a higher Local Preference value.

Key Takeaway

Local Preference is an IBGP attribute used to steer outbound traffic from an AS, with higher values indicating a more preferred exit path.

Local Preference in Action
Traffic prefers the path with the highest Local Preference value.
