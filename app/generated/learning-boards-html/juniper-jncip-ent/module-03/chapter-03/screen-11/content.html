Best Practices

Avoiding Common BGP Path Control Pitfalls

Ensuring Stability and Predictability in Your Network

Local Preference Scope

Misunderstanding its IBGP-only, outbound traffic influence.

MED Comparison

Forgetting it's only compared between routes from the *same* neighboring AS.

AS-Path Prepending

Prepending incorrect AS numbers or excessive times, leading to unreachable routes.

Safety Note

Always verify BGP path attributes using `show route detail` and `show bgp neighbor advertised-routes`. Test thoroughly in a lab environment before deploying changes to production to avoid network disruptions.

Key Takeaway

Incorrect application of BGP path control attributes can lead to unexpected routing; always verify configurations and test thoroughly.
