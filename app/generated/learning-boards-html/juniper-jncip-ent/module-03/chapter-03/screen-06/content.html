Configuring Local Preference in Junos OS

Policy-Based Outbound Traffic Steering

[edit policy-options]
prefix-list PREFER_ISP_B_FOR_THESE {
    192.0.2.0/24;
}

policy-statement SET_LP_ISP_A {
    term ALL_ROUTES_ISP_A {
        from protocol bgp;
        then {
            local-preference 200; # Prefer ISP-A generally
            accept;
        }
    }
}

policy-statement SET_LP_ISP_B {
    term SPECIFIC_ROUTES_ISP_B {
        from {
            protocol bgp;
            prefix-list PREFER_ISP_B_FOR_THESE;
        }
        then {
            local-preference 250; # Even higher LP for specific prefixes via ISP-B
            accept;
        }
    }
    term ALL_OTHER_ROUTES_ISP_B {
        from protocol bgp;
        then {
            local-preference 150; # Lower LP for other routes via ISP-B
            accept;
        }
    }
}
Key Takeaway

Junos OS uses import policies with the `local-preference <value>` action to configure Local Preference, directing outbound traffic.

Prefix-List Definition

Identifies specific routes that require special handling, allowing granular control.

Policy for ISP-A

Sets a higher Local Preference (e.g., 200) for all routes received from ISP-A, making it the general preferred outbound path.

Policy for ISP-B

Uses multiple terms to set an even higher Local Preference for specific prefixes, and a lower one for general routes, via ISP-B.

Pro-Tip

Apply these policies as import policies to the respective BGP groups or neighbors to ensure they take effect on incoming routes.
