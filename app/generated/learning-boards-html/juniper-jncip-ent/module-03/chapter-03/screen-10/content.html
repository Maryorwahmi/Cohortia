Configuring AS-Path Prepending in Junos OS

Policy-Based Inbound Traffic De-prioritization

[edit policy-options]
policy-statement PREPEND_TO_ISP_B {
    term PREPEND_AS {
        from protocol bgp; # Or specific prefixes you want to prepend
        then {
            as-path prepend "65000 65000 65000"; # Prepend your AS (e.g., 65000) three times
            accept;
        }
    }
}
Key Takeaway

Junos OS uses export policies with the `as-path prepend <AS-number>` action to lengthen the AS_Path, de-prioritizing inbound traffic.

Export Policy Creation

Define a policy that will be applied to routes advertised to the less preferred ISP.

`as-path prepend` Action

Use this action to add your AS number multiple times, making the path appear longer.

Pro-Tip

Typically, 2-4 prepends are sufficient. Excessive prepending can make your routes appear too far away and potentially cause them to be filtered.
