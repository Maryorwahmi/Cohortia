Configuring MED in Junos OS

Policy-Based Inbound Traffic Steering from a Neighboring AS

[edit policy-options]
prefix-list SERVICE_PREFIX {
    10.0.0.0/24;
}

policy-statement SET_MED_TO_ISP_A_LINK1 {
    term SERVICE_TRAFFIC {
        from {
            protocol bgp;
            prefix-list SERVICE_PREFIX;
        }
        then {
            metric 10; # Lower MED for service traffic via link-1
            accept;
        }
    }
    term ALL_OTHER_TRAFFIC {
        from protocol bgp;
        then {
            metric 50; # Higher MED for other traffic via link-1
            accept;
        }
    }
}
Key Takeaway

Junos OS uses export policies with the `metric <value>` action to configure MED, influencing inbound traffic from a specific neighboring AS.

Prefix-List for Services

Defines specific service prefixes that require distinct MED values for traffic steering.

Policy for Link-1

Sets a lower MED for service traffic and a higher MED for general traffic advertised via Link-1.

Common Mistake

Forgetting that MED is only compared between routes received from the *same* neighboring AS. It cannot influence traffic from different ISPs.
