Key Concepts: Part 1

Core BGP Path Control Attributes

Local Preference

An IBGP attribute used to influence outbound traffic from an AS; higher values are preferred.

Multi-Exit Discriminator (MED)

An EBGP attribute used to influence inbound traffic into an AS from a specific neighboring AS; lower values are preferred.

AS-Path Prepending

A technique used to lengthen the AS_Path attribute, making a path less desirable to influence inbound traffic from any AS.

Summary

These three BGP attributes are essential for fine-grained control over both outbound and inbound traffic flows in multi-homed networks.
