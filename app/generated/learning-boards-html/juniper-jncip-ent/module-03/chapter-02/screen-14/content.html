Key Concepts

Advanced takeaways from this chapter

`prefix-list`

A named list of IP prefixes for matching routes based on network address and length.

`route-filter`

A granular method for matching routes based on prefixes, allowing exact, longest-match, or range-based matching.

Import Policy

Applied to routes received from a BGP peer, controlling which routes are accepted into the local routing table.

Export Policy

Applied to routes advertised to a BGP peer, controlling which routes are sent out from the local routing table.

Implicit `reject`/`accept`

The default action for unmatched routes in a policy: `reject` for import, `accept` for export.

Summary Takeaway

Effective BGP policy implementation relies on precise matching, correct directional application, and careful consideration of implicit default actions to ensure network stability and desired traffic flow.
