Granular Control with `route-filters`

Exact, Longest-Match, and Range-Based Prefix Matching

Beyond Prefix-Lists

`route-filters` offer more flexible and granular prefix matching capabilities compared to `prefix-lists`, allowing for precise control over route selection.

Other Matching Criteria

Beyond prefixes, policies can match on other BGP attributes like `as-path-group` (using regex) or `community` values for highly granular control.

Key Takeaway

`route-filters` are essential for implementing highly specific route matching, enabling fine-tuned traffic engineering and filtering based on prefix length and range.

`route-filter` Matching Options
`route-filter 192.0.2.0/24 exact;`Matches only the specified prefix.
`route-filter 10.0.0.0/8 orlonger;`Matches the prefix and all more specific prefixes.
`route-filter 172.16.0.0/16 upto /24;`Matches prefixes within a range of lengths.
