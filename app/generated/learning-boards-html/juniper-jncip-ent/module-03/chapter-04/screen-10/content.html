Junos OS Configuration

Defining Route Target Extended Communities

Syntax for configuring extended communities, specifically Route Targets.

Specific Syntax

Extended communities require specific syntax for their type. For Route Targets, this is typically target:AS:VALUE or target:IP-ADDRESS:VALUE.

Centralized Definition

Like standard communities, extended communities are defined under the [edit policy-options community] hierarchy for consistent management.

Policy Integration

Once defined, these named extended communities are used in routing policies, especially vrf-import and vrf-export for MPLS VPNs.

user@router# edit
[edit policy-options]community VPN_A_RT_EXPORT {    members target:65000:100; # Defines a Route Target for VPN-A}community VPN_B_RT_IMPORT {    members target:65000:200; # Defines a Route Target for VPN-B}policy-statement EXPORT_VPN_A_ROUTES {    term 1 {        then {            community add VPN_A_RT_EXPORT; # Add RT to routes            accept;        }    }}policy-statement IMPORT_VPN_B_ROUTES {    term 1 {        from community VPN_B_RT_IMPORT; # Match routes with RT        then accept;    }}
Syntax Tip

The 'target' keyword is crucial for Route Targets, signaling its specific function in VPN route exchange.

Key Takeaway

Junos OS uses specific, typed syntax for extended communities, enabling precise control over advanced routing attributes like Route Targets in VPNs.
