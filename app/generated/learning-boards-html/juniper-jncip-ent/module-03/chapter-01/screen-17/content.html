Key Concepts: Origin, MED, and Algorithm

Understanding route source, inbound influence, and the selection process

Origin

Indicates how a route was learned by BGP (IGP, EGP, Incomplete); IGP is generally preferred.

Multi-Exit Discriminator (MED)

Influences how other ASes send traffic into your AS; lower is preferred, but only compared from the same AS.

BGP Best Path Selection Algorithm

A sequential process that evaluates BGP attributes in a predefined order to determine the optimal path to a destination.

Summary Takeaway

The Origin attribute defines a route's source preference, MED allows for granular inbound traffic engineering with specific peers, and the comprehensive BGP best path selection algorithm ensures deterministic routing decisions across the internet.
