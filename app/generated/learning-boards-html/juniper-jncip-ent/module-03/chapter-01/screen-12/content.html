Algorithm Steps

BGP Path Selection: Initial Steps (1-5)

The first critical attributes in the decision-making hierarchy

01

Highest Weight

Prefer the path with the highest Weight (Cisco-specific, local to router). This is the first and most powerful local tie-breaker.

02

Highest Local Preference

Prefer the path with the highest Local Preference. This influences outbound traffic for the entire AS.

03

Locally Originated

Prefer the path that was locally originated (e.g., via network statement or aggregation). These routes are highly trusted.

04

Shortest AS_Path

Prefer the path with the shortest AS_Path. Fewer AS hops are generally considered more direct.

05

Lowest Origin Type

Prefer the path with the lowest Origin type (IGP 'i' < EGP 'e' < Incomplete '?'). Prioritizes internal routes.

Key Takeaway

The first five steps of the BGP best path algorithm are highly influential, often determining the best path based on local preferences, AS-wide policies, and the route's origin and path length.
