Junos OS CLI

Inspecting BGP Attributes in Junos OS

Using CLI commands to verify BGP routing decisions

user@router> show route protocol bgp 192.0.2.0/24 detail
192.0.2.0/24 (active) (BGP)
    AS path: 65001 65002 I, validation-state: unverified
    Local preference: 100
    Multi-Exit Discriminator: 50
    Community: no-export
    Next-hop: 198.51.100.1 via ge-0/0/0.0
    ...
Key Commands
  • •show route <destination> active-path: Quick view of the active route.
  • •show route <destination> detail: More in-depth information.
  • •show route <destination> protocol bgp detail: Most comprehensive BGP-specific details.
Interpreting Output

In the example, 'AS path: 65001 65002 I' shows the ASes traversed and an IGP origin. 'Local preference: 100' and 'Multi-Exit Discriminator: 50' provide values for these key attributes, influencing path selection.

Key Takeaway

Mastering Junos CLI commands for inspecting BGP attributes is crucial for verifying policy application, troubleshooting routing issues, and gaining deep insight into BGP's path selection process.
