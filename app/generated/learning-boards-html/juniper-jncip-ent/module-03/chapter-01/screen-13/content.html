Algorithm Steps

BGP Path Selection: Subsequent Steps (6-11)

Further tie-breakers for complex routing scenarios

06

Lowest MED

Prefer the path with the lowest MED (only compared for routes from the *same* AS). Influences inbound traffic.

07

Prefer EBGP over IBGP

Prefer External BGP paths over Internal BGP paths. EBGP connections are often more direct to external destinations.

08

Lowest IGP Metric

Prefer the path with the lowest IGP metric to the BGP next-hop. Uses internal routing protocol cost.

09

Oldest EBGP Peer

Prefer the path received from the oldest EBGP peer (for routes from the same AS). A stability mechanism.

10

Lowest Router ID

Prefer the path received from the peer with the lowest router ID. A common deterministic tie-breaker.

11

Lowest IP Address

Prefer the path received from the peer with the lowest IP address. The ultimate tie-breaker for full determinism.

Key Takeaway

The later steps of the BGP best path algorithm provide granular tie-breaking mechanisms, ensuring a deterministic path selection even in highly complex scenarios, from MED comparisons to peer IP addresses.
