The Routing Engine: The Brain of Junos OS

Managing decisions and system operations.

Core Responsibilities

The RE is the central intelligence, handling all non-forwarding tasks. It ensures the network's logical structure is correctly maintained and the device is manageable.

Key Functions

  • Runs routing protocols (OSPF, BGP).
  • Manages Routing Information Base (RIB).
  • Builds and pushes Forwarding Information Base (FIB) to PFE.
  • Handles CLI access, SNMP, and logging.
  • Performs system management and software updates.
Key Takeaway

The RE is the control plane, making all routing decisions and managing the device, ensuring network intelligence and manageability.
