Monitoring the Routing Engine: CPU and Memory

Using CLI to assess control plane health.

Understanding RE Utilization

The Routing Engine's CPU and memory usage are critical indicators of the control plane's health. High utilization can signal issues like routing instabilities or even a denial-of-service attack targeting the control plane. It's essential to know how to interpret these metrics.

Key Commands

  • show system processes extensive: Provides detailed information about all running processes, including CPU and memory usage.
  • show system memory: Displays a summary of memory allocation and usage across the system.
Key Takeaway

Regularly monitoring RE CPU and memory helps proactively identify and mitigate control plane issues, ensuring network stability.
