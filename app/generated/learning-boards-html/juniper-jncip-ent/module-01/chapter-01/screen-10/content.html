Monitoring the PFE and Packet Flow

Verifying forwarding decisions and real-time traffic.

Verifying Forwarding

The PFE's forwarding table is the heart of data plane operations. Commands to inspect it are vital for ensuring traffic is routed as expected and for diagnosing path issues.

Key Commands

  • show route forwarding-table: Displays the hardware-optimized forwarding table (FIB) used by the PFE.
  • monitor traffic interface <interface-name>: Captures and displays packets on a specified interface for real-time analysis.
Key Takeaway

Use show route forwarding-table to inspect PFE's forwarding decisions and monitor traffic for real-time packet analysis on interfaces.
