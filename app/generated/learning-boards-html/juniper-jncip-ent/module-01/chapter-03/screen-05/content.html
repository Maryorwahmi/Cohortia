LACP: The Standard for Dynamic Link Aggregation

How devices negotiate and manage aggregated Ethernet links.

What is LACP?

LACP (Link Aggregation Control Protocol), defined by IEEE 802.3ad, is an open standard protocol that enables dynamic negotiation and management of Link Aggregation Groups (LAGs) between connected devices.

Dynamic Negotiation

Devices exchange LACP Data Units (LACPDUs) to agree on which physical links should form a bundle. This automates the process, reducing manual configuration errors and ensuring consistency.

LACP Modes: Active vs. Passive

  • Active: Actively initiates LACP negotiation by sending LACPDUs.
  • Passive: Waits to receive LACPDUs before responding.
  • At least one side must be active for a bundle to form.
