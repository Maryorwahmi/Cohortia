Practical Configuration

Implementing VRRP for Default Gateway Redundancy

Defining virtual router IDs, IP addresses, and priorities.

# On Master Router (e.g., SwitchA)
set interfaces vlan unit 10 family inet address 192.168.1.2/24 vrrp group 1 virtual-address 192.168.1.1
set interfaces vlan unit 10 family inet address 192.168.1.2/24 vrrp group 1 priority 150
set interfaces vlan unit 10 family inet address 192.168.1.2/24 vrrp group 1 preempt

# On Backup Router (e.g., SwitchB)
set interfaces vlan unit 10 family inet address 192.168.1.3/24 vrrp group 1 virtual-address 192.168.1.1
set interfaces vlan unit 10 family inet address 192.168.1.3/24 vrrp group 1 priority 100
# (Optional: omit 'preempt' if backup should remain master after primary recovers)
Key Takeaway

VRRP configuration involves defining a virtual IP, group ID, and priority on the Layer 3 interface, with the preempt option ensuring the highest-priority router becomes master.

1. Virtual IP Address

This is the shared IP address that client devices use as their default gateway. It's configured within the VRRP group on the Layer 3 interface.

2. Priority Setting

A numerical value (1-255) that determines which router becomes the master. Higher priority wins. The default priority is 100.

3. Preempt Option

When enabled, a higher-priority router will take over the master role if it recovers from a failure, ensuring the preferred master is always active when available.
