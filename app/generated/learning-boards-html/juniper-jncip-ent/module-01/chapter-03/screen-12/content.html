Verifying VRRP State and Comparing Redundancy Solutions

Ensuring seamless failover and choosing the right technology.

show vrrp
  Interface     State   Group   VR ID   Virtual IP address   Priority   Master IP address
  vlan.10       Master  1       1       192.168.1.1          150        Local
  vlan.10       Backup  1       1       192.168.1.1          100        192.168.1.2
Key Takeaway

Verify VRRP state with show vrrp and understand that LAGs, Virtual Chassis, and VRRP each provide distinct layers of redundancy for a comprehensive network design.

Common VRRP Issues

  • Incorrect Virtual IP: Mismatch in virtual IP address configuration.
  • Mismatched Authentication: If authentication is used, it must match between peers.
  • Connectivity Problems: Issues preventing VRRP hello packets from being exchanged.

Comparing Redundancy Solutions

  • LAGs: Link-level aggregation and redundancy (bandwidth + failover).
  • Virtual Chassis: Chassis-level redundancy and simplified management (device failover).
  • VRRP: Layer 3 default gateway redundancy (transparent client failover).
