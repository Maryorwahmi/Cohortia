Configuration Walkthrough

Implementing LACP on Juniper Devices

Step-by-step guide to bundling interfaces into an aggregated Ethernet link.

set chassis aggregated-devices ethernet device-count 1
set interfaces ge-0/0/0 ether-options 802.3ad ae0
set interfaces ge-0/0/1 ether-options 802.3ad ae0
set interfaces ae0 aggregated-ether-options lacp active
set interfaces ae0 unit 0 family ethernet-switching interface-mode trunk
set interfaces ae0 unit 0 family ethernet-switching vlan members all
Key Takeaway

Properly configuring LACP on Juniper involves defining the aggregated device, assigning member interfaces, activating LACP, and setting Layer 2 properties for the logical interface.

1. Define Aggregated Device

Use set chassis aggregated-devices ethernet device-count <N> to specify how many aggregated Ethernet interfaces (e.g., ae0, ae1) can be created on the chassis.

2. Assign Member Interfaces

For each physical interface (e.g., ge-0/0/0) to be part of the bundle, use set interfaces <interface> ether-options 802.3ad <ae-interface>.

3. Activate LACP & Configure Logical Interface

On the logical aggregated interface (e.g., ae0), enable LACP with set interfaces ae0 aggregated-ether-options lacp active. Then, configure its Layer 2 properties like interface-mode trunk and vlan members all.
