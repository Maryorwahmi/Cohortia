Layer 3 Redundancy

VRRP: Ensuring Default Gateway High Availability

Preventing single points of failure for client connectivity.

The Default Gateway Problem

Client devices rely on a single default gateway IP. If the physical router or Layer 3 switch providing this gateway fails, all devices on that subnet lose connectivity to other networks.

VRRP Solution: Virtual IP/MAC

VRRP (Virtual Router Redundancy Protocol) allows a group of routers to share a single virtual IP address and MAC address. This virtual address acts as the default gateway for client devices.

Master & Backup Roles

  • Master Router: Forwards traffic for the virtual IP.
  • Backup Routers: Monitor the master and are ready to take over if the master fails.
  • Failover is transparent to end hosts.

VRRP Failover Concept

Key Takeaway

VRRP ensures continuous Layer 3 connectivity by providing a highly available default gateway that transparently fails over between master and backup routers.
