Key Concepts

Reinforcing your understanding of network resilience.

VCP (Virtual Chassis Port)

Dedicated ports used to interconnect member switches in a Virtual Chassis, forming the high-speed internal links.

VRRP (Virtual Router Redundancy Protocol)

An open standard (RFC 5798) Layer 3 redundancy protocol that provides automatic default gateway failover for client devices.

Virtual IP Address

A shared IP address used by VRRP-enabled routers, which acts as the default gateway for client devices on a subnet.

Summary Takeaway

VCPs are vital for Virtual Chassis, while VRRP, with its virtual IP, master, and backup roles, ensures continuous Layer 3 default gateway availability for client devices.
