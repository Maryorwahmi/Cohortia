Verifying LACP Status and Common Issues

Ensuring your aggregated links are functioning correctly.

show interfaces ae0
  Link-level type: Ethernet, MTU: 1514, Speed: 2Gbps
  Link aggregation: Rx: 0, Tx: 0, Active Aggregator: Yes
  Aggregated Interface: ae0.0

show lacp interfaces
  Aggregated interface: ae0
    LACP state: Active, Role: Actor, System Priority: 127, System ID: 00:00:5e:00:53:01
    Member interfaces:
      ge-0/0/0: State: Current, Role: Actor, Port Priority: 127, Port ID: 1
      ge-0/0/1: State: Current, Role: Actor, Port Priority: 127, Port ID: 2
Key Takeaway

Regularly verify LACP status using show interfaces ae0 and show lacp interfaces to ensure bundle formation and quickly identify configuration mismatches or physical link issues.

Common Mistake: LACP Mode Mismatch

If one side is configured as lacp passive and the other is also lacp passive, the LACP bundle will not form. At least one side must be active to initiate negotiation.

Verification Commands

  • show interfaces aeX: Provides overall status of the aggregated interface.
  • show lacp interfaces: Displays detailed LACP state for each member link, including active/passive roles and operational status.

Other Troubleshooting Tips

  • Check physical cabling for integrity.
  • Ensure device-count is configured correctly (greater than 0).
  • Verify consistent LACP configuration on both ends of the link.
