DHCP Snooping

Protecting against rogue DHCP servers and IP spoofing

How it Works

DHCP snooping inspects DHCP messages, building a database of valid IP-to-MAC address bindings. It classifies switch ports as either 'trusted' or 'untrusted'.

Trusted vs. Untrusted Ports

  • Trusted: Connects to legitimate DHCP servers or other trusted switches.
  • Untrusted: Connects to end-user devices; blocks rogue DHCP server messages.
Key Takeaway

DHCP snooping is crucial for network integrity, preventing rogue DHCP servers from distributing invalid IP addresses and mitigating IP spoofing attacks.

Junos OS CLI Example: DHCP Snooping
set ethernet-switching-options secure-access-port dhcp-snooping vlan VLAN_SALES
set ethernet-switching-options secure-access-port interface ge-0/0/0 dhcp-snooping trust

Explanation

  • Enables DHCP snooping for `VLAN_SALES`.
  • Configures interface `ge-0/0/0` as a trusted port for DHCP snooping.

Verification Command

show ethernet-switching-options secure-access-port dhcp-snooping

Verify DHCP snooping configuration and trusted ports.
