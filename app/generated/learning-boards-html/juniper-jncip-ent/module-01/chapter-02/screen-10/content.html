Security Feature

Port Security (MAC Limiting)

Restricting unauthorized device access at the switch port

What is MAC Limiting?

A Layer 2 security feature that restricts the number of MAC addresses a switch port can learn. Once the limit is reached, no new MAC addresses are allowed.

Why Implement It?

  • Prevent Unauthorized Access: Blocks rogue devices from connecting.
  • Mitigate MAC Flooding: Protects against attacks that overwhelm the MAC table.
  • Enhance Network Control: Ensures only expected devices are on the network.
Key Takeaway

MAC limiting is a crucial first line of defense at the access layer, preventing unauthorized devices from connecting and enhancing overall network security.

Junos OS CLI Example: MAC Limiting
set ethernet-switching-options secure-access-port interface ge-0/0/0 mac-limit 2

Explanation

  • Configures port security options for the Ethernet switching family.
  • Applies MAC limiting to interface `ge-0/0/0`.
  • Sets the maximum allowed MAC addresses on `ge-0/0/0` to 2.

Common Action

When the MAC limit is exceeded, the default action is to drop traffic from new MAC addresses. Other actions like disabling the port can also be configured.
