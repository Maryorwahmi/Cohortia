VLAN Trunk Ports

Carrying traffic for multiple VLANs between network devices

Trunk Port Role

A trunk port is configured to carry traffic for multiple VLANs over a single physical link. It's primarily used for interconnecting switches, routers, or virtualized hosts.

802.1Q Tagging

Unlike access ports, trunk ports use 802.1Q tagging to insert a VLAN ID into each Ethernet frame, allowing the receiving device to identify the frame's VLAN origin.

Key Takeaway

Trunk ports are vital for scalable network designs, enabling multiple VLANs to share physical links efficiently through 802.1Q tagging.

Junos OS CLI Example: Trunk Port
set vlans VLAN_SALES vlan-id 10
set vlans VLAN_HR vlan-id 20
set interfaces ge-0/0/1 unit 0 family ethernet-switching interface-mode trunk
set interfaces ge-0/0/1 unit 0 family ethernet-switching vlan members [ VLAN_SALES VLAN_HR ]

Explanation

  • Defines `VLAN_SALES` (ID 10) and `VLAN_HR` (ID 20).
  • Sets interface `ge-0/0/1` to operate in trunk mode.
  • Allows both `VLAN_SALES` and `VLAN_HR` traffic on this trunk.
