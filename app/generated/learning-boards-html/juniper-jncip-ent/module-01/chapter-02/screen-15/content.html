Key Concepts

Protocols and security features to remember

RSTP

Rapid Spanning Tree Protocol (802.1w) provides faster convergence for loop prevention.

MSTP

Multiple Spanning Tree Protocol (802.1s) allows multiple spanning tree instances for load balancing.

Port Security

Restricts the number of MAC addresses learned on a switch port (MAC limiting).

DHCP Snooping

Filters untrusted DHCP messages and builds a database of valid IP-to-MAC bindings.

Dynamic ARP Inspection (DAI)

Validates ARP packets against the DHCP snooping binding database to prevent ARP spoofing.

Summary Takeaway

RSTP and MSTP ensure loop-free Layer 2 networks, while port security, DHCP snooping, and DAI provide essential access layer defense against common attacks.
