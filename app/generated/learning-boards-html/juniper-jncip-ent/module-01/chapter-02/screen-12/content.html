Dynamic ARP Inspection (DAI)

Preventing ARP spoofing attacks with trusted bindings

What is ARP Spoofing?

An attack where a malicious actor sends forged ARP replies to associate their MAC address with another device's IP address, intercepting traffic.

How DAI Works

DAI validates ARP packets against the IP-to-MAC address bindings in the DHCP snooping database. Invalid ARP packets on untrusted ports are dropped.

Key Takeaway

DAI is essential for preventing ARP spoofing attacks by validating ARP packets against trusted bindings, significantly enhancing Layer 2 security.

Junos OS CLI Example: Enable DAI
set ethernet-switching-options secure-access-port arp-inspection vlan VLAN_SALES

Explanation

  • Enables Dynamic ARP Inspection for `VLAN_SALES`.
  • The switch will now inspect ARP packets within this VLAN.

Prerequisite

DAI relies on the DHCP snooping binding database, so DHCP snooping should be enabled and configured first for optimal protection.
