VLAN Access Ports

Connecting end devices to a single VLAN on Juniper switches

Access Port Role

An access port is configured to carry traffic for only one specific VLAN. It's typically used for connecting end devices like workstations, servers, or printers that are unaware of VLAN tagging.

Traffic Handling

Traffic entering an access port is untagged. The switch internally associates this traffic with the VLAN ID configured on that port. Outgoing traffic is also untagged.

Key Takeaway

Access ports simplify connectivity for end devices by automatically assigning them to a single VLAN, handling untagged traffic transparently.

Junos OS CLI Example: Access Port
set vlans VLAN_SALES vlan-id 10
set interfaces ge-0/0/0 unit 0 family ethernet-switching interface-mode access
set interfaces ge-0/0/0 unit 0 family ethernet-switching vlan members VLAN_SALES

Explanation

  • Defines `VLAN_SALES` with ID 10.
  • Sets interface `ge-0/0/0` to operate in access mode.
  • Assigns `ge-0/0/0` to be a member of `VLAN_SALES`.
