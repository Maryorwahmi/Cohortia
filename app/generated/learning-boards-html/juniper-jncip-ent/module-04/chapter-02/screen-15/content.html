Key Concepts

Essential terms to remember

Anycast RP

A high-availability solution for RPs where multiple RPs share the same IP address, providing redundancy.

MSDP

Multicast Source Discovery Protocol, used between Anycast RPs to synchronize source registration and for inter-domain multicast routing.

Source-Active (SA) Message

An MSDP message containing information about an active multicast source (S,G) pair, exchanged between MSDP peers.

Summary Takeaway

Anycast RP provides RP redundancy, while MSDP ensures source synchronization and enables inter-domain multicast routing through SA messages.
