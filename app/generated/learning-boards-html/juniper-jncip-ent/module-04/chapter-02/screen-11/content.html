Configuring Anycast RP with MSDP

Implementing high-availability RPs on Juniper devices

Define Shared Anycast RP Address

On each router intended to be an Anycast RP, configure the same static RP address. This address will be advertised by all Anycast RPs into the unicast routing domain.

# On Router A (Anycast RP 1)
set protocols pim rp static address 192.168.10.1

Configure MSDP Peering

Establish MSDP peering between all Anycast RPs. This enables the exchange of Source-Active (SA) messages to synchronize source registration information.

# On Router A (Anycast RP 1)
set protocols msdp peer 192.168.10.2 local-address 192.168.10.1

Specify MSDP Group Range

Define the multicast group range for which MSDP will exchange SA messages. This ensures that only relevant source information is synchronized between peers.

# On Router A (Anycast RP 1)
set protocols msdp group-range 239.0.0.0/8

Repeat these configurations on Router B, swapping peer addresses.

Key Takeaway

Anycast RP with MSDP on Junos OS requires configuring a shared static RP address on multiple routers and establishing MSDP peering to synchronize source information for high availability.
