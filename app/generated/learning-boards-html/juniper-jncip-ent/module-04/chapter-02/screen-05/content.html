RP Discovery Method

Static RP Configuration

The simplest, but least scalable, RP discovery method

Manual Configuration

The RP's IP address is manually configured on every PIM router within the multicast domain. This requires consistent configuration across all devices.

Limited Scalability

Not suitable for large or growing networks due to the administrative overhead of manual configuration on numerous routers. Changes require widespread updates.

Single Point of Failure

If the statically configured RP fails, multicast forwarding for all associated groups ceases. There is no automatic failover, requiring manual intervention to restore service.

Junos OS Example
set protocols pim rp static address 192.168.10.1

This command configures the router to use 192.168.10.1 as the static Rendezvous Point for all PIM-SM groups.

Key Takeaway

Static RP is simple for small, stable networks but lacks scalability and fault tolerance, making it unsuitable for dynamic or critical multicast deployments.

Pro Tip

While simple, static RP is rarely used in production environments due to its limitations. Always consider dynamic alternatives for robust multicast.
