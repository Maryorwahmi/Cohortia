Junos OS Configuration

Configuring BSR and Candidate RP

Setting up dynamic RP discovery on Juniper devices

Enable PIM-SM

First, enable PIM-SM on all interfaces that will participate in multicast routing within the domain. This is a prerequisite for BSR and CRP functionality.

set protocols pim interface all mode sparse

Configure Candidate RP (CRP)

Designate a router as a Candidate RP, specifying its local address and the group ranges it will serve. This router will advertise its RP capabilities to the BSR.

set protocols pim rp local address 192.168.10.1
set protocols pim rp local group-range 239.0.0.0/8

Configure Candidate BSR (CBSR)

Configure a router to be a Candidate BSR. The BSR election process will determine the active BSR based on priority and IP address. The BSR floods RP-set information.

set protocols pim bsr priority 100
set protocols pim bsr address 192.168.20.1
Key Takeaway

Junos OS configuration for BSR and CRP involves enabling PIM, defining the RP's local address and group ranges, and setting BSR priority and source address for dynamic RP discovery.
