RP Synchronization

MSDP with Anycast RP

Synchronizing source information between Anycast RPs

The Synchronization Need

With multiple RPs sharing the same IP (Anycast RP), each RP needs to know about sources that registered with any other RP. Without this, traffic blackholes can occur.

MSDP's Role

MSDP (Multicast Source Discovery Protocol) runs between Anycast RPs. It's specifically designed to exchange active source information, ensuring all RPs have a consistent view of active sources.

Source-Active (SA) Messages

When a source registers with an Anycast RP, that RP generates a Source-Active (SA) message for the (Source, Group) pair. This SA message is then sent to its MSDP peers (other Anycast RPs).

Preventing Traffic Blackholes

MSDP ensures that if a receiver's DR points to a different Anycast RP than the one the source registered with, the DR will still learn about the source via MSDP, preventing traffic from being dropped.

Key Takeaway

MSDP is essential for Anycast RP, synchronizing source registration information between redundant RPs to ensure consistent multicast forwarding and prevent traffic blackholes.
