Anycast RP for PIM-SM

Achieving redundancy for the Rendezvous Point function

Shared RP Address

Multiple RPs are configured to use the exact same IP address for a given multicast group range. This shared address is the cornerstone of Anycast RP.

Unicast Routing Integration

The shared Anycast RP address is advertised into the unicast routing protocol (e.g., OSPF, ISIS) from all participating RPs. PIM routers use unicast routing to find the closest active RP.

Seamless Failover

If an Anycast RP fails, unicast routing automatically converges, redirecting PIM routers to another active RP. This provides transparent redundancy and prevents service disruption.

Why Anycast RP Matters

  • Eliminates the RP as a single point of failure.
  • Enhances multicast service availability.
  • Distributes RP load across multiple devices.
Key Takeaway

Anycast RP provides critical high availability for the RP function by using a shared IP and leveraging unicast routing for automatic failover.
