Network Security

Unicast Reverse Path Forwarding (URPF)

Mitigating IP Spoofing Attacks

What is URPF?

URPF is a security feature designed to mitigate IP spoofing attacks by verifying the source IP address of incoming packets against the router's unicast routing table.

  • •Checks if the source IP has a valid route back to its origin.
  • •Verifies the return path is through the incoming interface.
  • •Drops packets if the verification fails.
Key Takeaway

URPF acts as a critical defense against IP spoofing by ensuring that incoming packets originate from a legitimate and routable source path.

How URPF Protects

Packet arrives on an interface.

Router checks source IP against routing table.

Verifies return path through incoming interface.

If invalid, packet is dropped.

Example: Spoofed Packet

An attacker sends a packet with a source IP of an internal server from an external interface. URPF checks the routing table and finds the legitimate path to that internal server is via an internal interface. Since the packet arrived externally, URPF drops it.
