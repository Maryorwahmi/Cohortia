Key Concepts

Essential Terms to Remember

High Availability (HA)

A system design principle aimed at minimizing downtime and ensuring continuous operation by eliminating single points of failure.

VRRP

A first-hop redundancy protocol that provides automatic default gateway failover for hosts on a LAN segment.

Virtual IP Address

A shared IP address used by a VRRP group, acting as the default gateway for hosts on a LAN.

VRRP Master

The router in a VRRP group that actively responds to ARP requests and forwards traffic for the virtual IP address.

VRRP Backup

Routers in a VRRP group that monitor the master and automatically take over if the master fails.

Summary Takeaway

High Availability and VRRP are fundamental for building resilient networks, ensuring continuous operation and seamless gateway failover.
