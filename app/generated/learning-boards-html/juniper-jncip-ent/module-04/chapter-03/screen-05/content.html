Virtual Router Redundancy Protocol (VRRP)

Automatic Failover for Default Gateways

VRRP Core Function

VRRP provides automatic failover for default gateways, ensuring hosts on a LAN segment always have a reachable gateway even if the primary router fails.

  • •Uses a virtual IP address as the default gateway.
  • •A group of routers share this virtual IP.
  • •One router is Master, others are Backup.
Key Takeaway

VRRP ensures continuous network access by providing a resilient default gateway that automatically switches to a backup router upon failure.

How VRRP Works

Hosts use a Virtual IP as their default gateway.

Master Router responds to ARP for Virtual IP.

Master forwards all traffic for the Virtual IP.

Backup Routers monitor the Master's status.

Analogy: Two Security Guards

Imagine two security guards for a single entrance. One is the primary (Master) and handles all visitors. The other (Backup) stands ready. If the primary guard falls ill, the backup immediately steps in, and visitors don't even notice the change.
