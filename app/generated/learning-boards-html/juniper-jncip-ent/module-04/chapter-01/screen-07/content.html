IGMPv1, IGMPv2, and IGMPv3

Enhancements for Multicast Group Control

Version Compatibility

Ensuring compatible IGMP versions across the network is crucial to prevent receivers from missing traffic.

Common Mistake

An IGMP version mismatch can lead to hosts being unable to join groups or routers not learning memberships.

Key Takeaway

Each IGMP version brought significant improvements, with v3 offering the most granular control through Source-Specific Multicast.

IGMP Version Comparison

IGMPv1

Basic join messages

No explicit leave

IGMPv2

Explicit leave messages

Faster pruning

IGMPv3

Source-Specific Multicast (SSM)

Greater control & security

1

IGMPv1: Only supports hosts joining a group.

2

IGMPv2: Adds explicit leave messages for faster group departure.

3
