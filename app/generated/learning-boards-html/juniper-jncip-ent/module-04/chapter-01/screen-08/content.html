Protocol Independent Multicast (PIM)

Building Multicast Forwarding Paths

Core Function

Routes multicast traffic across the wider network from the source to interested receivers.

Protocol Independent

Leverages the existing unicast routing table to build its multicast forwarding paths, working with any unicast protocol.

Key Role

Constructs and maintains multicast distribution trees, ensuring traffic reaches all interested segments.

Key Takeaway

PIM is the glue that connects local IGMP memberships to network-wide multicast delivery, making it scalable and flexible.
