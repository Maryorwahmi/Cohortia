# Junos OS Basic IGMP & PIM-DM Configuration
set protocols igmp interface ge-0/0/0.0
set protocols pim interface ge-0/0/0.0 mode dense
set protocols pim interface ge-0/0/1.0 mode dense
1

Enable IGMP: On interfaces connected to receiver segments (e.g., ge-0/0/0.0).

2

Enable PIM-DM: On all interfaces participating in multicast routing (e.g., ge-0/0/0.0 and ge-0/0/1.0).

Configuring Multicast on Juniper Devices

Enabling IGMP and PIM-DM for Basic Operation

Common Mistake: Missing PIM

Forgetting to enable PIM on all interfaces in the forwarding path can lead to multicast traffic blackholes.

Common Mistake: IGMP Mismatch

Incorrect IGMP version configuration can prevent hosts from joining groups and receiving traffic.

Key Takeaway

Always verify IGMP and PIM configurations on all relevant interfaces to ensure proper multicast operation.
