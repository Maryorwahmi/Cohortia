Internet Group Management Protocol (IGMP)

Signaling Interest in Multicast Traffic

Core Function

Manages multicast group memberships between hosts and their directly connected routers on a local network segment.

Host Action

Sends an IGMP Host Membership Report to express interest in joining a specific multicast group.

Router's Role (Querier)

Periodically sends IGMP Host Membership Queries to discover active group members on its local segment.

Key Takeaway

IGMP is essential for routers to learn which local devices want to receive specific multicast traffic, enabling efficient local delivery.
