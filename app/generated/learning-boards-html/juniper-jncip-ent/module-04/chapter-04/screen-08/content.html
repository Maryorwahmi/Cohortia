Nonstop Bridging (NSB) Overview

NSB extends the concept of continuous control plane operation to Layer 2 protocols, synchronizing bridging state between redundant REs.

Layer 2 State: Synchronizes MAC address tables, VLAN information, and other Layer 2 state.

Uninterrupted L2 Forwarding: Ensures seamless takeover by backup RE, maintaining existing Layer 2 paths.

Safety Note

NSR/NSB do not protect against forwarding plane failures. Corrupted state synchronization can lead to issues on both REs. Requires careful planning and testing.

Key Takeaway

NSB is crucial for maintaining continuous Layer 2 connectivity during RE failover, but careful implementation and testing are vital to avoid potential issues.

NSR & NSB Configuration Examples

Enabling NSR and NSB involves simple commands under their respective hierarchies:

set routing-options nonstop-routing
set bridge-domains <bd-name> protocols nonstop-bridging

Verification of NSR status can be done using the show task replication command:

user@router> show task replication
    Stateful Replication: Enabled
    Client: rpd, Master: Yes, Connection: Up
    Client: chassisd, Master: Yes, Connection: Up
    ...

Verification Tip

Always verify the replication status after configuration to ensure both REs are synchronizing correctly. This is crucial for effective failover.
