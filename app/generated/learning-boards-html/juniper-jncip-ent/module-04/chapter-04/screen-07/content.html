NSR: Continuous Control Plane

NSR provides continuous control plane operation by synchronizing routing state between redundant Routing Engines (REs).

Dual RE Platforms: Requires Juniper devices with two Routing Engines (Master and Backup).

State Synchronization: Master RE continuously synchronizes routing protocol state (OSPF, BGP, routing tables) with the backup RE.

Seamless Failover: Backup RE takes over as master without interruption, using synchronized state.

Key Takeaway

NSR ensures continuous control plane operation and near-zero traffic loss during RE failover by actively synchronizing routing state between redundant routing engines.

NSR vs. GR: A Comparison

Graceful Restart (GR)

Minimizes disruption during a single RE restart by relying on neighbors to hold routes. Control plane still re-converges.

Nonstop Active Routing (NSR)

Provides continuous control plane operation with dual REs, preventing any re-convergence during failover. Higher availability.

Combined Benefits

Often used together for maximum resiliency, where NSR handles RE failover and GR provides a fallback for protocol restarts.
