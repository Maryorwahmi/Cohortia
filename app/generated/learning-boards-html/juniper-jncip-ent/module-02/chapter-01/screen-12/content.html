Hands-on: Configuring an ABR and Area 1 Router

Step-by-Step Junos OS Configuration Example

Router R1 (ABR)

Configured with interfaces in both Area 0 and Area 1, acting as the Area Border Router.

Router R2 (Area 1)

Configured with interfaces solely within Area 1, connecting to R1.

Goal: Adjacency & Routes

Establish OSPF neighbor adjacencies and ensure routes are exchanged between Area 0 and Area 1.

Key Takeaway

This hands-on configuration demonstrates the practical setup of an ABR and a standard area router in Junos OS.

Router R1 (ABR) Configuration

set system host-name R1
set interfaces lo0 unit 0 family inet address 192.168.0.1/32
set interfaces ge-0/0/0 unit 0 family inet address 10.0.0.1/24
set interfaces ge-0/0/1 unit 0 family inet address 10.0.1.1/24
set protocols ospf router-id 192.168.0.1
set protocols ospf area 0.0.0.0 interface ge-0/0/0.0
set protocols ospf area 0.0.0.1 interface ge-0/0/1.0
set protocols ospf area 0.0.0.1 interface lo0.0 passive

Router R2 (Area 1 Router) Configuration

set system host-name R2
set interfaces lo0 unit 0 family inet address 192.168.0.2/32
set interfaces ge-0/0/1 unit 0 family inet address 10.0.1.2/24
set protocols ospf router-id 192.168.0.2
set protocols ospf area 0.0.0.1 interface ge-0/0/1.0
set protocols ospf area 0.0.0.1 interface lo0.0 passive
