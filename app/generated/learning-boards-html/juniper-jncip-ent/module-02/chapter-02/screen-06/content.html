Stub Area Advantages and Rules

Stub areas offer significant benefits in resource optimization but come with strict operational requirements.

Reduced LSDB & Routing Table

Minimizes memory and CPU usage on internal routers by not storing Type 5 LSAs.

Simplified Management

Fewer routes to manage and troubleshoot within the stub area.

Key Takeaway

Stub areas offer significant resource savings but require strict adherence to configuration rules, including no ASBRs or virtual links, and consistent configuration across all routers in the area.

Stub Area Constraints

All Routers Must Agree

Every router within a stub area must be configured as stub; otherwise, OSPF adjacency will not form.

No ASBR Allowed

A stub area cannot contain an Autonomous System Boundary Router (ASBR) and cannot inject external routes.

No Virtual Links

Virtual links are not permitted to traverse or terminate within a stub area.
