Key Concepts: LSA Types

A quick reference for the different Link-State Advertisement (LSA) types discussed.

Type 3 LSA (Summary)

Generated by ABRs to advertise inter-area routes between OSPF areas.

Type 5 LSA (External)

Generated by ASBRs to advertise external routes into the OSPF domain.

Type 7 LSA (NSSA External)

Generated by ASBRs within an NSSA to advertise external routes, later translated to Type 5 by the NSSA ABR.

Summary Takeaway

Each LSA type serves a specific purpose in OSPF, and understanding their generation and propagation is fundamental to designing efficient and scalable networks with specialized areas.
