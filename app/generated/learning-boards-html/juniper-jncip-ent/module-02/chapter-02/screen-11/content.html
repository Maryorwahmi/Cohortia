Configuring NSSA and Totally NSSA

Junos OS uses the nssa keyword for Not-So-Stubby Areas, with an optional no-summaries keyword on the ABR for Totally NSSA functionality.

NSSA Area Configuration

Add the nssa keyword to the area definition on all routers within the NSSA.

Totally NSSA Configuration

On the ABR, add nssa no-summaries. Other routers in the area just use nssa.

Key Takeaway

The nssa keyword enables external route injection via Type 7 LSAs, and adding no-summaries on the ABR creates a Totally NSSA, blocking Type 3 LSAs.

Junos OS CLI Examples

# Configure an NSSA (on all routers in Area 0.0.0.2)
set protocols ospf area 0.0.0.2 nssa

# Configure a Totally NSSA (on the ABR for Area 0.0.0.2)
set protocols ospf area 0.0.0.2 nssa no-summaries

# Configure a Totally NSSA (on other routers in Area 0.0.0.2)
set protocols ospf area 0.0.0.2 nssa

Remember to apply the no-summaries keyword only on the ABR for the 'totally' functionality.
