Key Concepts

Review the fundamental definitions and characteristics of OSPF specialized areas.

Stub Area

An OSPF area that blocks Type 5 External LSAs, relying on a default route injected by the ABR.

Totally Stubby Area (TSA)

Blocks both Type 5 External LSAs and Type 3 Summary LSAs, relying solely on a default route from the ABR.

Not-So-Stubby Area (NSSA)

Allows an ASBR to inject external routes as Type 7 LSAs, which are translated to Type 5 by the ABR, while still blocking incoming Type 5 LSAs.

Summary Takeaway

Specialized OSPF areas are powerful tools for optimizing network performance and resource utilization by selectively controlling the propagation of different LSA types.
