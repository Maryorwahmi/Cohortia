NSSA: Bridging External and Stub Areas

Not-So-Stubby Areas (NSSAs) offer flexibility by allowing external routes to be injected into a stub-like area while still limiting LSA flooding.

Allows Internal ASBR

Unlike stub areas, NSSAs can contain an ASBR, enabling the injection of external routes from within the area.

Generates Type 7 LSAs

External routes are injected as Type 7 LSAs within the NSSA, a special LSA type for this purpose.

Key Takeaway

NSSAs offer a unique balance, allowing external route injection via Type 7 LSAs from an internal ASBR while still blocking Type 5 LSAs from entering the area.
