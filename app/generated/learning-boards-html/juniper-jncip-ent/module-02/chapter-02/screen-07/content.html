Totally Stubby Areas (TSAs)

TSAs extend stub area functionality by blocking both Type 5 External LSAs and Type 3 Summary LSAs, providing maximum routing table reduction.

Blocks Type 3 & Type 5 LSAs

Prevents both inter-area summary routes and external routes from entering the TSA.

Single Default Route

The ABR injects a single default route (0.0.0.0/0) for all external and inter-area destinations.

Key Takeaway

TSAs provide the highest level of LSA reduction, making them ideal for small, spoke-like areas that only need a single exit point to the rest of the network.
