Configuring Stub and Totally Stubby Areas

Junos OS provides straightforward commands to configure OSPF stub and totally stubby areas, primarily using the stub and no-summaries keywords.

Stub Area Configuration

Simply add the stub keyword to the area definition on all routers within that area.

Totally Stubby Area Configuration

On the ABR, add stub no-summaries. Other routers in the area just use stub.

Key Takeaway

The stub keyword is universal for all routers in a stub or totally stubby area, but no-summaries is exclusively applied to the ABR for totally stubby functionality.

Junos OS CLI Examples

# Configure a Stub Area (on all routers in Area 0.0.0.1)
set protocols ospf area 0.0.0.1 stub

# Configure a Totally Stubby Area (on the ABR for Area 0.0.0.1)
set protocols ospf area 0.0.0.1 stub no-summaries

# Configure a Totally Stubby Area (on other routers in Area 0.0.0.1)
set protocols ospf area 0.0.0.1 stub

Ensure consistent configuration across all routers within the specialized area to maintain OSPF adjacencies.
