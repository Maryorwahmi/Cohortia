Building a Python Op Script: Interface Descriptions

This script demonstrates how to create a custom operational command to display interface names and their configured descriptions using Python.

Script Purpose

Extend the Junos CLI to provide a quick overview of interface descriptions, aiding in documentation and troubleshooting.

Key Components

  • junos module for RPC interaction.
  • lxml for XML parsing and XPath.
  • Iterating through interface elements to extract data.
Key Takeaway

Python Op scripts, using Junos RPCs and XML parsing, enable powerful custom CLI commands for on-demand data retrieval and display.

show-interface-descriptions.py

# Example of a simple Junos Python op script to display interface descriptions
# Save this as /var/db/scripts/op/show-interface-descriptions.py

from junos import Junos_Configuration
from junos import Junos_RPC
from lxml import etree

def main():
    # Get the XML representation of the configuration
    with Junos_RPC() as rpc:
        response = rpc.get_config({'format': 'xml'})
        
        # Parse the XML response
        root = etree.fromstring(response.text)
        
        # Find all interfaces and their descriptions
        interfaces = root.xpath("//interfaces/interface")
        
        print("Interface Descriptions:")
        print("-----------------------")
        
        for interface in interfaces:
            name = interface.findtext("name")
            description = interface.findtext("description")
            
            if name:
                if description:
                    print(f"  {name}: {description}")
                else:
                    print(f"  {name}: (No Description)")
            
    print("-----------------------")

if __name__ == '__main__':
    main()

Configuration & Execution

set system scripts op file show-interface-descriptions.py
