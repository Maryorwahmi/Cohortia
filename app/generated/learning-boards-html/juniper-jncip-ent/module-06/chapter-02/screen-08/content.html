Gathering Junos Facts with Ansible

Retrieving Operational Data from Network Devices

Inventory File (inventory.ini)

[junos_routers]
router1 ansible_host=192.168.1.1 ansible_user=juniper_user
router2 ansible_host=192.168.1.2 ansible_user=juniper_user

[junos_routers:vars]
ansible_network_os=junos
ansible_connection=netconf

Playbook (get_junos_facts.yml)

---
- name: Gather facts from Junos devices
  hosts: junos_routers
  gather_facts: no
  connection: netconf

  tasks:
    - name: Get Junos device facts
      juniper.device.junos_facts:
        gather_subset:
          - config
          - interfaces
          - hardware
          - default
      register: junos_device_facts

    - name: Display Junos hostname and version
      debug:
        msg: "Hostname: {{ junos_device_facts.facts.hostname }}, Junos Version: {{ junos_device_facts.facts.version }}"

Explanation of Steps

  • •Inventory: Defines target devices and connection variables.
  • •Playbook: Targets junos_routers group, disables default fact gathering.
  • •junos_facts: Module to collect specific subsets of Junos device data.
  • •register: Stores module output for later use.
  • •debug: Prints desired facts to the console.
Key Takeaway

The junos_facts module, combined with a well-defined inventory, provides a powerful way to programmatically retrieve and display critical operational data from your Junos devices.
