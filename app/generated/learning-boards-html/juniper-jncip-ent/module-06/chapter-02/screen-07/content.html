Junos Integration

The juniper.device Collection

Specialized Modules for Junos OS Automation

Why a Dedicated Collection?

  • •Provides purpose-built modules for Junos OS.
  • •Understands Junos configuration syntax and operational commands.
  • •Enables structured and reliable interaction with Junos devices.

Installation

ansible-galaxy collection install juniper.device

This command installs the collection on your Ansible control node, making all Junos modules available for use in your playbooks.

Key Modules in juniper.device

junos_facts

Gathers device information (hostname, version, interfaces).

junos_install_config

Loads configuration changes from files or strings.

junos_rpc

Executes arbitrary Junos OS Remote Procedure Calls.
