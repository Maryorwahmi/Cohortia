Applying Configuration with junos_install_config

Loading and Committing Configuration Changes to Junos Devices

Module Capabilities

  • •Loads configuration from a file or a string.
  • •Supports various load formats: set, XML, JSON, text.
  • •Performs configuration validation and commit operations.

The Power of check_mode

  • •Allows dry-running a playbook without making actual changes.
  • •Crucial safety feature for previewing configuration impacts.
  • •Use check_mode: yes in task or ansible-playbook --check.

Example: junos_install_config Task

- name: Load configuration
  juniper.device.junos_install_config:
    config_file: "configs/my_config.set"
    load: "set"
    commit: yes
    check_mode: yes # Always test first!
Key Takeaway

Always use check_mode with junos_install_config to validate configuration changes before applying them to production, ensuring safety and preventing unintended network disruptions.
