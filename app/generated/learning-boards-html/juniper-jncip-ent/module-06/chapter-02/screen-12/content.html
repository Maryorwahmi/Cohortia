Understanding junos_install_config Load Options

Choosing the Right Method for Configuration Changes

Safe Load Options

set

Additive; modifies specific parts of the configuration. Safest for incremental changes.

merge

Combines provided config with existing; preserves unmentioned parts.

Pro Tip

For most operational changes, always prefer load: "set" or load: "merge" to ensure you only modify the intended parts of the configuration and avoid accidental data loss.

Impactful Load Options

replace

Replaces a specific hierarchy within the existing configuration.

override

DANGEROUS: Replaces the entire configuration. Use with extreme caution.

Common Mistake

Accidentally using load: "override" when intending to make incremental changes, which can wipe out the entire device configuration. Always double-check this parameter.
