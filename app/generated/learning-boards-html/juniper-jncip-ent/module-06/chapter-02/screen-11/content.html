Configuring an Interface with Ansible

Automating Junos Interface Descriptions with junos_install_config

Configuration File (configs/ge-0-0-0_desc.set)

set interfaces ge-0/0/0 description "Configured by Ansible"

This simple file contains the Junos 'set' command to update an interface description.

Playbook (configure_interface.yml)

---
- name: Configure an interface description on Junos devices
  hosts: junos_routers
  gather_facts: no
  connection: netconf

  tasks:
    - name: Load configuration using set commands
      juniper.device.junos_install_config:
        config_file: "configs/ge-0-0-0_desc.set"
        load: "set"
        commit: yes
        check_mode: yes # Always test with check_mode first!
      register: config_result

Execution Flow

  • •Define Config: Create a .set file with desired Junos commands.
  • •Create Playbook: Use junos_install_config to reference the config file.
  • •Dry Run: Execute with check_mode: yes to preview changes.
  • •Apply Changes: Run without check_mode to commit.
Key Takeaway

Separating configuration data into files and using junos_install_config with check_mode provides a modular, safe, and repeatable method for applying Junos configurations.
