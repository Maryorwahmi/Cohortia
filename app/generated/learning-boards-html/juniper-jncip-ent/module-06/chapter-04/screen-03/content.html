Expanding your automation skills

03

Utilize NETCONF Tools

Gain hands-on experience with tools like `netconf-console` to interact with Junos devices programmatically via NETCONF. This is key for testing and debugging.

VERIFIED COMPETENCY MILESTONE
04

Describe Junos OS REST API

Understand the capabilities and use cases of the Junos OS REST API for network automation, especially for web-based applications and cloud integrations.

VERIFIED COMPETENCY MILESTONE
05

Formulate REST API Calls

Learn to construct basic REST API calls to retrieve operational data and apply configuration changes to Junos devices. This is a practical skill for real-world automation.
