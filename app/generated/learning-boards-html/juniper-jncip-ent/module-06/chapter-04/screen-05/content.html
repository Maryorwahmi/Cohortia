Core Concept

Junos OS XML API

Mapping CLI to Programmatic Interaction

Definition

Juniper's XML-based data models that directly correspond to Junos OS CLI commands and configuration hierarchy.

Practical Tip

Append | display xml to any CLI command to see its XML equivalent, aiding automation script development.

Key Takeaway

Understanding the CLI-to-XML mapping is fundamental for effective NETCONF and REST API usage, bridging human and machine interaction.

Terminal Output: CLI to XML Mapping
user@junos-device> show interfaces terse | display xml
<rpc-reply xmlns:junos="http://xml.juniper.net/junos/21.4R0/junos">
  <interface-information>
    <physical-interface>
      <name>ge-0/0/0</name>
      <admin-status junos:style="UP">up</admin-status>
      <oper-status junos:style="UP">up</oper-status>
      <logical-interface>
        <name>ge-0/0/0.0</name>
        <address-family>
          <address-family-name>inet</address-family-name>
          <interface-address>
            <ifa-local>192.168.1.1/24</ifa-local>
          </interface-address>
        </address-family>
      </logical-interface>
    </physical-interface>
  </interface-information>
</rpc-reply>
