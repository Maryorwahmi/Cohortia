Practical Tools

NETCONF Interaction Tools

netconf-console and junos-pyez

netconf-console

A command-line utility for sending raw NETCONF XML RPCs and viewing XML responses, ideal for basic testing and learning.

junos-pyez

A Python library that abstracts raw XML complexities, providing a more Pythonic way to interact with NETCONF for robust automation.

Key Takeaway

Choose netconf-console for quick tests and debugging, and junos-pyez for building scalable, maintainable automation solutions.

Conceptual netconf-console Usage
# Example: Connect and send a basic RPC to get hostname
netconf-console --host YOUR_JUNOS_IP --user YOUR_JUNOS_USERNAME --password YOUR_JUNOS_PASSWORD --rpc "<rpc><get-config><source><running/></source><filter><system><host-name/></system></filter></get-config></rpc>"

# Expected (truncated) XML output:
<rpc-reply xmlns:junos="http://xml.juniper.net/junos/21.4R0/junos">
  <configuration>
    <system>
      <host-name>my-junos-device</host-name>
    </system>
  </configuration>
</rpc-reply>
