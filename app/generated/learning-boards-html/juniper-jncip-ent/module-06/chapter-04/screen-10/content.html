REST API Usage

Applying Configuration with REST API

Using HTTP POST for Configuration Updates

HTTP POST Method

Used to send data to the server to create or update a resource, typically for configuration changes.

JSON Payload

Configuration changes are typically sent as a JSON object in the request body, representing the desired state.

Key Takeaway

The REST API provides a flexible, web-centric way to automate configuration updates, making it ideal for integration with modern applications and workflows.

curl Example: Update Interface Description (JSON)
# Command to update an interface description via REST API
curl -X POST -u juniper_user:juniper_password -H "Content-Type: application/vnd.juniper.junos.configuration+json" \
  -d '{ "configuration": [ { "interfaces": [ { "name": "ge-0/0/3", "description": "REST API configured" } ] } ] }' \
  https://<junos-device>/rpc/ --insecure

# Expected (truncated) XML reply from Junos:
<rpc-reply xmlns:junos="http://xml.juniper.net/junos/21.4R0/junos">
  <ok/>
  <commit-results>
    <routing-engine>
      <name>re0</name>
      <commit-success/>
    </routing-engine>
  </commit-results>
</rpc-reply>
