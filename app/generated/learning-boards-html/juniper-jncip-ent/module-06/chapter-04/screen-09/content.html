REST API Usage

Retrieving Operational Data with REST API

Using HTTP GET for Information Retrieval

HTTP GET Method

Used to request data from a specified resource on the Junos device.

Structured Data

Data is returned in JSON or XML format, making it easy to parse and integrate into automation scripts.

Key Takeaway

The REST API's use of standard HTTP GET requests provides a simple, efficient, and reliable way to programmatically collect operational data from Junos devices.

curl Example: Get System Information (JSON)
# Command to retrieve system information in JSON format
curl -X GET -u juniper_user:juniper_password -H "Accept: application/json" \
  https://<junos-device>/rpc/get-system-information?format=json --insecure

# Expected (truncated) JSON output:
{
  "system-information": {
    "host-name": "my-junos-device",
    "os-name": "junos",
    "os-version": "21.4R1.10",
    "model": "qfx5100-48s-6q"
  }
}
