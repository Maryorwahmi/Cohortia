NETCONF Operations

Executing NETCONF RPCs

Retrieving and Loading Configuration

RPC for Retrieval

Use the <get-config> RPC to retrieve configuration or operational data from the device.

RPC for Configuration

The <load-configuration> RPC allows you to apply configuration changes, specifying action and format.

Key Takeaway

NETCONF RPCs provide granular control over device state, supporting transactional operations for reliable automation.

NETCONF RPC Examples (XML)
# Example: Get running configuration
<rpc message-id="101">
  <get-config>
    <source>
      <running/>
    </source>
  </get-config>
</rpc>

# Example: Load configuration (merge 'set' format)
<rpc message-id="102">
  <load-configuration action="merge" format="set">
    <configuration-text>
      set interfaces ge-0/0/2 description "Configured via NETCONF"
    </configuration-text>
  </load-configuration>
</rpc>
