Key Components
  • •Telemetry Agent: Junos device collecting data.
  • •gRPC: High-performance RPC framework for transport.
  • •Protocol Buffers: Efficient binary data encoding.
  • •Telemetry Collector: External system for data processing and analysis.
Efficiency Benefit

Binary data format significantly reduces bandwidth consumption compared to text-based protocols like JSON or XML.

Example Use

A collector receives real-time BGP session state updates, enabling immediate alerts for peering issues.

Key Takeaway

JTI's architecture leverages gRPC and Protocol Buffers for highly efficient, low-latency data streaming to external collectors.
