Key Concepts (Continued)

More essential terms to remember from this chapter.

OpenConfig

An industry-wide initiative defining vendor-neutral YANG data models for network device configuration and operational state, promoting interoperability.

YANG

A data modeling language used to model configuration and state data for network devices, forming the basis for OpenConfig.

Telemetry Agent

The Junos device itself, acting as the source, collecting and streaming telemetry data from its various sensors.

Telemetry Collector

An external system that receives, processes, stores, and analyzes streaming telemetry data from network devices.

Summary Takeaway

OpenConfig and YANG provide standardization, while the Telemetry Agent and Collector define the roles in a streaming telemetry solution.
