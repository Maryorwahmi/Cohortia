YANG Data Models

The language behind standardized network data.

What is YANG?

YANG (Yet Another Next Generation) is a data modeling language used to define the structure and semantics of configuration and state data for network devices.

  • •Standardized: Provides a common, machine-readable format.
  • •Vendor-Agnostic: Enables interoperability across different network equipment.
  • •Defines Structure: Specifies data types, constraints, and relationships.
  • •Foundation for OpenConfig: The language used to create OpenConfig data models.
Example: Interface Model
module: openconfig-interfaces
  +--rw interfaces
     +--rw interface* [name]
        +--rw name         string
        +--rw config
        |  +--rw name?      string
        |  +--rw type?      identityref
        +--ro state
           +--ro name?      string
           +--ro type?      identityref
           +--ro oper-status? identityref
Benefit

YANG ensures that telemetry data from different devices is consistently structured, simplifying data ingestion and analysis for collectors.

Key Takeaway

YANG provides the standardized blueprint for network data, enabling consistent interpretation and interoperability across diverse network devices and platforms.
