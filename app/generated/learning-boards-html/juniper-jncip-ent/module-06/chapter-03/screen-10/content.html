Configuring JTI: Sensors and Export Profile

Setting up what data to collect and where to send it.

Junos CLI
# Configure the telemetry sensor for interface statistics
set services analytics sensor SENSOR_INTF_STATS resource /junos/system/linecard/interface/
set services analytics sensor SENSOR_INTF_STATS resource /junos/system/linecard/interface/logical/usage/
set services analytics sensor SENSOR_INTF_STATS resource /junos/system/linecard/interface/physical/usage/
set services analytics sensor SENSOR_INTF_STATS resource /junos/system/linecard/interface/queue/

# Configure the export profile
set services analytics export-profile EXPORT_PROFILE_GRPC transport grpc
set services analytics export-profile EXPORT_PROFILE_GRPC reporting-interval 10000 # 10 seconds
set services analytics export-profile EXPORT_PROFILE_GRPC target-address 192.168.100.200 port 50051
Sensor Definition

The sensor command specifies the data paths (resources) on the Junos device from which telemetry data will be collected. Multiple paths can be defined for a single sensor.

Export Profile Details

The export-profile defines the transport protocol (gRPC), the frequency of data export (reporting-interval in milliseconds), and the destination IP address and port of the telemetry collector.

Pro-Tip

Ensure the target-address and port match your telemetry collector's listening configuration to avoid connection issues.

Key Takeaway

Sensors define the data to collect, while export profiles dictate how and where that data is streamed, including the gRPC transport and reporting interval.
