Configuration Steps

Configuring JTI: An Overview

The essential elements for streaming telemetry data.

1. Define Sensors

Specify what data to collect (e.g., interface stats, CPU usage).

2. Configure Export Profile

Define reporting interval, target collector IP, and port.

3. Specify Protocol (gRPC)

Choose gRPC for efficient, high-performance data transport.

Key Takeaway

JTI configuration relies on defining sensors for data collection, an export profile for destination and frequency, and gRPC for efficient transport.
