Configuring JTI: Rule and Commit

Linking sensors to export profiles and activating the configuration.

Junos CLI
# Associate the sensor with the export profile
set services analytics rule RULE_INTF_STATS sensor-name SENSOR_INTF_STATS
set services analytics rule RULE_INTF_STATS export-profile EXPORT_PROFILE_GRPC

# Commit the configuration
commit
Rule Definition

A rule acts as the bridge, linking a specific sensor-name (what data to collect) to an export-profile (how and where to send it).

Commit Action

The commit command applies the pending configuration changes, making the JTI setup active and initiating data streaming.

Common Mistake

Forgetting to commit the configuration is a frequent error, leading to JTI not becoming active. Always verify after configuration.

Key Takeaway

Rules connect sensors to export profiles, and the `commit` command is essential to activate the JTI configuration and begin data streaming.
