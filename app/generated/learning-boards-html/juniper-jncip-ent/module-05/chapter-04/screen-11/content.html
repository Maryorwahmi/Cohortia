Traffic Classification: Multifield (MF)

Granular Classification Using Multiple Fields

Key Aspects of MF Classification

  • •Multiple Fields: Classifies traffic based on various header fields (IP, port, protocol, flags).
  • •Granular Control: Offers fine-grained control over specific applications or user groups.
  • •Network Edge: Typically performed at the ingress of the network where traffic enters the QoS domain.
  • •Firewall Filters: Implemented on Juniper devices using firewall filters with QoS actions.

Juniper MF Classifier Example (VoIP)

# Firewall filter to identify VoIP SIP traffic
set firewall family inet filter VOIP_CLASSIFIER term VOIP_SIP from protocol udp
set firewall family inet filter VOIP_CLASSIFIER term VOIP_SIP from destination-port 5060
set firewall family inet filter VOIP_CLASSIFIER term VOIP_SIP then forwarding-class expedited-forwarding

# Apply filter to an interface
set interfaces ge-0/0/1 unit 0 family inet filter input VOIP_CLASSIFIER
Key Takeaway

MF classification provides granular traffic control by inspecting multiple header fields, typically at the network edge, and is implemented using firewall filters on Juniper devices.
