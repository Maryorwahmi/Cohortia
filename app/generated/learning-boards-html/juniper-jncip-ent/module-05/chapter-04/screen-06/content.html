QoS Model

Integrated Services (IntServ): End-to-End Guarantees

Resource Reservation for Specific Flows

How IntServ Works

  • •Resource Reservation: Reserves bandwidth and other resources end-to-end for specific application flows.
  • •RSVP Protocol: Uses Resource Reservation Protocol to signal resource requirements to network devices.
  • •Strong Guarantees: Offers very high assurance of performance once resources are reserved.

IntServ Scalability Challenge

Per-Flow State

Each router must maintain state for every individual flow, consuming significant resources.

Limited Scalability

Impractical for large enterprise or service provider networks with many active flows.

Key Takeaway

IntServ provides strong end-to-end QoS guarantees via RSVP but struggles with scalability due to per-flow state maintenance, limiting its use to smaller, specialized deployments.
