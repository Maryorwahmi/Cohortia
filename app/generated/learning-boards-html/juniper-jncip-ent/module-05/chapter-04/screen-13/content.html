Policers: Limiting Traffic Rate

Controlling Bandwidth and Preventing Congestion

How Policers Work

  • •Rate Limiting: Limits traffic to a configured bandwidth and burst size.
  • •Action on Excess: Discards (two-color) or remarks (three-color) excess traffic.
  • •Congestion Prevention: Prevents single flows from monopolizing bandwidth.
  • •Ingress Application: Often applied at the input direction of an interface.

Juniper Policer Example (HTTP)

# Define a policer to limit HTTP traffic
set firewall policer HTTP_LIMITER if-exceeding bandwidth-limit 10m
set firewall policer HTTP_LIMITER if-exceeding burst-size-limit 2m
set firewall policer HTTP_LIMITER then discard

# Apply policer within a firewall filter
set firewall family inet filter HTTP_POLICY term HTTP_TRAFFIC 
    from destination-port 80
set firewall family inet filter HTTP_POLICY term HTTP_TRAFFIC 
    then policer HTTP_LIMITER
Key Takeaway

Policers limit traffic rates by discarding or remarking excess packets, preventing congestion and ensuring fair bandwidth allocation, typically applied at ingress interfaces.
