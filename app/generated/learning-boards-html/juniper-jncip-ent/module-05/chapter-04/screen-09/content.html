Per-Hop Behaviors (PHBs): Router Actions

How Routers Treat Marked Traffic

Understanding PHBs

  • •Forwarding Treatment: Defines how a router handles a packet based on its DSCP value.
  • •Standardized: Ensures consistent behavior across different network devices.
  • •No Per-Flow State: Applied to traffic aggregates, not individual flows, maintaining scalability.
  • •Direct Impact: Directly translates DSCP markings into concrete network actions.

Common PHBs

Expedited Forwarding (EF)

For low-latency, low-jitter, low-loss services (e.g., VoIP). Strict priority.

Assured Forwarding (AF)

Provides delivery assurance within subscribed rates. Multiple classes and drop precedences (e.g., AF11, AF12, AF13).

Default Forwarding (DF)

Best-effort traffic, typically marked with DSCP 0. No special treatment.

Key Takeaway

PHBs define how routers treat packets based on their DSCP values, with EF for high priority, AF for assured delivery, and DF for best-effort traffic, ensuring consistent QoS actions.
