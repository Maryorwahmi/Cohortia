DSCP: Marking Traffic for QoS

The Differentiated Services Code Point Field

Understanding DSCP

  • •Location: 6-bit field in the IP header (upper 6 bits of ToS/DS field).
  • •Purpose: Marks packets to indicate their forwarding class and drop precedence.
  • •Signaling: Signals to subsequent routers how to treat the packet for QoS.
  • •Consistency: Ensures uniform QoS treatment across the network without per-flow state.

DSCP in the IP Header

0 1 2 3 4 5 6 7
+---+---+---+---+---+---+---+---+
|   DSCP    | CU  |
+---+---+---+---+---+---+---+---+

DSCP (Differentiated Services Code Point): 6 bits for classification.
CU (Currently Unused): 2 bits, typically set to 0.
Key Takeaway

DSCP is a 6-bit field in the IP header that marks packets to indicate their forwarding class and drop precedence, enabling consistent QoS treatment across a DiffServ network.
