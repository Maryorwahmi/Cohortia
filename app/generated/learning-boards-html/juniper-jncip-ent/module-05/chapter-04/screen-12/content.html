Rewrite Rules: Modifying Traffic Markings

Enforcing Marking Policies Across Network Boundaries

Purpose of Rewrite Rules

  • •Change Markings: Modify DSCP or CoS values of packets.
  • •Network Boundaries: Essential when traffic crosses different QoS domains (e.g., internal to service provider).
  • •Policy Enforcement: Ensures consistent marking policies are applied.
  • •Output Direction: Typically applied to egress interfaces.

Juniper Rewrite Rule Example

# Define rewrite rule to mark EF for expedited-forwarding traffic
set class-of-service rewrite-rules dscp my-rewrite-rule 
    forwarding-class expedited-forwarding loss-priority low code-point ef

# Apply to an output interface
set class-of-service interfaces ge-0/0/3 unit 0 
    rewrite-rules dscp my-rewrite-rule
Key Takeaway

Rewrite rules are used to change DSCP or CoS values on egress interfaces, ensuring consistent QoS marking policies when traffic traverses network boundaries or domains.
