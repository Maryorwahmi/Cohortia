Traffic Classification: Behavior Aggregate (BA)

Classifying Based on a Single Field

Key Aspects of BA Classification

  • •Single Field: Classifies traffic based on one field (e.g., DSCP for IP, CoS for Layer 2).
  • •Efficiency: Highly efficient, ideal for high-speed core network devices.
  • •Aggregate Treatment: Maps specific field values to internal forwarding classes and loss priorities.
  • •Scalability: Contributes to the scalability of DiffServ by avoiding deep packet inspection.

Juniper BA Classifier Example

# Map DSCP 'ef' to expedited-forwarding class
set class-of-service classifiers dscp my-dscp-classifier 
    forwarding-class expedited-forwarding loss-priority low code-points ef

# Apply to an interface
set class-of-service interfaces ge-0/0/0 unit 0 
    classifiers dscp my-dscp-classifier
Key Takeaway

BA classification efficiently groups traffic using a single header field (like DSCP), making it ideal for high-performance core network devices where broad prioritization is needed.
