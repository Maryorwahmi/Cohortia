QoS Model

Differentiated Services (DiffServ): The Scalable Solution

Classifying Traffic at the Edge, Treating at the Core

Key Principles of DiffServ

  • •Edge Classification: Traffic is classified into forwarding classes at the network edge.
  • •Core Treatment: Core routers apply Per-Hop Behaviors (PHBs) based on classification.
  • •No Per-Flow State: Routers do not maintain state for individual flows, ensuring scalability.
  • •Flexibility: Allows for diverse QoS policies without complex end-to-end signaling.

DiffServ Architecture Overview

Network Edge

Traffic is classified and marked with DSCP values.

Network Core

Routers apply PHBs based on DSCP, without per-flow state.

Key Takeaway

DiffServ is a scalable QoS model that classifies traffic at the network edge and applies Per-Hop Behaviors at the core, avoiding per-flow state for efficient management in large networks.
