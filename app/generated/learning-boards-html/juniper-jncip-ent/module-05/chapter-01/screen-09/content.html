Filter Actions

Standard Actions: Accept, Discard, Reject, Count, and Log

Defining Packet Treatment in Firewall Filters

accept: Permit Traffic

Allows the packet to pass through the device and continue processing.

discard: Silently Drop

Drops the packet without sending any notification to the source, enhancing security by not revealing filter policy.

reject: Drop with Notification

Drops the packet and sends an ICMP unreachable message to the source, useful for troubleshooting but reveals policy.

Key Takeaway

Choosing the right action is critical for both security and network diagnostics, balancing traffic control with operational visibility.

Monitoring & Logging Actions

count: Traffic Statistics

  • Tracks packets/bytes matching a term
  • Valuable for troubleshooting and monitoring

log: System Alerts

  • Sends a syslog message upon match
  • Alerts administrators to specific traffic patterns
