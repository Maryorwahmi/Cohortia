Match Conditions

Beyond the Basics: IP Protocol, Length, DSCP, and CoS

Expanding Granular Traffic Identification

IP Protocol Numbers

Match on specific IP protocols like tcp, udp, gre to target application or tunneling traffic.

Packet Length

Identify traffic based on its size, useful for detecting anomalies or specific attack patterns.

DSCP and CoS Values

Integrate with QoS policies by matching on Differentiated Services Code Point (DSCP) or Class of Service (CoS) values.

Key Takeaway

Junos filters provide extensive matching capabilities, allowing for highly specific traffic identification and integration with QoS policies.

Extended Match Criteria

Network Layer Matching

  • protocol tcp
  • protocol udp
  • protocol gre
  • packet-length <value>

QoS/CoS Matching

  • dscp <value>
  • dscp <name> (e.g., ef)
  • cos <value>
  • interface <name> (arrival interface)
