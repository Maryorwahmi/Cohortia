Advanced Match Conditions: TCP Flags and ICMP

Granular Control Over Session Establishment and Diagnostics

TCP Flags: Session Control

Match on `syn`, `ack`, `fin`, `rst` to control TCP session initiation, continuation, and termination. Useful for SYN flood prevention.

ICMP Types & Codes: Diagnostic Control

Filter specific ICMP messages like `echo-request` (ping) for reconnaissance prevention, while allowing `destination-unreachable` for network diagnostics.

Example: Blocking Ping

from icmp-type echo-request then discard can prevent external hosts from pinging internal resources.

Key Takeaway

Leveraging TCP flags and ICMP types provides fine-grained control over network communication, crucial for both security and operational visibility.

TCP Flags & ICMP Matching

TCP Flags

  • syn: New connection attempt
  • ack: Acknowledgment of data
  • fin: Graceful connection termination
  • rst: Abrupt connection termination

ICMP Types & Codes

  • echo-request (Type 8): Ping
  • echo-reply (Type 0): Ping response
  • destination-unreachable (Type 3): Network error
  • time-exceeded (Type 11): TTL expired
