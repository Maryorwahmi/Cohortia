Filter Architecture

Anatomy of a Junos Firewall Filter

Terms, Match Conditions, and Actions

Terms: Ordered Rules

A filter is a collection of terms, evaluated sequentially from top to bottom.

Match Conditions: Packet Criteria

Define what traffic a term applies to (e.g., source IP, destination port, protocol).

Actions: What to Do

Specify the operation on matching packets (e.g., accept, discard, reject, count).

Key Takeaway

The sequential order of terms is paramount; the first match determines the action, making careful design essential to avoid policy conflicts.
