NAT Types

Source Network Address Translation (SNAT)

Enabling Internal Hosts to Access External Networks

SNAT Flow
Internal Host (192.168.1.10)Source IP
Firewall (SNAT)Translates Source IP
Internet (203.0.113.5)Public Source IP

SNAT Purpose

Translates internal private IP addresses to public IP addresses for outbound connections.

Key Benefit

Allows multiple internal hosts to share a single public IP, conserving IPv4 addresses.

Key Takeaway

SNAT is essential for providing internet access to internal networks while maintaining address privacy.
