Interface NAT

Egress Interface IP Translation

The source IP address is translated to the IP address of the egress (outbound) interface of the firewall.

  • Simple to configure
  • Common for small deployments
  • Often combined with PAT
Use Case

A small office network where all internal users share the single public IP of the internet-facing firewall interface.

Pool NAT

IP Address Pool Translation

The source IP address is translated to an IP address selected from a defined pool of public IP addresses.

  • Offers more control and scalability
  • Can provide redundancy with multiple public IPs
  • Suitable for larger deployments
Key Takeaway

Choose Interface NAT for simplicity in small setups, and Pool NAT for scalability and control in larger environments.
