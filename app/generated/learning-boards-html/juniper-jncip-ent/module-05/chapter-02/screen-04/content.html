Stateless Firewall

Packet-by-Packet Inspection

Inspects each packet individually without considering its relation to previous packets or existing connections. Requires explicit rules for both inbound and outbound traffic.

  • No connection context
  • Higher rule complexity for bidirectional traffic
  • Less resource-intensive per packet
Common Pitfall

Forgetting to create return path rules can block legitimate responses.

Stateful Firewall

Connection-Aware Inspection

Maintains a session table to track the state of active connections. Subsequent packets of an established connection are automatically permitted.

  • Maintains connection context (session table)
  • Simplifies rules for bidirectional traffic
  • Blocks unsolicited inbound traffic by default
Key Takeaway

Stateful inspection offers superior security and performance by understanding the full context of network conversations.
