What is Static NAT?

Permanent One-to-One Mapping

A one-to-one, permanent mapping between a private IP address and a public IP address. Both source and destination NAT are implicitly performed.

  • Bidirectional: Works for both inbound and outbound traffic.
  • Consistent: Internal host always uses the same public IP.
Security Note

Exposes internal services directly; requires robust security policies.
