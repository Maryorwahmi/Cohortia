NAT Types

Destination Network Address Translation (DNAT)

Publishing Internal Services to External Users

DNAT Flow
External User (Public IP)Destination IP
Firewall (DNAT)Translates Destination IP
Internal Server (Private IP)Translated Destination IP

DNAT Purpose

Translates public destination IP addresses to internal private IP addresses for inbound connections.

Use Case

Making internal web servers, email servers, or other services accessible from the internet.

Key Takeaway

DNAT is crucial for securely exposing internal services to external users without revealing internal network topology.
