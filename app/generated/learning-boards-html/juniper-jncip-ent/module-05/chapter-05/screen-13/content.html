Module 5›Chapter 5.5›QoS Configuration Part 2

Configuring QoS: Scheduler Maps & Traffic Control Profiles

Applying QoS policies to interfaces and managing common pitfalls

# 4. Configure Scheduler Map: Maps forwarding classes to schedulers
set class-of-service scheduler-maps MY_SCHEDULER_MAP forwarding-class expedited-forwarding scheduler EF_SCHEDULER
set class-of-service scheduler-maps MY_SCHEDULER_MAP forwarding-class assured-forwarding scheduler AF_SCHEDULER
set class-of-service scheduler-maps MY_SCHEDULER_MAP forwarding-class best-effort scheduler BE_SCHEDULER

# 5. Configure Traffic Control Profile: Applies shaping and scheduler map
set class-of-service traffic-control-profiles MY_TCP shaping-rate 100m # Total interface shaping rate
set class-of-service traffic-control-profiles MY_TCP scheduler-map MY_SCHEDULER_MAP
set class-of-service traffic-control-profiles MY_TCP guaranteed-rate 50m # Guaranteed minimum for the interface

# 6. Apply Traffic Control Profile to an interface
set interfaces ge-0/0/0 unit 0 class-of-service traffic-control-profile MY_TCP

# Commit and verify
commit and-quit
show class-of-service interface ge-0/0/0 extensive
Scheduler Map

This command creates a `scheduler-map` that links each forwarding class (e.g., `expedited-forwarding`) to its corresponding scheduler (e.g., `EF_SCHEDULER`). This is how the system knows which scheduling rules to apply to which traffic type.

Traffic Control Profile

The `traffic-control-profile` is a powerful container. It defines the overall `shaping-rate` for the interface, a `guaranteed-rate`, and applies the `scheduler-map`. This is where hierarchical QoS policies often take shape.

Applying to Interface

The final step is to apply the `traffic-control-profile` to a specific interface (e.g., `ge-0/0/0 unit 0`). This activates all the configured QoS policies on that outbound interface.

Common Mistakes & Safety

Not policing SP traffic can starve lower queues. Misconfiguring `buffer-size` leads to drops or latency. Always monitor queue statistics and test thoroughly in a lab before production deployment.
