IPSec Protocols

Authentication Header (AH) vs. Encapsulating Security Payload (ESP)

Choosing Data Protection for Your IPSec VPN

Authentication Header (AH)

  • Provides: Data integrity and authentication.
  • Does NOT provide: Confidentiality (encryption).
  • Authenticates: Entire IP packet.

Encapsulating Security Payload (ESP)

  • Provides: Confidentiality (encryption), integrity, and authentication.
  • More commonly used: For comprehensive security.
  • Encrypts/Authenticates: IP payload and ESP header.
Key Takeaway

ESP is generally preferred for IPSec VPNs as it provides confidentiality (encryption) in addition to integrity and authentication, unlike AH which only offers integrity and authentication.
