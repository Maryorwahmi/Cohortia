Configuration Example

Juniper IKE Phase 1 Configuration

Setting Up the Secure Control Channel

Key Configuration Elements

  • IKE Proposal: Defines crypto parameters (encryption, hashing, DH group, lifetime).
  • IKE Policy: Links proposal to authentication method (e.g., pre-shared key).
  • IKE Gateway: Specifies peer, local interface, and IKE policy.

Common Mistake: Mismatched IKE parameters (encryption, hashing, DH group, PSK) between peers will prevent Phase 1 from establishing.

# IKE Phase 1 Configuration
set security ike proposal IKE_PROPOSAL_SITEA authentication-method pre-shared-keys
set security ike proposal IKE_PROPOSAL_SITEA encryption-algorithm aes-256-cbc
set security ike proposal IKE_PROPOSAL_SITEA authentication-algorithm sha256
set security ike proposal IKE_PROPOSAL_SITEA dh-group group14
set security ike proposal IKE_PROPOSAL_SITEA lifetime-seconds 28800

set security ike policy IKE_POLICY_SITEA proposals IKE_PROPOSAL_SITEA
set security ike policy IKE_POLICY_SITEA pre-shared-key ascii-text "MySecretKey123"

set security ike gateway IKE_GATEWAY_SITEB ike-policy IKE_POLICY_SITEA
set security ike gateway IKE_GATEWAY_SITEB address <Peer_SiteB_Public_IP>
set security ike gateway IKE_GATEWAY_SITEB local-identity ipv4-address 203.0.113.1
set security ike gateway IKE_GATEWAY_SITEB external-interface ge-0/0/0.0
set security ike gateway IKE_GATEWAY_SITEB version v2-only
Key Takeaway

IKE Phase 1 configuration on Juniper involves defining proposals for cryptographic parameters, policies for authentication, and gateways to identify peers and local interfaces.
