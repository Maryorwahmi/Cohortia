IPSec Modes

Tunnel Mode vs. Transport Mode

Encapsulating Traffic for Different VPN Scenarios

Tunnel Mode

  • Encapsulates: Entire original IP packet (header + payload).
  • Adds: A new outer IP header.
  • Use Case: Site-to-site VPNs (gateway-to-gateway).

Transport Mode

  • Encrypts/Authenticates: Only the IP payload.
  • Retains: Original IP header.
  • Use Case: Host-to-host communication.
Key Takeaway

Tunnel Mode is ideal for site-to-site VPNs by encapsulating the entire packet, while Transport Mode is for host-to-host, securing only the payload.
