Automation & Integration

Unlocking Automation with EOS: The External API (eAPI)

Programmatic Interaction for Cloud-Scale Environments

Open & Programmable

EOS provides a rich set of open APIs, with eAPI being the most prominent, enabling programmatic control and automation of network devices.

Standard Protocols

eAPI uses standard HTTP/HTTPS requests and JSON payloads, making it accessible and easy to integrate with existing development workflows and tools.

Automation Capabilities

It allows for automated configuration tasks, gathering of telemetry data, and seamless integration into orchestration and management platforms.

Example: Automated VLAN Provisioning

Instead of manually logging into each switch to create VLANs, an engineer can write a Python script that uses eAPI to send JSON commands to multiple Arista switches, provisioning VLANs across the entire network in seconds. This significantly reduces human error and speeds up deployment.

Beyond CLI: The Power Shift

While the CLI is familiar, eAPI represents a shift from imperative, human-driven commands to declarative, machine-driven automation. This allows for greater scalability, consistency, and integration into broader IT automation frameworks.

Key Takeaway

eAPI is a critical component of EOS, enabling programmatic control and automation of network devices through standard web technologies, essential for modern cloud-scale environments.
