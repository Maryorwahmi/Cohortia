EOS Integration: Orchestration and Infrastructure as Code

Seamlessly Connecting Arista with Management Platforms

Integration with Orchestration Tools

eAPI allows Arista switches to integrate with popular configuration management tools like Ansible, Puppet, and Chef, or custom scripts, for automated network provisioning.

Infrastructure as Code (IaC)

This integration enables network infrastructure to be defined, provisioned, and managed using code, bringing IaC principles to networking for consistency and scalability.

OpenConfig Support

EOS supports OpenConfig, an industry initiative to standardize network device configuration and management, further enhancing interoperability and automation potential.

Example: Automated Data Center Deployment

A cloud provider can use Ansible playbooks to deploy an entire data center network, including VLANs, routing protocols, and security policies, across hundreds of Arista switches. This ensures consistency, reduces deployment time from days to minutes, and minimizes human error.

The Power of Open Standards

OpenConfig's standardized data models mean that automation scripts written for one vendor's device can potentially work with another's, as long as both support OpenConfig. This reduces vendor lock-in and simplifies multi-vendor network management.

Key Takeaway

EOS's robust APIs and OpenConfig support enable deep integration with orchestration tools, making Infrastructure as Code a reality for network management and driving operational efficiency.
