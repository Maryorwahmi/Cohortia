Basic CLI Commands: Configuring Interfaces

Setting Up Network Connectivity

# Enter configuration modeconfigure terminal

# Configure an interfaceinterface Ethernet1
   description "Uplink to Spine1"
   no switchport
   ip address 10.0.0.1/30
   no shutdown
exit

# Save the configurationcopy running-config startup-config

Command Walkthrough

  • configure terminal: Enters global configuration mode.
  • interface Ethernet1: Selects the specific interface for configuration.
  • description: Adds a descriptive label to the interface.
  • no switchport: Configures the interface as a routed port (Layer 3).
  • ip address: Assigns an IP address and subnet mask to the interface.
  • no shutdown: Administratively enables the interface.
  • exit: Exits the current configuration mode.
  • copy running-config startup-config: Saves the active configuration to persistent storage.

Critical Step: Saving Configuration

Forgetting to execute copy running-config startup-config is a very common mistake. Without this command, any changes you make will be lost if the device reboots or loses power, leading to unexpected network behavior and downtime.

Key Takeaway

Properly configuring interfaces and saving the configuration are essential steps for establishing network connectivity and ensuring the persistence of your device settings.
