Virtual Extensible LAN (VXLAN)

An overlay network technology that encapsulates Layer 2 Ethernet frames within Layer 3 UDP packets.

How VXLAN Works
  • Extends Layer 2 segments across a Layer 3 IP network.
  • Enables VM mobility without IP address changes.
  • Simplifies virtualization management in cloud environments.
  • Uses a VXLAN Network Identifier (VNI) for segmentation.
Key Takeaway

VXLAN provides the data plane to seamlessly extend Layer 2 connectivity over a Layer 3 underlay, crucial for flexible cloud deployments.
