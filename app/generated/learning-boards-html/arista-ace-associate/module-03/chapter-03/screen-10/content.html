STP Configuration
Configuring Root Bridge Priority
Influencing the spanning tree topology

Why Adjust Priority?

  • Default priority (32768) means lowest MAC address wins.
  • Allows strategic placement of the root bridge for optimal traffic flow.
  • Prevents suboptimal paths and inefficient network performance.

Priority Values:

Lower numerical value makes a switch more likely to become the root. Common values are multiples of 4096 (e.g., 0, 4096, 8192).

Key Takeaway

Explicitly setting STP priority ensures predictable root bridge election and optimized network traffic paths.

Arista EOS Configuration Example
! Configure SwitchA as root for VLAN 10
Arista(config)# spanning-tree vlan 10 priority 4096

! Configure SwitchB with a higher priority for VLAN 10
Arista(config)# spanning-tree vlan 10 priority 28672

! Verify STP status
Arista# show spanning-tree active

Explanation:

By setting SwitchA's priority for VLAN 10 to 4096 (a low value), it becomes the root bridge for that VLAN. SwitchB's higher priority ensures it does not become the root for VLAN 10.
