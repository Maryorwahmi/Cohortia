STP Core Principle
Root Bridge Election
The foundation of a stable spanning tree

What is the Root Bridge?

The central switch in a spanning tree topology, serving as the reference point for all path calculations.

Election Process:

  • All switches exchange BPDUs containing their Bridge ID (BID).
  • The switch with the lowest BID becomes the root bridge.
  • BID = Configurable Priority (default 32768) + Switch MAC Address.
  • If priorities are equal, the lowest MAC address wins.
Key Takeaway

Strategic placement of the root bridge is crucial for optimal traffic flow, not just loop prevention.

Bridge ID Components

Priority Value

Configurable number (default 32768). Lower value is preferred.

Switch MAC Address

Unique hardware identifier. Used as a tie-breaker.

Lowest BID Wins

The switch with the numerically smallest BID becomes the root.
