STP Port Roles
Port Roles: Root and Designated
Defining active paths in the spanning tree

Root Port:

  • Exists on every non-root switch.
  • Provides the shortest, lowest-cost path back to the root bridge.
  • Cost is determined by link speed (e.g., 10Gbps < 1Gbps).

Designated Port:

  • Exists on each network segment (link).
  • Provides the lowest-cost path from that segment to the root bridge.
  • Only one designated port per segment.
Key Takeaway

Root and Designated ports are the active forwarding ports, while all other non-root, non-designated ports are placed in a blocking state to prevent loops.

Visualizing Port Roles

Root Bridge

The central point; all its ports are Designated Ports.

Root Port (RP)

Best path to the Root Bridge for non-root switches.

Designated Port (DP)

Best path from a segment to the Root Bridge.

Blocked Port (BP)

Prevents loops; receives BPDUs but does not forward traffic.
