STP Mechanism
STP's Solution: Logical Blocking
Creating a loop-free logical topology

How STP Prevents Loops:

  • Logically Blocks Paths: Disables redundant links to prevent frame circulation.
  • Maintains Physical Redundancy: Links are blocked but remain available for failover.
  • Creates Loop-Free Topology: Ensures a single, active path for data flow.

Key Components:

  • Bridge Protocol Data Units (BPDUs): Special frames exchanged between switches.
  • Bridge ID (BID): Composed of switch priority and MAC address, used for election.
Key Takeaway

STP uses BPDUs and Bridge IDs to intelligently block redundant paths, ensuring network stability while preserving fault tolerance.

The STP Process Flow
1

Switches Exchange BPDUs

Communicate Bridge IDs and path information.

2

Elect Root Bridge

The switch with the lowest Bridge ID becomes the central reference.

3

Determine Port Roles

Assigns root, designated, and blocked roles to ports.

4

Block Redundant Paths

Logically disables ports to prevent loops.
