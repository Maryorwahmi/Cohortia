BPDU Guard: Securing Edge Ports
Preventing unauthorized switches and loops

What is BPDU Guard?

A security feature that immediately puts a port into an error-disabled state if it receives a BPDU.

Key Considerations:

  • Purpose: Enhances security on access ports connected to end devices.
  • Benefit: Prevents accidental loops or unauthorized switches from joining the network.
  • Recovery: Requires manual intervention (shutdown/no shutdown) or auto-recovery.
Key Takeaway

BPDU Guard is a critical defense mechanism for edge ports, protecting the network from potential STP disruptions.

Arista EOS Configuration Example
! Enter interface configuration mode for Ethernet1
Arista(config)# interface Ethernet1

! Enable BPDU Guard on Ethernet1
Arista(config-if-Et1)# spanning-tree bpduguard enable

! Exit interface configuration mode
Arista(config-if-Et1)# end

! To recover an error-disabled port
Arista(config)# interface Ethernet1
Arista(config-if-Et1)# shutdown
Arista(config-if-Et1)# no shutdown

Explanation:

This enables BPDU Guard on Ethernet1. If a BPDU is received, the port will go into an error-disabled state. The recovery steps show how to manually re-enable the port.
