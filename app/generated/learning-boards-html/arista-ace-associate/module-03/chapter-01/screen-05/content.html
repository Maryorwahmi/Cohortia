Process Flow

The MAC Address Learning Process

How Switches Build Their Forwarding Tables

Step 1

Receive Frame

Switch receives an Ethernet frame on an interface.

Step 2

Examine Source MAC

Switch inspects the source MAC address of the incoming frame.

Step 3

Update MAC Table

If new, adds MAC address and associated interface to the CAM table.

Example Scenario

A frame arrives on Ethernet1 with source MAC 00:01:02:03:04:05. The switch learns that 00:01:02:03:04:05 is connected to Ethernet1 and adds it to its MAC table.

Key Takeaway

The MAC address learning process allows switches to build a dynamic, real-time map of network devices and their locations, essential for efficient forwarding.
