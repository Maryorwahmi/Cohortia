Key Concepts: Part 1

Essential terms from this chapter

MAC Address

A unique 48-bit hardware identifier for network interfaces, used for Layer 2 communication.

Ethernet Frame

The basic unit of data transferred over an Ethernet network, containing source and destination MAC addresses.

MAC Address Table (CAM Table)

A table maintained by a switch that maps MAC addresses to specific switch ports and VLANs.

Summary Takeaway

MAC addresses, Ethernet frames, and the MAC address table are the fundamental building blocks for efficient Layer 2 communication and intelligent forwarding decisions within a local network.
