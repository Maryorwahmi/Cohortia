Configuring Static MAC Entries

Manually Binding MAC Addresses to Ports

A static MAC address entry manually binds a MAC address to a specific interface and VLAN, preventing it from being learned dynamically or aged out. This is useful for security or critical devices.

Benefits of Static Entries
  • Enhanced Security: Prevents MAC spoofing or unauthorized device movement.
  • Predictable Forwarding: Ensures traffic always goes to a specific port.
  • Persistence: MAC address remains in table even if device is silent.
Key Takeaway

Static MAC entries provide a way to enforce specific device-to-port associations, offering security and predictability for critical network components.

Arista EOS Configuration Example
Arista# configure terminal
Arista(config)# mac address-table static 00:DE:AD:BE:EF:01 vlan 1 interface Ethernet2
Arista(config)# end

Arista# show mac address-table
  Vlan  Mac Address     Type   Ports
  ----  -----------     ----   -----
  1     00:DE:AD:BE:EF:01 STATIC  Ethernet2
  ...

Arista# configure terminal
Arista(config)# no mac address-table static 00:DE:AD:BE:EF:01 vlan 1 interface Ethernet2
Arista(config)# end
Caution

Incorrectly configured static MAC entries can lead to connectivity issues. Always verify your configuration with show commands after making changes.
