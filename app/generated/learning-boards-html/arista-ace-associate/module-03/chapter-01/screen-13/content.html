Key Concepts: Part 2

Essential terms from this chapter

Dynamic Learning

The process by which a switch automatically populates its MAC address table by inspecting source MAC addresses of incoming frames.

Unicast Forwarding

When a switch forwards a frame out a single, specific port based on a known destination MAC address in its table.

Flooding

When a switch sends a frame out all active ports (except the ingress port) because the destination MAC address is unknown, or it's a broadcast/unknown multicast frame.

Static MAC Address Entry

A manually configured entry in the MAC address table that permanently binds a MAC address to a port and VLAN.

MAC Address Aging

The process by which dynamically learned MAC address entries are removed from the table after a period of inactivity.

Summary Takeaway

Switches dynamically learn device locations, forward traffic efficiently via unicast, flood for unknown destinations, and can be manually configured with static entries, all while managing table hygiene through aging.
