Inspecting the MAC Address Table

Using 'show mac address-table' for Network Visibility

The show mac address-table command is your primary tool for viewing learned MAC addresses on an Arista EOS switch. It provides crucial details about device connectivity.

Key Information Displayed
  • VLAN: The VLAN ID associated with the MAC address.
  • MAC Address: The unique hardware identifier.
  • Type: Indicates if the entry is DYNAMIC (learned), STATIC (manually configured), or LEARNED.
  • Interface: The switch port where the device is connected.
Key Takeaway

Regularly using show mac address-table is essential for monitoring network devices, verifying connectivity, and troubleshooting Layer 2 forwarding issues.

Command Output Example
Arista# show mac address-table
  Vlan  Mac Address     Type   Ports
  ----  -----------     ----   -----
  1     00:11:22:33:44:55 DYNAMIC Ethernet1
  1     00:AA:BB:CC:DD:EE DYNAMIC Ethernet2
  10    00:DE:AD:BE:EF:01 STATIC  Ethernet5
  20    00:CA:FE:BA:BE:00 DYNAMIC Ethernet3

Arista# show mac address-table address 00:11:22:33:44:55
  Vlan  Mac Address     Type   Ports
  ----  -----------     ----   -----
  1     00:11:22:33:44:55 DYNAMIC Ethernet1
Pro Tip

Use the address or interface keywords with show mac address-table to filter output and quickly find specific entries, especially in large networks.
