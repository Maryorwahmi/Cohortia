Configuration Steps

Implementing Load Balancing on Arista EOS

Applying global load balancing settings

Key Points for Configuration

  • •Load balancing is a global setting, affecting all LAGs on the switch.
  • •Configured from global configuration mode.
  • •Use `port-channel load-balance ?` to explore available options.
  • •Verify configuration with `show port-channel load-balance`.
Key Takeaway

The global load balancing configuration is crucial for optimizing traffic distribution across all LAGs, directly impacting overall network performance.

Arista EOS: Configure Load Balancing

Arista(config)# port-channel load-balance ?
  dst-ip         Load balance based on destination IP address
  dst-mac        Load balance based on destination MAC address
  dst-port       Load balance based on destination TCP/UDP port
  src-dst-ip     Load balance based on source and destination IP address
  src-dst-ip-port  Load balance based on source and destination IP address and TCP/UDP port
  src-dst-mac    Load balance based on source and destination MAC address
  src-ip         Load balance based on source IP address
  src-mac        Load balance based on source MAC address
  src-port       Load balance based on source TCP/UDP port

Arista(config)# port-channel load-balance src-dst-ip
Arista(config)# end

Common Mistake

Forgetting that load balancing is global. If you have multiple LAGs with different traffic patterns, a single global setting might not be optimal for all of them.
