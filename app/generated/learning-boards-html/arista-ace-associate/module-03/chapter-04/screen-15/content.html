More Key Concepts to Remember

Additional essential terms from Link Aggregation

LACP Passive Mode

A port waits for LACP PDUs from a remote device to form a LAG; it will not initiate negotiation.

Static LAG (On Mode)

Manually configured link aggregation without LACP negotiation, lacking dynamic fault detection.

Load Balancing

The method used by a switch to distribute traffic across the member links within a LAG.

Summary Takeaway

Understanding LACP modes, static LAG, load balancing, and redundancy is key to deploying and managing efficient and resilient aggregated network links.
