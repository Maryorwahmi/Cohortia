Configuration Steps

Setting Up the Logical Port-Channel

The first step in Arista EOS LAG configuration

Key Considerations

  • •This is the logical interface for the LAG.
  • •Apply all Layer 2/3 configurations here (e.g., `switchport mode trunk`, IP addresses).
  • •Do NOT apply these configurations to individual member interfaces.
Key Takeaway

The Port-Channel interface is the central point for all network-level configurations of your aggregated link, ensuring consistency and proper operation.

Arista EOS: Configure Port-Channel

Arista(config)# interface Port-Channel 1
Arista(config-if-Po1)# description Uplink_to_Core
Arista(config-if-Po1)# switchport mode trunk # Or access, depending on use case
Arista(config-if-Po1)# switchport trunk allowed vlan all # If trunk
Arista(config-if-Po1)# exit

Pro Tip

Always add a descriptive `description` to your Port-Channel interfaces. This greatly aids in network documentation and troubleshooting, making it clear what the LAG is used for.
