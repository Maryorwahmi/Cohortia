Troubleshooting

Diagnosing and Resolving LAG Problems

Addressing LACP mismatches and configuration errors

Common LAG Issues

  • •LACP Mode Mismatch: E.g., Active + Static 'on' mode, or Passive + Passive.
  • •Incorrect Configuration: Applying L2/L3 settings to member interfaces instead of the Port-Channel.
  • •Inconsistent Link Parameters: Mismatched speed, duplex, or VLAN configurations on member links.
Key Takeaway

Effective LAG troubleshooting relies on understanding common pitfalls and using specific `show` commands to diagnose LACP negotiation and interface status.

Troubleshooting Steps & Commands

1. Verify LAG Status

Use `show port-channel summary` and `show lacp neighbor` to check bundle state.

2. Check Individual Link States

Use `show interfaces status` for physical link health.

3. Inspect LACP Details

Use `show lacp internal` for in-depth LACP negotiation information.

Pro Tip

Always ensure that all member links within a LAG have identical speed, duplex, and VLAN configurations. Mismatches are a frequent cause of LAG instability or failure.
