Assigning Physical Interfaces to a Port-Channel

Joining physical links to the logical bundle

Important Notes

  • •Each physical interface must be configured individually.
  • •Use `channel-group mode ` to assign and set LACP mode.
  • •Remove any existing `switchport access vlan` or `switchport mode access` from physical interfaces to avoid conflicts.
Key Takeaway

Physical interfaces are configured to join the Port-Channel, with the LACP mode determining their negotiation behavior, while the Port-Channel handles all higher-level configurations.

Arista EOS: Configure Member Interfaces

Arista(config)# interface Ethernet1
Arista(config-if-Et1)# channel-group 1 mode active # Assign to Port-Channel 1, active LACP
Arista(config-if-Et1)# no switchport access vlan # Remove any existing access VLAN config
Arista(config-if-Et1)# no switchport mode access # Ensure it's not an access port
Arista(config-if-Et1)# exit

Arista(config)# interface Ethernet2
Arista(config-if-Et2)# channel-group 1 mode active
Arista(config-if-Et2)# no switchport access vlan
Arista(config-if-Et2)# no switchport mode access
Arista(config-if-Et2)# end
