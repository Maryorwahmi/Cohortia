Restricting Allowed VLANs on Trunk Ports

Controlling which VLANs are permitted to traverse a trunk link.

Why Restrict VLANs?
  • Enhanced Security: Prevents unauthorized VLANs from traversing links.
  • Improved Performance: Reduces unnecessary broadcast traffic.
  • Simplified Management: Clearer understanding of VLAN flow.
Configuration Syntax

Use switchport trunk allowed vlan <VLAN_ID_RANGE> to specify allowed VLANs.

Key Takeaway

Explicitly defining allowed VLANs on trunk ports is a critical security and optimization practice, ensuring only necessary traffic traverses inter-switch links.

Arista EOS CLI: Restricting Allowed VLANs
Arista(config)# interface Ethernet1
Arista(config-if-Et1)# switchport mode trunk
Arista(config-if-Et1)# switchport trunk allowed vlan 10,20,30
Arista(config-if-Et1)# end

! Example with a range
Arista(config)# interface Ethernet2
Arista(config-if-Et2)# switchport mode trunk
Arista(config-if-Et2)# switchport trunk allowed vlan 1-100
Arista(config-if-Et2)# end
