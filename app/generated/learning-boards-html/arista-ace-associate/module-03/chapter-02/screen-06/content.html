Access Ports: Connecting End Devices to a Single VLAN

Configuring switch ports to carry traffic for a single, specific VLAN.

Access Port Definition

A switch port configured to carry traffic for a single VLAN, typically connected to an end device. Traffic is untagged upon egress.

Traffic Handling
  • Egress: Frames are sent untagged.
  • Ingress: Frames are automatically assigned to the configured access VLAN.
Key Takeaway

Access ports are the entry points for end devices into a specific VLAN, ensuring their traffic is correctly segmented without requiring the device to be VLAN-aware.

Arista EOS CLI: Configuring Access Ports
Arista(config)# interface Ethernet2
Arista(config-if-Et2)# switchport mode access
Arista(config-if-Et2)# switchport access vlan 10
Arista(config-if-Et2)# end
