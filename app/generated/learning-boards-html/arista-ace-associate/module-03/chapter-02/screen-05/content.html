Creating VLANs on Arista EOS Switches

Defining logical network segments using CLI commands.

Command Syntax

Use vlan <VLAN_ID> in global config mode, then name <VLAN_NAME> in VLAN config mode.

Important Notes
  • VLAN IDs range from 1 to 4094.
  • VLAN 1 is default; consider a dedicated management VLAN.
  • Descriptive names improve readability and management.
Key Takeaway

Creating VLANs is the first step in logical segmentation, defining the virtual networks before assigning physical ports.

Arista EOS CLI: Creating VLANs
Arista(config)# vlan 10
Arista(config-vlan-10)# name Sales
Arista(config-vlan-10)# exit
Arista(config)# vlan 20
Arista(config-vlan-20)# name Marketing
Arista(config-vlan-20)# exit
