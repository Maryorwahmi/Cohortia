Troubleshooting Guide

Diagnosing Common VLAN Configuration Issues

Systematic steps to identify and resolve VLAN-related problems.

Systematic Verification Steps
  • Verify VLAN existence: Use show vlan.
  • Check port assignments: Use show interfaces EthernetX switchport.
  • Inspect trunk configurations: Use show interfaces trunk.
Common Mistakes
  • Forgetting to create the VLAN globally.
  • Incorrect access VLAN assignment.
  • Native VLAN mismatches on trunks.
  • Incorrectly allowed VLANs on trunks.
Key Takeaway

A structured approach to verifying VLAN, port, and trunk configurations is essential for efficient troubleshooting and maintaining network stability.

Arista EOS CLI: Troubleshooting Commands
! Check VLAN existence
Arista# show vlan

! Check access port configuration
Arista# show interfaces Ethernet2 switchport

! Check trunk port configuration (including native VLAN and allowed VLANs)
Arista# show interfaces trunk

! Save configuration after making changes
Arista(config)# write memory
Arista(config)# copy running-config startup-config
