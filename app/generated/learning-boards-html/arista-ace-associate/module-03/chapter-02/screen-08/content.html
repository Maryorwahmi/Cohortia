Understanding 802.1Q Tagging

How VLAN IDs are embedded in Ethernet frames for trunk links.

What is 802.1Q?

An IEEE standard that defines a 4-byte tag inserted into an Ethernet frame header to identify its VLAN ID when traversing a trunk link.

Tag Components
  • VLAN ID (VID): 12-bit field, identifies up to 4094 VLANs.
  • Priority Code Point (PCP): For Quality of Service (QoS).
  • Canonical Format Indicator (CFI): For compatibility with Token Ring.
Key Takeaway

802.1Q tagging is the fundamental mechanism that allows a single physical trunk link to logically carry and separate traffic from multiple VLANs, maintaining network segmentation.
