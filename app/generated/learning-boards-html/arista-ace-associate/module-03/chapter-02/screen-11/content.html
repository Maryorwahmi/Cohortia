Native VLAN Mismatch: A Critical Troubleshooting Scenario

Understanding the impact and detection of mismatched native VLANs on trunk links.

What is a Mismatch?

Occurs when the native VLAN configured on one end of an 802.1Q trunk link does not match the native VLAN on the other end.

Impact & Detection
  • Impact: Untagged traffic misclassification, connectivity issues, potential security breaches.
  • Detection: Use show interfaces trunk on Arista EOS to identify discrepancies.
Key Takeaway

Native VLAN mismatches are a critical error that can silently break network connectivity and compromise security; always verify consistency on trunk links.

Arista EOS CLI: Identifying Mismatches
! On SwitchA (Native VLAN 1)
SwitchA# show interfaces trunk
Port        Mode    Encapsulation    Status        Native VLAN
Et1         on      802.1q           trunking      1 (default)

! On SwitchB (Native VLAN 99)
SwitchB# show interfaces trunk
Port        Mode    Encapsulation    Status        Native VLAN
Et1         on      802.1q           trunking      99 (Management)

! Output indicating a mismatch (often with a warning)
SwitchA# show interfaces Ethernet1 status
Port      Name      Status    Vlan      Duplex  Speed Type
Et1                 connected trunk     full    1G    10/100/1000 BaseT
% Warning: Native VLAN mismatch detected on Et1 with peer SwitchB (Et1)
