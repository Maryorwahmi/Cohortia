Key Concepts

Essential Terms and Ideas from This Chapter

VLAN (Virtual Local Area Network)

A logical subdivision of a network that isolates broadcast domains, improving security, performance, and manageability.

Access Port

A switch port configured to carry traffic for a single VLAN, typically connected to an end device, where traffic is untagged.

Trunk Port & 802.1Q

A switch port carrying multiple VLANs, typically between switches, using 802.1Q tagging to identify VLAN traffic.

Summary Takeaway

VLANs are fundamental for modern network design, enabling logical segmentation through distinct port types and the 802.1Q tagging standard to manage traffic flow efficiently and securely.
