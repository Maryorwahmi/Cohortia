Globally Routable vs. Local Communication

Understanding Global Unicast Addresses (GUAs) and Link-Local Addresses (LLAs)

Global Unicast Address (GUA)

Globally unique and routable on the internet. Similar to public IPv4 addresses, typically starts with '2' or '3'.

Link-Local Address (LLA)

Automatically configured, valid only for communication within the local link. Always starts with 'fe80::/10'.

Key Takeaway

GUAs enable global reach, while LLAs facilitate essential local network operations, even without a router.

GUA vs. LLA Comparison

Global Unicast (GUA)
  • Globally unique
  • Routable on Internet
  • Starts with 2 or 3
  • Example: 2001:db8::1
Link-Local (LLA)
  • Local link only
  • Not routable
  • Starts with fe80::/10
  • Example: fe80::abcd:1234

Each address type serves a distinct purpose in the IPv6 communication model.
