The Double Colon: Simplifying All-Zero Segments

Replacing Contiguous Zeros with '::'

Rule 2: Double Colon (::)

A single contiguous sequence of one or more all-zero segments can be replaced by '::'.

Critical Constraint

The '::' can only be used ONCE per IPv6 address to avoid ambiguity. Using it twice is invalid.

Key Takeaway

The double colon is a powerful tool for shortening IPv6 addresses, but its single-use rule is paramount for correct interpretation.

Double Colon Example

2001:db8:0:0:0:8a2e:370:7334
Applies Rule
2001:db8::8a2e:370:7334

The '::' replaces the contiguous block of three '0' segments.
