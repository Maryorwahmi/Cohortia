Arista EOS Configuration

Enabling IPv6 on Arista Interfaces

Essential Commands for Global Routing and Interface Addressing

Global IPv6 Routing

The ipv6 unicast-routing command is mandatory to enable IPv6 packet forwarding across the device.

Interface Configuration

Assign a GUA using ipv6 address and enable SLAAC with ipv6 address autoconfig on the desired interface.

Key Takeaway

Properly enabling global IPv6 routing and configuring interface addresses are foundational steps for IPv6 deployment on Arista EOS.

Arista# configure terminal
Arista(config)# ipv6 unicast-routing # Enable global IPv6 routing
Arista(config)# interface Ethernet 2
Arista(config-if-Et2)# ipv6 address 2001:db8:acad:1::1/64
Arista(config-if-Et2)# ipv6 address autoconfig # Enable SLAAC
Arista(config-if-Et2)# no shutdown
Arista(config-if-Et2)# exit
Arista(config)# exit
