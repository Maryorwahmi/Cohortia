Automatic IPv6 Address Assignment with SLAAC

Combining Router Prefixes and Interface IDs

How SLAAC Works

Devices listen for Router Advertisement (RA) messages from a router to obtain a network prefix.

EUI-64 Format

The device generates a unique 64-bit Interface ID, often from its MAC address using EUI-64, to complete the address.

Key Takeaway

SLAAC simplifies IPv6 deployment by enabling devices to self-configure their IP addresses without a central server.

SLAAC Process Flow

1. Router Advertises Network Prefix

e.g., 2001:db8:acad:1::/64

2. Device Generates Interface ID

e.g., from MAC address using EUI-64

3. Combines to Form Full IPv6 Address

Prefix + Interface ID
