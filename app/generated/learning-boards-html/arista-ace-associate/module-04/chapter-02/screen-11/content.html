Address Configuration

Stateful Assignment with DHCPv6

When You Need More Than Just an IP Address

DHCPv6 Purpose

Provides stateful IPv6 address assignment, maintaining a record of assigned addresses, similar to DHCP in IPv4.

Additional Parameters

Can distribute other network configuration details like DNS server addresses, which SLAAC typically does not.

Key Takeaway

DHCPv6 offers centralized control and comprehensive configuration, often complementing SLAAC in hybrid IPv6 deployments.

SLAAC vs. DHCPv6

SLAAC (Stateless)
  • Automatic IP assignment
  • No server state maintained
  • Primary for IP & gateway
  • Simpler deployment
DHCPv6 (Stateful)
  • Server-managed IP assignment
  • Server maintains state
  • Provides IP, DNS, NTP, etc.
  • Centralized control

Often used together for a comprehensive IPv6 address management solution.
