Mastering CIDR: Prefix Lengths for Flexibility

How CIDR Revolutionized IP Address Management

What is CIDR?

  • Classless Inter-Domain Routing.
  • Allows flexible and efficient allocation of IP addresses.
  • Replaced the rigid classful addressing scheme.

CIDR Notation (Prefix Length)

  • Subnet mask expressed as a prefix length (e.g., /24, /27).
  • Indicates the number of bits used for the network portion.
  • The remaining bits are for host identification.
Key Takeaway

CIDR's prefix length notation provides granular control over network sizing, enabling efficient IP address utilization and simplified routing.

CIDR Prefix Length Examples

192.168.1.0/24

Network: 24 bits (192.168.1)
Hosts: 8 bits
Subnet Mask: 255.255.255.0

10.0.0.0/8

Network: 8 bits (10)
Hosts: 24 bits
Subnet Mask: 255.0.0.0

172.16.0.0/16

Network: 16 bits (172.16)
Hosts: 16 bits
Subnet Mask: 255.255.0.0

Benefit: Flexible Network Sizing

CIDR allows network administrators to create subnets of varying sizes, perfectly matching the needs of different departments or segments, preventing address waste.
