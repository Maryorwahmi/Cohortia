Arista EOS Configuration

Configuring IPv4 on Arista Interfaces

Step-by-Step Interface Configuration on Arista Switches

Configuration Steps

  • Enter global configuration mode (configure terminal).
  • Select the target interface (e.g., interface Ethernet 1).
  • Assign IP address and subnet mask (ip address <IP>/<CIDR>).
  • Enable the interface (no shutdown).
Key Takeaway

Correctly configuring an interface's IP address and subnet mask is fundamental for a device to participate in an IPv4 network.

Arista EOS CLI: Basic IPv4 Configuration

Arista# configure terminal
Arista(config)# interface Ethernet 1
Arista(config-if-Et1)# ip address 192.168.10.1/24
Arista(config-if-Et1)# no shutdown
Arista(config-if-Et1)# exit
Arista(config)# exit

Explanation

  • ip address 192.168.10.1/24: Assigns the IP address 192.168.10.1 with a 255.255.255.0 subnet mask.
  • no shutdown: Activates the interface, making it operational.
