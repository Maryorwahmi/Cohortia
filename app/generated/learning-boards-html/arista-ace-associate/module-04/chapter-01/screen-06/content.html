Historical Context

Evolving IP Allocation: Classful vs. CIDR

Why Classless Inter-Domain Routing Became Essential

The Problem with Classful Addressing

  • Fixed network/host boundaries led to inefficient IP address allocation.
  • Large blocks (e.g., Class B with 65,534 hosts) often wasted addresses.
  • Rapid IP address exhaustion became a critical issue.
Key Takeaway

CIDR was developed to overcome the limitations of classful addressing, enabling more flexible and efficient use of the finite IPv4 address space.

Classful vs. Classless IP Addressing

Classful Addressing

  • Fixed network sizes (A, B, C).
  • Default subnet masks.
  • Inefficient address use.
  • Example: 192.168.1.0 (Class C)

Classless Addressing (CIDR)

  • Flexible network sizes.
  • Uses prefix length (/n).
  • Efficient address use.
  • Example: 192.168.1.0/24

Why the Change?

Classful addressing led to rapid IP address exhaustion. CIDR allows for more granular control over network sizes, preventing waste and extending IPv4's lifespan.
