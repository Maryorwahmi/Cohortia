Address Types

Network, Host, and Broadcast Addresses

Understanding Reserved and Usable Addresses within a Subnet

Network Address

  • The first address in a subnet.
  • Identifies the subnet itself.
  • Cannot be assigned to a host.

Broadcast Address

  • The last address in a subnet.
  • Used to send data to all devices within that subnet.
  • Cannot be assigned to a host.
Key Takeaway

Always remember that the network and broadcast addresses are reserved and cannot be used for individual devices; only host addresses are assignable.

Address Ranges in a /24 Subnet

Example: 192.168.1.0/24

Network Address: 192.168.1.0

Usable Host Addresses

Range: 192.168.1.1 to 192.168.1.254

Broadcast Address

Address: 192.168.1.255

Misconception: Assigning Reserved IPs

A common mistake is attempting to assign the network or broadcast address to a host. This will lead to network connectivity issues as these addresses have special functions.
