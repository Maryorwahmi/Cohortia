The Mechanics of Subnetting

Transforming Host Bits into Network Segments

How Bits are Borrowed

  • You 'borrow' bits from the host portion of the IP address.
  • These borrowed bits are then used to create additional network bits.
  • This process effectively creates more, but smaller, subnetworks.

Impact on Network & Hosts

  • More borrowed bits = more subnets, fewer hosts per subnet.
  • Fewer borrowed bits = fewer subnets, more hosts per subnet.
  • It's a trade-off to balance network segmentation and host capacity.
Key Takeaway

Subnetting is a precise calculation of borrowing host bits to create new network segments, balancing the number of subnets with the number of usable hosts per subnet.

Subnetting Example: /24 to /27

Original Network: 192.168.1.0/24

Network Bits: 24
Host Bits: 8
Usable Hosts: 254

Borrow 3 Host Bits

New Subnets: 192.168.1.0/27

Network Bits: 27
Host Bits: 5
Number of Subnets: 2^3 = 8
Usable Hosts per Subnet: 2^5 - 2 = 30

Outcome: More Granular Control

This allows for 8 distinct subnets, each capable of hosting 30 devices, providing better organization and reduced broadcast domains.
