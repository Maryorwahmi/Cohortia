Core Concept

Defining Network and Host with Subnet Masks

Separating Network from Host in an IPv4 Address

What is a Subnet Mask?

  • A 32-bit mask used to distinguish the network portion from the host portion of an IP address.
  • Works like a filter: '1's indicate network bits, '0's indicate host bits.
  • Essential for devices to understand their network boundaries.

Historical Context: Classful Addressing

  • IP addresses were grouped into classes (A, B, C, D, E).
  • Each class had a default subnet mask (e.g., Class C: 255.255.255.0).
  • This predefined mask determined network and host boundaries.
Key Takeaway

The subnet mask is the critical tool that tells a device which part of an IP address identifies the network and which identifies the specific device.
