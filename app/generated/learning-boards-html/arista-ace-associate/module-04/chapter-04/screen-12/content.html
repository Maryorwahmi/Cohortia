Common Inter-VLAN Routing Issues

Identify and resolve frequent configuration errors that prevent inter-VLAN communication on Arista EOS switches.

Missing ip routing

The switch will not perform Layer 3 routing without this global command.

Incorrect SVI IP Address

SVI IP must match the VLAN's subnet; otherwise, devices cannot reach their gateway.

Physical Port Assignment

Ensure physical access ports are correctly assigned to their respective VLANs.

Shutdown SVI

An SVI must have no shutdown applied to be administratively up and active.

Troubleshooting Flow
Is ip routing enabled?
Are SVI IPs correct & 'up/up'?
Are physical ports assigned?
Connectivity Restored!
Key Takeaway

Systematic troubleshooting, starting from global routing and moving to interface-specific configurations, is key to resolving inter-VLAN routing issues.
