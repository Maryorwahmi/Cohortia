Assigning Physical Ports to VLANs

Connect end devices to your VLANs by configuring physical switch ports as access ports and assigning them to the correct VLAN ID.

1. Enter Interface Mode

Navigate to the specific physical Ethernet interface (e.g., interface Ethernet 1).

2. Configure as Access Port

Set the port mode to access: switchport mode access.

3. Assign to VLAN

Assign the port to its respective VLAN: switchport access vlan <VLAN_ID>.

4. Activate Port

Ensure the port is active with no shutdown.

Arista EOS Configuration Example
Arista(config)# interface Ethernet 1
Arista(config-if-Et1)# description Sales_Access_Port
Arista(config-if-Et1)# switchport mode access
Arista(config-if-Et1)# switchport access vlan 10
Arista(config-if-Et1)# no shutdown
Arista(config-if-Et1)# exit

Arista(config)# interface Ethernet 2
Arista(config-if-Et2)# description Marketing_Access_Port
Arista(config-if-Et2)# switchport mode access
Arista(config-if-Et2)# switchport access vlan 20
Arista(config-if-Et2)# no shutdown
Arista(config-if-Et2)# exit
Pro Tip

Always use descriptive descriptions for your physical interfaces to aid in network documentation and troubleshooting.
