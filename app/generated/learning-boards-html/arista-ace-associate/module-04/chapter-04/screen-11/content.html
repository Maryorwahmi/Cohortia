Verifying SVI Configurations

Confirm SVI operational status, IP address assignment, routing table entries, and end-to-end connectivity.

1. Check SVI Status

Use show ip interface brief Vlan <VLAN_ID> to confirm IP and 'up/up' status.

2. Verify Connected Routes

Run show ip route connected to ensure VLAN networks are recognized as directly connected.

3. Test Connectivity

Use ping from the switch or end devices to confirm inter-VLAN communication.

Arista EOS Verification Commands
Arista# show ip interface brief Vlan 10
Arista# show ip interface brief Vlan 20
Arista# show ip route connected
Arista# ping 192.168.20.1 # Ping SVI in another VLAN
Arista# ping 192.168.20.10 # Ping host in another VLAN
Pro Tip

Always test connectivity from both the switch and actual end devices to ensure full network reachability.
