VLAN Creation and Global IP Routing

Establish VLANs and enable Layer 3 routing globally on the switch as the first steps for SVI functionality.

1. Create VLANs

Use vlan <VLAN_ID> and name <VLAN_Name> to define your logical network segments.

2. Enable Global IP Routing

Execute ip routing (and ipv6 unicast-routing if needed) in global config mode to activate Layer 3 forwarding.

Common Mistake

Forgetting ip routing is a frequent error that prevents inter-VLAN communication, as the switch remains a Layer 2 device.

Arista EOS Configuration Example
Arista# configure terminal
Arista(config)# vlan 10
Arista(config-vlan-10)# name Sales
Arista(config-vlan-10)# exit
Arista(config)# vlan 20
Arista(config-vlan-20)# name Marketing
Arista(config-vlan-20)# exit

Arista(config)# ip routing  # Enable global IP routing for IPv4
Arista(config)# ipv6 unicast-routing # Enable global IP routing for IPv6 (if needed)
Pro Tip

Always verify VLAN creation with show vlan before proceeding to SVI configuration.
