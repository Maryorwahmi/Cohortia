Step-by-Step Configuration

Configuring Switched Virtual Interfaces (SVIs)

Define logical Layer 3 interfaces for each VLAN by assigning IP addresses and ensuring they are active.

1. Enter SVI Interface Mode

Use interface Vlan <VLAN_ID> to configure the specific virtual interface.

2. Assign IP Address

Set the SVI's IP address and subnet mask (e.g., ip address 192.168.10.1/24).

3. Activate SVI

Ensure the SVI is administratively up with the no shutdown command.

Common Mistake

Assigning an SVI IP address outside its VLAN's subnet will cause routing failures for that VLAN.

Arista EOS Configuration Example
Arista(config)# interface Vlan 10
Arista(config-if-Vl10)# description Sales_VLAN_SVI
Arista(config-if-Vl10)# ip address 192.168.10.1/24
Arista(config-if-Vl10)# no shutdown
Arista(config-if-Vl10)# exit

Arista(config)# interface Vlan 20
Arista(config-if-Vl20)# description Marketing_VLAN_SVI
Arista(config-if-Vl20)# ip address 192.168.20.1/24
Arista(config-if-Vl20)# no shutdown
Arista(config-if-Vl20)# exit
Pro Tip

Use descriptive descriptions for your SVIs to easily identify their purpose.
