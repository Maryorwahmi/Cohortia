Key Concepts: Inter-VLAN Routing

Review the foundational terms and ideas from this chapter.

Inter-VLAN Routing

The process of forwarding network traffic between different Virtual Local Area Networks (VLANs).

Layer 3 Switch

A switch that can perform both Layer 2 switching and Layer 3 routing functions.

Switched Virtual Interface (SVI)

A logical Layer 3 interface on a Layer 3 switch associated with a specific VLAN, acting as its default gateway.

Chapter Summary

Inter-VLAN routing is essential for connecting segmented VLANs. Layer 3 switches, utilizing SVIs, provide the necessary routing capabilities by acting as default gateways for each VLAN, enabling seamless communication across different IP subnets.
