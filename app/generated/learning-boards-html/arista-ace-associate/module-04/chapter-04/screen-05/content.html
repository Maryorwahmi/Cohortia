Layer 3 Switches and Switched Virtual Interfaces (SVIs)

Layer 3 switches combine Layer 2 switching with Layer 3 routing, using SVIs as logical interfaces to route between VLANs.

Layer 3 Switch Defined

A switch capable of both Layer 2 (switching) and Layer 3 (routing) functions, often found in modern networks.

What is an SVI?

A Switched Virtual Interface is a logical Layer 3 interface associated with a specific VLAN.

SVI as Default Gateway

Each SVI acts as the default gateway for all devices within its corresponding VLAN.
