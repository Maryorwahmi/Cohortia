Static Route Configuration: Next-Hop IP

Configure a static route using a next-hop IP address on an Arista EOS device.

Scenario

Arista switch needs to reach 192.168.20.0/24. Next-hop router is 192.168.10.2.

Command Breakdown

ip route: initiates static route. 192.168.20.0: destination. 255.255.255.0: mask. 192.168.10.2: next-hop IP.

Key Takeaway

Using a next-hop IP for static routes is preferred on multi-access segments, allowing dynamic MAC address resolution for efficient forwarding.

Arista EOS CLI Configuration
Arista# configure terminal
Arista(config)# ip route 192.168.20.0 255.255.255.0 192.168.10.2
Arista(config)# exit

Explanation:

  • •Enters global configuration mode.
  • •Adds a static route for network 192.168.20.0/24.
  • •Specifies 192.168.10.2 as the next-hop IP address.
  • •Exits configuration mode.

Why Next-Hop IP?

On multi-access segments (like Ethernet LANs), using a next-hop IP allows the router to dynamically resolve the MAC address of the next device, ensuring efficient Layer 2 forwarding.
