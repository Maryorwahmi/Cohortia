Static Route Configuration: Exit Interface Considerations

Understand when to use an exit interface versus a next-hop IP for static routes.

Exit Interface Use Case

Typically reserved for point-to-point links where there's only one possible next device.

Common Mistake

Using an exit interface alone on a multi-access segment without a next-hop IP can cause routing issues.

Key Takeaway

Always use a next-hop IP for static routes on multi-access segments; reserve exit interfaces for point-to-point links.

Next-Hop IP

  • •Preferred for multi-access segments (Ethernet LANs)
  • •Router resolves MAC address dynamically
  • •Example: ip route 192.168.20.0 255.255.255.0 192.168.10.2

Exit Interface

  • •Reserved for point-to-point links
  • •Only one possible next device
  • •Example: ip route 192.168.30.0 255.255.255.0 Ethernet 3
Incorrect Configuration Example
Arista(config)# ip route 192.168.40.0 255.255.255.0 Ethernet 1  # DANGER: If Ethernet 1 is a multi-access segment!

Why this is a mistake:

  • •Router cannot determine the specific Layer 2 MAC address of the next-hop device on a shared segment.
  • •Results in packets being dropped or misdirected.
