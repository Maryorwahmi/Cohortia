Configuring Static Routes: Basic Command Structure

Learn the fundamental Arista EOS command for adding a static route.

Destination Network

The IP network address you want to reach (e.g., 192.168.20.0).

Subnet Mask

The network mask for the destination network (e.g., 255.255.255.0).

Next-Hop or Exit Interface

Specify either the next router's IP or the local interface to forward packets.

Key Takeaway

The `ip route` command requires a destination network, its subnet mask, and a clear indication of the next hop or exit interface for forwarding.

Arista EOS Static Route Command
ip route <destination-network> <subnet-mask> {<next-hop-ip> | <exit-interface>}

Example: Route to 192.168.20.0/24 via next-hop 192.168.10.2

ip route 192.168.20.0 255.255.255.0 192.168.10.2

Common Mistake

Using an exit interface on a multi-access segment without specifying a next-hop IP can lead to routing issues if the router cannot resolve the Layer 2 destination.
