Verification Commands

Verifying Static Routes: The show ip route Command

Inspect the routing table to confirm your static route configurations.

Show IP Route

Displays the entire routing table, including static, connected, and dynamic routes.

Show IP Route Static

Filters the output to show only manually configured static routes.

Key Takeaway

Regularly use `show ip route` and `show ip route static` to confirm your static routes are correctly installed and active in the routing table.

Arista EOS `show ip route` Output
Arista# show ip route

Codes: C - Connected, S - Static, R - RIP, M - Mobile, B - BGP
       D - EIGRP, EX - EIGRP external, O - OSPF, IA - OSPF inter area
       N1 - OSPF NSSA external type 1, N2 - OSPF NSSA external type 2
       E1 - OSPF external type 1, E2 - OSPF external type 2
       i - IS-IS, L1 - IS-IS level-1, L2 - IS-IS level-2, ia - IS-IS inter area
       * - Candidate default, U - Per-user static route, o - ODR
       P - Periodic downloaded static route

Gateway of last resort is 192.168.10.2 to network 0.0.0.0

S*    0.0.0.0/0 [1/0] via 192.168.10.2, Ethernet1
C     192.168.10.0/24 is directly connected, Ethernet1
S     192.168.20.0/24 [1/0] via 192.168.10.2, Ethernet1

Interpreting the Output:

  • •'S' indicates a static route.
  • •`0.0.0.0/0` is the default route.
  • •`[1/0]` represents administrative distance (1 for static) and metric (0).
  • •`via 192.168.10.2, Ethernet1` shows the next-hop IP and exit interface.
