Common Static Routing Mistakes

Avoid typical pitfalls when configuring and managing static routes on Arista EOS.

Incorrect Destination/Mask

Typographical errors in the destination network or subnet mask can lead to misdirected traffic.

Unreachable Next-Hop IP

If the next-hop router is down or misconfigured, the static route becomes a 'black hole'.

IP Routing Not Enabled

Forgetting `ip routing` (IPv4) or `ipv6 unicast-routing` (IPv6) prevents Layer 3 forwarding.

Key Takeaway

Always verify destination, next-hop reachability, and global IP routing enablement to prevent common static routing errors.

Pro-Tip: Verify Next-Hop Reachability

Before relying on a static route, always `ping` the next-hop IP address from the router to ensure it's reachable. An unreachable next-hop makes the static route useless.

Ping Next-Hop
Example: Unreachable Next-Hop
Arista# ping 192.168.10.2
Type escape sequence to abort.
Sending 5, 100-byte ICMP Echos to 192.168.10.2, timeout is 2 seconds:
.....
Success rate is 0 percent (0/5)

Impact:

  • •Any static route pointing to 192.168.10.2 will fail.
  • •Traffic for that route will be dropped.
