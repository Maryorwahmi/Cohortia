IPv6 Routing

Configuring Static Routes: IPv6 Example

Extend your static routing skills to IPv6 networks on Arista EOS.

IPv6 Command

Use ipv6 route instead of ip route for IPv6 static routes.

Prefix Length

Destination is an IPv6 prefix with its length (e.g., /64).

Key Takeaway

IPv6 static routes follow a similar logic to IPv4, using `ipv6 route` and specifying the destination with a prefix and length.

Arista EOS IPv6 Static Route Command
Arista(config)# ipv6 route 2001:db8:cafe:b::/64 2001:db8:cafe:a::2

Explanation:

  • •Adds an IPv6 static route.
  • •Destination network is 2001:db8:cafe:b::/64.
  • •Next-hop IPv6 address is 2001:db8:cafe:a::2.

IPv6 Next-Hop or Exit Interface

Similar to IPv4, you can specify either a next-hop IPv6 address (preferred for multi-access) or an exit interface (for point-to-point links).
