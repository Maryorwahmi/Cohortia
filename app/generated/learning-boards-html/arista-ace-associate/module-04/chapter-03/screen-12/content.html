Troubleshooting Static Routes: ping and traceroute

Utilize essential commands to diagnose connectivity and path issues.

Ping Command

Tests end-to-end connectivity to a destination IP address.

Traceroute Command

Traces the path a packet takes, identifying each hop and potential failure points.

Key Takeaway

`ping` confirms reachability, while `traceroute` pinpoints where connectivity breaks, making them essential for diagnosing static routing issues.

Arista EOS Troubleshooting Commands
Arista# ping 192.168.20.1
Arista# traceroute 192.168.20.1

Common Mistakes to Check:

  • •Incorrect destination network/mask in static route.
  • •Wrong or unreachable next-hop IP address.
  • •Forgetting to enable IP routing globally (ip routing or ipv6 unicast-routing).
  • •Firewall blocking traffic.

Unreachable Next-Hop

A static route pointing to an unreachable next-hop IP address creates a 'black hole' for traffic, meaning packets are sent but never reach their destination.
