Implementing a Default Static Route

Configure the 'gateway of last resort' to direct traffic to unknown destinations.

Gateway of Last Resort

Used when a router receives a packet for a destination not explicitly in its routing table.

IPv4 Default Route

ip route 0.0.0.0 0.0.0.0 <next-hop-ip>

IPv6 Default Route

ipv6 route ::/0 <next-hop-ipv6>

Key Takeaway

A default route is crucial for directing traffic to unknown destinations, typically the internet, acting as a catch-all for unlisted networks.

Arista EOS Default Route Configuration
Arista(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.1
Arista(config)# ipv6 route ::/0 2001:db8:cafe:a::1

Explanation:

  • •Configures an IPv4 default route via 10.0.0.1.
  • •Configures an IPv6 default route via 2001:db8:cafe:a::1.

Why is it important?

Without a default route, your network devices would be unable to reach any destination not explicitly defined in the routing table, effectively isolating them from the internet and other external networks.
