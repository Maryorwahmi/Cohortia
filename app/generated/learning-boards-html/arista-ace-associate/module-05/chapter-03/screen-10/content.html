Configuring the MLAG Domain

Defining the core MLAG parameters on Arista EOS

MLAG Domain Parameters

The MLAG domain configuration block defines the essential parameters that govern the MLAG relationship between two peer switches.

  • •Domain ID: A unique identifier for the MLAG domain (must match on both peers).
  • •Local Interface: The loopback IP of the current switch (its peer address).
  • •Peer Address: The loopback IP of the remote MLAG peer.
  • •Peer Link: The dedicated port-channel connecting the two MLAG peers.
Key Takeaway

Accurate configuration of the MLAG domain ID, peer addresses, and peer link is fundamental for establishing a functional and stable MLAG environment.

Arista-SW1 MLAG Domain Configuration
! Configure Loopback0 for peer address
interface Loopback0
   ip address 10.0.0.1/32

! Configure Peer Link (Port-Channel100)
interface Port-Channel100
   description "MLAG Peer Link to Arista-SW2"
   switchport mode trunk
   switchport trunk allowed vlan all
   no shutdown

interface Ethernet3
   channel-group 100 mode active
   no shutdown
interface Ethernet4
   channel-group 100 mode active
   no shutdown

! Configure MLAG Domain
mlag configuration
   domain-id 100
   local-interface Loopback0
   peer-address 10.0.0.2
   peer-link Port-Channel100
Common Mistake

Mismatched `domain-id` or incorrect `peer-address` can prevent MLAG from forming, leading to an 'Inactive' peer status.
