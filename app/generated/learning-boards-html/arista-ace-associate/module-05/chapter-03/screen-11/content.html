Configuring MLAG Interfaces (Port-Channels)

Connecting downstream devices to the MLAG domain

MLAG Port-Channel Configuration

After defining the MLAG domain, you configure the individual MLAG interfaces, which are port-channels connecting to downstream devices. These require a specific MLAG ID.

  • •Port-Channel Creation: Aggregate physical interfaces into a logical port-channel.
  • •MLAG ID Assignment: Use the mlag <MLAG_ID> command on the port-channel.
  • •Matching IDs: The MLAG_ID must be identical on corresponding port-channels across both MLAG peers.
  • •Trunk Mode: Configure the port-channel as a trunk to carry necessary VLANs.
Key Takeaway

Correctly configuring MLAG interfaces with matching MLAG IDs on both peers is essential for downstream devices to form a single, logical, and redundant LAG.

Arista-SW1 MLAG Interface Configuration
! Configure MLAG Interface (Port-Channel1)
interface Port-Channel1
   description "MLAG to Downstream Device"
   switchport mode trunk
   switchport trunk allowed vlan 10,20
   mlag 1
   no shutdown

interface Ethernet1
   channel-group 1 mode active
   no shutdown
interface Ethernet2
   channel-group 1 mode active
   no shutdown
Common Mistake

Forgetting the `mlag ` command or using mismatched IDs will prevent the logical LAG from forming.
