Verifying MLAG Status

Ensuring your MLAG domain is operational

Key Verification Commands

After configuration, it's essential to verify the MLAG status to ensure proper operation. Arista EOS provides specific commands for this purpose.

  • •show mlag: Provides an overview of MLAG status, peer status, and peer link health.
  • •show mlag interfaces: Displays the status of each configured MLAG port-channel.
  • •Expected Status: Look for "Configured, Enabled, Up" for MLAG state and "Active" for peer status.
Key Takeaway

Regularly using show mlag and show mlag interfaces is crucial for confirming MLAG health and proactively identifying potential issues.

Example: show mlag Output
MLAG Configuration:
  domain-id: 100
  local-interface: Loopback0 (10.0.0.1)
  peer-address: 10.0.0.2
  peer-link: Port-Channel100

MLAG Status:
  MLAG State: Configured, Enabled, Up
  Peer Status: Active
  Peer Link Status: Up
  Heartbeat Status: Ok

MLAG Interfaces:
  Port-Channel1: Up, MLAG ID 1
Troubleshooting Tip

If 'Peer Status' is 'Inactive', check IP reachability between peer addresses and the health of the peer link.
