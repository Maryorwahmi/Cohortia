Equal-Cost Multi-Path (ECMP) Routing
Enhancing Layer 3 load balancing and redundancy
What is ECMP?

ECMP is a Layer 3 routing technique that allows a router to use multiple paths to the same destination if those paths have the same routing cost. It's a fundamental aspect of modern network design.

Key Benefits
  • Load Balancing: Distributes traffic across multiple links, maximizing bandwidth.
  • Redundancy: Automatic rerouting over active paths if one fails, ensuring continuity.
  • Fast Convergence: Rapid recovery, especially when paired with quick detection.
How it Works

When a router has multiple routes to a destination with identical metrics, it installs all of them into its routing table. Traffic is then distributed across these paths based on a hashing algorithm, typically involving source/destination IP addresses and port numbers.

Example: Two paths to a server farm, both with an OSPF cost of 10. ECMP uses both.
Key Takeaway

ECMP is vital for optimizing network performance and providing inherent Layer 3 fault tolerance without complex failover protocols.
