Configuring BFD for VRRP
Accelerating VRRP failover with BFD integration
Scenario & Task

Scenario: Improve VRRP convergence time on `Arista-SW1` for VLAN 10.
Task: Enable BFD globally and associate it with VRRP group 1 on VLAN 10.

Instructions
  • Access `Arista-SW1` CLI.
  • Enable BFD globally.
  • Configure BFD parameters on the VLAN 10 interface.
  • Associate BFD with VRRP group 1 on VLAN 10.
  • Verify BFD and VRRP status.
Arista-SW1 Configuration
enable
configure terminal

! Enable BFD globally
bfd enable

! Configure BFD parameters on the interface
interface Vlan10
   ! Assuming Vlan10 is already configured with IP and VRRP
   bfd interval 500 min_rx 500 multiplier 3

! Associate BFD with VRRP group 1
   vrrp 1 bfd

end

! Verification commands
show bfd neighbors
show vrrp interface Vlan10 detail
Key Takeaway

Proper BFD configuration with VRRP significantly reduces failover times, enhancing the resilience of first-hop routing.
