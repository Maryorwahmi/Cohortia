Key Concepts

Essential terms to remember.

Link Aggregation Group (LAG)

A logical interface bundling multiple physical Ethernet links for increased bandwidth and redundancy.

EtherChannel

Cisco's proprietary term for link aggregation, functionally similar to a Link Aggregation Group (LAG).

Link Aggregation Control Protocol (LACP)

An IEEE 802.3ad standard protocol that dynamically negotiates and manages link aggregation groups between network devices.

Summary Takeaway

LAGs provide the core functionality, EtherChannel is a vendor-specific name, and LACP is the dynamic protocol that makes it all work reliably.
