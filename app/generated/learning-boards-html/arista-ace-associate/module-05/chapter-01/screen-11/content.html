Assigning Physical Interfaces to a LAG

Integrating Ethernet ports into the logical port channel.

Key Commands for Member Interfaces

  • `interface Ethernet`: Enters physical interface configuration.
  • `description "Member of LAG"`: Adds a descriptive label.
  • `channel-group mode active`: Assigns to port channel and sets LACP mode.
  • `no shutdown`: Ensures the physical interface is enabled.
Key Takeaway

Each physical interface must be explicitly assigned to the port channel with a consistent LACP mode for the LAG to form.

Arista EOS CLI Example
configure terminal

! Configure physical interfaces Et1 and Et2
! to join Port-Channel1 in LACP active mode
interface Ethernet1
   description "Member of LAG to Arista-SW2"
   channel-group 1 mode active
   no shutdown

interface Ethernet2
   description "Member of LAG to Arista-SW2"
   channel-group 1 mode active
   no shutdown

Common Mistake:

Forgetting to configure all intended member interfaces or mismatching LACP modes on the peer device will prevent the LAG from forming.
