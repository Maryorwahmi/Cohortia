Key Concepts

Essential terms to remember.

LACP Active Mode

An interface configured in active mode actively initiates LACP negotiation with its peer.

LACP Passive Mode

An interface configured in passive mode waits for its peer to initiate LACP negotiation.

Port Channel

The logical interface representing a Link Aggregation Group (LAG) on Arista EOS.

Summary Takeaway

LACP modes dictate negotiation behavior, and the Port Channel is the specific Arista EOS term for the logical aggregated interface.
