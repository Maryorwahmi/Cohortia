Process Flow

How LACP Negotiates Bundles

Devices exchange PDUs to agree on link aggregation parameters.

1. LACP Enabled

Interfaces configured for LACP start sending PDUs.

2. PDU Exchange

Devices exchange LACP PDUs with system/port info.

3. Negotiation & Bundle

If parameters match, links form a logical LAG.

LACP PDU Contents

  • System Priority & ID
  • Port Priority & ID
  • Key (identifies LAG)
  • Operational State

Why Dynamic Negotiation?

Dynamic negotiation ensures that both ends of the link agree on the parameters and operational state of the bundle. This prevents misconfigurations from causing network issues and allows for automatic detection and removal of failed links, enhancing overall network stability and resilience.

Key Takeaway

LACP PDUs facilitate a continuous negotiation process, ensuring consistent LAG formation and proactive fault detection across network devices.
