Creating the Logical Port Channel

Defining the aggregated link on Arista EOS.

Key Commands for Port Channel

  • `interface Port-Channel`: Creates the logical interface.
  • `description "LAG to Peer"`: Adds a descriptive label.
  • `no switchport`: For Layer 3 routed interfaces.
  • `switchport mode trunk`: For Layer 2 trunk interfaces.
  • `switchport trunk allowed vlan `: Specifies allowed VLANs for trunks.
Key Takeaway

The Port-Channel interface is the central point for configuring the logical LAG's Layer 2 or Layer 3 properties.

Arista EOS CLI Example
enable
configure terminal

! Create the Port-Channel interface
interface Port-Channel1
   description "LAG to Arista-SW2"
   ! For a Layer 2 trunk, configure:
   switchport mode trunk
   switchport trunk allowed vlan 10,20
   ! For a Layer 3 interface, use 'no switchport' and assign IP
   ! no switchport
   ! ip address 192.168.1.1/24

Pro Tip:

Always add a meaningful description to your interfaces for easier management and troubleshooting.
