Diagnosing LAG Formation Failures

Identifying and resolving common LACP misconfigurations.

Common Causes of LAG Failure

  • Physical Layer Issues: Bad cables, faulty transceivers, disconnected links.
  • Mismatched LACP Modes: e.g., active on one side, passive/none on the other.
  • Inconsistent Interface Settings: Speed, duplex, access/trunk mode mismatches.
  • VLAN Mismatches: Allowed VLANs on trunk ports not identical.
  • Conflicting Configurations: Interface already part of another LAG or other conflicting settings.
Key Takeaway

A systematic troubleshooting approach, starting from the physical layer and checking configuration consistency, is key to resolving LAG issues.

Troubleshooting Flow

1. Check Physical Layer (Cables, Transceivers)

2. Verify LACP Mode Consistency on Both Ends

3. Check Speed, Duplex, Port Type Consistency

4. Ensure No Conflicting Configurations

Remember:

Arista EOS often provides clear error messages or 'S' (Suspended) flags in `show port-channel summary` to indicate issues.
