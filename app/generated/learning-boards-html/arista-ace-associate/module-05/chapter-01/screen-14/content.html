LACP Configuration Scenario

Applying LACP active mode on Arista EOS switches.

Scenario Overview

  • Configure LACP LAG between `Arista-SW1` and `Arista-SW2`.
  • `Arista-SW1`: Ethernet interfaces Et1 and Et2.
  • Form `Port-Channel1` in LACP `active` mode.
  • Assume `Arista-SW2` is also configured with LACP `active`.
Key Takeaway

This activity reinforces the practical steps for creating and verifying an LACP LAG on Arista EOS.

Arista-SW1 Configuration Instructions
! Arista-SW1 Configuration
enable
configure terminal

! 1. Create the Port-Channel interface
interface Port-Channel1
   description "LAG to Arista-SW2"
   switchport mode trunk
   switchport trunk allowed vlan 10,20

! 2. Configure physical interfaces Et1 and Et2
!    to join Port-Channel1 in LACP active mode
interface Ethernet1
   description "Member of LAG to Arista-SW2"
   channel-group 1 mode active
   no shutdown

interface Ethernet2
   description "Member of LAG to Arista-SW2"
   channel-group 1 mode active
   no shutdown

end

! 3. Verification commands
show port-channel summary
show port-channel 1 detail
show interfaces Port-Channel1

Focus:

Pay attention to the `channel-group` command and the `mode active` keyword for LACP negotiation.
