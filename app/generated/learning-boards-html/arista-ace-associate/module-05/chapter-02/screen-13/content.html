Arista EOS Verification

Verifying STP Topology and Status

Commands to inspect Root Bridge, port roles, and states.

Key Verification Points

  • ●
    Root Bridge: Confirm the expected switch is the Root Bridge.
  • ●
    Port Roles: Verify Root Ports, Designated Ports, and Blocking Ports are assigned correctly.
  • ●
    Port States: Ensure ports are in the expected forwarding or blocking states.
Common Mistakes

Not influencing Root Bridge election (suboptimal paths) or enabling PortFast on uplink ports (temporary loops).

CLI Verification
Arista-SW1#show spanning-tree
! Displays global STP status, Root Bridge, and port roles/states

Arista-SW1#show spanning-tree vlan 10
! Displays STP status specifically for VLAN 10 (useful for PVST+)

Arista-SW1#show spanning-tree root
! Shows details about the Root Bridge and local switch's path to it
Key Takeaway

Regularly use `show spanning-tree` commands to confirm correct STP operation and prevent common misconfigurations that can lead to network issues.
