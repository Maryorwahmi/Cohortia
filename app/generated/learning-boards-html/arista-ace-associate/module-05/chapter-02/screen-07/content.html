STP Port Roles

Understanding Root and Designated Ports

Establishing the shortest path and forwarding responsibility.

Root Port (RP)

  • ●
    Lowest Cost Path: The port on a non-Root Bridge switch that offers the best (lowest cost) path to the Root Bridge.
  • ●
    Always Forwarding: This port is always in a forwarding state, actively participating in data transfer.
  • ●
    One per Non-Root Switch: Each non-Root Bridge switch has exactly one Root Port.

Designated Port (DP)

  • ●
    Segment Forwarding: The port on a network segment responsible for forwarding traffic onto that segment.
  • ●
    Closest to Root: Typically the port on the switch with the lowest path cost to the Root Bridge for that segment.
  • ●
    One per Segment: There is only one Designated Port per network segment.

Key Takeaway

Root Ports ensure non-Root Bridges have a clear path to the Root, while Designated Ports manage traffic forwarding on individual network segments.
