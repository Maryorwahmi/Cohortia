STP Components

Electing the Root Bridge

The central point of the spanning tree topology.

Root Bridge Election Process

  • ●
    Bridge ID (BID): Each switch has a unique BID, composed of a priority value (default 32768) and its MAC address.
  • ●
    BPDU Exchange: Switches exchange BPDUs containing their BIDs.
  • ●
    Lowest BID Wins: The switch with the numerically lowest BID is elected as the Root Bridge. Priority is compared first, then MAC address as a tie-breaker.
Example

If Switch A has priority 32768 and MAC A, and Switch B has priority 24576 and MAC B, Switch B will become the Root Bridge because its priority is lower. If both had 32768, the one with the lower MAC address would win.

Bridge ID Structure

Key Takeaway

The Root Bridge is the switch with the lowest Bridge ID, which is determined by its priority and MAC address, serving as the central reference for STP calculations.
