VRRP Configuration: Virtual IP and Group ID

Defining the virtual gateway for your subnet on Arista EOS.

Key Configuration Points

  • •Configure VRRP on a Layer 3 interface (e.g., VLAN interface).
  • •Assign a virtual IP address: this is the default gateway for end devices.
  • •The virtual IP must be in the subnet but not a physical IP of any router.
  • •Assign a VRRP group ID: must be consistent across all routers in the group.
Key Takeaway

The virtual IP and group ID are the foundational elements for establishing a VRRP-enabled redundant gateway, ensuring consistent access for end devices.

Arista EOS CLI Example
interface Vlan10
   ip address 192.168.10.2/24
   vrrp 1 ip 192.168.10.1
Explanation:
  • •vrrp 1: Specifies VRRP group ID 1.
  • •ip 192.168.10.1: Sets the virtual IP address for this group.
  • •This virtual IP will be the default gateway for devices in VLAN 10.
