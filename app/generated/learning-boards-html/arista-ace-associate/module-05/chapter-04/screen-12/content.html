Verifying VRRP Operational Status

Commands to confirm Master/Backup roles and settings.

Key Verification Commands

  • •show vrrp: Provides a summary of all VRRP groups, their state (Master/Backup), virtual IP, priority, and timers.
  • •show vrrp interface vlan <VLAN_ID>: Offers detailed information for a specific VRRP group on a VLAN interface.
  • •Look for the expected Master/Backup state and correct virtual IP address.
Key Takeaway

Regularly using show vrrp commands is essential to confirm that VRRP is operating correctly and providing the intended first-hop redundancy.

Arista EOS CLI Output Example (Master)
Arista-SW1#show vrrp

Vlan10 - Group 1
  State is Master
  Virtual IP is 192.168.10.1
  Virtual MAC address is 0000.5e00.0101
  Priority is 150
  Advertisement interval is 1.000 sec
  Preemption is enabled
  Master router is 192.168.10.2 (local)
Arista EOS CLI Output Example (Backup)
Arista-SW2#show vrrp

Vlan10 - Group 1
  State is Backup
  Virtual IP is 192.168.10.1
  Virtual MAC address is 0000.5e00.0101
  Priority is 100
  Advertisement interval is 1.000 sec
  Preemption is enabled
  Master router is 192.168.10.2
