Configuring VRRP on Arista-SW2

Setting up the Backup router to ensure redundancy for VLAN 10.

Configuration Steps for Backup

  • •Configure the physical IP address on its VLAN 10 interface.
  • •Define VRRP group 1 with the same virtual IP address (192.168.10.1).
  • •Set a lower priority (e.g., 100) than the Master to ensure it remains Backup.
  • •Preemption is enabled by default, allowing it to take over if the Master fails.
Key Takeaway

Configuring Arista-SW2 with a lower priority ensures it functions as the Backup, ready to assume the Master role if the primary gateway becomes unavailable.

Arista-SW2 Configuration
enable
configure terminal

interface Vlan10
   description "VLAN 10 for VRRP"
   ip address 192.168.10.3/24

   vrrp 1 ip 192.168.10.1
   vrrp 1 priority 100
   vrrp 1 preempt

end
Important Note

Both routers must be in the same VRRP group (ID 1) and share the same virtual IP address (192.168.10.1) for proper operation.
