Master Election

VRRP Configuration: Priority and Election

Determining which router becomes the active Master gateway.

How Master is Elected

  • •Each router in a VRRP group is assigned a priority (1-254).
  • •The router with the highest priority becomes the Master.
  • •Priority 255 is reserved for the router that owns the virtual IP as its physical IP.
  • •If priorities are equal, the router with the highest physical IP address on the interface becomes Master.
Key Takeaway

Priority is the primary factor in VRRP Master election, with higher values indicating preference, and physical IP serving as a tie-breaker.

Arista EOS CLI Example
interface Vlan10
   vrrp 1 ip 192.168.10.1
   vrrp 1 priority 150
Explanation:
  • •vrrp 1 priority 150: Sets the priority for VRRP group 1 to 150.
  • •A higher value (e.g., 150) makes this router more likely to become Master than one with a lower priority (e.g., 100).
Example Scenario

If Router A has priority 120 and Router B has priority 100, Router A will become the Master, assuming both are operational.
