Introducing VRRP: The Virtual Router

Creating a resilient, always-available default gateway.

Key Elements of a Virtual Router

  • •A group of physical routers forms a logical 'virtual router'.
  • •This virtual router has a unique 'virtual IP address'.
  • •It also has a 'virtual MAC address' for ARP responses.
  • •End devices use the virtual IP as their default gateway, unaware of physical changes.
Key Takeaway

VRRP's virtual router concept provides a transparent, highly available default gateway, abstracting physical device changes from end devices.
