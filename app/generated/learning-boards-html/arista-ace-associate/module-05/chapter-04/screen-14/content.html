Key Concepts

Essential VRRP Terms to Remember

First-Hop Redundancy Protocol (FHRP)

A category of protocols designed to provide default gateway redundancy for end devices.

Virtual Router

A logical router represented by a virtual IP and MAC address, managed by a VRRP group.

Virtual IP Address

The IP address assigned to the virtual router, used by end devices as their default gateway.

Virtual MAC Address

A specific MAC address used by the Master router to respond to ARP requests for the virtual IP.

Chapter Summary

VRRP provides critical first-hop redundancy by abstracting physical routers into a virtual gateway, ensuring continuous network connectivity for end devices.
