Configuring VRRP on Arista-SW1

Setting up the preferred Master router for VLAN 10.

Configuration Steps for Master

  • •Configure the physical IP address on the VLAN 10 interface.
  • •Define VRRP group 1 with the virtual IP address (192.168.10.1).
  • •Set a higher priority (e.g., 150) to make it the preferred Master.
  • •Preemption is enabled by default, ensuring it takes over if available.
Key Takeaway

Configuring a higher priority on Arista-SW1 ensures it acts as the primary, preferred Master for the VRRP group, providing active gateway services.

Arista-SW1 Configuration
enable
configure terminal

interface Vlan10
   description "VLAN 10 for VRRP"
   ip address 192.168.10.2/24

   vrrp 1 ip 192.168.10.1
   vrrp 1 priority 150
   vrrp 1 preempt

end
Scenario Context

Arista-SW1 is intended to be the primary default gateway for devices in the 192.168.10.0/24 subnet, using 192.168.10.1 as the virtual IP.
