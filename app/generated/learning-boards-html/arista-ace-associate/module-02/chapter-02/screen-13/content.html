Saving Configuration Changes

Ensuring your hard work persists across reboots and power cycles.

Arista-Leaf1# copy running-config startup-config

Key Takeaway

Always save your configuration using copy running-config startup-config to prevent losing changes on reboot.

Why it's Crucial

Unsaved changes in running-config are lost if the switch reboots or loses power, leading to configuration rollbacks and potential network disruption.

The Command

copy running-config startup-config copies the active configuration from RAM to non-volatile flash memory.

Best Practice

Make it a habit to save after any significant configuration change to ensure persistence and avoid rework.

Common Mistake

Forgetting this step is a very common and frustrating error, often discovered only after a device reboot.
