Configuring a Default Gateway for Mgmt0

Enabling communication beyond the local management subnet.

Arista-Leaf1# configure terminal
Arista-Leaf1(config)# ip routing mgmt
Arista-Leaf1(config)# interface Management0
Arista-Leaf1(config-if-Mg0)# ip route 0.0.0.0/0 192.168.100.1
Arista-Leaf1(config-if-Mg0)# end
Key Takeaway

A default gateway is essential for Mgmt0 to reach external management services like DNS, NTP, and syslog servers.

Why it's Necessary

Without a default gateway, the switch can only communicate with devices on its directly connected management subnet, limiting its functionality.

Command Sequence

First, enable management routing globally (ip routing mgmt), then define the default route within the Management0 interface.

Example Scenario

Your switch needs to send logs to a syslog server located on a different network segment. The default gateway tells it how to reach that server.

Common Pitfall

Forgetting ip routing mgmt will prevent the default route from being active, even if configured on the interface.
