Interface Transformation

Layer 3 Ethernet Interfaces

Converting a Layer 2 switchport to a routed port for IP routing.

Arista-Leaf1# configure terminal
Arista-Leaf1(config)# interface Ethernet1
Arista-Leaf1(config-if-Et1)# no switchport
Arista-Leaf1(config-if-Et1)#
Key Takeaway

The no switchport command is essential to enable Layer 3 routing capabilities on a physical Ethernet interface.

Default Behavior

Physical Ethernet interfaces on Arista switches are Layer 2 switchports by default, forwarding frames based on MAC addresses.

Why Convert to Layer 3?

Allows the switch to act as a router on that specific port, participating in IP routing decisions for traffic entering or leaving.

Critical Command

no switchport disables Layer 2 functionality, making the interface a Layer 3 routed port. This is a prerequisite for assigning an IP address.

Common Oversight

Forgetting no switchport is a frequent mistake, preventing IP address assignment and Layer 3 operation on the interface.
