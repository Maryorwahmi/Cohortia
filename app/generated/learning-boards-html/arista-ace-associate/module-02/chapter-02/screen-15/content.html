Chapter Recap

Essential Takeaways (Cont.)

More core ideas from this chapter to reinforce your learning.

speed and duplex

Interface parameters for configuring link speed (e.g., 100mbps, 1gbps) and duplex mode (half or full).

no shutdown

Command to administratively enable an interface, as interfaces are typically shut down by default.

running-config

The active configuration currently loaded in the switch's RAM, which is temporary.

startup-config

The configuration saved in non-volatile memory (flash), loaded upon switch reboot, making it persistent.

copy running-config startup-config

Command to save the active configuration from RAM to persistent storage, ensuring changes survive reboots.
