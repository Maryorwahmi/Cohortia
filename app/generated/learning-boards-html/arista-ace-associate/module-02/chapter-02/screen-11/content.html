Configuration Audit

Verifying Configuration Settings

Confirming active settings and interface status for operational integrity.

Arista-Leaf1# show running-config interface Ethernet1
interface Ethernet1
   description "Uplink to Router A"
   no switchport
   ip address 10.0.0.1/30
   no shutdown
!
Arista-Leaf1# show ip interface brief
Interface              IP Address      Status          Protocol
-------------------- --------------- --------------- ---------------
Ethernet1              10.0.0.1/30     up              up
Management0            192.168.100.10/24 up              up
Key Takeaway

Regularly verify configurations to ensure changes are active and interfaces are operating as expected.

show running-config

Displays the entire active configuration in RAM. Can be filtered (e.g., show running-config interface <name>).

show ip interface brief

Provides a quick summary of IP address assignments and the administrative/operational status of all IP-enabled interfaces.

Importance of Verification

Prevents misconfigurations from going unnoticed, which can lead to network outages or unexpected behavior.

Troubleshooting Tip

If an interface isn't working, always check its status with show ip interface brief and its full config with show running-config interface.
