Layer 3 Configuration

Assigning IP to Layer 3 Ethernet

Applying IP addresses to routed physical interfaces for network communication.

Arista-Leaf1(config)# interface Ethernet1
Arista-Leaf1(config-if-Et1)# no switchport
Arista-Leaf1(config-if-Et1)# ip address 10.0.0.1/30
Arista-Leaf1(config-if-Et1)# no shutdown
Arista-Leaf1(config-if-Et1)# end
Key Takeaway

An IP address on a Layer 3 Ethernet interface provides its network identity, enabling it to route traffic.

Prerequisite

Ensure the no switchport command has been issued on the interface before attempting to assign an IP address.

Command Syntax

Use ip address <ip-address>/<subnet-mask-length> within interface configuration mode.

Example Application

Configuring Ethernet1 with 10.0.0.1/30 allows it to be the endpoint for a point-to-point link to another router.

Configuration Error

Assigning an incorrect subnet mask can lead to network segmentation issues or devices being unable to communicate.
