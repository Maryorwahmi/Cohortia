Understanding CLI Operational Modes

A Hierarchical Approach to Device Interaction

CLI Mode Hierarchy
User EXEC ModePrompt: Switch>Limited monitoring & diagnostics
Privileged EXEC ModePrompt: Switch#Full monitoring, gateway to config
Global Configuration ModePrompt: Switch(config)#System-wide settings
Specific Configuration ModesPrompt: Switch(config-if)#, etc.Interface, VLAN, Router settings
Purpose of Hierarchy

Prevents accidental configuration changes by limiting available commands based on privilege level.

User EXEC Mode (>)

Initial login mode with very limited commands, primarily for basic monitoring and diagnostics.

Key Takeaway

The EOS CLI uses a hierarchical mode structure to control command access, starting with the most restricted User EXEC mode.
