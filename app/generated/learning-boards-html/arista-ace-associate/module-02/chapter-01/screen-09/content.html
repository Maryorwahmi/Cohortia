Context-Sensitive Help

Using the '?' Character

  • List Commands: Typing ? shows all available commands in current mode.
  • Parameter Help: Command followed by ? shows next available options.
Example
Switch#show ?
Switch#show ip ?
Tab Completion

Using the 'Tab' Key

  • Auto-Complete: Completes unique commands or keywords.
  • Show Options: Displays possible completions if multiple exist.
  • Reduces Errors: Minimizes typos and speeds up command entry.
Example
Switch#conf<Tab> (completes to 'configure')
Switch#show int<Tab> (shows 'interface', 'interfaces', etc.)
Key Takeaway

Leverage '?' for discovering commands and parameters, and 'Tab' for efficient command completion to significantly enhance your CLI productivity.
