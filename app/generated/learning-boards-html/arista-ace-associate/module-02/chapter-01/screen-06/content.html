Module 2›Chapter 1›User vs. Privileged EXEC
User EXEC Mode

Limited Access (Switch>)

  • Initial Login: First mode upon successful login.
  • Restricted Commands: Primarily basic monitoring and diagnostics.
  • Read-Only: No configuration changes possible.
Example Command
Switch>show version
Privileged EXEC Mode

Elevated Access (Switch#)

  • Access via enable: Elevates privileges from User EXEC.
  • Full Monitoring: Access to all show commands.
  • Configuration Gateway: Required to enter configuration modes.
Example Command
Switch>enable
Password:
Switch#show ip interface brief
Key Takeaway

Always start in User EXEC (>) for basic checks, then use 'enable' to transition to Privileged EXEC (#) for comprehensive monitoring and configuration access.
