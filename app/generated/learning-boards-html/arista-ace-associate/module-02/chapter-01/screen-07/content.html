Entering Global Configuration Mode

Applying System-Wide Settings

Key Aspects
  • Access Command: Use configure terminal from Privileged EXEC mode.
  • Prompt: Indicated by (config)#.
  • Scope: Apply settings that affect the entire device (e.g., hostname, global services).
Key Takeaway

Global Configuration mode is essential for applying system-wide settings and is the necessary step before diving into more specific configuration contexts.

CLI Command Example
Switch#configure terminal
Switch(config)#hostname Core-Switch-1
Core-Switch-1(config)#
Why it Matters

This mode is the foundation for all device-level configurations, from basic identification to enabling critical network services. Without it, you cannot customize your switch's global behavior.

Common Mistake

Attempting to configure specific features (like an interface IP address) directly in Global Configuration mode. These require navigating to a more specific sub-mode.
