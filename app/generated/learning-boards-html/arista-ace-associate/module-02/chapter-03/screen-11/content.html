Recovery Process

Loading a Saved Configuration

Revert to a previous known good state using a backup file.

Copy to Running-Config

Load the backup file's contents into the active running-config.

Review and Save

Carefully review changes, then save to startup-config to make them permanent.

CLI Demo: Configuration Restore

Loading and Saving a Backup

# Copy backup to running-config
switch# copy flash:/my-backup-config-date.cfg running-config
Copy completed successfully.

# Review changes (e.g., 'show diff running-config startup-config')
switch# show running-config interface Ethernet99
interface Ethernet99
   no shutdown
   description "Test change"

# After restore, verify the change is gone
switch# show running-config interface Ethernet99
% Interface Ethernet99 not found

# Make the restored configuration permanent
switch# copy running-config startup-config
Copy completed successfully.

# Explanation:
# - 'copy flash:/... running-config': Loads the backup into active config.
# - 'show running-config interface Ethernet99': Verifies changes.
# - 'copy running-config startup-config': Saves the active config permanently.
Key Takeaway

Restore configurations by copying a backup to running-config, review changes, then save to startup-config for permanence, avoiding common pitfalls.
