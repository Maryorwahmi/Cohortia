Configuration Management

Understanding Configuration States

Differentiating between active and persistent configurations.

Running-Config

The active configuration currently loaded in the switch's RAM. Changes are immediate but not persistent across reboots unless saved.

Startup-Config

The configuration stored in non-volatile memory (flash) that the switch loads upon reboot. It represents the persistent state.

CLI Demo: Local Backup

Saving Configuration to Flash

# Save the current running configuration to flash
switch# copy running-config flash:/my-backup-config-date.cfg
Copy completed successfully.

# Save the startup configuration to flash (if different)
switch# copy startup-config flash:/my-startup-backup.cfg
Copy completed successfully.

# Verify the backup file is on flash
switch# dir flash:
Directory of flash:/

  ...
  12345      -rw-  Jul 20 15:00  my-backup-config-date.cfg
  12345      -rw-  Jul 20 15:01  my-startup-backup.cfg
  ...

# Explanation:
# - 'copy running-config flash:/...': Saves the active config.
# - 'copy startup-config flash:/...': Saves the persistent config.
# - 'dir flash:': Confirms the backup file's presence.
Key Takeaway

Local backups save running-config or startup-config to flash, providing a quick recovery point, but external backups offer greater resilience.
