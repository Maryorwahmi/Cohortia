CLI Utilities

Managing Files on EOS Flash

Essential commands for organizing and maintaining the switch's internal storage.

dir flash:

Lists the contents of the flash directory, showing files and subdirectories.

mkdir flash:/<directory>

Creates a new directory on the flash memory for better organization.

rm flash:/<filename>

Deletes a specified file from flash. Use with extreme caution as files are not easily recoverable.

CLI Demo: File Management

Using Basic File System Commands

# List contents of flash
switch# dir flash:
Directory of flash:/

  456789120  -rw-  Jul 20 14:30  EOS-4.28.0F.swi
  12345      -rw-  Jul 20 15:00  my-backup-config-date.cfg
  ...

# Create a new directory
switch# mkdir flash:/archive
Directory 'flash:/archive' created.

# Copy a file into the new directory
switch# copy flash:/my-backup-config-date.cfg flash:/archive/my-backup-config-date.cfg
Copy completed successfully.

# Remove an old image file
switch# rm flash:/EOS-4.28.0F.swi
Delete flash:/EOS-4.28.0F.swi? [confirm]
File 'flash:/EOS-4.28.0F.swi' deleted.

# Explanation:
# - 'dir flash:': Shows current files and directories.
# - 'mkdir': Creates a new directory.
# - 'copy': Moves or copies files.
# - 'rm': Deletes files (requires confirmation).
Key Takeaway

Utilize dir, mkdir, and rm commands to organize and manage files on EOS flash, exercising caution with deletion.
