Upgrade Process: Step 2

Transferring the EOS Image

Securely copy the .swi file to the switch's internal flash memory.

Preferred Methods: SCP / SFTP

These protocols leverage SSH for secure, encrypted file transfers, ideal for production environments.

Destination: Flash Memory

The EOS image is copied to the switch's internal non-volatile storage, typically flash:/.

CLI Demo: SCP Transfer

Copying EOS Image from Workstation

# From your local management workstation
scp EOS-4.28.0F.swi admin@192.168.1.10:flash:/

# Expected output (password prompt, then transfer details)
admin@192.168.1.10's password:
EOS-4.28.0F.swi        100% 456MB 12.3MB/s   00:37

# Explanation:
# - 'EOS-4.28.0F.swi': The local path to the EOS image file.
# - 'admin@192.168.1.10': The remote username and IP address of the Arista switch.
# - 'flash:/': The destination directory on the switch's internal flash memory.
Key Takeaway

Utilize SCP or SFTP to securely transfer EOS image files to the switch's flash memory, protecting data integrity during transit.
