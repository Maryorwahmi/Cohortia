Configuration Management

Securing Backups Off-Device

Transferring configurations to external storage for enhanced disaster recovery.

Why External Backups?

Local backups are vulnerable to device failure; external backups provide crucial redundancy.

Secure Protocols: SCP / SFTP

Use these SSH-based protocols to securely transfer configuration files to a centralized backup server.

CLI Demo: External Backup

Copying Configuration to a Remote Server

# Copy a local backup file to a remote SCP server
switch# copy flash:/my-backup-config-date.cfg scp://admin@backup-server/configs/my-switch-config.cfg
admin@backup-server's password:
Copy completed successfully.

# Explanation:
# - 'flash:/my-backup-config-date.cfg': The source configuration file on the switch.
# - 'scp://admin@backup-server/configs/my-switch-config.cfg': The destination path on the remote SCP server.
#   - 'admin': Username on the backup server.
#   - 'backup-server': Hostname or IP of the backup server.
#   - '/configs/my-switch-config.cfg': Path and filename on the remote server.
Key Takeaway

External backups using SCP/SFTP to a centralized server are crucial for disaster recovery, protecting configurations against device failure.
