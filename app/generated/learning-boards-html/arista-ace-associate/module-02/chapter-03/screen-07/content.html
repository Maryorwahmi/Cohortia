Upgrade Process: Step 3

Initiating the EOS Installation

The final steps involve verifying the image and executing the installation command.

Pre-Upgrade Backup

Always back up your current configuration to provide a rollback point.

Verify File Presence

Use dir flash: to confirm the EOS image is on the switch's flash memory.

CLI Demo: Installation

Executing the `install source` Command

# From Privileged EXEC mode
switch# dir flash:
Directory of flash:/

  456789120  -rw-  Jul 20 14:30  EOS-4.28.0F.swi
  ...

switch# install source flash:/EOS-4.28.0F.swi
Proceed with install? [y/N]: y
...
Installation complete. A reload is required.
switch# reload
Proceed with reload? [y/N]: y

# Explanation:
# - 'dir flash:': Lists contents of flash to confirm image presence.
# - 'install source': Initiates the software upgrade process.
# - 'reload': Reboots the switch to apply the new EOS software.
Key Takeaway

Always back up configurations before installing a new EOS image, and be prepared for a system reload to complete the upgrade.
