Assessing CPU Load

Identifying Potential Performance Bottlenecks

The `show cpu` Command

Provides a summary of the switch's CPU utilization over various time intervals (e.g., 5 seconds, 1 minute, 5 minutes).

Causes of High CPU

  • Routing protocol flapping (instability)
  • Excessive control plane traffic
  • Denial-of-Service (DoS) attacks
  • Software bugs or inefficient processes
Key Takeaway

Establish a CPU utilization baseline for your devices; sudden spikes above this baseline warrant immediate investigation to prevent performance degradation.

Arista vEOS# show cpu
CPU utilization for five seconds: 10%
CPU utilization for one minute: 8%
CPU utilization for five minutes: 7%

PID Runtime(ms) Invoked uSecs 5Sec 1Min 5Min TTY Name

Example: A 5-second CPU of 10% is healthy. If this were 90%, it would indicate a problem.
