Setting Up SNMP Community Strings

Securely enable remote monitoring on your Arista switches.

Community String Defined

Authentication for SNMP

A password-like string used to authenticate access to SNMP-managed devices, controlling read-only or read-write permissions.

Security Best Practice

Avoid Default & Weak Strings

Always use strong, non-default community strings and restrict access to trusted Network Management Systems (NMS) hosts.

Key Takeaway

Properly configured SNMP community strings are vital for both enabling monitoring and securing your network devices.

SNMP Community Configuration

configure terminal
snmp-server community CohortiaMonitor ro
snmp-server host 192.168.1.101 version 2c CohortiaMonitor
end

This configuration sets a read-only community string and specifies a trap destination.
