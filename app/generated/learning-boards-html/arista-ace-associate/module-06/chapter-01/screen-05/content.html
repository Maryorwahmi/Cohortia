Checking Interface Health

Understanding `show interfaces status` Output

Command Overview

The show interfaces status command provides a quick summary of all network interfaces, their operational state (up/down), and connected VLANs.

Interpreting 'Down' Status

If an interface shows as 'down', it immediately signals a physical layer problem (e.g., cable issue) or a misconfiguration on the port or connected device.

Key Takeaway

Regularly checking show interfaces status is crucial for quickly identifying and addressing connectivity issues at the physical layer.

Arista vEOS# show interfaces status
Port Name Status Vlan Duplex Speed Type
Et1/1 -- connected 1 full 1G 1000BASE-T
Et1/2 -- notconnect 1 auto auto 1000BASE-T
Et1/3 -- connected 10 full 1G 1000BASE-T
Et1/4 -- connected 20 full 1G 1000BASE-T
Mgmt1 -- connected 1 full 1G Management
Example: Notice Et1/2 is 'notconnect'. This indicates a potential cable issue or a disabled port on the remote end.
