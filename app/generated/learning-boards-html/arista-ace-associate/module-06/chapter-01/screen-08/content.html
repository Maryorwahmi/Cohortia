Advanced Diagnostics

Pinpointing Resource Hogs

Using `show processes top` for Detailed Analysis

Beyond Aggregate Metrics

While show cpu and show memory provide overall utilization, show processes top offers granular, real-time statistics for individual processes.

Diagnosing Complex Issues

This command is invaluable for identifying which specific daemon or application is consuming the most CPU or memory, allowing for targeted troubleshooting.

Key Takeaway

Use show processes top to move from general resource concerns to specific process identification, enabling precise problem resolution.

Arista vEOS# show processes top
PID USER      PR  NI    VIRT    RES    SHR S  %CPU %MEM     TIME+ COMMAND
  1 root      20   0  1.0g  200m  100m S   5.0  5.0   0:15.23 init
  2 root      20   0  1.5g  150m   80m S   3.0  3.7   0:10.10 ribd
  3 root      20   0  1.2g  100m   60m S   2.0  2.5   0:08.05 bgp
  4 root      20   0  800m   50m   30m S   1.0  1.2   0:05.00 mlag
Example: If 'ribd' showed 70% CPU, you'd know to investigate routing protocol issues.
