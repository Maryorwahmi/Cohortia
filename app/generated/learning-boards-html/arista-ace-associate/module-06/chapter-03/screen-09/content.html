Basic CLI Scripting: Command Aliases

Simplifying repetitive commands on Arista EOS.

What are CLI Aliases?

  • Custom shortcuts for longer command sequences.
  • Reduces typing and potential for errors.
  • A simple form of imperative automation.
  • Enhances operational efficiency for repetitive tasks.
Key Takeaway

Command aliases in Arista EOS provide a simple, imperative way to automate and shorten frequently used command sequences, improving CLI efficiency.

Creating a CLI Alias

configure terminal
alias show_int_brief show interfaces status
end

Explanation: This sequence creates an alias named show_int_brief that, when typed, will execute the command show interfaces status.

Now, typing show_int_brief will execute show interfaces status.
