Basic CLI Scripting: Multi-line Configurations

Executing command sequences from a file.

How it Works

  • Commands are saved in a text file (e.g., .cli extension).
  • File content is piped or pasted into the device's CLI.
  • Ensures consistent application of multiple configuration lines.
  • Still an imperative approach, lacking state awareness.
Key Takeaway

Storing multi-line configurations in script files allows for repeatable execution of complex command sequences, though it remains an imperative approach.

Example: configure_vlan.cli

configure terminal
vlan 20
  name Sales
interface Vlan20
  ip address 192.168.20.1/24
end

Execution: Typically via cat configure_vlan.cli | ssh admin@device_ip from an external machine, or manual paste.

This script configures VLAN 20 and its SVI with a single execution.
