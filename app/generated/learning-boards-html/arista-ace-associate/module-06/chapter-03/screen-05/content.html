Definition

Imperative Configuration

Specifying how to achieve a desired state.

Key Characteristics

  • Command Sequence: Focuses on a precise order of operations.
  • Explicit Steps: Each action is explicitly defined and executed.
  • Traditional CLI: The most common example in network devices.
  • Process-Oriented: Emphasizes the 'how' over the 'what'.
Key Takeaway

Imperative configuration defines the exact sequence of commands to reach a desired network state, similar to following a recipe.

The 'Recipe' Approach

1.

configure terminal

2.

vlan 10

3.

name Engineering

4.

interface Vlan10

5.

ip address 192.168.10.1/24

6.

end

Each command is a distinct step, executed in order to build the desired configuration.
