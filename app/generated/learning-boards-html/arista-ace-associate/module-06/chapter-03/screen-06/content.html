Definition

Declarative Configuration

Specifying what the desired state should be.

Key Characteristics

  • Desired State: Focuses on the end result, not the steps.
  • System Intelligence: Tool determines 'how' to reach the state.
  • State Comparison: Compares desired vs. current state.
  • Modern Automation: Favored by tools like Ansible.
Key Takeaway

Declarative configuration defines the desired end state, allowing automation tools to determine and execute the necessary actions to achieve it.

The 'Desired Meal' Approach

Desired State

"I want VLAN 10 to exist, with IP 192.168.10.1 on its SVI, and Ethernet1 to be a member of it."

Automation Tool Logic

  • Check current VLAN 10 state.
  • If missing, create VLAN 10.
  • Check SVI IP for Vlan10.
  • If incorrect/missing, configure IP.
  • Check Ethernet1 membership.
  • If not in VLAN 10, add it.

The tool intelligently determines and executes only the necessary actions.
