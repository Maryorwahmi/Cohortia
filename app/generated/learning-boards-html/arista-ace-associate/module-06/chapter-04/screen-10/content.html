Testing Connectivity

Verifying eAPI with `curl`

Sending Your First Programmatic Request

`curl` Utility

A command-line tool for making HTTP requests, ideal for testing eAPI connectivity.

Key Flags

`-k` (ignore SSL warnings - lab only), `-u` (username:password), `-d` (JSON-RPC payload).

Payload Structure

The `-d` flag sends a JSON object specifying the `method` (e.g., `runCmds`) and `cmds` array.

`curl` Command Example

Retrieving 'show version' output via eAPI.

curl -k -u <username>:<password> https://<switch_ip>/command-api -d '
{
  "jsonrpc": "2.0",
  "method": "runCmds",
  "params": {
    "format": "json",
    "version": 1,
    "cmds": ["show version"]
  },
  "id": 1
}'
Key Takeaway

Use `curl` with `-k`, `-u`, and `-d` flags to send JSON-RPC payloads and verify eAPI connectivity.
