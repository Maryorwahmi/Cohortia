Introducing Arista eAPI

The Cornerstone of Arista's Programmability

What is eAPI?

Arista's Extensible API provides a robust and secure way to interact with switch configuration and operational state.

How it Works

Uses standard HTTP/HTTPS requests to execute CLI commands, retrieve output, and push configuration changes.

Structured Data

Returns data in a machine-readable JSON format, making it easy for programs to parse and process reliably.

eAPI vs. Screen Scraping

Understanding the key difference for robust automation.

eAPI
  • Structured JSON output
  • Robust & reliable
  • Designed for automation
Screen Scraping
  • Unstructured text output
  • Fragile & error-prone
  • Human-centric
Key Takeaway

eAPI offers a robust, secure, and structured way to interact with Arista switches, replacing fragile CLI screen scraping.
