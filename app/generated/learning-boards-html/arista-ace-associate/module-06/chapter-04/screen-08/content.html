Anatomy of a JSON-RPC Request

Executing CLI Commands Programmatically

`jsonrpc` Field

Specifies the JSON-RPC protocol version, typically "2.0", ensuring client-server compatibility.

`method` Field

Indicates the action to perform, such as `runCmds` for executing CLI commands.

`params` Field

Contains method-specific parameters, including `format` (e.g., "json") and the `cmds` array for CLI commands.

`id` Field

A unique identifier for the request, used to match responses to their corresponding requests.

JSON-RPC Payload Example

Requesting 'show version' output.

{
  "jsonrpc": "2.0",
  "method": "runCmds",
  "params": {
    "format": "json",
    "version": 1,
    "cmds": ["show version"]
  },
  "id": 1
}
Key Takeaway

JSON-RPC requests use `jsonrpc`, `method`, `params` (including `cmds` array), and `id` fields to execute CLI commands.
