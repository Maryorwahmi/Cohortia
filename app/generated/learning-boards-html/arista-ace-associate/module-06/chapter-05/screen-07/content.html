Building Your First Arista EOS Inventory

A practical example of an `inventory.ini` file for defining and connecting to Arista switches.

# inventory.ini

[arista_switches]
veos-1 ansible_host=192.168.0.10 ansible_user=admin ansible_password=arista ansible_network_os=arista.eos.eos
veos-2 ansible_host=192.168.0.11 ansible_user=admin ansible_password=arista ansible_network_os=arista.eos.eos

[all:vars]
ansible_connection=ansible.netcommon.httpapi
ansible_httpapi_use_ssl=True
ansible_httpapi_validate_certs=False # For lab, use proper certs in prod
ansible_httpapi_port=443

Key Inventory Elements

  • •`[arista_switches]` defines a host group.
  • •`veos-1`, `veos-2` are hostnames with specific IPs and credentials.
  • •`ansible_network_os` specifies the Arista EOS collection.
  • •`[all:vars]` sets global connection parameters for eAPI.
Key Takeaway

The inventory file is critical for Ansible to locate and authenticate with your Arista devices, using specific variables to define connection methods and operating systems.

Security Note

`ansible_httpapi_validate_certs=False` is for labs only. In production, always use proper certificate validation for security.
