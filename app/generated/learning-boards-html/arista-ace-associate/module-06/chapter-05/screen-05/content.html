Core Components

Ansible's Building Blocks

Understand the fundamental elements that drive Ansible automation: Inventory, Modules, Playbooks, and Tasks.

1. Inventory: Device List

A file (INI or YAML) listing managed hosts and organizing them into groups. It's Ansible's 'address book' for your network.

2. Modules: Action Units

Reusable code units that execute specific tasks on managed hosts, like configuring a VLAN or running a 'show' command.

3. Playbooks: Automation Scripts

YAML files that define a set of tasks to be executed on specific hosts, describing the desired state of the network.

4. Tasks: Individual Actions

Individual actions within a playbook, typically calling an Ansible module with specific parameters to perform a single step.
