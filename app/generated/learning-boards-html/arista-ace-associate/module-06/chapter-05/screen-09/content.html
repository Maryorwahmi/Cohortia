Playbook Basics

Executing Show Commands with Ansible

Create a simple playbook to retrieve operational data from your Arista switches.

# show_version.yml
---
- name: Get Arista switch version information
  hosts: arista_switches
  gather_facts: false # Not needed for simple command execution
  tasks:
    - name: Run 'show version' command
      arista.eos.eos_command:
        commands:
          - show version
      register: version_output # Store the output in a variable

    - name: Print version output
      debug:
        var: version_output.stdout_lines[0] # Access the first line of the output

Playbook Breakdown

  • •`hosts: arista_switches` targets devices in the inventory group.
  • •`eos_command` module executes `show version`.
  • •`register` saves command output to a variable.
  • •`debug` module prints variable content.
Key Takeaway

Ansible playbooks, combined with `eos_command`, provide an efficient way to retrieve and process operational data from multiple Arista switches simultaneously.

Execution Command

Run with: `ansible-playbook -i inventory.ini show_version.yml`
