Core Concept

Advanced Ping Options

The ping utility verifies basic IP reachability. Advanced options on Arista EOS provide deeper insights into connectivity, especially for complex network setups.

  • •
    source <source_ip>: Specifies the source interface or IP, crucial for asymmetric routing.
  • •
    repeat <count>: Sends multiple pings to observe packet loss over time.
  • •
    interval <seconds>: Sets the delay between successive ping requests.
Key Takeaway

Always consider using advanced `ping` options, especially `source`, to accurately diagnose connectivity from specific network segments or interfaces.

CLI Example: Advanced Ping
# Ping a destination from a specific source interface
ping 192.168.1.10 source Ethernet1

# Ping with 5 repetitions to check for intermittent loss
ping 10.0.0.5 repeat 5

# Ping with a 2-second interval
ping 172.16.0.1 interval 2
Common Mistake

Only using basic `ping` without specifying a source interface can mask issues related to specific routing instances or VLANs, leading to incomplete diagnostics.

Scenario Card

A server is unreachable from VLAN 10 but reachable from VLAN 20. Use `ping source vlan 10` to confirm reachability from the problematic VLAN's SVI.
