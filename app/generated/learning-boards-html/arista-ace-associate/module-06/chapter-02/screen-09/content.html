Steps to Configure Port Mirroring

Setting up a monitor session involves defining the session, specifying sources, and designating a dedicated destination interface.

  • •
    Enter Configuration Mode: configure terminal
  • •
    Define Session: monitor session <session_number> (e.g., monitor session 1)
  • •
    Specify Source: source interface <interface> {ingress | egress | both} or source vlan <vlan_id>
  • •
    Designate Destination: destination interface <interface>
  • •
    Exit Configuration: end
  • •
    Verify: show monitor session <session_number>
Key Takeaway

Always use a dedicated destination interface for `monitor session` and verify its configuration to ensure accurate and safe traffic mirroring.

CLI Example: Monitor Session Configuration
configure terminal
monitor session 1
  source interface Ethernet1 both
  destination interface Ethernet2
end

show monitor session 1
Common Mistake

Mirroring to an interface that is part of a production VLAN, which can lead to network loops or unintended traffic forwarding, causing service disruption.

Pro-Tip

Ensure the monitoring device connected to the destination interface can handle the mirrored traffic volume to prevent packet drops and ensure complete analysis.
