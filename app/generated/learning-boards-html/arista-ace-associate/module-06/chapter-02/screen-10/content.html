Core Concept

Using event-monitor

event-monitor is an Arista EOS utility that displays real-time log messages matching specific patterns or keywords, crucial for observing transient system events.

  • •
    Real-time Logs: See events as they occur, not just from historical logs.
  • •
    Pattern Matching: Specify keywords or regular expressions to filter output.
  • •
    Diagnose Transients: Ideal for catching intermittent interface flaps, routing changes, or other brief events.
Key Takeaway

`event-monitor` provides immediate visibility into system events, making it invaluable for diagnosing intermittent issues that traditional logging might miss.

CLI Example: event-monitor
# Monitor all events related to Ethernet1
event-monitor interface Ethernet1

# Monitor BGP adjacency changes
event-monitor bgp adjacency

# Monitor for specific error messages
event-monitor "Error:"
Common Mistake

Running `event-monitor` without specific filters, leading to an overwhelming amount of log output that makes it difficult to pinpoint relevant information.

Scenario Card

A routing protocol adjacency is intermittently dropping. Use `event-monitor adjacency` to observe real-time state changes and identify the exact timing of the drops.
