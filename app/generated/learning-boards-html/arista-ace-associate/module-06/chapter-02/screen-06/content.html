Definition

What is tcpdump?

tcpdump is a command-line packet analyzer available directly on Arista EOS. It allows you to capture and display network traffic flowing through the switch's CPU or specific interfaces.

  • •
    Direct Capture: Capture traffic without external taps or mirroring.
  • •
    Real-time Analysis: See packets as they traverse the network.
  • •
    Application-Layer Insight: Crucial for diagnosing issues beyond basic IP reachability.
Key Takeaway

`tcpdump` provides direct, on-switch packet-level visibility, essential for deep-dive troubleshooting of application and protocol issues.

CLI Example: Basic tcpdump
# Capture all traffic on Ethernet1
tcpdump interface Ethernet1

# Capture traffic hitting the CPU
tcpdump interface cpu
Analogy Card

Think of `tcpdump` as a high-speed camera that captures every conversation (packet) happening on a specific street (interface), allowing you to review the details later.

Why it Matters

When an application fails but the network seems up, `tcpdump` reveals if packets are being sent, received, or dropped at the switch level, guiding you to the root cause.
