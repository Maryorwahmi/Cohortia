Module 3 › Chapter 3.4 › oc new-app Flow
Command sequence
oc new-app https://github.com/sclorg/nodejs-ex --name=nodejs-app
# Monitor build
oc logs -f bc/nodejs-app
# Monitor rollout
oc rollout status dc/nodejs-app
# Expose route
oc expose svc/nodejs-app
oc get route nodejs-app -o jsonpath='{.spec.host}'
What to watch
  • BuildConfig logs for build success or failure.
  • ImageStream tag update after build completion.
  • DeploymentConfig rollout triggered by imageChange.
  • Create the Route explicitly and validate the application URL.
Common mistake
Assuming new-app leaves nothing to inspect. Instead, open oc describe on created resources to learn triggers and strategies.
