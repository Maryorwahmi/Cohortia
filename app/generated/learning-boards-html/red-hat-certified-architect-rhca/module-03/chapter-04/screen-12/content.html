Module 3 › Chapter 3.4 › Activity: Deploy & Autoscale
Steps
1. Prepare project
oc login --token=<token> --server=<api>
oc new-project my-app-project-deploy
oc project my-app-project-deploy
2. Scaffold app
oc new-app https://github.com/sclorg/nodejs-ex --name=nodejs-app
oc logs -f bc/nodejs-app
oc rollout status dc/nodejs-app
3. Expose and verify
oc expose svc/nodejs-app
oc get route nodejs-app -o jsonpath='{.spec.host}'
4. Configure HPA
oc autoscale dc/nodejs-app --min 1 --max 5 --cpu-percent 50
# Generate load in another terminal to observe scaling
Reflection
If a schema change requires recreate, modify the DeploymentConfig strategy, plan downtime, and ensure backups before applying.
