Module 3 › Chapter 3.4 › Horizontal Pod Autoscaler
Configure HPA
oc autoscale dc/my-webapp --min 2 --max 10 --cpu-percent 80
# Verify
oc get hpa
oc get pods -w
Practical checklist
  • Ensure resource requests are set so CPU percent is meaningful.
  • Generate load (hey or apachebench) in staging to observe scaling behaviour.
  • Monitor oc get hpa and oc get pods -w for replica changes.
Warning
HPA is reactive. It will not protect against unbounded resource spikes instantly—use limits and graceful degradation strategies.
