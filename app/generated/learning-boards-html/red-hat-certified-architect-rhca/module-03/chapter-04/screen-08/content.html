Module 3 › Chapter 3.4 › ImageStreams & BuildConfigs
Pipeline architecture
ImageStream
A named, tag-tracked reference to images. It hides registry details and can track external or internal images.
BuildConfig
Defines how to build images from source using S2I, Dockerfile, or custom strategies.
Example commands
oc new-build --name=my-nodejs-app --binary --strategy=source --image-stream=nodejs:latest
# Or from Git:
oc new-app https://github.com/sclorg/nodejs-ex --name=nodejs-example
Practical notes
  • ImageStream tag updates can trigger DeploymentConfig rollouts.
  • S2I simplifies builds by injecting source into a builder image.
  • Ensure BuildConfig uses trusted base images and vulnerability scanning.
Try this
Run oc new-app from a repo, watch bc logs, then oc get is to see the new tag and oc rollout status to observe the DeploymentConfig rollout.
