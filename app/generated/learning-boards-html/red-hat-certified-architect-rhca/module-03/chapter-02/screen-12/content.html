Module 3 › Chapter 3.2 › Common Pitfalls
Top pitfalls
Under-provisioned control plane: leads to slow reconciliation and operator failures.
DNS inconsistency: split-horizon or stale records break bootstrapping.
Firewall blocking: required ports must be open between nodes and external services.
Never expose etcd to public networks; limit its access to control plane segments only.
Mitigations
Validate sizing
Check CPU, RAM, and I/O on control plane templates before provisioning.
DNS & firewall tests
Run DNS resolutions and port checks from bootstrap and node images to verify connectivity.
Artifact retention
Store install-config, ignition files, and kubeconfig securely and version them.
Key Takeaway
Address sizing, DNS, firewall, and artifact retention proactively. Small validation steps prevent long debugging sessions later.
Quick checklist
Sizing OK, DNS consistent, ports open, artifacts archived, etcd isolated.
