Module 3 › Chapter 3.2 › openshift-install & Validation
Installer steps
Generate and inspect before applying. Archive outputs for recovery.
Example commands
# generate install-config and ignition
openshift-install create install-config
openshift-install create manifests
openshift-install create ignition-configs

# run the install
openshift-install create cluster
Validation commands
Use oc to check operators, nodes, and storage.
# login with generated kubeconfig
oc login --token=<your_token> --server=<api_url>

# operator and node checks
oc get clusteroperators
oc get nodes
oc get sc
Misconception
Assuming installer success equals cluster readiness. Operators may still reconcile after bootstrap finishes.
Key Takeaway
Archive installer artifacts and validate cluster health with oc get clusteroperators and node readiness checks before declaring the cluster ready.
Try this
After installation, list clusteroperators and note any in Degraded or Progressing for follow-up.
