Module 3 › Chapter 3.2 › Verification Tasks
Install method checklist
  • Confirm cloud APIs and automation for IPI; if absent, plan for UPI.
  • Record existing load balancer and network constraints that require manual configuration.
  • Decide on automation versus control trade-offs and document the rationale.
Pre-install validation
  • DNS resolves api and cluster names; firewall allows required ports.
  • RHCOS images are available and node templates meet sizing guidance.
  • Back up install-config.yaml and plan where kubeconfig will be stored.
Post-install checks
  • Identity provider responds and users can authenticate.
  • Default storage class exists and is tested by a sample PVC.
  • Review SCCs to ensure workloads run with least privilege.
Day 2 readiness
  • Update channel chosen and maintenance windows scheduled.
  • Monitoring is scraping control plane and application metrics.
  • Etcd backup frequency defined and recovery playbook available.
