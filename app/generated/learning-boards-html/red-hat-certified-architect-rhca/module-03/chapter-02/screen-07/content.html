Module 3 › Chapter 3.2 › Networking & DNS
Port & DNS matrix
Confirm these traffic flows before installation.
API server
TCP 6443 reachable by installer, bootstrap, and control plane nodes.
Router / ingress
TCP 80 and 443 exposed to external clients and configured on the router load balancer.
Etcd and node comms
Control plane nodes must reach etcd endpoints and each other without restrictive filtering.
Checks & examples
DNS consistency check
Resolve the API name from multiple subnets and compare answers; inconsistent results indicate split-horizon DNS issues.
Danger sign
Bootstrap stalls or ClusterOperators stuck in Progressing often point to networking or DNS problems.
Simple test
Use telnet or curl to the API and router ports from bootstrap and a prepared node to confirm reachability.
Key Takeaway
Validate DNS resolution across your network and ensure the API, router, and etcd ports are open between required endpoints before bootstrapping.
Check yourself
Have you validated API and ingress names from every network segment you will use?
