Module 3 › Chapter 3.2 › IPI vs UPI
Definition
Installer-Provisioned Infrastructure (IPI)
Installer automates VM, networking, and LB provisioning on supported clouds.
When to use
Supported public cloud, permissioned automation, minimal manual networking.
Benefits
Fewer manual steps, consistent environment, faster bootstrap.
Misconception
Automation removes governance needs; in reality policies still matter.
Definition
User-Provisioned Infrastructure (UPI)
Administrator prepares infrastructure then runs the installer against it.
When to use
Bare metal, custom load balancers, strict networking policies.
Benefits
Control over infrastructure components and integration points.
Pro tip
Document manual steps and version the provisioning scripts for repeatability.
Key takeaway
Choose IPI when cloud automation is supported; choose UPI when you need pre-existing network, storage, or load balancer control.
Example
On AWS with permissions you typically use IPI. In an on-prem datacenter with custom load balancers use UPI.
