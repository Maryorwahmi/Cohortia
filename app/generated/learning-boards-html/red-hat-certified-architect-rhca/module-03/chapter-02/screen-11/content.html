Module 3 › Chapter 3.2 › Security Context Constraints
What SCCs control
User IDs, capabilities, host access, and volume types at the pod level.
Restricted SCC
Default secure policy applied to most workloads; test here first.
Custom SCCs
Create minimal exceptions and bind them to specific service accounts.
Checks & commands
Inspect SCCs
oc get scc
oc describe scc restricted
Risk
Overly permissive SCCs can allow host filesystem access or root execution in containers, increasing attack surface.
Key Takeaway
Review SCCs immediately after install, prefer default restrictiveness, and only create scoped exceptions with documented justification.
