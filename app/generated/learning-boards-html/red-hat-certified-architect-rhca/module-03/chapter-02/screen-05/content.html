Module 3 › Chapter 3.2 › Pre-install Checklist
Checklist
  1. Topology: Record control plane and worker counts and etcd placement.
  2. Sizing: Confirm CPU, memory, and I/O meet Red Hat guidance.
  3. DNS: Ensure API and ingress names resolve and are consistent.
  4. Networking: Validate firewall rules and required ports are open.
  5. RHCOS: Prepare node images or templates and check boot behavior.
  6. Storage: Identify storage classes and dynamic provisioners available.
Examples & Checks
DNS check
Resolve api.cluster.example.com and verify the IP matches your API load balancer.
Command example
dig +short api.cluster.example.com
curl -k https://api.cluster.example.com:6443/healthz
Common mistake
Skipping firewall verification and assuming node-to-node communication works by default.
Key Takeaway

Run and document a short set of checks for topology, DNS, networking, RHCOS, and storage before invoking the installer to avoid avoidable failures.

Why it matters
Early validation reduces install friction and ensures production readiness from day one.
