Module 3 › Chapter 3.2 › Identity Providers
Supported providers
Common choices: LDAP, OpenID Connect, HTPasswd for test environments.
LDAP
Good for enterprises with an existing directory; supports group mapping for RBAC.
OpenID Connect
Works with modern identity providers and SSO flows.
HTPasswd
Simple file-based option for testing; not recommended for production.
Checks & mistakes
Validate provider reachability, TLS, and account mapping before granting cluster roles.
Common mistake
Granting cluster-admin too early; instead map groups to minimal roles and expand as needed.
Validation command
oc get oauth cluster -o yaml | grep -A 5 'identityProviders:'
Key Takeaway
Configure identity providers early, verify connectivity and TLS, and apply least-privilege RBAC mappings to control access.
