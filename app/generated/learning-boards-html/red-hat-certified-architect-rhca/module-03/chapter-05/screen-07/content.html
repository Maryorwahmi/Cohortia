StorageClass structure
Defines a provisioner, its parameters, and policies for dynamic PV creation.
Important fields: provisioner, parameters, reclaimPolicy, volumeBindingMode, allowVolumeExpansion.
Operational note: If a default StorageClass exists you can omit storageClassName in a PVC and the default will be used.
Example StorageClass (AWS EBS)
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: gp2-ssd
provisioner: kubernetes.io/aws-ebs
parameters:
  type: gp2
  fsType: ext4
reclaimPolicy: Delete
volumeBindingMode: Immediate
allowVolumeExpansion: true
Key Takeaway

StorageClasses drive dynamic provisioning. Confirm reclaimPolicy matches your data safety needs before using Delete.
