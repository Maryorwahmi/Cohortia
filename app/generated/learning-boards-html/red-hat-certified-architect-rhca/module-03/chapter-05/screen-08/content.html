Access Modes
Define how volumes can be mounted across nodes and pods.
ReadWriteOnce: single node read-write. Typical for block storage.
ReadOnlyMany: multiple nodes can read concurrently.
ReadWriteMany: multiple nodes can read and write concurrently; requires shared file systems like NFS or CephFS.
Scenario
If your application is a clustered file share with pods on different nodes that write to the same files, choose ReadWriteMany and a provider that supports it; block volumes will not work.
Pitfall

Using ReadWriteOnce on multiple pods on different nodes causes mount errors at runtime.

Key Takeaway

Match access modes to both app concurrency needs and the storage backend’s capabilities.
