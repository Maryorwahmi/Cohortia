Concept overview
Persistent Volume (PV)
Cluster-scoped storage resource representing real storage.
Persistent Volume Claim (PVC)
Namespace-scoped request that binds to a matching PV.
StorageClass
Blueprint used for dynamic provisioning by a provisioner.
Quick tip
When you need multi-node read-write access, prefer shared file systems like NFS or CephFS; block devices typically restrict you to one node.
