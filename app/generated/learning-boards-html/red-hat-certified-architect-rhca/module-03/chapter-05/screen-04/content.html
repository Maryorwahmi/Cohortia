Persistent Volume (PV)
Cluster-scoped resource representing provisioned storage.
Key attributes:
  • Capacity (for example, 10Gi, 100Gi)
  • Access modes: ReadWriteOnce, ReadOnlyMany, ReadWriteMany
  • Underlying storage type: NFS, Ceph, cloud disks, iSCSI
Common misconception
A PV is not directly edited by applications. It's a resource mapping to storage handled by admins or provisioners.
Example PV (NFS)
<apiVersion: v1>
<kind: PersistentVolume>
<metadata:
  name: nfs-pv>
<spec:
  capacity:
    storage: 100Gi
  accessModes:
    - ReadWriteMany
  nfs:
    path: /exports/data
    server: 10.0.0.5
  persistentVolumeReclaimPolicy: Retain
>
Key Takeaway

PVs declare storage availability and characteristics at the cluster level and are bound to namespace-scoped PVCs.
