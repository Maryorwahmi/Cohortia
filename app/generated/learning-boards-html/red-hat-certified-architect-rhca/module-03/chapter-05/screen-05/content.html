Persistent Volume Claim
A namespace-scoped request for storage.
Lifecycle and checks:
  • Pending: waiting for matching PV or provisioner
  • Bound: claim matched to a PV and ready to mount
  • Lost: the bound PV is unavailable or deleted
Checks to run when Pending:
  • oc get pvc <name> -n project to check status
  • oc describe pvc to view events and StorageClass reference
  • oc get sc to confirm StorageClass exists and its provisioner is healthy
Example PVC
<apiVersion: v1>
<kind: PersistentVolumeClaim>
<metadata:
  name: my-app-pvc>
<spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 10Gi
  storageClassName: gp2-ssd
>
Key Takeaway

PVCs are how applications request storage. Use describe and get commands to diagnose binding problems.
