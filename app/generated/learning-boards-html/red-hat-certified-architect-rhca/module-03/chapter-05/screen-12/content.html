Module 3›Chapter 3.5›Verify & Troubleshoot
Verify persistence
Write a file, delete the pod, and confirm the file remains after recreation.
Common commands:
  • oc get pvc <name> -n project
  • oc describe pvc <name> -n project
  • oc get sc and oc describe sc <name>
Troubleshooting checklist
If Pending: check StorageClass exists, provisioner health, backend capacity, and PVC events shown by describe.
Common mistake
Using Delete reclaimPolicy for critical data without backups may remove data unintentionally.
Key Takeaway
Confirm Bound status and the storage backend health before trusting a volume for production data.
