Nginx deployment manifest
A deployment that mounts a PVC into /opt/app-root/src/data.
Apply the manifest, then use oc exec to write and verify files in the mounted path.
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-data-writer
  labels:
    app: nginx-data-writer
spec:
  replicas: 1
  selector:
    matchLabels:
      app: nginx-data-writer
  template:
    metadata:
      labels:
        app: nginx-data-writer
    spec:
      containers:
      - name: nginx
        image: registry.access.redhat.com/ubi8/nginx-120
        ports:
        - containerPort: 8080
        volumeMounts:
        - name: nginx-persistent-storage
          mountPath: /opt/app-root/src/data
      volumes:
      - name: nginx-persistent-storage
        persistentVolumeClaim:
          claimName: my-data-pvc
Key Takeaway
Ensure claimName matches the PVC and that the PVC status is Bound before relying on the mounted storage.
