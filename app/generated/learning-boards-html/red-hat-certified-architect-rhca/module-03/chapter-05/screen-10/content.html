Module 3›Chapter 3.5›Create PVC & Deploy
Step-by-step
Follow these steps to provision and validate.
  1. Check storage classes: oc get sc
  2. Create PVC manifest and apply: oc apply -f my-pvc.yaml
  3. Confirm PVC is Bound: oc get pvc my-data-pvc
  4. Deploy Nginx with the PVC mounted and write data, then delete pod to confirm persistence.
Example verification
Get pod name, exec to write file, delete pod, and exec again to verify file persists.
PVC manifest
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: my-data-pvc
spec:
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 1Gi
  storageClassName: standard
Pro tip
If a PVC stays Pending, run oc describe pvc to view events and check the StorageClass and provisioner health.
