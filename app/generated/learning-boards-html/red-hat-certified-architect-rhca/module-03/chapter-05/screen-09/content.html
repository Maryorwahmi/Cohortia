Common Providers
Choose based on access modes and operational needs.
NFS
ReadWriteMany, simple shared file system, requires external server.
OpenShift Data Foundation (Ceph)
Provides block, file, object storage. Enterprise-grade HA and scalability.
Cloud Provider Disks
AWS EBS, Azure Disk, GCE PD: dynamic provisioning, usually ReadWriteOnce.
iSCSI / Fibre Channel
Traditional block storage on-premise; commonly statically provisioned for performance-sensitive workloads.
Choosing a provider
Match access mode, durability, encryption, backup, and HA requirements to provider capabilities.
Operational tip
Encrypt volumes for sensitive data and include backup strategies for disaster recovery.
Warning
If your app needs concurrent writes but the StorageClass only provisions block volumes, you will get runtime mount errors.
