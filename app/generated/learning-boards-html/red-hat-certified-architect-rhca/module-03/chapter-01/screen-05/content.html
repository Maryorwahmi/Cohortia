Architecture overview
Control plane services and responsibilities
kube-apiserver
Exposes the API and validates requests. All changes flow through the API server and into etcd.
etcd
Distributed key-value store containing the cluster's desired and current state. Quorum is vital for consistency.
kube-scheduler & controller-manager
Scheduler assigns pods to nodes; controllers reconcile resources to the desired state.
OpenShift control extensions
OpenShift API server extends Kubernetes API with resources like DeploymentConfig and ImageStream.
OpenShift Controller Manager reconciles OpenShift custom resources and coordinates integrated services like Router and Registry.
Common mistake

Underestimating etcd: small clusters with a single etcd member risk quorum loss. Always plan for >1 member and backups.
