Module 3 › Chapter 3.1 › etcd & API server
Definition and role
Etcd is the authoritative store; API server is the REST front-end
Example: Creating a Deployment writes its desired state to etcd via the API server. Controllers read that state and act to match it.
Operational checks: etcd member status, API server connectivity, and latency metrics affect cluster responsiveness.
Misconception

Treating etcd like any application store can lead to insufficient redundancy. Always plan for quorum and backups.

Quick checks
  • Verify etcd member list and health.
  • Ensure API server can reach etcd endpoints.
  • Keep regular etcd backups for recovery.
Key Takeaway

Protect etcd and verify API server connectivity to maintain cluster state and enable safe operations.
