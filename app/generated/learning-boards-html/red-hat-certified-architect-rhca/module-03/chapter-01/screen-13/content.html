Protecting etcd
Run an odd number of etcd members for quorum, monitor member health, and perform regular backups. Restore procedures must be tested before production incidents occur.
Example: With three etcd members, the cluster can tolerate one failure while preserving quorum; with a single member, any failure blocks writes.
Misconception: Adding worker nodes does not protect the control plane. HA requires multiple control plane nodes and replicated etcd members.
Operational checklist
  • Deploy multiple control plane nodes with replicated etcd members.
  • Monitor etcd health and API server latency.
  • Take regular etcd backups and test restores.
Key Takeaway

High availability requires planning for control plane redundancy, etcd quorum, and tested backup and restore procedures to avoid catastrophic outages.
