Module 3 › Chapter 3.1 › OpenShift SDN Modes
Mode cards
ovs-subnet (flat)
Simple, all pods can communicate across projects. Use when isolation is not required.
ovs-multitenant
Provides project isolation by default; reduces cross-project traffic and blast radius.
ovs-networkpolicy
Implements Kubernetes NetworkPolicy semantics for policy-driven enforcement across pods.
Example scenario
A multi-team cluster that shares the control plane should use ovs-multitenant to keep team projects isolated by default. If teams require fine-grained access, combine ovs-networkpolicy with explicit policies to allow only required traffic.
Pro tip

Test connectivity and policies in a staging environment before changing SDN mode in production, since it affects many workloads.
