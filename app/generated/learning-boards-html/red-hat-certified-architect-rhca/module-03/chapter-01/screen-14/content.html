Module 3 › Chapter 3.1 › Key Concepts
Control Plane
Hosts API server, controllers, scheduler, and etcd; its health and quorum are essential.
Worker Nodes
Run pods via kubelet and CRI-O; kube-proxy enforces Service networking rules.
Platform Services
Image Registry, Router, SDN, and Operators provide integrated capabilities beyond Kubernetes core.
Summary Takeaway

Map symptoms to components: image issues → registry; unreachable from outside → route/router; state changes failing → etcd/API server.
