Architecture › Fluentd flow
Log flow
Container stdout/stderr and node journals → Fluentd (DaemonSet) → Elasticsearch indices → Kibana search and dashboards.
Node-local Fluentd tails node logs and enriches them with metadata.
Fluentd forwards to Elasticsearch; indices make queries fast and support aggregations.
Kibana provides search, filters, and visualizations for incident investigation.
Operational considerations
  • Configure Fluentd buffering and retry to handle Elasticsearch outages.
  • Plan index lifecycle and retention to control storage use.
  • Monitor Fluentd and Elasticsearch health via Prometheus metrics and dashboards.
