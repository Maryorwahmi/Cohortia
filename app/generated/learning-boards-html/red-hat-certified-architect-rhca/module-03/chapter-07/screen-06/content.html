Example Service annotation
Apply an annotation so Prometheus scrapes the application endpoint.
apiVersion: v1
kind: Service
metadata:
  name: myapp
  annotations:
    prometheus.io/scrape: "true"
    prometheus.io/port: "8080"
spec:
  selector:
    app: myapp
  ports:
  - name: http
    port: 8080
    targetPort: 8080
Notes: ensure the container serves /metrics on the annotated port and labels match the Service selector.
Verification steps
  1. Confirm Service and Pod labels match.
  2. Check Prometheus targets for the new endpoint.
  3. Open Grafana and query the metric name to validate presence.
Pitfall

If metrics are missing, confirm the container is actually listening and not blocked by network policies.
