Definition › Pod states
Common pod conditions
  • CrashLoopBackOff: application exits repeatedly — check oc logs and the container command.
  • ImagePullBackOff: registry or ImageStream errors — verify image name and access.
  • Pending: scheduling constraints, taints, or PVC binding issues.
  • Evicted: node resource pressure; inspect node conditions.
Example commands
oc describe pod <pod-name> -n <project>
oc logs <pod-name> -n <project>
oc exec <pod-name> -- /bin/sh -c 'env && ps aux'
