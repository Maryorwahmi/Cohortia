Core Concept › Prometheus & Grafana
Prometheus: metrics and alerts
A pull-based time-series system that scrapes exporters and evaluates alerting rules.
  • Collects node and container metrics via exporters like kube-state-metrics and cAdvisor.
  • Stores sampled data as time series for trend analysis and alerting.
  • Integrates with Alertmanager to route alerts to responders.
Common misconception

Grafana is not a collector. If metrics are missing, check Prometheus scrape targets, not Grafana settings.

Grafana: dashboards and exploration
A visualization platform that queries Prometheus to render dashboards and panels for troubleshooting.
Example: node CPU trend and pod restart overlay help find correlation between deployments and CPU spikes.
Key takeaway

Use Prometheus for data and rules, Grafana to interpret results and guide remediation.
