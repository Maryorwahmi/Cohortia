Core Concept › EFK Stack
Fluentd — collector and forwarder
DaemonSet on each node collecting container logs, system logs, and audit trails and forwarding them to Elasticsearch.
Fluentd ensures logs are normalized and labeled so they are searchable in Kibana.
Elasticsearch + Kibana
Elasticsearch stores, indexes, and enables fast search and aggregations. Kibana provides the query and visualization surface.
Operational note

Plan index lifecycle and retention to avoid running out of storage in Elasticsearch; prune or archive old indices as needed.
