Process Flow › oc toolkit
Common commands and examples
oc describe pod <pod-name> -n <project>
oc logs -f <pod-name> -n <project>
oc exec <pod-name> -- curl -s http://backend.svc.cluster.local:8080
oc debug node/<node-name>
oc adm must-gather --image=<must-gather-image>
Use -f to follow logs and -p to fetch previous logs after a restart. Must-gather packages the evidence for support cases.
Checklist for incidents
  • Gather oc describe and oc logs outputs.
  • Try oc exec to reproduce the error within the container environment.
  • If host-level, use oc debug node and collect must-gather archive before making changes.
