Module 4 › Chapter 3.7 › Applied Objectives
01
Expose application metrics
Learn the annotation pattern to enable scraping and test endpoints so Prometheus collects meaningful application metrics for alerting and SLOs.
VERIFIED COMPETENCY MILESTONE
02
Centralize logs and manage retention
Configure ClusterLogging and sizing to prevent Elasticsearch storage exhaustion; know when to prune indices and archive older logs.
VERIFIED COMPETENCY MILESTONE
03
Follow a diagnostic workflow
Use oc describe and oc logs as first steps, then oc exec and oc debug for deeper inspection, reserving node changes until you identify host-level issues.
VERIFIED COMPETENCY MILESTONE
04
Manage alerts and incidents
Design alerting thresholds that are actionable and route them through Alertmanager to the right responders to avoid alert fatigue.
VERIFIED COMPETENCY MILESTONE
