Code Walkthrough › Failing deployment
failing-app.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: failing-webapp
spec:
  replicas: 1
  selector:
    matchLabels:
      app: failing-webapp
  template:
    metadata:
      labels:
        app: failing-webapp
    spec:
      containers:
      - name: failing-container
        image: registry.access.redhat.com/ubi8/nodejs-16
        command: ["sh", "-c", "echo 'Simulating a crash...' && exit 1"]
        ports:
        - containerPort: 8080
        resources:
          limits:
            memory: "128Mi"
            cpu: "100m"
Recovery commands
oc get pods -n troubleshooting-project
POD_NAME=$(oc get pod -l app=failing-webapp -o jsonpath='{.items[0].metadata.name}' -n troubleshooting-project)
oc describe pod $POD_NAME -n troubleshooting-project
oc logs $POD_NAME -n troubleshooting-project
oc set image deployment/failing-webapp failing-container=registry.access.redhat.com/ubi8/nginx-120 -n troubleshooting-project
oc patch deployment failing-webapp --type='json' -p='[{"op":"remove","path":"/spec/template/spec/containers/0/command"}]' -n troubleshooting-project
After patching, verify the pod becomes Running and check logs and dashboards for normal behavior.
