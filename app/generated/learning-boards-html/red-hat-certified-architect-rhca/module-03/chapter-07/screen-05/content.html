Exporter roles
Each exporter converts cluster or host state into metrics Prometheus can scrape.
kube-state-metrics — object state for pods, deployments, services.
node-exporter — host-level CPU, memory, disk, network.
cAdvisor — container resource usage and live stats.
Checklist:
  • Are exporter pods running?
  • Does Prometheus list the expected scrape targets?
  • Does the app expose /metrics and use stable labels?
Common pitfall
High-cardinality labels from application metrics can overload Prometheus storage or cause slow queries — prefer stable, low-cardinality labels.
Example

Annotate a Service with prometheus.io/scrape=true to expose an application endpoint for scraping by Prometheus.
