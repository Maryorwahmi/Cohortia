Terminal actions
Run these commands to deploy and verify connectivity.
# create project and deploy
oc login --token=<your_token> --server=<your_api_url>
oc new-project network-test-project
oc apply -f frontend-deployment.yaml -f frontend-service.yaml -f backend-deployment.yaml -f backend-service.yaml -n network-test-project

# verify connectivity from frontend pod
FRONTEND_POD=$(oc get pod -l app=frontend -o jsonpath='{.items[0].metadata.name}' -n network-test-project)
oc exec $FRONTEND_POD -n network-test-project -- curl -s http://backend-service.network-test-project.svc.cluster.local:8080
Apply deny-all
# backend-network-policy.yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: deny-all-to-backend
  namespace: network-test-project
spec:
  podSelector:
    matchLabels:
      app: backend
  policyTypes:
    - Ingress
  ingress: []
Observations and checks
  • Before policy: curl returns Nginx HTML.
  • After deny-all: curl times out or returns connection error.
  • After allowing frontend selector: connectivity returns.
Common pitfall
Don't forget to permit DNS and cluster services if your workload depends on them; otherwise you may block necessary system traffic.
