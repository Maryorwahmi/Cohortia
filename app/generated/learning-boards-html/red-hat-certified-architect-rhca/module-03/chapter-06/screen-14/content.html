Module 3 › Chapter 3.6 › Key Concepts
OpenShift SDN
Provides pod networking and determines default isolation semantics.
Routes vs Ingress
Routes are OpenShift-native; Ingress is Kubernetes-standard — pick based on tooling and features.
NetworkPolicy & Egress
Use NetworkPolicy for zero-trust; use Egress IP or Router to present a fixed outbound IP.
Summary Takeaway

Choose SDN mode for isolation, expose services with Routes or Ingress as appropriate, and enforce least-privilege traffic using NetworkPolicy; pick Egress IP or Router when a fixed outbound address is required.
