Module 3 › Chapter 3.6 › Egress Strategies
Egress Router
Traffic originates from pods in a project and is routed through a designated router pod which can have a specific IP.
Use when you need granular control over outbound processing, logging, or when source IP isn't easily assigned by the cluster network.
Egress IP
Assigns a static source IP to pods or a project; outbound traffic is SNATed to that IP by the cluster network.
Simpler for firewall scenarios where only a fixed source IP is required and the cluster supports egress IPs on nodes.
Example commands (simulation)
# annotate namespace to assign egress IPs (example)
oc patch namespace network-test-project -p '{"metadata": {"annotations": {"network.openshift.io/assign-egress-ips": "true"}}}' --type=merge
# or add egress IP (cluster-admin action)
oc adm egress-ip add-ip 192.168.1.100 --selector=app=frontend -n network-test-project
