Module 3 › Chapter 3.6 › Learning Objectives
Objectives mapped to lab steps
Each objective below includes a lab action and an assessment hint.
SDN modes
Lab: query current SDN mode and argue if it fits multi-tenant needs. Assessment: explain a risk of ovs-subnet.
Routes & Ingress
Lab: create a Route with TLS edge termination and curl the hostname. Assessment: pick termination for compliance.
NetworkPolicy
Lab: apply deny-all to backend then allow frontend selector; test with curl. Assessment: write a namespace-scoped rule.
Egress
Lab: simulate assigning an Egress IP and confirm source IP. Assessment: choose Egress IP vs Router for a firewalled endpoint.
Tip: keep a staging project to run these tests safely and always verify policy impact using pod-level curl checks and service cluster IP lookups.
