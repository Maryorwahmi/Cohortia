Allow frontend → backend (YAML)
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: allow-frontend-to-backend
  namespace: network-test-project
spec:
  podSelector:
    matchLabels:
      app: backend
  policyTypes:
    - Ingress
  ingress:
    - from:
      - podSelector:
          matchLabels:
            app: frontend
      ports:
        - protocol: TCP
          port: 8080
Apply this policy with oc apply -f and then re-run the curl from the frontend pod to confirm the response is restored.
Verification
# get frontend pod
FRONTEND_POD=$(oc get pod -l app=frontend -o jsonpath='{.items[0].metadata.name}' -n network-test-project)
# test
oc exec $FRONTEND_POD -n network-test-project -- curl -s http://backend-service.network-test-project.svc.cluster.local:8080
Key Takeaway
Apply minimal allow rules and iterate. Always confirm DNS, health checks, and monitoring traffic remain accessible after changes.
