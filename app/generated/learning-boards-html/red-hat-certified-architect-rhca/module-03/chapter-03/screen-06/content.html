RBAC primitives
  • Role: namespace-scoped permission set.
  • ClusterRole: cluster-scoped permission set.
  • RoleBinding: grants a Role or ClusterRole to a subject within a namespace.
  • ClusterRoleBinding: grants a ClusterRole cluster-wide.
Command example
oc policy add-role-to-user edit jane.doe -n my-dev-project
oc policy remove-role-from-user edit jane.doe -n my-dev-project
oc policy add-role-to-group admin dev-team -n my-dev-project
These policy commands create or remove RoleBindings for the given subject.
Misconceptions and guidance
  • Misconception: ClusterRoleBindings are just easier. Guidance: avoid cluster-wide bindings unless necessary.
  • Misconception: default roles are always sufficient. Guidance: review predefined roles and create custom Roles for specific needs.
