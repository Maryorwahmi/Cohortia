Module 3 › Chapter 3.3 › Assessment & Reflection
Sample question
A team needs full control in frontend-dev but must not manage roles or affect other projects. Which ClusterRole and binding do you use?
Answer: Bind the edit ClusterRole using a RoleBinding scoped to frontend-dev.
Practical task
Create my-app-project, add a dev user, grant edit, create a service account with read-only Role, deploy a pod using it, and demonstrate allowed and forbidden actions.
Reflection

When you design access, name the actor, the actions required, and the smallest scope that satisfies the need. This method prevents accidental privilege escalation.
