Terminal sequence
# As cluster admin
oc login -u system:admin
oc new-project my-app-project --display-name="My Application Development"

# Create test user and group (if using HTPasswd or oc adm)
oc adm create-user devuser --full-name="Developer User"
oc adm create-group dev-team
oc adm add-user-to-group dev-team devuser

# Grant edit role
oc policy add-role-to-user edit devuser -n my-app-project
# Or bind group to admin if owners need role management
oc policy add-role-to-group admin dev-team -n my-app-project
After granting roles, test by logging in as devuser and confirming expected access.
Service account steps
oc create serviceaccount app-reader-sa -n my-app-project
# apply Role and RoleBinding YAML from earlier
oc apply -f app-reader-role.yaml -n my-app-project
oc apply -f app-reader-rolebinding.yaml -n my-app-project
Update your Deployment to use serviceAccountName: app-reader-sa and redeploy to test behavior.
Validation

As the developer, oc get nodes should be forbidden; oc get pods -n my-app-project should succeed. Test both success and failure cases.
