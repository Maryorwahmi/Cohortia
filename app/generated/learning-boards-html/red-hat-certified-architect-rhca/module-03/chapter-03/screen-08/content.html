Module 3 › Chapter 3.3 › Built-in ClusterRoles
admin
Full control in a project, including role management. Use for project owners who manage members and quotas.
edit
Read/write for most resources but cannot manage roles. Ideal for developers and CI pipelines.
view
Read-only access for dashboards, auditors, or external review tools.
cluster-admin
Super-user access across the cluster. Only assign to trusted administrators and automation that truly needs cluster-wide privileges.
