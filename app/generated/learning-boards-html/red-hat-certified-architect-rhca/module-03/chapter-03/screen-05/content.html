Module 3 › Chapter 3.3 › Create, Inspect, and Delete Projects
Typical commands
oc new-project my-dev-project --display-name="My Development Project" --description="Project for the development team"
oc project my-dev-project
oc get projects
oc describe project my-dev-project
oc delete project my-dev-project
Run oc project to switch your current namespace and reduce risk of operating in the wrong project.
Safety checklist before deletion
  • List resources: oc get all -n <project>, oc get pvc -n <project>.
  • Export manifests for important objects and backups for persistent data.
  • Check for finalizers and long-running build or operator tasks that may block deletion.
Common pitfalls
  • Assuming deletion is instant; verify project status and look for blocked finalizers.
  • Failing to confirm context — an oc delete in the wrong project can be catastrophic.
Pro tip

Use descriptive display names and descriptions when creating projects to ease future audits and ownership tracking.
