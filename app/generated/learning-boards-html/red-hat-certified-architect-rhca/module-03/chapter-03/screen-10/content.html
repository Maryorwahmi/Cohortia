Module 3 › Chapter 3.3 › Least Privilege & Audits
Practical checklist
  • Prefer Role + RoleBinding scoped to a project whenever possible.
  • Use edit for deployers, view for observers, and custom Roles for narrow needs.
  • Audit: oc get rolebindings -n <project> and oc get clusterrolebindings.
Common mistakes
  • Granting cluster-admin to automation that only needs namespace access.
  • Using default service accounts for production workloads.
  • Allowing self-provisioner broadly without governance.
Warning

ClusterRoleBindings are powerful. Review them frequently and restrict who can create them.
