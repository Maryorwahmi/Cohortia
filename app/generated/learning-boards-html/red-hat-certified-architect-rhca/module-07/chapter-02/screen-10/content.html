Module 7 › Chapter 7.2 › qcow2 versus raw disk images
qcow2

Features

  • Supports snapshots, cloning, encryption, and thin provisioning.
  • Operationally flexible for backups and test/dev workflows.
raw

Features

  • Simple block image with minimal overhead.
  • Can provide slightly higher performance for heavy I/O cases.
Create qcow2 example
sudo qemu-img create -f qcow2 /var/lib/libvirt/images/myfirstvm.qcow2 30G
ls -lh /var/lib/libvirt/images/myfirstvm.qcow2
Note that the file will appear small initially because qcow2 is thin-provisioned; its actual disk usage grows as the VM writes data.
