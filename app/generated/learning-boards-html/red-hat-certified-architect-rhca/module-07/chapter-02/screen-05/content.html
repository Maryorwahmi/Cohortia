Module 7 › Chapter 7.2 › Managing libvirtd and VM lifecycle
Step 1
Enable and start libvirtd
Ensure libvirtd is enabled and running so guests can be managed after reboots.
sudo systemctl enable --now libvirtd
sudo systemctl status libvirtd
Step 2
Controller operations
Use virsh to list, start, stop, and make guests autostart.
virsh list --all
virsh start myvm
virsh autostart myvm
Step 3
Monitoring and logs
Check the daemon logs for errors that affect VM lifecycle and respond to SELinux denials or missing files.
sudo journalctl -u libvirtd -n 200
sudo ausearch -m avc -ts recent
Pro tip
Combine autostart with health checks: after enabling autostart, run a short boot test to ensure the VM reaches expected state after reboot.
