Module 7 › Chapter 7.2 › SELinux contexts and libvirt
Why it matters

SELinux prevents unauthorized processes from reading or writing VM images. libvirtd requires the svirt_image_t type to access disk files.

ls -Z /var/lib/libvirt/images
sudo chcon -Rv -t svirt_image_t /data/kvm_images/myvm.qcow2
Diagnostic steps
  • Check /var/log/audit/audit.log for AVC denials.
  • Use ausearch or audit2allow to inspect denials before creating policies.
  • Prefer chcon or semanage fcontext + restorecon rather than disabling SELinux.
Common error example

If a VM fails to start after moving its image, relabel the file with chcon -t svirt_image_t and re-run the VM. Only use audit2allow to craft narrowly scoped policies when truly required.
