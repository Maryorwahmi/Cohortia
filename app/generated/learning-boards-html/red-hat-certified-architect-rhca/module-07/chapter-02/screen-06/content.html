Module 7 › Chapter 7.2 › Bridged networking for KVM guests
Definition

Bridge

A bridge connects virtual interfaces and a physical NIC so guests share the host’s network segment and receive IPs from the same DHCP server.

Why it matters
  • Direct LAN presence simplifies management, discovery, and performance tuning.
  • Avoids port forwarding and NAT complexity for services exposed externally.
  • Requires proper firewall and host hardening to protect guests.
Concrete scenario

You have a web server VM that must receive a DHCP address from the corporate network and be reachable by other physical machines. Bridging provides that network identity without extra routing rules.

Misconception

Bridging is insecure by default. Reality: bridging requires host-level security controls, but it is safe when SELinux and firewalld are configured properly and management access is restricted.

Key Takeaway

Choose bridged networking for production workloads that need direct LAN presence; pair it with host security controls.
