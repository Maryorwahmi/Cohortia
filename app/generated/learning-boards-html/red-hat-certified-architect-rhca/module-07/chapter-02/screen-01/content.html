KVM Host Configuration and Management

Build and harden a KVM host: ensure libvirtd, prepare bridged networking, choose storage formats, and apply SELinux and firewall controls.

This module focuses on a practical, repeatable sequence: verify hardware and BIOS virtualization, install virtualization groups, configure network bridges, provision storage, and secure the host. Each topic contains commands you can run and verification steps to confirm success.
Explore Key Topics
Networking
Bridged networks let guests appear on the physical LAN; we'll show nmcli commands to build br0 and enslave a physical interface.
Storage
Compare qcow2, raw, and LVM-backed disks and create a thin-provisioned qcow2 image with qemu-img.
Security
Apply SELinux types, secure libvirtd and firewall rules, and learn common misconfigurations to avoid.

Key Takeaway

Treat the host as the single source of truth: manage libvirtd, networks, and storage deliberately, and enforce SELinux contexts and firewall rules before deploying production guests.
