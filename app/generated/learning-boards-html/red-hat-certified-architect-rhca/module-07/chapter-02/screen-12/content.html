Module 7 › Chapter 7.2 › Create qcow2 and LVM-backed disks
Create qcow2
Create a 30G thin-provisioned image and verify file listing.
sudo qemu-img create -f qcow2 /var/lib/libvirt/images/myfirstvm.qcow2 30G
ls -lh /var/lib/libvirt/images/myfirstvm.qcow2
Create LVM LV
Create a 20G logical volume in vg_kvm and confirm with lvdisplay.
sudo lvcreate -n myvm_disk -L 20G vg_kvm
sudo lvdisplay /dev/vg_kvm/myvm_disk
Verification and test
  • For qcow2: ls -lh shows a small apparent size until the VM writes data.
  • For LVM: lvdisplay confirms the LV and its attributes; attach the device and boot a test VM to confirm accessibility.
  • If images are stored outside the default path, update SELinux contexts before starting VMs.
