Module 7 › Chapter 7.2 › Host security: firewall, SSH, and maintenance
Access control
  • Limit SSH to admin IPs, use key-based auth, and disable password logins.
  • Use a bastion host for management if host is exposed publicly.
Firewall
Place bridge interfaces in zones that permit required traffic. Avoid broadly open zones on hosts running multiple tenants.
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=public --add-interface=br0 --permanent
sudo firewall-cmd --reload
Maintenance and monitoring
  • Keep the host patched and avoid installing unnecessary services.
  • Monitor audit logs and libvirtd logs for unusual activity.
  • Do not disable SELinux; resolve context issues instead of turning it off.
