Module 7 › Chapter 7.2 › Create a bridge with nmcli
Commands
Run these commands with sudo. Replace enp1s0 with your active interface.
sudo nmcli connection add type bridge autoconnect yes con-name br0 ifname br0 ipv4.method auto ipv6.method ignore
sudo nmcli connection add type ethernet autoconnect yes con-name enp1s0-slave ifname enp1s0 master br0
sudo nmcli connection up br0
sudo nmcli connection up enp1s0-slave
Verification
Check that br0 is UP and contains the physical interface.
ip a show br0
sudo brctl show
Common mistake
Forgetting to set ipv4.method auto on the bridge or not bringing up the slave leaves guests without DHCP or network access.
Scenario
After these commands, attach a VM NIC to br0. If the VM does not get an IP, re-check that both br0 and the slave connection are shown as UP by nmcli connection show --active and ip a.
Key Takeaway

Use nmcli for repeatable bridge creation and always verify both bridge and slave are active before trusting VM network behavior.
