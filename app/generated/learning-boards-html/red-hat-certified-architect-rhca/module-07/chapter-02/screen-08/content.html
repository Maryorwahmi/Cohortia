Module 7 › Chapter 7.2 › Verify bridge and diagnose connectivity issues
Checklist
  1. Confirm bridge exists: ip a show br0
  2. Confirm slave is attached: sudo brctl show
  3. Check active connections: nmcli connection show --active
  4. Inspect firewall zones and rules: sudo firewall-cmd --list-all --zone=public
Quick commands
ip a show br0
sudo brctl show
nmcli connection show --active
sudo firewall-cmd --get-active-zones
Common fixes
  • Bring up missing connections with nmcli connection up <name>.
  • Temporarily stop firewalld to test connectivity, then add needed rules rather than leaving it disabled.
  • Ensure guest NIC points to the correct bridge source in its domain XML or virt-manager settings.
Pitfall

Randomly restarting network services can disrupt other hosts. Follow the checklist to isolate the issue before broad restarts.
