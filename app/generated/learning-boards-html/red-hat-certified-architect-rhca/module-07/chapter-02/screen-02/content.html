Learning Objectives

From installation through security checks: measurable competencies for a production KVM host.

Bloom: Learn → Understand → Apply → Master
01
Host preparation
Install a minimal RHEL host, add the virtualization group, and enable libvirtd to start at boot.
Mnemonic: checklist (install → group → enable)
VERIFIED COMPETENCY MILESTONE
02
Network bridging
Create a bridge, enslave the physical NIC, and verify that VMs can obtain an address from DHCP.
Mnemonic: joiner (NIC → bridge → VM)
VERIFIED COMPETENCY MILESTONE
03
Storage provisioning
Create qcow2 images or LVM volumes, understand thin provisioning, and pick storage for performance and snapshots.
Mnemonic: store-by-need (qcow2 for features, raw for simplicity)
VERIFIED COMPETENCY MILESTONE
04
Host security
Apply SELinux contexts for images, configure firewall zones for bridges, and restrict management access to libvirtd.
Mnemonic: secure-first (SELinux → firewall → access)
VERIFIED COMPETENCY MILESTONE
