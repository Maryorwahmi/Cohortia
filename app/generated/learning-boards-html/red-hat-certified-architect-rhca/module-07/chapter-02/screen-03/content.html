Module 7 › Chapter 7.2 › How you'll demonstrate competency
Host check
Confirm libvirtd is enabled and running and that the virtualization package group exists.
sudo systemctl enable --now libvirtd
sudo systemctl status libvirtd
Networking check
After creating a bridge, verify it has an address and the slave is attached.
ip a show br0
sudo brctl show
Storage check
Create an image and list it to confirm thin provisioning or inspect LV presence.
sudo qemu-img create -f qcow2 /var/lib/libvirt/images/test.qcow2 10G
ls -lh /var/lib/libvirt/images/test.qcow2
SELinux check
Verify file contexts and fix images outside the default path.
ls -Z /var/lib/libvirt/images
sudo chcon -t svirt_image_t /data/kvm_images/myvm.qcow2
Firewall check
Confirm host zones permit bridge traffic or libvirt management if required.
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --list-all --zone=public
Final test
Boot a small test VM and verify DHCP or network connectivity and that the disk mounts correctly.
