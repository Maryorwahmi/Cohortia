Module 7 › Chapter 7.2 › Preparing a minimal RHEL host for KVM
Definition

Minimal host and virtualization group

A minimal host reduces services to lower attack surface and free resources. The virtualization package group installs libvirt, QEMU, and tooling in a consistent set.

Concrete example
After installing packages, enable and check libvirtd to confirm it will start after reboots.
sudo dnf groupinstall -y "Virtualization"
sudo systemctl enable --now libvirtd
sudo systemctl status libvirtd
Explanation
  • Install the virtualization group to ensure consistent versions of libvirt and QEMU.
  • Enable libvirtd to allow management of guests across boots and to support auto-starting VMs.
  • Minimal install avoids unnecessary services that compete for CPU, memory, or expose extra attack surface.
  • Verify with systemctl and confirm the host can list virtualization capabilities via virsh or virsh list --all.
Common misconception

A desktop GUI is not required for KVM hosts; it usually consumes resources and is unnecessary for server management.
