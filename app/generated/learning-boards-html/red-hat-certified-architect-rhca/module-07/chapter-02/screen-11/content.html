Module 7 › Chapter 7.2 › Storage locations and strategies
Filesystem images
Store qcow2 or raw files under /var/lib/libvirt/images. Simple to manage but may lead to I/O bottlenecks if multiple VMs share a single disk.
LVM volumes
Create logical volumes for each VM. Offers resizing and block-level snapshotting and is often preferred for production systems needing predictable performance.
Shared storage
NFS, iSCSI, or distributed filesystems enable live migration and HA because multiple hosts can access the same image simultaneously.
Design guidance
  • Map I/O-heavy VMs to local fast volumes or LVM-backed devices.
  • Use shared storage when you need live migration or multi-host access.
  • Avoid placing all VM images on a single slow filesystem to prevent I/O contention.
