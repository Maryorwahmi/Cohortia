Hands-on Activity
Create the VM
Run the virt-install command below to build and start the installer.
sudo virt-install \
  --name centos9-testvm \
  --ram 2048 \
  --vcpus 1 \
  --disk path=/var/lib/libvirt/images/centos9-testvm.qcow2,size=20,format=qcow2 \
  --network bridge=br0 \
  --os-variant centos-stream9 \
  --cdrom /var/lib/libvirt/images/CentOS-Stream-9-latest-x86_64-dvd1.iso \
  --graphics vnc,listen=0.0.0.0 \
  --noautoconsole \
  --boot cdrom,hd \
  --wait -1
Edit XML to remove CD-ROM
Run sudo virsh edit centos9-testvm, remove the <disk type='file' device='cdrom'> block, and ensure <boot dev='hd' /> appears before other boot entries.
Lifecycle commands exercise
Start with virsh start, then try virsh shutdown. If the guest is unresponsive, observe why before using virsh destroy.
Key Takeaway
Follow the create → install → edit → verify lifecycle to avoid leaving install media attached or misconfigured boot order.
