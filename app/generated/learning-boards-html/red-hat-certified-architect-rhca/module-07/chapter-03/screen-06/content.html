Definition
VM XML structure
The XML contains the VM's <os>, <devices>, and resource elements that libvirt reads at runtime.
Example — change boot order
<os>
  <type arch='x86_64' machine='pc-q35-6.2'>hvm</type>
  <boot dev='hd' />
  <boot dev='network' />
</os>
How to edit safely
  • Use virsh edit <VM> so libvirt validates on save.
  • Export a backup copy with virsh dumpxml > vmname.xml before large edits.
  • Mind device targets and addresses to avoid renaming or reordering disks inside the guest.
Common mistake
Editing XML while a VM is running and expecting all changes to apply immediately; some must be applied with virsh set* commands or after reboot.
Key Takeaway
Treat the XML as the single source of truth and validate edits before restarting or applying them to running guests.
