Module 07 › Chapter 7.3 › Key Concepts
virt-install
A CLI tool to create and provision VMs with full hardware parameters for repeatable deployments.
VM XML Definition
The authoritative libvirt configuration describing hardware, devices, and boot options for each VM.
virsh Lifecycle
Use virsh commands to list, start, shutdown, destroy, suspend, resume, and undefine VMs safely.
Summary Takeaway

Combine virt-install for provisioning, XML editing for authoritative configuration, and virsh for lifecycle and device management to run and automate KVM hosts reliably.
