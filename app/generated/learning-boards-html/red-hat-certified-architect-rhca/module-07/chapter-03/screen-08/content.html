Core virsh commands
Control VM state and startup behavior using a small set of well-understood commands.
virsh list --all
virsh start <VM_NAME>
virsh shutdown <VM_NAME>
virsh destroy <VM_NAME>
virsh reboot <VM_NAME>
virsh suspend <VM_NAME>
virsh resume <VM_NAME>
virsh undefine <VM_NAME>
virsh autostart <VM_NAME>  # enable
virsh autostart --disable <VM_NAME>  # disable
Interpretation
  • Prefer graceful shutdown to avoid data corruption.
  • Use destroy only as a last resort; check guest logs afterwards.
  • Undefine removes the libvirt record but not disk images.
Common mistake
Using destroy regularly in production can lead to filesystem corruption; always attempt shutdown first.
Key Takeaway
Learn the difference between graceful and forceful operations and protect guest data by using the correct virsh command for the situation.
