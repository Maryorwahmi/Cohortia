Core Concept
virt-install anatomy
A single virt-install command can define hardware, storage, network, and start installation immediately—ideal for automation.
Example command
sudo virt-install \
  --name rhel9-webserver \
  --ram 4096 \
  --vcpus 2 \
  --disk path=/var/lib/libvirt/images/rhel9-webserver.qcow2,size=30,format=qcow2 \
  --network bridge=br0 \
  --os-variant rhel9.0 \
  --cdrom /var/lib/libvirt/images/rhel-9.0-x86_64-dvd.iso \
  --graphics vnc,listen=0.0.0.0 \
  --noautoconsole \
  --boot cdrom,hd,network
What each option means
  • --name: unique VM identifier used by libvirt and virsh.
  • --ram / --vcpus: resource allocation that should reflect host capacity.
  • --disk: creates or points to a qcow2 image; size and format are explicit.
  • --network: connect to a bridge like br0 for external access.
  • --cdrom / --location: installation source; use network sources for automation.
Example
Run the command, connect with a VNC client, complete installation, then shut down and verify the VM is defined in libvirt.
Key Takeaway
Virt-install provides a single, scriptable entry point to define VM hardware and start installs, enabling automation and consistency.
