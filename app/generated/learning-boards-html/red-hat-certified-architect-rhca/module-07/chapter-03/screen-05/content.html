Definition
Parameter selection
Match flags to your deployment model: interactive vs automated, bridged vs isolated networking, and persistent disk expectations.
Automation tips
Prefer network installs and kickstart for unattended deployments; use --graphics none and --noautoconsole when no interactive console is needed.
Networking considerations
Bridging to br0 provides direct network access; ensure firewall and bridge configuration is correct before provisioning.
Parameter quick-reference
--cdrom
Local ISO for interactive installs
--location / --pxe
Use for network installs and automation
--noautoconsole
Prevent console attachment from blocking scripts
--graphics none
Headless installs suitable for automation
Misconception
Changing the virt-install command does not alter an already-created VM; use virsh and edit the XML for post-creation changes.
