Process Flow › tuned and Profiles
Apply virtual-host profile
sudo tuned-adm profile virtual-host
# Verify current profile
sudo tuned-adm active
After applying, re-run workloads to confirm reduced variability and improved throughput for VMs.
Validation tips
  • Re-run the same benchmark used for baseline measurement.
  • Observe host-level schedulers and guest performance to detect side effects.
  • Roll back if non-virtualization workloads regress.
Key Takeaway

tuned provides helpful system-level defaults, but only measurement can confirm whether a profile benefits your specific workloads.
