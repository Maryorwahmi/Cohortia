Definition › NUMA Awareness
NUMA XML Example
<numatune>
  <memory mode='strict' nodeset='0'/>
  <vcpu placement='auto'/>
</numatune>
If you require explicit CPU pinning to the same node, set vCPU cpuset values that map to that node. Use lscpu and numactl to inspect node mappings and verify behavior under load.
Practical Steps
  1. Inspect NUMA topology: lscpu -e.
  2. Design VM vCPU and memory to fit within a single node when possible.
  3. Set numatune and validate under representative load.
Key Takeaway

Aligning CPU and memory to the same NUMA node reduces latency and improves predictability for multi-socket servers.
