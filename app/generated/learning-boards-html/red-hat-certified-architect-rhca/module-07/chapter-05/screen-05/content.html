Pinning Example (XML)
<vcpu placement='static' cpuset='0-1'>2</vcpu>
<cputune>
  <vcpupin vcpu='0' cpuset='0'/>
  <vcpupin vcpu='1' cpuset='1'/>
</cputune>
Run lscpu -e to confirm physical core numbers. After applying, use mpstat -P ALL or htop to ensure pinned vCPU threads run on intended cores and that no unexpected contention appears.
Pinning Checklist
  • Inspect host topology with lscpu -e.
  • Choose physical cores, not just logical IDs.
  • Pin selectively and preserve host capacity.
Common Mistake

Pinning to hyperthreads without checking core layout can leave two vCPUs contending on one physical core. That increases latency, not reduces it.
