Core Concept › Diagnosing Bottlenecks
Common Host Commands
top / htop: live CPU and memory per process.
vmstat: system-wide memory, swap and CPU statistics over time.
iostat: block device throughput and latency metrics.
virt-top: per-VM CPU, memory and I/O similar to top.
Example: Interpreting I/O Wait
If iostat shows high await and virt-top shows a single VM with heavy reads, prioritize storage tuning or move the VM to faster storage. If host CPU shows high steal, the host is overloaded by scheduling, not the guest app itself.
Diagnostic Checklist
  • Collect a baseline with the same tools you will use to validate changes.
  • Correlate host metrics with virt-top per-VM stats.
  • Look for spikes in iowait, context switches, or page faults before changing configs.
Key Takeaway

Diagnosis requires both host and guest perspectives; one without the other can mislead your tuning decisions.
