Definition › Memory Ballooning
XML: Balloon with adjustable currentMemory
<memory unit='KiB'>4194304</memory>
<currentMemory unit='KiB'>2097152</currentMemory>
<devices>
  <memballoon model='virtio'></memballoon>
</devices>
Here the VM has a max of 4GB but starts at 2GB; the balloon driver lets the host manage the remaining pages dynamically.
When to avoid ballooning
  • Latency-sensitive databases that require stable memory allocations.
  • Workloads that swap heavily when memory is reclaimed, which increases I/O.
Key Takeaway

Use ballooning as a controlled tool for overcommitment and monitor guest swap and page faults to avoid performance degradation.
