Module 7 › Chapter 7.5 › Learning Objectives
01
Identify and diagnose bottlenecks
Use host tools like top, vmstat, iostat and KVM-specific tools such as virt-top to create a baseline and find whether CPU, memory, or I/O is the limiting resource. This skill matters because accurate diagnosis prevents wasted tuning effort.
Mnemonic: magnifying glass over a server
VERIFIED COMPETENCY MILESTONE
02
Implement CPU pinning and NUMA awareness
Configure vCPU pinning and align vCPUs and memory with NUMA nodes in the VM XML to reduce context switching and remote memory latency. This is essential for latency-sensitive workloads.
Mnemonic: pin icon and node alignment
VERIFIED COMPETENCY MILESTONE
03
Configure memory optimizations
Enable huge pages and use memory ballooning where appropriate, understanding persistence and the risk of excessive reclamation inside guests. Huge pages reduce TLB misses for memory-heavy applications.
Mnemonic: stacked pages
VERIFIED COMPETENCY MILESTONE
04
Optimize disk I/O and monitoring
Choose virtio-scsi, set disk driver options such as cache='none' and io='native' wisely, and use tuned profiles and monitoring to ensure predictable performance while understanding durability trade-offs.
Mnemonic: stacked disks
