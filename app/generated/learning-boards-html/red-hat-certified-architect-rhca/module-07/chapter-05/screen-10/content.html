Commands and Outputs
# Run virt-top to watch per-VM stats
virt-top

# Query qemu monitor for a VM's block info
virsh qemu-monitor-command myvm --cmd 'info block'

# Host-level I/O tool
iostat -x 1
Interpret outputs together: virt-top highlights the VM, iostat shows which device is slow, and qemu-monitor gives VM block internals for deeper debugging.
Guided Example
If virt-top reports a VM with high I/O and iostat shows high await on the backing device, consider moving the VM to faster storage or changing disk driver options. Use qemu-monitor block info to inspect queue depth and device errors as part of diagnosis.
Key Takeaway

Monitoring is most effective when you correlate multiple sources and use them consistently for baseline and validation.
