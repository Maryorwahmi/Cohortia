Hands-on Activity › Implement Pinning & Huge Pages
Lab Steps (condensed)
  1. Inspect CPU topology: lscpu -e.
  2. Allocate huge pages: echo 1024 > /sys/kernel/mm/hugepages/hugepages-2048kB/nr_hugepages.
  3. Shut down VM: virsh shutdown app-db-server.
  4. Edit VM XML: add vcpu placement and cputune vcpupin, and memoryBacking hugepages.
  5. Start VM and verify with virsh dumpxml, /proc/meminfo and virt-top.
Example XML snippets
<vcpu placement='static' cpuset='0-1'>2</vcpu>
<cputune>
  <vcpupin vcpu='0' cpuset='0'/>
  <vcpupin vcpu='1' cpuset='1'/>
</cputune>

<memory unit='KiB'>2097152</memory>
<currentMemory unit='KiB'>2097152</currentMemory>
<memoryBacking>
  <hugepages/>
</memoryBacking>
Reflection

After completing the steps, compare virt-top and host metrics pre- and post-change. Did latency fall and did TLB-related CPU overhead reduce? Consider rollback if host contention increased.
