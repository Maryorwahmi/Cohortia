Module 7 › Chapter 7.6 › Key Concepts
RHV Manager
Central orchestration and state tracking via UI and API for automation, HA, and migration.
RHV Hosts
KVM/QEMU/libvirt hosts that execute VMs and must share storage and compatible CPU features within a cluster.
Storage Domains
Logical containers for VM disks, ISOs, and templates that must be accessible to all hosts in a cluster.
Summary

These three components — Manager, Hosts, Storage Domains — form the essential relationship that enables RHV features like HA and live migration.
