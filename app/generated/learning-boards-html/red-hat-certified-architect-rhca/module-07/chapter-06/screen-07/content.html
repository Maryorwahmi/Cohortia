Data Center

Top-level container

Defines compatibility and groups clusters, networks, hosts and storage isolated by site or policy.
Example
A production data center set to RHEL 8 compatibility that contains multiple clusters for different workloads.
Cluster
A cluster groups hosts with compatible CPUs and shared storage. It is the domain for live migration and HA — VMs migrate only within cluster boundaries unless the environment is designed otherwise.
Common misconception
Clusters are more than organization tags; they are functional boundaries that determine whether features like live migration will work between two hosts.
Key Takeaway

Design clusters and data centers intentionally to control compatibility and to create clear boundaries for migration and HA.
