Module 7 › Chapter 7.6 › KVM & libvirt Integration
Architecture

Manager orchestrates host-side libvirt calls

Manager plans operations; libvirt executes them on the host. QEMU provides the VM runtime and memory transfer for migration.
Code-style example (conceptual)
# Manager creates VM XML, then instructs host libvirt to define and start domain
manager.prepare_vm(xml_definition)
manager.notify_host(host_id, 'define', xml_definition)
manager.notify_host(host_id, 'start', vm_name)

# For live migration, Manager checks storage and compatibility, then triggers migration
manager.check_compatibility(source, dest)
manager.ensure_storage_mounted(dest, data_domain)
manager.trigger_migration(source, dest, vm_name)
Concrete example
During migration, libvirt coordinates memory transfer while Manager sequences the steps and validates target state before finalizing the move.
Misconception
Do not confuse libvirt with the Manager: libvirt is an agent on hosts; the Manager is the central orchestration plane that issues libvirt operations.
Key Takeaway

RHV automates host-side libvirt operations so large-scale VM lifecycle actions can be performed reliably and consistently.
