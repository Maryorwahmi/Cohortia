Module 7 › Chapter 7.6 › Storage Domains
Types
Data Domain
Stores VM disk images, templates and snapshots. Required for VM storage that needs to be shared.
ISO Domain
Holds ISO images used to install guest operating systems.
Export Domain
Used to export and import VMs and templates between RHV systems.
Supported protocols
NFS, iSCSI, Fibre Channel, and GlusterFS are commonly used. Choose a protocol that provides the required performance and that can be mounted consistently by all hosts.
Common mistake
Attaching storage reachable only from some hosts prevents migration and HA. Always test mounts from each host prior to enabling critical features.
Key Takeaway

Shared and consistently mounted storage domains are the foundation for RHV high-availability and migration features.
