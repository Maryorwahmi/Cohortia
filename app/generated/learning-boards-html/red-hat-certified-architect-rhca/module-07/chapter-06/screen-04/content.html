Definition

RHV Manager (Engine)

Central orchestration service that stores environment state and issues commands to hosts through libvirt.

Capabilities
  • Web UI, REST API, CLI for administration and automation.
  • PostgreSQL-backed state tracking for hosts, VMs, networks, and storage.
  • Orchestrates HA, live migration, scheduling and templates.
Concrete example
When a host fails, the Manager chooses a host with capacity, confirms disk access, and issues restart commands so VMs resume on another host.
How it talks to hosts
Manager does not run VMs. It issues libvirt-driven operations to each host's libvirtd. Think of it as an automation engine that converts user intent into concrete libvirt commands executed on the hypervisors.
Common misconception
People sometimes expect the Manager to host workloads. It is strictly a control plane component; running it as a VM is possible but that VM is only for management, not production workloads.
Key Takeaway

Centralized state and orchestration are what enable HA, migration, and large-scale automation in RHV.
