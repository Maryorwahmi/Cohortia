Module 7 › Chapter 7.6 › Planning & Pitfalls
Checklist
  1. Design separate management and storage networks, and map logical networks to physical interfaces.
  2. Choose and provision shared storage (NFS/iSCSI/FC/GlusterFS) and confirm mounts from all hosts.
  3. Set compatibility levels in the Data Center and ensure hosts in a Cluster match required CPU and firmware features.
  4. Test live migration and HA with non-critical VMs before production rollout.
Frequent error
Assuming the Manager will compensate for poor networking or partial storage mounts; instead validate the underlying infrastructure first.
Key Takeaway

Infrastructure validation is essential: networks, firewalls, storage mounts, and host compatibility checks prevent operational failures when enabling RHV features.
