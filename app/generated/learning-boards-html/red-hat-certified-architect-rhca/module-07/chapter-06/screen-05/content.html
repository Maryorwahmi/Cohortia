Module 7 › Chapter 7.6 › RHV Hosts
Role

Execution plane: KVM + QEMU + libvirt

Hosts run the VMs and expose management through libvirtd, which the Manager uses to control VM lifecycle and migration.

Host components
  • KVM kernel module for virtualization extensions.
  • QEMU for device emulation and VM runtime.
  • libvirt/libvirtd for management API on the host.
Concrete scenario
During live migration, libvirt on both hosts exchanges state while QEMU streams memory pages; Manager coordinates the sequence and final handover.
Cluster constraint
Hosts in a cluster must share compatible CPU types and access to the same storage domains. That ensures VMs can live-migrate without CPU or I/O incompatibility errors.
Common misconception
Hosts need not be identical models, but you must ensure CPU compatibility settings and shared storage access across the cluster for migration and HA to function properly.
Key Takeaway

Treat hosts as managed KVM endpoints: plan for CPU compatibility, shared storage, and consistent network mappings.
