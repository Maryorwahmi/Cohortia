Module 7 › Chapter 7.6 › Logical Networks
Concept

Logical networks

Named network roles that get mapped to host NICs or bridges, enabling consistent configuration across the environment.
Example networks
ovirtmgmt (management), vm_network (guest traffic), storage_network (iSCSI or NFS).
Best practice
Use dedicated NICs and VLANs for management and storage networks. Map logical networks consistently to corresponding physical interfaces on every host to avoid configuration drift.
Misconception
Logical networks do not replace physical network design. They are an abstraction that depends on correct underlying switch and VLAN configuration to work reliably.
Key Takeaway

Define logical networks for roles and map them consistently on hosts; plan physical networking to support those mappings.
