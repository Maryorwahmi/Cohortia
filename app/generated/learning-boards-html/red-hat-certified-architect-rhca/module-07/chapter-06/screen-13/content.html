Module 7 › Chapter 7.6 › Admin Portal Walkthrough
Portal Sections
Dashboard
Shows health summary: running VMs, hosts, and storage alerts used for quick triage.
Compute → Data Centers / Clusters
Inspect compatibility levels, cluster membership, and migration boundaries.
Storage → Domains
Verify domain types, available space, and that each host can access the mounted storage.
Network → Logical Networks
See which logical networks are assigned to data centers and clusters and how they map to physical NICs on hosts.
Practical check
Use the portal to confirm mounts on each host, cluster compatibility, and to perform a test migration before trusting HA in production.
Key Takeaway

The Admin Portal is your primary validation and diagnostic interface for RHV architecture — use it to confirm everything is wired correctly before production use.
