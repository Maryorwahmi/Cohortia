Module 7 › Chapter 7.6 › Simulated Activity
Activity steps (simulated)
  1. Open dashboard and note overall health and running VMs.
  2. Compute → Data Centers: inspect compatibility and clusters.
  3. Compute → Clusters: verify CPU compatibility and host membership.
  4. Compute → Hosts: check each host status, libvirt connectivity, and resource usage.
  5. Storage → Domains: confirm shared data domains are mounted across hosts.
  6. Network → Logical Networks: validate logical-to-physical mappings and VLAN assignments.
Reflection
After the simulation, ask: can every host access the VM disks? Do cluster hosts share CPU compatibility? Is there spare capacity for HA restarts?
Key Takeaway

A short portal validation sequence prevents many deployment failures. Test migrations and HA before trusting production workloads to RHV.
