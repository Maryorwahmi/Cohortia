iSCSI
Block-level storage over IP, suitable for high I/O workloads with advanced array features.
virtio
Paravirtualized drivers that improve guest I/O efficiency for network and disk devices.
libvirt storage pool
An abstraction layer representing directories or block sources from which VM volumes are allocated.
Summary

Match storage protocols and virtio models to workload needs, isolate storage networks, verify permissions, and use libvirt commands to manage volumes safely.
