Command Demo
nmcli VLAN and bridge
Run these commands on your KVM host; verify with ip and brctl.
sudo nmcli connection add type vlan con-name enp1s0.20 dev enp1s0 id 20
sudo nmcli connection add type bridge con-name br20 ifname br20 ipv4.method auto ipv6.method ignore
sudo nmcli connection add type ethernet con-name enp1s0.20-slave ifname enp1s0.20 master br20
sudo nmcli connection up br20
sudo nmcli connection up enp1s0.20-slave

# Verification
ip a show br20
brctl show
Explanation & tips
  • Use connection names to make future changes reproducible.
  • Bringing up the bridge before the slave avoids transient routing issues.
  • Persist configuration in NetworkManager so it survives reboots.
Pro tip
Test with tcpdump or guest-to-guest ping across the VLAN to confirm tag propagation and isolation.
