Comparison
NFS (file-level)
Simple mounts, VM images are files on the share.
  • Easy setup and central management.
  • Works well for web/app servers and test/dev pools.
  • Sensitive to network latency and file lock semantics.
Libvirt NFS pool example
sudo virsh pool-define-as nfs_pool dir --target /mnt/nfs_share
sudo virsh pool-build nfs_pool
sudo virsh pool-start nfs_pool
sudo virsh pool-autostart nfs_pool
Comparison
iSCSI (block-level)
Hosts connect to LUNs; VMs see block devices.
  • Provides low-level block access and often better throughput.
  • Supports multipathing and storage-array features.
  • Requires initiator configuration and target management.
iSCSI workflow
sudo iscsiadm -m discovery -t sendtargets -p <ISCSI_TARGET_IP>
sudo iscsiadm -m node -T <TARGET_IQN> -p <ISCSI_TARGET_IP> -l
