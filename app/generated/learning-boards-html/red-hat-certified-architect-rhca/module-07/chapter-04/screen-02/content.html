Learning Objectives
Learn the skills, why they matter, and checkable milestones to verify competency.
01
Implement VLAN-aware bridges
Create VLAN sub-interfaces and attach them to VLAN-aware bridges for logical segmentation. Verified by observing tagged frames and bridge membership.
VERIFIED COMPETENCY MILESTONE
02
Configure shared storage (NFS, iSCSI)
Mount NFS shares and connect to iSCSI targets; define libvirt pools so multiple hosts can access VM images. Verified by creating a pool and listing it with virsh.
VERIFIED COMPETENCY MILESTONE
03
Leverage virtio drivers
Ensure guests use virtio-net and virtio-scsi or virtio-blk to minimize I/O overhead. Verified by checking guest device models in XML and OS-level driver bindings.
VERIFIED COMPETENCY MILESTONE
04
Manage libvirt pools & volumes
Use virsh pool and vol commands to provision, inspect, and delete VM disk volumes. Verified by creating and removing a test volume in a pool.
VERIFIED COMPETENCY MILESTONE
