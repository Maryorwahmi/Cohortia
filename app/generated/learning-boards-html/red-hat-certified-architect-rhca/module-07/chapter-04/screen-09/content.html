Definition
virtio explained
Paravirtualized drivers minimize emulation overhead and improve throughput for guests.
Network
virtio-net provides efficient packet transfer between guest and host.
Block/SCSI
virtio-blk or virtio-scsi expose disks through a paravirtual interface; virtio-scsi is recommended for advanced features.
Verification
Check guest dmesg or lsmod for virtio drivers and inspect domain XML for model="virtio" entries.
XML snippets
Disk example
<disk type='file' device='disk'>
  <driver name='qemu' type='qcow2' cache='none' io='native'/>
  <source file='/var/lib/libvirt/images/myvm.qcow2'/>
  <target dev='vda' bus='virtio'/>
</disk>
Network example
<interface type='bridge'>
  <mac address='52:54:00:xx:xx:xx'/>
  <source bridge='br0'/>
  <model type='virtio'/>
</interface>
Concrete example
Switching a VM from an emulated device to virtio often reduces CPU overhead and increases throughput for disk and network I/O.
