Storage Commands
virsh pool and vol
Create volumes and manage pools for guest disks.
# List pools
virsh pool-list --all

# Pool info
virsh pool-info nfs_kvm_pool

# Create a volume
virsh vol-create-as nfs_kvm_pool vm-disk1.qcow2 20G --format qcow2

# Delete a volume
virsh vol-delete /var/lib/libvirt/images/vm-disk1.qcow2
Explanation
  • Pools abstract directories or block sources; volumes are files or block objects inside pools.
  • vol-create-as returns the volume path which you then reference in a VM's disk source.
  • Deleting volumes requires the actual path; ensure no guests are using the volume.
Common mistake
Assuming pool-undefine removes data. Always check and explicitly delete volumes when reclaiming space.
