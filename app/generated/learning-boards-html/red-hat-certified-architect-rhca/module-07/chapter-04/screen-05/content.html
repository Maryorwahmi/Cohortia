SR-IOV
Enable VFs and assign to guests
Hardware + kernel steps to expose virtual functions for direct guest assignment.
Prerequisites
BIOS/UEFI SR-IOV enablement, NIC driver that supports SR-IOV, and kernel access to sysfs.
Enable VFs
Write desired VF count into /sys/class/net/DEVICE/device/sriov_numvfs.
Assign VF to VM
Attach the VF's PCI address in the guest's XML for direct assignment.
Caveat
VMs using VFs often cannot be live-migrated; plan maintenance windows or fallback paths accordingly.
Example command
# Check SR-IOV support in lspci
lspci -s <PCI_BUS_ID_OF_NIC> -v | grep -i "SR-IOV"

# Enable 4 VFs on NIC enp1s0f0
echo 4 | sudo tee /sys/class/net/enp1s0f0/device/sriov_numvfs
Concrete scenario
A database VM gets a dedicated VF to reduce packet processing latency, improving predictable query response times under load.
Verification
Use lspci and ip link to see the VFs, and check guest PCI devices after assigning a VF in its XML.
