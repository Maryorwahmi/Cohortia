Definition
virtio-blk
Simple paravirtual block device for single disk setups.
  • Lower complexity for single disk guests.
  • Sufficient for many legacy workloads.
  • Less flexible than virtio-scsi for advanced operations.
Definition
virtio-scsi
A paravirtual SCSI controller with richer feature support and scalability.
  • Supports multiple LUNs per controller and hot-plugging.
  • Enables SCSI features like UNMAP/TRIM and better queue handling.
  • Preferred for modern, I/O-intensive guests and dynamic storage management.
Example decision
For a VDI deployment where disks are hot-swapped or storage reclaiming is needed, prefer virtio-scsi; for a single-disk utility VM, virtio-blk suffices.
