Module 7 › Chapter 7.1 › Type‑1 vs Type‑2
Type‑1 (bare‑metal)
Runs on hardware, offers direct control over CPU, memory, and devices. KVM acts as a Type‑1 hypervisor when loaded into the Linux kernel.
  • Lower latency and near‑native performance with hardware virtualization extensions.
  • Stronger isolation due to minimal software layers.
  • Common in datacenters and production clusters.
Type‑2 (hosted)
Runs as an application on a general purpose OS. Useful for local testing and desktop virtualization.
  • Faster to deploy for developers and testers.
  • Introduces an extra scheduling layer and more potential I/O latency.
  • Less suitable for high‑performance production workloads.
Concrete scenario
Choose Type‑1 for a database cluster requiring predictable latency. Use Type‑2 for a developer laptop running multiple test OSes.
Key Takeaway

Match hypervisor type to workload requirements: performance and isolation for production, convenience for desktop use.
