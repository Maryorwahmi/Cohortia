Module 7 › Chapter 7.1 › Host Preparation
Terminal walkthrough
Commands you will run on a RHEL host to verify and install virtualization support.
Check CPU virtualization support
grep -E 'vmx|svm' /proc/cpuinfo
# Expected: lines showing flags: ... vmx ... or ... svm ...
Install virtualization packages
sudo dnf install @virtualization -y
# Installs libvirt, qemu-kvm, virt-install, virt-viewer, and related tools
Enable and verify libvirtd
sudo systemctl enable --now libvirtd
sudo systemctl status libvirtd
# Expected: active (running)
Add user to libvirt group
This allows non‑privileged management locally. You must log out and back in for group membership to take effect.
sudo usermod -aG libvirt $(whoami)
# Log out and back in, then run: id
Key Takeaway

This reproducible sequence verifies hardware and installs a consistent toolset to bootstrap KVM on RHEL.
