Linux Kernel
Memory management, scheduler, device drivers.
KVM
Kernel module enabling hardware virtualization.
QEMU
Emulates devices and translates guest I/O to host.
libvirt
API and daemon to manage VMs and networks.
Key Takeaway

KVM converts Linux into an enterprise-grade hypervisor; QEMU and libvirt complete the stack for emulation and management.
