Module 7 › Chapter 7.1 › Key Concepts
Virtualization
Creating virtual versions of compute, storage, or networking so multiple guests share hardware.
Hypervisor (VMM)
Software layer that creates and manages virtual machines.
KVM
Kernel module that enables hardware‑assisted virtualization on Linux.
Takeaway
Keep these definitions handy when you design or troubleshoot virtualization: they help communicate responsibilities and trade‑offs clearly.
