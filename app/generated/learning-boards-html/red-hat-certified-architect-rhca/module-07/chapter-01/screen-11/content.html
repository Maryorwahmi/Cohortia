Module 7 › Chapter 7.1 › VM Lifecycle
Common lifecycle steps
A reproducible lifecycle reduces human error and supports automation in production environments.
Define
Create domain XML via tools or handcraft for advanced options.
Start / Stop
Controlled by libvirtd; use virsh for automation.
Snapshot
Short‑term rollback; not a long‑term backup.
Live migration
Move running VMs between hosts to avoid downtime for maintenance. Requires shared storage or block migration and network planning.
Concrete tool mapping
Use virt‑install to create, virsh to manage in scripts, and libvirt API for orchestration with configuration management tools.
Misconception
Snapshots are backups. Use snapshots for short‑term testing; rely on backups and image scanning for long‑term recovery and compliance.
Key Takeaway

Automate lifecycle operations and treat snapshots as convenience, not a substitute for backups or image scanning.
