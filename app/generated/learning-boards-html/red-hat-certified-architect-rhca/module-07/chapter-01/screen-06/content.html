Module 7 › Chapter 7.1 › KVM Architecture
How KVM sits in the stack
KVM provides kernel hooks and uses hardware extensions so guest code runs efficiently with kernel scheduling semantics.
Kernel scheduler
Schedules VM processes alongside other system processes.
KVM modules
kvm, kvm_intel or kvm_amd provide virtualization primitives.
Guest process
Each VM runs as a process with access to virtualized CPUs and memory.
Example
Start a VM and observe it in top or ps as a qemu process backed by kernel KVM capabilities. The kernel enforces isolation between VMs.
Misconception check
KVM is not a separate host application; it is kernel code. Management tools run in userland but core virtualization primitives are in the kernel.
Key Takeaway

Because KVM is kernel‑integrated, it benefits from kernel improvements and provides an efficient path for guest execution when hardware extensions are available.
