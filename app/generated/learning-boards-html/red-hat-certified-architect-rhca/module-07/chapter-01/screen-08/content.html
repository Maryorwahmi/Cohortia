Module 7 › Chapter 7.1 › KVM + QEMU
Division of responsibilities
KVM provides execution primitives in the kernel; QEMU emulates hardware and runs the VM process in userland.
  1. QEMU starts a process and requests KVM via /dev/kvm.
  2. KVM sets up vCPU and memory contexts using hardware extensions.
  3. QEMU emulates devices and handles guest I/O via the host filesystem and network.
Performance note
CPU performance is governed by KVM and hardware; I/O performance often requires tuning QEMU device models and choosing appropriate storage backends.
Concrete example
A qemu-system process appears in ps; it maps guest disk I/O to a host file or block device while the kernel KVM module handles vCPU state transitions.
Key Takeaway

KVM and QEMU together provide efficient CPU execution and flexible device emulation; both must be considered when optimizing performance.
