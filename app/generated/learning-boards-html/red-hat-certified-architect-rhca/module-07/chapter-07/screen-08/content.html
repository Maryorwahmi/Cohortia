Module 7 › Chapter 7.7 › Adding RHV Hosts to the Environment
Admin Portal
Steps to add a host
  1. Log in to https://<RHV_MANAGER_FQDN>/ovirt-engine/webadmin.
  2. Navigate to Compute → Hosts and click New.
  3. Enter host FQDN or IP, SSH port, and root password or SSH key.
  4. Select Data Center and Cluster, then confirm. Manager will SSH to the host, install VDSM, KVM and libraries.
Post-add checks
Confirm the host reports 'Up' and VDSM is running, ensure shared storage mounts are visible, and test migration capability if needed.
Concrete scenario
Adding rhevh-02.example.com with SSH key authentication lets the Manager install required packages and bring the host into the selected cluster without manual package steps.
Common mistake
Not allowing SSH from the Manager or providing incorrect credentials causes the add operation to fail during agent installation.
Key Takeaway

Ensure SSH connectivity and credentials are correct and verify VDSM status after the Manager provisions the host.
