Module 7 › Chapter 7.7 › Key Concepts — Part 2
Storage domain activation
Correct NFS export options or iSCSI initiator access and filesystem permissions are required for activation.
Logical network mapping
Logical networks must be mapped to physical interfaces or bridges; VLAN IDs are applied when needed for isolation.
Verification checks
Mount storage from each host, confirm DNS forward/reverse, confirm firewall ports, and validate VDSM status as a pre-deployment checklist.
Final takeaway

Treat failed verification as a blocker; resolve DNS, firewall or storage permission issues before proceeding with hosted-engine --deploy or host additions.
