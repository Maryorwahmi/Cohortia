Module 7 › Chapter 7.7 › Key Concepts — Part 1
Self-Hosted Engine
Manager runs as a VM on hosts for higher availability, relying on shared storage and host lifecycle control.
hosted-engine --deploy
Interactive utility to create the engine VM disk, start the Manager VM and register the initial host.
VDSM
Host agent that executes Manager commands, reports status, and manages local virtualization services.
Summary

These three concepts are the backbone of RHV deployment; they depend on correct storage, network, and host preparation to function as intended.
