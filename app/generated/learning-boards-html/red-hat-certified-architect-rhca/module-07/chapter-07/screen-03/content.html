Applied Skills

Tasks and verification steps to prepare hosts and run the deployment safely.
Skill 05
Configure static management IP and DNS
Use nmcli and ping to set and verify connectivity and forward/reverse DNS for all RHV components.
VERIFIED COMPETENCY MILESTONE
Skill 06
Enable repos & install cockpit-ovirt-dashboard
Ensure required packages and the Cockpit plugin are available before running hosted-engine deploy.
VERIFIED COMPETENCY MILESTONE
Skill 07
Open firewall ports for VDSM, SSH, VNC
Confirm firewall rules to prevent host-manager communication failures during setup and operation.
VERIFIED COMPETENCY MILESTONE
Skill 08
Verify KVM and libvirt
Check CPU virtualization flags and libvirtd status so hosts are ready to run VMs and the engine VM.
VERIFIED COMPETENCY MILESTONE
