Module 7 › Chapter 7.7 › Running hosted-engine --deploy
Command
Execute the deploy utility on the first host
sudo hosted-engine --deploy
Prompts you will see: IP/netmask/gateway/DNS for Manager VM, shared storage details (NFS path or iSCSI target), resource sizing for engine VM, and admin password.
Common mistake
Beginning before verifying storage permissions or DNS will cause the script to fail or the Manager VM to be unreachable after creation.
Step overview
  1. Host prepares packages and required configuration.
  2. Create the Manager VM disk on the shared storage target you provided.
  3. Start the Manager VM and connect to it for final configuration.
  4. Initial host is registered in the new RHV environment.
Check

Verify the engine disk exists on the shared storage and is accessible from other hosts by mounting the share and listing files before concluding deployment.
