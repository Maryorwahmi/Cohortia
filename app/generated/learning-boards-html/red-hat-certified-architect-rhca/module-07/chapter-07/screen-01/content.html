RHV Deployment and Initial Configuration

Plan infrastructure, deploy the Manager as a self-hosted engine, add RHV Hosts, attach storage domains, and map logical networks for production readiness.

In this chapter you will follow concrete steps and command examples, verify prerequisites, and learn quick troubleshooting checks for common failures such as DNS and firewall issues.

Quick checklist
  • Static IPs & DNS
  • Shared storage accessible to hosts
  • Firewall ports for VDSM, SSH, and Manager
Instructor note
Before you run any deployment command, verify forward and reverse DNS, and ensure shared storage is reachable from all candidate hosts. These checks save hours during initial setup.
