Module 7 › Chapter 7.7 › Creating and Activating Storage Domains
NFS example
Create a new storage domain in Storage → Domains, select NFS and provide an export path for validation.
Example export and permissions
/exports/rhv_data *(rw,sync,no_root_squash,no_subtree_check)
# then
sudo exportfs -ra
sudo chmod 0755 /exports/rhv_data
# ensure access for vdsm:kvm as appropriate
Common pitfall
Exports that deny the vdsm user or use restrictive root squashing often prevent activation even when the server is reachable.
iSCSI notes
For iSCSI, ensure targets and LUNs are discoverable and accessible from every host. Multipath and initiator setup may be required for production.
Activation check
After creating a domain, RHV will attempt activation. If it fails, mount the NFS export on a host and check permissions or run iscsiadm discovery for iSCSI targets.
Key Takeaway

Always test storage mounts and permissions from all hosts before creating a storage domain to prevent activation failures.
