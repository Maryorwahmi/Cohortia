Module 7 › Chapter 7.7 › Logical Network Mapping
Define network
Create a logical network named vm_network, select Data Center and Cluster, and mark as a VM network. Optionally set VLAN ID for tagged traffic.
Mapping
On each host: Compute → Hosts → select host → Network Interfaces → Setup Host Networks. Drag vm_network to an interface such as enp2s0 or attach to a bridge used by VMs.
Verification
After mapping, confirm that a test VM attached to vm_network can reach peers and that VLAN tagging is consistent across host boundaries.
Misconception
Assuming networks propagate automatically to hosts. Mapping is explicit; plan mappings as part of host configuration.
Key Takeaway

Define logical networks for traffic roles and explicitly map them to host interfaces or bridges; test VLANs and connectivity after mapping.
