Learning Objectives

Develop the practical skills required to deploy and configure an RHV environment.
Bloom: Learn → Understand → Apply → Master
01
Plan infrastructure requirements
Define networks, storage, DNS, static IPs and firewall rules needed for a stable deployment. This prevents common setup failures.
VERIFIED COMPETENCY MILESTONE
02
Deploy the Manager as a self-hosted engine
Run hosted-engine --deploy and provide network, storage and resource details so the Manager VM runs on shared storage under host control.
VERIFIED COMPETENCY MILESTONE
03
Add and configure RHV Hosts
Use SSH or Admin Portal to register hosts, provision VDSM, and confirm host compatibility for live migration and HA.
VERIFIED COMPETENCY MILESTONE
04
Create and attach storage domains
Configure NFS or iSCSI domains, check export permissions and activate the domain for VM disk placement.
VERIFIED COMPETENCY MILESTONE
