Module 7 › Chapter 7.7 › Self-Hosted Engine Explained
Definition

What the self-hosted engine is

A Manager VM hosted on shared storage and run under the control of an RHV Host, ensuring Manager availability through the cluster.

Concrete example
Run hosted-engine --deploy on hostA; the Manager VM disk is created on NFS; if hostA fails, the Manager VM can be started on hostB which can access the same NFS export.
Misconception
Thinking the Manager VM is separate from the cluster: it is integral and managed by host agents for HA.
Pro tip
Ensure the Manager VM disk is on shared storage with consistent performance to prevent slow control-plane behavior.
Lifecycle steps
  1. Prepare host packages and storage access.
  2. Create engine VM disk on shared storage.
  3. Start Manager VM and finish engine setup.
  4. Host is added to RHV environment as first host.
Key Takeaway

Self-hosted engine ties Manager availability to shared storage and host lifecycle; verify storage reachability and DNS to enable HA behavior.
