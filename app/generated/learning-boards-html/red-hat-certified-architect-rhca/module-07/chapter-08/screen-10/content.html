Module 8 › Chapter 7.8 › Snapshots & Checkpoints
Core Concept

Point-in-time VM state using delta disks

Snapshots create delta images to capture changes after the snapshot. Revert restores the VM to the snapshot state; delete consolidates the delta into its parent.

Use cases
  • Testing patches and upgrades
  • Development checkpoints
  • Quick rollback before risky operations
Safety Note

Snapshots are not backups. Long snapshot chains can cause performance issues and increase failure blast radius.

Key Takeaway

Use snapshots for short-lived tasks and always consolidate or delete them when complete; maintain independent backups too.
