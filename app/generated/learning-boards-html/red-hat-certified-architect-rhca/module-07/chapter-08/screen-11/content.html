Module 8 › Chapter 7.8 › Application-Consistent Snapshots
What it does

Quiesce applications via QEMU Guest Agent

QGA coordinates inside the guest to flush buffers and pause I/O so the snapshot captures consistent application state. For Windows, VSS can be used via QGA.

Verification steps
  • Confirm QGA is installed and running inside the VM
  • Use the Admin Portal option to include applications list / memory
  • Verify the snapshot shows application-consistent metadata in the portal
Safety Note

Including memory and app lists yields more complete rollbacks but increases snapshot size. Use judiciously for critical workloads.

Pro Tip

Install and test QGA in staging VMs before relying on application-consistent snapshots in production.
