Module 8 › Chapter 7.8 › Migration Techniques
Pre-copy

Iterative memory copy

Memory pages are copied while the VM runs; repeated until dirty pages are minimal for a short cutover.

  • Pros: predictable, fewer page faults after cutover
  • Cons: can take long for highly dirty VMs
Post-copy

Resume on destination then fetch pages

Pause briefly to transfer CPU state, resume on destination, and fetch memory pages on demand.

  • Pros: shorter pause during cutover
  • Cons: higher latency from page faults and recovery risk
Example

For a web server with moderate memory churn, pre-copy is usually safe. For a VM with very large dirty memory churn, post-copy can shorten the pause but introduce latency after migration.
