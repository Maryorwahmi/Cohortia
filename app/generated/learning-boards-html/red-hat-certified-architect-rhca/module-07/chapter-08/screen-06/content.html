Module 8 › Chapter 7.8 › Fencing (STONITH)

What is fencing?

An enforced isolation or power-off of an unresponsive host using IPMI, Redfish, or other power interfaces to prevent split-brain.

Example

Network partition hides a host from Manager, but the host still has storage access. Fencing powers it off before VMs start elsewhere.

Misconception

Thinking fencing is optional. Without it HA cannot safely guarantee data integrity during failover.

How to validate
  1. Configure power management credentials for each host
  2. Run a controlled fence operation and confirm host powers off
  3. Test VM restart sequence after fencing to ensure failover works
Pro Tip

Use redundant power management endpoints when possible and document testing procedures for maintenance windows.
