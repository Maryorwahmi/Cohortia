Prepare Golden Image

Ensure the base VM is shut off, remove unique identifiers, and generalize the image before making a template.

Simulated command
sudo virt-sysprep --operations customize,ssh-userdir,dhcp-client-state,machine-id -a rhel8-base-vm

This command generalizes identifiers; in the portal you must then convert the powered-off VM into a template and seal it.

Template creation checklist
  • Confirm VM is powered off
  • Make Template → select cluster and storage domain
  • Check Seal Template to remove instance-specific data
Take Snapshot

Select the running VM (db-server-01), ensure QGA is active, and take a snapshot. Include memory and applications list if you need application-consistent state.

Verification

Open the VM’s Snapshots tab in the portal to confirm the snapshot appears and check its metadata for app-consistency flags.
