Module 8 › Chapter 7.8 › Live Migration
Core Idea

Move running VMs without interruption

Memory and CPU state are transferred to the destination host while the VM keeps running; disks remain on shared storage.

When to use
  • Host maintenance and patching
  • Load balancing to reduce resource contention
  • Evacuating a host with signs of failure
Checklist
  • Confirm migration network bandwidth and isolation
  • Check firewall rules allow migration ports
  • Validate CPU feature compatibility across hosts
Key Takeaway

Live migration prevents planned downtime but requires correct network and cluster settings to operate reliably.
