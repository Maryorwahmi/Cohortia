Module 8 › Chapter 7.8 › Migration Network
Setup

Provision a dedicated migration network or VLAN with high bandwidth and low latency. Avoid sharing it with heavy VM data traffic.

Diagnostic steps
  1. Ping and measure latency between hosts on migration interface
  2. Check Manager logs for migration error messages
  3. Validate firewall and port rules for migration traffic
Troubleshooting
  • Saturation: isolate migration traffic on its own NIC
  • Blocked ports: update firewall rules to allow migration
  • CPU mismatch: use CPU masking or compatible host sets
Pro Tip

Monitor migration bandwidth and limit concurrent migrations to avoid throughput collapse on shared links.
