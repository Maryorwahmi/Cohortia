Architecture

Monitoring • Storage • Fencing

Host Monitoring

VDSM agents report host health and resource metrics to Manager continuously.

Shared Storage

Disks must reside on a storage domain accessible by all hosts for HA to work smoothly.

Fencing

Use IPMI/Redfish to ensure failed hosts are powered off or isolated before failover.

Failure chain example
  1. VDSM detects host heartbeat loss
  2. Manager triggers fencing via power management
  3. After fencing success, Manager restarts VMs on healthy hosts using shared storage
Checklists & Tips
  • Verify VDSM agent connectivity and update intervals
  • Confirm storage domain access from every host
  • Test fencing credentials and simulate failure scenarios
Common Mistake

Assuming monitoring alone is sufficient. Fencing must be present to avoid split-brain.
