VDO › Chapter 1.3 › VDO Operations
Management steps
Create, format, mount, and monitor the VDO volume using vdo and vdostats.
  1. Create: sudo vdo create --name=myvdo --device=/dev/sdb --vdoLogicalSize=10T
  2. Format: sudo mkfs.xfs -K /dev/mapper/myvdo
  3. Mount: sudo mount /dev/mapper/myvdo /mnt/vdo_storage
  4. Verify: sudo vdostats --human-readable
Diagnostics
If issues arise, run vdo status, vdostats, and check dmesg for kernel messages. Confirm the vdo service and device mapper mappings are present.
Troubleshooting checklist
  • Is vdo service running and mapped? systemctl status vdo, vdo status
  • Is the underlying device healthy? Check smartctl or dmesg
  • Are CPU/memory adequate for dedupe/compression?
  • Are you using vdostats to measure savings rather than df?
Common Mistake

Stopping VDO without unmounting the mapped filesystem can corrupt the filesystem. Always unmount first.
