Learning Objectives
Part 1 — core storage skills and verification
Bloom: Learn → Understand → Apply → Master
01
Implement LVM snapshots
Create and merge snapshots for backups and testing, and monitor snapshot size to avoid overflow. VERIFIED COMPETENCY MILESTONE
Mnemonic: Venn of backup vs testing
02
Use VDO effectively
Deploy deduplication and compression and verify savings with vdostats to reduce physical storage usage. VERIFIED COMPETENCY MILESTONE
Mnemonic: Savings meter
03
Configure Stratis pools
Create pools and filesystems with stratis and use stratisd for simplified local storage workflows. VERIFIED COMPETENCY MILESTONE
Mnemonic: Pool → Filesystem
04
Troubleshoot connectivity & repair
Diagnose iSCSI and NFS client issues and use xfs_repair and fsck with the correct safety checks. VERIFIED COMPETENCY MILESTONE
Mnemonic: Check, Unmount, Repair
Each objective pairs a concrete command set with verification steps to ensure reliable operations in production.
