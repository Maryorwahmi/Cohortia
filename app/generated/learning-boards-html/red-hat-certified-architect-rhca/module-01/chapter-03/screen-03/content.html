Learning Objectives
Part 2 — encryption, repair, and verification
Bloom: Learn → Understand → Apply → Master
01
Implement LUKS
Encrypt a block device, open it with cryptsetup, and integrate with crypttab for boot unlock. VERIFIED COMPETENCY MILESTONE
Mnemonic: Encrypt → Open → Mount
02
Use repair tools safely
Run xfs_repair only on unmounted XFS filesystems; use fsck for ext family with appropriate flags. VERIFIED COMPETENCY MILESTONE
Mnemonic: Unmount first
03
Verify with status commands
Use lvs, vgs, pvs, cryptsetup status, df -h, and vdostats to confirm setup and health. VERIFIED COMPETENCY MILESTONE
Mnemonic: Check the outputs
Practice tip
Run the hands-on lab in a disposable VM and record commands and outputs for repeatable runbooks.
Each objective is paired with verification steps so you can demonstrate competency to peers or auditors.
