What VDO does
Block-level deduplication and compression for physical storage savings.
VDO creates a logical device larger than the physical backing store by hiding duplicate blocks and compressing unique data. This is ideal for workloads with repeated patterns such as VM images or container overlays. But it behaves like a block layer, so when you create a filesystem, the filesystem sees the VDO device as a regular block device. Because of this abstraction, tools that look at filesystem space will not reflect VDO savings; use vdostats to measure actual savings.
Create example
sudo vdo create --name=myvdo --device=/dev/sdb --vdoLogicalSize=10T
Verify
sudo vdostats --human-readable
When to use VDO
  • VM image stores or containers with many identical blocks.
  • Large datasets with redundant data patterns.
  • Not ideal when underlying device health or CPU/memory are constrained.
Key Takeaway

Use VDO to reduce physical storage when data patterns are redundant. Always verify savings with vdostats and monitor resource overhead.
