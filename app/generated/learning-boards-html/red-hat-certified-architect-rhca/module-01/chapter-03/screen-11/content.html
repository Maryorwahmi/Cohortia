Repair › Chapter 1.3 › xfs_repair & fsck
XFS repair rules
Use xfs_repair on unmounted XFS filesystems only. Consider -L only when necessary and after backups.
# Basic repair (unmounted)
sudo xfs_repair /dev/mapper/myxfs_vol

# Severe corruption (destructive)
sudo xfs_repair -L /dev/mapper/myxfs_vol
Precaution
If possible, take a block-level snapshot or backup before running destructive repair options.
fsck for non-XFS filesystems
fsck delegates to filesystem-specific checkers; prefer maintenance mode or unmounted state when possible.
  • Use fsck -n for a dry run when unsure.
  • During boot, fsck may run read-only checks; plan for downtime for repairs.
  • Always follow the filesystem-specific documentation for options and risks.
Warning

Never run xfs_repair on a mounted XFS filesystem. Doing so can make corruption worse or irrecoverable.
