Steps to create and restore
Follow these numbered steps carefully and verify each status output.
  1. Create snapshot: sudo lvcreate --size 1G --snapshot --name lv_critical_snap /dev/vg_appdata/lv_critical
  2. Verify with lvs: sudo lvs --options lv_name,lv_size,lv_attr,lv_mount
  3. Modify data: simulate changes in /mnt/appdata
  4. Unmount before merge: sudo umount /mnt/appdata
  5. Merge to restore: sudo lvconvert --merge /dev/vg_appdata/lv_critical_snap
  6. Remount and verify: sudo mount /dev/vg_appdata/lv_critical /mnt/appdata
Pro Tip

Use small, short-lived snapshots for application-level checkpoints and keep an eye on snapshot usage to avoid overflow.

Example scenario
# Create snapshot
sudo lvcreate --size 1G --snapshot --name lv_critical_snap /dev/vg_appdata/lv_critical

# Simulate change
sudo sh -c 'echo "Modified data after snapshot" >> /mnt/appdata/data.txt'

# Restore by merging
sudo umount /mnt/appdata
sudo lvconvert --merge /dev/vg_appdata/lv_critical_snap
# Remount and verify
sudo mount /dev/vg_appdata/lv_critical /mnt/appdata
cat /mnt/appdata/data.txt
Check your understanding
If the snapshot space fills, writes will fail. How would you prevent this? Answer: choose adequate snapshot size and keep snapshot lifetime short.
