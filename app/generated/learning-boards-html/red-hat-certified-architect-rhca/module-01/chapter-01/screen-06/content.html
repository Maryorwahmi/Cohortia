Module 1 › Chapter 1.1 › lsof Usage
Quick commands
# Show processes with port 8000 open
sudo lsof -i :8000

# Show all open files for a process and count them
sudo lsof -p 12345 | wc -l

# Show which process holds a specific file
sudo lsof /var/log/messages
Scenario
A database container fails with 'Too many open files'. Use lsof -p to count descriptors and confirm whether the service or runtime needs a higher LimitNOFILE.
Interpretation and pitfalls
  • High descriptor counts suggest leaks — track growth over time to confirm.
  • Descriptors held by libraries may be normal; inspect what type (socket, file, pipe) each descriptor represents.
  • Remember systemd and container runtimes may set different limits than your interactive shell.
Key Takeaway

lsof connects symptoms to process identities and descriptor types — vital when diagnosing leaks or held resources.
