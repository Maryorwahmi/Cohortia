Module 1 › Chapter 1.1 › strace Tracing
Attach and observe
# Attach to a running PID briefly (requires privileges)
sudo strace -p 12345

# Or trace a command from start and follow file/network calls
sudo strace -f -o /tmp/trace.log python3 -m http.server 8000
Example output (excerpt)
open("/var/log/app.log", O_WRONLY) = -1 EACCES (Permission denied)
Interpretation and tips
  • Look for repeated failing calls such as open or connect to find root causes.
  • Use the -f flag to follow child processes and -o to capture logs for post-analysis.
  • Remember strace influences timing — avoid long captures on production traffic.
Pro tip

Combine strace findings with lsof to map failing system calls to open descriptors and confirm the process identity.
