Starter commands (run on RHEL)
mkdir ~/web_app && cd ~/web_app
echo "Hello from Cohortia!" > index.html
nohup python3 -m http.server 8000 &
echo $! > ~/web_app/server.pid

# From a load client
ab -n 1000 -c 10 http://:8000/

# Monitoring samples
vmstat 1 5
iostat -xz 1 5
sar -u 1 5
When done, kill the server and clean the directory to leave the host tidy.
Inspection steps
  • Find the server PID and attach strace for a few seconds to observe system calls.
  • Use lsof -i :8000 to confirm listening sockets and lsof -p PID to count descriptors.
  • Compare vmstat and iostat outputs during the load to identify memory or I/O pressure.
Key Takeaway

This reproducible lab ties tools together so you can practice forming evidence-based hypotheses and safe remediations.
