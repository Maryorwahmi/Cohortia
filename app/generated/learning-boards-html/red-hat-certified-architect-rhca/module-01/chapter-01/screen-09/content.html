Module 1 › Chapter 1.1 › ss / netstat
Check listening sockets
# Show TCP/UDP sockets with process info
sudo ss -tunlp

# Filter for a specific port
sudo ss -tunlp | grep :80
Confirm the service is bound to the expected interface and port, and note the PID for further inspection.
Correlate with lsof and firewall
  • Use lsof -i :port to verify which process opened a socket.
  • Check firewall and container network settings if the socket is present but unreachable externally.
  • Remember container port mappings may differ from host bindings.
Key Takeaway

ss provides the authoritative host-level view of sockets; always correlate binding with runtime and firewall settings.
