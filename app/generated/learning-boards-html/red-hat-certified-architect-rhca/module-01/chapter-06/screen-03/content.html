Objective Actions
Structured Troubleshooting
Collect symptoms, form hypotheses, predict observable results, run targeted tests, and iterate until resolved.
sosreport
Run sudo sosreport, note the archive path, and treat the file as sensitive when sharing with support.
kdump
Verify kdump service, adjust crashkernel in GRUB, and confirm vmcore appears in /var/crash after a VM test panic.
journalctl & systemd
Use unit, priority, executable, kernel, and time filters; inspect unit files and properties to find misconfiguration.
Command Cheatsheet
journalctl -u <service> --since "5 minutes ago" -p err
sudo sosreport (collect archive; handle securely)
sudo systemctl status <service> and sudo systemctl show <service>
sudo systemctl status kdump and check /var/crash for vmcore
