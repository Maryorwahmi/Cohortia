Module 2 › Chapter 1.6 › sosreport
Definition & Purpose

sosreport gathers configuration, kernel and module data, networking and storage information, and logs into a single compressed archive for diagnostics or support cases. Use it to provide full context when targeted logs are insufficient.

Security Note
Because the archive may contain secrets or host-specific configuration, inspect and handle it using secure storage and transfer methods before sharing with support.
When to Run sosreport
  • Before large changes or upgrades.
  • When opening a support case with Red Hat.
  • To capture a baseline for comparison.
Run Example
sudo sosreport
# follow prompts; note the generated /var/tmp/xxxx-xxxx.tar.xz path
Inspect the archive before sharing and store it securely. Use the archive to accelerate support triage or to compare system states between working and failing hosts.
Key Takeaway

sosreport is a powerful evidence collector—use it when you need a full picture and always treat outputs as sensitive.
