Network Troubleshooting & Advanced Firewalling
Tools and patterns for diagnosing connectivity and applying granular firewall policies on RHEL systems.
Interactive 16:9 Masterclass
In this lesson
Packet capture, path diagnostics, routing, and firewall controls.

You'll practice tcpdump filters, interpret mtr statistics, inspect ip route/link output, and write firewalld rich and direct rules. We'll also review nftables basics for backend troubleshooting.

Why it matters
Reliable networks and minimal attack surfaces keep distributed apps running and secure in cloud environments.

A small misapplied rule or an overlooked route causes outages that are hard to diagnose without these combined skills.

Key Topics
tcpdump
Capture and filter packets to verify whether traffic reaches a host and how the host responds.
mtr
Continuous hop-by-hop latency and loss measurements to find problematic network segments.
firewalld & nft
Zones, rich and direct rules, and nftables basics to enforce least-privilege network access.
Visual Concept
Packet flow cards
Client → NAT / cloud edge → Load balancer → Server. Use tcpdump at endpoints and mtr across hops to find where packets drop.
Example
Web server cannot reach database on port 5432. Evidence set: ping results, mtr hop loss, tcpdump showing incoming SYN without server reply, and firewalld rich rules permitting or denying traffic.
Common pitfall
Forgetting --permanent when changing firewalld, or capturing without interface filters in tcpdump causing overwhelming output.
