Learning Objectives
Bloom band: Learn → Understand → Apply → Master
Learn → Apply
01
Diagnose complex connectivity
Use tcpdump, mtr, and ip route/link to decide if issues are client, server, or network related. Being methodical reduces false positives when racing to fix outages.
VERIFIED COMPETENCY MILESTONE
02
Analyze traffic patterns
Craft tcpdump filters to isolate relevant flows and spot anomalies, such as repeated retries or unexpected resets, and use captures for further inspection.
VERIFIED COMPETENCY MILESTONE
03
Configure advanced firewalld
Master zones, rich rules, and direct rules so you can enforce least privilege while keeping services available for legitimate clients.
VERIFIED COMPETENCY MILESTONE
04
Understand nftables fundamentals
Read and debug nft list ruleset output and know when to use direct nftables rules versus firewalld abstractions for maximum control.
VERIFIED COMPETENCY MILESTONE
