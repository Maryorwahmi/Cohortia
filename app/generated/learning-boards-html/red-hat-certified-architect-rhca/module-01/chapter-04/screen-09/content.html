nft command examples
# Add a simple accept rule for SSH in the filter table
sudo nft add rule ip filter input tcp dport 22 accept

# List the full ruleset
sudo nft list ruleset
Why nft matters
It replaces multiple legacy tools with a single, consistent backend and allows atomic updates to reduce transient policy gaps.
Key Takeaway

Learn to read nft list ruleset to map firewalld abstractions to concrete packet-handling rules and to debug backend behavior.

Practical notes
Mapping
After adding rich rules, run nft list ruleset to see how they appear in the ip filter table and which chains they occupy.
Misconception
nft is not merely syntax translation; it changes the management model by enabling atomic rule changes and unified tables.
Pro tip
When debugging, compare nft output before and after firewall-cmd changes to see the exact delta and reason about behavior.
