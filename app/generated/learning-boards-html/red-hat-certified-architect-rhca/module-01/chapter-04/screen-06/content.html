Module Network Security › Chapter Network Troubleshooting › ip commands
Commands and examples
ip link show
ip addr show
ip route show

# Add a temporary route for testing
sudo ip route add 10.0.0.0/8 via 192.168.1.1 dev eth0
Checklist
  • Interface state must be UP and carrier present.
  • IP address and prefix must match expected subnet.
  • Default gateway must exist for external reachability.
Misconception
Just because an interface is UP does not mean routing or gateway configuration is correct; always inspect routes explicitly.
Key Takeaway

Read the kernel view of interfaces, addresses, and routes first; that view determines packet forwarding and must be correct before other hypotheses are tested.

Scenario and example output
# Expected default route present
default via 192.168.1.1 dev eth0 proto static metric 100
10.0.0.0/8 dev eth0 proto kernel scope link src 10.0.2.5

# Missing default route example
# No 'default via' line: host cannot reach external networks
Action
If the default route is missing, add it temporarily to test and then make the permanent change in the network configuration scripts or network manager settings.
Pro tip
Document any temporary test routes and cleanup after troubleshooting to avoid accidental persistent debugging changes.
