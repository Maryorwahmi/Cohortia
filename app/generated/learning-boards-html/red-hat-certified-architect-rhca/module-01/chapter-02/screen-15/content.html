Module 1 › Chapter 1.2 › Key Concepts
Kernel Parameters (sysctl)
Runtime settings in /proc/sys. Use sysctl to inspect and set; persist under /etc/sysctl.d for reboot survival.
Kernel Modules
Loadable kernel code: inspect with lsmod/modinfo, manage with modprobe, and blacklist via /etc/modprobe.d when necessary.
tuned & GRUB
tuned groups settings into profiles; GRUB kernel args affect early boot and require careful testing and grub2-mkconfig updates.
Final takeaway

Adopt test-then-commit workflows, document all changes, and keep rescue paths ready when tuning kernel and boot settings.
