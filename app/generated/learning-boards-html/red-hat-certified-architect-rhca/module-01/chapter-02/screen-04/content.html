Module 1 › Chapter 1.2 › What are kernel parameters?
Concept
Runtime kernel settings that map to files under /proc/sys. They control networking, memory, security, and more.
Examples
  • vm.swappiness — how aggressively the kernel swaps memory to disk
  • fs.file-max — maximum number of file handles system-wide
  • kernel.sysrq — enable or disable SysRq debugging features
Misconception
Changing values directly under /proc/sys or with sysctl -w applies immediately but does not persist through a reboot unless written to a sysctl config file.
Key Takeaway

Use runtime changes to test, then commit validated settings to /etc/sysctl.d for persistence.

Terminal calls
# View all current parameters sysctl -a # View a specific parameter sysctl fs.file-max # Temporary change sudo sysctl -w vm.swappiness=10
Concrete example
To test reducing swap activity: temporarily set vm.swappiness to a lower value and monitor memory pressure and application latency before persisting.
