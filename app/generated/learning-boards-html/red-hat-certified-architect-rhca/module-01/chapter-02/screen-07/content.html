Why use modules?
Modules let you adapt kernel functionality for hardware, filesystems, and network features without a reboot, enabling more flexible administration.
# Inspect loaded modules lsmod # View module details modinfo bonding # Load a module (handles dependencies) sudo modprobe bonding
Concrete example
To enable network bonding for high-throughput applications, verify bonding is present with lsmod and load it with modprobe if required. Then confirm it supports your network stack.
Misconception

Unloading modules blindly can break running services. Check for usage and dependencies before removing modules in production.
