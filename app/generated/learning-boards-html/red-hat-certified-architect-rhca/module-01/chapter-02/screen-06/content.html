Module 1 › Chapter 1.2 › Persisting sysctl
Make validated settings persistent
Create descriptive files under /etc/sysctl.d and load them consistently across reboots.
Example file
# /etc/sysctl.d/90-swappiness.conf vm.swappiness = 10
Apply all sysctl files
Run sysctl --system to load files from /etc/sysctl.d, /run/sysctl.d, and /usr/lib/sysctl.d and apply their settings to the running kernel.
Pro Tip

Choose high numbers (90, 99) for custom files to ensure they override distribution defaults when intended.

Verification
After sysctl --system, confirm the effective value with sysctl parameter or by reading /proc/sys path.
