Blacklisting and ensuring early-boot effect
Prevent modules from autoloading and make sure they aren't present in initramfs.
# Example blacklist file # /etc/modprobe.d/blacklist-usb-storage.conf blacklist usb_storage # Rebuild initramfs so blacklist applies at early boot sudo dracut -f -v # Verify module does not load sudo modprobe usb_storage # should fail if properly blacklisted and initramfs rebuilt lsmod | grep usb_storage
Pro Tip

Use descriptive filenames and version control for modprobe.d entries so you can track why a module was blacklisted.

Concrete scenario
Security policy requires disabling usb_storage. Blacklist it, rebuild initramfs, attempt to load it manually to confirm, then validate on reboot in a test VM.
Common Mistake

Blacklisting without rebuilding initramfs can leave a module active during early boot, undermining the intended restriction.
