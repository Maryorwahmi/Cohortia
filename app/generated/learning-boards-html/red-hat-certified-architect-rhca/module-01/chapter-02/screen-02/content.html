Learning Objectives
Progress from inspection to persistent, profile-based tuning and safe boot-time changes.
01
Configure and persist sysctl
View and set kernel parameters using sysctl and persist them under /etc/sysctl.d for consistent system behavior.
VERIFIED COMPETENCY MILESTONE
02
Manage kernel modules
Load, unload, inspect, and blacklist modules; understand dependencies and initramfs implications.
VERIFIED COMPETENCY MILESTONE
03
Use tuned for workload profiles
Create and activate custom tuned profiles to apply grouped sysctl and system settings consistently.
VERIFIED COMPETENCY MILESTONE
04
Modify kernel boot parameters
Safely update GRUB kernel options, regenerate grub config, and test changes in a VM before production.
VERIFIED COMPETENCY MILESTONE
