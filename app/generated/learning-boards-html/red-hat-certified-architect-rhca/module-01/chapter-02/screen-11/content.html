Module 1 › Chapter 1.2 › Kernel boot parameters
Modify early boot behavior via GRUB
Kernel arguments provided by the bootloader affect system initialization and must be handled cautiously.
# Edit /etc/default/grub and then regenerate the grub config # BIOS systems sudo grub2-mkconfig -o /boot/grub2/grub.cfg # UEFI systems sudo grub2-mkconfig -o /boot/efi/EFI/redhat/grub.cfg # Example uses: rd.break for emergency shell, mem=XG to limit memory for testing
Warning

Incorrect GRUB configuration can prevent boot. Always copy existing grub config before editing and test in a VM snapshot.

Concrete troubleshooting scenario
If you need an early emergency shell to repair filesystems, add rd.break to kernel options, regenerate grub, and boot into the emergency environment to make repairs.
Key Takeaway

Treat GRUB changes like firmware edits: test, backup, and keep a rescue plan in case boot is impaired.
