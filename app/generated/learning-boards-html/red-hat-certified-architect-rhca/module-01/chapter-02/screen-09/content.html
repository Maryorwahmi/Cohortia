tuned: workload profiles
Use tuned to encapsulate system and kernel settings for specific workloads.
Built-in profiles
Examples include throughput-performance, latency-performance, and virtual-guest—choose one to match workload characteristics and toggles.
# Query tuned sudo tuned-adm list sudo tuned-adm active # Activate a profile sudo tuned-adm profile throughput-performance
Why use tuned?
It bundles sysctl, governor, and module settings so you can apply and manage optimizations at the workload level consistently across hosts.
Key Takeaway

tuned helps operationalize tuning by grouping related settings under named profiles you can activate and audit.
