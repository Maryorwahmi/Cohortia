Terminal walkthrough
Follow these steps in a VM snapshot and verify each result before proceeding.
# 1. Inspect current values sysctl fs.file-max sysctl vm.swappiness # 2. Persist fs.file-max sudo tee /etc/sysctl.d/90-file-max.conf <<EOF fs.file-max = 2097152 EOF sudo sysctl --system sysctl fs.file-max # 3. Persist vm.swappiness sudo tee /etc/sysctl.d/90-swappiness.conf <<EOF vm.swappiness = 10 EOF sudo sysctl --system sysctl vm.swappiness # 4. Ensure bonding module lsmod | grep bonding sudo modprobe bonding lsmod | grep bonding # 5. Blacklist dummy module and rebuild initramfs sudo tee /etc/modprobe.d/blacklist-my-dummy-module.conf <<EOF blacklist my_dummy_module EOF sudo dracut -f -v # 6. Create tuned profile sudo mkdir -p /etc/tuned/network-app-profile sudo tee /etc/tuned/network-app-profile/tuned.conf <<EOF [main] summary=Optimizations for network applications [sysctl] vm.swappiness=5 net.ipv4.tcp_tw_reuse=1 EOF sudo tuned-adm profile network-app-profile # Verify sysctl vm.swappiness sysctl net.ipv4.tcp_tw_reuse
Example validation
After persisting fs.file-max, use application logs and ulimit checks to confirm the server can open larger numbers of files under load.
Key Takeaway

Execute each step incrementally and verify after each change. Bundle proven changes into tuned profiles for repeatable deployment.
