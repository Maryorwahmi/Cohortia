What AIDE records
Attributes include ownership, permissions, size, timestamps, and cryptographic checksums. The configuration /etc/aide.conf controls monitored paths and attributes.
Initialize
sudo aide --init then move the generated aide.db.new.gz into /var/lib/aide/aide.db.gz.
Check
sudo aide --check to compare current state to the baseline and produce a report of differences.
Update
If changes are verified legitimate, update the database with sudo aide --update and replace the baseline after review.
Operational note
Run AIDE regularly via cron or scheduler and keep the database off the writable root filesystem if possible. If the baseline is writable by an attacker, alerts are less trustworthy.
Key Takeaway

AIDE is your forensic comparator. Treat unexpected changes seriously and preserve evidence when compromise is suspected.
