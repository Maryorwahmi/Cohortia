Module 1 › Chapter 1.5 › Hands-on Activity
Guided task checklist
Perform each step in a VM. Keep notes and preserve logs for later review.
SELinux custom policy
Create /opt/myapp/myapp.sh to write to /var/log/myapp, generate AVCs in permissive, run audit2allow, review the .te, and semodule -i after review.
AIDE workflow
Initialize baseline, make a small change to /etc/hosts, run aide --check, then aide --update after verification.
auditd monitoring
Add auditctl watches for passwd/shadow, change a password, and use ausearch -k to confirm the recorded event.
Safety reminders
Run this lab in an isolated VM. Preserve logs if you suspect tampering and do not update baselines until verified.
Key Takeaway

The combined practice of policy authoring, integrity checking, and audit monitoring builds confidence to detect and respond to changes safely.
