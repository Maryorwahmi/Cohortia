What auditd records and how
auditd captures kernel-level events and writes them to /var/log/audit/audit.log. Rules specify what to record and keys simplify searching.
Example rule
auditctl -w /etc/passwd -p wa -k user_auth_changes will log writes and attribute changes to /etc/passwd under the given key.
Search tools
Use ausearch -k user_auth_changes to find events and aureport for summaries and reports.
Operational caution
Design rules narrowly to avoid excessive noise and ensure log rotation to prevent disk exhaustion.
Concrete CLI
# watch /etc/passwd and /etc/shadow
auditctl -w /etc/passwd -p wa -k user_auth_changes
auditctl -w /etc/shadow -p wa -k user_auth_changes
# list rules
sudo auditctl -l
# search
sudo ausearch -k user_auth_changes -i
Key Takeaway

Use keys and focused rules so you can efficiently find the events that matter during investigations.
