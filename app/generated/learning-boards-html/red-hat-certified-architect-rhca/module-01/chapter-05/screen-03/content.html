Hands-on task mapping
Translate objectives into the practical steps you'll run in the lab environment.
SELinux Workflow
Generate AVC entries, run audit2allow to author a module, inspect the .te file, and semodule -i to install. Verify with getenforce and logs.
AIDE Lifecycle
aide --init, move baseline into place, aide --check after a controlled change, then aide --update once verified.
auditd Rules
Add watch rules for critical files, assign a key, then extract events with ausearch -k to validate capture.
OpenSCAP Scan
Run oscap xccdf eval to produce a report that lists pass/fail and suggested remediations.
Each operational step includes a verification stage: did the tool capture the expected event, and is the remedy minimal and reviewed before applying?
Quick Tip
Do work in VMs or isolated lab systems. Treat permissive mode as a diagnostic step, not a permanent setting.
