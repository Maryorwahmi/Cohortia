Module 1 › Chapter 1.5 › Hardening Practices
Operational hardening checklist
Apply the principle of least privilege, disable unnecessary services, enforce strong passwords, and automate patch management.
User policy
pam_pwquality settings, locked privileged accounts, and role separation.
Service security
Disable unused units and run services with minimal capabilities and accounts.
Runtime enforcement
Keep SELinux in enforcing and use targeted policies for exceptions.
Detection & logging
AIDE for integrity, auditd for events, and log rotation to sustain operations.
Example
When introducing a new web service, run it as an unprivileged user, ensure SELinux types map to its files, add an auditd rule for sensitive config files, and include it in OpenSCAP scans.
Key Takeaway

Hardening is layered work: apply small, reviewed changes across configuration, enforcement, detection, and compliance for resilient systems.
