Scan and report workflow
Choose a profile, run oscap eval, review the HTML report, and plan remediations with testing and change control.
# example scan (RHEL 8 SCAP content)
sudo oscap xccdf eval --profile standard --report report.html /usr/share/xml/scap/ssg/content/ssg-rhel8-ds.xml
# open report.html locally to review pass/fail and remediation guidance
Integrate scans into image pipelines so instances meet baseline requirements before deployment. Treat automated remediation as a last step after validation in staging environments.
Practical caution
OpenSCAP reports are snapshots. Use them in combination with runtime controls and audit logs to form a continuous security picture.
Key Takeaway

Use OpenSCAP for baseline measurement and CI gating, but test remediations thoroughly before applying in production.
