Definition

Contexts & Type Enforcement

A context labels resources with user:role:type:level. The type field enforces what can interact with what.

Inspecting contexts
Use ls -Z for files and ps -Z for processes to reveal their SELinux contexts.
Correcting labels
Declare persistent mappings with semanage fcontext and apply them with restorecon -Rv.
Example context
system_u:object_r:httpd_sys_content_t:s0 system_u:system_r:httpd_t:s0
The httpd process type httpd_t is checked against the file type httpd_sys_content_t by the policy.
Common mistake
Changing ownership or Unix permissions alone may not fix SELinux denials if the type is incorrect. Always verify and correct the context.
