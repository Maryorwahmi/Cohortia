Module 4 › Chapter 4.1 › SELinux Modes
Definition

Enforcing, Permissive, Disabled

Learn the safe workflow for mode changes and why permissive is for diagnostics only.

Enforcing
Blocks unauthorized actions and writes AVC denials to the audit log.
Permissive
Allows actions but logs the denials for analysis.
Disabled
Turns SELinux off. Avoid in production; it removes mandatory controls.
Common commands
getenforce
setenforce Permissive
setenforce Enforcing
# edit /etc/selinux/config for persistent mode
Guided example
If a web server write fails, switch to permissive, reproduce the write to generate AVC entries, then use those entries to build a minimal allow rule and return to enforcing once validated.
