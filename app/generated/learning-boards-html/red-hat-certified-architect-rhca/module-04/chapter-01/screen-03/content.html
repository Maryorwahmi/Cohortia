Practical Outcomes

Task-driven objectives so you leave with demonstrable SELinux capabilities.

Safe mode workflow
Use permissive to collect denials, then craft policy, test, and return to enforcing.
Context management
Set persistent file contexts with semanage fcontext and apply them with restorecon.
AVC triage
Extract subject, object, and class from audit entries and map to policy rules.
Module lifecycle
Generate .te, compile into .pp, install with semodule, and verify behavior under tests.
