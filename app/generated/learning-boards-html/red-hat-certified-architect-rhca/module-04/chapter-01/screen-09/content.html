Code Walkthrough

Generate a .te from AVC denials

Use audit2allow to translate collected denials into a starter Type Enforcement file, then review and tighten the rules.

Typical command
audit2allow -a /var/log/audit/audit.log -M myapp_httpd_log
Inspect .te
Open the generated myapp_httpd_log.te and verify the require block and allow statements are narrowly scoped.
Example .te snippet
module mycustom_httpd 1.0;

require {
  type httpd_t;
  type var_log_t;
  class file { append read write };
}

#============= httpd_t ==============
allow httpd_t var_log_t:file { append read write };
Review the file carefully and remove any allow statements that are broader than required.
Misconception
Do not install generated modules unmodified into production. Audit-generated suggestions are a starting point that you must refine for least privilege.
