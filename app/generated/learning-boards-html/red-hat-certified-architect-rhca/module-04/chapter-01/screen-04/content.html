Core Concept

MAC vs DAC

Understand why SELinux’s Mandatory Access Control complements ordinary Unix permissions and how that limits an attacker's reach.

Discretionary Access Control (DAC)
Owner-based permissions, changeable by users or root. Useful but insufficient against compromised services.
Mandatory Access Control (MAC)
System-enforced, label-driven policy that cannot be bypassed by users. SELinux is a MAC providing type enforcement.
Misconception
SELinux does not replace file permissions; it layers on top and enforces additional constraints based on types and contexts.
Scenario
A web server running as a service process obtains root via exploit. UNIX permissions may allow file access, but SELinux can stop the compromised process from reading or writing files outside its allowed types, limiting damage.
Check your understanding
  • Does SELinux replace owner-based permissions? No — it complements them.
  • Can root override SELinux policy by normal commands? No — policy is enforced at kernel level.
