Process

Compile and deploy a policy module

Use checkmodule, semodule_package, and semodule to build and install a policy. Keep policy sources under version control.

Commands
checkmodule -M -m -o mycustom_httpd.mod mycustom_httpd.te
semanage_package -o mycustom_httpd.pp -m mycustom_httpd.mod  # alternative name
semodule_package -o mycustom_httpd.pp -m mycustom_httpd.mod
semodule -i mycustom_httpd.pp
Verification
After install, replicate the action that originally caused the AVC and ensure no further denials, then check audit.log.
Rollback
Remove a module with semodule -r mycustom_httpd and keep .te files under source control to track changes.
Pro tip
Test modules in permissive first and prefer narrower file class permissions like append or write instead of broad directory writes.
