Module 4 › Chapter 4.1 › Lab: httpd logs
Hands-on Activity

Allow httpd to write to /opt/myapp/logs

Step 1 — Reproduce
Create the path and trigger a write to generate AVCs.
sudo mkdir -p /opt/myapp/logs
sudo touch /opt/myapp/logs/access.log
sudo -u apache touch /opt/myapp/logs/test_write.log
Step 2 — Collect
Use ausearch to extract relevant AVC entries.
ausearch -c httpd -m AVC -ts today
Step 3 — Generate
Create a draft policy with audit2allow and review it carefully.
audit2allow -a /var/log/audit/audit.log -M myapp_httpd_log
Step 4 — Compile & Install
Build the package and install it into the running policy.
checkmodule -M -m -o myapp_httpd.mod myapp_httpd.te
semodule_package -o myapp_httpd.pp -m myapp_httpd.mod
semodule -i myapp_httpd.pp
Step 5 — Verify
Re-run the write attempt and validate no AVCs remain, then setenforce 1 to re-enable enforcing behavior.
Optional — Relabel
If relabeling is preferred, declare a mapping and apply it.
semanage fcontext -a -t httpd_log_t "/opt/myapp/logs(/.*)?"
restorecon -Rv /opt/myapp/logs
