Learning Objectives

What you will be able to do and why each skill matters.

Learn → Understand → Apply → Master
01
Explain MAC vs DAC
Describe how SELinux’s Mandatory Access Control differs from owner-based permissions and why that strengthens the system.
Mnemonic: two concentric circles — owner control inside, system policy outside.
VERIFIED COMPETENCY MILESTONE
02
Manage modes and contexts
Use getenforce, setenforce, ls -Z, ps -Z, semanage, and restorecon to set and persist appropriate contexts and modes.
Mnemonic: map → label → restore.
VERIFIED COMPETENCY MILESTONE
03
Troubleshoot AVC denials
Analyze audit.log with ausearch and sealert to extract denying rules and suggested fixes.
Mnemonic: collect → read → act.
VERIFIED COMPETENCY MILESTONE
04
Create custom policy modules
Generate .te files with audit2allow, compile, package, and install modules while testing in permissive before enforcing.
Mnemonic: generate → compile → load.
VERIFIED COMPETENCY MILESTONE
