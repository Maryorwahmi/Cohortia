Best Practices

Least privilege and process

Least privilege
Grant specific file classes like append or write, not broad directory access.
Version control
Store .te sources and document policy rationale to support audits and rollbacks.
Common mistakes and fixes
  • Installing autogenerated modules without review — always inspect the .te first.
  • Using permissive as permanent state — collect data in permissive, then implement precise fixes and return to enforcing.
  • Granting broad permissions out of convenience — prefer targeted allow statements and relabeling where appropriate.
Operational checks
Use semodule -l to list modules, semodule -r to remove, and retest your application behavior after changes.
