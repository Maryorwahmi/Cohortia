Module 4 › Chapter 4.1 › Key Concepts
MAC vs DAC
MAC enforces system policies independent of file ownership; SELinux implements MAC.
SELinux Context
Labels use user:role:type:level; the type field drives Type Enforcement rules.
AVC Denial
Audit messages show scontext, tcontext, class, and requested permissions — the inputs for triage.
Policy Modules
Generate .te with audit2allow, compile and package, then install with semodule -i.
Context Management
Use semanage fcontext and restorecon to persist and apply labels.
Booleans & Controls
Booleans can toggle policy behavior, but changing them should be documented and limited.
Summary takeaway

SELinux enforces type-based rules. Triage via audit logs, prefer relabeling when logical, and craft narrow policy modules when needed. Test, document, and control changes.
