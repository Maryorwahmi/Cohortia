Architecture
Server and client roles
FreeIPA Server Components
LDAP (389): directory for users, hosts, groups, and policy.
Kerberos KDC: issues and validates authentication tickets.
DNS (BIND): publishes SRV records for service discovery.
NTP (Chrony): ensures time sync required by Kerberos.
CA (Dogtag): issues internal TLS certificates.
Client Behavior and Flow
Clients run SSSD for single sign-on. Typical flow:
  1. DNS SRV lookup finds IPA server.
  2. Client obtains Kerberos ticket from KDC.
  3. SSSD queries LDAP for user and group attributes.
  4. SSSD evaluates HBAC rules to allow or deny service access.
Common misconception

Replicas are active peers, not passive backups; design for multiple active servers to provide resilience.
