Preparing a server for installation
Preflight checklist
  • Set FQDN: sudo hostnamectl set-hostname ipa.example.com
  • Ensure static IP and resolvability (or temporary /etc/hosts entry)
  • Install packages: sudo dnf install -y ipa-server ipa-server-dns
  • Start NTP: enable and start chronyd to avoid Kerberos time issues
  • Verify open ports or allowed firewall rules for LDAP, Kerberos, DNS, HTTP
Why each step matters
DNS and FQDN ensure the installer can register records. NTP alignment is required because Kerberos tickets are time-sensitive. Package installation and port access let the installer provision services like the KDC and DNS. Missing any of these causes interactive failures or misconfigured services.
Common mistake

Skipping time sync or leaving DNS misconfigured is the most common cause of later authentication failures.
