Core Concept
What is FreeIPA?
An integrated identity management platform for Linux that ties authentication, directory, name resolution, time, and certificates together.
Quick Definition
Kerberos + LDAP + DNS + NTP + CA in one cohesive system.
Component cards
Kerberos: secure ticket-based authentication for services and users.
LDAP: the directory store for users, groups, host entries and policies.
DNS & NTP: service discovery and time sync required for reliable authentication.
CA: issues certificates for TLS between clients and services.
Example scenario
User authenticates on a client: the client obtains a Kerberos ticket, SSSD queries LDAP for groups and policies, then HBAC rules permit or deny the service access. If NTP is skewed or DNS SRV records are missing, the process fails.
Key Takeaway

FreeIPA is more than a directory; it is the coordinated services that enforce secure, discoverable authentication across many hosts.
