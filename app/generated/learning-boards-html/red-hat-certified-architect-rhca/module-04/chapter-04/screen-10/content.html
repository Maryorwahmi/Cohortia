Code Example
User and group management
# Create a user
ipa user-add jsmith --first=John --last=Smith --email=jsmith@example.com

# Modify or delete
ipa user-mod jsmith --setattr=description="Junior Admin"
ipa user-del jsmith

# Group management
ipa group-add developers
ipa group-add-member developers --users=jsmith,asmith
ipa group-find
Notes and verification
These commands modify LDAP entries that SSSD will present to clients during authentication. After adding a user, attempt to SSH to an enrolled client to validate account login and home directory creation.
Key Takeaway

Identity changes via ipa are authoritative and should be planned alongside HBAC and client settings for expected access behavior.
