Lab Walkthrough
Hands-on activity steps
Server checklist
  1. Set hostname and confirm resolvability.
  2. Install ipa-server and ipa-server-dns packages.
  3. Run ipa-server-install with DNS flags and strong passwords.
  4. Run kinit admin and confirm admin ticket.
Client and verification
  1. Set client hostname and /etc/resolv.conf to IPA DNS.
  2. Install ipa-client and run ipa-client-install --mkhomedir --enable-dns-autodiscovery.
  3. Create devuser and developers group; add user to group.
  4. Create HBAC rule and enable it, then test ssh login and home directory creation.
Verification commands: ipa user-find, ipa group-find, ssh devuser@localhost, pwd, ls -la ~
