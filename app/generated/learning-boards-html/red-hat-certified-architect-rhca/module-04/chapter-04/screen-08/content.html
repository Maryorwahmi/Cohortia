Definition
kinit and admin tickets
What kinit does
kinit authenticates a principal to the Kerberos KDC and obtains a ticket-granting ticket cached for the session. This ticket allows subsequent authenticated operations without re-entering passwords.
kinit admin
Practical notes
  • Use kinit before running ipa commands to ensure your session is authenticated.
  • Tickets expire; plan renewals or use keytabs for unattended machines.
  • kinit does not create accounts; it authenticates existing principals.
Key Takeaway

kinit admin is required to manage FreeIPA after install; handle ticket lifetimes in any automation.
