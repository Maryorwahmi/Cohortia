Enrolling a client
Canonical command
sudo ipa-client-install --mkhomedir --enable-dns-autodiscovery -p admin_password
--mkhomedir ensures home directories are created on first login; --enable-dns-autodiscovery uses SRV records to find IPA servers automatically.
Troubleshooting checklist
  • Verify /etc/resolv.conf points to IPA server for DNS resolution.
  • Test: host -t SRV _ldap._tcp.example.com to confirm SRV records.
  • Check firewall allows LDAP, KDC, and HTTP(S) to the IPA server.
  • Ensure CA certificate is accessible to the client during enrollment.
Key Takeaway

Client enrollment depends on resolvability and network access; when enrollment fails, verify DNS SRV records and firewall rules first.
