Command Walkthrough
ipa-server-install explained
Typical unattended command
sudo ipa-server-install \
  --ds-pwd="YourDirectoryManagerPassword" \
  --admin-pwd="YourAdminPassword" \
  --hostname=ipa.example.com \
  --domain=example.com \
  --realm=EXAMPLE.COM \
  --setup-dns \
  --auto-forwarders \
  --auto-reverse \
  -U
The installer will provision LDAP, KDC, DNS, NTP integration, and the internal CA. -U runs unattended for automation.
Post-install steps
  • Run kinit admin to obtain a Kerberos ticket for admin tasks.
  • Confirm DNS SRV records exist and resolve from clients.
  • Verify CA is issuing host/service certificates as expected.
Key Takeaway

Carefully review installer flags; automation is powerful but requires correct DNS and password handling.
