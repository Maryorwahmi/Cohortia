Quick command reference
Server Install
sudo ipa-server-install --setup-dns --domain=example.com --realm=EXAMPLE.COM -U
Client Enroll
sudo ipa-client-install --mkhomedir --enable-dns-autodiscovery -p admin_password
Identity & HBAC
ipa user-add, ipa group-add, ipa group-add-member, ipa hbacrule-add + add-user/host/service + enable
Final reminder

Use the DNS→NTP→Network→CA→SSSD order when diagnosing client enrollment and authentication problems to quickly find root causes.
