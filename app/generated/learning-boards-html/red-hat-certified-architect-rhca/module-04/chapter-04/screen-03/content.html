Module 4 › Chapter 4.4 › Practice Focus
Objective → Practice
  • Architecture: Map Kerberos, LDAP, DNS, NTP, CA to specific checks like SRV records and clock skew.
  • Server install: Ensure FQDN and static IP; populate /etc/hosts if DNS is pending.
  • Client enroll: Use --mkhomedir and DNS autodiscovery; verify with ssh and klist.
  • HBAC: Create group, add user, author HBAC rule to allow only required services.
Quick Mnemonics
DNS, NTP, CA — discovery, time, trust
SSSD + Kerberos — login and ticket validation
HBAC — who may connect where and to what
