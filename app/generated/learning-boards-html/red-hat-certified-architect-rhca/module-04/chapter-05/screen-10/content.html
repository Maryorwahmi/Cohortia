Core Concept › RBAC with sudo

Map roles to groups

Create groups named for roles and grant those groups the specific commands they need.

# Example: grant web_admins restart permission
%web_admins ALL=(root) NOPASSWD: /usr/bin/systemctl restart httpd.service
Comparison
Per-user: requires sudoers edits per person; prone to drift.
RBAC via groups: update group membership; sudoers is stable and auditable.
Key Takeaway

Prefer role groups over per-user rules so access changes are handled by group membership and audits become simpler.
