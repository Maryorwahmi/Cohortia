Learning Objectives

Bloom targets: Learn → Understand → Apply → Master
Verified Competency Milestone
01
Configure sudoers precisely

Write entries that allow a specific user or group to run only a defined command as a run-as user. This limits risk and follows least privilege.

Mnemonic: map user → runas → command
VERIFIED COMPETENCY MILESTONE
02
Use visudo for safe edits

Edit /etc/sudoers only through visudo so syntax is validated and accidental lockouts are prevented. It is a simple but essential habit.

Mnemonic: edit-safe-validate
VERIFIED COMPETENCY MILESTONE
03
Enable and verify sudo logging

Configure Defaults log_input, log_output when you need I/O capture, and verify entries in /var/log/secure and /var/log/sudo-io/.

Mnemonic: record everything
VERIFIED COMPETENCY MILESTONE
04
Design RBAC with groups and FreeIPA

Use group-based sudo rules or FreeIPA Sudo rules to assign roles and push consistent policies to clients via SSSD.

Mnemonic: assign roles, not users
VERIFIED COMPETENCY MILESTONE
