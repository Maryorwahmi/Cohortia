Process Flow › Designing Aliases
User_Alias
Group multiple user accounts into a role-like set for easier assignment.
Cmnd_Alias
Group related commands that a role should run, always with full paths.
Runas_Alias
Define which accounts commands may run as; useful for multi-account delegation.
User_Alias      WEB_ADMINS = john, mary
Cmnd_Alias      WEB_CMDS = /usr/bin/systemctl restart httpd.service, /usr/bin/systemctl status httpd.service
Runas_Alias     WEB_RUNAS = root
WEB_ADMINS ALL=(WEB_RUNAS) WEB_CMDS
Misconception
Aliases remove the need for precision. They do not; each command still requires full paths and careful argument limits.
Pro tip
Design alias names around roles like WEB_ADMINS so the sudoers file reads like policy documentation.
Key Takeaway

Use aliases to represent roles and related commands; keep aliases precise to retain safety.
