Assessment Review › Why option C
Correct configuration pattern
Cmnd_Alias NET_CMDS = /usr/sbin/ip addr show, /usr/sbin/ip route show
%network_team router01.example.com=(root) NOPASSWD: NET_CMDS
Defaults log_input, log_output
This approach uses an alias for clarity, scopes access to a host, uses full paths, and enables I/O logging for audit requirements.
Contrast: granting ALL or using wildcards is over-privilege and increases risk.
Key Takeaway

Explicit aliases plus logging meet compliance while minimizing privilege; avoid broad rules and wildcards.
