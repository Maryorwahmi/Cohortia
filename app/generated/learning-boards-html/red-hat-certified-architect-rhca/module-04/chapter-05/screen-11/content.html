Process Flow › FreeIPA Sudo Rules
Example sequence (conceptual)
ipa sudorule-add web_admin_restart --description="Allow web admins to restart httpd"
ipa sudorule-add-user web_admin_restart --groups=web_admins
ipa sudorule-add-host web_admin_restart --hostgroups=web_servers
ipa sudorule-add-cmd web_admin_restart --cmd="/usr/bin/systemctl restart httpd.service"
ipa sudorule-enable web_admin_restart
Define the rule, bind users or groups, scope it to hostgroups, add precise commands, then enable. Clients receive rules via SSSD.
Misconception: centralization eliminates careful rule design. It doesn’t—imprecise central rules scale poor practices faster.
Benefit
Single source of truth and consistent enforcement across enrolled hosts.
Check
Verify SSSD on clients and confirm sudo rules appear in /etc/sudoers or via getent sudoers.
