Example / Code › Sudoers snippets
Direct entries
# Allow 'john' to restart httpd on any host
john ALL=(root) /usr/bin/systemctl restart httpd.service

# Allow 'opsgroup' specific commands without password
%opsgroup ALL=(root) NOPASSWD: /usr/bin/systemctl restart httpd.service, /usr/bin/systemctl status httpd.service
Using aliases
User_Alias      ADMINS = john, mary
Cmnd_Alias      WEB_CMDS = /usr/bin/systemctl restart httpd.service, /usr/bin/systemctl status httpd.service
ADMINS ALL=(root) WEB_CMDS
Considerations
  • Reserve NOPASSWD for specific, low-risk commands to avoid removing an auth step.
  • Prefer aliases to reduce duplication and improve readability.
  • Validate changes with visudo before saving to avoid accidental lockouts.
Key Takeaway

Be explicit, prefer aliases, and use NOPASSWD sparingly while validating with visudo.
