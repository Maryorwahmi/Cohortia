Definition › Logging & I/O
Where sudo writes logs
  • /var/log/secure or /var/log/messages: default sudo events via syslog.
  • /var/log/sudo-io/: session I/O files when log_input and log_output are enabled.
Example log line
Mar 15 10:30:00 server sudo[12345]:    john : TTY=pts/0 ; PWD=/home/john ; USER=root ; COMMAND=/usr/bin/systemctl restart httpd.service
I/O logging
Add this to sudoers: Defaults log_input, log_output — files appear under /var/log/sudo-io/ and are replayable with sudoreplay.
Forensics
I/O capture shows what was typed and returned, which is invaluable for incident analysis.
Misconception

Logs alone are not enough; centralize and protect them to prevent tampering and to support searches.
