Definition › Sudoers structure

Key fields

  • User / Group: principal allowed to run commands. Groups use a % prefix.
  • Host: ALL or specific hostnames limit where the rule applies.
  • Runas: the account the command runs as, in parentheses.
  • Command: full path to the command and allowed arguments; avoid wildcards.
Examples
# Allow 'john' to restart httpd on any host
john ALL=(root) /usr/bin/systemctl restart httpd.service

# Allow 'opsgroup' two commands without password
%opsgroup ALL=(root) NOPASSWD: /usr/bin/systemctl restart httpd.service, /usr/bin/systemctl status httpd.service
Guidance and checks
  • Always specify full command paths to avoid PATH-based surprises.
  • Avoid broad ALL or wildcards in command lists; be specific about allowed arguments.
  • Remember rule order: earlier deny or restrictive rules take precedence.
Common mistake

Using wildcards or ALL for commands is a frequent cause of over-privilege. Be explicit.
