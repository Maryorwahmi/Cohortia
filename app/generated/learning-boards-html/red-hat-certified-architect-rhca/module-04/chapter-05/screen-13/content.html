Hands-on Activity › Lab starter
Starter commands
# 1. Create user
sudo useradd -m devops_junior
sudo passwd devops_junior

# 2. Edit sudoers with visudo and add:
# User_Alias      DEVOPS_JUNIORS = devops_junior
# Cmnd_Alias      NGINX_MGMT = /usr/bin/systemctl restart nginx.service, /usr/bin/systemctl status nginx.service
# DEVOPS_JUNIORS ALL=(root) NOPASSWD: NGINX_MGMT

# 3. Enable I/O logging in sudoers
# Defaults log_input, log_output
After saving, test by switching users and attempting allowed and denied commands, then inspect logs under /var/log/secure and /var/log/sudo-io/.
Testing checklist
  • su - devops_junior and run sudo /usr/bin/systemctl restart nginx.service (allowed)
  • Attempt sudo /usr/bin/systemctl stop nginx.service (should be denied)
  • As root, check sudo events in /var/log/secure and I/O files in /var/log/sudo-io/
  • Use sudoreplay to replay a captured session for investigation
Key Takeaway

Test allowed and denied commands and verify logs to ensure both least privilege and auditability.
