Module 4 › Chapter 4.2 › Direct Rules
Definition

Insert raw iptables/nftables rules

Direct rules allow expert users to place raw commands into the firewall chain with explicit priority and table/chain selection.

sudo firewall-cmd --direct --add-rule ipv4 filter INPUT 0 -s 192.168.1.0/24 -p tcp --dport 22 -j ACCEPT --permanent
sudo firewall-cmd --reload
Risks

Direct rules can conflict with generated rules, cause ordering issues, and bypass logging or abstractions; test with care and retain recovery access.

Migration pattern
Use direct rules temporarily when migrating legacy policies, but plan to convert them to rich rules or ipsets for maintainability.
Always set a low-priority number carefully; 0 is high precedence and may preempt other rules.
Key Takeaway

Only use direct rules when absolutely necessary, and fully document and test their interaction with firewalld-generated rules.
