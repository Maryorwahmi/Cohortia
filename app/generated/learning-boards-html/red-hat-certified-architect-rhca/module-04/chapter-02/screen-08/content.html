Module 4 › Chapter 4.2 › Masquerading
Definition

Source NAT with masquerade

Translate outgoing packets' source to the firewall's public IP so private hosts can reach external networks.

sudo firewall-cmd --zone=public --add-masquerade --permanent
sudo firewall-cmd --reload
When to use

Enable when internal private IPs need internet access through a single public IP on the firewall.

Example and testing
Enable masquerade, then from an internal host attempt to download or ping an external server to validate translation and return flow.
# Enable masquerade and reload
sudo firewall-cmd --zone=public --add-masquerade --permanent
sudo firewall-cmd --reload

# From an internal host: verify outbound connectivity
curl -I https://example.com
Common Mistake

Forgetting masquerade after setting up forwarding or expecting return packets to reach internal hosts will cause asymmetric routing failures.
