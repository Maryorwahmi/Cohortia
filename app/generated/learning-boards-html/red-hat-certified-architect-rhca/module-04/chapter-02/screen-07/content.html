Module 4 › Chapter 4.2 › Port Forwarding
Definition

Destination NAT with add-forward-port

Redirect an incoming public port to an internal IP and port so services can be hosted behind a firewall/router.

sudo firewall-cmd --zone=public --add-forward-port=port=80:proto=tcp:toport=80:toaddr=192.168.1.50 --permanent
sudo firewall-cmd --reload
Why it matters

Forwarding lets you host services privately while exposing only specific ports, reducing attack surface on internal hosts.

Checklist & example
  1. Apply forwarding to the incoming (public) zone.
  2. Confirm routing and internal host firewall allow traffic.
  3. Enable masquerade if return path requires SNAT.
# Forward 443 to localhost:80
sudo firewall-cmd --zone=public --add-forward-port=port=443:proto=tcp:toport=80:toaddr=127.0.0.1 --permanent
sudo firewall-cmd --reload
Common Mistake

Not applying forwarding to the correct zone or forgetting masquerade often breaks connectivity. Verify external tests and logs.
