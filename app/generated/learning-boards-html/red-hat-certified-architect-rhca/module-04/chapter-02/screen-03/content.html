Lab-ready objectives

Commands and checks you will execute in the hands-on activity.

Verify and assign zones
Use systemctl to enable firewalld and firewall-cmd to list active zones and bind interfaces so traffic follows intended policies.
sudo systemctl enable --now firewalld
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=internal --change-interface=eth1 --permanent
Rich rules with logging
Create precise allow, reject or drop rules and add a log prefix to capture attempts for analysis.
sudo firewall-cmd --zone=public --add-rich-rule='rule family="ipv4" source address="192.168.1.100" service name="ssh" accept' --permanent
IP sets
Create named ipsets, add entries, and reference them in rules for efficient updates.
sudo firewall-cmd --permanent --new-ipset=trusted-hosts --type=hash:ip
sudo firewall-cmd --permanent --ipset=trusted-hosts --add-entry=192.168.1.100
NAT and forwarding
Use add-forward-port for DNAT and add-masquerade for SNAT on outward-facing zones when needed.
sudo firewall-cmd --zone=public --add-forward-port=port=80:proto=tcp:toport=80:toaddr=192.168.1.50 --permanent
sudo firewall-cmd --zone=public --add-masquerade --permanent
