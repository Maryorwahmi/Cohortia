Configure firewalld zones
Assign interfaces and sources to zones to enforce trust boundaries. This reduces exposure by applying appropriate defaults per network segment.

Implement rich rules
Write fine-grained rules that reference source, destination, ports, services and logging for least-privilege access and auditability.
Mnemonic: Filter with a magnifier — exact match
VERIFIED COMPETENCY MILESTONE

Use IP sets
Create named sets of IPs or networks and reference them from rules to simplify updates and improve performance in dynamic environments.
Mnemonic: Address book for rules
VERIFIED COMPETENCY MILESTONE

Configure NAT and direct rules
