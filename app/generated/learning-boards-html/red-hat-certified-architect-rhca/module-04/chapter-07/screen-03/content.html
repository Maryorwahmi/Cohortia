Verification and troubleshooting

We emphasize measurable checks: create a rule, generate the event, and run ausearch and aureport to confirm. On rsyslog, verify that TLS is accepted by the server and certificates match expected common names. Also confirm logrotate policies actually compress and remove old logs according to retention policy.

Test 01
Generate a controlled edit and search by key to confirm auditd captured it.
Test 02
Run aureport to summarize failed authentications for the day.
Test 03
Send an authpriv message and confirm the remote server received it over TLS.
Key Takeaway

Verification steps are as important as configuration. Without testing, rules and forwarding can fail silently.
