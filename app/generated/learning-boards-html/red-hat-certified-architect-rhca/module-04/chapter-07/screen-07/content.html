Module 5 › Chapter 4.7 › Operational Pitfalls
Load & persist
Always place rule files under /etc/audit/rules.d and use the loader to apply them. This ensures rules survive restarts and are managed via configuration tools.
Checklist
  • Save rules to rules.d with clear names
  • Run the loader after editing
  • Validate events with ausearch
Avoiding volume problems
Design rules with filters and keys, and plan log rotation and remote forwarding. Monitor disk usage and set alerts to prevent full volumes.
Pro tip
Start with a small rule set in production, measure event rates, then expand carefully — this prevents surprises.
