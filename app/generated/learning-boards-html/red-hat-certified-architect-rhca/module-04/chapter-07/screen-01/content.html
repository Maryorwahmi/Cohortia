In this lesson
Design a secure, auditable logging pipeline with auditd and rsyslog

We start with a conceptual view of roles: auditd captures kernel-level security events, while rsyslog aggregates application and system logs. Together they enable immutable event records and centralized analysis required by compliance frameworks.

Auditd
Kernel-level events, system calls, file access. Writes to /var/log/audit/audit.log.
Rsyslog
Central collector and forwarder. Use TLS for secure transport to a remote server.
What you will do
Write rules, trigger events, search logs, and enable TLS forwarding.
Starter tasks
  • Create targeted auditd rules for passwd and sudo activity.
  • Search the audit log using ausearch and summarize with aureport.
  • Configure rsyslog client to forward authpriv logs with TLS.
Why it matters
Proper auditing enables investigations and provides evidence required by compliance regulations.
Explore Key Topics
Audit rules, log analysis, and secure forwarding are the three pillars you will practice.
