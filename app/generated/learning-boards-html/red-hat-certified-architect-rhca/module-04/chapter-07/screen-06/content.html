Starter rules (file)
# Monitor all write access to /etc/passwd and /etc/shadow
-w /etc/passwd -p wa -k passwd_changes
-w /etc/shadow -p wa -k shadow_changes

# Monitor execve for sudo
-a always,exit -F arch=b64 -S execve -F path=/usr/bin/sudo -k sudo_exec
Save the file to /etc/audit/rules.d/99-custom.rules and run the loader to apply changes.
Validation steps
  1. Create the rule file and save it under rules.d.
  2. Run the rules loader command to apply rules.
  3. Trigger events such as a touch or a sudo command.
  4. Use ausearch with the key to find matching events.
Common mistake
Avoid creating overly broad syscall rules without filters; they will flood audit logs.
