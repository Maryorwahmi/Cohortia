Starter Commands (conceptual)
Follow this loop: create rules file, run loader, trigger actions, search with ausearch, and confirm forwarding with rsyslog server logs. The chapter provides starter commands to seed your lab environment and an example rsyslog client snippet to enable TLS forwarding.
Test actions
Touch or edit the target files and run privileged commands to create events for verification.
Verification
Use ausearch with keys and aureport summaries; check the remote collector for forwarded authpriv messages.
