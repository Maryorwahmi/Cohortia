Module 5 › Chapter 4.7 › auditd Basics
Definition

Auditd captures syscall and file access events at the kernel level and writes them to an authoritative audit log. Events include who did what, when, and with which process context.

Example
A watch on /etc/passwd will create events when processes attempt to write or change file attributes, recording UID, PID, and timestamps.
Misconception
Auditd does not replace syslog. It complements syslog by providing kernel-level security data.
Key Takeaway

Use auditd for high-fidelity security events; keep rules targeted to avoid noise.

Annotated event fields
  • Timestamp and event type (audit record types)
  • Record metadata: PID, UID, EUID, AUid
  • System call or watched path and permission flags
  • Custom key for grouping related events
Practical check
Ensure /var/log/audit exists on immutable or well-monitored storage and verify auditd is running and receiving kernel events.
