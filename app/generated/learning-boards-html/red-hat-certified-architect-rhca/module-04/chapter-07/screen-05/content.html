Rule patterns
Two core patterns: file watches with -w and syscall rules with -a and -S. Combine permissions, arch, uid filters and a key.
-w /etc/passwd -p wa -k passwd_changes
-a always,exit -F arch=b64 -S execve -F euid=0 -k root_commands
-a always,exit -F arch=b64 -S open -F success=0 -k failed_writes
Note: Use a custom key to make searches simpler and limit syscall rules by arch and uid filters.
Practical guidance
  • Prefer targeted watches for sensitive files over broad syscall coverage.
  • Include success or failure filters when you care about outcome.
  • Attach distinct keys for rule classes to ease ausearch queries.
Check your understanding
What key would you use to find all passwd change events? Answer: the key you set, for example passwd_changes.
