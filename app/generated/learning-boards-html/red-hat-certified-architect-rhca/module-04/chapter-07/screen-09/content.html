Module 5 › Chapter 4.7 › aureport
Typical commands
# Summary for today
aureport --start today -ts 00:00:00 --end now --summary

# Show failed events
aureport -i --start today --failed
Use the interactive flag for more readable identifiers when available.
Operational use
Schedule regular reports for compliance windows and integrate their outputs into incident tickets when anomalies appear.
Pro tip
Combine aureport outputs with centralized log parsing to create dashboards for recurring audit metrics.
