Module 5 › Chapter 4.7 › ausearch
Common search patterns
# Search by key
ausearch -k passwd_changes

# Search for failed authentication
ausearch -m USER_AUTH -sv no
Use keys as your primary search handle. Combine multiple filters for precise results.
Reading results
ausearch returns low-level records. Look for the audit message type, PID, UID, and syscall-specific fields to reconstruct the action.
Misconception
ausearch is not a reporting tool. Use it to find raw events, then summarize with aureport if you need aggregated metrics.
