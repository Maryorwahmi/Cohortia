Module 04 › Chapter 4.3 › Hands-on: Flask
Step checklist
  1. Create user and log directory, set ownership.
  2. Install the app and create a unit file to run as that user.
  3. Enable PrivateTmp and ProtectSystem and restart the service.
  4. Add ProtectHome and NoNewPrivileges, then test filesystem access.
  5. Apply capability drops and network restrictions, then test functionality.
  6. Set MemoryLimit and TasksMax, then load-test and observe behavior.
Verification commands (conceptual)
Use systemctl status and journalctl -u your-service to observe startup errors, permission denials, and OOM or task-limit messages. Use curl to test endpoints and tail logs to confirm writes.
Pro Tip

Document each restriction and the reason for it so future maintainers can understand why a write path or capability was allowed.
