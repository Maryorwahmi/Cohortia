Module 04 › Chapter 4.3 › cgroups & limits
Recommended directives
  • CPUAccounting=true & MemoryAccounting=true — enable observation.
  • CPUShares=100 — relative CPU share.
  • MemoryLimit=500M — hard memory cap.
  • IOAccounting=true & IOWeight=100 — control I/O priority.
  • TasksMax=100 — limit process/thread counts.
Practical scenario
If a database service crashes due to excessive memory, set MemoryLimit and monitor for OOM messages. Use TasksMax to prevent fork bombs. Adjust limits in staging before production.
Key Takeaway

cgroups keep a misbehaving service from impacting others; enable accounting then apply guarded limits and monitor.
