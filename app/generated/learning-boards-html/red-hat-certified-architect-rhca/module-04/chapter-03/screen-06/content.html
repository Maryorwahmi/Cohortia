Module 04 › Chapter 4.3 › Capabilities & NoNewPrivileges
NoNewPrivileges=true
Blocks gaining privileges via setuid/setgid. Use it as a baseline protection for most services.
Misconception
It's not a substitute for dropping capabilities; it only prevents new privilege grants, not existing capabilities.
CapabilityBoundingSet
Remove specific capabilities with a tilde prefix, for example ~CAP_SYS_ADMIN. Test each removal to ensure the service still performs required actions.
Example
Drop CAP_NET_RAW for ordinary servers that don't need raw sockets; keep it only for packet capture tools.
