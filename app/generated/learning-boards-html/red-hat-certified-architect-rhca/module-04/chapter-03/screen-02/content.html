Module 04 › Chapter 4.3 › Learning Objectives
01
Apply systemd hardening
Choose and configure unit directives to minimize service privileges and exposure. Practice: add PrivateTmp and ProtectSystem to a test unit and verify behavior.
VERIFIED COMPETENCY MILESTONE
02
Configure cgroup limits
Enable accounting and set MemoryLimit, TasksMax and IOWeight to prevent resource exhaustion. Practice: set MemoryLimit on a demo service and observe it being culled when exceeding the limit.
VERIFIED COMPETENCY MILESTONE
03
Implement sandboxing features
Use ProtectHome, ProtectSystem, and NoNewPrivileges to shrink a service's access to the filesystem and privilege gains. Practice: restrict a static file server with ProtectHome and test file access attempts.
VERIFIED COMPETENCY MILESTONE
04
Limit capabilities & network families
Apply CapabilityBoundingSet and RestrictAddressFamilies so services only use needed capabilities and protocols. Practice: remove CAP_NET_RAW and observe a packet-capture tool fail as expected.
VERIFIED COMPETENCY MILESTONE
