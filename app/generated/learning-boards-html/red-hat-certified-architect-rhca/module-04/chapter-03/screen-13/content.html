Module 04 › Chapter 4.3 › Assessment reasoning
Scenario requirements
  • Limit RAM to 1 GB.
  • Prevent modification of system files.
  • Allow writes only to data and log directories.
Recommended directives
MemoryLimit=1G, ProtectSystem=full, ProtectHome=true, ReadWritePaths=/var/lib/db_server /var/log/db_server
Key Takeaway

Directives should be chosen to directly satisfy the stated requirement; map needs to controls and test them.
