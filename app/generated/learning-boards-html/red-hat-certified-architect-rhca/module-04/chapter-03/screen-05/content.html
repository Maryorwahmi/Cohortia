Module 04 › Chapter 4.3 › Filesystem directives
Process: enable and test
  1. Audit what paths the service reads and writes.
  2. Enable PrivateTmp=true and confirm temp files are isolated.
  3. Enable ProtectSystem and add ReadWritePaths for needed writable directories.
  4. Enable ProtectHome and confirm access to /home is blocked unless explicit access is granted.
Testing example
Run the service, attempt to create a file in /etc from the service context. With ProtectSystem active it should be denied; if the service needs that write, add a ReadWritePaths entry instead of disabling ProtectSystem entirely.
Common mistake

Over-restricting before testing causes failures. Add restrictions gradually and add precise exceptions when required.
