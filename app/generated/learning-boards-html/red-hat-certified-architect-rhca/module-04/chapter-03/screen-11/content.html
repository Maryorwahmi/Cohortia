Module 04 › Chapter 4.3 › Common mistakes
Symptoms
  • Service fails to start after adding a directive.
  • Operation not permitted errors in journal logs.
  • Network operations fail unexpectedly.
Recovery steps
  1. Check systemctl status and journalctl for specific errors.
  2. Temporarily relax one directive to confirm cause.
  3. Add a targeted ReadWritePaths or restore a capability if needed.
  4. Reapply protections and retest in staging.
Danger

Avoid running services as root to bypass restrictions; instead restore only the minimal capability required.
