Definition › Integrity controls
dm-integrity
Adds per-block checksums. Verify on read, update checksum on write. Good for detecting silent corruption.
Plan storage layout and performance tradeoffs; integrity metadata consumes space and affects I/O patterns.
dm-verity
A read-only hash-tree verification layer. Useful for immutable root images to guarantee they match a known root hash.
Use dm-verity when you need verifiable read-only images; combine with secure boot or signed root hashes for stronger guarantees.
Example concern
If layering integrity under encryption, ensure the integrity metadata itself is protected and available at the correct layer during boot.
Key Takeaway
Use integrity controls to detect tampering or corruption, but combine them with backups and careful layering with encryption.
