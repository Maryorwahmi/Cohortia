Step-by-step timeline
  1. Prepare: fallocate, losetup to create /dev/loop0.
  2. Encrypt: sudo cryptsetup luksFormat /dev/loop0 and set passphrase.
  3. Key file: dd from /dev/urandom, chmod 0400, luksAddKey with the file.
  4. Open & fs: luksOpen with --key-file, mkfs.ext4, mount to /data.
  5. Configure: get LUKS UUID, add crypttab entry, add fstab mount, run dracut -f.
  6. Verify: umount, luksClose, start systemd-cryptsetup service or reboot, mount should appear.
Starter commands
sudo fallocate -l 1G /tmp/disk.img
sudo losetup /dev/loop0 /tmp/disk.img
DEVICE=/dev/loop0
sudo cryptsetup luksFormat $DEVICE
sudo dd if=/dev/urandom of=/root/luks_key.bin bs=512 count=4
sudo chmod 0400 /root/luks_key.bin
sudo cryptsetup luksAddKey $DEVICE /root/luks_key.bin
LUKS_UUID=$(sudo cryptsetup luksUUID $DEVICE)
echo "myencryptedvolume UUID=$LUKS_UUID /root/luks_key.bin luks" | sudo tee -a /etc/crypttab
sudo dracut -f
# Test: umount, luksClose, then start service or reboot
