Architecture › Clevis & Tang
Binding workflow
Install Tang on a server and enable the socket. On clients, install Clevis and bind the LUKS device to Tang to enable NBDE.
Server
Install tang and start tangd.socket so the server can publish keys.
Client
sudo clevis luks bind -d /dev/sdb1 tang '{"url":"http://tang.example.com"}'
Operational notes
  • Ensure dracut integration so Clevis unlocks in initramfs.
  • Provide a recovery path in case the client cannot reach Tang.
  • Use network isolation and firewalling to protect Tang.
