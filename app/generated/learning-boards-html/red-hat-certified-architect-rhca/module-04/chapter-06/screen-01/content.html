Disk Encryption with LUKS
Secure block devices, automate unlocking, and add integrity checks.
This chapter shows the full workflow you will use in labs and production: initialize a LUKS header, open and close volumes, manage key slots, add key files for automation, configure crypttab, bind to Clevis and Tang for NBDE, and introduce dm-integrity and dm-verity for integrity protection. Practical commands and a hands-on scenario are included for guided practice.

Concept map
LUKS sits on a block device. Key slots hold passphrases or key files. crypttab or Clevis handles unlocking. dm-integrity and dm-verity add integrity checks.
Quick commands
sudo cryptsetup luksFormat /dev/sdb1
sudo cryptsetup luksOpen /dev/sdb1 myencryptedvolume
sudo cryptsetup luksClose myencryptedvolume
