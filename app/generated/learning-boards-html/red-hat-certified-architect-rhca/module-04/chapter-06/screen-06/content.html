Definition › Key slots & key files
Add and remove keys
Commands for key slot management and a secure key file example.
sudo dd if=/dev/urandom of=/root/luks_key.bin bs=512 count=4
sudo chmod 0400 /root/luks_key.bin
sudo cryptsetup luksAddKey /dev/sdb1 /root/luks_key.bin
sudo cryptsetup luksRemoveKey /dev/sdb1
Use luksAddKey to add either an interactive passphrase or a specified key file. luksRemoveKey prompts for an existing credential to verify.
Compare: passphrase vs key file
Passphrase: human-readable recovery method, requires manual entry at boot.
Key file: supports automation, must be stored with at least file-system level protection and preferably on encrypted media.
Misconception check
Multiple slots do not weaken encryption if keys are managed correctly. Each slot is an access method to the same encrypted data.
