Process › Format & open
Terminal walkthrough
Run these commands on a loop device or spare partition to avoid data loss.
sudo fallocate -l 1G /tmp/disk.img
sudo losetup /dev/loop0 /tmp/disk.img
DEVICE=/dev/loop0
sudo cryptsetup luksFormat $DEVICE
sudo cryptsetup luksOpen $DEVICE myencryptedvolume
sudo mkfs.ext4 /dev/mapper/myencryptedvolume
sudo mkdir -p /data
sudo mount /dev/mapper/myencryptedvolume /data
# After use
sudo umount /data
sudo cryptsetup luksClose myencryptedvolume
Explanation bullets
  • luksFormat writes the LUKS header and will destroy existing data on the device.
  • luksOpen maps a device to /dev/mapper/name for normal use.
  • mkfs and mount operate on the mapped device, not the encrypted underlying device.
  • Always umount before luksClose to avoid corruption.
Pro tip
Use a loop file in a lab environment to practice these steps safely and to script verification without risking production drives.
