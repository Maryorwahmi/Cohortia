LUKS header and key slots
The header stores parameters and slots; slots map credentials to the master key material.
Up to 8 key slots allow multiple passphrases or key files to unlock the same volume.
The header is essential: losing it usually means permanent data loss.
Key slots do not duplicate data; they enable access methods to the same master key.
Analogy
Think of LUKS as a locked safe. The safe holds the contents. Key slots are separate keys on the same lock mechanism; destroying the lock mechanism — the header — disables all keys.
Example commands
sudo cryptsetup luksFormat /dev/sdb1
sudo cryptsetup luksOpen /dev/sdb1 myencryptedvolume
sudo cryptsetup luksDump /dev/sdb1
Key Takeaway

Use multiple key slots for flexibility, but protect the header and back it up if required by policy.
