Verification tasks
  • luksDump to inspect key slots and status.
  • Use cryptsetup luksUUID to get the LUKS UUID for crypttab entries.
  • Simulate reboot: unmount, luksClose, then start the systemd-cryptsetup unit and mount to confirm.
  • Run dracut -f after adding Clevis so initramfs contains unlock logic.
Common mistake

Closing a LUKS device while a filesystem is mounted can corrupt data. Always unmount first.

Hands-on verification snippets
sudo cryptsetup luksDump /dev/loop0
sudo cryptsetup luksUUID /dev/loop0
sudo systemctl start systemd-cryptsetup@myencryptedvolume.service
ls -la /data
Use these checks after each change to confirm behavior before relying on automation.
