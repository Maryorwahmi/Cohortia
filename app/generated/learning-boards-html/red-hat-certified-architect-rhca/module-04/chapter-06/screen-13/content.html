Verify after changes
Use luksDump, luksUUID, and systemctl checks to confirm configuration.
Common errors
Never close a mapped device while the filesystem is mounted; always run dracut after adding unlock mechanisms.
Integrity + backups
Treat integrity tools as detectors, not substitutes for backups; back up headers and keys.
