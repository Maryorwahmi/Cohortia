Bonding Modes

Mode 1: Active-Backup

Only one slave interface is active at a time; others are standby for fault tolerance.

  • Provides fault tolerance against single link failures.
  • No special switch configuration is required.
  • Only one NIC's bandwidth is utilized at a time.
How Active-Backup Works

Active Slave: Handles all network traffic.

Backup Slaves: Monitor the active slave and take over upon failure.

Failover: Automatic and transparent to applications, ensuring continuous connectivity.

Use Case: Management Interface

Active-backup is ideal for a server's management interface, where consistent access is more important than maximizing bandwidth. If one link fails, you still have access to manage the server.

Key Takeaway

Active-backup bonding provides robust fault tolerance with minimal configuration, making it a reliable choice for basic network redundancy.
