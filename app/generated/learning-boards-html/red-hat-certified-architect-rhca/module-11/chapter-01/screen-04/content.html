Core Concept

IP Aliasing

Assigning multiple IP addresses to a single physical network interface.

  • Enables a single NIC to host multiple services.
  • Facilitates seamless service migration between IP ranges.
  • Optimizes hardware usage by avoiding extra physical interfaces.
Temporary Configuration with `ip`

The ip command provides a quick, but non-persistent, way to add an IP alias.

# Add secondary IP 192.168.1.100/24 to enp1s0
sudo ip addr add 192.168.1.100/24 dev enp1s0

# Verify the configuration
ip addr show enp1s0
Common Mistake

Forgetting that ip addr add changes are temporary and will be lost after a reboot or network service restart.

Scenario: Web Server Migration

A web server needs to respond to requests on both its old IP (192.168.1.50) and a new IP (192.168.1.100) during a transition period. IP aliasing allows this without downtime.

Key Takeaway

IP aliasing is a flexible way to manage multiple IP addresses on a single interface, but use nmcli for persistent configurations.
