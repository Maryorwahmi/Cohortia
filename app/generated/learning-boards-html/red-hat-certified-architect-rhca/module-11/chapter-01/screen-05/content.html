Persistent IP Aliasing with `nmcli`

NetworkManager provides a robust way to manage persistent IP aliases through connection profiles.

  • Ensures configurations survive reboots.
  • Leverages NetworkManager's connection-based approach.
  • Provides better organization and manageability for complex IP setups.
`nmcli` Commands for Persistent Alias

Create a new connection profile for the alias, linking it to the physical interface.

# Add a new connection for the alias
sudo nmcli connection add type ethernet con-name enp1s0-alias ifname enp1s0 ip4 192.168.1.100/24

# Modify the connection to use manual IP method
sudo nmcli connection modify enp1s0-alias ipv4.method manual ipv4.addresses 192.168.1.100/24

# Bring up the alias connection
sudo nmcli connection up enp1s0-alias

# Verify IP addresses
ip addr show enp1s0
Why `nmcli` is Preferred

NetworkManager handles the lifecycle of network connections, ensuring that aliases are correctly brought up and managed alongside the primary interface. This prevents conflicts and ensures consistent network behavior.

Key Takeaway

Always use nmcli for persistent network configurations in RHEL to ensure reliability and proper integration with NetworkManager.
