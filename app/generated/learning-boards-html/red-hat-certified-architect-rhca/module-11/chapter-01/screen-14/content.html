Verification & Troubleshooting

Verifying Bond Status and Common Issues

Confirm bond operation and diagnose problems using system files and best practices.

  • Use /proc/net/bonding/bond0 for detailed status.
  • Understand miimon parameter implications.
  • Coordinate switch configuration for LACP modes.
Checking Bond Status

The /proc/net/bonding/bond0 file provides critical information about your bond.

# View detailed bond information
cat /proc/net/bonding/bond0

# Expected output includes:
# Bonding Mode: active-backup
# MII Status: up
# Currently Active Slave: enp1s0
# Slave Interface: enp1s0
# Link Status: up
# Slave Interface: enp2s0
# Link Status: up
Common Bonding Pitfalls

`miimon` Misconfiguration

Incorrect interval for link monitoring can delay failover or cause excessive traffic.

LACP Switch Mismatch

For mode=4, switch ports must be configured for LACP; otherwise, the bond won't form.

Key Takeaway

Regularly verify bond status and be aware of common pitfalls like miimon and LACP switch mismatches to ensure robust network operations.
