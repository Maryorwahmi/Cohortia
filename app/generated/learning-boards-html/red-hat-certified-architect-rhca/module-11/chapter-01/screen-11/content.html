Advanced Bonding Modes

Mode 0 (balance-rr) & Mode 4 (802.3ad - LACP)

These modes offer load balancing and dynamic link aggregation for higher performance and resilience.

  • balance-rr: Round-robin packet distribution for load balancing.
  • 802.3ad (LACP): Dynamic aggregation for fault tolerance and bandwidth.
Comparison of Modes

Mode 0: balance-rr

  • Sequential packet transmission.
  • Load balancing & fault tolerance.
  • Requires switch support (EtherChannel/LAG).

Mode 4: 802.3ad (LACP)

  • Dynamic aggregation group.
  • Utilizes all active slaves for traffic.
  • Requires switch support (IEEE 802.3ad).
Key Consideration: Switch Support

Both balance-rr and 802.3ad modes require specific configurations on the network switch to function correctly. Always verify switch compatibility and configuration with your network team.

Key Takeaway

For load balancing and bandwidth aggregation, balance-rr and 802.3ad are powerful options, but necessitate careful switch configuration.
