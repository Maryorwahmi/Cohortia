Network Segmentation

VLAN Tagging

Allows a single physical interface to carry traffic for multiple Virtual Local Area Networks (VLANs).

  • Enhances security by isolating traffic types.
  • Simplifies network management and logical grouping.
  • Reduces physical cabling complexity.
How VLANs Work

Each Ethernet frame is tagged with a VLAN ID (IEEE 802.1Q) to identify which virtual network it belongs to. The physical switch then directs traffic based on these tags.

VLAN ID: A numerical identifier (1-4094) for each virtual network.

Sub-interface: A logical interface created on a physical NIC for a specific VLAN.

Real-world Use Case

In data centers, VLANs are used to separate tenant networks, management networks, and storage networks, all sharing the same physical cabling infrastructure for efficiency and security.

Key Takeaway

VLAN tagging is essential for creating segmented, secure, and manageable networks over shared physical infrastructure.
