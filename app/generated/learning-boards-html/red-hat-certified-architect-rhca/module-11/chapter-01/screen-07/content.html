Configuring VLAN Interfaces with `nmcli`

Create a VLAN sub-interface using nmcli, associating it with a physical NIC and a VLAN ID.

  • Defines a logical interface for a specific VLAN.
  • Ensures traffic is correctly tagged (802.1Q).
  • Provides persistent configuration through NetworkManager.
`nmcli` Commands for VLAN Interface

Example: Create VLAN 10 on enp1s0 with IP 10.0.10.1/24.

# Add a new VLAN connection
sudo nmcli connection add type vlan con-name enp1s0.10 dev enp1s0 id 10 ipv4.method manual ipv4.addresses 10.0.10.1/24

# Bring up the VLAN connection
sudo nmcli connection up enp1s0.10

# Verify the new interface
ip addr show enp1s0.10
Understanding the Command

The type vlan specifies a VLAN interface. dev enp1s0 links it to the physical device. id 10 sets the VLAN tag. The con-name is a descriptive name for the connection profile.

Key Takeaway

VLAN sub-interfaces are created using nmcli connection add type vlan, providing a persistent and managed way to segment network traffic.
