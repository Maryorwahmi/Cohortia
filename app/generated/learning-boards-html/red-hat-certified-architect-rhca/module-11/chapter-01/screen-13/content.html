Configuring a Network Bond with `nmcli`

Create a bond interface and add physical NICs as slave connections for high availability.

  • Define the bond interface with its mode and IP.
  • Add physical interfaces as slaves to the bond.
  • Ensure persistent configuration via NetworkManager.
`nmcli` Commands for Active-Backup Bond

Example: Create bond0 in active-backup mode using enp1s0 and enp2s0.

# 1. Create the bond interface
sudo nmcli connection add type bond con-name bond0 ifname bond0 mode active-backup ipv4.method manual ipv4.addresses 192.168.1.200/24 ipv4.gateway 192.168.1.1

# 2. Add slave interfaces to the bond
sudo nmcli connection add type ethernet con-name bond0-slave1 ifname enp1s0 master bond0
sudo nmcli connection add type ethernet con-name bond0-slave2 ifname enp2s0 master bond0

# 3. Bring up the bond connection (activates slaves too)
sudo nmcli connection up bond0
Understanding the Master/Slave Relationship

The bond interface acts as the 'master', and the physical NICs are its 'slaves'. This hierarchical structure allows NetworkManager to manage them as a single logical unit.

Key Takeaway

Configuring a bond with nmcli involves creating the bond master and then attaching physical interfaces as its slaves, ensuring persistent and managed redundancy.
