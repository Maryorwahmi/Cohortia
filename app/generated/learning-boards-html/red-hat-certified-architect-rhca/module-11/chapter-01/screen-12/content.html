Load Balancing Without Switch Support

Modes 5 & 6: Transmit and Adaptive Load Balancing

These modes offer load balancing and fault tolerance without requiring special network switch configurations.

  • balance-tlb: Transmit load balancing based on slave load.
  • balance-alb: Adds receive load balancing for IPv4 traffic.
How TLB and ALB Work

Mode 5: balance-tlb

  • Outgoing traffic distributed by current load.
  • Incoming traffic received by active slave.
  • Fault tolerance & transmit load balancing.

Mode 6: balance-alb

  • Includes balance-tlb features.
  • Adds receive load balancing for IPv4.
  • Achieved via ARP negotiation.
Key Advantage: Switch Independence

These modes are highly valuable in environments where you cannot configure the network switch for link aggregation, providing server-side load balancing capabilities.

Key Takeaway

When switch-side configuration is not an option, balance-tlb and balance-alb offer robust server-side load balancing and fault tolerance.
