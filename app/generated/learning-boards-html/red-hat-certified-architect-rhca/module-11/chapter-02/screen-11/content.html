ISC DHCP Server: Client Class-Based Assignments

Granular Control Over Network Access and Configuration

# Example client class for specific MAC addresses
class "printers" {
    match hardware;
}

subclass "printers" 00:11:22:33:44:55; # MAC address of a specific printer

subnet 192.168.1.0 netmask 255.255.255.0 {
    pool {
        range 192.168.1.201 192.168.1.210;
        allow members of "printers";
    }
    # Other pool for general clients
    pool {
        range 192.168.1.100 192.168.1.200;
        deny members of "printers";
    }
}
How Client Classes Work
  • Define a class with criteria (e.g., match hardware for MAC address).
  • Define subclass entries for specific client identifiers.
  • Use allow members of or deny members of within pool directives to apply different rules.
Use Cases

Assign specific IP ranges to printers, provide different DNS servers to development machines, or enforce network access policies based on device type.

Key Takeaway

Client class-based assignments offer powerful, flexible control over DHCP configurations, enabling tailored network access and resource allocation.
