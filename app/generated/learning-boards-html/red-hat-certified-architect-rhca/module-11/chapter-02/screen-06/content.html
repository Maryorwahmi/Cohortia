Configuring BIND Slave for Zone Transfers

Setting Up Slaves to Receive Zone Updates

zone "example.com" IN {
    type slave;
    file "slaves/example.com.zone";
    masters { 192.168.1.10; };
};
Key Directives
  • type slave;: Designates this server as a slave for the zone.
  • file "slaves/example.com.zone";: Specifies where the transferred zone data will be stored.
  • masters { IP_ADDRESS; };: Lists the IP addresses of the master servers to pull updates from.
Troubleshooting Tip

Ensure the masters IP is correct and that the slave has write permissions to the specified file path. Check firewall rules for TCP port 53.

Key Takeaway

Correctly configuring the slave's zone type and master IPs is vital for successful zone transfers and maintaining DNS redundancy.
