sshd_config example
A minimal, secure snippet to enforce keys and deny root.
# /etc/ssh/sshd_config
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
Port 2222
AllowUsers youruser
Restart sshd after editing and update firewall rules: remove default SSH service then add the new port and reload the firewall. Always test from a separate client session.
Supporting steps
  • Backup config: sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak
  • Edit and restart: sudo systemctl restart sshd
  • Firewall update: sudo firewall-cmd --permanent --add-port=2222/tcp; --remove-service=ssh; sudo firewall-cmd --reload
Common mistake
Disabling password auth without verified key access causes lockouts. Always keep a recovery method.
Key Takeaway

Plan and test SSH changes to improve security without sacrificing access.
