fail2ban loop
Filter logs → count failures → apply ban via firewall.
Configuration essentials
  • bantime, findtime, maxretry in [DEFAULT]
  • Enable sshd jail and set port to match your SSH port
  • Set banaction appropriate for your firewall (firewallcmd-ipset on RHEL)
Common pitfalls
Incorrect logpath or mismatched regex; banaction cannot apply rules; overly long bans impacting admins.
Verify and test
# Verify status
sudo fail2ban-client status sshd
# Test regex
sudo fail2ban-regex /var/log/secure /etc/fail2ban/filter.d/sshd.conf
Safety note
Avoid aggressive maxretry and bantime values before validating from a separate admin IP to prevent accidental lockouts.
Key Takeaway

Confirm log paths and firewall integration to ensure fail2ban can detect and block offenders.
