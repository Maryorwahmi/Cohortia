Module 12 › Chapter 11.10 › Quick Reference
SSH Checklist
Backup sshd_config, install keys, test login, then disable password auth and restart.
fail2ban Checklist
Set bantime/findtime/maxretry, verify logpath, test filters with fail2ban-regex, and confirm bans with fail2ban-client.
Monitoring Checklist
Forward logs to SIEM, review journalctl and audit logs, and prepare an incident response checklist.
Final Takeaway
Make changes incremental, testable, and observable so security improves without sacrificing availability.
