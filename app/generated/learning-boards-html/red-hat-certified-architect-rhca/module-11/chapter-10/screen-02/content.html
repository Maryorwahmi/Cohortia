Learning Objectives
Skills to validate in the hands-on activity
01
Network hardening
Minimize services and apply least privilege to reduce attack surface. Practice disabling unnecessary daemons and confirming required units remain enabled.
Venn: attack surface ∩ services
VERIFIED COMPETENCY MILESTONE
02
fail2ban configuration
Install and tune jail.local, set bantime and maxretry, and verify bans with fail2ban-client. Understand log paths and banaction choices.
Mnemonic: logs → filter → ban
VERIFIED COMPETENCY MILESTONE
03
SSH hardening
Enforce key-based auth, disable PermitRootLogin, and plan port changes safely. Always verify admin access before disabling passwords.
Timeline: plan → change → verify
VERIFIED COMPETENCY MILESTONE
04
Firewall & segmentation
Implement a default-deny nftables policy and restrict management ports to trusted ranges. Use segmentation to limit lateral movement in case of compromise.
Mnemonic: deny by default
VERIFIED COMPETENCY MILESTONE
