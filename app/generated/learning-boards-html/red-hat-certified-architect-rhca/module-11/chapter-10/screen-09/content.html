Module 12 › Chapter 11.10 › fail2ban Demo
Starter commands
# Install and enable
sudo dnf install fail2ban -y
sudo systemctl enable --now fail2ban

# /etc/fail2ban/jail.local
[DEFAULT]
bantime = 1h
findtime = 10m
maxretry = 3
banaction = firewallcmd-ipset

[sshd]
enabled = true
port = 2222
After editing, restart fail2ban and verify the sshd jail status with fail2ban-client status sshd. Watch journalctl -u fail2ban for errors.
Verification steps
  • Simulate failed SSH logins from another system.
  • Run sudo fail2ban-client status sshd to see banned IPs.
  • Use sudo fail2ban-regex /var/log/secure /etc/fail2ban/filter.d/sshd.conf to test filters.
Troubleshooting
If no bans appear, check logpath values and that firewalld is running for your banaction.
