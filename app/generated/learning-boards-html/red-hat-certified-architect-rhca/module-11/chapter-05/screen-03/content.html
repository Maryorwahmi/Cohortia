Objective evidence template
  1. Command used and full invocation.
  2. Selected output lines that justify your claim.
  3. One-sentence interpretation and next action.
Example
ss -tulpn | grep :80
If the output shows httpd listening on :80, interpret as the service binding correctly; next check firewall and application health. If no output, the service is not listening.
Capture guideline
Use precise tcpdump filters to limit file size, for example: sudo tcpdump -i eth0 host 192.168.1.10 and port 3306 -w db.pcap
Safety and scale
Avoid full interface captures during peak traffic; prefer targeted filters and timeboxed tests like iperf3 runs.
