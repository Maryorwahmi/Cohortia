Core Concept tcpdump — capture with filters
Example commands
# Capture DB traffic between serverA and serverB
sudo tcpdump -i eth0 host 192.168.1.10 and port 3306 -nnvvS -w db.pcap

# Capture HTTP traffic on port 80
sudo tcpdump -i eth0 port 80 -w http.pcap
Include -nn to avoid name lookups and -w to write binary PCAP files for later analysis.
What to look for in captures
  • SYN, SYN-ACK, ACK sequence for TCP connection establishment.
  • Retransmissions or duplicate ACKs indicating packet loss.
  • Long gaps between request and response implying application delays.
Security note
PCAPs can include sensitive data. Limit captures and store files securely; redact or truncate before sharing.
Key Takeaway

Use tcpdump for definitive, packet-level evidence but capture narrowly and responsibly to protect privacy and avoid heavy I/O.
