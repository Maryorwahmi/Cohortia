Definition ip — interface and routing inspection
Essential commands
ip addr show
ip route show
ip -s link show
ip neigh show
Use these to validate configuration and check for interface-level errors or misconfigurations.
What to inspect
  • Correct IP and netmask on the expected interface.
  • Default route points to the expected gateway.
  • Interface RX/TX error counters are zero or within normal ranges.
Contrast
Routing issues and ARP mismatches often look like unreachable hosts. Confirm local configuration before pursuing remote path diagnostics.
Key Takeaway

ip reveals the host’s view of the network; fix local address, route, or link errors first to avoid chasing remote problems.
