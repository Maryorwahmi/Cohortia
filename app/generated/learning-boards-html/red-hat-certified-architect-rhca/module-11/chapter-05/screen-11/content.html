Process Flow Systematic troubleshooting
1. Isolate scope
Determine who is affected and which services are impacted to narrow your testing targets.
2. Basic connectivity
Use ping and ip addr/route to confirm reachability and correct host configuration.
3. Service & firewall
Verify listening sockets with ss and check firewall rules on both ends before deeper analysis.
4. Path analysis
Use mtr to detect hop-level loss; follow up with targeted tcpdump captures if needed.
5. Throughput test
Use iperf3 to measure raw bandwidth and distinguish network capacity issues from host limits.
6. Host metrics & logs
Correlate sar/nmon and journalctl output to rule out resource or application errors.
Key Takeaway

Use a repeatable order of checks that moves from cheap probes to heavier evidence gathering; this minimizes impact and speeds diagnosis.
