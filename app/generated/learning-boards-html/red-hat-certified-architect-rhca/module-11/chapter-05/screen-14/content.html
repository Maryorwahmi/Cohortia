Summary Key Concepts
Latency
Round-trip delay between endpoints; measured with ping and reflected in mtr timing columns.
Bandwidth
Maximum data transfer rate; measured quantitatively with iperf3 tests between two hosts.
Packet loss
Packets that don’t reach their destination; visible as loss% in mtr and retransmissions in tcpdump.
Keep this trio—latency, bandwidth, packet loss—in mind as you decide which tools to run and which evidence to collect when diagnosing performance issues.
