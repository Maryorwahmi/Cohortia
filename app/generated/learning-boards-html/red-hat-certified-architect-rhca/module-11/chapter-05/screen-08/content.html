Process Flow iperf3 throughput tests
Server and client
# On server B (192.168.1.20)
iperf3 -s

# On server A (192.168.1.10)
iperf3 -c 192.168.1.20 -t 30 -P 5
Adjust -t for duration and -P for parallel streams to stress different parts of the stack.
Interpreting results
  • Compare the summed Mbits/sec to NIC speed expectations.
  • Use UDP mode to inspect jitter and packet loss metrics.
  • Repeat tests at different times to check for congestion-driven variation.
Misconception
Low iperf3 numbers do not automatically mean network hardware; rule out CPU, disk, and software limits before blaming the network.
Key Takeaway

Use iperf3 as a quantitative test for bandwidth and jitter; interpret results in the context of host resources and test configuration.
