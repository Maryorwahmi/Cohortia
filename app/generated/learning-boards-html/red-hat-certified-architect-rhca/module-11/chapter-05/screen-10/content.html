Definition sar and nmon — system-level context
Quick commands
# sar example: report network statistics
sar -n DEV 1 3

# nmon (interactive)
nmon
Use sar with sampling intervals to capture historical trends; install sysstat if missing.
Diagnosis pointers
  • Correlate network errors with CPU or disk peaks.
  • Look for rising queue sizes or interface drops that indicate overload.
  • Use these metrics to justify whether the issue is host-side or network-side.
False lead
Do not assume normal CPU usage rules out resource issues; transient spikes during test windows can still throttle throughput.
Key Takeaway

Always check host metrics to avoid misattributing performance issues to the network when the host is the bottleneck.
