Module 11 › Chapter 11.7 › VPN Definitions
Definition

A VPN encrypts traffic between endpoints so that communications over an untrusted network remain confidential and integrity-protected. Implementations differ by layer and negotiation method.

OpenVPN
SSL/TLS, client-to-site, UDP/TCP transport
IPsec
Network-layer, site-to-site, IKE and ESP
Concrete example
A consultant connects from a coffee shop using an OpenVPN client with a client certificate and reaches internal tools. Two branch offices connect via IPsec; each gateway advertises its internal subnet so hosts on each side can reach each other without per-host VPN clients.
Common misconception
IPsec is not inherently simpler; its configuration can be more rigid and requires matching proposals and often firewall rules for IKE and ESP. OpenVPN may traverse restrictive networks more easily by using TCP port 443.
Key Takeaway

Pick the VPN type to match the use case: flexible, client-based access or standardized, network-level tunnels.
