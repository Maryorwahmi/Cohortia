Module 11 › Chapter 11.7 › Objectives — Verification
Verification checklist
  • IP forwarding: Confirm persistent kernel setting so packets route between networks.
  • Firewall: Open OpenVPN UDP port and IPsec services, allow ESP and NAT-T when required.
  • Certificates / PSK: Ensure CA-signed server and client certs or matching pre-shared keys for IPsec.
  • Crypto policies: Match IKE/ESP proposals to avoid negotiation failures.
  • Logs and status: Use journald and strongSwan status to observe handshake and SA state.
Quick mnemonic
F P C L S — Forwarding, Ports, Certificates, Left/Right (IPsec), Status
