Module 11 › Chapter 11.7 › Client Certificates
Client cert lifecycle
  • Generate client request with Easy-RSA.
  • Sign request using the CA.
  • Assemble CA, client cert, and private key into a .ovpn file or distribution package.
  • Revoke compromised certs and update CRLs if necessary.
Troubleshooting checklist
If clients fail to connect or authenticate, check certificate expiry, verify CA trust, confirm correct file paths on the server, and inspect the OpenVPN logs for TLS handshake errors. If routes are missing, confirm server push directives and client route acceptance settings.
