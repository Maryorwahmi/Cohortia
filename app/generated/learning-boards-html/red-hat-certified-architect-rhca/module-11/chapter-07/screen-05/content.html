Module 11 › Chapter 11.7 › OpenVPN PKI
Steps (summary)
  1. Install openvpn and easy-rsa packages.
  2. Copy Easy-RSA to a working dir and init PKI.
  3. Build the CA and generate Diffie-Hellman parameters.
  4. Generate server and client certificate requests and sign them with the CA.
Common mistake
Using inconsistent certificate paths between your server.conf and the actual PKI output. Always confirm the ca, cert, key, and dh file locations.
Starter commands
sudo dnf install openvpn easy-rsa

cp -r /usr/share/easy-rsa/ /etc/openvpn/easy-rsa
cd /etc/openvpn/easy-rsa/3
./easyrsa init-pki
./easyrsa build-ca nopass
./easyrsa gen-dh
After these commands you will have a CA certificate, private key, and Diffie-Hellman file to use in your OpenVPN server configuration. Protect the CA private key carefully.
