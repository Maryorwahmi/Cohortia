Learning Objectives
Learn, Understand, Apply, Master
01
OpenVPN deployment
Install OpenVPN and Easy-RSA, build a CA, and issue server and client certificates. You will practice creating a server.conf that secures client traffic.
VERIFIED COMPETENCY MILESTONE
02
PKI and certificate management
Use Easy-RSA to initialize PKI, build a CA, create Diffie-Hellman parameters, and manage client certificates. These tasks protect private keys and verify identity.
VERIFIED COMPETENCY MILESTONE
03
IPsec site-to-site
Configure strongSwan with ipsec.conf and ipsec.secrets to connect two networks, match IKE and ESP proposals, and enable auto-start tunnels.
VERIFIED COMPETENCY MILESTONE
04
Troubleshooting and verification
Use system logs and vendor tools to check connection state, verify forwarding, and validate routing between internal hosts. Learn common fixes for certificate, firewall, and policy mismatches.
VERIFIED COMPETENCY MILESTONE
