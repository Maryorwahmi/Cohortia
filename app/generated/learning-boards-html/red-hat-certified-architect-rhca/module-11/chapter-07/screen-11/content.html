Starter script (SiteA-Gateway)
# Install
sudo dnf install strongswan -y

# Enable IP forwarding
sudo sysctl -w net.ipv4.ip_forward=1
sudo echo "net.ipv4.ip_forward = 1" | sudo tee /etc/sysctl.d/99-ip-forward.conf

# Configure ipsec.conf and ipsec.secrets as shown in the chapter
Verification commands
# On gateways
sudo ipsec status
journalctl -u strongswan -f

# From internal host on 10.0.1.0/24
ping 10.0.2.10
If the ping fails, first check ipsec status for a negotiated SA, then review strongSwan logs for policy mismatches, and verify the PSK matches on both sides. Confirm internal hosts use their gateway as default route.
