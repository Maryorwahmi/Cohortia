Example ipsec.conf (Site A)
config setup
    charondebug="ike 2, knl 2, cfg 2"
    uniqueids=no

conn siteA-to-siteB
    left=192.168.1.10
    leftsubnet=10.0.1.0/24
    right=192.168.2.20
    rightsubnet=10.0.2.0/24
    ike=aes256-sha2_256-modp1024!
    esp=aes256-sha2_256!
    keyexchange=ikev2
    authby=secret
    auto=start
Example ipsec.secrets
192.168.1.10 192.168.2.20 : PSK "YourStrongPresharedKey"
Mirror the connection block on Site B, swapping left and right values, and ensure the PSK matches exactly on both sides. Restart strongSwan after changes and use the status command for verification.
