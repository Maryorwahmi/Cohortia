Module 11 › Chapter 11.4 › Why nftables
Comparison
Unified framework
Handles IPv4, IPv6, ARP and bridging from the same tool; use inet tables to cover both IP families.
Atomic ruleset updates
Load a complete ruleset in one operation to avoid transient inconsistent states during updates.
Sets and maps
Group addresses or map inputs to outputs for concise, efficient kernel matching.
Example
Instead of adding many separate allow rules for management hosts, define a set of admin IPs and write a single accept rule that references it. This reduces complexity and eases updates.
Common misconception
People sometimes assume nftables is purely syntactic sugar over iptables. In truth it changes kernel matching primitives and provides objects like sets and maps that reduce rule duplication and improve performance. Treat it as a more capable, modern framework rather than a drop-in re-skin.
Key takeaway
Key Takeaway

Prefer nftables for modern deployments for unified handling of address families, atomic loading, and efficient large-list matching.
