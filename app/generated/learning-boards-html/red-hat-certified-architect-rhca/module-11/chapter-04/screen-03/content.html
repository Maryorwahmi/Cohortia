05
Map SELinux port contexts
Use semanage to label non-standard ports for services so SELinux permits binding. This ensures services can actually listen when firewall rules allow traffic.
Mnemonic: label then listen

06
Enable relevant SELinux booleans
Turn on persistent booleans like allowing httpd to make network connections when the application requires database access or proxying.
Venn: need vs allow
VERIFIED COMPETENCY MILESTONE
07
Diagnose denials safely
Use audit logs and sealert to find SELinux denials and apply targeted fixes rather than disabling SELinux, preserving mandatory protections.
Timeline: detect → interpret → fix
VERIFIED COMPETENCY MILESTONE
08
Validate and verify changes
After updating nftables or SELinux settings, confirm the active state with nft list ruleset and getsebool or audit searches to ensure intended behavior.
