Module 11 › Chapter 11.4 › Key Concepts
nftables
The modern unified packet filtering framework replacing the iptables family.
Table
Container for chains, typed by address family such as ip, ip6, or inet for dual-stack rules.
Chain & Hook
A chain is an ordered rule list attached to a hook like input or postrouting which determines when it runs.
Summary

Design rulesets by selecting the correct table type and hook, then use explicit accepts with a restrictive policy to reduce accidental exposure.
