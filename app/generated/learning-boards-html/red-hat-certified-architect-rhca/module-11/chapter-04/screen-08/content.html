Module 11 › Chapter 11.4 › NAT & Port Forwarding
Masquerade example
table ip nat {
    chain postrouting {
        type nat hook postrouting priority 100; policy accept;
        oifname "eth0" ip saddr 192.168.0.0/24 masquerade
    }
}
Enable IP forwarding to allow NATed packets to traverse: set net.ipv4.ip_forward to one and persist it. Confirm the firewall accepts forwarded connections in the forward chain.
Port forward (DNAT)
table ip nat {
    chain prerouting {
        type nat hook prerouting priority -100; policy accept;
        iifname "eth0" tcp dport 80 dnat to 192.168.0.10:80
    }
}
Test DNAT from an external client and check that forwarding allows the translated packet to reach the internal server. Use nft monitor for live packet events if you need to debug.
