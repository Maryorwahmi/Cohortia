Set example
# Define a set of admin IPs
set admin_ips {
    type ipv4_addr;
    flags interval;
    elements = { 192.168.1.10, 192.168.1.20-192.168.1.30 }
}

# Use the set in a rule
chain input {
    ip saddr @admin_ips tcp dport 22 accept
}
Maps and use cases
- Maps translate input to output values and are useful for dynamic NAT or routing decisions.
- Use maps when you need to change a packet field based on source or another key without many conditional rules.
- Verify types: selecting ipv4_addr or inet_service matters for accurate matches and to avoid load-time errors.
Pro tip
When you update a large set, prefer preparing a new set definition and atomically reloading the ruleset so kernel membership changes take effect without transient mismatches.
