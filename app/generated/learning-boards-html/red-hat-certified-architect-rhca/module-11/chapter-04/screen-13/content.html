Module 11 › Chapter 11.4 › SELinux Troubleshooting
Troubleshooting flow
  1. Reproduce the failure so logs contain the denial.
  2. Search AVC denials with ausearch -m AVC -ts today or run sealert -a for guidance.
  3. Apply targeted fixes such as semanage port additions or persistent setsebool toggles.
  4. Retest and document changes; do not disable SELinux as a shortcut.
Concrete commands
- Check for denials: sudo ausearch -m AVC -ts today
- Human readable analysis: sudo sealert -a /var/log/audit/audit.log
- Add port mapping: sudo semanage port -a -t http_port_t -p tcp 8080
- Enable boolean persistently: sudo setsebool -P httpd_can_network_connect_db on
Common pitfall
Do not suppress audit logs or disable SELinux to make problems disappear; use the logs as your guide to the minimal corrective change.
