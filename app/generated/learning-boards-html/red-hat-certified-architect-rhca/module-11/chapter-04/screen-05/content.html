Architecture
Table
Container typed by address family. Use inet for dual-stack handling.
Chain
Ordered rules attached to a hook with a policy. Example chains: input, forward, output.
Hook
Predefined processing points in the network stack where chains run, such as prerouting or postrouting for NAT.
Practical guidance
  • Use input hook for packets destined to local services and set a restrictive default policy there.
  • Use prerouting for DNAT before routing decisions; use postrouting for masquerade after routing.
  • Choose inet tables when you need identical rules for IPv4 and IPv6 to avoid duplication.
  • Set policy explicitly to avoid accidental openness from implicit defaults.
Example rule placement
Put accept rules for established connections in input chain and DNAT actions in the nat prerouting chain to ensure correct packet transformation order.
