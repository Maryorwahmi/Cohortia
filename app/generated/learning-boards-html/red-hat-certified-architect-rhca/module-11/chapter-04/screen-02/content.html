01
Understand nftables architecture
Recognize tables, chains and hooks and why a unified framework replaces separate IPv4/IPv6 utilities. This reduces complexity when managing dual-stack servers.
Venn: stack compatibility

02
Author rulesets and persist them
Write tables and chains, set policy defaults, load with nft, and persist changes so rules survive reboots in a controlled way.
Timeline: create → test → persist
VERIFIED COMPETENCY MILESTONE
03
Use sets and maps for efficiency
Group addresses or ports into sets and use maps to translate values. This simplifies large or dynamic lists and improves kernel matching performance.
Mnemonic: bucket list
VERIFIED COMPETENCY MILESTONE
04
Implement NAT and forwarding
Configure masquerade for outbound traffic and DNAT for port forwarding so internal services are reachable through an external interface.
Mnemonic: inside-out
