Module 11 › Chapter 11.4 › Inspect & Monitor
Useful commands
- nft list ruleset — show active kernel ruleset.
- nft monitor — observe packet matching and verdicts in real time.
- journalctl -u nftables.service — review load-time errors and service logs.
Check example
If a rule appears present but packets are still dropped, monitor traffic while you attempt a connection to see whether the packet matches a different chain, or whether connection tracking classifies it as invalid.
Live debugging
  1. Confirm ruleset with nft list ruleset.
  2. Start nft monitor and recreate the traffic from a test client.
  3. Interpret monitor output to find matching rule or drop reason.
  4. Check journalctl if a ruleset failed to load or a service reports errors.
