Starter rules and commands
# Define management subnet
define management_subnet = { 192.168.10.0/24 }

table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;
        iif "lo" accept
        ct state { established, related } accept
        ip saddr $management_subnet tcp dport 22 accept
        tcp dport { 80, 443 } accept
    }
}

table ip nat {
    chain prerouting {
        type nat hook prerouting priority -100; policy accept;
        iifname "eth0" tcp dport 80 dnat to 192.168.50.100:80
    }

    chain postrouting {
        type nat hook postrouting priority 100; policy accept;
        oifname "eth0" ip saddr 192.168.50.0/24 masquerade
    }
}
Verification and SELinux steps
- Load the file with nft -f and check nft list ruleset for the expected tables and chains.
- Enable IP forwarding: set net.ipv4.ip_forward to one and persist it in /etc/sysctl.d.
- If using standard ports no semanage change is needed. To add a non-standard port, use semanage port -a -t http_port_t -p tcp 8080.
- Turn on httpd network database access with setsebool -P httpd_can_network_connect_db on when required.
Final check
Key Takeaway

Test and verify traffic paths, SELinux contexts, and persistence before declaring the deployment complete.
