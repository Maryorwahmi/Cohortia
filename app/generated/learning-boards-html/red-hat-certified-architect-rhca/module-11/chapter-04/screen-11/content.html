Module 11 › Chapter 11.4 › SELinux Networking
Port contexts
- Use semanage port to add a non-standard port to a service context so the process can bind.
- Example command to label a port for httpd is provided in the chapter as a demonstration command.
Booleans
Enable booleans like httpd_can_network_connect_db with setsebool -P to allow httpd to contact remote databases persistently.
Troubleshooting SELinux
  • Search AVC denials with ausearch -m AVC or use sealert -a to get suggestions.
  • Avoid disabling SELinux; prefer targeted semanage port additions or enabling booleans.
  • Back up policy modules before making custom changes to preserve recoverability.
