Module 11 › Chapter 11.4 › Load & Persist
Deployment checklist
  1. Create and save a complete ruleset file and include flush ruleset at top so previous state is cleared.
  2. Load the file with nft -f and confirm no syntax errors.
  3. Verify active rules with nft list ruleset and test connectivity from a safe client.
  4. Persist by copying to /etc/sysconfig/nftables.conf or configuring nftables.service to load your file, then enable the service.
Troubleshooting tips
  • Use journalctl -u nftables.service to find load-time errors when the service starts.
  • Use nft monitor to see how packets match rules in real time while you test.
  • Avoid in-place edits without reload; always reload the tested file so the kernel matches your intended configuration.
  • Keep a rescue console or scheduled rollback to prevent lockout during remote changes.
