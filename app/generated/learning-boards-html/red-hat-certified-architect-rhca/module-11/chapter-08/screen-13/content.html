Module 11 › Chapter 11.8 › Samba Troubleshooting
Step checks
  1. testparm to validate smb.conf
  2. smbstatus to view active sessions and locks
  3. Confirm smbpasswd contains the user and group membership matches filesystem ACLs
  4. Check /var/log/samba for authentication errors
Common permission issues
  • Filesystem ownership conflicts with Samba valid users
  • Group membership not applied to existing files
  • SELinux context not set to samba_share_t
Verification

Mount the share from a client and attempt read/write operations while watching smbstatus and logs to correlate access and denials.
