Module 11 › Chapter 11.8 › NFS Server Setup
Checklist
  1. Install utilities: sudo dnf install nfs-utils krb5-workstation -y
  2. Create directories and set ownership/permissions
  3. Edit /etc/exports and mark fsid=0
  4. Run sudo exportfs -rv to refresh exports
  5. Enable and start services: sudo systemctl enable --now nfs-server rpcbind
  6. Open firewall: firewall-cmd --permanent --add-service=nfs; firewall-cmd --reload
Pro tip

Keep the pseudo-root and data directories separated so permissions can be stricter on data while root remains stable for mounts.

Commands (starter)
sudo dnf install nfs-utils krb5-workstation -y
sudo mkdir -p /srv/nfsshare/data
sudo chmod 0755 /srv/nfsshare
sudo chmod 0770 /srv/nfsshare/data
sudo exportfs -rv
sudo systemctl enable --now nfs-server rpcbind
sudo firewall-cmd --permanent --add-service=nfs
sudo firewall-cmd --reload
Common mistake

Starting only nfs-server without rpcbind or rpc-gssd (for Kerberos) will produce incomplete service registration and failing mounts.
