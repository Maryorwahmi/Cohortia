Module 11 › Chapter 11.8 › Samba / CIFS Basics
Definition

Samba exposes SMB/CIFS to Windows clients

Configure shares in /etc/samba/smb.conf, create Samba users with smbpasswd, and ensure filesystem and SELinux permissions allow the desired access.

smb.conf snippet
[myshare]
    comment = My Samba Share
    path = /srv/samba/myshare
    browseable = yes
    writable = yes
    valid users = @smbgroup
    create mask = 0664
    directory mask = 0775
Concrete Steps
  1. Install samba and samba-client packages.
  2. Create share directory, set ownership and group to match valid users.
  3. Create Samba user with smbpasswd -a and add to group.
  4. Enable and start smb and nmb services and open samba in the firewall.
Misconception

Assuming Windows access will work after editing smb.conf. You must also create samba users, configure SELinux contexts, and confirm filesystem permissions.
