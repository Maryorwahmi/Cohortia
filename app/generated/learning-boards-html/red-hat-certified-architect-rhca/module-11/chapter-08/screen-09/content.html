Quick Checks
  • showmount -e server to confirm exports
  • klist -kt /etc/krb5.keytab to verify keytab principals
  • Confirm time sync with chronyc tracking
  • Inspect firewall-cmd --list-services and rpcinfo -p
  • Check server logs: journalctl -u nfs-server
Common Errors
Clock skew: Kerberos rejects tickets if clocks differ. Fix by enabling chronyd/ntpd.
Keytab missing/corrupt: Use klist -kt to inspect and regenerate via KDC if needed.
fsid issue: Ensure fsid=0 is on the pseudo-root and other exports are subdirectories.
