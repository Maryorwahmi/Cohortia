Network File Systems (NFSv4) & Samba

Practical lab-focused walkthrough for secure NFS exports with Kerberos and Samba CIFS shares with SELinux-safe configuration.

Lab Walkthrough
Duration: ~15 min demo
NFSv4 Essentials

Single port 2049, pseudo-filesystem with fsid=0, Kerberos support for auth and privacy.

Samba / CIFS

SMB/CIFS shares for Windows clients. Uses smb.conf, smbpasswd, and requires SELinux labeling.

Why this matters

Centralized file access reduces duplication, simplifies backups, and enforces access control across mixed OS fleets.

Common Pitfall
