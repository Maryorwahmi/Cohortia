Learning Objectives
Bloom: Learn → Understand → Apply → Master
01
Configure secure NFSv4 exports

Learn to set fsid=0, restrict exports to subnets, and apply sec=krb5p. This prevents anonymous or unauthenticated mounts in production.

VERIFIED COMPETENCY MILESTONE
02
Integrate Kerberos for authentication

Set up service principals and keytabs. Kerberos ensures strong authentication and, with krb5p, encryption of data in transit.

VERIFIED COMPETENCY MILESTONE
03
Mount and manage NFS clients

Use nfs4 mounts with _netdev, manage persistent fstab entries, or use autofs for on-demand mounts to conserve resources.

VERIFIED COMPETENCY MILESTONE
04
Configure Samba for Windows clients

Create smb.conf shares, manage smbpasswd accounts, and apply samba_share_t contexts so Windows clients can access files securely.

VERIFIED COMPETENCY MILESTONE
