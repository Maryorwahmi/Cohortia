Module 11 › Chapter 11.8 › SELinux & Samba
Problem

Windows clients receive Access Denied while Samba and filesystem permissions appear correct. This often indicates SELinux blocking access.

Diagnosis
  • Check audit logs: sudo ausearch -m AVC -ts today | grep samba
  • Run sealert -a /var/log/audit/audit.log for analysis
Fix (relabelling)
sudo semanage fcontext -a -t samba_share_t "/srv/sambashare(/.*)?"
sudo restorecon -Rv /srv/sambashare
Booleans & notes
samba_enable_home_dirs: allow sharing home directories if required.
samba_export_all_rw: use with caution if broad write access is needed.
Misconception

Disabling SELinux fixes symptoms but removes valuable security controls. Relabel and set booleans instead.
