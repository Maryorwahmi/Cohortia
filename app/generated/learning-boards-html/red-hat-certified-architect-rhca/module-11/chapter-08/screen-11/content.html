Module 11 › Chapter 11.8 › Samba Setup
Steps
  1. sudo dnf install samba samba-client -y
  2. sudo mkdir -p /srv/sambashare; sudo chmod 0770; sudo chown root:samba_users
  3. Create system user and add to group; sudo smbpasswd -a smbuser
  4. sudo systemctl enable --now smb nmb; firewall-cmd --permanent --add-service=samba; firewall-cmd --reload
Validation
testparm
Run testparm to check smb.conf syntax and receive warnings before restarting services.
smbstatus
Use smbstatus to inspect active connections and locks for troubleshooting live sessions.
Pro tip

Back up /etc/samba/smb.conf before edits and use testparm to avoid syntax errors that block service reloads.
