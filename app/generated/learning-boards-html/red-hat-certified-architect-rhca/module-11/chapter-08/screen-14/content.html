Module 11 › Chapter 11.8 › NFS vs Samba
NFSv4 — Best when:
  • Linux-only clients needing POSIX semantics
  • Desire Kerberos-based authentication and encryption (krb5p)
  • Prefer kernel-mounted filesystems
Samba — Best when:
  • Windows clients require native SMB/CIFS support
  • Need Windows ACL compatibility or printer sharing
  • Willing to manage Samba users and SELinux contexts
Decision takeaway

Match protocol to client types and required features. It's common to run both in the same environment for different workloads.
