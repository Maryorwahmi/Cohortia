Module 11 › Chapter 11.8 › Key Concepts
NFSv4
Single port 2049, pseudo-filesystem with fsid=0, Kerberos support.
Samba / SMB
Expose SMB/CIFS to Windows clients; configure smb.conf and samba users.
SELinux
Label shares with samba_share_t and use setsebool for needed booleans rather than disabling SELinux.
Final takeaway

Layer checks: exports/shares, authentication artifacts (keytabs or smbpasswd), permissions, SELinux, and firewall in that order for efficient troubleshooting.
