Module 11 › Chapter 11.8 › /etc/exports & fsid=0
Process

Declare pseudo-root, then subexports

  1. Create /srv/nfsshare and set permissive root permissions for the root export.
  2. Add fsid=0 line to /etc/exports to mark the pseudo-root.
  3. Add subdirectory exports under that tree with subnet restrictions and sec=krb5p where needed.
  4. Run exportfs -rv and verify showmount -e.
Key Takeaway

fsid=0 centralizes the NFSv4 namespace; every other export must be a subdirectory of that root.

Example
# /etc/exports
/srv/nfsshare *(rw,sync,no_subtree_check,fsid=0)
/srv/nfsshare/data 192.168.10.0/24(rw,sync,no_subtree_check,sec=krb5p)
Common mistakes
  • Placing fsid=0 on a non-root export or omitting it entirely.
  • Using wildcards for exports that should be subnet-limited.
  • Neglecting to run exportfs after editing exports.
