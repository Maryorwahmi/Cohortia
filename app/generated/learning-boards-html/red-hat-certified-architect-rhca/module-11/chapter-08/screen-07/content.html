Architecture

KDC, NFS server, and clients

KDC
Hosts service principals and issues tickets used for authentication.
NFS Server
Requires nfs/server.example.com keytab at /etc/krb5.keytab and rpc-gssd running.
NFS Clients
Clients obtain tickets via kinit and mount with sec=krb5p for encrypted sessions.
Verify keytab
sudo klist -kt /etc/krb5.keytab
Common misconception

Assuming Kerberos works without time sync. Even small clock skew commonly causes authentication failures.

Quick Commands
# On KDC: create principal
kadmin.local -q "addprinc -randkey nfs/server.example.com@REALM.COM"
# on KDC: ktadd
kadmin.local -q "ktadd -k /tmp/nfs.keytab nfs/server.example.com@REALM.COM"
# copy to server and secure permissions
Key Takeaway

Kerberos requires principals, a secure keytab, rpc-gssd, and synchronized clocks to function reliably with NFSv4.
