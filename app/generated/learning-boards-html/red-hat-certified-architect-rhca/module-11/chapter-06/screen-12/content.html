Module 11 › Chapter 11.6 › PBR by UID
Exercise goal
Ensure all new connections created by a specific user account exit via eth1, regardless of the system default route.
Steps
  1. Find the UID of the application user.
  2. Add a routing table entry with a default via the intended gateway for eth1.
  3. Add an ip rule uidrange mapping the UID to the custom table.
  4. Verify with ip rule show and ip route get with uid simulation.
Remember: UID rules affect new connections. Existing sockets will not be moved retroactively, so test by restarting the application process.
Starter commands
# Get UID
APPUSER_UID=$(id -u appuser)

# Create table entry
echo "100 appuser_traffic" | sudo tee -a /etc/iproute2/rt_tables
sudo ip route add default via 192.168.B.1 dev eth1 table appuser_traffic

# Add UID-based rule
sudo ip rule add uidrange $APPUSER_UID-$APPUSER_UID table appuser_traffic

# Verify
sudo ip rule show
sudo ip route show table appuser_traffic
