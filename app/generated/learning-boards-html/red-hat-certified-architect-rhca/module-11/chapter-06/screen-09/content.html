Module 11 › Chapter 11.6 › OSPF vs BGP
OSPF (IGP)
Link-state protocol used within an autonomous system to compute shortest path routes from a shared topology. Good for converged, internal networks where topology is shared among peers.
BGP (EGP)
Path-vector protocol used between autonomous systems. Makes routing decisions based on path attributes and policy, suitable for inter-domain and internet routing.
When to recommend what
If you need dynamic, policy-rich inter-AS routing use BGP; for internal shortest-path convergence use OSPF. For simple host-level control or a gateway with limited peers, prefer static routes or PBR to avoid extra daemon complexity.
