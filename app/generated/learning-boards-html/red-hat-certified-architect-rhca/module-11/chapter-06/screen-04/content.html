Module 11 › Chapter 11.6 › Static Routing
Definition

Static route explained

A static route is a fixed kernel entry that sends traffic for a given prefix to a chosen next hop. It does not change unless you edit it, making troubleshooting straightforward when predictability is required.

Common use: VPN endpoints, isolated subnets, or backup links.
Misconception: Static means "set and forget"—you must still validate reachability when interfaces or gateways change.
Key Takeaway

Use static routes for predictable paths and persist them using NetworkManager or configuration files. Always verify with ip route get.

Code example
# Add a static route using ip command (temporary)
sudo ip route add 10.0.0.0/24 via 192.168.1.254 dev eth0

# Make it persistent using nmcli
sudo nmcli connection modify eth0 +ipv4.routes "10.0.0.0/24 192.168.1.254"
sudo nmcli connection up eth0
Example scenario
A server with a VPN peer that only reaches a management subnet via a separate gateway. A static route ensures the management subnet traffic never goes to the default gateway and avoids route flapping.
Check your work
  • Use ip route get to confirm the path.
  • Restart the connection and confirm persistent routes come back.
  • Watch for incorrect interface names or typos in gateway addresses.
