Learn & Understand
Practice a temporary static route and then persist it. Observe interface selection and common failure modes such as wrong gateway or interface mismatch.
Mnemonic: route → ip route get
Mnemonic: PBR → ip rule show
Apply & Master
Combine PBR with nftables NAT to route specific services out alternate gateways while translating addresses for internet access. Validate with nft list ruleset and tcpdump captures on both interfaces.
Mnemonic: NAT → nft list ruleset
Mnemonic: Verify → tcpdump
