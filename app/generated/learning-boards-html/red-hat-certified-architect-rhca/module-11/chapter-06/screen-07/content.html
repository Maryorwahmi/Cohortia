Definition

DNAT behavior and risks

DNAT rewrites destination addresses so external requests arrive at internal servers. Because this exposes internal services, pair DNAT with strict filter rules and service-level security controls. DNAT must be applied before routing decisions.

  • Use prerouting chain in nat table for DNAT.
  • Open the forward chain for translated flows and allow established states.
  • Confirm correct matching of external IP and port to avoid accidental wide-open forwarding.
nftables DNAT example
table ip nat {
    chain prerouting {
        type nat hook prerouting priority -100; policy accept;
        iifname "eth0" tcp dport 80 dnat to 192.168.0.10:80
    }
}
Tip: After adding DNAT, ensure your forward chain allows new established traffic between external and internal interfaces.
