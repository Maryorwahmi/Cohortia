Module 11 › Chapter 11.6 › NPTv6
What NPTv6 does
It replaces an internal IPv6 prefix with an external one so internal addresses remain stable while outward addressing changes. NPTv6 is useful for renumbering and certain multi-homing scenarios.
When to use it
Use NPTv6 when you cannot renumber internal hosts but need to change provider prefixes or present a consistent external addressing plan for multi-homing.
Misconception
NPTv6 is not a port-forwarding tool. It preserves host identifiers inside the prefix mapping and is intended for prefix-level translation.
Verification
Validate with ping and tcpdump. Confirm that the translated packets use the mapped prefix and that connection tracking remains coherent.
