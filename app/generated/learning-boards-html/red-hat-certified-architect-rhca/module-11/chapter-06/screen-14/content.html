Module 11 › Chapter 11.6 › Key Concepts
Static Route
A manually configured route that specifies a fixed next hop for a destination network.
Policy-Based Routing
Routing decisions based on source, UID, interface, or other packet attributes mapped via ip rules and custom tables.
SNAT / Masquerade
SNAT rewrites source addresses to a specific public IP. Masquerade dynamically uses the interface address for outgoing packets.
Takeaway

These three building blocks allow you to precisely control where packets go and how addresses are presented to the network.
