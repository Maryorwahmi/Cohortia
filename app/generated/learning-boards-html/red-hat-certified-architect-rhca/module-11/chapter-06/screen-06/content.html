Module 11 › Chapter 11.6 › SNAT & Masquerade
Concept

Source NAT behavior

SNAT rewrites packet source addresses so return traffic arrives at the translator. Masquerade is a form of SNAT that uses the outbound interface address dynamically. Both are applied after routing, in postrouting chains.

  • Enable net.ipv4.ip_forward for routed NAT traffic to pass.
  • Place SNAT/masquerade in the nat table postrouting chain.
  • Verify translations with nft list ruleset and tcpdump on the external interface.
nftables example
table ip nat {
    chain postrouting {
        type nat hook postrouting priority 100; policy accept;
        oifname "eth0" ip saddr 192.168.0.0/24 snat to 203.0.113.10 # Specific public IP
        # OR for dynamic IP:
        # oifname "eth0" ip saddr 192.168.0.0/24 masquerade
    }
}
Practice: switch between a fixed snat address and masquerade to observe the differences when the outward IP changes.
