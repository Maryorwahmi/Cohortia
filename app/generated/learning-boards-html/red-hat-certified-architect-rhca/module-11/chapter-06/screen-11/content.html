Module 11 › Chapter 11.6 › Gateway Scenario
Scenario summary
Gateway: eth0 public 203.0.113.10, eth1 private 192.168.100.1. Internal webserver: 192.168.100.100. Objectives: enable IP forwarding, DNAT port 80 to webserver, masquerade outbound, and PBR for webserver-originated traffic.
Starter commands
# 1. Enable IP forwarding
sudo sysctl -w net.ipv4.ip_forward=1
sudo echo "net.ipv4.ip_forward = 1" | sudo tee /etc/sysctl.d/99-ip-forward.conf

# see chapter for full file content
Verification steps
  • sudo nft list ruleset — check nat rules in prerouting and postrouting.
  • sudo ip rule show — confirm webserver_pbr entry exists.
  • sudo ip route show table webserver_pbr — verify default via 192.168.100.254.
  • tcpdump on eth0 and eth1 to confirm DNAT and masquerade behavior.
Configuration excerpt
table inet filter {
    chain forward { type filter hook forward priority 0; policy drop;
        iifname "eth1" oifname "eth0" accept
        iifname "eth0" oifname "eth1" ct state new tcp dport 80 accept
    }
}

table ip nat {
    chain prerouting { type nat hook prerouting priority -100; policy accept;
        iifname "eth0" tcp dport 80 dnat to 192.168.100.100:80
    }
    chain postrouting { type nat hook postrouting priority 100; policy accept;
        oifname "eth0" ip saddr 192.168.100.0/24 masquerade
    }
}
