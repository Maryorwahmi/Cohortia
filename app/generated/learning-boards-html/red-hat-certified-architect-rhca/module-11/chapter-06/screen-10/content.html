Quick checklist
  • Use ip route get from to see the chosen route.
  • Run ip rule show to inspect any PBR entries that change lookups.
  • Review nft list ruleset to confirm NAT and filter rules exist as intended.
  • Capture traffic on both interfaces with tcpdump to observe translation and direction.
Troubleshooting Tip

If ip route get shows a different path than expected, re-check ip rule priorities and custom table contents before changing firewall rules.

Verification commands (examples)
# Inspect rules and routes
sudo ip rule show
sudo ip route show table custom_route
sudo ip route get 8.8.8.8 from 192.168.100.100

# Verify nftables and capture
sudo nft list ruleset
sudo tcpdump -nni eth0 host 203.0.113.10 or host 192.168.100.100
