Module 11 › Chapter 11.6 › Safe Deployment
Testing and persistence
Mirror production interface names in your lab. Persist routes with NetworkManager or system config files. Keep rollback commands handy to remove ip rules and ip route entries quickly if you must restore service.
Security
Limit DNAT to necessary ports and sources, keep filter forward rules tight, and monitor for exposed services you did not intend to publish.
Operational tips
  • Enable net.ipv4.ip_forward before testing NAT functionality.
  • Use nft list ruleset and tcpdump to validate packet translations across interfaces.
  • Monitor conntrack for stale or overflowing entries when NAT volume is high.
