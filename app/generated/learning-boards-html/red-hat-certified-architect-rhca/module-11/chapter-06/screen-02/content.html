Module 11 › Chapter 11.6 › Learning Objectives
01
Configure static routes
Set fixed kernel routes for isolated networks, VPN peers, or when a default gateway is not enough. Example: send 10.0.0.0/24 via an alternate gateway to reach a host behind another router.
VERIFIED COMPETENCY MILESTONE
02
Implement policy-based routing (PBR)
Create ip rules and custom routing tables to route by source IP, UID, or interface. Use PBR for multi-homed hosts and to segregate application flows without changing service code.
VERIFIED COMPETENCY MILESTONE
03
Master advanced NAT with nftables
Write SNAT/masquerade for outbound connectivity and DNAT for incoming services. Understand when to translate prefixes with NPTv6 for IPv6 multi-homing scenarios.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot routing and NAT
Use ip route get, ip rule show, nft list ruleset, and tcpdump to verify that packets follow the expected path and that translations occur as intended.
VERIFIED COMPETENCY MILESTONE
