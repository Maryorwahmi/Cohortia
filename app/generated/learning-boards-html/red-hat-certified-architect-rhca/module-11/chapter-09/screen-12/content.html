Troubleshooting › Diagnose tc issues
Diagnostic commands
tc qdisc show dev eth0
tc -s qdisc show dev eth0
tc -s class show dev eth0
tc filter show dev eth0
Use these to confirm structure and watch counters change under test traffic.
Common errors & fixes
  • Wrong classid/handle: re-check numbers and parent relationships.
  • Typos in filter matches: re-run filter show to validate rules.
  • Priority mix-up: ensure lower numeric prio for higher importance.
Safety note
Misconfigured tc rules can impair connectivity. Test in lab and maintain console access.
