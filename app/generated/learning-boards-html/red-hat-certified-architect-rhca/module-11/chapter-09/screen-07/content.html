Core Concept › HTB hierarchy
Parent and child classes
Create a parent for the total bandwidth, then child classes for services with rate, ceil, and priority attributes.
Example attributes
  • rate: guaranteed minimum bandwidth.
  • ceil: maximum burstable bandwidth.
  • prio: numerical preference used during contention.
Commands (pattern)
sudo tc qdisc add dev eth0 root handle 1: htb default 30
sudo tc class add dev eth0 parent 1: classid 1:1 htb rate 100mbit ceil 100mbit
sudo tc class add dev eth0 parent 1:1 classid 1:10 htb rate 5mbit ceil 20mbit prio 1
sudo tc class add dev eth0 parent 1:1 classid 1:20 htb rate 10mbit ceil 50mbit prio 2
These commands form a parent class and two children with different guarantees and ceilings.
