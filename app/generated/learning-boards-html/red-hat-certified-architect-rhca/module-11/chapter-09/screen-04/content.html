Core Concept › Traffic Shaping
Controlled pacing of packets
Delay or limit transmissions so critical services keep usable performance under load.
Key points
  • Shaping enforces a long-term rate while allowing configured bursts.
  • QoS assigns priority so latency-sensitive flows go first when contention occurs.
  • Design requires rates, ceilings, and classification rules that map traffic to classes.
Analogy
Think of shaping as plumbing valves: HTB is a network of valves sharing a pipe; TBF is a single valve that refills tokens at a steady rate.
Concrete example
A server sending backups could saturate a 100 Mbps link and block SSH. By assigning SSH a guaranteed 5 Mbps and a higher priority, administrators retain remote access even while bulk transfers use leftover capacity.
Key Takeaway

Shaping balances fairness and responsiveness so critical services remain usable under contention.
