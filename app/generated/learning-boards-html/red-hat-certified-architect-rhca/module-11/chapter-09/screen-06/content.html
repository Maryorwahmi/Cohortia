Process Flow › TBF rate limit
How TBF works
Tokens are added at the configured rate. Packets consume tokens. If the bucket lacks tokens, packets are delayed until tokens accumulate.
When to use
  • To cap outbound bandwidth for a single class or application.
  • When you do not need hierarchical sharing across multiple services.
  • To prevent an interface from exceeding an ISP limit.
Example command
sudo tc qdisc add dev eth0 root tbf rate 1mbit burst 10kb latency 70ms
This sets eth0 to 1 megabit sustained, a 10 kilobyte burst allowance, and a queuing latency so packets are not held indefinitely before being dropped.
Key Takeaway
TBF is simple and effective for single-stream rate limits; adjust burst and latency to control short spikes and buffer time.
