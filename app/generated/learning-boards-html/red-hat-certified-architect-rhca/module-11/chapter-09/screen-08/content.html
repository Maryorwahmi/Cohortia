Filter patterns
Use u32 to match ports and assign flowid to a class. Filters can be prioritized so exact matches are evaluated first.
Verification
  • tc filter show dev eth0 to list filters.
  • tc -s class show dev eth0 to view counters for each class.
Typical filter commands
sudo tc filter add dev eth0 protocol ip parent 1:0 prio 1 u32 match ip dport 22 0xffff flowid 1:10
sudo tc filter add dev eth0 protocol ip parent 1:0 prio 2 u32 match ip dport 80 0xffff flowid 1:20
sudo tc filter add dev eth0 protocol ip parent 1:0 prio 99 u32 match ip dst 0.0.0.0/0 flowid 1:30
The catch-all ensures unclassified traffic goes to the default child class.
