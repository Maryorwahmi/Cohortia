Definition › tc components
Component map
Root qdisc (handle)
Entry point for all outgoing packets on an interface.
Classes (classid)
Allocation units with rate and ceil values.
Filters
Classification rules that assign packets to classes.
Leaves
Attached qdiscs that implement shaping or scheduling.
Practical notes
  • Always confirm interface name; wrong interface means no effect.
  • Handles and classids must match when you reference them in filters.
  • Leaves perform the actual token bucket or scheduler work for each class.
Common mistake
Forgetting to delete an existing qdisc before adding a new root qdisc can leave unexpected behavior; use tc qdisc del dev eth0 root to clear.
