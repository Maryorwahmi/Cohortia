Verification › Testing & measurement
Active testing recipes
  1. Start an iperf3 server on a remote host.
  2. Run iperf3 to specific ports to exercise SSH-like and HTTP-like flows.
  3. Use tc -s class show while tests run to observe byte counters and drops.
Pro tip
Use iperf3 reverse mode when you need to test shaping of outbound traffic from the server.
Useful commands
sudo tc -s class show dev eth0
sudo tc -s qdisc show dev eth0
iperf3 -c <remote_ip> -p 80 -t 10 -P 1 -R
Correlate iperf3 throughput readings with class counters to verify the shaping policy works as designed.
