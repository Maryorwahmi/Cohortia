Module 11 › Chapter 11.3 › Key Concepts
NTP
Protocol for clock synchronization across packet networks.
Chrony
Modern NTP implementation on RHEL with chronyd and chronyc.
Stratum
A numeric measure of a source's distance from a primary reference; lower is more authoritative.
Offset
The measured difference between the system clock and the reference time source.
Slewing
Gradually adjust the clock rate to converge to the correct time without a sudden jump.
Stepping
Instantly set the system clock to match the reference time; used for large initial corrections.
Summary
Use these terms to read configuration and chronyc output. They are the vocabulary of time synchronization operations and troubleshooting.
