Module 11 › Chapter 11.3 › Best Practices & Safety
Design principles
  • Use multiple upstream pools/servers for redundancy.
  • Provide internal authoritative servers for low-latency clients.
  • Monitor offsets and source reachability centrally.
Security & operations
  • Protect /etc/chrony.keys and rotate keys as needed.
  • Open UDP 123 only as required and use allow directives for subnets.
  • Document any use of local stratum and monitor these hosts carefully.
Deployment tip
Automate post-change verification: restart chronyd, run chronyc sources/tracking, and fail deployment if sources are unreachable or offsets are high.
Key Takeaway

Combine redundancy, monitoring, and strict authentication to keep time accurate and auditable across environments.
