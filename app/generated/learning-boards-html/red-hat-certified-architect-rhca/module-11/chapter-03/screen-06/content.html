Module 11 › Chapter 11.3 › chronyd modes
Definition

Client, Server, Peer

Each mode declares how chronyd gets or provides time. Choose the mode based on network topology and reliability of upstream sources.

Client
Queries upstream pool/server entries and adjusts local clock. Use iburst for faster initial sync.
Server
Provides time to network clients when ntpserve is enabled and allow directives permit access.
Peer
Mutual synchronization between peers when equal trust is desired.
Configuration highlights
Key chrony.conf directives include pool/server, allow for client access, ntpserve to enable server mode, and local stratum to stand in when upstream sources are unreachable. Also set driftfile and logdir for stability and logging.
Common mistake
Enabling server features without opening UDP 123 or without proper allow directives prevents clients from actually connecting. Always verify firewall rules and restart chronyd after changes.
Key Takeaway

Decide the role based on topology: clients pull, servers provide with ntpserve, and peers synchronize mutually when needed.
