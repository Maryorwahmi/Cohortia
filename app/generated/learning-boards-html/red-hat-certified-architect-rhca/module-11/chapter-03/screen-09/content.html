Module 11 › Chapter 11.3 › Configuring chronyd as a server
Architecture

Server responsibilities

  • Maintain reliable upstream references to public pools or authoritative sources.
  • Answer client requests when ntpserve is enabled and allow permits client subnets.
  • Log adjustments and monitor offsets to avoid serving incorrect time.
Operational checklist
  1. Edit /etc/chrony.conf: add pool/server entries, allow 192.168.x.x/24, ntpserve, and optionally local stratum.
  2. Restart chronyd: sudo systemctl restart chronyd.
  3. Open firewall: sudo firewall-cmd --permanent --add-service=ntp && sudo firewall-cmd --reload.
  4. Verify with chronyc sources and chronyc tracking.
Operational pitfall
Using local stratum without monitoring can propagate incorrect time. Reserve local stratum for isolated networks and document its use.
Key Takeaway

Make servers reliable: upstream sources, firewall rules, ntpserve, and monitoring prevent accidental propagation of bad time.
