Learning Objectives

Learn → Understand → Apply → Master

Bloom: Learn → Understand → Apply → Master
01
Importance of accurate time

Explain how timestamps affect logs, Kerberos, and certificates. This skill helps you reason about incident timelines and authentication failures.

VERIFIED COMPETENCY MILESTONE
02
Configure chronyd client/server

Use pool/server, driftfile, allow, ntpserve and local stratum to set up clients and servers. This enables robust synchronization in diverse networks.

VERIFIED COMPETENCY MILESTONE
03
Implement authentication

Create symmetric keys, secure /etc/chrony.keys, and reference keys in chrony.conf so clients and servers authenticate NTP packets.

VERIFIED COMPETENCY MILESTONE
04
Troubleshoot and verify

Use chronyc sources, tracking, and activity to interpret stratum, offset, and reachability. This helps diagnose firewall or network issues quickly.

VERIFIED COMPETENCY MILESTONE
