Module 11 › Chapter 11.3 › chrony.conf directives
Code example
# /etc/chrony.conf (client example)
pool 2.rhel.pool.ntp.org iburst
pool 0.centos.pool.ntp.org iburst

# Allow NTP client access from local network
allow 192.168.1.0/24

# Write current time drift
driftfile /var/lib/chrony/drift

# Log time adjustments
logdir /var/log/chrony
Use iburst for fast startup. Set driftfile so chronyd remembers hardware drift between reboots and logdir to capture adjustments.
Server example
# /etc/chrony.conf (server example)
pool 2.rhel.pool.ntp.org iburst
allow 192.168.100.0/24
local stratum 10
ntpserve
Remember to open UDP 123 in the firewall and restart chronyd. local stratum acts as a fallback authoritative source when no upstream servers are available.
Key Takeaway

Edit chrony.conf carefully, restart chronyd, and verify with chronyc to confirm the host behaves as client or server as intended.
