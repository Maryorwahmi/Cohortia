Practical objectives

Map to commands, files, and verification steps you will use.

Apply → Verify → Secure
Task
Map hosts and choose sources

Decide which systems need internal authoritative time and which can use public pools for resilience and low latency.

VERIFIED COMPETENCY MILESTONE
Task
Edit chrony.conf and restart

Add pool/server entries, enable ntpserve if acting as a server, set driftfile and logdir, and use iburst for fast initial sync.

VERIFIED COMPETENCY MILESTONE
Task
Create keys and protect them

Place keys in /etc/chrony.keys, set permissions to 600, and reference keys by ID from both client and server for authenticated sync.

VERIFIED COMPETENCY MILESTONE
Task
Verify with chronyc

Use chronyc sources -v and chronyc tracking to confirm state, stratum, and low offset; check firewall rules if sources are unreachable.
