Module 11 › Chapter 11.3 › Slewing vs Stepping
Definitions

Slewing: slowly adjust the clock rate so time converges without abrupt jumps. Safe for running services.

Stepping: immediately set the clock to the reference time. Useful for large offsets or initial corrections.

Practical usage

Use makestep to allow one-time stepping under controlled conditions, for example on first boot or when the offset exceeds a configured threshold.

A common scenario is new deployments where immediate correct time is necessary for authentication and logging.

Misconception
Avoiding stepping altogether can delay resolution of large offsets; instead use makestep under controlled circumstances.
Key Takeaway

Balance safety and speed: allow stepping for large corrections, and rely on slewing for small, ongoing adjustments.
