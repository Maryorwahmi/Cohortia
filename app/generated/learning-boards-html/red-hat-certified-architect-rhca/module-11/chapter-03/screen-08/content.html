Module 11 › Chapter 11.3 › Verifying with chronyc
Example commands
chronyc sources -v
# Shows State, Offset, Stratum, and reference

chronyc tracking
# Shows reference ID, stratum, last offset, and overall sync status

chronyc activity
# Shows number of online/offline sources
Run these commands after restarting chronyd and after changes. Repeat them while troubleshooting to confirm reachability and offset improvements.
Read the output
  • State: ^ server, = peer, ? unreachable — use this to identify why sources aren’t used.
  • Offset: difference in seconds; low is good, persistent high needs action.
  • Stratum: 1 is primary, higher values mean further away from a reference clock.
Troubleshooting step
If State is ?, check UDP 123 is allowed and validate network connectivity to the configured servers or pools.
Key Takeaway

chronyc commands give you the health of synchronization. Learn to interpret State, Offset, and Stratum to act quickly.
