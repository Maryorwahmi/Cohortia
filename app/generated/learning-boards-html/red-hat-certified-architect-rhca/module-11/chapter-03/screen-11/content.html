Module 11 › Chapter 11.3 › Common synchronization issues
Step-by-step checks
  1. Firewall: Ensure UDP 123 is allowed. Use firewall-cmd to add-service=ntp and reload.
  2. Network: Verify DNS and reachability of configured pool/server addresses.
  3. Config: Validate /etc/chrony.conf for typos and /etc/chrony.keys for correct key material and permissions.
  4. Monitoring: Use chronyc sources -v and tracking to see offsets and reachability before and after fixes.
Common errors
  • Forgetting UDP 123 in firewall rules.
  • Mismatched or missing keys causing authentication failures.
  • Persistent network jitter or unreliable upstream servers causing high offsets.
Pro tip
When offsets remain high, try an alternative known-good pool to see if the issue follows the network path or the local host's timing behavior.
Check

If chronyc shows ? for State, treat firewall and connectivity as the first two targets for remediation.
