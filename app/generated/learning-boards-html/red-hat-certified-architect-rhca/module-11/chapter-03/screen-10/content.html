Module 11 › Chapter 11.3 › Symmetric key authentication
chrony.keys example
# /etc/chrony.keys
# Key ID, Key Type, Key Value
1 MD5 YOUR_GENERATED_SECRET_BASE64==

# Protect permissions
sudo chmod 600 /etc/chrony.keys
sudo chown root:chrony /etc/chrony.keys
Ensure both client and server have the exact same key entry and secure permissions before referencing the key in chrony.conf.
chrony.conf usage
# Client config referencing key
server 192.168.100.10 key 1 iburst
After configuration restart chronyd on both ends. Verify with chronyc sources -v to confirm that authenticated sources are in use.
Key Takeaway

Symmetric key authentication ensures clients only trust configured servers. Keep keys secret and permissions restrictive.
