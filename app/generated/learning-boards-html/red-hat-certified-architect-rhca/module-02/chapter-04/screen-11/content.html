Definition Security and Credential Management

Controller credential types

Use Controller cloud credential types to store API keys and IAM information. Job templates reference these credentials so playbooks do not need embedded secrets. Controller also enforces RBAC for credential use.
Best practice: Create scoped credentials per environment and grant only the templates that need them permission to launch.

Audit and least privilege

Assign the minimal IAM permissions required for provisioning tasks and regularly review audit logs of Controller job runs and cloud changes to detect drift or misuse.
Common mistake
Using a single broad credential across many templates increases risk and makes it hard to track which automation performed a change.
