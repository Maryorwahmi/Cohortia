Hands-on Activity Master workflow with ansible-navigator

master_workflow.yml (conceptual)

---
- name: Full Cloud Provisioning and Configuration Workflow
  hosts: localhost
  connection: local
  gather_facts: false
  vars:
    vm_name: "my-app-server"
    vm_os: "RHEL8-Template"
  tasks:
    - name: Run VM Provisioning Playbook
      ansible.builtin.include_tasks: provision_vm.yml
      vars:
        vm_name: "{{ vm_name }}"
        vm_os: "{{ vm_os }}"
      register: provision_output

    - name: Run VM Configuration Playbook
      ansible.builtin.include_tasks: configure_vm.yml
      vars:
        provisioned_vm_ip: "{{ provision_output.ansible_facts.provisioned_vm_ip }}"
      when: provision_output.ansible_facts.provisioned_vm_ip is defined

Practical notes

  • Use debug tasks to simulate provisioning during development.
  • Validate that registered facts exist before passing them to downstream tasks.
  • When converting to Controller, map each include_tasks to separate job templates and chain them in a workflow.
