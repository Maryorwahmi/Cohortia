Comparison AWS vs Azure vs GCP Collections
amazon.aws
Modules include ec2_instance, s3_bucket, rds_instance, vpc_subnet. Useful for declaring AWS-native resources and tags.
Example: amazon.aws.ec2_instance to launch EC2 with AMI, instance type, and subnet.
azure.azcollection
Provides modules for resource groups, virtual machines, virtual networks, and storage accounts tailored to Azure resource model.
Example: modules to create resource groups and attach managed disks for VMs.
google.cloud
Offers modules to manage compute instances, networks, and storage in the Google Cloud model.
Example: google.cloud.compute_instance to declare VMs and network interfaces.
Design Tip

Isolate provider specifics inside roles so switching clouds requires minimal changes to orchestration logic.

Misconception

Collections are interchangeable; but module names and parameters differ and require provider-aware design.
