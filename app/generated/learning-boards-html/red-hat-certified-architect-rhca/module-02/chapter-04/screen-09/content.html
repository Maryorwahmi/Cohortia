Architecture Modular Role Design

Role examples

vpc_setup
Creates VPC, subnets, and outputs subnet IDs as facts for other roles to consume.
ec2_provision
Provisions instances with keys, security groups, and tags; consumes subnet IDs from vpc_setup.
rds_deploy
Deploys managed databases and configures network access using created subnets and security groups.

Composition pattern

Compose roles in workflows: run vpc_setup, register subnet facts, run ec2_provision with those facts, then rds_deploy. Each role should validate inputs and be idempotent so repeated runs do not cause drift.
Key Takeaway

Design small, testable roles and compose them with workflows so teams can reuse components and maintain clear boundaries.
