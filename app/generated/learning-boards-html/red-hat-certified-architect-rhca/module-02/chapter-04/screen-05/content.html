Process Flow Triggering Job Templates

Why trigger the Controller?

  • Centralized credential injection and RBAC for safer automation.
  • Single source of truth for playbooks, inventories, and execution context.
  • Centralized logs and audit trails for compliance and incident response.
Design rule
Pipeline passes minimal runtime parameters like environment and app version. Controller provides credentials and inventory.

Example: awx-cli call

# Example pipeline snippet that launches a Controller job template
awx-cli job_templates launch --name "Deploy Web Application" \
  --extra_vars '{"environment": "staging", "app_version": "1.2.0"}'

# Effect: Controller runs the template, injects credentials via its cloud credential types,
# uses the template's inventory, and records execution in its job output log.
Common mistake
Passing cloud provider credentials as CI variables and running playbooks on the runner increases exposure and fragments audit trails.
