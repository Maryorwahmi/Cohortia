Code Walkthrough Passing Variables and set_fact

Provisioning playbook (excerpt)

---
- name: Provision a VM
  hosts: localhost
  connection: local
  gather_facts: false
  tasks:
    - name: Simulate VM creation
      ansible.builtin.debug:
        msg: "Simulating VM provisioning for {{ vm_name }} with {{ vm_os }}"
      register: vm_provision_result

    - name: Output VM IP (simulated)
      ansible.builtin.set_fact:
        provisioned_vm_ip: "192.168.1.100"
      when: vm_provision_result is success

Configuration playbook (excerpt)

---
- name: Configure the Provisioned VM
  hosts: "{{ provisioned_vm_ip }}"
  gather_facts: false
  become: true
  tasks:
    - name: Simulate Nginx install
      ansible.builtin.debug:
        msg: "Simulating Nginx installation on {{ inventory_hostname }}"
Best practice
Return minimal, well-named facts to downstream jobs instead of entire objects.
Pitfall
Don't store transient values on CI runners; prefer Controller artifacts or extra_vars between templates.
Check
Ensure provisioned variables are defined before configuration steps run to avoid broken playbooks.
