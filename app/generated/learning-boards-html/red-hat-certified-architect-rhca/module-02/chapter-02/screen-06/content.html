Module 2 › Chapter 2.2 › Scaling with Automation Mesh
Process: scale execution
  1. Identify regions and edge locations where managed hosts live.
  2. Deploy Execution Nodes with Execution Environments near these hosts.
  3. Configure secure TLS and credentials so Execution Nodes can contact Controller and managed hosts.
  4. Monitor queue depth and resource utilization; add Execution Nodes to increase throughput.
Misconception: Horizontal Controller scale alone increases execution throughput. Reality: job execution capacity depends on Execution Nodes not Controller count.
Example scenario
A multinational company runs critical jobs in three regions. Deploying Execution Nodes per region reduced median job time by placing execution close to targets and prevented intermittent network failures from impacting central Controller performance.
Operational check: ensure Execution Nodes can reach managed hosts via SSH or WinRM and have proper firewall entries.
Monitoring: track per-node job queues, CPU, and memory to identify when to add capacity.
