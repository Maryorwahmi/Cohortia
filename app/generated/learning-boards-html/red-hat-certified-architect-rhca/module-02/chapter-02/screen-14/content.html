Module 2 › Chapter 2.2 › Design Decision — Global
Scenario summary
Central governance with localized execution to minimize latency and centralize policy control.
Validation steps: measure latency Controller→Execution Node and Execution Node→managed hosts; run sample playbooks in each region and compare durations; verify DB access and replication where required.
Why Automation Mesh
  • Offloads execution from Controller so control plane remains responsive.
  • Enables placement of nodes near managed hosts to reduce latency.
  • Supports centralized governance while distributing execution capacity.
