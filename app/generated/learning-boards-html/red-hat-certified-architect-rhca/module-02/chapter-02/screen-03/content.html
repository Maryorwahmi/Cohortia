Validation steps
  • Run a simulated Controller failure and observe failover via load balancer health checks.
  • Measure job latency from Controller to remote Execution Node and compare against local nodes.
  • Restore Automation Hub content from replicated storage to verify DR procedures.
  • Test PostgreSQL failover and confirm application connectivity without data loss.
