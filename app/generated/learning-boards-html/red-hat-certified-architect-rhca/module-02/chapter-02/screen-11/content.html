Module 2 › Chapter 2.2 › Monitoring & Maintenance
Controller metrics
  • CPU, memory, disk I/O, network latency.
  • API error rates, request latency, UI responsiveness.
Database metrics
  • Connections, slow queries, replication lag, disk usage.
  • Backups status and restore verification.
Execution & Hub metrics
  • Execution Node queue depth, image pull times, container resource usage.
  • Automation Hub storage, repository integrity, and sync status for DR.
Operational practice

Define alert thresholds, tie each alert to a runbook with remediation steps, and practice incident response through tabletop exercises and DR drills. Monitoring without actionable response is noise.
