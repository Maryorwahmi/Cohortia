Module 2 › Chapter 2.2 › Automation Hub Replication
Replication strategy
  • Mirror object storage buckets or sync file shares containing collection artifacts.
  • Replicate repository metadata to preserve collection integrity and versions.
  • Provision a standby Hub instance configured to use replicated storage for quick activation.
Operational tasks
Schedule content sync tasks, verify checksums after transfer, and include image mirroring to avoid long pulls during failover. Test collection pulls from the standby Hub periodically as part of DR drills.
Key Takeaway

Without replicated Hub content, failover may restore Controllers but not the artifacts they need, causing automation failures.
