Module 2 › Chapter 2.2 › Network Design & Firewall
Required flows
  • Controller/Execution Nodes → Managed hosts: SSH (Linux) or WinRM (Windows).
  • Controller nodes ↔ PostgreSQL: TCP 5432 with low latency and secure links.
  • Controller → Automation Hub: HTTPS to pull collections and images.
  • Execution Mesh node communication: TLS-encrypted control channels.
Misconception: Allowing broad network access 'for simplicity' increases attack surface and hides misconfiguration. Always restrict by source and destination where possible.
Operational checklist
  • Define firewall rules per component and validate connectivity with test jobs.
  • Measure latency between Controller and Execution Nodes; aim to place nodes where latency is minimal to managed hosts.
  • Ensure TLS trust between nodes and manage certificates centrally.
  • Document outbound internet requirements for updates and third-party integrations.
Why it matters

Network bottlenecks and misconfigured firewalls are frequent root causes of failed automation jobs and slow orchestration. Map and test all flows before production rollout.
