Module 2 › Chapter 2.2 › Conceptual HA Activity
Steps (conceptual)
  1. Install HAProxy on a separate server and create a frontend listening on 80/443.
  2. Configure a backend with option httpchk GET /api/v2/ping/ and list Controller servers.
  3. Define firewall rules for LB→Controllers and Controllers→PostgreSQL (port 5432).
  4. Simulate failure of one Controller and observe LB health check behavior.
Validation checklist
  • Can you access the Controller UI through the LB after failing one node?
  • Does the standby DB replica show acceptable replication lag?
  • Are Execution Nodes able to reach managed hosts after failover?
Expected outcome

A conceptual understanding of LB configuration and network rules, enabling you to produce an environment-specific haproxy.cfg and firewall plan for HA testing.
