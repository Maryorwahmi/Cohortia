Module 2 › Chapter 2.5 › Continuous Security
Routine
Scan, test, patch, verify
Schedule vulnerability scans and pen tests, and ensure timely patching of Controller, EEs, and database systems.
Scan EEs
Scan images before production use.
Track Remediation
Document fixes and verify in staging.
Example Workflow
On advisory release, scan all execution images and Controller hosts, prioritize fixes, rebuild images from patched bases, and promote via CI to production after testing.
Misconception
Delaying security updates until a convenient time risks exploitation; plan maintenance windows and automate updates where safe.
Key Takeaway

Operationalize security tasks: scanning, testing, patching, and verification make your AAP deployment resilient over time.
