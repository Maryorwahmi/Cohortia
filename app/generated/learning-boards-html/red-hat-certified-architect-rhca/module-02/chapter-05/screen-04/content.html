Module 2 › Chapter 2.5 › RBAC
Definition
Role-Based Access Control
Map users and teams to precise permissions on Controller resources so automation tasks run with controlled authority.
Users, Teams, Organizations
Users are individuals, teams are groups, organizations are resource containers for separation.
Permissions
Assign read, write, execute, or admin on projects, inventories, templates, and credentials.
Common Mistake
Granting admin too broadly undermines audits and increases blast radius.
Key Takeaway

Design a permission matrix that maps roles to minimal permissions and review access regularly.

Structure
Organization
Top-level boundary for users and resources.
Team
Group users to simplify permission assignments.
User
Individual account with assigned team memberships and roles.
Permissions
Apply to resources: project, inventory, job template, credential.
Concrete Example
Create team AppDeployers; grant execute on "Deploy WebApp Staging" template; do not grant view or modify on credential used by the template. Team members run deployments, but cannot view raw keys or change the credential.
