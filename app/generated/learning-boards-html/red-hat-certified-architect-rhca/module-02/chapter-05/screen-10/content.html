Module 2 › Chapter 2.5 › Log Forwarding
Checklist
  1. Identify sources: job events, auth, API, system logs.
  2. Configure secure forwarding (TLS) to SIEM.
  3. Map fields for search and correlation.
  4. Apply retention and access controls.
  5. Create alerts and test detection playbooks.
Example Alert
Alert when a single user executes more than N job runs in M minutes, or when someone modifies credential roles. These anomalies often indicate compromised automation or an insider misuse.
Operational Note
Include log-forwarding configuration in change control so upgrades do not break your SIEM pipeline.
Key Takeaway

Treat log forwarding as an operational service: secure transport, consistent mapping, and regular testing keep your monitoring effective.
