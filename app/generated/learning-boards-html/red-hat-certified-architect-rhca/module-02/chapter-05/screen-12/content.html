Module 2 › Chapter 2.5 › FIPS Compliance
What is required
FIPS-validated cryptography
Enable FIPS on RHEL and ensure all components use FIPS-validated crypto modules and libraries.
Inventory
Catalog components that perform cryptography.
Validate
Ensure libraries are FIPS-validated and configured correctly.
Practical Considerations
Enabling FIPS can affect libraries and integrations; plan testing and validation. Check third-party connectors and custom code that rely on cryptography to ensure compliance.
Misconception
Turning on FIPS at the OS level alone does not guarantee the entire automation stack is compliant.
Key Takeaway

Treat FIPS as a coordination project: enable OS FIPS and validate every component and integration that uses cryptography.
