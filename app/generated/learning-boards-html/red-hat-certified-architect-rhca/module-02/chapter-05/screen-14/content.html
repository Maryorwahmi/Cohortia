Module 2 › Chapter 2.5 › Key Concepts
RBAC
Restrict access by mapping users and teams to resource-level permissions.
Least Privilege
Grant only the minimum permissions needed to perform tasks and review them regularly.
Credential Types
Use centralized credential storage and runtime injection instead of embedding secrets.
Summary: RBAC + least privilege + credential hygiene + protected logging = a secure AAP deployment.
