Module 3 › Chapter 2.6 › ansible-builder & EEs
Define, build, validate
Use execution-environment.yml and requirements.txt to include Python libraries and collections inside an EE image.
Steps
  1. Create requirements.txt listing Python packages your modules need.
  2. Create execution-environment.yml describing dependencies and copy steps.
  3. Run ansible-builder build -f execution-environment.yml -t your-ee:tag.
  4. Test the image locally with ansible-navigator run ... --ee your-ee:tag.
Example execution-environment.yml
---
version: 1
build_arg_defaults:
  ANSIBLE_GALAXY_CLI_COLLECTIONS_PATH: "/usr/share/ansible/collections"
dependencies:
  python: requirements.txt # Include requests from requirements.txt
additional_build_steps:
  prepend_base: |
    # Any system-level packages needed, e.g.,
    # RUN dnf install -y git
  append_final: |
    COPY --from=builder /usr/src/app/my_custom_collection /usr/share/ansible/collections/ansible_collections/my_custom_collection_namespace/my_custom_collection
The append_final step copies your built collection into the EE filesystem so Ansible can import your module at runtime.
