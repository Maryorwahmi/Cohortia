Module 3 › Chapter 2.6 › REST API Integrations
Integration patterns
Use API calls to trigger job templates, pass variables, and poll for results. Keep authentication and auditability central to the design.
ITSM integration
Trigger change workflows and update ticket status with job output.
Monitoring
Launch remediation automatically on alert and record results back into monitoring or ticketing systems.
ChatOps
Allow authorized users to start jobs from Slack or Teams and receive job summaries in chat.
Design cautions
  • Use service accounts with scoped permissions for external systems.
  • Implement polling strategies and backoff when checking job status.
  • Record external origin information in job metadata for traceability.
Example outcome
ServiceNow triggers a Controller job, polls for completion, and updates the change request with job logs—this provides automation-driven change fulfilment with audit trails.
