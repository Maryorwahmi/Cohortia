Module 3 › Chapter 2.6 › Lab: Build EE
Terminal sequence
Follow these commands as a terminal-first demo. Use the example playbook provided in the chapter to validate the module and EE.
mkdir -p my_custom_collection/plugins/modules # create module file under plugins/modules # create requirements.txt with requests # create galaxy.yml and execution-environment.yml ansible-builder build -f execution-environment.yml -t my-custom-ee-with-api:latest ansible-navigator run test_api_module.yml --ee my-custom-ee-with-api:latest
Troubleshooting checklist
  • Verify the collection path inside the built image matches ANSIBLE_GALAXY_CLI_COLLECTIONS_PATH.
  • Check requirements.txt for correct package names and versions.
  • Run an interactive shell in the image to import libraries and inspect collection files.
Expected outcome
ansible-navigator runs the playbook inside the EE and your custom module can call external APIs using requests, producing the expected response data in the playbook output.
