Module 3 › Chapter 2.6 › Objectives — Applied outcomes
Objectives mapped to checkpoints
Module checkpoint

Module supports arguments, check mode, and returns changed boolean plus message. Test by running a playbook that creates and removes a temporary file.

EE checkpoint

Build an EE with requests in requirements.txt and your collection, then run a playbook using ansible-navigator to confirm imports succeed.

API integration checkpoint

Trigger a job via the REST API and poll for completion. Confirm job output is available and map the job ID back to the external system.

SDK checkpoint

Write a short SDK script that generates an inventory, starts a job, and parses the returned results to validate programmatic control.
