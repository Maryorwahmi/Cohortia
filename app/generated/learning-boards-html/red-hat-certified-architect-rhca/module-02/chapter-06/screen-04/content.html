Module 3 › Chapter 2.6 › Custom Modules
Definition & structure
Modules declare their arguments and return structured JSON. They implement idempotent actions and integrate with Ansible's execution model.
Key points
  • Use AnsibleModule for argument parsing and exit_json/fail_json results.
  • Respect check mode and avoid side effects when check mode is enabled.
  • Return changed boolean to let playbooks reason about state transitions.
Common mistake
Treating a script as a module without structured output or idempotency leads to brittle automation and difficult debugging.
Key takeaway
Modules should be predictable, testable, and report state so they can be packaged and reused safely across teams.
Concrete example
# plugins/modules/my_custom_module.py
#!/usr/bin/python
from ansible.module_utils.basic import AnsibleModule

def main():
    module = AnsibleModule(
        argument_spec=dict(
            name=dict(type='str', required=True),
            state=dict(type='str', default='present', choices=['present', 'absent']),
            message=dict(type='str', default='Hello from custom module!')
        ),
        supports_check_mode=True
    )

    name = module.params['name']
    state = module.params['state']
    message = module.params['message']

    changed = False
    result = {}

    if state == 'present':
        if not module.check_mode:
            with open(f"/tmp/{name}.txt", "w") as f:
                f.write(message)
            changed = True
        result['msg'] = f"Resource '{name}' created with message: '{message}'"
    elif state == 'absent':
        if not module.check_mode:
            import os
            if os.path.exists(f"/tmp/{name}.txt"):
                os.remove(f"/tmp/{name}.txt")
                changed = True
        result['msg'] = f"Resource '{name}' removed."

    module.exit_json(changed=changed, **result)

if __name__ == '__main__':
    main()
This example shows argument_spec, supports_check_mode, and correct use of exit_json. Use tests that verify both actions and non-actions to ensure idempotency.
