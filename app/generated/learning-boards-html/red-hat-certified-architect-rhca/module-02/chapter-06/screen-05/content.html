Plugin types and responsibilities
Understand what each plugin type is designed to do and plan accordingly to avoid misuse.
Filter plugins
Transform variables and template content. Keep them pure and fast.
Lookup plugins
Fetch external data at task time, such as CMDB entries or secrets.
Callback plugins
Observe playbook events to emit logs, metrics, or send notifications.
Scenario: CMDB lookup
If you need host metadata from a proprietary CMDB, implement a lookup plugin that performs the network call once per host resolution, returns structured variables, and caches results where appropriate. Avoid placing heavy network calls in a filter that runs repeatedly during template rendering.
Pro tip
Package plugins inside a collection and include that collection in your Execution Environment so every run has the correct plugin code available.
