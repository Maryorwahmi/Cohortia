Module 3 › Chapter 2.6 › Content Lifecycle
Development → Test → Promote → Deprecate
Develop
Feature branches, unit tests, and documentation.
Test
Integration tests in a staging EE that matches production deps.
Promote
Publish to Automation Hub channels following approval and testing.
Governance tip
Automate checks in CI to enforce formatting, tests, and to build the EE so the content is consistently validated before publishing.
