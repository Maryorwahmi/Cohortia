Module 3 › Chapter 2.6 › Key Concepts — Part 1
Custom Modules
Python scripts that implement idempotent actions and return structured results.
Custom Plugins
Filter, lookup, and callback plugins extend variable transforms, data retrieval, and runtime reporting.
ansible-builder
Tool to define and build Execution Environment images including dependencies and collections.
EE Definition File
YAML file that specifies what goes into the Execution Environment image.
REST API
Programmatic interface to launch jobs, manage inventories, and retrieve results for integrations.
Ansible SDK
Python bindings for programmatic control of inventories, jobs, and results processing.
Takeaway
Combine these concepts into a pattern: write modules/plugins, package into collections, build an EE, and distribute through Automation Hub while integrating through API or SDK.
