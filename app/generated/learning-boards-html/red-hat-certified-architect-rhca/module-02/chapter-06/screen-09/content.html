Module 3 › Chapter 2.6 › Ansible SDK
Programmatic automation
Use SDK scripts to assemble inventories, launch playbooks, and handle results when Python is the integration language.
Usage notes
  • Handle authentication and token refresh or scoped service accounts.
  • Process per-host results and build robust error-handling.
  • Log actions and include correlation IDs for traceability in enterprise workflows.
Contrast
Use the SDK for Python-driven tasks and the REST API for language-neutral integrations. Both can coexist in the same architecture depending on team needs.
Concrete scenario
A script builds inventory from a CMDB, launches a job, parses JSON results, and updates CMDB records with configuration state.
