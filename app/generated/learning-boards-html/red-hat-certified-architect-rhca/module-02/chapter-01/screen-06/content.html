Module 2 › Chapter 2.1 › Execution Environments
Definition

Execution Environments

Container images that contain Ansible, collections, and dependencies so jobs run predictably and safely.

Consistency
The same image yields identical runtime behavior across hosts and runs.
Isolation & security
Jobs run in containers, reducing dependency conflicts and protecting the Controller.
Scalability
Images can be run on mesh nodes or orchestrators to increase throughput.
Example & guidance
Concrete example
An EE built with community.general and a locked Python library ensures that automation using JSON parsing behaves consistently across runs.
Operational note
Plan registries and signing so images are trusted and available to mesh nodes, especially in air-gapped sites.
Misconception
EEs are more than packaging; they are an enabler of distributed execution and platform stability.
Key Takeaway

Adopt EEs for reproducibility and scale; align registries and hub policies to make them discoverable and secure.
