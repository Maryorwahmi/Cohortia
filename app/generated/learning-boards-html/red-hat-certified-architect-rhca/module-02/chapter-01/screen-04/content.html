Core Concept

Ansible Controller

The Controller is the central control plane that exposes a UI and API for orchestration, RBAC, scheduling, and logging.

Stateful dependency: PostgreSQL
Job history, schedules, and settings live in a database that must be sized and backed up.
Integration points
LDAP, AD, Git, monitoring, and external services all integrate here for enterprise workflows.
Operational risk
Underestimating DB load or authentication scale leads to degraded scheduling and long job queues.
Definition & example
Definition
The Controller centralizes orchestration, providing the UI, API, and RBAC for job definition and scheduling.
Concrete example
A medium enterprise configures a clustered Controller fronting an external PostgreSQL instance to support 200 concurrent job runs and retain logs for 90 days.
Common mistake
Treating the Controller as stateless and colocating the database on the same small VM, which causes contention under concurrency.
Key Takeaway

Plan the Controller as a stateful service: size and protect the database, and integrate identity early.
