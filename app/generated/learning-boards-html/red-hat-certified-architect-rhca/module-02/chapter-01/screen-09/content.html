Process Flow

Architect for scale

Database sizing
Plan PostgreSQL capacity for retention, concurrent jobs, and reporting load.
Networking & security
Define segmentation, firewall rules, and certificate rotation for Controller and mesh nodes.
Execution capacity
Choose between local runtime, dedicated nodes, or orchestrators for high concurrency.
Checklist & example
Architect checklist
  • External, tuned PostgreSQL instance or managed DB.
  • Load-balanced Controller nodes for HA.
  • Mesh nodes or orchestrated EEs for concurrency.
  • Monitoring and alerting on queues and DB metrics.
Concrete example
High-concurrency design: two Controller nodes, external PostgreSQL with replication, and a fleet of mesh nodes in three regions to handle regional workloads.
Common mistake
Focusing only on Controller HA while neglecting database performance and execution capacity, which still bottlenecks jobs.
Key Takeaway

Plan database, network segmentation, image distribution, and observability together to ensure predictable scaling and recovery.
