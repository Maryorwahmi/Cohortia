Delegation and single-run tasks
Use delegate_to and run_once for operations that must run on one host or against an API to avoid repeated changes.
- name: Create resource once delegate_to: localhost run_once: true ansible.builtin.command: /usr/bin/create_resource.sh
Async and poll
Use async with poll to start long tasks without blocking all hosts. Ensure you capture and check results later.
- name: Start long task ansible.builtin.shell: /usr/bin/long_job.sh async: 3600 poll: 0 - name: Wait for result async_status: jid: "{{ long_job.ansible_job_id }}" register: job_result until: job_result.finished retries: 30 delay: 10
Common misconception

Async removes blocking but you still need to check success and handle failures appropriately.
