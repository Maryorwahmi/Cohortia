Encrypting role variables
Create a vars file and encrypt it so secrets are not stored in SCM.
# Encrypted variable file: vars/secrets.yml
# ansible-vault encrypt vars/secrets.yml
vault_mysql_password: ENC[AES256,...]
After encrypting, reference vault variables in tasks or templates. Use a vault password file or platform-managed credential to supply the password at runtime.
Automation Platform credential types
AAP stores SSH keys, cloud credentials, and tokens securely and injects them to job templates. This avoids baking secrets into playbooks.
Practical tip
Use least privilege when creating credentials and assign them only to necessary job templates to reduce blast radius if a credential is compromised.
Key Takeaway

Encrypt secrets and prefer platform credential injection to eliminate plain-text secrets in repositories and logs.
