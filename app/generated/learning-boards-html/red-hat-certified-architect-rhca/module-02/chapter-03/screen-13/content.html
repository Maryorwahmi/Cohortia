Module 2 › Chapter 2.3 › Activity Overview
Activity steps (conceptual)
  1. Initialize the role skeleton with ansible-galaxy init webserver_config.
  2. Create tasks, handlers, and a template that includes the secret file.
  3. Create vars/vault.yml and encrypt it with ansible-vault encrypt.
  4. Prepare a dynamic inventory script that selects hosts by tag and run the playbook.
Playbook example
---
- name: Configure Webservers
  hosts: tag_Environment_Webservers
  become: true
  roles:
    - webserver_config
Run the playbook with the dynamic inventory and a vault password file. Verify that the role applied successfully and that encrypted variables were used to create the secret file on each host.
