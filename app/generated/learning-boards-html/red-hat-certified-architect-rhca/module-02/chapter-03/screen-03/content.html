Role & Collection Tasks
  • Organize tasks/handlers/vars/templates into role directories for reuse.
  • Package related roles and modules as a collection to standardize across teams.
  • Prefer existing collections before building custom modules.
Security & Credentials
  • Encrypt secrets with Ansible Vault files and reference them from roles.
  • Use AAP credential types to store SSH keys and API tokens centrally.
  • Follow least privilege when assigning credentials to templates.
Execution & Performance
  • Tune forks and choose strategy plugins; enable fact caching to shorten runs.
  • Delegate tasks or use async for operations that should not block all hosts.
  • Monitor control node resources when increasing parallelism.
Resilience & Idempotency
  • Write idempotent tasks; check state before changing resources.
  • Use block/rescue/always to manage failures without stopping unrelated hosts.
  • Use changed_when and failed_when for precise control of task outcomes.
