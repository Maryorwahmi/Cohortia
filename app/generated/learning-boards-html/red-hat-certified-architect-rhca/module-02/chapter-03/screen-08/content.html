Module 2 › Chapter 2.3 › Performance Tuning
Forks
Adjust forks in ansible.cfg or at runtime to increase parallel task execution. Monitor control node CPU, memory, and network when raising forks.
Strategy plugins
Linear is safe and predictable. Free can speed up runs in heterogeneous environments by letting faster hosts progress independently.
Fact caching & monitoring
Enable a fact cache backend such as jsonfile or redis so fact gathering is avoided or accelerated on subsequent runs.
Quick checklist
  • Baseline run time and resource usage.
  • Increase forks incrementally and observe impact.
  • Try free strategy for heterogeneous hosts.
  • Enable fact caching to reduce repeated cost of gathering facts.
Key Takeaway

Performance changes should be measured. Fact caching gives predictable savings, while forks and strategies require monitoring to avoid resource exhaustion.
