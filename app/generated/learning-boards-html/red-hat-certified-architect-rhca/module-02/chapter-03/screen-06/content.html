Module 2 › Chapter 2.3 › Dynamic Inventories
How dynamic inventory works
A plugin or script queries an external API and returns host groups and variables to Ansible at runtime.
Example use case
Filter cloud instances by tag, such as Environment: Production, and assign them to an inventory group used by a playbook. This eliminates manual host list maintenance.
Best practices
  • Test inventory scripts for performance with large datasets.
  • Implement caching to avoid repeated slow API calls.
  • Use tags or filters to limit the scope returned by the inventory.
Practical check
Run the inventory plugin or script and verify the JSON or YAML output contains the expected groups and hostvars. Confirm that a playbook using that inventory runs only against the intended hosts.
Sample invocation
ansible-inventory -i aws_ec2.yml --list
Key Takeaway

Dynamic inventories keep your automation aligned with live infrastructure; test and cache them to avoid runtime surprises.
