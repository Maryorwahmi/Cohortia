Module 2 › Chapter 2.3 › Webserver Role Walkthrough
Starter commands
Initialize the role and create the directory structure.
ansible-galaxy init webserver_config
cd webserver_config
Create and encrypt a secret vars file, then reference it from the role tasks.
echo "vault_web_secret: 'mySuperSecretAPIKey123'" > vars/vault.yml
ansible-vault encrypt vars/vault.yml
Role tasks excerpt
- name: Install Nginx
  ansible.builtin.yum:
    name: nginx
    state: present

- name: Copy Nginx configuration file
  ansible.builtin.template:
    src: nginx.conf.j2
    dest: /etc/nginx/nginx.conf
  notify: Restart Nginx

- name: Copy sensitive web content
  ansible.builtin.copy:
    content: "{{ vault_web_secret }}"
    dest: /etc/nginx/conf.d/secret_token.conf
    mode: '0600'

- name: Start and enable Nginx service
  ansible.builtin.service:
    name: nginx
    state: started
    enabled: true
Key Takeaway

This conceptual flow ties roles, Vault, and dynamic inventory together so you can apply the same role safely to discovered hosts in production.
