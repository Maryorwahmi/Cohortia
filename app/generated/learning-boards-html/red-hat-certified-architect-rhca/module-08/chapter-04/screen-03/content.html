Module 08 › Chapter 8.4 › Learning Objectives
01 Create environment paths
Task: In Satellite navigate to Content → Lifecycle Environments and add Development and Production with proper parents. Pitfall: incorrect parent order breaks promotion flow.
Verification: the environment tree shows Library → Development → Production and a promotion action is available.
02 Publish and promote Content Views
Task: Publish a new Content View version after repo sync, then promote it through environments. Pitfall: skipping publish leaves hosts on old versions.
Verification: hosts in the target environment show the new CV version in their details.
03 Register with activation keys
Task: Create activation key with Content View and environment, then run subscription-manager register on client. Pitfall: wrong activation key assigns incorrect Content View.
Verification: dnf repolist shows Satellite-hosted repos for the assigned Content View.
04 Manage subscriptions & errata
Task: Attach subscriptions, review Candlepin entitlements, and apply errata via Satellite or client. Pitfall: insufficient entitlements prevent repo access.
Verification: host subscription status shows 'Subscribed' and updateinfo lists applicable errata.
