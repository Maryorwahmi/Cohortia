Process Guidance › Common mistakes
Forgot to publish
If you sync repos but don't publish a new CV version, hosts will not see new errata.
Wrong activation key
A misconfigured key can place a host in the wrong environment or without required subscriptions.
Exhausted entitlements
Ensure your manifest has enough subscriptions; otherwise hosts will be Partially Subscribed and blocked from updates.
Checklist
Publish → Promote → Verify version presence → Confirm host subscription status → Apply errata in tested environment.
