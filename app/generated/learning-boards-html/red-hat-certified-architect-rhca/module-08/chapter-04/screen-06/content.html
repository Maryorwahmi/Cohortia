Code Walkthrough › hammer content-view promotion
List versions
# Find the latest version of your Content View
hammer content-view version list --content-view "Base RHEL 8 & Custom Apps" --organization "MyOrg"
Promote a version
# Promote version 1.0 to Development
hammer content-view version promote --content-view "Base RHEL 8 & Custom Apps" \
                                   --version "1.0" \
                                   --to-lifecycle-environment "Development" \
                                   --organization "MyOrg"
Notes & checks
  • Ensure the specified lifecycle environment exists.
  • Verify task history for success and check the Content View versions in target environment.
  • Remember: versions are immutable snapshots; promotion copies, not edits.
Pro tip
Script the list-and-promote sequence with validation to avoid accidental promotions to Production.
