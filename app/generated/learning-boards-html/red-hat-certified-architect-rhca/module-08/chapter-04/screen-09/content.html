Comparison › Subscribed vs Partially Subscribed
Subscribed
Host has required entitlements and can access all repos included in its Content View and lifecycle environment.
  • Allows dnf to see Satellite-hosted repos.
  • Receives applicable errata and package updates.
  • Typically shows 'Subscribed' in Satellite host details.
Partially Subscribed / Expired
Host is missing some entitlements or subscriptions have expired, which blocks repository access and updates.
  • Often due to exhausted pools or missing subscription attachment.
  • Fix by attaching the correct pool or updating the subscription manifest.
  • Verify with 'subscription-manager status' and Satellite host details.
Operational tip
Automate subscription audits and alert on 'Partially Subscribed' hosts so you can remediate before updates are required.
