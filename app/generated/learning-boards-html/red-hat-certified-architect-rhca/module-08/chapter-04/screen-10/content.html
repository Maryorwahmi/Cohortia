Definition › Apply errata and updates
Client checks
# Check for available errata
sudo dnf updateinfo list security
sudo dnf updateinfo list bugfix
sudo dnf updateinfo list enhancement

# Apply updates
sudo dnf update
Ensure the client repos point to the Satellite-provided Content View before applying updates.
Satellite flow
Sync repositories, publish a new Content View version, promote it to the target environment, then apply errata to hosts via Satellite or have clients pull updates.
Common pitfall
If you sync new errata but don’t publish and promote a new Content View version, hosts will not see the new patches.
