Process Flow › Register host
Install and register
sudo dnf install subscription-manager -y

# Replace values with your Satellite FQDN and activation key
sudo subscription-manager clean
sudo subscription-manager register --org="MyOrg" --activationkey="rhel8_dev_key" --serverurl="https://satellite.example.com" --baseurl="https://satellite.example.com/pulp/content" --force

# Verify
sudo subscription-manager status
sudo dnf repolist
Checks & pitfalls
  • Ensure activation key includes the correct Content View and subscriptions.
  • Run 'dnf repolist' to confirm repos are Satellite-provided.
  • If a host is not subscribed, it will not receive updates — verify entitlements in Satellite.
Analogy
Activation keys are like a registration template: they apply a set of attributes in one command.
