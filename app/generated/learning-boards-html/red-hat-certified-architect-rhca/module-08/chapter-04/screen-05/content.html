Process Flow › Create environment path
Step-by-step
  1. Open Content → Lifecycle Environments in Satellite UI.
  2. Create Development with parent Library.
  3. Create Production with parent Development.
  4. Publish and promote Content View versions along this path.
Verification: the environment tree shows Library → Development → Production and promotion actions list the next environment.
Common mistakes & checks
  • Don't set the wrong parent order; promotions will not reach intended targets.
  • Don't treat Library as a production environment; it's the synchronization container.
  • Check promotion history to ensure versions traveled the expected path.
Try this
Create a two-stage path: Dev → Prod, publish a small Content View change, and promote through Dev to verify history and availability.
