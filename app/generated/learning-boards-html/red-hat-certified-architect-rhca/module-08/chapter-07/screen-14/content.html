Troubleshooting › Sync & Visibility
Diagnostic checklist
  • Confirm repository synchronization.
  • Verify Content View filters are not excluding content.
  • Ensure the correct Content View version is published and promoted.
  • Check host registration and subscriptions.
Log locations
Review /var/log/messages and /var/log/foreman/production.log for synchronization and API errors. Check disk space on /var/lib/pulp.
Key Takeaway

Work top-down: server sync and publish, filters and promotion, then client registration and logs. Document any repeated failures.

Practical fix example
If a package is missing, check if the repo contains it, ensure no filter excludes it, publish a new CV version, promote to the host's lifecycle environment, then on the host run dnf clean all and retry.
Misconception
Don't assume the client is the issue first; often a missing publish or promotion is the root cause.
