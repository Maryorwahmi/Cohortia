Core Concept › Package Version Filters
Why filter by version?
To block a specific problematic release while allowing other versions of the same package to flow through updates.
Common mistake
Excluding by name only can prevent necessary fixes. Scope filters to versions when possible and document why the version is excluded.
Key Takeaway

Use versioned exclusions for precision, publish a new CV version, and test the result in a non-production lifecycle environment.

Example CLI
# Exclude a specific package version
hammer content-view filter create --content-view "RHEL8_Base_CV" \
  --name "Exclude_Bad_Package" \
  --type package \
  --inclusion-type exclude \
  --package-name "bad-package" \
  --package-version "1.0.0"
After running this command, publish a new Content View version to apply it.
Analogy
Think of a package filter like a safety gate that blocks a specific defective serial-number batch while leaving the rest of the production line running.
