Process › Applying Errata
Scope selection
Decide whether to apply to a single host, a host group, or an entire lifecycle environment based on risk and testing results.
Execution safety
Confirm subscriptions, host registration, and Content View promotion before running remote execution to apply updates.
Key Takeaway

Prefer targeted errata application and validate host state. Use remote execution with caution and monitoring.

Example commands
# List errata for a host
hammer host erratum list --name myclient.example.com --organization "MyOrg"

# Apply a specific erratum to a host
hammer host erratum apply --host myclient.example.com --errata-ids RHSA-2023:1234 --organization "MyOrg"
Prefer applying specific IDs during targeted maintenance windows.
Misconception
Remote execution is not a substitute for validation. It simplifies deployment but you still need pre-checks and post-verification steps.
