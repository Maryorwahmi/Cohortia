Module 8 › Chapter 8.7 › Key Concepts
Package Filter
Include or exclude RPMs by name and version to prevent problematic releases from reaching hosts.
Errata Filter
Control errata exposure by type so production only receives vetted updates.
Module Stream Filter
Pin streams like python38 to make runtime behavior consistent across hosts.
Summary
Filters shape published content. Publish new immutable Content View versions after filter changes, then promote sequentially for safe rollout.
