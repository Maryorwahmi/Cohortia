Definition › Module Stream Filter
What is a module stream?
A stream is a distinct minor/major line of packages for a component, allowing multiple versions to be available in parallel.
Why pin a stream?
To ensure all hosts use the same runtime version and avoid runtime incompatibilities caused by drifting streams.
Key Takeaway

Explicitly enable module streams in Content Views to guarantee consistent component versions across lifecycle environments.

Example
hammer content-view filter create --content-view "RHEL8_Base_CV" \
  --name "Enable_Python38" \
  --type module \
  --inclusion-type include \
  --module-stream "python38" \
  --repository "Red Hat Enterprise Linux 8 for x86_64 - AppStream RPMs"
Publish a new Content View version after creating this filter to include the module stream.
Pitfall
Not specifying streams can let hosts pick differing streams from AppStream; always pin in production-focused Content Views.
