Architecture › ISOs & Container Images
Custom ISOs
Create a File type repository and upload ISOs. Use them in provisioning templates for consistent installations and utilities.
Container images
Create a Docker type repository and push images into Satellite's registry to centralize distribution and scanning.
Key Takeaway

Use Satellite's file and OCI support to centralize internal ISOs and images, and verify pulls from your clusters or clients.

Podman push example
# Login to Satellite registry
podman login -u admin -p <admin_password> satellite.example.com:8443

# Tag the image
podman tag my-custom-app:latest satellite.example.com:8443/my-custom-product/my-custom-app:latest

# Push the image
podman push satellite.example.com:8443/my-custom-product/my-custom-app:latest
After pushing, confirm the image can be pulled by your internal clusters.
Misconception
Pushing custom images is not the same as syncing from external registries. Use push for internal builds and sync for third-party registries.
