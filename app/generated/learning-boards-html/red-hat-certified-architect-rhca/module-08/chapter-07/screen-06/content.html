Core Concept › Errata Types
Security
Critical for vulnerabilities
Prioritize testing and deployment. Often allowed for rapid promotion to production after verification.
Bugfix
Stability fixes
Important for system reliability; typically promoted after QA validation.
Enhancement
Feature changes
Defer to non-production until tested. Enhancements can change behavior and should be released cautiously.
Example filter
hammer content-view filter create --content-view "RHEL8_Base_CV" \
  --name "Security_Bugfix_Only" \
  --type erratum \
  --inclusion-type include \
  --errata-type security,bugfix
This ensures published Content View versions only include the listed errata types.
Verification
On a registered client run dnf updateinfo list security and list enhancement to confirm the filter's effect.
Key Takeaway

Errata filters implement policy at publish time — include only the categories you trust for each lifecycle stage.
