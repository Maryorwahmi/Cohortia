Module 8 › Chapter 8.6 › Import Roles
Recommended: Git import
Push your role to a Git repository and import it via Satellite UI: Configure → Ansible → Roles → Import from Git.
Before importing, validate role structure and syntax to avoid runtime errors after assignment.
Lab Note
If you cannot use a remote Git repo in the lab, copy the role to a path on Satellite and discover it with hammer or UI discovery methods.
Example role structure (conceptual)
nginx_role/
  tasks/
    main.yml
  templates/
    index.html.j2
  defaults/
  meta/
After import, roles are selectable when editing Host Groups or individual hosts under the Ansible Roles tab.
Misconception: Importing a role alone will not apply it automatically until it is assigned to a host group or run manually.
