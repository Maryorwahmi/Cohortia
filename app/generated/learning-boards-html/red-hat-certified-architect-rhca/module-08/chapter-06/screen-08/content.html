Module 8 › Chapter 8.6 › Assign Roles
Assign roles to host groups
Open Configure → Host Groups, edit the group, and add roles under Ansible Roles. Any host in that group inherits the role application when runs are triggered.
  • Host Group assignment scales configuration across many systems.
  • Roles can also be added at an individual host level for exceptions.
  • Parameters can be defined at multiple levels to customize behavior.
Parameter precedence
Satellite parameters around provisioning and Ansible follow clear precedence: organization → location → host group → host. Use this to plan defaults and safe overrides.
Example
Set apache_port at the host group level for all web servers, then override on a single host if needed. The host-level parameter wins.
Tip: Avoid per-host overrides when possible to reduce configuration sprawl and simplify auditing.
