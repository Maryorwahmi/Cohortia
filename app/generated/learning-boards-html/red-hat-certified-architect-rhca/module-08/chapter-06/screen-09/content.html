Module 8 › Chapter 8.6 › Run Roles
Run via Satellite UI
Select Hosts → Content Hosts, choose targets, and click Run Ansible Roles to execute assigned roles. Inspect Monitor → Jobs for the report.
When to use UI
One-off maintenance, exploratory runs, or small-scale verification.
Run via hammer CLI
Use hammer for scripted invocations and automation pipelines. The following example triggers a job template and passes an ansible role parameter to a specific host via search query.
hammer job-invocation create \
--feature ansible_roles \
--job-template "Run Ansible Roles" \
--search-query "name = myclient.example.com" \
--parameters "ansible_roles=apache_webserver_role" \
--organization "MyOrg"
Note: Use search queries to target groups or named hosts and parameterize role selection as needed.
