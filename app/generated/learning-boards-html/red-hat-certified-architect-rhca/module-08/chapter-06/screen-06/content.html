Module 8 › Chapter 8.6 › foreman.foreman Plugin
Install the collection
On your Ansible control node install the collection so the plugin is available to inventory lookups.
ansible-galaxy collection install foreman.foreman
Create inventory.yml as shown and secure the credentials with vault or environment variables in production.
# inventory.yml
plugin: foreman.foreman.foreman
url: https://satellite.example.com
username: ansible_user  # A Satellite user with API access
password: your_secure_password
validate_certs: true
# Optional: host_filters:
#  - content_view = "RHEL8_Base_CV"
#  - hostgroup = "Web Servers"
Verify inventory and connectivity
Use ansible-inventory to list hosts and then run a simple ping module across the inventory to confirm Ansible can reach returned hosts.
ansible-inventory -i inventory.yml --list
ansible -i inventory.yml all -m ping
Contrast: A static hosts file can become out-of-date when hosts are provisioned or retired. Using Satellite keeps inventory accurate and auditable.
