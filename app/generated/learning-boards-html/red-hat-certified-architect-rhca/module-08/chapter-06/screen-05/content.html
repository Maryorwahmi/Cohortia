Module 8 › Chapter 8.6 › Enable Integration
Enable the plugin
Confirm foreman-proxy-plugin-ansible is installed on the Satellite Server or Capsule that will run jobs. Decide execution locality based on where managed hosts live.
Decide Capsule vs Satellite
Use a Capsule near hosts for large deployments to reduce latency and central load.
Validate
Ensure Capsule/Satellite can reach managed hosts over SSH and has API connectivity back to Satellite if required.
Verification and Tests
Use small, targeted runs to confirm configuration before broad execution. Example: pick a single host and run a simple role or ping module through Satellite.
# Example verification steps (conceptual)
# 1. Confirm package: foreman-proxy-plugin-ansible is present on capsule or satellite
# 2. Check capsule can SSH to client and that API traffic is allowed
# 3. Trigger a small run from UI and inspect Monitor → Jobs for status
Common misconception: Installing the plugin is sufficient. You must also ensure network, credentials, and permissions are correct for execution to succeed.
