Module 8 › Chapter 8.6 › Dynamic Inventory
What is dynamic inventory?
Satellite supplies a live list of managed hosts and parameters to Ansible via a plugin so your control node always targets the correct hosts.
  • Eliminates the need for a manually maintained hosts file.
  • Automatically reflects provisioning, decommissioning, and group changes.
  • Exposes host parameters that roles can consume as variables.
Concrete Example
Install the foreman.foreman collection and create an inventory.yml that points to Satellite. Running an inventory list returns current hosts.
Key Takeaway

Dynamic inventory centralizes host discovery to prevent targeting errors and reduce operational drift.

Inventory Setup — Visual Steps
The following code snippet is the minimal inventory.yml you use on your Ansible control node to talk to Satellite.
plugin: foreman.foreman.foreman
url: https://satellite.example.com
username: ansible_user  # A Satellite user with API access
password: your_secure_password
validate_certs: true
# Optional: host_filters:
#  - content_view = "RHEL8_Base_CV"
#  - hostgroup = "Web Servers"
Run verification commands to confirm hosts are returned and reachable.
ansible-galaxy collection install foreman.foreman
ansible-inventory -i inventory.yml --list
ansible -i inventory.yml all -m ping
Misconception: Dynamic inventory removes access controls. It simply centralizes discovery; you still need proper API credentials and network access.
