What Satellite stores
Satellite will clone or reference role content imported from Git or local paths and surface them in the UI for assignment to host groups and hosts.
Example Role Behavior
An nginx role should install the package, enable and start the service, and deploy a templated index page using provided variables.
Role sample task (conceptual)
---
- name: Install Nginx
  ansible.builtin.dnf:
    name: nginx
    state: present

- name: Start and enable Nginx service
  ansible.builtin.systemd:
    name: nginx
    state: started
    enabled: true

- name: Copy Nginx default index page
  ansible.builtin.template:
    src: index.html.j2
    dest: /usr/share/nginx/html/index.html
    mode: '0644'
Remember to validate role syntax and test in a lab environment before broad assignment.
