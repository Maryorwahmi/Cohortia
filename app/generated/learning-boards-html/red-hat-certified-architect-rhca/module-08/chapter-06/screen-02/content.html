Learning Objectives
These objectives focus on the practical tasks and verifications you'll perform using Satellite and Ansible.
Learn → Understand → Apply → Master
Explain Satellite–Ansible integration
Describe how Satellite provides inventory and role management so teams can build automated lifecycles. Verified competency milestone: architecture review.
Mnemonic: Venn (Inventory ∩ Roles = Automated State)
Configure Satellite as inventory
Set up the foreman.foreman collection and inventory.yml so Ansible queries Satellite directly. Verified competency milestone: inventory.yml test run.
Mnemonic: Timeline (install → configure → test)
Import and assign roles
Import roles from Git, attach them to host groups, and override parameters as needed. Verified competency milestone: imported role appears in list.
Mnemonic: Icons (Git → Satellite → Host Group)
Run jobs and troubleshoot
Trigger roles via UI or hammer CLI and inspect Monitor → Jobs for detailed reports. Verified competency milestone: resolve a common SSH failure.
Mnemonic: Checklist (Run → Inspect → Fix)
