Module 8 › Chapter 8.6 › Troubleshooting
Common failure modes
  • SSH connectivity blocked by firewall or wrong credentials.
  • Missing Python interpreter on the managed host prevents module execution.
  • Syntax or role errors introduced before import.
  • Insufficient permissions for the Satellite user or network segmentation blocking Capsules.
Diagnosis steps
  1. Open the job report in Monitor → Jobs to read raw Ansible logs.
  2. Verify SSH to the client from the execution point; check keys and firewall rules.
  3. Confirm Python exists on the client and is in PATH.
  4. Run role syntax checks locally and re-import if needed.
Misconception: Job failures always mean role issues. Begin with connectivity and client checks first; they are most common.
