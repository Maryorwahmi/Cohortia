Module 8 › Chapter 8.6 › Best Practices
Credentials
Use least-privilege service accounts for API access and protect SSH keys with vaulting and rotation policies.
Role Lifecycle
Version roles in Git, validate before import, and promote through environments to production only after testing.
Change Control
Limit host-level overrides and require reviews for parameter changes. Retain job reports for audit trails.
Key Takeaway

Secure credentials, version control roles, and apply disciplined change control to keep automation reliable and auditable.
