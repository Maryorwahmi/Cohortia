Lab Practice
Follow the activity to create a simple Nginx role, import it, assign it to a Host Group, and verify Nginx runs on a test host. This validates your end-to-end workflow from Git to Satellite to managed host.
Step
Create role structure, commit to Git, import via Configure → Ansible → Roles.
Step
Assign role to Host Group and provision or update host to trigger application.
Step
Inspect Monitor → Jobs for execution output and verify service state on the host.
Troubleshooting Checklist
  • Confirm SSH connectivity and credentials from Satellite or Capsule to the client.
  • Ensure a Python interpreter is available on the client for Ansible to run tasks.
  • Validate role syntax locally before import to avoid runtime failures.
  • Check the Satellite user account permissions and capsule availability if using a Capsule for execution.
