Module 8 › Chapter 8.6 › Nginx Role Lab
Create role structure
mkdir -p ~/nginx_role/{tasks,handlers,templates,vars,defaults,meta}
# tasks/main.yml contains the install, start, and template tasks
Add an index.html.j2 template that references ansible_hostname so you can verify the page was deployed by the role.
<!DOCTYPE html>
<html>
<head>
    <title>Nginx from Satellite Ansible</title>
</head>
<body>
    <h1>Hello from Nginx provisioned by Satellite and Ansible!</h1>
    <p>This page was deployed on {{ ansible_hostname }} via an Ansible role managed by Satellite.</p>
</body>
</html>
Import and verify
Initialize a Git repo, push to a remote, then use Satellite's UI import-from-Git. After import, attach the role to a Host Group and run against a test host.
If Git is unavailable, copy the role to a path on Satellite and use hammer ansible role import or the UI discovery process as a lab fallback.
Check

Verify Nginx is running and the custom index page contains the managed host name to confirm the role executed successfully.
