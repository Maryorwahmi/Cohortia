Configuration Management with Satellite + Ansible
Integrate Satellite’s lifecycle controls with Ansible’s declarative playbooks to enforce host state.
Interactive 16:9 Masterclass
This chapter walks through the practical setup and workflows you need as an architect: enabling the foreman-proxy Ansible plugin, configuring Satellite as a dynamic inventory via the foreman.foreman collection, importing roles from Git, assigning them to host groups, running plays from the UI or hammer CLI, and inspecting job reports to troubleshoot failures. You’ll see worked command examples and a hands-on activity to import an Nginx role and apply it to a host group.
Why this matters
Automation reduces drift and ensures compliance from provisioning to runtime. Satellite + Ansible ties content and configuration together.
Practical outcome
You’ll be able to use Satellite as an inventory source and trigger roles so new hosts are configured automatically.
