Capsule Servers and Scalability
Extending Satellite services closer to managed hosts to lower WAN usage and speed provisioning.
Why Capsules matter

Capsules cache content, provide local network services, and proxy configuration management, which reduces cross-site traffic and improves performance for remote hosts.

What you'll learn
  • Planning placement, sizing storage and network needs for Capsules.
  • Installing a Capsule using satellite-installer and enabling pulp content.
  • Registering hosts to use a Capsule and syncing Content Views.
