Module 8 › Chapter 8.8 › Installing a Capsule
Prerequisites and registration
  • Register the RHEL host with subscription-manager and an activation key tied to the Capsule subscription.
  • Ensure FQDN resolves forward and reverse, and NTP/chrony is configured.
  • Enable Satellite and Capsule repositories before installing packages.
Installer command example
sudo subscription-manager register --org="MyOrg" --activationkey="my_capsule_key" --serverurl="https://satellite.example.com" --baseurl="https://satellite.example.com/pulp/content" --force

sudo subscription-manager repos --enable=rhel-8-for-x86_64-baseos-rpms \
  --enable=rhel-8-for-x86_64-appstream-rpms \
  --enable=satellite-6.13-for-rhel-8-x86_64-rpms \
  --enable=satellite-capsule-6.13-for-rhel-8-x86_64-rpms

sudo dnf update -y

sudo satellite-installer --scenario capsule \
  --capsule-parent-fqdn satellite.example.com \
  --foreman-proxy-dns true \
  --foreman-proxy-dns-interface eth0 \
  --foreman-proxy-dns-forwarders 8.8.8.8 \
  --foreman-proxy-dhcp true \
  --foreman-proxy-dhcp-interface eth0 \
  --foreman-proxy-dhcp-range "192.168.200.10 192.168.200.200" \
  --foreman-proxy-tftp true \
  --foreman-proxy-tftp-interface eth0 \
  --enable-foreman-proxy-plugin-ansible \
  --enable-foreman-proxy-plugin-discovery \
  --pulp-content-pulp_nodes true
Installer notes

Enable pulp_nodes to allow local content caching. If you plan to offer DHCP/DNS/TFTP, enable the corresponding foreman-proxy flags and ensure firewall rules permit those services.

Troubleshooting tips
  • Verify the Capsule appears under Infrastructure > Capsules in the Satellite UI after install.
  • Run a small Content View sync to test disk and network behavior before enabling heavy client traffic.
Pro Tip

Install with minimal services first to validate basic connectivity and certificates, then enable DHCP/DNS/TFTP once the Capsule is visible in Satellite.
