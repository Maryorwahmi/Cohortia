Module 9 › Chapter 8.9 › Objectives — Lab Skills
Validation Steps
  • Schedule db:sessions:clear and confirm session rows drop over time.
  • Run foreman-maintain backup capture and verify backup files exist in the target path.
  • Delete a test host and confirm an audit entry records the action.
Common Checks
  • Check /var/lib/pulp for disk usage growth patterns.
  • Confirm DNS, ports 443 and 5647, and NTP sync for registration problems.
  • Review /var/log/foreman/production.log for specific errors.
Security Checks
  • Verify RBAC roles limit permissions to necessary actions.
  • Confirm external IdM users map correctly to Satellite roles.
  • Monitor Administer › Audits for anomalous activity.
