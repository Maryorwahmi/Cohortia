Connectivity checks
# From Satellite/Capsule
ssh -v client.example.com
nc -zv client.example.com 22
# Check client python
ssh client.example.com python3 --version
Job logs & validation
  • Review Monitor › Jobs in Satellite for per-task failures.
  • Check client /var/log/messages or sudo logs for permission errors.
  • Confirm the target user can run required commands or sudo without prompts.
Pro-tip

Reproduce failing commands interactively on the client to isolate permission or interpreter issues.
