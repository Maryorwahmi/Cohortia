Registration flow checks
Quick tests
# DNS check
getent hosts satellite.example.com
# Port checks
nc -zv satellite.example.com 443
nc -zv satellite.example.com 5647
# Time sync
timedatectl status
Guidance
  • Confirm activation key has available subscriptions before using it.
  • Check the Satellite registration logs for explicit errors after attempted registration.
  • Ensure firewall rules between client and Satellite/Capsule allow needed traffic.
Misconception

Assuming certificate errors are always the cause; network and activation key issues are more common and easier to fix.
