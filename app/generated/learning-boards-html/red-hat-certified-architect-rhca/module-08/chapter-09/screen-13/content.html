Module 9 › Chapter 8.9 › Security Best Practices
RBAC

Create focused roles, assign groups, and remove unnecessary Admin privileges to enforce least privilege.

External IdM

Integrate Satellite with IdM or Active Directory and map external groups to Satellite roles for centralized control.

Certificates

Use trusted CAs in production and monitor expiration. Prefer external CA over self-signed certificates.

Auditing & Firewall

Auditing

Review Administer › Audits regularly to track administrative actions and detect anomalies.

Firewall

Restrict access to Satellite/Capsule ports to only necessary sources and networks.

Common mistakes
  • Using default admin credentials
  • Not integrating with external IdM
  • Granting overly broad permissions
