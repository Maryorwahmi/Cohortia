Checklist
  • Network connectivity to Red Hat CDN
  • Valid subscription manifest
  • Sufficient disk on /var/lib/pulp
  • Relevant logs: /var/log/pulp, /var/log/foreman/production.log
Example diagnostic
# Check disk
sudo df -h /var/lib/pulp
# Inspect pulp logs
sudo tail -n 200 /var/log/pulp/pulp_*.log
# Check foreman logs
sudo tail -n 200 /var/log/foreman/production.log
Misconception

Restarting services without capturing logs may lose error context. Capture logs first, then act.
