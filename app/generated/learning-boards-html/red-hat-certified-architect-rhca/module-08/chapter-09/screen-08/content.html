Module 9 › Chapter 8.9 › Backup & Restore
Full Backup Command
sudo foreman-maintain backup capture /var/lib/foreman-backup
  • The archive contains DB dumps, config files, and Pulp metadata; it can be large.
  • Run during a maintenance window and ensure enough free target space.
  • Store the backup on separate storage and encrypt when appropriate.
Restore Practice
  1. Copy backup to test host or recovery environment.
  2. Run documented restore steps and validate services start.
  3. Confirm content lookups and subscription services are functional.
Key takeaway

Backups are only useful when you can restore them reliably — schedule and test restores regularly.
