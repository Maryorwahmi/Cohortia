Module 9 › Chapter 8.9 › Database Cleanup
Command Walkthrough
sudo foreman-rake katello:delete_old_content_views
sudo foreman-rake katello:clean_orphaned_content
sudo foreman-rake katello:candlepin_cleanup
sudo foreman-rake db:sessions:clear
Guidance
  • Schedule these in a maintenance window and monitor disk I/O impact.
  • Configure retention thresholds consistent with your policy before running.
  • Always test on a staging copy when possible for high-risk cleanups.
Verification
  • List content-view versions: hammer content-view version list --content-view "My_CV" and confirm usage.
  • After cleanup, check du -sh /var/lib/pulp and database size queries.
  • Check logs for rake task errors in /var/log/foreman/production.log or journalctl.
Key takeaway

Use provided rake tasks, validate references, and monitor the environment post-run.
