Module 9 › Chapter 8.9 › Routine Maintenance
Definition

Routine maintenance explained

Scheduled tasks that remove stale data, rotate logs, prune unused content and apply updates so Satellite stays healthy and performant.

Why it matters

Prevents disk exhaustion, reduces query load, and lowers incident risk.

Common mistake

Deleting files under /var/lib/pulp manually instead of using supported cleanup commands can corrupt metadata.

Key takeaway

Automate supported cleanup tools and monitor space and DB trends.

Example
# Sample scheduled commands (cron or systemd timer)
sudo foreman-rake katello:delete_old_content_views
sudo foreman-rake katello:clean_orphaned_content
sudo foreman-rake db:sessions:clear
# Verify disk and DB after run
sudo du -sh /var/lib/pulp
sudo -u postgres psql -c "SELECT pg_size_pretty(pg_database_size('foreman'))"
Check

Confirm no content-view versions assigned to hosts before deleting.

Misconception

Assuming manual file deletion is faster; it risks leaving orphaned metadata.
