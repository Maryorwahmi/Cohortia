Practical checklist
Copy

Move backups to separate storage and verify integrity after transfer.

Encrypt

Encrypt backups to protect sensitive configuration and subscription metadata.

Test

Restore into staging and verify services, content, and UI state match expectations.

Example test run
  1. Capture backup with foreman-maintain.
  2. Copy archive to backup storage and verify checksum.
  3. Restore archive to a staging Satellite and validate content views and host registration.
