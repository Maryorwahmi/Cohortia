Module 9 › Chapter 8.9 › Content Pruning
Step-by-step
  1. List Content View versions: hammer content-view version list --content-view "My_CV"
  2. Confirm the version is not assigned to hosts or environments.
  3. Delete the unused version: hammer content-view version delete --content-view "My_CV" --version "1.0"
  4. Run cleanup: sudo foreman-rake katello:clean_orphaned_content
Example & Verification
# List versions
hammer content-view version list --content-view "My_CV"
# Delete an unused version
hammer content-view version delete --content-view "My_CV" --version "1.0"
# Clean orphaned files
sudo foreman-rake katello:clean_orphaned_content
# Check disk usage
sudo du -sh /var/lib/pulp
Misconception

Removing the version alone does not delete the package files. Run the orphaned content cleanup to free space.
