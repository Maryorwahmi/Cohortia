Module 8 › Chapter 8.5 › Troubleshooting Provisioning
Network boot failure

Symptoms: client never downloads kernel. Checks: DHCP options, TFTP server address, firewall UDP 69, Capsule TFTP settings.

Kickstart or ERB errors

Symptoms: Kickstart missing or installer aborts. Checks: preview generated Kickstart, validate ERB variables exist, test syntax.

Missing packages

Symptoms: dnf errors during install. Checks: ensure packages are in the assigned Content View and repositories synchronized.

Compute credential issues

Symptoms: Satellite cannot create or power a VM. Checks: API endpoint reachability, correct credentials and permissions.

DNS and registration

Symptoms: host does not appear in Satellite inventory after install. Checks: forward/reverse DNS, network access to Satellite, subscription-manager registration logs.

Remediation example

If TFTP is misaddressed in DHCP, update the DHCP server or Capsule settings to point clients to the correct TFTP server, then retry the PXE boot.
