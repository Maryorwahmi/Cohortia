Host Provisioning with Red Hat Satellite

Automate installs, register systems, and scale deployments using PXE, discovery, image-based methods, and compute integrations.

Why this matters

Provisioning with Satellite removes manual installation steps, enforces content control, and integrates VM lifecycle with configuration management so environments are reproducible and auditable.

PXE & Kickstart: Network boot plus automated install.

Explore Key Topics
PXE Provisioning
Network boot, TFTP, and Kickstart deliver unattended installs to bare-metal or VMs.
Kickstart Templates
ERB-driven Kickstart files let you inject host parameters and run post-install scripts like enabling httpd.
Host Groups
Group defaults for OS, partitioning, content view and provisioning templates for repeatable builds.
