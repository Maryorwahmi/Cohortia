Module 8 › Chapter 8.5 › Provisioning a Host
Checklist
  1. Validate compute resource credentials and API reachability.
  2. Create Host Group with OS, partition table, provisioning template, and compute profile.
  3. Create Host: name, IP, select Host Group and compute resource.
  4. Submit and monitor VM creation, PXE boot, and Kickstart execution.
  5. Confirm post-install registration and services are active.
Example: RHEL8 Web Server

Create a Host Group "RHEL8 Web Servers" that points to the Kickstart template adding httpd. Create a host that uses the Host Group; Satellite creates the VM, runs the Kickstart, and after install you can browse the custom index.html.

Monitoring and logs

Check the VM console to see kernel and initramfs load, review the generated Kickstart in Satellite, and if issues occur, consult the Satellite logs and the compute platform's task logs to find creation or credential failures.

Key Takeaway

Provisioning is a linear sequence; monitor each stage and confirm generated artifacts are correct before scaling.

Misconception

Assuming VM creation implies successful install. Creation is separate from PXE boot and Kickstart execution which must be verified.

Try this

Before mass provisioning, test one Host Group-host combination and confirm the expected services and registration occur.
