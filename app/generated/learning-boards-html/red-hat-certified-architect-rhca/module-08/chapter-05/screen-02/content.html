Learning Objectives

Understand, configure, and apply Satellite provisioning to produce repeatable RHEL hosts.

Bloom: Learn → Understand → Apply → Master
01
Explain provisioning methods

Identify PXE, discovery, image-based, and compute-integrated provisioning and when to use each.

VERIFIED COMPETENCY MILESTONE
02
Configure PXE and compute resources

Set up DHCP/TFTP or a Capsule, and add virtualization endpoints so Satellite can create and manage VMs.

VERIFIED COMPETENCY MILESTONE
03
Author Kickstart templates

Use ERB to inject host parameters and write %post scripts to install and enable services after install.

VERIFIED COMPETENCY MILESTONE
04
Troubleshoot provisioning

Diagnose TFTP, DHCP, DNS, missing packages in Content Views, and compute credentials that block provisioning.

VERIFIED COMPETENCY MILESTONE
