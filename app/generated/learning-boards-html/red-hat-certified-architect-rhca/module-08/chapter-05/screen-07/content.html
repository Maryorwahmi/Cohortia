Compute Resources

Register your virtualization endpoints so Satellite can talk to vCenter, OpenStack, RHV, or KVM and automate VM creation and power actions.

What to validate
  • API endpoint and credentials are correct and have permissions to create VMs.
  • Compute profiles map to templates, networks, and datastore choices.
  • Satellite can power on and off VMs via the compute API.
Host Groups
Host Groups are the standardization layer that pre-fills provisioning fields for repeatable deployments.
Host Group example
RHEL8 Web Servers
Content View: Base RHEL 8 & Custom Apps / Development. OS: Red Hat Enterprise Linux 8. Partition Table: Kickstart Default. Provisioning Template: Kickstart RHEL8 Web Server. Compute Profile: vCenter-Standard.
Key Takeaway

Use Host Groups to enforce installation defaults and compute profiles to target the correct environment.

Misconception

Host Groups set install-time defaults; they do not replace configuration management for ongoing system drift control.
