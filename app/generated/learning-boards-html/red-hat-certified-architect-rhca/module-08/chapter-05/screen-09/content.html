Kickstart snippet (ERB example)
# Root password
rootpw --iscrypted <%= root_pass %>

%post --log=/var/log/anaconda/post-install.log

# Install additional packages
dnf install -y httpd mariadb-server

# Enable and start services
systemctl enable --now httpd
systemctl enable --now mariadb

echo "Post-installation script completed."

%end
This template uses an ERB variable root_pass supplied by host parameters or Host Group defaults. The %post block installs and enables services, creating a ready host on first boot.
Pro tip

Keep logs in %post to aid troubleshooting and avoid storing plain-text secrets inside templates.

Testing and validation
Clone the Kickstart default template, edit, and preview the generated Kickstart for a sample host. Validate ERB syntax and ensure variables referenced are defined in the Host Group or host parameters.
Example activity

Add httpd to %packages and include a %post creating /var/www/html/index.html with a short message. Attach the template to a Host Group and provision one host to verify the service is running post-install.

Common mistake

A single missing ERB tag or Kickstart directive typo can prevent Kickstart generation or cause install failure; always preview and test on one VM first.
