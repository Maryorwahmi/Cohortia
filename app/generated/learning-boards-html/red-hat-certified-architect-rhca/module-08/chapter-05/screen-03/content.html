Applied Objectives

Concrete tasks you will configure and test in the hands-on activity.

Practical tasks
  • Add and validate a compute resource (credentials, API access, templates).
  • Create a Host Group that sets OS, partition table, provisioning template, and compute profile.
  • Customize a Kickstart with %packages and %post to install and enable httpd and a static index page.
  • Run a test provision, watch the PXE boot, and confirm registration via subscription-manager.
Activity Preview

Clone the Kickstart default template, add httpd to %packages and a %post to enable it, attach the template to a Host Group, then provision a VM to verify the site.

Verification

Check VM console and Satellite logs to confirm TFTP and Kickstart delivery.

Misconception

Creating a VM in a compute resource does not guarantee successful install; network boot and provisioning templates must be correct.

Pro tip

Use small test Host Groups and a single test VM before scaling to many hosts.
