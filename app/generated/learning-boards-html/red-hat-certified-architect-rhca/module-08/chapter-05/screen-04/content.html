Module 8 › Chapter 8.5 › What is Integrated Provisioning?
Definition and benefits

Integrated provisioning centralizes host creation, OS installation, and registration so every host follows organizational standards automatically.

Consistency
Templates and Host Groups ensure identical partitioning, packages, and post-install tasks.
Speed
Automated installs reduce time to deploy new nodes in DevOps workflows.
Auditability
Content Views and Host Groups produce repeatable, reviewable artifacts for compliance.
Example
Host Group: RHEL8 Web Servers
Contains RHEL 8 OS, partition table, Kickstart template that adds httpd in %packages and enables it in %post.
Common misconception
Satellite provisioning is more than subscription registration; it requires network services and templates to be correct for the install to complete.
Provisioning flow (conceptual)
  1. Add compute resource and Host Group.
  2. Create host entry; Satellite creates VM and configures DHCP/TFTP.
  3. VM PXE boots, downloads kernel/initramfs, and fetches Kickstart.
  4. Kickstart performs install and runs %post to configure services and register the host.
Key Takeaway

Provisioning automates the full lifecycle from VM creation to registration using templated artifacts.
