Module 8 › Chapter 8.5 › OS, Partition & Templates
Hierarchy of provisioning artifacts
Operating System entries in Satellite define the family of the OS and link to partition tables and provisioning templates. Partition tables define disk layouts. Provisioning templates provide the PXE boot and Kickstart content used at install time.
Partition Tables
Reusable disk layout definitions applied by the installer during Kickstart processing.
Provisioning Templates
PXELinux/Grub2 templates for boot and Kickstart templates with ERB for dynamic values.
Key Takeaway

Keep a clear mapping of Operating System entries to partition tables and templates to ensure Kickstarts are generated with correct layout.

Concrete example
OS: Red Hat Enterprise Linux 8
Architecture: x86_64. Partition Table: Kickstart Default. Provisioning Template: Kickstart default or custom Kickstart RHEL8 Web Server.
Pitfall

Editing a template without validating ERB syntax or the variables referenced can cause Kickstart generation to fail for hosts using that OS entry.

Check

Before scaling, test a Host Group with the OS entry and template to verify partitioning and package installation succeed.
