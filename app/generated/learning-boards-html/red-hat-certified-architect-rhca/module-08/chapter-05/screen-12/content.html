Module 8 › Chapter 8.5 › Key Concepts — Part 1
PXE-based Provisioning
Network boot, TFTP, and Kickstart deliver unattended installs.
Compute Resource
Platform endpoint that Satellite uses to create and manage VMs via API.
Host Group
A bundle of defaults for consistent, repeatable host provisioning.
Summary

These three concepts form the foundation of Satellite provisioning: network boot delivery, compute control, and standardized installation defaults.
