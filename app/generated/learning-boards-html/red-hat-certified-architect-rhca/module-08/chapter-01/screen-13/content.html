# Satellite Architecture Workflow Description

## Content Synchronization and Distribution:
1. Satellite syncs content from the Red Hat CDN into Pulp.
2. Content is stored and published in content views.
3. Capsules sync from Satellite and cache content locally.
4. Managed hosts pull content from Capsules or Satellite.

## Host Registration and Management:
1. Provision host (possibly via Satellite).
2. Install subscription-manager and register to Satellite or Capsule.
3. Host reports inventory and receives subscriptions and configs.
