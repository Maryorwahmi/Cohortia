Architecture

Satellite Server components

Pulp
Content storage and management for RPMs, images, and containers.
Foreman
Provisioning and lifecycle engine responsible for host registration and orchestration.
Candlepin & Katello
Candlepin handles subscription entitlement; Katello provides the integrated UI that ties services together.
Design concerns
  • Storage sizing for multiple RHEL versions and container images.
  • Disk I/O planning to prevent sync or publish bottlenecks.
  • Backup and recovery of content and metadata to avoid data loss.
Common mistake

Underestimating storage and I/O needs leads to slow synchronizations and failed publishes; plan conservatively and monitor usage.
