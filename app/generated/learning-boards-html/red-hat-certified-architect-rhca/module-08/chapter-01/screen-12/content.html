Module 08 › Chapter 8.1 › Managed hosts & lifecycle
Hierarchy

Host groups and provisioning

Host groups define provisioning templates and baseline configuration for a set of hosts, enabling repeatable provisioning across the estate.

Use host groups to encapsulate platform-level settings and let application owners inherit or request group-specific profiles.
Lifecycle

Content views & environments

Promote tested content from development to production using content views and lifecycle environments to avoid pushing unverified updates wide-scale.

Key Takeaway

Combined use of host groups and lifecycle views enforces reproducibility and reduces configuration drift across managed hosts.
