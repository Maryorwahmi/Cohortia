Registering a host

Install the required packages and run the registration command to link a RHEL host to the Satellite inventory and subscription system.

# Install helpers and register
sudo dnf install -y subscription-manager katello-agent
sudo subscription-manager register --org="example-org" --activationkey="example-key"
# Verify status
sudo subscription-manager status
What registration provides
  • Inventory of installed packages and errata applicability.
  • Subscription entitlement mapping and compliance visibility.
  • Ability to provision, push configuration, and report state from Satellite.
Troubleshooting tip

If registration fails with a certificate error, check DNS resolution, Foreman certificates, and firewall rules before reattempting.
