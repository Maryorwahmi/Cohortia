Module 08 › Chapter 8.1 › Satellite vs Capsule
Satellite Server

Central control plane

  • Hosts Pulp, Foreman, Candlepin, Katello.
  • Synchronizes with Red Hat CDN and defines content views.
  • Requires significant storage and I/O based on content volume.
Capsule Server

Distributed proxy and service hub

  • Caches content from Satellite and provides DNS/DHCP/TFTP/proxy services.
  • Improves performance and reduces WAN use for remote sites.
  • Easier to deploy than a full Satellite Server in remote locations.
