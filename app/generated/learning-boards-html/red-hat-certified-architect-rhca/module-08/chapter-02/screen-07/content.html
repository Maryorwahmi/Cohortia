Definition › FQDN and DNS requirements

FQDN rules

  • Set a fully qualified domain name for the host used by Satellite.
  • Ensure forward lookup (name → IP) and reverse lookup (IP → name) are consistent.
  • Use the FQDN when specifying certificate common names and for client registration.
# Verify resolution
host satellite.lab.example.com
host 192.168.122.10

Lab workaround

If DNS is not available, add the FQDN and IP to /etc/hosts. This works for lab installs but is not suitable for production because many clients and services expect a DNS infrastructure.

Misconception

Short names or non-resolvable hostnames will break certificate issuance and host registration. Always use a fully qualified domain name.
