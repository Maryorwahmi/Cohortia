Register and subscribe
sudo subscription-manager register --username=<YOUR_REDHAT_USERNAME> --password=<YOUR_REDHAT_PASSWORD> --auto-attach
sudo subscription-manager repos --enable=rhel-8-for-x86_64-baseos-rpms \
  --enable=rhel-8-for-x86_64-appstream-rpms \
  --enable=satellite-6.13-for-rhel-8-x86_64-rpms
Verify consumed subscriptions and enabled repos before installing packages needed by Satellite.
Host identity and time
sudo hostnamectl set-hostname satellite.lab.example.com
# If no DNS in lab
echo "192.168.122.10 satellite.lab.example.com satellite" | sudo tee -a /etc/hosts
sudo dnf install chrony -y
sudo systemctl enable --now chronyd
Confirm hostname resolution and chrony status; incorrect values lead to certificate and registration failures.
Installer checklist
  • Confirm FQDN resolves forward and reverse.
  • Ensure required ports will be open or that you understand the installer changes.
  • Decide on integrated vs external CA for production security.
Troubleshooting and logs
If installation fails, consult /var/log/foreman-installer/satellite.log for detailed errors. Common root causes are DNS, time skew, missing subscriptions, and insufficient disk I/O.
