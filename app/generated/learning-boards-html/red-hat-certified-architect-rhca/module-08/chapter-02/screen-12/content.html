Process Flow › Firewall and ports

Common ports

  • 80 (HTTP), 443 (HTTPS) — web UI and API.
  • 8140 — Puppet agent/master communication.
  • 5647, 9090 — ancillary service ports used by Satellite components.
  • 69 (TFTP), 67/68 (DHCP) — provisioning services if enabled.
Coordinate DHCP and TFTP enablement carefully to avoid network conflicts with existing infrastructure.

Checklist

Document the ports, request network changes as needed, and confirm that the provisioning interface has the expected routing and DHCP behavior.
Common mistake

Assuming the installer will fully correct firewall issues. It may configure rules, but missing network approvals or conflicting services still block proper operation.
