Checklist to prevent failures

  • Verify resolvable FQDN and reverse DNS.
  • Confirm subscription-manager shows the Satellite Infrastructure entitlement.
  • Check disk space and I/O performance for /var/lib/pulp.
  • Review firewall rules and DHCP/TFTP responsibilities on the network.
  • Consult installer logs when errors appear.

Quick verification

hostname -f
sudo subscription-manager list --consumed
df -h /var/lib/pulp
sudo systemctl status chronyd
Key Takeaway

Run a short verification script of host identity, subscriptions, time sync, and storage before running the installer.
