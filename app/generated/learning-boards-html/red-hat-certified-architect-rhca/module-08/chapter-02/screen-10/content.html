Definition › Subscription manifest & sync

What the manifest does

The manifest contains your entitlement information. After upload, Satellite can list the repositories you may sync and distribute to managed hosts.

Step: Content › Subscriptions › Manage Manifest — upload the manifest file obtained from Red Hat.
Common mistake

Uploading a manifest does not automatically sync repositories; you must create products and initiate repository syncs.

Sync example

Create a product named "Red Hat Enterprise Linux 8", add the BaseOS and AppStream repos, then start a sync. Monitor storage under /var/lib/pulp for growth.
Key Takeaway

Plan for the initial sync's storage and bandwidth demands before uploading the manifest and starting synchronization.
