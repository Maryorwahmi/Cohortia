Process Flow › Preparing the RHEL host

Preparation steps

  1. Register with subscription-manager and attach the Satellite Infrastructure subscription.
  2. Enable RHEL base and Satellite repositories for your RHEL version.
  3. Set a resolvable FQDN; verify forward and reverse DNS.
  4. Install and enable chronyd for NTP synchronization.
  5. Understand and prepare firewall port requirements or allow the installer to configure them deliberately.
Pro Tip

If DNS is unavailable in a lab, add the FQDN and IP to /etc/hosts for predictable resolution during install.

Command examples

sudo subscription-manager register --username=<user> --password=<pass> --auto-attach
sudo subscription-manager repos --enable=rhel-8-for-x86_64-baseos-rpms \
  --enable=rhel-8-for-x86_64-appstream-rpms \
  --enable=satellite-6.13-for-rhel-8-x86_64-rpms
sudo hostnamectl set-hostname satellite.lab.example.com
sudo dnf install chrony -y
sudo systemctl enable --now chronyd
Verify subscription-manager list --consumed and hostname -f. Confirm chronyd is active to prevent certificate validation errors later.
