Module 08 › Chapter 8.2 › Learning Objectives

Learning Objectives

Learn → Understand → Apply → Master

Bloom: Learn • Understand • Apply • Master
01
Identify prerequisites and sizing

Learn to estimate CPU, memory, and storage needs based on managed host counts, and why /var/lib/pulp I/O is a common bottleneck. Verified competency milestone: produce a simple sizing table for a lab vs production environment.

02
Prepare the RHEL host

Practice registering the host, enabling the correct repos, setting a resolvable FQDN, configuring NTP, and opening essential ports. Milestone: register and attach the Satellite Infrastructure subscription on a lab VM.

03
Execute satellite-installer

Understand and use key installer options for FQDN, organization, DNS/DHCP/TFTP, and certificate handling. Milestone: run a basic installer command in a lab that completes without fatal errors.

04
Post-install validation

Import the subscription manifest, perform the first content sync, and verify services and logs to ensure operability. Milestone: upload a manifest and trigger a repository sync.

VERIFIED COMPETENCY MILESTONE — Each card above maps to a practice task you can perform in a lab environment.
