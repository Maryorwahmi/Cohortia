Process Flow › Initial Sync
Sync workflow
  1. Upload subscription manifest to Satellite to enable entitled products.
  2. Navigate to Content > Products and click "Sync Red Hat Products" to list entitlements.
  3. Select only required products and start synchronization; monitor disk and network usage.
  4. After sync completes, repositories appear under their Product and can be added to Content Views.
Why it matters
A complete sync brings full package payloads into Satellite so hosts can install without live CDN access.
CLI example (hammer)
# Find products and repositories
hammer product list
hammer repository list --product "Red Hat Enterprise Linux 8"

# Sync a specific repository
hammer repository synchronize --name "Red Hat Enterprise Linux 8 for x86_64 - BaseOS RPMs" --product "Red Hat Enterprise Linux 8"
Key Takeaway

Use the UI for discovery and hammer for automation; initial syncs are heavy and must be planned.

Common mistake
Starting broad syncs without planning can exhaust bandwidth and storage.
