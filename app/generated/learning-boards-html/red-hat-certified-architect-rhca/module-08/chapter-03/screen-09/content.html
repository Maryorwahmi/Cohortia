Errata Filter

Errata filters select which types of errata are included. Typical choices are security and bugfix errata; enhancement errata can be excluded where stability is prioritized.

Example
hammer content-view filter create --content-view "RHEL8_Base_CV" --name "Security_Bugfix_Errata" --type erratum --inclusion-type include --errata-type security,bugfix
Package Filter

Package filters include or exclude specific packages or package versions. They are useful to prevent known-bad packages from reaching hosts or to restrict optional components.

Caution

Overly restrictive package filters can remove dependencies and break installations. Always validate dependencies after applying filters.

Common mistake

Applying filters without dependency checks can lead to missing packages in published versions.
