Key Concepts

Three compact concept cards to remember.

Software‑Defined Storage
Abstracts storage from hardware to create programmable pooled services.
Red Hat Ceph Storage
Unified object, block, and file storage with CRUSH placement and self‑healing.
Red Hat Gluster Storage
Scale‑out NAS using bricks and translators for file workloads and HPC.
Summary
