Ceph use cases: cloud, containers, and unified storage

Map Ceph's interfaces to common application needs and consider tuning requirements.

Block (RBD)
High‑performance block devices for VMs and databases with replication and snapshot support.
Object (RGW)
Massive scale object stores for images, media, and backups accessible via S3‑compatible APIs.
File (CephFS)
POSIX file system for shared configuration, logs, and workloads requiring standard filesystem semantics.
Concrete scenario
An OpenShift cluster uses RBD for database volumes, RGW for container image storage, and CephFS for shared build artifacts, simplifying infrastructure and reducing separate storage silos.
Key Takeaway

Ceph's unified interfaces reduce siloed storage, but require tuning to match performance and durability expectations.
