Where Red Hat storage fits in the ecosystem

How Ceph and Gluster connect to OpenShift and OpenStack to provide persistent storage services.

OpenShift integration
CSI drivers let OpenShift dynamically provision persistent volumes from Ceph or Gluster backends. Storage classes define reclaim policies and access modes used by applications.
OpenStack integration
Ceph commonly serves Cinder (block), Glance (image) and object needs via RGW; Gluster may provide shared file systems for workloads that require POSIX semantics.
Concrete example
A stateful application on OpenShift requests a persistent volume; the CSI driver provisions an RBD image on Ceph and returns the volume for the pod to mount, enabling persistent state across pod restarts.
Key Takeaway

Integration is powerful but requires correct CSI and storage class configuration and testing to ensure desired behavior.
