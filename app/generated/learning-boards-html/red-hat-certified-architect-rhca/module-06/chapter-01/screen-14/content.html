Assessment scenarios and recommended answers

Practice questions to justify design choices between Ceph and Gluster.

Scenario 1
OpenShift migration requiring block for DBs, object for assets, and shared file access.
Recommended
Red Hat Ceph Storage — unified block, object, and file from one cluster simplifies integration and management.
Scenario 2
Media company needs scalable, highly available file storage on commodity hardware.
Recommended
Red Hat Gluster Storage — scale‑out NAS with bricks and translators is a practical fit for file workloads.
Reflection question
Which product better matches your current environment and what operational changes are required to adopt it?
Key Takeaway

Use scenario reasoning and map storage needs to product strengths, explaining trade-offs clearly.
