Red Hat Gluster Storage
A file-oriented, scale-out NAS built from bricks, volumes, and a stackable translator architecture.
In this lesson

Learn the building blocks, choose appropriate volume types, and plan networks and hardware for resilient Gluster deployments.

Why it matters

Gluster helps you scale file services using commodity servers while offering flexible trade-offs between redundancy, capacity, and throughput.

Cluster snapshot (visual)
Bricks on nodes, aggregated into volumes via translators
Brick
A directory on a server's filesystem managed by GlusterFS.
Translator
Modular layer that provides replication, striping, and other behaviors.
Volume
A logical collection of bricks presented as a single namespace.
Self-Heal
Automatic synchronization when bricks return after failure.
