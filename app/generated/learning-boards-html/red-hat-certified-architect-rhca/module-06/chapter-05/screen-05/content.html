Module 6 › Chapter 6.5 › Volumes
Volume = Unified namespace
Volumes present multiple bricks as a single filesystem to clients and rely on translators to implement required behaviors.
Behavior
Defines replication, distribution, striping, or erasure coding.
Namespace
Single hierarchy for clients regardless of physical placement.
Example
A distribute 2 replica 3 volume on six bricks groups them into two replica sets of three. Files are stored in one replica set but the client sees a single mounted path for all files across the volume.
Key Takeaway

Volumes hide physical placement and let you choose behavior via translators — plan placement for desired redundancy and performance.
