Module 6 › Chapter 6.5 › Striped & Dispersed
Striped Volume
Breaks a file into stripes across multiple bricks to allow parallel access and improved throughput for large sequential I/O.
Use-case: media editing where large files are read and written sequentially. Limitation: no redundancy; a single brick failure can render a file unreadable.
Dispersed (Erasure Coded)
Splits data into k data and m parity fragments across k+m bricks, allowing up to m failures with better storage efficiency than full replication.
Use-case: large archives or cold storage where storage efficiency matters and some CPU is available for reconstruction.
Key Takeaway

Striping improves throughput; erasure coding improves storage efficiency while tolerating multiple failures—choose by workload and tolerance for rebuild cost.
