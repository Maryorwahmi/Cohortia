Module 6 › Chapter 6.5 › Distributed vs Replicated
Distributed Volume
Files are placed across bricks round-robin. Strength: capacity and simple scaling. Weakness: no redundancy; brick failure can lose data.
Use when raw capacity is the primary goal and data can be reconstructed if lost.
Replicated Volume
Data is synchronously copied across N bricks. Strength: availability and resilience to brick failure. Weakness: reduced usable capacity and higher write latency.
Use for critical data like home directories or shared configuration where availability matters.
Key Takeaway

Match volume type to data importance: choose replication for availability, distribution for capacity.

Common mistake

Assuming distribution provides safety. It does not — consider replication or erasure coding if you need redundancy.
