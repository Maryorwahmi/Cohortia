Stackable translators
Each translator provides a single capability. The request flows through the stack and translators modify behavior or data placement.
Replicate: duplicates writes across replica bricks for redundancy.
Stripe: splits large files into chunks for parallel I/O.
Distribute: places files across bricks to increase capacity.
Annotated stack
Visualize: Client request → Translate(replication) → Translate(striping) → Brick I/O. Order matters because each translator can alter I/O shape.
Example
A distributed then replicate stack gives distribution across replica groups and synchronous copies within each group; ideal for scalable, redundant file services.
