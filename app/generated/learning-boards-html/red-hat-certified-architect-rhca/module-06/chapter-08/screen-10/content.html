Module 7 › Chapter 6.8 › Gluster Rebalance & Quotas
Rebalance and quota workflows
Redistribute data and enforce limits to keep the cluster healthy and fair.
Rebalance example
Start rebalance after adding bricks and monitor its status until completion to ensure even distribution.
Quota example
Enable quota and limit usage on directories to prevent any single project from exhausting volume capacity.
Commands
# Start rebalance
sudo gluster volume rebalance my-volume start

# Check rebalance status
sudo gluster volume rebalance my-volume status

# Enable quota on a volume
sudo gluster volume quota my-volume enable

# Set a quota of 10GB for a directory
sudo gluster volume quota my-volume limit-usage /path/to/directory 10GB
Schedule rebalances and quota changes during maintenance windows. Pair quotas with monitoring and notifications so teams know when they approach limits.
