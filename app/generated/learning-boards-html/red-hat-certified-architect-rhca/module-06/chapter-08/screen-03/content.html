Module 7 › Chapter 6.8 › Learning Objectives — Advanced Skills
Performance Baselines
Establish normal ranges for IOPS, throughput, and latency so alerts can target real deviations. Include workload types and peak windows.
Why it matters
Baselines reduce false positives and focus attention on meaningful regression events during capacity changes or code rollouts.
Disk Health & SMART
Monitor S.M.A.R.T. attributes for OSD and brick disks to detect wear patterns and plan replacements before failure.
Snapshots & Backups
Use RBD and CephFS snapshots for fast recovery; combine with off-cluster exports for full disaster protection.
DR Drills
Regularly test restores and geo-replication promotion so RTO and RPO targets are validated and staff are practiced in recovery steps.
