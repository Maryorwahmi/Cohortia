Learning Objectives
Learn, Understand, Apply, Master
01
Manage Ceph Pools & PGs
Create erasure-coded or replicated pools, set quotas, and tune placement groups to balance data. Verified competency: create a pool and confirm balance with ceph -s.
Verified Competency Milestone
02
Gluster Rebalance & Quotas
Run volume rebalance and configure directory quotas to prevent runaway usage. Verified competency: enable quota and set a directory limit.
Verified Competency Milestone
03
Monitoring & Alerting
Integrate metrics, dashboards, and centralized logs to detect OSD/brick issues early. Verified competency: create a Prometheus scrape and Grafana panel for IOPS.
Verified Competency Milestone
04
Troubleshoot & Recover
Diagnose OSD/brick failures, resolve split-brain, and validate backups and DR workflows. Verified competency: recover an OSD and demonstrate a snapshot restore procedure.
Verified Competency Milestone
