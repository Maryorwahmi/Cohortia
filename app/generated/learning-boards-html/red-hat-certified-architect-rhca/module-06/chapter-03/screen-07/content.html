Adding hosts and provisioning OSDs with cephadm
The typical orchestration flow to register nodes and deploy OSD containers.
  1. Run sudo cephadm add-host <hostname> for each node you want to manage.
  2. Confirm SSH connectivity using cephadm's key and ensure sudo privileges are available.
  3. Inspect disks with lsblk -f and fdisk -l to find raw devices.
  4. Run sudo cephadm shell -- ceph orch apply osd --all-available-devices to provision OSDs.
Common-mistake
Trying to provision disks that contain partitions or that are part of RAID arrays; cephadm will skip them.
Troubleshooting steps
  • On the candidate host run: lsblk -f and fdisk -l /dev/sdX to inspect devices.
  • If partitions exist: wipefs -a /dev/sdX or sgdisk --zap-all /dev/sdX to clear signatures.
  • Verify SSH access: sudo cephadm shell -- ssh <new_host> 'ls' and check logs if denied.
These checks explain why the orchestration may report "No new devices found" and how to resolve it safely.
