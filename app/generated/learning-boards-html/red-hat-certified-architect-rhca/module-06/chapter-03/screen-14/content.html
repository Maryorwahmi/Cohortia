Module 6 › Chapter 6.3 › Key Concepts
cephadm
A Python tool that deploys Ceph daemons as containers using podman.
Bootstrap
The initial process that creates the first monitor and manager and produces admin configs.
OSD Provisioning
Discovery and automated creation of OSDs on raw, unused devices via orchestration.
Summary
These three concepts form the backbone of initial Ceph deployment and day-to-day management with cephadm.
