Assessment scenario: troubleshooting 'No new devices found'
A practical troubleshooting sequence for a common OSD provisioning failure.

Step 1: Inspect disks with lsblk -f and fdisk -l to find partitions or filesystems. Step 2: If disks are unused but carry signatures, use wipefs -a or sgdisk --zap-all to clear them. Step 3: Verify SSH connectivity using the cephadm SSH key and confirm sudo privileges on the remote host. Step 4: Re-run ceph orch apply osd and review cephadm logs if problems persist.

Example commands to practice
# Inspect devices on the host
lsblk -f
fdisk -l /dev/sdX

# Test SSH connectivity
sudo cephadm shell -- ssh new-host.example.com 'ls'

# Clear unused signatures (only if device is confirmed unused)
sudo wipefs -a /dev/sdX
sudo sgdisk --zap-all /dev/sdX
Walk through these steps in your lab environment and explain each output before taking action that modifies devices.
