Activity: Preparing a Host and Bootstrapping Simulation
Follow the scripted steps on a fresh RHEL VM to practice safely.
  1. Install Podman and cephadm with the package manager.
  2. Simulate sudo cephadm bootstrap --mon-ip 192.168.122.100 --allow-fqdn-hostnames.
  3. Create dummy /etc/ceph/ceph.conf and a placeholder keyring and set chmod 600 on the keyring.
  4. Run sudo cephadm shell -- ceph -s to observe expected status output in simulation.
Starter script (safe, simulated)
# Install tools
sudo dnf install -y podman cephadm

# Simulate bootstrap (placeholder IP)
echo "sudo cephadm bootstrap --mon-ip 192.168.122.100 --allow-fqdn-hostnames"

echo "Creating dummy /etc/ceph/ceph.conf and keyring"
sudo mkdir -p /etc/ceph
echo "[global]" | sudo tee /etc/ceph/ceph.conf
sudo touch /etc/ceph/ceph.client.admin.keyring
sudo chmod 600 /etc/ceph/ceph.client.admin.keyring

# Simulate status check
echo "sudo cephadm shell -- ceph -s"
Run this script as a practice run. The goal is familiarity with the sequence, not to create production daemons on the VM.
