Bootstrap walkthrough and post-bootstrap steps
Concrete commands and expected outputs you will use in the lab.

After installing cephadm and podman, run the bootstrap with a reachable monitor IP. The bootstrap will deploy a monitor and manager and generate configuration files and an SSH key. Copy the files to /etc/ceph and protect the keyring permissions. Finally enable the cephadm systemd service so orchestration persists.

Checklist
  • Install podman and cephadm
  • Run cephadm bootstrap with --mon-ip
  • Copy ceph.conf and keyring to /etc/ceph and chmod 600 keyring
  • Enable and start cephadm service
Terminal demo (simulated)
# On bootstrap node
sudo dnf install -y podman cephadm
sudo cephadm bootstrap --mon-ip 192.168.122.100 --allow-fqdn-hostnames

# After bootstrap follow instructions to copy files
sudo cp /etc/ceph/ceph.conf /etc/ceph/ceph.client.admin.keyring /etc/ceph/
sudo chmod 600 /etc/ceph/ceph.client.admin.keyring
sudo systemctl enable --now cephadm

# Verify
sudo cephadm shell -- ceph -s
This simulated output models the commands you will practice in the hands-on activity. Use a placeholder IP for lab runs and inspect the cephadm output for next steps.
