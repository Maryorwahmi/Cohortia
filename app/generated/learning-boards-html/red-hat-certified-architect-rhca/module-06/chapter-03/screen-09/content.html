Ceph Dashboard essentials
Accessing the dashboard and understanding its role in monitoring.

Retrieve the dashboard URL and admin credentials using the cephadm shell commands provided during bootstrap. The dashboard typically listens on HTTPS port 8443 on a manager node. If a self-signed certificate is acceptable for lab work, use the create-self-signed-cert command; for production, plan for trusted certificates.

Commands to know
 sudo cephadm shell -- ceph dashboard get-url
#> sudo cephadm shell -- ceph dashboard create-self-signed-cert
#> sudo cephadm shell -- ceph dashboard ac-user-show admin
Use the dashboard to inspect recovery progress and pool performance, but keep CLI checks readily available when troubleshooting network or certificate issues.
