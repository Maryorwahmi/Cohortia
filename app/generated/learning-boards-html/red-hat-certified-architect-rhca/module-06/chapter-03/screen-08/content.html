Core ceph CLI commands you will use daily
What each command shows and when to run it.
ceph -s
Summary status including overall health, monitor quorum, and OSD counts. Use it after changes to confirm cluster stability.
ceph osd tree
Shows placement and status of OSDs in the CRUSH map. Helpful for verifying OSDs are online and correctly placed.
ceph df
Displays pool usage and overall capacity metrics, useful for growth planning.
ceph health detail
Provides detailed warnings and errors when the cluster reports degraded or unhealthy states.
ceph auth ls
Lists authentication keys and capabilities. Validate admin key presence after bootstrap.
Practice these commands inside the cephadm shell for accurate context: sudo cephadm shell -- ceph -s
