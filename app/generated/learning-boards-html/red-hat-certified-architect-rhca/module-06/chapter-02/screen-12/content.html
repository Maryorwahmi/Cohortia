Module 6 › Chapter 6.2 › Key Concepts
Ceph Monitor (MON)
Keeps the authoritative cluster map and forms quorum for control-plane decisions.
Ceph OSD
Stores object data, replicates, rebalances, and performs recovery tasks.
CRUSH Algorithm
Deterministic placement algorithm that calculates which OSDs hold each object and its replicas.
Summary

Monitors, OSDs, and CRUSH together form Ceph's control, data, and placement model. Design with all three in mind for resilient, scalable storage.
