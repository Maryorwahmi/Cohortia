Module 6 › Chapter 6.2 › Rados Gateway (RGW)
What RGW provides
S3 and Swift compatible object endpoints translating HTTP calls to librados operations with scalability through horizontal gateway nodes.
Operational notes
  • Run RGW on dedicated nodes to avoid resource contention with OSDs.
  • Place RGW behind load balancers for high availability and scale.
  • Monitor RGW CPU and network; it translates many short-lived HTTP requests into Ceph operations.
Example use cases
Cloud-native applications, backups, large unstructured data sets, and services expecting S3 or Swift APIs.
Common mistake

Co-locating heavy RGW traffic with OSDs can create network and CPU contention that hurts storage performance.
