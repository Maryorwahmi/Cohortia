Module 6 › Chapter 6.2 › Storage Interfaces
RBD (Block)
Thin-provisioned block devices, striped across OSDs. Ideal for VMs and persistent volumes requiring block semantics.
Use when low-latency raw block access and fine-grained block control are required.
RGW (Object)
S3 and Swift compatible object endpoints. Good for backups, logs, and unstructured data at scale.
Use when applications expect RESTful object APIs and eventual consistency patterns.
CephFS (File)
POSIX filesystem backed by OSDs with MDS for metadata. Suitable for shared file workloads requiring POSIX semantics.
Use when many clients need a shared mount and consistent filesystem semantics.
Key Takeaway

All three interfaces share RADOS placement and OSDs, but their metadata paths and access semantics differ; choose based on application requirements rather than convenience alone.
