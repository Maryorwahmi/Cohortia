Module 6 › Chapter 6.2 › Ceph Metadata Server (MDS)
What MDS manages
Directory structures, inode metadata, permission information, and namespace operations for CephFS clients.
Why it matters

MDS caches metadata and distributes namespace operations so many clients can interact with a POSIX filesystem without overwhelming OSDs with small metadata requests.

Common misconception

MDS is not required for RBD or RGW. It serves only CephFS metadata needs.

Scaling pattern
Multiple active MDS instances can split the namespace to increase parallel metadata processing. Choose the number of MDSs based on metadata workload, not data capacity.
Key Takeaway

Deploy MDS only when you need CephFS. Scale MDS according to metadata load, and protect their stability to keep POSIX operations responsive.
