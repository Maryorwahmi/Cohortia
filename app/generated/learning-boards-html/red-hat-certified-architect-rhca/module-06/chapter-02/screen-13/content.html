Module 6 › Chapter 6.2 › Key Concepts
RBD / RGW / CephFS
Block, object, and file interfaces reuse the same storage backend but differ in semantics and metadata paths.
MDS (Metadata)
Handles CephFS namespace metadata and scales according to metadata workload.
Placement Group (PG)
Logical grouping of objects that CRUSH maps to sets of OSDs, affecting grouping and rebalancing behavior.
Final takeaway

Use the concepts in this chapter to validate design choices: correct failure domains, isolated networks, and appropriate hardware for OSDs and gateways will produce reliable Ceph deployments.
