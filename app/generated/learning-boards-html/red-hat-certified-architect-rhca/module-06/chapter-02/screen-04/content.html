Module 6 › Chapter 6.2 › Ceph Monitor (MON)
Definition
Monitors store the cluster map, manage quorum, and provide discovery services for clients and daemons.
Key points
  • Use an odd number of monitors to maintain Paxos quorum.
  • Monitors are critical for cluster control but not for data transfer.
  • Keep monitors on stable, low-churn nodes to avoid quorum loss.
Key takeaway

Protect quorum and avoid co-locating monitors with heavy I/O roles to ensure cluster management remains responsive.

Operational scenario
Imagine three monitors; if two are unreachable due to a network partition, the remaining monitor cannot form quorum and the cluster will stop accepting membership changes. Data on OSDs still exists, but control operations are blocked until quorum is restored.
Common mistake
Co-locating monitors on the same hosts as OSDs or gateways can amplify failures and cause quorum problems.
Pro tip
Keep monitor state backed up and use stable network paths for monitor-to-monitor communication.
Reflection

If you had to sacrifice a VM to host monitors, would you choose isolated lightweight nodes or multi-role servers? The safer choice favors isolation for cluster stability.
