Operator responsibilities
  • Deploy and configure Ceph monitors and OSDs
  • Create storage pools and manage CRs
  • Install CSI drivers and create StorageClasses
  • Provision cephx secrets and RBAC
Operational checklist
Capacity
Plan OSD count, replication, and erasure coding based on data durability targets.
Monitoring
Monitor Ceph health and network latency between monitors and compute nodes.
Topology
Decide whether to colocate OSDs with compute or isolate them in a dedicated storage tier.
Design note

Colocating OSDs reduces latency but increases resource contention. Isolate for predictable performance and easier scaling.
