Module 6 › Chapter 6.7 › Ceph storage types
Interface comparison
RBD (Block)
Single-writer, high performance
Best for databases and VM disks; exposes block devices as PVs.
CephFS (File)
POSIX shared filesystem
Allows multiple pods to mount the same filesystem concurrently.
RGW (Object)
S3-compatible object store
Used for backups, static assets, and applications using object APIs.
Decision checklist
  • Does workload need POSIX semantics? Use CephFS.
  • Does it need low-latency block I/O? Use RBD.
  • Does it use S3 APIs or store blobs? Use RGW.
Misconception

Object storage cannot provide POSIX semantics; do not try to use RGW where shared file locks and directories are required.
