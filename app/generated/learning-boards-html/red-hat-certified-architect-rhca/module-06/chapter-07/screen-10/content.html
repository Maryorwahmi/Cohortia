Module 6 › Chapter 6.7 › Ceph for OpenStack
Service mappings
Cinder: RBD backend for persistent block volumes; supports snapshots and cloning.
Glance: Store VM images as RBD for scalability and thin provisioning.
Nova: Use RBD for ephemeral disks and to enable live migration with shared storage.
Manila: Integrate CephFS for shared file services to VMs.
Operational practices
  • Create dedicated cephx users per OpenStack service
  • Assign minimal permissions to each cephx principal
  • Use separate pools for volumes and images to control performance
Key Takeaway

Map OpenStack services to Ceph pools and cephx users carefully to balance performance, security, and manageability.
