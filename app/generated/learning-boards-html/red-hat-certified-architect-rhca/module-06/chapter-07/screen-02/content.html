Learning Objectives
Learn the key skills and why they matter in production environments.
Learn → Understand → Apply → Master
01
Explain persistent storage needs
Describe why stateful containers require storage that persists beyond pod lifecycles and how access modes affect design. Verified competency: MILESTONE
02
Configure Ceph via CSI
Author a StorageClass for Ceph RBD/CephFS, understand secrets and parameters needed for dynamic provisioning. Verified competency: MILESTONE
03
Integrate Gluster Storage
Deploy and validate Gluster CSI StorageClass for shared file access when its architecture is preferred. Verified competency: MILESTONE
04
Map Ceph to OpenStack services
Design Ceph-backed Cinder, Glance and Nova integrations and assign minimal cephx users per service. Verified competency: MILESTONE
