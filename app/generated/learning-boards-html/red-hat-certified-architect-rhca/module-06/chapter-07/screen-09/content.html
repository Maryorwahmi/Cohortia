Module 6 › Chapter 6.7 › Gluster StorageClass
YAML example
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: glusterfs-sc
provisioner: org.gluster.csi.glusterfs
parameters:
  resturl: "http://gluster-rest-service.gluster-ns.svc.cluster.local:8080"
  restuser: "admin"
  secretNamespace: "gluster-ns"
  secretName: "gluster-rest-secret"
reclaimPolicy: Delete
volumeBindingMode: Immediate
allowVolumeExpansion: true
Validation checklist
  • REST URL resolvable and reachable from OpenShift nodes
  • Secret exists in the named namespace with correct credentials
  • Provisioner registered and CSI pods are running
Concrete test
Create a PVC with ReadWriteMany and attach it to two pods. Confirm both can write to a shared file concurrently.
Common mistake

Firewall or DNS issues between nodes and the Gluster REST service cause pending PVCs; verify connectivity before debugging CSI behavior.
