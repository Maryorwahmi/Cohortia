Module 6 › Chapter 6.7 › Common mistakes & validation
Common mistakes
  • Incorrect StorageClass parameters or secret names
  • Network/firewall issues to Ceph monitors or Gluster REST
  • Wrong ceph.conf path or missing keyrings in OpenStack configs
  • Using overly privileged cephx users
Validation steps
  1. Confirm CSI provisioner and node plugins are running
  2. Verify secret names and namespaces referenced by StorageClasses
  3. Create PVC, wait for Bound status, and attach to a pod
  4. Write data, restart pod, and confirm data persists
  5. Check Ceph health and pool image or Gluster volumes
Key Takeaway

Systematic validation prevents production outages. Use these steps as a pre-deployment checklist.
