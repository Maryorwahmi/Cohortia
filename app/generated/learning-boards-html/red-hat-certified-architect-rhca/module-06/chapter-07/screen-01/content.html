Integrating Red Hat Storage with OpenShift and OpenStack
Persistent volumes, StorageClasses and Ceph/Gluster backends for container and cloud platforms.
Why this matters
Stateful workloads require storage that survives pod lifecycle and delivers required performance and sharing semantics.
What you will do
Map application access modes to Ceph or Gluster, author StorageClasses and validate PVC lifecycle across OpenShift and OpenStack.
Explore Key Topics
Ceph RBD
High-performance block storage for databases and VM volumes.
CephFS & RGW
Shared POSIX file systems and S3-compatible object storage for apps and backups.
Gluster CSI
Shared file volumes via the Gluster CSI driver when that architecture fits.
Visual concept
OpenShift
Pod → PVC → StorageClass
CSI driver provisions an RBD, CephFS, or Gluster volume on demand.
OpenStack
Cinder/Glance → Ceph
Cinder provisions RBD volumes; Glance stores images as RBD, Nova uses RBD for disks.
Integration note
Use the OpenShift Data Foundation operator to deploy and manage Ceph for OpenShift. For OpenStack, configure service-specific cephx users with minimal permissions.
