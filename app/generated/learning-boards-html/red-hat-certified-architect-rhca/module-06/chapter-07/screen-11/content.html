Module 6 › Chapter 6.7 › Cinder RBD config
cinder.conf snippet
[DEFAULT]
enabled_backends = ceph

[ceph]
volume_backend_name = ceph
volume_driver = cinder.volume.drivers.rbd.RBDDriver
rbd_ceph_conf = /etc/ceph/ceph.conf
rbd_ceph_user = cinder
rbd_secret_uuid = <UUID_OF_CEPH_AUTH_SECRET>
rbd_pool = volumes
Checklist & pitfalls
  • Ensure rbd_ceph_conf points to the correct ceph.conf
  • Create a dedicated cephx user for cinder with minimal permissions
  • Store the key in a secure store and reference its UUID
Validation
Create a Cinder volume, then verify an RBD image exists in the volumes pool and that snapshots can be taken and cloned.
