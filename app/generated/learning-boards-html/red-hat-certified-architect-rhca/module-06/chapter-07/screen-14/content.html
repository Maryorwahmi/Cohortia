Module 6 › Chapter 6.7 › Key Concepts
Persistent storage
State survives pod lifecycle; choose access modes and backends carefully.
CSI provisioning
StorageClass + CSI controller + node plugin make dynamic provisioning possible.
Ceph & OpenStack
Ceph is the recommended backend for Cinder and Glance; use dedicated cephx users and pools per service.
Final takeaway

Design storage by matching workload needs to Ceph or Gluster interfaces, validate configuration and secrets, and test the full lifecycle before production.
