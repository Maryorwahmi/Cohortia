Module 6 › Chapter 6.6 › Replicated Volume
Definition

Replica volumes for high availability

A replicated volume keeps identical copies of data on each replica brick to provide redundancy and survive node failures.

# Create a replica 2 volume named 'rep-volume'
sudo gluster volume create rep-volume replica 2 \
  gluster-node01.example.com:/data/brick1 \
  gluster-node02.example.com:/data/brick1 force

# Start the volume
sudo gluster volume start rep-volume

# Verify
sudo gluster volume info rep-volume
sudo gluster volume status rep-volume
Concrete example

Two nodes, each providing one brick path. After creating and starting, confirm the volume is online and accessible from a client.

Key Takeaway

Replica volumes protect data by duplication; plan capacity accordingly and always use unique brick paths on separate nodes.
