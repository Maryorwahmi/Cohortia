Expansion

Add bricks and rebalance

Probe new nodes first, add bricks in groups that match the replica count, then rebalance to redistribute data.

Rules to remember:
  • Add bricks in multiples of replica count for distributed replicated volumes.
  • Probe new nodes before adding bricks.
  • Run rebalance and monitor its status after adding bricks.
    • # Add two bricks to a replica 2 distributed volume
sudo gluster peer probe gluster-node05.example.com
sudo gluster peer probe gluster-node06.example.com
sudo gluster volume add-brick dist-rep-volume \
  gluster-node05.example.com:/data/brick1 gluster-node06.example.com:/data/brick1 force

# Start rebalance
sudo gluster volume rebalance dist-rep-volume start
sudo gluster volume rebalance dist-rep-volume status
    Common error

    Adding a single brick to a replica 2 pattern will not create a valid replica set and the structure will not update as expected.

    Key Takeaway

    Follow the replica-count multiple rule when adding bricks, probe nodes first, then rebalance to redistribute data.
