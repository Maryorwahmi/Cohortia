Module 6 › Chapter 6.6 › Preparing nodes
Definition

What it means to prepare a node

Preparing means assigning dedicated storage for bricks, ensuring a fast network path for Gluster traffic, installing glusterd, and making mounts persistent.

Checklist
  • Dedicated NIC for Gluster traffic (10GbE recommended)
  • Separate disks/partitions for bricks; format with XFS
  • Install and enable glusterd on each node
  • Persistent mounts in /etc/fstab
Common mistake

Using the OS disk for bricks leads to contention and instability; always use separate disks or partitions for bricks.

Concrete example
# Partition /dev/sdb, format, mount, and add to fstab (example actions)
sudo parted -s /dev/sdb mklabel gpt
sudo parted -s /dev/sdb mkpart primary 0% 100%
sudo mkfs.xfs -f /dev/sdb1
sudo mkdir -p /data/brick1
sudo mount /dev/sdb1 /data/brick1
UUID=$(sudo blkid -s UUID -o value /dev/sdb1)
echo "UUID=${UUID} /data/brick1 xfs defaults 0 0" | sudo tee -a /etc/fstab
sudo mount -a
Key Takeaway

Bricks must be isolated from OS storage and mounted consistently; prepare network and time sync for reliable peer discovery.
