Install glusterd and probe a peer

Run the following on each node, then probe one from another to form the pool.

sudo dnf install -y glusterfs-server
sudo systemctl enable --now glusterd

# From gluster-node01:
sudo gluster peer probe gluster-node02.example.com

# Verify on any node:
sudo gluster peer status
Troubleshooting

If peer status does not show connected, check DNS, firewall, and that glusterd is running on both nodes.

Scenario

Two prepared RHEL nodes with /data/brick1 mounted. You install glusterd, probe the second node, and verify connectivity before creating volumes.

Key Takeaway

Peer probe plus verification is the gate to creating volumes. Resolve service or name resolution issues before creating bricks.
