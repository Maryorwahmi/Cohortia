Module 6 › Chapter 6.6 › Trusted Storage Pool
Process

Add nodes to the trusted pool

Follow a short sequence: enable glusterd, probe the peer, and verify with peer status. Repeat for each new node.

  1. Install and start glusterd on the new node.
  2. From an existing member, run peer probe new-node.example.com.
  3. Confirm with sudo gluster peer status on any member.
  4. If problems appear, check DNS, firewall, and systemd for glusterd.
Misconception

Peer probe does not prepare disks or networks; it only establishes trusted membership. Node readiness is a separate step.

Verification example
sudo gluster peer probe gluster-node02.example.com
sudo gluster peer status
# Expect: Peer in Cluster (Connected)
Key Takeaway

A trusted pool is required before creating volumes. Confirm peers are connected and reachable to prevent later replication faults.
