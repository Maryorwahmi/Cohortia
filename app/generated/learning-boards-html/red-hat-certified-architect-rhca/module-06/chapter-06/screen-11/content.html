Module 6 › Chapter 6.6 › Rebalance & Heal
Operation

Start rebalance and inspect heal

Rebalance redistributes data to new bricks; heal reconciles replicas and reports split-brain if files diverged.

  1. Run sudo gluster volume rebalance <volume> start
  2. Monitor with sudo gluster volume rebalance <volume> status
  3. Check healing with sudo gluster volume heal <volume> info
# Start and monitor rebalance
sudo gluster volume rebalance dist-rep-volume start
sudo gluster volume rebalance dist-rep-volume status

# Check heal info
sudo gluster volume heal dist-rep-volume info
Scheduling note

Rebalance and heal can be I/O intensive. Schedule them during low load and monitor network and disk metrics to prevent client impact.

Key Takeaway

After structural changes, rebalance first, then verify healing is complete to ensure consistent replicas across bricks.
