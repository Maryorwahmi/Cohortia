Module 6 › Chapter 6.6 › Client Access

Comparison

Native FUSE client
Full feature support, recommended for performance and healing behavior.
NFS / SMB
Useful for legacy clients; may lack some Gluster features and change performance semantics.
Note

When possible, prefer the native client for full semantics; use exports only when compatibility requires it.

# On a client install and mount (example)
sudo dnf install -y glusterfs-client
sudo mkdir -p /mnt/gluster_share
sudo mount -t glusterfs gluster-node01.example.com:/rep-volume /mnt/gluster_share
# To persist in /etc/fstab:
# gluster-node01.example.com:/rep-volume /mnt/gluster_share glusterfs defaults,_netdev 0 0
Key Takeaway

Choose the client method that matches your app’s need for Gluster features and consistency; native FUSE is the default recommendation.
