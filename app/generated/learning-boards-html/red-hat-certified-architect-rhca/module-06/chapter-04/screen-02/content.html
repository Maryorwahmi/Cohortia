Learning Objectives
Master configuration, deployment, and security for RBD, RGW, and CephFS.
01
Configure and manage RBD
Create pools and thin-provisioned images, map images to block devices, and use snapshots and clones in production.
VERIFIED COMPETENCY MILESTONE
02
Deploy and use RGW for object storage
Provision RGW instances, create S3 users, and interact with buckets using S3-compatible tools and SDKs.
VERIFIED COMPETENCY MILESTONE
03
Set up CephFS and MDS
Create metadata and data pools, deploy MDS daemons for availability, and mount the filesystem with kernel or FUSE clients.
VERIFIED COMPETENCY MILESTONE
04
Understand performance, use cases, and security
Match interface to workload, set PGs and replicas appropriately, and secure access using cephx and TLS where appropriate.
VERIFIED COMPETENCY MILESTONE
