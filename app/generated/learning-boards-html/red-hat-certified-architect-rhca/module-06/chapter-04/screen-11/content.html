Module 6 › Chapter 6.4 › Security
cephx authentication
Ceph clients authenticate with cephx using a username and secret key. Grant minimal permissions and avoid distributing admin keyrings to general clients.
RGW S3 keys
Create S3 users and keys with radosgw-admin. Store keys securely and rotate periodically. Use TLS for RGW endpoints.
Network and TLS
Segment Ceph traffic, limit monitor and OSD access, and front RGW with a load balancer for TLS termination and stable endpoints.
Practical checklist
  • Use cephx for client auth and assign minimal privileges.
  • Issue S3 keys via radosgw-admin and store in a secrets manager.
  • Front RGW with a load balancer and enable HTTPS in production.
  • Rotate keys and audit access regularly.
