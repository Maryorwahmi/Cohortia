Red Hat Ceph Storage: Block, Object, and File
Understand the role of RBD, RGW, and CephFS and how to provision each interface for VMs, cloud-native apps, and shared-file workloads.
In this lesson
RBD: persistent block storage
Thin-provisioned images, snapshots, cloning; used by VMs and stateful pods.
Coming up
RGW: S3-compatible object storage
Scale-out object store for backups, media, and cloud-native apps.
Also
CephFS: POSIX file system
Shared mountable filesystem backed by MDS for metadata management.
Interactive 16:9 Masterclass
Follow command examples in the lesson and try the hands-on activity: create an RBD image and an S3 user in a lab or simulated cluster.
Concept Map
Unified RADOS backend
Pools, OSDs, and CRUSH rules store objects used by all interfaces.
RBD
Thin-provisioned images, snapshots, map to /dev/rbdX for block workloads.
RGW
S3-compatible gateway offering buckets and objects; secure with TLS and load balancer.
CephFS
POSIX file interface managed by MDS daemons; kernel client recommended for performance.
