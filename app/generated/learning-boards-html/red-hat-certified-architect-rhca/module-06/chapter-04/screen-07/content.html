Deploy RGW with cephadm
Deploy one or more RGW instances for HA. Example command deploys two instances.
# Deploy an RGW instance named 'my-rgw' with two replicas
sudo cephadm shell -- ceph orch apply rgw my-rgw --placement="count=2"

# Verify RGW services
sudo cephadm shell -- ceph orch ls --service_type rgw

# Create an S3 user and return credentials
sudo cephadm shell -- radosgw-admin user create --uid=myuser --display-name="My User" --access-key=MYACCESSKEY --secret-key=MYSECRETKEY
# Save generated keys securely and configure client tools.
Pro tip
Automate user creation and key rotation with orchestration tooling to reduce manual exposure of keys.
Warning
Do not expose RGW instances directly in production without a load balancer and TLS.
Concrete example

After creating an S3 user, configure s3cmd or an SDK with the access and secret keys and try listing buckets. If using multiple RGW instances, point the client to a load-balanced endpoint to avoid manual failover logic.

Key Takeaway

RGW is scalable and fault tolerant when backed by multiple instances and a load balancer; secure access with TLS and strong credentials.
