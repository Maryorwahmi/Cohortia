Module 6 › Chapter 6.4 › Interface Comparison
RBD
Block device, thin-provisioned, snapshots, ideal for VMs and databases.
Operational concerns: choose appropriate PG count, replica factor >= 3 for production, and map from clients with proper credentials.
CephFS
POSIX shared file system; requires MDS for metadata management.
Operational concerns: deploy enough MDS for metadata throughput, prefer kernel client for performance, and size metadata pools correctly.
RGW
S3-compatible object gateway for unstructured data and cloud-native apps.
Operational concerns: place RGW behind a load balancer, secure endpoints with TLS, and create S3 users with radosgw-admin.
Decision checklist
  • Does the workload require POSIX semantics? Use CephFS.
  • Does it need direct block I/O and low latency? Use RBD.
  • Is the data unstructured and accessed via HTTP/S3 APIs? Use RGW.
