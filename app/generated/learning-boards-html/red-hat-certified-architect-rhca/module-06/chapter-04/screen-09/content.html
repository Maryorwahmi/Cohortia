How CephFS works

CephFS stores file data in RADOS pools while MDS daemons manage metadata — directories, inodes, and ACLs. This design separates fast path data I/O from metadata operations, enabling scale for different workload profiles.

Operational notes
  • Deploy multiple MDS daemons for availability and load sharing.
  • Metadata pool sizing and PGs matter for metadata-heavy workloads.
  • Prefer the kernel client when possible for best performance.
Key Takeaway

Use CephFS when applications require POSIX semantics and concurrent mounts; size MDS and metadata pools for expected metadata rates.

Commands to deploy CephFS
# Deploy MDS daemons (example: two instances)
sudo cephadm shell -- ceph orch apply mds myfs --placement="count=2"

# Create pools needed for CephFS
sudo cephadm shell -- ceph osd pool create myfs_metadata_pool 64 64
sudo cephadm shell -- ceph osd pool create myfs_data_pool 128 128

# Create the filesystem
sudo cephadm shell -- ceph fs new myfs myfs_metadata_pool myfs_data_pool

# Verify status
sudo cephadm shell -- ceph fs ls
sudo cephadm shell -- ceph fs status myfs
