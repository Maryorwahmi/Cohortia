Module 5 › Chapter 5.5 › Practical Reminders
Check router gateways
If instances can't reach the internet, inspect the router's external_gateway_info as your first verification step.
Use volume types
Expose SSD and HDD tiers via volume types so users request the right performance without knowing backend details.
Monitor Ceph
Run ceph status and pool checks regularly and alert on WARN or ERR to avoid service impact.
Final takeaway
These operational practices make networking and storage changes predictable and reduce failures in production OpenStack clouds.
