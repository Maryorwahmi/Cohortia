Module 5 › Chapter 5.5 › Ceph integration
What Ceph provides
  • RBD for block volumes with replication and distribution across OSDs.
  • Scalability by adding OSDs and storage nodes.
  • Unified backend for Cinder volumes and Glance images.
Design points: plan OSD counts, placement groups, and separate public/cluster networks for best performance.
Operational concerns

Under-provisioned OSDs or incorrectly sized placement groups lead to performance bottlenecks. Misconfigured pools can affect availability. Monitor cluster health to detect issues early.

Common mistake
Failing to separate traffic between public and cluster networks, which can degrade performance under load.
Key Takeaway

Ceph provides RBD-backed volumes for Cinder with strong resilience and scalability when designed and monitored carefully.
