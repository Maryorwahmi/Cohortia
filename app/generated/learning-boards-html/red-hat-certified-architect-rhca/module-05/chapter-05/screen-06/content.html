Module 5 › Chapter 5.5 › Provider vs Project Networks
Provider Networks
  • Mapped to physical networks for direct connectivity and high performance.
  • Used for floating IPs, external access, or services requiring physical network features.
  • Simpler mapping but less tenant-level flexibility.
Use case example: public-facing web tier that needs predictable bandwidth and low latency.
Project (Self-Service) Networks
  • Virtual, tenant-owned networks using overlays like VXLAN or VLANs.
  • Provide strong isolation and flexible topologies without changing physical switches.
  • Great for multi-tenancy and self-service networking.
Use case example: tenant staging environments that require full virtual network control without touching the physical fabric.
Trade-off
Performance and simplicity versus flexibility and isolation.
Common mistake
Exposing project networks directly to physical networks or misassigning external gateways, causing security or connectivity issues.
Pro Tip
Document which services require provider networks and reserve those physical mappings to prevent accidental tenant exposure.
