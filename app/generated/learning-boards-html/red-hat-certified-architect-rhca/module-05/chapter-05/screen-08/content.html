What is a Cinder volume?
  • Persistent block storage exposed to instances like a regular disk.
  • Volumes persist independently from instance lifecycle unless deleted.
  • Snapshots capture a volume state and can be used to create new volumes.
Example: create a 10GB volume and attach it to a running instance to hold database files that outlive the VM.
Operational notes

Use snapshots for backups or to create derived volumes. Choose volume types to map to backend characteristics and enforce policies for retention and deletion to avoid capacity issues.

Common mistake
Assuming snapshotting is automatic. Snapshots must be created and managed as part of your backup plan.
Key Takeaway

Treat volumes as durable resources; plan volume types and snapshot cadence based on workload requirements.
