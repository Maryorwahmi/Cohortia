Module 5 › Chapter 5.5 › Ceph Checks
Health and pools
# Check Ceph cluster status (if integrated)
sudo ceph status

# List Ceph pools
sudo ceph osd pool ls
Interpretation: HEALTH_OK is expected; any WARN/ERR requires investigation into OSDs, PGs, or network issues.
Operational guidance

Schedule regular Ceph checks and integrate them into monitoring and alerts. Validate that Cinder-related pools exist and have appropriate replication and size settings.

Common mistake: ignoring PG distribution and OSD usage until performance degrades; proactively monitor these metrics.
Key Takeaway

Run Ceph status and pool checks frequently and respond to warnings to maintain storage reliability and performance.
