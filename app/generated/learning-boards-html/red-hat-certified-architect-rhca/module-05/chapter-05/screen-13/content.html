Networking steps (follow and verify)
# Assume 'external-net' exists or create a placeholder
# openstack network create --external --provider-physical-network datacentre --provider-network-type flat external-net

# Create a new private network
openstack network create tenant-private-net

# Create a subnet in the private network
openstack subnet create --network tenant-private-net \
  --subnet-range 10.0.0.0/24 \
  --gateway 10.0.0.1 \
  --dns-nameserver 8.8.8.8 \
  tenant-private-subnet

# Create a router
openstack router create tenant-router

# Connect the private subnet to the router
openstack router add subnet tenant-router tenant-private-subnet

# Set the router's gateway to the external network
openstack router set --external-gateway external-net tenant-router
Storage steps (create and snapshot)
# Create a 10GB block storage volume
openstack volume create --size 10 my-data-volume

# (Attach to an instance as needed using your environment's attach method)
# Create a snapshot of the volume
openstack volume snapshot create --volume my-data-volume my-data-volume-snapshot

# Create a new volume from the snapshot
openstack volume create --snapshot my-data-volume-snapshot --size 10 new-volume-from-snapshot

# Verification commands
openstack network list
openstack subnet list
openstack router list
openstack router show tenant-router
openstack volume list
openstack volume snapshot list
Lab checkpoint
Confirm router external_gateway_info and that the snapshot status is available before creating a derived volume.
Safety tip
Detach and delete volumes carefully in lab environments to avoid orphaned storage. Use your cloud's recommended detach workflow.
Key Takeaway
Follow verification steps after each operation to catch configuration mistakes early.
