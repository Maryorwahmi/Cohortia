Module 5 › Chapter 5.5 › Applied Objectives
CLI Workflows

Practice the exact commands to create networks, subnets, routers, volumes and snapshots, then verify the results with list and show commands. Mastering these flows reduces common operational mistakes.

Verification

Learn to inspect router external gateway settings, list networks and subnets, and run Ceph status checks. Verification reveals configuration gaps before production impact.

Lab Readiness

Follow the guided lab to create a tenant network, attach a router to an external provider, create volumes, and snapshot them. The lab includes checkpoints to confirm success.

Common Pitfalls

Watch for incorrect CIDR ranges, forgotten external gateway settings, and under-provisioned Ceph resources. These are frequent causes of outages and performance problems.
