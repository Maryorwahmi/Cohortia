Module 5 › Chapter 5.5 › Cinder CLI
Common commands
# Create a 10GB block storage volume
openstack volume create --size 10 my-data-volume

# Create a snapshot of a volume
openstack volume snapshot create --volume my-data-volume my-data-volume-snapshot

# Create a new volume from a snapshot
openstack volume create --snapshot my-data-volume-snapshot --size 10 new-volume-from-snapshot
Verification and cautions
  • Confirm the snapshot status becomes available before creating a volume from it.
  • Verify backend capacity to avoid provisioning failures.
  • Plan retention for snapshots to avoid unexpected storage consumption.
Exercise: create a snapshot, wait for it to become available, then provision a new volume from it and attach to a test instance to validate integrity.
Key Takeaway

Snapshots enable cloning and backups, but always verify completion and pool capacity before provisioning derived volumes.
