Module 5 › Chapter 5.5 › Neutron fundamentals
Definitions and roles
  • Network: an isolated Layer 2 segment where instances attach and communicate.
  • Subnet: an IP address range with gateway and DNS settings for that network.
  • Router: a logical device that connects networks and can be given an external gateway for outbound traffic.
Analogy
Think of a network as a building floor, a subnet as the room's wiring plan and addresses, and the router as the building's exit to the city.
Common mistake
Assuming instances have internet access without verifying the router's external gateway. Verify router configuration to avoid this issue.
Concrete example
# Create a private network
openstack network create private-net

# Create a subnet in that network
openstack subnet create --network private-net \
  --subnet-range 192.168.1.0/24 \
  --gateway 192.168.1.1 \
  --dns-nameserver 8.8.8.8 \
  private-subnet

# Create a router and attach the subnet
openstack router create my-router
openstack router add subnet my-router private-subnet

# Set the router gateway to an external provider network
openstack router set --external-gateway external-net my-router
Key Takeaway

Define addressing and gateway intentionally; verify router external gateway to provide external connectivity.
