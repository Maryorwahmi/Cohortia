Module 5 › Chapter 5.5 › Troubleshooting
Networking checks
  • Confirm the instance IP is in the correct subnet and that security group rules allow egress.
  • Run router show and inspect external_gateway_info for the gateway mapping.
  • Check for overlapping CIDRs or incorrect gateway configuration that blocks routing.
Storage checks
  • Ensure the volume is in the expected state (available or in-use) and snapshots are complete.
  • If using Ceph, run ceph status and inspect pools and OSD health for degraded PGs or down OSDs.
  • Validate pool configuration and capacity to prevent provisioning failures.
Documentation
Record verification outputs and steps taken so teams can reproduce fixes and prevent recurrence.
Escalation
If backend checks show Ceph WARN/ERR, escalate to storage operations with Ceph status outputs and affected pool names.
Key Takeaway
Start with simple verification; then inspect router gateways and Ceph health to find root causes of connectivity or storage issues.
