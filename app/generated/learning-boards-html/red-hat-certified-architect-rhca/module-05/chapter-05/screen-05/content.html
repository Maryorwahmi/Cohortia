Module 5 › Chapter 5.5 › Create Tenant Network
Step-by-step
  1. Create the private network for the project and confirm creation.
  2. Create a subnet with a CIDR, gateway, and DNS entries; avoid overlapping ranges.
  3. Create a router and add the subnet so the tenant has routed connectivity.
  4. Set the router's external gateway to a provider network for outbound access.
  5. Verify with network, subnet, and router list/show commands.
Verification checklist
Run: openstack network list; openstack subnet list; openstack router show <router> and inspect external_gateway_info.
CLI Example
# Create a new private network
openstack network create tenant-private-net

# Create a subnet in the private network
openstack subnet create --network tenant-private-net \
  --subnet-range 10.0.0.0/24 \
  --gateway 10.0.0.1 \
  --dns-nameserver 8.8.8.8 \
  tenant-private-subnet

# Create a router and attach the subnet
openstack router create tenant-router
openstack router add subnet tenant-router tenant-private-subnet

# Set the router's gateway to the external network
openstack router set --external-gateway external-net tenant-router
Key Takeaway

Follow address planning and verify gateway configuration to ensure outbound connectivity for tenant instances.
