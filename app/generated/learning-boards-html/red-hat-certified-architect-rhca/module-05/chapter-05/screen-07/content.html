Module 5 › Chapter 5.5 › Neutron CLI Walkthrough
Create resources (example)
# Create a private network
openstack network create private-net

# Create a subnet in that network
openstack subnet create --network private-net \
  --subnet-range 192.168.1.0/24 \
  --gateway 192.168.1.1 \
  --dns-nameserver 8.8.8.8 \
  private-subnet

# Create a router and attach the subnet
openstack router create my-router
openstack router add subnet my-router private-subnet

# Set the router's gateway to an external provider network
openstack router set --external-gateway external-net my-router
Verification commands
  • Use openstack network list and openstack subnet list to confirm creation.
  • Use openstack router list and openstack router show <router> to inspect external_gateway_info.
  • If connectivity fails, confirm CIDRs do not overlap and that floating IPs are available on the provider network.
Misconception: instance IP equals internet access. Confirm the router has an external gateway first.
Key Takeaway

Make verification commands part of every provisioning step to catch gateway and CIDR issues early.
