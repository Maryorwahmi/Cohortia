Module 5 › Chapter 5.3 › Operational Checklist
Inspect introspection
Confirm hardware facts like cpu and memory_mb before tagging.
Map with node_data.yaml
Keep mappings separate from upstream templates for maintainability.
Use logs & --debug
Check openstack stack failures list, /var/log/heat/heat-engine.log and /var/log/mistral/mistral-api.log when issues occur.
Closing summary
Keep a repeatable sequence: install Undercloud, import and introspect nodes, tag and map them, then deploy with layered environment files. Validate at each step and use logs to resolve failures quickly.
