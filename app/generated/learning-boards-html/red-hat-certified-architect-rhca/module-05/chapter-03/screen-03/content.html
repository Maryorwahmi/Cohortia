Module 5 › Chapter 5.3 › Learning Objectives
Terminal Demo Plan
Undercloud install
Install openstack-director and run the installer after editing undercloud.conf to match your environment.
Node preparation
Create instackenv.json, import nodes, start bulk introspection, and validate results.
Tagging & mapping
Define node_data.yaml to map discovered hardware to Overcloud roles like compute and ceph-storage.
Deploy & verify
Run openstack overcloud deploy with templates and environment files, use --debug, check logs and stack failures list.
Starter snippet
# Example Overcloud deployment command
openstack overcloud deploy \
  --templates /usr/share/openstack-tripleo-heat-templates \
  -n /home/stack/templates/node_data.yaml \
  -e /home/stack/templates/network-environment.yaml \
  -e /home/stack/templates/ceph-environment.yaml \
  -e /home/stack/templates/overcloud_images.yaml \
  --stack overcloud \
  --debug
Verification tip
Capture the pre- and post-introspection 'openstack baremetal node list' to show state changes and confirm successful discovery.
