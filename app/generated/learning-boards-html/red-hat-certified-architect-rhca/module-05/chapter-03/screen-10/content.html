Module 5 › Chapter 5.3 › Heat Templates & Env Files
Layering pattern
Keep a small, focused environment file for each concern. For example, network-environment.yaml for network settings, ceph-environment.yaml for Ceph, and node-config.yaml for per-node tweaks. Pass them in order to overcloud deploy so later files override earlier ones when needed.
Why not edit templates?
Editing upstream templates complicates upgrades. Using environment files keeps customizations separate and easier to maintain across template updates.
Example list
  • network-environment.yaml — network and VLAN configuration
  • ceph-environment.yaml — enable and configure Ceph storage
  • overcloud_images.yaml — point to Overcloud images in Glance
Key Takeaway

Layer environment files to customize an Overcloud without modifying the upstream Heat templates, ensuring a maintainable deployment process.

Pro Tip
Name environment files clearly by concern and keep them small to make override behavior predictable during deployment.
