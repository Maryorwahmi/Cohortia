Provisioning network guidance

Provisioning network settings in undercloud.conf must match the physical cabling and switch configuration for your bare metal. Use a dedicated CIDR and interface to avoid collisions. Verify that DHCP and PXE traffic are enabled and that no external DHCP server will interfere.

Example check
If your provisioning_interface is eth1 and local_cidr is 192.168.24.0/24, ensure the nodes are connected to the eth1 network and there is no other DHCP on that segment.
Common mistake

Reusing a production network for provisioning often leads to IP conflicts and failed introspection. Use an isolated provisioning network.
