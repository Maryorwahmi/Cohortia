Module 5 › Chapter 5.3 › Undercloud Install
Step-by-step
  1. Prepare a minimal RHEL host and install openstack-director.
  2. Create or edit /etc/undercloud/undercloud.conf to set provisioning_interface, local_cidr, and image locations.
  3. Run openstack undercloud install and watch logs for errors.
Common failure modes
  • Incorrect IP ranges or provisioning interface preventing PXE boot.
  • Firewall rules blocking required services.
  • Insufficient disk space on the Undercloud host.
Log and verify
/var/log/undercloud-install.log
# Review this file when installation fails to find service start errors and network issues.
Key Takeaway

Correct undercloud.conf values and an open provisioning network are prerequisites for a successful Undercloud install.

Pro Tip
Reserve a dedicated provisioning network to avoid IP conflicts and to simplify PXE and introspection traffic during node discovery.
