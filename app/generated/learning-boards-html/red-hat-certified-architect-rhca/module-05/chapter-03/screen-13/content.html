Module 5 › Chapter 5.3 › Lab Walkthrough
Demo script (conceptual)
  1. Edit undercloud.conf with provisioning interface and CIDR.
  2. Create instackenv.json with MACs and power details.
  3. Import nodes and confirm with openstack baremetal node list.
  4. Run bulk introspection and inspect results for at least one node.
  5. Create node_data.yaml to tag nodes and prepare environment files.
  6. Run openstack overcloud deploy with templates, node_data and environment files using --debug.
Key Takeaway

Follow the sequence: configure Undercloud, import and introspect nodes, map roles, then deploy. Validate at each step to prevent cascading failures.

Terminal snippets
# Import nodes openstack baremetal import --json ~/instackenv.json # Start introspection openstack baremetal introspection bulk start # Show introspection openstack baremetal introspection show <NODE_UUID>
Accessibility note
When demoing, use a high-contrast terminal theme, captions and clear voiceover. Emphasize common mistakes like incorrect MACs and IPMI passwords.
