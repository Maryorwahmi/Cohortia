Module 5 › Chapter 5.3 › Overcloud Deploy
Command breakdown
openstack overcloud deploy \
  --templates /usr/share/openstack-tripleo-heat-templates \
  -n /home/stack/templates/node_data.yaml \
  -e /home/stack/templates/network-environment.yaml \
  -e /home/stack/templates/ceph-environment.yaml \
  -e /home/stack/templates/overcloud_images.yaml \
  --stack overcloud \
  --debug
Before running this command, confirm node_data mappings, validate environment file syntax, and verify introspection results. The --debug flag generates verbose output that helps identify resource or network failures quickly.
What to watch
  • openstack stack failures list to see resource failures
  • /var/log/heat/heat-engine.log for orchestration errors
  • console output of Overcloud nodes for boot issues
Key Takeaway

The overcloud deploy command ties together templates, node mapping and environment files; verify prerequisites first and use --debug to gather logs for troubleshooting.

Pro Tip
Run a dry-run style validation by checking environment files for syntax and ensuring image references exist in Glance before deploying.
