Module 5 › Chapter 5.3 › TripleO: Undercloud vs Overcloud
Definition

Undercloud

A minimal OpenStack deployment used to orchestrate and manage Overcloud builds. It hosts services such as Ironic, Heat, Glance, and Neutron for provisioning and orchestration.

Why it matters
It provides repeatable automation, making production deployments easier to upgrade and manage.
Misconception
Do not treat Undercloud as only an installer script; it's a running OpenStack environment with services and APIs used for orchestration.
Analogy

Think of Undercloud as a factory control room that runs the machines which assemble the product. The Overcloud is the finished product, assembled and ready for customers.

Components highlighted
  • Ironic: bare metal provisioning and introspection.
  • Heat: orchestration engine that applies templates to create resources.
  • Glance: stores images used to provision Overcloud nodes.
Concrete example
Install openstack-director on a RHEL host, configure undercloud.conf with provisioning CIDR and image URI, and run openstack undercloud install to bring the Undercloud up.
Key Takeaway

TripleO relies on a functioning Undercloud to reliably deploy and manage the Overcloud; treat it as an operational control plane, not a one-time installer.
