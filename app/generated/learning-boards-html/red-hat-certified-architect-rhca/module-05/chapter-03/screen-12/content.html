Module 5 › Chapter 5.3 › Troubleshooting Deploy Failures
Common causes
Network misconfiguration
Wrong VLAN IDs, IP conflicts, or firewall blocks affecting PXE and API traffic.
Resource mismatch
Nodes lack CPU, memory or disk to satisfy role requirements reported by introspection.
Driver or power issues
Wrong pm_type or incorrect IPMI credentials in instackenv.json prevent power controls or provisioning.
Template/environment errors
Incorrect environment file parameters or missing image references cause orchestration failures.
Logs & commands
  • openstack stack failures list — see failing resources
  • /var/log/heat/heat-engine.log — orchestration details
  • /var/log/mistral/mistral-api.log — workflow-level errors
Quick checklist

Verify network segments, validate introspection outputs, confirm driver settings, then re-run deploy with --debug to gather verbose logs.

Pro Tip
Address network and introspection issues first; many orchestration failures are downstream symptoms of earlier misconfiguration.
