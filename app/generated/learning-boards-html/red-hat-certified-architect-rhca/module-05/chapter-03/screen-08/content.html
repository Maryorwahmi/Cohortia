Module 5 › Chapter 5.3 › Hardware Introspection
Commands
# Start bulk introspection
openstack baremetal introspection bulk start

# Show introspection for a node
openstack baremetal introspection show
After introspection completes, inspect cpu, memory_mb and local_gb fields. These determine whether a node matches the role requirements defined in your node_data.yaml or flavors.
Example scenario
If a node returns memory_mb: 65536 and local_gb: 200, you can tag it as compute or storage based on your policy. If values are missing, rerun introspection or check PXE and network connectivity.
Misconception

Introspection is not a passive discovery; it actively PXE boots nodes and must be monitored for success. Don’t skip validation.

Check your understanding
What hardware fields would stop a node from being used as a compute host? (Answer: insufficient CPU or memory reported by introspection.)
