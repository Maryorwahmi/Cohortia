instackenv.json example
{
  "nodes": [
    {
      "pm_type": "ipmi",
      "pm_addr": "192.168.1.10",
      "pm_user": "admin",
      "pm_password": "password",
      "mac": [ "AA:BB:CC:DD:EE:F0" ],
      "cpu": 16,
      "memory": 65536,
      "disk": 200,
      "arch": "x86_64"
    }
  ]
}
After creating this file, run: openstack baremetal import --json ~/instackenv.json to register the nodes. Confirm with a node list before introspection to capture the imported state.
Import & verify
Use openstack baremetal import to register nodes. If imports fail, check MAC accuracy and power management credentials. Capture 'openstack baremetal node list' before and after import as proof of registration.
Common mistake

Incorrect MAC addresses or IPMI credentials prevent successful import and later power operations; double-check values before import.

Example verification
Run 'openstack baremetal node list' to see nodes appear in the Ironic inventory after import.
