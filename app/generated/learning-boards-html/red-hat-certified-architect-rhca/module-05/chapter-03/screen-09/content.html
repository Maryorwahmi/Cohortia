Module 5 › Chapter 5.3 › Node Tagging & Mapping
Tagging pattern
Controller
Nodes requiring high availability and control plane resources.
Compute
High CPU and memory nodes for tenant workloads.
Ceph-storage
Nodes with fast disks mapped for storage backends.
node_data.yaml usage
Provide node_data.yaml to overcloud deploy via -n to ensure Heat knows which nodes to consume for each role.
Practical advice
Review introspection fields such as cpu and memory_mb before tagging. If a node is missing expected resources, rerun introspection rather than forcing a tag.
Key Takeaway

Tagging maps hardware to roles; combine introspection validation with node_data.yaml to let Heat allocate nodes correctly during deploy.

If a node intended for compute shows less RAM than required, what should you do before tagging? (Answer: rerun introspection or inspect PXE/network issues.)
