Core Concept › Dependencies: RabbitMQ & DB
Why they matter
  • • RabbitMQ forwards RPC and task messages between services.
  • • Databases store persistent state for OpenStack services.
  • • Failures in either will produce service-level errors across the cloud.
Checks to run
RabbitMQ
Check queue depth, node status, and connection errors. Backlogs indicate consumers are blocked.
Database
Verify dumps succeed, confirm connectivity, and watch for slow queries or locks that block services.
Concrete Example

High RabbitMQ queue depth with many unacked messages often points to blocked consumers or network issues between controllers and workers.
