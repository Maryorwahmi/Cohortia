Definition › Centralized Logging
Why centralize logs?

Central logs let you search across services, correlate errors, and build dashboards for trends and anomalies.

  • • Index logs for fast search across controllers and compute nodes.
  • • Retain logs long enough for post-mortem and compliance.
  • • Use request IDs to trace an event end-to-end.
Common Mistake

Sending logs without consistent timestamps or without request context makes correlation unreliable. Always enable NTP and include identifiers in logs.

Stack comparison
ELK (Elasticsearch, Logstash, Kibana)
Open components that index logs, transform them, and visualize results. Common in self-hosted environments.
Splunk
Commercial platform with integrated indexing, search, and alerting. Operational trade-offs include licensing and appliance models.
Concrete Example

When a VM fails to boot, search for the instance UUID across Nova API, scheduler, compute, and Neutron logs to find the earliest failing component.
