Comparison › Neutron Agent Checks
Verify agents
# List network agents
openstack network agent list

# On a compute node, tail neutron agent logs
sudo journalctl -u neutron-openvswitch-agent.service -f

# Check network interfaces
ip a
Look for agent state, recent restarts, or interface errors. DHCP and metadata agents are essential for instance networking.
Concrete Example

If DHCP agent is down, instances may receive no IP lease. Fix agent crashes or networking configuration on the host to restore instance provisioning.

Common Mistake

Assuming compute is at fault without checking Neutron agents and host interfaces leads to unnecessary host reboots or misapplied fixes.
