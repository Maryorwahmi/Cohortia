Process Flow › CLI & Logs
Common Commands
# List OpenStack services
openstack service list

# Check Nova API logs (follow latest entries)
sudo journalctl -u openstack-nova-api.service -f

# Tail Neutron server logs
sudo journalctl -u openstack-neutron-server.service -f

# Show an instance
openstack server show
Note: replace <instance-id> with the affected instance UUID. Use systemctl status to check unit state if a service appears down.
Gathering evidence
  • • Capture openstack service list and relevant openstack server show output.
  • • Tail journalctl for implicated units and copy the first error lines.
  • • Check ip a and df -h for host network or disk issues.
Key Takeaway
Collect a minimal reproducible evidence set that includes CLI outputs and the relevant log excerpts before taking corrective actions.
