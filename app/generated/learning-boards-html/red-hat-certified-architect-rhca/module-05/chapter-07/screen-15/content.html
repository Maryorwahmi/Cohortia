Recall › Three Reminders
Monitor
Track service-specific metrics such as API latency, scheduler queues, and agent heartbeats in addition to host metrics.
Logs
Centralize logs with consistent timestamps and request IDs to reconstruct multi-service events.
Backup
Back up databases, /etc configurations, and Glance images; test restores regularly.
Reflection

Pick one of these reminders to improve this week. Small actions, like adding one Grafana panel or scheduling a restore test, produce measurable operational benefit.
