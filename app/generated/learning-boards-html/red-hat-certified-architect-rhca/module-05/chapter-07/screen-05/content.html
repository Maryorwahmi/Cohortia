Process Flow › Prometheus & Grafana
Architecture Summary

Prometheus scrapes exporters, stores time-series metrics, and triggers alerts. Grafana queries Prometheus and builds dashboards for context and trend analysis.

  • • Use exporters for Nova, Neutron, Cinder, Keystone, and host metrics.
  • • Label metrics with instance, host, and service roles.
  • • Archive long-term metrics for capacity planning.
Example Alert

Trigger when Nova API p99 latency is high AND RabbitMQ queue depth exceeds threshold. This reduces false positives and points to messaging bottlenecks.

Scrape pipeline
Exporters
Service and host exporters expose metrics endpoints.
Prometheus
Scrapes endpoints and stores data with labels for filtering.
Grafana
Builds dashboards and alerts backends.
Common Mistake
Using coarse scrape intervals that miss short-lived spikes in API latency.
Pro Tip
Label metrics by role so you can filter dashboards for controllers, compute nodes, or storage clusters quickly.
