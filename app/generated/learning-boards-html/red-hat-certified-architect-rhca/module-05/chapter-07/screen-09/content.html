Process Flow › Troubleshooting Workflow
Step-by-step
  1. Define the symptom and time window.
  2. Collect state via openstack CLI and system tools.
  3. Tail service logs and search central logs for correlated entries.
  4. Verify dependencies: RabbitMQ, DB, Keystone.
  5. Form a narrow hypothesis, test, and observe.
Example Scenario

If instances fail to boot and logs show messaging timeouts, verify RabbitMQ queue depth and connectivity. If backlog is present, address messaging or scaling rather than restarting compute nodes blindly.

Post-incident

Document root cause, remediation, and update runbooks and alerts to prevent recurrence.
