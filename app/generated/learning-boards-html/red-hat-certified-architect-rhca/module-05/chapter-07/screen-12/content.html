Definition › Backup & Recovery
Essential backups
  • • Databases: mysqldump or pg_dump for Keystone, Nova, Neutron, Cinder, Glance.
  • • Configuration files: /etc// directories for each service.
  • • Glance images and Ceph pool metadata: ensure durability or off-site copies.
Recovery considerations
A restore must produce a consistent control plane: import databases, restore configuration files, verify Keystone identity data, and re-register services if necessary. Testing recovery procedures regularly reduces surprises during real incidents.
Concrete Example
Restore MariaDB dumps, restore /etc/nova, then start nova-api and nova-scheduler in sequence while watching logs for migration errors.
Common Mistake
Backing up data but not configuration files leaves you unable to restore a working environment quickly.
