Module 5 › Chapter 5.4 › Key Pairs
Why key pairs
Key pairs enable public-key authentication and remove the need to manage host passwords. They are suitable for automation and avoid weak credentials in production systems.
Best practices
  • Generate keys with strong algorithms and protect private keys with a passphrase if appropriate.
  • Do not store private keys in code repositories or shared drives.
  • Rotate keys if an operator leaves or a key is suspected compromised.
Key Takeaway

Use SSH key pairs for predictable and auditable access; verify key injection after booting an instance.

Commands
# Generate an SSH key pair
ssh-keygen -t rsa -b 2048 -f ~/.ssh/my_openstack_key

# Upload the public key to OpenStack
openstack keypair create --public-key ~/.ssh/my_openstack_key.pub my_openstack_key

# List available key pairs
openstack keypair list
Verification
After launching, check instance metadata with openstack server show to see the key name. Attempt SSH using the private key and verify access is granted only with that key.
