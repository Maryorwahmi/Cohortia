Module 5 › Chapter 5.4 › Key Concepts
Key Pair
Public-key authentication for SSH. Upload the public key and keep the private key secure.
QCOW2
Copy-on-write image format supporting snapshots and sparse allocation; preferred for features and efficiency.
Security Group
Stateful firewall rules applied to instances; use least-privilege rules and attach groups intentionally.
Final takeaway
Combine secure access, curated images, and minimal network exposure to deliver reliable and safe instances. Verify each step with the OpenStack CLI commands shown earlier.
