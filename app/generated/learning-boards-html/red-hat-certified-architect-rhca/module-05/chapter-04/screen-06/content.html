Module 5 › Chapter 5.4 › Create a Flavor
Walkthrough
Run the create command with desired RAM, disk, and vcpus. Use flavor set to attach properties like hw:cpu_policy. Always verify with flavor list and flavor show.
Pro tip
Maintain a short catalog that maps flavor names to workload types and expected performance so operators pick the correct flavor under pressure.
Key Takeaway

Create, annotate, and verify flavors; document their intended use.

Terminal
# Create a custom flavor for a medium-sized VM
openstack flavor create --ram 4096 --disk 40 --vcpus 2 m1.medium-custom
# Set a flavor property, for example to request dedicated CPUs
openstack flavor set --property hw:cpu_policy=dedicated m1.medium-custom
# Verify the flavor exists
openstack flavor list
openstack flavor show m1.medium-custom
Expected verification
  • Flavor appears in openstack flavor list.
  • openstack flavor show shows the hw:cpu_policy property if set.
