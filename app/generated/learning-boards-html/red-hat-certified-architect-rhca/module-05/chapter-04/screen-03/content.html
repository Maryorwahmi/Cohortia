Module 5 › Chapter 5.4 › Verification Checklist
Objective checks
  • Instance lifecycle: use openstack server list and openstack server show to confirm boot and state transitions.
  • Flavor & key pair: create flavor then launch instance; confirm CPU and RAM match and key pair appears in the instance metadata.
  • Security group: list rules with openstack security group show and test connectivity to only allowed ports.
  • Images: upload an image and confirm it appears in openstack image list before booting.
VERIFIED COMPETENCY MILESTONE
Practical tips
Collect the output of these commands as evidence for your lab: openstack server show, openstack image list, openstack flavor show, and openstack security group show. Keep your SSH private key secure; never upload or share it.
Key Takeaway

Define explicit verification steps for each objective and collect CLI output as proof of competency.
