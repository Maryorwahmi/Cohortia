Module 5 › Chapter 5.4 › Key Concepts
Nova
Compute service that manages instance lifecycle and scheduling.
Glance
Image service that stores virtual disk templates in QCOW2 or RAW formats.
Flavor
Predefined virtual hardware profile: vCPU, RAM, and disk.
Takeaway
Remember the roles: Nova orchestrates, Glance provides images, and flavors determine the resources each instance receives. Use them together with key pairs and security groups to launch secure, well-sized instances.
