Module 5 › Chapter 5.4 › Glance Images
Image formats
QCOW2: supports snapshots, sparse files, and is space-efficient. RAW: simple and widely compatible but lacks snapshots and space-saving features.
Image lifecycle
Import vendor images or create your own by installing and hardening a system, then snapshot it to Glance. Keep images clean and include cloud-init for automation.
Key Takeaway

QCOW2 is usually preferred for images because it supports snapshots and efficient storage; manage images to avoid sprawl and stale templates.

Concrete command
# Upload a QCOW2 image to Glance
openstack image create "cirros" \
  --file cirros-0.5.2-x86_64-disk.img \
  --disk-format qcow2 --container-format bare \
  --public

# Verify
openstack image list
Common mistake
Using many slightly different images instead of parameterized configuration leads to image sprawl and storage waste. Standardize and patch images regularly.
