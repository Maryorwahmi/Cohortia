Managing Compute (Nova) and Image (Glance) Services

Provision virtual machines from trusted images, define flavors that match workload needs, secure access with key pairs and security groups, and keep image inventories clean and safe.

In this lesson • Terminal-first demo • Hands-on activity
Orientation

You will follow a repeatable flow: confirm or upload an image to Glance, create a flavor that fits your workload, add a key pair for SSH, open only the needed ports with a security group, then boot an instance and verify networking. These steps form the production-safe path to launching an instance.

Why it matters
  • Right-sized flavors reduce contention and cost.
  • Key pairs avoid password-based attacks.
  • Image hygiene reduces attack surface.
Explore Key Topics
Flavors & Sizing
Design flavors to match CPU, RAM and disk needs; avoid overcommit surprises.
Secure Access
Use SSH key pairs and minimal security group rules to limit exposure.
Image Hygiene
Prefer QCOW2 with cloud-init and purge unneeded packages before snapshotting.
Concept Map
How Nova and Glance connect
Glance
Image repository
Stores QCOW2 and RAW images used to boot instances. Images can be public or private per project.
Nova
Instance lifecycle
Nova uses images, flavors, key pairs and security groups to boot and manage instances for tenants.
Flavor
Virtual hardware profile
Defines CPU, RAM, and disk sizes. Create custom flavors to match workload profiles.
Quick start checklist
  • Confirm or upload your image to Glance.
  • Create or choose a flavor aligned with your workload.
  • Create a key pair for SSH and a narrow security group for ports.
