Module 5 › Chapter 5.4 › Nova Lifecycle
Definition
Nova manages compute resources and the lifecycle of instances. It schedules instances to compute nodes and coordinates with Glance, Neutron, and Cinder for images, networking, and block storage.
Common operations
  • Boot: create a new instance from an image and flavor.
  • Rebuild: replace the disk with another image and reboot.
  • Resize: change the instance flavor and resources.
  • Terminate: remove instance and free resources.
Key Takeaway

Nova controls instance lifecycle but depends on external services for images, networking and storage.

Example flow
When you run a server create command, Nova: requests the image from Glance, selects a host based on flavor and capacity, injects the SSH public key if provided, and applies security group rules. The instance then boots and registers its state in Nova.
Concrete example
Boot a tiny instance for testing, then use openstack server show to confirm host and flavor were honored.
Misconception
Changing a Glance image does not change already-running instances. To update running systems, rebuild or snapshot and relaunch from the updated image.
