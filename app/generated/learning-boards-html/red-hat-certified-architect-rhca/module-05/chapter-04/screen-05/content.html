Module 5 › Chapter 5.4 › Flavors
What a flavor defines
  • vCPU count
  • RAM in megabytes
  • Root disk size in gigabytes
  • Optional properties, e.g., hw:cpu_policy for dedicated CPUs
Comparison: default vs custom
Default
Quick to use but may not match production needs. Good for tests and CI tasks.
Custom
Tailored to workload; specify CPU policy and properties for performance-sensitive services.
Key Takeaway

Standardize a small set of documented flavors that align with common workloads and host capabilities.

Concrete example
openstack flavor create --ram 4096 --disk 40 --vcpus 2 m1.medium-custom
openstack flavor set --property hw:cpu_policy=dedicated m1.medium-custom
This creates a medium custom flavor and marks it for CPU dedication when supported by the host.
Misconception
Flavors are not access control labels; they determine resource allocation and scheduling, not tenancy or quota by name alone.
