Module 5 › Chapter 5.4 › Booting an Instance
Full launch command
openstack server create --image "cirros" --flavor m1.tiny --key-name my_openstack_key --security-group web-servers my-web-instance
This single command uses the pre-existing cirros image, a tiny flavor, an uploaded key, and a web security group to boot my-web-instance.
Post-launch verification
  • openstack server list to see the instance and its status.
  • openstack server show my-web-instance to inspect assigned host, addresses, and key name.
  • Assign a floating IP if you need external access and test SSH/HTTP connectivity.
Key Takeaway

A successful boot requires image, flavor, key pair, and security rules to be prepared and referenced in the server create command.

Common mistake
If SSH fails even though the instance is active and has a floating IP, check the security group rules and the key-name used at launch first.
Concrete scenario
You launch a web server but a browser shows connection refused. Confirm HTTP rule exists in the security group and that the instance firewall is not blocking the port.
