Module 5 › Chapter 5.4 › Learning Objectives
01
Manage Nova instances
Use Nova commands to boot, stop, and terminate VMs and check instance state. This ensures controlled lifecycle operations in production.
VERIFIED COMPETENCY MILESTONE
02
Flavors and key pairs
Create flavors that match CPU, RAM, and disk requirements; upload SSH public keys for secure, automated access to instances.
VERIFIED COMPETENCY MILESTONE
03
Security groups
Define stateful firewall rules to allow required ports and deny everything else. Practice least-privilege rules for production instances.
VERIFIED COMPETENCY MILESTONE
04
Manage Glance images
Upload and manage QCOW2 or RAW images, create snapshots, and enforce image lifecycle policies to avoid sprawl and security drift.
VERIFIED COMPETENCY MILESTONE

These objectives progress from knowing CLI commands to applying them in a secure, repeatable workflow and finally to mastering image hygiene and sizing decisions that affect performance and cost.
Mnemonic
Think: Image → Flavor → Key → Group. That order reflects preparing a boot template, sizing the VM, provisioning secure access, and opening necessary network paths.
