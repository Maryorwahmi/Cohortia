Module 5 › Chapter 5.1 › Glance
Image Repository
Store, catalog, and serve virtual disk images used to boot instances.
Image lifecycle
Upload, set metadata and visibility, version images, and retire old templates as needed.
Performance considerations
Backends and caching affect image fetch times during instance boot storms; plan placement accordingly.
Key Takeaway

Treat Glance as a catalog of templates and validate image visibility and fetch performance as part of deployment tests.

Concrete Example
Upload an image, mark it public for a test project, then boot multiple instances to measure startup times and backend load. Use this to tune cache or backend placement.
# glance image-create --name "centos-golden" --file centos.qcow2 --disk-format qcow2 --container-format bare
# openstack image list
