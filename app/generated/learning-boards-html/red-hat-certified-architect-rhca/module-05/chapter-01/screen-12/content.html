TripleO Deployment Model
Use an undercloud to deploy and manage the production overcloud, enabling automation and repeatable lifecycle operations.
Undercloud purpose
A management OpenStack instance used to image, provision and configure the production environment.
Overcloud outcome
The production cloud—controller, compute and storage nodes—managed by the undercloud for ongoing operations.
Misconception
TripleO is not a one-time installer. It remains as a management plane you operate for upgrades and lifecycle tasks.
Key Takeaway

Treat the undercloud as an operational component; secure and scale it appropriately since it manages lifecycle tasks for the production cloud.

Practical note
Ensure the undercloud has network access to provision PXE, and to any storage backends like Ceph that are required during overcloud configuration.
