Module 5 › Chapter 5.1 › Learning Objectives
Practical Outcomes
Verify endpoints, map services to nodes, and design resilient deployments.
Endpoint inspection
Use the OpenStack client to list services and endpoints and confirm public/internal/admin URLs are reachable.
Storage reasoning
Determine when Ceph provides better unified storage for block and object versus standalone Swift/Cinder backends.
Control plane resilience
Plan active-active or distributed control plane components to remove single points of failure.
Competency Milestones
  • List and describe each core service and its shoulder responsibilities.
  • Trace message-queue flows for a VM lifecycle operation.
  • Draft an overcloud node plan with Ceph-backed storage highlighted.
These milestones map directly to lab checks such as listing endpoints and verifying service types with the OpenStack client.
