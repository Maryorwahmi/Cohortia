Module 5 › Chapter 5.1 › Horizon
Horizon Dashboard
A UI client for interacting with OpenStack APIs and resources.
Use cases
Quick inspection of projects, launching single instances, and visual confirmation of resources.
Limitations
Not designed for large-scale automation or repeatable day-two operations; prefer Ansible and API-based workflows for those tasks.
Key Takeaway

Treat Horizon as an administrative client for inspection and demonstration; codify production tasks in automation for repeatability.

Practical check
Open Horizon, confirm you can list instances and networks, then repeat the same checks using the OpenStack client to verify parity and catalog accuracy.
