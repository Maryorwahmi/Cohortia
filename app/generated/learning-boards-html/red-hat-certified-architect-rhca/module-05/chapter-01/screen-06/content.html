Keystone Responsibilities
Authentication, identity, service catalog, and role mapping.
Tokens and sessions
Keystone issues short-lived tokens used by APIs to authorize requests and determine scoped access.
Service catalog
A central index of service endpoints. Accurate catalog entries ensure clients and services reach the intended API URLs.
Misconception
Treating Keystone as optional. Without Keystone, service authentication and catalog lookups fail and APIs become inaccessible.
Key Takeaway

Design Keystone with redundancy and reliable DB replication; verify token issuance and catalog entries during deployment validation.

Concrete Test
Request a token using the OpenStack client, then list services. If both succeed, Keystone authentication and catalog discovery are functional.
