Keystone
Identity, tokens and service catalog; prerequisite for API access.
Nova
Compute orchestration: scheduling, provisioning and lifecycle management.
Storage (Cinder/Swift/Ceph)
Block and object storage choices affect performance, durability and operations.
Summary
Keystone enables secure access, Nova runs compute, and storage architecture defines how data behaves and recovers. Verify endpoints to validate your control plane quickly.
