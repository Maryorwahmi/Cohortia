Module 5 › Chapter 5.1 › Nova
Compute Lifecycle
Scheduling, provisioning, and coordinating resources for instances.
Scheduler & placement
Evaluates resource availability and policies to choose hosts for instances.
Workers and hypervisors
Compute services on hypervisors execute the actual VM operations as directed by Nova control plane messages.
Integration note
Nova works with Glance for images, Neutron for networking, and Cinder for block attachments; orchestration requires all three to be reachable and correct.
Key Takeaway

Ensure Nova services are distributed and that supporting services—image, network, storage—are reliable to avoid failed instance operations.

Concrete scenario
A VM fails to boot because Glance is unreachable. Nova requests the image, receives an error, and the instance transitions to an error state. Fixing image availability restores provisioning flow.
