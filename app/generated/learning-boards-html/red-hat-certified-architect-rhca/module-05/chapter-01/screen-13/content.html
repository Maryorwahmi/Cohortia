Module 5 › Chapter 5.1 › HA & Scalability
Patterns for Resilience
Distribute control-plane roles, scale compute via pools, and design storage for failure tolerance.
Control plane replication
Run multiple API and scheduler nodes and cluster your message queue and database for failover and capacity.
Compute scaling
Add hypervisors into cells or pools instead of overloading a small set of hosts to increase capacity safely.
Storage durability
Use replication or erasure coding with Ceph and plan capacity for rebalancing during OSD failures.
Key Takeaway

Plan redundancy, test failover, and automate operations to keep the cloud available and maintainable at scale.
