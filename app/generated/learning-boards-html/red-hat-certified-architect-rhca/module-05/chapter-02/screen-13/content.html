Module 5 › Chapter 5.2 › Validation & Mistakes
Top mistakes
  • Not reserving control plane resources.
  • Sizing storage only for capacity, ignoring IOPS and network impact.
  • Using a single NIC for Ceph and tenant traffic under heavy load.
  • Exposing management APIs to tenant networks.
Validation checklist
  1. Deploy a pilot with representative VM classes.
  2. Run I/O benchmarks against Ceph-backed volumes.
  3. Simulate node failures and observe recovery behavior.
  4. Measure API latency and scheduler responsiveness under load.
Key Takeaway
Validation reveals hidden scale and performance issues so you can tune design choices before production rollout.
