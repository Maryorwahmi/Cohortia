Module 5 › Chapter 5.2 › Security Zones
Zone examples
  • Management zone — controllers, admin APIs, and orchestration services. Highly restricted.
  • Storage zone — Ceph public/cluster networks isolated from tenant traffic.
  • Tenant zones — isolated overlays or VLANs with security groups for workload-level controls.
Integrate Keystone with centralized identity to enforce role-based access and record which users and services may interact with control plane endpoints. Document and map these zone rules as part of your design artifacts.
Concrete policy example
Allow API access only from operator subnets; allow Ceph replication only on the cluster network; restrict tenant-to-management traffic via firewall rules at the leaf switches.
Common mistake
Exposing management APIs to tenant networks for convenience during deployment. This weakens your security posture and should be avoided.
