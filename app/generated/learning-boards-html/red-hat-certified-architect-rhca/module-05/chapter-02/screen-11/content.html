Module 5 › Chapter 5.2 › Network Topology
Topology checklist
  • Define external (provider) network CIDR and allocation pools.
  • Define tenant subnet CIDRs and gateways.
  • Map provider network to a physical interface for external connectivity.
  • Specify a Neutron router to connect tenant networks to the external network.
Example ranges: External 172.16.1.0/24 with gateway .1 and allocation pool .100-.200; Tenant 192.168.10.0/24 with gateway .1 and allocation pool .10-.254.
Concrete example
A VM in the tenant network requests a floating IP from the allocation pool; the Neutron router performs SNAT for outbound connections or routes traffic to the provider network depending on configuration. Verify that firewall rules and security groups allow intended flows.
Why this matters
A clear topology prevents ambiguous interface mappings and ensures consistent deployment via TripleO environment parameters.
