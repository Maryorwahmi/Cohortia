Module 5 › Chapter 5.2 › Traffic Segregation
Traffic roles
  • Management — orchestration, provisioning and node control.
  • API — service endpoints like Keystone, Nova, Neutron APIs.
  • Storage — Ceph public and cluster replication traffic.
  • Tenant data — VM east-west and north-south traffic.
Map each role to dedicated NICs or VLANs and set MTU for overlays. If tenant overlays are used, ensure the underlay provides sufficient MTU headroom.
Scenario
For a mid-size cloud, provide at least two 10GbE NICs: one for tenant and provider networks, another dedicated for Ceph replication and management. Validate with concurrent load tests to ensure no cross-traffic interference.
Common misconception
Assuming VLAN tagging on one NIC is equivalent to separate physical paths under all loads. It may be acceptable in small deployments but not under heavy Ceph or migration traffic.
