Process Flow › Lab Activity
Activity Steps
  1. Create project named data-science-project.
  2. Create users ds-admin and ds-member with secure passwords.
  3. Assign admin role to ds-admin and member to ds-member within the project.
  4. Verify assignments with role list commands and scoped operations.
Starter Commands
openstack project create data-science-project
openstack user create --password ds_admin_pass ds-admin
openstack user create --password ds_member_pass ds-member
openstack role add --user ds-admin --project data-science-project admin
openstack role add --user ds-member --project data-science-project member

# Verify
openstack role list --user ds-admin --project data-science-project
openstack role list --user ds-member --project data-science-project
Reminder: run these commands in a lab environment and store credentials securely.
