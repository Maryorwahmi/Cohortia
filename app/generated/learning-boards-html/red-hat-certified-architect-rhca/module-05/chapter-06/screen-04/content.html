Core Concept › Keystone Model
Definitions
User: an account for a person or service, used to authenticate and receive tokens.
Project: a container for resources, providing isolation and quotas between tenants.
Role: a set of permissions granted to a user within a project; scope matters.
Analogy
Think of projects as separate offices, users as employees, and roles as job titles that permit specific actions in that office only.
Concrete Example
# Create project
openstack project create data-science-project

# Create users
openstack user create --password ds_admin_pass ds-admin
openstack user create --password ds_member_pass ds-member

# Assign roles
openstack role add --user ds-admin --project data-science-project admin
openstack role add --user ds-member --project data-science-project member
Key Takeaway

Assign roles at the correct project scope and verify with role listing to avoid privilege leaks.
