Process Flow › CLI Sequence
Step-by-step
  1. Create the project to hold resources and quotas.
  2. Create user accounts with secure passwords or service credentials.
  3. Assign roles within the project scope, not globally unless needed.
  4. Verify assignments using role list commands and a scoped login.
Common mistake: forgetting to verify or granting admin at global scope.
Terminal Example
# Create a project
openstack project create data-science-project

# Create users
openstack user create --password ds_admin_pass ds-admin
openstack user create --password ds_member_pass ds-member

# Assign roles
openstack role add --user ds-admin --project data-science-project admin
openstack role add --user ds-member --project data-science-project member

# Verify roles
openstack role list --user ds-admin --project data-science-project
openstack role list --user ds-member --project data-science-project
Pro Tip

Run verification commands immediately after role changes and document the expected capabilities for each role.
