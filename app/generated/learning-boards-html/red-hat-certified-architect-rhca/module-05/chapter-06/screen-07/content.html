Process Flow › TLS & Testing
Checklist
  • Obtain IdP CA certificate and install or reference it in Keystone trust settings.
  • Choose ldaps or STARTTLS according to IdP capability.
  • Confirm bind DN has read access to user and group DNs.
  • Test with LDAP client before adding mappings in Keystone.
Misconception: permission errors often originate from failed TLS handshakes; check cert validation first.
Verification Commands
# Example: test TLS with openssl
openssl s_client -connect ldap.example.com:636 -showcerts

# Use an LDAP client to run a search and validate user DN and attributes
ldapsearch -H ldaps://ldap.example.com -D 'cn=binduser,dc=example,dc=com' -W -b 'ou=users,dc=example,dc=com' '(uid=alice)'

# Then test Keystone mapping with a known user after configuring backend
