Comparison › Customization Trade-offs
Usability
Simplify workflows, add internal links, and reduce cognitive load for regular users.
Security
Hide admin panels for non-admins but enforce access in Keystone; UI hiding is not a security control.
Maintainability
Prefer small template overrides and document changes to ease future upgrades and patching.
Key Takeaway

Balance usability with security and plan for maintenance. Enforce permissions in Keystone, not just in the UI.
