How Horizon Uses Identity
Horizon reads the user token issued by Keystone and shows UI elements according to role and scope.
Admin roles unlock system-level panels; project roles unlock project-specific actions.
Custom panels and links can be added by creating or overriding Django templates and theme assets.
Example Customization
Place theme files and update local settings to point to your theme directory. Modify headers or panels to reflect organizational needs.
# conceptual files to modify
/etc/openstack-dashboard/local_settings.py
/usr/share/openstack-dashboard/openstack_dashboard/themes/mytheme/static/mytheme/css/branding.css
/usr/share/openstack-dashboard/openstack_dashboard/templates/_header.html
Check Your Understanding

After a theme change, verify both admin and non-admin views to ensure essential functionality remains visible.
