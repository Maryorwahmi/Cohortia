Key Concepts

Advanced features and integration points

Block Storage

Storage presented as raw block devices, suitable for databases and virtual machines requiring high performance.

File Storage

Storage presented as a shared file system (e.g., NFS, SMB, CephFS, GlusterFS), offering POSIX compliance.

Erasure Coding

A data protection method in Ceph offering high durability and storage efficiency by encoding data across devices.

CRUSH Map

Ceph's algorithm for intelligent data placement and fault domain awareness, optimizing data locality and resilience.

OpenShift Data Foundation (ODF)

An OpenShift-native storage solution built on Ceph, providing persistent storage for containers managed via Kubernetes APIs.

StorageClass

A Kubernetes/OpenShift resource that defines the 'class' of storage to be provisioned, abstracting underlying storage details.

These advanced concepts are fundamental for designing and implementing highly resilient, scalable, and efficient data management solutions in complex enterprise environments.
