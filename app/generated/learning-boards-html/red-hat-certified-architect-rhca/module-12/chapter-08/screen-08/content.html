Efficient Data Durability with Erasure Coding

Optimizing Storage Efficiency Beyond Replication

Erasure Coding fragments and encodes data across multiple devices, offering higher storage efficiency than replication while maintaining data durability.

Key Takeaway

Erasure Coding is a cost-effective data protection method for large datasets and archival storage, providing durability with less storage overhead than traditional replication.

Common Misconception

Erasure Coding is not always a direct replacement for replication. It typically has higher computational overhead, making it less suitable for high-performance, low-latency workloads.

How Erasure Coding Works

1. Data Fragmentation

Original data is split into 'K' data chunks.

2. Parity Generation

'M' parity (coding) chunks are generated from the data chunks.

3. Distributed Storage

All K+M chunks are distributed across different OSDs.

Fault Tolerance

Data can be fully reconstructed even if 'M' chunks (and their corresponding OSDs) are lost, providing high durability.
