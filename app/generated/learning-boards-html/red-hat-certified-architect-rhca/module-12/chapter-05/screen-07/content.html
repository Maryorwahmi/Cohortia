RHEL Tuning

Automated Tuning with `tuned`

Optimizing system parameters with predefined profiles

What is `tuned`?

A Red Hat service that automatically adjusts system parameters based on predefined profiles, optimizing for specific workloads.

  • Applies kernel parameters, `sysctl` settings, etc.
  • Offers profiles like `throughput-performance` and `latency-performance`.
  • Can create custom profiles for unique needs.
Benefit: Provides a tested, validated approach to system optimization without deep manual intervention.
Common Mistake

Manually tweaking settings that `tuned` could manage, leading to conflicts or suboptimal configurations.

`tuned-adm` Commands

# List all available tuned profiles
sudo tuned-adm list

# Show the currently active profile
sudo tuned-adm active

# Activate the throughput-performance profile
sudo tuned-adm profile throughput-performance

# Verify the change (should now show throughput-performance)
sudo tuned-adm active
These commands allow you to manage and verify `tuned` profiles on your RHEL system.
Key Takeaway

`tuned` simplifies RHEL optimization by applying predefined profiles. Always use `tuned-adm` to manage and verify your active profile.
