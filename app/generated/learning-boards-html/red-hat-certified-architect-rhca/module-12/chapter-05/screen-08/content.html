Advanced RHEL Tuning

Manual Tuning Techniques

Fine-tuning beyond `tuned` profiles for specific needs

When to Tune Manually

For highly specific performance goals or unique bottlenecks not covered by `tuned` profiles.

  • Adjusting kernel parameters via `sysctl`.
  • Optimizing file system mount options.
  • Configuring Network Interface Card (NIC) settings.
Benefit: Granular control over system behavior for specialized workloads.
Safety Note

Aggressive manual tuning can lead to instability. Always back up configurations and test thoroughly.

Example: Open File Limits

# Edit /etc/security/limits.conf
# Add these lines to increase open file limits for all users
# The '*' wildcard applies to all users
* soft nofile 65536
* hard nofile 65536

# 'soft' is the current limit, 'hard' is the maximum limit
# A common adjustment for high-concurrency applications
# Requires user logout/login or service restart to apply
Increasing `nofile` limits prevents applications from running out of file descriptors under heavy load.
Key Takeaway

Manual tuning offers fine-grained control but demands careful, measured changes with thorough testing and configuration backups to ensure stability.
