Red Hat Ceph Storage for unified persistence
Choose Ceph for scalable block, file, and object storage across OpenShift, OpenStack, and traditional workloads.
  • Provides RBD block devices for OpenShift persistent volumes.
  • Supports object storage for backups and external ingestion.
  • Plan encryption and replication policies during design.
Concrete usage
An OpenShift cluster consumes Ceph RBD volumes for stateful services while an on-prem OpenStack environment uses Ceph for VM disks, all managed under unified storage policies for replication and encryption.
Misconception
Choosing storage only by price leads to misaligned performance and durability characteristics.
Pro tip
Define IO and durability SLAs up front, then design Ceph pools and replication to match them.
