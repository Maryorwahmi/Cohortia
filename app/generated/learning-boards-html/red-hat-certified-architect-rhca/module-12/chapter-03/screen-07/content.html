SELinux: Mandatory Access Control

Enforcing Fine-Grained Permissions at the OS Level

Mandatory Access Control (MAC)

Enforces system-wide security policies, overriding traditional discretionary access controls (DAC) and user permissions.

Principle of Least Privilege

Processes are granted only the minimum permissions necessary to perform their function, even if running as root.

Example: Apache Database Access

To allow Apache to connect to a remote database, you might need to enable an SELinux boolean: sudo setsebool -P httpd_can_network_connect_db on.

Key Takeaway

SELinux provides a robust Mandatory Access Control (MAC) system, ensuring processes only have the exact permissions needed, even for root, significantly hardening RHEL systems.

# SELinux Contexts and Booleans
# Check current SELinux status
sestatus

# List all SELinux booleans related to httpd
getsebool -a | grep httpd

# Enable Apache to connect to a remote database
sudo setsebool -P httpd_can_network_connect_db on

# Verify the boolean is enabled
getsebool httpd_can_network_connect_db
# Understanding SELinux Contexts
  • Every file, process, and port has an SELinux context.
  • Contexts define the type and role of an object.
  • SELinux policies define rules for how contexts can interact.
