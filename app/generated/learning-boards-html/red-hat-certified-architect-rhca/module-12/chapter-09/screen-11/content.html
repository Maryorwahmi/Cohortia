Ansible Playbook for Auditd Configuration

Ensuring robust auditing for compliance standards like PCI DSS

Ansible Playbook Task (Simplified)

# Example: Ansible playbook task to ensure auditd is configured for PCI DSS
- name: Ensure auditd service is running and enabled
  systemd:
    name: auditd
    state: started
    enabled: yes

- name: Copy auditd rules for PCI DSS compliance
  copy:
    src: pci-audit.rules
    dest: /etc/audit/rules.d/pci-audit.rules
    mode: '0640'
  notify: Restart auditd

Task 1: Ensure Auditd Service

  • Uses systemd module.
  • Ensures auditd is started and enabled.
  • Guarantees continuous system monitoring.

Task 2: Deploy Auditd Rules

  • Uses copy module to deploy pci-audit.rules.
  • Sets file permissions to 0640 for security.
  • notify: Restart auditd ensures rules are applied efficiently.
Key Takeaway

Ansible automates the configuration of auditd, ensuring that critical audit trails are consistently maintained across systems for compliance.
