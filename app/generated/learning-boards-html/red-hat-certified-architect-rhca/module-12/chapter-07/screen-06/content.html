Cloud Bursting for Peak Loads

Dynamically Extending Capacity to the Public Cloud

How Cloud Bursting Works
STEP 1

On-Premise Base Load

Handle normal traffic with existing infrastructure.

STEP 2

Peak Load Detected

Traffic exceeds on-premise capacity.

STEP 3

Burst to Public Cloud

Scale applications to public cloud resources.

Example Scenario

An e-commerce site experiences a 5x traffic surge during a holiday sale. Instead of buying more servers, it bursts its web application to an OpenShift cluster on AWS, handling the extra load seamlessly.

Key Takeaway

Cloud bursting optimizes resource use and cost by leveraging public cloud elasticity for temporary peak loads, enabled by OpenShift's consistent platform.
