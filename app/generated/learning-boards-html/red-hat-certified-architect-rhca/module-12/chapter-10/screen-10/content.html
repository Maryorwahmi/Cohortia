Types of Red Hat Architectural Diagrams

Visualizing solutions from conceptual to physical deployment

High-level Conceptual Diagrams

Shows how major Red Hat components (OpenShift, Ansible, Ceph) interact with external systems. Ideal for business stakeholders and initial discussions.

Example

A diagram showing OpenShift connecting to a public cloud database and an on-premise identity provider.

Logical Diagrams

Details application components, data flows, and service dependencies within OpenShift. Focuses on the software architecture and internal interactions.

Pro Tip

Use clear arrows to indicate data flow and dependencies between microservices.

Physical/Deployment Diagrams

Illustrates the placement of RHEL servers, OpenShift nodes, storage clusters, and network zones across data centers or cloud regions. Essential for operations.

Example

A diagram showing RHEL hosts in different racks, each running OpenShift nodes, connected to a Ceph storage cluster.
