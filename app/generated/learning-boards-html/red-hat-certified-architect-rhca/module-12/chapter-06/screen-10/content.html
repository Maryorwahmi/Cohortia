Ansible Broker & Operator Patterns

Extending OpenShift with Ansible Capabilities

Key Benefits

  • •Self-Service: Developers can provision resources via OpenShift Service Catalog.
  • •Kubernetes-Native: Manage application lifecycles using familiar OpenShift constructs.
  • •Automation Abstraction: Hide underlying automation complexity from end-users.
  • •Extensibility: Extend OpenShift's capabilities with custom Ansible logic.
Architectural Impact

These patterns enable a true cloud-native operational model, allowing complex automation to be managed directly within OpenShift.

Pattern Comparison

Ansible Broker

Exposes Ansible automation as services in the OpenShift Service Catalog, enabling self-service provisioning.

Ansible Operator

Uses Ansible playbooks to manage the lifecycle of Kubernetes-native applications and custom resources.
