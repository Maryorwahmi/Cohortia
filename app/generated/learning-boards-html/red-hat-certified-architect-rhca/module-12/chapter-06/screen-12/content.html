OpenSCAP Integration for Remediation

Automating Auditing and Remediation of Security Baselines

How Ansible & OpenSCAP Work Together

  • •Deploy Content: Ansible ensures SCAP Security Guide content is present.
  • •Evaluate Systems: Ansible invokes oscap to scan against profiles (e.g., CIS).
  • •Automate Remediation: Automatically corrects non-compliant settings.
Benefit for Architects

Ensures continuous compliance with security standards, reducing manual effort and audit complexities.

# Example: Ansible playbook to apply OpenSCAP remediation
---
- name: Apply OpenSCAP remediation for RHEL 8 CIS Profile
  hosts: all
  become: yes
  tasks:
    - name: Ensure SCAP Security Guide content is present
      dnf:
        name: scap-security-guide
        state: present

    - name: Apply CIS Level 1 Server profile remediation
      command: >
        oscap xccdf eval
        --profile xccdf_org.ssgproject.content_profile_cis
        --remediate
        --remediate-if-results-discrepancy
        /usr/share/xml/scap/ssg/content/ssg-rhel8-ds.xml
      args:
        warn: no # Disable warning for non-zero exit code if no remediation needed
Code Explanation

This playbook first ensures the necessary SCAP content is installed, then executes the oscap command to evaluate and remediate systems against the RHEL 8 CIS profile. The warn: no argument prevents the playbook from failing if no remediation is needed, making it robust.
