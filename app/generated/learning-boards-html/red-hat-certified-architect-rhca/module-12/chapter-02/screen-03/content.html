Practical tasks

Hands-on milestones

Two-node Pacemaker cluster
Install packages, authorize hosts, create cluster, create virtual IP and service resources, and test failover.
OpenShift replicas
Deploy a three‑replica application and observe automatic rescheduling when a worker fails.
Failover under load
Simulate traffic while failing an active node to ensure the cluster handles the transition.
Automation & management
Use Ansible playbooks or Satellite to manage packages and configurations across nodes.
Verification
What proves competency?
  • Working virtual IP that moves with service failover.
  • OpenShift deployment maintaining desired replicas after node failure.
  • Documented failover test showing acceptable response times.
