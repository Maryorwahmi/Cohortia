Module 12 › Chapter 12.2 › Lab: Two-node Pacemaker Cluster
Starter commands
# On both nodes:
sudo dnf install -y pacemaker corosync pcs resource-agents httpd
sudo systemctl enable --now pcsd
sudo passwd hacluster # set the cluster user password

# On node1 only (create and start cluster):
sudo pcs host auth node1.example.com node2.example.com -u hacluster -p 
sudo pcs cluster setup my_web_cluster node1.example.com node2.example.com
sudo pcs cluster start --all
sudo pcs property set stonith-enabled=false
sudo pcs property set no-quorum-policy=ignore

# Create resources (example shown earlier):
sudo pcs resource create VirtualIP ocf:heartbeat:IPaddr2 ip=192.168.1.100 cidr_netmask=24 op monitor interval=10s
sudo pcs resource create WebService systemd:httpd op monitor interval=20s
sudo pcs constraint colocation add WebService with VirtualIP INFINITY
sudo pcs constraint order VirtualIP then WebService
Verification steps
  • Run pcs status to confirm resources are running.
  • Stop httpd on the active node and observe resource relocation.
  • Reboot the active node and confirm the virtual IP and web page return on the other node.
Lab tips
Record failover times and any monitor errors. If failover is slow, reduce monitor intervals carefully and consider the impact on flapping detection.
Safety note
Disabling fencing and quorum settings is acceptable for labs but not production; document these changes and re-enable production protections when moving to real environments.
