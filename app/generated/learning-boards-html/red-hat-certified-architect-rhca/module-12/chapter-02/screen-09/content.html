Deployment with replicas

Declare the desired replica count so OpenShift keeps that many pods running and reschedules them if nodes fail.

apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-webapp
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-webapp
  template:
    metadata:
      labels:
        app: my-webapp
    spec:
      containers:
      - name: webapp
        image: myregistry/my-webapp:latest
        ports:
        - containerPort: 8080
Pro tip
Add readiness and liveness probes so the platform knows when to replace unhealthy pods.
Misconception
More replicas do not fix shared storage contention or database write conflicts without application changes.
Operational checks
  • Use anti-affinity to spread replicas across nodes.
  • Test node drain to confirm pods reschedule without service disruption.
  • Verify persistent volume access modes for multi-writer scenarios.
