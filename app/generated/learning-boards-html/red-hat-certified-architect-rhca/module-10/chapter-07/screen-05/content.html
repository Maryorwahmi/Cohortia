Monitoring Stack

OpenShift Monitoring with Prometheus

Prometheus collects metrics from applications and cluster components.

How Prometheus Works

  • •**Scraping:** Prometheus pulls metrics from configured HTTP endpoints.
  • •**Time-Series Database:** Stores metrics with timestamps for historical analysis.
  • •**Automatic Discovery:** OpenShift configures Prometheus to monitor core components.
  • •**Application Metrics:** Applications must expose metrics in Prometheus format (e.g., `/metrics`).
Example: Metrics Endpoint

A web application exposes `/metrics` with data like `http_requests_total{method="GET", path="/"} 1234`.

Prometheus in OpenShift

OpenShift integrates Prometheus to automatically monitor cluster components and allows for custom application metric collection.

Key Takeaway

Prometheus is the backbone of metric collection in OpenShift, providing raw data for performance analysis.
