Logging Stack

OpenShift Logging with the EFK Stack

Centralized log aggregation and analysis using Elasticsearch, Fluentd, and Kibana.

Fluentd

Collects logs from containers and nodes, then forwards them.

Elasticsearch

Stores and indexes logs, making them searchable and queryable.

Kibana

Provides a web interface for log visualization, querying, and analysis.

Why it matters

Centralized logging simplifies debugging, security auditing, and understanding application behavior across distributed systems.

Key Takeaway

The EFK stack is OpenShift's integrated solution for collecting, storing, and analyzing all your cluster and application logs.
