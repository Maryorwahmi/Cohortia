Essential Istio Terminology

Foundational Concepts for Service Mesh Mastery

Service Mesh

A dedicated infrastructure layer for handling service-to-service communication, providing traffic management, security, and observability.

Istio

An open-source service mesh that extends Kubernetes to connect, secure, control, and observe microservices.

Envoy Proxy

A high-performance proxy acting as Istio's data plane, deployed as a sidecar to intercept and manage network traffic.

Control Plane

The set of Istio components (Pilot, Citadel, Galley) that configure and manage the Envoy proxies.

Data Plane

The collection of Envoy proxies deployed as sidecars alongside application pods, handling actual network traffic.

Chapter Summary

A service mesh like Istio provides a critical infrastructure layer for managing microservices, abstracting network concerns through its data plane (Envoy proxies) and control plane (Pilot, Citadel, Galley).
