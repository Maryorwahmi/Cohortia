Module 10 › Chapter 10.5 › Practice Plan
Practice checklist
  • ● Create project and deploy v1 and v2 with labels to distinguish versions.
  • ● Expose each version with a Service that selects by version label.
  • ● Create a Route with alternateBackends and initial weights for canary testing.
  • ● Use curl loops to sample responses and validate weight changes.
  • ● Practice rollback using rollout undo and inspect history before switching traffic.
Safety notes
Limit canary traffic, validate observability and alerts, and separate schema changes from code rollouts to avoid irreversible data issues.
Key Takeaway

Practice incremental rollouts and rollback rehearsals so you can react quickly when production surprises occur.
