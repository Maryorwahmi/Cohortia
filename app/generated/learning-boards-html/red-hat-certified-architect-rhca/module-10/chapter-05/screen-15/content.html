Module 10 › Chapter 10.5 › OpenShift Primitives
Rollback
Use rollout undo to revert to a prior revision; remember this redeploys code but does not revert data.
DeploymentConfig (DC)
OpenShift-specific object with image-change triggers and deployment hooks useful for integrated workflows.
Service & Route
Service selects pods for internal traffic; Route exposes services externally and supports weighted alternate backends for canaries.
Bottom line
Use these primitives together: Services and Routes for traffic control, DeploymentConfig/Deployment for pod lifecycle; always test rollback and plan for data migration complexity.
