Module 10 › Chapter 10.5 › Blue/Green Cutover
Cutover process
1. Prepare
Launch Green with labels app=my-app, version=green and confirm replicas are ready.
2. Validate
Run smoke tests and integration checks against Green to ensure parity.
3. Switch
Update the Service selector to point to version=green for an atomic cutover.
4. Monitor
Observe metrics and be ready to revert the selector to version=blue if problems are detected.
Example command
# Switch to green
oc patch svc my-app-service -p '{"spec":{"selector":{"app":"my-app","version":"green"}}}'
Run this only after your validation suite passes. To revert, patch the selector back to version=blue.
Checklist before switching
  • Readiness probes green and passing.
  • No incompatible schema changes deployed yet.
  • Monitoring and alerts configured for quick detection.
  • Rollback plan documented and rehearsed.
Pro tip
Label conventions make switching and auditing simpler; use consistent labels like app and version to avoid selector mistakes.
