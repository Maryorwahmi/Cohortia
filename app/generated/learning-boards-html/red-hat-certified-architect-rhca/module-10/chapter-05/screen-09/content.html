Module 10 › Chapter 10.5 › Rollbacks & History
Commands overview (examples)
# View DeploymentConfig history
oc rollout history dc/my-app

# Rollback to previous deployment
oc rollout undo dc/my-app

# Rollback to a specific revision
oc rollout undo dc/my-app --to-revision=3
Notes
  • Rollout undo restores a prior pod template and image; it does not change persisted data back in time.
  • Check deployment hooks and triggers — they can affect whether a rollback re-executes builds.
Practical checklist
  • Inspect rollout history before undoing to select the correct revision.
  • Announce or coordinate rollbacks that might impact users.
  • Verify application state and run smoke tests after rollback completes.
Misconception
Don’t assume rollback reverts the database; plan migrations to be backward compatible or have separate data rollback steps.
