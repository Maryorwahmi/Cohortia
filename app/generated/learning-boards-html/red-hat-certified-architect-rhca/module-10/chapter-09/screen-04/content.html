Git as the Single Source of Truth

GitOps treats Git as the definitive source for all system configurations, enabling automated deployments and state reconciliation.

Definition

GitOps is an operational framework that uses Git repositories as the single source of truth for defining the desired state of infrastructure and applications. All changes are made via Git pull requests, which then trigger automated reconciliation.

Declarative State

System state is described in declarative files (YAML) stored in Git, not imperative scripts.

Pull-Based Automation

Automation agents pull changes from Git and apply them, rather than being pushed to.

Key Takeaway

By centralizing all configurations in Git, GitOps provides an immutable, auditable, and automated path to managing your systems.
