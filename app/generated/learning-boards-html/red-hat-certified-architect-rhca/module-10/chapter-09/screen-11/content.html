Automatic Synchronization and Self-Healing

Argo CD continuously monitors Git and the cluster to ensure the desired state is always maintained.

Automatic Synchronization

Argo CD detects new commits in the Git repository and automatically applies those changes to the target cluster, keeping it up-to-date.

Drift Detection

Argo CD continuously monitors the live cluster state and compares it against the desired state in Git, identifying any discrepancies or manual changes.

Self-Healing

If selfHeal: true is enabled, Argo CD automatically reverts manual changes in the cluster to match the desired state defined in Git, preventing configuration drift.

Example Scenario

A developer manually scales down a deployment from 3 replicas to 1. Argo CD detects this drift and, with self-healing enabled, automatically scales it back to 3 replicas as defined in Git.

Key Takeaway

Automatic synchronization and self-healing are core to GitOps, ensuring your cluster's state is always consistent with your version-controlled desired state in Git.
