Installing Argo CD with OpenShift GitOps Operator

Leverage the OpenShift GitOps Operator for a supported and integrated deployment of Argo CD.

01

Install Operator

Navigate to OpenShift console > Operators > OperatorHub. Search for "OpenShift GitOps" and install it in the openshift-operators namespace.

02

Verify Installation

Confirm that the openshift-gitops namespace is created and Argo CD pods are running within it, indicating a successful deployment.

03

Access Argo CD UI

Find the route for argocd-server in the openshift-gitops namespace via OpenShift console > Networking > Routes, and log in.

Terminal Command Example
# Verify Argo CD pods are running
oc get pods -n openshift-gitops
Why it matters

Using the OpenShift GitOps Operator ensures a consistent, supported, and integrated way to manage your Argo CD instances, simplifying lifecycle management and upgrades.

Key Takeaway

The OpenShift GitOps Operator is the recommended method for installing Argo CD, providing a seamless and integrated experience for GitOps on OpenShift.
