The Argo CD `Application` Resource

This custom resource defines how Argo CD manages your application's desired state.

Core Definition

The Application resource is a Kubernetes Custom Resource (CRD) that tells Argo CD where to find your application's manifests in Git, where to deploy them, and how to synchronize changes.

Source Repository

Specifies the Git URL, branch/tag, and path to the application manifests.

Target Destination

Defines the Kubernetes/OpenShift cluster and namespace for deployment.

Synchronization Policies

Configures automatic sync, pruning, self-healing, and namespace creation.

Key Takeaway

The Application resource is your declarative contract with Argo CD, specifying exactly how your application should be deployed and maintained.
