Controlling Pod Capabilities

Restricting Linux capabilities and privileged container access.

Linux Capabilities

  • Granular Permissions: Break down 'root' user into smaller, distinct privileges.
  • Examples: `NET_ADMIN` (network config), `SYS_ADMIN` (system admin).
  • Default Restriction: OpenShift's `restricted` SCC disallows most dangerous capabilities.
Key Takeaway

SCCs enforce least privilege by restricting Linux capabilities and preventing privileged container access, significantly reducing the attack surface.

Privileged Access

  • Full Host Access: A privileged container has all capabilities and direct access to host devices.
  • High Risk: Extremely dangerous in production due to potential for host compromise.
  • Default Denied: The `restricted` SCC explicitly disallows privileged containers.
Common Mistake

Granting overly permissive SCCs or allowing privileged containers without strict justification and careful evaluation of risks.
