Create and monitor a PipelineRun
Provide concrete params, workspace PVCs, and optional serviceAccount.
PipelineRun example
apiVersion: tekton.dev/v1beta1
kind: PipelineRun
metadata:
  generateName: app-build-deploy-run-
spec:
  pipelineRef:
    name: app-build-deploy-pipeline
  params:
    - name: git-url
      value: https://github.com/myorg/myrepo.git
    - name: git-revision
      value: main
  workspaces:
    - name: shared-workspace
      volumeClaimTemplate:
        spec:
          accessModes: ["ReadWriteOnce"]
          resources:
            requests:
              storage: 1Gi
Monitoring tips
  • Use tkn pipelinerun describe and oc get pod -w to follow progress.
  • Inspect step logs to locate failures quickly.
  • Check ImageStream and Deployment objects after successful runs.
Common pitfalls
  • Missing ServiceAccount permissions lead to failing deploy steps.
  • Insufficient PVC size causes workspace writes to fail.
Check your run
After completion, confirm an ImageStreamTag was created and the application route is present if deployed.
