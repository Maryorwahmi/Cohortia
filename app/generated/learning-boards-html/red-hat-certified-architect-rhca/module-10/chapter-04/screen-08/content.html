Trigger components
EventListener, TriggerBinding, TriggerTemplate—how they collaborate.
EventListener: receives webhook HTTP calls and routes events to configured triggers.
TriggerBinding: maps values from the event payload into parameters.
TriggerTemplate: creates the PipelineRun manifest using extracted values.
Security note
Protect EventListener endpoints and validate webhook signatures before creating PipelineRuns to prevent unauthorized executions.
Testing and validation
  • Send a sample webhook payload to the EventListener to confirm TriggerBinding extracts the right fields.
  • Confirm that a PipelineRun appears with expected params and workspace bindings.
Key takeaway: Automate carefully and secure the listener. Triggers complete the CI/CD loop by turning external events into pipeline executions.
