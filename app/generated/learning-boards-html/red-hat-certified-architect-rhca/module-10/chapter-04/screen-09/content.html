Module 10 › Chapter 10.4 › Workspaces & Results
Workspaces: files and artifacts
PVC-backed volumes shared by Tasks within a PipelineRun.
Use a shared-workspace to move source code from git-clone to build tasks, or to store test reports and binaries across steps.
Results: metadata
Small text values written by Tasks for later consumption or reporting.
Example: the build Task writes a Result with the built image digest so the deploy Task can reference it precisely.
Practical patterns
  • Workspace for source and artifacts; Results for digests, tags, and small counts.
  • Keep PVC size adequate for build artifacts; choose ReadWriteOnce or other modes based on use.
  • Emit Results for observability and to make downstream steps deterministic.
Key takeaway: Use Workspaces for files and Results for tiny pieces of data. Both together let Pipelines pass full artifacts and precise metadata between Tasks.
