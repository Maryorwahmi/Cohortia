Process Flow

oc new-app and oc new-build

oc new-app scaffolds a build, image stream, and deployment from an image or source repo to quickly create an application.
oc new-build registers a build configuration for a Dockerfile or S2I builder and optionally connects it to a repo.
Common Pitfall
Treating scaffolded resources as production-ready without adjusting securityContext, probes, and resource limits.
Command examples
Example S2I: oc new-app --name=my-nodejs-app --image-stream=nodejs:16~https://github.com/openshift/nodejs-ex.git
Example Dockerfile build: oc new-build --name=my-custom-app --dockerfile=./Containerfile --from-dir=.
Pro Tip

After scaffolding, review and adjust the Deployment and BuildConfig for non-root users, resource requests, and image pull policies.
