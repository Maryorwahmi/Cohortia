Containerfile Best Practices
Write Containerfiles that use minimal base images, avoid embedding secrets, and pin base image versions for reproducible builds.

Multi-stage Builds
Use build stages to compile or install dependencies and copy only required artifacts into a minimal runtime stage, reducing image size and attack surface.
Mnemonic: build → copy → runtime
VERIFIED COMPETENCY MILESTONE
03
Podman Local Workflow
Build, list, tag, and push images with Podman to validate the image locally before pushing to OpenShift’s registry.
Mnemonic: build, inspect, tag, push
VERIFIED COMPETENCY MILESTONE
04
OpenShift Build Strategies
Understand when to use Source-to-Image for quick source-driven builds and when Dockerfile builds are required for full control and multi-stage workflows.
Mnemonic: S2I = fast; Dockerfile = controlled
