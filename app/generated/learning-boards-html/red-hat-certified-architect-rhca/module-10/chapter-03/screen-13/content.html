Hands-on Activity

Build, push, deploy — Node.js

# Build locally
podman build -t my-nodejs-app:latest .

# Verify local run
podman run --rm -p 8080:8080 my-nodejs-app:latest

# Tag and push to OpenShift internal registry
REGISTRY_HOST=$(oc get route default-route -n openshift-image-registry --template='{{ .spec.host }}')
podman login -u $(oc whoami) -p $(oc whoami -t) $REGISTRY_HOST --tls-verify=false
podman tag my-nodejs-app:latest $REGISTRY_HOST/my-nodejs-project/my-nodejs-app:latest
podman push $REGISTRY_HOST/my-nodejs-project/my-nodejs-app:latest --tls-verify=false

# Apply deployment and expose
oc apply -f deployment.yaml
oc expose deployment my-nodejs-app --port=8080
oc expose service my-nodejs-app
oc get route my-nodejs-app
Validation Steps
  • Confirm the image serves the expected HTTP response.
  • Run a vulnerability scan and address high-priority findings.
  • Verify the deployed route returns the expected output.
Pro Tip

Add an automated image scan after your build step in CI and require a success gate before pushing to the registry.
