Module 10 › Chapter 10.3 › Key Concepts
Podman
Daemonless container engine for building and managing images locally compatible with Docker commands.
Containerfile
The recipe for assembling an image; use minimal instructions and pin base image versions for reproducibility.
Multi-stage Builds
Separate build and runtime stages to reduce final image size and remove build tools from production images.
Takeaway
Combine Podman, multi-stage Containerfiles, and UBI bases, and always scan and run as non-root before deploying to OpenShift.
