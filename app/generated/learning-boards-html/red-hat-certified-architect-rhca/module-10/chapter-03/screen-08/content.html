Node.js multi-stage Containerfile

# Stage 1: Build dependencies
FROM registry.access.redhat.com/ubi8/nodejs-16 AS builder
WORKDIR /app
COPY package*.json ./
RUN npm install --production

# Stage 2: Create the final runtime image
FROM registry.access.redhat.com/ubi8/nodejs-16-minimal
WORKDIR /app
COPY --from=builder /app/node_modules ./node_modules
COPY server.js .
EXPOSE 8080
USER 1001
CMD ["node", "server.js"]
Walkthrough Notes
  • Builder stage runs npm install to collect dependencies.
  • Runtime stage copies only node_modules and the server script.
  • Set a non-root USER to reduce privileges at runtime.
Scenario
After you build, run the image locally and confirm the web response before tagging for OpenShift.
Key Takeaway

Use the builder to prepare dependencies and the minimal runtime to deliver a small production image.
