Definition

Containerfile fundamentals

Key instructions: FROM, WORKDIR, COPY, RUN, USER, CMD. Keep the file minimal and pin base images for reproducible builds.

Best Practices
  • Start from a minimal UBI base and pin the tag.
  • Use multi-stage builds to avoid including build tools in runtime.
  • Use USER to avoid running as root in production.
  • Avoid embedding secrets; use OpenShift Secrets at runtime.
Key Takeaway

Your Containerfile should produce a minimal runtime image and make the build reproducible and auditable.

Example snippet
# Example: minimal Node.js runtime stage
FROM registry.access.redhat.com/ubi8/nodejs-16-minimal
WORKDIR /app
COPY --from=builder /app/node_modules ./node_modules
COPY server.js .
EXPOSE 8080
USER 1001
CMD ["node", "server.js"]
Common Mistake
Copying the entire build directory instead of only runtime artifacts, leading to larger images.
Pro Tip
Pin your base image tag to ensure predictable builds across environments.
