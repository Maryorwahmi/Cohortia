Process Flow

Multi-stage builds

Build in one stage, copy runtime artifacts into a second stage and leave build tools behind.

Stage 1
Compile or install dependencies
Stage 2
Copy artifacts into runtime
Result
Smaller runtime image
Common Mistake
Copying build directories instead of final artifacts keeps unnecessary layers and tools in the image.
Example (Java multi-stage)
# Stage 1: Build the application
FROM registry.access.redhat.com/ubi8/openjdk-11 AS builder
WORKDIR /app
COPY pom.xml .
COPY src ./src
RUN mvn clean package -DskipTests

# Stage 2: Create the final runtime image
FROM registry.access.redhat.com/ubi8/openjdk-11-runtime
WORKDIR /app
COPY --from=builder /app/target/*.jar app.jar
CMD ["java", "-jar", "app.jar"]
