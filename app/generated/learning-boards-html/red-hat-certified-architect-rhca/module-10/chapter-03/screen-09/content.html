Process Flow

Build, tag, push

# Build locally
podman build -t my-nodejs-app:latest .
podman images my-nodejs-app

# Get registry host and login
REGISTRY_HOST=$(oc get route default-route -n openshift-image-registry --template='{{ .spec.host }}')
podman login -u $(oc whoami) -p $(oc whoami -t) $REGISTRY_HOST --tls-verify=false

# Tag and push
podman tag my-nodejs-app:latest $REGISTRY_HOST/my-nodejs-project/my-nodejs-app:latest
podman push $REGISTRY_HOST/my-nodejs-project/my-nodejs-app:latest --tls-verify=false
Checklist
  • Confirm project exists in OpenShift.
  • Verify token validity before login.
  • Check pushed image appears in project registry.
Common Pitfalls
  • Using an incorrect registry host or missing project namespace in tag.
  • Expired tokens or insufficient push permissions.
  • Pushing an unverified image; always test locally first.
Key Takeaway

Authenticate, tag with the project path, and verify the pushed image exists in the target project before deploying.
