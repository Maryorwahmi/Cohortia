Definition

Image security and scanning

Run vulnerability scans and enforce runtime best practices to reduce attack surface and satisfy enterprise compliance.

Practices
  • Scan images with Clair or OpenSCAP or integrated OpenShift tools.
  • Run containers as a non-root user via USER in Containerfile.
  • Do not store credentials in images; use OpenShift Secrets.
Workflow checks
Scan after build: detect known CVEs before push.
Remediate by updating base images or libraries, then rebuild and rescanning.
Common Mistake
Relying only on runtime policies instead of fixing vulnerable packages inside the image itself.
