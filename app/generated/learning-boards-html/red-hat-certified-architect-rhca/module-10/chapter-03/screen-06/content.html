Definition

Red Hat Universal Base Image (UBI)

UBI are supported, redistributable base images optimized for enterprise use and compatibility with OpenShift.

Why UBI?
  • Redistributable and supported by Red Hat.
  • Designed for enterprise compatibility and reproducibility.
  • Use pinned tags to avoid unexpected changes.
Example pinning
# Pinning a UBI OpenJDK base image for reproducible builds
FROM registry.access.redhat.com/ubi8/openjdk-11:1.16

# Later stages can reference this pinned base to avoid surprise changes
FROM registry.access.redhat.com/ubi8/openjdk-11-runtime:1.16
Pro Tip
Integrate your image build with a vulnerability scanner to verify the pinned base’s known CVEs before deployment.
