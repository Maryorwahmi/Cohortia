Module 10 › Chapter 10.1 › Config & Build/Release/Run
Three-stage flow
Build
Create an immutable image and store it in a registry.
Release
Bind an image to environment-specific configuration to form a release.
Run
Start processes from the release; the platform ensures the desired state is maintained.
Practical example

CI builds image once; push to OpenShift registry; create a Deployment that references the image and inject environment variables or secrets for the target environment. When you update the image tag, the platform reconciles the deployment.

Common mistake
Rebuilding per environment hides whether a change came from code or config and makes rollbacks unreliable.
Key Takeaway

Keep build artifacts immutable and promote them through environments with environment-specific config applied at release time.
