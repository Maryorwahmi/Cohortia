Module 10 › Chapter 10.1 › OpenShift Components
Control plane
  • API server — accepts declarative resource definitions and serves the control API.
  • Scheduler — places pods on nodes using constraints like labels and taints.
  • Controller Manager — reconciles desired state, creating and adjusting resources.
  • etcd — stores cluster state reliably and must be sized for scale.
Developer & platform services
  • Internal registry — stores container images produced by builds.
  • Router — handles ingress and exposes services externally.
  • Source-to-image — streamlines building images from source.
  • OpenShift Pipelines (Tekton) — integrated CI/CD for build, test, and deploy.
  • Security features — SCCs and integrated identity management control access and privileges.
Architect note
Map requirements to components: availability concerns map to control plane sizing; deployment speed maps to pipeline design; security needs map to SCCs and network policies.
