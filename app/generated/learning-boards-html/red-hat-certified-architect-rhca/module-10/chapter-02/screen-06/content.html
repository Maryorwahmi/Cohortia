Module 10 › Chapter 10.2 › Communication Comparison
Synchronous

HTTP / gRPC

  • Immediate request and response with predictable latency.
  • Requires downstream availability; risk of cascading failures.
  • Easy to reason about but can tightly couple services.
OpenShift note
Use Service objects for stable DNS endpoints like product-catalog.my-app.svc.cluster.local.
Asynchronous

Message Queues / Event Streams

  • Decouples producers and consumers for better resilience.
  • Supports eventual consistency and scalable fan-out.
  • Introduces operational complexity like topic management and consumer lag.
Example
Order service publishes OrderCreated to Kafka. Shipping and Inventory independently consume and react.
Key Takeaway

Match communication style to business needs: immediacy favors sync; resilience and decoupling favor async.
