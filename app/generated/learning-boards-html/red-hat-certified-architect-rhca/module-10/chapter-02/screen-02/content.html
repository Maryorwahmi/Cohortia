Learning Objectives

Progress from design decisions to OpenShift implementation and operations.

Bloom: Learn → Understand → Apply → Master
01
Apply Domain-Driven Design

Decompose a monolith into bounded contexts, each mapped to an independently deployable service and team.

VERIFIED COMPETENCY MILESTONE
02
Evaluate Communication Patterns

Choose between synchronous and asynchronous communication by weighing latency, consistency, and fault tolerance.

VERIFIED COMPETENCY MILESTONE
03
Design Data Ownership

Implement database-per-service with PVs and PVCs, and handle cross-service transactions with Saga or eventual consistency.

VERIFIED COMPETENCY MILESTONE
04
Implement Operational Patterns

Apply service discovery, API gateways, and circuit breakers using OpenShift Services, Routes, and Deployment objects.
