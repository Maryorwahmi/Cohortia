Module 9 › Chapter 9.6 › Key Concepts — Core Terms
Load Balancing
Distributing incoming traffic across multiple backend servers to improve scalability, reliability, and performance.
Backend Pool
A group of servers that provide the same service and receive traffic from the load balancer.
Scalability
The ability to handle growing load by adding resources, often achieved via horizontal scaling behind a load balancer.
Summary

Use these core concepts to explain architecture choices, justify algorithm selection, and plan HA/LB tests and maintenance.
