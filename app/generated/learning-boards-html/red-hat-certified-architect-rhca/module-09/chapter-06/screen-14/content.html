Module 9 › Chapter 9.6 › Key Concepts — Algorithms & Tools
Round Robin
Sequential distribution; simple but ignores current load.
Least Connection
Routes to the server with the fewest active connections; better for variable-duration workloads.
IP Hash
Provides deterministic client affinity by hashing source IP; useful but limited when NAT is present.
Final takeaway

Use the right algorithm for your traffic, and pair HAProxy with Keepalived to make the load balancer itself resilient. Test failover, draining, and health checks before production rollout.
