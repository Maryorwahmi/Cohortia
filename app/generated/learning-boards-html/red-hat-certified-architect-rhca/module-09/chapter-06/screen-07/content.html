How it works
Round Robin sends each request to the next server in order. Weighted Round Robin multiplies that sequence by each server's weight so more capable servers receive more traffic.
  1. Assign weights based on measured capacity, not guesswork.
  2. Calculate distribution using the weight ratio to predict traffic splits.
  3. Monitor real traffic to confirm expected behavior and adjust as needed.
Concrete example
If A and C have weight 1 and B has weight 1.5 or 2 after an upgrade, B will receive more requests. For fifteen incoming requests, compute assignments using the weights to confirm expected counts per server.
Pitfall
Weighted Round Robin does not account for current active connections or response latency. If requests vary widely in processing time, prefer connection-aware algorithms.
