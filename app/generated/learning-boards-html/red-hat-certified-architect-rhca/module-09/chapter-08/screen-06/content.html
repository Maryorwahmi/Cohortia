Module 9 › Chapter 9.8 › vrrp_instance Fields

Essential fields

state
Initial role: MASTER or BACKUP. It is a starting point; election rules decide final master.
interface
Network device used for VRRP advertisements and VIP assignment.
virtual_router_id
Unique ID for the VRRP group. Must be identical on all participants for this VIP.
priority & advert_int
Priority elects master; advert_int controls heartbeat frequency and failover responsiveness.

Configuration checklist

Consistency
virtual_router_id, auth_pass, and interface must match between master and backup.
Tuning
Lower advert_int increases detection speed but raises network traffic; tune for your environment.
Misconfiguration risk
An interface mismatch or ID mismatch prevents the VIP group from forming correctly.
