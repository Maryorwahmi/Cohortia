Backup (example)

# /etc/keepalived/keepalived.conf on HAProxy-Backup (e.g., 192.168.1.51)
global_defs {
    router_id LVS_BACKUP
}

vrrp_script chk_haproxy {
    script "/usr/bin/systemctl is-active haproxy"
    interval 2
    weight 20
}

vrrp_instance VI_1 {
    state BACKUP
    interface eth0
    virtual_router_id 51
    priority 100
    advert_int 1
    authentication {
        auth_type PASS
        auth_pass mysecretpassword
    }
    virtual_ipaddress {
        192.168.1.200/24 dev eth0 label eth0:0
    }
    track_script {
        chk_haproxy
    }
}

Differences to note

  • State is BACKUP and priority is lower (100) than master (101).
  • Other fields must be identical: virtual_router_id, auth_pass, interface, and scripts.
  • Decide on preemption behavior based on operational needs: default preempt reclaims VIP on recovery.
Key Takeaway

Backup nodes must mirror the master's configuration except for state and priority to allow predictable failover.
