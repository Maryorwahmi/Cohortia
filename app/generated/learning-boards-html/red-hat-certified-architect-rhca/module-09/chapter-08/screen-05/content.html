Process

Install and enable Keepalived

Follow these exact commands to prepare each HAProxy node.

sudo dnf install -y keepalived
sudo systemctl enable --now keepalived
sudo systemctl status keepalived
Why enable now
Enabling the service immediately ensures Keepalived participates in the VRRP elections and survives reboots.
Check
Use ip addr show <interface> to confirm the VIP appears after Keepalived becomes master.
Common mistakes
  • Installing only on one node — both must run Keepalived.
  • Not opening VRRP protocol 112 in the firewall.
  • Forgetting to match virtual_router_id and auth on all nodes.
Key Takeaway

Install and start Keepalived on every HAProxy node and verify service and network state before configuring VRRP instances.
