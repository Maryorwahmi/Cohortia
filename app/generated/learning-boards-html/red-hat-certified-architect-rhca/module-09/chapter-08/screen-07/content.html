How checks influence election

Checks run at interval and weight affects effective priority.

Example check
vrrp_script chk_haproxy {
    script "/usr/bin/systemctl is-active haproxy"
    interval 2
    weight 20
}
Concrete effect
If the script returns success the node gains 20 points, helping it keep master. If it fails, those points are removed and failover can occur.

Operational tips

  • Test the script independently to ensure exit codes are predictable.
  • Tune interval to balance detection speed and false positives.
  • Prefer simple checks that reflect true service readiness.
Key Takeaway

Use vrrp_script to link service health to VRRP elections; failing checks lower priority and trigger failover.
