Start and verify

Use these operational checks to ensure the VIP is correctly handled.

Commands
sudo systemctl enable --now keepalived
sudo systemctl status keepalived
ip addr show eth0
curl http://192.168.1.200/
Testing failover
  1. Confirm VIP is on master with ip addr show.
  2. Run a continuous curl to the VIP from a client.
  3. Stop HAProxy on master and observe VIP move to backup.
  4. Restart services and observe preemption if enabled.
