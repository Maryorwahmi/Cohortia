Lab: Implement Keepalived for HAProxy

Follow these checklist steps in your two RHEL VMs with identical HAProxy configs.

Steps
  1. Install keepalived on both nodes with sudo dnf install -y keepalived.
  2. Place master and backup keepalived.conf as provided, adjusting eth0 and the VIP to your network.
  3. Open VRRP protocol and VIP ports with firewall-cmd and reload.
  4. Enable and start Keepalived, verify with systemctl status and ip addr show.
  5. Test failover by stopping HAProxy on master and observing VIP on backup; test node reboot as well.
Checks & Tips
  • Test vrrp_script independently to ensure reliable returns.
  • Monitor ip addr show and curl output continuously while testing.
  • Tune advert_int and interval to balance speed and stability.
