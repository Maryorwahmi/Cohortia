Module 9 › Chapter 9.8 › Common Mistakes

Checklist of mistakes

  • virtual_router_id mismatch across nodes
  • auth_pass mismatch or missing authentication
  • incorrect interface name in configuration
  • equal priorities causing unpredictable master selection
  • broken or untested vrrp_script checks
  • firewall blocking VRRP protocol 112

How to avoid

Validate fields
Confirm IDs, auth_pass and interfaces match before starting Keepalived.
Test scripts
Run the vrrp_script manually to ensure reliable exit codes and response times.
Firewall checks
Open VRRP and app ports on both nodes and verify with firewall-cmd --list-all.
