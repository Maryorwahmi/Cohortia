Module 9 › Chapter 9.2 › Quick Reference
1. Identical corosync.conf
Copy the same file to every node to guarantee ring membership.
2. Ports & interface
Allow UDP 5404/5405 and prefer a dedicated network for Corosync traffic.
3. Verify & fix
Use pcs status and corosync-cmapctl; run the firewall, network, config, SELinux checklist when troubleshooting.
Final thought

These simple, repeatable controls reduce the majority of Corosync setup failures and let Pacemaker manage resources reliably.
