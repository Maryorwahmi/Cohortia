Configuration example

Use this simplified snippet as a starting template. Ensure identical settings across nodes.

# /etc/corosync/corosync.conf (simplified example)
totem {
    version: 2
    cluster_name: myhacluster
    secauth: on
    crypto_cipher: aes256
    crypto_hash: sha256
    interface {
        ring_number: 0
        bindnetaddr: 192.168.1.0 # Network address for the interface
        mcastport: 5405
        ttl: 1
    }
}

quorum {
    provider: corosync_votequorum
    two_node: 1
}

logging {
    fileline: off
    to_stderr: no
    to_syslog: yes
    syslog_facility: daemon
    debug: off
    timestamp: on
}
Totem

Defines the communication protocol, security options, and which interface or network Corosync uses.

Quorum

Controls vote-based quorum. two_node: 1 is for two-node clusters only; do not enable it for 3+ nodes.

Key Takeaway

Edit corosync.conf carefully, copy the same file to every node, and confirm bindnetaddr and cluster_name match across the cluster.
