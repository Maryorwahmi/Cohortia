Verification & Troubleshooting

Concrete checks to confirm membership and quickly diagnose problems.

Verification commands
sudo pcs status
sudo pcs status corosync
sudo corosync-cmapctl

These commands reveal node membership, resource state, and Corosync cmap values for debugging.

Troubleshooting checklist
  • Open UDP ports 5404 and 5405 on all nodes.
  • Verify ping to the bindnetaddr and correct subnet masks.
  • Ensure /etc/corosync/corosync.conf is identical on all nodes.
  • Temporarily try setenforce 0 to check SELinux interference.
Key Takeaway

A short, repeatable checklist quickly resolves most Corosync membership failures and prevents unnecessary downtime.

Common Mistake

Assuming Corosync will ignore small config mismatches; in practice, even a single differing setting can prevent nodes from joining.
