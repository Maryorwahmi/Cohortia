Module 9 › Chapter 9.2 › Troubleshooting checklist
Fast checklist
1. Firewall

Open UDP ports 5404 and 5405 on all nodes using firewall-cmd or equivalent.

2. Network connectivity

Ping the bindnetaddr and verify subnet masks and routes for the Corosync interface.

3. Configuration consistency

Ensure /etc/corosync/corosync.conf is identical across nodes, especially cluster_name and bindnetaddr.

4. SELinux check

Temporarily run setenforce 0 to see if policies block Corosync; use a proper policy in production.

Key Takeaway

Work through the checklist in order: ports, connectivity, config, SELinux. This systematic approach resolves most membership problems efficiently.
