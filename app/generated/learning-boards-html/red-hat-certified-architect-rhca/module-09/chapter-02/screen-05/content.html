Module 9 › Chapter 9.2 › Install packages and prepare nodes
Procedure

Install and prepare each VM for clustering

Command
sudo dnf install -y corosync pacemaker pcs

Install the runtime and management utilities used to create and manage the cluster.

Enable required services
sudo systemctl enable pcsd
sudo systemctl start pcsd
sudo systemctl status pcsd

pcsd must be running for pcs host authentication and cluster creation to succeed.

Set hacluster password

Use the same password on both nodes so pcs host auth can authenticate between them.

Static IPs

Assign static addresses like 192.168.1.10 and 192.168.1.11 to avoid membership issues caused by address changes.

NTP

Synchronize clocks on all nodes because time skew affects message timeouts and membership decisions.

Key Takeaway

Installation is a short command plus essential follow-up: enable pcsd, set hacluster, confirm network and time sync before cluster creation.

Common Mistake

Skipping pcsd enablement or forgetting the hacluster password on one node will block authentication and setup.
