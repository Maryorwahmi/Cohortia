Module 9 › Chapter 9.2 › Quorum and the two_node option
Concept

Quorum enforces majority consensus

Majority quorum

By default, the cluster needs more than half of votes to form quorum, preventing a single node from acting alone and creating split-brain.

two_node: 1

In a two-node cluster, set two_node: 1 to allow a single node to form quorum if its peer fails. Do not use this in clusters of 3+ nodes.

Scenario

Two-node lab: with two_node: 1, Node1 continues serving when Node2 goes down — this improves availability but reduces majority strictness.

Key Takeaway

Use two_node only for true two-node clusters; for 3+ nodes rely on majority quorum to preserve safety and avoid split-brain.
