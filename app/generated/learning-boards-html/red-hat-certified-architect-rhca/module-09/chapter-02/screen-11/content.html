Module 9 › Chapter 9.2 › Two-node cluster walkthrough
Lab steps
Install on both nodes
sudo dnf install -y corosync pacemaker pcs
Enable pcsd and set password
sudo systemctl enable pcsd
sudo systemctl start pcsd
echo "your_secure_password" | sudo passwd --stdin hacluster
Authenticate and setup cluster
sudo pcs host auth node1.example.com node2.example.com -u hacluster -p your_secure_password
sudo pcs cluster setup myhacluster node1.example.com node2.example.com --force
sudo pcs cluster start --all
sudo pcs status
Expected result

Both nodes appear in pcs status as online members and the cluster reports healthy membership.

Troubleshoot

If nodes do not appear, re-run firewall, bindnetaddr, and config consistency checks; try setenforce 0 to test SELinux blocking.
