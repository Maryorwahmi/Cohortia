Module 9 › Chapter 9.2 › Learning Objectives

Learning Objectives

Learn, Understand, Apply, Master

Bloom: Learn → Understand → Apply → Master
01
Install Corosync and tools

Install corosync, pacemaker, and pcs on each node so you have the management tools and runtime available. This lets you create and administer the cluster from the command line.

VERIFIED COMPETENCY MILESTONE
02
Author corosync.conf

Understand totem, interface, quorum, and logging sections so nodes form a consistent ring and quorum rules reflect your cluster size.

VERIFIED COMPETENCY MILESTONE
03
Start services & verify

Enable and start corosync; use pcs status and corosync-cmapctl or pcs status corosync to confirm membership and ring health.

VERIFIED COMPETENCY MILESTONE
04
Diagnose common issues

Run firewall checks for UDP 5404/5405, verify network connectivity on bindnetaddr, and confirm corosync.conf is identical across all nodes.

VERIFIED COMPETENCY MILESTONE
