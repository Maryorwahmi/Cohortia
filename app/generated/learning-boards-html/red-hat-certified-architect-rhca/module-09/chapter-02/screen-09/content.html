Module 9 › Chapter 9.2 › Enable and start Corosync
Service control
sudo systemctl enable corosync
sudo systemctl start corosync
sudo systemctl status corosync

Enable the service to start at boot, start it now, and confirm it is active without runtime errors.

sudo pcs cluster setup myhacluster node1.example.com node2.example.com --force
sudo pcs cluster start --all
sudo pcs status

Use pcs to create and start the cluster once nodes are authenticated and corosync is configured.

Key Takeaway

Start services only after configuration is consistent; then use pcs status to verify nodes appear in the ring.
