Module 9 › Chapter 9.2 › pcs vs corosync-cmapctl
Tool comparison
pcs status

High-level cluster state: lists nodes and resources and shows whether services are running as expected.

sudo pcs status
sudo pcs status corosync
corosync-cmapctl

Low-level Corosync map inspection to reveal internal ring information, counters, and configuration values.

sudo corosync-cmapctl
Workflow

Start with pcs for a broad view, then use corosync-cmapctl when you need to inspect Corosync internals and diagnose unexpected membership behavior.

Key Takeaway

Use the right tool at the right level: pcs for status, corosync-cmapctl for internals.
