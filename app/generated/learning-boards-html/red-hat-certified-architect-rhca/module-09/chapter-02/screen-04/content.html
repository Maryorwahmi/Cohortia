Module 9 › Chapter 9.2 › What Corosync Does
Definition

Corosync: messaging, membership, quorum

Corosync provides the cluster with heartbeat messages, membership lists, and quorum voting logic so Pacemaker can manage resources safely.

Message transport: reliable delivery of cluster messages
Membership: who is currently online and part of the ring
Quorum: majority rules to prevent split-brain
Concrete example

If node2 stops responding, Corosync detects the missing heartbeats, updates membership, and combined with quorum settings determines whether node1 alone may continue providing services. In a two-node cluster, two_node: 1 can allow the single remaining node to form quorum; in larger clusters, majority quorum prevents a lone node from running resources.

Misconception

Corosync is not a resource manager. It does not start or stop resources; Pacemaker does that based on Corosync's membership and messaging information.

Key Takeaway

Treat Corosync as the cluster's communication layer and ensure network and time are stable for reliable membership decisions.
