Definition › Cloned Resources
What is a clone?

A clone runs multiple instances of a primitive across nodes, enabling active‑active deployment when the service supports it.

When to use
Distributed caches, stateless services, or agents designed for concurrent instances.
When not to use
Stateful databases or file systems that require exclusive access to storage should not be cloned unless the agent supports safe concurrency.
Example
# Create an NFS server primitive
sudo pcs resource create NFS_Server ocf:heartbeat:nfsserver op monitor interval=30s

# Convert to a clone
sudo pcs resource clone NFS_Server

# If the agent supports it, control instance uniqueness
# e.g. globally-unique=false (agent dependent)
Verify instances on each node with pcs status and ensure the agent's documentation allows concurrent instances.
