Code Walkthrough › STONITH Configuration
Enable fencing
# Enable STONITH globally
sudo pcs property set stonith-enabled=true

# Example: create an IPMI fence device for node1
sudo pcs stonith create my_ipmi_fencer fence_ipmilan ipaddr=192.168.1.200 login=admin passwd=password pcmk_host_list="node1.example.com" op monitor interval=60s

# And for node2
sudo pcs stonith create my_ipmi_fencer2 fence_ipmilan ipaddr=192.168.1.201 login=admin passwd=password pcmk_host_list="node2.example.com" op monitor interval=60s
Replace addresses and credentials with your hardware values and verify devices with sudo pcs stonith.
Verification & testing
  • Run sudo pcs stonith to list devices and status.
  • Test fencing in a controlled lab to confirm the device actually powers off the target node.
  • Document findings and keep fallback procedures in case fencing devices fail.
