Hands‑on Activity › Lab Steps
Lab checklist
  1. Set maintenance-mode=true.
  2. Install httpd on both nodes and create WebServer primitive.
  3. Create or verify SharedFS and VirtualIP primitives.
  4. Create WebAppGroup with desired startup order.
  5. Enable STONITH and create fence_manual for lab simulation.
  6. Exit maintenance-mode and test failover by stopping httpd on the active node.
Commands summary
# Maintenance mode on
sudo pcs property set maintenance-mode=true

# Create WebServer
sudo pcs resource create WebServer ocf:heartbeat:apache configfile="/etc/httpd/conf/httpd.conf" statusurl="http://127.0.0.1/server-status" op monitor interval=30s

# Group resources
sudo pcs resource group add WebAppGroup SharedFS WebServer VirtualIP

# Enable STONITH and add manual fence (lab only)
sudo pcs property set stonith-enabled=true
sudo pcs stonith create my_manual_fencer fence_manual pcmk_host_list="node1.example.com node2.example.com"

# Exit maintenance mode
sudo pcs property set maintenance-mode=false

# Verify
sudo pcs status
sudo pcs stonith
Observe WebAppGroup failover when you stop httpd, and confirm fencing device listing with pcs stonith.
