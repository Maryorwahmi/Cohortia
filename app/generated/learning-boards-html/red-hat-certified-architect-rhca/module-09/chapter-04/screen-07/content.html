Code Walkthrough › Clone Commands
Commands
# Create NFS primitive
sudo pcs resource create NFS_Server ocf:heartbeat:nfsserver op monitor interval=30s

# Create clone for active-active operation
sudo pcs resource clone NFS_Server

# Verify clone instances
sudo pcs status
sudo pcs status resources
If instances do not start on every node, inspect resource-discovery and placement constraints that might limit start targets.
Test and pitfalls
  • Bring down one node and confirm remaining instances continue to serve.
  • Ensure the agent supports concurrent instances before cloning stateful services.
  • Watch for name uniqueness options like globally-unique if applicable.
Pro Tip

Prefer clones for agents documented as active‑active and test thoroughly in lab to avoid conflicting writes.
