Learning Objectives

Build operational expertise across grouping, cloning, constraints, and fencing, with lab‑ready commands and checks.

01
Create and manage Resource Groups

Combine primitives so they run as one unit with ordered startup. This ensures multi‑tier services stay colocated and fail over atomically. VERIFIED COMPETENCY MILESTONE

02
Configure Cloned Resources

Run resource instances concurrently across nodes for active‑active services. Learn differences from groups and when clones are safe to use. VERIFIED COMPETENCY MILESTONE

03
Advanced Constraints

Define explicit ordering, colocation, preferences and negative constraints to shape placement and behaviour across nodes. VERIFIED COMPETENCY MILESTONE

04
STONITH Fencing

Enable and configure fencing devices so cluster failover does not risk shared storage corruption; test carefully in lab. VERIFIED COMPETENCY MILESTONE
