Core Concept › Advanced Constraints
What constraints do

They let you specify explicit ordering, colocation, and placement preferences for resources or groups beyond implicit group behavior.

Ordering
Ensure resource A starts before B, and stop in reverse, even when they are separate primitives.
Colocation
Force resources to run on the same or different nodes based on affinity or constraints.
Negative constraints
Prevent co‑location using negative scores like -INFINITY to avoid conflicts.
Example use
If a resource must not share a node with another, add a negative colocation constraint. If startup sequencing crosses groups, add an order constraint to express the dependency explicitly.
Key Takeaway

Use explicit constraints to express relationships groups cannot capture, and keep constraint sets simple and documented.
