Verification checklist

Lab Walkthrough Ready
Apache checks
  • DocumentRoot on shared mount and readable by apache user.
  • Status URL enabled so Pacemaker can monitor health.
  • SELinux file context set for httpd_sys_content_t.
MariaDB checks
  • datadir on shared storage with correct owner mysql:mysql.
  • mysqld can open socket and write logs in the shared path.
  • SELinux type mysqld_db_t applied to the directory.
Pacemaker checks
  • Resources include monitor ops and sensible timeouts.
  • Groups ensure SharedFS mounts before services start.
  • STONITH fencing enabled for stateful services.
Key Takeaway

Testing failover and validating permissions and SELinux contexts before production rollout is the most important safety step for HA services with shared storage.
