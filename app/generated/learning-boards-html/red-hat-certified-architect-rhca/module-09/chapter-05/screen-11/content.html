Module 9 › Chapter 9.5 › Lab Walkthrough
Lab steps
Prepare Apache
Install httpd, create content on /mnt/data/www, set DocumentRoot and apply SELinux httpd_sys_content_t.
Prepare MariaDB
Install mariadb-server, mkdir /mnt/data/mysql, chown mysql:mysql, initialize datadir and set my.cnf to datadir path.
Configure Pacemaker
Put cluster in maintenance mode, create resources, add to groups, exit maintenance mode, then test failover.
Checkpoints
  • Web content served via VirtualIP after failover.
  • MariaDB starts on standby and clients connect to VirtualIP_DB.
  • No SELinux AVC denials and appropriate ownership applied.
