Module 9 › Chapter 9.5 › Stateless vs Stateful
Stateless (Apache)
  • No transactional state in local files; content can be shared or synced.
  • Primary needs: SharedFS availability and health URL for monitoring.
  • Less strict fencing requirements but still test for race conditions.
Lab check
Verify index.html is served via VirtualIP after failover and statusurl returns 200.
Stateful (MariaDB)
  • Datadir contains transactional files that must remain consistent.
  • Use shared storage or replication; stonith fencing is mandatory to avoid corruption.
  • Longer start timeouts and careful monitor intervals are typical.
Lab check
After failover, confirm MariaDB starts and clients can connect to VirtualIP_DB and see the same data.
