Module 9 › Chapter 9.5 › Preparing Apache
Step-by-step
1. Install httpd
sudo dnf install -y httpd on all nodes.
2. Place content on SharedFS
Create /mnt/data/www/index.html and update DocumentRoot to point to /mnt/data/www.
3. Enable server-status
Configure mod_status or a lightweight health endpoint for statusurl monitoring.
4. Adjust SELinux
Use semanage fcontext and restorecon to apply httpd_sys_content_t to the mount point.
Check

After mounting and permission fixes, curl the status URL and the virtual IP to confirm the content is served.

Command snippets
sudo dnf install -y httpd
# Prepare shared content on active node
sudo mkdir -p /mnt/data/www
sudo tee /mnt/data/www/index.html > /dev/null <<'EOF'
Hello from SharedFS
EOF
# SELinux
sudo semanage fcontext -a -t httpd_sys_content_t '/mnt/data/www(/.*)?'
sudo restorecon -Rv /mnt/data/www
Pitfall
If you forget semanage, index.html may be readable by the OS but blocked by SELinux causing service failures after failover.
