Module 9 › Chapter 9.5 › Key Concepts
ocf:heartbeat:apache
Agent for managing Apache; use configfile and statusurl for health checks.
ocf:heartbeat:mysql
Agent for MariaDB/MySQL; set binary, config, datadir and socket for correct control.
datadir
Location of database files; in active-passive setups it must be on shared storage accessible by the active node only.
Summary
Use the correct resource agents and parameters, place stateful data on shared storage, and validate permissions and SELinux contexts. Fencing is mandatory for stateful services to protect data integrity.
