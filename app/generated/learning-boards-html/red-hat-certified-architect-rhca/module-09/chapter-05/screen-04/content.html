Module 9 › Chapter 9.5 › Apache HA
Definition

Apache: stateless pattern

Ensure content is available on shared storage and provide a status URL for health monitoring. If content cannot be shared, use synchronization and careful testing.

Example resource definition
sudo pcs resource create WebService ocf:heartbeat:apache configfile='/etc/httpd/conf/httpd.conf' statusurl='http://127.0.0.1/server-status' op monitor interval=30s op start timeout=40s op stop timeout=60s
Concrete scenario
Create a shared mount /mnt/data/www with index.html, adjust DocumentRoot, set SELinux to httpd_sys_content_t, then create the WebService resource and group it with SharedFS and VirtualIP.
Common mistake
Forgetting the statusurl or pointing DocumentRoot to a path that isn’t on the shared mount prevents proper monitoring and causes startup failures after failover.
Key Takeaway

Treat Apache as stateless: focus on making content available and health-checkable rather than synchronizing live transactional data.

Checklist
  • Install httpd on all nodes.
  • Place content on SharedFS or configure rsync if necessary.
  • Enable and confirm a server-status endpoint for monitoring.
  • Adjust SELinux contexts with semanage and restorecon for the mount point.
  • Create WebService resource and add it to a group with SharedFS and VirtualIP.
