Practical questions
Question 1
MariaDB fails to start after failover with permission denied on /mnt/data/mysql. Name two likely causes and how to resolve them.
Expected resolution: ensure mysql ownership and proper SELinux context using chown, semanage, and restorecon; then test starting mysqld and check logs.
Question 2
Why is Apache generally simpler to make HA than MariaDB? Explain the key data handling difference and a practical consequence.
Expected explanation: Apache is stateless; MariaDB is stateful and requires exclusive access to datadir or replication and fencing to prevent corruption.
Assessment Tip

When answering, include commands you would run to diagnose and fix the issue and describe how you would verify service health after the fix.
