Module 9 › Chapter 9.5 › Key Concepts — Safety
Shared Storage
Provide a single authoritative location for files used by stateful services; mount exclusively or use clustered FS for multi-writer access.
Stateful vs Stateless
The key design decision that determines storage and fencing strategy for HA deployments.
Safety: Fencing & SELinux
STONITH fencing prevents split-brain for stateful services and SELinux contexts must be set for non-standard storage paths.
Final takeaway
Design your HA configuration around the service type, protect state with proper storage and fencing, and run failover tests that exercise permissions and SELinux to ensure production readiness.
