Module 9 › Chapter 9.1 › Pacemaker
Role of Pacemaker
A resource manager that starts, stops, monitors, and migrates resources based on cluster state and configured policies.
Resource Agents
Scripts that implement start, stop, and monitor operations for services; the quality of agents affects failover correctness.
Operational example
Pacemaker migrates a database resource to a standby node when Corosync reports the primary as failed, using the database resource agent to start services cleanly.
Configuration notes
Define constraints, ordering, and location rules so Pacemaker places resources predictably during failover.
Misconception

Pacemaker does not repair corrupted data; it manages service lifecycle. Data integrity depends on replication and application-aware recovery.
