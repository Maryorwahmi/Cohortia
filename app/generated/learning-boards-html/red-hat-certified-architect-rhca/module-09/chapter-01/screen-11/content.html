Module 9 › Chapter 9.1 › Active-Active
How it works
Multiple nodes run the same service and share traffic, improving utilization and capacity.
Good fit
Stateless services or those designed for distributed state with conflict resolution.
Complexities
  • Data synchronization and consistency across active instances.
  • More complex testing and operational playbooks.
  • Potential for conflict or split-write scenarios without careful coordination.
Scenario

A web farm handling traffic behind a load balancer is active-active: adding nodes increases capacity and provides graceful degradation if one node fails.
