Module 9 › Chapter 9.3 › Hands-on Activity
Step-by-step commands
sudo pcs property set maintenance-mode=true
sudo pcs resource create VirtualIP ocf:heartbeat:IPaddr2 ip=192.168.1.100 cidr_netmask=24 op monitor interval=10s
sudo pcs resource create SharedFS ocf:heartbeat:Filesystem device="/dev/sdb1" directory="/mnt/data" fstype="xfs" op monitor interval=20s
sudo pcs constraint colocation add VirtualIP with SharedFS INFINITY
sudo pcs constraint order SharedFS then VirtualIP
sudo pcs property set maintenance-mode=false
sudo pcs status
sudo pcs status resources
sudo pcs constraint
Testing failover
Move resources manually or stop Pacemaker on the active node to simulate failure. For example: sudo pcs resource move VirtualIP node2.example.com. Observe that SharedFS and VirtualIP move together when colocation and order are correct.
Checklist
  • Device formatted and mount point created on all nodes
  • Constraints present and verified
  • Maintenance mode used for safe configuration
