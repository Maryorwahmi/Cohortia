Module 9 › Chapter 9.3 › Create Floating IP
Example command
sudo pcs resource create VirtualIP ocf:heartbeat:IPaddr2 ip=192.168.1.100 cidr_netmask=24 op monitor interval=10s
Parts explained
  • VirtualIP: unique resource name
  • ocf:heartbeat:IPaddr2: agent type and provider
  • ip / cidr_netmask: address and subnet
  • op monitor interval: monitoring frequency
Practical note
Ensure the IP is routable in your cluster network and not already used. If the IP cannot be assigned to the node interface, the agent will fail to start the resource.
Verification
sudo pcs status resources
# shows which node currently owns VirtualIP
Key Takeaway
IPaddr2 provides a floating IP that Pacemaker will move between nodes according to constraints and node health; monitoring interval affects detection speed and load.
