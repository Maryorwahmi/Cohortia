Module 9 › Chapter 9.3 › Pacemaker & Corosync
Claim

Corosync handles cluster messaging and membership; Pacemaker makes orchestration decisions and acts on resources in response to that state.

Example scenario
If a node loses network connectivity, Corosync detects the membership change and Pacemaker relocates resources to healthy nodes.
Misconception
Pacemaker is not a storage system. Ensure storage is cluster-aware or only mounted on one node at a time to prevent corruption.
Key Takeaway
Both messaging and orchestration must be correct for safe failover; problems in either cause unpredictable behavior.
Annotated roles
Corosync
Reliable messaging, membership, quorum.
Pacemaker
Resource orchestration, monitoring, and recovery decisions based on the CIB.
CIB
Replicated XML configuration that records resources and constraints for every node to act upon.
