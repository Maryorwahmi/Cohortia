Module 9 › Chapter 9.3 › Order & Colocation
Order example
sudo pcs constraint order SharedFS then VirtualIP
This ensures the filesystem is started before the IP is created, avoiding a service that comes up before its storage is available.
Colocation example
sudo pcs constraint colocation add VirtualIP with SharedFS INFINITY
INFINITY forces both resources to run on the same node. Use positive scores for preferences instead of hard requirements when needed.
Key Takeaway
Combine order and colocation to model dependencies where a resource must be mounted before another starts and both must run on the same node.
