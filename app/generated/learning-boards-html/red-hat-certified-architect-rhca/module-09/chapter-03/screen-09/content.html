Module 9 › Chapter 9.3 › Monitoring Interval
Short interval (responsive)
Pros: fast detection and quicker failover. Cons: higher CPU and I/O from frequent agent runs; may impact resource performance.
Example
VirtualIP with op monitor interval=10s detects address loss quickly and initiates failover.
Long interval (economical)
Pros: less overhead from monitoring. Cons: longer detection time increases service downtime before recovery.
Guideline
Pick intervals based on agent cost and acceptable downtime. Simple resources: shorter intervals. Costly probes: longer intervals.
Key Takeaway
Balance detection speed and resource overhead with a tuned op monitor interval; test in a lab to find safe defaults for your services.
