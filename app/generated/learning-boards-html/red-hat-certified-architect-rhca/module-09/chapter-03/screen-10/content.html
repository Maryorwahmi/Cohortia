Soft preference example
# Prefer VirtualIP to run on node1
sudo pcs constraint location VirtualIP prefers node1.example.com=50
The score 50 increases node1's attractiveness. If node1 fails, the resource will run elsewhere.
Hard pin and avoidance
Hard pin
Use a strong score or INFINITY in other constraints to require a resource to run on a specific node.
Tip
Avoid conflicting location constraints. If two constraints point to different preferred nodes with similar scores, evaluate how the scheduler resolves them.
