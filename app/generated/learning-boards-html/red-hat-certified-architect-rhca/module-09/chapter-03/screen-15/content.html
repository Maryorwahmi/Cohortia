Module 9 › Chapter 9.3 › Constraints & Monitoring
Location Constraint
Rules that prefer, pin, or forbid a resource from running on specific nodes using scores.
Order Constraint
Specifies sequence: ensure a resource starts or stops before another.
Colocation Constraint
Ensure resources run together on the same node or keep them apart, using INFINITY for hard co-location.
Takeaway
Constraints and monitoring intervals are the levers you use to align Pacemaker’s behavior with application requirements. Test thoroughly to ensure they interact as intended.
