Module 9 › Chapter 9.3 › Troubleshooting
Inspection checklist
  • Run sudo pcs status and sudo pcs status resources to observe ownership and failures.
  • Review the CIB for syntax and parameter mistakes.
  • Check logs with journalctl -u pacemaker -u corosync to find agent or membership errors.
Common root causes
Missing device paths, absent mount points, incorrect fstype, bad agent parameters, or conflicting constraints that leave no eligible node.
Diagnostic tip
Reproduce the failure in a lab by moving resources or stopping Pacemaker on a node; observe logs and pcs status to map the failure to configuration fixes.
Key Takeaway
Use status, CIB verification, and logs together to identify misconfigured parameters or constraint conflicts, and always test fixes in a non-production environment first.
