Module 9 › Chapter 9.3 › Shared Filesystem
Command example
sudo pcs resource create SharedFS ocf:heartbeat:Filesystem device="/dev/mapper/vg_data-lv_data" directory="/mnt/data" fstype="xfs" op monitor interval=20s
Important check
Confirm the device path exists and is formatted on every node before creating the resource. Also ensure /mnt/data exists on every node.
Storage considerations
  • Shared storage must be accessible from all nodes.
  • Non-clustered filesystems should be mounted by Pacemaker on only one node at a time.
  • Use clustered filesystems like GFS2 when concurrent mounts are required.
Common mistake
Mounting a non-clustered filesystem on multiple nodes simultaneously can corrupt data. Pacemaker prevents this when properly configured with a filesystem primitive.
