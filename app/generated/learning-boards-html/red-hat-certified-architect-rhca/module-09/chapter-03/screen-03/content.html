Module 9 › Chapter 9.3 › Practice Checklist
Maintenance mode
Always set maintenance-mode=true before major changes and reset to false after testing. This prevents Pacemaker from acting on incomplete configs.
CIB verification
Confirm pcs changes appear in the replicated Cluster Information Base so every node has the same config.
Resource monitoring
Use op monitor interval to balance detection speed and system overhead; too frequent checks can cause load, too slow increases RTO.
Constraint testing
Test colocation and order by moving resources or stopping a node; watch that related resources move together and startup order is preserved.
