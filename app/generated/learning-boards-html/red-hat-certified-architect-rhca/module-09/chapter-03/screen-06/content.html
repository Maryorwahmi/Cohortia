Module 9 › Chapter 9.3 › Resource Agents
What they do

Resource agents implement the operations Pacemaker uses to control resources: start, stop, and monitor. They are typically provided under the OCF namespace and referenced when creating primitives.

Common primitive types
  • IPaddr2 — floating IP addresses
  • Filesystem — mount a block device to a directory
  • apache, MariaDB — service-specific agents
Example
A filesystem resource must reference a device path available to all nodes and a mount directory that Pacemaker will manage on whichever node owns the resource.
Example resource definition
sudo pcs resource create SharedFS ocf:heartbeat:Filesystem device="/dev/mapper/vg_data-lv_data" directory="/mnt/data" fstype="xfs" op monitor interval=20s
Pitfall
Do not mount a non-clustered filesystem simultaneously on multiple nodes. That leads to corruption. Use a clustered filesystem or ensure only one node mounts it at a time.
