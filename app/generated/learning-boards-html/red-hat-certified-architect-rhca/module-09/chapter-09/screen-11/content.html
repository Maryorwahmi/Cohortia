Module 10 › Chapter 9.9 › Monitoring & Maintenance
What to monitor
Target metrics that indicate failing components or degraded performance.
  • HAProxy: backend up/down, latency, connections per second.
  • Keepalived: VRRP state changes, vrrp_script results.
  • Pacemaker: resource status, fencing events, node membership.
  • Backend apps: health endpoints, error rates, and response times.
Maintenance practices
Apply updates and configuration changes in a staged, automated manner to keep redundant nodes available.
Use Ansible
Automate configuration distribution and update rollouts so redundant nodes remain consistent.
Runbooks & DR drills
Keep clear operational runbooks and practice disaster recovery scenarios periodically to validate procedures.
Key Takeaway

Monitoring and staged maintenance reduce risk. Automate where possible and rehearse DR to keep your architecture dependable.
