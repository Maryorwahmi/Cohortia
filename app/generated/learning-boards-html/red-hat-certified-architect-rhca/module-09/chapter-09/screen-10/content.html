Module 10 › Chapter 9.9 › Testing & Validation
Test plan components
Create repeatable, instrumented tests to observe failover and recovery.
Node failure
Power off nodes or stop services to validate VIP movement and HAProxy continuity.
Resource failure
Stop backend services to verify HAProxy removes them and Pacemaker reassigns resources as needed.
Storage & partition
Simulate storage loss or network isolation to confirm fencing and data safety.
Acceptance criteria example
VIP failover within defined time, no lost committed transactions after database migration, and monitored alert thresholds not exceeded.
Documentation
Log test steps, times, and verification checks so you can repeat tests and track regressions.
Key Takeaway

Integrated, instrumented tests are the only way to validate that your HA/LB design behaves under realistic failures.
