Module 10 › Chapter 9.9 › HAProxy Health Checks
HAProxy example
Active health checks and backend server definitions.
global
  log /dev/log local0
  maxconn 4096

defaults
  mode http
  timeout connect 5s
  timeout client 50s
  timeout server 50s

frontend http-in
  bind 10.0.0.100:80   # VIP
  default_backend webservers

backend webservers
  balance roundrobin
  option httpchk GET /health
  server web01 10.0.1.11:80 check
  server web02 10.0.1.12:80 check
  server web03 10.0.1.13:80 check
Explainer bullets
  • option httpchk defines an active HTTP probe endpoint used to verify backend health.
  • Each server line ends with check to enable active probes for that server.
  • balance selects the distribution algorithm; roundrobin is deterministic and simple to test.
Concrete example
If web02 fails the health check, HAProxy stops sending requests to 10.0.1.12 until it returns healthy responses.
Key Takeaway

Active health checks make backend selection predictable and support faster recovery during failures.
