Exercise template
Use this structured template to document your architecture and testing plan.
1. Backend App Servers
Multiple instances behind HAProxy, health checks, and autoscaling considerations for resilience.
2. MariaDB Database
Active-passive with Pacemaker managing filesystem mounts and MariaDB, plus STONITH fencing.
3. HAProxy
Two or more HAProxy nodes with identical configs, distributing traffic to healthy backends.
4. Keepalived
Manage VIP failover for HAProxy using VRRP and vrrp_script checks aligned with HAProxy health.
Testing checklist
Include node power-off, service stop, storage unavailability, network partition, and load under failover scenarios. Define pass/fail criteria for each.
Key Takeaway

Document responsibilities, redundancy patterns, and tests. Validate and automate as much as possible before production deployment.
