Server lines and health
  • server name address:port check fall 3 rise 2 inter 5s
  • fall: consecutive failures to mark down; rise: consecutive successes to mark up.
  • inter: interval between checks; tune for responsiveness vs noise.
Tip: Use backup for a reserve server that only receives traffic if primaries fail.
Example backend
Roundrobin balancing with an HTTP health check and a backup server.
backend web_servers
    balance roundrobin
    option httpchk GET /health
    server web1 192.168.1.101:80 check fall 3 rise 2 inter 5s
    server web2 192.168.1.102:80 check fall 3 rise 2 inter 5s
    server web3 192.168.1.103:80 check fall 3 rise 2 inter 5s backup
Key Takeaway

Select a balancing algorithm that matches your workload and use weights for uneven capacities; always validate health behavior under simulated failures.
