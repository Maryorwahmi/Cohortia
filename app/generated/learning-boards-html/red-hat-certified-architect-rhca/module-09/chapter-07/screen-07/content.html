What belongs in defaults
  • mode: http or tcp for protocol-specific handling.
  • timeout connect, client, server, and http-keep-alive to limit resource usage.
  • option httplog, dontlognull, redispatch for request behavior.
  • maxconn per-section to protect node capacity.
Misconception: defaults are global. They are inherited by following sections, not process-wide like global.
Example defaults
Common baseline settings to include early in your configuration.
defaults
    mode http
    log global
    option httplog
    option http-server-close
    option forwardfor except 127.0.0.0/8
    retries 3
    timeout http-request 10s
    timeout connect 10s
    timeout client 1m
    timeout server 1m
    maxconn 2000
Key Takeaway

Defaults keep configuration DRY and consistent; override only where a listener or backend needs different behavior.
