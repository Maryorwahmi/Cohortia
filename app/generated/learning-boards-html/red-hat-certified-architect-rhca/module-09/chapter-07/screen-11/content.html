Module 9 › Chapter 9.7 › SSL Offloading
Why offload TLS
  • Removes CPU cost of TLS from backend servers.
  • Centralizes certificate management at the load balancer.
  • Requires careful file permissions and SELinux rules for cert readability.
Security note: protect the private key and consider re-encryption to backends if the internal network is not fully trusted.
Example bind for TLS
Use a combined PEM containing certificate and private key.
frontend https_front
    bind *:443 ssl crt /etc/haproxy/certs/mycert.pem
    default_backend web_servers
Key Takeaway

Terminate TLS at HAProxy to lower backend CPU load, but secure cert files and evaluate whether internal traffic needs encryption.
