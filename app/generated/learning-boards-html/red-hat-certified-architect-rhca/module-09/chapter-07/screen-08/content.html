Frontends are listeners
  • Bind to IP and port, e.g. bind *:80 or bind *:443 ssl crt /path/to/cert.pem.
  • Can redirect, apply ACLs, and select a default_backend.
  • Support differing behaviors per listener; not limited to a single backend.
Practical check: curl the HAProxy IP and ensure the response originates from a backend index page you created.
Example frontend
Simple listener that forwards to a backend and optionally handles TLS.
frontend http_front
    bind *:80
    # redirect scheme https code 301 if !{ ssl_fc }
    default_backend web_servers

frontend https_front
    bind *:443 ssl crt /etc/haproxy/certs/mycert.pem
    default_backend web_servers
Key Takeaway

Frontends are your control plane for client reachability. Verify bind addresses, ports, and TLS files before assuming traffic flows.
