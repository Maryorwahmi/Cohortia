Module 9 › Chapter 9.7 › Install & Verify
Installation commands
A sample install and service enable sequence you will run in the lab.
sudo dnf install -y haproxy
sudo systemctl enable --now haproxy
sudo systemctl status haproxy
Verification checks
  • Confirm systemctl reports active (running).
  • Use ss or netstat to ensure HAProxy is listening on the configured port.
  • Open firewall ports with firewall-cmd if listeners are blocked.
Common mistakes & checks
Pay attention to SELinux, firewall, and forgotten enable/start steps.
Forgot to enable service: oddly, HAProxy won’t start at boot unless enabled.
Port blocked by firewall: open 80, 443, 8080 as needed and reload the firewall.
SELinux: ensure HAProxy has permissions to bind ports and read cert files when using SSL.
Key Takeaway

Verify service state, listening ports, firewall, and SELinux before editing configuration to avoid wasted troubleshooting time.
