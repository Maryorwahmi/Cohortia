Module 9 › Chapter 9.7 › Common Pitfalls
Operational errors to check
  • Firewall: ensure ports 80, 443, and 8080 are open for HAProxy listeners.
  • SELinux: add port and file contexts so HAProxy can bind and read certs.
  • Redundancy: use Keepalived or similar to avoid single HAProxy failure.
Real lab failure: HAProxy won't start after adding ssl crt — check certificate path and SELinux file context first.
Troubleshooting checklist
Run these commands when debugging listener or start failures.
sudo systemctl status haproxy
ss -tulpn | grep haproxy
sudo firewall-cmd --list-all
sudo ausearch -m avc -ts recent
Key Takeaway

Always combine configuration work with network and OS checks: firewall, SELinux, and HA design prevent operational outages.
