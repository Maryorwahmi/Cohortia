Module 9 › Chapter 9.7 › Statistics Page
What the stats page shows
  • Backend server health and UP/DOWN status.
  • Current connections, session rates, and counters.
  • Listener state and configuration summaries for quick diagnosis.
Security: Protect the stats page with basic auth and firewall restrictions to avoid exposing sensitive operational data.
Example stats block
Bind to a management port and set a URI for the stats interface.
listen stats
    bind *:8080
    mode http
    stats enable
    stats uri /haproxy?stats
    stats realm Haproxy\ Statistics
    stats auth admin:password123
    stats refresh 10s
Key Takeaway

Use the stats page to validate health checks and traffic distribution during tests; lock it down in production.
