Module 9 › Chapter 9.7 › haproxy.cfg Structure
Section definitions
  • global: process-wide settings — log, user, maxconn, nbproc.
  • defaults: shared timeouts, mode, logging options applied to frontends/backends.
  • frontend: public listeners; bind to ports; route traffic.
  • backend: server pool, balance algorithm, health checks and server lines.
Tip: keep defaults concise and only override in specific frontends or backends when needed.
Config excerpt (annotated)
This excerpt shows each section name so you can map behavior quickly.
# global
global
    log /dev/log local0 info
    user haproxy
    maxconn 4000

# defaults
defaults
    mode http
    timeout client 1m
    timeout server 1m

# frontend
frontend http_front
    bind *:80
    default_backend web_servers

# backend
backend web_servers
    balance roundrobin
    server web1 192.168.1.101:80 check
