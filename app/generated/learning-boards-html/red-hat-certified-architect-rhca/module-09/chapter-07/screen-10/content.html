How health checks work
  • option httpchk GET /health instructs HAProxy which path to probe.
  • server lines include check and timing/thresholds: fall, rise, inter.
  • Checks determine whether a server is considered UP or DOWN for routing.
Practical: Create a simple /health endpoint that returns 200 OK so the check succeeds. Test by stopping the web service and observing status changes.
Check tuning example
Adjust fall/rise/inter to meet your service SLA for detection vs stability.
backend api_servers
    option httpchk GET /api/health
    server api1 192.168.1.10:8080 check fall 3 rise 2 inter 5s
    server api2 192.168.1.11:8080 check fall 3 rise 2 inter 5s
Key Takeaway

Health checks must match working endpoints; choose thresholds to balance timely detection and avoidance of false positives.
