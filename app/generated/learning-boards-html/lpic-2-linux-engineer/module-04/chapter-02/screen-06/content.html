Zone File Structure

Zone File Essentials: The SOA Record

The mandatory Start of Authority record defines administrative zone parameters.

Key SOA Components

  • •`$TTL`: Default Time-To-Live for records in the zone.
  • •`@ IN SOA`: Declares the primary name server and administrator email.
  • •`Serial`: **MUST** be incremented with every change to the zone file.
  • •`Refresh`: How often secondary servers check for updates.
  • •`Retry`: How long secondary servers wait before retrying a failed refresh.
  • •`Expire`: Maximum time secondary servers will keep zone data if unable to refresh.
  • •`Negative Cache TTL`: How long negative responses (e.g., non-existent domains) are cached.
Key Takeaway

The SOA record is the foundational administrative entry for any zone file, with the serial number being critical for propagating changes to secondary servers.

Code Walkthrough: `db.example.com` (SOA)
$TTL 86400
@       IN      SOA     ns1.example.com. admin.example.com. (
                        2023102701 ; Serial (YYYYMMDDNN)
                        3600       ; Refresh (seconds)
                        1800       ; Retry (seconds)
                        604800     ; Expire (seconds)
                        86400 )    ; Negative Cache TTL (seconds)
Common Mistake

Forgetting to increment the `Serial` number after changes. This prevents secondary servers from updating their zone data, leading to stale information.
