Resource Records

Mapping Hostnames to IPs: A and AAAA Records

Connecting human-readable names to network addresses.

Record Types & Usage

  • •**A Record:** Maps a hostname (e.g., `www`) to an IPv4 address (e.g., `192.168.1.100`).
  • •**AAAA Record:** Maps a hostname to an IPv6 address (e.g., `2001:db8::1`).
  • •**`@` Symbol:** Refers to the domain itself (e.g., `example.com`).
  • •**Multiple Records:** Define separate A/AAAA records for different services (e.g., `mail`, `ftp`).
Key Takeaway

A and AAAA records are fundamental for translating domain names into the IP addresses that computers use to locate resources on the network.

Code Walkthrough: `db.example.com` (A/AAAA Records)
; A Records (IPv4)
ns1     IN      A       192.168.1.10
ns2     IN      A       192.168.1.11
@       IN      A       192.168.1.100  ; The @ symbol refers to the domain itself
www     IN      A       192.168.1.100
mail    IN      A       192.168.1.120

; AAAA Records (IPv6 - optional)
@       IN      AAAA    2001:db8::100
Pro-Tip

Always ensure your NS records (from the previous screen) have corresponding A/AAAA records defined in your zone file. These are often called 'glue records' when they refer to the name servers themselves.
