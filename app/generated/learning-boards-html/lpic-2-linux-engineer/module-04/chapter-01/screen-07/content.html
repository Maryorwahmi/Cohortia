Recursive vs. Iterative Queries

Two Approaches to DNS Name Resolution

Recursive Query

Server provides full answer, contacting others if needed.

Iterative Query

Server provides best answer or referral, client continues search.

Key Takeaway

Clients typically use recursive queries to their local resolver, which then performs iterative queries to resolve names across the DNS hierarchy.

Query Flow Comparison

Understanding who does the 'legwork' in DNS resolution.

Recursive Query

  • Client asks local DNS server.
  • Local DNS server handles all steps.
  • Local DNS server returns final IP.

Iterative Query

  • Resolver asks server.
  • Server gives best answer/referral.
  • Resolver asks next server.
