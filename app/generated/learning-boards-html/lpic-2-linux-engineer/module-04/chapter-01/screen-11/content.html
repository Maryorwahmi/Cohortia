Configuring BIND Forwarders

Directing Unresolved Queries to Upstream DNS Servers

Key Directives

  • `forwarders { ... };`: Specifies upstream DNS servers.
  • `recursion yes;`: Enables recursive queries for clients.
  • `allow-query { ... };`: Defines which clients can query the server.
  • `listen-on { ... };`: Specifies network interfaces to listen on.
Key Takeaway

Properly configuring `forwarders` and `allow-query` in `named.conf.options` is essential for a functional and secure caching-only BIND server.

File: /etc/bind/named.conf.options
options {
    directory "/var/cache/bind";

    listen-on { any; }; # Listen on all IPv4 interfaces
    allow-query { any; }; # Allow queries from any client (restrict in prod!)

    recursion yes; # Enable recursion for clients

    forwarders {
        8.8.8.8;  # Google Public DNS
        8.8.4.4;  # Google Public DNS
    };

    dnssec-validation auto;
    auth-nxdomain no;
    listen-on-v6 { any; };
};
Security Note

For production, restrict `allow-query` to internal networks (e.g., `192.168.1.0/24;`) to prevent open resolvers.
