Fine-Tuning Filesystems

Optimizing performance and administrative settings.

tune2fs for ext Filesystems

tune2fs allows you to modify various parameters for ext2, ext3, and ext4 filesystems, such as volume labels, check intervals, and reserved block percentages.

Example: sudo tune2fs -L "MyDataVolume" /dev/sdb1

xfs_admin for XFS Filesystems

xfs_admin provides similar functionality for XFS filesystems, enabling you to change labels and other XFS-specific parameters.

Example: sudo xfs_admin -L "MyXFSVolume" /dev/sdb1

Key Takeaway

Use tune2fs and xfs_admin to optimize filesystem behavior. Regularly monitor disk and inode usage with df -h and df -i to prevent issues.

Monitoring Filesystem Usage

# Check disk space usage
df -h
# Output example:
# Filesystem      Size  Used Avail Use% Mounted on
# /dev/sda2       232G   15G  206G   7% /
# /dev/sdb1        10G  24M  9.5G   1% /mnt/data

# Check inode usage
df -i
# Output example:
# Filesystem        Inodes   IUsed   IFree IUse% Mounted on
# /dev/sda2       15258624  300000 14958624    2% /
