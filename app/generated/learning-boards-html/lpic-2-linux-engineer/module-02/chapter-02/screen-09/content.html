Building a Filesystem with mkfs

Initializing block devices for data storage.

The mkfs Command Family

The mkfs (make filesystem) command is used to create a new filesystem on a block device. Each filesystem type has its own variant, such as mkfs.ext4, mkfs.xfs, and mkfs.btrfs.

This process writes the necessary data structures to the partition, allowing the operating system to store and retrieve files.

Safety Note: Data Loss Warning

Running mkfs will irrevocably erase ALL data on the specified partition. Always double-check the device name (e.g., using lsblk or fdisk -l) to prevent catastrophic data loss.

Key Takeaway

mkfs is essential for preparing storage, but always verify the target device to avoid accidental data destruction.

Creating Filesystems

# Create an ext4 filesystem
sudo mkfs.ext4 /dev/sdb1

# Create an XFS filesystem
sudo mkfs.xfs /dev/sdb2

# Create a Btrfs filesystem
sudo mkfs.btrfs /dev/sdb3

# Example: Verify device before mkfs
lsblk
# Output will show device names and sizes
