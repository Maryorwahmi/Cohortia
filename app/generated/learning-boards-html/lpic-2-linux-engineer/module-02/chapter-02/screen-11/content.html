Detaching Filesystems: umount

Safely disconnecting storage from the system.

The umount Command

The umount command detaches a mounted filesystem from its mount point. This is crucial for ensuring data integrity before removing a device or performing maintenance.

Example: sudo umount /mnt/data

Common Issue: Filesystem Busy

If a filesystem is actively being used by a process, umount will fail. You need to identify and stop these processes first.

  • Identify processes: lsof /mnt/data or fuser -m /mnt/data
  • Resolve: Terminate processes or wait for them to complete.
Key Takeaway

Always use umount to safely detach filesystems. Troubleshoot 'busy' errors by identifying and managing active processes.

Unmounting & Troubleshooting

# Attempt to unmount
sudo umount /mnt/data
# Output if busy:
# umount: /mnt/data: target is busy.

# Identify processes using the mount point
lsof /mnt/data
# Output example:
# COMMAND   PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
# bash     1234 user  cwd    DIR  8,17     4096    2 /mnt/data

# Alternative to identify processes
fuser -m /mnt/data
# Output example:
# /mnt/data:           1234c

# After identifying, you might kill the process (use with caution!)
# sudo kill 1234

# Then try unmounting again
sudo umount /mnt/data
# Success: no output
