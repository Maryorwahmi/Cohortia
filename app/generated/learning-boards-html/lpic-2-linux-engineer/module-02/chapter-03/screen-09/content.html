Formatting and Mounting Logical Volumes

Making LVs usable by the operating system

01

Format the LV

Choose a filesystem (e.g., ext4, XFS) and format the Logical Volume. This prepares it for data storage.

sudo mkfs.ext4 /dev/my_vg/data_lv
02

Create Mount Point

Create a directory where the Logical Volume will be attached to the filesystem hierarchy.

sudo mkdir /mnt/lvm_data
03

Mount the LV

Attach the formatted Logical Volume to its designated mount point, making its contents accessible.

sudo mount /dev/my_vg/data_lv /mnt/lvm_data
04

Ensure Persistence

Edit /etc/fstab to ensure the LV is automatically mounted after system reboots.

/dev/my_vg/data_lv /mnt/lvm_data ext4 defaults 0 2
Key Takeaway

Formatting and mounting are crucial steps to make a Logical Volume functional, allowing the operating system to store and retrieve data from it.
