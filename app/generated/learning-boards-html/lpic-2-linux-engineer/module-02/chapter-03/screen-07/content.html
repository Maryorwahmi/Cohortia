Volume Groups (VGs): Pooling Storage

Combining Physical Volumes into a flexible storage pool

# Create a VG named 'my_vg' from two PVs
sudo vgcreate my_vg /dev/sdb1 /dev/sdc1

# Add another PV to an existing VG
sudo vgextend my_vg /dev/sdd1

# View all Volume Groups
sudo vgs

# Display detailed VG information
sudo vgdisplay
  • •VGs aggregate space from one or more PVs into a single pool.
  • •Use vgcreate to create a new Volume Group.
  • •Expand a VG by adding more PVs with vgextend.
  • •vgs and vgdisplay provide status and capacity information.
Key Takeaway

Volume Groups are the flexible storage pools that combine physical disks, providing a unified resource from which Logical Volumes can be dynamically allocated.

Example Output

sudo vgs

  VG    #PV #LV #SN Attr   VSize   VFree
  my_vg   2   0   0 wz--n- <300.00g <300.00g

This output shows a Volume Group named my_vg, composed of 2 PVs, with a total size of 300GB and all space currently free. No Logical Volumes or snapshots are yet created.

Common Mistake

Insufficient PVs

A common error is attempting to create a VG without first initializing the underlying physical devices as PVs. Always run pvcreate on your disks or partitions before trying to add them to a Volume Group with vgcreate or vgextend.
