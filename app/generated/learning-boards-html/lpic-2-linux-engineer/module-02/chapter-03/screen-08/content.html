Logical Volumes (LVs): Flexible Partitions

Carving out dynamic storage from Volume Groups

# Create a 10GB LV named 'data_lv' in 'my_vg'
sudo lvcreate -L 10G -n data_lv my_vg

# Create an LV using all remaining free space in 'my_vg'
sudo lvcreate -l 100%FREE -n all_space_lv my_vg

# View all Logical Volumes
sudo lvs

# Display detailed LV information
sudo lvdisplay
  • •LVs are virtual partitions created from a VG's free space.
  • •Use lvcreate to define the size, name, and parent VG.
  • •LVs appear as block devices (e.g., /dev/my_vg/data_lv).
  • •After creation, LVs are formatted with a filesystem and mounted.
Key Takeaway

Logical Volumes provide the operating system with flexible, resizable storage units, decoupled from the physical disk layout, enabling dynamic storage management.

Example Output

sudo lvs

  LV      VG    Attr       LSize  Pool Origin Data%  Meta%  Move Log Cpy%Sync Convert
  data_lv my_vg -wi-a----- 10.00g

This output confirms the creation of data_lv within my_vg, showing its size and attributes. The -wi-a----- indicates it's a writable, active LV.

Pro Tip

Naming Conventions

Adopt clear naming conventions for your VGs and LVs (e.g., vg_apps, lv_webserver). This improves readability and manageability, especially in complex environments with many volumes.
