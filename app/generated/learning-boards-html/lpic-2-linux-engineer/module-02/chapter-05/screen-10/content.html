NFS Diagnostics

Common NFS Troubleshooting Techniques

Diagnosing Connectivity and Permission Issues

Firewall Blocks

Verify ports 111 (rpcbind) and 2049 (NFS) are open on both server and client.

`/etc/exports` Errors

Check syntax and permissions. Use sudo exportfs -v on server to see active exports.

Hostname Resolution

Ensure client and server can resolve each other's hostnames (check DNS or `/etc/hosts`).

Diagnostic Commands

  • showmount -e server_ip: View server's exported shares.
  • rpcinfo -p server_ip: Check RPC services on the server.
  • journalctl -u nfs-server: Review server logs for errors.
Key Takeaway

A systematic approach, starting with network connectivity and then configuration files, is key to efficient NFS troubleshooting.

Common Mistake

Overlooking underlying Linux file permissions on the exported directory, which can prevent access even if NFS is configured correctly.
