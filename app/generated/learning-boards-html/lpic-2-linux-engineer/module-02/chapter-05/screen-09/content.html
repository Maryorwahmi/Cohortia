NFS Client Setup

Accessing NFS Shares: Manual and Persistent Mounts

Connecting to Remote Filesystems from the Client

Client Package

Install `nfs-common` (Debian/Ubuntu) or `nfs-utils` (RHEL/CentOS) on the client machine.

Mount Point

Create a local directory on the client to serve as the mount point (e.g., `/mnt/nfs_mount`).

Mounting NFS Shares
Manual Mount
sudo mount -t nfs server_ip:/srv/nfs_share /mnt/nfs_mount

Temporary mount, lost on reboot.

Persistent Mount (`/etc/fstab`)
server_ip:/srv/nfs_share /mnt/nfs_mount nfs defaults 0 0

Add this line to `/etc/fstab` for automatic mounting at boot.

Key Takeaway

Always verify a successful mount using df -h /mnt/nfs_mount to see the mounted filesystem.
