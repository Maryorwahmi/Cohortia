NFS Server Operations

Activating and Securing NFS Exports

Applying Changes and Opening Firewall Ports

Step 1

Export Shares

After editing `/etc/exports`, run sudo exportfs -a to make the new shares available.

Step 2

Start NFS Service

Ensure the NFS server is running and enabled: sudo systemctl enable --now nfs-server.

Step 3

Configure Firewall

Allow NFS traffic through your firewall (e.g., ports 111, 2049, and RPC dynamic ports).

Warning

Incorrect firewall rules are a common cause of NFS connectivity failures. Always verify!

Key Takeaway

Always run exportfs -a and ensure firewall rules are correctly configured after any changes to NFS server settings.
