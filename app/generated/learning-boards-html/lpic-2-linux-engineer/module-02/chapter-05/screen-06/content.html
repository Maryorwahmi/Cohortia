NFS Server Setup

Defining NFS Shares with `/etc/exports`

Specifying Directories, Clients, and Permissions

Installation

Install `nfs-kernel-server` (Debian/Ubuntu) or `nfs-utils` (RHEL/CentOS) on the server.

`/etc/exports` File

The primary configuration file for NFS, defining shared directories, allowed clients, and export options.

Syntax Overview

Each line specifies: [Directory_to_Export] [Client(s)](Options)

Example: /etc/exports
/srv/nfs_share  192.168.1.0/24(rw,sync,no_subtree_check) # Share to network range
/home/users     client1.example.com(rw,sync,no_root_squash) # Specific client, root access
                client2.example.com(ro,sync) # Another client, read-only
Pro Tip

Always ensure the exported directory has appropriate Linux permissions for the `nfsnobody` user or specific users if `no_root_squash` is not used.
