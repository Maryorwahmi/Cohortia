NFS Configuration

Key NFS Export Options

Controlling Access, Performance, and Security

rw / ro

Read/Write: Allows clients to read and write. Read-Only: Restricts clients to only read files.

sync / async

Sync: Writes to disk before replying (safer). Async: Replies before writing (faster, less safe).

no_subtree_check

Disables subtree checking, recommended to avoid issues with moved subdirectories.

no_root_squash (Security Risk)

Disables mapping client's root user to `nfsnobody`, granting client root full privileges on the share. Use with extreme caution for trusted clients only.

root_squash (Default & Recommended)

Maps client's root user to `nfsnobody` on the server, significantly enhancing security by limiting root privileges on the share.

Common Mistake

Forgetting to restart NFS services or run `exportfs -a` after modifying `/etc/exports` will prevent changes from taking effect.
