Samba Server Setup

Defining Samba Shares with `/etc/samba/smb.conf`

Global Settings and Individual Share Configurations

Installation

Install the `samba` package on your Linux server.

Configuration File

`/etc/samba/smb.conf` is the main configuration file, divided into `[global]` and `[share_name]` sections.

Key Parameters

  • path: Directory to share.
  • browsable: Share visibility.
  • guest ok: Unauthenticated access.
  • valid users: Specific user access.
  • read only: Write access control.
Example: /etc/samba/smb.conf
[global]
    workgroup = WORKGROUP
    security = user

[public]
    comment = Public Share
    path = /srv/samba/public
    guest ok = yes
    read only = no

[private]
    comment = Private User Share
    path = /srv/samba/private/%U
    valid users = %U
    read only = no
Pro Tip

Always run testparm after editing smb.conf to check for syntax errors before restarting services.
