The Root Directory: Foundation of FHS

Understanding `/`, `/bin`, and `/sbin`

The Root (/)

The top-level directory, parent of all other files and directories. It's the starting point for the entire filesystem hierarchy.

/bin: Essential User Binaries

Contains commands like ls, cp, mv. Available to all users and crucial for basic system operations, even in single-user mode.

/sbin: Essential System Binaries

Contains commands like fdisk, mkfs, reboot. Primarily for system administration and often requires root privileges.

Key Takeaway

The root directory is the base, with /bin providing user essentials and /sbin providing system administration tools, often requiring elevated privileges.

Terminal Demo: Exploring Binaries
# List contents of root directory
ls /

bin   boot  dev   etc   home  lib   lib32  lib64  libx32  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var

# Find where 'ls' command is located
which ls

/usr/bin/ls

# Find where 'fdisk' command is located
which fdisk

/usr/sbin/fdisk

# Attempt to run fdisk without root (will likely fail)
fdisk -l

fdisk: cannot open /dev/sda: Permission denied

# Note: On modern systems, /bin and /sbin are often symlinks to /usr/bin and /usr/sbin respectively.
