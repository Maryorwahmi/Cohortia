Pseudo-Filesystems

`/proc`: Kernel and Process Information

Interacting with the Kernel's Data Structures

What is /proc?

A pseudo-filesystem (not disk-backed) that provides an interface to kernel data structures. It offers real-time information about running processes and kernel parameters.

Key Information Sources

  • /proc/cpuinfo: CPU details (model, cores).
  • /proc/meminfo: Memory information (total, free, swap).
  • /proc/[PID]: Information about specific processes.
Pro Tip

You can dynamically change some kernel parameters by writing to files in /proc/sys, allowing for real-time system tuning. Use with caution!

Key Takeaway

`/proc` is your window into the kernel's live state, providing critical data for monitoring and advanced system diagnostics.

Terminal Demo: Inspecting /proc
# Get CPU information
cat /proc/cpuinfo | grep 'model name' | uniq

model name      : Intel(R) Core(TM) i7-10750H CPU @ 2.60GHz

# Get memory information
cat /proc/meminfo | grep MemTotal

MemTotal:       16384000 kB

# List processes (example: PID 1 for systemd)
ls -l /proc/1

dr-xr-xr-x 9 root root 0 Aug 20 09:50 cmdline
dr-xr-xr-x 9 root root 0 Aug 20 09:50 cwd
-r-------- 1 root root 0 Aug 20 09:50 environ
