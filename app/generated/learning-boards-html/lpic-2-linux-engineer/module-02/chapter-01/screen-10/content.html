Pseudo-Filesystems

`/sys`: Structured Kernel Objects Interface

A Modern View into Hardware and Drivers

What is /sys?

A newer pseudo-filesystem providing a structured interface to kernel objects, devices, and drivers. It's organized hierarchically for easier programmatic access.

Key Information Sources

  • /sys/class/net: Network interfaces.
  • /sys/block: Block devices (disks).
  • /sys/devices: All system devices.
Pro Tip

`/sys` is often used by system utilities and scripts to query hardware status and configure device parameters, offering a more consistent API than `/proc` for certain tasks.

Key Takeaway

`/sys` provides a structured, object-oriented view of kernel components, making it invaluable for hardware and driver diagnostics and management.

Terminal Demo: Inspecting /sys
# List network interfaces detected by the kernel
ls -l /sys/class/net

total 0
lrwxrwxrwx 1 root root 0 Aug 20 09:50 eth0 -> ../../devices/pci0000:00/0000:00:1f.6/net/eth0
lrwxrwxrwx 1 root root 0 Aug 20 09:50 lo -> ../../devices/virtual/net/lo

# List block devices
ls -l /sys/block

total 0
lrwxrwxrwx 1 root root 0 Aug 20 09:50 sda -> ../devices/pci0000:00/0000:00:1f.2/ata1/host0/target0:0:0/0:0:0:0/block/sda
lrwxrwxrwx 1 root root 0 Aug 20 09:50 sdb -> ../devices/pci0000:00/0000:00:1f.2/ata2/host1/target1:0:0/1:0:0:0/block/sdb

# View a specific device property (example: sda's size)
cat /sys/block/sda/size

976773168
