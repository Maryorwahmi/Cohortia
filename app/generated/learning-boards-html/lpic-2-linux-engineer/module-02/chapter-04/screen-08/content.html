Viewing Quota Usage with repquota

Summarizing Current Quota Status and Identifying Overages

# Summary for all quota-enabled filesystems
sudo repquota -a
# Details for a specific filesystem
sudo repquota /home
  • •

    + symbol: User has exceeded their soft limit and is in a grace period.

  • •

    * symbol: User has hit their hard limit and cannot write more data.

Common Mistakes

Forgetting usrquota/grpquota in fstab, not running quotacheck, or setting limits too low, which can block users from saving work.

Interpreting `repquota` Output

User/Group Name

Identifies the entity whose quota is being reported.

Block/Inode Usage

Current disk space and file count used by the entity.

Soft/Hard Limits

The configured warning and absolute maximum thresholds.

Key Takeaway

repquota is vital for monitoring quota compliance and identifying users who are approaching or exceeding their defined limits.
