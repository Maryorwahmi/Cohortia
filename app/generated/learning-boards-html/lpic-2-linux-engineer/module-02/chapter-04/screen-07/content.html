Setting User and Group Quotas

Defining Soft and Hard Limits for Disk Usage

# Interactive editing for user 'johndoe'
sudo edquota -u johndoe
# Non-interactive setting for user 'johndoe'
sudo setquota -u johndoe 100000 110000 50000 55000 /home
# (soft blocks, hard blocks, soft inodes, hard inodes)
  • •

    edquota -u username: Opens an editor to set user quotas.

  • •

    edquota -g groupname: Opens an editor to set group quotas.

  • •

    setquota: For scripting, sets quotas non-interactively.

Pro-Tip

Use edquota -t to set grace periods for soft limits, allowing users time to reduce usage before the soft limit becomes enforced as a hard limit.

Quota Limit Types

Soft Limit (Warning)

A threshold that triggers a warning and starts a grace period. User can still write data temporarily.

Hard Limit (Absolute Max)

An absolute maximum. No more data can be written once this limit is reached, even if a grace period is active.

Key Takeaway

Soft limits provide warnings and grace periods, while hard limits enforce strict maximums on disk and inode usage.
