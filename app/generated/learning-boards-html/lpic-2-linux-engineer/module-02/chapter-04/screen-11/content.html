Applying and Modifying ACLs with setfacl

Granting Specific Permissions to Users and Groups

# Grant user2 read/write to my_shared_dir
sudo setfacl -m u:user2:rw- my_shared_dir
# Grant dev_team full access
sudo setfacl -m g:dev_team:rwx my_shared_dir
# Set default ACL for new files/dirs
sudo setfacl -m d:u:user3:r-x my_shared_dir
# Remove user2's ACL entry
sudo setfacl -x u:user2 my_shared_dir
  • •

    -m: Modify or add an ACL entry.

  • •

    u:: Specifies a user entry. g:: Specifies a group entry.

  • •

    d:: Prefix for setting default ACLs on directories (inherited by new items).

  • •

    -x: Remove a specific ACL entry.

ACL Command Syntax

Modify Entry
setfacl -m u:user:perms file/dir
Remove Entry
setfacl -x u:user file/dir
Recursive
setfacl -R -m u:user:perms dir
Key Takeaway

setfacl is the command-line utility for creating, modifying, and removing specific ACL entries for users and groups.
