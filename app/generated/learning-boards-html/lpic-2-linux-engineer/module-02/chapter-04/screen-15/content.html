Key Concepts: Part 2

Essential terms and definitions from this chapter

Access Control List (ACL)

Granular permission system beyond owner/group/others.

`getfacl`

Command to display ACLs for files and directories.

`setfacl`

Command to set or modify ACLs for files and directories.

ACL Mask

Defines max effective permissions for non-owner/group ACL entries.

Default ACL

ACL entries for a directory inherited by new files/subdirectories.

`acl` Mount Option

Required in `/etc/fstab` to enable ACL support on a filesystem.

Summary Insight

ACLs provide a powerful, flexible permission system for complex access control, using specific commands and concepts like the mask and default inheritance.
