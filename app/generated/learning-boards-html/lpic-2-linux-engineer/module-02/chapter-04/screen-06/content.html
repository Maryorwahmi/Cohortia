Initializing and Activating Disk Quotas

Setting Up the Quota Database and Enabling Enforcement

# Initialize quota database for /home
sudo quotacheck -cum /home
# Activate quotas for /home
sudo quotaon /home
  • •

    quotacheck: Scans the filesystem, calculates usage, and creates aquota.user/aquota.group files.

  • •

    -c: Creates new quota files. -u: Checks user quotas. -m: Prevents remounting as read-only.

  • •

    quotaon: Activates the quota system, starting enforcement of defined limits.

Common Mistake

Attempting to run quotaon before quotacheck has successfully created the quota database files. quotaon relies on these files to function.

Quota Activation Flow

1.Remount Filesystem
With usrquota/grpquota
2.Run quotacheck
Builds quota database
3.Run quotaon
Activates quota enforcement
Key Takeaway

quotacheck prepares the data, and quotaon enables the kernel to enforce the defined disk usage limits.
