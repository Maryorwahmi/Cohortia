Enabling Quota Support in fstab

Preparing Your Filesystem for Quota Management

# Example /etc/fstab entry
/dev/sdb1 /home ext4 defaults,usrquota,grpquota 0 2
  • •

    usrquota: Enables disk quotas for individual users on the filesystem.

  • •

    grpquota: Enables disk quotas for groups on the filesystem.

  • •

    These options tell the kernel to track disk usage for the specified entities.

Common Mistake

Forgetting to remount the filesystem after modifying /etc/fstab. The changes won't take effect until the filesystem is remounted or the system is rebooted.

Applying `fstab` Changes

Edit /etc/fstab

Add usrquota and/or grpquota to the options for the target filesystem.

Remount Filesystem
sudo mount -o remount /home

Applies new mount options without rebooting.

Key Takeaway

Modifying /etc/fstab and remounting the filesystem are the foundational steps to enable quota functionality.
