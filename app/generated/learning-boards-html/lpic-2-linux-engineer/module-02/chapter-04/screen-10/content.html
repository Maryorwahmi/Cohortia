Enabling ACLs and Viewing with getfacl

Activating ACL Support and Inspecting Current Permissions

# Check if ACLs are enabled for /home
mount | grep /home
# Display ACLs for a shared directory
getfacl my_shared_dir
# Example output for getfacl
# file: my_shared_dir
# owner: user1
# group: group1
user::rwx
group::r-x
other::r-x
  • •

    acl mount option: Must be present in /etc/fstab for ACL support.

  • •

    getfacl: Displays the Access Control List for a given file or directory.

Important Note

If acl is not enabled, add it to /etc/fstab and remount the filesystem (e.g., sudo mount -o remount /path).

ACL Inspection Flow

1.Verify ACL Mount Option
mount | grep /path
2.Use getfacl
getfacl filename
3.Interpret Output
Owner, Group, Specific ACLs
Key Takeaway

getfacl is the essential command for inspecting the detailed permission entries defined by ACLs on any file or directory.
