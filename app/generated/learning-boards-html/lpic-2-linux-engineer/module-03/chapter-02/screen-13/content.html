Systematic DNS Troubleshooting & Firewall Checks

A step-by-step approach to diagnosing and resolving DNS issues

Verify Configuration Files

Start by checking /etc/resolv.conf for correct nameservers and search domains.

Test Reachability & Resolution

ping nameservers, then use dig or host for external and internal hostnames.

Additional Checks
  • Firewall: Ensure outbound UDP/TCP port 53 traffic to DNS servers is allowed.
  • Local Resolvers: Check status of systemd-resolved or dnsmasq with systemctl status.
  • `nsswitch.conf` Safety: Always back up /etc/nsswitch.conf before editing, as incorrect changes can severely impact system functionality.
Key Takeaway

A systematic approach, combining configuration checks, reachability tests, and diagnostic tools, is crucial for efficient DNS troubleshooting.
