Key Concepts

Essential terms and ideas from this chapter

/etc/resolv.conf

The primary configuration file for DNS client settings, specifying nameserver IP addresses and search domains.

/etc/nsswitch.conf

Defines the order in which the system consults various sources (e.g., files, DNS) for information, including hostnames.

systemd-resolved

A system service that provides DNS resolution, caching, and supports various protocols, often acting as a local stub resolver.

dnsmasq

A lightweight DNS forwarder and DHCP server, often used for local DNS caching in small networks or embedded systems.

What to Remember

These core components work in concert to ensure your Linux system can reliably translate hostnames into IP addresses for all network communications.
