Troubleshooting DNS: Common Configuration Mistakes

Identifying frequent errors in DNS client setup

Incorrect Nameserver Entries

If DNS servers in resolv.conf are unreachable or wrong, resolution will fail. Always ping them to verify.

Missing Search Domains

Applications may fail to resolve internal hostnames if the correct search domain isn't appended in resolv.conf.

Scenario: Unexpected IP

You expect appserver to resolve to 10.0.0.50 via DNS, but it resolves to 192.168.1.100. Checking /etc/hosts reveals an old entry for appserver, which takes precedence due to nsswitch.conf.

Key Takeaway

Always check /etc/hosts when a hostname resolves to an unexpected IP, as it can override DNS due to the nsswitch.conf lookup order.
