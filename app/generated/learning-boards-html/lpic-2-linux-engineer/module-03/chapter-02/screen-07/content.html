The Role of /etc/nsswitch.conf

Controlling the hostname resolution lookup order

Name Service Switch

Defines the order in which the system consults various sources for information, including hostnames.

`hosts` Line Importance

The hosts: files dns entry means /etc/hosts is checked before DNS for hostname resolution.

# Example: /etc/nsswitch.conf snippet
hosts: files dns myhostname

If /etc/hosts has an entry for 'appserver', it will be used instead of DNS.

# /etc/hosts192.168.1.100 appserver# DNS server for appserver: 10.0.0.50

Result: appserver resolves to 192.168.1.100.

Key Takeaway

/etc/nsswitch.conf determines the lookup priority for hostnames, making /etc/hosts a powerful local override if configured before DNS.
