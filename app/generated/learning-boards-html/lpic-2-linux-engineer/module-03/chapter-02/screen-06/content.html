Managing /etc/resolv.conf Dynamically

Understanding how NetworkManager and DHCP clients interact with resolv.conf

Automated Updates

NetworkManager, systemd-resolved, or DHCP clients frequently update /etc/resolv.conf automatically.

Manual Edits Overwritten

Direct manual changes to /etc/resolv.conf are often temporary and can be lost upon network restarts or DHCP renewals.

# Persistent DNS Configuration via nmcli
# Identify connection name (e.g., 'eth0-static')nmcli connection show# Modify DNS servers and search domainnmcli connection modify eth0-static ipv4.dns "192.168.1.10 8.8.8.8" ipv4.dns-search "corp.example.com"# Activate the modified connectionnmcli connection up eth0-static

This method ensures your DNS settings persist.

Key Takeaway

For persistent DNS changes, always configure them through the network management service (e.g., NetworkManager) rather than directly editing /etc/resolv.conf.
