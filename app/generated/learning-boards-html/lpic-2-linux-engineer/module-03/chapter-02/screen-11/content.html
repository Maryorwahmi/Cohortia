Using nslookup for DNS Queries

An older, yet still widely used, command-line DNS tool

Basic Lookups

Performs standard DNS queries for A records and other types, similar to host.

Specify Nameserver

Allows you to direct queries to a specific DNS server, useful for testing server functionality.

# Examples of nslookup
# Basic lookupnslookup example.com# Query a specific nameservernslookup example.com 8.8.8.8# Enter interactive modenslookup

In interactive mode, you can type 'server 8.8.8.8' then 'example.com'.

Key Takeaway

nslookup is a valuable tool for basic DNS queries and testing specific nameservers, complementing the more detailed output of dig.
