Diagnose and Fix DNS Resolution Issues

A practical scenario to apply your troubleshooting skills

Scenario: DNS Failure

ping google.com and ping internalapp.corp.example.com both fail with "Temporary failure in name resolution".

Your Task

Inspect resolv.conf, test nameserver reachability, modify NetworkManager DNS settings, and verify resolution.

Activate the modified connectionnmcli connection up eth0-static# 5. Verify resolv.conf updatecat /etc/resolv.confresolvectl status # If systemd-resolved is active# 6.
