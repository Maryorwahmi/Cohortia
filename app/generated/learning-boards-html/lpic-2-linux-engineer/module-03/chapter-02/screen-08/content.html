Understanding systemd-resolved

The modern local DNS stub resolver for systemd-based systems

Local Stub Resolver

Provides DNS resolution, caching, and supports protocols like DNSSEC and LLMNR on systemd-based systems.

`127.0.0.53` Listener

When active, /etc/resolv.conf often points to this local address, where systemd-resolved listens for queries.

# Inspecting systemd-resolved
# Check service status and configurationresolvectl status# Query a hostname through systemd-resolvedresolvectl query example.com

systemd-resolved forwards queries to upstream DNS servers configured via NetworkManager or DHCP.

Key Takeaway

systemd-resolved centralizes DNS resolution and caching, acting as a local intermediary for all DNS queries on modern Linux systems.
