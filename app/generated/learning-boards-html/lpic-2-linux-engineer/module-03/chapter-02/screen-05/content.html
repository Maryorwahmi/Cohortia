The /etc/resolv.conf File

Defining nameservers and search domains for resolution

Nameserver Directive

Specifies IP addresses of DNS servers in order of preference. The system queries them sequentially until a response is received.

Search Directive

Defines a list of domains to append to unqualified hostnames. This simplifies resolution for internal network resources.

# Example: /etc/resolv.conf
nameserver 8.8.8.8nameserver 8.8.4.4search example.com corp.example.com

If you ping 'webserver', the system will try:

  • webserver.example.com
  • webserver.corp.example.com
  • webserver (as an absolute name)
Key Takeaway

/etc/resolv.conf is the central point for configuring DNS servers and search paths, directly influencing how your system resolves hostnames.
