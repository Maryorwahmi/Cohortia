Persistent Configuration: Debian & Netplan

Alternative Approaches to Network Persistence

Debian `/etc/network/interfaces`
auto eth0
iface eth0 inet static
    address 192.168.1.10
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4
Key Takeaway

Different distributions use distinct configuration files for persistence; `netplan` offers a modern, unified approach via YAML.

Netplan Configuration (`.yaml`)
network:
  version: 2
  renderer: NetworkManager
  ethernets:
    eth0:
      dhcp4: no
      addresses: [192.168.1.10/24]
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]
Applying Netplan Changes

After modifying a Netplan YAML file, apply the changes using sudo netplan apply. Netplan then generates the necessary backend configuration for NetworkManager or systemd-networkd.
