Configuring Bridging with `nmcli`

Setting Up a Virtual Switch for VMs

`nmcli` Bridging Commands
# 1. Create bridge master connection
nmcli connection add type bridge con-name mybridge ifname br0 ipv4.method manual ipv4.addresses 192.168.1.30/24 ipv4.gateway 192.168.1.1

# 2. Add eth0 as a slave port to the bridge
nmcli connection add type ethernet con-name eth0-bridge-slave ifname eth0 master mybridge

# 3. Activate the bridge connection
nmcli connection up mybridge

# 4. Verify bridge status
nmcli connection show mybridge
ip addr show br0
Key Takeaway

`nmcli` facilitates bridge creation by defining a master and adding physical interfaces as ports, enabling shared network access for VMs.

Bridging Process Flow
Step 1

Define Bridge Master (e.g., `br0`) with IP settings.

Step 2

Add Physical NIC (e.g., `eth0`) as a port to the bridge.

Step 3

Activate the Bridge Master connection.

Step 4

Configure VMs to use `br0` for network access.

Troubleshooting Tip

Always check system logs (`journalctl -u NetworkManager` or `dmesg`) for errors if a bridge fails to activate or function as expected.
