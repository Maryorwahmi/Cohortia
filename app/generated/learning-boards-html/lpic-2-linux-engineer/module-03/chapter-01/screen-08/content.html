Persistent Configuration: Red Hat Systems

Managing Network Settings with `ifcfg-*` Files

Example `ifcfg-eth0` File
TYPE=Ethernet
BOOTPROTO=static
NAME=eth0
DEVICE=eth0
ONBOOT=yes
IPADDR=192.168.1.10
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=8.8.8.8
Key Takeaway

`ifcfg-*` files provide granular, persistent control over network interfaces on Red Hat systems, but require service restarts to apply changes.

Key Parameters
  • `BOOTPROTO`: `static`, `dhcp`, `none`.
  • `ONBOOT`: `yes` to activate at boot, `no` otherwise.
  • `IPADDR`, `NETMASK`, `GATEWAY`: Define static IP settings.
  • `DNS1`, `DNS2`: Specify DNS servers.
  • `NAME`, `DEVICE`: Logical and physical interface names.
Applying Changes

After editing `ifcfg-*` files, you must restart the network service (`systemctl restart network`) or reload the specific NetworkManager connection (`nmcli connection reload && nmcli connection up my-eth0`) for changes to take effect.
