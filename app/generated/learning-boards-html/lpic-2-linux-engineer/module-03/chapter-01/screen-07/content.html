Managing Connections with `nmcli`

Scripting and Automating Network Configurations

Key `nmcli` Commands
# List all connections
nmcli connection show

# Add a new static Ethernet connection
nmcli connection add type ethernet ifname eth0 con-name my-eth0 ipv4.method manual ipv4.addresses 192.168.1.10/24 ipv4.gateway 192.168.1.1

# Modify an existing connection (e.g., add DNS)
nmcli connection modify my-eth0 ipv4.dns "8.8.8.8"

# Activate a connection
nmcli connection up my-eth0

# Deactivate a connection
nmcli connection down my-eth0
Key Takeaway

`nmcli` is essential for programmatic network management, offering granular control over connections for automation and server administration.

`nmcli` Workflow
  • Show: View existing connections and their states.
  • Add: Create new connection profiles for various network types.
  • Modify: Adjust parameters of existing connections.
  • Up/Down: Activate or deactivate connections to apply changes.
  • Delete: Remove unwanted connection profiles.
`nmtui` for Interactive Use

For those who prefer a text-based graphical interface, `nmtui` provides an interactive, menu-driven way to configure NetworkManager connections. It's user-friendly for quick, manual adjustments without needing to remember complex `nmcli` syntax.
