Configuring Bonding with `nmcli`

Step-by-Step `active-backup` Mode Implementation

`nmcli` Bonding Commands
# 1. Create bond master connection (active-backup mode)
nmcli connection add type bond con-name mybond ifname bond0 mode active-backup ipv4.method manual ipv4.addresses 192.168.1.20/24 ipv4.gateway 192.168.1.1

# 2. Add eth0 as a slave to the bond
nmcli connection add type ethernet con-name eth0-slave ifname eth0 master mybond

# 3. Add eth1 as a slave to the bond
nmcli connection add type ethernet con-name eth1-slave ifname eth1 master mybond

# 4. Activate the bond connection
nmcli connection up mybond

# 5. Verify bond status
nmcli connection show mybond
ip addr show bond0
Key Takeaway

`nmcli` simplifies bonding setup by defining a master connection and attaching physical interfaces as slaves, enabling robust failover.

Bonding Process Flow
Step 1

Define Bond Master (e.g., `bond0`) with desired mode.

Step 2

Add Physical NICs (e.g., `eth0`, `eth1`) as slaves.

Step 3

Activate the Bond Master connection.

Step 4

Verify connectivity and failover functionality.

Important Note

Ensure physical interfaces intended for bonding are not already configured with IP addresses; the bond master will manage their IP settings.
