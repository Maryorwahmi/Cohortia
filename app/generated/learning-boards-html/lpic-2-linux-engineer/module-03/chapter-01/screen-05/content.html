Temporary IP Configuration with `ip`

Assigning Addresses and Managing Interface States

Command Syntax
# Assign IP address
ip addr add 192.168.1.10/24 dev eth0

# Bring interface up
ip link set eth0 up

# Bring interface down
ip link set eth0 down

# Verify configuration
ip addr show eth0
Key Takeaway

`ip` command changes are immediate but temporary; they do not persist across reboots without additional configuration.

Important Considerations
  • Non-Persistent: Changes are lost after a reboot.
  • Immediate Effect: Useful for testing and troubleshooting.
  • Device Naming: `eth0`, `enp0s3`, etc., refer to specific network interfaces.
  • CIDR Notation: `/24` specifies the subnet mask (e.g., 255.255.255.0).
Common Mistake

Forgetting that `ip` command changes are temporary. Always remember to implement persistent configuration methods for production systems to avoid network downtime after a reboot.
