Interface Inspection

Understanding Network Interfaces with ip link and ip addr

Verifying Physical and Logical Connectivity

# Display status of all network interfaces
ip link show

# Show IP addresses and details for interfaces
ip addr show

`ip link show` Output

  • `UP`/`DOWN`: Interface is administratively up or down.
  • `BROADCAST`, `MULTICAST`: Capabilities of the interface.
  • `NO-CARRIER`: Critical indicator of a physical link issue (e.g., cable unplugged, faulty hardware).
  • `state UP`: Interface is up and has a physical link.

`ip addr show` Output

  • `inet`: IPv4 address, netmask (e.g., `192.168.1.10/24`).
  • `brd`: Broadcast address.
  • `scope global`: Indicates a publicly routable address.
  • `link/ether`: MAC address of the interface.
  • Verify: Correct IP, netmask, and that the interface is assigned an IP.

Common Mistake: Overlooking `NO-CARRIER`

Many network issues are as simple as a disconnected cable. Always check `ip link show` for `NO-CARRIER` before diving into complex software diagnostics.

Key Takeaway

`ip link show` confirms physical link status, while `ip addr show` verifies logical IP configuration. These are fundamental checks for any network problem.
