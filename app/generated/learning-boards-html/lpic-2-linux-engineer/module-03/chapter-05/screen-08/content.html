Routing & Local Resolution

Examining Routing Tables and ARP with ip route and ip neigh

Ensuring Correct Packet Forwarding and Local Mapping

# Display the routing table
ip route show

# Show the ARP cache
ip neigh show

`ip route show` Output

  • `default via dev `: The default gateway for traffic to unknown networks. Crucial for internet access.
  • `link-local`: Routes for local network communication.
  • `src `: Specifies the source IP for packets.
  • Verify: The default gateway is present and points to the correct router.

`ip neigh show` Output

  • `ip_address dev interface lladdr mac_address REACHABLE`: A successful ARP entry.
  • `FAILED`: Indicates ARP resolution failed for that IP.
  • `STALE`: Entry is old and needs re-validation.
  • Verify: Correct IP-to-MAC mappings for local devices you expect to communicate with.

Analogy: The Post Office

The routing table is like the post office's rulebook for where to send letters. The ARP cache is like a local directory, telling the postman exactly which house (MAC address) corresponds to a street address (IP address) on his route.

Key Takeaway

Correct routing ensures packets reach their destination, while a healthy ARP cache is vital for successful local network communication. Both are critical for full connectivity.
