Testing Reachability with ping

Your First Line of Network Defense

# Basic ping to a hostname
ping -c 4 google.com

# Ping to an IP address
ping -c 4 8.8.8.8

# Ping from a specific interface
ping -c 4 -I eth0 192.168.1.1

Interpreting Ping Results

  • Success: Host is reachable, basic connectivity is good.
  • `ping google.com` fails, `ping 8.8.8.8` succeeds: Indicates a DNS resolution issue.
  • `ping 8.8.8.8` fails: Points to a deeper network problem (routing, firewall, physical).
  • `Destination Host Unreachable`: Often a routing issue or host is down.

Key Concept: ICMP

`ping` uses the Internet Control Message Protocol (ICMP) to send Echo Request packets and listen for Echo Reply. ICMP is also used for error reporting and operational information within the network.

Pro Tip: DNS vs. Connectivity

Always test both the hostname and its corresponding IP address. This quick check helps you differentiate between a DNS problem and a fundamental network path issue.

Key Takeaway

`ping` is your initial diagnostic tool. Its success or failure, especially when comparing hostname to IP, provides immediate clues about network reachability and DNS health.
