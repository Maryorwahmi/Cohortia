Capturing and Analyzing Network Traffic with tcpdump

Uncovering the Details of Network Communication

# Capture traffic on eth0 for host 192.168.1.100 on port 80
tcpdump -i eth0 host 192.168.1.100 and port 80

# Capture SSH traffic, no name resolution, very verbose, show hex/ASCII
tcpdump -i eth0 -nn -vvv -X port 22

# Capture to a file for later analysis with Wireshark
tcpdump -i eth0 -w capture.pcap

Key Flags for `tcpdump`

  • `-i `: Specify the network interface to capture on.
  • `host `: Filter traffic to/from a specific host.
  • `port `: Filter traffic on a specific port.
  • `-nn`: Don't resolve hostnames or port names (faster, clearer).
  • `-vvv`: Very verbose output (more protocol details).
  • `-X`: Show packet data in hex and ASCII.
  • `-w `: Write captured packets to a file.

What `tcpdump` Reveals

  • Are packets reaching your server?
  • Are responses being sent out?
  • Are there any unexpected protocols or malformed packets?
  • Is a firewall silently dropping packets?

Safety Note: Sensitive Data

`tcpdump` can capture sensitive information (passwords, private data) if not used carefully, especially on unencrypted networks. Always ensure you have proper authorization and understand the implications before capturing traffic on production networks.

Key Takeaway

`tcpdump` is the ultimate tool for deep network analysis, providing raw packet visibility to diagnose complex issues, but requires careful use due to potential data exposure.
