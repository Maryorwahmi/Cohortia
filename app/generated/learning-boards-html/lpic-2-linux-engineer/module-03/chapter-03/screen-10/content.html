Implementing and Persisting iptables Rules

Add rules to iptables chains and ensure they persist across reboots using save/restore mechanisms.

Blocking SSH from a Specific IP
iptables -A INPUT -s 192.168.1.50 -p tcp --dport 22 -j DROP

This rule appends to the INPUT chain, blocking TCP port 22 (SSH) from 192.168.1.50.

Making Rules Persistent (Red Hat)
iptables-save > /etc/sysconfig/iptables
systemctl enable iptables.service
systemctl start iptables.service
Key Flags Explained

-A (Append), -s (Source IP), -p (Protocol), --dport (Destination Port), -j (Jump/Target).

Persistence Mechanisms

iptables-save: Dumps current rules to a file.

iptables-restore: Loads rules from a file.

iptables-services: (Red Hat) Manages saving/restoring rules automatically.

netfilter-persistent: (Debian) Package for rule persistence.

Critical Reminder

Always save your iptables rules after making changes, or they will be lost upon system reboot.
