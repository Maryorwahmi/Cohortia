Introducing Firewalld: Zones and Abstraction

Firewalld uses zones to define security policies based on network environments, simplifying management.

Key Concepts of Firewalld
  • •
    Zone-Based Management: Assigns network interfaces to predefined security zones.
  • •
    Dynamic Updates: Allows changes without dropping existing connections.
  • •
    Default on Modern Linux: Standard on RHEL, CentOS, Fedora.
  • •
    Services & Ports: Easily manage allowed services (e.g., SSH, HTTP) and specific ports.
Practical Example

Assigning a server's external interface to the public zone automatically applies a restrictive default policy, enhancing security with minimal effort.

Common Firewalld Zones

Public

Untrusted networks, blocks most traffic.

Home

Trusted home network, more permissive.

Internal

Internal network, trusted by default.

DMZ

Demilitarized Zone, limited public access.

Common Pitfall

Failing to verify which zone a network interface is assigned to can lead to unintended exposure or blocked legitimate traffic.
