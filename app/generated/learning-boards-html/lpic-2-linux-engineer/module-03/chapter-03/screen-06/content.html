Managing Firewalld with firewall-cmd

Use firewall-cmd to configure zones, add services, and open ports, ensuring persistent changes with --permanent and --reload.

Common firewall-cmd Operations
# Check active zones
firewall-cmd --get-active-zones

# List services in public zone
firewall-cmd --zone=public --list-services

# Allow SSH permanently in public zone
firewall-cmd --zone=public --add-service=ssh --permanent

# Open specific port permanently
firewall-cmd --zone=public --add-port=8080/tcp --permanent

# Apply permanent changes
firewall-cmd --reload
Key Flags

--permanent ensures rules persist across reboots. --reload applies permanent changes without restarting the service, preventing connection drops.

Firewalld Workflow
1

Identify Zone: Determine the appropriate zone for your network interface (e.g., public, home).

2

Add Rule: Use --add-service or --add-port to allow traffic.

3

Make Permanent: Include --permanent to save the rule.

4

Apply Changes: Run firewall-cmd --reload to activate new rules.

5

Verify: Use --list-all or --list-services to confirm rules.

Important Note

Forgetting --permanent means your rules will disappear after a reboot, leaving your system potentially exposed or inaccessible.
