iptables Fundamentals: Chains and Targets

iptables directly interacts with Netfilter, using chains and tables for granular packet filtering.

Listing iptables Rules
iptables -L -n -v

This command lists all current iptables rules with numeric output and verbose details.

Key Components
  • •
    Tables: Categories of rules (e.g., filter, nat, mangle).
  • •
    Chains: Ordered lists of rules within tables (e.g., INPUT, OUTPUT, FORWARD).
  • •
    Rules: Criteria + action for packet matching.
  • •
    Targets: Action to take if a rule matches (e.g., ACCEPT, DROP, REJECT).
Practical Application

Blocking all incoming SSH traffic from a specific IP address requires a precise iptables rule targeting the INPUT chain.

iptables Packet Flow
1

Packet Arrives: Network packet enters the system.

2

PREROUTING Chain: Packet processed before routing decision.

3

INPUT Chain: For packets destined for the local system.

4

FORWARD Chain: For packets routed through the system.

5

OUTPUT Chain: For packets generated by the local system.

6

POSTROUTING Chain: Packet processed after routing decision.

Critical Rule

The order of iptables rules is crucial; specific DROP rules must precede general ACCEPT rules to be effective.
