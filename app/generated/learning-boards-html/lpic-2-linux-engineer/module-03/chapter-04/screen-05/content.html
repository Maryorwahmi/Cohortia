Inspecting the Routing Table

Using ip route show to understand network paths

default via 192.168.1.1 dev eth0 proto dhcp metric 100
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.10 metric 100
10.0.0.0/8 via 192.168.1.254 dev eth0
Key Takeaway

The `ip route show` command is your window into the Linux kernel's routing decisions, displaying all active routes, their gateways, and associated interfaces.

Default Route

The 'catch-all' route for all traffic not matching a more specific entry. Essential for external network access.

Specific Network Route

Defines paths to particular network segments, often directly connected or via a specific gateway.

Gateway (via)

The IP address of the next-hop router to which packets are sent to reach a destination network.

Interface (dev)

The network interface (e.g., eth0) through which packets are sent to reach the next hop or destination.
