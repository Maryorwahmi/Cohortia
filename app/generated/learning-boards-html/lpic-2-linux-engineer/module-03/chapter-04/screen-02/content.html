Principles of IP Routing

Understand how IP routing directs packets between networks, including the role of routing tables and network masks. This knowledge is foundational for all network communication.

Static Route Configuration

Configure temporary static routes using the `ip route add` command for specific network paths. This skill allows precise control over traffic flow to isolated networks.

Verified Competency Milestone
03

Default Gateway Management

Manage and troubleshoot the default gateway setting, understanding its critical role in external connectivity. A correctly configured gateway is vital for internet access.

Verified Competency Milestone
04

Routing Table Interpretation

Interpret entries in the Linux routing table using `ip route show` to identify network paths. This skill is crucial for diagnosing and understanding network connectivity.
