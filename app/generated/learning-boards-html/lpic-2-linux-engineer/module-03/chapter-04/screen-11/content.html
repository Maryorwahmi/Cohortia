Beyond Destination: Policy Routing

Making routing decisions based on more than just destination IP

Definition

An advanced routing technique that allows decisions to be made based on criteria beyond just the destination IP address.

Criteria

Can include source IP, protocol, user ID, or even specific network interfaces.

Implementation

Achieved using multiple routing tables and `ip rule` commands to define the decision logic.

Key Takeaway

Policy routing offers granular control over traffic flow, enabling complex routing scenarios based on various packet attributes beyond just destination.
