Making Routes Permanent

Ensuring routing configurations survive reboots

01

NetworkManager (nmcli)

Use nmcli connection modify <interface> +ipv4.routes "<network> <gateway>" to add persistent routes to connection profiles.

02

Red Hat-based Systems

Define static routes in /etc/sysconfig/network-scripts/route-<interface-name> files, e.g., 172.16.0.0/16 via 192.168.1.254.

03

Debian-based Systems

Add static routes to /etc/network/interfaces within the interface stanza or in separate sourced files.

Key Takeaway

Ensuring routing configurations are persistent is crucial for network stability, requiring specific commands or file edits based on the Linux distribution and network management tools.
