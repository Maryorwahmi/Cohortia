The Essential Default Gateway

Connecting to the wider internet

Definition

The IP address of the router to which all traffic for unknown destinations (outside the local network) is sent.

Importance

Crucial for external network connectivity; without it, a server can only communicate within its local segment.

ip route add default via 192.168.1.1 dev eth0
Key Takeaway

A single, correctly configured default gateway is paramount for a Linux server to reach any network beyond its immediate local segment.
