Directing Traffic with Static Routes

Manually defining specific network paths

ip route add 172.16.0.0/16 via 192.168.1.254 dev eth0
Key Takeaway

The `ip route add` command allows you to create static routes for specific networks, but these changes are temporary and require additional configuration for persistence.

Destination Network

The IP network (e.g., 172.16.0.0/16) that this route applies to.

Gateway IP (via)

The IP address of the next-hop router that will forward traffic to the destination network.

Outgoing Interface (dev)

The local network interface through which the gateway is reachable.

Important Note

Routes added with `ip route add` are temporary and will be lost upon system reboot. Persistence requires additional configuration.
