Executing Repairs

Performing Actions within chroot

Binding Virtual Filesystems and Executing Commands

Bind Virtual Filesystems

Mount `/dev`, `/proc`, and `/sys` from the live environment into the `/mnt` directory to provide essential system information.

Enter `chroot` Environment

Execute `sudo chroot /mnt` to switch your root directory to your installed system, allowing you to run commands as if you were booted normally.

Perform Repairs & Exit

Run necessary commands (e.g., `passwd root`, `grub-install`), then `exit` the `chroot` and unmount all partitions in reverse order.

# Chroot Sequence
# Mount virtual filesystems
sudo mount --bind /dev /mnt/dev
sudo mount --bind /proc /mnt/proc
sudo mount --bind /sys /mnt/sys

# Enter chroot
sudo chroot /mnt

# Inside chroot (e.g., reset root password)
passwd root

# Exit chroot
exit

# Unmount in reverse order
sudo umount /mnt/sys /mnt/proc /mnt/dev
sudo umount /mnt/boot # If applicable
sudo umount /mnt

# Reboot
sudo reboot
Key Takeaway

Binding virtual filesystems is crucial for `chroot` functionality; always unmount cleanly before rebooting to prevent issues.
