Minimal Boot Environments

Single-User Mode & Rescue Target

Diagnosing Post-Kernel Boot Failures

Single-User Mode (`single`)

Boots to a minimal shell, often requiring the root password. Useful for inspecting logs, checking `fstab`, and manually starting/stopping services. Less structured than `rescue.target`.

Usage:
# Append to kernel line in GRUB:
linux ... single

Rescue Target (`systemd.unit=rescue.target`)

A `systemd` target that boots to a minimal environment, providing a root shell. It's the modern equivalent of single-user mode, offering more controlled services.

Usage:
# Append to kernel line in GRUB:
linux ... systemd.unit=rescue.target
Key Takeaway

Both modes provide a minimal environment for system maintenance, but `rescue.target` is generally preferred on `systemd` systems for its structured approach.
