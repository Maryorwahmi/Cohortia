Manually Booting with GRUB Rescue

Setting Variables, Loading Modules, and Initiating Boot

Set Root & Prefix

Define the GRUB root partition and the prefix path to the GRUB directory (e.g., /boot/grub).

Load Modules

Use insmod to load necessary modules like normal, linux, and filesystem-specific modules (e.g., ext2, ext4).

Load Kernel & Initramfs

Specify the kernel image (vmlinuz) and the initial RAM filesystem (initrd.img) with their full paths.

Key Takeaway

The `boot` command initiates the system startup after all necessary GRUB components and kernel images are manually loaded.

# Manual GRUB Boot Sequence
grub rescue> set root=(hd0,msdos1)
grub rescue> set prefix=(hd0,msdos1)/boot/grub

grub rescue> insmod normal
grub rescue> insmod linux
grub rescue> insmod ext2 # Or ext4, etc.

grub rescue> linux /boot/vmlinuz-5.15.0-76-generic root=/dev/sda1 ro
grub rescue> initrd /boot/initrd.img-5.15.0-76-generic

grub rescue> boot
# System should now attempt to boot
Common Mistake

Forgetting to load filesystem-specific modules (e.g., `ext2`, `ext4`) can prevent GRUB from reading the kernel or initramfs files.
