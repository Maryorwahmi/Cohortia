Deep Dive into Modules with `modinfo`

Retrieving Comprehensive Information for Specific Kernel Modules

Terminal Output
$ modinfo iwlwifi
filename:       /lib/modules/5.15.0-76-generic/kernel/drivers/net/wireless/intel/iwlwifi/iwlwifi.ko
description:    Intel(R) Wireless WiFi driver for Linux
license:        GPL
author:         Intel Corporation
srcversion:     A1B2C3D4E5F6G7H8I9J0
alias:          pci:v00008086d00002723sv*sd*bc*sc*i*
...
parm:           11n_disable:Disable 11n functionality (int)
parm:           power_save:enable power saving (bool)
Output shows module details and configurable parameters.

Key Information Provided

  • filename: Path to the module file.
  • description: What the module does.
  • license: Licensing terms.
  • parm: List of configurable parameters and their types.
Practical Use

Use modinfo to identify module parameters for fine-tuning hardware behavior or troubleshooting driver issues.

Key Takeaway

modinfo is indispensable for understanding a module's capabilities and configuration options, crucial for advanced system management.
