Ensuring Modules Load at Boot

Configuring Persistent Module Loading with `/etc/modules-load.d/`

/etc/modules-load.d/
Step 1

Create a .conf file (e.g., virtualbox.conf).

Step 2

Add module name(s) to the file, one per line (e.g., vboxdrv).

Step 3

systemd-modules-load.service reads these files at boot.

Key Takeaway

Using /etc/modules-load.d/ is the standard and most reliable way to ensure kernel modules are loaded automatically at every system boot.
