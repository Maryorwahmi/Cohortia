Unloading Kernel Modules with `rmmod`

Safely Removing Modules from the Running Kernel

rmmod <module>
Check Usage & Dependencies
Unload Module

Failure Conditions

  • Module in use: Cannot unload if actively used by a process.
  • Dependencies: Fails if other modules depend on it.
Common Mistake

Attempting to rmmod a module that is still in use will result in an error. Ensure all dependent processes or modules are stopped first.

Example

To unload the loop module: sudo rmmod loop. This will only succeed if no processes are using it.

Key Takeaway

rmmod provides dynamic module removal, but requires careful attention to module usage and dependencies to prevent errors.
