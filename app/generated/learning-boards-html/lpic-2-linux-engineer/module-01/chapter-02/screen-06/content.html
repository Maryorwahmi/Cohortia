Identifying Loaded Modules with `lsmod`

Viewing Active Kernel Modules, Their Size, and Dependencies

Terminal Output
$ lsmod
Module                  Size  Used by
fuse                  139264  3
xt_conntrack           16384  1
nf_conntrack          172032  1 xt_conntrack
nf_defrag_ipv6         24576  1 nf_conntrack
nf_defrag_ipv4         16384  1 nf_conntrack
ip_tables              36864  1
x_tables               45056  3 xt_conntrack,ip_tables
loop                   36864  0
vboxdrv               532480  0
iwlwifi               380928  0
cfg80211              720896  1 iwlwifi
...
Output shows module name, memory size, use count, and dependent modules.

Understanding Columns

  • Module: Name of the kernel module.
  • Size: Memory footprint in bytes.
  • Used by: Number of other modules or processes using it.
  • Dependencies: List of modules that rely on this one.
Pro-Tip

Use lsmod | grep <module_name> to quickly filter and find specific modules, e.g., lsmod | grep vboxdrv.

Key Takeaway

lsmod is essential for a quick overview of active kernel components, aiding in system diagnostics and resource management.
