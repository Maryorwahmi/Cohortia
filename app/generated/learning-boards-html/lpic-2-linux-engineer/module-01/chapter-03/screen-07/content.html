Configuration Tools

Efficient Kernel Configuration: oldconfig and defconfig

Streamlining your configuration workflow

make oldconfig

Uses an existing .config file and prompts only for new options. Ideal for minor updates or replicating setups.

make defconfig

Generates a default configuration for your architecture. Useful for starting from scratch with a sensible baseline.

make localmodconfig

Creates a configuration based on currently loaded modules, aiming for a minimal kernel. Be cautious of missing inactive drivers.

Example: Using make oldconfig
cd /usr/src/linux-<version>
cp /boot/config-$(uname -r) ./.config
make oldconfig
Key Takeaway

Choose the right configuration tool to efficiently manage kernel options, whether updating an existing setup or starting fresh.

Why it matters

These tools significantly reduce the manual effort and potential for errors when configuring a kernel, making the process more manageable.
