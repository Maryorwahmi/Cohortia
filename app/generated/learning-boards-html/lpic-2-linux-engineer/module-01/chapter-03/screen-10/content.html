The Build Process

Compiling and Installing the Kernel

Bringing your custom kernel to life

make bzImage

Compiles the compressed kernel image. Use -j$(nproc) for parallel compilation to speed up the process.

make modules

Compiles all selected kernel modules. These are dynamically loadable components.

sudo make modules_install

Installs compiled modules into /lib/modules/<kernel-version>, making them available to the system.

sudo make install

Installs the kernel image, System.map, and .config to /boot/, and updates GRUB2.

Key Takeaway

The kernel build process is a sequential series of make commands that compile and install the kernel image and its modules.

Example: Full Build Sequence
cd /usr/src/linux-<version>
make -j$(nproc) bzImage
make -j$(nproc) modules
sudo make modules_install
sudo make install
