Critical Warning

Avoiding Common Configuration Mistakes

Ensuring a bootable and functional system

Disabling Essential Drivers

A common mistake is disabling drivers for storage controllers (e.g., SATA, NVMe) or root filesystems (e.g., EXT4, XFS).

Unbootable System Risk

Without critical drivers, the kernel cannot access the root filesystem, leading to boot failures or kernel panics.

Key Takeaway

Always ensure essential drivers for your root filesystem and boot device are either built-in or included in the initramfs.

Pro-Tip: Safe Configuration Strategy

Start with a known-good .config (e.g., from your current running kernel) and make incremental changes. Test thoroughly after each significant modification.

Example: Critical Options
# Ensure these are 'y' or 'm' (and in initramfs)
CONFIG_EXT4_FS=y
CONFIG_SCSI_SAS_HOST_SMP=y
CONFIG_ATA_PIIX=y
