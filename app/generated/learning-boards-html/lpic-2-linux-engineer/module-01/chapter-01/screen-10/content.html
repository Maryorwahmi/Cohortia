systemd Architecture

systemd Units: Building Blocks of System State

Configuration files that define how systemd manages various system resources.

.service Units

Manage background processes (daemons) like web servers (e.g., nginx.service).

.mount Units

Control filesystem mount points (e.g., home.mount for /home partition).

.device Units

Represent hardware devices, allowing systemd to manage their state and dependencies.

Unit Relationships

Pro Tip

.target units are special, grouping other units to define a specific system state, similar to runlevels.
