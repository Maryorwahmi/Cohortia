Core Concept

Firmware Initialization: BIOS and UEFI

The foundational layer that prepares hardware for the operating system.

BIOS (Basic Input/Output System)

Traditional firmware, limited to 16-bit mode, uses MBR for boot, and has slower boot times.

UEFI (Unified Extensible Firmware Interface)

Modern replacement, supports 64-bit mode, uses GPT and EFI System Partition (ESP), offers faster boot and more features.

Key Takeaway

Firmware (BIOS/UEFI) is the critical first step, performing hardware checks and initiating the bootloader, setting the stage for the OS.
