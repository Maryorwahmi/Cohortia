System States

systemd Targets: Defining System Runlevels

Groups of units that define a specific system state or operational environment.

multi-user.target

Provides a command-line interface with full networking capabilities. Ideal for servers.

graphical.target

Includes all services for a graphical desktop environment, building upon multi-user.target.

Key Takeaway

systemd targets provide a flexible and robust way to define and manage system states, crucial for both server and desktop environments.

Command Examples
# Check the default target
systemctl get-default

# Switch to a different target (e.g., multi-user)
systemctl isolate multi-user.target

# Set a new default target
sudo systemctl set-default graphical.target
Safety Note

Always be cautious when changing the default target. An inaccessible target can prevent correct booting.
