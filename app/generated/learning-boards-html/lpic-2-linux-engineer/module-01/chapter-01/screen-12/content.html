Hands-on: Customizing GRUB2 Parameters

Modify GRUB2 to add a custom kernel parameter for debugging purposes.

01Edit /etc/default/grub

Open the file and locate GRUB_CMDLINE_LINUX_DEFAULT. Add systemd.debug to enable verbose systemd output.

02Update GRUB2 Configuration

Run sudo update-grub to regenerate grub.cfg with your changes. This makes the new parameter active.

03Verify Changes

Reboot your system. Observe the boot process for verbose systemd output, or check /proc/cmdline after booting.

Terminal Demo
# Open GRUB default configuration
sudo nano /etc/default/grub

# --- Content of /etc/default/grub ---
# GRUB_CMDLINE_LINUX_DEFAULT="quiet splash"
# Change to:
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash systemd.debug"
# -----------------------------------

# Update GRUB configuration
sudo update-grub

# Expected output:
# Generating grub configuration file ...
# Found linux image: /boot/vmlinuz-...
# ... done

# Reboot to apply changes
sudo reboot
Real-world Connection

Adding kernel parameters is a common technique for debugging boot issues, enabling specific hardware features, or configuring system behavior.
