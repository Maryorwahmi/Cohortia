Hands-on: Rebuilding the initramfs Image

Force a rebuild of the initramfs to ensure specific modules are included or to fix corruption.

01Identify Current Kernel

Use uname -r to get the exact kernel version. This is important for targeting the correct initramfs.

02Rebuild initramfs

Execute sudo update-initramfs -u -k $(uname -r) (Debian/Ubuntu) or sudo mkinitcpio -P (Arch Linux).

03Verification

Ensure the command completes without errors. The new image will be in /boot. Reboot to test.

Terminal Demo
# Get current kernel version
uname -r
# Example output: 5.15.0-76-generic

# Rebuild initramfs for this kernel
sudo update-initramfs -u -k $(uname -r)

# Expected output:
# update-initramfs: Generating /boot/initrd.img-5.15.0-76-generic
# ...

# (Optional) Inspect the new image (Debian/Ubuntu)
lsinitramfs /boot/initrd.img-$(uname -r)

# Reboot to test the new initramfs
sudo reboot
Why it matters

A correct initramfs is vital for systems with complex storage configurations (e.g., LVM, encrypted disks) to boot successfully.
