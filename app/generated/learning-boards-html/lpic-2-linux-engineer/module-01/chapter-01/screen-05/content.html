Bootloader Deep Dive

GRUB2: Multi-Stage Boot Process

The Grand Unified Bootloader orchestrates the loading of your operating system.

01Stage 1: Initial Load

Resides in MBR (BIOS) or ESP (UEFI). Its tiny code loads Stage 2.

02Stage 2: Core Functionality

Located in /boot. Presents the boot menu and loads the kernel and initramfs.

Key Takeaway

GRUB2's multi-stage design ensures flexibility and resilience, allowing it to manage diverse boot environments and operating systems.
