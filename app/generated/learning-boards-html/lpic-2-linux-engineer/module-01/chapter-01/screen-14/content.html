Key Concepts: Core Boot Components

A quick review of the most important terms from this chapter.

BIOS/UEFI

Firmware responsible for initial hardware checks (POST) and loading the first stage of the bootloader.

GRUB2

The default bootloader for most Linux distributions, presenting boot options and loading the kernel.

grub.cfg

The primary configuration file for GRUB2, typically generated automatically by grub-mkconfig.

initramfs

Initial RAM filesystem, a temporary root filesystem loaded by GRUB2 to provide necessary drivers.

Summary Takeaway

The Linux boot process is a carefully orchestrated sequence, starting with firmware, transitioning to the bootloader, and relying on initramfs to prepare the environment for the kernel.
