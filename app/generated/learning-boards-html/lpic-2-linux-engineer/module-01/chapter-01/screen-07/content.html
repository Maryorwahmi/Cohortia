Critical Component

The Initial RAM Filesystem (initramfs)

A temporary root filesystem essential for mounting the real root.

What is initramfs?

A small, compressed filesystem image loaded into RAM. It provides a temporary root environment.

Why is it needed?

The kernel might lack built-in drivers for the root filesystem's disk controller or type (e.g., LVM, RAID).

Key Takeaway

initramfs is a vital bridge, loading necessary drivers to enable the kernel to find and mount the real root filesystem, ensuring a successful boot.
