Key Concepts: NFS Configuration & Management

Files and Commands for Server and Client

/etc/exports

The configuration file on the NFS server defining exported directories and access options.

exportfs

A command-line utility to manage NFS exports, refreshing the server's export table.

mount -t nfs

The command used on the client to mount a remote NFS share to a local directory.

Summary Takeaway

Effective NFS administration relies on understanding and correctly using /etc/exports for server configuration, and exportfs, showmount, and mount for client interaction.
