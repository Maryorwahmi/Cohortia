Architecture Overview

The Client-Server Model of NFS

How Clients and Servers Communicate for File Access

NFS Server Role

Exports directories, making them available over the network for clients to access.

NFS Client Role

Mounts exported directories, integrating remote files into its local filesystem.

Key Takeaway

The client-server model, powered by RPCs, allows NFS to provide transparent remote file access.

NFS Communication Flow
Client
Server
1. Mount Request (RPC)
2. File Operation (RPC)
3. Data Transfer (RPC)
Understanding RPC

Remote Procedure Calls (RPCs) are the core communication mechanism. They allow a client to execute a procedure on a remote server as if it were a local procedure, abstracting network details.
