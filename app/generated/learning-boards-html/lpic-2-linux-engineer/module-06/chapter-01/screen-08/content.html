Activating NFS Exports and Services

Using exportfs and systemctl to Apply Changes

Apply /etc/exports Changes

The exportfs -arv command re-reads and applies all export definitions from /etc/exports.

Manage NFS Services

Use systemctl to restart and enable nfs-kernel-server and rpcbind for persistent operation.

Key Takeaway

Always use exportfs -arv after modifying /etc/exports and ensure NFS services are running and enabled.

Terminal Commands
# Apply changes from /etc/exports
sudo exportfs -arv

# Expected output:
exporting 192.168.1.100:/data/shared

# Restart NFS services
sudo systemctl restart nfs-kernel-server rpcbind

# Enable services to start on boot
sudo systemctl enable nfs-kernel-server rpcbind

# Verify service status
sudo systemctl status nfs-kernel-server rpcbind
Common Mistake: Forgetting to Export

A common error is modifying /etc/exports but forgetting to run exportfs -arv. This will result in clients being unable to mount the share, as the server hasn't updated its internal list of available exports.
