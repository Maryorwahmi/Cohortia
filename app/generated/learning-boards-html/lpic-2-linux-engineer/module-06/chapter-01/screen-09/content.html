Client Setup

Preparing the NFS Client

Installing Client Tools and Verifying Exports

Install nfs-common

This package provides the necessary utilities for an NFS client to interact with remote shares.

Verify Server Exports

Use showmount -e nfs_server_ip to confirm the server is exporting the desired directory.

Key Takeaway

Always install nfs-common and verify server exports with showmount -e before attempting to mount.

Terminal Commands
# Install NFS client packages
sudo apt update
sudo apt install nfs-common -y

# Verify server exports (replace nfs_server_ip)
showmount -e 192.168.1.10

# Expected output:
Export list for 192.168.1.10:
/data/shared 192.168.1.100
Why Verify Exports?

Verifying exports with showmount helps confirm network connectivity to the NFS server and ensures the server is correctly configured to share the directory. This prevents troubleshooting client-side issues when the problem might be on the server.
