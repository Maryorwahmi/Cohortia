Key Concepts: NFS Security & Troubleshooting

Protocols, Authentication, and Diagnostic Tools

`anonuid` / `anongid`

NFS export options to specify the UID/GID for anonymous users (including squashed root), allowing for more granular permission control.

NFSv3

An older, simpler NFS protocol version, widely supported but lacking integrated security mechanisms beyond IP-based access control.

NFSv4

A newer, stateful NFS protocol version with improved firewall traversal and integrated Kerberos security for robust authentication.

Kerberos

A network authentication protocol providing strong authentication, integrity, and privacy for client/server applications, used to secure NFSv4.

`rpcinfo`

A command-line utility to query RPC services on a remote host, verifying that NFS-related services are running and accessible.

`nfsstat`

A command-line utility to display NFS statistics on both client and server, helping identify performance bottlenecks or error rates.

Chapter Takeaway

Securing NFS involves understanding protocol versions and implementing strong authentication like Kerberos, while effective troubleshooting relies on diagnostic tools like `rpcinfo` and `nfsstat`.
