Preventing Root Privilege Escalation

Understanding the Default `root_squash` Behavior

What is `root_squash`?

By default, NFS maps the client's `root` user (UID 0) to an anonymous user (typically `nobody` or `nfsnobody`) on the NFS server. This prevents a client's root user from having root privileges on the server's filesystem.

Why it Matters

This is a critical security measure that prevents a compromised client from gaining full administrative control over the NFS server's shared data, protecting against privilege escalation.

Client Root to Anonymous Mapping
Client Root (UID 0)
Server Anonymous (nobody)

Any action by client root on the share is performed as 'nobody' on the server.
