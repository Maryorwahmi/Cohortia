Essential NFS Troubleshooting Tools

Verifying Service Health and Performance with `rpcinfo` and `nfsstat`

`rpcinfo` Utility

  • **Purpose:** Lists all registered RPC services and their ports on a remote host.
  • **Usage:** `rpcinfo -p nfs_server_ip`
  • **Diagnosis:** Verifies `rpcbind` and NFS services (`nfsd`, `mountd`, etc.) are running and accessible. Essential for checking basic connectivity and service registration.
Key Insight

If NFS services aren't listed, they're either not running or blocked by a firewall.

`nfsstat` Utility

  • **Purpose:** Displays NFS statistics for both client and server operations.
  • **Usage:** `nfsstat -s` (server) / `nfsstat -c` (client)
  • **Diagnosis:** Helps identify performance bottlenecks, error rates, and retransmissions. Useful for pinpointing network issues or server overload.
Key Insight

High error rates or retransmissions often indicate underlying network or server problems.
