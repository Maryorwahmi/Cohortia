Key Concepts: Advanced NFS

Essential Terms for Configuration and Security

`async`

An NFS export option allowing the server to respond to requests before writing changes to disk, improving performance but with a slight data loss risk.

`root_squash`

The default NFS behavior that maps the client's `root` user to an anonymous user on the server for security, preventing privilege escalation.

`no_root_squash`

An NFS export option that disables `root_squash`, granting the client's `root` user full `root` privileges on the exported directory. Use with extreme caution.

Chapter Takeaway

Advanced NFS configuration involves a careful balance of performance, security, and granular access control through specific export options.
