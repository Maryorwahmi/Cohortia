Module 1 › Chapter 1.1 › What is a Blockchain?
Definition

Distributed, immutable ledger

Blocks are ordered records. Each block stores its own data and a hash pointing to the previous block, creating a chain that reveals tampering.

Metaphor — a stacked ledger
Pages in order, each with a seal that depends on the prior page's seal.
Key property
Tamper-evidence comes from cryptographic links, not magic permanence.
Common mistake
Confusing immutability with absolute unchangeability. Changes are detectable and costly to enact across the network.
Key Takeaway

Linking blocks by hashes makes historical edits evident and preserves a verifiable history across nodes.

Concrete example

Three-block chain example

Block 1: {transactions: [...], hash: H1, prev: 0}
Block 2: {transactions: [...], hash: H2, prev: H1}
Block 3: {transactions: [...], hash: H3, prev: H2}

If a transaction in Block 1 changes, H1 changes, so Block 2's prev no longer matches the new H1 and the chain is invalidated.
Why it matters
It lets independent participants detect inconsistencies without trusting a single operator.
Check your understanding
Explain how a single altered transaction propagates error through later hashes.
Analogy
Think of sealed envelopes where each envelope's seal includes a mark from the previous one. Breaking one seal breaks the chain of marks.
