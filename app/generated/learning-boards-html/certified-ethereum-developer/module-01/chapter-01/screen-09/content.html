Module 1 › Chapter 1.1 › Consensus and Agreement
Core claim

Consensus defines canonical history

Validators follow protocol rules to select which candidate blocks become part of the accepted ledger. Those rules determine how conflicts are resolved.

Proof-of-Work (PoW)
Attackers must expend large computational resources to outpace honest miners, raising the cost of rewriting history.
Proof-of-Stake (PoS)
Attackers risk losing economic stake, aligning incentives with honest behavior and lowering raw compute needs.
Misconception check
Consensus reduces disagreement but does not eliminate all risk; network size and validator distribution affect security.
Key Takeaway

Consensus mechanisms combine technical rules and incentives to make rewriting the ledger expensive and unlikely in honest networks.
