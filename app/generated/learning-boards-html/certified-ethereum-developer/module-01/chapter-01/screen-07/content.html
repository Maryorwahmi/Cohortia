Module 1 › Chapter 1.1 › Cryptographic Hashing
Definition

One-way fingerprints

Hash functions convert any input into a fixed-size digest. Small input changes create completely different digests, making them ideal for integrity checks.

Properties
Deterministic, one-way, avalanche effect.
Examples
SHA-256 used by Bitcoin; Keccak-256 used by Ethereum.
Misconception
A hash is not reversible encryption; it does not hide then reveal data with a key.
Key Takeaway

Hashes provide compact, tamper-evident fingerprints that blockchains use to secure chain integrity.

Concrete demonstration

Observe the avalanche effect

Input A: "Hello Cohortia!"
SHA-256: e3c... (example digest placeholder)

Input B: "Hello Cohortia! " (added space)
SHA-256: 9a1... (completely different digest)

Input C: "hello cohortia!" (lowercase)
SHA-256: f4b... (again different)
The exact digests above are examples of how tiny input changes produce unrelated outputs. Use a hash tool to try the experiment yourself and confirm the avalanche property.
Why it matters
Compact digests let nodes compare and verify data without exchanging full content.
Check
Ask: does a matching hash guarantee the original data's intent or only that the bytes match?
