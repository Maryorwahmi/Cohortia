Module 1 › Chapter 1.3 › MetaMask Setup
Steps
  1. Install MetaMask. Add the browser extension for Chrome, Firefox, Brave or Edge and open the welcome flow.
  2. Create a new wallet. Accept terms and write down the seed phrase on paper — store it offline. Never photograph or save digitally.
  3. Enable test networks. In settings toggle show test networks so Sepolia appears in the network list.
  4. Switch to Sepolia. Use the network selector and choose Sepolia Test Network for safe testing.
  5. Get test ETH. Copy the Sepolia address and paste into a faucet to request play ETH for testing.
Example & Check
Example scenario: you deploy a contract to Sepolia and test interactions. Since Sepolia ETH has no monetary value, mistakes won’t cost you real funds. Check your balance after requesting faucet funds and perform a small test transaction to confirm connectivity.
Key Takeaway

Testing on Sepolia is safe and essential. Always back up your seed phrase offline before any testing or deployment.

Common Mistake

Forgetting to check the active network before sending transactions can cause accidental Mainnet operations. Confirm network selection every time.
