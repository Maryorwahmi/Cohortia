The Ethereum Ecosystem

Learn how wallets manage keys, why nodes are essential infrastructure, and how Mainnet, Testnets and local networks change risk and iteration speed for developers.

Wallets
Manage public/private keys to send and receive ETH. Types include custodial, non-custodial, hot and cold.
Nodes
Run client software to validate blocks. Full, light, and archive nodes serve different roles.
Networks
Mainnet is production. Use Testnets and local chains to test without real value at stake.
Wallet • Node • Network
Wallet (MetaMask)
Stores your keys locally and signs transactions. Used in development to connect to RPC endpoints.
Node (Infura/Alchemy)
Provides RPC access to Mainnet or Testnets without running your own full node.
Network (Sepolia)
A safe test environment that mimics Mainnet behavior using play ETH.
