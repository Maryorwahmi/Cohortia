Module 1 › Chapter 1.3 › Networks
Mainnet
Live network where ETH has real monetary value and transactions are final.
Testnets (Sepolia)
Use Sepolia for safe deployment testing with play ETH and public network behavior.
Local (Ganache/Hardhat)
Run a personal chain on your machine for instant feedback and debugging during development.
Lifecycle Example
Start with a local network to write and unit test contracts quickly. Then deploy to Sepolia to test integration and behavior in a distributed environment. After audits and successful testnet runs, deploy to Mainnet. Each step reduces risk and increases confidence.
Local
Instant blocks, easy resets, deterministic tests.
Testnet
Public network, free test ETH, realistic but not identical to Mainnet.
Key Takeaway

Use the environment that matches your risk tolerance and development stage. Never test critical changes on Mainnet before adequate staging.
