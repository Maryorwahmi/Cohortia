Module 1 › Chapter 1.3 › Public & Private Keys
Definition

Private key = signer; Public key = address

A private key is used to cryptographically sign transactions. The public key is derived and displayed as an address to receive funds.

• Signatures prove authorization without revealing secrets. • Addresses appear in block explorers. • Seed phrases allow recovery by regenerating private keys.
Example
Create a MetaMask account to see a public address. The account's private key remains stored locally and is used whenever you confirm a transaction.
Security & Mistakes

Never paste your private key or seed phrase into a website. Treat them as irrevocable secrets. If exposed, funds can be moved immediately by an attacker.

Common Mistake

Typing seed phrases into online forms or storing them in cloud documents can lead to irreversible loss.

Key Takeaway

Protect private keys offline, prefer hardware wallets for large balances, and verify the authenticity of any recovery prompts.
