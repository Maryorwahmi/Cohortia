Module 1 › Chapter 1.3 › Quick Reference
Protect keys
Never share private keys or seed phrases. Back up offline and use hardware wallets for high value.
Environment strategy
Local for dev, Sepolia for testing, Mainnet for production. Confirm network before any transaction.
Infrastructure choices
Use RPC providers for convenience; run full nodes for privacy and independent verification; archive nodes for historical queries.
One final question
As you continue, ask: who controls keys, which network am I on, and who am I trusting for node data?
