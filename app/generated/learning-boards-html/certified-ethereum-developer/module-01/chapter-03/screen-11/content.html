Module 1 › Chapter 1.3 › Local Development
Why local networks
They provide instant confirmations, snapshots, and deterministic tests for fast iteration and debugging of smart contracts and scripts.
Developer workflow
  1. Start a local node (Ganache or Hardhat Network).
  2. Deploy contracts and run unit tests with deterministic accounts.
  3. Snapshot and revert state to debug and iterate quickly.
Example
Use Hardhat Network during development to inspect revert reasons and stack traces locally, then deploy to Sepolia for integration testing.
Key Takeaway

Local chains speed development with immediate feedback. Supplement with testnet runs to validate against a distributed network.
