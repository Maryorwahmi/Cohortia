Mechanics of EIP-1559
Base fee burned, optional tip to validator, improves predictability.
Base fee
Algorithmically adjusted per block; this amount is burned and not paid to validators.
Priority fee (tip)
Optional extra that goes to the validator to prioritize inclusion.
Key Takeaway
EIP-1559 separates the predictable base cost from competitive priority fees, but total ETH spent still depends on gas usage.
Concrete example
When demand rises, base fee increases and is burned; users can add a tip to gain priority but cannot avoid paying the base cost.
Misconception
Burning the base fee does not eliminate user costs; it only removes that portion of ETH from circulation.
