EVM — component overview
A deterministic virtual CPU executed by every full node.
Code execution
Nodes execute contract bytecode instruction by instruction, consuming gas for each operation.
State management
The EVM reads and writes the global state; successful execution updates persistent storage.
Gas accounting
Each operation has a gas cost; the EVM debits gas as it executes to prevent unbounded computation.
Isolation
Contracts run in isolated contexts; they cannot directly access a node's local state or external network resources.
Example: Token transfer
A transfer call triggers bytecode that adjusts balances and emits events; every node executes the same steps.
Process
Incoming transaction → EVM executes bytecode → gas debited → state updated on success.
Key Takeaway
The EVM enforces identical execution and gas accounting so contract behavior is auditable and consistent.
