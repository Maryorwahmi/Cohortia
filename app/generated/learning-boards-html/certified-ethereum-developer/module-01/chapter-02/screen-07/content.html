Module 1 › Chapter 1.2 › Ether (ETH)
What is Ether?
The network's native asset used as both value and payment for computation.
Store of value
ETH can be transferred, held, or traded like other cryptocurrencies.
Fuel for computation
Operations consume gas; gas is priced in ETH, so ETH pays for transaction and contract execution costs.
Why it matters
Designers must account for ETH costs when choosing contract complexity and when estimating user fees.
Concrete example
Sending 1 ETH to a friend costs the transfer amount plus a gas fee paid in ETH; users need both value and fuel to transact.
Common misconception
Gas is not a separate currency. It is a work unit converted to ETH through the Gas Price.
Key Takeaway
ETH funds both transfers and computation; effective DApp design minimizes unnecessary gas to improve UX.
