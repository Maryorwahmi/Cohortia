Objectives — practice and caution
Build practical intuition for contracts, the EVM, and gas mechanics.
01 Smart Contracts
Describe self-executing code stored on-chain and common use cases like automated payments.
02 EVM
Explain the deterministic runtime that every full node executes for consensus.
03 Misconception
ETH is not only a tradable coin; it is required to pay Gas for computation.
04 Gas Limit
Understand what happens when a transaction runs out of gas: execution stops but spent gas is not returned.
