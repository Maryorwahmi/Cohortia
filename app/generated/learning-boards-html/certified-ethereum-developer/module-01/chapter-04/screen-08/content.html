Definition

IPFS and content-addressing

IPFS stores files in a distributed manner and returns a content hash used to retrieve the exact file. Smart contracts store that hash as a compact, verifiable reference rather than storing bulky content directly.

Pattern: Upload file to IPFS → get content hash → store hash in contract
Benefit: Lower gas costs while preserving verifiability
Consideration: Ensure persistence and pinning strategies for availability
Concrete scenario
A creator uploads an image to IPFS. The DApp stores the returned hash in a mapping on-chain. Frontends fetch the image via IPFS using the hash and render the creator's profile.
Common misconception
Storing data off-chain makes the system centralized — not necessarily. Using decentralized file networks preserves decentralization for content while reducing on-chain cost.
Check your understanding
Why avoid storing full images on-chain? Answer: high gas costs and block size inefficiency; prefer content hashes on-chain with files on IPFS.
