Core Concept

What is a DApp?

A DApp places backend logic and persistent state on a decentralized network. Below are the four core characteristics you can use to evaluate any candidate DApp.

Open source — code is auditable and community-driven.
Decentralized — no single operator controls the backend.
Incentivized — native tokens often align participant behavior.
Censorship-resistant — on-chain logic is difficult to remove.
Key Takeaway

If backend rules and state live on a blockchain, the app behaves as a DApp with the benefits and trade-offs that implies.

Concrete example — tipping DApp
A frontend proposes a tip, a smart contract implements the transfer, and the result is recorded on-chain so anyone can verify the transfer later.
Common misconception
Decentralized does not equal anonymous. Transaction history is public and can be analyzed; anonymity requires separate privacy techniques not assumed by default.
