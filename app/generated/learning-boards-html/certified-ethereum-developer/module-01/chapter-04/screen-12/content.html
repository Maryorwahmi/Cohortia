Activity

Map the components

Label each component in the architecture and answer the three reflection questions about where code, media, and signing live.

Question 1: Which component contains the Solidity code that transfers ETH? Answer: the smart contract deployed on the Ethereum network.
Question 2: Where should a high-resolution profile image live? Answer: in decentralized storage such as IPFS, referenced by a content hash in the contract.
Question 3: How does the browser initiate a tip? Answer: the frontend builds a transaction and the Web3 provider prompts the user to sign and broadcasts it.
Common pitfall
Assuming off-chain files remain available without pinning. Use pinning strategies to ensure IPFS-hosted files stay retrievable.
Practical next step
Sketch the tipping DApp in your notes and identify where to add unit tests, what events to emit, and how to surface pending transaction states in the UI.
Key Takeaway
Clear mapping of responsibilities leads to better testing, fewer security surprises, and a smoother user experience.
