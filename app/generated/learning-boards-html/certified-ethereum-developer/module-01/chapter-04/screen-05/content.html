Architecture

Frontend → Web3 Provider → Smart Contracts

Each layer has a distinct responsibility. The frontend handles UI and prepares requests. The Web3 provider secures signing and broadcasts transactions. Smart contracts implement the authoritative logic on-chain.

Frontend
React, Vue — renders UI and calls Web3 APIs.
Web3 Provider
Manages accounts, signs transactions, and connects to the network.
Smart Contracts
Deployed Solidity code that enforces rules and updates state.
Decentralized Storage
IPFS/Arweave for large files; store references on-chain.
Concrete flow example
When a user tips, the frontend calls a tip function, the provider asks the user to sign the transaction, and the smart contract updates balances on-chain, emitting an event that the frontend can read later.
Why enforce rules on-chain?
Because frontends can be modified by attackers or forked, business-critical checks must be in the immutable smart contract to preserve integrity.
