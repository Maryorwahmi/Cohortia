Module 2 › Chapter 1.4 › Key Concepts
Decentralized Application (DApp)
An app whose backend rules and state run on a blockchain, enabling transparency and user ownership.
Smart Contract
On-chain code written in Solidity that holds the authoritative logic and state for the DApp.
Web3 Provider
A wallet or extension that allows the frontend to request signatures and interact with the blockchain.
Summary takeaway

Design DApps by mapping responsibilities, minimizing on-chain storage, testing contracts thoroughly, and crafting UX that respects signing and confirmation flows.
