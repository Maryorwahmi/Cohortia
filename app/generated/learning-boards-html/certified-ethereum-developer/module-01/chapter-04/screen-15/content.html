Module 2 › Chapter 1.4 › Key Concepts
IPFS
Decentralized file storage used to host large content while contracts store content hashes.
DeFi
Financial primitives implemented as composable smart contracts requiring high correctness and auditability.
DAO
Organization governed by smart contracts and token-holder decisions; governance design is critical.
Final takeaway

DApp design is a balancing act between transparent, on-chain truth and practical off-chain solutions for cost and UX. Start small, test thoroughly, and design with users in mind.
