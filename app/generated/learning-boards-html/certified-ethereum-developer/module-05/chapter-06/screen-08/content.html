Uploader example
This snippet demonstrates the exact flow used in a Node or browser context when the SDK is available.
// src/utils/ipfs.ts
import pinataSDK from '@pinata/sdk';
import { readFileSync } from 'fs'; // For Node.js environment, use File object in browser

const pinataApiKey = process.env.NEXT_PUBLIC_PINATA_API_KEY;
const pinataSecretApiKey = process.env.NEXT_PUBLIC_PINATA_SECRET_API_KEY;

const pinata = new pinataSDK(pinataApiKey, pinataSecretApiKey);

export async function uploadFileToIPFS(file: File): Promise {
  if (!pinataApiKey || !pinataSecretApiKey) {
    return null;
  }

  try {
    const result = await pinata.pinFileToIPFS(file, {
      pinataMetadata: { name: file.name },
      pinataOptions: { cidVersion: 0 }
    });
    return result.IpfsHash;
  } catch (error) {
    return null;
  }
}
Note: in the browser use the File object; in Node use a readable stream. Never commit API secrets to source control.
Error handling
Return null or display a friendly message on failure. Distinguish network errors from permission or key issues.
Security note
Store API keys in environment variables. When you cannot hide a secret in the client, proxy requests through a trusted backend.
