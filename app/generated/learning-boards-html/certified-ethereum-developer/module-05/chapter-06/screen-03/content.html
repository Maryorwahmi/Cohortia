Module 6 › Chapter 5.6 › Learning Objectives
Hands-on goals
  • Implement a file upload path that returns a CID from a pinning provider using secure API keys.
  • Call a smart contract function to save the ipfs://CID as tokenURI or a simple storage field.
  • Retrieve that CID and render the asset via an IPFS gateway for verification.
  • Configure pinning to guarantee long-term availability beyond a local node.
Safety checklist
Store keys in environment variables, confirm the CID after upload, avoid embedding large binary on-chain, and always use a pinning strategy for production assets.
Milestone
A deployed contract that returns a currentImageCID string and a UI that displays the pinned image confirms success.
