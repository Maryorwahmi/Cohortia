Module 6 › Chapter 5.6 › Common Mistakes
Mistakes that break availability
  • Assuming an uploaded CID remains available without pinning.
  • Exposing pinning API secrets in client-side code.
  • Storing large binaries on-chain instead of references.
  • Using a single public gateway as the only retrieval path.
Mitigations
Pin with services, use backends for secrets, optimize assets, and add multiple gateways for redundancy.
Moderation note
A CID guarantees immutability but not that the content is appropriate. Implement moderation policies for user-generated content if necessary.
