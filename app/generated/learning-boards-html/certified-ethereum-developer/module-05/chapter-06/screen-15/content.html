Module 6 › Chapter 5.6 › Key Concepts
Content Addressing
Data is identified by its cryptographic hash (CID), not location.
IPFS
A peer-to-peer file system that serves content by CID from any node that has it.
Pinning
Pinning prevents garbage collection and ensures content stays available over time.
Summary takeaway

Use IPFS for heavy content, store small CIDs on-chain, and rely on pinning services or nodes for persistence to build resilient DApps.
