Module 6 › Chapter 5.6 › Activity
Activity steps
1. Create Pinata account and API keys; add keys to .env.local.
2. Deploy ImageStorage.sol to a local Hardhat network and copy address.
3. Implement IPFSUploader: select file, call pinata.pinFileToIPFS, get result.IpfsHash.
4. Call contract.setImageCID with the CID and wait for confirmation.
5. Read currentImageCID and render the image using an IPFS gateway URL for verification.
Verification
Confirm the CID returned by Pinata matches the value stored on-chain and that the gateway loads the asset.
Safety reminder
Never commit .env.local to source control. Use a backend if you cannot keep secrets out of the client.
