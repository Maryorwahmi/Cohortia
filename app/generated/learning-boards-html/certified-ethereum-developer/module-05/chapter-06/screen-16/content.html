Module 6 › Chapter 5.6 › Quick Reference
CID is immutable
Any change produces a new CID; use this for integrity checks.
Pin for persistence
Use pinning services or run a node to keep content alive.
Store CID on-chain
Keep on-chain data minimal: store ipfs://CID as tokenURI or a string field.
One-line takeaway

Design for verifiability and availability: CIDs prove content, pinning preserves it, and on-chain references make it authoritative.
