How IPFS names content
A file's CID is produced by hashing its bytes. The CID is stable so long as the content is unchanged.
Immutability
CID changes when content changes; content integrity can be validated by re-hashing.
Deduplication
Exact duplicate files produce the same CID, saving storage across the network.

Gateway vs network

An IPFS gateway exposes content over HTTP but introduces centralization. For resilience, consider pinning or running a node.

Practical note
When designing a DApp, decide whether users rely on public gateways, a dedicated gateway, or direct peer-to-peer retrieval via a node or client library.
