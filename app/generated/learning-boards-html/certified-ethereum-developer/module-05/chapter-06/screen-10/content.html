Module 6 › Chapter 5.6 › Integration Architecture
Browser / UI
File input, validation, upload progress, and transaction UX. Can call SDK directly or proxy to backend.
Pinning Service
Receives file, returns CID, and pins content so it remains available across the IPFS network.
Smart Contract
Stores a small ipfs://CID reference and emits an event when updated for the UI to consume.
Flow bullets
  • Upload triggers pinFileToIPFS and returns a CID.
  • UI constructs tokenURI as ipfs://CID and calls contract.setImageCID.
  • Contract emits ImageCIDUpdated; UI listens and refreshes the asset URL.
Why events matter
Events let the UI respond immediately to on-chain updates without continuous polling and help surface confirmation status to users.
