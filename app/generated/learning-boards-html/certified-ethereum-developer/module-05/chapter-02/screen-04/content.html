Module 5 › Chapter 5.2 › Initialize a React or Next.js DApp
Commands
# Using create-react-app (for simpler SPAs)
npx create-react-app my-dapp-frontend --template typescript
cd my-dapp-frontend
npm start # or yarn start

# Using Next.js (recommended for production-grade DApps)
npx create-next-app@latest my-dapp-frontend --typescript --eslint --app
cd my-dapp-frontend
npm run dev # or yarn dev
Verification
  • Start the dev server and open the app at localhost:3000.
  • Confirm the welcome page renders before adding Web3 code.
Notes & Tips

Next.js provides file-system routing and server-side capabilities that are useful if your DApp needs pre-rendered pages or server-only secrets. create-react-app is simpler for single-page prototypes. After scaffolding, immediately create folders for components, hooks, utils, and contracts so your Web3 logic has a predictable place to live.

Key Takeaway

Scaffold with a purpose: pick the tool that matches your app's rendering and routing needs, then create a clean folder layout before adding blockchain code.
