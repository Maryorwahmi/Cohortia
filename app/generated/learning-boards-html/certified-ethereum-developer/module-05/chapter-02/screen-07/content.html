Example utility (visual)
import { ethers } from "ethers";

let provider;
let signer;

export async function getWeb3Provider() {
  if (window.ethereum) {
    // User has MetaMask, connect to it
    provider = new ethers.BrowserProvider(window.ethereum);
    signer = await provider.getSigner();
    console.log("Connected to MetaMask provider.");
  } else {
    // Fallback to a local Hardhat node for read-only operations
    provider = new ethers.JsonRpcProvider("http://127.0.0.1:8545");
    console.log("Connected to local Hardhat node (read-only).");
    // To send transactions programmatically, attach a Wallet with a local private key
    // const privateKey = "0xac0974..." // Example Hardhat private key
    // signer = new ethers.Wallet(privateKey, provider);
  }
  return { provider, signer };
}
Place this utility in src/utils/web3.js or src/app/utils/web3.ts and import it in components using an effect to initialize provider and optionally store the account.
Check
Run the app with MetaMask connected to your Hardhat node, then disconnect MetaMask and confirm the fallback message appears in console logs.
Key Takeaway

A single provider utility simplifies components and ensures a consistent fallback for read-only access when wallet injection is absent.
