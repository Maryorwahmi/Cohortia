Module 5 › Chapter 5.2 › Manage environment variables
Create-React-App
# .env
REACT_APP_CONTRACT_ADDRESS=0xYourDeployedContractAddress
REACT_APP_INFURA_PROJECT_ID=your_infura_id

# Access: process.env.REACT_APP_CONTRACT_ADDRESS
Next.js
# .env.local
NEXT_PUBLIC_CONTRACT_ADDRESS=0xYourDeployedContractAddress
INFURA_PROJECT_ID=your_infura_id # server-side only

# Access: process.env.NEXT_PUBLIC_CONTRACT_ADDRESS
Common Mistake

Putting secrets in client-prefixed env vars exposes them to the browser. Use server-only variables for private keys and rotation-ready secrets.
