Module 5 › Chapter 5.2 › Signers & Private Keys
Architecture
Browser wallet signer
Runs in the user’s wallet, requests explicit user approvals, and never exposes private keys to the page.
Programmatic Wallet signer
Created with a private key and a JsonRpcProvider for scripts or automated deployments. Keep keys out of client bundles.
Use browser wallets for user-initiated txs and Wallet signers only for CI or local scripts. When using Wallet signers, read private keys from secure environment variables in server or CI environments.
Safety Note

Never commit private keys or include them in client-side code. Use .env and server-side secrets for automation.

Check

Run a deploy script with a Wallet signer and a separate UI read operation with JsonRpcProvider to observe both patterns working as intended.
