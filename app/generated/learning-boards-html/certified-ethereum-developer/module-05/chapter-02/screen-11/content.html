Module 5 › Chapter 5.2 › Common mistakes
Checklist
  • Pin Node and package versions; use .nvmrc for Node.
  • Keep ABIs and addresses centralized and update after redeploys.
  • Never commit private keys; use server-side secrets.
  • Provide a read-only provider fallback when window.ethereum is absent.
Quick fixes
  • Resolve CORS by ensuring the node accepts your origin.
  • Reduce bundle size with lazy imports of Ethers.js where feasible.
  • Verify provider selection via console logs and a simple RPC call.
Key Takeaway

Many setup issues are avoided by simple verification steps: call an RPC method, read a contract value, and confirm provider selection with and without a wallet.
