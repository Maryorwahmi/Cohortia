Maintainable structure

Separate components, hooks, utils, contracts, and context so updates to smart contracts do not ripple through unrelated UI code. This makes testing and CI integration simpler.

Resilient provider

Build a utility that prefers a browser wallet for signing, and falls back to a JsonRpcProvider for read-only data when wallets are unavailable. This improves UX for non-wallet visitors.

Each objective above includes a verification step. For structure, create the folders and import an ABI from contracts/ into a test UI. For provider resilience, run the app without MetaMask and confirm you can still fetch contract state with a read-only provider.
