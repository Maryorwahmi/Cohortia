Module 5 › Chapter 5.2 › Project Structure
Recommended layout
my-dapp-frontend/
├── public/
├── src/
│   ├── components/
│   ├── hooks/
│   ├── pages/ or app/
│   ├── utils/       # web3 provider, ABI loaders
│   ├── contracts/   # ABI artifacts copied from Hardhat
│   ├── context/     # wallet/provider context
│   └── styles/
├── scripts/         # deployment scripts
├── .env.local
└── package.json
Centralize contract artifacts and provider utilities so redeploys only require a small set of changes. Consider adding CI tasks to update frontend config after deployments.
