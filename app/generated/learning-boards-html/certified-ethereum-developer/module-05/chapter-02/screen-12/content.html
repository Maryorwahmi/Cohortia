Module 5 › Chapter 5.2 › Hands-on Activity
Steps
  1. Scaffold Next.js with TypeScript: npx create-next-app@latest --typescript --app
  2. Install Ethers.js: npm install ethers
  3. Create Hardhat project, write contract, add deploy script
  4. Run npx hardhat node and deploy to localhost; copy address
  5. Add NEXT_PUBLIC_CONTRACT_ADDRESS in .env.local and start frontend
  6. Import connectWeb3 and confirm provider and account or fallback
Verification
  • Hardhat prints the deployed address in deploy script output.
  • The frontend console shows whether it connected to MetaMask or the local node.
  • The page displays a status string like Connected with account or Connected to local Hardhat node (read-only).
Try this

After setup, change the contract greeting, redeploy, and update NEXT_PUBLIC_CONTRACT_ADDRESS to validate how the frontend adapts to ABI/address changes.
