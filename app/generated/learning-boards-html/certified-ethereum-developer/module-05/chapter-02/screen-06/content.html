Module 5 › Chapter 5.2 › Run a local Hardhat node
Start the node
# In your Hardhat project directory
npx hardhat node

# Typical RPC endpoint
http://127.0.0.1:8545
Hardhat prints funded accounts and private keys to the terminal. Use those private keys only for local testing and never commit them.
Usage patterns
  • Connect MetaMask to the local RPC for interactive testing and signing.
  • Use a JsonRpcProvider in the frontend for read-only access if no wallet is present.
  • Automate redeploys with scripts to avoid manual address tracking.
Common Mistake

Expecting deployments to persist across node restarts. Hardhat nodes reset state unless you snapshot or redeploy with scripts.
