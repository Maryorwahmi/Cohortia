Module 5 › Chapter 5.4 › Transaction Lifecycle
Stages
Wallet Prompt

User signs or rejects. If rejected, show "Transaction rejected by user."

Sent (Hash)

Show the tx hash immediately so users can inspect the pending tx.

Pending

Show a spinner and note expected wait time or confirmation count.

Confirmed / Failed

On receipt, show success with hash or failure with parsed revert reason and next steps.

Concrete example

After sending, display: "Transaction sent: 0xabc... Waiting for confirmation..." Then update to "Confirmed: 0xabc..." and refresh balances.

Key Takeaway

Provide a clear lifecycle view and actionable next steps using the transaction hash as the primary anchor.
