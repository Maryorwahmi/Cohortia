Module 5 › Chapter 5.4 › Hands-on Activity
Activity Steps
  1. Deploy MyToken to your local Hardhat node and copy the address.
  2. Create src/utils/abis.ts and export a minimal ERC-20 ABI (balanceOf, transfer, decimals, symbol).
  3. Implement TokenBalanceDisplay: useEffect fetches balance and metadata; use ethers.formatUnits to display the balance.
  4. Implement TokenTransferForm: validate inputs, use ethers.parseUnits, send transfer via signer, await tx.wait(), and call onTransferSuccess on success.
  5. Integrate components in src/app/page.tsx: manage provider, signer, account, and refreshBalanceTrigger; wire onTransferSuccess to increment the trigger.
  6. Run the app, connect MetaMask to local node, perform a transfer, and verify the balance updates after confirmation.
Verification

If balances don’t update, ensure onTransferSuccess increments the trigger and TokenBalanceDisplay re-fetches when the key changes.
