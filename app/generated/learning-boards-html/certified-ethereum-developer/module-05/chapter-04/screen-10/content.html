Module 5 › Chapter 5.4 › Managing DApp State
Architecture

Top-level app holds provider, signer, account, and a refresh trigger. Child components receive provider/account or use context. TokenBalanceDisplay uses provider, account, tokenAddress, and a key based on the refresh trigger to re-fetch after transactions. TokenTransferForm calls onTransferSuccess to increment the trigger in the parent.

Local state

Form inputs, loading flags, errors.

Shared state

Provider, signer, connected account stored in context or a global store.

Event handling

Listen to accountsChanged, chainChanged, and disconnect to update state and inform the user when reconnection is needed.

Key Takeaway

Separate local and shared concerns, and use an explicit refresh trigger to synchronize reads after writes.
