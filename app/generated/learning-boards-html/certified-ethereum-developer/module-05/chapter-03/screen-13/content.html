Activity Steps
  1. Start the Next.js app and open it in the browser.
  2. Ensure MetaMask is installed and unlocked.
  3. Trigger connect; approve eth_requestAccounts in the wallet.
  4. Switch accounts in MetaMask and observe accountsChanged update UI.
  5. Switch networks and observe chainChanged handling or prompts to switch networks.
  6. Lock wallet or disconnect and verify UI resets.
Verification Checklist
  • Connected account displays correctly after approval.
  • accountsChanged updates address and re-fetches data.
  • chainChanged updates chainId and re-initializes network resources.
  • disconnect clears account and provider state.
Key Takeaway

Testing dynamic behaviours is the final proof that your wallet connection and event handling code is production-ready and user-safe.
