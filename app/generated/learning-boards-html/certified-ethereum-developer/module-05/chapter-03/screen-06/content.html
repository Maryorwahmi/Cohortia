Starter Code
import { ethers } from "ethers";

let provider = null;
let signer = null;
let currentAccount = null;
let currentChainId = null;

async function connectWallet() {
  if (typeof window.ethereum !== 'undefined') {
    try {
      const accounts = await window.ethereum.request({ method: 'eth_requestAccounts' });
      currentAccount = accounts[0];
      provider = new ethers.BrowserProvider(window.ethereum);
      signer = await provider.getSigner();
      const network = await provider.getNetwork();
      currentChainId = network.chainId.toString();
      // setupEventListeners();
      return { account: currentAccount, chainId: currentChainId };
    } catch (error) {
      if (error.code === 4001) {
        // user rejected
      } else {
        // other errors
      }
      return { account: null, chainId: null };
    }
  } else {
    // wallet not detected
    return { account: null, chainId: null };
  }
}
Concrete example
After user approval, currentAccount holds the first returned address and currentChainId is the numeric chain identifier, both usable in UI and validations.
Explanation & Pitfalls
Remember to: verify accounts array length, handle the 4001 error code meaning the user declined to connect, and avoid auto-retrying prompts that annoy users. Use provider.getNetwork() to confirm the network and prompt the user to switch if necessary.
Key Takeaway

Instantiate provider and signer only after a successful accounts response. Then read chainId and initialize event listeners to keep state accurate.
