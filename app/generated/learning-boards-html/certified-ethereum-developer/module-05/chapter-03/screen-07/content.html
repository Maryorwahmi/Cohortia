Event Setup
Register listeners after connect
Use window.ethereum.on to listen. Typical events: accountsChanged, chainChanged, disconnect. These let you react immediately to user changes rather than waiting for the next action.
accountsChanged
If empty, consider the wallet locked; if different, update signer and account-specific data.
chainChanged
Network changed — reinitialize contracts or prompt the user to switch to the expected network.
disconnect
Reset account, signer, and provider state and show disconnected UI.
Implementation snippet
function setupEventListeners() {
  if (window.ethereum) {
    window.ethereum.on('accountsChanged', handleAccountsChanged);
    window.ethereum.on('chainChanged', handleChainChanged);
    window.ethereum.on('disconnect', handleDisconnect);
  }
}

function removeEventListeners() {
  if (window.ethereum) {
    window.ethereum.removeListener('accountsChanged', handleAccountsChanged);
    window.ethereum.removeListener('chainChanged', handleChainChanged);
    window.ethereum.removeListener('disconnect', handleDisconnect);
  }
}
Key Takeaway

Always register and clean up listeners to ensure your DApp stays in sync and avoids memory leaks.
