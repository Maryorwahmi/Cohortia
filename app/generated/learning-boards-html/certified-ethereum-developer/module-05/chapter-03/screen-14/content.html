Module 5 › Chapter 5.3 › Key Concepts
Web3 Wallet
Key manager and signer for user identity and transactions.
window.ethereum
Injected provider object used to interact with the wallet.
EIP-1193
The standard JS provider API for wallets and DApps.
eth_requestAccounts
JSON-RPC method to prompt the user to connect accounts.
accountsChanged
Event emitted when the user's selected account changes.
chainChanged
Event emitted when the user switches the blockchain network in their wallet.
Summary

Keep these concepts central: the provider is the bridge, requests require permission, and events keep your UI accurate. Validate chain and account state before sensitive operations.
