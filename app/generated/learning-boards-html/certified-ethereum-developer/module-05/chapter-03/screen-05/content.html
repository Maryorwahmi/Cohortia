Process
Detect → Request → Resolve
Follow these steps in order to request account access and prepare signer/provider objects for use.
  1. Detect: if (typeof window.ethereum !== 'undefined') then proceed.
  2. Request: await window.ethereum.request({ method: 'eth_requestAccounts' }).
  3. Resolve: use the returned accounts[0] as the connected address and instantiate provider and signer.
  4. Handle rejection: catch error.code === 4001 and show a friendly explanation; do not re-prompt immediately.
Example result
You receive an accounts array. Use accounts[0] for display and provider.getSigner() for signing operations.

Key Takeaway

Permission must be explicitly granted. Handle rejection and absence with clear, non-blocking guidance.
