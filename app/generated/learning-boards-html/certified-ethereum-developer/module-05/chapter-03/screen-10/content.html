Disconnect
What to reset
Clear currentAccount, signer, and provider. Update UI state to reflect disconnection and prevent accidental transaction attempts.
Concrete example
On disconnect, set currentAccount = null, signer = null, provider = null, and set status to 'Wallet disconnected'.
Cleanup
Remove listeners such as accountsChanged and chainChanged during component unmount or app teardown to avoid duplicate events and stale closures.
function removeEventListeners() {
  if (window.ethereum) {
    window.ethereum.removeListener('accountsChanged', handleAccountsChanged);
    window.ethereum.removeListener('chainChanged', handleChainChanged);
    window.ethereum.removeListener('disconnect', handleDisconnect);
  }
}
Key Takeaway

Remove listeners reliably in your framework's teardown lifecycle to maintain correct event behavior and memory use.
