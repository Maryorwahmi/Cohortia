Security Notes
  • Never ask for private keys; wallets protect keys.
  • Handle user rejection (error.code === 4001) with a clear, non-aggressive message.
  • Validate chainId before attempting network-specific transactions.
  • Advise users to verify the DApp URL to avoid phishing.
UX Practices
Provide a clear status area that shows whether the wallet is connected, the current account, and the chainId. If the network is unsupported, prompt the user to switch and explain why. Avoid blocking the user from exploring read-only features when the wallet is not connected.
Key Takeaway

Design permission-friendly flows and validate wallet state before sensitive operations to protect users and avoid errors.
