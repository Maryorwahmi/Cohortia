Option A — Reload
Pros and cons
  • Pros: Simple, guarantees fresh state across the app.
  • Cons: Disruptive, may lose unsaved UI state.
When to use
Small apps or critical correctness needs where preservation of complex UI state is less important.
Option B — Graceful re-init
Pros and cons
  • Pros: Better UX, keeps UI and unsaved state intact.
  • Cons: Requires careful re-creation of contract instances and data flows.
When to use
Applications where a smooth user experience matters and you can reliably re-instantiate network-dependent resources.
