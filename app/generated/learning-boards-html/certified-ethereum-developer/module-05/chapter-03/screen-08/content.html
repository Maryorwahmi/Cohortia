Event Handler
What to do on accountsChanged
Key steps: check array length, clear state if empty, update account and signer if different, re-fetch account data, and update UI to reflect the new identity.
Concrete example
If accountsChanged returns ['0xABC...'], set currentAccount to that address, call provider.getSigner(), and refresh balances and allowances tied to that address.
Common mistake
Ignoring account changes or assuming a refresh will occur causes mismatched identities when sending transactions. Always trust the provider event and update state immediately.
Key Takeaway

Treat accountsChanged as authoritative: update signer, clear stale data, and notify the user of any important consequences.
