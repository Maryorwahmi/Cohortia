Listening Example
// Listen for ItemCreated
contract.on("ItemCreated", (itemId, owner, uri, event) => {
  console.log(`ItemCreated: ID=${itemId.toString()}, Owner=${owner}, URI=${uri}`);
  // Update UI or notify user
});

Handler considerations
  • Event arguments are decoded in order; the last parameter is usually the event object with transactionHash.
  • Update state incrementally rather than re-fetching entire collections.
  • Always remove listeners on cleanup to prevent duplicates and memory leaks.
Common mistake

Attaching multiple handlers for the same event when a component re-renders leads to duplicated UI updates. Remove handlers explicitly.
