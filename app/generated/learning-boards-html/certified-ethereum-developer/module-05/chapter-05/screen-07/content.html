Module 5 › Chapter 5.5 › Send & Wait Example
Example code
async function sendDataTransaction(contract, newValue) {
  if (!contract.signer) {
    console.error("Contract instance must have a signer for transactions.");
    return;
  }
  try {
    const tx = await contract.set(newValue);
    console.log("Transaction sent. Hash:", tx.hash);
    const receipt = await tx.wait();
    if (receipt && receipt.status === 1) {
      alert(`Data set to ${newValue} in transaction ${tx.hash}`);
      return true;
    } else {
      alert(`Transaction ${tx.hash} failed or reverted.`);
      return false;
    }
  } catch (error) {
    console.error("Error sending transaction:", error);
    if (error.code === 4001) {
      alert("Transaction rejected by user.");
    } else {
      alert(`Transaction failed: ${error.message}`);
    }
    return false;
  }
}
Explanation
  • Check contract.signer to ensure transactions can be signed.
  • contract.set(...) returns a TransactionResponse with a hash once broadcast.
  • tx.wait() returns a TransactionReceipt containing status, gasUsed, and events.
  • Catch both broadcast errors (e.g., user rejected) and execution failures reported in the receipt.
Key Takeaway

Design UI to await the receipt before declaring success and handle error codes like 4001 separately.
