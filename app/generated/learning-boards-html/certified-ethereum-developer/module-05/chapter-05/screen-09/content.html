Module 5 › Chapter 5.5 › Gas Estimation
How it works
estimateGas runs a simulated execution to calculate gas usage. Use it to detect likely reverts before spending gas. Wallets perform their own estimation too.
Example: const gasLimit = await contract.myFunction.estimateGas(arg1, arg2); If it throws, warn the user and do not send.
Best practices
  • Rely on wallet estimation for typical flows.
  • Use manual estimate when setting custom gas buffers.
  • Surface clear errors when estimation fails; do not broadcast blindly.
