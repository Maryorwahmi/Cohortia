Module 5 › Chapter 5.5 › Filtering & Historical Queries
Filtering
Create filters with contract.filters.EventName(indexed1, indexed2, ...). Use these to listen only for matching events and reduce client-side noise.
Historical queries
Use contract.queryFilter(filter, fromBlock, toBlock) for past events. Narrow ranges and indexed params make this efficient. For large queries, prefer an indexing service.
Rule of thumb

Use events for incremental updates and indexers for heavy historical queries to keep the frontend performant.
