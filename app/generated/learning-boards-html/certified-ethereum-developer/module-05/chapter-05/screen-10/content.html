Module 5 › Chapter 5.5 › Smart Contract Events
Why events?
  • Emit structured logs cheaply during execution.
  • Appear in TransactionReceipt so frontends can react after confirm.
  • Enable real-time UI updates without full polling.
Example (Solidity)
event ItemCreated(uint256 indexed itemId, address indexed owner, string uri);
event ItemSold(uint256 indexed itemId, address indexed seller, address indexed buyer, uint256 price);
Emit events where useful and use indexed fields to enable efficient filtering.
