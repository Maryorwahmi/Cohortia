Objective Cards
  • Estimate gas: Learn to call estimateGas and interpret failures as possible reverts or complex logic paths.
  • Handle confirmations: Use tx.wait(n) when extra confirmations are required for value-sensitive operations.
  • Subscribe and filter events: Create targeted listeners using indexed parameters to reduce noise and improve efficiency.
  • Listener cleanup: Remove or scope listeners to prevent memory leaks when components unmount or contracts change.
Mnemonic
Think: Send → Wait → Verify → React. Send the transaction, wait for confirmations, verify the receipt status, then react to events to update the UI.
