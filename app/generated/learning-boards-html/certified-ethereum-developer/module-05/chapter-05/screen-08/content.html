Module 5 › Chapter 5.5 › Response vs Receipt
TransactionResponse
Returned immediately after broadcast. Contains tx.hash and metadata but no execution status. Use it to show a pending link or hash to the user.
TransactionReceipt
Returned by tx.wait() after mining. Contains status, gasUsed, blockNumber, and events. Use receipt.status to confirm success.
Practical tip

Show a 'pending' state after the TransactionResponse and only show 'confirmed' after receipt.status === 1. This avoids false positives and keeps user expectations accurate.
