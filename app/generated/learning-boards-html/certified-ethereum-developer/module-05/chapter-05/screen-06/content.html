Module 5 › Chapter 5.5 › Contract & Signer
Pattern
For reads: new Contract(address, abi, provider). For transactions: new Contract(address, abi, signer). Check contract.signer before sending.
Example: If contract.signer is null, show 'Connect wallet' rather than calling a state-changing method that will fail silently or throw.
Visual: Contract instantiation
Provider-only contract → read-only methods
Signer-attached contract → prompts wallet, allows transactions
Always check for signer before calling state-changing methods to provide clear UX.
