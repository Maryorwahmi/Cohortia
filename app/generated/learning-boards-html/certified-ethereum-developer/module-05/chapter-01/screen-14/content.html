Module 5 › Chapter 5.1 › Key Concepts
ABI
JSON description of functions and types for encoding and decoding calls.
Contract Address
Unique on-chain identifier. Always use the address for the correct network.
Provider & Signer
Provider connects to a node; signer signs transactions via the user's wallet.
Summary

Keep ABI, address, and provider/signing patterns correct; surface read and write differences clearly; and handle errors gracefully to build dependable DApps.
