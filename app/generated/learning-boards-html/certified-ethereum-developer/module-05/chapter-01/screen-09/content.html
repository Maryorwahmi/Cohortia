Module 5 › Chapter 5.1 › Errors & Mistakes
ABI / Address
Verify ABI matches compiled contract and address is for the expected network. Mismatches produce call revert or function not found errors.
Asynchronous mistakes
Always await promises for reads and transactions; otherwise the UI may show incomplete or incorrect data.
User rejection
Detect and handle user rejection codes (for example, the wallet refusal code). Inform the user rather than retrying automatically.
Practical pattern
  1. Wrap calls in try/catch.
  2. Classify errors and present friendly messages.
  3. Log full errors for debugging but show actionable UI guidance.
