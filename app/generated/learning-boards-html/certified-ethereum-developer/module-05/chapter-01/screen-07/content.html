Example transaction flow
async function setStoredData(newValue) {
  if (!signer) { alert('Connect wallet first'); return; }
  try {
    const tx = await contract.set(newValue);
    console.log('Transaction sent:', tx.hash);
    const receipt = await tx.wait();
    console.log('Transaction confirmed:', receipt);
  } catch (error) {
    console.error('Error setting data:', error);
  }
}
UX tip: show a pending state after submission and a success state once the receipt arrives. Provide links to the transaction hash when appropriate.
Common errors
  • User rejected transaction: catch specific wallet error codes and inform the user without retrying automatically.
  • UNPREDICTABLE_GAS_LIMIT: gas estimation failed — check contract logic and revert reasons.
  • Insufficient funds: the user’s account must have enough to cover gas.
Key takeaway
Treat transactions as a multi-step asynchronous workflow and surface each step to the user.
