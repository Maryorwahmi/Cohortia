Module 5 › Chapter 5.1 › Read-only Calls
Example: get stored value
async function getStoredData() {
  try {
    const data = await contract.get();
    console.log('Stored data:', data.toString());
    return data.toString();
  } catch (error) {
    console.error('Error getting data:', error);
  }
}
Tip: Show a loading spinner while awaiting the call and catch errors to avoid leaving the user in a blank state.
Supporting points
  • Read calls require a provider to contact a node, though they don’t need a signer.
  • Always await the promise and convert BigNumber values for display.
  • Implement a refresh control so users can re-query the latest on-chain state.
Misconception
Read calls are free, but they are still network operations that can fail; handle errors and latency in the UI.
