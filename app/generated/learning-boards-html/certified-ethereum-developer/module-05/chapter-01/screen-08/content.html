Module 5 › Chapter 5.1 › Read vs Write
Read (view/pure)
No gas, no signature required, executed by a node. Use for displaying state like balances or stored values.
Example: contract.get() returns the stored number. Await the call and format the returned value before rendering.
Write (state-modifying)
Requires a signer and gas. The user must approve the transaction in their wallet and the network must mine it.
Example: contract.set(42) sends a transaction. Show pending status and update the UI after tx.wait() confirms mining.
UX rule of thumb
Treat transaction submission and confirmation as distinct states. Provide clear feedback: requested → submitted (tx hash) → confirmed (receipt). Avoid assuming immediate state changes.
