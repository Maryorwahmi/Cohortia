Interact: ethers.js & Etherscan
Confirm state and exercise functions after deployment.
Common ethers.js calls
  • myToken.decimals() → returns decimals for formatting
  • myToken.balanceOf(address) → returns base-unit balances
  • ethers.formatUnits(value, decimals) → convert to human amount
  • myToken.connect(signer).mint(to, amount) → owner-only mint
Explorer checks
Use Etherscan's Read Contract to inspect decimals and balanceOf. Use Write Contract with your wallet for owner actions, ensuring you are connected as the owner when calling privileged methods.
Common mistake
Calling owner-only functions from a non-owner account will revert. Check the signer before sending transactions.
Example
After deployment, run a script that prints human-readable token balances and then call mint from the owner to validate permissioning.
Check
Verify that token balances change only when expected and that decimals formatting matches decimals().
Takeaway
Use both programmatic checks and explorer inspections to fully validate token behavior after deployment.
