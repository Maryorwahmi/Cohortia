Configure Networks & Env
Use env variables for RPC and private keys before public deployments.
hardhat.config.js (excerpt)
require("@nomicfoundation/hardhat-toolbox");
require("dotenv").config();

const SEPOLIA_RPC_URL = process.env.SEPOLIA_RPC_URL;
const PRIVATE_KEY = process.env.PRIVATE_KEY;

module.exports = {
  solidity: "0.8.20",
  networks: {
    sepolia: {
      url: SEPOLIA_RPC_URL || "",
      accounts: PRIVATE_KEY !== undefined ? [PRIVATE_KEY] : [],
      chainId: 11155111,
    },
    localhost: {
      url: "http://127.0.0.1:8545/",
      chainId: 31337,
    }
  },
};
.env example
SEPOLIA_RPC_URL="YOUR_INFURA_OR_ALCHEMY_URL"
PRIVATE_KEY="YOUR_METAMASK_PRIVATE_KEY"
ETHERSCAN_API_KEY="YOUR_ETHERSCAN_API_KEY"
Ensure .env is in .gitignore and never commit your PRIVATE_KEY to source control.
Example
Deploy to sepolia after configuring SEPOLIA_RPC_URL and PRIVATE_KEY in .env, then run the deploy script with --network sepolia.
Common error
Missing or malformed RPC URL will prevent your script from connecting. Confirm URL and key syntax.
Takeaway
Separate configuration from code and use environment variables for secrets and endpoints.
