Common Mistakes & Security Pitfalls
Three areas to double-check before any deploy.
Decimals conversion
Always multiply human amounts by 10**decimals() when calling _mint. Forgetting this produces values off by large orders of magnitude.
Access control
Restrict mint to owner or governance. Public mint functions enable uncontrolled inflation and immediate devaluation.
Configuration secrets
Never commit PRIVATE_KEY or RPC URLs. Use dotenv and ignore .env in version control to avoid leaking credentials.
Quick tests
Local deploy → confirm balance; non-owner mint call → expect revert; verify .env not committed.
Misconception
Relying on UI controls alone to restrict actions is insufficient—contracts enforce rules on-chain.
Takeaway
Add unit, access, and configuration checks to your deployment checklist to prevent costly mistakes.
