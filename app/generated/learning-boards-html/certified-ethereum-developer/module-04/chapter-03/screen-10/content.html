Deploy locally then to Sepolia
Verify behavior before publishing to a public network.
Local commands
npx hardhat node
npx hardhat run scripts/deploy.js --network localhost
Confirm printed token balance equals your initial supply converted by decimals.
Testnet commands
npx hardhat run scripts/deploy.js --network sepolia
Use configured environment variables for RPC and private key. After deployment, use the explorer to inspect and verify the contract.
Example
Deploy locally, then deploy identical code to Sepolia to confirm behavior across networks.
Misconception
Assuming local success guarantees production readiness—testnet deployments and verification reveal environment-specific issues.
Takeaway
Use staged deployments and explorer verification to build confidence before any mainnet work.
