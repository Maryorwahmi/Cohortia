deploy.js — Key steps
Deploy the contract and confirm balances via ethers utilities.
Deploy script (excerpt)
const { ethers } = require("hardhat");

async function main() {
  const [deployer] = await ethers.getSigners();

  console.log("Deploying contracts with the account:", deployer.address);

  const initialSupply = 1000000; // 1 million tokens
  const MyToken = await ethers.getContractFactory("MyToken");
  const myToken = await MyToken.deploy("Cohortia Token", "CHT", initialSupply);

  await myToken.waitForDeployment();

  console.log("MyToken deployed to:", myToken.target);
  console.log("Deployer balance:", ethers.formatEther(await deployer.getBalance()));
  console.log("Token deployer balance:", ethers.formatUnits(await myToken.balanceOf(deployer.address), await myToken.decimals()));
}
Notes
  • getSigners: provides accounts from the network for deploying transactions.
  • formatUnits: converts token base units back to human-readable amounts using decimals.
  • waitForDeployment: ensures the deployment completes before querying state.
Pro tip
Log both native balance and token balance to confirm gas and token state after deployment.
Example
Running the script locally prints deployer address and the expected token balance equal to initialSupply.
Common mistake
Querying token decimals incorrectly leads to wrong human-readable formatting—use myToken.decimals() when calling formatUnits.
Takeaway
A deployment script is your single source of truth for reproducible publishes and initial state verification.
