Initialize Hardhat
Commands to scaffold a reproducible project.
Step-by-step
  1. mkdir my-erc20-token && cd my-erc20-token
  2. npm init -y
  3. npm install --save-dev hardhat
  4. npx hardhat → choose JavaScript or TypeScript
  5. npx hardhat node to run a local network
Why each step matters
  • Initialize: npm init creates package.json so dependencies are tracked.
  • Install Hardhat: provides compilation, local node, and plugins for testing and deployment.
  • Local node: fast feedback loop for testing mint/burn logic without costs.
Common mistake
Skipping the local node and deploying directly to a testnet can hide simple numeric or permission bugs until after you spend funds. Always verify locally first.
Example
Run npx hardhat node and then deploy scripts to localhost to see addresses and balances printed in the terminal.
Check
Confirm the deployer address and token balance after your first local deploy.
Takeaway
A reproducible Hardhat setup reduces surprises later in deployment and verification.
