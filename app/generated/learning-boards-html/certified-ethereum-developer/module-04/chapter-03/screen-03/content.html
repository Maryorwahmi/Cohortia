Skills and Practical Outcomes
Translate objectives into repeatable developer workflows.
Compile & Test
Run compilation and local tests using Hardhat to validate contract behavior before deployment.
Deploy & Verify
Use deployment scripts and environment-based credentials to publish to Sepolia and verify on a block explorer.
Interact Safely
Query decimals and balances via ethers.js or Etherscan, and ensure actions like mint are restricted.
Secure Defaults
Prefer OpenZeppelin implementations and be careful with numeric units and access control to avoid inflation bugs.
