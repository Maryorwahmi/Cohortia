Hands-on Activity
Mint → Verify → Transfer
Lab checklist
  1. Create nft0.png and nft1.png, upload images to IPFS and note CIDs.
  2. Create 0.json and 1.json with image fields set to those CIDs.
  3. Upload metadata directory to IPFS, get base CID and set baseTokenURI.
  4. Run deploy script to Sepolia and mint sample tokens.
  5. Verify tokenURI in IPFS gateway and transfer a token to a second account.
Troubleshoot tips
  • If tokenURI returns an error, re-check the trailing slash and file naming.
  • If image doesn't appear, confirm the image JSON references the correct image CID.
  • Check transaction receipts and wait for confirmations before reading state.
