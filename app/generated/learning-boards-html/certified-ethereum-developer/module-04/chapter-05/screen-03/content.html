Module 4 › Chapter 4.5 › Skill Breakdown
01 — Setup
Project initialization
mkdir my-nft-collection
cd my-nft-collection
npm init -y
npm install --save-dev hardhat @openzeppelin/contracts dotenv
npx hardhat
Run these commands exactly to create a workspace compatible with future scripts and tests.
02 — Contract
ERC-721 with access control
You will create MyNFT.sol using OpenZeppelin imports and Counters to ensure sequential tokenIds that are safe and predictable.
03 — Metadata
Images, JSON, IPFS
Prepare images, create metadata JSON files that include image URIs, and upload them to Pinata or IPFS to get a base CID.
04 — Deploy
Hardhat deploy scripts
Deploy MyNFT with name, symbol, and baseTokenURI. Mint tokens in the script and verify tokenURI values and owner addresses after deployment.
Verification
Etherscan + IPFS gateway
Use Etherscan read/write tabs and an IPFS gateway to check the metadata JSON and image render for any minted tokenURI.
