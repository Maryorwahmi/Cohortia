safeMint example
function safeMint(address to) public onlyOwner {
  uint256 newItemId = _tokenIdCounter.current();
  _tokenIdCounter.increment();
  _safeMint(to, newItemId);
}
This flow gets a current id, increments for the next call, and mints safely to the recipient. Note that _safeMint performs a receiver check to avoid sending NFTs into contracts that can’t handle them.
Quick notes
  • onlyOwner: prevents open minting by anyone.
  • Counters start at 0 by default; decide if you want 0 or 1 as the first tokenId.
  • _safeMint vs _mint: prefer _safeMint for transfer safety when recipients might be contracts.
  • Consider pause functionality for emergency response.
