Definition
tokenURI composition
_baseTokenURI example
_baseTokenURI = "ipfs://Qm...metadataBaseCID.../"; // tokenURI(0) -> ipfs://Qm...metadataBaseCID.../0
Always test tokenURI after deployment and open it in an IPFS gateway to confirm the JSON loads and references the expected image CID.
Pitfalls & guidance
  • Missing trailing slash: concatenate carefully to avoid malformed URIs.
  • Mutable HTTP URLs: avoid if you need permanent provenance.
  • Changing baseTokenURI after mint: can be used for reveals, but document the change and reason.
