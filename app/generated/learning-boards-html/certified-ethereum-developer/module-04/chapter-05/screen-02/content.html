Learning Objectives

Learn, understand, apply, and demonstrate the ERC-721 workflow from code to minted token.

LearnUnderstandApplyMaster
01
Environment setup

Install Hardhat and OpenZeppelin, initialize a project, and verify your local build and tests run. A correct setup lets you iterate on contracts and run deployments robustly.

VERIFIED COMPETENCY MILESTONE
02
Implement ERC-721

Use OpenZeppelin's ERC721, Counters for tokenIds, and Ownable for access control. This yields secure minting and predictable token identifiers.

VERIFIED COMPETENCY MILESTONE
03
Host metadata on IPFS

Prepare images and JSON metadata, upload to Pinata or IPFS CLI, and record the base CID. Immutable assets strengthen provenance.

VERIFIED COMPETENCY MILESTONE
04
Deploy and verify

Run a Hardhat deployment script to Sepolia, mint test tokens, and use Etherscan and an IPFS gateway to confirm tokenURI and ownership.

VERIFIED COMPETENCY MILESTONE
