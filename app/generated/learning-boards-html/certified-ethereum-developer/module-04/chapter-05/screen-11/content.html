Process
Deployment verification
Steps after deployment
  1. Find the contract address output by the script and open the network Etherscan.
  2. Call ownerOf(0) and tokenURI(0) from the Read Contract tab.
  3. Open the value of tokenURI in an IPFS gateway to view the JSON and image.
  4. Try transferFrom or safeTransferFrom from the Write Contract tab with MetaMask to test transfers.
Troubleshooting
  • tokenURI not working: check baseTokenURI trailing slash and file names.
  • Image not loading: confirm image CID in the JSON points to the correct image CID.
  • Mint tx pending: ensure you await receipts before calling ownerOf in scripts.
