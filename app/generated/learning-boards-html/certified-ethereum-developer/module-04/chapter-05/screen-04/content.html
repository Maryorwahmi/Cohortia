Core Concept
Editor & terminal ready
Commands to initialize
mkdir my-nft-collection
cd my-nft-collection
npm init -y
npm install --save-dev hardhat @openzeppelin/contracts dotenv
npx hardhat
Run the scaffold step and select a basic sample project to create directory structure for contracts and scripts.
Checklist & tips
  • Set Solidity compiler to 0.8.20 if you will use the provided MyNFT.sol syntax.
  • Store private keys in a .env file and reference them in hardhat.config.js; do not commit .env.
  • Keep @openzeppelin/contracts and Hardhat versions compatible to avoid import errors.
  • Run npx hardhat compile to catch early issues before writing deployment scripts.
