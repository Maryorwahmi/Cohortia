Process
Directory upload → baseTokenURI
Upload steps
  1. Upload images and copy their CIDs into the respective JSON files.
  2. Place JSON files in a metadata/ directory and upload that directory to Pinata or IPFS CLI.
  3. Capture the returned CID and form baseTokenURI as ipfs://<CID>/
  4. Use that baseTokenURI when deploying MyNFT so tokenURI resolves correctly.
Common mistakes
  • Forgetting the trailing slash when your files are named by number.
  • Uploading inconsistent file names so tokenIds don't map to files.
  • Not pinning files leading to eventual unavailability.
