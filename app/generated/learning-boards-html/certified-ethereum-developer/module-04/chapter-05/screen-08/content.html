Process
Assets → metadata → base CID
Example metadata file (1.json)
{
  "name": "My NFT #1",
  "description": "The first NFT in my Cohortia collection.",
  "image": "ipfs://Qm...image1CID...",
  "attributes": [
    { "trait_type": "Edition", "value": "1/100" }
  ]
}
Make sure the image field uses the IPFS CID returned when you upload the actual image file.
Checklist before upload
  • Match file names to tokenIds (0.json, 1.json).
  • Ensure image values point to ipfs://CIDs not HTTP placeholders.
  • Keep attribute schema consistent across items for marketplace compatibility.
  • Test one tokenURI in an IPFS gateway to confirm the image loads.
