Metadata functions
  • name(): human-readable token name, e.g., MyToken.
  • symbol(): ticker-like abbreviation, e.g., MTK.
  • decimals(): number of decimal places; used to convert between human amounts and base units.
  • totalSupply(): total tokens in base units.
Practical rule: always call decimals() in your client or script and compute amount * (10 ** decimals) before sending transactions. Present both base units and human values in your UI so users can verify amounts.
Concrete example
If decimals() returns 6 and you want to transfer 1.5 tokens, compute: 1.5 * 10^6 = 1_500_000. Call transfer(recipient, 1500000). Sending the number 1 would transfer one base unit, not one whole token. Always scale in your scripts.
Common mistake
Passing human amounts without scaling leads to transfers that are orders of magnitude off. This is a frequent source of lost tokens in demos and scripts.
