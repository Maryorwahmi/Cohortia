ERC-20 Standard
A minimal interface for fungible tokens that ensures interoperability.
Decimals & Units
decimals() determines base units; always scale human amounts before transactions.
Approve / transferFrom
approve grants permission; transferFrom consumes allowance to move tokens.
Takeaway
Treat ERC-20 as a predictable interface: scale amounts correctly, manage allowances carefully, and prefer audited implementations for production systems.
