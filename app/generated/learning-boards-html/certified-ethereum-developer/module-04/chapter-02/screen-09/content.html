Starter code
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract MockERC20 is ERC20 {
  constructor(string memory name_, string memory symbol_, uint256 initialSupply_) ERC20(name_, symbol_) {
    _mint(msg.sender, initialSupply_ * (10 ** decimals())); // Mint initial supply to deployer
  }

  function mint(address to, uint256 amount) public {
    _mint(to, amount);
  }

  function decimals() public view virtual override returns (uint8) {
    return 18; // Standard 18 decimals
  }
}
Note the scaling in the constructor: initialSupply_ * (10 ** decimals()). That mirrors what you must do in scripts. Also note the public mint helper — useful in tests but unsafe in production without access controls.
What to try
  • Deploy locally with a name, symbol, and initial supply and check balances.
  • Call mint from another account to see balance changes and events.
  • Practice approve and transferFrom flows between test accounts.
Safety note

Do not copy test helpers like a public mint into production contracts unless guarded by proper access control.
