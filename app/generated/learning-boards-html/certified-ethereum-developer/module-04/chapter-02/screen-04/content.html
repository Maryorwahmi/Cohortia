Module 4 › Chapter 4.2 › What is ERC-20?
Definition

ERC-20 is a standard interface for fungible tokens that specifies a small set of functions and two events. It enables wallets, exchanges, and contracts to handle tokens in a predictable way.

Key functions
  • Metadata: name(), symbol(), decimals(), totalSupply()
  • Balances & transfer: balanceOf(), transfer()
  • Allowance flow: approve(), allowance(), transferFrom()
Key Takeaway

ERC-20’s minimal interface creates broad compatibility: if a token implements the functions and emits the events, external tools can work with it.

Analogy & Example
Think of ERC-20 as a bank’s API specification for accounts and transfers. Any bank that exposes the same endpoints can be integrated into the same accounting dashboard. For example, a wallet reads decimals to display human amounts and listens for Transfer events to update transaction history without heavy state reads.
Event
Transfer
Emitted when tokens move, letting off-chain services track transfers efficiently.
Event
Approval
Emitted when an allowance is set, enabling delegated transfer workflows.
Common misconception: ERC-20 does not dictate how tokens are minted or burned, or how balances are internally accounted for. It only guarantees an interface that external systems can call and rely on.
