Module 4 › Chapter 4.2 › Allowance Lifecycle
Allowance timeline
1. approve
Owner grants allowance. Approval event emitted.
2. transferFrom
Spender moves tokens, allowance reduced by the amount.
3. approve change
Owner may reset to zero then set new allowance to avoid races.
4. audit
Observe Approval and Transfer events and call allowance() to verify remaining permission.
A best practice is to show both raw base-unit changes and human-readable token amounts when displaying this timeline so the user can reconcile actions easily.
