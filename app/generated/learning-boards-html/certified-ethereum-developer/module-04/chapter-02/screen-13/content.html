# After deploy, check balances in a script using ethers
const decimals = await token.decimals();
const amount = ethers.utils.parseUnits('1.5', decimals); // scales to base units
await token.transfer(recipient, amount);

# Approve and transferFrom
await token.connect(owner).approve(spender.address, ethers.utils.parseUnits('500', decimals));
console.log('allowance before', (await token.allowance(owner.address, spender.address)).toString());
await token.connect(spender).transferFrom(owner.address, recipient.address, ethers.utils.parseUnits('100', decimals));
console.log('allowance after', (await token.allowance(owner.address, spender.address)).toString());
These commands show the critical steps: scale with decimals, approve, then transferFrom while logging allowance to observe the lifecycle.
Mini-quiz (at 10 minutes)
Question: If decimals() returns 6 and you want to send 1.5 tokens, what integer do you pass to transfer()? Answer: 1_500_000. Practice this conversion in your script to avoid unit errors.
Lab tip

Log both human-readable and base-unit values in your scripts for clarity. Reset allowances when updating to avoid race windows.
