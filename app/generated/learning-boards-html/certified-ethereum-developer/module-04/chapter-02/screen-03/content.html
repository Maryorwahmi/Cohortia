Module 4 › Chapter 4.2 › Learning Objectives — Skills & Safety
Objective actions
  1. Read metadata and balances using contract calls to name, symbol, decimals, totalSupply, balanceOf.
  2. Convert human amounts to base units with decimals before transfers to avoid unit errors.
  3. Grant an allowance and execute transferFrom from a spender account, verifying allowance decrement.
  4. Practice resetting allowances to zero before changing values or using safe allowance helpers.
Mnemonic
Think: Metadata → Balances → Approve → Spend. Each step has an associated function and event you will use in the lab.
