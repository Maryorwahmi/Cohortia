Module 5 › Chapter 4.6 › Mixed Fungibility
Comparison table
ERC-20: single contract → single fungible asset
ERC-721: single contract → multiple unique tokens
ERC-1155: one contract → many ids, each id defines fungibility
Example: ticket lifecycle
Define id 10 as general-admission tickets (fungible). After the event, a specific ticket can be converted to id 10A for a stamped collectible (non-fungible). ERC-1155 models both states cleanly.
Design tip
Mnemonic

Plan ids as lifecycle buckets and map metadata URIs to reflect state transitions.
