ERC-1155 Checks
  • Always specify the token id in balanceOf and transfers.
  • Ensure ids and amounts arrays align for batch calls.
  • Validate receiver contracts implement ERC1155TokenReceiver.
ERC-4626 Checks
  • Test convertToShares/convertToAssets round-trip after yield events.
  • Define rounding rules and apply them consistently.
  • Verify totalAssets includes fees and accrued yield accurately.
Approval & UX

Make operator approvals explicit in UX, and educate users about setApprovalForAll scope to avoid surprises.

Testing checklist
  1. Unit test id semantics and batch flows
  2. Simulate deposits and yield for vaults
  3. Measure gas in staging for typical bundles
