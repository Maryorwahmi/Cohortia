Integration flow
  1. Discover vault asset type using asset()
  2. Read totalAssets() and totalSupply() for conversion context
  3. Preview deposit via convertToShares
  4. Execute deposit or mint and track shares
Practical checklist
  • Confirm asset and decimals match your expectations
  • Test conversions before executing state changes
  • Monitor for fees and ensure totalAssets reflects them
Key Takeaway

A standardized vault API reduces integration overhead and makes composable DeFi strategies tractable across many implementations.
