Module 5 › Chapter 4.6 › ERC-1155 Model
Core architecture
A single contract maps token ids to per-account balances. Operator approvals let third parties manage all ids for an owner.
balanceOf(account, id) — per-id balance
balanceOfBatch(accounts[], ids[]) — multi-balance query
safeTransferFrom / safeBatchTransferFrom — single or batched transfers
setApprovalForAll(operator, approved) — operator model
Example: Game inventory
Define id 1 as gold coins (supply large), id 2 as health potion (supply limited but fungible), id 1001 as a unique sword (supply = 1). Use batch transfers to move multiple prize tiers in one transaction.
