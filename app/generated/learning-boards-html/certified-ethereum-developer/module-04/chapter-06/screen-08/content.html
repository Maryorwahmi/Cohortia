Module 5 › Chapter 4.6 › ERC-4626 Intro
What ERC-4626 standardizes
  • deposit(assets, receiver)
  • withdraw(assets, receiver, owner)
  • mint(shares, receiver)
  • redeem(shares, receiver, owner)
  • convertToShares / convertToAssets
Concrete example

A vault that accepts USDC exposes convertToShares so a wallet can show users how many vault tokens they will receive for a deposit today. As yield accumulates, convertToAssets maps shares back to growing underlying assets.

Code-like signatures
function deposit(uint256 assets, address receiver) external returns (uint256 shares);
function mint(uint256 shares, address receiver) external returns (uint256 assets);
function redeem(uint256 shares, address receiver, address owner) external returns (uint256 assets);
function convertToShares(uint256 assets) external view returns (uint256 shares);
function convertToAssets(uint256 shares) external view returns (uint256 assets);
