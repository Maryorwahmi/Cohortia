ERC-6551 — NFT Bound Accounts

Allows NFTs to control smart contract wallets so an NFT can hold tokens and interact with contracts directly. This enables programmable NFTs with owned resources.

ERC-7579 — Modular Smart Accounts

Specifies pluggable account modules for signature schemes, recovery, and additional features to improve account abstraction and UX.

Use case: bundled trades

An NFT owning a wallet allows marketplaces to transfer not only the token but also the assets held within it, enabling richer exchange models.

Security note

These standards expand capability but increase responsibility: module security, upgrade paths, and clear UX about permissions become essential.
