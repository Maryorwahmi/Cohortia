Module 4 › Chapter 4.4 › tokenURI & Metadata
tokenURI pattern
tokenURI(uint256 tokenId) returns a URI pointing at a JSON object that describes the NFT's content and attributes.
Typical metadata JSON
{
  "name": "My Awesome NFT #1",
  "description": "A unique digital collectible from Cohortia.",
  "image": "ipfs://QmbWqxBEKC3P8tqsKc98xmWNzrzgNf2EwADgKsscsK",
  "attributes": [
    { "trait_type": "Background", "value": "Blue" },
    { "trait_type": "Mood", "value": "Happy" }
  ]
}
Immutability concerns
If tokenURI points to a mutable HTTP URL the asset and metadata can change, breaking permanence and trust. Prefer IPFS or similar immutable storage.
Common mistake
Using standard HTTP URLs for metadata allows creators to alter content, undermining provenance and permanence.
Key Takeaway

tokenURI bridges on-chain identity and off-chain data. Use immutable URIs to preserve the NFT's intended permanence.
