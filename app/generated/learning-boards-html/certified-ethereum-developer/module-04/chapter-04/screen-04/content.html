Module 4 › Chapter 4.4 › Uniqueness and tokenId
Definition
Each tokenId is a unique identifier for one NFT inside a contract. It is the basis for ownership, provenance, and metadata linking.
ownerOf(uint256 tokenId)
Returns the address that owns the specified tokenId. Use to verify ownership on-chain.
balanceOf(address owner)
Returns how many unique tokenIds the address holds. This is a count, not a measure of interchangeability.
Analogy
Think of tokenIds as labels on paintings in a gallery: one painting per label, each with a unique provenance record.
Example
// Example read flow
owner = contract.ownerOf(1)
// returns address that owns tokenId 1
count = contract.balanceOf(address)
// returns how many distinct NFTs address holds
Key Takeaway

tokenId is the persistent identity for an NFT; ownership and metadata reference that id to prove uniqueness.
