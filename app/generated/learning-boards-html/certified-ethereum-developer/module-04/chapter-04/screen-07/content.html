Why events matter
Events allow off-chain services to track transfers, approvals, and operator changes without expensive state queries.
Transfer
Emitted on every ownership change; indexed fields include from, to, tokenId.
Approval
Emitted when a single token's approved address changes; helps UIs show list permissions.
ApprovalForAll
Emitted when an operator is approved or revoked for all of an owner's tokens.
Example event snippet
Transfer(from: 0x..A, to: 0x..B, tokenId: 42)
Approval(owner: 0x..A, approved: 0x..C, tokenId: 42)
ApprovalForAll(owner: 0x..A, operator: 0x..M, approved: true)
Key Takeaway

Events are the observable signals wallets and marketplaces rely on to maintain accurate ownership and approval views.
