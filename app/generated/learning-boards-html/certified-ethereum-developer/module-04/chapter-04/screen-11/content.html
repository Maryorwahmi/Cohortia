Question 1
Explain the difference between transferFrom and safeTransferFrom and when to use safeTransferFrom.
Model answer
Both transfer ownership, but safeTransferFrom checks whether a contract recipient implements the receiver interface and reverts if it cannot accept the token. Use safeTransferFrom when sending to a contract to avoid accidental permanent loss.
Question 2
What are the risks of serving token metadata via mutable HTTP links compared to decentralized storage like IPFS?
Model answer
Mutable HTTP links allow creators to change or remove metadata, create a single point of failure, and reintroduce trust in a centralized host. Decentralized storage with immutable CIDs preserves permanence and aligns with NFT provenance expectations.
