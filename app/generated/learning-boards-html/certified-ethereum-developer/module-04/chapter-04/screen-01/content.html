Why it matters
NFTs represent unique ownership. Correct transfers and immutable metadata preserve value and trust.

Unique tokens
Each tokenId is a unique identifier. Think of a gallery of paintings where every canvas has its own label.
ownerOf(uint256 tokenId)
Returns the address that owns this tokenId. Use it to verify provenance.
Metadata link
tokenURI points to the token's JSON. Store that JSON in immutable storage so the token's identity remains stable.
tokenURI(uint256 tokenId)
Returns a URI to metadata JSON holding name, description, image, and attributes.
