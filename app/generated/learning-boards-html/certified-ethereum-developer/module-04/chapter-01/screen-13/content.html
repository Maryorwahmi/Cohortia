Safety first
Checklist of practical checks before trusting or deploying tokens.
Verify interface
Confirm required functions and events for the chosen ERC are present and behave as expected.
Test behavior
Run tests that validate transfers, approvals, and edge cases like zero balances and reentrancy where applicable.
Watch for dangerous extensions
Ensure added functions don't alter required behavior or introduce hidden access controls.
Audit and review
Audits reduce risk but do not remove it. Combine audits with automated tests and careful integration checks.
Common mistake

Trusting a token because it uses a known library without inspecting how it was configured or extended.
