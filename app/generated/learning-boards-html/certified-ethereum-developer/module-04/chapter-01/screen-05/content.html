Fungible tokens and ERC-20
Identical, interchangeable units suitable for currency-like uses.
Required functions
  • totalSupply() — total tokens in existence
  • balanceOf(address) — account balance
  • transfer(to, amount) — move tokens
  • approve / transferFrom — allowance pattern
Concrete example
A stablecoin where each unit represents the same value; wallets show balances and exchanges accept transfers uniformly.
Key Takeaway

Use ERC-20 when units are interchangeable and identity per unit is unnecessary.

Design considerations
Fungible tokens simplify accounting but cannot carry unique per-unit metadata. Choose them for points, currencies, and fungible shares.
Analogy
A bag of identical coins: swapping one coin for another makes no difference to value or identity.
Common mistake
Trying to represent unique collectibles with ERC-20. If each unit needs identity, choose an NFT standard instead.
