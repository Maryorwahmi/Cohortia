ERC (spec)
A standardized interface that defines required functions and events for token compatibility.
Token types
Fungible (ERC-20), Non-fungible (ERC-721), Semi-fungible / Multi-token (ERC-1155).
Benefits
Fractional ownership, transparent provenance, and programmable behavior through contracts.
Bottom line
Standards enable scale. Choose standards by asset interchangeability, metadata needs, and lifecycle requirements.
