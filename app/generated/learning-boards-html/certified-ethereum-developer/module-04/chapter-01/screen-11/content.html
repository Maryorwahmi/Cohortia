Block explorer checklist
A practical method to confirm ERC adherence and discover extensions.
Step 1: Find contract
Locate the contract address for a known token and open its Contract tab.
Step 2: Read Contract
Confirm functions like balanceOf or ownerOf exist and return expected values for test addresses.
Step 3: Events
Check Transfer and Approval events to ensure they appear during transfers and approvals.
Pitfall
Do not equate function presence with correct behavior — examine event history and transaction effects.
Try this
Pick one ERC-20 and one ERC-721 contract and list the functions you observe. Note any extensions.
Analogy
Think of functions as an API spec and events as logs that prove behavior occurred.
Key Takeaway
Inspection shows whether a contract behaves as the declared standard, not just whether it claims to.
