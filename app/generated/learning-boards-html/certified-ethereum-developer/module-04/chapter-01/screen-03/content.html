Verify standards by inspection
Checklist
  • ERC-20: name, symbol, decimals, totalSupply, balanceOf, transfer, approve, Transfer & Approval events.
  • ERC-721: ownerOf, tokenURI, safeTransferFrom, transferFrom, Transfer event, unique token IDs.
  • ERC-1155: batch operations and multi-token support for semi-fungible cases.
Milestone
Open a block explorer and find a token contract. Confirm the Read Contract exposes the expected functions. Note any extensions beyond the base standard.
Mnemonic
Interface first, implementation second.
Common mistake
Assuming a token labeled as a coin is fungible without checking the contract.
Reflection
Which function would confirm an ERC-721 token is unique? How would you verify it?
