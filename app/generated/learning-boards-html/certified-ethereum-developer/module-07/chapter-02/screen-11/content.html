Task example
task("set-greeting", "Sets a new greeting on the Greeter contract")
  .addParam("contract", "The Greeter contract address")
  .addParam("newgreeting", "The new greeting message")
  .setAction(async (taskArgs) => {
    const Greeter = await ethers.getContractFactory("Greeter");
    const greeter = Greeter.attach(taskArgs.contract);
    const tx = await greeter.setGreeting(taskArgs.newgreeting);
    await tx.wait();
    console.log(`Greeting set to "${taskArgs.newgreeting}" on ${taskArgs.contract}`);
  });
How to run
Invoke the task with npx hardhat set-greeting --contract 0x... --newgreeting "Hello" --network sepolia
Benefits
  • Parameterize interactions for repeatable maintenance.
  • Expose lightweight CLI for non-developers or scripts.
  • Wait for confirmations to provide deterministic success reporting.
Key Takeaway

Use tasks to encapsulate recurring post-deploy actions and reduce manual errors in maintenance steps.
