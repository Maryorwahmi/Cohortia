Process

Run a script on Sepolia

# Run deployment on Sepolia
npx hardhat run scripts/deployGreeter.js --network sepolia
Pre-run checks
  • Ensure SEPOLIA_RPC_URL is reachable and returns a chain ID.
  • Confirm deployer address from PRIVATE_KEY has test ETH.
  • Double-check chainId and account format in config.
Terminal output example
Deploying contracts with the account: 0xYourAddress
Account balance: 1000000000000000000
Greeter deployed to: 0xDeployedAddress
Post-run action
Copy the deployed address and verify it on the block explorer or via etherscan plugin when available.
Key Takeaway

The --network flag selects the runtime target; ensure your environment and account are ready before running.
