Learning Objectives

Targeted competencies and verified milestones

Bloom: Learn → Understand → Apply → Master
01
Configure networks
Edit hardhat.config.js to add RPC URLs, chain IDs and accounts so deployments sign correctly. Verified competency: run a script against Sepolia.
VERIFIED COMPETENCY MILESTONE
02
Write deployment scripts
Use ethers.getContractFactory and call deploy, then wait for the transaction to be mined. Verified competency: deploy Greeter locally and read state.
VERIFIED COMPETENCY MILESTONE
03
Manage secrets safely
Load PRIVATE_KEY and RPC keys from a .env file and keep it in .gitignore to avoid leaks. Verified competency: run a script using env vars only.
VERIFIED COMPETENCY MILESTONE
04
Diagnose deployment errors
Recognize insufficient funds, constructor revert, and chain ID mismatch, and apply fixes. Verified competency: troubleshoot a failed deployment and redeploy.
VERIFIED COMPETENCY MILESTONE
