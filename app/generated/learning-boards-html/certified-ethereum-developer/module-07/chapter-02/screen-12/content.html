Module 7 › Chapter 7.2 › Contract verification
Process
Include etherscan.apiKey in config and run the verify command after deployment.
# Verify contract
npx hardhat verify --network sepolia 0xDeployedAddress "ConstructorArg1"
If verification fails, confirm the compiler version, optimisation settings, and constructor arguments match the deployed build.
Why verify?
  • Enables public inspection of source code and ABI.
  • Makes it easier for wallets and services to interact with the contract.
  • Provides transparency and trust to users.
Key Takeaway

Verification does not change on-chain state; it publishes metadata that confirms the source behind the deployed bytecode.
