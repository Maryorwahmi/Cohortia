Core Concept

Hardhat overview

An environment for compiling, testing, running a local chain, scripting deployments, and extending via plugins.

Hardhat Network
A local in-memory chain for fast iteration and deterministic testing.
Plugins & Ethers.js
Integrates with ethers.js to deploy and interact with contracts programmatically.
Tasks
Custom CLI actions for repeatable post-deploy steps.
Key Takeaway

Hardhat brings local development and deployment tools together so you can iterate, test, and deploy reliably.

Analogy: Hardhat is the developer's terminal with a sandboxed blockchain
Quick terminal demo
# start local network
npx hardhat node

# run a deploy script locally
npx hardhat run scripts/deployGreeter.js --network localhost
Why this helps
  • Faster feedback than testnets.
  • Deterministic block progression for tests.
  • Easy integration with ethers.js for real scripting.
