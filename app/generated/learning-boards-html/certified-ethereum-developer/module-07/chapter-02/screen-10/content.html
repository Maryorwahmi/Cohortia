Architecture
Gas fields to consider
  • gasLimit — max gas units the tx can consume.
  • gasPrice — legacy gas price per unit.
  • maxFeePerGas & maxPriorityFeePerGas — EIP-1559 parameters for modern networks.
Hardhat gasReporter snippet
gasReporter: {
  enabled: process.env.REPORT_GAS !== undefined,
  currency: "USD",
  coinmarketcap: process.env.COINMARKETCAP_API_KEY,
},
Practical advice
  • Run tests with the gas reporter to estimate deployment cost.
  • Monitor provider fee suggestions and set a small buffer for production.
  • If transactions are consistently pending, raise maxPriorityFeePerGas first for speed.
Key Takeaway

Treat gas estimates as planning data and adjust fee parameters dynamically to match real network conditions.
