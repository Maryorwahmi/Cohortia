Objective Checklist

Quick actions you can perform to confirm each learning milestone.

Network Configuration
  • Confirm RPC URL responds with eth_chainId.
  • Match chainId in hardhat.config.js to the network.
Deployment Scripts
  • Run a dry local deploy to verify compilation and constructor arguments.
  • Log deployer address and balance before sending tx.
Secrets
  • Use dotenv and process.env to read keys.
  • Add .env to .gitignore and never commit keys.
Diagnostics
  • Interpret insufficient funds, revert, and pending transaction messages.
  • Adjust gas settings or provider if transactions aren’t mined.
