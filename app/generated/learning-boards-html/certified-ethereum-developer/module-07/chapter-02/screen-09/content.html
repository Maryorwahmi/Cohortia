Module 7 › Chapter 7.2 › Common Errors
Error: insufficient funds
Cause: Deployer address lacks ETH. Fix: Fund from a faucet or transfer test ETH, then retry.
Error: constructor revert
Cause: Constructor logic failed or wrong args. Fix: Verify parameters and run local tests to replicate the failure.
Error: tx not mined within X seconds
Cause: Low gas price or provider issue. Fix: Increase gasPrice or EIP-1559 fields or switch provider.
Error: incorrect chainId
Cause: chainId in config mismatches network. Fix: Set chainId to the network's ID in hardhat.config.js.
Quick diagnostic checklist
  • Check deployer balance.
  • Simulate constructor locally with hardhat or a unit test.
  • Verify RPC provider responsiveness and gas settings.
  • Confirm chainId and account configuration.
Common misconception
Treating timeouts as random: usually they indicate provider issues or insufficient gas — not an inscrutable network error.
Key Takeaway

Follow the diagnostic pattern: balance, constructor, gas/provider, chainId — in that order — to quickly resolve deployment failures.
