Module 7 › Chapter 7.1 › Network Comparison
Mainnet
Use for production. Requires real ETH. Final and immutable.
  • Funding: real ETH
  • Speed: variable, can be slow with congestion
  • Use case: live dApps and value transfer
Sepolia (Testnet)
Public testnet that mimics Mainnet characteristics while using test ETH.
  • Funding: test ETH from faucets
  • Speed: similar to public network timing, subject to congestion
  • Use case: staging and end-to-end testing
Hardhat Network (Local)
Local development chain with instant confirmations and reset capability.
  • Funding: provided by local node accounts
  • Speed: instant mining for rapid iteration
  • Use case: unit testing, debugging, and quick iteration
Decision rule

Start development on a local chain, stage on Sepolia for realistic interaction tests, and deploy to Mainnet only after verification and budget planning.
