Module 7 › Chapter 7.1 › Hardhat Lab
Quick commands
mkdir my-first-deployment
cd my-first-deployment
npm init -y
npm install --save-dev hardhat
npx hardhat        # Create a JavaScript project
npx hardhat compile
npx hardhat run scripts/deploy.js

# or run a local node in another terminal
npx hardhat node
npx hardhat run scripts/deploy.js --network localhost
Expected output
Console will print the deployer address, the account balance, and the deployed contract address. Use the printed address with the ABI from artifacts to call the greet function and verify the initial greeting.
Troubleshooting
  • If you see insufficient funds, check which account is being used and top it up on testnets or use the local node's funded accounts.
  • If the transaction is slow, ensure you are on the intended network and confirm current gas pricing.
  • If artifacts are missing, re-run compile and check hardhat.config.js for the correct paths.
