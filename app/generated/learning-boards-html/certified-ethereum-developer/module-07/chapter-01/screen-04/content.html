Module 7 › Chapter 7.1 › Ethereum Network Types
Definition

Mainnet, Testnet, Local

A concise label: Mainnet is production; testnets like Sepolia are staging; local networks provide speed and control for development.

Mainnet — production, requires real ETH, transactions are immutable and costly.
Testnet (Sepolia) — realistic environment using test ETH, useful for staging and end-to-end testing.
Local network (Hardhat/Ganache/Anvil) — instant confirmations, full reset, great for quick iteration.
Why it matters
  • Choosing the wrong network risks spending real ETH or missing environment-specific bugs.
  • Testnets reveal issues like gas usage and interactions with external services without financial risk.
  • Local chains speed development but cannot guarantee Mainnet behavior under congestion.
Comparison
Mainnet
Real ETH, high costs, production safety required.
Sepolia
Test ETH, realistic latency, useful for staging.
Hardhat/Ganache
Instant blocks, resets, deterministic testing.
Key Takeaway

Use local networks for development speed, testnets for realistic staging, and Mainnet only after full verification and funding.
