Definition
cast call and cast send
# Read a view function
cast call <GREETER_CONTRACT_ADDRESS> "greet()(string)" --rpc-url $SEPOLIA_RPC_URL

# Send a transaction (signed)
cast send <GREETER_CONTRACT_ADDRESS> "setGreeting(string)" "Welcome to Cohortia!" --private-key $FOUNDRY_PRIVATE_KEY --rpc-url $SEPOLIA_RPC_URL
Notes & pitfalls
  • Include the return type in call signatures so cast can decode results.
  • cast send requires a private key; never expose keys in code repositories.
  • Use cast for quick validation and Forge scripts for repeatable deployment logic.
