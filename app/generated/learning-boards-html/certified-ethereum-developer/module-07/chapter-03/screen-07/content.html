Definition
Project structure
src/
Contracts like Greeter.sol and MyNFT.sol live here.
script/
Forge deployment scripts that inherit Script.sol and implement run().
lib/
Third-party libraries installed with forge install.
test/
Solidity tests executed with forge test.
Script structure example
A deployment script is a Solidity contract that returns the deployed contract instance from run(), and uses vm helpers to broadcast transactions.
// script/DeployGreeter.s.sol
// SPDX-License-Identifier: MIT
// pragma solidity ^0.8.20;
// import "forge-std/Script.sol"; import "../src/Greeter.sol";
// contract DeployGreeter is Script { function run() public returns (Greeter) { vm.startBroadcast(); Greeter g = new Greeter("Hello"); vm.stopBroadcast(); return g; } }
Key Takeaway

Use the conventional folders for predictable automation and easy sharing across teams.
