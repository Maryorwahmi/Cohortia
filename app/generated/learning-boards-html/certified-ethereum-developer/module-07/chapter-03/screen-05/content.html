Definition
Forge · Cast · Anvil
Forge
Compile, test, run scripts. Use forge init and forge script to manage files and deployments.
Example commands:
forge init my-foundry-project
forge script script/Deploy.s.sol:Deploy --rpc-url $RPC --broadcast
Cast
Call view functions and send transactions without a full script. Ideal for quick checks and reads.
Example commands:
cast call <ADDRESS> "greet()(string)" --rpc-url $RPC
cast send <ADDRESS> "setGreeting(string)" "Hi" --private-key $PK --rpc-url $RPC
Anvil
A local node for fast, isolated development. Run Anvil to test scripts and transactions locally before targeting live networks.
Why it matters
Use Anvil to iterate quickly without spending testnet gas and to inspect state locally.
