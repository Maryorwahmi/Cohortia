Process Flow
Running forge script and important flags
Simulate first. Broadcast when ready. Verbosity helps debugging.
# Set environment variables
export FOUNDRY_PRIVATE_KEY="YOUR_DEPLOYER_PRIVATE_KEY_HERE"
export SEPOLIA_RPC_URL="https://eth-sepolia.example"

# Run script and broadcast
forge script script/DeployGreeter.s.sol:DeployGreeter --rpc-url $SEPOLIA_RPC_URL --broadcast --verify -vvvv
--broadcast: send transactions
--verify: attempt explorer verification
-vvvv: verbose logging and diagnostics
Key Takeaway

Always simulate first, then run with --broadcast when you intend to publish transactions. Use -vvvv to inspect low-level details.
