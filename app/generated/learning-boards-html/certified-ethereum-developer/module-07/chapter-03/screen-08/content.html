Code Walkthrough
Forge scripts in Solidity
Scripts inherit Script.sol and use vm helpers to control broadcasting.
// script/DeployGreeter.s.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "forge-std/Script.sol";
import "../src/Greeter.sol";

contract DeployGreeter is Script {
  function run() public returns (Greeter greeter) {
    // Start broadcasting transactions from the configured deployer
    vm.startBroadcast();

    greeter = new Greeter("Hello, Foundry!");

    vm.stopBroadcast();
  }
}
Explanation & pitfalls
  • vm.startBroadcast marks when transactions are signed and sent.
  • Without --broadcast, forge script only simulates actions locally.
  • Private keys are read from FOUNDRY_PRIVATE_KEY or CLI args; never hardcode keys.
Pro Tip
Simulate with high verbosity before broadcasting; use -vvvv to inspect transaction steps.
