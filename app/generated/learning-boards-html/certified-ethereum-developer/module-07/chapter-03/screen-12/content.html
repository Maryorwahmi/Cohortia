Common mistakes and safety notes
Omitting --broadcast
Without it forge script runs in simulation only; no on-chain effects.
Incorrect keys or RPC
Ensure FOUNDRY_PRIVATE_KEY and RPC URL are set and funded for the target chain.
Gas and funding
Specify gas-price options if necessary and confirm account balance.
Key security
Never hardcode secrets. Use environment variables and .gitignore entries.
Common Mistake

Simulating without broadcasting is useful, but always verify you intended simulation versus a real deployment before finishing.
