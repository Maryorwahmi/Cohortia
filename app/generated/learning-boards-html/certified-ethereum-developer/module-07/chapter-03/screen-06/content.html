Process Flow
Install and initialize
A quick terminal demo sequence you will run locally to set up a new project.
1. Install Foundry: run foundryup
2. Initialize a project: forge init my-foundry-project
3. Add libraries: forge install OpenZeppelin/openzeppelin-contracts --no-commit
Check the project layout and add .gitignore entries for private key environment files.
Terminal demo notes
# Example sequences shown as terminal actions
foundryup
forge init my-foundry-project
cd my-foundry-project
forge install OpenZeppelin/openzeppelin-contracts --no-commit
Tip: verify the presence of src, script, lib, and test before writing scripts.
Key Takeaway

Install once with foundryup, scaffold with forge init, then add dependencies like OpenZeppelin before coding.
