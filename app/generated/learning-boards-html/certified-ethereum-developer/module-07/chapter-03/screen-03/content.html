Learning Objectives — Practical Focus
Mapped to commands and checks you will perform in a terminal demo
01 — Initialize & verify
Command: forge init my-foundry-project. Verify src and script directories exist.
02 — Know the tools
Forge compiles and runs scripts, Cast is for CLI calls, Anvil is a local test node.
03 — Broadcast safely
Use vm.startBroadcast and set FOUNDRY_PRIVATE_KEY to sign transactions securely.
04 — Interact with Cast
Use cast call for reads and cast send for signed transactions with the private key provided by env.
