Learning Objectives

Skills to apply when optimizing gas and arranging data.

Bloom: Learn → Understand → Apply → Master
01
Select data structures
Choose mapping, struct or array based on lookup needs and iteration frequency.
VERIFIED COMPETENCY MILESTONE
02
Apply storage packing
Order struct members to pack small types into one 32-byte slot and lower SSTORE count.
VERIFIED COMPETENCY MILESTONE
03
Identify gas hotspots
Spot expensive operations like storage writes, external calls, and unbounded loops before deployment.
VERIFIED COMPETENCY MILESTONE
04
Use data locations correctly
Prefer calldata for external read-only complex inputs and memory for temporary variables to reduce copies and gas.
VERIFIED COMPETENCY MILESTONE
