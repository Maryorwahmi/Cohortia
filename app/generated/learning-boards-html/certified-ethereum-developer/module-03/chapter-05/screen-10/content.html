Practical strategies

Use this checklist when reviewing contract code for gas improvements.

Pack variables
Group small types to fit into one slot.
Prefer calldata
Use for read-only external complex inputs to avoid copies.
Cache reads
Read storage once into memory and reuse the local value.
Delete unused storage
Setting slots to zero can provide partial gas refunds.
Use events
Emit logs for history instead of storing large arrays on-chain.
Paginate loops
Break large work into bounded transactions to avoid gas limits.
Measure
Use a gas profiler to prioritize fixes — optimize frequent patterns first.
