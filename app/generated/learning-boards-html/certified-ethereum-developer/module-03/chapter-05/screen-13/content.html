Optimize UserProfile — Steps

1. Design struct
Order address, uint64, uint16, bool so the total fits in one slot.
2. Use mapping
Store profiles in mapping(address => UserProfile) for constant lookups.
3. Single assignment
Assign the complete packed struct in one write to reduce SSTOREs.
4. Use calldata
Pass complex external inputs as calldata when they are read-only.
Try this
Measure gas before and after packing and identify which change reduced SSTORE count the most.
