Module 4 › Chapter 3.5 › Storage vs Memory vs Calldata
Storage

Persistent & expensive

State variables live here; SSTORE is costly. Minimize writes and group them.

Memory

Temporary & cheaper

Use for local modifications and to cache reads to reduce repeated storage access.

Calldata

Read-only & cheapest

Pass external arrays or structs as calldata when you don't need to modify them.

Example pattern
Cache reads
Load state into a local memory variable and reuse it to avoid multiple SLOADs.
Use calldata
External view functions that accept arrays should use calldata to lower gas for callers.
