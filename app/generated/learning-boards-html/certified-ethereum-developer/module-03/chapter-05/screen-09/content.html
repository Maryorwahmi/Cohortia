Gas-expensive operations

Recognize and minimize these to keep transaction costs reasonable.

SSTORE (writing storage)
Most expensive. Minimize writes; prefer single assignments for packed structs.
External calls
Unpredictable gas and reentrancy risks. Avoid inside loops.
Unbounded loops
Can hit gas limits. Use pagination or off-chain processing.
String and dynamic data ops
Dynamic memory and copying are costly; avoid heavy string manipulation on-chain.
Mitigation
Cache reads, write once, and emit events instead of storing large histories.
Pattern
Order require checks cheaply to fail fast and save gas on bad calls.
Check
Avoid external calls in loops; isolate or move them off the critical path.
