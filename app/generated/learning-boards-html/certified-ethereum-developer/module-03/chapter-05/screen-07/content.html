Fixed-size arrays

Use uint256[5] style arrays for small, predictable collections — predictable storage layout and often cheaper operations.

When to use
Small sets of values known at design time.
Warning
Not flexible for growth; changing size requires migration or redeploy.
Dynamic arrays

Flexible size, but push, pop, and iteration can allocate or traverse many storage slots, raising gas costs.

Common pitfall
Unbounded loops over dynamic arrays can exceed block gas limits and fail transactions.
Alternatives
Use pagination, per-index getters, or events + off-chain indexing for large or growing datasets.
Example scenario

If you need to keep every historical transfer for queries, prefer emitting events and using off-chain tools rather than storing all transfers in a dynamic array on-chain.
