Definition

Storage packing explained

Solidity packs smaller fields into a 32-byte slot when possible. Order fields to maximize packing and reduce the number of storage slots.

Packing example
uint8 a; uint8 b; uint256 c; packs a and b together and stores c separately.
Misconception
Smaller types alone don't save gas unless they are arranged to share storage slots.
Key Takeaway

Optimizing struct member order is a simple, repeatable change that reduces storage slots and SSTORE cost across all writes.

Concrete comparison
Inefficient
struct MyData {
  uint256 largeNum;
  bool flag;
  uint8 smallNum;
}
// Uses 3 slots
Efficient
struct MyData {
  bool flag;
  uint8 smallNum;
  uint256 largeNum;
}
// Packs flag+smallNum into one slot; largeNum in another
