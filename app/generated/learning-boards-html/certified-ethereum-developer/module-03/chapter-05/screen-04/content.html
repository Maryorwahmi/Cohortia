Module 4 › Chapter 3.5 › Mappings
Core Concept

Mappings for key-value access

Mappings provide constant-time access by key and avoid iteration, saving gas when enumeration isn't required.

Guide
Access cost is independent of size; no length or iteration.
Misconception
Using an array for iteration adds storage writes and can be far more expensive than alternatives like events or off-chain indexing.
Key Takeaway

Prefer mappings when you need fast lookup and don’t require on-chain enumeration; index only when necessary.

Example
// mapping for balances
mapping(address => uint256) public balances;

function setBalance(address user, uint256 amount) public {
  balances[user] = amount; // single storage write for that key
}

function getBalance(address user) public view returns (uint256) {
  return balances[user]; // constant-time read
}
When to use
User balances, permissions, and any keyed storage where you don't need to iterate all keys.
When to avoid
When you must enumerate all entries on-chain frequently; consider events or off-chain indexing instead.
