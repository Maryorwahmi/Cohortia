Module 3 › Chapter 3.4 › onlyOwner vs Role-Based Access Control
onlyOwner
  • Single owner address controls sensitive functions.
  • Easy to implement and audit.
  • Risk: single point of compromise.
RBAC
  • Named roles for fine-grained permissions.
  • Supports delegation without sharing keys.
  • Requires secure role management and tests for role changes.
Use RBAC when roles map to different services or teams.
Use onlyOwner for small single-admin deployments with clear recovery plans.
Always test revoked role scenarios and the role-granting pathways.
