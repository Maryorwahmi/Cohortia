Module 3 › Chapter 3.4 › Integer overflow and underflow
What happens
Overflow: value exceeds type max and wraps; underflow: goes below zero and wraps. Attacks previously used wrapping to manipulate balances.
Mitigation: Solidity 0.8+ reverts on overflow/underflow by default. For legacy code, use SafeMath.
Key Takeaway

Prefer modern compilers and add focused boundary tests. When interacting with old contracts, inspect arithmetic carefully.

Testing & examples
Add unit tests that send maximum values and near-zero values into functions that perform arithmetic. Use fuzzing to discover unexpected inputs. If your code uses assembly, add extra scrutiny because compiler protections may not apply.
Example test: deposit a near-max uint256 and attempt to add an amount that would overflow — expect a revert under Solidity 0.8+.
Common mistake: Assuming external library calls always return checked values; always validate results you depend on.
