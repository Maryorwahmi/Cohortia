Module 3 › Chapter 3.4 › Security-first mindset: testing, audits, and bounties
Repeatable pipeline
1. Unit tests including edge cases and exploit reproduction tests.
2. Integration tests and fuzzing to explore unexpected inputs.
3. External audits and formal verification where appropriate.
4. Bug bounty programs to catch issues in production scenarios.
When an audit finds an issue, add a test that reproduces the exploit and include it in CI so fixes remain validated. Track compiler and dependency updates as part of maintenance to inherit security improvements.
Concrete activity
As a hands-on task, refactor a vulnerable withdraw to secure form, write an exploit test that fails on the vulnerable code, then show the test passes after the fix. This confirms both the vulnerability and the remediation.
Key Takeaway

Security is a continuous process: tests, audits, and bounties keep contracts safer over time. Make exploit tests part of your codebase.
