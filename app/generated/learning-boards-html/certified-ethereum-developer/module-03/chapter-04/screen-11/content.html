Module 3 › Chapter 3.4 › Front-running
How it works
An attacker watches the mempool and races to submit a transaction with higher gas to get executed earlier, profiting from ordering advantages.
Mitigations: commit-reveal, batching, economic disincentives, and minimizing high-value single transactions.
Testing and example
Simulate an attacker by re-submitting a transaction with higher gas price in a test environment. Verify the commit-reveal flow prevents the attacker from learning the revealed value before commit finalization.
Analogy: sealed-bid auction prevents bidders from reacting to visible bids; commit-reveal is the sealed bid equivalent on-chain.
Common misassumption: Private mempools replace protocol-level mitigations; they reduce exposure but are not a full solution.
