onlyOwner pattern
contract AdminControlled {
  address public owner;
  constructor() { owner = msg.sender; }
  modifier onlyOwner() {
    require(msg.sender == owner, "Not authorized");
    _;
  }
  function sensitiveFunction() public onlyOwner { /* ... */ }
}
Use onlyOwner for small teams but plan for recovery and ownership transfer controls.
Role-Based Access Control (RBAC)
RBAC defines named roles like MINTER_ROLE and PAUSER_ROLE and assigns them to addresses. Functions check whether the caller has the required role. This allows granular delegation without exposing full owner privileges. Prefer audited libraries and test role grants and revocations.
Pro-tip: Protect role-granting functions with multisig or timelock for high value systems.
Common mistake: Over-granting roles or leaving a role open to any caller; always require authorization for role changes.
