Module 3 › Chapter 3.4 › Key Concepts — Part 1
Reentrancy
External calls can re-enter the contract and exploit unchanged state.
Checks-Effects-Interactions
Perform validations, update state, then make external interactions.
Reentrancy Guard
A mutex-like modifier that prevents nested calls into a protected function.
Summary: Use CEI and guards together, test exploit scenarios, and keep compiler and library versions current to reduce risk.
