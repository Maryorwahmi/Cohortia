Code Walkthrough

StringUtils + using for

Library
library StringUtils {
  function isEmpty(string memory s) internal pure returns (bool) {
    return bytes(s).length == 0;
  }
  function concatenate(string memory a, string memory b) internal pure returns (string memory) {
    return string(abi.encodePacked(a, b));
  }
}
Contract using it
contract MyTextProcessor {
  using StringUtils for string;
  string public greeting = "Hello";
  function processAndDisplay(string memory inp) public view returns (string memory) {
    if (inp.isEmpty()) {
      return greeting.concatenate(" World!");
    } else {
      return greeting.concatenate(" ").concatenate(inp);
    }
  }
}
Example result

Calling processAndDisplay with an empty input returns "Hello World!" since isEmpty triggers the concatenate fallback.

Watch out

Avoid attaching libraries that implicitly assume a particular storage layout.
