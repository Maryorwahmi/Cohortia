Libraries and Upgradable Contracts

In this lesson you'll learn how to attach reusable library functions to types, why delegate semantics matter, and how proxy patterns let you update logic without losing state.

Reusable Code
Concept Map
Libraries
Stateless reusable code deployed once; functions can execute in caller context when delegated.
Using For
Attach functions to types for method-like syntax and clearer code.
Proxy Pattern
Holds state in an immutable proxy and forwards calls to replaceable logic contracts using delegatecall.
Quick Note

Upgradability provides flexibility but increases attack surface: storage layout and upgrade controls are critical decisions.
