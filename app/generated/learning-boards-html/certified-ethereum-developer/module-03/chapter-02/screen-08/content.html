Definition

Upgradable Contracts explained

Upgradability separates state and logic so you can replace the code that implements behavior while preserving stored data.

Typical flow
Deploy proxy with state, deploy implementation with logic, point proxy to implementation, update pointer to upgrade.
Why use it
Fix bugs, add features, or change behavior without moving user data off-chain or requiring complex migrations.
Trade-off
Upgradable design increases complexity and introduces risks that must be mitigated through governance and testing.
Scenario
Fixing a bug without migration

If a deployed token reveals a rounding bug, an upgrade can fix transfer logic while leaving user balances intact in the proxy's storage.

Key takeaway

Upgradability is a pragmatic tool for long-lived systems, but adopt it only with strong governance and audited libraries.
