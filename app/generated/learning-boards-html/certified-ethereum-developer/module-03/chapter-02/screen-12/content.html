Security focus

Storage collisions and mitigation

A storage collision happens when storage slots assumed by the implementation do not match the proxy's actual layout. Because delegatecall uses proxy storage, mismatches corrupt state.

Reserve dedicated slots in the proxy for admin data and document them.
Keep variable ordering stable or use explicit slot storage helpers to avoid implicit reordering problems.
Use audited upgrade plugins and limit upgrade authority to a secure governance process.
Example pitfall
Adding a new variable earlier

If an implementation adds a new state variable at the top of its contract, subsequent variables shift slots and can map to proxy state meant for different data.

Warning

Never change storage layout lightly; treat storage compatibility as a top-level design requirement.
