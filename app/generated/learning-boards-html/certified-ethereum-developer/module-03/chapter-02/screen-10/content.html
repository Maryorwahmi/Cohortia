Module 3 › Chapter 3.2 › Transparent vs UUPS
Transparent Proxy

Proxy-level admin

Admin functions live at the proxy. Calls from the admin are handled differently than user calls, preventing conflicts with implementation functions.

Good for well-defined admin separation and simple upgrade governance.
Requires the proxy to implement admin controls and careful access checks.
UUPS

Implementation-level upgrade logic

The implementation holds the upgrade function, while the proxy remains a thin forwarder. Upgrades are invoked through the implementation's logic and then update the proxy's pointer.

Leads to smaller proxies and flexible deployment but requires secure implementation code for upgrade paths.
A buggy implementation could compromise upgrade mechanisms, so auditing is essential.
Decision guide

Choose Transparent when you want admin separation at the proxy. Choose UUPS for a minimal proxy and when you accept upgrade logic living in implementation code with rigorous testing.
