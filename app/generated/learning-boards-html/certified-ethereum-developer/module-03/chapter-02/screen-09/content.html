Architecture

Proxy ← delegatecall ← Implementation

The proxy holds the state and forwards calls to an implementation that contains the logic. Using delegatecall allows the implementation's code to operate on proxy storage.

Proxy
Holds state and the pointer to the implementation address.
Implementation
Contains functions like transfer and mint; replaceable for upgrades.
Delegatecall
Executes implementation code in proxy's context so storage and msg.sender are preserved.
Checklist
  • Design storage layout and reserve slots for proxy-specific variables.
  • Minimize proxy complexity; prefer audited upgrade helpers.
  • Restrict who can perform upgrades with strong access control.
Misconception

The proxy is not a full duplication of logic — it intentionally delegates to keep the forwarding layer small and stateful.
