Module 3 › Chapter 3.2 › Key Concepts
Library
Reusable, single-deployed code; can execute in caller context when delegated.
using for
Attaches library functions to a type so calls look like methods on variables.
Upgradable Contracts
Separate state and logic so behavior can be updated without losing stored data.
Summary takeaway

Libraries improve reuse and gas efficiency; proxies enable upgrades but require storage planning, governance, and audited tools to be safe.
