Best practices

Securing upgrade paths

Access control

Prefer multisig or governance contracts to single keys for performing upgrades; record who can upgrade and how.

Audited tooling

Rely on battle-tested upgrade plugins and audited libraries to manage pointers and migrations safely.

Storage planning

Reserve and document storage slots; ensure implementations use compatible layouts to avoid collisions.

Test upgrades

Simulate upgrades and rollback scenarios on testnets before production deployment.

Communicate policy

Publish upgrade governance and change logs so users understand when behavior may change.
