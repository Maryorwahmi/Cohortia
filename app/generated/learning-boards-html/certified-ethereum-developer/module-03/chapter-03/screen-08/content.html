Core Concept
Custom Errors
Define typed error types and revert with them to reduce revert data size and gas.
Declaration
error Unauthorized(address caller);
error InsufficientBalance(uint256 required, uint256 available);
Using a custom error
Revert with structured arguments that off-chain tools can decode from the transaction receipt.
Example
if (msg.sender != owner) {
  revert Unauthorized(msg.sender);
}
if (_amount > balance) {
  revert InsufficientBalance(_amount, balance);
}
Key Takeaway

Use custom errors to reduce gas and provide typed revert data for tooling; define them at contract scope.
