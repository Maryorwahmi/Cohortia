Learning Objectives
Learn, understand, apply, and master the chapter outcomes.
01
Use require, revert, assert
You will recognize when to use each primitive: require and revert for expected input failures that refund gas, and assert for invariants that signal bugs.
VERIFIED COMPETENCY MILESTONE
02
Understand gas implications
You will explain why require and revert refund remaining gas while assert consumes all remaining gas, and what that means for user cost.
VERIFIED COMPETENCY MILESTONE
03
Implement custom errors
You will declare custom error types and revert with them to reduce gas and provide structured error data for off-chain parsing.
VERIFIED COMPETENCY MILESTONE
04
Emit and index events
You will design events with appropriate indexed parameters so front-ends and analytics tools can efficiently filter logs.
VERIFIED COMPETENCY MILESTONE
