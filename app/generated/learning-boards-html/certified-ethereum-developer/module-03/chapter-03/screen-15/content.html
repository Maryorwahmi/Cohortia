Module 3 › Chapter 3.3 › What to Remember
01 — Validate with require
Use require for expected input and permission checks so callers are refunded unused gas.
02 — Use assert sparingly
Only check invariants with assert; failures indicate bugs and consume remaining gas.
03 — Emit and index events
Emit concise events and index the fields UIs will filter by to make logs queryable.
Summary Takeaway

Choosing the correct error primitive and designing events carefully improves security, reduces gas costs for users, and makes your contract easier to monitor and maintain.
