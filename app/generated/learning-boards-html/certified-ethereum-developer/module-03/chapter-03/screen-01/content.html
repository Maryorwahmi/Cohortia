Error Handling and Events

Understand Solidity failure primitives, learn gas effects and best practices, and use events with indexed parameters to communicate with off-chain tools.

Concept Map
Require
Input & permission checks — refunds remaining gas on failure.
Custom Errors
Gas-efficient structured error data for programmatic handling.
Assert
Invariant checks — indicates bug, consumes remaining gas.
Events
Emit logs for off-chain UIs; index up to three fields for fast queries.
