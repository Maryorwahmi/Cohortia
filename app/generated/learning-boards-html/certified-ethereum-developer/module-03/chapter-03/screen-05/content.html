Core Concept
revert()
Explicitly revert with flexible logic and conditional checks. Refunds remaining gas like require.
Example
function withdraw(uint256 _amount) public {
  if (_amount == 0) {
    revert("Withdrawal amount cannot be zero.");
  }
  if (_amount > value) {
    revert("Insufficient contract balance.");
  }
  value -= _amount;
}
When to prefer revert
  • Multiple conditional branches where each branch returns a different reason.
  • When centralizing validation into helper functions that call revert on failure.
  • When you need a targeted rollback deeper inside function logic rather than at entrance.
Misconception
revert is not inherently costlier than require; use the one that makes code clearer while still refunding unused gas on failure.
Key Takeaway

Use revert when branching or centralized rollback increases clarity; it refunds gas like require.
