Indexed vs Non-indexed
Indexed parameters appear in topics and are searchable without inspecting the log data. Non-indexed parameters sit in the data blob and require decoding every log to locate values.
Example Event
event VoteCast(address indexed voter, uint256 candidateId); — here voter is indexed so front-ends can quickly find votes by address.
Design checklist
  • Which fields will UIs filter by? Index those first.
  • Keep event payloads small; don't store large strings in logs.
  • Remember the three-index limit and plan events accordingly.
Key Takeaway

Index the most commonly queried fields to make log queries fast and cost-effective for clients.
