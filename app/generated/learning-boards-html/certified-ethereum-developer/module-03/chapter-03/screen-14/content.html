Module 3 › Chapter 3.3 › Key Concepts
require()
Use for input and permission checks; refunds remaining gas on failure.
assert()
Use for invariants only; failure consumes remaining gas and signals bugs.
Custom Errors
Declare structured errors and revert with them to save gas and carry typed data.
Events & indexed
Emit logs for off-chain systems. Index up to three fields that clients will filter by to improve query performance.
