Core Concept
assert()
Verify invariants and internal consistency. On failure, all remaining gas is consumed.
Example
// After transfers, total supply should equal sum of balances
assert(balanceOf[address(this)] == totalSupply);
Why assert is special
  • Signals a developer-level bug rather than a user mistake.
  • Consumes remaining gas on failure to make issues visible and expensive.
  • Useful in post-state checks after complex updates to detect corruption.
Common Mistake
Using assert for input validation or expected user failures. That wastes gas and miscommunicates intent.
Key Takeaway

Reserve assert for impossible internal invariants; use require or revert for user-caused checks.
