Core Concept
Events & emit
Emit logs to make contract activity discoverable to off-chain systems without using storage.
Example
event Transfer(address indexed from, address indexed to, uint256 value);

function transfer(address _to, uint256 _amount) public returns (bool) {
  // transfer logic
  emit Transfer(msg.sender, _to, _amount);
  return true;
}
Design considerations
  • Events are cheap for off-chain observers but not reliable for on-chain decisions.
  • Include the minimal data needed; avoid writing large blobs to logs.
  • Decide which fields will be filtered in UIs and mark them indexed (up to three).
Key Takeaway

Emit concise events and index likely query fields so UIs can efficiently find relevant logs.
