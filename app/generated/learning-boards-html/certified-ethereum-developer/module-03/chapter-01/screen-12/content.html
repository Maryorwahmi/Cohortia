Architecture
Inherit when you need shared state
Abstract contracts provide shared helpers and storage. Use them when derived contracts should share an internal representation or logic.
Example
Ownable defines owner state and onlyOwner modifier used by many derived contracts.
Compose when you need replaceability
Interfaces and composition let you swap implementations without deep inheritance changes, ideal for external integrations and upgradeable components.
Example
Store a processor address conforming to a payment interface so you can replace processors without changing the consumer contract.
Practice prompt
For a feature that may change often, prefer composition + interface. For shared state and invariants, prefer inheritance.
