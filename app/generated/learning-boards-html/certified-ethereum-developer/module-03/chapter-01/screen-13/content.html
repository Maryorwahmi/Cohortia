Security
Test base and derived contracts thoroughly
Write unit tests for default base behavior, derived overrides, and modifier interactions. Confirm that events and state changes occur in the expected order when super is called.
Deployment check
Ensure base constructors initialize state correctly and ownership is assigned to the intended account.
Audit tip
Limit virtual functions and document intended overrides to aid auditors in tracing behavior.
Quick testing prompts
  • Call overridden functions and assert the expected implementation executed.
  • Test modifier stacks, e.g., onlyOwner + whenNotPaused combinations.
  • Simulate upgrade or replacement scenarios if using composition and interfaces.
Key Takeaway

Testing and explicitness mitigate the main risks introduced by inheritance choices in Solidity.
