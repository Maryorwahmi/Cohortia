Module 3 › Chapter 3.1 › What to Remember
Explicit extensions
Mark virtual only for intended hooks and declare override in derived implementations to show intent.
Right abstraction
Use abstract contracts for shared state and interfaces for signature-only external APIs.
Keep it simple
Favor shallow hierarchies and composition where replaceability and explicit behavior matter.
Final prompt

Try compiling examples with and without virtual/override to see compiler checks in action, and add unit tests that confirm which implementation runs when bases collide.
