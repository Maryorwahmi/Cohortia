Definition
virtual & override

virtual marks base functions as customizable; override marks derived implementations and must list base contracts when multiple parents define the same function.

Step 1: Decide which base functions are hooks and mark them virtual.
Step 2: In derived contracts, use override to modify implementations.
Step 3: When combining multiple bases, list them inside override(...).
Misconception
You can safely override any function without compiler help. Solidity requires explicit virtual and override to prevent that problem.
Code walkthrough
// Base contract
function processPayment(address recipient, uint256 amount) public virtual returns (bool) {
  emit PaymentProcessed(recipient, amount, "Standard Payment");
  return true;
}

// Derived contract overrides
function processPayment(address recipient, uint256 amount) public override returns (bool) {
  require(amount >= subscriptionFee, "Amount too low for subscription");
  emit PaymentProcessed(recipient, amount, "Subscription Payment");
  return super.processPayment(recipient, amount);
}
Pro tip
Mark only those base functions you expect to vary; avoid making everything virtual by default.
Check
If the compiler errors about missing override, confirm the derived function lists all base names that declare the same signature.
