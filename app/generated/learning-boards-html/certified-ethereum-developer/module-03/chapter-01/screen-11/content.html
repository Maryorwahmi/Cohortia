Core Concept
Pitfalls & Best Practices
  • Missing virtual prevents overrides; missing override causes compile errors.
  • When overriding functions from multiple bases, list all parent names in override(...).
  • Prefer shallow hierarchies and composition to avoid audit complexity.
  • Document intended extension points and side effects when calling super.
Warning
Complex inheritance increases risk. Each additional base adds to reasoning cost when auditing behavior.
Practical checklist
Testing
Write unit tests that confirm which implementation runs for functions defined in multiple bases and test modifier interactions thoroughly.
Documentation
Document why functions are virtual and where override is expected so future maintainers understand extension points.
