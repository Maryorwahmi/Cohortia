Module 3 › Chapter 3.1 › Key Concepts
Inheritance
Derived contracts reuse public and internal members from base contracts to centralize logic.
virtual / override
virtual allows change; override shows explicit modification and can list multiple parents.
Abstract vs Interface
Abstract contracts can have state and helpers; interfaces are signature-only for external APIs.
C3 Linearization
Solidity resolves multiple inheritance using a linearized order; check is ordering and explicit overrides.
Pitfalls
Missing virtual/override and deep hierarchies increase compilation errors and audit complexity.
Best practices
Keep hierarchies shallow, mark only intended virtuals, test override chains, and document linearization choices.
Summary

Use inheritance deliberately: centralize shared logic in bases, declare explicit extension points, and prefer interfaces or composition when you need replaceability.
