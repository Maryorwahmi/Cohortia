Structure
Contract anatomy
Pragma → Imports → contract Name → state variables → constructor → functions
State variables
Persisted values stored in contract storage and visible on-chain depending on visibility.
Functions
Methods to read or modify state. Visibility and mutability determine how they execute and whether they cost gas.
Constructor
Runs once on deployment to set initial state, such as an owner or initial message.
Example contract outline
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Example {
  string public message; // state

  constructor(string memory initial) {
    message = initial; // initialized on deploy
  }

  function setMessage(string memory newMessage) public {
    message = newMessage; // modifies state
  }

  function getMessage() public view returns (string memory) {
    return message; // reads state without gas when called locally
  }
}
Key Takeaway

Contracts organize on-chain state and behavior. Keep responsibilities clear and set explicit visibility to match intended access.
