Comparison
uint / uint256
Unsigned integer for counts and balances. Default size aligns with the EVM word size.
Use for: counters, token balances, timestamps
address
A 20-byte value representing an Ethereum account or contract. Used for transfers and ownership checks.
Use for: owners, recipients, contract references
bool
Simple true/false flag. Useful for pause switches and binary checks.
Use for: isActive, isPaused, hasAccess
Practical considerations
  • Prefer uint256 by default due to EVM alignment unless packing is needed.
  • Do not treat address as a string; use address-specific operations.
  • Booleans can be packed but may complicate struct layout; think about gas when storing many small values.
