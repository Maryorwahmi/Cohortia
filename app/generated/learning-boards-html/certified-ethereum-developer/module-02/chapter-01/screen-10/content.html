Functions & Gas
View vs State-changing
'view' functions do not modify storage and can be called without transactions; state-changing functions require transactions and gas.
function getMessage() public view returns (string memory) {
  return message;
}

function setMessage(string memory newMessage) public {
  message = newMessage;
}
Visibility considerations
  • Public: callable internally and externally; auto-generates getters for state variables.
  • External: better for external calls, slightly cheaper when called externally.
  • Internal/private: restrict access to within the contract or inheritance chain.
Common mistake

Failing to mark a read-only function as 'view' or leaving visibility implicit can lead to unnecessary gas costs and unintended access.
