Core Concept › Value vs Reference

Definition

Value types hold data directly and copy on assignment. Reference types hold a pointer to data, so assignments copy the reference, not the data.

Value Type Example
uint a = 5; uint b = a; // b is an independent copy
Reference Type Example
uint[] storage arrRef = myArray; // changes through arrRef affect myArray
Common Mistake
Assuming reference assignments create copies and then expecting mutations to be isolated.
Key Takeaway

Pick value types when you need independent data; use reference types when you need shared, mutable state.

Illustrative Scenario
Scenario: Balance Copy
uint a = 100;
uint b = a;
a = 0; // b still 100
Here balance values copy so b remains unchanged after a changes.
Scenario: Array Reference
uint[] storage refArr = products;
refArr.push(5); // products updated
Pushing through the reference mutates the original storage array.
