Value Types
Unsigned and signed integers, booleans, addresses and fixed-size bytes. They copy on assignment; this affects safety and gas.
Reference Types
Arrays, structs, mappings: these hold pointers. Mutating a referenced value updates the underlying storage.
Operators
Arithmetic, comparison, logical, and bitwise operators let you compute and reason about values in contracts.
