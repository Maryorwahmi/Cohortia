Hands-on Activity › Product Catalog Steps
Step 1: Define types
Create Product struct, products mapping, and nextProductId state variable initialized to 1.
Step 2: addProduct
Accept string memory and uint, construct Product in memory, store in mapping, increment nextProductId.
Step 3: getProduct & toggle
Implement a public view getProduct and a toggleAvailability that flips the in-storage boolean.
Test Checklist
  • Deploy and call addProduct multiple times; verify ids increment.
  • Call getProduct and verify fields match inputs.
  • Call toggleAvailability and verify the stored available flag flips.
Common mistakes
Not specifying memory/calldata for reference parameters, attempting to iterate mappings, or forgetting to increment nextProductId.
