Process Flow › storage / memory / calldata
Storage
Persistent state variables live here and remain on-chain between transactions. Writing to storage is expensive.
Example
uint[] public numbers; // stored on-chain
Mistake to avoid
Overwriting large storage structures in a single transaction without considering gas limits.
Memory and Calldata
Memory exists only during calls and is cheaper than storage. Calldata is read-only and cheapest for external inputs because it avoids copies.
Calldata Example
function submit(string calldata s) external { /* read s without copying */ }
Memory Example
function copy(string memory s) internal { /* temporary copy for manipulation */ }
Key Takeaway

Prefer calldata for external read-only inputs, memory for temporary in-call data, storage for persistent state.
