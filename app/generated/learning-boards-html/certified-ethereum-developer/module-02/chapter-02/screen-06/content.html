Arrays

Fixed-size arrays reserve slots; dynamic arrays can grow but may be expensive to resize or iterate.

Code
uint[5] fixedArr;
uint[] public dynamicArr;

Structs & Mappings

Structs group fields; mappings provide efficient key-based access but cannot be iterated when stored on-chain.

Code
struct Person { string name; uint age; address wallet; }
mapping(address => uint) public balances;
Example: Push struct to storage array
Product memory newProduct = Product({
  id: _id,
  name: _name,
  price: _price,
  inStock: true
});
products.push(newProduct);
Create the product in memory to avoid accidental storage mutations, then push to the storage array to persist it.
