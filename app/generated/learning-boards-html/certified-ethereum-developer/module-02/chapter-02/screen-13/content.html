Comparison › Pitfalls vs Practices
Pitfalls
  • Assuming reference assignments create copies.
  • Attempting to modify calldata directly.
  • Iterating unbounded arrays on-chain.
Best Practices
  • Be explicit: storage, memory, calldata for reference types.
  • Keep loops bounded or run them off-chain.
  • Separate pure calculations from state writes.
Key Takeaway

Treat data locations and type semantics as first-class design decisions; they control correctness and cost.
