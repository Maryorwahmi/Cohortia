Process Flow › Array Patterns
Fixed-size Array
uint[5] fixedArr; // reserved slots and predictable gas for indexed access.
Dynamic Array
uint[] public dynamicArr; // flexible, but resizing and iterating can be costly.
Avoid unbounded loops
Do not process every element of a large dynamic array on-chain. Prefer mappings for lookups, pagination, or off-chain aggregation of events.
Pattern: Index + Mapping
Use an array to preserve order and a mapping for fast existence checks by key.
Tip
If you must iterate, limit batch sizes and allow multiple transactions to continue processing.
