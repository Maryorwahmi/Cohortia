Distinguish value vs reference

03
Apply reference types safely
Declare and update arrays, structs, and mappings while understanding mutation semantics and iteration costs.
Mnemonic: stacked cards for array, struct, mapping

04
Choose data locations
Decide between storage, memory, and calldata for function parameters and local variables to manage gas and safety.
