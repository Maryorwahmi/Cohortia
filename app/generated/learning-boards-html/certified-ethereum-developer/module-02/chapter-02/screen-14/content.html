What to Remember
Value vs Reference
Value types copy; reference types share pointers and can mutate shared storage.
storage/memory/calldata
Storage persists on-chain; memory is temporary; calldata is cheapest read-only input for external calls.
Operators & Integer Math
Arithmetic, comparison, logical and bitwise operators are available; watch integer division and division by zero.
Final Takeaway
Making explicit choices about types and data locations keeps contracts correct, auditable, and more gas-efficient.
