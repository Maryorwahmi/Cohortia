// Arithmetic
+  -  *  /  %  **

// Comparison
==  !=  <  <=  >  >=
Remember integer division truncates; plan expressions to minimize precision loss.
Logical & Bitwise
// Logical
&&  ||  !

// Bitwise
&  |  ^  ~  <<  >>
Use bitwise ops when you need compact flags or shifts. Keep code readable and documented.
Concrete Example: calculateDiscount
function calculateDiscount(uint _price, uint _discountPercent) public pure returns (uint) {
  return _price - (_price * _discountPercent / 100);
}
This uses integer math to compute a percentage; ensure the order of operations avoids unintended truncation.
