Definition › Value Types
Integers
uint (unsigned) and int (signed). Defaults are uint256 and int256. Use uint for balances and counters; only use int if negative values are required.
Example: uint256 public balance = 100 ether;
Bool & Address
bool stores true/false flags. address stores 20-byte addresses; address payable can receive Ether and requires explicit payable conversion.
Example: address public ownerAddress; address payable recipient = payable(ownerAddress);
BytesN & Enums
Fixed-size bytes are bytes1..bytes32 for compact binary data. Enums define named constant sets and improve readability and safety.
Example: enum OrderStatus { Pending, Shipped, Delivered, Cancelled }
Practical tip
  • Prefer uint for balances; avoid signed integers unless needed.
  • Use address payable only when sending Ether; cast explicitly.
  • Use bytesN for fixed binary values like hashes to reduce gas.
