Module 3 › Chapter 2.5 › Key Concepts
Event
A log for off‑chain listeners to observe contract activity.
Indexed
Up to three fields that tools can filter on efficiently.
Custom Error
Typed error signatures used with revert for clear, gas‑efficient failures.
Takeaway: Design for observability and predictable error semantics—emit meaningful events, index what you will query, and prefer custom errors for structured, gas‑friendly diagnostics.
