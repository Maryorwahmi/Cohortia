Learning Objectives

Learn → Understand → Apply → Master

Bloom: Learn · Understand · Apply · Master
01
Use events for off‑chain communication

Declare and emit events to log meaningful actions that UIs and backends can listen to rather than polling state.

VERIFIED COMPETENCY MILESTONE
02
Design indexed parameters

Choose up to three indexed fields to enable efficient filtering by address, id, or other keys.

VERIFIED COMPETENCY MILESTONE
03
Apply custom errors

Declare error types and revert with them to return structured data and reduce gas costs compared to long strings.

VERIFIED COMPETENCY MILESTONE
04
Follow error handling best practices

Use require for inputs, revert with custom errors for complex checks, and assert only for invariants to make behavior predictable.
