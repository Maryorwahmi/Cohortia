Module 3 › Chapter 2.5 › Off‑Chain Listeners
Process Flow

From emit to UI

A clear sequence connects on‑chain emits to off‑chain updates.

1. Transaction
Function runs and emits events when state changes succeed.
2. Logs stored
Event data is written to transaction logs in the receipt.
3. Indexing
Nodes or indexers expose APIs to query logs by indexed fields.
4. Listener
A UI or backend subscribes to filters and processes the returned log payloads.
Indexing tip: index the fields you will filter by, such as addresses or identifiers.
Recovery tip: store authoritative state on‑chain; use logs to reconstruct views, not to enforce contract logic.
Example scenario

A DApp subscribes to Transfer events indexed by recipient address to show incoming transactions instantly without polling every account balance.
