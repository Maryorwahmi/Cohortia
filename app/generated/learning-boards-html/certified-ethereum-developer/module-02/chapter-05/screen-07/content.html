Module 3 › Chapter 2.5 › Indexed vs Non‑Indexed
Indexed

Searchable topics

Indexed parameters appear in topics and support efficient filtering by tools and explorers.

  • Up to three indexed parameters.
  • Ideal for addresses and IDs you will query often.
  • Used by wallets and backends to fetch relevant logs quickly.
Non‑Indexed

Payload data

Non‑indexed parameters live in the log data. They are retrievable after a filter identifies matching logs but cannot be used as filter criteria.

  • Good for amounts, balances, or metadata not used in queries.
  • Less flexible for listener filtering, but preserves topic slots.
Example: index from and to in Transfer to find transfers involving an address.
Caution: do not expect contracts to read logs; logs are for off‑chain only.
Design tip: prefer a small, stable event schema so DApps can depend on consistent topics.
