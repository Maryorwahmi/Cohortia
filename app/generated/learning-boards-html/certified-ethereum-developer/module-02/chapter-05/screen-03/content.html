Practical Objectives

Live coding tasks and verification steps.

Live coding: Remix & transaction logs
Declare & emit events

Implement Deposit, Withdrawal, Transfer, Mint events and emit them for state changes so UIs can subscribe to updates.

VERIFIED COMPETENCY MILESTONE
Inspect logs in Remix or explorer

Use transaction receipts to verify indexed filters and non‑indexed payloads were recorded correctly.

VERIFIED COMPETENCY MILESTONE
Declare custom errors

Use structured error types like InsufficientBalance and NotOwner and revert with them for clear diagnostics.

VERIFIED COMPETENCY MILESTONE
Refactor checks and fail early

Move validation to function start to save gas and ensure predictable reverts; use assert only for invariants.
