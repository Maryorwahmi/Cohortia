Module 3 › Chapter 2.5 › Best Practices
Checklist
Fail early with require or revert to save gas.
Use custom errors for structured data and lower gas than long strings.
Emit events for all meaningful state changes for observability.
Index only fields you will filter by; remember the three index limit.
Do not rely on logs for on‑chain decisions; logs are off‑chain signals.
Reserve assert for invariants, not user input checks.
Reflection

Which events will your DApp need to subscribe to, and what custom errors should be surfaced to users for better diagnostics?
