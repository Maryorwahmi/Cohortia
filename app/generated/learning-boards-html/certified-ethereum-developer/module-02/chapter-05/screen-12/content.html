Starter Code Guidance

Enhance the provided SimpleToken starter with events and custom errors as specified in the activity.

Events to add
  • Transfer(address indexed from, address indexed to, uint value)
  • Minted(address indexed to, uint amount)
  • Approval (optional for ERC‑20)
Custom errors to declare
  • InsufficientBalance(address sender, uint requestedAmount, uint currentBalance)
  • ZeroAmount()
  • NotOwner(address caller)
Owner controls: set owner in constructor and protect mint with NotOwner error.
Emit Transfer on successful transfer and Minted on mint so UIs reconstruct balances from events and state.
Try this

Refactor the starter code, deploy to Remix, call transfer and mint with valid and invalid inputs, and inspect emitted events and revert payloads in the transaction log.
