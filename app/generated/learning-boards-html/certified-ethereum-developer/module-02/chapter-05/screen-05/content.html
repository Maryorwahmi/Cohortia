Module 3 › Chapter 2.5 › Declare & Emit
Syntax

event & emit

Declare events at contract scope and emit them inside functions with the emit keyword.

// Event declaration
event Deposit(address indexed user, uint amount, uint newBalance);

function deposit() public payable {
  if (msg.value == 0) revert();
  balances[msg.sender] += msg.value;
  emit Deposit(msg.sender, msg.value, balances[msg.sender]);
}
Common mistake

Indexing all fields or relying on events for on‑chain decisions. Events are for off‑chain listeners and auditing; keep authoritative state in contract storage.

Practical Notes
Index up to three parameters for efficient queries. Use address fields as indexed when you expect listeners to filter by account.
Non‑indexed parameters are included in logs but must be retrieved after filtering by indexed fields.
Emit for transparency: deposits, withdrawals, ownership changes, mints, burns, and transfers.
