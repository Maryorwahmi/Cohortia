Module 3 › Chapter 2.5 › Require · Revert · Assert
Require
require(msg.sender == owner, "Only owner");

Good for simple, early input validation with an explanatory string during development or testing.

Revert with custom errors
if (balances[msg.sender] < amount) {
  revert InsufficientBalance(balances[msg.sender], amount);
}
Assert
// Use only for invariants
assert(totalSupply == sumOfBalances);

Assert signals a bug if it ever fails and will consume remaining gas; avoid for user input validation.

Practical rule

Fail early with require/revert to save gas. Reserve assert for internal consistency checks only.
