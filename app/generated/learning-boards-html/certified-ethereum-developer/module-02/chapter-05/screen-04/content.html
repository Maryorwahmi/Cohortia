Module 3 › Chapter 2.5 › What are Events?
Definition

Events are transaction logs

Events write structured data to transaction logs. Off‑chain systems read these logs to react to contract activity.

Why use events?
  • Gas‑cheaper than persistent storage.
  • Designed for off‑chain filtering and indexing.
  • Emit for all meaningful state transitions.
Concrete example

Emit Transfer(address indexed from, address indexed to, uint value) when tokens move. Wallets subscribe to that event to update UI quickly.

Key Takeaway

Use events to broadcast actions for off‑chain systems; don't rely on logs for contract state.

Analogy & Flow
Contract emits
Logs a structured message when a state change occurs.
Transaction logs
Stored in receipt and retrievable by tools.
Off‑chain listener
Filters by indexed fields and updates UI or backend processes.
