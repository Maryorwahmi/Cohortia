Module 2 › Chapter 2.3 › Visibility Specifiers
Quick reference
  • public: callable externally and internally; public variables get a getter.
  • external: callable only from outside; gas-efficient for calldata parameters.
  • internal: usable inside contract and by derived contracts.
  • private: only inside defining contract; not visible to children.
Callability matrix
External caller
public, external
Internal call
public, internal, private (private only in defining contract)
Gas note
External functions use calldata which avoids copying into memory for certain types and can be more gas-efficient for API endpoints intended only for external callers.
Example scenarios
  • A helper function used only inside the contract: make it private.
  • Logic that derived contracts must call: make it internal so children can access it.
  • External API intended only for users: make it external and optimized for calldata parameters.
Key takeaway
Pick the tightest visibility compatible with required interactions. This reduces accidental exposure and simplifies audits.
