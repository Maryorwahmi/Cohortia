Module 2 › Chapter 2.3 › Key Concepts
Function Signatures
Explicitly declare parameters, returns, visibility, mutability, and modifiers to communicate intent and enforce rules.
Visibility
Prefer the least permissive visibility that supports required calls: private, internal, public, external.
Mutability & Errors
Mark view/pure to optimize off-chain calls. Use require/revert for user checks and assert for invariants.
Takeaway
Write explicit function declarations, minimize exposure, and combine modifiers with clear error checks to build safe, maintainable contracts.
