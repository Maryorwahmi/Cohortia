Module 2 › Chapter 2.3 › Public vs External
Public
Callable internally and externally. Use when you need to invoke from inside the contract.
Use case: utility functions called both from APIs and internal logic.
External
Callable only from outside. Parameters arrive in calldata, avoiding copies to memory for certain types and saving gas.
Use case: API endpoints receiving large arrays or strings from external callers.
Practical advice
When optimizing for gas, prefer external for functions designed solely for external invocation. If internal calls are needed, use public. Always measure the actual gas impact in a profiler.
