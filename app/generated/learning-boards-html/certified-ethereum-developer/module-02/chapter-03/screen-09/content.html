Module 2 › Chapter 2.3 › Error Handling
require
For validating inputs and preconditions. Returns a message and refunds unused gas on failure.
Example: require(balances[msg.sender] >= amount, "Insufficient balance.");
revert
Explicitly revert with a message when deeper logic detection requires bailout.
Example: if (someComplexCheckFails) { revert("Complex failure"); }
assert
Use only for invariants that indicate a bug. assert consumes remaining gas on failure.
Example: assert(totalSupply == sumOfBalances);
Best practices
  • Check inputs early with require to avoid wasted work.
  • Use revert for clear bailout paths deep in logic.
  • Reserve assert for invariants and internal consistency.
Key Takeaway

Prefer require and revert for expected error conditions to refund gas and give clear messages; use assert only for invariants that indicate a serious bug.
