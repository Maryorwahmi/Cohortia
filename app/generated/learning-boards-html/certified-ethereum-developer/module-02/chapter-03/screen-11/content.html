Task checklist
  • Create onlyOwner modifier that reverts with a clear message.
  • Make deposit payable so anyone can send Ether to the contract.
  • Protect withdraw with onlyOwner and require checks for amount and balance.
  • Return contract balance with a public view getBalance function.
  • Test deposit from non-owner, withdraw from non-owner, withdraw > balance, and getBalance off-chain.
Pro tip
Use clear revert messages in require so tests and users can diagnose failures quickly.
