Module 2 › Chapter 2.3 › State Mutability
view
Reads state but does not modify it. Off-chain calls are gas-free. Be careful: internal use within a transaction still costs gas.
pure
Does not read or modify state. Ideal for deterministic calculations that depend only on inputs.
Examples
function getBalance() public view returns (uint currentBalance) {
  currentBalance = balance;
}

function calculateSum(uint a, uint b) public pure returns (uint) {
  return a + b;
}
Key takeaway
Label functions precisely: view for read-only access to storage, pure when no storage is involved. This helps users and optimizes gas for off-chain calls.
