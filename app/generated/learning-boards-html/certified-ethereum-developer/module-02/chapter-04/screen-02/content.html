01 — Implement conditionals
Write if / else if / else blocks to validate inputs and protect state. Eg. require age and license checks before allowing an action.
VERIFIED COMPETENCY MILESTONE
02 — Use loops safely
Apply for and while loops for bounded, predictable iterations, especially in memory or calldata arrays.
VERIFIED COMPETENCY MILESTONE
03 — Reason about gas
Estimate gas impact of loops and avoid functions that can exceed the block gas limit or be manipulated to DoS the contract.
VERIFIED COMPETENCY MILESTONE
04 — Design safe processing
Use pagination, pull patterns, or off-chain processing to handle large collections reliably and predictably.
VERIFIED COMPETENCY MILESTONE
