Core Concept
Conditional Statements in Solidity
if, else if, else — precise branching for safe state changes
Definition template
Definition & rules
  • If executes when its boolean condition is true.
  • Else if runs if the prior if was false and this condition is true.
  • Else runs when no prior condition matched.
  • Order matters: place specific checks before general ones because chains short-circuit.
Common misconception
Assuming two overlapping conditions will both run. They won’t; only the first true branch executes.
Example
// Example of conditional statements
function checkEligibility(uint age, bool hasLicense) public pure returns (string memory) {
    if (age >= 18 && hasLicense) {
        return "Eligible to drive.";
    } else if (age >= 18 && !hasLicense) {
        return "Eligible by age, but needs a license.";
    } else {
        return "Not eligible to drive.";
    }
}
Guided checklist
  1. Define clear boolean variables when expressions are complex.
  2. Order checks from most specific to most general.
  3. Include an else branch for unexpected inputs when appropriate.
  4. Use require for hard validation in public entry points.
Key Takeaway

Make branch logic explicit and auditable. Short-circuiting is intentional — place specific checks first to avoid logic errors.
