While loops and their risks
Dynamic-condition repetition — verify termination
Example: countdown
// Example of a while loop (use with care)
function countdown(uint start) public pure returns (uint) {
    uint current = start;
    while (current > 0) {
        // In a real contract, this would perform some action
        current--;
    }
    return current; // will be 0
}
This is safe because the loop body reduces current and termination is guaranteed by the input magnitude.
Safety checklist
  • Prove the loop condition becomes false in all cases.
  • Add an explicit iteration cap if the condition can depend on external input.
  • Avoid while loops in functions that process untrusted user data without bounds.
Common mistake

Assuming termination without proving it. An infinite while loop will exhaust gas and revert the transaction.
