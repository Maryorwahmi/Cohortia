Comparison
Storage vs Memory Iteration
Cost grows fast when loops read/write storage
Memory / Calldata loops
  • Caller supplies data; contract iterates a memory array.
  • Gas cost proportional to provided size; predictable if you limit input size.
  • Good for small aggregation tasks like summing a short array.
Storage loops
  • Iterating dynamic storage arrays reads expensive slots each iteration.
  • Risk: hit block gas limit and revert the transaction.
  • DoS risk: untrusted input can force long iterations.
Mitigation patterns
Pagination: split processing into pages
Pull pattern: users claim their share
Off-chain processing + proofs
