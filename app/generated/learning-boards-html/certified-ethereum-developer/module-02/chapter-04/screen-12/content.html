getFirstNWhitelisted pattern
// Return first _n addresses (bounded)
function getFirstNWhitelisted(uint _n) public view returns (address[] memory) {
    require(_n > 0, "_n must be positive");
    uint count = _n < whitelistedAddressesArray.length ? _n : whitelistedAddressesArray.length;
    address[] memory slice = new address[](count);
    for (uint i = 0; i < count; i++) {
        slice[i] = whitelistedAddressesArray[i];
    }
    return slice;
}
Ensure _n is bounded and document maximum gas cost for callers. This pattern intentionally limits iteration to a safe size.
