Common Pitfalls
Off-by-one, infinite loops, and unguarded iteration
Defensive checks prevent gas disasters
Off-by-one
Prefer i < length. Test loops with length 0, 1, and boundary values.
Infinite loop
Prove termination or add an iteration cap. Never accept unbounded user-controlled conditions.
Unguarded iteration
Avoid iterating large storage collections in one transaction. Use pagination, pull, or off-chain proofs.
Testing checklist
  1. Unit test loops for small and large inputs, including zero length.
  2. Simulate worst-case gas usage to detect reversion points.
  3. Check state consistency after removals and failed transactions.
