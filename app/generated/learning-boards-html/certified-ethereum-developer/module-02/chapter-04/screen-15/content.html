Key Concepts — Quick Reference
Fail early
Use require to validate entry conditions and make failures explicit.
Bound loops
Limit iterations or use memory/calldata loops to keep gas predictable.
Distribute cost
Use pull, pagination, or off-chain proofs to scale safely.
Final takeaway

Control flow must be correct and gas-aware. If a design allows untrusted input to force heavy on-chain work, change the design.
