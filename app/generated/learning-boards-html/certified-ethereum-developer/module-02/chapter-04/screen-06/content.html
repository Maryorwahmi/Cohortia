For loops and a safe memory example
Initialization; condition; increment — predictable when bounded
Structure
  1. Initialize a loop counter (e.g., uint i = 0).
  2. Provide a terminating condition (e.g., i < length).
  3. Increment or decrement the counter each iteration.
Common mistake
Using <= where < is required, causing out-of-bounds access or unexpected extra iteration.
Example: sumArray (memory)
// Example of a for loop (use with caution for dynamic arrays in storage)
function sumArray(uint[] memory _arr) public pure returns (uint total) {
    for (uint i = 0; i < _arr.length; i++) {
        total += _arr[i];
    }
    return total;
}
This function is safe for small memory arrays because the caller controls the array size and the loop is bounded.
Key Takeaway

Prefer bounded memory loops. Validate maximum sizes when loops depend on external input.
