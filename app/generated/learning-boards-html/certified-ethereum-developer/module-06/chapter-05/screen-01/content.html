Concept Map
Gas • Loops • External deps
Block Gas Limit
Caps work per block. If your operation needs more gas than the block allows, it cannot run.
Unbounded Loop
Iterating over an ever-growing list can make a function eventually impossible to call.
Pull Payments
Move the cost to claimants so distribution scales with users, not the contract owner.
Bounded Iteration
Process in batches to keep each transaction within gas limits.
