Module 6 › Chapter 6.5 › Gas limit attacks
Threat

Economic Denial of Service

An attacker makes a function too expensive to call so honest users stop using it.

Examples
  • Spamming storage entries to inflate iteration costs.
  • Triggering heavy calculations on paths callable by anyone.
Mitigations
Restrict who can add costly data, use deposits to deter spam, off-load work off-chain or batch carefully.
Concrete exercise
Simulate an attacker adding many entries and measure gas growth for functions that process that state. Determine when the cost becomes unaffordable.
Pro-tip
Use gas profiling in test frameworks and run stress tests with adversarial scripts to reveal economic DoS vectors.
