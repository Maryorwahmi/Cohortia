Pattern

Batch processing

Accept a limited range or batch size and process only that set per call, keeping gas under control.

Implementation checklist
  • Validate bounds and batch size in require checks.
  • Keep per-item gas predictable and conservative.
  • Allow anyone to call batches and optionally provide a small reward.
Operational note
Track progress with indices or a queue so completions can be monitored and resumed safely.
Example
function distributeAirdropBatch(uint256 _startIndex, uint256 _endIndex, uint256 _amount) public {
  require(_endIndex < participants.length, "End index out of bounds");
  require(_endIndex - _startIndex <= 100, "Batch size too large (max 100)");

  for (uint i = _startIndex; i <= _endIndex; i++) {
    address participant = participants[i];
    // distribution logic
  }
}
Analogy
Process a fixed number of files at a time instead of trying to import everything in one run.
