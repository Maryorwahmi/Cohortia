Module 6 › Chapter 6.5 › Data structure redesign
Arrays
Good for ordered lists and enumeration
Risk: iterating scales linearly and can exceed gas limits.
Mappings
Keyed access without enumeration cost
Use for claim balances and per-user flags to avoid full scans.
Merkle trees
Compact on-chain verification
Store a root and require off-chain proofs for membership to avoid on-chain lists.
Decision guide
  • If you need per-user claims without enumeration, prefer mappings.
  • If you must verify off-chain lists cheaply, use Merkle proofs.
  • If enumeration is required, combine arrays with batching and conservative caps.
