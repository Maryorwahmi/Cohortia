Module 6 › Chapter 6.5 › What is DoS?
Definition

Denial of Service for smart contracts

A DoS on-chain prevents legitimate users from interacting with essential functions by making them fail or too expensive to run.

How it happens
  • Gas cost of an operation grows with state size until it exceeds the block gas limit.
  • External dependency can be paused or revert, blocking your contract's workflows.
  • An attacker can intentionally inflate state or spam costly functions to raise economic cost.
Common misconception
DoS is not always an explicit attack: unbounded growth or poor design can cause the same effect without a malicious actor.
Concrete example
Iterating over a growing array until gas exceeds block limit.
Imagine a reward function that loops through every participant. If participants reach thousands, the loop may never finish.
Key takeaway
Design for predictable per-transaction gas. If cost can grow without bound, refactor the pattern.
