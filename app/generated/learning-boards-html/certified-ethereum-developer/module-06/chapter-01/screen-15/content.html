Module 6 › Chapter 6.1 › Assessment Walkthrough
Question 1 — Reentrancy
Explain why decrementing balance before an external call is risky. Show how an attacker re-enters the function and drains funds. Defensive fix: update state first or use pull payments.
Question 2 — Integer overflow
Explain how adding one to a variable at its type maximum wraps to zero in older compilers. Consequence: incorrect totals and potential loss. Defensive fix: use versions with automatic checks or explicit checked arithmetic.
Scoring hints
  • Describe the exploit sequence step-by-step.
  • Identify the exact vulnerable line(s) in code.
  • Propose minimal, practical code changes that remove the vulnerability.
Key Takeaway

Good answers show both attack steps and defensive code-level fixes. That demonstrates practical understanding, not just theory.
