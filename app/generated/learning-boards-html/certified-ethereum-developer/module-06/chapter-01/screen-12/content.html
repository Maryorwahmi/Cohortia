Module 6 › Chapter 6.1 › Oracle & Front-running
Oracle manipulation
External feeds can be manipulated; contracts should not trust a single data source for critical decisions.
Use aggregated or time-averaged values when possible.
Avoid immediate, single-sample price-dependent critical operations.
Front-running
Because transactions are visible before inclusion, adversaries can reorder and insert transactions to their advantage.
Mitigations include commit-reveal for sensitive inputs and batching to hide intent.
Design flows so a single reordered transaction cannot create outsized profit.
Key Takeaway

Treat every external input and transaction visibility as a potential source of manipulation; design with that threat model.
