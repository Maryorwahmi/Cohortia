Module 6 › Chapter 6.1 › Integer Overflow & Underflow
What happens
When calculations exceed type bounds, values wrap to the other end of the range, producing incorrect results.
Example: uint8 255 + 1 → 0
Example: uint8 0 - 1 → 255
Impact: token misallocation, balance errors, and logic bypass.
Defensive measures
  • Use language versions that check overflow by default when available.
  • Validate inputs and bounds for values involved in financial calculations.
  • Avoid unnecessarily small integer sizes when values can grow.
Misconception

Don't assume overflow is rare or impossible; focus on the worst-case input that can be provided by a user or another contract.
