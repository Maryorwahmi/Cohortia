Module 6 › Chapter 6.6 › Key Concepts
Oracle Problem
Bringing off-chain data on-chain adds trust and freshness assumptions that must be managed.
Oracle Manipulation
Stale feeds and flash-loan-driven price spikes can mislead contracts that use spot prices from manipulable sources.
Front-Running
Mempool visibility enables reordering and sandwich attacks; hiding or batching sensitive actions reduces exposure.
Takeaway
Design for layered defenses: diversify sources, smooth prices, add deviation checks, and reduce public observability for sensitive operations.
