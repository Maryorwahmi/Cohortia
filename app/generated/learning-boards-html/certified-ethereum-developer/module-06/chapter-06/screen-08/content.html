Module 6 › Chapter 6.6 › Decentralized Oracle Networks
Architecture
Multi-node aggregation
Multiple oracle nodes fetch data independently, then aggregate to reduce single-point manipulation risk.
Aggregation methods
Median, trimmed mean, and weighted averages each provide different resilience to outliers.
Source diversity
Nodes should fetch from different DEXs and data providers to avoid correlated failures.
Costs & trade-offs
Latency, gas, and complexity
  • More nodes and aggregation increase gas and coordination complexity.
  • Higher security often means slower updates—pick what aligns with user risk tolerance.
Key Takeaway

Decentralization of reporting reduces single-point risk but only when node sources are diverse and aggregation is chosen thoughtfully.
