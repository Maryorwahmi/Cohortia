Architecture patterns
Single-source vs decentralized networks
Compare common patterns and their trust boundaries.
Single-provider oracle
Simple and cheap but vulnerable to owner compromise or collusion.
Decentralized oracle network
Multiple nodes fetch data and aggregate it, making single-node manipulation harder.
Hybrid approaches
Combine aggregator nodes, multiple upstream sources, and sanity checks like thresholds or circuit breakers.
Trust boundaries
What you must trust
  • Node operators act honestly and fetch correct upstream feeds.
  • Aggregation methods accurately reflect the node inputs and handle outliers.
  • Update cadence matches the application's tolerance for stale data.
Example choice
A high-value lending protocol should prefer multi-node aggregation and TWAP to reduce the risk of a single flash loan manipulating collateral valuation.
