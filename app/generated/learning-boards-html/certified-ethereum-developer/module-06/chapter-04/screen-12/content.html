Module 6 › Chapter 6.4 › Common Pitfalls
Frequent issues
  • Missing access control modifiers on sensitive functions.
  • Incorrect expectations about msg.sender across contract calls.
  • Hardcoding privileged addresses instead of configurable state.
  • Uncontrolled use of renounceOwnership making a contract unmanageable.
Tests to run
  • Assert reverts for unauthorized callers on every sensitive function.
  • Call functions from a contract to observe msg.sender behavior.
  • Verify role grant and revoke behavior under different admin accounts.
Reminder

Assume every function without a guard is public. Add guards proactively and test them.
