SafeCounter example
// SPDX-License-Identifier: MIT
pragma solidity ^0.7.0;

import "@openzeppelin/contracts/utils/math/SafeMath.sol";

contract SafeCounter {
    using SafeMath for uint256; // Apply SafeMath to uint256
    using SafeMath for uint8;   // Apply SafeMath to uint8

    uint8 public count = 0;
    uint256 public totalValue = 0;

    function increment() public {
        count = count.add(1);
    }

    function decrement() public {
        count = count.sub(1);
    }

    function addToTotal(uint256 _amount) public {
        totalValue = totalValue.add(_amount);
    }
}
Notes and proof
  • SafeMath functions revert before a value would wrap, preserving contract invariants.
  • Using SafeMath for small types like uint8 still matters because the range is tiny.
  • Testing should include boundary cases: max value + 1 and 0 - 1.
Testing step
Deploy with 0.7.x, call increment at max and confirm the transaction reverts rather than wrapping.
Key Takeaway

SafeMath is straightforward to integrate and is a practical defense for legacy compilers.
