Module 6 › Chapter 6.3 › Key Concepts
Fixed-size Integers
Types like uint8 and uint256 have explicit numeric limits and define when wrapping can occur.
Integer Overflow/Underflow
Crossing numeric boundaries causes values to wrap in older compilers, creating security issues.
SafeMath & Compiler Checks
SafeMath reverts on error for pre-0.8.0; Solidity 0.8.0+ includes built-in checks, with optional unchecked blocks.
Summary Takeaway

Treat any unchecked arithmetic as a red flag. Use SafeMath for legacy compilers, rely on compiler checks in modern compilers, and only opt out with verified bounds and tests.
