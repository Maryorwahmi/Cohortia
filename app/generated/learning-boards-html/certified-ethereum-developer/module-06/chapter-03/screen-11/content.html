The unchecked block
Opt out of compiler checks for deliberate, constrained use cases.
Example usage
unchecked {
  count++; // no revert on overflow here
}
When to use
Narrowly scoped loops with proven bounds, or algorithms that intentionally rely on wrapping (rare).
When not to use
Never apply unchecked to general accounting, token transfers, or operations that depend on invariants without tests.
Key Takeaway

Unchecked blocks can save gas but reintroduce wrapping risks; use them sparingly and defend them with tests and documentation.
