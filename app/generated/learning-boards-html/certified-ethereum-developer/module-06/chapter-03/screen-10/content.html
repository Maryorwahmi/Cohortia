Solidity 0.8.0+: Built-in checks
Arithmetic now reverts by default on invalid results.
What changed
  • Plain arithmetic operations include overflow/underflow checks.
  • Transactions revert automatically instead of silently wrapping.
  • Developers no longer need SafeMath for basic arithmetic safety.
Unchecked blocks
You can opt out of checks for a block using 'unchecked { ... }'. Use this only when you can prove the operation is safe or intentionally want wrapping, such as specific low-level loops or cryptographic code that depends on wrapping semantics.
Migration note
When moving code to 0.8.x, remove redundant SafeMath calls where they only duplicated compiler checks, but retain tests to prove behavior remains correct.
Key Takeaway

Compiler-level checks improve safety and simplify code, but unchecked blocks reintroduce risk and require careful justification.
