OpenZeppelin's SafeMath
A defensive wrapper that reverts on arithmetic errors for older compilers.
Why it helps
  • Reverts the transaction before storing an invalid result.
  • Provides add, sub, mul, div, and mod helpers with checks.
  • Integrates via 'using SafeMath for' for readable calls.
How to use
// SPDX-License-Identifier: MIT
pragma solidity ^0.7.0;

import "@openzeppelin/contracts/utils/math/SafeMath.sol";

contract SafeCounter {
    using SafeMath for uint256;
    uint256 public totalValue = 0;

    function addToTotal(uint256 _amount) public {
        totalValue = totalValue.add(_amount);
    }
}
Pro tip
When updating legacy code, adding SafeMath calls is a quick and safe improvement that avoids a full language upgrade immediately.
Key Takeaway

SafeMath provides explicit guards that convert silent wrapping into safe reverts in Solidity versions prior to 0.8.0.
