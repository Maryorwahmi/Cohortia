Overflow vs Underflow
Understand the difference and why silent wrapping is hazardous.
Overflow
Occurs when result > max value. Example: uint8 255 + 1 wraps to 0 in older compilers.
Underflow
Occurs when result < min value. Example: uint8 0 - 1 wraps to 255.
Misconception
Assuming arithmetic always reverts — only true from 0.8.0 onward.
Security impact
Wrapped values can become attacker-controlled and break invariants.
Practical check
Validate ranges and use checked arithmetic for balances and totals.
Key Takeaway

Overflow and underflow are boundary-crossing errors that previously wrapped silently; treat unchecked arithmetic as a high-severity risk in financial logic.
