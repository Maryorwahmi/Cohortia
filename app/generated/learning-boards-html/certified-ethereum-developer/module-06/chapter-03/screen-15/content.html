Module 6 › Chapter 6.3 › Quick Reference
Know your ranges
Choosing types sets safe boundaries — document assumptions.
Use SafeMath (legacy)
SafeMath reverts on overflow/underflow for pre-0.8.0 code.
Prefer compiler checks
Solidity 0.8.0+ reverts by default; only use unchecked with proofs and tests.
Final Tip

Keep boundary tests in CI and treat any unchecked arithmetic as a deliberate, documented exception.
