Checks-Effects-Interactions
1. Checks: validate inputs and balances.
2. Effects: update balances and state variables immediately.
3. Interactions: perform external calls last and check results.
Example refactor
function withdrawSafe(uint256 _amount) public {
    require(balances[msg.sender] >= _amount, "Insufficient balance");

    balances[msg.sender] -= _amount; // Effect: update first

    (bool success, ) = msg.sender.call{value: _amount}("");
    require(success, "Transfer failed");
}
Key Takeaway
Reordering stops the simple reentrant loop because repeated require checks fail after the effect step.
