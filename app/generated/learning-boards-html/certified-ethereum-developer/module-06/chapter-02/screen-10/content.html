Refactor: CEI applied
function withdrawSafe(uint256 _amount) public {
    require(balances[msg.sender] >= _amount, "Insufficient balance");

    balances[msg.sender] -= _amount; // Effect: Update first

    (bool success, ) = msg.sender.call{value: _amount}("");
    require(success, "Transfer failed");
}
Check
Run attacker tests to ensure nested calls cannot withdraw twice.
Practical note
If transfer fails, your require will revert and the state remains consistent because the effect occurred before the interaction. Confirm desired behavior for failed payments.
Misconception
CEI alone cannot protect across multiple interacting functions unless the same discipline is applied everywhere.
