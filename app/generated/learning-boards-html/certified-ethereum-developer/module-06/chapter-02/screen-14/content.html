Module 6 › Chapter 6.2 › Key Concepts
Reentrancy Attack
External call allows the callee to call back before state updates, enabling repeated execution.
Checks-Effects-Interactions
Validate, update state, then interact. Reorder operations to remove re-entry windows.
Reentrancy Guard
A mutex-based modifier prevents re-entrant calls and complements CEI in complex flows.
Summary takeaway
Use CEI to remove simple re-entry windows, add nonReentrant for additional safety, and prefer call with these defenses to balance compatibility and protection.
