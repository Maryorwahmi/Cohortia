Module 6 › Chapter 6.2 › CEI + Guard
Combine CEI and nonReentrant
Pattern
Apply CEI inside functions and protect public entry points with a nonReentrant modifier to ensure mutually exclusive execution.
Example
contract SafeBank is ReentrancyGuard {
    mapping(address => uint256) public balances;

    function withdraw(uint256 _amount) public nonReentrant {
        require(balances[msg.sender] >= _amount);
        balances[msg.sender] -= _amount; // CEI effect
        (bool success, ) = msg.sender.call{value: _amount}("");
        require(success);
    }
}
Why it helps
CEI deals with ordering; the guard catches unexpected re-entries or oversights in complex flows.
Design note
Ensure guards cover the right functions and document intended mutual exclusions for future maintainers.
