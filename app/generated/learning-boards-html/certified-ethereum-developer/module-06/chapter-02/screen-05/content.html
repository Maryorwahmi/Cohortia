Reentrancy explained
Vulnerable pattern
Check balance → External call to recipient → Update balance. The external call can re-enter before update.
Concrete example
A withdraw that calls msg.sender.call{value: amount}("") before decrementing balances allows repeated withdrawals.
Contrast
Reentrancy is about control flow and external interactions. It is distinct from arithmetic or access control bugs.
Key takeaway
Always assume external calls are untrusted and order state updates before making them.
