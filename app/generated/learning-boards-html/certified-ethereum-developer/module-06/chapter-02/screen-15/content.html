Module 6 › Chapter 6.2 › What to Remember
Assume calls are untrusted
Any external call may change control flow; code accordingly.
Apply CEI
Checks, then Effects, then Interactions to remove re-entry windows.
Use guards
Add nonReentrant where complexity or public access increases risk.
Final practice tip
Refactor a vulnerable contract, run the attacker test, and document your defensive choices for code reviewers.
