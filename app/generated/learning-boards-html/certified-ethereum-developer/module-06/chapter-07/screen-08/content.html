Module 7 › Chapter 6.7 › Fuzz testing
What is fuzz testing?
Generate randomized inputs to validate properties and find edge cases you would not write manually.
Example property
For any valid transfer amount within balance, sender balance decreases and recipient increases by the same amount.
Assumptions matter
Use vm.assume to restrict fuzzed inputs to meaningful domains to avoid spurious failures.
Fuzz test sketch
function testFuzz_TransferWithRandomAmounts(address _from, address _to, uint256 _amount) public {
  vm.assume(_from != address(0) && _to != address(0) && _from != _to);
  myToken.mint(_from, 1000);
  uint256 initialFrom = myToken.balanceOf(_from);
  uint256 initialTo = myToken.balanceOf(_to);

  vm.startPrank(_from);
  if (_amount <= initialFrom) {
    myToken.transfer(_to, _amount);
    assertEq(myToken.balanceOf(_from), initialFrom - _amount);
  } else {
    vm.expectRevert("ERC20: transfer amount exceeds balance");
    myToken.transfer(_to, _amount);
  }
  vm.stopPrank();
}
Use fuzzing for functions with wide input domains and important invariants.
