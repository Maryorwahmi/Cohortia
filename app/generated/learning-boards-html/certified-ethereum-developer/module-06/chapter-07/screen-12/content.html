Module 7 › Chapter 6.7 › Integration testing
Integration pattern
Deploy all related contracts, configure addresses, simulate user actions, and assert system state and invariants.
Example flow
User deposits in Deposit → Deposit forwards to LendingPool → LendingPool uses PriceOracle to compute collateral value.
Testing tips
  • Use local deployments and mocks to keep tests deterministic.
  • Assert state changes and event emissions that demonstrate correct interactions.
  • Test failure paths such as oracle returning stale or invalid prices.
Key Takeaway

Write integration tests that prove the contracts work together and uphold cross-contract invariants.
