Foundry setup & patterns
Install foundryup, init a project, and write tests inside test/ in Solidity.
Cheatcodes
vm.addr, vm.deal, vm.startPrank, vm.expectRevert let you shape test context precisely.
setUp pattern
Deploy contracts and prepare accounts so tests share a known starting state.
Key Takeaway

Foundry's solidity-native tests and cheatcodes enable fast, expressive test scenarios and fuzzing.

Example test sketch
// test/MyToken.t.sol
import "forge-std/Test.sol";
import "../src/MyToken.sol";

contract MyTokenTest is Test {
  MyToken myToken;
  address owner = vm.addr(1);

  function setUp() public {
    vm.deal(owner, 10 ether);
    vm.startPrank(owner);
    myToken = new MyToken(1000);
    vm.stopPrank();
  }

  function testDeployment_AssignsTotalSupply() public view {
    assertEq(myToken.totalSupply(), myToken.balanceOf(owner));
  }
}
Use vm.assume to constrain fuzzed inputs and vm.expectRevert to assert failure messages.
