Smart Contract Testing with Hardhat & Foundry
Set up test environments, write unit and integration tests, and use fuzzing to find edge cases.
In this lesson
Why testing matters and how to start with Hardhat and Foundry.
Coming up
Walkthroughs for unit, integration, and fuzz tests plus a hands-on ERC-20 lab.
Common mistakes
Insufficient coverage, missing negative tests, and unreliably reset state.
Outcomes
Write tests that catch regressions and simulate real interactions between contracts.
Hands-on lab: ERC-20 tests
Write unit and integration tests, run them locally, then translate them to Foundry.
Explore Key Topics
Hardhat
JavaScript/TypeScript testing with Mocha, Chai, and ethers.js for scripting tests.
Foundry
Solidity-native tests with fast fuzzing and vm cheatcodes.
Fuzzing
Property-based tests that generate inputs to reveal edge cases and unexpected failures.
Testing workflow snapshot
Initialize, write tests, run locally, iterate, and integrate into CI.
Setup
npx hardhat init or forge init, install dependencies, create contracts and tests folders.
Run
npx hardhat test or forge test to run suites locally with fast feedback loops.
Analyze
Interpret failures, reproduce minimal cases, add negative tests and fuzzing where helpful.
