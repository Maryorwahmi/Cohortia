Module 7 › Chapter 6.7 › Hardhat setup
Hardhat setup steps
Initialize, install toolbox, create contract and test folders, and run tests.
Commands
npx hardhat init npm install --save-dev hardhat @nomicfoundation/hardhat-toolbox npx hardhat test
Test isolation
Deploy contracts inside beforeEach to ensure each test runs on a fresh state.
Negative tests
Assert expected revert messages to guarantee correct failure modes.
Example test pattern
// test/MyToken.test.js
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("MyToken", function () {
  let MyToken, myToken, owner, addr1;

  beforeEach(async function () {
    MyToken = await ethers.getContractFactory("MyToken");
    [owner, addr1] = await ethers.getSigners();
    myToken = await MyToken.deploy(1000);
    await myToken.deployed();
  });

  it("assigns total supply to owner", async function () {
    expect(await myToken.totalSupply()).to.equal(await myToken.balanceOf(owner.address));
  });
});
Key Takeaway

Run tests locally and isolate state to avoid flaky suites and hidden dependencies.
