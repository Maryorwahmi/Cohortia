The fodhelper.exe UAC Bypass

A Classic Example of Registry Manipulation

What is fodhelper.exe?

fodhelper.exe is a legitimate Windows utility (Features on Demand Helper) that is designed to auto-elevate without a UAC prompt.

  • Signed by Microsoft.
  • Trusted to perform administrative tasks.
  • Its auto-elevation makes it a prime target.

The Vulnerability

fodhelper.exe checks specific Registry keys for commands to execute upon launch. If a low-privileged user can write to these keys, they can inject malicious commands.

  • Key target: HKCU\Software\Classes\ms-settings\shell\open\command.
  • HKCU (HKEY_CURRENT_USER) is writable by standard users.
Key Takeaway

The fodhelper.exe bypass exploits a trusted auto-elevating process by manipulating its Registry-based execution commands.

fodhelper.exe Bypass Flow

1. Low-Privilege Access

Attacker has standard user shell.

2. Registry Manipulation

Attacker writes malicious command to HKCU.

3. Execute fodhelper.exe

Legitimate utility is launched.

4. Elevated Shell

Malicious command runs with admin privileges.
