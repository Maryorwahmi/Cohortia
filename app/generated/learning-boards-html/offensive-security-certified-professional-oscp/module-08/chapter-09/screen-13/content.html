Post-Exploitation Cleanup and Safety

Maintaining Stealth and System Stability

# 1. Delete payload and psexec.exe
C:\Temp> del C:\Temp\shell.exe
C:\Temp> del C:\Temp\psexec.exe
# 2. Remove Registry entries for UAC bypass
C:\Users\StandardUser> reg delete "HKCU\Software\Classes\ms-settings\shell\open\command" /f
The operation completed successfully.
Key Takeaway

Always clean up artifacts and revert system changes after an exploit to maintain stealth and prevent system instability.

Importance of Cleanup

Removing malicious files and reverting Registry changes is crucial for:

  • Stealth: Avoiding detection by security tools and administrators.
  • System Stability: Preventing unintended side effects or system malfunctions.
  • Professionalism: Leaving the target system in its original state.

Safety Note: Lab Environment Only

UAC bypasses are highly dependent on Windows versions and patch levels. Always test these techniques in a controlled lab environment. Incorrect modifications can lead to system instability or data loss.
