Key Takeaway

psexec -i -s cmd.exe is the direct command to launch an interactive SYSTEM shell from an elevated administrator context.

psexec Flags Explained

  • -i (Interactive): Ensures the new process runs interactively, allowing you to see and use the command prompt.
  • -s (SYSTEM): Specifies that the process should run under the SYSTEM account, granting the highest privileges.

Transferring psexec.exe

Before execution, you must transfer the psexec.exe binary to a writable location on the target system. This can be done via various methods like SMB, HTTP, or PowerShell downloads.

Verifying SYSTEM Privileges

Once the new command prompt appears, run the whoami command. A successful SYSTEM elevation will show nt authority\system as the current user.
