Understanding User Account Control (UAC)

Windows' Gatekeeper for Privileged Operations

The Dual Token System

When an administrator logs in, Windows creates two access tokens:

  • Full Administrator Token: Contains all administrative privileges.
  • Filtered Standard User Token: A restricted token used for most applications by default.

UAC's Core Function

UAC's primary role is to:

  • Mitigate Malware: Prevents malicious software from making system-wide changes.
  • Improve Security: Limits application privileges, requiring explicit consent for administrative tasks.
Key Takeaway

UAC ensures applications run with minimal privileges, prompting for consent only when administrative actions are truly needed.

Elevated Admin Context

The UAC prompt acts as a gate, requiring user consent before an application can elevate its privileges.

The Goal of a UAC Bypass

To elevate privileges from a standard user to a full administrator without triggering the UAC consent prompt. This does not typically grant SYSTEM privileges directly, but rather an elevated administrator context, from which further escalation can occur.
