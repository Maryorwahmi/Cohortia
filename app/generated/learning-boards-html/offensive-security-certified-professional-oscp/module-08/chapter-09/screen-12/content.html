Multi-Stage Attack Path Examples

Illustrating Complex Privilege Escalation Chains

Scenario 1: Service Exploitation to SYSTEM

1

Enumerate Thoroughly: Find weak service permissions.

2

Exploit a Service: Gain LocalService or NetworkService privileges.

3

Use a "Potato" Attack: Leverage SeImpersonatePrivilege to get SYSTEM.

Scenario 2: UAC Bypass to SYSTEM

1

Enumerate: Find an outdated application.

2

Exploit Application: Gain a low-privileged user shell.

3

Find a UAC Bypass: Elevate to Administrator.

4

Dump Credentials: Use Mimikatz for SYSTEM token/hashes.

5

Use psexec: Get a SYSTEM shell.

Key Takeaway

Always look for multiple paths and understand how each vulnerability can be leveraged to get closer to your ultimate goal. Test in a lab environment.
