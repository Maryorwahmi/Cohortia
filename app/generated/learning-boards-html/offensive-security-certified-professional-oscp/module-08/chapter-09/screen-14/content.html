Key Concepts: UAC & Bypass Fundamentals

Essential Terms and Techniques to Remember

UAC (User Account Control)

A Windows security feature that helps prevent unauthorized changes to the operating system by requiring administrative consent for privileged actions.

UAC Bypass

A technique to elevate privileges from a standard user to an administrator without triggering the UAC consent prompt.

Auto-Elevating Executables

Legitimate Windows applications designed to run with administrative privileges without a UAC prompt, often exploited in UAC bypasses.

Summary Takeaway

UAC is a critical defense, but understanding auto-elevating executables is key to bypassing it for privilege escalation.
