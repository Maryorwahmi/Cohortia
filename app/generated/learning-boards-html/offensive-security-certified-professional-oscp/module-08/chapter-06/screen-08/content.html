Post-Extraction Analysis

Using Impacket's secretsdump.py

Decrypting SAM and SECURITY hives to reveal password hashes.

  • •Part of the Impacket toolkit, used for parsing offline registry hives.
  • •Extracts local user NTLM hashes from SAM and cached domain credentials from LSA secrets.
  • •Output is suitable for offline cracking or pass-the-hash attacks.
Key Takeaway

After extracting the SAM and SECURITY registry hives, tools like secretsdump.py are essential for parsing these files and extracting the valuable password hashes they contain.

# On Kali Linux, after transferring SAM.hiv and SECURITY.hiv
secretsdump.py -sam SAM.hiv -security SECURITY.hiv LOCAL
This command uses secretsdump.py to extract hashes from the provided SAM and SECURITY hive files for local accounts.
Pro Tip

Always handle extracted hive files and hashes with extreme care due to their sensitive nature. Delete them securely after use.
