Browser Saved Passwords and RDP Files

Exploiting user convenience for credential discovery.

Browser Passwords: Web browsers (Chrome, Firefox, Edge) often store user passwords, typically encrypted.

Extraction Tools: Tools like LaZagne or dedicated browser forensics tools can extract these.

Requirements: Usually requires the user to be logged in or access to their profile directory.

RDP Files: Users sometimes save credentials within .rdp files for remote desktop connections.

Locations: Found in C:\Users\<user>\Documents or C:\Users\<user>\AppData\Roaming\Microsoft\Windows\RDP.

Usage: Passwords are encrypted but can sometimes be decrypted or used for "pass-the-hash" attacks.

Key Takeaway

User convenience features, such as saved browser passwords and RDP connection settings, often become overlooked sources of valuable credentials for attackers.
