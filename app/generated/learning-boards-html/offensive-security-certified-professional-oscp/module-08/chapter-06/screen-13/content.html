Key Concepts

Essential Terms in Credential Mining

LSASS

A Windows process enforcing security policy and storing credentials in memory.

Mimikatz

A post-exploitation tool to extract cleartext passwords, hashes, and Kerberos tickets from LSASS.

SAM Database

A Windows database storing local user account password hashes.

Summary Takeaway

These core concepts form the foundation for understanding and executing credential harvesting techniques on Windows systems.
