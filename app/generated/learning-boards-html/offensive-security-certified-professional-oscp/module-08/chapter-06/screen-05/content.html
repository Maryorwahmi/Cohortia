Critical Service

Local Security Authority Subsystem Service (LSASS)

A central process for security policy, authentication, and credential storage.

  • •Enforces security policy, including user authentication and access token management.
  • •Stores user credentials or derived hashes in memory for single sign-on (SSO) purposes.
  • •A high-value target for attackers due to the sensitive authentication data it holds.
  • •Requires elevated privileges (typically SYSTEM or Administrator) to access its memory.
Key Takeaway

LSASS is a prime target for attackers because it temporarily stores user credentials in memory, making it a rich source for post-exploitation activities.
