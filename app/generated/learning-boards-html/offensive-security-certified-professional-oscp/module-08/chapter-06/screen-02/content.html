01

Identify Credential Locations

Understand various locations where Windows stores sensitive credentials, including hashes and cleartext passwords. This knowledge is foundational for effective credential harvesting.

VERIFIED COMPETENCY MILESTONE
02

Extract from LSASS Memory

Learn to extract credentials from the Local Security Authority Subsystem Service (LSASS) process memory using tools like Mimikatz. This is a high-value target for attackers.

VERIFIED COMPETENCY MILESTONE
03

Extract from SAM & LSA Secrets

Identify and extract credentials from the Security Account Manager (SAM) database, LSA secrets, and other system files. These are crucial for local and cached domain credentials.

VERIFIED COMPETENCY MILESTONE
04

Explore Other Credential Sources

Explore methods for finding credentials in configuration files, browser data, and remote desktop connection files. These often contain cleartext passwords.
