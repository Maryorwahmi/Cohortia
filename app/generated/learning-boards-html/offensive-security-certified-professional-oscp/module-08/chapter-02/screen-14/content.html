Key Concepts

Essential takeaways from this chapter

sc qc

A native Windows command-line utility used to query the configuration of a specific service, revealing its BINARY_PATH_NAME.

icacls

A native Windows command-line utility to display or modify Access Control Lists (ACLs) for files and directories, crucial for permission checks.

accesschk.exe

A Sysinternals tool that quickly shows what access specific users or groups have to files, registry keys, and services.

These tools are indispensable for identifying and verifying service vulnerabilities in real-world scenarios.
