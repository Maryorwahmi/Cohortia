Using sc qc to Find USPs

The sc qc command queries the configuration of a service, revealing its BINARY_PATH_NAME. This is the primary method to identify unquoted service paths.

Command-line Utility: sc qc is a native Windows command for service configuration.

Key Parameter: Look for the BINARY_PATH_NAME in the output.

Vulnerability Indicator: Path contains spaces but lacks enclosing quotation marks.

Key Takeaway

Use sc qc "Service Name" to inspect BINARY_PATH_NAME for unquoted paths with spaces, which are prime indicators of a USP vulnerability.

Terminal Output Example
# Query service configuration to find unquoted paths
sc qc "Vulnerable Service"

# Example output for an unquoted path:
# SERVICE_NAME: Vulnerable Service
# TYPE               : 10  WIN32_OWN_PROCESS
# START_TYPE         : 2   AUTO_START
# ERROR_CONTROL      : 1   NORMAL
# BINARY_PATH_NAME   : C:\Program Files\Vulnerable App\vulnerable.exe
# LOAD_ORDER_GROUP   :
# TAG                : 0
# DISPLAY_NAME       : Vulnerable Service
# DEPENDENCIES       :
# SERVICE_START_NAME : LocalSystem

# Notice the BINARY_PATH_NAME has spaces but no quotes.
Pro Tip

When scanning, you can automate this by piping sc qc output to findstr or a PowerShell script to filter for unquoted paths containing spaces, saving significant time.
