Registry Structure

Registry Hives: HKLM vs. HKCU

Understanding the scope of system-wide and user-specific settings.

HKEY_LOCAL_MACHINE (HKLM)

  • •Stores settings for all users on the computer.
  • •Impacts system services and the operating system itself.
  • •Modifications can lead to SYSTEM privileges.
Key Takeaway

Targeting HKLM keys offers the highest potential for system-wide privilege escalation due to its broad impact.

HKEY_CURRENT_USER (HKCU)

  • •Stores settings specific to the currently logged-on user.
  • •Primarily affects the current user session.
  • •Less direct for privilege escalation, but useful for persistence.

Why the Distinction Matters

Consider a scenario where you've gained low-level access. If you can modify an HKLM key, your malicious code could run with SYSTEM privileges when the next administrator logs in. If you only modify an HKCU key, your code would only run when your current user logs in, which is useful for persistence but not direct privilege escalation. This distinction guides your attack strategy.
