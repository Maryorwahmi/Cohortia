Image File Execution Options (IFEO) Hijacking

Abusing debugger settings for process hijacking.

What is IFEO?

  • •Registry key designed for attaching debuggers to executables.
  • •Located at HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options.
  • •Can be abused to hijack the execution of legitimate programs.
Key Takeaway

IFEO hijacking allows an attacker to execute their code with the privileges of a targeted legitimate process.

How it's Exploited

  • •Low-privileged user adds a 'Debugger' value for a privileged executable (e.g., cmd.exe).
  • •The 'Debugger' value points to the attacker's malicious program.
  • •When the privileged executable runs, the malicious program executes instead, inheriting its privileges.

Example Scenario

Imagine you find write permissions on the IFEO key for 'taskmgr.exe' (Task Manager). You could set your reverse shell as the debugger. The next time an administrator opens Task Manager, your shell would execute with administrative privileges, granting you control. This is a powerful way to intercept and elevate privileges.
