Key Concepts: Part 2

Essential terms and ideas from this chapter.

`reg query`

A native Windows command-line utility used to display Registry key values and subkeys for reconnaissance.

`reg add`

A native Windows command-line utility used to add new Registry keys or entries, crucial for payload injection.

Image File Execution Options (IFEO)

A Registry key that allows a debugger to be specified for any executable, which can be abused for process hijacking.

Summary Takeaway

Tools like `reg query` and `reg add` are fundamental for Registry interaction, while IFEO offers an advanced technique for process hijacking.
