File Association Hijacking

Manipulating default program execution via Registry modifications.

How File Associations Work

  • •Registry (HKLM\SOFTWARE\Classes) stores default programs for file types.
  • •Example: .txt files open with Notepad.
  • •Legitimate function, but exploitable with weak permissions.
Key Takeaway

Hijacking file associations can lead to code execution when privileged processes open specific file types.

Exploitation Method

  • •Identify a file type frequently used by a privileged process.
  • •Check for write permissions on its associated Registry key in HKLM\SOFTWARE\Classes.
  • •Modify the default command to point to your malicious executable.
  • •When the privileged process opens that file type, your code executes.

Practical Example

Consider a system where an administrative script regularly processes `.bat` files. If you can modify the file association for `.bat` files to execute your malicious payload instead of the default interpreter, your code will run with administrative privileges every time that script is invoked. This is a powerful, albeit more complex, method for privilege escalation.
