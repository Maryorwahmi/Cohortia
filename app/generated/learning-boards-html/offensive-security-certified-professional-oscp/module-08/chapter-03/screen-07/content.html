Querying AutoRun Keys with `reg query`

Discovering existing AutoRun entries from the command line.

The `reg query` Command

  • •Native Windows utility for displaying Registry key values.
  • •Essential for initial reconnaissance of AutoRun entries.
  • •Helps identify programs configured for automatic startup.
Key Takeaway

Use `reg query` to list AutoRun entries and identify potential targets for exploitation.

Command Example
# Query HKLM Run key entries
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# Example Output:
# HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
#    SecurityHealth  REG_SZ  %ProgramFiles%\Windows Defender\MSASCuiL.exe
#    OneDrive        REG_SZ  "C:\Program Files\Microsoft OneDrive\OneDrive.exe" /background

Analyzing the Output

When you run `reg query`, look at the executable paths. If an entry points to a location where a low-privileged user has write access, or if the executable itself has weak permissions, it becomes a potential target. For instance, if 'OneDrive.exe' was in a user-writable folder, you could replace it with your malicious payload.
