Key Concepts: Part 1

Essential terms and ideas from this chapter.

Windows Registry

A hierarchical database storing configuration settings and options for the Windows operating system and installed applications.

Registry Hives

The top-level organizational units of the Registry, such as HKEY_LOCAL_MACHINE (HKLM) and HKEY_CURRENT_USER (HKCU).

AutoRun

Mechanisms within Windows that automatically launch programs or scripts at system startup or user login.

Summary Takeaway

The Windows Registry is a critical database, organized into hives, that controls system startup and offers significant attack surfaces via AutoRun mechanisms.
