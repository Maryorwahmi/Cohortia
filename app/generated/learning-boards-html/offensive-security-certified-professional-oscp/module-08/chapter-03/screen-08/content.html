Permission Checks

Identifying Weak Permissions with `accesschk.exe`

Pinpointing Registry keys vulnerable to unauthorized modification.

Using `accesschk.exe`

  • •Sysinternals utility for enumerating effective permissions.
  • •Crucial for verifying write access on Registry keys.
  • •Look for 'Write' or 'Full Control' for low-privileged users.
Key Takeaway

`accesschk.exe` is essential to confirm if a low-privileged user can modify a target Registry key.

Command Example
# Check permissions on the HKLM Run key
accesschk.exe -uwcqv "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# Example Output (Vulnerable):
#   RW  BUILTIN\Authenticated Users
#   RW  (YourUserAccount)

Interpreting Results

If `accesschk.exe` shows 'RW' (Read/Write) or 'Full Control' for 'Authenticated Users' or your specific low-privileged account on an HKLM AutoRun key, you've found a critical vulnerability. This means you can add or modify entries, leading to privilege escalation. Without these permissions, you'll need to explore other attack vectors.
