Efficiency in Enumeration

Sherlock.ps1 and PowerUp.ps1

Simplifying the search for missing kernel patches.

Sherlock.ps1

A PowerShell script that automatically checks for missing security updates related to known Windows kernel exploits. It compares installed KBs against a vulnerability database.

# Example usage
Import-Module C:\Temp\Sherlock.ps1
Find-AllVulns

PowerUp.ps1

Part of the PowerSploit framework, this script identifies various privilege escalation opportunities, including missing patches for kernel exploits, weak service permissions, and more.

# Example usage
Invoke-AllChecks
Key Takeaway

Automated scripts like Sherlock.ps1 and PowerUp.ps1 accelerate patch identification, but always verify their findings with manual checks.

PS C:\Users\lowpriv> Set-ExecutionPolicy Bypass -Scope Process -Force
PS C:\Users\lowpriv> Import-Module C:\Temp\Sherlock.ps1
PS C:\Users\lowpriv> Find-AllVulns
