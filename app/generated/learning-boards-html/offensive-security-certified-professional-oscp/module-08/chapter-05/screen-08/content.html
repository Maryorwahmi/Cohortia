Exploit Discovery

Matching Vulnerabilities to Exploits

Using Exploit-DB and Microsoft Security Bulletins.

Exploit-DB

Public Exploit Archive

A vast repository of exploits and vulnerable software. Search using OS versions, build numbers, or CVE IDs to find matching kernel exploits.

Example: Searching for "Windows Server 2012 R2 MS15-051"
Microsoft Security Bulletins

Vulnerability Details & Patches

Historical resource (now Security Update Guide) providing detailed information on vulnerabilities and their corresponding hotfixes. Use to confirm missing patches.

Example: Confirming KB3045999 is missing for MS15-051.

Pro Tip: CVEs and KBs

When searching, utilize Common Vulnerabilities and Exposures (CVE) IDs and Knowledge Base (KB) article numbers. These identifiers provide precise matches and streamline your research.

Key Takeaway

Effective exploit discovery relies on cross-referencing detailed system information with public vulnerability databases to find precise matches for unpatched kernel flaws.
