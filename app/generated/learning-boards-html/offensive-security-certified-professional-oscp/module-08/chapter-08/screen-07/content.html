Attack Process

Potato Attack Flow: Listener & Trigger

Setting the stage for NTLM authentication

01

Attacker Listener

The attacker runs a local listener on the target machine, waiting for NTLM authentication requests on a specific port.

02

Trigger NTLM Authentication

A local Windows service (e.g., BITS, Print Spooler) is triggered via COM objects to authenticate to the attacker's listener.

Key Takeaway

An attacker sets up a local NTLM listener and triggers a service (via COM) to authenticate to it.
