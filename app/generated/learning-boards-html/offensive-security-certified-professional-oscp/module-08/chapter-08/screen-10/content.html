Tool Variants

JuicyPotato vs. PrintSpoofer

Popular tools for 'Potato' attacks

JuicyPotato

A highly flexible tool that leverages SeImpersonatePrivilege and NTLM reflection by abusing COM objects.

  • Flexibility: Allows selection of various COM objects (CLSIDs) to trigger NTLM.
  • Success Rate: Often more successful in diverse environments due to adaptability.
  • Mechanism: Triggers local NTLM authentication via COM, then reflects to privileged API.
Key Feature

Ability to specify a CLSID for COM object interaction.

PrintSpoofer

A tool that specifically leverages the Windows Print Spooler service for privilege escalation.

  • Target: Print Spooler service, if it has SeImpersonatePrivilege.
  • Simplicity: Often simpler to execute as it doesn't require CLSID enumeration.
  • Mechanism: Abuses Print Spooler's functionality to create processes with SYSTEM privileges.
Key Feature

Directly targets a specific Windows service for exploitation.

Key Takeaway

JuicyPotato offers COM object flexibility, while PrintSpoofer targets the Print Spooler service for SYSTEM escalation.
