Key Concepts

Advanced techniques and tools

NTLM Reflection/Relay

A technique where an attacker intercepts and reflects/relays an NTLM authentication request locally.

'Potato' Attacks

A family of privilege escalation exploits leveraging SeImpersonatePrivilege and NTLM reflection/relay for SYSTEM access.

COM (Component Object Model)

A Microsoft technology for software components to communicate, often abused in Potato attacks to trigger NTLM authentication.

Summary Takeaway

NTLM reflection, 'Potato' attacks, and COM abuse are key to achieving SYSTEM privileges by exploiting Windows authentication mechanisms.
