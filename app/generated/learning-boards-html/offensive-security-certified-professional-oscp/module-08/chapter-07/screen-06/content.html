What is DLL Hijacking?

Exploiting the DLL Loading Mechanism for Code Execution

Core Principles of Hijacking

  • •Missing DLLs: An application requests a DLL that doesn't exist; attacker provides a malicious one.
  • •Insecure Search Paths: Attacker places a malicious DLL in a directory searched before the legitimate one.
  • •Privilege Escalation: If the vulnerable application runs with high privileges, the malicious DLL inherits them.
  • •Persistence: Can be used to maintain access by ensuring malicious code runs on application startup.
Key Takeaway

DLL Hijacking is a powerful technique to execute arbitrary code with elevated privileges by manipulating the Windows DLL search order.

Hijacking Scenarios

Missing DLL

Application requests a DLL that doesn't exist.

Insecure Path

Malicious DLL placed in an earlier-searched, writable directory.

Example

A SYSTEM process launches from C:\ProgramData\App\ and tries to load missing.dll. If a low-privileged user has write permissions to C:\ProgramData\App\, they can place their malicious missing.dll there, leading to SYSTEM privilege execution.
