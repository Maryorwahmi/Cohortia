Discovering Missing DLLs with Procmon

Real-time Monitoring for 'NAME NOT FOUND' Events

Procmon Filter Criteria

  • •Process Name: Target the specific high-privileged application (e.g., TargetProcess.exe).
  • •Operation: Filter for CreateFile, indicating an attempt to open or create a file.
  • •Result: Crucially, look for NAME NOT FOUND, signifying a failed file lookup.
  • •Path: Ensure the path ends with .dll to focus on Dynamic Link Libraries.
Key Takeaway

Procmon's precise filtering capabilities are indispensable for identifying missing DLLs and the exact paths where applications search for them.

# Example of using Process Monitor (Procmon)
# 1. Start Procmon.
# 2. Set filters:
- Process Name is <TargetProcess.exe>
- Operation is 'CreateFile'
- Result is 'NAME NOT FOUND'
- Path ends with '.dll'
# 3. Start the target high-privileged application.
# 4. Observe missing DLLs.
Pro Tip

Always run Procmon as an administrator to ensure it captures all system-level events, especially those related to high-privileged processes.
