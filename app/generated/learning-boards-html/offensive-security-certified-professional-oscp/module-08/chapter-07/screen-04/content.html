Core Concept

Understanding DLL Loading

How Windows Applications Find Dynamic Link Libraries

The Role of DLLs

  • •Shared Code: DLLs contain functions and resources used by multiple applications, promoting code reuse.
  • •Memory Efficiency: Reduces memory footprint as code is loaded once and shared across processes.
  • •Modularity: Allows for easier updates and maintenance, as components can be replaced independently.
  • •Dynamic Linking: Applications link to DLLs at runtime, not compile time, offering flexibility.
Key Takeaway

The DLL loading mechanism is a core Windows function, and its predictable search order is the foundation for hijacking attacks.

DLL Loading Process

1. Application Starts

Requires a specific function or resource.

2. Windows Initiates Search

Follows a predefined 'DLL Search Order'.

3. DLL Found & Loaded

Application executes functions from the loaded DLL.

Analogy

Imagine a chef needing a specific ingredient. Instead of always having it on hand, they check a list of places in a specific order (pantry, then local market, then specialty store). If an attacker can put a fake ingredient in the pantry, the chef uses that first.
