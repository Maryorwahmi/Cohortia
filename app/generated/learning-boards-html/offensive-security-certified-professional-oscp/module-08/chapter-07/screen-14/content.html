Key Concepts

Essential Terms to Remember

DLL (Dynamic Link Library)

A shared library of code and resources used by Windows applications to perform common functions.

DLL Search Order

The specific sequence of directories that Windows checks when attempting to locate and load a DLL.

DLL Hijacking

An attack where a malicious DLL is placed in a directory searched by a legitimate application before its intended DLL, causing the malicious DLL to be loaded and executed instead.

Summary Takeaway

DLLs are fundamental to Windows, and their predictable search order creates a powerful attack surface for code injection and privilege escalation.
