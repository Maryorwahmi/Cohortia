Vulnerability Analysis

Identifying Vulnerable Processes

When High-Privilege Applications Become Targets

Key Vulnerability Conditions

  • •High-Privilege Process: The target application runs as Administrator or SYSTEM.
  • •Missing DLL: The application attempts to load a DLL that does not exist.
  • •Insecure Write Permissions: A low-privileged user has write access to a directory in the DLL search path.
  • •Predictable Search Order: The application's DLL loading behavior is consistent and exploitable.
Key Takeaway

The convergence of high privileges, missing DLLs, and writable search paths creates prime DLL hijacking opportunities.

Vulnerability Chain

1. High-Privilege App

e.g., SYSTEM process

2. Attempts to Load DLL

e.g., missing.dll

3. DLL is Missing / Insecure Path

Low-priv user can write to search path.

4. Attacker Places Malicious DLL

Code executes with high privileges.

Scenario

A scheduled task runs C:\App\service.exe as SYSTEM. service.exe tries to load utility.dll from its own directory, but utility.dll is absent. If a standard user can write to C:\App\, they can plant a malicious utility.dll.
