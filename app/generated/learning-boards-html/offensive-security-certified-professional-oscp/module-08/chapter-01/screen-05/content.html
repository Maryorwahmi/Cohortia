Privilege Levels

The Goal: Administrator & SYSTEM Privileges

Understanding the ultimate targets for privilege escalation.

Administrator Privileges

  • Extensive control over the operating system.
  • Can install software, modify system settings, access most files.
  • Certain actions may still require User Account Control (UAC) elevation.
Key Capability

Manage system-wide configurations and user accounts.

SYSTEM Privileges

  • Highest privilege level on a Windows system.
  • Complete control over the kernel and all processes.
  • Bypasses most security checks, including UAC.
Key Capability

Unfettered access to the entire operating system, kernel-level control.

Key Takeaway

While Administrator provides extensive control, SYSTEM is the ultimate goal, offering complete, kernel-level access to a Windows machine.
