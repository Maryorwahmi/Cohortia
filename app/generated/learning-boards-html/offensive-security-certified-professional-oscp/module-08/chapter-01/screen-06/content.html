Windows Security

Understanding Windows Privilege Levels

Differentiating between Standard User, Administrator, and SYSTEM accounts.

Highest Privilege

SYSTEM Account

Complete control over the kernel and all processes. Bypasses most security checks, including UAC.

Elevated Privilege

Administrator

Manages the system, installs software, modifies settings. Subject to User Account Control (UAC) elevation.

Limited Privilege

Standard User

Limited access, primarily to their own profile and some system resources. Cannot make system-wide changes.

Key Takeaway

Windows privilege levels range from limited Standard User to powerful SYSTEM, each with distinct capabilities and security implications.
