User & Group Recon

Enumerating Users and Groups: net user & net localgroup

Mapping the human landscape of the target system.

C:\Users\User>net user

User accounts for \\WIN-SERVER

--------------------------------------------------------------------
Administrator          Guest                  User                   
The command completed successfully.

C:\Users\User>net localgroup Administrators

Alias name     Administrators
Comment        Administrators have complete and unrestricted access to the computer/domain

Members
--------------------------------------------------------------------
Administrator
User
The command completed successfully.

Key Information to Extract

  • Local User Accounts: Identify all users, including dormant or service accounts.
  • Group Memberships: Crucial for finding users in the 'Administrators' group or other privileged groups.
  • Detailed User Info: Look for password last set, account expiration, and other attributes that might indicate weaknesses.

Target Identification

Users in the 'Administrators' group are prime targets. If you can compromise one, you've achieved a significant privilege escalation.

Key Takeaway

Enumerating users and groups helps identify privileged accounts and potential targets for credential-based privilege escalation.
