Identifying Tasks with schtasks

Command-Line Utility for Task Discovery

The Command

schtasks /query /fo LIST /v provides a verbose, human-readable list of all scheduled tasks.

Key Fields to Inspect
  • Task Name: Identifies the task.
  • Run As User: The user context (e.g., SYSTEM, Administrator).
  • Task To Run: The executable or script path.
Key Takeaway

Prioritize tasks running as SYSTEM or Administrator that execute files in non-standard or potentially writable directories.

schtasks Example Output
# List all scheduled tasks with verbose output
schtasks /query /fo LIST /v

# Example output snippet:
TaskName:                \Microsoft\Windows\Application Experience\Microsoft Compatibility Appraiser
Run As User:             SYSTEM
Task To Run:             C:\Windows\system32\compattelrunner.exe

TaskName:                \MyCompany\DailyCleanup
Run As User:             SYSTEM
Task To Run:             C:\ProgramData\cleanup.bat

Notice: The DailyCleanup task runs as SYSTEM and targets a script in C:\ProgramData\, a common location for user-writable files.
