Inspecting File Permissions with icacls

Verifying Write Access to Target Executables/Scripts

The Tool: icacls

icacls is a command-line utility used to display or modify discretionary access control lists (DACLs) for files and directories.

What to Look For
  • (M): Modify permissions for your user or a group you belong to.
  • (F): Full control permissions.
  • These indicate you can replace or alter the file.
Key Takeaway

Confirming write permissions with icacls is a non-negotiable step before attempting to exploit a scheduled task.

icacls Example Output
# Check permissions on the target script
icacls "C:\ProgramData\cleanup.bat"

# Example output snippet:
C:\ProgramData\cleanup.bat BUILTIN\Administrators:(F)
                            NT AUTHORITY\SYSTEM:(F)
                            BUILTIN\Users:(RX)
                            NT AUTHORITY\Authenticated Users:(M)

Notice: Authenticated Users have (M) modify permissions, meaning a low-privileged user can overwrite this file.
