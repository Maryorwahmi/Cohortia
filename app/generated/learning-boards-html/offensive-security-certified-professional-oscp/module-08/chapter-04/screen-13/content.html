Unquoted Service Paths in Scheduled Tasks

Exploiting Path Ambiguity for Privilege Escalation

The Vulnerability

A scheduled task executes an executable with an unquoted path containing spaces, leading Windows to search for executables in intermediate directories.

Exploitation Method

If an attacker has write permissions to an intermediate directory, they can place a malicious executable with a matching name (e.g., Program.exe) to be executed with elevated privileges.

Key Takeaway

Always check for unquoted paths in scheduled tasks and inspect permissions on all directories in the execution path, not just the final executable.

Unquoted Path Execution Flow
# Task To Run: C:\Program Files\App\update.exe (UNQUOTED)

# Windows attempts to execute in this order:
1. C:\Program.exe
2. C:\Program Files\App.exe
3. C:\Program Files\App\update.exe (intended)

Scenario: If C:\Program Files\ is writable, an attacker could place a malicious App.exe there, which would execute before the legitimate update.exe.
