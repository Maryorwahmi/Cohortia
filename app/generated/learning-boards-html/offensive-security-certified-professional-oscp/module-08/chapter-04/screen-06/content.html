Case Study: The Cleanup Script

A Common and Effective Privilege Escalation Vector

The Setup

An admin configures C:\ProgramData\cleanup.bat to run daily at 2 AM with SYSTEM privileges.

The Vulnerability

A low-privileged user discovers they have write permissions to C:\ProgramData\cleanup.bat.

The Exploit

The user replaces cleanup.bat with a malicious script. At 2 AM, the malicious script executes with SYSTEM privileges.

Key Takeaway

This scenario is a textbook example of how weak file permissions on a high-privilege task's target can lead to full system compromise.
