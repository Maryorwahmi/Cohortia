gobuster with Extensions and Output

gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,html -o gobuster_output.txt
  • •-x: Specifies file extensions to try (e.g., .php, .txt).
  • •-o: Saves the output of the scan to a specified file.

Interpreting Scan Results

  • •**HTTP Status Codes:** gobuster reports status codes for each attempt.
  • •**200 OK:** Content found and accessible.
  • •**301/302 Redirect:** Content found, but moved to a new location.
  • •**403 Forbidden:** Directory/file exists, but access is denied (still a valuable discovery!).
Output Example

/admin (Status: 301) indicates a discovered admin directory.

Next Steps

Manually verify discovered paths in a browser and investigate further for vulnerabilities.

Key Takeaway

Using the -x flag for extensions and the -o flag for output are essential for targeted and well-documented gobuster scans.
