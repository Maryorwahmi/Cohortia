gobuster Basic Command Structure

gobuster dir -u http://target.com -w /usr/share/wordlists/dirb/common.txt
  • •dir: Specifies directory/file enumeration mode.
  • •-u: Sets the target URL for the scan.
  • •-w: Defines the wordlist to use for brute-forcing.

Understanding the Flags

  • •**dir Mode:** This is crucial; it tells gobuster to look for directories and files, not subdomains or other targets.
  • •**Target URL (-u):** The base URL of the web application you are testing. Ensure it's correct.
  • •**Wordlist (-w):** A text file containing a list of potential directory and file names. This is the engine of your brute-force attack.
Wordlist Importance

The quality and relevance of your wordlist directly impact the success of your content discovery.

Tool Overview

gobuster is known for its speed and efficiency in enumerating web content and subdomains.

Key Takeaway

Mastering the basic gobuster command with dir mode, target URL, and wordlist is fundamental for effective directory brute-forcing.
