Brute-Forcing SNMP Community Strings

Discovering Hidden Access with onesixtyone

Why Use onesixtyone?

  • Fast SNMP scanner for brute-forcing community strings.
  • Can use wordlists (e.g., /usr/share/wordlists/rockyou.txt).
  • Efficient for scanning multiple IPs from a list.
  • Crucial when default community strings are not 'public' or 'private'.
Key Takeaway

onesixtyone is your go-to tool for discovering non-default SNMP community strings, unlocking further enumeration with snmpwalk.

onesixtyone Command Example

Brute-forcing community strings with a wordlist

# Brute-force community strings from a wordlist
onesixtyone -c /usr/share/wordlists/rockyou.txt -i ips.txt

# Example: Scan a single IP with a custom wordlist
onesixtyone -c custom_strings.txt 192.168.1.105

# If successful, output might look like:
192.168.1.105 [private] Linux metasploitable 2.6.24-16-server

Important Note

The -i flag expects a file with IP addresses, one per line. For a single target, you can specify the IP directly after the wordlist.
