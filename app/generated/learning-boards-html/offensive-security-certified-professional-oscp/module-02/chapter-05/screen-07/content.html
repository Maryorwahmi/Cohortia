Enumerating SMB with enum4linux

Automating User, Group, and Share Discovery

What enum4linux Does

  • Lists users, groups, and shares.
  • Identifies password policies.
  • Discovers operating system information.
  • Wraps smbclient and nmblookup for efficiency.
Key Takeaway

enum4linux is a comprehensive script for rapid SMB reconnaissance, providing a wealth of information from a single command.

enum4linux in Action

Performing a comprehensive SMB enumeration

# Basic comprehensive enumeration
enum4linux -a 192.168.1.105

# Expected Output Snippet (Users)
[+] Enumerating users now
index: 0x20e Rtn: 0x01 Name: nobody Rid: 0x401
index: 0x20f Rtn: 0x01 Name: root Rid: 0x00
index: 0x210 Rtn: 0x01 Name: daemon Rid: 0x01

# Expected Output Snippet (Shares)
[+] Enumerating shares now
Sharename       Type      Comment
---------       ----      -------
IPC$            IPC       IPC Service (Metasploitable2 samba server)
ADMIN$          Disk      IPC Service (Metasploitable2 samba server)

Pro Tip: Analyze Output

Always review the full output for usernames, group names, accessible shares, and any other sensitive information that can be leveraged.
