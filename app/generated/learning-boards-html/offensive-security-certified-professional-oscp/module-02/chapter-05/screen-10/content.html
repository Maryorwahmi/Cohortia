Querying SNMP with snmpwalk

Unveiling Device Details with Community Strings

snmpwalk Capabilities

  • Queries network entities for a tree of information.
  • Extracts system uptime, network interfaces, processes.
  • Reveals installed software, user accounts, and open ports.
  • Requires a community string for access.
Key Takeaway

snmpwalk is indispensable for extracting detailed system information from SNMP-enabled devices, provided you can guess or brute-force the community string.

snmpwalk Command Example

Querying a target with the 'public' community string

# Attempt to query with 'public' community string (v1)
snmpwalk -c public -v1 192.168.1.105

# Expected Output Snippet (System Info)
iso.3.6.1.2.1.1.1.0 = STRING: "Linux metasploitable 2.6.24-16-server #1 SMP Thu Apr 10 13:23:42 UTC 2008 i686"
iso.3.6.1.2.1.1.3.0 = TIMETICKS: (132039200) 15 days, 6:46:32.00
iso.3.6.1.2.1.1.4.0 = STRING: "root"
iso.3.6.1.2.1.1.5.0 = STRING: "metasploitable"

Information Revealed

Look for OS versions, uptime, contact info, device names, and running services. This can directly inform your next steps.
