Lightweight Directory Access Protocol (LDAP) Enumeration

Mapping User and Group Information in Directories

What is LDAP?

  • Protocol for accessing distributed directory services.
  • Commonly used in Microsoft Active Directory.
  • Stores user, group, computer, and resource information.

ldapsearch for Queries

  • Command-line utility to query LDAP directories.
  • Requires host (-H) and base DN (-b).
  • Can reveal user lists, group memberships, and organizational data.
Key Takeaway

LDAP enumeration is vital for gathering user and group intelligence in Active Directory environments, often leading to credential-based attacks.

ldapsearch Command Example

Querying an LDAP directory for information

# Basic LDAP search for a domain
ldapsearch -x -H ldap://192.168.1.105 -b "dc=example,dc=com"

# Nmap script for LDAP user enumeration
nmap --script ldap-enum-users.nse -p389 192.168.1.105

# Example: Search for specific user attributes
ldapsearch -x -H ldap://192.168.1.105 -b "dc=example,dc=com" "(cn=John Doe)"

Common Challenge

Guessing the correct Base DN (e.g., dc=target,dc=local) is often required. Start with common patterns or use tools like Nmap for hints.
