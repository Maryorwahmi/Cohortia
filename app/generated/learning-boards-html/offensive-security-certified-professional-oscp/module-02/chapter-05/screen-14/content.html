Key Concepts

Essential Terms to Remember

Vulnerability Scanners

Automated tools (e.g., Nessus, OpenVAS) that identify known vulnerabilities by comparing system configurations against vulnerability databases.

Server Message Block (SMB)

A network file sharing protocol, primarily for Windows, often targeted for enumeration of shares and users due to misconfigurations.

enum4linux

A Linux tool for enumerating data from Windows and Samba hosts via SMB/NBT, automating user, group, and share discovery.

Summary Takeaway

Automated scanners provide breadth, but manual enumeration of protocols like SMB using tools such as enum4linux offers the depth needed for effective penetration testing.
