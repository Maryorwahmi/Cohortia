Targeted Enumeration

Customizing Scans with Specific NSE Scripts

Run individual scripts or categories for highly focused enumeration and vulnerability checks.

Targeted Information Gathering

Use scripts like smb-enum-shares.nse or http-enum to gather specific details about services.

Vulnerability Checks

Run scripts from the vuln category to identify known vulnerabilities on target services.

# Run Specific NSE Script (SMB Shares)
nmap --script smb-enum-shares.nse 192.168.1.105
# Run All Scripts in a Category (Vulnerability)
nmap --script "vuln" 192.168.1.105
# Enumerate Web Server Directories
nmap --script http-enum 192.168.1.105
Key Takeaway

Targeted NSE scripts allow for granular enumeration, focusing on specific services and potential vulnerabilities.
