Example Nmap Output Snippet
PORT     STATE SERVICE 21/tcp   open  ftp 22/tcp   open  ssh 80/tcp   open  http 139/tcp  open  netbios-ssn 445/tcp  open  microsoft-ds 3306/tcp open  mysql 5432/tcp open  postgresql
Open Port

An application is actively listening for connections on this port.

Filtered Port

A firewall or network device is blocking access, state is unknown.

Closed Port

No application is listening on this port, but it is accessible.

Common Mistake

Only scanning the top 1000 ports; many services run on non-standard ports.

Pro Tip

Always save Nmap output (e.g., -oN filename.txt) for documentation and later analysis.

Key Takeaway

Thoroughly interpret Nmap output to understand port states and always document your findings for effective penetration testing.
