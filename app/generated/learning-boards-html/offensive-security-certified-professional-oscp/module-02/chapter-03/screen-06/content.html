What is Traceroute?

traceroute (or tracert on Windows) is a network diagnostic tool that displays the path and measures transit delays of packets across an IP network.

How it Works
  • Sends packets with incrementally increasing Time-To-Live (TTL) values.
  • Each hop (router) decrements TTL and sends an ICMP "Time Exceeded" message.
  • Identifies intermediate routers and network devices.
What it Reveals
  • Network topology and routing paths.
  • Presence of firewalls or security devices.
  • Potential network bottlenecks or latency issues.
Terminal Output: traceroute google.com
traceroute to google.com (142.250.190.142), 30 hops max, 60 byte packets 1  _gateway (192.168.1.1)  0.345 ms  0.321 ms  0.318 ms 2  router.local (10.0.0.1)  1.234 ms  1.189 ms  1.201 ms 3  isp-router.net (72.14.200.1)  5.678 ms  5.701 ms  5.655 ms 4  108.170.247.193 (108.170.247.193)  12.345 ms  12.301 ms  12.389 ms 5  142.250.190.142 (142.250.190.142)  15.678 ms  15.701 ms  15.655 ms
Key Takeaway

traceroute maps the network path, revealing intermediate routers and network topology, which is vital for understanding target infrastructure.
