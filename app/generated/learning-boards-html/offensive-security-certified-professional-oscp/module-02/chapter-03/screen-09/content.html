When Ping Scans Fail

If a target host's firewall blocks ICMP (ping) requests, Nmap's default host discovery might incorrectly report the host as 'down'.

The -Pn Flag (No Ping)
  • Tells Nmap to treat all hosts as online.
  • Skips the host discovery phase entirely.
  • Forces Nmap to proceed directly to port scanning.
Use Cases

Essential when you suspect a host is active but is configured to block ICMP requests, ensuring you don't miss potential targets.

Command: nmap -Pn target.com
Starting Nmap 7.94 ( https://nmap.org ) at 2023-10-25 12:05 EDT Nmap scan report for target.com (192.168.1.105) Host is up (0.00040s latency). Key Takeaway

Use -Pn to force Nmap to scan a target even if it doesn't respond to pings, bypassing ICMP blocking firewalls.
