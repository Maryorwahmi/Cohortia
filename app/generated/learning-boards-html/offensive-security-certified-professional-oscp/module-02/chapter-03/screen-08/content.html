What is Host Discovery?

The process of identifying live hosts on a network before performing more intensive scans. It's the first step in narrowing down your targets.

The -sn Flag (Ping Scan)
  • Performs host discovery only, no port scan.
  • Sends ICMP echo requests, TCP SYN to port 443, and TCP ACK to port 80.
  • Efficient for quickly identifying active hosts across a subnet.
Why it Matters

Focuses subsequent, more intensive scans only on live targets, optimizing time and reducing network noise.

Command: nmap -sn 192.168.1.0/24
