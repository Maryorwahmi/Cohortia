TCP Connect Scan (-sT)

This scan type completes the full TCP three-way handshake (SYN, SYN/ACK, ACK) with the target port.

Trade-offs
  • **Reliability:** More reliable in some restricted network environments.
  • **Stealth:** Less stealthy as it establishes a full connection.
  • **Logging:** More likely to be logged by target systems and applications.
When to Use

Useful when raw packet privileges are unavailable or when SYN scans are blocked, prioritizing reliability over stealth.

Command: nmap -sT 192.168.1.100

Key Takeaway
