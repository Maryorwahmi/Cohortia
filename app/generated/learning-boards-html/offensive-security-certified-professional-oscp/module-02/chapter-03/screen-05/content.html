What is Ping?

ping is a command-line utility used to test the reachability of a host on an Internet Protocol (IP) network.

How it Works
  • Sends ICMP (Internet Control Message Protocol) Echo Request packets.
  • Listens for ICMP Echo Reply packets from the target.
  • Measures round-trip time (latency) and packet loss.
Common Misconception

A lack of ping response does not definitively mean a host is down; firewalls often block ICMP traffic.

Terminal Output: ping 192.168.1.1
PING 192.168.1.1 (192.168.1.1) 56(84) bytes of data.64 bytes from 192.168.1.1: icmp_seq=1 ttl=64 time=0.345 ms64 bytes from 192.168.1.1: icmp_seq=2 ttl=64 time=0.321 ms64 bytes from 192.168.1.1: icmp_seq=3 ttl=64 time=0.318 ms64 bytes from 192.168.1.1: icmp_seq=4 ttl=64 time=0.309 ms--- 192.168.1.1 ping statistics ---4 packets transmitted, 4 received, 0% packet loss, time 3009msrtt min/avg/max/mdev = 0.309/0.323/0.345/0.014 ms
Key Takeaway

ping quickly verifies host reachability, but a lack of response may indicate ICMP blocking, not necessarily an offline host.
