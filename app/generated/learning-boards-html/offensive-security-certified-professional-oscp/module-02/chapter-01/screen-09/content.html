DNS Queries with DIG

Mapping Domain Names to IP Addresses

Another essential tool for passive reconnaissance is `dig`, which stands for Domain Information Groper. This command-line utility is used to query Domain Name System (DNS) servers to obtain domain name related information.

DNS is the internet's phonebook, translating human-readable domain names like `example.com` into machine-readable IP addresses. By using `dig`, we can uncover various types of DNS records that reveal crucial details about a target's infrastructure.

For instance, querying the 'A' record (`dig example.com A`) will provide the primary IP address associated with the domain. Querying the 'MX' record (`dig example.com MX`) reveals the mail exchange servers responsible for handling email for the domain, which can sometimes indicate the email provider or associated services.

Querying the 'NS' record (`dig example.com NS`) shows the authoritative name servers for the domain, pointing us to where its DNS records are managed. Even 'TXT' records can sometimes contain valuable information, such as SPF or DKIM records used for email authentication, or other custom data. These queries help us map out the target's network presence and identify associated services.
