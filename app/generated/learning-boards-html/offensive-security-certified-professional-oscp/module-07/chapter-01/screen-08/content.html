Process and Disk Usage: `ps aux` and `df -h`

Monitoring System Activity and Resources

To gain a comprehensive understanding of the system's state, examining running processes and disk usage is essential. The `ps aux` command provides a snapshot of all running processes on the system, showing details like the user running the process, its PID, CPU and memory usage, and the command itself. Sorting this output, for example, by CPU usage (`ps aux --sort=-%cpu | head -n 10`), can quickly highlight resource-intensive processes. Sometimes, a process running with unusual privileges or one that is misconfigured might be identified here. While not always a direct path to escalation, understanding what's running on the system is fundamental. Equally important is checking disk space and mount points using `df -h`. This command displays the amount of disk space used and available on mounted file systems. While seemingly basic, it can reveal interesting information. For instance, if there are unusual or unexpected mount points, or if certain partitions have very specific permissions, it might warrant further investigation. In some scenarios, weak permissions on mounted drives or specific directories can be leveraged. Always consider how system resources and running services interact, as this interplay can expose vulnerabilities that are not apparent at first glance.

Key Takeaway

Analyzing running processes and disk usage helps identify system vulnerabilities and resource-related misconfigurations.
