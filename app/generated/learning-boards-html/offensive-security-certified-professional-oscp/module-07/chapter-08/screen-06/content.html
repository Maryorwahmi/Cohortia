The `~/.ssh/` Directory

On Linux systems, SSH keys and configuration files are typically found within the ~/.ssh/ directory in a user's home folder. This directory is a prime target for attackers.

id_rsa (Private Key)

The secret key for authentication. Must have strict permissions (chmod 600).

id_rsa.pub (Public Key)

The public counterpart to id_rsa, can be shared.

authorized_keys

Contains public keys authorized to log in as the user.

config

Contains host-specific SSH settings, potentially revealing other targets.

Key Takeaway

Always check the ~/.ssh/ directory for any user you compromise, as it's a treasure trove for further access.
