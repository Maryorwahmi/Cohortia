01

Identify SSH Key Locations

Locate common directories and files for SSH keys and configurations on Linux systems. This skill is foundational for discovering potential misconfigurations that can lead to unauthorized access.

VERIFIED COMPETENCY MILESTONE
02

Exploit Weak SSH Key Permissions

Understand and execute the process of exploiting weakly permissioned SSH private keys. This involves copying the key and using it to authenticate as the victim user, demonstrating a direct path to unauthorized access.
