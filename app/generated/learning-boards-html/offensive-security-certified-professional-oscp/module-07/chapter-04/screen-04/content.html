Core Concept

Linux Capabilities: Granular Privileges

Moving beyond traditional SUID permissions for fine-grained control.

What are Capabilities?

Capabilities are a partitioning of the privileges available to the root user into distinct units. This allows a process to be granted only the specific privileges it needs, rather than all of root's power.

  • •**Reduced Attack Surface:** A compromised program with limited capabilities cannot perform arbitrary root actions.
  • •**Fine-Grained Control:** Specific privileges like `CAP_NET_RAW` (raw sockets) or `CAP_CHOWN` (change file ownership) can be granted independently.
  • •**Modern Security:** A significant improvement over the all-or-nothing approach of SUID binaries.
Key Takeaway

Capabilities enhance security by limiting privileged processes to only necessary actions, but misconfigurations remain a risk.

Capability vs. SUID Model

SUID Bit
All of root's powers
Linux Capabilities
Specific, fine-grained privileges

Example: `ping` Utility

The `ping` command needs to create raw network sockets. Instead of running as root, it's granted the `CAP_NET_RAW` capability, allowing it to perform this specific task without full root privileges.
