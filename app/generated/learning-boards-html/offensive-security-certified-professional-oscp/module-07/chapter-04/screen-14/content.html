Key Concepts: Capabilities & `sudo`

Essential takeaways from this chapter.

Linux Capabilities

A granular permission model assigning specific privileges to processes, improving security over SUID.

`getcap` & `sudo`

`getcap` lists capabilities; `sudo` allows privileged command execution based on `/etc/sudoers`.

`sudo -l` & `NOPASSWD`

`sudo -l` reveals allowed commands; `NOPASSWD` entries enable passwordless root command execution.

Summary Takeaway

Mastering the identification and exploitation of Linux capabilities and `sudo` misconfigurations is crucial for effective privilege escalation in offensive security.
