Identifying Capabilities with `getcap`

Scanning the filesystem for binaries with elevated privileges.

How to Use `getcap`

The `getcap` command is used to list file capabilities. The `-r` flag performs a recursive scan from a specified directory.

getcap -r / 2>/dev/null
  • •**`-r /`**: Recursively scan from the root directory.
  • •**`2>/dev/null`**: Redirects standard error to `/dev/null` to suppress permission denied messages.
Key Takeaway

`getcap -r /` is essential for discovering binaries with capabilities, which can then be researched for privilege escalation paths.

Interpreting `getcap` Output

/usr/bin/python = cap_net_raw+ep

`cap_net_raw`

Allows creating raw network sockets, useful for tools like `ping` or `nmap`.

`+ep`

Indicates the capability is both 'effective' (currently active) and 'permitted' (allowed to be effective).

Common Mistake: Ignoring `+ep`

Just seeing a capability isn't enough; ensure it's `+ep` to confirm it's active and usable for exploitation.
