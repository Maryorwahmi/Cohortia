Capability Deep Dive

Understanding Key Capability Types

Assessing the privilege escalation potential of specific capabilities.

High-Impact Capabilities

Certain capabilities, if misconfigured, pose significant privilege escalation risks due to the powerful actions they permit.

  • •**`CAP_SYS_PTRACE`**: Allows tracing arbitrary processes. Can be used to inject code into root processes.
  • •**`CAP_DAC_OVERRIDE`**: Bypasses file read/write/execute permissions. Grants access to any file.
  • •**`CAP_SETUID`/`CAP_SETGID`**: Allows changing process user/group IDs. Can be used to become root.
Key Takeaway

Identifying and understanding the implications of powerful capabilities is crucial for leveraging them in privilege escalation.

Exploitation Workflow

1. Identify Capabilities (`getcap`)
2. Understand Capability Impact
3. Consult GTFOBins / Exploit Guides

Pro-Tip: Context is Key

A capability's danger depends on the binary it's assigned to. A `CAP_NET_RAW` on `ping` is normal; on `bash`, it's a critical vulnerability.
