`NOPASSWD` Entries: Direct Command Execution

Leveraging passwordless `sudo` commands for privilege escalation.

What `NOPASSWD` Means

The `NOPASSWD` directive allows a user to execute a specified command as root without requiring a password.

(ALL) NOPASSWD: /usr/bin/apt
  • •**Direct Access:** If the command can spawn a shell, it's an immediate root shell.
  • •**Common Binaries:** Look for `vim`, `less`, `more`, `find`, `nmap`, `perl`, `python`, `bash`, `sh`.
Key Takeaway

`NOPASSWD` for shell-spawning binaries is a critical vulnerability leading to direct root access.

Exploiting `NOPASSWD` with `vim`

If `vim` is allowed with `NOPASSWD`, you can use its internal command execution feature.

sudo vim -c ':!/bin/sh'

Explanation

The `-c` flag executes a `vim` command. `:!/bin/sh` tells `vim` to run `/bin/sh` as an external command, inheriting `sudo`'s root privileges.

Pro-Tip: GTFOBins

Always consult GTFOBins (gtfobins.github.io) for specific shell escape commands for various binaries.
