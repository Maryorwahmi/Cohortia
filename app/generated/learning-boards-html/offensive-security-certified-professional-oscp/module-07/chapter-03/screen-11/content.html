Module 7›Chapter 7.3›Avoiding Pitfalls
Ignoring Permissions

An SUID bit doesn't guarantee exploitability. The binary must allow command execution or file manipulation.

Blindly Running Exploits

Always understand the 'why' behind an exploit before attempting it. Copy-pasting without comprehension is risky.

Environment Variables

SUID binaries often sanitize the environment, making `PATH` or `LD_PRELOAD` manipulation ineffective.

Destructive Actions

Overwriting critical system files can render a system unusable. Restrict such actions to isolated lab environments.

SUID vs. 'sudo'

These are distinct mechanisms. 'sudo' is configured via /etc/sudoers, while SUID is a file permission. Don't confuse them.

The 'pkexec' Gateway

While not strictly SUID, 'pkexec' (PolicyKit) often acts as a gateway to elevated privileges, as seen with the PwnKit vulnerability.

Key Takeaway

Effective SUID/SGID exploitation requires careful analysis, understanding of limitations, and adherence to ethical guidelines, especially regarding destructive actions and environment manipulation.
