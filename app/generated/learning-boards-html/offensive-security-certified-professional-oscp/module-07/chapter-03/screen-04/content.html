SUID (Set User ID) Bit

When an executable has the SUID bit set, it runs with the permissions of the file's owner, not the user executing it.

User executes binaryBinary runs as owner

SGID (Set Group ID) Bit

When an executable has the SGID bit set, it runs with the permissions of the file's group owner, not the user's primary group.

User executes binaryBinary runs as group

Why They Matter for Security

  • Privilege Elevation: Allows low-privileged users to execute specific tasks requiring higher permissions.
  • Critical System Functions: Essential for utilities like passwd to modify root-owned files.
  • Exploitation Risk: Poorly written or configured SUID/SGID binaries can be manipulated to execute arbitrary commands with elevated privileges.
  • Attack Vector: A primary target for attackers seeking to escalate privileges from a compromised user account to root.
Key Takeaway

SUID/SGID bits are powerful but dangerous; they enable necessary system functions but also create significant privilege escalation opportunities if vulnerabilities exist.
