Understanding 'find' Permissions

  • -perm -4000: Searches for files with the SUID bit set. The '4' represents SUID in octal.
  • -perm -2000: Searches for files with the SGID bit set. The '2' represents SGID in octal.
  • -perm /u=s,g=s: A more readable way to find files with either SUID or SGID set.
  • -type f: Ensures only regular files are returned, excluding directories.
  • 2>/dev/null: Redirects standard error to null, suppressing 'Permission denied' messages.
Key Takeaway

Mastering 'find' commands with permission flags is essential for quickly and effectively identifying SUID/SGID binaries, a critical first step in privilege escalation.

Terminal Command Examples
# Find all SUID binaries
find / -perm -4000 -type f 2>/dev/null

# Find all SGID binaries
find / -perm -2000 -type f 2>/dev/null

# Find both SUID and SGID binaries
find / -perm /u=s,g=s -type f 2>/dev/null

# Example output snippet
/usr/bin/sudo
/usr/bin/passwd
/usr/bin/chfn
/usr/bin/chsh
/usr/bin/mount
/usr/bin/umount
/usr/bin/newgrp
Pro Tip: Suppress Errors

Always use 2>/dev/null with find commands to avoid overwhelming your terminal with 'Permission denied' errors, making the output much cleaner and easier to parse.
