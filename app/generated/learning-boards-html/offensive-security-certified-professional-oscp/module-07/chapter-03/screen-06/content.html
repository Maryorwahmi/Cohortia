Legitimate SUID/SGID Binaries

  • /usr/bin/passwd: Allows users to change their password by writing to /etc/shadow as root.
  • /usr/bin/sudo: Enables specific users to run commands as other users (often root) based on sudoers configuration.
  • /usr/bin/ping: Needs raw socket access to send ICMP packets, which requires root privileges.
  • /usr/bin/mount/umount: Allows non-root users to mount/unmount filesystems as configured.

These are generally secure and not directly exploitable.

Potentially Exploitable Binaries

  • Unusual/Custom Binaries: Any non-standard SUID/SGID program is a high-priority target.
  • Known Vulnerabilities: Standard utilities with specific versions that have documented exploits (e.g., older nmap, find, vim).
  • Misconfigurations: Binaries that allow arbitrary command execution or file manipulation when run with elevated privileges.

These require deeper investigation for privilege escalation paths.

Leveraging GTFOBins

GTFOBins (gtfobins.github.io) is an invaluable resource that lists Unix binaries that can be exploited by attackers to bypass local security restrictions.

Provides clear instructions for privilege escalation.
Example: SUID Nmap
# If nmap is SUID, GTFOBins suggests:
nmap --interactive
nmap> !sh
# This drops you into a root shell
Key Takeaway

Thorough analysis, combined with resources like GTFOBins, is crucial to differentiate between benign SUID/SGID binaries and those that offer viable privilege escalation paths.
