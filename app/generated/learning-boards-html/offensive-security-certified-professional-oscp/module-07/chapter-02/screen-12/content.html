Execution Phase

Executing and Gaining Root

Make the exploit executable and run it to achieve a root shell.

target@victim:~$ chmod +x /tmp/dirtycow
target@victim:~$ /tmp/dirtycow
root@victim:/# whoamiroot
Key Takeaway
Grant executable permissions with chmod +x and then run the exploit using its full path or ./ prefix to achieve a root shell.
Granting Executable Permissions
Linux security requires files to have executable permissions before they can be run. The chmod +x <filename> command grants these permissions, making your exploit runnable.
Running the Exploit
Execute the exploit using ./<exploit_name>. The ./ tells the shell to look for the executable in the current directory. A successful exploit typically results in a root shell.
Execution Pitfall
Forgetting the ./ prefix or not specifying the full path to the exploit can lead to a 'command not found' error, even if the file is present and executable.
