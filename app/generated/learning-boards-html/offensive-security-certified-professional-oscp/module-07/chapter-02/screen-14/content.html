Classic Kernel Vulnerabilities: Dirty COW and PwnKit

Explore two prominent kernel-level flaws that enabled widespread privilege escalation.

Dirty COW (CVE-2016-5195)

A Linux kernel vulnerability allowing local privilege escalation by modifying read-only memory. Attackers could overwrite sensitive files (e.g., /etc/passwd) to gain root access.

Kernel Memory Manipulation

PwnKit (CVE-2021-4034)

A memory corruption vulnerability in the pkexec utility, allowing a local attacker to gain root privileges. This flaw was present in a widely used system program.

System Utility Exploitation

Impact of Dirty COW

Dirty COW allowed attackers to gain write access to read-only memory, which could be used to modify critical system files or inject malicious code into running processes, leading to root.

Impact of PwnKit

PwnKit's memory corruption in pkexec, a program designed to execute commands as another user (often root), provided a straightforward path for local users to escalate privileges to root.

Key Takeaway

Both Dirty COW and PwnKit demonstrate how critical vulnerabilities, whether in the kernel or core system utilities, can be exploited to achieve full root access, emphasizing the need for constant patching.
