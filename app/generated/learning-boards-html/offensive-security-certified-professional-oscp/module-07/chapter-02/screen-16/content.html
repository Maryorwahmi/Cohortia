Chapter Review

Key Concepts (Continued)

Further reinforce your understanding of advanced terms and vulnerabilities.

Cross-compilation

Compiling code on one architecture/OS for execution on a different architecture/OS, useful when the target lacks a compiler.

Dirty COW (CVE-2016-5195)

A well-known Linux kernel vulnerability allowing local privilege escalation by modifying read-only memory.

PwnKit (CVE-2021-4034)

A memory corruption vulnerability in pkexec that allows local privilege escalation to root.

Summary Takeaway

Cross-compilation is a key technique, while Dirty COW and PwnKit are landmark vulnerabilities illustrating the severe impact of kernel and system utility flaws.
