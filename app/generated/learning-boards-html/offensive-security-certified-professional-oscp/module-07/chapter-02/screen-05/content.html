Identifying Vulnerable Kernel Versions

Use uname -a and /proc/version to pinpoint target kernel details.

kali@attacker:~$ uname -a
Linux target-vm 4.4.0-116-generic #139-Ubuntu SMP Mon Feb 19 14:04:09 UTC 2018 x86_64 x86_64 x86_64 GNU/Linux
kali@attacker:~$ cat /proc/version
Linux version 4.4.0-116-generic (buildd@lcy01-amd64-02) (gcc version 5.4.0 20160609 (Ubuntu 5.4.0-6ubuntu1~16.04.9) ) #139-Ubuntu SMP Mon Feb 19 14:04:09 UTC 2018
Key Takeaway

The output of uname -a provides the critical kernel version string needed for exploit searching. Always cross-reference with other system info.

Understanding `uname -a`

This command displays comprehensive system information, including the kernel name, release, version, and architecture. The kernel version string is the most important piece for exploit matching.

`cat /proc/version` Insights

This file often reveals the kernel version, build date, and the GCC compiler version used. It can provide additional context or confirm details from uname -a.

Common Mistake

Relying solely on the kernel version without confirming the distribution (e.g., Ubuntu, Debian) can lead to using incompatible exploits and system instability.
