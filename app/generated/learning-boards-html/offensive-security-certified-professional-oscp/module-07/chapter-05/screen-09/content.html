Exploiting Writable Cron Scripts

Injecting Malicious Payloads for Root Access

The Core Idea

If a cron job runs as a privileged user (e.g., root) and its script is writable by your low-privileged user, you can modify the script to execute your own commands with elevated privileges.

Important Safety Note

Always append your payload to the script, rather than overwriting it. Overwriting can break legitimate system functions and alert administrators.

Key Takeaway

Writable cron scripts offer a direct and powerful path to privilege escalation by allowing direct injection of malicious commands.

Steps to Exploit Writable Scripts

1

Check Permissions

Use ls -l /path/to/script.sh to confirm write permissions for your user.

2

Append Malicious Command

Add your payload (e.g., SUID binary or reverse shell) to the end of the script.

3

Wait for Execution

The cron job will execute your command with its privileges on its next scheduled run.

4

Gain Elevated Shell

Access your root shell (e.g., /bin/bash -p or catch reverse shell).
