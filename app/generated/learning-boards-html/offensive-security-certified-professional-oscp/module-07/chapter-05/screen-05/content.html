Key System Cron Locations

/etc/crontab

The main system crontab file. Explicitly defines the user for each job.

/etc/cron.d/

Directory for individual cron files, often used by installed applications.

/etc/cron.hourly/

Scripts in this directory run once every hour.

/etc/cron.daily/

Scripts in this directory run once every day.

/etc/cron.weekly/

Scripts in this directory run once every week.

/etc/cron.monthly/

Scripts in this directory run once every month.

Example: Listing /etc/cron.d/ contents

ls -la /etc/cron.d/

This command reveals individual cron job files that might be running privileged tasks.

Where to Find Global Scheduled Tasks

Why Check These?

These locations often contain jobs executed by the root user, making them prime targets for privilege escalation if their scripts or directories are writable by a low-privileged user.

Key Information to Extract

  • User executing the job (often root).
  • Full path to the script or command.
  • Frequency of execution.
Key Takeaway

Thoroughly examine all system-wide cron locations for jobs running as privileged users, as these are common vectors for privilege escalation.
