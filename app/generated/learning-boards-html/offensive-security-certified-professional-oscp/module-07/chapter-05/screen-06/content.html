Viewing User Crontabs

Command: crontab -l

crontab -l

Displays the cron jobs scheduled for the currently logged-in user.

Storage Location

/var/spool/cron/crontabs/<username>

Each user's crontab is stored as a file named after their username in this directory.

Example: Root's Crontab

cat /var/spool/cron/crontabs/root

This command would show the cron jobs scheduled to run as the root user, if you have sufficient permissions to read it.

Checking Individual User Schedules

Why They Are Important

Even if not running as root, user cron jobs can be part of a privilege escalation chain if they execute scripts with insecure permissions or use commands vulnerable to PATH manipulation.

Key Considerations

  • Always check `crontab -l` for your current user.
  • Look for scripts with weak permissions.
  • Identify commands called without full paths.
Key Takeaway

User crontabs are a vital part of cron job enumeration; never assume only system-wide jobs are exploitable.
