What are .so Files?

Shared Object files are dynamically linked libraries containing code that programs load at runtime.

Dynamic Loading

Programs don't include all code directly; they load shared libraries as needed, often at startup.

The _init Function

A special constructor function within a shared library that executes automatically when the library is loaded.

Exploitation Goal

Replace a legitimate, writable .so with a malicious one to execute code with the privileges of the loading process.

Key Takeaway

Exploiting writable shared libraries allows for dynamic code injection, where malicious code runs with the privileges of the calling process upon library load.
