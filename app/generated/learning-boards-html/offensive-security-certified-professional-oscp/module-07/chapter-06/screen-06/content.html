# Find world-writable directories
find / -writable -type d 2>/dev/null
# Find files owned by root but writable by your group
find / -user root -perm -g+w -type f 2>/dev/null
# Find files owned by root but writable by others
find / -user root -perm -o+w -type f 2>/dev/null

Filtering with grep

Pipe the output to grep to search for specific keywords like "passwd" or "shadow" to quickly identify critical files.

find / -writable -type f 2>/dev/null | grep "passwd"

Why Writable Directories Matter

A writable directory allows you to create new files, replace existing ones, or even plant malicious scripts that a privileged process might later execute.

Root-Owned, User-Writable

These files are particularly dangerous. If a file is owned by root but writable by your user or group, you can modify it, and any process that executes it as root will then run your malicious code.

Key Takeaway

Always expand your search beyond simple world-writable files to include directories and files with specific owner/group writable permissions for a complete picture.
