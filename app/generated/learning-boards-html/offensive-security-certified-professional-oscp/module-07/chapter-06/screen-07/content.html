Module 7›Chapter 7.6›Hijacking User Accounts
# Add a new root user 'newroot' with an empty password
echo "newroot::0:0:newroot:/root:/bin/bash" >> /etc/passwd
# Then simply 'su newroot' and you're root.
su newroot

/etc/passwd Structure

Contains user account details: username:password_hash:UID:GID:comment:home_dir:shell. A '0' for UID grants root privileges.

Empty Password Hash

The second field, normally for the password hash, is left empty (::) allowing login without a password.

The Vulnerability

If /etc/passwd is writable by a low-privileged user, they can append new user entries or modify existing ones, effectively creating a backdoor for root access.

Immediate Root Access

By adding a user with UID 0, the system treats this new user as root, allowing direct privilege escalation via su.

Safety Note

Incorrectly modifying /etc/passwd can break user authentication and lock everyone out of the system. Only perform this in controlled lab environments.
