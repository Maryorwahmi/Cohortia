Discovering NFS Shares on a Server

Using cat /etc/exports to reveal configurations.

The `/etc/exports` File

This file defines which directories an NFS server exports, to which clients, and with what specific options. It's the primary configuration source for NFS shares.

What to Look For

  • Exported Directories: The paths being shared.
  • Client Access: Specific IPs, networks, or `*` (all clients).
  • Options: Permissions like `rw` (read/write), `ro` (read-only), `sync`, `no_subtree_check`, and critically, `no_root_squash`.
Key Takeaway

Always check /etc/exports on a compromised Linux target to identify NFS shares and their associated security settings.

Terminal: Target Server
user@target:~$ cat /etc/exports
/home/shared_data 192.168.1.0/24(rw,sync,no_subtree_check)
/var/www/html *(ro,sync)
/opt/backups 10.0.0.0/8(rw,no_root_squash)

Explanation:

  • /home/shared_data is shared with the 192.168.1.0/24 network, allowing read/write access.
  • /var/www/html is shared with all clients (*) but is read-only.
  • /opt/backups is shared with the 10.0.0.0/8 network and includes the dangerous no_root_squash option.
