Security Mechanism

Understanding root_squash

Preventing client-side root from gaining server-side root.

Default & Secure Behavior

root_squash is the default NFS option. It maps client-side root users (UID 0) to an unprivileged user (e.g., nobody) on the NFS server.

Why It Matters

  • Privilege Separation: Ensures a compromised client root doesn't automatically become server root.
  • Defense-in-Depth: Adds a layer of security, limiting the impact of client-side breaches.
  • Standard Practice: Essential for secure NFS deployments.
Key Takeaway

root_squash is a critical security feature that prevents client-side root users from exercising root privileges on the NFS server, mitigating privilege escalation.

How `root_squash` Works

Attempts access

NFS Server

Server Nobody (UID 65534)

root_squash ensures that even if a client connects as root, their privileges are downgraded on the server, preventing unauthorized root access to shared files.
