Key Concepts

Critical security aspects and exploitation techniques.

`root_squash`

The default NFS option that maps client-side root users to an unprivileged user on the server, preventing root access.

`no_root_squash`

A dangerous NFS option that allows client-side root users to retain root privileges on the mounted share on the server.

`nosuid` / `noexec`

Mount options that prevent SUID bits from taking effect or binaries from being executed on a mounted file system, respectively.

Summary Takeaway

Understanding the distinction between root_squash and no_root_squash is paramount for NFS security. Always check for defensive mount options like nosuid and noexec.
