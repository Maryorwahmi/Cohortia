Key Concepts

Essential terms and ideas to remember.

NFS (Network File System)

A distributed file system protocol allowing remote access to files over a network as if they were local.

`/etc/exports`

The configuration file on an NFS server that defines which directories are exported and to whom.

`showmount -e`

A command-line utility to query an NFS server for its exported directories from an attacking machine.

Summary Takeaway

NFS facilitates shared storage, but its configuration, particularly in /etc/exports, must be carefully reviewed. Tools like showmount -e are essential for discovering potential vulnerabilities.
