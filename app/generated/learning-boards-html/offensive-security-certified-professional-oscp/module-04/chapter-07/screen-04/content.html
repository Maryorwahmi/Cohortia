What is msfvenom?

msfvenom is a command-line utility within the Metasploit Framework used to generate payloads (shellcode) in various formats for different architectures and platforms. It's your primary tool for crafting the malicious code that will execute on the target.

Key Function

Creates custom payloads for diverse architectures and operating systems, including reverse and bind shells.

Reverse Shell

Target initiates connection back to attacker, often bypassing egress firewalls. Preferred for most buffer overflows.

Bind Shell

Target opens a listening port; attacker connects to it. Can be blocked by ingress firewalls.
