Component Breakdown

TARGET_IP / TARGET_PORT

Network address and service port of the vulnerable application.

OFFSET

Number of bytes to fill the buffer before reaching the EIP overwrite.

RETN (JMP ESP)

Memory address of a JMP ESP instruction, in little-endian format.

NOP_SLED

A sequence of 0x90 (No Operation) instructions creating a 'landing zone' for shellcode.

Key Takeaway

Each variable must be precisely defined based on your prior analysis to ensure the exploit functions correctly.
