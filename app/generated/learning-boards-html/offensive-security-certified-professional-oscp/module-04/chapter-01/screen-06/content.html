Dynamic Memory

The Stack: Function Calls and Local Data

A LIFO Structure for Execution Context

LIFO Principle

The stack operates on a Last-In, First-Out (LIFO) basis. The last item pushed onto the stack is the first one to be popped off, similar to a stack of plates.

Stack Frames

When a function is called, a new 'stack frame' is pushed. It contains local variables, function parameters, and the crucial return address, which dictates where execution resumes.

Return Address

This is a memory address stored within a stack frame, indicating the instruction pointer's location for the program to return to after the current function completes. Overwriting this is a common exploit target.

Stack Behavior

  • **Growth Direction:** Typically grows downwards in memory addresses (towards lower addresses).
  • **Automatic Management:** Memory is automatically allocated and deallocated as functions are called and return.
  • **Local Scope:** Primarily used for data with a limited lifetime, tied to function execution.
  • **Predictable Structure:** Its organized nature makes it a common target for buffer overflows.
Key Takeaway

The stack is a LIFO memory region crucial for function execution, managing local data and return addresses. Its predictable, downward growth makes it a primary target for buffer overflows, as overwriting the return address can hijack program control.
