Heap-Based Buffer Overflows: A Brief Introduction

More Complex, Less Predictable Targets

Heap Overflow Definition

Occurs when a program writes data beyond the allocated boundary of a dynamically allocated buffer on the heap, corrupting adjacent heap data or metadata.

Complexity & Predictability

Exploiting heap overflows is generally more complex due to the heap's less predictable structure and dynamic allocation patterns, making direct EIP control harder.

Targeting Heap Metadata

Exploits often involve corrupting internal heap metadata or adjacent data structures to achieve arbitrary writes or eventually code execution, rather than directly overwriting a return address.

Key Differences from Stack Overflows

  • **Memory Region:** Heap vs. Stack.
  • **Allocation:** Dynamic (malloc) vs. automatic (function calls).
  • **Growth:** Upwards vs. downwards.
  • **Exploit Focus:** Metadata corruption vs. return address overwrite.
  • **OSCP Focus:** Stack-based overflows are the primary focus for the OSCP.
Key Takeaway

Heap-based buffer overflows involve corrupting dynamically allocated memory, often targeting heap metadata. They are more complex to exploit than stack overflows due to the heap's less predictable structure, requiring different techniques to achieve control.
