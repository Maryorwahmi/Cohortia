Memory Architecture

Program Memory Layout: Static Segments

Understanding Where Code and Global Data Reside

Text Segment (Code)

Stores the compiled machine code instructions of the program. It's typically read-only to prevent unauthorized modification of the program's logic, enhancing security.

Data Segment

Holds global and static variables that are initialized before the main() function is called. These variables have a fixed value at program startup.

BSS Segment

Contains uninitialized global and static variables. The operating system ensures these variables are zero-initialized before the program begins execution, providing a clean slate.

Why This Matters

  • **Security:** Read-only text segment protects against code injection.
  • **Predictability:** Global variables have known locations and initial states.
  • **Foundation:** These segments form the immutable or pre-defined parts of a program's memory.
  • **Exploit Context:** Understanding these helps differentiate from dynamic memory targets.
Key Takeaway

Static memory segments (text, data, BSS) house the program's instructions and global variables, providing a stable, often read-only, foundation for execution. Their fixed nature contrasts with dynamic memory, which is crucial for understanding buffer overflows.
