Key Concepts

What to remember from this chapter

Padding

The 'A's or other filler bytes sent before the EIP overwrite to fill the buffer up to the return address location.

Little-endian

A byte order where the least significant byte is stored at the lowest memory address (common in Windows).

Big-endian

A byte order where the most significant byte is stored at the lowest memory address (common in network protocols).

Summary Takeaway

Padding and understanding endianness are vital for precisely controlling EIP and crafting robust buffer overflow exploits.
