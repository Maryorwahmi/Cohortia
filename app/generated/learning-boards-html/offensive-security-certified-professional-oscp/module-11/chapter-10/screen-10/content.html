Persistence Analysis

Identifying Persistence Mechanisms with PowerShell

Using check_persistence.ps1 for forensic insights into attacker footholds.

function Check-Persistence {
    Write-Host "--- Checking Run Registry Keys ---"
    Get-ItemProperty HKLM:\Software\Microsoft\Windows\CurrentVersion\Run | Format-List
    Get-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run | Format-List
    Write-Host "`n--- Checking Startup Folders ---"
    Get-ChildItem "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\Startup"
    Get-ChildItem "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup"
    Write-Host "`n--- Checking Services (Auto-start) ---"
    Get-Service | Where-Object {$_.StartType -eq "Auto"} | Select-Object Name,DisplayName,Status,BinaryPathName | Format-Table -AutoSize
}
Check-Persistence

Registry Run Keys

The script queries HKLM and HKCU Run keys, common locations for programs to launch automatically at user login or system startup.

Startup Folders

It checks both global (ProgramData) and user-specific (APPDATA) Startup folders for malicious executables or scripts.

Auto-Start Services

The script identifies services configured to start automatically, a common and powerful method for attackers to maintain persistent access to a system.

Key Takeaway

Automated PowerShell persistence checks are vital for quickly uncovering attacker footholds and understanding how they maintain access on Windows systems.
