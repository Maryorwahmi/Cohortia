Key Concepts

Essential terms and ideas to remember from this chapter.

Advanced Persistence

Sophisticated techniques used to maintain long-term, stealthy access to a compromised system.

Windows Services

Programs that run in the background on Windows, often with high privileges, and can be configured to start automatically.

sc.exe

(Windows) Service Control command-line utility for creating, modifying, and deleting services.

Summary Takeaway

Advanced persistence leverages deep OS knowledge to establish covert, long-term access, often through Windows services managed by sc.exe.
