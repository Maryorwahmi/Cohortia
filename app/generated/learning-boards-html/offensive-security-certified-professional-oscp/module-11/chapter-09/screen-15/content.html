Key Concepts (Continued)

More essential terms and ideas to remember from this chapter.

WMI Event Subscriptions

(Windows) A powerful and stealthy persistence mechanism that uses WMI to trigger actions based on system events.

systemd units

(Linux) Configuration files that define services, mounts, sockets, and other system resources managed by the systemd init system.

Rootkit

A collection of software tools designed to enable continued privileged access to a computer while actively hiding its presence from administrators.

Summary Takeaway

WMI, systemd, and rootkits represent advanced, stealthy, and resilient persistence mechanisms that require deep OS understanding to implement and detect.
