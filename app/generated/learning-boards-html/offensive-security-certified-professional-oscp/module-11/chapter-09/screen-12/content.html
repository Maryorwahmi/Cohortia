Concealing Malicious Activity

Methods for hiding processes, files, and kernel modules.

Why Hide?

  • Evade Detection: Prevent discovery by system administrators and security tools.
  • Maintain Access: Ensure long-term persistence by remaining covert.
  • Bypass Monitoring: Avoid logging and auditing mechanisms.
  • Increase Operational Security: Reduce the attacker's footprint on the system.
Key Takeaway

Effective concealment involves manipulating OS internals to make malicious processes, files, and modules invisible to standard detection methods.

Hiding Mechanisms

Process Hiding
  • Unlinking from process lists (kernel-mode).
  • ptrace manipulation for visibility.
File Hiding
  • Modifying directory listing functions.
  • Alternate Data Streams (ADS) on NTFS.
Module Hiding (Linux)
  • Unlinking malicious kernel modules.
  • Removes module from kernel's loaded list.

Alternate Data Streams (ADS) Example

On Windows, you can hide data within an existing file using ADS. For instance, echo "I am hidden!" > legitfile.txt:hidden.txt creates a hidden stream named hidden.txt associated with legitfile.txt, which is not visible in normal directory listings.
