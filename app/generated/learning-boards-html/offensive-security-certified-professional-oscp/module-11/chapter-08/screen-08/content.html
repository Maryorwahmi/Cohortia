IIS Logs: Web Server Activity

Located typically in C:\inetpub\logs\LogFiles\, these text files record all web server access and errors. They can be edited or deleted, but complete removal leaves a suspicious gap.

Action

Edit specific entries or delete the log file (with caution).

Recycle Bin: Deleted Files

Found at C:\$Recycle.Bin\, this stores files deleted via the standard 'Delete' option, making them recoverable. Ensure permanent removal.

Action

Bypass Recycle Bin for sensitive files or empty it securely.

Prefetch Files: Program Execution

Located in C:\Windows\Prefetch\, these track program execution to speed up startup. Deleting them removes evidence of tools run.

Action

Delete specific Prefetch files related to attacker tools.

Key Takeaway

Beyond Event Logs, IIS logs, Prefetch files, and the Recycle Bin are crucial Windows artifacts that must be addressed for thorough anti-forensics.
