# Download sdelete.exe (Sysinternals)
# From Microsoft Sysinternals website or via PowerShell Gallery
# Conceptual Command: Securely Delete a File
sdelete.exe -p 3 C:\Path\To\sensitive_data.txt
# Overwrites 'sensitive_data.txt' 3 times before deletion.
# Conceptual Command: Securely Wipe Free Space
sdelete.exe -z C:
# Wipes free space on the C: drive to prevent recovery of previously deleted files.
# Explanation of sdelete options:
-p N: Specifies the number of overwrite passes.
-z: Zero free space (for volumes).
Standard Deletion Flaw

Windows `del` command only removes file pointers, leaving data recoverable by forensic tools until overwritten.

`sdelete.exe` Benefits

Provides robust, multi-pass overwriting for files and free space, making data recovery extremely difficult or impossible.

Key Takeaway

`sdelete.exe` is the essential Windows tool for secure deletion, ensuring sensitive data is permanently erased and unrecoverable.
