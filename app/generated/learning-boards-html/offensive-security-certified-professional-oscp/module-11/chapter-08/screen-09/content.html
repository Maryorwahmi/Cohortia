# Create Dummy Malicious File & Reference File
echo "Malicious content" > evil_script.sh
touch -t 200001010000.00 reference_file.txt  # Sets reference to Jan 1, 2000
# Check Initial Timestamps of evil_script.sh
stat evil_script.sh
# Output will show current access, modify, change times.
# Modify evil_script.sh Timestamps to Match reference_file.txt
touch -r reference_file.txt evil_script.sh
# Verify Modified Timestamps
stat evil_script.sh
# Output: Access, Modify, Change times should now reflect reference_file.txt (Jan 1, 2000).
File Timestamps Explained
  • atime: Last access time (read).
  • mtime: Last modification time (content changed).
  • ctime: Last change time (metadata changed).

These are crucial for forensic timelines.

`touch -r` for Stealth

The -r option allows you to copy timestamps from a legitimate file, making your malicious file appear to be part of the system's history.

Key Takeaway

`touch -r` on Linux is a powerful timestomping technique to obscure the true creation or modification time of files, hindering forensic analysis.
