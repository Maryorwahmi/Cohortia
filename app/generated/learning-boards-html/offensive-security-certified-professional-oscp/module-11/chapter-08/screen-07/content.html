# Accessing Event Viewer
eventvwr.msc
# Clearing Event Logs with wevtutil.exe
wevtutil cl System
wevtutil cl Security
wevtutil cl Application
wevtutil cl "Windows PowerShell"
# Clearing Event Logs with PowerShell
Clear-WinEvent -LogName Security
Clear-WinEvent -LogName System
Clear-WinEvent -LogName Application
# Important Note on Selective Editing
# Selective editing of Windows Event Logs is highly complex and risky.
# It often involves exporting, editing, and re-importing, which can corrupt logs.
# Generally, clearing entire logs is more practical in pentesting, with authorization.
Key Windows Event Logs
  • Security: Logon/logoff, privilege use, object access.
  • System: Device drivers, system components.
  • Application: Events logged by applications.
  • PowerShell: PowerShell command execution.
Risk of Corruption

Attempting to surgically remove specific entries from Windows Event Logs can easily lead to log corruption, making the tampering obvious.

Key Takeaway

`wevtutil.exe` and `Clear-WinEvent` are primary tools for clearing Windows Event Logs, but selective editing is generally impractical and risky.
