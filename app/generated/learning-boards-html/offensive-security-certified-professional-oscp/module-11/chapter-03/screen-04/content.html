Core Concept

What is Network Pivoting?

Using a compromised host as an intermediary to access otherwise inaccessible network segments.

The Strategic Advantage

  • Extends reach from DMZ to internal networks.
  • Bypasses direct firewall restrictions.
  • Enables discovery and exploitation of internal hosts.
  • Transforms a compromised host into a 'jump box'.

Scenario: DMZ to Internal

You've compromised a web server in the DMZ. This server can reach the internal corporate network, but your attacker machine cannot. Pivoting uses the DMZ server as a bridge to access internal resources.

Key Takeaway

Pivoting is essential for lateral movement and accessing high-value targets within segmented networks.
