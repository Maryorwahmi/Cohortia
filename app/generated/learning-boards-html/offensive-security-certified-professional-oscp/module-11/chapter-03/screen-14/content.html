Key Concepts: Pivoting & Forwarding

Reinforce your understanding of the essential terms and techniques.

Network Pivoting

Using a compromised host as an intermediary to access otherwise unreachable network segments.

Port Forwarding

Redirecting network traffic from one port to another, potentially on a different machine, to bypass restrictions.

Local Port Forwarding (-L)

SSH feature to forward a local port on the attacker's machine to a port on a remote destination, via the jump host.

Remote Port Forwarding (-R)

SSH feature to forward a port on the attacker's machine to a port on a remote destination, initiated from the jump host.

Dynamic Port Forwarding (-D)

SSH feature to create a SOCKS proxy on the attacker's local machine, routing all traffic through the jump host.

Summary Takeaway

Mastering these SSH forwarding techniques is fundamental for bypassing network segmentation and accessing internal resources in advanced penetration tests.
