Local Port Forwarding in Action

Accessing an internal web server using SSH local port forwarding.

Scenario Setup

  • Attacker Machine: Your local system.
  • JumpHost (DMZ): 10.0.0.5 (compromised).
  • InternalWeb: 192.168.1.100:80 (target).
  • Goal: Access InternalWeb from AttackerMachine.
Key Takeaway

The -L flag creates a tunnel from your local port to a remote destination via the jump host.

# 1. Establish Local Port Forwarding from Attacker Machine
ssh -L 8080:192.168.1.100:80 user@10.0.0.5
This command maps your local port 8080 to the internal web server's port 80, through the JumpHost.
# 2. Access InternalWeb from Attacker Machine (new terminal)
curl http://localhost:8080
Expected Output: HTML content of the internal web server.
