01

Explain Network Pivoting

Understand the core concept of network pivoting and its critical role in extending access to internal, otherwise inaccessible, network segments during penetration tests. This skill is foundational for advanced network exploitation.

VERIFIED COMPETENCY MILESTONE
02

Differentiate Port Forwarding

Distinguish between local, remote, and dynamic port forwarding techniques, understanding their distinct purposes, mechanisms, and when to apply each in various network scenarios. This ensures you choose the right tool for the job.

VERIFIED COMPETENCY MILESTONE
03

Implement Local Port Forwarding

Execute SSH local port forwarding commands to securely access services located on a remote network from your local machine, effectively bypassing network segmentation and firewalls. This is a fundamental tunneling skill.

VERIFIED COMPETENCY MILESTONE
04

Implement Remote Port Forwarding

Set up SSH remote port forwarding to expose internal services from a compromised host back to your attacker machine, enabling you to interact with them as if they were local. This is crucial for reverse connections.
