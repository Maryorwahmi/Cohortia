SSH Fundamentals

SSH Port Forwarding Overview

Explore the three primary types of SSH port forwarding for secure network access.

What is Port Forwarding?

  • Redirects network traffic from one port to another.
  • Creates a secure tunnel through an intermediary host.
  • Bypasses firewalls and network segmentation.
  • Essential for accessing services not directly exposed.
Key Takeaway

SSH offers robust, built-in capabilities for creating secure tunnels to extend network reach.

1. Local Port Forwarding (`-L`)

Access a remote service from your local machine via a jump host.

2. Remote Port Forwarding (`-R`)

Expose an internal service to your local machine, initiated from the jump host.

3. Dynamic Port Forwarding (`-D`)

Create a SOCKS proxy on your local machine, routing all traffic through the jump host.
