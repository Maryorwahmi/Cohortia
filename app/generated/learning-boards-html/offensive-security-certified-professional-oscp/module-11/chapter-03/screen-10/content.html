Dynamic Port Forwarding (`-D`)

Create a SOCKS proxy on your local machine for versatile network routing.

What is a SOCKS Proxy?

  • Routes network packets between client and server.
  • Supports various protocols (TCP, UDP).
  • Enables dynamic forwarding to any destination.
  • Acts as a general-purpose network relay.

Key Advantage

Allows you to proxy all your network tools (browser, Nmap, Metasploit, etc.) through the compromised host, making it appear as if you are directly on its network.

Key Takeaway

Dynamic forwarding is the most flexible SSH pivoting method, enabling full network tool integration.

# 1. Establish Dynamic Port Forwarding (SOCKS Proxy)
ssh -D 1080 user@JumpHost
This creates a SOCKS proxy on your local machine, listening on port 1080.
# 2. Configure Proxychains to use the SOCKS proxy
# Edit /etc/proxychains4.conf or proxychains.conf
[ProxyList]
socks5 127.0.0.1 1080
Now, any tool run with `proxychains` will route traffic through the JumpHost.
