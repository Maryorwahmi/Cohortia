Leveraging HTTP/HTTPS for Data Exfiltration

Blending data transfers with legitimate web traffic

Universal Port Access

Most corporate networks permit outbound traffic on ports 80 (HTTP) and 443 (HTTPS), making these protocols widely available for data transfer.

Blending with Legitimate Traffic

Exfiltration via HTTP/HTTPS can easily mimic normal web browsing, making it harder for basic network monitoring to distinguish malicious activity.

Key Takeaway

HTTP/HTTPS offers a high probability of success due to common port allowances, but requires careful execution to avoid detection by advanced traffic analysis.

POST Requests to Attacker Server

Attackers typically set up a web server to receive data via HTTP POST requests. This allows for sending files or encoded data in the request body.

Potential for Detection

While traffic blends, network monitoring solutions can analyze unusual request sizes, frequencies, or destinations, potentially flagging suspicious activity.

Common Misconception

HTTP/HTTPS exfiltration is not entirely undetectable. It can be identified by analyzing traffic anomalies, even if the ports are open.
