Key Concepts: Core Techniques

Essential methods for data exfiltration.

HTTP/HTTPS Exfiltration

Sending data encoded within standard web requests (GET/POST) over ports 80/443 to an attacker-controlled web server.

`curl` / `wget` / `Invoke-WebRequest`

Command-line tools (`curl`, `wget` on Linux; `Invoke-WebRequest` on Windows) for making web requests, commonly used for HTTP/HTTPS exfiltration.

DNS Tunneling

A highly covert channel that encodes data within DNS queries and responses, allowing exfiltration over port 53 UDP.

Summary Takeaway

Mastering these core techniques is fundamental for any successful data exfiltration operation, balancing visibility with stealth requirements.
