Skills you'll gain in this chapter

01

Implement HTTP/HTTPS POST Exfiltration

Learn to send data via HTTP/HTTPS POST requests to an attacker-controlled web server. This skill is crucial for leveraging common web traffic for covert data movement.

VERIFIED COMPETENCY MILESTONE
02

Utilize `wget` or `curl` for File Transfers

Master the use of command-line tools like `wget` and `curl` on Linux, and `Invoke-WebRequest` on Windows, for outbound file exfiltration. This enables versatile data movement across different OS environments.
