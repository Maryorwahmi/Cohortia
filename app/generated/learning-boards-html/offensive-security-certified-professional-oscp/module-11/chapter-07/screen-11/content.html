COVERT CHANNEL TYPES

Storage Channels (Protocol Abuse)

Embedding data into unused or seldom-used fields of legitimate network protocols.

ICMP ID/Sequence Number

Encoding data into the ID or sequence number fields of ICMP echo requests. These fields are often ignored by basic firewalls and monitoring.

TCP Sequence/Acknowledgement Numbers

Modulating data into the sequence or acknowledgment numbers of TCP packets. This requires precise control over TCP stacks and is more complex to implement.

HTTP Headers

Using custom or less-common HTTP headers (e.g., `X-Exfil-Data`) to transmit small chunks of base64-encoded data within legitimate web traffic.

DNS TXT Records

Storing data directly in DNS TXT records, which are designed for arbitrary text, allowing for covert data transfer through DNS queries.

Key Takeaway

Storage channels exploit the flexibility and often overlooked fields of common network protocols to create hidden data pathways, demanding deep protocol inspection for detection.
