Exfiltration Strategy

Strategic Approach: Channel Selection

Leveraging Common Protocols and Covert Methods

Factors for Selection

Consider network egress filtering, available tools on the target, data volume, and the required level of stealth when choosing an exfiltration channel.

Key Takeaway

The most effective exfiltration channels blend with legitimate network traffic, bypassing egress filters and minimizing detection risk.

Topic Cards Grouped by Category
HTTP/HTTPS

Sending data via web requests (POST, encoded in URLs). Common and often allowed.

DNS Tunneling

Encoding data within DNS queries or responses. Highly effective for bypassing strict egress filters.

ICMP Tunneling

Encoding data within ICMP (ping) packets. Can be effective if ICMP traffic is allowed.

FTP/SFTP

Direct file transfer if outbound connections on ports 20/21 or 22 are allowed.

Email

Sending data as attachments or within email bodies. Often a last resort.

Cloud Storage

Uploading to attacker-controlled cloud services if credentials are found.
