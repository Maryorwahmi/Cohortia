Key Concepts

Advanced Techniques and Preparations

Covert Channel

A communication path that is hidden within legitimate communication, used to transmit data secretly.

Compression

Reducing the size of data to facilitate faster transfer and potentially bypass size limits.

Encryption

Encoding data to prevent unauthorized access, ensuring confidentiality during transfer.

Data Discovery

The process of locating specific types of sensitive data on a compromised system.

Summary Takeaway

Advanced exfiltration often relies on covert channels, data compression, encryption, and meticulous data discovery to achieve stealth and reliability.
