Data Classification

Identifying Valuable Targets

Categories of Information Sought by Adversaries

Why Data Value Matters

The type and sensitivity of data directly influence an attacker's motivation, effort, and the potential impact of a breach. Prioritizing targets is key.

Key Takeaway

Understanding the value and sensitivity of different data types is crucial for effective target identification and strategic exfiltration planning.

Topic Cards Grouped by Category
Credentials

Usernames, passwords, hashes, API keys, SSH keys, private certificates. Often unlock further access.

Intellectual Property

Source code, proprietary algorithms, design documents, trade secrets, research data.

Customer Data (PII/PHI)

Names, addresses, SSNs, financial details, health records. High legal and reputational risk.

Financial Data

Transaction records, balance sheets, financial forecasts. Directly monetizable information.

Strategic Documents

Business plans, merger/acquisition details, legal documents. Provides competitive intelligence.

Configuration Files

Database connection strings, server configurations, network diagrams. Critical for deeper access.
