Challenges: Data Discovery

Finding the Data You Need on a Compromised Host

Why it's a Challenge

Sensitive data is often hidden, poorly named, or located in unexpected places, requiring systematic and persistent search efforts to uncover.

Key Takeaway

Thorough data discovery is the prerequisite for any successful exfiltration, demanding strong enumeration skills and an understanding of common data storage patterns.

Step-by-Step Cards
01

Initial Reconnaissance

Leverage initial access and reconnaissance to understand the system's purpose and likely data types it holds.

02

Host Enumeration

Perform thorough host enumeration (e.g., `ls -laR`, `find / -name "*.conf"`) to map file systems and identify potential data locations.

03

Targeted Keyword Search

Search for specific keywords (e.g., 'password', 'API_KEY', 'confidential') within files using tools like `grep`.

04

Identify Sensitive File Types

Look for common sensitive file extensions like `.sql`, `.pem`, `.key`, `.docx`, `.pdf`, or `.xls` in relevant directories.
