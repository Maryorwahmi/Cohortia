Challenges: Network Egress Filtering

Understanding Outbound Traffic Restrictions

What is Egress Filtering?

A network security measure that monitors and restricts outbound traffic from a network based on predefined policies, often blocking unusual ports or protocols.

Key Takeaway

Egress filtering is a primary defense against exfiltration, compelling attackers to use allowed protocols or covert channels to bypass restrictions.
