Challenges: Data Volume

Overcoming Bandwidth and Size Limitations

Why it's a Challenge

Large data volumes require high-bandwidth, reliable channels and are more prone to detection by network monitoring systems due to unusual traffic patterns.

Key Takeaway

Compression and splitting are vital techniques for managing data volume, enhancing reliability, and reducing the footprint of large exfiltration attempts.

Comparison Cards Table
Small Data (e.g., Credentials)
  • Low bandwidth requirement
  • Quick transfer
  • Less likely to trigger alerts
  • Can use simple channels
Large Data (e.g., DB Backups)
  • High bandwidth needed
  • Longer transfer time
  • Higher risk of detection
  • Requires compression & splitting
Example: Splitting a 5GB File

Using split -b 100M db_backup.sql.gz db_backup_part_ breaks a 5GB file into 50 smaller, more manageable 100MB chunks, improving transfer resilience.
