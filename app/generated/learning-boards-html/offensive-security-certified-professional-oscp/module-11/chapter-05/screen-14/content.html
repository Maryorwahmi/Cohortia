Key Concepts

Essential Terms for Data Exfiltration

Data Exfiltration

The unauthorized transfer of data from a target system or network to an external, attacker-controlled location.

Sensitive Data

Information that, if disclosed, could cause harm to an individual or organization, including PII, PHI, financial data, and intellectual property.

Egress Filtering

Network security measure that monitors and restricts outbound traffic from a network based on policy, often blocking unusual ports or protocols.

Summary Takeaway

Data exfiltration is the covert theft of sensitive information, a process heavily influenced by the target data's nature and network egress filtering defenses.
