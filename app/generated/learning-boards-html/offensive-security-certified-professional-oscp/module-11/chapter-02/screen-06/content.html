Navigating the Linux Filesystem

Discovering Directories and Hidden Files for Clues

# Command: pwd
pwd
# Output:
/home/lowprivuser
# Command: ls -la
ls -la
# Output (excerpt):
drwxr-xr-x 3 lowprivuser lowprivuser 4096 Apr 20 10:00 .drwxr-xr-x 3 root        root        4096 Apr 19 15:30 ..-rw------- 1 lowprivuser lowprivuser  512 Apr 20 09:55 .bash_historydrwxr-xr-x 2 lowprivuser lowprivuser 4096 Apr 19 16:00 .ssh-rw-r--r-- 1 lowprivuser lowprivuser  220 Apr 19 15:30 .bashrc
Key Takeaway

Hidden files (e.g., `.bash_history`, `.ssh`) are often overlooked but can contain critical credentials or command history.

# Command: ls -la /home/
ls -la /home/
# Output (excerpt):
drwxr-xr-x 3 lowprivuser lowprivuser 4096 Apr 20 10:00 lowprivuserdrwxr-xr-x 3 devuser     devuser     4096 Apr 18 14:20 devuser

Why it Matters

  • Configuration Files: Discover application settings, web server configs.
  • Credentials: Find SSH keys, database passwords, API tokens in dotfiles.
  • User Activity: `.bash_history` reveals commands executed by users.
  • System Structure: Understand how data is organized.
Pro Tip

Always check `/root/` and other user home directories, even if you don't have full read access, for clues about other users or sensitive files.
