Kernel, OS Details, and Running Applications

Key Takeaway

Analyzing running processes with `ps aux` can reveal unusual activity, processes running as root, or vulnerable applications.

# Command: ps aux
ps aux
# Output (excerpt):
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMANDroot         1  0.0  0.1 168668  9000 ?        Ss   Apr19   0:01 /sbin/initroot       789  0.0  0.1 108000  6000 ?        Ss   Apr19   0:00 /usr/sbin/sshdlowpriv+  1234  0.0  0.0  25000  3000 pts/0    R+   10:05   0:00 ps aux

Why it Matters

  • Vulnerability Identification: Kernel and OS versions can point to known exploits.
  • Resource Usage: `df -h` and `mount` reveal storage and potential data locations.
  • Process Analysis: Identify suspicious processes, their owners, and command-line arguments.
  • Application Discovery: Running processes indicate installed software.
Common Mistake

Ignoring seemingly benign processes. Even common applications can have misconfigurations or known vulnerabilities.
