Key Takeaway

`netstat -antp` is invaluable for identifying active connections, listening services, and the processes behind them.

# Command: netstat -antp
netstat -antp
# Output (excerpt):
Active Internet connections (servers and established)Proto Recv-Q Send-Q Local Address           Foreign Address         State       PID/Program nametcp        0      0 0.0.0.0:22              0.0.0.0:*               LISTEN      789/sshd: /usr/sbitcp        0      0 127.0.0.1:3306          0.0.0.0:*               LISTEN      1234/mysqldtcp        0      0 192.168.1.100:80        0.0.0.0:*               LISTEN      987/apache2

Why it Matters

  • Connectivity: Understand how the host communicates with other systems.
  • Service Discovery: Identify open ports and the services listening on them.
  • Pivot Points: Discover connections to internal networks or other hosts.
  • Process Mapping: Link network activity to specific running applications.
Common Mistake

Only checking for external connections. Internal listening ports often expose less secure services for local exploitation.
