Package Managers and Critical File Hunting

# Command: dpkg -l (Debian/Ubuntu)
dpkg -l
# Output (excerpt):
ii  apache2       2.4.41-4ubuntu3.4  amd64        Apache HTTP Serverii  mysql-server  8.0.25-0ubuntu0.20.04.1 amd64        MySQL database server
# Command: find / -name "*config*" 2>/dev/null
find / -name "*config*" 2>/dev/null
# Output (excerpt):
/etc/apache2/apache2.conf/var/www/html/wp-config.php/home/lowprivuser/.gitconfig
Key Takeaway

The `find` command with `grep` is essential for locating sensitive files like credentials, configuration data, and private keys.

# Command: find / -type f -name "*.log" -exec grep -Hn "password" {} \; 2>/dev/null
find / -type f -name "*.log" -exec grep -Hn "password" {} \; 2>/dev/null
# Output (excerpt):
/var/log/apache2/error.log:123:Authentication failed for user 'admin' with password 'weakpass123'

Why it Matters

  • Vulnerable Software: Identify outdated or misconfigured applications.
  • Credentials: Discover plaintext passwords, API keys, SSH private keys.
  • Configuration Data: Understand application behavior and database connections.
  • Log Analysis: Find error messages, user activity, and potential credential leaks.
Common Mistake

Forgetting to redirect errors (`2>/dev/null`) when using `find`, which can clutter your terminal with 'Permission denied' messages.
