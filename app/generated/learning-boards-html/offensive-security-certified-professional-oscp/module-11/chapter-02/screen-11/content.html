Uncovering Windows System Details and Running Tasks

OS Version, Hostname, and Process Analysis

# Command: systeminfo
systeminfo
# Output (excerpt):
OS Name:                   Microsoft Windows Server 2019 StandardOS Version:                10.0.17763 N/A Build 17763System Manufacturer:       VMware, Inc.System Model:              VMware Virtual Platform
# Command: tasklist /svc
tasklist /svc
# Output (excerpt):
Image Name                     PID Services========================= ======== ============================================svchost.exe                   1024 Dnscache, LanmanWorkstation, ...spoolsv.exe                   1568 Spooler
Key Takeaway

Always examine the full command line and executable path of processes, not just their names, to detect spoofing or suspicious parameters.

# Command: wmic process get Caption,ExecutablePath,CommandLine /format:list
wmic process get Caption,ExecutablePath,CommandLine /format:list
# Output (excerpt):
Caption=svchost.exeCommandLine="C:\Windows\System32\svchost.exe -k LocalServiceNetworkRestricted -p"ExecutablePath=C:\Windows\System32\svchost.exeCaption=cmd.exeCommandLine="C:\Windows\System32\cmd.exe /c whoami"ExecutablePath=C:\Windows\System32\cmd.exe

Why it Matters

  • Vulnerability Mapping: OS version and hotfixes can indicate known exploits.
  • Application Insight: Identify all running software and services.
  • Malicious Activity: Spot unusual processes, their command lines, or parent processes.
  • Persistence: Processes can reveal how malware maintains access.
Common Mistake

Only looking at process names. Always examine the full command line and executable path for suspicious parameters or spoofing.
