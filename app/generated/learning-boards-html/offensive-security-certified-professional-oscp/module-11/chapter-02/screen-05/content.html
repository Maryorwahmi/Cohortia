Linux Enumeration

Understanding Your Linux User Context

Identifying Current Privileges and Group Memberships

# Command: whoami
whoami
# Output:
lowprivuser
# Command: id
id
# Output:
uid=1001(lowprivuser) gid=1001(lowprivuser) groups=1001(lowprivuser),27(sudo),100(users)
Key Takeaway

Always check group memberships with `id` as they can reveal hidden privileges, like `sudo` access.

# Command: cat /etc/passwd
cat /etc/passwd
# Output (excerpt):
root:x:0:0:root:/root:/bin/bashsys:x:3:3:sys:/dev:/usr/sbin/nologinlowprivuser:x:1001:1001:,,,:/home/lowprivuser:/bin/bashwww-data:x:33:33:www-data:/var/www:/usr/sbin/nologin

Why it Matters

  • Privilege Assessment: Determines what actions you can perform.
  • User Discovery: Identifies other potential user accounts on the system.
  • Escalation Paths: Group memberships (e.g., `sudo`, `docker`) can indicate privilege escalation opportunities.
Common Mistake

Assuming low privileges based solely on `whoami`. Always check `id` for group memberships that might grant elevated capabilities.
