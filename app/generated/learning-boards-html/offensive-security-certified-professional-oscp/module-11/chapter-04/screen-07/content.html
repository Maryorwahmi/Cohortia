Pass-the-Hash (PtH) Attacks

Authenticating with NTLM Hashes

What is Pass-the-Hash?

Pass-the-Hash (PtH) is an attack technique where an attacker authenticates to a remote server by using a user's NTLM hash instead of their plaintext password. This is possible because Windows authentication protocols (like NTLM) often only require the hash for verification, not the original password.

Why PtH is Effective

  • No Plaintext Needed: Bypasses the need to crack hashes.
  • Widespread Protocol: Many systems still use NTLM for authentication.
  • Stealthy: Less noisy than brute-forcing or password guessing.
  • Leverages Existing Credentials: Uses legitimate hashes for access.
Key Takeaway

PtH attacks exploit the NTLM authentication mechanism by directly using a user's NTLM hash to gain access to other systems, making it a powerful lateral movement technique.

Example: PtH with crackmapexec

If you have the NTLM hash for a domain administrator, you can use crackmapexec (CME) to attempt to get a shell on multiple machines in a subnet where that administrator has local admin rights.

attacker@kali:~$ crackmapexec smb 10.0.0.0/24 -u Administrator -H <NTLM_HASH> --exec-shell cmd.exe

# Example NTLM hash for a blank password:
# 31d6cfe0d16ae931b73c59d7e0c089c0

# CME will attempt to connect to each host in the subnet
# and execute a command shell if successful.

This command attempts to authenticate to all SMB services in the `10.0.0.0/24` subnet using the provided NTLM hash for the 'Administrator' user.

Pro-Tip

Always prioritize PtH over password cracking or brute-forcing. It's faster, more reliable, and significantly less likely to trigger account lockouts or detection alerts.
