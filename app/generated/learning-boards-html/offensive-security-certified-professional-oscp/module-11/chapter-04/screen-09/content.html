Windows Privilege Escalation

Token Impersonation

Assuming Another User's Security Context

What is Token Impersonation?

Token impersonation is a Windows technique where a process assumes the security context of another user's access token. An access token contains the security information for a logon session and identifies the user, the user's groups, and the user's privileges. By impersonating a token, an attacker can perform actions with the privileges of the original user.

Why it's Powerful

  • Bypass Authentication: No password or hash needed once token is stolen.
  • Privilege Escalation: Impersonate a higher-privileged user (e.g., SYSTEM).
  • Lateral Movement: Execute commands or access resources as another user.
  • Exploits Trust: Leverages existing high-privileged processes.
Key Takeaway

Token impersonation allows an attacker to operate with the privileges of another user by stealing their security token, providing a potent method for privilege escalation and lateral movement on Windows.

Tools and Techniques

Tools like incognito.exe (part of Metasploit's getsystem module) are commonly used to list and impersonate tokens. Vulnerabilities like PrintSpoofer can also be exploited to gain SYSTEM privileges and then impersonate tokens.

# Example Metasploit commands for token impersonation
meterpreter > getsystem
meterpreter > load incognito
meterpreter > list_tokens -u
# Lists available tokens

meterpreter > impersonate_token
