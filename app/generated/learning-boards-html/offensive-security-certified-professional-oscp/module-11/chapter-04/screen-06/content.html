Dumping LSASS Memory

Capturing Credentials for Offline Analysis

Why Dump LSASS?

  • Contains Live Credentials: Stores hashes, tickets, and sometimes plaintext passwords.
  • Offline Analysis: Reduces footprint on the target system.
  • Bypasses EDR: Using legitimate tools like procdump can evade detection.
  • Comprehensive Data: Captures all active session credentials.

The Process

1

Gain SYSTEM Privileges: Required to access lsass.exe memory.

2

Execute procdump: Dump lsass.exe memory to a file.

3

Exfiltrate Dump: Transfer the .dmp file to your attacker machine.

4

Analyze Offline: Use Mimikatz or similar tools to extract credentials.

Key Takeaway

Dumping lsass.exe memory with procdump and analyzing it offline is a stealthy and effective method to obtain credentials from a Windows system for lateral movement.

Example: Dumping LSASS with procdump

After gaining SYSTEM privileges on a Windows machine, you can use procdump.exe to create a memory dump of the lsass.exe process. The -ma flag specifies a full memory dump, and -accepteula bypasses the license agreement prompt.

C:\> procdump.exe -accepteula -ma lsass.exe lsass.dmp

# Output will show the dump being written:
# Process: lsass.exe (1234)
# Writing dump file lsass.dmp...
# Dump complete.

Once lsass.dmp is created, you would securely transfer it to your Kali Linux machine for analysis using tools like Mimikatz.

Security Note

While procdump is legitimate, its use in a penetration test should always be explicitly authorized due to the sensitive nature of the data it handles.
