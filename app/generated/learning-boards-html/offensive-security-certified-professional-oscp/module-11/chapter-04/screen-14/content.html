Key Concepts

Essential Terms to Remember

Lateral Movement

Extending access from an initially compromised system to other systems within the same network.

Credential Access

The process of obtaining legitimate credentials (passwords, hashes, tickets) from a compromised system.

Mimikatz

A post-exploitation tool used to extract plaintext passwords, NTLM hashes, and Kerberos tickets from Windows memory (lsass.exe).

NTLM Hash

A cryptographic hash of a user's password, used in Windows for authentication, particularly in NTLM authentication.

Pass-the-Hash (PtH)

An attack technique where an attacker authenticates to a remote server using a user's NTLM hash instead of their plaintext password.

Chapter Summary

Lateral movement is the strategic expansion of access within a network, often achieved by obtaining credentials through tools like Mimikatz and leveraging them in attacks such as Pass-the-Hash.
