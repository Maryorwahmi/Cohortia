Linux Lateral Movement

SSH Key Reuse

Leveraging Stolen SSH Private Keys

What is SSH Key Reuse?

SSH key reuse involves using a found SSH private key (e.g., id_rsa) from a compromised Linux system to authenticate to other machines where the key's owner has an account. This bypasses password authentication and leverages existing trust relationships established through SSH.

Key Steps

  • Locate Private Keys: Search common directories like ~/.ssh/.
  • Check Permissions: Ensure the key has chmod 600 permissions.
  • Identify Target Hosts: Look for ~/.ssh/config or .bash_history.
  • Authenticate: Use ssh -i <private_key> user@target_ip.
Key Takeaway

SSH key reuse is a highly effective Linux lateral movement technique that exploits compromised private keys to gain authenticated access to other systems without needing a password.

Example: Finding and Using SSH Keys

You can use the find command to search for SSH private keys across the filesystem. Once found, ensure correct permissions and then use the key to connect.

attacker@kali:~$ find / -name "id_rsa" 2>/dev/null
/home/user/.ssh/id_rsa

attacker@kali:~$ chmod 600 /home/user/.ssh/id_rsa

attacker@kali:~$ ssh -i /home/user/.ssh/id_rsa user@192.168.1.100
# You are now logged into 192.168.1.100 as 'user'.

This demonstrates how a compromised key can grant immediate access to another system.

Pro-Tip

Always check ~/.ssh/config for configured SSH aliases and .bash_history for commands that reveal connections to other hosts, as these can point to valuable targets.
