Domains and Organizational Units

Structuring network objects for administration and policy enforcement.

Domain Definition

A logical grouping of network objects sharing a common database, security policies, and trust relationships (e.g., example.com).

Organizational Unit (OU)

Containers within a domain used to group objects for administrative purposes and to apply Group Policy Objects (GPOs).

Key Takeaway

Domains define security boundaries, while OUs provide flexible administrative delegation and policy application within those boundaries.
