DNS: The Locator Service for Active Directory

How Active Directory relies on DNS for locating critical services.

Fundamental for AD

AD relies on DNS to locate domain controllers and other services; without it, AD cannot function.

SRV Records

Pen testers query DNS for SRV records (e.g., _ldap._tcp.dc._msdcs.<domain>) to find DCs.

Key Takeaway

DNS enumeration is often the first step in understanding a target network's AD infrastructure.

DNS Resolution for AD Services
Client Request
Query DNS for _ldap._tcp.dc._msdcs.corp.local SRV record
DNS Server Responds with DC IP (e.g., 192.168.1.100)
Client Connects to DC
