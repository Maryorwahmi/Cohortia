Hands-on Activity

Basic AD Service Enumeration

Using network tools to identify key Active Directory services.

Scenario

Given a DC IP (e.g., 192.168.1.100) and domain (e.g., corp.local), identify DNS, LDAP, and Kerberos services.

Reflection

How does this initial reconnaissance inform your next steps in a penetration test?

Key Takeaway

Effective service enumeration provides crucial insights for mapping the network and identifying attack vectors.

Enumeration Commands
# Identify DNS Service (SRV records)
nslookup
server 192.168.1.100
set type=SRV
_ldap._tcp.dc._msdcs.corp.local

# Identify LDAP Service (ports 389, 636)
nmap -p 389,636 -sV 192.168.1.100

# Identify Kerberos Service (port 88)
nmap -p 88 -sV 192.168.1.100
Pro Tip

Always replace placeholder IPs and domain names with your lab environment's actual values.
