Key Concepts

Essential Active Directory Terminology (Continued)

Group Policy Object (GPO)

A collection of settings controlling user and computer accounts within an AD domain.

Domain Controller (DC)

A server hosting AD DS, responsible for authenticating users, enforcing policies, and hosting the AD database.

DNS

A hierarchical naming system crucial for AD to locate domain controllers and other services.

LDAP

An application protocol for accessing and maintaining distributed directory information services, used to query and modify AD.

Kerberos

A network authentication protocol using 'tickets' to securely prove identity between communicating nodes.

Summary Takeaway

GPOs, DCs, DNS, LDAP, and Kerberos are the operational pillars of AD, each presenting unique opportunities and challenges for penetration testers.
