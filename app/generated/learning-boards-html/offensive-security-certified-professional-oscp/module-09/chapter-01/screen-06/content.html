AD Logical Structure

Trees and Forests: Scaling Active Directory

Understanding the highest logical structures and trust relationships.

AD Tree

Multiple domains sharing a contiguous DNS namespace (e.g., sales.example.com and it.example.com within example.com).

AD Forest

The highest logical structure, consisting of one or more AD trees sharing a common schema, configuration, and global catalog.

Key Takeaway

Forests establish implicit, transitive trust relationships between all contained domains, crucial for understanding lateral movement paths.
