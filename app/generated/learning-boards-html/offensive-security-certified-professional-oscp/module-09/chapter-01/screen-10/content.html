Kerberos: The Authentication Protocol

Secure, ticket-based authentication for Active Directory.

Ticket-Based System

Uses Ticket Granting Tickets (TGTs) and Service Tickets (STs) for strong authentication.

Attack Vectors

Vulnerable to attacks like Kerberoasting (offline cracking) and Pass-the-Ticket (reusing stolen TGTs).

Key Takeaway

Understanding the Kerberos authentication flow is crucial for identifying and exploiting its inherent vulnerabilities.

Simplified Kerberos Authentication Flow
1. User Requests TGT from KDC (DC)
2. KDC Issues TGT to User
3. User Presents TGT to KDC for Service Ticket (ST)
4. KDC Issues ST to User
5. User Presents ST to Service for Access
