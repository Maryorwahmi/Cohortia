LDAP: Querying the Active Directory Database

The primary protocol for accessing and modifying directory information.

Primary Protocol

LDAP is used to query and modify the AD database, retrieving information about objects and their attributes.

Reconnaissance Tool

Vital for pen testers to enumerate users, groups, computers, and discover sensitive attributes.

Key Takeaway

Mastering LDAP filters and queries is essential for precise and effective Active Directory reconnaissance.

LDAP Query Example: Finding Admin Users
# Example: Find all users in 'Domain Admins' group
ldapsearch -x -H ldap://192.168.1.100 -b "DC=corp,DC=local" \
  "(&(objectClass=user)(memberOf=CN=Domain Admins,CN=Users,DC=corp,DC=local))"

# Example: Find users with 'password never expires' attribute
ldapsearch -x -H ldap://192.168.1.100 -b "DC=corp,DC=local" \
  "(&(objectClass=user)(userAccountControl:1.2.840.113556.1.4.803:=65536))"

# Example: Find all computer objects
ldapsearch -x -H ldap://192.168.1.100 -b "DC=corp,DC=local" \
  "(objectClass=computer)"
Pro Tip

Understanding LDAP filters allows you to craft highly specific queries, extracting targeted information that generic tools might miss.
