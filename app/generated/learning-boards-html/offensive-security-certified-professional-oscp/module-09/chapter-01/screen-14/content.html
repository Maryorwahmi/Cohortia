Key Concepts

Essential Active Directory Terminology

Active Directory (AD)

Microsoft's directory service for Windows domain networks, centralizing management of users, computers, and resources.

Domain

A logical grouping of network objects sharing a common database, security policies, and trust relationships.

Forest

The highest logical structure in AD, consisting of one or more AD trees sharing a common schema and configuration.

Summary Takeaway

Understanding these foundational AD components is crucial for mapping network structures and identifying potential attack surfaces.
