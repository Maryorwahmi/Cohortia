Exploiting Domain Trusts for Lateral Movement

Identifying and leveraging trust paths for cross-domain access and privilege escalation.

Exploitation Strategy
  • Identify Trusts: Map out all trust relationships between domains.
  • Compromise Credentials: Obtain privileged credentials (hash/ticket) in a trusted domain.
  • Lateral Movement: Use compromised credentials to access resources in the trusting domain.
  • Privilege Escalation: Potentially escalate to Enterprise Admin in the forest root domain.
Key Takeaway

Exploiting domain trusts involves leveraging compromised credentials in one domain to gain access and escalate privileges in a trusted domain, facilitating lateral movement.

Example Scenario
Child Domain
Parent Domain
Compromise Child Domain Admin.
Parent Domain
Forest Root
Leverage transitive trust to access Parent Domain, then Forest Root.
Common Misconception

A one-way trust from A to B does not mean B cannot attack A. If a user in B has admin rights in A due to misconfiguration, B can still attack A.
