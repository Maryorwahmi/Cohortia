Exploiting Unconstrained Delegation

The attack flow to leverage unconstrained delegation for privilege escalation.

Attack Steps
  1. 1. Compromise Delegated Server: Gain administrative access to a server or service account configured for unconstrained delegation.
  2. 2. Force Privileged Authentication: Trick a Domain Admin (or other privileged user) into authenticating to the compromised server.
  3. 3. Capture TGT: Extract the Domain Admin's Ticket Granting Ticket (TGT) from the compromised server's memory (e.g., using Mimikatz).
  4. 4. Impersonate Domain Admin: Inject the captured TGT into your session to gain full Domain Admin privileges.
Key Takeaway

The core of unconstrained delegation exploitation is capturing a privileged user's TGT by forcing their authentication to a compromised, delegated server.
