Domain Trusts: Connecting Active Directory Domains

Exploring transitive and non-transitive trust relationships.

What is a Domain Trust?
  • Security Relationship: Allows users in one domain to access resources in another.
  • Authentication & Authorization: Facilitates secure access across domain boundaries.
  • Lateral Movement: Key for expanding access in multi-domain environments.
Key Takeaway

Domain trusts are security relationships that enable cross-domain resource access, making them critical for understanding lateral movement paths in complex Active Directory structures.

Types of Domain Trusts
Transitive Trusts: Extend beyond directly trusted domains (A trusts B, B trusts C => A trusts C). Common within a forest.
Non-Transitive Trusts: Apply only directly between two domains (A trusts B, B trusts C => A does NOT trust C).
Tooling: BloodHound & PowerShell

Use BloodHound for visualizing trust relationships and `Get-ADTrust` in PowerShell for enumeration.
