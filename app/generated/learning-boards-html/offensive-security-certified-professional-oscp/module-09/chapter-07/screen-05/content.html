Unconstrained Delegation Explained

How a service can impersonate clients to any resource in Active Directory.

Key Characteristics
  • Service Account/Computer Account: Configured on a specific account.
  • TGT Forwarding: Forwards the client's Ticket Granting Ticket (TGT).
  • Any Service, Any Server: The TGT can be used to access any service on any server.
  • High Risk: Compromise of the delegated server leads to full impersonation of authenticated users.
Key Takeaway

Unconstrained delegation is a highly permissive setting that allows a service to capture and reuse a client's TGT, enabling full impersonation if the delegated server is compromised.
