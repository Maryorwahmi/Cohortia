The Ultimate Prize: Domain Controller Compromise

Understanding why Domain Controllers are the primary target in Active Directory.

Why Target DCs?
  • Central Authority: DCs hold the Active Directory database, including all user and computer accounts.
  • Credential Store: All NTLM hashes and Kerberos keys are stored on DCs.
  • Policy Enforcement: Group Policy Objects (GPOs) are managed and enforced by DCs.
  • Domain Dominance: Full control over a DC grants complete control over the entire Active Directory domain.
Key Takeaway

Compromising a Domain Controller is the most impactful action in an Active Directory attack, leading to full control over the domain's users, resources, and security.

Impact of DC Compromise
Full User Control
Access to All Resources
Modify Security Policies
Domain Dominance
Common Misconception

Some believe DC attacks are only for 'red teams'. However, understanding these attacks is equally vital for 'blue teams' to build robust defenses and detect intrusions.
