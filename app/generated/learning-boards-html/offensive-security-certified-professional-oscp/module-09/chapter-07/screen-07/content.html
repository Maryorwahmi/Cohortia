DCSync: Simulating a Domain Controller

Requesting replication of sensitive data from a legitimate Domain Controller.

What is DCSync?
  • Replication Protocol: Abuses the Active Directory replication protocol.
  • Hash Extraction: Extracts NTLM hashes for all domain users, including `krbtgt`.
  • No Physical Access: Does not require direct access to the DC's disk or memory.
  • High Impact: Provides credentials for Golden Tickets and persistent access.
Key Takeaway

DCSync is a powerful attack that allows an attacker to extract all domain password hashes by simulating a Domain Controller and requesting replication.

DCSync Prerequisites

Domain Admin Equivalent Privileges: Typically required to initiate the attack.

`DS-Replication-Get Changes All` Permission: Required on the domain object.

`DS-Replication-Get Changes` Permission: Also required on the domain object.

Misconception

DCSync does not require physical access to the DC. It leverages network protocols, making it a remote attack once privileges are obtained.
