Key Concepts: Core Attacks

Essential takeaways from Domain Controller and Trust Exploitation.

Unconstrained Delegation

A delegation setting allowing a service to obtain and reuse a client's TGT to access any service on any server.

DCSync

An attack simulating a DC to request and dump all password hashes from a legitimate Domain Controller.

DCShadow

An attack registering a rogue DC to inject arbitrary, persistent data into Active Directory.

Summary Takeaway

These advanced attacks demonstrate how attackers can compromise, extract credentials from, and persistently modify Active Directory, highlighting the need for robust defensive strategies.
