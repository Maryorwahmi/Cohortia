DCShadow: Pushing Changes to Active Directory

Registering a rogue DC to inject arbitrary data into Active Directory.

What is DCShadow?
  • Data Injection: Allows injecting arbitrary data into Active Directory.
  • Rogue DC: Registers a compromised machine as a temporary Domain Controller.
  • Stealthy Persistence: Changes are replicated as legitimate DC traffic, making detection harder.
  • Requires Elevated Privileges: Needs Domain Admin equivalent permissions.
Key Takeaway

DCShadow is an advanced, stealthy attack for injecting arbitrary, persistent changes into Active Directory by temporarily registering a rogue Domain Controller.

DCShadow vs. DCSync
DCSync: Pulls data (hashes) from DC.
DCShadow: Pushes data (modifications) to AD.
Use Cases

Create new Domain Admin accounts, modify user attributes, change ACLs for persistence, or inject malicious GPOs.

Detection Challenge

DCShadow is harder to detect than direct AD modifications because it mimics legitimate replication traffic, blending into normal operations.
