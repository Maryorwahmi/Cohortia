AdminSDHolder and SDProp Mechanism

How Active Directory protects highly privileged accounts from unauthorized ACL modifications.

AdminSDHolder Object

A special container in CN=System that holds a predefined Security Descriptor (ACL template) for protected groups.

SDProp Process

The Security Descriptor Propagator runs every 60 minutes (by default) to compare and overwrite ACLs of protected accounts to match AdminSDHolder.

Protected Groups
  • Domain Admins
  • Enterprise Admins
  • Schema Admins
  • Account Operators
  • And others...

Members of these groups have their ACLs automatically reset by SDProp.

Impact: ACL Reset

Any custom permissions set directly on a protected account will be reverted by SDProp, making direct ACL manipulation non-persistent for these accounts.

Key Takeaway

SDProp ensures that highly privileged accounts maintain a consistent and secure set of permissions, preventing attackers from establishing persistent control through direct ACL modifications on those accounts.
