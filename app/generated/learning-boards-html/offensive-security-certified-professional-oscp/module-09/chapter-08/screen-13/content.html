Key Concepts

Essential terms and ideas from this chapter.

Persistence

The ability for an attacker to maintain access to a compromised system or network, even after reboots or password changes.

Backdoor Account

A secret or hidden user account created by an attacker to maintain access to a compromised system.

AdminSDHolder

A container object in Active Directory that defines permissions for protected groups, propagated by SDProp.

Chapter Summary

This chapter provided a deep dive into establishing persistence and employing defense evasion techniques within Active Directory, covering backdoor accounts, GPO modifications, AdminSDHolder, ACL manipulation, and detection countermeasures.
