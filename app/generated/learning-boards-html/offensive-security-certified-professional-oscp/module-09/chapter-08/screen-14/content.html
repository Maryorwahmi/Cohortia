Key Concepts

Essential terms and ideas from this chapter.

SDProp

The Active Directory process that runs periodically to ensure protected account ACLs match AdminSDHolder.

ACL Manipulation

Modifying permissions on Active Directory objects to grant persistent control to an attacker-controlled account.

Defense Evasion

Techniques used by attackers to avoid detection by security controls, monitoring systems, and incident responders.

Chapter Summary

This chapter provided a deep dive into establishing persistence and employing defense evasion techniques within Active Directory, covering backdoor accounts, GPO modifications, AdminSDHolder, ACL manipulation, and detection countermeasures.
