Backdoor Accounts: Creation and Concealment

Establishing new, hidden, or modified privileged accounts for sustained access.

Core Idea: Direct Access

Creating new user accounts with administrative privileges provides a straightforward and reliable method for maintaining access to a compromised Active Directory environment.

Common Mistake: Obvious Naming

Creating accounts with easily identifiable malicious names (e.g., 'attacker_admin') significantly increases the chance of immediate detection by security analysts and automated tools.

Concealment Strategies
  • Create "hidden" accounts: Use names that blend with legitimate accounts (e.g., svc_backup_new, helpdesk_temp).
  • Modify existing accounts: Add privileged groups (e.g., Domain Admins) or reset passwords on rarely used accounts.
  • Set adminCount=1: For accounts in protected groups, this attribute is set, making them subject to AdminSDHolder protection.
Example: Blending In

Instead of 'eviladmin', an attacker might create 'sql_svc_temp' or 'dev_ops_sync' to mimic legitimate service accounts, making them harder to spot during routine audits.

Key Takeaway

Backdoor accounts are effective for persistence, but their longevity depends on sophisticated naming and modification techniques to avoid detection.
