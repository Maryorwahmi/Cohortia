ACL Manipulation for Broad Control

Modifying Access Control Lists on Active Directory objects to grant persistent control.

Core Idea: Granular Permissions

ACLs define who can access and modify Active Directory objects. Attackers can modify these permissions to grant themselves persistent control over specific users, groups, or the domain itself.

Misconception: Only Admins can do this

With the right initial access, even a non-admin account can be granted powerful permissions via ACL manipulation, effectively escalating privileges without group membership.

Impact of GenericAll
  • DCSync: Replicate directory changes, including password hashes.
  • Create New Users: Add new accounts to the domain.
  • Modify GPOs: Alter Group Policy Objects for widespread impact.
  • Full Control: Effectively gain complete control over the targeted object.
Tooling: BloodHound

Tools like BloodHound are essential for identifying weak ACLs and potential abuse paths, helping both attackers and defenders understand complex permission relationships.

Key Takeaway

ACL manipulation is a stealthy and powerful persistence technique that can grant extensive control over Active Directory objects, often bypassing traditional detection methods.
