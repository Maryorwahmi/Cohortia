Post-Dumping: Lateral Movement & Escalation

Leveraging acquired credentials for deeper network compromise

Leveraging Acquired Credentials

  • •Lateral Movement: Authenticate to other systems where the compromised user has access.
  • •Privilege Escalation: Gain higher-level access within the domain (e.g., domain admin).
  • •Domain Compromise: Achieve full control over the Active Directory environment.
Key Takeaway

Credential dumping is a pivotal step that transforms initial access into widespread network control, enabling advanced attack techniques.

Common Post-Dumping Attacks

Pass-the-Hash (PtH)

Use an NTLM hash to authenticate to a remote system without knowing the plaintext password.

Pass-the-Ticket (PtT)

Use a stolen Kerberos ticket to authenticate to services or systems.

Kerberoasting

Request service tickets for service principal names (SPNs) to obtain hashes for offline cracking.
