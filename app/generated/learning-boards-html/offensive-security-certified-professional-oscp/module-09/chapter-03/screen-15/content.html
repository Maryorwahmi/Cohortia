Key Concepts

Essential terms to remember from this chapter

LSASS

The Local Security Authority Subsystem Service, a Windows process responsible for enforcing security policy and storing sensitive credential information in memory.

Mimikatz

A powerful post-exploitation tool used to extract plaintext passwords, NTLM hashes, and Kerberos tickets from LSASS memory on Windows systems.

CrackMapExec (CME)

A versatile post-exploitation tool for enumerating and attacking Active Directory environments, capable of password spraying, share enumeration, and more.

LSA Protection

A security feature in Windows that aims to prevent unauthorized processes from reading LSASS memory, making credential dumping more difficult.

Summary Takeaway

These tools and concepts are fundamental for both offensive operations and for understanding how to defend against advanced credential theft attacks.
