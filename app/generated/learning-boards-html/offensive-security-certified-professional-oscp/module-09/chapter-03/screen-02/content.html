Execute Initial Access Techniques

Learn to perform password spraying and exploit weak credentials to gain a foothold in Active Directory environments. This skill is crucial for understanding how attackers first breach a network's perimeter.

Utilize Responder for NTLMv2 Capture

Learn to deploy Responder to capture NTLMv2 hashes from network traffic, understanding its role in credential theft. This technique exploits name resolution protocols to intercept authentication attempts.
