Key Concepts

Essential terms to remember from this chapter

Password Spraying

An attack where a single common password is tried against many user accounts to avoid account lockouts and identify weak passwords.

NTLMv2 Hash

A cryptographic hash of a user's password, used in the NTLM authentication protocol, valuable for offline cracking or Pass-the-Hash attacks.

Responder

A tool used to poison LLMNR, NBT-NS, and MDNS requests to capture NTLMv2 hashes from network traffic.

Credential Dumping

The process of extracting authentication material (passwords, hashes, tickets) from a compromised system's memory or storage.

Summary Takeaway

Mastering these concepts provides the foundation for gaining initial access and extracting critical credentials in Active Directory environments.
