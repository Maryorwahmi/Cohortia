Credential Dumping Overview & LSASS

Extracting authentication material from a compromised system's memory

What is Credential Dumping?

  • •Goal: Extract sensitive authentication data from a compromised host.
  • •Targets: Memory (LSASS), registry, or local files.
  • •Data Types: Plaintext passwords, NTLM hashes, Kerberos tickets.
  • •Purpose: Enable lateral movement, privilege escalation, and domain compromise.
Key Takeaway

Credential dumping is a critical post-exploitation step that provides the necessary authentication material to deepen an attacker's presence within a network.

The LSASS Process

Local Security Authority Subsystem Service

A core Windows process responsible for enforcing security policy, user authentication, and managing security tokens.

Credential Storage

LSASS stores sensitive authentication information in memory, including plaintext passwords (if not protected), NTLM hashes, and Kerberos tickets for logged-on users.

Why it matters

Compromising LSASS allows an attacker to extract credentials for any user currently logged into the system, including highly privileged accounts.
