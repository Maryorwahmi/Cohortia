Kerberoasting: Exploiting Service Principal Names

How SPNs become a target for credential theft in Active Directory.

What is an SPN?
  • •A unique identifier for a service instance in Active Directory.
  • •Tells the Kerberos KDC which account is running a specific service.
  • •Required for services running under domain user accounts (e.g., SQL Server, IIS).
  • •Allows clients to locate and authenticate to these services using Kerberos.
Example SPN

MSSQLSvc/sqlserver.corp.local:1433 identifies a SQL Server instance.

SPN & Service Account Relationship

Service Principal Name (SPN)

Unique identifier for a service

Service Account

Domain user running the service

Key Takeaway

SPNs are critical for Kerberos authentication, but their association with domain user accounts makes them a prime target for credential harvesting.
