Key Concepts

Further essential terms for Kerberos exploitation.

TGS-REP

The Kerberos service ticket issued by the KDC in response to a TGS-REQ, encrypted with the target service's key.

KDC

The Key Distribution Center, a service running on a Domain Controller responsible for issuing Kerberos tickets.

DoesNotRequirePreAuth

An Active Directory user account attribute that, when TRUE, allows a user to request a TGT without preauthentication, making them vulnerable to AS-REPRoasting.

Rubeus

A C# Kerberos interaction toolkit for red teamers, capable of performing various Kerberos attacks, including AS-REPRoasting and Kerberoasting.

Summary Takeaway

Understanding these core components and tools is essential for both executing and defending against advanced Kerberos-based credential attacks.
