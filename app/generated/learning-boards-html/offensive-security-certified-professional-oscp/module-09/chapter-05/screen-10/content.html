AS-REPRoasting: Bypassing Preauthentication

Exploiting disabled Kerberos preauthentication for user account hashes.

The Vulnerability
  • •Targets user accounts with the Do not require Kerberos preauthentication flag enabled.
  • •Normally, clients preauthenticate by encrypting a timestamp with their password hash.
  • •Preauthentication prevents offline brute-forcing of Ticket Granting Tickets (TGTs).
  • •When disabled, an attacker can request a TGT without proving identity.
Impact

The KDC returns an encrypted TGT, which the attacker can crack offline to obtain the user's NTLM hash.

Preauthentication Flow

Standard Kerberos

Client preauthenticates with password hash

KDC Issues TGT

Only after successful preauthentication

VS.

AS-REPRoasting Target

Preauthentication disabled: KDC issues TGT directly

Key Takeaway

The 'Do not require Kerberos preauthentication' flag is a critical misconfiguration that directly enables AS-REPRoasting.
