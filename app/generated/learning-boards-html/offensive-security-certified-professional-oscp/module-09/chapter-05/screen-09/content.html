Cracking Kerberoasted Hashes Offline

Using Hashcat to reveal service account passwords from collected tickets.

Hashcat Command
hashcat -m 13100 -a 0 spns.txt /usr/share/wordlists/rockyou.txt
  • •-m 13100: Specifies the hash mode for Kerberoasted hashes.
  • •-a 0: Indicates a dictionary attack (using a wordlist).
  • •spns.txt: The input file containing the collected Kerberos tickets.
  • •/usr/share/wordlists/rockyou.txt: The wordlist used for cracking.
Success Factor

The effectiveness of cracking heavily depends on the quality and comprehensiveness of your wordlist.

Example Cracked Output
$krb5tgs$23$*svc_mssql$corp.local$sqlserver.corp.local*...:SQLPass123!
Common Mistake

Forgetting to use the correct Hashcat mode (13100 for Kerberoasted hashes) will prevent successful cracking.

Key Takeaway

Successful offline cracking of Kerberoasted hashes yields service account credentials, which are often highly privileged.
