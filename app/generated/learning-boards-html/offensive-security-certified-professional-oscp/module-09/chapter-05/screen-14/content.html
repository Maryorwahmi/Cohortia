Kerberoasting vs. AS-REPRoasting

Key differences in targets, outcomes, and Hashcat modes.

Comparative Analysis
Kerberoasting
  • •Target: Service Principal Names (SPNs) associated with user accounts.
  • •Vulnerability: KDC issues encrypted service tickets (TGS-REP) to any legitimate user.
  • •Outcome: Service account's NTLM hash (from cracked TGS-REP).
  • •Hashcat Mode: 13100
AS-REPRoasting
  • •Target: User accounts with DoesNotRequirePreAuth flag enabled.
  • •Vulnerability: KDC issues encrypted TGTs without preauthentication.
  • •Outcome: User account's NTLM hash (from cracked TGT).
  • •Hashcat Mode: 18200
Key Takeaway

Both attacks are effective for privilege escalation from low-privileged users, but their distinct targets and hash types require different execution strategies and cracking modes.
