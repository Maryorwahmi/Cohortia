Attack Vector

ESC8: Weak Certificate Template ACLs

Modifying Template Permissions for Elevated Privileges

The Misconfiguration

A certificate template's Access Control List (ACL) allows low-privileged users to modify its security settings (e.g., Full Control or WriteProperty rights).

Attack Goal

Modify the template to enable sensitive functionalities (like Client Authentication or Enrollment Agent), then enroll for a certificate with elevated privileges.

Key Takeaway

Secure ACLs on certificate templates are as critical as the template's initial configuration to prevent privilege escalation.

ESC8 Attack Flow

1. Low-Privileged User

Identifies template with weak ACLs.

2. Modify Template Settings

Attacker uses WriteProperty rights to enable sensitive EKU/EA.

3. Enroll for New Certificate

Attacker enrolls for a certificate using the modified template.

4. Achieve Privilege Escalation

The new certificate grants elevated privileges, often leading to Domain Admin.
