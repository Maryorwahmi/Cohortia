Vulnerable Certificate Templates: Subject Name Control

Specifying Any User's Name in Certificate Requests

The Misconfiguration

A certificate template is configured with Supply in request for the subject name, allowing the requester to define the certificate's subject.

Attack Goal

A low-privileged attacker requests a certificate, specifying a highly privileged user's name (e.g., Domain Admin) as the subject, leading to impersonation.

Key Takeaway

Lack of subject name validation in certificate templates can enable attackers to forge identities and gain unauthorized access.

Subject Name Impersonation

1. Vulnerable Template Identified

Template allows 'Supply in request' for Subject Name.

2. Attacker Crafts Request

Includes target user's name (e.g., 'Domain Admin') in the subject field.

3. CA Issues Certificate

Certificate Authority issues a valid certificate for the specified subject.

4. Impersonation Achieved

Attacker uses the certificate to authenticate as the target user.
