Attack Vector

ESC1: Enrollment Agent Template Abuse

Impersonating Users via Misconfigured Certificate Templates

The Misconfiguration

A certificate template allows users to enroll for a certificate with both Client Authentication (or Any Purpose) and Enrollment Agent functionality.

Attack Goal

Obtain an Enrollment Agent certificate, then use it to request a certificate on behalf of a highly privileged user (e.g., Domain Admin) for impersonation.

Key Takeaway

ESC1 is a direct path to Domain Admin by leveraging a trusted PKI component to forge identities.

ESC1 Attack Flow

1. Low-Privileged User

Identifies vulnerable template.

2. Enroll for Enrollment Agent Cert

Attacker obtains certificate with 'Enrollment Agent' rights.

3. Request Cert on Behalf of DA

Using EA cert, attacker requests a new certificate for a Domain Admin.

4. Impersonate Domain Admin

Attacker uses DA's certificate for authentication and privilege escalation.
