Key Concepts

Essential terms from advanced AD attacks

Active Directory Certificate Services (AD CS)

Microsoft's PKI implementation for issuing and managing digital certificates within an AD environment.

ESC1 (Enrollment Agent Template Abuse)

An AD CS misconfiguration allowing an attacker to enroll for an Enrollment Agent certificate and request certificates on behalf of other users.

ESC8 (Weak Certificate Template ACLs)

An AD CS misconfiguration where a template's ACL allows low-privileged users to modify it, leading to privilege escalation.

Summary Takeaway

AD CS misconfigurations like ESC1 and ESC8 are critical attack vectors, often exploited by tools like Certify.exe for privilege escalation.
