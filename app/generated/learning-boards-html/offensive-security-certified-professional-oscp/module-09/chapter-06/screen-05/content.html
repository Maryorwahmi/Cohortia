GPO Mechanics

GPO Structure and Application Hierarchy

How policies are linked and enforced

Key GPO Settings

  • Security Options (e.g., password policies)
  • Software Deployment (MSI packages)
  • Startup/Shutdown Scripts (batch, PowerShell)
  • Restricted Groups (local admin rights)
  • Scheduled Tasks (immediate tasks)

GPO Linking & Precedence

  • Linked to Sites, Domains, or Organizational Units (OUs).
  • Applied hierarchically: Site > Domain > OU.
  • Lower-level settings can override higher-level ones.
  • 'Enforced' GPOs override all lower-level policies.
Key Takeaway

The hierarchical application and 'Enforced' status of GPOs create complex policy interactions, which are often overlooked and can be exploited by attackers.
