Learning Objectives

What you'll achieve in this chapter

Bloom's Taxonomy:
Learn Understand Apply Master
01

Explain GPO Purpose

Understand the core function of Group Policy Objects in Active Directory for centralized management. This knowledge forms the baseline for identifying deviations and potential misconfigurations.

VERIFIED COMPETENCY MILESTONE
02

Identify Abusable Settings

Pinpoint specific GPO settings that can be exploited for privilege escalation or persistence. This involves recognizing common attack vectors like 'Restricted Groups' or script deployment.

VERIFIED COMPETENCY MILESTONE
03

Utilize GPO Enumeration Tools

Learn to effectively use `gpresult`, `BloodHound`, and PowerShell cmdlets to enumerate and analyze GPOs. These tools are critical for discovering GPO configurations and their impact.

VERIFIED COMPETENCY MILESTONE
