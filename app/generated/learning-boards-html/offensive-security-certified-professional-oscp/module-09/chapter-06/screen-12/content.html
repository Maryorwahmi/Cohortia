Other Attack Vectors

Additional GPO Abuse Scenarios

Beyond the common misconfigurations

LAPS Misconfigurations

  • LAPS secures local admin passwords.
  • Weak ACLs on the LAPS GPO can allow attackers to read stored passwords.
  • Detection: Examine ACLs on the LAPS GPO and `ms-Mcs-AdmPwd` attribute.

Software Installation

  • GPOs deploy MSI packages for software installation.
  • Attackers can modify the MSI or the deployment share.
  • Result: Malicious software pushed to target machines.
Key Takeaway

Beyond common script and group abuses, LAPS and software deployment GPOs can also be misconfigured, offering diverse paths for privilege escalation and persistence.
