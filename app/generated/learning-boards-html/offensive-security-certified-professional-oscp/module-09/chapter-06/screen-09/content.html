Common Abuse Scenario

GPO Abuse: Restricted Groups

A classic path to local administrator rights

What are Restricted Groups?

A GPO setting that specifies which users or groups should be members of local groups (e.g., Administrators) on target machines. Intended for security, but often misconfigured.

Exploitation Example

A GPO adds Domain Users to the local Administrators group on all machines in WORKSTATION_OU. If you compromise any Domain User account, you gain local admin on all workstations in that OU.

Detection Methods

  • Review GPO reports for 'Restricted Groups' settings.
  • Use BloodHound's queries to find GPOs granting local admin rights.
  • Look for broad group memberships (e.g., 'Domain Users') in local `Administrators`.
Key Takeaway

'Restricted Groups' misconfigurations are a direct and common way to achieve widespread local administrator privileges for low-privileged users.

Restricted Groups Attack Flow
1. Compromise Domain User
2. GPO Adds User to Local Admins
3. Log in to Workstation
4. Achieve Local Admin Rights
This simple chain can lead to widespread privilege escalation.
