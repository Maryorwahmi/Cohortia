Key Concepts: GPO Abuse & Tools

Essential tools and attack vectors

Startup/Shutdown Scripts

GPO settings that deploy scripts running with `SYSTEM` privileges during system startup or shutdown.

Immediate Tasks

GPO settings that allow the creation of scheduled tasks on target machines, which can be configured to run with specific privileges.

`gpresult`

A Windows command-line utility used to display the Resultant Set of Policy (RSoP) for a user and computer.

`Get-GPO`

A PowerShell cmdlet used to retrieve comprehensive information about Group Policy Objects across the domain.

Summary Takeaway

Leveraging GPO-deployed scripts and tasks, combined with effective enumeration using `gpresult` and PowerShell, are key to uncovering and exploiting GPO abuse vectors.
