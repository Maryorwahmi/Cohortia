Discovering Applied GPOs with `gpresult`

Your first step in GPO reconnaissance

What `gpresult` Does

  • Displays the Resultant Set of Policy (RSoP).
  • Shows GPOs applied to the current user and computer.
  • Reveals GPO precedence and effective settings.
  • Essential for initial local GPO reconnaissance.

Command Syntax

gpresult /R /Scope Computer
gpresult /R /Scope User

The `/R` switch provides a summary report. Specify `/Scope Computer` or `/Scope User` to filter results.

Key Takeaway

`gpresult` is crucial for understanding the immediate GPO landscape on a target machine, but it only shows applied policies, not all domain GPOs.

`gpresult` Output Example (Simplified)
...
Applied Group Policy Objects
-----------------------------
    Default Domain Policy
    Workstation Security Policy
    Software Deployment GPO
...
The user is a part of the following security groups
---------------------------------------------------
    Domain Users
    ...

Interpretation: This output shows three GPOs applied to the current context. You would then investigate 'Workstation Security Policy' and 'Software Deployment GPO' for potential misconfigurations.

Pro Tip: Look for custom GPO names. Default policies are often hardened, but custom ones are more prone to misconfigurations.
