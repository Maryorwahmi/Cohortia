Common Abuse Scenario

GPO Abuse: Startup/Shutdown Scripts

Injecting malicious code via system scripts

How it Works

  • GPOs deploy scripts (batch, PowerShell) that run with `SYSTEM` privileges.
  • Scripts execute during system startup or shutdown.
  • If an attacker can modify the script or its network share, they can inject malicious code.

Exploitation Example

A GPO runs \\DC01\NETLOGON\startup.bat. If an attacker has write access to the NETLOGON share, they can modify startup.bat to add a backdoor user or execute a reverse shell.

Detection Methods

  • Examine GPO settings for startup/shutdown scripts.
  • Check ACLs on the network paths where scripts are stored.
Key Takeaway

Weak permissions on GPO-deployed startup/shutdown scripts allow attackers to inject code that executes with `SYSTEM` privileges, leading to high-impact compromise.

Script Abuse Workflow
1. Identify GPO Script
2. Check Script Share ACLs
3. Modify Script with Malicious Code
4. Wait for System Startup/Shutdown
Malicious code executes with `SYSTEM` privileges.
