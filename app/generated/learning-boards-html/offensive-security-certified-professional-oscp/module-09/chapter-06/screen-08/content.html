Visualizing GPO Attack Paths with BloodHound

Connecting GPOs to privilege escalation

How BloodHound Helps

  • Collects GPO link and effect data via `SharpHound`.
  • Visualizes GPOs granting local admin rights.
  • Maps GPOs modifying security settings.
  • Identifies GPOs deploying scripts with elevated privileges.
  • Simplifies complex GPO relationships into clear attack paths.

Example Scenario

BloodHound can show if a GPO linked to an OU with sensitive servers has a 'Restricted Groups' policy that adds a low-privileged user to the local Administrators group on those servers. This is a direct path to local privilege escalation.

Key Takeaway

BloodHound is invaluable for visualizing the impact of GPOs on attack paths, transforming raw data into actionable insights for privilege escalation.
