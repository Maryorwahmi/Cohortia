Core Definition

Bypassing Password Authentication

Pass-the-Hash (PtH) and Pass-the-Ticket (PtT) are post-exploitation techniques that allow an attacker to authenticate to remote systems or services using stolen NTLM hashes or Kerberos tickets, respectively, without ever needing the plaintext password.

Why It Matters

Enabling Lateral Movement

These attacks are crucial for lateral movement and privilege escalation within Active Directory. They allow attackers to move between systems and access resources as a compromised user, even if the password is unknown.

Key Distinction

Hash vs. Ticket

PtH exploits NTLM authentication using NTLM hashes, while PtT exploits Kerberos authentication using Kerberos tickets (TGTs or STs). Both achieve similar goals but leverage different protocols.

Key Takeaway

PtH and PtT are powerful techniques that bypass traditional password authentication, making them essential for advanced post-exploitation in Active Directory environments.
