Learning Objectives

By the end of this chapter, you will be able to:

Bloom's Taxonomy:LearnUnderstandApplyMaster
01

Explain PtH & PtT Concepts

Articulate the core principles of Pass-the-Hash and Pass-the-Ticket attacks, including their underlying authentication mechanisms. This skill is vital for understanding how these techniques bypass traditional password security.

VERIFIED COMPETENCY MILESTONE
02

Utilize Impacket for PtH

Employ Impacket's `psexec.py`, `wmiexec.py`, and `pth-winexe` scripts to perform Pass-the-Hash attacks for lateral movement. This practical skill allows you to gain remote access using stolen NTLM hashes.

VERIFIED COMPETENCY MILESTONE
03

Understand Kerberos Tickets

Grasp the process of creating and using Kerberos tickets, including Golden and Silver Tickets, for authentication without a password. This knowledge is fundamental for advanced Kerberos exploitation.

VERIFIED COMPETENCY MILESTONE
04

Execute PtT & Identify Prerequisites

Execute Pass-the-Ticket attacks using Mimikatz to inject tickets and impersonate users, and identify the conditions necessary for successful PtH and PtT attacks. This combines practical execution with critical situational awareness.

VERIFIED COMPETENCY MILESTONE
