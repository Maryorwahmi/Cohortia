Mimikatz PtH Usage
mimikatz.exe
sekurlsa::pth /user:administrator /domain:corp.local /ntlm:31d6cfe0d16ae931b73c59d7e0c089c0 /run:cmd.exe
Command Breakdown

Understanding the Parameters

  • sekurlsa::pth: The Mimikatz module for Pass-the-Hash.
  • /user:<username>: Specifies the user account to impersonate.
  • /domain:<domain_name>: Specifies the domain of the user.
  • /ntlm:<ntlm_hash>: The NTLM hash of the target user.
  • /run:<command>: The command to execute with the injected hash, typically `cmd.exe`.
How It Works

In-Memory Hash Injection

Mimikatz's `sekurlsa::pth` module injects the NTLM hash directly into the current process's logon session. This creates a new authentication context, allowing subsequent actions or launched processes to authenticate as the specified user.

Key Advantage

Local Privilege Escalation & Lateral Movement

This technique is highly effective for escalating privileges on a compromised Windows host or for initiating lateral movement from that host to other systems within the domain, leveraging the injected credentials.

Key Takeaway

Mimikatz provides a powerful Windows-native method for PtH by injecting NTLM hashes directly into memory, enabling local privilege escalation and lateral movement.
