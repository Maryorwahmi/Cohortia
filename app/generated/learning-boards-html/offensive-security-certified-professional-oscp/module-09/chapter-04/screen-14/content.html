Key Concepts: PtH & PtT Fundamentals

A quick recap of the essential ideas from this chapter.

Pass-the-Hash (PtH)

An attack where an attacker authenticates to a remote system using a user's NTLM hash, without knowing the plaintext password.

Pass-the-Ticket (PtT)

An attack where an attacker authenticates to a remote system or service using a stolen or forged Kerberos ticket, without knowing the user's password or hash.

Impacket

A collection of Python classes for working with network protocols, including indispensable tools for PtH, PtT, and other Active Directory attacks.

Summary Takeaway

PtH and PtT are foundational post-exploitation techniques that bypass traditional password authentication by leveraging NTLM hashes and Kerberos tickets, with Impacket being a key tool for their execution.
