Silver Ticket Definition

Forged Service Ticket (ST)

A Silver Ticket is a forged Kerberos Service Ticket (ST) that grants an attacker access to a *specific* service on a *specific* server. It's a more targeted attack compared to the domain-wide access of a Golden Ticket.

Critical Credential

Service Account NTLM Hash

To forge a Silver Ticket, you need the NTLM hash of the *service account* running the target service (or the computer account's NTLM hash if the service runs as LocalSystem). This is distinct from the `krbtgt` hash.

Stealth Advantage

No KDC Validation

Silver Tickets are often stealthier because they do not involve the Key Distribution Center (KDC) for validation once injected. This makes them harder to detect by traditional Kerberos monitoring tools.

Key Takeaway

Silver Tickets offer targeted, stealthy access to specific services by forging STs using the service account's NTLM hash, bypassing KDC validation.

Silver Ticket Prerequisites
  • Domain Name: e.g., `corp.local`
  • Domain SID: e.g., `S-1-5-21-1234567890-1234567890-1234567890`
  • Service Account NTLM Hash: For the target service.
  • Service Principal Name (SPN): e.g., `cifs/server01.corp.local`
  • Desired User to Impersonate: e.g., `administrator`
Mimikatz Silver Ticket Command
mimikatz.exe
kerberos::golden /user:administrator /domain:corp.local /sid:S-1-5-21-1234567890-1234567890-1234567890 /rc4:<service_account_ntlm_hash> /service:cifs/server01.corp.local /target:server01.corp.local /ptt
Use Case

Targeted Persistence & Access

Silver Tickets are ideal for maintaining persistence on specific high-value servers or services, allowing an attacker to access resources like file shares or databases without triggering broader domain alerts.
