PtH Definition

Authenticating with NTLM Hashes

Pass-the-Hash (PtH) is an attack where an attacker uses a user's NTLM hash to authenticate to a remote system, bypassing the need for the plaintext password. This exploits the NTLM challenge-response protocol.

How NTLM Works

Challenge-Response Mechanism

Instead of sending a password, the client encrypts a server-provided challenge with the user's NTLM hash. The server does the same and compares the results. If they match, authentication succeeds.

Prerequisite for Success

Local Administrator Privileges

For a PtH attack to grant an administrative shell on a target, the user whose hash is used must have local administrative privileges on that specific target machine.

Key Takeaway

PtH leverages NTLM hashes to impersonate users, but its effectiveness for administrative access depends on the compromised user's local privileges on the target system.
