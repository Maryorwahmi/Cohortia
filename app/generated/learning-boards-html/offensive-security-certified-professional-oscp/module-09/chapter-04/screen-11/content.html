Golden Ticket Definition

Forged Ticket Granting Ticket (TGT)

A Golden Ticket is a forged Kerberos TGT that grants an attacker indefinite access to any service in the domain as any user, including Domain Admins. It represents a complete compromise of the Active Directory domain.

Critical Credential

The `krbtgt` Account NTLM Hash

The most crucial piece of information for forging a Golden Ticket is the NTLM hash of the `krbtgt` account. This account is responsible for encrypting and signing all Kerberos TGTs, making its hash the master key for the domain.

Attack Tool

Mimikatz for Creation & Injection

Mimikatz is the primary tool used to create and inject Golden Tickets. It requires the domain name, domain SID, `krbtgt` hash, and the desired user to impersonate. The `/ptt` flag injects the ticket directly.

Key Takeaway

Golden Tickets provide ultimate domain control by forging TGTs using the `krbtgt` hash, allowing indefinite impersonation of any user across all services.

Golden Ticket Prerequisites
  • Domain Name: e.g., `corp.local`
  • Domain SID: e.g., `S-1-5-21-1234567890-1234567890-1234567890`
  • `krbtgt` Account NTLM Hash: Obtained by compromising a Domain Controller.
  • Desired User to Impersonate: e.g., `administrator`
Mimikatz Golden Ticket Command
mimikatz.exe
kerberos::golden /user:administrator /domain:corp.local /sid:S-1-5-21-1234567890-1234567890-1234567890 /krbtgt:<krbtgt_ntlm_hash> /ptt
Security Implication

Complete Domain Compromise

A successful Golden Ticket attack grants an attacker full control over the Active Directory domain, making it one of the most severe post-exploitation outcomes. Protecting the `krbtgt` hash is paramount.
