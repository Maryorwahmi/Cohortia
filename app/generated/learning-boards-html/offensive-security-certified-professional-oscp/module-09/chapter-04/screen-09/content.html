Critical Prerequisite

Local Administrator Rights on Target

For a PtH attack to yield an administrative shell on a remote machine, the user whose NTLM hash is used must possess local administrative privileges on that specific target system. Domain Admin rights alone are not sufficient for local execution.

Common Mistake

Assuming Domain Admin = Local Admin

A common misconception is that a Domain Admin hash automatically grants local admin rights on all domain-joined machines. This is not always true, especially in hardened environments where local admin groups are restricted.

Impact of Missing Privileges

Limited or Failed Access

If the user's hash does not correspond to a local administrator on the target, the PtH attack will either fail to authenticate or result in a non-administrative shell, limiting lateral movement capabilities.

Key Takeaway

Always confirm the target user's local administrative privileges on the specific machine you intend to compromise via PtH to ensure successful administrative access.
