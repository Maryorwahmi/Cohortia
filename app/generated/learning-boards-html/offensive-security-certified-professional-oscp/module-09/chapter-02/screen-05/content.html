Nmap for Initial AD Reconnaissance

Identifying Services and Basic Information

nmap -p 53,88,135,139,389,445,464,636,3268,3269 \
     --script "smb-enum-users,ldap-search,smb-os-discovery" \
     -sV <DC_IP>
Common Mistake

Running Nmap without specific AD scripts misses valuable initial enumeration data.

Key Takeaway

Leverage Nmap's script engine with AD-specific scripts to gain deep initial insights into services and potential user accounts.

Target AD Ports

Scan common AD ports (88, 135, 139, 389, 445, 636) to identify core services.

Leverage Nmap Scripts

Use scripts like `smb-enum-users` and `ldap-search` for deeper, automated enumeration.

Identify OS & Services

The `-sV` flag and `smb-os-discovery` script help identify the operating system and service versions.
