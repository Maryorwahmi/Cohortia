Learning Objectives
Skills for Uncovering Active Directory Secrets
Bloom's Taxonomy:
LearnUnderstandApplyMaster
01

Execute Reconnaissance Techniques

Learn to discover Active Directory domain information, including domain names, user accounts, groups, and computer objects. This skill is vital for mapping the target environment's structure.

VERIFIED COMPETENCY MILESTONE
02

Utilize Common Enumeration Tools

Gain proficiency with tools like nmap, enum4linux, ldapsearch, and PowerView to gather intelligence from an AD environment. This ensures you can extract data efficiently.

VERIFIED COMPETENCY MILESTONE
03

Interpret Key AD Object Attributes

Learn to identify and interpret key attributes of AD objects that are valuable for subsequent attack phases. This includes understanding their security implications.

VERIFIED COMPETENCY MILESTONE
04

Understand DNS, SMB, LDAP Exploitation

Grasp the importance of DNS, SMB, and LDAP in the enumeration process and how to exploit their functionalities. This knowledge is crucial for targeted attacks.

VERIFIED COMPETENCY MILESTONE
