Phases 4 & 5: Gaining and Maintaining Access

Exploiting Vulnerabilities and Establishing Persistence

Gaining Access

Leveraging identified vulnerabilities (e.g., buffer overflows, SQL injection) to achieve initial unauthorized access to the target system.

Maintaining Access

Establishing persistent access through backdoors, rootkits, or new user accounts to simulate a long-term compromise.

Exploitation Scenario

Consider a web application vulnerable to SQL injection. An attacker could exploit this to bypass login authentication (gaining access). Once inside, they might upload a web shell and create a new administrative user account to ensure they can return later, even if the SQL injection vulnerability is patched (maintaining access).

Key Takeaway

Exploitation leads to initial access, which is then secured for long-term assessment to understand the impact of a sustained compromise.
