Phases 2 & 3: Scanning and Enumeration

Actively Discovering and Detailing Target Information

Scanning

Direct interaction with target systems to identify live hosts, open ports, running services, and OS versions (e.g., using Nmap).

Enumeration

Extracting more detailed information from identified services and hosts, such as user accounts, specific software versions, or hidden directories.

Scanning & Enumeration Example

A Nmap scan might reveal that a web server is running on port 80. Following this, enumeration tools could then identify that the server is running Apache 2.4.x and has a publicly accessible /dev directory, which might contain sensitive development files. This detailed information is crucial for the next phase.

Key Takeaway

Scanning and enumeration provide the detailed insights needed for effective exploitation by mapping the network and detailing services.
