Penetration Test Phase

Phase 1: Reconnaissance

Gathering Intelligence Without Direct Interaction

Definition

The initial phase of gathering as much information about the target as possible without directly interacting with it.

Key Techniques

Includes Open-Source Intelligence (OSINT), domain registration lookups, social media analysis, and public data searches.

Goal

To build a comprehensive profile of the target's infrastructure, employees, and technologies to identify potential entry points.

OSINT Example: Google Dorks

Using advanced search operators like site:example.com filetype:pdf can reveal publicly accessible documents that might contain sensitive information, such as internal network diagrams or employee lists. Similarly, searching LinkedIn for employees of a target company can provide insights into their roles and technologies used.

Key Takeaway

Thorough reconnaissance provides a strong, low-risk foundation for subsequent testing phases by minimizing footprint and maximizing intelligence.
