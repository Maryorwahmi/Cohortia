Software & Bootloader

Kali Installation: Software Selection and GRUB

Finalizing the core system and boot configuration.

Final Installation Steps

  • •Software Selection: Keep default options (GNOME desktop, standard utilities).
  • •GRUB Boot Loader: Install GRUB to the master boot record (MBR) of your virtual hard disk (e.g., /dev/sda).
  • •Finish Installation: Allow the installer to complete.
  • •Remove ISO: Crucially, unmount the Kali ISO before rebooting.
  • •Reboot: Restart your VM into the new Kali Linux system.
Key Takeaway

Accept default software selections, install GRUB to the MBR (e.g., /dev/sda), and remember to unmount the ISO before rebooting into your new Kali system.

Bootloader Importance

GRUB: Grand Unified Bootloader

Manages the boot process for Linux systems.

MBR: Master Boot Record

The primary boot sector of a hard disk, essential for starting the OS.

Critical Reminder

Forgetting to remove the ISO image from the virtual drive before rebooting is a common oversight. This will cause your VM to boot back into the installer, preventing you from reaching your newly installed Kali system.
