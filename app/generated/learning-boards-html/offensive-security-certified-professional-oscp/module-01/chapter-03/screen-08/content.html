User & Disk Setup

Kali Installation: User Account and Disk Partitioning

Securing your system and allocating storage space.

Key Configuration Points

  • •Non-root User: Create a standard user account for daily operations.
  • •Strong Password: Essential for account security.
  • •Guided Partitioning: Use "Guided - Use entire disk" for simplicity in VMs.
  • •Disk Selection: Choose the virtual hard disk you created.
  • •Confirm Changes: Review partitioning summary before writing to disk.
Key Takeaway

Create a non-root user with a strong password for security, and use 'Guided - Use entire disk' for straightforward partitioning in your Kali VM.

User & Disk Best Practices

Non-Root User

Minimizes risk of system damage or compromise.

Strong Password

Protects your user account from unauthorized access.

Guided Partitioning

Simplifies disk setup for virtual environments.

Review & Confirm

Prevents accidental data loss on the virtual disk.

Misconception

A common mistake is to log in as the 'root' user for daily tasks. While powerful, this bypasses many security checks and makes your system highly vulnerable to errors or malicious actions. Always use a non-root user and elevate privileges with 'sudo' when necessary.
