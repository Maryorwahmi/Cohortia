Key Concepts

Essential terms from this chapter.

Kali Linux

A Debian-based Linux distribution specifically designed for penetration testing and digital forensics.

ISO Image

A disk image file containing an exact copy of an entire data CD or DVD, used for OS installation.

SHA256 Checksum

A cryptographic hash function used to verify the integrity and authenticity of a file, preventing tampering.

Summary Takeaway

Kali Linux is the specialized OS for pentesting, installed via an ISO image whose integrity must be verified using a SHA256 checksum.
