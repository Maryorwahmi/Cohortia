Installation Process

Initiating the Kali Graphical Installation

Starting the guided setup for your new attacker machine.

Initial Setup Steps

  • •Mount ISO: Attach the Kali ISO to your VM's virtual CD/DVD drive.
  • •Boot VM: Start the virtual machine to launch the installer.
  • •Graphical Install: Select this option from the boot menu for a user-friendly interface.
  • •Locale Settings: Choose your language, location, and keyboard layout.
  • •Network Config: Provide a hostname (e.g., kali-oscp) and optional domain.
Key Takeaway

Begin Kali installation by mounting the ISO, booting the VM, selecting 'Graphical install,' and configuring initial locale and network settings.

Why it Matters

Properly configuring the hostname and network during installation ensures your Kali machine is identifiable and can communicate effectively, which is fundamental for any penetration testing activity.
