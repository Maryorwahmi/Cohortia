Configuring Host-Only Network

Step-by-Step Isolation in Your Hypervisor

1.Access VM Settings

With Metasploitable2 powered off, open its settings in your hypervisor (VirtualBox or VMware).

2.Navigate to Network

Find and select the "Network" section in the VM's configuration menu.

3.Set Adapter Type

  • VirtualBox: Set "Attached to:" to `Host-Only Adapter`.
  • VMware Player: Set "Attached to:" to `Host-only (VMnet1)`.

Understanding Host-Only

A Host-Only network creates a private virtual network between your host machine and its VMs. It's ideal for lab environments where VMs need to communicate with each other and the host, but not the external internet.

Key Takeaway

Host-Only networking is the safest choice for vulnerable VMs, ensuring they are isolated from your external network while allowing internal lab communication.

Important Note

Ensure your Kali Linux VM is also configured to the *same* Host-Only network adapter to enable communication between attacker and target.
