Tool Spotlight

Introducing Metasploitable2 and OWASP BWA

Your Go-To Vulnerable Targets for Practice

Metasploitable2: The All-Rounder

  • Developed by Rapid7, Ubuntu-based Linux distribution.
  • Packed with dozens of intentionally vulnerable services.
  • Includes FTP, SSH, Samba, Tomcat, MySQL, PostgreSQL.
  • Features vulnerable web apps like DVWA and Mutillidae.
  • Ideal for beginners to practice diverse exploitation techniques.

OWASP BWA: Web App Focus

  • OWASP Broken Web Applications Project.
  • Collection of web applications with common vulnerabilities.
  • Excellent for focused web application penetration testing.
  • Examples include SQL injection, XSS, broken authentication.
  • Complements Metasploitable2 for a comprehensive lab.

Why These?

These VMs offer a wide array of real-world vulnerabilities in a controlled setting. They are well-documented and widely used in the cybersecurity community, making them excellent choices for OSCP preparation and general skill development.

Key Takeaway

Metasploitable2 and OWASP BWA are foundational vulnerable VMs, providing diverse and realistic targets for developing penetration testing skills.

Pro Tip

Start with Metasploitable2 due to its broad range of vulnerabilities. Once comfortable, explore OWASP BWA for deeper web application testing.
