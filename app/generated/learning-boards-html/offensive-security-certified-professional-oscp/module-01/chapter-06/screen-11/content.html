Verifying Connectivity with Ping

Ensuring Your Attacker Can Reach the Target

1.Ensure Both VMs Running

Verify both Kali Linux and Metasploitable2 VMs are powered on and configured on the same Host-Only network.

2.Open Kali Terminal

Switch to your Kali Linux VM and open a new terminal window.

3.Ping the Target IP

Execute ping -c 4 <Metasploitable2_IP_address> (e.g., ping -c 4 192.168.56.102).

Expected Output

PING 192.168.56.102 (192.168.56.102) 56(84) bytes of data.
64 bytes from 192.168.56.102: icmp_seq=1 ttl=64 time=0.500 ms
64 bytes from 192.168.56.102: icmp_seq=2 ttl=64 time=0.480 ms
...
--- 192.168.56.102 ping statistics ---
4 packets transmitted, 4 received, 0% packet loss, time 3003ms

Successful replies indicate connectivity. If you see "request timed out", troubleshoot network settings.

Key Takeaway

Successful `ping` replies confirm basic network connectivity, a prerequisite for any further reconnaissance or exploitation.

Troubleshooting Tip

If `ping` fails, check VM network adapter settings (Host-Only), IP addresses (ifconfig on both VMs), and ensure no firewalls are blocking ICMP.
