Performing Initial Nmap Scan

Discovering Open Ports and Services on the Target

1.Open Kali Terminal

Ensure Kali Linux is running and has connectivity to Metasploitable2. Open a new terminal.

2.Execute Nmap Scan

Run the following command, replacing the IP with your Metasploitable2's IP address:

nmap -sV -sC -oA metasploitable_scan_results 192.168.56.102

3.Review Output Files

Check the generated files (.nmap, .xml, .gnmap) for detailed scan results.

Nmap Flags Explained

  • -sV: Attempts to determine service versions on open ports.
  • -sC: Runs default Nmap scripts for basic enumeration.
  • -oA <basename>: Outputs results in all formats (normal, XML, grepable) to files with the specified basename.
Key Takeaway

An initial `nmap` scan is fundamental for active reconnaissance, revealing open ports and services that represent potential attack vectors.

Pro Tip

Always save your `nmap` results. They are invaluable for later stages of penetration testing, including vulnerability analysis and exploitation.
