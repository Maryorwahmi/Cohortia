Importing Metasploitable2 into Your Hypervisor

Creating the Virtual Machine in VirtualBox or VMware

1.VirtualBox: Create New VM

  • Click `New`, name it `Metasploitable2`.
  • Type: `Linux`, Version: `Ubuntu (64-bit)`.
  • Memory: `1024 MB`, CPU: `1`.

2.VirtualBox: Use Existing Disk

For Hard Disk, choose `Use an existing virtual hard disk file` and select the extracted `Metasploitable.vmdk` file.

3.VMware Player: Open or Create

  • Option A: `Open a Virtual Machine` and select `Metasploitable.vmx`.
  • Option B: `Create a New Virtual Machine`, then point to the `Metasploitable.vmdk` as an existing disk.

Resource Allocation

While Metasploitable2 doesn't require many resources, allocating at least 1GB RAM and 1 CPU ensures it runs smoothly without impacting your host machine's performance significantly.

Key Takeaway

The key to importing is to select the pre-existing .vmdk file as the virtual hard disk, rather than creating a new one.

Pro Tip

Always double-check that you've selected the correct .vmdk file to avoid booting into an empty or incorrect OS.
