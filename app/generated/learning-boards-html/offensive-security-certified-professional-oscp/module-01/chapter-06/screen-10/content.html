First Boot and Default Credentials

Getting Started with Metasploitable2

1.Power On Metasploitable2

Start the VM. It will boot up and automatically log in to a console, presenting a command prompt.

2.Default Credentials

The default username is msfadmin and the password is msfadmin. These are for initial access and checks.

3.Identify IP Address

From the Metasploitable2 console, type ifconfig to find its dynamically assigned IP address on the Host-Only network.

ifconfig Output Example

eth0      Link encap:Ethernet  HWaddr 08:00:27:xx:xx:xx
          inet addr:192.168.56.102  Bcast:192.168.56.255  Mask:255.255.255.0
          UP BROADCAST RUNNING MULTICAST  MTU:1500  Metric:1
          ...

Look for the inet addr under the active network interface (e.g., eth0).

Key Takeaway

After booting, identify Metasploitable2's IP address using ifconfig, as this IP is your target for all subsequent attacks.

Pro Tip

While msfadmin is the default, in real-world scenarios, you'd never know credentials beforehand. This is purely for lab practice.
