Chapter Summary

Key Concepts

Essential terms from this chapter

Virtualization

Creating virtual versions of OS, servers, or resources on a single physical machine.

Hypervisor

Software that creates and runs virtual machines (VMs), also known as a VMM.

Virtual Machine (VM)

An emulation of a computer system, running as a guest OS on a host machine.

Host & Guest OS

Host OS is on the physical computer; Guest OS runs inside the VM.

Type 1 Hypervisor

'Bare-metal' hypervisor that runs directly on the host hardware (e.g., VMware ESXi).

Type 2 Hypervisor

'Hosted' hypervisor that runs as an application on top of a host OS (e.g., VirtualBox).

Summary Takeaway

Understanding virtualization fundamentals, including hypervisors and VMs, is crucial for building a secure and effective penetration testing lab.
