Network Modes Comparison

NAT vs. Bridged: Internet Access & Exposure

Understanding Connectivity and Risks

NAT (Network Address Translation)

  • VM shares host's IP address
  • Can access the internet via host
  • Cannot be directly accessed from host/LAN
  • Good isolation from home network
Use Case

Attacker VM needs internet for updates, but targets should not be exposed.

Bridged Adapter

  • VM acts as a full participant on physical network
  • Obtains its own IP from router (DHCP)
  • Easy communication with host/other physical machines
  • VM is exposed to your home network (security risk)
Use Case

Generally avoided for vulnerable targets in a pentesting lab due to exposure.
