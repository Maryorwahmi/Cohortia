File Content Viewing

Displaying File Contents

Quickly Inspecting Text Files and Logs

Tools for Viewing Files

  • •cat: Displays entire file contents to standard output, best for small files.
  • •less: Allows scrolling forward and backward through large files page by page.
  • •more: Similar to less, but typically only allows forward scrolling.
Key Takeaway

Choose the right command for the file size: cat for quick checks of small files, and less (preferred) or more for navigating extensive logs or configuration files.

Command Walkthrough: cat & less
# 1. Display contents of /etc/passwd (small file)
kali@kali:~$ cat /etc/passwd
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
... (user entries)

# 2. View a larger log file with 'less'
kali@kali:~$ less /var/log/syslog
Feb 20 10:00:01 kali systemd[1]: Starting Cleanup of Temporary Directories...
Feb 20 10:00:01 kali systemd[1]: Finished Cleanup of Temporary Directories.
... (scrollable content)

# 3. View a large wordlist with 'more'
kali@kali:~$ more /usr/share/wordlists/rockyou.txt
password
123456
... (press space to continue, 'q' to quit)

Practical Tip

When analyzing logs for specific keywords, you can combine cat with grep: cat /var/log/auth.log | grep "Failed password" to filter output before viewing.
