Ownership & Processes

Changing Ownership and Introduction to Processes

Assigning Control and Monitoring System Activity

Key Concepts

  • •chown: Changes the owner and/or group of a file or directory.
  • •Accountability: Ensures correct users/services control specific resources.
  • •Process: An instance of a running program.
  • •Monitoring: Essential for identifying suspicious activity and managing resources.
Key Takeaway

Managing file ownership with chown and understanding system processes are fundamental for maintaining control and security within a Linux environment.

Command Walkthrough: chown
# 1. Create a file owned by current user
kali@kali:~$ touch my_file.txt
kali@kali:~$ ls -l my_file.txt
-rw-r--r-- 1 kali kali 0 Feb 20 15:30 my_file.txt

# 2. Change owner and group to 'root' (requires sudo)
kali@kali:~$ sudo chown root:root my_file.txt
kali@kali:~$ ls -l my_file.txt
-rw-r--r-- 1 root root 0 Feb 20 15:30 my_file.txt

# 3. Change owner back to 'kali'
kali@kali:~$ sudo chown kali my_file.txt
kali@kali:~$ ls -l my_file.txt
-rw-r--r-- 1 kali root 0 Feb 20 15:30 my_file.txt

Process Management Context

Understanding which user owns a running process is critical. If a web server process is running as 'root', it's a significant security concern, as a compromise could grant full system control.
