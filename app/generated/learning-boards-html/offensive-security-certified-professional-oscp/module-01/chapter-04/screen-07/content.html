File Manipulation

Moving, Renaming, and Deleting Files

Managing Your Digital Assets Responsibly

Critical File Operations

  • •mv: Moves files/directories or renames them.
  • •rm: Deletes files.
  • •rm -r: Recursively deletes directories and their contents.
  • •WARNING: rm -rf / can delete your entire system without warning. Use with extreme caution.
Key Takeaway

Always verify your target and command syntax when using mv and especially rm to prevent accidental data loss or system damage.

Command Walkthrough: mv & rm
# 1. Move a script to a new directory
kali@kali:~$ mv my_script.sh /opt/scripts/

# 2. Rename a file
kali@kali:~$ touch old_name.txt
kali@kali:~$ mv old_name.txt new_name.txt
kali@kali:~$ ls
new_name.txt ...

# 3. Remove a file
kali@kali:~$ rm unwanted_file.txt

# 4. Remove a directory and its contents (recursive)
kali@kali:~$ mkdir temp_dir
kali@kali:~$ touch temp_dir/temp_file.txt
kali@kali:~$ rm -r temp_dir

Common Mistake: rm -rf /

This command forcefully and recursively deletes everything from the root directory. It's extremely dangerous and can render your system unusable. Always be cautious with rm, especially with -f and -r.
