File Manipulation

Creating and Copying Files & Directories

Organizing Your Pentesting Workspace

Core Operations

  • •mkdir: Creates new directories to structure your projects.
  • •cp: Duplicates files or directories, preserving the original.
  • •cp -r: Used for recursive copying of directories and their contents.
Key Takeaway

Proper use of mkdir and cp ensures your pentesting resources are organized and accessible without modifying critical system files.

Command Walkthrough: mkdir & cp
# 1. Create a new directory
kali@kali:~$ mkdir my_tools
kali@kali:~$ ls
Desktop Documents Downloads Music my_tools Pictures Public Templates Videos

# 2. Copy a file to the current directory
kali@kali:~$ cp /usr/share/wordlists/rockyou.txt .
kali@kali:~$ ls
Desktop Documents Downloads Music my_tools Pictures Public rockyou.txt Templates Videos

# 3. Copy a directory recursively
kali@kali:~$ mkdir source_dir
kali@kali:~$ touch source_dir/file1.txt
kali@kali:~$ cp -r source_dir destination_dir
kali@kali:~$ ls destination_dir
file1.txt

Common Use Case

Before modifying a critical configuration file, always make a backup copy using cp. For example: cp /etc/apache2/apache2.conf /etc/apache2/apache2.conf.bak.
