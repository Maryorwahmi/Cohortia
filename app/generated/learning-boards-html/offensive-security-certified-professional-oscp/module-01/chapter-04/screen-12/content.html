Process Control

Monitoring and Terminating Processes

Managing Running Applications with 'ps' and 'kill'

Process Management Tools

  • •ps aux: Lists all running processes with detailed information.
  • •PID: Process ID, a unique identifier for each running process.
  • •kill <PID>: Sends a graceful termination signal to a process.
  • •kill -9 <PID>: Forcefully terminates an unresponsive process (use as last resort).
Key Takeaway

Efficiently monitoring and terminating processes is vital for system health, resource management, and responding to unexpected or malicious activity.

Command Walkthrough: ps & kill
# 1. List all processes and filter for 'firefox'
kali@kali:~$ ps aux | grep firefox
kali      1234  0.5  2.1 123456 87654 ?        Sl   Feb20   0:15 /usr/lib/firefox/firefox
kali      5678  0.0  0.0   8760  2340 pts/0    S+   15:40   0:00 grep --color=auto firefox

# 2. Terminate the Firefox process (PID 1234)
kali@kali:~$ kill 1234

# 3. Forcefully terminate an unresponsive process (PID 9876)
kali@kali:~$ kill -9 9876

Pentesting Relevance

You might use ps aux to identify processes running as 'root' or other privileged users, which could be targets for privilege escalation exploits.
