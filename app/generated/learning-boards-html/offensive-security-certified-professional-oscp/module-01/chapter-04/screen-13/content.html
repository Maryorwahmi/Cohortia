Essential Commands for Initial Reconnaissance

Network Insight Tools

  • •ip addr: Displays network interface details (IP, MAC, etc.).
  • •ifconfig: Older command, similar functionality to ip addr.
  • •ping: Tests network connectivity to a host using ICMP packets.
  • •Reconnaissance: Crucial for determining if a target is alive and reachable.
Key Takeaway

ip addr and ping are your first steps in network reconnaissance, providing fundamental information about network interfaces and host reachability.

Command Walkthrough: ip addr & ping
# 1. Display all network interface information
kali@kali:~$ ip addr show

    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo

    inet 192.168.1.100/24 brd 192.168.1.255 scope global dynamic eth0

# 2. Ping google.com 4 times
kali@kali:~$ ping -c 4 google.com

Troubleshooting Tip

If ping fails, it could indicate a network issue, a firewall blocking ICMP, or the host simply being offline. It's a quick way to narrow down connectivity problems.
