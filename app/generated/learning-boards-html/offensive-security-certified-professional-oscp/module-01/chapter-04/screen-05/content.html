File System Navigation

Navigating Directories with 'cd' and 'find'

Efficiently Moving and Locating Files

Key Navigation Techniques

  • •cd ..: Move up to the parent directory.
  • •cd ~: Go directly to your home directory.
  • •cd /: Jump to the root directory.
  • •find: Powerful command to search for files based on name, type, size, and more.
Key Takeaway

Effective use of cd and find drastically reduces the time spent locating critical files and navigating complex file systems during an assessment.

Command Walkthrough: cd & find
# 1. Change to web root directory
kali@kali:~$ cd /var/www/html
kali@kali:/var/www/html$ pwd
/var/www/html

# 2. Move up one directory
kali@kali:/var/www/html$ cd ..
kali@kali:/var/www$ pwd
/var/www

# 3. Find all PHP files on the system
kali@kali:~$ find / -type f -name "*.php" 2>/dev/null
/var/www/html/index.php
/usr/share/php/example.php

# 4. Find a specific configuration file
kali@kali:~$ find /etc -name "apache2.conf"
/etc/apache2/apache2.conf

Pentesting Scenario

Imagine you've gained a shell on a target system. You can use find / -type f -name "*config*.php" to quickly locate web application configuration files that might contain database credentials or other sensitive information.
