Conceptualizing Network Communication

OSI and TCP/IP Models for Penetration Testers

Key Takeaway

Network models provide a structured framework for understanding communication flows, crucial for identifying attack surfaces and vulnerabilities.

Why it Matters for Pentesting

Understanding these models helps you pinpoint where vulnerabilities might exist, from application logic to network routing, guiding your attack strategy.

Concrete Example

If a web server is vulnerable to SQL injection, you know to focus on the Application Layer (HTTP) and how it interacts with the Transport Layer (TCP) on port 80 or 443.

OSI vs. TCP/IP Model Comparison

OSI Model (7 Layers)
  • 7. Application
  • 6. Presentation
  • 5. Session
  • 4. Transport Relevant
  • 3. Network Relevant
  • 2. Data Link Relevant
  • 1. Physical
TCP/IP Model (4 Layers)
  • 4. Application Relevant
  • 3. Transport Relevant
  • 2. Internet Relevant
  • 1. Network Access Relevant
Focus for Pentesting

For pentesting, we often focus on the Application, Transport, Internet/Network, and Data Link/Network Access layers to understand how services operate and where vulnerabilities might be exploited.
