Application Protocols

Key Services and Their Ports

HTTP, HTTPS, DNS, SMB, SSH, and FTP

Key Takeaway

Specific protocols govern common network services, each using designated ports, which are critical indicators for penetration testers during reconnaissance.

Why it Matters for Pentesting

Identifying open ports and their associated protocols allows you to quickly narrow down potential attack vectors and focus on known vulnerabilities for those services.

Pro Tip

Always verify the service running on a port, as administrators can change default port assignments. Don't just assume HTTP is on port 80.

Common Protocols and Default Ports

HTTP (Port 80)

Hypertext Transfer Protocol for unencrypted web traffic.

HTTPS (Port 443)

Secure HTTP for encrypted web traffic, using SSL/TLS.

DNS (Port 53 UDP/TCP)

Domain Name System, translates domain names to IP addresses.

SMB (Ports 139, 445)

Server Message Block for file and printer sharing on Windows. A frequent target.

SSH (Port 22)

Secure Shell for encrypted remote command-line access.

FTP (Ports 20, 21)

File Transfer Protocol for transferring files. Often misconfigured.
