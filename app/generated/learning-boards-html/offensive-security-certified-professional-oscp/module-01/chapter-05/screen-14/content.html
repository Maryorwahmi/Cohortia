Fundamental Network Concepts

Essential Terms for OSCP Success

OSI Model

A 7-layer conceptual framework for understanding network communication.

TCP/IP Model

A 4-layer practical model that describes internet communication.

IPv4

A 32-bit addressing scheme for identifying devices on a network.

Summary Takeaway

Understanding network models, IP addressing, and their distinctions provides the essential framework for effective penetration testing and target analysis.
