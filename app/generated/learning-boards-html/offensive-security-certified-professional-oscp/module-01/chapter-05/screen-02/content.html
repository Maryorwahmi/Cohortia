Differentiate Network Models

Distinguish between the OSI and TCP/IP Models, focusing on layers relevant to penetration testing. This helps you understand where vulnerabilities might exist in the communication stack.

VERIFIED COMPETENCY MILESTONE
02

Explain IPv4 Addressing

Explain the basics of IPv4 addressing, including private vs. public IPs and CIDR notation. This knowledge is fundamental for network reconnaissance and target identification.

VERIFIED COMPETENCY MILESTONE
03

Understand Subnetting Concepts

Understand fundamental subnetting concepts (network ID, host ID, broadcast address) and their impact on network segmentation. This helps in mapping network boundaries.

VERIFIED COMPETENCY MILESTONE
04

Identify Network Protocols & Ports

Identify and describe common network protocols (ARP, ICMP, TCP, UDP, HTTP, HTTPS, DNS, SMB, SSH, FTP) and their associated ports. This is key for reconnaissance.
