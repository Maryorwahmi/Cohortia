Network Segmentation

Dividing Networks with Subnetting

Understanding Network ID, Host ID, and Broadcast Address

Key Takeaway

Subnetting divides networks into smaller segments, defined by a Network ID, Host IDs for devices, and a Broadcast Address, all critical for network mapping.

Why it Matters for Pentesting

Accurate subnetting knowledge allows you to precisely define the scope of your target, identify potential network boundaries, and avoid scanning out-of-scope IPs.

Concrete Example

If you're given a target 192.168.1.0/24, you immediately know the network starts at .0, ends at .255, and hosts are .1 through .254.

Subnet Components: 192.168.1.0/24

Network ID: 192.168.1.0

The first address in the subnet range. It identifies the network itself and cannot be assigned to a host.

Host IDs: 192.168.1.1 to 192.168.1.254

The range of addresses available for assignment to individual devices (hosts) within the subnet.

Broadcast Address: 192.168.1.255

The last address in the subnet range. Used to send data to all devices on that specific subnet simultaneously.
