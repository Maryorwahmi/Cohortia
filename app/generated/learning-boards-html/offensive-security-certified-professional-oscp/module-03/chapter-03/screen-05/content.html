Delivery Vectors

Common Client-Side Delivery Vectors

How Exploits Reach the Target User

Client-side exploits are delivered through various channels that require user interaction to activate the malicious payload.

  • •Browser-based attacks target web browser vulnerabilities.
  • •Malicious file formats embed exploits in common documents.
  • •Drive-by downloads occur without explicit user consent.
Key Takeaway

Understanding these vectors is crucial for both offensive planning and defensive strategies, as each presents unique challenges.

Primary Delivery Mechanisms

Browser-based Exploits

Target vulnerabilities in web browsers or their plugins when a user visits a malicious website.

Malicious File Formats

Exploits embedded in documents (PDFs, Office files) that execute when opened by a vulnerable application.

Drive-by Downloads

Malicious code downloaded and executed without explicit user consent, often via browser vulnerabilities.

Important Note

While `browser_autopwn` was a classic Metasploit module for browser exploits, its effectiveness against modern, patched browsers is limited due to robust security features. However, understanding its mechanics is still valuable for older systems or specific scenarios.
