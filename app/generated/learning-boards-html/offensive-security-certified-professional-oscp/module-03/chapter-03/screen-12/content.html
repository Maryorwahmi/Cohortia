Scenario: Targeting an Invoice User

Crafting a Client-Side Attack for a Specific Target

This scenario outlines a step-by-step approach to compromising a user who frequently handles invoices, integrating all learned techniques.

  • •Generate a `windows/meterpreter/reverse_tcp` payload with `msfvenom`.
  • •Embed the payload into a PDF using a Metasploit file format exploit.
  • •Set up a `multi/handler` listener on your Kali machine.
  • •Craft a convincing phishing email or host the file on a web server.
Key Takeaway

Effective client-side exploitation is a blend of technical skill and psychological manipulation, tailored to the target's context.

Attack Flow for Invoice User

1. Generate Payload

Use `msfvenom` to create `evil.exe` (e.g., `windows/meterpreter/reverse_tcp`).

2. Embed in PDF

Use `exploit/windows/fileformat/adobe_reader_js_embed_exe` to create `Overdue_Invoice.pdf`.

3. Set Up Listener

Configure `multi/handler` with matching `PAYLOAD`, `LHOST`, `LPORT`.

4. Deliver via Phishing

Send a convincing email with the PDF attachment or a link to it.
