Exploitation Step 5

Locating a JMP ESP Instruction

Finding a reliable memory address to redirect execution to our shellcode.

The Role of JMP ESP

To execute your shellcode, you need to redirect EIP to a location where your shellcode resides. A `JMP ESP` instruction is ideal as ESP typically points to the beginning of your shellcode on the stack.

  • `JMP ESP` jumps to the address pointed to by the ESP register.
  • ESP usually points to the start of your injected shellcode.
  • Must find in a DLL without ASLR (Address Space Layout Randomization).
Key Takeaway

Finding a `JMP ESP` instruction in a non-ASLR module is crucial for redirecting the hijacked EIP to the start of your shellcode, enabling its execution.

Using Mona.py to Find JMP ESP

# In Immunity Debugger, with Mona.py loaded:
!mona jmp -r esp -m "essfunc.dll"
# This command searches for JMP ESP instructions within the 'essfunc.dll' module.
# Mona will list addresses and indicate if ASLR is enabled for the module.

# Example Output (truncated):
---------- Mona Results ----------
0x625011AF   JMP ESP   [essfunc.dll]   ASLR: False, Rebase: False, SafeSEH: False, OS: False, EHF: False, DEP: False
# Select an address where ASLR is 'False'.
# For example, 0x625011AF would be a good candidate.
# Remember to convert this to little-endian for your payload (AF 11 50 62).

Mona.py helps locate `JMP ESP` instructions in loaded DLLs. It's vital to choose an address from a module where ASLR is disabled to ensure the address remains constant across program runs.
