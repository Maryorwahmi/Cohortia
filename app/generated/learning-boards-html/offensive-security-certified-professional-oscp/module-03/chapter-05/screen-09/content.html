Identifying Bad Characters

Detecting and excluding bytes that corrupt shellcode or terminate string operations.

What are Bad Characters?

Bad characters are specific byte values that can terminate string operations or cause issues when included in your shellcode, leading to corruption or truncation.

  • `\x00` (Null byte): Most common, terminates strings.
  • `\x0a` (Newline): Can interfere with parsing.
  • `\x0d` (Carriage Return): Similar to newline, can cause issues.
  • Must be excluded from shellcode for reliable execution.
Key Takeaway

Bad characters are bytes that interfere with shellcode execution; identifying and excluding them, often using tools like Mona.py, is vital for payload integrity.

Using Mona.py to Find Bad Characters

# 1. Generate a byte array excluding known bad characters (start with \x00)
!mona bytearray -b "\x00"
# This generates a file (e.g., bytearray.txt) with all bytes from \x01 to \xff.

# 2. Modify your Python script to send:
payload = b"A" * offset + b"BBBB" + bytearray_from_file

# 3. Send the payload and observe in Immunity Debugger.
#    Follow the ESP register in the dump to see your byte array in memory.

# 4. Compare the memory dump with the original byte array file
!mona compare -f C:\path  o\bytearray.txt -a <address_of_your_bytearray_in_memory>
# Mona will report any corrupted bytes, which are your bad characters.
# Add them to the -b flag in the bytearray command and repeat until no more are found.

Mona.py helps generate a full byte array. You send this array, then compare the memory dump to the original file to find any bytes that were corrupted, indicating they are 'bad characters' that need to be excluded from your shellcode.
