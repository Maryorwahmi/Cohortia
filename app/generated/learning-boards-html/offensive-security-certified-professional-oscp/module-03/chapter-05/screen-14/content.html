Key Concepts: Core Terminology

Essential definitions for understanding buffer overflows.

Buffer Overflow

A vulnerability where a program writes more data into a buffer than it can hold, overwriting adjacent memory.

Stack

A region of memory used for local variables, function arguments, and return addresses during function calls.

Stack Frame

The portion of the stack allocated for a single function call, containing its specific data.

Return Address

The memory address where program execution should continue after a function completes.

EIP (Extended Instruction Pointer)

A CPU register that stores the memory address of the next instruction to be executed.

Fuzzing

A technique of sending large, malformed, or random data to an input to discover vulnerabilities.

Summary Takeaway

Mastering these core terms provides the conceptual framework necessary to understand the mechanics and implications of buffer overflow vulnerabilities.
