Buffer Overflows: Definition & Stack Fundamentals

Understanding how excess data can overwrite critical memory structures.

What is a Buffer Overflow?

A buffer overflow occurs when a program attempts to write more data into a fixed-size memory buffer than it was allocated to hold. This excess data 'overflows' into adjacent memory locations.

  • Can overwrite critical data structures.
  • Potentially redirects program execution flow.
  • Often targets the 'return address' on the stack.
Key Takeaway

Buffer overflows are memory corruption vulnerabilities that allow attackers to overwrite adjacent memory, crucially the return address, to hijack program control.

The Stack and Stack Frames

The stack is a crucial memory region. When a function is called, a new 'stack frame' is created, containing vital information:

Local Variables

Data declared within the function.

Return Address

Where execution resumes after function.

Saved EBP

Pointer to previous stack frame.

Function Arguments

Parameters passed to the function.

The stack grows downwards in memory. Overwriting a buffer can reach and corrupt the return address, allowing an attacker to control the program's flow.
