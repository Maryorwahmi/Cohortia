Key Concepts: Memory Protections

Essential Terms for Advanced Exploitation

DEP (Data Execution Prevention)

A security feature that prevents code execution from non-executable memory regions like the stack or heap.

ASLR (Address Space Layout Randomization)

A security feature that randomizes the memory addresses of key program components to make exploitation harder.

SEH (Structured Exception Handling)

A Windows mechanism for handling runtime errors; its overwrite can be an exploitation vector.

Summary Takeaway

Modern operating systems use DEP and ASLR to prevent traditional buffer overflow attacks, requiring advanced bypass techniques like SEH overwrite.
