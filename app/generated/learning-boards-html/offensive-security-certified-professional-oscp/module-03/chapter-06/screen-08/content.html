Information Leakage

Exploiting vulnerabilities to leak memory addresses, allowing calculation of randomized offsets.

  • •A separate bug reveals a pointer or address.
  • •This leaked address serves as a reference point.
  • •Offsets to other critical locations can then be determined.
Concrete Example

A format string vulnerability might leak stack addresses, which can then be used to calculate the base address of a loaded library.

Non-ASLR Modules

Identifying loaded modules (DLLs) compiled without ASLR support, providing stable addresses.

  • •These modules have constant base addresses.
  • •Provide reliable locations for gadgets or functions.
  • •Tools like Mona.py's !mona modules help identify them.
Pro Tip

Always check for non-ASLR modules first, as they often provide the easiest and most reliable ASLR bypass.

Key Takeaway

Information leakage and the presence of non-ASLR modules are primary methods to overcome the address randomization introduced by ASLR.
