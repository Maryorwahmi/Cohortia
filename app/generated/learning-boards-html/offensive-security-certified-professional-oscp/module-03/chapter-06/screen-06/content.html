Introduction to ROP

Return-Oriented Programming (ROP) is a technique to bypass DEP by reusing existing code sequences.

  • •No new shellcode is injected; existing instructions are chained.
  • •Relies on 'gadgets' – small instruction sequences ending with RET.
  • •Gadgets are found in executable memory (DLLs, main executable).
Concrete Example

An attacker might chain a 'pop eax; ret' gadget, followed by a 'pop ebx; ret' gadget, then a 'mov [eax], ebx; ret' gadget to write a specific value to a memory address.

Key Takeaway

ROP allows attackers to construct arbitrary functionality by carefully arranging existing code snippets on the stack, effectively bypassing DEP.
