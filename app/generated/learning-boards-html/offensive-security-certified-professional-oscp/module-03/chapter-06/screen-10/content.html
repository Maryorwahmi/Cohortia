What is SEH?

Structured Exception Handling (SEH) is a Windows mechanism for gracefully handling runtime errors.

  • •Manages program crashes and unexpected events.
  • •Exception handler addresses are stored on the stack.
  • •A buffer overflow can overwrite these handler pointers.
Concrete Example

If a program attempts to access an invalid memory address, an exception occurs. Normally, SEH would direct this to a default handler, but an overwrite can hijack this process.

Key Takeaway

SEH overwrite exploits the exception handling mechanism in Windows to redirect program execution to attacker-controlled code when an error occurs.

SEH Record on the Stack

Stack Frame (Normal Data)
nSEH (Next SEH Record Pointer)
SEH (SEH Handler Pointer)

A buffer overflow can overwrite the nSEH and SEH pointers on the stack.
