How DEP Works

DEP marks memory regions as non-executable, preventing malicious code from running in areas intended for data.

  • •Targets data-only segments like the stack and heap.
  • •Blocks attempts to execute injected shellcode from these regions.
  • •Triggers an exception and terminates the program upon violation.
Concrete Example

If an attacker injects shellcode into the stack and tries to jump to it, DEP will detect the execution attempt from a non-executable page and crash the application.

Key Takeaway

DEP is a fundamental defense that forces attackers to find alternative methods for code execution, such as reusing existing executable code.
