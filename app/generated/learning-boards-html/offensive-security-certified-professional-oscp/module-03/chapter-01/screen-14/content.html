Chapter Summary

Key Concepts: Vulnerability Management

Essential terms for identifying and analyzing weaknesses.

Vulnerability

A flaw or weakness in a system that can be exploited to compromise its security.

CVE

A standardized naming system for publicly known information security vulnerabilities.

Vulnerability Scanner

Automated software that identifies security weaknesses in computer systems, networks, and applications.

Summary Takeaway

Understanding what vulnerabilities are, how they are identified by CVEs, and the role of automated scanners forms the essential groundwork for any penetration test.
