Core Concept

What is a Vulnerability?

A Flaw That Can Compromise System Security

Definition

A flaw or weakness in a system's design, implementation, operation, or management that could be exploited to violate its security policy.

Common Categories
  • By Impact: Remote Code Execution, Denial of Service, Information Disclosure
  • By Component: Operating System, Web Application, Network Service
Key Takeaway

Understanding the diverse nature and categorization of vulnerabilities is fundamental to effective security analysis.

Visual Analogy
Faulty Lock (Vulnerability)
Unlocked Door (Exploitation)
Scenario

A web server running outdated software has a known bug. An attacker uses this bug to gain unauthorized access, similar to using a weak point in a lock to open a door.
