Extracting Credentials with Mimikatz

Leveraging memory forensics to dump passwords and hashes

What is Mimikatz?

  • A powerful Windows post-exploitation tool.
  • Extracts plaintext passwords, NTLM hashes, and Kerberos tickets.
  • Targets the Local Security Authority Subsystem Service (LSASS) process memory.
  • Enables lateral movement and further privilege escalation.

Key Commands

  • privilege::debug: Required to gain debug privileges for memory access.
  • sekurlsa::logonpasswords: Dumps credentials from LSASS.
  • Output includes usernames, domains, NTLM hashes, and sometimes plaintext passwords.

Key Takeaway

Mimikatz is an indispensable tool for Windows post-exploitation, providing access to credentials that can significantly expand an attacker's reach within a network.
