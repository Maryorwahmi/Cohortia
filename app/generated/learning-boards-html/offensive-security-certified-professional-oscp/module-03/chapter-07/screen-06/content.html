Kernel Exploits and SUID Binaries

Leveraging OS vulnerabilities and misconfigurations for root access

Kernel Exploits

  • Exploiting vulnerabilities in the OS kernel itself.
  • Example: Dirty Cow (CVE-2016-5195).
  • Often require specific kernel versions.
  • Can grant immediate root access.

SUID/SGID Binaries

  • Executables run with owner's permissions, not executing user's.
  • If owned by root and vulnerable, can be exploited.
  • Example: Old nmap with SUID bit set.
  • Enumeration: find / -perm -4000 2>/dev/null
Terminal Demo: Finding SUID Binaries
lowuser@target:~$ find / -perm -4000 2>/dev/null
/usr/bin/sudo
/usr/bin/passwd
/usr/bin/nmap # Potentially exploitable if old version
/usr/local/bin/suid_app

This command lists all SUID binaries, which are prime targets for privilege escalation if misconfigured or vulnerable.

Key Takeaway

Actively search for kernel vulnerabilities and misconfigured SUID binaries on Linux systems, as they often provide direct paths to root privileges.
