Scheduled Tasks and Startup Programs

Automating malicious payloads for continuous access

Scheduled Tasks / Cron Jobs

  • Windows: schtasks /create /tn "MyBackdoor" /tr "C:\Users\Public\backdoor.exe" /sc ONLOGON /ru System
  • Linux: Adding entries to /etc/crontab or user's crontab.
  • Executes payloads at specific intervals or system events.

Startup Programs

  • Windows: Placing payloads in startup folders or modifying registry run keys (e.g., HKCU\Software\Microsoft\Windows\CurrentVersion\Run).
  • Linux: Modifying .bashrc or .profile for user-level persistence.
  • Ensures execution upon user login or system startup.

Key Takeaway

Scheduled tasks and startup programs offer robust and often stealthy methods for establishing persistence, ensuring long-term access to compromised systems.
