Core Workflow

Navigating Metasploit: Search, Use, and Options

Finding and preparing your modules for action.

1. Search

Use search <keyword> to find relevant modules by name, vulnerability, or type. This helps you locate the right tool quickly.

2. Use

Select a module with use <module_path>. This loads the module into your current Metasploit session, preparing it for configuration.

3. Show Options

Display configurable parameters for the selected module using show options. This is crucial for understanding what needs to be set.

# Example Commands
msf6 > search ms08_067
# Find modules related to MS08-067

msf6 > use exploit/windows/smb/ms08_067_netapi
# Select the specific exploit module

msf6 exploit(windows/smb/ms08_067_netapi) > show options
# Review required parameters like RHOSTS, LHOST, LPORT
Pro Tip

Always use show options and show advanced options to fully understand a module's capabilities and requirements.

Key Takeaway

The initial workflow involves searching for modules, selecting them, and thoroughly reviewing their configuration options.
