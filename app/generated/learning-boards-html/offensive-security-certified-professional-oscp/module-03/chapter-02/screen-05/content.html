Module Type

Exploits: Gaining Initial Access

Code designed to leverage vulnerabilities for control.

Definition

Pieces of code that take advantage of a specific vulnerability in a target system to gain control or access.

Purpose

To achieve unauthorized execution of code or gain elevated privileges on a vulnerable machine.

Key Characteristic

Often targets specific software versions or configurations, requiring precise matching for success.

# Common Exploit Examples
exploit/windows/smb/ms08_067_netapi
# Targets a critical Windows SMB vulnerability

exploit/multi/http/tomcat_mgr_deploy
# Exploits weak credentials on a Tomcat server
Analogy

Think of an exploit as a specialized key designed to open a specific, flawed lock on a target system.

Key Takeaway

Exploits are the initial attack vector, leveraging vulnerabilities to establish a foothold on a target system.
