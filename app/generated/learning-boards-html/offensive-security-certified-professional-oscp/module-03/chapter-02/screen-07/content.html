Auxiliary Modules

Information Gathering & Scanning

Purpose

Perform various functions not directly exploitation, such as scanning, fuzzing, or information gathering.

Examples

  • auxiliary/scanner/portscan/tcp (Port scanning)
  • auxiliary/scanner/smb/smb_login (SMB brute-forcing)
  • auxiliary/dos/smb/smb_ms09_050_smb2_negotiate_overflow (DoS attacks)
Post-Exploitation Modules

Deepening Access & Persistence

Purpose

Run on a compromised system to gather more information, escalate privileges, or maintain persistence.

Examples

  • post/windows/gather/enum_logged_on_users (Enumerate users)
  • post/multi/manage/shell_to_meterpreter (Upgrade shell)
  • Leverage Meterpreter sessions for advanced actions.
Key Takeaway

Auxiliary modules are for pre-exploitation tasks like scanning, while post-exploitation modules are for actions on an already compromised system.
