Key Concepts

Module types and their roles in the exploitation lifecycle.

Payload

Code executed on a target system after a successful exploit, providing desired functionality (e.g., a shell).

Auxiliary Module

A Metasploit module that performs various tasks like scanning, fuzzing, or information gathering, not directly involving exploitation.

Post-Exploitation Module

A Metasploit module designed to run on a compromised system to gather information, escalate privileges, or maintain persistence.

Summary Takeaway

Payloads define post-exploit actions, auxiliary modules assist in reconnaissance, and post-exploitation modules deepen control on compromised systems.
