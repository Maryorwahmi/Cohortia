Module Type

Payloads: Executing Actions on Target

The code that runs after a successful exploit, providing desired functionality.

Definition

Small pieces of code executed on a target system after a successful exploit, providing desired functionality.

Purpose

To establish shells (reverse/bind), upload files, or enable advanced post-exploitation capabilities like Meterpreter.

Example: Meterpreter

An advanced, highly versatile payload providing an interactive shell with many post-exploitation features.

# Common Payload Example
windows/meterpreter/reverse_tcp
# Establishes an encrypted connection back to your attacking machine.

linux/x86/shell_bind_tcp
# Opens a listening port on the target for you to connect to.
Misconception

An exploit gains access; a payload defines what you do with that access. They work in tandem.

Key Takeaway

Payloads are crucial for defining post-exploitation actions, from simple shells to advanced Meterpreter sessions.
