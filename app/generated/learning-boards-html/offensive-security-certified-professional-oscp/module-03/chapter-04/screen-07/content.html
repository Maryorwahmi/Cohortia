Manual SQLi Detection: Column Count

Finding the Right Number of Columns

To perform a UNION-based SQL injection, you first need to know how many columns the original query selects. This is because the injected `UNION SELECT` statement must match the original query's column count. A common manual technique involves using the `ORDER BY` clause. By incrementally increasing the number in `ORDER BY N--`, you can determine the maximum number of columns. When `ORDER BY` exceeds the actual column count, the database will return an error, revealing the correct number.

Key Takeaway

Systematically testing `ORDER BY N--` is essential for preparing UNION-based SQLi attacks.

Example Query Structure

Original Query:

SELECT name, price FROM products WHERE id = ;
Manual Test Steps

Test payloads like:

  • ?id=1' ORDER BY 1-- (Works)
  • ?id=1' ORDER BY 2-- (Works)
  • ?id=1' ORDER BY 3-- (Error!)

Conclusion: 2 columns.
