Manual SQLi Detection: UNION Select

Extracting Data with UNION

With the column count known (e.g., 2), we can now use `UNION SELECT` to extract data. The injected query must match the original query's structure. For instance, to get the database version, we might inject: `' UNION SELECT NULL, @@version --`. This replaces the original data with `NULL` for the first column and the database version for the second. To dump user credentials, we could try: `' UNION SELECT username, password FROM users --`. This requires knowing the table and column names. Successful execution means the application will display the requested data, demonstrating a powerful data exfiltration technique.

Key Takeaway

`UNION SELECT` allows attackers to retrieve data from other tables by aligning column counts and types.

Example Payload

Extracting Database Version:

?id=1' UNION SELECT NULL, @@version --
Example Payload

Extracting User Credentials:

?id=1' UNION SELECT username, password FROM users --
