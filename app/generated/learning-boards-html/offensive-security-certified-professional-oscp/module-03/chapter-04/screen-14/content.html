Scenario: Command Injection Assessment

Choosing the Right Payload

You've found a command injection vulnerability in a ping utility. The URL is `http://example.com/diagnose.php?host=google.com`. You want to execute the `id` command on the server. Which payload is most likely to work? Consider URL encoding and command separators. The semicolon (`;`) is a standard Linux command separator. When URL-encoded, it becomes `%3B`. Therefore, injecting `google.com %3B id` is the most direct way to execute the `id` command after the initial hostname processing.

Key Takeaway

Proper URL encoding of command separators is critical for successful command injection.

Payload Options
  • A) google.com | id
  • B) google.com && id
  • C) google.com %26%26 id
  • D) google.com %3B id
Correct Payload

Option D: google.com %3B id

The semicolon (`%3B`) reliably separates commands for sequential execution on Linux.
