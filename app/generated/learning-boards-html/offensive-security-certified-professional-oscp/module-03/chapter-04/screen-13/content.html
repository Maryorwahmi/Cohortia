Scenario: SQL Injection Assessment

Identifying the Next Step

You've found a potential SQL Injection vulnerability at `?itemid=123`. Your attempt with `UNION SELECT` failed with a 'different number of columns' error. This means your injected query's column count doesn't match the original. What's the best next step? The most effective approach is to determine the correct column count. This is achieved by systematically testing the `ORDER BY` clause. Incrementing the number in `ORDER BY N--` until an error occurs reveals the maximum valid column count, allowing you to craft a successful `UNION SELECT` statement.

Key Takeaway

The `ORDER BY` clause is crucial for determining the correct column count needed for UNION-based SQLi.

Problem

Error: 'Different number of columns'

Your `UNION SELECT` statement does not match the original query's column count.

Solution

Use `ORDER BY` to find the column count:

  • ?itemid=123' ORDER BY 1--
  • ?itemid=123' ORDER BY 2--
  • ?itemid=123' ORDER BY 3-- (Error!)

Conclusion: 2 columns.
