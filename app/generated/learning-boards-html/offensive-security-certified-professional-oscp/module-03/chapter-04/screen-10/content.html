Definition

Command Injection

Executing Arbitrary OS Commands

Command Injection occurs when an application executes user-supplied input directly as a system command without proper sanitization. This vulnerability allows an attacker to run arbitrary operating system commands on the server, potentially leading to full system compromise. It's a severe risk because it bypasses application logic and interacts directly with the server's OS.

Key Takeaway

Never execute user input directly as a system command. Always validate and sanitize it, or use safer alternatives.

Example Scenario

Ping Utility Vulnerability

If a web app uses user input `IP_ADDRESS` in a command like `ping -c 4 `, injecting `127.0.0.1; ls -la /` could execute `ls -la /` after the ping command.

Common Separators

Linux/Unix:

  • `;` (semicolon)
  • `&&` (AND)
  • `||` (OR)
  • `|` (pipe)

Windows:

  • `&`
  • `&&`
  • `|`
  • `||`
