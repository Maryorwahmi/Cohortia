Learning Objectives: Part 1

Building Foundational Skills for OSCP Documentation

Bloom's Taxonomy:
LearnUnderstandApplyMaster
01

Identify Evidence Types

Learn to recognize the specific categories of evidence, such as screenshots, command output, and logs, that are crucial for a successful OSCP exam report. This ensures you collect all necessary proofs to validate your findings.

VERIFIED COMPETENCY MILESTONE
02

Master Screenshot Techniques

Develop proficiency in capturing clear, contextual, and unedited screenshots that effectively demonstrate commands, outputs, and successful exploitation. This skill is vital for providing undeniable visual proof.

VERIFIED COMPETENCY MILESTONE
03

Collect Textual Evidence

Learn to efficiently gather and organize command output, configuration files, and custom exploit code as plain text. This ensures all non-visual proofs are systematically stored for your final report.

VERIFIED COMPETENCY MILESTONE
