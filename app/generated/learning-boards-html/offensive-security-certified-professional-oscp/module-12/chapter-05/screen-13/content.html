Evidence Management

Organizing Evidence with a Logical Directory Structure

Create a dedicated, structured directory for each target machine to streamline retrieval and report generation.

Per-Target Organization

Create a main directory for the exam, then a separate subdirectory for each target machine (e.g., 192.168.1.101_WebApp01).

Categorized Subdirectories

Within each target folder, create subdirectories for nmap, screenshots, exploits, and logs to keep evidence types separate.

Descriptive Naming

Name screenshots descriptively (e.g., 1_initial_shell_whoami.png) to easily identify and insert them into your report.

Key Takeaway

A well-organized directory structure per target machine is crucial for efficient evidence retrieval and streamlined report writing.
