Proof for Exploits: Buffer Overflows & Web

Document the critical steps of your exploitation chain for complex vulnerabilities.

Buffer Overflow Steps

Fuzzer output, debugger (EIP, bad chars, JMP ESP), exploit code, and final shell.

Web Exploit Steps

Browser views of vulnerable parameters, Burp Suite requests/responses, and the resulting shell.

Complete Chain of Proof

Each screenshot should logically connect to the next, building a clear narrative of your exploitation.

Key Takeaway

For complex exploits, provide a sequential series of screenshots that clearly demonstrate each critical step from vulnerability to shell.

Buffer Overflow
  • Fuzzer output
  • Debugger (EIP, bad chars)
  • Exploit code
  • Final shell
Web Exploitation
  • Browser view (vulnerable param)
  • Burp Suite (request/response)
  • Resulting shell
