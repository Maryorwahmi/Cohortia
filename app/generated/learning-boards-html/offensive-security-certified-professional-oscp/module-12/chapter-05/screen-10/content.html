Textual Evidence

Collecting Command Output & File Contents

Beyond screenshots, preserve full command results and configuration files as plain text.

Full Nmap Results

Save complete Nmap scans as text files, especially for initial and buffer overflow machines, for easy reference.

Enumeration Script Output

Preserve the extensive output from scripts like linpeas.sh or winpeas.exe in plain text format.

Configuration Files & Code

Collect important configuration files (e.g., /etc/sudoers) and any custom exploit code you developed.

Key Takeaway

Textual evidence provides comprehensive, searchable records that complement screenshots and are essential for a detailed report.
