Screenshot Guidelines

Context is King: Command & Output

Your screenshot must clearly show both the command you executed and its resulting output.

Input and Output

Always capture the command you typed and the system's response. This proves your action and the result.

Avoid Ambiguity

Without the command, the output lacks context and can be misinterpreted or deemed insufficient proof.

Reviewer's Perspective

Always consider if a reviewer can understand your actions and results from the screenshot alone. Clarity is key.

Key Takeaway

A screenshot is only complete when it shows both the command executed and its full output, providing undeniable context.
