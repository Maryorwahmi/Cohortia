Activity Logging

Anatomy of an Effective Log Entry

A detailed, timestamped log entry helps you recall the exact sequence of events for each machine.

Timestamp & Target

Each entry begins with a precise timestamp and identifies the target machine (IP and name).

Commands & Observations

Record every significant command executed and any notable observations, like open ports or directory listings.

Milestones & Screenshots

Clearly mark significant achievements (e.g., shell obtained) and reference associated screenshots for visual proof.

Key Takeaway

A well-structured log entry with timestamps, commands, observations, and screenshot references is crucial for accurate report writing.

[2023-10-27 10:15:30] Target: 192.168.1.105 (WEBAPP01)
[2023-10-27 10:15:35] Ran nmap -sC -sV -oA nmap/webapp01 192.168.1.105
