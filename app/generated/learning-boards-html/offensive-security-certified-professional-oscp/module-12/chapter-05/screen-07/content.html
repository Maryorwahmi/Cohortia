Essential Proofs

Key Information for Initial & Root Access

Always include specific commands to prove your privilege level and target system identity.

Initial Linux Shell

Include whoami to show user and ip a or ifconfig to confirm target IP and presence.

Initial Windows Shell

Use whoami /all for detailed user info and ipconfig for network configuration.

Root/SYSTEM Access

For highest privileges, capture id (Linux) or whoami /priv (Windows) to confirm.

Key Takeaway

Specific commands like whoami, ip a, id, whoami /all, and whoami /priv are non-negotiable for proving access levels.

Linux Initial Access
kali@kali:~$ whoami
www-data
kali@kali:~$ ip a
... inet 192.168.1.105/24 ...
Windows Initial Access
C:\> whoami /all
... User SID ...
C:\> ipconfig
... IPv4 Address: 192.168.1.106 ...
Linux Root Access
root@kali:~$ id
uid=0(root) gid=0(root) groups=0(root)
Windows SYSTEM Access
C:\> whoami /priv
... SeDebugPrivilege ...
... NT AUTHORITY\SYSTEM ...
