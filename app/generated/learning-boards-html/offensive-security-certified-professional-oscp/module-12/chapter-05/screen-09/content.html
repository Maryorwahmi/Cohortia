Module 12›Chapter 12.5›File Contents & Service Enumeration
Specific Evidence

Proof for File Contents & Service Enumeration

Capture sensitive data and comprehensive enumeration results as clear evidence.

Sensitive File Contents

Use cat or type commands to display contents of files like /etc/passwd or SAM, showing both command and output.

Service Enumeration

Capture full output from tools like nmap, enum4linux, or rpcclient to prove service discovery and details.

Clarity and Completeness

Ensure screenshots are clear, unedited, and show the full context to leave no doubt about your findings.

Key Takeaway

Always provide clear screenshots of commands used to display sensitive file contents and the full output of enumeration tools.

File Content Example
kali@kali:~$ cat /etc/passwd
root:x:0:0:root:/root:/bin/bash
www-data:x:33:33:www-data:/var/www:/usr/sbin/nologin
Nmap Scan Example
kali@kali:~$ nmap -sC -sV 192.168.1.105
... PORT   STATE SERVICE VERSION
... 80/tcp open  http    Apache httpd 2.4.x
Enum4linux Example
kali@kali:~$ enum4linux -U 192.168.1.106
... User: Administrator (RID: 500)
... User: Guest (RID: 501)
