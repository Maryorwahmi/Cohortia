Module 12›Chapter 8›Initial Recon
Core Principle

Scan All Targets

After the BOF, perform a quick, comprehensive nmap scan on all remaining targets to get a high-level overview of services and potential vulnerabilities.

Benefits of Early Recon
  • Identifies low-hanging fruit.
  • Highlights familiar vulnerabilities.
  • Informs target prioritization.
  • Prevents tunnel vision on a single machine.
Key Takeaway

A broad initial reconnaissance provides the strategic intelligence needed to efficiently plan your attack path across all exam machines.

Nmap Command for Comprehensive Scan
# Comprehensive Nmap Scan
nmap -sC -sV -oA all_targets <IP_RANGE>

# Explanation of Flags:
-sC: Default script scan (e.g., vulnerability checks)
-sV: Service version detection
-oA: Output in all formats (Nmap, Grepable, XML)
<IP_RANGE>: The IP range of your exam targets

# Example:
nmap -sC -sV -oA all_targets 192.168.1.1-254

This command provides a high-level overview of open ports, services, and common script output for all targets.
