Definition

What is Pivoting?

Pivoting is the technique of using a compromised machine as an intermediary (a 'pivot') to access other machines on an otherwise inaccessible internal network segment.

Identifying Pivot Points
  • Look for machines with multiple network interfaces (e.g., using ip a or ipconfig).
  • These machines act as bridges between different network segments.
Key Takeaway

Pivoting is essential for expanding your attack surface into isolated internal networks, often leading to higher-value targets.
