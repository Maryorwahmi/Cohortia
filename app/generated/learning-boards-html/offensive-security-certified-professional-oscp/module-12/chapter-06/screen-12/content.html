Tool Spotlight

Converting Markdown to PDF with Pandoc

Finalizing your report for submission

Key Takeaway

Pandoc is the essential tool for converting your Markdown report into a professional PDF, ensuring it meets submission requirements.

Pro-Tip

Install pandoc and its dependencies (like xelatex) on your Kali Linux machine well before the exam to avoid last-minute setup issues.

terminalbash
# 1. Install pandoc (if not already installed)
sudo apt update
sudo apt install pandoc -y

# 2. Create a sample Markdown file (sample_report.md)
# (Content as shown in previous Markdown examples)

# 3. Convert to PDF using xelatex engine
pandoc sample_report.md -o sample_report.pdf --pdf-engine=xelatex

# Alternative for Word document conversion:
pandoc sample_report.md -o sample_report.docx

# Review the generated PDF:
xdg-open sample_report.pdf
