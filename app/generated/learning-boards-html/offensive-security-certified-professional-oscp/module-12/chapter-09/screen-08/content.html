Technical Pitfall

Uncovering Privilege Escalation Paths

Don't overlook common misconfigurations and vulnerabilities.

Key Takeaway

Systematically check for common privilege escalation vectors using both automated tools and manual verification.

Common PrivEsc Vectors

  • Misconfigured SUID/GUID Binaries: Executables running with elevated permissions.
  • Weak File Permissions: Modifiable system files or scripts.
  • Kernel Exploits: Outdated kernels with known vulnerabilities.
  • Scheduled Tasks/Cron Jobs: Scripts running as root or SYSTEM.
  • Service Misconfigurations: Unquoted service paths, weak service permissions.
Privilege Escalation Checklist

Linux: sudo -l & SUID

Check for commands runnable as root and SUID binaries.

Windows: Services & Permissions

Look for misconfigured services, unquoted paths, and weak ACLs.

Automated Scripts

Use linpeas.sh and winpeas.exe as a baseline for enumeration.
