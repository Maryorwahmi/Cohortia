Technical Pitfall

Strategic Metasploit Usage

Adhering to exam rules for tool usage to avoid disqualification.

Key Takeaway

Know and follow Metasploit usage rules strictly; develop manual exploitation skills for other targets.

Why Rules are Strict

  • Skill Assessment: Ensures candidates demonstrate manual exploitation proficiency.
  • Fairness: Standardizes the playing field for all candidates.
  • Real-World Relevance: Manual skills are crucial in scenarios where automated tools are limited.
  • Integrity: Upholds the value and reputation of the OSCP certification.
Metasploit Usage Guidelines

One Non-BOF Machine

Only use Metasploit on one machine, excluding the Buffer Overflow target.

Manual Exploitation Focus

Develop strong manual skills for all other machines.

Document Your Choice

Clearly state which machine Metasploit was used on in your report.
