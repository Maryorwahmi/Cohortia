Common Technical Impacts of Exploitation

Exploring the direct control and access gained by an attacker.

Arbitrary Code Execution

Attacker can run any command on the system (e.g., SYSTEM shell, reverse shell).

Data Exfiltration

Sensitive data (e.g., database contents, files) is stolen from the system.

Authentication Bypass

Attacker gains unauthorized access without valid credentials (e.g., logging in as admin).

Denial of Service (DoS)

Disruption of service availability, making it inaccessible to legitimate users.

Information Disclosure

Revealing sensitive configuration files, user lists, or other confidential data.

Example Scenario

Achieving a SYSTEM shell on a domain controller is a direct technical impact, granting full control over the system.

Key Takeaway

Clearly defining the technical impact helps remediation teams understand the immediate system-level consequences of an exploit.
