The Common Vulnerability Scoring System (CVSS)

Objectively rating vulnerability severity for consistent communication.

Understanding CVSS

CVSS is a free and open industry standard for assessing the severity of computer system security vulnerabilities. It provides a way to capture the principal characteristics of a vulnerability and produce a numerical score reflecting its severity.

  • •Score Range: 0.0 (lowest) to 10.0 (highest severity).
  • •Purpose: Objective severity rating, prioritization, and consistent communication.
  • •OSCP Context: Understanding CVSS principles is key, even if full calculation isn't always required.
Key Takeaway

CVSS provides a standardized, objective method to score vulnerability severity, crucial for consistent risk assessment and communication.

Key CVSS Factors

CVSS considers several metrics to determine a vulnerability's base score:

Attack Vector

How an attacker gains access (e.g., Network, Local).

Attack Complexity

Difficulty of exploiting the vulnerability (e.g., Low, High).

Privileges Required

Level of access needed by attacker (e.g., None, Low, High).

User Interaction

If user interaction is required (e.g., None, Required).

Impact (C, I, A)

Confidentiality, Integrity, and Availability impact (e.g., None, Low, High).

Example

A network-exploitable vulnerability with no authentication, leading to full C, I, A compromise, would typically score as Critical (e.g., 9.8).
