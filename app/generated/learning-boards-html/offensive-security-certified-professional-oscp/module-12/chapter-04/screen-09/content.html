Common Finding: Linux

Addressing SUID-enabled Binaries

Removing dangerous SUID permissions on Linux systems.

Vulnerability Explained

  • Issue: SUID bit set on binaries that can be exploited (e.g., find).
  • Risk: Allows users to execute the binary with the owner's (often root) privileges.
  • Impact: Privilege escalation to root.
Key Takeaway

Regularly audit SUID binaries and remove permissions from any that are not strictly necessary for system function.

Concrete Example

An SUID find binary can be used to execute commands as root, e.g., find . -exec /bin/sh -p \;.

Remediation Command

# Identify SUID binaries (as root or with sudo)find / -perm -4000 2>/dev/null# Example output showing vulnerable find:/usr/bin/find# Remediation: Remove SUID bit from findchmod u-s /usr/bin/find# Verify (should no longer appear in the find output)find / -perm -4000 2>/dev/null
