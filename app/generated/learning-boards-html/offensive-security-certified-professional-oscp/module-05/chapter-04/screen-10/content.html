Predictable Session IDs: A Guessing Game for Attackers

When session identifiers are not truly random

Predictable session IDs occur when an application generates session identifiers using easily guessable patterns. This allows attackers to predict valid IDs and hijack active user sessions, bypassing authentication.

  • Weak Generation: IDs based on sequential numbers, timestamps, or simple hashes.
  • Exploitation: Attackers guess valid IDs to impersonate users.
  • Mitigation: Use long, cryptographically secure, and random session IDs.
Key Takeaway

Session IDs must be generated with strong cryptographic randomness to prevent attackers from predicting and exploiting them for session hijacking.

Predictable ID Patterns
Sequential: ID=101, ID=102, ID=103
Timestamp-based: ID=1678886400 (Unix timestamp)
User-data hash: ID=hash(username)
Pro-Tip

Always inspect session IDs for patterns. Use Burp Intruder with 'Numbers' or 'Custom Iterator' payloads to test for sequential or predictable values.
