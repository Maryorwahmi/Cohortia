Session Hijacking: Taking Over an Active Session

Methods and consequences of impersonating a legitimate user

Session hijacking is the act of taking over an active user session. By stealing or predicting a valid session ID, an attacker can impersonate the legitimate user and gain unauthorized access to their account and functionalities.

  • Stealing Session IDs: Via XSS, network sniffing (unencrypted traffic), or malware.
  • Predictable IDs: Exploiting weak session ID generation algorithms.
  • Consequence: Full account compromise, unauthorized actions, data theft.
Key Takeaway

Session hijacking is a high-impact vulnerability that can be prevented by using strong, random session IDs, secure cookie flags, and always enforcing HTTPS.

Session Hijacking Vectors
Cross-Site Scripting (XSS): Injecting scripts to steal cookies.
Network Sniffing: Intercepting unencrypted session IDs.
Predictable Session IDs: Guessing the session token.
Session Fixation: Forcing a known session ID onto the victim.
Misconception

HTTPS alone does not prevent session hijacking. While it encrypts traffic, session IDs can still be stolen via XSS or other client-side vulnerabilities.
