Hydra: The Versatile Brute-Forcer

Performing brute-force attacks from the command line

Hydra is a powerful, command-line brute-forcing tool that supports a wide range of protocols beyond just web applications. It's highly efficient for systematically testing credentials.

  • Multi-Protocol Support: Works with HTTP/S, FTP, SSH, Telnet, and many more.
  • Command-Line Interface: Offers flexibility and scripting capabilities for automation.
  • Failure String Detection: Identifies unsuccessful attempts by matching a specific string in the response.
Key Takeaway

Hydra is an essential command-line tool for brute-forcing various services, offering flexibility and efficiency for credential testing beyond web forms.

Hydra HTTP-POST-FORM Example 
hydra -L users.txt -P passwords.txt target.com http-post-form "/login.php:username=^USER^&password=^PASS^:Login failed"

This command attempts to brute-force a login form at /login.php on target.com.

  • -L users.txt: Specifies the file containing usernames.
  • -P passwords.txt: Specifies the file containing passwords.
  • ^USER^ & ^PASS^: Placeholders for Hydra to inject values.
  • :Login failed: The string in the response indicating a failed login attempt.
Common Mistake

Incorrectly defining the failure string. If the string doesn't accurately reflect a failed login, Hydra might report false positives or miss successful attempts.
