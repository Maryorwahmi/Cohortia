Burp Suite Intruder: Automating Brute-Force Attacks (Part 1)

Configuring your attack with payload positions and types

Burp Suite Intruder is a powerful tool for automating customized attacks, including brute-forcing. It allows you to precisely define which parts of an HTTP request to test with various payloads.

  • Capture Request: Send a vulnerable request (e.g., login) from Burp Proxy to Intruder.
  • Mark Positions: Highlight parameters (e.g., username, password) and click 'Add $' to mark for fuzzing.
  • Select Attack Type: Choose 'Sniper' for single parameter, 'Cluster Bomb' for multiple independent parameters.
Key Takeaway

Mastering payload position marking and attack type selection in Burp Intruder is crucial for effective automated vulnerability testing.

Intruder Attack Types
Sniper: Single parameter, one payload list.
Battering Ram: Multiple parameters, same payload list.
Cluster Bomb: Multiple parameters, different payload lists.
Pitchfork: Multiple parameters, synchronized payload lists.
Common Mistake

Forgetting to clear default payload markers. This can lead to unintended fuzzing of unrelated parameters, wasting time and potentially causing issues.
