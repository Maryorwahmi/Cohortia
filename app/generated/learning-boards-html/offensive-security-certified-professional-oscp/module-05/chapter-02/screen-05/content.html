SQLi Type
Error-Based SQL Injection
Leveraging Database Errors for Information Leakage

This technique relies on the application displaying detailed database error messages to the user.

Attackers intentionally trigger errors using specific SQL functions or syntax that reveal information.

Commonly exploited functions in MySQL include UPDATEXML and EXTRACTVALUE, which can be manipulated to produce error messages containing query results.

Example payload structure:

AND (SELECT 1 FROM (SELECT COUNT(*), CONCAT(version(), FLOOR(RAND(0)*2)) x FROM information_schema.plugins GROUP BY x)a)-- -

This payload attempts to reveal the database version within an error message.

How it Works
Triggering Errors to Leak Data
Vulnerable Input:
' AND (SELECT 1 FROM (SELECT COUNT(*), CONCAT(version(), FLOOR(RAND(0)*2)) x FROM information_schema.plugins GROUP BY x)a)-- -
Application Response:
Database Error: ... ERROR 1110 (42000): ERROR at line 1: ERROR :COLLATION 'utf8mb4_general_ci' is not valid for UNICODE (longer)...
DATA EXFILTRATION VIA ERROR
Key Takeaway

Error-based SQLi exploits verbose database error messages to reveal sensitive information, making it effective when error handling is weak.
