Core Concept
Authentication Bypass via SQLi
Exploiting Login Forms

SQL Injection can be used to bypass authentication mechanisms by manipulating the SQL query that verifies user credentials.

Consider a login query:

SELECT * FROM users WHERE username = '{$username}' AND password = '{$password}';

If an attacker inputs ' OR '1'='1 into the username field, the query becomes:

SELECT * FROM users WHERE username = '' OR '1'='1' AND password = '{$password}';

The '1'='1' condition is always true, making the entire WHERE clause true and allowing access without a valid password.

Example Scenario
Login Form Input
Username:
' OR '1'='1
Password:
[any value]
ATTACKER PAYLOAD
Key Takeaway

Directly embedding user input into SQL queries creates a critical vulnerability, enabling attackers to bypass authentication by manipulating query logic.
