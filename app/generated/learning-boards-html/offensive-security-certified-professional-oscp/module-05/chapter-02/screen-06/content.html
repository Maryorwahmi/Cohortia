Union-Based SQL Injection
Combining Queries to Retrieve Data

This technique uses the UNION operator to merge results from two or more SELECT statements.

It requires identifying the number of columns in the original query and ensuring compatible data types.

Step 1: Find Column Count

Use ORDER BY or GROUP BY clauses to determine the number of columns. For example, appending ORDER BY 1-- -, ORDER BY 2-- -, etc., to a vulnerable parameter.

Step 2: Find Displayable Columns

Use UNION SELECT NULL, NULL, ...-- - to find which columns display output.

Step 3: Extract Data

Inject functions like database() or user() into displayable columns.

' UNION SELECT NULL, database(), user()-- -
Example Scenario
Extracting Database Name & User
Vulnerable URL:
http://example.com/products.php?id=-1 UNION SELECT NULL, database(), user()-- -
Result:
Database: web_app_db, User: app_user@localhost
DATA EXFILTRATION VIA UNION
Key Takeaway

Union-based SQLi allows attackers to retrieve data from arbitrary tables by combining their malicious query with the application's legitimate query.
