SQLi Type
Blind SQL Injection
Inferring Data Through Application Behavior

Blind SQLi is used when the application does not directly display database errors or query results.

Attackers infer information by observing the application's response patterns.

1. Boolean-Based Blind SQLi:

Injects queries that yield a TRUE or FALSE result. The attacker observes differences in the application's response (e.g., page content, status) to determine the condition's truthfulness.

Example: ?id=1 AND SUBSTRING(VERSION(),1,1)='5'

2. Time-Based Blind SQLi:

Injects commands that cause a time delay (e.g., SLEEP(5)). A delay indicates the injected condition was true.

Example: ?id=1 AND IF(SUBSTRING(VERSION(),1,1)='5', SLEEP(5), 0)

Inference Methods
Observing Application Responses
Boolean-Based:
Page loads normally (TRUE) vs. Page shows error/different content (FALSE)
Time-Based:
Page loads quickly (FALSE) vs. Page loads after a delay (TRUE)
INFERRING DATA BIT BY BIT
Key Takeaway

Blind SQLi requires patience and careful observation of application behavior to infer database information indirectly, making it stealthier but more complex.
