SSRF Impact

SSRF Impact: Port Scanning & Advanced Protocols

Expanding SSRF exploitation beyond simple HTTP requests.

Internal Port Scanning

By making requests to different ports on internal hosts and observing responses (e.g., connection refused, timeout), attackers can map internal services.

Leveraging file:// Protocol

If allowed, the file:// protocol can be used to read local files on the server.

file:///etc/passwd
Leveraging gopher:// Protocol

An older protocol that can be used for more advanced interactions with non-HTTP services like Redis or MySQL.

Reconnaissance Power

SSRF allows attackers to gain a detailed understanding of internal network services and their status.

Protocol Versatility

The ability to use non-HTTP protocols significantly expands the attack surface and potential impact.

Key Takeaway

Always restrict the protocols and domains that a server-side application can request to prevent advanced SSRF exploitation.
