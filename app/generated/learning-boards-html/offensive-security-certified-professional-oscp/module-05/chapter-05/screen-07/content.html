Bypass Technique

Double Extension Bypass Techniques

Exploiting how servers parse multiple file extensions.

Scenario: Last Extension Check

Server only checks the final extension (e.g., .jpg) for validity.

Bypass Example 1: shell.php.jpg

Upload shell.php.jpg. Server sees .jpg and allows. If PHP handler processes .php first, it executes.

Scenario: Last Extension Stripping

Server strips the last extension (e.g., .jpg) during processing.

Bypass Example 2: shell.jpg.php

Upload shell.jpg.php. Server strips .jpg, resulting in shell.php, which then executes.

How it Works

Exploits discrepancies between application validation and web server configuration for file handling.

Pro-Tip

Always test how the server actually processes filenames, not just what the application claims.

Key Takeaway

Implement a strict whitelist of allowed extensions and rename uploaded files to prevent extension-based attacks.
