Key Concepts: Advanced Attacks

Essential terms and ideas from advanced web application attacks.

XML External Entity (XXE)

A vulnerability where an XML parser processes XML input containing a reference to an external entity, leading to file disclosure, SSRF, or RCE.

DOCTYPE

A declaration in XML that specifies the Document Type Definition (DTD), which can be abused in XXE attacks.

External Entity

A construct in XML that can refer to external resources, such as files or URLs, often exploited in XXE.

Chapter Summary

Advanced web attacks like XXE and insecure deserialization exploit fundamental data processing flaws, often leading to severe impacts like remote code execution.
