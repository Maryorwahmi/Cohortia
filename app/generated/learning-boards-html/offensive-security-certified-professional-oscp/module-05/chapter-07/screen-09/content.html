Insecure Deserialization

Understanding the risks of processing untrusted serialized data.

What is Deserialization?
  • Serialization: Converting an object into a stream of bytes for storage or transmission.
  • Deserialization: Reconstructing the object from that stream of bytes.
  • The Vulnerability: Occurs when an application deserializes untrusted, attacker-controlled data.
  • Impact: Can lead to arbitrary code execution, denial of service, or authentication bypass by injecting malicious objects.
Key Takeaway

Deserializing untrusted data allows attackers to manipulate application logic by controlling object creation and method calls.

Serialization Process & Attack Point

Object in Memory

e.g., UserSession { id: 123, role: 'guest' }

Serialized Data (Bytes)

e.g., `a:2:{s:2:"id";i:123;s:4:"role";s:5:"guest";}`

ATTACKER MANIPULATION POINT

Reconstructed Object

e.g., UserSession { id: 123, role: 'admin' } (Malicious)

Common Mistake: Assuming serialized data is inherently safe because it's not human-readable. It can be easily crafted by an attacker.
