Reading Arbitrary Files via XXE

Leveraging external entities to disclose sensitive server files.

Attack Steps
  1. Identify XML Input: Find an application endpoint that processes XML data.
  2. Craft Malicious DTD: Define an external entity pointing to a local file (e.g., `file:///etc/passwd`).
  3. Embed Entity Reference: Include the entity reference (`&xxe;`) within the XML body.
  4. Observe Response: Check the application's response for the file's content.
Key Takeaway

Successful XXE file disclosure can reveal critical system information, aiding further exploitation and privilege escalation.

XXE Payload for File Disclosure
<?xml version="1.0"?> <!DOCTYPE foo [ <!ENTITY xxe SYSTEM "file:///etc/passwd"> ]> <foo>&xxe;</foo>

Scenario: An e-commerce site uses XML to process product reviews. An attacker submits a review with this payload, and the server's response includes the `/etc/passwd` file, revealing system users.

Misconception: Assuming `file:///` is the only protocol. XXE can also use `http://`, `ftp://`, `gopher://`, etc., depending on the parser's capabilities.
