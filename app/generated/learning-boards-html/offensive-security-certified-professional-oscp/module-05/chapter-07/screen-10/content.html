Language-Specific Deserialization Examples

How insecure deserialization manifests in Java and PHP.

Key Concepts
  • Gadget Chain: A sequence of existing methods in an application that, when called in a specific order, leads to an attacker's desired action (e.g., RCE).
  • Magic Methods (PHP): Special methods (e.g., `__destruct`, `__wakeup`) that are automatically called during object lifecycle events, often exploitable during deserialization.
  • `ysoserial`: A popular tool for generating deserialization payloads for various Java applications.
Key Takeaway

Exploiting deserialization requires understanding language-specific object models and identifying 'gadget chains' to achieve RCE.

PHP `unserialize()` Vulnerability
<?php // Vulnerable code: $data = unserialize($_GET['data']); // Attacker crafts 'data' parameter to trigger magic methods // Example of a simple PHP object that could be part of a gadget chain class Logger { public $logFile; public $message; public function __destruct() { file_put_contents($this->logFile, $this->message, FILE_APPEND); } } // If an attacker can control $logFile and $message, they can write arbitrary content to any file. ?>

Scenario: A PHP application uses `unserialize()` to process user-supplied session data. An attacker crafts a malicious serialized string that, when deserialized, triggers a `__destruct` method in a logging class to write a web shell to the server.

Prevention: Avoid deserializing untrusted data. If necessary, use secure serialization formats like JSON or implement strict integrity checks and whitelisting of allowed classes.
