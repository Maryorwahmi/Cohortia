Whitespace, Alternative Syntax & DNS Rebinding

Advanced techniques for bypassing WAFs in specific scenarios.

Advanced Evasion Tactics
  • Whitespace & Junk Characters: Insert extra spaces, newlines (`%0a`), or unprintable characters to break signatures. Example: `SELECT%0a* FROM users`.
  • Alternative Syntax: Use less common SQL functions or operators. Example: `id LIKE '1'` instead of `id=1`.
  • DNS Rebinding: For SSRF, use a domain that resolves to an external IP, then rebinds to an internal IP after WAF check.
  • False Positives & Whitelisting: Exploit known WAF false positives or find whitelisted endpoints.
Key Takeaway

Advanced WAF bypasses leverage subtle parsing differences, alternative command structures, or timing-based attacks like DNS rebinding to circumvent defenses.

DNS Rebinding for SSRF Bypass

Step 1: Initial DNS Resolution

attacker.com -> External_IP (WAF checks, deems safe)

Step 2: DNS Rebind (short TTL)

attacker.com -> Internal_IP (Application makes request, WAF already passed)
