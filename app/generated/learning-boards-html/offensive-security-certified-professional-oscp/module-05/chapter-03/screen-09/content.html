Bypass Techniques

Evading XSS Filters: Encoding & Case Variation

Creative Approaches to Bypass Protections

HTML Entity Encoding

Convert special characters into their HTML entity equivalents (e.g., < becomes &lt;). Filters might only decode once, allowing the script to execute.

&lt;script&gt;alert(1)&lt;/script&gt;

URL Encoding

Encode special characters in the URL (e.g., < becomes %3c). This can bypass filters that don't fully decode URL parameters.

%3cscript%3ealert(1)%3c/script%3e

Case Variation

Alter the casing of keywords (e.g., sCrIpT instead of script). Simple case-sensitive filters can be easily bypassed this way.

<sCrIpT>alert(1)</sCrIpT>
Key Takeaway

XSS filters can often be bypassed by creatively using HTML entity encoding, URL encoding, or varying the case of your payload elements.
