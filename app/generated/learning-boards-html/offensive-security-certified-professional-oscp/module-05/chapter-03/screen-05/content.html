XSS Type 1

Reflected XSS: Non-Persistent Attacks

Malicious Scripts Reflected from the Server

Non-Persistent Nature

The malicious script is not stored on the server. It's reflected immediately in the server's response after being submitted in a request.

URL-Based Delivery

The XSS payload is typically embedded within a URL parameter. The attacker must trick the victim into clicking this specially crafted link.

Example Scenario

A search page `example.com/search?query=test` is vulnerable. An attacker injects `` into the `query` parameter, and the server reflects it.

Payload Example

<script>alert(document.cookie)</script> to steal cookies, or <img src=x onerror=alert(1)> as a bypass.

Key Takeaway

Reflected XSS is a common, non-persistent attack where malicious scripts are immediately echoed by the server, often via a crafted URL.
