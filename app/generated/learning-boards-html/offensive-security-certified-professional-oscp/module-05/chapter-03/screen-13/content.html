Key Concepts

Essential XSS Terminology

Cross-Site Scripting (XSS)

A client-side code injection attack where malicious scripts are injected into web pages viewed by other users.

Reflected XSS

Malicious script is reflected immediately in the server's response, typically via a crafted URL, requiring user interaction.

Stored XSS

Malicious script is permanently stored on the server (e.g., database) and executed when victims view the compromised page.

Summary Takeaway

XSS is a critical client-side vulnerability with three main types: Reflected, Stored, and DOM-based, each exploiting different injection and execution mechanisms.
