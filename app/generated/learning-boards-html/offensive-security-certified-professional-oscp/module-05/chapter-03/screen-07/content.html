XSS Type 3

DOM-based XSS: Client-Side Vulnerabilities

Exploiting Dynamic DOM Manipulation

Client-Side Only

This XSS type occurs entirely within the client-side code, meaning the server is not involved in reflecting or storing the malicious payload.

DOM Manipulation

Vulnerabilities arise from client-side scripts that take user input and dynamically write it to the Document Object Model (DOM) without proper sanitization.

Example Scenario

A JavaScript function reads a URL fragment (e.g., `http://example.com/page.html#name=`) and writes it directly to the DOM.

Payload Example

#'><img src=x onerror=alert(1)> if the script inserts the value into an HTML attribute, breaking out of the attribute.

Key Takeaway

DOM-based XSS exploits client-side scripts that unsafely write user input into the DOM, leading to script execution without server interaction.
