Configuring Burp Suite for HTTP Traffic

Browser Proxy Settings

Step-by-Step Configuration

  1. Launch Burp Suite: Start the Burp Suite Community Edition. It typically listens on 127.0.0.1:8080 by default.
  2. Open Browser Settings: In Firefox, go to Settings (or Preferences).
  3. Navigate to Network Settings: Search for "proxy" and select Network Settings.
  4. Choose Manual Proxy: Select Manual proxy configuration.
  5. Set HTTP Proxy: Set HTTP Proxy to 127.0.0.1 and Port to 8080.
  6. Enable HTTPS Proxy: Check Also use this proxy for HTTPS.
  7. Confirm Settings: Click OK to save the changes.
