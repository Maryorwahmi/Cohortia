Phase 1: Information Gathering & Reconnaissance

Mapping the Application's Landscape

Key Activities

  • Technology Identification: Discovering web server, frameworks, databases.
  • Directory & File Enumeration: Finding hidden or sensitive paths.
  • Application Structure Mapping: Understanding the layout and functionality.
  • Subdomain Discovery: Expanding the attack surface.

Example: Discovering a Hidden Admin Panel

Using a tool like `Gobuster` to brute-force common directory names, a tester might discover a `/admin` directory that isn't linked from the main site. This hidden panel could be poorly secured, offering an easy entry point if found.

Essential Tools for Reconnaissance

Nmap

Port scanning, service version detection.

Nikto / Wappalyzer

Web technology identification.

Gobuster / Dirb

Directory and file brute-forcing.

Sublist3r

Subdomain enumeration.

Key Takeaway

Thorough information gathering is crucial; it provides the intelligence needed to identify potential attack vectors and prioritize testing efforts effectively.
