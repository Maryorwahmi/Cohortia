OWASP Top 10: Injection and Cross-Site Scripting

Common and Impactful Vulnerabilities

Injection Flaws

Occur when untrusted data is sent to an interpreter as part of a command or query, allowing attackers to execute unintended commands.

  • SQL Injection: Manipulating database queries.
  • Command Injection: Executing OS commands on the server.
  • Impact: Data breaches, system compromise, unauthorized access.

Example: SQL Injection Bypass

A login form vulnerable to SQL Injection might allow an attacker to enter ' OR '1'='1 as a password, bypassing authentication and gaining access without valid credentials.

Cross-Site Scripting (XSS)

Enables attackers to inject malicious client-side scripts into web pages viewed by other users, leading to various client-side attacks.

  • Reflected XSS: Malicious script from request reflected in response.
  • Stored XSS: Malicious script permanently stored on target servers.
  • DOM-based XSS: Vulnerability in client-side code modifying the DOM.
  • Impact: Session hijacking, defacement, malicious redirects.
Key Takeaway

Injection and XSS are critical vulnerabilities stemming from improper input handling, allowing severe server-side and client-side attacks respectively.
