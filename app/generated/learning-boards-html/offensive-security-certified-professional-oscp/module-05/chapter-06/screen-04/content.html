Core Concept

Understanding OS Command Injection

When unsanitized user input executes system commands.

Key Idea

OS Command Injection occurs when an application executes user-supplied input as part of a system command, leading to arbitrary command execution on the server.

How it Works
  • Application builds a system command using user input.
  • Lack of sanitization allows special characters to alter command structure.
  • Attacker injects arbitrary commands that the server executes.
  • Impact ranges from information disclosure to full remote code execution.
Common Mistake

Failing to validate or sanitize all user input before passing it to system command functions. Always assume user input is malicious.

# Vulnerable PHP script example
<?php
$ip_address = $_GET['ip'];
$command = "ping -c 4 " . $ip_address;

// Executes the command directly without sanitization
system($command);
?>
Attacker's Goal

To break out of the intended command and execute their own arbitrary operating system commands on the server.
