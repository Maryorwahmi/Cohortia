Core Concept

Local File Inclusion (LFI) Explained

Reading arbitrary files from the local system.

Key Idea

LFI allows attackers to include and read arbitrary local files by manipulating user-supplied file paths, leading to sensitive information disclosure and potential RCE.

How it Works
  • Application includes local files based on user input.
  • Lack of validation allows path manipulation.
  • Attacker reads arbitrary files on the server.
  • Can lead to sensitive data disclosure or RCE.
Common Misconception

LFI is only for reading files. In reality, it can often be escalated to remote code execution through techniques like log poisoning.

# Vulnerable PHP script example
<?php
$page = $_GET['page'];

// Includes the file specified by 'page' without validation
include($page);
?>
Attacker's Goal

To manipulate the page parameter to include files outside the intended directory, such as system configuration files or password files.
