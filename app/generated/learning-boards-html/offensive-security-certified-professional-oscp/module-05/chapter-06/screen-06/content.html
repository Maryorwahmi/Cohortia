Shell Metacharacters for Injection

Understanding command separators and operators.

Key Idea

Shell metacharacters like `;`, `&`, `|`, and `` ` `` allow attackers to chain or substitute commands, with specific syntax variations for Linux/Unix and Windows.

Why They Matter

These characters are interpreted by the shell, not as literal input, but as instructions to control command execution flow. They are the core of command injection.

Common Mistake

Assuming metacharacter behavior is identical across all operating systems. Always test and verify OS-specific syntax.

Linux/Unix Injection Characters
  • ;: Command separator (execute sequentially)
  • &: Run command in background
  • &&: Execute if previous command succeeds
  • ||: Execute if previous command fails
  • |: Pipe output of one command to another
  • ` `: Backticks for command substitution
  • $(command): Command substitution (modern syntax)
Windows Injection Characters
  • &: Command separator
  • &&: Execute if previous command succeeds
  • |: Pipe output of one command to another
  • ||: Execute if previous command fails
