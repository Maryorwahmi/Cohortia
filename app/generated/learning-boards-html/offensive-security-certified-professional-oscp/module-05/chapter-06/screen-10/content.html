Reconnaissance Targets

Identifying Sensitive Files for LFI

Key system and application files to target.

Key Idea

Targeting files like `/etc/passwd`, log files, and using PHP wrappers in LFI can reveal sensitive system information, credentials, or even source code.

Why These Files?

These files often contain critical system information, user credentials, or application logic that can be leveraged for further exploitation or privilege escalation.

Pro Tip

Always check for default paths and common file names first. Tools like FFUF or DirBuster can help automate this process.

Common LFI Target Files (Linux)
  • /etc/passwd: User accounts
  • /etc/shadow: Hashed passwords (requires root)
  • /etc/issue, /etc/os-release: OS version info
  • /var/log/apache2/access.log: Apache access logs
  • /var/log/auth.log: Authentication logs
PHP Wrapper Targets
  • php://filter/read=convert.base64-encode/resource=index.php: Read source code
  • data://text/plain,<?php phpinfo(); ?>: RCE if allow_url_include is on
