Security Best Practices

Preventing Injection and Inclusion Vulnerabilities

Implementing robust input validation and configuration.

Key Idea

Prevent command injection by sanitizing input and using parameterized commands; mitigate LFI/RFI by validating file paths, whitelisting, and disabling `allow_url_include`.

Common Mistakes
  • Not escaping/sanitizing user input for system commands.
  • Not validating file paths for inclusion.
  • Enabling allow_url_include in PHP.
Proactive Defense

Regular security audits and code reviews are essential to catch these vulnerabilities before they are exploited in production environments.

Defenses for Command Injection
  • **Input Sanitization:** Filter or escape all user-supplied input.
  • **Parameterized Commands:** Use APIs that separate commands from arguments.
  • **Whitelisting:** Only allow a predefined set of safe inputs.
Defenses for File Inclusion (LFI/RFI)
  • **Strict Path Validation:** Validate all file paths, disallowing directory traversal.
  • **File Whitelisting:** Only allow inclusion of a predefined list of safe files.
  • **Disable `allow_url_include`:** Ensure this PHP setting is off.
  • **Least Privilege:** Run web server with minimal necessary permissions.
