Exploitation Scenario

Exploiting LFI with Directory Traversal

Accessing files outside the web root.

Key Idea

Directory traversal (`../`) is used in LFI to move up the file system hierarchy, allowing access to files outside the web root, such as `/etc/passwd`.

Vulnerable URL

http://example.com/index.php?page=about.php

Attacker's Goal

To manipulate the page parameter to read sensitive system files.

Directory Traversal Payload
http://example.com/index.php?page=../../../../etc/passwd
Expected Result

The web application includes and displays the content of the /etc/passwd file, revealing user accounts on the Linux server.

Important Note

The number of ../ sequences needed depends on the web application's directory depth relative to the file you want to access.
