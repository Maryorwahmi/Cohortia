Example Scenario

A 'Ping' Utility Vulnerability

Injecting commands through a simple network tool.

Key Idea

A semicolon (`;`) can separate commands, allowing an attacker to execute additional commands after the intended one in a vulnerable application.

Vulnerable Application Logic

A web application takes an IP address as input for a 'ping' utility. The server constructs a command like: ping -c 4 {$ip_address}.

Attacker Input

127.0.0.1; whoami

Original Command
ping -c 4 127.0.0.1
Injected Command
ping -c 4 127.0.0.1; whoami
Resulting Action

The server first executes ping, then immediately executes whoami, potentially revealing the web server's user account in the response.
