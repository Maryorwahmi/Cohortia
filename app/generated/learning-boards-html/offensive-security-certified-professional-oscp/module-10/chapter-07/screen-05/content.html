Core Methodology

Living Off The Land Binaries and Scripts (LOLBAS)

Abusing Trusted System Tools

Definition

LOLBAS involves using legitimate, signed, and whitelisted binaries or scripts already present on a target system to perform malicious actions, bypassing security controls.

Why it Works

Since these binaries are trusted by the OS and AWL policy, they are allowed to execute, enabling attackers to achieve objectives without introducing new, unauthorized executables.

Key Takeaway

LOLBAS leverages the inherent trust in system tools, making it a stealthy and effective method for bypassing AWL and other security defenses.

The LOLBAS Principle: Trust Exploitation

Target System

Whitelisted Binaries & Scripts

Legitimate Binary (e.g., `regsvr32`)

Abused for Malicious Action

Achieve Objective

Code Execution, Persistence, etc.
