Chapter Summary

Key Concepts

Essential Terms to Remember

Application Whitelisting (AWL)

A security control that only allows explicitly approved applications to run on a system, blocking all others by default.

Living Off The Land Binaries and Scripts (LOLBAS)

A methodology of using legitimate, pre-installed tools and binaries on a system to carry out malicious actions, bypassing security controls like AWL.

`regsvr32.exe`

A Windows utility used to register/unregister DLLs, which can be abused to download and execute scriptlets from remote servers.

Summary Takeaway

AWL is a powerful defense, but LOLBAS techniques, exemplified by `regsvr32.exe`, demonstrate how trusted system binaries can be repurposed to bypass these controls.
