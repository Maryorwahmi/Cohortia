LOLBAS Technique

Executing DLL Functions with `rundll32.exe`

Running Malicious DLLs

rundll32.exe C:\Windows\System32\shell32.dll,Control_RunDLL C:\Users\Public\malicious.dll,EntryPoint
Command Explained

`rundll32` executes a specified function from a DLL. Here, it's used to call `Control_RunDLL` from `shell32.dll` to then load and execute a function from `malicious.dll`.

Malicious DLL

The `malicious.dll` contains the attacker's code, and `EntryPoint` is the function within it that `rundll32` is instructed to execute.

Combined Techniques

While this example uses a local DLL, `rundll32` can be combined with other methods (e.g., `mshta.exe`) to download and execute remote DLLs.

Key Takeaway

`rundll32.exe` is a versatile LOLBAS for executing functions from malicious DLLs, leveraging its whitelisted status as a core Windows utility.

`rundll32` Execution Flow

1.

Attacker creates a malicious DLL with an exported function.

2.

Places the DLL on the target system (or uses a download method).

3.

Executes `rundll32.exe` specifying the DLL path and function name.

4.

`rundll32` loads the DLL and executes the specified malicious function.

Analogy

Think of `rundll32` as a remote control for DLLs. If you can swap out the battery (the DLL) with a malicious one, the remote control (rundll32) will still function, but with a different outcome.
