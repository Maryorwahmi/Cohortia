Key Concepts

Expanding Your Understanding

`msbuild.exe`

The Microsoft Build Engine, which can be used to execute arbitrary inline C# or Visual Basic code embedded in project files.

`InstallUtil.exe`

A .NET Framework utility that can execute custom installer components within a .NET assembly, allowing for arbitrary .NET code execution.

`rundll32.exe`

A Windows utility that executes a specified function from a DLL, often abused to run malicious DLL functions.

Summary Takeaway

Advanced LOLBAS techniques leverage trusted binaries like `msbuild.exe`, `InstallUtil.exe`, and `rundll32.exe`, alongside weaknesses like DLL Sideloading, to bypass AWL.
