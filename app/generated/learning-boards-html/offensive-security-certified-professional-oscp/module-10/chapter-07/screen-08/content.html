Key Takeaway

`InstallUtil.exe` can execute arbitrary .NET code by pointing it to a specially crafted .NET assembly, making it a versatile AWL bypass for .NET environments.

`InstallUtil` Bypass Flow

1.

Attacker develops a .NET assembly with malicious code in its `Install` method.

2.

Compiles the code into an executable (e.g., `malicious.exe`).

3.

Places the malicious assembly on the target system.

4.

Executes `InstallUtil.exe` pointing to the malicious assembly, triggering the `Install` method.

Pro Tip

The `/U` flag (uninstall) is often used to execute the `Install` method, as it's part of the installation/uninstallation lifecycle.
