Practical Sandbox Detection in C++

Querying system resources to identify a VM.

#include <windows.h>
#include <stdio.h>

int main() {
    MEMORYSTATUSEX statex;
    statex.dwLength = sizeof(statex);
    GlobalMemoryStatusEx(&statex);

    SYSTEM_INFO sysInfo;
    GetSystemInfo(&sysInfo);

    printf("Physical Memory: %lld MB
", statex.ullTotalPhys / (1024 * 1024));
    printf("Number of Processors: %d
", sysInfo.dwNumberOfProcessors);

    if (statex.ullTotalPhys / (1024 * 1024) < 2048 || sysInfo.dwNumberOfProcessors < 2) {
        printf("Possible VM/Sandbox detected. Exiting or performing benign actions.
");
        // Exit or execute benign code path
        return 0;
    }

    printf("Looks like a real system. Proceeding with malicious payload...
");
    // Execute actual malicious payload
    return 0;
}
Code Explanation
  • GlobalMemoryStatusEx: Retrieves information about the system's physical and virtual memory. We use ullTotalPhys to get total physical RAM.
  • GetSystemInfo: Provides details about the current system, including dwNumberOfProcessors.
  • Conditional Logic: If total physical memory is less than 2GB (2048 MB) OR the number of processors is less than 2, it's flagged as a potential VM/Sandbox.
  • Payload Behavior: The code then prints a message indicating detection and suggests exiting or performing benign actions. Otherwise, it proceeds with the 'malicious' payload.
Key Takeaway

Simple system resource checks like memory and CPU count are effective initial indicators for sandbox detection, allowing payloads to adapt their behavior to avoid analysis.

Pro Tip

Combine multiple checks (e.g., registry keys, specific process names, user activity) for more robust sandbox detection, as sophisticated sandboxes can emulate basic resource configurations.
