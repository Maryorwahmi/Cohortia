Identifying Virtual Environments

Key indicators malware looks for to detect a sandbox.

Resource Constraints

Sandboxes are often provisioned with minimal resources to save costs and speed up analysis. Malware can check for these limitations.

  • Low Memory/Disk Space: Often less than 2GB RAM or limited disk.
  • Few CPU Cores: Typically 1 or 2 cores, unlike a user's multi-core system.

Virtualization Artifacts

Virtualization software leaves specific traces on the system that can be detected by a payload.

  • Registry Keys/Files: Unique entries for VMware, VirtualBox, etc.
  • MAC Addresses: Specific vendor prefixes for virtual network adapters.

Behavioral Anomalies

Sandboxes often lack the typical human interaction and long execution times found on real user systems.

  • Lack of User Activity: No mouse movement, keyboard input, or browsing.
  • Short Execution Time: Malware run for only a few seconds or minutes.
  • Specific Process Names: Presence of analysis tools or monitoring processes.
Key Takeaway

Malware leverages a combination of resource checks, virtualization artifacts, and behavioral anomalies to reliably detect if it's operating within a sandbox or virtual machine environment.
