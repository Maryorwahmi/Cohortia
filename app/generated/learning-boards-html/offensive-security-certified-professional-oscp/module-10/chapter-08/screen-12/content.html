Kernel-Level Monitoring & Limitations

Understanding EDR's deeper defenses and the scope of userland evasion.

Userland Monitoring

  • Involves DLL injection and API hooking in user-mode processes.
  • Detects suspicious API calls (e.g., NtCreateThreadEx).
  • Bypassed by unhooking and direct syscalls.
  • Focus for OSCP-level evasion.
Example

An EDR hooks WriteProcessMemory to detect process injection. Unhooking this function bypasses the userland check.

Kernel-Level Monitoring

  • Operates within the Windows kernel, using callbacks and minifilters.
  • Provides deeper visibility and control over system activity.
  • Significantly harder to bypass, often requiring kernel exploits.
  • Generally outside OSCP scope.
Limitation

Userland evasion techniques do not bypass kernel-level EDR monitoring, which requires more advanced and risky methods.

Key Takeaway

While userland evasion is critical, EDRs also employ kernel-level monitoring, which remains a significant challenge and is typically beyond the scope of userland bypasses.
