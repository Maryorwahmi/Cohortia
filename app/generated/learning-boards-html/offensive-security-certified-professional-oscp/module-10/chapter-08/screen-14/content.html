Key Concepts to Remember

Essential terms and ideas from this chapter.

Endpoint Detection and Response (EDR)

Advanced security solutions that continuously monitor endpoint activity, using analytics to detect and respond to threats.

API Hooking

A technique used by EDRs to intercept and monitor API calls made by processes, allowing for inspection or blocking.

Userland Hooks

API hooks implemented in user-mode memory, typically by injecting a DLL into a process and modifying API function prologues.

Kernel-Level Monitoring

EDR capabilities operating within the Windows kernel, providing deeper visibility and control over system activity.

Unhooking

A technique to bypass userland API hooking by restoring the original, unhooked bytes of an API function from a clean DLL copy.

Direct Syscalls

A technique to bypass userland API hooking by directly invoking kernel system calls using assembly instructions.

Summary Takeaway

Mastering EDR evasion involves understanding both userland and kernel-level defenses, and applying techniques like unhooking and direct syscalls responsibly.
