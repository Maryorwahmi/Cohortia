Unhooking NtAllocateVirtualMemory (Part 2)

Executing the unhooking and testing the restored function.

Determine Prologue Size

SIZE_T prologueSize = 23; (example for x64) defines the bytes to overwrite.

Change Memory Protection

VirtualProtect grants write access to the hooked function's prologue.

Overwrite and Restore

memcpy copies original bytes, then VirtualProtect restores original permissions.

Test Unhooked Function

A conceptual call to NtAllocateVirtualMemory_Unhooked verifies the bypass.

Key Takeaway

The core unhooking operation involves precise memory manipulation and protection adjustments, followed by a test to confirm the bypass.
