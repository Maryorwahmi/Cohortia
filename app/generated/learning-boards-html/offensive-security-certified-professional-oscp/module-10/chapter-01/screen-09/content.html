What is a Firewall?

A network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. It acts as a barrier between trusted and untrusted networks.

Firewall Rule Components

  • Source/Destination IP: Which hosts are allowed to communicate.
  • Port Numbers: Which services (e.g., 80 for HTTP, 22 for SSH) are accessible.
  • Protocols: Which communication methods (e.g., TCP, UDP, ICMP) are permitted.
  • Action: Allow or deny the traffic.
Key Takeaway

Firewalls are rule-based traffic filters; understanding their rules is crucial for identifying network access points.

Basic vs. Next-Gen Firewalls

Evolving capabilities for deeper inspection.

Basic Firewall
  • Packet filtering
  • Stateful inspection
  • IP/Port/Protocol rules
Next-Gen Firewall (NGFW)
  • Deep packet inspection
  • Application-level filtering
  • Threat intelligence integration

NGFWs provide more granular control and advanced threat prevention.
