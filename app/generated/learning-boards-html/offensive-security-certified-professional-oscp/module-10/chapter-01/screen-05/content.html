What is Antivirus (AV)?

Antivirus software is designed to detect, prevent, and remove malicious software from computer systems. It's a fundamental layer of endpoint security.

Signature-Based Detection

  • Mechanism: Scans files and processes for known malicious patterns (signatures).
  • Signatures: Unique byte sequences or hash values associated with specific malware.
  • Action: Flags, quarantines, or deletes files matching known signatures.
Key Takeaway

Signature-based AV is effective against known threats but reactive and vulnerable to new or modified malware.

How Signature Detection Works

A simple process of matching known malicious patterns.

1. File Scan
2. Signature Database Lookup
3. Match or No Match
4. Action (Quarantine/Delete)
