Key Concepts

Essential terms to remember from this chapter

Antivirus (AV)

Software designed to detect, prevent, and remove malicious software, often relying on signature-based and heuristic detection.

Endpoint Detection and Response (EDR)

Advanced security solution that continuously monitors and collects data from endpoints, using analytics to detect and respond to threats.

Firewall

Network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules.

Summary Takeaway

These core defenses form the backbone of modern cybersecurity, each with unique strengths and weaknesses that attackers must understand.
