Key Concepts

Essential terms to remember from this chapter

IDS/IPS

Systems that monitor (IDS) or actively block (IPS) network traffic for suspicious activity and known attack patterns.

Application Whitelisting (AWL)

A security measure that only allows explicitly approved applications to run on a system, blocking all others by default.

LOLBAS

Living Off The Land Binaries and Scripts: The practice of using legitimate, pre-installed tools on a system to carry out malicious actions.

Summary Takeaway

Effective penetration testing requires understanding these advanced defenses and the techniques used to bypass them.
