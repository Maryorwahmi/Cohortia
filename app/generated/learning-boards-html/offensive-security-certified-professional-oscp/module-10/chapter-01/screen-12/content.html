What is Application Whitelisting?

Application Whitelisting (AWL) is a security control that dictates which applications are permitted to run on a system. All other applications are blocked by default.

How AWL Works

  • Explicit Approval: Only applications on an approved list are allowed to execute.
  • Default Deny: Any application not on the whitelist is automatically prevented from running.
  • Reduces Attack Surface: Significantly limits the types of code an attacker can execute.
  • Strong Zero-Day Defense: Highly effective against unknown malware, as it won't be on the whitelist.
Key Takeaway

AWL is a powerful 'default deny' security model that prevents unauthorized code execution, but can be bypassed by abusing whitelisted binaries.

Whitelisting vs. Blacklisting

Two fundamental approaches to application control.

Blacklisting (AV)
  • Blocks known bad
  • Reactive
  • Vulnerable to unknowns
Whitelisting (AWL)
  • Allows known good
  • Proactive
  • Strong against unknowns

AWL provides a more secure default posture by denying everything not explicitly permitted.
