IDS/IPS Evasion

HTTP/HTTPS Evasion

Encapsulating malicious traffic within legitimate-looking HTTP or HTTPS requests helps blend C2 communications with normal web activity, leveraging commonly allowed ports (80/443).

  • •Blending In: Use common user-agent strings, legitimate-looking URLs, and standard HTTP methods.
  • •HTTPS Advantage: Encryption prevents IDS/IPS from inspecting the payload.
  • •Metadata Visibility: IDS/IPS can still see destination IP and SNI (Server Name Indication) for HTTPS.
Key Takeaway

HTTP/HTTPS evasion is effective due to its ubiquity and encryption, but requires careful customization of traffic patterns and selection of C2 domains to avoid detection by metadata analysis.

Mimicking Legitimate Traffic
Malicious PayloadRaw C2 Data
HTTP/HTTPS WrapperLegitimate-looking Headers
IDS/IPS ViewNormal Web Traffic

By wrapping C2 data in HTTP/HTTPS, it appears as benign web traffic, bypassing many detection systems.

Common Mistake

Using default C2 profiles with easily identifiable user-agent strings or beaconing patterns. Always customize your C2 profiles to blend in more effectively.
