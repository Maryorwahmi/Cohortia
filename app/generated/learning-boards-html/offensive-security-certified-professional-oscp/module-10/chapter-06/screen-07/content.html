DNS Tunneling

DNS tunneling encapsulates non-DNS traffic within DNS queries and responses, leveraging the fact that DNS (port 53) is almost always allowed outbound. This creates a stealthy covert channel.

  • •Mechanism: Client makes DNS requests for specially crafted subdomains (e.g., command.payload.evil.com).
  • •Attacker Server: Responds with encoded commands or data, disguised as DNS records.
  • •Tools: Popular tools include dnscat2 and iodine.
Key Takeaway

DNS tunneling is a highly stealthy method to bypass strict egress filtering by hiding C2 traffic within legitimate DNS communications, making it difficult to detect.

DNS Tunneling Flow

Malicious data is hidden within DNS requests and responses, allowing communication through port 53.

Real-world Connection

Many advanced persistent threats (APTs) use DNS tunneling for C2, as it's difficult to detect without deep packet inspection and behavioral analysis of DNS traffic.
