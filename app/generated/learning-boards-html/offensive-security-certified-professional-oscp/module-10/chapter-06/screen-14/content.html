Key Concepts: Tunneling & Evasion

Essential Techniques for Bypassing Network Defenses

Egress Filtering

Firewall rules that control and restrict outbound network traffic from a network, often a primary target for bypass.

Tunneling

Encapsulating one network protocol's data within another protocol, used to bypass firewalls or create secure channels.

SSH Tunneling

Using the Secure Shell protocol to create encrypted tunnels for various types of network traffic (dynamic, local, remote port forwarding).

Dynamic Port Forwarding

An SSH tunneling technique that creates a SOCKS proxy, allowing arbitrary traffic to be routed through the SSH connection.

Local Port Forwarding

An SSH tunneling technique that forwards a local port to a port on a remote server (or a host reachable from it).

Remote Port Forwarding

An SSH tunneling technique that forwards a port on a remote server to a port on the local machine.

Summary Takeaway

Mastering SSH tunneling, including dynamic, local, and remote port forwarding, is fundamental for bypassing egress filtering and establishing versatile covert channels in penetration testing.
