Covert Channel

ICMP Tunneling

ICMP tunneling encapsulates data within ICMP echo requests and replies, creating a covert channel where only basic network services are permitted. It's slower but highly effective in restricted environments.

  • •Mechanism: Data is hidden within the payload of ICMP packets (ping requests/replies).
  • •Condition: Requires outbound ICMP traffic to be allowed by the firewall.
  • •Tools: Common tools include icmpsh and ptunnel.
Key Takeaway

ICMP tunneling provides a low-bandwidth, high-stealth communication channel, making it a valuable option when other tunneling methods are blocked by strict egress filtering.

Common Misconception

ICMP tunneling is not always undetectable. Excessive or unusual ICMP traffic patterns can still trigger alerts on sophisticated IDS/IPS or network monitoring systems.
