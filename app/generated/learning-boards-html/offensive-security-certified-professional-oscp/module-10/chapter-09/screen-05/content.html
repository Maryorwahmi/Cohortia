Timestomping on Linux

Manipulating File Timestamps with touch

  • •Modify creation, modification, and access times of files.
  • •Evade forensic analysis by making malicious files appear legitimate.
  • •Use touch -r to reference timestamps from benign system files.
Example Scenario

You've deployed a backdoor script. To hide its recent creation, you match its timestamps to an old, trusted system binary like /bin/ls.

Key Takeaway

Timestomping on Linux with touch -r is a simple yet powerful way to obscure the true age of malicious files, hindering forensic efforts.

# Create a dummy file
touch /tmp/evil.sh

# Verify initial timestamps (example output)
stat /tmp/evil.sh
# Access: 2023-10-27 10:00:00.000000000 +0000
# Modify: 2023-10-27 10:00:00.000000000 +0000
# Change: 2023-10-27 10:00:00.000000000 +0000

# Change creation/modification time to match /bin/ls
touch -r /bin/ls /tmp/evil.sh

# Verify new timestamps (will match /bin/ls)
stat /tmp/evil.sh
# Access: 2022-01-15 08:30:00.000000000 +0000 (example)
# Modify: 2022-01-15 08:30:00.000000000 +0000 (example)
# Change: 2023-10-27 10:01:00.000000000 +0000 (current time)
Explanation

The touch -r command copies the reference file's access and modification times. Note that the 'Change' (inode modification) time will still update, but this is less commonly scrutinized than access/modification times for file age.
