Key Concepts (Continued)

Essential terms to remember from this chapter

PowerShell Empire

A post-exploitation framework that enables fileless operations, including the ability to execute .NET assemblies in memory.

execute-assembly

A PowerShell Empire module that allows running .NET executables or DLLs directly in memory on a target system.

Invoke-Mimikatz

A PowerShell script that loads and executes the functionality of Mimikatz entirely in memory, without writing the mimikatz.exe or mimikatz.dll files to disk.

Process Injection

The technique of injecting code into the address space of another running process.

Summary Insight

These tools and techniques are crucial for understanding how advanced adversaries operate and how to defend against them effectively.
