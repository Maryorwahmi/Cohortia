How Reflective DLL Injection Works

A detailed walkthrough of the in-memory loading mechanism.

Process Steps
  • Attacker allocates memory in target process.
  • Malicious DLL (with ReflectiveLoader) is written to memory.
  • Remote thread created, pointing to ReflectiveLoader.
  • ReflectiveLoader maps DLL, resolves imports, calls DllMain.
Example Target

Injecting into explorer.exe or notepad.exe to leverage their existing process space and permissions.

Key Takeaway

Reflective DLL injection is a multi-step process where a self-loading DLL is injected and executed entirely within a target process's memory, bypassing standard OS loading mechanisms.
