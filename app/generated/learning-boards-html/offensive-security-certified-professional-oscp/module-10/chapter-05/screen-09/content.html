Post-Exploitation Tooling

PowerShell Empire's execute-assembly

Running .NET executables directly in memory without touching disk.

Module Capabilities
  • Executes compiled .NET assemblies (.exe or .dll).
  • Operates entirely in memory on the target system.
  • Bypasses disk-based AV scans.
  • Ideal for deploying tools like Mimikatz or custom C# payloads.
Why it's Powerful

Enables stealthy execution of powerful .NET tools, leveraging the trusted PowerShell process and avoiding file system artifacts.

Key Takeaway

execute-assembly is a critical Empire module for fileless execution of .NET tools, offering significant stealth advantages in post-exploitation scenarios.

Empire's execute-assembly Flow
1Generate .NET Assembly
2Empire Agent on Target
3Load execute-assembly
4Execute In-Memory
