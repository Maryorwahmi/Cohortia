Key Concepts

Essential terms to remember from this chapter

Fileless Malware

Malicious code that operates entirely in a computer's memory, leveraging legitimate system tools without writing any executable files to disk.

In-Memory Execution

The technique of loading and executing malicious code directly within a process's memory space, rather than from a file on disk.

Reflective DLL Injection

A specific form of in-memory execution where a malicious DLL is loaded and executed directly from memory into a target process, bypassing traditional LoadLibrary calls.

ReflectiveLoader

A special function embedded within a reflective DLL that handles the process of mapping the DLL into memory, resolving imports, and transferring control to its entry point.

Summary Insight

These foundational concepts highlight how attackers leverage memory-resident operations to bypass traditional security and achieve stealth.
