Polymorphism: Dynamic Payload Alteration

Malware that changes its form but not its function

What is Polymorphism?

Polymorphism refers to malware that changes its internal structure and appearance with each infection or execution, while retaining its original functionality. This makes it difficult for static signature-based detection.

  • •Core Code Intact: The malicious payload remains functionally the same.
  • •Varied Appearance: Surrounding code, encryption keys, or instruction sequences are altered.
  • •Example: shikata_ga_nai generates a unique decoder stub each time.
Key Takeaway

Polymorphic malware changes its form to evade detection, but its core malicious logic remains constant, challenging static AV signatures.
