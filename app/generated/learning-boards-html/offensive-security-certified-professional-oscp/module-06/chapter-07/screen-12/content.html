Module 6.7 › Chapter 6.7 › XSS Filter Bypass Intro

Activity Objective

Identify a basic XSS filter and craft an XSS payload to bypass it using encoding or alternative tags to trigger an alert(1).

Prerequisites

  • Kali Linux VM
  • Vulnerable web application with a basic XSS filter (e.g., DVWA Reflected XSS, Medium security, or custom PHP page)
Key Takeaway

Bypassing XSS filters requires understanding how they operate and creatively leveraging HTML parsing quirks to execute malicious scripts.

Scenario: Filtered Script Tag

You've found a reflected XSS vulnerability, but the application filters out the <script> tag. Your goal is to make an alert(1) pop up.

Initial Attempt & Observation

// PHP filter example: $input = str_replace('<script>', '', $_GET['param']); // ... then $input is reflected in HTML // Your payload attempt: <script>alert(1)</script>

When you inject <script>alert(1)</script>, the filter removes the <script> tags, and no alert appears. This confirms the filter's presence.
