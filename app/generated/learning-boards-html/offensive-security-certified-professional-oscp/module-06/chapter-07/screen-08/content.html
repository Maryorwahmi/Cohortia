Common Evasion Tactics

  • Polymorphic Payloads: Malware that changes its code or signature to avoid detection by antivirus.
  • Code Obfuscation: Making code difficult to read and analyze, hindering static analysis by security tools.
  • Encryption: Encrypting malware to hide its malicious content until runtime, bypassing initial scans.
  • LOLBins (Living Off The Land Binaries): Abusing legitimate system tools (e.g., PowerShell, Certutil) for malicious purposes.
  • Zero-Day Exploits: Leveraging unknown vulnerabilities that security solutions have no signatures or behavioral patterns for.
Key Takeaway

Attackers continuously innovate evasion techniques, making it imperative for defenders to adopt multi-layered, behavioral-based security solutions and stay updated.

Evasion in Action: Example Scenario

Initial Phishing: Email with a link to a trusted cloud service.

Payload Delivery: User downloads an obfuscated PowerShell script from the cloud service.

Execution: Script runs using PowerShell (LOLBin), potentially evading AV/EDR.
