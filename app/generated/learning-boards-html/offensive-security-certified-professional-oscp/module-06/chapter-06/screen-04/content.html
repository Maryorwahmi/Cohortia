Definition

What are File Format Exploits?

Attacks that leverage vulnerabilities in software used to open and process common document types (e.g., PDF, Office documents). These flaws, when triggered by a specially crafted file, can lead to arbitrary code execution.

  • Target complex applications like PDF readers and Office suites.
  • Exploit flaws in parsers and rendering engines.
  • Goal: Deliver a payload (reverse shell, backdoor) upon file opening.
  • Bypasses many network-level defenses.
Key Takeaway

File format exploits are client-side attacks that leverage software vulnerabilities to execute malicious code, often requiring only user interaction to open a document.

Attack Flow

How They Work

1. Craft Malicious File: Attacker creates a document (e.g., PDF, DOCX) with embedded exploit code.

2. User Interaction: Victim is socially engineered to open the malicious document.

3. Exploit Triggered: Document reader's vulnerable code is activated, leading to code execution.

4. Payload Execution: Malicious code (e.g., reverse shell) runs on the victim's system.
