Key Concepts: Part 2

Advanced terms from this chapter

Modules

Pre-built scripts or functionalities within BeEF that allow attackers to perform specific actions on hooked browsers (e.g., create alerts, redirect, steal cookies).

XSS (Cross-Site Scripting)

A web security vulnerability that enables attackers to inject client-side scripts into web pages viewed by other users, often used to deliver BeEF hooks.

Summary Takeaway

BeEF's 'Modules' provide diverse exploitation capabilities, frequently delivered to victim browsers via 'Cross-Site Scripting' (XSS) vulnerabilities.
