Key Concepts: Part 1

Essential terms from this chapter

BeEF (Browser Exploitation Framework)

A penetration testing tool focused on exploiting vulnerabilities in web browsers, turning them into attack platforms.

Hooking

The process of injecting a JavaScript payload (`hook.js`) into a victim's web browser, establishing a persistent connection back to the BeEF server.

Command & Control (C2)

The infrastructure used by an attacker to maintain communications with compromised systems, in this case, hooked browsers.

Summary Takeaway

BeEF leverages browser vulnerabilities through 'hooking' to establish a Command & Control channel, enabling remote exploitation of client-side systems.
