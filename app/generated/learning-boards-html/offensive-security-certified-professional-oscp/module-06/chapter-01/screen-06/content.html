Attack Vectors

Web Browsers: A Gateway for Exploitation

Constant Interaction with Untrusted Content

  • •

    XSS (Cross-Site Scripting): Injecting malicious scripts into websites, executed in victim's browser.

  • •

    CSRF (Cross-Site Request Forgery): Tricking browsers into sending unauthorized authenticated requests.

  • •

    Browser Exploits: Targeting flaws in rendering engines or JavaScript interpreters for code execution.

Key Takeaway

Browsers are highly exposed attack surfaces due to their continuous processing of diverse, often untrusted, web content.

Browser Attack Flow
Malicious Website/Ad

Hosts exploit code or injected script.

Victim's Web Browser

Executes malicious code (XSS, CSRF, browser exploit).

Compromise

Session hijacking, data theft, malware installation.

Example

An attacker injects a script into a forum post. When another user views the post, the script runs in their browser, stealing their session cookie.
