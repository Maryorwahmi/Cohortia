Core Concept

The Client as a Target: Software and Human

Exploiting User Applications and Trust

  • •

    Software Vulnerabilities: Client applications (browsers, email, document readers) can have exploitable flaws.

  • •

    Human Trust: Users often interact with untrusted content, opening doors for social engineering.

  • •

    Goal: Compromise client system, gain control, or steal sensitive information.

Key Takeaway

Client-side attacks leverage both technical vulnerabilities in software and the human element of trust and interaction.

Client Vulnerability Model
Client Software

Browsers, Email, Docs

Human User

Curiosity, Trust, Urgency

Compromised System

Control, Data Theft

Scenario

A user opens a 'critical update' email attachment, which exploits a vulnerability in their PDF reader, leading to system compromise.
