Attack Vectors

Email and Documents: Malicious Delivery Channels

Phishing, Attachments, and Crafted Files

  • •

    Email Phishing: Deceptive messages with malicious links or attachments to steal info or deliver malware.

  • •

    Malicious Attachments: Files (e.g., ZIP, EXE) containing malware, often disguised as legitimate documents.

  • •

    Document Exploits: Crafted PDFs, Office files exploiting vulnerabilities in document readers for code execution.

Key Takeaway

Email and document processing software are critical attack vectors, relying on user interaction to trigger exploits or reveal sensitive data.

Email & Document Attack Flow
Malicious Email

Phishing link or attached crafted file.

Victim's Email Client/Reader

User opens email or attachment.

Compromise

Credential theft, malware execution.

Example

A user receives an email with a 'receipt.pdf' attachment. Opening it exploits a flaw in their PDF viewer, granting the attacker remote access.
