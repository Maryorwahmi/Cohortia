Core Concept

Client-Side vs. Server-Side: Understanding the Target

Where the Attack Executes Matters

Server-Side Attacks

Directly target vulnerabilities in server applications, services, or operating systems. The malicious code executes on the server itself.

Client-Side Attacks

Target vulnerabilities in software running on a user's device (e.g., browser, email client). Malicious code executes on the victim's machine.

Key Distinction

Server-side attacks compromise the server; client-side attacks compromise the user's endpoint.

Attack Execution Context
Server-Side

Targets server applications (e.g., database, web server)

Client-Side

Targets user applications (e.g., browser, email client)

Example Scenario

A SQL Injection attack directly queries a server's database. An XSS attack injects script into a webpage that executes in a user's browser.
