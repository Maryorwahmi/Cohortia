Chapter Review

Key Concepts

Essential Terms to Remember

Client-Side Attack

An attack targeting vulnerabilities in software running on a user's device (e.g., web browser, email client, document viewer) rather than directly on a server.

Attack Vector

The path or means by which an attacker gains access to a computer or network server in order to deliver a payload or malicious outcome.

User Interaction

The active participation of a human user, often unwitting, in facilitating an attack (e.g., clicking a link, opening a file).

Summary Takeaway

Client-side attacks target user-facing software, relying on specific attack vectors and often requiring user interaction to succeed.
