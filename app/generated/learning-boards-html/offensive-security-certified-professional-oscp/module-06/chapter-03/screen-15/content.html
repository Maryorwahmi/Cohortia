Key Concepts

Essential XSS Terminology

Cross-Site Scripting (XSS)

A web vulnerability allowing attackers to inject malicious client-side scripts into web pages viewed by other users.

Reflected XSS

The injected script is reflected off the web server and executed immediately in the victim's browser, typically via a malicious link.

Stored XSS (Persistent)

The injected script is permanently stored on the target server and executed whenever users access the affected content.

Summary Takeaway

XSS is a versatile client-side vulnerability with reflected and stored variants, each posing distinct risks for script injection and execution in user browsers.
