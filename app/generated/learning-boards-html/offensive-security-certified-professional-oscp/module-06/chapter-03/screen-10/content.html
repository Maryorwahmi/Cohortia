Bypassing XSS Filters - Basic Evasion

Understanding and Circumventing Sanitization Techniques

Common XSS Filters Target:

  • <script> tags
  • javascript: URLs
  • Event handlers (e.g., onload, onerror)
  • Specific characters (e.g., <, >, ")

Evasion Technique: Alternative Tags

If <script> is blocked, try other tags that can execute JavaScript:

<img src=x onerror=alert(1)>
<svg onload=alert(1)>

These leverage event handlers to trigger script execution.

Evasion Technique: Encoding & Obfuscation

Use encoding to bypass filters that look for literal strings:

&#x3C;script&#x3E;alert(1)&#x3C;/script&#x3E;

HTML entity encoding for < and >. Also, try breaking up keywords:

<scr<script>ipt>alert(1)</scr<script>ipt>

Pro Tip: Understand Context

The effectiveness of evasion techniques depends heavily on the context of the injection point (e.g., inside an HTML tag, attribute, or JavaScript string). Always analyze how your input is processed.

Key Takeaway

Basic XSS filter evasion involves using alternative HTML tags, character encoding, and keyword obfuscation to trick sanitization mechanisms and achieve script execution.
