Key Concepts

Essential Terms to Remember

Credential Harvesting

The process of collecting user authentication details (usernames, passwords) through deceptive means, often via phishing.

Fake Login Page

A fraudulent web page designed to mimic a legitimate login portal, used to trick users into submitting their credentials to an attacker.

Impersonation

The act of assuming the identity of another person, typically by using stolen credentials, to gain unauthorized access or deceive others.

Summary Takeaway

Credential harvesting is a multi-stage attack that uses deceptive fake login pages to capture user credentials, which are then leveraged for impersonation to gain unauthorized access to systems.
