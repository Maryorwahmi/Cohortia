Deploying Your Phishing Infrastructure

Setting Up Apache on Kali for Credential Capture

1

Navigate to Web Root

cd /var/www/html

This is Apache's default directory for serving web content.

2

Place Cloned Page

mv login.php index.html

Rename your cloned page (e.g., `login.php`) to `index.html` for default access.

3

Add Capture Script

cp capture.php .

Place your `capture.php` script in the same directory as your cloned page.

4

Start Apache Service

sudo service apache2 start

Ensure your web server is running to serve the phishing page.

Accessing Your Page

Once Apache is running, your phishing page will be accessible from a target machine by navigating to http://YOUR_KALI_IP/index.html (or the appropriate path if you didn't rename it).

Concrete Example

After cloning http://testphp.vulnweb.com/login.php into /var/www/html/testphp.vulnweb.com/, you would rename login.php to index.html and place capture.php there. Then, start Apache and access it via http://YOUR_KALI_IP/testphp.vulnweb.com/.

Key Takeaway

Proper deployment on an Apache server is crucial. This involves correctly placing your cloned page and capture script in the web root and ensuring the Apache service is active, making your phishing infrastructure operational.
