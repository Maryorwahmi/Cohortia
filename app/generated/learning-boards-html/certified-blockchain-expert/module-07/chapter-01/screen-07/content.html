Module 7 › Chapter 7.1 › Wallet Interaction
Process Flow

Connect wallet and send

1
Install & open wallet
User installs a wallet extension and selects a testnet like Sepolia for safe testing.
2
Connect to the DApp
User approves connection; the frontend receives an address and can display balances or permissions.
3
Prepare transaction
Frontend uses a web3 library to build a transaction object and requests signature from the wallet.
4
Wallet prompts & submit
The wallet displays gas fee details and approval information. If confirmed, the txn is broadcast and later mined on-chain.
Concrete example
Connect MetaMask on Sepolia, observe the popup when attempting a token swap and read the gas fee details before approving.
Common mistake
Treating the wallet as a server: the wallet only signs and authorizes; it does not store application state or execute business logic for the DApp.
