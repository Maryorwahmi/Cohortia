Module 7 › Chapter 7.1 › DApp Anatomy

Components

Frontend UI: Standard web code that renders and collects user input.
Web3 Library: Bridges the UI and blockchain, formats calls and helps with wallet integration.
Smart Contracts: On-chain logic and state—immutable once deployed unless designed otherwise.
Blockchain Network: Provides consensus, validation, and a public ledger recording transactions and state.
Decentralized Storage: Optional file stores for large media that are expensive on-chain.
Key takeaway
A DApp is a hybrid: keep UX in the frontend but move authoritative rules and state to smart contracts when decentralization is required.
Interaction flow
Concrete example
User clicks swap in the frontend, the web3 library prepares a transaction, the user signs with a wallet, and the contract executes the swap on-chain.
Misconception
Storing all data on-chain is necessary; instead, use decentralized storage for large files and keep critical state on-chain.
