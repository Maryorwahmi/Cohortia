Module 7 › Chapter 7.1 › Decentralized Storage

Why use decentralized storage?

Store large files off-chain and keep small, authoritative pointers on the blockchain to save cost and preserve integrity.

When to use
  • Large media or files that are too costly to store on-chain
  • When you need content-addressable, tamper-evident storage
  • For NFT assets where on-chain pointers reference off-chain content
Options
IPFS and Arweave are examples mentioned in this chapter. They keep content available without relying on a single cloud provider.
Concrete example
An NFT marketplace stores image files on IPFS and writes the content identifier into token metadata on-chain so buyers can verify the asset's authenticity.
Misconception
Decentralized storage eliminates all availability issues; in reality, persistence and access considerations still require design choices and possible pinning strategies.
