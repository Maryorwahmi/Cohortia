Module 7 › Chapter 7.1 › Key Concepts
Web3
A decentralized internet model where users hold more control and applications use blockchains for authoritative logic.
DApp
An application that runs backend logic via smart contracts on a blockchain while using a frontend for UX.
Decentralization
Distributes control and data to reduce single points of failure and increase resistance to censorship.
Takeaway: These concepts are tied—understand how decentralization influences design choices, security responsibilities, and user expectations.
