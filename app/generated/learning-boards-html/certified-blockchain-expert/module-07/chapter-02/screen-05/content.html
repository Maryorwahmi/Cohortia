Definition

Frontend (Client‑Side)

Responsible for UX, rendering blockchain data, and requesting signatures for transactions.

  • Uses familiar frameworks: React, Vue, Angular.
  • Integrates wallet adapters to prompt signature flows.
  • Fetches off‑chain assets like images from IPFS using hashes stored on‑chain.
Concrete example
A React UI reads NFT ownership from a contract and loads the artwork from IPFS using the content hash.
Sample Frontend Code (pseudo)
// Example: reading a contract and fetching IPFS image
const provider = new ethers.providers.Web3Provider(window.ethereum)
const contract = new ethers.Contract(address, abi, provider)
const owner = await contract.ownerOf(tokenId)
const cid = await contract.tokenURI(tokenId) // returns a content hash
// fetch image from IPFS gateway
const img = await fetch(`https://ipfs.io/ipfs/${cid}`)
Key Takeaway

Keep UX responsive and clearly communicate signing and confirmation states when the frontend triggers transactions.
