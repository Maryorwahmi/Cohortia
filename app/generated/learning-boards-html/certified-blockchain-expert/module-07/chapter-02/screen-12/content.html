Comparison

NFT Marketplace Stack

Frontend
React handles listings, wallet connections, and swap UI.
Middleware
ethers.js or wagmi to read contract state and send signed transactions.
Blockchain
Solidity contracts manage ownership, transfers, and royalties.
Storage
Artwork on IPFS; contract stores the CID as a reference.
Data Flow
User initiates buy → frontend assembles params → ethers.js requests wallet signature → wallet signs and broadcasts → contract transfers ownership on inclusion.
Key Takeaway

Map responsibilities clearly: on‑chain for ownership and rules; off‑chain for large assets and fast UI iterations.
