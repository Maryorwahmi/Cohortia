Hardhat Quick Setup

Follow the hands‑on steps to scaffold a local development environment for smart contracts.

1. Initialize project
mkdir my-first-dapp && cd my-first-dapp; npm init -y
2. Install Hardhat
npm install --save-dev hardhat
3. Create config
npx hardhat → select create an empty hardhat.config.js
Compile Outcome
// After npx hardhat compile
you'll find:
- artifacts/contracts/Greeter.sol/Greeter.json
- abi and bytecode inside the JSON

// Frontend uses ABI to build contract instance
const contract = new ethers.Contract(address, abi, provider)
Key Takeaway

Compiling produces the ABI that bridges contracts and frontend code; use a local Hardhat environment to iterate safely before deployment.
