Learning Objectives

These milestones guide practical competence: diagramming architecture, mapping tech, explaining smart contracts, and separating on‑chain from off‑chain responsibilities.

01
Diagram the DApp layers

Create a clear three‑layer diagram and explain the responsibilities of frontend, middleware, and smart‑contract backend.

VERIFIED COMPETENCY MILESTONE
02
Identify tech per layer

Map tools like React, ethers.js, Solidity, Hardhat, and IPFS to the correct layer and explain their role.

VERIFIED COMPETENCY MILESTONE
03
Explain smart contracts as backend

Describe how smart contracts manage state and enforce rules, with concrete examples like token transfers or NFT ownership.

VERIFIED COMPETENCY MILESTONE
04
Differentiate on‑chain vs off‑chain

Decide which data and logic must be on‑chain versus stored off‑chain for cost, speed, and trust reasons.
