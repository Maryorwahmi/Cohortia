Integration Snippet
// instantiate after wallet connect
counterContract = new ethers.Contract(counterContractAddress, counterContractABI, signer);

// read-only example
const currentCount = await counterContract.getCount();
console.log('Current Count:', currentCount.toString());

// state-changing example
const tx = await counterContract.increment();
console.log('Transaction sent:', tx.hash);
await tx.wait();
console.log('Transaction confirmed');

// event listener
counterContract.off('CountIncremented');
counterContract.on('CountIncremented', (user, newCount, event) => {
  console.log('EVENT: Count Incremented by', user, 'to', newCount.toString());
});
Example Note
Convert returned BigNumber values to string before displaying. Recreate the contract when signer becomes available.
Misconception
Do not assume contract.on fires before confirmation; rely on mined events or tx.wait confirmation for final state.
