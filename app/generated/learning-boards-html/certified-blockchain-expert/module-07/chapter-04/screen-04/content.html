Module 7 › Chapter 7.4 › Contract Address & ABI
What is a Contract Address?
A contract address is the blockchain location where the contract code and storage live. It is network-specific: an address on a local Hardhat node is different from Sepolia or mainnet.
What is an ABI?
The ABI is a JSON array describing functions and events. It allows libraries like ethers.js to encode function calls and decode return values and event logs.
Key Takeaway

Always use the compiled artifact ABI and deploy address from the same build and network to avoid mismatches.

Concrete Example
After compiling Counter.sol, open artifacts/contracts/Counter.sol/Counter.json and copy the abi array into app.js or import the JSON. Use the address printed by your deploy script as the contract address.
Common Mistake
  • Using an ABI that doesn't match the deployed bytecode.
  • Using an address from a different network than the provider you are connected to.
Mnemonic
Think: address = map location, ABI = dictionary of allowed actions.
