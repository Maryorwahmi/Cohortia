Module 7 › Chapter 7.4 › Learning Objectives
Practical Outcomes
Compile & Extract ABI
Use Hardhat to produce the artifacts and import the ABI into your frontend project.
Provider vs Signer
Use a provider for free reads; a signer is required for transactions and wallet prompts.
Event-driven UI
Subscribe to events for push updates and avoid frequent polling of view functions.
Assessment Tip
Run the provided deploy and interact scripts. You should see initial count, increment and decrement transactions, confirmations, and logged events in the terminal output.
