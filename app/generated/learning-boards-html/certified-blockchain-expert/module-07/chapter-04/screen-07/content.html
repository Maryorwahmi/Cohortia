Transaction Lifecycle

3. Broadcast
tx.hash returned

Example Flow
User clicks Increment → wallet opens → after signing the app shows transaction hash → await tx.wait() → refresh getCount() or wait for event.
Common Mistakes
  • Treating broadcast as confirmed.
  • Not handling user rejection errors (code 4001).
  • Not extracting revert messages from error.data.message.
