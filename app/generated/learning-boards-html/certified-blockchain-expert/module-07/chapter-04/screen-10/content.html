Module 7 › Chapter 7.4 › Deploy & Interact Scripts
Terminal-first Lab
Start a local Hardhat node, run the deploy script to get the address, paste it into interact.js, and run the interaction script to observe state changes and logged events in the terminal.
# start node
npx hardhat node

# deploy to localhost
npx hardhat run scripts/deploy.js --network localhost

# run interaction script
npx hardhat run scripts/interact.js --network localhost
Expected Terminal Output
You should see initial count, transaction hashes for increment/decrement, confirmations, and event logs printed by queryFilter.
Diagnostic Tip
If the script errors, confirm the ABI and address are from the same compiled artifact and network.
