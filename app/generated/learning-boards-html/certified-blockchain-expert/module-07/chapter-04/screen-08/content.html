Event Listener Pattern
Use contract.off to remove prior listeners, then contract.on to subscribe. The callback receives event args and a full event object, including the transaction hash.
// Example listener counterContract.off("CountIncremented"); counterContract.on("CountIncremented", (user, newCount, event) => { // update UI using newCount });
Why events matter
  • Push-based updates are more efficient than polling.
  • Events include indexed fields to filter important data like user addresses.
  • Historical events can be queried via queryFilter for a block range.
Common Mistake
Attaching listeners multiple times without removing them leads to duplicate UI updates and memory leaks.
