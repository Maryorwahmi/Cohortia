Module 7 › Chapter 7.4 › Hands-on Activity
Activity Steps
  1. Add Counter.sol to contracts and run npx hardhat compile.
  2. Run npx hardhat node and deploy with scripts/deploy.js to get address.
  3. Paste the address into scripts/interact.js and run it to observe logs.
  4. Confirm increment and decrement transactions and events are logged.
Expected Result
You will see initial count 0, increment and decrement tx hashes and confirmations, and event lines from queryFilter showing user and newCount.
Debug Tip
If events are missing, ensure you used the deployed contract address printed by the deploy script and the correct artifact ABI in interact.js.
