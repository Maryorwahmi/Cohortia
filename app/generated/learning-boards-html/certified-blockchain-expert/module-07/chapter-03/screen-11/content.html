Module 7 › Chapter 7.3 › Wallet events
accountsChanged
Handler guidance:
  1. If accounts array is empty, clear provider, signer, and userAddress and disable actions.
  2. If an address is present, set userAddress and optionally reinitialize signer.
  3. Refresh displayed balance and any account-scoped data.
chainChanged
Handler guidance:
  • Inform the user the network changed and reload or reinitialize provider and signer.
  • Check for network mismatch with your DApp expectations and show corrective instructions.
  • Avoid continuing operations that assume a prior chain context.
Why it matters

Handling these events prevents mistaken transactions and keeps on-screen data accurate as users change accounts or networks in their wallet.
