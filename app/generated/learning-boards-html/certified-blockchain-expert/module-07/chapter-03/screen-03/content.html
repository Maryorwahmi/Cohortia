Learning Objectives — UX & Safety

Practical checks to make your DApp reliable and trustworthy.

Bloom: Apply → Master
01
Detect wallet

Always check window.ethereum exists before calling methods. If missing, show a friendly install message and avoid runtime errors.

VERIFIED COMPETENCY MILESTONE
02
Manage UI state

Enable or disable buttons based on whether provider and signer are initialized to avoid confusing the user and reduce errors.

VERIFIED COMPETENCY MILESTONE
03
Handle rejections

Wrap requests in try...catch. Detect codes like 4001 to show user-friendly messages when the user declines a request.

VERIFIED COMPETENCY MILESTONE
04
React to changes

Listen for accountsChanged and chainChanged to refresh data and avoid operating on the wrong network or account.

VERIFIED COMPETENCY MILESTONE
