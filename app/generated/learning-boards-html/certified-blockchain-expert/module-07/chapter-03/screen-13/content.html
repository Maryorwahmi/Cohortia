Module 7 › Chapter 7.3 › Hands-on Activity
Task
  1. Implement async function displayAccountInfo() that checks signer and userAddress.
  2. Call provider.getBalance(userAddress) and format with ethers.formatEther.
  3. Append Connected Address and Balance to outputDiv and call this from connect handler.
async function displayAccountInfo() {
  if (!signer || !userAddress) {
    outputDiv.textContent += '
Wallet not connected.';
    return;
  }
  try {
    const balance = await provider.getBalance(userAddress);
    outputDiv.textContent += `
Connected Address: ${userAddress}
Balance: ${ethers.formatEther(balance)} ETH`;
  } catch (error) {
    outputDiv.textContent += `
Error displaying account info: ${error.message}`;
  }
}

getAccountInfoBtn.addEventListener('click', displayAccountInfo);
Testing checklist
  • Run a local server and open the page in a browser with MetaMask installed.
  • Connect wallet and confirm the formatted balance appears automatically.
  • Test getAccountInfo button to confirm manual refresh works.
Key Takeaway

Showing the balance immediately after connection improves user trust and confirms the app is correctly linked to the wallet.
