Module 7 › Chapter 7.3 › Connect Wallet Code
Key snippet
connectWalletBtn.addEventListener('click', async () => {
  if (typeof window.ethereum !== 'undefined') {
    try {
      await window.ethereum.request({ method: 'eth_requestAccounts' });
      provider = new ethers.BrowserProvider(window.ethereum);
      signer = await provider.getSigner();
      userAddress = await signer.getAddress();
      outputDiv.textContent = `Wallet connected: ${userAddress}
`;
      updateUI(true);
      window.ethereum.on('accountsChanged', (accounts) => { /* handle */ });
      window.ethereum.on('chainChanged', (chainId) => { window.location.reload(); });
    } catch (error) {
      outputDiv.textContent = `Error connecting wallet: ${error.message}`;
      updateUI(false);
    }
  } else {
    outputDiv.textContent = 'MetaMask not detected.';
  }
});
Explanation & best practices
  • Always check window.ethereum before calling requests to avoid exceptions.
  • Call updateUI only after provider and signer are initialized so buttons reflect true state.
  • Use event listeners to react to wallet changes rather than relying on a page refresh alone.
Misconception

Assuming a connected signer never changes. Users can switch accounts or networks at any time; always verify before sending transactions.
