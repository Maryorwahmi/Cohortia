Learning Objectives

Skills you will practice and verify in this chapter.

Bloom: Learn → Understand → Apply → Master
01
Project setup

Create a Node project and install ethers.js so the frontend can import provider and signer APIs. This gets your tooling ready for integration and local testing.

VERIFIED COMPETENCY MILESTONE
02
Connect a wallet

Use eth_requestAccounts and BrowserProvider to request user permission and obtain a signer for transaction signing. This step ensures the app acts on behalf of the user only after consent.

VERIFIED COMPETENCY MILESTONE
03
Read account info

Call provider.getBalance and signer.getAddress, then format the BigInt balance into ETH. Display it immediately after connecting the wallet for good UX.

VERIFIED COMPETENCY MILESTONE
04
Send transactions

Construct a transaction using parseEther for the value, call signer.sendTransaction, and await tx.wait to confirm the transaction was mined.

VERIFIED COMPETENCY MILESTONE
