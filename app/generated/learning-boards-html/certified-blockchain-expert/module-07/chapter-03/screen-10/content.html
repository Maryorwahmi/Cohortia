Module 7 › Chapter 7.3 › Provider Comparison
Browser-injected (MetaMask)
  • Requires user wallet; exposes window.ethereum.
  • Provides signer capabilities after user grants permission.
  • Best for operations where user must sign transactions.
RPC providers (Infura, Alchemy)
  • Server or client endpoints for node access without a wallet.
  • Great for read-only queries and app-level data fetching.
  • Cannot sign on behalf of the user; not a replacement for a signer.
Practical pattern

Use RPC providers for background reads and BrowserProvider for actions that require user signatures. This split reduces wallet prompts and improves performance for heavy queries.
