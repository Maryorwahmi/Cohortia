Module 7 › Chapter 7.3 › Quick Reference
Detect wallet
Check window.ethereum before calling any wallet method.
Provider vs Signer
Use provider for reads and signer for operations that require signatures.
User consent
Always wrap sending calls in try...catch and handle rejection codes gracefully.
Final takeaway

Build with clear wallet checks, separate reads and writes, and explicit user consent to make dependable, safe DApp frontends.
