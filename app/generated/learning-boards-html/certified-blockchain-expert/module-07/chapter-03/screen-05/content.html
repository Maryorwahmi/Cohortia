Module 7 › Chapter 7.3 › Provider vs Signer
Definition
Provider

An interface for querying chain data. Use it to get balances, block info, and read-only contract state. Example: provider.getBalance(address).

Signer

Represents an account able to sign transactions and messages. It prompts the user through their wallet for consent before sending transactions.

Contrast & examples
  • Use provider.getBalance(address) to read a balance without user prompts.
  • Use signer.sendTransaction({ to, value }) to request the wallet sign and broadcast a transfer.
  • Use public RPC providers for heavy read work; reserve signer usage for actions requiring user consent.
Key Takeaway

Keep queries and signing separate: provider for reads, signer for writes requiring explicit user approval.
