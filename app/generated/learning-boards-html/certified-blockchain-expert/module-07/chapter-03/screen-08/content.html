Module 7 › Chapter 7.3 › Get Account Info
displayAccountInfo
async function displayAccountInfo() {
  if (!signer || !userAddress) {
    outputDiv.textContent += '
Wallet not connected.';
    return;
  }
  try {
    const balance = await provider.getBalance(userAddress);
    outputDiv.textContent += `
Connected Address: ${userAddress}
Balance: ${ethers.formatEther(balance)} ETH`;
  } catch (error) {
    outputDiv.textContent += `
Error displaying account info: ${error.message}`;
  }
}
Notes & pitfalls
  • formatEther converts BigInt to decimal ETH string for display.
  • Balances can be out of date if there are pending transactions; refresh after confirmations.
  • Always guard calls with signer and userAddress checks to avoid exceptions.
Key Takeaway

Fetch balance with provider.getBalance and convert with ethers.formatEther so users see readable ETH amounts.
