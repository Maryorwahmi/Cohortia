Commands
mkdir dapp-frontend
cd dapp-frontend
npm init -y
npm install ethers
npx http-server
Serve files locally so the browser can load index.html and MetaMask can inject window.ethereum. Use a testnet for practice to avoid mainnet cost.

Why this matters
  • Correct package setup avoids import errors when using the ESM build of ethers.
  • Running a local server avoids file:// restrictions and allows injected providers to initialize correctly.
  • Using a testnet prevents accidental mainnet transactions during development.
Key Takeaway

A reliable local setup is essential: install ethers and serve your files so wallet injection and imports work smoothly.
