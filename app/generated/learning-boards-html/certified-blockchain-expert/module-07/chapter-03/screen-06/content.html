Module 7 › Chapter 7.3 › Wallet connection
Steps
1. Detect wallet

if (typeof window.ethereum !== 'undefined') then proceed, otherwise show install guidance.

2. Request accounts

await window.ethereum.request({ method: 'eth_requestAccounts' }) — user sees wallet prompt and must approve.

3. Initialize provider & signer

provider = new ethers.BrowserProvider(window.ethereum); signer = await provider.getSigner();

UI and event handling
  • Update connect button text and enable action buttons after connection.
  • Listen for window.ethereum.on('accountsChanged') to refresh address and balances.
  • Listen for window.ethereum.on('chainChanged') to detect network mismatch and reload or reinitialize as needed.
Common mistake

Not wrapping eth_requestAccounts in try...catch. When a user rejects, handle it gracefully rather than leaving the UI blocked.
