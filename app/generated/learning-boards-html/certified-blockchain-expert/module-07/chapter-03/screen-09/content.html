Module 7 › Chapter 7.3 › Send ETH
Transaction snippet
const recipientAddress = '0xYourRecipientAddressHere';
const amountToSend = ethers.parseEther('0.001');
try {
  outputDiv.textContent += `
Initiating transaction to ${recipientAddress} for ${ethers.formatEther(amountToSend)} ETH...`;
  const tx = await signer.sendTransaction({ to: recipientAddress, value: amountToSend });
  outputDiv.textContent += `
Transaction sent! Hash: ${tx.hash}`;
  outputDiv.textContent += `
Waiting for transaction to be mined...`;
  await tx.wait();
  outputDiv.textContent += `
Transaction confirmed!`;
} catch (error) {
  outputDiv.textContent += `
Error sending ETH: ${error.message}`;
  if (error.code === 4001) outputDiv.textContent += '
Transaction rejected by user.';
  if (error.code === 'INSUFFICIENT_FUNDS') outputDiv.textContent += '
Insufficient funds for gas.';
}
Guidance
  • Replace placeholder recipient addresses before sending on any network.
  • Show clear status updates during submission and confirmation so users don’t retry prematurely.
  • After confirmation, refresh balances to reflect the new state.
Common mistake

Sending without confirming network and address changes can result in lost funds or transactions on the wrong chain.
