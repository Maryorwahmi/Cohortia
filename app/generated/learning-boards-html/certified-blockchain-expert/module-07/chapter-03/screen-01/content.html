Frontend Development for DApps

Connect wallets, fetch balances, and send transactions safely using ethers.js. Practical patterns and common pitfalls included.

Duration: Live coding session
In this lesson

Install ethers, connect MetaMask using eth_requestAccounts, read address and balance, and send a test transaction with confirmation handling.

Why it matters

Every transaction requires a signed approval. The frontend must communicate network state and errors clearly to users to avoid lost funds.

Coming up

Provider vs signer, getBalance, sendTransaction and tx.wait(), and event handling for account and chain changes.

Safety note

Never request private keys in the frontend. Use wallet prompts and handle rejections gracefully.
