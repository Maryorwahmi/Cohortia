Module 7 › Chapter 7.3 › Key Concepts
Provider
Read-only interface for querying chain data like balances and blocks.
Signer
Account abstraction capable of signing transactions; requires wallet consent.
tx.wait()
Waits for a transaction to be mined and returns a receipt with confirmation details.
Summary

Use provider for reads, signer for writes, always check window.ethereum, handle user rejections, and test on a testnet before mainnet deployment.
