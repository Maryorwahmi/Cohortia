Supply Chain & XSS
Dependencies and injection attacks
Reduce risk by controlling what runs in user browsers and review third-party code carefully.
Supply chain defenses
  • Pin dependency versions and check lockfiles into version control.
  • Use reputable libraries and audit updates before merging.
  • Use CI to verify reproducible builds.
XSS prevention
  • Sanitize all user input and encode output.
  • Avoid inserting raw HTML from untrusted sources.
  • Prefer framework templating that auto-escapes content.
Common mistake

Trusting a dependency because it’s popular. Popularity is not a substitute for code review and pinned versions.
