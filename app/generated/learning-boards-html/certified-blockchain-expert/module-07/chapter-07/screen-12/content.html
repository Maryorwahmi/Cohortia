Frontend Security
Phishing & key management
Protect the user journey and delegate sensitive operations to trusted wallets.
Phishing risks
Fake sites can prompt users to approve dangerous transactions. Users must confirm domain authenticity and transaction details before signing.
Developer actions
Enforce HTTPS, display clear transaction metadata, and provide warnings about suspicious links.
Key management & supply chain
Never request or store user private keys. Use wallet integrations and audit third-party packages and pinned versions to avoid injected code.
Key Takeaway

Delegate signing to secure wallets and educate users to verify domains and transaction intent before approving.
