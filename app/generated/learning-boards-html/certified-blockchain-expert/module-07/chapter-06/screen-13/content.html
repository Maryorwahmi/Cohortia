Module 7 › Chapter 7.6 › Deploy PriceConsumer
Deployment checklist
  1. Install @chainlink/contracts in your project.
  2. Add PriceConsumerV3.sol with the correct feed address for your network.
  3. Compile, configure Hardhat network with RPC key and private key, fund testnet account.
  4. Run deploy script and copy the deployed address.
  5. Attach in console and call getLatestPrice, then convert using feed decimals.
Expected output
A deployed contract address and a printed integer representing the scaled price. Use formatUnits or divide by ten to the feed decimals to display the human price.
Common pitfalls
Wrong feed address, insufficient gas, wrong compiler version, or forgetting to fund LINK when using job-based requests.
Why it matters
Seeing the live feed confirms your contract can trust and act on external data — a fundamental capability for many DApps.
