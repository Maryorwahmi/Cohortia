Oracle Problem
Smart contracts cannot directly access external APIs or sensors, limiting on-chain logic unless bridged.
Blockchain Oracle
A service that fetches off-chain data, formats it, and delivers it for contract consumption.
Decentralized Oracle Network
A network of nodes that fetch and aggregate data, reducing single-node risk for critical applications.
Summary Takeaway

Treat oracle choice as a core security decision: prefer aggregated, decentralized feeds for high-value logic and always validate freshness and format.
