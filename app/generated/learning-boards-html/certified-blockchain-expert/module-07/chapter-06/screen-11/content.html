Operational notes
You must fund the contract with LINK tokens and configure the jobId and node operator. Ensure your fulfill function protects against reentrancy and checks the originating requestId.
Key Takeaway
API requests require node operators and LINK payment. Treat callbacks as external transactions and validate them carefully.
