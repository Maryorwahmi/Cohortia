Module 7 › Chapter 7.6 › Chainlink Request Flow
Request lifecycle
1. Requester creates request and pays fee
2. Nodes detect request and accept job
3. Nodes fetch external API or adapter
4. Nodes submit on-chain responses
5. Aggregation and consumer reads final value
Concrete example
A PriceConsumer requests ETH/USD. Several nodes query exchanges, transform data to the agreed format, and post results. The aggregator contract computes a median or weighted average and stores the latestRoundData for consumers to query.
Design checklist
  • Ensure adequate LINK funding or payment model for requests.
  • Check update cadence vs freshness requirements.
  • Validate timestamps or answered-in-round fields for staleness protection.
