Module 7 › Chapter 7.6 › Chainlink Architecture
Core components
  • Requester contract: emits a request for external data.
  • Chainlink Oracle nodes: independent operators that fulfill requests.
  • External adapters: node plugins that connect to specific APIs or systems.
  • Decentralized data feeds: aggregated, tamper-resistant contracts that expose a single trusted value.
Practical note
Before relying on a feed, inspect node diversity, update frequency, and any available reputation metrics. Aggregation parameters determine how individual reports are combined into the final value.
Concrete example
An ETH/USD price feed aggregates multiple node reports into a single aggregated answer contract that many consumer contracts subscribe to for consistent pricing.
Key Takeaway
Chainlink separates request logic from node execution and aggregation, lowering the risk of single-node manipulation when used correctly.
