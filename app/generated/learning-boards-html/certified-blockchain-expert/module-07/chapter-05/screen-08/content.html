Module 7 › Chapter 7.5 › ipfs-http-client example
Setup
Install ipfs-http-client in your Node or frontend project and ensure an IPFS daemon or remote gateway with HTTP API is available.
Use case
Upload a user's NFT image, get the CID, include it in an NFT metadata JSON, then store the metadata CID on-chain.
Misconception
Do not assume public gateways are always available during testing; use a local daemon for development when possible.
Code snippet
import { create } from 'ipfs-http-client';

// Connect to a local IPFS node
const ipfs = create({ host: 'localhost', port: 5001, protocol: 'http' });

async function uploadFileToIPFS(fileContent) {
  try {
    const { cid } = await ipfs.add(fileContent);
    console.log("Uploaded to IPFS. CID:", cid.toString());
    return cid.toString();
  } catch (error) {
    console.error("Error uploading to IPFS:", error);
    return null;
  }
}

async function retrieveFileFromIPFS(cid) {
  try {
    const chunks = [];
    for await (const chunk of ipfs.cat(cid)) {
      chunks.push(chunk);
    }
    const fileContent = Buffer.concat(chunks).toString();
    console.log("Retrieved from IPFS:", fileContent);
    return fileContent;
  } catch (error) {
    console.error("Error retrieving from IPFS:", error);
    return null;
  }
}
Example flow
Read file into ArrayBuffer, pass to uploadFileToIPFS, receive CID string, then send CID to your smart contract as a metadata pointer.
