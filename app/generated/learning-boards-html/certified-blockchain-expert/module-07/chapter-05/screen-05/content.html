Module 7 › Chapter 7.5 › Content vs Location
Location addressing (HTTP)
A URL points to a specific server and path. If the server moves or the file is replaced, the URL no longer guarantees the original content.
  • Depends on server availability
  • Can be modified without notice
Content addressing (IPFS)
A CID is a cryptographic hash of the content. Any change results in a different CID, so the identifier guarantees integrity.
  • Host-agnostic retrieval
  • Immutable content identity
Concrete example
Two websites can serve an image named "logo.png". Only a CID proves that both deliver the same bytes. If you store the CID on-chain, anyone can fetch from any IPFS node and validate the content is unchanged.
Misconception check
Content addressing does not remove the need to host content; it only makes the identity verifiable. You still need nodes to serve the bytes.
Key takeaway
CIDs prove exactly what you requested, independent of where it is hosted.
