Module 7 › Chapter 7.5 › IPFS add & retrieve
Steps
  1. Start IPFS daemon: ipfs daemon
  2. Add file: ipfs add filename
  3. Get CID from response and use ipfs cat CID to view
  4. Optional: pin CID or use pinning service
Concrete example
Create hello.txt with "Hello Cohortia!", run ipfs add hello.txt, note the returned CID, then ipfs cat that CID to see the content.
Key takeaway
The CID is your verifiable pointer. Pin it for availability and store it on-chain when you need an immutable reference.
CLI example
# Start the daemon
ipfs daemon

# Add a file
ipfs add hello.txt
# output: added Qm... hello.txt

# Read file
ipfs cat Qm...
Pro tip
After adding, immediately pin the CID on a remote pinning service or additional nodes if you need long-term availability.
