Module 7 › Chapter 7.5 › Activity: Upload metadata
Steps
  1. Start ipfs daemon.
  2. Upload image first, note image CID.
  3. Create nft_metadata.json with image field set to ipfs://IMAGE_CID/filename.
  4. Run ipfs add nft_metadata.json and copy metadata CID.
  5. Open https://ipfs.io/ipfs/METADATA_CID to verify.
Common mistake
Uploading metadata before the image causes broken image references. Always upload assets first and pin them before creating metadata.
Starter JSON
{
  "name": "Cohortia Expert Badge",
  "description": "A badge signifying expertise in blockchain technology from Cohortia.",
  "image": "ipfs://QmVgQ7...YOUR_IMAGE_CID.../cohortia_badge.png",
  "attributes": [
    { "trait_type": "Course", "value": "Certified Blockchain Expert" },
    { "trait_type": "Level", "value": "Intermediate" },
    { "trait_type": "Year", "value": 2023 }
  ]
}
Reflection
How will you ensure the image and metadata CIDs remain available to collectors after minting? Consider pinning and replication strategies.
