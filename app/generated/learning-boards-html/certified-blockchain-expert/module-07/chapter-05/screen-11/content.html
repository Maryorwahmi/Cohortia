Module 7 › Chapter 7.5 › Privacy & Gateways
Privacy
Do not store unencrypted sensitive data on IPFS. Anyone who can access a CID can request the content if it is hosted.
Mutability
Every content change yields a new CID. Use name systems if you need a stable mutable pointer to the latest CID.
Misconception
IPFS is not confidential by default. Integrity is guaranteed by CIDs, privacy is the developer's responsibility.
Gateway reliance
A public gateway provides HTTP access to IPFS content but introduces a single point you may rely on. For resilience, encourage running nodes or use multiple gateways.
Key takeaway
Design for privacy, mutability, and redundancy up front. Encryption and pinning are core operational requirements.
