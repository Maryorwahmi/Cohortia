Definition
Layer 1 (L1)

The base blockchain that handles consensus, validation, and final settlement. Any change here affects the global state and security.

Role: ultimate settlement and security root
Trade-off: can become a throughput bottleneck if every transaction is on-chain
Definition
Layer 2 (L2)

Protocols built on top of L1 to run transactions off-chain or in parallel, reducing fees and latency while relying on L1 for settlement or dispute enforcement.

Role: increase throughput and lower cost
Misconception: not all L2s inherit full L1 security automatically
Question to decide
Does your operation require global finality? If yes, prefer on-chain settlement; if no, consider L2 designs.
Example
Micropayments: move off-chain with state channels. Token bridging: use sidechains with two-way peg.
Key takeaway
L2s solve throughput limits by shifting execution while trading off different security properties depending on design.
