Definition
Sidechain

An independent blockchain that runs in parallel to L1 with its own consensus, validators, and token economics.

Use case: dApps that require a fast, configurable environment and EVM compatibility.
Warning: security depends on sidechain validator honesty and bridge mechanics.
Mechanism
Two-way peg

Lock asset on L1 → mint equivalent token on sidechain → use it there → burn representation on sidechain → unlock on L1.

Example: Lock ETH on mainnet, mint pegged ETH on Polygon, burn to unlock later.
Misconception: Pegging does not automatically transfer L1 consensus to the sidechain.
Security checklist
  • Who controls the bridge and validator set?
  • Are there economic incentives and slashing for validators?
  • How quickly can funds be recovered if validators misbehave?
