Process Flow
State Channel Steps
1
Open channel (on-chain)
Participants lock funds into a channel contract. This is the only required on-chain setup for many flows.
2
Off-chain updates
Signed state updates are exchanged and replace previous states. These are instant and fee-free off-chain interactions.
3
Dispute period
If an old state is posted, a challenge window allows a newer signed state to be submitted to the contract.
4
Close and settle
The final agreed state is broadcast and funds are released according to balances.
Key Takeaway

State channels minimize on-chain interactions to setup and settlement while requiring signed off-chain state handling and dispute monitoring.

Example: Micropayments
Alice and Bob open a channel with 5 and 3 ETH. They exchange many signed updates and finally close with the latest balance submitted on-chain for settlement.
Common mistake: Assuming channels are safe if participants go offline. Monitoring or delegate services are often needed.
Pro tip: Set short dispute windows with reliable monitoring for active participants; longer windows reduce risk for absent parties.
