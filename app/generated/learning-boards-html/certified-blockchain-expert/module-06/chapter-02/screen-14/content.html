Module 06 › Chapter 6.2 › Key Concepts
L2 Scaling
Move execution off L1 to increase throughput while using L1 for final settlement.
State Channels
Lock funds, exchange signed off-chain updates, settle final state on L1; great for micropayments.
Sidechains
Parallel chains using a two-way peg; faster and configurable but dependent on validator security.
Final summary
Choose the L2 pattern that matches transaction frequency, required finality, and acceptable trust assumptions. Design monitoring and dispute handling from the start.
