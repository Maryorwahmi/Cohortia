State channel examples
Lightning Network for Bitcoin: optimized for micropayments and routing across channels. Raiden for Ethereum: similar model applied to ERC-20 tokens.
Typical use: micropayments, instant transfers, low fees
Sidechain examples
Polygon: EVM-compatible sidechain with bridges for asset transfer. Liquid Network: Bitcoin sidechain focused on faster, confidential transactions.
Typical use: dApps needing faster blocks and cheaper execution
Evaluation prompt
For your project, list which parts need instant payments versus which need full contract environments, then match those to a channel or sidechain approach.
