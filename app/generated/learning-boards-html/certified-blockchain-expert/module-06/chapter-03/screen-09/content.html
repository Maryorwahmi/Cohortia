Module 06 › Chapter 6.3 › ZK-Rollup Validity Proofs
What the ZKP proves

Correct state computation

The proof certifies that the new state root matches the application of the transactions to the previous state root. L1 verifies the proof and finality is immediate.

Does not remove data availability — rollups still post data or commitments so state is reconstructible.
Proof generation is computationally expensive and requires circuit design expertise.
Concrete example
A batch with three transfers is accompanied by a ZK validity proof that mathematically guarantees the resulting state root is correct. The L1 contract verifies this and accepts the batch instantly.
Key Takeaway

ZK-Rollups use cryptographic proofs for immediate finality, trading lower latency for higher proof-generation complexity.
