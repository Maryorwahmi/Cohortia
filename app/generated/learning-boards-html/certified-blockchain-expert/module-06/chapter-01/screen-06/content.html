Module 06 › Chapter 6.1 › Security
What security means
Resistance to attacks that alter history or allow double-spends, achieved via cryptography, consensus and economic costs.
Mechanisms
Consensus rules, staking or mining costs, and replication across nodes.
Socio-economic angle
Security depends on incentives and the real-world cost required to mount an attack, not only on math.
Concrete example
Both Bitcoin and Ethereum have invested in consensus and economic mechanisms that make attacks costly, improving ledger immutability and user trust.
Misconception
Security is not only algorithmic strength; weak incentive design or concentrated control can undermine security despite strong cryptography.
Key Takeaway

Assess both technical defenses and incentive alignment when judging security.
