Module 06 › Chapter 6.1 › Layered Approaches
Why layering works
By assigning settlement to a secure base layer and throughput to secondary layers, projects balance strong guarantees with higher performance.
Layer 1 (L1)
Focuses on decentralization and security—final settlement and canonical state.
Layer 2 (L2)
Handles high-frequency transactions and improves throughput, settling periodically to L1.
Key Takeaway

Layered architectures let each layer optimize for a subset of properties while preserving a secure settlement anchor.

L2 examples
State channels, sidechains, and rollups move work off-chain or off the main consensus while relying on L1 for security.
Misconception
Assuming Layer 2 completely inherits all L1 guarantees without explicit settlement rules—design matters.
