Module 06 › Chapter 6.1 › Analysis Template
Step-by-step
  1. Choose two projects
  2. Gather architecture & consensus details
  3. Identify observable priorities
  4. Map to the trilemma
  5. Justify with technical evidence
  6. Write a 200–300 word analysis per project
Example prompts
What consensus does the project use? How many independent validators exist? Does the project rely on Layer 2s or sharding? Which property appears compromised?
Tip

Be explicit about assumptions and use measurable evidence rather than marketing statements.
