Oracle: fetch, verify, deliver
An oracle obtains off-chain data, applies verification or cross-checks, and publishes the result on-chain so smart contracts can use it deterministically.
Fetch
Nodes query APIs, exchanges, or sensors to gather raw data points.
Verify
Cross-check sources, validate formats, and detect anomalies before submission.
Deliver
Submit the validated data in a deterministic on-chain transaction for the consumer contract.
Concrete scenario
A lending protocol needs an ETH/USD price. A decentralized oracle network collects prices from multiple exchanges, verifies differences, aggregates them, and writes a single price that the protocol can read for liquidation decisions.

Key Takeaway

Oracles formalize how external facts enter the blockchain: they must fetch, verify, and deliver data in a way that preserves determinism and trust.
