Objective: Oracle Security

Identify how false data from an oracle can produce harmful outcomes and what properties make an oracle trustworthy.

  • Understand possible failure modes
  • Recognize the need for aggregation and redundancy
  • Know that incentives matter to node behavior
VERIFIED COMPETENCY MILESTONE
Objective: Hands-on Mock Oracle

Deploy a mock oracle contract and a consuming contract, simulate a price update, then call the consumer to read the price and resolve a market.

  • Practice deployment order and owner updates
  • Observe how an on-chain consumer reads stored values
  • Test the resolve flow after time has elapsed
VERIFIED COMPETENCY MILESTONE
Why this matters

Oracles connect the blockchain to practical applications. If those connections are weak or single-sourced, you trade off decentralization, opening your contract to manipulation or outage. Practicing with a mock oracle reveals those trade-offs in a safe environment.
