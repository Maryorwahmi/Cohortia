Module 6 › Chapter 6.4 › Layer 1 vs Layer 2
Definition & contrast
Layer 1 scaling changes the base protocol; Layer 2 reduces base load by moving work off-chain.
Layer 1 example
Sharding splits the base chain into parallel shards that each handle subset of transactions and state.
Layer 2 example
Rollups batch many transactions off-chain and publish compressed proofs to Layer 1.
Common misconception
They are not exclusive. Effective scaling often mixes a stronger base layer and Layer 2s for specialized throughput.
Why it matters
  • Layer 1 changes affect node resource needs and decentralization.
  • Layer 2 can be deployed faster but relies on a secure base layer for settlement.
  • Sharding as a Layer 1 change increases parallelism but raises design complexity.
Key Takeaway

Decide whether scaling needs a base-layer change or an off-chain design by weighing throughput needs against decentralization costs.
