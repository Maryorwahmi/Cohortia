Module 6 › Chapter 6.4 › Key Concepts
Beacon Chain
A coordinating layer that assigns validators and anchors shard security and finality.
Data Availability Committees
Committees that guarantee shard data is available for verification; they help light clients but add trust assumptions.
Block Size Increase
Increasing block size raises TPS but increases node resource requirements and can reduce decentralization.
Final takeaway

Sharding offers the most comprehensive L1 scaling path but requires careful design for communication, data availability, and validator coordination. Use the trade-offs described here to evaluate proposals thoughtfully.
