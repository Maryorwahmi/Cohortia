Module 6 › Chapter 6.4 › Execution Shards
State partitioning
Shards hold local accounts and contracts. Design determines how state is located and accessed across shards.
Local execution
Transactions that only touch local state complete without cross-shard messaging.
Partition strategies
Hash-based address mapping or application-level assignment decides which shard owns a contract or account.
Developer considerations
  • Design contracts with cross-shard messaging patterns in mind.
  • Provide clear state discovery mechanisms so clients find where contracts live.
  • Plan failure and rollback modes for cross-shard calls to avoid partial operations.
Key Takeaway

Sharding shifts execution concerns into partitioning and messaging; good API and state lookup patterns make cross-shard use practical.
