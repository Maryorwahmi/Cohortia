Advanced Oracles: From Feeds to Functionality
Oracles as sources of proofs, compute, and verified attributes.
What makes an oracle "advanced"?
  • • Produces cryptographic proofs with data (e.g., VRF proofs) so the contract can verify authenticity.
  • • Executes heavy or specialized computation off‑chain and returns verifiable results to save gas.
  • • Provides identity attestations or attributes in a privacy-preserving way for compliance or reputation.
Common misconception: an oracle that returns a single signed number is not functionally equivalent to one that returns a proof of a complex off-chain computation.
Concrete example
A video game mints NFTs where rarity is assigned by a VRF for fairness, while a separate computation oracle periodically calculates leaderboards using off‑chain match data and submits a proof to the contract. Both oracles reduce on‑chain cost but differ in proof and trust expectations.
Key takeaway
Key Takeaway

Match the oracle capability to the dApp requirement: randomness, verified compute, or identity—each requires different proofs and trust levels.
