Key Concepts
Verifiable Random Function (VRF)
A provable source of randomness that returns a number with a cryptographic proof the contract can verify.
Computation Oracle
Performs heavy off‑chain computation and returns verified results, often with ZK proofs or optimistic checks.
Identity Oracle
Attests to user attributes in a privacy-preserving way to enable compliance and eligibility checks.
Takeaway
Choose the oracle type based on provable fairness needs, computation integrity, or privacy-preserving identity requirements, and always document trust assumptions.
