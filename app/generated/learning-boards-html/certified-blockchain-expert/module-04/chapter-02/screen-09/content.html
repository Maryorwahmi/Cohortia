What chaincode does

Implements business logic, reads and writes key-value pairs, and generates a read-write set during simulation for endorsement.

Example: a transfer function reads balances, subtracts and adds amounts, and returns a write set without committing it yet.
Developer guidance
  • Keep chaincode deterministic across endorsers to ensure identical endorsements.
  • Design read sets to avoid unnecessary conflicts and improve throughput.
  • Test chaincode with the same endorsement policy used in production.
Key Takeaway

Chaincode must be deterministic and tested against endorsement policies to avoid invalid transactions at commit time.
