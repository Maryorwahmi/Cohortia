Definition › Ledger Components
World State

A current-key-value database for efficient reads. Choose CouchDB for rich JSON queries or LevelDB for simple key-value storage.

Use case: fast asset lookups in a commerce application.
Blockchain (Transaction Log)

An immutable, append-only record of ordered transactions that guarantees auditability and historical provenance.

Note: deletions in world state do not remove historical transactions from the blockchain.
Key Takeaway

Keep both parts in mind: world state for performance, blockchain for audit and history.
