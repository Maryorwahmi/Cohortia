Core Concept › Modular Architecture
Definition

A modular architecture separates concerns into replaceable components: ordering, membership, consensus, and state storage. Permissioned networks use certificates to identify participants.

Ordering: sequences transactions but does not execute chaincode.
CAs: issue X.509 certificates for identity and TLS.
State DB: LevelDB or CouchDB hold world state for fast queries.
Analogy & Example

Think of Fabric as a modular data center where you can replace the database engine or the message queue without rewriting your applications. Example: a supply chain network uses CouchDB when rich queries are needed for JSON assets, or LevelDB for simple key-value updates.

Key Takeaway

Choose components to match performance, privacy, and operational constraints; permissioned identity enables governance.
