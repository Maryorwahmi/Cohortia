Architecture › Ordering Service
Role

Collect endorsed transactions and produce ordered blocks for peers to validate and commit.

Ordering is sequencing, not execution
Implementations
Solo — single node, dev/testing only.
Kafka — distributed log, crash fault tolerance (operationally heavy).
Raft — recommended for production, crash fault tolerant and easier deployment.
Impact on fault tolerance
  • Solo: no fault tolerance.
  • Kafka: tolerated crashes but required external cluster management.
  • Raft: tolerates node crashes and provides leader election with simpler operations.
