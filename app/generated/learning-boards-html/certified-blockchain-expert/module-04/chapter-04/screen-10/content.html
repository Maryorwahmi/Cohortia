Definition

Oracles

Oracles bridge off-chain data and the ledger by signing external facts that contracts can trust during verification.

Use cases
Prices, reference data, identity attestations or regulatory approvals.
Safety note
Treat Oracles as trusted inputs; consider redundancy and legal trust when selecting sources.
Example
A transaction requiring a current index value can include a signed statement from an Oracle that the participants include in the transaction payload and reference during contract verification.
Pro tip

Model oracle-signed facts as attachments or commands that contracts can read and verify deterministically.
