Process Flow

Transaction steps

  1. Initiator builds transaction with inputs, outputs and commands.
  2. Local contract.verify() runs to validate business rules.
  3. Flow sends proposal; participants run verify() and sign if agreed.
  4. Submit to Notary for uniqueness check and Notary signature.
  5. Distribute finalized transaction; each party records it locally.
Concrete example
A lender proposes a DealState change. The borrower validates the terms and signs. The Notary confirms input states are unspent, signs, and the nodes record the updated deal state showing ACCEPTED.
Check

Always verify that all expected signers are present before contacting the Notary to avoid rejections or partial finality issues.
