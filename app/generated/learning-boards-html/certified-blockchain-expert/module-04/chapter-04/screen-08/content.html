Definition

Notaries

Notaries provide uniqueness consensus by checking that input states are unconsumed before signing a transaction.

Key constraints
  • They do not execute contract.verify().
  • They return a signature only if inputs are unspent.
  • Networks may offer multiple notaries with different models.
Example: preventing double-spend
When a DealState is consumed by a transaction, the Notary checks that state hasn't been spent already. If another transaction tried to consume the same input concurrently, the Notary rejects the later request, preserving uniqueness.
Common mistake

Expecting notaries to validate contract logic. Always put business rules in contracts and test them thoroughly.
