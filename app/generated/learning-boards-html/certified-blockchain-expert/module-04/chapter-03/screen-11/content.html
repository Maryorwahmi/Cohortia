Module 4 › Chapter 4.3 › Common Mistakes
Mistake vs Fix
Not checking GetState before PutState
Fix: use GetState and return an error for create operations if bytes != nil.
Poor error messages
Fix: return descriptive, non-sensitive shim.Error messages that indicate corrective action.
Secrets in code or external calls
Fix: keep secrets out of chaincode and use oracles for external data.
Testing & Access Control
Add unit tests for marshal/unmarshal and stub behavior. Implement checks that only the current owner or an authorized role can transfer or delete assets. This prevents unauthorized state changes and eases audits.
Quick test idea

Write a unit test that calls transferAsset with a non-existent ID and expects an error about missing asset.
