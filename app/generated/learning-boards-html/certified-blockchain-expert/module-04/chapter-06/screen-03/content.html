Skills to Practice
Permissioning Policy
Create rules that control validator and participant membership using smart contracts and identity lists.
Private Transaction Coding
Assemble transactions that set a privateFor list and sign/send them through Quorum RPC for PTM handling.
Consensus Selection
Choose IBFT for byzantine robustness, Raft for trusted simplicity, or Clique for authority-based signing.
Milestone

Complete a short architecture sketch that includes a PTM, a permissioning contract, and a consensus choice with rationale.
