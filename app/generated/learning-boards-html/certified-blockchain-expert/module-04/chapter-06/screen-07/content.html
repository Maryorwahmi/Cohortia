Module 5 › Chapter 4.6 › Sending a Private Transaction
Code Pattern (visual)
This code shows how a transaction includes a privateFor field so the node will invoke its PTM for encryption and distribution. The actual code block is for reference; in narration we describe its behavior and testing implications.
const Web3 = require('web3');
const web3 = new Web3('http://localhost:22000');

const privateFor = ['ROAZBWtSacxXQrOe3FGAqJDyJjG5PRQPLTFDwMexrkN='];
const contractAddress = '0x...';
const contractAbi = [...];
const myContract = new web3.eth.Contract(contractAbi, contractAddress);

const data = myContract.methods.setValue(42).encodeABI();

const tx = {
  from: '0x...',
  to: contractAddress,
  gas: 3000000,
  data: data,
  privateFor: privateFor
};

// Sign and send as usual; the node's PTM handles the private payload
Explanation
  • privateFor contains PTM public keys of recipients; it tells the node which PTMs should receive the encrypted payload.
  • The node signs and broadcasts a transaction whose on-chain data is only a hash; private payloads travel off-chain between PTMs.
  • To verify private state, query a recipient node — non-participating nodes will not show the private update.
Check Your Understanding

If a recipient's PTM public key is missing from privateFor, the intended recipient will not receive the payload and private execution will fail.
