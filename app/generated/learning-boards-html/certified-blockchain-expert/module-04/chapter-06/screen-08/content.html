Module 5 › Chapter 4.6 › Public vs Private State
Public State
Contains global contract state derived from public transactions. All network nodes can read this state and it ensures ledger consistency.
  • Updated by public transactions
  • Visible to every participant
  • Contains only non-sensitive or hashed references when used with PTMs
Private State
Node-local state updated only by private transactions that the node participated in and for which it received the encrypted payload from a PTM.
  • Stored and executed locally on participant nodes
  • Not visible to non-participating nodes
  • Requires correct PTM distribution and recipient keys
Concrete Scenario

When two banks settle privately, the public ledger records a hash to preserve ordering and integrity, while each participant updates its private state with settlement details that only they can read. Non-participant nodes cannot reconstruct the private values from the hash alone.
