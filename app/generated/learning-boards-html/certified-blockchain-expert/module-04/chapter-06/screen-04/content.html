Module 5 › Chapter 4.6 › Quorum: Permissioned Ethereum
Definition

Quorum is a permissioned fork of Geth that supports enterprise needs: controlled membership, private transactions via a PTM, and high-throughput consensus options.

Concrete Example
Three banks run a Quorum network where a permissioning smart contract approves new validators; only approved nodes can validate interbank settlement transactions.
Common Misconception
Permissioned networks control membership but do not automatically hide transaction payloads. Privacy requires a PTM that encrypts and distributes payloads to designated parties.
Key Takeaway

Quorum is about adding enterprise controls to Ethereum while keeping developer compatibility.

Comparison
Public Ethereum
  • Open participation
  • Global state visible
  • Proof-of-Work historically
Quorum
  • Permissioned membership
  • Private and public state separation
  • IBFT, Raft, or Clique consensus
Reflect: When designing a consortium ledger, permissioning helps governance, but privacy and key management must be designed separately.
