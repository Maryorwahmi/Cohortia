Quorum and Enterprise Ethereum
Permissioned Ethereum that keeps developer familiarity while adding privacy and performance.

Quorum is a fork of the Go Ethereum client optimized for enterprise deployments. It replaces open permissioning with controlled membership, swaps Proof-of-Work for enterprise-friendly consensus, and routes sensitive payloads through a Private Transaction Manager so only intended parties can decrypt them. This preserves Solidity compatibility while offering private state for sensitive logic.

In this lesson
We’ll explore architecture, private transactions, consensus choices, developer workflow, and ecosystem alternatives like Hyperledger Besu and the EEA.
Privacy
Private Transaction Manager encrypts payloads and shares them only with recipients.
Consensus
IBFT, Raft or Clique give immediate finality and higher throughput for permissioned networks.
Compatibility
Quorum stays compatible with Solidity and Ethereum tools, easing developer adoption.
Visual Concept
Public State
A hash records private payloads but data is not exposed.
Private State
Updated only on nodes that received the encrypted payload.
Key Takeaway

Quorum mixes Ethereum compatibility with enterprise features: permissioning, private payload routing, and faster consensus to meet corporate needs for privacy and throughput.
