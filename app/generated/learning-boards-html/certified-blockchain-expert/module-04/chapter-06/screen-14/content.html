Module 5 › Chapter 4.6 › Key Concepts
Quorum
A permissioned Ethereum fork that adds privacy and enterprise consensus options.
Private Transaction Manager
Encrypts and distributes private payloads; chain stores only the payload hash.
Public vs Private State
Public state is global; private state is node-local and only updated for transaction participants.
Takeaway

Privacy in enterprise Ethereum is an architectural pattern: permissioning, PTMs, consensus and governance must be designed together to meet confidentiality and throughput needs.
