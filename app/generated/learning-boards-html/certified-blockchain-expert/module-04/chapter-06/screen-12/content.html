Interbank Private Transaction
1. Bank A prepares payload
Constructs contract call, adds privateFor with Bank B's PTM key, and sends to local PTM.
2. PTM encrypts and distributes
PTM encrypts payload per recipient and stores encrypted blobs for retrieval.
3. Chain records a hash
A public transaction recording the hash is processed on Quorum; only recipients update private state.
If a recipient key is omitted from privateFor, the payload will not reach that party’s PTM and private execution will not occur for them. Include delivery monitoring and error logs to catch this class of misconfiguration early.
Try This

When testing, verify private state updates on recipient nodes and confirm non-participant nodes do not expose private values.
