Module 4 › Chapter 4.5 › Building and deploying CorDapps
Local build
Run the Gradle task to prepare test nodes and place CorDapp JARs into the cordapps folders for each node in build/nodes. Ensure the CorDapp targets the correct Corda API version.
./gradlew deployNodes
Production notes
Distribute the CorDapp JAR to each node operator and place it in their cordapps directory prior to node startup. Avoid including conflicting runtime libraries inside the JAR.
Checklist
  • Confirm Corda API compatibility.
  • Test verify rules with unit tests.
  • Coordinate deployment across nodes to prevent mismatched behavior.
