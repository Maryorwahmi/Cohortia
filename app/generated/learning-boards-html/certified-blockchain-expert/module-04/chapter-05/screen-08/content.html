Module 4 › Chapter 4.5 › Commands and Signers
Intent vs Authorization
Commands state the intent (Create/Accept/Settle). Signers listed in the command are the keys whose signatures are required to authorize that intent. Verify must confirm these keys are present.
Common mistake
Forgetting to include required signer keys prevents signature collection; including extra keys forces unnecessary approvals.
Concrete example
val command = Command(DealCommands.Accept(), inputDealState.lender.owningKey)
// verify() checks command.signers.contains(input.lender.owningKey)
In Accept, the lender must sign to acknowledge the acceptance. The initiator should list the lender key when building the command, and CollectSignaturesFlow will collect it from the lender's node.
