Module 4 › Chapter 4.5 › Common mistakes & safety notes
Top pitfalls
  • Missing participants → distribution failures.
  • Uncovered verify() paths → runtime exceptions or insecure transitions.
  • Flow ordering errors → deadlocks or failed signature collection.
  • Notary omitted or misconfigured → transaction errors.
  • Hardcoded identities → brittle, non-portable flows.
Mitigations & tests
Unit test verify branches, integration test end-to-end flows, validate participant propagation from state, and run small node deploy tests with the JAR to confirm runtime behavior.
Pro tip
Write a smoke flow test that creates a deal and checks both parties record the same finalized transaction.
