Module 4 › Chapter 4.5 › CreateDealFlow walkthrough
Flow outline
  1. Get Notary reference.
  2. Build output DealState with status PROPOSED.
  3. Create Command with participant signers.
  4. Build TransactionBuilder and call verify(serviceHub).
  5. Sign initial transaction and CollectSignaturesFlow with borrower.
  6. Call FinalityFlow to notarize and record.
Handle FlowException and ensure sessions are initiated in the same order in both initiator and responder to avoid deadlocks.
Core code excerpt
val notary = serviceHub.networkMapCache.notaryIdentities.first()
val outputState = DealState(dealId, value, ourIdentity, borrower, "PROPOSED", participants)
val command = Command(DealCommands.Create(), participants.map { it.owningKey })
val txBuilder = TransactionBuilder(notary)
  .addOutputState(outputState, DEAL_CONTRACT_ID)
  .addCommand(command)
// 5. verify
txBuilder.verify(serviceHub)
// 6. sign, collect, finalize...
This sequence ensures contract rules are enforced before any signatures are collected, protecting all parties.
