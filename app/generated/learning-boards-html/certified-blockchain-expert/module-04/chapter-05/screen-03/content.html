Module 4 › Chapter 4.5 › Learning Objectives — Applied
Verification checklist
Participant distribution
Ensure participants includes every counterparty so they receive the transaction and can sign.
Contract assertions
Test verify() paths for each command: Create, Accept, Settle to avoid unexpected runtime failures.
Flow signatures
Collect required signers with CollectSignaturesFlow and check owningKey usage in commands.
Deployment
Use Gradle deployNodes for local testing; distribute JARs to production nodes manually.
Practice prompts
  1. Write a unit test that calls DealContract.verify for Create with bad inputs and expect an exception.
  2. Run an end-to-end flow where borrower signs and finality records the transaction to both vaults.
  3. Adjust participants and confirm missing-party behavior from the vault logs.
