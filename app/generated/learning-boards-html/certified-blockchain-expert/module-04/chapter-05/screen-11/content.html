Responder pattern
Use SignTransactionFlow and override checkTransaction to enforce local business rules before signing. After signing, call ReceiveFinalityFlow to record the finalized transaction.
Pitfall
Querying the vault without checking status or LinearID can select wrong states; always filter precisely.
AcceptDealFlow snippet
// retrieve PROPOSED DealState by LinearID
val dealStateAndRef = serviceHub.vaultService.queryBy(DealState::class.java)
  .states.filter { it.state.data.linearId == dealLinearId && it.state.data.status == "PROPOSED" }.single()
val input = dealStateAndRef.state.data
val output = input.copy(status = "ACCEPTED")
val command = Command(DealCommands.Accept(), input.lender.owningKey)
// build tx with input and output, verify, sign, collect lender signature, finalize
Responder must check that they are the lender and that status transitions match the contract before signing.
