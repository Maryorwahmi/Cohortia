Author assertions that prevent invalid transitions, such as non-empty IDs and positive values. Remember verify runs before signing.
VERIFIED COMPETENCY MILESTONE

Create Flow logic
Build transactions with TransactionBuilder, collect signatures using CollectSignaturesFlow, and finalize with FinalityFlow and a Notary.
VERIFIED COMPETENCY MILESTONE

Build & Deploy CorDapp
Package a CorDapp JAR and deploy it to each node's cordapps directory so the node loads the app at start.
