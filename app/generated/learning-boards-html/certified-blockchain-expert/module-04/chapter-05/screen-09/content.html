Module 4 › Chapter 4.5 › Flows: orchestrating a transaction
Standard flow steps
  1. Get Notary reference.
  2. Build output state and command with required signers.
  3. Create TransactionBuilder and call verify(serviceHub).
  4. Sign initial transaction as initiator.
  5. Initiate sessions and CollectSignaturesFlow.
  6. Call FinalityFlow to notarize and distribute.
Responder flows use SignTransactionFlow to perform checks before signing and ReceiveFinalityFlow to record the finalized transaction.
