Developing CorDapps on R3 Corda
Compose immutable states, verifiable contracts, and orchestrated flows to record shared facts.
Why this matters
Corda's split between validation and notarization keeps business rules local and private while preventing double-spend.
What you'll build
A DealState, a DealContract verify implementation, and flows to create and accept a deal, then package as a CorDapp JAR.
Explore Key Topics

Contracts

Flows
Orchestrate signatures & finality
Concept map
State
Immutable data with participants. Example: DealState with lender, borrower and status.
Contract
Enforces rules. verify() throws if assertions fail. Commands like Create, Accept, Settle.
Flow
Build transaction, collect signatures, call FinalityFlow to notarize and record.
Deploy
Package CorDapp JARs and place them in each node's cordapps folder before start.
Coming up
We will step through code examples and a flow lab that shows how to create and accept a deal, including responder checks and common errors to avoid.
