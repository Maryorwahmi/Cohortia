What to notice
  • @BelongsToContract ensures this state is validated by the right contract.
  • Party objects represent legal node identities; participants determine distribution.
  • Status strings encode lifecycle stages; transitions are enforced by the contract.
Common mistake

Adding unnecessary sensitive fields increases exposure. Keep participant lists precise to preserve privacy.

Code snippet
@BelongsToContract(DealContract::class)
@CordaSerializable
data class DealState(
  val dealId: String,
  val value: Long,
  val lender: Party,
  val borrower: Party,
  val status: String,
  override val participants: List<Party>
) : ContractState
Example: create output with status PROPOSED and participants list including lender and borrower so both receive the transaction for signing.
