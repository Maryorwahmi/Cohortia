What the code does
It concatenates block data and a nonce, hashes them, and checks for a hash that matches a leading-zero pattern. The loop halts on success or after a max attempts limit, and timing shows the work cost.
Important: increasing the required zeros from four to six increases expected work by roughly 16× per extra zero in hex-based checks.
Key code excerpt
import hashlib
import time

def calculate_block_hash(block_header_data, nonce):
  combined_data = (block_header_data + str(nonce)).encode('utf-8')
  return hashlib.sha256(combined_data).hexdigest()

def mine_block(block_header_data, difficulty_target_prefix, max_nonce=10000000):
  start_time = time.time()
  for nonce in range(max_nonce):
    current_hash = calculate_block_hash(block_header_data, nonce)
    if current_hash.startswith('0' * difficulty_target_prefix):
      end_time = time.time()
      return nonce, current_hash, end_time - start_time
  return None, None, time.time() - start_time
