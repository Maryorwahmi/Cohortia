Adjustment timeline (conceptual)
Window start
Begin measuring 2,016 blocks.
Measure elapsed
Compute time taken to mine the window.
Compare to target
Expected time is two weeks for Bitcoin; compare actual to expected.
Apply adjustment
Decrease target if blocks were fast; increase if slow. New target controls next window.
Misconception

Adjustment is not instant — it is periodic and designed to smooth large shifts, meaning block times can temporarily deviate until the next recalculation.

Concrete example: if the last 2,016 blocks took one week, the protocol will make the puzzle harder so future blocks slow toward the two-week expected time.
Why it matters: difficulty adjustment prevents runaway block rates and stabilizes issuance schedules and confirmations.
