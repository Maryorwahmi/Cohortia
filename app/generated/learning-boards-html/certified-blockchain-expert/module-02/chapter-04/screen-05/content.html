Module 2 › Chapter 2.4 › Mining Loop
Mining steps
1
Assemble header
Include prev hash, Merkle root, timestamp, target, and starting nonce.
2
Hash header
Compute SHA-256 digest of the header bytes.
3
Compare to target
Accept if numeric hash ≤ target, otherwise continue.
4
Broadcast and verify
Winner broadcasts block; nodes validate with a single hash and append.
Explanation and example
If the target effectively requires four leading zeros, roughly one in sixteen thousand hashes will qualify. Miners increment the nonce billions of times across the network until someone finds a qualifying hash. When found, verification is cheap and quick for everyone else.
Key Takeaway

Mining is a repeated trial-and-error loop; the target controls how often a trial succeeds and how costly the search becomes.

Analogy: lottery-style odds for the correct nonce.
Pro-tip: miners vary coinbase to expand the search space beyond the nonce when needed.
Misconception check: verification repeats no work—just one hash call.
