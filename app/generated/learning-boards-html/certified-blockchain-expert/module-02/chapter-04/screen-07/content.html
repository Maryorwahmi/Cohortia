Module 2 › Chapter 2.4 › Target Size Comparison
Small target (Hard)
Few hashes qualify. Expected trials increase dramatically. Attack cost rises because an attacker needs more hash rate to produce competing chain work.
Misconception
People sometimes think harder means fewer miners; actually difficulty only changes required work per block, miners respond by scaling hardware or leaving if unprofitable.
Large target (Easy)
More hashes qualify frequently. Blocks are found faster unless adjusted. Easier mining can reduce economic cost per block and may lower the barrier for consolidation.
Practical note
Difficulty is commonly reported as a human-friendly number inversely related to the raw target; this is how miners and explorers compare work levels.
Check your understanding
If network hash rate doubles, without adjustment blocks would be found twice as fast; the difficulty mechanism counteracts this by reducing the target numeric value so the average block time returns to its goal.
