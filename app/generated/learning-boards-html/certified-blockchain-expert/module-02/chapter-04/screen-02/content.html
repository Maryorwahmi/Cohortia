Learning Objectives
These objectives connect technical steps with security and economic reasoning.
01
Explain mining process
Define nonce, block header, and target. Describe step-by-step how miners search nonces to find a qualifying hash and why block verification is fast.

02
Describe difficulty adjustment
Explain how the network measures a block window and adjusts the target to keep average block time stable, for example the 2,016-block window.
VERIFIED COMPETENCY MILESTONE
03
Analyze economic incentives
Relate block rewards and fees to miner behavior and discuss how cost structures deter dishonest manipulation of the chain.
VERIFIED COMPETENCY MILESTONE
04
Evaluate security & trade-offs
Assess 51 percent risk, energy consumption concerns, and how fixed block times impact scalability and fees.
