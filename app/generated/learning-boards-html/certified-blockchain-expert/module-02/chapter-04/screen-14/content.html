Module 2 › Chapter 2.4 › Key Concepts
Nonce
Miner-controlled number that changes the block header hash outcome.
Difficulty Target
Numeric threshold a hash must be at or below for a block to be valid.
Difficulty Adjustment
Periodic recalculation to keep average block time near the protocol target.
Summary Takeaway

PoW secures networks by converting computation and real-world energy into an economic cost that deters attacks, while periodic difficulty adjustment stabilizes block production.
