Module 2 › Chapter 2.3 › What is a Consensus Mechanism?
Definition

Consensus mechanism

An algorithm enabling distributed nodes to agree on a single, consistent state with determinism, verification, and incentives.

Primary role

Ensure every honest node converges to the same ledger despite delays and malicious actors.

What it must provide
  • Deterministic rule for choosing valid history
  • Evidence easy for others to verify
  • Incentives that encourage honesty
Illustration
Node

Imagine a small token network where each node proposes a block and the network follows a rule that selects the longest chain. Even when two blocks are proposed nearly simultaneously, the rule ensures honest nodes eventually accept the same block once one chain becomes longer.

Concrete example

Two conflicting transactions from one user propagate to different peers. The consensus rule orders them by chain inclusion, not by arrival time, preventing double acceptance.

Common misconception

Consensus is not just majority voting. Rules must include verification and incentive structures; otherwise majority control can be abused.

Key Takeaway

Consensus combines rules, verifiable evidence, and incentives so many independent nodes act as a reliable single authority.
