Architecture

Accumulated work and security

Each block contains proof of work; the network evaluates total chain work when choosing the canonical history. To succeed at rewriting history, an attacker must overtake the honest chain’s total work.

51% attack

If an attacker controls more than half of total hashing power, they can occasionally create a longer chain and reverse recent blocks, enabling manipulation.

Economic defense

Large required investment and the risk of destroying asset value make sustained attacks expensive and unattractive.

Example thought

If the honest network produces 100 units of work per hour, an attacker must exceed that rate to catch up. The larger the honest work, the harder and costlier it is to overtake.

Misconception check

A 51% attack is theoretical and requires resources; it is not impossible, only costly. Security is probabilistic and scale-dependent.

Key Takeaway

PoW defends history by accumulating verifiable work; increasing total work raises attack cost and improves security.
