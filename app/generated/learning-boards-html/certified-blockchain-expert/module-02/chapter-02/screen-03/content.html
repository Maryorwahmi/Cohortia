Skills Checklist

A practical checklist you can use to self-assess after the hands-on activity.

Generate ECDSA Key Pair

Create a private key and derive a public key on secp256k1. Confirm the public key can be shared safely.

Sign Transaction Hash

Hash transaction text and sign the digest. Verify signature length and R/S structure conceptually.

Verification & Tamper Test

Change one transaction field and confirm verification fails. Explain why the digest changes drastically.

Derive Address

Hash the public key to create a public key hash and encode to form an address. Understand each step's role.

Secure Key Storage

Implement at least one cold backup and one hardware wallet test. Describe how these prevent remote theft.

Explain Non-Repudiation

Articulate why a valid signature ties an action to a private key holder and how that supports trustless systems.
