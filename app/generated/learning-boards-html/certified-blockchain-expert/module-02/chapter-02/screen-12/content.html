Assessment: Tampering Scenario

Explain why a tampered transaction fails verification and what that implies about signature binding.

Question
Mallory changes Alice's recipient to herself after Alice signs. Why does the network detect this change?
Guided answer
Nodes hash the received transaction and compare that digest against the signature verified with Alice's public key. The digest differs after the change, so the signature fails verification and the transaction is rejected.
Misconception check
Signatures do not protect confidentiality; they only bind authorization to specific data. If keys are stolen, non-repudiation no longer holds.
Extension
If Mallory provides a new signature and public key, nodes check whether the inputs are unspent and whether the public key matches the originating address used to prove ownership of UTXOs.
Key Takeaway

A signature binds to the digest of a transaction. Any change to that digest breaks the link, preventing tampered transactions from being accepted by the network.
