Learning Objectives

Four competencies you will practice and verify.

Bloom: Learn → Understand → Apply → Master
01
Understand Public-Key Cryptography

Explain key pairs, the one-way relation from private to public, and why sharing the public key is safe. This matters because it enables verification without exposing secrets.

Venn: secrecy vs. sharing
VERIFIED COMPETENCY MILESTONE
02
Explain Signing & Verification

Describe hashing a transaction and signing the digest with a private key, plus how the public key is used to verify the signature. This skill prevents tampering and proves origin.

Timeline: hash → sign → verify
VERIFIED COMPETENCY MILESTONE
03
Identify ECDSA Components

Name the R and S values produced by ECDSA and the secp256k1 curve used by Bitcoin and Ethereum. Understand why elliptic curves reduce key size while keeping security.

Mnemonic: R & S pair
VERIFIED COMPETENCY MILESTONE
04
Apply Key Safety Best Practices

Evaluate trade-offs between cold storage, hardware wallets, and managed software keys. Choose backups that resist both theft and accidental loss.

Icons: safe, cloud
VERIFIED COMPETENCY MILESTONE
