Derivation hierarchy

A deterministic chain transforms a secret into a usable address while minimizing exposed data.

1
Private Key
Random 256-bit integer, never shared. If lost or stolen, funds are irretrievable.
2
Public Key
Curve point derived by multiplying the generator point by the private key.
3
Public Key Hash
Hash the public key (SHA-256 then RIPEMD-160) to reduce size and reveal less raw public-key data.
4
Address
Encode the public key hash with a version and checksum to produce a user-facing address like those used in Bitcoin.
Key Takeaway

Addresses are derived from public keys to be compact and include safeguards; the private key is the root of control.

Quick example
Private → Public point → SHA-256 → RIPEMD-160 → Base58Check → Address (human-friendly).
Misconception
The address is not the private key nor always the full public key; it is typically a hashed and encoded form of the public key.
Why reveal the public key only when spending? It minimizes exposure of the public key material until necessary, adding a limited privacy and attack surface benefit.
