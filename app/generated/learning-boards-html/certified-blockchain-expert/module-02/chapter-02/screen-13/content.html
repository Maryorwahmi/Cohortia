Checklist before signing

A short set of operational checks to avoid irreversible mistakes.

Confirm serialization
Ensure canonical byte ordering so all verifiers compute the same hash.
Verify addresses
Protect against clipboard or typing attacks; re-check address prefixes and lengths.
Check device security
Use hardware wallets or air-gapped signing when possible.
Confirm fees & policy
Set fees appropriately and check replace settings if relevant to avoid stuck transactions.
Test low-value transfer
When unsure, send a small test amount first to validate the full flow.
Post-broadcast verification
Check the transaction on the network to ensure outputs match your intent.
Key Takeaway

Adopt a pre-sign checklist and habitually verify the broadcasted transaction; signatures are irreversible and mistakes are costly.
