Conceptual Python

This snippet shows key generation, signing a hash, verifying the signature, and a tamper test. Run in a safe environment.

from ecdsa import SigningKey, SECP256k1, VerifyingKey
import hashlib

# Generate keys
private_key = SigningKey.generate(curve=SECP256k1)
public_key = private_key.get_verifying_key()

# Message (mock transaction)
message = 'Sender: Alice, Recipient: Bob, Amount: 10 BTC, Fee: 0.001'

# Hash the message
message_hash = hashlib.sha256(message.encode('utf-8')).digest()

# Sign the hash
signature = private_key.sign(message_hash)

# Verify signature
valid = public_key.verify(signature, message_hash)
print('Signature valid for original message?', valid)

# Tamper
tampered = message.replace('Bob', 'Mallory')
tampered_hash = hashlib.sha256(tampered.encode('utf-8')).digest()
valid_tampered = public_key.verify(signature, tampered_hash)
print('Signature valid after tampering?', valid_tampered)
Practical note
Use canonical serialization for transactions before hashing so every verifier computes the same digest.
Misconception
Do not assume binary signatures are human-readable; inspect validity flags instead of raw bytes when testing.
Key Takeaway

Try the tamper test: verification should succeed for the original digest and fail when any part of the transaction changes.
