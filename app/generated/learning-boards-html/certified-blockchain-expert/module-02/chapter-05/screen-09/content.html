Module 3 › Chapter 2.5 › Delegated Proof of Stake (DPoS)
Process Flow

DPoS: vote → elect → delegate

1. Token-holder voting

Each token is a vote; holders select a small set of delegates.

2. Delegates produce blocks

Elected delegates validate and propose blocks in a fast, scheduled rotation.

3. Accountability

Delegates can be replaced by voter action if they act maliciously or poorly.

Concrete example

With 21 witnesses, block production is fast and coordinated. Voters replace underperforming witnesses through periodic votes.

Common concern

Power concentration: a small elected set can collude unless elections and rewards encourage diversity.

Key Takeaway

DPoS increases throughput by delegating block production to a small elected set; governance quality determines how much decentralization remains.
