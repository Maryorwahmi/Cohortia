Core Concept Properties of Cryptographic Hash Functions
Formal properties
  • Determinism: same input → same digest every time.
  • Pre-image resistance: hard to recover original from digest.
  • Second pre-image resistance: hard to find a different input matching an existing digest.
  • Collision resistance: infeasible to find two distinct inputs with the same digest.
Common misconception
Hashing is reversible — incorrect. Hashing is one-way; encryption is reversible with a key. Mixing them up can lead to flawed threat models.
Concrete example
Take the transaction string and hash it with SHA-256. Change a single digit and hash again; the outputs are unrelated. This avalanche effect is essential for tamper detection.
Key takeaway
Key Takeaway

Use collision-resistant, one-way hashes to ensure integrity; do not rely on weak or broken hash algorithms.
