Code Walkthrough Building a Merkle Tree — Python Example
Core logic
import hashlib

def sha256(data):
  return hashlib.sha256(data.encode('utf-8')).hexdigest()

def build_merkle_tree(transactions):
  if not transactions:
    return None

  leaf_hashes = [sha256(tx) for tx in transactions]

  current_level = leaf_hashes
  while len(current_level) > 1:
    next_level = []
    if len(current_level) % 2 != 0:
      current_level.append(current_level[-1])

    for i in range(0, len(current_level), 2):
      combined_hash = sha256(current_level[i] + current_level[i+1])
      next_level.append(combined_hash)
    current_level = next_level

  return current_level[0]
Explanation
The code converts transactions into hex digests, makes pairs, duplicates the last leaf when necessary, and reduces upward to a single root. Keep input ordering consistent across producers and verifiers.
Common mistake
Concatenating raw bytes vs hex strings changes the inputs to the hash. Use a consistent encoding strategy on both ends.
