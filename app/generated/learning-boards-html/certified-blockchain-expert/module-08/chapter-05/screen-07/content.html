Architecture

Handoff pattern

Off-chain discussion refines proposals that are then submitted on-chain for a vote or council decision. Clear roles and thresholds make this pattern robust.

Stage 1
Off-chain debate

Research, drafts, community feedback, and security review.

Stage 2
Formal proposal

Codified proposal submitted on-chain with required deposits or signatures.

Stage 3
On-chain execution

Voting, tallying, and automatic enactment if thresholds are met.

Protocol example
Polkadot combines an elected council, technical committee for emergencies, and public referenda. This balances wide participation with expert oversight to handle urgent issues.
Pro tip

Define clear thresholds for moving from off-chain discussion to on-chain proposal to prevent confusion and rushed votes.
