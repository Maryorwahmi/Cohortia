Core Concept

ZK-rollups and instant finality

Use zero-knowledge proofs to attest that a batch of off-chain transactions is valid, enabling a single on-chain verification step.

How they work
Transactions executed off-chain. A prover generates a ZKP that the new state follows from the previous state and included transactions.
Benefits
Instant finality after verification, strong security tied to Layer 1, and large data compression for throughput.
Design trade-offs
Prover complexity and proof generation costs vary depending on the ZK scheme and supported VM model.
Key Takeaway

ZK-rollups deliver high throughput with cryptographic validity; plan for prover infrastructure and proof costs when designing systems.

Example platforms
zkSync
An implementation focused on payments and EVM compatibility using ZK proofs.
StarkNet
Uses STARK proofs for scalability with different prover assumptions and transparency properties.
Polygon zkEVM and Scroll
Projects aiming for EVM-compatibility with ZK proof strategies to ease developer migration.
Misconception check: ZK proofs validate correctness without revealing private inputs, so privacy can be maintained while achieving Layer 1 security.
