Module 8 › Chapter 8.3 › Off-chain storage with on-chain hashing
Pattern

Off-chain PII, on-chain hash

Keep personal data in a controlled system and store only a cryptographic hash or pointer on the ledger for integrity verification.

Integrity
Anonymity after deletion
Requires off-chain controls
Example

Supply chain dApp stores supplier PII off-chain; on-chain it records a product ID and a hash of supplier details. When PII is erased off-chain, the hash remains but cannot be reversed to the data.

Step-by-step
  1. Store PII in GDPR-compliant database with deletion API.
  2. Compute a cryptographic hash of the record.
  3. Write the hash and a reference ID on-chain for audit.
  4. On erasure request, remove the off-chain record so the on-chain hash is unresolvable.
Common mistake

Storing encrypted PII directly on-chain. Even encrypted payloads remain immutable and cannot be erased; if keys leak the PII is exposed.
