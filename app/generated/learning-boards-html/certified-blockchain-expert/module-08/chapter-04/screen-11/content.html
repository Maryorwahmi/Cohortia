Module 8 › Chapter 8.4 › FIFO Calculation Walkthrough
Worked example

Transactions and FIFO steps

Initial transactions:
1) Jan 15: Bought 0.5 ETH for $1,000  => Lot A: 0.5 ETH @ $1,000
2) Mar 10: Received 0.1 ETH staking (1 ETH = $2,500)
   => Ordinary income = 0.1 * $2,500 = $250
   => Lot B: 0.1 ETH @ $250
3) Apr 20: Bought 0.5 ETH for $1,500  => Lot C: 0.5 ETH @ $1,500

4) Jul 05: Traded 0.5 ETH for 100 LINK (1 ETH = $3,000)
   FIFO: sell Lot A (oldest) 0.5 ETH @ cost $1,000
   Proceeds = 0.5 * $3,000 = $1,500
   Capital gain = $1,500 - $1,000 = $500
   Remaining lots: Lot B (0.1 @ $250), Lot C (0.5 @ $1,500)

5) Sep 12: Sold 0.2 ETH for $700
   FIFO: sell Lot B first (0.1 @ $250) and 0.1 from Lot C
   Basis of 0.1 from Lot C = (0.1 / 0.5) * $1,500 = $300
   Total basis = $250 + $300 = $550
   Proceeds = $700
   Capital gain = $700 - $550 = $150

Summary:
Ordinary income = $250 (staking)
Capital gains = $500 (Jul 05) + $150 (Sep 12) = $650
Key takeaway
FIFO consumes oldest lots and staking rewards are taxed as income but also form basis for future gains.
Concrete numbers
Ordinary income: $250. Total capital gains in the scenario: $650. Remaining holding after Sep 12: Lot C has 0.4 ETH left with cost basis $1,200.
Common mistake
Not applying FIFO correctly across lots or mixing methods across wallets will change reported gains — be consistent.
