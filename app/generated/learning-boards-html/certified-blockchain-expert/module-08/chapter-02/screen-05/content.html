Module 8 › Chapter 8.2 › Utility Tokens
Core definition

A utility token provides access to a product or service on a blockchain network. Its value should be primarily functional, not based on investment returns.

Example
In-game tokens or network-specific access tokens used to pay for storage or compute.
Risk signal
A pre-launch token sale that funds development while promising future appreciation can trigger securities scrutiny.
Mitigation
Deliver features early, emphasize utility in marketing, and implement on-chain usage patterns like burn-on-use or in-app spenders.
Concrete design prompts
  • Define an explicit functional path where tokens are redeemed for services.
  • Include mechanics that separate token value from passive financial returns.
  • Align marketing with tangible utility and avoid statements about price appreciation.
Key Takeaway

Genuine utility depends on real service access; design features and timing that show functional use help avoid security classification.

Check: Is the primary reason for purchase access to a working service?
Misconception check: Governance rights alone do not prove a security status, but combined with profit expectations they can.
