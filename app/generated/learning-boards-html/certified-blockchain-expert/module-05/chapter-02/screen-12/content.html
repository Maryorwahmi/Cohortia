Checklist before deployment
A repeatable set of development steps to reduce risk.
Compiler
Use latest stable Solidity and pin pragma to avoid accidental downgrades.
Design
Keep contracts small, modular, and minimize external calls.
Patterns
Apply CEI and use reentrancy guards for transfer functions.
Access
Use msg.sender checks and RBAC libraries rather than tx.origin.
Testing
Write unit tests for edge values and use testnets to validate behavior.
Analysis
Run Slither and Mythril, triage warnings, and perform manual reviews.
Remember: the checklist reduces human error by making secure choices routine. Always re-run after refactors and before audit requests.
