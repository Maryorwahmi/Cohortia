Key Concepts
Quick reminders of essential security terms.
Reentrancy
An external call that allows the callee to call back into the contract before state updates finalize.
Integer Overflow/Underflow
Arithmetic wrapping that can be exploited; Solidity >=0.8.0 reverts on overflow by default.
Access Control
Mechanisms to restrict actions to authorized accounts; prefer msg.sender checks and RBAC libraries like Ownable.
Summary: Recognize these patterns during reviews and apply the appropriate mitigation described in this chapter.
