Access control essentials
Grant roles explicitly, avoid brittle checks, and prefer library code for ownership and roles.
- Correct check: require(msg.sender == owner) ensures the immediate caller is authorized.
- Incorrect: require(tx.origin == owner) can be spoofed through a malicious intermediary contract.
- Best practice: use OpenZeppelin Ownable or AccessControl and test transfer flows.
Key Takeaway: Authorization must reflect the immediate caller and be auditable in events and transfer paths.
Comparison: msg.sender vs tx.origin
msg.sender
Immediate caller. Safe for access checks and composable across contract calls.
tx.origin
Original external account that started the transaction. Not safe for authorization in composable systems.
Misconception check: Some developers use tx.origin believing it blocks contract-based calls. It actually makes contracts vulnerable to social engineering attacks via intermediary contracts.
