Module 5 › Chapter 5.2 › Static analysis: Slither and Mythril
Automated scanning
Run static analysis early to find patterns; always triage the results manually.
- Slither: source-level checks for common anti-patterns including reentrancy and access control issues.
- Mythril: bytecode/concolic analysis to explore execution paths and find edge-case failures.
- Misconception: These tools find everything — false. They catch many classes, but manual review and tests are still required.
Key Takeaway: Automate scanning, but interpret results with domain knowledge and follow up with tests and audits.
Command examples
slither your_contract.sol

# Mythril analyzes bytecode
myth analyze compiled_contract.json
Workflow: run scanners, triage findings, write tests reproducing issues, then iterate. Do not skip manual inspection for high‑risk code paths.
