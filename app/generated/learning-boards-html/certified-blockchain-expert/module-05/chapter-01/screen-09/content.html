Module 5 › Chapter 5.1 › Digital Signatures
Definition
Signatures: authenticate and bind
Private key signs a message digest; public key verifies. Signatures prove the signer authorized that exact data, providing non-repudiation.
Why ECDSA?
ECDSA offers compact keys and efficient verification, which is why many cryptocurrencies adopt it for signing transactions.
Misconception
A signature proves ownership of a key, not necessarily the honest intent of the signer. If a key is compromised, signatures can authorize malicious actions.
Concrete flow
  1. Compute transaction digest using SHA-256.
  2. Sign digest with private key (ECDSA).
  3. Broadcast signed transaction; nodes verify with public key.
Example
If an attacker alters the amount, the recomputed digest differs and signature verification fails, rejecting the modified transaction.
Key Takeaway

Protect private keys. Signatures secure authenticity, but key compromise undermines that guarantee.

Pro tip
Use hardware wallets for significant holdings and require manual verification of transaction details before signing.
