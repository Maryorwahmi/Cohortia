Module 5 › Chapter 5.1 › Hashing Functions
Definition
Hashing: fixed-size digests for integrity
Properties: determinism, preimage resistance, and collision resistance make hashes reliable identifiers and tamper detectors.
Typical uses
  • Transaction IDs and block IDs
  • Linking blocks via previous-hash fields
  • Proof-of-work puzzles based on difficulty targets
Misconception
Hashing is not encryption. You cannot recover the original message from a hash, so hashes provide integrity but not confidentiality.
Concrete example
Given transaction data like sender, receiver, amount, and timestamp, SHA-256 produces a 256-bit hash. Changing the timestamp by one second yields a completely different digest, making tampering visible.
Mnemonic
Think: One-way fingerprint that changes with any input tweak.
Key Takeaway

Hashes are compact, deterministic evidence of content. They enable block linking and quick tamper checks but are not reversible.
