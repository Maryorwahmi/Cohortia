Definition

Zero-Knowledge Proofs explained

ZKPs let a prover show a statement is true while hiding the secret witness. The verifier learns only the truthfulness, not the underlying data.

  • Soundness: dishonest provers can't convince the verifier of false statements.
  • Completeness: honest provers can generate valid proofs for true statements.
  • Zero-knowledge: no extra knowledge about the witness is revealed.
Analogy

Prove you know the path through a maze without showing the path itself; the verifier gets assurance you can exit, not the route.

Teaching cards
Concrete example

A user proves they have enough balance for a trade without showing the balance; the network verifies correctness via the proof.

Misconception

Zero-knowledge does not mean no data ever flows; it means only the statement's truth flows, not the secret witness.

Takeaway

Use ZKPs when you need verifiable correctness without revealing inputs, and check the proof assumptions carefully.
