Module 5 › Chapter 5.5 › Common Mistakes
Safety Note

Implementation risks to avoid

Cryptographic bugs

Flawed implementations can leak secrets or allow forged proofs; require audits.

Trusted setup mishandling

Compromised ceremony for SNARKs risks system integrity; plan transparent ceremonies.

Side-channel leaks

Timing and network analysis can weaken mixing; coordinate to reduce leakage.

Key management

Poor storage or over-sharing of view keys exposes private data; enforce minimal disclosure and rotation.

Action

Require cryptographic review, threat modeling for deanonymization paths, and documented operational controls before deploying PETs.
