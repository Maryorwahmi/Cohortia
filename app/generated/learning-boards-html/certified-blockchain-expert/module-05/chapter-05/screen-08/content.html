Module 5 › Chapter 5.5 › Confidential Transactions & Mixing
Technique

Confidential Transactions (CTs)

CTs hide amounts using commitments and range proofs so the network can verify no new value was created while amounts stay private.

Benefit: hides balances and transfer sizes. Consideration: requires cryptographic proofs that increase transaction size.
Technique

Ring Signatures

A transaction signature can be produced by any member of a set, making it infeasible to determine which member signed and protecting sender privacy.

Benefit: sender ambiguity. Consideration: set selection and size affect anonymity.
Technique

CoinJoin

Multiple users combine inputs and outputs into one transaction to break linkability between specific senders and receivers.

Benefit: disrupts tracing heuristics. Consideration: coordination and timing leaks can weaken privacy.
Example

A privacy-focused design might combine CTs to hide amounts with ring signatures to obscure senders and CoinJoin for mixing, addressing multiple linkability signals.
