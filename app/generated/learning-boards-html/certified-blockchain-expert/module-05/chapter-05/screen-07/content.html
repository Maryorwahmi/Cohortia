Module 5 › Chapter 5.5 › Homomorphic Encryption
Definition

Compute on encrypted data

Encrypted inputs can be processed so the encrypted output decrypts to the correct plaintext result. This maintains confidentiality during computation.

  • Partial HE: supports specific operations like addition or multiplication.
  • Fully HE: supports arbitrary computation but is computationally expensive.
  • Key management is critical: who can decrypt results determines usefulness.
Practical notes
Concrete example

A service computes an encrypted aggregate of private user metrics and returns an encrypted sum that only the data owner can decrypt.

Misconception

HE does not remove on-chain linkability or metadata exposure; it protects inputs during computation only.

Takeaway

Use HE when input confidentiality during processing is essential, and combine with other PETs for full transactional privacy.
