Code walkthrough

This Python script demonstrates a commitment to a secret and a prover claim checked by a verifier in a simplified way. It is an educational analogy, not a secure ZKP implementation.

import hashlib
import random

def generate_hash(data):
  return hashlib.sha256(str(data).encode()).hexdigest()

secret_number = random.randint(1, 1000)
secret_commitment = generate_hash(secret_number)

print(f"Prover's Secret Number: {secret_number} (kept private)")
print(f"Public Commitment to Secret: {secret_commitment}
")

# Prover proves evenness if hash matches commitment

def prover_proves_even(secret_num, commitment):
  if generate_hash(secret_num) == commitment:
    if secret_num % 2 == 0:
      return True, f"I know a number whose hash is {commitment} AND it's even."
    else:
      return False, "My secret number is not even."
  return False, "My secret number does not match the commitment."
Explanation
Key parts: a public commitment derived from a secret, a prover that makes a claim tied to the commitment, and a verifier that accepts or rejects based on consistency. The script prints outcomes so you can experiment with different secrets.
Try this

Change the claimed property from evenness to divisibility by three and observe verification behavior.

Misconception check

This simplification exposes the secret in some branches and trusts global variables; real ZKPs avoid leaking witness data and are non-interactive or use cryptographic transforms.

Key Takeaway

Use the script to form intuition about commitments and verification, then study formal ZKP constructions for secure deployment.
