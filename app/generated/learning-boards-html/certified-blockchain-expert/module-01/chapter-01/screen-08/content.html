Definition

Immutability: What it Means and How it's Achieved

Tamper-evidence from cryptographic linking and consensus rules.
How it works
Each block references the previous block's digest; changing one block requires updating all following blocks and convincing the network to accept the change.
Concrete example
Altering an old transfer forces recomputation of subsequent blocks and must overcome network consensus, which is infeasible on large networks.
Misconception
Immutability is strong tamper-resistance, not guaranteed legal finality under all governance scenarios.
Visual: tamper evidence
Chain reaction
Changing Block 2 invalidates Block 3 and Block 4 because each contains the prior digest. The network will detect mismatches during validation.
Key Takeaway

Tamper-evidence arises from chaining plus distributed validation, making undetected changes impractical.

Think

Plan for governance and key management because immutability does not remove operational risks.
