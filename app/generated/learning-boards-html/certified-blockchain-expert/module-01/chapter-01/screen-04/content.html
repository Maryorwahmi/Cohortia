Core Concept

What is a blockchain?

A precise definition and the ledger metaphor to make the idea concrete.
Formal definition
A sequence of blocks, each with transactions and a cryptographic link to its predecessor, creating an append-only record verified by the network.
Ledger metaphor
Think of pages chained by a summary; changing an old page breaks every later summary.
Concrete example
If a recorded transfer is changed, the cryptographic link no longer matches and other nodes detect the tamper attempt.
Common mistake
Immutability is not mystical absolute permanence; it depends on consensus and the difficulty of rewriting history.

Key Takeaway

The chain structure makes tampering evident because changed data invalidates subsequent links.
