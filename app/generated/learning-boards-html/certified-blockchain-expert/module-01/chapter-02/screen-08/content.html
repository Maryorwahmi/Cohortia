Comparison › Merkle Proof vs Full Download
Full node
  • Stores full transactions and block data.
  • Verifies all proofs and consensus rules locally.
  • High storage and bandwidth requirements.
Light client with Merkle proof
  • Downloads block headers and Merkle proofs only.
  • Verifies inclusion by reconstructing the Merkle root from a small set of hashes.
  • Lower storage and bandwidth, but depends on header correctness.
Proof size
Proportional to the tree height, typically logarithmic in number of transactions.
Trust anchor
Merkle proofs anchor to the Merkle root in the header; the header must be trusted or validated via consensus.
Use case
Mobile wallets and light nodes use Merkle proofs to stay lightweight while verifying history.
