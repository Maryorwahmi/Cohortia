Example code (visual only)
import hashlib

def calculate_sha256(data_string):
    # encode string to bytes and compute SHA-256
    return hashlib.sha256(data_string.encode('utf-8')).hexdigest()

print(calculate_sha256("Cohortia Blockchain"))
print(calculate_sha256("Cohortia Blockchain."))  # small change
print(calculate_sha256("cohortia blockchain"))  # case change
print(calculate_sha256("Cohortia Blockchain"))  # same as first
Observe output: the first and last digests match; the slightly modified inputs produce unrelated digests. This confirms determinism and the avalanche effect.
Explanation
  • Encoding to bytes standardizes input to the hash function.
  • The digest is a fixed-size hexadecimal string representing the hash output.
  • Small changes produce completely different outputs — an integrity alarm.
Concrete takeaway
Use hashing when you need an irreversible fingerprint of data. Do not use it for confidentiality.
Common mistake
Do not expect similar inputs to have similar hashes; that undermines detection of small tampering.
