Overview

This chapter shows how cryptographic hash functions ensure integrity, how Merkle trees summarize and make verification efficient, and how public-key cryptography enables digital signatures for authentication and non-repudiation. You will be prepared to run the provided Python examples and reason about attacker scenarios.

Why this matters
Together these primitives let distributed systems detect tampering, verify specific transactions efficiently, and ensure only authorized owners can spend assets.
