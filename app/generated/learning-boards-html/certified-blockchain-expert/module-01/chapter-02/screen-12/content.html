Hands-on Activity › Hashing & Merkle Simulation
Part 1: SHA-256 tests
Implement the calculate_sha256 function using hashlib, then test with strings that differ by a period or case. Confirm that identical inputs reproduce the same digest and that small changes produce unrelated digests.
Part 2: Merkle simulation
Hash four transactions to create leaves, pair and hash them to form intermediate nodes, then hash those to produce the Merkle root. Change one transaction and recompute to see the root change.
Reflection prompt
Write one paragraph: how did the Merkle root change when you altered a transaction, and what does that imply for a verifier that checks only the root?
Checklist
  • Implement calculate_sha256 and run sample inputs.
  • Construct leaf hashes for four sample transactions.
  • Compute intermediate hashes and the Merkle root.
  • Modify one transaction and observe the new root.
Key Takeaway
This activity links hands-on code with theoretical properties: hashes detect tiny changes, and Merkle roots summarize many transactions for efficient verification.
