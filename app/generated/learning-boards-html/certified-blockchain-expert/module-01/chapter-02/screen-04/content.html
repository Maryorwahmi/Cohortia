What is a cryptographic hash?

A function that takes any-size input and returns a fixed-size digest with properties making it suitable for integrity checks. The digest is deterministic but practically impossible to reverse or collide.

Properties
  • Deterministic — same input yields same digest.
  • One-way — cannot recover original input from digest.
  • Collision resistant — finding two inputs with same digest is infeasible.
  • Avalanche effect — tiny input changes produce large digest differences.
Concrete example
Hash the phrase "Cohortia Blockchain", then change a single character. You will get two unrelated digests, demonstrating determinism and the avalanche effect together.
Key Takeaway

Hash functions create compact, tamper-evident fingerprints for data; they are the integrity primitive in blockchains.

Visual & analogy
Think of a hash as a DNA fingerprint for data. Two different people rarely share the same fingerprint; likewise, different data will almost never share the same cryptographic digest.
Common misconception
Hashing is not encryption. You cannot retrieve original data from a hash, and encryption is reversible with a key. Use hashing for integrity, encryption for confidentiality.
