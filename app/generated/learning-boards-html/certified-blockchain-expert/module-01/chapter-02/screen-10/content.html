Process Flow › Sign & Verify
Signing steps
  1. Compute digest of the transaction data using a hash function.
  2. Use your private key to compute a signature over that digest.
  3. Attach the signature to the transaction and broadcast it.
Verification steps
Recompute the digest from received data, then use the public key to validate the signature. If it matches, authenticity and integrity hold.
Practical notes
  • Signatures do not encrypt transaction content.
  • They provide non-repudiation: a signer cannot credibly deny a signed transaction.
  • Protect private keys to prevent unauthorized signing.
Warning
Signing unknown data can create permanent, non-repudiable actions. Verify transaction details before signing.
