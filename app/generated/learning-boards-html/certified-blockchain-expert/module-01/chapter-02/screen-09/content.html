Core Concept › Public-Key Cryptography
Private key
Secret value used to create signatures. Anyone with it can authorize transactions and thus control assets. Store offline when possible.
Protection tips
  • Prefer hardware wallets for signing.
  • Keep encrypted backups; avoid sharing private keys.
Public key
Derived from the private key and used to verify signatures. It can be published and used to receive funds. It does not allow signing by itself.
Misconception
Sharing your public key does not let others spend your funds; only the private key can do that.
Key Takeaway

Public-key pairs enable signatures that authenticate senders without exposing secret keys. Protect private keys: they are the single point of failure for asset control.
