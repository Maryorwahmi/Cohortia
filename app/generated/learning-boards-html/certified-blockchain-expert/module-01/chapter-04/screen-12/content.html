Process Flow

Block Broadcast, Validation, and Chain Extension

A mined block is broadcast and rigorously validated by peers. Accepted blocks extend each node's ledger and increase transaction confirmations.

Block validation checklist
  • Header format and consensus work check
  • Previous block linkage and chain integrity
  • Re-validation of included transactions
Fork resolution
When multiple valid branches exist, nodes follow the longest valid chain; orphaned blocks' transactions return to mempools.
Example
Two miners produce blocks simultaneously. Nodes temporarily diverge until one branch extends farther and becomes the accepted chain.
Key takeaway
Confirmations are probabilistic security: each additional block exponentially reduces reversal risk.
