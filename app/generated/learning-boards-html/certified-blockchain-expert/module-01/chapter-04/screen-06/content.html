Definition

Light Nodes (SPV): Efficiency with Trade-offs

SPV nodes download block headers and request Merkle proofs for specific transactions, minimizing storage while enabling proof of inclusion.

How Merkle proofs help
A Merkle branch proves a transaction is included in a block header without revealing other transactions.
When to use SPV
Mobile wallets and lightweight clients where storage and CPU are limited.
Concrete scenario
A phone wallet requests a Merkle proof from a full node after seeing a header for block N; the proof demonstrates inclusion of the outgoing transaction without syncing the entire chain.
Misconception check
SPV improves efficiency but cannot independently validate every historic rule — full nodes are required for full verification.
