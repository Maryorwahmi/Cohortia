Definition

Transaction Structure: Inputs, Outputs, and Signatures

Transactions reference prior outputs as inputs, present outputs for recipients and change, and include signatures to authorize spending.

Inputs
Reference previous UTXOs and include signatures proving the sender controls them.
Outputs
Create new UTXOs specifying recipient addresses and amounts; change returns to the sender via an output.
Concrete example
Alice consumes a UTXO of 1.5 and sends 1 to Bob, creating a 1 output to Bob and a 0.499... change back to Alice; the leftover is the fee to miners.
Misconception check
This is not an account debit. Funds move by consuming and producing discrete UTXOs that must be referenced precisely.
