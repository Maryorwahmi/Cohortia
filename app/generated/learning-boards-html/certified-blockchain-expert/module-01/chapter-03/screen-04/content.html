Module 1 › Chapter 1.3 › What is DLT?
Core Concept
Distributed Ledger Technology
A decentralized database where multiple participants maintain synchronized copies and updates are agreed by protocol rather than a single administrator.
Replication
Multiple nodes store the same ledger to avoid a single point of failure.
Synchronization
Updates are propagated so each copy converges to the same state.
No central administrator
Control is distributed and enforced by protocol rules.
Key Takeaway

DLT is a family of replicated ledgers; choose the structure and participation model to match trust and performance needs.

Analogy & Example
Imagine several independent libraries that all keep the same catalogue. No single library can change entries without the others agreeing through a shared process. Similarly, a set of banks may run nodes and agree on transfers without a central clearinghouse.
Common Misconception
Equating DLT strictly with blockchain hides other ledger structures like directed acyclic graphs; those alternatives may fit different performance or design constraints.
Why it matters
Understanding the general model prevents early design mistakes, like selecting an overly costly consensus for a permissioned enterprise workflow where trust is already established.
