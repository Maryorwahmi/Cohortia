Module 1 › Chapter 1.3 › Proof of Work Process
Process Flow
1
Gather Transactions
Collect pending transactions and compute a Merkle root to summarize them.
2
Construct Block Header
Include previous block hash, Merkle root, timestamp, and nonce field.
3
Mining Puzzle
Iterate nonce values and hash the header until the hash meets the target difficulty.
4
Broadcast and Verify
Peer nodes verify the hash and, if valid, add the block and give the miner the reward.
Concrete Example
If the target requires a hash starting with four zeros, miners test nonces starting at zero and increment until one nonce produces such a hash. The time grows quickly as required leading zeros increase.
Misconception
The mining puzzle has no external meaning; its value is the cost it imposes, which secures the chain by economic difficulty.
Key Takeaway

PoW secures open networks by converting compute work into a costly gate for block creation.
