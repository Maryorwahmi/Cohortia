Module 1 › Chapter 1.3 › Blockchain vs Other DLTs
Comparison
Blockchain
  • Organizes transactions in blocks linked via hashes.
  • Gives a clear, linear order for transactions.
  • Fits consensus schemes that use block checkpoints like PoW.
Concrete example
Bitcoin uses blocks containing a Merkle root and previous hash; changing a past block requires re-mining subsequent blocks.
Comparison
Non-block DLT
  • May use directed acyclic graphs or other structures.
  • Can allow multiple references and parallel confirmation paths.
  • Requires different consensus and finality mechanisms.
Design note
Choose structure based on ordering and throughput needs: blocks favor simple ordering, other structures can support concurrent processing.
Takeaway
Match data structure to consensus and operational goals; blockchain is not the only DLT and may be overkill or insufficient depending on requirements.
