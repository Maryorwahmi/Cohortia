Module 1 › Chapter 1.3 › Simulating PoW
Steps
  1. Save pseudocode as simple_miner.py and run with '00' as target prefix.
  2. Record time and nonce results for '00', '000', and '0000'.
  3. Change the transactions string and repeat to observe different nonces and times.
What to Observe
  • Execution time grows sharply as difficulty increases.
  • Different transaction inputs change the exact nonce and timing.
  • Results vary per run due to hash randomness, but averages show the difficulty effect.
Practical note
In real networks miners use optimized code and specialized hardware; this activity is intentionally simple to illustrate the core loop.
Key Takeaway
Hands-on experiments make the abstract cost of PoW concrete: difficulty settings map directly to expected compute and energy use.
