Module 3 › Chapter 3.3 › Key Concepts
Solidity
A statically typed, contract-oriented language for the EVM.
State Variables
Persist on-chain, cost gas to change, and define the contract's stored state.
Visibility
public, private, internal, external control access and should be chosen conservatively.
Takeaway

Design contracts with clear structure, test constructors and visibility, and pick types that balance semantics and gas cost.
