Module 3 › Chapter 3.3 › Data Types
uint / int
Unsigned and signed integers with explicit sizes. Use uint256 as a default for supplies and counters. Older compilers did not revert on overflow; newer ones do.
address
20-byte Ethereum addresses with helpers like balance. Use address to track owners and recipients.
bool
Simple true/false flags. Pack into structs to save storage when possible.
string
UTF-8 text for human-readable data. Strings can be more expensive; consider bytes for short raw values.
bytes
Raw byte sequences. Generally more gas-efficient for short binary data compared to string.
Concrete example
Use uint256 for totalSupply in a token, and address for owner. If you store a short identifier, prefer bytes32 or bytes over string when possible to save gas.
