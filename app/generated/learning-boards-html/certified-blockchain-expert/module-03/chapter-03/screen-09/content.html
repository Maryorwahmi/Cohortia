Contract code
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleStorage {
    // State variable to store a string
    string public message;

    // Constructor: executed only once when the contract is deployed
    constructor() {
        message = "Hello Cohortia!";
    }

    // Function to update the message
    function setMessage(string memory _newMessage) public {
        message = _newMessage;
    }

    // Function to retrieve the message
    function getMessage() public view returns (string memory) {
        return message;
    }
}
Annotated notes
  • pragma: Pins compiler range and prevents incompatible compilation.
  • message variable: public creates an automatic getter and lives in storage.
  • constructor: Initial assignment at deployment; runs once.
  • setMessage: writes to storage and requires gas; accept inputs in memory where appropriate.
  • getMessage: view function that reads storage; free when called off-chain.
Check your understanding
After deploying, which call costs gas: getMessage or setMessage? Try both and observe the difference.
