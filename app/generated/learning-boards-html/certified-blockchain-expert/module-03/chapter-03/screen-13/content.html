Module 3 › Chapter 3.3 › Gas & Safety
Practical guidelines
  • Default to restrictive visibility and add access control for privileged actions.
  • Use uint256 for counts and totals; only choose smaller sizes when you pack data intentionally.
  • Prefer bytes for short binary data to save gas over string when appropriate.
  • Minimize state writes; compute off-chain when you can and write essential results only.
Example check
Add require statements to setter functions to validate inputs and prevent invalid states that require costly rollback and debugging.
Key Takeaway
Design for auditability and safety first, then optimize gas where profiling shows repeated cost impact.
