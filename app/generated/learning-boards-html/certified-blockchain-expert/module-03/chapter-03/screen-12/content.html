Module 3 › Chapter 3.3 › Constructors
Constructor behavior
Runs once during deployment, sets initial state, and consumes deployment gas. Parameters must be provided at deploy time.
constructor(uint256 _initialNumber) {
  storedNumber = _initialNumber;
}
Deployment test steps
Deploy with representative constructor values, then immediately call getters to confirm initial state. If using upgradeable proxies, prefer explicit initialize functions instead of constructors.
Misconception
Constructors can be run later. They only run once during deployment. For re-initialization use a dedicated initialize function guarded by access control.
