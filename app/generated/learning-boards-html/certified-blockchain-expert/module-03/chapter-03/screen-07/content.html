Module 3 › Chapter 3.3 › State Variables
What persistence means
State variables are recorded in contract storage so their values survive across transactions and function calls.
Example: uint256 public storedNumber; — this variable is persisted and an automatic getter is available.
Gas note: Writing storage is significantly more expensive than reading. Optimize writes and pack variables when possible.
Misconception: public means free — public only means readable externally; writing still costs gas.
Scenario
If you store user balances in a mapping or uint, carefully control functions that modify those balances. Making update functions public without access control can let anyone alter persistent funds.
Key Takeaway

Design storage deliberately: minimize state, prefer restrictive visibility, and understand that each write has a network-wide cost.
