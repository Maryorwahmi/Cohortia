Module 3 › Chapter 3.3 › Visibility Specifiers
public
Accessible from anywhere. State variables get an automatic getter. Use when external read or call is required.
private
Only the declaring contract can access. Useful for secrets or internal bookkeeping that must not be exposed to derived contracts.
internal
Accessible within the contract and by inheriting contracts. Default for many members when no visibility is specified.
external
Only callable from outside the contract, via transactions or other contracts. Can be more gas-efficient for calldata-heavy calls.
Security note
Set the most restrictive visibility possible and add access controls for privileged actions like withdrawals.
