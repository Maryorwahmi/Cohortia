Learning Objectives
Learn, understand, apply, and master core Solidity concepts.
Bloom
Learn → Understand → Apply → Master
01
Identify contract structure
Recognize pragma, contract, state variables and functions so you can map a file to runtime behavior. Visual mnemonic: a labeled contract block.
VERIFIED COMPETENCY MILESTONE
02
Apply basic data types
Use uint, int, address, bool, bytes and string with awareness of gas and semantics. Mnemonic: colored type table.
VERIFIED COMPETENCY MILESTONE
03
Explain state persistence
Describe how state variables are stored on-chain and how reads and writes affect gas. Mnemonic: storage disk icon.
VERIFIED COMPETENCY MILESTONE
04
Differentiate visibility
Understand public, private, internal, external and choose the most restrictive option by default. Mnemonic: access lock icons.
VERIFIED COMPETENCY MILESTONE
How you'll practice
  • Write a simple storage contract and a number storage contract in Remix.
  • Compile with a 0.8.x compiler and inspect auto-generated getters.
  • Try changing visibility and see how the ABI and access change.
Reflection prompt
Which state variables in your project should be public getters and which should remain internal or private? Consider security and the need for read-only access.
