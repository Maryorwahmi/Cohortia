Labeled architecture
Identify each part: constructor, state variables, functions, events, modifiers.
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Demo {
  // state variable
  uint256 public count;

  // constructor
  constructor(uint256 init) {
    count = init;
  }

  // state-changing function
  function increment() public {
    count += 1;
  }

  // view function
  function getCount() public view returns (uint256) {
    return count;
  }
}
Explanation cards
  • State variable: Persisted on-chain and visible per visibility rules.
  • Constructor: Runs once at deployment to initialize state.
  • Functions: Either read-only view or state-modifying and gas-consuming.
  • Events: Emit logs for off-chain listeners and cheaper indexing than storage for some use cases.
Concrete scenario
A counter contract uses a uint state variable for a supply. Increment operations change on-chain state and must be protected if only admins should call them.
