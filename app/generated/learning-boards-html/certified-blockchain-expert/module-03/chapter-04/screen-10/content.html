Module 3 › Chapter 3.4 › Common Issues
Insufficient Funds
Ensure your deploying account has enough testnet Ether. If a transaction runs out of gas, the attempt fails and gas used up to failure is consumed.
Wrong Network
Confirm MetaMask’s network before deploying; the wrong network causes failed interactions or misplaced deployments.
Constructor Arguments
Provide required constructor values during deployment or the contract may start in an unintended state.
ABI / Address Mismatch
Always use the ABI generated from the same compilation and the correct deployed address when interacting from a dApp.
Gas Estimation
Test gas usage on local networks and consider adding safety margins for complex transactions.
Fix Flow
Use JavaScript VM for quick checks, run tests locally on Hardhat, fund MetaMask for testnet deploys, confirm constructor inputs, then deploy and verify address and ABI in your app.
