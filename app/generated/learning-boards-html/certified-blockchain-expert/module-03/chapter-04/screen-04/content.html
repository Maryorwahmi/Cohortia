What solc outputs
  • EVM bytecode: executable instructions stored at the contract address.
  • ABI (JSON): public/external function and event signatures, parameter types, and return types.
  • Why both: bytecode runs; ABI lets clients build the data payload and parse responses.
Common misconception
The ABI is not executable. It is a schema used by off-chain tools to format transactions. Treat it as a blueprint rather than program code.
Key Takeaway
You need bytecode to deploy and ABI plus address to interact correctly from a dApp.
