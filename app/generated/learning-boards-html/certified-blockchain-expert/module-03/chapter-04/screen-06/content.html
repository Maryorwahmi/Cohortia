Module 3 › Chapter 3.4 › Remix Environments
JavaScript VM
Simulated in-browser blockchain with pre-funded accounts and instant mining.
Best for rapid prototyping and function tests.
State resets on refresh; gas is simulated.
Use when you want immediate feedback without spending funds.
Injected Provider (MetaMask)
Connects Remix to your wallet to deploy to public testnets or mainnet.
Requires correct network selection and sufficient Ether to pay gas.
Useful for real-world testing and visibility on explorers.
Use when you need a deployment that others can inspect on a public chain.
Local Node (Hardhat / Ganache)
Run a reproducible local blockchain on your machine for testing and scripting deployments.
Supports advanced debugging and testing frameworks.
Use for automated tests and predictable gas behavior in CI.
Practical flow
  1. Start in JavaScript VM to validate logic.
  2. Run tests on Hardhat/Ganache for reproducibility.
  3. Use Injected Provider to deploy to a testnet via MetaMask.
