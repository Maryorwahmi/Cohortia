View and Pure Functions
These functions read state or compute values without changing storage. They do not consume gas when called locally.
Examples: getNumber() in SimpleNumberStorage.
Remix tip: view calls return values instantly in the UI.
State-changing Transactions
Functions that write to storage require a transaction and gas. The transaction must be mined to take effect.
Examples: setNumber(uint256) updates storedNumber and consumes gas.
Remix tip: simulated in JavaScript VM, prompts MetaMask in Injected Provider.
Example
Call getNumber to read 777; send setNumber with 999 to change the stored value and pay gas for the transaction.
Pro tip
Label UI actions clearly as read-only or transactional so users expect gas and confirmations where needed.
