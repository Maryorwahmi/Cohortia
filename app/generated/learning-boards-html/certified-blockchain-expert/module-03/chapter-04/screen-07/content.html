Starter code (SimpleNumberStorage)
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleNumberStorage {
  uint256 public storedNumber;

  constructor(uint256 _initialNumber) {
    storedNumber = _initialNumber;
  }

  function setNumber(uint256 _newNumber) public {
    storedNumber = _newNumber;
  }

  function getNumber() public view returns (uint256) {
    return storedNumber;
  }
}
Step actions
  1. Compile the contract and check for errors.
  2. Select JavaScript VM in Deploy & Run Transactions.
  3. Enter constructor value, for example 123, then click Deploy.
  4. Click getNumber to read; enter 456 and click setNumber to change state.
Result
After the transaction is mined in the JavaScript VM, getNumber returns the new storedNumber. The terminal shows the transaction receipt and gas used in the simulation.
