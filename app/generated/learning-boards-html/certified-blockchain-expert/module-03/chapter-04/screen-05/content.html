Module 3 › Chapter 3.4 › Deployment Flow
Step-by-step
1. You compile to get bytecode and ABI.
2. Create a transaction with bytecode in the data field and no recipient address.
3. The EVM executes the constructor as part of deployment.
4. Runtime code is stored at the new contract address derived from deployer and nonce.
5. Transaction receipt contains the new contract address and gas used.
Note: On public networks, gas must be paid in native Ether. In Remix JavaScript VM, this is simulated with pre-funded accounts.
Deploy Transaction
No to-address • data = bytecode • constructor runs once
compile → deploy → mine → address
Example scenario
Deploying SimpleNumberStorage with initial number 123 in JavaScript VM creates an instance you can call immediately; on a public testnet you must confirm the MetaMask transaction and wait for mining.
