Module 3 › Chapter 3.1 › Key Concepts
Ethereum Virtual Machine
The deterministic runtime that executes smart contract bytecode.
Externally Owned Account (EOA)
A private-key controlled account that signs transactions to initiate actions.
Contract Account
An on-chain account containing code and storage, executed by the EVM when called.
Summary

These three concepts are the core building blocks for understanding how Ethereum runs code, manages accounts, and processes transactions.
