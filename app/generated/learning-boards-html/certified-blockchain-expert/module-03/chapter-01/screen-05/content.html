Module 3 › Chapter 3.1 › EVM
Definition

Ethereum Virtual Machine

A replicated runtime that executes smart contract bytecode deterministically on every full node, producing identical state transitions.

Concrete example

A token contract's transfer function updates two balances and emits an event; the EVM makes the same updates on every node.

Why determinism matters

Determinism ensures consensus: nodes can independently verify that the same code and inputs produce the same outputs.

Common misconception

The EVM is not a cloud server; operations cost gas and every step is visible in the shared state.

Anatomy
Inputs
Transaction data, caller address, and current state.
Processing
Bytecode execution steps charged in gas.
Outputs
State updates, logs, and return data.
Key Takeaway

EVM makes smart contracts auditable and verifiable, but imposes gas costs for every operation.
