Module 3 › Chapter 3.1 › Account Types
Externally Owned Account

EOA — controlled by a private key

Signs transactions, sends Ether, and calls contracts. Has balance and nonce but no code.

Example

Alice signs a transaction in her wallet to call a DEX swap.

Misconception

An EOA cannot execute code on its own; it only signs and sends transactions.

Contract Account

Contract — controlled by deployed code

Holds bytecode and storage. Executes when called and can send Ether or create other contracts during execution.

Example

A token contract transfers balances and emits events when invoked by a transaction.

Key takeaway

Contracts act on input; EOAs provide signed input. Neither can spontaneously create a signed transaction outside execution flow.
