Module 3 › Chapter 3.1 › Ethereum vs Bitcoin
Core Claim

Different design goals

Bitcoin prioritizes secure value transfer with minimal scripting. Ethereum prioritizes deterministic execution of arbitrary programs on a shared blockchain state.

Bitcoin example

Send 1 BTC from Alice to Bob; ledger updates and transaction is final.

Ethereum example

Call a DEX smart contract to swap tokens; the contract executes code and updates multiple balances atomically.

Common misconception

Not all blockchains are equally suited for on‑chain programs; architecture and gas change what you can build.

Comparison
Scope
Bitcoin: value transfer. Ethereum: value + computation.
Programming model
Bitcoin: limited scripts. Ethereum: Turing‑complete EVM bytecode executed by nodes.
Costs
Bitcoin: transaction fee. Ethereum: gas for each operation; gas limits control execution.
Key Takeaway

Choose Ethereum when you need shared, verifiable program execution; choose Bitcoin for minimal, robust value transfer.
