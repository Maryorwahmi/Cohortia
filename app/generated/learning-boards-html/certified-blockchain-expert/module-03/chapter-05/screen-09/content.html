Module 4 › Chapter 3.5 › Modifiers — Practices
Do
  • Write single-purpose modifiers like onlyOwner, whenNotPaused.
  • Fail fast with require to save gas on unauthorized calls.
  • Stack modifiers for clear, composable checks and test ordering.
Don't
  • Put heavy logic or state changes inside modifiers.
  • Forget the underscore — it prevents the function from running.
  • Assume stacking order is irrelevant; test different orders.
Check Your Understanding
Write two small modifiers and stack them in a function. Test both orders and observe how the revert message and gas used change when the first check fails versus the second.
