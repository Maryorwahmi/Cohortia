Module 4 › Chapter 3.5 › Key Concepts
Event
A log emitted with emit to inform off-chain apps; not readable by contracts.
Modifier
A reusable pre-condition with the underscore placeholder where the function runs.
Inheritance
Reuse state and behavior across contracts using is; use virtual and override for customization.
Takeaway

Design contracts so events carry off-chain signals, modifiers centralize security, and inheritance shares proven modules while you override only where needed.
