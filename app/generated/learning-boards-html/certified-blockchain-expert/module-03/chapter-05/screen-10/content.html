Simple Inheritance Example
contract Ownable {
  address public owner;
  constructor() { owner = msg.sender; }
  modifier onlyOwner() { require(msg.sender == owner, "Ownable: caller is not the owner"); _; }
}

contract MyToken is Ownable {
  string public name = "My Cohortia Token";
  function mint(address _to, uint256 _amount) public onlyOwner { /* ... */ }
}
Key Rules
  • A child inherits public and internal members, not private ones.
  • Constructors of parents run when the child is deployed.
  • Use virtual in parent and override in child for function customization.
Safety Note
Avoid deep or tangled inheritance hierarchies. Even though Solidity uses C3 linearization, complex hierarchies can introduce subtle vulnerabilities; test merged behavior thoroughly.
