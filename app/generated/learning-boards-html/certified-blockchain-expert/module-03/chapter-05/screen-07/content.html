Module 4 › Chapter 3.5 › Function Modifiers
Modifier Example
address public owner;

constructor() { owner = msg.sender; }

modifier onlyOwner() {
  require(msg.sender == owner, "Only owner can call this function");
  _;
}

function withdrawFunds() public onlyOwner {
  payable(owner).transfer(address(this).balance);
}
Best Practices
  • Keep modifiers single-purpose and simple.
  • Always include the underscore where appropriate.
  • Use clear error messages in require to aid debugging.
Common Mistake
Leaving out the underscore will stop the function body from executing, often silently causing confusion during testing.
