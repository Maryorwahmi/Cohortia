Module 4 › Chapter 3.5 › Abstract Contracts
Abstract Example
abstract contract Base {
  function doWork() public virtual;
}

contract Impl is Base {
  function doWork() public override { /* implementation */ }
}
Practical Notes
  • Abstract contracts define required behavior without implementation.
  • Mark parent functions virtual and child functions override for customization.
  • Compiler enforces matching signatures and helps prevent accidental mistakes.
Check
When designing abstract bases, document the intended override points and run compilation to ensure all abstract methods are implemented by derived contracts before deployment.
