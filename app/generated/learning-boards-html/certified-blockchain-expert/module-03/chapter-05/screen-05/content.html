Module 4 › Chapter 3.5 › Emit Events
Step-by-step
  1. Design the event signature with the fields you want to expose.
  2. Mark at most three parameters as indexed for filtering efficiency.
  3. Emit the event immediately after the state change that clients care about.
  4. Confirm emitted logs in the transaction receipt or explorer for correctness.
Example Signature
event Transfer(address indexed from, address indexed to, uint256 value);

// Emitted inside a transfer function
emit Transfer(sender, receiver, amount);
Why it matters
Choosing which fields to index affects client performance and gas cost. Correctly emitted events let UIs update quickly and support analytics without heavy on-chain storage.
Common Mistake
Indexing every parameter increases costs and rarely helps client queries.
Pro Tip
Index addresses and identifiers that correspond to typical search queries, like user wallets or token IDs.
