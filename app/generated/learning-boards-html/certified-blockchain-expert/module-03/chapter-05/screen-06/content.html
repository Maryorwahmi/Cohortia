Module 4 › Chapter 3.5 › Remix Workflow
Terminal-style Steps
  1. Compile AccessControlledStorage.sol in Remix’s Solidity Compiler.
  2. Deploy with an initial value and note the deployer account as owner.
  3. Call updateValue as owner; inspect transaction details for ValueUpdated in logs.
  4. Switch to another account and call updateValue; observe revert and no logs emitted.
What to look for in logs
Event name, data payload, and topics for indexed fields. Confirm that the address and values match the expected parameters from the call you made.
Example Verification
A successful update emits ValueUpdated and appears under logs. A revert due to onlyOwner prevents state change and there are no emitted logs. This proves modifiers stop code before events run.
