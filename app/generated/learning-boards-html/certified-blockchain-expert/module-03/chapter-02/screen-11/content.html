Module 3 › Chapter 3.2 › Activity
Step-by-step activity
Estimate a transfer fee, then analyze a block to compare estimates to reality.
  1. Estimate: Simulate a transfer for 0.001 ETH. Get gasEstimate and current gasPrice. Compute cost = gasEstimate × gasPrice.
  2. Find a block: Choose a recent block and note block number, timestamp, gasUsed, gasLimit, and base fee.
  3. Inspect a tx: Open any transaction in that block. Record gasUsed, gasPrice, and compute actual fee = gasUsed × gasPrice.
  4. Compare: How close was your estimate? If different, check for contract calls or additional storage operations.
  5. Reflect: Decide what confirmation depth you would require for a similar transfer and why.
Expected outcome
You will be able to explain differences between estimates and actual gasUsed and articulate how block gas limits influenced which transactions were included.
Check
Did unused gas get refunded? Did your estimate match the transaction's gasUsed? If not, why?
