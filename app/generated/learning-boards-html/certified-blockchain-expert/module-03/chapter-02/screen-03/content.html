Module 3 › Chapter 3.2 › Practice Objectives
Estimate & Compare
Run a simulated transfer to get a gas estimate, then find a similar transaction on a block explorer to compare estimated versus actual gas used.
Practice
Estimate cost for 21,000 gas at 30 Gwei and compare to recorded gas used in a real transfer.
Reflection
If estimates differ, check whether the transaction included a contract call or extra storage writes.
Inspect Block Metadata
Identify block height, timestamp, gas used, gas limit, and base fee. Pick a transaction and note its gas used and fee paid.
Competency
Explain how a block's gas limit affected which transactions fit in that block.
