Step-by-step fee math
Follow these calculations to reason about maximum and actual costs.
Step 1
Identify gasLimit set by sender and current gasPrice in Gwei.
Step 2
Compute max fee: gasLimit × gasPrice. Convert Gwei to Ether for user-facing cost.
Step 3
After execution, compute actual fee: gasUsed × gasPrice. Refund any unused gas.
Worked example
gasLimit = 200,000; gasPrice = 50 Gwei → max fee = 0.01 ETH. If gasUsed = 150,000 → actual fee = 0.0075 ETH.
Common mistake
Setting gasLimit too low causes failure and loss of consumed gas; setting gasPrice too low delays inclusion.
Try this
Use the provided calculation to estimate fees before sending. Convert Gwei to Ether: 1 Gwei = 10⁻⁹ ETH.
