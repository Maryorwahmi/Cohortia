Fields and their roles
Each field enforces correctness or carries data for execution.
nonce
Sequential counter per sender. Prevents replay and ensures ordered execution.
to
Recipient address: EOA or contract account.
value
Amount of Ether to transfer, may be zero for contract calls.
data
ABI-encoded function selector and parameters for contract interactions.
signature
Cryptographic proof (r, s, v) that the transaction is authorized by the sender's private key. Nodes verify it before executing state changes.
Example
Two pending transactions must have unique nonces. A replacement transaction uses the same nonce with a higher gasPrice to replace an earlier pending one.
Check your understanding
If a transaction’s data field is non-empty, what should you inspect before broadcasting? Verify the contract address, function selector meaning, and parameters to avoid unexpected approvals or transfers.
