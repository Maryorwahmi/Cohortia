Module 5 › Chapter 5.3 › Per-frame pattern
1. Poll / Drain
Collect raw device state or drain OS event queue so you have the latest inputs.
2. Update Manager
Copy current to previous, then update current from the raw state so transitions are detectable.
3. Translate to Actions
Query the manager for active or newly pressed actions and prepare inputs for game systems.
4. Run Game Systems
Apply movement, physics, AI responses, and UI changes based on translated actions.
5. Render
Draw the frame reflecting the applied actions, ensuring the frame shows the player's intent.
Key Takeaway

Enforce a stable input-to-action point in your loop so transitions like just-pressed are detected reliably and gameplay feels responsive.
