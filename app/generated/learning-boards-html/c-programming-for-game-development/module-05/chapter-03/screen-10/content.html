Module 5 › Chapter 5.3 › Testing & Mistakes
Common mistakes
  • • Hardcoding key checks in entities, making remapping difficult.
  • • Not tracking previous state, breaking just-pressed detection.
  • • Processing input after systems or rendering, introducing latency.
Warning
Avoid returning only the first active action if your game requires multiple simultaneous actions.
Test strategies
Inject simulated states into InputManager: set previous false, current true for a just-pressed test; set current true across frames for held tests. Assert expected outputs and console messages.
Assessment tip: For movement use IsKeyDown; for jump use IsKeyJustPressed. Write tests to confirm both behaviors.
