Input Handling in the Game Loop
From raw device data to game actions: polling, events, and mapping.

This lesson explains why input is gathered early each frame, when to poll, when to use events, and how an InputManager abstracts raw keys into actions that your game logic consumes.

In this lesson
Polling vs Event
Compare continuous checks and event notifications.
InputManager
Map raw input to game actions for flexibility.
Key Held vs Just Pressed
Differentiate continuous movement from one-shot actions.
Visual: Mapping Flow
Raw input → InputManager → GameAction → Game Systems
Raw Input: key codes, mouse positions, gamepad axes
InputManager: binds keys to actions, tracks held/just-pressed
GameAction: MoveForward, Jump, OpenMenu
