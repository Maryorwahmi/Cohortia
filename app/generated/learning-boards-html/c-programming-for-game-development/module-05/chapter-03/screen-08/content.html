Module 5 › Chapter 5.3 › KeyHeld vs KeyJustPressed
Implementation steps
  1. 1. Maintain currentKeyStates and previousKeyStates maps in InputManager.
  2. 2. At frame start, copy current to previous.
  3. 3. Update current from the raw input source.
  4. 4. IsKeyDown checks current; IsKeyJustPressed checks current && !previous.
Analogy: previous is a snapshot of what you saw last frame; current is what you see now. The difference reveals new presses.
