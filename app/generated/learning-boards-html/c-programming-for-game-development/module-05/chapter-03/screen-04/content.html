Module 5 › Chapter 5.3 › Why input belongs early
Definition and purpose

Input handling: collect raw device data and convert it to a consistent set of game actions before updates run.

  • • Ensures game updates reflect the player's latest commands for that frame.
  • • Makes physics and AI respond deterministically to the same input snapshot.
  • • Reduces perceived input latency by applying changes before rendering.
Key Takeaway

Read and normalize input early each frame so visuals and gameplay reflect the player's intent immediately.

Concrete example

In a platformer, read the jump key at the frame start. The physics step will apply upward velocity and collision will run using that velocity before rendering, producing a frame that shows the jump immediately.

Common mistake: reading input after physics or rendering, causing missed or delayed reactions.
Check your understanding:
If an attack should occur the instant a button is pressed, when should you sample that button relative to combat resolution? Answer: before applying combat effects, so the input is reflected in the same update.
