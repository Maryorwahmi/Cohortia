Module 5 › Chapter 5.3 › Key Concepts
Polling-based Input
Query device state each frame for continuous actions.
Event-driven Input
Receive notifications on input changes for one-shot responses.
InputManager
Translate raw input into game actions and provide a unified API.
Takeaway
Use polling for held controls, events for discrete triggers, and an InputManager to keep game logic device-agnostic and testable.
