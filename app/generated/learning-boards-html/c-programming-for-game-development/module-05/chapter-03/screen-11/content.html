Module 5 › Chapter 5.3 › Run vs Jump
Run logic (held)
// Pseudocode
if (inputManager.IsKeyDown(KeyCode::W)) {
  player.velocity.x += speed * deltaTime;
}
This ensures movement continues every frame the key is held.
Jump logic (just pressed)
// Pseudocode
if (inputManager.IsKeyJustPressed(KeyCode::Space) && player.isGrounded) {
  player.velocity.y = jumpImpulse;
}
A single impulse is applied only when the press transitions from not-pressed to pressed.
