Module 5 › Chapter 5.3 › InputManager Design
Responsibilities
  • • Store bindings: KeyCode → GameAction.
  • • Track current and previous key states for held and just-pressed detection.
  • • Expose queries: IsActionActive, IsKeyJustPressed, RemapKey.
Benefit: Tests can simulate input by modifying the manager's state maps instead of needing real devices.
Example API
public: void UpdateInputStates(); bool IsKeyDown(KeyCode); bool IsKeyJustPressed(KeyCode); void SetKeyBinding(KeyCode,GameAction); GameAction GetActiveAction();
Key Takeaway

Design the InputManager to hide device details so game code only uses action queries and stays platform-agnostic.
