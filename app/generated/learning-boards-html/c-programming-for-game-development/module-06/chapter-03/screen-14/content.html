Concurrency / Parallelism
Concurrency manages tasks; parallelism runs them at the same time on multiple cores.
std::thread
Creates a new thread; remember to join or detach to manage lifetime.
std::mutex & lock_guard
Synchronize access to shared data; prefer lock_guard for RAII safety.
Takeaway
Parallelism improves performance when work is independent; synchronization ensures correctness. Use the right abstraction for the job and measure the results.
