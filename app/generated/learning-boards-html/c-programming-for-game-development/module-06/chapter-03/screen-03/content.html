Technical Skills and Safety
Concrete coding practices you will use in engine code.
Pass by reference
Use std::ref when you want a thread to operate on shared containers without copying.
Synchronize
Protect shared state with std::mutex and prefer std::lock_guard for exception safety.
Task APIs
Use std::async and std::future to simplify life-cycle when tasks return values.
Verified Competency Milestone

Implement a small parallel loop that uses threads to process chunks and a mutex to protect a logging function.
