Code
#include <future>
#include <vector>
#include <numeric>

long long sumRange(const std::vector<int>& data, int start, int end) {
  long long total = 0;
  for (int i = start; i < end; ++i) total += data[i];
  return total;
}

// launch async tasks, collect futures, and combine results with .get()
Explanation
  • std::async launches a callable and returns a std::future for its result.
  • Call future.get() to wait for completion and retrieve the value.
  • Prefer std::launch::async when you want a new thread rather than deferred execution.
Concrete example
Compute partial sums with async calls, then combine futures to produce the total sum without manual join bookkeeping.
Key Takeaway

std::async simplifies task-based parallelism and result aggregation, often safer than managing many raw threads.
