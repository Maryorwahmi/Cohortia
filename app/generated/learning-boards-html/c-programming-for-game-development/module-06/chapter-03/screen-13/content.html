Module 6 › Chapter 6.3 › Threads vs Tasks
Raw std::thread
  • Full control over thread lifecycle and affinity.
  • Requires explicit join/detach and careful argument passing.
  • Higher risk of lifecycle bugs if not managed correctly.
std::async / std::future
  • Simplifies task submission and result retrieval.
  • Reduces bookkeeping and often plays well with thread pools.
  • Use std::launch::async to request immediate execution on a new thread.
Example decision

If you need values returned and want less management, choose async. If you need a dedicated long-running thread with special scheduling, choose std::thread.
