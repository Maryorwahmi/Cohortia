Module 6 › Chapter 6.3 › Parallelizable Tasks
Common candidates
Particles
Many independent updates; easy to chunk into ranges.
Physics
Independent rigid bodies or region-based updates work well in parallel.
AI
Per-agent logic can be distributed when it doesn’t require global locks.
Asset loading
Background decompression and I/O avoid blocking the main thread.
Chunking process
1
Identify independent units of work that do not share writable state.
2
Partition into contiguous chunks or spatial regions to preserve cache locality.
3
Schedule each chunk to a worker and synchronize only when necessary.
Example

Split a physics body array into four ranges and assign each to a thread per frame, then combine any collision events afterward.
