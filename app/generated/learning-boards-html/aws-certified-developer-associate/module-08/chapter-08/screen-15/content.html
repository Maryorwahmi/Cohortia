Module 8 › Chapter 8.8 › Key Concepts
IAM Permissions
Use CloudTrail to find denied actions and grant only the exact actions needed to service roles.
buildspec.yml Errors
Syntax or command typos in buildspec cause immediate build failures; validate YAML and reproduce commands locally.
appspec.yml & Hooks
Hook script failures are visible in CodeDeploy events and the codedeploy-agent log on EC2; check paths and script permissions.
Final takeaway
Permissions and configuration errors are fixable with targeted investigation. Build a repeatable test loop and alerting so issues are discovered and resolved quickly.
