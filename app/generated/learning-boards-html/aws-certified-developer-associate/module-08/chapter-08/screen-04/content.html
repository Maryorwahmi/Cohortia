Module 8 › Chapter 8.8 › Locate Failures
Process Flow

Start at the failing stage

Identify the stage, action, and execution ID before running any fixes. These point you to the exact logs and artifacts.

1
Capture stage and action
This directs you to the service execution record you must inspect.
2
Follow execution links
Open CodeBuild/CodeDeploy logs linked from the pipeline execution to read detailed output.
3
Ask diagnostic questions
Is this a syntax/config, dependency, environment, or IAM problem?
Key Takeaway

Treat the pipeline visual as your map — it tells you precisely where to begin your log-based investigation.

Example

Failed Build action traced to CodeBuild execution

A build stage shows 'Failed' and links to CodeBuild execution ID. The build record contains a link to CloudWatch logs showing the failing install command and exit code.

What to copy
Stage name, action name, execution ID and commit SHA — use these values in ticketing and searches.
Common mistake
Fixing the deploy stage without checking the build artifacts produced earlier.
