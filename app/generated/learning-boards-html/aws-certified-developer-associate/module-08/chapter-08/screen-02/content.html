Learning Objectives

Skills you will practice and verify during the lab walkthrough.

Bloom: Learn → Understand → Apply → Master
01
Locate pipeline failures

Identify the specific stage and action in CodePipeline where execution stops and gather the action context for deeper inspection.

VERIFIED COMPETENCY MILESTONE
02
Read service logs

Use CloudWatch Logs for CodeBuild and Lambda, and CodeDeploy agent logs on EC2, to extract the root error and failing command or script output.

VERIFIED COMPETENCY MILESTONE
03
Diagnose config & IAM

Verify build environments, runtime versions, and IAM permissions for the service roles involved in the failing action.

VERIFIED COMPETENCY MILESTONE
04
Implement monitoring

Set CloudWatch alarms and SNS notifications for failed pipeline executions and key metrics so failures surface quickly to responders.

VERIFIED COMPETENCY MILESTONE
