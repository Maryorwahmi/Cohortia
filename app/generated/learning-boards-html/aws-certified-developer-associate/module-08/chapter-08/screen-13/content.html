Lab Walkthrough

Simulate, inspect, fix, verify

Follow a tight loop: introduce a small error, find the failing line in logs, fix locally, push, and confirm success.

Step-by-step
  1. Edit buildspec.yml to introduce a typo in a command.
  2. Commit and push to CodeCommit to trigger the pipeline.
  3. Open the failed CodeBuild execution and read CloudWatch logs for the error line.
  4. Reproduce locally in the same runtime, fix the typo, commit, and push the correction.
  5. Confirm the pipeline now completes successfully.
Example log snippet
[Container] Running command npm instll
/codebuild/output/tmp/script.sh: line 1: npm: command not found
Phase complete: INSTALL State: FAILED
Key Takeaway

Hands-on repetition builds a fast mental model: logs point to commands, local reproduction confirms causes, and small commits validate the fix.

Practice checkpoints
Checkpoint 1
Can you locate the exact failing command and its exit code in CloudWatch logs?
Checkpoint 2
Can you reproduce the same failure locally in the same runtime image?
Checkpoint 3
After the fix, does the pipeline's Build stage complete and the deployment proceed?
Reflection: What one change shortened your debug time most—better logs, local reproduction, or clearer artifact names?
