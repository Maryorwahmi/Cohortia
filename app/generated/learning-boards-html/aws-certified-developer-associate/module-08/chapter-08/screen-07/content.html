Module 8 › Chapter 8.8 › CodeDeploy
Definition

Agent logs & lifecycle hooks

Inspect the CodeDeploy agent log on EC2 to read lifecycle hook script output and identify failing commands or missing files mentioned by appspec.yml.

Where to look
/var/log/aws/codedeploy-agent/codedeploy-agent.log contains the full agent run and hook outputs.
What to check
  • appspec.yml file paths and script names
  • Exit codes from hook scripts and any stderr output
  • Instance profile permissions for S3 or other services
Example

Failing lifecycle hook

If the ValidateService hook fails, the agent log will show the script output and its exit code. Fix the script or its environment, then redeploy. If the application fails to start, check app logs (for example, Apache or application error logs) in addition to the agent log.

Common mistake

Only checking the CodeDeploy console Events; for EC2 targets, the agent log on the instance is required to see script stdout and stderr.

Try this

SSH into the target instance, tail the codedeploy-agent.log during a redeploy, and watch for the failing hook’s output to identify the offending command or missing file.
