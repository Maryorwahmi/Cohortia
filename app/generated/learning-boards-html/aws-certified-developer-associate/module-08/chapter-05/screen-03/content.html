Module 8 › Chapter 8.5 › Practice & Troubleshoot
Practical tasks
  • Create pipeline named MyWebApp-Pipeline with a fresh service role.
  • Use the default artifact store so CodePipeline places artifacts into S3 for handoff.
  • Add a manual approval action before production deploy and subscribe an SNS topic for notifications.
  • Inspect execution history and drill into CodeBuild logs or CodeDeploy events when a stage fails.
Mnemonic: create → connect → verify → monitor. Each step produces an artifact and a record in execution history.
Verification cards
Verify Source
Push a commit and confirm the pipeline triggers a new execution and creates a source artifact in S3.
Verify Build
Check CodeBuild logs for compilation results and artifact upload confirmation.
Verify Deploy
Confirm CodeDeploy events show a successful application revision registration and deployment.
