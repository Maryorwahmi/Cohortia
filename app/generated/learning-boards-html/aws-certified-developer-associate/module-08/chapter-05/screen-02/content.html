Mnemonic
Remember: S-B-T-D — Source, Build, Test, Deploy. Artifacts move right; approvals pause the flow. Use the pipeline execution history to trace an artifact through these stages.
Quick Tip

Treat each stage as a contract: inputs must match an action's expected artifact structure to avoid failures.
