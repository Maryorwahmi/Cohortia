Module 8 › Chapter 8.5 › Best Practices
Practical rules
  • Split unit and integration tests into separate stages for faster feedback.
  • Define artifact naming and layout conventions and document them for all teams.
  • Use approvals sparingly and pair them with SNS notifications for fast response.
  • Version pipeline configs so the pipeline can be recreated reliably.
Recovery & observability
Keep CodeBuild logs and CodeDeploy events easy to reach from the pipeline UI. When incidents occur, re-run or replay a specific artifact to reproduce behavior, rather than rebuilding from an unverified source.
Key Takeaway
Design pipelines for speed, clarity, and recoverability by enforcing clear contracts and observability across stages.
