Module 8 › Chapter 8.5 › Hands-on: Create Pipeline
Prerequisites
  • CodeCommit repo named my-first-ci-cd-app with index.html, appspec.yml, and scripts/
  • CodeBuild project MySimpleWebAppBuild configured to output artifacts to your S3 bucket
  • CodeDeploy application MyWebApp and deployment group MyWebApp-Prod
Console steps
Create pipeline → Name it MyWebApp-Pipeline → Choose New service role → Default artifact store → Add Source (CodeCommit) → Add Build (CodeBuild) → Add Deploy (CodeDeploy) → Create pipeline.
Trigger from terminal
# Edit index.html locally
git add index.html
git commit -m "Update to version 2"
git push origin main
After pushing, watch the pipeline execution. If any stage fails, open the execution history and click the failing action for links to CodeBuild logs or CodeDeploy events.
Key Takeaway
A single commit can drive a full release when the pipeline is correctly wired and roles are in place.
