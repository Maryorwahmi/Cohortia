Module 8 › Chapter 8.5 › Troubleshooting
Step-by-step diagnosis
  1. Open pipeline execution history and locate the failed action.
  2. Click through to the provider's logs (CodeBuild logs, CodeDeploy events).
  3. If logs point to missing files, inspect the S3 artifact contents.
  4. If error states access issues, audit the pipeline service role permissions.
Pro tip
Use the pipeline's links to jump directly to the service logs; they include the specific error messages needed to fix the problem.
Example scenarios
Build failure
CodeBuild shows a failed test or missing dependency. Fix buildspec or dependencies and re-run.
Deploy failure
CodeDeploy events indicate appspec or hook errors, or agent not running. Check instance agent and appspec structure.
Key Takeaway

Start at pipeline history, follow service links, and inspect artifacts and roles to pinpoint the root cause quickly.
