Process Flow EC2 lifecycle hooks
Prepare → Install → Start → Validate
1. BeforeInstall
2. AfterInstall
3. ApplicationStart
4. ValidateService
BeforeInstall
Stop services, back up files, or prepare the environment so the install step can proceed cleanly.
AfterInstall
Install dependencies and set permissions once new files are present. This prevents missing-file errors.
ApplicationStart
Start or restart application services and ensure processes come up correctly.
ValidateService
Run tests or a simple curl to verify the app responds with expected content before you route traffic.
Example scripts
stop_web_server.sh — check running process and stop Apache start_web_server.sh — install httpd and start service validate_service.sh — sleep, check process and curl localhost
Common mistake
Running installation prior to copying files leads to missing artifacts; keep order strict.
Key Takeaway

Sequence hooks so preparation happens first, files arrive, then installation, start, and validation to ensure reliable deployments.
