Architecture Application & Deployment Group
Logical container and target definition
Deployment application
A logical name for your deployable artifact. Use one application per microservice or logical component to keep deployments focused.
Deployment group
Defines targets (EC2 by tag, Lambda alias, ECS service), service role, deployment type, and configuration.
Common setup
Name the group clearly, assign a role with CodeDeploy permissions, and select instance tags or service selectors that match your resources.
Deployment configurations
  • CodeDeployDefault.AllAtOnce — update all targets quickly.
  • CodeDeployDefault.OneAtATime — update serially for minimal risk.
  • CodeDeployDefault.HalfAtATime — update in batches to balance speed and capacity.
Recommendation
Choose a config based on capacity: use OneAtATime for critical services and AllAtOnce for non-critical or low-traffic updates.
