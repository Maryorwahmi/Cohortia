Comparison EC2 vs Lambda vs ECS
Pick hooks and validation appropriate to the platform
EC2 / On-Prem
Agent-based. appspec.yml lists files and lifecycle hooks like BeforeInstall and ValidateService. Use this when you need direct file placement and service control.
Example
Copy index.html to /var/www/html and run scripts to stop and start Apache.
AWS Lambda
Versioned deployments and traffic shifting. appspec.yml focuses on updating function versions and running hooks during traffic migration, such as BeforeAllowTraffic and AfterAllowTraffic to validate the new version.
Example
Deploy new version, run smoke tests, then shift traffic once validated.
Amazon ECS
Integrates with service deployments and load balancers. CodeDeploy can help coordinate task updates and control traffic to new tasks while validation occurs.
Example
Update task definition, let CodeDeploy shift traffic across target groups, and validate service health checks.
Practical rule
Match the appspec hooks and validation to the runtime model: file control for EC2, version checks for Lambda, and task-level checks for ECS.
