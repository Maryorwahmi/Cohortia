Definition Lambda deployment hooks
Validate versions while traffic shifts
Traffic-shift hooks
  • BeforeAllowTraffic — run quick tests before new version receives traffic.
  • AfterAllowTraffic — run post-shift checks after traffic is shifted to the new version.
Example
Deploy version v2, invoke a smoke test in BeforeAllowTraffic, shift 10% then 100% if validations pass.
Why this matters
Versioned deployment with traffic shifting minimizes risk and provides an easy rollback path by reverting the alias to the old version.
Design checklist
  1. Keep smoke tests brief and deterministic.
  2. Use alarms to trigger automatic rollback if error rates rise.
  3. Log test output to help debug failures quickly.
Key Takeaway

Lambda appspec.yml focuses on versions and traffic validation; use short tests before allowing full traffic.
