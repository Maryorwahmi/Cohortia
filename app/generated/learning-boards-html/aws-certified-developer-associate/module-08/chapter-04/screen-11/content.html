Process Flow Blue/Green with ELB
Provision → Validate → Shift → Monitor → Rollback
Step-by-step
  1. Provision green environment with the new revision and run ValidateService checks.
  2. If validation passes, initiate traffic shifting via ELB using a chosen policy.
  3. Monitor CloudWatch alarms for errors or latency during the shift.
  4. If alarms trigger, CodeDeploy can automatically rollback by shifting traffic back to blue.
Traffic policies
AllAtOnce, Linear, and Canary control the pace of traffic migration and the validation windows between increments.
Design notes
  • Make validation checks representative of real requests.
  • Plan for stateful migrations separately; blue/green favors stateless or backward-compatible changes.
  • Use alarms to automate rollback to the known-good environment.
Key Takeaway

Combine staged traffic shifting with deterministic validation and monitoring to achieve safe production cutovers and quick rollback when needed.
