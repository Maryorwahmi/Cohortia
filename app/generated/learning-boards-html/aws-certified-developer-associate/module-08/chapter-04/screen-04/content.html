Core Concept What is CodeDeploy?
A managed deployment automation service
Automates file copy, scripts, traffic control and monitoring for safe, repeatable releases.
Definition & context

CodeDeploy orchestrates deployments across EC2 instances, Lambda functions, and ECS services to reduce manual steps and ensure consistency.

Concrete example
Package a static site, appspec.yml copies index.html to /var/www/html and runs start scripts to serve the site.
Misconception
Automation is not validation: include ValidateService hooks to confirm traffic can reach the new release.
Key takeaway
CodeDeploy makes updates predictable and easier to roll back by centralizing deployment steps and traffic control.
Platform support
EC2 / On-premises
Uses an agent on instances and appspec.yml hooks to run scripts and copy files.
AWS Lambda
Deploys new versions and shifts traffic with lifecycle hooks oriented to allow traffic only when ready.
Amazon ECS
Integrates with service deployments to update tasks and manage traffic via load balancers when appropriate.
Why this matters: reduce human error and enable consistent rollouts across environments.
