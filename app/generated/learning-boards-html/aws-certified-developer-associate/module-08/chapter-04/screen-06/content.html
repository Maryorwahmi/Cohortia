Definition appspec.yml structure
Files and hooks form the deployment playbook
Files section
Maps source paths in your artifact to destination paths on targets. Paths are relative to the artifact root.
Hooks section
  • BeforeInstall — stop services or prepare the instance
  • AfterInstall — install dependencies after files are copied
  • ApplicationStart — start services
  • ValidateService — run tests to verify the deployment
Common trap: wrong path or non-executable scripts cause the deployment to fail.
Sample appspec.yml
version: 0.0
os: linux
files:
  - source: /index.html
    destination: /var/www/html/
hooks:
  BeforeInstall:
    - location: scripts/stop_web_server.sh
      timeout: 300
      runas: root
  AfterInstall:
    - location: scripts/start_web_server.sh
      timeout: 300
      runas: root
  ValidateService:
    - location: scripts/validate_service.sh
      timeout: 300
      runas: root
Pro tip
Place scripts in a scripts directory at the artifact root and mark them executable before bundling.
