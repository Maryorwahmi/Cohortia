Definition
Infrastructure as Code (CloudFormation)
Define AWS resources in YAML or JSON templates so you can version, review, and deploy infrastructure consistently across environments.
Why it matters
Treat pipeline resources like application code to reduce manual setup, enable reviews, and ensure consistent deployments.
Key Takeaway

Use CloudFormation to version control CI/CD resources and make deployment environments repeatable and auditable.

Concrete example — S3 bucket template snippet
AWSTemplateFormatVersion: '2010-09-09'
Description: Creates an S3 bucket with versioning
Parameters:
  BucketName:
    Type: String
Resources:
  MyVersioningBucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: !Ref BucketName
      VersioningConfiguration:
        Status: Enabled
Outputs:
  S3BucketName:
    Value: !Ref MyVersioningBucket
This snippet shows how resources and outputs are declared; use Parameters to keep templates reusable across environments.
