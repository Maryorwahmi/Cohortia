Process Flow
Canary Deployment Steps
1. Choose traffic percent
Start small, typical 1–5%.
2. Define metrics & thresholds
Errors, latency, business KPIs. Example: 5xx > 1% for 5 minutes.
3. Run and observe
Collect logs, traces and user behavior data for diagnosis.
4. Ramp or rollback
Gradually increase traffic when healthy, or rollback if alarms fire.
Key Takeaway

Structured canaries let you validate in production and limit user impact when issues appear.

Scenario: Payment endpoint update
You introduce a new checkout optimization. Route 3% of traffic to the new service version. Monitor 5xx errors and completion rate for five minutes. If 5xx errors go above 1% for five minutes, rollback automatically. If both metrics are stable, increase to 10%, then 50%, then 100%.
Common mistake
Ramping too quickly after short windows of positive data. Use sustained monitoring windows and multiple metrics before expanding traffic.
