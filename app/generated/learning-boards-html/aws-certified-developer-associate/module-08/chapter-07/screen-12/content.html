Deploy and Update an S3 Stack
  1. Create s3-bucket-template.yaml locally with Parameters, Resources, Outputs.
  2. CloudFormation console: Create stack → upload template → supply BucketName parameter.
  3. Monitor Events until CREATE_COMPLETE and verify bucket in S3.
  4. Modify template to add a BucketPolicy that denies non-HTTPS access.
  5. Update stack: upload modified template and Create change set; review changes and Execute.
Template update snippet (policy addition)
# In Resources, add a BucketPolicy resource that denies non-HTTPS access
BucketPolicy:
  Type: AWS::S3::BucketPolicy
  Properties:
    Bucket: !Ref MyVersioningBucket
    PolicyDocument:
      Statement:
        - Effect: Deny
          Principal: '*'
          Action: 's3:*'
          Resource:
            - !Sub 'arn:aws:s3:::${MyVersioningBucket}/*'
            - !Sub 'arn:aws:s3:::${MyVersioningBucket}'
          Condition:
            Bool:
              aws:SecureTransport: 'false'
Create the change set, confirm it shows adding BucketPolicy, then execute and verify the policy in S3 console.
