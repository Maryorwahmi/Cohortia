S3 Bucket Template Explained
Parameters let you supply environment-specific values; Resources declare AWS objects; Outputs expose useful values for other stacks or operators.
Common pitfall
Bucket names must be globally unique. Using a parameter with clear validation helps prevent deployment failures.
Full template (example)
AWSTemplateFormatVersion: '2010-09-09'
Description: >
  This template creates an S3 bucket with versioning enabled.
Parameters:
  BucketName:
    Type: String
    Description: The name of the S3 bucket to create.
Resources:
  MyVersioningBucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: !Ref BucketName
      VersioningConfiguration:
        Status: Enabled
Outputs:
  S3BucketName:
    Value: !Ref MyVersioningBucket
  S3BucketARN:
    Value: !GetAtt MyVersioningBucket.Arn
