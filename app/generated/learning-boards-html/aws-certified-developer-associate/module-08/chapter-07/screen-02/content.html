Learning Objectives
These skills focus on lowering deployment risk and making infrastructure changes predictable.
01
Implement Canary & A/B Testing
Roll out new versions to a small subset to validate behavior and compare variants against business metrics. This reduces blast radius while you measure impact.
VERIFIED COMPETENCY MILESTONE
02
Configure Automated Rollbacks
Tie CloudWatch alarms to CodeDeploy so deployments revert automatically if critical metrics cross thresholds, limiting user impact and speeding recovery.
VERIFIED COMPETENCY MILESTONE
03
Use IaC for CI/CD Resources
Define CodeCommit, CodeBuild, CodePipeline, and CodeDeploy resources in CloudFormation so environments are reproducible and auditable.
VERIFIED COMPETENCY MILESTONE
04
Parameterize Templates & Use Change Sets
Make templates reusable across environments and preview stack changes to avoid unintended deletions or modifications before execution.
VERIFIED COMPETENCY MILESTONE
