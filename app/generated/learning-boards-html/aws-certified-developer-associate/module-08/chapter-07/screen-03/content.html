Learning Objectives — Applied View
Plan a Canary
Define target percentage, monitoring windows, and rollback thresholds so you can iterate safely on production traffic.
Milestone: Canary validated in staging and 1st production release sent to 1–5% users.
Define A/B Metrics
Choose conversion or engagement metrics, route traffic with weights, and run the test long enough to reach statistical confidence.
Milestone: Winner determined and promoted or rolled back.
Configure Alarms & Rollback
Create CloudWatch alarms for critical metrics and link them to deployment groups so CodeDeploy can revert if thresholds are breached.
Milestone: Alarm triggers a rollback in a controlled test.
Author Parameterized Templates
Use Parameters to supply environment-specific values and Change Sets to preview updates before execution.
Milestone: Template deployed to dev, then promoted to staging with different parameters.
