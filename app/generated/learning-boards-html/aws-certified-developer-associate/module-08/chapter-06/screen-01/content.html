Introduction to Serverless Deployment with AWS SAM
Learn how to describe, package, and deploy Lambda-based APIs using SAM, and know when to consider the Serverless Framework.

In this lesson you will understand serverless benefits, the SAM template model, and the CLI workflow that turns code into an API. We emphasize practical steps you can run in a terminal so you can reproduce deployments across environments.
