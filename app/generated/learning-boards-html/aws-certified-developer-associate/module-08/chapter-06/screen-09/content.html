Hands-on Activity
Deploying the 'Hello World' Serverless API
Terminal-first commands and expected outputs for a successful deployment.
Steps
sam init  # choose Python 3.9, Hello World, project name=my-serverless-api
cd my-serverless-api
sam build  # creates .aws-sam/build
sam deploy --guided
  # set stack name, region, allow role creation, save to samconfig.toml
# After deploy: copy API URL and run
curl https://.execute-api..amazonaws.com/Prod/hello
Expected: the CLI reports the API endpoint and curl returns the JSON {"message": "Hello from your Serverless API!"}.
Troubleshooting & cleanup
If the curl response fails, check CloudWatch logs for the Lambda function, confirm dependencies built into .aws-sam/build, and ensure deploy had permission to create roles. To remove resources:
aws cloudformation delete-stack --stack-name my-serverless-api-stack
Tip: Save answers to samconfig.toml during guided deploy to reproduce the same deploy later with sam deploy.
Key Takeaway

Follow the full sam init → sam build → sam deploy --guided flow to avoid missing artifacts and to produce a working API endpoint you can test with curl.
