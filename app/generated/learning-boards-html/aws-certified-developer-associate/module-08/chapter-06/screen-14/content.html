Module 8 › Chapter 8.6 › Key Concepts
Serverless Computing
Provider manages servers, you pay per execution and focus on code and events.
AWS SAM
SAM extends CloudFormation with shorthand for Lambda, API Gateway, and packaging operations.
SAM CLI Flow
sam init → sam build → sam deploy --guided. Build packages code; deploy applies a CloudFormation stack.
Summary Takeaway

Use SAM to author concise templates and run the CLI workflow to produce reliable, repeatable serverless deployments. Verify permissions and always run sam build before deploying.
