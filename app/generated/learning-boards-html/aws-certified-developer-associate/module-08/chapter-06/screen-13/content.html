Lifecycle: From Local Code to Deployed API
A step-by-step timeline of build, package, deploy, and runtime events to guide troubleshooting.
1. sam build
Packages code and dependencies into .aws-sam/build.
2. sam deploy
Uploads artifacts and creates a CloudFormation change set.
3. CloudFormation
Creates IAM roles, Lambda, and API Gateway in dependency order.
4. Verify & logs
Copy API URL, call it with curl, and inspect CloudWatch logs for function output.
This timeline shows where to check when problems arise: build for packaging issues, deploy for permission or packaging upload problems, and CloudWatch for runtime behavior.
