Learning Objectives
Skills to practice: read templates, run the SAM CLI workflow, and deploy an API.
01
Understand serverless fundamentals
Define serverless execution, pay-per-execution, and why moving operational burden to the provider reduces maintenance. Recognize when serverless suits an application.
VERIFIED COMPETENCY MILESTONE
02
Use the SAM CLI workflow
Run sam init to scaffold, sam build to package code and dependencies, and sam deploy --guided to create the CloudFormation stack. This reproducible flow prevents missing modules at deploy time.
VERIFIED COMPETENCY MILESTONE
03
Author template.yaml entries
Write Resources with Type AWS::Serverless::Function, include Transform for SAM processing, and set Properties like Handler, Runtime, and CodeUri.
VERIFIED COMPETENCY MILESTONE
04
Deploy and test a serverless API
Use sam deploy --guided, record the API endpoint, and verify the JSON response with curl. Understand cleanup steps to remove resources after testing.
VERIFIED COMPETENCY MILESTONE
