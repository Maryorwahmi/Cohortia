Understand the handler signature and response format for API integration.
Handler pattern
A handler receives two arguments: event, which contains request data, and context, which provides runtime info. Logging the event is useful for debugging.
Misconception
Returning native Python objects without JSON-encoding the body will break API Gateway integrations. Always serialize the body to a string where required.
Try this

Add a query parameter and include it in the returned body to verify end-to-end request handling.

Example code
import json

def lambda_handler(event, context):
    """
    Sample Lambda function that returns a simple greeting.
    """
    print("Received event:", json.dumps(event))
    return {
        "statusCode": 200,
        "headers": {"Content-Type": "application/json"},
        "body": json.dumps({"message": "Hello from your Serverless API!"})
    }
This handler prints the event for CloudWatch logs, then returns a JSON body string with the greeting. Use statusCode and headers to control the HTTP response.
