Practical Objectives
Terminal commands, build artifacts, and verification steps you'll run.
Initialize a SAM project
Use sam init to scaffold a project that includes template.yaml and a sample application directory.
Mnemonic: scaffold → inspect → build
VERIFIED COMPETENCY MILESTONE
Build and package code
Run sam build to collect dependencies and create a deployable artifact under .aws-sam/build.
Mnemonic: build → package → deploy
VERIFIED COMPETENCY MILESTONE
Guided deploy and confirmation
Use sam deploy --guided to set stack name, region, and consent for role creation, then save to samconfig.toml for repeatability.
Mnemonic: guided settings → saved config
VERIFIED COMPETENCY MILESTONE
Test endpoint and cleanup
Copy the API URL from deploy output, test with curl to verify JSON, and optionally delete the CloudFormation stack when finished.
Mnemonic: test → verify → clean
VERIFIED COMPETENCY MILESTONE
