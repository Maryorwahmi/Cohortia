Definition
AWS Serverless Application Model (SAM)
A CloudFormation extension that simplifies serverless resource definitions and packaging.
Transform directive

Including Transform: AWS::Serverless-2016-10-31 is essential; it instructs CloudFormation to expand SAM shorthand into the resources required to run your application.

Automatic wiring
Declare Events for a function and SAM will create the API Gateway integration and basic IAM role, reducing boilerplate.
When to inspect generated resources
If permissions fail or you need custom roles, examine the expanded CloudFormation template to see what SAM generated and extend it as needed.
SAM workflow
SAM CLI commands transform and deploy your application; below are the conceptual steps.
Define
Write template.yaml with Transform and Resources entries.
Build
Run sam build to collect code and dependencies into build artifacts.
Deploy
Use sam deploy --guided to create or update a CloudFormation stack from the packaged template.
Remember: SAM keeps CloudFormation's benefits while reducing the surface area for common serverless patterns.
