Assessment Idea
Common Assessment Questions
Practice reasoning about template syntax and CLI flow.
Question reasoning
  1. Event for API Gateways in SAM uses Type: Api with Path and Method.
  2. If deployment reports missing modules, likely sam build was not run to package dependencies.
  3. CodeUri points to the function source that sam build packages and uploads during deploy.
Practice prompt
Open a template.yaml and find HelloWorldFunction. Identify its Type, Handler, and Events. Explain why each field is required for the deploy to create a working HTTP endpoint.
Common Mistake

Confusing event types or skipping sam build are frequent causes of failed deployments and exam traps.

Self-check: can you explain what Transform does and why the function's CodeUri matters during deploy?
