World Interaction and Collectibles
Understand Area2D, signals, instancing, and safe removal to create modular collectibles.
In this lesson

You will build a Coin.tscn using Area2D + Sprite2D + CollisionShape2D, script the collected behavior using body_entered, and spawn instances with PackedScene.instantiate().

Why it matters

Overlap detection enables pickups and triggers that do not block player movement, creating cleaner and more flexible interactions for level design.
