Module 3 › Chapter 3.2 › Key Concepts
Area2D
Detects overlaps without causing physical collisions; ideal for collectibles and triggers.
Signals
Use body_entered for physics bodies and area_entered for Area2D overlaps; emit collected before queue_free().
queue_free()
Schedule node deletion at frame end to avoid runtime crashes from immediate free().
Takeaway: Design coins as modular Area2D scenes that announce events. Use PackedScene.instantiate() to spawn them and a central manager to handle scoring and effects.
