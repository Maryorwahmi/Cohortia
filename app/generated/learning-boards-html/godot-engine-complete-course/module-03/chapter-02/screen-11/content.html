Module 3 › Chapter 3.2 › Instancing PackedScene
Spawn pattern
Export a PackedScene variable and use instantiate() to create new coin instances. Add them to the tree and set their position before the physics step runs.
Checklist
  • Ensure PackedScene is assigned in the inspector.
  • Instantiate, add_child, set position, connect collected signal.
  • Test spawn positions and signal delivery.
Code (visual)
# In a GameManager.gd
@export var coin_scene: PackedScene # Drag your Coin.tscn here in the Inspector

func _ready() -> void:
    spawn_coin(Vector2(100, 100))
    spawn_coin(Vector2(200, 150))

func spawn_coin(position: Vector2) -> void:
    if coin_scene:
        var new_coin = coin_scene.instantiate() # Create an instance of the coin scene
        get_parent().add_child(new_coin) # Add it to the current scene's root or a specific node
        new_coin.position = position
        new_coin.connect("collected", _on_coin_collected)

func _on_coin_collected() -> void:
    print("Player collected a coin!")
Editor note: use get_parent() or a dedicated collectibles parent node so your scene tree stays organized.
