Module 3 › Chapter 3.2 › Create a Coin Scene
Step-by-step
1
Create Area2D root named Coin
This root will emit signals and host the Sprite and CollisionShape.
2
Add Sprite2D for visuals
Scale small icons down so coins read at gameplay size.
3
Add CollisionShape2D
Choose CircleShape2D or RectangleShape2D and size to match the sprite.
4
Attach script and connect body_entered
Connect the signal in the Node tab and implement the callback to check for the player, emit collected, and queue_free().
Editor note: save this scene as Coin.tscn to reuse and instance later.
Concrete example
If the player moves through a coin’s area, the body_entered callback should verify the collider is the player and then queue_free the coin so it disappears by the end of the frame.
Common mistake
Connecting the signal to the wrong node or forgetting to size the CollisionShape2D causes unreliable collection events.
Pro tip
Use the Node tab to double-click body_entered and let the editor create the callback stub so your function signature matches expectations.
