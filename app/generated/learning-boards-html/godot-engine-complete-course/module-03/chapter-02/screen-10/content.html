Module 3 › Chapter 3.2 › queue_free()
Why queue_free()
queue_free() safely schedules deletion at the end of the frame, preventing crashes that can occur if you free a node while its code is still running.
Practical tip
Emit your collected signal first, then call queue_free(). This preserves expected signal delivery while avoiding unsafe immediate deletion.
Debugging steps
  1. Add print statements to the collected handler.
  2. Confirm the print appears before the coin disappears.
  3. If crashes occur, check for free() calls and replace them with queue_free().
Warning
Using free() inside physics or signal callbacks can cause hard-to-reproduce runtime errors. Prefer queue_free().
