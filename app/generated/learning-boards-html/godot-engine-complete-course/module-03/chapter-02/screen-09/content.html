Module 3 › Chapter 3.2 › Name vs Group
Name check
Example: if body.name == "Player". Fast to write but fragile. Renaming breaks logic and it doesn’t generalize to multiple players.
When acceptable
Quick prototypes or throwaway tests where you control the scene naming strictly.
Group check
Example: if body.is_in_group("player"). More robust, supports many nodes, resistant to renames, and clearer intent.
Recommendation
Use groups for production code. Add the Player node to the "player" group in the editor to enable this check.
Quick checklist
  • Add Player to group "player" via the Node tab.
  • Check is_in_group("player") inside the body_entered callback.
  • Test with multiple player-like nodes to ensure only intended nodes trigger collection.
