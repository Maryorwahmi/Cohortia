How signals work
Area2D emits body_entered when a physics body enters, area_entered when another area enters. Connect these signals to callbacks that accept the entering node as a parameter.
Best practice
Emit a custom collected signal from the coin before calling queue_free() so external systems can react to the collection.
Common mistakes & checks
  • Forgetting to connect the collected signal to the GameManager, leaving score unchanged.
  • Using body.name checks that break when node names change; use groups instead.
  • Calling free() instead of queue_free(), which can crash during iteration.
Question: When would you use area_entered instead of body_entered? Answer: When you expect another Area2D to enter, such as overlapping trigger zones.
