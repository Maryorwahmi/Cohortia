Module 3 › Chapter 3.2 › Lab Walkthrough
Lab steps
  1. Create Coin.tscn as Area2D with Sprite2D and CollisionShape2D.
  2. Attach Coin.gd and connect body_entered to the root callback.
  3. Add GameManager with score variable and a handler for collected.
  4. Place coins in editor or spawn with PackedScene.instantiate().
  5. Connect collected signals to GameManager and verify queue_free() behavior.
Key Takeaway
Test as you go: confirm prints and coin disappearance to validate both signal emission and safe deletion.
Starter code snippets
# GameManager.gd
extends Node2D

var score: int = 0

func _on_coin_collected() -> void:
    score += 1
    print("Current Score: ", score)
Test tip: If the score does not update, open the Node tab for each coin instance and confirm the collected signal is linked to GameManager._on_coin_collected.
