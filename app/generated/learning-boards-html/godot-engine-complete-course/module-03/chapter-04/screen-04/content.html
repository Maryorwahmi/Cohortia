Core Concept
Control nodes — UI building blocks
Control nodes provide anchors, margins, and automatic resize behavior. They are the recommended base for all UI.
When to use Control
Any time you need stable HUD elements that should not move with the game camera.
Common Containers
HBoxContainer, VBoxContainer, GridContainer for automatic layout.
Pitfall to avoid
Using Sprite nodes for UI which then move with the camera.
Key Takeaway

Use Control nodes for UI so layout and input are handled predictably across screen sizes.
