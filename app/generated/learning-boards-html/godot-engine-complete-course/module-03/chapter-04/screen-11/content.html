Architecture
Autoload — GameManager
Autoload provides a single authoritative source for global variables and transitions across scenes.
Key responsibilities
  • Hold global variables: score, player_health, game_paused.
  • Provide methods: add_score, take_player_damage, toggle_pause.
  • Emit signals when state changes so UI updates reactively.
GameManager example
<pre><code># GameManager.gd (autoload) extends Node var score: int = 0 var player_health: int = 5 var game_paused: bool = false func add_score(amount: int) -> void: score += amount score_updated.emit(score) func take_player_damage(amount: int) -> void: player_health -= amount player_health_updated.emit(player_health) if player_health <= 0: get_tree().change_scene_to_file("res://Scenes/GameOverScreen.tscn") func toggle_pause() -> void: game_paused = not game_paused get_tree().paused = game_paused game_paused_toggled.emit(game_paused) </code></pre>
