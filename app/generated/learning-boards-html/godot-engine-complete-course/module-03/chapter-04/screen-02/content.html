Learning Objectives
These skills use Control, CanvasLayer, pause mechanics, and Autoloads to create robust UI and persistent state.
01
Control nodes & layout
Understand Control as the base for UI and containers that manage layout automatically.
Verified Competency Milestone
02

Place UI on a CanvasLayer so it stays above the game world and scales predictably.
Verified Competency Milestone
03

Verified Competency Milestone
04
Autoload GameManager
Create a global singleton to hold score, health, and pause state and emit signals for UI updates.
