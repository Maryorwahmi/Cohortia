_unhandled_input for pause
Place this in a node that remains active and can see global input.
<pre><code>func _unhandled_input(event: InputEvent) -> void: if event.is_action_pressed("ui_cancel"): GameManager.toggle_pause() get_viewport().set_input_as_handled() </code></pre>
Explanation
  • is_action_pressed checks the named input action. Use Input Map to verify bindings.
  • toggle_pause updates GameManager.game_paused and get_tree().paused.
  • set_input_as_handled prevents the event from performing other unwanted actions.
Test
