Architecture
CanvasLayer — keep UI above the world
CanvasLayer provides a separate render layer. Use it to host HUD and overlay scenes so they won’t be occluded or transformed by the main camera.
Practical pattern
Create HUD.tscn as CanvasLayer, instance it in your main scene, then add Labels and containers inside.
Pause overlays
Make PauseMenu a CanvasLayer with a semi-transparent ColorRect to dim the game while paused.
Key Takeaway

Put HUD and overlay scenes on CanvasLayer to ensure they render independently of the game camera and world transforms.

Quick checklist
  • Create a CanvasLayer named HUD and add HBoxContainer -> ScoreLabel, HealthLabel.
  • Instance HUD.tscn in main scene instead of copying nodes into main scene.
  • Use anchors and containers for resolution independence.
Misconception
CanvasLayer handles draw order but you still manage Control anchors for scaling. Don’t rely on CanvasLayer alone to solve layout issues.
