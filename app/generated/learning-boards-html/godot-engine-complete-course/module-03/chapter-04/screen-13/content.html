Symptoms vs Fixes
UI moves with camera
Move UI into a CanvasLayer and use Control containers for layout.
Game stays paused
Ensure get_tree().paused is set false on unpause and that resume buttons call toggle_pause.
HUD not updating
Connect HUD to GameManager signals and check that signals are emitted when values change.
Quick debug tips
  • Log inside GameManager methods to confirm order of operations.
  • Temporarily use prints in signal handlers to ensure they fire once per event.
  • Test full flows: collect coin, pause/unpause, and cause game over to ensure transitions behave as expected.
