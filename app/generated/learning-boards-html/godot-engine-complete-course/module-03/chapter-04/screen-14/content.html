Module 4 › Chapter 3.4 › Key Concepts
Control Nodes
Layout-aware UI base for labels, images, and containers.
CanvasLayer
Separate render layer so HUD stays on top and unaffected by camera.
Autoload (GameManager)
Global singleton for score, health, and pause state with signals for UI updates.
Summary

Structure your UI with Control nodes on CanvasLayer and centralize state with an Autoload to make UI predictable and maintainable across scenes.
