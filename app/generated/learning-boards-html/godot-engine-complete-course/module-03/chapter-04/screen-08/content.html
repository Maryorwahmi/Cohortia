Process Flow
Pause menu implementation
Sequence: input → GameManager.toggle_pause → get_tree().paused toggled → game_paused_toggled signal → PauseMenu.visible updated.
Step 1 — Detect pause key
Use _unhandled_input to catch the pause action even when other nodes consume events.
Step 2 — Toggle pause
GameManager.toggle_pause toggles a boolean and sets get_tree().paused accordingly.
Step 3 — Show overlay
PauseMenu listens to the signal and updates visible to block input to the game.
Key Takeaway

Use a central toggle for pause and update UI through signals so pause logic and overlay remain synchronized.

Practical tips
  • Consume the pause input with get_viewport().set_input_as_handled() to avoid duplicate actions.
  • Ensure the PauseMenu resume button calls GameManager.toggle_pause.
  • Test pause while playing and during UI interactions to ensure no side effects.
Pitfall
Relying on nodes that don't receive input when paused will make unpausing impossible; centralize pause input handling.
