Definition
Label and TextureRect
Use Label to show text like "Score: 10". Use TextureRect to show images such as hearts or icons, swapping texture to reflect state.
Updating Label
Set score_label.text = "Score: " + str(GameManager.score) when the score changes or connect to a signal for updates.
Switching Texture
Change texture_rect.texture to a full or empty heart to reflect health states.
Example UI snippet
ScoreLabel: "Score: 0" — update when GameManager emits a score change. Health TextureRects in an HBoxContainer — swap textures to show damage.
Common mistake
Updating UI every frame in _process instead of responding to signals or discrete events can cause unnecessary work and make logic harder to follow.
Key Takeaway

Prefer event-driven updates for Labels and TextureRect changes. Use containers to manage layout of multiple icons.
