Module 03 › Chapter 3.3 › Integrate Enemies
Integration flow
Instance Enemy.tscn in the main scene and place them on walkable surfaces.
Tune exported properties per instance to avoid overlapping patrols and to create enemy variety.
Run the scene and observe collisions, damage, and whether defeated enemies queue_free correctly without errors.
If damage occurs continuously, implement body_exited to stop periodic damage or give the player temporary invulnerability after a hit.
Playtest tips
  • Place enemies at varying start_x values
  • Use inspector to tune speed and patrol_distance per instance
  • Verify DamageArea sizing visually in the editor
Key Takeaway

Iteration matters: instance, tune, and test so enemy behaviors feel consistent and bugs are caught early.
