Signal wiring example
func _ready() -> void:
  start_x = global_position.x
  $DamageArea.body_entered.connect(_on_DamageArea_body_entered)

func _on_DamageArea_body_entered(body: Node2D) -> void:
  if body.name == "Player":
    if body.has_method("_take_damage"):
      body._take_damage(damage_to_player)
Prefer method checks or groups to avoid hard-coded names that break when scenes are reorganized.
Best practices
  • Connect signals in code so dependencies are explicit
  • Use has_method to avoid runtime errors
  • Consider grouping nodes (e.g., add_to_group("player")) for easier checks
Key Takeaway

Treat signal handlers as entry points: validate inputs, then call centralized damage methods for consistent behavior.
