Module 03 › Chapter 3.3 › Create Enemy.tscn
Step-by-step
  1. Create a 2D scene and set root to CharacterBody2D; rename to "Enemy".
  2. Add a Sprite2D child and assign a simple icon so visuals are visible during testing.
  3. Add a CollisionShape2D to the root and match it to the sprite for floor and wall collisions.
  4. Add an Area2D named DamageArea with its own CollisionShape2D for attack reach.
  5. Attach Enemy.gd and export speed, health, patrol_distance, and damage_to_player for inspector tuning.
  6. Connect DamageArea.body_entered to a handler that verifies the body is the player and calls _take_damage on them.
Concrete example
Try speed=50, health=3, patrol_distance=100, damage_to_player=1. Instance two enemies in your main scene to observe interactions.
Key Takeaway

A clear scene assembly reduces later debugging; separate physical collision and hit detection early.

Common mistake: forgetting to connect the DamageArea signal or incorrectly naming the player node — verify names or use groups.
