Player.gd additions
# Player.gd (additions)
@export var health: int = 5

func _take_damage(amount: int) -> void:
  health -= amount
  print("Player took ", amount, " damage. Health: ", health)
  if health <= 0:
    print("Game Over!")
    get_tree().reload_current_scene()
This pattern is intentionally simple for quick testing. For more polish, trigger death animations and show a Game Over screen before reloading.
Edge cases to consider
  • Prevent multiple damage events per frame by using enter/exit or short invincibility frames
  • Save player progress before reload if needed
  • Use groups or method checks to avoid calling methods on unrelated nodes
Key Takeaway

Keep player death logic centralized and prefer scene reloads for a predictable reset while testing combat mechanics.
