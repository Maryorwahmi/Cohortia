Module 03 › Chapter 3.3 › Area2D for Combat Collision
How to use
Add an Area2D as a child and attach a CollisionShape2D. For enemy damage to player, connect DamageArea.body_entered to a handler that checks the colliding body. For player attacks, activate an Area2D during the attack animation and listen for area_entered on enemies.
Example
DamageArea.body_entered calls Player._take_damage(1) when body.name is "Player" or body.is_in_group("player").
Checklist
  • Ensure shapes are sized for intended reach
  • Connect signals in _ready or the editor
  • Validate entering body identity before applying damage
Key Takeaway

Area2D gives overlap events so you can implement precise attack windows without interfering with physics movement.
