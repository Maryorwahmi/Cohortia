Module 03 › Chapter 3.3 › Common Mistakes & Fixes
Mistake → Fix
Using physics collision for damage
Move hit detection into Area2D and use signals to apply damage only when intended.
Calling free directly
Use queue_free to schedule safe removal and avoid errors if the node is still in use.
Frame-by-frame damage
Use timers or entry/exit signals to control damage intervals instead of attacking every physics frame.
Missing validations in handlers
Check body.name, groups, or has_method before calling methods to prevent runtime errors.
Quick fixes
  • Use queues for removal
  • Validate signals and methods
  • Test with multiple enemies and attack styles
Key Takeaway

Find and fix combat mistakes by separating concerns, validating inputs, and scheduling safe node removal.
