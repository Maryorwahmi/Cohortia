Module 03 › Chapter 3.3 › Patrolling AI
Core loop
Maintain current_direction, set velocity.x = speed * current_direction, check global_position.x against start_x ± patrol_distance, invert direction when limit reached, apply gravity if airborne, and call move_and_slide.
Example values
speed = 50, patrol_distance = 100, start_x recorded on _ready. Enemy travels between start_x - 100 and start_x + 100.
Misconception
Avoid setting global_position directly each frame. Use move_and_slide so collisions are resolved and the enemy doesn't clip through environment geometry.
Visualization
Range
Start position anchors the patrol center. Boundaries become start_x ± patrol_distance so you can tune how wide the enemy roams.
Key Takeaway

Patrols are deterministic and easy to tune; store anchor positions and always use physics-aware movement calls.
