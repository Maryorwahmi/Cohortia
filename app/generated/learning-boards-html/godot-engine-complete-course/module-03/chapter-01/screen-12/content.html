Instant vs Smooth
Avoid snapping velocity.x to zero. Use move_toward for natural deceleration and better animation blending.
  • When input exists: velocity.x = direction_x * speed for immediate response.
  • When no input: velocity.x = move_toward(velocity.x, 0, speed * delta) for smooth stopping.
  • Consider reduced horizontal control in air by scaling speed when not is_on_floor.
Practical tip
Tune the third argument of move_toward to control how quickly the player slows—higher values stop faster, lower values give glide.
Snippet
if direction_x:
  velocity.x = direction_x * speed
else:
  velocity.x = move_toward(velocity.x, 0, speed * delta)
Key Takeaway

Smooth deceleration improves feel and helps animation timing; avoid abrupt stops unless the game requires them.
