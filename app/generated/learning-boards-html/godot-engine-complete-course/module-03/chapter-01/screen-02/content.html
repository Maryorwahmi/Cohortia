Learning Objectives
Skills to verify as you practice

01
Assemble CharacterBody2D player
Create a CharacterBody2D root with Sprite2D and CollisionShape2D to represent the player. This gives you a script-driven body that still collides correctly.
VERIFIED COMPETENCY MILESTONE
02
Write physics updates in the fixed loop
Use _physics_process for consistent physics behavior and to update a velocity vector. This prevents frame-rate dependent bugs and tunneling.
VERIFIED COMPETENCY MILESTONE
03
Capture input with Input singleton
Read action strengths and presses to convert player controls into velocity changes, allowing remappable controls in Project Settings.
VERIFIED COMPETENCY MILESTONE
04
Use move_and_slide for collisions
Move the CharacterBody2D with move_and_slide so the engine resolves collisions and sliding automatically, avoiding manual position tweaks.
VERIFIED COMPETENCY MILESTONE
