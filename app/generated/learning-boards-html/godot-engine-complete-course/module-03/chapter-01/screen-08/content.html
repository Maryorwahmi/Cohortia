Read mapped actions
Action strengths support keyboard and gamepad and allow remapping in Project Settings.
  • Use get_action_strength("ui_right") - get_action_strength("ui_left") for horizontal direction.
  • Use is_action_just_pressed("ui_accept") for single-tap jump triggers.
  • Keep input reads in _physics_process for consistent reaction to physics ticks.
Pro tip
Favor action names rather than hard-coded keys so players can remap controls easily and support gamepads naturally.
Input example
var direction_x = Input.get_action_strength("ui_right") - Input.get_action_strength("ui_left")
if Input.is_action_just_pressed("ui_accept") and is_on_floor():
  velocity.y = jump_velocity
if direction_x:
  velocity.x = direction_x * speed
Common mistake

Polling raw key events rather than actions makes remapping and gamepad input harder to support later.
