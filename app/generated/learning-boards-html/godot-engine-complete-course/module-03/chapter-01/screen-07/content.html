Velocity Vector2
x controls horizontal speed; y controls vertical speed and follows screen coordinates where down is positive.
  • Set velocity.x from input strengths for left/right movement.
  • Apply gravity to velocity.y every physics frame: velocity.y += gravity * delta.
  • Set velocity.y to a negative jump_velocity to move upward on jump.
Misconception
Assuming positive Y is up will invert jump and gravity behavior—use negative jump_velocity to go up.
Quick example
# conceptual snippet
var velocity = Vector2.ZERO
# apply gravity
velocity.y += gravity * delta
# jump
if Input.is_action_just_pressed("ui_accept") and is_on_floor():
  velocity.y = jump_velocity
# horizontal
velocity.x = direction_x * speed
move_and_slide()
Key Takeaway

Treat velocity as pixels-per-second; remember negative y moves the player upward.
