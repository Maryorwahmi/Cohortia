Module 3 › Chapter 3.1 › _physics_process(delta)
Fixed-rate updates for physics
Use this callback to update velocity and call movement functions so collisions are predictable.
  • Physics frames run at a fixed tick; multiply accelerations by delta for frame-rate independence.
  • is_on_floor checks are most reliable when performed in the physics loop.
  • move_and_slide should be called inside _physics_process to align movement with collision resolution.
Misconception check
Do not use _process for physics updates; its variable timing can cause missed collisions and inconsistent movement feel.
Code pattern
func _physics_process(delta: float) -> void:
  # Apply gravity and movement here
  velocity.y += gravity * delta
  handle_input()
  move_and_slide()
Pro tip

Treat _physics_process as the single source of truth for movement logic; keep visuals and animation playback in _process if needed.
