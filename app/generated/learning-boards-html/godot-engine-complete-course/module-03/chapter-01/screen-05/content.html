Module 3 › Chapter 3.1 › Scene Setup
Step-by-step
  1. Create a new 2D scene and change the root to CharacterBody2D. Rename it Player.
  2. Add Sprite2D as a child. Load a placeholder texture such as icon.svg.
  3. Add CollisionShape2D as a child. Assign RectangleShape2D or CapsuleShape2D and resize to fit the sprite.
  4. Attach a script Player.gd to the Player node and export variables for tuning.
  5. Place a StaticBody2D floor in the main scene to test collisions.
Example
Use RectangleShape2D sized to the sprite bounds; toggle shape visibility while running to check alignment.
Common Pitfalls
  • Forgetting CollisionShape2D or leaving it disabled—player will not collide.
  • Misaligned shape causing floor checks to fail or the player to get stuck on edges.
  • Using overly complex collision shapes initially; keep shapes simple.
Key Takeaway

Set up a clear player scene structure and confirm collision shape alignment before coding movement logic.
