Module 3 › Chapter 3.1 › What is CharacterBody2D?
CharacterBody2D
A node for characters that are primarily controlled by code but need collision detection.
Core properties
  • Provides a velocity Vector2 that your code updates each physics frame.
  • Offers helpers like is_on_floor to check contact points.
  • Works with move_and_slide so collisions are resolved by the engine.
Misconception
Treating it like a StaticBody2D or changing position manually defeats collision handling and causes tunneling.
Key Takeaway

Choose CharacterBody2D for precise script-driven player motion while retaining engine collision resolution.

Analogy
Think of CharacterBody2D as a car you drive manually; the physics engine provides the road and collision rules so you can't drive through walls if you steer into them while using the proper controls.
Quick contrast
RigidBody2D
Physics-driven, reacts to forces and impulses.
CharacterBody2D
Script-driven motion with engine collision helpers.
Code hint
Use a velocity Vector2 and call move_and_slide() from _physics_process to move a CharacterBody2D.
