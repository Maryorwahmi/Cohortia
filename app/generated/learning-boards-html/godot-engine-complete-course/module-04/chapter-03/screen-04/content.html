Module 4 › Chapter 4.3 › What is a Shader?
Definition
A small GPU program that controls rendering
  • Runs on the GPU and executes in parallel for many pixels.
  • Gives fine-grained control over color, texture sampling, and animation.
  • For 2D, fragment shaders are most commonly used to change how a sprite looks.
Common misconception
Shaders are not only for 3D. In 2D, fragment shaders provide powerful per-pixel control for effects like glow, tint, and dissolve.
Concrete example
A tint effect multiplies the red channel: multiplying red by 2.0 makes colors appear redder without changing the texture itself. This alters only the final pixel color returned by the fragment shader.
Why it matters
Using shaders reduces the need for multiple texture variants and enables dynamic, runtime-driven visuals controlled by code or time, improving workflow flexibility.
Key Takeaway

A shader is a compact GPU program; in 2D, fragment shaders control pixel color and are central to visual effects.
