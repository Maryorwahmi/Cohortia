Module 4 › Chapter 4.3 › Dissolve Effect
Shader
shader_type canvas_item; uniform float dissolve_amount : hint_range(0.0, 1.0) = 0.0; void fragment() { vec4 original_color = texture(TEXTURE, UV); float dissolve_pattern = UV.x; // simple left-to-right pattern if (dissolve_pattern < dissolve_amount) { discard; } COLOR = original_color; }
Replace dissolve_pattern with a noise texture sample for richer results. Use the Inspector to slide dissolve_amount from 0 to 1 and watch the sprite vanish.
Notes
discard removes the fragment from the frame. It's efficient but may change blending behavior; test with transparency and overlays.
Inspector & Script
Expose dissolve_amount as a uniform so game code or the Inspector can animate the dissolve over time.
Key Takeaway

Use a uniform threshold against a pattern and discard to implement dissolve effects; prefer noise textures for realism.
