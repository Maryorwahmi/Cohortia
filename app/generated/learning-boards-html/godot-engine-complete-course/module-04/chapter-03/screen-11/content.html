Module 4 › Chapter 4.3 › Apply ShaderMaterial
Steps
  1. Create a new Shader resource and write your shader code.
  2. Create a ShaderMaterial and assign the Shader to it.
  3. Select your Sprite2D and set its Material property to the ShaderMaterial.
  4. Expose uniforms and modify them from the Inspector or with set_shader_parameter.
Starter script pattern
extends Sprite2D var dissolve_material: ShaderMaterial func _ready(): if material is ShaderMaterial: dissolve_material = material else: print("Error: Sprite2D material is not a ShaderMaterial.") return dissolve_material.set_shader_parameter("dissolve_amount", 0.0)
Always verify the material type before calling set_shader_parameter to avoid runtime errors. Use the Inspector for quick tuning during iteration.
