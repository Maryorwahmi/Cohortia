Module 4 › Chapter 4.3 › Troubleshooting
Checklist
  • Syntax and semicolons — GLSL-like code is strict.
  • Ensure shader_type canvas_item; is present for 2D shaders.
  • Verify that material is a ShaderMaterial before setting parameters.
  • Confirm UV usage and texture import settings to avoid sampling artifacts.
Performance tips
Keep fragment() calculations simple, avoid large loops, and prefer precomputed textures for complex patterns. Profile when in doubt.
Debug approach
Start with a simple shader that returns a solid color, then add one operation at a time until you reproduce the issue.
Developer warning
Avoid infinite loops or extremely heavy per-pixel math inside fragment(); this can crash the GPU driver or freeze the scene.
