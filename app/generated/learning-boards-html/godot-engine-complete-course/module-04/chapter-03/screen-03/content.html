Practice path
Step 1 — Create Shader
Create a new Shader resource and ensure the first line is shader_type canvas_item; so Godot knows this shader targets CanvasItem nodes.
VERIFIED COMPETENCY MILESTONE
Step 2 — Attach to Material
Create a ShaderMaterial, assign the shader, and set the material on a Sprite2D to see immediate results in the editor or running scene.
VERIFIED COMPETENCY MILESTONE
Step 3 — Test with TIME
Use TIME to animate values like pulse or hue. Confirm the animation runs in the scene and is frame-rate independent.
VERIFIED COMPETENCY MILESTONE
Step 4 — Control from Script
Set shader uniforms from GDScript to create gameplay-driven visuals like dissolves or damage flashes.
VERIFIED COMPETENCY MILESTONE
