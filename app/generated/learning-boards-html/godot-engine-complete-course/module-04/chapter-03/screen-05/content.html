Module 4 › Chapter 4.3 › Vertex vs Fragment
Vertex Shader
Alters vertex positions
  • Runs per vertex, useful for mesh deformation and waving effects.
  • Good for geometry-level changes like bending or parallax meshes.
  • Less common for simple 2D sprite color effects.
Example: offset vertices with a sine function for a wave.
Fragment Shader
Computes final pixel color
  • Runs for every pixel; ideal for tints, pulses, dissolves, and sampling textures.
  • Uses UV coordinates to position effects across a sprite.
  • Can be more expensive per pixel — watch performance.
Example: blend the original texture with a target color using a time-driven factor.
Practical tip
If you only need color or texture-based changes, implement them in the fragment shader. Use vertex shaders when you must alter mesh positions or create geometry-level motion.
