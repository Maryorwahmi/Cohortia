Module 4 › Chapter 4.3 › Built-in Variables
COLOR
Final pixel color (vec4)
Set COLOR at the end of fragment() to determine what pixel is drawn. Preserve alpha when needed.
UV
Texture coordinates (vec2)
Ranges from 0.0 to 1.0 across the texture. Use UV to position gradients or sample textures reliably.
TEXTURE
Sampler2D for node's texture
Use texture(TEXTURE, UV) to read the original pixel. Correct sampling depends on UV and texture import settings.
TIME
Seconds since game start (float)
Drive animated effects. Use functions like sin(TIME) to create oscillations or pulsing blends.
Example pattern
Compute float pulse = (sin(TIME * 2.0) + 1.0) / 2.0 to get a smoothly varying value between 0 and 1 to feed into mix().
Watch UV ranges and keep per-pixel math simple to avoid performance problems.
