Module 4 › Chapter 4.3 › Red Tint Shader
Code
shader_type canvas_item; void fragment() { vec4 original_color = texture(TEXTURE, UV); // Multiply red channel to make the sprite appear redder COLOR = vec4(original_color.r * 2.0, original_color.g, original_color.b, original_color.a); }
Paste this into a new Shader resource. Create a ShaderMaterial, assign it to a Sprite2D, and observe the tint in the running scene.
Explanation
The shader performs a single texture lookup and scales the red channel. This keeps the operation inexpensive while producing a clear visual change.
Misconception
Directly editing texture files is not required. Shaders modify output at render time, keeping original assets intact.
Key Takeaway

Sample TEXTURE with UV, modify channels, and preserve alpha to produce a safe, editable tint effect.
