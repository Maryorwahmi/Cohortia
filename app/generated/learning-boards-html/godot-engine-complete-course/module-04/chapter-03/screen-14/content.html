Shader
A GPU program that controls how graphics are rendered.
Vertex Shader
Modifies vertex positions; used for mesh or geometry changes.
Fragment Shader
Runs per pixel and computes the final color for 2D effects.
Quick takeaway
When you need color and texture control per pixel in 2D, write fragment shaders and start with shader_type canvas_item;.
