Module 4 › Chapter 4.3 › Pulsing Color with TIME
Code
shader_type canvas_item; void fragment() { vec4 original_color = texture(TEXTURE, UV); float pulse = (sin(TIME * 2.0) + 1.0) / 2.0; // 0..1 vec4 target_color = vec4(0.0, 0.0, 1.0, 1.0); COLOR = mix(original_color, target_color, pulse * 0.5); }
Explanation & tips
  • Pulse uses sin(TIME) mapped to 0..1 for smooth oscillation.
  • mix() blends original texture with a target color based on pulse strength.
  • Keep pulse math cheap; avoid multiple texture reads per fragment where possible.
Misconception
TIME is continuous seconds, not frame count, so animations scale across machines; don't assume frame-based increments.
