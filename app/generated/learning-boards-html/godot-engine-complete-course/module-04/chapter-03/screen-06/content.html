Module 4 › Chapter 4.3 › shader_type canvas_item
Purpose
Declares the shader's target as 2D CanvasItem
This gives access to fragment(), COLOR, UV, TEXTURE, TIME, and other CanvasItem-specific built-ins. It also instructs the engine how to compile and apply the shader for 2D nodes.
Common mistake
Forgetting this line or using the wrong shader type prevents access to 2D built-ins and often causes the shader to fail or behave unexpectedly.
Quick example snippet
shader_type canvas_item; void fragment() { // fragment() runs per pixel and can access UV, COLOR, TIME }
Key Takeaway

Always declare shader_type canvas_item; at the top of 2D shaders to ensure correct built-in access and behavior.
