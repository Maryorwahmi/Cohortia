Dust Puff Setup
Follow these Inspector settings to create a compact, readable dust puff that plays on demand.
Core settings
One Shot: true; Amount: 20; Lifetime: 0.8; Explosiveness: 1.0; Preprocess: 0.0
Emission & Motion
Shape: Sphere radius 5; Initial Velocity 20; Gravity y=100; Angular Velocity 90–180.
Visuals
Texture: radial GradientTexture2D; ColorRamp: light grey → transparent; Scale Curve: 1.0 → 1.5 → 0.0
Testing
Call play_at_position from player script on jump/land and adjust gravity or velocity to match weight.
Starter script
extends CPUParticles2D

func _ready():
  emitting = false
  finished.connect(on_particles_finished)

func play_at_position(pos: Vector2):
  global_position = pos
  emitting = true

func on_particles_finished():
  hide()
  # or queue_free() if you want single-use
Call play_at_position(Vector2(x,y)) from the player to show the puff. If the puff looks too floaty, increase gravity or decrease initial velocity.
