Definition
Burst vs Continuous
One Shot
True: emit once. False: continuous emission.
Amount & Lifetime
Together determine how many particles are visible over time.
Preprocess
Simulate seconds before start so ambient effects are already established.
Examples
Explosion
One Shot true, Amount high, Lifetime short, Explosiveness 1.0 for a tight burst.
Rain
One Shot false, Amount and Lifetime balanced, Preprocess to show rain immediately on load.
Steam vent
One Shot false but low Amount and short Lifetime to create a thin, continuous plume.
Pro tip

For continuous ambient effects, tune Preprocess so the scene doesn't render an empty start frame while particles ramp up.
