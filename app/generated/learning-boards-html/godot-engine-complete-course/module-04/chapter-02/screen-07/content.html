Triggering an explosion
Use restart to reset particle state, set emitting true to start, and connect finished to clean up.
extends Node2D

# Assuming 'explosion_particles' is a CPUParticles2D node in this scene
func trigger_explosion(at_pos: Vector2):
  var explosion = $explosion_particles
  explosion.global_position = at_pos
  explosion.restart()         # resets internal particle timers
  explosion.emitting = true   # start emitting (One Shot should be true for a burst)

# If One Shot is true, connect the 'finished' signal to a cleanup:
func _on_explosion_particles_finished():
  $explosion_particles.queue_free()  # remove when complete
Explanation and pitfalls
  • restart() clears previous timers so repeated plays look consistent.
  • emitting toggles the live emission; for bursts set One Shot true.
  • finished signal fires when a one-shot system completes; use it to queue_free or hide.
  • Common mistake: not connecting finished and leaving one-shot nodes in the scene, wasting memory.
Check

Try calling the function rapidly. If you see partial bursts, add restart() to ensure a fresh emission each time.
