Common Controls & How to Configure Them
Button
Emits pressed; set font size and Expand for consistent sizing.
Label
Display static/dynamic text; set alignment and font overrides.
TextureRect
For backgrounds/icons; adjust expand_mode to control scaling behavior.
ProgressBar
Set value and max_value to visualize quantities like health.
LineEdit / TextEdit
Accept user input; always validate and sanitize external input when used in networks or saves.
CheckBox / OptionButton
Use for boolean options and dropdown selections in settings menus.
Key Takeaway

Match control types to tasks and configure their sizing and visuals with containers and anchors for reliable behavior.
