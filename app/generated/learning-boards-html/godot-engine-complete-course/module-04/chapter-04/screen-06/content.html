Size Flags — What they do
Decide how a container distributes its available space to children.
Expand
Asks the parent to include this child when dividing extra space.
Fill
Makes the child fully occupy the space assigned in a direction.
Shrink Center / Shrink End
Alignment options used when children are smaller than the available space.
Example — Menu buttons
In a centered VBoxContainer, enable Horizontal Expand on each button so they match widths. This keeps visual balance as the window scales.
Pro Tip
Only expand on the axis you want to stretch. Overusing Expand can make children size equally when you don't want that.
Key Takeaway

Size flags let containers produce consistent layouts without manual pixel math; use them deliberately.
