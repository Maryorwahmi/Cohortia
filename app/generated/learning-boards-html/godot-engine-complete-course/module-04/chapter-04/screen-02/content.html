Learning Objectives
Skills to practice in the lab walkthrough
Learn → Understand → Apply → Master
01
Understand the Control node
Learn the base properties—anchors, margins, size flags—and why Control is the base for UI. Knowing this prevents layout bugs when scaling windows.
VERIFIED COMPETENCY MILESTONE
02
Use container nodes
Arrange and resize children automatically with HBox, VBox, Margin, Grid, and Panel containers for responsive layouts.
VERIFIED COMPETENCY MILESTONE
03
Implement common UI elements
Configure Button, Label, TextureRect, ProgressBar, and LineEdit for menus and HUDs so they look and behave reliably.
VERIFIED COMPETENCY MILESTONE
04
Connect UI signals
Wire pressed and other signals to GDScript to make UI interactive and update game state or scenes dynamically.
VERIFIED COMPETENCY MILESTONE
