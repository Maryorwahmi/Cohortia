VBoxContainer — Menu Pattern
Center a VBox, use Separation for spacing, enable Horizontal Expand on button children for consistent widths.
Workflow
  1. Place VBox in root Control and set Layout to Center.
  2. Add Title label and Buttons as children.
  3. Set Separation and Size Flags on children.
HBoxContainer — Toolbars
Use for horizontal button rows; Vertical Expand on children ensures matching heights when needed.
Common mistake
Relying on manual offsets instead of Separation and size flags leads to inconsistent spacing when UI scales.
Key Takeaway

Use VBox for vertical menus and HBox for horizontal toolbars, and control spacing with Separation and size flags.
