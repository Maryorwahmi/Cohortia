Module 5 › Chapter 4.4 › Main Menu Lab
Step-by-step
  1. Create a new 2D Scene and change the root to Control (rename MainMenu).
  2. Set MainMenu layout to Full Rect so it covers the viewport.
  3. Add a VBoxContainer child and set its Layout to Center; set Separation to 15.
  4. Add TitleLabel and three Buttons as children; set button font sizes and Horizontal Expand.
  5. Add VersionLabel outside the VBox, set Layout to Bottom Wide and offset it up slightly.
  6. Attach script to MainMenu and connect pressed signals in _ready to functions that print, change scenes, or quit.
  7. Run and resize the window to validate responsiveness; optionally add a TextureRect background and experiment with expand_mode.
Starter script
extends Control

@onready var new_game_button = $VBoxContainer/NewGameButton
@onready var options_button = $VBoxContainer/OptionsButton
@onready var quit_button = $VBoxContainer/QuitButton
@onready var version_label = $VersionLabel

func _ready():
  new_game_button.pressed.connect(_on_new_game_button_pressed)
  options_button.pressed.connect(_on_options_button_pressed)
  quit_button.pressed.connect(_on_quit_button_pressed)
  version_label.text = "Game Version: " + ProjectSettings.get_setting("application/config/version")

func _on_new_game_button_pressed():
  print("Starting a new game!")

func _on_options_button_pressed():
  print("Opening options menu!")

func _on_quit_button_pressed():
  print("Quitting game!")
  get_tree().quit()
