Module 5 › Chapter 4.4 › Grid & Panel Containers
GridContainer — Inventories
Use Expand on slots and let the grid distribute space so cells resize consistently.
Practical example
A 4x4 inventory: each slot as a child Control with Expand horizontally and vertically will keep a uniform tile layout across resolutions.
MarginContainer & PanelContainer
MarginContainer adds padding to a single child; PanelContainer adds a background stylebox to create framed UI panels.
Best practice
Use PanelContainer to group a dialog visually and MarginContainer inside to create consistent internal padding.
