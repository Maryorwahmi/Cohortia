Control Node — Definition
The base layout and input node used by all UI elements.
Core properties
  • Position and size: derived from anchors and margins.
  • Anchors: normalized corners in parent space.
  • Margins: pixel offsets from anchors control size/padding.
  • Size flags: hints used by containers to resize children.
Common misconception
Control always draws UI. Actually, Control defines layout and input; visual rendering is provided by subclasses like TextureRect, Label or custom drawing.
Practical example — Centered Panel
Set both anchors to 0.5 and use margins to specify half-width and half-height around the center point. This centers and gives the panel a fixed size relative to the screen.
Check your understanding
  • What does anchors=(0.5,0.5) mean for the control's reference point?
  • How do margins change when anchors are full-screen versus centered?
Key Takeaway

Control organizes layout and input; learn to use anchors and margins before scripting positions.
