Anchors and Margins — Process
Steps to reason about anchor and margin changes.
Step 1 — Choose anchor mode
Decide if the control should stretch with parent (anchors 0 to 1) or stay relative to a point (anchors at center).
Step 2 — Set margins
Use margins as pixel offsets from the chosen anchors to set padding or control size.
Example
Anchors left/right=0.5 and margins left=-150, right=150 produces a 300px width centered panel.
Quick checks
  • Does the control stretch unexpectedly after resizing? Check anchors.
  • Is the control the wrong pixel size? Inspect margins after adjusting anchors.
  • Are anchors set to normalized coordinates, not pixels?
Practical Tip

Use the Layout presets in the editor to quickly switch anchor presets and then fine-tune margins.
