What to Remember
Control Node
Base class providing layout and input behavior.
Anchors & Margins
Anchors set reference points; margins provide offsets and size.
Containers
Use HBox, VBox, Grid, Margin, and Panel to compose responsive layouts.
Takeaway

Design UIs by composing containers and setting anchors and size flags, then connect signals in script to make them interactive.
