Troubleshooting Jumps and parenting issues

Quick debug steps

  1. Verify camera_node_path points to the active Camera2D.
  2. Ensure no other code moves ParallaxBackground node; use scroll_offset instead.
  3. Check mirroring values match texture widths exactly.
  4. Align update timing between camera movement and parallax update to prevent jitter.
Practical test
Remove all layers except one. Move camera slowly and inspect scroll_offset values printed to the console. If values are smooth but visuals jump, mirroring or texture scaling is the likely culprit.
Pro Tip

A minimal scene with a single tiled layer is your fastest route to diagnosing visual jumps. Add layers back one at a time after the base works.
