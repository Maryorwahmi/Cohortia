Definition mirroring for seamless repetition

Mirroring explained

Use mirroring to specify the repeat size for a ParallaxLayer. For horizontal loops, mirroring.x should equal texture width in pixels.

Checklist
  • Confirm your texture is tileable.
  • Use the original texture pixel width for mirroring.x.
  • Set mirroring.y only if you need vertical tiling.
Example scenario
Cloud strip texture
Texture width = 1024 px → set mirroring = Vector2(1024, 0) so clouds repeat horizontally.
Common error
Using scaled TextureRect width rather than original texture width produces visible seams.
Key Takeaway

Mirroring enables infinite repeating backgrounds. Use the texture's pixel width, not the node's scaled size.
