Process Flow GDScript: Camera sync

Starter script

Use this minimal pattern on a ParallaxBackground node. Assign Camera2D via the inspector or rely on viewport fallback.
extends ParallaxBackground

@export var camera_node_path: NodePath # Drag your Camera2D here in the Inspector
var camera: Camera2D

func _ready():
  if camera_node_path:
    camera = get_node(camera_node_path)
  else:
    camera = get_viewport().get_camera_2d()
  if not camera:
    print("Warning: No Camera2D found or assigned for ParallaxBackground.")

func _process(delta):
  if camera:
    scroll_offset = camera.global_position
Note: avoid moving the ParallaxBackground node itself; use scroll_offset to control visuals.
Explanation & checks
  • camera_node_path: inspector-friendly assignment helps scene reuse.
  • viewport fallback: useful in small scenes without an explicit path.
  • Use _process for visual sync to avoid physics step mismatch.
Key Takeaway

Set scroll_offset from camera global position each frame. This keeps parallax layers predictable and smooth.
