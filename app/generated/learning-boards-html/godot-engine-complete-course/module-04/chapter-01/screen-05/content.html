Definition ParallaxBackground & ParallaxLayer

Roles and parenting

  • ParallaxBackground: container that exposes scroll_offset used by children.
  • ParallaxLayer: holds textures and applies motion_scale and mirroring to create relative movement.
  • Common setup: ParallaxBackground as a child of Camera2D or updated from camera position in script.
Pitfall
Placing TextureRect directly under ParallaxBackground bypasses motion_scale. Always nest visuals under ParallaxLayer.
Architecture snapshot
Camera2D (parent)
ParallaxBackground usually attached here so it follows camera automatically.
ParallaxBackground
Exposes scroll_offset to children. Update via script if not parented to camera.
ParallaxLayer → TextureRect
Each layer contains the visual element and uses motion_scale, motion_offset, and mirroring.
Key Takeaway

Keep ParallaxBackground as the coordinator and put visuals inside ParallaxLayer so motion_scale applies correctly.
