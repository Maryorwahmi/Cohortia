Definition motion_offset and positioning

Positioning with motion_offset

Set starting positions for layers so artwork lines up and tiles read correctly when the camera moves.

Use case
Center a mountain layer while clouds tile from the left edge by tweaking motion_offset values.
Tip
Apply small offsets to reduce visual repetition when mirroring identical textures.
Quick checklist
  • Set motion_offset in editor to align artwork visually before movement.
  • Confirm motion_offset does not conflict with mirroring size.
  • Preview camera sweep to ensure no seams or sudden jumps appear.
Key Takeaway

motion_offset sets the layer's visual start point. Use it to craft initial composition and reduce tiled repetition.
