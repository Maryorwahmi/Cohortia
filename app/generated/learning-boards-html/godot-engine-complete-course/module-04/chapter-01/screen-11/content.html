Core Concept TextureRect: tiling & layout

Key properties

expand_mode = IgnoreSize
Prevents TextureRect from forcing parent size changes. Keeps artwork native.
stretch_mode = Tile
Repeats texture instead of stretching it. Required for seamless repeating backgrounds.
Pitfall
Using Scale for stretch_mode will distort tiles and break mirroring calculations.
Visual test
  • Set tileable texture and stretch_mode to Tile.
  • Set mirroring to texture width and move the camera continuously; look for seams.
  • If seams appear, re-export texture with seamless edges and re-check import repeat settings.
Key Takeaway

Prepare textures to tile, set TextureRect to Tile and IgnoreSize, and use mirroring for efficient continuous backgrounds.
