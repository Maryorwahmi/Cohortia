Process Flow Three-layer example

Scene construction steps

  1. Create 2D scene and add Camera2D.
  2. Add ParallaxBackground as a child of the Camera2D.
  3. Add three ParallaxLayer nodes with TextureRect children.
  4. Set TextureRect expand_mode = IgnoreSize and stretch_mode = Tile if repeating.
  5. Assign motion_scale: 0.1, 0.4, 0.7 and set mirroring using texture width.
Example values
Distant
motion_scale = Vector2(0.1, 0.1)
Mid-ground
motion_scale = Vector2(0.4, 0.4)
Near
motion_scale = Vector2(0.7, 0.7)
Key Takeaway

Start with three distinct layers and verify each one tiles seamlessly and moves at a perceptible, different speed.
