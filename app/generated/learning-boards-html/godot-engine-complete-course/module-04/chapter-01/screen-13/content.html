Hands-on Activity Multi-Layered Forest Parallax

Step-by-step

  1. Import three textures: sky/mountains, forest, bushes.
  2. Create 2D scene with Camera2D. Add ParallaxBackground as its child.
  3. Add three ParallaxLayer nodes; each gets a TextureRect child.
  4. Set TextureRect.expand_mode = IgnoreSize and stretch_mode = Tile.
  5. Set motion_scale: distant 0.1, mid 0.4, near 0.7; set mirroring to texture widths.
  6. Attach the camera-sync script and run the scene. Verify motion and tiling.
Checks
  • No seams when camera crosses texture width.
  • Distinct relative speeds between layers.
  • Smooth motion with camera movement and no jumps.
Key Takeaway

Follow the steps and verify mirroring and motion_scale; incremental checks prevent confusion and help debugging.
