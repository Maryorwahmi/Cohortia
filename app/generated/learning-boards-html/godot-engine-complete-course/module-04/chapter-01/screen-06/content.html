Process Flow Understanding motion_scale

How motion_scale works

  1. ParallaxBackground provides a scroll_offset based on camera position.
  2. ParallaxLayer multiplies that offset by its motion_scale Vector2.
  3. The result is applied to the layer's visuals to shift them on-screen.
Example values
Distant: Vector2(0.1, 0.1) • Middle: Vector2(0.4, 0.4) • Near: Vector2(0.7, 0.7)
Common mistake
Setting motion_scale to Vector2(1.0, 1.0) for a layer meant to appear distant will remove the parallax effect. Check values per axis.
Interactive tuning pattern
Step 1
Start with large differences: 0.1, 0.4, 0.7 and iterate.
Step 2
Move the camera slowly and observe perceived depth. Reduce gaps if layers feel disconnected.
Step 3
If vertical parallax feels odd, set Y motion to zero and use only X for horizontal games.
Key Takeaway

motion_scale is the single most important tuning parameter for believable parallax. Use per-axis values to control horizontal or vertical parallax independently.
