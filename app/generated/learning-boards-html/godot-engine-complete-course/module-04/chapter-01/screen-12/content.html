Comparison Common mistakes & performance

Mistake vs Fix

No perceived depth
motion_scale values too similar
Fix: increase difference (e.g., 0.1, 0.4, 0.7)
Abrupt texture end
mirroring not set
Fix: set mirroring to texture pixel width
Performance drop
Large textures or heavy shaders
Fix: tile small textures and profile shaders

Testing & debugging

  • Isolate layers to confirm each one's movement.
  • Move camera slowly to reveal seams or jumps.
  • Profile on target hardware and remove costly shaders if needed.
Pro Tip

Start simple: one tiled layer, verify mirroring, then add a second and third layer. Keep changes incremental for easier debugging.
