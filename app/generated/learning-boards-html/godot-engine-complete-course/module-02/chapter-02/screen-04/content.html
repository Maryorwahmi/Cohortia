If statements
Run a block only when its condition is true. Indentation defines scope in GDScript.
var current_health = 75

if current_health > 70:
  print("Player is healthy.")
elif current_health > 30:
  print("Player is wounded.")
else:
  print("Player is critically injured!")
  • Always end the condition line with a colon and indent the block beneath it.
  • Use elif to keep branches mutually exclusive; else is the fallback.
  • Incorrect indentation or missing colons cause syntax or logic errors in GDScript.
Concrete Example
Check a player's health percentage to display a message and trigger different animations or state changes.
Analogy
An if is a doorway that only opens when a condition is satisfied; elif is another exclusive doorway next in line.
Key Takeaway

Use if for single checks and elif/else to handle ordered, exclusive outcomes; keep indentation consistent.
