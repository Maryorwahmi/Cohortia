Core Concept › For loops & range()
Range examples
range(n) yields 0..n-1. Use start and step when needed.
# Iterating over a range of numbers
for i in range(5): # i will be 0, 1, 2, 3, 4
  print("Loop iteration:", i)

# Iterating over an array
var enemy_names = ["Goblin", "Orc", "Dragon"]
for name in enemy_names:
  print("Enemy:", name)

# Iterating dictionary keys
var player_stats = {"strength": 10, "dexterity": 8, "intelligence": 12}
for stat_name in player_stats:
  print(stat_name, ":", player_stats[stat_name])
Common pitfall: off-by-one
If you need 5 iterations including the end value, ensure your range arguments reflect that. Confirm whether the endpoint should be inclusive.
Example
To loop from 1 to 5 inclusive, use range(1, 6).
Key Takeaway

For known counts, prefer for with range to avoid manual counter bugs and accidental infinite loops.
