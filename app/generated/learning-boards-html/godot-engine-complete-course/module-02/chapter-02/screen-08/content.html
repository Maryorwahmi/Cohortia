Comparison › Arrays vs Dictionaries
Array iteration
Good for ordered lists like enemies or collected items.
var enemy_names = ["Goblin", "Orc", "Dragon"]
for name in enemy_names:
  print("Enemy:", name)
If you remove elements while looping, iterate a copy or collect removals first.
Dictionary iteration
Iterate keys, then index into the dictionary for values.
var player_stats = {"strength": 10, "dexterity": 8}
for stat_name in player_stats:
  print(stat_name, ":", player_stats[stat_name])
Dictionaries are for keyed data; do not rely on ordering.
Pro tip

When order matters, use arrays. When you need fast lookup by name, use dictionaries.

Common Mistake

Mutating the same collection while iterating can skip or duplicate elements.
