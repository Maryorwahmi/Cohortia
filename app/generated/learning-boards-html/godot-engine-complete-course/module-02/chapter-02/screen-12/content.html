Health state branching
Use an if/elif/else chain so one outcome is chosen and the rest are skipped.
if current_health_percentage > 75:
  print("Aggressive")
elif current_health_percentage >= 25:
  print("Cautious")
else:
  print("Fleeing")
Spawning fixed counts
Use for with range(10) to spawn ten enemies—clear and less error-prone than a while in this case.
for i in range(10):
  var enemy = enemy_scene.instance()
  enemy.position = Vector2(randf()*400, randf()*300)
  add_child(enemy)
