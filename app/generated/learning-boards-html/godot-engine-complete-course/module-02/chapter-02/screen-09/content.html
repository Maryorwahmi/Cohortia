While loop example
Repeat until a condition changes; ensure a termination step exists.
var charge_level = 0
while charge_level < 100:
  print("Charging... ", charge_level, "%")
  charge_level += 10 # Increment to eventually exit the loop
print("Charge complete!")
Safety checklist
  • Ensure a statement inside the loop makes the condition false eventually.
  • Consider maximum iteration guards or break conditions to avoid hangs.
  • Prefer non-blocking patterns in Godot for time-based behavior; avoid long tight loops in the main thread.
Warning

An infinite while loop will freeze the editor or game. Test loops carefully and include exit conditions.
