Match: pattern dispatch
Compare one expression against several patterns. Use it for enums or discrete states.
enum GameState { START, PLAYING, PAUSED, GAME_OVER }
var current_state = GameState.PLAYING

match current_state:
  GameState.START:
    print("Game is starting.")
  GameState.PLAYING:
    print("Game is currently active.")
  GameState.PAUSED:
    print("Game is paused.")
  GameState.GAME_OVER:
    print("Game over!")
  _:
    print("Unknown game state.")
When to prefer match
  • Switching on an enum or input action with many discrete values.
  • Keeping related cases visually grouped and easy to add to.
  • Including a wildcard pattern ensures a safe default path.
Pro tip
Use match to reduce nesting and improve readability for state machines and behavior dispatch.
