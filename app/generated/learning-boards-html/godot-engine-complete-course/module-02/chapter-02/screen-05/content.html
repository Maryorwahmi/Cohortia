Process Flow › If/Elif/Else Ordering
Ordered checks matter
Check the most specific or critical condition first to avoid accidental matches later.
# Bad: multiple ifs may all run
if current_health > 75:
  print("Aggressive")
if current_health >= 25 and current_health <= 75:
  print("Cautious")
if current_health < 25:
  print("Fleeing")

# Good: exclusive chain
if current_health > 75:
  print("Aggressive")
elif current_health >= 25:
  print("Cautious")
else:
  print("Fleeing")
Explanation & Pitfalls
Separate ifs evaluate independently. Use elif when checks are mutually exclusive to avoid duplicate side effects.
  • Always verify coverage: do your branches cover all inputs?
  • Use else as a catch-all for unexpected states.
  • Read branches in order to confirm only one should be true at a time.
Common Mistake

Writing multiple standalone if statements when the intent is a single exclusive outcome.
