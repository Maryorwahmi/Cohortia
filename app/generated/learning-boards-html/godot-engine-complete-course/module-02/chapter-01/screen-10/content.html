Example

Move a Node2D

Use position and delta to move smoothly.
var speed: float = 150.0

func _process(delta):
	# move to the right
	position.x += speed * delta
	print("Position:", position)
Check

Confirm the node inherits Node2D and that the Output shows the expected position values as the scene runs.

Common pitfalls
  • Accessing position on a node that is not Node2D.
  • Forgetting to multiply by delta and getting FPS-dependent motion.
  • Attempting to modify properties on a null node reference.
Safety tip

Check node existence and type before mutating properties to avoid runtime crashes.
