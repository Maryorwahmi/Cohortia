Comparison

Operators that return boolean

Equality & order
if health == 0:
  print("Player dead")
if score >= 100:
  print("Level complete")
Logical combinations
if health > 0 and not is_paused:
  process_player_input()
if has_key or is_admin:
  open_door()
Float equality pitfall

Avoid exact equality for floats. Use a small threshold comparison for safety.

Practical checks
Access guard
Check for null before accessing node methods.
if my_node != null:
  my_node.do_something()
Compound condition
Combine checks to gate actions safely.
if health > 0 and inventory.has_space():
  pick_item()
Key Takeaway

Use comparisons for branching and logical operators to express multi-condition rules. Avoid float equality; prefer thresholds.
