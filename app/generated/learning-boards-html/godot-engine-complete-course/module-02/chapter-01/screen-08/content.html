Architecture

Initialize then update

Use _ready for setup that requires the scene tree and _process(delta) for continuous updates.

func _ready():
	print("Player initialized")
	position_2d = Vector2(100, 50)

func _process(delta):
	# delta is seconds since last frame
	position.x += speed * delta
Misconception

Do not perform heavy calculations in _process without need. Prefer timers or signals for rare events.

Why delta matters
Frame-rate independence prevents faster machines from causing faster movement or slower machines from causing laggy motion.
Example: consistent motion
Multiplying speed by delta scales movement by elapsed time.
Check your code
If motion varies with FPS, you likely forgot to multiply by delta.
Key Takeaway

Initialize state in _ready, perform frame updates in _process using delta for consistent behavior across different frame rates.
