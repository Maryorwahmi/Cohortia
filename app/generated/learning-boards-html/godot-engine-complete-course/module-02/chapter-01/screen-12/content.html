Definition

Scope and null checks

Top-level vars are available to all functions in the script; locals are function-scoped.
# top-level
var my_node: Node = null

func _ready():
	my_node = get_node("SomeChild")

func do_action():
	if my_node != null:
		my_node.play()
Misconception

Assuming a node exists without checking its existence leads to crashes. Always guard calls that could hit null.

Practical checklist
  • Initialize variables with safe defaults.
  • Use top-level vars for state that multiple functions read and write.
  • Guard node access with existence checks.
  • Avoid accidental shadowing by reusing variable names across scopes.
Key Takeaway

Respect variable scope, initialize defaults, and add null checks around scene-tree interactions to keep your game robust.
