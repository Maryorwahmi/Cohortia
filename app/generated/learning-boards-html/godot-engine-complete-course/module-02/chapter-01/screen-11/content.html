Module 2 › Chapter 2.1 › Type Conversion

Convert explicitly to avoid errors

Use conversion helpers like str() to join text and numbers, and keep types consistent.

Bad example
# will raise a runtime error
var result = "Score: " + 100
Correct
var result = "Score: " + str(100)
print(result)
Tip
When debugging type errors, print the typeof() of the variable to confirm its runtime type.
Key Takeaway

Prefer explicit conversion and annotations to reduce runtime type errors when mixing values like text, numbers, and vectors.
