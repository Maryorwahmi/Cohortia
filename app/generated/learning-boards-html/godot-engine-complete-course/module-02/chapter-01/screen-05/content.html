Numeric Types
Use ints for counts and floats for fractional values like delta-based movement.
var health: int = 100
var speed: float = 150.0
var elapsed: float = 0.016
Boolean & String
Booleans control branching; Strings hold text and must be concatenated or converted explicitly.
var is_alive: bool = true
var player_name: String = "Hero"
var message: String = "Score: " + str(10)
Vector Types
Use Vector2 for 2D positions and velocities, Vector3 for 3D. They support vector math methods.
var position: Vector2 = Vector2(100, 250)
position.x += 10
var velocity: Vector2 = Vector2(1, 0) * 150
Misconception

Vectors are not simple arrays; they provide geometry helpers and operator support that simplify movement math.
