Core Concept

Declare & Initialize

Create storage with var, set a starting value, and optionally annotate the type for clarity.

Common mistakes
  • Forgetting var causes a syntax error.
  • Declaring a typed variable without initializing can leave it null until assigned.
Key Takeaway

Initialize variables immediately when possible and add a type annotation when you want stronger guarantees.

Examples & Analogy
Inferred type
var player_name = "Hero"
var health = 100
var speed = 150.0
Explicit typing
var health: int = 100
var position: Vector2 = Vector2(0, 0)
Analogy
Think of a variable as a labeled box. The type is the label telling you what kind of items go inside. Initializing puts the first item in the box so code that depends on it finds a value immediately.
