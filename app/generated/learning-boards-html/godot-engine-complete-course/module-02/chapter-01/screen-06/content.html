Process Flow

Common arithmetic patterns

Use these operators to mutate game state efficiently.
Damage example
Decrease health when hit.
# assume health is int
health -= damage_amount
print("Health:", health)
Score increment
Add points concisely.
score += 50
print("Score:", score)
Modulo for timing
Run an action every N frames.
if frame_count % 60 == 0:
  print("One second passed")
Misconception

Using = instead of == tries to assign a value. Use == for comparison or the expression will be wrong.

Visual steps
1. Read the current value
Access the variable you intend to update, e.g., health.
2. Compute the change
Use arithmetic or modulo to compute delta.
3. Apply with assignment operator
Use +=, -= for clarity and less code.
Key Takeaway

Assignment operators make state updates compact. Always confirm type behavior for division and modulo operations.
