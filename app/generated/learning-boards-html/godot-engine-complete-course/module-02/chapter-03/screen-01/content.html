What you'll master

Write reusable functions, emit and connect signals, and access nodes safely to build modular game systems.

In this lesson

Functions, signals, node paths, and a health-system activity.

Core idea

Decouple event producers and consumers with signals; encapsulate logic with functions.

Outcome

A working player health flow that updates UI and triggers game over via signals.

Visual summary

A Player emits health-change and death events. GameManager and UI connect to those signals to update state without direct coupling.

Producer
Player (emits)
Consumers
GameManager, UI
Starter code peek
extends CharacterBody2D

signal player_health_changed(new_health: int, max_health: int)

var current_health: int = 100

func take_damage(amount: int):
  current_health -= amount
  emit_signal("player_health_changed", current_health, 100)

Node Access

Quick tip
Always check for null after get_node or use @onready caching to avoid accessing nodes that aren't yet in the tree.
