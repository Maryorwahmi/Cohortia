Module 3 › Chapter 2.3 › Listening for Signals — GameManager Example
GameManager.gd — Starter
extends Node2D

@onready var player_node = $"Player"

func _ready():
  if player_node:
    player_node.player_health_changed.connect(_on_player_health_changed)
    player_node.player_died.connect(_on_player_died)

func _on_player_health_changed(new_health: int, max_health: int):
  print("GameManager: Player health updated to", new_health, "/", max_health)

func _on_player_died():
  print("GameManager: Player has died! Game Over.")
Explanation

GameManager caches the player and connects to its signals in _ready. Handlers respond to updates without changing Player internals.

Edge case
If multiple players exist, connect each player's signals to separate handlers or pass the emitting node as an argument to differentiate them.
Practical tip
Use a single manager to subscribe to many emitters for centralized game-level logic like score, lives, or level flow.
