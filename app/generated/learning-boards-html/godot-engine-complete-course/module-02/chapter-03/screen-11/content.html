Module 3 › Chapter 2.3 › Health System Activity — Wiring the Pieces
Starter steps
  1. Create Player with HealthLabel and DamageButton children.
  2. Declare signals in Player.gd and use @onready for children.
  3. Connect DamageButton pressed to a handler that calls take_damage(10).
  4. Emit player_health_changed and player_died where appropriate.
  5. In GameManager cache player and connect to its signals.
Debug checklist
  • Are @onready references non-null?
  • Are connect calls executed in _ready after nodes exist?
  • Do handlers match emitted argument counts and types?
Starter Player.gd snippet
extends CharacterBody2D

signal player_health_changed(new_health: int, max_health: int)
signal player_died

@onready var health_label = $HealthLabel
@onready var damage_button = $DamageButton

var max_health: int = 100
var current_health: int = 100:
  set(value):
    current_health = clamp(value, 0, max_health)
    health_label.text = "HP: " + str(current_health) + "/" + str(max_health)
    emit_signal("player_health_changed", current_health, max_health)
Activity result
A DamageButton click calls take_damage, Player updates label and emits signals, GameManager responds to game over.
