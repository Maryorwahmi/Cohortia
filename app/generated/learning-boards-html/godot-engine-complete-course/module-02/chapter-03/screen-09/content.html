Module 3 › Chapter 2.3 › Node Paths and get_node — Relative and Absolute
Path examples
Relative path
get_node("../Enemy")
Goes up one level then finds Enemy as a sibling.
Absolute path
get_node("/root/MainScene/Player")
Starts at the scene root; useful for guaranteed global access but fragile to scene naming changes.
@onready and $ shorthand

Example: @onready var camera = $"Camera2D" caches the child camera once ready, avoiding repeated lookups.

Null check
Always guard against null when a node may not exist: if my_node != null: my_node.do_something()
Practical tip
Prefer short, well-named paths and test them in the Scene dock whenever you reorganize nodes.
