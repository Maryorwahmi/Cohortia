Module 3 › Chapter 2.3 › Connecting Signals — Editor vs Code
Step-by-step: Editor
  1. Select the node in the Scene dock.
  2. Open the Node tab and find the signal (for example pressed).
  3. Double-click the signal and choose the receiver and method name.
  4. Godot will add a slot function on the target script and wire the connection.
When to use
Good for UI and scenes that rarely change structure.
Step-by-step: Code
# In Player.gd _ready()
damage_button.pressed.connect(_on_damage_button_pressed)

func _on_damage_button_pressed():
  take_damage(10)
When to use
Dynamic nodes, pools of objects, or conditional wiring at runtime.
Gotcha
Connect only after both emitter and receiver exist. Verify that the handler signature accepts the expected arguments.
