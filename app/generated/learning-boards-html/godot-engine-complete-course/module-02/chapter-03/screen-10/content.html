Module 3 › Chapter 2.3 › Functions vs Signals — When to Use Each
Functions (Synchronous)
  • Immediate execution and return values.
  • Best for internal logic and helpers.
  • Clear call chain for debugging.
Example

calculate_bonus(score) returns a number the caller uses to update state.

Signals (Decoupled)
  • Emit to notify unknown listeners.
  • Great for UI updates and global coordination.
  • Supports many listeners without changing the emitter.
Example

emit_signal("player_health_changed", new_health, max_health) lets multiple systems update.

Design tip
If only one well-known receiver exists and you need tight control, a function call is simpler. If multiple or unknown receivers should react, use signals.
