Code Walkthrough

This example shows defining and calling functions, including a return value.

extends Node2D

var health: int = 100
var score: int = 0

func _ready():
  print("Initial Health:", health)
  take_damage(20) # Call the function
  print("Health after damage:", health)

func take_damage(amount: int):
  health -= amount
  if health < 0:
    health = 0
  print("Player took", amount, "damage.")

func calculate_bonus(current_score: int) -> int:
  if current_score > 1000:
    return 100
  return 50
Explanation
  • define a function with func and give it a clear name and parameter list.
  • return values with -> type and return keyword when the caller needs a result.
  • call functions from lifecycle methods like _ready to run behavior at the right time.
Common mistake
Not calling a defined function or calling it with wrong argument types; check signatures and call sites.
Concrete example

take_damage(20) lowers health then clamps it. calculate_bonus returns either 100 or 50 depending on score. These are distinct responsibilities.

Key Takeaway
Prefer small functions with a single purpose; combine them to create higher-level behaviors.
