Module 3 › Chapter 2.3 › Common Errors and Debugging Patterns
Frequent problems
Misspelled signal or function
Keep a single declaration and reuse it; copy-paste names to avoid typos.
Null node references
Use @onready and guards: if my_node != null: my_node.do_something()
Mismatched signal arguments
Ensure handler signatures accept the same parameters that emit_signal provides.
Early connections
Connect in _ready or after add_child so both sides exist when wiring occurs.
Debugging steps
  1. Add prints after emits and inside handlers.
  2. Verify @onready variables are not null.
  3. Check console errors for missing functions or wrong arguments.
