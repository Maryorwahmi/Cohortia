Player.gd — signal example
extends CharacterBody2D

signal player_health_changed(new_health: int, max_health: int)
signal player_died(cause: String)

var health = 100

func take_damage(amount: int):
  health -= amount
  if health <= 0:
    emit_signal("player_died", "fell into a pit")
    queue_free()
  else:
    emit_signal("player_health_changed", health, 100)
Design notes
  • Declare signals at the top of the script for visibility.
  • Keep argument lists minimal and typed when helpful.
  • Emit only when state has changed meaningfully.
Avoid this
Emitting many signals per frame for the same state change can create noisy logic; consolidate emissions when possible.
Try this
Emit a health-changed signal only when health actually differs from the last emitted value.
