Module 3 › Chapter 2.3 › What to Remember — Part 1
Function
Named block of code you call directly; can accept parameters and return values.
Signal
Event a node emits; other nodes can connect to react without direct references.
emit_signal()
Call to announce an event and optionally pass arguments to listeners.
Summary

Use functions for direct behavior and signals to inform other systems; design minimal, typed signal arguments and guard node access with @onready or null checks.
