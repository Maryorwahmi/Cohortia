Accessing child nodes
Use the $ shorthand for direct child lookups and @onready to cache references safely.
# Example snippet
extends Node2D
@onready var my_sprite = $Sprite2D

func _ready():
  if my_sprite:
    print("Sprite2D found! Its name is: ", my_sprite.name)
    my_sprite.position.x += 50
  else:
    print("Sprite2D not found as a child of Main.")
Best practices
  • Cache references with @onready to avoid repeated lookups.
  • Use relative paths like $Visuals/Sprite2D for nested children.
  • Confirm the node exists before accessing its properties to avoid runtime errors.
Key Takeaway

Node paths are relative to the script owner. Use $ and @onready to write clearer, safer code.
