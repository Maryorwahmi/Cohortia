Process Flow
Instancing steps
1
Create/Open parent scene
Example: GameWorld with Node2D root already open.
2
Instance Child Scene
Use the chain-link icon in the Scene dock and select Player.tscn from the file system.
3
Confirm hierarchy
An instance node appears as a child; open it to inspect internal nodes.
4
Run and verify
Play the scene to confirm the instanced player's behavior and output messages.
Example
Player.tscn instanced inside GameWorld.tscn.
Key Takeaway

Instancing keeps your game modular: change the source scene and all instances update automatically.
