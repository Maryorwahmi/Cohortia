Learning Objectives — Part 2
Scripts, running scenes, and safe practices
01
Attach GDScript
Create and attach a .gd script, implement the _ready callback, and use the print function for startup messages.
Mnemonic: a script is the node's behavior file.
VERIFIED COMPETENCY MILESTONE
02
Run and Observe
Run the current scene and check the Output panel for the print function text to validate startup behavior.
Mnemonic: run to verify, inspect the Output panel for messages.
VERIFIED COMPETENCY MILESTONE
03
Use Node Paths
Access children reliably with the dollar shorthand and relative paths to avoid lookup errors in scripts.
Mnemonic: $ChildName is shorthand for get_node.
VERIFIED COMPETENCY MILESTONE
04
Avoid Common Errors
Save scenes and scripts regularly and check node paths to prevent runtime failures when running scenes.
Mnemonic: save early, save often.
VERIFIED COMPETENCY MILESTONE
