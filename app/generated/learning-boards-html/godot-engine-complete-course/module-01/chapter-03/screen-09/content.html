Process
Assemble GameWorld
1. Create GameWorld.tscn
New 2D scene → Node2D root → rename to GameWorld → Save as GameWorld.tscn
2. Instance Player and Enemy
Use Instance Child Scene in the Scene dock and select Player.tscn and Enemy.tscn
3. Inspect instances
Open the instanced node to confirm Sprite2D, CollisionShape2D, and scripts are present
4. Save and run
Save GameWorld and any modified scenes or scripts, then Play Current Scene to verify
Common mistake
Copying nodes manually instead of instancing causes maintenance problems later.
Warning

Avoid duplicating node trees; prefer instancing to preserve a single source of truth for shared objects.
