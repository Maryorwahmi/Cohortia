Attach script and use _ready
Attach a GDScript to a node and implement the _ready function to run initialization code once the node enters the scene tree.
# GameWorld.gd
extends Node2D

# Called when the node enters the scene tree for the first time.
func _ready():
  print("Hello, Godot World!")
Practical check
After saving the script, Play Current Scene and watch the Output panel for the printed message.
Key Takeaway

Use _ready for startup tasks; use print to confirm the script ran and to inspect key runtime values briefly.

Misconception check: _ready runs after children are available, so accessing child nodes inside _ready is safe.
