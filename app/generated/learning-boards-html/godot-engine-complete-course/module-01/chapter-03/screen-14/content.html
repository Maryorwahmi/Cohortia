Build main_scene and run a script
Follow these steps to practice the full loop: create main_scene, attach Main.gd, adjust a child sprite, and run to observe Output messages.
# Main.gd
extends Node2D

func _ready():
  print("The Main scene is ready!")
  var my_sprite = $Sprite2D
  if my_sprite:
    print("Sprite2D found! Its name is: ", my_sprite.name)
    my_sprite.position.x += 50
  else:
    print("Sprite2D not found as a child of Main.")

func _process(delta):
  pass
Expected Results
  • Output panel shows startup messages confirming the scene and sprite.
  • The sprite appears slightly shifted to the right when the scene runs.
  • If not, check node name and saved state before running.
