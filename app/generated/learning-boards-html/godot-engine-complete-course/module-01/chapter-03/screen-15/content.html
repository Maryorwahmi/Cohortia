Key Concepts
Three compact reminders for daily work
Node
A single-purpose building block such as Sprite2D or Camera2D.
Scene
A saved .tscn collection of nodes you can instance elsewhere.
Scene Tree
Parent-child hierarchy where transforms and context propagate downward.
Takeaway

Design small reusable scenes from appropriate node types, arrange them in a logical scene tree, and verify behavior by running the scene and checking the Output panel.
