Learning Objectives
Practical skills to compose scenes and attach simple scripts
01
Understand Nodes
Describe node types and why nodes are the basic units of composition. Knowing roles helps you choose the right node when building a scene.
Mnemonic: think of nodes as atoms that form larger molecules.
VERIFIED COMPETENCY MILESTONE
02
Compose Scenes
Build a reusable scene, save it as a .tscn, and explain why scenes make game objects modular and maintainable.
Mnemonic: scenes are reusable components you can drop into levels.
VERIFIED COMPETENCY MILESTONE
03
Use the Scene Tree
Explain parent-child transform inheritance and demonstrate how moving a parent moves children while preserving local offsets.
Mnemonic: think of parent transforms as an offset base for children.
VERIFIED COMPETENCY MILESTONE
04
Instance Scenes
Add existing .tscn files to another scene so updates propagate to all instances and reduce duplication.
Mnemonic: instancing is like placing a linked copy that updates with the source.
VERIFIED COMPETENCY MILESTONE
