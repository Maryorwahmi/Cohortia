Definition
Play Current vs Play Project
Play Current runs the open scene immediately for fast iteration. Play Project runs the main scene set in Project Settings for full-game testing.
Play Current
Quickly test the scene you're editing, like GameWorld.tscn.
Play Project
Runs the configured main scene across the whole project.
Practical tip
If prompted to choose a main scene when pressing Play Project, point to the scene you want used at startup.
Key Takeaway

Save your scenes and scripts before running and watch the Output panel for expected print messages as confirmation.
