Core Concept
Nodes: focused responsibilities
Each node provides a single role. Combine nodes to create richer behavior and structure.
Sprite2D
Renders a 2D texture; use for visuals.
Camera2D
Defines what part of the world the player sees.
CharacterBody2D
Built-in movement and collision behaviors for player characters.
Example: Player Scene
Root: CharacterBody2D • Child: Sprite2D • Child: CollisionShape2D
Analogy
Consider nodes as electronic components: a speaker plays sound, a light emits light. Wiring them together creates a device. Choose the right component to make the device work well.
Key Takeaway

Pick node types by responsibility and compose scenes from specialized nodes for predictable behavior.
