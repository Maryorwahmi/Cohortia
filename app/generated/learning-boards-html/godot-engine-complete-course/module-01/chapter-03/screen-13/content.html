Common mistakes vs fixes
Wrong node path
Fix: check the hierarchy and use $ChildName or @onready var reference to cache the node.
Forgetting to save
Fix: save scenes and scripts before running; the editor executes the saved files.
Wrong responsibility
Fix: place movement code on physics nodes and visuals on render nodes to keep structure clear.
Quick checklist
  • Confirm node names and paths in the Scene dock.
  • Use $ shorthand and @onready for safe access.
  • Save before running and watch print output for verification.
Warning

Do not copy node trees manually when instancing exists; it leads to divergent behavior and maintenance overhead.
