Definition
Scenes: saved node hierarchies

Save a group of nodes as a scene file so it can be instanced elsewhere. Scenes keep related nodes, resources, and scripts together.

Analogy
Treat a scene like a prefab: design once, reuse many times. Fix it once at the source and all instances update.
Example Scene File
# Player.tscn (simplified)
[ext_resource path="res://Player.gd" type="Script" id=1]
[node name="Player" type="CharacterBody2D"]
script = ExtResource( 1 )
[node name="Sprite2D" type="Sprite2D" parent="."]
texture = null
[node name="CollisionShape2D" type="CollisionShape2D" parent="."]
shape = null
Key Takeaway

Use scenes to package node groups; prefer instancing over manual copying to keep projects maintainable.
