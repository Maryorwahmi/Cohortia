Module 1 › Chapter 1.1 › First Project
Step-by-step
1. Download the Standard Godot build for your OS.
2. Extract and run the executable (Godot is portable).
3. In Project Manager click New Project, choose a name and path.
4. Click Create Folder, then Create & Edit to open the editor.
Tip
Keep a dedicated projects folder to avoid misplaced files and simplify backups.
Quick editor tour
Look for the Scene tree (organize nodes), FileSystem (assets), Inspector (select and edit properties), and Viewport (visual editor). These panels are where you'll assemble scenes and tune properties.
Key Takeaway

Completing the Project Manager steps gets you into the editor where you can assemble nodes, import assets, and run quick tests.
