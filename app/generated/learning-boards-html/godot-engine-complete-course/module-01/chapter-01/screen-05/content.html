Concept

Save a group of nodes as a scene file. Instance that scene into others so multiple copies share the same source and updates.

Practice example
Enemy scene
AI node (script)
AnimatedSprite
CollisionShape2D
Misconception
Instancing creates independent duplicates. In truth, instances refer to the same saved scene, allowing centralized updates.
Workflow sketch
Save as Player.tscn
1. Build Player scene. 2. Save scene file. 3. Open Level scene. 4. Instance Player.tscn where needed. 5. Edit Player to update all instances.
Key Takeaway

Use scenes as templates. Instance to reuse and keep behavior centralized for fast iteration.
