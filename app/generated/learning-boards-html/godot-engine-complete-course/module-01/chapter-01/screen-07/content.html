Module 1 › Chapter 1.1 › Workflow
Process steps
1. Design — define mechanics and scope.
2. Assets — create or import visuals, audio, and data.
3. Assemble — build scenes and organize nodes.
4. Script — add behavior with GDScript or C#.
5. Test & debug — run scenes and iterate.
6. Export — package for target platforms.
Practical example
Prototype a top-down shooter: design simple movement, import player sprite and bullet image, assemble a Player scene and Bullet scene, script shooting and collision, playtest to adjust speed, then export a web build to test in a browser.
Pro tip
Export small test builds early to identify platform-specific issues like input mappings or aspect ratios.
