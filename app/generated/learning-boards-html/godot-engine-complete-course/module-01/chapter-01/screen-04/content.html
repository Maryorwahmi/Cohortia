What is a node?

A node represents one distinct responsibility in your game. Nodes are composable and can be extended with scripts. Think of them as single-purpose building blocks that you arrange into trees.

Example
Player scene
CharacterBody2D (movement)
Sprite2D (visual)
CollisionShape2D (collision)
Common mistake
Putting all logic in one node. Split responsibilities instead.
Pro tip
Name nodes by role and keep scripts small to simplify testing and reuse.

Key Takeaway

Model game objects as small, focused nodes. Compose them into scenes to enable reuse and easier debugging.
