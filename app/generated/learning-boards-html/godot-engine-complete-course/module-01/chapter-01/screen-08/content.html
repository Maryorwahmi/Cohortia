Organizing assets
Use folders like /assets/sprites, /assets/audio, /assets/models. Keep naming consistent: player_idle.png, player_run.png. Consistent names make scripts and animation setup simpler.
Shared resources
Reference the same sprite from multiple scene instances rather than embedding separate copies.
Common mistake
Storing many unorganized asset files will slow iteration and cause missing references across scenes.
Importer behaviour
Godot watches the project folder and shows resources in the FileSystem. When you replace a source file, re-import or refresh to update references. For images, set proper import settings for filtering and compression depending on platform needs.
Key Takeaway

Treat assets as shared resources. Organize and name them consistently to simplify reuse and iteration.
