2D: Key elements
  • Sprites, TileMap, and 2D physics
  • Nodes like CharacterBody2D, Sprite2D, CollisionShape2D
  • Pixel art and orthographic camera
Example
A platformer built from TileMap and CharacterBody2D nodes with per-pixel sprite animations.
3D: Key elements
  • Meshes, materials, lights, and 3D physics
  • Nodes like CharacterBody3D, MeshInstance3D, CollisionShape3D
  • Perspective camera and lighting considerations
Example
A simple 3D exploration scene with a directional light, low-poly mesh environment, and a CharacterBody3D player.
Key Takeaway

Use the node set and assets that match the dimension of your game. The editor patterns are similar, but assets and physics behavior differ.
