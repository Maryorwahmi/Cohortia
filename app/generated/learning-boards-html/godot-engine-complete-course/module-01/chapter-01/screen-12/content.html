Module 1 › Chapter 1.1 › Test & Export
Debugging tips
  • Use prints and breakpoints to inspect runtime state.
  • Create minimal scenes to reproduce bugs quickly.
  • Log inputs and state changes to track intermittent issues.
Common pitfall
Delaying platform-specific tests until late can lead to costly rework. Export small builds early.
Export checklist
Decide target platforms, check input mapping, verify screen resolutions, profile performance, and produce a small test build to validate these settings before a final export.
Key Takeaway

Make testing and export part of regular iteration. Small exported builds reveal platform issues early and reduce later rework.
