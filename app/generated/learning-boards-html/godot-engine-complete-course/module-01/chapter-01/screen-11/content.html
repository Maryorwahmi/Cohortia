Node layout
Player.tscn
CharacterBody2D (script: movement)
├─ Sprite2D (visual)
├─ AnimationPlayer (animations)
└─ CollisionShape2D (collision)
Design note
Keep movement logic in CharacterBody2D and delegate health and UI to other nodes for clarity.
Concrete scenario
When the player collides with an enemy, the Enemy node reduces the Health node's value and emits a signal. The Health node handles death and notifies the level to play an effect. This way the Player scene doesn't need to know level-specific behavior.
Key Takeaway

Build the Player as a focused scene. Use signals to communicate with the outside world rather than embedding external logic inside the player.
