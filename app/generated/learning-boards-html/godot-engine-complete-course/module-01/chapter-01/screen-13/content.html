Why monoliths fail
Large scripts entangle concerns: changing one feature risks breaking others. They also reduce reusability and make debugging harder.
Refactor example
Move health code into a Health node that exposes damage() and emits a death signal. Have other nodes call damage() and listen for death.
Steps to refactor
  1. Identify a single responsibility to extract.
  2. Create a new node or script for it.
  3. Move logic and test independently.
  4. Wire communication using signals or method calls.
Key Takeaway

Design for separation of concerns. Small, focused nodes and scripts reduce bugs and improve reuse.
