Step-by-step: Import & Organize
  1. Create folders in res:// such as Art, Scenes, Scripts, Audio.
  2. Drag image files from your OS file explorer into the chosen folder in FileSystem.
  3. Let Godot generate .import settings automatically; do not delete .import files.
  4. Move or rename files inside Godot to keep scene references intact.
  5. After importing, assign textures in the Inspector and save your scene.
Example
Import player.png into res://Art, then drag it from FileSystem to the Sprite2D Texture slot in the Inspector.
Pitfall
Moving files outside Godot breaks scene references; always move via FileSystem or the editor UI.
Folder suggestions
  • res://Art
  • res://Scenes
  • res://Scripts
  • res://Audio
Key Takeaway

Keep a predictable folder structure and use the FileSystem dock to perform moves so scene links remain valid.
