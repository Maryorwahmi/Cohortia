Module 1 › Chapter 1.2 › Key Concepts
Scene Dock
Shows node hierarchy and parent-child transforms for scene composition.
FileSystem
Mirrors res://; import and organize assets in folders to keep projects manageable.
Inspector
Context-sensitive editor for node and resource properties; use it for rapid iteration.
One-line takeaway
Structure scenes, organize assets, and tune properties in the Inspector. These three habits make Godot projects scalable and easier to debug.
