Common Pitfalls
  • Storing everything at res:// root.
  • Moving files outside the editor and breaking references.
  • Editing project.godot by hand without understanding.
  • Assuming Inspector edits apply globally.
Best Practices
  • Create res://Art, res://Scenes, res://Scripts, res://Audio up front.
  • Perform file moves inside the FileSystem dock so Godot updates links.
  • Use Project Settings UI to change project.godot values.
  • Use resources or scripts for shared properties, and export variables for tuning.
