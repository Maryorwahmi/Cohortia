Module 1 › Chapter 1.2 › Create & Save Scene
Step-by-step
  1. Open 2D workspace and create a new scene.
  2. Add Node2D and rename it to Main.
  3. Add child → Sprite2D and select it.
  4. Import an image into res://Art via FileSystem.
  5. Drag the image from FileSystem into Sprite2D’s Texture slot in the Inspector.
  6. Position the sprite and save Scene → Save Scene As… → res://Scenes/main_scene.tscn.
Verification
Reload the saved scene to confirm textures and hierarchy persisted.
Example naming
Use descriptive names like main_scene.tscn and res://Art/player.png to keep assets discoverable.
Key Takeaway

Follow the save and folder steps every time so scenes remain reusable and references intact.
