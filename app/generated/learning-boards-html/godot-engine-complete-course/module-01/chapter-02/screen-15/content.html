Module 1 › Chapter 1.2 › Final Checklist
1. Create folders
res://Art, res://Scenes, res://Scripts, res://Audio.
2. Move inside FileSystem
Use the editor so scene references update.
3. Name nodes clearly
Main, Player, UI are descriptive and help navigation.
4. Use Inspector for tuning
Edit selected node properties and use exported variables for designers.
5. Save often
Save scenes as .tscn and scripts as .gd so work is preserved and versionable.
6. Let Godot manage imports
Adjust import options in the Import dock rather than deleting .import files.
