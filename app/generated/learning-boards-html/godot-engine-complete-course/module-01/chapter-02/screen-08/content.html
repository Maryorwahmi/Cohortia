Why Output matters
Output is the runtime log for prints, warnings, errors, and import messages. It is essential for diagnosing missing files and script errors.
Debugging workflow
  1. Run the scene and watch Output for messages.
  2. Add print statements to scripts to show values during execution.
  3. Use reported file paths or node names to select and inspect problematic objects.
  4. Fix assets or script logic, then re-run to confirm the messages clear.
Example
If Output says a texture is missing after moving files externally, move the file back into res:// via FileSystem and update the Sprite2D Texture in Inspector.
Quick checks
  • Look for stack traces and file paths in error messages.
  • Use print to confirm variable values and execution flow.
Key Takeaway

Output turns invisible issues visible. Read errors carefully and use the Inspector to locate the referenced node or resource.
