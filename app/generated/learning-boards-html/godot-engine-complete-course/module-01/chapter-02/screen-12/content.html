Module 1 › Chapter 1.2 › Asset Import
What happens on import
Godot creates import metadata files and applies default settings. These files control compression and platform-specific options.
When to edit
Use the Import dock for an asset to change settings and re-import. Avoid manual edits of .import files unless you understand the consequences.
Pitfall
Deleting .import files may force Godot to recreate them with defaults, which can change asset behavior unexpectedly.
Example workflow
Import sprite.png, select it, adjust compression in Import tab, click Reimport to apply settings across platforms.
Key Takeaway

Rely on Godot’s import pipeline and Import tab. Don’t manually remove .import metadata unless you need to reset a specific asset and know why.
