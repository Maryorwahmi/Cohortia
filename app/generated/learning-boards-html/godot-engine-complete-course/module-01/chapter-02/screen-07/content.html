What the Inspector shows
  • Node properties: Position, Scale, Rotation, Visibility.
  • Resource fields: Texture, Material, Animation settings.
  • Exported script variables become editable here for tuning.
Example
Select a Sprite2D and assign a texture from FileSystem to the Inspector’s Texture slot to see the image appear in the viewport.
Practical guidance
Use the Inspector to iterate visually. If multiple nodes need the same parameter, consider a reusable resource or script to avoid manual repetition.
Misconception
Inspector edits are not global by default; they affect the selected node or opened resource only.
Pro tip
Use exported variables in scripts to expose tunable values in the Inspector for designers to tweak.
Key Takeaway

The Inspector is your quick tuning interface. Use it frequently to iterate faster and to catch visual mistakes early.
