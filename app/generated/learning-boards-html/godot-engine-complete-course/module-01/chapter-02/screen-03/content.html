Practice steps and quick checks
Follow these steps to confirm each objective and catch common mistakes early.
Docks check
  • Select a node and confirm Inspector shows properties.
  • Look for messages in Output after running or printing.
File check
  • Find project.godot in project root — don’t delete it.
  • Confirm .tscn scene files appear where you save them.
Scene save
  • Save as main_scene.tscn in res://Scenes and reopen it to verify.
Organize assets
  • Create res://Art and move textures there; avoid storing everything at res:// root.
Competency Check
Pass when you can create a scene, assign a texture from FileSystem to Inspector, save as .tscn, and run without asset errors.
Common misconception
Imported images do not automatically attach to nodes; you must assign them to the node's Texture property in the Inspector.
