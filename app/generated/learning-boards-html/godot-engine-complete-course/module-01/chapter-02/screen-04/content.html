Quick Definition

Godot’s editor divides editing into specialized docks to keep scene structure, asset management, property editing, and runtime feedback separate but connected.

Scene Dock (Scene Tree)
Shows nodes in parent-child order; reorganize to change transform inheritance.
FileSystem
Mirror of your res:// folder and subfolders; use it to import and categorize assets.
Key Takeaway

Learn the role of each dock so you can quickly find where to add nodes, assign textures, and inspect properties.

Hierarchical example
A simple 2D scene hierarchy and the related properties you will edit in the Inspector.
Scene Tree
  • Main (Node2D)
  • Player (Sprite2D)
  • CollisionShape2D (child of Player)
Inspector Snapshot
When Player is selected, Inspector shows Position, Scale, Rotation, and Texture. Change values here to update the node immediately.
Output
Print statements and errors appear here when you run the scene. Use it to confirm resources loaded correctly or to find missing assets.
Common mistake
Editing a property you think is global. The Inspector always applies to the selected node or resource only.
Pro tip
Name your root nodes clearly (Main, UI, Level1) to keep the Scene Tree readable as projects grow.
