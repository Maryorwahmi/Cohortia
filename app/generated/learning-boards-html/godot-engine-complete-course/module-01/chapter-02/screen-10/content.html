Module 1 › Chapter 1.2 › Project Files
Primary file types
project.godot
Global project configuration. Do not delete; edit only through Project Settings unless you know the format.
.tscn (Text Scene)
Scene files defining the node structure and saved properties. Human-readable and version-control friendly.
.gd (GDScript)
Script files containing game logic attached to nodes. Edit in the Script tab.
Other resources
  • .tres — text resources for reusable objects and materials.
  • Image and audio files referenced by scenes.
  • .import files generated and managed by Godot for imported assets.
Key Takeaway

Use the editor to manage files; .tscn and .gd are text-based and suitable for collaboration under version control.
