Module 1 › Chapter 1.2 › Scene Tree
Key idea

Use parents to group and position related children so objects move and behave as a unit.

Quick example
Main (Node2D) → Player (Sprite2D) → CollisionShape2D. Move Main to reposition entire object.
Common mistake
Assuming children ignore parent transforms; reparenting can change behavior unexpectedly if you don’t check positions.
Scene Tree — visualized example
Hierarchy
  • Main (Node2D)
  • ├─ Player (Sprite2D)
  • │ └─ CollisionShape2D
  • └─ UI (CanvasLayer)
Practical steps
  1. Create Node2D root and rename to Main.
  2. Add Sprite2D as child and assign a texture in Inspector.
  3. Save scene as main_scene.tscn in res://Scenes.
Key Takeaway

Group related nodes under a parent to create reusable objects and simpler movement logic.
