Commands to know
git status   # what changed
git log --oneline   # concise history
git diff   # see unstaged changes
Run these commands daily. They give you quick insight into your current work and help avoid accidental commits of unwanted files.
Quick habit
Make commits after small, testable changes and write messages that answer what changed and why. This makes future debugging and collaboration faster.
