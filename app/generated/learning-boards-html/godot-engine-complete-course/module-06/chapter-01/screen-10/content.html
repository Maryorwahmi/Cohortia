Common remote commands
git remote add origin <repository_url>
git push -u origin main

git pull origin main
Set the upstream on initial push so future pushes can omit the remote and branch. Pulling before you begin work avoids many simple conflicts.
Team agreement
Decide whether to use a single main branch, feature branches, or pull requests. Consistency reduces accidental overwrites and merge surprises.
