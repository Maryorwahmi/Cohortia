Module 6 › Chapter 6.1 › Activity
Step-by-step
  1. Create MyFirstGitGame in Godot and add folders: Scenes, Scripts, Assets.
  2. Open terminal: cd path/to/MyFirstGitGame
  3. Run git init
  4. Create .gitignore with Godot rules and save at project root
  5. git add . and git commit -m "Initial project setup with basic structure and gitignore"
  6. Verify with git status

git status
# Expected: nothing to commit, working tree clean
