Module 6 › Chapter 6.1 › Mistakes vs Fixes
Common mistake
  • Tracking .godot or *.import files.
  • Not pulling before pushing to the remote.
  • Making large, unfocused commits.
Fix
  • Add .godot/ and *.import to .gitignore.
  • Run git pull origin main before starting work.
  • Stage specific files and commit logically grouped changes.
Warning

If .godot is tracked, consider reverting and removing those files from history or recreating the repository with a proper .gitignore to avoid persistent conflicts.
