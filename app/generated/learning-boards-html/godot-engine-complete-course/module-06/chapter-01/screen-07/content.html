Module 6 › Chapter 6.1 › Git Init
Terminal walkthrough
cd path/to/MyFirstGitGame
# create repository
git init

# create .gitignore and add rules
# stage files (only unignored files)
git add .

# commit with a descriptive message
git commit -m "Initial project setup with basic structure and gitignore"
Staging all files with git add . is convenient, but when you need precision, stage files individually. Small, focused commits make history easier to read and revert.
Checklist
  • Run git init in project root.
  • Create .gitignore before staging files.
  • Use clear commit messages for the initial setup.
