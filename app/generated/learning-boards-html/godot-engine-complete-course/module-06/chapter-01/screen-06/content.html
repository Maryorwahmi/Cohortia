What is an autoload?

An autoload is a script configured to load at game startup so its functions and state are available globally.

Why a dedicated folder?
  • Discoverability: contributors find globals quickly.
  • Low coupling: keep global state minimal and well-documented.
  • Refactor safety: grouped singletons are easier to replace or test.
Example
Utils/ global.gd # autoload for settings and state audio_manager.gd # singleton for SFX and music control # In project settings, autoload these scripts so they are available everywhere
Pro tip
Keep autoload responsibilities narrow. If a script grows large, consider splitting it and only autoload what truly needs global access.
