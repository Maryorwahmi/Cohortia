Recommended .gitignore
# Godot-specific ignores
.godot/
*.import
export_presets.cfg
*.pck
*.zip
*.translation
Place this file at the project root before running your first git add. After adding it, run git status to confirm generated files are no longer shown as untracked.
Common mistake
Committing .godot/ causes frequent, noisy merge conflicts because project settings are often user-specific. Always ignore it unless your team intentionally shares editor settings.
