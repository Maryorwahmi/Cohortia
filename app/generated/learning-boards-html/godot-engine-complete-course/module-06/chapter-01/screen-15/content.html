Module 6 › Chapter 6.1 › Quick Reminders
Be consistent
Agree on and document your folder layout so everyone follows the same conventions.
Ignore the noise
Use a .gitignore with .godot/ and *.import to keep only meaningful files in the repo.
Daily Git habits
Commit small, descriptive changes and pull regularly to reduce merge pain and keep progress visible.
Parting question

Which single habit will you adopt first: documenting the structure, adding .gitignore, or making smaller commits?
