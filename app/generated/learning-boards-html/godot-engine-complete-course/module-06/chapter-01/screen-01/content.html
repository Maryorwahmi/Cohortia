Module 6 › Chapter 6.1 › Overview

Why this chapter matters

Projects that begin organized and use version control scale. The visible example shows a tidy folder layout and Git commands you will use immediately. This reduces merge conflicts and keeps work reversible.

In this lesson
  • Design a consistent folder layout for Scenes, Scripts, and Assets.
  • Initialize Git and create a Godot .gitignore.
  • Use Git to commit, push, and pull while avoiding editor-specific files.
Coming up
  • Folder patterns and a hybrid approach.
  • Hands-on Git commands and examples.
  • Common mistakes and how to fix them.
