Module 6 › Chapter 6.1 › Staging & Commits
Step sequence
  1. Make focused changes in the editor or code.
  2. Stage specific files with git add path/to/file.
  3. Commit with git commit -m "Descriptive message".
  4. Run git status to ensure the working tree is clean.
git add Scripts/player.gd git commit -m "Add player movement and jump mechanics"
Misconception
Large commits are not inherently better. They make it hard to find when a specific change introduced a bug. Prefer small, focused commits with clear messages.
