Module 6 › Chapter 6.1 › Project Structure
Definition

A project structure groups files by role or feature to make the project navigable and maintainable over time.

Why this prevents problems
  • Faster onboarding: new team members find assets without asking.
  • Reduced accidental edits: related files are co-located.
  • Simpler automation: build or export scripts can rely on known paths.
Common misconception
A flat layout is not always simpler. For medium projects, a small, logical hierarchy scales better than a single folder with dozens of files.
Example layout
MyFirstGitGame/ Scenes/ player.tscn level1.tscn Scripts/ player.gd enemy.gd Assets/ Sprites/ player_idle.png Audio/ sfx_jump.wav Fonts/ ui_font.tres Utils/ global.gd .gitignore
Feature grouping
Group files that implement a single feature together, such as player or enemy folders.
Type grouping
Group by file type like Scenes, Scripts, and Assets for clearer navigation across the whole project.
