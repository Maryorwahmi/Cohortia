Module 6 › Chapter 6.1 › Objectives — Practice
Skills to practice
  • Initialize a repo with git init and create a meaningful first commit message.
  • Create and verify a .gitignore that includes .godot/ and *.import so team-specific files are excluded.
  • Use git status to confirm the working tree is clean after committing.
  • Push the initial branch to a remote and pull before starting new work to minimize conflicts.
Quick check
After following the steps, run git status. A clean result shows "nothing to commit, working tree clean." If you see generated .import files listed, revisit your .gitignore entries.
