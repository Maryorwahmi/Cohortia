Module 6 › Chapter 6.4 › Troubleshooting
Most common errors
Missing Templates: Use Manage Export Templates to download the correct version.
Incorrect Paths: Verify icon and resource paths in the preset to avoid missing assets.
Permissions: On Linux/macOS run chmod +x on the exported binary if it won’t run.
Web-specific issues
File protocol security: Serve HTML5 exports from a web server to avoid CORS and loading errors.
Large sizes: Prune unused features and exclude development assets with filters.
Icon packaging: macOS may need packaging into an .app bundle for distribution rules.
