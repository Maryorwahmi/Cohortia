Export settings
  • HTML File: index.html
  • Export Type: Wasm
  • Enable Pck Download Slicing when appropriate
  • Optional: Enable PWA options
Test locally
Open a terminal in the exported folder and run:
python -m http.server 8000
Then open http://localhost:8000/index.html in your browser. This avoids file:// restrictions that block resource loading.
