Module 6 › Chapter 6.4 › Desktop Export Flow
Step-by-step cards
1
Open Export
Project > Export... then Add > Windows Desktop.
2
Configure
Set executable name, icon, features, and resources mode.
3
Export
Click Export Project... to an empty folder.
4
Verify
Run the executable; on Unix-like systems set chmod +x if required.
Common pitfall
Exporting into a non-empty folder can mix old and new files. Always export to a clean folder when testing.
