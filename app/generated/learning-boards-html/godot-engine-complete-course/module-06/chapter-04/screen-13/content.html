Module 6 › Chapter 6.4 › Hands-on Checklist
Checklist
  1. Open Project > Export... and confirm templates are installed.
  2. Create Desktop preset: set executable, icon, features, resources, and filters.
  3. Export desktop build to an empty folder and run the executable; set chmod +x if needed.
  4. Create HTML5 preset: set index.html, choose Wasm, and optionally enable slicing and PWA.
  5. Export HTML5 and serve it via a local HTTP server to test in the browser.
