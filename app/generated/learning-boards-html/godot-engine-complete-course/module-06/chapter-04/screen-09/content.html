Module 6 › Chapter 6.4 › Pck Slicing & PWA
Pck Download Slicing
Split your .pck into smaller chunks so that the browser can download essential assets first and lazy-load the rest, improving initial load time for large games.
Design note
Decide which assets are critical for first-run gameplay and place them in the initial slice.
Progressive Web App
Enable manifest and service worker options to allow installability and offline support where feasible. Test service-worker behavior on an HTTP server.
Key Takeaway

Slicing improves perceived load time; PWA options add native-like installability. Both require testing on a real server.
