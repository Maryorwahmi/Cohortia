What is a .pck?

A single packed file containing scenes, scripts, textures, audio, and other project assets that the exported runtime loads at startup.

Packaging modes
  • Embed resources into a single .pck and ship with the executable (convenient).
  • Export resources as loose files for easy modding or debugging.
