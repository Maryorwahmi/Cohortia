Module 6 › Chapter 6.4 › Export Presets
Definition
A saved profile that captures all export settings for a single platform and configuration.
Example Preset
Windows Release
Executable MyAwesomeGame, .ico assigned, 3D disabled, resources embedded in .pck.
Common misconception
Presets do not include engine templates. Templates are separate binaries you must install and link in Project Settings.
Use
Standardize releases
Speed
Save time on repeat exports
Safety
Avoid configuration drift
