Module 6 › Chapter 6.4 › Export Templates
Step-by-step
  1. Open Project > Export... and click Manage Export Templates if prompted.
  2. Download and install templates that match your Godot version.
  3. In Project Settings, check Editor > Export > Templates path if required.
  4. Verify platforms appear in the Export dialog before creating presets.
Example
If you use Godot 4.x but install 3.x templates, packaging will fail; re-download the correct version.
Troubleshooting
  • Missing templates: run Manage Export Templates and install.
  • Wrong version: re-download matching templates for your editor.
  • Wrong path: set the template folder under Project Settings if automatic install failed.
