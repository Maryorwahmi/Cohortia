Module 6 › Chapter 6.4 › HTML5 Export
Output files
- index.html (or named HTML file)
- game.wasm (when exporting Wasm)
- loader.js
- game.pck
Export Type
Choose Wasm for modern builds; JavaScript is legacy.
Customization
Custom HTML Shell: Replace the wrapper to add loading UI or integrate web APIs.
Head Include: Inject meta tags, CSS, or scripts into the generated page head.
PWA: Optionally generate a manifest and service worker for installability and offline use.
