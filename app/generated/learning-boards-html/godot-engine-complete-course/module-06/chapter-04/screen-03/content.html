Practical checks
  • Confirm export templates match your editor version to avoid packaging errors.
  • Run executables after exporting to confirm resources are present and not filtered out.
  • On Linux/macOS set execute permissions for binaries when needed.
  • Serve HTML5 builds over HTTP to avoid browser security restrictions.
Verification tips
- Check icon files and platform-specific packaging paths.
- Disable unused engine features like 3D for a 2D game to reduce size.
- Use slicing for large .pck files to improve initial web load times.
