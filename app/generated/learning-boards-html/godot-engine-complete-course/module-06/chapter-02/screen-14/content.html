Module 6 › Chapter 6.2 › Key Concepts
Profiling
Measuring execution to identify where time and memory are spent.
Bottleneck
The component limiting overall performance; fix this first.
Overdraw
Pixels painted multiple times per frame; reduce translucency and stacking to improve GPU time.
Summary

Use these terms to interpret profiler output and choose remedies: profiling reveals the bottleneck, and then apply culling, batching, scripting, or loading strategies to fix it.
