What is overdraw?

When multiple layers paint the same pixels in one frame, the GPU wastes time re-rendering those pixels. Reduce translucent stacking and avoid large covers when possible.

Frustum culling: objects outside camera view are not rendered.
Occlusion culling: objects hidden behind others can be skipped with appropriate setup.
Batching: group identical materials and meshes to reduce draw calls.
Side-by-side example
Left: 1000 individual sprites each creating a draw call — high Draw time. Right: same visual using MultiMeshInstance2D — single draw call and much lower GPU time.
Pro Tip
Use texture atlases so sprites share the same texture, improving automatic batching.
Key Takeaway

Batching and culling address different costs: culling removes unnecessary pixels, batching reduces draw-call overhead.
