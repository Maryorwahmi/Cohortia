Module 6 › Chapter 6.2 › Learning Objectives
Hands-on outcomes
  • Profile an unoptimized scene, capture CPU/GPU hotspots and identify the main bottleneck.
  • Refactor a spawner to use instancing or disabled processing and measure the delta in frames per second.
  • Replace repeated get_node calls with cached references and confirm lower script time in the profiler.
  • Implement threaded loading or preloading to remove mid-game hitches during asset streaming.
Mnemonic
PROFILE → PINPOINT → PATCH → PROVE: Measure first, fix exactly, and verify with the profiler.
VERIFIED COMPETENCY MILESTONE
Demonstrate a real profiler measurement and a single targeted optimization that improves frame time for that scene.
