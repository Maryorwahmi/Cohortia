Module 6 › Chapter 6.2 › Asynchronous Loading
Why async loading

Loading large textures or meshes synchronously can pause the main loop and create visible hitches. Asynchronous loading avoids blocking and spreads work over multiple frames.

Use ResourceLoader.load_threaded_request() to request a resource on a background thread.
Poll the loader and only assign resources once they are ready.
Prefer incremental loads during a loading scene for predictable UX.
Example sequence
  1. Enter loading scene and start background load requests for large assets.
  2. Show progress while polling ResourceLoader until ready.
  3. Swap to gameplay scene once essential resources are loaded; continue background streaming for non-critical assets.
Key Takeaway

Moving heavy loads off the main thread or into loading screens removes runtime hitches and improves player experience.
