Module 6 › Chapter 6.2 › GDScript Best Practices
Key patterns
  • Cache node references in _ready or onready variables.
  • Avoid object creation in per-frame loops; reuse Vector2/Color where possible.
  • Minimize string building in critical sections.
  • Use engine built-in math and transform helpers when available.
Common Mistake

Calling get_node inside _process for frequently accessed nodes, which repeats an expensive lookup every frame.

Concrete example
<gdscript>
# Bad: repeated lookup
func _process(delta):
  var pos = get_node("Player").position
  # work with pos

# Better: cache once
onready var player = get_node("Player")
func _process(delta):
  var pos = player.position
</gdscript>
Key Takeaway

Small code changes can yield large runtime improvements when applied to hot code paths identified by profiling.
