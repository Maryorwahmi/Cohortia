Module 6 › Chapter 6.2 › Profiler Essentials
Definition

Profiling captures runtime metrics to show which systems and functions consume the most frame time or memory.

What to look for
  • High cumulative CPU time on specific functions or scripts.
  • High Draw or Render time pointing to GPU cost.
  • Large or growing memory allocations over time.
  • Spikes during loading or scene transitions indicating blocking I/O.
Example
Capture profiler while 1000 enemies spawn; inspect which function shows longest self time.
Common mistake
Optimizing without profiling, which often wastes effort on non-critical code.
Walkthrough: quick profiler session
  1. Run the scene and recreate the slow behavior.
  2. Open Debugger → Profiler and record a few seconds.
  3. Sort by Total Time and inspect top entries; note node or function names.
  4. Formulate a single fix and re-measure the same scenario.
Key Takeaway

A profiler gives the data you need to pick the right optimization. Use it to avoid guessing.
