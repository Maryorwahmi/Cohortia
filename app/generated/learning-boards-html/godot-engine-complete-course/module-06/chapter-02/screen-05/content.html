Why hierarchies matter

Each node may receive callbacks and be traversed. Many nodes, especially if active, add CPU load every frame.

Use TileMap or TextureRect to combine static sprites and reduce node count.
Flatten deep trees when a flat structure can produce the same behavior with fewer traversals.
Disable processing for off-screen objects using VisibilityNotifier nodes to pause logic.
Common Mistake

Keeping every node active "just in case" increases CPU usage and makes profiling results less clear.

Example: pausing an off-screen enemy
Attach a VisibilityNotifier2D. When the notifier reports exit, set a flag or set_process(false) on the enemy. When it enters, resume processing. This stops _process and _physics_process from running unnecessarily.
Check your understanding
Which nodes truly need per-frame logic? Consider UI, physics actors, and animated objects separately and disable the rest.
Key Takeaway

Keep the active node set minimal. Dormant nodes should not run each frame.
