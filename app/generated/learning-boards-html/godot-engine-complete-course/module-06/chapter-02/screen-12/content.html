Module 6 › Chapter 6.2 › Hands-on Lab
Lab steps
  1. Create the test scene with Spawner and Enemy.tscn and set enemy_count to 1000.
  2. Run and record baseline numbers in Monitor and Profiler while enemies spawn.
  3. Replace individual enemy sprites with a MultiMeshInstance2D and set instance transforms.
  4. Re-run the same scenario and compare Draw and CPU metrics.
  5. Optional: add VisibilityNotifier2D to other objects and measure script time improvement.
Lab hint
Ensure the MultiMeshInstance2D has a material in the inspector and that transform_format is TRANSFORM_2D for proper placement.
Starter code snippets
<gdscript># Spawner.gd (optimized snippet)
@export var enemy_texture: Texture2D
@export var enemy_count: int = 1000
@onready var multi_mesh_instance: MultiMeshInstance2D = $MultiMeshInstance2D

func _ready():
  multi_mesh_instance.multimesh = MultiMesh.new()
  multi_mesh_instance.multimesh.mesh = QuadMesh.new()
  multi_mesh_instance.multimesh.texture = enemy_texture
  multi_mesh_instance.multimesh.transform_format = MultiMesh.TRANSFORM_2D
  multi_mesh_instance.multimesh.instance_count = enemy_count
  for i in range(enemy_count):
    var t = Transform2D()
    t.origin = Vector2(randf_range(0,1024), randf_range(0,600))
    multi_mesh_instance.multimesh.set_instance_transform_2d(i, t)
</gdscript>
Key Takeaway

Measure first, refactor visuals to MultiMesh, then verify Draw and CPU improvements in the profiler.
