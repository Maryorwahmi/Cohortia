Module 6 › Chapter 6.5 › Submission Process
Step-by-step
1. Developer Account
Register and verify identity; note fees and tax setup needed for paid releases.
2. Game Information
Title, description, genre, supported languages, and age rating info.
3. Assets
Screenshots, trailer, icon, key art, and press kit elements for visibility.
4. Build Upload
Use platform tools or APIs and follow the required file formats and signing steps.
5. Review Process
Expect technical and content checks; be ready to respond and submit fixes.
6. Pricing & Release
Set price, regional availability, and launch date. Consider timed launches for visibility.
Key Takeaway

Run a full practice submission to catch packaging or asset issues before the official review. It saves days of back-and-forth.

Example Build Names
Windows: MyGame.exe + data.pck
Android: MyGame.apk
iOS: MyGame.ipa
Steam: bundle your build and supporting files as required
