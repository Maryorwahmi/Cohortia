Module 6 › Chapter 6.3 › Assertions & push_error
Definition

assert(condition, message)

Check assumptions at runtime. In debug builds, a failing assert halts execution and prints the provided message.

func _ready():
  assert(selected_item_index >= 0 and selected_item_index < item_names.size(), "Initial selected_item_index is out of bounds!")
  process_item_selection()
Definition

push_error(message)

Report non-fatal problems to the output console while allowing execution to continue. Useful for recoverable or informational errors.

When to use which
  • assert for critical invariants you expect always to hold during development.
  • push_error for recoverable issues you still want logged for investigation.
Pro tip

Write clear assertion messages that explain why the value is invalid and what the expected range or type is.
