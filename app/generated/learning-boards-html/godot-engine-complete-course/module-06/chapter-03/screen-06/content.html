Code Example
extends Node2D

@export var item_names: Array[String] = ["Sword", "Shield", "Potion"]
@export var selected_item_index: int = 3 # intentionally out of bounds

func _ready():
  print("Game started!")
  process_item_selection()
  print("Game finished!")
This snippet sets selected_item_index to 3 while there are only three items indexed 0..2. The check later prints an error but continues. Use a breakpoint at the condition to inspect values at runtime.
Guided steps
  1. Run the scene in the editor and watch the Output and Errors panels for the invalid index message.
  2. Set a breakpoint at the if condition that checks bounds.
  3. When paused, inspect item_names and selected_item_index in Variables to confirm source and value.
  4. Fix by setting a valid Inspector value or adding an assert to fail early.
Key Takeaway

Breakpoints make it easy to observe whether a variable value is set by code or by the Inspector, guiding your fix.
