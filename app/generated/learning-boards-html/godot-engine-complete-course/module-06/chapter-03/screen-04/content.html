Core Concept

Debugger & Output Console

The output panel holds logs and messages. The errors panel shows stack traces and highlights the faulty line.

What a stack trace shows
  • The exact call sequence that led to the error.
  • The script file and line where the failure occurred.
  • Context lines often show local function names and arguments.
Common mistake
Ignoring warnings because they don't crash immediately.
Key Takeaway

Use the errors panel and stack trace to find the failing file and line before making code changes.

Example Output
<Errors> Invalid get index 'position' (on base: 'nil').
   At: res://Player.gd:42: in function 'move_player'
   At: res://Main.gd:27: in function 'update_players'
How to respond
  1. Open the file and go to the reported line.
  2. Read the surrounding code and identify which variable may be null.
  3. Set a breakpoint or add a quick print to verify state before the line executes.
Check your understanding
If a stack trace shows the failure in a helper function, remember the root cause may be a bad argument passed by the caller.
