Module 6 › Chapter 6.3 › Assert Example
Code to add an assert
func _ready():
  print("Game started!")
  assert(selected_item_index >= 0 and selected_item_index < item_names.size(), "Initial selected_item_index is out of bounds!")
  process_item_selection()
  print("Game finished!")
When this assert fails in a debug run, Godot pauses and shows the message and stack trace. This directs you to the early setup problem rather than a downstream symptom. Keep asserts descriptive to speed diagnosis.
Key Takeaway

Asserts document and enforce critical invariants and produce clear diagnostics during development.
