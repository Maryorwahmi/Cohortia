Question 1: Stopped player
Best approach: set a breakpoint at the beginning of the player's process function and step through, inspecting position, velocity, and any variables that affect input handling. This gives the exact time and place the behavior changes.
Question 2: Safe HUD access
var hud = get_node_or_null("../HUD")
assert(hud != null, "HUD node is missing!")
hud.update_score(10)
This pattern prevents a later null method call and gives a clear development-time error if the HUD is missing.
