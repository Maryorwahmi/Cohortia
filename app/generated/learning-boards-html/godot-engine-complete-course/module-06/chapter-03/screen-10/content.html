Module 6 › Chapter 6.3 › Prevent Runtime Errors

Null Reference

Check nodes and resources before use. Use get_node_or_null and if checks to guard access.
var hud = get_node_or_null("../HUD")
if hud:
  hud.update_score(10)
else:
  push_error("HUD node is missing!")

Type Mismatch

Use type hints to surface incorrect assignments at edit time and document intent with types.
var health: int = 100
# Engine will warn if you assign a non-integer value when static typing is enabled

Index Out of Bounds

Check array size before indexing to avoid runtime exceptions.
if index < items.size():
  var item = items[index]
else:
  push_error("Index out of range")
Why it matters
These simple guards stop obscure crashes and make failures easier to diagnose with clear messages and stack traces.
Key Takeaway

Small checks prevent common runtime errors and reduce time spent tracking down causes.
