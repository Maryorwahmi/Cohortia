Prevent common runtime errors

Small checks catch most crashes: null checks, type hints, and bounds guards.

01
Avoid null reference errors
Use get_node_or_null and conditional checks before using a node or resource that may not exist.
02
Reduce type mismatches
Declare type hints and enable static typing to surface incompatible assignments earlier.
03
Guard array access
Check index bounds with size checks before indexing arrays or strings to avoid out-of-range errors.
04
Combine checks with logs
When a guard triggers, log or assert with a clear message so debugging points to intent, not guesswork.
