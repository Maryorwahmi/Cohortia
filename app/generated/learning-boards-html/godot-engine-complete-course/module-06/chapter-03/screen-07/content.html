What to inspect when paused

  • Expand self to view exported variables and runtime changes.
  • Check local variables and function arguments for unexpected values.
  • Examine call stack frames to see who passed the value in.
Scenario
If selected_item_index is 3 at pause, check whether any earlier code assigns it, or if the Inspector default is incorrect. That tells you whether to fix initialization or runtime logic.
Controlled experiments
  1. Pause on the condition line and change the Inspector value; resume to observe behavior.
  2. Use Step Over to evaluate the condition without entering every called function.
  3. Use Step Into when you suspect the helper contains the bug.
Try this

Set a breakpoint and predict the value of selected_item_index before you inspect. Then compare prediction to actual value to build debugging intuition.
