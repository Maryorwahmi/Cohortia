Split-screen architecture
SubViewportContainer
A UI control that displays a SubViewport's texture.
SubViewport
The actual render surface with its own Camera3D set to current.
Camera3D per SubViewport
Each camera renders an independent view inside its SubViewport.
Optimization tips
  • Reduce SubViewport resolution.
  • Lower shadow and post-processing quality in secondary views.
  • Use LOD, and disable expensive layers when possible.
Common mistake
Trying to use multiple current cameras in the main scene rather than separate SubViewports; split-screen requires isolated viewports.
Key Takeaway

Split-screen works with SubViewports per player; optimize each viewport’s resolution and quality to preserve framerate.
