Module 6 › Chapter 5.5 › What is Camera3D?
Camera3D overview
A Camera3D node converts 3D space into the 2D image players see and governs culling and clip boundaries.
Core responsibilities
  • Define viewpoint via transform (position and rotation).
  • Control Projection type and field of view.
  • Set near and far clip planes that influence rendering and artifacts.
Concrete example
Place a Camera3D at the player’s eye height, set current to true, and the world becomes visible from that point. If you move the camera, the entire scene viewpoint changes.
Common mistake
Forgetting to set current on the Camera3D or assuming multiple cameras automatically show multiple views. Use Viewports for additional simultaneous views.
Key Takeaway

A Camera3D is both a design choice for player perception and a rendering control that affects performance and visuals.
