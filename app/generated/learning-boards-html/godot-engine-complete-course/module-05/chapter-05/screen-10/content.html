Module 6 › Chapter 5.5 › Viewports & SubViewports
Pattern overview
Use SubViewport to render a separate camera view and map its texture to geometry or UI.
Concrete example
A security camera uses a SubViewport with a Camera3D rendering a small scene. That SubViewport texture is applied to a screen mesh.
Common mistake
Forgetting to set the Camera3D current inside the SubViewport results in no output. Each viewport needs its own current camera context.
Performance note
Each SubViewport may re-render the scene. Use lower resolutions, limited update rates, or simplified scene layers to reduce cost.
Key Takeaway

SubViewports let you show additional perspectives, but treat each extra render as a performance cost and optimize accordingly.
