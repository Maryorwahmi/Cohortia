Module 5 › Chapter 5.2 › GDScript Material Example
Pattern explained
  • Find your MeshInstance3D node and ensure it has a mesh.
  • Create a StandardMaterial3D and set albedo_color or albedo_texture.
  • Enable and assign normal textures and set metallic and roughness values.
  • Assign the material with set_surface_override_material, usually per surface index.
Memory note
Reuse material resources and avoid repeatedly creating heavy textures at runtime.
Code example
# Example: Programmatically assigning a material to a MeshInstance3D
extends Node3D

@onready var my_mesh_instance = $MeshInstance3D

func _ready():
  if my_mesh_instance and my_mesh_instance.mesh:
    var new_material = StandardMaterial3D.new()

    # Set base color (Albedo)
    new_material.albedo_color = Color(0.8, 0.2, 0.1)

    # Load an Albedo texture
    var albedo_texture = load("res://assets/textures/my_albedo.png")
    if albedo_texture:
      new_material.albedo_texture = albedo_texture
      albedo_texture.set_flags(Texture.FLAG_FILTER)

    # Set Metallic and Roughness
    new_material.metallic = 0.8
    new_material.roughness = 0.3

    # Load and assign a Normal Map
    var normal_map_texture = load("res://assets/textures/my_normal_map.png")
    if normal_map_texture:
      new_material.normal_enabled = true
      new_material.normal_texture = normal_map_texture
      new_material.normal_scale = 1.0

    my_mesh_instance.set_surface_override_material(0, new_material)
