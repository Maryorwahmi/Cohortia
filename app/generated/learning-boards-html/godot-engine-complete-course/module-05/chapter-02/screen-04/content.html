Why format choice matters

The exported format controls what data travels with your model: textures, PBR parameters, node hierarchy, and animation. This affects how much work you do after import.

GLTF (.gltf / .glb)
Recommended for PBR workflows. Preserves textures and material parameters reliably.
FBX
Good for animations but exporter versions can change behavior. Check scale and axis conventions.
OBJ
Geometry and UVs only. Textures must be assigned manually; not PBR-ready by default.
DAE (Collada)
Scene and animation capable but can be inconsistent across tools.
Import checklist
  • Ensure unit scale in exporter matches Godot units to avoid size mismatches.
  • Embed or export texture files alongside the model and verify they import.
  • Check normals and UV unwraps; flipped normals break lighting.
  • For FBX, verify animation baking and node transforms in a test scene.
Tip
Export a small test object first to confirm exporter settings produce the expected result in Godot.
