Module 5 › Chapter 5.2 › Importing Models into Godot
Step-by-step Import
1. Add files
Drag the model and texture images into the FileSystem dock so Godot can create imported resources.
2. Inspect Import dock
Adjust Unit Scale, toggle animations, and choose material import behavior before clicking Reimport.
3. Instance and validate
Instance the generated scene, add a Camera3D and DirectionalLight3D, and check appearance.
4. Fix missing textures
If textures didn’t import, assign them in the material resource or re-export with embedded textures.
Troubleshooting Checklist
  • Scale mismatch: adjust Unit Scale or re-export with correct units.
  • Flipped axes: rotate model or adjust export axis settings.
  • Missing textures: re-export with embedded textures or drag images into material slots.
  • Animation issues: bake transforms or export with supported animation format.
Key Takeaway
Verify import settings before heavy scene use. Small test imports save time.
