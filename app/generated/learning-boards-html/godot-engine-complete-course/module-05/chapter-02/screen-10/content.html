Normal maps

Normal maps store normal vectors per pixel to influence lighting. They are typically tangent-space maps used to add high-frequency detail cheaply.

Check
Set normal textures to linear color space in import settings and enable normal map flags when assigning.
Ambient Occlusion

AO maps darken small crevices to simulate soft shadowing where ambient light is occluded. Use AO alongside base color and roughness for depth.

Practical example
A barrel: normal map for dents, AO to darken seams where planks join, improving perceived realism.
