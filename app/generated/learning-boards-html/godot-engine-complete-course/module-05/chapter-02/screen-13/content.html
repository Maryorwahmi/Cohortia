Module 5 › Chapter 5.2 › Texture a Simple Model — Lab
Lab steps
  1. Download or prepare a GLTF model with PBR textures and add to FileSystem.
  2. Instance the model into a scene, add Camera3D and DirectionalLight3D for evaluation.
  3. Locate or create StandardMaterial3D and assign it to the MeshInstance3D.
  4. Drag Albedo, Normal, Roughness, Metallic, and AO into their slots in the Inspector.
  5. Tweak Metallic and Roughness sliders and observe changes in reflections and highlights.
  6. Adjust texture import settings for compression and appropriate resolution for performance.
Checks and validation
Confirm normal map orientation and linear color space settings for non-color maps.
Check object scale and pivot; fix in exporter or Import dock if needed.
Test on target hardware to validate memory and performance impact.
Outcome
A textured model that responds correctly to scene lighting and runs efficiently when textures are optimized.
