Recommended node patterns
  • Player: CharacterBody3D → CollisionShape3D, Camera3D, MeshInstance3D.
  • Static geometry: StaticBody3D → CollisionShape3D(s) → MeshInstance3D.
  • Interactive object: RigidBody3D → CollisionShape3D → child Area3D for triggers.
Always make collision shapes direct children of the physics node responsible for collisions so contact resolution and queries behave as expected.
Example

A pushable box uses RigidBody3D with a BoxShape3D. If you also need a pickup trigger nearby, add an Area3D as a sibling or child that only detects overlaps.

Avoid
Don't parent CollisionShape3D under MeshInstance3D unless that MeshInstance is itself a physics body; collisions are ignored otherwise.
