Basic 3D Movement & Collision

Implement consistent player motion and robust collision handling using Godot's physics nodes.

In this lesson you'll pair code with simple collision shapes so visuals stay performant and interactions predictable.
In this lesson
  • How to move a CharacterBody3D with move_and_slide()
  • Choosing CollisionShape3D resources for performance
  • When to use RigidBody3D, StaticBody3D, or Area3D
Target: reliable player movement, correct collisions, and clean triggers.
Visual Concept
Simplify collisions, focus on behavior
Player
CharacterBody3D
Direct movement via velocity and move_and_slide(). Use a CapsuleShape3D for a humanoid.
Environment
StaticBody3D + CollisionShape3D
Static collision for floors and walls. Keep geometry simple for performance.
Physics Objects
RigidBody3D
Used when objects should be fully simulated by physics forces.
Triggers
Area3D
Detect overlaps and emit signals for pickups and zones.
