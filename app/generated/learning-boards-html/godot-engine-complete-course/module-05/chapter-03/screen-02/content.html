01
Character Control
Move a CharacterBody3D using physics-safe code.

Implement move_and_slide() and gravity inside _physics_process(), so movement is frame-rate independent and collisions are consistent.

VERIFIED COMPETENCY MILESTONE
02
Collision Shapes
Define collision boundaries with CollisionShape3D.

Choose simple primitives like capsule, box, or sphere so physics remains performant while matching the visual intent closely enough for gameplay.

VERIFIED COMPETENCY MILESTONE
03
Body Types
Differentiate CharacterBody3D, RigidBody3D, StaticBody3D.

Pick the right node: CharacterBody3D for direct control, RigidBody3D for simulated physics, StaticBody3D for immovable geometry.

VERIFIED COMPETENCY MILESTONE
04
Collision Events
Detect overlaps with Area3D and slide collisions.

Use signals like body_entered or get_slide_collision() to respond to collisions, pickups, and triggers without coupling logic to visual meshes.
