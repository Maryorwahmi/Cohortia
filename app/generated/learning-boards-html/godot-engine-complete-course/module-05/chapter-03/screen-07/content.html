Module 5 › Chapter 5.3 › Body Types
CharacterBody3D
Direct control, move_and_slide()

Use for players and NPCs that need responsive, script-driven movement.

RigidBody3D
Fully simulated physics

Use for objects that should react to forces and collisions naturally.

StaticBody3D
Immovable collision

Use for level geometry and scenery that does not move but must block others.

Example: rolling barrel (RigidBody3D), floor (StaticBody3D), player (CharacterBody3D). Which do you choose for a sliding platform that players control? Consider Composite choices: moving platforms may be Kinematic-like or controlled via CharacterBody3D movement logic depending on design.
