Module 5 › Chapter 5.3 › First-Person Controller
Step-by-step
  1. 1. Add DirectionalLight3D and StaticBody3D floor with BoxShape3D.
  2. 2. Add CharacterBody3D and child CollisionShape3D with CapsuleShape3D.
  3. 3. Add Camera3D as a child and set it slightly above the capsule.
  4. 4. Attach the movement script and map input actions in Project Settings.
  5. 5. Add StaticBody3D obstacles and run the scene to test collisions and jumps.
Quick checks
  • Player should not pass through static obstacles.
  • Jump only when is_on_floor() returns true.
  • Pickups should use Area3D, not a static collision body.
Why this matters
A reliable test scene helps you iterate on feel and catch collision issues early in development.
