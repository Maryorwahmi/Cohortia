Module 5 › Chapter 5.3 › Pitfalls
Tunneling

Occurs when movement per physics frame is larger than the thickness of a collider. Use continuous collision detection or increase shape thickness to mitigate it.

Debug steps: run in slow motion, add logging with get_slide_collision_count(), or place thin debug colliders to observe misses.
Scaling issues

Avoid non-uniform scale on physics bodies and collision shapes. If you must scale, adjust the collision resource parameters or scale the parent Node3D consistently.

Quick fix
Increase collision thickness or enable continuous collision detection for very fast objects.
