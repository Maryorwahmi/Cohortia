Module 5 › Chapter 5.4 › OmniLight3D (Point Light)
How it works

OmniLight3D emits equally in all directions and uses distance-based falloff. Tune range so the effect is local rather than globally brightening the scene.

When to use
Torches, lamps, candles, or any small source where proximity matters.
Tuning tips
  • Lower range to keep illumination local.
  • Adjust Energy so it complements ambient light.
  • Enable shadows selectively only for key Omni lights.
Concrete scenario
Place an OmniLight3D above a campfire object with low range and warm color. The fire lights nearby characters while the forest beyond remains darker, preserving contrast.
Common Mistake
Adding many Omni lights with shadows enabled everywhere, causing excessive GPU cost and muddy lighting. Prefer a few shadowed sources and simpler lights elsewhere.
Key Takeaway
Use Omni lights for localized highlights; tune falloff and enable shadows only where they matter.
