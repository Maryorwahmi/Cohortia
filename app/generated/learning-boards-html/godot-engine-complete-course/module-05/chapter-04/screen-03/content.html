Module 5 › Chapter 5.4 › Learning Objectives — Practical Focus
Hands-on flow
  1. Create a small 3D scene with a ground plane and a few meshes to cast shadows.
  2. Add a WorldEnvironment and create an Environment resource for global settings.
  3. Add a DirectionalLight3D, enable shadows, rotate for sun angle, and compare days.
  4. Add Omni or Spot lights for local effects and tune falloff or cone angle.
Success criteria
  • Primary directional light defines scene mood and casts readable shadows.
  • Local lights add detail without costing excessive shadows.
  • Environment ambient and fog preserve silhouette detail and atmosphere.
