Module 5 › Chapter 5.4 › Key Concepts
Light Types
Directional, Omni, and Spot each serve distinct scene roles and should be chosen by intent.
Shadows
Shadows add depth but should be prioritized for primary lights; tune bias and modes to avoid artifacts.
WorldEnvironment
A single global node that controls sky, ambient light, fog, and glow for consistent atmosphere.
Final takeaway

Lighting choices shape both mood and performance — tune lights, shadows, and environment together and test on target hardware.
