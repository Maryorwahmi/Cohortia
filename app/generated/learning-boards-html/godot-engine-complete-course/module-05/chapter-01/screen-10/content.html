Script (readable snippet)
extends Node3D

func _ready():
    var cube = MeshInstance3D.new()
    var box_mesh = BoxMesh.new()
    cube.mesh = box_mesh
    cube.transform.origin = Vector3(0, 0.5, -3)
    add_child(cube)

    var camera = Camera3D.new()
    camera.transform.origin = Vector3(0, 2, 5)
    camera.look_at(cube.transform.origin, Vector3.UP)
    camera.current = true
    add_child(camera)

    var sun = DirectionalLight3D.new()
    sun.transform.basis = Basis.looking_at(Vector3(-1, -1, -1))
    sun.shadow_enabled = true
    add_child(sun)

    var ground = MeshInstance3D.new()
    var plane_mesh = PlaneMesh.new()
    plane_mesh.size = Vector2(10, 10)
    ground.mesh = plane_mesh
    ground.transform.origin = Vector3(0, 0, 0)
    add_child(ground)
Explanation and steps
  • Create nodes with .new() and assign node properties like mesh and transform.
  • Use transform.origin to set position; look_at points a camera at a target with Vector3.UP as the up vector.
  • Enable camera.current so the game uses that camera at runtime.
  • Create lights and enable shadows for realism, then add a large plane for the floor.
Key Takeaway

This script shows how to build a complete, visible 3D scene from code by instancing nodes, setting transforms, and adding lighting.

Practice
Change the camera position and FOV to see how perspective and framing change the scene composition.
