Module 5 › Chapter 5.1 › Node3D — the spatial root
Definition
Node3D supplies position, rotation, and scale for 3D objects and serves as a container for spatial hierarchies.
Analogy
Think of Node3D as an invisible frame you can move. Children are glued to that frame and move when the frame moves.
Common mistake
Expecting Node3D to render or adding mesh properties to it. Visuals require MeshInstance3D or similar nodes.
Example
Create a Node3D named RoomRoot, add child MeshInstance3D primitives, then translate RoomRoot to move everything in one step.
Practice + Takeaway
Create a parent Node3D and at least two child MeshInstance3D nodes. Move, rotate, and scale the parent and observe child local transforms remain relative.
Key Takeaway

Node3D organizes spatial structure; use it to group objects and apply bulk transforms without changing child local offsets.

Try this
Name the root clearly (e.g., RoomRoot) to make hierarchies easier to manage.
Pro tip
Use Node3D to move entire sets like furniture or grouped decorations in level design.
