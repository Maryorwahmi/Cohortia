Module 5 › Chapter 5.1 › Lighting performance and practical tips
Rule of thumb
Start with one DirectionalLight3D and add lights sparingly. Test performance early and often.
When to use shadows
Enable shadows only for lights that contribute meaningfully to visual clarity, like the main sun or a player's flashlight.
Optimization
Prefer baked lighting for static environments and restrict dynamic shadow casters to essential objects.
Key Takeaway

Good lighting is a balance: aim for clarity and aesthetic with the fewest shadowed lights required for the scene.
