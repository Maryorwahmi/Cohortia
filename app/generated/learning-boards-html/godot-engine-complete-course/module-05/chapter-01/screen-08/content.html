What Camera3D does
Defines the viewpoint and projection used to render the 3D scene to the player.
Important properties
  • current — when true, the camera is active for rendering
  • fov — field of view in degrees for perspective projection
  • projection — Perspective or Orthogonal
Concrete example
Place Camera3D at Vector3(0,2,5), then call look_at on the camera pointing to the object origin to frame the subject neatly. Make the camera current before running the scene.
Key Takeaway

The active Camera3D defines what the player sees. Adjust FOV and projection to achieve appropriate framing and style.

Try
Switch between Perspective and Orthogonal to observe differences in depth and scale.
Mistake
Forgetting to set camera.current = true so the game shows the intended view.
