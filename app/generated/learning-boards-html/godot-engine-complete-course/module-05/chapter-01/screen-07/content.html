Module 5 › Chapter 5.1 › Local vs Global Transforms
Local Transform
Values stored on the node and interpreted relative to the parent node's transform. Remain constant when you move the parent.
Example
Child at local Vector3(0,1,0) stays that value even if the parent moves; its global position updates accordingly.
Global Transform
The absolute position, rotation, and scale in world space after all parent transforms are applied.
Use case
Set spawn locations or move objects to exact world coordinates using global_transform or global_position.
Try
Move a parent 5 units and check child's global_position to confirm the sum of parent + local offset.
Mistake
Changing child local position expecting global to be fixed while parent moves.
Tip
When in doubt, print both local and global values to the console to see how transforms compose.
