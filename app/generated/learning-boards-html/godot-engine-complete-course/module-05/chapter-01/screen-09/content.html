Light types
  • DirectionalLight3D — sunlike, parallel rays
  • OmniLight3D — point source, radiates in all directions
  • SpotLight3D — directional cone, useful for focused highlights
Concrete example
Add a DirectionalLight3D to a room to create overall illumination and rotate it to change shadow direction.
Performance notes
Shadows are expensive. Use a few key shadowed lights and prefer baked lighting for static scenes on lower-end targets. Test early on target hardware.
Key Takeaway

Pick light types to match scene intent and be conservative with shadow-casting lights to preserve performance.

Try
Enable shadow on a DirectionalLight3D and rotate it to observe how shadows define geometry.
Mistake
Adding many dynamic shadow-casting lights without testing performance impact.
