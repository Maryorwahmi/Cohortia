What is MeshInstance3D?
A node that holds a Mesh resource and displays geometry in the 3D world.
Primitive Meshes
  • BoxMesh — cube/rectangular block
  • SphereMesh — sphere
  • PlaneMesh — flat floor or wall
Concrete use
Assign New BoxMesh to a MeshInstance3D and adjust its transform to prototype furniture or walls.
Example + Common mistake
Example: create a MeshInstance3D, assign BoxMesh, set origin to Vector3(0,0.5,-3) so the cube sits above the floor. Common mistake: expecting a MeshInstance3D to have lighting or material by default; appearance depends on Light3D and materials.
Key Takeaway

MeshInstance3D shows a Mesh resource. Use primitives to sketch levels before moving to custom models.

Try
Swap BoxMesh size to see how mesh properties change the visible geometry.
Pro tip
Keep primitives simple; they render faster and clarify composition during design.
