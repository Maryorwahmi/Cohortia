Learning Objectives
Practice-focused milestones that verify you can build and render a basic 3D scene.
Learn

01
Navigate the 3D editor
Learn viewport controls, scene tree, and Inspector usage so you can place and inspect objects precisely.
Mnemonic: viewport camera + inspector = scene control
VERIFIED COMPETENCY MILESTONE
02
Add and use MeshInstance3D
Create primitives like BoxMesh and PlaneMesh, assign them, and use them to prototype levels and objects.
Mnemonic: mesh resource = visible geometry
VERIFIED COMPETENCY MILESTONE
03
Master transforms and axes
Use position, rotation, and scale; understand Y-up axes and the difference between local and global transforms.
Mnemonic: local = relative, global = absolute
VERIFIED COMPETENCY MILESTONE
04
Configure camera and lighting
Place a Camera3D, set it current, and add a DirectionalLight3D to reveal shapes while balancing performance.
Mnemonic: camera current = scene visible
