Module 5 › Chapter 5.1 › Common mistakes and debugging tips
Quick checklist
  1. Is a Camera3D present and current?
  2. Does MeshInstance3D have a Mesh assigned?
  3. Are lights present and configured?
  4. Are transforms placing objects out of view?
  5. Are parent rotations or scales affecting children?
Practical debug
Create a minimal test: a PlaneMesh floor, a BoxMesh cube at the origin, a DirectionalLight3D, and a Camera3D set current. If this renders, add other nodes back one at a time to find the issue.
Key Takeaway

Isolate issues by building a minimal visible scene first, then reintroduce complexity to locate the problem.
