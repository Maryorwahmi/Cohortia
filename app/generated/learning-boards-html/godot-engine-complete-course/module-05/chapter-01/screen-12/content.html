Module 5 › Chapter 5.1 › Editor camera vs Camera3D nodes
Editor camera
A temporary navigation tool used only in the editor for designing and previewing scenes.
Not saved as a runtime camera.
Camera3D node
A scene node that becomes a player view when its current property is true and exposes FOV/projection settings.
Persistent and configurable for runtime behavior.
Practical tip
If you like an editor vantage, copy the transform values into a Camera3D node so it reproduces that view when the game runs.
Key Takeaway

Editor camera is temporary; configure a Camera3D for the actual player-facing view and make it current.
