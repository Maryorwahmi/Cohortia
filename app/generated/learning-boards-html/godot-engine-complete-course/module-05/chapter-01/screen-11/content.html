Module 5 › Chapter 5.1 › Build a simple 3D room
Step-by-step
  1. Add a Node3D root named RoomRoot.
  2. Create a MeshInstance3D with PlaneMesh, set size to Vector2(10,10) for floor.
  3. Add four BoxMesh MeshInstance3D and position/rotate to form walls.
  4. Add a center BoxMesh or SphereMesh as decoration.
  5. Place Camera3D at a good vantage point and call look_at to face center; set current=true.
  6. Add DirectionalLight3D, enable shadows, and rotate for pleasing shading.
Notes and checks
  • Adjust wall origins and rotations so their faces meet cleanly.
  • Confirm the camera.current property is true before running the scene.
  • Test with and without shadows to compare visual clarity and performance.
Key Takeaway

This sequence reinforces transforms, parenting, and the need for camera + light to make a readable 3D scene.
