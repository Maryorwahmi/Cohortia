Module 5 › Chapter 5.1 › Key Concepts
Node3D
Spatial root for transforms; groups objects without rendering.
MeshInstance3D
Displays a Mesh resource; use primitives for rapid prototyping.
Camera3D
Defines the player's view. Set current=true to render the scene at runtime.
Summary takeaway

Use Node3D for structure, MeshInstance3D for visuals, Camera3D for view, and Light3D carefully for illumination. Validate scenes with a minimal test to diagnose issues quickly.
