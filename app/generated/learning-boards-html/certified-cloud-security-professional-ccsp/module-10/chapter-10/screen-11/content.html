Policy as Code for Serverless Permissions
Enforcing least privilege for AWS Lambda functions.
Least Privilege

Grant only necessary permissions to serverless functions to minimize the attack surface.

Resource Specificity

Define policies that target specific buckets and objects, not broad S3 access.

Automated Enforcement

Use PaC to ensure these granular permissions are consistently applied during deployment.

Key Takeaway

Policy as Code is crucial for implementing and maintaining granular security controls like least privilege in serverless architectures.

Conceptual Policy as Code (YAML)
AWSTemplateFormatVersion: '2010-09-09'
Description: Policy as Code for Serverless Function Permissions

Resources:
  MyProcessingFunction:
    Type: AWS::Lambda::Function
    Properties:
      FunctionName: MyProcessingFunction
      Handler: index.handler
      Role: !GetAtt MyProcessingFunctionRole.Arn
      Code:
        ZipFile: |
          # Python code for Lambda function
          import json
          import os
          import boto3

          s3_client = boto3.client('s3')
          source_bucket = os.environ.get('SOURCE_BUCKET_NAME')
          processed_bucket = os.environ.get('PROCESSED_BUCKET_NAME')

          def handler(event, context):
              print(f"Processing event: {event}")
              # Logic to read from source_bucket and write to processed_bucket
              return {
                  'statusCode': 200,
                  'body': json.dumps('Processing complete!')
              }
      Runtime: python3.9
      Timeout: 30
      Environment:
        Variables:
          SOURCE_BUCKET_NAME: my-source-data-bucket-prod
          PROCESSED_BUCKET_NAME: my-processed-data-bucket-prod

  MyProcessingFunctionRole:
    Type: AWS::IAM::Role
    Properties:
      AssumeRolePolicyDocument:
        Version: '2012-10-17'
        Statement:
          - Effect: Allow
            Principal:
              Service: lambda.amazonaws.com
            Action: sts:AssumeRole
      ManagedPolicyArns:
        - arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole # Allows logging to CloudWatch
      Policies:
        - PolicyName: IamRolePolicy
          PolicyDocument:
            Version: '2012-10-17'
            Statement:
              # 1. Read-only access to my-source-data-bucket-prod
              - Effect: Allow
                Action:
                  - s3:GetObject
                Resource: arn:aws:s3:::my-source-data-bucket-prod/*
              # 2. Write access to my-processed-data-bucket-prod
              - Effect: Allow
                Action:
                  - s3:PutObject
                Resource: arn:aws:s3:::my-processed-data-bucket-prod/*
              # 3. No other S3 access is implicitly denied by default
