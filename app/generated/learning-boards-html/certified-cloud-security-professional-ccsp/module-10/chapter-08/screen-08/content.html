Due Diligence Process

Phase 2: Advanced Security Assessment

Penetration tests, architecture, and shared responsibility

03

Penetration Test Reports

For high-risk vendors, request redacted penetration test summaries. These reports offer insights into the vendor's proactive security testing and vulnerability management processes, demonstrating their commitment to finding and fixing flaws.

  • Reveals vulnerability management maturity.
  • Provides evidence of active security testing.
  • Focus on summaries, not full reports.
04

Security Architecture Review

For critical services, review the vendor's security architecture. This involves understanding their design principles, control implementation, and how it aligns with your organization's security requirements and risk tolerance.

  • Aligns with organizational requirements.
  • Examines control design and implementation.
  • Crucial for understanding underlying security.
05

Shared Responsibility Model

Clarify the exact division of security responsibilities between your organization and the vendor. Misunderstandings here are a common source of security gaps, making explicit definition vital for clear accountability.

  • Define 'security of the cloud' vs. 'in the cloud'.
  • Prevents critical security gaps.
  • Ensures clear accountability.
Key Takeaway

Beyond basic checks, advanced due diligence includes reviewing penetration tests, security architecture, and clearly defining shared responsibilities.
