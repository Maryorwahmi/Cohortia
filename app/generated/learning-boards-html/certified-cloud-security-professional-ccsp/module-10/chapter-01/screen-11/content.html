Core Model

The Shared Responsibility Model

Delineating security duties between customer and CSP

Cloud Service Provider (CSP)

  • Security *of* the cloud: Physical infrastructure, network, virtualization layer.
  • Ensures the cloud environment itself is secure and operational.
  • Examples: Physical security, host OS, network hardware, hypervisor.
CSP Responsibility

Securing the underlying infrastructure that supports cloud services.

Cloud Customer

  • Security *in* the cloud: Data, applications, operating systems, network configuration, IAM.
  • Responsible for configuring and managing security within their cloud usage.
  • Examples: Data encryption, application security, user access, network firewalls.
Customer Responsibility

Securing their own data and applications deployed within the cloud environment.

Key Takeaway

Understanding the shared responsibility model is crucial for identifying and addressing security gaps, ensuring a robust cloud security posture.
