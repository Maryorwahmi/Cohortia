Cloud Security Alliance (CSA) Cloud Controls Matrix (CCM)

A cloud-specific framework for security control objectives.

What is CCM?

The CSA CCM is a comprehensive framework providing 197 control objectives across 17 domains, specifically designed for cloud security. It helps both cloud customers and providers assess and communicate security posture.

  • •
    Maps to NIST, ISO 27001, PCI DSS, HIPAA.
  • •
    Facilitates due diligence for CSP selection.
  • •
    Used with CSA STAR program for public registry.

Key Takeaway

The CSA CCM is a vital, cloud-specific framework for assessing CSP security, offering a standardized approach and mapping to global regulations.
