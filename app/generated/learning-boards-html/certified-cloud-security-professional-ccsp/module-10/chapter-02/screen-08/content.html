Implementing, Assessing, Authorizing, and Monitoring

Executing and maintaining security controls in the cloud.

4

Implement

Put the selected security controls into practice. This involves configuring systems, deploying tools, and establishing operational procedures in the cloud environment.

Example: Deploying a Web Application Firewall (WAF) and configuring cloud IAM policies.
5

Assess

Determine if controls are implemented correctly, operating as intended, and producing the desired security outcome. This includes security testing and verification.

Example: Conducting vulnerability scans on cloud instances and reviewing audit logs.
6

Authorize

Make a risk-based decision to authorize the system to operate. This formal acceptance of residual risk is typically granted by a senior organizational official.

Example: Granting an Authorization to Operate (ATO) for a new cloud-based application.
7

Monitor

Continuously monitor the system and its controls for changes, new threats, and ongoing effectiveness. This ensures security remains robust over time.

Example: Implementing continuous security monitoring tools and incident response procedures for cloud resources.
Key Takeaway

The latter stages of NIST RMF emphasize continuous vigilance and adaptation, crucial for maintaining security in dynamic cloud environments.
