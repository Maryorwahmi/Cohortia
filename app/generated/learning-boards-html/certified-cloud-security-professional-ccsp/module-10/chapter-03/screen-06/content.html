Adapting Policies for Cloud Service Models

Understanding how IaaS, PaaS, and SaaS require different policy focuses.

IaaS (Infrastructure as a Service)

Customer focus: OS, applications, network config, IAM, data encryption. Provider focus: underlying hardware and virtualization.

PaaS (Platform as a Service)

Customer focus: Applications, data, platform access, secure coding. Provider focus: OS, middleware, runtime, underlying infrastructure.

SaaS (Software as a Service)

Customer focus: Data governance, user access, acceptable use, provider vetting. Provider focus: Everything else.

Shared Responsibility Model
Policies must clearly delineate responsibilities based on the service model.
