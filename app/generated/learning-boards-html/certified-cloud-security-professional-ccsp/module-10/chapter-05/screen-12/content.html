Data Protection

Auditor Focus

  • Data classification, encryption at rest and in transit.
  • Protection against loss (backup/recovery).
  • Meeting data residency requirements.
Example

Verifying that all databases containing PII are encrypted using customer-managed keys and backed up to a separate, secure region.

Configuration Management

Auditor Focus

  • Cloud resources configured to secure baselines.
  • Robust change management process.
  • Prevention of unauthorized or insecure modifications.
Key Takeaway

Consistent data protection and controlled configuration changes are fundamental to maintaining cloud security and compliance.
