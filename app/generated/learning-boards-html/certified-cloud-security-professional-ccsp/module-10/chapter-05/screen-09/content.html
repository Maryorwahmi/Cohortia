Module 10›Chapter 10.5›Critical Evidence for Cloud Audits

Key Evidence Types

Configuration Snapshots

  • Output from tools like AWS Config, Azure Policy.
  • Shows current configurations of resources (e.g., security groups, IAM policies, encryption settings).
  • Verifies adherence to secure baselines.
Example

An AWS Config rule showing that all S3 buckets are encrypted with KMS keys, demonstrating data at rest protection.

Audit Logs

Key Details

  • Logs from CSP services (e.g., AWS CloudTrail, Azure Monitor).
  • Demonstrate who did what, when, and where.
  • Must be securely stored, immutable, and retained for required periods.
Common Mistake

Failing to ensure log immutability or adequate retention periods, compromising their validity as audit evidence.
