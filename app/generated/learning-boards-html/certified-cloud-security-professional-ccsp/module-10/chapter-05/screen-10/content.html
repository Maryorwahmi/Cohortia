Additional Evidence for Cloud Audits

ACLs & IAM Policies

Documentation of permissions granted to users and services, demonstrating least privilege.

Vulnerability Scan Reports

Results from vulnerability assessments of customer-managed components (e.g., OS, applications in IaaS).

Incident Response Records

Documentation of how security incidents were handled, demonstrating response capability.

Data Encryption Status

Evidence that data at rest and in transit is encrypted according to policy.

Vendor Due Diligence Records

Documentation of assessments performed on CSPs and other third-party vendors.

Key Takeaway

A variety of evidence types, from access controls to vendor assessments, are needed to prove cloud security compliance.
