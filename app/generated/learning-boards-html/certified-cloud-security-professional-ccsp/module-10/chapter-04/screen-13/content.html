Shared Responsibility: Customer vs. CSP

Clarifying Compliance Obligations in the Cloud

CSP Responsibility: 'Of the Cloud'

The cloud service provider is responsible for the security and compliance of the underlying infrastructure.

  • •Physical Security: Data centers, hardware, facilities.
  • •Network Infrastructure: Global network, virtualization.
  • •Compute & Storage: Underlying hardware and software for these services.
  • •Compliance Certifications: Achieving certifications like ISO 27001, SOC 2, PCI DSS for their infrastructure.
Key Takeaway

CSPs secure the global infrastructure that supports your cloud services, ensuring the foundational security of the cloud itself.

Customer Responsibility: 'In the Cloud'

The customer is responsible for everything they configure and deploy within the cloud environment.

  • •Data Classification & Handling: Ensuring data is correctly categorized and managed.
  • •Access Management: Configuring IAM roles, policies, and least privilege.
  • •Network Security Configuration: Setting up virtual networks, firewalls, security groups.
  • •Application Security: Securing applications deployed in the cloud.
  • •Data Encryption: Implementing and managing encryption keys.
  • •Audit Log Review: Regularly reviewing and responding to security logs.
Key Takeaway

Customers are accountable for securing their data, applications, and configurations within the cloud environment.
