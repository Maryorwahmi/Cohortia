CLOUD SECURITY MODEL

Shared Responsibility: Who Secures What?

Clarifying Roles in Virtualized Cloud Environments

Cloud Provider's Responsibility

SECURITY OF THE CLOUD
  • Physical Infrastructure: Data centers, servers, networking hardware.
  • Hypervisor: The virtualization layer and its security.
  • Underlying Network: Core network infrastructure.
  • Global Infrastructure: Regions, availability zones.
Example

Ensuring the physical security of server racks and patching the hypervisor software against known vulnerabilities.

Cloud Customer's Responsibility

SECURITY IN THE CLOUD
  • Operating Systems: Guest OS patching and configuration.
  • Applications: Security of deployed applications.
  • Data: Encryption, access control, and integrity of data.
  • Network Configuration: Virtual firewalls, network security groups.
Example

Updating the Linux kernel within a VM and configuring a virtual firewall to block unauthorized ports for an application.

Key Takeaway

Cloud providers secure *of* the cloud (hypervisor, infrastructure), while customers secure *in* the cloud (VMs, OS, data), preventing security gaps.
