Key Concepts Revisited

Essential Terms in Virtualization Security

Hypervisor

Software, firmware, or hardware that creates and runs virtual machines, abstracting the physical hardware.

Type 1 Hypervisor

Runs directly on the host hardware (bare-metal), offering strong isolation and performance for cloud environments.

Type 2 Hypervisor

Runs as an application on a conventional OS (hosted), inheriting OS vulnerabilities and offering weaker isolation.

VM Escape

An attack where an attacker breaks out of a virtual machine's isolation to access the host system or other VMs.
