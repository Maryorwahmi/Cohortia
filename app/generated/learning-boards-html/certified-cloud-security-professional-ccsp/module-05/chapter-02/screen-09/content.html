Network Security

Virtual Firewalls: Security Groups and NSGs

Controlling Ingress and Egress Traffic to VMs

Stateful Packet Filters

Security Groups (AWS) and Network Security Groups (Azure) act as virtual firewalls at the VM or subnet level.

Ingress & Egress Rules

Define granular rules specifying allowed ports, protocols, and source/destination IP addresses for traffic.

Principle of Least Privilege

Only open ports and allow traffic that is absolutely necessary for the application's function.

Key Takeaway

Security Groups and NSGs are crucial for network isolation, enabling granular control over VM traffic based on the principle of least privilege.

Network Isolation in Practice

Web Server Example

Allow HTTP (port 80) and HTTPS (port 443) from 0.0.0.0/0 (internet) for public access.

Database Server Example

Allow database port (e.g., 3306) ONLY from the IP addresses or security group of the application servers.

Micro-segmentation

Apply granular network policies to individual VMs or application tiers to limit lateral movement in a breach.

Security Tip

Regularly review your security group rules to ensure they still adhere to the principle of least privilege as your application evolves.
