API Gateway: Authentication & Throttling

Controlling access and managing request loads for serverless APIs.

Authentication & Authorization

Implement API keys, OAuth, JWT, AWS Cognito, or Azure AD to control who can invoke functions.

Throttling & Rate Limiting

Set limits on client requests to protect against DoS attacks and manage costs.

Example Scenario

An API Gateway configured with an API key and a rate limit of 100 requests/second per client.

API Gateway Security Flow

Client Request
API Gateway
Authentication Check
Throttling & Rate Limiting
If Valid
Serverless Function
Key Takeaway

API Gateways are critical for serverless security, providing robust authentication, authorization, and throttling capabilities to protect functions from unauthorized access and abuse.
