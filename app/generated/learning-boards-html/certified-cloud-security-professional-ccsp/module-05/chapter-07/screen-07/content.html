Implementing Robust Input Validation

Rigorous checks for data types, formats, and expected values.

Validation Steps

Check data types, formats, lengths, and expected values for all inputs.

Best Practice

Implement validation at the very beginning of your function code to 'fail fast' on invalid inputs.

Error Handling

Return clear error messages (e.g., 400 Bad Request) for invalid or missing inputs.

Validated Lambda Function (Python):
import json

def lambda_handler(event, context):
    if 'body' not in event:
        return {'statusCode': 400, 'body': json.dumps({'message': 'Missing body'})}
    try:
        body = json.loads(event['body'])
    except json.JSONDecodeError:
        return {'statusCode': 400, 'body': json.dumps({'message': 'Invalid JSON'})}

    if 'userId' not in body:
        return {'statusCode': 400, 'body': json.dumps({'message': 'userId required'})}
    try:
        user_id = int(body['userId'])
    except ValueError:
        return {'statusCode': 400, 'body': json.dumps({'message': 'userId must be integer'})}

    # Original function logic proceeds only with valid user_id
    message = f"Processing user ID: {user_id}"
    return {
        'statusCode': 200,
        'body': json.dumps({'message': message})
    }
Key Takeaway

Implementing explicit checks for data types, formats, and presence at the start of your function is crucial for preventing malicious inputs from compromising your serverless application logic.
