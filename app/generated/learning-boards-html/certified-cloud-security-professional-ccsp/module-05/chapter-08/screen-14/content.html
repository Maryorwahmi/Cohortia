Key Concepts

Essential terms to remember

Micro-segmentation

Granular network isolation of individual workloads (VMs, containers, functions) to limit lateral movement.

Service Mesh

A dedicated infrastructure layer for handling service-to-service communication in microservices, offering security features.

Mutual TLS (mTLS)

Cryptographically authenticating and encrypting communication between two services, ensuring both parties are trusted.
