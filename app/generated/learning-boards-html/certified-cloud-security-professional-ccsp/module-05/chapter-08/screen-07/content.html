Securing Serverless and Preventing Lateral Movement

Extending micro-segmentation to serverless functions

Serverless Micro-segmentation

Achieved by placing functions within a Virtual Private Cloud (VPC) and configuring security groups for their network interfaces.

  • Controls access to internal resources.
  • Limits network exposure for functions.

Preventing Lateral Movement

Micro-segmentation severely restricts an attacker's ability to move from a compromised workload to other systems, reducing the 'blast radius' of a breach.

  • Isolates compromised systems.
  • Contains threats to a smaller area.
