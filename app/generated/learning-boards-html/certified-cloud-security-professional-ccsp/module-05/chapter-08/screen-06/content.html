Micro-segmentation Across Cloud Platforms

Applying policies to Virtual Machines and Kubernetes

Virtual Machines (VMs)

For VMs, micro-segmentation is typically achieved using cloud provider security groups (e.g., AWS Security Groups, Azure Network Security Groups) or virtual firewalls.

  • Restricts traffic between specific instances or subnets.
  • Acts as a virtual firewall at the instance level.

Kubernetes Containers

In Kubernetes, Network Policies provide micro-segmentation for pods, defining ingress and egress rules based on labels.

  • Controls pod-to-pod communication.
  • Leverages labels for dynamic policy enforcement.
Cloud-Native Micro-segmentation Controls

Security Groups (VMs)

Virtual firewalls for instances, controlling traffic at the NIC level.

Network Policies (Kubernetes)

Rules for pod communication based on labels and namespaces.

These controls enable precise, workload-level network isolation.
Key Takeaway

Micro-segmentation is implemented using cloud-native controls like Security Groups for VMs and Network Policies for Kubernetes, enabling granular traffic control.
