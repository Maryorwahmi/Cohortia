Responsibility Model

Shared Responsibility: KaaS (Kubernetes-as-a-Service)

In KaaS offerings, the provider manages the control plane, while the customer secures worker nodes and application configurations.

Provider Responsibility

  • •Kubernetes Control Plane (API server, etcd).
  • •Underlying infrastructure for control plane.

Customer Responsibility

  • •Worker Node Security (OS, patching).
  • •Container Images & Application Deployments.
  • •Kubernetes Configurations (RBAC, Network Policies).
Example

With Google GKE, Google manages the Kubernetes API server, but you are responsible for securing your Pods, setting up RBAC, and defining network policies.

Key Takeaway

In KaaS, while the provider secures the control plane, the customer retains critical responsibilities for worker node security and all application-level Kubernetes configurations.
