Attack Vectors

Resource Limits and Network Configuration

Mismanagement of container resources and network access can lead to denial-of-service and unauthorized exposure.

Lack of Resource Limits

  • •DoS Attacks: Containers consume all host resources.
  • •Starvation: Other containers or host OS become unresponsive.

Insecure Network Configuration

  • •Exposed Ports: Direct internet access without firewalls.
  • •Permissive Policies: Overly broad communication between containers.
Scenario

A new containerized microservice is deployed without CPU limits. A bug causes it to enter an infinite loop, consuming 100% CPU, making the entire host unresponsive and affecting other critical services.

Key Takeaway

Enforce strict resource limits (CPU, memory, disk I/O) and implement granular network policies to prevent DoS attacks and unauthorized access in container environments.
