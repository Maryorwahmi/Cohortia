Terminal Demo: Verify Permissions
# Create a temporary pod to test the service account
$ kubectl run --rm -it --serviceaccount=pod-reader-sa --image=busybox:1.35 --restart=Never test-pod-reader -- sh

# Inside the pod, try to list pods (should succeed)
/ # kubectl get pods
NAME        READY   STATUS    RESTARTS   AGE
test-pod-reader   1/1     Running   0          5s

# Try to delete a pod (should fail with permission denied)
/ # kubectl delete pod test-pod-reader
Error from server (Forbidden): pods "test-pod-reader" is forbidden: User "system:serviceaccount:default:pod-reader-sa" cannot delete resource "pods" in API group "" in the namespace "default"
Hands-on Lab

Implementing RBAC: Testing Permissions

Confirming least privilege with practical commands.

Verification Pod

Run a temporary pod configured to use the specific Service Account to test its permissions.

Expected Outcomes

Successful read operations (get, list) and failed write/delete operations confirm least privilege.

Key Takeaway

Always validate your RBAC configurations to ensure they enforce the intended security posture and prevent over-privilege.
