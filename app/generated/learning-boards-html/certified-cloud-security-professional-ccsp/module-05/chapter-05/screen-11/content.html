Pod Hardening

Implementing Pod Security Standards (PSS)

Enforcing security best practices at the pod level.

Replaced PSPs

PSS provides a modern, robust mechanism for enforcing pod security, replacing the deprecated Pod Security Policies.

Namespace-Level Enforcement

Apply PSS profiles to namespaces to ensure all pods within adhere to specific security requirements.

Key Requirements

Enforces rules like running as non-root, disallowing host path mounts, and preventing privileged containers.

Key Takeaway

PSS ensures a consistent and strong security posture for all pods by enforcing predefined security levels at the namespace level.

PSS Security Levels
1. PrivilegedUnrestricted, known escalations allowed.
2. BaselineMinimally restrictive, prevents escalations.
3. RestrictedHeavily restricted, hardening best practices.
