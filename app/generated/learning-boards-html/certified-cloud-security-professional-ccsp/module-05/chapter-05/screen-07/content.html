Terminal Demo: Create Role
# rbac-config.yaml (continued)
---
apiVersion: rbac.authorization.k8s.io/v1
kind: Role
metadata:
  name: pod-reader-role
  namespace: default
rules:
- apiGroups: [""] # "" indicates the core API group
  resources: ["pods"]
  verbs: ["get", "watch", "list"]
---
# Apply the configuration
$ kubectl apply -f rbac-config.yaml
role.rbac.authorization.k8s.io/pod-reader-role created
Hands-on Lab

Implementing RBAC: Defining Roles

Specifying permissions for Kubernetes resources.

API Groups

Categorize Kubernetes resources (e.g., core API group for pods, 'apps' for deployments).

Resources & Verbs

Specify the Kubernetes objects (e.g., 'pods') and the allowed actions (e.g., 'get', 'list').

Key Takeaway

Roles are the 'what' in RBAC, defining the specific permissions that can be granted to an identity.
