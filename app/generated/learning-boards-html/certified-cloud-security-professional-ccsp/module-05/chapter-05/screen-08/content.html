Terminal Demo: Create RoleBinding
# rbac-config.yaml (continued)
---
apiVersion: rbac.authorization.k8s.io/v1
kind: RoleBinding
metadata:
  name: pod-reader-binding
  namespace: default
subjects:
- kind: ServiceAccount
  name: pod-reader-sa
  namespace: default
roleRef:
  kind: Role
  name: pod-reader-role
  apiGroup: rbac.authorization.k8s.io
---
# Apply the configuration
$ kubectl apply -f rbac-config.yaml
rolebinding.rbac.authorization.k8s.io/pod-reader-binding created
Hands-on Lab

Implementing RBAC: RoleBindings

Connecting identities to their defined permissions.

The 'How' of RBAC

RoleBindings are the crucial link that associates a Service Account (who) with a Role (what).

Namespace Scope

RoleBindings, like Roles, are namespace-scoped, meaning they apply only within a specific namespace.

Key Takeaway

RoleBindings are essential for activating the permissions defined in a Role for a specific Service Account.
