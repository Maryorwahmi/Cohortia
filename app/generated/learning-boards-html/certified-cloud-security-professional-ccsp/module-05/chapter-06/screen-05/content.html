Serverless vs. VMs and Containers

Understanding the Shifting Responsibility

Key Differences in Management
  • •VMs: Customer manages OS, runtime, and application.
  • •Containers: Customer manages container image and application; provider manages host OS.
  • •Serverless (FaaS): Provider manages OS, runtime, and scaling; customer manages function code and configuration.
Key Takeaway

The shift in responsibility with serverless significantly reduces the customer's operational security burden, allowing a focus on application-level security and IAM.

Virtual Machines (VMs)

Full control over the guest OS and application stack. High management overhead.

Customer Responsibility
  • •OS, Runtime, Application

Containers

Portable, isolated environments. Shared host OS, but customer manages container image.

Customer Responsibility
  • •Container Image, Application

Serverless (FaaS)

Event-driven functions. Provider manages almost all infrastructure.

Customer Responsibility
  • •Function Code, Configuration
