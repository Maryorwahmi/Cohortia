Defining Serverless Computing

Code Execution Without Server Management

Key Characteristics
  • •No Server Management: Cloud provider handles all infrastructure provisioning and maintenance.
  • •Event-Driven: Code executes only when triggered by specific events (e.g., HTTP request, database change).
  • •Automatic Scaling: Resources scale instantly up or down based on demand.
  • •Pay-per-Execution: Billing is based on actual resource consumption, not idle time.
Key Takeaway

Serverless computing frees developers from infrastructure management, enabling faster development, automatic scaling, and cost-efficient, event-driven applications.

Function-as-a-Service (FaaS)

The core compute component, where developers deploy individual functions that run in response to events.

Examples
  • •AWS Lambda
  • •Azure Functions
  • •Google Cloud Functions

Backend-as-a-Service (BaaS)

Cloud services that provide backend functionality without requiring server management, often integrated with FaaS.

Examples
  • •AWS DynamoDB, S3
  • •Azure Cosmos DB
  • •Google Firebase
