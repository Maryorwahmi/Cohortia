Data Masking in Action: A Python Example

Implementing a simple masking function

Pattern-Based Masking

Replaces most digits with 'X' while retaining the last few for format validation.

Utility Preservation

Masked data maintains format and length, making it suitable for functional testing.

Security Benefit

Prevents exposure of actual sensitive values in non-production environments.

Python Masking Example
# Simple masking function (replaces all but last 4 digits)
def mask_credit_card(card_number):
    if not isinstance(card_number, str) or len(card_number) < 4:
        return "INVALID"
    return "X" * (len(card_number) - 4) + card_number[-4:]

# Example Usage:
original_cc = "4111222233334444"
print(f"Original CC: {original_cc}")
masked_cc = mask_credit_card(original_cc)
print(f"Masked CC:   {masked_cc}") # Output: XXXXXXXXXXXX4444

original_ssn = "987-65-4321"
print(f"Original SSN: {original_ssn}")
masked_ssn = mask_credit_card(original_ssn) # Applies same logic
print(f"Masked SSN:  {masked_ssn}") # Output: XXXXX-4321
