Tokenization in Action: A Python Example

Generating and retrieving tokens with a simple vault

Token Generation

A unique, non-sensitive token (e.g., UUID) is generated for sensitive data.

Secure Storage

The original sensitive data is stored in a 'token vault' linked to its token.

Detokenization

The token is used to retrieve the original data from the vault when needed.

Python Tokenization Example
import uuid

token_vault = {}

def tokenize_data(sensitive_data):
    token = str(uuid.uuid4())
    token_vault[token] = sensitive_data
    return token

def detokenize_data(token):
    return token_vault.get(token, "Token not found")

# Example Usage:
original_ssn = "987-65-4321"
ssn_token = tokenize_data(original_ssn)
print(f"Tokenized SSN: {ssn_token}")
detokenized_ssn = detokenize_data(ssn_token)
print(f"Detokenized SSN: {detokenized_ssn}")
