EBS Snapshot: Creating a Volume Backup

Capturing point-in-time copies of block storage for recovery.

# 1. Launch an EC2 instance (e.g., t2.micro in us-east-1)

# 2. Connect to the instance and create a dummy file:
# SSH into your EC2 instance
sudo su
echo "This is important data from the EC2 instance." > /home/ec2-user/important_data.txt
chown ec2-user:ec2-user /home/ec2-user/important_data.txt

# 3. Create an EBS Snapshot of the instance's root volume:
# Find the Volume ID of your EC2 instance's root volume
aws ec2 create-snapshot \
    --volume-id vol-YOUR_VOLUME_ID \
    --description "Snapshot for CCSP Module 3 Demo" \
    --tag-specifications 'ResourceType=snapshot,Tags=[{Key=Name,Value=CCSP-Demo-Snapshot}]'
Step 1 & 2: Setup

Launch an EC2 instance and create a sample file. This simulates a real-world scenario where you have critical data on a volume that needs protection.

Step 3: Create Snapshot

Use the AWS CLI to create a snapshot of the EBS volume. This creates a point-in-time backup. Remember to replace `YOUR_VOLUME_ID` with your actual volume ID.

Key Takeaway

EBS snapshots are fundamental for creating reliable backups of block storage, capturing the entire volume state for future recovery.
