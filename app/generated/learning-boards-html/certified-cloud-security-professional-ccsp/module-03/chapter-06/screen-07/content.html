Core Concept

Data Archiving: Long-Term Retention and Compliance

Cost-effective storage for infrequently accessed, regulatory-mandated data.

Primary Purpose

Long-term retention for compliance, legal, or historical reasons, not quick recovery.

Cloud Tiers

Utilizes specialized low-cost storage like AWS Glacier or Azure Archive Storage.

Key Takeaway

Archiving balances extreme cost-effectiveness with durability for rarely accessed data, with slower retrieval times.

Archiving vs. Backup: Key Differences
Archiving

Access: Infrequent, slow
Cost: Very Low
Purpose: Compliance, Legal, Historical
Example: 7-year financial logs

Backup

Access: Frequent, fast
Cost: Moderate
Purpose: Operational Recovery
Example: Daily database backups
