S3 Cross-Region Replication: Setting Up DR

Configuring continuous data replication for object storage resilience.

# 1. Enable versioning on the source bucket
aws s3api put-bucket-versioning \
    --bucket source-bucket-YOURUNIQUEID \
    --versioning-configuration Status=Enabled

# 2. Create a destination bucket in a different region
aws s3 mb s3://destination-bucket-YOURUNIQUEID --region us-west-2
Step 1: Enable Versioning

Versioning on the source bucket is crucial. It preserves multiple versions of an object, protecting against accidental overwrites or deletions, and is a prerequisite for replication.

Step 2: Create Destination Bucket

The destination bucket must be in a different AWS region than the source. This provides geographical redundancy, essential for disaster recovery.

Key Takeaway

Versioning and cross-region destination setup are foundational for S3 replication, ensuring data integrity and geographical resilience.
