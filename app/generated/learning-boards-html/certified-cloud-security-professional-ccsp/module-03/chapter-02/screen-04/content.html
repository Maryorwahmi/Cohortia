Core Concept

The Landscape of Cloud Data Storage

Choosing the Right Architecture for Your Data

Object Storage

Stores data as objects in buckets, each with a unique identifier and metadata. Highly scalable and durable for unstructured data.

  • Ideal for backups, archives, media files, data lakes.
  • Accessed via APIs (HTTP/S).
  • Security via IAM, bucket policies, ACLs.

Block Storage

Provides raw, unformatted storage volumes attached to virtual machines. Analogous to a physical hard drive.

  • Best for databases, OS volumes, high I/O applications.
  • Accessed at the block level by the OS.
  • Security tied to VM, network security groups.

File Storage

Offers a shared file system mounted by multiple instances, with a familiar hierarchical directory structure and file-level locking.

  • Suitable for shared applications, content management.
  • Accessed via standard file protocols (NFS, SMB).
  • Security via POSIX/Windows ACLs, cloud IAM.
Key Takeaway

Each cloud storage type is optimized for different data characteristics and access patterns, requiring tailored security strategies and controls.

Common Misconception

Assuming a 'one-size-fits-all' security approach for all cloud storage types can lead to critical vulnerabilities and data breaches.
