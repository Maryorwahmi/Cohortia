Data State

Data in Transit Encryption

Securing data as it moves between clients and cloud services.

Key Mechanisms

  • **TLS/SSL Protocols:** Encrypt data over public networks (e.g., HTTPS).
  • **VPNs:** Create encrypted tunnels for secure communication.
  • **Direct Connect/ExpressRoute:** Provide private, encrypted links to cloud.
  • **Private Networks (VPCs):** Secure inter-service communication within the cloud.
Critical Enforcement

Always enforce TLS 1.2 or higher and ensure all communication paths, including inter-service, are secured.

Practical Examples

Accessing Cloud Services

Always use https:// endpoints for services like AWS S3 or Azure Blob Storage to ensure data is encrypted during transfer.

Inter-Service Communication

Configure cloud services to communicate over private networks (e.g., AWS VPCs) and ensure TLS is used for all internal API calls.

Key Takeaway

Data in transit encryption is non-negotiable; enforce strong TLS versions and secure all network paths to prevent interception.
