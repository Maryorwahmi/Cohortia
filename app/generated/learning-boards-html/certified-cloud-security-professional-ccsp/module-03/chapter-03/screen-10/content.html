S3 SSE-KMS with AWS CLI (Part 1)

Encrypting an S3 object using a customer-managed KMS key via the AWS CLI.

AWS CLI Commands
# 1. Ensure you have a KMS key created.
# Example: aws kms create-key --description "My S3 Encryption Key"

# 2. Get the ARN of your KMS key
#    aws kms list-keys
#    aws kms describe-key --key-id <your-key-id>

# 3. Upload a file to S3 with SSE-KMS
#    Replace 'your-kms-key-arn' with the actual ARN
#    Replace 'your-bucket-name' and 'your-file.txt' with actual values
aws s3 cp your-file.txt s3://your-bucket-name/your-file.txt \
    --server-side-encryption aws:kms \
    --sse-kms-key-id arn:aws:kms:us-east-1:123456789012:key/your-kms-key-arn
Important Note

Always replace placeholder values like your-kms-key-arn and your-bucket-name with your actual AWS resource identifiers.

Command Breakdown

  • aws s3 cp: The command to copy files to S3.
  • --server-side-encryption aws:kms: Specifies using AWS KMS for server-side encryption.
  • --sse-kms-key-id: Provides the ARN of your customer-managed KMS key.
  • This ensures data is encrypted with a key whose lifecycle and access policies are under your control.
Key Takeaway

Using SSE-KMS with a customer-managed key provides enhanced control and compliance over your S3 object encryption.
