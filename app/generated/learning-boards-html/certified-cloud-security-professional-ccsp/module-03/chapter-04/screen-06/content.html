Core Actions of DLP Policies

Automated Responses to Sensitive Data Detections

1. Monitoring

Alerts security teams when sensitive data is detected, providing visibility without immediate enforcement. Ideal for initial policy testing.

2. Blocking

Prevents the transmission or storage of sensitive data, stopping exfiltration in real-time. This is a direct enforcement action.

3. Quarantining

Moves sensitive data to a secure, restricted location for review, isolating it from unauthorized access and preventing further spread.

4. Redacting/Masking

Modifies sensitive data to obscure its content while allowing non-sensitive parts to remain visible. Useful for compliance reporting.

5. Encryption

Automatically encrypts sensitive data upon detection, rendering it unreadable without the correct decryption key, even if exfiltrated.

Key Takeaway

DLP policies provide a spectrum of automated responses, from passive monitoring to active blocking and encryption, enabling precise control over sensitive data.
