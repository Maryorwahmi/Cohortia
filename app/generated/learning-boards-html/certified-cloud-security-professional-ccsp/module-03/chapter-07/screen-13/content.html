Hands-on: Automating Data Lifecycle in AWS S3

Configuring retention and expiration policies using S3 lifecycle rules

Scenario Overview

Simulate a data retention and destruction scenario for an S3 bucket. Configure lifecycle rules to move old objects to a lower-cost archive tier and then permanently delete them.

  • Create an S3 bucket and upload dummy files.
  • Define a lifecycle policy for archiving and expiration.
  • Apply and verify the policy using AWS CLI.
Key Takeaway

Automating S3 lifecycle rules is a practical way to manage data retention and destruction, ensuring compliance and optimizing storage costs.

Terminal Walkthrough
# 1. Create an S3 bucket
aws s3 mb s3://ccsp-retention-demo-YOURUNIQUEID --region us-east-1

# 2. Upload dummy files
echo "Current data" > current_data.txt
echo "Old data to archive" > old_data.txt
aws s3 cp current_data.txt s3://ccsp-retention-demo-YOURUNIQUEID/current_data.txt
aws s3 cp old_data.txt s3://ccsp-retention-demo-YOURUNIQUEID/old_data.txt

# 3. Create S3 Lifecycle Policy JSON (lifecycle_policy.json)
{
  "Rules": [
    {
      "ID": "ArchiveAndExpireRule",
      "Status": "Enabled",
      "Filter": { "Prefix": "" },
      "Transitions": [
        { "Days": 30, "StorageClass": "GLACIER" }
      ],
      "Expiration": { "Days": 90 }
    }
  ]
}

# 4. Apply the lifecycle policy
aws s3api put-bucket-lifecycle-configuration \
    --bucket ccsp-retention-demo-YOURUNIQUEID \
    --lifecycle-configuration file://lifecycle_policy.json

# 5. Verify the lifecycle policy
aws s3api get-bucket-lifecycle-configuration \
    --bucket ccsp-retention-demo-YOURUNIQUEID
