Secure Destruction: Cryptographic Erasure

Deleting the encryption key to render data unrecoverable, even if bits persist

How Cryptographic Erasure Works

This method leverages encryption to render data unrecoverable without physically altering the storage medium.

  • If data was encrypted, deleting the encryption key makes the data inaccessible.
  • The underlying data bits may persist, but they are effectively unrecoverable.
  • Highly effective for cloud storage where physical destruction is not feasible for customers.
Key Takeaway

Cryptographic erasure, by deleting encryption keys, is a highly effective and cloud-native method for rendering data unrecoverable.

Cryptographic Erasure in Practice

For encrypted S3 objects, deleting the associated KMS key performs cryptographic erasure.
When decommissioning an encrypted EBS volume, ensure its KMS key is also destroyed.
Shared Responsibility

Customers are responsible for managing their encryption keys; CSPs handle underlying infrastructure sanitization.
