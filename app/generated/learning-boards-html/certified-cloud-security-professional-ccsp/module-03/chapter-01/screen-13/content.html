Key Concepts

Essential terms and ideas from this chapter.

Data Classification

Categorizing data based on sensitivity, value, and regulatory requirements to apply appropriate security controls.

Data Discovery

The technical process of locating and identifying data across an organization's cloud infrastructure, often using automated tools.

Personally Identifiable Information (PII)

Any data that can be used to identify a specific individual, such as names, addresses, or social security numbers.

Chapter Summary

Data classification and discovery are foundational to cloud security, enabling organizations to identify, categorize, and protect sensitive information effectively.
