Simulating Data Classification with AWS S3 Tags

Use AWS CLI to create a bucket, upload data, and apply classification tags.

Instructions: Step 1-3

  • Create an S3 bucket: A unique bucket for our exercise.
  • Upload sample data: Two files, one public, one sensitive.
  • Simulate manual classification: Apply 'Classification' and 'Owner' tags to the sensitive file.
Key Takeaway

Object tagging is a fundamental method for applying metadata-driven classification to individual data items in cloud storage.

# 1. Create an S3 bucket
aws s3 mb s3://my-ccsp-data-discovery-bucket-YOURUNIQUEID --region us-east-1

# 2. Upload sample data
echo "This is public information." > public_info.txt
echo "Name: John Doe, SSN: 987-65-4321, DOB: 01/01/1980" > sensitive_pii.txt
aws s3 cp public_info.txt s3://my-ccsp-data-discovery-bucket-YOURUNIQUEID/public/public_info.txt
aws s3 cp sensitive_pii.txt s3://my-ccsp-data-discovery-bucket-YOURUNIQUEID/private/sensitive_pii.txt

# 3. Simulate manual classification (tagging)
aws s3api put-object-tagging \
    --bucket my-ccsp-data-discovery-bucket-YOURUNIQUEID \
    --key private/sensitive_pii.txt \
    --tagging '{"TagSet": [{"Key": "Classification", "Value": "Restricted"}, {"Key": "Owner", "Value": "Finance"}]}'
Remember

Replace 'YOURUNIQUEID' with a unique identifier to avoid bucket name conflicts.
