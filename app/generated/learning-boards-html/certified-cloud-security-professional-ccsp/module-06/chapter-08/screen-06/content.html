Automated Application and Image Security Testing

Scanning Code, Containers, and Dependencies

Static Application Security Testing (SAST)

Scans source code and IaC templates for vulnerabilities and misconfigurations on every commit. Example: SonarQube, Checkmarx, cfn_nag.

Dynamic Application Security Testing (DAST)

Runs automated vulnerability scans against deployed applications in staging environments to find runtime issues. Example: OWASP ZAP, Nessus.

Container Image Scanning

Automatically scans container images for known vulnerabilities before they are pushed to a registry or deployed. Example: Clair, Trivy, AWS ECR Scan.

Dependency Scanning

Checks third-party libraries and open-source components for known vulnerabilities. Example: Snyk, Dependabot.

Secret Scanning

Detects hardcoded secrets (e.g., API keys, credentials) in code repositories to prevent accidental exposure. Example: GitGuardian, TruffleHog.

Key Takeaway

A combination of SAST, DAST, container, dependency, and secret scanning provides robust, automated security coverage throughout the CI/CD pipeline.
