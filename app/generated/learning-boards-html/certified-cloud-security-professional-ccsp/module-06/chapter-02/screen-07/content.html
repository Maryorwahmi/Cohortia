Threat Categorization

STRIDE: Identifying Core Threats (Part 1)

Focusing on identity and data integrity.

S - Spoofing

An attacker pretending to be someone or something else.

  • Cloud Example: Faking a user identity to access an application or forging an API request to impersonate a legitimate service.
  • Impact: Unauthorized access, data manipulation, or system compromise.
  • Mitigation Focus: Strong authentication (MFA, OAuth), robust authorization, API Gateway authorizers.

T - Tampering

Unauthorized modification of data.

  • Cloud Example: Altering data in transit between cloud services or modifying configuration files stored in an S3 bucket.
  • Impact: Data corruption, incorrect processing, system instability, or security bypass.
  • Mitigation Focus: TLS/SSL for data in transit, encryption for data at rest, digital signatures, integrity checks.
Key Takeaway

Spoofing targets identity, while Tampering targets data integrity; both require robust authentication and data protection mechanisms in cloud designs.
