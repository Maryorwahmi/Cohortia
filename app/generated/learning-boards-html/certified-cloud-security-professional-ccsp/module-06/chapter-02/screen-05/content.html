Cloud Context

Unique Cloud Complexities

Expanding the attack surface in dynamic cloud environments.

Why Cloud is Different

  • Dynamic Resources: Constantly changing infrastructure (scaling, ephemeral instances).
  • Shared Responsibility: Clear division of security duties between provider and customer.
  • Extensive API Usage: Services interact primarily via APIs, creating new attack vectors.
  • Microservices/Serverless: Distributed architectures with numerous independent components.
  • Increased Attack Surface: More potential entry points and configuration points for attackers.

Key Cloud Characteristics

Dynamic Infrastructure

Resources scale on demand, changing network topology and attack surface.

Shared Responsibility

Security duties are split between cloud provider and customer.

API-Driven Interactions

Services communicate via APIs, requiring robust authentication/authorization.

Microservices/Serverless

Distributed components increase complexity and potential misconfigurations.

Key Takeaway

Cloud's dynamic nature and distributed architectures necessitate a tailored approach to threat modeling to address its expanded attack surface.
