Threat Categorization

STRIDE: Identifying Core Threats (Part 3)

Ensuring availability and access control.

D - Denial of Service (DoS)

Preventing legitimate users from accessing a service.

  • Cloud Example: API flooding, resource exhaustion (e.g., Lambda concurrency limits), or consuming all available bandwidth.
  • Impact: Service unavailability, business disruption, financial losses, reputational damage.
  • Mitigation Focus: WAFs, rate limiting, auto-scaling, robust error handling, DDoS protection services.

E - Elevation of Privilege (EoP)

An attacker gaining more permissions than they should have.

  • Cloud Example: Exploiting a vulnerability to gain root access to an underlying host or assuming an overly permissive IAM role.
  • Impact: Complete control over cloud resources, data exfiltration, system compromise.
  • Mitigation Focus: Principle of Least Privilege, strong access controls (IAM policies), regular vulnerability scanning, patch management.
Key Takeaway

DoS targets service availability, while EoP targets authorization; both are critical for maintaining operational integrity and security posture in the cloud.
