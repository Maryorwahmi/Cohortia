STRIDE: Identifying Core Threats (Part 2)

Addressing accountability and data confidentiality.

R - Repudiation

An attacker denying having performed an action.

  • Cloud Example: A user denying a transaction or resource deletion without proper audit trails or logging to prove otherwise.
  • Impact: Lack of accountability, inability to trace actions, legal and compliance issues.
  • Mitigation Focus: Comprehensive logging (CloudTrail, access logs), digital signatures, strong authentication.

I - Information Disclosure

Unauthorized exposure of data.

  • Cloud Example: Sensitive data in public S3 buckets, unencrypted logs, or exposed databases due to misconfigurations.
  • Impact: Data breaches, regulatory fines, reputational damage, competitive disadvantage.
  • Mitigation Focus: Least privilege access, data encryption (at rest and in transit), data masking, secure logging practices.
Key Takeaway

Repudiation threats undermine accountability, while Information Disclosure compromises confidentiality; both require robust logging and stringent access controls.
