Mapping Cloud Architecture with DFDs

Visualizing data flows to identify potential attack surfaces.

Understanding Data Flow Diagrams

DFDs are graphical representations that show how data moves through a system, highlighting key components and interactions.

  • Processes: Where data is transformed (e.g., Lambda functions).
  • Data Stores: Where data rests (e.g., S3 buckets, DynamoDB).
  • External Entities: Users or other systems interacting with the application (e.g., end-users, third-party services).
  • Data Flows: The movement of data between components.

Cloud Components in a DFD

API Gateways

Entry points for requests, often handling routing and authentication.

Lambda Functions

Serverless compute, processing data and interacting with other services.

S3 Buckets

Object storage for raw data, processed files, or backups.

DynamoDB Tables

NoSQL databases for application data storage.

Key Takeaway

DFDs are crucial for visualizing cloud architecture, revealing how data moves and where vulnerabilities might exist across various cloud services.
