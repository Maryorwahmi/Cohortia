Input Validation & Output Encoding Process

1

Receive Untrusted Input

API requests, SQS messages, S3 events.

2

Validate Input

Check format, type, length, range, content.

3

Process Data

Only if validation passes.

4

Encode Output

Context-specific encoding (HTML, JS, URL).

Why Validate?

Prevents injection attacks (SQL, NoSQL, command), buffer overflows, and unexpected application behavior by ensuring data conforms to expectations.

Example: Serverless Function

A Lambda function processing image metadata from an S3 event should validate file type, size, and embedded metadata to prevent malicious payloads.

Key Takeaway

Always treat external input as hostile. Validate it rigorously and encode all output based on its rendering context to prevent common web vulnerabilities.
