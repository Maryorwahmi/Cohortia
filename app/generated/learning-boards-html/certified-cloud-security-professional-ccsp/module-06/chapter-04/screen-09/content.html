RASP: Real-Time Attack Blocking

Continuous monitoring and active protection in production.

How RASP Works

  • Runtime Agent: Deploys an agent within the application's production runtime environment.
  • Real-Time Monitoring: Continuously observes application behavior for malicious activity.
  • Active Blocking: Detects and blocks attacks as they happen, preventing exploitation.
  • Self-Protection: Acts as a 'self-healing' security mechanism for critical applications.

Key Takeaway: Last Line of Defense

RASP provides crucial real-time protection in production, actively blocking attacks and safeguarding against vulnerabilities that bypass earlier testing stages, including zero-day threats.

Strengths & Limitations

Strengths:

  • Real-time attack blocking.
  • Protects against zero-days.
  • Operates in production.

Limitations:

  • Potential performance overhead.
  • Risk of false positives blocking legitimate traffic.
  • Requires careful tuning.
