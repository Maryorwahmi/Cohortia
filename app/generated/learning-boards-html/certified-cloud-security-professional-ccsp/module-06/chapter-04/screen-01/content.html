Cloud-Native Security Testing

Layered Defense for Continuous Deployment

In the agile world of cloud-native development, security must be integrated seamlessly and continuously throughout the CI/CD pipeline. This chapter explores specialized application security testing (AST) tools—SAST, DAST, IAST, and RASP—each designed to detect different types of vulnerabilities at various stages of the development and deployment lifecycle. Together, these tools form a layered defense, providing comprehensive coverage from code commit to production runtime.

Key Idea

Integrate SAST, DAST, IAST, and RASP throughout the CI/CD pipeline for a comprehensive, layered defense against evolving threats.
