Shared Responsibility: Software as a Service (SaaS)

Understanding customer and CSP duties in SaaS

CSP Responsibilities (Salesforce, Microsoft 365)

  • • Application security and development
  • • Data security (encryption, storage)
  • • Runtime, OS, and middleware management
  • • All underlying infrastructure
CSP Focus

Security OF the entire application stack.

Customer Responsibilities

  • • User access management (roles, permissions)
  • • Data classification and sensitivity labeling
  • • Ensuring appropriate use of the service
  • • Client-side endpoint security
Customer Focus

Security IN the application's configuration and usage.

Concrete Example

With Salesforce, Salesforce secures the application and infrastructure. You manage user accounts, roles, and data within your Salesforce instance.

Common Oversight

Failing to properly configure user roles and permissions within the SaaS application, leading to over-privileged users or data exposure.
