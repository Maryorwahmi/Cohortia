Shared Responsibility: Platform as a Service (PaaS)

Understanding customer and CSP duties in PaaS

CSP Responsibilities (Azure App Service, AWS Elastic Beanstalk)

  • • Operating system management and patching
  • • Runtime environment (e.g., Java, .NET)
  • • Middleware (e.g., web servers)
  • • Underlying infrastructure (physical, network, virtualization)
CSP Focus

Security OF the platform and underlying infrastructure.

Customer Responsibilities

  • • Applications and application code security
  • • Data (encryption, access controls, classification)
  • • Identity and Access Management (IAM) for application users
  • • Application configuration and settings
Customer Focus

Security IN the application and its data.

Concrete Example

Using Azure App Service: Microsoft handles the OS and web server, but you secure your web application code, protect the data it processes, and manage user authentication.

Common Oversight

Assuming the CSP's platform security extends to your application code, leading to vulnerabilities like SQL injection or insecure API endpoints.
