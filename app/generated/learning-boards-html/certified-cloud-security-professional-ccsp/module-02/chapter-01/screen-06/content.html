Shared Responsibility: Infrastructure as a Service (IaaS)

Understanding customer and CSP duties in IaaS

CSP Responsibilities (AWS, Azure, GCP)

  • • Physical facilities and security
  • • Network infrastructure (routers, switches)
  • • Virtualization layer (hypervisor)
  • • Underlying compute, storage, and networking hardware
CSP Focus

Security OF the cloud: the foundation.

Customer Responsibilities

  • • Operating systems (patching, configuration)
  • • Applications and middleware
  • • Data (encryption, access controls)
  • • Network configuration (security groups, VPCs)
  • • Identity and Access Management (IAM)
Customer Focus

Security IN the cloud: what you build and run.

Concrete Example

Deploying a Windows Server VM on AWS EC2: AWS secures the physical server, but you are responsible for patching the Windows OS, configuring its firewall, and securing your applications.

Common Oversight

Neglecting OS patching or misconfiguring network security groups, assuming the CSP handles these, can lead to critical vulnerabilities.
