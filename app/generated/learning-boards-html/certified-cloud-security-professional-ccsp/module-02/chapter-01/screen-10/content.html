Architectural Principle

Defense in Depth

Layering multiple security controls for comprehensive protection

Core Definition

Defense in Depth involves layering multiple, independent security controls to protect assets. If one control fails, another is there to catch it.

  • • Reduces the likelihood of a single point of failure.
  • • Increases the effort and time required for an attacker to succeed.
  • • Creates a more resilient security posture.
Key Takeaway

Never rely on a single security control. Assume controls can fail and plan for redundancy.

Layers of Cloud Security

Network Segmentation

VPCs, subnets, and network access control lists (NACLs) to isolate traffic.

Security Groups/WAF

Firewall rules at the instance level and web application firewalls at the edge.

Authentication & Encryption

Strong IAM, MFA, and encryption for data at rest and in transit.

Concrete Example

A web application is protected by a WAF, a security group restricting ports, an OS firewall on the VM, and application-level authentication. Four layers of defense.
