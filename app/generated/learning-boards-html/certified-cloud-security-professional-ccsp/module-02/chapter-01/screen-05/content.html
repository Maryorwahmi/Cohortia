Fundamental Model

The Shared Responsibility Model

Clarifying security roles in the cloud

Core Concept

The Shared Responsibility Model defines the security obligations of the cloud service provider (CSP) and the cloud customer. It's crucial for preventing security gaps.

  • • CSP: Responsible for security OF the cloud (infrastructure, physical facilities, network hardware, hypervisor).
  • • Customer: Responsible for security IN the cloud (data, applications, OS, network config, IAM).
Key Takeaway

Misunderstanding the Shared Responsibility Model is a leading cause of cloud security breaches. Always know your part.

Visualizing the Divide

Security OF the Cloud (CSP)

The provider secures the physical data centers, network infrastructure, and virtualization layer. Think of it as securing the building and utilities.

Security IN the Cloud (Customer)

You secure your data, applications, operating systems, network configurations, and user access. This is securing what you put inside the building.

Common Mistake

Assuming the CSP handles all security. This leads to neglecting customer responsibilities, creating critical vulnerabilities.
