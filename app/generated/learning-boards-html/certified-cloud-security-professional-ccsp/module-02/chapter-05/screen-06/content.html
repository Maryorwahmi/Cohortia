Multi-Factor Authentication (MFA)

Adding critical layers of security beyond passwords.

Something You Know

Password, PIN, security question answer.

Something You Have

Authenticator app, SMS code, hardware token, phone.

Something You Are

Biometrics: fingerprint, facial scan, iris scan.

Key Takeaway

MFA is a critical security control that requires multiple verification factors, significantly reducing the risk of unauthorized access even if credentials are compromised.
