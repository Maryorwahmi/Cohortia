Least Privilege IAM Policy in AWS

Creating an AWS IAM policy for specific S3 bucket access.

1. Define the IAM Policy:

This policy grants `s3:ListBucket` and `s3:GetObject` permissions only for the specified bucket and its objects.

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "ListSpecificBucket",
      "Effect": "Allow",
      "Action": "s3:ListBucket",
      "Resource": "arn:aws:s3:::my-application-logs-12345"
    },
    {
      "Sid": "GetObjectsFromSpecificBucket",
      "Effect": "Allow",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-application-logs-12345/*"
    }
  ]
}

2. Create User & Attach Policy:

Create the IAM user 'AppLogReader' and attach the policy.

3. Test Access (AWS CLI):

# Should succeed:
aws s3 ls s3://my-application-logs-12345/
aws s3 cp s3://my-application-logs-12345/some_log_file.txt .

# Should fail (Access Denied):
aws s3 ls
aws s3 rm s3://my-application-logs-12345/some_log_file.txt
Key Takeaway

Precisely defining IAM policies to grant only necessary permissions is fundamental to enforcing least privilege and securing cloud resources.
