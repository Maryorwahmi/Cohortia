Intrusion Detection & Prevention Systems

Monitoring and Blocking Malicious Activity

Intrusion Detection System (IDS)

Monitors network traffic and system activity for suspicious patterns and alerts on threats.

  • **Function:** Detects and alerts, but does not block.
  • **Mechanism:** Signature-based (known attacks) or anomaly-based (unusual behavior).
  • **Cloud Example:** AWS GuardDuty for intelligent threat detection.
Key Takeaway

While IDS provides crucial visibility and alerts, IPS offers an active defense, automatically preventing detected threats, making it a powerful tool for real-time protection in dynamic cloud environments.

Intrusion Prevention System (IPS)

Actively blocks or prevents detected threats in real-time, in addition to alerting.

  • **Function:** Detects, alerts, and actively blocks/prevents.
  • **Mechanism:** Can drop packets, reset connections, or reconfigure firewalls.
  • **Cloud Example:** Azure Security Center's threat protection capabilities.
Common Misconception

Confusing IDS and IPS. Remember, IDS is like a security camera with an alarm, while IPS is like a security guard who can also intervene and stop an intruder.
