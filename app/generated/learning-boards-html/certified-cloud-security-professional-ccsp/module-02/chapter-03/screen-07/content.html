Application Security

Web Application Firewalls (WAFs)

Protecting Against Web Exploits

WAF Definition

A security solution that monitors, filters, and blocks HTTP/HTTPS traffic to and from a web application.

  • **Focus:** Application-layer attacks (Layer 7 of OSI model).
  • **Deployment:** Often deployed in front of web servers or load balancers.
  • **Cloud Examples:** AWS WAF, Azure Application Gateway with WAF.

Attacks Mitigated by WAFs

  • **SQL Injection:** Prevents malicious SQL queries.
  • **Cross-Site Scripting (XSS):** Blocks script injection attacks.
  • **Cross-Site Request Forgery (CSRF):** Protects against unauthorized commands.
  • **OWASP Top 10:** Addresses a wide range of common web vulnerabilities.

WAF Traffic Flow

User Request (Internet)
Web Application Firewall (Inspects & Filters)
Web Application (Protected)
WAF (Filters Response)
User Response (Internet)
Key Takeaway

WAFs are indispensable for securing public-facing web applications against common and sophisticated web exploits, providing a crucial layer of defense at the application layer.
