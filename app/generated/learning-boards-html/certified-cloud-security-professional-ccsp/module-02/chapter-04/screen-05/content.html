Core Concept

Encryption at Rest

Securing Data Stored on Persistent Media

What it Protects

Data stored on databases, storage buckets, disks, and other persistent media.

Key Benefit

Renders data unreadable if the physical storage is accessed or compromised.

Common Cloud Examples
  • AWS S3 (SSE-S3, SSE-KMS, SSE-C)
  • Azure Storage (Microsoft-managed keys, CMK via Key Vault)
