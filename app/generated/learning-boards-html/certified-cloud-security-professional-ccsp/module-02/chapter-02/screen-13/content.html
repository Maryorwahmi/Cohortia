Key Concepts

Essential takeaways from this chapter

VPC / VNet

A logically isolated section of the cloud providing foundational network isolation for your resources.

Security Groups / NSGs

Stateful (SG) or stateless (NSG) virtual firewalls controlling inbound/outbound traffic for instances or subnets/NICs.

Web Application Firewall (WAF)

A Layer 7 firewall that protects web applications from common exploits like SQL injection and XSS.

Summary Takeaway

Effective cloud security starts with robust network segmentation and granular traffic control at every layer of your architecture.
