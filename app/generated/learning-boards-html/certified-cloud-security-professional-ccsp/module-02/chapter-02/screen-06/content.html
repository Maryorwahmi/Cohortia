Virtual Firewall

AWS Security Groups: Instance-Level Protection

Stateful firewalls controlling traffic for individual instances

Definition

A virtual firewall that controls inbound and outbound traffic for one or more EC2 instances. They are stateful.

Key Feature

Stateful filtering: automatically allows return traffic for any permitted outbound connection.

Common Mistake

Opening 0.0.0.0/0 (any IP) for sensitive ports like SSH or database access, creating unnecessary attack surfaces.

Security Group Rules
# Example: Web Server Security Group

Inbound Rules:
- Protocol: TCP, Port: 80 (HTTP), Source: 0.0.0.0/0 (Anywhere)
- Protocol: TCP, Port: 443 (HTTPS), Source: 0.0.0.0/0 (Anywhere)
- Protocol: TCP, Port: 22 (SSH), Source: YourAdminIP/32

Outbound Rules:
- Protocol: All, Port: All, Destination: 0.0.0.0/0 (Allow all outbound)
# Or more restrictively:
# - Protocol: TCP, Port: 8080, Destination: AppTierSG (to application servers)
Example Scenario

A web server needs to accept public HTTP/HTTPS traffic but only allow SSH access from a specific IT administration IP address range.
