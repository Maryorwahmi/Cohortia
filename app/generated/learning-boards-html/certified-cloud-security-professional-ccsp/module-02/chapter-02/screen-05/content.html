Subnets: Organizing Your Cloud Network

Dividing your VPC/VNet for application tiers and environments

Three-Tier Architecture
Purpose

Logically divide a VPC/VNet to separate application tiers or environments (dev, staging, prod).

Security Benefit

Enables distinct security controls and access policies for different components, reducing exposure.

Example

A public subnet for web servers, private subnets for application servers and databases.
