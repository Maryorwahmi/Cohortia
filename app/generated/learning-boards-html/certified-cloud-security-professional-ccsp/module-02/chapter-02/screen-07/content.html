Virtual Firewall

Network Security Groups (NSGs): Subnet and NIC Control

Defining traffic rules for subnets and network interfaces

Definition

A virtual firewall in Azure/GCP that filters network traffic to and from Azure resources in a VNet. Can be associated with subnets or individual network interfaces.

Key Difference (vs. AWS SG)

NSGs are stateless when applied to subnets, requiring explicit inbound and outbound rules. AWS Security Groups are stateful.

Misconfiguration Risk

Overly permissive rules (e.g., allowing 'Any' source/destination) can expose sensitive resources to unauthorized access.

NSG Rule Application
# Example: Azure NSG Rule for a Web Subnet

Inbound Rule: Allow HTTP/HTTPS
- Priority: 100
- Source: Any
- Source Port Range: *
- Destination: Any
- Destination Port Range: 80, 443
- Protocol: TCP
- Action: Allow

Outbound Rule: Allow to App Subnet
- Priority: 200
- Source: Any
- Source Port Range: *
- Destination: AppSubnetCIDR
- Destination Port Range: 8080
- Protocol: TCP
- Action: Allow
Practical Use

An NSG applied to a web subnet allows public HTTP/HTTPS inbound, but only permits outbound traffic to the application subnet on a specific port.
