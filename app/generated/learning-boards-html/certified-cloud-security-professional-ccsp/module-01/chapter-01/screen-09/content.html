Cloud Service Models: IaaS, PaaS, SaaS

Each model defines a different level of provider and customer responsibility for security.

IaaS (Infrastructure as a Service)

Provider manages infrastructure; customer manages OS, applications, data.

PaaS (Platform as a Service)

Provider manages OS, middleware; customer manages applications, data.

SaaS (Software as a Service)

Provider manages entire application stack; customer uses the software.

Key Takeaway

The level of customer security responsibility decreases from IaaS to PaaS to SaaS, requiring different security strategies.
