PaaS: Platform as a Service

How security responsibilities shift with PaaS offerings.

CSP Responsibilities

The cloud provider manages more of the stack:

  • Underlying infrastructure (physical, virtualization).
  • Operating system (patching, hardening).
  • Platform runtime (e.g., Java, Python environment).
  • Potentially managed database services.
Example

CSP handles OS patching for your managed app service.

Customer Responsibilities

Your focus shifts to your application and its data:

  • Application code (secure coding, vulnerability management).
  • Data stored within the platform (encryption, access).
  • Configuration of platform-specific services.
  • Managing application-level user access.
  • Ensuring data privacy and compliance within the application.
Key Takeaway

PaaS reduces infrastructure overhead, but you remain responsible for your application's security and data integrity.
