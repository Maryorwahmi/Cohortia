Network and Application Security

Your role in securing cloud networks and deployed applications.

Network Security

While CSPs provide infrastructure, you configure your virtual networks:

  • Virtual Networks: Configuring VPCs, subnets.
  • Traffic Control: Setting up Security Groups, NACLs.
  • Resource Isolation: Segmenting networks to limit lateral movement.
  • VPNs: Securely connecting on-premises to cloud.
Example

Configuring a Security Group to allow only HTTPS traffic to your web server.

Application & Endpoint Security

Securing your code and virtual machines:

  • Secure Coding: For IaaS and PaaS applications.
  • Vulnerability Management: Regular scanning and patching of applications.
  • Runtime Protection: WAFs, RASP for applications.
  • Endpoint Security (IaaS): Securing VM OS with AV, host firewalls.
  • Secure Usage (SaaS): Configuring app features securely.
Key Takeaway

Your network and application configurations are critical security controls that you must actively manage.
