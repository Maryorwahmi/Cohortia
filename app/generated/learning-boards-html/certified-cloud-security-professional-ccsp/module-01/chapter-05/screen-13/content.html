Key Concepts: Core Definitions

Essential terms from the Cloud Shared Responsibility Model.

Shared Responsibility Model

A framework defining security responsibilities between cloud provider and customer.

Security of the Cloud

Provider's responsibility for the underlying infrastructure (physical security, hardware, virtualization).

Security in the Cloud

Customer's responsibility for everything they put into or run within the cloud (data, applications, OS, configurations).

Summary Takeaway

The shared responsibility model is fundamental for effective cloud security, clearly dividing duties between the provider and the customer to prevent security gaps.
