Understanding the Cloud Shared Responsibility Model

Defining Security Roles in the Cloud

This model is arguably the most critical concept for any cloud security professional. It defines what security responsibilities fall to the cloud service provider and what responsibilities fall to the customer. Misunderstanding this model is a common source of security breaches.

Key Idea

The cloud shared responsibility model clarifies security duties between cloud providers and customers, preventing critical gaps.
