SaaS: Software as a Service

Minimal customer responsibility, but critical security duties remain.

CSP Responsibilities

The cloud provider manages almost the entire stack:

  • Application itself.
  • Underlying platform.
  • All infrastructure (physical, OS, network).
  • Application security and patching.
Example

CSP secures email servers and the email application for an online email service.

Customer Responsibilities

Your focus shifts to user and data governance within the application:

  • Identity and Access Management (IAM) within the SaaS app.
  • Data classification and secure usage of the application.
  • Ensuring compliance with data residency and privacy regulations.
  • Setting strong passwords and enabling MFA for users.
Key Takeaway

Even in SaaS, you have vital responsibilities for user access, data governance, and secure application usage.
