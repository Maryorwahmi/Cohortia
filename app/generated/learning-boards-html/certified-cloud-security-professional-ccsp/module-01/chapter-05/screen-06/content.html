Security in the Cloud

Your responsibilities for securing your data and applications.

What it Encompasses

This refers to the security of everything that the customer puts into or runs within the cloud environment. It's your operational security domain.

  • Customer Data: Encryption, access controls, backups.
  • Applications: Code, configurations, runtime.
  • Operating Systems: Patching, hardening (in IaaS).
  • Network Configurations: VPCs, subnets, security groups.
  • IAM: User accounts, roles, permissions.
Customer's Goal

To configure and manage all deployed elements securely to protect against threats.

Key Responsibilities

Specific tasks the customer undertakes to secure their cloud assets:

  • Data classification, encryption (at rest and in transit), DLP.
  • Implementing strong authentication (MFA) and least privilege.
  • Configuring virtual networks, subnets, and security groups.
  • Secure coding practices and vulnerability management for applications.
  • Patching and hardening guest operating systems (for IaaS).
Key Takeaway

You are accountable for securing your data, applications, and configurations within the cloud, leveraging the provider's secure infrastructure.
