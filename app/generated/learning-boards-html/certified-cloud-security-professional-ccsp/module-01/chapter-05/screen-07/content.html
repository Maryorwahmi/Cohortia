IaaS: Infrastructure as a Service

Understanding shared responsibility in an IaaS environment.

CSP Responsibilities

The cloud provider secures the foundational infrastructure:

  • Physical infrastructure (data centers, hardware).
  • Virtualization layer (hypervisors).
  • Underlying network fabric.
Example

CSP ensures the physical server running your VM is secure and available.

Customer Responsibilities

You manage almost everything running on the infrastructure:

  • Operating system (patching, hardening, configuration).
  • Applications installed on the OS.
  • Data (encryption, access controls, backups).
  • Network configurations (VPC, subnets, security groups).
  • Identity and Access Management (IAM) for VMs and applications.
Key Takeaway

IaaS gives you maximum control, but also maximum responsibility for security 'in' the cloud.
