Security of the Cloud

The cloud service provider's commitment to infrastructure security.

What it Covers

This refers to the security of the underlying infrastructure that supports the cloud services. It's the foundation upon which everything else runs.

  • Physical Facilities: Data centers, environmental controls.
  • Hardware: Servers, storage, networking components.
  • Virtualization Layer: Hypervisors, underlying OS.
  • Network Fabric: Core network infrastructure.
Provider's Goal

To ensure the availability, integrity, and confidentiality of the core cloud infrastructure.

Key Responsibilities

Specific tasks the CSP undertakes to secure the cloud infrastructure:

  • Physical security of data centers (e.g., access controls, surveillance).
  • Environmental controls (e.g., cooling, fire suppression).
  • Patching and securing host operating systems.
  • Ensuring network infrastructure resilience and protection.
  • Hardware maintenance and replacement.
Key Takeaway

The CSP is solely responsible for the security of the physical and virtual infrastructure that makes cloud services possible.
