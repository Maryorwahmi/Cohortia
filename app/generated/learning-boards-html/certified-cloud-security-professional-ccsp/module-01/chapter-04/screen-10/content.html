Network Access Control Lists (NACLs): Stateless Subnet Filters

Filtering traffic at the subnet level for broad network security

NACL Characteristics

  • Stateless: Separate rules for inbound and outbound traffic.
  • Subnet-Level: Applies to all instances within a specific subnet.
  • Packet Filtering: Evaluates traffic based on rules (allow/deny).
  • Coarse-Grained Control: Provides broad network security for entire segments.
Key Takeaway

NACLs offer stateless, subnet-level traffic filtering, providing a powerful, broad-stroke security layer that complements the granular control of Security Groups.

NACL vs. Security Group

NACLs

  • Stateless
  • Subnet level
  • Applies to all instances in subnet
  • Supports Allow/Deny rules

Security Groups

  • Stateful
  • Instance level
  • Applies to specific instances
  • Supports Allow rules only (implicit deny)

NACLs act as a firewall for subnets, while Security Groups act as a firewall for instances.

Both are crucial for a layered defense strategy.
