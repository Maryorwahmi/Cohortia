Network Segmentation

Subnets: Public, Private, and Secure Placement

Dividing your VPC for enhanced security and control

Subnet Types & Purpose

Public Subnet

For resources needing direct internet access (e.g., web servers).

Private Subnet

For sensitive resources without direct internet access (e.g., databases).

  • Logical Subdivision: Breaks down VPC IP ranges.
  • Internet Access: Public via Internet Gateway; Private via NAT Gateway/VPN.
  • Security Best Practice: Place sensitive data in private subnets.
Key Takeaway

Strategic use of public and private subnets is crucial for isolating sensitive resources and controlling internet exposure within your VPC.
