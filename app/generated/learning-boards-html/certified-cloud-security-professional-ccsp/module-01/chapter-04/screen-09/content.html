Network Control

Security Groups: Stateful Virtual Firewalls

Controlling traffic at the instance level for granular protection

Key Characteristics

  • Stateful: Automatically allows return traffic for permitted connections.
  • Instance-Level: Controls traffic for individual virtual machines.
  • Isolation: Crucial for separating workloads and restricting communication.
  • Granular Rules: Define specific inbound/outbound protocols, ports, and sources/destinations.
Key Takeaway

Security Groups are essential for enforcing instance-level network access control, acting as virtual firewalls to protect individual cloud resources.

Security Group Rules Example

Web Server Security Group
Inbound Rules
  • HTTP (TCP 80): Allow from 0.0.0.0/0 (Internet)
  • HTTPS (TCP 443): Allow from 0.0.0.0/0 (Internet)
  • SSH (TCP 22): Allow from 192.168.1.10/32 (Admin IP)
Outbound Rules
  • All Traffic: Allow to 0.0.0.0/0 (Internet) - *Common, but can be restricted*
Database Security Group
Inbound Rules
  • MySQL (TCP 3306): Allow from Web Server SG (Private IP)
Outbound Rules
  • All Traffic: Deny - *Strictly controlled*
