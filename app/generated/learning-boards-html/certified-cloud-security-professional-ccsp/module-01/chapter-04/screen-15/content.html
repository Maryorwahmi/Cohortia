Key Concepts: Security Controls & Principles

Essential terms for securing cloud resources

Subnet

A logical subdivision of a VPC's IP address range, can be public or private.

Security Group

A stateful virtual firewall that controls inbound and outbound traffic for instances.

Least Privilege

Granting only the minimum necessary permissions to users and systems.

Summary Takeaway

Effective cloud security relies on segmenting networks, controlling instance traffic, enforcing minimal access, and layering defenses.
