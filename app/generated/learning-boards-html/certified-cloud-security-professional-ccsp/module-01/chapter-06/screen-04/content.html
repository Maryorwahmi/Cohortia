Core Concept

The Shared Responsibility Model

Understanding Your Role in Cloud Security

Cloud Provider's Responsibility (Security OF the Cloud)

  • Physical security of data centers
  • Network infrastructure (routers, switches)
  • Virtualization infrastructure (hypervisors)
  • Underlying hardware and software

Customer's Responsibility (Security IN the Cloud)

  • Data (encryption, access control)
  • Applications and operating systems
  • Network configuration (firewalls, security groups)
  • Identity and Access Management (IAM)
  • Client-side data encryption
Key Takeaway

Customers must actively manage and configure their cloud resources securely, as cloud providers only secure the underlying infrastructure.

Shared Security in Action

Cloud Provider: Security OF the Cloud

Secures physical infrastructure, network, virtualization, and hardware.

Customer: Security IN the Cloud

Responsible for data, applications, OS, network config, and IAM.
