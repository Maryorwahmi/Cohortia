Shared Responsibility Model

Provider Responsibility

Security of the cloud (infrastructure, physical, network).

Customer Responsibility

Security in the cloud (data, apps, configs, IAM).

Key Security Considerations

  • •Network Segmentation: Isolate workloads effectively.
  • •Strong IAM: Control access to resources.
  • •Data Encryption: Protect data at rest and in transit.
  • •Continuous Monitoring: Detect misconfigurations and threats.
Common Mistake

Leaving storage buckets publicly accessible or using overly permissive Identity and Access Management (IAM) policies can lead to severe data breaches.

Key Takeaway

Public cloud security is a shared responsibility. While providers secure the cloud, customers are accountable for securing their data and configurations within it.
