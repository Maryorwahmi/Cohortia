Service Model Deep Dive

Infrastructure as a Service (IaaS)

The Foundation of Cloud Computing

What IaaS Provides

Virtualized Servers (VMs)
Storage & Databases
Networking Components
Operating Systems
  • Provider manages physical infrastructure, virtualization, and network.
  • Customer manages OS, applications, data, runtime, and middleware.
  • Offers highest flexibility and control to the customer.
Key Takeaway

IaaS provides raw computing power and flexibility, but places significant responsibility on the customer for securing everything above the virtualization layer.

Use Case Example

Migrating a legacy ERP system to the cloud ('lift and shift') where specific OS configurations and direct server access are required, or hosting custom web applications.

Pro Tip

Leverage IaaS for maximum control when deep customization or specific compliance requirements necessitate direct management of the operating system and application stack.
