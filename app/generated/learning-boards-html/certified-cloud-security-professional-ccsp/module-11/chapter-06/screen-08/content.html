Audit & Compliance

Common Cloud Audit Frameworks

Demonstrating Compliance and Control Effectiveness

These frameworks provide standardized methods for assessing and verifying the security and compliance of cloud services and customer configurations.

Key Takeaway

Leverage provider audit reports and maintain your own evidence to successfully navigate cloud security audits.

Preparation Tip

Gathering evidence of control implementation and reviewing policies are key steps in audit preparation.

Framework

SOC 2

Focuses on security, availability, processing integrity, confidentiality, and privacy of data handled by service organizations.

Framework

ISO/IEC 27001

International standard for Information Security Management Systems (ISMS), demonstrating a systematic approach to managing sensitive information.

Framework

CSA STAR

Security, Trust & Assurance Registry. A public registry documenting security controls of cloud offerings.
