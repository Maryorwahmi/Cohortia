Contractual Compliance Question

Focusing on Data Sovereignty

A cloud customer is reviewing a cloud service agreement (CSA) and a data processing addendum (DPA). Which of the following clauses is *most critical* for addressing data sovereignty and ensuring compliance with national data protection laws?

a) SLA for uptime and performance.
b) Physical security controls for data centers.
c) Explicit agreement on geographic regions for data storage and cross-border transfers.
d) Indemnification clauses for IP infringement.
Explanation

Data sovereignty is directly tied to the legal jurisdiction of data storage. Clauses defining geographic regions and cross-border transfers are essential for compliance.
