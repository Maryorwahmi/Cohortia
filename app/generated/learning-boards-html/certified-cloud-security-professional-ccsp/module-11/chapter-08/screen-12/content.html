Module 11 › Chapter 11.8 › Choosing Key Management: A Scenario
Scenario

Deploying a new service with highly sensitive PII and financial data in the public cloud, requiring maximum control and compliance.

Strategy Evaluation
  • Default KMS: Low control, easy.
  • BYOK: Medium control (origin), cloud manages lifecycle.
  • Dedicated HSM: High assurance, provider managed.
  • HYOK (On-prem HSM): Max control, customer manages lifecycle.
Recommendation

For maximum control and compliance with sensitive data, HYOK is recommended. It ensures master keys remain entirely outside the cloud provider's infrastructure.

Key Takeaway

Strategic key management choices like HYOK are critical for securing highly sensitive data, while proactive QSC planning ensures long-term data protection.
