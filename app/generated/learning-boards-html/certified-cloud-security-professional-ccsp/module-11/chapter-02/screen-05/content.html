Data Classification Levels & Controls

Public

Minimal restrictions, public access.

Internal

Company-wide access, basic controls.

Confidential

Restricted access, strong encryption, MFA.

Restricted

Highly sensitive, strict residency, client-side encryption.

Automated tools like AWS Macie aid in discovery and tagging.
Definition

Categorizing data based on its sensitivity, value, and regulatory requirements to inform security policies.

Why it Matters

Ensures appropriate security controls are applied, preventing over-securing or under-securing data, optimizing cost and risk.

Key Takeaway

Without proper classification, effective data security is impossible, leading to inefficiencies or critical vulnerabilities.
