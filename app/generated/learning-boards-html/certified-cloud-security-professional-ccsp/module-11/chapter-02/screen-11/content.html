DLP: Monitoring & Blocking Data Exfiltration

Data In Motion

Monitors network traffic, email, web uploads.

Data At Rest

Scans cloud storage for sensitive data.

Data In Use

Monitors endpoint activities and applications.

DLP integrates with cloud services to enforce policies and prevent unauthorized sharing.
Definition

Tools and processes designed to prevent sensitive data from leaving an organization's control, whether accidentally or maliciously.

Example Policy

A DLP policy might block an employee from uploading a file containing credit card numbers to an unapproved public storage service.

Key Takeaway

Effective DLP requires accurate data classification, well-defined policies, and continuous monitoring to prevent data exfiltration.
