Data Lifecycle Stages & Controls

1. Create

Data Classification

2. Store

Encryption, Access Controls

3. Use

Masking, Tokenization

4. Share

Secure Transfer, Access Policies

5. Archive

Retention, Immutable Storage

6. Destroy

Secure Sanitization

Supporting Explanation
  • Data classification is foundational at 'Create'.
  • Encryption and access controls are vital for 'Store'.
  • Data masking protects sensitive data during 'Use'.
  • Secure transfer protocols are key for 'Share'.
  • Immutable storage ensures data integrity for 'Archive'.
  • Secure sanitization prevents recovery at 'Destroy'.
Concrete Example

A financial record is created (classified as 'Confidential'), stored in an encrypted S3 bucket, used by an analytics app (masked), shared with auditors (secure transfer), archived for 7 years, then securely wiped.

Key Takeaway

Neglecting any stage of the data lifecycle creates a significant security vulnerability.
