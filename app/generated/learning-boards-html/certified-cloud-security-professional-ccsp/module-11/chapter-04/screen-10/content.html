Practical Application

Automating Security Scans in CI/CD

Shifting left with SAST, DAST, and container image scanning.

Integrating Security Tools

SAST (Static Analysis)

Scan source code for vulnerabilities on every commit/PR.

DAST (Dynamic Analysis)

Scan running applications in staging environments.

Container Image Scanning

Scan Docker images for vulnerabilities before pushing to registry.

IaC Scanning

Identify misconfigurations in cloud infrastructure templates.

Conceptual GitLab CI/CD Snippet

image_scan_job:
  stage: build
  image: docker:latest
  services:
    - docker:dind
  script:
    - docker build -t my-app:latest .
    - docker run --rm -v $PWD:/src aquasec/trivy:latest image my-app:latest
  allow_failure: false
  rules:
    - if: '$CI_COMMIT_BRANCH == "main"'

This snippet demonstrates integrating Trivy for container image scanning, failing the pipeline if vulnerabilities are found.

Key Takeaway

Automating security scans within CI/CD pipelines enables continuous security validation, shifting left to detect and remediate vulnerabilities early and efficiently.
