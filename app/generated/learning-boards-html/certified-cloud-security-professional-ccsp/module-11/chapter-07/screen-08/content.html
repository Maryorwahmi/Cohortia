Due Diligence

Shared Assessments & Vendor Risk

Standardized frameworks that facilitate efficient due diligence by allowing cloud providers to document their security and compliance posture.

How They Work
  • Cloud providers document security controls and compliance in a standardized format.
  • Customers use this standardized information for their own risk assessments.
  • Reduces repetitive questionnaires for both providers and customers.
  • Enables easier comparison of provider security postures.
Key Programs
CSA STAR
Registry & Attestations
Shared Assessments Program
Standardized Questionnaires
Efficiency Gain

Shared assessments reduce the burden on both cloud providers and customers by standardizing the process of verifying security and compliance claims.
