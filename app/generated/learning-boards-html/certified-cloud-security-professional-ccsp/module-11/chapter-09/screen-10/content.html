Scenario Analysis: Prioritization and Shared Responsibility
Apply security principles and the shared responsibility model to make informed decisions.
Prioritize Actions

Identify the most critical asset, immediate threat, or impactful control. In incident response, containment is often the first step.

Consider the CIA Triad

Evaluate which aspect (Confidentiality, Integrity, Availability) is most at risk or needs primary protection in the given scenario.

Apply Shared Responsibility Model

Determine who (customer or provider) is responsible for the security aspect in question, based on the cloud service model.

Key Takeaway

Prioritization based on security principles and a clear understanding of the shared responsibility model are fundamental for selecting the most effective solution in scenario-based questions.

Shared Responsibility Example (PaaS)
Customer Responsibility

Application code, data, configuration, access management.

Provider Responsibility

Operating system, network controls, virtualization, physical infrastructure.

Common Mistake

Confusing customer and provider responsibilities within a specific cloud service model, leading to an incorrect answer.
