Shared Responsibility Model: IaaS

Customer and provider obligations for Infrastructure as a Service.

Cloud Provider Responsibilities

  • Physical Infrastructure
  • Virtualization (Hypervisor)
  • Physical Network

Example: AWS secures the physical host and hypervisor for an EC2 instance.

Customer Responsibilities

  • Operating Systems (Guest OS)
  • Applications
  • Data & Network Configuration

Example: You are responsible for Windows updates and firewall rules on your EC2 Windows Server VM.

Key Takeaway

In IaaS, customers maintain significant control and responsibility over the operating system, applications, and data within their virtualized environment.
