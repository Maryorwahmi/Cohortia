NIST's Five Essential Characteristics

Understanding the core attributes and their security implications.

01

On-Demand Self-Service

Users provision resources without human interaction.

Risk: Shadow IT, misconfigurations.
02

Broad Network Access

Capabilities available over the network via standard mechanisms.

Risk: Increased attack surface.
03

Resource Pooling

Multiple tenants share underlying physical resources.

Risk: Data leakage, unauthorized access.
04

Rapid Elasticity

Resources can be scaled rapidly, both up and down.

Risk: Security controls lag scaling.
05

Measured Service

Resource usage is monitored, controlled, and reported.

Benefit: Crucial for auditing & compliance.
Key Takeaway

Each NIST characteristic of cloud computing introduces specific security challenges that demand careful consideration and appropriate controls to mitigate risks effectively.
