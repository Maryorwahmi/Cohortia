Key Concepts: Network & Compute

Essential terms for advanced cloud security.

Micro-segmentation

Fine-grained network segmentation applied to individual workloads to restrict lateral movement.

Web Application Firewall (WAF)

Protects web applications from common web exploits at the application layer by inspecting HTTP/HTTPS traffic.

Golden Image

A pre-configured, hardened, and patched VM image used as a template for deploying new instances.

Summary Takeaway

Advanced cloud security relies on granular network controls, application-aware firewalls, and securely hardened compute baselines.
