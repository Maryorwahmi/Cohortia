What is Micro-segmentation?

Micro-segmentation is a security technique that enables the creation of granular network policies for individual workloads, rather than broad network segments. This approach isolates workloads from each other, even within the same network.

  • •Zero-Trust Principle: Operates on the 'never trust, always verify' model, assuming no implicit trust between workloads.
  • •Restricts Lateral Movement: Significantly limits an attacker's ability to move from a compromised workload to others.
  • •Policy Enforcement: Policies are applied based on workload attributes (tags, roles) rather than IP addresses, making them dynamic.
Concrete Example

In a microservices architecture, each service (e.g., authentication, payment, inventory) can have its own network policy, allowing only necessary communication between them, even if they reside on the same subnet.
