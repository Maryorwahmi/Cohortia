Containment: Limiting the Damage

Stopping the spread of an active security incident

Cloud-Specific Containment Actions

  • Isolate Instances: Modify security groups/WAFs to block traffic to compromised VMs.
  • Block Malicious IPs: Update network access controls or WAF rules.
  • Suspend Accounts: Temporarily disable compromised user or service accounts.

Example: Compromised EC2 Instance

If an EC2 instance is compromised, a rapid containment action would be to modify its associated security group to deny all inbound and outbound traffic. This immediately isolates the instance from the network, preventing it from exfiltrating data or spreading malware to other resources. This action can often be automated via AWS Lambda functions triggered by security alerts.

Key Takeaway

Rapid containment in the cloud leverages network controls and automation to quickly isolate compromised resources and prevent further damage.
