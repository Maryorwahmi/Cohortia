Eradication & Recovery: Eliminating Threats and Restoring Services

Removing the root cause and bringing systems back online securely

Eradication Strategies

  • Patch Vulnerabilities: Apply security updates to fix exploited weaknesses.
  • Remove Malware/Misconfigurations: Clean infected systems or correct security settings.
  • Terminate & Redeploy: For cloud instances, often the safest way to ensure eradication using golden images.

Recovery Actions

  • Validate Eradication: Confirm the threat is completely gone before restoring.
  • Restore from Backups: Utilize snapshots and trusted backups for data and system recovery.
  • Secure & Monitor: Ensure systems are hardened and continuously monitored post-recovery.
Key Takeaway

Eradication focuses on removing the root cause, often by redeploying from trusted images, while recovery restores services securely using backups and validation.
