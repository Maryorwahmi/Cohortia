Scenario: PII Protection In Use

A financial organization needs to ensure confidentiality and integrity of PII during processing, even from privileged cloud administrators. Which technology offers the strongest protection for data in use?

Correct Answer: c) Confidential Computing

Explanation: The critical phrase is 'during processing, even from privileged cloud administrators.' Confidential computing uses hardware-protected Trusted Execution Environments (TEEs) to keep data encrypted and isolated in memory while it is being processed, even from the underlying OS or hypervisor.

Key Takeaway

Confidential Computing is the strongest practical solution for protecting sensitive data (like PII) while it is actively being processed in memory, even from privileged cloud insiders.

Data Protection Technologies

a) Data Loss Prevention (DLP)

Prevents data exfiltration, but doesn't protect data during active processing in memory. Incorrect.

b) Homomorphic Encryption (HE)

Allows computation on encrypted data, but is computationally intensive and largely theoretical for broad application today. Incorrect.

c) Confidential Computing

Uses hardware-protected TEEs to keep data encrypted and isolated in memory during processing. Correct.

d) Quantum-Safe Cryptography (QSC)

Addresses future threats from quantum computers to existing encryption, not specifically data in use protection from privileged insiders today. Incorrect.
