Key Concepts

Essential terms to remember

Image Hardening

Securing a base OS image by removing unnecessary components and applying security settings before deployment.

Patch Management

The systematic process of acquiring, testing, and applying software updates and security patches to systems.

Host-Based Security

Security controls implemented directly on a compute instance, such as anti-malware and HIDS.

Summary Takeaway

Securing cloud compute begins with a strong foundation: hardened images, continuous patching, and robust host-based controls are essential for all instances.
