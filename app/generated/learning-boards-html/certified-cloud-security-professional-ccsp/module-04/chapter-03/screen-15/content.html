Key Concepts (Cont.)

Advanced terms for cloud compute security

Containers

Lightweight, portable units encapsulating an application and its dependencies, sharing the host OS kernel.

Container Orchestration

Platforms like Kubernetes that automate deployment, scaling, and management of containerized applications.

Serverless Functions

Event-driven compute services where the cloud provider fully manages the underlying infrastructure.

Summary Takeaway

Modern cloud compute security relies on understanding containers and orchestration, securing serverless functions, and universally applying the principle of least privilege.
