VM Security

Patch Management & Host-Based Controls

Continuous defense for running virtual machines

Automated Patching

Regularly apply OS and application patches using cloud services like AWS Systems Manager Patch Manager or Azure Update Management to address known vulnerabilities.

Host-Based Security

Install anti-malware, Host-based Intrusion Detection/Prevention Systems (HIDS/HIPS), and ensure robust logging and auditing are enabled directly on the VM.

Key Takeaway

A combination of automated patching and comprehensive host-based security provides a strong, ongoing defense for cloud VMs.

Terminal Demo: Implementing Host Controls
# Example: Installing an anti-malware agent (ClamAV) on a Linux VM
# 1. Update package lists
sudo apt update

# 2. Install ClamAV
sudo apt install clamav clamav-daemon -y

# 3. Update virus definitions
sudo freshclam

# 4. Scan a directory (e.g., /var/www/html)
sudo clamscan -r /var/www/html

# Example: Configuring basic logging with rsyslog to send to a remote SIEM
# 1. Edit rsyslog configuration
sudo nano /etc/rsyslog.conf

# 2. Add line to forward logs (replace SIEM_IP and PORT)
# *.* @SIEM_IP:PORT

# 3. Restart rsyslog service
sudo systemctl restart rsyslog
Pro-Tip

Leverage cloud-native IAM for instance access (e.g., AWS Session Manager) instead of long-lived SSH keys or RDP passwords to enhance auditability and reduce credential exposure.
