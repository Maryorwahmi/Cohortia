Encryption Fundamentals

Encryption at Rest for Cloud Storage

Protecting data when it's stored on disk

Why Encryption at Rest?

  • •Data Confidentiality: Prevents unauthorized access to stored data.
  • •Compliance: Meets regulatory requirements (e.g., HIPAA, PCI DSS).
  • •Mitigates Physical Theft: Protects data even if storage media is stolen.
  • •Defense in Depth: Adds a critical layer of security.
Key Takeaway

Always encrypt sensitive data at rest; choose the key management option that best fits your control and compliance needs.

Provider-Managed Keys

Cloud provider handles key creation, storage, and rotation.

  • •Examples: AWS SSE-S3, Azure SSE-Azure.
  • •Benefit: Simplicity and ease of use.

Cloud KMS-Managed Keys

You manage keys within a cloud Key Management Service (KMS).

  • •Examples: AWS KMS, Azure Key Vault, Google Cloud KMS.
  • •Benefit: Greater control, often HSM-backed.

Customer-Provided Keys (CSEK)

You manage keys entirely on-premises and provide them to the cloud service.

  • •Benefit: Highest level of customer control.
  • •Consideration: Increased operational overhead.
