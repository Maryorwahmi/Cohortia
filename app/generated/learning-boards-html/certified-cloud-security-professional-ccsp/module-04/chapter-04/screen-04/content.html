Core Concept

Understanding Cloud Storage Types

Each type has unique security considerations

Why Differentiate?

  • •Optimized Use Cases: Each storage type is built for specific data needs.
  • •Distinct Security Features: Controls vary significantly across types.
  • •Risk Mitigation: Applying the right security prevents misconfigurations.
  • •Compliance: Meeting regulatory requirements often depends on correct implementation.
Key Takeaway

Selecting the appropriate cloud storage type and understanding its specific security model is the foundation for a secure cloud data strategy.

Object Storage

For unstructured data (backups, media, data lakes). Accessed via APIs.

  • •Security Focus: Access control (bucket policies, ACLs, SAS) and encryption.
  • •Common Mistake: Publicly accessible buckets.

Block Storage

Persistent volumes for VMs (databases, high I/O apps). Behaves like a hard drive.

  • •Security Focus: Volume encryption, snapshot encryption, VM access control.
  • •Example: AWS EBS, Azure Managed Disks.

File Storage

Shared file system access (NFS, SMB). For shared drives, content repositories.

  • •Security Focus: Network access, IAM integration, encryption.
  • •Example: AWS EFS, Azure Files.
