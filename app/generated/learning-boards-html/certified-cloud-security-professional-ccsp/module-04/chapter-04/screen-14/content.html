Key Concepts: Part 1

Essential terms and ideas from this chapter

Object Storage

Cloud storage for unstructured data (e.g., S3, Azure Blob Storage) accessed via APIs.

Block Storage

Cloud storage providing persistent volumes for virtual machines (e.g., EBS, Azure Managed Disks).

File Storage

Cloud storage offering shared file system access (e.g., EFS, Azure Files) using NFS or SMB.

Encryption at Rest

Encrypting data while it is stored on disk, often using cloud-native KMS or customer-provided keys.

Encryption in Transit

Encrypting data as it moves over a network, typically using TLS/SSL.

Key Management Service (KMS)

A cloud service for creating, managing, and controlling encryption keys (e.g., AWS KMS, Azure Key Vault).

Summary Insight

Securing cloud storage requires a multi-faceted approach, combining an understanding of storage types with robust encryption and key management strategies.
