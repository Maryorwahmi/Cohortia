Key Concepts: Part 2

Essential terms and ideas from this chapter

Bucket Policy

JSON-based policies in object storage defining access permissions for buckets and objects.

Shared Access Signature (SAS)

A URI granting restricted access rights to Azure Storage resources for a specified period.

Data Lifecycle Management

Policies automating data movement between tiers or deletion based on age/access patterns.

Object Immutability

Feature preventing objects from being deleted or overwritten for a fixed period (e.g., S3 Object Lock).

Data Loss Prevention (DLP)

Technologies and processes detecting and preventing sensitive data from leaving organizational control.

Summary Insight

Implementing robust access controls, lifecycle management, immutability, and DLP are critical for comprehensive cloud storage security and compliance.
