Storage Type Security

Securing Block Storage

Protecting persistent volumes for virtual machines

Block Storage Characteristics

  • •Persistent Volumes: Data persists independently of the VM.
  • •High Performance: Ideal for databases and I/O-intensive applications.
  • •Direct Attachment: Volumes attach directly to a single VM.
  • •Examples: AWS EBS, Azure Managed Disks, Google Persistent Disks.
Key Takeaway

Always encrypt block storage volumes and their snapshots, and tightly control VM access to them.

Encryption

Encrypt volumes at creation using KMS keys.

  • •Benefit: Protects data at rest on the virtual disk.
  • •Also: Encrypt snapshots to secure backups.

Access Control

Restrict access to underlying VMs that attach these volumes.

  • •Methods: Network Security Groups (NSGs), IAM roles.
  • •Goal: Prevent unauthorized VM access to storage.

Common Mistake

Encrypting the volume but neglecting to encrypt its snapshots.

  • •Impact: Unencrypted snapshots can expose sensitive data.
  • •Solution: Always ensure snapshot encryption is enabled.
