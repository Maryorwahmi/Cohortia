Key Concepts: Core Infrastructure

Essential terms for understanding cloud components

Compute

Cloud resources providing processing power, such as Virtual Machines (VMs), containers, and serverless functions.

Network

Virtual infrastructure defining connectivity, including Virtual Private Clouds (VPCs), subnets, routing, and virtual firewalls.

Storage

Cloud services for data persistence, encompassing object storage, block storage, and file storage.

Summary Takeaway

Mastering these core components—Compute, Network, and Storage—is foundational for understanding and securing any cloud environment, as they represent the essential building blocks of cloud infrastructure.
