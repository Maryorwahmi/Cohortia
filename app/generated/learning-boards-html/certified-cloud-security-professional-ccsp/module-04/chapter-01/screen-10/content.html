SRM in IaaS: Customer vs. Provider

Understanding responsibilities in Infrastructure-as-a-Service

IaaS: Infrastructure-as-a-Service

Cloud service model providing virtualized compute, network, and storage resources.

Provider Responsibilities

  • Physical infrastructure
  • Hypervisor
  • Network fabric
  • Data center security

Customer Responsibilities

  • Operating system (patching, hardening)
  • Applications & data
  • Network configuration (security groups)
  • Identity & access management
Key Insight

IaaS offers maximum flexibility but places significant security responsibilities on the customer, requiring vigilance over the operating system and application layers.

Practical Example

If you deploy a Linux VM on Azure, Microsoft secures the physical server, but you are responsible for applying kernel updates, configuring SSH access, and securing any web server software running on it.

Common Misconfiguration

Failing to regularly patch the operating system of IaaS instances is a critical and common vulnerability, often leading to exploits and breaches.
