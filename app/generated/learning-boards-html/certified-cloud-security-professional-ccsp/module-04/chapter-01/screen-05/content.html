Compute Resources Explained

The processing power behind your cloud applications

What is Compute?

Provides the processing power for running applications and workloads in the cloud.

Virtual Machines (VMs)

Emulated computer systems offering full OS control. Example: AWS EC2, Azure Virtual Machines.

Containers

Lightweight, portable packages for applications and dependencies. Example: Docker, Kubernetes.

Serverless Functions

Run code without managing servers. Provider handles infrastructure. Example: AWS Lambda, Azure Functions.

IaaS Context

Customer manages OS, applications, and data; provider manages hypervisor and physical infrastructure.

Key Insight

The choice of compute model directly impacts the scope of customer security responsibilities, from OS patching to application hardening.

Practical Example

If you provision an Azure Virtual Machine, you are responsible for applying security patches to its Windows or Linux operating system, while Microsoft secures the underlying physical server.

Security Consideration

Misunderstanding compute responsibilities can lead to unpatched systems, vulnerable applications, and unauthorized data access, making it a critical area for security focus.
