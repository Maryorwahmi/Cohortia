Key Concepts: Shared Responsibility

Critical terms for cloud security accountability

Shared Responsibility Model

A framework outlining the division of security responsibilities between the cloud provider and the cloud customer, varying by service model.

Security OF the Cloud

The cloud provider's responsibility for securing the underlying infrastructure, physical facilities, and core services.

Security IN the Cloud

The customer's responsibility for securing their data, applications, operating systems, network configurations, and access controls within the cloud environment.

Summary Takeaway

The Shared Responsibility Model clearly delineates security duties, with the provider securing the cloud's foundation ('OF the cloud') and the customer securing their deployed assets ('IN the cloud').
