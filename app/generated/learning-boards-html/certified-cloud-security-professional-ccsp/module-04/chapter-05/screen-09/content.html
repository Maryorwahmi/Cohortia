Kubernetes Security: Shared Responsibility in Orchestrated Environments

Understanding security roles in managed Kubernetes services and customer duties for worker nodes and applications.

Provider's Responsibility: Control Plane

  • Manages the Kubernetes control plane (API server, scheduler, etcd).
  • Ensures the security and availability of core Kubernetes components.
  • Handles patching and hardening of control plane infrastructure.

Customer's Responsibility: Worker Nodes

  • Securing the underlying virtual machines or physical servers (worker nodes).
  • Ensuring worker nodes are patched, hardened, and configured securely.
  • Managing host-based security on worker nodes.

Customer's Responsibility: Applications (Pods)

  • Securing container images for vulnerabilities.
  • Implementing Pod Security Standards and Network Policies.
  • Managing Role-Based Access Control (RBAC) for pods and users.
  • Handling secrets management for sensitive data.
Key Takeaway

In Kubernetes, customers are responsible for securing everything from the worker nodes up to their applications, while the provider secures the control plane.
