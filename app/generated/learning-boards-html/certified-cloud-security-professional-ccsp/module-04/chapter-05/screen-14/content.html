Serverless Controls

Serverless Security: Key Customer Controls

Implementing critical security measures for serverless functions, focusing on permissions, code, and data handling.

Function Permissions (IAM)

  • The most critical control: apply least privilege to function roles.
  • Over-privileged roles are a major attack vector.
  • Ensure functions only access resources they absolutely need.

Code Security

  • Ensure the function code itself is secure and free of vulnerabilities.
  • Perform static analysis and dependency scanning.
  • Follow secure coding best practices.

Input/Output Validation & Secrets Management

  • Validate all inputs to prevent injection attacks.
  • Sanitize outputs to prevent data exfiltration.
  • Securely handle sensitive data using dedicated secret stores.

Network Configuration

  • Restrict function access to private VPCs or specific network endpoints.
  • Limit outbound connectivity to only necessary services.
  • Use network controls to segment serverless functions.
Key Takeaway

Even in serverless, granular control over permissions, code, data, and network access is vital for robust security.
