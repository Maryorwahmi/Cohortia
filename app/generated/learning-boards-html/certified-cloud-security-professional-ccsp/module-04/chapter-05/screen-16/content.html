Key Concepts: Virtualization Fundamentals

Essential terms and definitions from this chapter.

Hypervisor

The software layer that creates and runs virtual machines, providing isolation between VMs and managing physical hardware resources.

VM Escape

A security vulnerability where a malicious virtual machine breaks out of its isolation and gains unauthorized access to the hypervisor or other virtual machines on the same physical host.

Hyper-jacking

An attack where an attacker takes control of the hypervisor itself, potentially gaining control over all virtual machines running on it.

Pod Security Standards (PSS)

Kubernetes policies that enforce security best practices for pods, such as preventing privileged containers and limiting host access.
