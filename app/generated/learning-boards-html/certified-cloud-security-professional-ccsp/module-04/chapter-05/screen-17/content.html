Key Concepts: Container & Serverless Security

Essential terms and definitions for modern cloud compute models.

Kubernetes Network Policies

Rules that specify how groups of pods are allowed to communicate with each other and with external network endpoints, enabling network segmentation within a cluster.

Container Runtime

The software responsible for running containers (e.g., Docker Engine, containerd), which interacts with the host OS kernel.

Ephemeral Execution Environment

A short-lived, isolated environment in which serverless functions execute, providing inherent security benefits by minimizing attack surface and state.

Defense in Depth

A security strategy that employs multiple layers of security controls to protect against various threats, ensuring that if one layer fails, others are still in place.
