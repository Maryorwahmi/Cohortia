Resilient Architectures

Multi-Availability Zone (AZ) Deployments

Building high availability within a single cloud region.

Key Characteristics

  • Physically isolated data centers within a region.
  • Independent power, cooling, and networking.
  • Protects against single data center failures.
  • Common pattern for high availability.
Concrete Example

An e-commerce application deploys its web servers across three AZs using an Auto Scaling Group. If one AZ goes offline, the load balancer automatically routes traffic to the healthy AZs, and new instances are launched to maintain capacity.

Key Takeaway

Multi-AZ deployments are crucial for in-region high availability, protecting your applications from localized data center failures and ensuring continuous operation within a single cloud region.
