Check Your Understanding: Audit Logs
Identifying the Right Azure Service

Which Azure service provides the most comprehensive audit trail for management plane activities?

  • a) Azure Network Watcher
  • b) Azure Blob Storage
  • c) Azure Activity Log
  • d) Azure Security Center

Correct Answer: c

The Activity Log records control-plane events for auditing.

Azure Activity Log
Your Source for Management Events
Control-Plane Events
Records resource creation, updates, deletions, and administrative actions.
