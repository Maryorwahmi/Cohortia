Core Concept
Identity and Access Management (IAM)
The Foundation of Cloud Security

IAM defines who can access what resources and perform which actions in the cloud.

Key Principles:

  • Least Privilege: Grant only necessary permissions. Avoid wildcards like `*`. Example: `s3:GetObject` on a specific bucket instead of `s3:*` on all buckets.
  • Role-Based Access Control (RBAC): Assign permissions to roles, then users to roles.
  • Temporary Credentials: Use roles for programmatic access; rotate keys if necessary.
  • Separation of Duties: Prevent single individuals from having excessive control.
