Enforcing Multi-Factor Authentication (MFA)
A Non-Negotiable Layer of Security

MFA adds a crucial second layer of security beyond passwords, requiring multiple verification factors.

Factors typically include:

  • Something you know (e.g., password)
  • Something you have (e.g., authenticator app code, hardware token)
  • Something you are (e.g., fingerprint - less common for cloud access)

Enforcement:

  • Mandatory for root/owner accounts and privileged IAM users.
  • Can be enforced via IAM policies (e.g., denying actions if MFA is not present).
MFA Enforcement Example
AWS IAM Policy Condition
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Deny",
      "Action": "*",
      "Resource": "*",
      "Condition": {
        "BoolIfExists": {
          "aws:MultiFactorAuthPresent": "false"
        }
      }
    }
  ]
}
This policy denies all actions if MFA is not present.
