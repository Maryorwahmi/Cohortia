Layered Defense

Subnet-Level Control: NACLs and ASGs

Stateless traffic filtering at the subnet boundary.

What are NACLs/ASGs?

Virtual firewalls that control traffic at the subnet level, providing an additional, stateless layer of network access control.

  • Stateless: Inbound and outbound rules are evaluated independently.
  • Rule Order: Rules are processed in numerical order (lowest to highest).
  • Coarse-grained: Applies to all instances within a subnet.
Use Case

Ideal for broad subnet-wide traffic policies, such as explicitly denying traffic from known malicious IP ranges.

Security Groups vs. NACLs

Security Groups

  • Stateful
  • Instance/ENI level
  • Default: Allow all outbound
  • Evaluates all rules before allowing/denying

Network ACLs

  • Stateless
  • Subnet level
  • Default: Deny all inbound/outbound
  • Processes rules in order (lowest to highest)
Both are crucial for a defense-in-depth strategy, but serve different purposes.
Key Takeaway

NACLs provide a stateless, subnet-level firewall, offering an additional layer of defense that complements the instance-level control of Security Groups.
