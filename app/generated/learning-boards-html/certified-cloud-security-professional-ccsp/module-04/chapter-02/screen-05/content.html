Design Principle

Network Segmentation with Subnets

Dividing VPCs into subnets based on trust levels and application tiers.

Why Segment Your Network?

Segmentation is crucial for limiting the 'blast radius' of a security incident and enforcing the principle of least privilege.

  • Isolation: Prevents lateral movement of attackers.
  • Control: Granular traffic management between tiers.
  • Compliance: Helps meet regulatory requirements.
Common Mistake

Placing all resources (web servers, app servers, databases) in a single subnet, which eliminates isolation benefits and increases risk.

Subnet Tiers for a Three-Tier Application

Public Subnet

Web Servers (Internet-facing)

Private Subnet (Application)

Application Servers (Internal access only)

Private Subnet (Database)

Databases (Highly restricted access)

Key Takeaway

Effective subnet segmentation is a critical security control, isolating resources by trust level and limiting the potential impact of a breach.
