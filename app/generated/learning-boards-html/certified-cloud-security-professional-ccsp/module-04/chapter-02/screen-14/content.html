Chapter Summary

Essential Cloud Network Security Concepts

Foundational Building Blocks

VPC/VNet

A logically isolated virtual network dedicated to your cloud account, where you launch your cloud resources.

Subnet

A subdivision of a VPC/VNet, used for network segmentation based on trust levels and application tiers.

Security Group/NSG

A stateful virtual firewall that controls inbound and outbound traffic for individual instances or network interfaces.

Summary Takeaway

VPCs/VNets, subnets, and security groups form the fundamental layers for building isolated, segmented, and access-controlled cloud networks.
