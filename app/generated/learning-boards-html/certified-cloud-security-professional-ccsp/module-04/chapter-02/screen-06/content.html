Access Control

Instance-Level Firewalls: Security Groups

Stateful virtual firewalls for individual cloud resources.

What are Security Groups/NSGs?

Virtual firewalls that control inbound and outbound traffic for individual instances or network interfaces.

  • Stateful: Automatically allows return traffic for established connections.
  • Granular: Rules apply directly to specific resources.
  • Default Deny: All traffic is denied unless explicitly allowed.
Key Principle

Always apply the principle of least privilege: grant only the necessary network access, and no more.

Security Group Rule Examples

Web Server SG (Inbound)

Allow HTTP (Port 80) from 0.0.0.0/0

Allow HTTPS (Port 443) from 0.0.0.0/0

Database Server SG (Inbound)

Allow MySQL (Port 3306) from Web Server SG

(No direct internet access)

Admin Access SG (Inbound)

Allow SSH (Port 22) from Trusted Office IP (e.g., 203.0.113.5/32)

Key Takeaway

Security Groups are essential for controlling traffic to individual cloud resources, acting as stateful firewalls that enforce granular access policies.
