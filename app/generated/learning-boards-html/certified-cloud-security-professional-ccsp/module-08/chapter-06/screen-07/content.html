Module 8 › Chapter 8.6 › Digital Signatures
Core Concept
Digital Signatures
Authenticity, integrity, and non-repudiation for digital documents.
Key Takeaway

Proves who sent a message and that it hasn't been altered, preventing the sender from denying it.

Misconception

A digital signature is not the same as encrypting a document with a private key for confidentiality; it's about proving origin and integrity.

Process
Hash + Private Key Encrypt

The sender hashes the document, then encrypts that hash with their private key. The recipient verifies by hashing the document and decrypting the signature with the sender's public key.

Properties
Authenticity, Integrity, Non-repudiation
Use Case
Code Signing
