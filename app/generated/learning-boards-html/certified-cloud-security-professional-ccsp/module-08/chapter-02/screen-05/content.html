DR Strategy

Backup and Restore

The foundational and most cost-effective cloud DR approach

How it Works

  • •Regularly back up data and configurations.
  • •Store backups in secure, separate cloud object storage.
  • •In a disaster, provision new infrastructure and restore from backups.
Key Takeaway

This strategy is ideal for non-critical applications where cost is a primary concern and longer recovery times are acceptable.

Example Scenario

Backing up an EC2 instance's EBS volumes as snapshots and storing database backups in S3 for a development environment.

Strategy Trade-offs

Pros: Low Cost

Minimal ongoing infrastructure costs.

Cons: High RTO

Recovery can take hours or days.

Cons: High RPO

Data loss up to the last backup.

Best For: Non-Critical Apps

Acceptable downtime and data loss.
