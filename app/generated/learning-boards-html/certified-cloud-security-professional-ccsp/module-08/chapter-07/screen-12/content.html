Practical Application

Implementing Key Access Control

A real-world example with AWS IAM policy for KMS

Principle of Least Privilege

Grant only the necessary permissions for an application to perform its function, nothing more.

Security Risk

Granting `kms:DeleteKey` to an application role could lead to irreversible data loss if compromised.

Key Takeaway

IAM policies enforce least privilege for KMS keys, granting only necessary actions and preventing destructive operations.

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Principal": {
                "AWS": "arn:aws:iam::123456789012:role/MyApplicationRole"
            },
            "Action": [
                "kms:Encrypt",
                "kms:Decrypt",
                "kms:ReEncrypt*",
                "kms:GenerateDataKey*",
                "kms:DescribeKey"
            ],
            "Resource": "*"
        }
    ]
