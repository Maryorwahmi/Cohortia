Core Concept

Data States: In Transit vs. At Rest

Understanding where data is vulnerable and why encryption is essential.

Data In Transit

Data actively moving between systems, such as client-server communication or inter-service calls. Vulnerable to eavesdropping and tampering.

Data At Rest

Data stored persistently on storage mediums like databases, object storage, or block volumes. Vulnerable to unauthorized access if the storage is compromised.

Key Takeaway

Comprehensive cloud security requires distinct encryption strategies for data in motion and data in storage, addressing different threat vectors.

Data In Transit

Data moving across networks (e.g., client to server, service to service).

Threat: Eavesdropping, Tampering

Data At Rest

Data stored persistently (e.g., databases, object storage, backups).

Threat: Unauthorized Access, Theft
