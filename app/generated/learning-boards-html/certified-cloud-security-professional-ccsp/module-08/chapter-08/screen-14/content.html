Key Concepts

Essential terms to remember from this chapter

Encryption in Transit

Protecting data as it moves across networks between systems.

Encryption At Rest

Protecting data when it is stored on persistent storage mediums.

TLS/SSL

Protocols for securing network communications, commonly used for HTTPS.

These concepts form the bedrock of data protection, ensuring confidentiality and integrity across all data states in the cloud.
