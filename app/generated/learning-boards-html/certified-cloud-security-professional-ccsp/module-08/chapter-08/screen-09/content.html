At Rest Encryption

Protecting Stored Data with Server-Side Encryption

Encrypting objects in cloud storage like S3 and Azure Blob Storage.

Server-Side Encryption (SSE)

The cloud provider encrypts data at the object level as it's written to disk and decrypts it when read, protecting against storage compromise.

Key Management Options

SSE offers different key management options: SSE-S3 (S3-managed), SSE-KMS (KMS-managed), and SSE-C (customer-provided keys).

Key Takeaway

SSE is a flexible solution for data at rest, allowing you to choose the level of key management control that best fits your security and compliance needs.

SSE-S3

Keys are managed entirely by the cloud storage service (e.g., Amazon S3). Simplest to implement, minimal control over keys.

SSE-KMS

Keys are managed by a Key Management Service (e.g., AWS KMS, Azure Key Vault). Provides more control, auditability, and integration with IAM.

SSE-C

You provide the encryption key to the cloud service. You are responsible for key management, offering high control but increased operational burden.
