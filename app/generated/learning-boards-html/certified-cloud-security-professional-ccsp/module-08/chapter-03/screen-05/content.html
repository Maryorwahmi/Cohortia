Core Concept
Image-Based Backups
Capturing the entire VM state for rapid deployment.

Image-based backups (like AMIs or VM Images) capture the entire state of a virtual machine: OS, applications, and data.

They enable rapid provisioning of new, identical instances, crucial for disaster recovery.

Useful for creating standardized 'golden images' for consistent deployments.

Use Case

Rapidly deploying new instances after a disaster or creating a standardized server template.

AWS CLI Example
aws ec2 create-image \
  --instance-id i-0abcdef1234567890 \
  --name "MyWebServer-DR-Image" \
  --description "Image for DR purposes"
Creating an AMI from an existing instance.
