Data Replication Strategies
Ensuring availability and low RPO through continuous data copying.

Replication continuously copies data for high availability and low RPO.

Database Replication: Multi-AZ for HA, cross-region replicas for DR.

Object Storage Replication: S3 Cross-Region Replication (CRR) for durability across geographies.

Protects against failures and regional outages.

Key Benefit

Achieve near-zero data loss (RPO) and rapid failover capabilities by keeping data synchronized across locations.

S3 Cross-Region Replication (CRR)
# Simplified CloudFormation snippet for S3 CRR
Resources:
  SourceBucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: my-source-bucket-prod
      ReplicationConfiguration:
        Role: !GetAtt ReplicationRole.Arn
        Rules:
          - Id: MyReplicationRule
            Status: Enabled
            Destination:
              Bucket: !GetAtt DestinationBucket.Arn
              StorageClass: STANDARD
  DestinationBucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: my-destination-bucket-dr
Automating object replication between buckets in different regions.
