Core Concept
Snapshot Backups
Point-in-time copies of block storage for quick recovery.

Snapshots are incremental point-in-time copies of block storage volumes (like AWS EBS or Azure Disks).

They store only changed blocks since the last snapshot, making them storage-efficient.

Ideal for quickly restoring a volume to a previous state, such as after a failed update or data corruption.

Example

Recovering a corrupted database volume or rolling back an OS update on a VM.

AWS CLI Example
aws ec2 create-snapshot \
  --volume-id vol-0abcdef1234567890 \
  --description "My critical data volume snapshot"
Initiating a snapshot for a specific volume.
