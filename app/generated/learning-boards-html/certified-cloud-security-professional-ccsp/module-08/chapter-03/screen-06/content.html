Core Concept
Object Storage Backups
Durable, scalable storage for files, databases, and application data.

Utilizes services like Amazon S3, Azure Blob Storage, or Google Cloud Storage for backups.

Ideal for backing up files, logical database dumps, application logs, and user-generated content.

Offers high durability and cost-effectiveness, making it suitable for long-term archival.

Example

Storing database dumps, application logs, or user-uploaded content for long-term retention.

AWS CLI Example
aws s3 sync /my/local/data \
  s3://my-dr-bucket/backups/
Synchronizing local data to an S3 bucket.
