Hands-on Activity
Configuring S3 Object Lock
Implementing immutable backups for compliance and ransomware protection.

Objective: Ensure critical logs are immutable for 7 years.

Steps: Create S3 bucket with Object Lock, upload file, apply 7-year Compliance mode retention.

Verification: Attempt to delete the object and reduce retention period; observe expected failures.

This practical exercise reinforces the security benefits of immutable storage.

Key Takeaway

Successfully configuring immutable storage demonstrates a robust defense against data tampering and unauthorized deletion.

AWS CLI Commands
# Create bucket with Object Lock enabled
aws s3api create-bucket --bucket my-immutable-logs-bucket-unique-name-12345 --object-lock-enabled-for-bucket --region us-east-1

# Upload file and apply 7-year Compliance mode retention
aws s3api put-object --bucket my-immutable-logs-bucket-unique-name-12345 \
  --key transaction_log_2023.txt \
  --body transaction_log_2023.txt \
  --object-lock-mode COMPLIANCE \
  --object-lock-retain-until-date "2030-10-27T00:00:00Z"
Note: Replace bucket name and date as needed.
