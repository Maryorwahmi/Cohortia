Key Concepts

Essential terms to remember for cloud resilience

High Availability (HA)

A system's ability to operate continuously without failure for a long time, minimizing downtime.

Fault Tolerance (FT)

A system's ability to continue operating without interruption or data loss even when critical components fail.

Availability Zone (AZ)

Isolated data centers within a cloud region, providing redundancy against localized failures.

Summary Takeaway

High Availability and Fault Tolerance are critical for cloud resilience, achieved by leveraging cloud infrastructure like Availability Zones and Regions to minimize downtime and prevent data loss.
