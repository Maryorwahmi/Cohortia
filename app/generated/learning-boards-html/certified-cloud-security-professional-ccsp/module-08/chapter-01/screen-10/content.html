What Cloud Providers Secure and Make Resilient

Responsibility *for* the cloud infrastructure

Provider's Core Responsibilities

Cloud providers are responsible *for* the security and resilience of the underlying cloud infrastructure:

  • •**Physical Security:** Data centers, facilities, and hardware.
  • •**Global Network:** Network infrastructure, redundancy, and connectivity.
  • •**Underlying Hardware:** Compute, storage, and networking hardware.
  • •**Hypervisor:** The virtualization layer that runs virtual machines.
Key Insight

Cloud providers build highly resilient infrastructure to withstand common failures and regional disruptions, but this is at the foundational level.

Example: Database Instance

  • •**Provider ensures:** Robust underlying hardware, redundant power/cooling in data centers, reliable network connectivity.
  • •**Provider's goal:** To keep the core database service available and resilient at the infrastructure layer.
  • •**What's NOT covered:** Your specific database configuration, backups, or application-level failover.
Analogy

The cloud provider builds a secure, earthquake-resistant building, but you're responsible for securing the valuables inside your apartment.

Key Takeaway

Cloud providers ensure the resilience of the foundational cloud infrastructure, including physical security, network, hardware, and hypervisor, but not the customer's specific workloads.
