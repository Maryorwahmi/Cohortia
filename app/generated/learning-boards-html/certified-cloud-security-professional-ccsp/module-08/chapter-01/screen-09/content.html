The Shared Responsibility Model and BC/DR

Clarifying roles in cloud resilience

Shared Responsibility Overview

A framework outlining the security and resilience responsibilities of both the cloud provider and the cloud customer.

  • •Provider is responsible *for* the cloud.
  • •Customer is responsible *in* the cloud.
  • •Crucial for effective BC/DR planning.
Common Mistake

Assuming the cloud provider handles all BC/DR. This misunderstanding creates significant security and resilience gaps.

Impact on BC/DR

  • •**Provider:** Ensures infrastructure resilience (physical security, global network, hardware).
  • •**Customer:** Configures applications, data, OS, network for high availability and recovery.
  • •Requires active planning and implementation from the customer.
Example Scenario

Cloud provider ensures data center power, but you must configure database backups and cross-region replication for your data.

Key Takeaway

The Shared Responsibility Model mandates that while cloud providers secure the underlying infrastructure, customers are responsible for BC/DR of their data, applications, and configurations within the cloud.
