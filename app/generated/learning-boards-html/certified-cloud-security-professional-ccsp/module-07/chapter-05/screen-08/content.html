DR Strategy

Backup and Restore

The Foundational Cloud DR Approach

How it Works

  • Mechanism: Automate snapshots of VMs, databases, and storage volumes.
  • Storage: Backups stored in different regions for geographical resilience.
  • Recovery: Launch new resources from these backups after a disaster.
  • RTO/RPO: Typically higher compared to other methods due to restoration time.

Best Use Case

Suitable for non-critical applications or data that can tolerate longer downtime and some data loss.

AWS CLI Example
# Example AWS CLI command to create an EBS snapshot (for backup)aws ec2 create-snapshot --volume-id <YOUR_VOLUME_ID> --description "Backup snapshot for DR"

Explanation: This command creates a point-in-time snapshot of an Elastic Block Store (EBS) volume. This snapshot can later be used to restore the volume or create a new one, forming the basis of a backup and restore DR strategy.

Key Takeaway

Backup and Restore is a cost-effective, foundational DR strategy in the cloud, best suited for scenarios where higher RTO and RPO are acceptable.
