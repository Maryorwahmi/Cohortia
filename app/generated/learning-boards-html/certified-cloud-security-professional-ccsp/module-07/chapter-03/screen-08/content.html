Configuring CloudTrail Logging (AWS Example)

Directing API Activity Logs to CloudWatch for Analysis

# Example AWS CLI command to configure CloudTrail to send logs to CloudWatch Logs# This assumes you have a CloudTrail trail already created.# First, get the ARN of your existing CloudTrail trail# aws cloudtrail describe-trails --query "trailList[?Name=='my-security-trail'].TrailARN" --output text# Then, update the trail to send logs to a CloudWatch Logs log group# You need a Log Group ARN and an IAM Role ARN that CloudTrail can assume to write to CloudWatch Logs.aws cloudtrail update-trail \  --name my-security-trail \  --cloud-watch-logs-log-group-arn arn:aws:logs:us-east-1:123456789012:log-group:CloudTrail/DefaultLogGroup \  --cloud-watch-logs-role-arn arn:aws:iam::123456789012:role/CloudTrailToCloudWatchLogsRole
Key Takeaway

Streaming CloudTrail logs to CloudWatch Logs enables real-time monitoring and alerting on API activity, crucial for security.

Command Breakdown

`aws cloudtrail update-trail`

Modifies an existing CloudTrail trail's configuration.

`--name my-security-trail`

Specifies the name of the CloudTrail trail to update.

`--cloud-watch-logs-log-group-arn`

The ARN of the CloudWatch Logs log group where logs will be sent.

`--cloud-watch-logs-role-arn`

The ARN of the IAM role CloudTrail assumes to write to CloudWatch Logs.

Pro-Tip

Ensure the IAM role has the necessary permissions (`logs:PutLogEvents`) to write to the specified CloudWatch Logs log group.
