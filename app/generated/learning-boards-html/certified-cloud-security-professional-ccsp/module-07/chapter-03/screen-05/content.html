API Activity Logs: The Management Plane View

Auditing Every Interaction with Your Cloud Resources

What They Capture

  • •
    Who: The identity that made the API call (user, role, service).
  • •
    When: The exact timestamp of the API call.
  • •
    Where: Source IP address of the request.
  • •
    What: The specific API action performed and the affected resource.

Example: A log entry showing an IAM user 'admin-dev' attempting to delete a production S3 bucket from an unusual IP address.

Key Takeaway

API activity logs are the definitive source for auditing control plane actions, essential for detecting unauthorized changes and security incidents.

Cloud Provider Examples

AWS CloudTrail

Records API calls for AWS services, delivering logs to S3 and CloudWatch.

Azure Activity Logs

Provides insight into subscription-level events in Azure, including resource creation/deletion.

Pro-Tip: Always enable API activity logging across all regions and accounts to ensure full visibility and compliance.

Misconception

API logs only capture management events. They also capture data plane operations for services like S3, providing deeper insights.
