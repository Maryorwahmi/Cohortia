Log Types

Resource & Application Logs: Operational and Code Insights

Diving Deeper into Service Behavior and Application Events

Resource Logs: Service-Specific Data

  • •
    VPC Flow Logs: Network traffic patterns (source/dest IP, ports, protocols).
  • •
    Database Logs: Queries, connection attempts, performance metrics.
  • •
    Load Balancer Logs: Client IPs, request distribution, HTTP status codes.

Example: A VPC Flow Log showing an unusual spike in outbound traffic to an unknown IP address, potentially indicating data exfiltration.

Key Takeaway

Resource logs provide operational insights into cloud services, while application logs offer visibility into application-level events and vulnerabilities.

Application Logs: Code-Level Events

Code Insights

Errors, warnings, and custom events from your applications.

These logs are generated by your custom applications running on various cloud compute services (EC2, containers, serverless). They are crucial for debugging, performance monitoring, and identifying application-level security vulnerabilities like SQL injection attempts or authentication failures.

Misconception

Application logs are automatically collected by cloud providers. Often, you need to configure your applications to send logs to a centralized cloud logging service.
