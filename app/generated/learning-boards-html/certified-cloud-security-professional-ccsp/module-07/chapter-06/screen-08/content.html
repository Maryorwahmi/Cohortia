Method Overview

Serverless Function Forensics

Investigating serverless functions requires focusing on logs and code due to their stateless nature.

  • •**Invocation Logs:** Collect detailed logs (CloudWatch, Azure Monitor) for each function execution.
  • •**API Activity Logs:** Review logs (CloudTrail, Azure Activity Log) for deployment and modification events.
  • •**Source Code Analysis:** Examine the function's code for vulnerabilities or malicious logic.
Key Takeaway

Serverless forensics relies heavily on comprehensive logging and source code analysis, as there is no persistent state to acquire.

**Example:** A malicious serverless function is deployed. Investigators analyze CloudWatch Logs to see its invocation patterns and CloudTrail logs to identify who deployed it and when, then review the source code for vulnerabilities.

Pro Tip

Ensure comprehensive logging is enabled for all serverless functions and integrated with a centralized log management solution for efficient forensic analysis.
