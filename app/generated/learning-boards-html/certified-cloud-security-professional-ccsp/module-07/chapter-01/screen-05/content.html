Fundamental Principle

The Shared Responsibility Model: Core Principles

Delineating security obligations between CSPs and customers.

Key Aspects

  • Security OF the Cloud: CSP's responsibility (infrastructure, facilities, hardware).
  • Security IN the Cloud: Customer's responsibility (data, applications, OS, network config, IAM).
  • Varies by Service: Specific responsibilities can differ based on the cloud service model (IaaS, PaaS, SaaS).
  • Crucial for Compliance: Essential for audit and regulatory adherence.
Key Takeaway

Always understand and verify your specific security responsibilities for each cloud service to prevent critical security gaps.

Common Mistake

Assuming the cloud provider handles all security, leading to customer-side misconfigurations or unsecured applications.

Shared Responsibility Breakdown

Cloud Service Provider (CSP)

Security OF the Cloud: Global infrastructure, regions, availability zones, edge locations, compute, storage, database, networking, virtualization.

Customer

Security IN the Cloud: Customer data, platform, applications, operating systems, network and firewall configurations, identity and access management (IAM).
