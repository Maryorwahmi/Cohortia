Fundamental Principle

The Shared Responsibility Model

Clarifying Roles in Cloud Security and Compliance

CSP Responsibility: Security of the Cloud

The cloud provider is responsible for the underlying infrastructure, physical security, network, virtualization, and the services themselves. This includes global infrastructure and core services.

Customer Responsibility: Security in the Cloud

The customer is accountable for their data, applications, operating systems, network configurations, and access management within the cloud environment. This includes encryption, patching, and identity management.

Shared Responsibility

The model clarifies that while the CSP secures the infrastructure, the customer is responsible for securing their data and applications within that infrastructure.

Key Takeaway

Misunderstanding the shared responsibility model is a common compliance mistake; customers must actively secure their cloud workloads.
