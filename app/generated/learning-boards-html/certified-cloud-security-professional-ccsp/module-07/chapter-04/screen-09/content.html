Identifying Cloud-Specific Attack Patterns
Practical Correlation Rules for Common Cloud Threats
Unauthorized Resource Deletion

Detects multiple 'Delete' operations on critical resources (e.g., S3 buckets, EC2 instances) by a non-administrative user, indicating potential compromise or sabotage.

Suspicious New IAM Activity

Identifies the creation of new IAM users or roles followed by unusual or high-privilege activity from those new identities, suggesting privilege escalation or backdoor creation.

Malicious IP Network Traffic

Detects network traffic from an EC2 instance or other cloud resource to known malicious IP addresses, indicating potential compromise or command-and-control communication.

Security Group Rule Changes

Alerts on changes to security group rules that expose sensitive ports (e.g., 22, 3389, 443) to the internet, potentially creating new attack surfaces.

Unusual Geographic Login

Flags administrative user logins from unusual or previously unseen geographic locations, indicating potential credential compromise or unauthorized access.

Key Takeaway

Implementing cloud-specific correlation rules is vital for detecting unique attack patterns and suspicious activities prevalent in dynamic cloud environments, enhancing proactive threat detection.
