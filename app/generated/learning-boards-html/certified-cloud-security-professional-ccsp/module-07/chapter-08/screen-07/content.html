CWPP Capabilities

CWPP in Action: Protecting Diverse Workloads

Defending against malware, exploits, and unauthorized activities within your compute resources

Key Questions CWPP Answers

  • • Is malware running on my EC2 instance?
  • • Is this container making suspicious outbound connections?
  • • Is my serverless function being exploited?
  • • Are there unauthorized processes executing?
Key Takeaway

CWPP provides granular, real-time protection against active threats, complementing CSPM's focus on configuration security.

Car Analogy: CWPP as the Internal Alarm

If CSPM checks if the car's doors are locked (configuration), CWPP is like:

  • • An alarm system detecting unauthorized entry.
  • • An immobilizer preventing the engine from starting without a key.
  • • Sensors detecting suspicious activity *inside* the vehicle while it's running.

It protects against active threats even if initial perimeter defenses are bypassed.

Common Threats Addressed

Malware, zero-day exploits, unauthorized process execution, network-based attacks within the workload.
