Key Concepts

Essential terms to remember from this chapter

Cloud Security Posture Management (CSPM)

Continuously monitors cloud configurations for misconfigurations, compliance violations, and security risks across the control plane.

Cloud Workload Protection Platform (CWPP)

Provides runtime protection and deep security for diverse cloud workloads (VMs, containers, serverless functions) within the data plane.

Control Plane

The layer of cloud infrastructure responsible for managing and orchestrating resources (e.g., API calls, configuration changes).

Summary Takeaway

CSPM and CWPP are distinct but complementary, providing a layered defense by securing cloud configurations and protecting running workloads.
