Customer's Ultimate Responsibility

Understanding the shared responsibility model in cloud compliance.

Shared Responsibility Model

A framework outlining the security responsibilities of the cloud service provider (CSP) and the customer.

Key Divisions
  • CSP: Security *of* the cloud (infrastructure, hardware, facilities).
  • Customer: Security *in* the cloud (data, applications, OS, network config, access).
  • Ultimate accountability for data and compliance rests with the customer.
Compliance Accountability

Even if a CSP is certified for a regulation like GDPR, the customer is responsible for ensuring their specific use of the cloud services complies with that regulation.

Example: Data Exposure

If a customer misconfigures an S3 bucket to be publicly accessible, exposing sensitive data, the customer is liable for any resulting data breach or compliance violation, not the CSP.

Common Pitfall

Relying solely on CSP certifications without understanding and implementing your own security controls and configurations. Certifications are a starting point, not a complete solution.

Key Takeaway

The shared responsibility model places ultimate accountability for data and compliance squarely on the customer, demanding active management of security *in* the cloud.
