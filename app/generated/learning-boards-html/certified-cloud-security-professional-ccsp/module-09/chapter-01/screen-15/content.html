Key Concepts

Critical frameworks and models for cloud compliance.

CLOUD Act

U.S. law allowing U.S. law enforcement to compel U.S.-based cloud providers to disclose data globally.

GDPR Extraterritoriality

The principle that GDPR applies to organizations processing EU residents' personal data, regardless of their location.

Shared Responsibility Model

A framework outlining security responsibilities between CSP and customer, with the customer accountable for security *in* the cloud.

Summary Takeaway

These frameworks and models define the global compliance landscape and delineate accountability, making them essential for effective cloud security and risk management.
