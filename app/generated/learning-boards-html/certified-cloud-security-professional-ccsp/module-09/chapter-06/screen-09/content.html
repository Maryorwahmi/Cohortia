Strategies for IaaS Environments

Acquiring Evidence from Virtual Machines and Networks

IaaS Control

More control over OS and virtual disks allows for traditional forensic techniques like disk imaging.

Key Takeaway

For IaaS, leverage virtual disk snapshots for forensic imaging and network flow logs for communication analysis.

Common Mistake

Attempting live forensic acquisition on a compromised instance, which can alter evidence and compromise integrity.

IaaS Evidence Acquisition Steps

1. Create Volume Snapshot

Take a point-in-time, read-only copy of the virtual disk (e.g., EBS volume).

2. Create New Volume from Snapshot

Provision a new, isolated volume from the forensic snapshot.

3. Attach to Forensic Instance

Mount the new volume to a clean, secure forensic analysis VM.

4. Analyze Network Flow Logs

Review VPC Flow Logs or Network Watcher logs for network communication details.
