Cloud Forensics

Multi-tenancy & API-driven Infrastructure

Unique Challenges in Cloud Investigations

Multi-tenancy Impact

Isolating forensic data for a single customer in shared environments can be complex and raise privacy concerns.

Key Takeaway

Cloud investigations require careful data isolation in multi-tenant setups and a strong reliance on API logs for evidence.

Example: API Call Logs

Instead of OS logs, you'd analyze AWS CloudTrail or Azure Activity Log to track management plane activities and configuration changes.

API-Driven Evidence

API Call Logs

Primary source of evidence for most cloud operations (e.g., AWS CloudTrail, Azure Activity Log).

Management Plane Focus

Logs detail actions taken on cloud resources, not necessarily internal system states.

Granularity Limitations

May not provide the same depth of detail as direct OS-level forensic tools.
