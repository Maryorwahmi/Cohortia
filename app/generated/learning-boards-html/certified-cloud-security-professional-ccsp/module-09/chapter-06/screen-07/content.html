Cloud Forensics

Distributed Environments & Shared Responsibility

Navigating Evidence Across Cloud Boundaries

Distributed Evidence

Evidence can be spread across multiple VMs, storage services, network logs, and geographical regions, complicating collection.

Key Takeaway

Cloud forensics requires understanding distributed data locations and working within CSP-defined access boundaries.

Example: Multi-Region Data

A single application's logs might be in US-East, database backups in EU-West, and user-uploaded files in Asia-Pacific, all needing coordinated collection.

Shared Responsibility Impact

CSP Responsibility

Security OF the cloud (physical infrastructure, hypervisor).

Customer Responsibility

Security IN the cloud (data, applications, network configuration).

Limited CSP Access

Customers cannot directly access CSP infrastructure for forensic imaging.
