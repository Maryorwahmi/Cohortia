CSA STAR Program: Tiered Assurance

Documenting and Evaluating Cloud Security Controls

What is CSA STAR?

The Cloud Security Alliance (CSA) STAR (Security, Trust & Assurance Registry) program offers a tiered approach to cloud security assurance. It combines self-assessments, third-party attestations, and continuous monitoring.

Purpose

Transparency for CSPs, evaluation for customers.

Key Benefit

Flexible assurance levels for diverse needs.

Key Takeaway

CSA STAR provides a structured way for CSPs to demonstrate security and for customers to assess it, offering increasing levels of assurance.

CSA STAR Assurance Levels
Level 1

Self-Assessment

CSPs submit a completed Consensus Assessments Initiative Questionnaire (CAIQ) based on the CSA Cloud Controls Matrix. Basic transparency.

Level 2

Third-party attestations leveraging existing certifications like SOC 2 or ISO 27001. Higher assurance.

Level 3

Continuous Monitoring

The highest level of assurance, involving ongoing, real-time monitoring of security controls and compliance.
