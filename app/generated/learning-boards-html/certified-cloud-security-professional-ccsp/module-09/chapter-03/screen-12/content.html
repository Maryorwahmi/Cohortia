Key Concepts

Essential terms and ideas from this chapter.

Service Level Agreement (SLA)

A contract defining the level of service expected from a provider, outlining metrics like uptime, performance, and responsibilities.

Data Processing Addendum (DPA)

A legally binding document specifying terms for processing personal data, crucial under regulations like GDPR, detailing controller and processor responsibilities.

Shared Responsibility Model

A framework clarifying security responsibilities: CSP for security *of* the cloud, customer for security *in* the cloud.

Summary Takeaway

Understanding SLAs, DPAs, and the Shared Responsibility Model is fundamental to establishing a secure and compliant cloud environment.
