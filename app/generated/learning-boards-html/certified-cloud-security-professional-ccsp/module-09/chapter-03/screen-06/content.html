Fundamental Principle

Navigating the Shared Responsibility Model

Understanding who is responsible for what is key to cloud security.

CSP: Security *of* the Cloud

The Cloud Service Provider (CSP) is responsible for protecting the infrastructure that runs all of the services offered in the cloud.

  • **Physical Infrastructure:** Data centers, hardware, networking.
  • **Virtualization:** Hypervisors, underlying compute, storage, and network fabric.
  • **Global Infrastructure:** Regions, Availability Zones, Edge Locations.
  • **Example:** Ensuring the physical security of data centers and patching hypervisor software.
Key Takeaway

The Shared Responsibility Model clarifies that the CSP secures 'of the cloud' (infrastructure), while the customer secures 'in the cloud' (data, applications, configuration).

Customer: Security *in* the Cloud

The customer is responsible for securing their data, applications, and configurations within the cloud environment.

  • **Data:** Encryption, access controls, backups.
  • **Applications:** Application security, patching, vulnerability management.
  • **Operating Systems:** OS patching, configuration, host-based firewalls.
  • **Network Configuration:** Security groups, network access control lists (NACLs), VPNs.
  • **Identity & Access Management (IAM):** User management, permissions, multi-factor authentication.
Common Mistake

Many organizations mistakenly assume that by outsourcing to a cloud provider, all security responsibilities are transferred, leading to critical security gaps.
