Module 8 › Chapter 8.1 › Choosing the Right Target
Target Options
Match compatibility needs with operational objectives.
Azure SQL Database (PaaS)
Best for modern cloud apps without server-level dependencies; highest managed service benefits.
Azure SQL Managed Instance
Offers broad compatibility while providing many PaaS benefits for easier migrations from on-premises.
SQL Server on VM
Lift-and-shift option for maximum compatibility and OS-level control at the cost of managed features.
Decision Example
DMA flags CLR assemblies and linked servers; Azure Migrate shows steady CPU and memory underutilization.
Option 1
Refactor CLR to T-SQL and move to Azure SQL Database — lowest operational overhead but requires code change.
Option 2
Choose Managed Instance to preserve compatibility with minimal refactor if other server features are used.
Key Takeaway

Compatibility findings and remediation effort should drive whether you accept PaaS or choose a more compatible hosting option.
