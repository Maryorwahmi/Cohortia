Module 8 › Chapter 8.1 › Pre-migration Assessment
Definition & Scope
Discovery, assessment, and planning form the scope of pre-migration work.
Discovery
Inventory servers, databases, and application dependencies to define scope and stakeholders.
Assessment
Run DMA and related checks to find breaking changes, behavior differences, and performance constraints.
Planning
Translate findings into remediation tasks, testing plans, and a migration approach that fits downtime needs.
Concrete Example
On-prem SQL Server with CLR assemblies and SQL Agent jobs.
Finding
CLR assemblies not supported in Azure SQL Database.
Remediation Options
Refactor CLR logic to T-SQL, move logic to application code, or choose Managed Instance/VM.
Key Takeaway
Assessment lets you choose the least-disruptive remediation and target service before migration.
