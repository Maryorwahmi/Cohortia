Module 8 › Chapter 8.1 › Migration Strategies
Offline Migration
Backup/restore or export/import requiring downtime. Useful for test/dev or low-impact apps.
Online Migration
Continuous synchronization to minimize downtime, typically using DMS for cutover-ready replication.
Hybrid Migration
Seed data using a bulk method, then use replication for final delta to shorten cutover windows.
Example
Use DMS continuous replication for mission-critical systems and schedule a short cutover once sync is complete.
Common Mistake
Assuming online migration eliminates the need for end-to-end testing or rollback planning.
Key Takeaway

Strategy choice depends on downtime tolerance, size, and test readiness. Always include rollback and test windows.
