Module 8 › Chapter 8.1 › Testing & Rollback
Testing Checklist
  • Verify backups are restorable to the target environment.
  • Run functional test suites against the migrated staging database.
  • Execute representative load and performance tests to validate resource choices.
  • Confirm scheduled jobs and external dependencies operate as expected.
Rollback Criteria
Define clear thresholds for errors, latency, and data divergence that trigger rollback actions.
Example Scenario
Staging migration shows a stored procedure returns different results under a rare input pattern.
Action
Investigate behavior change, decide to fix or rollback, and update the migration backlog with root cause and test cases.
Key Takeaway

Testing and rollback plans prevent surprises in production; rehearse them in staging before cutover.
