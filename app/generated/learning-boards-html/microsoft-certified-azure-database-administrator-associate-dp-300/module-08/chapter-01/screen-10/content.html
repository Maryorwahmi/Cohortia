How Azure Migrate Rightsizing Works
Analyze historical metrics, recommend SKUs, and estimate costs.
Metrics Used
CPU, memory, disk I/O, and historical peaks used to propose appropriate sizes.
Adjustments
Consider peak workloads, maintenance windows, and planned growth when selecting SKUs.
Example
Historic average CPU 30%, average memory 40%, with short spikes to 80%.
Recommendation
Choose a SKU with headroom for spikes and enable scaling for sustained growth.
Key Takeaway

Treat rightsizing as a starting point; validate with tests and plan for scaling based on future demand.
