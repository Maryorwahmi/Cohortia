Module 8 › Chapter 8.1 › Azure Migrate vs DMA
Azure Migrate
Discovery, dependency mapping, historical performance and rightsizing.
  • Server and application discovery across the estate.
  • Dependency mapping between apps and databases.
  • Rightsizing recommendations using historical metrics.
Example
Discovering SQL clusters and selecting Managed Instance vs VM based on sustained CPU and memory trends.
Data Migration Assistant (DMA)
Deep compatibility analysis at the database level with actionable remediation suggestions.
  • Schema and object compatibility checks.
  • Breaking and behavior change identification.
  • Exportable reports for remediation planning.
Example
DMA finds unsupported CLR code and suggests refactor or alternate hosting choices.
Common Mistake

Relying on DMA alone and skipping estate discovery can miss dependencies and lead to an incomplete migration plan.
