Module 8 › Chapter 8.1 › DMA Hands-on
Step-by-step
  1. Install Data Migration Assistant on a machine that can reach your SQL Server.
  2. Create a new Assessment project and choose source and target server types.
  3. Select target version and enable compatibility and feature parity checks.
  4. Connect to the source server and pick databases for assessment, e.g., AdventureWorks2019.
  5. Start the assessment and review the Compatibility and Feature Parity tabs.
  6. Export the report and convert findings into a prioritized remediation backlog.
