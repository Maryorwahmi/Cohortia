Module 8 › Chapter 8.1 › Network & Security
Connectivity Checklist
  • Ensure assessment/migration machine can reach source SQL Server and Azure endpoints.
  • Open firewall ports and add IP allow lists for assessment tools.
  • Confirm authentication and encryption settings are compatible with tools.
Bandwidth & Transfer Strategy
Plan for initial seed, delta sync, and final cutover based on available throughput.
Example
Use a bulk export to seed large databases, then use continuous replication for deltas to shorten cutover windows.
Common Mistake

Treating migration as purely an application problem and underestimating network and security prerequisites causes delays.
