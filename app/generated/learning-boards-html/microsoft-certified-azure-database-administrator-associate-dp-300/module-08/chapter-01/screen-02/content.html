Learning Objectives
Practical outcomes tied to verification milestones.
01
Identify migration phases
Describe discovery, assessment, remediation, cutover and why each phase reduces risk.
Verified competency milestone: Outline a migration plan with phases and timelines.
02
Use DMA for DB assessment
Run DMA to find compatibility and feature parity issues that need remediation.
Verified competency milestone: Produce and explain a DMA assessment report.
03
Analyze assessment reports
Prioritize breaking changes and performance bottlenecks; estimate remediation effort.
Verified competency milestone: List top 3 remediation tasks and estimated effort.
04
Formulate migration strategy
Decide between online, offline, or hybrid moves based on downtime needs and complexity.
Verified competency milestone: Choose and justify a migration approach for a sample workload.
