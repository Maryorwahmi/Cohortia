Module 08 › Chapter 8.3 › Hands-on Objectives
Practical skills and validation
Objective: Perform an offline MySQL migration. You will run mysqldump on a local server, create an empty database on Azure Database for MySQL, and import using the mysql client. This step verifies you can move schema and data reliably when you control downtime.
Objective: Configure source for online migration. For PostgreSQL enable logical WAL output and replication slots. For MySQL enable log_bin and set binlog_format to ROW. These changes allow DMS to capture and apply ongoing changes during migration.
Troubleshooting
Common issues include missing server parameter changes, blocked network access, and view DEFINER problems. Each must be validated before cutover.
Verification
After migration, run sample queries, compare row counts, rebuild indexes, and run analyze to refresh statistics.
