Module 08 › Chapter 8.3 › Azure DMS Workflow
Process Flow
Provision DMS and run online migration
  1. Provision an Azure DMS instance.
  2. Create a migration project and select PostgreSQL or MySQL as source and Azure PaaS as target.
  3. Configure source and target endpoints with credentials and networking.
  4. Enable logical/binlog replication on the source and start migration (full load + continuous sync).
  5. Monitor until target is caught up, then perform cutover and validate.
Connectivity
Ensure DMS can reach the source database. This commonly requires firewall rules, VNet integration, or network peering.
Common Mistake
Not enabling required source parameters for logical replication or binlog will prevent DMS from establishing continuous sync.
Key Takeaway

DMS automates data capture and apply but requires source configuration and network access; monitor and validate before cutover.
