Module 08 › Chapter 8.3 › Logical Replication
Core Concept
PostgreSQL logical replication prerequisites
Logical replication requires server-side configuration changes and often an extension to decode WAL into logical events. These changes are mandatory for DMS online migrations.
Key parameters include setting wal_level to logical, and increasing max_replication_slots and max_wal_senders. Install wal2json or pglogical where required to provide a usable logical stream.
Server Parameters
  • wal_level = logical
  • max_replication_slots = <enough slots>
  • max_wal_senders = <replication clients>
Watchouts
Logical replication increases WAL retention needs. Monitor disk usage and adjust retention or archiving policies to prevent storage exhaustion.
Key Takeaway

Enable logical WAL output and sufficient replication capacity, and test decoding extensions before starting an online migration.
