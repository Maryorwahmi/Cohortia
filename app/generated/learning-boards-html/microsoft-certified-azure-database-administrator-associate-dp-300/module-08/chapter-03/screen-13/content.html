Module 08 › Chapter 8.3 › Quick Checklist
Test First
Run a full dry run to measure export, transfer, restore, and validation timing.
Confirm Connectivity
Ensure DMS or restore clients can reach your source through firewalls and networks.
Keep Backups
Retain source backups and a rollback plan until post-migration validation is complete.
Final Prompt
Before cutover, confirm test results, parameter changes, connectivity, and backup integrity so the production migration is predictable.
