Module 08 › Chapter 8.3 › MySQL Binlog
Definition
Binlog configuration for online replication
Enable binary logging and use row-based format so that DMS can capture precise row changes and apply them to Azure Database for MySQL during continuous sync.
Required Settings
  • log_bin = ON
  • binlog_format = ROW
  • binlog retention configured long enough for migration
Common Mistake
Not ensuring binlog retention is sufficient, which can cause replication gaps if older binlogs are purged before DMS reads them.
Key Takeaway

Row-based binlogs and adequate retention are essential for reliable online migrations with DMS for MySQL.
