Module 08 › Chapter 8.3 › mysqldump / mysql
Definition
Offline MySQL export and import
mysqldump creates an SQL script containing schema and data. The mysql client executes that script against the target database to recreate objects and rows.
Example Commands
mysqldump -h localhost -u <source-user> -p <source-db> > output-file.sql

mysql -h <azure-mysql-server-name>.mysql.database.azure.com -u <azure-mysql-admin-user> -p <target-db> < output-file.sql
DEFINER Clause
Views can include a DEFINER user. If that user is missing on Azure, view creation may fail. Remove or change DEFINER to CURRENT_USER in the dump, or recreate the referenced user on the target.
Common Mistake
Assuming privileges and DEFINER contexts migrate automatically. Explicitly validate views, procedures, and permissions after import.
Key Takeaway

mysqldump is simple and effective, but handle view definer and privilege differences carefully.
