Learning Objectives
Master the migration steps and post-migration verification for PostgreSQL and MySQL to Azure.
01
Assess Compatibility
Identify extension and server parameter differences that affect behavior on Azure. This reduces surprises in production.
VERIFIED COMPETENCY MILESTONE
02
Offline Migration
Use pg_dump/pg_restore or mysqldump/mysql to export and import when downtime can be scheduled. This is simple and reliable for many scenarios.
VERIFIED COMPETENCY MILESTONE
03
Online Migration with DMS
Provision DMS, enable logical replication or binlog on the source, and run continuous sync to minimize downtime for large, active systems.
VERIFIED COMPETENCY MILESTONE
04
Post-migration Optimization
Rebuild indexes, run analyze, tune memory and buffer settings, and validate performance after migration.
VERIFIED COMPETENCY MILESTONE

These objectives move from reading tools to executing migrations and validating production behavior.
