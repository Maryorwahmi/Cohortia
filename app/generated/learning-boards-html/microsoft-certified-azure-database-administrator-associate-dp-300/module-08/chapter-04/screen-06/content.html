Module 8 › Chapter 8.4 › Schema and object verification
Checklist
  • Compare table and column definitions between source and target.
  • Verify index names, keys, included columns, and uniqueness constraints.
  • Confirm stored procedures and functions compile and run expected inputs.
  • Check permissions and logins for least-privilege access.
Example

Script the definition of a stored procedure on the source, compare to the target, and run a smoke invocation to verify behavior.

Concrete verification card
Index check
List indexes and compare column lists and sizes; missing index columns often cause plan regressions.
Permissions
Validate that application logins map to appropriate users and roles on the target server.
Common mistake

Only checking object names; always compare full definitions and test runtime behavior to be safe.
