Module 8 › Chapter 8.4 › Data integrity validation methods
Techniques
  • Deterministic: full checksums or row counts for small to medium tables.
  • Sampling: aggregates and partitioned checks for very large tables.
  • Column-level checks: SUM, AVG, MIN, MAX to detect value-level differences.
  • Schema object presence: ensure tables and indexes exist as expected.
Key takeaway

Combine counts with value aggregates to detect omissions and corruption.

Concrete examples (visual)
-- SQL Server: checksum or aggregated sum
SELECT COUNT(*) AS rows, SUM(TotalAmount) AS total_sum FROM Sales.Orders;

-- PostgreSQL: aggregate sample
SELECT COUNT(*), AVG(quantity), SUM(amount) FROM public.orders WHERE order_date > '2023-01-01';

-- MySQL: optimize or analyze table after validation
ANALYZE TABLE orders;
Note: these queries are evidence items to record; do not rely on a single check.
Misconception

Identical row counts alone do not guarantee identical values. Include column-level checks or checksums for critical fields.
