Module 8 › Chapter 8.4 › Server parameters and service tier choices
Engine parameters to review
  • PostgreSQL: shared_buffers, work_mem, effective_cache_size.
  • MySQL: innodb_buffer_pool_size, query_cache_size.
  • SQL Server: MAXDOP and cost threshold for parallelism.
When to scale

Scale service tier if CPU, memory, or I/O are consistently constrained after tuning and index work.

Decision flow
  1. Monitor metrics to identify the limiting resource.
  2. Apply index and statistics fixes first to reduce unnecessary resource use.
  3. Tune engine parameters that address the observed bottleneck.
  4. If limits persist, increase vCores or switch service tier and re-evaluate.
Common mistake

Scaling before optimization; always verify whether tuning and index maintenance can resolve the issue at lower cost.
