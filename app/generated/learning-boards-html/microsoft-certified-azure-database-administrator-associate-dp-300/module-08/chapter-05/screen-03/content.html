Skills Breakdown

Tasks you will practice and the reasoning behind them.
Focus: Provisioning → Partitioning → Tuning
Provision
Create account, choose Core (SQL) API, select regions and capacity mode for required latency.
Partition
Pick a partition key that evenly distributes data and avoids hot partitions for high-throughput workloads.
Tune
Manage RUs, enable autoscale when appropriate, and optimize indexing to reduce RU consumption on common queries.
Hands-on flow

Create account, add a database and container with partition key, insert sample JSON, run queries, observe RU charge.

Common mistake

Choosing a partition key that concentrates traffic produces hot partitions, causing throttling even with sufficient account-level RUs.
