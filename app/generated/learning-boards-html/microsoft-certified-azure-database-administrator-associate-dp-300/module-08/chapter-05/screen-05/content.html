Module 08 › Chapter 8.5 › Accounts, Databases, and Containers
Resource boxes
Account
Global distribution boundary and management scope for regions and keys.
Database
Logical grouping of containers; optional throughput at database level.
Container
Unit of scalability and throughput. Define partition key here.
Administration tip

Place datasets that share throughput and partitioning patterns in the same container. Keep unrelated workloads in separate containers to simplify scaling and RBAC.

Partitioning callout
When creating a container you select a partition key path such as /category. That key determines distribution across physical partitions and therefore the container's ability to scale horizontally.
Example
Products container with partition key /category groups similar items and attempts to distribute load by category.
Common mistake
Using a narrowly distributed key that causes a hot partition under heavy write or read traffic.
Key Takeaway

Match resource hierarchy to isolation and scale needs. Containers are your scaling units; partition keys decide distribution.
