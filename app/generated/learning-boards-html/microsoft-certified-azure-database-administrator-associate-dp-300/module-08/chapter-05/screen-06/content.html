Module 08 › Chapter 8.5 › Provisioning a Cosmos DB Account
Provisioning steps
1
Create account and select API
Choose Core (SQL) for JSON documents or another API that matches your application.
2
Select regions and capacity mode
Pick regions for low-latency reads and choose between provisioned and autoscale throughput.
3
Create database and container
Provide database ID, container ID, select partition key, and set throughput at container or database level.
Verification
Insert sample JSON documents and run sample queries. Observe the Query Stats to see RU charge for each query and adjust throughput or indexing as needed.
Example
Create a products database and container, choose /category as partition key, and set 400 RUs to start.
Watch
Monitor RU consumption and throttling. If queries are expensive, inspect indexing or increase RUs rather than over-provisioning blindly.
