Module 08 › Chapter 8.5 › Request Units (RUs)
What is an RU?

An RU is a performance currency that abstracts compute, I/O, and memory cost for a database operation. Operations consume RUs; you provision capacity in RUs per second.

Point reads are cheap; full scans and cross-partition queries are expensive.
Provision at container or database level. Autoscale can expand RUs automatically within a range.
Monitor
Use Query Stats to see RU cost per query and metrics to view RU consumption trends. Throttling (429) means RU limits were exceeded.
Practical tips
Reduce RU cost
Optimize queries and indexing. Avoid cross-partition scans by using filters on the partition key when possible.
Autoscale
Autoscale adjusts RUs automatically within a range, simplifying management for variable workloads.
Key Takeaway

Track RU charge per operation and tune queries, indexes, and throughput to meet SLAs without waste.
