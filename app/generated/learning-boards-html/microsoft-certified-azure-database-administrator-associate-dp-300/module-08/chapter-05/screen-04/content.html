Module 08 › Chapter 8.5 › What is Cosmos DB?
Definition

Azure Cosmos DB is Microsoft's managed, globally distributed NoSQL database service supporting multiple models and APIs for flexible application needs.

Multi-model: documents, key-value, graph; choose an API that matches your app.

Globally distributed: replicate data to regions for low-latency reads and disaster recovery.

Throughput model: operations consume Request Units that you provision or autoscale.

Example
An international product catalog stored as JSON, replicated to several regions for low-latency product reads.
Misconception
Cosmos DB is not a drop-in relational replacement; its trade-offs involve consistency models and partitioning, not relational joins between containers.
Multi-model APIs
SQL (Core)
JSON document queries using a SQL-like language.
MongoDB API
MongoDB wire protocol compatibility for document apps.
Gremlin
Graph data model for connected data and traversals.
Key Takeaway

Pick the API that maps to your data model. Use Cosmos DB when you need flexible schemas, global replication, and predictable low latency.
