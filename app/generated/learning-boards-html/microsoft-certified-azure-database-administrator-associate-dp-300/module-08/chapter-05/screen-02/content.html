Learning Objectives

Skills you will gain and why they matter for operations.
Bloom: Learn → Understand → Apply → Master
01
Explain core Cosmos DB concepts

You will describe global distribution, multi-model APIs, and the five consistency levels. This matters because each choice affects latency and application guarantees.

VERIFIED COMPETENCY MILESTONE
02
Provision and configure resources

You will create accounts, databases, and containers, and set throughput and regions. Proper configuration ensures resilience and low-latency access.

VERIFIED COMPETENCY MILESTONE
03
Manage Request Units and throughput

You will understand RUs, provision or autoscale throughput, and monitor RU consumption to prevent throttling and control cost.

VERIFIED COMPETENCY MILESTONE
04
Use SQL API and control indexing

You will run SQL-like queries against JSON documents and adjust indexing policies to optimize RU usage and query performance.

VERIFIED COMPETENCY MILESTONE
