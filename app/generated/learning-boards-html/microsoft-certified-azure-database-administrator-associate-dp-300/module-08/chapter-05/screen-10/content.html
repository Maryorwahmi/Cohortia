Query example
Run the following SQL-like query in Data Explorer to inspect product documents and RU charge.
-- Example: Query documents in a Cosmos DB container (SQL API)
SELECT c.id, c.productName, c.price
FROM c
WHERE c.category = 'Electronics' AND c.price > 100
ORDER BY c.price DESC
Tip: Include the partition key in the WHERE clause when possible to avoid cross-partition queries and to lower RU charges. After running the query, review Query Stats to see RU charge, and then iterate.
Example scenario
Query products where category equals Electronics and price over 100 to return id, name and price ordered by price.
Query Stats

Observe RU charge per query in Data Explorer. High values indicate cross-partition scans or non-indexed predicates.

Key Takeaway

Prefer point reads and partition-key filtered queries to minimize RU cost. Use composite indexes for frequent multi-attribute queries.
