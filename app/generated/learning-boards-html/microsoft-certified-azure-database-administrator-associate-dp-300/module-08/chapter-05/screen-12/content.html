Module 08 › Chapter 8.5 › Consistency Levels
Consistency comparison
Strong
Latest reads guaranteed; higher latency.
Bounded Staleness
Reads lag by a configured amount.
Session
Good balance: read-your-writes in a session.
Consistent Prefix
No out-of-order writes; eventual completeness.
Eventual
Lowest latency and highest availability; eventual convergence.
Example
Shopping cart user experience: Session consistency ensures users see their own recent writes without forcing global Strong consistency.
Misconception
Strong consistency is not always best for global apps because of cross-region latency penalties.
Key Takeaway

Choose the weakest consistency that satisfies correctness to reduce latency and improve availability. Session is often a pragmatic default.
