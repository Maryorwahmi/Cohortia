Module 08 › Chapter 8.5 › Partition Keys and Hot Partitions
Partition key definition

A partition key is a JSON property path used to distribute items across logical and physical partitions. It controls parallelism and storage layout.

Good partition keys: spread writes and reads, remain present on most documents, and avoid skew.
Poor keys: single-value fields, very small cardinality, or keys that map high percentage of traffic to one partition.
Scenario
If /userId distributes evenly across users, it may be better than /region which could concentrate traffic.
Hot partition
A busy category that receives most writes will create a hot partition and can cause throttling even with adequate RUs overall.
Design patterns
Synthetic keys
Combine fields, for example category:region, to increase cardinality and reduce hotspots.
Re-evaluate with metric data
Monitor partition RU consumption and request distribution to validate your choice and adjust if needed.
Key Takeaway

Partition keys should be chosen for expected access patterns, not only uniqueness. Monitor and adapt if you see hotspots.
