Administering Azure Database for MariaDB and Hyperscale (Citus)

Understand managed MariaDB administration and how Hyperscale with Citus distributes PostgreSQL data for high throughput and massive scale.

In this lesson

You will learn provisioning, configuration, security, monitoring and backups for MariaDB, and the architecture, distribution strategies, and common operational tasks for Hyperscale (Citus).

Coming up

Guided SQL examples show how to create distributed and reference tables, and a hands-on activity walks through provisioning a Hyperscale cluster and distributing tables.

Topic: MariaDB Admin
Provision, tune parameters, secure access, and use Azure Monitor and automated backups to maintain operations.
Topic: Hyperscale (Citus)
Coordinator and worker nodes, distributed and reference tables, and distribution column design for scaling queries.
Topic: Hands-on
Provision a cluster, connect to the coordinator, create distributed and reference tables, then run queries to observe routing.
Visual concept
Cards show the two services and a simple relation: managed MariaDB for compatible web apps, Hyperscale (Citus) for sharded, high-volume workloads.
Quick example
Create a distributed table on the coordinator using a high-cardinality column like device_id, and create a reference lookup table for small frequently-joined data. This combination keeps joins efficient and enables parallel query execution.
Tip: When planning, list your most common query filters and joins. That list will guide whether MariaDB or Hyperscale (Citus) is a better fit, and which distribution column to choose for Citus.
