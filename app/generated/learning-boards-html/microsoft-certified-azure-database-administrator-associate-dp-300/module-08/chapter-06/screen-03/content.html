Module 8 › Chapter 8.6 › Lab Outcomes
01
Change and test server parameters

Apply a parameter such as max_connections or query_cache_size and observe effects via a controlled workload to verify the change.

VERIFIED COMPETENCY MILESTONE
02
Provision and scale Hyperscale

Deploy a Hyperscale server group, add worker nodes, connect with psql to the coordinator, and validate node health before distributing tables.

VERIFIED COMPETENCY MILESTONE
03
Create distributed and reference tables

Use create_distributed_table and create_reference_table. Insert data and run queries to confirm routing and colocation benefits.

VERIFIED COMPETENCY MILESTONE
04
Monitor and recover data

Use Azure Monitor metrics and automated backups to identify issues and perform point-in-time restores when necessary.

VERIFIED COMPETENCY MILESTONE
