Provision and connect
1. Create Hyperscale (Citus) server group in the portal and choose coordinator and worker node sizes. 2. Add at least two worker nodes. 3. Copy the coordinator psql connection string and connect from your terminal.
Checklist before distributing
  • Confirm worker nodes are healthy and visible to the coordinator.
  • Plan distribution column based on cardinality and query patterns.
  • Have a reference table plan for small lookup data.
SQL example (run on coordinator)
-- Create a distributed table
CREATE TABLE products (
  product_id INT,
  product_name TEXT,
  category_id INT,
  price DECIMAL
);
SELECT create_distributed_table('products', 'category_id');

-- Create a reference table
CREATE TABLE categories (
  category_id INT PRIMARY KEY,
  category_name TEXT
);
SELECT create_reference_table('categories');
