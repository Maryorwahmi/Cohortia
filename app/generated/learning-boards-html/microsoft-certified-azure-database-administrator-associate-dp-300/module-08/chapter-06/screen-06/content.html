Module 8 › Chapter 8.6 › Security & Connectivity
Network controls
  • Firewall rules: restrict by client IP ranges.
  • Virtual Network service endpoints: narrow access to VNets.
  • Private Link: allow private connectivity without public endpoints.
Database access

Manage users and roles, enforce least privilege, and use TLS for encrypted transport. Rotate admin credentials and audit access regularly.

Concrete scenario

Place an app tier in a VNet and connect via Private Link. Create an application user with minimal privileges for data operations; reserve the admin account for maintenance.

Common mistake

Relying solely on firewall rules. Fix by combining network isolation with user privilege controls and enforced TLS.
