Coordinator and workers
Coordinator node

Entry point for applications; holds metadata about shard placement and rewrites queries to run across worker nodes.

Worker nodes

Store shards of distributed tables and execute query fragments in parallel to scale storage and CPU capacity horizontally.

Table types
  • Distributed tables: sharded by a distribution column across workers.
  • Reference tables: fully replicated on each worker, good for small lookup data.
  • Local tables: stored only on the coordinator for small admin data.
Misconception check

Citus makes scaling easier but does not remove the need for thoughtful schema and distribution design; poor choices can cause data movement and slow queries.
