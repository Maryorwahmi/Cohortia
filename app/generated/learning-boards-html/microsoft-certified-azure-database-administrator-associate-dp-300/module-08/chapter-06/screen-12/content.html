Module 8 › Chapter 8.6 › Key Concepts
Azure Database for MariaDB
A fully managed MariaDB service providing automated patching, backups, high availability, and adjustable performance tiers.
Hyperscale (Citus)
A PostgreSQL deployment that shards data across worker nodes and routes queries via a coordinator to scale horizontally.
Distribution column
The key used to shard distributed tables; choose a high-cardinality, frequently-used column in joins and filters to optimize routing.
Takeaway: Use managed MariaDB for compatibility and operational simplicity. Use Hyperscale (Citus) when you need horizontal scale, and design distributions to match query patterns.
