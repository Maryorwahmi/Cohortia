Module 8 › Chapter 8.6 › Query Behavior
How routing works

If a query filters or joins on the distribution column, the coordinator routes the work to the relevant worker(s), enabling localized execution and efficient parallelism.

Colocation for joins

For joins between distributed tables, colocate them by using the same distribution column so the join can execute on workers without moving data across nodes.

Failure modes and fixes
  • Data skew: rebalance by choosing a different distribution column or pre-hashing keys.
  • Cross-node joins: refactor schema to use reference tables or align distribution keys.
  • Lack of distribution column in queries: encourage application queries to filter by the distribution key for performance.
Check with EXPLAIN

Run explain plans on the coordinator to see if queries are routed to workers and how many nodes participate. This reveals whether your distribution choices are effective.
