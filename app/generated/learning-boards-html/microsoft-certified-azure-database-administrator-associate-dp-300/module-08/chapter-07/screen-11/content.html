Module 8 › Chapter 8.7 › Security & Governance
Storage access
Prefer managed identities or limited-scope credentials for external data sources and COPY jobs. Apply RBAC at the container level in your data lake.
Practice
Use least-privilege identities and rotate secrets for any service principals or tokens you must use.
Audit
Enable query and storage access logs to track who queried which files and detect anomalous or costly activity.
Data protection
  • Use row-level security and data masking in dedicated pools for production datasets.
  • Control who can run serverless queries and what containers they can access.
Common misconception
Serverless queries are subject to the same storage permissions as any other client; governance must be applied at the storage and workspace level.
