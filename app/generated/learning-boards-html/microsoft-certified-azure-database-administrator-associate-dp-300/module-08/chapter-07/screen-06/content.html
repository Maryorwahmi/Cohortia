Module 8 › Chapter 8.7 › Provisioning a dedicated pool
Process
  1. Create Synapse workspace with linked Data Lake Storage Gen2.
  2. Add a dedicated SQL pool and choose an initial DWU level aligned to expected load.
  3. Run sample ETL and queries to validate performance and distribution.
  4. Configure schedules to scale or pause during off-peak hours to manage cost.
Example decision
If nightly ETL must finish in two hours for a 10-node plan, choose DWU based on test runs that meet that SLA, then automate scale if load spikes.
Common mistake
Not pausing the dedicated pool outside business hours leads to unnecessary costs.
Operational checklist
Estimate DWU from SLAs
Run representative queries to measure runtime and scale as needed.
Validate distribution
Design table distributions to avoid data skew for parallel execution.
Schedule pause/resume
Automate pause during predictable idle periods to reduce cost.
Why it matters

Right-sizing compute ensures SLAs are met while costs remain controlled.
