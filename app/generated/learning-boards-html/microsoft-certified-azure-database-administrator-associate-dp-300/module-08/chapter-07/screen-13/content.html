Module 8 › Chapter 8.7 › When to load into dedicated
Decision checklist
  • Does the dataset need predictable, repeated queries or dashboarding?
  • Are there concurrency or latency SLAs that serverless cannot meet reliably?
  • Do you require advanced governance, masking, or row-level security?
Workflow
Explore with serverless, validate schema and query patterns, then use COPY to bulk-load curated data into a dedicated pool and apply distribution/partition strategies for performance.
Practical tip
Measure query patterns over time in serverless before committing large datasets to provisioned compute.
