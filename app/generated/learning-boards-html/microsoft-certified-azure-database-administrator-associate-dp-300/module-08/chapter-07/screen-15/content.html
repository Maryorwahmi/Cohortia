Module 8 › Chapter 8.7 › Key Concepts
Azure Synapse Analytics
A unified platform combining warehousing and lake-based analytics for BI and ML.
Synapse SQL Pool (dedicated)
Provisioned MPP compute measured in DWUs for predictable performance.
Serverless SQL Pool
On-demand T-SQL over data lake files billed per data processed, ideal for exploration.
Takeaway
Use serverless for discovery and reserved DWUs for production warehousing; move data when usage patterns justify the cost and governance needs.
