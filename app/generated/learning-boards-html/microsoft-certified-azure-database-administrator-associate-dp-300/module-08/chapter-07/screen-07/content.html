How PolyBase works
Define an external data source and external file format. Query files with T-SQL or load results into tables.
Example statements
-- Create an external data source
CREATE EXTERNAL DATA SOURCE MyDataLake
WITH (
    LOCATION = 'abfss://<container>@<storageaccount>.dfs.core.windows.net/',
    TYPE = HADOOP,
    CREDENTIAL = MyCredential
);

-- Create an external file format for CSV
CREATE EXTERNAL FILE FORMAT CsvFormat
WITH (
    FORMAT_TYPE = DELIMITEDTEXT,
    FORMAT_OPTIONS (
        FIELD_TERMINATOR = ',',
        STRING_DELIMITER = '"',
        FIRST_ROW = 2
    )
);
When to use PolyBase
  • When you want to query external files without copying them.
  • When you need metadata-driven access and flexible schema handling.
Performance note
For very large bulk loads, consider the COPY statement as a higher-performance alternative to move data into dedicated tables.
Example use

Create an external data source pointing to your data lake and query CSV files to validate schema before importing.
