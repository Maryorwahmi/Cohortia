Module 8 › Chapter 8.7 › Operational Checklist
Dedicated pool metrics
  • Query duration and concurrency
  • DWU utilization and queue times
  • Distribution skew and I/O patterns
Serverless metrics
  • Data processed per query
  • Frequency of expensive queries
  • Files accessed and source containers
Alerts & Governance
Set alerts for cost spikes and long-running queries, and correlate logs to find inefficient patterns. Review identities and access policies regularly to avoid unauthorized access.
