Module 8 › Chapter 8.7 › COPY statement
COPY example
-- COPY INTO example to bulk load CSV files
COPY INTO MyDedicatedTable
FROM 'folder/data.csv'
WITH (
    FILE_TYPE = 'CSV',
    CREDENTIAL = (IDENTITY = 'Managed Identity'),
    FIRSTROW = 2
);
This instructs Synapse to read the CSV, skip the header row, and use managed identity to access storage. COPY runs in parallel for performance.
Practical advice
  • Ensure your target table distribution and indexing match query patterns for analytics.
  • Test COPY on sample data to validate parsing options such as FIRSTROW and delimiters.
  • Review load results and rejected rows for data quality issues.
Key Takeaway

Use COPY for fast, parallel bulk loads from your data lake into dedicated Synapse tables, and validate data after load.
