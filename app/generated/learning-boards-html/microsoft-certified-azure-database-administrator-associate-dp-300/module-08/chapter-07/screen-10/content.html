Module 8 › Chapter 8.7 › Cost & Mistakes
Dedicated pool pitfalls
  • Leaving the pool running when not needed creates ongoing charges.
  • Over-provisioning DWU without validating with real workloads wastes budget.
Serverless pitfalls
  • Running unfiltered SELECT * over large files processes large volumes and can be costly.
  • Not specifying schema or projections can increase scanned data and parsing overhead.
Best practices
Use serverless for discovery with targeted filters, validate workloads, then move frequently queried and curated datasets into a dedicated pool. Automate pause/resume schedules and monitor usage to keep costs predictable.
