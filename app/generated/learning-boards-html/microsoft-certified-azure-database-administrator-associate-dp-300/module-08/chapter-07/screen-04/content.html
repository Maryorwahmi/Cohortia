Azure Synapse Analytics — definition
A platform for ingesting, preparing, managing, and serving data for analytics and ML.
Core capabilities
  • Provisioned MPP data warehousing with dedicated SQL pools for predictable performance.
  • Serverless SQL pool for on-demand T-SQL queries directly over data lake files.
  • Integrated pipelines and workspace tools for orchestration and notebooks.
Example
Use serverless SQL to explore raw logs in Parquet, then COPY curated rows into a dedicated pool table for nightly reporting.
Misconception
Synapse is not just a single database; it's an integrated set of services with different compute models.
Visual summary
Think of Synapse as a workspace where files live in a data lake, you can query them directly with serverless SQL, or you can load them into a provisioned MPP pool for production reporting.
Key Takeaway
Pick serverless for exploration and dedicated pools for repeatable performance and concurrency.
