Module 8 › Chapter 8.7 › Hands-on Activity
Steps
  1. Upload sales_data.csv to a container in your Data Lake Storage Gen2.
  2. Open Synapse Studio, create a new SQL script, and connect to the built-in serverless endpoint.
  3. Run an OPENROWSET query to preview rows and add a WHERE filter to limit scanned data.
  4. Add a WITH clause to declare types, then re-run and compare results.
Starter query
SELECT TOP 100 *
FROM OPENROWSET(
  BULK 'https://<your-storage-account-name>.dfs.core.windows.net/rawdata/sales/sales_data.csv',
  FORMAT = 'CSV',
  PARSER_VERSION = '2.0',
  HEADER_ROW = TRUE
) AS SalesData
WHERE SalesData.Amount > 100
ORDER BY SalesData.OrderDate DESC;
Run this to see filtered rows. Then add a WITH clause to explicitly set types for safer downstream processing.
