Module 8 › Chapter 8.7 › Learning Objectives
Operational Decisions
  • When to provision a dedicated pool for predictable high-performance ETL and reporting.
  • When to use serverless queries for ad-hoc exploration and schema discovery in a data lake.
  • How pausing dedicated compute lowers cost without moving storage.
Practical Skills
  • Create external data sources and file formats for PolyBase or COPY.
  • Write COPY jobs to bulk-load CSV or Parquet into dedicated tables.
  • Use OPENROWSET in serverless SQL to query files directly with T-SQL.
Tip
Treat serverless as a discovery and validation layer before you decide to move data into a dedicated pool for production workloads.
Caution
Avoid leaving dedicated pools running unused. For serverless, avoid unfiltered queries over very large files that scan excessive data.
