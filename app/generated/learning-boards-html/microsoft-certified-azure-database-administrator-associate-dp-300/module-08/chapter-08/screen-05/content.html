Module 8 › Chapter 8.8 › Linked Services & Datasets
Definition
Linked Service

A linked service stores connection and authentication details. Prefer Managed Identity where supported to avoid embedding credentials in configs.

Definition
Dataset

A dataset represents a specific table or file and its format. Import schemas to simplify mapping and reduce runtime errors.

Example
SalesCsvDataset → AzureDataLakeStorageLS (Managed Identity)
Pro Tip
Use dataset previews and linked service test connections before running debug jobs.
Starter SQL
Run this in your Azure SQL Database to create the target table used by the sink dataset.
-- Connect to your Azure SQL Database and run this
CREATE TABLE [dbo].[SalesData] (
  OrderID INT,
  CustomerID INT,
  OrderDate DATE,
  Amount DECIMAL(10, 2)
);
Key Takeaway
Prepare the sink schema first, test linked services, and prefer managed identities to avoid secret sprawl.
