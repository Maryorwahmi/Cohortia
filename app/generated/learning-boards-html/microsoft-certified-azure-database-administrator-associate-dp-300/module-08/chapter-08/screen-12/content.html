Module 8 › Chapter 8.8 › Azure Stream Analytics
Key capabilities
  • SQL-like streaming queries for filtering and aggregation.
  • Windowing functions: tumbling, sliding, hopping.
  • Integrations to Event Hubs, IoT Hub, and sinks like SQL DB or Power BI.
Example scenario

Detect device anomalies: compute a one-minute average via a tumbling window and write records that exceed thresholds to a SQL table for alerting and investigation.

Misconception

Streaming is not a replacement for batch analytics; it provides immediacy while batch handles large-scale historical processing and reprocessing.

Takeaway

Use Stream Analytics when business outcomes require fast detection and response; pair it with batch pipelines for full history and reprocessing.
