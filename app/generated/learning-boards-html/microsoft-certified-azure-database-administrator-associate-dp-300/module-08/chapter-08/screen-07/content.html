Module 8 › Chapter 8.8 › Cross-DB vs Elastic
Cross-Database Queries
Azure SQL Managed Instance
  • Single query spans multiple databases on the same instance.
  • Good for instance-scoped features and tight transactional integration.
  • Requires Managed Instance deployment and instance-level permissions.
Elastic Queries
Azure SQL Database (elastic tools)
  • Query across many sharded databases to aggregate results.
  • Designed for horizontal scale with separate database shards per tenant.
  • Consider query fan-out cost and coordination overhead.
Decision checklist
Match pattern to administrative boundary, feature needs, and query shape. If you need instance-scoped features use Managed Instance; if you need horizontal shard scaling use elastic queries and plan for fan-out costs.
