Module 8 › Chapter 8.8 › ADF Activities
Process
Pipeline step sequence
1
Ingest (Copy Data)
Move raw files from source systems into Data Lake Storage Gen2.
2
Transform (Data Flow)
Run mapping data flows for filtering, type conversions and writing Parquet.
3
Load (Copy / Stored Proc)
Copy curated data into Azure SQL, or call a stored procedure to merge rows.
Example
Copy sales_data.csv → Sales staging Parquet → Load into dbo.SalesData
Common mistake
Running heavy joins in Copy activity instead of a Spark Data Flow causes performance and scale issues.
Activity JSON (conceptual)
{
  "name": "CopyDataToSynapse",
  "type": "Copy",
  "inputs": [{ "referenceName": "SourceDataset", "type": "DatasetReference" }],
  "outputs": [{ "referenceName": "SinkDataset", "type": "DatasetReference" }],
  "typeProperties": {
    "source": { "type": "AzureSqlSource" },
    "sink": { "type": "AzureSqlSink" },
    "enableStaging": true,
    "stagingSettings": { "linkedServiceName": "AzureBlobStorageLinkedService" }
  }
}
Key Takeaway
Choose the right activity for the right workload and include retries, logging, and idempotency checks in every pipeline.
