Module 8 › Chapter 8.8 › Learning Objectives
01
Integrate Azure Data Factory

Create, schedule, and orchestrate ETL/ELT pipelines that move and transform data across Azure SQL, Data Lake, Synapse, and Databricks. This matters because repeatable pipelines reduce manual workload and ensure consistent analytics-ready data.

VERIFIED COMPETENCY MILESTONE
02
Secure with Private Link & Managed Identities

Use private endpoints and Azure AD identities so services authenticate without secrets and avoid public endpoints. This reduces risk of credential leaks and strengthens network-level security for production workloads.

VERIFIED COMPETENCY MILESTONE
03
Scale with Cross-DB & Elastic Queries

Implement cross-database queries on Managed Instance and elastic queries for sharded Azure SQL Databases to support horizontal scaling. Knowing when to use each pattern enables efficient design for multi-tenant and sharded scenarios.

VERIFIED COMPETENCY MILESTONE
04
Govern with Azure Purview

Catalog, classify, and track lineage so stakeholders can find and trust data assets across on-premises and cloud sources. Governance supports compliance, data quality, and reproducible analytics.
