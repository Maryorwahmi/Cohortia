Module 8 › Chapter 8.8 › Azure Purview
What it does
Catalog, classify, and trace lineage
  • Discover assets across on-premises and cloud sources by registering data stores.
  • Classify sensitive data using built-in or custom scanning rules to support compliance.
  • Capture lineage so you can follow data from source through ADF pipelines into analytical stores.
Example
Register your Data Lake and Azure SQL, scan for PII, and use lineage to validate which pipeline produced a curated table.
Common mistake
Delaying Purview onboarding until late in a project leads to missing lineage and costly rework. Start with critical data sources first.
Key Takeaway
Treat governance as part of the pipeline: register sources, run scans, and capture lineage early to support audits and trust.
