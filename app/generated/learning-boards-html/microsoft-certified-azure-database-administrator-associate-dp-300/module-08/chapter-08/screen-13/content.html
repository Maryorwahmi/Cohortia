Module 8 › Chapter 8.8 › Secure, Governed Integration
Pattern overview

ADF orchestrates ingestion using Managed Identities to authenticate. Private Link encloses PaaS endpoints in your VNet. Purview indexes and provides lineage for compliance and discovery.

Practical steps
  1. Enable Managed Identity for ADF and grant least-privilege roles on targets.
  2. Create Private Endpoints for databases and storage and validate DNS resolution.
  3. Register sources and pipelines in Purview for classification and lineage capture.
Gotcha

Private Link requires DNS updates and may affect connectivity; plan a validation window and test service-to-service authentication early.

Example flow
ADF (managed identity) → Private Endpoint to Storage (staging) → Databricks job reads staging via MI → Purview scans staging and records lineage → Final sink is Private Link–secured Azure SQL.
Takeaway

Combine network isolation, identity-based auth, and governance to create auditable, secure data platforms that scale safely.
