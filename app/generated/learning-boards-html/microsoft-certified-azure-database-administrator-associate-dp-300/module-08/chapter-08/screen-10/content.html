When to stage

Stage when direct reads stress the source, when transformations require distributed compute, or when you need to enable parallel downstream processing.

Partitioning rules
  • Pick partition keys used by common filters (date, tenant, region).
  • Keep partition sizes balanced to avoid skew.
  • Use parquet with columnar compression for analytics workloads.
Misconception

More parallel threads always help — not true. Monitor source limits and tune concurrency to the weakest component.

This conceptual JSON shows enableStaging and an explicit staging linked service to improve throughput.
Checklist
  • Test with production volumes.
  • Monitor source CPU, IOPS, and network.
  • Tune batch size, parallelism, and partition keys.
