Module 8 › Chapter 8.8 › Private Link & Identities
Definition
Azure Private Link

Creates a private endpoint in your VNet so PaaS services are reached by private IP addresses and avoid public internet exposure.

Managed Identities

An Azure AD identity managed by the platform that services use to authenticate to other Azure resources without secrets.

Example
Assign Data Factory's managed identity the db_datawriter role on the target Azure SQL Database and configure the linked service to use Managed Identity authentication.
Pitfall
Neglecting DNS updates for Private Link causes services to still resolve public endpoints, breaking private connectivity.
Verification checklist
  • Confirm private endpoint has a private IP in the VNet and appropriate NSG rules.
  • Validate DNS resolution maps the service FQDN to the private IP.
  • Grant the managed identity explicit database roles and test authentication.
  • Add pipeline retries and monitoring for authentication failures.
Key Takeaway
Private Link plus Managed Identity removes both public exposure and secret management, but requires DNS and permissions checks to function reliably.
