Module 8 › Chapter 8.2 › Connectivity
Key points
  • Ensure blob storage permits reads from the import process and that SAS tokens are valid.
  • For DMS, confirm a route to your on-premises SQL Server via VPN, ExpressRoute, or allowed public endpoints.
  • Open firewall ports and test credentials before starting migration jobs.
Validation checklist
- Test blob SAS read using a simple HTTP GET.
- Use a jump host to try connecting to the source SQL Server with the same credentials DMS will use.
- Verify storage network rules and DMS permissions.
Common failure
Expired SAS tokens or blocked storage/network rules causing import failures.
Pro tip
Automate connectivity tests and include them in migration runbooks to catch issues early.
Key Takeaway

Network and storage access problems are common—test them before exporting or starting DMS to avoid delays.
