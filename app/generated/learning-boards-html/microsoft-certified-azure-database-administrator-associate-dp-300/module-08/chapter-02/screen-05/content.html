Module 8 › Chapter 8.2 › BACPAC
Definition
BACPAC file

A BACPAC is a compressed export of a database's schema and data. It is useful when the source can be taken offline or when a snapshot copy is acceptable.

Process
  1. Export BACPAC from source (SSMS or sqlpackage).
  2. Upload BACPAC to Azure Blob Storage and generate SAS.
  3. Import BACPAC into Azure SQL Database using portal, SSMS, or CLI.
When not to use
Avoid for large, highly transactional systems needing continuous availability or for migrations that require minimal downtime.
Example
Migrating a reporting database during a scheduled maintenance window using SSMS Export Data-tier Application and importing to Azure SQL Database.
Key Takeaway

BACPAC is simple and reliable for smaller or quiesced databases, but it requires downtime during export/import.
