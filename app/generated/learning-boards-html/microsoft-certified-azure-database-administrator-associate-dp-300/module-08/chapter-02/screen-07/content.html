Module 8 › Chapter 8.2 › Azure DMS
How it works
Initial load plus continuous sync
1. DMS performs a full data load to the target.
2. DMS applies incremental changes from transaction logs or CDC to keep the target synchronized.
3. When ready, you perform a cutover with minimal downtime.
Example: A retail checkout system remains online on source while DMS synchronizes sales transactions to the Managed Instance; cutover occurs during a brief window when traffic is low.
Requirements
  • Network connectivity from DMS to source (VPN/ExpressRoute or public endpoint and firewall rules).
  • Appropriate credentials and permissions for source and target endpoints.
  • Provisioning of a DMS instance in the correct subscription and region.
Misconception
DMS automates everything; you still must plan networking and validate migration scope.
Monitoring
Use DMS job monitoring to watch full load and continuous sync progress and to surface blocking errors.
Key Takeaway

DMS minimizes downtime via continuous synchronization, but it requires careful network and credential configuration.
