Module 8 › Chapter 8.2 › Post-migration
Security
Create server logins, map database users, validate roles and permissions, and configure firewall and auditing on the target.
Performance
Rebuild or reorganize indexes, update statistics, and run key queries to compare performance against baseline metrics.
Validation
Execute application integration tests, check connection string updates, and confirm expected behavior under load.
Key Takeaway

Post-migration verification and tuning are essential; treat them as a formal phase with pass/fail criteria before decommissioning the source.
