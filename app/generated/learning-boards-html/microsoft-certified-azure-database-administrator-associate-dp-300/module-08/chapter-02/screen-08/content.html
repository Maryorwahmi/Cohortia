Module 8 › Chapter 8.2 › DMS cutover
Provisioning and project setup
Create DMS instance and migration project
  1. Provision DMS in the portal and ensure region alignment.
  2. Create migration project: source SQL Server, target Azure SQL Database or Managed Instance.
  3. Configure and validate source/target endpoints and credentials.
Run and monitor
Full load, continuous sync, validate
  • Start migration: wait for initial full load to complete.
  • Monitor continuous sync until incremental backlog is minimal.
  • Run verification queries and application tests on the target.
Cutover checklist
Plan a short maintenance window, pause writes or switch traffic, finalize sync, validate behavior, update connection strings, and keep a rollback plan ready.
Key Takeaway

Monitoring and validation are essential; never cut over without testing the synchronized target under expected workloads.

Common mistake
Cutover without a validation run or rollback plan, leading to service disruption.
