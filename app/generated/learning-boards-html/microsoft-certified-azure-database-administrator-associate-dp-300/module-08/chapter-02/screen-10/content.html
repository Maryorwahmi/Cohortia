Module 8 › Chapter 8.2 › Azure Data Studio
Capabilities
  • Instance discovery and compatibility assessment.
  • SKU recommendations and migration guidance.
  • Wizard-driven DMS orchestration for online migrations.
Workflow
1. Install SQL Migration extension.
2. Connect to on-premises instance and run assessment.
3. Follow the wizard to configure DMS and start migration.
Example
Run an assessment that recommends Managed Instance for a database using SQL Agent jobs, then start a DMS project from the extension.
Misconception
It simplifies but does not replace networking and permission validation steps.
Key Takeaway

Azure Data Studio accelerates assessment and DMS orchestration, making migrations more repeatable and guided.
