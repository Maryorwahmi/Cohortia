Module 4 › Chapter 4.1 › Destination Choices
Log Analytics
Queryable logs with KQL, good for cross-resource analysis and dashboards.
Best for: troubleshooting, query and visualization
Storage Account
Cost-effective long-term archive for retention and regulatory audits.
Best for: archival, compliance
Event Hub
Stream telemetry to downstream systems like SIEMs or custom analytics pipelines.
Best for: streaming, integrations
Concrete routing example
Send QueryStoreRuntimeStatistics to Log Analytics for performance analysis, archive raw server logs to Storage for retention, and stream security audit events to Event Hub.
Key Takeaway

Map each telemetry type to the destination that best supports its use: analyze, archive, or stream — don’t duplicate without reason.
