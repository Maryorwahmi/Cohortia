Module 4 › Chapter 4.1 › Diagnostic Settings
Step-by-step
1.
Open your database resource and select Diagnostics settings under Monitoring.
2.
Click Add diagnostic setting and give it a clear name, for example SQLDBMonitoring.
3.
Select log categories like SQLInsights, QueryStoreRuntimeStatistics, and Errors, and select AllMetrics if you need metric alerts.
4.
Choose destination: Log Analytics for queryable analysis, Storage for archive, Event Hub for streaming out.
5.
Save and verify telemetry by running a test query or waiting for a known event to appear in your workspace.
Key Takeaway

Choose only the log categories you need and route to the destination that supports the intended analysis or retention.

Visual checklist
Destination guidance
Log Analytics = query and analyze; Storage = long term archive; Event Hub = stream to external tools.
Example selection
For Azure SQL: SQLInsights, QueryStoreRuntimeStatistics, Errors, and AllMetrics when needed for alerts.
Validation
After saving, confirm records appear in the workspace with a simple KQL filter for TimeGenerated.
