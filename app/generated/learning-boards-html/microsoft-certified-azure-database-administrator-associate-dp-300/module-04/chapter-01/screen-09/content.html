Module 4 › Chapter 4.1 › Alerts & Action Groups
Create an alert rule
Scope: choose the database resource to monitor.
Condition: pick metric or log signal and set threshold and aggregation.
Frequency: how often the condition is evaluated.
Action Group: attach notifications and automated actions.
Example

Metric alert: CPU percentage > 80% for 5 minutes. Action group sends email to DBAs and calls a webhook for automated scaling.

Action group components
Notifications
Email, SMS, push, voice — who gets alerted and on what severities.
Automations
Webhooks, Azure Functions, or ITSM integrations for automated remediation.
Common pitfall
Too many action groups or overly broad notifications lead to confusion and ignored alerts.
