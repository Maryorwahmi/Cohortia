Module 4 › Chapter 4.1 › Metrics vs Logs
Metrics

Numeric, sampled values used for dashboards and real‑time alerting.

Examples
CPU percentage, IOPS, storage usage.
Best use
Immediate alerts and trend charts for operational health.
Logs

Event records that include details like errors, runtime stats, and query traces for analysis.

Examples
Diagnostic logs, audit logs, QueryStoreRuntimeStatistics entries.
Best use
Root cause analysis, historical queries, and detailed troubleshooting with KQL.
Concrete scenario
Alert on CPU metric when >80% for 5 minutes. Use logs to find which queries were active during that interval.
Common mistake
Alerting on transient metric spikes or generating too many log alerts causes noise and fatigue.
Key Takeaway

Use metrics for fast detection and logs for deep investigation. Design alerts to focus on sustained, meaningful conditions.
