Azure Monitor explained

A single platform that collects metrics and logs from databases and routes them for analysis and action.

What it collects
  • Metrics: CPU percentage, IOPS, storage usage.
  • Logs: diagnostic logs, audit trails, query runtime details.
Why it matters
Central telemetry allows correlation between resource state and events for faster diagnostics.
Concrete example
A sustained CPU spike triggers an alert; stored logs then reveal which queries were running, making root cause identification possible.
Key Takeaway

Treat Azure Monitor as both collector and router — pick metrics for alerts and logs for deep analysis.

Common misconception
Do not confuse metrics with logs: metrics are numeric and short‑lived, logs are descriptive and better for root cause analysis.
