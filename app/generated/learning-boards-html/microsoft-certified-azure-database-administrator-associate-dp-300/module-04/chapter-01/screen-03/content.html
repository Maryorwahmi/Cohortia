Practical Outcomes
Real tasks you can perform confidently
Apply → Operate
Identify
Choose Azure Monitor and Log Analytics to capture metrics and logs from your database resources for both live and historical analysis.
Configure
Enable diagnostic settings like SQLInsights or PostgreSQLLogs and select destinations to preserve useful telemetry.
Alert
Create metric alerts with thresholds, aggregation periods, and attach action groups for notifications and automation.
Distinguish
Use metrics for quick state checks and logs in Log Analytics for detailed query and error analysis over time.
VERIFIED COMPETENCY MILESTONE

Able to configure diagnostic settings and create a working metric alert that notifies an action group.
