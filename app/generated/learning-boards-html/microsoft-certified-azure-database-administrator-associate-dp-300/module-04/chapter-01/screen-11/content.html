Module 4 › Chapter 4.1 › Azure SQL Analytics
What it provides

Curated dashboards for SQL performance: top queries, wait statistics, and resource usage across databases.

Use case
Compare performance across databases and find server‑wide offenders quickly.
Integration
Enable SQL diagnostic categories and send to a workspace where the solution package is enabled.
Key Takeaway

Azure SQL Analytics is a focused layer on Log Analytics for SQL performance across many databases; pair it with custom KQL when you need deeper investigation.

Scenario card
Problem
Multiple databases on a managed instance show intermittent latency spikes; individual investigation is slow.
Solution
Enable Azure SQL Analytics to surface top queries and wait types across databases, then drill down with KQL for root cause.
Misconception
Do not treat it as a standalone logger; it relies on diagnostic settings to collect the underlying data.
