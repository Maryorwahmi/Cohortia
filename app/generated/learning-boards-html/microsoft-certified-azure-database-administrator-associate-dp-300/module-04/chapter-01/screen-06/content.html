How Log Analytics fits

Log Analytics stores diagnostics and exposes Kusto Query Language to filter and aggregate logs at scale.

Useful KQL patterns
  • filter to narrow events by time and level
  • summarize to aggregate counts or averages
  • top to find highest values or most frequent items
Concrete example
Query the AzureDiagnostics table for error entries, group by operation name, and find the top problem sources.
Key Takeaway

Learn basic KQL to convert stored logs into troubleshooting answers quickly.

KQL example
AzureDiagnostics
| where TimeGenerated >= ago(30d)
| where ResourceType contains "DATABASE"
| where Level == "Error"
| summarize Count = count() by OperationName
| top 10 by Count
Explanation
This query filters errors from database resources in the last 30 days, groups by operation name, and shows the top 10 operations by count.
Misconception
Avoid assuming raw logs are self‑explaining; add useful filters and groupings to surface patterns.
