Module 4 › Chapter 4.1 › Key Concepts
Azure Monitor
Unified collection and routing of metrics and logs from Azure resources.
Log Analytics & KQL
Store and query logs with Kusto Query Language for deep troubleshooting and trend analysis.
Diagnostic Settings
Configure which logs and metrics to collect and the destinations to receive them.
Alerts
Define conditions on metrics or logs and connect action groups to notify or automate responses.
Action Group
Collection of notifications and actions that a fired alert will trigger.
Azure SQL Analytics
A specialized solution that surfaces SQL performance insights across databases.
Summary Takeaway

Collect what you need, route where it’s useful, and alert on what requires action to keep databases reliable and debuggable.
