Applied Objectives

These objectives map directly to the hands-on activity so you can verify competency after practice.

05
Run Query Store analytics
Retrieve top CPU queries and correlate execution plans with observed spikes; milestone: match a query ID to a slow period in Query Store.
VERIFIED COMPETENCY MILESTONE
06
Inspect live waits and blocking
Identify blocking sessions with dm_exec_requests and dm_tran_locks; milestone: find blocking_session_id and the blocking SQL text in a live sample.
VERIFIED COMPETENCY MILESTONE
07
Classify waits via sys.dm_os_wait_stats
Map waits like PAGEIOLATCH and LCK_M_X to remediation steps such as indexing or investigating blocking chains; milestone: recommend an initial action for a given dominant wait type.
VERIFIED COMPETENCY MILESTONE
08
Validate recommendations safely
Test automated index or plan changes in a non-production environment before applying; milestone: run a before/after comparison of key metrics for a target query.
VERIFIED COMPETENCY MILESTONE
