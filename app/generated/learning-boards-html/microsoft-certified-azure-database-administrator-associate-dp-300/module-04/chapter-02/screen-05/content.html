Definition

Key DMVs to Know

Target these DMVs when diagnosing common problems: who is running work, what they run, and where waits occur.

sys.dm_exec_sessions — connection and client details
sys.dm_exec_requests — active requests, CPU, reads, blocking
sys.dm_io_virtual_file_stats — per-file I/O counters
sys.dm_tran_locks — current locks and resources
Example
-- Inspect blocking and SQL text for active requests SELECT r.session_id, r.blocking_session_id, r.wait_type, r.cpu_time, st.text AS sql_text FROM sys.dm_exec_requests r CROSS APPLY sys.dm_exec_sql_text(r.sql_handle) st WHERE r.session_id <> @@SPID ORDER BY r.cpu_time DESC;
Supporting Point
Cross-apply to get SQL text and use blocking_session_id to trace the blocking chain.
Pro Tip
Avoid wide DMV joins on busy systems; start with the minimal columns you need.
Key Takeaway

Pick the smallest DMV that answers your question to limit diagnostic overhead and speed resolution.
