Hands-on Activity

Analyze Query Store Data

Steps:
  1. Enable Query Store on a non-production copy.
  2. Run representative workload to populate Query Store.
  3. Use SSMS report or run the Query Store DMV query to find top consumers.
  4. Inspect plans for top queries and test a remediation in staging.
  5. Measure before/after and document the result.
Sample workload snippets to run:
SELECT * FROM sys.objects ORDER BY name;
SELECT COUNT(*) FROM sys.columns;
WAITFOR DELAY '00:00:05'; -- simulate long-running query
SELECT TOP 10 * FROM sys.messages ORDER BY message_id DESC;
Validation
Capture key metrics such as CPU time, logical reads, and execution count for the target query before and after your change. Confirm the change benefits the targeted workload and does not introduce regressions.
Safety Note
Some DMV queries can be heavy on busy systems; avoid running large cross-database joins in production and always prefer targeted diagnostics.
Key Takeaway

This activity turns recorded Query Store data into validated fixes; test everything under representative load before production changes.
