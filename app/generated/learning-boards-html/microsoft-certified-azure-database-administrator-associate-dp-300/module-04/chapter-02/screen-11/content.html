Core Concept

Common Bottlenecks

CPU: inefficient plans, missing indexes, expensive scalar functions. Check CPU time in dm_exec_requests and Query Store.
I/O: PAGEIOLATCH waits and high logical reads. Check io virtual file stats and query logical reads.
Memory: low cache hit ratios and paging; examine buffer usage and plan cache pressure.
Blocking: LCK_M_X waits and blocking_session_id chains in dm_exec_requests and dm_tran_locks.
Scenario
If you see high CPU and many CXPACKET waits, investigate parallelism, check expensive missing-index candidates, and review plan operators for excessive work per row.
Remediation Checklist
  • Identify top queries by resource from Query Store.
  • Inspect execution plans for scans, sorts, or nested loops on large rowsets.
  • Test index or query changes in staging and measure before/after metrics.
Key Takeaway

Correct diagnosis determines whether to tune queries, change indexes, or scale resources; don’t assume scaling is the first step.
