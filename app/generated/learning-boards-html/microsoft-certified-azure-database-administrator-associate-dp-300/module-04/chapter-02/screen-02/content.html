Learning Objectives

These skills emphasize live diagnosis, historical analysis, and safe tuning practices.

Bloom: Learn → Understand → Apply → Master
01
Utilize Dynamic Management Views
Run and interpret DMV queries to inspect active sessions, requests, I/O stats, and locks in real time. Knowing which DMV to query speeds diagnosis during incidents.
Mnemonic: live window icon
VERIFIED COMPETENCY MILESTONE
02
Interpret Query Store
Use Query Store reports and DMVs to find historical plan changes, top CPU or I/O consumers, and regression windows so you can restore or force a better plan when justified.
Mnemonic: recorder tape
VERIFIED COMPETENCY MILESTONE
03
Leverage Intelligent Insights
Understand AI-driven findings and recommendations; validate automated index or plan changes in a test environment before applying them in production.
Mnemonic: magnifier + spark
VERIFIED COMPETENCY MILESTONE
04
Identify common bottlenecks
Recognize CPU, I/O, memory, and blocking symptoms in metrics and DMVs so you can choose targeted remediation and measure impact.
Mnemonic: four-pillar chart
VERIFIED COMPETENCY MILESTONE
