Comparison

Intelligent Insights vs Performance Recommendations

Intelligent Insights: anomaly detection, root cause hints, and narrative explanations.
Performance Recommendations: index suggestions, parameterization help, and optional automatic tuning actions.
Guideline
Treat insights as diagnostic leads and recommendations as candidate changes. Validate both with representative tests before applying.
Concrete Scenario
Intelligent Insights flags a sudden degradation for a reporting workload and recommends a non-clustered index. Test by creating the index in staging, replay representative queries, and compare CPU and logical reads before applying to production.
Common Mistake
Applying recommendations without measuring impact can introduce regressions elsewhere; indexes have global effects on DML and storage.
Key Takeaway

Automated tools accelerate discovery but require human validation to ensure changes benefit overall workload.
