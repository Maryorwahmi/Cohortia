Query Store Code Walkthrough

Run these DMVs to surface top CPU consumers, then inspect plans and runtime stats for regression analysis.

-- Top 10 queries by average CPU time from Query Store SELECT TOP 10 qt.query_text_id, q.query_id, qt.query_sql_text, SUM(rs.avg_cpu_time) AS total_avg_cpu_time, SUM(rs.count_executions) AS total_executions FROM sys.query_store_query_text AS qt JOIN sys.query_store_query AS q ON qt.query_text_id = q.query_text_id JOIN sys.query_store_plan AS p ON q.query_id = p.query_id JOIN sys.query_store_runtime_stats AS rs ON p.plan_id = rs.plan_id GROUP BY qt.query_text_id, q.query_id, qt.query_sql_text ORDER BY total_avg_cpu_time DESC;
Next Steps
1. Select top query_id from result. 2. Query sys.query_store_plan for that query_id and list plan_id and plan hash. 3. Query sys.query_store_runtime_stats filtered by plan_id to compare performance.
Pro Tip
Also check execution count: a moderate-cost query with millions of executions may have higher cumulative cost than a single expensive one.
Key Takeaway

Combine average per-execution metrics with execution counts and plan comparisons to prioritize actions.
