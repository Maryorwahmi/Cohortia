Key Concepts — Part 1

Dynamic Management Views (DMVs)
System views that expose current internal server state for live diagnostics.
Wait Statistics
Aggregated wait types that indicate which resource class queries are waiting on.
Query Store
Persistent capture of query text, execution plans, and runtime stats for retrospection.
Summary
Use DMVs for immediate evidence, wait stats to classify the resource, and Query Store to analyze historical changes and regressions.
