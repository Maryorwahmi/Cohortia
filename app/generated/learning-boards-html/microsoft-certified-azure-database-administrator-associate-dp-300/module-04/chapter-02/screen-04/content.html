Core Concept

Dynamic Management Views

Read-only server views that report current engine state. Use them to inspect sessions, requests, waits, and I/O at the moment of analysis.

Examples: sys.dm_exec_requests, sys.dm_exec_sessions
I/O stats: sys.dm_io_virtual_file_stats
Waits: sys.dm_os_wait_stats
Key Takeaway

DMVs are your live diagnostic lens: quick to query and essential for operational troubleshooting.

Definition
-- Example: currently running requests with wait types
SELECT
    session_id,
    status,
    command,
    blocking_session_id,
    wait_type,
    wait_time,
    last_wait_type,
    wait_resource,
    cpu_time,
    total_elapsed_time,
    reads,
    writes,
    logical_reads,
    program_name,
    query_text = SUBSTRING(st.text, (r.statement_start_offset / 2) + 1,
                           ((CASE r.statement_end_offset
                                 WHEN -1 THEN DATALENGTH(st.text)
                                 ELSE r.statement_end_offset
                             END - r.statement_start_offset) / 2) + 1)
FROM
    sys.dm_exec_requests AS r
CROSS APPLY
    sys.dm_exec_sql_text(r.sql_handle) AS st
WHERE
    r.session_id <> @@SPID
ORDER BY
    cpu_time DESC;
Supporting Point
DMVs show current waits and resource usage; use them to capture live contention evidence.
Common Mistake
Expecting DMVs to show historical spikes. They may not if the incident already subsided.
