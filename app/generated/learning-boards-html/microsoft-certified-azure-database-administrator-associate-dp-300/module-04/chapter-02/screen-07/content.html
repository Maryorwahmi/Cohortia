Definition

Query Store

A historical recorder of queries, plans, and runtime stats. Use it to find regressions and compare plans across time.

sys.query_store_query, sys.query_store_plan, sys.query_store_runtime_stats
Built-in reports in SSMS: Top Resource Consuming Queries
Key Takeaway

Use Query Store to attach performance changes to plan changes and to recover a better-known plan when appropriate.

Example Query
-- Top 10 queries by average CPU time from Query Store
SELECT TOP 10
    qt.query_text_id,
    q.query_id,
    qt.query_sql_text,
    SUM(rs.avg_cpu_time) AS total_avg_cpu_time,
    SUM(rs.count_executions) AS total_executions
FROM
    sys.query_store_query_text AS qt
JOIN
    sys.query_store_query AS q
    ON qt.query_text_id = q.query_text_id
JOIN
    sys.query_store_plan AS p
    ON q.query_id = p.query_id
JOIN
    sys.query_store_runtime_stats AS rs
    ON p.plan_id = rs.plan_id
GROUP BY
    qt.query_text_id, q.query_id, qt.query_sql_text
ORDER BY
    total_avg_cpu_time DESC;
Supporting Point
Query Store is persistent; it lets you inspect plan changes after the fact, unlike transient DMV state.
