Module 5 › Chapter 4.6 › Correlate App & DB
Step-by-step cards
1. Select
Identify application error logs and database diagnostics tables.
2. Filter
Narrow by HTTP status, error category, or slow-query thresholds.
3. Normalize
Ensure resource names align across tables for joins.
4. Join
Join on resource and a small time window, then inspect combined rows.
Example
Find AppServiceHTTPLogs with 5xx and join to AzureDiagnostics errors within one minute to see coincident events for the same resource.
Pitfall

Correlation does not prove causation. Use trace ids or step into traces to confirm the causal path.
