Module 5 › Chapter 4.6 › Distributed Tracing
Tracing pattern
  • Create a trace for the incoming request with a root operation id.
  • Record child spans for calls to services and database interactions.
  • Include correlation ids in application logs and custom metrics.
Concrete example
Instrument a web API endpoint so that the call to the database appears as a child span showing duration and any exceptions. Traces expose where time accumulates across the path.
Misconception check
Tracing does not replace metrics or diagnostics; it complements them by showing the user-perceived path and time distribution, helping to map metrics to code paths.
Key Takeaway

Use tracing to tie user latency to database calls. Instrument key endpoints, include correlation ids, and combine traces with KQL correlation for full diagnostics.
