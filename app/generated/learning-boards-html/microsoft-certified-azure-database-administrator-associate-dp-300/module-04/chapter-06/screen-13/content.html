Module 5 › Chapter 4.6 › Capacity Planning
Trend analysis timeline
  1. Collect daily and weekly metrics for CPU, IOPS, memory, and storage growth.
  2. Identify peak-hour percentiles (e.g., 95th percentile CPU).
  3. Project growth to forecast when thresholds will be reached.
Decision framework
If write-heavy and CPU-limited, scale up. If read-heavy, consider read replicas. Always attempt tuning before costly scaling.
Practical steps
  • Use Azure Advisor recommendations as one input.
  • Test scaling in staging, monitor the impact, and revert if required.
  • Combine scaling with index and query tuning for cost-efficiency.
Key Takeaway

Forecast using percentiles and storage growth, test scaling actions, and prioritize optimization before capacity increases when possible.
