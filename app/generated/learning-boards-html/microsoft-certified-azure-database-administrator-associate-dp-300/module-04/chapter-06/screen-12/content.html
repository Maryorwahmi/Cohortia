Module 5 › Chapter 4.6 › Custom Telemetry
When to create custom telemetry
  • When business or application context is missing from default logs.
  • When you need a correlation id across systems.
  • When a pattern recurs and you need targeted aggregation for alerts.
Instrumentation tips
  • Emit low-cardinality custom metrics for counts and durations.
  • Log correlation ids and key context fields to custom logs.
  • Plan retention and sampling to avoid cost spikes.
Key Takeaway

Custom telemetry gives you the missing link between business events and database behavior, making correlation and alerts more precise.
