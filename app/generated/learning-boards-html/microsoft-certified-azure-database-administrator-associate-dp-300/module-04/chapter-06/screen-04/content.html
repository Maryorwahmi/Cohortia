Definition & Core Operators
  • let: name an expression or window for reuse.
  • parse: extract structured fields from message text.
  • summarize: aggregate values over bins or groups.
  • join: correlate two tables by resource and time.
Concrete example
Define a CPU threshold and find top queries during spikes by joining AzureMetrics and AzureDiagnostics within the same time window.
Key Takeaway

KQL makes correlation explicit: name windows, extract fields, and join by resource and time to turn telemetry into root-cause evidence.

Common misconception
Assuming a single slow query is the entire cause. Often spikes include multiple queries or infrastructure bottlenecks like I/O bursts.
Try this pattern
  1. Define thresholds and a lookback using let statements.
  2. Find metric bins that exceed thresholds with summarize.
  3. Join diagnostics filtered by the same resource and time window.
  4. Order by aggregated CPU or duration to find top offenders.
Scenario Card
During an evening spike you correlate CPU percent rising above 80% with several queries that together consumed most CPU; optimization reduced the peak.
