Simple KQL to find deadlocks
AzureDiagnostics
| where ResourceProvider == "MICROSOFT.SQL" and Category == "Deadlock"
| project TimeGenerated, Resource, DeadlockXml = Message
| order by TimeGenerated desc
| take 50
This retrieves recent deadlock XML blobs. Use take and date filters to limit load.
Next steps after retrieval
  • Copy XML into a deadlock visualizer to view the lock graph.
  • Parse XML to extract victim's session id and involved SQL text.
  • Map session ids back to application traces or connection strings to find the calling code.
Safety note
Avoid scanning large time ranges in production. Use precise filters and | take to reduce diagnostic load.
