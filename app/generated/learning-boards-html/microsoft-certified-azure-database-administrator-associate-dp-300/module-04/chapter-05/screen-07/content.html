Module 4 › Chapter 4.5 › Enable Tuning
Scope choices
Server-level defaults apply across databases; database-level settings let you tune per workload.
Recommended workflow
  1. Enable monitor-only at database scope and collect recommendations.
  2. Review Query Store and suggested actions over time.
  3. Enable apply automatically selectively after validation.
Mode differences
Monitor-only records recommendations. Apply automatically allows immediate changes when recommendations are validated.
Safety tip
Use monitor-only first. If applying automatically, consider limiting to Force Plan initially before index create/drop.
Common Mistake

Turning on apply automatically without an observation period can introduce unexpected index changes that affect writes or rare reports.
