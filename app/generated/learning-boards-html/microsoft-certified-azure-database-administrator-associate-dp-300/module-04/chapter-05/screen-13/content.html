Adaptive Query Processing features
Batch mode adaptive joins
Choose join strategies during execution based on observed row counts.
Interleaved execution
Use actual nested results to refine upstream cardinality estimates within the same execution.
Memory grant feedback
Adjusts memory grants over time to avoid spills or wasted allocation for repeating queries.
AQP works automatically when database compatibility levels and engine features support it. It complements statistics and tuning by adding runtime resilience to queries that would otherwise suffer when estimates are wrong.
Example
Memory grant feedback reduces memory spills for a repeated analytic query by adjusting grants after observing actual usage.
Misconception
AQP is not a substitute for good statistics and maintenance; it helps where runtime feedback can improve plan choices.
