Module 4 › Chapter 4.5 › Scheduled Maintenance
Index fragmentation
Fragmented indexes increase random I/O. Use fragmentation metrics to decide between reorganize and rebuild.
Rebuild
Creates a new index to provide optimal page ordering; typically used for high fragmentation.
Reorganize
Lightweight inline defragmentation that moves pages to improve order without full rebuild cost.
Statistics updates
Keep column and index statistics current so the optimizer can choose effective plans. Schedule updates after large data loads.
Practical rule
Use fragmentation thresholds to trigger maintenance and schedule heavy work during off-peak windows. Prefer ONLINE rebuilds where supported to reduce impact.
Common Mistake

Rebuilding indiscriminately wastes resources. Target only indexes that exceed fragmentation thresholds or are known hotspots.
