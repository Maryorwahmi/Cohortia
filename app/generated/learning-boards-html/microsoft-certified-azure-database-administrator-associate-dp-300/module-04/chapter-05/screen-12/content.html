High-level steps
  1. Retrieve credentials from Automation assets or use Managed Identity.
  2. Connect to Azure SQL Database securely.
  3. Query fragmentation using sys.dm_db_index_physical_stats.
  4. Rebuild or reorganize when thresholds are exceeded, optionally with ONLINE = ON.
  5. Log actions and close connections.
Remember to include try/catch blocks, dry-run flags, and alerting for failures or long-running operations.
Example (simplified)
# Connect and check fragmentation
$cmd.CommandText = "SELECT OBJECT_NAME(ips.object_id) AS TableName, i.name AS IndexName, ips.avg_fragmentation_in_percent FROM sys.dm_db_index_physical_stats(DB_ID(), NULL, NULL, NULL, 'LIMITED') AS ips INNER JOIN sys.indexes AS i ON ips.object_id = i.object_id AND ips.index_id = i.index_id WHERE ips.avg_fragmentation_in_percent > 30 AND ips.index_id > 0;"
$reader = $cmd.ExecuteReader()
while ($reader.Read()) {
  $tableName = $reader.GetString(0)
  $indexName = $reader.GetString(1)
  $fragmentation = $reader.GetDouble(2)
  Write-Output "Rebuilding index '$indexName' on table '$tableName' with fragmentation $fragmentation%"

  $rebuildCmd.ExecuteNonQuery()
}
$reader.Close()
