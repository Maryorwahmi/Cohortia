Module 4 › Chapter 4.5 › Statistics Updates
When to update statistics
  • After large data imports or batch updates.
  • When query plans shift due to stale estimates.
  • On a schedule if your workload patterns are predictable.
Misconception
Running full statistics updates constantly wastes resources; target updates where data changes are significant.
T-SQL example
-- Update statistics for a single table
UPDATE STATISTICS [dbo].[Sales];

-- Update with fullscan for more accurate stats after large imports
UPDATE STATISTICS [dbo].[LargeTable] WITH FULLSCAN;

-- Update statistics for all tables (use with caution)
EXEC sp_msforeachtable 'UPDATE STATISTICS ? WITH SAMPLE 50 PERCENT';
When you automate, include checks for data-change thresholds and run full scans only when justified.
Key Takeaway

Schedule statistics updates after significant data changes and automate them with checks to avoid unnecessary system load.
