Module 4 › Chapter 4.5 › Key Concepts
Automatic Tuning
Force Plan, Create Index, Drop Index perform workload-driven corrections; validate before apply.
Maintenance Tasks
Index rebuilds/reorganizes and statistics updates correct fragmentation and stale estimates on a schedule.
Azure Automation
Runbooks schedule and run maintenance tasks with secure credentials and auditing.
Takeaway
Automate carefully: test in non-production, run in monitor-only first, and use runbooks to apply threshold-based maintenance during safe windows.
