Enable automatic tuning
You will learn to enable Force Plan, Create Index, and Drop Index at server or database level and choose monitor or apply modes. This matters because automated decisions can reduce regressions when configured carefully.

Schedule maintenance tasks
You will configure index rebuilds/reorganizes and statistics updates using automation so fragmentation and stale stats are corrected on a predictable cadence.
VERIFIED COMPETENCY MILESTONE
03
Author Automation runbooks
You will create PowerShell or Python runbooks that connect to databases, check fragmentation, and run rebuilds or statistics updates as scheduled tasks.
VERIFIED COMPETENCY MILESTONE
04
Understand Adaptive Query Processing
You will learn how AQP features like memory grant feedback or interleaved execution adapt plans at runtime to handle skew and improve stability.
