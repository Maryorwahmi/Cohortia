Module 4 › Chapter 4.5 › Automatic Tuning
What automatic tuning does
Automatic tuning uses observed queries to suggest or apply three actions that reduce regressions and improve throughput.
Force Plan
Pins a previously known good execution plan when a query's plan regresses, avoiding sudden slowdowns.
Create Index
Recommends and can create non-clustered indexes that benefit recurring query patterns.
Drop Index
Finds unused or duplicate indexes and can drop them to reduce write and storage cost.
Example
When a previously fast report query slows after a plan change, automatic tuning can force the last good plan so user experience is preserved while you investigate the root cause.
Key Takeaway

Automatic tuning reduces regression risk by applying proven corrections, but it requires monitoring and staged rollout for index create/drop actions.

Misconception
Automatic tuning is not a set-and-forget replacement for human review. It is a tool that automates corrective actions while you validate recommendations and monitor outcomes.
Monitoring modes
  • Monitor only: record recommendations without applying changes.
  • Apply automatically: allow the service to enact recommendations.
Practical check
Start with monitor-only or test in non-production. Review suggested indexes and drops before allowing automatic application.
