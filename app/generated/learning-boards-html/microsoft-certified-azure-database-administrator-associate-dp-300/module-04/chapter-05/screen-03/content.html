Practical Objectives
Test in non-production, monitor recommendations, automate safely.
Test first
Validate index recommendations and runbooks in a non-production environment to avoid unintended impact.
Monitor before apply
Use monitor-only mode to review recommendations before switching to automatic apply for create and drop index actions.
Schedule smartly
Run heavy maintenance like rebuilds during low-traffic windows and consider ONLINE rebuilds when supported.
Review regularly
Periodically inspect Query Store and tuning recommendations to catch persistent issues or false positives.
