Module 4 › Chapter 4.4 › Composite Indexes
Design process
1. List query predicates
Capture WHERE, JOIN, ORDER BY, and GROUP BY columns used by critical queries.
2. Rank by selectivity
Place the most selective equality column first for best pruning effect.
3. Include ordering if needed
Add ORDER BY columns to the index key or as an included column to avoid sorts.
4. Test and measure
Create the index, re-run EXPLAIN ANALYZE, and confirm fewer rows and lower cost.
Example
-- Target query filters by Category and StockQuantity and orders by Price CREATE INDEX IX_Products_Category_Stock_Price ON Products (Category, StockQuantity, Price); -- Alternatively in Azure SQL add INCLUDE(ProductName) to cover output
This composite index supports the WHERE filters and can also help avoid sorting by Price when appropriate.
