Module 4 › Chapter 4.4 › Inefficient Patterns
Table Scan
Cause: missing index or non-selective predicate. Fix: add index for selective columns or accept scan for small tables.
Filesort / Sort
Cause: ORDER BY without usable index ordering. Fix: include order column in index or rewrite query.
Nested Loop Join
Cause: large unindexed inner side. Fix: index join keys or encourage hash/merge join via statistics or rewrite.
Key Lookup
Cause: index doesn't cover required columns. Fix: make the index covering using INCLUDE or add needed columns.
Excessive Materialization
Cause: SELECT * or wide projections. Fix: select only needed columns and consider intermediate staging.
Stale Statistics
Cause: data changes after a large load or delete. Fix: run ANALYZE or UPDATE STATISTICS then re-evaluate plan.
Key Takeaway

Prioritize fixing the highest-cost patterns first: scans and sorts on large row counts, then expensive join behaviour.
