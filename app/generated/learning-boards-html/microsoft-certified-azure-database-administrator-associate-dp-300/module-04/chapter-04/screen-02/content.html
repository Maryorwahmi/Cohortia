Learning Objectives
Four measurable skills to analyze and optimize queries across Azure SQL, PostgreSQL, and MySQL.
01
Run and interpret EXPLAIN

Use EXPLAIN and EXPLAIN ANALYZE to compare estimated versus actual rows and timings. This skill reveals where optimizer estimates diverge from reality.

VERIFIED COMPETENCY MILESTONE
02
Spot inefficient plan patterns

Recognize table scans, filesorts, and nested loops on large unindexed inputs so you can prioritize fixes.

VERIFIED COMPETENCY MILESTONE
03
Design effective indexes

Choose columns and order for composite and covering indexes to satisfy WHERE, JOIN, and ORDER BY efficiently.

VERIFIED COMPETENCY MILESTONE
04
Manage statistics & rewrites

Keep statistics current and apply simple rewrites like avoiding SELECT star, replacing IN with EXISTS where useful, and using UNION ALL.
