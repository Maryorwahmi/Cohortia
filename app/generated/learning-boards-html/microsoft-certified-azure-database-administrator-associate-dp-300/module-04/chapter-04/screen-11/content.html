Common rewrites
  • Avoid SELECT * — request only required columns so indexes can cover the query.
  • Use EXISTS vs IN — EXISTS can short-circuit and avoid scanning entire subquery results.
  • Prefer UNION ALL — skip duplicate elimination when not needed to avoid sort overhead.
  • Simplify joins — join on indexed columns and avoid functions on join keys.
Example change
-- Before: SELECT * FROM Products WHERE Category='Electronics' AND StockQuantity < 10; -- After: SELECT ProductName, Price, StockQuantity FROM Products WHERE Category='Electronics' AND StockQuantity < 10;
Narrowing the column list may allow a covering index to satisfy the query entirely and avoid lookups.
Try this

Before adding an index, try a simple rewrite and check EXPLAIN ANALYZE for reduced cost.

Misconception

Not every rewrite helps; measure to avoid wasted effort.
