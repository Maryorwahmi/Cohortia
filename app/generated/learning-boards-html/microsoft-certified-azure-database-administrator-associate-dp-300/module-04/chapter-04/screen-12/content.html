Module 4 › Chapter 4.4 › Products Optimization
Baseline
EXPLAIN ANALYZE SELECT ProductName, Price, StockQuantity FROM Products WHERE Category = 'Electronics' AND StockQuantity < 10 ORDER BY Price DESC LIMIT 10;
Record actual rows, operators (Seq Scan), and total time before making changes.
Index to add
-- Azure SQL CREATE NONCLUSTERED INDEX IX_Products_Category_Stock_Price ON Products (Category, StockQuantity) INCLUDE (ProductName, Price); -- PostgreSQL / MySQL: create composite index on Category, StockQuantity, Price
Create the index, then re-run EXPLAIN ANALYZE to compare operator changes and timings.
Expected result

Index Seek or Index Scan replaces Seq Scan, fewer rows processed, and lower execution time.

If not improved

Update statistics and re-check. Consider index order or covering columns.

Watch out

Assess write overhead for the new index before applying it to heavy-write tables.
