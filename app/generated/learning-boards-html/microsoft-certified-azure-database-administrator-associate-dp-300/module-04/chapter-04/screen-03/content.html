Measure, Change, Verify

A disciplined workflow reduces guesswork and prevents over-indexing. Use actual execution plans to validate improvements.

Step 1 — Capture baseline
Run EXPLAIN ANALYZE and record actual rows, time, and high-cost operators.
Step 2 — Apply one change
Create targeted index or update stats; avoid multiple simultaneous changes.
Step 3 — Re-run and compare
Confirm index scan, reduced rows, and lower total time. If not improved, revert or try a different approach.
Quick checklist
  • Record estimated vs actual rows and times.
  • Identify single highest-cost operator to target.
  • Make one change and re-measure immediately.
  • Consider write overhead before adding indexes.
