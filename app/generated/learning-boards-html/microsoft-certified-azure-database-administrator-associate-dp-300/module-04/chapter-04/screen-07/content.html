Why indexes matter
They reduce I/O and CPU for reads by avoiding full table scans on selective queries.
Types to know
  • Clustered index — defines physical order of rows (SQL Server).
  • Non-clustered index — secondary structure for lookups.
  • B-tree indexes — common for range and equality queries.
  • Hash and full-text — specialized use cases.
Analogy
An index is like the index of a book: you use it to jump directly to relevant pages instead of scanning every page.
Key Takeaway

Create indexes to match query predicates; they speed reads but slow writes and use storage.
