Module 4 › Chapter 4.3 › Tuning Workflow
Step-by-step
  1. Record baseline metrics under representative load.
  2. Enable and collect slow logs; enable pg_stat_statements if possible.
  3. Prioritize queries by frequency and cumulative time, not only single slow runs.
  4. Use EXPLAIN to inspect plans and decide index or rewrite strategies.
  5. Apply one change, monitor same metrics, and iterate.
Common Mistakes
  • Tuning multiple parameters at once, making root cause unclear.
  • Increasing memory beyond physical RAM and causing swapping.
  • Targeting only single slow executions and ignoring high-frequency moderate-cost queries.
