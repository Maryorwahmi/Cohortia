Key Parameters
MySQL tuning essentials
  • innodb_buffer_pool_size: primary InnoDB cache for data and indexes; set large but within RAM limits.
  • max_connections: limit concurrent sessions to avoid per-connection memory exhaustion.
  • slow_query_log & long_query_time: enable and tune to capture queries over a sensible threshold for your workload.
  • query_cache_size: often deprecated; avoid for high-concurrency workloads where it may cause contention.
Scenario
Admin notices high CPU and slow responses. They inspect innodb buffer settings and find a tiny pool on a server with large RAM. Increasing the pool will likely reduce disk reads and lower CPU wait time. Monitor after change to ensure no swapping.
Watchout
Some parameters are limited by Azure's managed environment. Use the Server parameters blade and check allowed ranges before planning large changes.
Action
Increase innodb_buffer_pool_size to a sensible fraction of RAM and monitor IOPS, read latency, and memory usage.
