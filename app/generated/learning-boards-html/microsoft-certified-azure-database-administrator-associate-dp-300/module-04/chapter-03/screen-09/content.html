KQL Example
AzureDiagnostics
| where ResourceProvider == "MICROSOFT.DBFORPOSTGRESQL"
| where Category == "PostgreSQLLogs"
| parse Message with * "duration: " duration_ms:long " ms  statement: " query_text:string
| where isnotempty(duration_ms) and duration_ms > 500
| project TimeGenerated, Resource, query_text, duration_ms
| order by TimeGenerated desc
Explanation
  • Filter logs for your provider and category to narrow to database logs.
  • Parse the message to extract duration and the statement text for easy sorting.
  • Order by time and duration to find recent and long-running statements for inspection.
Pro Tip

Use time filters and grouping to find frequently occurring statements rather than only the single slowest execution.
