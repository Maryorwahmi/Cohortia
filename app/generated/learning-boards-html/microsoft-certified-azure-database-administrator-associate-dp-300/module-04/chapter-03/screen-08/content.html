How to enable
PostgreSQL and MySQL logging
  • PostgreSQL: set log_min_duration_statement to a threshold like 500 to log queries slower than 500ms.
  • MySQL: set slow_query_log = ON and long_query_time = 1 to capture queries over one second.
  • Use Diagnostic Settings to send PostgreSQLLogs or MySQL logs to a Log Analytics workspace for analysis.
Best practices
Choose thresholds that balance usefulness against log volume. Test threshold values in staging, and ensure retention and filtering are configured to keep costs manageable.
Example
Set log_min_duration_statement = 500, run a report, wait for logs to arrive in Log Analytics, then filter by duration to find slow statements.
Misconception
Logs alone don't reveal frequency or cumulative cost. Combine logs with aggregated stats to prioritize optimizations.
