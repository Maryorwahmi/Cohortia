Module 2 › Chapter 1.4 › Database-level Firewall Rules
What it is
A rule stored inside one Azure SQL Database that permits specific IP addresses to connect to that database only.
When to use
When an application or client must be allowed to a single database while other databases remain private.
Limitations
Works for Azure SQL Database single or elastic pools. Not applicable to Managed Instance or all flexible servers.
T-SQL example
-- T-SQL example for Azure SQL Database database-level firewall
EXEC sp_set_database_firewall_rule N'WebAppAccess', '192.168.1.10', '192.168.1.10';
Concrete example
An application server with IP 192.168.1.10 needs access only to customerdb. Add the rule and test the connection from that server. If the server tries to reach other databases, the network rule will prevent a connection.
Misconception

A database-level firewall rule does not grant access to database objects; you must still assign appropriate database users and roles.
