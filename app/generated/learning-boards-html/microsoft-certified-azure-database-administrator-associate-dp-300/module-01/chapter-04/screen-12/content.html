Module 2 › Chapter 1.4 › Hands-on Activity
Configure server firewall and simulate VNet service endpoint
1
Add server-level firewall rule
In the SQL server Networking blade, set Public network access to Selected networks, then Add your client IP or add a named rule for the known IP range and save.
2
Simulate service endpoint
On the same Networking page, add an existing virtual network and enable the Microsoft.Sql service endpoint on the chosen subnet to route traffic over the backbone.
3
Validate
Test connectivity from the allowed IP and from a VM in the subnet to confirm access and routing. Check DNS resolution if using Private Link later.
Lab tip

Coordinate with network owners before changing VNet settings and retain rollback steps to quickly revert changes if a test impacts production traffic.
