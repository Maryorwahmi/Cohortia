Module 2 › Chapter 1.4 › Authentication Options
SQL Authentication
Usernames and passwords managed by the database server itself. Common for legacy apps.
Requires careful password rotation and does not provide organizational identity policies like MFA or centralized auditing.
Azure AD Authentication
Centralized identity via Azure Active Directory for users, groups, and service principals.
Supports SSO, MFA, and centralized lifecycle management. Still requires database permissions to be granted to AD identities.
CLI example — set Azure AD admin
# Azure CLI example to set an Azure AD admin for Azure SQL Server
az sql server ad-admin create \
  --resource-group myResourceGroup \
  --server mySqlServer \
  --display-name "myAADAdmin" \
  --object-id
Concrete example: designate an Azure AD group as server admin, then grant a database role to a second group so application users receive least-privilege access automatically through group membership.
