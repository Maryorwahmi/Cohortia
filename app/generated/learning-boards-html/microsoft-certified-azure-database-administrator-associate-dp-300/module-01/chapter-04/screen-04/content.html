Module 2 › Chapter 1.4 › Network Access Control
Server-level vs Database-level
Define broad server access or narrow database-only access to control network reachability.
Server-level rule
Applies to all databases on the server. Use for shared client ranges, but avoid overly broad ranges.
Database-level rule
Stored in the database and restricts access to a single database. Not available for all server types.
Common mistake
Allowing broad IP ranges or enabling 'Allow Azure services' without compensating controls can grant unintended access. Use least privilege and combine with private connectivity where possible.
CLI example — server firewall rule
# Azure CLI example for Azure SQL Database server firewall
az sql server firewall-rule create \
  --resource-group myResourceGroup \
  --server mySqlServer \
  --name OfficeAccess \
  --start-ip-address 203.0.113.45 \
  --end-ip-address 203.0.113.45
Key Takeaway

Use server rules for known client ranges and database rules for per-database restrictions. Test connectivity after adding rules.
