Module 2 › Chapter 1.4 › Learning Objectives
Objective 01
Implement server-level and database-level firewall rules
01

Create IP allow rules at the server scope or at a specific database. This matters because server rules open access for all databases under the server while database rules narrow access to a single database.

Verified Competency Milestone
Objective 02
Differentiate VNet service endpoints and Azure Private Link
02

Understand how service endpoints secure traffic over the backbone and how Private Link assigns a private IP in your VNet for full private access and addressability.

Verified Competency Milestone
Objective 03
Configure Azure AD authentication for Azure databases
03

Set an Azure AD admin and use Azure AD users, groups, or service principals to authenticate, enabling single sign-on and centralized lifecycle management.

Verified Competency Milestone
Objective 04
Explain TDE and Always Encrypted for data protection
04

Distinguish between at-rest encryption with TDE and client-side column encryption with Always Encrypted, and when to apply customer-managed keys.

Verified Competency Milestone
