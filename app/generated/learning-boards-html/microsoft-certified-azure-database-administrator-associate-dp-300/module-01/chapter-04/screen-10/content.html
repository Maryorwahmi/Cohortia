Encryption in Transit
Client connections use TLS by default to protect data as it moves between client and server.
Ensure clients are configured to require TLS and validate certificates when compliance demands strict validation.
Transparent Data Encryption (TDE)
Encrypts database files, logs, and backups at the page level. Azure enables TDE by default but offers customer-managed keys.
Use service-managed keys for simplicity. Use customer-managed keys in Key Vault when you require rotation policies or stronger key control.
Misconception & Takeaway
Do not assume TDE prevents authorized users from reading data. TDE protects storage compromise; combine with client-side encryption for privacy against privileged insiders.
