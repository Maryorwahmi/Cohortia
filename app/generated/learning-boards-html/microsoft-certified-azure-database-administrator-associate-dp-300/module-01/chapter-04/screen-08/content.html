Module 2 › Chapter 1.4 › Azure Private Link Architecture
What Private Link provides
Private endpoint inside your VNet, private IP addressing, and traffic that never touches the public internet.
DNS
Configure private DNS so the database host resolves to the private IP. Without DNS changes, clients may still reach the public endpoint.
Security controls
Apply NSGs, route tables, and on-premises connectivity policies to private endpoint traffic like any other VNet resource.
Concrete example
Create a private endpoint in the 'app-subnet', approve the endpoint on the service resource, and add an A record in private DNS so myazuresqldb.database.windows.net resolves to the private IP. Then test from the app VM to confirm the private route.
Key Takeaway

Private Link delivers true private connectivity and simplifies network security by making PaaS resources part of your VNet address space.
