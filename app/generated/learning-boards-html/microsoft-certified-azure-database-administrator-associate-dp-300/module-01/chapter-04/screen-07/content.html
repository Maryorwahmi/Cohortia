Module 2 › Chapter 1.4 › Simulating VNet Service Endpoint
Enable service endpoint — step-by-step
1
Choose VNet and subnet
Identify the subnet where your application resources reside and that will reach the database over the backbone.
2
Enable service endpoint
Add the Microsoft.Sql service endpoint to the subnet. This can be done in the portal or with CLI/ARM templates.
3
Adjust database firewall settings
Allow the VNet or specific subnet ranges if your server requires explicit network entries.
4
Validate connectivity
Test from a VM or resource in the subnet to confirm traffic travels over the backbone and access is permitted.
Note

Service endpoints do not assign private IPs. If you require a private endpoint with a VNet address, implement Azure Private Link instead.
