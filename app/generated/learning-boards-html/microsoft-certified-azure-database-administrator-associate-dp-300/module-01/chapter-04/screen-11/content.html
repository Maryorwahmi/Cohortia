Module 2 › Chapter 1.4 › Always Encrypted
How it works
Clients encrypt column values before sending them to the database; only clients with keys can decrypt values back to plaintext.
Design consideration: encrypted columns may restrict certain queries and require application-driver support. Plan schema and queries accordingly.
Concrete scenario
A healthcare app stores diagnoses in an encrypted column. The application decrypts values on the client using a key in Key Vault, while DBAs cannot see plaintext in the database.
Key Takeaway

Always Encrypted prevents privileged server roles from reading sensitive columns. Use it alongside TDE and network protections for full defense in depth.
