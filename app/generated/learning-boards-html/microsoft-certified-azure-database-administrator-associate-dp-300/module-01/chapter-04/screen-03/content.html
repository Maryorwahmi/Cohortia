Module 2 › Chapter 1.4 › Learning Objectives — Practical Skills
Objective mapping
Firewall Rules
Create a server rule with Azure CLI and a database rule with T-SQL, then attempt a connection from the allowed IP to confirm access.
Private Connectivity
Enable a service endpoint on a subnet and compare connectivity. Then simulate a Private Link private endpoint to confirm private IP addressing.
Authentication & Encryption
Azure AD Auth
Set an Azure AD admin, then log in using an Azure AD identity to verify group membership and auditing information.
TDE & Always Encrypted
Confirm TDE is enabled and examine key management. Implement Always Encrypted for a column and validate that only the client can decrypt values.
Verification checklist
  • Server and database-level rules created and tested.
  • Service endpoint enabled and Private Link simulated where required.
  • Azure AD admin set and authentication validated.
  • TDE status checked and Always Encrypted tested for a sensitive column.
