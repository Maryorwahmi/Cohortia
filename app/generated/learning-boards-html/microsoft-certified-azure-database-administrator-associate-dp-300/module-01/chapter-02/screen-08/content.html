Definition
SQL Server on Azure VM
Full control of OS and SQL Server; suitable when PaaS cannot provide required features.
When to pick
Specific OS requirements, legacy dependencies, or unsupported SQL Server features in PaaS.
Operational overhead
You manage patching, backups, HA, and monitoring.
Example scenario
A legacy application requires a specific Windows configuration and native extensions that are not supported in Azure SQL PaaS, so it is hosted on a VM with SQL Server.
Common mistake
Choosing a VM for convenience without planning for ongoing OS and SQL Server maintenance tasks.
Key Takeaway
Prefer PaaS unless you truly need OS-level control; VMs are flexible but require more operations work.
