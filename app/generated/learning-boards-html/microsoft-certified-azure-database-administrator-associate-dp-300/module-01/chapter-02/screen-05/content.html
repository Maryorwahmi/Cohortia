Definition
Single Database
Fully managed, isolated database for a single application with low operational overhead.
Ideal for
Cloud-native apps, dev/test, and smaller production workloads.
Example
A microservice handling orders uses a Single Database to keep schema and access simple.
Misconception
Single Database cannot scale. In fact, you can scale compute and storage, and select Hyperscale if you need massive size.
Practical checklist
  • Confirm application isolation requirements and cross-database needs.
  • Estimate peak usage and whether per-database scaling is cost-effective.
  • Start with General Purpose tier for balanced workloads; monitor and adjust.
Key Takeaway

Use Single Database for independent apps; if you run many small databases with varying load, evaluate an Elastic Pool.
