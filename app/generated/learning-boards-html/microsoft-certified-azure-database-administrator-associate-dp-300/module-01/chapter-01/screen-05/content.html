Module 1 › Chapter 1.1 › IaaS for databases — VM-based deployments
Definition

Run your database on Azure VMs

Full control over OS and database engine. You manage patching, backups, and HA.

Concrete example

Running SQL Server on a VM to preserve SQL Server Agent jobs and cross-database queries is a typical IaaS choice.

When to choose

Legacy compatibility or custom OS-level requirements make IaaS appropriate despite higher operational overhead.

Common pitfall

Treating IaaS as zero-maintenance. You still own updates, backups, and availability architecture.

Operational checklist
  • Provision VM size and storage performance appropriate for workload.
  • Plan OS and engine patching windows and testing.
  • Implement backup solution and recovery testing.
  • Design HA using availability sets or zone-redundant deployments.
Quick scenario

A bank with strict on-prem features migrates to VMs to keep those features while using Azure for hardware and networking.
