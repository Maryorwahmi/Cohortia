Core Concept

Shared responsibility model for databases

Know what Azure manages and what your team must secure and monitor.

Azure responsibilities
  • Physical infrastructure and hypervisor.
  • Platform patching for PaaS.
  • Basic encryption and platform controls.
Customer responsibilities
  • Data governance and access controls.
  • Network isolation and firewall rules.
  • Authentication and key management.
Practical steps

Enable private access or VNet integration, apply RBAC, audit activity logs, and enable threat detection features where available.

Concrete example

For a PaaS database, rely on Azure for OS patching but configure firewall, VNet, and RBAC to restrict who can connect and manage data.

Common pitfall

Assuming platform defaults are secure enough for production. Always validate and add network and access controls as needed.

Key Takeaway

Document responsibilities and implement customer-side controls for data, access, and network isolation to meet security and compliance goals.
