Lab steps to follow (observe, don’t create)
  1. Search the portal for SQL, PostgreSQL, and MySQL services and open overview pages.
  2. Open the Create blade for each service and note deployment options like Single DB, Managed Instance, Flexible Server.
  3. Examine compute, storage, HA, and networking options to understand trade-offs.
  4. Close blades without creating resources; record notes about cost-driving settings.
Mnemonic
Observe → Record → Compare → Decide
What to note
  • Which deployment option matches feature needs.
  • Which networking options support private access or VNet integration.
  • How service tiers influence resilience and cost.
Key Takeaway

Knowing where to find configuration options helps you plan migrations and avoid accidental provisioning that creates cost or security exposure.
