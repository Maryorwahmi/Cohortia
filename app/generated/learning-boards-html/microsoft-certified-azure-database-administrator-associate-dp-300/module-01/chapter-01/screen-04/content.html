Core Concept

Service model comparison

Understand who owns OS, engine, backups, and which workloads fit each model.

IaaS — You manage OS & DB
  • Use when you need legacy features or full control.
  • Example: SQL Server on a VM to preserve agent jobs.
PaaS — Azure manages platform
  • Azure handles OS, patching, backups and HA.
  • Example: Azure SQL Database for managed relational needs.
SaaS — Application-level
  • Minimal infrastructure control; consume the service.
  • Example pattern: globally distributed multi-model services.
Key Takeaway

Match service model to the level of control you need and the operational burden you can support.

Misconception

Assuming PaaS removes DBA work entirely. In truth, PaaS shifts focus from infrastructure to database performance, tuning, and security tasks.
