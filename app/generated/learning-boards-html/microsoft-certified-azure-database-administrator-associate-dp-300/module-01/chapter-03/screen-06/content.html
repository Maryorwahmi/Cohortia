Tier comparison

Burstable

Best for development and small production workloads. Baseline CPU with burst capacity and easy cost savings when stopped during idle times.

General Purpose

Balanced CPU and memory for most business applications with predictable performance.

Memory Optimized

Higher memory and processing for high-performance transaction workloads and heavy caching.

Example

An internal analytics tool used mainly during business hours can use Burstable to save costs overnight and on weekends, then be scaled up if sustained peaks emerge.

Common Mistake

Picking a tier solely on initial price without forecasting steady-state usage or I/O needs.

Key Takeaway

Profile your workload and choose a tier that matches baseline needs; monitor and right-size after deployment.
