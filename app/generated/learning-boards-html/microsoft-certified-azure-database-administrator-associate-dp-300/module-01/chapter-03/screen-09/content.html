Module 1 › Chapter 1.3 › Deployment Walkthrough
Steps
  1. Create a Virtual Network and add a subnet delegated to the Flexible Server provider.
  2. Start Flexible Server creation and complete Basics: resource group, name, region, workload type.
  3. In Networking choose Private access and pick the delegated subnet.
  4. Optionally enable zone-redundant high availability if supported.
  5. Review and create, then verify the server has a private IP and VNet integration in the Networking blade.
Verification & Troubleshooting
  • If the subnet is not delegated, delegate it to Microsoft.DBforPostgreSQL/flexibleServers or Microsoft.DBforMySQL/flexibleServers, then retry.
  • Confirm private IP appears on the server overview and that application resources can connect within the VNet.
  • Check region and tier support for zone-redundant HA before enabling it.
Key Takeaway

Follow the VNet delegation and private access steps carefully. Verify the private IP and networking blade to ensure the server is isolated inside your VNet.
