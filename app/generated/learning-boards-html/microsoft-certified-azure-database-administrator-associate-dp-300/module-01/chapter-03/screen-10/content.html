Module 1 › Chapter 1.3 › Mistakes & Cost
Common mistakes
  • Picking Single Server for new production — loses VNet and HA features.
  • Under-provisioning storage and hitting IOPS limits despite spare CPU.
  • Assuming zone-redundant HA is available for all tiers and regions without checking.
Use monitoring and telemetry as your feedback loop to detect these problems early and adjust configuration accordingly.
Cost tips
  1. Use burstable for low-duty-cycle workloads.
  2. Stop the server during predictable idle periods.
  3. Right-size after observing production telemetry.
Checklist

Confirm VNet delegation, check HA support for the chosen region/tier, and provision storage for the expected IOPS including backup retention.
