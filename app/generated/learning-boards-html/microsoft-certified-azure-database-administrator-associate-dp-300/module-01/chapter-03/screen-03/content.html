Module 1 › Chapter 1.3 › Applied Objectives

Practice Tasks

  1. Create a VNet with a delegated subnet for Flexible Server.
  2. Deploy a Flexible Server selecting private access and confirm private IP assignment.
  3. Choose burstable or general purpose compute based on workload profile.
  4. Provision storage to meet expected IOPS and monitor I/O after deployment.

Verification Steps

Confirm subnet delegation to Microsoft.DBforPostgreSQL/flexibleServers or Microsoft.DBforMySQL/flexibleServers.
Check server overview for a private IP when private access is selected.
If HA was enabled, note the zone-redundant configuration in the High availability blade.
Monitor I/O and adjust storage if IOPS are constrained.
Verified Competency Milestone

Successfully deploy a Flexible Server into a delegated subnet with private access and confirm it appears on your VNet with a private IP address.
