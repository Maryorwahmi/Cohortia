Module 1 › Chapter 1.3 › Storage & IOPS
Definition

Provisioned storage controls IOPS

IOPS scale with provisioned storage size. If you provision too little storage, disk throughput becomes the limiting factor even when CPU is available.

Signs of under-provisioning
  • High disk queue length
  • Increased transaction latency
  • CPU underutilized while waits spike
Mitigation
  • Increase storage to raise IOPS
  • Monitor I/O metrics after changes
  • Consider workload optimization if needed
Concrete example

A payment processing database saw latency during peak hours. CPU was low but disk queue length was high. Increasing storage raised IOPS and reduced latency.

Key Takeaway

Match provisioned storage to I/O needs and monitor telemetry to right-size storage over time.
