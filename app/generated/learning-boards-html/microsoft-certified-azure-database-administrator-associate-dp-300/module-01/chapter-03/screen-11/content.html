Module 1 › Chapter 1.3 › CLI: Firewall Rule
When to use

Use a CLI firewall rule for temporary, controlled access from known IPs while testing connectivity. Remove these rules when finished to reduce exposure.

Example command
az postgres flexible-server firewall-rule create --resource-group myResourceGroup --name myFirewallRule --server-name mypgflexserver --start-ip-address 192.168.1.1 --end-ip-address 192.168.1.10
Replace the server name, resource group, and IP range with your values before running.
Best practice
  • Prefer private VNet integration for production.
  • Use firewall rules only for temporary access and auditing.
  • Script rule creation and removal to avoid lingering open entries.
Key Takeaway: Use CLI for controlled tests, not as a replacement for secure network design.
