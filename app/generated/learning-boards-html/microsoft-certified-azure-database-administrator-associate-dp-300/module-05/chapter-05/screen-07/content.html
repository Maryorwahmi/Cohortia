PITR Commands
Example CLI commands used to restore a database to a specific timestamp. These create a new server or database as the restored target.
az mysql flexible-server restore \
  --resource-group MyResourceGroup \
  --name MyRestoredMySQLServer \
  --source-server MySourceMySQLServer \
  --restore-point-in-time "2023-10-27T14:30:00Z" \
  --no-wait

az sql db restore \
  --resource-group MyResourceGroup \
  --server MySqlServer \
  --name MyRestoredDb \
  --from-database MySourceDb \
  --from-server MySqlServer \
  --restore-point-in-time "2023-10-27T14:30:00Z"
Walkthrough Notes
  • Capture the 'good' timestamp before the incident.
  • Restore to a new name and verify data before cutover.
  • Use --no-wait for asynchronous restores and monitor progress.
Validation Checklist
Connect to restored DB, run SELECTs for affected tables, and confirm constraints and indexes are intact.
