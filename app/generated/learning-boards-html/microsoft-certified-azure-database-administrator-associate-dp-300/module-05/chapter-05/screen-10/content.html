Definition
Short-Term Retention
Default is 7 days; configurable up to 35 days for Azure SQL, Managed Instance, PostgreSQL and MySQL Flexible Server.
Why it matters
Short-term retention defines how far back you can reconstruct changes with PITR. Configure to match expected recovery needs.
Practical Example
If short-term retention is 7 days and an incident occurs 10 days after the event, PITR cannot recover that earlier state; consider LTR or extended retention.
Key Takeaway
Align retention length with the maximum acceptable data-loss window for your application.
