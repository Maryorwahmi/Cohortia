Definition
Update Backup Redundancy
Change the backup storage redundancy property to meet DR requirements and monitor cost and availability.
az sql db update \
  --resource-group MyResourceGroup \
  --server MySqlServer \
  --name MyDatabase \
  --backup-storage-redundancy GRS
Operational Considerations
  • Changes may incur additional storage cost.
  • Allow time for asynchronous replication to establish cross-region copies.
  • Validate geo-restore capability after changing to GRS or GZRS.
Misconception

Selecting GRS does not instantly make cross-region restore instantaneous; the async copy must be available first.
