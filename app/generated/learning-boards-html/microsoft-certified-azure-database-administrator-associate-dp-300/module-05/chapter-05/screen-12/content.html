Process
Set LTR Policy
az sql db ltr-policy set \
  --resource-group MyResourceGroup \
  --server MySqlServer \
  --database MyDatabase \
  --weekly-retention "P4W" \
  --monthly-retention "P6M" \
  --yearly-retention "P5Y" \
  --week-of-year 1
This example keeps weekly backups for 4 weeks, monthly backups for 6 months, and yearly backups for 5 years, with the yearly backup taken in the first week of the year.
Checklist
  • Define ISO 8601 retention durations for each slot.
  • Confirm LTR snapshots appear in portal under Available LTR backups.
  • Document retrieval procedures for LTR restores.
Key Takeaway

LTR is for long-term archival; use it alongside short-term retention to cover both operational recovery and compliance needs.
