Definition
Automated Backup Types
Full backup
A complete copy of the database taken periodically; usually weekly.
Differential backup
Captures changes since the last full backup; typically every 12–24 hours.
Transaction log backup
Captures transactions every few minutes to enable precise point-in-time recovery.
How they work together
Reconstructing a point-in-time uses the last full backup, the latest differential after that full, and transaction logs up to the desired timestamp.
Concrete Example
If full backup was Sunday, differential today contains all changes since Sunday, and transaction logs cover each five‑minute window. To restore to 14:37 you use Sunday full, today's differential, and logs up to 14:37.
Misconception
Differential backups are not replacements for transaction logs when you need a precise timestamp; both are required for PITR.
