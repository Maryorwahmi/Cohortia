Module 5 › Chapter 5.5 › Key Concepts
Automated Backups
Full, differential, transaction logs performed regularly to enable PITR.
Backup Redundancy
LRS, ZRS, GRS, GZRS define protection from local to regional failures.
Point-in-Time Restore
Restore to a timestamp within the retention window; restores create a new database for verification.
Takeaway
Treat backup type, redundancy, and retention as the three knobs that determine your recoverability. Test restores regularly to ensure backups are usable.
