Definition
Geo-restore
Recover to a different region using geo-replicated backups when the primary region is unavailable.
When to use
Geo-restore is suitable if you need cross-region recovery but do not use continuous replication. For faster failover, use active geo-replication or auto-failover groups.
Checklist
  • Ensure GRS or GZRS is enabled for backups if you want geo-restore capability.
  • Document expected restore time and data currency for geo-restore scenarios.
Trade-off

Geo-restore gives cross-region recoverability but may have higher RTO and slightly older data than active replication solutions.
