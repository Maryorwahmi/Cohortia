HADR plan checklist
Step-by-step items to include and verify.
1. Stakeholders and objectives: list owners and approved RTO/RPO per app.
2. Dependency inventory: services that must be recovered or reconfigured.
3. Runbooks: pre-checks, commands, verification, rollback steps, contacts.
4. Communication plan: who, how, and escalation paths during events.
5. Test schedule: frequency and scope, and a review loop to update documents.
Example runbook excerpt
Pre-check: verify replication health and backups. Action: initiate planned failover via Auto-Failover Group. Verify: run application smoke tests, confirm transaction writes to new primary. Rollback: document steps to failback and re-synchronize data.
Key Takeaway
A runbook is a checkable script that reduces mistakes during a crisis. Keep it short, specific, and practiced.
Pro tip
Automate verification steps where possible, such as smoke tests and health checks, to reduce manual overhead during tests.
