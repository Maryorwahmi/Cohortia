Module 5 › Chapter 5.6 › Failover Testing
Design test scope
Non-production mirrored tests are safest. Production tests require change control and rollback plans.
Frequency: Annual minimum; quarterly or bi-annual for critical services.
Metrics: Capture actual RTO and observed RPO during each test.
Scope: Test the full stack: app, DB, caches, storage, and networking.
Key Takeaway
Testing is non-optional. It reveals real-world gaps and keeps recovery runbooks accurate.
Test checklist
  • Notify stakeholders and schedule the window.
  • Take baselines and ensure backups are current.
  • Execute failover, run smoke tests, and record timings.
  • Perform failback and verify post-failback consistency.
  • Document lessons learned and update runbooks.
Safety note
Always test in non-production first. If production testing is required, ensure clear rollback and stakeholder approval.
