Guided test plan
Follow these steps for the Auto-Failover Group scenario.
Pre-test
  1. Notify stakeholders and schedule window.
  2. Baseline timings and confirm backups.
  3. Ensure smoke tests are ready.
Execution
  1. Initiate planned failover via Auto-Failover Group.
  2. Run smoke tests and record completion time.
  3. Measure replication lag for RPO verification.
Post-test
  1. Perform planned failback and run consistency checks.
  2. Document actual RTO/RPO and update runbooks.
  3. Schedule remediation for issues found.
Key Takeaway
A short, repeatable test plan helps prove readiness and provides concrete timing data you can show stakeholders.
