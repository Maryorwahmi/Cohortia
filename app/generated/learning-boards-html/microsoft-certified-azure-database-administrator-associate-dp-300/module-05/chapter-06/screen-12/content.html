Module 5 › Chapter 5.6 › Common Mistakes
Frequent errors
Recognize and address typical operational missteps.
Assuming automation removes testing: Automation helps but doesn’t validate app behavior.
No runbook ownership: Assign an owner and review after every test.
Alert fatigue: Tune alerts to map to real action thresholds and owners.
Mitigation strategies
  • Schedule realistic, full-stack tests and post-test reviews.
  • Version runbooks and require ownership and sign-off after changes.
  • Set alerts based on measurable thresholds tied to RTO/RPO and assign response steps.
Key Takeaway
Mitigate risks by practicing, owning documentation, and configuring actionable monitoring.
