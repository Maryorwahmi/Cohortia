Module 5 › Chapter 5.3 › LTR CLI
CLI example
az sql db ltr-policy set \
    --resource-group MyResourceGroup \
    --server MySqlServer \
    --database MyDatabase \
    --weekly-retention "P12W" \
    --monthly-retention "P12M" \
    --yearly-retention "P10Y" \
    --week-of-year 1
Checklist
  • Verify LTR entries appear in Backups > Retention policies.
  • Test restoring an LTR backup to a test server to confirm retrieval.
Practical guidance

Schedule verification runs in your audit cycle that list LTR backups and attempt a restore. Keep retrieval runbooks available for auditors and incident responders.

Misconception

LTR is not immediate; the first archived backup appears at the next scheduled full backup after enabling the policy.

Key Takeaway

Automate LTR policy creation and verification so compliance teams and incident responders have reliable archival backups to retrieve.
