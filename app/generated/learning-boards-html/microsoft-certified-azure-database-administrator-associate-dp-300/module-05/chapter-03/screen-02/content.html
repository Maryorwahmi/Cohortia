Learning Objectives

Learn, understand, apply, and demonstrate key DR skills for Azure SQL.

Bloom’s taxonomy
Learn

01
Implement Geo-Restore

Restore a database from geo-redundant backups to a different region to recover from a total regional outage.

Mnemonic: think "backup pairs" — geo-redundant backups are stored in a paired region.

VERIFIED COMPETENCY MILESTONE
02
Configure Long-Term Retention

Set weekly, monthly and yearly retention rules so full backups are stored for compliance and historical recovery.

Mnemonic: W-M-Y = weekly, monthly, yearly checkpoints for compliance.

VERIFIED COMPETENCY MILESTONE
03
Leverage Auto-Failover Groups

Replicate databases across regions with a persistent listener to reduce recovery steps and lower RTO.

Mnemonic: "single endpoint, many regions" — keep your app connection stable.

VERIFIED COMPETENCY MILESTONE
04
Understand RTO and RPO trade-offs

Evaluate how each DR option affects acceptable downtime and data loss and plan tests to validate targets.

Mnemonic: "RTO = time; RPO = data" — both guide your choice and cost.
