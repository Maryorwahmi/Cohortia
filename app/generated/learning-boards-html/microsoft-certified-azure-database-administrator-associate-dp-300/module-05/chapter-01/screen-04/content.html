Definition
High Availability (HA)
HA keeps a database operational through redundant components and automatic failover for localized faults within a region.
Concrete example
Azure SQL Database moves a database to a healthy node after a server failure, often with seconds of interruption.
Common misconception
HA is not absolute; tier and configuration determine whether zone redundancy or only local redundancy applies.
Key Takeaway

HA addresses component-level failures with redundancy and failover. Verify your service tier and settings to ensure the level of availability you need.

How it works
Redundant replicas
Multiple copies of data and standby compute nodes ready to take over.
Automatic failover
Platform detects failures and switches traffic to a healthy replica.
Health monitoring
Continuous checks ensure timely detection of unhealthy nodes.
Tier differences
Some tiers offer zone redundancy; others provide local redundancy only.
