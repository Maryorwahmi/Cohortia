Failure types and mitigations
Choose layered protections to address multiple failure modes.
Hardware Failures
Cause: disk, server, NIC faults. Mitigation: local redundancy, automatic failover, platform-managed replicas.
Sign: transient unavailability for a small subset of requests. Test: node failover drills.
Software Failures
Cause: engine crash, corruption. Mitigation: backups, point-in-time restore, patch management.
Sign: errors or corruption in data. Test: restore to staging environment and validate.
Network Failures
Cause: connectivity loss within a datacenter or region. Mitigation: Availability Zones, retries, redundant paths.
Sign: intermittent latency spikes or region-scoped connectivity loss. Test: simulate zone failure.
Human Error
Cause: accidental deletion, misconfiguration. Mitigation: point-in-time restore, RBAC, and auditing.
Sign: sudden missing data or configuration drift. Test: accidental delete recovery exercise.
Key Takeaway

Address each failure type with targeted mitigations and layer protections so no single mode causes prolonged outage or data loss.
