Core Concept
Azure PaaS HADR capabilities
PaaS reduces operational overhead by managing many HADR mechanisms, but configuration is still required to meet specific targets.
Platform-managed tasks
Hardware provisioning, patching, and local replica management are handled by Azure.
Customer responsibilities
Define RTO/RPO, enable zone redundancy or geo-replication when needed, and test failover procedures.
Example
Azure SQL Database maintains replicas automatically, but to meet stricter cross-region RTO/RPO you must configure geo-replication or auto-failover groups.
Key Takeaway

Leverage PaaS defaults to reduce operational work, but explicitly enable additional HADR features when business targets demand it.
