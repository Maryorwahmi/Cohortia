Module 5 › Chapter 5.4 › Flexible Server HA
What it is

A primary server and a warm standby are deployed in different Availability Zones. Transactions are replicated synchronously or semi-synchronously so the standby can be promoted without losing committed data.

Guarantee
RPO = 0 for supported failure scenarios; automatic failover reduces RTO.
Costs
Warm standby uses compute and storage; plan capacity and cost accordingly.
Key Takeaway
Flexible Server HA should be used for production workloads that cannot tolerate data loss during an AZ outage.
Annotated topology
Primary (Zone 1)
Accepts writes, commits synchronously to standby before acknowledging transactions.
Warm Standby (Zone 2)
Receives replicated transactions and is ready to be promoted automatically upon failure.
Example
If Zone 1 has a hardware failure, the standby in Zone 2 is promoted and the logical endpoint remains available to the application with minimal downtime.
