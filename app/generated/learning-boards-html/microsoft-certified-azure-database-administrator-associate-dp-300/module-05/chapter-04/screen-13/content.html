Module 5 › Chapter 5.4 › Hands-on Activity
Activity Steps
1. Prepare
Choose resource group, pick AZ-capable region, plan names and credentials.
2. Create HA Flexible Server
Use CLI or portal and enable high availability with primary and standby zones set.
3. Verify Standby
Confirm standby exists in the standby zone and replication is healthy.
4. Create Read Replica
Add a cross-region replica and wait for healthy status and acceptable lag.
5. Test Promotion
In a sandbox, promote the replica, update connection strings, and run smoke tests.
6. Document
Record timings, replication lag behavior, and any issues to refine RTO/RPO estimates.
Remember: perform promotion drills in non-production and automate monitoring and alerts for replication lag and backup success.
