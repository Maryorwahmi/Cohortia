Module 5 › Chapter 5.4 › Flexible vs Single
Flexible Server (Recommended)
  • Built-in zone-redundant HA with automatic failover and RPO=0.
  • Cross-region read replicas, geo-restore, PITR for DR.
  • Better operational tooling for failover and standby management.
Single Server (Legacy)
  • Limited HA; standbys may not be AZ-aware and automatic failover is limited.
  • Relies more on geo-restore and manual intervention for DR.
  • Consider migrations to Flexible Server for production-critical workloads.
Key Takeaway

Flexible Server provides stronger HADR guarantees; choose it when availability and automatic failover are required.
