High Availability & Disaster Recovery

Learn how Flexible Server provides zone-redundant synchronous HA, how read replicas supply read-scaling and cross-region DR, and when to use geo-restore or PITR.

In this lesson

Understand HA topology, run CLI deployments, design read replica strategies, and practice recovery steps so you can meet RPO/RTO goals.

Why it matters

Choosing the right HADR option directly affects data loss risk, application downtime, and operational complexity. This chapter helps you choose intentionally.

Explore Key Topics
Flexible HA

Zone-redundant standby with synchronous replication for RPO=0 and automatic failover.

Read Replicas

Asynchronous copies for read scale and cross-region DR with manual promotion.

Backup Restore

Geo-restore and PITR rely on backups and have longer RTO/RPO than synchronous HA.
