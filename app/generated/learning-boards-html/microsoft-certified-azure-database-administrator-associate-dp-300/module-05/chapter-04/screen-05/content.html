Module 5 › Chapter 5.4 › Create PostgreSQL with HA
CLI Example
az postgres flexible-server create \
    --resource-group MyResourceGroup \
    --name MyPgFlexServer \
    --location eastus \
    --sku-name Standard_D2ds_v4 \
    --tier GeneralPurpose \
    --version 14 \
    --storage-size 32 \
    --high-availability Enabled \
    --zone 1 \
    --standby-zone 2 \
    --admin-user pgadmin \
    --admin-password MyStrongPassword123!
Note the --high-availability Enabled flag and both --zone and --standby-zone parameters. After this command completes, check the server's replication status and standby availability zone in the portal or via az cli show commands.
Checks & Examples
  • Verify standby zone and replication health after deployment.
  • Run a simple transaction test, then simulate a failover in a controlled lab and verify no committed data is lost.
  • Document the endpoint and confirm your application reconnects as expected.
Key Takeaway
Use the CLI flags for HA provision and always validate standby and replication health after create.
