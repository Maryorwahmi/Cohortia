Learning Objectives
Bloom's path: Learn → Understand → Apply → Master
01
Understand Flexible HA
Know zone-redundant synchronous replication and warm standby behavior.
Mnemonic: think "Primary + Standby in different zones"
VERIFIED COMPETENCY MILESTONE
02
Configure Read Replicas
Create and monitor asynchronous replicas for scaling and DR.
Mnemonic: "Replicas for reads, promotion for write"
VERIFIED COMPETENCY MILESTONE
03
Implement DR from Backups
Use geo-restore and point-in-time restore when replicas are unsuitable.
Mnemonic: "Backups are the fallback"
VERIFIED COMPETENCY MILESTONE
04
Compare Single vs Flexible
Decide which deployment meets availability and operational needs.
Mnemonic: "Flexible = AZ-aware; Single = legacy"
VERIFIED COMPETENCY MILESTONE
Skill Path
  1. Read the architecture: primary, standby, replicas.
  2. Deploy a Flexible Server with HA enabled using CLI or portal.
  3. Create and monitor read replicas; practice promotion in a test plan.
  4. Run geo-restore and PITR drills from geo-redundant backups.
Remember: verify replication health and test promotions before trusting a DR plan.
