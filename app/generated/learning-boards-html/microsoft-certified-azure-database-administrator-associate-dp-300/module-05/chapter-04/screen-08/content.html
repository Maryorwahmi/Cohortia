DR Options
1. Read Replica Promotion
Manual promotion of a cross-region replica. Fast but can cause data loss due to asynchronous replication.
2. Geo-Restore
Restore from geo-redundant backups to a different region. Reliable but longer RTO and RPO.
3. Point-in-Time Restore
Restore to a specific point in time to recover from corruption or accidental deletes. Useful as both operational recovery and DR if backups are geo-redundant.
Quick workflow
  1. Choose DR target: replica promotion or backup restore.
  2. Script promotion or restore steps; include connection string updates.
  3. Run a lab drill to confirm RTO and data integrity.
Tip: maintain an ops playbook for each DR option and test it regularly.
