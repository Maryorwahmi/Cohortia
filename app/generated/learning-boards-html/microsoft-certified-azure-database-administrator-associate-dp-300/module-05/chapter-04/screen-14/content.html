Module 5 › Chapter 5.4 › Key Concepts
Flexible Server HA
Zone-redundant automatic failover with synchronous replication for RPO=0.
Read Replicas
Asynchronous copies for read scale and manual promotion to DR targets.
Synchronous vs Async
Synchronous ensures zero data loss; asynchronous improves performance but risks lag.
Takeaway

Match HADR choices to SLAs: Flexible Server HA for strict availability; replicas and backups for scale and secondary DR. Test and monitor everything.
