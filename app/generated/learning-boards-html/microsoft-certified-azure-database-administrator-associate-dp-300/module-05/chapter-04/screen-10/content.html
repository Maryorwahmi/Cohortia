Module 5 › Chapter 5.4 › Monitoring & Promotion
Daily checks
  • Replication lag and health metrics for each replica.
  • Backup completion and retention for PITR/geo-restore.
  • Alerting on failures and prolonged lag.
Small habit: verify one replica health daily and run a monthly promotion drill in a sandbox.
Promotion runbook (short)
  1. Confirm replica is Healthy and lag is acceptable.
  2. Quiesce writes to original primary if reachable.
  3. Execute manual promotion on the replica.
  4. Update application connection strings and DNS entries.
  5. Run smoke tests and monitor errors.
Document who performs each step and how to roll back if data loss concerns arise.
