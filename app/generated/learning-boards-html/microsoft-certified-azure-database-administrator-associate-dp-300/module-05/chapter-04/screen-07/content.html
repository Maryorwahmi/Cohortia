Module 5 › Chapter 5.4 › Create MySQL Read Replica
CLI Example
az mysql flexible-server replica create \
    --resource-group MyResourceGroup \
    --name MyMySQLReadReplica \
    --source-server MyMySQLPrimaryServer \
    --location westus
After running this, wait for replication status to report healthy. Monitor metrics for replication lag and test a promotion workflow in a safe environment.
Verification checklist
  • Confirm replica status becomes Healthy.
  • Observe replication lag metrics; set alerts if lag exceeds thresholds.
  • Practice manual promotion and reconnect application in test runs.
Common mistake
Assuming automatic failover: replicas require manual promotion and connection updates.
