Module 5 › Chapter 5.4 › Learning Objectives — Practice
01 — Verify Flexible HA

Enable high availability at creation, observe standby in a different AZ, and confirm synchronous replication and zero data loss via transaction checks.

Test idea: write a transaction, simulate primary failover in a lab, and check data on new primary.
02 — Create & Monitor Replicas

Deploy a cross-region read replica, monitor replication lag metrics, and practice promoting the replica to read/write in a test plan.

Test idea: run read-heavy queries on the replica to confirm offload and check replica health status.
03 — DR from Backups

Simulate data corruption and run a point-in-time restore or geo-restore to measure how long recovery takes and verify data integrity.

Test idea: restore to a new server in another region and run application smoke tests.
04 — Compare Deployments

Prepare a short comparison sheet showing HA, DR features, and operational steps for Single Server vs Flexible Server to show decision rationale.

Test idea: run a small outage simulation and estimate downtime for each deployment type.
