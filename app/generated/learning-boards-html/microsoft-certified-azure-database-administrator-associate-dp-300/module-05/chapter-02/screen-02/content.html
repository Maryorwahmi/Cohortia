Learning Objectives
Master the configuration and operational checks for Azure SQL HA features.
01
Explain Azure SQL HA architecture

Describe how Azure builds on Always On Availability Groups and which service tiers use synchronous replicas or separated compute/storage. This helps you choose a tier that meets RPO/RTO requirements.

Mnemonic: Layered stack — AG foundation at the core
VERIFIED COMPETENCY MILESTONE
02
Configure Availability Zones

Enable zone redundancy when the region and tier support it, and verify replicas or compute/storage are distributed across zones to survive datacenter outages.

Mnemonic: Three pins — independent power, cooling, networking
VERIFIED COMPETENCY MILESTONE
03
Implement Active Geo-Replication

Create readable secondaries for cross-region DR and read-scale. Understand that replication is asynchronous and requires manual promotion for failover.

Mnemonic: Read outlets — secondaries serve reads
VERIFIED COMPETENCY MILESTONE
04
Set up Auto-Failover Groups

Create a failover group to automate failover across regions and preserve a single read-write listener endpoint so applications don't need connection-string changes.

Mnemonic: One listener — single connection point
VERIFIED COMPETENCY MILESTONE
