Definition
Availability Zones
Independent datacenters inside an Azure region used to distribute replicas or components for resilience.
Explanation
  • Zones are physically separate, reducing common-mode failures like power or cooling outages.
  • Business Critical spreads replicas across zones; General Purpose spreads compute and storage.
  • ZoneRedundant must be supported in the chosen region and tier; confirm before enabling.
Concrete example
Enable zone redundancy during database creation with the ZoneRedundant parameter in the CLI, or update an existing database to be zone-redundant if the region supports it.
Common mistake
Trying to enable zone redundancy in a region or tier that lacks support. Always verify region and tier capabilities first.
Visual: zone outcomes
Zone failure: Business Critical retains a quorum and promotes a secondary.
Compute/storage separation: General Purpose provides resilience through redundant storage and compute placement.
Key Takeaway

Pick zones for protection against datacenter outages. Verify region/tier support and test planned failovers to confirm app behavior.
