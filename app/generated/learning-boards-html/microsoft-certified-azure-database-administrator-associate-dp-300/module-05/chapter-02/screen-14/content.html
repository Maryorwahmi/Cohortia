Module 5 › Chapter 5.2 › Key Concepts
Always On Availability Groups
The underlying SQL Server HA/DR technology used by Azure SQL; Azure manages it for you by tier.
Availability Zones (AZ)
Physically separate locations in a region used to distribute replicas or components for datacenter-level resilience.
Active Geo-Replication
Asynchronous readable secondaries in same or different regions, used for read-scale and manual failover.
Auto-Failover Groups
Automated failover for groups of databases with a persistent read-write listener and optional read-only listener.
Grace Period
A setting on failover groups that defines wait time before automatic failover to balance data-loss risk against downtime.
Read-Write & Read-Only Listener
Endpoints provided by Auto-Failover Groups so applications can use stable connection strings across failovers.
Summary

Align tier selection, zone redundancy, replication method, and failover automation to your business RPO/RTO. Then test and document failover behavior.
