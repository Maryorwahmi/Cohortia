Process
Enable Zone Redundancy (CLI)
Create or update a database with the zone-redundant parameter, then verify.
Create a new zone-redundant database
az sql db create \
  --resource-group MyResourceGroup \
  --server MySqlServer \
  --name MyZoneRedundantDb \
  --edition GeneralPurpose \
  --family Gen5 \
  --capacity 2 \
  --zone-redundant \
  --backup-storage-redundancy GRS \
  --assign-identity
Update an existing database to be zone-redundant
az sql db update \
  --resource-group MyResourceGroup \
  --server MySqlServer \
  --name MyExistingDb \
  --zone-redundant
Key Takeaway

Run the CLI commands after validating region/tier support, then check replication distribution and run a planned failover test.

Notes
  • Ensure backup storage redundancy (GRS) is set if cross-region backup resiliency is required.
  • Zone redundancy availability varies by region and tier; confirm support first.
  • Testing is essential: perform planned failovers to verify application resilience.
