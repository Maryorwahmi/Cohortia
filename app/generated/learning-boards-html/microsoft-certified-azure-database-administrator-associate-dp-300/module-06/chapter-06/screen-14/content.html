Assessment questions
  1. Which DMV do you query first to find a long‑running request, and what fields are most helpful?
  2. How do you ensure a stored procedure rolls back on error and logs details for postmortem analysis?
  3. Describe how you would validate a missing index recommendation before deploying it to production.
Guided lab steps: simulate a slow query, query active requests in a separate window, collect missing index suggestions after the run, and implement UpdateProductPrice with TRY...CATCH and AdminAuditLog insert statements. Verify that the failing case inserts an audit row.
Key Takeaway

Assessments should confirm you both interpret diagnostics and apply safe fixes that are auditable and reversible.
