Top waits query
Use this pattern to list the top wait types and their share of total wait time.
-- Example: Top 10 wait statistics
SELECT TOP 10
    wait_type,
    SUM(wait_time_ms) AS total_wait_time_ms,
    SUM(waiting_tasks_count) AS total_waiting_tasks,
    CAST(SUM(wait_time_ms) * 100.0 / SUM(SUM(wait_time_ms)) OVER() AS DECIMAL(5, 2)) AS percentage
FROM
    sys.dm_os_wait_stats
WHERE
    wait_type NOT LIKE 'SLEEP%' AND wait_type NOT LIKE 'LAZYWRITER_SLEEP'
GROUP BY
    wait_type
ORDER BY
    total_wait_time_ms DESC;
Interpretation
Map the top wait types to resource categories and investigate those subsystems first.
Misconception
A single wait type does not always indicate the true root cause; use additional counters and request-level details to confirm.
Concrete mapping
  • PAGEIOLATCH_* → storage I/O latency
  • LCK_M_S or LCK_M_X → blocking/locking issues
  • SOS_SCHEDULER_YIELD → CPU contention or long running CPU tasks
Practical step
Capture waits before and after a change to verify its effect on the dominant wait types.
Key Takeaway

Use aggregated wait types to prioritize investigations; combine with request-level DMVs to confirm a root cause.
