Pattern to attach text and plan
Use OUTER APPLY with the request view to get both the currently executing statement and the plan XML.
OUTER APPLY
    sys.dm_exec_sql_text(r.sql_handle) st
OUTER APPLY
    sys.dm_exec_query_plan(r.plan_handle) qp
-- Use the statement_start_offset and statement_end_offset to extract the executing statement
Save the plan XML for offline analysis. Plan operators reveal which step is expensive and whether an index can reduce I/O.
Concrete guidance
  • Capture both statement_text and batch text; offsets point to the active statement.
  • Compare plan operators with execution counters to find the right tuning target.
  • Always validate changes in a separate environment before applying to production.
Pro tip

When in doubt, save the plan XML and review it with a plan viewer to make structural comparisons before changing indexes.
