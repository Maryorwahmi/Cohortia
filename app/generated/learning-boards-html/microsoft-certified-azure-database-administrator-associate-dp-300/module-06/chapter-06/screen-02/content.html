Learning Objectives
Gain measurable skills for diagnosing performance problems and making administrative code resilient.
01 — DMVs & DMFs
Query engine state in real time
Learn to run DMVs and DMFs to inspect sessions, requests, and engine counters so you can pinpoint live problems.
VERIFIED COMPETENCY MILESTONE
02 — Wait Statistics
Interpret waits to find root causes
Analyze aggregated wait types to see whether I/O, CPU, or locking dominates, and map that to corrective action.
VERIFIED COMPETENCY MILESTONE
03 — Missing Indexes
Collect recommendations and evaluate impact
Retrieve index suggestions from DMVs, estimate their impact, and learn why not every suggestion should be implemented.
VERIFIED COMPETENCY MILESTONE
04 — TRY...CATCH
Write resilient administrative code
Use TRY...CATCH and the ERROR_* functions to log failures and keep automation predictable and auditable.
VERIFIED COMPETENCY MILESTONE
