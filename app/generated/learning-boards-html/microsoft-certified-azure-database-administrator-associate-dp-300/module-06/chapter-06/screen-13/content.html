Module 6 › Chapter 6.6 › Mistakes & Tips
Common mistakes
  • Treating DMVs as historical logs instead of taking snapshots.
  • Applying all missing index suggestions without checking overlap and write impact.
  • Changing production without saving the captured plan and related wait stats.
  • Using PRINT instead of persistent logging for automated scripts.
Pro tips
  • Exclude your diagnostic session from results so you don't confuse the cause with your checks.
  • Save plan XML, statement text, and a snapshot of waits together for reproducibility.
  • Prefer targeted or filtered indexes for write‑heavy tables.
  • Create a standard AdminAuditLog schema early and use it consistently for error logging.
Quick checklist
Snapshot DMVs periodically, test candidate indexes, save artifacts, and log errors persistently.
Reminder

Diagnostics are only useful when paired with reproducible artifacts and measured testing.
