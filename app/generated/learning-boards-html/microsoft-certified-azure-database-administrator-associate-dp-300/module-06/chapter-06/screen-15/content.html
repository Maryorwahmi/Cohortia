Module 6 › Chapter 6.6 › Key Concepts
DMV (Dynamic Management View)
A virtual table exposing server state used for monitoring and diagnosing live issues.
Wait Statistics
Aggregated waits that indicate where queries spend time and point to I/O, CPU, or locking issues.
Missing Index Recommendation
Engine suggestions for indexes; treat as candidates, not prescriptions.
Summary
Use DMVs to identify issues, interpret waits to choose a subsystem to investigate, validate index suggestions in staging, and wrap administrative changes in TRY...CATCH with audit logging for safe operations.
