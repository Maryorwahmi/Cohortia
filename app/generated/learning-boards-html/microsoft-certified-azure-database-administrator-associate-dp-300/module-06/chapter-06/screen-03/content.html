Module 6 › Chapter 6.6 › Learning Objectives
Apply these skills in operations
Each objective maps to a small checklist you can use during an incident to reduce mean time to repair.
Checklist — DMVs
  • Run sys.dm_exec_requests to find heavy sessions
  • Use sys.dm_exec_sql_text and sys.dm_exec_query_plan to inspect the statement and plan
Checklist — Waits
  • Query sys.dm_os_wait_stats and group by wait_type
  • Map dominant waits to I/O, CPU or locking investigations
Checklist — Indexes
  • Collect suggestions from missing index DMVs
  • Estimate impact and test in nonproduction
Checklist — Errors
  • Add TRY...CATCH and log ERROR_MESSAGE, ERROR_LINE
  • Rollback transactions when appropriate and rethrow if needed
