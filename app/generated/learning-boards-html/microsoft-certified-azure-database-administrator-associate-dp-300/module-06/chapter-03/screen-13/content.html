Practice question
Queries filter by OrderDate and CustomerID while the table’s clustered index is OrderID. What index will help most and why?
Recommended answer
Create a non-clustered index on (OrderDate, CustomerID). Optionally INCLUDE other frequently selected columns to make the index covering.
Why
This index matches the predicate and reduces scans by allowing direct lookups. It avoids changing the clustered index and the disruptive impact that could have on other queries.
Misconception check
Avoid immediately changing the clustered index unless table-wide access patterns strongly favor a different physical order; a correct non-clustered index is safer and more targeted.
Key Takeaway

Answer index selection with query evidence. Use execution plans and DMVs to validate the improvement after creating the index.
