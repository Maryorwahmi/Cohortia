Module 6 › Chapter 6.3 › Key Concepts
View
A virtual table defined by a query; use for abstraction and security. Consider indexed views only when requirements fit.
Index
Speeds lookups. Clustered controls physical order; non-clustered supports targeted filters and joins.
Constraint
Rules like PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK and DEFAULT enforce data integrity at the database level.
Summary

Design objects with intent: abstract with views, optimize with measured indexes, and protect data with constraints. Always test and measure in development before production changes.
