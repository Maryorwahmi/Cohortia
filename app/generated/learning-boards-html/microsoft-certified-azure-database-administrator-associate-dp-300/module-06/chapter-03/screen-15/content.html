Module 6 › Chapter 6.3 › Quick Reference
Index
Key structure for fast lookups. Non-clustered = key + pointer. Clustered = table row order.
PRIMARY KEY / UNIQUE
PRIMARY KEY = identity, no NULLs. UNIQUE enforces distinct values and can allow NULLs.
CHECK / DEFAULT / FOREIGN KEY
CHECK limits valid values, DEFAULT supplies fallback values, FOREIGN KEY enforces referential integrity.
One-line takeaway

Design objects with clear intent: improve queries where needed, protect data with constraints, and always validate changes in a development environment.
