Dev-to-Prod workflow
Implement DDL in development, run performance tests, and review execution plans before promoting changes. This reduces surprises in production environments.
Mnemonic: Test, measure, document.
VERIFIED COMPETENCY MILESTONE
Use data-driven index decisions
Analyze DMV suggestions and query plans to decide when to add or remove indexes rather than guessing from code alone.
Mnemonic: Let the plan speak.
VERIFIED COMPETENCY MILESTONE
Document intent for each object
Record why an index or constraint exists to help future DBAs and devs manage trade-offs and avoid accidental drop or duplication.
Mnemonic: Code with a purpose note.
VERIFIED COMPETENCY MILESTONE
Protect production with rollbacks
Back up or script reversals when making DDL changes. When in doubt, apply in a maintenance window and monitor impact.
Mnemonic: Have a safe exit strategy.
