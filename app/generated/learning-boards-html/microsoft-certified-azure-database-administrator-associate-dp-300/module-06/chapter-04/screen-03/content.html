Module 6 › Chapter 6.4 › How we will practice
Practice checklist
Follow these steps and verify each result with system views.
Provision
Create login and user mapped to that login or an Azure AD identity.
Grant
Grant only required permissions, e.g., SELECT, INSERT on specific tables.
Verify
Query sys.database_principals and sys.database_permissions to confirm outcomes.
Common Mistake

Assigning high-privilege roles like db_owner when granular permissions would suffice increases attack surface and hinders audits.

Pro Tip

Prefer Azure AD identities for managed services and use password-based users only when necessary for compatibility.
