Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master

Script administrative operations

VERIFIED COMPETENCY MILESTONE

VERIFIED COMPETENCY MILESTONE

Enumerate objects for audits

Use sys.tables, sys.procedures, and sys.columns to script audits and schema discovery tasks.
