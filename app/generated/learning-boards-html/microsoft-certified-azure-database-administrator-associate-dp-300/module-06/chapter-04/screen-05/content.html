Module 6 › Chapter 6.4 › Logins vs Users
Login (Server Principal)
Authenticates to the server
  • - Created at server or in master for Azure SQL DB
  • - Example: CREATE LOGIN AppLogin WITH PASSWORD = '...'
  • - Controls who can open a connection
Verification
Query sys.server_principals to confirm the login exists and attributes like authentication type.
User (Database Principal)
Authorizes access within a database
  • - Created inside each database and mapped to a login or external provider
  • - Example: CREATE USER AppUser FOR LOGIN AppLogin
  • - Grants permissions on objects in that database
Verification
Query sys.database_principals and sys.database_role_members to inspect membership and roles.
Concrete example
Create login in master. Create user in application DB mapped to login. Grant minimal privileges.
Prefer Azure AD users where possible to centralize identity management.
Avoid db_owner; grant schema or object-level permissions instead.
