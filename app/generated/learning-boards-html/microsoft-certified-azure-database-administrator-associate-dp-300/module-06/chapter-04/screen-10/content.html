Module 6 › Chapter 6.4 › Object Enumeration with System Views
Discovery snippet
-- List tables with schema-qualified names
SELECT QUOTENAME(s.name) + '.' + QUOTENAME(t.name) AS FullName
FROM sys.tables t
JOIN sys.schemas s ON t.schema_id = s.schema_id
ORDER BY FullName;

-- List columns for a particular table
SELECT name, system_type_name
FROM sys.dm_exec_describe_first_result_set_for_object(OBJECT_ID('dbo.Orders'), 0);
Best practices
  • Use QUOTENAME when composing object names to handle special characters.
  • Record the discovery output for audit and reproducibility.
  • Use system views rather than relying on naming conventions or manual lists.
Key Takeaway

Programmatic discovery keeps scripts adaptable to schema changes and supports safe dynamic operations.
