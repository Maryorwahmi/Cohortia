Module 6 › Chapter 6.4 › Azure AD Users and External Provider
Example: Create an Azure AD user
Use CREATE USER [AAD_User_Name] FROM EXTERNAL PROVIDER; for individuals, or CREATE USER [AAD_Group_Name] FROM EXTERNAL PROVIDER; for groups.
Benefits
Centralizes identity, simplifies credential rotation, and integrates with enterprise access controls.
Checklist before creating
Confirm tenant membership and object names, and ensure necessary Azure roles are assigned externally.
Practical note
Prefer AD identities for managed services, and document the mapping in your deployment runbook.
Common Mistake

Assuming AD users eliminate the need for permission reviews; continue to apply least privilege and verify effective access.
