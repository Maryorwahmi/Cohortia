Module 6 › Chapter 6.4 › Create a Login and Mapped User
T-SQL Example
USE master; -- Or the master DB for Azure SQL DB
GO

CREATE LOGIN AppLogin WITH PASSWORD = 'YourStrongPassword123!', CHECK_POLICY = ON;
GO

USE YourApplicationDB; -- Replace with actual DB name
GO

CREATE USER AppUser FOR LOGIN AppLogin;
GO

-- Grant specific permissions
GRANT SELECT ON SCHEMA::dbo TO AppUser;
GRANT INSERT ON dbo.Orders TO AppUser;
GO
Example intent
Create application credentials that map authentication to database authorization.
Misconception
Don't give db_owner to simplify permissions; assign minimal object rights instead.
Verification steps
  • Query sys.server_principals to see the created login.
  • Use sys.database_principals to confirm the database user exists and is mapped.
  • Check sys.database_permissions to confirm grants are applied.
Key Takeaway

Always verify created principals and permissions with system views after running provisioning scripts.
