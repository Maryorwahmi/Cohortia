Module 6 › Chapter 6.4 › Granting Permissions and Least Privilege
Grant flow
1. Decide minimal privilege
Map application actions to the least set of permissions required.
2. Apply grants precisely
Grant on objects or schemas instead of assigning broad roles.
3. Verify and log
Use system views and permission checks to record effective rights.
Concrete example
Grant SELECT on a schema and INSERT on a specific table to a reporting user. Avoid db_owner assignment.
Key Takeaway

Design grants around actions, not convenience. Automate checks to ensure grants are correct and auditable.

Verification snippet
Query sys.database_permissions joined to sys.database_principals to list permissions granted to a user for auditing.
