Module 6 › Chapter 6.4 › T-SQL for Administrative Tasks
What this term means

Administrative T-SQL uses standard SQL commands and system views to perform management work in a repeatable, auditable way.

Why repeatability matters
Scripts can be stored, reviewed, and executed consistently across environments.
Auditability
Commands and outputs can be logged and compared for compliance and incident response.
Practical checks
Scripts should check for existing objects and confirm success before proceeding.
Key Takeaway

Turn one-off admin steps into idempotent scripts that you can test and review.

Example
A scripted flow: verify database exists → create login if missing → create user mapped to login → grant minimal permissions.
-- Conceptual script fragment (illustrative)
-- Check database and create a login + user mapping
USE master;
GO
