Starter queries
-- Step 1: List users and roles
SELECT dp.name AS UserName, dp.type_desc AS UserType, ISNULL(rp.name,'N/A') AS RoleName
FROM sys.database_principals dp
LEFT JOIN sys.database_role_members drm ON dp.principal_id = drm.member_principal_id
LEFT JOIN sys.database_principals rp ON drm.role_principal_id = rp.principal_id
WHERE dp.type IN ('S','U','G') AND dp.sid IS NOT NULL;
GO

-- Step 2: Create ReportUser (password-based example)
CREATE USER ReportUser WITH PASSWORD = 'YourStrongPassword_R3p0rt!';
GO

Verification

Key Takeaway

Audit first, apply minimal grants, and verify results. Log both pre- and post-change states for an auditable trail.
