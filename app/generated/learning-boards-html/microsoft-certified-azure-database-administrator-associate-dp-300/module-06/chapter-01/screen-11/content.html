Module 6 › Chapter 6.1 › Azure Differences
On-premises
  • Administrators run backup and restore T-SQL commands as part of maintenance.
  • DBAs manage the full stack including physical backup files.
  • T-SQL may include more operational control statements tied to the server instance.
Azure SQL
  • Platform-managed backups are common; administrators focus on schema, security, and data tasks.
  • T-SQL is used for object management, user and role administration, and tuning queries and indexes.
  • Design scripts with the platform's managed behaviors in mind and test in non-production environments.
Practical implication

When operating in Azure, focus your T-SQL automation on tasks you control. For backups and restores, rely on platform features or data export approaches rather than attempting on-premises backup commands that may not be supported.

Key Takeaway

Map your scripts to what you can control in Azure and avoid assuming on-premises procedures are always applicable.
