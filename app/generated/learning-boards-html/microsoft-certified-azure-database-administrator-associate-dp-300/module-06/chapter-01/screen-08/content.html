Module 6 › Chapter 6.1 › Variables & Control Flow
Example
DECLARE @currentValue NVARCHAR(100);
SELECT @currentValue = SettingValue
FROM AppSettings
WHERE SettingName = 'MaintenanceMode';

IF @currentValue = 'OFF'
BEGIN
  UPDATE AppSettings
  SET SettingValue = 'ON', LastModified = GETDATE()
  WHERE SettingName = 'MaintenanceMode';
END;
Explanation
  • Variables hold values for conditional checks across the script.
  • IF...ELSE allows safe conditional execution; verify conditions with SELECT first.
  • Prefer set-based updates; use loops only when set operations cannot express the needed logic.
Common pitfall

Using cursors for large datasets can be very slow. Rewrite as set-based queries when possible or batch carefully.

Key Takeaway

Use variables to capture state and control flow sparingly. Favor set-based logic for performance and clarity.
