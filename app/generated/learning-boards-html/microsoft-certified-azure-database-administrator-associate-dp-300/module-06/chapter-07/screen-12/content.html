Module 7 › Chapter 6.7 › Organize Artifacts
Hierarchy
Repository layout and naming conventions
A consistent layout accelerates reviews and reduces errors when promoting runbooks to production.
Suggested folders
  • notebooks/runbooks — operational .ipynb files
  • scripts/powershell — reusable .ps1 scripts
  • pipelines — YAML pipeline definitions
  • templates — parameter templates and docs
Naming & versioning
Use descriptive names and include a changelog. Tag releases and publish pipeline artifacts for approved runbook versions.
Secrets & parameters
Keep placeholders in code and supply real values from Key Vault or pipeline variables at runtime.
Key Takeaway
Consistent repository hygiene and protected branches make automation safe and reviewable.
