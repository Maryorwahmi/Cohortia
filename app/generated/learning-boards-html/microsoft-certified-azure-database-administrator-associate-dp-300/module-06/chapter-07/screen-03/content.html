Module 7 › Chapter 6.7 › Lab-ready Goals
Learning Objectives — Practical Outcomes
Exact tasks to check off in a lab environment.
Notebook runbook
Author and save an .ipynb that queries Azure SQL, PostgreSQL, and MySQL and captures outputs for review and version control.
PowerShell automation
Write Az cmdlets to list databases and scale servers; ensure the scripts run without manual intervention when authenticating via managed identity or service principal.
Secure authentication
Use Connect-AzAccount for development and managed identities or service principals for non-interactive pipeline execution.
Pipeline integration
Store notebooks and scripts in Azure Repos and configure Pipelines to run and schedule them for repeatable operations.
