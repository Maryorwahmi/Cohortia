Create CrossPlatformHealthCheck.ipynb
Follow these steps in Azure Data Studio and your pipeline environment.
Step-by-step
  1. Add markdown cell describing purpose and preconditions.
  2. Add SQL cell and run: SELECT DB_NAME(), GETDATE(), @@VERSION;
  3. Add PostgreSQL cell and run: SELECT datname FROM pg_database WHERE datistemplate = false;
  4. Add MySQL cell and run: SELECT VERSION(), CURRENT_USER();
  5. Save, commit to Azure Repos, and create a pipeline to run or schedule the notebook.
PowerShell challenge
Add a fourth PowerShell cell or script that lists all Azure SQL servers non-interactively using a service principal or a managed identity.
Starter PowerShell snippet for the challenge
# Authenticate non-interactively (example for service principal)
# Connect-AzAccount -ServicePrincipal -Tenant "" -ApplicationId "" -Credential (Get-Credential)

# List all Azure SQL servers in the subscription
Get-AzSqlServer | Select-Object ResourceGroupName, ServerName, Location | Format-Table
Lab Tip
If you cannot run non-interactive auth locally, put the PowerShell snippet into a pipeline step using a service connection and run it from the pipeline agent.
