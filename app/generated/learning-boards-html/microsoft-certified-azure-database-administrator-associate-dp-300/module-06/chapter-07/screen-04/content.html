Module 7 › Chapter 6.7 › Azure Data Studio & Notebooks
Definition
Azure Data Studio Notebooks
Notebooks are executable documents that combine code cells in different languages with rich markdown documentation. They are ideal for runbooks, diagnostics, and reproducible operational tasks across database engines.
Core capabilities
  • Run T-SQL, PowerShell, Python, Kusto within the same notebook.
  • Attach each code cell to a specific database connection using connection metadata.
  • Save and version notebooks as .ipynb files.
Common misconception
Notebooks are not only for analytics; they are suited for operational runbooks and scheduled diagnostics when integrated with automation tooling.
Key Takeaway

Use notebooks to combine checks across engines and include markdown to document preconditions and expected outcomes.

Concrete Example
A single notebook runs three cells: a T-SQL cell to read DB properties, a PostgreSQL cell to list databases, and a MySQL cell to show server version. Save it as CrossPlatformHealthCheck.ipynb and commit to source control.
Notebook JSON (simplified)
{
  "cells": [
    {"cell_type":"markdown","source":"# Cross-Platform Database Health Check"},
    {"cell_type":"code","metadata":{"connection":{"database":"YourAzureSQLDB","server":"your-azuresqldb-server.database.windows.net","provider":"MSSQL"}},"source":"SELECT DB_NAME() AS DatabaseName, GETDATE() AS CurrentTime, @@VERSION AS SQLVersion;"},
    {"cell_type":"code","metadata":{"connection":{"database":"postgres","server":"your-postgresql-server.postgres.database.azure.com","provider":"PostgreSQL"}},"source":"SELECT datname FROM pg_database WHERE datistemplate = false;"},
    {"cell_type":"code","metadata":{"connection":{"database":"mysql","server":"your-mysql-server.mysql.database.azure.com","provider":"MySQL"}},"source":"SELECT VERSION() AS MySQLVersion;"}
  ]
}
