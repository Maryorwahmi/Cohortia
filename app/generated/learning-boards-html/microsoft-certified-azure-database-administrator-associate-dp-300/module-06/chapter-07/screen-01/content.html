Cross-Platform Automation with Azure Data Studio and PowerShell
Notebooks for interactive runbooks • PowerShell for scripted automation • CI/CD for repeatable deployments
Why this matters
Automation reduces manual steps, improves reproducibility, and lets you operate a mixed set of database engines from a single documented workflow.
Explore Key Topics
Notebooks
Executable markdown that connects to multiple engines and captures results.
PowerShell
Az cmdlets let you script create, scale, and configure resources consistently.
CI/CD
Store notebooks and scripts in Repos and run them from Pipelines for safe automation.
Interactive Concept
Notebook snapshot
A single notebook can run T-SQL, psql, and MySQL queries in separate cells and collect results together for review, saving the whole document as a reproducible runbook.
Example
SELECT DB_NAME() AS DatabaseName from Azure SQL; then run a PostgreSQL query to list databases, then SELECT VERSION() on MySQL. Save as an .ipynb file.
