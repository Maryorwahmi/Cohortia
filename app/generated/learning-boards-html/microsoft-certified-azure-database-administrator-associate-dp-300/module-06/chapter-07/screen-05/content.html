Cross-Platform Health Check Notebook
A focused notebook template with one practical check per cell and connection metadata for each engine.
Notebook structure
  • Markdown header describing purpose and preconditions.
  • SQL cell: DB properties and status via T-SQL.
  • PostgreSQL cell: list databases using pg_catalog.
  • MySQL cell: return server version and user context.
Best practices
Replace placeholders before committing, include expected outputs in markdown, keep each cell focused, and commit small incremental updates to notebooks.
Code cells (excerpts)
-- Azure SQL: database info
SELECT DB_NAME() AS DatabaseName, GETDATE() AS CurrentTime, @@VERSION AS SQLVersion, DATABASEPROPERTYEX(DB_NAME(), 'Status') AS DatabaseStatus;

-- PostgreSQL: list non-template databases
SELECT datname FROM pg_database WHERE datistemplate = false;

-- MySQL: version and current user
SELECT VERSION() AS MySQLVersion, CURRENT_USER() AS CurrentUser;
