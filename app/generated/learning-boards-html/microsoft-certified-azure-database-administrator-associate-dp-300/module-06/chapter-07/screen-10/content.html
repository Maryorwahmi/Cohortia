Module 7 › Chapter 6.7 › DevOps Integration
Process Flow
Repo → Pipeline → Run → Archive
Version control and pipeline execution make runbooks repeatable and auditable.
Store
Commit notebooks and scripts to Azure Repos; use branches and PR policies for approvals.
Test
Run unit tests and execute notebook checks in pipelines; fail on unexpected outputs.
Run
Execute with service principal or managed identity; inject secrets from Key Vault or pipeline variables.
Archive results
Publish logs and outputs as pipeline artifacts for auditing and troubleshooting.
Important practice
Keep secrets out of repos. Use Key Vault integration or pipeline secure variables to provide credentials at runtime.
