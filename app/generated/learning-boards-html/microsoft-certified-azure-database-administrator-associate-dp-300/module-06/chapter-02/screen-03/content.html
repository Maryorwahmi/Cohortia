Practice & Safety

Testing, least-privilege, and monitoring are core to trustworthy automation.

Test in staging
Run job steps and runbooks against a non-production copy and validate results and error conditions.
VERIFIED COMPETENCY MILESTONE
Least privilege
Use managed identities or service principals with minimal permissions to reduce blast radius.
VERIFIED COMPETENCY MILESTONE
Observability
Log runbook output and connect failures to Azure Monitor alerts so operators are notified immediately.
VERIFIED COMPETENCY MILESTONE
