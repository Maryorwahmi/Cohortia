Definition

Azure Automation Runbook

A runbook is a scripted workflow that performs management or operational tasks across Azure resources.

  • Supports PowerShell, Python, or graphical designer.
  • Can use managed identities or service principals for authentication.
  • Integrates with Azure Monitor for alerting on job status.
Misconception
Runbooks are not a replacement for server-side Agent when you control the instance; they are complementary for PaaS and cross-resource tasks.
PowerShell runbook example
# PowerShell runbook: check Azure SQL Database size
Connect-AzAccount -Identity
param(
  [string]$ResourceGroupName,
  [string]$ServerName,
  [string]$DatabaseName
)
try {
  $db = Get-AzSqlDatabase -ResourceGroupName $ResourceGroupName -ServerName $ServerName -DatabaseName $DatabaseName
  Write-Output "Database $($DatabaseName) size: $($db.MaxSizeBytes / 1GB) GB"
}
catch {
  Write-Error "An error occurred: $($_.Exception.Message)"
}
Scenario
Schedule this runbook daily to log database sizes and trigger a scaling review if growth exceeds thresholds.
