Error Handling & Notifications

Make sure failures are visible and actionable with logs and alerts.

SQL Agent practice
Use TRY/CATCH, write to a maintenance log, and notify an operator on failure.
Azure Automation practice
Capture exceptions, write detailed output, and create Azure Monitor alerts for failed runbook jobs.
Common mistake
Blindly retrying without logging or escalation hides persistent problems. Limit retries and escalate if repeated failures occur.
Example notification flow
  1. Job fails and records error to a maintenance log.
  2. SQL Agent or runbook triggers operator or Azure Monitor alert.
  3. Alert sends email and webhook to an incident channel.
  4. Operator investigates using job history and logs.
Key Takeaway
Make failures noisy and informative so operators can act quickly.
