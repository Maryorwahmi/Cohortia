Daily Index Maintenance

  1. Connect to Azure SQL Managed Instance with SSMS or Azure Data Studio.
  2. Create an operator named DBA_Alerts and set a test email address.
  3. Create a job named Daily_Index_Maintenance and add a T-SQL step to rebuild indexes.
  4. Configure the step to use the correct database context and notify DBA_Alerts on failure.
  5. Create a daily schedule (e.g., 3:00 AM) and link it to the job.
  6. Manually start the job and verify job history and notifications.
Starter T-SQL for test table
USE YourDatabaseName;
GO

IF OBJECT_ID('dbo.TestTableForIndexes','U') IS NULL
BEGIN
  CREATE TABLE dbo.TestTableForIndexes (ID INT IDENTITY(1,1) PRIMARY KEY, DataColumn NVARCHAR(255), CreateDate DATETIME DEFAULT GETDATE());
  DECLARE @i INT = 0;
  WHILE @i < 10000
  BEGIN
    INSERT INTO dbo.TestTableForIndexes (DataColumn) VALUES (NEWID());
    SET @i = @i + 1;
  END;
  CREATE NONCLUSTERED INDEX IX_DataColumn ON dbo.TestTableForIndexes (DataColumn);
END;
GO
