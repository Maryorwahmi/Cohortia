Core Concept

SQL Server Agent

Runs inside Managed Instance or SQL Server on VM; jobs, steps, schedules, and operators provide server-side automation.

  • Native job scheduling with step control and error flow.
  • Direct T-SQL execution for maintenance tasks like index rebuilds.
  • Operators allow email notifications on job status changes.
Misconception
Native access doesn't mean agent is available in PaaS. Azure SQL Database does not expose SQL Server Agent.
Core Concept

Azure Automation

Cloud-native runbooks (PowerShell, Python, or graphical) that orchestrate across Azure resources and integrate with Azure Monitor.

  • Runbooks can use managed identities to authenticate without stored credentials.
  • Integrates with Azure Monitor for alerting on runbook job failures.
  • Useful when you need cross-resource or serverless orchestration for PaaS databases.
Key takeaway
Azure Automation is the right choice when you need a managed, cross-resource automation surface or when SQL Agent is unavailable.
