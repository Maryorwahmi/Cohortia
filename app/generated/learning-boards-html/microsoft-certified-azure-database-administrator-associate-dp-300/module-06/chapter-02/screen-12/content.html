Best Practice

Operational Checklist

  • Test automations in staging with representative data.
  • Use consistent, descriptive naming for jobs and runbooks.
  • Schedule maintenance during agreed off-peak windows.
  • Log start/end, status, and error details to a central table.
  • Review job/runbook history regularly and adjust retries and schedules.
Scenario: Large environment
Shard maintenance across objects or databases to avoid long-lock windows and enable parallel recovery if a shard fails.
Key takeaway
Automation must be repeatable, observable, and owned. Treat jobs and runbooks like code with testing and reviews.
