Module 06 › Chapter 6.5 › Monitoring, verification
Verification checklist
  • Capture fragmentation and query metrics before maintenance.
  • Run maintenance and update statistics with FULLSCAN if needed.
  • Compare post-maintenance fragmentation and plan costs.
  • Review job history logs and alert events for failures.
Common mistake
Scheduling overlapping heavy jobs that compete for IO and harm performance.
Pro tip
Stagger maintenance across databases and adjust batch sizes based on observed lock and log behavior.
Check your understanding
If a query degrades after a load, do you check fragmentation or statistics first? Consider both but refresh statistics after index changes.
Key Takeaway

Validation and monitoring are required to prove maintenance effectiveness; avoid shortcuts like routine shrink and overlapping heavy jobs.
