T-SQL examples
Use these snippets as templates. Replace YourDatabaseName and object names with your targets and test carefully in a nonproduction environment.
USE YourDatabaseName;
GO

-- Rebuild a specific index online
ALTER INDEX IX_Customers_LastName_FirstName ON dbo.Customers REBUILD WITH (ONLINE = ON);
GO

-- Rebuild ALL indexes on a table online
ALTER INDEX ALL ON dbo.Customers REBUILD WITH (ONLINE = ON);
GO

-- Update statistics for a table with full scan
UPDATE STATISTICS dbo.Customers WITH FULLSCAN;
GO

-- Update statistics for a specific index
UPDATE STATISTICS dbo.Customers IX_Customers_LastName_FirstName WITH FULLSCAN;
GO
Concrete note
Always run UPDATE STATISTICS after rebuild if your workload needs the most accurate distribution data for plan selection.
Misconception
ONLINE = ON removes all risk; it reduces blocking but still consumes resources and must be scheduled with care.
Checklist before running
  • Verify disk and CPU headroom for heavy operations.
  • Schedule during low activity and notify stakeholders.
  • Capture job output and compare fragmentation before and after.
Key Takeaway

Use provided T-SQL templates, adapt names, run in test, and update statistics after maintenance to maximize optimizer benefit.
