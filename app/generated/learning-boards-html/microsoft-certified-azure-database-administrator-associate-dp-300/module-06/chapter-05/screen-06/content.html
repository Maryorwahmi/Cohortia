Module 06 › Chapter 6.5 › Measuring fragmentation
Steps
  1. Run sys.dm_db_index_physical_stats for the database, object, and index.
  2. If fragmentation ≤ 5%: no maintenance required.
  3. If fragmentation > 5% and ≤ 30%: run ALTER INDEX REORGANIZE.
  4. If fragmentation > 30%: run ALTER INDEX REBUILD; use ONLINE = ON if supported.
  5. After maintenance: run UPDATE STATISTICS with FULLSCAN for accurate optimizer data.
Common mistake
Relying on a single run of maintenance without post-checks; always confirm fragmentation and plan metrics improved.
Concrete example
If sys.dm_db_index_physical_stats reports 35% fragmentation for IX_OrderDetails_ProductID, schedule ALTER INDEX REBUILD WITH (ONLINE = ON) during an off-peak window. After the rebuild, run UPDATE STATISTICS Sales.OrderDetails WITH FULLSCAN to refresh distribution metadata.
Key Takeaway

Use a measured decision flow and validate results; thresholds guide action but monitoring validates effectiveness.
