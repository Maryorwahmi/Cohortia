Learning Objectives
Bloom targets: Learn → Understand → Apply → Master
Learn → Understand → Apply → Master
01
Explain why proactive maintenance matters
Describe how fragmentation, stale statistics, and missed integrity checks affect performance and recovery. You will justify scheduling choices for off-peak windows.
VERIFIED COMPETENCY MILESTONE
02
Implement index and statistics scripts
Write T-SQL that conditionally rebuilds or reorganizes indexes and runs update statistics with appropriate sampling or full scan.
VERIFIED COMPETENCY MILESTONE
03
Configure integrity checks for Azure
Plan DBCC CHECKDB schedules for Managed Instance and use automation options for Azure SQL Database when needed after bulk operations.
VERIFIED COMPETENCY MILESTONE
04
Manage logs and cleanup safely
Design transaction log and cleanup procedures, including safe batching for deletes and careful use of shrink operations only when justified.
VERIFIED COMPETENCY MILESTONE
