Module 06 › Chapter 6.5 › Scheduling and automation
Scheduling options
Choose the mechanism that fits your deployment: SQL Agent for Managed Instance and VMs; Azure Automation, Functions, or Elastic Jobs for Azure SQL Database.
Best practices
Schedule during off-peak hours, include logging and email or alert hooks for failures, and avoid overlapping heavy jobs across instances.
Validation: review job histories and metrics after runs to confirm fragmentation and plan improvements.
Scheduling checklist
  • Choose runtime: SQL Agent, Automation, Functions, or Elastic Jobs.
  • Set off-peak windows and stagger across databases.
  • Add retry logic, logging, and alerting for failures.
Key Takeaway

Automate maintenance with appropriate scheduling tools for your deployment and validate runs through logs and alerts.
