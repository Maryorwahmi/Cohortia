Batch delete pattern
Delete in chunks using a loop and a controlled batch size, then pause between batches to reduce lock duration and log pressure.
USE YourDatabaseName;
GO

DECLARE @RowsAffected INT = 1;
DECLARE @BatchSize INT = 10000;
DECLARE @CutoffDate DATETIME = DATEADD(year, -1, GETDATE());

WHILE @RowsAffected > 0
BEGIN
    DELETE TOP (@BatchSize) FROM AdminAuditLog
    WHERE ActionTimestamp < @CutoffDate;

    SET @RowsAffected = @@ROWCOUNT;

    IF @RowsAffected > 0
        WAITFOR DELAY '00:00:01';
END;
GO
This pattern reduces transaction duration and gives the log time to be backed up and truncated between batches for MI/VM or managed operations in Azure SQL.
Checklist
  • Ensure the delete predicate has supporting indexes.
  • Start with small batch sizes and increase cautiously.
  • Monitor locks and log growth during the run.
Key Takeaway

Batched deletes are the safe way to remove large amounts of data while protecting availability and controlling log growth.
