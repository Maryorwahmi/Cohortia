Module 06 › Chapter 6.5 › Statistics and the Query Optimizer
What are statistics?

Statistics are histograms and metadata about column value distribution used to estimate how many rows a query will return.

Concrete example
After bulk imports, the histogram may not reflect new value frequencies. The optimizer may choose a suboptimal plan until statistics are refreshed.
Tip: Use FULLSCAN when accurate distributions matter; use SAMPLE percent when you need speed.
Practical actions
  • Identify volatile tables and schedule more frequent statistic updates.
  • Run UPDATE STATISTICS TableName WITH FULLSCAN after big data loads or index rebuilds.
  • Monitor query plans for sudden cardinality estimate changes to signal stale statistics.
Key Takeaway

Accurate statistics are essential for the optimizer—refresh them after large data changes to prevent plan regressions.
