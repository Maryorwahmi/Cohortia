Azure Automation
A cloud service for automating management tasks across resources using runbooks.
Automation Account
Central hub for runbooks, variables, modules, and identity used by automation jobs.

Runbook
A script (PowerShell or Python) executed by Azure Automation to perform a task.
Summary

These concepts work together: runbooks inside Automation Accounts run with identities and modules to automate database operations safely.
