Schedules
Recurring tasks
Use for daily backups, scaling before predictable load, or nightly maintenance.
Webhooks
External triggers
Expose an HTTP POST endpoint to start runbooks from external systems. Secure them appropriately.
Alerts & Logic Apps
Event-driven automation
Link Azure Monitor alerts to runbooks for automated remediation; use Logic Apps for multi-step orchestrations.
Example
Link a schedule to a runbook that stops a MySQL flexible server at 10 PM. Use an alert to trigger a runbook when free storage falls below a threshold.
Key Takeaway

Pick the trigger that matches the operational pattern: recurring, reactive, external, or orchestrated.
