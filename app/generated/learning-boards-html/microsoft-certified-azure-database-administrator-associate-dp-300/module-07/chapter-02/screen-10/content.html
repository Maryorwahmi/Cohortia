PowerShell
Az modules
Import Az.Sql and other Az modules to expose cmdlets used by your PowerShell runbooks.
  • Install and update modules in the Automation Account.
  • Version control matters for predictable behavior.
    • Python
    Add packages
    Add azure-identity, azure-keyvault-secrets and database drivers (pg8000) to the Automation Account's Python packages list.
  • Failure to add packages causes import errors at run time.
  • Keep package versions compatible with the runtime version.
    • Pro tip

    Document package and module versions required by each runbook and include that as part of publish procedures to avoid runtime surprises.

    Key Takeaway

    Pre-provision modules and packages in the Automation Account so runbooks import dependencies reliably.
