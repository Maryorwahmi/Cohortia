Hardcoding secrets
Risk: secrets appear in code and logs. Fix: use Key Vault and Managed Identity.
Insufficient error handling
Risk: silent failures. Fix: implement try/catch, log details, and fail jobs explicitly when needed.
Over-privileged identities
Risk: compromised automation can cause wide impact. Fix: assign least privilege and narrow scope.
Missing dependencies
Risk: import errors at run time. Fix: add required modules and packages to the Automation Account before publishing.
Action

Create a pre-deployment checklist: secure secrets, dependency list, test plan, and scoped permissions before publishing a runbook.
