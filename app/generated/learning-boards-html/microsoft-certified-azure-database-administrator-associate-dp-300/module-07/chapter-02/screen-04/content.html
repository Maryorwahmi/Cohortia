Definition
Azure Automation
A managed service for authoring and running runbooks to perform operational tasks across Azure and non-Azure systems.
When to use it
  • Scheduled maintenance: backups, scale operations, nightly scripts.
  • Event-driven responses: triggered by alerts or webhooks.
  • Cross-service orchestration: combine monitoring, scaling and notification actions.
Analogy
Think of Automation as a scheduled operations engine that runs playbooks for your databases.
Concrete example
Schedule a runbook to scale an Azure SQL Database up before a weekly report job and scale back down afterward. The runbook authenticates with Managed Identity and uses Az cmdlets to change the service objective.
Common misconception
Automation is not a replacement for CI/CD. It complements deployment pipelines by handling runtime operational tasks like scaling, maintenance, and checks.
Key Takeaway

Use Azure Automation for repeatable, auditable operational tasks and pair it with secure secrets management.
