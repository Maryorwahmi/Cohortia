Module 7 › Chapter 7.1 › Security & Permissions
Principle of least privilege
Assign only required DDL and DML permissions to the pipeline identity, scoped to the target database and schema.
Checklist
  • Use managed identities or service principals with narrow scopes.
  • Store secrets in secure pipeline variables or Key Vault.
  • Audit and rotate credentials regularly.
Rollback and backups
Automate backups or snapshot steps before production deployments and keep documented restore steps available to the team.
Misconception
Giving a pipeline full admin rights simplifies scripts but increases risk. Prefer scoped permissions and explicit required operations instead.
Operational pro-tip

Test permission scopes in a sandbox environment to ensure the pipeline identity can perform the intended operations without over-privileging.
