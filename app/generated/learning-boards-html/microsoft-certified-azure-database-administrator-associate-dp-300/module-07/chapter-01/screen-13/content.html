Module 7 › Chapter 7.1 › Troubleshooting
Paths
Ensure PathtoPublish points to the actual .dacpac output. Validate build outputs locally if unsure.
Permissions
Use least privilege for deployment identities and avoid using full admin credentials in pipelines.
Testing
Run deployments in dev/staging and validate both schema and data outcomes before production runs.
Backups & Rollback
Automate backups before production deployments; prefer restore over manual fixes if rollback is needed.
Agent dependencies
Ensure client tools like psql or mysql are installed in pipeline agents used for running migrations.
Reflection
Which mitigation—better testing, stricter permissions, or automated backups—would most improve your team's deployments right now?
