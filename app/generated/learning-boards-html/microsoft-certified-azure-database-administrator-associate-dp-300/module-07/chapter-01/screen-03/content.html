Module 7 › Chapter 7.1 › Learning Objectives — Milestones
01 • Principles
Milestone: Create a short case showing schema-as-code preventing manual drift. Evidence: a Git commit history and a diff demonstrating a schema change tracked in SSDT or script files.
Venn mnemonic: Versioning ∩ Automation ∩ Collaboration
VERIFIED COMPETENCY MILESTONE
02 • Configure DevOps
Milestone: Create an Azure DevOps project and Azure Repo, push an SSDT solution or migration scripts. Evidence: a pipeline trigger on commit and visible repo tree.
Timeline mnemonic: Repo → CI → Artifact → CD
VERIFIED COMPETENCY MILESTONE
03 • CI
Milestone: Run a pipeline that builds the .sqlproj to a .dacpac or validates migration scripts and publishes them as an artifact. Evidence: published build artifact and pipeline logs showing success.
Simple icon mnemonic: Package
VERIFIED COMPETENCY MILESTONE
04 • CD & Safety
Milestone: Deploy the artifact to a dev/staging environment, run post-deployment data scripts, and show rollback readiness. Evidence: deployment logs, backups, and a rollback plan.
Pro tip: Schema deploy first, then data scripts
VERIFIED COMPETENCY MILESTONE
