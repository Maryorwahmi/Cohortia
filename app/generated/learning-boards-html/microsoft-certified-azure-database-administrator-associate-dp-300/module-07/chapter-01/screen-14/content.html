Module 7 › Chapter 7.1 › Key Concepts
Database DevOps
Apply automation, versioning, and CI/CD to database schema and data to reduce errors and accelerate releases.
SQL Server Data Tools (SSDT)
A Visual Studio extension to author SQL projects that represent a database schema as code.
Data-tier Application Package (.dacpac)
A compiled artifact from SSDT that describes the desired database state for deployment tasks to consume.
Summary
Use these concepts together: version your schema, build artifacts in CI, and deploy with CD while protecting data and credentials.
