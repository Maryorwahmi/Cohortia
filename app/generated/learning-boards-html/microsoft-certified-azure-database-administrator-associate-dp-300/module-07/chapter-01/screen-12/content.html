Module 7 › Chapter 7.1 › Hands-on: CI/CD
Starter steps
  1. Create SQL Server Database Project MyAzureSQLDBProject in Visual Studio and add a Products table.
  2. Create an Azure DevOps project and an Azure Repo, then push your solution to main.
  3. Create a pipeline with the provided azure-pipelines.yml to build and publish the .dacpac.
  4. Run the pipeline and validate the dacpac artifact is published.
Sample SQL to add
CREATE TABLE dbo.Products (
  ProductID INT PRIMARY KEY,
  ProductName NVARCHAR(100)
);
Add this file to your SSDT project, commit, and push to trigger CI.
Key Takeaway

Follow the commit → CI build → artifact verification steps before wiring up CD; adapt artifacts for migration-driven databases by publishing validated scripts instead of a .dacpac.
