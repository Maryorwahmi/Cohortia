Module 7 › Chapter 7.1 › Schema vs Data Sequence
Correct: Schema first
Steps: deploy .dacpac to apply schema updates, then execute post-deploy data scripts that assume the new schema.
Why this matters
  • Prevents script failures when columns/tables do not exist.
  • Helps generated deployment scripts preserve existing data.
Incorrect: Data first
Running data updates before schema is applied commonly causes immediate failures and rollbacks. This is a frequent root cause of outages.
Mitigations
  • Use idempotent data scripts.
  • Include pre-checks to ensure required columns exist.
  • Keep backups and rollback scripts prepared.
Key Takeaway

Order matters: apply schema changes first, then data migrations, and design scripts to be safe when run multiple times.
