Module 7 › Chapter 7.5 › Testing DDM
Step-by-step
  1. Create the sample Sales.Customers table and insert rows.
  2. Apply DDM rules to Email and CreditCardNumber columns.
  3. Create login TestUser and grant SELECT on the table.
  4. Connect as TestUser and run SELECT to observe masked values.
  5. Connect as admin to confirm unmasked output.
Common mistake
Granting UNMASK too broadly defeats privacy controls; grant only to roles with a clear need.
Example SQL snippets
-- Create a non-privileged test user
CREATE LOGIN TestUser WITH PASSWORD = 'YourStrongPassword!';
CREATE USER TestUser FOR LOGIN TestUser;
GRANT SELECT ON Sales.Customers TO TestUser;

-- Test result: connect as TestUser and run:
SELECT CustomerID, Email, CreditCardNumber FROM Sales.Customers;
