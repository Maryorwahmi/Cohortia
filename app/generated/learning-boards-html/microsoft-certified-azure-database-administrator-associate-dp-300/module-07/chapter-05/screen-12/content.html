Module 7 › Chapter 7.5 › Policy & Defender
Azure Policy
Create policies and initiatives to enforce required settings such as enabling auditing or restricting SKUs.
Example policy
Require that Azure SQL databases have auditing enabled and forward logs to a central Log Analytics workspace.
Behavior
Policies can deny, append, or audit non-compliant resources and run at scale across subscriptions.
Defender for Cloud
Provides continuous assessment, recommendations, and compliance dashboards for database security posture.
Use case
Defender flags missing auditing, weak configurations, and suggests remediation steps to improve compliance.
Best practice
Combine policy enforcement with Defender alerts to detect drift and act quickly on security findings.
