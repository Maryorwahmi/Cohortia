Module 7 › Chapter 7.5 › Always Encrypted
Definition

Client-side encryption for sensitive columns

Data is encrypted before it reaches the server; the server stores ciphertext and never holds the keys to decrypt.
Keys
Column Master Key (CMK) protects Column Encryption Key (CEK). CEK encrypts column values.
Use case
Protect PHI or payment data so DBAs cannot view plaintext even during maintenance.
Design notes
  • Plan key storage and rotation; CMKs often live in a key vault outside the database.
  • Ensure client drivers support Always Encrypted operations for encryption and decryption.
  • Combine with classification to determine which columns require this level of protection.
Misconception check
Always Encrypted protects column contents but does not replace audit trails or classification processes.
