Module 7 › Chapter 7.5 › Protection Comparison
Dynamic Data Masking
Presentation-level masking for non-privileged users.
Pros: Fast to implement. Cons: Not encryption, DBAs may still see plaintext.
Always Encrypted
Client-side encryption where the server never sees plaintext.
Pros: Strong separation of duties. Cons: Requires driver support and key management.
Transparent Data Encryption
Encrypts data at rest on the server disks.
Pros: Protects backups and storage. Cons: Server can access plaintext when running.
Key Takeaway

Choose masking for quick privacy, Always Encrypted for strict separation, and TDE for disk-level protection; combine as needed.
