Module 7 › Chapter 7.5 › Auditing Example
Code walkthrough
This conceptual T-SQL shows a database audit specification capturing common DML actions. Use portal tooling to bind audits to storage destinations.
-- Conceptual example of a database audit specification
CREATE DATABASE AUDIT SPECIFICATION [Audit_Data_Access]
FOR SERVER AUDIT [SQL_Server_Audit]
ADD (SELECT ON DATABASE::[MyDatabase] BY public),
ADD (UPDATE ON DATABASE::[MyDatabase] BY public),
ADD (DELETE ON DATABASE::[MyDatabase] BY public),
ADD (INSERT ON DATABASE::[MyDatabase] BY public)
WITH (STATE = ON);
Explanation
  • Audit captures read and write operations to provide an access trail for sensitive data.
  • Bind the audit to a central destination: Storage for retention, Log Analytics for queries, Event Hub for streaming.
  • Filter to relevant actions to control volume and cost.
Concrete scenario
Audit SELECT on patient diagnosis columns so you can trace who accessed those records during an investigation.
