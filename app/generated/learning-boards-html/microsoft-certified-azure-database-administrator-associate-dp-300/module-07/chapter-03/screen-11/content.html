Server parameters: PostgreSQL
Common parameters and how to approach safe tuning.
  • work_mem — memory per sort/hash; tune for heavy sorts but watch concurrency.
  • shared_buffers — PostgreSQL buffer cache; increase carefully alongside OS cache.
  • effective_cache_size — planner hint of available cache; helps planner estimates.
Practical checks
SHOW work_mem; and SHOW shared_buffers; let you inspect current values. Test changes in staging and run representative concurrent queries to observe memory pressure and query times.
Concrete example
If many concurrent sorts are spilling to disk, gradually increase work_mem and rerun workloads, monitoring RAM to avoid OOM scenarios.
