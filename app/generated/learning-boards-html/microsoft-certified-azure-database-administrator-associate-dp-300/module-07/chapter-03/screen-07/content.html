Definition
Azure Cloud Shell
A browser-based shell with Azure CLI pre-installed for fast, consistent administration.
Why use it?
  • No local CLI install required; consistent tool versions.
  • Quickly run az commands and pair with psql/mysql for immediate tests.
  • Store scripts in the mounted file share or source control to persist them.
Concrete example
Use Cloud Shell to set log_min_duration_statement and then run a test query from the same session to confirm logs are produced.
Practical notes
  • Sessions are ephemeral; persist scripts to your cloud-backed file share.
  • Cloud Shell is ideal for short admin tasks and automation testing.
  • For heavy data processing use a VM with sufficient resources instead of Cloud Shell.
Common misconception
Don't assume Cloud Shell keeps long-running state or installed packages between sessions; treat it as a consistent ephemeral admin environment.
