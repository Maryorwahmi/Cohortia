Core Concept
Using the mysql client
Connect and inspect server runtime state, manage privileges, and perform table maintenance.
Connection example
mysql -h <your_server_name>.mysql.database.azure.com -P 3306 -u <admin_user>@<your_server_name> -p <database_name>
Inspect runtime variables and optimize a table when necessary:
SHOW VARIABLES LIKE 'innodb_buffer_pool_size';
SHOW STATUS;
OPTIMIZE TABLE my_table;
EXPLAIN SELECT * FROM my_table WHERE ...;
Concrete scenario
If a reporting query is slow and EXPLAIN shows full table scans, run OPTIMIZE after large deletes to compact pages, but also consider adding an index or resizing the InnoDB buffer pool for sustained improvements.
Common mistake
Relying solely on OPTIMIZE TABLE; it doesn't replace good indexing and query design.
Key takeaway
Combine runtime inspection, EXPLAIN, and targeted maintenance to diagnose and improve MySQL performance.
Pro tip
Enable the slow query log and long_query_time to capture problematic queries before tuning buffer sizes or indexes.
