Module 7 › Chapter 7.4 › Hands-on Activity
Lab steps
  1. Create Function App (Python) and enable system-assigned Managed Identity.
  2. Store MySQL admin password in Key Vault and grant the Function identity Get permission.
  3. Set application settings: DB_HOST, DB_NAME, DB_USER, KEY_VAULT_NAME, DB_PASSWORD_SECRET_NAME.
  4. Create products table in MySQL and verify connectivity from Workbench.
  5. Deploy createproduct HTTP function and test with a POST containing product_name and price.
SQL to create table
CREATE TABLE IF NOT EXISTS products (
  product_id INT AUTO_INCREMENT PRIMARY KEY,
  product_name VARCHAR(255) NOT NULL,
  price DECIMAL(10, 2) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
Test tip
Use Postman or curl to POST to the function URL and then verify the row appears in MySQL Workbench.
