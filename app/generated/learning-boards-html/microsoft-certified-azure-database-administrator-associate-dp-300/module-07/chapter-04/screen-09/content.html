Identity without credentials
Use system-assigned Managed Identity to authenticate to Key Vault and other Azure services securely.
Steps
  1. Enable system-assigned Managed Identity on the Function App.
  2. Grant the identity Get permission on the specific Key Vault secret.
  3. Use DefaultAzureCredential in your function code to request the secret at runtime.
Why it matters
This pattern eliminates embedded credentials, centralizes secret rotation, and aligns with least privilege security practices.
Misconfigurations to avoid
  • Granting broad Key Vault roles instead of secret-level Get permission.
  • Placing production secrets in plain app settings or code.
  • Assuming Managed Identity has outbound network access without checking VNet and firewall rules.
Operational tip
Test Key Vault permission with a minimal script and ensure the Function App identity appears in the Key Vault access policy or RBAC role for secrets.
