Module 7 › Chapter 7.4 › What are Azure Functions?
Core definition
Azure Functions run event-driven code without you managing servers; they scale and bill per execution.
Analogy
Think of functions as short scripts that run on demand — like a webhook handler or a scheduled cron job — but hosted and scaled by Azure.
When to use
  • Short-lived tasks triggered by events or schedules.
  • Lightweight APIs that perform single queries or updates.
  • Background processing that reacts to changes without a persistent server.
Key Takeaway

Prefer functions for focused, idempotent database work that benefits from automatic scaling and managed runtime.

Example scenario — Order processing
Insert
New row added to Orders table.
Trigger
Function invoked to process order data.
Actions
Update inventory, send confirmation, push analytics.
Misconception
Serverless always equals lower cost: not always. Evaluate execution frequency and duration before choosing serverless over reserved resources.
