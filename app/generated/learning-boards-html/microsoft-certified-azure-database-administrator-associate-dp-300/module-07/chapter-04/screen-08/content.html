Module 7 › Chapter 7.4 › Event Grid bridge
Publish minimal events from the application
Keep events small, include entity id and timestamp, and ensure publishing is part of the write workflow or uses an outbox pattern.
Application writes
Application inserts a row and publishes a corresponding event to Event Grid or message bus.
Event Grid
Event Grid receives the published event and invokes subscribers such as Azure Functions.
Function
Function processes the event, performs reads/writes, or forwards to downstream systems.
Outbox pattern
Use a transactional outbox to guarantee event publication even if the app experiences a partial failure.
Practical advice
  • Include idempotency keys and source timestamps in events.
  • Keep payloads small and fetch canonical data from the database if needed.
  • Use a reconciliation Timer job to correct missed events.
Common mistake
Publishing large blobs in events couples services; instead publish identifiers and let consumers fetch details as needed.
