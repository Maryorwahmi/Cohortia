Module 7 › Chapter 7.4 › Troubleshooting
Common failure modes
  • Missing or misspelled App Settings for DB_HOST, KEY_VAULT_NAME, etc.
  • Key Vault access denied due to missing identity permission.
  • Network timeouts from VNet or Private Endpoint misconfiguration.
  • Leaked connections causing connection pool exhaustion.
Debug checklist
Confirm App Settings, test Key Vault access with the Function identity, validate DNS for Private Endpoint, and add detailed logs around connection open/close.
Use Application Insights
Instrument functions with structured logs and exceptions. Traces that include the step name help you quickly identify whether the failure occurred at secret retrieval, connection, or query time.
Common mistake
Hardcoding passwords to bypass permission issues only shifts the failure and increases risk. Fix permissions and network configs instead.
