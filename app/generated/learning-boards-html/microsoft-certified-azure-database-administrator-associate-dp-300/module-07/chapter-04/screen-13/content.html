Module 7 › Chapter 7.4 › Principles & Ops
Least privilege and rotation
Grant only the permissions needed and rotate secrets in Key Vault to limit exposure if a credential is compromised.
Identity roles
Assign Function identity minimal Key Vault secret Get and specific database roles that permit required operations only.
Secret rotation
Rotate credentials in Key Vault and validate functions retrieve the updated secret without code changes.
Deployment and monitoring
Use CI/CD for repeatable deployments and Application Insights for observability. Alert on error rates and high latencies.
Key Takeaway
Operational controls and least-privilege access reduce risk and make function-driven database integrations maintainable at scale.
