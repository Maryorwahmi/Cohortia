Module 7 › Chapter 7.6 › Common Issues

Problems

  • Missing indexes: leads to scans and high I/O.
  • Non-sargable predicates: functions on columns prevent seeks.
  • Blocking: long transactions holding locks stop concurrency.
  • Outdated statistics: optimizer misestimates cardinality.
  • Parameter sniffing: a plan optimized for one parameter may be poor for others.

Fixes

  • Create targeted nonclustered or columnstore indexes; evaluate effect on writes.
  • Rewrite predicates to be sargable (avoid wrapping columns in functions).
  • Find blockers via DMVs and reduce transaction scope to lower lock time.
  • Update statistics or use filtered/column-specific statistics for skewed data.
  • Mitigate parameter sniffing with recompile options or by testing forced plans in Query Store.
Pro Tip
Make one change at a time and measure its impact with Query Store or repeatable DMV sampling.
