Module 7 › Chapter 7.6 › Change Management
Baseline
Capture duration, CPU, logical reads, and plan IDs before any change. Store these values as your control set.
Staging
Reproduce workload at realistic scale and test index or query changes. Validate plans and metrics here first.
Rollout
Use phased rollout, maintenance windows, and a rollback plan. Monitor Query Store or DMVs for regressions after change.
Repeatable tests
Keep a small suite of queries to run before and after changes; record the results for traceability.
Runbook
Document steps, verification queries, alert thresholds, and rollback steps so others can validate or revert the change.
