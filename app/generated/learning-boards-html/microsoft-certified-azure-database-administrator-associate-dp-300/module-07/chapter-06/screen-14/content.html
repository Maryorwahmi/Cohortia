Module 7 › Chapter 7.6 › Key Concepts
Query Execution Plan
Shows steps and costs; use actual plans to compare estimated and real work.
Query Store
Historical capture of queries and plans; useful for identifying regressions and forcing plans.
DMVs / DMFs
Provide live state: active sessions, waits, I/O stats, and index usage for immediate diagnosis.
Remember to test changes in non-production, measure before and after, and avoid permanent fixes without evidence. Use Query Store as your evidence store and Extended Events for fine-grained captures.
