Learning Objectives

These four objectives will ensure you can diagnose query bottlenecks, track history, measure live state, and apply index and event-based approaches for durable performance improvements.

01
Interpret Execution Plans
Read operation sequences and costs, spot scans, seeks, and sorts. This skill helps you locate the single operation that causes high CPU or I/O across queries.
VERIFIED COMPETENCY MILESTONE
02
Use Query Store
Capture historical query plans and runtime stats, identify regressions, and force previously good plans to restore performance without code changes.
VERIFIED COMPETENCY MILESTONE
03
Query DMVs/DMFs
Inspect active requests, waits, I/O, and index usage to diagnose blocking and resource contention in real time.
VERIFIED COMPETENCY MILESTONE
04
Index Strategy & Events
Choose OLTP or OLAP index approaches, find unused/missing indexes, and use Extended Events for intermittent issues.
VERIFIED COMPETENCY MILESTONE
