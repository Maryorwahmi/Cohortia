Module 7 › Chapter 7.6 › Learning Objectives

Outcomes you can verify

Each objective maps to a concrete verification: captured plan, DMV output, plan change after indexing, and an Extended Events capture.

Verify Query Store
After enabling, run a sample query and confirm it appears in Top Resource Consuming Queries with captured plans.
Verify DMVs
Run queries against sys.dm_exec_requests or pg_stat_activity to show active queries and waits for a target session.
Verify Index Change
Create a nonclustered index, re-run the slow query, and observe plan change from scan to seek and improved runtime.
Verify Extended Events
Collect long-running queries and review event payload to find parameter values or lock information contributing to slowness.
