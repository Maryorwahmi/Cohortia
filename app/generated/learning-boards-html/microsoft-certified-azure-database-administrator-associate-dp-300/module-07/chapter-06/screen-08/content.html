Module 7 › Chapter 7.6 › Index Strategy
OLTP index rules
  • Use narrow, selective nonclustered indexes on predicate and join columns.
  • Avoid many overlapping indexes that increase write cost.
  • Measure seek vs scan counts and remove unused indexes.
Example
Create a nonclustered index on CustomerID and OrderStatus to support frequent lookups by customer and status.
OLAP index rules
  • Prefer columnstore indexes for large analytic scans and aggregates.
  • Allow wider composite indexes to cover reporting queries.
  • Keep maintenance windows for bulk load and index rebuilds.
Key Takeaway
Pick indexes based on workload access patterns, measure usage, and always validate changes in non-production before production rollout.
Measure
Use sys.dm_db_index_usage_stats to find seeks, scans, and updates per index.
Test
Apply index changes in a staging environment with realistic data volumes before production.
Balance
Weigh read improvements against write overhead and storage impact.
