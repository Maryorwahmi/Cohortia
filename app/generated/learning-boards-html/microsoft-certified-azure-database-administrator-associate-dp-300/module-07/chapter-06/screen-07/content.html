Azure SQL
Query Store for history, DMVs like sys.dm_exec_requests for live state, and Extended Events for granular capture.
SELECT TOP 10 qt.query_sql_text, q.query_id, SUM(rs.avg_cpu_time) AS avg_cpu_time
FROM sys.query_store_query_text qt
JOIN sys.query_store_query q ON qt.query_text_id = q.query_text_id
JOIN sys.query_store_plan p ON q.query_id = p.query_id
JOIN sys.query_store_runtime_stats rs ON p.plan_id = rs.plan_id
GROUP BY qt.query_sql_text, q.query_id
ORDER BY avg_cpu_time DESC;
PostgreSQL
EXPLAIN ANALYZE for actual plans and pg_stat_activity/pg_stat_statements for active and aggregated metrics.
EXPLAIN ANALYZE SELECT product_name, price FROM products WHERE price > 100;

SELECT pid, usename, application_name, client_addr, state, query
FROM pg_stat_activity WHERE state = 'active';
