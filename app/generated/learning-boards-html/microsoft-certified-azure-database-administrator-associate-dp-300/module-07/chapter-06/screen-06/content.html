Common DMVs
  • sys.dm_exec_requests — currently executing requests and duration.
  • sys.dm_exec_sessions — session metadata and client info.
  • sys.dm_db_index_usage_stats — seeks, scans, lookups, and updates per index.
  • sys.dm_io_virtual_file_stats — file-level I/O counters.
-- Example: active queries in PostgreSQL
SELECT pid, usename, application_name, client_addr, backend_start, state, query
FROM pg_stat_activity
WHERE state = 'active'
ORDER BY query_start;
Investigation flow
  1. Identify long-running or blocked sessions with DMVs.
  2. Capture the query text and execution plan for the session.
  3. Check waits, CPU, and I/O to classify the bottleneck.
  4. Apply fixes: index, query rewrite, statistics update, or transaction tuning.
Key Takeaway
DMVs are best used for immediate diagnosis and when paired with plan captures or Query Store for historical context.
