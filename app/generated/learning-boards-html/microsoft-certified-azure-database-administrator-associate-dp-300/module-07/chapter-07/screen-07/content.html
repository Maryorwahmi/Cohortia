Module 8 › Chapter 7.7 › ADF Hands-on
Checklist
  • Create ADLS Gen2 container raw-data.
  • Configure Linked Service for PostgreSQL (use Key Vault).
  • Configure Linked Service for ADLS Gen2 using Managed Identity.
  • Create datasets and a Copy Data activity, then debug and monitor.
Scenario

Move the products table from PostgreSQL into ADLS Gen2 as products/products.csv with a header row, then verify file contents in Storage Explorer or the portal.

Pro tip: run a small sample first to validate schema and mapping before copying the full table.
