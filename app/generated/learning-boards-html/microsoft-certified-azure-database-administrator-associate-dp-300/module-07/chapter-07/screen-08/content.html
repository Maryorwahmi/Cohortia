Module 8 › Chapter 7.7 › Power BI modes
DirectQuery

Real-time queries to source

  • Data stays in source; Power BI queries at run time.
  • Best when you need near-instant freshness and low dataset size.
  • Risk: can introduce load and slower interactions on the source.
Avoid DirectQuery for high-interaction dashboards against production OLTP databases.
Import mode

In-memory model for performance

  • Data is cached in Power BI's model for fast interaction.
  • Best for large dashboards and complex visuals where speed matters.
  • Requires scheduled refreshes or incremental refresh to keep data updated.
Prefer Import mode with Synapse or aggregated tables for large datasets.
Key Takeaway

Balance freshness and performance: use Import mode for fast, interactive reports and DirectQuery only when real-time data is essential and source impact is acceptable.
