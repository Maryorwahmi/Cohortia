Module 8 › Chapter 7.7 › Pipeline design

Volume · Velocity · Variety

Assess dataset size, freshness needs, and schema complexity to choose batch, micro-batch, or streaming. Include validation and monitoring in every design.

Batch
Daily ETL jobs via ADF for large volumes with low freshness needs.
Micro-batch
Frequent incremental copies using watermarks for moderate latency.
Streaming
Event Hubs or CDC for near real-time processing; higher complexity and cost.
Checklist
  • Define acceptable lag for consumers.
  • Measure source DB load during tests.
  • Plan error handling and retries.
Pro Tip

Start with a conservative batch design and iterate to micro-batch or streaming only when business needs justify added complexity.
