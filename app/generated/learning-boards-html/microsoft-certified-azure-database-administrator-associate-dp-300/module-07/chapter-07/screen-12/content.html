Module 8 › Chapter 7.7 › Key Concepts
Azure Synapse Analytics
Unified data warehousing, big data, and integration for large-scale analytics.
Azure Data Factory
Cloud service to orchestrate, move, and transform data across sources and targets.
ETL / ELT
Two integration patterns: transform before load (ETL) or transform after load (ELT) inside the analytical store.
Summary

These key concepts form the backbone of integrating operational data with analytics and AI: choose the right target, move data securely, and pick the integration pattern that fits your scale and freshness needs.
