Overview

Synapse for warehousing and big data

Synapse combines dedicated SQL pools, serverless SQL, and Spark pools to handle large-scale analytics. It integrates tightly with ADF for data movement.

Architecture notes
  • Use dedicated SQL pools for predictable warehousing performance.
  • Use Spark pools to run large-scale transformations and feature engineering.
  • Store raw files in ADLS Gen2 and reference them from Synapse for ELT patterns.
Concrete example

Use ADF to copy yesterday's transactional data to a Synapse staging table, run ELT transformations in a stored procedure, and expose aggregated tables to Power BI for reporting.

-- Conceptual SQL to create an external table in Synapse
CREATE EXTERNAL TABLE [dbo].[ExternalOrders] (
  [OrderID] INT NOT NULL,
  [CustomerID] INT NOT NULL,
  [OrderDate] DATETIME NOT NULL,
  [OrderTotal] DECIMAL(10,2) NOT NULL,
  [OrderStatus] VARCHAR(50) NOT NULL
)
WITH (
  LOCATION = 'dbo.Orders',
  DATA_SOURCE = [AzureSqlDataSource],
  FILE_FORMAT = [SqlFileFormat]
);
Key Takeaway

Choose Synapse when you need scale, cross-source joins, and the ability to prepare large datasets for models or reports.
