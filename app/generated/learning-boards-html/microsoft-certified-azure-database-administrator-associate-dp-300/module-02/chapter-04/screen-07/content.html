Module 2 › Chapter 2.4 › Managed Instance and VNet Integration
Architecture
Dedicated subnet + NSGs
Managed Instance runs inside a dedicated subnet. Plan address space and NSG rules carefully so only authorized subnets can connect.
Dedicated Subnet
Reserve a subnet solely for Managed Instance and size for growth.
Network Security Group
Define inbound/outbound rules to allow only necessary traffic.
Service Outbound
Allow outbound for patching and monitoring using service tags where possible.
NSG example
Allow inbound TCP 1433 from the application subnet and deny other inbound sources. Log NSG hits to monitor unexpected traffic.
Check your design

Ensure the subnet has enough IP addresses and does not include other workloads. Use flow logs to validate allowed traffic patterns.
