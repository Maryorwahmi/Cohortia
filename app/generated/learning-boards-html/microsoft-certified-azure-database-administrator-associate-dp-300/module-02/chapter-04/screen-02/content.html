Learning Objectives
Learn the network and identity controls you need to protect Azure database services.
Learn
Understand
Apply
Master
01
Implement private connectivity
Create Private Endpoints and Private DNS Zones so your database traffic remains on the Microsoft backbone. Verified competency milestone: confirm name resolution returns the private IP from a VM in the VNet.
02
Configure firewall rules correctly
Manage server and database-level IP rules for public endpoints only for controlled scenarios. Verified competency milestone: document which IP ranges are allowed and why.
03
Integrate Azure AD authentication
Set an AAD admin, create AAD users/groups inside the database, and enable centralized access and MFA. Verified competency milestone: sign in with an AAD account to the database.
04
Apply RBAC with least privilege
Assign built-in roles like SQL DB Contributor or create custom roles to limit management scope. Verified competency milestone: grant a user the ability to create databases but not manage VMs.
