Module 2 › Chapter 2.4 › Server-level and Database-level Firewall Rules
Definition
Server and database firewall rules
Allow IP addresses or ranges to access a public-facing database server. Useful for admin or short-lived access.
  • Quick to configure for management access.
  • Brittle for dynamic clients and not identity-aware.
  • Keep least-privilege in mind and prefer private connectivity for production.
Scenario
A DBA needs access from a corporate office with a static IP: create a server-level rule permitting that IP and log access. For production, migrate the app to a VNet and use Private Link instead.
Common Mistake

Leaving firewall rules as the sole protection for a production database exposes it to risks if IPs change or an admin credential is compromised.
