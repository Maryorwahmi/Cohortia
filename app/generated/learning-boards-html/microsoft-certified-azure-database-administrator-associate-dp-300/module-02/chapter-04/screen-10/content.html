Module 2 › Chapter 2.4 › Azure RBAC for Databases
Roles hierarchy
Subscription
Broadest scope; affects all resources.
Resource Group
Group related resources; common assignment point for teams.
Resource
Narrowest scope; assign when you must limit permissions tightly.
Practical example
Assign SQL DB Contributor at the resource group so DB admins can create and manage databases without broader control of networking or storage. For custom needs, create a role with only the exact actions required.
Check your permissions

Sign in as the target user to validate allowed Azure actions and ensure they match operational needs before granting the role widely.
