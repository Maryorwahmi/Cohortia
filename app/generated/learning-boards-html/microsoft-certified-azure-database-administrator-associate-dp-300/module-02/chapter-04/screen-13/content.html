Module 2 › Chapter 2.4 › Key Concepts — Identity & Controls
VNet Service Endpoints
Restrict a service to traffic from specific subnets while the service retains a public endpoint.
Azure AD Authentication
Centralized identities and MFA for database sign-in; requires an AAD admin set on the server.
Azure RBAC
Manage who can administer Azure database resources; assign roles with least privilege.
Final takeaway

Network and identity controls together provide layered protection. Verify DNS, permissions, and monitoring to keep your databases secure over time.
