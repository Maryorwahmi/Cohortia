Module 2 › Chapter 2.4 › Learning Objectives — Practical Checks
Private Link checks
  • Create the Private Endpoint and confirm its state is Approved.
  • Create a Private DNS Zone and link it to the VNet so FQDN resolves privately.
  • Test name resolution from a VM in the VNet; expect the private IP.
Mnemonic
Endpoint, DNS link, Resolve — EDR
AAD & RBAC checks
  • Set an AAD admin on the server and create a test AAD user in the database.
  • Assign RBAC roles at the appropriate scope and verify permissions with a test user.
  • Confirm that RBAC does not grant in-database privileges unless mapped.
Mnemonic
Admin, Assign, Audit — AAA
