Module 2 › Chapter 2.4 › Azure Active Directory Authentication
How it works
Set an AAD admin on the server, create AAD users or groups as database principals, and grant roles. This enables SSO and MFA when supported.
Example SQL
CREATE USER [AAD_USER_OR_GROUP_NAME] FROM EXTERNAL PROVIDER;
Best practices
  • Set an AAD admin before attempting to create AAD users in the database.
  • Manage access through AAD groups rather than individual users when possible.
  • Review sign-in and audit logs to track identity-based access.
Key Takeaway

AAD simplifies identity lifecycle and enables stronger protections like MFA, but you must still map AAD principals to database roles.
