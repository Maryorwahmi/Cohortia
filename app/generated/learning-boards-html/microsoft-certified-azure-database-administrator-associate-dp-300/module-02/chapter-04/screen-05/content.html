Module 2 › Chapter 2.4 › Implementing Private Link
Steps
1
Identify resources
Existing SQL server, target VNet and subnet with free IPs.
2
Create Private DNS Zone
Use the provider standard zone for the service so FQDN resolves privately.
3
Create Private Endpoint
Link the endpoint to the server and subnet, then create the DNS zone group.
4
Verify and remove public access
Test name resolution and connection, then remove public firewall rules as appropriate.
Example verification
From a VM in the app subnet, run a name resolution for the server FQDN. Confirm it returns a private IP from the VNet address space. Then attempt a database connection using that FQDN to ensure traffic flows over the private path.
Why this matters

A missing DNS link is the most common reason Private Link fails; applications keep resolving the public IP and cannot reach the private interface.
