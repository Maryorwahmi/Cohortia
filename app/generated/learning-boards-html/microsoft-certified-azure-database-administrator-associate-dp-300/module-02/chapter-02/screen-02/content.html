Learning Objectives
Master deployment steps, configuration choices, and service differences for Azure SQL.
01
Deploy via Portal and CLI

Execute guided portal steps and scripted CLI commands to create servers and databases. This ensures you can perform both manual verification and automation.

VERIFIED COMPETENCY MILESTONE
02
Configure server and database settings

Select server name, admin credentials, firewall rules, and a service tier such as General Purpose. These choices determine security posture and performance.

VERIFIED COMPETENCY MILESTONE
03
Provision Managed Instance

Create a Managed Instance in a dedicated subnet inside a VNet, choose vCore sizes, and plan for longer deployment times and private access.

VERIFIED COMPETENCY MILESTONE
04
Differentiate services

Understand when to use Azure SQL Database versus Managed Instance by weighing networking, compatibility, and management differences.
