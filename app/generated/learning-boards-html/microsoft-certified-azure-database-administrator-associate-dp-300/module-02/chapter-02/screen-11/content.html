Module 2 › Chapter 2.2 › Post-deployment
Checklist
Operational steps after deployment
  • Set collation and timezone preferences as needed for your data.
  • Enable Azure Defender for SQL and configure auditing and threat detection.
  • Configure geo-replication (Azure SQL Database) for disaster recovery.
  • Restore backups, configure SQL Agent jobs, and set up maintenance tasks (Managed Instance).
  • Connect to Azure Monitor for performance metrics and alerts.
Example
Enable Defender for SQL alerts, then create Azure Monitor alert rules to notify DBAs on elevated CPU or unexpected query patterns.
Key Takeaway

Plan configuration and monitoring as part of deployment to reach production readiness quickly and safely.
