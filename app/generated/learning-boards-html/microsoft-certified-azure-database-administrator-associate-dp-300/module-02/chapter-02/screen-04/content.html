Module 2 › Chapter 2.2 › Logical Server
Definition
What the logical server manages
  • Logins and administrator credentials
  • Server-level firewall rules
  • Auditing and identity settings
Practical example
Name: projectX-sql-7f3a. Admin: sqladmin. Use AAD authentication for apps to avoid shared passwords.
Common Mistake
Weak or reused credentials
Reusing admin passwords or weak strings invites credential theft and lateral access. Prefer AAD and managed identities for automation.
Check your understanding
Does the server name need to be unique?
Yes — logical server name is globally unique and forms the connection FQDN.
When to use AAD?
Use AAD for centralized identity and to avoid password reuse for applications and admins.
