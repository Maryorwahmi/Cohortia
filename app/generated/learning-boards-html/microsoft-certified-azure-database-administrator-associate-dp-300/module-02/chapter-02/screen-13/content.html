Module 2 › Chapter 2.2 › Database vs Managed Instance
Azure SQL Database
  • Single-database PaaS, public endpoint by default
  • Server-level firewall rules to control access
  • Service tiers: General Purpose, Business Critical, Hyperscale
Azure SQL Managed Instance
  • Instance-level PaaS with near 100% SQL Server compatibility
  • Mandatory VNet integration and dedicated subnet
  • Private connectivity and instance-scoped features like SQL Agent
Key Takeaway

Choose Azure SQL Database for cloud-native apps with simpler networking; choose Managed Instance when you need instance compatibility and private VNet integration for migrations.
