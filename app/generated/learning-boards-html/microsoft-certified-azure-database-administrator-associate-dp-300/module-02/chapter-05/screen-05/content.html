Definition Template Structure
Parameters
External inputs such as sqlServerName, sqlAdminLogin, and location. Use types like string or secureString for secrets.
Variables
Computed values to avoid repetition, e.g. concat(parameters('sqlServerName'), '.database.windows.net').
Outputs
Return values for chaining deployments, such as a server FQDN or resourceId.
Resources
Define each Azure resource. Example types include Microsoft.Sql/servers and Microsoft.Sql/servers/databases. Include dependsOn when order matters.
Common mistake: hardcoding environment-specific values instead of parameterizing them.
