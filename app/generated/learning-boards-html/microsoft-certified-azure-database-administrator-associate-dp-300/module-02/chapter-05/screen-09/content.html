Code Walkthrough Deploy via CLI
CLI sequence
# create resource group
az group create --name cohortia-pg-arm-rg --location eastus

# deploy with a parameters file
az deployment group create \
  --resource-group cohortia-pg-arm-rg \
  --template-file postgres-flex-template.json \
  --parameters @postgres-flex-parameters.json

# preview changes with what-if
az deployment group create --resource-group cohortia-pg-arm-rg --template-file postgres-flex-template.json --mode WhatIf --parameters @postgres-flex-parameters.json
Portal
Interactive: upload template and provide parameters for single deployments.
Automation
CLI/PowerShell fit CI/CD and pipelines, where parameters are injected securely.
