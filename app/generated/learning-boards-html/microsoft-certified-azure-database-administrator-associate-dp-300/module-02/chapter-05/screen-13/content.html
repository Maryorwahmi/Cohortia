Hands-on Activity PostgreSQL Template
Template excerpt
{
  "parameters": {
    "pgServerName": { "type": "string" },
    "pgAdminLogin": { "type": "string" },
    "pgAdminPassword": { "type": "secureString" },
    "clientIpAddress": { "type": "string" }
  },
  "resources": [
    { "type": "Microsoft.DBforPostgreSQL/flexibleServers", /* server properties */ },
    { "type": "Microsoft.DBforPostgreSQL/flexibleServers/firewallRules", "dependsOn": [ "[resourceId('Microsoft.DBforPostgreSQL/flexibleServers', parameters('pgServerName'))]" ] }
  ],
  "outputs": { "pgServerFqdn": { "type": "string", "value": "[concat(parameters('pgServerName'), '.postgres.database.azure.com')]" } }
}
Verification steps
  1. Create resource group: az group create --name --location .
  2. Deploy with az deployment group create --template-file postgres-flex-template.json --parameters @postgres-flex-parameters.json.
  3. Confirm outputs for pgServerFqdn and inspect the firewall rule in the Portal.
