Process Flow Parameters vs Variables
Parameters (public)
  • Supplied at deployment time.
  • Use types: string, secureString for passwords.
  • Examples: sqlServerName, location, adminLogin.
Variables (private)
  • Computed inside the template using expressions.
  • Reduce repetition, e.g. serverFqdn = concat(parameters('sqlServerName'), '.database.windows.net').
  • Change once; used across multiple resources.
Example
Parameter: pgServerName; Variable: pgServerFqdn built with concat.
Misconception
Don't place secrets in clear-text parameters; use secureString or Key Vault references.
Takeaway
Parameterize what changes; compute what repeats.
