Architecture Linked Templates
Top-level orchestration
Main template deploys shared resources (VNet, RG) then links to nested templates for databases and application components.
Module example
A database module accepts subnetId and returns an output with the server's resourceId or FQDN for wiring into other modules.
Benefit
Team ownership and reuse of modules.
Design tip
Keep module parameters minimal and well-documented.
Pitfall
Avoid tight coupling by passing full resource objects; prefer IDs and outputs.
