Model comparison
vCore (provisioned)
Granular CPU/memory control; pay for allocated capacity constantly.
vCore (serverless)
Scales compute automatically and can pause when idle to save cost.
DTU
Bundled compute/memory/I/O unit for simplified sizing; less granular control.
Concrete example
A dev database with long idle periods can use serverless to pause compute and save money. A production OLTP service usually uses provisioned vCores for consistent performance.
Checklist for compute selection
  • Measure hourly CPU and I/O usage patterns.
  • Decide if predictable latency or cost savings are the priority.
  • Estimate monthly cost under typical and peak loads for each model.
Misconception
Choosing serverless without analyzing steady-state usage can lead to higher costs and unpredictable latency during scale events.
