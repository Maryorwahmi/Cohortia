Module 2 › Chapter 2.1 › Managed Instance
Architecture snapshot
Managed Instance runs inside your Virtual Network and provides an instance-scoped environment similar to on-premises SQL Server. It supports features that facilitate lift-and-shift migrations and gives near-complete compatibility with on-premises instances.
Use case
Migrate enterprise apps needing SQL Agent or cross-database queries.
Network
Deploy into a VNet subnet and plan IP space and routing carefully.
Migration checklist
  • Inventory feature use on the source instance.
  • Validate compatibility on a test Managed Instance.
  • Plan VNet address space and subnet size before provisioning.
Concrete example
An app with scheduled SQL Agent jobs and many cross-database queries benefits from Managed Instance because those on-premises features are supported.
Common mistake
Assuming Managed Instance eliminates all migration effort; you still must test jobs, logins, and performance under expected load.
