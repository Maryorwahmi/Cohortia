Step-by-step simulation
  1. Define requirements: throughput, storage growth, HA, and network isolation.
  2. In the portal, select SQL databases and start a Create flow to explore 'Configure database' options.
  3. Compare General Purpose vs Business Critical and select compute: provisioned vCores for steady moderate load.
  4. On Networking, choose Private Endpoint, create or pick a VNet and subnet with reserved IPs.
  5. Review estimated cost and consider Hybrid Benefit or reserved capacity for savings.
Scenario note
For the sample app with moderate performance and strict private access, General Purpose with 4 vCores and a Private Endpoint offers a cost-effective, secure configuration to review.
Key takeaway
Simulating the configuration helps reveal cost and network implications before creating resources.
