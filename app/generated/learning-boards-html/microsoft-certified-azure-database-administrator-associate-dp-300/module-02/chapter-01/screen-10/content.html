VNet & subnet planning
Decide IP address ranges, create dedicated subnets for database services and private endpoints, and plan Network Security Groups to restrict traffic to required sources and ports.
Sizing
Reserve address space to allow future instances and private endpoints without renumbering.
Security
Use NSGs and route tables to enforce least-privilege access between subnets.
Concrete example
Create a dedicated subnet for Private Endpoints, reserve an address range large enough for all planned endpoints, and restrict access so only application subnets can reach the database.
Common pitfall
Underestimating IP needs for subnets and endpoints leads to painful reconfiguration later; plan for growth.
Checklist
  • Define VNet address space and subnet sizes.
  • Reserve subnets for DB services and private endpoints.
  • Plan NSGs, peering, and on-prem connectivity impacts.
