Module 2 › Chapter 2.1 › Cost Optimization
Cost levers
Azure Hybrid Benefit
Use existing SQL Server licenses to lower platform costs when eligible.
Reserved instances
Commit to longer terms for predictable workloads to reduce hourly costs.
Compute model choice
Provisioned vCores for steady workloads; serverless for intermittent usage.
Concrete example
A predictable production database benefits from reserved instances and Hybrid Benefit; a dev/test environment benefits from serverless or burstable tiers.
Cost assessment process
  1. Estimate steady-state and peak resource consumption.
  2. Model cost under provisioned, serverless, and DTU assumptions.
  3. Apply license benefits and reserved pricing to predictable workloads.
Misconception
Focusing only on sticker price ignores operational savings from managed services; compare total ownership, not just hourly costs.
