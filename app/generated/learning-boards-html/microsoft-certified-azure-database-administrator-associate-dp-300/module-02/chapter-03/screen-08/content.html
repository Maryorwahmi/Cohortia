Module 2 › Chapter 2.3 › Zone-Redundant HA
What is zone-redundant HA?
A standby replica is provisioned in a different availability zone and a failover is performed automatically if the primary zone becomes unavailable.
When to enable
Enable when your application SLA requires automatic recovery from a zone failure, such as e-commerce, financial, or high-availability services.
Operational notes
  • Enabling HA adds a standby replica and associated cost.
  • Failover is automatic, but you should test failover procedures in a staging environment.
  • HA is not a replacement for point-in-time backups or disaster recovery planning.
Scenario
A retail platform enables zone-redundant HA before the holiday season to ensure availability if a single data center zone has an outage.
Key Takeaway

Enable zone-redundant HA when automatic cross-zone failover is required; continue to maintain backups for data protection.
