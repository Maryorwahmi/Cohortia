Module 2 › Chapter 2.3 › Connecting to Servers
PostgreSQL Example
psql -h mypgserver.privatelink.postgres.database.azure.com -U pgadminuser -d postgres
From a VM within the VNet the FQDN resolves via private DNS.
MySQL Example
mysql -h mymysqlserver.privatelink.mysql.database.azure.com -u mysqladmin -p
Use the mysql client or Workbench from a VM in the same VNet or from a public IP that is whitelisted.
Troubleshooting Checklist
  • Is the server private? If so, are you on a VM in the VNet or using a VPN/jump box?
  • Does the server FQDN resolve from your client? Verify DNS settings.
  • Are firewall rules configured for public access clients?
Key Takeaway

Connection failures most often stem from network placement and DNS, not credentials. Verify network path first.
