Connect, Configure, Validate
Hands-on operations you'll practice
Bloom: Apply → Master
01
Connect Using Clients

Use psql/pgAdmin for PostgreSQL, or mysql/Workbench for MySQL. Practice connecting from a VM in the same VNet when using private access.

Mnemonic: VM → FQDN → Credentials
VERIFIED COMPETENCY MILESTONE
02
Tune Server Parameters

Adjust critical settings like max_connections or innodb_buffer_pool_size through the Server parameters blade or CLI, testing changes first in non-production.

Mnemonic: Test → Apply → Monitor
VERIFIED COMPETENCY MILESTONE
03
Monitor with Azure Monitor

Instrument your servers to capture CPU, storage, and connection metrics and iterate on sizing based on real workload data.

Mnemonic: Monitor → Adjust
VERIFIED COMPETENCY MILESTONE
04
Validate Networking & Access

Confirm access paths: from VM in VNet for private access, or via firewall rules for public access. Use jump boxes or VPN where required.

Mnemonic: Validate → Test → Confirm
VERIFIED COMPETENCY MILESTONE
