Compute Tier Definitions
Burstable
Cost-effective for development and low-traffic services where CPU bursts are infrequent.
General Purpose
Balanced CPU, memory, and network for most production workloads with predictable performance.
Memory Optimized
High-memory machines for in-memory operations, caching, and heavy analytics.
Storage and IOPS Guidance
Storage size impacts available IOPS. Plan for peak writes and read-heavy workloads. Underprovisioning storage often causes later performance and scaling outages.
Example
An analytics reporting service may require Memory Optimized with large storage and high IOPS, while a background job queue can use Burstable with modest storage.
Common Mistake

Choosing minimal storage to save costs, then hitting IOPS limits under real traffic. Always project growth and test under load.
