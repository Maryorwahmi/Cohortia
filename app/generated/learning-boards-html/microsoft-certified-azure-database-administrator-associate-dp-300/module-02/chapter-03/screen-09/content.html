Module 2 › Chapter 2.3 › Admin & Security
Credential Best Practices
Choose a non-generic admin username, generate a strong password, and store it in a secure secret store. Rotate credentials regularly and avoid embedding passwords in scripts.
Private DNS
When deploying with VNet integration, create and link a private DNS zone to resolve the server's FQDN inside the VNet.
Access Patterns
For private servers, use a jump box VM or VPN to access resources in the VNet. For public servers, limit firewall IP rules to only required addresses.
Common Mistake
Expecting immediate access after DNS or firewall changes; always verify from the intended client and allow time for propagation.
Key Takeaway

Design credentials and access methods up front, and use private DNS plus jump boxes for secure private access.
