Module 2 › Chapter 2.3 › Server Parameters
Important Parameters
PostgreSQL
  • max_connections — limit concurrent connections.
  • work_mem — per-operation memory for sorts and joins.
  • shared_buffers — memory for caching database pages.
MySQL
  • innodb_buffer_pool_size — critical for caching InnoDB data and indexes.
Tuning Workflow
  1. Measure current metrics with Azure Monitor under representative load.
  2. Change one parameter at a time in a staging environment.
  3. Observe effects and rollback if instability occurs.
Danger
Applying aggressive parameter changes without testing can cause crashes or degraded performance.
Key Takeaway

Tune iteratively with metrics and staging tests; do not apply sweeping defaults blindly in production.
