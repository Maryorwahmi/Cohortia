Definition
Dynamic Data Masking
Mask column output for non-privileged users without changing stored data.
Mask types include default, email, partial, and random. Grant the UNMASK permission to administrators who must see full values. 
ALTER TABLE Customers
ALTER COLUMN EmailAddress ADD MASKED WITH (FUNCTION = 'email()');

ALTER TABLE Customers
ALTER COLUMN CreditCardNumber ADD MASKED WITH (FUNCTION = 'partial(0,"XXXX-XXXX-XXXX-",4)');
When to use
  • Protect data in support or analyst views.
  • Meet compliance requirements for casual access.
  • Combine with role checks so only specific accounts have UNMASK.
Misconception
Masking is not encryption. It reduces visible exposure but does not make data unreadable to privileged accounts.
Key Takeaway

Use DDM to minimize accidental exposure, and pair it with permissions and encryption where appropriate.
