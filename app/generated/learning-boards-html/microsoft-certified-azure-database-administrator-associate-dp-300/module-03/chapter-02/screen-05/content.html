Comparison
Fixed Roles
Predefined roles simplify administration but can be too broad for application access.
db_owner
Full control — use only for DBAs. Granting this to services risks accidental schema changes.
db_datareader / db_datawriter
Useful for general read or write access but may be too wide for specific table needs.
Comparison
Custom Roles
Tailor permissions at schema and object level to follow least privilege for apps and services.
CREATE ROLE ReportingAppRole;
GRANT SELECT ON SchemaName.TableName1 TO ReportingAppRole;
GRANT SELECT ON SchemaName.TableName2 TO ReportingAppRole;
ALTER ROLE ReportingAppRole ADD MEMBER [ReportingAppUser];
This example grants only SELECT on two tables and then adds the reporting user to the role.
Misconception
Custom roles are time-consuming. In practice, a few targeted roles reduce risk significantly and are straightforward to manage.
Check
If a service only needs to read two tables, prefer a custom role with those SELECT grants instead of db_owner.
