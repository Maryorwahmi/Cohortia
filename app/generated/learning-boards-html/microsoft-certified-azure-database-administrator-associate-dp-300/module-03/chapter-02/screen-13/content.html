Hands-on Activity
Verification checklist
Role Tests
Run allowed and denied operations for each role member and capture results.
RLS Tests
Set session contexts for multiple values and confirm only matching rows return.
DDM Tests
Query masked columns as masked and unmasked accounts; test exports and tools.
Audit Capture
Collect audit logs showing enforcement and include them in verification artifacts.
Remediation
If a test shows unexpected access, document the rollback steps: revoke role, reassign fine-grained grants, and retest.
Key Takeaway

A repeatable verification matrix is the final step to ensure authorization policies are safe for production.
