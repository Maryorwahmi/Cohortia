Learning Objectives
Learn, understand, apply, and begin to master these authorization techniques.
Bloom
Learn → Understand → Apply → Master
01
Apply Principle of Least Privilege
Identify minimal permissions and remove unnecessary rights to reduce risk.
VERIFIED COMPETENCY MILESTONE
02
Manage fixed and custom roles
Use fixed roles for common tasks, custom roles to scope permission to objects the app needs.
VERIFIED COMPETENCY MILESTONE
03
Implement Row-Level Security
Filter rows using session context or user attributes to enforce per-user data visibility.
VERIFIED COMPETENCY MILESTONE
04
Configure Dynamic Data Masking
Hide sensitive column values from non-privileged users without altering the stored data.
VERIFIED COMPETENCY MILESTONE
