CREATE TABLE dbo.EmployeeData (
  EmployeeID INT PRIMARY KEY,
  EmployeeName NVARCHAR(100),
  Department NVARCHAR(50),
  Salary DECIMAL(10, 2),
  Region NVARCHAR(50)
);

Next, create the role and grant SELECT, then add your test user to the role. Finally, implement the security function and policy to filter by Region using SESSION_CONTEXT.
Test steps
  1. Connect as test user and set session region to 'East'.
  2. Run SELECT * FROM dbo.EmployeeData and confirm only East rows appear.
  3. Connect as admin and confirm all rows appear without session context.
Common mistakes
Not setting SCHEMABINDING on the predicate function when required, or failing to set or clear session context in pooled connections.
