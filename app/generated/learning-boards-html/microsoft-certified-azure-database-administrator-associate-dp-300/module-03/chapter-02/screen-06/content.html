Create a Reporting Role
Example sequence to create a custom read role and add a user.
CREATE ROLE ReportingAppRole;
GRANT SELECT ON SchemaName.TableName1 TO ReportingAppRole;
GRANT SELECT ON SchemaName.TableName2 TO ReportingAppRole;
ALTER ROLE ReportingAppRole ADD MEMBER [ReportingAppUser];
Test the role by connecting as ReportingAppUser and trying queries that should fail, like INSERT or SELECT on other tables. Logging and audit traces should show only allowed activity.
Checks
  • Verify SELECT works on the two tables.
  • Attempt disallowed actions to confirm failure.
  • Review role membership and document the purpose.
Misconception
Granting schema-wide rights "just in case" is the same as over-privileging—review before production deploys.
