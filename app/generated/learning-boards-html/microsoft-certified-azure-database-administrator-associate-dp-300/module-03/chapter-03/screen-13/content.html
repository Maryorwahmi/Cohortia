Module 3 › Chapter 3.3 › Practice: Restrict, Enable, and Verify
Step 1
Restrict server-level firewall rules. Remove any broad ranges and add your client IP so you can still connect.
Step 2
Enable Service Endpoint on the subnet and add the corresponding VNet rule to the database server.
Step 3
Verify connectivity from an internal VM and ensure external clients are denied. Optional: create a Private Endpoint and validate DNS resolution.
Checkpoints
  • Subnet shows service endpoint enabled for the correct service.
  • Server VNet rule references the exact subnet resource ID.
  • NSG allows outbound traffic to the database private IP or service endpoint.
