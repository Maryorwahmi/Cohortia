Module 3 › Chapter 3.3 › Troubleshooting Service Endpoint Failures
Step-by-step checks
  1. Verify subnet has the service endpoint enabled for the service name used.
  2. Confirm the VNet rule on the database references the exact subnet resource ID.
  3. Inspect NSGs for outbound blocking of the database port.
  4. Test connectivity from a VM in the subnet to see if routing occurs over the backbone.
Troubleshooting example
If the VM cannot connect, but the subnet shows a VNet rule exists, check whether the subnet's service-endpoints list contains the correct service. If missing, the traffic will not be routed properly even though the server rule exists.
Misconception
A server-side VNet rule alone is sufficient. It is not — the subnet must advertise the endpoint identity.
Pro tip
Automate checks that validate endpoint enablement and NSG rules after deployment to catch misconfigurations early.
