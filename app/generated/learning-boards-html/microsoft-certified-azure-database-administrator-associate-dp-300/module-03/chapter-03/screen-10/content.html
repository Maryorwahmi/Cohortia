Module 3 › Chapter 3.3 › Network Security Layers for Database Access
Layer
Firewall rules
IP allowlists that limit public access; keep them minimal and documented.
Layer
Network Security Groups
Subnet-level controls to restrict ports and outbound destinations for client apps.
Layer
VNet Service Endpoints
Route traffic over Azure backbone and bind subnets as allowed identities on the service.
Production pattern
Remove broad public rules, implement Private Endpoint for the database, configure private DNS, and use NSGs to permit only necessary outbound traffic from client subnets. Keep an emergency admin IP rule that is tightly controlled and audited.
