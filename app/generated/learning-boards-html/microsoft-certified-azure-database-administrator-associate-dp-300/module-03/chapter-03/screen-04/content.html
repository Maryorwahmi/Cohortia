Module 3 › Chapter 3.3 › Firewall Rules for Azure Databases
Definition

Server-level IP allowlists

Server-level firewall rules allow or block traffic based on source IP ranges. They are typically configured in the Azure portal, Azure CLI, or PowerShell and apply across databases on the server.

Notes
  • Use specific start and end IPs to limit access to known clients.
  • Avoid ranges like 0.0.0.0–255.255.255.255 which open public access.
  • Database-level rules exist for SQL but server-level rules are common and simpler to manage.
Concrete example
# Add a rule allowing a single public IP
# Start and end IP are the same to allow a single address
az sql server firewall-rule create --resource-group MyResourceGroup --server MySqlServer --name DevLaptop --start-ip-address 203.0.113.45 --end-ip-address 203.0.113.45
Run from your admin machine. After adding, test connectivity. Remove the rule when no longer needed.
Common mistake

Enabling "Allow Azure services" or adding broad IP ranges without justification. Both increase risk—verify and tighten immediately.

Key Takeaway

Firewall rules are necessary but not sufficient—combine them with VNet controls or Private Endpoints for stronger isolation.
