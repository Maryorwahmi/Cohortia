Module 3 › Chapter 3.3 › Server-level vs Database-level Rules
Comparison
Server-level
  • Applies to all databases on the server.
  • Easier to manage for uniform access.
  • Common for PostgreSQL and MySQL.
Database-level
  • Applies to a single Azure SQL database.
  • Allows per-database exceptions and least privilege.
  • More operational overhead to maintain.
Scenario
A single server hosts production and analytics databases. Use database-level rules to allow analytics team IPs to the analytics database only, keeping production restricted to the app subnet.
Key Takeaway

Choose the level that matches your operational model and enforce rules via automation to prevent drift.
