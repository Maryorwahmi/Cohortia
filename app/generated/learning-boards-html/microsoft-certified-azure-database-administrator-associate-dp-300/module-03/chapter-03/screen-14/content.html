Module 3 › Chapter 3.3 › Key Concepts
Firewall Rules
IP-based allowlists that reduce exposure; use least privilege and avoid broad ranges.
Service Endpoints
Extend subnet identity to services and keep traffic on the Azure backbone; service remains publicly addressable.
Private Endpoints
Project the service into your VNet with a private IP; preferred for production and compliance-sensitive workloads.
Summary takeaway

Start with least-permissive firewalls, add VNet Service Endpoints when you need backbone routing, and prefer Private Endpoints plus DNS and NSGs for production isolation.
