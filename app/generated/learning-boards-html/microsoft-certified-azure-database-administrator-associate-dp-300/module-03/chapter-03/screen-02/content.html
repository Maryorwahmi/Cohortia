Follow the sequence from concept to lab: know the controls, understand how they route traffic, apply steps in your subscription, and verify that access is limited to intended resources.

01
Configure firewall rules

Define server-level IP allowlists for SQL, PostgreSQL, and MySQL and avoid broad ranges. This reduces surface area and allows controlled admin access.

VERIFIED COMPETENCY MILESTONE
02
Integrate with VNets

Enable Service Endpoints on subnets and add VNet rules to restrict database access to those subnets over the Azure backbone.

VERIFIED COMPETENCY MILESTONE
03
Use Private Endpoints

Create a Private Endpoint so the database has a private IP in your VNet, preventing public internet exposure and supporting strict compliance needs.

VERIFIED COMPETENCY MILESTONE
04
Identify misconfigurations

Detect common mistakes such as broad rules, missing service endpoints on the subnet, or DNS not resolving to private IPs, and fix them with targeted steps.
