Module 3 › Chapter 3.3 › CLI Examples and Safe Defaults
Secure CLI pattern
# Remove overly broad rules (example)
az sql server firewall-rule delete --resource-group MyResourceGroup --server MySqlServer --name AllowAll

# Add a single client IP rule
az sql server firewall-rule create --resource-group MyResourceGroup --server MySqlServer --name AdminIP --start-ip-address 203.0.113.45 --end-ip-address 203.0.113.45
After each command, query the current rules and test connectivity from the intended client to ensure the change had the desired effect.
Verification commands
# Show subnet details and endpoints
az network vnet subnet show --resource-group MyResourceGroup --vnet-name MyVNet --name MySubnet

# List server vnet rules
az sql server vnet-rule list --resource-group MyResourceGroup --server MySqlServer
Use these checks in automation to validate the environment matches your security baseline after deployment steps.
