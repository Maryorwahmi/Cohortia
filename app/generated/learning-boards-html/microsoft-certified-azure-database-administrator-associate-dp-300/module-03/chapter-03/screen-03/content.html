Verification checklist
  • Remove broad IP rules; add a specific admin client IP and save.
  • Enable Service Endpoint on the client subnet and add a VNet rule to the server.
  • Create a Private Endpoint and link a private DNS zone so the FQDN resolves privately.
  • From a VM inside the subnet, confirm connection succeeds; from outside, confirm it fails.
Common checks
DNS
Ensure private DNS resolves the database FQDN to the Private Endpoint IP.
NSG rules
Confirm outbound rules allow client apps to reach the database private IP or service endpoint.
