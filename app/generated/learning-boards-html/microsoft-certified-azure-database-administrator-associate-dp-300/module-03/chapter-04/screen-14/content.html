What to Remember › Key Concepts
Transparent Data Encryption
Encrypts database files, logs, and backups at the storage layer.
Always Encrypted
Client-side column encryption that keeps values hidden from the engine.
SSL / TLS
Encrypts network traffic between clients and database servers to prevent eavesdropping.
Summary takeaway
Combine these protections according to your data classification and compliance requirements to cover storage, client, and network threats.
