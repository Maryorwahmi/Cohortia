Verification checklist
  • Run SELECT DB_NAME(database_id), encryption_state FROM sys.dm_database_encryption_keys; to confirm TDE status.
  • In Key Vault, create a key and grant server access; confirm database can use the key as CMK for TDE.
  • Use the SSMS Always Encrypted wizard to create CMK and CEK, then observe encrypted binary values when the client is not configured.
  • Update connection strings to require encryption and confirm session-level TLS is active.
VERIFIED COMPETENCY MILESTONE
Quick examples
Enable TDE via CLI (PostgreSQL)
az postgres flexible-server parameter set \
  --resource-group MyResourceGroup \
  --server-name MyPostgresServer \
  --name azure.enable_data_encryption_at_rest \
  --value ON
SQL verification query
SELECT DB_NAME(database_id) AS DatabaseName, encryption_state
FROM sys.dm_database_encryption_keys;
