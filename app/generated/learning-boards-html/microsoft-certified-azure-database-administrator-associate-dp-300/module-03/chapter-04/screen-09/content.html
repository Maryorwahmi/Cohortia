Process Flow › Always Encrypted Wizard
Wizard steps
  1. Right-click database → Tasks → Encrypt Columns to launch the wizard.
  2. Select the target column (e.g., CreditCardNumber) and choose encryption type.
  3. Create a new Column Encryption Key and a Column Master Key; choose Azure Key Vault as CMK source.
  4. Run the operation or generate an automation script; then verify results in SSMS and from clients.
Verification steps
After encryption, connect without client-side decryption and run a SELECT to see ciphertext. Then connect with an application configured for Always Encrypted and confirm plaintext is available to the application only.
Example choices
Choose deterministic encryption if you require equality joins or lookups. Choose randomized if you prioritize stronger confidentiality and do not need equality comparisons.
Common pitfall
Selecting randomized encryption while the application needs equality searches will break lookups. Test encryption types with your queries first.
