Comparison › Service-managed vs Customer-managed Keys
Service-managed keys
Microsoft manages key creation, rotation, and storage. Minimal configuration and low operational burden.
  • Pros: simplicity, less administration, automatic rotation.
  • Cons: limited control over key lifecycle and audit events.
When to use
Non-regulated workloads or where operational simplicity is a priority.
Customer-managed keys (CMK)
Keys live in Azure Key Vault under your control. You manage rotation, revocation, and access policies for compliance and audits.
  • Pros: full control, auditable access, integration with security processes.
  • Cons: increased responsibility to rotate and maintain key availability.
Implementation notes
Create a Key Vault key, grant the DB server access, then configure TDE to use that key. Test rotation to avoid service disruption.
