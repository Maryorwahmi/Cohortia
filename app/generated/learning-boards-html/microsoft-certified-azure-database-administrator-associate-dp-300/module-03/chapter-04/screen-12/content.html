Comparison › Deterministic vs Randomized
Deterministic
Same plaintext yields same ciphertext, enabling equality comparisons and lookups.
  • Use when application needs exact-match searches.
  • Weaker confidentiality compared to randomized.
Randomized
Stronger confidentiality; same plaintext encrypts differently each time, preventing equality searches.
  • Use when searchability is not required.
  • Preferred for highly sensitive columns where lookups are not needed.
Decision tip

Apply the least permissive encryption type that still supports your application queries and verify performance and correctness after encryption.
