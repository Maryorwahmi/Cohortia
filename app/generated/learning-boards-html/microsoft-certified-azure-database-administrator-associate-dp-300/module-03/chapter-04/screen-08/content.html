Definition › Always Encrypted
Core idea
Clients encrypt and decrypt sensitive column values so the database engine never sees the plaintext.
Components
Column Master Key (CMK) in Key Vault and Column Encryption Key (CEK) used by the client driver.
Concrete example
A client application encrypts a credit card number before INSERT; without client-side decryption, SSMS shows ciphertext for that column.
Limitations

Operations on encrypted columns are limited. Use deterministic encryption for equality searches and randomized for stronger confidentiality without searchability.

Developer note
Client drivers must be configured with access to the CMK for transparent encryption and decryption in applications.
C# snippet (visual)
string connectionString = "Data Source=myserver.database.windows.net;Initial Catalog=mydatabase;Column Encryption Setting=Enabled;";
using (SqlConnection connection = new SqlConnection(connectionString))
{
  connection.Open();
  using (SqlCommand command = new SqlCommand("INSERT INTO Customers (SSN, Name) VALUES (@ssn, @name);", connection))
  {
    command.Parameters.AddWithValue("@ssn", "123-45-678");
    command.Parameters.AddWithValue("@name", "John Doe");
    command.ExecuteNonQuery();
  }
}
