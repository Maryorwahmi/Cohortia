Core Concept › At rest vs In transit
Data at rest
Files, transaction logs, and backups stored on disk or cloud storage.
Transparent Data Encryption (TDE)
Performs real-time I/O encryption and decryption at the storage layer. Transparent to applications.
Concrete example
If a backup file is copied from storage, TDE ensures the file remains encrypted and unreadable without the keys.
Key Takeaway

TDE protects storage-level artifacts but does not limit what privileged DB engine users can see when data is decrypted in memory.

Data in transit
Client-server network traffic between applications and the database.
SSL / TLS
Provides encryption and integrity for network sessions; prevent eavesdropping and tampering.
Concrete example
Adding Encrypt=True to a SQL Server connection string forces the client to negotiate TLS with the server, protecting credentials and queries in transit.
Common mistake

Relying on server defaults without requiring encryption in the client can leave connections vulnerable to downgrade attacks.
