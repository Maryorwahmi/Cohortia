01
Enable TDE across Azure databases
Implement and verify Transparent Data Encryption for Azure SQL, PostgreSQL, and MySQL so storage and backups are encrypted. Verified competency: run the verification query in SSMS or CLI.
VERIFIED COMPETENCY MILESTONE
02
Differentiate service-managed vs customer-managed keys
Understand trade-offs: service-managed for simplicity, CMK in Key Vault for control, rotation, and audit. Verified: configure a CMK and confirm server access to Key Vault.
VERIFIED COMPETENCY MILESTONE
03
Configure Always Encrypted for sensitive columns
Set up CEKs and CMKs, use client drivers or SSMS wizard so DBAs cannot see plaintext. Verified: observe encrypted column values when client-side encryption is not enabled.
VERIFIED COMPETENCY MILESTONE
04
Enforce SSL/TLS for all client connections
Require encryption in connection strings and client configuration to prevent downgrade attacks. Verified: update connection strings and confirm encrypted sessions.
VERIFIED COMPETENCY MILESTONE

Classify data to inform encryption strategy
Use sensitivity labels and classification to prioritize Always Encrypted columns and CMK protection.
VERIFIED COMPETENCY MILESTONE
06
Manage key lifecycle and rotation
Practice rotating CMKs in Key Vault and confirm databases can access rotated keys without service interruption.
VERIFIED COMPETENCY MILESTONE
07
Avoid common mistakes
Check client-side settings, avoid weak key practices, and verify encryption states regularly.
