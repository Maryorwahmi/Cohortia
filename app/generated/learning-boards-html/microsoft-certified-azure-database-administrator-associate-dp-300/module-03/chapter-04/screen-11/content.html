Definition › SSL/TLS Enforcement
SQL Server example
Server=tcp:myserver.database.windows.net,1433;Initial Catalog=mydatabase;Persist Security Info=False;User ID={your_username};Password={your_password};Encrypt=True;TrustServerCertificate=False;Connection Timeout=30;
Encrypt=True forces TLS; TrustServerCertificate=False ensures proper certificate validation.
PostgreSQL example
Host=mypgserver.postgres.database.azure.com;Port=5432;Database=mydatabase;Username=myuser;Password=mypassword;Ssl Mode=Require;
Ssl Mode=Require ensures the client negotiates an encrypted session.
Common mistakes
  • Not including encryption parameters in the client connection string.
  • Setting TrustServerCertificate=True in production, which bypasses certificate validation.
  • Assuming server defaults guarantee client enforcement of TLS.
