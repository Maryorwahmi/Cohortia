Learning Objectives
Skill-based goals and why they matter for secure database access.
01
Differentiate authentication vs authorization
Define identity verification versus permission decisions. This distinction prevents granting excessive rights when an identity is authenticated.
Mnemonic: Identity check vs permission map
VERIFIED COMPETENCY MILESTONE
02
Configure Azure AD authentication
Set an Azure AD admin, create contained users, and use Azure AD features like MFA for stronger authentication across databases.
Mnemonic: Single identity plane
VERIFIED COMPETENCY MILESTONE
03
Implement SQL authentication safely
Create logins with strong policies, enable password expiration, and avoid embedding credentials in code or configuration files.
Mnemonic: Password rules and rotation
VERIFIED COMPETENCY MILESTONE
04
Use Managed Identities for services
Grant a system-assigned or user-assigned identity access to databases to remove secrets and automate credential lifecycle management.
Mnemonic: Identity lives in Azure
