Core Concept
Authentication vs Authorization
Two separate responsibilities in access control. Both are required to grant effective access.
Authentication
Verifies who is connecting. Examples: Azure AD token, SQL username and password.
Authorization
Grants or denies actions within a database. Examples: db_datareader, db_datawriter roles.
Key Takeaway

Authentication without correct database-level authorization can still block access. Configure both to provide usable access.

Concrete example
An Azure AD admin authenticates to the server. To access a user database, create a contained database user and add db_datareader role.
Misconception
Server-level admin implies full database access — incorrect. Database users must still be created and granted proper roles.
Check your understanding
  • Can an authenticated Azure AD user access a user database without a contained user? No.
  • Which feature enables MFA for database access? Azure AD conditional access.
