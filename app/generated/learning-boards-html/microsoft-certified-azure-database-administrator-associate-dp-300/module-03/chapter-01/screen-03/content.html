Hands-on and Security Checks
Confirm configurations and validate authentication events.
Practical checklist
  • Set Azure AD admin for a server and wait for propagation.
  • Connect with Azure AD identity via Azure Data Studio or SSMS.
  • Create a contained database user with FROM EXTERNAL PROVIDER and assign roles.
  • Create SQL logins with CHECK_POLICY and CHECK_EXPIRATION when SQL auth is required.
Verification
Attempt a connection as the new database user and check server audit logs for successful authentication events.
