Process Flow
Set Azure AD admin → Create contained user → Grant roles
1. Set Azure AD admin
In the Azure portal, open the server, choose Active Directory admin, select a user or group, save and wait for propagation.
2. Connect with Azure AD identity
Use Azure Data Studio or SSMS with Azure AD authentication. Authenticate using your organizational account and complete MFA if prompted.
3. Create contained user and assign roles
Run T-SQL to create the user FROM EXTERNAL PROVIDER and then ALTER ROLE to add the user to db_datareader or other roles.
Terminal-style commands
-- Select database
USE MyDatabase;
GO
-- Create contained Azure AD user
CREATE USER [anotheruser@yourdomain.com] FROM EXTERNAL PROVIDER;
GO
-- Grant read and write roles as needed
ALTER ROLE db_datareader ADD MEMBER [anotheruser@yourdomain.com];
ALTER ROLE db_datawriter ADD MEMBER [anotheruser@yourdomain.com];
GO
Verification: attempt to connect to MyDatabase using the target Azure AD account and perform a simple SELECT to confirm read privileges.
Common mistake

Forgetting to create the contained user in the specific database or failing to assign roles is the most frequent cause of unexpected access failures.
