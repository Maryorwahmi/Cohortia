Comparison
SQL Authentication vs Azure AD
SQL Authentication
Server-managed usernames and passwords. Use for legacy clients. Requires secret management.
Azure AD Authentication
Centralized identities, MFA, conditional access, and reduced secret sprawl.
Safe SQL login example
-- Create a secure SQL login with policy enforcement
CREATE LOGIN MySqlLogin WITH PASSWORD = 'StrongPassword123!', CHECK_EXPIRATION = ON, CHECK_POLICY = ON;
GO
CREATE USER MySqlUser FOR LOGIN MySqlLogin;
GO
If CHECK_POLICY or CHECK_EXPIRATION are disabled, you weaken password controls. Avoid turning them off to bypass rotation or complexity.
Pitfall

Hardcoding credentials into application code is a primary source of leaks. Use Key Vault or Managed Identities instead.
