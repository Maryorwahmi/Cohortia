Definition
Managed Identities
Passwordless Azure AD identities assigned to resources to authenticate to other Azure services.
System-assigned
Lifecycle tied to a single resource and deleted with it.
User-assigned
Reusable identity as a standalone resource, assignable to multiple resources.
Practical example
Grant the managed identity a contained database user and add it to db_datareader so an Azure Function can query the database without any secrets in its configuration.
Key Takeaway

Managed Identities remove secret management for Azure resources, but you must still assign minimal database privileges and review access regularly.
