Module 3 › Chapter 3.1 › Key Concepts
Authentication
Verifying identity before access is granted.
Authorization
Determines what an authenticated identity may do within a database.
Azure AD & Managed Identities
Centralized identity and passwordless access reduce secret management and enable stronger protections.
Summary takeaway

Prioritize Azure AD and Managed Identities, enforce password policies for SQL auth, and always apply least privilege and auditing for authentication events.
