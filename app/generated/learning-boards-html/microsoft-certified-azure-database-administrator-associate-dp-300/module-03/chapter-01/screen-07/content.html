Connection Flow
Azure AD authentication with client support
Choose the Azure AD authentication option in SSMS or Azure Data Studio and complete MFA or conditional access as required by the tenant.
Troubleshooting hints
  • Authentication errors often show token acquisition failures—check conditional access and MFA prompts.
  • Permission errors indicate missing database-level authorization—confirm contained user and roles.
  • Use server audit logs to distinguish authentication from authorization failures.
Example connection steps
-- Client: SSMS or Azure Data Studio
-- Server name: mysqldbserver.database.windows.net
-- Authentication: Azure Active Directory - Universal with MFA
-- Username: yourname@yourdomain.com
-- Complete browser-based MFA when prompted, then open a query window against MyDatabase
If a SELECT fails after connection, create a contained user and grant db_datareader to the Azure AD account in that database.
