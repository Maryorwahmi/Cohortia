From query to automated response
Use Log Analytics queries to feed Azure Monitor alerts and attach action groups to automate follow-up.
Typical chain
  1. Route audit events to Log Analytics.
  2. Create a KQL query that captures the condition to alert on.
  3. Make a Log Alert rule and attach an action group.
  4. Action group notifications or automated runbooks respond to incidents.
Scenario
Alert on repeated LOGIN_FAILED events by ClientIP, notify the security team, and trigger a function to add the IP to a block list.
Key Takeaway

Test the full pipeline — query, alert, and action — in a lab so your automation behaves as intended in production.

Common mistake
Creating alerts without testing recipients and automation. Verify alerts trigger and actions succeed in a controlled scenario.
Pro tip
Use action groups with clear escalation paths and include playbook runbooks for repeatable containment steps.
