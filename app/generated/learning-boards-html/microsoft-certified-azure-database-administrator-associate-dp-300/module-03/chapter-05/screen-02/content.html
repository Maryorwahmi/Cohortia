Learning Objectives
Each objective ties a configuration or analysis skill to a measurable outcome.
01
Configure Azure SQL Auditing
Enable auditing to Storage, Event Hub, or Log Analytics and learn why Log Analytics is often preferred for querying and alerting.
VERIFIED COMPETENCY MILESTONE
02
Use Azure Defender for SQL
Enable Defender to run vulnerability assessments and Advanced Threat Protection so you detect threats and get remediation steps.
VERIFIED COMPETENCY MILESTONE
03
Analyze audit data with KQL
Query audit events in Log Analytics and create alerts for unusual patterns like repeated failed logins from the same IP.
VERIFIED COMPETENCY MILESTONE
04
Design a review and response plan
Create a review cadence for audit logs, define incident response steps, and secure logs to prevent tampering.
