Module 4 › Chapter 3.5 › Azure Defender for SQL
Vulnerability Assessment
Continuous scanning that lists misconfigurations and suggests remediation with a baseline for tracking.
What VA finds
  • Excessive permissions or roles.
  • Missing recommended protections.
  • Sensitive data exposures or weak policies.
Advanced Threat Protection
Real-time anomaly detection for SQL injection, brute-force attempts, and unusual access patterns.
Example
ATP might detect a sudden spike in failed logins from a remote IP or an unusual high-volume SELECT that looks like data exfiltration.
Misconception
Thinking Defender replaces patching and least-privilege. It finds issues and anomalies, but teams must remediate and enforce the fixes.
Pro tip
Run initial scans, review findings, implement high-value remediations, and then use baselines to ignore expected deviations while monitoring for new issues.
