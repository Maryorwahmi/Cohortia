Module 4 › Chapter 3.5 › Vulnerability Assessment
1. Scan
Initiate an on-demand vulnerability scan in Defender for SQL and wait for results.
2. Review
Inspect findings, note severity, and map issues to owners who can remediate.
3. Remediate
Apply fixes such as reducing permissions, enabling protections, or hardening configurations.
4. Baseline
Record accepted findings so future scans highlight new or regressed items only.
Example prioritization
Fix credentials and broad schema privileges first, then lower-risk configuration hints second.
Check your understanding
If a scan flags an account with db_owner, what is the immediate remediation step? Reduce privileges to the least required role and re-scan to confirm.
