Lab checklist
Follow these steps in your lab subscription to validate auditing and vulnerability scanning.
1. Configure auditing to Log Analytics
In the Azure portal navigate to your SQL server, Security > Auditing. Turn Auditing On and select Log Analytics workspace as the destination. Save.
2. Generate sample events
Attempt a failed login, sign in successfully, run a SELECT, and optionally CREATE TABLE to produce audit entries.
3. Verify in Log Analytics
Open Logs and run the provided KQL query to confirm events are ingested and fields like ActionName and ClientIP appear.
4. Run Vulnerability Assessment
In Defender for Cloud, configure Vulnerability Assessment and click Scan. Review results, remediate high-impact items, then re-scan to confirm closure.
KQL query reminder
AzureDiagnostics
| where ResourceType == "SQLServers" or ResourceType == "SQLDatabases"
| where Category == "SQLSecurityAuditEvents"
| order by TimeGenerated desc
| project TimeGenerated, ActionName, Succeeded, ClientIP, SessionId, Statement
Checkpoint
Confirm audit events are visible and that a VA scan produced findings you can act on. If not, revisit destinations and permissions.
