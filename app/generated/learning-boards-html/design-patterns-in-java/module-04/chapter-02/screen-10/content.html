Layering streams
FileInputStream → BufferedInputStream → DataInputStream is a classic stack of decorators. Each wrapper adds capability while preserving the stream interface.
Why this helps
  • Compose buffering, conversion, and parsing independently.
  • Avoids changing base stream classes for every new capability.
  • Enables reuse of small, focused wrappers across many contexts.
Analogy
Think of the base stream as raw data and each decorator as a tool that adds a single capability, like a filter in a pipeline.
Key Takeaway

Studying JDK stream wrappers shows how decorators scale in real libraries and why they remain small and composable.
