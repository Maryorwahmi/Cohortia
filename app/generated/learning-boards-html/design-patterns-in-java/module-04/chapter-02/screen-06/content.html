Module 4 › Chapter 4.2 › Abstract Decorator
Structure
The abstract decorator implements the component interface and maintains a reference to a component. It delegates calls to that reference by default so concrete decorators need only add their enhancements.
Example code
<// Abstract Decorator
public abstract class CoffeeDecorator implements Coffee {
  protected Coffee decoratedCoffee;
  public CoffeeDecorator(Coffee decoratedCoffee) { this.decoratedCoffee = decoratedCoffee; }
  @Override public String getDescription() { return decoratedCoffee.getDescription(); }
  @Override public double getCost() { return decoratedCoffee.getCost(); }
}
Design notes
  • Delegation centralizes forwarding logic and reduces duplication.
  • Concrete decorators override only methods they augment.
  • Decorators may be stacked recursively; trace calls to debug order issues.
Pro tip
Pro Tip

Keep decorators focused and stateless when possible. If decorators hold state, document how order affects behavior.
