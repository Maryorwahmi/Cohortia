Client example
<// Client code
public class CoffeeShop {
  public static void main(String[] args) {
    Coffee myCoffee = new SimpleCoffee();
    System.out.println("Order 1: " + myCoffee.getDescription() + " | Cost: $" + myCoffee.getCost());

    // Add Milk
    myCoffee = new MilkDecorator(myCoffee);
    System.out.println("Order 2: " + myCoffee.getDescription() + " | Cost: $" + myCoffee.getCost());

    // Fancy coffee with multiple decorators
    Coffee fancyCoffee = new SimpleCoffee();
    fancyCoffee = new SugarDecorator(fancyCoffee);
    fancyCoffee = new WhippedCreamDecorator(fancyCoffee);
    fancyCoffee = new MilkDecorator(fancyCoffee);
    System.out.println("Order 3: " + fancyCoffee.getDescription() + " | Cost: $" + fancyCoffee.getCost());
  }
}
Notes & checks
  • Declared type is Coffee; runtime object is decorated stack.
  • Order of wrapping affects description order; cost is additive in this example.
  • Wrapping the same reference updates the object in place for that variable.
