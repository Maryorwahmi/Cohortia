Module 4 › Chapter 4.2 › Subclassing Explosion
Definition

Subclassing explosion is the rapid growth of classes when each combination of independent features is modeled as a distinct subclass. It leads to duplication and inflexibility.

Concrete example
If you have three toppings, inheritance could require up to eight classes for all combinations. Maintaining shared behavior across those classes is error-prone and costly.
Analogy
Baking every cake flavor as a separate recipe file instead of layering ingredients before baking.
Common mistake
Using inheritance for independent features because it seems straightforward for the first one or two features.
Quick contrast
Inheritance encodes combinations at compile time. Decorators compose at runtime, so adding a feature is adding a wrapper, not a new leaf in the class tree.
Key takeaway
Key Takeaway

When independent features must combine, prefer composition through decorators to avoid exponential subclassing.
