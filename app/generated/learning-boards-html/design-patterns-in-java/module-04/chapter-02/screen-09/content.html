Decorator vs Inheritance
Decorator composes features at runtime and avoids subclass explosion; inheritance encodes combinations in types and can become unmanageable when features combine independently.
Decorator vs Adapter vs Proxy
  • Decorator: add responsibilities, preserve interface.
  • Adapter: change interface so code can interoperate.
  • Proxy: control access, add surrogates like caching or security.
Examples
Java I/O streams use decorators (BufferedInputStream) to add behavior. An adapter would be used if you needed to present a different API, and a proxy might manage access to a resource.
