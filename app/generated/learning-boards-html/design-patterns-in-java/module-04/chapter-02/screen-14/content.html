Module 4 › Chapter 4.2 › Key Concepts
Decorator Pattern
Add behavior to objects dynamically while preserving their interface.
Component
Interface implemented by both components and decorators for interchangeability.
Concrete Component
The base object receiving decorators, e.g., SimpleCoffee.
Summary Takeaway

Use decorators to compose behavior at runtime and avoid subclass combinatorics; keep decorators focused and preserve the component contract.
