Module 4 › Chapter 4.1 › Class vs Object Adapter
Class Adapter
Uses inheritance to adapt an adaptee to the target. Requires the adapter to extend the adaptee and implement the target.
Pros
Can directly override adaptee behavior and reuse protected members.
Cons
Java’s single inheritance limits use. Increases coupling to a concrete adaptee class.
Object Adapter
Adapter implements the target and holds a reference to the adaptee instance, delegating translated calls.
Pros
Flexible, supports any adaptee instance, favors composition over inheritance.
Cons
Requires explicit delegation code; translation logic must be implemented carefully.
Practical verdict
In Java prefer object adapters for maintainability and testability. Choose class adapter only when the language and the domain favor inheritance and you control the adaptee.
