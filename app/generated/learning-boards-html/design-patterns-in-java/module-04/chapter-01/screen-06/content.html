Module 4 › Chapter 4.1 › Target & Adaptee
Target: Shape
// Target interface expected by the new graphics library
public interface Shape {
  void draw(Graphics g);
}
Note: The target accepts a Graphics context. The adapter must accept this contract and decide how to use or ignore the Graphics value when delegating.
Adaptee: LegacyRectangle
// Adaptee: The legacy class with an incompatible interface
public class LegacyRectangle {
  public void draw(int x, int y, int width, int height) {
    System.out.println("Drawing LegacyRectangle at (" + x + "," + y + ") with width " + width + ", height " + height);
  }
}
Note: This method takes explicit coordinates and dimensions. The adapter will compute width and height from coordinate pairs when given two points.
Checklist before adapting
  • Confirm parameter units and expected ranges.
  • Decide what to do with the Graphics context: use it, pass it along, or ignore it after logging.
  • Plan validation for negative widths or inverted coordinates.
