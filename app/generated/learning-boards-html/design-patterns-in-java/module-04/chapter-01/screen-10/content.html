IO adapters
InputStreamReader adapts a byte stream to a character reader by translating bytes using a character set. This is a classic object adapter translating low-level bytes into higher-level characters.
Collection adaptation
Collections.list(Enumeration) adapts an older Enumeration to a modern List by iterating and copying elements into an ArrayList, providing a List that client code expects.
Design lesson
These examples show adapters preserving semantics while exposing modern interfaces. When designing your own adapters, mirror this approach: make conversions explicit and testable, and prefer composition to keep components decoupled.
