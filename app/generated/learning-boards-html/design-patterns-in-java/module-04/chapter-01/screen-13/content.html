Question 1
Which pattern to use when a payment gateway accepts double and currency code, but your app uses BigDecimal and Currency? What must the adapter convert?
Answer outline: Use Adapter. Convert BigDecimal to double carefully, handle rounding, and convert Currency to currencyCode string. Add tests for precision and mapping.
Question 2
Explain how Collections.list(Enumeration) is an adapter.
Answer outline: Collections.list iterates the Enumeration (adaptee) and builds a List (target), translating iteration semantics into a modern collection; test that order and elements match.
