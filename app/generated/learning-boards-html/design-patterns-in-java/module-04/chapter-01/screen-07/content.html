Adapter code (object adapter)
// Adapter: Implements the Target interface and contains an instance of the Adaptee
public class RectangleAdapter implements Shape {
  private LegacyRectangle legacyRectangle;
  private int x1, y1, x2, y2; // Store coordinates for the legacy rectangle

  public RectangleAdapter(LegacyRectangle legacyRectangle, int x1, int y1, int x2, int y2) {
    this.legacyRectangle = legacyRectangle;
    this.x1 = x1;
    this.y1 = y1;
    this.x2 = x2;
    this.y2 = y2;
  }

  @Override
  public void draw(Graphics g) {
    // Translate the new interface's call to the old interface's call
    int width = x2 - x1;
    int height = y2 - y1;
    // Normalize to prevent negative dimensions
    if (width < 0) { width = -width; }
    if (height < 0) { height = -height; }
    legacyRectangle.draw(x1, y1, width, height);
    System.out.println("Adapter: Translated draw call for new Graphics context.");
  }
}
This implementation uses composition, computes dimensions, and forwards the call. In production add explicit validation and tests for coordinate ordering and edge cases.
Example notes
The Graphics parameter is unused here for simplicity. In real GUI code you may apply Graphics for styling while still delegating geometry to the adaptee.
Common mistake
Failing to normalize coordinates leads to negative width or height and unexpected behavior in the adaptee.
Key Takeaway

Compose the adaptee, implement the target, convert parameters carefully, and add tests for translation boundaries.
