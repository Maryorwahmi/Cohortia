Module 4 › Chapter 4.1 › Intro

Bridge incompatible components without changing them

Use the Adapter pattern to translate one interface into another, keeping existing code intact and enabling reuse.

In this lesson

Why adapters exist, class vs. object adapters in Java, a full object-adapter code walkthrough, and hands-on exercises to practice safe translation logic.

Why it matters

Adapters let you integrate legacy libraries and third-party APIs without invasive changes, preserving stability while enabling new features.

Concept strip
Adapter
Implements the target and translates calls to the adaptee.
Adaptee
Existing class with an incompatible interface you cannot change.
Target
The interface client code expects to use.
Quick analogy
Universal travel adapter
It translates the plug so the device and socket cooperate without changing either side.
Visual overview
T
Target: Shape
Client expects draw(Graphics g)
A
Adaptee: LegacyRectangle
Provides draw(x,y,width,height)
The adapter implements Shape and forwards translated calls to LegacyRectangle.
