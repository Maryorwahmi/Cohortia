Module 4 › Chapter 4.1 › What is Adapter?
Definition and roles

Target: Interface clients expect.

Adaptee: Existing class with incompatible API you cannot change.

Adapter: Implements target and translates requests to the adaptee.

Analogy
A travel adapter translates plug shapes so devices and sockets cooperate without modifying either side.
Misconception
Adapters should not change core behavior. They only map interfaces. If you need to alter semantics, consider other patterns or refactoring.
Key Takeaway

Adapter provides a translator between incompatible interfaces while preserving the adaptee’s behavior.

Comparison: Adapter vs Facade
Adapter
Translates one interface to another so an existing component can be used by client code.
Facade
Provides a simpler unified interface over multiple subsystems; not primarily a translation layer.
Concrete example
A LegacyRectangle provides draw(x,y,width,height). A Shape expects draw(Graphics). The adapter computes width and height from coordinates and forwards the call, making LegacyRectangle usable in new drawing code without modification.
