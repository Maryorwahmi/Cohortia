Decision checklist
  • Is changing either interface impractical or risky? If yes, consider an adapter.
  • Are the differences primarily about method signatures or data formats? Adapters can translate those cleanly.
  • If small differences exist, could a helper method suffice instead of a full adapter?
  • Will the adapter create brittle assumptions about formats or coordinate systems? If so, add tests and validation.
VERIFIED COMPETENCY MILESTONE
Implementation checklist
  • Implement the target interface on the adapter class.
  • Hold an adaptee instance for composition and delegate translated calls.
  • Document parameter conversions and edge cases.
  • Add unit tests for translation logic and error handling.
