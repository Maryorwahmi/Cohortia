Module 4 › Chapter 4.1 › Mistakes & Safety
Common mistake
Using adapters as shortcuts for code that should be refactored. This can create hidden layers that are costly to maintain.
Input errors
Not normalizing coordinates or not validating units leads to incorrect delegation and runtime errors.
Hidden semantics
Adapters may hide side effects or performance characteristics. Document and test these behaviors explicitly.
Best practices
  • Favor composition over inheritance in Java.
  • Normalize and validate all converted values; add defensive checks.
  • Write unit tests that assert both interface conformance and correct parameter translation.
  • Document any assumptions and conversion rules clearly in code comments and design notes.
