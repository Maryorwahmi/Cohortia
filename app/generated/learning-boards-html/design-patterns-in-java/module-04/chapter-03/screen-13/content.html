Detecting a God object
A facade becomes a God object when it gathers many unrelated methods, growing in responsibility and coupling.
Symptoms
  • Facade has many methods spanning distinct domains.
  • Tests for the facade become large and complex.
  • Clients rarely use more than a small set of methods together.
Remedies
  • Split by domain: playback facade, radio facade, settings facade.
  • Keep the facade surface small and well-documented.
  • Offer direct component access for advanced operations.
Key Takeaway

Prefer multiple focused facades over one large facade to preserve clarity and maintainability.
