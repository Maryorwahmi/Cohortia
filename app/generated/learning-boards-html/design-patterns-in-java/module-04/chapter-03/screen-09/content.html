Module 4 › Chapter 4.3 › Benefits vs Drawbacks
Benefits
  • Simplifies common operations into single method calls.
  • Reduces client coupling to subsystem internals.
  • Makes APIs easier to document and learn.
Key Takeaway

Use facades to streamline frequent or complex sequences so clients can do more with less code.

Drawbacks & Mitigations
  • Risk: God object. Mitigation: split into multiple focused facades.
  • Risk: Hiding needed features. Mitigation: allow direct access to components when necessary.
  • Risk: Extra indirection. Mitigation: measure critical paths and avoid unnecessary delegation.
Pro tip

Document facade responsibilities and list operations intentionally omitted so advanced clients know where to go.
