Client code example
public class HomeTheaterClient {
  public static void main(String[] args) {
    Amplifier amp = new Amplifier();
    DvdPlayer dvd = new DvdPlayer();
    Tuner tuner = new Tuner();
    Projector projector = new Projector();
    Lights lights = new Lights();

    HomeTheaterFacade homeTheater = new HomeTheaterFacade(amp, tuner, dvd, projector, lights);

    homeTheater.watchMovie("The Matrix");
    homeTheater.endMovie();

    homeTheater.listenToRadio(102.7);
    homeTheater.endRadio();
  }
}
The client code focuses on high-level actions. If the application required direct control, the components remain available for specialized use.
Practical considerations
  • Constructor injection facilitates testing and inversion of control.
  • Facade should document which operations are simplified and which are not covered.
  • When multiple facades are needed, keep each focused on a cohesive concern.
Key Takeaway

A facade gives clients fewer decisions to make, improving readability and reducing errors.
