Facade Design Checklist
  1. Find repeated client sequences to encapsulate.
  2. Prefer injection of components for testability and lifecycle control.
  3. Keep methods focused and cohesive.
  4. Document lifecycle and error semantics clearly.
  5. Provide access to underlying components for advanced use when needed.
  6. Write tests and review responsibilities periodically.
Key Takeaway

Use the checklist before adding a facade to ensure it simplifies rather than centralizes complexity.
