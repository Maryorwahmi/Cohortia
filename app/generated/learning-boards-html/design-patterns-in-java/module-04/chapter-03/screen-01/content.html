The Facade Pattern
Simplify client code by providing a single entry point to a subsystem of many classes.
Orientation

You will see a concrete Java example that composes subsystem objects, a runtime demonstration of calling watchMovie and endMovie, and guidance to avoid common anti-patterns. This chapter focuses on composition-based facades that orchestrate but do not subsume subsystem responsibilities.

Use Case
Make a multi-step operation available as a single method call, like watchMovie.
Benefit
Reduces coupling and hides sequence complexity from clients.
