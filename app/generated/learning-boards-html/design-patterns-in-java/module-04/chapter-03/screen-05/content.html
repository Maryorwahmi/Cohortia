Facade — concise definition
A Facade provides a unified, higher-level interface to a subsystem, composed of many interacting classes.
How it works
  • Facade holds references to subsystem objects via composition.
  • Facade methods implement common sequences by delegating calls to those objects.
  • Clients call facade methods instead of multiple subsystem operations.
Key Takeaway

Use facades to present simple operations that map to multi-step subsystem workflows.

Concrete metaphor
A facade is like a remote: you press play and many devices change state correctly, you don’t flip switches on each device.
Misconception
A facade is not a replacement for the subsystem. Keep components testable and accessible for advanced use.
Check your understanding
