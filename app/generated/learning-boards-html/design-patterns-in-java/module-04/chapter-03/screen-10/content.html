Module 4 › Chapter 4.3 › Lifecycle & Errors
Lifecycle choices
  • Injection: Caller controls creation and teardown; facade focuses on orchestration.
  • Internal construction: Facade creates components and owns lifecycle; easier to use but harder to test.
  • Hybrid: provide constructors for both modes to support flexibility.
Design tip

Prefer injection for testability; if the facade constructs objects, allow overriding for testing.

Error handling
  • Wrap subsystem exceptions into facade-level exceptions to simplify client contracts.
  • Preserve the original cause to aid diagnostics.
  • Document which exceptions are thrown and which are suppressed or logged.
Key Takeaway

Make lifecycle and error policies explicit in the facade contract so clients know where responsibility lies.
