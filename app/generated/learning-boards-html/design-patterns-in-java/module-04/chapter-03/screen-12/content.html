Assessment: transferFunds
Design a facade method that encapsulates the common funds transfer workflow for API users of a legacy banking subsystem.
Subsystems involved
  • AccountManager: checks and updates balances.
  • TransactionService: creates transaction records.
  • SecurityValidator: validates user and operation permissions.
  • LedgerUpdater: writes ledger entries for auditing.
Facade responsibilities
  • Validate user and accounts.
  • Check funds and create transaction atomically.
  • Update balances and ledgers; ensure rollback on failure or provide compensation.
Design reminder

Keep the facade focused on transfer flow. If other unrelated banking features accumulate, create separate facades to preserve cohesion and maintainability.
