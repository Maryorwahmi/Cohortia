ImageProxy — lazy initialization
The proxy holds the filename and a reference to RealImage, creating it on first use.
// Proxy: Controls access and provides lazy loading
public class ImageProxy implements Image {
  private String filename;
  private RealImage realImage; // Reference to the real subject

  public ImageProxy(String filename) {
    this.filename = filename;
  }

  @Override
  public void display() {
    if (realImage == null) {
      // Lazy initialization
      realImage = new RealImage(filename);
    }
    realImage.display(); // Delegate to the real subject
  }
}
Safety note
Consider synchronization for multithreaded environments and ensure exceptions from RealImage surface to callers.
Example scenario
A gallery app creates proxies for each image at startup; thumbnails show immediately while full images load when viewed.
Key Takeaway

A virtual proxy delays expensive work until necessary; verify thread-safety and exception semantics in your implementation.
