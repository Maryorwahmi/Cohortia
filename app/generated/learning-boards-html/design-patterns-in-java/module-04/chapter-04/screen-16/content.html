Remote Proxy
Local representative for a remote object; hides marshalling and network details.
Smart Reference
Performs bookkeeping on access, such as counting references or locking for concurrency control.
Implementation Checklist
Define Subject, preserve semantics, handle concurrency, test first and repeat access, and secure denial responses.
Final Thought

A well-designed proxy gives you control without forcing clients to change. Use it deliberately and test thoroughly.
