The Proxy Pattern
A surrogate that controls access, creation, or representation of a real object.
Virtual
Defer creation of expensive objects until needed.
Protection
Enforce permission checks before delegating.
Remote
Represent objects in a different address space.
When to use

You need control over access or expensive creation, or you must represent a remote resource without changing client code.

Common mistake

Using a proxy where a simple direct call or wrapper suffices adds unnecessary indirection and maintenance cost.
