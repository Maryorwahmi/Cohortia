Client: ImageViewer
Create proxies early, trigger real loads only on display.
// Client code
public class ImageViewer {
  public static void main(String[] args) {
    System.out.println("Application starting...");

    Image image1 = new ImageProxy("photo1.jpg");
    Image image2 = new ImageProxy("report_chart.png");

    System.out.println("Proxies created. Real images not loaded until display is called.");

    System.out.println("
--- Displaying image1 ---");
    image1.display(); // Loads photo1.jpg

    System.out.println("
--- Displaying image1 again ---");
    image1.display(); // Just displays photo1.jpg

    System.out.println("
--- Displaying image2 ---");
    image2.display(); // Loads report_chart.png
  }
}

Reflection
If you see loading messages only at first display, the proxy is behaving as intended. If loading occurs at proxy creation, the proxy is not lazy.
