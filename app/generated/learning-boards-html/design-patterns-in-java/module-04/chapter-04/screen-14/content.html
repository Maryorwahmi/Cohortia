Assessment ideas
Scenario questions and code verification tasks.
Scenario question
Loading high-resolution profile pictures lazily: which proxy type and why? (Expected: Virtual Proxy.)
Code task
Implement a ProtectionProxy that enforces a simple role check and lazily creates the real service when authorized.
Grading checklist
  • Preserves Subject interface and observable behavior.
  • Lazy initialization occurs only when needed.
  • Authorization paths do not construct the real service for denied users.
  • Exception and concurrency handling documented or tested.
