Module 5 › Chapter 4.4 › Proxy vs Decorator
Compare intent, not form
Both wrap, but answer different design questions.
Decorator
  • Adds responsibilities or features.
  • Focus: what the object can do.
  • Example: add encryption or logging to output.
Proxy
  • Controls access, timing, or representation.
  • Focus: when and how the object is accessed.
  • Example: lazy loading, authorization checks, remote access.
Mislabel Check
If the wrapper changes semantics or timing, ask whether access control or feature addition is the primary intent before naming the pattern.
