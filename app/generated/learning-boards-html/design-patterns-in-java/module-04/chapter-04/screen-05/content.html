Module 5 › Chapter 4.4 › Proxy Structure
Roles
Each role has distinct responsibilities that keep clients decoupled from implementation details.
Subject
Defines the methods both proxy and real subject expose. Clients compile to this type.
Real Subject
Performs actual work and may be expensive to create or located remotely.
Proxy
Implements Subject, holds reference to Real Subject, and applies control logic before delegating.
Pro Tip
Keep the proxy’s public surface identical to the subject and avoid leaking proxy-specific methods to clients.
UML-style cards
Subject
interface Image { void display(); }
Real Subject
RealImage implements heavy loading and display behavior.
Proxy
ImageProxy implements the same interface and controls when RealImage is created and used.
Check your understanding

Can a proxy change return values? No — it should preserve observable behavior; only control logic and timing should differ.
