Module 5 › Chapter 4.4 › Remote & Smart Reference
Remote Proxy
Represents an object in a different address space. It marshals calls and handles network errors so the client can use the remote service transparently.
Consideration
Network failures and latency are now part of the proxy’s responsibilities. Ensure robust error handling and retries where appropriate.
Smart Reference Proxy
Performs additional work on access: counting references, locking, or loading related state when the real subject is accessed.
Example
Increment a usage counter each time display is called to support eviction policies.
Misuse warning
Avoid placing heavy business logic in smart references that alters semantics. The proxy should augment access, not change the core contract.
