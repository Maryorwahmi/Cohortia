Module 5 › Chapter 4.4 › Key Concepts
Proxy Pattern
A surrogate that controls access to a real object while preserving its interface.
Virtual Proxy
Defers creation of expensive objects until first use.
Protection Proxy
Enforces access control before delegating to the real subject.
Summary Takeaway

Use proxies to manage access or expensive creation, preserve the Subject interface, and keep error and concurrency semantics consistent with the real subject.
