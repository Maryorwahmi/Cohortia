Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Master
01
Define the Proxy pattern
Explain proxy as a surrogate implementing the same interface to control access or defer creation. This matters because it preserves client code while adding control logic.
Mnemonic: Mirror interface
VERIFIED COMPETENCY MILESTONE
02
Distinguish proxy types
Identify virtual, protection, remote, and smart-reference proxies by intent and example, so you can choose the right variant.
Mnemonic: VPR-S (Virtual, Protection, Remote, Smart)
VERIFIED COMPETENCY MILESTONE
03
Implement proxies in Java
Write a virtual proxy for lazy init and a protection proxy for authorization checks, using a common Subject interface.
Mnemonic: Interface first
VERIFIED COMPETENCY MILESTONE
04
Choose when to use a proxy
Recognize scenarios where a proxy reduces cost or increases safety versus when it adds needless indirection or performance overhead.
Mnemonic: Cost vs Control
