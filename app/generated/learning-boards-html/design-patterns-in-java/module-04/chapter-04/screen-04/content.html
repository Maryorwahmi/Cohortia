Module 5 › Chapter 4.4 › What is a Proxy?
Proxy explained
A surrogate that controls access, timing, or representation while preserving the Subject interface.
Key claim
The proxy and real subject implement the same interface so the client is unaware of the substitution.
Metaphor
A receptionist screens and forwards requests for an executive, adding control and delay when needed.
Misconception
Proxy is not a Decorator. Decorator adds features; Proxy manages when and whether a feature is reached.
Key Takeaway

Use a proxy when you need to control access, defer creation, or represent a remote resource while keeping client interactions unchanged.

Concrete example
Virtual proxy for large images.
// Subject interface
public interface Image {
  void display();
}

// RealSubject: expensive to create
public class RealImage implements Image {
  private String filename;

  public RealImage(String filename) {
    this.filename = filename;
    loadImageFromDisk();
  }

  private void loadImageFromDisk() {
    System.out.println("Loading " + filename + " from disk...");
    try { Thread.sleep(2000); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    System.out.println(filename + " loaded.");
  }

  public void display() {
    System.out.println("Displaying " + filename);
  }
}
