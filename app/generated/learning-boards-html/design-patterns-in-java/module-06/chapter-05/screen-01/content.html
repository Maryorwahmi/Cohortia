Visual concept
Context
Holds a Strategy reference and delegates execution. It does not implement algorithms itself.
Strategy Family
An interface with one or more methods. Concrete strategies implement algorithm variants.
Topics
Interchangeable algorithms
Swap behaviors at runtime without touching the context.
Java implementation
Context holds a Strategy interface and concrete classes implement it.
When not to use it
Prefer simple parameters or factory methods when variations are tiny.
Key Takeaway

Strategy separates what varies: algorithms live in their own classes and the context simply delegates.
