Module 6 › Chapter 6.5 › What is Strategy?
Pattern claim
The context delegates algorithm execution to a Strategy interface implemented by concrete classes.
Analogy
Think of a sorting toolbox: you pick quicksort, mergesort, or bubble sort as needed rather than reworking the caller each time.
When it shines
When a family of related algorithms exists and you need runtime flexibility or easier testing.
Misconception
Not always necessary for a single algorithm or tiny variations; it can add class overhead.
Definition cards
Context
Uses a Strategy reference and delegates algorithm execution to it. Does not implement the algorithm itself.
Strategy
An interface or abstract class declaring the method(s) the context calls.
Concrete Strategy
A class that implements the Strategy interface and provides a single algorithm variant.
Key Takeaway

Strategy moves algorithm code out of the context and into focused classes that are easy to extend and test.
