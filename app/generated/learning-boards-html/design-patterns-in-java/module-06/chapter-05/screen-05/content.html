Module 6 › Chapter 6.5 › Components
Architecture overview
A simple interaction: Context holds Strategy, Context calls Strategy method, ConcreteStrategy performs algorithm.
Strategy (interface)
Declare the contract for all algorithms. Example method: applyDiscount(double originalPrice).
Concrete Strategies
Implement the contract with different behaviors: percentage, fixed amount, or none.
Context
Keeps a reference to Strategy and delegates the operation. Provide setter to change strategies at runtime.
Implementation tip
Prefer constructor injection with a sensible default strategy and a setter for runtime changes. Avoid instanceof checks in the Context.
Concrete examples
NoDiscountStrategy
Returns the original price unchanged. Useful as a default behavior.
PercentageDiscountStrategy
Reduces price by a percentage. Keep calculation inside this class so tests focus on the formula only.
FixedAmountDiscountStrategy
Subtracts a fixed amount and ensures price does not go below zero.
Key Takeaway

Design each strategy to implement one clear algorithm so the Context remains simple and extensible.
