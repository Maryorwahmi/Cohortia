// 1. Strategy Interface
interface DiscountStrategy {
  double applyDiscount(double originalPrice);
}

// 2. Concrete Strategy: No Discount
class NoDiscountStrategy implements DiscountStrategy {
  @Override
  public double applyDiscount(double originalPrice) {
    System.out.println("Applying no discount.");
    return originalPrice;
  }
}

// 2. Concrete Strategy: Percentage Discount
class PercentageDiscountStrategy implements DiscountStrategy {
  private double percentage; // e.g., 0.10 for 10%

  public PercentageDiscountStrategy(double percentage) {
    this.percentage = percentage;
  }

  @Override
  public double applyDiscount(double originalPrice) {
    System.out.println("Applying " + (percentage * 100) + "% discount.");
    return originalPrice * (1 - percentage);
  }
}

// 2. Concrete Strategy: Fixed Amount Discount
class FixedAmountDiscountStrategy implements DiscountStrategy {
  private double fixedAmount;

  public FixedAmountDiscountStrategy(double fixedAmount) {
    this.fixedAmount = fixedAmount;
  }

  @Override
  public double applyDiscount(double originalPrice) {
    System.out.println("Applying fixed amount discount of $" + fixedAmount);
    return Math.max(0, originalPrice - fixedAmount);
  }
}

// 3. Context Class
class ShoppingCart {
  private DiscountStrategy discountStrategy;
  private double totalPrice;

  public ShoppingCart(double initialPrice) {
    this.totalPrice = initialPrice;
    this.discountStrategy = new NoDiscountStrategy();
  }

  public void setDiscountStrategy(DiscountStrategy discountStrategy) {
    this.discountStrategy = discountStrategy;
    System.out.println("Discount strategy set to: " + discountStrategy.getClass().getSimpleName());
  }

  public double calculateFinalPrice() {
    return discountStrategy.applyDiscount(totalPrice);
  }

  public void setTotalPrice(double totalPrice) { this.totalPrice = totalPrice; }
}
Example scenario
Create a ShoppingCart, set a PercentageDiscountStrategy, observe the reduced total, then switch to a FixedAmountDiscountStrategy without changing ShoppingCart code.
Explanation & guidance
  • Keep applyDiscount implementation details inside each strategy class.
  • Use a default strategy to avoid null checks in the Context.
  • Change strategies at runtime via a setter when client-driven selection is required.

Key Takeaway

The code shows how a small Context delegates large algorithm variations to focused Strategy classes that are easy to extend and test.
