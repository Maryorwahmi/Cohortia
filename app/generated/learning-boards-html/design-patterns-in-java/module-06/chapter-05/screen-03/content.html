Module 6 › Chapter 6.5 › Practice Objectives
Apply in code
Implement interfaces and concrete classes for each algorithm, and wire them into a Context that delegates execution.
Mnemonic: Interface → Strategies → Context
Milestone: ShoppingCart with three discount strategies
Verify & test
Write unit tests for each strategy class to validate algorithm correctness independent of the Context.
Mnemonic: isolate algorithms for tests
Milestone: tests pass for each discount calculation
When not to use Strategy
If you have only one algorithm or tiny variations, a method parameter or factory is simpler and lighter.
Caution: avoid premature abstraction
Milestone: justify extra classes
Contrast with State
Strategy chooses algorithm by client; State changes behavior based on an object's internal state and may manage transitions itself.
Mnemonic: Strategy = what; State = how
Milestone: explain the difference with an example
