GameCharacter: what to implement

Follow the starter code: Inventory, CharacterMemento, GameCharacter, GameHistory. Ensure constructor scoping and defensive copying.
// CharacterMemento (concept)
class CharacterMemento {
  private final int health;
  private final Inventory inventory; // snapshot deep copy

  CharacterMemento(int health, Inventory inventory) {
    this.health = health;
    this.inventory = new Inventory(inventory.getItems());
  }

  int getHealth() { return health; }
  Inventory getInventory() { return new Inventory(inventory.getItems()); }
}
Steps & checks
  1. Create Inventory with a copy constructor and safe getters.
  2. Make CharacterMemento fields final and deep copy in constructor.
  3. Implement GameCharacter.saveState() and restoreState(memento).
  4. Use GameHistory to add and retrieve mementos by index or stack pop.
  5. Test: pick up items, save, change state, then restore and verify console output.
Common mistake

Returning internal references or failing to deep copy leads to shared mutable state between current object and saved snapshots.

Pro tip

Use defensive copying consistently for every mutable field, including lists and nested objects.
