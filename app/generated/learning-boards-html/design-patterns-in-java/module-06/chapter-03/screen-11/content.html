Undo/Redo
Editors save document snapshots and use a history stack for undo. Mementos encapsulate document state.
Checkpoints
Periodic snapshots for fault recovery or long-running operations; consider persistence to disk.
Game saves
Save player stats, positions, and inventories as mementos; use deltas to reduce memory between saves.
When designing, classify state size and mutability. For large or frequently changing state, prefer hybrid approaches: periodic persistent mementos plus transient in-memory deltas. For small, infrequent changes, full in-memory snapshots are often simplest and sufficient.
