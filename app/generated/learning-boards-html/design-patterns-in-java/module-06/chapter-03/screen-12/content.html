Assessment Idea

Design exercise

Implement a DrawingCanvas originator, a DrawingMemento that deep copies a List<Shape>, and a HistoryManager caretaker. Write tests covering save and restore scenarios and snapshot isolation.
Checklist
  • Only Originator can access wide memento interface.
  • Saved mementos remain unchanged after Originator mutates.
  • Mutable fields are deep-copied inside memento.
  • History limits or persistence behave correctly under load.
