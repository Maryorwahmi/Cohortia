Learning Objectives

Learn to design and implement safe state snapshots, and make trade-offs for production systems.

01
Explain the Memento purpose

Describe how snapshots let an object save and restore internal state while preserving encapsulation. This matters for undo and checkpoints.

Venn: privacy ∩ snapshot
VERIFIED COMPETENCY MILESTONE
02
Implement the three roles

Create Originator, Memento, and Caretaker in Java, using inner classes or package scope so only the Originator accesses saved state.

Mnemonic: O → M → C
VERIFIED COMPETENCY MILESTONE
03
Choose appropriate scenarios

Recognize undo/redo, checkpointing, and game saves as primary use cases where mementos bring value without breaking design.

Timeline: action → save → restore
VERIFIED COMPETENCY MILESTONE
04
Manage trade-offs

Assess memory cost and choose strategies like limiting history, diffs, or persistence when full snapshots are expensive.

Checklist: memory, immutability, scope
VERIFIED COMPETENCY MILESTONE
