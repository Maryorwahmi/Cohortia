Key Concepts

Three compact reminders to guide implementations and design decisions.

Memento Pattern
Save and restore object state without exposing private fields.
Three Roles
Originator creates/restores, Memento stores snapshot, Caretaker manages history without peeking.
Memory & Safety
Use immutability, deep copies, and history policies to avoid aliasing and out-of-memory issues.
Final takeaway

Memento gives you safe snapshots; design access and history thoughtfully to keep code correct and efficient.
