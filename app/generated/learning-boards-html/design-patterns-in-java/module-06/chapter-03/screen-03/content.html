Learning Objectives — Practical Focus

Hands-on skills for writing mementos and caretakers and for making trade-offs in production code.

01
Create immutable mementos

Use final fields and deep copies so saved snapshots cannot be altered by external code.

Visual: lock icon
VERIFIED COMPETENCY MILESTONE
02
Protect access scope

Prefer inner classes or package-private constructors so only the Originator sees the Memento's internals.

Mnemonic: origin-only access
VERIFIED COMPETENCY MILESTONE
03
Store history safely

Caretakers should store opaque mementos, often using stacks for undo behavior and avoiding direct inspection of contents.

Visual: stack
VERIFIED COMPETENCY MILESTONE
04
Plan for memory

Decide on limits, deltas, or persistence to keep memento history practical in real applications.

Checklist: limit, delta, persist
