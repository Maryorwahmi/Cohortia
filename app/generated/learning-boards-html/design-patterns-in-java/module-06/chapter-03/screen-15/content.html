What to Remember

Three quick reminders to carry into your designs.

Originator owns state
Only the Originator should create and read the memento's internal snapshot.
Make mementos immutable
Use final fields and defensive copies so saved snapshots cannot be mutated externally.
Manage memory
Limit history size, use deltas, or persist older mementos to keep memory under control.
Closing thought

Choose snapshots when restoring full state is easiest; otherwise consider commands or hybrid approaches.
