Best Practices

Design rules

  • Make the memento immutable and final where possible.
  • Limit access by using inner classes or package-private scope.
  • Deep copy mutable fields and return copies from getters.
  • Provide only minimal metadata to Caretaker if needed.
Mistakes to avoid
  1. Making mementos public and mutable.
  2. Allowing Caretaker to modify or inspect full state.
  3. Failing to deep copy composite state and causing aliasing bugs.
Check

Unit test that modifying the current object after saving does not change the saved memento.
