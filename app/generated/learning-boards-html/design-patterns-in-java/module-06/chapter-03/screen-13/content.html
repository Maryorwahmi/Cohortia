Cursor position & persistence

Include cursor position in the memento and serialize older snapshots to disk to keep memory bounded.
// EditorMemento with cursor
class EditorMemento {
  private final String content;
  private final int cursor;

  EditorMemento(String content, int cursor) {
    this.content = content;
    this.cursor = cursor;
  }

  String getSavedContent() { return content; }
  int getCursor() { return cursor; }
}
