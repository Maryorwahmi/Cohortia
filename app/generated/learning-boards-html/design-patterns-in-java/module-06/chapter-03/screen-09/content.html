Pitfalls & Trade-offs

Memory mitigation strategies

Limit history
Keep only the last N mementos to bound memory usage.
Delta mementos
Store only changes between states instead of full snapshots.
Persist to disk
Serialize older mementos to disk and reload when needed.
Externalize large assets
Store IDs or references to heavyweight data instead of duplicating it in every memento.
When choosing a mitigation strategy, profile memory and consider restore latency. Deltas save space at a cost of complexity; persistence saves memory at a cost of IO and potential delay. Pick the combination that fits your application's responsiveness and complexity constraints.
