Comparison

Snapshot (Memento)

  • Stores full object state as a snapshot.
  • Simple restore semantics: replace current state with saved state.
  • Potentially high memory usage for large states.
Good when
State is complex and easier to restore wholesale than invert operation-by-operation.
Comparison

Operation (Command)

  • Records actions and their inverses.
  • Often uses less memory but requires explicit inverse logic.
  • Better for fine-grained, reversible operations.
Good when
You can implement reliable inverse operations and want to avoid heavy snapshots.
Hybrid approaches combine both: periodic mementos for checkpoints and command-based undo for fine-grained steps between checkpoints. This balances memory and reversibility. When you design, measure the state size and estimate history depth to choose the right strategy.
