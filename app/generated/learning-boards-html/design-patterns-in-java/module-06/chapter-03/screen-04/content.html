Core Concept

Why Memento

Capture an object's snapshot without exposing its private fields. Preserve encapsulation and avoid tight coupling.

Quick bullets
  • Originator creates and restores its own snapshot.
  • Caretaker stores opaque mementos and never inspects them.
  • Mementos should be immutable or restricted so state can't be altered externally.
Key Takeaway

Memento retains encapsulation by letting the object control what to save and how to restore it.

Analogy
Think of the Originator as a camera that takes photos. The Memento is the photograph. The Caretaker is an album that stores photos but never opens the camera to change how photos are taken.
Example: Text Editor
Editor saves content and cursor position into a memento. History stores mementos for undo.
Misconception
Making mementos public and mutable defeats encapsulation and allows state corruption.
Check your understanding
If you need operations to reverse actions precisely, consider whether the Command pattern fits better than Memento for some workflows.
