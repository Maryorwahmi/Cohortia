Starter Code (sketch)
// Song.java
class Song {
  private String title; private String artist;
  public Song(String title, String artist) { this.title = title; this.artist = artist; }
  public String getTitle() { return title; }
  public String getArtist() { return artist; }
}

// SongIterator.java
interface SongIterator { boolean hasNext(); Song next(); }

// PlaylistAggregate.java
interface PlaylistAggregate { SongIterator createIterator(); void addSong(Song song); }
ConcretePlaylist hints
Use LinkedList<Song> for storage and addSong to append.
Implement PlaylistIterator as an inner class that uses an index and checks expectedMod.
In main, create the playlist, add songs, get iterator, and iterate printing each song.
Checkpoints

Print titles, trigger a concurrent modification to observe the exception, and optionally add Iterable support.
