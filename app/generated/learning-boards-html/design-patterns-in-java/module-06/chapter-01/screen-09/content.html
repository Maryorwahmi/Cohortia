Implement Iterable
class ConcreteBookShelf implements Iterable<Book> {
  // existing fields and methods
  @Override
  public java.util.Iterator<Book> iterator() {
    return new BookShelfIterator(); // inner class that implements java.util.Iterator
  }
}

// Now client can do:
// for (Book book : bookShelf) { System.out.println(book.getTitle()); }
Notes
Return a fresh iterator for each call to iterator() so iterations are independent.
Use java.util.Iterator methods to integrate with libraries and language constructs.
If you expose both a custom iterator and Iterable, document the expectations about concurrent modification behavior.
