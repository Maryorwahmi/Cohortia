The Iterator Pattern
Traverse aggregates safely and consistently without exposing implementation details.
Why it matters

Separating traversal makes code resilient to changes in how collections store data and reduces duplicated traversal logic across clients.

Core API
hasNext(), next() — the minimal contract for external iteration used across Java collections.
