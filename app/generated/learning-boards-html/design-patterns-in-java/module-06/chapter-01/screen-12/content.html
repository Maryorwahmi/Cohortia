Module 6 › Chapter 6.1 › Assessing Iterator Design for Trees
Interface sketch
enum TraversalType { PRE_ORDER, IN_ORDER, POST_ORDER }

interface TreeIterator { boolean hasNext(); Node next(); }

interface TreeAggregate { TreeIterator createIterator(TraversalType type); }
Design notes
Each concrete iterator encapsulates traversal state such as a stack for iterative traversal.
Keep traversal logic isolated so clients never touch nodes directly.
For mutable trees consider modCount checks to provide fail-fast behavior when needed.
Assessment prompt
