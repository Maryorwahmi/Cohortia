Module 6 › Chapter 6.1 › What the Iterator Pattern Is
Definition
Iterator: an object that steps through an aggregate sequentially

Treat traversal as a single responsibility. The aggregate manages data; the iterator manages traversal.

Analogy

Think of an attendant delivering items from a concealed conveyor belt — the customer never sees the mechanism.

Key Takeaway

Separate traversal responsibilities to make collections easier to change and reuse.

Concrete Example (conceptual)
BookShelf
Provides createIterator() which returns a BookIterator that knows how to walk shelf positions.
Playlist
ConcretePlaylist returns PlaylistIterator that traverses an internal linked list of songs.
Common misconception

Iterators do not duplicate collection responsibilities. They only observe or step through elements; they should not manage element lifecycle or storage policies.
