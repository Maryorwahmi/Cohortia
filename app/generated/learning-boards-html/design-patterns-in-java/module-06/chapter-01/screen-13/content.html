Module 6 › Chapter 6.1 › Design Guidelines and Common Mistakes
Guidelines
  • Separate traversal from storage; iterator only steps and returns elements.
  • Use inner-class iterators for direct access to private state, keeping the public API small.
  • Implement modCount checks or snapshot behavior and document which you choose.
  • Return a new iterator for each iterator() invocation so iterations are independent.
  • Write unit tests for normal iteration, edge cases, and concurrent modification detection.
Common mistakes
Exposing internal collections publicly which creates fragile client code.
Not checking bounds and letting next() return null instead of throwing NoSuchElementException.
Assuming fail-fast equals thread-safety; it only detects unexpected changes.
