Interfaces and Element
// BookIterator
interface BookIterator {
  boolean hasNext();
  Book next();
}

// BookShelfAggregate
interface BookShelfAggregate {
  BookIterator createIterator();
}

// Book (element)
class Book {
  private String title;
  private String author;
  public Book(String title, String author) { this.title = title; this.author = author; }
  public String getTitle() { return title; }
  public String getAuthor() { return author; }
}

Common mistake

Exposing internal collection for clients to iterate directly creates tight coupling and fragile code.
