Module 6 › Chapter 6.1 › Design Steps for a Custom Iterator
Step-by-step
1.
Define iterator and aggregate interfaces.
2.
Implement concrete aggregate with private storage and add methods to mutate safely.
3.
Implement iterator as inner class and maintain traversal index or node pointer.
4.
Add modCount checks to detect concurrent modification or choose to disallow mutations during iteration.
5.
Expose Iterable to enable enhanced for-loop if interoperability is desired.
Example scenario
Playlist backed by LinkedList<Song> where PlaylistIterator keeps an index or node reference and checks expectedMod each step.
Key Takeaway

A clear checklist reduces subtle bugs and clarifies who owns traversal responsibility.
