Practice tasks
  • Implement BookShelf iterator as an inner class and use hasNext/next to print titles.
  • Add modCount checks to detect concurrent modifications and throw an exception when detected.
  • Implement ConcretePlaylist backed by LinkedList and create PlaylistIterator to traverse songs.
  • Optionally make your aggregate implement Iterable to support the enhanced for-loop.
Why safety checks

Fail-fast behavior makes bugs obvious. Detecting concurrent modification early prevents subtle data corruption and encourages correct usage patterns.

Mnemonic
Capture modCount → compare each step → fail fast
Milestone
Demonstrate traversal and fail-fast detection in the Playlist lab to earn the verified competency.
