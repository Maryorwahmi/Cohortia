Module 6 › Chapter 6.4 › Testing & Debugging
Unit Tests
Test each ConcreteState by calling methods and asserting context.setState was called or context.currentState changed to the right class.
  • Directly test state methods with a fresh Context
  • Assert new state type after action
  • Test invalid actions do not change state
Integration Tests
Simulate sequences through the Context API and assert final states and side effects match expectations.
Example sequence: play → nextSong → pause → play → stop.
Debug Tip

Log the current state's class name on each transition to trace flows during development and tests.
