Architecture

Context, State, ConcreteState

Each role has a focused responsibility: Context delegates, State defines the interface, ConcreteState implements behavior and transitions.
Context
Holds current state and delegates requests to it.
State
Interface or abstract class that defines operations states must implement.
ConcreteState
Implements behavior and may change the Context's state.
Example: Door
ClosedState.lock calls context.setState(new LockedState()) to perform the transition where the behavior occurs.
<!-- Representative call -->
// Context delegates
public void lock() {
  currentState.lock(this);
}

// In ClosedState
public void lock(Door door) {
  System.out.println("Locking the door.");
  door.setState(new LockedState());
}
Key Takeaway

Put transitions next to the behavior that triggers them so changes are localized and easy to extend.
