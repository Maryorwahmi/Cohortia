Starter Code
// MediaPlayerState.java
interface MediaPlayerState {
  void play(MediaPlayer player);
  void pause(MediaPlayer player);
  void stop(MediaPlayer player);
  void nextSong(MediaPlayer player);
}

// StoppedState.java (provided)
class StoppedState implements MediaPlayerState {
  @Override
  public void play(MediaPlayer player) {
    System.out.println("Starting playback from stopped state.");
    player.setState(new PlayingState());
  }
  @Override
  public void pause(MediaPlayer player) {
    System.out.println("Cannot pause, player is stopped.");
  }
  @Override
  public void stop(MediaPlayer player) {
    System.out.println("Player is already stopped.");
  }
  @Override
  public void nextSong(MediaPlayer player) {
    System.out.println("Moving to next song from stopped state.");
    player.setState(new PlayingState());
  }
}
Run Sequence
Simulate the following in main: create player, play, nextSong, pause, play, stop, pause. Expect printed state transitions and one ignored pause while stopped.
Pro Tip

Use small unit tests to simulate the call sequence and assert the class name of current state after each action.
