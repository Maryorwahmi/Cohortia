Module 6 › Chapter 6.4 › TrafficLight Refactor
Steps
  1. Find methods that switch on the state field.
  2. Create a State interface with required operations.
  3. Extract each case into a ConcreteState class.
  4. Change Context to hold a State reference and delegate.
  5. Move transitions into ConcreteState implementations.
Concrete Example
Old: handleRequest switches on color. New: light.handleRequest calls currentState.handleRequest(light). RedState decides to call light.setState(new GreenState()).
Common Mistake

Migrating code piecemeal without centralizing shared helpers leads to duplicated logic. Centralize before extracting.
