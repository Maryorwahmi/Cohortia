Module 6 › Chapter 6.4 › Vending Machine
Design Steps
  1. Create VendingMachineState with insertMoney, selectProduct, dispenseProduct, refundMoney.
  2. Implement IdleState, HasSelectionState, HasMoneyState, SoldOutState.
  3. Put transitions in ConcreteState implementations and keep inventory in Context.
Example Transition
HasMoneyState.dispenseProduct decrements inventory and may set state to SoldOutState when count reaches zero.
Assessment Tip

Describe how the pattern avoids long conditionals by delegating behavior to state objects and include tests for normal and error flows.
