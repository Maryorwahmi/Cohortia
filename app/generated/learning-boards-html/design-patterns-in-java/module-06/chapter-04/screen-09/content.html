Module 6 › Chapter 6.4 › State vs Strategy
State
Object changes behavior based on internal state. State objects often know the context and can change it.
  • Context holds current state
  • Transitions happen inside states
  • Useful for mode-driven behavior
Strategy
Context or client selects an algorithm. Strategies are interchangeable and typically stateless.
  • Client chooses a strategy
  • Strategies don't change context
  • Useful for algorithm selection
Analogy
State: a traffic light that moves through modes on its own. Strategy: a driver choosing the navigation method before starting a trip.
Key Takeaway

Ask who chooses and who drives transitions: external selection suggests Strategy; internal transitions suggest State.
