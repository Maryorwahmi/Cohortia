Module 6 › Chapter 6.4 › Pitfalls
Mistake
Using State as a cosmetic refactor without moving transitions into states.
Fix: Ensure states can call context.setState and place transition logic in the state methods.
Mistake
Storing shared mutable data inside state objects.
Fix: Keep shared data in Context and give states read-only access or pass context as needed.
Pro Tip
Before extracting, list all branches that depend on the state field. If they span many methods or are duplicated, extraction will pay off. Write tests for each state's behavior to prevent regressions.
