Architecture
Pattern elements
  • Mediator interface: defines communication methods colleagues call.
  • Concrete mediator: holds colleagues, routes messages, and implements collaboration rules.
  • Colleague abstraction: stores mediator reference and declares send/receive.
  • Concrete colleague: implements behavior and delegates interaction to mediator.
Design notes
Mediator keeps the collaboration rules; colleagues remain small and easier to test. Use multiple mediators when interactions span unrelated domains.
Example roles
ChatMediator, ChatRoom (concrete mediator), User (colleague), ChatUser (concrete colleague).
