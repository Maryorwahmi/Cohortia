Benefits
  • Reduced coupling between colleagues.
  • Single place to change routing and coordination rules.
  • Colleagues become easier to unit test.
Risks
  • Mediator can become a god object if responsibilities expand too far.
  • Potential single point of failure and performance bottleneck.
  • Concurrency concerns when multiple threads interact with mediator state.
Mitigations
Design mediators with narrow, cohesive responsibilities; split coordination into multiple mediators if needed; make collections thread-safe or synchronize access; and write integration tests to validate routing logic.
Pro-tip

Document the mediator’s scope in code comments and design notes so teams avoid adding unrelated logic later.
