Code: mediator
<!-- ChatMediator.java -->
interface ChatMediator {
  void sendMessage(String message, User user);
  void addUser(User user);
}

<!-- User.java (abstract colleague) -->
abstract class User {
  protected ChatMediator mediator;
  protected String name;

  public User(ChatMediator mediator, String name) {
    this.mediator = mediator;
    this.name = name;
  }

  public String getName() { return name; }
  public abstract void send(String message);
  public abstract void receive(String message);
}
Notes
  • Keep the mediator interface minimal and focused on communication operations.
  • Make colleagues depend on the interface, not a concrete mediator class.
  • Register colleagues with the mediator during construction or via a separate registration call.
Key Takeaway

Design the mediator interface first so colleagues code against abstraction and routing stays centralized.
