The Mediator Pattern: Centralizing Communication
Coordinate interactions through a single mediator so colleagues remain unaware of each other’s internals. This simplifies maintenance and evolution when communication rules change.
Interactive 16:9 Masterclass
Mediator concept
Central controller that routes messages and coordinates colleagues.
Problem
Direct object-to-object links cause tight coupling and scattered logic.
Pattern
Introduce a mediator interface and colleagues that speak only to it.
Trade-off
Contain coordination logic, but avoid turning the mediator into a god object.
Explore Key Topics
Problem: Coupling
When objects hold references to many peers, changes ripple across the system.
Structure
Mediator interface, concrete mediator, colleague abstraction, concrete colleague.
Trade-offs
Centralize coordination but limit scope to avoid a single monolith.
