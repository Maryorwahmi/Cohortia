Core Concept
Tangled direct communication
When objects hold references to many peers, update and notification logic appears in multiple places, making the codebase fragile and hard to reason about.
  • Symptoms: many imports, long constructors with peer parameters, duplicated routing logic.
  • Why it matters: changes ripple across peers, tests need many collaborators instantiated.
  • Misconception: direct communication is always simpler — it can cause long-term maintenance costs.
Analogy: Air traffic control
Planes report to a central tower that coordinates takeoffs and landings, so each plane doesn't need to know the state of every other plane.
Diagram: many-to-many vs mediator

Key Takeaway

Move coordination to one focused component only when it reduces overall coupling and improves clarity.
