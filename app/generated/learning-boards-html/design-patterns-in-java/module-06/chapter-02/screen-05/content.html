Definition
Mediator: central coordinator
Colleagues notify the mediator and the mediator coordinates responses and routing of messages to other colleagues.
Colleague role
Holds a mediator reference and delegates communication to it instead of to peers.
Mediator role
Implements coordination rules and knows its colleagues so it can route or broadcast messages.
Concrete example
ChatRoom mediator
Users send messages to ChatRoom which broadcasts to other users. Adding a new user touches the ChatRoom only.
Common mistake
Giving the mediator unrelated responsibilities turns it into a god object.
