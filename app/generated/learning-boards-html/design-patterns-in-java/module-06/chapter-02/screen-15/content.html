Module 06 › Chapter 6.2 › Key Concepts
Mediator Pattern
An object that encapsulates interactions among a set of objects, reducing direct references.
Mediator
An interface defining communication methods colleagues call to coordinate actions.
Concrete Mediator
An implementation that holds colleagues and executes routing and coordination rules.
Takeaway

Speak the terms clearly: mediator interface, concrete mediator, and the pattern’s goal to reduce direct coupling.
