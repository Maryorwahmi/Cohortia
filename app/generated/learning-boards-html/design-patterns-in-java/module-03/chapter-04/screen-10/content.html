Module 4 › Chapter 3.4 › Refactoring Steps
Step-by-step
1. Find 'new' hotspots
Search for direct instantiation in clients. These spots are brittle and hide dependencies.
2. Choose minimal pattern
Pick Builder for many options, Factory for runtime type selection, Prototype for costly setup.
3. Introduce abstraction
Add a factory interface or builder and route client code through it incrementally.
4. Replace singletons with DI
Let your DI container manage scope to preserve testability.
5. Test and iterate
Run unit tests after each change and add tests for the new factory or builder behavior.
Concrete example
Refactor ReportGenerator to accept a ReportFactory via constructor injection. Replace direct PdfReport and CsvReport construction with factory.createReport(type).
Mistake to avoid: performing a large refactor without tests. Incremental changes are safer and reversible.
