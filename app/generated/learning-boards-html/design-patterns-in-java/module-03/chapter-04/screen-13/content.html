Module 4 › Chapter 3.4 › Refactor Checklist
Refactor checklist
  1. Write tests covering current ReportGenerator behavior.
  2. Create Report interface and concrete PdfReport/CsvReport classes.
  3. Implement ReportFactory and SimpleReportFactory.
  4. Inject ReportFactory into ReportGenerator and replace direct instantiation.
  5. Run tests, add factory tests, and refactor until green.
Common pitfalls
  • Missing tests for factory edge cases.
  • Accidentally leaving direct instantiation in some code paths.
  • Replacing simple constructors unnecessarily.
Key Takeaway

Refactor incrementally and test at each step; success is measured by simpler tests and centralized creation logic.
