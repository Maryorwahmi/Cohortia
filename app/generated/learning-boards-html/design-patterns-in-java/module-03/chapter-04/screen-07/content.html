Module 4 › Chapter 3.4 › Prototype Pattern
What it does
Prototype provides cloning to create new instances from existing templates, avoiding repeated setup cost.
Use case
Game entities, configuration templates, or any object where deep setup or expensive initialization is costly.
Registry pattern
Combine with a registry that stores prototypes. A factory clones from the registry to produce instances on demand.
Pitfall
Deep cloning can be CPU- and memory-intensive. Test and profile before choosing Prototype for performance reasons.
Key Takeaway

Prototype is valuable when clones save expensive construction; ensure cloning cost is actually lower.

Concrete scenario
An enemy template with behavior trees, animation state, and configured AI is cloned on spawn. Cloning avoids rebuilding the tree and reloading assets repeatedly.
Misconception check
Treat prototypes as immutable templates. Mutating prototypes in place leads to subtle bugs when clones should be independent.
