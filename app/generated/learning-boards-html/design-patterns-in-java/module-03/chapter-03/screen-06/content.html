Module 3 › Chapter 3.3 › DI Types: Constructor, Setter, Field
Constructor Injection
Dependencies come through the constructor. Best for required collaborators and immutability.
public class NotificationService {
  private final MessageService messageService;

  public NotificationService(MessageService messageService) {
    this.messageService = messageService;
  }
}
Advantage: object created in a valid state. Pitfall: very long constructors signal design issues.
Setter Injection
Optional dependencies are supplied via setters; useful for mutable or optional collaborators.
public class UserService {
  private UserRepository userRepository;

  public void setUserRepository(UserRepository userRepository) {
    this.userRepository = userRepository;
  }
}
Remember to validate optional dependencies before use.
Field Injection
Dependencies are injected directly into fields with annotations. Concise but harder to unit test outside the container.
public class UserService {
  @Autowired
  private UserRepository userRepository;
}
Use field injection sparingly; prefer constructor injection for testability.
