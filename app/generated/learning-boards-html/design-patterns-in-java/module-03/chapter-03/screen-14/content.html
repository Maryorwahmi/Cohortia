Module 3 › Chapter 3.3 › Key Concepts — Part 1
Inversion of Control (IoC)
The framework controls creation and calling into application code.
Dependency Injection (DI)
Dependencies are provided from the outside rather than created internally.
IoC Container
A framework like Spring that instantiates, wires, and manages bean lifecycles.
Summary: Use these concepts as the mental model when you design classes that declare dependencies and rely on a container to supply them.
