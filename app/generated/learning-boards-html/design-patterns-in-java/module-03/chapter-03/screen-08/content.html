Module 3 › Chapter 3.3 › Creational Patterns vs DI Containers
Factory Method
A @Bean method in a configuration class is effectively a factory method the container calls to obtain instances.
@Configuration
public class AppConfig {
  @Bean
  public UserRepository userRepository() {
    return new JpaUserRepository();
  }
}
Singleton
Spring provides managed singletons by default, avoiding the need for a class-level getInstance call while keeping testability and configurability.
You can change scope to prototype if you need new instances each time.
Builder
Use Builder for complex object setup and then inject the built object. DI handles wiring; Builder handles complex construction detail.
Example use: configuring an HttpClient before injection into services.
Key Takeaway

DI containers often take on the role of factories and singleton managers; creational patterns still apply for specific construction tasks and configuration objects.
