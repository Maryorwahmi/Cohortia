Starter code
public class Computer {
    private final String cpu;      // required
    private final int ramGB;       // required
    private final String storageType;
    private final int storageGB;
    private final String gpu;
    private final boolean hasWifi;
    private final String operatingSystem;

    private Computer(ComputerBuilder builder) {
        this.cpu = builder.cpu;
        this.ramGB = builder.ramGB;
        this.storageType = builder.storageType;
        this.storageGB = builder.storageGB;
        this.gpu = builder.gpu;
        this.hasWifi = builder.hasWifi;
        this.operatingSystem = builder.operatingSystem;
    }

    // Getters omitted for brevity

    public static class ComputerBuilder {
        private final String cpu;
        private final int ramGB;
        private String storageType = "SSD";
        private int storageGB = 500;
        private String gpu = "Integrated";
        private boolean hasWifi = true;
        private String operatingSystem = "Windows";

        public ComputerBuilder(String cpu, int ramGB) {
            this.cpu = cpu;
            this.ramGB = ramGB;
        }

        // Implement fluent setters here and build()
    }
}
Exercise
Implement storageType(), storageGB(), gpu(), hasWifi(), operatingSystem(), and build() to validate ramGB > 0 and storageGB > 0. Use a new ComputerBuilder instance per object in the demo main.
Try this

Run the provided demo main to build an office PC, gaming PC, and server. Confirm invalid values throw exceptions during build.
