Apply, Validate, and Compare

Hands-on objectives: implement ComputerBuilder, add build-time checks, and summarize when Builder is the right choice.

01
Apply Builder
Use the pattern for User, Product, or Computer classes and demonstrate multiple configurations in a main method.
VERIFIED COMPETENCY MILESTONE
02
Validation
Add validation in build() so constructed objects are guaranteed valid; e.g., non-negative numbers and required fields present.
VERIFIED COMPETENCY MILESTONE
03
Avoid reuse pitfall
Understand that reusing the same builder can lead to accidental carry-over state; prefer fresh builders for clarity.
VERIFIED COMPETENCY MILESTONE
04
Compare patterns
Be able to explain the difference between Builder, Factory Method, and plain constructors and when to use each.
VERIFIED COMPETENCY MILESTONE
