Client code examples
// Required-only
User user1 = new User.UserBuilder("Alice", "Smith").build();
System.out.println(user1);

// Partial configuration
User user2 = new User.UserBuilder("Bob", "Johnson")
    .age(30)
    .phone("123-456-7890")
    .build();
System.out.println(user2);

// Full configuration
User user3 = new User.UserBuilder("Charlie", "Brown")
    .age(25)
    .phone("987-654-3210")
    .address("123 Main St, Anytown")
    .build();
System.out.println(user3);

// Validation example
try {
  User invalid = new User.UserBuilder("Invalid","User").age(-5).build();
} catch (IllegalArgumentException e) {
  System.err.println("Error creating user: " + e.getMessage());
}
Notes
  • Builder calls are self-documenting: method names label each value.
  • Validation at build prevents invalid objects instead of surfacing errors later.
  • Create a new builder per object to avoid accidental state carry-over.
Key Takeaway

Client code reads like a sequence of named steps; you no longer rely on positional parameters to convey intent.
