Module 3 › Chapter 3.2 › Best Practices

Design choices

  • Use defaults for optionals to reduce required configuration.
  • Document required constructor args in the Builder and list defaults.
  • Make builder inner static when tied to the class; otherwise use a top-level builder for reuse.

Safety & API hygiene

  • Return defensive copies for collections to avoid exposing mutable state.
  • Create a new builder per object rather than mutating a reused builder.
  • Keep fluent method names intention-revealing and consistent.
Key Takeaway

Adopt Builder where it improves clarity; keep the API documented, safe, and simple for callers to use correctly.
