Module 3 › Chapter 3.2 › Quick Reminders
Avoid telescoping
If many optional params exist, use Builder to preserve readability and prevent order errors.
Validate in build()
Centralize validation to reject invalid objects early and consistently.
Make the result immutable
Set final fields in a private constructor and expose only getters to keep state stable.
Final thought

Choose the creational pattern that makes your API easiest for callers to use correctly. Builder shines when configuration complexity and optionality grow.
