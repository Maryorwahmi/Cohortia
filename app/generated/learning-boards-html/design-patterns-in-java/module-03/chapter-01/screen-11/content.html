Module 3 › Chapter 3.1 › Prototype vs Factory

Prototype Advantages

  • Efficient when initialization is expensive.
  • Good for runtime-determined types and many similar instances.
  • Works well with a prototype registry for flexible lookups.

Factory / Constructor Advantages

  • Clear, explicit creation and dependency injection.
  • No cloning semantics to manage across nested objects.
  • Better for simple objects or when types are known at compile time.
Decision prompt
Ask whether cloning avoids expensive initialization and whether you can ensure nested independence. If yes, choose Prototype; otherwise prefer factories.
