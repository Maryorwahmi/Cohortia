Learning Objectives

Skills to practice: reasoning, implementing, comparing, and applying cloning in Java.

Bloom: Learn → Understand → Apply → Master
01
Explain the Prototype pattern

Describe when cloning is more efficient than constructing new objects and identify real examples like configuration and game entities.

VERIFIED COMPETENCY MILESTONE
02
Implement Cloneable and clone()

Write a safe clone override and handle CloneNotSupportedException appropriately in application code.

VERIFIED COMPETENCY MILESTONE
03
Distinguish shallow and deep copy

Understand that shallow copy duplicates references; deep copy clones nested mutable objects to avoid shared state.

VERIFIED COMPETENCY MILESTONE
04
Apply Prototype in systems

Use a prototype registry to return clones by key and decouple clients from concrete instantiation logic.

VERIFIED COMPETENCY MILESTONE
Each milestone will be reinforced with code examples and a hands-on Document cloning activity later in the chapter.
