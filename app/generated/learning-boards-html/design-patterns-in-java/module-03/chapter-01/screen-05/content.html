Module 3 › Chapter 3.1 › Cloneable & clone()
Definition

Cloneable marker and shallow copy

Object.clone is protected, so you override clone, implement Cloneable, and call super.clone for a shallow copy.

• Behavior: primitives are copied, references are copied as references.
• Exception: calling clone without Cloneable throws CloneNotSupportedException.
• Responsibility: your override must clone nested mutable fields if independence is required.
Pro tip

Document whether clone performs shallow or deep copy so callers know how to use clones safely.

Code Example
public class ShallowConfiguration implements Cloneable {
  private String theme;
  private int fontSize;
  private DatabaseConnection dbConnection; // reference type

  public ShallowConfiguration(String theme, int fontSize, DatabaseConnection dbConnection) {
    this.theme = theme;
    this.fontSize = fontSize;
    this.dbConnection = dbConnection;
  }

  @Override
  public Object clone() throws CloneNotSupportedException {
    return super.clone(); // shallow copy: dbConnection reference copied, not duplicated
  }

  public static class DatabaseConnection {
    private String url;
    public DatabaseConnection(String url) { this.url = url; }
    public String getUrl() { return url; }
    public void setUrl(String url) { this.url = url; }
  }
}
Try: clone a ShallowConfiguration and change the DatabaseConnection url in the clone. Observe the original's url changes too.
