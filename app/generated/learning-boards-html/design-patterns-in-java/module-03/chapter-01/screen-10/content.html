Common Pitfalls

Missing Cloneable
Forgetting to implement Cloneable on nested classes leads to CloneNotSupportedException when you try to clone them.
Unintended shared state
Super.clone duplicates references, so nested mutable objects remain shared unless explicitly cloned.
Over-cloning
Cloning immutable objects wastes time; prefer sharing immutable references.
Exception handling
Decide whether to declare CloneNotSupportedException or wrap it in an unchecked exception in controlled contexts.
Checklist

Implement Cloneable for nested mutable types, clone only what must be independent, document clone behavior, and validate with tests.
