Module 3 › Chapter 3.1 › Key Concepts
Prototype Pattern
Create objects by copying an existing instance rather than building from scratch.
Cloneable & clone()
Cloneable is a marker; Object.clone performs a shallow copy by default.
Deep vs Shallow
Deep copy duplicates nested mutable objects; shallow copy duplicates only references.
Summary

Prototype saves setup cost and supports many similar objects. Implement cloning carefully, test independence, and choose deep cloning only where necessary.
