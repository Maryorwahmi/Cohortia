CloneNotSupported
Implement Cloneable or handle the checked exception when calling clone.
Deep Clone Rule
Clone nested mutable objects; immutable fields can be shared safely.
Registry Tip
Use a prototype registry for reusable prototypes and decoupled creation by key.
Final takeaway

Cloning is powerful when used deliberately: balance performance, correctness, and complexity when choosing between shallow and deep copy.
