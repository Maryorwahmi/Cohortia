Module 3 › Chapter 3.1 › Shallow vs Deep
Shallow Copy

Top-level duplication only

  • Primitives copied; references copied as references.
  • Nested mutable objects are shared between original and clone.
  • Fast and simple, but may introduce shared-state bugs.
Common mistake
Assuming super.clone creates independent nested objects when it does not.
Deep Copy

Recursively duplicate nested objects

  • Clone nested mutable fields inside the outer object's clone method.
  • Each nested class must support cloning where independence is required.
  • Ensures original and clone do not share mutable state.
When to deep copy
Deep copy fields that will be mutated independently; avoid expensive deep clones of immutable or read-only data.
Check

Ask which nested fields must be independent and implement deep cloning only for those to balance correctness and cost.
