Architecture

Prototype Manager

Store prototypes mapped to keys. Clients request a key and receive a clone, freeing them from concrete constructors.

Register
Add fully-initialized prototypes to the registry under a unique key.
Retrieve
Request a key and return a clone of the stored prototype.
Trade-offs
Centralized management simplifies changes but requires consistent cloning semantics and careful updates to prototypes.
Example
A shape registry holds circle and square prototypes. The editor requests 'circle' and receives independent clones to place on the canvas.
Check
Decide whether prototypes should be immutable (shareable) or cloneable (independent) before registering them.
