DeepConfiguration.clone()

Use super.clone(), cast result, then clone mutable fields on the cloned instance.

public class DeepConfiguration implements Cloneable {
  private String theme;
  private int fontSize;
  private DatabaseConnection dbConnection; // reference

  @Override
  public Object clone() throws CloneNotSupportedException {
    DeepConfiguration clonedConfig = (DeepConfiguration) super.clone();
    if (this.dbConnection != null) {
      clonedConfig.dbConnection = (DatabaseConnection) this.dbConnection.clone();
    }
    return clonedConfig;
  }

  public static class DatabaseConnection implements Cloneable {
    private String url;
    @Override
    public Object clone() throws CloneNotSupportedException {
      return super.clone(); // clone nested fields here if needed
    }
  }
}
Confirm deep copy with a test that mutates dbConnection in the clone but asserts the original's url is unchanged.
Checklist
  • Implement Cloneable on classes that must be cloned.
  • Override clone and call super.clone() to copy primitives and references.
  • Manually clone mutable reference fields on the cloned instance.
  • Write unit tests to validate independence of nested state.
Misconception
Assuming that cloning only top-level fields is sufficient when nested fields will be modified independently.
