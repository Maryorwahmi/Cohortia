Module 3 › Chapter 3.1 › Document Clone Demo
Template
// Author and Content classes implement Cloneable
class Author implements Cloneable { ... }
class Content implements Cloneable { ... }

class Document implements Cloneable {
  private String title;
  private Author author;
  private Content content;

  @Override
  protected Object clone() throws CloneNotSupportedException {
    Document cloned = (Document) super.clone();
    cloned.author = (Author) author.clone();
    cloned.content = (Content) content.clone();
    return cloned;
  }
}

// main: create original, clone, mutate clone, print both
Run the main method, then change clone's author name and content text. The original should remain unchanged if deep cloning is correct.
Expected Console Output
Original Document: Document{title='Project Proposal', author=Author{name='Jane Doe', ...}, content=Content{text='Initial draft text.', version=1}}

Cloned Document (after modification): Document{title='Revised Project Proposal', author=Author{name='John Smith', ...}, content=Content{text='Final approved text.', version=2}}

Original Document (after clone modification): Document{title='Project Proposal', author=Author{name='Jane Doe', ...}, content=Content{text='Initial draft text.', version=1}}
Check
If the original shows the clone's changes, your deep clone is incomplete and shared references remain.
