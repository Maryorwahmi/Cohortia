Core Concept

Prototype Pattern

Create objects by copying a prototype to avoid repeating expensive construction.

• Definition: a prototypical instance is duplicated to produce new objects rather than invoking constructors repeatedly.
• Example: a Configuration object loaded once from file or DB; clones are modified per need.
• Misconception: cloning eliminates complexity—no, it shifts the complexity into correct cloning of nested references.
Key Takeaway

Prototype is efficient for expensive setup and bulk creation, but requires careful handling of nested state.

Analogy
3D printer analogy
A 3D printer can reproduce a model quickly. The prototype is the finished model; cloning saves the time of building it anew each time.
When to use
When object initialization is expensive, or when many similar objects with small differences are needed.
Check your understanding
If your object holds only immutable fields, is deep cloning necessary? Think about safety and performance.
