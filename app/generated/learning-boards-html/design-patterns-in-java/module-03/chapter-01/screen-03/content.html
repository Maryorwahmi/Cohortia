Practice & Pitfalls

Focused tasks: implement clone, test deep vs shallow behavior, and handle exceptions.

Task
Write unit tests that clone an object and then mutate nested fields. For deep copy, the original must remain unchanged. For shallow copy, you should observe shared changes.
Pitfall
Forgetting to clone nested mutable fields causes subtle bugs. Also, handle CloneNotSupportedException consciously instead of ignoring it.
Mnemonic
Think: prototype = ready model; clone = copy the model; deep clone = copy the model and its parts.
Milestone
Verify a deep clone by changing clone components and asserting the original is unchanged.
