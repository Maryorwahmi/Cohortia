Module 5 › Chapter 5.3 › Roles & Collaborators
Collaborators
Command Interface
Defines execute and optional undo so invokers call a stable API.
Concrete Command
Binds a Receiver and parameters, implements execute to delegate work.
Receiver
Performs the actual operations requested by the command.
Invoker
Triggers commands and may keep history for undo; it is unaware of receiver internals.
Analogy
Think of a Command as a remote control instruction, the Invoker as the remote, and the Receiver as the appliance. The remote doesn't implement the appliance behavior; it only sends the instruction object.
Common pitfall
Don't create a separate class for every trivial action when actions are similar; prefer parameterized commands to reduce class proliferation.
