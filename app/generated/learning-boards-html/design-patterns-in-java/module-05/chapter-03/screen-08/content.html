Module 5 › Chapter 5.3 › Undo/Redo Process
Undo / Redo Steps
1. Capture
Save pre-operation state required for undo.
2. Execute
Call receiver via the command's execute method.
3. Record
Push the command onto the undo stack.
4. Redo management
On undo push to redo stack; clear redo when new actions occur.
Concurrency note
Use synchronized blocks or concurrent collections to protect history stacks if multiple threads run commands.
Resource trade-off
Deep copies ensure safe undo but increase memory; consider bounded history or diffs to limit cost.
