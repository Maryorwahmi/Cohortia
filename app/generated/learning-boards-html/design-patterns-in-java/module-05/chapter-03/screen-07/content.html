Code: Invoker with history
// Invoker: RemoteControl
class RemoteControl {
  private Command command;
  private List<Command> history = new ArrayList<>(); // For undo/redo

  public void setCommand(Command command) {
    this.command = command;
  }

  public void pressButton() {
    if (command != null) {
      command.execute();
      history.add(command); // Add to history for undo
    }
  }

  public void pressUndo() {
    if (!history.isEmpty()) {
      Command last = history.remove(history.size() - 1);
      last.undo();
    }
  }
}
Explanation
  • The invoker keeps a history stack of executed commands so undo can be performed in reverse order.
  • Undo logic is delegated to the command's undo method; invoker only manages sequencing.
  • Design note: for redo, maintain a second stack and push commands when undone so they can be reapplied.
Edge case
If commands share receivers and mutate shared state, ensure the command captured all necessary context for undo before execute.
