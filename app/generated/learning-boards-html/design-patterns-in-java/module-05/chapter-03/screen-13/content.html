DimLightCommand task
Create a command that sets brightness and restores previous brightness on undo.
Capture previous brightness before execute.
Execute should call receiver.setBrightness(newLevel).
Undo restores the captured level exactly.
Macro and composition
A MacroCommand holds a sequence of commands and executes them in order. Its undo calls undo on each child command in reverse order. This enables recording and playback of multiple operations as one unit.
Challenge: Implement a MacroCommand and verify that undo reverses child commands correctly even when children have complex state.
