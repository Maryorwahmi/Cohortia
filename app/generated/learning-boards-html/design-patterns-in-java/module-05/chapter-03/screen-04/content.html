Module 5 › Chapter 5.3 › What the Command Pattern Is
Definition

Encapsulate a request as an object so operations can be treated as data.

Claim
Commands let you parameterize clients with different requests and support queuing and logging.
Misconception
Commands are not a place to centralize heavy logic; keep the Receiver responsible for work.
Key Takeaway

Make requests objects so they can be queued, logged, and reversed; avoid stuffing them with business logic.

Concrete example
Text editor actions
Cut, copy, paste, and save become command objects each holding a reference to the TextEditor receiver. The UI simply triggers execute.
Why it matters
This decouples UI wiring from implementation and makes it easy to implement features like macros and undo stacks.
