Module 5 › Chapter 5.3 › Key Concepts
Command Pattern
Encapsulate a request as an object so it can be parameterized, queued, logged, or undone.
Roles
Command, Concrete Command, Receiver, Invoker — each has a clear responsibility.
Undo / Redo
Store executed commands in a history stack and call undo on the last command to reverse it.
Final takeaway

Design commands to be lightweight delegates, capture undo state before mutation, and manage concurrency and serialization when queuing or logging.
