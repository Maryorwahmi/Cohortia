Starter code (excerpt)
// Command Interface
interface CalculatorCommand {
  void execute();
  void undo();
}

// Receiver: Calculator
class Calculator {
  private int currentValue = 0;
  private Stack<Integer> history = new Stack<>();

  public void add(int value) {
    history.push(currentValue);
    currentValue += value;
    System.out.println("Added " + value + ". Current value: " + currentValue);
  }

  public void restorePreviousState() {
    if (!history.isEmpty()) currentValue = history.pop();
  }

  public int getCurrentValue() { return currentValue; }
}

// Example concrete command
class AddCommand implements CalculatorCommand {
  private Calculator calculator;
  private int operand;
  public AddCommand(Calculator calculator, int operand) { this.calculator = calculator; this.operand = operand; }
  @Override public void execute() { calculator.add(operand); }
  @Override public void undo() { calculator.restorePreviousState(); }
}
Activity steps
  1. Define CalculatorCommand with execute and undo.
  2. Implement MultiplyCommand and DivideCommand following Add/Subtract examples.
  3. Create User invoker that executes commands and pushes them to an executed stack.
  4. Run a sequence of operations, then undo them and verify the Calculator restores values.
Safety tip
For divide, check for zero before modifying state; do not push a state snapshot if the operation fails.
