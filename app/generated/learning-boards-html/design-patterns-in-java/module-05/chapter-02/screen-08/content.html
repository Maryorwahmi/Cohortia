Module 5 › Chapter 5.2 › NewsPublisher Activity
Step-by-step
  1. Define NewsPublisher with subscribe, unsubscribe, publishNews.
  2. Define NewsSubscriber with receiveNews(articleTitle, content).
  3. Implement BlogPublisher holding a List of subscribers and calling receiveNews on publish.
  4. Create EmailSubscriber and SmsSubscriber that print messages when receiving news.
  5. Run a main: subscribe several, publish, unsubscribe one, publish again.
Code template is provided in the chapter. Use it as a scaffold and insert logging to observe lifecycle behavior.
Concrete template
interface NewsPublisher {
  void subscribe(NewsSubscriber s);
  void unsubscribe(NewsSubscriber s);
  void publishNews(String title, String content);
}

interface NewsSubscriber {
  void receiveNews(String title, String content);
}
When testing, verify that unsubscribed subscribers receive no further messages.
