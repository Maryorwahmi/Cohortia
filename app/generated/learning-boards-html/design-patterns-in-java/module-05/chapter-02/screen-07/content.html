// Concrete Subject: WeatherStation
class WeatherStation implements Subject {
  private List<Observer> observers;
  private String weatherUpdate;

  public WeatherStation() {
    this.observers = new ArrayList<>();
  }

  @Override
  public void addObserver(Observer o) { observers.add(o); }

  @Override
  public void removeObserver(Observer o) { observers.remove(o); }

  @Override
  public void notifyObservers() {
    for (Observer observer : observers) { observer.update(weatherUpdate); }
  }

  public void setWeather(String newWeather) {
    this.weatherUpdate = newWeather;
    notifyObservers();
  }
}
Example flow
1) Create WeatherStation. 2) Create PhoneDisplay and TVDisplay. 3) Add observers to the station. 4) Call setWeather to trigger updates. 5) Remove a subscriber to stop updates.
Analogy
Think of the station as a broadcast tower and displays as radios tuned in. If a radio is turned off but not unsubscribed, the tower still keeps a reference to it.
