Module 5 › Chapter 5.2 › Benefits Comparison
Observer
  • Loose coupling: Subject only depends on an interface.
  • Event-driven: avoids polling overhead.
  • Extensible: add new Observers without changing Subject.
Polling (contrast)
  • Higher CPU and latency due to repeated checks.
  • Tighter coupling when components require direct access to state.
  • Harder to scale as more consumers are added.
Practical note
Choose Observer when you have true one-to-many relationships and want efficient notifications. Always pair it with lifecycle and concurrency safeguards.
