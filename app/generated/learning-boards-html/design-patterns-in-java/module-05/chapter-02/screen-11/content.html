Module 5 › Chapter 5.2 › Thread Safety
Synchronization strategies
  • Use synchronized blocks around add/remove and notify when simple.
  • Use CopyOnWriteArrayList for safe iteration without locks when modifications are rare.
  • Protect shared state with locks or atomic variables when needed.
Avoiding update storms
  • Make update handlers idempotent.
  • Schedule heavy work on worker threads instead of inside update.
  • Debounce or batch frequent updates to reduce churn.
Testing tips
Simulate concurrent registrations and notifications, and verify no lost or duplicate notifications under load.
