Module 5 › Chapter 5.2 › Memory Leaks
Problem
If Observers are not removed, the Subject retains references and prevents garbage collection. This commonly happens with UI components that forget to unsubscribe during teardown.
Consequence
Increased memory usage and unexpected behavior from stale observers still receiving updates.
Mitigation
Use explicit unsubscribe at lifecycle end or hold WeakReference to observers when appropriate.
Checklist
  • Log add/remove events during testing.
  • Unsubscribe observers in destructors or teardown methods.
  • Consider weak references for short-lived observers.
