Module 5 › Chapter 5.1 › Runtime Selection
Selection mechanisms
  • Setter injection for explicit runtime choice (e.g., user selects payment method).
  • Configuration-based wiring at startup for environment-driven behavior.
  • Automatic heuristics inside client code to pick strategy based on data.
Lifecycle & resources
If strategies hold resources, manage their lifecycle explicitly. Prefer lightweight or stateless strategies when frequent swapping is required.
Example
Sorter chooses algorithm based on input size: quick for large, insertion for small collections.
