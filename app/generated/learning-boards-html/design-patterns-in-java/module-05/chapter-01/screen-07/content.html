Module 5 › Chapter 5.1 › Document Export
Starter code (template)
// Strategy Interface
interface DocumentExportStrategy {
  void export(String documentContent);
}

// Concrete strategies: PdfExportStrategy, HtmlExportStrategy

// Context: DocumentProcessor
class DocumentProcessor {
  private DocumentExportStrategy exportStrategy;
  public void setExportStrategy(DocumentExportStrategy strategy) { this.exportStrategy = strategy; }
  public void exportDocument(String content) {
    if (exportStrategy == null) {
      System.out.println("No export strategy set. Cannot export document.");
      return;
    }
    exportStrategy.export(content);
  }
}
Notes & example
  • PdfExportStrategy prints a PDF preview line for demo purposes.
  • HtmlExportStrategy wraps content in simple html tags for demonstration.
  • To add PlainTextExportStrategy, implement the same interface and register it with the processor.
Key Takeaway

Use strategy interfaces to add new export formats without modifying the processor code.
