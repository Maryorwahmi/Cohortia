Module 5 › Chapter 5.1 › Components
Strategy Interface
Declares the method signature shared by all algorithms. It must be cohesive and represent the family of algorithms.
Example: ShippingCostCalculator with calculate(Order order).
Concrete Strategies
Implement the interface with specific behavior. Keep them focused and testable in isolation.
Example: ExpressShippingCalculator handles fast delivery rules.
Context
Holds a strategy reference, delegates algorithm calls, and may provide a setter to change strategies at runtime. Owns operation-wide state.
Example: ShippingService calls strategy.calculate(order).
Example
Sorter context + QuickSortStrategy or MergeSortStrategy for different data sizes.
Misconception
Context must implement algorithms — false. Context should only delegate to the strategy interface.
Key Takeaway
Partition responsibilities: interface for contract, strategy for algorithms, context for orchestration.
