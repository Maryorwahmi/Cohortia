Module 5 › Chapter 5.1 › Implementation
Five steps
  1. Design the Strategy Interface with consistent method signature.
  2. Create Concrete Strategies implementing the interface.
  3. Implement Context that holds and delegates to a Strategy reference.
  4. Wire strategies at runtime through setter or constructor injection.
  5. Unit test strategies and Context behavior independently.
Pitfall & fix
Pitfall: strategies with hidden mutable state. Fix: make strategies stateless or let Context own state and pass it into strategy methods.
Pro-tip
Prefer constructor injection for immutable strategy configuration, and setter injection when runtime swapping is required.
Key Takeaway

Follow a clear sequence from interface to runtime wiring and test each component independently for reliability.
