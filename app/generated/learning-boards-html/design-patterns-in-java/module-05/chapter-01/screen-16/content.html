Module 5 › Chapter 5.1 › Quick Reference
Loose coupling
Context depends on an interface, enabling independent algorithm changes.
Stateless strategies
Avoid shared mutable state inside strategies to prevent concurrency issues.
Be pragmatic
Don’t apply Strategy for trivial, stable tasks where a simple conditional is clearer.
Final takeaway
When behavior must vary, encapsulate algorithms behind an interface, keep strategies focused and stateless, and prefer Strategy when extensibility and testability matter.
