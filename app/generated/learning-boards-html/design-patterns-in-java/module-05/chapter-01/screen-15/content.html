Module 5 › Chapter 5.1 › Key Concepts
Strategy Pattern
Defines a family of algorithms and makes them interchangeable at runtime.
Strategy Interface
A contract that ensures all concrete algorithms can be called interchangeably by the context.
Context
Holds and uses a strategy reference, and delegates the algorithm execution to it.
Summary Takeaway
Use Strategy to decouple algorithm choice from implementation, improving extensibility and testability while avoiding hidden state and excessive indirection.
