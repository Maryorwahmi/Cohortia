Module 5 › Chapter 5.1 › Pitfalls
Over-engineering
Don’t add Strategy if behavior is stable and unlikely to change.
Hidden mutable state
Avoid sharing strategy instances that keep internal state across threads or contexts.
Interface mismatch
If algorithms require different inputs, create separate strategy families instead of forcing one interface.
Avoidance checklist
Ask whether each strategy has single responsibility, whether state is explicit, and whether the interface fits all algorithms.
