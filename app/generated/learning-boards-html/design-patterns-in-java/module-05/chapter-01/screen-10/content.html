Module 5 › Chapter 5.1 › Interface Design
Rules of thumb
  • Keep parameters consistent across strategies.
  • Prefer returning a result instead of mutating external state.
  • Pass required data explicitly; avoid hidden dependencies.
Statelessness
Stateless strategies are safer, easier to reuse, and avoid concurrency issues. If configuration is needed, inject it during construction.
Concrete checklist
For each new strategy ask: Does it require the same inputs? Will it be tested independently? Can it remain stateless?
Key Takeaway
A well-scoped interface preserves interchangeability and simplifies testing.
