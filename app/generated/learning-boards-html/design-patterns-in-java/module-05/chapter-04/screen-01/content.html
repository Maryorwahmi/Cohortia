The Iterator Pattern
Access elements sequentially without exposing internal structure
Why it matters
Iterators let client code traverse different collection types in the same way. Change the collection internals and client code stays unchanged.
When to use
Use when you need uniform traversal, multiple traversal strategies, or when hiding an aggregate's representation improves maintainability.
Explore Key Topics
Problem: Coupling
Without iterators, clients must know internal layouts like arrays or links.
Pattern: Roles
Aggregate creates an iterator; iterator tracks position and returns elements.
Java: Iterable
Implement Iterable to use the enhanced for-loop and return a java.util.Iterator.
