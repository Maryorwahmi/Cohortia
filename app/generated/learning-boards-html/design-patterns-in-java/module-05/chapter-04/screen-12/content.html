Module 5 › Chapter 5.4 › External vs Internal
External Iterator
Client calls hasNext and next. Use when traversal control, removal, or pausing is needed.
Example: java.util.Iterator used directly or via enhanced for-loop.
Internal Iterator
Aggregate accepts a callback and applies it to each element internally. Use for concise processing and possible optimizations.
Caveat: clients cannot easily stop mid-iteration or manage complex state.
