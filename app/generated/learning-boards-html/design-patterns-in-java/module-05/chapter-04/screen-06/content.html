Module 5 › Chapter 5.4 › Iterator API
Method descriptions
  • hasNext(): boolean — checks if more elements exist.
  • next(): E — returns next element, advances state, throws NoSuchElementException if empty.
  • remove(): void — optional; removes last returned element through iterator semantics.
Misconception
Calling next without checking hasNext is a runtime error. Always check hasNext or handle NoSuchElementException.
Code sketch
<!-- Example: iterator loop sketch -->
Iterator<Book> it = library.createIterator();
while (it.hasNext()) {
  Book b = it.next();
  System.out.println(b);
}

// If next() is called now, it should throw NoSuchElementException
The code above illustrates safe iteration using hasNext, and shows the contract that next must enforce.
