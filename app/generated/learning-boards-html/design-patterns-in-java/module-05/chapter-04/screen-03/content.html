Concrete checks
  • next must throw NoSuchElementException when no elements remain.
  • remove can be supported or throw UnsupportedOperationException — decide based on aggregate capabilities.
  • Fail-fast iterators detect structural modification and surface bugs early with ConcurrentModificationException.
  • For multi-threaded access, prefer concurrent collections or synchronize iteration and modification.
Practice tips
Keep iterator state minimal: a reference to the aggregate and a position index or node reference. Delegate complex removals or rebalancing to the aggregate. Keep iterators focused on traversal and element access.
