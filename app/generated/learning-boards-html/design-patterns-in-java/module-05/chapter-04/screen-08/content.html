Iterator behavior
  • Maintain a position index or node reference.
  • hasNext uses aggregate.getNumberOfBooks() to decide.
  • next uses aggregate.getBook(position) then increments position.
  • Throw NoSuchElementException when next is called with no elements left.
Code excerpt
<!-- LibraryIterator core -->
class LibraryIterator implements Iterator<Book> {
  private Library library;
  private int position = 0;
  public LibraryIterator(Library library) { this.library = library; }
  @Override public boolean hasNext() { return position < library.getNumberOfBooks(); }
  @Override public Book next() {
    if (!hasNext()) throw new NoSuchElementException();
    return library.getBook(position++);
  }
  @Override public void remove() {
    throw new UnsupportedOperationException("Remove not supported");
  }
}
Test the iterator on empty and non-empty libraries to confirm correct exceptions and traversal order.
