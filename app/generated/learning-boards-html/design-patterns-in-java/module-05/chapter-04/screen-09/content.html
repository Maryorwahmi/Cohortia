Module 5 › Chapter 5.4 › Iterable & for-each
Why implement Iterable
It lets clients use concise for-each loops while your class still returns a standard iterator. Returning a fresh iterator each call ensures multiple traversals can run concurrently without shared state.
Quick reminder
for-each is syntactic sugar for iterator-based traversal; behavior and safety follow iterator contracts.
Code example
// After Library implements Iterable<Book>
for (Book book : library) {
  System.out.println("Reading: " + book);
}

// Compiler translates this into use of iterator(), hasNext(), next()
Ensure iterator() returns a new iterator instance each call so loops don't interfere with one another.
