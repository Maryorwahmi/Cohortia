Module 5 › Chapter 5.4 › Pattern Roles
Iterator Interface
hasNext(), next(), optional remove()
  • hasNext signals whether more elements are available.
  • next returns the next element and advances iterator state.
  • remove, if supported, allows safe removal through the iterator.
Aggregate Interface
iterator() or createIterator()
  • Returns a Concrete Iterator associated with the aggregate.
  • Keeps storage private; clients never access internal arrays or nodes directly.
  • Can offer multiple iterator factories for different traversal strategies.
Concrete Aggregate
Implements the aggregate interface and returns a suitable iterator instance.
Concrete Iterator
Maintains traversal position and accesses elements through aggregate methods.
Client
Uses only the iterator interface, remaining independent of storage details.
