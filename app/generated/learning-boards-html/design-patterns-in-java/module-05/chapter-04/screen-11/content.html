Module 5 › Chapter 5.4 › Traversal Strategies
Strategy examples
  • Forward iterator: standard sequential order.
  • Reverse iterator: tracks from tail to head or uses index reverse.
  • Filtered iterator: returns only elements matching a condition.
Design pattern
Offer multiple createIterator methods or a single factory that accepts a traversal parameter. Clients remain oblivious to internal storage while gaining flexible traversal options.
Analogy
Like different folders that present the same photos in different orders: the storage is the same, presentation varies.
