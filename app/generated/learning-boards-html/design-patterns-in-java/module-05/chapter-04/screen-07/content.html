Module 5 › Chapter 5.4 › Library Aggregate
Explanation
The Library stores Book objects and exposes addBook, getBook, and getNumberOfBooks. It implements Iterable so it can be used with the enhanced for-loop by returning an iterator instance.
Design tip
Keep accessors minimal and targeted for iterator use to maintain encapsulation.
Code excerpt
<!-- Library: key methods -->
class Library implements BookCollection, Iterable<Book> {
  private List<Book> books = new ArrayList<>();
  public void addBook(Book book) { books.add(book); }
  public Book getBook(int index) { return books.get(index); }
  public int getNumberOfBooks() { return books.size(); }
  public Iterator<Book> createIterator() { return new LibraryIterator(this); }
  @Override public Iterator<Book> iterator() { return createIterator(); }
}
This excerpt shows the aggregate methods the iterator relies on rather than exposing the list directly.
