Design notes
  • Keep buildHouse() final so the overall construction sequence is enforced.
  • Provide concrete layFoundation() and installWindows() in the base class.
  • Implement buildWalls(), addRoof(), and paintHouse() in concrete builders.
  • Consider an optional customLandscaping() hook for extension without burden.
Why this helps
Centralizing common steps prevents duplication and ensures every house follows the same lifecycle.
Starter code (excerpt)
// AbstractHouseBuilder
abstract class AbstractHouseBuilder {
  public final void buildHouse() {
    layFoundation();
    buildWalls();
    addRoof();
    installWindows();
    paintHouse();
    System.out.println("House construction complete!");
  }

  protected abstract void buildWalls();
  protected abstract void addRoof();
  protected abstract void paintHouse();

  private void layFoundation() {
    System.out.println("Laying concrete foundation with steel reinforcement.");
  }

  private void installWindows() {
    System.out.println("Installing standard double-pane windows.");
  }
}

// Concrete builders implement the abstract methods
