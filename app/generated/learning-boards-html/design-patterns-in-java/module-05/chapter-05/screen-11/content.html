Assessment task

Design AbstractETLProcess with runETL() calling extractData(), transformData(), loadData(). Implement at least two concrete ETL processes and a test that confirms the shared sequence runs for both.

Code sketch
abstract class AbstractETLProcess {
  public final void runETL() {
    extractData();
    transformData();
    loadData();
  }

  protected abstract void extractData();
  protected abstract void transformData();
  protected abstract void loadData();
}
Check
Is runETL final? Are primitives protected? Is error handling centralized or provided via hooks?
Misconception
Putting extract, transform, and load in a single concrete class without a template reduces reuse and makes enforcing sequence harder.
