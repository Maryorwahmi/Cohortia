Module 6 › Chapter 5.5 › Comparison
Primitive operations (must implement)
  • Declared abstract; subclasses must provide behavior.
  • Used when a step is essential and varies across implementations.
  • Visibility typically protected to restrict external calls.
Example
formatBody() for different report types.
Hook methods (optional)
  • Provide default implementation; subclasses may override.
  • Useful for optional steps like extra logging or post-processing.
  • Reduce subclass burden by supplying safe defaults.
Example
customerWantsCondiments() in BeverageMaker.
Common mistake
Making too many abstract methods forces repetitive implementations; prefer concrete defaults when behavior is shared.
