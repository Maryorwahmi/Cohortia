Module 6 › Chapter 5.5 › Learning Objectives
Implementation checklist
  • Define an abstract base class with a final template method that sequences steps.
  • Declare primitive operations as protected abstract methods.
  • Provide concrete methods for invariant behavior and hook methods with safe defaults.
  • Create concrete subclasses that implement primitives and optionally override hooks.
Analysis checklist
  • Ensure subclasses can substitute without altering algorithm semantics.
  • Avoid making trivial steps abstract; prefer sensible defaults.
  • Consider resource cleanup and thread-safety in the template or hooks.
  • Keep the template final to protect algorithm integrity.
Verified Competency Milestone
Implement AbstractHouseBuilder and both concrete builders from the chapter, run them, and confirm both build sequences complete with the same steps in order.
