Module 6 › Chapter 5.5 › Use Cases & Examples
Frameworks
Frameworks define the flow and call developer-provided implementation points; this enforces a contract between framework and app code.
ETL Pipelines
A fixed extract-transform-load sequence with varying extractors and transformers maps well to a template method.
Report Generators
Different formats require different formatBody implementations but share the fetch/process/save sequence.
When not to use
If subclasses must reorder steps or if variation is better handled by composing interchangeable strategies, prefer composition over the template method.
