Structure to observe
  • template method declared final to prevent reorder or omission of steps.
  • private concrete methods for invariant operations like boiling water.
  • protected abstract methods for primitives to let subclasses implement them.
  • hooks with default behavior to make extension optional.
Check your understanding

Can a subclass change the order of operations? No, the template is final and prevents that.

Example code (excerpt)
<!-- Abstract base: BeverageMaker -->
abstract class BeverageMaker {

  public final void prepareBeverage() {
    boilWater();
    brew();
    pourInCup();
    addCondiments(); // hook or primitive
  }

  protected abstract void brew();
  protected abstract void addCondiments();

  private void boilWater() {
    System.out.println("Boiling water");
  }

  private void pourInCup() {
    System.out.println("Pouring into cup");
  }

  protected boolean customerWantsCondiments() {
    return true; // default hook
  }
}

// Concrete Coffee and Tea implement brew and addCondiments
