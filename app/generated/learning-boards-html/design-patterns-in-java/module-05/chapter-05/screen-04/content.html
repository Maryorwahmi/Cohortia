Module 6 › Chapter 5.5 › Definition
Formal definition

An abstract class defines a template method that outlines the algorithm and calls primitive operations. Subclasses implement the primitive operations; hook methods provide optional behavior with safe defaults.

Analogy
A recipe lists required steps; different cooks provide their own spices and techniques but follow the same sequence.
Misconception
Inheritance is not forbidden — it's the mechanism used to share the algorithm structure while allowing variation through primitives.
Pattern anatomy
Abstract Class
Holds the template method and some concrete methods.
Template Method
Final method that enforces step order.
Primitive Ops
Abstract methods implemented by subclasses.
Hook Methods
Optional overrides with safe defaults.
Why it matters

Centralizing control flow prevents duplicated sequence code, ensuring consistent execution order across implementations and simplifying maintenance.
