Module 1 › Chapter 1.1 › Hands-on Activity
Task
  1. Refactor Employee fields to private and add getters/setters with validation.
  2. Create Manager extends Employee and override displayInfo.
  3. Write a main that stores Employee and Manager in an Employee[] and calls displayInfo.
Success criteria: negative salaries rejected; Manager info displays department when invoked via Employee reference.
Starter & Test Snippet
public class TestRefactor {
  public static void main(String[] args) {
    Employee e = new Employee("Alice", "E1", 50000);
    Manager m = new Manager("Bob", "M1", 70000, "Engineering");

    Employee[] arr = new Employee[]{ e, m };
    for (Employee em : arr) {
      em.displayInfo(); // Should show Manager department for Bob
    }

    e.setSalary(-100); // Should be rejected by validation
  }
}
