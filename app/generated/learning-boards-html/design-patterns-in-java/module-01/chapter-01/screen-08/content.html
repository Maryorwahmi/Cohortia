Core Concept

Polymorphism: Many forms from one interface

Treat different concrete types through a common supertype and rely on overridden behavior at runtime.

Runtime vs Compile-time
Overriding supports runtime polymorphism; overloading is resolved at compile time.
Design tip
Favor polymorphic designs over type checks; use interfaces to express shared capability.
Key Takeaway

Polymorphism enables flexible code by letting different objects respond appropriately to the same method call.

Polymorphism Example
class Shape {
  public void draw() {
    System.out.println("Drawing a generic shape.");
  }
}

class Circle extends Shape {
  @Override
  public void draw() {
    System.out.println("Drawing a Circle.");
  }
}

class Rectangle extends Shape {
  @Override
  public void draw() {
    System.out.println("Drawing a Rectangle.");
  }
}

// Usage
Shape[] shapes = new Shape[]{ new Circle(), new Rectangle(), new Shape() };
for (Shape s : shapes) {
  s.draw();
}
Common Mistake

Relying on instanceof checks to branch logic often means the design lacks an appropriate polymorphic abstraction.
