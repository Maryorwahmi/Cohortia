Core Concept

Abstraction: Hiding complexity behind contracts

Define what an object does with abstract classes or interfaces so callers don't depend on implementation details.

Benefit: Loose coupling and easier substitution of implementations.
Pitfall: Too many abstract layers create confusion; prefer concise contracts.
Interface and Abstract Class Notes
  • abstract class: mix abstract and concrete methods, not instantiable.
  • interface: defines a contract; implementations provide behavior.
  • Since Java 8, interfaces can include default and static methods to share small implementations.
Example capability names from the chapter: Flyable, Runnable — interfaces express a can-do relationship.
