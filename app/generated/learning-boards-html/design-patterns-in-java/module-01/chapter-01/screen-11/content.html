Encapsulation → State/Strategy

Keep internal state safe and swap behaviors without exposing details.

Inheritance → Template Method

Define an algorithm skeleton and let subclasses override specific steps.

Polymorphism → Strategy/Command

Invoke different concrete behavior through a shared interface at runtime.

Practical tip

When you learn a new pattern, ask which OOP pillar it applies. This simplifies understanding and shows how to combine patterns safely.
