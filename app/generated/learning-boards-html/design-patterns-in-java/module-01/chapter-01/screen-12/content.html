Module 1 › Chapter 1.1 › Anti-patterns
Public Fields

Exposing fields directly breaks encapsulation and couples callers to internal structure.

Misused Inheritance

Inheriting for code reuse rather than modeling a true subtype leads to rigid hierarchies.

instanceof Overuse

Frequent type checks are a smell; prefer polymorphic methods to dispatch behavior.

Over-abstracting

Too many abstract layers add complexity without delivering clearer design.

Check Your Understanding

Review a class: can you state who owns the data, what invariants must hold, and whether a subtype truly satisfies the parent's contract?
