Module 1 › Chapter 1.1 › Composition vs Inheritance
Inheritance

Use when 'is-a' fits

  • Subclass should be substitutable for superclass.
  • Shared state and behavior belong in the parent.
  • Example: Car extends Vehicle.
Composition

Use when 'has-a' fits

  • Compose objects to add capabilities and swap implementations.
  • Reduces coupling and supports testing by mocking components.
  • Example: Vehicle has an Engine interface implemented by different engines.
Analogy

Think of inheritance as a species taxonomy and composition as assembling parts: species membership is fixed, while parts can be swapped or upgraded.

Pro tip: Favor composition for new designs unless a clear subtype relationship exists.
