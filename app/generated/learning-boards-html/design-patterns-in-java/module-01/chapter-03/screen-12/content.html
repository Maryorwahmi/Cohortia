Module 1 › Chapter 1.3 › Hands-on Mapping
Activity

For each scenario, name the primary problem and pick Creational, Structural, or Behavioral. Justify your choice in one sentence.

Scenario A: Complex Report construction with optional sections → Creational (Builder suits multi-step, configurable construction).
Scenario B: Legacy PaymentGateway incompatible with new ShoppingCart → Structural (Adapter translates interfaces to integrate systems).
Scenario C: Multiple UI parts update automatically on events → Behavioral (Observer defines one-to-many updates on state changes).
Scenario D: Single globally accessible configuration manager → Creational (Singleton controls instantiation and global access).
Scenario E: Switch sorting algorithms at runtime → Behavioral (Strategy encapsulates interchangeable algorithms for runtime selection).
Reflection
When mapping, always focus on the central design intent: creation, composition, or communication. That focus guides the correct category choice.
