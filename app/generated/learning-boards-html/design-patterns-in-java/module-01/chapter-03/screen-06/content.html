Module 1 › Chapter 1.3 › Pattern Categories
Creational

Object creation mechanisms

Aim to create objects in ways suited to different situations, increasing flexibility and reuse.

Examples: Singleton, Factory Method, Builder.
Structural

Composition of classes and objects

Help form larger structures while keeping parts flexible and interchangeable.

Examples: Adapter, Decorator, Facade.
Behavioral

Algorithms and object responsibilities

Describe object communication, assigning responsibilities and defining interaction patterns.

Examples: Observer, Strategy, Command.
Categorization tip
Focus on the pattern's primary intent when classifying it. A pattern may touch multiple concerns, but its category reflects the main design problem it solves.
