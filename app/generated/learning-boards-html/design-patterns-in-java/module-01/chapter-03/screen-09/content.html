Module 1 › Chapter 1.3 › Behavioral Patterns
Intent

Define communication and control

Behavioral patterns specify how objects interact and assign responsibilities so systems behave flexibly at runtime.

Observer: a subject notifies many observers automatically on changes.
Strategy: encapsulate interchangeable algorithms and swap them at runtime.
Command: wrap a request as an object to decouple requester and executor.
When to use
When you need decoupled communication, runtime algorithm selection, or objects to collaborate without tight dependencies.
Example: many UI components subscribed to updates use Observer to receive change notifications.
Misconception: behavioral patterns are not only about moving methods; they intentionally reassign responsibility to improve flexibility.
