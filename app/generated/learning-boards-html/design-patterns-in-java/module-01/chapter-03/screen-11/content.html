Module 1 › Chapter 1.3 › Common Mistakes
Watch out for
Over-engineering: applying a pattern where a simple solution suffices, increasing indirection and boilerplate.
Wrong pattern: choosing a pattern whose intent doesn't match the problem, leading to confusion.
Global state via Singleton: using Singleton for mutable global state causes hidden coupling and testing pain.
Check: does the pattern make the intent clearer and reduce duplication?
If not, prefer the simpler approach.
