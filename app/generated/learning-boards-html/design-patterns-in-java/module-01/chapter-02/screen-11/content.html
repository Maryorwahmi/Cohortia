Module 1 › Chapter 1.2 › Encapsulation
Pattern: Private Fields + Accessors
Use private fields and expose controlled methods to read or mutate state. Validate inputs in setters or constructors.
Avoid
Returning an internal mutable list directly; instead, return a copy or unmodifiable view.
Example Code
public class Person {
  private String name;

  public Person(String name) {
    if (name == null || name.isEmpty()) throw new IllegalArgumentException("name required");
    this.name = name;
  }

  public String getName() { return name; }
}
Key Takeaway

Encapsulation enforces invariants and enables safe refactoring; validate inputs early and avoid exposing internals.
