Starter Interface
// Loggable interface
author: chapter source
public interface Loggable {
  void log(String message);
}
Interface declares a contract: any implementing class must provide a log method. It does not hold instance state.
ConsoleLogger Implementation
public class ConsoleLogger implements Loggable {
  private static int logCount = 0;

  @Override
  public void log(String message) {
    System.out.println("[LOG] " + message);
    logCount++;
  }

  public static int getTotalLogs() {
    return logCount;
  }
}

// Usage
ConsoleLogger a = new ConsoleLogger();
ConsoleLogger b = new ConsoleLogger();
a.log("first");
b.log("second");
System.out.println(ConsoleLogger.getTotalLogs()); // prints 2
Misconception

Static fields are a substitute for good design. Prefer instance-based injections unless global sharing is required.
