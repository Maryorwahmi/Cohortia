Module 1 › Chapter 1.2 › Class vs Object
Definition
Class: blueprint describing fields and methods. Object: an instance with concrete values in memory.
Analogy
A machine design (class) produces widgets (objects). The design does not change per widget; each widget holds its own measurements.
Concrete Example
Book class with title, author, isbn fields. new Book("1984", "Orwell") creates an object with those values.
Common Misconception
A class does not hold instance-specific runtime data; only objects do. Confusing the two leads to incorrect designs and bugs.
Example Code
// Class definition
public class Book {
  private String title;
  private String author;

  public Book(String title, String author) {
    this.title = title;
    this.author = author;
  }
}

// Instantiation
Book b = new Book("1984", "George Orwell");
Key Takeaway

Decide whether data belongs to the type or to each instance before choosing static or instance fields.
