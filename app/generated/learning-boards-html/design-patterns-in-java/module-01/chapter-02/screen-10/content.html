Modifier Cheat Sheet
  • public: accessible from anywhere.
  • private: accessible only within the class.
  • protected: accessible in subclasses and same package.
  • default: accessible only within the same package.
Practical Example
Keep fields private. Provide public getters and controlled setters. Use protected only when subclassing requires narrow extension points.
Common Mistake
Making fields public to simplify access increases coupling and breaks encapsulation.
Check Your Design

Ask whether external code truly needs direct access. If not, keep it private and offer controlled accessors.
