Module 1 › Chapter 1.2 › Pitfalls & Best Practices
Avoid Overusing Static
Static creates shared state that's hard to test. Use it for constants and pure utilities only.
Hide Implementation
Prefer private fields and controlled accessors over exposing public fields to maintain encapsulation.
Evolve Interfaces Carefully
Use default methods only to add small, non-breaking behavior; avoid heavy logic in interfaces.
Reflection

Which of your recent classes would break tests due to a static counter or public field? Consider refactoring to reduce hidden coupling.
