Module 1 › Chapter 1.2 › Static vs Instance
Instance
  • Each object has its own copy of instance fields.
  • Instance methods operate on that object's state.
  • Use for properties that vary per object (e.g., color, name).
Example
Car car1 = new Car("red"); Car car2 = new Car("blue"); car1 and car2 have different colors stored as instance fields.
Static
  • Owned by the class; a single copy shared across all instances.
  • Static methods can be called without an object.
  • Commonly used for constants and utilities.
Misconception
Static equals convenient global state. Prefer instance-based design for testability unless sharing is intentional.
Check

If you reset this value for one object and all objects reflect the change, it is static.

Pro Tip
Keep static methods pure and side-effect free when possible to avoid global state complications.
