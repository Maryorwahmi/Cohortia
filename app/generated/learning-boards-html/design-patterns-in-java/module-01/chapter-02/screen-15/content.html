Module 1 › Chapter 1.2 › Quick Reference
Static
One copy per class. Use for true class-level data or utilities.
Interface
Define behavior contracts. Implementations provide concrete logic.
Access Control
Limit visibility to protect internals. Prefer private fields with controlled accessors.
Final Prompt

When you design a new class, ask: what should be shared, what should be per-instance, and which behaviors are best expressed as an interface?
