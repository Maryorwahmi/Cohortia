What an Interface Is
A contract declaring methods a class must implement. It enables polymorphism and loose coupling.
Default Methods
Provide a default implementation that implementing classes may override. Useful for evolving APIs.
Misconception
Interfaces do not hold per-instance mutable state. They describe behavior, not instance data.
Example: PaymentProcessor
public interface PaymentProcessor {
  void processPayment(double amount);

  default void logAttempt() {
    System.out.println("Processing payment...");
  }
}

public class CreditCardProcessor implements PaymentProcessor {
  @Override
  public void processPayment(double amount) { /* implementation */ }
}
Key Takeaway

Design interfaces for behavior, keep them small, and use default methods sparingly to evolve APIs without breaking implementations.
