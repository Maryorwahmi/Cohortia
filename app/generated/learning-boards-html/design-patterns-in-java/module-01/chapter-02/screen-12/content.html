Starter Code (Interface)
// 1. Define the Loggable interface
public interface Loggable {
  void log(String message);
}
This interface defines the required log behavior. Any class that implements it must provide a log method.
ConsoleLogger Implementation
public class ConsoleLogger implements Loggable {
  private static int logCount = 0;

  @Override
  public void log(String message) {
    System.out.println("[LOG] " + message);
    logCount++;
  }

  public static int getTotalLogs() { return logCount; }
}

public class LoggingDemo {
  public static void main(String[] args) {
    ConsoleLogger l1 = new ConsoleLogger();
    ConsoleLogger l2 = new ConsoleLogger();

    l1.log("first");
    l2.log("second");
    l1.log("third");

    System.out.println(ConsoleLogger.getTotalLogs()); // expected output: 3
  }
}
Testing Note

Remember to reset static state between tests or design tests that do not rely on global counters to avoid inter-test interference.
