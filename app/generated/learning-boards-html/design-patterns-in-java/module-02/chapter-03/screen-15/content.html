Module 3 › Chapter 2.3 › Quick Reference
Interface design
Keep AbstractProduct interfaces small so clients depend only on needed behavior.
Factory responsibility
ConcreteFactories should only assemble and return matching ConcreteProducts; avoid extra logic inside factories.
Plan for change
Expect maintenance when adding new product types; prefer Abstract Factory when families are stable.
Summary takeaway

Abstract Factory enforces family consistency and decouples clients from concrete classes. Use it when matched product families and runtime swapping are important, and plan for the maintenance cost of adding new product types.
