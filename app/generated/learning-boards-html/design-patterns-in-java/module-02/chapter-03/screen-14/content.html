Module 3 › Chapter 2.3 › Key Concepts
Family consistency
A single factory instance creates matching products so families remain consistent at runtime.
Decoupling
Clients depend only on abstract factories and product interfaces, simplifying testing and swapability.
Trade-offs
Adding new product types requires interface and factory changes; adding new families is straightforward.
Final takeaway

Use Abstract Factory to enforce family-wide consistency and decouple clients from concrete classes. Balance its benefits against maintenance costs when product types change frequently.
