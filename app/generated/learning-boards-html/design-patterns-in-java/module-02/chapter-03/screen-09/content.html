Module 3 › Chapter 2.3 › Concrete Factories
WindowsFactory
// Concrete Factory for Windows
public class WindowsFactory implements GUIFactory {
    @Override
    public Button createButton() {
        return new WindowsButton();
    }

    @Override
    public Checkbox createCheckbox() {
        return new WindowsCheckbox();
    }
}

Implementation tip

Keep factories focused on construction. If products require complex setup, delegate that to builder helpers invoked by the factory rather than embedding complex workflows inside factory methods.
