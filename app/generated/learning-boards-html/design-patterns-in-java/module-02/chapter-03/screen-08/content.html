GUIFactory: the creation contract
This interface forces every concrete factory to provide methods for each product type used by the client.
// Abstract Factory
public interface GUIFactory {
    Button createButton();
    Checkbox createCheckbox();
}
Benefit
Compile-time guarantee that concrete factories create all needed product types.
Trade-off
Adding a new product type requires changing the interface and every concrete factory implementation.
