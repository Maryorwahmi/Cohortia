Visual concept
Factory Family
An abstract factory exposes methods to create each product type in a family.
Concrete Family
A concrete factory returns matching concrete products for one family, such as Windows or macOS.
Client
Client code asks the factory for products by their abstract types and never depends on concrete product classes.
