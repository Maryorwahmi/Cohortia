Eager Initialization
Instance created when class is loaded; simple and thread-safe.
<!-- EagerSingleton.java -->
public class EagerSingleton {
  // The single instance is created when the class is loaded
  private static final EagerSingleton instance = new EagerSingleton();

  // Private constructor to prevent direct instantiation
  private EagerSingleton() {
    System.out.println("EagerSingleton instance created.");
  }

  // Public static method to provide the global access point
  public static EagerSingleton getInstance() {
    return instance;
  }

  public void showMessage() {
    System.out.println("Hello from EagerSingleton!");
  }
}
Explanation & example
  • Thread-safe because the JVM ensures class initialization happens once.
  • Good when instance creation is cheap or always required at startup.
  • Not suitable when instance creation is expensive and rarely used.
Common mistake

Assuming eager solves reflection or serialization issues. It does not; those require separate safeguards.
