Module 2 › Chapter 2.1 › ConfigurationManager Exercise
Starter guidance

Implement the ConfigurationManager as an enum singleton or another robust Singleton. Initialize a map of properties only once and expose getProperty(key).

// Suggested approach (conceptual)
public enum ConfigurationManager {
  INSTANCE;

  private Map<String,String> properties;

  ConfigurationManager() {
    properties = new HashMap<>();
    properties.put("appName", "MyAwesomeApp");
    properties.put("version", "1.0.0");
    properties.put("databaseUrl", "jdbc:mysql://localhost:3306/myapp_db");
    System.out.println("ConfigurationManager: Properties loaded.");
  }

  public String getProperty(String key) {
    return properties.get(key);
  }
}
Validation checklist
  • Call getInstance multiple times; confirm identity is consistent.
  • Test concurrent getInstance calls to see a single initialization message.
  • If using serialization, serialize and deserialize and confirm instance identity with readResolve or enum semantics.
Common mistake

Initializing properties on every method call instead of in the constructor or enum initializer defeats the Singleton's single-initialization advantage.
