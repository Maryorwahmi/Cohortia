Enum Singleton

Declare a single enum constant to create a robust Singleton that handles serialization and reflection.

// EnumSingleton.java
public enum EnumSingleton {
  INSTANCE; // The single instance

  public void showMessage() {
    System.out.println("Hello from EnumSingleton!");
  }
}
Pros & cons
  • Pros: simple, thread-safe, handles serialization and many reflection issues automatically.
  • Cons: enforces a single instance across the JVM, which can reduce test flexibility and make multi-context scenarios harder.
  • When in doubt, prefer enum for truly global services; prefer DI where flexibility matters.
Key Takeaway

Enum singletons are the recommended robust approach in Java; weigh testability and coupling before adopting a Singleton.
