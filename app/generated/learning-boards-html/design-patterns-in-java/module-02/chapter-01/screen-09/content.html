Reflection can bypass private constructors

Using reflection, a caller can make a private constructor accessible and call it to create a new instance, breaking the Singleton guarantee.

Example concept: obtain the declared constructor, set it accessible, and invoke newInstance to create a second instance. This is shown conceptually in the chapter and demonstrates the attack surface.
Mitigation strategies
  • Add a guard in the constructor that throws if an instance already exists.
  • Use enum singletons which prevent reflective creation of enum constants.
  • Understand this raises the bar but does not make reflection impossible in every environment.
Pro Tip

If reflection is a realistic threat in your runtime, prefer enum Singletons and constructor guards together.
