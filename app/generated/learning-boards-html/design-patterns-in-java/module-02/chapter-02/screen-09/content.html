Module 2 › Chapter 2.2 › Factory Method vs Simple Factory
Simple / Static Factory
  • Single static method returns different concrete types based on input.
  • Easy to implement but must be edited for new products.
  • Tends to centralize creation logic into one class.
Factory Method (GoF)
  • Uses inheritance: Creator declares factory, ConcreteCreators override it.
  • Add new types by adding classes, not modifying existing factories.
  • Supports polymorphism and aligns with Open/Closed Principle.
When to choose which
Prefer static factory when types are stable and you want simplicity.
Prefer Factory Method when you expect frequent extension and want polymorphic factories.
