Module 2 › Chapter 2.2 › ConcreteCreators & Client
Concrete Creators
// Concrete Creators
public class WordDocumentCreator extends DocumentCreator {
  @Override
  public Document createDocument() {
    return new WordDocument();
  }
}

public class PdfDocumentCreator extends DocumentCreator {
  @Override
  public Document createDocument() {
    return new PdfDocument();
  }
}
Client Example
// Client code
public class Application {
  public static void main(String[] args) {
    DocumentCreator wordCreator = new WordDocumentCreator();
    wordCreator.processNewDocument(); // Creates and processes a WordDocument

    DocumentCreator pdfCreator = new PdfDocumentCreator();
    pdfCreator.processNewDocument(); // Creates and processes a PdfDocument
  }
}
Key Takeaway

Clients work with Creator and Product abstractions; ConcreteCreators are the only classes that know about concrete products.

Misconception

Don't let client code call new ConcreteProduct directly; choose a Creator and invoke its operations instead.
