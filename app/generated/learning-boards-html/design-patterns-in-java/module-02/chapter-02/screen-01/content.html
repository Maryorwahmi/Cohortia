Factory Method

Learn why deferring instantiation to subclasses makes your Java code open to extension and closed to modification.

In this lesson: understand participants, refactor a tightly coupled example, and implement a logger factory exercise to practice.
Why it matters

Directly creating concrete objects scatters knowledge of specific classes across clients. The Factory Method groups creation logic into a Creator hierarchy so clients work with the Product interface only.

Problem
Tight coupling via new operators and if/else chains.
Pattern
Creator declares factory method; ConcreteCreators return ConcreteProducts.
Benefit
Add products by adding classes, not by modifying clients.
Visual concept
Creator
Declares factory method; uses Product in operations.
Product
Interface or abstract class for created objects.
ConcreteCreator
Overrides factory to return a ConcreteProduct.
ConcreteProduct
Implements Product behavior.
