Module 2 › Chapter 2.2 › What is the Factory Method?
Definition

Factory Method explained

The Factory Method declares a method for creating a Product and lets subclasses decide which ConcreteProduct to return. This moves 'new' out of client code.

Quick cards
Product: interface or abstract type that clients use.
Creator: declares the factory method and may use the Product in operations.
ConcreteCreator: overrides factory to return a specific ConcreteProduct.
Analogy

Think of a restaurant menu. The menu (Creator) defines a dish category. Different chefs (ConcreteCreators) prepare a specific dish (ConcreteProduct) that conforms to the category (Product). Diners order by category, not by chef implementation.

Common misconception
A static factory that switches on a type string is not the GoF Factory Method. The Factory Method uses subclassing and polymorphism to decide the concrete type.
Key Takeaway

Deferring creation via a factory method reduces client knowledge of concrete classes and enables safe extension.
