Module 2 › Chapter 2.2 › Pitfalls & Best Practices
Common Mistakes
  • Overuse when only one product exists.
  • Creating a single 'god' factory that knows everything.
  • Mixing product-specific APIs into the Product interface.
Best Practices
  • Keep Product interfaces minimal and stable.
  • Give each creator a focused responsibility and configuration.
  • Mock Creator or Product interfaces in tests for isolation.
Check your understanding

Identify one constructor call in your code that, if replaced by a Creator, would avoid editing multiple clients when adding a new type.
