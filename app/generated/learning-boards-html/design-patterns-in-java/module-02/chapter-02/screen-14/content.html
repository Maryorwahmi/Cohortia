Module 2 › Chapter 2.2 › Key Concepts
Factory Method Pattern
Defines a method for creating objects and defers the exact class to subclasses.
Pattern Roles
Product, ConcreteProduct, Creator and ConcreteCreator each have focused responsibilities.
Open/Closed Principle
Add new product types by adding classes, not by modifying existing client code.
Takeaway

Use Factory Method to move construction into a polymorphic creator hierarchy so your codebase becomes easier to extend and maintain.
