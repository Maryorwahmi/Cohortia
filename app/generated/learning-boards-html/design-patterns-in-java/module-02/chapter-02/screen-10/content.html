Module 2 › Chapter 2.2 › Advantages
Decoupling

Clients program to the Product interface and do not need to import concrete classes. This reduces dependencies and simplifies testing.

Extensibility

Add a new ConcreteProduct and ConcreteCreator to extend behavior without modifying existing code.

Flexibility

ConcreteCreators can return decorated or specialized products, enabling variation without client changes.

Centralized creation

Creation logic lives in creators, making it easier to change initialization policies or add logging and instrumentation.

Tradeoff

The pattern adds classes and indirection. Use it when extension, polymorphism, or centralized creation adds measurable value.
