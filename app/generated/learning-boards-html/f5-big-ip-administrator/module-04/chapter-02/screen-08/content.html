Dynamic HTTP Header Manipulation

The `HTTP::header` command family provides functions to `insert`, `remove`, or `replace` HTTP headers in requests or responses.

  • •**Insert:** Add new headers (e.g., `X-Forwarded-For` for client IP).
  • •**Remove:** Strip unwanted or sensitive headers (e.g., `Cookie`, `Server`).
  • •**Replace:** Modify existing header values (e.g., `User-Agent`).
Caution: Application Impact

Incorrect header modifications can break application functionality or introduce security vulnerabilities. Always understand the impact and test thoroughly.

Key Takeaway

HTTP header manipulation offers granular control over traffic, enabling advanced security, logging, and application compatibility features.

iRule Code ExampleHeader Control
when HTTP_REQUEST {
    # Insert X-Forwarded-For header with client IP
    HTTP::header insert X-Forwarded-For [IP::client_addr]
    log local0. "Inserted X-Forwarded-For: [IP::client_addr]"

    # Remove a specific cookie for security reasons
    if { [HTTP::cookie exists "sensitive_cookie"] } {
        HTTP::header remove Cookie "sensitive_cookie"
        log local0. "Removed sensitive_cookie"
    }
}

when HTTP_RESPONSE {
    # Remove the 'Server' header from backend responses
    HTTP::header remove Server
    log local0. "Removed Server header from response"
}
Example Scenario

A backend application needs to know the original client IP. An iRule inserts the `X-Client-IP` header with `[IP::client_addr]` before forwarding the request.
