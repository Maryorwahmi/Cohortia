Basic Tcl Syntax: Conditional Logic and String Manipulation

Control the flow of your iRule logic and transform data using Tcl's conditional statements and string commands.

Key Tcl Constructs

  • Conditional Logic (`if/else`): Execute code blocks based on specific conditions.
  • String Manipulation (`string` commands): Modify and analyze text data from traffic.
Key Takeaway

Conditional statements enable dynamic decision-making, while string commands facilitate data transformation within iRules.

Tcl Conditionals & String Operations

when HTTP_REQUEST {
    # Get the URI and convert it to lowercase for case-insensitive comparison
    set uri_path [string tolower [HTTP::uri]]

    # Conditional statement: Check if the URI starts with "/admin"
    if { $uri_path starts_with "/admin" } {
        # Log an alert for admin access attempts
        log local0. "Admin access attempt detected for $uri_path"
        # Example: You could also redirect or block here
    } else {
        # Log regular access
        log local0. "Regular access to $uri_path"
    }

    # Get the length of the URI path
    set uri_length [string length $uri_path]
    log local0. "URI length: $uri_length characters"
}
Syntax Tip

Pay close attention to the placement of square brackets [] for command substitution and curly braces {} for code blocks in Tcl.
