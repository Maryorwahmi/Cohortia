Basic Tcl Syntax: Variables and Comments

Learn how to declare variables and add comments to your iRules for clarity and maintainability.

Key Tcl Concepts

  • Variables (`set`): Store data for use within your iRule logic.
  • Comments (`#`): Document your code for readability and future reference.
Key Takeaway

Proper use of variables and comments is fundamental for writing clear, functional, and maintainable iRules.

Tcl Variables & Comments in Action

when HTTP_REQUEST {
    # Declare a variable to store the client's IP address
    set client_ip [IP::client_addr]

    # Declare a variable for a custom message
    set message "Request from $client_ip"

    # Log the message to the local system log
    log local0. $message

    # Example of another variable and its usage
    set admin_path "/admin"
    # We'll use this in conditional logic later!
}
Syntax Tip

Always enclose string values in double quotes when assigning them to variables, especially if they contain spaces or special characters.
