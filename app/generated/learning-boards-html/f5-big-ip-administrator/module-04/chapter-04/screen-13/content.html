Lab: Create Data Group Object & iRule

Integrating the external file into BIG-IP and enforcing policies.

iRule Definition

when CLIENT_ACCEPTED {
    # Check if the client IP matches any IP in the external data group
    if { [class match [IP::client_addr] equals my_blocked_ips_dg] } {
        log local0. "Blocked client [IP::client_addr] due to malicious IP data group match."
        drop
    }
}

This iRule uses class match to check client IPs against the data group and drops connections if a match is found.

Pro Tip

Ensure the data group name in the iRule exactly matches the object name created in the GUI, not the file path.

Step-by-Step: GUI Configuration
1.

Create External Data Group Object

Navigate to Local Traffic > Data Groups > External Data Group List. Click Create. Name it my_blocked_ips_dg, Type: Address, External File Name: /Common/blocked_ips.dg.

2.

Create the iRule

Navigate to Local Traffic > iRules > iRule List. Click Create. Name it block_malicious_ips_irule and paste the provided Tcl code.

Key Takeaway

The GUI object links the iRule to the external file, enabling dynamic policy enforcement without direct iRule modification.
