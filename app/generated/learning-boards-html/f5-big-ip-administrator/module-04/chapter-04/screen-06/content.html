External Data Group Example

How iRules leverage external data for dynamic traffic control.

External Data Group File Content
# This is a comment
192.168.1.100/32 := "Blocked for abuse"
10.0.0.0/8 := "Internal network"

This file defines IP addresses or networks and optional descriptions. It's stored on the BIG-IP file system.

iRule Using the Data Group
when CLIENT_ACCEPTED {
  if { [class match [IP::client_addr] equals blocked_ips] } {
    drop
  }
}

The iRule uses class match to check if the client IP is in the blocked_ips data group.
