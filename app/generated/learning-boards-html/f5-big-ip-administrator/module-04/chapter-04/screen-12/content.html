Lab: Create External Data Group File

Setting up the foundation for dynamic IP blocking via SSH.

Scenario: Block Malicious IPs

You need to block connections from a list of malicious IP addresses. We'll use an external data group and an iRule.

Pro Tip

Using external data groups for blacklists allows for quick updates without modifying BIG-IP configuration objects or iRules.

Step-by-Step: SSH File Creation
1.

Log in via SSH

Access your BIG-IP command line interface.

2.

Create Directory

mkdir -p /config/filestore/files_d/Common_d/external_data_groups_d/

3.

Create Data Group File

echo "1.1.1.1/32 := \"Malicious IP 1\"" > /config/filestore/files_d/Common_d/external_data_groups_d/blocked_ips.dg
echo "2.2.2.2/32 := \"Malicious IP 2\"" >> /config/filestore/files_d/Common_d/external_data_groups_d/blocked_ips.dg
4.

Verify File Content

cat /config/filestore/files_d/Common_d/external_data_groups_d/blocked_ips.dg

Key Takeaway

Creating the external data group file via SSH is the first step to enabling dynamic, file-based IP blacklisting in BIG-IP.
