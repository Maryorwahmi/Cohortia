Connection Mirroring: Preserving Active Sessions

Replicating Active Connection State for Uninterrupted User Experience

What is Connection Mirroring?

Connection mirroring is a vital feature that ensures seamless failover for active connections. When enabled, the active BIG-IP replicates connection state information to the standby unit.

  • Replicates TCP session tables and persistence records.
  • Allows the new active unit to pick up existing connections.
  • Prevents users from experiencing dropped sessions during failover.

Impact Without Mirroring

Active BIG-IP
Standby BIG-IP
Without mirroring, active connections are reset during failover.
Key Takeaway

Connection mirroring is crucial for maintaining active user sessions across failovers, ensuring an uninterrupted user experience.
