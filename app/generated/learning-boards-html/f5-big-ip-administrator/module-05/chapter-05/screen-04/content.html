Disaster Recovery vs. High Availability

Understanding the distinct roles of HA and DR in application resilience.

High Availability (HA)

  • •Focuses on mitigating local component failures.
  • •Operates within a single data center.
  • •Protects against issues like server crashes, network device failures.
  • •Ensures continuous operation of individual services.
Example

Redundant power supplies, clustered web servers, or dual network switches within one site.

Disaster Recovery (DR)

  • •Protects against catastrophic events affecting an entire data center.
  • •Involves deploying applications across multiple, geographically separated data centers.
  • •Ensures seamless redirection to alternative sites.
  • •Maintains business continuity during regional outages.
Example

Having a primary data center in New York and a secondary in London for failover.

Key Takeaway

HA is about component resilience within a site, while DR is about site resilience across multiple geographic locations.
