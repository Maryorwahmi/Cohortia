Wide IPs: Global DNS Entry Points

The foundation for intelligent global server load balancing.

Definition

What is a Wide IP?

A Wide IP is a global DNS record (e.g., www.example.com) that F5 BIG-IP DNS manages. It intelligently responds to DNS queries with the IP address of the most appropriate data center.

Global DNS Resolution

Acts as the authoritative DNS for the application across all sites.

Dynamic Traffic Steering

Directs users to the best performing or closest data center.

Key Takeaway

Wide IPs are the global entry points for your applications, enabling BIG-IP DNS to dynamically manage traffic at the DNS level.

Analogy

Think of a Wide IP as a smart phonebook entry that always gives you the best contact number for a service, no matter where you are or what's happening.
