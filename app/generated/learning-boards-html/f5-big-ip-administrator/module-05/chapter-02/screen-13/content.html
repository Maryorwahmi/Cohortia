Key Concepts to Remember

Essential AFM Terminology and Principles

Firewall Rules

Individual statements defining criteria (source, destination, port, protocol) and an action (accept, drop, reject) for network traffic.

Firewall Rule List

An ordered collection of firewall rules that are applied sequentially to traffic, with the first matching rule's action taking precedence.

Network Firewall Policy

A collection of firewall rule lists and other settings applied to specific BIG-IP objects to enforce security.
