Definition

Anatomy of an AFM Firewall Rule

Individual statements defining criteria and actions for network traffic.

Source/Destination IP

Defines the origin and target IP addresses or ranges for traffic.

Source/Destination Port

Specifies the port numbers used by the client and server for communication.

Protocol

Identifies the network protocol, such as TCP, UDP, or ICMP.

Action

Determines how matching traffic is handled: accept, drop, or reject.

Key Takeaway

Each rule component must be precisely defined to ensure effective and secure traffic filtering.

Rule Logic Flow

Match Destination Port?
