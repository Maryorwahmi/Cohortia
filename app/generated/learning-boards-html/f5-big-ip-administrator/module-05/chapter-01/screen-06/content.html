LTM Security

Basic DoS Protection with LTM

Mitigating common denial-of-service attacks at the traffic layer

LTM Capabilities

Key DoS Mitigation Features

  • HTTP Header Inspection: Drops malformed or suspicious HTTP requests.
  • Protocol Compliance: Enforces strict adherence to protocol standards, rejecting non-compliant traffic.
  • Connection Rate Limiting: Limits new connections per second to prevent resource exhaustion.
  • Source IP Throttling: Restricts traffic from sources exhibiting suspicious behavior.
Key Takeaway

F5 BIG-IP LTM provides essential basic DoS protection through traffic inspection, protocol enforcement, and rate limiting, acting as a first line of defense.

Example: Rate Limiting

Protecting a Login Page

A common target for DoS is a login page. An LTM virtual server can be configured with a connection rate limit of, say, 10 connections per second. If an attacker tries to flood the page with hundreds of requests per second, LTM will drop the excess connections, ensuring legitimate users can still access the login page without the backend servers being overwhelmed.

# Add a connection rate limit to the Virtual Server
tmsh modify /ltm virtual my_http_vs rate-limit 10 rate-limit-mode destination
tmsh save /sys config
Misconception

LTM is a Full DoS Solution

While LTM offers basic DoS protection, it's not a complete solution for advanced, sophisticated DoS attacks. For comprehensive DoS mitigation, specialized modules like AFM are required.
