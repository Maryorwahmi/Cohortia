Network Security

Advanced Firewall Manager (AFM)

High-performance, stateful network firewall at Layers 3 and 4

Layer 3/4 Protection: Operates at the network and transport layers, acting as a stateful firewall.

Granular Access Control: Enforces policies based on IP, port, protocol, and application context.

Advanced DoS Mitigation: Protects against sophisticated network-based DoS attacks like SYN floods.

Key Takeaway

F5 BIG-IP's AFM provides robust network-level firewall capabilities, offering granular access control and advanced DoS protection for your infrastructure.

AFM in Action

Protecting a Database Server

A critical database server should only accept connections from specific application servers on a particular port (e.g., SQL port 1433). AFM can enforce this policy, blocking all other incoming traffic, even if it originates from within the network. This prevents unauthorized access and reduces the attack surface for the database.

Key Distinction

AFM vs. Traditional Firewalls

AFM is an application-aware network firewall, meaning it can understand context beyond basic IP/port, unlike many traditional network firewalls. It integrates deeply with BIG-IP's traffic management.
