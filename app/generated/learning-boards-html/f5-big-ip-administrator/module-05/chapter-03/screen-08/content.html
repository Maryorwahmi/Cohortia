ASM's Learning Capabilities: Building Smart Policies

Automatically refining security policies through observation.

Observing Legitimate Traffic

ASM monitors normal application usage to understand expected behavior, including URLs, parameters, and input formats.

Automated Policy Suggestions

Based on observations, ASM suggests adding new entities or enforcing constraints to the security policy.

Minimizing False Positives

This iterative process helps create a highly accurate positive security policy, reducing legitimate traffic blocks.

Key Takeaway

ASM's learning mode observes legitimate traffic to automatically suggest and refine security policy rules, enhancing accuracy and reducing false positives.

1. Initial Policy (Blocking)

Only basic rules, many legitimate requests blocked.

2. Learning Mode (Transparent)

ASM observes traffic, suggests new allowed URLs/parameters.

3. Refined Policy (Blocking)

Accurate whitelist, minimal false positives, strong protection.
