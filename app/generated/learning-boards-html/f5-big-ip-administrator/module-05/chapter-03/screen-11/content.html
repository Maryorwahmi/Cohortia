Creating a Basic ASM Security Policy

Step-by-step guide to initial policy setup.

01

Create New ASM Policy

Define a new security policy, e.g., my_webapp_asm_policy, as the foundation for protection.

02

Associate with Virtual Server

Link the new policy to an existing HTTP Virtual Server (e.g., my_http_vs) to enable traffic inspection.

03

Set Transparent Enforcement

Configure the policy to 'Transparent' mode initially to log violations without blocking, allowing for fine-tuning.

04

Enable Learning Mode

Activate learning to observe legitimate traffic and automatically suggest policy enhancements.

Key Takeaway

Create an ASM policy, associate it with a Virtual Server, set to transparent mode, and enable learning to begin policy refinement.
