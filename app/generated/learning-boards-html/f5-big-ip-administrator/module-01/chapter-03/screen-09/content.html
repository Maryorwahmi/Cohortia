One-Arm Topology

Single Interface Deployment

BIG-IP connects to both clients and servers via a single network interface or VLAN, acting as a transparent proxy.

  • •
    Minimal Network Changes: Easy to integrate into existing networks.
  • •
    Use Case: SSL offloading, WAF functionality without routing re-architecture.
Visual Analogy

Like a sidecar attached to a motorcycle, handling specific tasks without being directly in the main path.

Two-Arm Topology

Inline Deployment

BIG-IP sits inline between client and server networks, using separate VLANs and interfaces for each, providing full segmentation.

  • •
    Maximum Control: Full network segmentation and traffic flow management.
  • •
    Use Case: Strong security, routing between distinct network segments (e.g., data center).
Visual Analogy

Like a bridge connecting two separate landmasses, controlling all traffic that passes between them.

Key Takeaway

Choosing between one-arm and two-arm topologies depends on the desired level of network control, segmentation, and integration complexity.
