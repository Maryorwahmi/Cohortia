Step 4: Save & Verify

Ensuring Persistence and Functionality

After configuration, save changes and verify network settings to confirm proper operation.

  • •
    Save Config: tmsh save sys config to persist changes.
  • •
    Verify VLAN: tmsh show net vlan internal_network.
  • •
    Verify Self-IP: tmsh show net self self_ip_internal.
  • •
    Verify Route: tmsh show net route.
Why it matters

Saving ensures configurations survive reboots, and verification confirms that all settings are active and functional.

Key Takeaway

Always save your configuration and perform thorough verification to prevent data loss and ensure network connectivity.

Terminal: Save & Verify Commands
# Save the configuration to make changes persistent
save sys config

# Verify the VLAN configuration
show net vlan internal_network

# Verify the Self-IP configuration
show net self self_ip_internal

# Verify the routing table
show net route

# Perform a live connectivity test (e.g., ping a device on the network)
ping 192.168.20.10 # Example: ping a server on the internal_network
Pro-Tip

Always perform a live connectivity test (e.g., ping) after configuration changes to confirm actual network reachability.
