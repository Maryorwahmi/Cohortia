Step 2: Create Self-IP

Assigning 192.168.20.254/24

We'll assign an IP address to the internal_network VLAN, allowing BIG-IP to communicate on that segment.

  • •
    Command: tmsh create net self
  • •
    Address: 192.168.20.254/24 (example).
  • •
    VLAN: vlan internal_network.
  • •
    Services: allow-service default (SSH, HTTPS, ICMP).
Why it matters

The Self-IP is BIG-IP's identity on the VLAN, enabling health checks, management, and sourcing traffic to devices on that segment.

Key Takeaway

A Self-IP is essential for BIG-IP to actively participate and communicate within a specific VLAN, enabling critical functions.

Terminal: Self-IP Creation
# Create a Self-IP for the new VLAN
# Assigns 192.168.20.254/24 to 'internal_network' VLAN
# 'allow-service default' permits SSH, HTTPS, ICMP
create net self self_ip_internal address 192.168.20.254/24 vlan internal_network allow-service default

# Note: Ensure the IP address and subnet mask align with your network plan.
# This IP will be used by BIG-IP to communicate on this VLAN.
Common Mistake

Using an incorrect subnet mask or placing the Self-IP on the wrong VLAN will prevent BIG-IP from communicating.
