Unified Access and Global Availability

Secure access and intelligent global traffic routing for distributed applications.

  • •APM: Single Sign-On (SSO), Multi-Factor Authentication (MFA), granular access control.
  • •BIG-IP DNS (GTM): Global Server Load Balancing (GSLB), disaster recovery.
  • •Optimized Experience: Directs users to the best-performing data center.
Key Takeaway

APM and BIG-IP DNS are crucial for managing secure user access and ensuring high availability and optimal performance for applications deployed across multiple geographic locations.

Access Policy Manager (APM)

Provides unified, secure access to applications and networks, including SSO, MFA, and granular access control.

BIG-IP DNS (GTM)

Offers global server load balancing (GSLB) to direct users to the closest or best-performing data center.

Example Scenario

A global company uses APM for employees to securely access internal applications from anywhere, while BIG-IP DNS ensures customers are always routed to the nearest, most responsive data center for their online services.
