iRule Debugging

Debugging iRules with log local0

Gain visibility into iRule execution and variable values by writing messages to the system log.

How it Works
  • log local0. "<message>": Writes a custom message to /var/log/ltm.
  • Include iRule variables (e.g., [IP::client_addr]) to inspect their values at runtime.
  • Monitor /var/log/ltm using tail -f to see messages in real-time.
Key Takeaway

log local0 provides essential runtime visibility, transforming iRule debugging from guesswork into a precise, data-driven process.

# Example iRule with log local0 statements
when HTTP_REQUEST {
  log local0. "HTTP Request received from [IP::client_addr]"
  if { [HTTP::uri] starts_with "/admin" } {
    log local0. "Admin URI detected: [HTTP::uri]"
    pool admin_pool
  } else {
    log local0. "Non-admin URI: [HTTP::uri]"
    pool default_pool
  }
}
Monitoring logs:
tail -f /var/log/ltm | grep "HTTP Request received"
