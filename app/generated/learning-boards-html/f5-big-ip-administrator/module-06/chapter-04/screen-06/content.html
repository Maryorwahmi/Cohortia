# Capture traffic for specific client and virtual server, save to file
tcpdump -ni <ext_interface> host <client_ip> and host <vs_ip> -s0 -w /var/tmp/capture.pcap
Key Flags Explained:
  • -s0: Captures full packet contents (snaplen 0). Essential for deep analysis.
  • -w <file>: Writes raw packets to a file for later analysis (e.g., with Wireshark).
  • and: Logical operator to combine filters (e.g., host and port).
# Example: Capture HTTP traffic on port 80
tcpdump -ni 0.0 port 80
Advanced Usage

tcpdump: Filtering and Output Options

Refine your packet captures with specific filters and save options for targeted analysis.

Common Filters
  • host <ip>: Filter by source or destination IP.
  • port <num>: Filter by TCP/UDP port number.
  • src host <ip> / dst host <ip>: Specific source/destination.
  • net <network>: Filter by network range.
Safety Note

tcpdump can generate very large files quickly, potentially filling disk space. Use filters judiciously and stop captures promptly to avoid production impact.
