Connectivity Diagnosis

Diagnosing Server-Side Connectivity Issues

Steps to ensure the BIG-IP can successfully communicate with its backend pool members.

Verification Steps
  • BIG-IP Reachability: From BIG-IP bash, ping and telnet to pool member IP and application port.
  • Health Monitor Status: Check pool member status and review /var/log/ltm for monitor failures.
  • Backend Configuration: Verify routing, backend firewalls, and application service listening ports.
Monitor Limitation

A pool member might be 'up' but still not processing traffic correctly if the health monitor isn't designed to detect application-level issues.

# Example: Telnet to a pool member's web port
telnet 10.1.1.100 80
Expected Output (Success):
Trying 10.1.1.100...
Connected to 10.1.1.100.
Escape character is '^]'.
Expected Output (Failure):
Trying 10.1.1.100...
telnet: connect to address 10.1.1.100: Connection refused
