Troubleshooting Pool and Node Status Issues

Investigating why pool members are marked 'down' and their impact on application availability.

Key Steps
  • Identify Down Members: Use tmsh show /ltm pool <pool_name> members.
  • Review Health Monitor: Check monitor configuration and /var/log/ltm for failure reasons.
  • Application-Level Issues: Consider custom monitors if members are 'up' but not functional.
Common Issue

Backend server firewall blocks, application service not running, or incorrect health monitor configuration are frequent causes of 'down' pool members.

# Show status of pool members for a specific pool
tmsh show /ltm pool my_web_pool members
