ssldump for SSL/TLS Decryption

A utility to capture and decrypt SSL/TLS traffic on BIG-IP, providing visibility into encrypted communications.

Why Use ssldump?
  • Decrypt SSL/TLS traffic for inspection.
  • Diagnose certificate issues, cipher mismatches.
  • Troubleshoot application-level errors within encrypted sessions.
  • Verify SSL handshake process.
Important Note

ssldump requires the BIG-IP to have the necessary private key for decryption. Like tcpdump, use filters to avoid excessive data capture.

# Basic ssldump command structure
ssldump -A -n -i <interface> host <client_ip> and port 443
Key Flags Explained:
  • -A: Prints all fields in the SSL records.
  • -n: Disables name resolution (faster output).
  • -i <interface>: Specifies the network interface.
  • host <client_ip>: Filters by client IP.
  • port 443: Filters for standard HTTPS traffic.
# Example: Capture SSL traffic from 192.168.1.100 on external interface
ssldump -A -n -i 0.0 host 192.168.1.100 and port 443
