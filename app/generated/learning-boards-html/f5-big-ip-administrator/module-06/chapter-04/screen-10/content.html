Connection Insight

Understanding Active Connections with tmsh

Utilize tmsh show /sys connection to inspect real-time traffic flow and connection states through the BIG-IP.

Key Information Provided
  • Source and destination IP addresses and ports.
  • Connection state (e.g., ESTABLISHED, TIME_WAIT).
  • Client-side vs. Server-side connection status.
  • Virtual server and pool member associated with the connection.
Key Takeaway

This command helps visualize the connection path, identifying where traffic might be stalled or dropped between the client, BIG-IP, and backend server.

# Show all active connections
tmsh show /sys connection
# Filter connections by client IP
tmsh show /sys connection cs-client-addr 192.168.1.100
