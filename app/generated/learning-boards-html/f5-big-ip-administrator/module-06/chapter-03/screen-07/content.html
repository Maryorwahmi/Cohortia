Leveraging the Configuration Utility Dashboards

Visualize BIG-IP health with intuitive graphical interfaces.

Overview Dashboard

Provides a high-level summary of system health, virtual servers, and pool status. Your starting point for quick health checks.

Module Statistics
  • LTM: Detailed metrics for virtual servers, pools, and nodes.
  • AFM: Firewall events and connection statistics.
  • Other Modules: Specific data for provisioned services.
Key Takeaway

The BIG-IP GUI offers both high-level and detailed statistics, allowing you to monitor real-time health and analyze historical trends for effective troubleshooting.

BIG-IP GUI Monitoring Paths

Overview > Dashboard

High-level system summary and status.

Statistics > Performance > System

CPU, Memory, and Connections graphs.

Statistics > Module Statistics > Local Traffic

Detailed metrics for Virtual Servers, Pools, and Nodes.
