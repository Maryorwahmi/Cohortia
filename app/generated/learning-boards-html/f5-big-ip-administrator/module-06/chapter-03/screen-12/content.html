Holistic View

Correlating Performance Data for Deeper Insights

Combine metrics and logs to get the full picture of an issue.

Key Data Points for Correlation
  • System Metrics: CPU, Memory, TMM CPU.
  • Connection Statistics: Current connections, connection rate.
  • Module Statistics: Virtual server, pool, node specific data.
  • Log Files: /var/log/ltm for event messages and errors.
  • Application Metrics: Backend server performance data.
Scenario Example

If clients report slow performance, check CPU/memory, then virtual server connection rates, and finally /var/log/ltm for errors to pinpoint the root cause.

Key Takeaway

Never rely on a single metric. Correlate data from various sources to understand the full context of an issue and accurately diagnose its root cause.

Correlation Flow for Troubleshooting

1. Observe System Metrics

CPU, Memory, Connections (GUI: Statistics > Performance)

2. Check Module Statistics

Virtual Servers, Pools, Nodes (GUI: Statistics > Module Statistics)

3. Review Log Files

/var/log/ltm for errors and events (CLI: tail -f /var/log/ltm)

4. Analyze Application Metrics

Backend server performance, application logs (External tools)
