Configuring Remote Syslog via tmsh

Using the Traffic Management Shell for command-line remote syslog setup, ideal for automation.

tmsh Commands
  • create /sys syslog remote-server my_syslog_server host 192.168.1.100 remote-port 514
  • modify /sys syslog remote-servers add { my_syslog_server }
  • save /sys config
  • quit
Verification

Use list /sys syslog remote-servers to confirm configuration and logger to send a test message.

Key Takeaway

tmsh offers a powerful, scriptable way to configure remote syslog, but always remember to save your configuration and test thoroughly.

tmsh Remote Syslog Configuration
# SSH into BIG-IP and enter tmsh
tmsh

# Create a remote syslog server destination
create /sys syslog remote-server my_syslog_server host 192.168.1.100 remote-port 514

# Add the remote server to the default syslog configuration
modify /sys syslog remote-servers add { my_syslog_server }

# Save the configuration
save /sys config

# Exit tmsh
quit
Pro Tip

For automation, these commands can be combined into a single script to ensure consistent syslog configurations across multiple BIG-IP devices.
