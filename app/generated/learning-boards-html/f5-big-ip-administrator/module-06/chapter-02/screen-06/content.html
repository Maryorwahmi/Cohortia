System Health

General System and Security Logs

Exploring /var/log/messages for system events and /var/log/secure for authentication activities.

/var/log/messages
  • Records general system messages.
  • Daemon activity and kernel events.
  • Useful for non-traffic related issues (e.g., disk space, service failures).
/var/log/secure
  • Logs authentication attempts (success/failure).
  • User logins and security-sensitive actions.
  • Critical for detecting unauthorized access.
Key Takeaway

Don't overlook /var/log/messages and /var/log/secure; they provide crucial insights into overall system health and security posture beyond traffic events.

Example: Authentication Failure
# Sample /var/log/secure entry
Jul 20 10:05:15 bigip1 sshd[5678]: Failed password for invalid user admin from 192.168.1.5 port 54321 ssh2

# Sample /var/log/messages entry
Jul 20 10:06:00 bigip1 err kernel: [  123.456] Out of memory: Kill process 9876 (tmm) score 999 or sacrifice child
Misconception

Assuming all critical events are in /var/log/ltm. System-level and security issues often appear in messages or secure first.
