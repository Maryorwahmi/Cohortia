Managing Local User Accounts

Creating and assigning roles for internal BIG-IP access.

Key Concepts
  • Roles: Define user permissions (e.g., Administrator, Operator, Guest).
  • Partitions: Segment configuration for granular access control.
  • Shell: Specifies command-line environment (e.g., Bash for advanced tasks).
GUI Path

System > Users > User List > Create

Key Takeaway

Local user accounts with specific roles and partitions are fundamental for controlling access and permissions within the BIG-IP system.

`tmsh` Command: Create Local User
create /auth user <username> password <password> shell bash home /home/<username> role administrator
Example Scenario

To create a user 'network_ops' with operator privileges for monitoring, you'd adapt the command to `role operator`.
