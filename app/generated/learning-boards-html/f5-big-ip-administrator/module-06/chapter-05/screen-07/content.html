Installation Process

BIG-IP Software Installation via GUI

A Step-by-Step Walkthrough Using the Configuration Utility

1. Upload Software Image

Navigate to `System > Software Management > Image List`, then click `Import` to upload the new `.iso` file.

2. Install to New Boot Location

Select the uploaded image, click `Install`, and choose an *unused* boot location (e.g., `HD1.2`).

3. Reboot into New Image

After installation, reboot the system and select the new boot location to activate the updated software.

Key Takeaway

Always install new software into a *new* boot location via the GUI to ensure a safe rollback option if issues arise.
