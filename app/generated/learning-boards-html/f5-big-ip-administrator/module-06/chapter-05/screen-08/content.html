Advanced Installation

BIG-IP Software Installation via TMSH

Leveraging the Command Line for Precise Control and Rollback

# SSH into BIG-IP and enter tmsh
tmsh

# List available images (after upload)
list /sys software image

# Install image to a new boot location
install /sys software image BIGIP-16.1.3.iso volume HD1.2

# After installation, reboot into the new boot location
reboot slot HD1.2
Key Takeaway

TMSH offers precise control for upgrades, and always installing to a *new boot location* is crucial for a reliable rollback strategy.

Boot Locations Explained

`HD1.1` (Active)

Current running software version.

`HD1.2` (New Install)

Target for new software installation.

`HD1.3` (Empty/Old)

Available for future use or older versions.
