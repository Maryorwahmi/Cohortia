Tcl Syntax

Basic TCL Syntax for iRules: Variables and Conditionals

Building dynamic logic with `set` for variables and `if/elseif/else` for conditions.

Variables with `set`

Store and reuse values: `set my_var "value"`.

Conditional Logic (`if`)

Execute code blocks based on conditions: `if { condition } { ... }`.

Command Substitution `[ ]`

Execute commands within conditions, e.g., `[HTTP::uri]` to get the URI.

Tcl Code Example
when HTTP_REQUEST {
    set client_ip [IP::client_addr]
    if { [HTTP::uri] starts_with "/admin" } {
        log local0. "Admin access attempt from $client_ip"
        # Further action for admin
    } elseif { [HTTP::uri] starts_with "/public" } {
        # Public access logic
    } else {
        # Default action
    }
}
Key Takeaway

Tcl's `set` and `if` statements are fundamental for creating dynamic and conditional logic within your iRules, enabling intelligent traffic handling.
