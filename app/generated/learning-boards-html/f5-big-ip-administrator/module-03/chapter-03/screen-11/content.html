HTTP to HTTPS Redirection with iRules

Enforcing secure connections for all web application traffic.

Detect HTTP Traffic

iRule checks if the virtual server is listening on port 80 (HTTP).

Issue 301 Redirect

Uses `HTTP::redirect` to send a 'Moved Permanently' response to the client.

Construct HTTPS URL

Builds the new URL using `https://[HTTP::host][HTTP::uri]`.

iRule for HTTPS Redirection
when HTTP_REQUEST {
    # Check if the virtual server is listening on port 80 (HTTP)
    if { [TCP::local_port] == 80 } {
        # Perform a 301 (Moved Permanently) redirect to HTTPS
        HTTP::redirect "https://[HTTP::host][HTTP::uri]"
    }
}
Key Takeaway

This iRule is a fundamental security measure, ensuring all client connections are upgraded to HTTPS, protecting data in transit. Remember to apply it only to HTTP virtual servers.
