Core Definition

What is SSL/TLS?

SSL (Secure Sockets Layer) and its successor TLS (Transport Layer Security) are cryptographic protocols that provide secure communication over a computer network. They ensure data integrity, confidentiality, and authentication between client and server.

  • Establishes an encrypted link.
  • Verifies server identity using certificates.
  • Protects data from eavesdropping and tampering.
BIG-IP's Role

The BIG-IP as an SSL Proxy

The F5 BIG-IP intercepts and manages the SSL/TLS handshake, acting as a proxy for both the client and the server. This allows it to decrypt, inspect, and re-encrypt traffic.

  • Offloads cryptographic burden.
  • Enables security inspection (WAF, iRules).
  • Provides granular control over encryption.
