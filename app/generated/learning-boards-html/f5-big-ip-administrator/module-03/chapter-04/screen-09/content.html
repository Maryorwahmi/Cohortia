SSL Re-encryption in Action

Maintaining End-to-End Encryption

Step 1

Client Connects to BIG-IP

Client SSL Profile decrypts incoming traffic.

Step 2

BIG-IP Inspects Traffic

Plaintext data is available for iRules, WAF, etc.

Step 3

BIG-IP Re-encrypts Traffic

Server SSL Profile establishes new encrypted connection.

Step 4

Backend Receives Encrypted Traffic

Data remains secure to the final destination.

Key Takeaway

SSL Re-encryption allows the BIG-IP to act as an SSL proxy, enabling inspection while ensuring data remains encrypted from client to backend server.
