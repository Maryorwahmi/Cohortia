How Source IP Persistence Works

  • •**Key:** Uses the client's source IP address to identify the session.
  • •**Mapping:** Maps a specific client IP to a particular pool member.
  • •**Configuration:** Apply the `source_addr` persistence profile to the virtual server.
  • •**Benefit:** Simple to implement and effective for clients with unique IPs.
Concrete Example

A user at home with a unique public IP address connects to a web application. Source IP persistence ensures all their requests go to the same server, maintaining their session state.

Key Takeaway

Source IP persistence is a simple, IP-based method, but its effectiveness diminishes when multiple clients share the same source IP address.

Source IP Persistence Flow

Client Request

Client (IP: 192.168.1.100) sends request.

BIG-IP Maps

Maps 192.168.1.100 to Server A.

Subsequent Requests

All from 192.168.1.100 go to Server A.

Limitation

Multiple clients behind a NAT/proxy share one IP, leading to uneven load on a single server.
