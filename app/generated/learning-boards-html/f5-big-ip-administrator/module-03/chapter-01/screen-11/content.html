How Cookie Persistence Works

  • •**Cookie Insertion:** BIG-IP inserts a special cookie into the client's initial HTTP response.
  • •**Client Returns Cookie:** Client's browser sends this cookie back with subsequent requests.
  • •**Server Identification:** BIG-IP uses cookie info to direct requests to the correct backend server.
  • •**Benefit:** Tracks individual clients regardless of source IP, ideal for proxies/NAT.
Concrete Example

An online banking application uses cookie persistence to ensure that once a user logs in, all their subsequent actions (e.g., checking balance, making transfers) are handled by the same server, maintaining their authenticated session.

Key Takeaway

Cookie persistence is highly effective for web applications, providing robust session affinity by tracking clients via HTTP cookies, even behind proxies.

Cookie Persistence Modes

HTTP Cookie Insert

BIG-IP generates and inserts its own cookie.

HTTP Cookie Rewrite

BIG-IP modifies an existing application-set cookie.

HTTP Cookie Passive

BIG-IP expects the application to set the cookie.

Consideration

Choose the mode that best integrates with your application's existing cookie management strategy.
