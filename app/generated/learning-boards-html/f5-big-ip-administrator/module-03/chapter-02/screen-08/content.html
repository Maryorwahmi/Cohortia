Built-in Monitors
Specialized Built-in Monitors
Tailored checks for specific service types.
DNS Monitor

Verifies DNS resolution, ensuring the server can correctly resolve hostnames.

SQL Monitor

Connects to a database and can execute a query to check its operational status.

Key Takeaway

Use specialized monitors for precise health checks of services like DNS, FTP, LDAP, and SQL, enhancing monitoring accuracy.

Other Specialized Monitors
FTP Monitor

Checks the health of the FTP service, ensuring file transfer capabilities.

LDAP Monitor

Verifies the availability and responsiveness of your LDAP directory service.

These monitors provide granular, protocol-specific health checks for diverse services.
