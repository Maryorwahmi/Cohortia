Custom Monitoring
Implementing Custom External Monitors: Configuration Steps
Integrating your custom script with the F5 BIG-IP GUI.
Upload & Permissions

Upload script to /usr/bin/monitors/ and make it executable (chmod +x).

GUI Configuration

Create a new monitor, set Type to External, and specify External Program path.

Key Takeaway

Properly configuring the script's location, permissions, and GUI settings is essential for BIG-IP to execute custom monitors.

BIG-IP GUI Configuration Steps
Step 1: Upload

Copy script to /usr/bin/monitors/ via SCP/SFTP.

Step 2: GUI Config

Local Traffic > Monitors > Create, set Type: External.

Step 3: Program Path

Specify /usr/bin/monitors/your_script.sh.

Step 4: Apply

Apply the monitor to your pool or pool members.

These steps ensure your custom script is correctly integrated and utilized by BIG-IP.
