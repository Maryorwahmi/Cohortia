Built-in Monitors
Application-Aware Checks: HTTP and HTTPS Monitors
Verifying web service functionality and content delivery.
Send String

The exact HTTP/HTTPS request sent to the server (e.g., GET /healthcheck.html).

Receive String

The expected response content or HTTP status code (e.g., 200 OK or Application Healthy).

Key Takeaway

HTTP/HTTPS monitors provide granular application health checks by validating both connectivity and expected content.
