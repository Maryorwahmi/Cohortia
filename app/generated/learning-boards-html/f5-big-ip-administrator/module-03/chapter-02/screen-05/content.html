Built-in Monitors
Basic Connectivity: ICMP and TCP Monitors
Understanding the foundational built-in health checks.
ICMP Monitor

Pings the server's IP address to check basic network reachability. It confirms the server is online but not necessarily that its services are running.

TCP Monitor

Attempts to establish a TCP connection to a specified port. It verifies if a service is listening and accepting connections on that port.

Key Takeaway

Use ICMP for network presence and TCP for basic service listening. Neither confirms full application functionality.

Monitor Capabilities Comparison
ICMP
  • •Checks network reachability.
  • •Uses ping protocol.
  • •Does NOT check application service.
TCP
  • •Checks if service is listening on port.
  • •Establishes a TCP connection.
  • •Does NOT check application content.
While essential, these monitors provide only a foundational layer of health verification.
