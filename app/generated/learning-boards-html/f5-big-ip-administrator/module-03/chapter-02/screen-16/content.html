Key Concepts: Part 1
Essential terms for health monitoring

Health Monitor

A BIG-IP object that periodically checks pool member availability and responsiveness.

ICMP Monitor

A basic monitor that checks network reachability using ping.

TCP Monitor

Checks if a service is listening on a specific TCP port.

HTTP/HTTPS Monitor

Sends a web request and expects a specific response code or string.

Send String

The request payload sent by an HTTP/HTTPS monitor (e.g., GET /healthcheck).

Summary

These foundational concepts define how BIG-IP monitors basic network reachability, service listening, and application content delivery.
