Pools: Grouping Backend Servers

A logical collection of real servers hosting the same application or service.

Logical Grouping

A Pool organizes multiple backend servers (Pool Members) into a single unit for traffic distribution.

Hosts Same Service

All Pool Members within a Pool are expected to run the same application or service, ensuring consistency.

Destination for Virtual Server

Virtual Servers direct client traffic to a Pool, which then intelligently selects a healthy member.

Key Takeaway

Pools are crucial for organizing backend resources, enabling load balancing, and ensuring high availability for applications.
