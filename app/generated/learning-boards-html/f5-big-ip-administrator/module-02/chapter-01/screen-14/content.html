Key Concepts

Essential terms and definitions from this chapter.

Virtual Server

A logical object on the BIG-IP with an IP address and port that clients connect to, acting as the entry point for application traffic.

Pool

A logical grouping of backend servers (Pool Members) that host the same application or service.

Pool Member

An individual backend server within a Pool, identified by its IP address and service port.

Summary Takeaway

Virtual Servers act as client entry points, directing traffic to Pools, which intelligently distribute requests among their Pool Members (backend servers) for high availability and scalability.
