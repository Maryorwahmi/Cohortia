Setting Up a Web Application Service

A practical walkthrough for Virtual Server and Pool configuration.

01

Create the Pool

Define a Pool (e.g., `web_app_pool`) to group your backend servers.

Example

`web_app_pool`

02

Add Pool Members

Add backend servers with their IP addresses and service ports to the Pool.

Example

`10.1.10.10:80`, `10.1.10.11:80`

03

Create the Virtual Server

Set up a Standard Virtual Server with its client-facing IP and port.

Example

`192.168.1.100:80`

04

Associate VS with Pool

Link the Virtual Server to the Pool to enable traffic forwarding.

Example

`web_app_vs` to `web_app_pool`

Key Takeaway

A successful configuration involves creating a Pool with healthy members and correctly associating it with a Virtual Server to enable load-balanced traffic flow.
