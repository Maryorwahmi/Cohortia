Module 2›Chapter 2.3›Least Connections
Operational Principle

Fewest Active Connections

New connections are sent to the Pool Member currently handling the lowest number of active connections. This is a dynamic, real-time decision.

Ideal Use Case

Long-Lived Connections

Highly effective for applications with persistent sessions (e.g., databases, streaming) where connection duration varies, ensuring balanced active load.

Benefit

Prevents Overload

By considering current workload, it helps prevent individual servers from becoming bottlenecks, leading to more even resource utilization.

Key Takeaway

Least Connections is a smarter choice than Round Robin for dynamic workloads, as it actively balances the number of concurrent connections.
