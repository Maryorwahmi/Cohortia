Nodes vs. Pool Members

Understanding the fundamental building blocks of a Pool.

What is a Node?

A Node represents a physical or virtual server with a specific IP address on your network. It's a fundamental network object that the BIG-IP knows about, essentially a declaration of a server's existence.

  • •Defined by IP address only (e.g., 10.1.10.10).
  • •Does not directly serve application traffic.
  • •A server's network presence.

What is a Pool Member?

A Pool Member is a specific service instance on a Node, defined by the Node's IP address and a particular service port. This is the actual endpoint that receives application traffic.

  • •Defined by IP address AND service port (e.g., 10.1.10.10:80).
  • •Directly serves application traffic.
  • •A specific application service.

Key Takeaway

A Node is the server's IP, while a Pool Member is a specific service (IP:Port) on that server. This allows for granular control over individual application instances.
