Key Concepts

Essential terms to remember.

gateway_icmp / tcp

Network-level monitors for basic reachability (ping) and port responsiveness (TCP handshake).

http / https

Application-level monitors that send HTTP/HTTPS requests and check for specific response codes or content.

Monitor Parameters

Interval (how often to check), Timeout (how long to wait), and Retries (failures before marking down).

Summary Takeaway

Effective health monitoring relies on selecting appropriate monitor types, fine-tuning their parameters, and accurately interpreting the visual status indicators to ensure continuous application availability.
