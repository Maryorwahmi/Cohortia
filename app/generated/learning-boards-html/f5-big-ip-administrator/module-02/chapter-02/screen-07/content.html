Network-Level Health Checks

Basic reachability with gateway_icmp and tcp monitors.

gateway_icmp Monitor

A basic network-level monitor that uses ICMP (ping) to check if a server's IP address is reachable on the network.

  • •Purpose: Verifies network connectivity to the Node.
  • •Mechanism: Sends an ICMP echo request (ping).
  • •Example: Checks if 10.1.10.10 responds to a ping.

tcp Monitor

A monitor that checks if a specific TCP port on a server is open and responsive, indicating a service is listening.

  • •Purpose: Verifies if a service port is listening.
  • •Mechanism: Attempts a TCP handshake on the specified port.
  • •Example: Checks if 10.1.10.10:80 is open.
