What goes where
  • Project-level build.gradle: repositories and classpath plugins used across modules.
  • Module-level build.gradle: dependencies, compileSdkVersion, minSdkVersion, and build types.
  • Add libraries to dependencies with implementation lines so classes become available at compile time.
Pro tip

When adding a library, sync Gradle and watch the build output for resolution errors — they often indicate version conflicts or missing repositories.

Example dependency
implementation 'androidx.constraintlayout:constraintlayout:2.1.4'
Why it matters
Dependencies declared in the module build.gradle determine which libraries are bundled and compiled into your app. Put them in the right file to avoid build problems.
