Module 3 › Chapter 3.2 › Hands-on Activity
Step-by-step
  1. Open app/src/main/res/layout/activity_main.xml in Android Studio.
  2. Replace or set the root to a LinearLayout with android:orientation="vertical" and android:gravity="center".
  3. Add a TextView title, two EditText fields with android:hint, and a Button for login. Set android:id on each.
  4. Use match_parent for input widths, wrap_content for labels, and set inputType="textPassword" for the password field.
  5. Preview the layout in the Design editor and run on an emulator to confirm the UI renders and responds.
Example code reminder
Use the LinearLayout XML example provided earlier as your starting point. After changes, preview and run to validate.
Key Takeaway

Follow the edit → preview → run cycle to ensure layout edits behave as expected on actual devices.
