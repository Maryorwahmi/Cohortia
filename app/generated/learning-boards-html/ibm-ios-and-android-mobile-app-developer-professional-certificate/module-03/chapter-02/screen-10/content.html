Module 3 › Chapter 3.2 › Layout Comparison
LinearLayout
Arranges children in a row or column. Use android:orientation to control direction and android:gravity for alignment. Best for simple, ordered layouts like forms.
Pros: Simple, predictable, easy to read.
Cons: Can require nesting for complex arrangements.
RelativeLayout
Positions children relative to one another or the parent. Useful when you need overlap or specific alignment without deep nesting.
Pros: Flexible positioning, can reduce nesting.
Cons: Can become hard to maintain if rules become complex.
Scenario guidance
If you need a straight list of items, use LinearLayout. If you must position elements relative to each other — for example, anchor one view below another and align another to the parent edge — RelativeLayout may simplify the layout. Always preview and refactor to maintain readability.
