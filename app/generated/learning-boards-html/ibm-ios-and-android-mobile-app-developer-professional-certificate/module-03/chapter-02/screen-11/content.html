Module 3 › Chapter 3.2 › Common Views
TextView
Displays text. Use textSize, textColor, and padding. Prefer strings.xml for text content to support localization.
EditText
Editable text input. Use android:hint for placeholder and android:inputType to control keyboard and masking for passwords.
Button
Clickable control that performs an action. Style with padding and margin and wire click behavior from your Activity code.
Example attributes
  • android:id="@+id/editTextUsername" — unique identifier for code references.
  • android:layout_width="match_parent" — often used for input fields to span available width.
  • android:inputType="textPassword" — obscures input for passwords.
Common mistake
Leaving user-facing text in layout XML instead of strings.xml reduces the ability to localize the app. Use resource strings for labels and placeholders.
