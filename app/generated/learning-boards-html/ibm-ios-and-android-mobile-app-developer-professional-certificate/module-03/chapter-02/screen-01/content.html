Android project anatomy

Identify the key directories, configuration files, and UI building blocks so you can confidently edit and extend an Android app.

App module
Home for application code: app/src/main/java or kotlin and app/src/main/res. Activities and resources live here.
Config files
AndroidManifest.xml declares components and permissions; build.gradle controls dependencies and build settings.
Resources
res contains layouts, drawables, strings, colors, and fonts — separate from code for maintainability and localization.
UI building blocks
Views like TextView, Button, EditText and containers like LinearLayout and RelativeLayout form the visible screen.
