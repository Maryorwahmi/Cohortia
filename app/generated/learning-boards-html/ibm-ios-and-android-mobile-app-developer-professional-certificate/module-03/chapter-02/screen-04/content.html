app/src/main
This module tree is the standard workspace for your app logic and assets. Inside you will always find the source folder and res folder.
Source (java / kotlin)
Contains Activities, Fragments, and other classes organized by package name.
res (resources)
Layouts, drawables, mipmap, values, and fonts — used by the UI and packaged with the app.
Key Takeaway

Edit UI text in values/strings, change layout structure in res/layout, and write behavior in java or kotlin files.

Visual file map
res/layout
XML layout files that define how screens are structured.
res/drawable
Images and XML drawables used by the UI.
res/values
Strings, colors, dimensions, and styles for consistent design and localization.
res/mipmap
Launcher icons for different screen densities.
Common mistake
Placing translatable text directly in layout XML instead of using res/values/strings.xml makes localization harder and is a frequent beginner error.
