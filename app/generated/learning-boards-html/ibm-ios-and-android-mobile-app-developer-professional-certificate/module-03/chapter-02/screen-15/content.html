Resources in res
Layouts, drawables, and strings belong in res for reuse and translation.
Declare permissions
Add uses-permission tags in the manifest to avoid runtime security exceptions.
Simple layouts first
Start with LinearLayout for straight rows or columns, then refactor if you need more complex positioning.
Final takeaway
Use the project structure and these UI basics to build, preview, and run the login UI exercise. Small, correct layout choices lead to reliable, maintainable screens.
