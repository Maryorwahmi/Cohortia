Activity as a screen
An Activity provides a window for UI and handles user interaction for a single focused task. It typically inflates a layout resource and responds to UI events.
Example
LoginActivity inflates activity_main.xml, reads the username and password fields, and handles the login button tap.
Common misconception
Do not confuse an Activity with a single view. Activities host many views and coordinate logic beyond layout.
Checklist
  • Create an Activity class in the source package.
  • Inflate the layout resource with setContentView in onCreate.
  • Register the Activity in AndroidManifest.xml.
Scenario
You need a screen for user profile editing. Create a ProfileActivity, design res/layout/activity_profile.xml, and register ProfileActivity in the manifest so the system can start it.
Key Takeaway

Map screens to Activity classes and register them to make the app navigable and maintainable.
