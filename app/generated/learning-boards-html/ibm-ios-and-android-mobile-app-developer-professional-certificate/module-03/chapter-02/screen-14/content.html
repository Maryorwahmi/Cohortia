Module 3 › Chapter 3.2 › What to Remember
app/src/main
Source and resource separation supports maintainability and localization.
AndroidManifest.xml
Register components and declare permissions required by the app.
build.gradle
Module-level Gradle lists dependencies and SDK versions — edit here for library access.
Takeaway
Keep code, resources, and configuration distinct. When you need to change UI, edit res/layout and values; when you need to change behavior, edit source files; when you need capabilities or libraries, update the manifest or Gradle respectively.
