What you will do
  • Open app/src/main and locate Java or Kotlin source packages and res folders.
  • Edit activity_main.xml to add TextView, EditText, and Button with the right attributes and ids.
  • Preview the layout in Android Studio and run it on an emulator to confirm behavior.
  • Declare a permission in AndroidManifest.xml when required and add dependencies in build.gradle when you use libraries.
Quick mnemonic
Code vs assets: Code = java | kotlin. Assets = res. Config = manifest and gradle.
VERIFIED COMPETENCY MILESTONE
Create and run the login layout in an emulator to confirm you can edit and preview UI files correctly.
