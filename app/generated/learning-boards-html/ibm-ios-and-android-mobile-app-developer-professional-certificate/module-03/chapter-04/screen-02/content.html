Bloom: Learn → Understand → Apply → Master
01
Use ConstraintLayout

You will position views using anchors and guidelines, creating flat hierarchies that adapt across screen sizes. VERIFIED COMPETENCY MILESTONE

02
Build RecyclerView lists

You will wire a RecyclerView with a LayoutManager and Adapter to display many items efficiently. VERIFIED COMPETENCY MILESTONE

03
Create Adapters & ViewHolders

You will implement a ViewHolder and Adapter pattern to bind user data to item views for reuse. VERIFIED COMPETENCY MILESTONE

04
Navigate with Intents and extras

You will start Activities with explicit Intents and pass extras to share small data like a userName between screens. VERIFIED COMPETENCY MILESTONE

Visual mnemonics
Constraint = Anchor
An anchor ties a view edge to another edge or the parent.
RecyclerView = Reuse
ViewHolder holds references so views are rebound instead of recreated.
Intent = Message
Extras carry small key-value pairs like a username between Activities.
