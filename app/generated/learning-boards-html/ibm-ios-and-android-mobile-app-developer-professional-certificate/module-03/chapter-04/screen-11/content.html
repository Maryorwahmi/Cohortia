Module 4 › Chapter 3.4 › Wiring RecyclerView in MainActivity
MainActivity.kt (snippet)
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val userRecyclerView: RecyclerView = findViewById(R.id.userRecyclerView)
        userRecyclerView.layoutManager = LinearLayoutManager(this)

        val users = listOf(
            User("Alice Smith", "Online"),
            User("Bob Johnson", "Offline"),
            User("Charlie Brown", "Away")
        )
        userRecyclerView.adapter = UserAdapter(users)
    }
}
Testing
Run on your AVD or device and confirm the list renders and taps navigate to the detail screen. If nothing appears, check that the LayoutManager is set and the adapter provides itemCount > 0.
Debug checklist
  • Is the RecyclerView present in activity_main.xml and using match constraints with ConstraintLayout if needed?
  • Did you set a LayoutManager?
  • Does your Adapter return a non-zero item count?
  • Is the target Activity declared in AndroidManifest.xml?
