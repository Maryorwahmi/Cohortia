Module 4 › Chapter 3.4 › Intents and explicit navigation
Explicit Intent pattern
val intent = Intent(this, UserDetailActivity::class.java)
intent.putExtra("userName", "Alice")
startActivity(intent)
Receiving extras
In the receiving Activity's onCreate, call intent.getStringExtra("userName") and handle nulls or defaults appropriately before using the value in the UI.
Manifest reminder
Declare activities in AndroidManifest.xml: <activity android:name=".UserDetailActivity" />. Missing this causes ActivityNotFoundException at runtime.
Common-mistake
Mismatched extra keys between sender and receiver. Use constants for keys to avoid typos.
