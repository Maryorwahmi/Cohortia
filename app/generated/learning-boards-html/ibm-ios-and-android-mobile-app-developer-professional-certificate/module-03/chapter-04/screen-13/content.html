UserDetailActivity snippet
class UserDetailActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_user_detail)

        val userName = intent.getStringExtra("userName") ?: "Guest"
        findViewById(R.id.detailUserNameTextView).text = "Hello, $userName!"
    }
}
Error handling
Provide fallbacks for missing extras and avoid assuming non-null values. Use defaults for numeric extras to prevent unexpected values.
Key Takeaway
Treat extras as optional by default and defend your code with null checks or defaults so the UI remains stable.
