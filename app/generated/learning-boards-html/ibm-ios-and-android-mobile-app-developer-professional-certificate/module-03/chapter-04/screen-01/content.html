Layouts, Lists, and Navigation

Understand how ConstraintLayout structures your UI, how RecyclerView scales lists, and how Intents link screens and pass data.

In this lesson

Refactor layouts to ConstraintLayout, add a RecyclerView, implement a UserAdapter, and navigate with Intent extras to a detail Activity.

Why it matters

Flat constraints keep rendering fast; recycling views reduces memory pressure; explicit Intents make component communication predictable.

Explore Key Topics
ConstraintLayout anchors, RecyclerView architecture, Intent extras between Activities.
Visual concept
Constraint anchors
Anchoring a view to a sibling or parent defines position and allows adaptive layouts without nested containers.
RecyclerView
Large lists reuse views; Adapter binds data; LayoutManager controls arrangement.
Intents
Explicit Intents start Activities and extras pass typed key-value data between them.
Coming up
Live coding refactor, build a simple UserAdapter, and wire navigation to a detail screen using extras.
