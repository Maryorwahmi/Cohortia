Module 4 › Chapter 3.4 › Common mistakes and debugging tips
Checklist
  • ConstraintLayout: each view needs at least one horizontal and one vertical constraint.
  • RecyclerView: remember to set a LayoutManager and ensure getItemCount() > 0.
  • Adapter: check adapterPosition != RecyclerView.NO_POSITION before acting on clicks.
  • Intents: declare the destination Activity in the manifest and use consistent extra keys.
  • Performance: keep binding fast; offload heavy ops from onBindViewHolder.
Quick fixes
Add missing constraints and rebuild layout to see changes.
Set LayoutManager: recyclerView.layoutManager = LinearLayoutManager(this)
Declare activity in manifest to avoid ActivityNotFoundException.
