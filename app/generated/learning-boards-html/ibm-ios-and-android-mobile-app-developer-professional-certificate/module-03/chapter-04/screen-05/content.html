Module 4 › Chapter 3.4 › Setting constraints, guidelines, and chains
Step-by-step
  1. Add primary views and give each an id so you can reference them in constraints.
  2. Constrain vertical position: set top/bottom relationships to a sibling or the parent.
  3. Constrain horizontal position: set start/end relationships; use both to center a view.
  4. Introduce guidelines for consistent columns or margins across devices.
  5. Use chains to control distribution between a set of sibling views.
  6. Preview on multiple sizes and orientations and fix missing or conflicting constraints.
Example
Constrain button.top to title.bottom with 24dp margin and constrain button.start and button.end to parent to keep it centered below the title across widths.
Common-mistake
Forgetting a horizontal or vertical constraint. When a view lacks either, the runtime places it at the top-left corner. Always ensure at least one constraint for each axis.
Pro tip
Use 0dp (match constraints) when you want a view to expand between constraints; use wrap_content for intrinsic sizing.
