SDK Manager workflow
  1. Open Tools → SDK Manager in Android Studio.
  2. Under SDK Platforms, select the Android releases you need.
  3. Under SDK Tools, ensure Build-Tools, Emulator, and Command-line Tools are checked.
  4. Download matching system images for emulator testing; choose Play Store images when needed.
Supporting notes
  • NDK: install only if you will use C/C++ code.
  • Build-Tools: Gradle can request specific versions — keep these updated.
  • Disk usage: system images are often the largest downloads.
Common mistake
Skipping system images required for testing leads to emulator errors later; install them proactively.
