Module 3 › Chapter 3.1 › Android Virtual Device
AVD components
  • Device definition: model and screen size.
  • System image: Android API level and Play Store presence.
  • Hardware profile: RAM, CPU cores, and camera support.
When to use Play Store images
When your app needs Google APIs like Maps or Play Services during testing.
Example scenario
Create an AVD named MyPixel4AVD using a recommended system image for API 34 when you need to test Android 14 behaviors and Google APIs. Adjust RAM if your machine can spare memory for faster emulation.
Misconception
The emulator is identical to a physical device — not always. Always validate critical flows on real hardware when possible.
