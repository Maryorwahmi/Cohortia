Module 3 › Chapter 3.1 › Gradle & Initial Build
What happens on first build
  1. Gradle resolves and downloads plugin and library dependencies.
  2. Build tools compile Kotlin/Java sources and package resources.
  3. Artifacts are cached so future builds are faster.
If the build fails
Check event log for network errors, ensure SDK and build-tools are installed, and verify the JDK path in settings. Firewall restrictions often block Gradle downloads.
Pro tip
Allow the first build to complete without interrupting network activity; subsequent builds will be much faster.
