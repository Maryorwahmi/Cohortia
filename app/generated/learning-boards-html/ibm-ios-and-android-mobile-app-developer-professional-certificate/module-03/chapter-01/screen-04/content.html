Module 3 › Chapter 3.1 › Install Android Studio
Step-by-step installer flow
  1. Download the official Android Studio installer for your OS.
  2. Run the installer and follow on-screen prompts; accept recommended components.
  3. Open Android Studio and complete the setup wizard, which configures SDK paths.
  4. Open SDK Manager to confirm platforms and tools are installed.
Pro tip
Accept defaults when learning, but verify SDK components later to avoid missing tools.
Installer checklist
  • SDK Platform (latest stable) installed
  • Android Emulator installed
  • Android SDK Build-Tools and Command-line Tools present
  • Enough disk space for system images
Check your install
Open SDK Manager and Device Manager to confirm everything is visible and up to date.
