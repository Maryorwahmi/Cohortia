Module 3 › Chapter 3.1 › Create an AVD
Create device — quick steps
  1. Open Tools → Device Manager → Create device.
  2. Choose a Phone device profile (Pixel 4 or Pixel 6 recommended).
  3. Select a system image; use Play Store images for Google APIs.
  4. Adjust RAM and hardware profile; name the AVD and finish.
  5. Launch the AVD to verify it boots and your app runs.
Example AVD
Name: MyPixel4AVD. Device: Pixel 4. System image: Recommended API 34 with Play Store. RAM: 2048 MB (adjust if host memory is limited).
Common mistake
Not downloading the chosen system image first — the AVD cannot start until the image is available locally.
