Module 3 › Chapter 3.1 › Minimum SDK & Language
Language comparison
Kotlin: concise, modern, recommended for new apps.
Java: well-supported, more verbose, legacy codebases may use it.
Minimum SDK trade-offs
Lower Minimum SDK: wider audience, may need compatibility libraries.
Higher Minimum SDK: access to newer APIs, fewer supported devices.
Recommendation: For learning, API 24 balances coverage and modern features.
Key takeaway
Pick Kotlin for new projects and choose a Minimum SDK that fits your target audience and feature needs.
