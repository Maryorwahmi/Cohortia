Project configuration
Name: MyFirstAndroidApp
Package: com.example.myfirstandroidapp
Language: Kotlin
Minimum SDK: API 24 (balanced support)
After creation
Expect an initial Gradle build and the default Hello World activity. Check the Project window to explore files.
Quick example — Activity layout
<!-- res/layout/activity_main.xml (simplified) -->
<LinearLayout
  xmlns:android="http://schemas.android.com/apk/res/android"
  android:layout_width="match_parent"
  android:layout_height="match_parent"
  android:orientation="vertical"
  android:gravity="center"
  android:padding="16dp">

  <TextView
    android:id="@+id/hello_text"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Hello World!"
    android:textSize="18sp" />

</LinearLayout>
This simple layout is what you’ll see when the app runs on the emulator. It confirms your build and AVD are working together.
