Module 3 › Chapter 3.1 › Android SDK
Core components
SDK Platforms
Contain Android APIs for each release used at compile time.
Build-Tools
Compilers and packaging utilities used by Gradle to build APKs.
System Images
Images used by the emulator to simulate device OS and features.
Example & misconceptions
Example: To test API 30 features, install Android 11 SDK Platform and a matching system image. Misconception: "Android Studio installs everything I need" — verify SDK Manager to confirm components and free space.
Key takeaway
Keep SDK components aligned with the API levels you need and remove unused images to save space.
