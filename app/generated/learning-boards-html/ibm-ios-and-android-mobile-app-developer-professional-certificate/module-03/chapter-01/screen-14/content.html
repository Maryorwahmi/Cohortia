Module 3 › Chapter 3.1 › Key Concepts
Android Studio
The official IDE providing the tools you need to build, run, and debug apps.
Android SDK
Platforms, build-tools, and system images required to compile and test apps.
AVD
A virtual device that simulates screen sizes and Android versions for testing.
Remember
Keep SDKs updated, enable hardware acceleration, and verify the initial Gradle build to confirm your environment is ready.
