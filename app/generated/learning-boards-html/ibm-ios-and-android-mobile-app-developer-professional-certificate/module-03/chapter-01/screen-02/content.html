Learning Objectives

Learn → Understand → Apply → Master

01
Install Android Studio
Complete a full installation and initial setup, ensuring SDK components are installed. This matters because the IDE orchestrates builds, emulation, and debugging for your apps.
VERIFIED COMPETENCY MILESTONE
02
Manage Android SDK
Understand SDK Platforms, Build-Tools, and system images so you can target specific Android versions and APIs. This reduces compatibility surprises when running your app.
VERIFIED COMPETENCY MILESTONE
03
Create and use AVDs
Set up virtual devices with appropriate system images and hardware profiles to test different screens and APIs without physical hardware.
VERIFIED COMPETENCY MILESTONE
04
Create your first project
Scaffold an Empty Activity, configure package and minimum SDK, and run the first Gradle build to verify environment correctness.
VERIFIED COMPETENCY MILESTONE
