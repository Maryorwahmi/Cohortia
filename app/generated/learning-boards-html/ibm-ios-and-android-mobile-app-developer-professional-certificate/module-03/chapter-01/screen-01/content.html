Setting Up Your Android Development Environment

Install Android Studio, manage SDK components, build an AVD, and run an Empty Activity so you can test apps locally.

Android Studio
IDE with editor, emulator, and profiler.
Android SDK
Libraries and tools to build apps.
AVD
Virtual device for testing.
In this lesson you will follow a clear setup path: download Android Studio, configure SDK components, create an AVD with a Play Store image if needed, then scaffold and run an Empty Activity. Each step matters: SDK selection controls supported APIs, AVD settings determine hardware simulation, and Gradle downloads dependencies during the first build. We’ll also highlight common pitfalls you can fix quickly, such as enabling virtualization in BIOS or installing HAXM for faster emulation.
