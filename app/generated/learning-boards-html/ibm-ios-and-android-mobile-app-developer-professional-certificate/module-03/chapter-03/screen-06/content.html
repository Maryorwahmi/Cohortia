Module 3 › Chapter 3.3 › Toast vs Snackbar
Comparison
Toast
A short, non-interactive popup that disappears automatically. Use for simple confirmations.
Characteristics
  • Non-interactive, brief
  • Does not support actions or undo
  • Good for simple confirmations
Example
After saving preferences show a Toast saying 'Settings saved'.
Comparison
Snackbar
A bottom-attached message with optional action and swipe-to-dismiss. Use when the user may need to respond or undo.
// Snackbar usage example
Snackbar.make(findViewById(android.R.id.content), "Login failed. Retry?", Snackbar.LENGTH_LONG)
  .setAction("RETRY") {
    // handle retry logic here
    Toast.makeText(this, "Retrying login...", Toast.LENGTH_SHORT).show()
  }
  .show()
Design note
Snackbars belong to the view hierarchy and can be anchored; they are generally preferred when offering inline recovery actions.
