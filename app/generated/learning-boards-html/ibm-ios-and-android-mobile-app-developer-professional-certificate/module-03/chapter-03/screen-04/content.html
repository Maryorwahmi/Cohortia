Module 3 › Chapter 3.3 › Event Listeners
Core Concept
What is an event listener?
A listener observes view events and triggers code. Keep handlers small and delegate heavy work elsewhere.
Key points
  • Attach listeners in onCreate after setContentView.
  • Use findViewById to reference Views by id.
  • Keep listener code light; hand off heavy tasks.
  • Always convert EditText.text to String with toString().
Common mistake
Forgetting to call toString() on EditText.text leads to type mismatches; treat the Editable as raw user input and convert it before processing.
Key Takeaway

Listeners connect UI events to app logic. Make them fast and safe by validating input and delegating heavy work.

Code example: wiring a Button listener and reading EditText values. Keep this handler minimal and non-blocking.
// In MainActivity.kt
import android.os.Bundle
import android.widget.Button
import android.widget.EditText
import android.widget.Toast
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.activity_main)

    val usernameEditText: EditText = findViewById(R.id.editTextUsername)
    val passwordEditText: EditText = findViewById(R.id.editTextPassword)
    val loginButton: Button = findViewById(R.id.buttonLogin)

    loginButton.setOnClickListener {
      val username = usernameEditText.text.toString()
      val password = passwordEditText.text.toString()
      if (username.isNotEmpty() && password.isNotEmpty()) {
        Toast.makeText(this, "Attempting login for: $username", Toast.LENGTH_SHORT).show()
      } else {
        Toast.makeText(this, "Please enter both username and password.", Toast.LENGTH_LONG).show()
      }
    }
  }
}
Example scenario
A user taps Login; your listener validates fields and shows a Toast. This immediate feedback confirms the tap worked.
Check your understanding
What happens if you perform a network call directly inside the listener? Consider UI thread responsiveness and user experience.
