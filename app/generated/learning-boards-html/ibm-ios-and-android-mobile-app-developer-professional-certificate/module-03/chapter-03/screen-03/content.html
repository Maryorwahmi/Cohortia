Practice Tasks
Wire a Login Button
Use findViewById, setOnClickListener, read EditText.text.toString(), and show a Toast on success or error.
Add Snackbar Action
Replace a failed login toast with a Snackbar offering a retry action to practice interactive feedback.
Lifecycle Logging
Add Log.d lines in each lifecycle method and observe Logcat while rotating and backgrounding the app.
Mnemonic
Create → Start → Resume → Pause → Stop → Destroy
Map each word to when the activity becomes visible, interactive, loses focus, becomes invisible, and is cleaned up. Use this when deciding where to save state or release resources.
