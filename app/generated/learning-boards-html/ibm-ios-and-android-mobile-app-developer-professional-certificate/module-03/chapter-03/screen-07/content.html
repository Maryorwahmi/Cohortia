Module 3 › Chapter 3.3 › Activity Lifecycle
Definition
Activity Lifecycle
A sequence of callback methods the system calls to manage an activity's lifetime. Your code should respond to these lifecycle signals to manage resources and state.
onCreate()
Initial setup: setContentView and initialize Views and adapters.
onStart() / onResume()
Activity becomes visible and interactive; start animations and exclusive resources.
onPause() / onStop()
Save transient state quickly, stop animations, and release resources not required while hidden.
Misconception
Do not assume onDestroy will always be called. The system can kill the process to reclaim memory without invoking final cleanup methods.
Key Takeaway

Use lifecycle callbacks to initialize and release resources at the right time, and rely on onSaveInstanceState to persist small transient UI state.
