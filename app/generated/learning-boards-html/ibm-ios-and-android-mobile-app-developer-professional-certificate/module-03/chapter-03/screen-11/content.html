Module 3 › Chapter 3.3 › Background Work
Architecture
Place heavy work off the main thread
Use ViewModel, coroutines, or WorkManager to perform long tasks and keep lifecycle methods fast.
Pattern
Listener → ViewModel/worker → Background task → LiveData/observer updates UI.
Misconception
ViewModel helps retain objects across rotation but you still must persist small UI state separately if needed.
Concrete example
On Login tap, call viewModel.login(username, password) which launches a coroutine. Observe LiveData to update UI and show Toast or Snackbar on completion.
Key Takeaway

Keep lifecycle methods and listeners free of blocking work. Use lifecycle-aware patterns to coordinate background tasks and UI updates.
