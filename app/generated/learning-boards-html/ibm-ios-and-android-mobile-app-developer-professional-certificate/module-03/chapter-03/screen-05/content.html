Process
Wire the Login Action
Follow these steps to make the UI respond to a tap without blocking the UI thread.
Steps
  1. Call setContentView in onCreate.
  2. Use findViewById to get EditText and Button.
  3. Set setOnClickListener on the Button.
  4. Inside listener, call .text.toString() and validate.
  5. Show Toast or Snackbar; delegate network work off the UI thread.
Pitfall
Running long operations here freezes the UI. Use coroutines or background threads for network and database work.
Key Takeaway

Keep listeners focused on UI tasks: validate, give feedback, and hand off heavy work to background routines to keep the app responsive.

Live code panel: this is the exact pattern you will type into MainActivity to make the Login button respond.
// snippet inside onCreate()
val usernameEditText: EditText = findViewById(R.id.editTextUsername)
val passwordEditText: EditText = findViewById(R.id.editTextPassword)
val loginButton: Button = findViewById(R.id.buttonLogin)

loginButton.setOnClickListener {
  val username = usernameEditText.text.toString()
  val password = passwordEditText.text.toString()
  if (username.isNotEmpty() && password.isNotEmpty()) {
    Toast.makeText(this, "Logging in as $username", Toast.LENGTH_SHORT).show()
    // TODO: start async auth task
  } else {
    Toast.makeText(this, "Please fill all fields.", Toast.LENGTH_LONG).show()
  }
}
Example
Tapping Login with empty fields shows a long Toast prompting completion; with values, a short Toast appears confirming action.
Pro tip
Debounce rapid taps by disabling the button until the operation completes, or use a short cooldown timer.
