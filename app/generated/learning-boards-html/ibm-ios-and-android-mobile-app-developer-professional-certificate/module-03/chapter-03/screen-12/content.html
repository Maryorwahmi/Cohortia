Common mistakes and remedies
Short examples show the cause and the recommended fix.
Forgetting .toString()
Cause: using Editable directly. Fix: call editText.text.toString() before validation or sending to backend.
Blocking UI in listeners
Cause: synchronous network calls. Fix: launch asynchronous task in ViewModel or coroutine.
Relying on onDestroy
Cause: assuming final cleanup runs. Fix: save essential transient state in onSaveInstanceState, use persistent storage for long-lived data.
Quick checklist
  • Convert Editable → String
  • Offload long tasks
  • Save transient state
  • Debounce rapid taps
  • Use Snackbars for actions
