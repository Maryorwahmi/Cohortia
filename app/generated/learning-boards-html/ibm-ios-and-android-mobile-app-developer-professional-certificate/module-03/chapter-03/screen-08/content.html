Module 3 › Chapter 3.3 › Lifecycle Responsibilities
A careful plan for each callback
Assign concise responsibilities so your activity behaves predictably and performs well under navigation and configuration changes.
onCreate()
UI inflation, view binding, one-time setup.
onStart()
Prepare visibility-bound resources.
onResume()
Start animations, listeners, and exclusive resources.
onPause()
Quickly save UI state, stop animations; avoid heavy work here.
onStop()
Release large resources not needed while hidden.
onDestroy()
Final cleanup if called; do not rely on it for essential persistence.
Performance guidance
Avoid blocking the UI thread in any lifecycle method. Use lifecycle-aware components, coroutines, or background threads for I/O. Keep onPause especially fast.
Quick question
If a preference save takes 300ms, where should you perform it so the UI does not stutter? Think about async patterns and where to trigger them.
