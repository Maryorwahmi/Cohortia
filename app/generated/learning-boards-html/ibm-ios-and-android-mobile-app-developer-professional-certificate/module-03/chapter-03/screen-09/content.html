Module 3 › Chapter 3.3 › Save & Restore
Definition
Saving UI State
Use onSaveInstanceState to persist small transient values into a Bundle before possible destruction; restore them in onCreate.
Guideline
Save minimal, primitive or parcelable-friendly values. Avoid heavy data. Use preferences or database for long-lived data.
Key Takeaway

Persist transient UI state to survive configuration changes and unexpected system-initiated destruction.

Code example: saving a username string in onSaveInstanceState and restoring it in onCreate.
override fun onSaveInstanceState(outState: Bundle) {
  super.onSaveInstanceState(outState)
  val username = findViewById<EditText>(R.id.editTextUsername).text.toString()
  outState.putString("savedUsername", username)
}

override fun onCreate(savedInstanceState: Bundle?) {
  super.onCreate(savedInstanceState)
  setContentView(R.layout.activity_main)

  if (savedInstanceState != null) {
    val savedUsername = savedInstanceState.getString("savedUsername")
    findViewById<EditText>(R.id.editTextUsername).setText(savedUsername)
  }
}
Example
Rotate the device after typing in the username field. If you saved the value, the text reappears when the activity recreates.
