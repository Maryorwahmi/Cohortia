Module 3 › Chapter 3.3 › Key Concepts
Event Listener
An object that waits for and handles view events like taps and text changes.
Toast vs Snackbar
Toasts are brief and non-interactive; Snackbars can offer an action and are part of Material components.
Activity Lifecycle
onCreate → onStart → onResume → onPause → onStop → onDestroy: use each to manage resources and state.
Summary Takeaway

Design listeners to be quick, present clear feedback, and save transient UI data before potential destruction to maintain a reliable user experience.
