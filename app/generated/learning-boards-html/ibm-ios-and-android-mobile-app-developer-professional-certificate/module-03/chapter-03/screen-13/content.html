Lab: Login logic & lifecycle logs
Follow these steps and confirm Logcat output matches the expected lifecycle sequence.
Step 1 — Wire UI
findViewById each view, setOnClickListener on buttonLogin, read .text.toString(), validate and show Toasts.
Step 2 — Add logs
Add Log.d(TAG, "onCreate called") and similar in all lifecycle methods and filter Logcat by TAG.
Step 3 — Save state
Implement onSaveInstanceState to putString("savedUsername", username) and restore in onCreate.
Expected Logcat sequences
Launch: onCreate → onStart → onResume
Home: onPause → onStop
Return: onRestart → onStart → onResume
Rotate: onPause → onStop → onDestroy → onCreate → onStart → onResume
