Testing Pyramid
Unit Tests
Fast tests for individual functions and classes; run them often during development.
Integration Tests
Verify that modules work together correctly, for example ViewModel and repository interactions.
UI / Instrumentation Tests
Simulate user flows to validate user experience; use sparingly for critical paths.
Practical checklist
  • Write unit tests for business logic first.
  • Add integration tests for flows that combine modules.
  • Create one or two UI tests for the app's critical path.
Example
Unit test: assert addItem increases list length. Integration test: ensure item persisted via repository. UI test: simulate add flow and observe new item in list.
Key Takeaway

Balance test speed and coverage: fast unit tests prevent many regressions; use broader tests for integration and UI confidence.
