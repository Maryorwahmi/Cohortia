Module 6 › Chapter 6.5 › Performance Optimization
Performance first
Use profiling tools to identify slow frames, heavy allocations, and hotspot functions before changing code.
  • Move long tasks off the UI thread (coroutines, GCD, async/await, isolates).
  • Optimize images by resizing and using appropriate formats.
  • Batch or cache I/O and network calls to reduce work during rendering.
Comparison
Main-thread work: UI freezes and dropped frames. Background work: smooth interactions and responsive UI. Profile to decide where to move work.
Pro Tip

Use sampling profilers for CPU hotspots and memory allocation traces to find unexpected allocations that cause GC pauses.

Kotlin coroutine example: move work off main thread
fun loadAndProcess() {
  viewModelScope.launch(Dispatchers.IO) {
    val data = repository.fetchLargePayload()
    val processed = heavyProcessing(data)
    withContext(Dispatchers.Main) {
      _uiState.value = processed
    }
  }
}
Common Mistake
Running heavy synchronous loops during UI rendering or decoding full-size images on the main thread.
Measure
Only optimize code paths identified by profiling. Measure before and after each change to confirm improvement.
Try this
Run the profiler, identify one slow frame or allocation, and refactor that code to run asynchronously. Re-run and compare the frame times to confirm the improvement.
