Flutter widget test (counter example)
// Example widget test
import 'package:flutter_test/flutter_test.dart';
import 'package:flutter/material.dart';

void main() {
  testWidgets('Counter increments smoke test', (WidgetTester tester) async {
    await tester.pumpWidget(const MyApp());

    expect(find.text('0'), findsOneWidget);
    expect(find.text('1'), findsNothing);

    await tester.tap(find.byIcon(Icons.add));
    await tester.pump();

    expect(find.text('0'), findsNothing);
    expect(find.text('1'), findsOneWidget);
  });
}
Tip: make assertions on visible text and behavior rather than on internal widget structure to keep tests robust.
Test checklist
  • Build the widget in the test harness.
  • Verify initial state with expect() calls.
  • Simulate user actions with tester.tap() and tester.pump().
  • Assert final state matches expectations.
Common mistake
Relying on timing without controlling pumps can make tests flaky; prefer deterministic pumps and mock async sources.
Key Takeaway

Automate critical UI interactions with widget tests to prevent regressions and speed iteration.
