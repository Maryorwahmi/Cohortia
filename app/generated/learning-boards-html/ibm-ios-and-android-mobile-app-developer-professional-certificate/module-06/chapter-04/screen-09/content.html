Code Walkthrough

Initialize and Branch

Example commands you might include in your README to help reviewers or collaborators.

git init
git add .
git commit -m "chore: initial commit"

git branch -m main
git remote add origin <remote-repo-url>
git push -u origin main

# Create a feature branch
git checkout -b feature/user-profile
# Work, then
git add .
git commit -m "feat: add user profile screen"
git push -u origin feature/user-profile
Branching Strategy
Use a simple feature-branch workflow: develop in branches, open pull requests for review, merge to main when ready. Keep main deployable.
Common Mistake
Working directly on main increases risk of regressions and makes rebasing harder. Avoid it.
