Manage Requests — Backlog & Time-box

Adopt a clear rule: only items marked MVP are allowed in the initial release.
Backlog Example
Priority A: essential; Priority B: nice-to-have; Priority C: future ideas.
Time-box
Allocate fixed time to build features; stop at the deadline to assess readiness.
Deferred List
Keep a visible list of deferred features so they can be prioritized for later releases without distracting the current work.
Check Your Understanding
If a stakeholder asks for a new reporting feature two weeks before launch, how would you evaluate it relative to MVP goals?
