Learning Objectives

Skills to plan, design, and manage your capstone project.

Bloom's taxonomy: Learn → Understand → Apply → Master
01
Define MVP & Scope
Distill core features that deliver value and document non-functional targets. Keeping scope tight prevents project failure from scope creep.
Venn: User need + Feasible + Minimal
VERIFIED COMPETENCY MILESTONE
02
Choose a Framework
Evaluate native iOS/Android versus Flutter or React Native based on performance, timeline, and device needs.
Timeline vs Performance chart
VERIFIED COMPETENCY MILESTONE
03
Wireframe UI/UX
Create wireframes and mockups to validate flows and spot usability issues before coding.
Mnemonic: Sketch → Iterate
VERIFIED COMPETENCY MILESTONE
04
Data & Git Workflow
Outline local vs remote data plans and establish a Git branching strategy for safe collaboration.
Mnemonic: Local first, sync later
VERIFIED COMPETENCY MILESTONE
Checkpoint

By passing each milestone, you demonstrate readiness to proceed: a documented MVP, framework choice rationale, basic wireframes, data plan, and a Git repo with a feature branch.
