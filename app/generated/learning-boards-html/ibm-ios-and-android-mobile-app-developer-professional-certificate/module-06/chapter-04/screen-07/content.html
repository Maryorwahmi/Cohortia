Module 6 › Chapter 6.4 › Data Management Strategy
Definition

Local, Remote, or Hybrid?

Decide where each piece of data lives and how updates flow between device and server.
Local Options
iOS: Core Data; Android: Room/SQLite; alternatives: Realm.
Remote Options
BaaS like Firebase or a custom REST/GraphQL backend for sync and sharing.
Hybrid Strategy Example
Notes app: local storage for offline access, sync to cloud for multi-device access. Specify sync triggers and conflict resolution rules.
Sync Considerations
When to push changes, conflict handling, and network error strategies.
Authentication
Plan token-based auth or OAuth where needed and document how tokens are stored and refreshed.
Key Takeaway

Prioritize local persistence for responsiveness; add remote sync when multi-device access or backups are required.
