Module 6 › Chapter 6.4 › Repo Structure

Recommended Layout

A minimal, reviewer-friendly layout:
  • src/ — application source code
  • assets/ — images and static assets
  • docs/ — wireframes and design notes
  • README.md — run instructions and MVP description
Pro Tip
Include a short script in README to build and run the app so reviewers can quickly validate functionality.

Collaboration Checklist

  • Create feature branches per task
  • Open pull requests with clear descriptions
  • Link PRs to milestones or issues
  • Run simple CI checks before merge
Why it matters
These practices make it easy to review changes, revert if needed, and demonstrate steady progress on your capstone.
