Process

Sketch → Validate → Mockup

Step 1: Sketch
Draw core screens for the primary flow using pen or low-fi tool.
Step 2: Validate
Test sketches with a peer or potential user to catch flow issues early.
Step 3: Mockup
Build higher-fidelity mockups for the screens that matter most to implementation.
Example Flow: Habit Tracker
Main List
Shows habits with quick toggles and progress.
Add Habit
Minimal fields: title, frequency, reminder toggle.
Habit Detail
Shows history and edit controls.
Pro Tip
Keep each wireframe to one task; cluttered screens hide usability issues.
