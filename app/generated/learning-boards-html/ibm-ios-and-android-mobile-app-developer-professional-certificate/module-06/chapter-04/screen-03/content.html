Module 6 › Chapter 6.4 › Practical Outcomes

Capstone Deliverables

Produce artifacts that show planning clarity and development readiness.

Problem Statement
One to two sentences describing the user and problem the app solves.
MVP Feature List
3–5 essential features; separate nice-to-haves to avoid scope creep.
Framework Justification
Short paragraph explaining framework choice relative to goals.
Wireframes
Simple sketches of main screens and navigation flow.
Checklist
  • Problem statement drafted
  • MVP and nice-to-have lists created
  • Framework choice justified
  • Wireframes for core flow attached
  • Git repo initialized with feature branch
