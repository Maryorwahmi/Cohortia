Module 6 › Chapter 6.4 › Define Scope & MVP
Definition

Minimum Viable Product

The smallest set of features that delivers the app's core value and allows early user feedback.

Example: Recipe Organizer
Essential: sign up, add recipe, search list. Defer: video uploads, social feeds.
Non-functional Requirements
Performance targets, basic security, and acceptable devices should be listed alongside features.
Key Takeaway

An MVP is focused and reliable — it tests the primary hypothesis without packing extraneous features.

Scope Decision Process
  1. Write a concise problem statement to clarify the primary user need.
  2. List all potential features and tag them as essential or deferred.
  3. Define success criteria for each essential feature to avoid ambiguity.
  4. Document non-functional targets that affect architecture or platform choice.
Common Mistake
Confusing MVP with a prototype. An MVP should be usable and meet acceptance criteria, not just a mock.
Acceptance Example
Success: A registered user can add a recipe and see it listed within two taps.
