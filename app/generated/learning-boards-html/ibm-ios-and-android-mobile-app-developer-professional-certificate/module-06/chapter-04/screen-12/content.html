Module 6 › Chapter 6.4 › Activity: Define MVP

Checklist

  1. Write a concise problem statement (1–2 sentences).
  2. List 3–5 essential MVP features and 2–3 deferred features.
  3. Select a framework and write a brief justification.
  4. Create wireframes for the core flow (main, add, detail).
  5. Initialize a Git repo and create a feature branch for the first screen.
Deliverables
Attach a short document with your problem statement, feature list, framework justification, and wireframe images. Push code with a feature branch so reviewers can inspect progress.
Reflection Prompt
What is the single metric or user action that will tell you your MVP is successful after release?
