Identity

Bundle ID & versioning

Set the bundle identifier to a unique reverse-DNS string such as com.yourcompany.yourappname and make sure it matches the App ID registered in App Store Connect. In the General tab set Version to what users will see and Build to an integer you increment with each new upload.

Example settings
Bundle Identifier: com.yourname.mytestapp
Version: 1.0
Build: 1
Tip

If you upload a new binary without changing the build number, App Store Connect will reject it because the build must be unique.

Practice
  1. Open your project's General tab and note Bundle Identifier, Version, and Build.
  2. Set Version to 1.0 and Build to 1, archive the project, and upload.
  3. Make a small change, increment Build to 2, archive again, and confirm App Store Connect accepts the new upload.
Common mistake

Treat the Version and Build as separate: version for users, build for uploads. Always increase the build number on each upload.
