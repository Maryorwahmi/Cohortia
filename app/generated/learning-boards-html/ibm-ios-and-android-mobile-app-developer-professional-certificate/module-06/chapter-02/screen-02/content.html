Instructor note

How to practice

Use a simple Hello World project, set a unique bundle identifier like com.yourname.mytestapp, enable automatic signing for practice, set version to 1.0 and build to 1, archive, and verify the archive appears in Organizer. Then upload and check TestFlight processing.

Tip: Increment build number for every upload.
Watch out: mismatched bundle IDs cause signing errors.
