Module 6 › Chapter 6.2 › Code Signing: What it is and why it matters
Definition

Code signing

Code signing uses a distribution certificate to show who published the app, and a provisioning profile to state which App ID and release channel the app is authorized for. Together they allow Xcode and Apple's servers to verify origin and integrity.

Concrete example
A test app with bundle ID com.yourname.mytestapp requires a provisioning profile that lists that exact App ID and a valid distribution certificate to upload a TestFlight build. If the profile lists a different App ID, signing fails.
Misconception check
Signing is not optional for distribution. You must have matching artifacts; automatic signing can help but you should still verify the matches.
Visual
Distribution Certificate
Identifies the developer and authorizes signing for distribution.
Provisioning Profile
Links App ID, certificate, and distribution channel (App Store or device list).
Bundle Identifier
Unique app id like com.yourcompany.yourappname — must match the profile.
Key Takeaway

Always confirm that certificate validity and the provisioning profile's App ID match your project's bundle identifier before archiving.
