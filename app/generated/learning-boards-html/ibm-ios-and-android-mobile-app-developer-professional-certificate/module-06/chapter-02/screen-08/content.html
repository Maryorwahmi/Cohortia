Module 6 › Chapter 6.2 › Using Xcode's Organizer to Upload Builds
Upload steps
1. Open Organizer and select the archive matching your Version/Build.
2. Click Distribute App → App Store Connect → Upload.
3. Confirm signing choices (automatic signing helps) and validate the archive.
4. Complete upload and monitor processing in App Store Connect.
What to check
  • Archive validation results for signing or missing assets.
  • Certificate and provisioning profile validity and App ID match.
  • Version and Build values correspond to the intended release.
Pro tip

Use automatic signing during practice to let Xcode create or choose matching profiles, but review generated profiles before relying on them for production releases.
