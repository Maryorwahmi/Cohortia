Module 6 › Chapter 6.2 › Archiving an App and what an .xcarchive contains
Steps

Create an archive

  1. Select a Generic iOS Device or physical device target.
  2. Choose Product > Archive — Xcode compiles and packages assets.
  3. Open Organizer, select the archive, and choose Distribute App to upload.
Archive contents
/MyApp.xcarchive
  - Info.plist (metadata)
  - Products/Applications/MyApp.app (binary)
  - dSYMs/ (debug symbol files)
Validation

Use Organizer's Validate step to catch signing or asset issues before upload. Validation surfaces mismatches between the archive and the provisioning profile or missing required resources.

Misconception
Archive does not equal upload. You must explicitly distribute the archive to App Store Connect through Organizer.
Key Takeaway

An archive contains the binary and symbol files required for distribution and crash reporting. Validate before upload to catch signing issues early.
