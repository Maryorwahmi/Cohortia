Process

Build a Signed Android App Bundle

Use Android Studio’s Generate Signed Bundle / APK wizard, choose AAB, select your signing config, and finish to create a signed .aab for Play.

Why AAB?

Play creates optimized APKs per device configuration, reducing download and install size for users.

Concrete Example

Upload myapp.aab to Play and Play produces smaller APKs for arm64 devices that exclude unnecessary binaries and resources.

Android Studio Steps
  1. Select Build → Generate Signed Bundle / APK
  2. Choose Android App Bundle and module
  3. Select signing configuration and finish build
Key Takeaway

AAB is the recommended Play publishing format because it enables smaller, optimized APKs at install time.

Misconception

AAB eliminates signing — incorrect. You must sign the AAB before upload using your keystore.
