Module 6 › Chapter 6.3 › Configuring build.gradle
Definition

Configure Gradle Signing

Reference your keystore so Gradle signs release builds automatically, and keep secrets out of version control.

Safer Practice

Store passwords in a gradle.properties file excluded from git, or use environment variables for CI systems.

Key Takeaway

A correct signing config prevents unsigned releases and supports reproducible builds.

Example build.gradle snippet
android {
    ...
    signingConfigs {
        release {
            storeFile file("your_keystore_name.jks") // Path to your keystore
            storePassword "your_store_password"
            keyAlias "your_key_alias"
            keyPassword "your_key_password"
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled true
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}
Note: Replace quoted passwords with secure lookups in real projects. This snippet shows the structure Gradle expects.
