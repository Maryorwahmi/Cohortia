Process Flow
Screenshots & localization
Capture UI that clearly shows the app’s main tasks and export per platform device sizes.
  1. Identify core flows to showcase, like task list and create task screens.
  2. Capture images on device or emulator at required resolutions.
  3. Localize in-image text or provide translated variants for different locales.
  4. Upload correct sets to App Store Connect and Play Console for each device family.
Example card
Phone screenshot
Show the main task list and an inset of the new task flow.
7-inch tablet
Highlight split layouts and secondary panes.
10-inch tablet
Show wider layouts and any tablet-only UI elements.
Common mistake
Using promotional mockups that do not match the current build. Reviewers expect screenshots to reflect the submitted app.
Key Takeaway

Capture and export screenshots per device family and localize where appropriate so listings are accurate and persuasive.
