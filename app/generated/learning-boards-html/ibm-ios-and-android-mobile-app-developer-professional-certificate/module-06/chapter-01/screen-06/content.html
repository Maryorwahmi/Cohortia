Definition
App icons: iOS and Android
Icons must be supplied at multiple sizes. The App Store specifically requires a high-resolution listing icon, and Android uses adaptive foreground/background layers.
Example requirements
Supply a 1024x1024 store icon for iOS and layered foreground/background assets for Android adaptive icons so system masks render correctly.
Common mistake
Upscaling a small image to meet a size requirement which produces a blurry result and may prompt reviewer rejection.
Pro tip
Design icons as vectors in your editor then export required raster sizes to avoid scaling artifacts.
Key Takeaway

Prepare a complete icon set and layered assets for Android so store listing and device icons look sharp and correct.

Asset checklist (visual)
iOS icon set
  • 1024x1024 App Store icon
  • Device sizes for settings and home screen at @1x, @2x, @3x
  • Organize into .xcassets for Xcode
Android adaptive icon
  • Foreground layer image
  • Background layer image
  • Export for multiple densities and place into mipmap folders
