Step 1 - Task model
class Task {
  String title;
  bool isCompleted;

  Task({required this.title, this.isCompleted = false});

  void toggleComplete() {
    isCompleted = !isCompleted;
  }
}
Step 2 - ToDoListModel
class ToDoListModel extends ChangeNotifier {
  final List<Task> _tasks = [];
  List<Task> get tasks => _tasks;

  void addTask(String title) {
    _tasks.add(Task(title: title));
    notifyListeners();
  }

  void toggleTaskCompletion(int index) { ... }
}
Step 3 - Provide
Wrap your app with ChangeNotifierProvider(create: (_) => ToDoListModel()). Use MultiProvider if you need more models.
Step 4 - Consume and UI tips
  • Use Consumer or context.watch to rebuild the ListView when tasks change.
  • Use context.read inside FloatingActionButton onPressed to add tasks.
  • Use Selector for individual tiles to avoid rebuilding the entire list.
