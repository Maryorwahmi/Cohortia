Module 4 › Chapter 4.3 › Mistakes & Debugging
Forgot notifyListeners
Symptom: UI doesn't update. Fix: call notifyListeners after mutations; add debug prints to confirm execution path.
Using watch in handlers
Watch is for build. Use read in onPressed and other callbacks to avoid build-time subscription errors.
Provider instantiation errors
Creating providers in build creates new instances. Provide at stable ancestors and use create to let Provider manage disposal.
DevTools tip

Use Flutter DevTools Provider tab to inspect active providers and their values. This quickly reveals duplicate instances and lifecycle anomalies.
