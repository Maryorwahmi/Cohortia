Module 4 › Chapter 4.3 › Provider placement
Provide at root for app-wide state
runApp(
  ChangeNotifierProvider(
    create: (context) => ToDoListModel(),
    child: const MyApp(),
  ),
);
Root placement gives a single shared instance to all descendants, ideal for user/session data or global lists.
MultiProvider
MultiProvider(
  providers: [
    ChangeNotifierProvider(create: (_) => ToDoListModel()),
    ChangeNotifierProvider(create: (_) => UserProfileModel()),
  ],
  child: const MyApp(),
)
Disposal note

If you use ChangeNotifierProvider with create, Provider disposes the model automatically. If you instantiate a model yourself and pass it with Provider.value or store it in a field, then call dispose on it when it's no longer needed to prevent leaks.

Mistake to avoid
Providing models inside build methods or creating new instances repeatedly leads to multiple models and unexpected behavior.
