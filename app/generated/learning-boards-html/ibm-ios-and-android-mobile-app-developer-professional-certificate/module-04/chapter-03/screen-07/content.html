Module 4 › Chapter 4.3 › Consume patterns
context.watch
Listens and rebuilds

Use in build when the widget must reflect model changes automatically.

context.read
Access without listening

Use in onPressed or event handlers to call model methods without subscribing to updates.

Consumer
Scoped rebuilds

Wrap a small subtree to control which part of the UI rebuilds when the model changes.

Selector

Selector extracts a value from a model and only rebuilds when that selected value changes. This reduces unnecessary rebuilds when your model contains many fields but the widget cares about one.

Example
Use Selector to watch a boolean completed flag for a single list tile so only that tile rebuilds when toggled.
Anti-pattern
Using watch inside an onPressed handler or wrapping large regions in Consumers indiscriminately.
