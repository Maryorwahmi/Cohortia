Practical Build

Follow a guided to-do list activity where you'll define Task and ToDoListModel, provide the model, and build a listening ListView. Each change calls notifyListeners to refresh listening widgets.

Step
Define models
Create Task and ToDoListModel extending ChangeNotifier.
Step
Provide models
Wrap MyApp with ChangeNotifierProvider or MultiProvider.
Step
Consume safely
Use context.watch in build, context.read in event handlers, and Selector when only part of the state matters.
Common checklist
  • Call notifyListeners after state changes.
  • Use context.read in buttons and handlers.
  • Dispose ChangeNotifier when not using create.
Testing idea: change the addTask method to guard empty titles and verify the list updates correctly in the UI.
