Module 4 › Chapter 4.1 › Widget tree
Hierarchy

Root to leaf

Root widget (MaterialApp) → Scaffold → AppBar / Body → Center → Text. Each widget's build returns widgets, composing the UI declaratively.
Misconception
Widgets are not heavyweight views. They are immutable descriptors, and Flutter efficiently updates the rendered output.
Concrete example
The main function calls runApp(const MyApp()), MyApp extends StatelessWidget, and build returns a MaterialApp with a Scaffold. This pattern is the typical starting point for many apps and shows how structure flows from a root widget.
When to use StatefulWidget
Use it when UI depends on mutable local state like form inputs or animation controllers.
Performance tip
Keep build methods fast and extract reusable widgets to avoid unnecessary rebuilds.
Key Takeaway
Design the widget tree deliberately. Small, focused widgets are easier to reuse, test, and maintain.
