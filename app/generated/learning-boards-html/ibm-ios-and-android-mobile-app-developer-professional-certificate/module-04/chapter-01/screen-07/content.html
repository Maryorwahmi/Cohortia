Module 4 › Chapter 4.1 › flutter doctor
Process

Read and act on output

flutter doctor
[✓] Flutter (Channel stable, ...)
[!] Android toolchain - develop for Android devices (some issues found)
    • Android SDK is missing component X
    • Run: flutter doctor --android-licenses
This sample shows how flutter doctor annotates the issue and often provides the command you need to run next. Execute suggestions in order and re-run flutter doctor until no major issues remain.
Example fixes
  • Accept Android licenses: flutter doctor --android-licenses
  • Install missing SDK tools via Android Studio's SDK Manager.
  • Install Xcode command-line tools on macOS when prompted.
Common pitfall
Skipping flutter doctor can hide configuration issues that only surface later as build failures or device connection errors.
