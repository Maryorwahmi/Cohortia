Frequent issues

  • PATH not set: flutter command not found. Add .../flutter/bin to PATH.
  • Android toolchain: missing SDK components or licenses. Run flutter doctor --android-licenses and install tools in Android Studio.
  • No device: start an emulator or connect a device and verify with flutter devices.
  • Dependencies: forgot flutter pub get after editing pubspec.yaml.

Checks to run now

Run these in order: flutter --version, flutter doctor, flutter devices, flutter pub get. Follow flutter doctor's suggested commands until no major issues remain.
