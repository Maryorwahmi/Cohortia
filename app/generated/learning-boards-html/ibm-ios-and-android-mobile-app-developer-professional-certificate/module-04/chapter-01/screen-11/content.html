Code
// lib/main.dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Hello Flutter',
      theme: ThemeData(
        primarySwatch: Colors.blue,
      ),
      home: Scaffold(
        appBar: AppBar(
          title: const Text('My First Flutter App'),
        ),
        body: const Center(
          child: Text(
            'Hello, Cohortia!',
            style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
          ),
        ),
      ),
    );
  }
}
Explain
Imports bring in Material widgets. main calls runApp, which mounts the widget tree. MyApp's build returns MaterialApp which sets theme and home. Scaffold provides AppBar and body layout. Text is the visible string you change.
Example edit
Change the Text string and AppBar title, save, and hot reload to see the update without restarting the app.
Key Takeaway
The starter main.dart shows the minimal pieces you modify first—Text content, TextStyle, and AppBar title—before adding more widgets.
