Module 4 › Chapter 4.1 › Personalize app
Activity steps
  1. Run flutter create my_personal_app and open lib/main.dart.
  2. Change the Text string to include your name.
  3. Adjust TextStyle: fontSize 30.0, color Colors.deepPurple, fontWeight FontWeight.w900.
  4. Edit AppBar title and set backgroundColor to Colors.green.
  5. Run flutter run and use hot reload to iterate.
Troubleshooting
If dependencies changed, run flutter pub get. If emulator is not visible, confirm with flutter devices.
Example edits
body: const Center(
  child: Text(
    'Hello, Alex! Welcome to Flutter!',
    style: TextStyle(fontSize: 30.0, fontWeight: FontWeight.w900, color: Colors.deepPurple),
  ),
),
appBar: AppBar(
  title: const Text('My Awesome App'),
  backgroundColor: Colors.green,
),
Key Takeaway
Personalizing UI text and style is the fastest way to validate your setup and gain confidence with hot reload.
