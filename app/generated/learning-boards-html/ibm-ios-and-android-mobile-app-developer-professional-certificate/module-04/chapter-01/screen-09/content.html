Module 4 › Chapter 4.1 › Run your app
Commands
flutter devices
flutter run
flutter run -d <device_id>
List devices first, then target a specific device when necessary. Use the ID returned by flutter devices in the run command. This avoids launching on the wrong emulator.
Example
If flutter devices shows emulator-5554, run flutter run -d emulator-5554 to launch on it. Once running, press r in the terminal or use your IDE hot reload command to apply changes.
Common mistake
Trying to run without an emulator or device will cause a failure; confirm a target with flutter devices first.
