Module 4 › Chapter 4.1 › Create Project
Command

flutter create my_first_app

Run the command in a terminal. It generates folders and a default counter app so you can compile and run immediately.
Important files
  • lib/ — Dart source files, edit main.dart here.
  • pubspec.yaml — Dependencies and assets configuration.
  • android/ios/ — Platform-level build configs when needed.
Example
Open lib/main.dart to see the generated app. Modify the Text widget in the Center to personalize the greeting, then save and hot reload to preview changes instantly.
Key Takeaway
The scaffolded project contains everything you need to begin; most iteration happens inside lib and pubspec.yaml.
