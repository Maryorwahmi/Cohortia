Module 4 › Chapter 4.1 › Learning Objectives — Practical
Task checklist
  1. 1.
    Run flutter doctor and follow suggested fixes for SDKs or licenses.
  2. 2.
    Create a project with flutter create my_first_app and inspect lib and pubspec.yaml.
  3. 3.
    Edit lib/main.dart, change the text widget content and AppBar title, then save.
  4. 4.
    Run flutter run, select a device if needed, and use hot reload to iterate.
Verification tips
  • After flutter doctor shows no major issues, try flutter devices to see connected targets.
  • If licenses are missing on Android, run flutter doctor --android-licenses.
