Module 4 › Chapter 4.2 › Container: Styling, Positioning, Sizing
What Container does
  • Add padding around a child and set explicit width/height.
  • Apply decoration: color, border, boxShadow, borderRadius.
  • Position children inside layout constraints.
Tip: Prefer Padding for padding-only needs and SizedBox for fixed spacing. Use Container when you combine decoration with sizing.
Example
Container(
  padding: EdgeInsets.all(16.0),
  margin: EdgeInsets.only(bottom: 20.0),
  decoration: BoxDecoration(
    color: Colors.blueAccent,
    borderRadius: BorderRadius.circular(10.0),
    boxShadow: [BoxShadow(color: Colors.black26, blurRadius: 8.0, offset: Offset(0,4))],
  ),
  child: Text('Welcome to Cohortia!', style: TextStyle(fontSize:22,color:Colors.white)),
)
Takeaway: Container combines visual decoration and layout control—use it thoughtfully to keep widget trees readable.
