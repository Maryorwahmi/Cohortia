Module 4 › Chapter 4.2 › Row vs Column
Row (horizontal)
Main axis: horizontal. Use mainAxisAlignment to control left-right placement. Use Expanded to let children grow to fill available horizontal space.
Column (vertical)
Main axis: vertical. Use mainAxisAlignment to control top-bottom placement. Wrap children with Flexible or SizedBox when height is constrained.
Practical patterns
  • Use Row for toolbars and horizontal icon groups.
  • Use Column for stacked content and vertical forms.
  • Use Expanded to distribute remaining space and prevent overflow.
Debugging tip: Overflowed errors usually indicate a child has unbounded size; add constraints or Flexible wrappers to fix it.
