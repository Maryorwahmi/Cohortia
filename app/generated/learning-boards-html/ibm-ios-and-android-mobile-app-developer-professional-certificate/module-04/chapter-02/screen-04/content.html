Module 4 › Chapter 4.2 › Everything is a Widget
Definition

Widgets are immutable UI descriptions

A widget describes how a part of the interface should look given its configuration. When data changes, Flutter builds new widgets and updates the display efficiently.

Analogy: Widgets are like LEGO bricks — small parts composed into greater structures.
Misconception: Immutability means static UI. Reality: mutable state lives in State objects when needed.
Key Takeaway: Composition and immutability make reasoning about UI predictable and testable.
Concrete Example
Start with a Text widget. Wrap it in a Container to add padding and color. Change the color; Flutter builds new widget instances and patches the screen.
Check your understanding
Why does Flutter rebuild widgets instead of mutating them? Think about predictability and rendering simplicity.
When would you avoid rebuilding an expensive subtree? Consider extracting it into a const widget or using keys.
