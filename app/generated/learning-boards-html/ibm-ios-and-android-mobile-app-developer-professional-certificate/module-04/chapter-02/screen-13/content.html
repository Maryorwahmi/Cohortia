Scaffold
Provides appBar, body, floatingActionButton and other high-level slots for a page.
Row / Column
Axis-based widgets for horizontal and vertical layout with alignment controls.
Container
Wrapper for padding, decoration, sizing; use when you need combined visual properties.
Final takeaway

Start small, compose consistently, and keep mutable state isolated. These rules will make your Flutter UIs easier to build and maintain.
