Module 4 › Chapter 4.2 › StatelessWidget Example
Code
import 'package:flutter/material.dart';

class MyTitle extends StatelessWidget {
  final String title; // This is immutable

  const MyTitle({super.key, required this.title});

  @override
  Widget build(BuildContext context) {
    return Text(
      title,
      style: const TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
    );
  }
}
Explanation & Best Practices
  • Keep fields final; StatelessWidget should not hold mutable data.
  • Let parents supply changing data; the parent rebuilds to pass a new value.
  • Extract truly static widgets as const constructors to avoid rebuild cost.
Takeaway: Use StatelessWidget for predictable, configuration-driven UI and push state upward when possible.
