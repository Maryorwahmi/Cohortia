Module 4 › Chapter 4.2 › Scaffold, Row, Column — Layout Primitives
Key properties
  • Scaffold: provides appBar, body, floatingActionButton, and drawer placeholders.
  • Row: horizontal layout; mainAxisAlignment controls left‑to‑right distribution.
  • Column: vertical layout; mainAxisAlignment controls top‑to‑bottom distribution.
Misconception: mainAxisAlignment.end on a Column pushes children to the bottom of the column, not to the right. Remember which axis is affected.
Concrete layout example
Scaffold(
  appBar: AppBar(title: Text('Widget Layout Demo')),
  body: Center(
    child: Column(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        Container(padding: EdgeInsets.all(16.0), child: Text('Welcome')),
        Row(mainAxisAlignment: MainAxisAlignment.spaceEvenly, children: [Icon(Icons.star), Icon(Icons.favorite)]),
      ],
    ),
  ),
)
Takeaway: visualize axes and practice small layout experiments to develop intuition and prevent over-nesting.
