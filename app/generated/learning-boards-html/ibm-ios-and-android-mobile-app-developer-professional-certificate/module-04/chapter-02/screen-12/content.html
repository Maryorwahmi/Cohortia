Widget Tree
A hierarchical structure of widgets that defines layout and rendering order.
StatelessWidget
Immutable widget rendered from constructor values; no internal state.
StatefulWidget
Paired with a State object that holds mutable data and calls setState to rebuild.
Quick Summary

Use the widget tree to organize UI, prefer stateless widgets where possible, and keep mutable data inside State objects to control updates.
