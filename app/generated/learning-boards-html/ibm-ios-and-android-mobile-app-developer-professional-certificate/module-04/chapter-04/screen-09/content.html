Module 5 › Chapter 4.4 › pushNamed & arguments
Usage
// Send arguments
Navigator.pushNamed(
  context,
  '/second',
  arguments: 'Data via Named Route!'
);

// Retrieve in destination
final String? data = ModalRoute.of(context)?.settings.arguments as String?;
Safety checklist
  • Cast arguments to the expected type using as Type?.
  • Check for null before using the value in your UI.
  • Prefer small, simple objects or maps for arguments to avoid complex serialization across routes.
Example

Navigate to /detail with a product id string as arguments, then display it in the detail screen, guarding against null or wrong types.
