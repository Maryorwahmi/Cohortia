Example retrieval with null check
final String? data = ModalRoute.of(context)?.settings.arguments as String?;

return Scaffold(
  appBar: AppBar(title: const Text('Detail Screen')),
  body: Center(
    child: Text('Received: ${data ?? "No data received"}'),
  ),
);
Avoid force-casting without checks. Prefer nullable casts and user-friendly fallbacks so your app degrades gracefully when arguments are absent or incorrect.
