Common methods
// Replace the current route
Navigator.pushReplacementNamed(context, '/home');

// Push and remove until predicate is true (e.g., clear all previous)
Navigator.pushAndRemoveUntil(
  context,
  MaterialPageRoute(builder: (context) => const HomeScreen()),
  (route) => false,
);
When to use
  • pushReplacementNamed: replace a single route like login after success.
  • pushAndRemoveUntil: clear multiple routes, useful after onboarding or for resetting the app to a fresh state.
  • Always consider user expectations for back navigation when removing history.
Use case

After a successful login, replace the login screen so pressing back does not return the user to the login flow.
