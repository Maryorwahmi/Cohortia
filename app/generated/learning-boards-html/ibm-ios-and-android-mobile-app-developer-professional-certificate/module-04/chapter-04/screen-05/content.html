Module 5 › Chapter 4.4 › Navigator.push & pop
Code pattern
// Push a new route
Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => const SecondScreen()),
);

// Pop the current route
Navigator.pop(context);
Explanation
  • MaterialPageRoute wraps a widget and provides a platform-adaptive transition.
  • push adds a Route to the top of the Navigator's stack and shows it.
  • pop removes the top Route and returns to the previous one.
  • Awaiting push lets you receive a value returned by pop.
Example scenario

A product list pushes a product detail screen. When the user saves changes on the detail screen, popping with a result can update the list immediately.
