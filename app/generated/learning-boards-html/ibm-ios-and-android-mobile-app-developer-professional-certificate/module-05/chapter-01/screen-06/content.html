Module 5 › Chapter 5.1 › Environment Setup
Step-by-step
  1. Install Node.js (LTS) and verify with node -v.
  2. Install Expo CLI globally: npm install -g expo-cli.
  3. Install Xcode for iOS simulators (macOS) and Android Studio for Android emulators.
  4. Install Expo Go on your phone for quick device testing.
Common Pitfall

Skipping SDK installs for simulators or using an older Node version often causes early failures.

Quick Commands
npm install -g expo-cli
node -v
If you encounter package install errors, check your Node version and your network/firewall settings. Temporarily disabling strict firewall rules or using a different network often resolves connectivity problems to the npm registry.
Why this matters
A healthy environment reduces friction and keeps the focus on learning React Native rather than fighting tools.
