Checklist: Environment Health
  • Confirm Node LTS is installed and check node -v.
  • Install Expo CLI using npm and confirm expo --version.
  • Ensure Xcode for iOS simulators and Android Studio for Android emulators are installed when needed.
  • Check network connectivity and temporarily disable strict firewalls if the dev server does not respond.
Common Mistake

Trying to run a simulator without installing platform SDKs, or using a very old Node version that breaks package installs.

Quick Commands
Install Expo CLI
npm install -g expo-cli
Create and start a project
expo init MyFirstReactNativeApp
cd MyFirstReactNativeApp
npm start
