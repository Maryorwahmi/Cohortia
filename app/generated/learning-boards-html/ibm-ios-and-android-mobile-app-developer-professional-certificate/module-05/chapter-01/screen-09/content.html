What Expo does
  • Provides a CLI to scaffold and run apps quickly.
  • Includes many native APIs available without native code.
  • Offers Expo Go to run projects on physical devices via QR codes.
When to eject

If you need a native module that Expo doesn’t support, you can migrate to a bare workflow to integrate custom native code.

Concrete Example

If you need camera access, Expo’s camera library often covers the requirement without writing native code. For specialized hardware or unique native SDKs, you may need to add a native module or eject to the bare workflow.

Key Takeaway
Use Expo to speed prototyping and learning, and plan for a migration path if your app requires custom native capabilities later.
