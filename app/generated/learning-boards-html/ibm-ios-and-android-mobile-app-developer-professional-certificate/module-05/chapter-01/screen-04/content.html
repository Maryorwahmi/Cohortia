Module 5 › Chapter 5.1 › What is React Native?
Definition

React Native is a framework for building native mobile apps using JavaScript and React. Components like View, Text, and Image map to native platform controls rather than being rendered inside a WebView.

Analogy
Think of React Native as writing a script in JavaScript that directs native actors on stage; the actors are native UI components.
Misconception
React Native does not remove the need for native code in all cases; native modules remain an option for platform-specific functionality.
Key Takeaway

You get native UI performance with familiar React patterns, and you can add native modules when JavaScript alone isn't enough.

Mapping Example
A Text component you declare in JavaScript renders as a platform text control. In practice this means layout and accessibility behave like native elements, improving performance and user experience compared to hybrid web views.
Scenario
You are prototyping a feed. Most layout and list logic can be shared between iOS and Android. For a custom camera plugin you might use an existing native module or write a small bridge.
Check your understanding
When would you prefer to write a native module? When you need access to low-level platform APIs or to optimize a performance-critical path that JavaScript cannot handle effectively.
