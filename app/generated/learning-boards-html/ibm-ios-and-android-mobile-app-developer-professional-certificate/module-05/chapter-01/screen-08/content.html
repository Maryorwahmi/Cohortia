Try this

Change the title text and background color, save the file, and observe live reload on your device or simulator.

Practical notes
  • Live reload speeds iteration but avoid frequent heavy computation in render functions.
  • If changes don't appear, confirm the dev server is running and that you edited the active App.js file.
  • Use Expo Developer Tools to control devices and simulators.
Misconception
Live reload is not a production hot-swap; it speeds development but production builds are created separately.
