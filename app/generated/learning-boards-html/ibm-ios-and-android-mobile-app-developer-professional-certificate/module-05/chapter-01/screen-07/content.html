Module 5 › Chapter 5.1 › Create a Project
Terminal Demo (scaffold)
npm install -g expo-cli
expo init MyFirstReactNativeApp
When prompted, choose the blank template for a minimal starting point. This creates a new directory and installs dependencies automatically.
Tip

If expo init stalls, check your network and retry. Use npm to install expo-cli if you prefer npm-based tooling.

Start the App
cd MyFirstReactNativeApp
npm start
This starts the Expo dev server and opens the Expo Developer Tools in your browser, where you can select a simulator, emulator, or scan a QR code with Expo Go on your mobile device.
Check
Ensure you run these commands from the newly created project directory. Running npm start elsewhere will fail to find project files.
