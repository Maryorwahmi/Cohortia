Module 5 › Chapter 5.1 › Hands-on Activity
Activity Steps
  1. expo init MyCustomApp → choose blank template.
  2. cd MyCustomApp → npm start to launch the dev server.
  3. Open App.js, change the displayed Text and background color, save to observe live reload.
Debugging Tip
Keep the terminal visible for error logs. Syntax errors will show immediately in the terminal and the device logs.

Why this matters
Small, iterative edits plus live reload accelerate learning and reduce feedback time when building UI.
