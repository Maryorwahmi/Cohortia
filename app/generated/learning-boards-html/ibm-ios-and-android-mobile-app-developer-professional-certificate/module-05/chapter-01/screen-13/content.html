Module 5 › Chapter 5.1 › Run Targets & Testing
Timeline: Test progression
  1. Start on simulator/emulator for rapid iteration.
  2. Use Expo Go and QR code to test on a physical device.
  3. Validate sensors, performance, and touch interactions on hardware.
Network note
For Expo Go, ensure your device and development machine share the same local network or use USB forwarding if supported.
Concrete Example
Test a camera or sensor flow on a real device because simulators often mock or lack accurate sensor behavior. Confirm performance and UI responsiveness under real-world conditions before release.
Key Takeaway
Simulators are great for speed; devices are required for final validation. Use both as part of your testing routine.
