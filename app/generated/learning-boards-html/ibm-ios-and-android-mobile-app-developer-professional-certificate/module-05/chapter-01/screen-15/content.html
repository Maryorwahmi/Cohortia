Module 5 › Chapter 5.1 › Key Concepts
React Native
Framework to build native mobile apps with JavaScript and React.
Cross-Platform Development
Develop once and run on iOS and Android with a shared codebase.
Native UI Components
UI elements map to platform-native widgets for performance and platform feel.
Summary takeaway
Use React Native for fast cross-platform development, rely on Expo to bootstrap and iterate, and add native modules only when required.
