Module 5 › Chapter 5.1 › Troubleshooting
Symptoms & Solutions
Symptom: npm install fails or expo init stalls. Fix: check node -v, try a different network, or temporarily disable strict firewalls.
Symptom: Simulator won’t start. Fix: ensure Xcode or Android Studio SDKs are installed and emulators are configured.
Symptom: Live reload not reflecting changes. Fix: confirm you are editing the active App.js and restart the dev server if needed.
Pro Tip
Use the Expo Developer Tools to see QR codes, logs, and run targets. They often simplify troubleshooting connectivity and device selection.
Terminal Diagnostics
# Check Node
node -v
# If expo commands fail
expo --version
# Restart dev server if needed
npm start
Why logs matter

Terminal logs show stack traces and errors that point to missing modules, syntax errors, or network failures — use them as the first diagnostic tool.
