What are native modules?

Native modules are platform-specific code components written in Swift, Objective-C, Java, or Kotlin that expose native APIs to JavaScript through a bridge. Use them for functionality not available in JavaScript libraries or when you need optimized native performance.

Example
A custom camera SDK with low-level image processing may require a native module to achieve the necessary performance and access.
Misconception

React Native does not fully eliminate native code; it minimizes it and provides a bridge when needed.

Practical path
Start with Expo and available community packages. If required functionality is missing, consider a bare workflow and add a small native module; keep native code limited and well-documented.
Key Takeaway
Reserve native modules for cases where JavaScript lacks access or performance; prefer community packages first to reduce complexity.
