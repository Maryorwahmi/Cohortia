Module 5 › Chapter 5.3 › Functional Updates
Direct update
// direct update
setCount(count + 1);
This reads the current count variable. If multiple updates happen before a render, this value may be stale.
Functional updater
// functional updater
setCount(prev => prev + 1);
This always receives the latest previous state, ensuring increments are correct even when updates are batched.
Try this
Trigger three quick increments and compare which approach yields three increments consistently.
Pitfall
Using direct updates in async callbacks can quietly drop updates; tests may hide the issue outside rapid interactions.
Key Takeaway
When the new state depends on prior state, use the updater form to ensure correctness.
