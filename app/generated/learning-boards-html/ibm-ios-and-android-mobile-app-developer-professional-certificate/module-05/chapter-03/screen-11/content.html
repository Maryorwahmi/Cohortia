TodoListScreen (state + effect)
// TodoListScreen.js (excerpt)
const [todos, setTodos] = useState([{id:'1', text:'Learn hooks'}]);

React.useEffect(() => {
  if (route.params?.newTask) {
    const { newTask } = route.params;
    setTodos(current => [...current, { id: String(current.length + 1), text: newTask }]);
    navigation.setParams({ newTask: undefined });
  }
}, [route.params?.newTask, navigation]);
This effect appends a new task when the param arrives and clears it to avoid duplicates on future focuses.
AddTaskScreen (send small param)
// AddTaskScreen.js (excerpt)
const [taskText, setTaskText] = useState('');

const handleSave = () => {
  if (taskText.trim()) {
    navigation.navigate('TodoList', { newTask: taskText });
  }
};
Pass the new task as a small param. The list screen integrates it into its state and becomes the single source of truth.
Key Takeaway
Keep authoritative data in one place and use navigation params for small, transient handoffs between screens.
Pro tip
Use navigation.addListener('focus') to refresh data when the screen becomes active, especially if data can change elsewhere.
Watch out
Do not pass large objects or entire arrays as params; prefer identifiers and fetch or reconstruct heavy data on the destination.
