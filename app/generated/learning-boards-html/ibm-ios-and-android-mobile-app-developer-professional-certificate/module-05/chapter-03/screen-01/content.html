State Management and Navigation in React Native
Build interactive screens using hooks, and move between them with React Navigation's stack pattern.

This module shows three practical skills: adding local state with useState, performing controlled side effects with useEffect, and wiring a simple stack navigator to move between screens while passing parameters. You'll see code examples, common pitfalls, and a short hands-on plan to build a to-do flow.
