Module 5 › Chapter 5.3 › Key Concepts
useState
A hook for component-local state; returns a value and a setter to trigger re-renders.
useEffect
Run code after render for side effects and control execution with a dependency array.
Side Effects
Operations that reach outside the component, like network calls or subscriptions; manage and clean them carefully.
Summary takeaway: Use state for ephemeral UI, effects for after-render work, and disciplined dependencies to keep the app predictable. Small, clear params in navigation keep flows lightweight and secure.
