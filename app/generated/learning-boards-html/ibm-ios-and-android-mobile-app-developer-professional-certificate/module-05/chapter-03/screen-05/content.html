Counter example
// App.js
import React, { useState } from 'react';
import { View, Text } from 'react-native';

export default function CounterApp() {
  const [count, setCount] = useState(0); // initialize

  const increment = () => setCount(prev => prev + 1); // safe update
  const decrement = () => setCount(prev => prev - 1);

  return (
    <View>
      <Text>Count: {count}</Text>
      {/* UI controls would call increment/decrement */}
    </View>
  );
}
This code shows the pattern: useState returns [value, setter]. Use the updater function form when the new value is derived from the previous one.
Supporting points
  • State updates schedule re-renders; they are not always immediate.
  • Functional updates avoid stale reads in rapid updates or async contexts.
  • Keep state minimal—derived values can be computed from state when rendering.
Common mistake
Using setCount(count + 1) in a handler that may run multiple times quickly can lead to missed increments. Use the prev form instead.
