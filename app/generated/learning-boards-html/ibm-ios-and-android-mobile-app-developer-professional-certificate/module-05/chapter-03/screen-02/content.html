Perform side effects (useEffect)
Run code after renders for tasks like logging or fetching. Controlling when effects run prevents unnecessary network calls and infinite loops.
Mnemonic: Dependency array controls timing

Set up Stack Navigator
Wrap your app with NavigationContainer and declare screens. A clear navigation structure makes flows predictable for users.
Timeline: install → wrap → declare screens

Pass and read params between screens
Use navigation.navigate with a params object and access route.params on the destination. Prefer IDs for large data to avoid heavy parameter payloads.
Mnemonic: pass small keys, fetch large data
