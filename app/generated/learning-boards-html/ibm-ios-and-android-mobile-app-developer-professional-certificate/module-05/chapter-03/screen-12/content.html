Lifecycle phases
Render
Triggered by state or prop changes; returns UI to display.
Effect
Runs after the render. Controlled by dependencies.
Cleanup
Runs before next effect or on unmount to avoid leaks.
Example: subscribe in an effect, update state on events, and cleanup by unsubscribing. If the event handler updates state frequently, design your updates and dependencies so the UI remains stable and avoids unnecessary re-renders.
Key Takeaway
Think in terms of render phases and control effects to prevent loops and memory leaks.
Check
If an effect updates state, ensure that update does not re-trigger the effect unless intended by dependencies.
