Logging when count changes
// Example: log count changes
import React, { useState, useEffect } from 'react';

function CounterApp() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log('Count has changed to:', count);
    // cleanup not needed for simple logging
  }, [count]); // runs when 'count' changes

  return null; // UI omitted for brevity
}
The effect runs after each render in which count changed. Use the dependency array to precisely control effect triggers and avoid extra work.
Supporting notes
  • Empty dependency array: run once after mount.
  • No array: run after every render (dangerous for heavy work).
  • Return a cleanup function to unsubscribe or cancel timers.
Common mistake
Including non-stable values (like new inline functions or objects) causes effects to re-run each render. Memoize or list minimal dependencies.
