Module 5 › Chapter 5.3 › Dependency Arrays
Empty array []
Runs once after initial render. Use for setup or one-time fetches.
Specific deps [a, b]
Runs when any listed variable changes. Use to react to particular state changes.
No array
Runs after every render. Often undesirable and may cause loops.
Example pitfall: listing an inline object or function as a dependency will usually trigger the effect every render because those references are new each time. Solutions include memoizing functions or moving stable values into state or refs.
Pro tip
When uncertain, list the minimal set of dependencies and test. Use ESLint rules for hooks to surface missing dependencies.
Warning
Effects that update state without careful dependency lists are a common source of infinite render loops.
