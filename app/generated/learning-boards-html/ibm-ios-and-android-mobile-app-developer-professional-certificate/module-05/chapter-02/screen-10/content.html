Refactor example
// styles example const styles = StyleSheet.create({ container: { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 20 }, header: { fontSize: 24, fontWeight: 'bold' }, card: { backgroundColor: '#fff', borderRadius: 10, padding: 16, width: '90%' }, buttons: { flexDirection: 'row', justifyContent: 'space-around', width: '100%' } });
When to use StyleSheet
Use StyleSheet when styles are reused or when you want a clear separation between layout and component logic. It helps readability and can lower runtime cost when style objects are stable across renders.
Key Takeaway

Refactor repeated or complex inline styles into StyleSheet.create to centralize styles and improve maintainability.

Misconception
StyleSheet alone won't fix performance if you recreate large style objects on every render. Keep styles stable and reuse references.
