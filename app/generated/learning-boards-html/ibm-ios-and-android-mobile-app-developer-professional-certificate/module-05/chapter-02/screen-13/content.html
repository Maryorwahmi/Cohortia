Module 5 › Chapter 5.2 › Common Mistakes
Troubleshooting checklist
  • Text not rendering properly: ensure strings are wrapped in Text.
  • Incorrect units: use numbers for dp, avoid 'px' and 'em'.
  • Axis confusion: draw the main and cross axis when debugging Flexbox.
  • Style duplication: move repeated styles into StyleSheet.create.
  • Accessibility: add accessibilityLabel for images and touchables.
  • Fixed widths: prefer flex or percentage widths for responsiveness.
Debug approach
Change one property at a time, re-run, and observe. Use small test containers to isolate behavior and log layout boxes if necessary. Visualizing axes solves many alignment problems quickly.
Pro tip

Keep a small utilities stylesheet for margins and spacing to avoid scattered numbers and inconsistent spacing across components.
