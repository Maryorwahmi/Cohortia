Four-step layout process
1
Choose axis
Decide whether children flow vertically (column) or horizontally (row).
2
Reserve regions
Use nested Views with flex ratios to allocate header, body, and footer space.
3
Distribute main-axis
Use justifyContent to align children along the main axis (space-between, center, space-around).
4
Align cross-axis
Use alignItems to position children on the cross axis (stretch, center, flex-start).
Concrete example
To center a login form vertically, set the container to flex:1 and justifyContent:'center'. To center inputs horizontally as well, add alignItems:'center'.
Visual reminder
Main axis: direction items flow (depends on flexDirection). Cross axis: perpendicular to main axis.
flex: controls how much a child grows to fill available space. A child with flex:1 will expand.
Key Takeaway

Always label axes in your head: if you know the main axis, justifyContent and alignItems become predictable tools.

Common mistake
Applying justifyContent when you meant alignItems. If items move in the wrong direction, check which axis is active.
