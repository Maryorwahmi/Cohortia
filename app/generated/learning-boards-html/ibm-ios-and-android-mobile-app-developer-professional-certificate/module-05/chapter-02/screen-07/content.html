Module 5 › Chapter 5.2 › justifyContent vs alignItems
Compare scenarios
Column (default)
Main axis: vertical. justifyContent affects vertical spacing; alignItems controls horizontal alignment.
Row
Main axis: horizontal. justifyContent affects horizontal spacing; alignItems controls vertical alignment.
Example question
You want three buttons evenly spaced across the bottom of the screen. Set flexDirection:'row' and justifyContent:'space-around'. Use alignItems:'center' so buttons sit on the same vertical level.
Quick test card
Check: swap flexDirection from column to row and observe which property changes alignment behavior.
Misconception: justifyContent always moves elements left/right. It does that only when the main axis is horizontal.
Key Takeaway

Label your axes mentally. Knowing the main axis clarifies which property to change.
