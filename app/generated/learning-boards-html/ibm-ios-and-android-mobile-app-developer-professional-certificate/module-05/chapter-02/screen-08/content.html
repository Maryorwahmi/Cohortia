Header / Body / Footer pattern
Start with a top-level container that fills the screen. Reserve space with small fixed-height header and footer Views, and give the body flex:1 so it receives remaining space. This keeps the main content flexible while stabilizing navigation and actions.
Concrete layout example
Top Title (fixed), Profile content (flex:1), Bottom action buttons (row with justifyContent:'space-around').
Accessibility note
Ensure footer buttons are at least 44x44 dp or larger for comfortable taps and include accessibilityLabel strings.
Visual sample (annotated cards)
Header: title and optional back button. Keep compact height.
Body: main content area, set flex:1. Can host scrollable lists or centered card.
Footer: action buttons in a row with adequate spacing.
Common mistake

Giving every child flex:1 makes their sizes equal but often not what you want; prefer explicit ratios for predictable layouts.
