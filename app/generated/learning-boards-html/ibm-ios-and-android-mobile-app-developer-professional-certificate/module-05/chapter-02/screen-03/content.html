Objective → Scenario
Core Components
Scenario: Put a user name and bio in a profile. Use Text for both so font scaling and accessibility work correctly.
Flexbox
Scenario: Two action buttons must sit side-by-side at the bottom. Use flexDirection: 'row' and justifyContent: 'space-around'.
StyleSheet
Scenario: Reuse button and card styles across screens. StyleSheet.create improves readability and performance.
Responsive Screen
Scenario: A card centers on both portrait and landscape. Use flex:1 containers and avoid fixed pixel widths.
Quick Diagnostics
  • Text not scaling or selectable? Ensure it's wrapped in a Text component.
  • Elements overlap on rotation? Check flexDirection and flex values on containers.
  • Styles inconsistent across screens? Move repeated style objects into StyleSheet.create.
  • Buttons hard to press? Add accessibilityLabel and ensure hitSlop or padding is sufficient.
