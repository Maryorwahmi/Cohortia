Module 5 › Chapter 5.2 › Key Concepts
Core Components
View, Text, Image, Button map to native widgets; pick by role to ensure accessibility and native behavior.
Flexbox
Main axis vs cross axis matters; use justifyContent and alignItems intentionally for responsive layout.
StyleSheet
Refactor repeated styles into StyleSheet.create for readability and to reduce style allocations.
Final Takeaway

Compose UIs by choosing the correct component, arranging them with Flexbox, and centralizing styles. Test across devices and include accessibility labels for robust mobile UX.
