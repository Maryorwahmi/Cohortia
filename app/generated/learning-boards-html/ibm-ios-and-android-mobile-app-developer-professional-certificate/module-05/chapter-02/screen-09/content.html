Module 5 › Chapter 5.2 › Hierarchy & Text Rules
Text nesting and inheritance
Text must live inside a Text component. You may nest Text inside Text for inline style overrides. Views do not inherit text styles. To keep typography consistent, create a shared style and apply it to each Text element or build a small Text wrapper component that applies the base style automatically.
Concrete example
Wrap user name in <Text> with a header style, and bio in another <Text> with smaller font size. If you need bold inline text inside a sentence, nest a child Text with fontWeight set to bold.
Style planning
Since styles don't cascade, prefer StyleSheet.create and shared style objects. This prevents duplication and ensures consistent spacing, color, and typography across components.
Common mistake

Expecting global CSS rules to apply. In React Native, apply styles explicitly or create wrapper components.

Check your understanding
If a font weight change doesn't affect a child Text, verify whether the child has a conflicting style or whether the font supports the weight on the platform.
