Wrap text
Always place visible strings inside a Text component to ensure font scaling and accessibility.
Plan axes
Label main and cross axes before applying justifyContent or alignItems to avoid alignment surprises.
Centralize styles
Use StyleSheet.create for repeated styles to improve readability and reduce style reallocation.
