Module 5 › Chapter 5.2 › Profile Card Activity
Six steps
  1. Create top-level container: { flex:1, justifyContent:'center', alignItems:'center' }.
  2. Add card View with padding, borderRadius, and width:'80%'.
  3. Place Image for avatar with width, height, and borderRadius to form a circle.
  4. Add Text for name and bio. Wrap each string in Text components.
  5. Create buttonGroup View: flexDirection:'row', justifyContent:'space-around'. Add two buttons with flex:1 and marginHorizontal.
  6. Refactor repeated styles into StyleSheet.create and add accessibilityLabel props.
Debug tip
If sizes flicker or images overlap, confirm numerical width/height and that parent container sizes are stable (avoid percent widths inside auto-sizing parents).
Starter template
Use the provided starter App.js in the earlier code walkthrough. Replace placeholder image URL with a test URL during development and remove before production if offline assets are needed.
Key Takeaway

Follow the steps in order: container, card, media, text, actions, refactor. This yields a stable, responsive profile card.
