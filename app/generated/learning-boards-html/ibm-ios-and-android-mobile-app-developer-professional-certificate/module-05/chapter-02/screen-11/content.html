Module 5 › Chapter 5.2 › Button Row
Pattern: Horizontal buttons
Wrap buttons in a View with flexDirection:'row'. Use justifyContent:'space-around' or 'space-between' to control spacing. Give each button container flex:1 and horizontal margin to create breathing space.
Example: buttonContainer: { flexDirection: 'row', justifyContent: 'space-around', width: '80%' } and child buttons with flex:1 and marginHorizontal:8.
Accessibility
Make buttons at least 44 dp tall and include accessibilityLabel. Avoid tiny tap targets by adding padding to the touchable area.
Concrete Scenario
Arrange a Follow and Message button evenly across the card bottom. Use a buttonGroup with width:'100%' inside the card, and set justifyContent:'space-around' so they remain even when the card shrinks.
Key Takeaway

Prefer flexible sizing over fixed widths for buttons so they adapt across screen sizes and densities.
