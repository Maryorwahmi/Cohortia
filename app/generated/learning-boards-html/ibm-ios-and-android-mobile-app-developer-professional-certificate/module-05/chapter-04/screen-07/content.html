Definition

Virtualized lists

FlatList takes props: data, renderItem, keyExtractor. It renders items lazily as they become visible.

SectionList groups data into sections with titles and individual data arrays per section, useful for categorized lists.

Practical tips
  • Provide keyExtractor that returns a string, e.g., item.id.toString().
  • Memoize renderItem or use PureComponent for item rows to reduce re-renders.
  • Use getItemLayout when row height is fixed to speed up initial scroll.
Common Mistake

Using ScrollView for large datasets leads to poor performance. Prefer FlatList for long or unknown-length lists.
