Checklist
  • Loading stuck? Ensure setLoading(false) in finally.
  • FlatList jitter? Use stable keys and memoized rows.
  • Missing persisted data? Await setItem and check keys spelling.
  • Silent API errors? Check response.ok and inspect status codes.
Debugging tips

Simulate network failures by changing endpoints or toggling network mode in your emulator. Add console logs around state updates to verify transitions. Test persistence by restarting the app and verifying load paths.

Key Takeaway

Use targeted simulations to reproduce failures and verify each state change in your network and storage flows.
