Practical checks
Fetch check: call fetch, check response.ok, parse JSON, set state. Verify with console or UI render.
List check: FlatList renders items lazily; provide keyExtractor that returns item.id.toString().
Error check: show ActivityIndicator during fetch; display a clear message or Alert on failure.
Persistence check: save JSON.stringify(value) to AsyncStorage and load it in useEffect on mount; restart to confirm persistence.
Common pitfall reminders
  • Not checking response.ok leads to silent failures when servers return 4xx or 5xx.
  • Using ScrollView for long lists causes performance issues; prefer FlatList.
  • Storing secrets in AsyncStorage is unsafe; use secure storage instead.
