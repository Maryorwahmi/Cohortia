Process Flow

Loading → Success → Error

1. Start fetch: setLoading(true), clear previous error.
2. Success: parse JSON, setData, optionally save to cache or AsyncStorage.
3. Error: set error message, show Alert or inline message, allow retry.
4. Finalize: in finally setLoading(false) so spinner stops.
Example UI elements
  • ActivityIndicator while loading to avoid blank screens.
  • Inline error text with a short retry button (or suggestion) when fetch fails.
  • Clear previous data when starting a new fetch to avoid confused displays.
Common Mistake

Leaving loading true on error leads to a never-ending spinner. Always clear loading in finally.

Key Takeaway

Explicit state transitions keep your UI predictable and prevent negative user experiences.
