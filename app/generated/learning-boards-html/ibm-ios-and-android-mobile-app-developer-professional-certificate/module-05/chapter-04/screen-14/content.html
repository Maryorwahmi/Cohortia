Module 5 › Chapter 5.4 › Key Concepts
fetch API
Promise-based network requests; always check response.ok and parse JSON.
FlatList / SectionList
Virtualized lists that render visible items only for performant scrolling.
AsyncStorage
Unencrypted key-value store for small non-sensitive data; stringify objects before saving.
Summary Takeaway

Combine reliable fetch patterns, virtualized lists, and careful persistence to build responsive, resilient mobile experiences.
