What is AsyncStorage?

A simple, unencrypted, asynchronous key-value storage mechanism for small amounts of non-sensitive data in React Native.

API snippets
import AsyncStorage from '@react-native-async-storage/async-storage';

await AsyncStorage.setItem('last_city', JSON.stringify('London'));
const stored = await AsyncStorage.getItem('last_city');
const city = stored ? JSON.parse(stored) : null;
Practical guidance
  • Always JSON.stringify before saving non-string values.
  • Await getItem on mount and initialize component state from the value.
  • Do not store secrets. Use a secure storage plugin for sensitive tokens.
Example

Save the last searched city after a successful weather fetch so the app can load it automatically on next launch.
