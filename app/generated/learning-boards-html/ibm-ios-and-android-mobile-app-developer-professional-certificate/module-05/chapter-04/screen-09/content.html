Process Flow

Search → Fetch → Save → Restore

// key parts of the flow
// load last city on mount
useEffect(() => {
  const loadLastCity = async () => {
    try {
      const storedCity = await AsyncStorage.getItem('last_searched_city');
      if (storedCity) setCity(storedCity);
    } catch (e) { console.error('Failed to load last city:', e); }
  };
  loadLastCity();
}, []);

// on search
const handleSearch = async () => {
  setLoading(true); setError(null);
  try {
    const response = await fetch(`https://api.example/weather?q=${city}&appid=KEY&units=metric`);
    if (!response.ok) throw new Error('City not found');
    const data = await response.json();
    setWeatherData(data);
    await AsyncStorage.setItem('last_searched_city', city);
  } catch (e) {
    setError(e.message || 'Failed to fetch weather.');
  } finally {
    setLoading(false);
  }
};
Notes & best practices
  • Save the city only after a successful fetch to avoid persisting invalid data.
  • Handle invalid responses (404) with a clear message and let the user retry.
  • Use ActivityIndicator while loading and disable inputs to prevent duplicate requests.
Key Takeaway

Seed state from storage on mount and update storage only on confirmed success to keep persisted data meaningful.
