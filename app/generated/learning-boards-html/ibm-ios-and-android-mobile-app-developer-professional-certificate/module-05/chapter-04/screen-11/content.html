Process Flow

Save → Load

Save: const json = JSON.stringify(value); await AsyncStorage.setItem(key, json);

Load: const raw = await AsyncStorage.getItem(key); const value = raw ? JSON.parse(raw) : null;

Always guard parse with try...catch to avoid corrupt data crashes.

Example scenario
After a successful weather fetch, save { lastCity: 'London' } as JSON so the app can automatically fetch for that city on next launch.
Common Mistake

Parsing null without checking leads to exceptions. Always check the returned string before JSON.parse.
