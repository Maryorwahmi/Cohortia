Definition

What to store in AsyncStorage

  • Safe: UI theme, last searched city, non-sensitive caches.
  • Unsafe: passwords, refresh tokens, credit card data.
  • Alternative: use secure storage or encrypted databases for sensitive items.
Best practices
  1. Never persist secrets in plaintext.
  2. Prefer short-lived tokens and server-side validation.
  3. Remove persisted tokens on logout and rotate credentials appropriately.
Key Takeaway

AsyncStorage is great for convenience, not for secrets. Choose encrypted storage when security matters.
