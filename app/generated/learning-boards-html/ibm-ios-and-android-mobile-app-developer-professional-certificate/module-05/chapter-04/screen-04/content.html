Core Concept

Fetch with useEffect

This snippet shows the canonical pattern: fetch, validate response, parse JSON, handle errors, and update loading state so the UI remains predictable.

// App.js - fetch posts
import React, { useState, useEffect } from 'react';

export default function PostListScreen() {
  const [posts, setPosts] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const fetchPosts = async () => {
      try {
        const response = await fetch('https://jsonplaceholder.typicode.com/posts');
        if (!response.ok) {
          throw new Error(`HTTP error! status: ${response.status}`);
        }
        const json = await response.json();
        setPosts(json);
      } catch (e) {
        setError('Failed to load posts. Please try again later.');
      } finally {
        setLoading(false);
      }
    };
    fetchPosts();
  }, []);
}
Explanation & example
  • Define loading and error state so the UI can show an ActivityIndicator or an error message.
  • Check response.ok to catch HTTP errors rather than assuming success.
  • Use finally to ensure loading is cleared whether the call succeeds or fails.
Concrete example
Try the URL above; then change it to an invalid path to confirm your catch block runs and your ActivityIndicator stops.
Key Takeaway

Always validate responses and clear loading state so users see accurate feedback.
