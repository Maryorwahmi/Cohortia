Architecture
Bare React Native builds, signing, and release checklist
Prepare Xcode and Gradle, secure keys, and verify performance.
For iOS, configure provisioning profiles and certificates; for Android, generate a keystore and configure Gradle signing. Avoid shipping debug builds or embedding secrets directly in source. Use secure storage for keys and environment variables for build-time secrets. Profile for re-render hotspots and optimize lists and large images. Enable analytics and crash reporting before release to gather production feedback and prioritize fixes after launch.
Pre-release Checklist
Signing
Configure certificates/profiles for iOS and keystore/Gradle for Android.
Performance
Use FlatList, lazy load images, and minimize unnecessary re-renders.
Security & Privacy
Move keys out of source and confirm privacy disclosures and permissions.
Key Takeaway

A careful release checklist reduces app review friction and ensures you can monitor and respond to production issues effectively.
