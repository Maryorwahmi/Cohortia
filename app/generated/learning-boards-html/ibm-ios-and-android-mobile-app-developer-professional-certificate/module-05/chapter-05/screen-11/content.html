Process Flow
Running tests and common pitfalls
Use npm test, configure Jest, and avoid brittle patterns.
Mock native modules in test setup, await async updates using findBy or waitFor, and keep tests focused on user-visible outcomes. Flaky tests often stem from race conditions or insufficient cleanup; use afterEach to restore mocks when needed. CI runs help catch platform-specific issues early.
Supporting Cards
Async Handling
Use await, findBy, or waitFor for operations that resolve later.
Mocking Native Modules
Provide simple mocks for native APIs used by components under test.
CI Integration
Run tests in CI to catch platform regressions before release.
Key Takeaway

Keep tests fast, focused, and user-oriented. Triage failures to decide whether to update code or tests.
