Process Flow
React Native Debugger: step through code
Open the debugger, set breakpoints, inspect variables, and step execution.
1. Enable Remote Debugging
Open the dev menu and choose Debug Remote JS to connect to desktop devtools.
2. Set a Breakpoint
Place a breakpoint in the event handler you want to inspect and reproduce the action.
3. Step and Inspect
Use step-into and watch expressions to see how values change and where logic diverges from expectation.
Supporting Notes
  • Remote debugging runs JS in your desktop process; timing may differ from device execution.
  • Use the React panel to correlate a stack frame to a UI component and inspect props/state at pause time.
  • Close the debugger when measuring performance to see native timings accurately.
Concrete Example
Set a breakpoint inside an increment handler to verify whether the updater uses the previous value or a stale closure value.
Key Takeaway

Use step debugging to confirm the exact sequence of operations and protect against subtle closure and timing bugs that logs cannot reliably expose.
