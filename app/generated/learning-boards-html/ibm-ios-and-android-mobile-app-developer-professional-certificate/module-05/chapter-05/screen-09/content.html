Definition
Jest and React Native Testing Library
Write tests that assert what users see and do.
Jest runs and reports tests, while React Native Testing Library gives you queries that reflect the UI. This combination encourages tests that focus on the user's experience rather than internal implementation. Use mock functions for callbacks and assert on rendered text or accessibility labels when possible.
Code Example
// __tests__/MyButton.test.js
import React from 'react';
import { render, fireEvent } from '@testing-library/react-native';
import MyButton from '../components/MyButton';

describe('MyButton', () => {
  it('renders correctly with given title', () => {
    const { getByText } = render();
    expect(getByText('Press Me')).toBeTruthy();
  });

  it('calls onPress when button is pressed', () => {
    const mockOnPress = jest.fn();
    const { getByText } = render();

    fireEvent.press(getByText('Test Button'));

    expect(mockOnPress).toHaveBeenCalledTimes(1);
  });
});
Key Takeaway

Write tests that mirror user interactions: render, find, interact, then assert visible outcome to keep tests resilient and useful.
