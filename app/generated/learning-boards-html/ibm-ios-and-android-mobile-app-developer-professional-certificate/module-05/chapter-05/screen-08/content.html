Core Concept
Testing strategy: unit, integration, and E2E
Choose the right test level for each concern and prefer user-focused assertions.
Unit Tests
Fast, isolated tests for functions or components.
Integration Tests
Exercise interactions between components and small modules.
E2E Tests
Validate full user flows on devices or emulators.
Concrete Example
Test a counter by asserting the displayed text increments when the button is pressed, not by examining internal state. This keeps tests resilient to implementation changes.
Misconception

Testing implementation details leads to brittle tests; prefer user-observable outcomes instead.
