Refactoring tips
Extract small components
Create HeaderView and ActionRow to simplify ContentView and enable focused previews.
When to elevate state
If multiple views need the same data, use @Binding or ObservableObject rather than duplicating state.
Testing and previews
Smaller views are easier to preview and test in Canvas, improving iteration speed.
Concrete refactor example
struct HeaderView: View {
  var title: String
  var body: some View { /* image + text */ }
}

// Use HeaderView(title: greetingMessage)
