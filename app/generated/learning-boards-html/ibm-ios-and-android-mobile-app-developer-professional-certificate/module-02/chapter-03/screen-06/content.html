Module 3 › Chapter 2.3 › Layout with VStack and HStack
Step-by-step: Build a header
1. Create a VStack
Place image and headline inside.
2. Add an HStack for actions
Place two Buttons side-by-side inside an HStack.
3. Tune spacing and alignment
Use spacing: and alignment: parameters and apply padding on the container.
Code sketch
VStack(spacing: 12) {
  Image(systemName: "hand.wave.fill")
    .resizable()
    .scaledToFit()
    .frame(width:100,height:100)

  Text("Welcome")
    .font(.title2)

  HStack(spacing: 16) {
    Button("Accept") { }
    Button("Cancel") { }
  }
}
Common layout pitfalls
  • Assuming children will auto-expand: use frame or Spacer when you need expansion.
  • Putting modifiers in the wrong place: modifiers on a container affect the whole group.
  • Over-nesting: break repeated groups into reusable small Views.
Why it matters

Clear composition using stacks keeps UI code readable and reusable as your app grows.
