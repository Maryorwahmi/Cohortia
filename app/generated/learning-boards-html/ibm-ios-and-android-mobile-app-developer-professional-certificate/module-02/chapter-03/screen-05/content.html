Reference examples
VStack {
  Image(systemName: "hand.wave.fill")
    .resizable()
    .scaledToFit()
    .frame(width:100,height:100)
    .foregroundStyle(.orange)

  Text("Welcome to Cohortia!")
    .font(.title)
    .fontWeight(.bold)
    .padding()

  HStack {
    Button("Accept") { }
    Button("Decline") { }
  }
}
Tip
Use HStack for side-by-side controls and VStack for vertical groups. Nest them to build complex layouts.
Common mistake
Don't try to mutate a View's stored properties directly. Use state wrappers like @State for mutable values.
Concrete scenario

Imagine a welcome screen with a logo, a headline, and two action buttons. With VStack for the logo and headline, and HStack for the actions, you can express this layout in fewer lines than an imperative approach.

Check your understanding
  • Which view would you use for a tappable control? Answer: Button.
  • How would you place two labels horizontally? Use HStack.
  • How to keep an image aspect ratio? Use scaledToFit.
