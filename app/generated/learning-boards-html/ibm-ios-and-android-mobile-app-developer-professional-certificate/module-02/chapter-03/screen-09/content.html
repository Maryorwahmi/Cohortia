Full code example
import SwiftUI

struct CounterView: View {
  @State private var count = 0

  var body: some View {
    VStack(spacing: 16) {
      Text("Count: \(count)")
        .font(.largeTitle)
        .padding()

      HStack(spacing: 20) {
        Button("Decrement") {
          if count > 0 { count -= 1 }
        }
        Button("Increment") { count += 1 }
      }
      .buttonStyle(.borderedProminent)
    }
    .padding()
  }
}
Concrete example
Add a guard so the count never goes negative. This keeps UI state valid and predictable.
Pro tip
Keep Button actions short and delegate long work to background tasks to avoid blocking UI updates.
Walkthrough highlights
  1. Declare @State to allow mutation and observation.
  2. Display the state in a Text view using interpolation.
  3. Change state inside Button closures to trigger UI updates.
Key Takeaway

Mutate @State to update UI. Simple actions map directly to visible changes in SwiftUI.
