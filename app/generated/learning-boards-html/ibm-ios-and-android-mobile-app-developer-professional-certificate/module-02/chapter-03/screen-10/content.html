Module 3 › Chapter 2.3 › Xcode Canvas and Live Preview
How to use Canvas
  • Open the SwiftUI file and choose Editor > Canvas to show the preview.
  • Enable Live Preview to interact with Buttons and toggles inside the preview.
  • Use multiple preview configurations to test different device sizes.
Practical suggestion
Keep Canvas open during layout changes; small adjustments to modifiers will immediately reveal visual impact.
Limitations
  • Canvas may not reflect device performance characteristics.
  • Some advanced runtime behaviors require the simulator or device.
Why it matters

Canvas shortens the feedback loop so you can iterate faster and experiment with modifiers and layouts interactively.
