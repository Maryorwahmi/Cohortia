Module 3 › Chapter 2.3 › What is a SwiftUI View?
Definition & structure

A View is a Swift value that declares UI. The body property returns 'some View' which can be a single view or a composition of many views.

Example
import SwiftUI

struct MyFirstView: View {
  var body: some View {
    Text("Hello, SwiftUI!")
  }
}
Common misconception
Views are not mutable widgets. Properties are immutable unless wrapped with state wrappers like @State.
Key takeaway
Treat the body as a description of UI for the current state; compose small views into larger ones.
Analogy & quick check

Think of a View as a recipe: the body lists ingredients and steps, and SwiftUI handles the cooking. Try changing a string inside Text and observe the preview update.

Try this
Create a file named MyFirstView.swift, implement the example above, and open the Canvas. Confirm the Text appears as expected.
Key Takeaway

A View's body declares UI. Use small Views as building blocks for larger interfaces.
