Module 3 › Chapter 2.3 › View Modifiers and Their Order
Two scenarios
Scenario A — padding then background
Text("My Title")
  .padding(10)
  .background(Color.red)
  .padding(5)
  .background(Color.blue)
Result: red covers text + 10pt padding; blue covers that block + 5pt padding.
Scenario B — background then padding
Text("My Title")
  .background(Color.red)
  .padding(10)
  .background(Color.blue)
Result: red is tight around text; outer blue surrounds red plus the padding area.
Practice prompt

Open ContentView.swift and paste Scenario A and B. Toggle between them and observe the Canvas. Ask: which modifier produces the outermost background?

Key Takeaway

Modifier order changes the visual and layout outcome — think of modifiers as a pipeline.
