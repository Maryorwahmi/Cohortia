Module 3 › Chapter 2.3 › Avoiding State and Mutability Errors
Example mismatch
struct BadView: View {
  var text = "Hello"

  var body: some View {
    VStack {
      Text(text)
      Button("Change") { text = "World" }
    }
  }
}
This will compile but Text won't update because text isn't @State.
Fix
Make the property @State or pass a Binding from the parent so mutations trigger redraws.
Shared state note
For state shared across views, use ObservableObject and @Published; we'll cover that later.
Quick diagnostic
  1. Is the value changing but the UI not updating? Check for @State.
  2. Does a child need to write to parent state? Use @Binding.
  3. Do multiple views need the same state? Consider ObservableObject.
Common mistake

Treating Views like mutable objects causes confusing behavior. Prefer the state wrappers SwiftUI provides.
