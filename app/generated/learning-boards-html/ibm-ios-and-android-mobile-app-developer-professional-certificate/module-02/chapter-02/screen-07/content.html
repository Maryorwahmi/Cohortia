Process Flow Optional Binding Patterns

if let and guard let for safe unwrapping

If let example
if let unwrappedName = username {
  print("Welcome, \(unwrappedName)!")
} else {
  print("Please log in.")
}
Guard let example
func submitForm(name: String?) {
  guard let name = name else {
    print("Name is required")
    return
  }
  // name is non-optional here
  print("Submitting for \(name)")
}
Why use guard let?
Guard let reduces nesting and clearly expresses preconditions. Use it at the top of functions when a missing value means early return.
Misconception Check

Both patterns are safe. Choose based on clarity: if let for local branching, guard let for validating preconditions.
