Learning Objectives

Master these foundational skills and verify them with the included Playground exercises.

Bloom's Path
Learn → Understand → Apply → Master
01
Declare variables and constants
Learn to use let for constants and var for mutable state. This reduces accidental mutation and clarifies intent.
Verified Competency Milestone
02
Understand core data types
String, Int, Double, and Bool, plus type inference. Know when to annotate types for clarity.
Verified Competency Milestone
03
Work with optionals safely
Use optional binding and nil coalescing to avoid crashes when values are absent.
Verified Competency Milestone
04
Control flow, functions, and types
Write if/else, for-in, and functions; choose struct vs class appropriately to prevent unintended side effects.
Verified Competency Milestone
