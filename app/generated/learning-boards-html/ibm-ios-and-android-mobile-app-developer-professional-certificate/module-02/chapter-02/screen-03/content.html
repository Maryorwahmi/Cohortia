Practice Objectives and Milestones

Short, verifiable checks you can run now in a Playground to confirm understanding.

Try: let vs var
Declare a let and try to reassign it. Expect a compile-time error. That confirms immutability.
Try: Types and inference
Create values with and without annotations to see how Swift infers types and when explicit annotation helps readability.
Try: Optional unwrapping
Use if let and nil coalescing to handle missing values without runtime crashes.
Try: if/else and for-in
Write a conditional and iterate an array of strings, printing each element to the results pane.
Try: Functions
Define a function that computes an area or sum and returns a Double, then call it with test data.
Try: Struct vs Class
Make a struct and class example to observe copy vs reference behavior, and verify which fits your design.
