Code Walkthrough Functions

Define and call functions with parameters and return values

Function example
func calculateRectangleArea(width: Double, height: Double) -> Double {
  return width * height
}

let area1 = calculateRectangleArea(width: 10.0, height: 5.0)
print("Area 1: \(area1)")

let area2 = calculateRectangleArea(width: 7.5, height: 3.2)
print("Area 2: \(area2)")
Explanation
  • Functions encapsulate logic; give them a single responsibility and a clear name.
  • Use typed parameters and a typed return to keep contracts explicit and predictable.
  • Prefer returning values for easier testing; mutate state only when appropriate.
Analogy
Think of a function as a recipe: inputs are ingredients, the function is the cooking, and the return value is the finished dish.
Pro Tip

Name functions so calls read naturally, for example: calculateRectangleArea(width:height:).

Key Takeaway

Small, well-typed functions make code easier to reason about and test in Playgrounds.
