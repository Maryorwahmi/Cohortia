What to Remember

Prefer immutability
Use let unless you need to change the value; it improves safety and clarity.
Handle optionals explicitly
Unwrap with binding or provide defaults; avoid force-unwrapping in production.
Choose structs for value semantics
Prefer structs for independent copies; use classes when shared identity or inheritance is required.
Final Prompt
Before you stop coding today, write one small Playground snippet that uses at least one let, one optional, and a function. Running it will cement the ideas you've learned.
