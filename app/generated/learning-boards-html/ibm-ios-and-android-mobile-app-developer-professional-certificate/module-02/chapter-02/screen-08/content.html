Definition Nil Coalescing

Provide a concise default when an optional is nil

Code example
var email: String?
let displayEmail = email ?? "No email provided"
print(displayEmail)
When to use
  • Use when a reasonable default exists and absence does not require special handling.
  • Avoid when you must detect missing data or when the default would mask a bug.
Scenario
Showing "No email provided" in a profile is a good use of nil coalescing. Defaulting a missing server timestamp to now might hide synchronization issues, so avoid coalescing in that case.
Key Takeaway

Nil coalescing is concise for defaults; use binding when absence needs explicit branching.
