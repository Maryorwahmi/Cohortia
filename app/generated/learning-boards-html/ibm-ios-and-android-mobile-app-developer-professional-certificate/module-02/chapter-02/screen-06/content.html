Core Concept Optionals

Represent absence safely with optionals

Code examples
var username: String? = "Alice"
var email: String?

if let unwrappedUsername = username {
  print("Welcome, \(unwrappedUsername)!")
} else {
  print("Please log in.")
}

let displayEmail = email ?? "No email provided"
print(displayEmail)
Explanation
  • Optionals model values that may be absent, using a clear syntax: Type?.
  • Optional binding (if let / guard let) unwraps safely and provides a non-optional value inside a controlled scope.
  • Nil coalescing supplies a default when the optional is nil, reducing branching in simple cases.
Scenario Card
Imagine loading a profile: email may be missing. Use optional binding to show the email only when present, or nil coalescing to display a default message when absent.
Common Mistake

Avoid force-unwrapping optionals in production code; it defeats the safety model and can crash your app.

Key Takeaway

Handle nil explicitly with binding or coalescing. Prefer safe unwrapping to keep apps stable.
