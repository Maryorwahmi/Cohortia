Assessment Idea Check understanding with short questions

Common Assessment: Constants, Optionals, and Structs

Sample Question 1
Given var city: String = "New York" and let country: String? = "USA", what happens if you try to reassign country? Explain why. Correct answer: compile-time error because country is a constant declared with let.
Sample Question 2
Which construct ensures copies are independent when passed around: class or struct? Explain the difference in behavior on assignment. Correct answer: struct, because it is a value type and assignment creates a copy.
Why these questions work

They require both factual recall and reasoning about consequences — the heart of programming competence.

Key Takeaway

Explain not just the result but the why. That reveals true understanding of semantics, not just syntax.
