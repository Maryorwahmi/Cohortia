Core Concept Control Flow

if/else and for-in loops

Examples
let isAuthenticated = true
if isAuthenticated {
  print("User is logged in.")
} else {
  print("User needs to authenticate.")
}

for i in 1...5 {
  print("Count: \(i)")
}

let fruits = ["Apple", "Banana", "Cherry"]
for fruit in fruits {
  print("I like \(fruit)")
}
Best practices
  • Avoid mutating the collection you are iterating; iterate over a copy if you must remove items.
  • Prefer clear boolean names like isAuthenticated for readable conditions.
  • Use ranges intentionally and be aware of closed vs half-open ranges.
Analogy
Think of if/else as a forked road and for-in as repeating the same step for each passenger in a queue.
