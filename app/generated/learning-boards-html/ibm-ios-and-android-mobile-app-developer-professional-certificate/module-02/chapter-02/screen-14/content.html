Hands-on Planning Live-Coding Demo Plan

Plan your 15-minute Playground demo

Stepwise agenda
  1. Introduce let vs var with simple reassign attempts and compiler feedback.
  2. Show common types and type inference with examples and explicit annotations.
  3. Demonstrate optionals: direct print, if let, guard let, and nil coalescing.
  4. Use if/else and for-in loops to process data and show outputs.
  5. Define and call a function that returns a value; test edge cases.
  6. Contrast struct and class with copy vs reference examples and explain where each fits in app design.
Timing Tip
Allocate 2–3 minutes per segment, give extra time for optionals since learners often need that reinforcement.
Result Focus
Keep the results pane visible and explain why each output confirms the expected behavior.
