Comparison Struct vs Class

Value and reference semantics explained

Struct example (value type)
struct Point {
  var x: Int
  var y: Int
}

var p1 = Point(x: 10, y: 20)
var p2 = p1 // copy
p2.x = 30
print("p1.x: \(p1.x), p2.x: \(p2.x)") // 10, 30
Class example (reference type)
class Person {
  var name: String
  init(name: String) { self.name = name }
}

let person1 = Person(name: "Charlie")
let person2 = person1 // reference
person2.name = "David"
print("person1.name: \(person1.name), person2.name: \(person2.name)") // David, David
When to use Struct

Prefer for small data models where copies are acceptable and predictable behavior is desired.

When to use Class

Use when you need shared mutable state, identity, or inheritance, such as view controllers or coordinators.

Misconception

Choosing class for convenience can introduce hard-to-find bugs due to shared state; always question whether identity is required.
