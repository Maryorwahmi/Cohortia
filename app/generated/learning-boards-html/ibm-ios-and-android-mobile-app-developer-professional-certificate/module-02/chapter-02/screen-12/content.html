Hands-on Activity Playground Lab

Experiment with Optionals and Functions

Starter Playground code
// Declare an optional
var userName: String? = "Alex"
print("Direct print: \(userName)")

// Optional binding
if let name = userName {
  print("Hello, \(name)!")
} else {
  print("User name is not set.")
}

// Assign nil and try again
userName = nil
if let name = userName {
  print("Hello, \(name)!")
} else {
  print("User name is not set after being set to nil.")
}

// Function example
func calculateRectangleArea(width: Double, height: Double) -> Double {
  return width * height
}
let area1 = calculateRectangleArea(width: 10.0, height: 5.0)
print("Area 1: \(area1)")
Guided steps
  1. Run the code and observe Optional("Alex") printed directly, then a clean greeting from binding.
  2. Set the optional to nil and observe the else path output.
  3. Call the function with different values and confirm numeric conversion when mixing types.
Reflection
Note how binding clarifies where values exist and how functions return predictable outputs. These experiments reveal language guarantees and compiler guidance.
Key Takeaway

Small, repeatable tests in Playgrounds solidify understanding of optionals and functions quickly.
