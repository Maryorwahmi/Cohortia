Module 2 › Chapter 2.1 › Lab Checklist
Checklist
  1. Install Xcode and allow initial component setup.
  2. Create iOS App project selecting SwiftUI and Swift.
  3. Edit ContentView.swift: set Text to "Hello, Cohortia!".
  4. Select iPhone simulator and press Run.
  5. If errors appear, inspect the Issues Navigator and fix the first error.
Verification
Confirm that the Simulator shows Hello, Cohortia! and that there are no blocking errors in the Issues Navigator. If testing hardware, connect a device and verify app installs and runs there too.
Key Takeaway
Use this checklist as your ready-to-run verification flow before continuing to feature development.
