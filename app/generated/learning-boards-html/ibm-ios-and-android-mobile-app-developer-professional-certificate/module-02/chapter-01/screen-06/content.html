Module 2 › Chapter 2.1 › Create New Project
Step-by-step
  1. Select Create a new Xcode project from the welcome screen.
  2. Choose iOS → App template and click Next.
  3. Enter Product Name (HelloCohortia) and Organization Identifier (com.yourname).
  4. Select Interface: SwiftUI and Language: Swift. Click Next and save the project.
Quick Check
Confirm ContentView.swift appears in the Navigator and contains the default Text element to edit.
What to avoid
Do not pick the wrong interface. Picking UIKit when you intend to use SwiftUI changes starter files and can confuse learning. If you make a wrong choice, create a new project with the correct selections.
Key Takeaway
Accurate project settings yield the expected starter code and smoother builds when you run the app.
