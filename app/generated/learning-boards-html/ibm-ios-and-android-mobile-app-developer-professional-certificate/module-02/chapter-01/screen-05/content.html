Module 2 › Chapter 2.1 › Xcode Interface
Key Areas
Navigator Area
Browse files, search, and view build or runtime issues. Use the Issues Navigator to diagnose build failures.
Editor Area
Write code and view SwiftUI previews. The Editor shows the file you opened from the Navigator.
Inspectors Area
Shows attributes and properties for the selected element or file for quick modification.
Example Workflow
Open ContentView.swift from the Navigator, edit the Text view in the Editor, and use the Inspector to change modifiers. Select a simulator from the Toolbar and press Run to see changes in the iOS Simulator.
Misconception
You do not need a physical device for early UI work. Use the Simulator first, but remember hardware testing is essential later.
Key Takeaway
Learn each pane's role so you can quickly find files, edit code, and adjust UI attributes without hunting through menus.
