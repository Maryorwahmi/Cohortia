Module 2 › Chapter 2.1 › Run in iOS Simulator
Run Steps
  • Select a simulator from the scheme menu (for example, iPhone 15 Pro).
  • Click the Play (Run) button in the Toolbar to build and launch the app.
  • Observe the app in the Simulator and interact with its UI to test behavior.
Simulator Tips
Use the Hardware and Features menus in the Simulator to rotate the device, simulate memory warnings, or change location.
Limitations
Simulators do not perfectly replicate camera, battery, or some sensor behavior. For those scenarios, test on a physical device before release.
Key Takeaway
Use the Simulator for quick iteration across screen sizes, but schedule physical device tests for hardware-dependent features.
