Module 2 › Chapter 2.1 › Key Concepts
Xcode
Apple's macOS IDE for building, running, and debugging iOS apps.
iOS Simulator
A virtual device environment included with Xcode for testing apps without hardware.
SwiftUI
A declarative framework for building UIs using Swift, with live previews in Xcode.
Summary

These concepts form the backbone of the development setup: Xcode provides the tools, Simulator speeds iteration, and SwiftUI modernizes UI construction.
