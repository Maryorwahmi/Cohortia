Module 2 › Chapter 2.1 › Learning Objectives
01
Install and configure Xcode
Download from the Mac App Store, accept the license, and wait for initial components. This completes your toolchain so you can build apps.
Mnemonic: App Store → Agreement → App ready
VERIFIED COMPETENCY MILESTONE
02
Navigate the Xcode IDE
Identify Navigator, Editor, Inspectors, and Toolbar so you can find files and change UI properties quickly.
Mnemonic: N-E-I-T — Navigator, Editor, Inspectors, Toolbar
VERIFIED COMPETENCY MILESTONE
03
Create a new iOS project
Use the App template, set the product name and organization identifier, choose SwiftUI and Swift, and save the project location.
Mnemonic: Name → Org → Interface → Language
VERIFIED COMPETENCY MILESTONE
04
Run and debug on Simulator or device
Select a simulator like iPhone 15 Pro to build and run. For physical devices, understand developer account requirements and device recognition.
Mnemonic: Simulate first, then device-test
VERIFIED COMPETENCY MILESTONE
