Terminal Checks
# Android
adb devices

# macOS / iOS tools
xcode-select --install
xcrun simctl list devices
Expected outputs show device lists or an installer prompt. Missing commands indicate PATH or incomplete install.
Quick troubleshooting mnemonic
Disk space: free 50–100 GB before large SDK downloads.
PATH: ensure platform-tools path contains adb for terminal access.
Xcode: open once to allow component installs before using simulators.
