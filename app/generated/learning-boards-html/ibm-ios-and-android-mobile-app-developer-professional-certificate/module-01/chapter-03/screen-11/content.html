Module 2 › Chapter 1.3 › Troubleshooting
Common errors
adb command not found — fix by adding platform-tools to PATH.
Simulator missing — open Xcode and allow component installs, then run simctl again.
Emulator slow — enable virtualization and reduce RAM or resolution.
Stepwise fix example
If adb returns command not found: 1) locate platform-tools inside your SDK, 2) add it to your PATH, 3) restart the terminal and run adb devices to verify the emulator shows as device.
Avoid full reinstalls until you have checked PATH and component install status; reinstalls waste time for many configuration issues.
