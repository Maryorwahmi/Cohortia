Module 2 › Chapter 1.3 › Verification Commands
Android example
$ adb devices
List of devices attached
emulator-5554	device
If you get command not found, add platform-tools to PATH and re-open your terminal.
iOS example
$ xcrun simctl list devices
== Devices ==
-- iOS 17.2 --
    iPhone 15 Pro (YYYYY-YYYY-Y...) (Booted)
Booted indicates a running simulator. If devices are missing, open Simulator from Xcode and try again.
