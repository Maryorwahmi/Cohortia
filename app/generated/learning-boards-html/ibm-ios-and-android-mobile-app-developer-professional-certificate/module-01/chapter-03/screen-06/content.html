Module 2 › Chapter 1.3 › AVD Manager
Create AVD
  1. Select device profile (e.g., Pixel 7).
  2. Choose a system image (download if necessary).
  3. Adjust hardware settings if required and finish creation.
Use multiple AVDs for different API levels and form factors to reveal compatibility problems.
Performance tips
Enable virtualization (VT-x/AMD-V) for near-native emulator speed.
Use snapshots/quick-boot to skip full cold boots during iteration.
Lower RAM or resolution if your machine runs out of memory.
Check
After launch, run adb devices and look for emulator- entries to confirm connectivity.
