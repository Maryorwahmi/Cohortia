Module 2 › Chapter 1.3 › Install Android Studio
Step-by-step
1. Download installer
Get the package for Windows, macOS, or Linux from the official site and save it locally.
2. Run installer & launch
Follow OS-specific steps. On macOS, drag to Applications. On Linux run studio.sh.
3. Complete setup wizard
Accept defaults to install SDK, platform-tools and a default AVD image unless you need custom settings.
Common-mistake
Skipping SDK downloads during setup causes missing-tool errors later; re-run the setup or use SDK Manager to add components.
Concrete example
Create a Pixel 7 AVD using the recommended Tiramisu image. If the system image is missing, click Download. Once booted, run adb devices to see emulator listed as emulator-5554.
Key Takeaway
Install the SDK and at least one system image during initial setup so emulator creation and adb commands work immediately.
