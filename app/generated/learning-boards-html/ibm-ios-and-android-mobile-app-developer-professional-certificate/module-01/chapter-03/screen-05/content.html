Module 2 › Chapter 1.3 › Android SDK & adb
Definitions
Android SDK
APIs, build tools, libraries and documentation required to compile and run Android apps.
Platform-tools
Utilities such as adb that let you install apps, capture logs, and forward ports to emulators and devices.
adb (Android Debug Bridge)
A command-line tool to list devices, install APKs, and debug running apps. It requires platform-tools on PATH.
Example commands
# List running devices/emulators
adb devices

# Example PATH note (macOS)
# export PATH="$HOME/Library/Android/sdk/platform-tools:$PATH"
If adb lists no devices despite emulator running, ensure the emulator and adb versions are compatible and PATH points to the correct SDK.
