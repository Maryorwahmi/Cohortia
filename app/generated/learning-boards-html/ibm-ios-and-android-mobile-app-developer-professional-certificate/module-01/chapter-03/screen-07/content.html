Module 2 › Chapter 1.3 › Install Xcode
Steps
1. Download Xcode
Use the Mac App Store and allow time for the download and installation; Xcode can be a large file.
2. Open Xcode
On first launch Xcode may install additional components—let it finish.
3. Install command-line tools
Run the installer: xcode-select --install and follow the prompts to enable terminal builds.
Example verification
# Install CLI tools
xcode-select --install

# List simulators
xcrun simctl list devices
If simctl shows Booted devices after launching Simulator, your setup is ready for local iOS testing.
