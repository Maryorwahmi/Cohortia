Module 2 › Chapter 1.3 › Key Concepts
Android Studio
Official IDE that installs SDKs, emulator images, and manages the AVD toolchain.
Xcode
Apple’s macOS IDE containing iOS Simulators and build tools required for iOS development.
SDK / Platform-tools
SDK contains libraries and build tools; platform-tools include adb for device communication.
Summary

Keep native IDEs installed, verify with terminal commands, and maintain PATH and virtualization settings to ensure reliable app testing.
