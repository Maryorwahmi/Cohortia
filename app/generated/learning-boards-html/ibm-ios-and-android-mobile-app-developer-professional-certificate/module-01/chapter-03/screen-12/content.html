Module 2 › Chapter 1.3 › Activity: Verify Setup
Android Verification
1. Launch Android Studio and open AVD Manager.
2. Create Pixel 7 AVD and download the system image.
3. Start emulator and run adb devices to confirm an emulator entry.
iOS Verification (macOS)
1. Install Xcode from the App Store and open it once.
2. Run xcode-select --install to add CLI tools.
3. Open Simulator and run xcrun simctl list devices to check Booted status.
Reflection

Record any errors and the fix you applied. This short log becomes your setup checklist for future machines.
