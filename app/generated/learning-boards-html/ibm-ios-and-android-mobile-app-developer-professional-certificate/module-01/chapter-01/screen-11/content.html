Best Practices
  • Request permissions at point of need with a clear explanation of benefit.
  • Minimize the scope and frequency of permission requests.
  • Provide clear fallback behavior if the user declines.
  • Document data collection and respect platform privacy disclosures.
Concrete Scenario
A location-based reminder app shows a preview of reminders without location, then asks for precise location when the user taps to create a geo-reminder. This explains the benefit and only requests permission when the user is ready to accept it.
Common Mistake

Requesting permissions at first launch leads to high decline rates and lost functionality. Progressive requests improve acceptance.
