Module 1 › Chapter 1.1 › Navigation Patterns
iOS Patterns
  • Tab bars at the bottom for primary navigation.
  • Top-left back button and large title headers.
  • System gestures and consistent spacing guidance.
Example
A social app uses tabs for feed, search, notifications, and profile on iOS, making main areas reachable with the thumb.
Android Patterns
  • Navigation drawer for many destinations or bottom navigation for 3–5 primary destinations.
  • Floating action buttons for prominent, contextual actions.
  • System-level back affordance that users expect to return or dismiss.
Example
A productivity app uses a drawer to surface many tools and a floating action button to quickly create new items.
Key Takeaway

Adapt navigation surfaces to platform norms while preserving a consistent underlying information structure.
