Module 1 › Chapter 1.1 › Testing Strategy
Timeline
Early: Emulators and unit tests
Mid: Real-device functional and accessibility tests
Late: Staged rollouts and telemetry
Representative Devices
  • iOS: current flagship, recent previous generation.
  • Android: flagship, mid-range, and low-end devices across common vendors.
Accessibility Checks
  • Screen reader walkthroughs, large-text layouts, and high-contrast mode.
  • Keyboard navigation where relevant and touch target verification.
Key Takeaway

Testing must include representative hardware, accessibility checks, and staged release validation to reduce real-world failures.
