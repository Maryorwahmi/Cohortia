Core Practices
  • Provide accessible labels and descriptions for all interactive elements.
  • Support dynamic text sizes and responsive layouts for larger fonts.
  • Ensure color contrast meets legibility needs and avoid color-only cues.
  • Design large touch targets and logical focus order for navigation.
Concrete Example
A login form with labeled fields, clear error descriptions, and large buttons reduces confusion for screen reader users and speeds completion for everyone. Test with VoiceOver or TalkBack and with increased text sizes to validate the flow.
Common Mistake

Relying solely on color to communicate state or skipping semantic labels — both break accessibility for assistive technologies.
