Module 1 › Chapter 1.1 › Designing for Fragmentation
Techniques
  • Responsive, adaptive layouts that reflow content rather than hiding it.
  • Provide multiple image densities and vector assets where possible.
  • Use runtime capability checks and feature flags for graceful degradation.
  • Define a pragmatic minimum supported OS and document fallbacks.
Code Example (conceptual)
// Pseudocode: check capability before enabling feature
if (device.supports('highQualityDecoder')) {
  enableHighQualityImages()
} else {
  useCompressedImages()
}

// Fallback for older OS
if (os.version <= 21) {
  useLegacyPermissionFlow()
} else {
  requestRuntimePermissions()
}
Key Takeaway

Plan adaptive UI and capability checks so features degrade gracefully on less capable devices or older OS versions.
