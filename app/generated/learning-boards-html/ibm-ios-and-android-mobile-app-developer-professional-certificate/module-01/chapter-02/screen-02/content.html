Learning Objectives

Part 1 — core recognition and evaluation skills

Learn → Understand → Apply → Master
01
Differentiate paradigms
Recognize native, hybrid, and cross-platform patterns and the technical differences that define them. This matters because naming the paradigm focuses your architecture choices.
VERIFIED COMPETENCY MILESTONE
02
Identify languages & frameworks
List the primary languages and IDEs tied to each approach so you can estimate hiring and tooling needs. This reduces onboarding surprises.
VERIFIED COMPETENCY MILESTONE
03
Evaluate pros and cons
Weigh performance, cost, and maintenance trade-offs against project requirements so your recommendation is evidence-based.
VERIFIED COMPETENCY MILESTONE
04
Choose native vs cross-platform
Apply scenario-based rules of thumb to decide when a native solution is required and when Flutter or React Native suffice.
VERIFIED COMPETENCY MILESTONE
