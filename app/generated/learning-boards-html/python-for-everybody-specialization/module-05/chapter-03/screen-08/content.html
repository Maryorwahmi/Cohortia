Module 5 › Chapter 5.3 › Duplicates
Find and remove duplicates
Keep the right occurrence and avoid dropping legitimate repeats.
Useful calls
df.duplicated()              # boolean Series

df.drop_duplicates()         # drop duplicates, keep first

df.drop_duplicates(keep='last')

df.drop_duplicates(keep=False)  # drop all duplicates

df.drop_duplicates(subset=['ID','Value'])
Example
A table with ID values [1,2,1,3] will mark the second occurrence of ID 1 as duplicate; drop_duplicates keeps one row unless keep=False is used.
Common mistake
Dropping duplicates blindly can remove legitimate repeated events. Inspect duplicates before removal.
Key Takeaway

Identify duplicate rows, examine them, and use subset or keep options to remove only unintended duplicates.
