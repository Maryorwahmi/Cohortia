Module 5 › Chapter 5.3 › dropna() options
Drop rows or columns
Compare behaviors and choose the least destructive option.
Common calls
df.dropna()              # drop rows with any NaN

df.dropna(how='all')    # drop rows if all values are NaN

df.dropna(axis=1)       # drop columns with any NaN

df.dropna(subset=['A','B'])  # drop rows missing in A or B
Example
If a product description column is optional, dropping rows with missing descriptions will remove many valid transactions. Consider dropping the column instead if descriptions are unnecessary.
Common mistake
Using df.dropna(inplace=True) without checking the percentage removed. Always preview the result and keep a copy.
Key Takeaway

Drop data only when the cost of keeping missing values outweighs the cost of removing them. Measure the loss first.
