Module 5 › Chapter 5.3 › fillna() strategies
Fill missing values
Choose constant, statistic, or propagation fills depending on context.
Examples
# fill with a constant
df['City'].fillna('Unknown', inplace=False)

# fill numeric with median
df['Age'].fillna(df['Age'].median(), inplace=True)

# forward fill
df.fillna(method='ffill')
Practical note
When using mean or median, compute the statistic on training data in modeling workflows to avoid leakage.
Common mistake
Using fillna globally without considering column types can corrupt categorical fields or introduce inappropriate numeric values.
Key Takeaway

Match the fill strategy to the variable. Validate by re-counting missing values and sampling rows.
