Learning Objectives
A skill-focused checklist for hands-on cleaning work.
01
Identify common issues
Recognize missing values, duplicates, and wrong dtypes so you focus cleaning where it matters. A quick count per column helps gauge impact.
VERIFIED COMPETENCY MILESTONE
02
Detect missing data
Use isnull and .sum() to locate and count absent entries before choosing drop or impute strategies.
VERIFIED COMPETENCY MILESTONE
03
Remove duplicates
Detect duplicates with duplicated() and remove rows selectively with drop_duplicates and subset criteria.
VERIFIED COMPETENCY MILESTONE
04
Convert and transform
Cast types with astype or pd.to_numeric and perform small transforms like renaming or applying a function per element.
VERIFIED COMPETENCY MILESTONE
