Module 5 › Chapter 5.3 › Find missing values
Locate missing values
Use boolean masks and counts to prioritize fixes.
Code pattern
# count missing per column
print(df.isnull().sum())

# prioritize columns with most missing
print(df.isnull().sum().sort_values(ascending=False))
This pair of calls turns presence detection into actionable counts.
Example
A 'Customer' table shows Age missing twice and City once; you may impute Age but set City to 'Unknown' if categorical.
Common mistake
Inspecting only head() can hide later missing rows. Use full-column counts before deciding.
Key Takeaway

Measure missingness across columns first. Use counts to choose the least risky remediation.
