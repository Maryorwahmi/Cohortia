Data Cleaning: definition and role
Making data accurate and analysis-ready.
What it includes
  • Detect missing values and duplicates.
  • Convert columns to appropriate types for operations.
  • Apply targeted transforms and renaming for clarity.
Analogy
Cleaning data is like proofreading a report: small unnoticed errors change the conclusions.
Concrete example
import pandas as pd
import numpy as np

data = {'A': [1, 2, np.nan, 4], 'B': [5, np.nan, 7, 8]}
df = pd.DataFrame(data)
print(df.isnull().sum())
# A    1
# B    1
This check reveals missing counts per column. Deciding how to proceed requires understanding the dataset and the downstream calculation you plan to run.
Key Takeaway

Always inspect and quantify problems before applying fixes. Dropping or filling without verification can introduce bias.
