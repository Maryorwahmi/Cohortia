Module 5 › Chapter 5.3 › Type conversion
Cast types with care
Prefer coercing functions to surface bad values for review.
Code examples
# safe numeric conversion
import pandas as pd

df['Numbers_numeric'] = pd.to_numeric(df['Numbers'], errors='coerce')

# parse dates
df['Dates_datetime'] = pd.to_datetime(df['Dates'])

# direct cast (may fail)
df['Col'] = df['Col'].astype(int)
Example from chapter
A 'Numbers' column with values ['1','2','3','four'] becomes [1,2,3,NaN] after pd.to_numeric with errors set to 'coerce', making 'four' explicit as missing.
Common mistake
Using astype directly on messy columns causes exceptions. Use coercion to reveal problematic entries first.
Key Takeaway

Coerce conversions to NaN when needed, then handle the NaNs using your chosen strategy.
