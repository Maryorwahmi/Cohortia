Rename columns and apply functions
Small renames and derived columns improve clarity and analysis.
Code patterns
# rename
df = df.rename(columns={'old_col_name': 'NewColumnName'})

# apply function
def double_value(x):
  return x * 2

df['DoubledValue'] = df['Value'].apply(double_value)
Example
Renaming 'EmailAddress' to 'Email' makes downstream code simpler. Applying a doubling function creates features for testing.
Common mistake
Forgetting to check dtype after apply can leave numeric-looking data as strings, breaking later math operations.
Key Takeaway

Use rename for clarity and apply for custom per-element logic. Verify outputs and dtypes after each step.
