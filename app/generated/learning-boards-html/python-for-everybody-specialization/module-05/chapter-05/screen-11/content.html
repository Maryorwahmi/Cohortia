Module 6 › Chapter 5.5 › Handling large datasets and aggregation
Aggregation patterns
  • Aggregate by day/week/month depending on the analysis window.
  • Use rolling means to smooth noise while preserving trend direction.
  • Downsample by selecting representative points or computing percentiles per bin.
Why it matters
Smaller, aggregated datasets yield faster exports and better interactivity for most exploratory tasks. Save raw data separately if needed for deep analysis.
Common mistake
Embedding an entire multi-million point series will slow rendering and may make the file unusable for casual viewers.
Key Takeaway

Prepare aggregated or sampled data for exports to preserve interactivity and keep file sizes practical for sharing.
