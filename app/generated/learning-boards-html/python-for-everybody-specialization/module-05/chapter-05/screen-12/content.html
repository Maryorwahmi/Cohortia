Module 6 › Chapter 5.5 › Privacy and best practices
Practical safety steps
  • Review data for PII; remove or anonymize identifiers before exporting.
  • Aggregate records where possible to prevent exposure of individuals.
  • Include a caption or note listing data sources and preprocessing steps for transparency.
Misconception
Hiding labels or legends does not remove embedded data; the serialized values remain in the HTML.
Key Takeaway

Treat exported HTML as a data artifact and apply the same privacy checks you would for any data file before sharing.
