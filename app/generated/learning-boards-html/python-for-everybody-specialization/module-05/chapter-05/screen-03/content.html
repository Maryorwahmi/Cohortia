Practical Workflow Steps
Follow these tasks during the lab to produce a verified HTML export.
1. Generate data
Create a DataFrame with Date and numeric column, or load from CSV.
2. Build Plotly figure
Use go.Scatter with lines+markers and set hovermode='x unified' for clear tooltips.
3. Customize and test
Add title, axis labels, and hovertemplate to surface exact values on hover.
4. Export and verify
Call fig.write_html with include_plotlyjs option, open the file, and confirm interactivity.
Quick mnemonic
D → F → C → E
Data, Figure, Customize, Export — follow this order to avoid missing steps.
Milestone

Open the exported HTML and interact with the chart to mark the activity complete.
