Module 6 › Chapter 5.5 › Common mistakes and how to fix them
Quick fixes
  • Blank chart: verify include_plotlyjs isn't 'cdn' when offline or ensure network access.
  • Missing plot: check browser console for JavaScript errors and validate figure in a notebook.
  • Large file: aggregate or downsample data before exporting, or use CDN to reduce file size.
Example diagnostic
If an exported file is blank, open devtools console. If it reports plotly not found, your include_plotlyjs setting omitted the library.
Misconception
Believing that embedding always guarantees smaller files. Embedding increases single-file size; CDN reduces it at the cost of requiring internet access.
Pro Tip

Keep a small test export when iterating. Confirm behavior before running full exports with larger datasets.
