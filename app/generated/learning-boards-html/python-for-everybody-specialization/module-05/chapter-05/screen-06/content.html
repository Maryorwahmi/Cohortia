Module 6 › Chapter 5.5 › Create an interactive Plotly line chart
Example figure code
import plotly.graph_objects as go

fig = go.Figure(data=[
  go.Scatter(x=data['Date'], y=data['Visitors'], mode='lines+markers', name='Visitors')
])

fig.update_layout(
  title='Daily Website Visitors Over 30 Days',
  xaxis_title='Date',
  yaxis_title='Number of Visitors',
  hovermode='x unified'
)

# fig.show()  # test locally
Hover customization
Use fig.update_traces(hovertemplate='Date: %{x}
Visitors: %{y}') to control what appears in the tooltip and the formatting.
Common mistake
Using overly verbose hover templates can make the tooltip hard to scan. Keep it concise and focused on the data point.
Key Takeaway

Build a clear figure and test interactive behaviors locally before exporting to ensure the exported HTML will behave as intended.
