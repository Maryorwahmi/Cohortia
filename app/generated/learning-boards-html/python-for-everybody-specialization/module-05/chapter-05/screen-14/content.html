Module 6 › Chapter 5.5 › Key Concepts
Interactive Visualization
Charts that let users zoom, pan, hover, and toggle traces to explore data.
Plotly write_html()
Method to export a Plotly Figure into an HTML file for browser viewing.
Self-contained vs CDN
Embedding plotly.js for offline use or linking to a CDN for smaller files with online dependency.
Takeaway

Match your export strategy to how your audience will access the chart: offline recipients get embedded files; web viewers benefit from CDN-hosted JS.
