Data Serialization
Plotly stores chart data and layout as JSON inside the HTML so the browser can re-create the visualization.
Privacy & Documentation
Remove or aggregate sensitive fields and include a short provenance note before sharing visualizations widely.
Best Practices
Test exports locally, choose embedding or CDN deliberately, and keep files small enough for the intended audience.
Final takeaway

Export with intention: match file format and size to how your audience will access, and protect sensitive information before sharing.
