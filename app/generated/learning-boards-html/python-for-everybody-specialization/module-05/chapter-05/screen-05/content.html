Module 6 › Chapter 5.5 › Generate time-series sample data
Starter code pattern
import pandas as pd
from datetime import date, timedelta

start_date = date(2023, 1, 1)
dates = [start_date + timedelta(days=i) for i in range(30)]
# Simulate a fluctuating series
visitors = [100 + i*2 + (i%7)*8 - (i%3)*3 for i in range(30)]

data = pd.DataFrame({'Date': dates, 'Visitors': visitors})
print(data.head())
Practical tips
  • Ensure Date is a datetime type when plotting for correct axis formatting.
  • Use small deterministic noise so debugging is repeatable.
  • For large data consider aggregating before export to keep HTML size reasonable.
Common mistake
Leaving Date as plain strings can prevent Plotly from treating the axis as time-based, which breaks tick formatting and zoom behavior.
Key Takeaway

Prepare clean, typed data before plotting; small, realistic datasets are ideal for interactive testing.
