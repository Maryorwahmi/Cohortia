Module 6 › Chapter 5.5 › Export call and sizing options
Typical export call
output_file_name = 'daily_visitors_chart.html'
fig.write_html(output_file_name, include_plotlyjs='cdn', default_width='100%', default_height='500px')
Use percent width for responsiveness and a fixed height to ensure the chart has room for axes and tooltips.
Host embedding note
When embedding in another page, the container's CSS determines responsiveness. Ensure the container allows width:100% children to expand.
Key Takeaway

Control default sizing at export, and always test in the target hosting environment to confirm responsiveness.
