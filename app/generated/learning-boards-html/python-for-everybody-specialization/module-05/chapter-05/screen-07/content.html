Module 6 › Chapter 5.5 › fig.write_html options
Embedded (include_plotlyjs=True)
Full plotly.js is embedded in the file. Pros: offline-ready. Cons: larger file size, slower to distribute by email.
CDN (include_plotlyjs='cdn')
HTML references an external network copy of plotly.js. Pros: smaller HTML, faster for hosted pages. Cons: requires internet to load the library when opened.
Common pitfalls
  • Choosing 'cdn' when you need offline viewing causes a blank chart if no network is available.
  • Choosing False removes the library and results in no rendering unless Plotly is loaded elsewhere.
Quick test

Export both ways and open the files locally to compare file size and loading behavior before sharing.
