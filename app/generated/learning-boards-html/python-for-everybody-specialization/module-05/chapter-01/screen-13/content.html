Process Flow

Detect and handle file and encoding errors

• Wrap file opening in a try block and catch FileNotFoundError to inform the user.
• Specify encoding explicitly for text files; use UTF-8 by default when possible.
• For unknown encodings, consider a tolerant mode or inspect the file before bulk processing.
Practical pattern
Use try/except around the with open block and provide clear error messages while avoiding program crashes.
Example check
If you expect non-ASCII characters, include encoding='utf-8' in your open call. If you still encounter UnicodeDecodeError, check the file with a text inspector or try a different encoding for a quick diagnostic run.
Misconception

Assuming default encoding always works will cause intermittent failures when collaborating with files from different systems.
