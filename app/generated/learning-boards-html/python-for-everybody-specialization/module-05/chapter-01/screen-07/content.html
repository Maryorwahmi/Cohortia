Definition

Regular expressions

A sequence of characters that defines a search pattern. Use for validation, extraction, and replacements.

• Character classes like \d, \w, and \s match digits, word characters, and whitespace.
• Quantifiers control repetition: one or more, zero or more, exact counts.
• Parentheses capture sub-patterns for later retrieval by index.
Misconception
Avoid overusing regex for simple checks; string methods are easier to read and sometimes faster.
When to use
Use regex when text has structure you can describe with patterns, like email addresses, numeric IDs, or log formats. For brittle or nested formats, consider a parser.
Functions to know
  • • re.search — find the first match and get a match object.
  • • re.findall — return all non-overlapping matches as a list.
  • • re.sub — replace matches with a replacement string.
