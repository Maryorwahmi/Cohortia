Module 5 › Chapter 5.1 › Key Concepts
Capturing groups
Use parentheses to capture subpatterns and retrieve them from match objects when needed.
Greedy quantifiers
Default quantifiers match as much as possible; use non-greedy when you need the smallest match.
Escape special chars
Escape dots and other metacharacters when you intend to match them literally to avoid unexpected behavior.
Final takeaway

Design regex patterns deliberately, test on sample lines, and combine them with safe file-handling patterns to process real data reliably.
