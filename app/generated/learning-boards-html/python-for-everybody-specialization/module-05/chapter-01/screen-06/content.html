Comparison

Read vs Write vs Append

'r' — read: Open only for reading; file must exist.
'w' — write: Create or overwrite; use with care to avoid data loss.
'a' — append: Add to end without removing existing content; useful for logs.
'b' — binary: Combine with other modes for non-text data, such as 'rb' or 'wb'.
Practical note
When writing text files, explicitly set encoding to avoid Unicode errors. For cross-platform paths, build paths programmatically to avoid FileNotFoundError.
Example & Mistakes
Example: Append log
Open the file with append mode to add events safely without truncating previous entries.
Common mistake
Using 'w' instead of 'a' for periodic logging can accidentally erase historical records.
Encoding issue
If you see a UnicodeDecodeError, re-open with the correct encoding such as 'latin-1' or explicitly use 'utf-8' where appropriate.
Key Takeaway

Match the file mode to your intent and always set encoding for text files.
