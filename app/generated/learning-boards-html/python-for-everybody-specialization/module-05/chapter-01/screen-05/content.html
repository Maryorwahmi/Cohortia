Definition

Line-by-line iteration

Use the file object as an iterator to read each line sequentially without loading the whole file.

• Iteration yields one line per loop, keeping memory usage low.
• Use strip to remove trailing newline characters when exact matches are required.
• Compose with generators or filters to chain transformations without intermediate lists.
Pro tip

If you need partial buffering for speed, consider reading in fixed-size chunks but only when you understand the trade-offs for line boundaries.

Example
count = 0
with open('application.log', 'r', encoding='utf-8') as file:
  for line in file:
    if 'ERROR' in line:
      count += 1
print('Total errors found:', count)
Common mistake
Avoid file.read() for very large files because it loads everything into memory and can crash your program.
Check your needs
If you need random access or full-text search across boundaries, iteration may need to be combined with indexing or a streaming parser.
