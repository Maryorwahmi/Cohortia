Extracting an ID

import re

log_line = "User 'john.doe@example.com' logged in with ID: 12345 from IP: 192.168.1.100"
match = re.search(r'ID: (\d+)', log_line)
if match:
  user_id = match.group(1)
  print('Extracted User ID:', user_id)
else:
  print('User ID not found.')
Explanation
  • • The pattern captures one or more digits following the literal label 'ID:'.
  • • Parentheses create a capturing group; group(1) returns that captured substring.
  • • Always verify match is not None before accessing groups to avoid errors.
Common confusion
If you expect multiple IDs in a single string, search returns only the first. Use findall to retrieve all matches.
Key Takeaway

Use search for the first match and capture groups to extract specific subparts; check for None first.
