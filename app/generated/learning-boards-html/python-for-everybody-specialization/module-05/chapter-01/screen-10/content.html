Module 5 › Chapter 5.1 › re.sub redaction
Code Example
import re

text_with_phones = "Call us at 123-456-7890 or 987.654.3210 for assistance."
cleaned_text = re.sub(r'\d{3}[-.]\d{3}[-.]\d{4}', '[PHONE_NUMBER_REDACTED]', text_with_phones)
print('Cleaned text:', cleaned_text)
Explanation
  • • Use curly braces to match exact counts like three digits. Escape dots to match literal separators.
  • • Greedy quantifiers may consume too much; use non-greedy forms when you need the shortest match.
  • • After substitution, review results to ensure no unintended text was replaced.
Common mistake
Unescaped special characters change semantics. For example, a dot matches any character unless escaped.
Key Takeaway

Test substitution patterns on sample text and escape literal characters to avoid unintended replacements.
