Module 5 › Chapter 5.1 › re.findall emails
Code Example
import re

text = "Contact us at support@example.com or sales@anothersite.org. My personal email is me@mymail.net."
emails = re.findall(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', text)
print('Found emails:', emails)
Explanation & Checks
  • • The pattern uses a word boundary to anchor full addresses and a character class for the username.
  • • The dot in the domain is escaped to match a literal period.
  • • If you include parentheses in the pattern, findall returns captured groups rather than full matches.
Practical tip
After extracting, validate and deduplicate results before saving them to avoid noisy records.
Key Takeaway

Use findall for comprehensive extraction and design your pattern carefully to return the exact substrings you expect.
