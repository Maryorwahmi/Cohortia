Multiple lines & legend
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 10, 100)
y1 = np.sin(x)
y2 = np.cos(x)

plt.plot(x, y1, label='Sine Wave', color='blue', linestyle='-')
plt.plot(x, y2, label='Cosine Wave', color='red', linestyle='--')
plt.title('Sine and Cosine Waves')
plt.xlabel('X-axis')
plt.ylabel('Y-axis')
plt.legend()
plt.grid(alpha=0.3)
plt.savefig('sine_cosine.png')
plt.show()
Style tips
  • Always label axes with units where applicable.
  • Use legends when multiple datasets appear in the same axes; include labels in plot calls.
  • Prefer subtle grid lines and consistent color palettes.
Misleading scaling
Avoid truncating axes to exaggerate differences without noting it; be transparent about axis ranges to maintain trust.
Key Takeaway

Effective styling is functional: it helps readers interpret the plotted data quickly and accurately.
