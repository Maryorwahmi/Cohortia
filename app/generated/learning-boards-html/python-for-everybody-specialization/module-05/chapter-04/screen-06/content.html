Module 5 › Chapter 5.4 › Line Plots
Example
import matplotlib.pyplot as plt
import numpy as np

# Daily temperatures
days = np.arange(1, 8)
temps = [20, 22, 21, 23, 25, 24, 26]

plt.plot(days, temps, marker='o', color='tab:blue')
plt.title('Daily Temperature Trend')
plt.xlabel('Day')
plt.ylabel('Temperature (°C)')
plt.grid(True)
plt.savefig('temperature_trend.png', dpi=300)
plt.show()
This script demonstrates the core steps: data arrays, plot call, labels, grid for readability, and saving with a high resolution.
Guidance
  • Use markers for small data sets so individual points are visible.
  • Ensure x is ordered; avoid lines for categories without order.
  • Adjust figure size with plt.figure(figsize=(w,h)) for display or export needs.
Key Takeaway

Use line plots for continuous or ordered data and label axes; avoid misleading continuity for unordered categories.
