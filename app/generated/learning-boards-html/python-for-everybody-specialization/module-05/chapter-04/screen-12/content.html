Module 5 › Chapter 5.4 › Common Mistakes
Top mistakes
  1. Missing labels and title
  2. Wrong plot type for the data
  3. Overlapping ticks and tiny figure size
  4. Misleading axis scales
  5. Forgetting to save or low-resolution exports
Quick checklist
  • Title and axis labels present
  • Plot type matches question
  • Ticks readable, legend present if needed
  • Saved file opens at intended quality
Pro tip

Run the checklist as the last step of your plotting script; it saves time and prevents mistakes from reaching stakeholders.
