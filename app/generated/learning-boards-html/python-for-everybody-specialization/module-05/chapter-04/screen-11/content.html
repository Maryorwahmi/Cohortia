Module 5 › Chapter 5.4 › Saving Figures
Save example
import matplotlib.pyplot as plt

plt.plot([1,2,3],[4,5,6])
plt.title('Simple plot')
# Save high-resolution PNG for report
plt.savefig('report_figure.png', dpi=300)
# Then show in interactive session
plt.show()
Tips
  • Choose format by extension: .png, .pdf, .svg, etc.
  • Use dpi for raster images; vector formats like PDF and SVG scale without loss.
  • Call plt.close() when generating many figures in a loop to free memory.
Key Takeaway

Save figures at the required resolution and format before showing them to guarantee reliable output files for sharing.
