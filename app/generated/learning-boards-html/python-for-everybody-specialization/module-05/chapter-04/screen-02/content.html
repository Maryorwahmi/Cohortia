How these objectives fit together

You will first choose a plot to answer your question, then implement it using pyplot. After plotting, you will style your figure so it communicates effectively and finally export it for sharing. Each stage supports the next: a well-chosen plot becomes useful only when it is labeled and saved correctly.

Mnemonic
PLOT — Pick, Label, Output, Tidy
Outcome
Clear, reproducible figures for analysis and reports.
