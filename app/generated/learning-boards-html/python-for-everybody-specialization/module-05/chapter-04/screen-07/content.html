Module 5 › Chapter 5.4 › Bar Charts
Code Example
# Sales by product category
import matplotlib.pyplot as plt

categories = ['Electronics', 'Clothing', 'Books', 'Home Goods']
sales = [15000, 10000, 7000, 12000]

plt.figure(figsize=(8,5))
plt.bar(categories, sales, color=['skyblue','lightcoral','lightgreen','gold'])
plt.title('Total Sales by Product Category')
plt.xlabel('Product Category')
plt.ylabel('Total Sales ($)')
plt.xticks(rotation=45, ha='right')
plt.tight_layout()
plt.savefig('sales_by_category.png')
plt.show()
Practical tips
  • Rotate x-ticks when labels overlap; use ha='right' for alignment.
  • Use plt.figure to control aspect ratio; wider figures help many categories.
  • Color choices should aid interpretation, not distract; use palettes for consistency.
Misuse to avoid
Do not use bar charts to imply a continuous relationship between categories. Bars represent separate groups.
Key Takeaway

Bar charts make categorical comparisons clear; adjust rotation and size to maintain label readability.
