Example tweaks
# Axis limits and annotation
import matplotlib.pyplot as plt
x = [1,2,3,4,5]
y = [10,15,12,20,18]

plt.plot(x, y, marker='o')
plt.title('Sales over time')
plt.xlabel('Month')
plt.ylabel('Sales')
plt.xlim(1,5)
plt.ylim(8,22)
plt.xticks(x)
plt.text(4,20,'Campaign launched', fontsize=9, ha='left')
plt.grid(alpha=0.2)
plt.savefig('annotated_sales.png')
plt.show()
Best practices
  • Set ticks explicitly for categorical axes to avoid ambiguity.
  • Annotate only when the extra context changes interpretation.
  • Document axis ranges if they are trimmed or rescaled.
Misleading scaling

Avoid truncating axes without a clear note; visual accuracy supports trust.
