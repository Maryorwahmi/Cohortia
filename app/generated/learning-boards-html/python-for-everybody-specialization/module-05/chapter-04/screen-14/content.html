Question 1
Which plot shows relationship between hours studied and exam score?
A) Line plot B) Bar chart C) Scatter plot D) Pie chart
Correct: C) Scatter plot — it displays paired numeric observations where each point represents one student.
Question 2
Which sequence saves a high-resolution JPEG then displays it?
A) show then save B) save then show C) save without dpi then show D) export then show
Correct: B) save then show — call savefig with dpi before show to ensure the file contains the intended figure.
Reflection

When you select a plot type or a file workflow, briefly state why it fits the data and how it preserves honest interpretation. That habit improves both analysis and communication.
