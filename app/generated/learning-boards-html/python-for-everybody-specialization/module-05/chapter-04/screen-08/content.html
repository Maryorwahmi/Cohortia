Module 5 › Chapter 5.4 › Scatter Plots
Example
import matplotlib.pyplot as plt

study_hours = [2,3,5,6,7,8,9,10,11,12]
exam_scores = [60,65,70,75,80,85,90,92,95,98]

plt.scatter(study_hours, exam_scores, color='purple', marker='o', s=100, alpha=0.7)
plt.title('Study Hours vs. Exam Scores')
plt.xlabel('Study Hours per Week')
plt.ylabel('Exam Score')
plt.grid(True, linestyle='--', alpha=0.6)
plt.savefig('study_vs_score.png')
plt.show()
Interpretation tips
  • Look for trend direction and spread: positive, negative, or none.
  • Use alpha to handle overlap and s to change marker size for importance.
  • Remember: association does not imply causation; be cautious in claims.
Common mistake
Overplotting without transparency can hide clusters; use alpha or binning to reveal density.
Key Takeaway

Scatter plots are the tool of choice for relationships; design markers and transparency to keep dense plots readable.
