What it is

Matplotlib and pyplot

Matplotlib is a comprehensive plotting library. pyplot is the small, MATLAB-like interface you’ll use most for basic static plots.

Common actions
  • Import pyplot as plt
  • Call plt.plot, plt.bar, or plt.scatter
  • Set titles and labels, then save or show
Pitfall
Assuming state isolation between figures. Always call plt.figure() when you need a fresh canvas.
Starter code
import matplotlib.pyplot as plt
import numpy as np

# Small example: simple line
x = np.linspace(0, 10, 50)
y = np.sin(x)

plt.figure(figsize=(8,4))
plt.plot(x, y, color='blue', label='sine')
plt.title('Sine wave')
plt.xlabel('x')
plt.ylabel('sin(x)')
plt.legend()
plt.savefig('sine_wave.png', dpi=150)
plt.show()
This minimal script shows the pyplot workflow: create figure, plot data, label, save, then show. Saving before showing keeps output consistent across environments.
