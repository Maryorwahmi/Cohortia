Objective Practice Plan

Short experiments you can run to confirm each learning objective.

Explain Pandas advantages
Replace a Python loop with a vectorized sum and observe simpler code and faster execution for larger arrays.
Differentiate Series & DataFrame
Extract a column from a DataFrame and call a Series method to see the structural difference in behavior and available APIs.
Create Series and run ops
Construct Series from a list and a dict, then add a scalar to the Series to confirm element-wise arithmetic.
Build & inspect DataFrames
Load a small CSV into a DataFrame, run head and info, and check that numeric columns are not strings before calculating means.
