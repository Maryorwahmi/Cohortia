Module 5 › Chapter 5.2 › Create Series
Process Flow

Constructors & index behavior

Choose constructor based on source data: list, NumPy array, or dict. Confirm the resulting index to avoid alignment issues later.

Step 1 — List/array
Default integer index 0..n-1. Access by position or create a custom index if labels matter.
Step 2 — Dictionary
Keys become labels. Useful when your data already includes meaningful names.
Step 3 — Inspect
Check index, dtype, and missing values with attributes and methods like index, dtype, and isnull.
Code Examples
import pandas as pd
import numpy as np

# From a list
s1 = pd.Series([10, 20, 30, 40, 50])
print(s1.index)

# From a list with custom index
s2 = pd.Series([10, 20, 30], index=['a', 'b', 'c'])
print(s2['a'])

# From a dictionary
data_dict = {'Math': 90, 'Science': 85, 'English': 92}
s3 = pd.Series(data_dict)
print(s3.index)
Example scenario
Store sensor readings as a Series using timestamps as the index so you can align different sensors by time later.
