Module 5 › Chapter 5.2 › loc & iloc
Definition

Label vs position

loc selects by label; iloc selects by integer position. Their slice semantics differ — loc is inclusive, iloc follows Python exclusivity for the stop index.

Rule of thumb
Use loc for meaningful labeled indices like dates or IDs; use iloc for raw positional slicing.
Common pitfall
Assuming default numeric index means loc and iloc are interchangeable; this breaks when index is non-numeric.
Code examples
# Position-based
print(df.iloc[0])        # first row by position

# Label-based (if index has labels)
print(df.loc[1])         # row labeled 1, not necessarily first

# Mixed selection
print(df.loc[1, 'Age'])
print(df.iloc[0, 1])
Check
Always check df.index to know whether labels or positions are the safer choice for your selection.
