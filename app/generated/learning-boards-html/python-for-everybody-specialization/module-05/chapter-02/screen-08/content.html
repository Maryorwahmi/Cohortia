Module 5 › Chapter 5.2 › DataFrame
Definition

Pandas DataFrame

A two-dimensional labeled structure: columns are Series, rows share an index, and each column can have its own data type.

Common constructors
From dict of lists, list of dicts, NumPy arrays, or pd.read_csv for files.
Inspect after create
Always check df.shape, df.columns and df.index to verify construction matched expectations.
Key Takeaway

Think of a DataFrame as a collection of named Series sharing the same index — perfect for multi-field records.

Example
import pandas as pd

data = {
    'Name': ['Alice', 'Bob', 'Charlie', 'David'],
    'Age': [25, 30, 35, 28],
    'City': ['New York', 'Paris', 'London', 'Tokyo']
}

df = pd.DataFrame(data)
print(df.shape)
print(df.columns)
Scenario
Use a DataFrame to hold tabular survey results where different columns have different types, like strings and numbers.
