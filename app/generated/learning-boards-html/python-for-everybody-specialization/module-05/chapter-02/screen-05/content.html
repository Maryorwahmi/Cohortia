Module 5 › Chapter 5.2 › Series
Definition

Pandas Series

A one-dimensional labeled array with an index and a dtype. Use it for single columns or vectors of values.

Analogy
A Series is like a labeled column in a spreadsheet — each cell has a label and a value.
When to use
For a single column you want to index, summarize, or apply element-wise math to.
Key Takeaway

Series adds labels and vectorized ops to an array — ideal for single-column data with meaningful indices.

Quick examples
import pandas as pd

# From a list
s1 = pd.Series([10, 20, 30, 40, 50])

# From a list with custom index
s2 = pd.Series([10, 20, 30], index=['a', 'b', 'c'])

# From a dictionary
data_dict = {'Math': 90, 'Science': 85, 'English': 92}
s3 = pd.Series(data_dict)
Common mistake
Treating a Series as a full table. If you need multiple named fields, use a DataFrame.
