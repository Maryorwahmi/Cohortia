Process

Indexing and arithmetic

Use integer positions or labels to access elements. Arithmetic applies element-wise and aligns on labels when combining Series.

Access examples
  • Position: s[0] or s.iloc[0]
  • Label: s['label'] or s.loc['label']
  • Slices: loc is label-inclusive, iloc is position-based and end-exclusive
Arithmetic
Adding a scalar affects every element; adding two Series aligns by index labels and can produce NaN when labels are missing.
Code walkthrough
import pandas as pd

s2 = pd.Series([10,20,30], index=['a','b','c'])
print(s2[0])        # position access -> 10
print(s2['a'])      # label access -> 10

s_add = s2 + 5      # element-wise + scalar

s_other = pd.Series({'b':100, 'c':200, 'd':300})
s_sum = s2 + s_other  # aligns on labels: 'a' and 'd' produce NaN where missing
print(s_sum)
