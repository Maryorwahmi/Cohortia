Boolean indexing

Create a Boolean mask using column conditions and apply it to the DataFrame to select rows that match the condition.

Single condition
df[df['Age'] > 28] selects rows where the Age column is greater than 28.
Compound filters
Combine with & and |. Example: df[(df['Age'] > 28) & (df['City'] == 'London')].
Code example
# Filter for Grade >= 80
high = df_students[df_students['Grade'] >= 80]

# Filter for Class A
class_a = df_students[df_students['Class'] == 'A']

# Compound filter example
both = df_students[(df_students['Grade'] >= 80) & (df_students['Class'] == 'A')]
Warning
Do not use Python's and/or between Series; use & and | with parentheses instead.
