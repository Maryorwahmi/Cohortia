Series vs DataFrame selection

Single-string keys give a Series; lists of column names give a DataFrame. Dot notation is convenient but limited.

Single column
df['Name'] returns a Series that supports Series methods like mean or sum.
Multiple columns
df[['Name','City']] returns a DataFrame suitable for further table-level operations.
Key Takeaway

Choose Series or DataFrame selection intentionally to match the methods you plan to call next.

Code examples
# Single column -> Series
print(df['Name'])

# Multiple columns -> DataFrame
print(df[['Name','City']])

# Dot notation (use carefully)
print(df.Age)
Pro tip
Prefer bracket notation for predictable behavior and to handle names with spaces or special characters.
