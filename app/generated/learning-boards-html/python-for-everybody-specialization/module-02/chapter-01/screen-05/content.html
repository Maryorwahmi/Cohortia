Module 2 › Chapter 2.1 › Indexing & Slicing
Rules for indices
  • Zero-based positive indices: first element at index 0
  • Negative indices: -1 is last, -2 second-last
  • IndexError occurs when index not in 0..len(list)-1
Slicing semantics
  • Syntax: start:end:step
  • Start inclusive, end exclusive — end is the stop position
  • Omitting values defaults to the list's start or end
Tip: use a full slice with no arguments to copy a list: copy = my_list[:]
Examples
fruits = ["apple", "banana", "cherry", "date"]
print(fruits[0])   # apple
print(fruits[-1])  # date
print(fruits[1:3]) # ['banana', 'cherry']
print(fruits[:2])  # ['apple', 'banana']
print(fruits[::2]) # ['apple', 'cherry']

copy = fruits[:]   # shallow copy of list
Common mistake
Expecting the slice end to be included. Remember end is exclusive and can change slice length by one unexpectedly.
