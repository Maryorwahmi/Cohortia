Module 2 › Chapter 2.1 › What is a list?
Definition

An ordered, mutable collection of items enclosed in square brackets. Order gives each item an index; mutability lets you change contents after creation.

Properties
  • Ordered: indices start at zero
  • Mutable: elements can be replaced or removed
  • Heterogeneous: can contain mixed types, including lists
Analogy
A numbered shelf where items can be replaced, added, or taken away.
Concrete example
# An empty list
my_empty_list = []

# A list of strings
fruits = ["apple", "banana", "cherry", "date"]

# A list with mixed types
mixed = ["Alice", 30, True, 175.5]

# A list of lists (matrix)
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
Key Takeaway

Use lists for ordered, changeable sequences and remember nested lists introduce deeper structure and reference behavior.
