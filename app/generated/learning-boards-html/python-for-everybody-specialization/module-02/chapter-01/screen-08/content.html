Module 2 › Chapter 2.1 › Removing Elements
Delete by index or value
  • del list[index] deletes by index and returns nothing
  • list.remove(value) deletes first matching value; raises ValueError if not found
  • list.pop([index]) removes and returns item; default pops last element
When removing many items, prefer building a new list or a comprehension to avoid iteration pitfalls.
Examples
fruits = ["apple","banana","cherry","date","banana"]
del fruits[0]            # removes 'apple'
fruits.remove("banana") # removes first 'banana'
last = fruits.pop()      # removes and returns last item

# Remove all 'banana' via comprehension
fruits = [x for x in fruits if x != "banana"]
Warning
Calling remove on a missing value raises ValueError. Check membership first to avoid a crash.
