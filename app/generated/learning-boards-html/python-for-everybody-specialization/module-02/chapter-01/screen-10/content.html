Module 2 › Chapter 2.1 › sort() vs sorted()
In-place versus new list
  • list.sort(): modifies the original list and returns None
  • sorted(list): returns a new sorted list, leaving the original unchanged
  • Both accept key and reverse arguments for custom ordering
Remember: sort returns None — assigning its result to a variable will set that variable to None.
Examples
nums = [3, 1, 4, 2]
sorted_nums = sorted(nums)  # [1,2,3,4], nums unchanged
nums.sort()                 # nums is now [1,2,3,4]

# Sorting with key
words = ["apple","Banana","cherry"]
words_sorted = sorted(words, key=str.lower)
Key Takeaway
Choose sort for in-place updates and sorted for safe, non-destructive sorting when the original order must be preserved.
