Lists in Python
Ordered collections you can change at runtime

Think of a list as a numbered shelf. Each slot holds an item, the order is significant, and you can replace or move items without rebuilding the shelf. Lists can hold strings, numbers, booleans, or even other lists.

Why this matters

Lists let you manage sequences of data succinctly and efficiently, which you will do in almost every Python program you write.

[ "apple", "banana", "cherry" ]
[1, 2, 3, 4]
["Alice", 30, True]
Shelves & indexes
First item is index 0. Negative indices count from the end. Slicing extracts subsequences using start:end:step where the end is exclusive.
Common methods: append, insert, remove, pop, sort, reverse, count, index, extend
