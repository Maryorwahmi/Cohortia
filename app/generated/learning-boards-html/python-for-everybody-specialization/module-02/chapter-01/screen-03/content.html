Practice Checklist
Check length before indexing
Use the length function to confirm an index is valid, preventing IndexError when indices are dynamic.
Example mnemonic: length is your safety rope.
Guard removals
Check membership with the membership operator before remove, or handle ValueError to avoid runtime crashes.
Try-if-present pattern reduces surprises.
Choose extend vs plus
Plus creates a new list; extend mutates the existing list. Use extend when you want to preserve the same list object.
Mnemonic: extend extends the same shelf.
Enumerate for index + value
Enumerate yields pairs of index and item, avoiding manual index management and off-by-one errors.
Use enumerate when position information matters.
