Common loops
for fruit in fruits:
    print("I love", fruit)

# With index
for i, fruit in enumerate(fruits):
    print(f"Fruit at position {i}: {fruit}")
Prefer enumerate instead of manual counters. It reduces off-by-one errors and simplifies code.
Mutating while iterating
If you remove items inside a for loop, the loop's internal index still advances and can skip elements. Safer options include iterating over a copy or using a list comprehension to produce a new list.
# Unsafe
for item in items:
    if should_remove(item):
        items.remove(item)

# Safer
for item in items[:]:
    if should_remove(item):
        items.remove(item)
