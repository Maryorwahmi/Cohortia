Assignment vs copy
original = [1, 2, 3]
alias = original
alias[0] = 99
print(original)  # [99, 2, 3]

# Shallow copy
copy = original[:]
copy[0] = 1
print(original)  # [99, 2, 3] unchanged by copy
A full slice creates a shallow copy. For nested lists, inner lists are still shared unless you perform a deep copy.
Nested list example
matrix = [[1,2],[3,4]]
shallow = matrix[:]
shallow[0][0] = 99
print(matrix)  # [[99,2],[3,4]]  inner list changed
Common mistake
Expecting a slice copy to isolate nested elements. Use copy utilities or recreate inner structures to avoid shared references.
Key Takeaway

Assignment binds names to the same list object. Use copies when you need independent collections, and be mindful of nested lists.
