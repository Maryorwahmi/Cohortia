Module 2 › Chapter 2.1 › Methods & Safety
append / insert / extend
Mutate the list by adding items; extend adds many items from an iterable.
remove / pop / del
Delete items by value or index; guard against ValueError and IndexError.
sort vs sorted
sort mutates the list and returns None; sorted returns a new list.
Quick summary
Keep a safety checklist: check lengths, verify membership before removal, watch for aliasing, and avoid in-loop mutation unless intentional.
