Module 2 › Chapter 2.1 › Adding Items
Methods and operators
  • append(item): add single item to end, in-place
  • insert(index, item): insert at position, in-place
  • extend(iterable): add all items from iterable, in-place
  • +: concatenation returns a new list
Tip: passing a list to append creates a nested list element; use extend to flatten additions.
Examples
fruits = ["apple", "banana"]
fruits.append("cherry")      # ['apple', 'banana', 'cherry']
fruits.insert(1, "apricot") # ['apple', 'apricot', 'banana', 'cherry']
more = ["date", "elderberry"]
fruits.extend(more)           # modifies fruits in place
all_fruits = fruits + ["fig"] # returns a new list
Key Takeaway
Choose extend for bulk in-place updates and plus when you intentionally want a new list object.
