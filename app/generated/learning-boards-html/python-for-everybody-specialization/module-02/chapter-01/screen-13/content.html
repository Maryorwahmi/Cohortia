Module 2 › Chapter 2.1 › Common Mistakes
Error patterns
  • IndexError: index out of range — check len before accessing
  • ValueError: remove called on missing value — test membership first
  • Mutation while iterating: causes skipped items — iterate over a copy or build a new list
Debug tip: add prints before and after operations to observe how indices and contents change.
Quick fixes
Use if index < len(list) to guard indexing, use if item in list before remove, use list comprehension for filtered results, and avoid mutable defaults in function signatures.
Common misconception
Believing sort returns the sorted list. sort mutates and returns None; use sorted if you need a new list.
