Module 2 › Chapter 2.1 › Nested Lists
Representation
matrix = [[1,2,3],
          [4,5,6],
          [7,8,9]]
print(matrix[1][2])  # accesses second row, third column -> 6
Remember that matrix[1] returns the inner list at index one, and appending or assigning to that inner list mutates the shared object unless copied.
Copy pitfalls
# Wrong: creates three references to the same list
rows = [[0]*3] * 3
rows[0][0] = 1
print(rows)  # all rows show the change

# Correct: build each row separately
rows = [[0]*3 for _ in range(3)]
Gotcha
Using multiplication duplicates references for nested lists. Use a comprehension to create independent inner lists.
