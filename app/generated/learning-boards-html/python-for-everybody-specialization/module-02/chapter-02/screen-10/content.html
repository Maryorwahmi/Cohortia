Process

Iterating dictionary contents

for key in dict: iterates keys
for v in dict.values(): iterates values
for k, v in dict.items(): iterates key-value pairs
If you need to modify during iteration, first convert keys to a list: for k in list(d.keys()): ...
Examples
person = {'name': 'Alice', 'age': 31, 'city': 'New York'}

# Keys
for k in person:
  print(k)

# Values
for v in person.values():
  print(v)

# Items
for k, v in person.items():
  print(f"{k}: {v}")

# Modify safely
for k in list(person.keys()):
  if should_remove(k):
    del person[k]
Iterate with items when you need both pieces of data for processing, reporting, or formatting output.
