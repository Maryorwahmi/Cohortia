Core Concept

What is a dictionary?

A dictionary stores unique key-value pairs. Use keys as labels for fast retrieval instead of positions.

Keys are unique and immutable
Values can be any type and may repeat
.lookup is key-based and efficient
Key Takeaway

Choose keys that uniquely identify values and remain immutable to avoid runtime errors and unpredictable behavior.

Analogy
A Rolodex where the key is the card label and the value is the card content.
Example: person
name: 'Alice' age: 30 city: 'New York'
Example: product_prices
'laptop': 1200 'mouse': 25 
# Empty dictionary
my_empty = {}

# Keys map to values
person = {'name': 'Alice', 'age': 30}
