Definition

Creating dictionaries

Use curly braces with key: value pairs. An empty dictionary is {}. Keys must be immutable.

Concrete examples
person = {'{"name"}': 'Alice', '"age"': 30}
product_prices = {'{"laptop"}': 1200, '"mouse"': 25}
student_grades = {101: 95, 102: 88}
Key Takeaway

Create dictionaries with clear, immutable keys so lookups are intuitive and consistent.

Live-code walkthrough
# Empty dictionary
my_empty = {}

# Person record
person = {
  'name': 'Alice',
  'age': 30,
  'city': 'New York'
}

# Numeric keys as labels
student_grades = {
  101: 95,
  102: 88
}

print(person)
print(student_grades)
Run these lines to see the printed dictionaries. Note how numeric keys act as labels, not positions.
