Module 2 › Chapter 2.2 › Key Concepts
Dictionary
A collection of unique key-value pairs enclosed in curly braces.
Key-Value Pair
A unique key maps to a corresponding value; keys identify values for lookup.
Key
An immutable, unique identifier such as a string, number, or tuple.
Summary

Use clear immutable keys and prefer safe retrieval patterns to make your dictionary usage predictable and error-resistant.
