Process Flow

Add or modify with assignment

  1. Choose a key that uniquely identifies the value.
  2. Assign dictionary[key] = value to add or update.
  3. Print or inspect the dictionary to confirm the new state.
Remember: assignment mutates the dictionary in place and can replace an existing value without warning.
Example
person = {'name': 'Alice', 'age': 30}

# Add a new key
person['email'] = 'alice@example.com'

# Update existing key
person['age'] = 31

print(person)
# {'name': 'Alice', 'age': 31, 'email': 'alice@example.com'}
Tip: When storing lists as values, create separate lists to avoid shared references.
