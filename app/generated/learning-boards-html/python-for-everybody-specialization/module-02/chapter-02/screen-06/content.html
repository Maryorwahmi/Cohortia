Definition

Direct access and KeyError

Use bracket syntax when you are certain the key exists. Otherwise you risk a KeyError which stops execution.

Common mistake: directly accessing missing keys causes KeyError.
Safer pattern: check 'in' or use the get method for optional keys.
Key Takeaway

Reserve bracket access for guaranteed keys; otherwise prefer membership checks or safe retrieval to avoid errors.

Example & walkthrough
person = {'name': 'Alice', 'age': 30}

# Safe: key exists
print(person['name'])  # Alice

# Unsafe: may raise KeyError
# print(person['country'])  # KeyError if uncommented

# Safer check before access
if 'country' in person:
  print(person['country'])
else:
  print('country not set')
Practice by intentionally reading a missing key to see the KeyError, then refactor to a check or safe retrieval to make the code robust.
