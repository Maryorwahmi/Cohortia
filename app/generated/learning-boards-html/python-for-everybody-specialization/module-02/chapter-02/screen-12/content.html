Common Mistakes

Mutable keys & iteration safety

Error: using list or dict as a key raises a TypeError: unhashable type.
Modification during iteration can raise RuntimeError: dictionary changed size during iteration.
Key Takeaway

Use immutable keys and iterate over a key list copy if you must change the dictionary during iteration.

Examples & safe patterns
# Invalid key
# bad = {[1, 2]: 'value'}  # raises TypeError: unhashable type: 'list'

# Safe iteration when removing keys
d = {'a': 1, 'b': 2, 'c': 3}
for k in list(d.keys()):
  if k == 'b':
    del d[k]

print(d)  # {'a': 1, 'c': 3}
When in doubt, copy keys for modification or construct a new dictionary to avoid runtime errors and surprises.
