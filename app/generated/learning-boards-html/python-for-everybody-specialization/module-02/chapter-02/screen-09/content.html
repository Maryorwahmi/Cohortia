Definition

Removing entries

del removes a key-value pair and raises KeyError if missing.
pop removes and returns the value, accepts a default to avoid KeyError.
popitem removes an arbitrary or last-inserted pair and returns it.
clear empties the dictionary.
Key Takeaway

Use the method that best matches whether you need the removed value and whether the key might be absent.

Examples
person = {'name': 'Alice', 'email': 'alice@example.com', 'age': 31}

# Remove without return
del person['email']

# Remove and get value with default
removed = person.pop('zip_code', 'N/A')  # returns 'N/A' and does not raise

# Remove last-inserted pair
pair = person.popitem()

# Empty the dictionary
# person.clear()
When removing keys you may want to log or use the returned value from pop for downstream logic such as confirmation messages or auditing.
