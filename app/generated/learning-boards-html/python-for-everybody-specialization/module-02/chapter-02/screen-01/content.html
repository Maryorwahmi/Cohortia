Dictionaries: Key-Value Pairs

Learn how to store and retrieve related data by mapping unique keys to values, handle common errors safely, and use dictionary methods to iterate and update structured information.

Analogy: Labeled Drawers
A key labels a drawer; the value is what's inside.
Key: name → Value: Alice
Key: id 101 → Value: 95
Key: 'laptop' → Value: 1200
Key: 'is_student' → Value: False
Explore Key Topics
Create & Access
Make dictionaries with curly braces and read values by keys. Remember that direct access can raise an error if a key is missing.
Modify & Remove
Assign to a key to add or update. Use del, pop, or popitem to remove entries safely when needed.
Iterate & Inspect
Use keys(), values(), and items() to examine contents and loop through dictionary elements efficiently.
