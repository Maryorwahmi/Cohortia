Module 3 › Chapter 2.3 › Key Concepts
Tuple
Ordered, immutable sequence typically written with parentheses.
Immutable
Cannot add, remove, or reassign elements; prevents accidental structure changes.
Packing & Unpacking
Comma-separated values pack into a tuple; unpack to assign elements to variables.
Summary takeaway

Use tuples when you need stable, position-based records or dictionary keys and use packing/unpacking for clear, concise multi-value returns.
