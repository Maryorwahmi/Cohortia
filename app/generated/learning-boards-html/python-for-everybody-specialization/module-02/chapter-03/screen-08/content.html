Packing example
rgb_color = 255, 0, 128
print(rgb_color)        # <-- (255, 0, 128)
print(type(rgb_color))  # <-- <class 'tuple'>
Packing happens whenever Python sees comma-separated values in an expression context. Parentheses are optional but often helpful for clarity.
Unpacking example
coordinates = (10.0, 20.5)
latitude, longitude = coordinates
print(f"Latitude: {latitude}, Longitude: {longitude}")

# Swapping
a = 10
b = 20
a, b = b, a
print(a, b)  # <-- 20 10
Unpacking requires matching the number of targets unless you use a starred expression to collect leftovers.
