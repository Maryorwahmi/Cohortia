Practice checkpoints
  • Syntax: Remember comma, not parentheses, define a tuple. Empty tuple is () and single-item needs a trailing comma.
  • Access: Use zero-based indexing and negative indices. Slicing returns a new tuple view.
  • Packing: Multiple values separated by commas become a tuple automatically.
  • Unpacking: Assign tuple elements directly to variables; counts must match, unless using starred expressions.
Mnemonic
Comma is king. Parentheses are optional. Think "locked structure" when you need immutability.
