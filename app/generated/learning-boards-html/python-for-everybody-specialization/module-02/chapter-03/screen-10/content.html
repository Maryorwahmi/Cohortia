Feature comparison
MutabilityList: mutable · Tuple: immutable
SyntaxList: [ ] · Tuple: ( ) or comma-separated
MethodsList: many (append, remove, sort) · Tuple: few (count, index)
Use casesList: dynamic collections · Tuple: fixed records, dict keys, returns
Decision guide
  1. If you need to change items often, pick a list.
  2. If the collection represents a fixed record or needs to be a dictionary key, pick a tuple.
  3. When intent matters, tuples communicate immutability to other developers.
Small performance differences exist but should not be the primary decision; prefer clarity and correctness first.
