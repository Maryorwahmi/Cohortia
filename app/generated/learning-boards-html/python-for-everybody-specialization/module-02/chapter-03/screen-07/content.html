Module 3 › Chapter 2.3 › Immutability in practice
What raises an error
Attempting to assign to an index of a tuple causes a TypeError because the container's membership is fixed.
coordinates = (10.0, 20.5)
# coordinates[0] = 15.0  # TypeError: 'tuple' object does not support item assignment
Mutable element inside a tuple
You cannot replace the list object inside a tuple, but you can modify that list's contents.
mutable_in_tuple = ([1, 2], "hello")
mutable_in_tuple[0].append(3)
print(mutable_in_tuple)  # <-- ([1, 2, 3], 'hello')
# mutable_in_tuple[0] = [3,4]  # TypeError if attempted
Think: tuple locks the slots, but the objects in those slots can still be changed if they are mutable.
