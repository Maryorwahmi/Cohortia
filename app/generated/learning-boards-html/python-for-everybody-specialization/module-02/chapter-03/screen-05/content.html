Rules for creating tuples
  1. Comma-separated items form a tuple: 1, 2, 3 produces a tuple in many contexts.
  2. Parentheses improve readability: (1, 2, 3) is common and clear.
  3. Empty tuple: () is the literal for no items.
  4. Single element: use a trailing comma, for example (5,) — without the comma it's just the value 5.
Code examples
my_empty_tuple = ()
coordinates = (10.0, 20.5)
rgb_color = 255, 0, 128
single_not_tuple = (5)
single_tuple = (5,)
print(type(single_not_tuple))  # <class 'int'>
print(type(single_tuple))      # <class 'tuple'>
Common mistake
Forgetting the trailing comma on a single value silently changes its type. When in doubt, use a trailing comma for single-element tuples to be explicit.
Key Takeaway
Comma, not parentheses, is the tuple signal. Use trailing comma for a single item and () for empty tuples.
