Module 3 › Chapter 2.3 › Tuple methods
count()
Returns how many times a value appears in the tuple.
my_tuple = (1, 2, 3, 2, 4, 2)
print(my_tuple.count(2))  # <-- 3
index()
Returns the index of the first occurrence of the value, or raises a ValueError if not present.
my_tuple = (1, 2, 3, 2)
print(my_tuple.index(3))  # <-- 2
Because tuples cannot be changed, these methods only help inspect contents rather than modify them.
