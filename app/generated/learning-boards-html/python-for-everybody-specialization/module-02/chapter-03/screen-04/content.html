Claim: Tuple is an ordered, immutable sequence

Once created, the tuple's membership and order cannot be changed. This makes tuples excellent for fixed records and consistent function returns.

Analogy
A tuple is like a locked frame: positions are fixed. If a frame contains a photograph mounted on a magnet, the photograph can shift; similarly, mutable elements inside a tuple can still change.
Key takeaway
Immutability protects the sequence structure, not the internal mutability of objects contained within it.
Concrete examples
Coordinates
(10.0, 20.5) — fixed pair used to identify a location.
RGB value
255, 0, 128 → (255, 0, 128) — color components that should remain in place.
Function returns
Functions return multiple values in a tuple so callers get a stable, position-based result.
Common misconception: immutability means no nested change — incorrect. Only the container is immutable.
