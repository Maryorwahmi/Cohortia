Indexing rules
  • First element: index 0.
  • Last element: index -1.
  • Slices: start:stop returns a new tuple; stop is exclusive.
Code examples
days_of_week = ("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
print(days_of_week[0])     # <-- 'Mon'
print(days_of_week[-1])    # <-- 'Sun'
print(days_of_week[1:4])   # <-- ('Tue', 'Wed', 'Thu')
sub = days_of_week[:3]     # <-- ('Mon', 'Tue', 'Wed')
Practical notes
Slicing returns a tuple and never modifies the original. Use negative indices for quick access to trailing elements. When unpacking, make sure the number of variables matches the number of items or use a star expression to collect remaining items.
Check your understanding
If days_of_week[1:4] returns three items, what is the correct index for the last of those three? Think positionally: start is 1, stop is 4 (exclusive), last index is 3.
