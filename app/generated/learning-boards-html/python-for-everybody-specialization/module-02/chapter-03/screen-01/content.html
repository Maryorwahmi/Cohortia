Tuples: Immutable Sequences

Ordered sequences that protect their structure. Use them for fixed records, composite keys, and function returns.

Example
Coordinates: (10.0, 20.5) — a fixed pair that should not change.
Why it matters
Immutability prevents accidental edits and lets tuples be used as dictionary keys for composite identifiers.
Explore Key Topics
Creation & Syntax
Parentheses optional; commas define tuples; trailing comma for single-item tuples.
Packing & Unpacking
Pack values into a tuple automatically; unpack into variables for clear assignments.
Immutability
Prevent modification of structure; mutable items inside can still change.
