Module 2 › Chapter 1.3 › String Methods
Method quick reference
upper() → all uppercase
lower() → all lowercase
strip() → remove leading/trailing whitespace
replace(old, new) → substitute substrings
capitalize() → first char uppercase, rest lowercase
len(string) → character count
Examples
s = " Hello World! " print(s.upper()) # HELLO WORLD! print(s.lower()) # hello world! print(s.strip()) # Hello World! print(s.replace("World","Python")) print(len("Python Programming")) # 18
Misconception
These methods do not modify the original string; they return a new one. If you need the cleaned value later, save it to a variable.
Key Takeaway

String methods are your first line of defense for messy input; chain them to normalize user-provided text before validation or display.
