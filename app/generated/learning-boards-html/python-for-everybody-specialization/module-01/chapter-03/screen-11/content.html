Module 2 › Chapter 1.3 › Common Mistakes
TypeError from mixing types
Trying to add a string and a number will raise an error. Convert strings to int or float before math or use formatting for display.
Forgetting strip()
Extra spaces can break comparisons or produce ugly output. Use strip to normalize input and then validate length.
Fix: Validate conversions
Use try-except loops to re-prompt on invalid numeric input.
Fix: Assign method results
Remember to save strip(), replace(), and case conversions back into variables.
Fix: User-friendly errors
Print clear messages when input fails so users know how to correct it.
