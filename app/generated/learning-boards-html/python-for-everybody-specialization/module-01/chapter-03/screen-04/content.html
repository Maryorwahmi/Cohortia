Module 2 › Chapter 1.3 › The input() function
Definition

What input does

  • Displays an optional prompt and waits for the user to type.
  • Always returns the entered text as a string.
  • Works for names, phrases, or numeric text that must be converted before math.
Cleaning tip
Call strip on the result to remove accidental leading or trailing spaces before further processing.
Key Takeaway

input returns text; always consider cleaning and conversion depending on how you plan to use that value.

Example
# Ask for a name and greet name = input("What is your name? ") print("Hello, " + name) # If the user types " alice ", consider cleaning: clean_name = name.strip().title() print("Hello, " + clean_name)
Misconception
Some learners assume input auto-detects numbers. It does not. If you need numeric math, convert the returned string explicitly to int or float and handle conversion errors.
