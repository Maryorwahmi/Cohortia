Module 2 › Chapter 1.3 › Number Formatting
Examples
score = 95.4567
print(f"Score: {score:.1f}%")   # shows one decimal place
print(f"Score: {score:.2f}%")   # shows two decimal places

price = 1200.5
print("The price is ${:.2f}".format(price))  # two decimals for currency
Formatting applies only to presentation. Use the raw numeric variable for calculations and format when you display the result.
Common mistake
Trying to round by concatenating a rounded string can make subsequent numerical use harder; prefer numeric rounding for computation and formatting only for display.
Key Takeaway

Use format specifiers in f-strings or .format() to present numbers consistently and professionally.
