Module 2 › Chapter 1.3 › Convert Input
Conversion Steps
1. Ask and strip
raw = input(prompt); cleaned = raw.strip()
2. Try conversion
Use try: value = int(cleaned) or float(cleaned) except ValueError: repeat prompt
3. Use the numeric value
Perform arithmetic once conversion succeeds
Example: validation loop
while True:
  s = input("Enter a whole number: ").strip()
  try:
    n = int(s)
    break
  except ValueError:
    print("That is not a valid whole number. Try again.")

# Now n is safe to use in math
Misconception
Converting without validation assumes perfect input. Expect mistakes and give helpful feedback — this keeps users from being confused by raw error traces.
