Input & Output Checklist
  1. Write a clear prompt describing expected format.
  2. Call strip() to remove leading/trailing spaces immediately.
  3. Validate numeric input with a loop and try-except when converting.
  4. Use f-strings or .format() to present numbers with appropriate precision.
  5. Normalize text with case methods before comparison or storage.
  6. Test with empty, spaced, and invalid inputs to confirm behavior.
Key Takeaway

A small checklist prevents most input edge cases and turns simple scripts into friendly tools for users.
