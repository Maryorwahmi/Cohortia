interactive_app.py (excerpt)
print("--- Welcome to the Cohortia Interactive App! ---")

name_input = input("What is your full name? ")
formatted_name = name_input.strip().title()

while True:
  fav_number_str = input("What is your favorite whole number? ")
  try:
    fav_number = int(fav_number_str)
    break
  except ValueError:
    print("That's not a valid whole number. Please try again.")

city_input = input("Which city do you live in? ")
formatted_city = city_input.strip().capitalize()

lucky_number = fav_number * 7

print(f"
Hello, {formatted_name} from {formatted_city}!")
print(f"Your favorite number is {fav_number}.")
print(f"A fun fact: Your favorite number multiplied by 7 is {lucky_number}!")
Example behavior
If the user types " alice smith ", the program prints "Alice Smith". If they type "ten" for the number, the loop asks again until a valid integer is provided.
Pro Tip

Test the app with varied inputs: extra spaces, mixed case, and invalid number text to see the robustness of your cleaning and validation steps.
