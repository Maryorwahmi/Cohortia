Module 2 › Chapter 1.3 › Practice & Assessment
Hands-on activity
Create interactive_app.py that asks for name, favorite whole number, and city, validates the number, computes favorite*7, and prints formatted results using f-strings.
Try inputs: " alice smith ", "ten", " 42 ", and observe how validation and strip() change behavior.
Assessment idea
Which code correctly converts a price and prints a two-decimal discounted price? Answers that convert the input to float and use formatting are correct.
Key Takeaway

Practice both writing the program and predicting outputs; validation and formatting are as important as conversion.
