Module 2 › Chapter 1.3 › Concatenation vs Formatting
Concatenation (+)
Simple joins of strings. Requires explicit conversion for numbers.
first = "John"
last = "Doe"
print(first + " " + last)

age = 30
# Must convert age to join:
print("Age: " + str(age))
Limitation: mixing types forces manual conversions and can produce TypeError if missed.
Formatting (f-strings & .format())
Embed variables and format numbers cleanly without manual conversions.
name = "Alice"
score = 95.5
print(f"Student: {name}, Score: {score:.1f}%")

# .format example
print("The {} costs ${:.2f}.".format("Laptop", 1200.5))
Benefit: clearer code, direct numeric formatting, fewer conversion mistakes.
When to use +: quick joins
When to use f-strings: readable embedding & formatting
When to use .format(): compatibility and placeholder control
