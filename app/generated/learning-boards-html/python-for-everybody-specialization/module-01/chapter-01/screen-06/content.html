Enter and use the REPL
Type python or python3 and press Enter. Look for the >>> prompt, then type expressions or call the print function to see results instantly.
$ python >>> 100 / 3 33.333333333333336 >>> print("My first interactive Python line!") My first interactive Python line!
Exit with exit(), Ctrl+D (macOS/Linux), or Ctrl+Z then Enter (Windows).
Practice prompts
  • Compute 5 * 7 and confirm the numeric result.
  • Call the print function with a short message to verify string output.
  • Try a quick type error to see an interpreter message and learn how it looks.
Common Mistake
Expecting the REPL to save work. Lines typed here disappear when you exit. Save important code in a file instead.
Key Takeaway

Use the REPL to test expressions quickly, then copy successful lines into a script for reuse.
