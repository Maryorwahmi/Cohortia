Learning Objectives

Learn → Understand → Apply → Master

Bloom: practical setup and execution
01
Install Python
Run the official installer and add Python to PATH so the system finds the interpreter. This step makes it possible to run python from any folder and install packages later.
VERIFIED COMPETENCY MILESTONE
02
Use the Interpreter
Open the REPL to evaluate expressions and call the print function. Immediate feedback helps verify understanding before saving code to files.
VERIFIED COMPETENCY MILESTONE
03
Write & Run a Script
Create a .py file with the print function, save it, then run it from the terminal using the python command. This turns experiments into repeatable runs.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot Common Errors
Read SyntaxError and NameError messages, correct missing punctuation or typos, and re-run. Error messages point to the cause and the approximate location.
VERIFIED COMPETENCY MILESTONE
