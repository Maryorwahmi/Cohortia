What is a SyntaxError?

An error raised when Python cannot parse your code due to incorrect punctuation, unmatched quotes, missing parentheses, or similar grammar issues.

print("Welcome to Cohortia"
The interpreter will indicate a SyntaxError and often the line number or near the end-of-file where it expected more tokens. Inspect the referenced line closely.
Fixing steps
  1. Read the error message and note the line number.
  2. Open the file and check punctuation, quotes, and parentheses on that line.
  3. Save the file and run it again to confirm the error is gone.
Key Takeaway
SyntaxError messages point to grammar problems. Fix the punctuation and save before re-running.
