Why PATH matters
  • PATH tells your terminal where to look for programs like python and pip.
  • Adding Python to PATH during installation allows simple commands like python --version to work anywhere.
  • If PATH is not set you will see an error when invoking python from a folder that doesn't contain the interpreter.
Verification commands
python --version pip --version
Pro Tip
On macOS and Linux you may use python3 instead of python if your system reserves python for another version.
Installation steps (general)
  1. Download the official installer referenced in this chapter.
  2. Run the installer. On Windows, enable "Add Python to PATH".
  3. Open a terminal and run the verification commands above.
Common mistake
Skipping the PATH checkbox on Windows or not using the correct command (python vs python3) causes a "command not found" error. Re-run the installer or update PATH to fix this.
Key Takeaway

Verify your install immediately with python --version and pip --version. If those succeed, move to the REPL test.
