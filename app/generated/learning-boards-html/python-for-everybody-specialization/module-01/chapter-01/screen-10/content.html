What is a NameError?

Raised when code references a name that hasn't been defined in the current scope or was misspelled.

pint("Hello") # typo: 'pint' is not defined
Fix by correcting the name to print and re-running. If the name should have been set earlier in the code, ensure that line executed before the reference.
Debug checklist
  • Check for typos in the name.
  • Ensure the variable or function was defined before use.
  • Confirm necessary imports are present.
Key Takeaway
NameError usually signals a small typo or an undefined variable. Fix the name or the definition order and try again.
