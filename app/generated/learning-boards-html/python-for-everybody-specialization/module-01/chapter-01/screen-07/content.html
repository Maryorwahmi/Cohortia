hello.py example
# This is my first Python script!
print("Hello, Cohortia learners!")
print("Python is fun!")
Save as my_first_script.py (or hello.py) and then run these commands in your terminal:
$ cd path/to/your/folder $ python my_first_script.py Hello, Cohortia learners! Python is fun!
If you see no output, check that you saved the file after edits and that your terminal is in the folder where the file lives. Use the ls or dir command to list files and confirm.
Scenario
You edited a file but the terminal shows the previous output. Most likely you did not save the file. Save and run again to see updated results.
Pro Tip
Keep a dedicated folder for projects, and cd into it before running scripts to avoid confusion about file locations.
Key Takeaway

Edit, save, change into the folder, and run with python filename.py to execute your script and see reproducible output.
