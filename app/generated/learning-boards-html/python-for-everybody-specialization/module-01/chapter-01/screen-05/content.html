Python Interpreter

A program that reads and executes Python code. It supports two modes: interactive REPL and running scripts saved in files.

Interactive Mode (REPL)
Type commands, see immediate results, useful for quick tests and learning syntax.
Script Mode
Save code in a .py file and run the file as a program to produce repeatable output.
Quick example
$ python >>> 2 + 2 4 >>> print("Hello, Cohortia!") Hello, Cohortia!
Analogy
The interpreter is like a radio host who reads scripts (your code) and performs actions for listeners (the computer). Interactive mode is like improvisation; script mode is reading a prepared piece.
Key Takeaway

Use the REPL to test ideas quickly, then move working code into scripts for repeatable runs.
