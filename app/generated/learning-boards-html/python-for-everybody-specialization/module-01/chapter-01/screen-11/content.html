Hands-on checklist

Install & PATH
Run the official installer and enable adding Python to PATH on Windows. Verify with python --version.
REPL Practice
Enter the interpreter, compute 100 / 3, and print a test message. Exit when done.
Script Run
Create my_first_script.py with two print calls, cd to the folder, and run with python my_first_script.py.
If you see errors
Read the error type and location. For SyntaxError, check punctuation. For NameError, check spelling and definitions or imports.
Key Takeaway
This short loop gives fast feedback and a reproducible script you can build on in later chapters.
