Short Drills

A set of verifiable steps you can complete in 10 minutes to confirm each skill.

Install & Verify
Run these commands after installing: python --version and pip --version. If either returns an error, check PATH or reinstall.
Interactive Check
Enter the interpreter, try arithmetic like 5 * 7, then call the print function to see output. Exit with exit() or the platform shortcut.
Script Run
Create my_first_script.py with two print calls, save, cd to the folder, and run python my_first_script.py to see both lines printed.
Troubleshoot
If you see SyntaxError or NameError, read the message, fix punctuation or typos, save, and re-run. The error message gives the likely location to inspect.
