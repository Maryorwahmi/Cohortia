What is pip?

pip installs and manages external Python packages. It usually installs with Python, but you should verify it now.

$ pip --version pip 23.0.1 from ... (python 3.x)
If pip returns an error, ensure your Python installation completed and that pip is on PATH. Sometimes using pip3 instead of pip is appropriate on systems with multiple Python versions.
Why verify now?
Many later lessons require packages. Verifying pip now prevents interruptions later when you need to install a library quickly.
Key Takeaway
Confirm pip works so future package installs run smoothly. If it fails, re-check PATH or reinstall Python with pip enabled.
