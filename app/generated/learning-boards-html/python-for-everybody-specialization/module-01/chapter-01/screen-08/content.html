Module 1 › Chapter 1.1 › Interactive vs Script
Interactive Mode (REPL)
  • Immediate evaluation and feedback.
  • Great for experimenting and quick calculations.
  • Session is ephemeral; actions are not saved to a file automatically.
>>> 2 + 2 4
Script Mode
  • Code is saved in a .py file and re-runnable.
  • Use scripts for programs that require multiple lines or need to be shared.
  • Run with python filename.py from the terminal.
# my_script.py print("Line one") print("Line two")
Misconception
The REPL is a substitute for saving code. It is not. Use it for testing, then transfer working code into scripts.
Key Takeaway
Experiment interactively, then save the final sequence as a script for reproducibility.
