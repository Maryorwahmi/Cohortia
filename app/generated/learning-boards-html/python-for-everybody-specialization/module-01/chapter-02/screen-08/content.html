Module 1 › Chapter 1.2 › Arithmetic
Operator list
Addition: a + b
Subtraction: a - b
Multiplication: a * b
Division (true): a / b → float
Floor division: a // b → integer portion
Modulo: a % b → remainder
Exponentiation: a ** b → power
Concrete example
If you have 24 hours and group them into 7-hour blocks, floor division gives 3 full blocks and modulo gives 3 leftover hours. Use true division to compute average scores with fractional results.
Key takeaway
Key Takeaway

Match the operator to intent: precision versus whole-group counts and remainders.
