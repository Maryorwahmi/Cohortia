Strings (str)
Text inside single or double quotes. Use escape sequences to include quotes or new lines. Strings must be converted to numbers for arithmetic.
Example
Concatenate a name and a label by converting numbers to text, or format with placeholders for readability.
Booleans (bool)
Represent True or False. Used in conditions and control flow. Capitalization matters: True and False are the language values.
Practical note
An empty string is not a boolean but evaluates as falsey in condition checks; keep types explicit for clarity.
