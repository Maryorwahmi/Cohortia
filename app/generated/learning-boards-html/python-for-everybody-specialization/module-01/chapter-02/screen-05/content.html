Module 1 › Chapter 1.2 › Types & Inspection
Concept
Python assigns a type to each value when you store it. During development you can inspect that type to ensure code that follows treats the value correctly. This is a lightweight debugging tool that prevents runtime errors.
Common misconception
A string of digits looks like a number but remains text until converted. Treating it as a number without conversion causes errors in arithmetic operations.
Code walkthrough
# Example script (visual only)
student_name = "Alice Smith"
student_age = 20
gpa = 3.85
is_enrolled = True

# Print values and their types
print("Name:", student_name, "Type:", type(student_name))
print("Age:", student_age, "Type:", type(student_age))
print("GPA:", gpa, "Type:", type(gpa))
print("Enrolled:", is_enrolled, "Type:", type(is_enrolled))
Running this example prints each value and the runtime classification so you can confirm the program's state.
