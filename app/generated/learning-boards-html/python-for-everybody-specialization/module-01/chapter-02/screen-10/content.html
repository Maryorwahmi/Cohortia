Module 1 › Chapter 1.2 › Assignment Operators
Shorthand forms
Add-assign: x += 5
Subtract-assign: x -= 2
Multiply-assign: x *= 3
Divide-assign: x /= 2
Equivalent expansion helps understanding: x += 5 performs x = x + 5 under the hood. Use expansion to debug unexpected results.
Example scenario
When tracking score, use add-assign to accumulate points. Confirm score starts numeric to avoid errors when adding.
Common mistake
Applying add-assign to text without conversion causes a type mismatch that will raise an error.
