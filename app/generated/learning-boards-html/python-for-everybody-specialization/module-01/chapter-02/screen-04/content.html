Module 1 › Chapter 1.2 › Variables
Definition and rules
  • Variables store values under a name you choose.
  • Assign with equals, for example: age = 30 in code (visual only).
  • Names use snake_case, start with a letter or underscore, and contain letters, numbers, or underscores.
  • Avoid starting with a number or including spaces.
Common mistakes
Type confusion
Reassigning a variable from a number to a string is allowed but can break later code that expects a number.
Concrete example
student_name holds text, student_age holds an integer, and course_credits holds a number used in calculations. Descriptive names reduce errors and make outputs readable.
Key takeaway
Key Takeaway

Pick clear, valid names and reassign deliberately to avoid logic errors caused by unexpected types or overwritten values.
