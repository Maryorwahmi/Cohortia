Module 1 › Chapter 1.2 › Integers & Floats
Integers (int)
  • Whole numbers: 10, -5, 0.
  • Use for counts and indices.
  • Floor division returns an integer portion.
Floating-point (float)
  • Numbers with decimals: 3.14, -0.5, 2.0.
  • Results from true division are floats.
  • Converting a float to int truncates the fractional part.
Example & takeaway
If total score divided by count yields 85.666, the average is a float. If you need the number of whole completed segments, use floor division to get the integer portion. Convert explicitly and know that truncation is not rounding.
