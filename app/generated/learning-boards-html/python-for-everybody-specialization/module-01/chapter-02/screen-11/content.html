Common conversions
  • Convert to int when you need whole-number arithmetic.
  • Convert to float when you need decimals or precise division.
  • Convert to str when combining text with numbers for display.
Error example
Trying to add text and number directly raises a TypeError. Convert one operand to the other's type to resolve it.
Hands-on code
# Type conversion example (visual only)
price_str = "49.99"
quantity_str = "2"

# Convert and compute
price_float = float(price_str)
quantity_int = int(quantity_str)
total_cost = price_float * quantity_int

# Convert back for display
message = "Your total is: $" + str(total_cost)
print(message)
This shows converting numeric text to numbers for math, then converting the result to text for concatenation and display. Be cautious converting invalid strings which cause conversion errors.
