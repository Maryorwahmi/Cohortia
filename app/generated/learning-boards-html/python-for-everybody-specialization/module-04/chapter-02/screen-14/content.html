Module 04 › Chapter 4.2 › Key Concepts
sqlite3 module
Python's built-in module for interacting with SQLite databases stored in files.
sqlite3.connect()
Open or create a database file and return a connection object for subsequent operations.
Connection object
Represents the link to the database and creates cursors, commits, and closes the file.
Summary

These three concepts are the foundation for using SQLite from Python: the module, opening a connection, and managing the connection lifecycle.
