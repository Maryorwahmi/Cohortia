Cursor example

Create a cursor from the connection and use it to run SQL.

cursor = conn.cursor()
print("Cursor created successfully!")

# Run a simple query
cursor.execute('SELECT name, email FROM users')
rows = cursor.fetchall()
for row in rows:
  print(row)
Note
Use fetchone for a single record to avoid loading large result sets into memory.
Why it matters

The cursor is how Python communicates SQL intent. Proper use of fetch methods keeps your app efficient and predictable.

Key Takeaway

A cursor executes SQL and returns results; choose fetchone or fetchall based on expected result size.
