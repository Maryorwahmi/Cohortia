Module 04 › Chapter 4.2 › What is sqlite3?
sqlite3 module

A compact API included with Python that lets you open and operate on SQLite database files using standard SQL.

Core property
Serverless single-file storage with ACID transactions.
Concrete example
A desktop notes app keeping all records in notes.db for simple distribution and backup.
Misconception
It is not only for learning; it can be reliable for many production scenarios that suit single-file storage.
Key Takeaway

sqlite3 makes it easy to use SQL in Python without external servers; pick SQLite when you need a lightweight, transactional local store.
