Products schema

A table showing price, optional description, and a default stock quantity.

cursor.execute('''
    CREATE TABLE IF NOT EXISTS products (
        product_id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        description TEXT,
        price REAL NOT NULL,
        stock_quantity INTEGER DEFAULT 0
    )
''')
conn.commit()
Concrete example
Insert a product without stock_quantity and the schema will use 0 automatically.
Why it matters

Defaults reduce special-case handling in application code and keep data consistent across rows.

Key Takeaway

Use defaults and constraints to make your database enforce sensible rules so application logic is simpler and safer.
