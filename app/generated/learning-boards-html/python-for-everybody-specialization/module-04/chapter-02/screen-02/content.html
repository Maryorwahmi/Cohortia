Learning Objectives

Learn, understand, apply, and prepare to master SQLite with Python.

Bloom: Learn → Understand → Apply → Master
Verified Competency Milestones
01
Understand sqlite3
Know what sqlite3 provides as Python’s built-in database interface and why SQLite is a single-file engine suitable for small apps.
VERIFIED COMPETENCY MILESTONE
02
Open or create a DB file
Use sqlite3.connect with a filename to open an existing database or create a new file for local data storage.
VERIFIED COMPETENCY MILESTONE
03
Create and use a cursor
Create cursor objects from the connection to execute SQL and fetch query results in Python.
VERIFIED COMPETENCY MILESTONE
04
Create tables idempotently
Write CREATE TABLE IF NOT EXISTS statements and commit changes to persist schema updates safely across runs.
VERIFIED COMPETENCY MILESTONE
