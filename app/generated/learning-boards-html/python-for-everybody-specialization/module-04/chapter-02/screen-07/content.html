Module 04 › Chapter 4.2 › CREATE TABLE
Schema example

A users table with primary key and constraints to ensure valid data.

try:
    cursor.execute('''
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            email TEXT UNIQUE NOT NULL
        )
    ''')
    print("Table 'users' created or already exists.")
    conn.commit()
except sqlite3.Error as e:
    print(f"An error occurred: {e}")
finally:
    conn.close()
    print("Database connection closed.")
Tip
IF NOT EXISTS makes setup scripts safe to run repeatedly during development and tests.
Schema notes
  • Define primary keys to uniquely identify rows.
  • Use NOT NULL and UNIQUE to prevent invalid or duplicate entries.
  • Use DEFAULT for sensible automatic values where appropriate.
Key Takeaway

Write explicit CREATE TABLE statements, protect them with IF NOT EXISTS, and commit to persist schema changes.
