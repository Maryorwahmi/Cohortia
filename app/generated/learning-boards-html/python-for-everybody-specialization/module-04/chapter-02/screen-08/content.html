Complete example

This script shows the defensive pattern: initialize conn, connect, create cursor, run CREATE TABLE, commit, and close.

import sqlite3

conn = None # Initialize conn to None for error handling
try:
    conn = sqlite3.connect('my_first_database.db')
    cursor = conn.cursor()

    cursor.execute('''
        CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL,
            email TEXT UNIQUE NOT NULL
        )
    ''')
    print("Table 'users' created or already exists.")
    conn.commit()

except sqlite3.Error as e:
    print(f"An error occurred: {e}")
finally:
    if conn:
        conn.close()
        print("Database connection closed.")
Common mistake
Forgetting to initialize conn leads to errors when closing in finally if connection failed.
Practice
Run the script twice to confirm IF NOT EXISTS prevents errors on the second run.
