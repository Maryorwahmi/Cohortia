Transaction steps

A short sequence to remember when changing schema or data.

Step 1
Execute SQL
Run CREATE, INSERT, UPDATE, or DELETE via cursor.execute.
Step 2
Call conn.commit()
Persist staged changes to the database file so they survive closing.
Step 3
Close connection
Release locks and finalize the transaction with conn.close.
Common mistake

Skipping commit then inspecting the file elsewhere creates confusing missing-data errors.

Key Takeaway

Commit any changes you want to keep, then close the connection to avoid locks and ensure durability.
