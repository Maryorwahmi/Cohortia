Try / Except / Finally pattern

Use defensive initialization and finally to close the connection regardless of errors.

import sqlite3

conn = None
try:
    conn = sqlite3.connect('ecommerce.db')
    cursor = conn.cursor()
    # execute statements
    conn.commit()
except sqlite3.Error as e:
    print(f"Database error: {e}")
except Exception as e:
    print(f"General error: {e}")
finally:
    if conn:
        conn.close()
        print("Database connection closed.")
Tip
Initialize conn to None so finally can safely check and close it only when set.
Common failures
  • Permission errors when creating a file in a protected path.
  • SQL syntax mistakes causing sqlite3.Error exceptions.
  • Uncommitted changes lost when not calling commit.
Key Takeaway

Expect database operations to fail; catch sqlite3.Error and use finally to close connections to preserve integrity.
