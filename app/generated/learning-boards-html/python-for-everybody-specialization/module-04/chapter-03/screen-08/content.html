Module 4 › Chapter 4.3 › SELECT & Fetching
Code Examples
# Fetch all users
cursor.execute("SELECT id, name, email FROM users")
all_users = cursor.fetchall()
for user in all_users:
    print(f"ID: {user[0]}, Name: {user[1]}, Email: {user[2]}")

# Fetch a single user by id
cursor.execute("SELECT name, email FROM users WHERE id = ?", (1,))
single_user = cursor.fetchone()
if single_user:
    print(f"User with ID 1: Name={single_user[0]}, Email={single_user[1]}")

# Iterate cursor for large results
cursor.execute("SELECT name FROM users WHERE email LIKE '%example.com%'")
for row in cursor:
    print(f"Name: {row[0]}")
Behavior note

Calling fetchall consumes the remaining rows. After fetchall, fetchone returns None unless the query is re-executed.

Key Takeaway

Pick a retrieval method based on expected result size and re-run queries if you need different access patterns.
