Practice Plan
  1. Create table if not exists and inspect schema.
  2. Insert one row using parameter substitution and commit.
  3. Insert multiple rows with executemany and check rowcount.
  4. Query with WHERE, fetchone, fetchall, and iterate cursor.
  5. Handle IntegrityError and always close the connection.
Quick mnemonic
SAFE
  • S — Substitute parameters
  • A — Always commit
  • F — Fetch appropriately
  • E — Exit and close connections
