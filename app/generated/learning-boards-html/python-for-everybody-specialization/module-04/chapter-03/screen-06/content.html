Module 4 › Chapter 4.3 › executemany()
Example
new_users = [
    ("Charlie Chaplin", "charlie@example.com"),
    ("Diana Prince", "diana@example.com"),
    ("Eve Adams", "eve@example.com")
]
cursor.executemany("INSERT INTO users (name, email) VALUES (?, ?)", new_users)
print(f"Inserted {cursor.rowcount} new users.")
conn.commit()
Note: cursor.rowcount reports the number of rows affected by the last call. For executemany it reflects the batch size in many implementations.
Batching tips
  • Validate rows before inserting
  • Use reasonable batch sizes to avoid long transactions
  • Handle IntegrityError to identify problematic rows
Common mistake

Relying on implicit commits per row slows performance. Group inserts and call commit once per batch.
