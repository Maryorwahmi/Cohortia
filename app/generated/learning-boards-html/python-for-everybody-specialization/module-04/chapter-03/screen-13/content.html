Example: stream processing
cursor.execute("SELECT id, name, total_amount FROM Orders WHERE total_amount > ?", (100.0,))
for order in cursor:
    # Process one order at a time
    print(f"Order ID: {order[0]}, Amount: {order[2]}")
    # Possibly write to file, send to API, etc.
Iterating helps keep memory usage low. If you need to retry or paginate, control the query with LIMIT/OFFSET or re-execute with different parameters.
When to re-execute

If you need random access or multiple passes over the same results, fetch to a local structure or re-run the query.

Key Takeaway

Use cursor iteration for one-pass, memory-conscious processing of large query results.
