Module 4 › Chapter 4.3 › INSERT & Placeholders
Concept

Parameter substitution

Use question-mark placeholders and pass a tuple of values to cursor.execute. sqlite3 performs escaping and binding for you.

Example
import sqlite3

conn = sqlite3.connect('my_first_database.db')
cursor = conn.cursor()

cursor.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT NOT NULL, email TEXT UNIQUE NOT NULL)")
user_name = "Alice Wonderland"
user_email = "alice@example.com"
cursor.execute("INSERT INTO users (name, email) VALUES (?, ?)", (user_name, user_email))
conn.commit()
conn.close()
Why it matters

Using placeholders prevents malicious input from becoming executable SQL. It also standardizes how values are passed, simplifying error handling and portability.

Common misconception

Some think placeholders are only necessary for web inputs. In fact, they are best practice for all dynamic data, including API responses and file contents.

Key Takeaway

Always bind values with placeholders. This is the simplest and most effective defense against SQL injection.
