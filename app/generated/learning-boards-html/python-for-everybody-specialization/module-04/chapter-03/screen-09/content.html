Example: Exact Match
cursor.execute("SELECT name, email FROM users WHERE email = ?", (user_email,))
result = cursor.fetchone()
if result:
    print(f"Found: {result[0]} - {result[1]}")
else:
    print("Not found")
Example: Pattern Match
pattern = "%example.com%"
cursor.execute("SELECT name FROM users WHERE email LIKE ?", (pattern,))
for row in cursor:
    print(row[0])
Common Mistake

Do not concatenate wildcard patterns into SQL strings. Build the pattern in Python and bind it with placeholders.
