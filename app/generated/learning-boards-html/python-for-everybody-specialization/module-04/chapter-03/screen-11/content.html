Module 4 › Chapter 4.3 › Common Mistakes
Forget Commit

If you don't call conn.commit(), inserted rows will not be saved to disk. Commit after logical units of work.

Fetch Ordering

fetchall consumes all rows. Don't expect fetchone to return the same rows after fetchall unless you re-execute the query.

Open Connections

Leaving connections open causes resource leaks and possible locks. Use finally to close or context managers when appropriate.

IntegrityError

Unique constraint violations raise sqlite3.IntegrityError. Catch it to provide a clear response rather than crashing the app.

Assuming IDs

Don't assume row ids start at 1 in every DB. Prefer retrieving the last inserted id or querying by unique fields.

Manual Escaping

Trying to manually escape inputs is fragile. Use parameter substitution instead of DIY escaping.
