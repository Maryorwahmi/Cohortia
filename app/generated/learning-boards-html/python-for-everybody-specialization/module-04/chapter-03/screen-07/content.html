Module 4 › Chapter 4.3 › Safe vs Unsafe
Unsafe (vulnerable)
# DO NOT DO THIS
user_input = "'; DROP TABLE users; --"
sql = "INSERT INTO users (name, email) VALUES ('" + user_input + "', 'x@example.com')"
cursor.execute(sql)

This concatenation treats input as SQL. The malicious fragment could terminate the VALUES list and execute arbitrary commands.

Safe (parameterized)
# Safe binding
user_input = "'; DROP TABLE users; --"
cursor.execute("INSERT INTO users (name, email) VALUES (?, ?)", (user_input, 'x@example.com'))

Here the input is treated as data. The database stores the literal string rather than executing it.

Quick Tip

Always prefer parameter binding to manual escaping. It is simpler and more reliable across drivers.
