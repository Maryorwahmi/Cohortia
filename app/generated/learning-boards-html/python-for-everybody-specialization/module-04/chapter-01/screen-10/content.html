INSERT INTO Examples

These inserts populate the Students table from the chapter. Observe values align with column types.

INSERT INTO Students (name, age, grade) VALUES ('Alice Smith', 20, 3.8);
INSERT INTO Students (name, age, grade) VALUES ('Bob Johnson', 22, 3.5);
INSERT INTO Students (name, age, grade) VALUES ('Charlie Brown', 19, 4.0);
After inserting, run SELECT queries to confirm data and to practice filtering and sorting.
Practical notes
  • Match data types: integers into INTEGER, decimals into REAL, strings into TEXT.
  • Omit AUTOINCREMENT primary key values to let the database assign them.
  • Handle constraint violations in your application code to avoid crashes.
