CREATE TABLE Walkthrough

This SQL defines the Students table with types and constraints. Read it and consider which columns should be NOT NULL in your own design.

CREATE TABLE Students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age INTEGER,
    grade REAL
);
Note: AUTOINCREMENT assigns ids so inserts don't need an explicit id value.
Type guidance
  • INTEGER: whole numbers and ids.
  • TEXT: strings, names, descriptions.
  • REAL: decimal values like grades or prices.
  • BLOB: binary data such as images or files.
Common pitfall
Using TEXT for numeric fields prevents numeric queries and calculations.
