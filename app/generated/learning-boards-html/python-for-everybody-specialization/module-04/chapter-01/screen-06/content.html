Core Concept

Primary Keys

A primary key uniquely identifies each row. Use it to reference rows reliably across operations and tables.

Students example
id INTEGER PRIMARY KEY AUTOINCREMENT ensures each student gets a unique numeric id assigned by the database.
Design question
Choose surrogate ids when natural keys are unreliable or may change over time.
Implication
Primary keys enable efficient lookup and form the target for foreign keys that connect tables.
Pro tip
Prefer small integer keys for joins; use UNIQUE constraints or UNIQUE columns when natural uniqueness is required.
Common mistake
Using mutable fields like email or name as the primary key can cause problems when those values change.
Key Takeaway

Pick a stable, unique primary key so your rows are always addressable and safe to reference from other tables.
