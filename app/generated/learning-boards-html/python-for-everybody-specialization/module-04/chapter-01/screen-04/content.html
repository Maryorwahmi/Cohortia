Core Concept

What is a Database and an RDBMS?

A database stores persistent structured information. An RDBMS organizes that data into tables and enforces relationships and constraints.

Example
An e-commerce site uses Users, Products, and Orders tables rather than repeating product details in every order.
Why it matters
Persistence keeps data between program runs and enables efficient, reliable queries for reporting and features.
Common mistake
Assuming databases are only for huge systems; lightweight RDBMS like SQLite are excellent for small apps and testing.
Key Takeaway

Use an RDBMS when you need durable, structured storage and the ability to express relationships between datasets.

Analogy: digital filing cabinet
Folders are tables, sheets inside are rows, and columns label attributes like name or price. Queries let you pull only the files you need.
Table
Collection of related records (e.g., Students).
Row
Single record representing one entity (e.g., one student).
Column
Attribute of a record (e.g., name, age, grade).
Query
A precise request to retrieve or change data using SQL.
