Foreign Keys and Relationships

Foreign keys refer to primary keys in other tables, forming relationships and preventing orphaned references.

Enrollments example
Enrollments(student_id, course_id, grade) links Students.id to Courses.course_id using foreign keys.
Design choice
Decide cascade actions: delete child records when a parent is removed, or prevent deletion to preserve history.
Join table pattern
Use a simple linking table for many-to-many relationships. It keeps each table focused on its entity and avoids redundancy.
Concrete benefit
Referential integrity guarantees that an enrollment always points to existing student and course records.
Misconception
Copying data between tables for speed often causes inconsistent updates and harder maintenance.
