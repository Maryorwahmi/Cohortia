What to Remember

Three short reminders to guide your next designs.

Define schemas first
Clear column names and types make data predictable and queries reliable.
Use keys for links
Primary and foreign keys model relationships and enable safe joins.
Let DB enforce rules
Constraints reduce application complexity and protect data across clients.
