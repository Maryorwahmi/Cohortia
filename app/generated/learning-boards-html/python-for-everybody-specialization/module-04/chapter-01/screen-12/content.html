Design & Create: Books Table

Use a book_id for stability, TEXT for title and author, INTEGER for publication year, and REAL for price. Make title and author NOT NULL.

CREATE TABLE Books (
    book_id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    author TEXT NOT NULL,
    publication_year INTEGER,
    isbn TEXT UNIQUE,
    genre TEXT,
    price REAL
);

Design checklist
  • List required columns and mark them NOT NULL.
  • Decide a stable primary key strategy.
  • Use UNIQUE for ISBN when available to prevent duplicates.
  • Test INSERTs and SELECTs to confirm expected behavior.
