Definition

Tables, Rows, and Columns

Columns define what type of data a field can hold. Rows are the actual entries. Together they structure the dataset.

Example: Students table
Columns: id, name, age, grade. Rows: Alice, Bob, Charlie each with values for those columns.
Design tip
Keep each column focused on a single attribute. Avoid packing multiple pieces of data into one column.
Visual sample
Students
id | name | age | grade
1 | Alice Smith | 20 | 3.8
2 | Bob Johnson | 22 | 3.5
3 | Charlie Brown | 19 | 4.0
Why this helps
Consistent column types let you run numeric calculations and filters efficiently.
Mistake to avoid
Storing numeric data as text prevents range queries and math operations.
