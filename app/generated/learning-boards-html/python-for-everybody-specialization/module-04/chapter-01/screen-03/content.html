Learning Objectives — Practice

These objectives prepare you to design tables, insert records, and enforce integrity across related tables.

Design tables with constraints
Decide when a column should be NOT NULL, UNIQUE, or have a default, to prevent incomplete or duplicate data.
VERIFIED COMPETENCY MILESTONE
Insert and rely on AUTOINCREMENT
Let the database assign primary key values to avoid collision and simplify code.
VERIFIED COMPETENCY MILESTONE
Link tables using foreign keys
Use foreign keys in join tables, such as Enrollments, to relate students and courses safely.
VERIFIED COMPETENCY MILESTONE
Choose data types correctly
Select INTEGER for counts and IDs, REAL for decimals, TEXT for strings, and BLOB for binary data like images.
