SQL: Purpose and Declarative Style

Write what you want, not how to get it. Let the database engine decide the best execution plan.

DDL vs DML
CREATE TABLE is DDL. INSERT INTO is DML. Use both to define structure and change data.
Example
CREATE TABLE Students(...) then INSERT INTO Students(name, age, grade) VALUES(...).
Why declarative matters
Declarative queries are concise and allow databases to use indexes and optimizers to be fast even on large datasets.
Practice prompt
Try writing a SELECT that returns names of students with grade > 3.5 and think how the database finds matching rows.
