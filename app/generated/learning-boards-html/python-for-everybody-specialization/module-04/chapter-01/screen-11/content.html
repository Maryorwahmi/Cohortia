Data Types: Choose Carefully

INTEGER
Ids and whole numbers used in calculations or indexing.
REAL
Floating point decimals like grades or prices.
TEXT
Strings such as names and ISBNs that may include non-numeric characters.
BLOB
Binary data like images or file contents.
Mistakes and clarifications
  • Storing numbers as TEXT prevents numeric filters and arithmetic.
  • Not using NOT NULL for required fields allows incomplete records.
  • Choosing BLOB for media keeps large binary data out of TEXT fields.
Design prompt
For each column ask: will I sort, compute, or pattern-match this field? Let that decide the type.
