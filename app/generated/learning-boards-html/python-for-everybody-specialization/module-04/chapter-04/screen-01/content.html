Updating, Deleting, and Practical Database Operations
How to change data safely, undo failures, and import web data into SQLite
Interactive 16:9 Masterclass
Why this chapter

Databases change over time. You will learn the SQL and Python patterns to update and remove rows safely, and to make those changes reversible when something goes wrong.

Scope

UPDATE, DELETE, WHERE, transactions, rollback, INSERT OR IGNORE, and integrating JSON from web APIs into local tables.

Visual concept
Table (before)
id | name | email
1 | Alice | alice@example.com
2 | Bob | bob@example.com
3 | DeleteMe | delete@example.com
→
Table (after)
id | name | email
1 | Alice | alice.new@example.com
2 | Bob | bob@example.com
Always use WHERE
In this lesson
  • UPDATE and DELETE syntax and safety checks
  • Parameter substitution and cursor.rowcount
  • Transaction patterns: commit and rollback
  • Fetch JSON from an API and insert with INSERT OR IGNORE
