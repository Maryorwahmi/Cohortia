What UPDATE does

UPDATE assigns new values to one or more columns in rows that match a WHERE condition. Use placeholders to pass values safely from Python.

Example code
import sqlite3

conn = sqlite3.connect('my_first_database.db')
cursor = conn.cursor()

new_email = 'alice.new@example.com'
user_id = 1
cursor.execute("UPDATE users SET email = ? WHERE id = ?", (new_email, user_id))
print(f"Rows affected: {cursor.rowcount}")
conn.commit()
conn.close()
Key points
  • Use parameter substitution (placeholders) to avoid injection.
  • Multiple columns can be updated in a single UPDATE statement.
  • cursor.rowcount reveals how many rows changed; verify with SELECT.
Example scenario
You need to change a single customer's email after they update it on a profile page. Use an UPDATE with WHERE id = ? and parameter substitution to change only that row and then select it back to confirm.
Key Takeaway

UPDATE is powerful; always specify WHERE and use parameter placeholders, then check rowcount before committing.
