Module 5 › Chapter 4.4 › Checklist
1. Confirm WHERE
Preview rows with SELECT and ensure the WHERE condition matches only intended rows.
2. Parameterize queries
Use placeholders and pass values as tuples to avoid injection and quoting issues.
3. Use transactions
Group related writes, commit on success, and rollback on error.
4. Verify changes
Check cursor.rowcount and run a SELECT as confirmation before commit.
5. Handle duplicates
Use INSERT OR IGNORE for idempotent imports; choose REPLACE only when safe.
6. Test first
Run scripts against a copy of the database when possible and keep backups.
Final question

Before committing a destructive change, what three checks will you perform to ensure it targets only the intended rows?
