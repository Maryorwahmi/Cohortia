Module 5 › Chapter 4.4 › WHERE Clause Safety
The problem

Without WHERE, UPDATE and DELETE act on the entire table. This can overwrite or remove all records and is nearly always unintended.

Warning
If you see statements like UPDATE table SET ... with no WHERE, stop and run a SELECT with the same condition that you plan to use.
Quick verification steps
  • Run SELECT id FROM table WHERE to preview rows.
  • Execute UPDATE/DELETE but delay commit; inspect cursor.rowcount.
  • If counts match expectations, call conn.commit(); otherwise conn.rollback().
Analogy
Think of WHERE as the address that points the database to a single house. Without it, you're renovating the whole street when you only meant to update one home.
Common mistake

Forgetting WHERE during quick edits or copy-paste is the most frequent cause of unintended mass changes.
