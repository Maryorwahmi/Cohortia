Transaction pattern
  1. Begin operations (sqlite opens a transaction implicitly).
  2. Execute multiple INSERT/UPDATE/DELETE statements.
  3. If all succeed, call conn.commit().
  4. If an exception occurs, call conn.rollback() in except block.
Example flow
Insert two temporary users, simulate an error, then rollback so neither user remains in the database.
try:
  cursor.execute("INSERT INTO users (name,email) VALUES (?,?)", (...))
  cursor.execute("INSERT INTO users (name,email) VALUES (?,?)", (...))
  # Simulate or catch an error
  conn.commit()
except Exception as e:
  conn.rollback()
Pro tip

Only commit when a logical unit of work is complete. Use rollback in the except branch to keep the database consistent.
