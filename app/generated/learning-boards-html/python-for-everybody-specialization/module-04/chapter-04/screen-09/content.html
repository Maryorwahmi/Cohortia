Module 5 › Chapter 4.4 › Verification
Use rowcount

Immediately after an execute call, inspect cursor.rowcount to see how many rows changed. It offers a fast sanity check.

Example
cursor.execute('UPDATE Orders SET total_amount = ? WHERE order_id = ?', (new_total, order_id)) print(cursor.rowcount) # Expect 1
Follow-up SELECT
After rowcount confirms an effect, run a SELECT with the same WHERE to verify the exact values now stored in the row.
Check your assumptions

If rowcount differs from expectation, do not commit. Inspect the WHERE logic and the data, then rollback if needed.
