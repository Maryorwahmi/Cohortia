Module 5 › Chapter 4.4 › INSERT OR IGNORE
When to use IGNORE

Use IGNORE when importing data where duplicates are expected and you prefer to keep existing rows untouched instead of failing the entire operation.

Caveat
You still need to check how many rows inserted and whether skipped rows require separate handling.
cursor.executemany(
  "INSERT OR IGNORE INTO api_users (id,name,username,email,phone,website) VALUES (?,?,?,?,?,?)",
  users_to_insert
)
print('Rows affected:', cursor.rowcount)
conn.commit()
Decision

Choose IGNORE for idempotent imports; choose REPLACE only when you want to overwrite existing rows and accept the side effects.
