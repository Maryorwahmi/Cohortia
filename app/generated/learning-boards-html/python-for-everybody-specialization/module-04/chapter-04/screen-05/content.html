Module 5 › Chapter 4.4 › Parameter Substitution
Step-by-step: safe execution
  1. Write SQL with ? placeholders for each dynamic value.
  2. Build a tuple or list of Python values in the same order.
  3. Call cursor.execute(sql, params) or cursor.executemany for many rows.
  4. Check cursor.rowcount and run a verification SELECT before commit.
  5. Call conn.commit() when results match expectations; else conn.rollback().
Code pattern
sql = "UPDATE users SET name = ?, email = ? WHERE id = ?"
params = (new_name, new_email, user_id)
cursor.execute(sql, params)
print('Rows affected:', cursor.rowcount)
Misconception check
Do not build SQL strings by concatenating user input. Even a seemingly simple string replacement can allow an attacker to change your SQL logic.
