  1. Update customer email with UPDATE Customers SET email = ? WHERE customer_id = ? and commit after verifying rowcount.

Key Takeaway

Work incrementally: execute, inspect rowcount, SELECT to confirm, then commit. Use rollback in except blocks to preserve the original state when errors occur.
