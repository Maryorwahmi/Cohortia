Module 5 › Chapter 4.4 › DELETE
Scoped delete
DELETE FROM table WHERE id = ? removes only one row when the condition matches a single id. Verify with SELECT afterward.
Example
cursor.execute('DELETE FROM users WHERE id = ?', (3,)) cursor.execute('SELECT * FROM users WHERE id = ?', (3,)) # Expect no rows returned
Full-table delete
DELETE FROM table_name; removes all rows. Treat this as a destructive operation and protect it behind backups and confirmation steps.
Misconception
Some users assume full deletes are easily reversible; without a transaction or backup, they are permanent once committed.
Key Takeaway

DELETE is simple but destructive. Always scope deletions and use transactions to allow rollback if an error occurs.
