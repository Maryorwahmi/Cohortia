Catch URLError
Handle unreachable hosts and DNS failures
Pattern
import urllib.request
import urllib.error

try:
  with urllib.request.urlopen(url) as resp:
    text = resp.read().decode('utf-8')
except urllib.error.URLError as e:
  print(f"Error accessing URL: {e.reason}")
except Exception as e:
  print("An unexpected error occurred")
  • Catch URLError to handle network-level failures clearly.
  • Log technical details separately while showing a user-friendly message.
  • Reserve a general except block for unexpected issues and debugging only.
Example scenario
If a domain does not exist, URLError will be raised. Your program can catch it and say the host is unreachable rather than crashing.
Common mistake

Catching all exceptions and ignoring them hides real bugs. Handle URLError explicitly and then decide how to handle other exceptions.
