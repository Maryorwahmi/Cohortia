URL & HTTP
URL points to a resource; HTTP carries the request and response as bytes.
urlopen & read
urlopen returns a file-like object. read() returns bytes from the network.
Decode before processing
Use UTF-8 to convert bytes to strings before using string methods.
Summary

These three rules — know the URL/HTTP model, treat network output as bytes, and decode text with UTF-8 — are the core habits to build reliable web data code.
