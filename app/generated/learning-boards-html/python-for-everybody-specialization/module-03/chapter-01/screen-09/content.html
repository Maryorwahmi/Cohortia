Module 3 › Chapter 3.1 › Text vs Binary
Textual content
Decode with UTF-8 and parse
Examples include plain text, HTML and JSON. After decoding you can split, search, or use JSON parsing to work with the content.
Binary content
Keep as bytes and save to a file
Examples include images and compressed archives. Write bytes to a binary file and avoid decoding to prevent corruption.
Practical check
If headers indicate text or you know the URL returns text, decode. Otherwise keep bytes.
Mistake
Decoding image bytes will result in errors or corrupted output when saved.
Tip
When in doubt, inspect the first few bytes or check content-type headers before decoding.
