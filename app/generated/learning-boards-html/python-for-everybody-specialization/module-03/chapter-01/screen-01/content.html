Retrieving Data with urllib
Open URLs, handle bytes, and decode to strings for further processing

You will fetch text from small web resources, decode raw bytes into Unicode strings using UTF-8, and add simple error handling to keep programs resilient. The practice focus is reading, decoding, and processing text-based content retrieved via HTTP.
