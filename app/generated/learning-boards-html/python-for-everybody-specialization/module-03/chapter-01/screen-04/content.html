Module 3 › Chapter 3.1 › URL & HTTP
Definition and analogy
URL as address, HTTP as delivery
A URL encodes the location of a web resource. HTTP defines how clients request a resource and how servers respond. The response body is a sequence of bytes; the interpretation of those bytes depends on the content type and encoding.
Analogy
Address on an envelope: URL names where to send the request; HTTP is the postal service that delivers a response back.
Concrete example
Requesting a small text file URL returns bytes that, when decoded with UTF-8, yield readable text you can print or parse.
Common misconception
Not all URLs return text. Attempting to decode binary data as text will fail or corrupt the data.
Quick checklist
  • Confirm the URL is well-formed before requesting.
  • Inspect response headers when available to learn content type.
  • Decide whether to decode or to save as raw bytes.
Key Takeaway

Treat the response as bytes first; only decode to text when you know the content is textual and you have the correct encoding.
