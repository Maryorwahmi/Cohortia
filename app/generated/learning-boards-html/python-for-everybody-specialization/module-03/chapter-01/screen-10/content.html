Example code
Follow these steps to observe bytes then strings
import urllib.request
import urllib.error

url = "http://data.pr4e.org/romeo.txt"
try:
  with urllib.request.urlopen(url) as webpage:
    data_bytes = webpage.read()
    print(type(data_bytes))  # shows bytes
    data_string = data_bytes.decode('utf-8')
    print(type(data_string)) # shows str
    print(data_string)
except urllib.error.URLError as e:
  print(f"Error accessing URL: {e.reason}")
  • Observe the printed types to see the conversion from bytes to string.
  • Decode explicitly; do not rely on implicit conversion.
  • Handle URLError to ensure graceful failure when the host is unreachable.
Result expectation
You should see the type bytes, then str, and then the text content printed to the console.
Key Takeaway

Checking types before and after decoding is a quick way to verify you handled bytes and strings correctly.
