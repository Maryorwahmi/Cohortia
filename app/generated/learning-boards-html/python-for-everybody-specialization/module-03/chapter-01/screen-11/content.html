Step-by-step
A simple pipeline to practice fetching and decoding
  1. Import urllib.request and urllib.error.
  2. Wrap urlopen in try-except and catch URLError.
  3. Read bytes with read() and decode with UTF-8.
  4. Split the decoded string with split() to get words.
  5. Count words using a dictionary and sort by frequency.
