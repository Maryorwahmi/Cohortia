Learning Objectives
Targeted outcomes and why each is useful
01
URLs & HTTP
Identify resources and the request-response model
Recognize that a URL points to a resource and HTTP governs access; this matters because every remote read begins with those concepts.
VERIFIED COMPETENCY MILESTONE
02
urllib.request
Open and read URL resources in Python
Using urlopen returns a file-like object. This makes web data accessible with familiar read patterns from local files.
VERIFIED COMPETENCY MILESTONE
03
Bytes → Decode
Convert bytes into strings using UTF-8
Network responses arrive as bytes. Decoding is necessary before string operations; forgetting it is a common source of bugs.
VERIFIED COMPETENCY MILESTONE
04
Error handling
Catch URLError and handle unreachable hosts
Wrap network calls in try-except to provide helpful messages or retries instead of crashing the program.
VERIFIED COMPETENCY MILESTONE
Bloom's progression
Learn → Understand → Apply → Master
Mnemonic
Think: URL names the resource, urllib opens it, decode converts it, errors tell you when it fails.
Quick tip
If a response contains non-text data, keep it as bytes and save to a file instead of decoding.
