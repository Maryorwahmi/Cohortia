Code walkthrough
Open, read, and decode a remote text file
Example code
import urllib.request

url = "http://data.pr4e.org/romeo.txt"
with urllib.request.urlopen(url) as response:
  data_bytes = response.read()
  data_string = data_bytes.decode('utf-8')
  print(data_string)
  • Use the with statement so the connection closes automatically even if errors occur.
  • read returns bytes; decode to get a string for printing and parsing.
  • If you expect binary content, do not call decode; instead write bytes to a file.
Example result
The printed content will be the human-readable text contained in the remote file once decoded.
Key Takeaway

Treat response.read() as bytes. Decoding makes the content usable as a Python string.
