Module 3 › Chapter 3.1 › Bytes vs Strings
Bytes (raw)
Raw octets suitable for binary data
Use bytes when working with images, compressed files, or raw network streams. Do not attempt string operations on bytes; instead decode when you need text.
Check
# After read()
# type(value) is bytes
Strings (decoded)
Unicode text for printing and parsing
Decode bytes using UTF-8 to obtain a string suitable for split, find, and other text operations. Always verify encoding if you see weird characters.
Check
# After decode('utf-8')
# type(value) is str
Example
Read bytes from a remote text file, decode, then split into words to count frequencies.
Mistake
Calling split on bytes or concatenating bytes with strings leads to type errors.
Tip
Use type checks or print the type to confirm whether you have bytes or a string before processing.
