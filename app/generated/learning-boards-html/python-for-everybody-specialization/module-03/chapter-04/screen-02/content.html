Learning Objectives
Bloom bar: Learn → Understand → Apply → Master
01. Define JSON

Explain JSON as a lightweight, language-independent format. Knowing this helps you choose the right parser and expectations for structure.

VERIFIED COMPETENCY MILESTONE
02. Map to Python

Translate JSON objects to dicts and arrays to lists so you can work with data using familiar Python operations.

VERIFIED COMPETENCY MILESTONE
03. Parse & Access

Use json.loads to parse and then chain key and index lookups to reach nested values while avoiding KeyError.

VERIFIED COMPETENCY MILESTONE
04. Serialize

Use json.dumps to produce JSON text suitable for APIs or files and use indent for human-readable output.
