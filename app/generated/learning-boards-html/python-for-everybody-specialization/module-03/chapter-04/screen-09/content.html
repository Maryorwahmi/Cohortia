Module 4 › Chapter 3.4 › json.dumps()
Code example
import json

users_list = [
  {'id':1, 'name':'Alice'},
  {'id':2, 'name':'Bob'}
]

new_user = {'id':3, 'name':'Charlie'}
users_list.append(new_user)

json_text = json.dumps(users_list, indent=2)
print(json_text)
Notes
  • json.dumps returns a string; use json.dump to write to a file object.
  • Provide indent for readable output during development.
  • Convert non-serializable types to strings before calling dumps.
Misconception: Using dumps on very large data can be memory intensive; stream to a file when needed.
