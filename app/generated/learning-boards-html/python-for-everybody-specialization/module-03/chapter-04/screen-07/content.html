Module 4 › Chapter 3.4 › json.loads()
Code example
import json

data = '''[
  {'id':1, 'name':'Alice', 'email':{'address':'alice@example.com'}}
]'''

users_list = json.loads(data)
print(type(users_list))          # expected: list
print(len(users_list))
print(type(users_list[0]))       # expected: dict
print(users_list[0]['name'])
Explanation & tips
  • json.loads expects a text string; decode bytes first when fetching from the web.
  • Top-level arrays return lists; objects return dicts.
  • Wrap loads in try/except to catch JSONDecodeError for malformed input.
Misconception: json.load and json.loads differ — loads parses strings, load reads file objects.
