Module 4 › Chapter 3.4 › Nested Access
Examples
# direct indexing (may raise KeyError)
email_addr = user['email']['address']

# safe chaining with defaults
email_addr = user.get('email', {}).get('address', 'No email')

# check type before nested access
if isinstance(user.get('email'), dict):
  email_addr = user['email'].get('address', 'No email')
When to use which
  • Use direct indexing when structure is guaranteed by your API or prior validation.
  • Use .get chaining in exploratory code or when the input may be incomplete.
  • Always supply sensible defaults so downstream logic can continue.
Pro tip: Centralize defensive access in a helper function to keep processing loops clean.
