JSON Object
Collection of name/value pairs — Python dict
{
  'id': 1,
  'name': 'Alice Smith',
  'email': {'type': 'personal', 'address': 'alice@example.com'}
}
JSON Array
Ordered list of values — Python list
[
  {'id':1, 'name':'Alice'},
  {'id':2, 'name':'Bob'}
]
Every API
Most API responses are nested objects and arrays; practice recognizing tokens while scanning.
Misconception
Keys are not attributes; they are string labels you use to look up values in a dict.
Why it matters
Mapping shapes quickly to Python types speeds development and reduces parsing errors.
