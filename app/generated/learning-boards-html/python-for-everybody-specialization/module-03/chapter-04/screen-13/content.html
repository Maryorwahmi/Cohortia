Module 4 › Chapter 3.4 › Serialization
Serialization example
import json

user = {'id':3, 'name':'Charlie', 'joined':'2020-01-01'}
json_text = json.dumps(user, indent=2)
print(json_text)
Deserialization example
import json

json_text = '''{'id':3, 'name':'Charlie'}'''
obj = json.loads(json_text)
print(type(obj))  # dict
Practical caution
Convert non-primitive types before serializing and validate the deserialized structure before trusting keys and types.
