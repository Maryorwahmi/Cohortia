Exercise template
import urllib.request
import json

url = 'http://py4e-data.dr-chuck.net/comments_42.json'
with urllib.request.urlopen(url) as response:
  data_bytes = response.read()
  data_string = data_bytes.decode('utf-8')
info = json.loads(data_string)
comments = info.get('comments', [])

total_count = 0
for item in comments:
  name = item.get('name')
  count = int(item.get('count', 0))
  print(f'Name: {name}, Count: {count}')
  total_count += count

print(f'Total sum of counts: {total_count}')
Hints & checks
  • Use .get with a default to handle missing keys safely.
  • Convert count to int to be sure arithmetic works as expected.
  • Print a summary count to verify results against expectations.
Common mistake: forgetting to decode bytes or using item['count'] without confirming the key exists.
