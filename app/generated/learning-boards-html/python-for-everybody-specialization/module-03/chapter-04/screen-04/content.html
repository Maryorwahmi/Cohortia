Module 4 › Chapter 3.4 › JSON vs XML
JSON
Compact, maps to native structures
  • Objects are name/value pairs — Python dicts.
  • Arrays are ordered lists — Python lists.
  • No closing tags; less verbose and quicker to read.
Use case: REST APIs returning records and lists.
XML
Verbose, flexible, schema-capable
  • Elements and attributes allow mixed content.
  • Often requires schema or XSLT for validation and transformation.
  • Good for document-centric structures rather than simple records.
When to use: legacy APIs or document markup that needs schemas.
Concrete example
A JSON user array is shorter and maps directly to a Python list of dicts; XML needs many closing tags and parsing into similar structures is more work.
Common mistake
Assuming XML is better for every structured exchange; often it's overkill for record-based APIs.
Key takeaway
Choose JSON for most API data; use XML when schema and mixed content are required.
