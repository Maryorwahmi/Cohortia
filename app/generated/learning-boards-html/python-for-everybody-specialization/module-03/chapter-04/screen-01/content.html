Web Services and JSON
Interactive 16:9 Masterclass — learn to parse, inspect, and produce JSON in Python

JSON is the lightweight format that modern web APIs return. This lesson shows how JSON represents objects and arrays, how Python's json module converts JSON into dictionaries and lists, and how you safely extract nested data for real programs.
