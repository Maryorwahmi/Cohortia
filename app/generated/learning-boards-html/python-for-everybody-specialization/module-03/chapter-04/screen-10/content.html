Module 4 › Chapter 3.4 › Fetch & Decode
Starter template
import urllib.request
import json

url = 'http://py4e-data.dr-chuck.net/comments_42.json'
with urllib.request.urlopen(url) as response:
  data_bytes = response.read()
  data_string = data_bytes.decode('utf-8')

info = json.loads(data_string)
# validate
comments = info.get('comments', [])
print(f'Retrieved {len(comments)} comments.')
Practical notes
  • Always decode bytes to UTF-8 before parsing.
  • Validate that expected top-level keys exist before iterating.
  • Catch URLError for network problems and JSONDecodeError for bad payloads.
Real-world connection: APIs may change shape; validate keys each time you fetch.
