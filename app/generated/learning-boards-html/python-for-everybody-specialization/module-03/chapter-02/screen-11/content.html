ID, class, and attribute selection

Use IDs for uniqueness, class_ for shared styles, and attribute dictionaries for custom filters.
# By id
item = soup.find(id='main-content')

# By class
paragraphs = soup.find_all('p', class_='section-text')

# By attribute
links = soup.find_all('a', href='/contact')

# Narrow by container
main = soup.find(id='main-content')
if main:
  contact_links = main.find_all('a')
Practical test
Try selectors in the console or a small script across multiple pages to confirm they select consistent targets.
Common mistake
Targeting visual classes used for layout rather than semantic markers; these classes change frequently with CSS updates.
Key Takeaway

Pick selectors that reflect content structure, not presentation. Narrow searches by context when needed.
