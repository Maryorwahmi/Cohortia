Tolerating imperfect pages

Design scripts to handle missing attributes and malformed markup gracefully.
Defensive code pattern
link = item.find('a')
if link is None:
  continue
href = link.get('href')  # safe access
if href:
  process(href)
  • Check for None before accessing methods or attributes.
  • Use get to read attributes and provide defaults when appropriate.
  • Log unexpected counts to detect structural changes early.
Parser choice
Try html.parser first; install lxml if HTML is messy or you need speed.
Debugging tip
Print parts of the parse tree or node contents to verify your selectors return the expected nodes before extracting attributes.
Key Takeaway

Expect imperfect HTML. Use tolerant parsers and defensive code to build resilient scrapers.
