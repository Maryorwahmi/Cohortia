Module 3 › Chapter 3.2 › Scrape Movie List

Task steps

  1. Fetch the HTML from the provided URL and decode it to a string.
  2. Create a BeautifulSoup object with 'html.parser' or 'lxml' as available.
  3. Find all <li> tags and for each one call find('a').
  4. If the anchor exists, read anchor.get_text() and anchor.get('href') and print them.
  5. Handle missing anchors or missing href values defensively by skipping or logging.
# Template snippet
movies = soup.find_all('li')
for item in movies:
  link = item.find('a')
  if link:
    title = link.get_text()
    url = link.get('href')
    print(f"Title: {title}, URL: {url}")
Practical tip
If URLs are relative, combine with the page's base URL to form absolute links for downstream use.
Common mistake
Assuming every li has an anchor; check and skip when absent to avoid attribute errors.
Key Takeaway

Follow fetch → parse → extract, and add defensive checks for missing elements or attributes.
