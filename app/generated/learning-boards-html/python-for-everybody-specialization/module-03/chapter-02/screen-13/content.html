Module 3 › Chapter 3.2 › Inspecting Pages

Find stable targets

Developer tools reveal page structure and help you pick selectors that survive layout changes.

Look for IDs
IDs are usually unique. Prefer them when present.
Container elements
Find the parent grouping element and search within it to narrow results.
Dynamic content check
If content is injected by JavaScript, a simple HTTP GET may not include it—inspect the raw response to confirm.
Key Takeaway

Inspect with dev tools, prefer structural selectors, and verify in a small script before scaling up.
