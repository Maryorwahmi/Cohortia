Core Concept

Tags, attributes, and the DOM tree

Elements are nodes; attributes hold data. Treat the document as a tree for dependable traversal.

  • Tags define elements such as <p>, <a>, <div>.
  • Attributes like id and class provide hooks to find elements.
  • Parents contain children; siblings share a parent—use these relationships to navigate.
Key Takeaway

Design extraction logic around DOM relationships rather than text patterns.

Annotated example
<ul class="movies"> <li><a href="/m1">Movie A</a></li> <li><a href="/m2">Movie B</a></li> </ul> This structure shows a parent <ul> with child <li> elements, each containing an <a> tag whose href is the actual URL.
Extraction plan
Find the <ul>, iterate its <li> children, then read each <a>'s href attribute.
Common mistake
Searching the raw HTML string for 'href' produces false matches outside desired list items.
