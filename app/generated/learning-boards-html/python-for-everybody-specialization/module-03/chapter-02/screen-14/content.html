Common mistakes and quick fixes

  • Use class_ instead of class when filtering by class.
  • Ensure the parser you name is installed on your system.
  • Print counts and node repr to verify selectors return expected nodes.
  • Use get('attr') and None checks for attributes to avoid exceptions.
Debug checklist
1) Confirm HTML contains the expected markup. 2) Print find_all counts. 3) Inspect repr of a sample node.
Key Takeaway

Small defensive checks and printing intermediate values are the fastest path to fixing broken scrapers.
