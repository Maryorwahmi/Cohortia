Methods to get text and attributes

# Text extraction
para = soup.find('p')
print(para.get_text())  # returns text from the element and children

# When element wraps plain text
span = soup.find('span', class_='course-title')
print(span.string)  # works only when span contains a single text node

# Attribute extraction
link = soup.find('a')
href = link.get('href')
print(href)
  • get_text() strips tags and returns combined visible text.
  • .string is fragile when elements have nested tags.
  • Use get('attr') to read attributes and check for None.
Example
For <span class="course-title">Python Programming</span> use find then .get_text() for the visible title.
Common mistake
Using element.string without checking for nested tags can yield None and cause attribute errors when you call strip() or similar methods.
Key Takeaway

Use get_text() for robust text; use get('attribute') and defensive checks for attributes.
