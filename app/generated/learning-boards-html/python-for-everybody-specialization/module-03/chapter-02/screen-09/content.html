Sample code

from bs4 import BeautifulSoup

html_doc = """
<html><head><title>The Dormouse's story</title></head>
<body>
<p class="title"><b>The Dormouse's story</b></p>

<p class="story">Once upon a time there were three little sisters; and their names were
<a href="http://example.com/elsie" class="sister" id="link1">Elsie</a>,
<a href="http://example.com/lacie" class="sister" id="link2">Lacie</a> and
<a href="http://example.com/tillie" class="sister" id="link3">Tillie</a>;
</p>

<p class="story">...</p>
</body></html>
"""

soup = BeautifulSoup(html_doc, 'html.parser')
print('Title:', soup.title.string)
first_p = soup.find('p')
print('First paragraph:', first_p.get_text())
all_links = soup.find_all('a')
for link in all_links:
  print('Link text:', link.get_text(), 'Href:', link.get('href'))
link2 = soup.find(id='link2')
print('Link with id link2:', link2.get_text())
Walkthrough notes
  • Use soup.title.string to get the title element's text.
  • Iterate find_all('a') to collect link text and href attributes.
  • Use find(id='...') to locate a specific element by id.
Key Takeaway

This example is a template: adapt the same patterns to your target pages by inspecting tags and attributes first.
