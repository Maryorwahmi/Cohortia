Install and create a BeautifulSoup object

Install beautifulsoup4, optionally lxml, fetch HTML, then parse.
pip install beautifulsoup4
# Optional for a faster parser:
pip install lxml

from bs4 import BeautifulSoup
import urllib.request

with urllib.request.urlopen(url) as response:
  html = response.read().decode('utf-8')

soup = BeautifulSoup(html, 'html.parser')  # or 'lxml' if installed
print(soup.title.string)
Why parser choice matters
html.parser is built-in; lxml can handle malformed HTML more robustly.
Common mistake
Specifying 'lxml' without installing it will raise an import error.
Quick example
Create a BeautifulSoup object and print the page title using the built-in parser. This confirms parsing succeeded.
Key Takeaway

Install, fetch, decode, and then parse. Choose the parser for resilience against malformed pages.
