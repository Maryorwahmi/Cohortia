Process Flow
Defensive Parsing Steps
  1. Parse the XML and locate the repeating element list.
  2. For each record, assign child elements to variables using find.
  3. Check each variable for None and set a default when needed.
  4. Log or record missing fields and continue processing remaining records.
Avoid blanket try-except; prefer explicit checks plus narrow exception handling for parse errors only.
Scenario
You import a course catalog where some courses omit credits. Log the course id and a message when credits are missing, set credits to a default like 0 or 'TBD', and continue.
