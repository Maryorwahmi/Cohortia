Definition
XML Fundamentals
  • Root element: the single top-level tag that contains all others.
  • Elements: named tags that form nodes in the hierarchy.
  • Attributes: name-value pairs on a start tag that provide metadata.
  • Text content: the string value inside an element.
Common misconception: attributes are not child elements. Parsers expose attributes differently and you should treat them as metadata, not nodes to iterate like children.
Concrete Example
<users>
  <user id="1">
    <name>Alice Smith</name>
    <email type="personal">alice@example.com</email>
  </user>
</users>
Key Takeaway

Map the XML tree before coding: root, repeated elements, attributes to read, and values to extract.
