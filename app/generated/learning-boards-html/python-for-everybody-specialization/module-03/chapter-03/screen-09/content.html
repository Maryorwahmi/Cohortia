Catalog Parsing Template
Follow the template below to parse and extract course id, title, and credits. Replace defaults and logging to match your application's needs.
Starter Code
import xml.etree.ElementTree as ET

xml_data = '''
<catalog>
  <course id="CS101">
    <title>Introduction to Programming</title>
    <credits>3</credits>
  </course>
  <course id="MA201">
    <title>Calculus I</title>
    <credits>4</credits>
  </course>
</catalog>'''

root = ET.fromstring(xml_data)
courses = root.findall('course')
for course in courses:
    course_id = course.get('id')
    title_el = course.find('title')
    credits_el = course.find('credits')
    title = title_el.text if title_el is not None else 'Untitled'
    credits = credits_el.text if credits_el is not None else 'Unknown'
    print(f"Course ID: {course_id}, Title: {title}, Credits: {credits}")
Run this script to verify it prints course records. If credits are missing, consider whether to set a numeric default or a placeholder string depending on downstream needs.
