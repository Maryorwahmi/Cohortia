Code Walkthrough
Accessing content and attributes
• element.text returns the text content of an element node.
• element.get('name') returns the attribute value or None if absent.
• Always assign the result of find to a variable and check it before reading .text.
Common Mistake

Calling .text on the result of find without checking for None will raise AttributeError when the element is missing.

Example
for user in users:
    user_id = user.get('id')
    name_el = user.find('name')
    name = name_el.text if name_el is not None else 'Unknown'
    email_el = user.find('email')
    email = email_el.text if email_el is not None else ''
    email_type = email_el.get('type') if email_el is not None else None
    phone_el = user.find('phone')
    phone = phone_el.text if phone_el is not None else None
    print(user_id, name, email_type, email, phone)
This pattern makes your script resilient: it sets sensible defaults and avoids raising AttributeError on missing nodes.
