Planned Failover

For Anticipated Outages (Zero Data Loss)

  • Used for scheduled maintenance or planned migrations.
  • Primary VMs are gracefully shut down.
  • Ensures latest data is fully replicated to target region.
  • Guarantees zero data loss.
  • Controlled and orderly transition.
Unplanned Failover

For Actual Disasters (Minimal Data Loss)

  • Used for unexpected disasters where primary region is unavailable.
  • Replicas are brought up using the latest available recovery point.
  • Data loss is minimized to the configured RPO (seconds/minutes).
  • Rapid response for sudden, critical events.
  • Primary VMs are assumed to be offline.
Concrete Example

Planned: Moving workloads for a datacenter upgrade. Unplanned: Recovering applications after a regional power grid failure.

Key Takeaway

Planned failover ensures zero data loss for anticipated outages, while unplanned failover provides rapid recovery for sudden disasters with minimal data loss (up to RPO).
