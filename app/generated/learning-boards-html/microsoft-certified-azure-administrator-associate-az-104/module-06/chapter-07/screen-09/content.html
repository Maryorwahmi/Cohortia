Step 3

Mobility Service Installs

ASR automatically installs an agent on the VM to capture data writes.

Mobility Service Role

This lightweight agent captures data writes on the VM, sending them to a cache storage account. It's essential for continuous replication and has minimal performance impact.

Concrete Example

When you enable DR for 'myVM01', ASR pushes the Mobility Service extension to it, allowing ASR to track all changes made to the VM's disks.

Key Takeaway

Configuring ASR starts with a Recovery Services vault and installing the Mobility Service extension on the VM to capture data writes for replication.
