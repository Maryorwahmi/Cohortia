Deep Dive into Log Analytics Agents

Software components installed on Virtual Machines to collect guest operating system data.

Agent Types

Microsoft Monitoring Agent (MMA) for Windows VMs and OMS agent for Linux VMs.

Data Collected

Performance counters, Windows Event Logs, Linux Syslog, and custom text logs.

Common Mistake

Forgetting to install or properly configure the agent, leading to incomplete monitoring data.

Key Takeaway

Log Analytics agents are essential for collecting detailed guest OS telemetry, providing deep visibility into VM health and activity.
