Diverse Data Sources for Log Analytics

Connecting various environments to your central log repository for unified monitoring.

Azure Resources (Diagnostic Settings)

Stream operational, audit logs, and metrics from services like VMs, App Services, Storage Accounts, and Key Vaults.

Native Integration
Virtual Machines (Log Analytics Agent)

Collect guest OS performance, event logs (Windows), syslog (Linux), and custom text logs from Azure and on-premises VMs.

OS-Level Data
Azure Activity Log

Records subscription-level events like resource creation, deletion, and updates, crucial for auditing and compliance.

Platform Events
Key Takeaway

Log Analytics provides a unified logging solution by integrating logs from Azure resources, VMs (via agents), and platform-level activity logs.
