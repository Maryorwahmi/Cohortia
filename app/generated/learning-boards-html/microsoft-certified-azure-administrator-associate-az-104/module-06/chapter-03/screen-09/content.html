Advanced KQL: Summarize and Sort

Aggregating and ordering data for deeper insights and trend analysis.

summarize Operator

Aggregates data using functions like count(), avg(), min(), max(), often grouped by columns using by. Example: AzureActivity | summarize Count = count() by Caller

sort by Operator

Orders query results by one or more columns in ascending (asc) or descending (desc) order. Example: AzureActivity | sort by TimeGenerated desc

Common Pitfall

Using summarize without a by clause aggregates the entire dataset into a single row, losing granular context.

Key Takeaway

summarize and sort by are crucial for transforming raw log data into structured, actionable insights, enabling effective trend analysis.

KQL Advanced Query Example

AzureActivity
| where ActivityStatus == "Failed"
| summarize FailedCount = count() by Caller
| sort by FailedCount desc
| take 5
Example Scenario

To find the top 5 callers with failed activities, you would filter for ActivityStatus == "Failed", summarize by Caller to count failures, and then sort in descending order.
