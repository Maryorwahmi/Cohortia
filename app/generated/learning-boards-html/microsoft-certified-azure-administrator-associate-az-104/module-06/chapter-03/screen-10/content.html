Understanding Log Table Structure

Navigating dedicated tables and their columns for effective KQL queries.

Dedicated Tables

Each log type (e.g., Heartbeat, Perf, AzureActivity) is stored in its own table within the Log Analytics workspace.

Predefined Schema (Columns)

Each table has specific columns (e.g., TimeGenerated, Computer, OperationName) that hold particular pieces of information.

IntelliSense & Discovery

The query editor provides IntelliSense to suggest tables and columns, aiding in schema discovery.

Key Takeaway

Knowing the specific tables and their column schemas is fundamental for writing accurate and efficient KQL queries.

Common Log Tables & Examples

Heartbeat Table

Contains data from Log Analytics agents, indicating VM health and connectivity.

Columns: Computer, TimeGenerated, OSType

Perf Table

Holds performance counter data from guest operating systems.

Columns: Computer, CounterName, CounterValue, TimeGenerated

AzureActivity Table

Contains subscription-level events from the Azure Activity Log.

Columns: TimeGenerated, OperationNameValue, ResourceGroup
