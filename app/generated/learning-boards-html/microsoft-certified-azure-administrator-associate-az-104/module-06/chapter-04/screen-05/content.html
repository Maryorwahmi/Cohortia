Alert Types

Understanding Alert Categories

Different alerts for different monitoring needs.

Metric Alerts

Triggered when a numerical metric (e.g., CPU, network I/O) crosses a defined threshold.

  • Near real-time performance.
  • Capacity planning.
  • Stateful (fire once, resolve).

Log Alerts

Based on the results of a KQL query against data in a Log Analytics workspace.

  • Complex pattern detection.
  • Specific event occurrences.
  • Numerical or row-based.

Activity Log Alerts

Respond to events in the Azure Activity Log, such as administrative operations or service health.

  • Security auditing.
  • Configuration changes.
  • Service health incidents.
Key Takeaway

Azure Monitor provides specialized alert types—Metric, Log, and Activity Log—to address distinct monitoring requirements across performance, logs, and control plane events.
