Alert Type Focus

Metric Alerts: Threshold-Based Monitoring

Responding to performance and capacity changes in near real-time.

What are Metric Alerts?

Metric alerts are triggered when a numerical metric (like CPU percentage, network bytes, or database DTU utilization) crosses a specified threshold. They are ideal for near real-time performance issues.

  • •Excellent for detecting performance bottlenecks.
  • •Useful for capacity planning and resource scaling.
  • •Stateful: fires once when condition met, resolves when condition clears.
Key Takeaway

Metric alerts provide immediate feedback on resource performance, allowing for proactive intervention based on defined thresholds.

Common Metric Alert Scenarios

High CPU Usage

Alert if VM CPU exceeds 90% for 5 minutes.

Low Disk Space

Notify if available disk space drops below 10GB.

High Network Latency

Alert if network latency exceeds 100ms.

Database DTU Usage

Warn if database DTU utilization is consistently high.

Common Misconception

Some believe metric alerts are only for simple 'up/down' checks. In reality, they can monitor complex performance trends over time, using aggregation types like average, minimum, maximum, and count over specified periods.
