Log Alerts: Querying for Complex Patterns

Uncovering deep insights from detailed log data with KQL.

What are Log Alerts?

Log alerts are based on the results of a Kusto Query Language (KQL) query against data in a Log Analytics workspace. They are powerful for detecting complex patterns or specific events within log data.

  • •Detects patterns not visible in simple metrics.
  • •Uses KQL for flexible and powerful querying.
  • •Can be numerical (count/sum) or row-based.
Key Takeaway

Log alerts provide granular control over monitoring by allowing custom KQL queries to identify specific events or complex patterns in log data.

KQL Query Example: HTTP 500 Errors

// Alert if more than 100 HTTP 500 errors in 5 minutes
AppRequests
| where TimeGenerated > ago(5m)
| where ResultCode == 500
| summarize ErrorCount = count() by bin(TimeGenerated, 1m)
| where ErrorCount > 100
Explanation
  • •`AppRequests`: Specifies the log table to query.
  • •`ago(5m)`: Filters data from the last 5 minutes.
  • •`ResultCode == 500`: Identifies HTTP 500 errors.
  • •`summarize`: Counts errors, grouped by 1-minute intervals.
Use Case Example

You could configure a log alert to notify your security team if more than 5 failed login attempts occur from the same IP address within a 10-minute window, indicating a potential brute-force attack.
