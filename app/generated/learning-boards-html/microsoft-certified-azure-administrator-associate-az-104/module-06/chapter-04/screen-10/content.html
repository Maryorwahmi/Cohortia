Alert Configuration

Action Groups: Defining Responses

Orchestrating notifications and automated responses when an alert fires.

What is an Action Group?

An action group is a collection of notification preferences and automation actions that are executed when an Azure Monitor alert is triggered. It centralizes and standardizes incident response.

  • •Defines 'what to do' when an alert fires.
  • •Can include multiple notification and automation actions.
  • •Reusable across multiple alert rules.
Key Takeaway

Action groups are the core of automated incident response in Azure, allowing you to define comprehensive and consistent reactions to alerts.

Example: Multi-Action Response

Email Operations Team

Sends detailed alert information to a distribution list.

SMS On-Call Engineer

Sends a critical text message for immediate attention.

Trigger Logic App

Automates creation of a Jira ticket for tracking.

Common Mistake

A common pitfall is not configuring action groups with enough redundancy. Relying solely on email, for example, means critical alerts could be missed if the recipient is offline or email systems are down. Always consider multiple notification channels.
