Chapter 6.6

Key Concepts

Essential terms for Azure Backup management

Backup Jobs

A centralized view within a Recovery Services vault showing the status and details of all backup and restore operations.

Full VM Restore

Creating a completely new Virtual Machine from a selected recovery point, including all its disks and configuration.

Restore Disks

Restoring only the disks from a recovery point to a storage account, allowing for manual VM creation or disk attachment.

Summary Takeaway

Effective Azure Backup management relies on understanding monitoring tools and the different VM restore options to ensure rapid and appropriate data recovery.
