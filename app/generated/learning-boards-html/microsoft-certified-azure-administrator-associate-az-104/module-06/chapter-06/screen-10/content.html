Step-by-Step: Executing a File-Level Restore

A guided scenario for recovering accidentally deleted files.

1

Initiate File Recovery in Portal

Navigate to your Recovery Services vault, select the VM, and choose "File Recovery." Select a recovery point from before the data loss occurred.

Action: Select VM > File Recovery > Choose Recovery Point.
2

Download & Copy Recovery Script

Download the executable script (Windows) or utility (Linux) and its associated password from the Azure portal. Copy these to your designated recovery server (e.g., the original VM).

Action: Download Executable/Script & Password > Copy to VM.
3

Execute Script & Mount Drive

On the recovery server, open an elevated Command Prompt, navigate to the script's location, and run it. Enter the password when prompted. This will mount the recovery point as a temporary drive letter.

Action: Run `IaaSRecoveryScript_*.exe` > Enter Password.
4

Copy Files & Unmount Drive

Browse the mounted drive in File Explorer, locate the missing file, and copy it back to its desired location. Once done, unmount the drive either from the Azure portal or using `diskpart` commands on the VM.

Action: Copy File > Unmount Disks (Portal or `diskpart`).
Key Takeaway

This process significantly reduces RTO for file-level data loss, allowing for quick and targeted recovery without the overhead of a full VM restore.
