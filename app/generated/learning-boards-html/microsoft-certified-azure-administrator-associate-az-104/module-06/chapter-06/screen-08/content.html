Component-Level Recovery

Restore Disks: Targeted Data Retrieval

Recovering only the virtual machine disks for flexible re-assembly.

How it Works

  • Select a VM backup item and a recovery point.
  • Choose the "Restore disks" option.
  • Specify a target storage account where the recovered disks will be placed.
  • Azure Backup restores the OS and/or data disks as VHD files.
Key Takeaway

'Restore disks' offers flexibility by recovering only the VM's disks. This is useful for custom VM creation, attaching to existing VMs, or accessing specific data without a full VM rebuild.

Flexible Post-Restore Actions

  • Create New VM: Use the restored VHDs to manually provision a new Azure VM with custom settings.
  • Attach to Existing VM: Mount the restored data disks to an operational VM to access the recovered data.
  • Data Extraction: Simply download the VHDs to extract specific files or perform analysis.

When to Use Restore Disks

This option is ideal when you need to recover specific data from a VM, want to create a VM with a custom configuration, or when the original VM's configuration is intact but its data disks are corrupted.

Scenario: A data disk on your VM is accidentally formatted. You need to recover the data from a previous backup without affecting the OS or other disks.
