Full VM Restore: Rebuilding from Disaster

Creating a completely new virtual machine from a recovery point.

What it Restores

  • All Disks: OS disk and any data disks attached to the VM.
  • Network Interfaces: The VM's network configuration.
  • VM Configuration: Settings like size, availability set, and extensions.
  • New VM Instance: A completely new VM is provisioned.
Key Takeaway

Use 'Restore new VM' for disaster recovery when the original VM is unrecoverable. It provides a complete, point-in-time restoration of the entire VM and its configuration.

Ideal for Disaster Recovery

This option is perfect when the original VM is completely lost, corrupted, or needs to be restored to a different environment (e.g., a new resource group or virtual network) for testing or failover purposes.

Scenario: A production VM's OS disk is corrupted beyond repair. You need to restore the entire VM to its state from 24 hours ago in a new, isolated network for validation.

Key Configurations

During the restore, you'll specify the new VM name, resource group, and virtual network. This allows for flexible deployment, including restoring to a different subscription or region if configured.

Consideration: Ensure the target resource group and virtual network have appropriate permissions and resources.
