Chapter 6.6

Key Concepts

Advanced protection and recovery terms

File-Level Restore

A granular recovery option to restore individual files or folders from a VM backup without restoring the entire VM.

Soft Delete

A feature that retains deleted backup data in a recoverable state for a specified period, protecting against accidental deletion.

Immutability

A security feature that makes backup data non-erasable and non-modifiable for a defined duration, protecting against ransomware and malicious acts.

Summary Takeaway

Leveraging granular restore options like file-level recovery, combined with advanced protection features like soft delete and immutability, creates a robust and resilient data protection strategy in Azure.
