Precision Recovery

File-Level Restore: Recovering Individual Files

Granular recovery of specific files or folders without full VM restoration.

How it Works

  • Select the VM and desired recovery point in the Recovery Services vault.
  • Download a generated script (Windows) or utility (Linux).
  • Run the script/utility on a designated "recovery server" (can be the original VM).
  • The recovery point is mounted as a temporary local drive.
  • Browse and copy desired files/folders.
Key Takeaway

File-level restore is highly efficient for recovering specific data, minimizing downtime and resource usage compared to a full VM restore. It's ideal for accidental deletions or targeted file corruption.

Benefits of File-Level Restore

  • Reduced RTO: Significantly faster recovery for individual files compared to full VM restores.
  • Minimal Downtime: No need to take the entire VM offline.
  • Resource Efficiency: Avoids the time and cost of provisioning a new VM.
  • Granular Control: Precisely target and recover only the data you need.

The 'Recovery Server' Concept

A 'recovery server' is any VM (the original or another) where the recovery script is executed. This VM temporarily hosts the mounted recovery point, allowing you to access the backed-up files as if they were on a local drive.

Consideration: The recovery server needs network connectivity to the Recovery Services vault and sufficient permissions.
