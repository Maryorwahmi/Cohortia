Core Concept

MARS Agent: Protecting On-Premises Files

The Microsoft Azure Recovery Services (MARS) agent is a lightweight client used to back up files, folders, and system state from on-premises Windows servers and clients directly to a Recovery Services vault.

  • Installs directly on Windows machines (servers/clients).
  • Enables granular selection of files, folders, or system state.
  • Performs block-level incremental backups for efficiency.
  • Encrypts data using a passphrase before sending to Azure.
Use Case

Ideal for small on-premises file servers or individual workstations needing off-site protection for specific critical files and folders without full VM backup.

MARS Agent Workflow

1. Install Agent: Download and install MARS agent on Windows machine.

2. Register: Register the agent with a Recovery Services vault.

3. Select Data: Choose specific files, folders, or system state to back up.

4. Backup: Data is encrypted and sent to the Recovery Services vault.

Key Takeaway

The MARS agent provides a simple, direct, and secure way to back up specific files and folders from on-premises Windows machines to Azure.
