Key Concepts: Backup Mechanics
Understanding how backups are performed and managed.

Application-consistent backup

A backup that ensures data integrity for applications by quiescing them during the snapshot process (e.g., using VSS for Windows).

Incremental Backup

Backups that only transfer changed blocks of data after the initial full backup, reducing backup time and storage costs.

Microsoft Azure Recovery Services (MARS) Agent

A lightweight agent used to back up files, folders, and system state from on-premises Windows servers and clients directly to a Recovery Services vault.

Summary Takeaway

Understanding application-consistent backups, incremental backups, and the MARS agent is key to implementing efficient and reliable data recovery strategies.
