MARS Agent: What It Does and Doesn't Do

The MARS agent is designed for specific on-premises backup scenarios, primarily focusing on granular file and folder protection.

  • Does: Back up files, folders, and system state from Windows machines.
  • Does: Provide block-level incremental backups directly to Azure.
  • Does Not: Perform full virtual machine-level backups for on-premises VMs.
  • Does Not: Offer application-aware backup for on-premises applications like SQL or Exchange at the VM level.
Misconception

A common mistake is assuming the MARS agent can back up entire on-premises VMs. It's for files/folders/system state only; full VM backup requires other solutions.

Comparison: On-Premises Backup Solutions

MARS Agent

Purpose: File, folder, and system state backup.
Workloads: On-premises Windows servers/clients.
Recovery: Granular file/folder recovery.

Azure Backup Server / DPM

Purpose: Full VM, application-aware backup.
Workloads: On-premises Hyper-V, VMware, SQL, Exchange.
Recovery: Full VM, application-level recovery.

Key Takeaway

The MARS agent is ideal for file/folder backup, but full on-premises VM protection requires more comprehensive solutions like Azure Backup Server or DPM.
