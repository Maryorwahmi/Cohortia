How Azure VM Backup Works
Automated snapshots and incremental data transfer to the vault.
STEP 1

Enable Backup

Azure Backup service installs an extension on the VM.

STEP 2

Take Snapshot

VSS (Windows) or file-consistent snapshot of disks.

STEP 3

Transfer Data

Changed blocks (incremental) sent to Recovery Services vault.

Application-Consistent vs. File-Consistent

Application-consistent backups (Windows VSS) ensure data integrity for running applications. File-consistent backups (Linux) ensure all files are in a consistent state at the time of snapshot.

Key Takeaway

Azure VM backup is an automated process using extensions and snapshots, providing efficient incremental backups to the Recovery Services vault.
