Lab: Triggering and Monitoring VM Backup
Initiating the first backup and tracking its progress.
STEP 1

Access Backup Item

Navigate to `myRSVault01` > "Backup items" > "Azure Virtual Machine". Select `myVM01`.

STEP 2

Trigger Backup Now

In the VM's backup item blade, click "Backup now". Choose a retention date (e.g., 30 days from now) and click "OK".

STEP 3

Monitor Backup Job

Monitor the backup job progress in the "Backup jobs" section of the vault. The first backup will take some time.

Checkpoint

Ensure the backup job status changes from "In progress" to "Completed" without errors.

Backup Job Initiated

Your VM's initial backup is now running, providing the first recovery point.

Key Takeaway

Triggering and monitoring the initial backup job is crucial to confirm that your Azure VM is actively protected and generating recovery points.
