Azure Monitor Capabilities

Tools for Visualization, Analysis, and Action

Azure Monitor provides powerful tools to visualize, analyze, and act upon collected telemetry data, transforming raw data into actionable insights.

Metrics Explorer

Chart and analyze numerical metric data over time.

Log Analytics Workspaces

Store and query log data using Kusto Query Language (KQL).

Alerting

Receive notifications when specific conditions are met.

Dashboards

Create customizable views for at-a-glance health insights.

Key Takeaway

Azure Monitor's integrated tools allow you to not only collect data but also to effectively visualize, analyze, and respond to insights from your cloud environment.
