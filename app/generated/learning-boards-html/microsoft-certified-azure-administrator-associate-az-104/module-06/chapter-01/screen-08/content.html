Metrics: The 'What'

Numerical Snapshots

Metrics are quantifiable data points that describe a system's state at a given moment. They are lightweight and collected frequently.

  • Data Type: Numerical values (e.g., CPU %, network bytes).
  • Purpose: Real-time performance monitoring, trending, alerting.
  • Granularity: High frequency, aggregated data.
  • Example: "CPU utilization is 90%."
Logs: The 'Why'

Detailed Event Records

Logs are event-based text records that provide detailed diagnostic information about specific occurrences within a system.

  • Data Type: Structured/semi-structured text (e.g., error messages, audit trails).
  • Purpose: Deep troubleshooting, root cause analysis, security investigations.
  • Granularity: Event-specific, detailed context.
  • Example: "High CPU due to process X starting at Y time."
Correlation Power

Integrating Insights

Azure Monitor's strength lies in its ability to integrate and correlate metrics and logs. An alert from a metric (e.g., high CPU) can lead you directly to the relevant logs to understand the underlying cause, providing a complete picture for effective problem resolution.

Key Takeaway

Use metrics for immediate performance checks and alerts, and logs for in-depth investigation and understanding the root cause of issues.
