Diagnostic Settings: The Gateway to Data Collection

Diagnostic settings on Azure resources allow you to specify which types of logs and metrics should be collected and where they should be sent.

Resource-Specific

Configured individually for each Azure service (VMs, App Services, Storage, etc.).

Select Data Types

Choose which categories of logs (e.g., application, web server) and metrics to collect.

Define Destinations

Specify where the collected data should be sent (e.g., Log Analytics, Storage Account).

Example Scenario

Enabling VM Guest OS Monitoring

By default, a new Azure VM only sends host-level metrics. To get detailed performance counters from within the guest OS (e.g., memory usage, specific process CPU), you must enable the Azure Diagnostics extension or Log Analytics agent on the VM, then configure diagnostic settings to send this guest OS data to a Log Analytics workspace.

Key Takeaway

Diagnostic settings are essential for granular control over telemetry collection, ensuring Azure Monitor receives the specific data needed for comprehensive insights.
