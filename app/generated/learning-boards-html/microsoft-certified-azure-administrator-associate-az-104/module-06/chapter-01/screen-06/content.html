Data Type: Metrics

Metrics: The 'What' of Your System's Health

Metrics are numerical values that describe some aspect of a system at a particular point in time, ideal for near real-time alerting and performance analysis.

Numerical Values

Quantifiable data points like percentages, counts, or rates.

High Frequency Collection

Collected frequently (e.g., every minute) for near real-time insights.

Ideal for Alerting

Perfect for setting up alerts on thresholds (e.g., CPU > 90%).

Example Metrics

Common Metric Types

  • CPU Utilization: Percentage of CPU being used.
  • Network In/Out: Bytes transferred to and from a resource.
  • Disk I/O Operations: Reads/writes per second on a disk.
  • HTTP Request Count: Number of web requests received by an application.
  • Database Connections: Active connections to a database server.
Key Takeaway

Metrics provide a quick, numerical 'what' about your system's performance, enabling real-time monitoring and immediate alerts.
