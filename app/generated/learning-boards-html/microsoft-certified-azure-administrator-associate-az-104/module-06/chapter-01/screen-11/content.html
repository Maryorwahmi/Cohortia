Data Destinations

Where Does Your Monitoring Data Go?

Collected logs and metrics from diagnostic settings can be sent to various destinations, each optimized for different use cases.

Log Analytics Workspace

For advanced querying and analysis of log data using KQL.

Azure Storage Account

For cost-effective, long-term archival of logs and metrics.

Azure Event Hub

For streaming data to external systems or custom analytics platforms.

Strategic Choice

Matching Destination to Need

The choice of destination depends on your specific requirements. Log Analytics is best for active analysis, Storage for long-term retention, and Event Hubs for real-time integration. A well-planned strategy often involves using a combination of these destinations.

Key Takeaway

Selecting the correct destination for your diagnostic data is crucial for optimizing analysis, archival, and integration with other systems.
