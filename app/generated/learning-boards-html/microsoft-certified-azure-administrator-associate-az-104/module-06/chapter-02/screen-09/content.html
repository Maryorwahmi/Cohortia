Filtering Metrics: Focusing Your Investigation

Narrowing down data to specific dimension values

What is Filtering?

The process of narrowing down metric data to specific dimension values, allowing you to focus your analysis on particular components or operations.

When to Use Filtering

  • Isolate Components: View data for a specific disk, network interface, or instance.
  • Exclude Noise: Remove irrelevant data points from your chart.
  • Combine with Splitting: Refine a split view to focus on a subset of components.
Key Takeaway

Filtering allows precise control over which metric data is displayed, enabling highly targeted analysis and troubleshooting.
