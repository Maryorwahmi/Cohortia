Introducing Metrics Explorer

Your gateway to visualizing Azure resource performance

What is Metrics Explorer?

The primary tool in the Azure portal for visualizing and analyzing Azure Monitor metrics. It provides an interactive charting experience.

Key Features

  • Scope Selection: Choose the resource to monitor.
  • Metric Namespace: Grouping of related metrics.
  • Metric Selection: Pick the specific data point.
  • Time Range: Adjust view from minutes to months.
Key Takeaway

Metrics Explorer is the central hub for visualizing Azure resource performance, offering flexible charting and time-range adjustments.

Steps to Visualize Metrics

1.Navigate to Azure Resource
2.Select 'Metrics' under Monitoring
3.Choose Metric Namespace & Metric
4.View & Adjust Time-Series Chart
