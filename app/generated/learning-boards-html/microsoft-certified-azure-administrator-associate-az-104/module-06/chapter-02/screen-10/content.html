Scenario Walkthrough

Diagnosing VMSS CPU Spikes

Applying Metrics Explorer for real-world troubleshooting

The Problem

Overall CPU utilization on a Virtual Machine Scale Set (VMSS) is intermittently spiking. Need to identify if it's widespread or isolated.

Diagnostic Outcome

  • Isolated Spikes: Investigate specific VM instances for misbehaving applications.
  • Widespread Spikes: Consider scaling out the VMSS or optimizing the overall workload.
Key Takeaway

Splitting by instance is crucial for diagnosing VMSS performance issues, differentiating between localized and widespread problems.

Step-by-Step Diagnosis

1.Select VMSS & 'Percentage CPU' Metric
2.Apply Splitting by 'Instance' Dimension
3.Interpret Individual Instance CPU Lines
4.Determine if Issue is Localized or Widespread
