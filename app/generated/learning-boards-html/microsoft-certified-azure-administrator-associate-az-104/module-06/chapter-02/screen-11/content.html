Custom Metrics: Extending Azure Monitor's Reach

Tracking application-specific data points for comprehensive insights

Why Custom Metrics?

Platform metrics cover infrastructure, but custom metrics allow you to track application-specific data like active users, API call times, or queue lengths.

How to Send Custom Metrics

  • Azure Monitor REST API: Direct HTTP calls.
  • SDKs: For .NET, Java, Node.js, etc.
  • Application Insights: Integrated application monitoring.
Key Takeaway

Custom metrics enable monitoring of unique application and business data, providing a complete view of your solution's health.
