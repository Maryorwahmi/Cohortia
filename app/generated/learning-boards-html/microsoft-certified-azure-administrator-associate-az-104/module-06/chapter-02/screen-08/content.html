Splitting Metrics: Pinpointing Specific Issues

Breaking down data by dimensions for detailed component analysis

What is Splitting?

Displaying separate lines on a metric chart for each unique value of a selected dimension. This provides a granular view of performance across components.

Why Use Splitting?

  • Localized Issues: Identify if a problem affects one instance or all.
  • Component Comparison: Compare performance across different parts.
  • Targeted Troubleshooting: Focus efforts on specific problematic areas.
Key Takeaway

Splitting metrics by dimensions is essential for diagnosing localized performance issues within a resource, like a single VM in a scale set.
