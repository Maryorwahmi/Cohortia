Core Concept

Azure Monitor Metrics: The Foundation

Quantitative insights into resource health and performance

What are Metrics?

Numerical values representing a specific aspect of an Azure resource at a particular time. They are lightweight and collected at regular intervals.

Key Characteristics

  • Numerical: Always a quantity or percentage.
  • Time-Series: Stored with a timestamp, ideal for trending.
  • Lightweight: Efficient for near real-time monitoring.
  • Proactive: Excellent for spotting anomalies and degradation.
Key Takeaway

Metrics provide quantitative summaries for quick performance insights, complementing detailed event logs for comprehensive monitoring.

Metrics vs. Logs: A Quick Comparison

Metrics

Quantitative summary, time-series, for trending & alerting.

  • CPU %
  • Network I/O
  • Disk IOPS

Logs

Detailed event information, for auditing & troubleshooting.

  • Error messages
  • Access records
  • Application traces

Metrics tell you what is happening; Logs tell you why.
