Aggregating Metrics: Summarizing Performance

Combining data points to reveal trends and overall health

What is Aggregation?

The process of combining multiple metric data points over a time period into a single, summary value. This helps in understanding overall trends.

Common Aggregation Types

  • Avg: Average value over the period.
  • Min/Max: Lowest/Highest value observed.
  • Sum: Total of all values (e.g., total bytes).
  • Count: Number of data points collected.
Key Takeaway

Choose the correct aggregation type (Avg, Max, Sum) based on the metric's nature to avoid misinterpreting performance data.
