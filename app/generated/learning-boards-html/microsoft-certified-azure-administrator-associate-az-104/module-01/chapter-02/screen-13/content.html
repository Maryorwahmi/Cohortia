Azure CLI Basics

Creating Storage Accounts with CLI

Provisioning a storage account using Azure CLI commands.

Command: Use az storage account create to provision a new storage account.

Globally Unique Name: The --name parameter requires a name unique across all of Azure.

Key Parameters: Specify --resource-group, --location, --sku (e.g., Standard_LRS), and --kind (e.g., StorageV2).

Key Takeaway

Azure CLI enables precise, automated deployment of storage accounts, requiring careful attention to unique naming and configuration parameters.

Azure CLI Command for Storage Account Creation

# Create a new storage accountaz storage account create \
  --name myclistorage12345 \
  --resource-group my-cli-rg \
  --location eastus \
  --sku Standard_LRS \
  --kind StorageV2
Common Mistake

Using a storage account name that is not globally unique will cause the deployment to fail.
