Deploying a Storage Account (Part 2)

Configuring performance, redundancy, and finalizing your storage account deployment.

Key Configuration Steps

  1. 1

    Performance Tier: Select 'Standard' (general purpose) or 'Premium' (high performance).

  2. 2

    Redundancy Option: Choose 'Locally-redundant storage (LRS)' for learning, or 'Geo-redundant storage (GRS)' for higher durability.

  3. 3

    Review Defaults: Navigate through Networking, Data protection, Encryption, and Tags tabs; defaults are usually fine for basic setup.

  4. 4

    Deploy: Click "Review + create" and then "Create". Monitor deployment notifications.

Key Takeaway

Performance and redundancy choices are critical for storage accounts, impacting cost, availability, and durability.
