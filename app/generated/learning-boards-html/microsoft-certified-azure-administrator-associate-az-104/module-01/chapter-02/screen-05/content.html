Portal Navigation

Dashboard and Navigation Essentials

Quickly find and manage resources with the dashboard, navigation pane, and search bar.

Customizable Dashboard: Personalize with widgets for a quick overview of resources, health, and billing.

Navigation Pane: Left-hand menu for quick access to services like 'All resources' and 'Resource groups'.

Powerful Search Bar: Top-of-portal tool to find resources, services, documentation, or marketplace offerings quickly.

Key Takeaway

Mastering the search bar is crucial for efficient navigation and significantly speeds up administrative tasks.
