Key Concepts (Part 1)

Essential terms and ideas to remember from this chapter.

Azure Portal

A web-based, unified console for managing Azure resources graphically.

Azure Cloud Shell

An interactive, browser-accessible shell for managing Azure resources, pre-configured with tools.

Azure CLI

A cross-platform command-line tool for executing Azure administrative commands.

Summary Takeaway

The Azure portal, Cloud Shell, and Azure CLI are the foundational tools for effective Azure resource management, offering both graphical and command-line capabilities.
