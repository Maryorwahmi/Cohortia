Introducing Azure Cloud Shell

Your browser-accessible command-line environment for Azure.

Browser-Accessible: Manage Azure resources directly from your web browser, no local installation required.

Pre-Configured Tools: Comes with Azure CLI, Azure PowerShell, Git, and text editors ready to use.

Shell Flexibility: Choose between Bash (Linux-style) or PowerShell (Windows-centric) environments.

Key Takeaway

Cloud Shell streamlines Azure management by providing a powerful, pre-configured command-line environment in your browser.
