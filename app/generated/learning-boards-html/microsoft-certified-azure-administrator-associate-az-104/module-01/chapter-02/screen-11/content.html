Cloud Shell Setup

Accessing and Setting Up Cloud Shell

Launching your command-line environment and persisting your files.

Launch: Click the Cloud Shell icon (>_) in the Azure portal's top global header.

One-Time Setup: Create a storage account to persist your files (home directory) across sessions.

Shell Selection: Switch between Bash and PowerShell using the dropdown menu within the terminal window.

Key Takeaway

The initial storage account setup ensures your Cloud Shell environment is persistent, saving your work across sessions.

Cloud Shell Launch Flow

1. Click Cloud Shell Icon

2. Create Storage Account (First Time)

Common Mistake

Skipping the storage account creation means your Cloud Shell files won't persist across sessions.
