Protecting with CanNotDelete

The CanNotDelete lock prevents deletion of a resource or resource group, while still allowing modifications.

  • Deletion Prevention: Ensures critical resources cannot be accidentally removed.
  • Modification Allowed: Users can still update resource configurations.
  • Scope Application: Can be applied at subscription, resource group, or individual resource level.
Key Takeaway

Use CanNotDelete locks on production resource groups to prevent accidental deletion, ensuring operational continuity.

Azure CLI Command
# Apply a CanNotDelete lock to a resource groupaz lock create --name "CannotDeleteProductionRG" --resource-group "my-prod-rg" --lock-type CanNotDelete --notes "Prevent accidental deletion of production resources."
Explanation

This command creates a resource lock named CannotDeleteProductionRG on the resource group my-prod-rg.

The --lock-type CanNotDelete parameter ensures that no user can delete this resource group or any resources within it.

The --notes parameter provides a descriptive message for the lock's purpose, aiding in future management and auditing.
