Core Services: Compute

App Service & Functions: PaaS and Serverless

Platform as a Service (PaaS) for web apps and serverless compute for event-driven code

Azure App Service (PaaS)

  • Hosts web apps, APIs, mobile backends.
  • Azure manages OS, patching, scaling.
  • Focus on code, not infrastructure.

Azure Functions (Serverless)

  • Runs small code snippets in response to events.
  • No server management required.
  • Pay only for execution time.
Key Takeaway

App Service and Functions offer increasing levels of abstraction, allowing developers to deploy and scale applications with minimal infrastructure management, optimizing for agility and cost.

Common Misconception

Serverless doesn't mean no servers; it means you don't manage them. Azure still uses servers, but they are fully abstracted from you.

Compute Abstraction Levels
Azure Virtual Machines (IaaS)

You manage OS, runtime, apps

Azure App Service (PaaS)

Azure manages OS, runtime; you manage apps

Azure Functions (Serverless)

Azure manages everything; you provide code

Higher abstraction means less management overhead for you.
