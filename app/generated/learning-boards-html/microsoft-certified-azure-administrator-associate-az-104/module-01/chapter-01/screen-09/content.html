Core Services: Compute

Azure Virtual Machines (VMs): IaaS Power

Infrastructure as a Service (IaaS) offering for full OS control

What are Azure VMs?

Virtualized servers running in Azure datacenters, offering IaaS.

  • You control the operating system (Windows, Linux).
  • Ideal for migrating existing on-premises servers.
  • Requires management of OS patching, updates, and software.
Key Takeaway

Azure VMs provide maximum control over your compute environment, making them versatile for various workloads, especially those requiring specific OS configurations.

Use Case

Running a legacy application that requires a specific version of Windows Server and custom software installations.

IaaS Model: Shared Responsibility
Azure (Cloud Provider)

Manages physical hardware, networking, virtualization

You (Customer)

Manages OS, applications, data, network configuration

IaaS provides flexibility but requires more customer management.
