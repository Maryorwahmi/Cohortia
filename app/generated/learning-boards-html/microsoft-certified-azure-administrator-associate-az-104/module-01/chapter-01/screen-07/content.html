Subscriptions: Billing and Administration

Administrative units linking to an Azure account and providing billing boundaries

What is an Azure Subscription?

A logical container that links to an Azure account and defines a billing boundary.

  • All Azure resources must belong to a subscription.
  • Aggregates billing for all contained resources.
  • Acts as a boundary for applying policies and access control.
Key Takeaway

Subscriptions are essential for managing costs, delegating administrative responsibilities, and organizing resources within Azure.

Example Scenario

A company might use separate subscriptions for 'Development', 'Testing', and 'Production' environments to manage budgets and access independently.
