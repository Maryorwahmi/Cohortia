Core Services: Networking

Network Security Groups (NSGs)

Virtual firewalls for filtering network traffic to and from Azure resources

What are NSGs?

A virtual firewall that filters network traffic to and from Azure resources in a VNet.

  • Define inbound and outbound security rules.
  • Rules based on IP, port, and protocol.
  • Applied to subnets or individual NICs.
Key Takeaway

NSGs are fundamental for securing your Azure network, allowing precise control over traffic flow and protecting your resources from unwanted access.

Common Misconception

NSGs are stateless for inbound traffic; they don't automatically allow return traffic. You need explicit rules for both directions if not using stateful services.

NSG Rule Application
Network Security Group (NSG)
