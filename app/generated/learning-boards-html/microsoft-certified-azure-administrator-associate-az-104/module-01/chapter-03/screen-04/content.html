Core Concept

Azure Resource Manager (ARM)

ARM is the deployment and management service for Azure, providing a management layer that enables you to create, update, and delete resources in your Azure subscription.

Unified Interface

All interactions with Azure (Portal, CLI, PowerShell, REST APIs) go through ARM, ensuring consistent processing.

Centralized Management

Provides a single control plane for managing, auditing, and governing resources across your subscription.

Key Takeaway

ARM is the consistent front-door for all Azure resource operations, ensuring uniform processing regardless of the tool used.

Creating a Virtual Machine via the Azure Portal triggers ARM, which then communicates with the 'Microsoft.Compute' Resource Provider to provision the VM.
