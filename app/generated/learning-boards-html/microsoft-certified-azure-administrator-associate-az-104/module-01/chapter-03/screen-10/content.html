ARM Template Code: Parameters
{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    "storageAccountName": {
      "type": "string",
      "metadata": {
        "description": "Name of the Storage Account"
      }
    },
    "location": {
      "type": "string",
      "defaultValue": "[resourceGroup().location]",
      "metadata": {
        "description": "Location for the Storage Account"
      }
    },
    "storageAccountSku": {
      "type": "string",
      "defaultValue": "Standard_LRS",
      "allowedValues": [
        "Standard_LRS",
        "Standard_GRS",
        "Standard_RAGRS",
        "Standard_ZRS",
        "Premium_LRS",
        "Premium_ZRS"
      ],
      "metadata": {
        "description": "Storage Account SKU"
      }
    }
  },
  "resources": [
    // ... resources defined here ...
  ],
  "outputs": {
    // ... outputs defined here ...
  }
}
Explanation

Understanding the Parameters Section

storageAccountName

A string parameter for the globally unique name of the storage account, provided at deployment.

location

String parameter for the resource location, defaulting to the resource group's location for convenience.

storageAccountSku

String parameter defining the SKU (e.g., Standard_LRS) with `allowedValues` for strict validation.

Key Takeaway

Parameters allow you to define customizable inputs for your ARM templates, making them adaptable to different environments and requirements without modifying the core template file.
