ARM Template Code: Resources & Outputs
{
  "$schema": "https://schema.management.azure.com/schemas/2019-04-01/deploymentTemplate.json#",
  "contentVersion": "1.0.0.0",
  "parameters": {
    // ... parameters defined here ...
  },
  "resources": [
    {
      "type": "Microsoft.Storage/storageAccounts",
      "apiVersion": "2021-09-01",
      "name": "[parameters('storageAccountName')]",
      "location": "[parameters('location')]",
      "sku": {
        "name": "[parameters('storageAccountSku')]"
      },
      "kind": "StorageV2",
      "properties": {}
    }
  ],
  "outputs": {
    "storageAccountEndpoint": {
      "type": "string",
      "value": "[reference(resourceId('Microsoft.Storage/storageAccounts', parameters('storageAccountName'))).primaryEndpoints.blob]"
    }
  }
}
Explanation

Defining Resources and Outputs

resources Section

Defines the Azure Storage Account with its type, API version, name (from parameter), location, SKU, and kind.

outputs Section

Returns the primary blob endpoint of the deployed storage account, useful for verification or integration.

reference Function

Used in outputs to retrieve runtime properties of a deployed resource, like its endpoints.

Key Takeaway

The resources section is where you declaratively define the Azure services to be deployed, while outputs provide a mechanism to extract and display important information from the deployed resources.
