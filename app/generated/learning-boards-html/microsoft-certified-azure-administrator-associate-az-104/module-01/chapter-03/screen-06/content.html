Definition

What are Resource Providers?

Resource Providers are services that offer specific Azure resources. When you deploy a resource, ARM communicates with the relevant provider to provision it.

Specialized Services

Each provider manages a distinct set of resource types and their properties (e.g., VMs, Storage Accounts, Virtual Networks).

ARM Interaction

ARM acts as the orchestrator, sending requests to the appropriate Resource Provider to fulfill deployment commands.

Key Takeaway

Resource Providers are specialized services that expose the actual Azure resources, acting as ARM's interface to provision and manage specific resource types.

Common Resource Providers

Microsoft.Compute

Offers Virtual Machines, Virtual Machine Scale Sets, Disks.

Microsoft.Storage

Offers Storage Accounts (Blob, File, Queue, Table storage).

Microsoft.Network

Offers Virtual Networks, Network Security Groups, Load Balancers.

Troubleshooting Tip

If a deployment fails, check if the required Resource Provider is registered in your subscription using Azure CLI or PowerShell.
