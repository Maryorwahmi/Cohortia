Understanding AKS Architecture

Key components that form a managed Kubernetes cluster.

Core Components
  • Control Plane: Azure-managed, includes API server, scheduler, controllers.
  • Worker Nodes: Azure VMs running your containerized applications (pods).
  • Pods: Smallest deployable unit, one or more containers.
  • Deployments: Manages pod lifecycle and desired replica count.
  • Services: Defines logical set of pods and access policy (stable IP/DNS).
  • Ingress: Manages external HTTP/HTTPS access to services.
Analogy: City Management

The Control Plane is like the city council (Azure-managed), setting policies. Worker Nodes are the city blocks, and Pods are individual buildings. Deployments ensure enough buildings exist, Services provide addresses, and Ingress manages traffic flow into the city.

Key Takeaway

AKS architecture combines Azure-managed control plane with user-managed worker nodes, leveraging Kubernetes objects like Pods, Deployments, and Services for robust application orchestration.
