Provisioning an AKS Cluster

Setting up your managed Kubernetes environment with Azure CLI.

Key Parameters
  • `--resource-group`: The resource group for your cluster.
  • `--name`: A unique name for your AKS cluster.
  • `--node-count`: Initial number of worker nodes.
  • `--enable-managed-identity`: For secure Azure resource access.
  • `--generate-ssh-keys`: For SSH access to worker nodes (optional).
  • `--kubernetes-version`: Specify a supported Kubernetes version.
Post-Creation Step

After cluster creation, use az aks get-credentials to configure kubectl to connect to your new AKS cluster. This is essential for managing your applications.

Key Takeaway

Provisioning an AKS cluster is a multi-step process involving Azure CLI commands for creation and credential configuration, enabling `kubectl` interaction.

Create AKS Cluster
az aks create \
  --resource-group MyAKSClusterGroup \
  --name MyAKSCluster \
  --node-count 2 \
  --enable-managed-identity \
  --generate-ssh-keys \
  --kubernetes-version 1.27.7
Configure `kubectl`
az aks get-credentials \
  --resource-group MyAKSClusterGroup \
  --name MyAKSCluster \
  --overwrite-existing
Verify Nodes
kubectl get nodes

This command will show the worker nodes in your newly created AKS cluster, confirming `kubectl` is configured.
