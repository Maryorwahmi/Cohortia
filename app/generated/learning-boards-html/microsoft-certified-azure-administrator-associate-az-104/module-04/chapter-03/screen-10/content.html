Auto-scaling Logic
Scale Out Rules

Define conditions (e.g., high CPU) that trigger the addition of new VM instances to handle increased load.

Scale In Rules

Define conditions (e.g., low CPU) that trigger the removal of VM instances to optimize costs during low demand.

Common Metrics

CPU percentage, memory percentage, network I/O, or custom metrics can be used to drive scaling decisions.

Key Takeaway

Auto-scaling rules are the core mechanism for VMSS to dynamically adjust resources, ensuring optimal performance and cost efficiency.
