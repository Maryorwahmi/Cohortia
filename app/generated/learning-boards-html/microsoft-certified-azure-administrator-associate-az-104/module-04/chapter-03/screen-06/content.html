What are Update Domains?

Logical groups of VMs that can be rebooted together during planned maintenance events by Azure.

How they work

Azure updates one update domain at a time, allowing other VMs to remain operational and ensuring application availability.

Typical Configuration

An Availability Set commonly spans 5 update domains, enabling a rolling update process.

Common Mistake

Placing only one VM in an Availability Set provides no HA benefit; at least two VMs are required for redundancy.

Azure CLI: Create Availability Set & VMs
az vm availability-set create \
  --resource-group MyHAAppGroup \
  --name MyWebAppAS \
  --platform-fault-domain-count 2 \
  --platform-update-domain-count 5 \
  --location eastus

az vm create \
  --resource-group MyHAAppGroup \
  --name WebVM1 \
  --image UbuntuLTS \
  --size Standard_B2s \
  --admin-username azureuser \
  --generate-ssh-keys \
  --availability-set MyWebAppAS

az vm create \
  --resource-group MyHAAppGroup \
  --name WebVM2 \
  --image UbuntuLTS \
  --size Standard_B2s \
  --admin-username azureuser \
  --generate-ssh-keys \
  --availability-set MyWebAppAS
Key Takeaway

The `--availability-set` parameter links VMs to the set, ensuring distribution across fault and update domains.
