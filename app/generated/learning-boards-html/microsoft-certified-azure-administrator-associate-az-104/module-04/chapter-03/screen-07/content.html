Azure Region with Availability Zones
What are Availability Zones?

Physically separate locations within an Azure region, each with independent power, cooling, and networking.

Protection Scope

Provides protection against datacenter-wide failures, offering a higher level of isolation than Availability Sets.

Azure CLI: Deploy VMs to Zones
az vm create \
  --resource-group MyDRAppGroup \
  --name AppVMZone1 \
  --image UbuntuLTS \
  --zone 1 \
  --location eastus2

az vm create \
  --resource-group MyDRAppGroup \
  --name AppVMZone2 \
  --image UbuntuLTS \
  --zone 2 \
  --location eastus2
Key Takeaway

Availability Zones are essential for applications requiring maximum resilience against large-scale regional outages.
