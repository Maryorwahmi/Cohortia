Azure CLI: Create a Basic VM Scale Set
az vmss create \
  --resource-group MyScaleSetGroup \
  --name MyWebAppScaleSet \
  --image UbuntuLTS \
  --admin-username azureuser \
  --generate-ssh-keys \
  --instance-count 2 \
  --upgrade-policy-mode Automatic \
  --load-balancer "" # Creates a default basic load balancer
Key Takeaway

This command creates a VMSS with initial instances, automatic updates, and a load balancer for traffic distribution.

`--instance-count`

Sets the initial number of VM instances in the scale set. This can be dynamically changed later by auto-scaling rules.

`--upgrade-policy-mode Automatic`

Ensures that OS and application updates are applied automatically in a rolling fashion across instances, minimizing downtime.

`--load-balancer ""`

Automatically provisions a basic public load balancer to distribute incoming traffic evenly across all VMSS instances.

Scenario

Launching a new web service that needs to handle unpredictable user traffic efficiently.
