App Service Plan & Web App

Understanding the foundational building blocks of Azure App Service.

Key Takeaway

The App Service Plan defines compute resources, while the Web App is the application itself. Multiple Web Apps can share a single App Service Plan for cost efficiency.

Analogy

Think of an App Service Plan as a hotel building with shared amenities, and each Web App as a guest room within that building, hosting a unique application.

App Service Plan vs. Web App

App Service Plan

  • Defines underlying compute resources (VM size, instances, region, OS).
  • The billing unit for App Service.
  • Can host multiple Web Apps.

App Service (Web App)

  • The actual application (web, mobile, API).
  • Consumes resources from its assigned App Service Plan.
  • Can be deployed with various runtimes (Python, .NET, Java, etc.).
