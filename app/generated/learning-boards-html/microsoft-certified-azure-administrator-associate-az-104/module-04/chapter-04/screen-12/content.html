Deployment Slots: The Swap Operation

Instantly redirecting traffic between staging and production slots.

Key Takeaway

The swap operation is a near-instantaneous hostname redirection between slots, enabling zero-downtime deployments and quick rollbacks without restarting applications.

How it Works
  • **Pre-warming:** New instances in staging are warmed up before swap.
  • **Configuration Swap:** App settings and connection strings can be slot-specific.
  • **Traffic Redirection:** DNS records are updated to point to the new 'production' slot.
