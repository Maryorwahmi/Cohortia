Deploying a Web App: Plan Creation

Setting up the foundational compute resources with Azure CLI.

Key Takeaway

The `az appservice plan create` command provisions the underlying compute resources for your web apps, defining OS, SKU, and location.

Command Breakdown
  • `--resource-group`: Logical container for Azure resources.
  • `--name`: Unique name for the App Service Plan.
  • `--is-linux`: Specifies a Linux-based plan.
  • `--sku B1`: Basic tier, 1 instance (dedicated compute).
  • `--location`: Azure region for resource deployment.
