Integrating Custom Data into ARM Templates

Adding custom data scripts directly into your ARM template for VM deployment.

ARM Template Snippet with Custom Data

"osProfile": {  "computerName": "[parameters('vmName')]",  "adminUsername": "[parameters('adminUsername')]",  "adminPassword": "[parameters('adminPassword')]",  "customData": "[base64(variables('nginxInstallScript'))]"},"variables": {  "nginxInstallScript": "#!\\/bin\\/bash\
sudo apt-get update\
sudo apt-get install -y nginx\
sudo systemctl start nginx\
sudo systemctl enable nginx\
echo \"<h1>Hello from my automated Azure VM!<\\/h1>\" | sudo tee \/var\/www\/html\/index.nginx-debian.html"}

Note: The script content in the variable is escaped for JSON. The base64() function encodes it before passing to the VM.

Key Steps

  • Define the script content as an ARM template variable.
  • Ensure the script is properly escaped for JSON.
  • Use the base64() template function to encode the script.
  • Assign the encoded script to the customData property in the VM's osProfile.
Key Takeaway

Embedding Base64-encoded custom data in ARM templates allows for a single, self-contained deployment of both infrastructure and initial configuration.

Consideration

For very large or complex scripts, consider storing them externally and referencing them, or using VM extensions.
