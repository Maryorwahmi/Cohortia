Executing ARM Template Deployments with Azure CLI

Using the Azure CLI to deploy ARM templates to a resource group.

Azure CLI Deployment Command

az deployment group create \  --resource-group MyAutomatedVMGroup \  --template-file vm-template.json \  --parameters adminPassword='<YourSecurePassword>'

Note: Replace <YourSecurePassword> with an actual strong password. For security, never hardcode sensitive information directly into the template file.

Command Breakdown

  • az deployment group create: Initiates a new deployment within a resource group.
  • --resource-group: Specifies the target resource group for the deployment.
  • --template-file: Path to your local ARM template JSON file.
  • --parameters: Provides values for template parameters, allowing customization.
Key Takeaway

The Azure CLI provides a powerful and secure way to execute ARM template deployments, enabling consistent and repeatable infrastructure provisioning.

Security Best Practice

Always pass sensitive parameters like passwords securely via the CLI or integrate with Azure Key Vault.
