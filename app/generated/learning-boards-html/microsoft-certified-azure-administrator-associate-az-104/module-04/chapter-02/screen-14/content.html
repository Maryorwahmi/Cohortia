Alternative: az vm create with Custom Data

Deploying a VM with custom data directly using the Azure CLI.

az vm create Command with Custom Data

az vm create \  --resource-group MyAutomatedVMGroup \  --name MyNginxVM \  --image UbuntuLTS \  --size Standard_B2s \  --admin-username azureuser \  --generate-ssh-keys \  --custom-data @init-nginx.sh \  --public-ip-sku Standard \  --nsg-rule SSH

Note: The @init-nginx.sh syntax tells the CLI to read the script content from the specified file.

Key Parameters

  • --resource-group: Target resource group.
  • --name: Name of the new VM.
  • --image: OS image to use (e.g., UbuntuLTS).
  • --custom-data @file: Path to the script file for post-deployment configuration.
Key Takeaway

For single VM deployments, az vm create with --custom-data @file offers a quick way to provision and configure a VM.

When to Use

Ideal for quick tests or single VM setups where a full ARM template for the VM itself is not strictly necessary.
