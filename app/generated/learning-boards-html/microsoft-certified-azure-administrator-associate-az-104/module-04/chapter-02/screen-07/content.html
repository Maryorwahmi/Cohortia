Template Flexibility

ARM Template Parameters and Variables

Making templates reusable and dynamic with deployment-time inputs and internal constructs.

Parameters: External Inputs

"parameters": {  "vmName": {    "type": "string",    "defaultValue": "myAutomatedLinuxVM"  },  "adminPassword": {    "type": "securestring",    "metadata": {      "description": "Password for the VM."    }  },  "location": {    "type": "string",    "defaultValue": "[resourceGroup().location]"  }}
  • Provided at deployment time.
  • Enable template customization without modification.
  • Use securestring for sensitive data.
  • Example: VM name, admin password, location.

Variables: Internal Constructs

"variables": {  "nicName": "[concat(parameters('vmName'), '-nic')]",  "publicIpAddressName": "[concat(parameters('vmName'), '-publicip')]",  "vnetName": "myVNet",  "subnetName": "default"}
  • Constructed within the template.
  • Simplify complex expressions and reuse values.
  • Not exposed at deployment time.
  • Example: Concatenated resource names.
Key Takeaway

Parameters allow external input for template reuse, while variables streamline internal logic and naming conventions.
