Implementing Custom Data: Nginx Installation Script

A shell script to install and configure Nginx on a Linux VM.

init-nginx.sh Script

#!/bin/bashsudo apt-get updatesudo apt-get install -y nginxsudo systemctl start nginxsudo systemctl enable nginxecho "<h1>Hello from my automated Azure VM!</h1>" | sudo tee /var/www/html/index.nginx-debian.html

Script Actions

  • Updates package lists.
  • Installs Nginx web server.
  • Starts Nginx service.
  • Enables Nginx to start on boot.
  • Creates a custom HTML welcome page.
Key Takeaway

Custom data scripts enable automated software installation and configuration, making VMs immediately functional upon deployment.

Common Mistake

Syntax errors in the custom data script or incorrect permissions can prevent successful execution.
