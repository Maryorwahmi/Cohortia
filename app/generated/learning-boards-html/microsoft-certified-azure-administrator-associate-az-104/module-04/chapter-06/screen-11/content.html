Security Considerations

Securing your serverless resources.

Implementing robust security measures is crucial for Azure Functions and Logic Apps.

  • Access Control: Use restrictive authorization levels (Function, Admin) for Functions.
  • Managed Identities: Prefer managed identities for authenticating to other Azure services.
  • Secure Connections: Use secure authentication (OAuth, Managed Identities) for Logic App connectors.
  • Secret Management: Store secrets in Azure Key Vault, not directly in definitions.
  • Input/Output Validation: Validate all incoming and outgoing data.

Security Best Practices

Functions: Avoid anonymous triggers unless absolutely necessary.

Logic Apps: Use Azure Key Vault for sensitive connection strings.

General: Always validate data to prevent vulnerabilities.

Example: A Function App using a managed identity to access Azure Key Vault for secrets.
