Introducing Azure Functions

Event-driven, serverless code execution.

Azure Functions provide a 'Functions-as-a-Service' (FaaS) model, enabling you to run small pieces of code (functions) in response to various events like HTTP requests, queue messages, or timers.

  • Ideal for event-driven computations, APIs, and data processing.
  • Functions are stateless by default; Durable Functions enable stateful workflows.
  • Functions are hosted within a 'Function App', which manages infrastructure and scaling.

Azure Functions

What it is: A serverless compute service for event-driven code.

Key Feature: Functions-as-a-Service (FaaS) model.

Triggers: HTTP, timers, queues, blobs, and more.

Example: A function that resizes an image whenever a new one is uploaded to Blob Storage.
