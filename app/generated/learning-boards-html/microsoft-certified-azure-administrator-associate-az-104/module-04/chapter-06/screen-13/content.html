Key Concepts

Essential takeaways from this chapter.

Serverless Computing

Cloud model abstracting server management; focus on code, auto-scaling, pay-per-use.

Azure Functions

Event-driven, code-first compute service (FaaS) for custom logic and APIs.

Azure Logic Apps

Low-code/no-code visual platform for workflow automation and service integration.

Functions for code, Logic Apps for workflows. Secure both!
