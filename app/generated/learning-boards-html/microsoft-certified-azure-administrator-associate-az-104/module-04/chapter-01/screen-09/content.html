CLI Deployment

Deploying a Linux VM with Azure CLI

Using az group create and az vm create for automated provisioning

Steps for CLI Deployment

  • Ensure Azure CLI is installed and logged in (`az login`).
  • Create a Resource Group to organize resources.
  • Use `az vm create` with essential parameters.
  • Generate SSH keys for secure Linux VM authentication.

Key Parameters Explained

--image UbuntuLTS: Specifies the OS image. --size Standard_B2s: Defines VM compute resources. --generate-ssh-keys: Creates SSH keys for secure login. --nsg-rule SSH: Automatically configures NSG to allow SSH traffic.

# Create a Resource Groupaz group create --name MyResourceGroup --location eastus

# Deploy a Linux VMaz vm create \ --resource-group MyResourceGroup \ --name MyLinuxVM \ --image UbuntuLTS \ --size Standard_B2s \ --admin-username azureuser \ --generate-ssh-keys \ --public-ip-sku Standard \ --nsg-rule SSH
Key Takeaway

The Azure CLI provides a powerful, scriptable way to deploy VMs, enabling automation and consistent resource provisioning through detailed command parameters.
