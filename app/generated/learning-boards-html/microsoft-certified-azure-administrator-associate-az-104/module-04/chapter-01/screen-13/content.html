Network Security

Network Security Groups: Your Virtual Firewall

Controlling inbound and outbound traffic for Azure resources

What is an NSG?

A virtual firewall that filters network traffic to and from Azure resources. It can be applied to a network interface or a subnet.

How NSG Rules Work

  • Allow or deny traffic based on 5-tuple (Source IP, Source Port, Destination IP, Destination Port, Protocol).
  • Rules are processed by priority (lower number = higher priority).
  • Default rules exist (e.g., DenyAllInbound, AllowVNetInbound).
Key Takeaway

NSGs are essential virtual firewalls that control traffic flow to your VMs, using prioritized rules to define what communication is permitted or denied.
