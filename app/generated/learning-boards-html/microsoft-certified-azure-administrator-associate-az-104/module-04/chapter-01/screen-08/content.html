Security Risk: Default NSG Rules

By default, Azure allows RDP (3389) for Windows or SSH (22) for Linux from *any* source. Always refine these rules to trusted IP ranges for production environments.

Key Takeaway

The Azure portal offers a comprehensive, tab-driven workflow for VM deployment, but requires careful attention to default security settings, especially NSG rules.
