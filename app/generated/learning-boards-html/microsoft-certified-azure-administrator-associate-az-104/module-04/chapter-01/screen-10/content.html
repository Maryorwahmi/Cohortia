CLI Authentication

Connecting to Your Deployed VM

SSH for Linux and RDP for Windows VMs

Linux VM Connection

  • Use SSH (Secure Shell) client.
  • Requires public IP address and SSH keys (generated during `az vm create`).

Windows VM Connection

  • Use RDP (Remote Desktop Protocol) client.
  • Requires public IP address and admin password (specified during `az vm create`).

Security Risk: Open Access

Default NSG rules often allow RDP/SSH from *any* source. Always restrict access to specific, trusted IP ranges to minimize attack surface.

# Connect to Linux VM via SSHssh azureuser@<publicIpAddress>

# Example for Windows VM creation (password instead of keys)az vm create \ --resource-group MyWindowsVMGroup \ --name MyWindowsVM \ --image Win2019Datacenter \ --size Standard_B2s \ --admin-username azureadmin \ --admin-password <YourPassword> \ --public-ip-sku Standard \ --nsg-rule RDP
Key Takeaway

Always secure VM access by using appropriate connection methods (SSH for Linux, RDP for Windows) and, critically, by restricting NSG rules to trusted sources.
