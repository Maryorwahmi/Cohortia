Health Probes

Continuously monitor backend instance health for reliable traffic distribution.

Purpose of Health Probes

Health probes are used by the load balancer to monitor the health and availability of instances in the backend pool. This ensures traffic is only sent to healthy servers.

  • •If an instance fails a probe, it's temporarily removed from rotation.
  • •Traffic is automatically redirected to healthy instances.
  • •Instance is re-added when it passes probes again.
Common Issue

Misconfigured health probes (wrong port/path, aggressive thresholds) can lead to incorrect instance health status.

Probe Types & Configuration

Azure Load Balancer supports various probe types to match your application's monitoring needs.

  • •TCP Probe: Checks if a TCP handshake can be completed on a specific port.
  • •HTTP Probe: Sends an HTTP GET request to a specified path and expects a 200 OK response.
  • •HTTPS Probe: Similar to HTTP, but uses HTTPS for secure endpoints.
  • •Configurable interval (how often to probe) and threshold (number of failures before marking unhealthy).
Best Practice

Configure probes to reflect actual application health, not just OS availability.

Key Takeaway

Health probes are crucial for dynamic traffic management, ensuring only healthy instances receive new connections.
