Frontend IP & Backend Pool

Understanding the primary entry and resource grouping components.

Frontend IP Configuration

This is the public or private IP address that clients connect to. It serves as the single point of contact for your load-balanced application.

  • •Public IP: For internet-facing applications, accessible globally.
  • •Private IP: For internal applications, accessible within your VNet.
  • •Acts as the virtual IP (VIP) for the load balancer.
Analogy

Think of the Frontend IP as the main entrance to a building, where all visitors arrive.

Backend Pool

A group of virtual machines or VM scale set instances that will receive the load-balanced traffic. These are the actual resources running your application.

  • •Contains the network interfaces (NICs) of backend VMs.
  • •Load balancer distributes traffic among healthy instances in this pool.
  • •Can include VMs from different Availability Zones (Standard SKU).
Misconception

The backend pool itself doesn't perform load balancing; it's a collection of resources that the load balancer distributes traffic to.

Key Takeaway

The Frontend IP is the public face, and the Backend Pool is the collection of servers behind the Load Balancer.
