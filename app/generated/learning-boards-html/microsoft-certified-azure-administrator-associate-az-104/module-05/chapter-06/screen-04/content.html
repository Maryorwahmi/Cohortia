What is Load Balancing?

Load balancing is a technique for distributing incoming network traffic across multiple backend resources, such as virtual machines or containers. It acts as a 'traffic cop' for your applications.

Key Benefit 1

High Availability: Redirects traffic from unhealthy servers, ensuring continuous service.

Key Benefit 2

Enhanced Scalability: Allows applications to handle increased user load by adding more backend resources.

Key Benefit 3

Optimized Resource Utilization: Prevents single server bottlenecks by evenly distributing workload.

Key Takeaway

Azure Load Balancer operates at Layer 4 (Transport Layer) of the OSI model, distributing traffic based on IP address and port number.
