Deploying Standard LB: Backend Pool & VMs

Configuring the backend resources that will receive load-balanced traffic.

3. Create a Backend Pool

The backend pool is a collection of virtual machines or VM scale set instances that will receive the load-balanced traffic. Create this logical grouping first.

az network lb address-pool create \
  --resource-group NetworkingLabRG \
  --lb-name MyStandardLB \
  --name MyBackendPool
Best Practice

Use descriptive names for your backend pools to easily identify their purpose.

4. Add VMs to the Backend Pool

Associate your virtual machines with the backend pool by adding their Network Interface Card (NIC) IP configurations to the pool.

# Get NIC IDs for WebServerVM01 and WebServerVM02
NIC_ID_1=$(az vm show -g NetworkingLabRG -n WebServerVM01 --query 'networkProfile.networkInterfaces[0].id' -o tsv)
NIC_ID_2=$(az vm show -g NetworkingLabRG -n WebServerVM02 --query 'networkProfile.networkInterfaces[0].id' -o tsv)

az network nic ip-config address-pool add \
  --resource-group NetworkingLabRG \
  --nic-name $(basename $NIC_ID_1) \
  --ip-config-name ipconfig1 \
  --lb-name MyStandardLB \
  --address-pool MyBackendPool

az network nic ip-config address-pool add \
  --resource-group NetworkingLabRG \
  --nic-name $(basename $NIC_ID_2) \
  --ip-config-name ipconfig1 \
  --lb-name MyStandardLB \
  --address-pool MyBackendPool
Important

Ensure VMs are in the same VNet/subnet or have proper peering for connectivity.

Key Takeaway

VMs are added to the backend pool via their NIC IP configurations, making them discoverable by the Load Balancer.
