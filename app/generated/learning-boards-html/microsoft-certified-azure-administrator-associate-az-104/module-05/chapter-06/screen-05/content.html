Azure Load Balancer SKUs

Understand the differences between Basic and Standard Load Balancer SKUs.

Basic SKU
  • •Suitable for small-scale apps and dev/test environments.
  • •Limited number of backend pool resources.
  • •Does not support Availability Zones.
  • •Limited health probe capabilities.
  • •No outbound rules support (can lead to SNAT port exhaustion).
  • •Free, but not recommended for production workloads.
Caution

Basic SKU has limited functionality and is not secure by default for outbound connections.

Standard SKU
  • •Recommended for production environments.
  • •Supports up to 1000 backend pool resources.
  • •Integrates with Availability Zones for zone redundancy.
  • •Provides robust health probe capabilities.
  • •Supports outbound rules for explicit outbound connectivity control.
  • •Secure by default (only allows explicitly defined inbound traffic).
Pro Tip

Always use Standard SKU for production workloads to leverage its full feature set and security benefits.
