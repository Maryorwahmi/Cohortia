Inbound NAT & Outbound Rules

Direct traffic to specific VMs and control outbound connectivity.

Inbound NAT Rules

Used to direct specific traffic from a frontend IP and port directly to a specific VM in the backend pool on a specific port, bypassing load balancing.

  • •Ideal for administrative access (SSH/RDP) to individual VMs.
  • •Maps a unique frontend port to a backend VM's private IP and port.
  • •Provides secure, direct access without exposing VMs publicly.
Example

Frontend IP:50000 → VM1:22 (SSH)

Outbound Rules (Standard SKU)

Explicitly define how backend instances connect to the internet. This feature is only available with the Standard Load Balancer SKU.

  • •Provides more control over outbound connectivity.
  • •Prevents SNAT port exhaustion issues common with Basic Load Balancers.
  • •Required for backend VMs to initiate internet connections when using Standard LB.
Security Note

Standard Load Balancers are secure by default; outbound rules are necessary for internet access.

Key Takeaway

Inbound NAT rules enable direct VM access, while outbound rules provide explicit internet connectivity for Standard Load Balancers.
