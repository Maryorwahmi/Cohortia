Troubleshooting Common Issues

Diagnosing and resolving problems with Azure Load Balancer.

Misconfigured Health Probes

Incorrect health probe settings are a leading cause of traffic distribution problems.

  • •Wrong Port/Path: Probe points to a port or path where the application isn't listening.
  • •Aggressive Thresholds: Too low an interval or threshold can prematurely mark healthy instances as unhealthy.
  • •NSG Blocking: Network Security Group (NSG) rules might block probe traffic (from IP 168.63.129.16).
Diagnosis Step

SSH/RDP into VM, verify application status and listening port (e.g., netstat -tulnp).

Outbound Connectivity & Persistence

Other common issues include unexpected outbound behavior and session management.

  • •Standard LB Outbound: VMs might not reach the internet if outbound rules aren't configured (secure by default).
  • •Session Persistence: Source IP affinity can lead to uneven distribution or reduced fault tolerance if not carefully managed.
  • •NSG Inbound: Always use NSGs to restrict inbound traffic to necessary ports, even with Standard LB.
Monitoring

Regularly monitor Load Balancer metrics and logs for proactive issue identification.

Key Takeaway

Effective troubleshooting involves verifying health probes, understanding outbound rules, and considering session persistence implications.
