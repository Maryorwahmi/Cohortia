Deploying Standard LB: Health Probe & Rules

Final steps to enable health monitoring and traffic distribution.

5. Create a Health Probe

Define a health probe to monitor the availability of instances in the backend pool. This example uses an HTTP probe on port 80.

az network lb probe create \
  --resource-group NetworkingLabRG \
  --lb-name MyStandardLB \
  --name MyHTTPProbe \
  --protocol Http \
  --port 80 \
  --path / \
  --interval 5 \
  --threshold 2
Probe Parameters

--interval: seconds between probes. --threshold: consecutive failures to mark unhealthy.

6. Create a Load Balancing Rule

This rule defines how incoming traffic on the frontend IP and port is distributed to the backend pool, using the health probe.

az network lb rule create \
  --resource-group NetworkingLabRG \
  --lb-name MyStandardLB \
  --name MyHTTPRule \
  --protocol Tcp \
  --frontend-port 80 \
  --backend-port 80 \
  --frontend-ip-name MyLBFrontend \
  --backend-pool-name MyBackendPool \
  --probe-name MyHTTPProbe \
  --disable-outbound-snat true
Important Flag

--disable-outbound-snat true is recommended for Standard LB to manage outbound connectivity explicitly.

Key Takeaway

A health probe ensures backend instance reliability, and a load balancing rule directs traffic based on defined criteria.
