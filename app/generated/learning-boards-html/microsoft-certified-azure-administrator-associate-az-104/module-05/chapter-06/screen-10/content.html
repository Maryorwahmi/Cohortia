Deploying Standard LB: Public IP & LB Creation

Step-by-step Azure CLI commands for initial Load Balancer setup.

1. Create a Public IP for the Load Balancer Frontend

This public IP will be the external address clients use to connect to your load-balanced application. It must be a Standard SKU for Standard Load Balancer.

az network public-ip create \
  --resource-group NetworkingLabRG \
  --name MyLBFrontendPublicIP \
  --sku Standard \
  --allocation-method Static \
  --zone 1 \
  --location eastus
Pro Tip

Using a static allocation method ensures the IP address remains constant, which is ideal for public-facing services.

2. Create the Standard Load Balancer

This command provisions the Load Balancer resource itself and links it to the public IP you just created as its frontend IP configuration.

az network lb create \
  --resource-group NetworkingLabRG \
  --name MyStandardLB \
  --sku Standard \
  --frontend-ip-name MyLBFrontend \
  --public-ip MyLBFrontendPublicIP \
  --location eastus
Common Mistake

Forgetting to specify --sku Standard when creating the Load Balancer, leading to a Basic SKU with limited features.

Key Takeaway

The public IP is the entry point, and the Load Balancer resource orchestrates traffic distribution using this IP.
