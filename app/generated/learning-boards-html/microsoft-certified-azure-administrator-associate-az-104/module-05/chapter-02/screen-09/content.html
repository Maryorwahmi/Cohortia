Assigning Static Private and Public IPs via CLI

Practical steps to configure IPs using Azure CLI.

Step 1: Get NIC Name
NIC_ID=$(az vm show \
  --resource-group MyNetworkingRG \
  --name myVM \
  --query 'networkProfile.networkInterfaces[0].id' \
  --output tsv)
NIC_NAME=$(basename $NIC_ID)
Step 2: Assign Static Private IP
az network nic ip-config update \
  --resource-group MyNetworkingRG \
  --nic-name $NIC_NAME \
  --name ipconfig1 \
  --private-ip-address 10.0.1.10 \
  --private-ip-allocation-method Static
Step 3: Create Standard Static Public IP & Associate
az network public-ip create \
  --resource-group MyNetworkingRG \
  --name myVMStaticPublicIP \
  --sku Standard \
  --allocation-method Static \
  --zone 1 # Optional
az network nic ip-config update \
  --resource-group MyNetworkingRG \
  --nic-name $NIC_NAME \
  --name ipconfig1 \
  --public-ip-address myVMStaticPublicIP
