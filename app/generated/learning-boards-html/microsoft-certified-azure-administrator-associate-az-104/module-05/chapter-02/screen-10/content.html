Lab: Configure Static IPs for a VM

Apply your knowledge by configuring static IPs in Azure.

Prerequisites

Resource group (e.g., `NetworkingLabRG`), VNet with subnet (e.g., `ProductionVNet` with `WebTierSubnet`).

Steps
  • Create VM without public IP.
  • Get Network Interface (NIC) name.
  • Assign static private IP (e.g., `10.100.1.10`).
  • Create Standard static public IP.
  • Associate public IP with VM's NIC.
  • Verify configuration.
Lab Environment
Azure VM
Azure Portal / CLI
