Core Concept
Public IP Addresses: Internet Connectivity

Enabling your Azure resources to be accessible from the internet.

SKUs: Basic vs. Standard

Basic: Simpler, dynamic/static allocation. Good for individual VMs or non-critical services.

Standard: Zone redundant, static allocation only. Required for Standard Load Balancer/Firewall. Recommended for production.

Allocation: Dynamic vs. Static

Dynamic: IP may change if resource is stopped/deallocated. Suitable for non-critical outbound access.

Static: IP is reserved and constant. Essential for stable internet-facing services and DNS management.
