Understanding Network Address Translation (NAT)

How Azure enables private resources to communicate with the internet.

SNAT (Outbound)

When a VM with a private IP initiates an outbound connection to the internet, Azure translates its private IP to a public IP. This allows the VM to reach external services.

DNAT (Inbound)

When traffic arrives at a VM's public IP address, Azure translates it to the VM's private IP address, routing the connection correctly to the internal resource.
