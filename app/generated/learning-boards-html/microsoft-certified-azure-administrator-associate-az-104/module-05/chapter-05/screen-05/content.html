DNS Fundamentals

Public DNS Zones in Azure

Hosting internet-accessible domains with Azure DNS

  • Internet Accessibility: Used for domains that need to be resolved from anywhere on the internet.

  • Domain Hosting: Hosts DNS records for domains like yourcompany.com.

  • Authoritative Source: Once configured, Azure DNS becomes the authoritative name server for your domain.

Common Misconception

Azure DNS hosts your domain's records, but it does not register the domain name itself. Domain registration is done through a separate registrar.

Public DNS Zone Workflow
1. Register Domain

Purchase yourcompany.com from a registrar.

2. Create Public DNS Zone

Set up yourcompany.com in Azure DNS.
