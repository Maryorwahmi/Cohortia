Creating a Public DNS Zone

Step-by-step with Azure CLI for 'mycompany.com'

  • Prerequisite: Ensure a resource group exists (e.g., MyNetworkingRG).

  • Command: Use az network dns zone create to establish the zone.

  • Automatic Records: NS and SOA records are automatically created upon zone creation.

Key Takeaway

Creating a public DNS zone is the first step to managing your domain's internet-facing records in Azure, with essential records automatically provisioned.

# Example: Create a Public DNS Zone
# Assume MyNetworkingRG exists

# Create a public DNS zone
az network dns zone create \
  --resource-group MyNetworkingRG \
  --name mycompany.com
Command Explanation

This command creates a new public DNS zone named mycompany.com within the specified resource group. This zone will host all public DNS records for your domain.
