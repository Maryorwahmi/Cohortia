Essential Public DNS Record Types

Mapping domain names to resources with A and CNAME records

A Record (Address Record)

Maps a domain name to an IPv4 address. Essential for directing web traffic to a specific server with a static IP.

Example: www.example.com → 20.1.2.3
CNAME Record (Canonical Name)

Maps an alias domain name to another canonical (primary) domain name. Useful for services with dynamic IPs or complex hostnames.

Example: blog.example.com → exampleblog.azurewebsites.net
Key Takeaway

A records provide direct IP mapping, while CNAMEs offer flexible aliasing, crucial for managing dynamic cloud resources.
