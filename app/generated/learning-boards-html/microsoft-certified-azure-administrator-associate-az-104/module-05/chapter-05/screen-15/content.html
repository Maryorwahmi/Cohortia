Chapter Review

Key Concepts: Part 1

Essential terms and definitions from this chapter

Azure DNS

A highly available and scalable DNS hosting service for managing public and private DNS domains in Azure.

Public DNS Zone

A DNS zone hosted in Azure DNS for domains accessible from the internet.

Private DNS Zone

A DNS zone hosted in Azure DNS for name resolution within and across Azure Virtual Networks, not internet-accessible.

Record Set

A collection of records of the same type (e.g., multiple A records) for a specific name within a DNS zone.

A Record

Maps a domain name to an IPv4 address, commonly used for pointing websites to servers.

CNAME Record

Maps an alias domain name to another canonical (primary) domain name, useful for dynamic services.

Summary Takeaway

Azure DNS provides flexible and scalable solutions for both public and private domain management, utilizing various record types to direct traffic effectively.
