VNet Linking for Private DNS

Connecting Virtual Networks for name resolution and registration

Registration VNet Link

Azure VMs in the linked VNet automatically register their hostnames and private IPs as A records in the private DNS zone.

Resolution VNet Link

Resources within the linked VNet can resolve names defined in the private DNS zone. Can be independent of registration.

Pro-Tip

For most scenarios, link your VNet for both registration and resolution to enable seamless internal name discovery for VMs.
