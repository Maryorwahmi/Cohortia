Common DNS Resolution Issues

Diagnosing and resolving DNS problems in Azure

  • Incorrect Record Types: Using A record instead of CNAME, or vice-versa.

  • Typos: Simple mistakes in domain names or IP addresses.

  • Missing VNet Link: Forgetting to link a VNet for resolution in private DNS zones.

Key Takeaway

Systematic troubleshooting involves checking record types, syntax, TTL values, and crucial VNet links for private DNS resolution.

Troubleshooting Flow
1. Check Record Types

Are A, CNAME, MX, TXT records used correctly?

2. Verify Syntax & TTL

Look for typos and ensure reasonable TTL values.

3. Check VNet Links (Private DNS)

Confirm VNet is linked for resolution to the private zone.
