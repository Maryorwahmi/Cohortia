Deploying Application Gateway: Gateway Creation

Creating the Application Gateway instance with basic configuration

Step 3: Create Application Gateway

az network application-gateway create \
  --resource-group NetworkingLabRG \
  --name MyAppGateway \
  --location eastus \
  --sku Standard_v2 \
  --capacity 2 \
  --vnet-name ProductionVNet \
  --subnet AppGatewaySubnet \
  --public-ip-address AppGatewayPublicIP \
  --http-settings-cookie-based-affinity Enabled \
  --http-settings-port 80 \
  --http-settings-protocol Http \
  --frontend-port 80 \
  --priority 100 \
  --probe-path / \
  --probe-protocol Http \
  --tags "Environment=Dev" \
  --min-capacity 2 \
  --max-capacity 5 \
  --zones 1 2 3

This command provisions the Application Gateway with a Standard_v2 SKU and basic HTTP settings.

Key Takeaway

The `az network application-gateway create` command is comprehensive, establishing the core gateway and its initial operational parameters.

Pro-Tip

The Standard_v2 SKU is recommended for production due to its auto-scaling, zone redundancy, and enhanced performance capabilities.

Application Gateway Creation Parameters

Resource Group & Name

Organizes and identifies the gateway.

Location & SKU

Geographic region and feature tier (e.g., Standard_v2).

Capacity & Zones

Number of instances and redundancy across availability zones.

VNet & Subnet

Network integration for backend communication.

Public IP Address

External access point for clients.

HTTP Settings & Probes

Backend connection parameters and health monitoring.

Deployment Time

Be aware that Application Gateway deployments can take 15-20 minutes to complete.
