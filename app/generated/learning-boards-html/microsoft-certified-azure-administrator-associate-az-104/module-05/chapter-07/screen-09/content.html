Application Gateway Components

Understanding the building blocks of an Azure Application Gateway deployment

Frontend IP

The public or private IP address where clients connect to the Application Gateway.

Listeners

Define IP, port, and protocol (HTTP/HTTPS) for incoming client requests, handling SSL certificates.

Request Routing Rules

Link listeners to backend pools, defining how requests are routed based on URL path or host headers.

Backend HTTP Settings

Define parameters for Application Gateway's connection to backend servers (port, protocol, affinity).

Backend Pools

Groups of backend servers (VMs, App Services, IPs) that host your web application.

Health Probes

Monitor the health of backend instances, ensuring traffic is only sent to healthy servers.

Key Takeaway

Each component plays a vital role in defining how Application Gateway receives, processes, and routes web traffic to backend services.
