Deploying Application Gateway: Subnet Requirements

Understanding the networking prerequisites for Application Gateway deployment

Key Requirements

  • •
    Dedicated Subnet: Application Gateway must reside in its own subnet; no other resources allowed.
  • •
    Adequate Size: Subnet must be large enough for current and future Application Gateway instances.
  • •
    Common Prefixes: A /24 or /27 address prefix is typically sufficient.
  • •
    No Specific Name: The subnet does not require a specific name like Azure Firewall's subnet.
Key Takeaway

Proper subnet planning is critical for Application Gateway deployment, ensuring dedicated resources and sufficient IP capacity.

Common Mistake

Not providing a dedicated subnet or using one that is too small, leading to deployment failures or scaling issues.
