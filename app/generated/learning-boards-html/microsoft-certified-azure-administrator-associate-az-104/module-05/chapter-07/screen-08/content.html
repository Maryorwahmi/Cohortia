URL-based Routing & Multi-site Hosting

Directing traffic based on URL paths and hosting multiple applications on one gateway

How They Work

  • •
    URL-based Routing: Routes requests to different backend pools based on the URL path (e.g., /images/*).
  • •
    Multi-site Hosting: Routes requests to different backend pools based on the HTTP host header (e.g., site1.com vs. site2.com).
  • •
    Efficiency: Consolidates multiple applications or services behind a single Application Gateway instance.
Key Takeaway

These features provide granular control over web traffic, enabling flexible application architectures and cost-effective hosting.

Common Mistake

Incorrectly configuring host headers on backend web servers for multi-site setups, leading to routing failures.
