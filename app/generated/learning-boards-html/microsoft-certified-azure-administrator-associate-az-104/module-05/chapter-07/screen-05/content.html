Feature Overview

Key Features of Application Gateway

Exploring the advanced capabilities that enhance web application delivery

SSL/TLS Termination

Offload SSL decryption from backend servers, improving performance and simplifying configuration.

Web Application Firewall (WAF)

Protect web applications from common vulnerabilities and exploits based on OWASP core rule sets.

URL-based Routing

Route traffic to different backend pools based on the URL path of the incoming request.

Multi-site Hosting

Host multiple web applications on the same Application Gateway instance using host headers.

Session Affinity

Ensure requests from the same user session are routed to the same backend server (cookie-based).

WebSocket & HTTP/2

Support for modern web protocols, enabling real-time communication and improved performance.

Key Takeaway

Application Gateway's features are tailored to optimize web application performance, security, and routing complexity.
