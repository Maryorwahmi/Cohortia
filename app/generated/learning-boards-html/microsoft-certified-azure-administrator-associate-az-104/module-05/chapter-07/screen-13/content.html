Deploying Application Gateway: Backend Pool & Common Mistakes

Adding backend targets and avoiding common configuration pitfalls

Step 4: Add Backend Pool Targets

NIC_ID_1=$(az vm show -g NetworkingLabRG -n WebServerLB01 --query 'networkProfile.networkInterfaces[0].id' -o tsv)
NIC_ID_2=$(az vm show -g NetworkingLabRG -n WebServerLB02 --query 'networkProfile.networkInterfaces[0].id' -o tsv)

az network application-gateway address-pool update \
  --resource-group NetworkingLabRG \
  --gateway-name MyAppGateway \
  --name appGatewayBackendPool \
  --servers $NIC_ID_1 $NIC_ID_2

This command updates the default backend pool with the NIC IDs of your web servers.

Key Takeaway

Correctly configuring backend pools and understanding common pitfalls are crucial for a reliable Application Gateway setup.

Common Mistakes

Misconfigured health probes, incorrect URL path rules, or host headers can lead to traffic not reaching backend servers.
