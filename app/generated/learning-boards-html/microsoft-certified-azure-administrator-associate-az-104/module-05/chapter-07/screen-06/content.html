SSL/TLS Termination (Offloading)

Understanding how Application Gateway handles encryption and decryption for web traffic

How it Works

  • •
    Client Connection: HTTPS traffic arrives at Application Gateway.
  • •
    Decryption: Application Gateway uses its installed SSL certificate to decrypt the traffic.
  • •
    Backend Forwarding: Traffic is forwarded as unencrypted HTTP to backend servers.
  • •
    Optional Re-encryption: Application Gateway can re-encrypt traffic to backend for end-to-end security.
Key Takeaway

SSL/TLS termination centralizes certificate management and reduces backend server load, improving application performance.

Pro-Tip

Always ensure your SSL certificates are correctly configured and renewed regularly for HTTPS listeners to avoid service interruptions.
