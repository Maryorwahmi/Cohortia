Creating an NSG with Azure CLI

Setting up your network security container

Command Line Interface

Azure CLI provides a powerful way to manage Azure resources programmatically.

Resource Group & Name

Specify the resource group and a descriptive name for your new NSG.

Initial State

An NSG starts with default rules; custom rules are added later to define specific traffic policies.

Azure CLI Command
# Example: Create an NSG
# Assume MyNetworkingRG exists

az network nsg create \
  --resource-group NetworkingLabRG \
  --name WebServerNSG
Expected Output (abbreviated)
{
  "id": "/subscriptions/.../resourceGroups/NetworkingLabRG/providers/Microsoft.Network/networkSecurityGroups/WebServerNSG",
  "location": "eastus",
  "name": "WebServerNSG",
  "provisioningState": "Succeeded",
  "resourceGroup": "NetworkingLabRG",
  "securityRules": [],
  "tags": {},
  "type": "Microsoft.Network/networkSecurityGroups"
}
Key Takeaway

The `az network nsg create` command is the first step to establish a network security boundary in Azure.
