NSG Association Levels

Applying security rules at the subnet or NIC level

Subnet Association

Rules apply to all resources within the entire subnet, providing broad network-level control.

NIC Association

Rules apply only to a specific virtual machine's network interface, offering granular VM-level control.

Dual-Layer Evaluation

Both NSGs are evaluated; traffic must be allowed by both to pass, adding complexity but also robust security.

Key Takeaway

Traffic must be allowed by both subnet and NIC NSGs; inbound evaluates subnet then NIC, outbound evaluates NIC then subnet.
