What are Network Security Groups (NSGs)?

NSGs act as a stateful, packet-filtering firewall that controls inbound and outbound traffic to Azure resources.

Core Function

NSGs filter network traffic to Azure VMs and subnets based on rules, acting as a critical layer of defense.

Software-Defined

Unlike physical firewalls, NSGs are integrated into the Azure networking stack, offering flexibility and scalability.

Stateful Operation

Automatically allows return traffic for established outbound connections, simplifying rule management.
