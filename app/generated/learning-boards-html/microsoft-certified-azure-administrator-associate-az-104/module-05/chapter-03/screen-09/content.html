Adding an Inbound HTTP Rule

Allowing web traffic to your resources

Rule Parameters

Define source/destination, ports, protocol, direction, priority, and access type.

Priority is Key

Set a low priority number (e.g., 100) to ensure the rule is evaluated before broader deny rules.

Allow HTTP (Port 80)

This rule enables public access to web servers, a common requirement for many applications.

Azure CLI Command
# Add an inbound rule to allow HTTP (port 80) traffic from any source
az network nsg rule create \
  --resource-group NetworkingLabRG \
  --nsg-name WebServerNSG \
  --name AllowHTTPInbound \
  --priority 100 \
  --direction Inbound \
  --source-address-prefixes '*' \
  --source-port-ranges '*' \
  --destination-address-prefixes '*' \
  --destination-port-ranges 80 \
  --protocol Tcp \
  --access Allow \
  --description "Allow inbound HTTP traffic"
Rule Breakdown
Priority: 100
Direction: Inbound
Source: Any (*)
Destination Port: 80
Protocol: TCP
Access: Allow
Key Takeaway

Carefully define rule parameters to precisely control traffic flow, ensuring necessary services are accessible.
