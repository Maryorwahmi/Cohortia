Key Concepts

Essential terms to remember

Network Security Group (NSG)

A stateful, packet-filtering firewall that controls inbound and outbound network traffic to Azure resources.

Security Rule

A component of an NSG that defines whether to allow or deny traffic based on priority, direction, source/destination, port, and protocol.

Priority

A number (100-4096) assigned to an NSG rule, determining its evaluation order (lower numbers have higher priority).

Chapter Summary

NSGs are fundamental for Azure network security, using prioritized rules to control traffic flow at the subnet or NIC level, with ASGs simplifying management.
