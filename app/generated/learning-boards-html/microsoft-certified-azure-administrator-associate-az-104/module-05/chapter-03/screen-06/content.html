Default NSG Rules

Understanding the baseline security policies

Cannot Be Deleted

These rules are permanent but can be overridden by custom rules with higher priority (lower number).

Baseline Security

They provide essential connectivity within the VNet and to the internet, along with default deny rules.

Default NSG Rules Overview
AllowVnetInbound

Priority 65000: Allows VNet traffic.

AllowAzureLoadBalancerInbound

Priority 65001: Allows Azure LB traffic.

DenyAllInbound

Priority 65500: Denies all other inbound.

AllowVnetOutbound

Priority 65000: Allows VNet outbound traffic.

AllowInternetOutbound

Priority 65001: Allows internet outbound traffic.

DenyAllOutbound

Priority 65500: Denies all other outbound.

Key Takeaway

Default rules provide a necessary foundation, but custom rules are essential to tailor security for specific application needs.
