Application Security Groups (ASGs)

Simplifying NSG rule management for workloads

Group VMs by Workload

Instead of individual IPs, group VMs (e.g., 'WebServers') for easier management.

Dynamic Rule Application

NSG rules automatically apply to VMs added or removed from an ASG, without rule modification.

Reduced Overhead

Simplifies policy management, especially in large or frequently changing environments.
