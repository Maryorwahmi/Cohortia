NSG Rules and Priority

How traffic is evaluated against security rules

Rule Components

Source/Destination: IP addresses or IP ranges.

Port Ranges: Specific ports or ranges (e.g., 80, 443, 22).

Protocol: TCP, UDP, ICMP, or Any.

Direction: Inbound or Outbound.

Access: Allow or Deny.

Priority Evaluation
100

Allow RDP from Office IP

Specific rule, higher priority (lower number).

200

Allow HTTP from Any

General rule, lower priority.

65500

Deny All Inbound

Default rule, lowest priority.

Pro Tip

Always test your NSG rules thoroughly after configuration to ensure traffic flows as expected and security is maintained.

Key Takeaway

Rule priority is critical: lower numbers mean higher precedence, and the first matching rule determines the traffic's fate.
