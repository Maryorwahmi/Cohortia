Associating NSG with a VM's Network Interface

Applying security policies to a virtual machine

Targeting the NIC

NSG rules are applied directly to the VM's network interface for granular control.

Dynamic NIC Retrieval

Use `az vm show` to programmatically get the NIC name, ensuring accuracy.

Immediate Effect

Once associated, the NSG's rules instantly begin filtering traffic for the VM.

Azure CLI Commands
# Assume WebServerVM01 exists

# Get the NIC name of the VM
NIC_NAME=$(az vm show \
  --resource-group NetworkingLabRG \
  --name WebServerVM01 \
  --query 'networkProfile.networkInterfaces[0].id' \
  --output tsv | awk -F'/' '{print $9}')

echo "NIC Name: $NIC_NAME"

# Associate the NSG with the VM's network interface
az network nic update \
  --resource-group NetworkingLabRG \
  --name $NIC_NAME \
  --network-security-group WebServerNSG
Example Output (NIC Name)
NIC Name: webservervm01-nic
Key Takeaway

Associating an NSG with a NIC is the final step to enforce its security rules on a specific virtual machine.
