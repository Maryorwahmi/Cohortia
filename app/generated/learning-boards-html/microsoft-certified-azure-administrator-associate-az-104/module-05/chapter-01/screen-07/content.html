Classless Inter-Domain Routing (CIDR)

Using CIDR to define flexible and efficient IP address ranges.

Understanding CIDR Blocks

A CIDR block combines an IP address with a network prefix length (e.g., 10.0.0.0/16). The prefix length determines the size of the network.

  • Network Prefix: The number after the slash (e.g., /16) indicates the number of bits for the network portion.
  • Host Bits: The remaining bits are used for host addresses within that network.
Example

10.0.0.0/16 means the first two octets (10.0) are fixed for the network, allowing for 2^(32-16) = 65,536 IP addresses.

CIDR and Network Size

The prefix length directly impacts the number of available IP addresses:

  • /16: 65,536 IP addresses (e.g., 10.0.0.0 to 10.0.255.255).
  • /24: 256 IP addresses (e.g., 10.0.1.0 to 10.0.1.255).
  • Smaller prefix number = Larger network.
Key Takeaway

CIDR notation is essential for defining VNet and subnet address ranges. A smaller prefix number (e.g., /16) indicates a larger network with more available IP addresses.
