Managing VNets with Azure CLI

Using command-line tools for efficient and scriptable network deployments.

Azure CLI Commands

The Azure CLI provides powerful commands for VNet and subnet management:

  • az group create: Create a resource group to contain your VNet.
  • az network vnet create: Deploy a new VNet with specified address space.
  • az network vnet subnet create: Add subnets to an existing VNet.
Key Parameter

The --address-prefix parameter is crucial for defining the CIDR block for both VNets and subnets.

CLI Example: Create VNet & Subnets

# Create a resource groupaz group create --name MyNetworkingRG --location eastus

# Create the VNet with a /16 address spaceaz network vnet create \
  --resource-group MyNetworkingRG \
  --name MyVNet \
  --address-prefix 10.0.0.0/16 \
  --location eastus

# Add a subnet for web servers with a /24 address spaceaz network vnet subnet create \
  --resource-group MyNetworkingRG \
  --vnet-name MyVNet \
  --name WebSubnet \
  --address-prefix 10.0.1.0/24

# Add another subnet for application serversaz network vnet subnet create \
  --resource-group MyNetworkingRG \
  --vnet-name MyVNet \
  --name AppSubnet \
  --address-prefix 10.0.2.0/24
Key Takeaway

The Azure CLI provides a robust, scriptable method for creating and managing VNets and subnets, enabling automation and precise control over network configurations.
