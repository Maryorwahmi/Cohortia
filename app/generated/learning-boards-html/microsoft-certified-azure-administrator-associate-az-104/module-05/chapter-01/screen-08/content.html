Network Segmentation

Subnets: Logical Grouping and Security

Dividing your VNet's IP space to organize resources and apply policies.

Purpose of Subnets

Subnets are logical segments of your VNet's IP address space. They serve two primary purposes:

  • Logical Grouping: Organize resources based on function (e.g., web, app, database tiers).
  • Security Policies: Apply specific Network Security Groups (NSGs) to control traffic flow.
Analogy

A VNet is like a large corporate campus, and subnets are the individual buildings or departments within it, each with its own access rules and purpose.

Subnet Design Example

Web Subnet

For front-end web servers, accessible from the internet.

App Subnet

For application servers, communicating with web and database tiers.

DB Subnet

For database servers, with strict inbound access rules.

Key Takeaway

Subnets are vital for logically segmenting your VNet, enabling organized resource deployment and the application of granular security policies to different application tiers.
