Reserved IP Addresses in Subnets

Understanding which IP addresses Azure reserves for internal use.

Azure's IP Reservations

For every subnet you create, Azure automatically reserves 5 IP addresses for internal network management:

  • First 4 IP addresses: For network address, default gateway, and Azure DNS.
  • Last 1 IP address: For the subnet broadcast address.
Common Misconception

Assuming all IP addresses in a CIDR block are available for your resources. Always subtract 5 from the total count.

Impact on Usable IPs

This reservation reduces the number of available IP addresses for your resources. For example:

  • /24 Subnet: 256 total IPs - 5 reserved = 251 usable IPs.
  • Planning Impact: Always factor in these 5 reserved IPs when calculating subnet capacity.
Key Takeaway

Azure reserves 5 IP addresses per subnet for internal operations. Always subtract these from the total CIDR block size when planning your usable IP address space to avoid exhaustion.
