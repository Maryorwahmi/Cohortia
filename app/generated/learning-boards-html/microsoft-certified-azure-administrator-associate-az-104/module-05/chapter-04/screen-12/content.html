SNAT and DNAT: Network Address Translation in Azure Firewall

Understanding Source and Destination NAT for traffic flow.

Source Network Address Translation (SNAT)

  • Purpose: For outbound traffic from your VNet to the internet.
  • Mechanism: Translates private source IP addresses of VMs to the firewall's public IP.
Key Takeaway

SNAT handles outbound traffic by masking internal IPs with the firewall's public IP, while DNAT enables controlled inbound access to internal services.

Destination Network Address Translation (DNAT)

  • Purpose: For inbound traffic from the internet to services within your VNet.
  • Mechanism: Translates incoming public IP traffic to the private IP address of a resource behind the firewall.

Example: Exposing a Web Server

You have a web server at 10.0.1.4 on port 80. You configure a DNAT rule to translate incoming traffic to the firewall's public IP on port 80 to 10.0.1.4:80. This allows external users to access your web server.
