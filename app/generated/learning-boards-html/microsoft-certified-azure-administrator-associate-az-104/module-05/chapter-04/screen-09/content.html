Azure Firewall Policy and Rule Collections

Centralized management for consistent security across multiple firewalls.

What is a Firewall Policy?

  • Global Resource: A top-level resource for managing firewall configurations.
  • Centralized Management: Apply a single policy to multiple Azure Firewalls.
  • Rule Collections: Group Network or Application Rules for logical organization.
Key Takeaway

Firewall Policies provide a scalable way to manage consistent security rules across multiple Azure Firewalls from a single point.

Benefits for Enterprises

  • Consistent Security: Enforce uniform policies across all environments.
  • Simplified Management: Reduce operational overhead for large deployments.
  • Audit & Compliance: Easier to review and ensure adherence to security standards.

Example: Creating a Policy and Rule Collection

az network firewall policy create \
  --resource-group MyNetworkingRG \
  --name MyFirewallPolicy \
  --location eastus

az network firewall policy rule-collection-group network-collection create \
  --resource-group MyNetworkingRG \
  --policy-name MyFirewallPolicy \
  --name AllowRDPCollection \
  --priority 1000 \
  --action Allow \
  --rule-name AllowRDPToVM \
  --rule-protocols TCP \
  --rule-source-addresses '*' \
  --rule-destination-addresses 10.0.1.10 \
  --rule-destination-ports 3389
