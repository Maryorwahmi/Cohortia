Chapter Goals

Learning Objectives

Skills You'll Master in This Chapter

Bloom's Taxonomy:
LearnUnderstandApplyMaster
01

Describe Features & Benefits

Identify the core capabilities of Azure Firewall and understand its advantages as a managed network security service. This helps you choose the right security solution for different scenarios.

VERIFIED COMPETENCY MILESTONE
02

Plan & Deploy Firewall

Learn the prerequisites and steps for successfully deploying Azure Firewall into an Azure Virtual Network. This includes understanding the dedicated subnet requirements.

VERIFIED COMPETENCY MILESTONE
03

Configure Network & Application Rules

Master the creation and configuration of Network Rules and Application Rules to precisely control inbound and outbound traffic flow. This is key for granular security.

VERIFIED COMPETENCY MILESTONE
04

Integrate with Route Tables for Forced Tunneling

Understand how to use User-Defined Routes (UDRs) and route tables to force all outbound traffic through Azure Firewall for inspection. This ensures comprehensive security.

VERIFIED COMPETENCY MILESTONE
