Deployment Essentials

Deploying Azure Firewall: The AzureFirewallSubnet

A dedicated subnet is crucial for Azure Firewall functionality.

Subnet Requirements

  • Name: Must be exactly AzureFirewallSubnet.
  • Size: Must be exactly /26 (e.g., 10.0.0.0/26).
  • Exclusivity: No other resources can be deployed in this subnet.
Key Takeaway

The AzureFirewallSubnet with a strict /26 size is a non-negotiable prerequisite for Azure Firewall deployment.

Why a /26 Subnet?

The /26 subnet provides 64 IP addresses. Azure reserves the first few and last few, leaving enough for the firewall's internal components, including management and data plane interfaces, and allowing for future scaling. This size is optimized for the firewall's operational needs and ensures stability.

Common Mistake: Incorrect subnet size will cause deployment failure.

Example: Creating the Subnet

az network vnet subnet create \
  --resource-group MyNetworkingRG \
  --vnet-name MyVNet \
  --name AzureFirewallSubnet \
  --address-prefix 10.0.0.0/26

This Azure CLI command creates the necessary subnet within your existing Virtual Network.
