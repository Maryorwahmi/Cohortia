Network Rules: IP and Port Filtering

Traditional 5-tuple rules for granular traffic control.

Understanding Network Rules

  • 5-Tuple Filtering: Based on Source IP, Destination IP, Port, and Protocol.
  • Processing Order: Processed before Application Rules.
  • Protocols: Supports TCP, UDP, ICMP, and Any.
Key Takeaway

Network Rules are fundamental for controlling traffic based on IP addresses, ports, and protocols, acting as the first line of defense.

Example: Allowing RDP Access

To allow RDP (Remote Desktop Protocol) access to a specific virtual machine from your administrative workstation, you would create a Network Rule:

  • Source: Your workstation's public IP address.
  • Destination: The private IP address of your VM.
  • Port: 3389 (RDP default port).
  • Protocol: TCP.
  • Action: Allow.

Pro-Tip: Least Privilege

Always configure Network Rules with the principle of least privilege in mind. This means only allowing the minimum necessary traffic, rather than broad 'Any' rules, to reduce your attack surface.
