Common Mistakes and Safety Notes

Avoiding pitfalls and ensuring robust firewall security.

Common Mistakes to Avoid

  • Incorrect AzureFirewallSubnet size: Must be exactly /26.
  • Misconfigured Route Tables: Leads to traffic not routing or routing loops.
  • Ignoring Intra-subnet Traffic: NSGs are still primary for traffic within the same subnet.
Key Takeaway

Proper subnet sizing, correct UDR configuration, and understanding the scope of NSGs vs. Firewall are crucial to avoid common deployment and routing issues.

Safety Notes & Best Practices

  • Principle of Least Privilege: Only allow necessary traffic; default to deny.
  • Thorough Testing: Always test connectivity after rule or routing changes.
  • Log Integration: Use Azure Monitor and Sentinel for proactive threat detection.

Check Your Understanding

If a VM in a subnet with forced tunneling has an NSG allowing all outbound traffic, which security control takes precedence for internet traffic?

(Answer: Azure Firewall, because routing happens at the subnet level before NSG evaluation for internet-bound traffic.)
