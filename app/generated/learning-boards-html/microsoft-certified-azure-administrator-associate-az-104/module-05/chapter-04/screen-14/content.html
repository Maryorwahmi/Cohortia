Chapter Review

Key Concepts: Core Components

Essential terms and definitions from this chapter.

Azure Firewall

A managed, stateful, cloud-native network security service that provides centralized network protection for your Azure Virtual Networks.

AzureFirewallSubnet

The dedicated /26 subnet required within a VNet for Azure Firewall deployment, exclusively for the firewall.

Network Rules

Firewall rules based on 5-tuple (source IP, destination IP, port, protocol) for filtering traffic, processed before application rules.

Summary Takeaway

Azure Firewall provides centralized, stateful protection, requiring a specific subnet and utilizing Network Rules for IP/port-based traffic control.
