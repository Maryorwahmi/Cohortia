Initiatives: Grouping Policies for Scale

Collections of policy definitions for broader governance goals.

What are Initiatives?

Initiatives, or Policy Set Definitions, are logical groupings of multiple policy definitions. They allow you to manage and assign a comprehensive set of rules as a single unit.

  • Simplify Management: Assign one initiative instead of many individual policies.
  • Achieve Broader Goals: Combine policies for security, cost management, or operational excellence.
  • Consistent Application: Ensures all related rules are applied uniformly.
Key Takeaway

Use initiatives to streamline policy management and apply comprehensive governance frameworks efficiently.

Example: Azure Security Baseline

An initiative like "Azure Security Baseline" can include policies such as:

  • Enforce MFA: Requires multi-factor authentication for all users.
  • Encrypt Storage: Ensures all storage accounts use encryption.
  • Log Network Activity: Mandates logging for network security groups.
  • Restrict Public IPs: Prevents creation of public IP addresses on VMs.

Benefits of Using Initiatives

  • Reduced Administrative Overhead: Fewer assignments to manage.
  • Holistic Compliance: Ensures a complete set of rules is applied.
  • Improved Readability: Clearer understanding of governance goals.
