Policy Effects

Understanding Policy Effects

The actions Azure Policy takes when rules are met.

Deny

Prevents resource creation or update if it violates the policy rule. This is a hard stop for non-compliance.

Example

Block VMs deployed in unauthorized regions.

Audit

Warns about non-compliance but allows resource creation/update. Provides visibility without blocking.

Example

Report storage accounts not enforcing HTTPS.

DeployIfNotExists

Deploys a resource or configuration if a condition isn't met. Automates remediation.

Example

Add diagnostic settings to VMs if missing.

Modify

Changes properties of a resource to bring it into compliance. Requires a managed identity.

Example

Add a specific tag to resources if missing.

Key Takeaway

Choose the right effect to balance strict enforcement with operational flexibility and automated remediation.
