Creating a Custom Policy for Storage Encryption

Defining and deploying a custom policy via Azure CLI.

Steps Overview

  1. Create a dedicated Resource Group for the demo.
  2. Define the custom policy in a JSON file to audit storage encryption.
  3. Create the custom policy definition in Azure using Azure CLI.
Key Takeaway

The Azure CLI provides a powerful way to programmatically define and deploy custom policies for automated governance.

Azure CLI Commands
# 1. Create a Resource Group
RG_NAME="PolicyDemoRG"
LOCATION="eastus"
az group create --name $RG_NAME --location $LOCATION

# 2. Create Custom Policy Definition (audit-storage-encryption.json)
# (Content for this file is provided in the previous screen's JSON)

# 3. Create the Custom Policy Definition in Azure
POLICY_DEF_NAME="AuditStorageEncryption"
az policy definition create \
    --name $POLICY_DEF_NAME \
    --display-name "Audit Storage Accounts without Blob Service Encryption" \
    --description "Audits storage accounts that do not have encryption enabled for blob services." \
    --rules audit-storage-encryption.json \
    --mode Indexed
