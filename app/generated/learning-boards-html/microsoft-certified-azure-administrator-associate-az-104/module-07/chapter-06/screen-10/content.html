Custom Policy Example

Enforcing HTTPS for Storage Accounts

Creating a custom policy definition and assigning it via Azure CLI.

Policy Definition Explained

This JSON policy definition audits storage accounts that do not enforce HTTPS-only traffic. It targets Microsoft.Storage/storageAccounts and checks the supportsHttpsTrafficOnly property.

  • Target: Storage accounts (Microsoft.Storage/storageAccounts).
  • Condition: supportsHttpsTrafficOnly is false.
  • Effect: Audit (reports non-compliance). Change to Deny to block.
Key Takeaway

Custom policies allow precise control over resource configurations, enabling automated enforcement of security standards.

Custom Policy Definition (audit-https.json)
{
  "properties": {
    "displayName": "Storage accounts should use HTTPS only",
    "policyType": "Custom",
    "mode": "Indexed",
    "description": "This policy ensures that all storage accounts enforce HTTPS traffic only.",
    "policyRule": {
      "if": {
        "allOf": [
          {
            "field": "type",
            "equals": "Microsoft.Storage/storageAccounts"
          },
          {
            "field": "Microsoft.Storage/storageAccounts/supportsHttpsTrafficOnly",
            "equals": false
          }
        ]
      },
      "then": {
        "effect": "Audit"
      }
    }
  }
}
