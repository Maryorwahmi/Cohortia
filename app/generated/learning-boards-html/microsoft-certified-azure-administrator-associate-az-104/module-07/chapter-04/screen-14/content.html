Key Concepts

Advanced features and implementation terms

Adaptive Tuning

A feature of DDoS Protection Standard that learns an application's normal traffic patterns to accurately detect and mitigate attacks.

DDoS Protection Plan

A regional Azure resource that virtual networks are associated with to enable Azure DDoS Protection Standard.

Attack Analytics & Metrics

Detailed telemetry provided by DDoS Protection Standard during an attack, viewable in Azure Monitor.

Summary Takeaway

Adaptive tuning, protection plans, and attack analytics are key components for implementing and managing Azure DDoS Protection Standard effectively.
