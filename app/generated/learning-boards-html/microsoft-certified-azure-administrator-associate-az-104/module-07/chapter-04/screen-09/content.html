Onboarding Your Virtual Networks

Implementing Azure DDoS Protection Standard requires creating a plan and linking your virtual networks to it.

Step 1: Create DDoS Protection Plan

Establish a regional DDoS protection plan, which acts as the central policy container.

Step 2: Associate Virtual Network

Link your target virtual network to the created DDoS protection plan. All public IPs within that VNet are then protected.

Key Takeaway

DDoS Protection Standard is applied at the VNet level, protecting all public IP addresses within the associated virtual network.

Azure CLI Example
# Create DDoS Protection Planaz network ddos-protection create \    --resource-group DDoSProtectionDemoRG \    --name MyDDoSProtectionPlan \    --location eastus# Get the ID of the DDoS Protection PlanDDP_PLAN_ID=$(az network ddos-protection show \    --resource-group DDoSProtectionDemoRG \    --name MyDDoSProtectionPlan \    --query id \    --output tsv)# Update the VNet to be associated with the DDoS Protection Planaz network vnet update \    --resource-group DDoSProtectionDemoRG \    --name ProtectedVNet \    --ddos-protection-plan $DDP_PLAN_ID \    --enable-ddos-protection true
This code snippet demonstrates how to create a DDoS plan and link a virtual network.
