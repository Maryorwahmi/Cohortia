Command Walkthrough

Using `az keyvault secret show`

  • •Specify Vault & Secret: Use `--vault-name` and `--name` to identify the target secret.
  • •Default Output: Returns a JSON object with all secret properties.
  • •Extract Value: Use `--query value` to filter for only the secret's value.
  • •Plain Text Output: Add `--output tsv` to get the raw secret value, ideal for scripting.
Pro-Tip

When retrieving secrets programmatically in applications, use Azure SDKs with `DefaultAzureCredential` for the most secure and managed approach.

Key Takeaway

The `az keyvault secret show` command, especially with `--query value --output tsv`, enables secure and efficient retrieval of secret values from Key Vault for application use.

Azure CLI Terminal
# Retrieve a secret
az keyvault secret show --vault-name $KV_NAME --name $SECRET_NAME --query value --output tsv

# Output (example):
Server=tcp:mysqldb.database.windows.net,1433;Database=mydatabase;Uid=myuser;Pwd=mypassword;
Explanation

This command directly outputs the secret value, making it easy to capture in a script or environment variable for an application to consume. The `--output tsv` is crucial for getting just the raw value.
