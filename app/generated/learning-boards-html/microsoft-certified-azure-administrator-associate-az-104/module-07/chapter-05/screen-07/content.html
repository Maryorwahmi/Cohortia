Categorizing Sensitive Data

Key Vault Object Types

Secrets

Arbitrary strings of data, typically used for passwords, connection strings, or API keys.

Keys

Cryptographic keys for encryption, decryption, signing, and verification. Can be generated or imported.

Certificates

X.509 certificates, often used for TLS/SSL. Can be imported or generated and managed by Key Vault.

Key Takeaway

Azure Key Vault provides a versatile store for three distinct types of sensitive objects: Secrets for arbitrary data, Keys for cryptographic operations, and Certificates for secure communication.

Real-world Connection

A web application might store its database connection string as a 'Secret', use a 'Key' to encrypt user data, and manage its SSL/TLS 'Certificate' for HTTPS communication, all within Key Vault.
