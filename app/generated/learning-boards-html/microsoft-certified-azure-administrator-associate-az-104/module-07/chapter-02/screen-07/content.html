Associating NSGs: NICs and Subnets

Applying security at different network levels

Association Types

Subnet Association

Rules apply to ALL resources within that subnet. Provides broad network-level security.

NIC Association

Rules apply ONLY to the specific VM's Network Interface Card. Provides granular VM-specific control.

Dual Association Evaluation Order

  • IN

    Inbound Traffic: Subnet NSG rules processed first, then NIC NSG rules.

  • OUT

    Outbound Traffic: NIC NSG rules processed first, then Subnet NSG rules.

Key Takeaway

Understanding the distinct evaluation order for inbound and outbound traffic when NSGs are associated with both subnets and NICs is critical for effective security policy enforcement.

Common Mistake

Mismanaging NSG association, especially when applying NSGs to both a NIC and a subnet, can create complex rule evaluation paths and lead to unexpected traffic behavior. Always map out your intended flow.
