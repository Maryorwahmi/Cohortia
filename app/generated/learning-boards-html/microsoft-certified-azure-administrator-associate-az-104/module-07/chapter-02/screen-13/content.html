Hands-on Lab

Implementing NSGs and ASGs

Securing application tiers with custom rules

Activity Steps

  • •Create Application Security Groups (ASGs) for Web and DB tiers.
  • •Create Network Security Groups (NSGs) for Web and DB subnets.
  • •Associate NSGs with their respective subnets.
  • •Add inbound rules to WebSubnetNSG for HTTP/HTTPS from Internet to WebASG.
  • •Add inbound rule to DbSubnetNSG for SQL from WebASG to DbASG.
Key Takeaway

ASGs and NSGs combine to create a powerful, application-aware security posture, simplifying management and enhancing protection for multi-tier applications.

Azure CLI: ASG & NSG Configuration

# Create Application Security Groups (ASGs)
az network asg create --resource-group $RG_NAME --name WebASG --location $LOCATION
az network asg create --resource-group $RG_NAME --name DbASG --location $LOCATION

# Create NSG for Web Subnet & Associate
NSG_WEB_NAME="WebSubnetNSG"
az network nsg create --resource-group $RG_NAME --name $NSG_WEB_NAME
az network vnet subnet update --resource-group $RG_NAME --vnet-name $VNET_NAME --name $WEB_SUBNET_NAME --network-security-group $NSG_WEB_NAME

# Add Inbound HTTP/HTTPS rules to WebSubnetNSG
az network nsg rule create --resource-group $RG_NAME --nsg-name $NSG_WEB_NAME --name AllowHttpInbound --priority 100 --direction Inbound --access Allow --protocol Tcp --source-address-prefixes Internet --destination-asgs WebASG --destination-port-ranges 80
az network nsg rule create --resource-group $RG_NAME --nsg-name $NSG_WEB_NAME --name AllowHttpsInbound --priority 110 --direction Inbound --access Allow --protocol Tcp --source-address-prefixes Internet --destination-asgs WebASG --destination-port-ranges 443

# Create NSG for DB Subnet & Associate
NSG_DB_NAME="DbSubnetNSG"
az network nsg create --resource-group $RG_NAME --name $NSG_DB_NAME
az network vnet subnet update --resource-group $RG_NAME --vnet-name $VNET_NAME --name $DB_SUBNET_NAME --network-security-group $NSG_DB_NAME

# Add Inbound SQL rule to DbSubnetNSG
az network nsg rule create --resource-group $RG_NAME --nsg-name $NSG_DB_NAME --name AllowSqlFromWeb --priority 100 --direction Inbound --access Allow --protocol Tcp --source-asgs WebASG --destination-asgs DbASG --destination-port-ranges 1433
