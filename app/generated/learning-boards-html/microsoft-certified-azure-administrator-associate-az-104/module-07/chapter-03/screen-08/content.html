Rule Configuration

Configuring Application Rule Collections

Filtering HTTP/S traffic based on Fully Qualified Domain Names (FQDNs)

Application Rule Capabilities

  • FQDN-Based Filtering: Control access to specific websites and services.
  • HTTP/S Traffic: Specifically designed for web protocols.
  • Transparent Proxy: No client-side configuration needed for proxy settings.

Example: Allow Specific Outbound FQDNs

# Create an Application Rule Collection (Allow Outbound to specific FQDN)az network firewall application-rule create \    --resource-group $RG_NAME \    --firewall-name $FW_NAME \    --collection-name "OutboundAppRules" \    --action Allow \    --priority 100 \    --name "AllowMicrosoftUpdates" \    --protocols Http=80 Https=443 \    --source-addresses "*" \    --fqdn-tags "WindowsUpdate" # Or use --target-fqdns "www.microsoft.com"
Security Note

Always use the most restrictive FQDNs possible to minimize the risk of unauthorized web access or data exfiltration.

Key Takeaway

Application rules are critical for securing outbound web traffic, allowing you to precisely control access to FQDNs for HTTP/S protocols.
