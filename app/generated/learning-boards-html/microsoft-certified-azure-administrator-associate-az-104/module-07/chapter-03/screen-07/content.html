Rule Configuration

Configuring Network Rule Collections

Controlling Layer 3 and 4 traffic with precision

Network Rule Parameters

  • Source Addresses: IP addresses or ranges initiating the traffic.
  • Protocols: TCP, UDP, ICMP, or Any.
  • Destination Ports: Specific ports or ranges (e.g., 53, 22).
  • Destination Addresses: Target IP addresses or ranges.

Example: Allow Outbound DNS

# Create a Network Rule Collection (Allow Outbound DNS)az network firewall network-rule create \    --resource-group $RG_NAME \    --firewall-name $FW_NAME \    --collection-name "OutboundNetworkRules" \    --action Allow \    --priority 100 \    --name "AllowDNS" \    --protocols UDP \    --source-addresses "*" \    --destination-addresses "8.8.8.8", "8.8.4.4" \    --destination-ports 53
Pro-Tip

Use specific IP ranges and ports to minimize the attack surface. Avoid broad 'Any' rules unless absolutely necessary and justified.

Key Takeaway

Network rules are essential for controlling non-web traffic, enabling precise filtering based on IP addresses, protocols, and ports for services like DNS and SSH.
