Rule Management

Understanding Azure Firewall Rule Collections

Defining traffic filtering policies and processing order

Key Principles

  • Three Types: DNAT, Network, and Application rule collections.
  • Strict Order: DNAT rules first, then Network, then Application.
  • Priority within Collections: Lower number means higher precedence.
  • Implicit Deny: Traffic not explicitly allowed is blocked by default.

Rule Processing Flow

1. DNAT Rule Collection (Inbound Translation)
2. Network Rule Collection (L3/L4 Traffic)
3. Application Rule Collection (HTTP/S FQDN)
Common Mistake

Incorrectly assuming rule processing order can lead to traffic being unexpectedly blocked or allowed. Always remember DNAT -> Network -> Application.

Key Takeaway

Mastering the rule collection types and their processing order is fundamental to effectively securing your Azure network with Azure Firewall.
