Deploying Azure Firewall: The Dedicated Subnet

Critical requirements for successful firewall provisioning

Subnet Requirements

  • Mandatory Name: The subnet MUST be named AzureFirewallSubnet.
  • Exact Size: The subnet address prefix MUST be exactly /26.
  • Dedicated Use: No other resources can be deployed into this subnet.

Example: Creating the Subnet (Azure CLI)

# Create AzureFirewallSubnet (CRITICAL: Must be /26)az network vnet subnet create \    --resource-group $RG_NAME \    --vnet-name $VNET_NAME \    --name AzureFirewallSubnet \    --address-prefix 10.0.0.0/26
Common Mistake

Using an incorrect subnet name or size will cause deployment to fail. Always verify AzureFirewallSubnet and /26.

Key Takeaway

The AzureFirewallSubnet with a /26 prefix is a non-negotiable requirement for Azure Firewall deployment, ensuring its proper operation and integration.
