Azure Firewall vs. NSGs: When to Use Which

Understanding the distinct roles in network security

Azure Firewall

  • Centralized: Single point of control for entire VNet.
  • Stateful: Tracks connection states.
  • Advanced Features: FQDN filtering, threat intelligence.
  • Use Case: Perimeter security, hub-and-spoke, outbound internet.

Network Security Groups (NSGs)

  • Decentralized: Applied at NIC or subnet level.
  • Stateful: Also tracks connection states.
  • Basic Filtering: IP, port, protocol. No FQDN.
  • Use Case: Micro-segmentation, internal VNet traffic.
Key Takeaway

For comprehensive security, combine Azure Firewall for perimeter defense and centralized control with NSGs for granular internal network segmentation.
