Implementing DNAT Rules for Inbound Access

Translating public IP addresses to private resources

How DNAT Works

  • Inbound Traffic: Specifically for connections originating from outside your VNet.
  • IP Translation: Maps firewall's public IP/port to internal private IP/port.
  • Security Layer: Hides internal network topology from external users.

Example: Exposing a Web Server

Internet User (Public IP)
Azure Firewall (Public IP: 20.1.2.3, Port: 443)
Web Server (Private IP: 10.0.1.4, Port: 443)
Key Takeaway

DNAT rules are crucial for securely exposing internal services to the internet, translating public IP requests to private resources while maintaining network isolation.
