Key Concepts

Essential terms to remember from this chapter

Azure Firewall

A fully managed, stateful network firewall as a service that provides centralized network security for Azure Virtual Networks.

AzureFirewallSubnet

The dedicated subnet (must be /26) required for deploying an Azure Firewall instance within your virtual network.

DNAT Rule Collection

Rules used to translate inbound public IP addresses to private IP addresses for resources behind the firewall, enabling secure external access.

Summary Takeaway

Azure Firewall provides centralized, stateful network security, requiring a specific subnet for deployment and utilizing DNAT rules for inbound traffic translation.
