Network Security

Restricting Access with Storage Account Firewalls

Controlling network access based on IP addresses or ranges.

Key Idea

Storage account firewalls act as a perimeter defense, allowing access only from specified IP addresses or virtual networks.

Core Action

By default, storage accounts are publicly accessible. Firewalls allow you to change this to a 'deny by default' posture.

Pro Tip

Always follow the principle of least privilege: only allow access from the absolute minimum required IP addresses or VNet subnets.

# Deny all public network access by default
az storage account update \
  --name <your-storage-account-name> \
  --resource-group az104storage-rg \
  --default-action Deny
# Allow access from a specific IP address
az storage account network-rule add \
  --account-name <your-storage-account-name> \
  --resource-group az104storage-rg \
  --ip-address 203.0.113.45
Expected Outcome

After denying default access, only requests from the whitelisted IP address (e.g., 203.0.113.45) will succeed. All other public access attempts will be blocked, enhancing security.
