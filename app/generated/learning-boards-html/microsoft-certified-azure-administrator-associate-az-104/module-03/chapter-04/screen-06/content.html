Protecting Data at Rest with SSE and CMK

Understanding default and customer-managed encryption options.

Key Idea

Azure Storage ensures data confidentiality by encrypting all data at rest, offering both Microsoft-managed and customer-managed key options.

Storage Service Encryption (SSE)

  • •Default Encryption: Automatically encrypts all data at rest.
  • •Microsoft-Managed Keys: Keys are managed by Microsoft.
  • •Transparent: No action required from the user.
  • •Baseline Security: Provides a strong, automatic layer of protection.

Customer-Managed Keys (CMK)

  • •User-Provided Keys: You supply your own encryption keys.
  • •Azure Key Vault: Keys are stored and managed securely here.
  • •Full Control: You manage key lifecycle (rotation, revocation).
  • •Compliance: Ideal for specific regulatory requirements.
