Delegated Access with Shared Access Signatures

Granting temporary, granular permissions without full account keys.

Key Idea

Shared Access Signatures provide a secure way to grant limited, time-bound access to specific storage resources for external clients or applications.

Core Concept

A Shared Access Signature (SAS) is a URI that grants restricted access rights to Azure Storage resources. It allows you to grant access for a specified period of time and with specific permissions.

Use Case

A mobile app needs to upload user photos directly to a blob container without exposing the storage account's primary key. A SAS token can be generated for this specific task.

SAS Token Structure

Resource URI

The specific storage resource (blob, container, queue, table) to be accessed.

Permissions

Read, write, delete, list, add, create, update, process.

Expiry & Start Time

The duration for which the SAS token is valid.

Signature

A hash of the SAS fields, ensuring authenticity.

Always use User Delegation SAS for enhanced security.
