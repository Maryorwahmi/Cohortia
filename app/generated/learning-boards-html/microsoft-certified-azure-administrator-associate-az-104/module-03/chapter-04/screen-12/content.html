Optimizing Data with Replication and Lifecycle Management

Ensuring redundancy, compliance, and cost efficiency.

Key Idea

Object Replication ensures data redundancy, while Data Lifecycle Management optimizes storage costs and enforces compliance policies.

Object Replication

Replicates block blobs between source and destination storage accounts, typically for cross-region redundancy and disaster recovery.

DLM Benefits

Automates data tiering (Hot, Cool, Archive) and deletion, reducing costs and ensuring compliance with data retention policies.

# Example Lifecycle Management Policy (JSON)
{
  "rules": [
    {
      "enabled": true,
      "name": "MoveToCoolAndArchive",
      "type": "Lifecycle",
      "definition": {
        "actions": {
          "baseBlob": {
            "tierToCool": { "daysAfterModificationGreaterThan": 30 },
            "tierToArchive": { "daysAfterModificationGreaterThan": 90 }
          }
        },
        "filters": {
          "blobTypes": ["blockBlob"],
          "prefixMatch": ["mycontainer/logs"]
        }
      }
    }
  ]
}
Policy Explanation

This policy moves block blobs in 'mycontainer/logs' to the Cool tier after 30 days of modification, then to Archive after 90 days, optimizing storage costs.
