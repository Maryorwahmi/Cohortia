Creating Containers via Azure Portal

A guided walkthrough for setting up your blob storage.

1.

Navigate to Storage Account

In the Azure portal, find your storage account and select 'Containers' under 'Data storage'.

2.

Click '+ Container'

Initiate the creation process by clicking the button to add a new container.

3.

Provide Name & Access Level

Enter a unique name (lowercase, 3-63 chars) and choose an access level.

Container Access Levels

  • Private (no anonymous access): Default and most secure. Only authenticated users.
  • Blob (anonymous read access for blobs only): Public read access to blobs, not container.
  • Container (anonymous read access for containers and blobs): Public read access to blobs and container list.
Best Practice

Start with Private access and only grant more permissive access if absolutely necessary and with careful consideration.

Key Takeaway

The Azure portal simplifies container creation, but always prioritize security by choosing the least permissive access level first.
