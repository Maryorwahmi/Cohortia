Uploading and Downloading Blobs

Essential operations for moving data to and from Blob Storage.

# Upload a block blob
az storage blob upload \
--container-name myprivatecontainer \
--file myimage.jpg \
--name myimage.jpg \
--type block
Upload Explanation

The --file parameter specifies the local path, while --name is the blob's name in Azure. --type block is standard for general files.

# Download a blob
az storage blob download \
--container-name myprivatecontainer \
--name myimage.jpg \
--file ./downloaded_myimage.jpg
Download Explanation

The --name parameter refers to the blob in Azure, and --file specifies the local path to save the downloaded content.

Key Takeaway

Mastering upload and download commands is fundamental for moving your data efficiently between your local environment and Azure Blob Storage.
