Secure Access with Shared Access Signatures (SAS)

Granting restricted, time-limited access to your storage resources.

What is a SAS?

A Shared Access Signature (SAS) is a URI that grants restricted access rights to your Azure Storage resources.

  • Granular Control: Specify resources, permissions, and duration.
  • Enhanced Security: Avoids distributing sensitive storage account keys.
  • Principle of Least Privilege: Grant only necessary access.
Key Takeaway

SAS is a critical security feature for granting temporary, controlled access to your Azure Storage without compromising your main account keys.

Types of SAS

  • User delegation SAS: Secured with Azure AD credentials. Recommended for superior security.
  • Service SAS: Secured with the storage account key. Delegates access to a resource in one storage service (e.g., Blob).
  • Account SAS: Secured with the storage account key. Delegates access to resources across one or more storage services.
Common Mistake

Creating overly permissive SAS tokens (too many permissions, too long expiry) can pose a significant security risk.
