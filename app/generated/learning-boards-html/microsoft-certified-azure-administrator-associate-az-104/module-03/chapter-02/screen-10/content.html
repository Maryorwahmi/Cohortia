Deleting Blobs and Managing Properties

Maintaining data hygiene and understanding blob metadata.

# Delete a blob
az storage blob delete \
--container-name myprivatecontainer \
--name myimage.jpg
Caution

Blob deletion is permanent. Always ensure you have appropriate backup strategies in place before deleting critical data.

Blob Properties & Metadata

  • System Properties: Automatically maintained by Azure (e.g., size, last modified, content type).
  • Custom Metadata: User-defined key-value pairs providing additional context (e.g., 'author', 'project').
  • Purpose: Useful for organizing, searching, and programmatic management without inspecting content.
Key Takeaway

Beyond deletion, leveraging blob properties and custom metadata is key for sophisticated data management and organization.
