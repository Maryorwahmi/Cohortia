Three Types of Blobs

Each optimized for specific data storage and access patterns.

Block Blobs

Ideal for storing text or binary files, composed of blocks of data managed individually.

  • Use Cases: Documents, media files, backups.
  • Size: Up to 190.7 TiB.
  • Operations: Efficient for large file uploads.

Page Blobs

Optimized for random read and write operations, used for virtual hard drive (VHD) files.

  • Use Cases: Azure IaaS VM VHDs.
  • Size: Up to 8 TiB.
  • Operations: Efficient byte-range updates.

Append Blobs

Optimized for append operations, where new blocks are only added to the end.

  • Use Cases: Logging scenarios (IoT, web server logs).
  • Operations: Continuous data writing.
Key Takeaway

Choosing the correct blob type is crucial for optimizing performance and cost based on your data's access patterns and intended use.
