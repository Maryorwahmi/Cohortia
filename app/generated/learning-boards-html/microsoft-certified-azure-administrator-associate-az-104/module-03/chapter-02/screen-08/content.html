Creating Containers via Azure CLI

Automating container creation with command-line efficiency.

# Set environment variables for convenience
export AZURE_STORAGE_ACCOUNT=<your-unique-storage-account-name>
export AZURE_STORAGE_KEY=<your-storage-account-key>
# Create a container with private access
az storage container create \
--name myprivatecontainer \
--public-access off

Command Breakdown

  • az storage container create: The core command to create a new container.
  • --name: Specifies the desired name for your new container.
  • --public-access off: Sets the container to private, preventing anonymous access.
Key Takeaway

The Azure CLI provides a robust, scriptable method for creating containers, essential for automation and maintaining infrastructure as code.
