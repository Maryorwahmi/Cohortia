Blob Access Tiers for Cost Optimization

Aligning storage costs with data access frequency.

Hot Access Tier

Optimized for frequently accessed data.

  • Storage Costs: Highest
  • Access Costs: Lowest
  • Ideal For: Actively used data, web content.

Cool Access Tier

For infrequently accessed data (stored for >30 days).

  • Storage Costs: Lower than Hot
  • Access Costs: Higher than Hot
  • Ideal For: Short-term backups, older media.

Archive Access Tier

For rarely accessed data (stored for >180 days), with flexible latency.

  • Storage Costs: Lowest
  • Access Costs: Highest (with latency)
  • Ideal For: Long-term backups, compliance data.
Key Takeaway

Selecting the appropriate access tier is crucial for optimizing storage costs by aligning with your data's access frequency and retention policies.
