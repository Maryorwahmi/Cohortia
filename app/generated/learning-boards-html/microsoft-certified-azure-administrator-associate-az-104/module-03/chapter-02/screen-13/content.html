Generating a User Delegation SAS via CLI

A secure, step-by-step process for granting temporary access.

# First, get a user delegation key (valid for a limited time)
# Requires Azure AD login with appropriate RBAC permissions
start=$(date -u -d "5 minutes ago" '+%Y-%m-%dT%H:%MZ')
expiry=$(date -u -d "1 hour" '+%Y-%m-%dT%H:%MZ')
key_info=$(az storage account generate-user-delegation-key \
--account-name $AZURE_STORAGE_ACCOUNT \
--resource-group az104storage-rg \
--start $start \
--expiry $expiry \
--query "{value:value}" -o tsv)
# Now, use the user delegation key to generate a SAS token for a specific blob
sas_token=$(az storage blob generate-sas \
--account-name $AZURE_STORAGE_ACCOUNT \
--container-name myprivatecontainer \
--name myimage.jpg \
--permissions r \
--expiry $expiry \
--auth login \
--as-user \
--query "value" -o tsv)
echo "SAS Token: $sas_token"
echo "Full Blob URL with SAS: https://$AZURE_STORAGE_ACCOUNT.blob.core.windows.net/myprivatecontainer/myimage.jpg?$sas_token"

SAS Generation Steps

  • Step 1: Generate a user delegation key (requires Azure AD login and RBAC permissions).
  • Step 2: Use the key to generate the SAS token for a specific blob/container, defining permissions and expiry.
  • Result: A secure URL for temporary, restricted access without exposing account keys.
Key Takeaway

User delegation SAS is the most secure way to grant temporary access to blobs, leveraging Azure AD for authentication and granular control.
