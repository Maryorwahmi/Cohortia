Key Concepts

Expanding your understanding of file synchronization

Azure File Sync

A service that centralizes your organization's file shares in Azure Files while maintaining on-premises file server performance and compatibility.

Sync Group

Defines the synchronization topology, linking a cloud endpoint (Azure File share) with one or more server endpoints (paths on registered Windows Servers).

Cloud Tiering

A feature that moves infrequently accessed files from the local server cache to Azure Files, recalling them on demand to optimize local storage.

Summary Takeaway

Azure File Sync, with its sync groups and cloud tiering, provides a robust hybrid solution for centralizing file shares in Azure while optimizing local storage and access.
