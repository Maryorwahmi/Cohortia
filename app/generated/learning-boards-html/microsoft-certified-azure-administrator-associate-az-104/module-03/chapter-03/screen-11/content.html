Module 3›Chapter 3.3›Dissecting Azure File Sync Components
Component 1

Storage Sync Service

The top-level Azure resource for Azure File Sync. It manages server registrations and sync groups, acting as the central hub for your synchronization deployments.

Component 2

Sync Group

Defines the sync topology, linking a cloud endpoint (Azure File share) with one or more server endpoints (paths on registered Windows Servers). All endpoints are kept in sync.

Component 3

Cloud Endpoint

An Azure File share that acts as the source of truth for the sync group. It's where your centralized cloud data resides.

Component 4

Server Endpoint

A specific path on a registered Windows Server (e.g., D:\Data) that you want to sync with the Azure File share. This is your local cache.

Component 5

Azure File Sync Agent

A downloadable software package installed on your Windows Server to enable synchronization. It monitors changes and facilitates data transfer.

Key Takeaway

Azure File Sync relies on interconnected components—Storage Sync Service, Sync Groups, Endpoints, and the Agent—to establish and maintain seamless hybrid file synchronization.
