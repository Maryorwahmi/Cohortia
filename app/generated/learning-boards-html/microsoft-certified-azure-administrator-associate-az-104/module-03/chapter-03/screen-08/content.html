Module 3›Chapter 3.3›Mounting Azure File Shares on Windows
Mounting Steps

Connecting via `net use`

  1. Navigate to your storage account in the Azure portal.
  2. Select "File shares" under "Data storage".
  3. Click on your specific file share.
  4. Click "Connect" and select "Windows".
  5. Choose a drive letter and copy the provided script.
  6. Run the script from an elevated PowerShell or Command Prompt.
Security Note

Using the storage account access key directly for mounting production file shares is a security risk. Consider Azure AD DS integration for identity-based authentication.

PowerShell Command Example
net use Z: \\<your-unique-storage-account-name>.file.core.windows.net\myshare /user:AZURE\<your-unique-storage-account-name> <your-storage-account-key>
Command Breakdown
  • net use Z:: Assigns drive letter Z.
  • \\<account>.file.core.windows.net\myshare: The UNC path to your Azure File share.
  • /user:AZURE\<account>: Specifies the username for authentication.
  • <key>: Your storage account access key (password).
Key Takeaway

Mounting Azure File shares on Windows is achieved using the `net use` command, but always prioritize identity-based authentication over direct access keys for production security.
