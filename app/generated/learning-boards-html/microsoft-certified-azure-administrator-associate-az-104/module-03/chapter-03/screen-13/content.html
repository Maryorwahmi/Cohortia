What is Cloud Tiering?

Dynamic File Placement

Cloud tiering allows frequently accessed files to be cached locally on the server, while less frequently accessed files are seamlessly tiered to Azure Files. This reduces local storage footprint.

Consideration

Be mindful of rehydration cost and latency for archived files. Plan your tiering policies carefully based on access patterns to avoid unexpected delays or charges.

How it Works
  • Local Cache: Hot data remains on the local server for fast access.
  • Cloud Archival: Cold data is moved to Azure Files, freeing up local space.
  • Seamless Recall: Tiered files are automatically recalled from Azure when accessed.
Configuration: Based on free space percentage or date policy.
Key Takeaway

Cloud tiering optimizes local storage by intelligently moving infrequently accessed files to Azure, reducing costs and space while maintaining transparent user access.
