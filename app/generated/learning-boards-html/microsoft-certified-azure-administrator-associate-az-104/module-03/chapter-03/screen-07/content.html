Step-by-Step Guide

Using Azure CLI to Create a File Share

  1. Ensure you have your storage account name and resource group.
  2. Use the `az storage share create` command.
  3. Specify the share name, account name, and quota.
  4. Verify creation with the output table.
Prerequisite: An existing Azure Storage Account (General-purpose v2).
Common Mistake

Forgetting that storage account names must be globally unique, or using a storage account kind that doesn't support file shares (e.g., BlobStorage only).

Azure CLI Command
# Create a file share named 'myshare' with a 100 GiB quota in a Standard storage account
az storage share create \
--name myshare \
--account-name <your-unique-storage-account-name> \
--quota 100 \
--output table
Expected Output (Table Format)
Name QuotaGiB EnabledProtocols AccessTier ShareUsageBytes SnapshotCount
--------- -------- ---------------- ---------- --------------- -------------
myshare 100 SMB Transaction_Optimized 0 0
Key Takeaway

The Azure CLI provides a powerful, scriptable method for creating Azure File shares, allowing you to define name, associated storage account, and quota efficiently.
