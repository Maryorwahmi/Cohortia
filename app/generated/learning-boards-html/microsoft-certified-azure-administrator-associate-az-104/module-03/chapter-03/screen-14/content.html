Module 3›Chapter 3.3›High-Level Azure File Sync Deployment
1

Deploy Storage Sync Service

Create the top-level Azure resource in your subscription to manage sync deployments.

2

Register Windows Server

Install the Azure File Sync agent on your on-premises server and register it with the Storage Sync Service.

3

Create a Sync Group

Define the sync topology by creating a sync group and specifying your Azure File share as the cloud endpoint.

4

Add a Server Endpoint

Within the sync group, add a server endpoint by selecting your registered server and the local path to sync.

Key Takeaway

Azure File Sync deployment follows a logical sequence: deploy the service, register servers, create sync groups, and define server endpoints to establish hybrid file synchronization.
