Data Protection

Redundancy Options: LRS & ZRS

Ensuring data durability within a single region.

Locally Redundant Storage (LRS)
  • Data copied 3x within a single physical location
  • Protects against component failures (e.g., disk)
  • Least expensive option
Zone-Redundant Storage (ZRS)
  • Data copied 3x across Availability Zones in primary region
  • Protects against datacenter-level failures
  • Higher durability and availability within a region
Key Takeaway

LRS offers basic protection within a single location, while ZRS provides enhanced resilience by distributing data across multiple physical zones.

Regional Redundancy

LRS vs. ZRS within a Region

LRS (Locally Redundant)
  • 3 copies in one datacenter
  • Protects against hardware failure
  • No protection against datacenter outage
ZRS (Zone-Redundant)
  • 3 copies across 3 Availability Zones
  • Protects against datacenter outage
  • Higher availability within region
ZRS offers superior protection against regional datacenter failures compared to LRS.
