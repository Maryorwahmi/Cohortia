Storage Account Access Keys: Handle with Care

Powerful credentials granting full administrative access.

What are Access Keys?
  • Two 512-bit keys (key1, key2) per storage account
  • Grant full administrative control over all data
  • Equivalent to root passwords
Security Implications & Mistakes
  • **Never** hardcode in applications or public repos.
  • **Never** embed in client-side code.
  • Major security vulnerability if compromised.
Key Takeaway

Access keys are highly sensitive; use Shared Access Signatures (SAS) or Azure AD RBAC for granular, secure application access instead.

Bash Terminal
# Retrieve the storage account access keys
az storage account keys list \
  --account-name myuniqueaz104storage \
  --resource-group myStorageRG \
  --output table

# Expected output:
# KeyName    Value                                                                      Permissions
# ---------  -------------------------------------------------------------------------  -------------
# key1       xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx  Full
# key2       yyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyyy  Full

# Important Security Note:
# These keys grant full administrative access. Treat them like root passwords.
# Never embed them directly in client-side code or public repositories.
# For application access, use Shared Access Signatures (SAS) or Azure AD RBAC.
**Warning:** Access keys are highly sensitive. Never expose them publicly.
