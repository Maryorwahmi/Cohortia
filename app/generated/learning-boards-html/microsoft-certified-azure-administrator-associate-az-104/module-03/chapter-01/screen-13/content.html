Creating a Storage Account via Azure CLI

Provisioning a General-purpose v2 storage account with GRS redundancy.

CLI Commands Overview
  • `az group create`: Creates a resource group.
  • `az storage account create`: Provisions the storage account.
  • `--sku Standard_GRS`: Specifies Geo-Redundant Storage.
  • `--kind StorageV2`: Sets account type to General-purpose v2.
Best Practice Highlight

Always disable public access to blobs by default (`--allow-blob-public-access false`) for enhanced security.

Key Takeaway

The Azure CLI provides a powerful, scriptable way to create and configure storage accounts, enabling automation and adherence to best practices.

Bash Terminal
# Ensure you are logged in to Azure CLI: az login

# 1. Create a resource group if you don't have one
az group create \
  --name myStorageRG \
  --location eastus

# Expected output:
# {
#   "id": "/subscriptions/.../resourceGroups/myStorageRG",
#   "location": "eastus",
#   "name": "myStorageRG",
#   "properties": {
#     "provisioningState": "Succeeded"
#   },
#   "tags": null,
#   "type": "Microsoft.Resources/resourceGroups"
# }

# 2. Create a GPv2 storage account with GRS redundancy
az storage account create \
  --name myuniqueaz104storage \
  --resource-group myStorageRG \
  --location eastus \
  --sku Standard_GRS \
  --kind StorageV2 \
  --allow-blob-public-access false
