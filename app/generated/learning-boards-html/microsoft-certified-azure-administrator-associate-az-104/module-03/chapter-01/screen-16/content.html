Key Concepts

Essential terms to remember

Azure Storage Account

A central container grouping Azure Storage data services like Blob, File, Table, and Queue.

Azure Blob Storage

Object storage for massive amounts of unstructured data like images, videos, and backups.

Azure File Storage

Fully managed file shares accessible via industry-standard SMB or NFS protocols.

Azure Table Storage

A NoSQL key/attribute store for structured, non-relational data with flexible schemas.

Azure Queue Storage

A reliable messaging service for asynchronous communication between application components.

General-purpose v2 (GPv2)

The recommended, flexible storage account type supporting all services and features with optimal pricing.

Summary Takeaway

Azure Storage Accounts offer a versatile suite of services, each tailored for specific data needs, with GPv2 being the modern standard for comprehensive storage solutions.
