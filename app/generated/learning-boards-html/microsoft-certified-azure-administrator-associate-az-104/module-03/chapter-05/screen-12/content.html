Offline Migration

Azure Data Box Family

Physical appliances for large-scale, offline data transfers.

Why Use Data Box?

  • Bypass Network Constraints: Ideal for limited bandwidth scenarios.
  • Large-Scale Transfers: Designed for terabytes to petabytes of data.
  • Secure: Data is encrypted during transit and at rest.
  • Efficient: Significantly faster than online transfers for bulk data.
Key Takeaway

The Azure Data Box family provides physical appliances for secure, high-volume offline data migration, effectively overcoming network bandwidth limitations for large datasets.

Data Box Family Options

Data Box Disk

Capacity: 8 TB to 40 TB

Multiple SSDs for smaller, large-scale transfers.

Data Box

Capacity: 20 TB to 80 TB

Ruggedized appliance for medium-large transfers.

Data Box Heavy

Capacity: 500 TB to 1 PB

Massive capacity for petabyte-scale migrations.

Pro-Tip

Always estimate your data volume accurately to select the most cost-effective and appropriately sized Data Box appliance for your migration.
