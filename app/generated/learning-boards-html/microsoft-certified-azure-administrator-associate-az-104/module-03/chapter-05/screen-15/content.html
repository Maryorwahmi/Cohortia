Key Concepts: Data Migration

Essential terms for moving data to Azure

Message

Data unit stored in a queue, up to 64 KB.

AzCopy

Command-line utility for high-performance data transfer to/from Azure Storage.

Azure Storage Explorer

Graphical desktop tool for managing Azure Storage resources.

Azure Data Box

Family of physical appliances for large-scale offline data migration.

Azure Data Factory

Cloud data integration service for complex, recurring data workflows.

Azure Import/Export

Service for importing/exporting large data using physical disk drives.

Chapter Summary

Efficient data migration to Azure relies on tools like AzCopy for online transfers, Azure Storage Explorer for graphical management, Azure Data Box for offline bulk transfers, and Azure Data Factory/Import/Export for advanced scenarios.
