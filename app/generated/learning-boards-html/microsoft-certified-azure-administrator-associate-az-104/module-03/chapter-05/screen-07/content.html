Managing Tables and Entities with Azure CLI

Practical steps to create tables, insert, and query entities.

Key CLI Commands

  • az storage table create: Creates a new table in your storage account.
  • az storage entity insert: Adds a new entity (row) to a specified table.
  • az storage entity query: Retrieves entities based on specified filters.
  • PartitionKey & RowKey: Essential for uniquely identifying and organizing entities.
Key Takeaway

The Azure CLI provides robust commands for creating tables, inserting entities with Partition and Row Keys, and querying data in Azure Table Storage.

# Set environment variables
export AZURE_STORAGE_ACCOUNT=<your-account-name>
export AZURE_STORAGE_KEY=<your-storage-key>

# Create a table
az storage table create \
  --name mycustomers \
  --account-name $AZURE_STORAGE_ACCOUNT

# Add an entity (USA partition)
az storage entity insert \
  --table-name mycustomers \
  --entity PartitionKey=USA RowKey=CUST001 Name=Alice City=NewYork \
  --account-name $AZURE_STORAGE_ACCOUNT

# Add another entity (Canada partition)
az storage entity insert \
  --table-name mycustomers \
  --entity PartitionKey=Canada RowKey=CUST003 Name=Charlie City=Toronto \
  --account-name $AZURE_STORAGE_ACCOUNT

# Query entities by Partition Key
az storage entity query \
  --table-name mycustomers \
  --filter "PartitionKey eq 'USA'" \
  --account-name $AZURE_STORAGE_ACCOUNT \
  --output table
