Key Concepts

Essential terms to remember from this chapter

Microsoft Entra ID

Microsoft's cloud-based identity and access management service.

Tenant

A dedicated instance of Microsoft Entra ID for an organization, isolated from others.

Directory

The container within a tenant that holds all user, group, and application objects.

Summary Takeaway

Microsoft Entra ID is the cloud-based identity service, with each organization having its own isolated tenant containing its directory of users, groups, and applications.
