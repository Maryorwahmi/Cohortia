Key Concepts

Advanced features and tools to remember

Single Sign-On (SSO)

Log in once to access multiple connected applications without re-authenticating.

Multi-Factor Authentication (MFA)

Requires more than one method of authentication to verify a user's identity.

Microsoft Entra Connect

A tool that synchronizes on-premises AD DS identities with Microsoft Entra ID.

Summary Takeaway

SSO and MFA are key features for secure and seamless access, while Entra Connect facilitates hybrid identity management.
