Key Concepts

Essential terms for external identities.

External Identities

Users from outside your organization's Microsoft Entra ID tenant.

Azure B2B Collaboration

A Microsoft Entra ID feature to invite guest users from other organizations to access resources in your tenant.

Guest User

An external user account created in your Microsoft Entra ID tenant via B2B collaboration, linked to their home identity provider.

Summary Takeaway

Understanding external identities, Azure B2B collaboration, and the concept of a guest user forms the foundation for secure and efficient cross-organizational access.
