The Secure Invitation Mechanism

How external users join your tenant.

1. Admin Invites Guest

Administrator sends an invitation via Azure portal, CLI, or PowerShell.

2. Guest Receives Email

Guest user gets an invitation email with a unique redemption link.

3. Guest Redeems Invitation

Guest clicks the link, authenticates with their home IDP, and gains access.

Security Highlight

Authentication is handled by the guest's home identity provider, ensuring their credentials remain secure and separate from your tenant.

Key Takeaway

Microsoft Entra ID creates a linked user object for guests, managing authorization within your tenant while delegating authentication to their existing identity provider.
