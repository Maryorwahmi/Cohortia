Step-by-Step: Inviting a Guest User

A practical guide using the Azure portal.

01

Navigate to Users

Go to Microsoft Entra admin center > Users > All users > New user > Invite external user.

02

Provide Guest Details

Enter the guest's email address, a display name, and an optional personal message.

03

Assign Groups/Roles (Optional)

You can assign groups or roles during invitation, but often better to do so after acceptance.

04

Review and Invite

Click 'Review + invite' then 'Invite' to send the invitation email to the guest user.

Key Takeaway

The Azure portal provides a guided, secure process for inviting external users, allowing for clear identification and initial access configuration.
