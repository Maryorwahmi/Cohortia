Common Built-in Azure Roles

Understanding predefined permissions for typical scenarios.

Owner

Full access to all resources, including the ability to delegate access. Highly privileged, use sparingly.

Contributor

Full access to all resources, but cannot delegate access. Suitable for resource managers.

Reader

View all resources, but cannot make any changes. Ideal for monitoring or auditing.

User Access Administrator

Manage user access to Azure resources, including assigning and removing roles.

Virtual Machine Contributor

Manage virtual machines, but not the virtual network or storage account they're connected to.

Storage Blob Data Contributor

Read, write, and delete Azure Storage blob containers and blobs. Data plane access.

Key Takeaway

Azure's built-in roles provide predefined permission sets for common scenarios, simplifying access management and supporting the principle of least privilege without needing custom definitions for every task.
