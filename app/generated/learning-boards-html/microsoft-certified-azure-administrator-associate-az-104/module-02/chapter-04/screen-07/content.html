The "Where": Scope of Access

Specifying the hierarchical boundaries for RBAC assignments.

What is Scope?

Scope specifies the resource or set of resources to which an RBAC assignment applies. Azure resources are organized hierarchically, and permissions inherit down this structure.

  • •The 'where' in an RBAC assignment.
  • •Determines the reach of permissions.
  • •Inheritance simplifies management but requires caution.

Example: Subscription vs. Resource Group

Assigning 'Reader' role at the subscription level grants view access to ALL resources in that subscription. Assigning it at a resource group level limits view access to only resources within that specific group.

Key Takeaway

Scope defines where an RBAC assignment applies within Azure's hierarchical structure, with permissions inheriting down from higher levels, requiring careful consideration for least privilege.
