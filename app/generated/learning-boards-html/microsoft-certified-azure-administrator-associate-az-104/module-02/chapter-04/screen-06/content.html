The "What": Role Definition

Defining the specific actions a security principal can perform.

What is a Role Definition?

A Role Definition is a collection of permissions. It defines the set of actions that a security principal can perform on Azure resources, acting as the 'what' in an RBAC assignment.

  • •Specifies allowed operations.
  • •Can include `Actions` and `NotActions`.
  • •Can be built-in or custom.

Example: Virtual Machine Reader

A role definition might include the permission Microsoft.Compute/virtualMachines/read. This allows the assigned principal to view virtual machine properties but not to create, update, or delete them.

Actions

Specific operations that are permitted, e.g., Microsoft.Storage/storageAccounts/write.

NotActions

Specific operations that are explicitly excluded from the allowed actions, even if they are part of a broader action set.

Key Takeaway

Role definitions are collections of permissions that dictate what actions a security principal can perform, ensuring precise control over resource interactions.
