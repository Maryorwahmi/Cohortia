Key Concepts

Essential terms from this chapter.

Role-Based Access Control (RBAC)

Azure's authorization system for managing access to resources, defining who can do what.

Principle of Least Privilege

Granting users only the minimum permissions required to perform their tasks, a fundamental security practice.

Security Principal

The 'who' in an RBAC assignment; the entity (user, group, service principal, managed identity) granted access.

Summary Takeaway

RBAC, enforcing the principle of least privilege, defines how security principals interact with Azure resources, forming the bedrock of cloud security.
