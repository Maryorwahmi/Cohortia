Key Concepts

Essential Terms to Remember

Member User

A standard user account within your organization's Microsoft Entra ID tenant, typically an employee.

Guest User

An external user invited to access resources in your Microsoft Entra ID tenant through B2B collaboration.

Security Group

A Microsoft Entra ID group used to manage access to resources, often assigned Azure roles (RBAC).

Chapter Summary

Mastering the distinction between user types and the strategic use of security groups is fundamental for implementing robust access control and maintaining a secure cloud environment.
