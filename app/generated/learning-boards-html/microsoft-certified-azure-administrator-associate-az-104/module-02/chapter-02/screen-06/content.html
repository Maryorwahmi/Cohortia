Creating New Users in Azure Portal

Step-by-Step Account Provisioning

Step 1

Navigate to Entra Admin Center

Go to the Microsoft Entra admin center, then select 'Users' from the left-hand navigation pane.

Step 2

Initiate New User Creation

Click on 'New user' and then choose 'Create new user' to open the user creation form.

Step 3

Provide User Details

Enter the User Principal Name, Display Name, initial password, and optionally job information. Ensure 'Require user to change password on first sign-in' is checked.

Step 4

Review and Create

Review all entered details for accuracy, then click 'Review + create' and finally 'Create' to provision the new user account.

Pro-Tip

Always enforce strong password policies and prompt users to change their initial password to prevent security vulnerabilities.

Key Takeaway

The Azure portal is ideal for creating individual user accounts, offering a clear, guided process to ensure all necessary details are captured securely.
