Member Users vs. Guest Users

Distinguishing Internal and External Identities

Member Users

  • •Typically employees or full-time staff within your organization.
  • •UPN belongs to one of your verified domains (e.g., john.doe@yourcompany.com).
  • •Full access to Microsoft Entra ID features and resources based on assigned roles.
  • •Considered internal identities.
Use Case

Standard access for internal employees to all necessary company resources and applications.

Guest Users

  • •External users (partners, vendors, customers) needing limited access.
  • •UPN reflects original organization (e.g., jane_external.com#EXT#@yourtenant.onmicrosoft.com).
  • •Limited access to specific resources, requiring invitation processes (B2B collaboration).
  • •Considered external identities.
Use Case

Granting specific access to a project folder or application for a third-party consultant.

Key Takeaway

Properly distinguishing between member and guest users is essential for applying the correct security policies and managing external collaboration effectively.
