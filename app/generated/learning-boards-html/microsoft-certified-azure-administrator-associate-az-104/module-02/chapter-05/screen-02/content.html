Module 2 › Implementing and Managing Identity and Access › Learning Objectives

Learning Objectives

What you will be able to do after this chapter

01

Explain Entra ID Governance Benefits

Understand the purpose and advantages of Entra ID Governance features for security and compliance.

02

Implement Access Reviews

Configure and manage access reviews for groups and applications to ensure appropriate access levels.

03

Describe Privileged Identity Management (PIM)

Understand how PIM provides just-in-time access for privileged roles, reducing security risks.

04

Configure PIM Assignments & Terms of Use

Activate eligible assignments for roles and understand how Terms of Use enforce policies for guest users.
