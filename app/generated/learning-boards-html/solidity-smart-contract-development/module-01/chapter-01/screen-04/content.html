Core Concept

What is a blockchain?

A shared ledger recorded in blocks; cryptographic links create tamper resistance and shared truth.

Key properties
  • Decentralization: no single central authority controls the ledger.
  • Immutability: blocks link cryptographically so history is hard to alter.
  • Transparency: transaction history is typically visible to participants.
Concrete example
A token transfer included in a block becomes part of every node's copy; later disputes are resolved by inspecting cryptographic block links.
Common mistake
Assuming transparency means personal identity is exposed. Transactions are visible, but addresses are pseudonymous.
Key Takeaway

Blockchain creates a shared, tamper-resistant history that supports trust without a central authority.

Annotated chain
Block
Contains a set of transactions and a hash pointer to the previous block.
Linking
Cryptographic hashes bind blocks together; changing one requires recalculating later blocks.
Copies
Many nodes store the ledger; consensus ensures a consistent canonical history.
