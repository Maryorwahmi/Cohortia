Hands-on Activity

Exploring the chain with a block explorer

Key fields to examine when inspecting an address or transaction.

Address view
Balance, transactions list, internal transactions, and contract tab if code is deployed.
Transaction details
Hash, block number, Gas price, Gas used, fee paid, and input data for contract calls.
Contract tab
Look for verified source, read and write functions, and events emitted by the contract.
Concrete walkthrough
Search a known router or token address. Note Gas used on swap transactions and check whether the contract's code is verified to understand function names.
Why it matters
Explorer data helps you estimate Gas, verify intended behavior, and debug unexpected on-chain outcomes.
Key Takeaway

Use explorers to observe real transactions and learn practical Gas patterns before writing and deploying contracts.
