Core Concept

EOAs vs Contract Accounts

Who can act and how actions are initiated on Ethereum.

Externally Owned Account (EOA)
Controlled by a private key; can sign and send transactions to any address.
Contract Account
Holds immutable code and a balance; executes code only when called by a transaction.
Analogy
EOA is a person with a key; contract account is a vending machine that reacts to inputs.
Key Takeaway

Contracts cannot self-initiate transactions; EOAs are the actors that trigger on-chain behavior.

Developer example
When you deploy a contract, an EOA signs the deployment transaction. Later, users (EOAs) call contract functions to change its state.
Common mistake
Thinking a contract can spontaneously create an outgoing transaction; it can only perform actions during a triggered execution context.
