Definition

Ethereum: a programmable blockchain

Ethereum runs code across all nodes so contracts behave predictably and trustlessly.

Smart contracts
On-chain programs compiled to EVM bytecode that execute deterministically when called.
Ether and Gas
Ether is the native token and pays for Gas, the unit of computation.
EVM
A virtual machine that executes compiled contract bytecode on every node.
Key Takeaway

Ethereum adds programmability to the ledger, enabling trustless apps but introducing execution cost and complexity.

Analogy
Think of Ethereum as a shared computer: the ledger stores state and the EVM runs code that changes that state, with each operation costing Gas.
Developer example
Deploying a token contract publishes code to an address. Users interact with that address; the EVM applies the contract's logic to update balances.
Common mistake
Assuming you can change deployed contract code later. Contracts are immutable unless you design explicit upgrade patterns.
