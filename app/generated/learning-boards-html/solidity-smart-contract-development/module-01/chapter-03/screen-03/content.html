Practical verification steps
Check 1
Node and npm versions
node -v
npm -v
Expected: both print a version number, confirming runtime and package manager are present.
Check 2
Scaffold Hardhat
mkdir my-hardhat-project
cd my-hardhat-project
npm init -y
npm install --save-dev hardhat
npx hardhat
Choose "Create a basic sample project" when prompted to generate sample contracts and tests.
Check 3
Run sample tests
npx hardhat test
Passing tests confirm the compiler, network simulation, and test runner are working together.
