Code Walkthrough
Install and scaffold
npm install --save-dev hardhat
npx hardhat
Select "Create a basic sample project" when prompted to generate example files.
Run sample tests
npx hardhat test
Successful tests confirm compilation, an ephemeral local network, and the Mocha/Chai test runner are functioning.
If tests fail: check solidity version in hardhat.config.js and match it to the sample contract's pragma.
