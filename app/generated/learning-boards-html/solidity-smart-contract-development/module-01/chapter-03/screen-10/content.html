Architecture
contracts/
Solidity source files. Group by feature and keep interfaces separate.
scripts/
Deployment and helper scripts. Reuse when moving to testnets by reading network config.
test/
Unit and integration tests. Keep tests deterministic and fast using the local network.
Best practices
  • • Keep deployments reproducible and parameterized by network settings.
  • • Avoid heavy side effects in tests; reset state between tests when necessary.
  • • Document the purpose of each script and test file for team clarity.
