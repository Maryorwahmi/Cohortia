Process Flow
Troubleshooting checklist
  1. 1. Verify Node and npm versions: node -v, npm -v.
  2. 2. Ensure dependencies installed: npm install.
  3. 3. Check solidity version in hardhat.config.js matches contract pragma.
  4. 4. Confirm plugins are required and installed.
Example error: Unsupported Solidity version
This usually means the solidity field in hardhat.config.js doesn't match the pragma in your contract. Update the config to the correct version, then recompile.
Misconception: "Reinstalling everything fixes it." Often a simple config mismatch is the root cause; inspect errors before reinstalling at random.
