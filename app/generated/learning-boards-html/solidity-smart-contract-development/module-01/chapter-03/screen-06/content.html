Process Flow
Scaffold → Inspect → Verify
Quick commands
mkdir my-first-contract
cd my-first-contract
npm init -y
npm install --save-dev hardhat
npx hardhat
Choose "Create a basic sample project" when prompted. This produces a working example you can run immediately.
Generated structure
  • • contracts/ — Solidity files (e.g., Lock.sol)
  • • scripts/ — deploy and utility scripts
  • • test/ — JavaScript test files
  • • hardhat.config.js — main configuration
  • • package.json — project manifest
Key Takeaway

Scaffolding gives you a runnable baseline. Run the sample tests to confirm everything is wired correctly.
