Core Concept
Example hardhat.config.js
// hardhat.config.js
require("@nomicfoundation/hardhat-toolbox");

/** @type import('hardhat/config').HardhatUserConfig */
module.exports = {
  solidity: "0.8.24",
  networks: {
    hardhat: {}
  }
};
Note: the toolbox plugin is commonly required to enable ethers and testing helpers.
Practical checks
  • • Match the solidity field to your contracts' pragma.
  • • If you need multiple compilers, use compilers: [{ version: "0.8.24" }, { version: "0.7.6" }].
  • • Only add network configs you intend to use to keep the file simple.
Common Mistake

Forgetting to set solidity or using a wrong version causes compiler errors. Always cross-check pragma lines.
