Definition
Why Node.js?
It executes JavaScript tools outside the browser and provides npm for package management.
Install & verify
node -v
npm -v
# optional
npm install -g yarn
yarn -v
Tip: If tools fail, check that your PATH points to the installed node binary or use a version manager.
Example scenario
On a fresh machine, install Node and run the commands above. If node -v returns a version below your project's required version, update Node.
Misconception: "Any Node version will work." Some packages require modern language features so match your project's recommended Node range.
Key Takeaway

Confirm Node and npm (or Yarn) versions before installing Hardhat to avoid subtle compatibility issues.
