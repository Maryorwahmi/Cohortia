Definition
Common plugins in toolbox
  • • @nomicfoundation/hardhat-ethers — Ethers.js integration
  • • @nomicfoundation/hardhat-chai-matchers — Assertions for contracts
  • • hardhat-gas-reporter — Gas usage reports
  • • solidity-coverage — Test coverage
Install toolbox
npm install --save-dev @nomicfoundation/hardhat-toolbox
# then in hardhat.config.js
require("@nomicfoundation/hardhat-toolbox");
Add the require line at the top of your config to enable plugin features in your tasks and tests.
