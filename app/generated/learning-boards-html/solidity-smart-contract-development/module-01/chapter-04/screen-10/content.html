Constructor pattern
contract SimpleStorage {
  uint256 public storedData;
  address public owner;

  constructor(uint256 initialData) {
    storedData = initialData;
    owner = msg.sender; // deployer becomes owner
  }

  function set(uint256 x) public {
    require(msg.sender == owner, "Only owner can set data");
    storedData = x;
  }
}
Why this matters
Constructor sets initial trust boundaries like owner.
msg.sender is fundamental for authorization checks.
require enforces conditions and reverts on failure.
Common Mistake

Assuming msg.sender points to the original transaction sender across calls. In proxied or meta-transaction patterns this may differ; test ownership flows carefully.
