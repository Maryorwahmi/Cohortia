Module 2 › Chapter 1.4 › Basic Data Types
Type cards
uint / uint256 — unsigned integer for counts and balances
int / int256 — signed integer when negatives are needed
bool — true or false flags
address — 20-byte account identity
string — dynamic UTF-8 text
bytes / bytes32 — dynamic or fixed byte arrays
Example
contract TypesExample {
  uint256 public count;
  address public owner;
  bool public active;
  bytes32 public id;
}
Misconception

Using smaller uint types always saves gas. Only true when variables are carefully packed into storage slots.
