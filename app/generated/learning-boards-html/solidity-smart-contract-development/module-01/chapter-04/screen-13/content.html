Module 2 › Chapter 1.4 › Common Mistakes
Mistake list
  1. Leaving state public and exposing sensitive data.
  2. Using broad pragma ranges that allow breaking changes.
  3. Emitting events before performing state changes.
  4. Forgetting payable on Ether-accepting functions.
  5. Misunderstanding gas costs of storage writes and copies.
Best practices
  • Pin compiler via pragma and include SPDX.
  • Test ownership checks and event emissions in Hardhat tests.
  • Use explicit types and clear visibility for every declaration.
Key Takeaway

Run small tests, review visibility and mutability, compile often, and emit events after state changes to avoid common failures.
