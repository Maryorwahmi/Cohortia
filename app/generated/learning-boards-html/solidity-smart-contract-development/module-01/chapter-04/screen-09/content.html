Module 2 › Chapter 1.4 › Functions & Mutability
Code examples
function set(uint256 x) public {
  storedData = x; // mutates state, costs gas
}

function get() public view returns (uint256) {
  return storedData; // reads state, free off-chain
}

function sum(uint256 a, uint256 b) public pure returns (uint256) {
  return a + b; // pure: no state access
}

function deposit() public payable {
  // accepts Ether
}
Important notes
  • view/pure describe state access, not callability or visibility.
  • payable is required to receive Ether; omitting it causes calls with value to revert.
  • A transaction calling a view function still costs gas if mined; only off-chain call simulation is free.
