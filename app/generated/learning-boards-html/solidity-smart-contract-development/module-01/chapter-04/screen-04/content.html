Module 2 › Chapter 1.4 › Pragma & SPDX
What they are
  • SPDX-License-Identifier: short license tag for clarity and open-source best practice.
  • pragma solidity ^0.8.24; pins the compiler range to avoid incompatible releases.
Example
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;
Common Mistake

Using a very broad pragma range or omitting it can allow incompatible compilers to change behavior and introduce vulnerabilities.

Why it matters
Reproducibility: auditors and tools expect a pinned compiler version.
Safety: compiler updates can change semantics that affect security.
Tooling: build systems like Hardhat use pragma to select a compiler binary.
Key Takeaway

Always include an SPDX line and a conservative pragma to keep builds stable and auditable.
