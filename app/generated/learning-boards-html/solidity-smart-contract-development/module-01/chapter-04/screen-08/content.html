Module 2 › Chapter 1.4 › Visibility Modifiers
Modifiers at a glance
  • public: external access and automatic getter for state variables.
  • private: only inside the contract it is declared.
  • internal: contract and inheriting contracts can access.
  • external: callable from outside; efficient for calldata-heavy calls.
Example scenario
If you store an owner address that must be public for transparency, use public. If it controls secrets, use private and expose controlled getters with checks.
Common Mistake

Marking sensitive state public by default exposes it. Audit visibility to match intended access patterns.
