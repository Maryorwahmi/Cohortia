Contract Anatomy
State variables: persistent storage on-chain.
Functions: change or read state; controlled by visibility and mutability.
Constructor: runs once at deployment to initialize state.
Events: logs for off-chain consumption.
// SPDX-License-Identifier: MIT pragma solidity ^0.8.24; contract SimpleStorage { uint256 public storedData; // state function set(uint256 x) public { storedData = x; // behavior } }
Design guidance
  • Keep a single responsibility per contract where practical.
  • Group related state and methods together for easier auditing.
  • Limit public exposure: prefer private/internal when possible.
Misconception

Contracts are not ephemeral modules. Once deployed they persist and store state for all future interactions.
