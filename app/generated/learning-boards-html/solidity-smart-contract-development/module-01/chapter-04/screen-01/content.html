Your First Solidity Smart Contract

Write a minimal contract that stores a number, initialize it at deploy time, control who can change it, and log updates for off-chain listeners.

In this lesson
Pragma & SPDX, contract block, state & types, function modifiers, constructor, events.
Why it matters
Syntax choices affect compilation, gas, and security. A correct structure prevents common vulnerabilities and makes contracts auditable.
Explore Key Topics
Pragma & SPDX
Pin compiler version and declare license for reproducible builds and clear licensing.
State & Types
State variables persist on-chain. Choose uint, bool, address, string appropriately for storage and gas cost.
Functions & Events
Use view/pure for read-only calls, emit events for off-chain monitoring, and require for basic checks.
Preview: SimpleStorage
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract SimpleStorage {
  uint256 public storedData;

  constructor(uint256 initialData) {
    storedData = initialData;
  }

  function set(uint256 x) public {
    storedData = x;
  }

  function get() public view returns (uint256) {
    return storedData;
  }
}
Key Takeaway

A minimal contract shows compiler pinning, persistent state, controlled updates, and read-only access using view.
