Event example
event DataChanged(address indexed changer, uint256 oldValue, uint256 newValue);

function set(uint256 x) public {
  uint256 oldData = storedData;
  storedData = x;
  emit DataChanged(msg.sender, oldData, storedData);
}
Event guidance
  • Include indexed fields for common filters like addresses.
  • Do not rely on events for on-chain logic; they are off-chain observables.
  • Emit after state changes so logs reflect the final state.
Key Takeaway

Events provide an efficient, indexed log for UI and audit trails, but are not a substitute for state when on-chain reads are required.
