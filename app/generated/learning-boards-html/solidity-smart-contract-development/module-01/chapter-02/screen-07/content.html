Contracts and Accounts
Addresses, EOAs, and contract interactions
Contract Account
After deployment, the contract runs at a specific address and holds state and code.
Accepts transactions and can send funds
Can call other contracts
Cannot directly access off-chain data
Interaction model
EOA sends a transaction → EVM executes contract function → state may change and events can be emitted for off-chain listeners.
Concrete example
An EOA calls deposit() sending ETH; the contract updates a mapping tracking balances and emits an event for wallets to display.
Misconception
Contracts cannot fetch web data by themselves; they require an oracle or an on-chain reporter to provide external inputs.
