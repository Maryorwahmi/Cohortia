Escrow: state & functions
State variables
  • buyerAddress
  • sellerAddress
  • itemPrice
  • fundsHeld (bool)
  • deliveryConfirmed (bool)
Key functions
depositFunds, confirmDelivery, releaseFunds, refundBuyer — each guarded with checks on caller and state.
Example pseudocode
// state
address buyerAddress
address sellerAddress
uint itemPrice
bool fundsHeld
bool deliveryConfirmed

// functions
function depositFunds() payable { /* buyer sends ETH */ }
function confirmDelivery() { /* seller or buyer marks delivery */ }
function releaseFunds() { /* send ETH to seller if confirmed */ }
function refundBuyer() { /* refund after timeout */ }
Common mistake

Not validating the caller or state before transferring funds can lock or lose funds. Always check conditions and test edge cases.
