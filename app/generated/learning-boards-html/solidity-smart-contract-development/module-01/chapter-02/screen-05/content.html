Contract Lifecycle
From code to on-chain state
1. Author
Write Solidity source with state and functions.
2. Compile
Source → EVM bytecode by a compiler.
3. Deploy
Send deployment transaction; contract gets an address.
4. Interact
Transactions invoke functions and change state.
Why compile matters
Compilation fixes exact bytecode that will run on every node; small source differences change runtime behavior.

State changes
  • Transactions that call functions can alter stored variables.
  • Each change is recorded in a block and is verifiable.
  • Self-destruct is possible if implemented, otherwise contract remains.
Common misconception
Deployment is not free and not trivial to reverse; plan testing and migration strategies before publishing.
