Limitations & Security
Immutability, gas, and common vulnerabilities
Immutability
Bugs are difficult to fix; typical response is to deploy a new contract and migrate state.
Gas costs
Complex code increases user cost and can limit practical usage; optimize hot paths.
Common vulnerabilities
  • Reentrancy attacks
  • Integer overflows/underflows
  • Improper access control
Security reminder
Audits and testing help but do not guarantee safety. Plan migrations and communication for emergency fixes.
Key Takeaway

Design for minimal trust, test thoroughly, and assume you'll need a migration plan for critical issues.
