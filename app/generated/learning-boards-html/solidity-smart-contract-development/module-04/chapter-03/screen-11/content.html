Module 4 › Chapter 4.3 › Testing & Validation
Unit Tests

Assert CEI ordering, balance updates, and that withdraw sets balances to zero before transferring. Include negative tests that expect revert messages.

Integration Tests

Simulate campaign lifecycle, multiple contributors, deadlines passing, and success/failure transitions to validate the state machine and pause behavior.

Fuzzing

Use fuzzing to explore unexpected input combinations and edge cases that handwritten tests might miss, like extreme gas usage or unusual value distributions.

Key Takeaway

Tests are your safety net; aim for negative tests and lifecycle simulations, not just happy paths.
