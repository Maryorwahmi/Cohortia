Module 5 › Chapter 4.6 › Monitoring & Alerts
On-chain signals to watch
  • Owner or admin role changes.
  • Large transfers or bulk withdrawals.
  • Multiple failed transactions from the same address.
  • Upgrade function calls and implementation address changes.
Integrations

Hook alerts into Slack, PagerDuty, or SMS and implement automated runbooks for initial containment, such as pausing activity where possible.

Example alert rule

Trigger: Transfer event with value > X or call to upgradeTo. Response: Generate high-severity alert, notify core team, and run automated diagnostic snapshot of contract state.

Check

Do you have alert thresholds and a documented on-call rotation? If not, set them before mainnet deployment.
