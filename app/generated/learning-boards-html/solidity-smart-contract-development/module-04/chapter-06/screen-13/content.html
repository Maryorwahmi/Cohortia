Module 5 › Chapter 4.6 › Hands-on Task
Task steps
Setup
  1. Initialize Hardhat and install @openzeppelin/hardhat-upgrades.
  2. Create TokenV1 with initializer and mint logic.
  3. Deploy TokenV1 via upgrades.deployProxy and record proxy address.
Verification: Query balances and owner via proxy address.
Upgrade
  1. Create TokenV2 inheriting TokenV1 and add a burn(uint256) onlyOwner function.
  2. Deploy TokenV2 implementation and call upgrades.upgradeProxy with proxy address.
  3. Verify balances persisted and burn works.
Verification: Balances unchanged; burn reduces owner balance.
Checklist: initializer used • storage layout stable • _authorizeUpgrade restricted
Common pitfall: forgetting initializer or changing storage order
Pro tip: run storage-layout diff between implementations
