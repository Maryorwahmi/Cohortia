Practical Milestones

Each objective below includes a verification step you can run after deployment.

Deploy TokenV1 proxy

Use upgrades.deployProxy with initializer and confirm proxy address is returned.

Verification: Query balance and owner on proxy address.
Upgrade to TokenV2

Deploy new implementation and call upgrades.upgradeProxy to swap logic while keeping the proxy address.

Verification: Balances unchanged; new functions available.
Monitoring & Alerts

Create listeners for owner changes, large transfers, or repeated failures and hook alerts into a PagerDuty or Slack channel.

Verification: Trigger a simulated event and confirm alert delivery.
