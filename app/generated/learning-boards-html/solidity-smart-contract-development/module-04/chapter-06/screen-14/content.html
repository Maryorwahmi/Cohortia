Module 5 › Chapter 4.6 › Key Concepts
Immutability
Code permanence is valuable but complicates fixes without upgrade patterns.
UUPS
Minimal proxy, implementation holds upgrade logic and authorization hook.
Post-Deployment Security
Monitor, alert, pause, and have an incident response plan to limit impact of issues.
Summary

Combine careful upgradeable design with strict authorization and active monitoring to evolve contracts safely without compromising user funds.
