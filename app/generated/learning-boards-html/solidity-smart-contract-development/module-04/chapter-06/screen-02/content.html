Learning Objectives

Bloom progression: Learn → Understand → Apply → Master

Bloom: Learn • Apply
01
Explain immutability and migration cost

Describe why immutable contracts make patching hard and why redeploying loses state. This matters when users hold balances or persistent protocol data.

Verified Competency Milestone
02
Describe proxy architecture

Explain how a proxy stores state and delegates calls to an implementation contract, preserving address continuity for users.

Verified Competency Milestone
03
Implement UUPS safely

Use initializer functions, avoid constructors for state, and ensure storage compatibility when rolling out new implementations.

Verified Competency Milestone
04
Run post-deploy security

Set up real-time on-chain alerts, incident response plans, emergency pause controls and bug bounty programs to reduce impact of incidents.

Verified Competency Milestone
