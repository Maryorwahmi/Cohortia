Module 04 › Chapter 4.4 › Access control
Failing authorization test
await expect(myContract.connect(addr1).onlyOwnerFunction())
  .to.be.revertedWith("Not owner");
Use revertedWith to assert specific error messages for clearer failure diagnostics, but a plain reverted check can be appropriate for native arithmetic failures.
Complementary success test
Also include a test where the owner calls the function and it returns the expected value or emits the expected event. This completes the authorization contract test.
Key Takeaway
Testing both failure and success cases validates access control and prevents privilege regressions.
