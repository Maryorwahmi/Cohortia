Module 04 › Chapter 4.4 › Events & balances
Event assertion example
await expect(token.transfer(addr1.address, 100))
  .to.emit(token, "Transfer")
  .withArgs(owner.address, addr1.address, 100);
This test ensures the Transfer event was emitted with the correct arguments, which off-chain indexers depend on.
Balance change example
await myContract.deposit({ value: ethers.utils.parseEther("1.0") });
await expect(() => myContract.withdraw(ethers.utils.parseEther("0.5")))
  .to.changeEtherBalance(owner, ethers.utils.parseEther("0.5"));
Use changeEtherBalance to assert net changes while letting the matcher account for gas costs. Pair this with an event assertion for completeness.
Key Takeaway
Combine event and balance assertions to fully validate side effects that matter to users and integrations.
