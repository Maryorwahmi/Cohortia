Module 04 › Chapter 4.4 › Project setup
Install dev dependencies
npm init -y
npm install --save-dev hardhat @nomiclabs/hardhat-waffle ethereum-waffle chai @nomiclabs/hardhat-ethers ethers
After installing, run the Hardhat initializer to create hardhat.config.js, contracts, and test directories. Make sure your package manifest records the devDependencies for CI reproducibility.
Misconception
Installing tools globally is unnecessary; prefer local devDependencies to keep project builds isolated and reproducible.
Minimal hardhat.config.js
require("@nomiclabs/hardhat-waffle");

module.exports = {
  solidity: "0.8.17",
  networks: {
    hardhat: {}
  }
};
Specify the compiler version that matches your contracts. If you use a different version in contracts, compilation will fail or behave unpredictably.
Key Takeaway
A consistent, reproducible toolchain prevents environment-related test failures and speeds local iteration.
