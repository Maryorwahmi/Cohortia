Module 04 › Chapter 4.4 › Vulnerability tests
Reentrancy test pattern
  • Deploy victim and attacker contracts in test setup.
  • Fund the victim with Ether, trigger the attack, then assert final balances or state.
  • If attack succeeds, the test demonstrates a vulnerability to be fixed.
Warning
If an adversarial test passes (attack succeeds), treat that as a high-priority security failure to remediate before deployment.
Denial-of-Service pattern
Construct tests that populate large arrays or trigger loops with many participants, and assert whether functions revert or handle batching correctly.
Key Takeaway
Adversarial tests serve as permanent regression checks against serious classes of vulnerabilities.
