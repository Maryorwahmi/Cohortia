Test skeleton
const { expect } = require("chai");
const { ethers } = require("hardhat");

describe("Counter", function () {
  let counter, owner, addr1, addr2;

  beforeEach(async function () {
    [owner, addr1, addr2] = await ethers.getSigners();
    const Counter = await ethers.getContractFactory("Counter");
    counter = await Counter.deploy();
    await counter.deployed();
  });

  it("should have initial count of 0", async function () {
    expect(await counter.getCount()).to.equal(0);
  });
});
This skeleton shows the standard pattern: retrieve signers, deploy the contract, and write short, focused it blocks for assertions.
Practical tips
  • Prefer fresh deployments in beforeEach for isolation.
  • Keep each test focused on a single observable outcome.
  • Use clear, descriptive test names that explain expected behavior.
Common mistake
Reusing the same contract across tests can hide stateful bugs and make failures dependent on earlier tests.
