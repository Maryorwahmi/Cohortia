Module 04 › Chapter 4.4 › Mistakes & practices
Common mistakes
  • Only testing happy paths and ignoring edge cases.
  • Using shared state across tests causing order-dependence.
  • Relying on logs instead of automated assertions.
  • Ignoring gas considerations and DoS scenarios.
Best practices
  • Isolate tests with beforeEach deployments.
  • Assert events and state or balances together.
  • Add adversarial and large-input tests for security.
  • Measure coverage and include edge cases in test plans.
Key Takeaway
A disciplined test suite with edge-case coverage is a reliable defense against both logic bugs and attack vectors.
