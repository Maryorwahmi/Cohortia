Module 04 › Chapter 4.4 › Why testing matters
Definition & claim

A test suite provides deterministic checks against contract logic and security properties before deployment. With Hardhat’s local network, you run tests quickly without relying on public testnets.

Example
Assert that a withdrawal emits a FundsWithdrawn event and increases the beneficiary's Ether balance.
Misconception
Passing the happy path does not guarantee safety; tests must include reverts, edge cases, and adversarial scenarios.
Key Takeaway

Treat tests as executable specifications that prove both functionality and security properties.

Practical checklist
  • Run assertions for both state change and emitted events.
  • Use fresh deployments for isolated tests with beforeEach.
  • Simulate transactions from different signers to test access control.
  • Create adversarial contracts for reentrancy and DoS tests.
