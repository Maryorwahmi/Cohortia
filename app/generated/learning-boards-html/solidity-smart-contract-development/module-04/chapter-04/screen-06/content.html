Counter.sol
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Counter {
    uint256 public count;

    function increment() public {
        count++;
    }

    function decrement() public {
        count--; // Solidity 0.8.0+ reverts on underflow
    }

    function getCount() public view returns (uint256) {
        return count;
    }
}
This contract demonstrates state mutation, safe arithmetic in modern Solidity, and a simple getter. Tests should assert both state values and revert behavior for invalid operations.
Testing focus areas
  • Initial state equals zero.
  • Increment increases the count by one.
  • Decrement reverts when count is zero.
  • Different signers can interact with the contract via connect.
Key Takeaway
A minimal contract helps you focus on test structure, assertions, and attacker simulation before applying the patterns to larger contracts.
