Core Concept
External Call Dependencies
If a critical action depends on an external contract, failures there can DoS your contract.
Risk: external contract paused or maliciously reverting.
Mitigation: checks-effects-interactions and pull/batch patterns.
Operational: add pause/unpause when external services are unreliable.
Practical patterns
  • Update state before external calls to avoid inconsistent balances.
  • Use pull payments when sending funds to unknown recipients.
  • Provide fallback or admin options if essential external services fail.
Check
List each external dependency and document failure modes and an operational response for each.
