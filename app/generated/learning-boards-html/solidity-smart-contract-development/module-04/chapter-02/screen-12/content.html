Best Practices
Security Checklist
Enumerate APIs
List all public/external functions and intended callers.
Protect setters
Apply onlyOwner or role checks and validate inputs like addresses.
Avoid unbounded loops
Use pull payments or batching for large collections.
Handle external calls
Assume failures and design graceful fallbacks or pause mechanisms.
Use RBAC
Assign roles and prefer multisigs for sensitive permissions.
Test DoS scenarios
Simulate large arrays, failing external calls, and partial batch processing.
Key Takeaway

Make access rules explicit, avoid unbounded single-transaction work, and design for external failures. Audit and test these assumptions regularly.
