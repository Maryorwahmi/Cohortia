Underflow in transfer

Solidity example (vulnerable, older compiler)
// SPDX-License-Identifier: MIT
pragma solidity ^0.7.0; // older compiler example

contract VulnerableToken {
    mapping(address => uint256) public balances;
    uint256 public totalSupply;

    constructor(uint256 initialSupply) {
        totalSupply = initialSupply;
        balances[msg.sender] = initialSupply;
    }

    function transfer(address _to, uint256 _amount) public returns (bool) {
        require(balances[msg.sender] - _amount >= 0, "Insufficient balance"); // problematic

        balances[msg.sender] -= _amount; // underflow possible
        balances[_to] += _amount;
        return true;
    }
}
Why this fails
The subtraction inside require can underflow before the comparison in compilers without automatic checks. The underflow produces a large value and the require condition succeeds, leading to incorrect state changes.
Test tip

Write a unit test that calls transfer with amount greater than sender balance and assert the transaction reverts in secure code.
