Make tests that act like attackers

Reentrancy Test
Deploy attacker contract with fallback that calls withdraw. Assert vulnerable contract drains and secure one does not.
Arithmetic Tests
Attempt ops that exceed type bounds and assert reverts on safe code.
CI Integration
Include exploit tests in continuous integration so refactors don't reintroduce vulnerabilities.
Final practice tip

Treat tests as living documentation: they show both how to break and how to fix code.
