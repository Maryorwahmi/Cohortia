Static analysis and Slither
Automated scanning that helps you catch common pitfalls early in development.
Install and run
pip install slither-analyzer
slither path/to/MyContract.sol
Slither outputs categorized findings. Use those categories to prioritize fixes and avoid blocking on low-confidence warnings.
Inspect & triage
  • Validate high-severity warnings first, especially reentrancy and incorrect access control.
  • Mark false positives and document why they are safe for future reviewers.
  • Integrate Slither into CI to catch regressions early.
Common-mistake
Treating a clean Slither report as a guarantee. Always layer with tests, fuzzing, and expert review.
