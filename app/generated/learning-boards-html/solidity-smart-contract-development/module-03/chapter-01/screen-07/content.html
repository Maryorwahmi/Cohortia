Module 3 › Chapter 3.1 › virtual vs override
Example
contract Pausable {
  bool public paused;
  constructor() { paused = false; }
  function pause() public virtual { paused = true; }
  function unpause() public virtual { paused = false; }
}

contract Advanced is Pausable, Owned {
  function pause() public override onlyOwner { super.pause(); }
}
Notes
  • Mark base functions virtual only when you expect safe overrides.
  • Derived functions must list override and can still call super to reuse parent logic.
  • In multiple inheritance, list all bases in override if function exists in several bases.
Pitfall

Removing or weakening access control in an override introduces critical vulnerabilities. Strengthen or preserve, never weaken.
