Inheritance & Polymorphism in Solidity
Create modular contracts, control overrides, and avoid common inheritance vulnerabilities.

This chapter focuses on practical rules: declare base functions virtual to allow overrides, use override in derived contracts, call parent logic with super when you need it, and pass constructor arguments explicitly when needed. Multiple inheritance follows Solidity's C3 linearization so order matters.

In this lesson
Owned and Pausable examples, virtual/override rules, super calls, constructor chaining, and pitfalls.
