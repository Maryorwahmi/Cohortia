Module 3 › Chapter 3.1 › override & super
AdvancedMyContract snippet
contract AdvancedMyContract is Owned, Pausable {
  uint public counter;
  constructor(uint _initialCounter) { counter = _initialCounter; }

  function pause() public override onlyOwner {
    super.pause();
  }

  function unpause() public override onlyOwner {
    super.unpause();
  }

  function increment() public whenNotPaused { counter++; }
}
Practical guidance
  • Use onlyOwner in the override to strengthen access control.
  • Call super to preserve base state changes such as setting paused to true.
  • Test both behavior and access restrictions in unit tests to ensure expectations hold.
Key Takeaway

Combining override and super lets you extend behavior safely while maintaining parent invariants.
