Component boxes
Owned
Sets owner, onlyOwner modifier.
Pausable
Pause/unpause logic, virtual functions.
Advanced
Inherits Owned and Pausable; overrides pause to add access control.
Design tips
  • Order bases intentionally in the is clause to control initialization and override resolution.
  • Document any shared ancestor behaviors to avoid surprises from diamond structures.
  • Implement explicit overrides in the leaf contract to make behavior clear.
Watch out

Diamond inheritance can be valid but requires careful reasoning about which base's implementation runs. Test resolution thoroughly.
