Module 3 › Chapter 3.1 › Polymorphism
Concept

Different contracts can respond to the same function call in unique ways when a base marks a function virtual and a derived uses override.

Concrete example
A base provides getX virtual; a derived overrides getX to return x + y. This is used to customize behavior while using the same interface.
Misconception check
  • Polymorphism is not implicit dynamic dispatch; it's explicit and resolved via compile-time rules.
  • Only mark functions virtual when you design for extension and can guarantee invariants.
Key Takeaway

Use polymorphism deliberately to provide interchangeable behavior while preserving security and invariants.
