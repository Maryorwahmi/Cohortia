Module 3 › Chapter 3.1 › Key Concepts
Inheritance (is)
Derived contracts gain public and internal members from base contracts; constructors run to initialize shared state.
virtual / override
Mark bases virtual to permit overrides; derived functions use override and may call super to reuse parent logic.
Multiple Inheritance
C3 linearization resolves ambiguity. Order bases deliberately and test resolution and constructor effects.
Summary

Design inheritance with intent, preserve or strengthen security in overrides, and validate behavior with unit tests that check initialization and permissions.
