Module 3 › Chapter 3.1 › What is inheritance?
Quick Definition

Inheritance lets a derived contract acquire public and internal state and functions from base contracts using the is keyword. Constructors of bases run during deployment.

Common misconception: inheritance copies storage. In reality, declaration and shadowing determine storage layout; duplicate names create separate variables.
Concrete example
// Owned base
contract Owned {
  address public owner;
  constructor() { owner = msg.sender; }
  modifier onlyOwner() { require(msg.sender==owner, "Caller is not the owner"); _; }
}

contract MyContract is Owned {
  uint public value;
  constructor(uint _initialValue) { value = _initialValue; }
}
Explanation & implications
  • Base constructors run first, ensuring shared state like owner is set before derived logic.
  • Inherited modifiers such as onlyOwner can be combined with new modifiers in derived contracts.
  • Avoid shadowing state variables; it creates separate storage and confusion.
Key Takeaway

Inheritance centralizes shared behavior but requires explicit constructor handling and careful storage design.
