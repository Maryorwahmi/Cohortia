Module 3 › Chapter 3.1 › Shadowing & access risks
State shadowing example
contract Base { uint public value; }
contract Derived is Base { uint public value; // shadowing - BAD }
Both variables exist separately. Code reading Base.value differs from Derived.value and leads to confusion.
Access control warning

If a base function is protected by a modifier, ensure overrides also enforce it. Removing modifiers in overrides weakens security and is a common vulnerability.

Check

Add unit tests that assert storage values and permission checks after every override to catch these issues early.
