Module 4 › Chapter 3.5 › Key Concepts
Gas Optimization
Write code that minimizes writes, copies, and expensive operations to lower user fees.
storage / memory / calldata
Calldata is cheapest for external reads, memory for mutable temps, storage for persistent state.
Storage Packing
Group small fixed-size fields together to share 256-bit slots and save gas on writes and deployment.
Takeaway
Balance readability and gas: prefer clear layouts that also reduce storage and copying, and always measure gas impact before finalizing optimizations.
