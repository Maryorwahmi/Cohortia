Module 4 › Chapter 3.5 › Calldata in Practice
Example function
function processData(uint[] calldata _data) external pure returns (uint) {
  uint sum = 0;
  for (uint i = 0; i < _data.length; i++) {
    sum += _data[i];
  }
  return sum;
}
// calldata avoids copying large arrays into memory for external calls
If you need to change values, copy explicitly:
uint[] memory mutable = new uint[](_data.length);
for (uint i = 0; i < _data.length; i++) { mutable[i] = _data[i]; }
Pro-tip
Declare read-only external parameters as calldata to save gas; only allocate memory when mutation is essential.
Visual comparison
calldata
Cheapest for external reads; no copy.
memory
Temporary mutable copy; costs to allocate and copy large inputs.
storage
Persistent and most expensive for writes.
