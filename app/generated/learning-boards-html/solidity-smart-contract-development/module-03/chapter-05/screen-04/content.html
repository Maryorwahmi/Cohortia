Module 4 › Chapter 3.5 › Mappings of Mappings
Definition
Nested mapping for multi-key access

Use mappings of mappings to model relationships like owner→spender→allowance. Reads are constant-time and cheap relative to iterating arrays.

Example
mapping(address => mapping(address => uint256)) public allowances; // allowances[owner][spender]
Common mistake
Storing arrays of pairs for lookups — causes expensive, repeated iteration for each check.
Key Takeaway

Prefer mappings for direct access, and add a boolean mapping or counter for existence checks instead of iterating an array.

Annotated pattern
Fast Read

allowances[owner][spender] returns value without loops.

No enumeration

Mappings don’t track keys; keep a separate array or counter when you must enumerate.

Existence helper

Use mapping(address => bool) to check registration quickly.

Swap-and-pop

If you must keep an array, delete by swap-and-pop to avoid shifting costs.

Scenario
Permissioned token approvals
You need to check whether owner allowed spender for specific amount frequently. A mapping of mappings gives O(1) checks and minimal gas for reads.
