Module 4 › Chapter 3.5 › Arrays vs Mapping
Array pattern
Ordered collection

Use when you need stable order, iteration, or indexing in a predictable sequence.

struct Product { string name; uint256 price; bool available; }
Product[] public products;
// products.push(...) is cheap. Removing middle elements is expensive.
Swap-and-pop delete
If order doesn't matter, swap last element into index and pop to delete cheaply.
Mapping + counter
Unordered, efficient operations

Use mapping(uint => Product) and a productCount to simulate an indexable collection without costly shifting on deletes.

mapping(uint => Product) public products;
uint public productCount;
// Add: products[++productCount] = Product(...);
// Delete: delete products[id];
Key Takeaway

Pick arrays for order; pick mappings when you need cheap deletes and constant-time access.
