Module 4 › Chapter 3.5 › Data Locations
storage

Persistent state that remains on-chain. Writing here is expensive; reading is cheaper but still costly compared to memory.

Example
State variables like mapping and arrays live in storage and incur high gas when modified.
memory

Temporary workspace for function calls. Cheaper than storage but copying large inputs to memory costs gas.

calldata

Read-only view of external inputs. The most gas-efficient for reference types passed to external functions because no copy is made.

Code note
function processData(uint[] calldata _data) external pure returns (uint) {
  uint sum = 0;
  for (uint i = 0; i < _data.length; i++) {
    sum += _data[i];
  }
  return sum;
}
// _data is read-only and very gas efficient for external calls
Misconception check
Declaring an argument as memory for an external call forces a copy; prefer calldata when you only read.
