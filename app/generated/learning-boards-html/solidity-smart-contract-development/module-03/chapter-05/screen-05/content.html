Module 4 › Chapter 3.5 › Structs with Arrays
Pattern
Structs inside mappings or arrays

Structs let you keep related fields together. When paired with mappings, they provide efficient keyed storage with organized fields accessible in one expression.

Example
struct UserProfile {
  string name;
  uint256 lastLogin;
  address[] ownedNFTs;
}
mapping(address => UserProfile) public userProfiles;
// Access: userProfiles[msg.sender].name
Gas note
Appending to ownedNFTs modifies storage and incurs gas. Consider alternatives when updates are frequent.
Key Takeaway

Keep arrays that change rarely inside structs; for frequent changes, use mappings or event logs instead of storing large mutable arrays.

Scenario & Alternatives
Keep small references
Store token IDs or indexes instead of full objects to reduce bytes written.
Events for off-chain lists
Emit ownership transfers and let an indexer maintain the full list off-chain.
Mapping references
Use mapping(id => bool) for existence checks rather than scanning an array.
