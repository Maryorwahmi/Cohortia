Module 4 › Chapter 3.5 › Events & Optimizations
Events

Emit for off-chain logs instead of storing large transient data.

immutable & constant

Use for values that do not change to avoid storage reads and reduce gas.

view & pure

Mark helpers as read-only to document intent and allow free external calls.

Key Takeaway

Choose events for logging, immutable/constant for fixed values, and view/pure for helpers — together these reduce storage and read costs.
