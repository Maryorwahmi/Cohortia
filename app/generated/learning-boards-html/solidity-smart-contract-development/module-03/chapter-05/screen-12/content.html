Module 4 › Chapter 3.5 › Loop Optimization
Design options
  • Split heavy loops into multi-transaction batches.
  • Use mappings to avoid scanning arrays for existence or status checks.
  • Off-load aggregation or sorting to off-chain services and write summarized results on-chain via events or compact state updates.
Example
// Dangerous: iterates over user-controlled array in storage
for (uint i = 0; i < registeredUsers.length; i++) {
  // expensive per-iteration work
}

// Better: process in batches or use mapping checks instead
Warnings
  • Unbounded loops can make transactions fail once the collection grows.
  • View functions called off-chain are free, but internal contract callers will still pay gas.
Key Takeaway

Avoid full storage scans; batch work, use mappings, or perform heavy computation off-chain and record compact results on-chain.
