Architecture

Abstract base and concrete implementation

Abstract base

Holds shared state like admin and provides implemented helpers such as getAdmin. Declares abstract functions that derived contracts must implement.

Concrete implementation

Implements the abstract function using a storage reference such as an IERC20 token, enabling the contract to be deployed and used.

Example summary

PaymentProcessor sets admin and leaves processPayment abstract. ERC20PaymentProcessor fills in the payment logic with token transfers, adhering to the base contract's expectations.

Key Takeaway

Abstract contracts let you standardize behavior while sharing stateful helpers, reducing duplicated ownership and getter logic across implementations.
