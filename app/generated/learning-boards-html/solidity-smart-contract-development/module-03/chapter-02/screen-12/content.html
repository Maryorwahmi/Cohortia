Module 3 › Chapter 3.2 › Interface vs Abstract
Interface

Purely declarative

Defines external function signatures only. No state, no implementation. Use to talk to unknown contracts like ERC20 tokens.

Example
interface IERC20 { function transfer(address recipient, uint256 amount) external returns (bool); }
Abstract Contract

Blueprint with state

Can include implemented functions, state variables, and constructors. Enforces that derived contracts implement abstract members before deploy.

Key Takeaway

Use interfaces for external interaction and abstract contracts for shared implementation plus enforced behavior.
