Hands-on Activity

Build a Safe Vault

Steps
  1. Implement SafeMath functions with require checks for overflow and division by zero.
  2. Define IVault interface with deposit, withdraw, balanceOf, totalVaultBalance signatures.
  3. Create AbstractVault using SafeMath, maintain balances mapping and owner, implement balanceOf.
  4. Implement SimpleEtherVault to accept Ether, update balances with SafeMath, and withdraw with onlyOwner.
Starter code hint
Follow the starter template and fill the TODOs for SafeMath functions and SimpleEtherVault logic. The template assumes totalVaultBalance is contract balance.
Common mistakes
  • Declaring state inside a library instead of in the vault contract.
  • Forgetting to use using SafeMath for uint and calling a.add(b) incorrectly.
  • Trying to deploy AbstractVault without implementing virtual functions.
Key Takeaway

This activity ties library syntax, interface design, abstract base patterns, and secure Ether handling into a single practical exercise.
