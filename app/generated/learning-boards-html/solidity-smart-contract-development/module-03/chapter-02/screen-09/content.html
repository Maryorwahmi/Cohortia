Process Flow

Deploying and linking libraries

  1. Deploy the library contract and capture its deployed address.
  2. Link the library address to dependent contract artifacts during deployment or via your build tool.
  3. Deploy dependent contracts that reference the linked library address.
Hardhat note

Hardhat can inject library addresses when you use the deployer scripts and handle linking automatically if dependencies are declared in the project configuration.

Decision guide
  • Inline small, hot helpers for lowest per-call gas.
  • Link large, shared libraries to centralize audits and reduce deploy size.
Key Takeaway

Link when you want a single audited copy of code; inline when you need minimal call cost.
