No state in libs

Keep libraries pure or view-only; store state in contracts.

DELEGATECALL caution

Public library calls run in the caller's storage; audit linked libraries.

Abstract vs Interface

Choose abstract for shared state; choose interface for external signatures only.

Final thought

Design with reuse and trust boundaries in mind: centralize audited helpers in libraries and require implementations through abstract contracts when necessary.
