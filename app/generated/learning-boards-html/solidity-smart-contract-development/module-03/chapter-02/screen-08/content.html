Code Walkthrough

Attach library functions to types

import "./Math.sol";

contract Calculator {
  using Math for uint; // Attach Math functions to uint

  uint public result;

  function calculateSum(uint a, uint b) public {
    result = a.add(b); // reads like a method
  }

  function calculateDifference(uint a, uint b) public {
    result = a.sub(b);
  }
}
Syntactic effect

using-for changes call syntax by binding the first parameter to the instance. It does not alter function semantics nor create new types.

Concrete tip

If you forget the using-for line, a.add(b) will fail to compile and you must call Math.add(a,b) directly. Keep your using-for directives near the consuming contract for clarity.

Key Takeaway

using-for enhances readability and encourages consistent use of shared helpers across contracts.
