Module 3 › Chapter 3.2 › Key Concepts
Library

Stateless utilities, no persistent storage, and designed for reuse and linking.

using for

Attaches library functions to a type so they can be called with instance.method() syntax.

Abstract Contract

Blueprints with optional implemented helpers and state; derived contracts must implement abstract functions.

Summary takeaway

Choose the right abstraction: library for stateless helpers, interface for external signatures, and abstract contract for shared state and partial implementations.
