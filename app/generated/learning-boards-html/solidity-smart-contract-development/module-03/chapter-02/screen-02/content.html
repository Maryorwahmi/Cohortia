Learning Objectives

Know, apply, and verify key libraries and abstract-contract skills.

Bloom: Learn → Understand → Apply → Master
01
Design a Safe, Stateless Library

You will structure a SafeMath-style library with overflow checks and pure functions. This skill prevents arithmetic bugs and centralizes fixes across contracts.

Venn: correctness + reuse
VERIFIED COMPETENCY MILESTONE
02
Attach Library Functions with using for

You will apply the using-for directive to call library functions as if they were methods on a type. This yields clearer code and consistent syntax across a codebase.

Mnemonic: method-like calls
VERIFIED COMPETENCY MILESTONE
03
Deploy and Link Libraries

You will practice deploying a library and linking it to dependents using a Hardhat-style deployment script. This avoids duplicating bytecode at deploy time.

Timeline: deploy → link → use
VERIFIED COMPETENCY MILESTONE
04
Differentiate Abstract Contracts & Interfaces

You will explain when to use an abstract contract with shared state vs a pure interface used only for external calls. This reduces design errors across teams.

Venn: spec + implementation
VERIFIED COMPETENCY MILESTONE
