Module 3 › Chapter 3.4 › Deploy & Upgrade Flow
Conceptual Steps
1. Deploy LogicV1
Prepare logic code and deploy the implementation contract.
2. Deploy Proxy
Proxy constructor points at LogicV1 and sets the owner who controls upgrades.
3. Initialize via Proxy
Call initialize through proxy so state is set in proxy storage.
4. Exercise Functions
Call increment or other functions to confirm behavior and state.
5. Upgrade
Deploy LogicV2, call upgradeTo on proxy, then test again to confirm state persists.
Example Check
After upgrade, getVersion through proxy should return the new version string while the counter value remains unchanged except for subsequent function calls.
Common mistake
Calling initialize on the implementation directly leaves proxy storage uninitialized and can corrupt expectations.
