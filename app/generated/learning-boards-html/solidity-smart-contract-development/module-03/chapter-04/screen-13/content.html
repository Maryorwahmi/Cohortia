Module 3 › Chapter 3.4 › Hands-on Exercise
Conceptual Steps to Simulate
  1. Create LogicV1: counter, initialize, increment, getVersion returns V1.
  2. Deploy SimpleProxy pointing at LogicV1 and call initialize through proxy to set counter to 10.
  3. Call increment through proxy and verify counter is 11 via proxy reads.
  4. Deploy LogicV2 with matching storage layout, add decrement and getVersion returns V2.
  5. Call upgradeTo on proxy to point to LogicV2, then verify getVersion returns V2 and counter remains 11. Call decrement and verify counter changes.
Success criteria
State values kept across upgrade; new functions operate as expected; no unexpected overwrites.
Watch out for
Calling initialize on implementation, changing variable order in LogicV2, or leaving upgradeTo unprotected.
