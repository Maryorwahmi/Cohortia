Module 3 › Chapter 3.4 › Key Concepts
Immutability
Deployed code cannot change; proxies trade some simplicity to allow fixes while preserving state.
Proxy & Implementation
Proxy holds state and forwards execution; implementations are replaceable logic modules.
delegatecall
Runs implementation code in proxy storage and preserves the original caller and value.
Summary
Use proxies to evolve logic when necessary, but enforce storage layout discipline, initializer guards, and strong upgrade governance.
