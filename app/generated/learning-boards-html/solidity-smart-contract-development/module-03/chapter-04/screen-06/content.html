Module 3 › Chapter 3.4 › delegatecall
What delegatecall does
  • Executes code at the target address.
  • Uses the calling contract's storage slots for reads and writes.
  • Preserves msg.sender and msg.value from the original external caller.
Concrete example
Proxy receives increment call. It delegatecalls implementation. Implementation increases counter, and the counter in proxy storage changes.
Contrast: call vs delegatecall
call: callee uses its own storage and msg.sender is the caller contract.
delegatecall: callee's code runs but uses caller storage; msg.sender remains the original external caller.
Danger
Storage layout mismatch causes writes to unexpected slots and can corrupt proxy state or the implementation pointer itself.
