Module 3 › Chapter 3.4 › Testing & Audit
Testing checklist
  1. Unit tests covering logic functions called through the proxy.
  2. Integration tests simulating deploy, initialize, calls, upgrade, and post-upgrade calls.
  3. Negative tests for re-initialization, upgrade failures, and revert paths.
  4. Storage layout comparisons between versions to detect slot shifts.
Audit focus
  • Delegatecall usage and fallback correctness.
  • Storage slot assignments and layout compatibility.
  • Upgrade access controls and initializer protections.
Pro tip
Rehearse upgrades on a staging network and record the exact steps and transactions you will run in production to minimize surprises.
