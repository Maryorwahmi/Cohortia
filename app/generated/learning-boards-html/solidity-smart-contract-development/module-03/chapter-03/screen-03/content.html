Applied Goals

Translate error patterns into tests and events into UI signals.

Verifier
Define custom errors with parameters
Use typed errors to make test assertions precise and cheaper than long strings.
VERIFIED COMPETENCY MILESTONE
Logger
Emit events with indexed fields
Choose what to index and keep payloads concise to minimize gas while enabling efficient off-chain queries.
VERIFIED COMPETENCY MILESTONE
Order
Emit events consistently around state changes
Decide whether to emit before or after a state change and be consistent to avoid confusing logs.
VERIFIED COMPETENCY MILESTONE
Testability
Assert reverts and events in unit tests
Write test cases that expect specific custom errors and check for emitted indexed events to validate behaviour.
