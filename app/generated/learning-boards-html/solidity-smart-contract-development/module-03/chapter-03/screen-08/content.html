Core Concept › Events & emit

What events are for

Events log information for off-chain systems. They are cheaper than on-chain storage and are indexable for efficient queries.

  • • Declare with event and write with emit.
  • • Up to three parameters can be indexed to enable fast filtering by off-chain clients.
  • • Do not put secret data in events; logs are public forever.
Emission timing
Emit after successful state changes to avoid logging an action that later reverts; for ownership transfers you may emit previous and new owner to record context.
Event example
event Deposit(address indexed user, uint amount, uint newBalance);

function deposit() public payable {
  require(msg.value > 0, "Deposit amount must be greater than zero");
  balances[msg.sender] += msg.value;
  emit Deposit(msg.sender, msg.value, balances[msg.sender]);
}
A frontend can listen for Deposit events to update UI immediately when new deposits happen without polling balances constantly.
Why it matters
Events make your contract observable and integrate it with UIs and indexes efficiently while keeping on-chain state smaller and cheaper.
