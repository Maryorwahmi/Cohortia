Learning Objectives

Progress from validation checks to events and hands-on Escrow design.

Bloom: Learn → Understand → Apply → Master
01
require / revert
Validate inputs and refund gas
Learn to use require and revert for expected failures. These stop execution and return remaining gas to the caller, making them suitable for user input validation and permission checks.
VERIFIED COMPETENCY MILESTONE
02
assert
Protect internal invariants
Use assert only for conditions that should never fail. A failed assert consumes remaining gas and signals a contract logic bug rather than user error.
VERIFIED COMPETENCY MILESTONE
03
Custom errors
Gas-efficient structured error reporting
Define typed errors to return compact failure data. Custom errors reduce gas compared to long string messages and allow off-chain tooling to match specific failure types.
VERIFIED COMPETENCY MILESTONE
04
Events
Log state changes for off-chain apps
Emit events with indexed parameters so external clients can filter and react efficiently without polling contract storage.
VERIFIED COMPETENCY MILESTONE
