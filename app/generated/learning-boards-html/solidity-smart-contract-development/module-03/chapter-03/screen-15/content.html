Summary › Key Concepts
require / revert
Expected checks that refund gas; prefer concise messages or custom errors in production.
assert
For invariants only; a failing assert indicates a logic bug and consumes remaining gas.
Events
Emit indexed logs for off-chain UIs; they are cheaper than storing state on-chain.
Key Takeaway

Design errors and events intentionally: choose patterns based on whether a failure is user-facing or internal, prefer custom errors for efficiency, and emit concise events for observability. Test both failure modes and emitted logs.
