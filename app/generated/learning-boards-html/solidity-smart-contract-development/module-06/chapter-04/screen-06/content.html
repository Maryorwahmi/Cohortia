Definition

Signer Management and connect()

Use signers to model distinct users and preserve correct msg.sender semantics.

Pattern
// obtain signers
[owner, user1] = await ethers.getSigners();

// user1 approves vault
await myToken.connect(user1).approve(vault.address, amount);

// user1 deposits
await vault.connect(user1).deposit(amount);
This sequence ensures approve and deposit originate from user1 so token allowances and deposits map to the same address.
Checks to add
  • Assert myToken.allowance(user1.address, vault.address) equals approved amount.
  • Assert myToken.balances(user1.address) decreases after deposit.
  • Attempt privileged calls from unauthorized signers and expect revert messages.
Misconception: using the default signer accidentally can hide bugs related to caller identity. Be explicit with connect().
