Testing approve → transferFrom Flow

Recreate the approval and transfer lifecycle and assert state at each step.

// Example test snippet (structure shown, escapes applied)
await myToken.connect(owner).transfer(user1.address, depositAmount);

await myToken.connect(user1).approve(vault.address, depositAmount);
expect(await myToken.allowance(user1.address, vault.address)).to.equal(depositAmount);

await expect(vault.connect(user1).deposit(depositAmount))
  .to.emit(vault, "Deposited")
  .withArgs(user1.address, depositAmount);

Checklist
  • Transfer tokens to the test user before approve.
  • Assert allowance immediately after approve.
  • Use expect(...).to.emit to verify events on deposit.
Common Mistake

Forgetting approve leads to a revert from transferFrom; ensure tests explicitly simulate both steps.
