Activity: Staking Contract Integration Test

Use the same integration patterns to test a Staking contract.

Starter checklist
  1. Deploy MyToken and Staking in beforeEach, passing token address to Staking.
  2. Transfer tokens to user1 and assert initial balance.
  3. user1 approves Staking then stakes amount; assert balances and stakedBalances.
  4. user1 unstakes and assert balances and totalStaked return to expected values.
  5. Negative tests: stake(0), unstake too large, and missing approve.
Key takeaway
This activity reinforces deployment order, signer usage, allowance checks, and cross-contract assertions for a different consumer contract pattern.
