Cross-Contract Assertions and Events

Assert each contract's state and emitted events to validate integrated behavior.

Example assertion sequence
  1. Assert myToken.allowance(user1, vault) equals depositAmount after approve.
  2. Expect vault.deposit to emit Deposited(user1, depositAmount).
  3. Assert myToken.balances(user1) decreased by depositAmount.
  4. Assert myToken.balances(vault) increased by depositAmount.
  5. Assert vault.deposits(user1) equals depositAmount.
Check events and state to ensure both sides of the token transfer reflect the operation.
Pro tip
Use expect(...).to.emit with .withArgs to tightly couple event arguments to your assertions and catch mismatches early.
Common Mistake

Relying only on one contract's state can hide a failed transfer or an allowance bug; assert both sides.
