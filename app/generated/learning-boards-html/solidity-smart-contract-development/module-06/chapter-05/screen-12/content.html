Module 6 › Chapter 6.5 › Common debugging pitfalls
Pitfall list
  • Misread gas errors: Check stack trace; a revert can mimic out-of-gas.
  • State not resetting: Ensure beforeEach deploys fresh contracts to avoid hidden state influence.
  • Missing awaits: Always await ethers.js calls to avoid race conditions in tests.
  • External call failures: Trace into called contracts — the revert may originate elsewhere.
Strategy card
Debugging checklist
  1. Run the failing test in isolation.
  2. Add prints around suspect lines and callers.
  3. Read the stack trace and follow the call stack.
  4. Escalate to verbose opcode traces if needed.
Key Takeaway

Follow a checklist and escalate tools deliberately to avoid wasted effort chasing symptoms.
