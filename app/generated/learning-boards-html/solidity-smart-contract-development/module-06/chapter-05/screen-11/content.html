Module 6 › Chapter 6.5 › Hardhat node & console
Quick commands
➜ npx hardhat node
# starts a local node on port 8545

➜ npx hardhat console --network localhost
> const c = await ethers.getContractAt("BuggyContract", address)
> await c.setValue(150)
Use the console to call functions, inspect public variables, and try sequences interactively. Console logs appear in the node terminal where the node is running.
When to use
  • Reproduce multi-step failures interactively.
  • Inspect contract storage after each transaction.
  • Test external contract calls in isolation.
Warning

Node state persists across sessions; redeploy for a clean test run to avoid hidden state effects.
