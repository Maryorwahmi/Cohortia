Sample questions
  • Overflow scenario: Where would you place console prints to confirm an arithmetic overflow and how would you interpret missing prints?
  • Tool selection: When is console logging preferred over a verbose trace and vice versa?
  • External call failure: How do you trace into a failing external contract call to find the root cause?
Scoring rubric
Partial credit for correct short plans. Full credit for stepwise reproduction, targeted prints, stack trace reading, and correct escalation to verbose traces when needed.
Reflection

Describe one scenario from your own code where a console print would have saved you an hour of investigation. What would you have printed?
