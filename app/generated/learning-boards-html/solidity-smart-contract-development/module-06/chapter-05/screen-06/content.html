Test snippet
// test/BuggyContract.js
it("Should revert if value is too high and show console logs", async function () {
  console.log("--- Testing setValue revert ---");
  await expect(buggyContract.setValue(250))
    .to.be.revertedWith("Value must be less than 200");
  console.log("--- setValue revert test complete ---");
});
When running npx hardhat test you will see printed lines like Current value before update: 100 and New value proposed: 250, followed by the revert message. These prints show what the contract saw before it reverted.
Observation

If you see the proposed value matches your expectation, the require triggered correctly and the issue is the guard condition; if the proposed value is unexpected, look earlier in the call sequence.

Check

If logs stop before a point you expected, the transaction reverted earlier — move prints earlier to narrow the exact failing statement.

Key Takeaway

Console logs reveal the last successful observation before a revert — use them to narrow where the transaction failed.
