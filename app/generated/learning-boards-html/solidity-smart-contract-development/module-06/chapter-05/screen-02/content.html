Learning Objectives

Skills you will practice and verify with milestones.

Bloom: Learn → Understand → Apply → Master
01
Use console.log in Solidity

Print runtime values from your contract during tests to confirm state and flow. Practice placing prints before and after suspicious lines to narrow causes.

VERIFIED COMPETENCY MILESTONE
02
Read stack traces

Interpret Hardhat’s automatic stack trace to locate the file and line that caused a revert and follow the call sequence that led to it.

VERIFIED COMPETENCY MILESTONE
03
Run verbose transaction traces

Use the --verbose flag to view opcodes, gas consumption, and state changes when diagnosing complex failures or gas surprises.

VERIFIED COMPETENCY MILESTONE
04
Avoid common pitfalls

Recognize misinterpreted gas errors, test state leakage, missing awaits, and failing external calls, and apply strategies to isolate them.

VERIFIED COMPETENCY MILESTONE
How we’ll practice

Through code examples, test runs, reading Hardhat traces, and a hands-on activity where you locate and fix an intentional bug in a sample contract.
