Module 6 › Chapter 6.5 › Hands-on: BuggyCalculator
Starter contract
// contracts/BuggyCalculator.sol
pragma solidity ^0.8.0;
import "hardhat/console.sol";
contract BuggyCalculator {
  uint public result;
  function add(uint a, uint b) public {
    console.log("Entering add. a:", a, "b:", b);
    uint sum = a + b;
    require(sum != 100, "Sum cannot be 100!"); // intentional bug
    result = sum;
  }
}
Activity steps
  1. Run npx hardhat test and observe the failing add test and revert message.
  2. Add console logs around sum calculation and re-run to see printed values.
  3. Read the stack trace to confirm the require line and remove it.
  4. Re-run tests to verify the fix.
Key Takeaway

This activity practices the full debug loop and shows when to use prints vs traces.
