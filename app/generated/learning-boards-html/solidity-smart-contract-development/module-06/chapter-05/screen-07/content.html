Module 6 › Chapter 6.5 › Running tests & reading output
Step-by-step
1 — Run tests
npx hardhat test and watch console.log output mixed with test results to get immediate clues.
2 — Read stack trace
Identify the at-line that shows the file and line number of the revert.
3 — Escalate
Use npx hardhat test --verbose for opcode-level detail when needed.
Terminal demo (conceptual)
➜ npx hardhat test
--- Testing setValue ---
Current value before update: 100
New value proposed: 250
Error: VM Exception while processing transaction: reverted with reason string 'Value must be less than 200'
 at Contract. (contracts/BuggyContract.sol:21:9)
Use the file and line from the at-line to open the contract and inspect that require. If needed, rerun with --verbose to see the full opcode trace and gas profile.
