Module 6 › Chapter 6.5 › Generic reverts
Problem

Some runtime failures emit a generic revert without a reason string. Division by zero is a common example.

Use console logs

Print the operands involved in arithmetic operations to confirm which value is zero or invalid.

Read stack trace

Find the at-line to locate the exact operation that reverted.

Example
function divideByZero(uint _divisor) public view returns (uint) {
  return value / _divisor; // revert if _divisor is 0
}

// Test
await expect(contract.divideByZero(0)).to.be.reverted;
If console prints show the divisor as zero, the blame is the caller. If the divisor looks valid, follow the stack trace to detect earlier corrupting state or external calls that changed values.
