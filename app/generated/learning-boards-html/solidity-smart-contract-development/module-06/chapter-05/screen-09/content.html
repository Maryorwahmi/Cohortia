Reading the trace
Error: VM Exception while processing transaction: reverted with reason string 'Value must be less than 200'
    at Contract. (contracts/BuggyContract.sol:21:9)
    at Context. (test/BuggyContract.js:12:5)
Open the file at the line reported and inspect the statement. If the failing line is inside a nested external call, follow earlier at-lines to find the original caller that passed the problematic value.
Practical checklist
  • Locate the at-line file and line number.
  • Read the surrounding code to identify the failing condition or opcode.
  • Trace backwards through call stack entries to find the origin of bad input.
Misconception

The at-line indicates where the revert was detected, not always where incorrect data originated.
