console.log (Solidity)
Print values from contracts during local tests to inspect state and flow quickly.
Stack Trace
Hardhat shows file and line of a revert and the call stack to trace the error source.
Verbose Trace
Use --verbose for opcode-level execution, gas costs, and state changes when needed.
Summary takeaway

Combine quick prints with stack and verbose traces and practice careful test hygiene to diagnose and fix smart contract bugs efficiently.
