Process Flow
Negative testing workflow
1. Identify guard
Which require or modifier should block the call?
2. Set failing state
Choose signer or invalid input that triggers the guard.
3. Assert revert
Use to.be.revertedWith with the exact message.
4. Confirm no state change
Read storage values and ensure nothing changed.
5. Complement with positive test
Run the success case and assert expected state and events.
Check

Ask: did the guard prevent any partial updates? If yes, the negative test is complete.
