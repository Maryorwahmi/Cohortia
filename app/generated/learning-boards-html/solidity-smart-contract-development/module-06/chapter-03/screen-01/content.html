Advanced Testing Techniques
Verify reverts, confirm event payloads, and test modifiers with confidence.

This lesson teaches negative testing, event assertions, and modifier checks using Hardhat and Waffle's chai-ethers matchers. The examples that follow use an Ownable contract and a simple ERC-20 to ground concepts in code.

In this lesson
Reverts, events, and modifier tests
Tools
Hardhat + chai-ethers / Waffle matchers
Outcome
Tests that prove both success and failure paths
Example contract
Ownable and MyERC20 examples anchor test patterns for reverts and events.
Explore key topics
Exact revert messages, event assertions with arguments, and modifier negative testing each improve confidence before deployment.
