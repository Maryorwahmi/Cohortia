Event testing with to.emit(...).withArgs(...)
Why events matter
Events provide the canonical source for off-chain systems. Tests ensure logs match expected values so explorers and front-ends behave correctly.
Signer and topics
Use the correct signer for transactions because event fields often reflect msg.sender or previous owner values.
// event test example
await expect(ownable.connect(owner).transferOwnership(addr1.address))
  .to.emit(ownable, "OwnershipTransferred")
  .withArgs(owner.address, addr1.address);

// ERC-20 transfer example
await expect(token.connect(owner).transfer(addr1.address, 100))
  .to.emit(token, "Transfer")
  .withArgs(owner.address, addr1.address, 100);
Pro tip

When matching indexed parameters, pass the expected address values; withArgs will compare topics as provided.
