Definition
Testing modifiers and access control
Test matrix
  • Allowed signer: call succeeds, state change or event observed.
  • Disallowed signer: call reverts with the specific message.
Signer care
Always use connect(signer) to send transactions from different accounts when testing msg.sender dependent logic.
// modifier tests (visual example)
await expect(ownable.connect(owner).doSomethingImportant())
  .to.equal("Important task completed!");

await expect(ownable.connect(addr1).doSomethingImportant())
  .to.be.revertedWith("Ownable: caller is not the owner");
Key Takeaway

Test both sides of modifier checks and assert state or events on success and exact messages on failure.
