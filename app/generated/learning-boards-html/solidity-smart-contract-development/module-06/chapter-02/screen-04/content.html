Core Concept
describe, it, beforeEach
A disciplined structure keeps tests readable and isolated.
describe()
Groups related tests for one contract or feature.
it()
An individual test case describing expected behavior.
beforeEach()
Runs setup before every it to ensure clean state.
Concrete example
A beforeEach deploys Counter so each it sees count reset to zero, avoiding test interdependence.
Key Takeaway

Keep tests atomic: one expectation per it, clean state via beforeEach, and group with describe for clarity.

Typical pattern (annotated)
// test/Counter.js
describe("Counter", function () {
  let Counter;
  let counter;
  let owner;

  beforeEach(async function () {
    Counter = await ethers.getContractFactory("Counter");
    [owner] = await ethers.getSigners();
    counter = await Counter.deploy();
    await counter.deployed();
  });

  it("Should have an initial count of 0", async function () {
    expect(await counter.getCount()).to.equal(0);
  });
});
Common mistake
Using before instead of beforeEach can leave mutated state between tests and produce order-dependent failures.
