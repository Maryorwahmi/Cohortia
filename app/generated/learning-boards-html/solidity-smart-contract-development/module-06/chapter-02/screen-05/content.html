Process Flow
Deploying Contracts in Tests
1
Get ContractFactory
ethers.getContractFactory('YourContract')
2
Get Signers
const [owner, addr1] = await ethers.getSigners()
3
Deploy and await
const c = await Factory.deploy(); await c.deployed()
Example note
Place these steps inside beforeEach to ensure each test begins with a newly deployed contract instance and known signer roles.
Common mistake
Forgetting to await deploy() or deployed() leaves unresolved promises and can cause assertions to run before the contract exists.
Try this
beforeEach(async function () {
  const Factory = await ethers.getContractFactory("Counter");
  [owner, addr1] = await ethers.getSigners();
  counter = await Factory.deploy();
  await counter.deployed();
});
Key Takeaway

Always await asynchronous deployment steps and run them in beforeEach for isolation.
