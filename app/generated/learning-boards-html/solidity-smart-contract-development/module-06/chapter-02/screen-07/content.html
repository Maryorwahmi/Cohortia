Comparison
to.equal vs to.be.revertedWith
to.equal
Compare returned values or state after a transaction. Always await the view call.
to.be.revertedWith
Assert a transaction fails and includes the expected revert message from require or revert.
Examples
expect(await counter.getCount()).to.equal(1);
await expect(counter.decrement()).to.be.revertedWith("Count cannot be negative");
Why both matter
  • Value assertions confirm side effects and return values.
  • Revert assertions confirm guards and error handling.
  • Together, they describe both correct and safe failure behaviors.
Key Takeaway

Assert both success and failure paths with precise matchers to make tests meaningful documentation.
