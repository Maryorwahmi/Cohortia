Learning Objectives
What you'll be able to do after completing this chapter
Bloom: Learn → Understand → Apply → Master
01
Write basic unit tests
Practice writing tests that call contract functions and assert expected state. This skill prevents regressions and clarifies expected behavior.
02
Use Waffle assertions
Learn expect(...).to.equal and revertedWith to verify both outputs and error conditions. This gives precise checks for correctness.
03
Structure tests with hooks
Use describe, it, and beforeEach to organize tests and re-deploy contracts for isolation. This keeps suites reliable and readable.
04
Deploy and use signers
GetContractFactory, deploy, and getSigners let you simulate different accounts and test access-control and multi-user behavior.
