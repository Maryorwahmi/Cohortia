How to use these objectives
Work through conceptual exercises for a simple Counter contract, practice stating invariants, and sketch fuzz scenarios. Use these tasks to decide which properties to formalize and which functions to fuzz first.
Practical mnemonic
Think: Inputs, Invariants, Instances. That order guides where fuzzing and properties add value.
