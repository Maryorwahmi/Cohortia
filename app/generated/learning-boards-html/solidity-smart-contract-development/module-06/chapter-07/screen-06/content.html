Definition

Property-Based Testing

State general invariants that should hold for all valid inputs and let a generator search for counterexamples.

Example property
For an ERC20 transfer: sender balance before plus recipient balance before equals sender balance after plus recipient balance after, ignoring fees.
Counterexample
When a generated input violates the property, the framework reports the exact inputs and state that caused failure.
Practical advice
  • Explicitly state preconditions so the generator filters invalid initial states.
  • Keep properties small and focused for clear counterexamples.
  • Use properties to guard critical invariants like total supply or account conservation.
Key Takeaway

Good properties reduce test maintenance and expose logic flaws across many inputs.
