High-value targets

  • Complex arithmetic and financial calculations
  • Access control routines and authorization checks
  • Token logic: transfers, approvals, balance invariants
  • State machines with multiple transitions
Triage heuristic
Rank functions by impact on funds and global invariants, then apply fuzzing and properties to the top-ranked items. This gives the best return for compute time.
Misconception
Fuzzing everything is expensive and low-value. Focus on high-risk surface first.
Key Takeaway

Apply breadth where risk and input space size are large; otherwise rely on targeted unit tests.
