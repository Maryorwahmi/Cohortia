Module 7 › Chapter 6.7 › Designing Properties
Process

4-step property design

1. Pick invariant
Choose the core truth you want to hold for all inputs.
2. State preconditions
Specify valid initial states the property assumes.
3. Implement oracle
Write a boolean check that is cheap and decisive.
4. Run & refine
Execute the generator, inspect counterexamples, and narrow or correct the property.
Concrete tip
Start with conservation-style invariants: sums or monotonicity are usually easy to assert and diagnostically useful.
Common error
Omitting preconditions causes the generator to produce irrelevant counterexamples that waste debugging time.
Key Takeaway

Design small, testable properties and make preconditions explicit before generating inputs.
