Definition

Fuzz Testing

Automated generation of many inputs to uncover crashes, reverts, and unexpected state changes in contract functions.

How it works
  • Generate random or malformed inputs
  • Call contract functions repeatedly
  • Log failures and produce counterexamples
Harness requirements
  • Resettable state or controlled sequences
  • Clear oracles to decide success or failure
  • Instrumentation for counterexample reporting
Concrete scenario
A fuzzer calls decrement many times with different initial counts and interleaved state changes to find sequences that bypass the require check or yield incorrect counts.
Misconception
Fuzzing does not guarantee complete coverage; it increases breadth and finds surprising interactions but still needs good oracles.
Key Takeaway

Prioritize fuzzing for functions with wide numeric ranges or untrusted external inputs.
