pragma solidity ^0.8.0;

contract Counter {
  uint public count;

  constructor() {
    count = 0;
  }

  function increment() public {
    count++;
  }

  function decrement() public {
    require(count > 0, "Count cannot be negative");
    count--;
  }

  function getCount() public view returns (uint) {
    return count;
  }
}
Properties to assert
  • increment property: count_after > count_before for any call.
  • decrement property: if count_before > 0 then count_after < count_before and count_after ≥ 0.
  • invariant: count never becomes negative under valid preconditions.
Fuzz scenario
Generate random initial counts and random sequences of increment and decrement calls to find ordering or precondition violations. Include boundary values like zero and very large numbers.
Key Takeaway

Properties plus fuzz sequences reveal ordering issues that single-case unit tests may miss.
