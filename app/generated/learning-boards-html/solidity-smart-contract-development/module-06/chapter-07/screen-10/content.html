Test-oracle challenge
For complex contracts it can be hard to programmatically decide if an outcome is correct for arbitrary inputs. This reduces the effectiveness of automated search unless you craft precise oracles.
Tooling note
Foundry and hevm include fuzzing. Hardhat/Waffle need integrations or external tools to run property-based checks.
Performance & scope
Comprehensive fuzzing can be expensive. Use limited budgets in CI and run extended campaigns on dedicated infrastructure when required.
Misconception
Fuzzing alone finds all bugs. It increases confidence but must be combined with good properties and unit tests to form a complete strategy.
Practical tip

Start small: a few strong properties and short fuzz runs often find high-value bugs quickly.
