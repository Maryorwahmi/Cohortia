Test Types Compared

Choose the right test scope to catch the class of bug you care about.

Scope guide
Unit
Single function behavior
Fast, isolated tests that verify outputs and reverts for specific inputs. Example: deposit updates balance and reverts on zero.
Integration
Contract interactions
Tests multiple contracts working together. Example: Vault handling ERC-20 transferFrom reverts or approvals.
End-to-end
Full stack journey
Validate the complete user flow from UI actions to on-chain effects on a testnet or local fork.
Example scenario
A Vault contract accepts ERC-20 deposits. Unit tests verify Vault's accounting functions. Integration tests simulate a token transferFrom and a revert from the token contract. An E2E test simulates a user depositing via a front-end and confirms the final balance on the chain.
Pro tip

Write many fast unit tests, a few targeted integration tests, and only essential E2E scenarios to keep the suite maintainable.

Pitfall

Relying solely on E2E tests for correctness; E2E is slower and harder to debug for small logic errors.
