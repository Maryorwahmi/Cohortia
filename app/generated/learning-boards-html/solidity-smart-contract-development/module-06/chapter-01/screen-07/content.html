Module 6 › Chapter 6.1 › Integration testing
Scenario

Vault and ERC-20 interaction

Integration tests deploy both contracts and simulate real interactions including approvals and transfer behavior.

Test steps
  1. Deploy token and Vault contracts.
  2. Mint or allocate tokens to a test account and approve the Vault.
  3. Call Vault.deposit and assert token transfer and Vault accounting.
  4. Simulate token revert to ensure Vault handles errors safely.
Why it matters
Integration tests catch issues like wrong address usage, missing approval flows, or unhandled revert return values that unit tests won’t show.
Example pitfall
If your Vault assumes transferFrom returns true but a token reverts instead, funds could be inconsistent. An integration test that forces a revert reveals this mismatch early.
Pro tip

Use small token stubs in integration tests to simulate both normal and failing token behavior.
