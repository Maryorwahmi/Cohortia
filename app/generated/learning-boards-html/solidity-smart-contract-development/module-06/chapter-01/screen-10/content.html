Typical workflow

Follow these steps each time you add or change contract logic to keep tests dependable and repeatable.
1. Initialize
Run npx hardhat to scaffold a project with contracts/ and test/ folders.
2. Write tests
Create unit tests for each function and integration tests for interactions.
3. Use Waffle matchers
Assert reverts, events, and balances clearly to speed debugging.
4. Run and iterate
Run npx hardhat test locally and fix issues quickly thanks to instant mining and traces.
Example assertion
Waffle makes it easy to assert that a transaction reverted or that an event emitted with certain arguments, so tests read like specifications.
Key takeaway

Combine Hardhat’s environment with Waffle’s matchers to write clear, fast, and actionable tests.
