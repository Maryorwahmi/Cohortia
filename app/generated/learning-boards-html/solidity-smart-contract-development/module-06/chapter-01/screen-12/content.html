Interpreting results

Read passing outputs for confirmation and failing outputs for targeted debugging information such as revert reasons and stack traces.

  1) Deposit
       should revert when amount is zero:
     Error: VM Exception while processing transaction: revert
     at Context. (test/deposit.test.js:23:16)
Use the referenced test file and contract line to find the failing assertion or revert and correct the logic or the test expectation.
Debugging steps
  • Open the test file and replicate the failing call in isolation.
  • Check the contract line referenced in the trace to find the cause of revert.
  • Fix logic or adjust test to reflect the intended behavior, then rerun tests.
Pro tip
Use focused tests to reproduce failures quickly; wide integration or E2E tests are useful, but small failing unit tests are fastest to debug.
Key takeaway

Treat test failures as precise feedback. Use Hardhat traces to locate and fix the exact failing logic quickly.
