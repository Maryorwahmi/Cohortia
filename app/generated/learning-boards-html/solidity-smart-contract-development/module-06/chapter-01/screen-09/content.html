Hardhat Network features

Hardhat provides a local network with instant mining, debugging traces, and optional forking for realistic tests against live state.

Instant mining
Transactions confirm immediately so tests run fast and deterministically.
Detailed traces
Hardhat surfaces stack traces and revert messages to speed debugging of failing tests.
Forking
You can replicate a mainnet or testnet state locally to validate contract behavior in real-world scenarios without spending real assets.
When to fork
Use forking when your contract interacts with existing mainnet contracts or when realistic state matters for correctness checks.
Key takeaway

Use Hardhat’s speed for frequent tests and its forking capability for high-confidence integration checks against realistic state.
