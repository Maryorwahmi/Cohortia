Module 6 › Chapter 6.1 › Initialize Hardhat

Terminal steps

Follow these commands to scaffold your test environment and confirm it runs.

$ mkdir my-contract-tests
$ cd my-contract-tests
$ npx hardhat
When prompted, select Create a JavaScript project or Create a TypeScript project and accept defaults.
$ npx hardhat test
  SampleTest
    ✔ runs the sample test

  1 passing (xxms)
What to inspect
  • Look for hardhat.config.js (or .ts) and contracts/ and test/ folders.
  • Confirm the sample test passes so your toolchain and network are functional.
Common mistake
Not running the sample test. Always run the scaffolded test to ensure your environment is set up correctly before writing new tests.
Key takeaway

Scaffolding plus a passing sample test confirms your Hardhat environment is ready for focused test writing.
