Practical checks

Each objective below lists a small action or explanation that verifies competency.

01 — Explain immutability
Write a short paragraph describing why a deployed bug is costly and how tests reduce that risk. VERIFICATION: your paragraph names at least one irreversible consequence.
02 — Map test types
Provide three scenarios and label each as unit, integration, or E2E. VERIFICATION: include one reason for each selection.
03 — Explain Hardhat features
List Hardhat Network features you would use when testing and why. VERIFICATION: mention forking or instant mining.
04 — Initialize project
Run npx hardhat and confirm contracts/ and test/ exist. VERIFICATION: run the sample test and report the result.
Mnemonic
Think: "Check early, test interactions, simulate users, then deploy with confidence." Use this as a quick checklist before any mainnet deployment.
Verified Competency Milestone

Complete the init and run the sample test. If it passes, your environment is configured for further tests.
