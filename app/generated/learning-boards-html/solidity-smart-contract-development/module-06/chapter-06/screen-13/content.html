Practical Application

Running & Interpreting Gas Reports

Executing tests and understanding the output

Execute Tests with `REPORT_GAS`

Run your Hardhat tests with `REPORT_GAS=true` environment variable to activate the plugin.

Analyze Report Output

Review the table in your terminal or `gas-report.txt` showing gas consumption per function.

Identify Gas-Heavy Functions

Look for functions with high `avg(gas)` values to prioritize your optimization efforts.

Terminal Command & Example Output

REPORT_GAS=true npx hardhat test
