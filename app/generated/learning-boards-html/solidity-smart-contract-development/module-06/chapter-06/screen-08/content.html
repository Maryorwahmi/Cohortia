Function Types

`view` and `pure` Functions

Gas-free operations for off-chain calls

No State Modification

`view` and `pure` functions do not alter the blockchain state, meaning they don't perform `SSTORE` operations.

Gas-Free Off-Chain Calls

When called externally (off-chain), these functions do not cost any gas, saving users transaction fees.

`view` vs. `pure`

`view` reads state but doesn't modify. `pure` neither reads nor modifies state, only uses inputs.

Code Example: `view` and `pure`

contract QueryExample {
    uint256 public storedValue = 10;

    // Reads state, does not modify
    function getValue() public view returns (uint256) {
        return storedValue;
    }

    // Does not read or modify state, only uses inputs
    function add(uint256 a, uint256 b) public pure returns (uint256) {
        return a + b;
    }

    // Modifies state, costs gas
    function setValue(uint256 _newValue) public {
        storedValue = _newValue;
    }
}
Key Takeaway

Always use `view` or `pure` for functions that don't need to modify state to enable gas-free queries.
