Optimization Strategy

Efficient Data Types & Storage Packing

Choosing the right types for gas savings

Storage Variable Packing

Compiler can pack consecutive small storage variables (e.g., `uint8`, `bool`) into a single 256-bit slot, saving `SSTORE` costs.

`uint256` vs. Smaller `uint`s

For local variables, `uint256` is often cheaper due to EVM's 256-bit word size. Smaller types for storage only save gas if packed.

`bytes32` over `string`/`bytes`

For short, fixed-length data, `bytes32` is much cheaper than dynamic `string` or `bytes` arrays.

Storage Packing Example

Non-Packed


uint256 a;
uint8 b;
uint256 c;

3 storage slots

Packed


uint8 b;
uint8 c;
uint256 a;

2 storage slots (b & c packed)

Key Takeaway

Order storage variables to allow the compiler to pack smaller types, reducing `SSTORE` operations.
