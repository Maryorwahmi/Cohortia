Optimization Strategy

Avoiding Redundant Calculations & Loops

Streamlining computation for lower gas costs

Pre-calculate Values

Compute a value once and store it in a memory variable if it's used multiple times within a function.

Minimize Loops

Loops, especially over dynamic arrays or mappings, are gas-intensive. Consider alternative data structures or off-chain processing.

Avoid External Calls in Loops

Making external contract calls or complex state changes inside loops incurs significant gas costs per iteration.

Code Example: Loop Optimization

contract LoopExample {
    uint256[] public values;

    function sumValuesBad() public view returns (uint256) {
        uint256 total = 0;
        for (uint i = 0; i < values.length; i++) {
            total += values[i]; // Reads values[i] multiple times if used elsewhere
        }
        return total;
    }

    function sumValuesGood() public view returns (uint256) {
        uint256 total = 0;
        uint256 length = values.length; // Cache length
        for (uint i = 0; i < length; i++) {
            uint256 currentValue = values[i]; // Cache array element
            total += currentValue;
        }
        return total;
    }
}
Key Takeaway

Cache array lengths and elements within loops to avoid redundant reads and calculations.
