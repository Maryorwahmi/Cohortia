Setup Guide

Configuring `hardhat-gas-reporter`

Installation and `hardhat.config.js` setup

Installation

Install `hardhat-gas-reporter` and its peer dependency `@nomiclabs/hardhat-web3` using npm.

Configuration in `hardhat.config.js`

Require the plugin and add a `gasReporter` object to your module exports for customization.

Customization Options

Set `enabled` via environment variable, `currency`, `gasPrice`, `token`, `outputFile`, and `coinmarketcap` API key.

Code Example: `hardhat.config.js`

require("hardhat-gas-reporter");
require("@nomiclabs/hardhat-web3");

module.exports = {
    solidity: "0.8.19",
    networks: {
        hardhat: {},
    },
    gasReporter: {
        enabled: (process.env.REPORT_GAS) ? true : false,
        currency: 'USD',
        gasPrice: 20,
        coinmarketcap: process.env.COINMARKETCAP_API_KEY,
        token: 'ETH',
        outputFile: 'gas-report.txt',
    }
};
Key Takeaway

Proper configuration allows for flexible and targeted gas cost analysis during development.
