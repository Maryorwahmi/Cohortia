What an artifact contains — ABI and bytecode
Artifacts provide the ABI and bytecode used by frontends and deploy scripts.
Minimal artifact structure
{
  "abi": [ /* function and event descriptions */ ],
  "bytecode": "0x...",
  "metadata": { /* compiler metadata and settings */ }
}
How it's used
  • Frontends import the ABI to encode calls and decode events.
  • Deployment scripts reference bytecode when creating contract instances.
  • Use artifacts from CI to ensure frontends and scripts use canonical ABIs.
