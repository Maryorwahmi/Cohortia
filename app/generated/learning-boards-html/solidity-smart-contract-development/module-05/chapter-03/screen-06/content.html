Core Concept The test/ directory
The test/ directory and testing workflow
Automated tests verify contract behavior before you deploy.
Why tests matter
  • Catch logic and permission bugs before they become permanent on-chain.
  • Document intended behavior for future contributors.
  • Allow automated regression checks as contracts evolve.
Concrete test pattern
Deploy a fresh contract instance, call functions that change state, then assert expected values or events. Use snapshots to reset state between tests for speed.
Example
Deploy Greeter, call greet(), and assert the returned greeting matches the expected string.
