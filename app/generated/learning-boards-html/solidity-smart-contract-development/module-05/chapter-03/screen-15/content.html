Key Concepts
Three compact reminders of the most important project elements.
contracts/
Solidity source files; organize with subfolders for larger projects.
scripts/
Deploy and utility scripts that automate reproducible tasks.
test/
Automated tests using Hardhat’s test stack to validate contracts before deployment.
Summary takeaway: Keep source and configuration under version control, exclude generated and installed folders, and use automated scripts and tests to make builds and deployments reproducible.
