hardhat.config.js — example and explanation
A small configuration that sets the compiler and networks.
// hardhat.config.js
require("@nomicfoundation/hardhat-toolbox");

/** @type import('hardhat/config').HardhatUserConfig */
module.exports = {
  solidity: "0.8.19", // Specify the Solidity compiler version
  networks: {
    hardhat: {
      // Configuration for the Hardhat Network (local development)
      chainId: 31337, // Default Hardhat Network chain ID
    },
    sepolia: {
      url: "https://sepolia.infura.io/v3/YOUR_INFURA_API_KEY", // Example for Sepolia testnet
      accounts: [process.env.PRIVATE_KEY] // Accounts for deployment
    }
  }
};
Annotated highlights
  • require loads plugins that extend Hardhat with utilities.
  • solidity selects the compiler version; keep it compatible with contract pragmas.
  • networks lists deployment targets; use environment variables for secrets.
Misconception
Changing the compiler here automatically changes pragma lines in contracts. It does not. Verify compatibility explicitly in source files.
