Process Flow The scripts/ directory
Write and run deployment scripts
Automate deploys and tasks with scripts stored under scripts/.
Typical steps in a deploy script
  1. Import ethers and the contract factory.
  2. Deploy the contract with the desired constructor arguments.
  3. Wait for deployment and log the deployed address.
  4. Optionally verify or save addresses for frontends.
Run with: npx hardhat run scripts/deploy.js and add --network to target other networks.
Concrete example
The sample deploy.js deploys Greeter and prints its address. This reproducible script lets anyone deploy the same contract locally or to a testnet by changing the network flag.
Security note
Never hardcode private keys in scripts. Use environment variables or configuration placeholders to keep secrets out of source control.
Pro tip

Use the same script for local and testnet runs by parameterizing network-specific values and accounts.
