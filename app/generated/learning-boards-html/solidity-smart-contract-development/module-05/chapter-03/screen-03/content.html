Bloom's Progression
Learn → Understand → Apply → Master
Learn
Name the directories: contracts, scripts, test, artifacts.
Understand
Explain hardhat.config.js and why the compiler settings matter.
Apply
Run scripts, compile, and execute tests to validate changes.
Master
Maintain deterministic installs and safe config for collaboration.
Practical check
Open hardhat.config.js, change the solidity version, run npx hardhat compile, and observe whether compilation succeeds. This demonstrates your ability to apply configuration changes safely.
