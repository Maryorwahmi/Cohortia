Output cache/ and artifacts/
cache/ and artifacts/ — compilation outputs
Generated files that connect compiled contracts to deployments and frontends.
cache/
Holds compilation caches to speed builds. Safe to delete because Hardhat will rebuild it on the next compile.
artifacts/
Contains compiled output per contract including ABI and bytecode. Frontends and scripts typically consume these JSON files.
Practical note
Don’t commit artifacts unless you have a specific reason. Prefer regenerating artifacts in CI and publishing curated ABIs if needed by frontends.
Key Takeaway
Artifacts are the bridge between compiled contracts and runtime use; understand ABI and bytecode to integrate frontends and scripts.
