Core Files package.json & package-lock.json
package.json and package-lock.json
Manage dependencies and ensure deterministic installs across machines.
package.json
Lists project metadata and dependency ranges. Developers and CI use its scripts and dependency declarations to install and run tooling.
Why commit it?
So collaborators know which packages the project needs and how to run npm scripts like test or compile.
package-lock.json
Records exact package versions installed, including nested dependencies, making installs reproducible.
Common mistake
Not committing the lockfile can lead to different dependency resolutions between developers or CI systems.
Key Takeaway
Commit package.json and package-lock.json; ignore node_modules to keep repo size manageable and installs deterministic.
