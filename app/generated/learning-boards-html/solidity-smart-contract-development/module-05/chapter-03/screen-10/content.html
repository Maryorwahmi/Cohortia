node_modules/ and .gitignore
Installed dependencies are restored from lockfiles rather than stored in Git.
Why not commit node_modules?
  • It's large and bloats your repository.
  • It contains platform-specific files that differ across systems.
  • It defeats the purpose of package-lock determinism.
Best practice
Add node_modules/ to .gitignore and commit package-lock.json so others can run npm install to recreate the same modules.
Common mistake
Forgetting .gitignore entries and accidentally committing cache/ or node_modules/ will create repository bloat and collaboration issues.
