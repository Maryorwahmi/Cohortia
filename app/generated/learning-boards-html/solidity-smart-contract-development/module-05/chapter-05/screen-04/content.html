Module 5 › Chapter 5.5 › Run the Hardhat compile command
Core Concept
Run npx hardhat compile
A single command triggers Hardhat to read config, find contracts, and run the Solidity compiler.
Typical terminal command
npx hardhat compile
When you run this command Hardhat does several deterministic actions: reads hardhat.config.js, scans the contracts/ directory for .sol files, invokes solc, and writes the results to cache/ and artifacts/.
  • Verify working directory is project root before running the command.
  • Expect a subdirectory per contract under artifacts/contracts.
  • If compile reports an error, read the compiler message and the file path it references.
Key Takeaway

One compile command produces both cache and artifacts. Always confirm artifacts exist for each contract after running the command.

Process steps (concise)
1. Read config
Hardhat reads hardhat.config.js to determine compiler settings, optimization, and paths.
2. Scan contracts/
All .sol files in contracts and subdirectories are discovered for compilation.
3. Invoke solc
The Solidity compiler produces bytecode, ABI, and metadata.
4. Write outputs
Outputs include cache/ (intermediate) and artifacts/ (final JSON per contract).
Concrete example
If you have contracts/Counter.sol, after compilation you should see artifacts/contracts/Counter.sol/Counter.json. Open that JSON to confirm it contains bytecode and an abi entry.
Common mistake

Running the compile command from the wrong directory or not saving your file before compiling are frequent causes of missing artifacts.
