Learning Objectives
Learn, understand, apply, and verify your competency.
Learn → Understand → Apply → Master
01
Execute the Hardhat compilation command
Run npx hardhat compile and observe the terminal output indicating success or failure. Practicing the command ensures you can quickly reproduce compiled artifacts in any project.
VERIFIED COMPETENCY MILESTONE
02
Understand Hardhat's compilation output
Locate artifacts/ and cache/ and learn what each holds. Knowing the role of the cache helps you interpret why small edits recompile faster.
VERIFIED COMPETENCY MILESTONE
03
Explain bytecode and ABI
Learn that bytecode is the on-chain executable, and the ABI describes how to encode and decode contract calls. This distinction is essential for deployment and client interaction.
VERIFIED COMPETENCY MILESTONE
04
Prepare to troubleshoot compilation issues
Recognize common causes of compilation warnings and errors so you can fix compiler settings or source mismatches before deploying.
VERIFIED COMPETENCY MILESTONE
