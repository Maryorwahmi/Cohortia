Orientation
Why this matters
When you compile, two outputs are essential: the bytecode that is stored on-chain at deployment, and the ABI that describes how to encode calls and decode results. Misreading these outputs or using mismatched compiler settings causes runtime failures that are hard to debug. This lesson gives you practical steps to run and inspect compilation, so you can deploy with confidence.
