Comparison
Bytecode vs ABI
Know which output you need at each stage of a deployment workflow.
Bytecode
Low-level machine code produced by the compiler. Stored on-chain at deployment and executed by the EVM.
ABI
JSON description of functions and events. Used by clients to encode transactions and decode results.
Example
Deploy stores bytecode for Counter. Later, a script or wallet uses the ABI to construct a call to increment and to interpret the returned count value.
Key Takeaway

Use bytecode to deploy and ABI to interact. Both are required to complete the development lifecycle.

Common pitfalls
  • Trying to call a contract with an ABI that does not match the deployed bytecode leads to failed transactions or decoding errors.
  • Mistaking the ABI for executable code — ABI only describes how to communicate with the contract.
Quick practice prompt
Open an artifact and confirm the bytecode field is non-empty, then find the abi array and scan for a function signature you expect.
Check your understanding

Question: Which artifact entry do you need to build a transaction to call a function? (Answer: the ABI, for encoding.)
