Module 5 › Chapter 5.5 › Post-Compile Checklist
Process Flow

Validate, test, and record

  1. Confirm artifacts contain ABI and bytecode.
  2. Review and address compiler warnings.
  3. Run unit and integration tests against compiled contracts.
  4. Capture compiler and optimizer settings used for this build.
  5. Perform a clean compile when configuration changes.
Concrete Scenario

After a compile you notice a warning about an unused variable. Remove or document the variable, recompile, then run tests. If tests pass and the warning is gone, proceed to capture settings for the deployment artifact.

Quick Automation

Automate a post-compile script to check artifacts, fail on new warnings, and save compiler metadata with each build to reduce human error.

Common Mistake

Skipping tests after a successful compile because the build succeeded. Compile success does not guarantee runtime correctness.

Key Takeaway

Treat compilation as the start of validation: inspect artifacts, fix warnings, run tests, and record metadata for reproducible deployments.
