Architecture
Plugin System
Extend Hardhat with integrations you need while keeping the core lightweight and focused.
Integration examples
Ethers.js for scriptable blockchain interaction and Waffle for testing helpers are common integrations mentioned in the chapter.
When to add
Add plugins incrementally during feature or optimization work to keep debugging simple and configuration manageable.
Practical approach
Install one plugin, validate its output on a sample script or test, then proceed to the next plugin. Keep plugin configs isolated so you can remove or update them easily.
Concrete scenario
During a gas optimization sprint, add a gas reporter to compare implementations, then remove it or leave it for continuous monitoring depending on value.
Key Takeaway

Treat plugins as optional extensions: add them when they give measurable benefits and keep configuration minimal.
