Process Flow
Hardhat Runner
Create named, scriptable tasks to orchestrate repetitive development and release workflows with predictable behavior.
• Define small, composable tasks that can be combined for complex flows.
• Use tasks to reproduce deployments with consistent parameters across environments.
• Expose tasks to scripts and CI for repeatable release processes.
Concrete example
A task that compiles contracts, deploys a set of addresses with specified constructor arguments, and writes the deployed addresses to a JSON file for later use.
Design guidance
Keep tasks focused. Small tasks are easier to test, reuse, and compose into larger workflows than monolithic scripts.
Common mistake
Embedding environment-specific values directly in tasks instead of accepting parameters makes tasks brittle across networks.
Pro tip
Parameterize tasks for network, gas limits, and constructor args so the same task works in local, staging, and CI environments.
Key Takeaway

Use the Runner to capture repeatable deployment steps and reduce human error in releases.
