Module 5 › Chapter 5.1 › Key Concepts
Hardhat
A flexible development environment for building and testing smart contracts.
Hardhat Network
A local, resettable Ethereum network for instant testing and tracing.
Plugin System
A modular way to add capabilities like testing helpers, gas reporting, and verification tools.
Summary
Hardhat combines a developer-first environment, a fast local network for validation, and a plugin architecture so you can tailor tooling to real project needs.
