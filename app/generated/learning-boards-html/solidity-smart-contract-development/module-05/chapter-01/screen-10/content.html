Definition
Debugging & Tracing
Traces show low-level execution while console logs report runtime values; together they reveal root causes of failing tests.
• Use traces to see opcode-level state changes and which branch executed.
• Use console logs in Solidity for quick variable inspection during runs.
• Isolate scenarios into minimal tests to make traces readable and focused.
Concrete example
A failing transfer test reveals via trace that a require check reverted before the balance update; adding a permission assertion prevents future regressions.
Practical steps
  1. Reproduce the failing transaction in a minimal test.
  2. Run the test on Hardhat Network and request a trace for the failing transaction.
  3. Inspect the trace for unexpected jumps, reverts, or missing state writes.
  4. Add a targeted test assertion to lock the intended behavior.
Key Takeaway

Combine console logs and traces to find the root cause and then codify a test that prevents regressions.
