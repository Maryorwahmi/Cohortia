Module 6 › Chapter 5.6 › Multi-signer Testing
Pattern
  1. Get signers: const [owner, addr1, addr2] = await ethers.getSigners();
  2. Deploy contract with one signer in beforeEach.
  3. Simulate actions: await contract.connect(addr1).someAction();
Reminder

Always connect the signer that should be the transaction sender; otherwise tests may not simulate real permission paths.

Concrete example
// Simulate addr1 decrementing after owner increment
await counter.increment();
await counter.connect(addr1).decrement();
expect(await counter.getCount()).to.equal(0);
Pitfall

Forgetting to contract.connect will perform the call from the default signer, giving a false impression of role access.
