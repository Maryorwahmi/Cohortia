Edge cases & events

You will explicitly test failure conditions such as require reverts and verify that important events are emitted so off-chain systems can respond reliably.

Activity
Write tests for MyToken: deployment supply, successful transfer, revert on insufficient balance, and Transfer event emission.
Running tests

Use npx hardhat test. Hardhat compiles, spins up a local network, deploys contracts, and runs test files inside test/ to produce deterministic failure traces.

Why this matters

Tests simulate user interactions and attacker cases before you ever deploy immutable code that could be costly to replace.
