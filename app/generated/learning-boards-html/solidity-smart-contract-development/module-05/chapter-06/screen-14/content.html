Module 6 › Chapter 5.6 › Assessment Ideas
Access control assertion
Use to.be.revertedWith with the expected owner error message when testing calls from a non-owner signer. This confirms the contract enforces only-owner logic.
Example
await expect(pausable.connect(addr1).pause()).to.be.revertedWith("Ownable: caller is not the owner");
Balance change assertion
Use to.changeEtherBalance to assert a sender's Ether decreased by the expected amount after a deposit, and that the recipient increased, while accounting for gas.
Example
await expect(async () => await depositBox.connect(addr1).deposit({ value: ethers.utils.parseEther("1") })).to.changeEtherBalance(addr1, ethers.utils.parseEther("-1"));
