Test execution architecture
  1. npx hardhat test compiles contracts if needed.
  2. Hardhat Network is launched locally and deterministically.
  3. Tests deploy contracts using ethers.getContractFactory and contract.deploy.
  4. Each test run starts from a clean state; use beforeEach for per-test setup.
Pro tip

Keep deployments in beforeEach to ensure test isolation and avoid state leakage across cases.

Concrete example
When a test uses ethers.getSigners(), the Hardhat Network provides multiple signer objects so you can simulate different users without connecting to a real network.
Common misconception

Passing tests in Hardhat does not guarantee production safety; tests reduce risk but should be paired with audits and careful design.
