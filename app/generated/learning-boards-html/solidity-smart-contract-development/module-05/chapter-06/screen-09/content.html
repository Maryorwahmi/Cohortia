Module 6 › Chapter 5.6 › Events & Transfer
Why test events

Events are consumed by wallets, front ends, and monitoring tools. If an event is missing or has wrong arguments, integrations will misbehave even when internal state looks correct.

Takeaway

Assert both state and event emission for critical actions like token transfers.

Concrete example (MyToken)
// After transfer
await expect(myToken.connect(owner).transfer(addr1.address, amount))
  .to.emit(myToken, 'Transfer')
  .withArgs(owner.address, addr1.address, amount);
Pitfall

Relying only on event presence without checking arguments hides subtle regressions in emitted data.
