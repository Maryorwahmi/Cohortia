Module 6 › Chapter 5.6 › Pitfalls
Top mistakes
  • Forgetting await on transactions and reads.
  • Sharing contract instances across tests without reset.
  • Not asserting specific revert messages.
  • Neglecting multi-signer and edge-case scenarios.
Remediation checklist
• Await transactions and .deployed()
• Use beforeEach to create fresh state
• Use revertedWith for explicit failure reasons
• Simulate different signers for role tests
Check

If a test fails nondeterministically, inspect awaits and whether tests share state across it cases.
