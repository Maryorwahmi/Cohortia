Module 6 › Chapter 5.6 › Run & Inspect
Run command
$ npx hardhat test

Hardhat compiles, starts a local network, deploys, and executes tests. Failures include traces and failing assertions for debugging.

Interpreting failures
  • Read the assertion message and stack trace.
  • Confirm the revert message when relevant.
  • Re-run the single failing test file to isolate the issue.
Practice

When a test fails, run that file alone and inspect prior actions and awaits. This focused loop speeds up fixes and clarifies assumptions.
