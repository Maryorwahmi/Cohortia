Common matchers
  • to.equal — Assert a returned value or a view reading equals the expected number or string.
  • to.be.revertedWith — Assert a transaction reverts with the specific error message.
  • to.changeEtherBalance — Assert that an account's Ether balance changed by an expected amount after a transaction.
Key Tip

Assert both the event and the state change when testing economic functions to avoid false confidence.

Concrete snippets
// Example assertions
expect(await counter.getCount()).to.equal(1);
await expect(counter.decrement()).to.be.revertedWith("Count cannot go below zero");
expect(await myToken.totalSupply()).to.equal(initialSupply);
await expect(() => depositBox.connect(addr1).deposit({ value: ethers.utils.parseEther("1") })).to.changeEtherBalance(addr1, ethers.utils.parseEther("-1"));
Misuse

Using to.equal on transactions that don't immediately return values can be misleading; read contract state after awaiting the transaction.
