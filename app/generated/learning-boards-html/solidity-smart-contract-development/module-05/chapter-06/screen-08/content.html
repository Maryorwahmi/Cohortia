Module 6 › Chapter 5.6 › Test Organization
Pattern: describe / it / beforeEach
Group
describe("Counter") groups tests related to the same contract or feature.
Case
it("Should increment") defines a single expectation and contains the actions and assertions for that case.
Setup
beforeEach(async () => { deploy fresh contract }) ensures isolation between it cases.
Check your understanding

If two it blocks depend on a shared mutated state, rewrite them to deploy a fresh instance per test to avoid coupling.
