Hands-on › Terminal Demo
Full command sequence
Run these commands in order to scaffold and verify your Hardhat project.
$ mkdir my-first-dapp
$ cd my-first-dapp
$ npm init -y
$ npm install --save-dev hardhat
$ npx hardhat init   # choose option: Create a basic sample project
$ npx hardhat compile
Check 1
Run node -v and npm -v to confirm runtime before starting.
Check 2
Open package.json and confirm hardhat appears under devDependencies after install.
Check 3
Confirm artifacts/ and cache/ exist after npx hardhat compile.
