Assessment Prep
Verify and troubleshoot
A short checklist and remediation flow to confirm readiness for the lab and assessment.
Quick checklist
  1. Run node -v and npm -v to confirm installation.
  2. Run npm install --save-dev hardhat and confirm devDependencies in package.json.
  3. Run npx hardhat init and choose the basic sample project.
  4. Run npx hardhat compile and check artifacts/ and cache/.
Troubleshooting flow
  • If binary not found → ensure npm install completed and use npx to run local binary.
  • If permission denied → avoid sudo, use nvm or fix npm permissions.
  • If compilation errors → check solidity version in hardhat.config.js and contract syntax.
  • If PATH issues on Windows → restart the shell or system after installing Node.
Practice question
Why does hardhat init often fail when the user types it without npx? Answer: the hardhat binary is installed locally, not in the system PATH; npx runs the project-local binary in node_modules/.bin.
