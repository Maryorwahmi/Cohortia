Core Concept › Install Tooling
npm install --save-dev hardhat
Add Hardhat to devDependencies so the CLI stays local to the project.
Terminal (example)
$ npm install --save-dev hardhat
+ hardhat@2.x.x
added 50 packages from 40 contributors and audited 100 packages
This creates node_modules/ and package-lock.json and adds hardhat under devDependencies in package.json.
Why devDependency?
  • devDependencies are tools used during development and testing but not shipped with contract deployments.
  • Local installs recorded in package.json let other developers reproduce the environment with npm install.
  • Global installs can mask the version you depend on and cause inconsistencies in CI or teammates' machines.
Quick Check
Open package.json and confirm a devDependencies property containing hardhat; ensure node_modules and package-lock.json exist.
Key Takeaway

Install Hardhat as a devDependency to keep versions project-scoped and reproducible across collaborators.
