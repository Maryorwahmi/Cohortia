Process › Compile
npx hardhat compile
Compile contracts to produce artifacts and cache used by tests and deployment scripts.
Example terminal output
$ npx hardhat compile
Compiling 1 file with 0.8.4
Compilation finished successfully
Artifacts written to artifacts/
Cache written to cache/
If compilation fails, read the error and check the solidity version in hardhat.config.js or the sample contract syntax.
Artifacts vs. Cache
  • artifacts/: contains ABI and compiled bytecode used by scripts and frontends.
  • cache/: stores intermediate build data to speed incremental compiles.
  • Commit only source files and package manifests; artifacts and node_modules are typically ignored in .gitignore.
Try this
Run npx hardhat compile twice: observe that the second run is faster because the cache speeds up compilation.
Key Takeaway

Compilation succeeds when the toolchain and sample files are compatible; artifacts and cache confirm success.
