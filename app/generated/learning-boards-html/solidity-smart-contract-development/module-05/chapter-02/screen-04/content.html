node -v and npm -v
Quick terminal checks that confirm your runtime and package manager are installed correctly.
Terminal check (example)
$ node -v
v16.13.0
$ npm -v
8.1.0
If you see numeric output, your environment is ready. If not, reinstall Node or restart your terminal to update PATH.
Explanation
  • node -v prints the Node runtime version; Hardhat runs on Node so this must be present.
  • npm -v prints the package manager version; npm installs dependencies like Hardhat.
  • Missing output usually means Node wasn't installed correctly or PATH wasn't updated; try restarting your shell.
  • Avoid using sudo for npm installs; use a version manager if you need multiple Node versions.
Concrete Example
On a fresh machine, opening the terminal and running node -v should display a version like v16.x. If not, install the LTS version and then re-run the commands.
Key Takeaway

Confirming Node and npm is the first defensive step; it prevents confusing errors later when installing or running Hardhat.
