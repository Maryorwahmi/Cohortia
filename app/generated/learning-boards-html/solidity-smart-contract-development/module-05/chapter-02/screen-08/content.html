Basic sample project structure
A minimal scaffold that includes a contract, a deploy script, a test, and a config file to compile and run quickly.
contracts/
Contains Solidity files such as Greeter.sol used to teach compilation and deployment.
scripts/
Deployment and interaction scripts that demonstrate how to deploy the sample contract.
test/
Example test files show how to write automated tests for your contracts.
hardhat.config.js
The primary configuration file defining compilers, networks, and custom tasks. Confirm this file exists after initialization.
Concrete Advice
Select the basic sample project during initialization to receive a working example you can compile and test immediately. Treat these files as learning examples, not production-ready modules.
