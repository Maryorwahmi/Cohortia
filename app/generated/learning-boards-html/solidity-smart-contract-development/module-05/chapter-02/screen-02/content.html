Bloom: Learn → Understand → Apply → Master
01
Verify Node.js & npm
Run node -v and npm -v to confirm your runtime and package manager are available. This prevents obscured CLI failures later.
Mnemonic: version check → green light
VERIFIED COMPETENCY MILESTONE
02
Initialize package.json
Use npm init -y to create package.json. This file records dependencies, scripts, and ensures consistent installs across machines.
Mnemonic: manifest first
VERIFIED COMPETENCY MILESTONE
03
Install Hardhat as devDependency
npm install --save-dev hardhat keeps the CLI local to the project, recorded under devDependencies in package.json.
Mnemonic: dev-only tooling
VERIFIED COMPETENCY MILESTONE
04
Run npx hardhat init
Use npx to run the project-local Hardhat binary and create a basic sample project for hands-on practice.
Mnemonic: npx runs local CLI
