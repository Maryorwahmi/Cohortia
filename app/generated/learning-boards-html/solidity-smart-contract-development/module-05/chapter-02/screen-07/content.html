Definition › npx
npx hardhat init
Run the project-local Hardhat binary to scaffold or configure your project safely.
Command + prompts (example)
$ npx hardhat init
Welcome to Hardhat v2.x.x
What do you want to do?
  1. Create a basic sample project
  2. Create an advanced sample project
  3. Create an empty hardhat.config.js
  4. Quit
Choose 1 to create the basic sample project for the course exercises.
Notes and common misconception
  • npx looks for a matching binary in node_modules/.bin and runs it when present.
  • Using npx avoids needing global installs and ensures the correct tool version is executed.
  • If npx must fetch a package because no local binary exists, it uses a temporary copy — prefer local devDependencies instead.
Concrete Example
Run npx hardhat init and confirm you select Create a basic sample project to generate a ready-to-compile scaffold.
Key Takeaway

Always prefer npx to run project-local CLIs so teammates and CI use the same binary version.
