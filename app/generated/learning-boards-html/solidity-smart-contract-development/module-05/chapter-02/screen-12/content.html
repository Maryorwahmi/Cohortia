What each file and folder is for
A quick reference to help you manage source and artifacts correctly.
contracts/
Holds Solidity sources like Greeter.sol; these are compiled to ABI and bytecode.
scripts/
Deployment and helper scripts for automating interactions during development.
test/
JavaScript tests that validate contract behavior and prevent regressions.
hardhat.config.js
Main configuration specifying Solidity version, networks, and plugin settings.
node_modules/
Contains installed packages and binaries. Typically not committed to source control.
artifacts/ & cache/
Artifacts store ABI and bytecode; cache speeds up incremental compilation. Artifacts may be ignored in src repos depending on workflow.
Key Takeaway

Commit package.json and package-lock.json. Ignore node_modules and, depending on your release process, artifacts and cache. Understand each folder role to keep your repo clean.
