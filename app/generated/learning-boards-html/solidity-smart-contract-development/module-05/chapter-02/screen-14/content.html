What to Remember
Key Concepts
Short definitions to keep handy during setup.
Node.js
A JavaScript runtime used to run Hardhat and CLI tools outside the browser.
npm
The package manager that installs Hardhat and other project packages.
package.json
A manifest file listing dependencies and scripts for reproducible installs.
Summary: Install Node, create package.json, add Hardhat as a devDependency, and use npx to run the local CLI for reproducible development.
