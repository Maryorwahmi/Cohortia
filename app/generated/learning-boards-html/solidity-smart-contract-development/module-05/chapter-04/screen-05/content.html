Top-of-file directives
These two lines set compiler boundaries and license information for people and tools that inspect your source.
Example
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.9;
Here the caret allows 0.8.9 up to, but not including, 0.9.0. If you need a specific patch, avoid the caret and use an exact version.
Why it matters
Compiler changes can introduce subtle behavioral differences. A clear pragma protects you from accidental breaking changes, and a license comment makes legal status explicit for downstream users.
Common misconception
Pragma is not decorative: missing or incorrect pragma leads to warnings or compilation mismatch. Never rely on default behavior.
Check
Match your pragma to the compiler version used in hardhat.config.js and run a compile to confirm there are no compatibility warnings.
