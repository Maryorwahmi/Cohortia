Constructor usage
Use the constructor to establish a reliable initial state at deployment time.
Example
constructor() {
  _count = 0;
}
Or accept parameters to initialize different deployments: constructor(uint256 initialCount) { _count = initialCount; }.
Test
Deploy a fresh instance in a test and assert getCount returns the expected initial value.
Misconception
Constructors are not callable after deployment. Any required setup should happen inside the constructor or through explicit functions guarded by access checks.
Why it matters
Failing to initialize important state may leave the contract unusable or insecure. Make initialization explicit and test it.
