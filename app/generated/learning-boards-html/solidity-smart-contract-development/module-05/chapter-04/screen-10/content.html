Module 5 › Chapter 5.4 › decrement()
Safe decrement pattern
Validate preconditions with require to avoid invalid state transitions and provide a clear reason on revert.
Code
function decrement() public {
  require(_count > 0, "Counter cannot go below zero");
  _count--;
}
Runtime check
Call decrement when _count is zero and confirm the transaction reverts with the error message to validate your guard works.
Why explicit checks
Explicit requires provide readable errors, which improves developer and user experience when transactions fail.
Misconception
Relying solely on implicit arithmetic checks can leave you without a helpful error message. Use require to clarify the condition that failed.
