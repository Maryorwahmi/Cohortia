Turn objectives into quick checks
Each learning objective maps to a short action: create file, compile, run a view call, write a test for a state change. Use these checks to build confidence.
Quick Checklist
  • Create contracts/Counter.sol and run npx hardhat compile.
  • Add pragma and SPDX-License-Identifier, then recompile to confirm compatibility.
  • Implement getCount as a view and call it locally to verify return value.
  • Write tests or script to call increment, decrement and setCount to assert state changes.
Verified Competency
If compilation and simple tests succeed, you can claim competency in basic contract authoring and state management.
Bloom's Focus
Apply and test. Make the contract do something and verify it behaves as expected.
Common Pitfall
Forgetting the contracts folder or naming mistakes prevents Hardhat from compiling your file. A compile failure is often a path or pragma mismatch, not always a code bug.
