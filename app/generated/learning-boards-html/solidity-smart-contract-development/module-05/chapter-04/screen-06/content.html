State variables and visibility
Use appropriate types and visibility to express who may read or change data.
Example declaration
uint256 private _count;
This stores a non-negative integer in contract storage. private prevents other contracts from calling a Solidity-level selector to access it, although the stored value is still part of the chain state.
Misconception
private does not encrypt or hide data on-chain. Anyone inspecting the chain can still see stored values.
Architecture Snapshot
Contract
Encapsulates state and methods. The contract name defines the on-chain object you deploy.
State Variable
Persistent storage on the blockchain; choose types and visibility for correct semantics and gas cost considerations.
Quick rule
Use uint256 for counters and be explicit about visibility. Provide controlled access through view functions rather than exposing mutable state directly.
