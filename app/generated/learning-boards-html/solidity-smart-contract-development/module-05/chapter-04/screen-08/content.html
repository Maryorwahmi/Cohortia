getCount: a view function
Returns the current counter value without modifying contract state when called off-chain.
Code
function getCount() public view returns (uint256) {
  return _count;
}
Practical check
Call getCount from a script or console and confirm the provider returns a numeric result without creating a transaction.
Context
View is a mutability tag. It communicates intent and informs callers that the function will not persist state changes when executed as an eth_call.
Gotcha
Calling a view function inside another transaction contributes to gas for that transaction. view does not magically make transactions free.
Key Takeaway
Use view for read-only operations and confirm with an eth_call during development.
