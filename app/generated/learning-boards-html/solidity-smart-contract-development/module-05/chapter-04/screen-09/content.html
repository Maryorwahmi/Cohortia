Incrementing state
A simple state change demonstrates the transaction lifecycle and gas implications.
Code
function increment() public {
  _count = _count + 1; // or _count++;
}
Test tip
Call increment from a signer and then call getCount to confirm the new value. Each write costs gas; use local networks for quick iteration.
Gas note
Storage writes are expensive. Batch writes and avoid unnecessary storage churn to keep user costs low.
Pro-tip
Emit an event on important state changes so off-chain services can react without polling contract state continuously.
