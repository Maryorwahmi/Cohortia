Create contracts/Counter.sol
Put every contract file under the contracts folder so Hardhat compiles and generates artifacts predictably.
Process Steps
  1. Create a file named contracts/Counter.sol.
  2. Add top-level pragma and SPDX-License-Identifier.
  3. Write a minimal contract skeleton and run npx hardhat compile.
  4. Confirm artifact appears in artifacts/.
Common mistake
Saving the file in the wrong folder or using an unexpected file extension prevents automatic discovery and compilation.
Live-coding layout
Editor: skeleton file
// contracts/Counter.sol
// SPDX-License-Identifier: UNLICENSED
pragma solidity ^0.8.9;

contract Counter {
  // skeleton: state and functions will be added in later steps
}
Why this matters
Conventions reduce friction: compilers, deployment scripts, and tests expect a standard layout. Staying conventional avoids time-consuming debugging of tool configuration.
Check
Run npx hardhat compile. If you see a Counter artifact, you are ready to add logic.
