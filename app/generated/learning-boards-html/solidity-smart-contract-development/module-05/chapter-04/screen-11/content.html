Module 5 › Chapter 5.4 › setCount()
Accepting and assigning parameters
Parameters let you set state based on external input; validate when appropriate and consider access control.
Code
function setCount(uint256 newCount) public {
  _count = newCount;
}
Security note
If setCount is public, anyone can call it. Add owner checks or remove test-only setters before production deployment.
Parameter rules
Value types like uint256 do not require data location specifiers. For strings and arrays, use memory or calldata to avoid compilation errors.
Check
Write a test that calls setCount with a chosen value and asserts getCount returns that value immediately after the transaction is mined.
