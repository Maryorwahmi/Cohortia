Learning Objectives
Understand, write, and validate a minimal Solidity contract in Hardhat.
01
Create a contract file
Add contracts/Counter.sol so Hardhat finds your contract. This matters because Hardhat uses the contracts folder by convention to compile and deploy artifacts.

Write contract basics
Define a state variable, constructor, and functions that read and update state. This is the core structure of most contracts you will build.
VERIFIED COMPETENCY MILESTONE
03
Use pragma & SPDX
Specify compiler compatibility and license. These lines prevent unexpected compilation results and clarify licensing for third-party use.
VERIFIED COMPETENCY MILESTONE
04
Apply Solidity syntax
Choose types like uint256, set visibility such as public or private, and use require for validation to avoid invalid states.
