Definition › Compiler & Optimizer Settings
Key settings
  • solidity.version must equal the deployed compiler version.
  • solidity.settings.optimizer.enabled should match deployment.
  • solidity.settings.optimizer.runs must be the same number used at compile time.
Misconception check: changing optimizer runs can alter bytecode structure and lead to mismatches.
Config snippet
solidity: {
  version: "0.8.20",
  settings: {
    optimizer: {
      enabled: true,
      runs: 200,
    }
  }
}
Record these settings at deployment time. If you used a different tool or custom compilation pipeline, capture the exact compiler and settings used there as well.
