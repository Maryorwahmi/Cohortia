Process Flow › Running the Verify Command
Syntax and rules
  • Use the network flag to point at the network where the contract is deployed.
  • Provide the deployed contract address exactly.
  • Supply constructor arguments in order and format; quote strings.
Tip: copy constructor args from deployment artifacts to avoid encoding mistakes.
Example command
npx hardhat verify --network sepolia 0xYourContractAddress "My Token" "MTK"
If verification fails with argument errors, check order, types, and quoting. For complex types use the same encoding used during deployment.
