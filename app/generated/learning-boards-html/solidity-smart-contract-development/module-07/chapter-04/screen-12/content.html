Hands-on › Lab Walkthrough — Setup
Deploy and capture address
Run your deployment script with the sepolia network flag and note the deployed address printed by the script. Keep this address handy for verification.
npx hardhat run scripts/deploy_counter.js --network sepolia
Install plugin and set API key
Install the plugin, require it in config, and add ETHERSCAN_API_KEY to .env. Confirm .env is ignored by git.
Mistake to avoid: forgetting to add .env to .gitignore and exposing your key.
