Process Flow › Install and Configure Plugin
Steps
  1. Run npm install --save-dev @nomicfoundation/hardhat-etherscan in your project.
  2. Require the plugin and dotenv in hardhat.config.js so environment variables are available.
  3. Add an etherscan object with apiKey: process.env.ETHERSCAN_API_KEY to your module.exports.
Security note: keep your API key in .env and never commit it.
Config example
// hardhat.config.js
require("@nomicfoundation/hardhat-toolbox"); // includes etherscan plugin
require("dotenv").config();

module.exports = {
  solidity: "0.8.20",
  networks: { /* ... */ },
  etherscan: {
    apiKey: process.env.ETHERSCAN_API_KEY,
  },
};
This example shows the minimal entries you need. If you used optimizer settings during deployment, include them under solidity.settings as well.
