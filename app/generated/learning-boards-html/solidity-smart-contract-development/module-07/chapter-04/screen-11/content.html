Process Flow › Verification Scope
Public networks

Only contracts deployed to public explorers like Sepolia and Mainnet can be verified on Etherscan.

If you deploy to Sepolia, use the sepolia network flag when verifying; local deployments cannot be validated publicly.
Address sanity

Always use the exact deployed address when calling the verify command. Mistyping the address produces failures unrelated to compilation.

Quick Check

Confirm network and address before running verification to avoid time-consuming debugging.
