Module 7 › Chapter 7.4 › Learning Objectives — Lab Focus
Four lab tasks
01 Inspect
View an unverified contract on Sepolia and note the missing source and UI limitations.
02 Install
Add the Hardhat Etherscan plugin to your project and require it in hardhat.config.js.
03 Configure
Set your Etherscan API key in .env and match compiler/optimizer settings to deployment.
04 Verify
Run npx hardhat verify with the network, address, and correct constructor args.
Checklist mnemonic
Use the checklist: Address, API key, Compiler, Optimizer, Args. Confirm each item before running verification.
