Definition › Etherscan API Key & Secure Storage
Where it comes from

Create an account on Etherscan and generate an API key; the same key works for supported testnets.

Add ETHERSCAN_API_KEY to .env and reference it via process.env in hardhat.config.js.
Security best practices
  • Never hardcode the API key into source files.
  • Add .env to .gitignore and use CI secrets for automated pipelines.
  • Restrict key usage and rotate if compromised.
