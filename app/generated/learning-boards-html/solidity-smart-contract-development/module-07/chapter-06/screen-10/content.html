Module 7 › Chapter 7.6 › Event Listeners
Listener patterns
window.ethereum.on('accountsChanged', (accounts) => {
  if (accounts.length === 0) {
    // user disconnected
  } else {
    // update signer and contract instances
  }
});

window.ethereum.on('chainChanged', (chainId) => {
  // recommended: reload or re-init provider/signer
  window.location.reload();
});
Reloading is a simple approach, but you can also programmatically re-initialize provider, signer and contracts for a smoother UX.
UI guidance
Notify the user immediately when accounts or chains change and show what decisions your app made in response.
Warning

Not handling account or chain changes yields stale signer usage and can cause transactions to be signed by the wrong account.
