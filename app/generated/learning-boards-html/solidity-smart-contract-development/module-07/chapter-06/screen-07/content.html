Module 7 › Chapter 7.6 › Calling a view function (getCount)
Code snippet
async function getCount() {
  try {
    const currentCount = await counterContract.count();
    document.getElementById('countDisplay').innerText = currentCount.toString();
  } catch (error) {
    console.error('Error getting count:', error);
    document.getElementById('countDisplay').innerText = 'Error';
  }
}
Use provider-based contract instances for reads to avoid any signing prompts and to keep the UI responsive.
UX elements
  • Show a Loading state while awaiting the read call.
  • Handle and display errors clearly, not just in the console.
  • Refresh reads after tx.wait resolves to surface new state.
