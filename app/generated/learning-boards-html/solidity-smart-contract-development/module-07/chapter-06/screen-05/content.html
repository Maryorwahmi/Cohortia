Module 7 › Chapter 7.6 › Detecting and Connecting a Wallet
Steps to connect
1
Check if window.ethereum exists to detect a wallet.
2
Call window.ethereum.request with method eth_requestAccounts.
3
On success, enable actions and create provider/signer; on failure, show a message.
4
Register accountsChanged and chainChanged listeners to handle runtime changes.
Example Guard
if (typeof window.ethereum !== 'undefined') {
  await window.ethereum.request({ method: 'eth_requestAccounts' });
  // proceed to create provider/signer
} else {
  // show install wallet message
}
UX tips
  • Disable transaction controls until the user connects.
  • Show clear status messages: not connected, connecting, connected.
  • On rejection, provide retry and brief explanation of why the request is needed.
