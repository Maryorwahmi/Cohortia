Module 7 › Chapter 7.6 › Common Mistakes and Defensive Patterns
Missing Wallet
Always check typeof window.ethereum !== 'undefined' before calling request. Provide an install message if absent.
Forgotten awaits
Await tx.wait for writes. Not doing so results in stale reads and poor UX.
Exposed keys
Never store private keys in front-end code; signing must occur inside the user's wallet.
Pro-tip
Use clear UI states and disable controls until the app is ready. Log useful errors but also show friendly messages to the user so they understand next steps.
