Module 7 › Chapter 7.6 › Read vs Write
Read (Provider)
  • Free, fast, no wallet confirmation.
  • Use for state display and periodic refreshes.
  • Attach provider to the contract instance.
Write (Signer)
  • Requires user signature in wallet and creates a transaction.
  • Always await tx.wait and show pending/confirmed states.
  • Attach signer to the contract instance for writes.
UX checklist
Minimize prompts, show clear messages for confirmation and pending transactions, and avoid unnecessary signer attachment for simple reads.
