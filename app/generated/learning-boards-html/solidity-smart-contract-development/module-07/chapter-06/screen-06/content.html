Module 7 › Chapter 7.6 › Provider and Signer in ethers.js
Code walkthrough
// After user connects
const provider = new ethers.providers.Web3Provider(window.ethereum);
const signer = provider.getSigner();

// For read-only calls
const readOnlyContract = new ethers.Contract(contractAddress, contractABI, provider);

// For state-changing calls
const writableContract = new ethers.Contract(contractAddress, contractABI, signer);
Remember to re-create the signer if accountsChanged fires. The provider is safe to reuse for reads across the session.
Example
Use provider for getCount, and signer for increment so MetaMask prompts for confirmation.
Pro tip
If you only need reads, passing provider reduces unnecessary user prompts. Only attach signer when a write is required.
