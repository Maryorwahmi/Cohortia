Module 7 › Chapter 7.6 › Learning Objectives
User Experience Goals
  • Show install instructions when window.ethereum is undefined.
  • Update UI states: not connected, pending transaction, confirmed.
  • Listen for accountsChanged and chainChanged and respond appropriately.
Error & Edge Cases
  • Handle user rejection of eth_requestAccounts with a friendly message.
  • Always guard calls with if (typeof window.ethereum !== 'undefined').
  • Remember to await tx.wait for consistent state updates.
Verification Tasks
Build the index.html file with the ethers.js CDN, click Connect Wallet, confirm MetaMask prompts, run getCount to read the contract, and trigger increment to observe a MetaMask transaction and a status update after tx.wait.
