Basic Front-End Interaction
Connect wallets, get Provider and Signer, call contracts safely from the browser.
In this lesson

You will wire window.ethereum to an ethers.js Web3Provider, obtain a signer, attach an ABI and address, and make read and write calls with clear UX for confirmations and errors.

Why it matters

Front-end integration is the bridge between your contract logic and real users. Correct handling of providers, signers and transaction lifecycle prevents bad UX and security mistakes.

Explore Key Topics
Wallet Connect
Detect window.ethereum and request accounts.
Provider & Signer
Provider for reads, Signer for signed transactions.
Read vs Write
View calls are free; state changes create transactions and must be awaited.
Visual: Browser -> Wallet -> Contract
Browser
Contains your dApp. Loads ethers.js and code that requests the user to connect their wallet.
Wallet (MetaMask)
Exposes window.ethereum and performs secure signing inside the extension or mobile app.
Contract (ABI + Address)
The ABI tells ethers.js which functions exist and how to encode calls to the deployed address.
