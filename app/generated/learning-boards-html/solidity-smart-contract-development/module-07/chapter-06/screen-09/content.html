Contract instantiation
const counterContract = new ethers.Contract(contractAddress, contractABI, signer);
// or for reads
const counterRead = new ethers.Contract(contractAddress, contractABI, provider);
Keep contractABI extracted from your build artifacts to ensure function signatures match the deployed bytecode.
Network alignment
Ensure the wallet is on the same network as the deployed contract (for example, Sepolia in this exercise). If networks mismatch, calls will fail or return unexpected values.
Scenario
A contract deployed to Sepolia will not be reachable if the user's wallet is on Mainnet. Prompt users to switch networks when necessary.
