Module 7 › Chapter 7.6 › Common Assessment Questions
Question 1
Why does window.ethereum.request throw 'cannot read request of undefined' and how would you fix it?
Expected answer: window.ethereum is undefined; add a typeof check and inform the user to install a wallet.
Question 2
A confirmed transaction was submitted but the UI still shows old data. What did you forget?
Expected answer: forgetting to await tx.wait before polling the updated state.
Grading checklist
  • Shields against missing wallet and user rejection.
  • Correct provider/signer usage and tx.wait calls.
  • Event listeners for account and chain changes are implemented.
