Module 7 › Chapter 7.6 › Calling a state-changing function (increment)
Write call pattern
async function incrementCounter() {
  try {
    const tx = await counterContract.increment();
    await tx.wait();
    await getCount();
  } catch (error) {
    console.error('Error incrementing counter:', error);
  }
}
Show a 'pending' message after tx is submitted and replace it with 'confirmed' after tx.wait resolves to avoid confusing the user.
Example scenario
User clicks Increment, MetaMask prompts for gas and confirmation, the app shows 'Incrementing... Confirm in MetaMask.', then waits for tx.wait and updates the count when confirmed.
Common mistake
Not awaiting tx.wait leads to stale reads and poor UX because your UI may refresh before the block containing the transaction is mined.
