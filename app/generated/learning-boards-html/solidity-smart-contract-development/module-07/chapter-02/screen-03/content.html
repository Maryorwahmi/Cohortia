Install and verify dotenv
Run npm install --save-dev dotenv and require it in hardhat.config.js to load variables from .env at runtime.
Checklist
  • Install dotenv
  • Create .env with keys
  • Add .env to .gitignore
Why separate keys?
Use distinct testnet keys to isolate risk if a test key is exposed.
File and repo hygiene
Ensure .env appears in .gitignore and confirm with git status before committing.
Example
Add the single line .env to your .gitignore file so local secrets never enter version control history.
Quick tip
Prefer a hardware wallet or separate deployment key for Mainnet to reduce exposure.
