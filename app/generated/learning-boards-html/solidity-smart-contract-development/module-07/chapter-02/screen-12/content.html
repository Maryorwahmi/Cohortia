Pre-deploy checklist
  • dotenv is installed and required in hardhat.config.js
  • .env exists with SEPOLIA_RPC_URL and PRIVATE_KEY and is added to .gitignore
  • sepolia entry uses process.env values and chainId is 11155111
  • Test connectivity by querying account balance
  • Use distinct keys for testnet and Mainnet; prefer hardware wallet for Mainnet
Safety tip
Rotate API keys after accidental exposure and avoid reusing keys across environments.
Final question
If one of your keys were leaked, which network would you revoke first and why?
