Module 7 › Chapter 7.2 › What is hardhat.config.js?
Definition
A JavaScript module exporting a configuration object that controls compilation, networks, and tasks.
Why it matters
Centralized settings make builds reproducible and deployments explicit.
Concrete example
Exporting solidity: '0.8.20' pins the compiler version so all contributors compile identically.
Misconception
It's not just convenience; it controls which keys sign and which networks receive transactions.
Key Takeaway

Treat hardhat.config.js as your project's deployment manifest and audit it before any network action.

Annotated structure
Top-level fields
  • solidity: compiler version
  • networks: named endpoints and accounts
  • plugins and paths
Practical check
Before running deploy scripts verify that each network entry has a valid url and accounts when targeting a public network.
