Module 7 › Chapter 7.2 › Accounts and private keys
What are private keys?
Secrets that authorize transactions from a wallet and control its funds.
Concrete example
Place your test wallet key in PRIVATE_KEY inside .env and load it with dotenv so deployments sign with that key only.
Danger
Hardcoding a Mainnet private key in source exposes it to theft and accidental pushes to remote repositories.
Best practice
Use environment variables for keys and distinct keys per environment; prefer hardware wallets for Mainnet.
Practical steps
  1. Install dotenv and require it in hardhat.config.js
  2. Create .env with PRIVATE_KEY="0x..." and SEPOLIA_RPC_URL
  3. Verify .env is listed in .gitignore and confirm with git status
Key Takeaway

Never commit private keys. Store them in environment variables and isolate testnet and production keys.
