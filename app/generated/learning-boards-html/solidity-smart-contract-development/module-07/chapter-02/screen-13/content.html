Module 7 › Chapter 7.2 › Key Concepts
hardhat.config.js
The single export that defines compiler and network behavior for your project.
RPC URL
Endpoint that allows your project to query and send transactions to a node; often requires an API key.
Private Key & dotenv
Store keys in .env and load them via dotenv; never commit .env and prefer separate keys per network.
Summary takeaway: Centralize configuration, keep secrets out of source, and set explicit chain identifiers to deploy safely and predictably.
