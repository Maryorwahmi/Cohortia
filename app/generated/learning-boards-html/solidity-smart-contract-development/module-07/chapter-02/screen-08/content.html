Module 7 › Chapter 7.2 › Using dotenv in hardhat.config.js
Commands and files
Install dotenv as a dev dependency and create a .env containing SEPOLIA_RPC_URL and PRIVATE_KEY. Ensure .env is in .gitignore.
.env example
SEPOLIA_RPC_URL="https://eth-sepolia.g.alchemy.com/v2/YOUR_ALCHEMY_API_KEY"
PRIVATE_KEY="0x..."
hardhat.config.js snippet
// hardhat.config.js
require("@nomicfoundation/hardhat-toolbox");
require("dotenv").config(); // Load environment variables

module.exports = {
  solidity: "0.8.20",
  networks: {
    sepolia: {
      url: process.env.SEPOLIA_RPC_URL,
      accounts: [process.env.PRIVATE_KEY],
      chainId: 11155111,
    },
    mainnet: {
      url: process.env.MAINNET_RPC_URL || "", // Placeholder
      accounts: process.env.MAINNET_PRIVATE_KEY !== undefined ? [process.env.MAINNET_PRIVATE_KEY] : [],
      chainId: 1,
    }
  }
};
Note the placeholder pattern for Mainnet to avoid accidental use of a real key in source.
