Module 7 › Chapter 7.2 › Secure Sepolia deployment setup
Steps
  1. npm install --save-dev dotenv
  2. Create .env with SEPOLIA_RPC_URL and PRIVATE_KEY
  3. Add .env to .gitignore and verify with git status
  4. Require dotenv in hardhat.config.js
  5. Test connectivity by querying account balance
Common mistakes
  • Wrong environment variable names
  • Not restarting shell after adding env vars
  • Using Mainnet key for test deployments
Quick verification
Run a small script that prints the account balance. If it connects and returns a numeric balance, RPC and key are valid.
