Calling a view function
View and pure functions return data without creating a transaction. They use the provider for a local simulation.
// read a public state variable
const current = await counter.count();
console.log(`Current count: ${'${current.toString()}'}');
When to use reads
  • Displaying UI state
  • Running tests that assert values
  • Monitoring contract metrics
Misconceptions
A view call will never emit events or permanently change state. If you need to mutate state, you must send a transaction with a signer and await its confirmation.
