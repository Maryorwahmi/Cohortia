Where to find the ABI
Hardhat writes compiled artifacts with bytecode and ABI. Use artifacts path to load the ABI into scripts and tasks.
Code
// load ABI from Hardhat artifact
const artifact = require("../artifacts/contracts/Counter.sol/Counter.json");
const abi = artifact.abi;
const counter = new ethers.Contract(CONTRACT_ADDRESS, abi, ethers.provider);
Practical check
  • Confirm compile step completed before running scripts
  • Use the artifact from your project, not a copied ABI
  • Match the contract name and compiled output version
Why loading artifacts matters
Loading ABI from artifacts ensures your scripts target the exact interface your source compiled into. It avoids mismatches that lead to call failures or decoded values that make no sense.
Misconception
An ABI copy from elsewhere might mismatch parameter names or types; always prefer the project's compiled artifact to keep interface parity.
Try this

After compiling, open artifacts/.../Contract.json and inspect the abi array to confirm your expected functions exist before running a script against a deployed address.
