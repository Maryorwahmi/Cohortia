Module 7 › Chapter 7.5 › Learning Objectives
Locate ABI artifacts
Hardhat saves compiled artifacts under artifacts/contracts/<ContractName>.sol/<ContractName>.json. Load the ABI into scripts to instantiate contracts correctly.
Verified competency milestone
Attach vs getContractAt
getContractAt lets you fetch a deployed contract by name and address; attach uses a factory to bind an address to the compiled interface. Both produce a Contract instance.
Verified competency milestone
Diagnose interaction errors
Check signer vs provider, network selection, ABI mismatches, and whether tx.wait() was awaited to avoid race conditions.
Verified competency milestone
Send ETH and check receipts
Use overrides to send value to payable functions or signer.sendTransaction to fund a contract; then inspect the TransactionReceipt for gas and events.
Verified competency milestone
