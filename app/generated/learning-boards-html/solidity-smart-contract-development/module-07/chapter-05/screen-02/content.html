Learning Objectives
Build, run, and automate contract interactions using Hardhat and ethers.js.
Learn
Understand
Apply
Master
01
Create a Contract instance
Instantiate an ethers.Contract using an address and ABI to interact with deployed code. This matters because without a correct ABI the calls cannot be encoded or decoded properly.
Verified competency milestone
02
Call read-only functions
Use a Provider to call view/pure functions that cost no gas. Example: reading a counter value locally from the RPC node.
Verified competency milestone
03
Send state-changing transactions
Use a Signer to send transactions, await tx.wait(), and inspect the TransactionReceipt for gas used and events.
Verified competency milestone
04
Automate with scripts & tasks
Write Hardhat scripts and define tasks to run interactions from the CLI. This saves time and reduces manual errors in repeated operations.
Verified competency milestone
