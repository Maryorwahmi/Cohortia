Module 7 › Chapter 7.5 › Response vs Receipt
TransactionResponse
Returned immediately after sending a transaction. Contains the hash and a promise to wait for the receipt.
const tx = await counter.increment();
console.log(tx.hash);
// tx is a TransactionResponse
TransactionReceipt
Returned after await tx.wait(); includes gasUsed, blockNumber, and logs with emitted events for validation.
const receipt = await tx.wait();
console.log(receipt.blockNumber, receipt.gasUsed);
console.log(receipt.logs); // event data
Debugging tip
Log the tx.hash for explorer lookup and inspect receipt.logs to confirm expected events emitted by your contract.
