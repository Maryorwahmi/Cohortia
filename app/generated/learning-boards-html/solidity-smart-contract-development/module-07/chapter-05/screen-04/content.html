What a Contract instance contains
Address locates the deployed code. ABI describes functions, events, and types. Signer or Provider determines read/write capabilities.
Example
Using a Counter contract, attaching yields callable methods like count(), increment(), and decrement().
Misconception
The ABI is not secret; it contains no private keys or state. It only describes the public surface for encoding and decoding.
Key Takeaway

A correct address and matching ABI are required for predictable interactions; mismatches lead to call failures or incorrect decoding.

Code snippets
// using Hardhat helper
const counter = await ethers.getContractAt("Counter", "0xDeployedAddress...");

// or directly with ABI
const contractABI = require("../artifacts/contracts/Counter.sol/Counter.json").abi;
const counter2 = new ethers.Contract("0xDeployedAddress...", contractABI, ethers.provider);
Check you loaded the right ABI
  • Confirm artifact path artifacts/contracts/<Name>.sol/<Name>.json
  • Match function names and parameter types with your Solidity source
  • Ensure address corresponds to the deployed network
