Module 7 › Chapter 7.5 › Sending ETH
Payable function call
Call a contract function that is payable and include value in the overrides object to send ETH along with the call.
// send 0.1 ETH to a payable function
await contract.deposit({ value: ethers.utils.parseEther("0.1") });
Direct transfer to address
Use the signer to send ETH to the contract address without invoking a specific function.
// fund the contract
await signer.sendTransaction({ to: contractAddress, value: ethers.utils.parseEther("0.5") });
Unit caution
Always convert human-readable ETH values to wei using parseEther or you'll send incorrect amounts.
