Interacting with Deployed Contracts
Use address + ABI to create a Contract instance. Read with a Provider, write with a Signer, and automate with scripts or tasks.
In this lesson
Get Contract instances, call view functions, send transactions, and write scripts.
Tools
Hardhat, ethers.js, artifacts ABI, signer vs provider.
Why it matters
Safely interacting with contracts is essential for testing, deployment, and production scripts.
Coming up
Hands-on examples using a Counter contract, a sample interaction script, and a Hardhat task to automate increments.
Quick orientation
Contract = address + ABI. Provider for reads. Signer for writes. Await tx.wait() for confirmations. Small mistakes here cause failed interactions.
Visual concept
Address + ABI → Contract instance → Read / Write
Address
Where the contract lives on-chain.
ABI
JSON description of functions, events and types.
Signer / Provider
Provider: read-only. Signer: signs & pays gas.
