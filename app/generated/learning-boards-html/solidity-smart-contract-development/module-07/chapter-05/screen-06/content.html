Module 7 › Chapter 7.5 › Provider vs Signer
Provider
Connects to an RPC node for read-only queries. No signing and no gas expenditure.
Example
const counter = new ethers.Contract(addr, abi, ethers.provider); const current = await counter.count();
Misuse
Attempting a state-changing call with only a provider will fail because no signature or gas payment is provided.
Signer
Represents an account with a private key; can sign and send transactions and pay gas.
Example
const [signer] = await ethers.getSigners(); const counter = new ethers.Contract(addr, abi, signer); const tx = await counter.increment();
Pro tip

Use provider-based reads in monitoring tools to avoid unnecessary gas. Use signer for controlled writes, and always confirm the signer is on the correct network.
