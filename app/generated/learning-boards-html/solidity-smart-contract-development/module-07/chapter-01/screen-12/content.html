Module 7 › Chapter 7.1 › Testing Cadence
Recommended cadence
Local Unit Tests
Run on every change for fast feedback.
CI & Automation
Automate local tests to catch regressions early.
Sepolia Integration
Scheduled staging runs for end-to-end checks.
What to automate
  • Unit tests and linting on commits.
  • Gas reporting and coverage on PRs.
Integration checks
Test wallet flows, oracles, and contract interactions on Sepolia before release.
Key Takeaway

Balance speed and realism: automate local tests for speed, and use Sepolia for realistic integration checks.
