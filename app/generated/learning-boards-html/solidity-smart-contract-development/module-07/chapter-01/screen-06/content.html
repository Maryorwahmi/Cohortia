Module 7 › Chapter 7.1 › Local Development Networks
What they provide
Speed, resets, and free ETH

Local networks let you run tests and experiments with instant confirmations and a resettable chain state so you can iterate quickly.

Hardhat Network
Built-in network that integrates with Hardhat tests and scripts. Fast and convenient.
Ganache / Anvil
Alternative local nodes useful for isolated environments and certain debugging tools.
Concrete example
Running npx hardhat test launches a local Hardhat Network instance, deploys contracts, executes tests, and tears down the node automatically for quick feedback.
Misconception
Local networks are not substitutes for testnets; they do not reproduce public network latency, gas dynamics, or external services' behavior.
Key Takeaway

Use local nodes for fast tests. Always follow with public testnet checks before Mainnet deployment.
