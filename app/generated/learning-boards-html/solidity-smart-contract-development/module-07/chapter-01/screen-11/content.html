Module 7 › Chapter 7.1 › Hands-on Activity
Step-by-step checklist
  1. Initialize a new Hardhat project: npx hardhat and choose the basic sample project.
  2. Install dotenv: npm install --save-dev dotenv.
  3. Create a .env with SEPOLIA_RPC_URL and PRIVATE_KEY (use a test wallet).
  4. Update hardhat.config.js to load dotenv and add the sepolia block with chainId 11155111.
  5. Run npx hardhat test locally, then deploy to sepolia with npx hardhat run --network sepolia script/deploy.js.
Common pitfalls
Do not commit .env, do not use a production private key for testnets, and double-check network names in deployment commands.
Concrete example
After configuring .env and hardhat.config.js, run a local deploy and a Sepolia deploy. Check transaction receipts for chainId 11155111 to confirm you are on Sepolia.
Key Takeaway

Practice the full flow locally first, then repeat it on Sepolia with a test wallet and faucet ETH.
