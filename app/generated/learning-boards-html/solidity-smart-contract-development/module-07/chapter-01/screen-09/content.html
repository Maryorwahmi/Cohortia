Module 7 › Chapter 7.1 › Mistakes & Safety
Common mistakes
  • Deploying to Mainnet by mistake.
  • Using a production-funded wallet for tests.
  • Committing private keys or revealing secrets in source control.
Safety measures
  • Use .env and environment variables for keys and RPC URLs.
  • Maintain separate test and production wallets.
  • Add explicit deploy confirmations and network checks in scripts.
Key Takeaway

Treat deployment like an operational task with checks, separation of secrets, and pre-deploy confirmations.
