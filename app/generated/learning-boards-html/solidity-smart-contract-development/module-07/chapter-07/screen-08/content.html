Parse logs from a receipt
Use parseLog to decode known event logs; skip unknown logs safely.
const tx = await contract.increment();
const receipt = await tx.wait();
for (const log of receipt.logs) {
  try {
    const parsed = contract.interface.parseLog(log);
    if (parsed.name === "CountChanged") {
      console.log(`Parsed event: ${parsed.args.user} -> ${parsed.args.newCount}`);
    }
  } catch (e) {
    // log not from this contract or unknown event — ignore
  }
}
  • Always use try-catch around parseLog to avoid crashing on unrelated logs.
  • Indexed fields live in topics; parseLog returns both indexed and non-indexed args in parsed.args.
  • Use this pattern in tests to assert the correct events were emitted with expected values.
Concrete example
After calling increment, a script can immediately confirm the user and newCount from the parsed receipt, providing a reliable assertion in tests and scripts.
Common mistake
Trying to parse logs without the correct contract interface will fail. Always attach the ABI for the contract you expect to parse.
Key Takeaway

Parsing receipts gives immediate, deterministic confirmation that a transaction emitted expected events — wrap parse calls in try-catch to handle unrelated logs.
