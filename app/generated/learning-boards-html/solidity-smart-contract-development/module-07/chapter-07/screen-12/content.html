Quick runbook
  1. Deploy updated Counter and copy address.
  2. Run listener: npx hardhat run scripts/listen_events.js --network sepolia (or localhost).
  3. In another terminal, call increment and decrement via a script or console.
  4. Observe listener output and verify parsed receipt logs.
// Example: send tx and parse
const tx = await counter.increment();
const receipt = await tx.wait();
for (const log of receipt.logs) {
  try { const parsed = counter.interface.parseLog(log); console.log(parsed.name, parsed.args); } catch (e){}
}
Key Takeaway

Run the full cycle in your dev environment to observe how emit, listen, query, and parse work together in practice.

Try this edge case
Interact with another contract in the same block to inject unrelated logs and see why parseLog requires try-catch handling when iterating receipt.logs.
Pro tip
When reconstructing history for a UI, paginate by block windows and cache results to avoid repeated heavy queries.
