Learning Objectives
Four verified competencies you will build
01
Define and emit events
Write Solidity events with appropriate types and indexed parameters. Emitting logs is cheaper than storing history in contract storage.
Mnemonic: think of events as a publish-only activity log.
VERIFIED COMPETENCY MILESTONE
02
Listen and query with ethers.js
Attach runtime listeners using contract.on and retrieve historical data using queryFilter with indexed filters.
Mnemonic: live stream vs replaying a log.
VERIFIED COMPETENCY MILESTONE
03
Parse receipts with parseLog
Decode raw logs found in a mined transaction's receipt to confirm event arguments right after a state change.
Mnemonic: receipts are the transaction's storybook.
VERIFIED COMPETENCY MILESTONE
04
Advanced interactions and gas
Plan batching, manage nonces, and set gas limits or EIP-1559 fees for fast, reliable inclusion when timing matters.
Mnemonic: gas strategy is your transaction's priority tag.
VERIFIED COMPETENCY MILESTONE
