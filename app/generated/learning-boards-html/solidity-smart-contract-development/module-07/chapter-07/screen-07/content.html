Filter by indexed parameter
Use contract.filters to build efficient filters for queryFilter.
// Example: fetch Minted events for a specific owner
const userAddress = await signer.getAddress();
const filter = contract.filters.Minted(userAddress, null);
const mintedEvents = await contract.queryFilter(filter, startBlock, endBlock);
// mintedEvents now contains decoded event objects for this contract ABI
  • Always provide sensible start and end blocks to limit the scope.
  • Paginate over block windows for long histories to avoid timeouts.
  • If the ABI changes, be cautious: older logs may not decode cleanly.
Scenario
Build a UI list of NFTs minted by the connected user by filtering Minted events with the owner's address in the indexed slot.
Common mistake
Fetching all events and filtering client-side is inefficient and slow; prefer node-side filtering via indexed parameters where possible.
Key Takeaway

Use contract.filters with indexed fields and queryFilter over bounded block ranges to retrieve relevant historical logs efficiently.
