Module 8 › Chapter 7.7 › Common Mistakes
Four common mistakes
  • Not indexing searchable fields and then filtering client-side.
  • Parsing logs without handling unknown logs or ABI changes.
  • Using providers that don't support the subscription type you need.
  • Poor nonce and gas handling when sending many transactions.
Robust pattern
Add try-catch around parseLog, choose indexed fields intentionally, use WebSocket providers for listeners, and test events in unit tests by decoding receipts.
Test checklist
For every event: verify it's emitted after state change, check indexed values are searchable via queryFilter, and parse a receipt during tests to assert arguments.
Key Takeaway

Adopt small, repeatable checks for indexing, parsing, provider compatibility, and nonce handling to avoid common production issues.
