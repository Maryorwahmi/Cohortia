Comparison
Error → Likely cause → Fix
Insufficient funds
Top up the deploying account with test ETH from a faucet or use another funded wallet.
Incorrect private key
Confirm the private key in hardhat.config.js and ensure it's the test wallet, not your main wallet.
Invalid RPC URL
Verify the RPC endpoint and network name; try connecting with a simple provider call to confirm reachability.
More errors
Constructor argument mismatch
Re-check the constructor signature and pass arguments in the correct order and type.
Missing await deployed()
Add await contract.deployed() to ensure mining before subsequent interactions.
Troubleshooting checklist
Read the stack trace, verify balance and key, confirm RPC reachability, recompile contracts, and re-run the script with logging.
