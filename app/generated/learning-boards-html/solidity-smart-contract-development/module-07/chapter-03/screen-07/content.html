Definition
Pass constructor arguments
Constructor arguments are supplied to deploy() in the same order and types as the Solidity constructor declaration.
// Token example
const Token = await ethers.getContractFactory('MyToken');
const token = await Token.deploy('My Awesome Token', 'MAT');
await token.deployed();
console.log(token.address);
Common errors and checks
  • Missing arguments: deploy() fails because constructor signature is not satisfied.
  • Wrong types: pass strings for string parameters, addresses as strings, and use BigNumber or string for large integers.
  • Mismatched names: ensure getContractFactory uses the correct contract name matching the compiled artifact.
Quick check
Log your arguments before deploy to confirm they match the constructor and avoid sending transactions with incorrect initialization.
Key Takeaway

Match types and order exactly when passing constructor arguments to avoid immediate deployment failures.
