Process
Run with the Hardhat CLI
Execute scripts locally or on a named network using the --network flag and ensure configuration is correct beforehand.
// Local deployment
npx hardhat run scripts/deploy_counter.js --network localhost

// Testnet deployment
npx hardhat run scripts/deploy_counter.js --network sepolia
Checklist before running
  • Compile contracts so artifacts exist for getContractFactory.
  • Verify hardhat.config.js has RPC URL and private key set for the target network.
  • Confirm the deploying account has sufficient ETH for gas on the chosen network.
Observation
The CLI will show console logs from your script; capture the address and transaction hash printed there for later use.
Key Takeaway

Use the CLI command with the desired --network and verify configuration and balances to avoid avoidable failures.
