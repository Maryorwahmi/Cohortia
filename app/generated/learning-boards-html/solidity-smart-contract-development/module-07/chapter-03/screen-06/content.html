Process Flow
Initiate → Confirm
deploy() initiates the on-chain creation; deployed() waits for the mining confirmation that makes the contract address usable.
// pattern to capture both identifiers
const token = await MyToken.deploy('Name','SYM');
console.log('deploy tx hash:', token.deployTransaction.hash);
await token.deployed();
console.log('contract address:', token.address);
Explanation and common pitfalls
  • deploy() returns a Contract object immediately, but the blockchain state may not include it until mined.
  • deployed() resolves when the deployment transaction is mined and the address is valid for interaction.
  • On public testnets confirmation times vary; always await deployed() before calling contract methods.
Common mistake
Skipping await deployed() leads to failed interactions because the contract may not yet exist at the address you expect.
Key Takeaway

Always await the confirmation step to guarantee the blockchain has recorded the new contract before proceeding.
