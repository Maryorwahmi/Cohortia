Learning Objectives
Build skills to write, run, and validate Hardhat deployment scripts.
Bloom: Learn → Understand → Apply → Master
01
Understand deployment steps
Describe each step from factory creation to awaiting confirmation and why awaiting is required for reliable interactions.
VERIFIED COMPETENCY MILESTONE
02
Write deployment scripts with ethers.js
Create scripts that call ethers.getContractFactory and deploy, including passing constructor arguments when required.
VERIFIED COMPETENCY MILESTONE
03
Execute on local and public testnets
Use the Hardhat CLI to run scripts locally for speed and on testnets for external verification, and configure RPC and keys properly.
VERIFIED COMPETENCY MILESTONE
04
Interpret output and troubleshoot
Read the contract address and transaction hash, and diagnose failures like insufficient funds, wrong RPC, or missing await deployed().
VERIFIED COMPETENCY MILESTONE
