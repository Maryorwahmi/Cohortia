Get ContractFactory
The factory contains compiled bytecode and the ABI and provides the deploy method to create a contract instance.
Code pattern
const { ethers } = require('hardhat');

async function main() {
  const Counter = await ethers.getContractFactory('Counter');
  // Counter is a factory, not an instance
  const counter = await Counter.deploy();
  await counter.deployed();
  console.log('Counter deployed to:', counter.address);
}

main().catch((e) => console.error(e));
Key points
  • Factory binds ABI and bytecode for deployment.
  • Call factory.deploy(...args) to start deployment.
  • Factory can deploy multiple instances; the returned Contract is a specific instance.
  • Verify the contract name matches the compiled artifact to avoid runtime errors.
Pro tip
If getContractFactory throws, run a fresh compile and confirm the artifact name exactly matches the contract name used.
Key Takeaway

ContractFactory is the deploy-time blueprint; preserve the distinction between factory and instance to avoid confusion.
