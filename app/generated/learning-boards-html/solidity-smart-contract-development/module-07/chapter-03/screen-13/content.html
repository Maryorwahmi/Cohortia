What to Remember
A final checklist for safe deployments.
Await deployed()
Ensure the blockchain has mined the deployment before interacting with the contract.
Match constructor args
Pass arguments in the correct order and type to deploy() to avoid immediate reverts.
Log address & tx hash
Record both values for future interactions and for auditing or debugging purposes.
Final Checklist
Compile → configure RPC & key → confirm balance → run with correct --network → await deployed() → store outputs.
