Module 3 › Chapter 2.5 › require vs revert vs assert
require
User input and preconditions. Refunds unused gas; good for access control and validation.
revert
Explicit failure path. Useful when complex logic leads to a failure. Works well with custom errors.
assert
Internal invariants only. Failure signals a bug and is costly; use sparingly.
Gas and messages
String messages are easy to read but cost gas. Custom errors encode a signature and parameters, which is cheaper and easier for clients to parse programmatically.
