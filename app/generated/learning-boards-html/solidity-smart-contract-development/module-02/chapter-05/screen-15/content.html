Module 3 › Chapter 2.5 › What to Remember
Events are off-chain
Use them for notifications and indexing, not for contract logic.
Index selectively
Index fields you will filter by to balance cost and performance.
Use custom errors
They reduce gas and return structured parameters for clients.
Practice by implementing the token transfer challenge: seed the deployer, validate inputs with custom errors, update balances atomically, and emit a Transfer event with indexed addresses so you can test filtering in a transaction console.
