Module 3 › Chapter 2.5 › Key Concepts
Events
Off-chain logs for observers; not usable by contracts.
Indexed parameters
Up to three; use selectively to speed queries at a gas cost.
Errors
Require and revert refund gas; assert indicates a bug and is costly. Custom errors save gas and return structured data.
Final takeaway

Design events for client needs, index only what you will query, and use custom errors with require or revert to write safer, cheaper contracts.
