Module 3 › Chapter 2.5 › Learning Objectives
01
Declare and emit events

You will learn how to declare events and emit them so off-chain clients can index contract activity. This matters for UX and analytics because events are the reliable bridge between on-chain activity and user interfaces.

VERIFIED COMPETENCY MILESTONE
02
Use indexed parameters

You will understand how indexing up to three parameters lets off-chain tools filter events efficiently and when indexing is worth the extra gas cost.

VERIFIED COMPETENCY MILESTONE
03
Implement require/revert/assert

You will practice validating inputs and preconditions with require, triggering explicit failures with revert, and reserving assert for internal invariants only.

VERIFIED COMPETENCY MILESTONE
04
Define custom errors

You will define and trigger custom errors to return structured, gas-efficient failure reasons that client code can parse reliably.
