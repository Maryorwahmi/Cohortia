Events and Error Handling
How contracts notify off-chain systems and how to fail safely

This chapter shows how to declare and emit events to create filterable logs, how to mark parameters as indexed, and how to handle errors using require, revert, assert, and custom errors. Good logging and error design makes dApps responsive, debuggable, and secure.
