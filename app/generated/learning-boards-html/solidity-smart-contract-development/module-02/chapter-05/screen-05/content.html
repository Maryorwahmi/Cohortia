Module 3 › Chapter 2.5 › Declaring and Emitting Events
Steps to follow
  1. Choose the facts external clients need to observe and search by.
  2. Declare the event with descriptive names and types.
  3. Mark up to three parameters as indexed for efficient filtering.
  4. Emit the event when the state change occurs and tests pass.
  5. Verify emitted topics and data in transaction logs.
Concrete example
Transfer declared with two indexed addresses to allow searching by sender or receiver, and emitted on successful transfer.
Code snippet
event Transfer(address indexed from, address indexed to, uint value);

function transfer(address recipient, uint amount) public {
  require(amount > 0, "Amount must be positive");
  // update balances
  emit Transfer(msg.sender, recipient, amount);
}
Testing tip
Use Remix or your test runner to send a transaction and inspect the event topics and data in the transaction log to confirm values and indexed topics.
