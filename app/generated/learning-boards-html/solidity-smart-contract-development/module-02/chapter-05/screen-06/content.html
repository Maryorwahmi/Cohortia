Module 3 › Chapter 2.5 › Indexed vs Non-Indexed
Indexed parameters
  • • Become topics that off-chain tools can filter quickly.
  • • Up to three parameters may be indexed.
  • • Useful for addresses, ids, or keys commonly queried.
When not to index
Avoid indexing rarely queried fields or large strings since indexing increases gas without practical benefit.
Practical example
event Transfer(address indexed from, address indexed to, uint value);

// Query all transfers to a specific address by filtering the 'to' topic.
Choose indexed parameters based on how your front-end or analytics will search logs.
