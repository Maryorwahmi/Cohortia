Module 3 › Chapter 2.5 › Common Mistakes & Best Practices
Common mistakes
  • • Using assert for input validation — costly and semantically wrong.
  • • Indexing all event fields — unnecessary gas overhead.
  • • Relying on events as contract state — they are off-chain only.
Best practices
  • • Use require and revert for recoverable errors; assert only for invariants.
  • • Prefer custom errors for gas efficiency and structured data.
  • • Emit concise events that front ends need to reconstruct activity.
