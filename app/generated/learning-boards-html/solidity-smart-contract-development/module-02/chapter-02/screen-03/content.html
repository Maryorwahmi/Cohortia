Short-circuiting for Gas Savings

Place cheap boolean checks first so expensive operations are skipped when the result is already known.

Mnemonic: Cheap first
VERIFIED COMPETENCY MILESTONE
02
Replace Unbounded Loops

Use mappings for membership checks or split work into paginated batches instead of iterating over large arrays.

Mnemonic: Map, Page, Batch
VERIFIED COMPETENCY MILESTONE
03
Audit-Friendly Conditionals

Keep conditional logic flat and descriptive so auditors and future maintainers can reason about allowed code paths.

Mnemonic: Flat, Clear
VERIFIED COMPETENCY MILESTONE
04
Balance Correctness and Cost

Design expressions and flow to prevent state changes on failed operations and to avoid unnecessary gas consumption.

Mnemonic: Correct + Cheap
