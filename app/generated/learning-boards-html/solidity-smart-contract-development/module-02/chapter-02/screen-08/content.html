Flag pattern
uint8 flags = 0; // 00000000

function setFlag(uint8 bit) public {
  require(bit < 8);
  flags |= (1 << bit);
}

function isFlagSet(uint8 bit) public view returns (bool) {
  require(bit < 8);
  return (flags & (1 << bit)) != 0;
}
When to use

Use bitwise flags when you need compact storage for many boolean attributes and can accept lower readability.

Common mistake

Misindexing bits or misapplying masks can silently break logic. Always document which bit maps to which flag.

Key Takeaway

Bitwise ops are efficient but low-level. Use them when storage economy matters and keep clear documentation to avoid errors.
