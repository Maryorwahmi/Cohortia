Countdown example
function countdown(uint _start) public pure returns (uint) {
  uint i = _start;
  uint total = 0;
  while (i > 0) {
    total += i;
    i--;
  }
  return total;
}
This is safe because i decreases each iteration and will reach zero deterministically.
Warning

If the loop condition depends on external state that might not change, the loop could run until gas is exhausted and revert.

Safer patterns
  • Batch processing across multiple transactions
  • Maintain aggregates incrementally instead of scanning
  • Use mappings for membership checks to avoid iteration
Key Takeaway

Never rely on unproven termination conditions. Prefer deterministic or bounded loops and consider off-chain work where appropriate.
