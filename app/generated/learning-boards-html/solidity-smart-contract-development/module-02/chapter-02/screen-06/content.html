Module 2 › Chapter 2.2 › Comparison Operators
Examples and use

Comparison operators evaluate relations and return true or false. Common uses include access checks, threshold gates, and validation of inputs.

  • Access: caller == owner
  • Range checks: value >= minimum && value <= maximum
  • Equality vs identity: compare types carefully
Concrete snippet
function isAdmin(address _addr) public view returns (bool) {
  return (_addr == admin);
}
Misconception

Comparing mismatched types or expecting implicit conversions can lead to unexpected results. Be explicit in types and ranges.

Key Takeaway

Use clear comparisons for gate conditions and verify operand types to avoid subtle bugs.
