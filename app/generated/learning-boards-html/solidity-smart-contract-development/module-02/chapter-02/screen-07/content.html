Illustration
function checkAccess(address _caller, uint _value) view returns (bool) {
  if (_caller == owner && _value > 100) {
    return true;
  } else if (_caller != owner && _value < 50) {
    return false;
  }
  return false;
}
Here, owner equality is cheap and can prevent evaluating value checks in many cases.
Concrete tip

Order boolean operands by expected cost: cheapest first to maximize skipped evaluations and save gas.

Misconception

Never rely on side effects inside boolean operands because short-circuiting may skip them.

Key Takeaway

Short-circuiting is a tool. Use operand ordering for gas savings and avoid embedding required side effects in conditions.
