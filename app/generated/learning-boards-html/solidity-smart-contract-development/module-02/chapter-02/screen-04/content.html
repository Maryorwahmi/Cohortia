Definition

Operator families

Simple descriptions link each operator category to the programmer intent and typical use-cases on-chain.

Quick reference
  • Arithmetic: +, -, *, /, %
  • Comparison: ==, !=, <, >, <=, >=
  • Logical: &&, ||, ! (short-circuiting applies)
  • Bitwise: &, |, ^, ~, <<, >>
Example

Use comparison and logical operators to check if msg.sender is authorized and a numeric threshold is met before proceeding.

Key Takeaway

Match operator type to intent: computation, test, combination, or bit manipulation. Clarity beats clever packing when security is at stake.

Annotated examples
Arithmetic snippet
uint sum = a + b;
uint product = a * b;
uint remainder = a % b;
Logical & Comparison
if (caller == owner && value > 100) {
  // proceed
}
Misconception

Bitwise tricks save storage but reduce readability. Short-circuiting means second operands may not run—don’t rely on side effects there.
