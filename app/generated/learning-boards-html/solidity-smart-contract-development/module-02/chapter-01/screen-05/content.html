Definition
Address and address payable
Explicit payable types make value transfers intentional and safer.
Key methods and semantics
  • address.balance shows the current Wei balance of an account.
  • To send Ether, cast to address payable and use transfer or call with value.
  • Low-level call returns success flag; always check it when sending funds.
Code pattern
// inside a contract
address public recipient;
address payable public payRecipient;

function send(uint amount) public payable {
  payRecipient = payable(recipient); // explicit conversion
  (bool ok, ) = payRecipient.call{value: amount}("");
  require(ok, "Failed to send Ether.");
}
Practical guidance
  • Keep explicit payable usage local to functions that handle funds.
  • Prefer checks-effects-interactions pattern when updating state and sending Ether.
  • Measure amounts in Wei and be deliberate about units to avoid off-by-decimal errors.
Common misconception
An address type is not automatically able to receive Ether without casting; mixing them can hide intended financial flows.
Key Takeaway

Use address payable explicitly and check transfer results to make fund flows explicit and auditable.
