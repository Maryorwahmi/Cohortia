Arrays: fixed-size vs dynamic
Declare, mutate, and iterate with gas in mind.
Declaration patterns
  • Fixed-size: uint[5] public fixedArr;
  • Dynamic: uint[] public dynArr; use push to append.
  • Memory arrays inside functions are transient; storage arrays persist on-chain.
Code example
uint[] public scores;

function addScore(uint s) public {
  scores.push(s); // grows dynamic array
}

function removeLast() public {
  scores.pop(); // removes last element
}
Gas-aware operations
  • Avoid loops over unbounded arrays in a single transaction.
  • For removals, swap with last and pop to avoid shifting all elements.
  • Consider mappings for large, address-keyed datasets to enable O(1) access.
Common mistake

Iterating a large dynamic array in one function can exceed gas limits — design bounded operations or use off-chain indexing.

Concrete scenario
A registry that pushes entries per user is okay for small communities. For public, unbounded registries, use pagination, events, and off-chain indices rather than full on-chain scans.
