What to Remember
Key Concepts
Three compact reminders to use when building contracts.
Value vs Reference
Value types copy on assignment; reference types point to storage. This affects updates and tests.
Address and Payable
Use address payable only when sending or receiving Ether and check transfer success.
Fixed vs Dynamic
Prefer bytesN for fixed-size data and avoid unbounded loops over dynamic arrays.
Summary Takeaway

Type choice shapes correctness, gas cost, and security. Initialize state, use explicit payable handling, and design bounded operations.
