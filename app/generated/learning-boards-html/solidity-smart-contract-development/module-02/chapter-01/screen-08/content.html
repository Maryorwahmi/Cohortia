Enums and Structs
Model states and composite data cleanly.
Enum example
An enum captures a finite set of states. Using descriptive names prevents invalid numeric constants from creeping into logic.
enum Status { Pending, Approved, Rejected }
Status public current = Status.Pending;

function approve() public {
  current = Status.Approved;
}
Struct example
Group related fields like id, description, and vote counts in a single Proposal struct to simplify storage and access.
struct Proposal {
  uint id;
  string description;
  uint forVotes;
  uint againstVotes;
  address proposer;
}

Proposal public p;
Important nuance

Assigning storage references creates pointers; copying to memory produces independent copies. Choose intentionally when mutating nested fields.
