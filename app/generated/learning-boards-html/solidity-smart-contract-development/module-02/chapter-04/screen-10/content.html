Module 2 › Chapter 2.4 › Contract walkthrough
Contract highlights
  • State variables like counters and dynamic arrays live in storage.
  • Immutable set in constructor reduces future read cost.
  • Constant values are embedded in bytecode and avoid storage slots.
  • Mapping of structs with storage reference for in-place updates.
Snippet: immutable and constant
address public immutable deployer; // set in constructor
uint public constant MAX_LIMIT = 1000; // compile-time constant
Snippet: calldata vs memory
function processArrayInMemory(uint[] memory _inputArray) public pure returns (uint sum) { ... }
function processExternalArray(uint[] calldata _data) external pure returns (uint product) { ... }
Notice how calldata avoids the implicit copy used by public functions. Use calldata for large external arrays to save gas.
