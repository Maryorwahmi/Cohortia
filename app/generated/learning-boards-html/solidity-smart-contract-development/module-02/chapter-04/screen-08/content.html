Module 2 › Chapter 2.4 › Constants & Immutables
Constant
Values known at compile time are embedded into bytecode and avoid storage slots.
uint public constant MAX_LIMIT = 1000; // compile-time constant
Immutable
Set once during deployment in the constructor; cheaper than storage for reads.
address public immutable deployer;

constructor() {
  deployer = msg.sender; // set at deployment
}
Key Takeaway

Identify values that never change or change only at deployment and mark them constant/immutable to cut storage reads.
