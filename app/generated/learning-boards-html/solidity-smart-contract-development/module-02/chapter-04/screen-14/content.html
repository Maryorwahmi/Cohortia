Module 2 › Chapter 2.4 › Key Concepts
Storage
Persistent and costly. Update in place using storage references when editing mappings or structs.
Memory & Calldata
Memory is temporary and modifiable; calldata is read-only and most efficient for external inputs.
Constant / Immutable
Promote compile-time and deployment-time values out of storage to lower read cost.
Summary

Choosing the right data location and using constant/immutable are small changes that lead to safer contracts and meaningful gas savings.
