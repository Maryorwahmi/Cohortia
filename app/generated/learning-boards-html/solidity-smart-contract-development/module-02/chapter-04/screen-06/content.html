Module 2 › Chapter 2.4 › What is calldata?
Definition & behavior
Immutable, read-only region used for external function arguments. Most efficient for large, read-only inputs.
When to use
  • External functions that only read arguments.
  • Large arrays or structs passed from off-chain callers.
  • Batch validation routines where no modification is required.
Key Takeaway

Prefer calldata for large external inputs to avoid copies into memory and reduce gas usage.

Concrete example
// External function using calldata for efficiency
function processExternalArray(uint[] calldata _data) external pure returns (uint product) {
  product = 1;
  for (uint i = 0; i < _data.length; i++) {
    product *= _data[i];
  }
}
Misconception
Declaring a parameter without calldata on an external function may cause an implicit copy to memory, increasing gas cost unexpectedly.
