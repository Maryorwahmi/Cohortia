Read vs Write cost comparison
Storage Write
Highest cost. Avoid frequent writes where possible.
Storage Read
Cheaper than writes but still expensive compared to memory/calldata.
Memory / Calldata
Memory cheaper for small allocations; calldata best for large read-only inputs.
Concrete strategy
Perform heavy computation in memory. Use calldata for external large arrays. Write to storage once with the final result or update in-place via storage reference.
