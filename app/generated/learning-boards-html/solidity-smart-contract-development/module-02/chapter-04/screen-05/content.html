Module 2 › Chapter 2.4 › What is memory?
Definition & behavior
Ephemeral workspace that lasts only during a function call. Use for temporary arrays, local computation, and function parameters when safe.
Characteristics
  • Cleared at the end of the call.
  • Cheaper than storage for reads/writes, but still costs gas for large allocations.
  • Assigning storage to memory creates a deep copy.
Key Takeaway

Keep heavy computation in memory and avoid needless copies from storage for large collections unless you must persist results.

Concrete example: processing an input array
function processArrayInMemory(uint[] memory _inputArray) public pure returns (uint sum) {
  for (uint i = 0; i < _inputArray.length; i++) {
    sum += _inputArray[i];
  }
}
Misconception
Assuming memory copies are free. If you copy a large storage array into memory, that deep copy is costly.
