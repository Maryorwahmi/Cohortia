Module 2 › Chapter 2.4 › Common mistakes
Checklist to avoid costly mistakes
Mark parameters explicitly
Always specify storage or memory for complex types in function parameters to control copy behavior.
Use calldata for external reads
Switch public to external with calldata for large off-chain inputs to save gas.
Prefer storage references to rebuild
When editing mapping structs, retrieve a storage reference and set fields directly.
Find constant/immutable candidates
Promote compile-time or deployment-time values to constant/immutable to cut reads.
Concrete refactor prompt
Refactor a public function that takes a large array to be external and accept calldata instead of memory. Measure gas before and after.
