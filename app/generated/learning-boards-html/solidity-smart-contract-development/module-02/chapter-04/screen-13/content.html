Module 2 › Chapter 2.4 › Checklist & Testing
Validation checklist
Unit tests
Test create/update/read flows and edge cases such as empty arrays and max-size inputs.
Gas measurements
Run before/after gas reports for key functions to measure impact of refactors.
Code review checklist
Require explicit qualifiers, flag storage-to-memory copies, and encourage immutable/constant when applicable.
Automation
Automate a test that fails if a function unexpectedly copies large arrays or if gas increases beyond a threshold.
Why this matters

Solid tests and gas measurements ensure your data-location choices are correct, safe, and economically sensible on-chain.
