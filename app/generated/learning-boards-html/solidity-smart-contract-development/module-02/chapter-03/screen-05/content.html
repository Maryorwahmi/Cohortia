Module 2 › Chapter 2.3 › Visibility modifiers
At-a-glance comparison
public
Callable externally and internally. Default when omitted.
private
Only within the same contract; not visible to derived contracts.
internal
Accessible in this contract and derived contracts; not external.
external
Callable only from outside; reads args from calldata for gas savings.
Pattern: external API → internal implementation
function doActionExternal(uint[] calldata data) external {
  _doActionInternal(data);
}

function _doActionInternal(uint[] memory data) internal {
  // shared implementation
}
Example note
Use calldata on external functions to avoid copying large arrays into memory, saving gas when possible.
Common mistake
Trying to call an external function internally as if it were public will fail or be inefficient; prefer internal delegation.
