Module 2 › Chapter 2.3 › Custom modifiers
onlyOwner example
modifier onlyOwner() {
  require(msg.sender == owner, "Only owner can call this function.");
  _;
}
Attach this modifier to functions to enforce owner-only execution without repeating the check.
onlyRegistered example
modifier onlyRegistered() {
  require(registeredUsers[msg.sender], "Not registered.");
  _;
}
Use this to gate access to view or action functions for registered users only.
Common mistake

Putting heavy logic in modifiers can hide side effects. Keep modifiers short and clear.
