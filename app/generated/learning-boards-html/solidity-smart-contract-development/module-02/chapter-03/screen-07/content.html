Module 2 › Chapter 2.3 › view and pure
view
Reads state but does not modify it. Free when called off-chain.
function getCurrentCounter() public view returns (uint) {
  return _internalCounter;
}
pure
Does not read or write state. Deterministic computation only.
function calculateSum(uint a, uint b) public pure returns (uint) {
  return a + b;
}
Key Takeaway

Choose view or pure to convey intent and enable gas-free reads from user interfaces and scripts.
