Module 2 › Chapter 2.3 › Common pitfalls
Checklist of mistakes
  • Forgetting payable on functions that should accept Ether.
  • Making internal helpers public by accident.
  • Assuming view is always free during transactions.
  • Calling external functions internally like normal functions.
  • Heavy logic in modifiers.
Mitigations
  • Prefer internal/private helpers and thin public wrappers.
  • Write unit tests for edge cases: insufficient payment, unauthorized access.
  • Check call return values when sending Ether out.
