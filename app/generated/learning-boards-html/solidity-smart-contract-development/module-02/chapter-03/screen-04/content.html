Definition

Function signature and intent

A signature includes the name, parameter types, and return types. Use view or pure when possible to show read-only intent.

Concrete example
function calculateSum(uint a, uint b) public pure returns (uint) {
  return a + b;
}
Misconception
All helpers must be public — false. Make helpers private/internal if not part of API.
Pro tip
Mark pure when you only use parameters; mark view when you read state but do not write it.
Why it matters

Explicit signatures improve interoperability, security, and developer experience. They make it clear how external callers and other contracts should interact with your code.

Key Takeaway

Design functions with clear signatures and mark mutability to communicate intent and reduce gas where possible.
