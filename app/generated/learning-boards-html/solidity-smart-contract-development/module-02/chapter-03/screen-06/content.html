Module 2 › Chapter 2.3 › Private vs Internal
Inheritance hierarchy
Design members that should be shared with children as internal. Keep sensitive helpers private to prevent accidental overriding or misuse.
Private example
function _decrementCounterPrivate() private {
  _internalCounter--;
}
Internal example
function _getInternalCounter() internal view returns (uint) {
  return _internalCounter;
}
Checklist
  • Will derived contracts extend this behavior?
  • Could external callers misuse this helper?
  • Prefer internal for reusable logic, private for locked details.
