Module 2 › Chapter 2.3 › Key Concepts
Function Signature
Name, parameter types, and return types define the callable interface.
Visibility
public, private, internal, external — choose to limit callers and optimize gas.
Mutability
view reads state; pure neither reads nor writes. Both are gas-free off-chain.
Summary

Use the right signature, visibility, and mutability to make functions safe, clear, and efficient.
