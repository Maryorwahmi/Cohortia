Core Concept

What is a dApp?

A web interface backed by on-chain smart contracts and blockchain state.

Key properties
  • Transparency: contracts and transactions are inspectable.
  • Immutability: state changes are recorded and durable.
  • Censorship resistance: no single operator controls state.
Concrete example

An NFT marketplace uses a contract to list tokens, transfer ownership, and enforce royalties. The frontend collects user input and asks the wallet to sign transactions.

Common misconception

Believing the entire app must be hosted on-chain. In reality, the UI is usually a standard web app that talks to on-chain contracts.

Key Takeaway

A dApp moves backend logic to smart contracts on a blockchain while keeping a familiar frontend.

Architecture snapshot
Frontend
React, Vue, or Angular UI that builds the experience.
Smart Contracts
Business logic and state stored on-chain.
Wallet
User identity and signature provider for transactions.
