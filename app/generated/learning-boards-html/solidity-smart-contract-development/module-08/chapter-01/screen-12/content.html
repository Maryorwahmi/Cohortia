Module 8 › Chapter 8.1 › Nodes vs Indexers
Direct Node Queries

Authoritative reads

Query a node for contract state or logs. Trustworthy and decentralized but can be slow for complex searches.

Best used for verifying critical state and for on-demand checks that must match the chain exactly.
Centralized Indexers

Fast, rich queries

Pre-process events into a database to support search, pagination, and aggregated views for responsive UIs.

Use indexers when UI responsiveness matters, but be mindful that they reintroduce a centralized component.
Example

An NFT gallery queries an indexer for fast listing and search, but checks ownership on-chain before a transfer to ensure correctness.
