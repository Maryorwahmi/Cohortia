Definition

Frontend role in a dApp

Displays data, initiates signed actions, and handles asynchronous confirmations from the blockchain.

Frameworks
React, Vue, or Angular provide component models and state tools suited for dApp UIs.
State management
Store pending transactions, confirmed state, and cached reads separately to avoid confusion.
UX patterns
Wallet connection
Clearly show connection state and which account is active.
Transaction lifecycle
Show pending, confirmed, and failed states. Consider optimistic UI with revert on failure.
Performance
Cache read-only queries and use indexers when needed for faster UI responses.
Misconception check: Never assume a transaction is final immediately—design the UI to reflect asynchronous confirmations and possible failures.
