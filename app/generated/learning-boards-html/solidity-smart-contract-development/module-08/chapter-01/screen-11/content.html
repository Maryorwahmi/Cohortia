Process Flow

Wallet integration and user flows

Detect provider, request connection, prepare transaction, request signature, broadcast, and monitor confirmation.

1. Detect
Find an injected provider or mobile connector.
2. Connect
Request account access and show active address.
3. Sign
Prepare transaction data and ask the wallet to sign with explicit consent.
4. Confirm
Monitor confirmations and update the UI after finality.
Example

When a user sends a token transfer: the UI builds calldata, the library prepares a transaction, the wallet prompts for signature, and the app listens for the confirmation to update balances.

Misconception check: connecting a wallet does not give a dApp control over the account. Actions require explicit user signatures, which the wallet mediates.
