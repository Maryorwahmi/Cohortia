Module 8 › Chapter 8.1 › Smart Contracts as Backend
Definition

Smart contracts as backend logic

Contracts contain rules and state that are authoritative and verifiable on-chain.

What to put on-chain
Token transfers, immutable permissions, and dispute resolution logic that must be trustless.
What to keep off-chain
Large media, expensive computations, and frequently changing UI content belong off-chain for cost and flexibility.
Trade-offs and guidance
Gas costs make frequent writes expensive; design contracts to minimize state changes and batch operations where sensible.
Immutability is an advantage but requires careful design, tests, and upgrades strategies such as proxies if evolution is necessary.
Example
An on-chain token transfer enforces balances immutably, while a user profile picture is better stored off-chain and referenced by a hash.
Key Takeaway

Reserve on-chain logic for rules that require trustless execution; offload heavy data and mutable content off-chain.
