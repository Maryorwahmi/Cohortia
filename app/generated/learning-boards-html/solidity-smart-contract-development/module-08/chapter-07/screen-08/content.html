Module 8 › Chapter 8.7 › Pending Transactions
Why lock actions
Locking prevents users from sending identical requests while the first is still being processed, saving gas and avoiding confusion.
Show a spinner and message like Processing… with the transaction hash for traceability.
Disable actionable inputs that would create equivalent transactions.
On failure, show the revert reason and clarify recovery steps.
Concrete Example
When the user sets a greeting, set isMining true. Render Processing with hash and disable the greeting input until confirmation or failure.
Key Takeaway
Make pending visible and prevent duplicate actions to protect users and avoid wasted fees.
