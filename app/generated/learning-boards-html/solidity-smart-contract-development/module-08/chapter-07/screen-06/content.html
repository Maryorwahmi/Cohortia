Module 8 › Chapter 8.7 › dApp States
Disconnected
Explain why connection is required and what actions will be available once connected. Provide clear instructions on connecting a wallet and verifying an account selection.
Connected but no account
Detect and prompt the user to select an active account. Explain that multiple wallet profiles can be present and one must be chosen.
Wrong Network
Show the required network name and guide users to switch. Emphasize not to attempt transactions on an unsupported chain.
Example
If your contract is on Sepolia and a user is on Mainnet, display: Wrong Network. Please switch to Sepolia. Provide steps or instructions for the wallet switch process.
Key Takeaway
Make each state explicit and prevent the user from performing unsupported actions.
Misconception
Assuming the wallet alone will prevent wrong-network transactions. Your UI must detect and warn first.
