Module 8 › Chapter 8.7 › Loading Data
Principles
  • Show loading state with context, not blank content.
  • Prefer skeletons or progressive loading of the most recent items first.
  • Cache frequent reads when safe to reduce repeated fetch delays.
Concrete Example
Load latest event immediately and display older events as they arrive. Show Loading contract state with a spinner so users know the app is fetching data.
Key Takeaway
Keep users informed and enable interaction with loaded parts while remaining data fetches in the background.
