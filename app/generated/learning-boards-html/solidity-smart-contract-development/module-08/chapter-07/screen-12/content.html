Module 8 › Chapter 8.7 › Accessibility & Security
Accessibility rules
  • Semantic HTML and ARIA for status messages.
  • Keyboard-accessible controls and logical focus order.
  • Sufficient color contrast and visible focus styles.
Security UI rules
Never request or store private keys in the frontend. Make your app visually distinct from wallet UI and avoid fake dialogs that mimic wallet prompts.
Key Takeaway
Design inclusively and defensively: make legitimate wallet flows obvious and avoid UI that could aid phishing.
