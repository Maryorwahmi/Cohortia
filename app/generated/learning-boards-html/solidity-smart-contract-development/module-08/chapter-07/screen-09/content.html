Module 8 › Chapter 8.7 › Transaction Errors
Translation pattern
Capture low-level revert signals and present an explanation plus next steps. Keep messaging non-technical but specific enough to act on.
If revert reason contains allowance, show steps to approve token spending.
If user rejected the signature, explain that no on-chain change occurred and how to retry.
If unknown, provide troubleshooting steps: check balance, check gas, consult transaction history.
Example message
Transaction reverted: Insufficient allowance. To fix, approve token allowance in your wallet and try again. If unsure, check token balance and allowance settings.
Key Takeaway
Convert technical errors into clear steps the user can follow to recover.
