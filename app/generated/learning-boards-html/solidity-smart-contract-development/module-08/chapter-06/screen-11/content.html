Module 8 › Chapter 8.6 › Event Filtering
Indexed example
// Solidity
event GreetingUpdated(address indexed updater, string oldGreeting, string newGreeting, uint timestamp);
Index the address you will filter by, such as updater, to enable node-side filtering.
Filter in Ethers
// JavaScript
const filter = greeterContract.filters.GreetingUpdated(specificAddress);
greeterContract.on('GreetingUpdated', filter, listener);
This tells the node to send only events where updater equals the specific address, saving bandwidth and CPU.
Design tip
Choose indexed parameters during contract design based on the queries your frontend will perform most often.
