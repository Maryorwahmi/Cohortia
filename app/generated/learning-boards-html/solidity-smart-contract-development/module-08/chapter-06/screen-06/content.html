Module 8 › Chapter 8.6 › Emit & indexed
Event Declaration
// Example Solidity event declaration
// event GreetingUpdated(address indexed updater, string oldGreeting, string newGreeting, uint timestamp);
Index addresses you will filter on. Non-indexed fields are stored in the log data and cannot be filtered by the node.
Emit in Function
// In setGreeting
string memory _oldGreeting = greeting;
greeting = _newGreeting;
emit GreetingUpdated(msg.sender, _oldGreeting, _newGreeting, block.timestamp);
Emit captures the old and new values as part of the transaction receipt. Use emit to notify off-chain systems that something changed.
Misconception
Non-indexed event fields cannot be efficiently filtered server-side; they require client-side inspection after retrieval.
