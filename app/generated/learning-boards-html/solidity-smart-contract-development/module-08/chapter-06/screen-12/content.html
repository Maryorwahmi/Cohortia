Module 8 › Chapter 8.6 › Common Mistakes
Forgetting cleanup
Not calling contract.off leads to duplicate listeners and memory usage that grows over time.
Over-fetching
Re-fetching all state on every event causes latency and node load; update only what changed when possible.
Node reliability
Dropped connections may miss events. Consider re-querying logs on reconnect or using a reliable subscription service for production.
Performance note
Keep listeners light, index useful fields, and reconcile state on reconnect to maintain both speed and correctness.
