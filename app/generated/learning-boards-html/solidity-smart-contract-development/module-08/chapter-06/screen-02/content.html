Explain events and receipts

Describe how emitting an event records data in the transaction receipt and how that differs from on-chain storage. This matters because events are cost-efficient logs useful for historical records and triggers.

VERIFIED COMPETENCY MILESTONE

Update UI responsively

Use event payloads to update only the affected elements, avoiding unnecessary full contract fetches that add latency and cost.

VERIFIED COMPETENCY MILESTONE

Filter and optimize

Apply indexed parameters and contract.filters to subscribe to only relevant events, lowering bandwidth and CPU on the client and node.
