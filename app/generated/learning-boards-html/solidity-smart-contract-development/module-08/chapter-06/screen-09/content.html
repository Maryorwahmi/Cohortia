Module 8 › Chapter 8.6 › useEffect Pattern
Pattern
useEffect(() => {
  if (!greeterContract) return;
  const listener = (updater, oldGreeting, newGreeting, timestamp, event) => {
    setLatestEvent({ updater, oldGreeting, newGreeting, timestamp: new Date(Number(timestamp) * 1000).toLocaleString() });
    fetchContractData(greeterContract);
  };

  greeterContract.on('GreetingUpdated', listener);

  return () => greeterContract.off('GreetingUpdated', listener);
}, [greeterContract]);
This creates the listener only when greeterContract changes and removes it on unmount or change.
Pitfalls
  • Anonymous handlers inside useEffect prevent reliable removal.
  • Adding listeners on every render causes duplicate callbacks.
  • Heavy synchronous work in listener increases UI lag; keep it light.
Pro tip
If you re-create the listener for new props, remove the previous one first in the same effect to avoid overlap.
