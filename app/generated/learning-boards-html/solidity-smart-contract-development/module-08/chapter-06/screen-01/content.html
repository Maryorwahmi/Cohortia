Events power real-time dApps

You will learn how Solidity emits events and how the browser can subscribe to them. This reduces polling, improves responsiveness, and helps you build more interactive user experiences.

In this lesson
Define events, emit them in Solidity, and wire listeners with Ethers.js.
Coming up
Filter events by indexed params and prevent memory leaks with proper cleanup.
Hands-on
Update Greeter.sol, deploy, then add a useEffect listener in React to show live updates.
Why it matters
Events let your dApp react instantly to state changes with minimal network overhead.
