Lab steps
  1. Update Greeter.sol to emit GreetingUpdated and deploy it.
  2. Replace ABI in frontend and add latestEvent state.

  4. Test: change greeting, check console and UI.
Developer checks
Console shows 'GreetingUpdated event received' and latestEvent renders updater, oldGreeting and newGreeting. No duplicate console logs after navigation or hot reloads.
Troubleshooting
If listener never fires, verify ABI matches deployed contract, contract address is correct, and the contract was actually deployed with the event defined.
