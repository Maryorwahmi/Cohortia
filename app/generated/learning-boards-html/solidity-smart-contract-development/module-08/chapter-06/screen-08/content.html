JS Listener
// Listener signature example
const listener = (updater, oldGreeting, newGreeting, timestamp, event) => {
  setLatestEvent({ updater, oldGreeting, newGreeting, timestamp: new Date(Number(timestamp) * 1000).toLocaleString() });
  fetchContractData(greeterContract);
};

greeterContract.on('GreetingUpdated', listener);
// Later: greeterContract.off('GreetingUpdated', listener);
Listener arguments arrive in Solidity-declared order followed by an event object. Use a stable reference so off can remove it.
React lifecycle
Set up the listener inside useEffect when the contract instance is available, and return a cleanup function that removes the listener to avoid leaks.
Tip
Prefer named functions or useRef to hold the handler so you can reliably remove it in cleanup.
