After the build completes, inspect the dist folder. Confirm that index.html references the generated asset filenames and that any environment values (API endpoints, contract addresses) were baked in during build time.
Verification step

Serve the dist folder locally with a static server and walk through the UI to ensure wallet integration and contract calls succeed.

Common mistake

Deploying an unbuilt project or a development build will break asset references and routing when served statically from IPFS.

Checklist
  • Confirm build output directory name (dist or build) for your toolchain.
  • Verify asset paths in index.html and ensure routing works when served statically.
  • Ensure production RPC and contract addresses were set before building.
Key Takeaway

The build output is the single artifact you will pin to IPFS — validate it thoroughly before uploading.
