Deploy the dApp to IPFS

Follow a reproducible, secure process to publish your production build to IPFS and ensure it stays available and verifiable.

Interactive 16:9 Masterclass
Terminal demo style — build, pin, verify
In this lesson
Build

Compile your React app into static files using the project's build script so the result can be uploaded to IPFS.

Pin

Use a pinning service like Pinata to pin your build directory so the CID remains available on the network.

Resolve

Optionally point an ENS contenthash to the CID so users can reach your dApp with a .eth name.

Concept snapshot
IPFS CID
A cryptographic hash addressing your static build. Any change creates a new CID.
Access example
https://ipfs.io/ipfs/<YOUR_CID>/ or via a Pinata gateway to load your deployed dApp.
Key Takeaway

Decentralize both smart contracts and frontend files to achieve full censorship resistance and integrity for your dApp.
