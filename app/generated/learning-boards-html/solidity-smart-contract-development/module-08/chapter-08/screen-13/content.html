Module 8 › Chapter 8.8 › Activity & Assessment
Manual activity
  1. Run npm run build and confirm dist folder contains index.html.
  2. Log into Pinata, upload the dist folder, and copy the CID returned.
  3. Open https://ipfs.io/ipfs/<CID>/ and verify asset loads and wallet connects.
Evidence to collect
CID value, screenshot of the gateway loading your dApp, console log showing successful contract calls, and notes about where API keys are stored.
Assessment checks
  • Can the dApp be accessed via at least two public gateways?
  • Does a wallet connect and do read-only contract calls succeed?
  • Can you describe or perform updating the ENS contenthash if you own the name?
Key Takeaway

A deployment is complete only after verification: asset integrity, runtime behavior, and a clear update plan for future releases.
