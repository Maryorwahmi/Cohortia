Essential pattern: authenticate, collect files, call addAll with pin=true.
// Example: collect and upload
const ipfs = create({ host: 'ipfs.pinata.cloud', port: 5001, protocol: 'https', headers: { authorization: auth } });
for await (const file of ipfs.addAll(getFiles(buildPath), { pin: true, wrapWithDirectory: true })) {
  // log file.path and file.cid
}
// The script prints the root CID for use in CI.
API Key Safety
Never commit keys. Use a .env locally and secrets in CI. Rotate keys if exposed and restrict API permissions where possible.
CI Integration Pattern
  1. Checkout code, run tests.
  2. Run npm run build to produce dist.
  3. Run the deploy script using CI secrets to upload and pin the dist folder.
  4. Store the root CID as a pipeline artifact and optionally call a step to update ENS.
Pro Tip

Emit the CID as a simple JSON artifact so later workflow steps can parse and use it without manual copy-paste.
