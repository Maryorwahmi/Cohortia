Comparison: Web UI vs Programmatic
Web UI

Fast for manual uploads and small releases. Good for initial testing and one‑off pins.

Programmatic/API

Automatable and repeatable for CI. Allows scripts to capture the CID and feed it into downstream steps like ENS updates.

Decision guide: use the web UI for quick tests and the API for CI/CD deployments to guarantee reproducibility and traceability.
Immutability & ENS

When you update files, IPFS returns a new CID. ENS contenthash is a pointer to a CID. To serve a new release under the same human‑readable name you must update the ENS record to the new CID. This is a manual or scripted step in your CI pipeline.

Common mistake

Assuming ENS will follow your updates automatically. ENS points to a specific CID; you must update it when you publish a new CID.

Key Takeaway

Choose a pinning approach that matches your release cadence and ensure ENS updates are part of your deployment pipeline if you want a stable user‑visible domain.
