const ipfs = create({ host: 'ipfs.pinata.cloud', port: 5001, protocol: 'https', headers: { authorization: auth } })

Note: export your PINATA_KEY and PINATA_SECRET to the environment before running the script. In CI, store them as repository secrets and inject them into the job.
Gotcha

If you forget wrapWithDirectory you may get separate CIDs for each file rather than a single root CID for the site.

Pro tip

Pin incrementally for large sites and capture the root CID last, so uploads can resume and be verified stepwise.

Security reminder

Never commit API keys. Use environment variables locally and secrets in your CI provider when automating deployments.
