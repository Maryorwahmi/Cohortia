Module 8 › Chapter 8.2 › Scaffold a new Vite React project
Create the project
Run the Vite create command exactly as shown to generate a React template.
npm create vite@latest my-dapp-frontend -- --template react
cd my-dapp-frontend
Check that src/, index.html, and package.json were created before continuing.
Why include the template flag?
Specifying --template react ensures the scaffold includes React entry files like App.jsx and main.jsx.
Quick Inspection
ls -la
# expect: src/ index.html package.json
Key Takeaway

A single create command produces a predictable starting point for adding dApp-specific code.
