Module 8 › Chapter 8.2 › Verify prerequisites: Node.js and npm
Check versions in your terminal
Run these commands and confirm they print supported versions.
node -v
npm -v
Recommended: Node.js v16 or higher to match modern React and Vite requirements.
Common Install Errors
  • Old Node versions can cause package install failures.
  • Stale npm cache can produce inconsistent installs.
Troubleshooting Steps
If install fails: run npm cache clean --force, remove node_modules and package-lock.json, then npm install again.
Why it matters

A correct Node/npm setup avoids frustrating installation errors and keeps your toolchain consistent.
