Activity: Initialize Your dApp Frontend
Follow these steps in order to confirm your environment.
1. Scaffold
npm create vite@latest my-solidity-dapp-frontend -- --template react
cd my-solidity-dapp-frontend
2. Install
npm install
npm install ethers
3. Run dev server
npm run dev
# open the shown URL
4. Edit App.jsx
Change the h1 to "Welcome to My Solidity dApp!" and save to observe HMR.
Key Takeaway

Completing these steps verifies your frontend is ready for contract integration and iterative development.
