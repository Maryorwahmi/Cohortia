Module 8 › Chapter 8.2 › Install project dependencies
Install commands
Run the following commands in the project root to install base packages and Ethers.js.
npm install
npm install ethers
Confirm ethers appears in package.json under dependencies.
Package.json check
{
  "dependencies": {
    "react": "...",
    "react-dom": "...",
    "ethers": ""
  }
}
Common Mistake
Running npm install outside the project directory will install packages globally or in the wrong folder. Confirm your shell's current directory first.
Key Takeaway

Install base packages and Ethers.js so your frontend can call contracts and manage wallets.
