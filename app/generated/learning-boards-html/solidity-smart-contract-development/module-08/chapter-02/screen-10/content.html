Module 8 › Chapter 8.2 › Start the development server
Start and verify
Run the dev script and open the reported URL to confirm the app loads.
npm run dev
# open http://localhost:5173 (default)
Make a small edit to App.jsx and save to see hot module replacement in action.
Port Conflicts
If the default port is busy, Vite suggests an alternate port, or you can set one in vite.config.js.
Network Access
If testing from another device, ensure your firewall allows local network access to the dev server.
Key Takeaway

A running dev server gives you a live environment to test wallet connections and contract calls before integration.
