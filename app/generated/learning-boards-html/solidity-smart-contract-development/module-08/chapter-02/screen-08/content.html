Module 8 › Chapter 8.2 › Vite-React project file structure
Typical project tree
my-dapp-frontend/
├── index.html
├── package.json
└── src/
    ├── main.jsx   # app entry point
    └── App.jsx    # root component
Place wallet and contract helpers under src/, for example src/ethersProvider.js or src/hooks/useWallet.js.
Example module
// src/ethersProvider.js
import { ethers } from 'ethers'
// export a function that returns provider or signer used across components
Why centralize
Centralizing wallet and contract logic prevents duplication, eases testing, and keeps components focused on UI rendering.
Key Takeaway

A small, predictable file structure helps manage growing dApp logic and improves testability.
