Module 8 › Chapter 8.2 › Common mistakes and troubleshooting
Common issues
  • Node.js version issues: older versions may break installs.
  • npm install errors: stale cache or lockfile conflicts.
  • Port conflicts: another process using 5173.
  • Firewall: blocks access from other devices on the network.
Troubleshooting steps
  1. Check node -v and npm -v.
  2. Run npm cache clean --force.
  3. Remove node_modules and package-lock.json, then npm install.
  4. Let Vite suggest another port or set one in vite.config.js.
When to escalate
If errors persist after cache clearing and reinstall, inspect terminal logs for specific package errors before reinstalling Node.
Key Takeaway

A short, repeatable troubleshooting flow saves time when resolving common setup issues.
