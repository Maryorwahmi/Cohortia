Set up a React + Vite dApp Frontend
A fast, minimal starter environment for building and testing your smart contract UI

This chapter walks you through verifying Node and npm, scaffolding a Vite React project, installing Ethers.js, and running the local dev server so you can test your dApp locally with hot module replacement.

Explore Key Topics
Scaffold with Vite
Create the project using Vite's React template for a minimal, fast starting point.
Add Ethers.js
Install a lightweight Web3 library to sign transactions and call contracts from the frontend.
Run and Verify
Start the dev server and perform a small code edit to confirm HMR is working.
Key Takeaway

A minimal React+Vite scaffold plus Ethers.js lets you iterate fast while building UI that connects to your smart contracts.
