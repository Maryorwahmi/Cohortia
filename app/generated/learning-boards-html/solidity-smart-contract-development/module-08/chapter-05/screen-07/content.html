Process Flow

Transaction lifecycle

Sent

Show tx.hash immediately after the wallet signs and broadcasts the transaction so users can inspect it externally.

Pending

Disable inputs, show a spinner or message, and explain that the network is processing the transaction.

Mined / Final

Check receipt.status. On success, refresh data; on failure, parse revert and guide the user.

Example

After greeterContract.setGreeting(newGreeting), show the hash and then await tx.wait() to update the greeting displayed.

Common mistake

Assuming a broadcasted hash equals success before the transaction is mined.
