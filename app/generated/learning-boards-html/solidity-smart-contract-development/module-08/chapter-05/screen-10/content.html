Definition

Transaction reverts & handling

User rejection

Detected via a wallet error code (e.g., 4001). Tell the user they cancelled and how to retry.

On-chain revert

Parse err.data.message when available and explain which require() likely failed or suggest contract rules to check.

Insufficient funds

Explain that gas+value exceed their balance and provide steps to add funds or reduce the value sent.

Pro tip

Log full error objects for debugging, but show cleaned user-friendly messages in the UI.
