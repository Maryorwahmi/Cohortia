Process Flow

Signer vs Provider

Provider: read-only access to the network and state.
Signer: signs transactions and represents a user's account.
When signer is present, instantiate contract with signer to enable writes.
Misconception

A provider cannot sign; never assume read permission implies write permission.

Code pattern
// use signer when available
if (provider && signer) {
  const contract = new ethers.Contract(GREETER_CONTRACT_ADDRESS, GreeterABI.abi, signer);
  setGreeterContract(contract);
} else if (provider) {
  const contract = new ethers.Contract(GREETER_CONTRACT_ADDRESS, GreeterABI.abi, provider);
  setGreeterContract(contract);
}
Example consequence

Calling setGreeting without a signer triggers an error indicating a signer is required for gas estimation or signing.
