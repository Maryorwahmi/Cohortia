Definition

Payable functions

Functions declared payable accept Ether; include a value override when calling from the frontend.

Convert Ether to Wei using parseEther before sending.
Ensure the signer has enough balance for value + gas.
Await tx.wait() to confirm the transfer succeeded on-chain.
Code snippet
const amountInEther = '0.01';
const tx = await greeterContract.deposit({ value: ethers.parseEther(amountInEther) });
await tx.wait();
Take care to surface both the value being sent and estimated gas to the user before they confirm in their wallet.
