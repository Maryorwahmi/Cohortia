Core Concept

What is a Transaction?

A brief definition and the properties that distinguish transactions from read-only calls.

Signed by a user and broadcast to the network.
Consumes gas and can transfer Ether when payable.
Asynchronous: returns a tx hash, then is mined later.
Can revert due to require() or require-like checks; gas is still consumed.
Key Takeaway

Treat writes as non-instant operations and design your UI to handle pending, success, and failure states.

Example
// send transaction to set greeting
const tx = await greeterContract.setGreeting(newGreeting);
console.log('Hash:', tx.hash);
const receipt = await tx.wait();
if (receipt.status === 1) {
  // success: refresh state
}
Common misconception

Expecting immediate state changes after sending the transaction. The transaction must be mined and confirmed before UI state is authoritative.
