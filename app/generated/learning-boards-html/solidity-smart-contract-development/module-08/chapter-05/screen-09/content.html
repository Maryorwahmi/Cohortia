Gas: automatic estimate vs manual override

Automatic estimation

Ethers.js estimates gas for common calls. Use this by default to simplify UX and reduce errors for typical users.

Best for most users
Manual override

Allow advanced users to set gasLimit or gasPrice when deterministic needs demand it. Validate inputs and explain risks.

Advanced option
Example

If a function loops over user input, gas can spike; warn and estimate higher for safety.

Common mistake

Setting gas too low and failing to surface the resulting revert meaningfully to the user.
