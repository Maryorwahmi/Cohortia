Key Concepts

Transaction
Signed instruction that changes state and costs gas.
Signer
Represents a connected account that can sign and send transactions.
tx.wait()
Waits for mining and returns a TransactionReceipt with status and gas info.
Summary

Design your frontend around explicit transaction lifecycles, clear user feedback, and conservative gas handling to provide reliable write experiences.
