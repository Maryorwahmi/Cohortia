Event
accountsChanged
React to account switches to preserve correctness of displayed address, signer, and user data.
const handleAccountsChanged = (accounts) => {
  if (accounts.length === 0) {
    setAccount(null);
    setSigner(null);
    setError('Please connect to MetaMask.');
  } else if (accounts[0] !== account) {
    setAccount(accounts[0]);
    if (provider) setSigner(provider.getSigner());
    setError('');
  }
};

window.ethereum.on('accountsChanged', handleAccountsChanged);
Concrete Example
A user switches from one address to another. Immediately re-query any balances or permissions tied to the previous address to ensure the UI reflects the new account.
Mistake to Avoid
Failing to update signer after accountsChanged leaves your app using the old signer, causing signing prompts to reference the incorrect account and confusing users.
Check Yourself

After handling accountsChanged, does your UI show the new address and recent account-specific data like token balances?
