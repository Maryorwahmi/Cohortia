Event
disconnect
When the wallet disconnects, clear account-specific state and show a reconnect path.
const handleDisconnect = (error) => {
  console.error('MetaMask disconnected:', error);
  setAccount(null);
  setSigner(null);
  setError('MetaMask disconnected. Please reconnect.');
};

// In cleanup
return () => {
  window.ethereum.removeListener('accountsChanged', handleAccountsChanged);
  window.ethereum.removeListener('chainChanged', handleChainChanged);
  window.ethereum.removeListener('disconnect', handleDisconnect);
};
Concrete Example
If the user locks their wallet or revokes permissions, show a clear state indicating the user is disconnected and provide steps to reconnect or refresh the page.
Developer Pitfall
Not removing listeners on unmount can cause multiple invocations of handlers if the component mounts again, leading to duplicated state updates.
Key Takeaway

Remove listeners and reset state on disconnect so your app remains predictable and secure.
