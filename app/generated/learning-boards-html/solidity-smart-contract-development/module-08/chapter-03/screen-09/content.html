Event
chainChanged
Switching network changes the chainId; validate and reinitialize to ensure contract interactions target the correct chain.
const handleChainChanged = (chainId) => {
  console.log('Network changed to:', chainId);
  // Simple and safe: reload to re-initialize app state
  window.location.reload();
};

window.ethereum.on('chainChanged', handleChainChanged);
Concrete Guidance
If your dApp only supports Sepolia, detect the connected chain and show a clear banner asking the user to switch. Offer guidance rather than failing silently.
Pitfall
Attempting to reuse contract addresses across networks causes transactions to fail or perform unintended actions on a different chain.
Key Takeaway

Treat chain changes seriously: either reload or reinitialize providers and contracts, and inform the user when the connected network is unsupported.
