Implement Wallet Connection in App.jsx
Follow these steps to add a working connect flow and test it locally.
Step-by-step
  1. Add useState hooks for provider, signer, account, network, and error.
  2. In useEffect, check for window.ethereum; if present, create new ethers.BrowserProvider(window.ethereum) and setProvider.
  3. Attach listeners for accountsChanged, chainChanged, and disconnect. Return a cleanup function to remove them.
  4. Implement connectWallet: call window.ethereum.request({ method: 'eth_requestAccounts' }) in try/catch. Handle err.code === 4001 for rejection.
  5. After connect, call provider.getSigner() and provider.getNetwork() to set signer and network in state.
  6. Run npm run dev, click Connect Wallet, test rejection and success flows, then switch accounts and networks to verify listeners.
Expected Results
On connect: UI shows connected account and network name. On reject: friendly error appears. On account switch: account updates. On network change: app reloads or shows unsupported network message.
Key Takeaway

Test interactions in a live browser with MetaMask installed; follow the lifecycle and verify each event handler behaves as expected.
