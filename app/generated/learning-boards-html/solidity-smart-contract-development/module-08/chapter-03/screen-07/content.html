Definition
Signer
An account-capable object used to sign transactions and messages via the wallet.
How to obtain
// After connect and provider initialization
const currentSigner = await provider.getSigner();
setSigner(currentSigner);

// Use signer to send transactions; the wallet will prompt the user
await currentSigner.sendTransaction({ to: someAddress, value: someValue });
Practical Example
When a user clicks a UI action to mint a token, call a contract method using a signer so the wallet shows a confirmation and the user explicitly authorizes on-chain changes.
Misconception
The signer does not export the private key to your JS environment. It sends signing requests to the wallet which handles the private key securely.
Key Takeaway

Treat getSigner as the gateway to user-authorized state changes; always obtain it only after eth_requestAccounts succeeds.
