connectWallet
Request permission from the user and initialize signer and network state on success.
const connectWallet = async () => {
  if (!provider) { setError('No Ethereum provider found. Please install MetaMask.'); return; }
  try {
    const accounts = await window.ethereum.request({ method: 'eth_requestAccounts' });
    setAccount(accounts[0]);
    const currentSigner = await provider.getSigner();
    setSigner(currentSigner);
    const currentNetwork = await provider.getNetwork();
    setNetwork(currentNetwork.name);
  } catch (err) {
    if (err.code === 4001) setError('Wallet connection rejected by user.');
    else setError('Error connecting to wallet: ' + err.message);
  }
};
Example & UX
If the user rejects, show a neutral message explaining the action is optional and provide a retry button in your UI. If connection succeeds, immediately show the connected address and network name so the user knows the app's context.
Common Mistake
Not handling the rejection error (4001) causes confusing states where the UI waits for an account that never arrives. Always set a clear error state in this case.
Pro Tip

After successful connect, immediately cache the network name and account in local state so renders remain stable while other initialization continues.
