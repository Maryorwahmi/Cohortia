Skills and Safety Practices
Practical Safety Rules
  • Never request or transmit private keys; all signing must happen inside the wallet's secure signer.
  • Always check the connected chain's chainId or network name and inform the user when it differs from your contracts' network.
  • Handle user rejection (error code 4001) gracefully and do not retry without explicit consent.
  • Remove event listeners on unmount to avoid memory leaks or duplicate handlers.
Example
If a user switches MetaMask from Sepolia to Mainnet, the chainId will change. Your app should detect the change and either reload or re-initiate contract instances to avoid sending transactions to the wrong network.
