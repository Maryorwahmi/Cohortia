Mistake
Not checking for provider
Attempting to use provider methods when window.ethereum is undefined causes runtime errors.
Fix
Guard initialization with an existence check and show a clear install prompt when missing.
Mistake
Not handling user rejection
Ignoring error.code === 4001 leads to stuck or unclear UI.
Fix
Catch the error, show a friendly message, and let the user retry when ready.
Mistake
Ignoring accountsChanged or chainChanged
Your app can become inconsistent when the wallet state diverges from the UI.
Fix
Listen for events and update account, signer, and network state, or reload to reinitialize cleanly.
Mistake
Exposing private keys or asking users to paste them
This is a critical security error that ruins trust and exposes funds.
Fix
Always delegate signing to the wallet's signer and never collect private keys in the frontend.
