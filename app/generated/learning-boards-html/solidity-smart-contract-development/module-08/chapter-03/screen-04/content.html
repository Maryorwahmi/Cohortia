Definition
Detect window.ethereum
Confirm whether a browser wallet is injected so your app can safely initialize a provider or show guidance to install one.
Detection Snippet
useEffect(() => {
  if (window.ethereum) {
    // safe to initialize provider later
  } else {
    setError('MetaMask or other Web3 wallet not detected. Please install one.');
  }
}, []);
Concrete example: If window.ethereum is undefined in a user's browser, show a short help message and a link to wallet install instructions. Don't attempt provider calls or request accounts.
Key Takeaway

A detection check prevents runtime errors and gives users a clear next step when no wallet is installed.

Why it matters
Many errors arise from calling provider APIs when no wallet is present. Detecting the provider keeps your dApp robust and user friendly.
Common Mistake
Assuming window.ethereum is always present — this causes exceptions in environments without injected wallets or during server-side rendering.
Check Your Understanding
What should your UI show if window.ethereum is absent? A clear install guide and no wallet-specific controls until the user installs or connects a wallet.
