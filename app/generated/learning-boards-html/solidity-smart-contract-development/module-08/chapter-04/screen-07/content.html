Module 8 › Chapter 8.4 › Init in React
Step-by-step
  1. Detect window.ethereum and create a provider object.
  2. Store provider in state so effects can react to it.
  3. In a useEffect watching provider, construct new ethers.Contract and set it into state.
  4. Call a fetch function immediately after instantiation to populate UI state.
Checklist & tips
  • Re-create contract when provider changes to handle network switches.
  • Keep fetch logic separate so you can call it on demand.
  • Clear stale data when the wallet disconnects to avoid confusing UI.
