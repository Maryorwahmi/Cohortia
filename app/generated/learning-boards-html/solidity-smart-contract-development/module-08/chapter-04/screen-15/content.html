Init
Effect-driven initialization

Create the contract inside a useEffect that depends on provider so it re-inits correctly.

Fetch
Small async fetch

Await the results, set state, and clear on error to avoid stale UI values.

Events
Listen & respond

Handle accountsChanged, chainChanged, and disconnect to keep displayed data accurate.

Parting tip

Make reads robust before adding write interactions; a clear read experience builds user trust and simplifies debugging.
