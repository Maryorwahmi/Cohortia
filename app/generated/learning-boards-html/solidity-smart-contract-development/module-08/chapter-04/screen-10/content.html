Module 8 › Chapter 8.4 › Provider vs Signer
Provider

Gives read-only access to a node. Use it for view and pure calls that do not require signing.

Best for

Fetching current state for the UI, non-sensitive queries, caching results.

Signer

Wraps a provider and can sign transactions with the user's private key. Required for state-changing operations.

Use sparingly

Only request a signer when the user intends to send a transaction to reduce prompts and simplify testing.
