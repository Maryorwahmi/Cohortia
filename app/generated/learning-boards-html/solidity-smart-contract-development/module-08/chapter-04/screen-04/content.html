Module 8 › Chapter 8.4 › View & Pure Functions
Definition

A view function may read state but does not alter it. A pure function does not even read state and returns computed values only.

Concrete example
A public string variable such as name has an auto-generated getter you can call from JavaScript to obtain the current name.
Common mistake
Trying to call a function that changes state as if it were free will require a signer and will fail when using only a provider.
Why this matters for UIs
  • Reads are instant and cheap, so you can update UI frequently without asking the user to confirm.
  • Designate display-only getters for any state you expect the client to show often.
  • Use pure functions for deterministic calculations that depend only on inputs.
Key Takeaway

Expose read-only state via view or pure functions so the frontend can fetch live data quickly and without gas.
