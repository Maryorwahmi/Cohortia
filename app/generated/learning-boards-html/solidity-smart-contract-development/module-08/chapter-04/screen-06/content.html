Module 8 › Chapter 8.4 › Import & Instantiate
Key steps
  • Copy Greeter.json into src/contracts.
  • Import the JSON and use its abi property.
  • Create new ethers.Contract(address, GreeterABI.abi, provider).
Example (visual only)
// Import artifact
import GreeterABI from './contracts/Greeter.json'

const GREETER_CONTRACT_ADDRESS = '0x...yourAddress...'

// Given a provider
const contract = new ethers.Contract(
  GREETER_CONTRACT_ADDRESS,
  GreeterABI.abi,
  provider
)

// Ready to call read-only functions
const greeting = await contract.greet()
const name = await contract.name()
