Module 8 › Chapter 8.4 › Wallet Events
accountsChanged

If the wallet account changes, update account state, refresh the signer, and re-fetch contract data or clear it if disconnected.

chainChanged

Network switches often require reloading provider state. A safe strategy is to reload and reinitialize the contract instance on chain changes.

disconnect

When the wallet disconnects, clear account, signer, and any fetched contract data so the UI does not display stale information.

Key Takeaway

Handle wallet events proactively so your read-only UI always reflects the correct account and network context.
