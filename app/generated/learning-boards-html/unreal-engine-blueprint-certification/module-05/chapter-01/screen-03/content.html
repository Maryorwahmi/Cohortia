Practice: Build a Score HUD
A focused practice loop to make and display a simple HUD.
Create
Right-click Content Browser → User Interface → Widget Blueprint. Name it WBP_ScoreHUD.
Design
Drag a TextBlock for Score, adjust text, font size, color and anchor to top-left.
Display
From BeginPlay call Create Widget (WBP_ScoreHUD) then Add to Viewport.
Quick Debug Checklist
  • Was Add to Viewport called?
  • Is the widget Visibility set to Visible?
  • Are you accessing children before the widget exists?
  • Are anchors set for target resolutions?
