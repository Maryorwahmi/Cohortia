Module 5 › Chapter 5.1 › What is UMG?
Definition & Role
UMG is the visual UI system in Unreal used to create HUDs, menus, and interactive overlays.
Designer + Graph
Designer: layout; Graph: event handling and bindings.
UserWidget
Base class for custom widgets that holds visuals and logic.
Runtime lifecycle
Create an instance, then Add to Viewport to render it.
Concrete example
Imagine a Player Health display: a TextBlock shows current health while a ProgressBar fills to the health percentage. You create the widget asset, place those widgets in the Designer, and in the Graph bind a function that updates the TextBlock whenever health changes.
Misconception
Creating the asset alone does not display it. You must instantiate and add it to the viewport.
Why it matters
UI delivers player feedback and controls; good UMG design improves usability and accessibility of your game.
Key Takeaway

UMG combines visual layout and Blueprint logic to produce interactive UI. Asset creation, visual design, and runtime instantiation form the complete UMG workflow.
