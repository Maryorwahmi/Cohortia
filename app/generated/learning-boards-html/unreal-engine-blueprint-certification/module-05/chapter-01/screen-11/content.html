Module 5 › Chapter 5.1 › Score HUD Activity
Activity Steps
Create WBP_ScoreHUD and wire it into BeginPlay.
Designer
Add TextBlock with text "Score: 0". Anchor to top-left, set X=20, Y=20. Name it ScoreText and expose as variable.
Level Blueprint
Event BeginPlay → Create Widget (WBP_ScoreHUD) → save to HUDInstance → Add to Viewport(HUDInstance).
Updating score
When scoring events occur, call a function that sets ScoreText text on HUDInstance to the new value.
Starter Blueprint snippet
// In your Level Blueprint
// Event BeginPlay
//      |
//      V
//   Create Widget (Class: WBP_ScoreHUD) -> HUDInstance
//      |
//      V
//   Add to Viewport (Target: HUDInstance)

// Later, when score changes:
//   HUDInstance -> SetText(ScoreText, "Score: 10")
Common mistake
Attempting to update ScoreText before storing HUDInstance causes null references. Always create and store the instance first.
