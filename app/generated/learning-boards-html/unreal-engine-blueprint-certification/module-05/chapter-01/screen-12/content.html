Widget lifecycle checklist
Follow these checks when UI does not appear or behave.
Step 1: Was Create Widget called?
Create an instance before anything else.
Step 2: Add to Viewport
Without this, the instance is not rendered.
Step 3: Visibility and Z-order
Ensure set to Visible and not layered behind other elements.
Common developer error
Accessing widget children from another Blueprint before the widget instance exists leads to null references. Always call child updates after storing the Create Widget return value.
