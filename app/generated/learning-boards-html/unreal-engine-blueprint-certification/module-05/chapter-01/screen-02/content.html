Learning Objectives
Skills to build a basic HUD and display it at runtime.
Bloom: Learn → Understand → Apply → Master
01
Explain UMG's role
Describe why UMG is the visual UI system and how Designer and Graph work together.
Mnemonic: Asset → Designer → Graph
VERIFIED COMPETENCY MILESTONE
02
Create Widget Blueprint
Make a UserWidget asset and add TextBlock and Button elements in the Designer.
Mnemonic: Right-click → User Interface → Widget Blueprint
VERIFIED COMPETENCY MILESTONE
03
Arrange using layout panels
Use Canvas Panel and anchors for positioning; know responsive limits.
Mnemonic: Anchor then place
VERIFIED COMPETENCY MILESTONE
04
Display widget at runtime
Use Create Widget then Add to Viewport from Level Blueprint, PlayerController, or GameMode.
Mnemonic: Create → Add
VERIFIED COMPETENCY MILESTONE
