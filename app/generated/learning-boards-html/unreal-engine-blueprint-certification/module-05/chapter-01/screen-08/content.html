Module 5 › Chapter 5.1 › Canvas Panel & Layout
Canvas Panel basics
Absolute placement with optional anchors to support relative positioning.
Anchors
Set anchors before position offsets to keep widgets consistent across resolutions.
Absolute coordinates
Use X/Y for exact overlay placement, such as center crosshairs or HUD elements.
Complementary panels
Combine with Boxes or Scale Box for layouts that should resize gracefully.
Practical example
Anchor a Score TextBlock to top-left and set offsets X=20, Y=20. Anchor a High Score to top-right so it remains visible on wide screens.
Key Takeaway
Anchor first, position second. Use Canvas Panel for overlays, but prefer container panels for adaptive content.
