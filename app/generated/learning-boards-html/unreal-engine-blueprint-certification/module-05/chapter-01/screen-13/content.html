Assess & Debug
Practical questions and a repeatable checklist to resolve UI issues.
Quick question
Why doesn't a widget appear? Often because Add to Viewport was not called.
Widget choice
Best widget for text values: TextBlock. Use ProgressBar for visual fill states.
Debug checklist
  • Confirm Create Widget executed.
  • Confirm Add to Viewport executed.
  • Check Visibility and Z-order.
  • Verify instance reference before updating children.
Reflective prompt
After confirming Create Widget and Add to Viewport, check Visibility and whether another widget is occluding your UI. If still hidden, verify your anchors and screen resolution behavior.
