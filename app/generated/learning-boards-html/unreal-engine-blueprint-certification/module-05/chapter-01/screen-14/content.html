Module 5 › Chapter 5.1 › Key Concepts
UMG
Unreal's visual UI system combining Designer and Graph for interactive interfaces.
Widget Blueprint
An asset defining the visual layout and interactive logic of UI elements.
Create & Add
Instantiate with Create Widget, then render with Add to Viewport to make the UI visible.
Takeaway
Keep the asset, design, and runtime steps distinct: asset is the blueprint, Designer composes visuals, Graph wires behavior, and Create+Add makes it appear.
