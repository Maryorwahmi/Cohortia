Module 5 › Chapter 5.1 › Designer vs Graph
Designer tab
Visual canvas for layout. Place TextBlock, Button, Image and containers. Set anchors and absolute positions for Canvas Panel.
Drag-and-drop widgets
Adjust properties in Details panel
Set anchors for responsiveness
Graph tab
Add event handlers, bind functions, and update widget children at runtime using Blueprint nodes.
OnClicked and event nodes
Expose widget children as variables
Update TextBlock or ProgressBar dynamically
Example workflow
Place a TextBlock in Designer, give it a name like ScoreText, then in Graph on an event update ScoreText's text when the player earns points. Remember you must create and add the widget instance before Graph updates will take effect in Play mode.
Key Takeaway

Use Designer for structure and Graph for behavior. Name widget children you intend to control in the Graph and ensure the widget instance exists when calling those nodes.
