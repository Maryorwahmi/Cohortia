Module 5 › Chapter 5.1 › Creating a Widget Blueprint
Step-by-step
Create and name a UserWidget asset, then design basic elements.
1. Create asset
Right-click Content Browser → User Interface → Widget Blueprint. Choose UserWidget.
2. Name it clearly
Use WBP_PlayerHUD or WBP_ScoreHUD so purpose is obvious to other designers.
3. Open Designer
Drag TextBlock, Button, Image, and containers from the Palette.
4. Save and test
Save the asset before instantiating at runtime to avoid stale references.
Concrete example
Create WBP_PlayerHUD, add a TextBlock with text "Player Health: 100", then a Button labeled "Heal Player". Nest the TextBlock inside the Button to ensure it moves with the button.
Key Takeaway

A Widget Blueprint is both visual and logical. Name assets clearly and save before runtime use.
