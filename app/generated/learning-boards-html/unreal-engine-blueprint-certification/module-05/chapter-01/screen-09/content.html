Module 5 › Chapter 5.1 › Create Widget → Add to Viewport
Runtime steps
Instantiate and render a widget during gameplay using Blueprint nodes.
Create Widget
Select the Widget Class (WBP_PlayerHUD). The node returns an instance reference.
Add to Viewport
Pass the returned instance to render it on screen. Store reference if you will update it later.
Where to call
PlayerController or GameMode for persistent UI; Level Blueprint for quick tests.
Blueprint snippet
// In your Level Blueprint
// Event BeginPlay
//      |
//      V
//   Create Widget (Class: WBP_ScoreHUD)
//      |
//      V
//   Add to Viewport (Target: Return Value from Create Widget)
Key Takeaway

Create an instance before updating or referencing widget children, and always Add to Viewport to make the widget visible.
