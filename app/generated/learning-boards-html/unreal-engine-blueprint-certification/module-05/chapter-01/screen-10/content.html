Module 5 › Chapter 5.1 › Where to Instantiate
Choose based on lifetime
Level Blueprint, PlayerController, and GameMode each have trade-offs for widget lifecycle and access.
Level Blueprint
Easy for quick tests; not persistent across levels.
PlayerController
Good for persistent HUDs tied to the player; accessible client-side.
GameMode
Useful for game-rule UI; note server-only behavior in multiplayer contexts.
Practical guideline

If UI should follow the player across levels, instantiate it in PlayerController. For level-specific debug UI, Level Blueprint is fastest. Consider networking when choosing GameMode.
