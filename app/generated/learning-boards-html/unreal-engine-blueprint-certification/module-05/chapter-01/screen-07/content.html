Module 5 › Chapter 5.1 › TextBlock & Button
TextBlock
Used to display text such as Score: 0 or Player Health: 100. Update text from the Graph to reflect gameplay state.
Best practices
  • Expose frequently-updated TextBlocks as variables for quick access in Graph.
  • Pick font size and color for readability at target resolutions.
Button
Represents a clickable area. Add a child TextBlock as a label or set Style properties for visible feedback.
Common pitfall
Buttons can be invisible if you don't place visible content. Always add a label or style the button background.
Quick scenario
Place a Button labeled Heal Player. In the Graph use the OnClicked event to call a function on the player that increases health and then update the health TextBlock. This ties the visual to gameplay behavior.
