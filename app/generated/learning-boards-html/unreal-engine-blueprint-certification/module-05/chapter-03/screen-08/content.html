TextBlock styling
Set font family, size, color, and outlines in the TextBlock's Style. Use a limited type scale so headings and labels share consistent rhythm.
Tip: choose one readable font and a small set of sizes for body, label, and title to keep interfaces cohesive.
Button states & Slate Brushes
Buttons use separate visuals for normal, hovered, pressed, and disabled. Slate Brushes define these visuals and can be swapped centrally via a Style asset.
Avoid scattered tints and textures; central Styles make cross-widget updates simple.
