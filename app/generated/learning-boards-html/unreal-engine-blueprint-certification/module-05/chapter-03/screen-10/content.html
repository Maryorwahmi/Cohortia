Create an animation
Add a new Animation in the Animations panel, select a widget, add a Track, then choose the property to keyframe, such as Render Opacity.
Remember to set both start and end keyframes to define the full transition.
Example: FadeInMenu
Time 0.0: Render Opacity = 0.0. Time 1.0: Render Opacity = 1.0. Play Animation to see the fade appear when the widget constructs.
Common Mistake

Forgetting the starting keyframe or leaving the final keyframe unchanged results in an animation that jumps or doesn't reach the intended final state.
