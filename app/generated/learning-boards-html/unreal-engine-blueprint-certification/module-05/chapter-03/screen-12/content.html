Module 5 › Chapter 5.3 › Hands-on: Main Menu
Quick Steps
  1. Create WBP_MainMenu.
  2. Make Vertical Box the root; set anchors to Stretch and offsets to 0.
  3. Add three Buttons and TextBlocks: New Game, Options, Quit.
  4. Set Button padding and Size to Fill for adaptive width.
  5. Create Button Style asset and assign Slate Brushes/tints for states.
  6. Create FadeInMenu animation: Render Opacity 0.0 → 1.0 over 1s.
  7. In Graph: Event Construct → Play Animation (FadeInMenu).
  8. Add widget to viewport from BeginPlay to test.
Example properties
Button Padding: Top 10, Bottom 10. Vertical Box Alignment: Center. Animation length: 1.0s. Render Opacity start: 0.0, end: 1.0.
Check: after changing the Button Style asset, all buttons should adopt the new hover color immediately—this confirms centralized styling.
