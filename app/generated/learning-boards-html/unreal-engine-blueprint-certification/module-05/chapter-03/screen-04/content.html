Module 5 › Chapter 5.3 › Canvas vs Panels
Core differences
  • Canvas Panel: Absolute coordinates and anchors. Good for overlays and free-form layout.
  • Vertical / Horizontal Box: Automatic stacking and filling. Ideal for menus and toolbars.
  • Grid Panel: Row/column alignment for inventory-like layouts.
  • Common pitfall: using Canvas for everything makes cross-resolution testing painful.
Key Takeaway

Use layout panels to reduce manual positioning and improve responsiveness. Use Canvas only when absolute placement is required.

Concrete example
Create a main menu: make a Vertical Box root, add three Buttons, set Size to Fill, and center the Vertical Box by stretching anchors. The menu will scale across resolutions without manual offsets.
