Module 5 › Chapter 5.3 › Pitfalls & Fixes
Layout mistakes
  • Using Canvas for everything → move repeated structures into layout panels.
  • Inconsistent fonts/colors → create centralized Style assets.
  • Re-parenting without checking anchors → inspect Details panel after changes.
Animation mistakes
  • Missing start or end keyframes → always define both values.
  • Playing before Add to Viewport → ensure widget exists or trigger later.
  • Improper playback speed/looping → choose short, event-driven animations for UI.
Warning

Skipping resolution testing is common and costly. Always preview multiple aspect ratios after layout changes.
