Module 5 › Chapter 5.3 › Vertical Box
How it works
  • Stacking: children are placed top-to-bottom in order added.
  • Size: Auto or Fill — Fill expands to use remaining space.
  • Padding: adds space around each child without repositioning others.
  • Alignment: parent alignment controls group positioning inside its container.
Key Takeaway

Vertical Box is your default for stacked lists and menus. Use Fill and padding for adaptive spacing.

Example: 3-button menu
Place three Buttons inside a Vertical Box, set each Button Size to Fill and add Top/Bottom padding of 10. The buttons expand to match the Vertical Box width and maintain consistent spacing as the root resizes.
Pro Tip
If you need unequal heights, set Fill weights or use nested containers per row to control proportions.
