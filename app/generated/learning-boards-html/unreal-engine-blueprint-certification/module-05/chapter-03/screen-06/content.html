Module 5 › Chapter 5.3 › Horizontal & Grid
Horizontal Box
Best for row-based controls like toolbars or icon rows. Use Fill for equal distribution and padding for spacing. Check alignment to keep icons centered vertically.
Example
A toolbar of three buttons that expands horizontally with the window while maintaining even spacing.
Grid Panel
Use for inventories and option grids. Assign cells to each child and control padding to form uniform slots. Easier to maintain than nested boxes for tabular data.
Analogy
Think of Grid Panel as a spreadsheet: add or remove columns without recalculating many manual offsets.
