Module 6 › Chapter 5.5 › Event-Driven vs Polling
Event-driven

Runs when something meaningful happens. Example: OnHealthChanged triggers HUD update. Pros: minimal runtime cost, clear intent. Cons: requires an event to exist.

Polling (Timer)

Runs at a fixed interval. Example: Check enemy proximity every 0.5 seconds. Pros: simple to implement when events aren't available. Cons: still consumes cycles regularly.

Guideline

Prefer events for correctness and performance. Use timers sparingly for periodic tasks when events are not practical. Always document the interval decision.
