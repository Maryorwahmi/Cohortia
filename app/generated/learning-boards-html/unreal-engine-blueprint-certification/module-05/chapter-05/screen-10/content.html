Module 6 › Chapter 5.5 › Widget Reflector
What Widget Reflector shows
  • Active widget hierarchy and parent relationships.
  • Properties such as Visibility and Geometry bounds.
  • Which widget is under the mouse cursor in the running game.
Use it to confirm creation, detect Collapsed/Hidden states, or find widgets that are off-screen because of layout constraints.
Debugging steps
  1. Play in editor and open Widget Reflector via Developer Tools.
  2. Interact with UI and click suspect elements while watching the hierarchy highlight.
  3. Inspect visibility and parent containers; inspect bindings if an expected value is empty.
Real example: An invisible button was actually present but its parent container had zero size; the Reflector helped find the parent constraint.
