Module 6 › Chapter 5.5 › IsValid & Safety
When to IsValid
  • After Create Widget before binding or adding to viewport.
  • Before calling functions on references that may be destroyed.
  • When a reference is set externally or depends on network state.
Avoid overusing IsValid inside every node; place checks where ownership or lifecycle boundaries are crossed.
Blueprint snippet
// In BP_MyGameMode Graph
// Event BeginPlay
//      |
//      V
//   Create Widget (Class: WBP_MainMenu)
//      |
//      V
//   IsValid? (Target: Return Value from Create Widget)
//      | (Is Valid)
//      V
//   Set MainMenuRef (Variable)
//      |
//      V
//   // ... rest of your binding and Add to Viewport logic ...
//
//      ^ (Is Not Valid)
//      |
//   Print String (Text: "Error: Main Menu Widget failed to create!")
