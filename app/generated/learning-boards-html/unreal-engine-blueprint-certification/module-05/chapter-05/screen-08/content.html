Module 6 › Chapter 5.5 › Optimization Checklist
Step 1 — Cache references

Store frequently used actor or widget references during BeginPlay or Construct to avoid repeated Get All calls. Cached references are cheaper than repeated queries and stabilize behavior when actors are created once.

Step 2 — Timer vs Tick

If you must poll, use Set Timer by Event and choose a sensible interval (for example, 0.5s). This reduces calls by the ratio of frames per second to timer frequency.

Step 3 — Event-driven updates

Bind to events or dispatchers so logic runs only when state changes. This is often the cleanest and cheapest solution.

Concrete scenario

An enemy proximity check moved from Tick to a timer that runs every 0.5 seconds reduced the per-frame workload dramatically while keeping gameplay responsiveness acceptable.
