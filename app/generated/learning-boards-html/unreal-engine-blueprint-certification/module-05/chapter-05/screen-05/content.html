Module 6 › Chapter 5.5 › Folder Structure
Suggested top-level folders
Blueprints/
Characters, AI, GameModes
UI/
HUD, Menus, Notifications
Maps/
Persistent and streaming maps
Meshes/
Skeletal and static meshes
Materials/
Audio/
Group by function first, then type. For example: Blueprints/Characters/AI and Blueprints/Characters/Player.
Example refactor

Move all UI widgets for the HUD into UI/HUD and rename elements with TXT_ or BTN_ prefixes. Update bindings and add a comment box in each widget graph describing its purpose.

Common pitfalls
  • Dumping assets into a single folder during quick prototyping and never cleaning up.
  • Renaming or moving assets without verifying references and bindings.
Why it matters: A clear folder layout reduces search time and merge conflicts when multiple developers work in the same project.
