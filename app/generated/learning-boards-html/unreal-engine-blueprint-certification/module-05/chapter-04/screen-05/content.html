Module 5 › Chapter 5.4 › Direct Casting Workflow
Common node sequence
Get Player Controller → Cast To MyPlayerController → Call Function
// Conceptual Blueprint pseudo-code
OnButtonClicked:
  ControllerRef = Get Player Controller
  If ControllerRef is not null:
    MyController = Cast To MyPlayerController(ControllerRef)
    If Cast succeeds:
      MyController->StartNewGame()
This example shows the safety checks you should consider: confirm the controller exists and ensure the cast succeeds before calling functions.
When to use
Single known target, low risk of refactor, quick prototype calls.
Pitfalls
Tight coupling, broken casts after refactor, and fragile references when used with Get All nodes.
Pro-tip
Cache references when you Create Widget or on BeginPlay to avoid repeated Get calls, but ensure lifetime management.
