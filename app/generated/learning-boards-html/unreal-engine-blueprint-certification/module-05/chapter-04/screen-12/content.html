Step-by-step checklist
  1. Add Event Dispatcher OnNewGameClicked in WBP_MainMenu.
  2. Call OnNewGameClicked from New Game's OnClicked event.
  3. In BP_MyGameMode BeginPlay Create Widget WBP_MainMenu and Set MainMenuRef.
  4. Get MainMenuRef → Get OnNewGameClicked → Bind Event to OnNewGameClicked → Create HandleNewGameRequest.
  5. Inside HandleNewGameRequest Print String, Remove from Parent(MainMenuRef), Open Level("YourGameLevelName").
