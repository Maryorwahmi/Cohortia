Module 5 › Chapter 5.4 › Two-way UI communication
What it means
Widgets must relay player intent and pass context to gameplay Blueprints so the game responds to UI actions.
Concrete example
A Main Menu's New Game button signals GameMode to load a level and remove the menu from view.
Common mistake
Overusing Get All Actors or deep casts when a dispatcher or interface would be cleaner and safer.
Key Takeaway

Plan the communication direction and scope before implementing: one-off calls, broadcasts, or contracts.

Analogy: Postal System
Think of messages sent by widgets as mail. Direct casting is handing the mail to a specific person. A dispatcher is like a town bell announcing an event. An interface is an agreed mailbox standard each household implements.
When to Cast
You have a single known target and stability in class design.
When to Dispatch
Multiple listeners or loose coupling are required.
When to Use Interfaces
You need a defined contract and polymorphic calls to different receivers.
Avoid
Excessive Get All nodes and unchecked casts that can return null or wrong instances.
