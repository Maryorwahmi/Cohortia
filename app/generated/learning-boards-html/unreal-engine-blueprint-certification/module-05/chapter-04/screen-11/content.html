Checklist for failing handlers
  • Bind order: ensure Bind Event to Dispatcher runs before the dispatcher is called.
  • Reference validity: store widget references when you Create Widget.
  • Cast checks: only call methods after cast success.
  • Print for debug: confirm handler entry before level transitions.
Common errors
Using Get All Actors or Get All Widgets to locate instances causes inefficiency and unpredictability; prefer direct references or creation-time wiring.
Quick recovery tip
Add Print String at the start of your bound handler, trigger the UI, and confirm the message appears to isolate whether the binding succeeded.
