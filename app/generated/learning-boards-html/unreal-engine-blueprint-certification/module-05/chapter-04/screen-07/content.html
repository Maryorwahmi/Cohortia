Blueprint pseudo-code (conceptual)
// In BP_MyGameMode - Event BeginPlay
Create Widget(Class: WBP_MainMenu)
Set MainMenuRef = return value
Get MainMenuRef -> Get OnNewGameClicked
Bind Event to OnNewGameClicked -> Create Custom Event: HandleNewGameRequest
Add to Viewport(MainMenuRef)

// Custom Event: HandleNewGameRequest
Print String "New Game Started!"
Remove from Parent(Target: MainMenuRef)
Open Level("YourGameLevelName")
Checklist
  • 1. Create and store widget reference after Create Widget.
  • 2. Get the Event Dispatcher from that reference.
  • 3. Bind a custom event immediately after creating the widget.
  • 4. Verify with a Print String before destructive actions like Open Level.
Debug tip
If your handler doesn't run, confirm MainMenuRef isn't null and binding code executes before the widget's Call to the dispatcher happens.
