Module 5 › Chapter 5.4 › Key Concepts
Direct Casting
Convert a generic object into a known class to call its functions directly.
Event Dispatcher
Broadcast an event from a widget that other Blueprints can bind to and handle.
Blueprint Interface
Define function signatures so different classes can implement a common message contract.
Quick takeaway
Match pattern to scope: cast for direct calls, dispatchers for broadcasts, interfaces for contracts.
