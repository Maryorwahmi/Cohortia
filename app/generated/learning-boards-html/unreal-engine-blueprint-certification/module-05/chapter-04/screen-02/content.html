Learning Objectives
Understand and apply UI→gameplay communication patterns: Direct Casting, Event Dispatchers, and Blueprint Interfaces.
01
Establish UI→Gameplay Channels
Create references from Widget Blueprints to gameplay Blueprints using Get Player Controller, Get Game Mode, or passed references so the UI can call functions or dispatch events.
VERIFIED COMPETENCY MILESTONE
02
Use Event Dispatchers
Broadcast UI events with dispatchers and bind in GameMode or other Blueprints to respond without tight coupling.
VERIFIED COMPETENCY MILESTONE
03
Implement Blueprint Interfaces
Define interface functions to call by message so multiple classes can respond to UI calls in their own way.
VERIFIED COMPETENCY MILESTONE
04
Pass Data Safely
Send parameters through dispatchers or interface functions so gameplay receives necessary context like selected option or new health values.
VERIFIED COMPETENCY MILESTONE
Bloom: Learn → Understand → Apply → Master
