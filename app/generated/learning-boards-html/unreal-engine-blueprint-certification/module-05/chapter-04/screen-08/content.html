Module 5 › Chapter 5.4 › Passing Parameters
Example dispatcher signature
OnOptionSelected(String OptionName)
When calling OnOptionSelected, provide the chosen option string. The bound handler receives that same string as its parameter.
Why keep parameters small?
Smaller payloads are easier to reason about and less likely to reference objects that may be destroyed. Use simple data or lightweight structs when necessary.
Concrete scenario
WBP_Options calls OnSaveSettings(IsFullscreen: Boolean, VolumeLevel: Float). BP_GameSettingsManager's handler receives those values and writes them to disk.
Watch out
Passing actor references requires you to ensure those actors remain valid; prefer IDs or lightweight structs when lifetime is uncertain.
Binder signature
When you create the custom event during Bind Event, include the same parameters so the handler receives the data cleanly.
