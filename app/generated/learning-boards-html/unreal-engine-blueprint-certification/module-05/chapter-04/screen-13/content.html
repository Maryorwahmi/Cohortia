Module 5 › Chapter 5.4 › Assessment Scenarios
Scenario A — Save Settings
UI broadcasts OnSaveSettings; GameSettingsManager binds to receive and persist the settings. Best: Event Dispatcher.
Scenario B — Update HUD Ammo
Player Character pushes updates to a HUD that may vary in class. Best: Blueprint Interface BPI_UpdateAmmo.
Scenario C — Quick Prototype Call
A debug toggle that calls a known Player Controller method. Acceptable: direct cast with safety checks.
Reflective prompt
Which pattern would you choose for a UI that must notify both the GameMode and several Actor listeners? (Hint: a dispatcher provides the simplest broadcast.)
