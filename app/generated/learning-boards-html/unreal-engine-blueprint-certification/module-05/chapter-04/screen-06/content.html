Module 5 › Chapter 5.4 › Event Dispatchers
Three-step dispatcher pattern
1. Create Dispatcher
Add an Event Dispatcher variable in WBP_MainMenu named OnNewGameClicked.
2. Call Dispatcher
On the New Game button's OnClicked, call OnNewGameClicked so the widget broadcasts the event.
3. Bind to Dispatcher
From GameMode after Create Widget, Get OnNewGameClicked and Bind Event to OnNewGameClicked to handle the request.
Example flow
Create Widget → Store MainMenuRef → Get dispatcher → Bind Custom Event HandleNewGameRequest → Add to Viewport.
Mistake to avoid
Binding after the widget is already destroyed or forgetting to store the widget reference so Bind has no target.
Why this helps
Dispatchers decouple the sender from receivers, allowing multiple systems to react without the widget knowing about them.
