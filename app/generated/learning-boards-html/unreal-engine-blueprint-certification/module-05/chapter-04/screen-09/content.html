Module 5 › Chapter 5.4 › Blueprint Interfaces
What an Interface is
A simple contract of function names and parameters. No logic lives in the interface asset itself.
Concrete use
Define BPI_UpdateHUDHealth(NewHealth: Integer), implement it on WBP_PlayerHUD, then call the message from Player Character to update the HUD.
How to create
Right-click in Content Browser → Blueprints → Blueprint Interface, add functions and parameters, then implement in Class Settings of your Blueprints.
Common gotcha
Remember to call the Message node for interface calls and to implement each interface function inside the class that uses it.
When to prefer
Use interfaces when multiple different classes should respond to the same message and you want strong decoupling and clear contracts.
