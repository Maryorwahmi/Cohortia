Module 5 › Chapter 5.2 › Hands-on Activity
Step-by-step checklist
  1. Add ProgressBar to Designer; check Is Variable; rename PB_Health.
  2. Create Integer variables: CurrentHealth (100) and MaxHealth (100).
  3. Bind PB_Health.Percent: To Float(CurrentHealth) / To Float(MaxHealth) → Return.
  4. Add OnClicked for Heal Button and implement Get → Add(20) → Clamp → Set CurrentHealth.
  5. Update TextBlock_Health via binding or Set Text(To Text(CurrentHealth)).
  6. Compile, Save, Play, and test by clicking Heal Player.
