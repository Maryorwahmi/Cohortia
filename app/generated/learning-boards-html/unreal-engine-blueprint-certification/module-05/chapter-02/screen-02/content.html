Learning Objectives
Learn → Understand → Apply → Master
Bloom: Learn · Understand · Apply · Master
01
Wire OnClicked for Buttons
Create an OnClicked event in the Graph to respond when a Button is pressed and released. This connects UI interaction to gameplay effects, such as healing a player by updating a health variable.
VERIFIED COMPETENCY MILESTONE
02
Update TextBlock at runtime
Use Set Text or a binding to change a TextBlock's content when underlying game data changes, keeping the player informed of current state like health or score.
VERIFIED COMPETENCY MILESTONE
03
Use widget variables
Enable Is Variable to expose widgets like TextBlock_Health or PB_Health in the Graph so you can call Set Text or update Percent values directly.
VERIFIED COMPETENCY MILESTONE
04
Bind properties for automatic updates
Create binding functions for properties like Text or Percent so UMG calls them when it needs to refresh, avoiding inefficient per-frame updates.
VERIFIED COMPETENCY MILESTONE
