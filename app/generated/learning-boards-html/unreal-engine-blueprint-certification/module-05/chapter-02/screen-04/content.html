Create the OnClicked event
Select the Heal Button, open Events in Details, and click + next to OnClicked. This generates an event node in the Graph ready for logic.
Step-by-step
  1. Select Button in Designer
  2. In Details → Events, click + for OnClicked
  3. Go to Graph and wire subsequent nodes from the event's execution pin
Quick Example
Attach a Print String to the OnClicked node to verify the event fires. Then replace the print with your health-update logic.
