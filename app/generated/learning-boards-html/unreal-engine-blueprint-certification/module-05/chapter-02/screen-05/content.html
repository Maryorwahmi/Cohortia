What Is a widget variable?
A widget variable is a Designer widget flagged for Graph access. Check Is Variable in Details to expose it by name in the Graph.
Example
Select a ProgressBar and check Is Variable. Rename it PB_Health. Compile. In the Graph you can now Get PB_Health and call Set Percent or read current value.
Why it matters
Variables let the Graph directly modify widget properties, attach animations, and pass references between nodes—essential for interactive UI behavior.
Misconception
Bindings eliminate the need for widget variables. Not true: bindings are ideal for property refresh, but many operations—Set Text calls, manual animations, or passing the widget to functions—require a variable reference.
Quick checklist
  • Check Is Variable on widgets you will reference.
  • Use clear names like TXT_Health, PB_Health, BTN_Heal.
  • Compile to refresh the Variables list in the Graph.
Key takeaway
Key Takeaway

Is Variable is the bridge between Designer visuals and Graph logic. Use it to manipulate widgets at runtime.
