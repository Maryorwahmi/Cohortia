Naming conventions
Use type prefixes and descriptive names to make Graph wiring clear and maintainable.
Suggested prefixes
BTN_ for Buttons, TXT_ for TextBlocks, PB_ for ProgressBars, IMG_ for images.
Debugging tips
Add Print String nodes after events to confirm the right handler fires. Use comments or reroutes to annotate purpose in complex graphs.
Common error
Leaving default names like Button_0 and later connecting the wrong variable. Rename immediately after adding widgets.
Key takeaway
Key Takeaway

Consistent naming is a simple, high-leverage habit that prevents many UI wiring bugs.
