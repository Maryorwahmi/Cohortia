Blueprint sequence (visual)
OnClicked (Button)
  → Get CurrentHealth (int)
  → Add (int) [+20]
  → Clamp (Min:0, Max:MaxHealth)
  → Set CurrentHealth (int)
  → Optional: Set Text(TextBlock_Health) with To Text(CurrentHealth)
  → Optional: Print String("Health: " + To Text(CurrentHealth))
This chain ensures the value is computed, constrained, and saved. Use Print String while testing to confirm values change as expected.
Example nodes explained
  • Get CurrentHealth: reads the variable's current value.
  • Add: increases the value by the heal amount.
  • Clamp (Integer): prevents values outside 0..MaxHealth.
  • Set CurrentHealth: writes the new value back.
Pitfall
Forgetting Clamp can let CurrentHealth exceed MaxHealth, breaking UI expectations. Always clamp when increasing values.
