Interactive UI Elements and Event Handling
Turn static widgets into responsive gameplay controls with events, variables, and bindings.
Why this matters
Players expect immediate feedback. Events map input to game state changes and bindings keep displays accurate.
What you'll build
An interactive health display with a Heal button and a bound ProgressBar percent.
Explore Key Topics
Events
OnClicked and other widget events trigger Blueprint nodes when the player interacts.
Variables
Mark widgets as variables to reference them in the Graph and change properties at runtime.
Bindings
Bind Text or Percent to functions so UMG updates them automatically when values change.
Visual concept: WBP_PlayerHUD interaction
Button (Heal)
Has OnClicked event. When fired, it updates CurrentHealth and optionally calls Set Text.
TextBlock_Health
Marked as variable or bound to a GetText function that returns CurrentHealth converted to text.
Connections
OnClicked updates CurrentHealth → ProgressBar bound percent recalculates as CurrentHealth / MaxHealth → TextBlock binding or Set Text shows new value.
In this lesson: we will practice creating events, variables, bindings and avoiding common mistakes like leaving widgets unmarked as variables.
