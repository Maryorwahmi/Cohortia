Module 5 › Chapter 5.2 › Text Update Patterns
Set Text (Manual)
Use when you want to update text in response to a discrete event like OnClicked. Drag TextBlock variable into the Graph and call Set Text with a converted value.
Example
OnClicked → Get CurrentHealth → To Text(int) → Set Text on TextBlock_Health.
When to use
Formatting or updates tied to a specific action, not continuous refreshes.
Binding (Automatic)
Create a binding function for the Text property so UMG calls the function when it needs to render. The function returns the string representation of your variable.
Example Binding
Get CurrentHealth → To Text → return. Or construct "Health: X / Y" and return that.
Performance note
Keep binding logic simple — heavy computations inside bindings run whenever UMG refreshes. Use bindings for frequent updates and Set Text for rare, complex updates.
