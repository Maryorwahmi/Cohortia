Module 5 › Chapter 5.2 › Bindings vs Set Text
Binding
Automatic: create a function that returns the property value and let UMG call it whenever needed.
  • Pros: minimal wiring, always up-to-date for frequent changes.
  • Cons: called often, so logic must be lightweight.
Set Text (Manual)
Explicit: call Set Text from events when you want to update the display immediately and control timing.
  • Pros: precise control; good for complex formatting.
  • Cons: more wiring; you must call it every time value changes.
Decision guide
If the value updates frequently and is cheap to compute, bind it. If updates are tied to explicit events or require expensive formatting, use Set Text. Never update UI via Event Tick.
