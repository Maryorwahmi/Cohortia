Module 3 › Chapter 3.2 › Event Hit vs Event Overlap
Event Overlap (detection)

Fires when two objects set to Overlap share space. Good for triggers like pickups or detection zones.

// Blueprint-style pseudocode
OnComponentBeginOverlap(OtherActor)
  if OtherActor is Player then
    GrantHealth(OtherActor, 25)
    DestroySelf()
  end
end

// Note: Ensure Generate Overlap Events is enabled
Misconception
Overlap does not block movement. If you need stopping behavior, use Block and Event Hit instead.
Event Hit (physical)

Fires when blocking collisions occur and provides impact details like Location, Normal, and Other Actor useful for impact effects and physics responses.

// Blueprint-style pseudocode
OnComponentHit(HitResult)
  SpawnImpactEffect(HitResult.Location, HitResult.Normal)
  if HitResult.OtherActor is PhysicsActor then
    ApplyImpulse(HitResult.OtherActor, -HitResult.Normal * Strength)
  end
end
Key Takeaway

Pick Overlap for detection-only triggers and Hit for physical blocking collisions that require impact information.
