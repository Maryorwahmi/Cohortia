Practical Skills

Concrete abilities to build and test collision-driven gameplay.

Apply → Verify
Enable Physics & Tune Mass
Turn on Simulate Physics for meshes that should respond to gravity and forces. Set mass to match the object's expected resistance to motion.
Mnemonic: Heavier = harder to move
VERIFIED COMPETENCY MILESTONE
Apply Forces vs Impulses
Use Add Force for continuous pushes and Add Impulse for instant pushes like a single shove or explosion impulse.
Mnemonic: Force = push over time; Impulse = one-time shove
VERIFIED COMPETENCY MILESTONE
Blueprint Event Responses
Use On Component Begin Overlap for triggers and Event Hit to catch blocking collisions and retrieve impact details.
Mnemonic: Overlap = detect, Hit = block
VERIFIED COMPETENCY MILESTONE
Testing & Debugging
Use debug line traces and visualize collision shapes in the editor to verify that presets and channels are set correctly.
Mnemonic: Visualize first, then adjust
