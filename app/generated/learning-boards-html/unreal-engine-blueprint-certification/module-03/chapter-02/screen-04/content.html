Module 3 › Chapter 3.2 › What is Collision Detection?
Definition & Rationale

Collision detection determines when volumes intersect and triggers either physical response or detection-only events. It is a functional foundation for movement, triggers, and physics simulation.

Analogy
Think of collision shapes as sticky outlines; when two outlines overlap, the engine decides whether to stop them or simply note the overlap.
Concrete Example
A pickup uses Overlap so the player collects it without being blocked. A wall uses Block to prevent walking through it.
Common Mistake
Using BlockAll everywhere leads to unintended physical bumps and performance costs. Tailor responses to needs.
Key Takeaway

Collision decides both detection and physical response. Choose shapes and rules to match gameplay intent.

Visual guide: overlapping volumes
Block vs Overlap
Block stops motion and can trigger Event Hit; Overlap detects entry and triggers overlap events without stopping movement.
Try this
Place a pickup with Overlap and walk through it. Then change it to BlockAll and observe how the player is blocked — that's the difference in behavior.
