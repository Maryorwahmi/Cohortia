Box Collision

Best for aligned environment geometry and cubic meshes. Tends to be cheap and stable for blocking surfaces and trigger volumes.

Use case
Crates, doors, environmental triggers
Sphere Collision
Rolling objects, simple proximity detections
Capsule Collision
Character bodies, stable standing and crouch transitions
Key Takeaway

Match shape to object geometry and movement. Tune size and offset to avoid clipping or false collisions.

Tuning and common pitfalls
  • Always verify collision shape visually in the editor; meshes and collisions can be misaligned.
  • Don't leave default sizes; scale collision so it matches the visible geometry closely.
  • Use simple shapes where possible — complex per-poly collisions are costly.
  • Test interactions: if ground detection fails, check the capsule origin and foot position relative to the shape.
Quick test
Toggle collision visualization, place the actor, and observe overlaps or penetrations while the player moves nearby.
