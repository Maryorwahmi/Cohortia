Mass & Its Effects

Mass scales acceleration: the same impulse produces less velocity on heavier objects. Tune mass to match visual scale and expected gameplay feel.

If an object is too light and jittery, increase mass or add damping.
For very small objects, consider disabling physics simulation if physics isn't essential.
Use simplified collision shapes to improve solver stability.
Tuning checklist
  • Set mass consistent with object size and expected resistance.
  • Add linear or angular damping to reduce oscillation after impacts.
  • Simplify collision shapes when stability problems occur.
  • Test pushes and impulses at gameplay speeds to validate behavior.
Key Takeaway

Tune mass, damping, and collision complexity together to achieve stable and believable physics responses.
