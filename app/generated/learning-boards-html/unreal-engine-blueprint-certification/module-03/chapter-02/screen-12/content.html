Module 3 › Chapter 3.2 › Trigger Volume Walkthrough
Quick steps
  1. Create Actor Blueprint named BP_TriggerZone.
  2. Add Box Collision and size it for player entry.
  3. Set Collision Presets to OverlapAllDynamic and check Generate Overlap Events.
  4. In Event Graph add On Component Begin Overlap, cast Other Actor to your player, then Print String on success.
Key Takeaway

A trigger uses Overlap to detect entry without blocking. Verify Generate Overlap Events and both sides of the interaction.

Blueprint pseudocode
// On Component Begin Overlap (BoxCollision)
If OtherActor is ThirdPersonCharacter then
  Print String("Player Entered Trigger Zone!")
end
Test by placing BP_TriggerZone in the level and playing. Walk into the box to see the printed message. If nothing prints, verify the player class and that Generate Overlap Events is enabled.
