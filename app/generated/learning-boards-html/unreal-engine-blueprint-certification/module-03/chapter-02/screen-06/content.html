Collision Presets

Presets are quick assignments for common roles, setting a component’s default responses to other channels. They speed up configuration.

BlockAll
Blocks all channels and produces physical hits.
OverlapAll
Detects overlaps without blocking movement.
PhysicsActor
Configured for objects that simulate physics and should collide realistically.
Custom Collision Channels

Define categories like Player, Projectile, Pickup and explicitly set Ignore, Overlap or Block between them for specific behaviors.

Example matrix
Player blocks WorldStatic, overlaps Pickup, ignores PlayerProjectile to prevent self-damage.
Best practice
Sketch an interaction table before assigning channels to avoid accidental global blocking.
Common Mistake
Relying on BlockAll by default instead of crafting a precise interaction map, which can cause unwanted physics and performance issues.
