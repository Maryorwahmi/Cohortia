Module 3 › Chapter 3.2 › Pushable Cube Walkthrough
BP_PushableCube setup
  1. Create Actor Blueprint named BP_PushableCube.
  2. Add Static Mesh (Shape_Cube) and Box Collision to match size.
  3. On the Static Mesh enable Simulate Physics and set Collision Preset to PhysicsActor.
Key Takeaway

Simulate Physics must be enabled for impulses to move the mesh. Tune mass for expected response.

Player Blueprint Push logic
// On Push input pressed
LineTrace By Channel(Start = PlayerLocation + Forward*100,
                     End = PlayerLocation + Forward*500,
                     Trace Channel = Visibility)
If Hit Actor is BP_PushableCube then
  Get Static Mesh Component
  Add Impulse At Location(Impulse = PlayerForward * 20000,
                          Location = Hit.ImpactPoint)
end
Test by placing BP_PushableCube in level. Aim and press Push key. If cube does not move, confirm Simulate Physics is on and the Static Mesh collision is set to interact with the trace channel.
