Module 3 › Chapter 3.2 › Create Custom Channel
Step-by-step
Step 1
Open Project Settings → Engine → Collision and add an Object Channel named 'Pickup' or similar.
Step 2
Set the default response and save. Return to your Actor and select the collision component to use the new channel.
Step 3
On both interacting Actors, set how they respond to the channel: Block, Overlap, or Ignore. Verify both sides match your intended behavior.
Step 4
Test using Play-in-Editor and collision visualization to confirm events fire as expected.
Visual checklist
  • Channel named clearly and used consistently across Actors.
  • Both object responses configured to produce the desired Event Hit or Overlap.
  • Generate Overlap Events enabled for overlap triggers.
  • Test with debug visuals and a simple test actor in the level.
Key Takeaway

Channels avoid ad-hoc blocking rules; define them deliberately and configure both sides of the interaction.
