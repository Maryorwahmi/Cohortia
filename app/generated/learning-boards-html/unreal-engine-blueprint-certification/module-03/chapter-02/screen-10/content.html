Module 3 › Chapter 3.2 › Forces vs Impulses
Add Force

A continuous application that accelerates the object while it is applied. Good for steady influences like wind or engine thrust.

// Blueprint node usage
AddForce(TargetMesh, ForceVector, ForceMode: Acceleration)
When to use
Continuous environmental effects or sustained pushes.
Add Impulse

An instantaneous change in momentum. Useful for single events like a player shove or explosion impulse.

// Blueprint node usage
AddImpulseAtLocation(TargetMesh, ImpulseVector, ImpactPoint)
When to use
Single interactions where an instant reaction is needed.
Common Pitfall
Applying large continuous forces without damping can cause runaway velocities. Prefer impulses or clamp forces when necessary.
