Hands-on

Projectile Blueprint

Components, events, and a self-destruct timer form a reliable projectile implementation.

Components to add
  • Sphere Collision (radius ~10), Collision Presets = Projectile, Generate Overlap Events checked.
  • Static Mesh (Shape_Sphere) as a child.
  • Projectile Movement with Initial and Max Speed = 2000.
Event Graph

BeginPlay: Set Timer by Event, Time = 3.0, calls DestroySelf. On Component Hit: Destroy Actor Self.

Event Graph pseudocode
Event BeginPlay:
  Set Timer by Event (Time=3.0, Looping=false)
    -> Custom Event DestroySelf

On Component Hit (Sphere Collision):
  Spawn Emitter at Location (optional)
  Destroy Actor (Target=Self)

Custom Event DestroySelf:
  Destroy Actor (Target=Self)
Key Takeaway

Combine collision and a timer for robust tear down so projectiles cannot persist indefinitely.
