Player spawn wiring

Map input to Spawn Actor from Class, supply a correct transform, and set Owner to Self.

Practical steps
  1. Add Input Action Fire in Project Settings and map to Left Mouse Button.
  2. In ThirdPersonCharacter Blueprint, add Input Action Fire (Pressed).
  3. Spawn BP_Projectile with Spawn Transform from a socket or forward offset; set Owner to Self.
Spawn wiring pseudocode
On Input Action Fire (Pressed):
  Transform muzzleTransform = GetSocketTransform(Mesh, 'Muzzle')
  // or compute using GetActorLocation + ForwardVector * 100
  SpawnActorFromClass(BP_Projectile, muzzleTransform, Owner=Self, CollisionHandling=TryToAdjust)
Key Takeaway

Use sockets for precision and assign Owner so the projectile knows its creator and behaves accordingly.
