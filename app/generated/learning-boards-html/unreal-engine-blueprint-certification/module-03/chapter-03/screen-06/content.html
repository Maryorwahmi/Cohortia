Module 3 › Chapter 3.3 › Constructing a Spawn Transform
Blueprint pattern

Build reliable transforms

Use socket transforms or compute relative offsets from the owner to avoid origin spawns and wrong rotations.

When to use sockets

If your mesh has a Muzzle socket, Get Socket Transform ensures precise placement and orientation for projectiles.

When to compute offset

If sockets aren't present, calculate location using Get Actor Location + Get Actor Forward Vector * distance.

Blueprint-like pseudocode
// Compute spawn transform for projectile
Vector ownerLocation = GetActorLocation(Self)
Vector forward = GetActorForwardVector(Self)
Vector spawnLocation = ownerLocation + forward * 100
Rotator spawnRotation = GetControlRotation(Self) // or GetActorRotation
Transform spawnTransform = MakeTransform(spawnLocation, spawnRotation, Vector(1,1,1))
SpawnActorFromClass(BP_Projectile, spawnTransform, Owner=Self, CollisionHandling=TryToAdjust)
Key Takeaway

Never rely on default transform; always compute or read a specific transform for predictable spawn results.
