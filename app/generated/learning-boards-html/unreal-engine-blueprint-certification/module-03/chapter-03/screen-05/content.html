Module 3 › Chapter 3.3 › Spawn Actor from Class
Process Flow

Using the Spawn node

Pick a class, compute a spawn transform, set Owner and collision handling, then execute the node.

Step 1 — Choose Class

Select the Blueprint Class to instantiate, e.g., BP_Projectile or BP_Enemy.

Step 2 — Build Spawn Transform

Use Get Actor Transform, socket transforms, or Make Transform to provide Location, Rotation, and Scale.

Step 3 — Set Owner & Collision

Connect Self to Owner to track creation and choose Collision Handling to control initial placement behavior.

Collision Handling examples
  • Always Spawn, Ignore Collisions: good for VFX that can overlap.
  • Try To Adjust Location But Always Spawn: nudges spawn location to avoid overlaps for NPCs.
  • Do Not Spawn If Colliding: safe when placement must be exact.
Misconception

Owner is not only for replication — it also communicates creation intent and is used by logic like damage filtering.

Key Takeaway

Provide a correct transform and owner; choose collision handling based on gameplay needs.
