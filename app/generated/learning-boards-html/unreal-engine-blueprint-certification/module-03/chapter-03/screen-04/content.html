Module 3 › Chapter 3.3 › What is spawning?
Core Concept

Spawning explained

Create instances of Blueprint Classes during gameplay so they act like normal Actors.

Why spawn?
  • Enable dynamic gameplay: enemies, projectiles, pickups appear when needed.
  • Save design time by not pre-placing every instance in the level.
  • Control lifecycle and memory usage by destroying when finished.
Concrete example

Pressing Fire spawns BP_Projectile with a muzzle transform and Owner set to the player so it doesn't damage its creator.

Common mistake

Leaving the Spawn Transform default causes Actors to appear at world origin; always derive transforms from a spawn point or socket.

Analogy

Think of spawning as printing a new game object from a template. The template is the Blueprint class and the printed copy is a live Actor that can be manipulated independently.

Key Takeaway

Treat every spawned Actor as a distinct object with its own lifecycle and clean it up when finished.
