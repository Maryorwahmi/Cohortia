Bind & Broadcast steps
// Source (Character)
Event Dispatcher: OnCharacterInteracted
Call OnCharacterInteracted when MyInteract (Pressed) occurs

// Listener (BP_InteractionListener) in BeginPlay
Get Player Character → Cast to ThirdPersonCharacter
Bind Event to OnCharacterInteracted → Create Custom Event ReactToInteraction
ReactToInteraction → Set Text Render to "Character Interacted!"
Example & Caveats

Dispatchers are ideal when multiple or unknown actors must react. Ensure that binds occur before the first expected broadcast and handle failed casts gracefully. Unbind if listeners may be destroyed mid-game.

Pro tip

Use dispatchers to reduce coupling and make systems easier to extend without changing the source actor.
