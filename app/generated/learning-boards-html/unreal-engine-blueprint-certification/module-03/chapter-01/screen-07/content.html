Module 3 › Chapter 3.1 › Input States
State cards
Pressed

Fires once immediately. Use for single-trigger actions like reload or a discrete jump impulse.

Triggered

Fires repeatedly while held. Use for continuous movement or sustained fire. Beware frequency and performance implications.

Released

Fires once when input is released. Good for charge-and-release mechanics or cleanup logic.

Example & Misconception

If you wire walking to Pressed you will see a single-frame movement. Instead use Triggered to apply movement every frame or per input tick. Many learners assume Pressed can be used for everything; match the input state to the intended gameplay timing.

Check your understanding

Would reloading a weapon be Pressed or Triggered? Why? (Answer: Pressed because reloading should happen once per key press.)
