Module 3 › Chapter 3.1 › Custom Events
Purpose

Create a Custom Event like OpenDoor to represent a clear action. Call it from anywhere with a reference, or bind it to a dispatcher for broader reach.

Best practice

Keep custom events focused and name them by intent, not implementation details.

Example
BP_Door: Custom Event OpenDoor

OpenDoor handles animation and collision. Another actor with a reference can call OpenDoor directly; multiple actors can also bind to a dispatcher instead.

Key Takeaway

Use custom events to keep logic modular; prefer dispatchers when you need multiple or dynamic listeners.
