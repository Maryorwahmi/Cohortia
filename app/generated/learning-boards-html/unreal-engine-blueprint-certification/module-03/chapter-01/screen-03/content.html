Module 3 › Chapter 3.1 › Practice Checklist
Setup Input Actions

Open Project Settings → Input. Add Action Mappings: MyMoveForward → W, MyInteract → E. This separates physical keys from game actions.

Mnemonic: Map then Bind
VERIFIED COMPETENCY MILESTONE
Wire Input in Blueprint

Right-click Event Graph, search Input Action MyMoveForward and Input Action MyInteract. Use Pressed and Released pins to trigger Print String for testing.

Mnemonic: Press → Print → Validate
VERIFIED COMPETENCY MILESTONE
Create & Bind Dispatcher

Add an Event Dispatcher OnCharacterInteracted in your character. Call it on Interact Pressed. In the listener Actor, bind a custom event at BeginPlay to react.

Mnemonic: Dispatch, Bind, React
VERIFIED COMPETENCY MILESTONE
Validate and Debug

Place the listener in the level, play, and press keys. Confirm Print Strings and Text Render changes. Use this to ensure bindings and casts are correct.

Mnemonic: Test early, fix fast
