Module 3 › Chapter 3.1 › Input Actions & Mappings
Step-by-step
  1. Open Project Settings → Input and add an Action Mapping name, such as MyMoveForward.
  2. Assign a physical key or button, for example W for MyMoveForward and E for MyInteract.
  3. Save settings. In your Character Blueprint, add Input Action MyMoveForward and respond to its pins.
Pro tip

Use semantic action names so designers and players can remap keys without code changes.

Concrete example
MyMoveForward → W

Assign W to MyMoveForward. In the Blueprint, use the Pressed pin to start movement and Released to stop or print debug messages to validate.

Key Takeaway

Action Mappings decouple hardware from behavior so controls are flexible and maintainable.
