Module 3 › Chapter 3.1 › Key Concepts
Event-Driven Programming
Run logic when events occur, not by continuous polling.
Input Actions & Mappings
Abstract actions map to keys so players can remap controls safely.
Event Dispatchers
Broadcast events so multiple listeners can bind and respond without tight coupling.
Takeaway

Design interactions as event flows: map inputs semantically, use the correct input state, bind listeners at BeginPlay, and avoid heavy Tick use.
