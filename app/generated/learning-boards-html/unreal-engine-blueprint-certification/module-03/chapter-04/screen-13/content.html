Module 4 › Chapter 3.4 › Debugging Tips
Issue: Invisible Widget
Confirm Create Widget is followed by Add to Viewport and that the Event BeginPlay executes. Use Print String to verify execution.
Issue: Failed Casts
Open binding functions and check your Cast To node's target class. If the wrong controller class is used the binding will return defaults.
Issue: Stale UI
Keep game state in the controller. If widgets store values locally they can become out of sync when the controller changes state elsewhere.
Pro tip
Use small controller functions like IncrementScore so you can add logging inside controller code and isolate problems away from the widget.
