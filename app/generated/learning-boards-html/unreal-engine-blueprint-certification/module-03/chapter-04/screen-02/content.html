Overview

These objectives focus on practical skills: designing widgets, connecting them to runtime values, and triggering game actions from UI with clear separation between presentation and game state.

01 Create Widget Blueprints
Design a WBP for HUDs and menus, and learn why Widget Blueprints hold presentation and simple input handling.
VERIFIED COMPETENCY MILESTONE
02 Bind UI to Game Data
Use Bindings for Text and Percent so your UI reflects score, health, and other runtime values automatically.
VERIFIED COMPETENCY MILESTONE
03 Handle Button Events
Wire On Clicked to call controller functions or update simple UI state like incrementing score.
VERIFIED COMPETENCY MILESTONE
04 Display & Manage Widgets
Instantiate with Create Widget and make visible with Add to Viewport; remove with Remove from Parent when done.
VERIFIED COMPETENCY MILESTONE
