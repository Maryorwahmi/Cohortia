Binding examples
// Score binding pseudocode
Get Player Controller
Cast To ThirdPersonPlayerController
Get PlayerScore
Return Text("Score: "+ ToText(PlayerScore))

// Health percent binding
Get Player Controller
Cast To ThirdPersonPlayerController
Get PlayerHealth
Get PlayerMaxHealth
Return PlayerHealth / PlayerMaxHealth
Button event
In the widget's Event Graph use On Clicked to get the controller, cast, and then either call a controller function IncrementScore or set PlayerScore directly by adding 10. Prefer calling an explicit controller function for clarity and reuse.
Quick test

Play the level, click Add Score, and confirm the Score text updates; if not, verify the widget was added to the viewport and casts succeed.
