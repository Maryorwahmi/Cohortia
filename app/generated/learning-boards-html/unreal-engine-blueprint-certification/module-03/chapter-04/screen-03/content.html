Hands-on checklist
  • 1. Create WBP_PlayerHUD and add Canvas Panel.
  • 2. Add Text Block for Score and configure font size.
  • 3. Add Progress Bar for Health and set Fill Color to green.
  • 4. Add Button with child Text 'Add Score'.
  • 5. Save and return to Player Controller for Create Widget logic.
Testing steps
Play the level and confirm the HUD appears. Click Add Score to verify text increments. Change PlayerHealth and confirm the progress bar reflects the percent.
Common pitfall: creating a widget but forgetting to add it to the viewport makes it invisible.
Mnemonic
Think: Create Instance, Add to Viewport, Bind Properties, Handle Events — C A B H.
Why separate logic?
Keep complex game state changes in controller or game mode, and let widgets focus on inputs and display. This keeps Blueprints maintainable and reusable.
