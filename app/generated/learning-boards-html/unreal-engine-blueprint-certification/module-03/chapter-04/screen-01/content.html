Basic UI Elements and Player Feedback

Build a responsive HUD using UMG, connect it to your game variables, and add simple button interactions that affect gameplay.

UMG Preview
In this lesson

Create a Widget Blueprint, add Text, Progress Bar, and Button widgets, display the HUD with Create Widget and Add to Viewport, and bind values to variables.

Why it matters

Clear, reactive UI gives players immediate feedback on health, score, and actions, which improves usability and perceived responsiveness of your game.

Explore Key Topics
Designing Widgets
Place and style Text Blocks, Progress Bars and Buttons in the Designer tab to create a readable HUD layout.
Displaying UI
Use Create Widget and Add to Viewport in a controller or Game Mode to show widgets at runtime.
Dynamic Updates
Bind widget properties to game variables so the HUD updates automatically as the game state changes.
