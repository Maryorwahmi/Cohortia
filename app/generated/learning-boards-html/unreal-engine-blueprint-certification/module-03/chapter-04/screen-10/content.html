Module 4 › Chapter 3.4 › Create WBP_PlayerHUD
Designer actions
  1. Create Widget Blueprint → WBP_PlayerHUD.
  2. Confirm Canvas Panel root is present.
  3. Drag Text Block, set text to 'Score: 0', anchor top-left.
  4. Add Progress Bar, set Fill Color to green, position below score.
  5. Add Button, add child Text 'Add Score', style for contrast.
Layout notes
Use anchors to lock UI to corners and check scale with different safe-zone settings. Avoid placing critical info at the absolute edges where it can be cropped on some displays.
Quick test
Open the Designer viewport size selector and check small, medium, and large resolutions to confirm element positions and text legibility.
Key Takeaway

Careful anchors and readable fonts make a HUD usable across resolutions; the visual design should support immediate comprehension.
