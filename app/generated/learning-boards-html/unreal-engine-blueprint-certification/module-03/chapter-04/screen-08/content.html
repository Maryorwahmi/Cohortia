How to bind
  1. Select the widget (Text Block or Progress Bar).
  2. In Details, click Bind next to Text or Percent and choose Create Binding.
  3. In the binding function, get Player Controller, cast to your controller class, access PlayerScore or PlayerHealth.
  4. Return the proper type: Text for Text Block, float 0-1 for Percent.
Key Tip

For percent bindings divide current by max to produce a 0-1 value, and convert numbers to text for display bindings.

Binding example
// Pseudocode for a binding function in the widget
Get Player Controller
Cast to ThirdPersonPlayerController
Get PlayerHealth
Get PlayerMaxHealth
Return PlayerHealth / PlayerMaxHealth  // float 0-1 for Percent
This function is attached to the Progress Bar's Percent property and ensures the bar reflects the controller's health values automatically.
Misconception

Avoid writing manual Event Tick updates for UI properties; use bindings to keep logic focused and efficient.
