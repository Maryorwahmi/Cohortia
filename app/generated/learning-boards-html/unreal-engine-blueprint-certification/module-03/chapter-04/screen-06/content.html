Widgets at a glance
Text Block
Displays text. Bind Text to PlayerScore and prepend 'Score: ' when returning the string from the binding function.
Image
Shows a texture or icon. Use for life icons, ability images, or HUD decoration.
Progress Bar
Shows percentage. Bind Percent to a division result like PlayerHealth / PlayerMaxHealth for automatic updates.
Button
Clickable widget. Use On Clicked to call controller functions or send events; avoid heavy logic inside the widget.
Example combination
WBP_PlayerHUD components
Top-left: Text Block "Score: 0". Below it: green Progress Bar with Percent bound to PlayerHealth / PlayerMaxHealth. Somewhere visible: Button 'Add Score' that increments score via controller.
Key Takeaway

Combine these widgets to give clear numeric and visual feedback; use bindings to keep them synchronized with game state.
