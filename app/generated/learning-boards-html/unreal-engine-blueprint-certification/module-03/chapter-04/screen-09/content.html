On Clicked flow
// In WBP_PlayerHUD Event Graph
OnClicked (AddScoreButton)
→ Get Player Controller
→ Cast To ThirdPersonPlayerController
→ Call IncrementScore(Amount = 10)
IncrementScore is a controller function that updates PlayerScore and keeps game state centralized.
Testing & Common mistakes
  • Ensure the cast to your controller succeeds; otherwise the function call will fail.
  • Do not place heavy gameplay logic inside the widget's Event Graph.
  • Verify the binding updates the visible text after the controller changes the value.
Pro tip

Name your controller functions with clear verbs like IncrementScore so the widget calls read clearly in the Event Graph.
