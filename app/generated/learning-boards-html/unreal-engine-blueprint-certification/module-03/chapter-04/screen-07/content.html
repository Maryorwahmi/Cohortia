Module 4 › Chapter 3.4 › Create & Display
Node sequence
Event BeginPlay
→ Create Widget (Class = WBP_PlayerHUD)
→ Promote Return Value to variable PlayerHUDRef
→ Add to Viewport (Target = PlayerHUDRef)
Store the widget reference if you need to call functions on it or remove it later with Remove from Parent.
Pitfall

If Add to Viewport is omitted, the widget will be instantiated but never visible.

Example scenario
In your Player Controller, on BeginPlay create WBP_PlayerHUD, save the returned reference to PlayerHUDRef, and call Add to Viewport. Later you can call Remove from Parent on PlayerHUDRef when the HUD is no longer needed, for example on level end.
Key Takeaway

Always pair Create Widget with Add to Viewport and keep a reference to the widget if you will update or remove it later.
