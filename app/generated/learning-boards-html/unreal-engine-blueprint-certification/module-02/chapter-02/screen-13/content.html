Module 2 › Chapter 2.2 › Loop Comparison
For Loop
Best for fixed repeat counts and when you need the Index to position or configure instances.
For Each Loop
Best for iterating arrays directly, readable access to each element and its index.
While Loop
Best for condition-driven repetition. Always include Delay or limits to prevent infinite loops.
Decision Table
  • Spawn N objects by index → For Loop.
  • Process each inventory item → For Each Loop.
  • Run repeated checks every few seconds while condition true → While Loop with Delay.
Key Takeaway

Match loop type to intent. Use Delay and limits to keep While loops safe and predictable in the game loop.
