Module 2 › Chapter 2.2 › Sequence Node
Core Concept

Start multiple actions cleanly

Sequence helps you fire several independent execution paths from a single entry, keeping graphs tidy and intentional.

When to use
Trigger UI updates, sounds, and inventory changes together when an item is picked up or an event occurs.
Misconception
Sequence is not a timing primitive. If you need precise sequencing over time, add Delay or chain actions explicitly.
Example
Item pickup actions
Sequence Then 0: Update UI. Then 1: Play sound. Then 2: Add to inventory. Then 3: Update quest log.
Key Takeaway

Use Sequence to reduce wiring complexity and show related actions clearly from one trigger.
