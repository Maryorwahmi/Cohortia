Module 2 › Chapter 2.2 › Checker — For Each + Branch
Task

Iterate spawned cubes and detect overlaps

Use For Each on SpawnedCubes, call Get Overlapping Actors for each element, test Length > 0 with Branch, then react on True.

Reaction pattern
Print overlapping cube name and disable its collision to avoid duplicate messages.
Walkthrough
For Each (SpawnedCubes)
  Overlapping = Get Overlapping Actors(Array Element)
  If (Length(Overlapping) > 0)
    Branch True:
      Print String("Cube Overlapping: " + Array Element Name)
      Set Actor Enable Collision(Array Element, No Collision)
// Completed: done
Debug Tip

Use Print String liberally while testing to confirm element names and branch results, then remove or switch to logging once stable.
