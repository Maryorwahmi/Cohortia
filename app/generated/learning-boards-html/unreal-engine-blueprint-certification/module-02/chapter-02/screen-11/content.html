Task

Spawn 5 cubes and store them

Use Event BeginPlay → For Loop (0 to 4) → Spawn Actor From Class. Connect Index to Make Vector X multiplied by 200.

Checklist
  • First Index = 0, Last Index = 4
  • Multiply Index by 200 for spacing
  • Add returned actor to SpawnedCubes array with Add Unique
Code Walkthrough
Event BeginPlay
ForLoop(FirstIndex=0, LastIndex=4)
  Location.X = Index * 200.0
  Spawned = Spawn Actor From Class(ActorClass=Cube, Transform=MakeTransform(Location))
  Add Unique(SpawnedCubes, Spawned)
