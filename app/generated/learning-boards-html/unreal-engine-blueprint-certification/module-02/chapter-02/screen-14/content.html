Module 2 › Chapter 2.2 › Key Concepts
Branch Node
Executes one of two paths based on a Boolean condition.
For Loop
Iterates a fixed range using a First and Last Index; exposes Index each iteration.
For Each Loop
Processes each element in an array and provides the element and index.
While Loop
Repeats while a condition is true; requires Delay or limits to avoid infinite loops.
Sequence
Fires multiple independent execution paths in order from one event trigger.
Delay
Pauses execution for a duration; useful inside While loops to yield engine time and avoid blocking.
Summary
Match node to intent: Branch for decisions, For/For Each for repetition, While with Delay for conditional checks over time, Sequence to organize multiple starts. Test often and guard loops.
