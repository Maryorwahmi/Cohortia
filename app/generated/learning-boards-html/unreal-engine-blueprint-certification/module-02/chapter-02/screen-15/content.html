Guard loops
Always add Delay or limits to While loops to ensure exit and frame responsiveness.
Separate concerns
Collect data in loops; apply UI and side effects after Completed or via Sequence for consistent state.
Test with logs
Use Print String to observe execution paths and values while iterating or branching; remove or adjust later.
Final Takeaway
Small, safe patterns scale better than clever shortcuts. Use clear conditionals, guarded loops, and orderly sequences to build reliable game mechanics.
