Branch

If-Else decisions with Booleans

Use Branch whenever execution should follow one of two paths based on a true/false test.

Good practice
Name your Boolean variables clearly and avoid deep nested branches. Prefer combining checks with logical operators or functions for clarity.
Common mistake
Forgetting to wire both True and False pins when both sides require actions leads to silent bugs.
Concrete Example
Check player death
// Pseudocode representing the Branch test
if (PlayerHealth <= 0)
{
  Trigger PlayerDied event;
}
else
{
  Continue gameplay;
}
Key Takeaway

Use Branch for clear yes/no decisions and always verify both outcomes during testing.
