Module 2 › Chapter 2.2 › While Loop
Definition & Risk

Conditional repetition with careful guarding

While repeats while a Boolean stays true. Use Delay or iteration limits to avoid infinite loops.

Safe patterns
Place a Delay in Loop Body or pair While with Do N or an explicit counter to ensure exit.
Warning
A While loop without Delay can become an infinite loop and block the editor or game thread.
Concrete Example
Damage zone check every 3 seconds
// While Loop pattern
While (IsPlayerAlive)
{
  Delay(3.0)
  If (IsPlayerOnDamageZone)
    ApplyDamage(10)
}
Pro Tip

Prefer a Delay inside the loop for repeated timed checks. Use clear exit conditions and test with a debug toggle switch.
