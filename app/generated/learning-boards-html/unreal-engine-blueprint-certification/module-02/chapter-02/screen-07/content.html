Module 2 › Chapter 2.2 › For Each Loop
Definition

Iterate arrays element by element

Use For Each to apply the same operation to every element in an array, receiving the element and index each time.

Typical use
Process inventory, update actors, or check properties across a list of objects.
Pitfall
Mutating the same array during iteration can skip elements or corrupt order. Collect changes and apply after the loop when needed.
Concrete Example
Check each spawned cube for overlaps
For Each (SpawnedCubes as Array)
  Overlapping = Get Overlapping Actors(Array Element)
  Length = Length(Overlapping)
  If (Length > 0)
    Branch True: Print "Cube Overlapping: " + Array Element Name
    Set Actor Enable Collision(Array Element, No Collision)
// Completed: continue
Key Takeaway

Use For Each to make array processing explicit and readable; avoid modifying the array while iterating.
