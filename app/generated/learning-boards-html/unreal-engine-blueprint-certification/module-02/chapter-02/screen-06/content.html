Module 2 › Chapter 2.2 › For Loop
Process

Spawn by count and use Index

Set First Index and Last Index, use Index for positioning, store Return Value to an array, and use Completed for continuation.

Practical pattern
First Index: 0. Last Index: 4. Loop Body: Spawn Actor; Add to SpawnedCubes. Completed: Start checks.
Misuse
Treating Index as time or frame count leads to logic errors. Index is iteration ordinal only.
Concrete Spawn Example
Spawn 5 cubes spaced by Index
// Blueprint pseudocode for spawn placement
FirstIndex = 0
LastIndex = 4
ForLoop(FirstIndex, LastIndex)
  // Loop Body
  Location.X = Index * 200.0
  SpawnedActor = Spawn Actor From Class(Cube, MakeTransform(Location))
  Add Unique(SpawnedCubes, SpawnedActor)
// Completed: Continue
Key Takeaway

Use Index to space or configure each spawned instance and store references for later iteration.
