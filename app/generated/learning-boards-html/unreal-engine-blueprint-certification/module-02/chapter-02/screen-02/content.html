Mnemonic
Think D-R-S: Decide (Branch), Repeat (For / For Each / While), Sequence (order multiple starts). Use Delay to breathe between repeats.
Key Takeaway

Focus on correctness first, then readability. Safe loops and clear sequences prevent bugs and frame drops.
