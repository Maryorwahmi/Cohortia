Arithmetic operators
Add (+): increase values like score
Subtract (-): reduce values like health
Multiply (*): scale modifiers
Divide (/): compute ratios
Example
// On coin pickup
Get iPlayerScore
Add 10
Set iPlayerScore

// On damage
Get fPlayerHealth
Subtract DamageAmount
Set fPlayerHealth
If fPlayerHealth <= 0.0 -> Set bIsPlayerDead = true
Comparison operators

Output Booleans you can use to route flow with Branch nodes. Use Less Equal or Greater Equal for thresholds like death checks.

Precision caution

Assigning a Float to an Integer truncates decimals. Comparing floats for equality can be unstable; prefer tolerance checks if exact equality matters.

Key Takeaway

Choose numeric types by whether fractional precision matters, and watch conversions when assigning results between types.
