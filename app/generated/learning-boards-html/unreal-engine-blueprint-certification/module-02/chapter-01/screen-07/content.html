Module 2 › Chapter 2.1 › Get and Set Nodes
Definition

Get outputs the current value; Set assigns a new value and requires execution wiring. Sets change state at the moment their execution pin runs.

Example sequence
// Event: TakeDamage(DamageAmount: Float)
Get CurrentHealth
Subtract DamageAmount
Set CurrentHealth
Min with 0.0
Set CurrentHealth
If CurrentHealth <= 0.0 -> Set bIsPlayerDead = true
Note: The second Set after Min ensures health never becomes negative.
Order matters

Wiring execution pins determines sequencing. A misplaced Set can overwrite the intended value or run before a check completes.

Common mistake

Using multiple Gets and Sets without clear execution ordering can lead to race-like behavior in graphs. Structure the flow so each assignment is intentional.

Key Takeaway

Use Get to read, Set to write, and order Sets explicitly with execution wires to avoid unexpected values.
