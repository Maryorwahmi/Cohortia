Module 2 › Chapter 2.1 › Key Concepts — Part 1
Variable

A named storage slot in a Blueprint that holds a single value during gameplay. Initialize to prevent unpredictable state.

Data Type

Defines what values a variable can store: Boolean, Integer, Float, String, Vector, Rotator, Transform, and Object Reference are common types in Blueprints.

Type Casting

Convert a generic object reference to a specific class type before accessing class-specific properties. Always check the cast’s success branch.

Summary Takeaway

Master these concepts to create predictable state, avoid type errors, and wire robust gameplay logic in Blueprints.
