Module 2 › Chapter 2.1 › Common Data Types
Numeric types
Integer (i)
Whole numbers for counts and indexes. Example: iPlayerScore = 10.
Float (f)
Decimal-capable numbers for health, speed. Example: fPlayerHealth = 87.5.
Logical and text
Boolean (b)
True/false flags. Example: bIsPlayerDead = false.
String
Text values. Example: PlayerName = "Ava".
Spatial types
Vector
X,Y,Z position or direction
Rotator
Pitch,Yaw,Roll rotation
Transform
Location, rotation, and scale bundle
Object Reference

References point to actor or widget instances so you can call functions or access properties on that instance. Example: store a reference to the player character to modify its health after a hit.

Important: Cast a generic Actor reference to a specific class before accessing class-specific properties.
Concrete scenario

Store SpawnPoint as a Vector, store SpawnedEnemy as an Object Reference. Use the Object Reference to read or set the enemy's transform.

Misconception

Implicit conversions can mask precision loss. For counts prefer Integer, for fractional values prefer Float to avoid truncation.

Key Takeaway

Map a type to the real-world nature of the data: toggle, count, measurement, text, position, orientation, or object instance.
