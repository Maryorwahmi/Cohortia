Module 2 › Chapter 2.1 › What is a Variable?
Core definition

A named container in a Blueprint that stores a single value of a declared data type. It represents state you can read or change during gameplay.

Analogy

Like boxes in a toolbox: each box has a label and holds a specific kind of item. Putting the wrong item causes problems when you expect a certain tool.

Common misconception

Variables are not global unless placed in a global object. Actor variables belong to each actor instance and maintain separate values per instance.

Key Takeaway

Variables model state. Name them clearly, set a default, and pick a type that matches intended usage.

Concrete example
// Blueprint sequence described as pseudocode for clarity
Event BeginPlay
  Set fPlayerHealth = 100.0
  Set iPlayerScore = 0
EndEvent

// Later, on coin pickup
Get iPlayerScore
Add 10
Set iPlayerScore
Why this matters

Choosing correct types preserves precision, prevents compile errors, and communicates intent to other developers and designers.
