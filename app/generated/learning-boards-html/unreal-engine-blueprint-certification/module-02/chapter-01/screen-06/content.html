Module 2 › Chapter 2.1 › Creating & Initializing
Step-by-step
  1. Add variable in My Blueprint and enter a descriptive name.
  2. Select its data type from the type dropdown.
  3. Open Details panel and set a sensible default value.
  4. Optionally mark Instance Editable or Expose on Spawn as needed.
Example naming: fPlayerHealth, iCoins, bHasKey.
Why initialize?

Initialization ensures predictable starting values and avoids logic that depends on garbage or default-zero behavior.

Concrete example
// My Blueprint
Variable: CurrentHealth : Float
Default: 100.0
InstanceEditable: true

// Behavior
When spawned, CurrentHealth is 100.0 unless overridden in level details
Designer workflow

A designer places an actor and edits the CurrentHealth in the Details panel to create easy difficulty variations without editing graphs.

Key Takeaway

Defaults and instance flags make variables predictable and reusable across many actor instances.
