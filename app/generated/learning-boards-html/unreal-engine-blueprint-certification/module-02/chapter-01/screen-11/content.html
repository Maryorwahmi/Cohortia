Module 2 › Chapter 2.1 › Player Health Walkthrough
Step sequence
// BP_PlayerHealthSystem setup
Variables:
  CurrentHealth : Float = 100.0 (Instance Editable)
  IsDead : Bool = false

// Event Graph
Custom Event: TakeDamage(DamageAmount: Float)
  Get CurrentHealth
  Subtract (CurrentHealth - DamageAmount)
  Set CurrentHealth (result)
  Min(CurrentHealth, 0.0)
  Set CurrentHealth (clamped)
  Get CurrentHealth
  LessEqual(0.0)
  Branch
    True -> Set IsDead = true
    False -> (no action)
  // Optional: Print String "Player is Dead!" on True
Testing: Place BP_PlayerHealthSystem in level and call TakeDamage from Level Blueprint or a key event to simulate hits.
Concrete checks
  • Confirm default CurrentHealth appears in Details.
  • Trigger TakeDamage multiple times and watch health decrement.
  • Verify IsDead becomes true when health reaches zero.
Common pitfall

Forgetting the clamping step can cause negative health values and unexpected branching; always clamp to prevent invalid states.

Key Takeaway

This small system ties together variables, Get/Set, arithmetic, comparisons, and branching into a reliable gameplay behavior pattern.
