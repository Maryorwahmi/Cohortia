Module 2 › Chapter 2.1 › Learning Objectives
01
Differentiate Variable Types

Recognize Booleans, Integers, Floats, Strings, Vectors, Rotators and Object References, and select the type that matches the value's usage in gameplay.

Mnemonic: b for boolean, i for int, f for float — prefixing helps readability.

02
Declare & Initialize Variables

Add variables in the My Blueprint panel, choose types, set default values, and optionally mark instance editable or expose on spawn to control how designers set values.

Visual: My Blueprint panel list with defaults visible in Details.
VERIFIED COMPETENCY MILESTONE
03
Use Get and Set Nodes

Drag variables into the Event Graph as Get to read values or Set to assign new values. Set nodes have execution pins; Get nodes only output data pins.

Tip: Use descriptive names like fHealth, iScore, bIsAlive for clarity.
VERIFIED COMPETENCY MILESTONE
04
Apply Operators & Avoid Cast Errors

Perform arithmetic, comparison, and logical operations. Be aware of type mismatches and use explicit casting for object references when necessary.

Contrast: Implicit conversions exist, but explicit casts avoid ambiguous behavior when accessing object-specific properties.
