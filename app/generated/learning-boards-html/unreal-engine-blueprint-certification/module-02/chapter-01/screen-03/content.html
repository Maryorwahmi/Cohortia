Naming & Initialization

Use prefixes like b, i, f to show type intent. Always set a sensible default in the Details panel to avoid uninitialized behavior at runtime.

Example: fPlayerHealth default 100.0.
Try this
Create CurrentHealth as Float and set default to 100.0. Observe the default in the Details panel when the actor is selected.
Instance Editable & Expose on Spawn

Mark variables to be configurable per instance or for assignment when spawning an actor. This keeps graphs generic but tunable by designers.

Scenario: Spawned enemy with variable SpawnHealth exposed on spawn so each spawn can vary.
Testable Sequences

Build small graphs: Get score, Add constant, Set score, Print String. Run and verify values in the Output Log to confirm expected changes.

Diagnose Type Errors

Try an invalid operation such as adding a String to an Integer. Read the compile error to identify which node and pins caused the mismatch.
