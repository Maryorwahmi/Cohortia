What is an Object Reference?

A variable that stores a pointer to an instance of an actor, component, or widget so you can later call its functions or read its variables.

Casting pattern
// Example flow
Get Actor of Class (PlayerCharacter)
Store as Actor reference
Cast to PlayerCharacter
If cast success -> access fPlayerHealth or Call PlayerFunction
If cast fail -> handle safely
Concrete example

You store a reference to an object found in the level. Cast it to the specific class to access unique variables like fPlayerHealth. If you skip the cast, class-specific pins won’t be available.

Common mistake

Assuming casts always succeed can crash logic paths. Always use the cast's success branch before proceeding to use typed properties or functions.

Key Takeaway

Use Object References to connect actors, cast to access specific members, and handle failures to keep graphs robust.
