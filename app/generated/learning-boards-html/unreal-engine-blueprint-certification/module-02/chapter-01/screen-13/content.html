Get Node

Retrieves the current value of a variable. Use it when you need to read state without changing it.

Set Node

Assigns a new value to a variable and has an execution pin. Wire its execution to control when the write happens.

Operators

Arithmetic and logical nodes compute values and Booleans. Ensure operand types are compatible to avoid compile errors or precision loss.

Final takeaway

Practice small, testable graphs that Get, update with operators, and Set variables. Initialize defaults, name clearly, and cast safely to build reliable Blueprints.
