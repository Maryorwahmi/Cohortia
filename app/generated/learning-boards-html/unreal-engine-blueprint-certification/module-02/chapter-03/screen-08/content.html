Definition
Structs: designing custom records
Structs bundle different typed fields into a single named variable, ideal for items, stats, and quest data.
F_ItemData example
ItemID (Name), ItemName (String), ItemDescription (Text), ItemWeight (Float), ItemIcon (Texture2D).
Make and Break
Use Make to construct a Struct before Add; use Break when iterating to access fields for UI or logging.
Key Takeaway

Structs reduce parameter clutter and make passing complex items between functions clear and type-safe.

Practical pattern
Create an Array of F_ItemData to represent inventory. Use Make when adding new items and Break inside For Each Loop to display fields in UI.
Misconception check
Structs do not eliminate the need to access fields—they are a convenience that groups fields but you still Break to read or wire them into widgets.
