Arrays: creation and core operations
Create an Array variable by selecting a base type and toggling the grid icon. Then use built-in nodes to manipulate elements safely.
Example usage
Array of Actors for active enemies: Add on spawn, Remove Index on death, For Each Loop for status updates.
Common pitfall
Zero-based indexing: last index is Length minus one. Verify index bounds before Get or Set to avoid errors.
Key Takeaway

Test array operations by printing Length and element values during runtime to confirm expected behavior.
