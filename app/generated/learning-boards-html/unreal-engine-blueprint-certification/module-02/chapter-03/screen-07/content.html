Definition
Maps: key-value storage and safe lookups
Use Maps when you need to retrieve data by a unique identifier quickly and without iteration.
Concrete example
Map for configuration where "Volume" → 0.75, "Brightness" → 1.0.
Common mistake
Assuming Find always yields a valid value. Always check Found to avoid default-value bugs.
Useful nodes
Add, Find (+Found), Remove, Contains Key, Get Keys, Get Values.
Practical note
If you need to display entries in a specific order, extract keys into an Array and sort them, or use an Array of Structs instead of a Map. Maps excel when order is irrelevant but lookup speed is important.
Check this
When reading a Map, always branch on the Found boolean from Find before using the returned value to prevent applying default fallbacks unintentionally.
Key Takeaway

Maps are for keyed lookups—guard the Find node's Found flag and maintain order separately when needed.
