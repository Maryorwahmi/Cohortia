Process Flow
Iterating Arrays safely
Use For Each Loop to read elements and indexes. When removing, avoid altering the same array in a forward iteration.
Example: Display inventory
For Each Loop over Inventory Array of F_ItemData, Break Struct, and print ItemName and ItemWeight to debug output.
Removal pattern
Collect indices to remove in a temp array, then remove them after looping, or loop backwards when removing by index.
Check your understanding
If you remove index 2 while iterating forward over five items, what happens to the next element? Removing shifts later elements down, so the next element may be skipped or misindexed unless handled explicitly.
Pro tip
Use For Each Loop when you only need values and not positions. Use indexed loops when you must remove or reorder elements safely.
