Choosing between Array, Map, and Struct
Array
Ordered collections. Best when order matters or you iterate frequently. Example: leaderboards or spawn lists.
Map
Key-value lookup for quick retrieval by unique ID. Example: settings map keyed by name. Check Found after Find.
Struct
Grouped fields of different types. Example: F_ItemData for inventory items.
Hybrid examples: Array of Structs for ordered inventories, Map of Structs for a lookup table of unique item definitions. Ask yourself: do I access by position, by identifier, or as a whole record?
Key Takeaway

Design systems by access pattern: index → Array, key → Map, grouped fields → Struct. Combine them when needed.
