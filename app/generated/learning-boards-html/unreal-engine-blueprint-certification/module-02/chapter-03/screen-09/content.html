Hands-on Activity
Build a simple inventory: step-by-step
Follow these precise steps in your project to create a working inventory using an Array of Structs.
Step 1 — Create Struct
F_ItemData with ItemID, ItemName, ItemDescription, ItemWeight, ItemIcon.
Step 2 — Inventory variable
BP_InventoryManager: PlayerInventory of type F_ItemData set as Array.
Step 3 — AddItemToInventory
Custom Event AddItemToInventory(ItemToAdd: F_ItemData) → Add to PlayerInventory → Print "Added: " + ItemName.
Continue: Display and Remove
Implement DisplayInventory with For Each Loop and Break to print Name and Weight. Implement RemoveItemFromInventory by comparing ItemID and calling Remove Index, followed by Return to exit the loop once removed.
Test sequence
Spawn BP_InventoryManager, call AddItemToInventory several times at BeginPlay using Make F_ItemData, call DisplayInventory, remove an ItemID, and call DisplayInventory again to confirm removal.
