Architecture
Common patterns and pitfalls at scale
Array of Structs
Ordered inventory where each element is a full item record. Use Set Array Elem when mutating an element and bounds-check indices.
Map of Structs
Registry of item templates keyed by ID for fast lookups; maintain separate ordering if display order matters.
Mutation pitfalls
Avoid removing elements while iterating forward; check Found on Map Find; use Return after removing to exit loops when appropriate.
Key Takeaway

Mix structures to match both storage and access needs, and always protect mutations with checks and safe removal patterns.
