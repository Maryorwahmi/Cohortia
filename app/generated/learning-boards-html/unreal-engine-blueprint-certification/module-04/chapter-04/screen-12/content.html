Module 5 › Chapter 4.4 › Assessment & Best Practices
Assessment question
Implement a main menu with Quit. Which node closes the game and what safety step must you add? Answer: use Quit Game node and implement a confirmation dialog before executing it.
Inventory design check
Use a Vertical Box or Scroll Box and create a WB_InventoryItemSlot widget for each entry to keep the list modular and reusable.
Best practices
  • Keep UI logic thin and delegate state changes to authoritative Blueprints.
  • Always preview multiple resolutions and avoid fixed pixel placements.
  • Reset input mode and cursor when closing UI-heavy screens.
Closing thought
Good UI is modular, responsive, and communicates with game logic cleanly. Use bindings and anchors to reduce bugs, and always design for real gameplay flows and edge cases.
