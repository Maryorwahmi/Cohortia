Module 5 › Chapter 4.4 › Anchors & Responsive Workflow
Step-by-step
  1. 1. Select the panel type (Canvas for HUDs).
  2. 2. Set the child widget's Anchor (e.g., Top Left for health).
  3. 3. Adjust offsets and size to match your design.
  4. 4. Preview multiple resolutions with Fill Screen and iterate.
Concrete example
Anchor a ProgressBar to Top Left, set Size X 300, Size Y 30. Bind Percent to GetHealthPercentage so the UI shows live health changes without manual updates.
Visual checklist
  • Are critical elements anchored to screen edges?
  • Do offsets behave predictably when anchors change?
  • Have you previewed several resolutions?
Misconception check
Anchors do not automatically resize children. Use layout containers or percentage-based logic to scale sizes.
Try now
Open WB_PlayerHUD, anchor the health bar to the top-left and preview at two resolutions. Observe how offsets change meaning and adjust accordingly.
