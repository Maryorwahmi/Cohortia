Module 5 › Chapter 4.4 › Key Concepts
UMG & Widgets
Widgets are UI elements; User Widget Blueprints combine layout with logic.
Panels & Anchors
Use Canvas for anchored HUDs, Boxes/Grids for flow and lists; anchors keep layouts responsive.
Bindings & Input Mode
Bind UI to simple functions for automatic updates; switch input modes and cursor visibility when opening and closing UI.
Summary
Design modular widgets, use anchors for responsiveness, bind to lightweight functions, and manage input transitions to create stable in-game UIs.
