Module 5 › Chapter 4.4 › Common UI Patterns
Main Menu
Use Vertical Box for stacked buttons. On Start: Remove From Parent, Create Widget for HUD, Add To Viewport, and set input mode back to Game Only.
HUD
Canvas Panel with anchored ProgressBars and TextBlocks. Bind display values to player functions for automatic updates.
Inventory
Use Scroll Box + Uniform Grid or Wrap Box. Each slot is a reusable User Widget with Image and quantity TextBlock.
Communication patterns
Use Blueprint Interfaces or Event Dispatchers to send actions from UI widgets to the player character or game mode, keeping UI layers decoupled from game logic implementation.
Key Takeaway
Structure UIs as modular components and choose panels based on layout needs. Keep UI logic thin and communicate with game Blueprints for authoritative state changes.
