Panel comparison
Canvas Panel
Free-form positioning with anchors; ideal for HUD corners and precise placement.
Vertical / Horizontal Box
Automatic stacking for menus and lists with predictable flow.
Grid Panel
Table-like layout for item slots and even spacing.
Common mistake
Using fixed pixel positions without anchors causes UI to break at different screen sizes. Always test multiple resolutions.
Key takeaway
Choose the panel that matches content flow and use anchors for responsiveness.
Concrete example
Place a ProgressBar in a Canvas Panel. Set its Anchor to Top Left, Size X 300, Size Y 30, then bind Percent to a GetHealthPercentage function on the player character. Preview at 720p and 1080p to confirm positioning.
Design mnemonic
Think: Canvas = corners, Boxes = flow, Grid = table.
Try this
In the Designer, switch the Canvas child's Anchor between Top Left and Center and watch how offset values behave — this reveals how anchors define layout relative points.
