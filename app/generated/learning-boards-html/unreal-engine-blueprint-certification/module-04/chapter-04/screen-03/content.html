Practical Habits
  • Modular widgets speed iteration and reuse across menus and inventory screens.
  • Anchors keep HUD elements stable on any resolution.
  • Bindings reduce manual update code for common properties like health and score.
  • Always restore input mode to avoid leaving the player with UI-only controls.
Hands-on milestones
Build WB_PlayerHUD, add bindings for health and score, and implement a Main Menu that toggles input modes and shows confirmation dialogs for Quit.
Common pitfall
Using fixed pixel positions without anchors. This often breaks your layout on different devices. Always preview the UI in multiple resolutions with the Fill Screen dropdown.
