// BP_PlayerCharacter variables
Float CurrentHealth = 100.0
Float MaxHealth = 100.0
Integer PlayerScore = 0

// GetHealthPercentage()
Return CurrentHealth / MaxHealth

// GetScoreText()
Return "Score: " + ToString(PlayerScore)
These functions are intentionally simple. Bind the ProgressBar.Percent to GetHealthPercentage and the TextBlock.Text to GetScoreText to keep UI synced automatically.
