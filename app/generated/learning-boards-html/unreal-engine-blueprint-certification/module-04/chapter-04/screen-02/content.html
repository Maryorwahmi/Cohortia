Understand UMG fundamentals
Learn that widgets are Blueprint assets with Designer and Graph. This knowledge helps you design and script UI behavior without raw code.
VERIFIED COMPETENCY MILESTONE
02
Design responsive layouts
Use Panel Widgets and Anchors to create UIs that scale across resolutions. Avoid fixed-pixel placement without anchors to prevent layout breakage.
VERIFIED COMPETENCY MILESTONE
03
Implement data binding
Bind properties like Text or Percent to functions or variables so UI elements update automatically when game state changes.
VERIFIED COMPETENCY MILESTONE
04
Handle UI input & widget events
Use events like OnClicked and set the Player Controller's input mode so players can interact with menus and HUD elements reliably.
