Module 5 › Chapter 4.4 › UMG & User Widget Blueprint
Definition
UMG is the visual UI editor. User Widget Blueprints pair the Designer for layout and the Graph for logic. Widgets inside them behave like variables and functions in any Blueprint.
Widgets
Button • TextBlock • ProgressBar • Image
User Widget Blueprint
Contains Designer layout and Graph bindings/events to the game state.
Example
A WB_PlayerHUD user widget has a ProgressBar (health) and a TextBlock (score) whose properties are bound to functions on the player character.
Starter layout (Designer Tab)
[Canvas Panel]
    [ProgressBar] (Anchor: Top Left, Position: 0,0, Size: 300,30, Percent: Bound to GetHealthPercentage)
    [TextBlock] (Anchor: Top Right, Position: -10,0, Size: Auto, Text: Bound to GetScoreText)
Quick tip
Treat User Widget Blueprints as reusable components. If an inventory slot repeats, make that slot its own User Widget and Create Widget for each item instance.
Key Takeaway

UMG widgets are Blueprints. Use Designer for layout and Graph for behavior so UI can react to game state without manual per-frame updates.
