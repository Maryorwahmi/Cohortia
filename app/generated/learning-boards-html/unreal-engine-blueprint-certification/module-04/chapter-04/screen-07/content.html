How bindings work
Create a binding from a widget property to a function. The binding runs and the return value is used for the property value.
Example binding flow
// GetHealthPercentage_Binding (WB_PlayerHUD)
Get Player Character
Cast To BP_PlayerCharacter
Call GetHealthPercentage on the casted reference
Return the percentage value
Binding tips
  • Keep binding functions simple to avoid unnecessary work during UI updates.
  • Verify casts and null references when a binding returns nothing.
  • Use bindings for Percent, Text, Visibility, and color where appropriate.
Concrete wiring
Inside WB_PlayerHUD, select ProgressBar>Percent > Bind > Create Binding. In the new binding Graph, Get Player Character, Cast To BP_PlayerCharacter, call GetHealthPercentage, and wire it to the Return Node.
Debugging
If a binding returns no data, first confirm the Get Player Character result, then check the cast and the called function. Bindings rely on valid references.
Key Takeaway
Use bindings to reduce manual update logic. Keep bound functions lightweight and verify references when troubleshooting.
