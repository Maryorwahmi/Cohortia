Module 5 › Chapter 4.4 › Input & Widget Events
Widget events you'll use
  • OnClicked — respond to button presses.
  • OnHovered / OnUnhovered — show hover states or tooltips.
  • OnValueChanged — respond to sliders and numeric inputs.
Player Controller input modes
Set Input Mode: UI Only, Game And UI, or Game Only. Show or hide mouse cursor with Show Mouse Cursor.
Example flow
Start Game button OnClicked: call GameMode StartGame, Remove From Parent on Main Menu widget, Create Widget for HUD, Add To Viewport, then Set Input Mode to Game Only and hide cursor.
Checklist before shipping
  • Ensure you reset input mode when a menu closes.
  • Confirm the cursor visibility state matches the current input mode.
  • Use confirmation dialogs for destructive actions like Quit Game.
Key Takeaway
Wire widget events for interaction and manage Player Controller input modes so the player always has appropriate control context.
