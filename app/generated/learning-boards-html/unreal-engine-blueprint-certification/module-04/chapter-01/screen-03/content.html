Practical checks and common fixes
  • Confirm Trace Channel: ensure walls block your chosen channel so traces don't hit through geometry.
  • Choose Trace Type: use Line Trace for precise UI-like interactions; use Sphere Trace for broader detection cones.
  • Timeline Pattern: Play From Start → Delay on Finished → Reverse From End to close cleanly.
  • Context Switching: Add/Remove Input Mapping Contexts to swap controls when changing modes.
  • Debugging: enable Draw Debug Type during testing and add print/log messages for hit results.
Quick mnemonic
Think: Contexts, Traces, Timelines, Events — C-T-T-E — a checklist before playtesting.
