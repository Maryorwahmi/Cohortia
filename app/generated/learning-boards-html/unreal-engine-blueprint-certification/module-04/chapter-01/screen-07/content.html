Module 4 › Chapter 4.1 › Character Movement
Blueprint pattern
[Sample logic]
Get Input Action "Move" -> Get Value (X,Y)
Get Control Rotation -> Get Forward Vector, Get Right Vector
Add Movement Input(Forward, Value.Y)
Add Movement Input(Right, Value.X)
This keeps movement consistent with the Character Movement Component and leverages existing physics and collision responses.
Example scenario
On a slope the Character Movement Component will handle sliding and step-up, which you preserve by using Add Movement Input instead of directly setting locations.
Key Takeaway

Route motion through Add Movement Input and tune the Character Movement Component for desired behaviors.
