Module 4 › Chapter 4.1 › Activity
Step-by-step checklist
  1. Create BP_InteractableDoor: add Static Mesh + Box Collision.
  2. Add DoorTimeline with Float Track OpenAlpha, keys 0→1 over 1s.
  3. Create BPI_Interactable with Interact(); implement in door blueprint.
  4. On Interact: Play From Start. Timeline Update -> Lerp -> Set Relative Location.
  5. On Timeline Finished: Delay 3s -> Reverse From End.
  6. In player: Input Action Interact -> Line Trace -> Does Implement Interface -> Interact(Message).
  7. Test with Draw Debug and Print String; verify collision channels block walls.
Example checks
  • Does the door move relative to its actor origin?
  • Does the trace hit only intended actors?
  • Does pausing remove the gameplay IMC?
Key Takeaway

Follow the checklist, verify collision settings, and use debug draw so your first tests produce clear, actionable results.
