Module 4 › Chapter 4.1 › Debugging
Checklist
  • Trace through walls? Verify trace channel and mesh collision presets.
  • Unintended input? Confirm IMC remove/add calls on mode changes.
  • Timeline offsets wrong? Cache relative transforms at BeginPlay.
Debug tools
  • Draw Debug Type on traces to visualize them live.
  • Print String to log hit actor names and distances during testing.
  • Temporarily set collision presets to isolate behavior.
Key Takeaway

Use practical debug checks for traces, contexts, and timelines to resolve common interaction issues quickly.
