Module 4 › Chapter 4.1 › Trace → Interact
Event graph pattern
[BP_PlayerCharacter Event Graph]
Input Action Interact (Triggered)
  -> Line Trace By Channel
     Start: Camera Location
     End: Start + ForwardVector * 500
     Trace Channel: Visibility
  -> Break Hit Result
  -> Branch (Condition: Blocking Hit)
     True -> Does Implement Interface (BPI_Interactable) (Target: Hit Actor)
       -> Branch (Return Value)
          True -> Interact (Message) (Target: Hit Actor)
Include the player in Ignore Actors to avoid hits on self, and set Draw Debug Type to visualize traces while testing.
Example
Player presses Interact, the trace hits a door, Does Implement Interface returns true, and the door receives the Interact message to begin opening.
Common mistake
Using the wrong Trace Channel or not setting collision presets so walls block the chosen channel. Always verify collision settings for interactive props and geometry.
Key Takeaway

A trace + interface call pattern decouples the player from specific object types and keeps interaction logic modular and testable.
