Module 4 › Chapter 4.1 › GameMode & GameState
Roles
  • GameMode: authoritative rules, spawning, match flow.
  • GameState: shared global state for players and actors to read.
Example flow
StartGame in GameMode initializes scores and input contexts, GameState stores current time and match status for display widgets.
Pause handling
Set Game Paused true, show pause UI, and remove gameplay IMC so player input has no effect. Decide which systems should continue (music) and which should pause (AI).
Key Takeaway

Keep authoritative rules in GameMode and put observable, replicated data in GameState for consistent game flow and easy access by UI and actors.
