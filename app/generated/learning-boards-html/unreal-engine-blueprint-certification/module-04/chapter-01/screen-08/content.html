Module 4 › Chapter 4.1 › Traces
Trace types
  • Line Trace: precise, returns first blocking hit.
  • Sphere Trace: radius-based, better for slightly off-center targets.
Example
Start = Camera Location, End = Start + ForwardVector * InteractionDistance. Break Hit Result and test for interface implementation or tag.
Debug checklist
  • Is Trace Channel set to Visibility or a custom channel blocked by walls?
  • Are you ignoring the player actor to avoid self-hits?
  • Use Draw Debug Type to visualize the trace during testing.
Key Takeaway

Pick the trace that matches your interaction tolerance and confirm collision responses so traces hit what you expect.
