Module 4 › Chapter 4.1 › Actions vs Axes
Concept

Treat discrete intents like Interact as triggers. Treat continuous controls like Move as analog inputs that supply values to movement systems.

Concrete example
A Move Input Action returns an X/Y vector. Multiply that vector by camera forward/right to produce world movement vectors, then call Add Movement Input with those directions and the appropriate scale.
Common mistake
Feeding raw axis values directly into position updates bypasses the Character Movement Component and its collision handling. Use Add Movement Input to keep physics consistent.
Key Takeaway

Map analog actions to movement vectors and always route movement through the Character Movement Component for correct physics and collisions.
