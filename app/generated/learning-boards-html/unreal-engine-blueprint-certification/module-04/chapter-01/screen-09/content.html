Blueprint steps
[BP_InteractableDoor Event Graph]
Event Interact (from BPI_Interactable)
  -> Play From Start (DoorTimeline)

DoorTimeline Update
  -> Lerp (Vector) (A: InitialLocation, B: InitialLocation + Z(200), Alpha: OpenAlpha)
  -> Set Relative Location (Static Mesh)

DoorTimeline Finished
  -> Delay (3.0)
  -> Reverse From End (DoorTimeline)
Remember to cache InitialLocation at BeginPlay so Lerp uses relative values and the door moves correctly if the actor is placed elsewhere in the level.
Example behavior
Player triggers Interact, door plays open timeline, remains open for three seconds, then reverses the timeline to close.
Common mistake
Using world locations instead of relative transforms causes misplacement when actors move or are instanced. Cache the mesh's relative transform at BeginPlay.
Key Takeaway

Timelines provide smooth, reversible animations; drive transforms with relative values and trigger playback from Interact events.
