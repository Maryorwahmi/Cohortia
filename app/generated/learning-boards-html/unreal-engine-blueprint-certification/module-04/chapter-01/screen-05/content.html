Module 4 › Chapter 4.1 › Switching IMCs
Mode change steps
  1. Detect mode trigger (enter vehicle, open menu).
  2. Call Add Input Mapping Context for the new IMC.
  3. Call Remove Input Mapping Context for the old IMC.
  4. Optionally set priority or consume input events.
Example
On vehicle entry: Add IMC_Player_Vehicle, Remove IMC_Player_OnFoot. On exit, reverse the calls.
Checklist
  • Are old contexts removed? If not, remove them explicitly.
  • Do IMCs share actions that need priority? Assign ordering.
  • Are remaps preserved? Keep Input Actions stable across contexts.
Key Takeaway

Treat context swaps as explicit state transitions and verify them during testing to avoid conflicting behavior.
