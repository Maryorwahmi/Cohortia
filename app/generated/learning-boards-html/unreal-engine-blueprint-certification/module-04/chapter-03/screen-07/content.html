Write Small Tasks

Custom Tasks & Services

Design tasks to do one thing and finish. Use services to keep data fresh without blocking execution.

Example Service
BTS_UpdateTargetLocation — runs every 0.5s, reads TargetActor, writes CurrentTargetLocation.
Example Task
BTT_FindRandomPatrolLocation — finds a random navigable point, sets PatrolLocation, finishes success.
Key Takeaway

Favor small, testable nodes. Use services sparingly and measure their cost when many AI run in parallel.

Blueprint Pattern
// BTS_UpdateTargetLocation (pseudo-Blueprint steps)
Event ReceiveTickAI(OwnerController, ControlledPawn)
  -> Get Blackboard Component
  -> Get Value As Object(TargetActor)
  -> If TargetActor != null
      -> Get Actor Location
      -> Set Value As Vector(CurrentTargetLocation, ActorLocation)
Misconception
Placing heavy game logic inside a Task that never finishes. Tasks should return success or fail so the tree can continue making decisions.
