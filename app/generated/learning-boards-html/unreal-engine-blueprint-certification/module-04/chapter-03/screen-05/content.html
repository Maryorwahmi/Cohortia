Structure

Composites, Decorators, Tasks, Services

Use selectors for priority, sequences for ordered steps, decorators for gating, tasks to act, and services to keep data fresh.

Selector Example
Try Attack, then Chase, then Patrol. Stops at the first successful branch.
Sequence Example
Find Cover → MoveToCover → Shoot. Sequence fails if Find Cover cannot find a spot.
Key Takeaway

Mix node types intentionally: priority, order, conditions, actions, and periodic updates are distinct responsibilities.

Visual Cards
Decorator
Checks a condition like 'TargetActor Is Set' or 'Has Line of Sight To'.
Service
Runs periodically to update Blackboard keys such as CurrentTargetLocation.
Task
Performs actions: Move To, Play Animation, or custom Blueprint tasks.
Common Misconception
Using Services for constant heavy tracing. Prefer timed updates and event-driven checks where possible to save CPU.
