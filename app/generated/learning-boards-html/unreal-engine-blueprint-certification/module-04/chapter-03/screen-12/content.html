Module 4 › Chapter 4.3 › Starter Activity
Steps

Create Blackboard and Behavior Tree

  1. Create BB_EnemyAI with TargetActor (Object) and PatrolLocation (Vector).
  2. Create BT_EnemyAI and Run Behavior Tree in BP_EnemyAIController BeginPlay.
  3. Hook AIPerception to set/clear TargetActor on the Blackboard.
  4. Build a Selector: Chase Sequence (TargetActor Is Set) and Patrol Sequence (TargetActor Is Not Set).
  5. Add Service to Chase to update target location and a custom BTT_FindRandomPatrolLocation for patrol.
Key Takeaway

Follow the event-driven pattern: perception updates Blackboard, tree decorators gate branches, services refresh dynamic data.

Starter Blueprint Pseudocode
// BP_EnemyAIController OnTargetPerceptionUpdated
If SuccessfullySensed && IsPlayerCharacter:
  Get Blackboard Component (self)
  Set Value As Object(TargetActor, PerceivedActor)
Else:
  Get Blackboard Component (self)
  Clear Value(TargetActor)

// BT_EnemyAI Layout
Root
  Selector
    Sequence (Decorator: TargetActor Is Set)
      Service: BTS_UpdateTargetLocation
      Task: Move To (Blackboard Key: TargetActor)
    Sequence (Decorator: TargetActor Is Not Set)
      Task: BTT_FindRandomPatrolLocation
      Task: Move To (Blackboard Key: PatrolLocation)
      Task: Wait (2.0s)
Validation
Run the Behavior Tree Monitor to confirm keys and branch activity. If Chase doesn't run, inspect the decorator configuration and Blackboard values.
