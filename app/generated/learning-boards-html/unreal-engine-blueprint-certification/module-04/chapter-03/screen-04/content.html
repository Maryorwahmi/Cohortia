Definition

Blackboard: Key-Value Store

A Blackboard is a centralized memory where nodes read and write values used to control Behavior Tree flow.

Common Keys
  • TargetActor — Object (Actor)
  • PatrolLocation — Vector
  • Alerted — Bool
Best Practice
Keep keys explicit and limited. Avoid using a single catch-all key for many unrelated values.
Key Takeaway

Blackboards decouple perception from action by providing a shared, named memory for your Behavior Tree.

Concrete Example
Use AIPerception's OnTargetPerceptionUpdated to Set Value As Object on the Blackboard when the player is sensed, and Clear Value when lost. The chase Sequence checks TargetActor Is Set to decide whether to run.
Common Mistake
Treating the Blackboard as global shared memory for every pawn. Usually give each AI its own Blackboard Component instance.
