Concept

NavMesh, Areas, and Agent Settings

Nav Areas assign traversal cost and behavior to geometry; agent settings control what the agent can fit through.

Nav Areas Example
Assign NavArea_Danger to hazardous regions and increase cost so AI avoids them when possible.
Agent Settings
Set Agent Radius and Height in navigation settings to match pawn collision to avoid getting stuck.
Key Takeaway

Nav Areas and agent sizing are essential tools to shape AI movement without changing behavior code.

Practical Notes
If paths look blocky, adjust cell size; if NavMesh generation takes too long, increase cell size. For groups, enable Crowd Manager and tune Separation, Avoidance, and Cohesion to reduce collisions.
Common Mistake
Neglecting Agent Radius/Height, which often causes pawns to get stuck in narrow spaces despite a correct NavMesh.
