Optimization

Reduce expensive updates

Space out Services, avoid per-frame line traces across many AI, and use events when possible.

Checklist
  • Are Services too frequent?
  • Are heavy traces batched or event-driven?
  • Do Tasks have clear exit conditions?
Key Takeaway

Profile early, limit per-AI expensive work, and use the Behavior Tree Monitor to pinpoint logical failures quickly.

Debug Example
If the Chase branch won't run even though TargetActor is set, inspect the Blackboard tab and ensure the decorator's Key Query matches 'Is Set' and the key name is identical.
Profiler Tip
Use engine profiling commands to find which behaviors spike CPU and then correlate with Services or Tasks that run at the same frequency.
