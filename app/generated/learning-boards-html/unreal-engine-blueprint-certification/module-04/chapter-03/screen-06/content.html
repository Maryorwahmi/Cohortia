Module 4 › Chapter 4.3 › Perception to Action
Process

AIPerception → Blackboard → Behavior Tree

Respond to perception events by updating Blackboard values that drive tree decorators and tasks.

Step-by-step
  1. On perception success: Set Value As Object(TargetActor).
  2. On perception lost: Clear Value(TargetActor).
  3. Behavior Tree decorator checks TargetActor Is Set to run Chase Sequence.
  4. Service updates current actor location periodically for Move To accuracy.
Key Takeaway

Link perception events to Blackboard updates so the tree always has the data needed to act.

Concrete Example
[AIPerceptionComponent OnTargetPerceptionUpdated]
    -> [Branch] (Condition: Successfully Sensed && Is Player Character)
        [True]
            -> [Get Blackboard Component (self)]
            -> [Set Value As Object (TargetActor, Perceived Actor)]
        [False] (Player Lost)
            -> [Get Blackboard Component (self)]
            -> [Clear Value (TargetActor)]
Debug Tip
If the tree doesn't chase, confirm Run Behavior Tree is called on BeginPlay and check the Decorator configuration in the Behavior Tree Monitor.
