Interfaces & Event Dispatchers

Use interfaces for generic function calls and dispatchers to broadcast events that many objects may subscribe to.

Blueprint Interface Example
Define I_Alertable with OnAlert. Any pawn implementing the interface can be notified without casting.
Event Dispatcher Example
Broadcast EnemySpotted to local listeners; receivers subscribe on BeginPlay and unsubscribe on EndPlay.
Global State
GameState or shared Blackboard-like keys can hold global alert status, but use sparingly to avoid accidental coupling between unrelated systems.
Design Tip
Have only designated broadcasters (e.g., squad leaders) send global events to reduce noise and CPU cost from frequent checks across many pawns.
