Module 4 › Chapter 4.2 › Patrolling: waypoints and AI Move To
Top/bottom split — patrol process
Steps
  1. Place TargetPoint actors (Waypoint_A, Waypoint_B) in the level.
  2. Add PatrolWaypoints array to BP_EnemyAIController and populate with the waypoints.
  3. Create CurrentWaypointIndex integer and StartPatrol custom event.
  4. In StartPatrol, call AI Move To using the waypoint's actor location; on success increment index and delay before next StartPatrol.
Example
CurrentWaypointIndex = 0, PatrolWaypoints = [Waypoint_A, Waypoint_B]. StartPatrol moves to Waypoint_A, On Success sets index to 1, delay, then moves to Waypoint_B, then wraps to 0.
Key Takeaway

Use TargetPoints and On Success events for reliable patrol loops that work with NavMesh pathfinding.

Common mistake

Forgetting to build or cover the patrol area with a NavMesh causes AI Move To to fail or produce straight-line movement.

Implementation cards
PatrolWaypoints: Array<Actor> — fill in editor or populate dynamically.
StartPatrol: Get(PatrolWaypoints, CurrentWaypointIndex) → AI Move To → On Success increment index and Delay(1s) then StartPatrol.
Wrap-around: if index >= length then set to 0.
