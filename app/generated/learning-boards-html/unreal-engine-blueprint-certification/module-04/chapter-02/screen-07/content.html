Module 4 › Chapter 4.2 › Chasing: reacting to perception
Chase control flow
• Bind OnTargetPerceptionUpdated in the controller. If Successfully Sensed and actor is player then set state to Chase.
• Call AI Move To targeting the perceived actor. Use actor-targeted Move To so the path updates as the player moves.
• Use a retriggerable Delay or Timer to update the Move To target every 0.3–0.6 seconds while in Chase state.
• When perception reports false, Stop Movement, set state to Patrol, and call StartPatrol.
Misconception check
Don’t assume one Move To call will track a moving target; schedule regular Move To updates or use actor-targeted Move To with periodic retriggering to keep the AI following smoothly.
Example
On perception true: Set CurrentAIState = Chase → AI Move To(Target: Player) → On Success Delay(0.5) then AI Move To again while state = Chase.
Key Takeaway

Retrigger Move To while chasing to follow a moving target and use Stop Movement plus StartPatrol when the target is lost.
