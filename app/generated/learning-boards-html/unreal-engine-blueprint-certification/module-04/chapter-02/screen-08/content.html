Module 4 › Chapter 4.2 › State Machine Design with Enums
Hierarchy
• Create E_AI_State enum with Idle, Patrol, Chase (and optionally Attack).
• Add CurrentAIState variable to the AI Controller and default it to Patrol.
• Use Switch on Enum where behavior decisions are evaluated, and route execution to the appropriate logic branch.
• Keep state-specific functions isolated: StartPatrol for Patrol, ChaseLoop for Chase, etc.
Example transitions
• BeginPlay: CurrentAIState = Patrol → StartPatrol()
• OnTargetPerceptionUpdated (sensed): CurrentAIState = Chase → Start chase retrigger loop
• OnTargetPerceptionUpdated (lost): CurrentAIState = Patrol → Stop Movement → StartPatrol()
Misconception
Avoid putting multiple behaviors in a single state. Each state should be responsible for clear actions and transitions so you can inspect and test them individually.
Key Takeaway

Enums plus Switch on Enum create readable state machines. Design explicit entry and exit rules to avoid flicker between states.
