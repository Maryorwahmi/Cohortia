Module 4 › Chapter 4.2 › Activity: Build a Patrolling & Chasing Enemy
Step-by-step
  1. Create BP_EnemyAI (Character): add mesh and capsule, set AI Controller Class to BP_EnemyAIController.
  2. Add AIPerceptionComponent to BP_EnemyAI and configure Sight (1500, 2000, 60) and affiliation detection.
  3. Create BP_EnemyAIController (AIController) and in BeginPlay bind OnTargetPerceptionUpdated from controlled pawn's perception component.
  4. Add PatrolWaypoints array and CurrentWaypointIndex; create StartPatrol custom event that AI Move To waypoint, On Success increment and loop with Delay(1s).
  5. In perception handler set state to Chase and call AI Move To actor while sensed; on loss set to Patrol, Stop Movement, and StartPatrol.
  6. Add NavMesh Bounds Volume covering route and press 'P' to visualize. Use ShowDebug AI Perception and ShowDebug AI Navigation while testing.
Expected result
The AI patrols between waypoints and switches to chase the player when sensed, then returns to patrol when the player is lost.
Test tips
Place waypoints clearly visible in the level, then toggle NavMesh visualization and debug perception traces during runtime to iterate quickly.
