Senses to configure
Sight
  • Set Sight Radius and Lose Sight Radius
  • Set Peripheral Vision Angle (cone)
  • Set Detection by Affiliation (Enemies/Friendlies/Neutrals)
Hearing
  • Set Hearing Range
  • Generate noise events from player or AI
  • Can trigger chase without visual contact if configured
Event pattern
Bind OnTargetPerceptionUpdated in BeginPlay of the AI Controller. The event yields the perceived actor, whether sensing succeeded, and the sense type. Use that to set E_AI_State and call AI Move To when necessary.
Quick example
When Successfully Sensed is true and the actor is the player, set CurrentAIState to Chase and call AI Move To targeting the player's actor. If perception reports false, revert state to Patrol and resume patrolling.
Misconception check
Do not assume Sight Radius implies line-of-sight: blocked collision or wrong trace channels can prevent detection. Also confirm affiliation settings so the player can actually be detected.
Key Takeaway

AIPerceptionComponent centralizes senses; its events are the gateway to state changes like Chase or Patrol.
