AI Controller
Owns decision-making, perception, path requests and state variables.
AIPerceptionComponent
Provides senses (Sight, Hearing) and fires OnTargetPerceptionUpdated events.
NavMesh / AI Move To
AI Move To uses the NavMesh generated by NavMesh Bounds Volume for reliable pathfinding.
Summary
Combine controllers, perception, state machines, and a proper NavMesh to create patrol-and-chase enemies you can iterate and debug quickly.
