Module 2 › Chapter 1.3 › Event-driven Execution Flow
Core Idea
Events fire, execution wires carry order, and data pins carry values. Keep sequencing explicit by chaining execution pins when order matters.
Example Chain
Event BeginPlay → Set Variable(myMessage) → Print String. The variable is set before it is printed because execution flows along the white wire.
Common Mistake
Don't rely on the visual position of nodes to determine order. Only execution connections enforce timing and sequence.
Process Steps
1. Event fires
2. Execution wire moves
3. Data pins pass values
// Pseudo representation of execution order
BeginPlay -> SetMyMessage("Hello") -> PrintString(GetMyMessage())
Check Your Understanding
If PrintString reads a variable, ensure the Set occurs earlier on the execution wire so the printed value is the updated one.
