Module 2 › Chapter 1.3 › Create Your First Actor Blueprint
Step sequence
  1. Create Blueprint Class → Actor → BP_MyFirstActor.
  2. Add Static Mesh component; set SM_Cube in Details.
  3. Add String variable MyMessage and set default.
  4. In Event Graph wire BeginPlay → Print String using Get MyMessage.
  5. Compile, place Actor in level, then Play to verify output.
Scenario
You want a visible cube in the level that announces itself when play starts.
Expected Result
After placing BP_MyFirstActor in the level and pressing Play, the message defined in MyMessage appears in the Viewport.
Reflection
Which step failed if you don’t see the message: missing compile, wrong variable wiring, or actor not placed in the level?
