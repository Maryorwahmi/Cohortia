Functions
Encapsulated graphs with inputs and outputs. They can access Blueprint variables and are ideal for class-specific behaviors.
Example
Create a function GetGreeting that returns a string, then call it from multiple places to centralize message logic.
Macro Libraries
Reusable node sequences callable from many Blueprints. Best for repeated wiring patterns that don’t require tight encapsulation.
When to use
Use macros for repeated visual wiring; use functions when you need clear inputs, outputs, and encapsulation.
Refactor Checklist
  • Is this sequence repeated? Extract it.
  • Does it need inputs or outputs? Use a function.
  • Will multiple Blueprints use this? Consider a Macro Library or Interface.
