Module 2 › Chapter 1.3 › Types of Blueprints
Actor Blueprint
Reusable objects placed in levels. Combine components with logic for things like doors, pickups, or characters.
Use when: you need many instances across maps.
Level Blueprint
Level-specific scripts that reference actors placed in that level. Good for map-level triggers and sequences not shared across levels.
Use when: the event is unique to a single map.
Widget Blueprint
Compose UI elements like menus, HUDs, and inventory screens. Widgets handle layout and user interaction separate from Actors.
Use when: building user interface components.
Blueprint Interface
Defines function signatures that multiple Blueprints implement. Interfaces decouple senders and receivers so logic can call behaviors without type dependencies.
Use when: different Blueprints must respond to the same calls.
Macro Library
Reusable node graphs that you can include in many Blueprints—ideal for repeated sequences like common math or logging patterns.
Use when: you repeat the same node sequence often.
Common Mistake
Putting reusable logic in a Level Blueprint makes it hard to reuse and maintain. Prefer Actor Blueprints or Interfaces for reuse.
