Module 2 › Chapter 1.3 › Blueprint Editor Panels
Panel Roles
Viewport
Preview and position visual components. Helps confirm transforms and attachment points.
Components
Hierarchy of parts. Add a Static Mesh to make an Actor visible in the level.
Details
Edit properties and defaults for the selected item. Check selection before changing values.
My Blueprint
Organize variables, functions, macros, and graphs for quick access when wiring logic.
Practical Walkthrough
Add a Static Mesh
In Components, click Add Component, choose Static Mesh, then set SM_Cube in Details under Static Mesh.
Create a Variable
Open My Blueprint, add a String variable, name it MyMessage, and set a default value in Details.
Tip
Consistent naming in My Blueprint speeds dragging variables into the Event Graph and reduces wiring mistakes.
