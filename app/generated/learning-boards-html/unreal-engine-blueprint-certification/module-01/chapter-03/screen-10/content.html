Module 2 › Chapter 1.3 › Variables & Data Flow
Variable Types
String
Text messages and labels.
Boolean
True/false flags like IsLocked.
Float / Integer
Numeric values for counters, speeds, and thresholds.
Vector / Object
Positions, directions, and references to other Actors.
Example: Use a variable in Print
// Create variable
String MyMessage = "Hello from a variable!"

// Event
BeginPlay
  -> Get MyMessage
  -> PrintString(Get MyMessage)
Editable Instances
Expose defaults so each placed Actor can show a different message without editing the Blueprint graph.
