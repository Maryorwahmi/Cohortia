Module 2 › Chapter 1.3 › Key Concepts
Blueprint
A visual container combining components, variables, and an Event Graph for behavior.
Execution & Data
White execution wires order actions; colored data pins pass typed values between nodes.
Blueprint Types
Actor for reusable objects, Level for map-specific events, Widget for UI, Interface and Macros for reuse and decoupling.
Summary

Blueprints let you implement gameplay visually. Organize logic, compile often, and prefer small, testable graphs for faster iteration and fewer bugs.
