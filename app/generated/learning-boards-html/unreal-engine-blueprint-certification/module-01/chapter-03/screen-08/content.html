Module 2 › Chapter 1.3 › BeginPlay → Print String
Step-by-step
1. Add Event BeginPlay
Right-click in the Event Graph and select BeginPlay if it isn’t present.
2. Add Print String
Search for Print String and add it. Type a message in the string field to show at runtime.
3. Wire and Compile
Drag the white execution wire from BeginPlay to the Print String execution input, then click Compile.
Code Panel (visual pseudo)
Event BeginPlay
  -> Print String: "My first Blueprint is alive!"

// Optional with variable
Variable MyMessage = "Hello from a variable!"
Event BeginPlay
  -> Get MyMessage
  -> Print String(Get MyMessage)
Test
Compile and press Play in the main editor. The message should appear in the Viewport if the graph is wired and compiled.
