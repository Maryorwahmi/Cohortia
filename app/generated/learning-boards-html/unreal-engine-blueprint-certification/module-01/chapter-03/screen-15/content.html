Module 2 › Chapter 1.3 › Essential Terms
Execution Pin
White pins that control the order of node execution—sequence your actions here.
Data Pin
Colored pins carrying typed values between nodes; they don’t trigger execution by themselves.
Compile
Convert and validate Blueprint changes so the engine uses your latest logic during Play.
Takeaway

When you edit Blueprints: wire execution, pass typed data, compile, and then test. These steps are your error-reduction routine.
