Lab Checkpoints
  • Place Static Mesh Actor and Point Light from Place Actors panel.
  • Inspect Components in the Details Panel and verify a StaticMeshComponent exists.
  • Parent a chair to a table in the World Outliner and verify transform inheritance.
  • Build a small room with SM_Floor and SM_Wall assets using grid snapping.
Verification Tasks
Task: Change Spot Light Component intensity; expected: lighting in the viewport brightens immediately.
Task: Move parent Actor; expected: all child components and child Actors move consistently.
Task: Enable grid snapping and align floor tiles; expected: edges meet without gaps.
