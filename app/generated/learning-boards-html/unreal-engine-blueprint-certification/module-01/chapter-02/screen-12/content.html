Snapping types
  • Grid Snapping — locks translation to grid increments.
  • Angle Snapping — rotates by fixed degrees.
  • Scale Snapping — enforces consistent scale steps.
Practical guidance
Match grid size to your modular mesh dimensions to prevent gaps between tiles.
Use angle snapping for symmetry and tiled rotation increments.
Toggle snapping only when you need fine control to avoid unintended alignment jumps.
Key Takeaway
Snapping removes small errors and ensures modular assets meet cleanly — essential for production-ready levels.
