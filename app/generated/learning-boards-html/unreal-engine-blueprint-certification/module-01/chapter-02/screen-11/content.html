Gizmo basics
W = move, E = rotate, R = scale. Use axis handles for constrained transformations.
Local vs world axes: toggle transform mode in the toolbar to change behavior.
Check numeric transforms in Details for precise edits.
Practice prompt
Rotate a door 90 degrees using E with angle snapping enabled. If rotation looks off, check the pivot position to ensure it rotates around the hinge.
Key Takeaway
Control transforms with W/E/R and confirm axis and pivot settings to avoid unexpected motions.
