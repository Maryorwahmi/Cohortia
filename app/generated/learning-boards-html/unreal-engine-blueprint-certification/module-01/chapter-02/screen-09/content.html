World Outliner
See every Actor in the level, reparent children, and rename items for clarity.
  • Drag an Actor onto another to make it a child.
  • Use search to find objects by name.
Details Panel
Inspect properties and the Components list for the selected Actor. Add or configure Components here.
Example: expand Components on a wall Actor to find StaticMeshComponent and Add Component → Spot Light.
Tip: Confirm selected Actor name in the Details header before adding components to avoid accidental attachments.
Check
After adding a component, move the parent Actor and confirm the new component follows. If it doesn't, re-open Outliner and verify parentage.
