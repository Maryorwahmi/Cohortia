Learning Objectives
Bloom path: Learn → Understand → Apply → Master
01
Differentiate Actor & Component
Identify Actors as containers and Components as attached modules that add visuals or behavior. This supports modular design and reuse.
VERIFIED COMPETENCY MILESTONE
02
Add & configure Actors
Place Static Mesh and Light Actors from the Place Actors panel and Content Browser, then adjust properties in Details for the desired result.
VERIFIED COMPETENCY MILESTONE
03
Attach & detach Components
Use the Add Component button and World Outliner parenting to compose behaviors. Experiment with moving parent and child to confirm hierarchy.
VERIFIED COMPETENCY MILESTONE
04
Master transforms & snapping
Use W/E/R keys, grid/angle/scale snapping, and temporary pivot moves to align and animate objects precisely.
VERIFIED COMPETENCY MILESTONE
