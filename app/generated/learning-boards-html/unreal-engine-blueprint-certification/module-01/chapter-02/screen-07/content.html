Module 1 › Chapter 1.2 › Place Actors & Content Browser
Place Actors panel
Fast access to common Actor types like lights, cameras, and volumes for rapid scene building.
Good for: Point Light, Spot Light, Directional Light, Primitive shapes.
Tip: Use Place Actors when prototyping a level layout because it's quick to manipulate common types.
Content Browser
Drag specific assets (SM_ prefabs) into the scene to create Actors that reference those assets via Components.
Good for: Static meshes from Starter Content, skeletal meshes, materials.
Practice: Drag SM_Floor_400x400 to origin then enable grid snapping to align edges perfectly.
Example
Drag a Point Light from Place Actors and a floor mesh from Content Browser. Use grid snapping to ensure the floor sits at 0,0,0 and the light is centered above it.
