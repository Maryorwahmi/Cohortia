Module 1 › Chapter 1.2 › Common Component Types
Components you will use daily
StaticMeshComponent — supplies visible geometry and collision for static objects.
SkeletalMeshComponent — used for animated characters and rigged objects.
Light Components — Point, Spot, Directional. Configure intensity and range in Details.
Collision Components — Capsule, Box, Sphere. Define physics and overlap behavior.
Movement Components — CharacterMovementComponent for player locomotion and jumping.
Quick examples
Lamp Actor = StaticMeshComponent + PointLightComponent.
Enemy Pawn = SkeletalMeshComponent + CapsuleComponent + MovementComponent.
Security Camera = StaticMeshComponent + CameraComponent.
Key Takeaway

Choose components to match single responsibilities: visuals, collision, sensing, or movement. Compose them to construct the Actor you need.
