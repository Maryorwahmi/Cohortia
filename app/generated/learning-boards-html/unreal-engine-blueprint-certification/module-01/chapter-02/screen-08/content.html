Module 1 › Chapter 1.2 › Add & Configure Actors
Step-by-step
  1. Choose Place Actors or Content Browser.
  2. Drag asset into Viewport; set transform with W/E/R.
  3. Rename Actor in World Outliner for clarity.
  4. Open Details Panel to inspect Components and properties.
  5. Adjust mobility, collision, light intensity, and color as needed.
  6. Test in-viewport and save level.
Practical tips
Rename objects immediately to prevent confusion during later edits.
Set mobility correctly: static for level geometry, movable for animated objects and lights when needed.
Use Details Panel filters to find exact Component properties quickly.
Example
Place a floor, snap to origin, place walls with grid snapping, add a Point Light and set attenuation so the room is evenly lit. Rename objects to Floor_Main, Wall_North, Light_Ceiling.
