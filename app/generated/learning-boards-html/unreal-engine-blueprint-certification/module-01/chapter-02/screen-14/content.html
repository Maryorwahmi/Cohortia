Module 1 › Chapter 1.2 › Lab Walkthrough
Step sequence
  1. Drag SM_Floor_400x400 to origin and enable grid snapping.
  2. Add SM_Wall_400x200 pieces and rotate them into place with angle snapping.
  3. Place SM_TableRound and SM_Chair; parent chair to table in World Outliner.
  4. Add a Point Light from Place Actors; position and set attenuation.
  5. Select a wall, Add Component → Spot Light, change intensity and cone angle.
  6. Use Alt + MMB to move pivot to a corner and rotate the wall as a hinge.
Checkpoints
Checkpoint: Move the table; the chair should follow as a child.
Checkpoint: Toggle grid snapping; the walls should keep clean edges when snapping is on.
Checkpoint: After pivot move, the wall rotates around the new point like a door.
Why this lab
This compact project ties together placement, hierarchy, component attachment, and transform precision so you can apply the same techniques in larger levels.
