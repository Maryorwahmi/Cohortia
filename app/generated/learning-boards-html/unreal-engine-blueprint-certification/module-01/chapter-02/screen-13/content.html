Module 1 › Chapter 1.2 › Pivot Points
Why pivot matters
Pivot defines center of rotation and scaling. Move it to simulate hinges or localized transformations.
Temporary pivot: Alt + Middle Mouse Button to reposition for a single operation.
Persistent pivot: Ctrl + Alt + Middle Mouse Button for longer edits.
Practice
Select a wall Actor, move pivot to a corner using Alt+MMB, rotate to mimic a door, then reset the pivot and rotate again to compare behaviors.
Example
Rotating a door around its hinge requires moving the pivot to the hinge location; otherwise rotation looks wrong.
