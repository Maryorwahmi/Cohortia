Module 1 › Chapter 1.2 › Attaching & Detaching Components
Add Component workflow
  1. Select Actor in Viewport or Outliner.
  2. Open Details Panel and choose Add Component.
  3. Pick the component type and configure properties.
  4. Save changes to Blueprint or level as needed.
Remove or move
To remove: select the component entry in Components list and delete it. To emulate moving, add the same component to the target Actor and copy settings.
Avoid trying to drag components between separate Actor instances; reattach and set properties intentionally.
Example
Attach a Spot Light Component to a wall Actor. Change the cone angle and intensity, then delete it to observe the immediate effect in the viewport.
