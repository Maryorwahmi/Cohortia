Module 1 › Chapter 1.1 › Key Concepts
Unreal Engine
A real-time 3D creation tool for games and visualization.
Blueprints
Visual scripting for gameplay and quick iteration without C++.
Project Templates
Scaffolding like First/Third Person or Blank with Starter Content.
Viewport Navigation
RMB + WASD, Q/E, and scroll wheel for camera control.
World Outliner / Details
Outliner lists Actors; Details provides numeric properties for precision.
Content Browser / Transforms
Store assets, drag into Viewport, then use W/E/R to move, rotate, scale.
Summary
Practice these core Editor skills to prepare for building Blueprints and interactive scenes: project creation, navigation, asset placement, and precise transforms.
