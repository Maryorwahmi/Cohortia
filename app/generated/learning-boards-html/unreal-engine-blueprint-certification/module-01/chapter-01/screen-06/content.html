Create
This plain sequence is useful when you want a reproducible setup for lab exercises and ensures the Content Browser contains starter assets for practice.
Verification
  1. Open Content Browser and expand StarterContent → Props.
  2. Drag SM_Chair into the Viewport.
  3. Select the chair and confirm transform values in Details Panel.
  4. Use W/E/R to transform and press Ctrl + S to save.
Troubleshoot
If StarterContent is missing, recreate with Starter Content enabled or import assets manually into Content Browser.
