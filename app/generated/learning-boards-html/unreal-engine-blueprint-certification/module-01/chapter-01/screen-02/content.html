Learning Objectives
Progress from identification to confident application with short milestones.
Bloom: Learn → Understand → Apply → Master
01
Identify core Editor panels
Name and locate Viewport, World Outliner, Details, Content Browser, and Modes.
Mnemonic: imagine a workshop layout — view, list, adjust, store.
Verified Competency Milestone
02
Navigate the 3D Viewport
Use camera controls: right-mouse look, WASD movement, Q/E vertical shifts, and scroll wheel speed.
Mnemonic: Right-hand pilot controls camera like a first-person camera.
Verified Competency Milestone
03
Create projects from templates
Choose Blank or genre templates and select Blueprint, target hardware, and quality presets.
Mnemonic: Template = pre-built scaffolding for common gameplay.
Verified Competency Milestone
04
Manipulate objects with transforms
Select Actors and use W, E, R for move, rotate, and scale; verify values in Details Panel.
Mnemonic: WER = move, rotate, resize.
Verified Competency Milestone
