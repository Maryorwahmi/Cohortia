Details Panel
Inspect and edit Actor properties with precision.
What you can edit
  • Transform: Location, Rotation, Scale (numeric fields).
  • Materials and components settings.
  • Blueprint-exposed variables for instances.
Example: precise alignment
Set the same Y coordinate for two chairs through numeric input to align them perfectly.
Key Takeaway

Rely on numeric values for repeatable edits; use the Details Panel to avoid accidental misplacement.

Quick Exercise
Select SM_Chair, note its Z value. Increase Z by 40 to lift the chair, then revert. Observe immediate changes in the Viewport.
Misconception
Dragging is always precise — not true. Numeric edits give exact reproducible positions.
