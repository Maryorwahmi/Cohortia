Create a New Project
Follow these steps to create a Blank Blueprint project with Starter Content.
Step 1 — Open Project Browser
Launch Unreal and choose Games → Next.
Step 2 — Select Template
Choose Blank (or a genre template if you want player controllers pre-made).
Step 3 — Project Settings
Pick Blueprint, Desktop/Console, Maximum, enable Starter Content, then name and create.
Common mistake
Accidentally selecting C++ or disabling Starter Content. Both choices add complexity for beginners.
Quick verification
After creation, open the Content Browser and confirm StarterContent exists. Try dragging SM_Chair into the Viewport.
Why this matters
A good template aligns the project with your learning goals and prevents rework later.
