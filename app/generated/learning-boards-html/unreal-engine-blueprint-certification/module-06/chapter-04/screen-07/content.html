Module 6 › Chapter 6.4 › Blackboard
Definition

Blackboard: typed shared state

Create keys with explicit types. Link the Behavior Tree to the Blackboard asset and use the AI Controller to run the tree so nodes can access it at runtime.

TargetActor (Object)
Stores the seen player or target actor reference.
LastKnownLocation (Vector)
Where the target was last observed.
PatrolPoint (Vector)
Current destination for patrolling behavior.
Usage patterns
  • Sensors write: Pawn Sensing On See Pawn sets TargetActor and LastKnownLocation.
  • Services update: Periodic checks refresh distances or visibility flags on the Blackboard.
  • Decorators read: Blackboard decorators gate sequences based on key state being set or in a threshold.
  • Tasks consume: Move To tasks read vector keys and act on them.
Common mistake
Mismatched key types or names cause nodes to fail silently. Keep a clear key list and type checks during development.
