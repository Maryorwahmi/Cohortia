Event wiring
On See Pawn → Set Blackboard Values
Set TargetActor (Object) and LastKnownLocation (Vector) using the seen pawn's actor location.
Service pattern
Attach Service to Composite
Service runs periodically while the branch is active and can update derived Blackboard values like distanceToTarget.
Checks
Use Behavior Tree and Blackboard debuggers to verify on-event writes and service updates. Ensure services are not running expensive traces every tick.
Common mistake

Putting heavy traces or large loops in Services. Instead, run such operations on longer timers or asynchronously.
