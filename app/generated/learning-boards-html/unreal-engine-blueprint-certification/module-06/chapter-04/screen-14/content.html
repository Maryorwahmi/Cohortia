Module 6 › Chapter 6.4 › Key Concepts
Behavior Tree
Hierarchical decision graph: Selectors, Sequences, Tasks, Services, Decorators.
Blackboard
Typed shared memory for Actors, Vectors, Booleans used across BT nodes.
EQS
Generator + Tests + Contexts produce scored options for the AI to choose.
Takeaway

Compose BT, Blackboard, and EQS thoughtfully: decide, store, query, then act — and use debuggers to iterate quickly.
