Module 6 › Chapter 6.4 › Selector vs Sequence
Selector (OR)
Try A
Try B
Try C

Use when you want fallback strategies. The composite succeeds as soon as one child succeeds.

Concrete example
Try chase; else take cover; else patrol
Selector: ChaseSequence, MoveToCover, PatrolSequence
Sequence (AND)
Step 1
Step 2
Step 3

Use when all steps must succeed in order. If any step fails, the sequence fails and stops.

Concrete example
MoveTo(LastKnownLocation) → Wait → Run EQS → MoveTo(PatrolPoint)
Sequence ensures search steps complete in order.
Misconception
Replacing a Selector with a Sequence can make the agent attempt incompatible actions sequentially instead of choosing a working option.
Pro tip
Use decorators to prevent sequences from starting when required state is missing.
Check
Verify children order: leftmost child has priority in Selector logic.
