Checks & tips
  • Ensure Query Params map contexts correctly (Self Actor, Target Actor).
  • Set EQS density and Min Scores to avoid poor candidates.
  • Trigger EQS on events or timers, not every tick.
  • Use Blackboards to decouple data production from consumption.
Key Takeaway

EQS supplies ranked options; Behavior Trees must consume and act on those options via Blackboard keys and tasks.
