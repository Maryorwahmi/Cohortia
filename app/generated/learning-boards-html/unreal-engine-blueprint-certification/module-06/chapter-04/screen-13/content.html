Module 6 › Chapter 6.4 › Performance & Mistakes
Performance rules
Services: keep them light
Run expensive checks on timers or asynchronously; avoid heavy traces per tick.
EQS frequency & density
Lower density and run only when needed. Cache results when the scene is stable.
Blackboard hygiene
Avoid many ephemeral keys; clear values when no longer relevant to prevent stale triggers.
Common mistakes
  • Running EQS every tick instead of on demand.
  • Heavy traces or loops inside Services.
  • Not clearing Blackboard keys after use.
Key Takeaway

Measure and limit expensive operations; design for clarity so behavior is debuggable and performant as it scales.
