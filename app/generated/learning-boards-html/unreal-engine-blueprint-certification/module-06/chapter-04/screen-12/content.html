Module 6 › Chapter 6.4 › Debugger Walkthrough
Behavior Tree Debugger
Select AI Controller in World Outliner → Debug dropdown → choose Behavior Tree
The BT editor will highlight active nodes and show decorator evaluations in real time.
Blackboard Debugger
Open from the same Debug dropdown
Watch key values update as sensors or services write into the Blackboard.
EQS Debug
Enable AI Debug under View → Developer
See sampled points, per-point scores, and the winning point visualized in the viewport as the query runs.
Key Takeaway

Visual debuggers are essential. Use them to validate keys, decorator logic, and EQS scoring instead of guessing at runtime behavior.
