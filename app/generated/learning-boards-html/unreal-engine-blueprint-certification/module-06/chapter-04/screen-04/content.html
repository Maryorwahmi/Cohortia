Module 6 › Chapter 6.4 › Behavior Trees
Definition

Behavior Tree anatomy

A modular hierarchy: Root → Composites → (Decorators/Services) → Tasks. Re-evaluated each tick to adapt to changes.

Selector (OR)
Succeeds when any child succeeds; used for fallbacks.
Sequence (AND)
Succeeds only if all children succeed; used for ordered tasks.
Services & Decorators
Services update state while branch is active. Decorators guard execution.
Key Takeaway

Design BTs as modular, reusable building blocks. Keep each node focused and predictable.

Example
Patrol → Search → Chase pattern
Root
Selector
Sequence: Player Seen
Decorator: TargetActor Is Set
Sequence: Search
Runs EQS and moves to result
Common mistake
Treating BT like a one-shot script
Remember BTs re-evaluate each tick; design for repeated checks, not single-pass logic.
