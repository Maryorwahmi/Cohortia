BTTask_SetNextPatrolPoint (pseudo)
// BTTask_SetNextPatrolPoint (Blueprint Task)
// Override ReceiveExecuteAI
//   Get AI Controller -> Get Controlled Pawn
//   Get Blackboard Component -> Get Value As Vector (PatrolPoint)
//   Get All Actors Of Class (TargetPoint) -> For Each Loop
//     If Actor Location == PatrolPoint (from Blackboard)
//       Store the other TargetPoint as the NextPatrolPoint
//   Set Blackboard Value As Vector (PatrolPoint, NextPatrolPoint Location)
//   Finish Execute (Success)
Concrete example
When PatrolPoint equals A, set it to B so the agent alternates between points.
Misconception
Don't perform heavy pathfinding inside a task's tick; tasks should complete or yield quickly.
Checklist
  • Blackboard key types must match values.
  • AI Controller runs the Behavior Tree on BeginPlay.
  • Task finishes with Success or Failure explicitly.
  • Use Services for periodic state updates instead of blocking tasks.
Key Takeaway

Implement small focused tasks that update Blackboard and finish cleanly; keep heavy work elsewhere.
