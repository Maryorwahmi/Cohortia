Call Stack Analysis
How to move from a heavy node to its root trigger using profiler data.
Self Time vs Total Time
Self time: time inside the node. Total time: includes child calls. Use both to understand cost distribution.
Follow the Callers
Find the functions that call the heavy node and see how often they invoke it.
Example: A heavy physics calculation node shows high total time but low self time; expanding callers reveals it is invoked thousands of times by an AI update loop. The fix is to decouple the physics calculation from per-AI updates or batch it.
Quick Checklist
  • Record a focused trace around the spike.
  • Filter to the suspect Blueprint class.
  • Sort nodes by total time to find hotspots.
  • Inspect callers to find triggering frequency.
  • Apply a single change and reprofile.
Misconception Check

Don't optimize the first heavy node you see without understanding how often it's triggered — you might be treating a symptom, not the cause.
