Hands-on Activity
Part 2: Blueprint Debugger Lab
Follow this sequence to set breakpoints and watch variables while stepping through a simple flow.
Setup
Create DebugMe event, Sequence node, two Branches, Set MyDebugValue to 10 then 20 before each Branch as described in the chapter.
Breakpoint Flow
Place breakpoints, play in PIE, when execution pauses add MyDebugValue to Watch, then use Step Over/Into/Out to observe changes.
What to Observe
Watch shows assignments occurring in order, Branch conditions evaluated, and where execution jumps — it reveals the exact cause of unexpected behavior.
Lab Checkpoint

You should be able to show the debugger paused with MyDebugValue in the Watch panel demonstrating the value change between nodes.

Common Mistakes
  • Not adding the right variables to Watch.
  • Using too many breakpoints and losing focus.
  • Leaving breakpoints enabled in production builds.
Safety Tip

Remove breakpoints before packaging. Use the debugger during development to gain precise insight without adding noisy logs.
