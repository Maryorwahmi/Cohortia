Definition
Debug Overhead
How instrumentation and temporary diagnostics affect performance and rules to avoid problems.
Use prints to verify flow, then remove or gate them. For high-frequency code paths, prints should be avoided entirely. If you must collect runtime data, use sampling or conditional logging so that normal execution stays fast.
When acceptable
Low-frequency events, developer builds, or gated diagnostics.
Avoid
High-frequency loops, many actors, or production builds with active prints.
Practical Tip
Wrap prints in a debug flag variable and ensure it is disabled during profiling. Use the Output Log for aggregated messages rather than many prints per frame.
Why it matters

Uncontrolled logging masks true performance data and can become the problem you are trying to solve.
