Efficient Iteration
Steps to reduce cost when working with large arrays or nested loops.
Filter First
Narrow the set before expensive operations. Use predicates or cached flags to skip irrelevant items.
Use Maps/Lookup
If you need direct access by key, switch arrays to Maps to avoid linear searches.
Chunk Work
Process parts across frames or on a timer to keep frame time bounded.
Concrete example: Instead of checking visibility against all AI agents every frame, maintain an 'activeAgents' array updated when agents move or when player position changes. Only iterate activeAgents for expensive pathfinding checks.
Common Mistakes
Running nested loops on Tick, not profiling the loop to confirm cost, and assuming fewer actors means no problem.
Check Your Understanding
How would you reduce work if only 10% of 1,000 elements need regular updates? Hint: maintain a list of 'dirty' items and update only those.
