Definition
Using Stat Commands
Quick console commands to triage frame-time issues during PIE.
Common commands
Stat FPS — shows FPS and frame time
Stat Unit — shows game/draw/GPU times
Stat Game — detailed game thread costs
Stat Blueprint — Blueprint execution time
Key Takeaway

Start with stat commands for fast triage, then capture a profiler session to dig deeper into node-level costs.

Example: Console Usage
{`// Open the in-editor console during PIE and type:`} Stat FPS Stat Unit Stat Game Stat Blueprint
Interpretation: If Stat Unit shows high game time, focus on CPU-side cost. If GPU time is high, look at meshes, materials, and draw calls instead.
