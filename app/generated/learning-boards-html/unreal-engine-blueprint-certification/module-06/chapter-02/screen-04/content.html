Core Concept
Performance Bottlenecks
A focused definition and a concrete example that illustrates how one costly pattern can dominate frame time.
Definition: A bottleneck is the element that limits the overall throughput or framerate. In Blueprints this often appears as a node or a set of nodes that regularly execute and are expensive. Example: placing a For Loop with 10,000 iterations inside Event Tick for a single actor seems expensive; multiply that by dozens of actors and every frame spends significant CPU time executing those iterations. Misconception: small operations are harmless. Reality: small per-frame costs multiplied across many objects or many frames become large costs.
Visual: Bottleneck Analogy
Busy Chef Analogy
If one chef must do every step for every dish, throughput suffers. Move repeatable tasks off the critical path to free the kitchen.
Indicator
Consistent frame spikes and high game thread time.
Pitfall
Assuming GPU is the problem when the game thread is the bottleneck.
Key Takeaway

Focus on the single largest consumer of frame time first. Profiling reveals the true bottleneck — not guesswork.
