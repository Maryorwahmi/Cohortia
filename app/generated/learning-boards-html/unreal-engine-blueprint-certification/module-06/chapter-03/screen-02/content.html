Learning Objectives
Skills you'll apply to bridge C++ and Blueprints
01
Interoperability

Explain how C++ forms the engine foundation and Blueprints extend it visually. Verified competency milestone

02
When to use C++

Identify performance or access needs that require C++ instead of Blueprints. Verified competency milestone

03
Expose members

Use UFUNCTION and UPROPERTY specifiers to expose functions and variables to Blueprints. Verified competency milestone

04
Blueprint events

Implement BlueprintImplementableEvent and BlueprintNativeEvent to let Blueprints add or override behavior. Verified competency milestone
