Module 6 › Chapter 6.3 › Learning Objectives — Practical Outcomes
Declare BlueprintCallable

Make C++ functions callable from Blueprint graphs so designers can trigger engine logic without C++ edits.

Control property access

Choose ReadWrite or ReadOnly to let Blueprints read or modify C++ state safely.

Implementable vs Native

Use implementable events for required Blueprint hooks, native for defaults designers can override.

Compile and test

Compile C++ after edits and bind events or dispatchers in Blueprint to verify behavior.
