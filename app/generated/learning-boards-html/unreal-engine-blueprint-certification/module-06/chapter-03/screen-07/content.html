Module 6 › Chapter 6.3 › Expose Variables
Principles
  • BlueprintReadWrite: allow read and write from Blueprints.
  • BlueprintReadOnly: allow read-only access to state.
  • EditAnywhere / VisibleAnywhere control editor visibility and editability.
Misconception

Marking everything ReadWrite leads to accidental coupling; prefer functions to mutate sensitive state.

Key Takeaway

Expose minimal state. Use properties for values, functions for controlled changes.

Code example
// MyCharacter.h
UCLASS()
class MYGAME_API AMyCharacter : public ACharacter
{
    GENERATED_BODY()

public:
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category = "Character Stats")
    float MaxHealth;

    UPROPERTY(VisibleAnywhere, BlueprintReadOnly, Category = "Character State")
    bool bIsDead;
};
EditAnywhere allows designers to set defaults in the editor. VisibleAnywhere shows runtime values without making them editable.
