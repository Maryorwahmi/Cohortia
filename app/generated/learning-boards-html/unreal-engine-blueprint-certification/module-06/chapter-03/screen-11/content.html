Module 6 › Chapter 6.3 › Event Dispatchers
Pattern

Declare dynamic multicast delegates in C++, mark them BlueprintAssignable, and broadcast from C++ when state changes occur.

When to use
  • To notify UI, VFX, or other Blueprint systems of state changes.
  • For decoupled systems where listeners subscribe at runtime.
Performance note: dynamic delegates are convenient for Blueprint binding but consider direct calls for hot paths.
HealthComponent snippet
DECLARE_DYNAMIC_MULTICAST_DELEGATE_TwoParams(FOnHealthChanged, float, CurrentHealth, float, MaxHealth);
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnTakeDamage, float, DamageAmount);

UPROPERTY(BlueprintAssignable, Category = "Health")
FOnHealthChanged OnHealthChanged;

UPROPERTY(BlueprintAssignable, Category = "Health")
FOnTakeDamage OnDamageTaken;

// Broadcast when health changes
OnHealthChanged.Broadcast(CurrentHealth, MaxHealth);
In Blueprint: bind to OnHealthChanged and update UI or play sound when broadcasted.
