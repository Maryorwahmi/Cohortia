Module 6 › Chapter 6.3 › When to prefer C++ over Blueprints
C++ — Use when
  • Performance is paramount: heavy math, large loops, fixed-timestep updates.
  • Access to low-level engine APIs or third-party libraries is required.
  • Defining core base classes for consistency across the project.
  • Large teams need stricter version control and code review workflows.
Example: pathfinding, physics helpers, or inventory back ends.
Blueprints — Use when
  • Rapid iteration on gameplay feel or visual responses.
  • Designer-driven tuning without a C++ compile step.
  • Small logic and event wiring with low-frequency calls.
Misconception check

Not every function belongs in C++; small gameplay wiring in Blueprints is fine and often faster for iteration.
