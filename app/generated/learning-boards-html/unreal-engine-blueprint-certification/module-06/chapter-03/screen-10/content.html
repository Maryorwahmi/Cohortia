Module 6 › Chapter 6.3 › BlueprintNativeEvent
Pattern

Declare UFUNCTION(BlueprintNativeEvent) in the header and provide _Implementation in the .cpp for the default behavior.

Parent Call

Blueprint overrides can call the parent C++ implementation explicitly using Parent Call if they want both behaviors.

Misconception: overriding always runs C++ default — it runs only if the Blueprint calls the parent explicitly.
Code example
// MyDoor.h
UCLASS()
class MYGAME_API AMyDoor : public AActor
{
    GENERATED_BODY()

public:
    UFUNCTION(BlueprintNativeEvent, Category = "Door")
    void OpenDoor();

    // The _Implementation method defines the C++ default
    void OpenDoor_Implementation();
};

// MyDoor.cpp
void AMyDoor::OpenDoor_Implementation()
{
    UE_LOG(LogTemp, Warning, TEXT("C++ Default OpenDoor called!"));
    // Default rotation logic
}
In Blueprint override: add Parent Call to invoke C++ default, or omit to replace it entirely.
