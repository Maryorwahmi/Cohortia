Module 6 › Chapter 6.3 › BlueprintImplementableEvent
What it is

A function declared in C++ with no native implementation. Blueprints implement it as an Event node.

When to use
  • When C++ triggers events that are presentation-specific.
  • When each Blueprint subclass should supply unique visual behavior.
Misconception: Implementable events do not provide a C++ fallback.
Code & example
// MyWeapon.h
UCLASS()
class MYGAME_API AMyWeapon : public AActor
{
    GENERATED_BODY()

public:
    UFUNCTION(BlueprintImplementableEvent, Category = "Weapon")
    void OnWeaponFired(); // Blueprint implements this

    void Fire(); // C++ calls OnWeaponFired
};

// MyWeapon.cpp
void AMyWeapon::Fire()
{
    // C++ logic for firing (raycast, ammo reduction)
    OnWeaponFired(); // Call the Blueprint-implemented event
}
In Blueprint subclass: implement Event OnWeaponFired and add particle or sound nodes.
