Module 6 › Chapter 6.3 › Expose Functions
Concept

UFUNCTION with BlueprintCallable exposes actions to Blueprint graphs. BlueprintPure marks read-only queries.

  • Declare in header with the proper specifier and Category for organization.
  • Implement in the .cpp file and compile the project.
  • Document whether the function mutates state to guide designers.
Pro tip

Group Blueprint-exposed functions into coherent categories for editor discoverability.

Code example
// MyCharacter.h
UCLASS()
class MYGAME_API AMyCharacter : public ACharacter
{
    GENERATED_BODY()

public:
    UFUNCTION(BlueprintCallable, Category = "Character Actions")
    void MyCustomCPlusPlusFunction();

    UFUNCTION(BlueprintCallable, BlueprintPure, Category = "Character Info")
    float GetCurrentHealth() const;
};

// MyCharacter.cpp
void AMyCharacter::MyCustomCPlusPlusFunction()
{
    // C++ logic here
    UE_LOG(LogTemp, Warning, TEXT("MyCustomCPlusPlusFunction called from Blueprint!"));
}

float AMyCharacter::GetCurrentHealth() const
{
    return HealthComponent->GetCurrentHealth();
}
Remember to compile so Blueprint nodes appear. Use Category to organize nodes in the editor.
