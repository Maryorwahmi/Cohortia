Module 6 › Chapter 6.3 › Compile & Verify
Step-by-step
  1. Declare UFUNCTION / UPROPERTY with Category and desired specifiers in the header.
  2. Implement behavior in the .cpp file and initialize properties where needed.
  3. Compile the C++ project in your IDE or use the editor Compile button.
  4. Refresh or re-open Blueprints and check the context menu and details panel.
  5. Test nodes and bindings, iterate on signatures and access control.
Editor tip
Use Category to group functions logically for designers.
Error handling
Read the compile output log to find missing includes or syntax errors.
Check your understanding

After compiling, does the function show in the Blueprint context menu and is the property visible in the details panel?
