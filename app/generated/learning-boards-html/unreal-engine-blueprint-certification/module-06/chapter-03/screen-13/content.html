Warning › Debugging & Compilation
Common issues
  • Missing includes or Generated.h in the header prevents reflection processing.
  • Syntax errors in headers block UnrealHeaderTool and stop code generation.
  • Incorrect specifier choice confuses intended behavior between implementable and native events.
  • Forgetting to compile means Blueprints won't see new nodes or properties.
Debug tip
Use the compiler and editor logs; they usually point to the problematic file.
Repair flow
Reduce the header to minimal content, recompile, then add declarations back incrementally.
Try this

If a Blueprint node is missing, recompile and check the header for syntax or reflection macro issues before changing Blueprints.
