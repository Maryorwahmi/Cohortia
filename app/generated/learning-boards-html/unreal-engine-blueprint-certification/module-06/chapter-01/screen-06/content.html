Module 6 › Chapter 6.1 › Maps & Sets
Map — key → value
Efficient lookups by unique key

Map<FName, FInventoryItem> provides immediate access to an item by its name, avoiding full Array scans.

Common operations: Add, Remove, Find (by key)
Use when lookups by identifier are frequent.
Set — unique elements
Track presence without duplicates

Sets automatically prevent duplicates and are ideal for flags like active effects or visited nodes. Order is not preserved.

Common operations: Add, Remove, Contains, Union
Misconception: Sets are not ordered lists; they are about uniqueness.

Key Takeaway
Maps for keys, Sets for uniqueness, Arrays for order. Pick based on required behavior.
