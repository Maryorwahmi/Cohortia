Module 6 › Chapter 6.1 › Key Concepts
Enum (Enumeration)
A named set of integer constants that constrain valid choices and clarify logic.
Struct (Structure)
A composite type that groups related fields into a single variable for easy passing and storage.
Array
An ordered collection that allows duplicates and supports iteration and indexed access.
Summary

Use these types together to design data ownership and reduce coupling across Blueprints.
