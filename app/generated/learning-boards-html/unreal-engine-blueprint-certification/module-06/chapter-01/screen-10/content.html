// Input Action Interact (Pressed)

//   Call Interact (Message) on InteractableActor

// BP_PickupItem - Implement BPI_Interactable
// On Interact:
//   Create FInventoryItem
//   Cast to Player Character
//   Add to Player.Inventory (Array of FInventoryItem)
//   Call Player.OnInventoryUpdated (Event Dispatcher)
//   Destroy Actor
Checklist
  • Create FInventoryItem Struct with the specified fields.
  • Add Inventory: Array of FInventoryItem to Player.
  • Create OnInventoryUpdated Event Dispatcher and Bind in UI.
Key Takeaway

Wire interactions via interfaces and broadcast state changes with dispatchers to keep systems decoupled and testable.
