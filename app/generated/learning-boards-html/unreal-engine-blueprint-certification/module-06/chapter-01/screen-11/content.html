Module 6 › Chapter 6.1 › Inventory Architecture
Components
  • Data: FInventoryItem Struct defines item fields.
  • Storage: Player has Inventory Array and possibly a Map for lookups.
  • Interaction: BP_PickupItem implements BPI_Interactable to add items.
  • Notification: Player exposes OnInventoryUpdated Event Dispatcher for listeners.
  • Presentation: UI binds to dispatcher and refreshes display.
Example Extension
Maintain Map<FName, FInventoryItem> alongside Array to support quick item searches by ID while preserving display order in the Array.
Key Takeaway

Architect your Blueprints around data owners and message channels so features can extend without brittle coupling.

Common error
Putting UI logic inside pickups or directly referencing many UI actors from gameplay actors increases coupling and maintenance work.
