Module 6 › Chapter 6.1 › Choose Collections
Step 1 — Do you need order?
Yes → Array. No → go to Step 2.
Step 2 — Must elements be unique?
Yes → Set. No → go to Step 3.
Step 3 — Need fast lookup by ID?
Yes → Map. Otherwise an Array is fine for small or rarely-searched lists.
Scenario
Inventory system choice
If you display items in pages and preserve order, use Array<FInventoryItem>. If you often retrieve an item by unique name or id, maintain Map<FName, FInventoryItem> alongside an Array for ordering. If you need to know whether a buff is active at most once, use Set<FName>.
Key Takeaway

Mix structures when necessary: Structs group fields; Arrays maintain order; Maps give fast keys; Sets enforce uniqueness.
