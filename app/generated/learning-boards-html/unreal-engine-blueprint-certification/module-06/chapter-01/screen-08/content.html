Module 6 › Chapter 6.1 › Blueprint Interfaces
Core Idea
Interface = contract of functions

Any Blueprint that implements the interface must provide the functions declared, allowing message-style calls without knowing concrete classes.

Concrete Example
Create BPI_Interactable with Interact. Implement it on BP_PickupItem, BP_Door, and BP_NPC so the player Can call Interact generically.
Why it matters
Interfaces reduce tight coupling and eliminate repetitive casts, making it easy to add new interactive object types without changing player logic.
Common mistake
Overusing interfaces for one-off interactions where a simple reference would be clearer. Use interfaces for shared, cross-class behavior.
Key Takeaway

Interfaces provide polymorphism in Blueprints; use them to call behavior on many actor types without casting.
