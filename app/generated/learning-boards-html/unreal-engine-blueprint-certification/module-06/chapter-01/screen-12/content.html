Module 6 › Chapter 6.1 › Lab Activity
Step 1 — Create Struct
Create FInventoryItem with the required fields in the Content Browser under Blueprints.
Step 2 — Add Inventory & Dispatcher
Add Inventory: Array of FInventoryItem to Player and create OnInventoryUpdated Event Dispatcher on Player.
Step 3 — Interface & Pickup
Create BPI_Interactable with Interact and implement it on BP_PickupItem. In Interact, add item, call dispatcher, and destroy actor.
Step 4 — Bind and Test
Bind Event to OnInventoryUpdated on Player BeginPlay and print item names in the bound handler. Place pickups in level and test interaction.
Key Takeaway

This lab connects type-safe data with decoupled messaging so gameplay changes remain easy to extend and debug.
