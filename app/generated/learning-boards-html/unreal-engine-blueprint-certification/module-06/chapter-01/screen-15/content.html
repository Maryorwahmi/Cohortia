Module 6 › Chapter 6.1 › Key Concepts
Map
Key-value store for fast lookup by unique identifier; useful for item metadata retrieval.
Set
Unordered, unique collection ideal for presence checks and preventing duplicates.
Blueprint Interface
A contract enabling polymorphic calls to different Blueprints that implement the same functions.
Closing Summary

Combine these tools thoughtfully: group data with Structs, select the right collection for behavior, and use Interfaces and Dispatchers to keep Blueprints decoupled and scalable.
