Module 6 › Chapter 6.1 › Arrays
Core Concept
Array — ordered collection of same-type elements
  • Add, Remove Index, Get (copy), Get (ref), For Each Loop, Length are common operations.
  • Use Get (ref) to mutate elements directly; use Get (copy) when you just need data.
  • Arrays allow duplicates and preserve element order.
Key Takeaway

Arrays are your go-to for sequences, lists, and ordered inventories; consider Maps for frequent keyed lookups.

Example
Player Character has Inventory: Array of FInventoryItem. On pickup, Add new FInventoryItem. To print items, use For Each Loop and print ItemName.
Common mistake
Using an Array for frequent lookups by ID instead of a Map; this leads to repeated loops and poorer performance.
Try this
// Blueprint pattern (pseudocode)
// Inventory: Array of FInventoryItem
Add(Item)
ForEachLoop(Inventory) -> Print(Item.ItemName)
If need fast lookup by name often, consider Map<FName, FInventoryItem>
