Module 6 › Chapter 6.1 › Enums & Structs
Definition
Enum — finite named choices

An Enum defines a closed set of named integers. Use it when a variable should only hold one of a small set of valid values.

Example: EWeaponType → Pistol, Rifle, Shotgun
Misconception: Enums are not just labels; they prevent invalid numeric states.
Definition
Struct — grouped fields

A Struct bundles related variables into a single type so you can pass one object instead of many separate variables.

Example: FInventoryItem with ItemName, ItemIcon, ItemQuantity, ItemDescription
Pro tip: Add fields to Structs to evolve your data without reworking every function signature.
Concrete Example
Inventory Struct Example
FInventoryItem { ItemName: FName, ItemIcon: Texture2D, ItemQuantity: Integer, ItemDescription: Text }
Key Takeaway

Enums constrain valid values; Structs simplify passing grouped data across Blueprints.
