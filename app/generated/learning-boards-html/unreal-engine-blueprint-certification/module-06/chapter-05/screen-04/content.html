Module 6 › Chapter 6.5 › Exam Structure
Definition
Exam Coverage

The certification checks practical Blueprint usage across logic, OOP patterns, gameplay framework, UI, AI, debugging, and asset management.

Formats to Expect
  • Multiple-choice for concept checks.
  • Scenario analysis asking for the best Blueprint pattern.
  • Debugging snippets requiring root-cause identification.
Key Takeaway

Answers that show understanding of trade-offs — coupling, performance, and maintainability — are preferred.

Concrete Example — Debugging Scenario
Problem: An AI updates target location every tick causing slowdowns. Best fix: move updates to a timed Service or only update when significant change occurs. Avoid recommending broad actions like 'optimize project settings' which miss the local logic issue.
Misconception: Choosing the fastest-sounding option rather than the decoupled, maintainable pattern often leads to incorrect selections.
Checklist for Scenario Questions
  • Identify required effect (what must happen).
  • List constraints (performance, coupling, reusability).
  • Sketch minimal Blueprint that respects constraints.
  • Choose solution that minimizes side effects and maximizes reuse.
Common Mistake

Favoring direct casts everywhere instead of interfaces or dispatchers can produce brittle designs — exam questions often penalize that brittleness.
