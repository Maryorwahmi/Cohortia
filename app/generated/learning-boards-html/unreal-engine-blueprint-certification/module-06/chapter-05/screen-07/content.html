Git Essentials (practice)
  • git add — stage files to commit.
  • git commit — record a snapshot with a message.
  • git push / git pull — sync with remote repositories.
  • git branch — work on features or experiments safely.
Remember .gitignore targets: Binaries, Build, DerivedDataCache, Intermediate, Saved.
Document Blueprints
Use comment boxes for complex node groups; add descriptions on variables and functions so intent is visible during reviews and exams.
Concrete habit: after fixing logic, add a comment with the bug summary and the reasoning behind the fix.
Modular Design Patterns
Refactor repeated logic into functions, macros, or Actor Components. Use Blueprint Interfaces or Event Dispatchers to avoid tight coupling. Modular systems are easier to test and explain during an exam scenario.
Try this now
Initialize a local Git repo, commit the current project, then refactor a Blueprint into separate functions and make a descriptive commit. This sequence proves you can both change and record project history.
