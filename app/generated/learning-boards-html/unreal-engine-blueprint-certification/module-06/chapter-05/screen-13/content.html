Exam-time tactics
Pace, flag, and move on when needed
  1. Read questions fully; underline or note keywords like "most efficient" or "decoupled."
  2. If stuck, answer the best reasoned option and flag if review is allowed.
  3. Simulate exam scenarios locally: practice debugging and refactoring with a timer.
Portfolio checklist
  • Three small, complete projects with clear goals and readme notes.
  • Repository with meaningful commits and a short demo video or screenshots.
  • Document design decisions, naming conventions used, and key Blueprint patterns.
Key Takeaway

Practice under timed conditions and present small, well-documented projects that highlight Blueprint clarity and professional habits.

Sample portfolio entry
Title: Puzzle Chamber
  • Short description of mechanics and Blueprint structure.
  • Folder map showing Content/Blueprints/Characters, /UI, /AI.
  • Key commits: initial prototype, refactor naming, add comments, fix bug.
Version control note
Include a short note about your .gitignore choices (exclude Binaries, Intermediate, Saved) and initial commit that establishes structure and naming conventions.
Motivational close
Small, polished work communicates discipline. Build, finish, document, and iterate.
