  • Blueprints

  • Audio
Naming Conventions (examples)
BP_PlayerCharacter, WBP_HealthBar, BT_EnemyAI, T_GroundTexture, M_PlayerMaterial. Keep names descriptive and consistent.
Refactor Steps
  1. Create folders and move assets in small batches.
  2. Verify references and fix broken links after each batch.
  3. Rename using a consistent prefix strategy.
Concrete Example — Before & After
Before: many assets at Content root with names like 'Player', 'health_ui', 'enemy_tree'. After: Blueprints/Characters/BP_PlayerCharacter, UI/WBP_HealthBar, AI/BehaviorTrees/BT_EnemyAI.
This makes searching by prefix and folder predictable during an exam or review.
Pitfall

Avoid too many nested folders; deep trees can hide assets and slow you down. Balance clarity with accessibility.

Key Takeaway

Consistent prefixes and a shallow, logical folder layout save time and reduce exam errors caused by missing assets or wrong references.
