Quick Reference — Common Pitfall
Using Event Tick for frequent, heavy calculations is a frequent source of performance issues. Replace with timed Services, conditional updates, or event-driven triggers. In exam scenarios, identify 'Event Tick' or perpetual loops as likely culprits for performance questions.
