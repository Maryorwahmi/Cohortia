Mnemonic: House and Rooms
Think of the program as a house. The global scope is the whole house. Each function is a room with its own local items that do not leave the room unless explicitly shared.
Why this matters
Predicting where a name resolves prevents bugs and guards against accidental state change across the program.
Practice idea
Run a snippet that assigns inside a function and compare prints inside and outside the function to see the difference.
