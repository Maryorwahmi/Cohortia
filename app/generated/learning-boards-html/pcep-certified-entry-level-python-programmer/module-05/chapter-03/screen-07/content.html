Module 5 › Chapter 5.3 › Reading globals
Example: read-only access
global_variable = "I am a global variable"

def another_function():
    print(global_variable)  # reads the global successfully

another_function()
print(global_variable)
This code shows reading a global works inside a function without any special declaration because there is no assignment inside the function that would create a local.
UnboundLocalError trap
If you try to update a global by assigning to its name inside the function without declaring it global, Python assumes the name is local and the earlier read fails. That causes an UnboundLocalError. The solution is to either declare global or change the design to pass and return the value.
Common mistake

Trying to increment a global inside a function with a direct assignment without declaring it global leads to an error.
