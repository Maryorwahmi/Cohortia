Module 5 › Chapter 5.3 › Assessment
Sample question
x = 10

def my_func():
    x = 20
    print(x)

my_func()
print(x)
Predict the two printed values, then run the code. Write a short explanation of why the global x remains 10 after the function call.
Answer guide
Function prints 20; global print shows 10. The assignment creates a local x inside the function.
Key Takeaway

Explain why each incorrect option fails to update the global — that reasoning reinforces scope understanding.
