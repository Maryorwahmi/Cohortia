Module 5 › Chapter 5.3 › Practical Reminders
Assigns create locals
Any assignment inside a function binds a local name unless declared global.
Read globals freely
Functions can read module-level names without special declarations.
Prefer explicit data flow
Pass parameters and return values; reserve global for clear, documented shared state.
Final thought

When in doubt, predict the output and then run the code. That quick experiment is the fastest way to verify your mental model of scope.
