Practice cards
Explain scope
Write a function with a local variable, call it, and attempt to access the name afterwards to see it is not defined.
Differentiate
Access a global variable inside a function for reading, then try to assign to it and observe the result.
Apply LEGB
Create names at different scopes and predict which one is used when referenced.
Use global
Implement a counter with and without global to see when the module-level value changes.
Verification
Each practice includes a printed output you can predict before running the code. Correct prediction equals verified competency. Use the provided hands-on template to try the global vs local update for a counter or score variable.
Quick check
Predict the output of a function that assigns to a name also defined globally. Then run and compare.
