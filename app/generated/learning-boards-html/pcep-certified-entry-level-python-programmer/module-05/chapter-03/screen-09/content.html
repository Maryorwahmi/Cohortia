Exercise template
score = 100  # Global variable

def award_points_local():
    # local_score shows the effect without changing global
    local_score = score + 10
    print(f"Inside award_points_local (local_score): {local_score}")

def award_points_global():
    global score
    score += 10
    print(f"Inside award_points_global (global score modified): {score}")

print(f"Initial global score: {score}")

award_points_local()
print(f"Global score after award_points_local: {score}")

# Call award_points_global() and print global score again to observe change
Predict
Before running, predict the printed values after each call to confirm your understanding.
Observe
The first call prints a local updated value; the global remains unchanged until award_points_global runs with global declared.
Key Takeaway

Use prediction plus observation to internalize how scope affects program state changes.
