Module 5 › Chapter 5.3 › Local vs Global
Local variables (inside functions)
  • Created when the function runs and typically destroyed afterwards.
  • Multiple functions can safely use the same local name without collision.
  • Assignment inside a function creates a local name by default.
Example
A loop index or temporary calculation should often be local to the function using it.
Global variables (module level)
  • Defined at top-level and persist for the program's runtime.
  • Readable inside functions without special declarations.
  • To assign to a global inside a function, declare it with the global keyword first.
Example
Configuration flags or a shared counter that many functions read from may be global, but modify with care.
Common-mistake
Assigning inside a function thinking it changes the global leaves the global unchanged, because the assignment creates a local instead.
Pro tip
When in doubt, pass values as parameters and return results rather than relying on globals.
Key Takeaway

Prefer local state and data flow through parameters; use global only for clearly shared configuration with controlled modification.
