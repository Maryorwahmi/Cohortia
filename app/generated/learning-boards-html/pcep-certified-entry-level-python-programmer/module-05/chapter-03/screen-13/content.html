Enclosing scope (nested functions)
When functions are nested, an inner function can read names from an outer function's scope. This is the Enclosing level in LEGB and is how closures capture values. Assignment into an enclosing scope requires a nonlocal declaration, which is different from global and affects only enclosing function scopes.
Built-in scope
If a name is not found in Local, Enclosing, or Global, Python checks built-in names before raising NameError. Avoid shadowing built-ins by choosing clear variable names.
Check
If you see nested functions, be explicit about where assignments should bind: local, nonlocal, or global. That reduces surprises and clarifies intent.
