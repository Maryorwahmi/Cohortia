Module 5 › Chapter 5.3 › What is variable scope?
Definition and significance
  • Scope is the region in which a variable name maps to a value.
  • Local variables exist inside functions and usually disappear after execution.
  • Global variables are defined at module level and are visible across functions for reading.
  • Scope prevents unintended interactions between separate parts of a program.
Key Takeaway

Think of local names as private to a function. Global names sit on a shared shelf for reading unless explicitly modified.

Concrete example
def my_function():
    local_variable = "I am local to my_function"
    print(local_variable)

my_function()
# print(local_variable)  # NameError: local_variable is not defined in global scope
Why this shows scope
The name local_variable is created and used only inside the function; outside it is undefined.
Common mistake
Assuming the name will persist after the function ends leads to NameError when accessed globally.
