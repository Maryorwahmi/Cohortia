Module 5 › Chapter 5.3 › LEGB Rule
LEGB: ordered steps
Local: current function scope.
Enclosing: any outer function scopes when functions are nested.
Global: module-level names.
Built-in: Python's standard names like print, len, str.
Quick check
If the same name exists in two scopes, the one found earlier in LEGB is used.
Concrete scenario
name = 'global'

def outer():
    name = 'enclosing'
    def inner():
        print(name)  # prints 'enclosing' due to Enclosing in LEGB
    inner()

outer()
Misconception
An inner function cannot reassign an enclosing variable unless nonlocal is used; assignment without declaration creates a local name.
