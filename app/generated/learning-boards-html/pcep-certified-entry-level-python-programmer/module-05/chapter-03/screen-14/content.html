Module 5 › Chapter 5.3 › Key Concepts
Variable Scope
The region of a program where a name is recognized and can be accessed.
Local vs Global
Locals are function-bound and short-lived; globals are module-bound and visible for reading by functions.
LEGB Rule
Python searches Local, Enclosing, Global, Built-in in that order when resolving names.
Summary takeaway

Predict name resolution using LEGB, avoid accidental assignment that creates locals, and use global only when shared mutable state is necessary.
