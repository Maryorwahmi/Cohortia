Module 5 › Chapter 5.2 › Mixing Arguments
Rule illustrated
Valid: describe_pet('cat', pet_name='whiskers')
Invalid: describe_pet(pet_name='whiskers', 'cat') — SyntaxError
Design tip

Place required parameters first, then optional parameters with defaults. Callers can then use simple positional calls for required data and keywords for optional overrides.

Supporting steps
  1. Read the function signature to identify required vs defaulted parameters.
  2. Call with positional values for required parameters only.
  3. Use keyword arguments to override specific default parameters as needed.
