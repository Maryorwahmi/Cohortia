Module 5 › Chapter 5.2 › Overriding Defaults
Pattern: defaults then overrides
  • Place defaults after required parameters so calls remain natural.
  • Use keyword arguments to override defaults for clarity.
  • Test both default and override paths in your code.
Example override
def display(value, format='text'):
    # default behaviour
    pass

# override default format
display(123, format='json')
Supporting guidance

Avoid hidden side effects in defaults. If a default triggers heavy work, consider making that behavior explicit to the caller to avoid surprising performance costs.

Pro tip

When in doubt, prefer a clear explicit parameter over a complex implicit default. Simpler calls are easier to reason about later.
