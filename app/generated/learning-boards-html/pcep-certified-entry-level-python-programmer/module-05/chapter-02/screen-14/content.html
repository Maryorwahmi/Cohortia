Signature layout
  1. Required positional parameters: values every caller must provide.
  2. Defaulted parameters: optional values with sensible defaults.
  3. Keyword-only parameters: explicit named configuration when needed.
Return strategy

Return tuples for fixed positional results. Use dictionaries or objects when returned data benefits from named access or may evolve.

Checklist
  • Do parameter names communicate meaning?
  • Are defaults documented and sensible?
  • Can callers use keywords to reduce ambiguity?
