01
Differentiate parameters and arguments

Recognize parameter names in a function signature and match them to values passed at call time. This reduces confusion between declaration and invocation.

VERIFIED COMPETENCY MILESTONE
02
Use positional and keyword arguments

Apply positional arguments when order is natural and keyword arguments when you want clarity or reorderability. This prevents swapped-value bugs.

VERIFIED COMPETENCY MILESTONE
03
Define default parameter values

Set sensible defaults in function definitions so callers can omit common arguments, simplifying the API and reducing repetition.

VERIFIED COMPETENCY MILESTONE
04
Return multiple values as tuples

Pack results into a single return using a tuple and unpack them at the call site for clear, lightweight multiple returns.
