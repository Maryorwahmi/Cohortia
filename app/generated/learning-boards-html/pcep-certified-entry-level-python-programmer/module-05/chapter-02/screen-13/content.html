Module 5 › Chapter 5.2 › Common Mistakes
Logical errors (silent)

Swapping positional arguments produces wrong output without raising an exception. Verify by calling with keywords to see the intended mapping.

Example
describe_pet('harry', 'hamster')  # runs but yields incorrect meaning
Syntax errors (immediate)

Placing a positional argument after a keyword argument causes a SyntaxError. Fix by moving positionals before keywords.

Example
describe_pet(pet_name='whiskers', 'cat')  # SyntaxError
Mutable default pitfall

Avoid lists or dicts as default parameters unless you intentionally want shared state across calls. Use None and create a new object inside the function instead.

Quick checklist
  • Read the signature first.
  • Test with keyword calls to check mapping.
  • Match unpack targets to return structure.
