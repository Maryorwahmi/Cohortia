Module 5 › Chapter 5.2 › Positional Arguments
Two examples: correct and swapped
Correct order
describe_pet('hamster', 'harry')
# prints: I have a hamster. My hamster's name is Harry.
Swapped order (logical bug)
describe_pet('harry', 'hamster')
# prints misleading sentences even though code runs
Guidance

Prefer positional for short functions where parameter order is obvious. For longer signatures, prefer keywords to avoid accidental swaps.

Supporting notes
  • Positional calls are concise and common for simple functions.
  • They produce logical errors if you misorder values of the same type.
  • To verify intent, rewrite a positional call as a keyword call and compare outputs.
