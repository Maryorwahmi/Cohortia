Example: named arguments
describe_pet(pet_name='harry', animal_type='hamster')
# order does not matter; naming ensures correct mapping
When to use

Prefer keywords for functions with many parameters, optional settings, or when values are not naturally ordered. They make calls self-documenting.

Mixing with positional args

You can combine positional and keyword arguments, but positional ones must appear first. For example, describe_pet('cat', pet_name='whiskers') is valid. Reversing that order causes a syntax error.

Common misconception

Keywords are not less efficient; they are a readability tool. Use them where they reduce ambiguity.
