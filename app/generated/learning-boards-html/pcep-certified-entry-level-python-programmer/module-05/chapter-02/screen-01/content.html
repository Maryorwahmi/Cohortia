Module 5 › Chapter 5.2 › Overview
Parameters, Arguments, and Return Values
A practical guide to passing data into functions and getting results back
In this lesson

Differentiate parameters and arguments. Practice positional and keyword styles. Use defaults. Return and unpack multiple values as tuples.

Why it matters

Clear signatures make code readable, prevent logical errors from swapped inputs, and let you design functions that are easy to call and reuse.

How to use this chapter

Follow examples, run the provided code snippets, and try the BMI activity to practice defaults and unpacking returns.
