Module 5 › Chapter 5.2 › Parameters vs Arguments
Clear definitions
  • Parameter: the name listed in a function definition, a local variable placeholder.
  • Argument: the actual value supplied when calling the function, assigned to the parameter.
  • Mental model: parameter = slot, argument = thing you put into the slot.
Example
def describe_pet(animal_type, pet_name):
    print(f"I have a {animal_type}.")
    print(f"My {animal_type}'s name is {pet_name.title()}.")

# animal_type and pet_name are parameters
# 'hamster' and 'harry' are arguments
describe_pet('hamster', 'harry')
Key Takeaway

When debugging, check whether the mistake is in the parameter names or the arguments supplied; they are distinct responsibilities.

Common misconception

People sometimes call arguments "parameters" and vice versa. This confusion leads to changing the wrong part of the code. Always map signature names to call values to avoid this error.

Try this
Swap the two arguments in the example and observe how the meaning changes even though the code still runs. That shows parameters control meaning, not execution.
Why it matters

Distinguishing them helps you write clearer APIs and prevents silent logical errors caused by swapped values or incorrect assumptions about what a function expects.
