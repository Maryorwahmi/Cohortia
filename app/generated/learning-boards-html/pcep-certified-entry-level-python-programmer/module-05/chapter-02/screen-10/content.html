Example: returning a tuple
def get_user_info(first_name, last_name, age):
    full_name = f"{first_name.title()} {last_name.title()}"
    return full_name, age  # returns a tuple (full_name, age)

user_data = get_user_info('john', 'doe', 30)
print(f"User data: {user_data}")
# Output: User data: ('John Doe', 30)
When to use tuples
  • Use tuples for a fixed set of returned values with positional meaning.
  • Use dictionaries if callers need to access results by name.
  • Remember the function returns a single object: the tuple.
