Module 5 › Chapter 5.4 › Name Collisions
Problem example
# bad practice
from utils import *
from helpers import *

# Which module defined format_text? Hard to tell and easy to clash.
Safer alternatives
  • import utils; result = utils.format_text(...)
  • from utils import format_text # explicit single name
  • Use aliases to disambiguate when necessary.
Developer checklist

Make imports explicit, keep public names documented, and avoid wildcard imports in reusable libraries.
