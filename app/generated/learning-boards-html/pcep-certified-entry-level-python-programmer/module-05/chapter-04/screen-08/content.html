Package structure
my_project/
├── main.py
└── calculations/
    ├── __init__.py
    ├── basic_ops.py
    └── advanced_ops.py
The presence of __init__.py marks the directory as a package; you can import modules using dotted names that show their package path.
Import examples
Use from calculations import basic_ops or from calculations.basic_ops import add depending on how you want to reference the code.
Design note

Decide which names belong in __init__.py to present a simple, consistent API for package users.
