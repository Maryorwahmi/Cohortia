Practical checklist
  • Move related helpers into a module file with a clear name.
  • Keep import-time side effects minimal; use a main guard for examples.
  • Prefer explicit imports for clarity; avoid indiscriminate wildcard imports.
  • Use aliases sparingly to shorten long module names or resolve name conflicts.
VERIFIED COMPETENCY MILESTONE
Mnemonic
Think 'SAPM' — Split, Arrange, Prefix, Main-guard: split code, arrange files, prefix imports clearly, add main guard for runnable examples.
