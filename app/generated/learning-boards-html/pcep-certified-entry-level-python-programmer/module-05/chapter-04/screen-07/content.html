Module alias example
# main.py
import math_operations as mo
from math_operations import add as plus_func

result_add_alias = mo.add(3, 2)
result_plus = plus_func(8, 4)
Aliases shorten repetitive calls and help resolve name conflicts when necessary.
When to alias
  • Long module names you call frequently.
  • Resolve name collisions between modules and local names.
  • Adopt common community aliases when they add clarity.
Pro tip

Use short, meaningful aliases and document non-obvious choices so collaborators are not surprised.
