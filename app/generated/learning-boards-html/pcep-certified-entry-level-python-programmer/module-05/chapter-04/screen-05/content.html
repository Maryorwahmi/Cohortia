Code walkthrough
# main.py
import math_operations

result_add = math_operations.add(10, 5)
result_sub = math_operations.subtract(10, 5)
print(f"Addition: {result_add}, Subtraction: {result_sub}")
This code clearly shows where add and subtract come from, which is useful when many modules may define similar names.
Why prefer this form?
  • Prevents name clashes by namespacing members.
  • Makes code origins explicit for readers and debuggers.
  • Import runs top-level setup once, avoiding repeated work.
Common misconception

Importing a module copies code into your file. In reality Python loads the module once and binds a reference to it.
