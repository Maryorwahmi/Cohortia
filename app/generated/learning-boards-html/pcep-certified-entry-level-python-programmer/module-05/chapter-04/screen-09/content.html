Module 5 › Chapter 5.4 › Importing from Packages
Example — module import
# main.py
from calculations import basic_ops
print(basic_ops.add(1, 2))

# or import directly
from calculations.basic_ops import add
print(add(1, 2))
Tip
If you expose common names at the package level, users can import them with from calculations import add for a simpler surface.
Key Takeaway

Dotted imports map the file system to import paths. Keep package __init__ minimal and intentional.
