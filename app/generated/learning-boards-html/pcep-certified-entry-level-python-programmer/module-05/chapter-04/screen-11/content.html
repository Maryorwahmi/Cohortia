greetings.py (starter)
# greetings.py
def say_hello(name):
  print(f"Hello, {name}!")

def say_goodbye(name):
  print(f"Goodbye, {name}!")

if __name__ == '__main__':
  print("Running greetings.py directly...")
  say_hello("Test User")
  say_goodbye("Test User")
main_app.py (starter)
# main_app.py
import greetings

# Use greetings functions without running the module's test block
greetings.say_hello("Cohortia Learner")
greetings.say_goodbye("Cohortia Learner")
Check your understanding
Run main_app.py and notice that only the greetings called from main_app.py print. Then run greetings.py directly to see the test prints from the main guard. This confirms the difference between import and direct execution.
