Module 5 › Chapter 5.4 › What is a Module?
Definition
A module is a Python file named with the .py extension that contains related functions, classes, or variables and can be imported by other files.
Key points:
  • Module name equals filename without .py.
  • Importing does not copy code; it executes top-level statements once and binds the module object.
  • Avoid heavy work at import time to keep imports cheap and predictable.
Key Takeaway

Use modules to group related code and make functions reusable without duplication.

Example module
# math_operations.py
def add(a, b):
  return a + b

def subtract(a, b):
  return a - b
Analogy
Treat a module like a toolbox. Each function inside is a tool you call by referencing the toolbox name, keeping your workspace tidy.
