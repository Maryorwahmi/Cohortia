Direct import example
# main.py
from math_operations import add, subtract

result = add(20, 7)
print(f"Addition directly: {result}")
Advantages
  • Less typing and clearer local calls.
  • Good for small scripts and tests where names are controlled.
Warning
from module import * hides where names come from and can cause collisions. Avoid it in larger projects.
