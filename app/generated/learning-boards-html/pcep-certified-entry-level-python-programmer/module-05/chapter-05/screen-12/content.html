Module 6 › Chapter 5.5 › Pitfalls
Common pitfalls
  • Catch specific exceptions: Avoid generic Exception handlers for normal flow.
  • Signal failures: Use None, raise, or explicit return values rather than silently continuing.
  • Initialize resources: Set file = None before try and check before closing in finally.
  • Narrow try blocks: Keep risky lines inside try to avoid hiding other bugs.
Quick remedies
Prefer with for files.
Catch ValueError for conversions.
Use tests to catch logical errors early.
