When to raise

Raise when the function cannot honor its contract or when invalid input requires caller-level handling. Use ValueError or TypeError as appropriate to the condition.

def require_positive(n):
    if n <= 0:
        raise ValueError('n must be positive')
    return n * 2

# Caller can catch ValueError and react accordingly
Re-raising with context
try:
    do_something()
except Exception as e:
    raise RuntimeError('Failed while processing X') from e
Re-raising preserves the original traceback and attaches additional context, which is useful for debugging and logging.
