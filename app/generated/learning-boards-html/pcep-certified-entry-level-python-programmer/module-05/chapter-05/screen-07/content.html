Module 6 › Chapter 5.5 › finally vs with
Pattern: finally
file = None
try:
    file = open('config.txt')
    data = file.read()
except FileNotFoundError:
    print('File not found')
finally:
    if file:
        file.close()
Pattern: with
with open('config.txt') as file:
    data = file.read()
# file is automatically closed here
Choose with for clarity and brevity when an object supports the context manager protocol. Use finally when cleanup depends on conditional variables or when you must support older objects without context-management support.
