Robust Functions: Error Handling and Debugging

You’ll learn to catch exceptions, guarantee cleanup, and use debug techniques to find logical issues. This chapter shows concrete code patterns and common pitfalls.

In this lesson
Try-except basics and examples.
Coming up
Else/finally and file safety patterns.
Practice

Outline
  • Identify error types: syntax, logical, runtime.
  • Implement try, except, else, finally in functions.
  • Debug with print statements and read tracebacks.
Visual Concept
Flow: try → except → else → finally
A safe function tries risky operations, handles known exceptions, runs success-only logic in else, and always performs cleanup in finally.
Example snippets
def calculate_average(numbers):
    try:
        total = sum(numbers)
        average = total / len(numbers)
        return average
    except ZeroDivisionError:
        print("Error: empty list")
        return 0.0
Key Takeaway

Predict failures, handle specific exceptions first, and guarantee cleanup so functions remain reliable.
