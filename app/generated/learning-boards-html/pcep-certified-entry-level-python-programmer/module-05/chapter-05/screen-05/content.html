Code walkthrough
def calculate_average(numbers):
    try:
        total = sum(numbers)
        count = len(numbers)
        average = total / count
        return average
    except ZeroDivisionError:
        print("Error: Cannot calculate average of an empty list.")
        return 0.0
    except TypeError:
        print("Error: The list must contain only numbers.")
        return None
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
        return None

Explanation & checks
  • Put only risky operations in try so you don't accidentally catch unrelated errors.
  • Catch ZeroDivisionError for empty collections specifically.
  • Handle TypeError to report invalid inputs and avoid crashing users' programs.
  • Use the generic except only for logging and re-raising when appropriate.
Key Takeaway

Design exception handlers that provide useful feedback and preserve a clear contract with callers.
