Module 6 › Chapter 5.5 › Types of Errors
Definition & explanation

Syntax errors are parsing failures; logical errors are mistakes in reasoning; runtime errors happen during execution and are handled with exceptions.

Syntax error (example)
def bad_function()
    print("missing colon")
Logical error (example)
Function returns zero for empty list without signaling that no data existed, leading callers to treat zero as a valid average.
Runtime error (example)
1 / 0  # ZeroDivisionError
Why it matters

Classifying the error helps you decide the fix: a syntax edit, better tests or logic, or defensive exception handling. Mixing strategies or hiding errors can make debugging much slower.

Common misconception

Treating runtime exceptions as logical errors. Many runtime issues can be prevented by input validation, but some need explicit handlers.

Key takeaway

Decide whether to fix, validate, or handle an error based on its type; choose the least surprising behavior for callers.
