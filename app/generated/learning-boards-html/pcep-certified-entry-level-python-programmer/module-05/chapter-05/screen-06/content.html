Module 6 › Chapter 5.5 › try-except-else-finally
Process steps
1. Try
Run operations that may raise exceptions.
2. Except
Handle specific exceptions to recover or report errors.
3. Else
Execute success-only logic after try completes without exceptions.
4. Finally
Always run cleanup code whether an exception occurred or not.
Concrete example
def process_file_data(filename):
    file = None
    try:
        file = open(filename, 'r')
        data = file.read()
        print(f"File content: {data[:50]}...")
    except FileNotFoundError:
        print(f"Error: File '{filename}' not found.")
    except IOError as e:
        print(f"Error reading file '{filename}': {e}")
    else:
        print(f"Successfully processed file '{filename}'.")
    finally:
        if file:
            file.close()
            print(f"File '{filename}' closed.")
Why this pattern

It clearly separates error handling, success actions, and guaranteed cleanup so resources are not leaked and logic is easier to reason about.
