Common mistakes
  • Over-broad catching: Catching Exception hides the real bug and slows debugging.
  • No cleanup: Forgetting to close files can leak resources — use finally or with.
  • Silent failures: Returning defaults without logging can mask logic errors.

Activity

Implement get_positive_integer() using a loop, try-except for value conversion, and input checks to keep prompting until a positive integer is returned.

Pro tip

When in doubt, log or print the exception message during development so you can decide whether to handle or re-raise it in production.
