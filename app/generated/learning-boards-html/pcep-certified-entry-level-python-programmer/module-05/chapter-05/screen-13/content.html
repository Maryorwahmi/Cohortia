def process_data(value):
    try:
        result = 100 / int(value)
        print(f"Result: {result}")
    except ValueError:
        print("Error: Invalid number format.")
    except ZeroDivisionError:
        print("Error: Cannot divide by zero.")
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
    else:
        print("Processing complete without errors.")
    finally:
        print("Function execution finished.")

# process_data('hello')
Predict the printed output: the ValueError handler runs and the finally message prints. This reinforces that else does not run when an exception occurs, and helps you practice reading program flow under exceptions.
