Process Flow Invoking functions
Live example
def greet_user(name):
    print(f"Hello, {name}! Welcome to Cohortia.")

# Calling the function executes the body
greet_user("Alice")
greet_user("Bob")

# Without parentheses you reference the function object, not execute it
# print(greet_user)  # shows a function object
Run calls with different arguments to observe parameter binding and outputs changing accordingly.
Explanation bullets
  • Parentheses tell Python to execute the function body.
  • Arguments are assigned to parameters in order, unless named.
  • Missing parentheses returns the function object, not its result.
  • Wrong argument counts cause errors at call time.

Key Takeaway

Remember to include parentheses to invoke behavior and supply matching arguments.
