Definition Return and None
Returned result example
def calculate_square(number):
    """Calculates the square of a given number."""
    result = number * number
    return result

squared_value = calculate_square(5)
print(f"The square of 5 is: {squared_value}")
Here the caller stores the returned value for later use. The function itself does not print unless instructed to.
No explicit return
def do_nothing():
    pass

return_of_nothing = do_nothing()
print(return_of_nothing)  # shows None
A function that prints and a function that returns are used differently: printing displays text immediately; returning provides a value for later computation.
Misconception
Expecting print to produce a usable return value will lead to confusion when you try to use the printed output in expressions.
