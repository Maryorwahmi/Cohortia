Definition Syntax and docstrings
Example function
def greet_user(name):
    """
    This function greets the person passed in as an argument.
    """
    print(f"Hello, {name}! Welcome to Cohortia.")

# Define does not execute the body until you call the function.
Notice the docstring and the indented body. The function stores behavior under the given name for later calls.
Explanation bullets
  • def signals a new function definition to Python.
  • Parameters name inputs; they are local inside the function body.
  • A docstring documents intent and usage for others and tools.
  • The body must be consistently indented to avoid syntax errors.
Common mistake
Mixing tabs and spaces or forgetting the colon will prevent the function from being defined.
Key Takeaway

Follow the def line with a docstring and a consistently indented body for clarity and correctness.
