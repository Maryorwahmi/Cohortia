Core Concept Docstrings & Style
Short docstring example
def calculate_square(number):
    """Return the square of number."""
    return number * number
Keep docstrings concise and focused on what the function expects and returns.
Longer docstring pattern
def calculate_rectangle_area(length, width):
    """Calculate and return the area of a rectangle.

    Parameters:
        length: numeric length of the rectangle.
        width: numeric width of the rectangle.

    Returns:
        Numeric area calculated as length times width.
    """
    return length * width
When helpful, list parameters and the return type to make intent explicit for future readers.
