Common Pitfall Indentation & Missing Calls
Indentation error example
def broken():
print("This is wrong")  # IndentationError

# Correct:
def fixed():
    print("This is correct")
Keep indentation consistent. Configure your editor for spaces and a visible indentation guide.
Missing parentheses example
def say_hi():
    print("Hi")

# Wrong: prints a function object
print(say_hi)

# Right: calls the function
say_hi()
If you expect an action and see a function object, check for parentheses at the call site.
