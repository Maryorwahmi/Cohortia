Summary Key Concepts
Function
A named block of code that performs a specific task and can be reused.
Parameter vs Argument
Parameters declare expected inputs; arguments are the concrete values passed at call time.
Return & None
Return sends a value back to the caller; if absent, the function returns None implicitly.
Summary takeaway
Use functions to name behavior, accept inputs through parameters, and return values for reuse. That pattern supports modular, testable code.
