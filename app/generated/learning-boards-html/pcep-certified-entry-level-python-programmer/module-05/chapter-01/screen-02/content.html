01
Explain the purpose of functions
Describe why naming and reusing code reduces repetition and bugs in programs.
Mnemonic: Think 'name your step' like a recipe step.
VERIFIED COMPETENCY MILESTONE
02
Define a function with def
Write a function signature, optional parameters, and an indented body following Python syntax rules.
Mnemonic: Parentheses hold inputs, colon starts the body.
VERIFIED COMPETENCY MILESTONE
03
Call functions with arguments
Invoke a function by name and pass values that match the parameters expected by the function.
Mnemonic: Call uses parentheses — leaving them off references the function itself.
VERIFIED COMPETENCY MILESTONE
04
Use return to produce values
Return sends a result back. Without return, the function implicitly yields None.
Mnemonic: Return hands a value back to the caller.
