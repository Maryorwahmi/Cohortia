Comparison Before and after refactor
Before: repeated code
number = 2
print(number * number)

number = 3
print(number * number)

number = 4
print(number * number)
This approach copies the same logic three times, increasing maintenance work.
After: function extraction
def calculate_square(number):
    return number * number

print(calculate_square(2))
print(calculate_square(3))
print(calculate_square(4))
One definition and multiple calls keep the logic centralized and easier to change.
Key Takeaway

Centralize repeated logic in a function to simplify updates and reduce bugs.
