Tuples — Immutable Sequences

Understand why tuples are fixed, how to create them, and when immutability helps correctness.

Tuples are small, efficient containers for related values you don’t want changed. They are commonly used for structured data, returning multiple values from functions, and as dictionary keys because they are hashable when containing only hashable items.

We’ll cover creation, the single-element comma rule, indexing and slicing, packing and unpacking, and practical patterns where immutability improves safety and performance.

Explore Key Topics
Creation
Parentheses and commas; single-element tuples need a trailing comma.
Packing & Unpacking
Assign multiple values at once and receive multiple returns from functions.
Hashable Use
Tuples can be dictionary keys when their elements are immutable.
Visual Concept
Birth certificate vs shopping list
Tuple — laminated card
Fixed values, safe to hash, good for function returns and records.
coordinates = (10.0, 20.0)
person = ("Alice", 30, "New York")
single = (5,)
List — whiteboard
Editable, can append or remove items, ideal for collections that change.
shopping = ["milk", "eggs"]
shopping.append("bread")
Key Takeaway

Use tuples when you need a fixed, ordered collection that should not change and can be safely used as a dictionary key.
