Module 3 › Chapter 3.3 › What to Remember
Comma rule
A trailing comma distinguishes single-element tuples from parenthesized expressions.
Immutable behavior
Tuples cannot be changed; assignment to an index raises a TypeError.
Hashable keys
Tuples of hashable items can be dictionary keys; avoid embedding mutable items.
Final thought

When in doubt, pick the container that best expresses whether values should remain stable or change. That clarity reduces bugs and makes your code easier to understand.
