Module 3 › Chapter 3.3 › What is a tuple?
Core Concept

Tuples are ordered and immutable

Immutability means you cannot change the contents once created. That gives tuples specific uses where fixed data is valuable.

Analogy

Treat a tuple like a laminated record — legible and durable but not writable. A list is like a whiteboard you can edit freely.

Key Takeaway

Use tuples for structured, unchanging records and when you need hashable containers.

Example
coordinates = (10.0, 20.0)
person = ("Alice", 30, "New York")
empty = ()
single = (5,)
  • Ordered: position determines meaning; person[0] is name.
  • Immutable: assignments like person[1] = 31 raise a TypeError.
  • Hashable when elements are hashable: usable as dictionary keys.
Misconception

Parentheses alone do not always create a tuple; commas are the real tuple separators. Use a trailing comma for single-element tuples.
