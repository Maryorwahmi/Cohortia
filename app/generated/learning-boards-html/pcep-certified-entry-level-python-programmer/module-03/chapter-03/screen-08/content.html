Module 3 › Chapter 3.3 › Tuples vs Lists
Lists

Mutable, flexible

  • Can be changed: append, pop, assign.
  • Good for collections that grow or shrink.
  • Not hashable; cannot be used as dict keys.
Example
todo = ['buy milk']
todo.append('send email')
Tuples

Immutable, stable

  • Cannot change after creation.
  • Use for fixed records and function returns.
  • Hashable when elements are hashable — usable as keys.
Example
coords = (100, 200)
# safe as a dict key when elements are hashable
