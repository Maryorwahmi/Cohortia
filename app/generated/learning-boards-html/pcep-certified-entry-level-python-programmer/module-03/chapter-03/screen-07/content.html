Module 3 › Chapter 3.3 › Packing & Unpacking
Definition

Pack values, then unpack them

This pattern is compact and often used when functions return multiple related values.

Star unpacking

Use a star to capture remaining items: head, *tail = seq.

Examples
# packing
pair = 3, 1

# unpacking
quotient, remainder = divmod(10, 3)

# starred
first, *rest = (1, 2, 3, 4)
print(first)  # 1
print(rest)   # [2, 3, 4]
  • Mismatched counts raise a ValueError.
  • Starred unpacking provides flexible captures for remaining items.
