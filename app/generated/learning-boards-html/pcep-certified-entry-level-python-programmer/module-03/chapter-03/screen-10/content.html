Module 3 › Chapter 3.3 › Tuple modification
Error Example
user = ("coder_joe", 29, True)
# user[1] = 30  # TypeError: 'tuple' object does not support item assignment
Create a new tuple
new_user = user[:1] + (30,) + user[2:]
print(new_user)  # ('coder_joe', 30, True)
Alternate: convert to list
temp = list(user)
temp[1] = 30
user = tuple(temp)
print(user)
  • Choose new tuple creation to keep immutable semantics explicit.
  • Use list conversion when many changes are needed, then freeze back to a tuple.
