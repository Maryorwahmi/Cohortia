Process Flow

Steps to access and slice

  1. Use zero-based index to retrieve an element.
  2. Use negative index to count from the end.
  3. Use slice notation to extract a sub-sequence; result is a new tuple.
  4. Use concatenation to build new tuples from existing ones.
Check your understanding

What happens to the original tuple after slicing? It stays unchanged; you get a new tuple.

Code
person = ("Alice", 30, "New York")
first = person[0]        # 'Alice'
last = person[-1]        # 'New York'
pair = person[0:2]      # ("Alice", 30)
new_person = ('Alice', 31, 'New York')
combined = person + ("engineer",)
  • Remember: assignment like person[1] = 31 raises a TypeError.
  • Slicing returns a tuple, not a list, keeping immutability intact.
