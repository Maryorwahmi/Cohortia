Module 3 › Chapter 3.3 › Key Concepts
Tuple
An ordered, immutable collection defined by commas and often wrapped in parentheses.
Immutability
You cannot change a tuple’s contents; operations that appear to modify return new tuples.
Packing & Unpacking
Comma-separated values form tuples; unpacking assigns elements to variables cleanly.
Takeaway

Use tuples to express fixed, ordered data; learn the trailing comma rule, unpacking patterns, and when hashability matters.
