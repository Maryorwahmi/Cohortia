Module 3 › Chapter 3.3 › How to create tuples
Core Concept

Comma-first construction

Use commas to separate values. Parentheses clarify grouping and are required for empty tuples and recommended for readability.

Single-element rule

Always use a trailing comma when creating a one-item tuple: (value,)

Misconception

Seeing parentheses does not guarantee a tuple. The comma is the defining syntax element.

Code examples
# multiple-element tuples
coords = (10.0, 20.0)
colors = 'red', 'green', 'blue'

# empty tuple
empty = ()

# single-element tuple
not_a_tuple = (5)    # int
single = (5,)        # tuple

# packing without parentheses
packed = 1, 2, 3
  • Prefer parentheses for clarity and empty tuples.
  • Use trailing comma for one element to prevent type confusion.
