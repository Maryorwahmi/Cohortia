Module 3 › Chapter 3.3 › Learning Objectives

Practice checklist

  • Write a normal tuple and print its type and elements.
  • Create an empty tuple and a single-element tuple using a trailing comma.
  • Index negative and positive positions, and slice a sub-tuple.
  • Pack values into a tuple without explicit parentheses and then unpack them.

Safety checks

Attempt to assign into a tuple to see the TypeError and try to use a tuple containing a list as a dictionary key to observe a hashing error. These experiments build understanding of hashability and immutability.

# Example
user_profile = ("coder_joe", 29, True)
print(user_profile[0])  # 'coder_joe'
# user_profile[1] = 30  # raises TypeError
