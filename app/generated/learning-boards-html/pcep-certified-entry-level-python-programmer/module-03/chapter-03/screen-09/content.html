Architecture

Composite keys with tuples

Use tuples of immutable values to represent multi-part keys for fast dictionary lookup.

Rule

All elements inside the tuple must be hashable for the tuple to be a valid key.

Example
# mapping positions to objects
grid = {}
grid[(10, 20)] = 'tree'
print(grid[(10, 20)])  # 'tree'

# invalid key
bad = (1, [2, 3])
# grid[bad] = 'error'  # raises TypeError
  • Embedding mutable items prevents tuple from being hashable.
  • Prefer tuples of ints or strings for dictionary keys.
