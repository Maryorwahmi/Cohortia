Module 3 › Chapter 3.3 › Common Mistakes

Trailing comma confusion

a = (5)   # int
b = (5,)  # tuple

Assignment error

t = (1, 2)
# t[0] = 10  # TypeError

Unhashable element

bad = (1, [2, 3])
# use as key -> TypeError

Check each element’s type before using a tuple as a key. Prefer tuples of primitives for dictionary keys.
