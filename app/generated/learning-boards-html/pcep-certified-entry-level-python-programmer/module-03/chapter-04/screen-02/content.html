Learning Objectives
Understand and use dictionaries in everyday Python programs.
01
Recognize dictionary structure
Identify keys and values and explain why keys must be immutable. This matters when choosing identifiers for lookup operations in your programs.
Mnemonic: labeled drawers
VERIFIED COMPETENCY MILESTONE
02
Create and access entries
Build dictionaries with literals or by starting empty, and access values directly or with get to avoid exceptions when missing keys may occur.
Mnemonic: literal braces vs safe get
VERIFIED COMPETENCY MILESTONE
03
Mutate and remove entries
Use assignment to add or update keys, and del or pop to remove pairs. Know how pop returns a value and can accept a default.
Mnemonic: assign to add, pop to remove
VERIFIED COMPETENCY MILESTONE
04
Iterate and inspect contents
Use keys(), values(), and items() to traverse dictionaries for reporting or batch updates. This helps in processing structured records reliably.
Mnemonic: keys, values, items — choose the view you need
