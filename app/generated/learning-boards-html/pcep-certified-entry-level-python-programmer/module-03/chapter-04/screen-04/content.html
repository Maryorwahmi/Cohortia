Definition
Dictionary concept and syntax
A mapping from unique keys to values, created with curly braces and colon separators.
Example
student = {"name": "Alice", "age": 20, "major": "Computer Science"}
print(student["name"])  # Alice
Keys are on the left of the colon and must be immutable; values are on the right and can be any type.
Key point
Lookup by key is efficient and direct.
Misconception
Do not treat dictionaries like ordered lists for positional access.
Why this matters

Using meaningful keys lets you write code that is easier to read, maintain, and extend. Dictionaries let you represent records and configurations naturally without index arithmetic or parallel lists. Their mutability makes them convenient for stateful scripts and incremental updates.

Analogy
Think of a dictionary as a labeled drawer set where each label maps to a stored item. You open a drawer by label, not by counting drawers.
Key Takeaway

Prefer key-based access for structured records; choose immutable keys and clear labels.
