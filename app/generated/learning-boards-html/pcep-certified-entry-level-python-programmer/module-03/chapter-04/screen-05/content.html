Code walkthrough
Create and access
# Create a literal dictionary
student = {"name": "Alice", "age": 20}

# Empty dictionary
empty_dict = {}

# Direct indexing - will raise KeyError if missing
print(student["name"])  # Alice

# Safe access with get - returns default instead of raising
print(student.get("city", "Not Available"))  # Not Available
Note: get does not insert the key into the dictionary; it only returns a fallback value.
Explanation bullets
  • Literal creation is concise and readable for known initial values.
  • Empty dictionaries are useful when populating entries later in code.
  • Direct indexing signals certainty: use only when the key is present.
  • get is safer in contexts where keys may be optional or user-provided.
Pro tip
Use get with a meaningful default to make outputs predictable when data is incomplete.
Key Takeaway

Use indexing when keys are known; use get to avoid KeyError and return defaults for missing keys.
