Direct access
value = d[key]  # raises KeyError if key missing
Use when the key is known to exist. Good for internal invariants and tight loops where missing keys are programming errors.
get()
value = d.get(key, default)  # safe when key may be absent
Use in user-facing or optional-field contexts. get never mutates the dictionary and returns a default when missing.
pop()
value = d.pop(key, default)  # removes and returns value
Use when removing an entry and needing its value. Provide a default to avoid KeyError when absent.
Common mistake
Expecting get to insert keys or using direct access on unpredictable input causes runtime errors. Choose methods that express your intent clearly.
Check your understanding
When should you use pop instead of get? When you need the value removed and available for further processing.
