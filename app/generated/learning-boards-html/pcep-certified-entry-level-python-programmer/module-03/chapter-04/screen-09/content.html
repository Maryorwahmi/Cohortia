Allowed keys
  • Strings: "product_id"
  • Numbers: 42 or 3.14
  • Tuples of immutables: ("NY", 2021)
Disallowed keys
  • Lists: [1, 2, 3] — mutable
  • Dictionaries: {"a":1} — mutable
Practical example
# Use a tuple for composite key
locations = {}
locations[("New York", 2021)] = {"sales": 1200}

# This will raise TypeError
# bad = {[1,2]: "value"}
When in doubt, convert mutable structures to immutable forms before using them as keys.
