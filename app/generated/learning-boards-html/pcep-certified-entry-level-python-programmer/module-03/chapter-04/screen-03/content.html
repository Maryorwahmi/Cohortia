Practice flow
  1. Create dictionaries by literal and empty constructor.
  2. Access values directly and with get for safety.
  3. Add/modify keys using assignment.
  4. Remove keys with pop and del, capturing values when needed.
VERIFIED COMPETENCY MILESTONE
Common checks
  • Keys are immutable and unique; values can repeat.
  • get returns a default rather than raising KeyError.
  • items returns pairs useful for unpacking in loops.
