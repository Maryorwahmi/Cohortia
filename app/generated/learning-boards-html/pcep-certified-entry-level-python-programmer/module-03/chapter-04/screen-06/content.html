Mutation steps
1. Add or update
Use assignment: inventory["Monitor"] = {"quantity":15, "price":300.00}
2. Remove with pop
removed = inventory.pop("Mouse", None) # returns None if missing
3. Delete with del
del inventory["Keyboard"] # raises KeyError if missing
Code example
# Start inventory
inventory = {}
# Add a product
inventory["Laptop"] = {"quantity": 10, "price": 1200.00}
# Update quantity
inventory["Laptop"]["quantity"] = 8
# Remove and capture
removed = inventory.pop("Mouse", None)
# Delete strictly
# del inventory["Keyboard"]  # only if you want an error when missing
Using pop with a default prevents KeyError and returns the removed value for logging or restocking logic.
When to pop
When you need the value after removal or want a safe default.
When to del
When missing keys should trigger an error for debugging.
