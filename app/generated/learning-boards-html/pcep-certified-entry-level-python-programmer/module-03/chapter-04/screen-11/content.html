KeyError
Direct access on unknown keys raises an exception. Use get with a default to handle optional data safely.
TypeError from mutable keys
Lists and dicts cannot be used as keys. Convert them to tuples or strings first.
Accidental overwrite
Assignment replaces previous values. Save or copy data first if you need history.
Quick checklist
  • Use get(key, default) for optional keys.
  • Only use immutable types as keys.
  • Avoid mutating dictionary while iterating; iterate over list(d.keys()) instead.
  • Standardize key naming to avoid subtle mismatches.
