Practical Skills and Checks
Short tasks to confirm each objective through immediate feedback.
Create & Index
  • Build a list and print the element at index 0 to confirm the first item.
  • Print the element at index -1 to confirm negative indexing returns the last item.
Modify & Add
  • Assign a new value to an existing index to check mutability.
  • Use append and insert and then print the list to confirm order changes.
Remove Safely
  • Use pop to remove and capture the last item, and del to remove by index.
  • Use remove to delete a value and observe only the first occurrence is removed.
Verify
Always print the list and its length after changes to confirm expected structure and avoid off-by-one errors.
