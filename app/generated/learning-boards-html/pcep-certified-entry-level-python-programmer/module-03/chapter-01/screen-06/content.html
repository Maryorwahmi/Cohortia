Mutable Behavior Changing list contents
Modify by assignment
items = ["pen", "pencil", "notebook"]
items[1] = "marker"
print(items)   # ['pen', 'marker', 'notebook']

# swap example
items[0], items[1] = items[1], items[0]
Assignment replaces existing elements without creating a new list object.
References and copy
Be careful: multiple names can reference the same list. Use slicing or the list() constructor to make a shallow copy when needed.
a = [1,2]; b = a; b[0] = 99 → a sees 99
copy = a[:] or copy = list(a) makes a shallow copy
Misconception

Assigning one list to another name does not copy it; it binds another reference to the same object.
