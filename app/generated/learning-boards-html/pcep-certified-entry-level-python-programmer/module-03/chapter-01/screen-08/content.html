Removing Items del, remove, and pop
del by index
Use when you know an element's position and do not need it returned.
items = ["a","b","c"]
del items[0]
print(items)  # ['b','c']
remove(value) and pop()
remove deletes the first matching value; pop removes and returns by index or last if omitted.
items = [1,2,1,3]
items.remove(1)   # removes first 1 → [2,1,3]
last = items.pop()  # removes and returns 3
Common pitfall

remove removes only the first match; to remove all instances you must loop or use a comprehension.
