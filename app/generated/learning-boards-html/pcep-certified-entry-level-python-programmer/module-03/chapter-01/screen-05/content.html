Definition & Access Creating lists and indexing
How to create
# populated list
my_shopping_list = ["milk", "bread", "eggs"]
# empty list
empty_list = []
# mixed types
mixed = [1, "two", [3, 4]]
Creating lists is literal and direct; use an empty list when you will append items later.
Indexing rules
Remember zero-based indexing and negative indexes for end-relative access.
my_shopping_list[0] → first element
my_shopping_list[-1] → last element
IndexError occurs when index >= len(list) or < -len(list)
Common mistake

Assuming indexes start at 1. When you try to access position 1 thinking it's the first element you will get the second element instead.
