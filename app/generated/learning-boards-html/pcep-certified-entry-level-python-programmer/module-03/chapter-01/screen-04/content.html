Core Concept What is a Python list?
Lists: ordered, mutable collections
A flexible container for related items that preserves order.
Definition and properties
  • Ordered: elements have stable numeric positions starting at zero.
  • Mutable: you can change elements after the list is created.
  • Heterogeneous: items of different types may coexist in one list.
  • Supports positive and negative indexing to access elements from either end.
Analogy: a bookshelf where each slot has a number and you can insert, replace, or remove books.
Concrete example
my_shopping_list = ["milk", "bread", "eggs"]
print(my_shopping_list[0])   # prints: milk
print(my_shopping_list[-1])  # prints: eggs
my_shopping_list[1] = "butter"
print(my_shopping_list)      # ['milk', 'butter', 'eggs']
Key Takeaway

Lists keep order and allow in-place changes; remember references may share the same list object.
