Add Elements Appending and inserting items
append example
groceries = ["Apples", "Milk", "Bread"]
groceries.append("Cheese")
print(groceries)  # ['Apples', 'Milk', 'Bread', 'Cheese']
append always places the value at the end and increases length by one.
insert example
groceries = ["Apples", "Milk", "Bread"]
groceries.insert(1, "Eggs")
print(groceries)  # ['Apples', 'Eggs', 'Milk', 'Bread']
insert shifts existing elements to the right; choose it when position matters.
Pro tip

When building a large list, append is generally faster than many inserts because insert may move many elements.
