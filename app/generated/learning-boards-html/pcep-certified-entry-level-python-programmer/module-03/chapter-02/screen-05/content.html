Module 3 › Chapter 3.2 › Negative indices & steps
Rule summary
  • Negative index -1 refers to the last element.
  • Negative step traverses backward; end is still exclusive relative to direction.
  • Out-of-range start/end are clamped; slicing never raises an IndexError.
Misconception check

Assuming end is inclusive when stepping backwards causes off-by-one errors. Work through small examples to clarify directionality.

Examples and outputs
arr = list(range(10))  # [0..9]
print(arr[7:2:-1])  # [7,6,5,4,3]
print(arr[-3:])      # [7,8,9]
print(arr[:-3])      # [0..6]
print(arr[::-2])     # [9,7,5,3,1]
Example card

arr[::-1] is a fast idiom for a reversed copy. Use it instead of manual loops when you need a reversed snapshot.

Key takeaway

Think in terms of traversal direction: positive step moves forward, negative step moves backward, end is exclusive along that direction.
