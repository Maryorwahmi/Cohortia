Module 3 › Chapter 3.2 › List comprehensions
Pattern

[expression for item in iterable if condition]

# squares 0..9
squares = [x**2 for x in range(10)]
# even squares
even_squares = [x**2 for x in range(10) if x % 2 == 0]
Why it matters

Comprehensions reduce boilerplate and make simple transformations clearer than equivalent loops.

When not to use

Avoid compressing complex logic into a single comprehension. Break steps into named functions or loops to preserve readability and debuggability.

Example card

Transform a list of temperatures to Fahrenheit or filter by threshold in one readable line using a comprehension.

Check your understanding

Rewrite a short for-loop that builds a list of doubled values into a comprehension and compare outputs.
