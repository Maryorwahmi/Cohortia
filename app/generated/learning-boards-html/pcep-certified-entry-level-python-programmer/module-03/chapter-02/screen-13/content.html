Module 3 › Chapter 3.2 › Quick Reference
Slice returns new

Use slices to make snapshots or reversed copies without mutating the original list.

Methods may mutate

If a method returns None, it likely modifies the object in place. Confirm before assigning its result to a variable.

Assignment is a reference

When you assign one list to another variable, both names reference the same object. Copy explicitly when independence is required.

Final takeaway

Think: will this operation change the original or create a new list? That question guides safe, predictable code.
