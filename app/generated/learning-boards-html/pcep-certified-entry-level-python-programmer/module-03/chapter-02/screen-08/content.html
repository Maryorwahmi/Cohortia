Module 3 › Chapter 3.2 › Mutability & Aliasing
Concept

Assignment gives a second name for the same object. Mutations via any name affect the same list in memory.

list_a = [1,2,3]
list_b = list_a
list_b.append(4)
print(list_a)  # [1,2,3,4]
Safe copy

list_b = list_a[:] or list_b = list_a.copy() creates an independent shallow copy for lists of primitives.

Visual analogy

Think of a list as a box. Assigning another name to it is like putting a second label on the same box. Copying is building a new box with the same items inside.

Common mistake

Assuming assignment clones a list leads to silent shared-state bugs. Always copy deliberately when needed.

Quick check

Use id(list_a) and id(list_b) or the is operator to confirm whether two names point to the same object.
