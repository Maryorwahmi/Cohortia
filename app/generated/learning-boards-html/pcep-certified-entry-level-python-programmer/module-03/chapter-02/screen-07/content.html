Module 3 › Chapter 3.2 › count() & index()
count()

Returns the number of occurrences of a value. Safe to call even if value isn't present.

nums = [22,30,22,28]
print(nums.count(22))  # 2
print(nums.count(99))  # 0
index()

Returns the index of the first occurrence. Raises ValueError if not found, so check membership or handle exceptions.

names = ['alice','bob','carol']
if 'bob' in names:
  print(names.index('bob'))  # 1
# or
try:
  idx = names.index('dave')
except ValueError:
  print('not found')
Pro tip

Use count to check existence before calling index, or use try/except to handle missing values gracefully.

Example

In temperature data, count tells you how often a reading repeats; index finds the first time a certain reading occurs.
