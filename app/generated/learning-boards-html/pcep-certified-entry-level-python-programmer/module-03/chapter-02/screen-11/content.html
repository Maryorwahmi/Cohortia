Module 3 › Chapter 3.2 › reverse() vs [::-1]
In-place reverse()

Mutates the list and returns None. Use when you intend to change the same list object.

a = [1,2,3]
a.reverse()
print(a)  # [3,2,1]
Slicing reversed copy

Produces a new list in reversed order and leaves the original untouched.

a = [1,2,3]
b = a[::-1]
print(a)  # [1,2,3]
print(b)  # [3,2,1]
Tip

Use sorted(my_list, reverse=True) or sorted(my_list)[::-1] to get sorted copies without mutating the original.

Check

If you need both versions keep the original by slicing or using sorted to produce copies.

Misconception

Expecting reverse to return the reversed list is a common source of bugs; reverse returns None.
