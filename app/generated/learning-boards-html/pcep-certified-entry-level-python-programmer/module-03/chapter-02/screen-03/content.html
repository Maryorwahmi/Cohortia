Module 3 › Chapter 3.2 › Practice & Checks
Slice check

Write three slices: first 3 items, last 3 items, every second item. Confirm the original list is unchanged by printing both lists.

Sort vs sorted

Sort a list in place, then repeat with the sorted function. Verify whether the original list was modified and discuss when each choice is appropriate.

Aliasing check

Assign list_a to list_b, mutate list_b, and show list_a changed. Then create a true copy and show changes no longer propagate.

Comprehension check

Write a comprehension to compute squares and one that filters evens. Print outputs and compare to a loop implementation to see readability gains.
