Module 3 › Chapter 3.2 › Temperature data example
Starter and solution code
temperatures_celsius = [25.5, 28.1, 22.0, 29.3, 22.0, 27.8, 30.5, 22.0]

# 1. high_temperatures using list comprehension
high_temperatures = [t for t in temperatures_celsius if t > 27.0]

# 2. Sort original in descending order (in place)
temperatures_celsius.sort(reverse=True)

# 3. Index of first 22.0 in the sorted list
# handle presence to avoid ValueError
if 22.0 in temperatures_celsius:
  first_22_index = temperatures_celsius.index(22.0)
else:
  first_22_index = -1

# 4. Count occurrences of 22.0 in the original list (prior to sort we could keep a copy)
# if we need the original order, make a copy first. For demonstration, assume original values count is desired
original_count_22 = [25.5,28.1,22.0,29.3,22.0,27.8,30.5,22.0].count(22.0)

# 5. Create reversed copy of high_temperatures using slicing
reversed_high = high_temperatures[::-1]

print('Original temperatures (sorted descending):', temperatures_celsius)
print('High temperatures (above 27.0):', high_temperatures)
print('Index of first 22.0 in sorted list:', first_22_index)
print('Count of 22.0 in original list:', original_count_22)
print('Reversed high temperatures:', reversed_high)
Explanation & tips
  • high_temperatures uses a comprehension to filter values above 27.0 and creates a new list.
  • Sorting temperatures_celsius in place changes that list; if you need the original, copy it first.
  • Use membership checks before index to avoid ValueError or use try/except.
  • Count is computed on the original dataset; if you sorted the list first, preserve the original or compute count before sorting.
  • reversed_high uses slicing [::-1] to make an independent reversed copy of the filtered list.
Key takeaway

Plan when you will mutate and when you will keep copies. Use comprehensions for concise filtering and slicing for safe copies.
