Module 3 › Chapter 3.2 › sort() vs sorted()
In-place (list.sort)

Modifies the same list object. Returns None. Use when you want to change the list itself and save memory.

nums = [3,1,4,2]
nums.sort()
print(nums)  # [1,2,3,4]
Return new (sorted)

Returns a new sorted list and leaves the original unchanged. Use when you need both original and sorted versions.

nums = [3,1,4,2]
new_nums = sorted(nums)
print(nums)     # [3,1,4,2]
print(new_nums) # [1,2,3,4]
Pro tip

If you see assignment = list.sort(), it's likely a bug — the variable will be None.

When to choose

Use sorted when you need the original later; use sort for one-off reordering where memory matters.

Quick check

Print before and after to be certain which object changed.
