Concept snapshot

Slicing, in-place methods, and comprehensions

Slicing returns new lists. Methods like sort and reverse change the same list. Comprehensions produce new lists concisely. Aliasing connects variable names to a single list object — that connection matters.

Slice
list[start:end:step] → new list
In-place
list.sort() and list.reverse() modify the original
Comprehension
[expr for item in iterable if cond] → concise new list
