Temperature-Based Clothing Advisor — Starter Code
Trace this starter code and test boundary inputs to see which branch runs.
# Get temperature input from the user
temperature_str = input("Enter the current temperature in Celsius: ")
temperature = int(temperature_str)

# Your conditional logic goes here
if temperature > 25:
    print("Wear light clothes and stay hydrated.")
elif temperature >= 15: # This condition implicitly means 15 <= temperature <= 25
    print("A light jacket or sweater might be comfortable.")
else:
    print("Bundle up with a warm coat and scarf.")
Tip: try values such as twenty-six, twenty-five, fifteen, and fourteen to confirm each branch behaves as expected. Converting input to integer before comparison is essential.
Scenario checks
  • temperature = 30 → light clothes branch runs.
  • temperature = 20 → middle branch runs because first check is false.
  • temperature = 10 → else runs as fallback.
Key Takeaway

Convert inputs and test boundary values so each branch maps to the intended range.
