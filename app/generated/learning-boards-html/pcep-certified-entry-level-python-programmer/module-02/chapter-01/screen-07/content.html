Comparison
Boolean Expressions & Comparison Operators
Use comparisons to build expressions that return True or False.
== equal to: checks whether two values are the same.
!= not equal to: true when values differ.
< less than, > greater than, <= and >= inclusive variants.
Concrete example
score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")
Here the comparisons are ordered so higher thresholds are tested first. A score of eighty-five matches the second condition because the first was false.
Pro tip: read comparisons as plain language, for example 'score greater than or equal to ninety'.
Mistake to avoid: using assignment instead of comparison in a condition will cause a syntax error or wrong logic.
