Chaining with elif
Check multiple exclusive conditions in a planned order so only one branch runs.
score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")
Rule: specific to general. Put the highest thresholds first.
Pitfall: reversed order can cause a higher-priority case to be masked by an earlier broader check.
Concrete scenario
A score of eighty-five: first check fails, second passes, and the program prints Grade B. Later checks are ignored by design.
Key Takeaway

Plan the order of your conditions to ensure each possible input maps to the intended branch.
