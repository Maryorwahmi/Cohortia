Core Concept
What is a Conditional Statement?
A control-flow tool that decides whether a section of code should run based on a boolean test.
Quick bullets
  • Evaluates a boolean expression to either True or False.
  • Executes the indented block only when the expression is True.
  • Transforms linear code into conditional branches for different inputs.
Key Takeaway

Conditionals let programs respond differently to different data; they are the minimum unit of decision-making.

Analogy
A gated turn on a road: gate open means take the turn (run the block), closed means continue on the straight route.
Example: Voting eligibility
age = 20
if age >= 18:
    print("You are eligible to vote.")
print("Program continues here.")
This example evaluates the boolean expression age greater than or equal to eighteen; when true, the print function inside the block runs. If age were sixteen, that print would be skipped.
Common mistake: expecting conditionals to produce values. They control flow instead.
Pro tip: write clear conditions and small blocks for easier tracing and testing.
