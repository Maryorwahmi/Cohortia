Best Practices
Fallbacks, Input Validation, and Safe Defaults
Plan for unexpected or invalid inputs by providing explicit fallback behavior.
Validation pattern
Check the input, convert to the expected type, and use an else branch to handle invalid values or prompt the user again.
Example structure (pseudo):
# convert input
try:
    temperature = int(input_str)
except ValueError:
    print("Please enter a valid number.")
else:
    # proceed with conditional branches
    pass
Why this matters
Explicit defaults avoid silent failures and make behavior easier to test and maintain.
Key Takeaway

Design your conditionals with safety in mind: validate input and provide clear fallback actions to keep programs robust.
