Writing an if Statement
Key punctuation and indentation rules you must follow to form valid conditionals.
age = 20
if age >= 18:
    print("You are eligible to vote.")
print("Program continues here.")
Step through: the assignment runs, then the boolean check, then the indented print only when the check is true. The final print always runs because it is not indented under the if.
Common error: incorrect indentation or mixing tabs and spaces leads to IndentationError or unexpected grouping.
Check: use four spaces per level and a consistent editor setting to avoid mixed whitespace.

Misconception check
The colon after the if is required; indentation defines the block and is not optional or cosmetic.
