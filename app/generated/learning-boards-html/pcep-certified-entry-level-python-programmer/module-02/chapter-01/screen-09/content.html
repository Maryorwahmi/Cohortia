Indentation: Why Whitespace Matters
Indentation groups statements into blocks and is required syntax in Python.
Best practice: use four spaces per indentation level and configure your editor to insert spaces. Avoid mixing tabs and spaces to prevent subtle errors.
Common symptom: IndentationError when lines are misaligned or tabs and spaces mix.
Pro tip: enable visible whitespace or a linter to reveal mismatched indentation immediately.
Visual example
# Correct indentation
if x > 0:
    print("Positive")
    print("End of block")

# Incorrect indentation - the second print is misaligned
if x > 0:
    print("Positive")
  print("This will cause an error or unexpected grouping")
The misaligned line may raise an error or be outside the intended block. Keep indentation consistent for predictable grouping.
