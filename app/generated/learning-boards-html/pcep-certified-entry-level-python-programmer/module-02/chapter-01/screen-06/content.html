Using else for Alternative Paths
Else defines the fallback when the if condition is not met.
temperature = 25
if temperature > 30:
    print("It's a hot day! Stay hydrated.")
else:
    print("The weather is pleasant.")
When temperature is thirty-five the if branch runs. When temperature is twenty-five the else branch runs. Else has no condition; it executes only if all previous checks were false.
Pro tip: use else for clear defaults in input validation so user feedback is explicit.
Mistake to avoid: using else for a specific test—prefer elif with its own condition instead.
Example scenario
A clothing advisor prints different advice depending on temperature. Else ensures a default message when the hot-case is not met.
Key Takeaway

Use else to handle the remaining cases you did not explicitly test for. It makes behavior predictable.
