Common Mistakes
Assignment vs Comparison
Assignment gives a value, comparison checks equality. Use the correct operator for each intent.
# Wrong - assignment is not a comparison
# if x = 10:
#     print("Wrong")

# Correct - equality comparison
if x == 10:
    print("Ten")
Also be cautious with identity checks. For most conditional logic, you want value equality rather than checking whether two variables point to the same object.
Short checklist
  • Use equals-equals for comparisons.
  • Use single equals to assign outside of conditions.
  • Prefer value equality over identity checks unless you specifically need object identity.
Mistake Reminder

Using the wrong operator will cause syntax errors or subtle bugs; read conditions aloud to verify intent.
