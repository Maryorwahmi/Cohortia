Module 3 › Chapter 2.3 › Safety & resources
Iteration cap
Add a counter and break if iterations exceed a safe maximum while testing or when handling unpredictable input.
Quit commands
Allow the user to type a special value to exit a loop and use break to handle it cleanly.
Timeouts & resources
When loops access external resources, ensure you release resources and consider timeouts to avoid denial-of-service scenarios.
Testing strategy
Test loops with small, known inputs and with intentionally bad inputs to confirm safeguards trigger as expected.
