Module 3 › Chapter 2.3 › Key Concepts
Loop
A control flow statement that repeats a block while a condition is true.
while
Executes its indented body repeatedly while its boolean condition remains true.
Loop body
The indented block that executes each iteration; include updates that move toward termination.
Summary

Design loops by specifying the stopping condition, ensuring variables change toward that stopping condition, and using break or continue carefully to control flow. Test boundary cases and add safeguards for robust behavior.
