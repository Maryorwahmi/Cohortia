Module 3 › Chapter 2.3 › Indentation & loop body
Rule
Statements indented under the while are executed each iteration. Statements at the same level as while run after the loop ends.
count = 3
while count > 0:
    print(count)
    count -= 1
print("Done")  # runs after the loop
Warning
If you accidentally un-indent the update, it will not run each iteration and the loop may never end.
Practical layout
Keep loop bodies short. Move complex logic into functions and call them inside the loop to keep indentation clear and maintainable.
Mini-check
Before running, read each indented block and confirm it should execute repeatedly. If not, adjust indentation or refactor into a helper.
