Module 3 › Chapter 2.3 › Quick reference
Initialize & update
Set control variables before the loop and ensure they change in every path that can repeat.
break vs continue
break exits the loop; continue skips the current iteration. Ensure skipped iterations still allow termination.
Test & safeguard
Run small cases, test boundaries, and add iteration limits or quit commands for robust loops.
Final takeaway

When you can explain how a loop will stop in one clear sentence, you have designed it safely. Use the three reminders as a quick checklist before running your code.
