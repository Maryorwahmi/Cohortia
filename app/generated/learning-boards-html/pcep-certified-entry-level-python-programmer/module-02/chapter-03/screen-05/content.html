Module 3 › Chapter 2.3 › While loop flow
Step 1
Evaluate the condition. If it's false, skip the loop entirely.
Step 2
Execute the indented loop body when the condition is true.
Step 3
Update variables or state so the condition can change toward false.
Step 4
Re-evaluate the condition and repeat or exit.
Annotated example
countdown = 5
print("Starting countdown...")
while countdown > 0:
    print(countdown)
    countdown = countdown - 1  # update moves state toward termination
print("Blast off!")
Initialization
countdown starts at 5 before the loop.
Update
The countdown is reduced each iteration to eventually stop the loop.
Takeaway
Always trace how the condition changes across iterations and ensure some path leads to termination.
