Learning Objectives

Learn, understand, apply, and master while loops and basic loop control statements.

Bloom's taxonomy
Learn
Understand
Apply
Master
01
Explain iteration
Describe what iteration is and why loops are more efficient than copying code. Use examples like printing a sequence or validating input repeatedly.
VERIFIED COMPETENCY MILESTONE
02
Construct while loops
Write and run while loops that evaluate a condition each time and execute an indented block until the condition becomes false.
VERIFIED COMPETENCY MILESTONE
03
Prevent infinite loops
Identify why a loop never ends and correct the loop control variable update or the condition to ensure termination.
VERIFIED COMPETENCY MILESTONE
04
Use break and continue
Apply break to exit early when a condition is met and continue to skip the rest of the current iteration when appropriate.
VERIFIED COMPETENCY MILESTONE
