Predict output

count = 0

Choose the correct continue usage
Compare variants and pick the one that avoids infinite loops by ensuring the counter changes when continue runs.
Study tip
Work through small examples interactively and annotate counter values for each iteration. This habit quickly exposes off-by-one and infinite-loop problems.
Reflection
After solving, explain why each loop terminates and which branch guarantees the counter changes. Can you find an alternate safe design using break?
