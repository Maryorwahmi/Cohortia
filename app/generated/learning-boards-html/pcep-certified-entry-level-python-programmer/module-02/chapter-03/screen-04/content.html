Module 3 › Chapter 2.3 › What is iteration?
Definition
Iteration is repeating the same operation until a condition changes. Use loops to avoid copying code and to process many elements with consistent logic.
Examples
  • Printing numbers 1 to 100.
  • Asking for user input until valid data is entered.
  • Processing items in a list one by one.
Common misconception
Loops are only for numeric counters. In reality, they run until any boolean condition becomes false — counters are just one common pattern.
Analogy
Think of a loop as a kitchen timer: it repeats a task while the timer is running and stops when time runs out or you cancel it early.
Key takeaway
Loops replace repeated code with a controlled, single definition of the repeated action. Decide what must change each iteration to reach the stopping point.
