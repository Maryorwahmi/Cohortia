Repeat actions with while

Learn how while checks a condition each cycle, how to update loop variables, and when to use break or continue to control flow.

In this lesson
Countdown example, loop control variables, preventing infinite loops, break and continue, and a hands-on ATM simulator.
Why it matters
Loops let programs handle repetitive tasks cleanly and interact with users until a valid condition is reached.
Explore Key Topics
while Mechanics
Condition check, loop body execution, and re-evaluation each cycle.
Control Flow
Use updates, break, and continue to shape iteration behavior.
Safe loops
Prevent infinite loops and guard resources with sensible updates.
Visual concept
condition → body → update
Condition
A boolean expression checked each cycle to decide whether to run the body.
Loop body
The indented code executed when the condition is true. Include updates here.
Update
Modify variables so the condition will eventually be false to end the loop.
Break / Continue
Break exits immediately; continue skips to the next iteration.
