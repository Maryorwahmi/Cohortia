Module 3 › Chapter 2.3 › continue vs break
continue
Skip the remainder of the current iteration and go to the next one. Useful to ignore invalid or uninteresting cases.
break
Immediately exit the loop and continue execution after it. Useful when a goal is achieved and you can stop early.
Common mistake
Using continue before updating loop variables in a while loop can cause an infinite loop because the state doesn't change for that iteration.
Example (for clarity)
for i in range(1, 6):
    if i % 2 == 0:
        continue
    print(f"{i} is an odd number.")
This prints 1, 3, 5 because continue skips even numbers.
Design tip
When using continue in a while loop, either update the control variable before continue, or ensure another path in the body updates it so termination remains possible.
