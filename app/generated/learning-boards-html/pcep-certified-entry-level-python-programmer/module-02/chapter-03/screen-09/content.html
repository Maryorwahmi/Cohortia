Module 3 › Chapter 2.3 › Infinite loops & off-by-one
Infinite loop
Occurs when the condition never becomes false. Often caused by missing updates or updates hidden behind branches not taken.
Off-by-one
Choose < vs <= depending on whether boundary values should be included. Trace the number of iterations to confirm expected counts.
Quick checklist
  • Is the control variable initialized?
  • Is it updated on every path through the loop?
  • Does the condition match the intended number of runs?
Example contrast
while count < 5 runs five times for count values 0..4. while count <= 5 runs six times for 0..5. Pick the comparison to match your intent.
Testing tip
Use small example ranges and print the counter each iteration to confirm the loop runs the correct number of times before scaling up.
Key takeaway
Small off-by-one mistakes or missing updates are common and easy to catch by tracing values and testing boundary cases.
