Module 3 › Chapter 2.3 › Countdown walkthrough
Source code
countdown = 5
print("Starting countdown...")
while countdown > 0:
    print(countdown)
    countdown = countdown - 1  # update
print("Blast off!")
Iteration trace
  • Iteration 1: countdown = 5 → print 5 → countdown becomes 4
  • Iteration 2: countdown = 4 → print 4 → countdown becomes 3
  • ... continues until countdown = 0 and the loop stops
Debug tip
If a loop never ends, add a temporary iteration counter or extra prints so you can see which value fails to change.
Mini exercise
Try removing the update line and run in a safe environment. Then restore the update and observe how behavior changes. What did you learn about termination?
Key takeaway
Every while loop must have a path that eventually makes the condition false unless you intentionally intend an infinite loop with a break exit later.
