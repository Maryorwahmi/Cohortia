Guarding example
# Using short-circuit to avoid IndexError
my_list = []
if my_list and my_list[0] == 'first_item':
  print("First item present")
else:
  print("No first item or list empty")
my_list is tested first; when it's empty the second part is not evaluated and no error occurs.
When short-circuit helps
  • Prevent runtime errors by checking safe conditions first.
  • Skip expensive calculations when not necessary.
  • Avoid using side-effectful expressions that may get skipped, which harms readability.
Check your understanding
Identify which part of an expression you should place first to protect later parts from errors.
Key Takeaway

Order conditions to protect later checks and avoid dangerous side effects when relying on short-circuiting.
