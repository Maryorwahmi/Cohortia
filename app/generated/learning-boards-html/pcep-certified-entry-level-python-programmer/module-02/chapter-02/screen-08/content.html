Module 2 › Chapter 2.2 › Operator precedence
Precedence summary
  • not is evaluated before and
  • and is evaluated before or
Example
if not A and B is interpreted as (not A) and B. If you intend to negate the whole pair, write not (A and B).
Practical patterns
  1. Use parentheses to make groupings explicit.
  2. Extract complex sub-conditions into named booleans to document intent.
  3. When rewriting negative logic, check equivalence using a few sample inputs.
Common Mistake

Assuming left-to-right evaluation produces the intended grouping without parentheses.
