Module 2 › Chapter 2.2 › Combining comparisons
Examples
# Chained comparison vs explicit
age = 30
# chained form
if 18 <= age <= 65:
  print("Age within working range")

# explicit combined form
is_age_ok = (age >= 18) and (age <= 65)
if is_age_ok:
  print("Age within working range")
Both forms are valid. The explicit named boolean improves readability for complex validations.
Design recommendation
  • Extract comparisons into named booleans when they represent meaningful checks.
  • Use parentheses to group combined logic and document intent.
  • Test edge cases where comparisons change truth values to avoid off-by-one errors.
Key Takeaway

Name important comparisons and then combine them — it makes logic easier to read and verify.
