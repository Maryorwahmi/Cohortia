Learning Objectives

Skills you'll practice and why they matter for program correctness and safety.

Bloom: Learn → Understand → Apply → Master
01
Understand operator syntax

Know what and, or, and not do and how they change boolean expressions. This helps you read and write conditions correctly.

VERIFIED COMPETENCY MILESTONE
02
Build compound expressions

Combine comparisons and booleans to express multi-part rules, using parentheses for clarity and correctness.

VERIFIED COMPETENCY MILESTONE
03
Predict using truth tables

Use truth tables to determine outcomes before running code, which strengthens debugging and test design skills.

VERIFIED COMPETENCY MILESTONE
04
Short-circuit & safe checks

Apply short-circuit behavior to avoid errors and boost performance, such as guarding list access with a prior truth test.

VERIFIED COMPETENCY MILESTONE
