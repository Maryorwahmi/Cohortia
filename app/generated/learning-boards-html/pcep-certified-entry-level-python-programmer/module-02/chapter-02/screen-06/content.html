Module 2 › Chapter 2.2 › or — at least one condition
Code example
# Example: discount eligibility
is_senior = False
is_student = True
has_coupon = False

if is_senior or is_student or has_coupon:
  print("You qualify for a discount!")
else:
  print("No discount applied.")
Only one of the three booleans needs to be True for the discount to apply.
Explanation & checklist
  • or is useful when there are multiple acceptable conditions.
  • Ensure the alternatives do not unintentionally broaden access or change security rules.
  • Remember short-circuit behavior: a True left-hand operand skips evaluation of the right-hand side.
Check your understanding
Try flipping each boolean to False and True and predict the printed output before running the code.
Key Takeaway

Use or to express alternatives, and test permutations to avoid accidental permissiveness.
