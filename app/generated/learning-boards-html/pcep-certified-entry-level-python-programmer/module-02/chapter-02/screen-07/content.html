Module 2 › Chapter 2.2 › not — invert a condition
Example
is_sunny = False
if not is_sunny:
  print("It might be cloudy or rainy today.")
else:
  print("Don't forget your sunglasses!")
not flips the boolean value of is_sunny so the first branch runs when the day is not sunny.
Practical notes
  • Use not for single-term negation or for clarity when testing the opposite of a condition.
  • When negating complex expressions, add parentheses or rewrite positively to avoid misreading the logic.
  • De Morgan's laws show equivalent positive forms and can guide clearer rewrites.
Common mistake
Applying not to an entire combined expression without parentheses can change which parts are negated—be explicit.
Key Takeaway

Use not to invert conditions, but be explicit with parentheses or positive rewrites for compound logic.
