Module 2 › Chapter 2.2 › What logical operators are
Definition

Logical operators combine or invert boolean expressions

Use simple analogies: and as multiple keys, or as a voting system, not as a flip of state. These help you choose the correct operator when framing rules.

and — all required
Gate with multiple keys: if one key is missing the gate stays closed.
or — any one suffices
Voting system: one positive vote is enough to pass.
not — invert
Flips the outcome of a single boolean expression.
Example cards
Driving eligibility

age >= 18 and has_license must both be true to allow driving.

Discount rule

is_senior or is_student or has_coupon — any one true grants a discount.

Negation

if not is_sunny: take the umbrella path.

Key Takeaway

Map each operator to a real-world analogy and test with simple code before combining operators.
