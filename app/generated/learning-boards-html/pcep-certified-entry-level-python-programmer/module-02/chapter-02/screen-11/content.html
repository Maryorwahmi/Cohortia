Security example
if user_authenticated or user_is_admin grants access if either is True. If the intent is to require both, use and. A misplaced or can allow unauthorized access.
Danger
Logical mistakes in permission checks can create real security vulnerabilities. Double-check boolean logic in sensitive code paths.
Debugging checklist
  1. Read the requirement as a sentence and compare it to the code.
  2. Add parentheses to show intended groupings.
  3. Break logic into named booleans for clarity and test them separately.
Key Takeaway

Translate natural language requirements carefully and avoid implicit assumptions about truthiness or precedence.
