Module 2 › Chapter 2.2 › and — require every condition
Code example
# Example: driving eligibility
age = 25
has_license = True

if age >= 18 and has_license:
  print("You are eligible to drive.")
else:
  print("You are not eligible to drive.")
This code prints the eligibility message only when both checks are True.
Explanation & common pitfall
  • and returns True only when every condition is True.
  • Python stops evaluating subsequent conditions if an earlier one is False — this is short-circuiting.
  • Do not rely on order-insensitive behavior if any test has side effects; order can matter.
Pro tip
Guard expressions that would raise errors by placing a safe check first, for example verifying a list is non-empty before indexing it.
Key Takeaway

Use and for mandatory conditions and to protect later checks using short-circuiting.
