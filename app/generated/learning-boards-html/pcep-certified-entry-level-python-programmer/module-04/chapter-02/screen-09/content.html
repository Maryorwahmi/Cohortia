Difference and symmetric difference

A = {1,2,3}
B = {3,4,5}
A - B   # {1,2}
B - A   # {4,5}
A ^ B   # {1,2,4,5}  # symmetric difference
Practical tips
  • To find items removed between snapshots, use old_set - new_set.
  • To detect items added, use new_set - old_set.
  • To show any change, use symmetric difference to highlight all differences.
Key Takeaway

Use difference to ask directional questions and symmetric difference to see all exclusive changes.
