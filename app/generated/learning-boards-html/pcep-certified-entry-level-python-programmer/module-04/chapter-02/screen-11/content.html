Definition

Hashability and allowed element types

Sets accept hashable elements such as numbers, strings, and tuples of hashable items. Mutable containers like lists or dicts are not allowed.

# allowed
s = set()
s.add((1, 2))   # tuple is hashable

# not allowed
# s.add([1, 2])  # raises TypeError: unhashable type: 'list'
Checklist
  • If an element can change its contents, it’s not safe to use in a set.
  • Use tuples for small immutable records that need to be in sets.
  • If you must store mutable objects, consider identifiers or frozen representations.
Key Takeaway

Confirm element hashability to avoid TypeError and ensure set behavior remains reliable.
