Core Concept

Sets are unordered and unique

Think of a set as a bag of unique items. Order is irrelevant and duplicates are discarded automatically.

Example
my_set = {1, 2, 3, 2, 4}
# my_set becomes {1, 2, 3, 4}
my_list = [1,1,2,3,3]
unique = set(my_list)
# unique is {1,2,3}
Common mistake
Using {} to make an empty set creates a dictionary instead. Use the constructor to make an empty set.
Visual proof
{1, 2, 3, 2, 4} → {1, 2, 3, 4}
{} is a dict; empty set is set()
No indexing: my_set[0] raises a TypeError
Key Takeaway

Choose sets when uniqueness matters and you don’t need order or indexing.
