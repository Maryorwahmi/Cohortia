Process Flow

Registered vs attended example

registered_users = {"Alice", "Bob", "Charlie", "David"}
attended_users = {"Bob", "Charlie", "Eve", "Frank"}
registered_but_absent = registered_users - attended_users
late_signups = attended_users - registered_users
both = registered_users & attended_users
# registered_but_absent: {'Alice','David'}
# late_signups: {'Eve','Frank'}
# both: {'Bob','Charlie'}
Explanation cards
Registered but absent: registered - attended
Attended but not registered: attended - registered
Both registered and attended: intersection
Key Takeaway

Express attendee analysis with set operations instead of manual loops for clarity and speed.
