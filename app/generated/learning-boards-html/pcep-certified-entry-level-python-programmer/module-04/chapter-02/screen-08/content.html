Union and intersection in practice

Use union to gather all unique items across sources and intersection to find the common items shared by both sources.

Scenario
registered_users = {'Alice', 'Bob', 'Charlie', 'David'} attended_users = {'Bob', 'Charlie', 'Eve'}
Union → {'Alice','Bob','Charlie','David','Eve'}
Intersection → {'Bob','Charlie'}
Quick strategy
  • If you only need overlap, intersect the smaller set into the larger one for performance.
  • Chain operations to express multi-step queries in readable code.
  • Remember: operators return new sets; originals remain unless reassigned.
Key Takeaway

Map data questions to union/intersection for concise, efficient comparisons.
