Definition

Create sets from literals and iterables

Use curly braces for explicit sets and the set constructor for general iterables and empty sets.

# set literal with duplicates
my_set = {1, 2, 3, 2, 4}
# result: {1, 2, 3, 4}

# convert iterable to set
data = [1,1,2,3,3]
unique = set(data)
# unique is {1,2,3}

# empty set (correct)
empty_set = set()
# {} is an empty dict, not a set
Quick checks
  • Converting a list to a set removes duplicates but does not preserve order.
  • Use set() for empty sets; curly braces mean a dict for empty literal.
  • The set constructor accepts any iterable, including tuples and strings.
Key Takeaway

Prefer set() when creating from other collections or when you need an empty set.
