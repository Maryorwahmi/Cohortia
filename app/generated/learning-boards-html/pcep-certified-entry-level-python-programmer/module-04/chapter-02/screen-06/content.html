Process Flow

Add and remove items

add()
Insert single element; ignores duplicates.
update()
Merge an iterable of elements into the set.
remove()
Remove element; raises an error if missing.
discard()
Remove element if present; no error if missing.
pop()
Remove an arbitrary element and return it.
Example walkthrough
ids = {101, 102, 103}
ids.add(104)
ids.update([105,106])
# ids now contains 101..106
ids.discard(999)   # safe: no error if absent
try:
  ids.remove(999)  # would raise KeyError
except KeyError:
  pass
popped = ids.pop()  # removes an arbitrary element
Key Takeaway

Pick discard to avoid errors when removal may be optional and remove when absence is exceptional.
