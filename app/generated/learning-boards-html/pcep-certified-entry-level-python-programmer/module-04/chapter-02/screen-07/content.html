Set operations and their meanings

Union (|) — all unique elements from both sets.
Intersection (&) — elements common to both sets.
Difference (-) — elements in the first set but not the second.
Symmetric difference (^) — elements in either set but not both.
Examples
set1 = {1, 2, 3}
set2 = {3, 4, 5}
set1 | set2     # {1,2,3,4,5}
set1 & set2     # {3}
set1 - set2     # {1,2}
set1 ^ set2     # {1,2,4,5}
Note: these operations return new sets. Use them to write concise comparisons instead of manual loops.
Key Takeaway

Set operators express common data-comparison questions with clear, fast operations.
