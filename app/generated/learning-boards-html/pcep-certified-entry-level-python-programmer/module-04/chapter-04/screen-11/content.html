Module 5 › Chapter 4.4 › Parsing a log entry
Example: break into parts
log_entry = "2023-10-27 14:35:01 - INFO - User 'john_doe' logged in from IP 192.168.1.100"
parts = log_entry.split(' - ')
# parts -> [timestamp, level, message_part]
timestamp = parts[0]
log_level = parts[1]
message_part = parts[2]

# extract username
start = message_part.find("'") + 1
end = message_part.find("'", start)
username = message_part[start:end]

# extract IP
ip_start = message_part.rfind(" ") + 1
ip_address = message_part[ip_start:]
Key step

Check that find returned valid positions before slicing to avoid incorrect substrings or negative indices.

Common mistake

Indexing parts without validating split length can raise errors for malformed lines. Always guard list indexing.

Formatted output
print(f"Timestamp: {timestamp}")
print(f"Log Level: {log_level}")
print(f"Username: {username}")
print(f"IP Address: {ip_address}")
