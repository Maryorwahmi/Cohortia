Module 5 › Chapter 4.4 › Strings are immutable
Core Concept

Immutability with examples

Understand that plus and asterisk create new strings; slicing returns a new substring. Use reassignment when you expect a change to persist.

Concrete examples
greeting = "Hello" + " " + "World!"    # concatenation
stars = "*" * 5                         # repetition -> "*****"
my_string = "Python"
slice_part = my_string[1:4]              # -> "yth" (index 1..3)
last_char = my_string[-1]                # -> 'n'
Common mistake

Expecting methods to modify the original string. Always assign the return value to preserve changes.

Key takeaway

Treat strings like safe read-only sequences; reassign transformed values when needed.

Slicing visual guide
Original
P y t h o n
Indices: 0 1 2 3 4 5 | negative: -6 -5 -4 -3 -2 -1
Slice example
my_string[1:4] -> y t h
End index is exclusive. Off-by-one errors are common; check intended characters.
Try a quick mental check: to include the first three characters use my_string[:3]. To get all but the last character use my_string[:-1]. These patterns are predictable once you remember zero-based indexing and exclusive end positions.
