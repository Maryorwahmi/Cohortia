Module 5 › Chapter 4.4 › Common mistakes

Frequent errors

  • Off-by-one slicing: verify the exclusive end index.
  • Calling join on a list instead of the separator string.
  • Assuming methods mutate the original string rather than returning new ones.
  • Mismatched placeholders and arguments in format or percent formatting.

Debugging tips

Print intermediate tokens after split to confirm structure.
Use find() checks or try-except around index when format is inconsistent.
Normalize and validate before aggregation: strip and lower before using as keys.
Key takeaway

Small checks and normalized inputs prevent many common string-related bugs.
