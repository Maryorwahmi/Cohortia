Module 5 › Chapter 4.4 › Key Concepts
Immutability
Methods return new strings; reassign when you need the change to persist.
split / join
split turns text to tokens; join concatenates tokens using the separator string.
strip / replace
strip removes edge characters; replace substitutes occurrences inside the string.
Summary

Practice these core methods in sequence: clean input, split into tokens, validate, and format output with f-strings.
