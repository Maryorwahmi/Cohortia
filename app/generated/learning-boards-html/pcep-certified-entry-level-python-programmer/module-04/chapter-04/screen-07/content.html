Module 5 › Chapter 4.4 › find() vs index()
Comparison

Behavior difference

Use the safest option depending on whether a missing substring is expected or exceptional.
find()
Returns -1 when not found. Good for conditional checks before slicing or parsing.
index()
Raises ValueError when not found. Use when absence should trigger an explicit error path.
Example: extract quoted username
message_part = "User 'john_doe' logged in"
start = message_part.find("'")
if start != -1:
  end = message_part.find("'", start+1)
  username = message_part[start+1:end]
else:
  username = ""  # handle missing quotes gracefully
If you used index instead of find and quotes were missing, your code would raise and require try-except to continue. Choose the approach that fits your error-handling strategy.
