Use f-strings for readable output

Embed variables and simple expressions directly and apply specifiers for numeric formatting.

name = "Alice"
age = 30
pi = 3.14159

# Simple interpolation and numeric formatting
print(f"My name is {name} and I am {age} years old.")
print(f"Pi to two decimal places: {pi:.2f}")

# Alignment and thousands separator
value = 12345.678
print(f"Value: {value:>10,.2f}")
Formatting notes
  • :.2f rounds floats to two decimals.
  • :, adds thousand separators.
  • >10 right-aligns in a 10-character field.
Pro tip

Keep expressions inside braces simple and side-effect free. Use helper variables when needed for clarity.
