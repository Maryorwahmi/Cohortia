Module 5 › Chapter 4.4 › Trimming and replacing
Definition

strip, lstrip, rstrip

Use these to remove unwanted leading/trailing characters. By default they target whitespace, but you can give a character set to strip.

text = "   Hello World   "
clean = text.strip()        # 'Hello World'
left = text.lstrip()       # 'Hello World   '
right = text.rstrip()      # '   Hello World'
When to use

Trim before parsing or validation to avoid false negatives when checking isdigit or equality.

Replace

replace(old, new)

Use replace to substitute substrings. It replaces all occurrences and returns a new string. For targeted changes, combine with find and slicing.

msg = "I like apples"
new_msg = msg.replace("apples", "oranges")  # 'I like oranges'
Pitfall

replace is global; accidental replacements may change substrings you didn't intend. Verify before using on large texts.
