Module 5 › Chapter 4.4 › split() and join()
Process Flow

Tokenize, transform, rebuild

Follow the numbered process to parse CSV-like text into structured values and format a final report.
1
Split by entries
Use split(',') to get individual product strings; call strip() on each to remove stray spaces.
2
Split fields
For each entry split by ':' to separate name and quantity, then validate quantity with isdigit before int conversion.
3
Rebuild
Use a separator like ' ' or ', ' and call join() on it to produce the final display string.
Example walkthrough
raw = "  apples:10 , BANANAS:5,   oranges:2   "
entries = [e.strip() for e in raw.strip().split(',')]  # ['apples:10','BANANAS:5','oranges:2']
for e in entries:
  name, qty = e.split(':')
  name = name.strip().lower()
  qty = qty.strip()
  if qty.isdigit():
    # convert and use
    pass
Pitfall

Consecutive delimiters can produce empty strings; filter them out before indexing.

Pro tip

Use list comprehensions to trim each token after splitting for cleaner downstream logic.
