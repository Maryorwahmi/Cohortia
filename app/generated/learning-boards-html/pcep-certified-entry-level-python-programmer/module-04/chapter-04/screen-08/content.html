Case transforms

Normalize text for comparison and display. Choose lower-case keys for storage and a formatted version for user-facing output.
Methods
upper(), lower(), capitalize(), title() — each returns a new string with transformed case.
Example
'BANANAS'.lower() -> 'bananas'; 'apples'.capitalize() -> 'Apples'.

Validation helpers

Use isdigit, isalpha, isalnum to check content before conversions or logic branches.
qty_str = " 10 "
if qty_str.strip().isdigit():
  qty = int(qty_str.strip())
else:
  # handle invalid quantity
  pass
Remember: isdigit does not accept negative signs or decimal points. For those cases, use a conversion attempt with try-except on int or float.
