Module 4 › Chapter 4.1 › Key Concepts
Tuple
An ordered, immutable collection useful for fixed records.
Packing & Unpacking
Pack by listing values; unpack to assign multiple variables in one statement.
count() & index()
Inspection methods that read contents; index raises ValueError when absent.
Final takeaway

Use tuples to express immutability and fixed records. Remember the trailing comma for single items and prefer unpacking for clear multi-value assignments.
