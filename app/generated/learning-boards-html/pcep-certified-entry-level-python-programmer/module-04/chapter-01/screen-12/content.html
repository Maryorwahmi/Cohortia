Implement the search using unpacking

def find_student_score(student_id, records):
    scores = []
    for record in records:
        sid, subject, score = record
        if sid == student_id:
            scores.append(score)
    return scores

# Using the starter records, calling find_student_score(101, grade_records)
# returns [85, 78]
Why unpacking helps
It gives direct names to fields so comparisons and appends read naturally and keep intent clear.
Edge cases
If no matches are found, return an empty list. If records have unexpected structure, validate length before unpacking.
