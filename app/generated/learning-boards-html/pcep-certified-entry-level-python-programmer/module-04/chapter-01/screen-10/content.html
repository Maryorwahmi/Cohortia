Module 4 › Chapter 4.1 › Tuples vs Lists
Comparison

When to use each type

Choose tuple
Fixed records, hashable keys, small immutable groups of values.
Choose list
Collections you will modify: append, remove, or reorder items frequently.
Memory & semantics
Tuples communicate immutability and may be more memory efficient for fixed data.
Edge case
Hashability note
A tuple is hashable only if every element inside it is hashable. If an element is a list or another unhashable type, the tuple cannot be used as a key.
Decision question
Ask whether you expect the sequence to change. If yes, choose a list. If not, choose a tuple to signal immutability.
Key Takeaway

Pick the type that matches intended use: safety and hashability for tuples, mutability and flexibility for lists.
