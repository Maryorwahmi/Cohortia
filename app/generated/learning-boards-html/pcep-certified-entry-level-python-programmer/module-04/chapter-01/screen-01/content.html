Tuples — Immutable Sequences

A tuple is an ordered sequence that cannot be changed after it's created. Keep data stable, use tuples as records, and unpack values simply.

In this lesson

What you'll understand and why it matters

Tuples help you keep collections intact. Use them when the structure represents a single record or when you need hashable containers for keys. We'll practice syntax, indexing, packing, unpacking, and common methods.

Creation
Parentheses or commas, with a trailing comma for singles.
Operations
Indexing, slicing, count and index methods only.
Use-cases
Fixed records, dictionary keys, return multiple values.
Visual Concept

Tuple as a Locked Record

Think of a tuple as a small, sealed card that lists values in order. You can read any entry, but you cannot change what’s inside the sealed card.
