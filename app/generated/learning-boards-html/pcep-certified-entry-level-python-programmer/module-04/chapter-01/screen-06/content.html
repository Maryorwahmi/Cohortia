Core Concept

Read only access with indexing and slicing

Indexing returns a single element. Slicing returns a new tuple. Both obey the same zero-based rules as lists.

t = (1, 2, 'hello', True)
first = t[0]        # 1
sub = t[1:3]        # (2, 'hello')
step = t[0:4:2]     # (1, 'hello')
Misconception
Slicing does not modify the original tuple. It creates a new tuple containing selected elements.
Example
Coordinate extraction
Given coordinates = (10, 20, 5), indexing gives x = 10, y = 20. Use slicing to get multiple components if needed.
Why it matters
Indexing and slicing are predictable operations on immutable sequences, enabling safe reading of structured data without side effects.
Key Takeaway

Index and slice tuples to read values; remember slices are new tuples and do not change the source.
