Forms of tuple creation

Use parentheses for clarity, or list items separated by commas for packing. For a single element, include a trailing comma to create a tuple rather than a grouped expression.
my_tuple = (1, 2, 'hello', True)
another_tuple = 10, 20, 'world'
single_item = (42,)
Tip
When reading code, ask whether parentheses group an expression or define a tuple. The comma matters.
Common mistake
Writing (42) yields the integer 42, not a tuple. Add a trailing comma to create a single-element tuple.
Concrete example
Packing example
Assign multiple return values from a function into variables directly by listing them. Packing happens when values are comma-separated.
Why it matters
Correct creation prevents type surprises and keeps records predictable when used as keys or immutable records.
Key Takeaway

A comma — not parentheses alone — is what defines a single-element tuple; use parentheses for readability in complex expressions.
