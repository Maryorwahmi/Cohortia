Packing and unpacking in action

# Packing creates a tuple implicitly
coords = 10, 20

# Unpacking assigns elements to variables
x, y = coords

# Swapping without temporary
a, b = b, a
Example use
A function returning name and age can be assigned directly: name, age = get_user_info(). Unpacking improves readability over index access.
Notes & pitfalls
Mismatch errors
If the number of variables does not match the tuple length, Python raises a ValueError. Use extended unpacking if needed.
Why it matters
Unpacking creates clearer code, especially when handling multiple return values or swapping variables concisely.
Key Takeaway

Packing and unpacking are idiomatic ways to move between grouped values and individual variables with clear, concise syntax.
