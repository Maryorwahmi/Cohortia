Module 4 › Chapter 4.1 › What is a tuple?
Definition

Tuple — ordered and immutable

An ordered collection that cannot be changed once created. Think of it as a sealed record with numbered slots you can read but not alter.

Ordered
Each item has a stable index starting at zero; indexing and slicing behave like lists.
Immutable
You cannot assign to elements or change length; attempts raise an error, which enforces safety.
Hashable uses
If elements are themselves hashable, the tuple can be used as a dictionary key or set element.
Example & contrast
Example record
A student record: (1001, "Alice Smith", "2005-03-15") — the ID and date of birth remain constant, preventing accidental changes.
Common misconception
Immutability is not a limitation. Use lists when you must change items; use tuples when you want fixed content.
Key Takeaway

Tuples give you predictable, read-only sequences ideal for fixed records and hashable containers.
