Definition

count and index explained

These methods let you inspect a tuple's contents without mutating it. Use them to gather simple statistics or find positions of values.

t = (1, 2, 2, 3, 2)
occ = t.count(2)     # 3
pos = t.index(3)     # 3

# If value missing, index raises ValueError; check membership first.
Practice tip
Before calling index, consider using membership testing to avoid a ValueError when a value might be absent.
Scenario
Score analysis
Given student scores in a tuple, count returns how many times a particular score occurs; index finds the first appearance.
Misconception
These methods do not mutate data. If you need to update occurrences, create a new tuple or use a mutable structure like a list.
Key Takeaway

Use count and index for simple inspections; handle missing values before calling index to avoid exceptions.
