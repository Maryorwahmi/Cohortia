Comparison

Square brackets vs get

• Square brackets return a value or cause a KeyError if the key is missing.
• The get operation returns None or a supplied default when the key is missing.
• Use brackets when the key must exist; use get to avoid exceptions with optional fields.
Misconception
get avoids exceptions but can hide bugs if you silently accept None; choose explicit defaults to reveal issues early.
Code examples
student = {"name": "Alice", "age": 20}

# Direct lookup (assumes key exists)
print(student["name"])  # prints Alice

# get with default (safe if key missing)
print(student.get("gpa", "N/A"))  # prints N/A if no gpa
Notice: use a clear default value to make behavior explicit and avoid silently accepting None when that would be awkward later.
