Module 4 › Chapter 4.3 › Keys must be immutable
Definition

Hashable keys only

• Keys must be immutable so Python can compute stable hashes for lookup.
• Use strings, numbers, or tuples for composite keys.
• Avoid lists, dictionaries, or sets as keys; they will raise a TypeError.
Common error
Attempting to use a mutable key causes a TypeError. Convert mutable components to a tuple or string first.
Example alternative: instead of using a list of coordinates as a key, use a tuple of coordinates so it remains immutable.
Pro Tip

When in doubt, choose a simple string or integer key and store complex, mutable data as the associated value.
