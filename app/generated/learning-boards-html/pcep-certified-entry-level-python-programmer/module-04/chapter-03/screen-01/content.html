Dictionaries — Key‑Value Pairs

Model labeled data with unique keys and flexible values. Perfect for lookups, configuration, and nested structures like JSON.

In this lesson you will see: safe access patterns, methods for adding and removing, iteration strategies, and practical examples such as a contact book and frequency counter.
Explore Key Topics
Creating
Use curly braces or the dict constructor to build mappings.
Accessing
Square brackets raise errors; get returns a default.
Iteration
Loop keys, values, or items to process data efficiently.

Key Takeaway

Use dictionaries when you need fast lookup by a meaningful label rather than by an index. Keys must be immutable and unique; values can be any type, including nested dictionaries.
