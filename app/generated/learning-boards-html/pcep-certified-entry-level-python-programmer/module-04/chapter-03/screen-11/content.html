Architecture

Sensor data model

sensor_data = {
    "sensor_A": {"temperature": 25.5, "humidity": 60},
    "sensor_B": {"temperature": 23.1, "pressure": 1012}
}

# Update nested value
sensor_data["sensor_A"]["temperature"] = 26.0

# Add new sensor
sensor_data["sensor_C"] = {"temperature": 24.0, "light": 500}
Ensure the top-level key exists before assigning inner keys to avoid errors. Use setdefault when you want to create the inner dictionary on demand.
Patterns
• Create nested dictionaries for grouped attributes.
• Use setdefault(key, {}) to initialize an inner dictionary safely.
• Avoid shared mutable references across multiple keys unless intentional.
Why it matters

Nested mappings mirror JSON and many API responses, making dictionaries a natural choice for parsing and building structured data.
