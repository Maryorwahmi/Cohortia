Module 4 › Chapter 4.3 › Creating dictionaries
Process Flow

Steps to create

  1. Decide meaningful keys that are immutable, such as strings or numbers.
  2. Choose values that represent the data, allowing nested structures when needed.
  3. Use braces for simple literals or dict for programmatic construction.
  4. Assign to a variable and verify with a quick print or inspection.
Key Takeaway

Prefer literal braces for clarity; use dict when converting other structures into a mapping.

Examples
# Literal dictionary
student = {"name": "Alice", "age": 20, "major": "Computer Science"}

# Empty dictionaries
empty1 = {}
empty2 = dict()

# Numeric keys for inventory
inventory = {101: 50, 102: 120, 103: 75}
Try both literal and constructor styles. Use fresh empty dictionaries to avoid accidental shared state in functions.
