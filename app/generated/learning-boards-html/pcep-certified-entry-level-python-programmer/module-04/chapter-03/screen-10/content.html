Module 4 › Chapter 4.3 › Contact book
Starter code
contact_book = {}

def add_contact(book, name, phone, email):
    book[name] = {"phone": phone, "email": email}
    print(f"Contact '{name}' added/updated.")

def get_contact_info(book, name):
    contact = book.get(name)
    if contact:
        print(f"Contact: {name}")
        print(f"  Phone: {contact['phone']}")
        print(f"  Email: {contact['email']}")
    else:
        print(f"Contact '{name}' not found.")

def delete_contact(book, name):
    if name in book:
        del book[name]
        print(f"Contact '{name}' deleted.")
    else:
        print(f"Contact '{name}' not found.")
This code shows straightforward use of assignment, get for safe retrieval, and del after a membership check.
Walkthrough
• add_contact assigns a nested dictionary with phone and email as values.
• get_contact_info uses get to avoid errors when a name is missing and prints structured details when found.
• delete_contact checks membership before using del to avoid KeyError.
