Module 4 › Chapter 4.3 › When to use dictionaries

Common scenarios

Lookup by ID
Map user or product IDs to records for fast retrieval.
Configuration
Store keyed settings and default values for application options.
Counting & grouping
Accumulate frequencies or group items under labels efficiently.
Combine dictionaries with lists when you need ordered collections of records, or when each label points to a sequence of items. Always decide based on lookup patterns and data mutability.
