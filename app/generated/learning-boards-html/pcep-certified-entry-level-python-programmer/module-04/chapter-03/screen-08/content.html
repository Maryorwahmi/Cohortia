Module 4 › Chapter 4.3 › Iteration
Patterns
• for key in dict: iterates keys.
• dict.values() yields values only.
• dict.items() yields key‑value tuples; unpack with for key, value in dict.items().
• Avoid changing the dictionary while iterating over it.
If you must mutate, iterate over list(dict.keys()) to work on a stable snapshot.
Code walkthrough
contacts = {"Alice": {"phone": "123-456"}, "Bob": {"phone": "987-654"}}

# Keys
for name in contacts:
    print(name)

# Values
for info in contacts.values():
    print(info["phone"])

# Items with unpacking
for name, info in contacts.items():
    print(name + ": " + info["phone"])
Unpacking makes code readable: name and info are explicit. Use values when you only care about data, not labels.
