Module 4 › Chapter 4.3 › Word frequency counter
Code example
text = "This is a test. This test is simple."
words = [w.strip(".?,!").lower() for w in text.split()]

# Conditional pattern
counts = {}
for w in words:
    if w in counts:
        counts[w] += 1
    else:
        counts[w] = 1

print(counts)

# get shortcut
counts2 = {}
for w in words:
    counts2[w] = counts2.get(w, 0) + 1

print(counts2)
Both approaches produce the same result; the get shortcut is concise. Normalize text first to avoid counting the same word in multiple forms.
Explanation
• Split and normalize words before counting to ensure consistency.
• Use a dictionary where keys are words and values are counts.
• get provides a default zero to increment without conditionals.
• To filter short words, check length before updating counts.
