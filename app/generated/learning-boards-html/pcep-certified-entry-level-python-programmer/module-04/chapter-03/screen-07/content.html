Module 4 › Chapter 4.3 › Add / Modify / Delete
Definition

Common mutation patterns

• Add or update: assign to a key.
• Remove and ignore value: del key.
• Remove and use value: pop key with optional default.
• Empty dictionary: clear removes all items.
Common Mistake
Using pop without a default on a possibly missing key will cause a KeyError. Prefer a default when uncertain.
Example and scenario
product = {"id": 101, "stock": 50}

# Add or update
product["stock"] = 45  # update
product["name"] = "Widget"  # add

# Remove and retrieve
removed = product.pop("stock", "not found")

# Delete without return
if "name" in product:
    del product["name"]

# Clear all
product.clear()
Practice these patterns and check for missing keys before calling pop without a default.
