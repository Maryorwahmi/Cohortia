Learning Objectives

Bloom: Learn → Understand → Apply → Master

Bloom Progress
01
Create dictionaries
Use braces or the dict constructor to represent labeled data.
You’ll practice making empty and populated dictionaries and see how types of keys and values differ.
VERIFIED COMPETENCY MILESTONE
02
Access safely
Learn square‑bracket lookup and the get method to avoid errors.
Understand when to prefer a direct access that should exist and when to use a default value to prevent exceptions.
VERIFIED COMPETENCY MILESTONE
03
Add, change, remove
Assign to keys, delete with del, and remove with pop to get values back.
Practice updating values and handling attempts to remove missing keys gracefully.
VERIFIED COMPETENCY MILESTONE
04
Iterate and apply
Loop keys, values, and items and use dictionaries for real problems like counting.
You’ll implement a simple contact book and a word frequency counter to see dictionaries in action.
VERIFIED COMPETENCY MILESTONE
