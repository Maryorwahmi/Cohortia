Module 4 › Chapter 4.3 › What is a dictionary?
Definition

Dictionaries store labeled pairs

Keys identify values. Keys are unique and immutable. Values can be any type, including nested dictionaries.

• Analogy: a phone book where a name maps to a phone number.
• Unordered: rely on labels, not positions.
• Nested structures allow complex models, such as sensors with multiple readings.
Key Takeaway

Think in terms of keys and meaning, not numeric positions. Keys are your lookup handles.

Concrete Example
Student record
A single dictionary models named attributes.
student = {"name": "Alice", "age": 20, "major": "Computer Science"}
Keys: name, age, major. Values: string, number, string.
Nested example
Top-level keys map to sub-dictionaries for structured data.
sensor_data = {"sensor_A": {"temperature": 25.5, "humidity": 60}, "sensor_B": {"temperature": 23.1, "pressure": 1012}}
Access nested values by chaining two lookups.
Common Mistake
Using mutable objects like lists as keys will raise an error because keys must be immutable.
Pro Tip
Choose keys that are meaningful identifiers in your domain, such as user IDs or product SKUs, for clarity and correctness.
