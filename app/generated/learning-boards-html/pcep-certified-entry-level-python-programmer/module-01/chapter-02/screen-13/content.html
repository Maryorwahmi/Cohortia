Module 1 › Chapter 1.2 › Key Concepts
Variables
Named containers for values; pick clear names and initialize them reliably.
Data Types
int, float, str, bool — choose based on how you plan to use values and validate before casting.
Operators
Arithmetic and assignment operators perform calculations and update variables; remember precedence and floor division differences.
Summary

Practice small, runnable checks: assign a value, inspect its type, convert when needed, and compute with the correct operators to build stable programs.
