Data Types
int • float • str • bool
Each type describes allowed operations and how values behave in expressions and assignments.
Integer (int)
Whole numbers without decimals. Example: 42
Float (float)
Numbers with a decimal point. Example: 3.14
String (str)
Text enclosed in quotes. Example: "Hello"
Boolean (bool)
Truth values True or False. Used in conditions.
Quick comparisons and behavior
Numeric vs Text
A numeric literal like 10 behaves differently than the string "10". To use "10" in math you must convert it to a numeric type first.
Boolean usage
Booleans control flow: comparisons produce booleans, and logical operators combine them for decision-making.
Try this example
a = 10
b = 3.5
name = "Python"
is_ready = True

print(type(a))   # <class 'int'>
print(type(b))   # <class 'float'>
print(type(name))# <class 'str'>
print(type(is_ready)) # <class 'bool'>
Run these lines and inspect each printed type. This helps connect the term to runtime behavior.
