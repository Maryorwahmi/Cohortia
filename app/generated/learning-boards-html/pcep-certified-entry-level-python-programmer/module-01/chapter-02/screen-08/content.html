Code Examples
Quotes, concatenation, and conversion
name = "Alex"
score = 95

# convert number to string before concatenation
message = "Player: " + name + ", Score: " + str(score)
print(message)

# formatted output alternative (readable)
print(f"Player: {name}, Score: {score}")
Try both methods; formatted strings keep code clean and avoid explicit conversions scattered through expressions.
Notes & pitfalls
Immutability
String operations return new strings; modifying many large strings can be less efficient than joining lists.
Type error example
Adding a number and string directly causes a TypeError. Convert or format instead.
Key Takeaway
Convert non-strings before concatenation or use formatted strings for clarity and correctness.
