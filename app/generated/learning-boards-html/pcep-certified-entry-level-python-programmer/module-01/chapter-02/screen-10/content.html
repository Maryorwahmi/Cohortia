Cast Examples
Safe conversions and common ValueError
num_str = "123"
num_int = int(num_str)
print(num_int + 7)   # 130

price_str = "19.99"
price_float = float(price_str)
print(price_float * 2) # 39.98

bad = "hello"
# int(bad) would raise ValueError
Try converting numeric strings and observe results. To handle bad input, validate or use exception handling in later lessons.
Guidance
int() behavior
Converts strings of digits to integers; truncates decimal when converting floats to int by discarding the fractional part.
float() behavior
Converts decimal strings to floating-point numbers; useful when you need fractional arithmetic.
Common pitfall
Attempting to cast non-numeric strings raises ValueError. Validate input or use try-except to handle it gracefully.
