Starter code
Save and run the file named calculator.py
# Save this file as calculator.py

# 1. Define item_price (float)
item_price = 25.99

# 2. Define tax_rate (float, e.g., 0.07 for 7%)
tax_rate = 0.07

# 3. Calculate tax_amount
tax_amount = item_price * tax_rate

# 4. Calculate total_cost
total_cost = item_price + tax_amount

# 5. Print all calculated values clearly
print("Item Price: $", item_price)
print("Tax Rate: ", tax_rate * 100, "%")
print("Tax Amount: $", tax_amount)
print("Total Cost: $", total_cost)
Run the script and inspect printed values. If you read values from input later, convert strings to float before calculations.
Teacher hints
If you need the tax_rate displayed as 7 percent, multiply by 100 when printing. Validate any user input before casting to float to avoid ValueError.
