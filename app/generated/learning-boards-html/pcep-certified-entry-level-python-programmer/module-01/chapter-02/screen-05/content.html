Process
Rules and style steps for choosing names
Step 1 — Syntax rules
Start with a letter or underscore; follow with letters, numbers, or underscores; remember names are case-sensitive.
Step 2 — Avoid keywords
Do not use reserved Python keywords like if, for, or print as variable names; this will cause syntax errors.
Step 3 — Prefer snake_case
Use all lowercase with underscores to separate words for clarity and community consistency.
Step 4 — Avoid shadowing built-ins
Don't name variables list, str, or dict if you still need the built-in functionality later.
Examples and checks
# valid names
user_name = "Alex"
_total = 5
items_3 = 10

Key Takeaway

Clear, correct names reduce bugs and make code easier to read by others and yourself later.
