Comparison Examples
Operators that produce booleans
a = 10
b = 3
print(a == 10)   # True
print(b > 5)   # False
print(a != b)    # True

# combining
is_admin = False
has_permission = True
print(is_admin and has_permission) # False
print(is_admin or has_permission)  # True
Run these lines to observe True or False results and use the type function to confirm boolean type.
Notes
True and False
Boolean literals must be capitalized. They are commonly produced by comparison expressions.
Common pitfall
Confusing assignment and comparison. Using a single equals is assignment, double equals compares values.
Check your understanding
Try print(type(a > b)) to confirm comparisons return booleans and drive conditional logic.
