Division and type inspection
# integer and float division
x = 10
y = 3
z = 10.0

print(x / y)      # 3.333...
print(type(x / y))# <class 'float'>

print(x // y)     # 3
print(type(x // y))# <class 'int'>

print(z / y)      # 3.333...
print(type(z / y))# <class 'float'>
Run these lines to confirm when results are floats and when they are ints. Observe how float operands influence results.
Explanation cards
Division (/)
Always returns a float even for integer operands. Useful when fractional results matter.
Floor division (//)
Discards fractional part. Use when you explicitly need an integer quotient.
Check your understanding
If you divide a float by an int, the result is a float. Try print(type(10.0 / 3)).
