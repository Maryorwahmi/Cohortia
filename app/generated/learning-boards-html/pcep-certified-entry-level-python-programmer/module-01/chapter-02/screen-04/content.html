Module 1 › Chapter 1.2 › What is a Variable?
Core Concept
Variables as labeled boxes
Use variable names to describe data so code reads like a recipe. Clear names reduce bugs and make maintenance easier.
Analogy
A variable is like a labeled jar in a pantry. The label helps anyone pick the right ingredient when following a recipe.
Common mistake
Using reserved words like print as names or starting a name with a digit will produce syntax errors.
Key Takeaway
Name variables clearly and initialize them with meaningful values to make code self-explanatory.
Example assignments and inspection
# assign values
age = 30
user_name = "Cohortia"
price = 19.99
is_active = True

# inspect types
print(type(age))       # <class 'int'>
print(type(user_name)) # <class 'str'>
Run these lines to see each variable's type. Use descriptive names like user_name and item_price.
