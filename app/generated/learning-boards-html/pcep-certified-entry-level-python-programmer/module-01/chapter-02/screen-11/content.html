Arithmetic Operators
Common operators and examples
+ - *
Addition, subtraction, multiplication behave predictably on numeric types.
/ // % **
Division returns float, floor division truncates, modulo gives remainder, exponentiation raises to power.
Assignment operators
Use = to assign, and +=, -=, *= to update a variable by applying an operation then assigning back.
Example: rectangle area
length = 15.5
width = 7.2
area = length * width
print("The area of the rectangle is:", area)  # 111.6
The result type matches the operand types — multiplying floats yields a float. Use parentheses to clarify precedence when mixing operations.
Key Takeaway

Choose the right division for your problem and use combined assignment to write concise updates like x += 5.
