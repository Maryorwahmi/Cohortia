Objectives — Practical Skills
Explain Python
Define Python as a readable, interpreted, and general-purpose language and list two sample uses like web or data science.
Install & Verify
Confirm installation with a terminal version check so the interpreter is ready to run scripts.
Write & Run
Save a .py file and execute it to see print output, validating the save-execute cycle.
Fix Syntax Errors
Use interpreter messages to spot missing punctuation or unmatched delimiters and correct them.
Fix Indentation Errors
Use consistent indentation—typically four spaces—to avoid IndentationError when defining blocks.
Hands-on Practice
Complete the personal greeting script activity to verify your environment and skills.
