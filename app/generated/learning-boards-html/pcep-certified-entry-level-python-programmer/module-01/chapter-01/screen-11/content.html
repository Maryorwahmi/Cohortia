Syntax errors
Errors caused by incorrect structure or missing punctuation.
Example (erroneous)
print("This is my first program!"
This example is missing a closing parenthesis and will produce a syntax error indicating the statement is incomplete or an unexpected end of input.
How to debug
  • Read the interpreter's error message and check the reported line number.
  • Look for unmatched quotes, missing parentheses, or commas.
  • If the error persists, inspect the previous line — the real issue may start earlier.
Practice tip
Intentionally introduce a small syntax error and then correct it to learn how messages map to mistakes.
Common Mistake

Assuming the reported line always contains the root cause. Often an earlier line introduced the unmatched delimiter.
