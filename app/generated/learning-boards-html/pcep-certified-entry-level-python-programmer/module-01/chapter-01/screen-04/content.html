What is Python?
A high-level, interpreted, general-purpose language focused on readability.
Plain-language definition

Python reads like a readable recipe: it focuses on clear structure and uses indentation to mark blocks. The interpreter runs your code directly, which is ideal when you want quick feedback.

Concrete example
A short script can parse a text file and print a summary in a few lines, making Python a fast choice for small automation tasks.
Common misconception
Interpreted doesn't always mean slow; libraries and implementation choices often determine performance. The readability benefit is the key beginner advantage.
Key Takeaway

Python trades low-level control for developer productivity and readability, making it an excellent first language and a strong tool for many domains.

Quick facts
  • High-level: abstracts machine details for human-friendly code.
  • Interpreted: runs line by line through the interpreter.
  • General-purpose: used in web, data science, AI, automation, game development.
  • Readable: significant indentation reduces visual noise.
