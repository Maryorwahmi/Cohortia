Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Explain Python and uses
Describe Python's nature and common applications in web, data, AI, and automation, and why readability matters for collaboration.
VERIFIED COMPETENCY MILESTONE
02
Set up the interpreter
Install Python, add it to your path, and run a version check to confirm the interpreter is available for running scripts.
VERIFIED COMPETENCY MILESTONE
03
Write and run a script
Create a .py file that uses the print function, save it, and execute it from the terminal to see output immediately.
VERIFIED COMPETENCY MILESTONE
04
Find and fix errors
Identify common syntax and indentation errors using interpreter messages and correct them to restore execution.
VERIFIED COMPETENCY MILESTONE
