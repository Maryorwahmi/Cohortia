Run from terminal
A four-step sequence you will repeat often.
  1. 1. Save your file with a .py extension.
  2. 2. Open a terminal or integrated terminal in your editor.
  3. 3. Change directory to the file's folder.
  4. 4. Invoke the interpreter with the filename to execute.
Troubleshooting
If you encounter a command-not-found issue, confirm the interpreter installation and PATH. If the interpreter reports an error, use the line number to find and fix it.
Practical example
Navigate to your project folder and run the script. Seeing the expected output confirms the interpreter and file system are cooperating.
Key Takeaway

Mastering the terminal run loop is essential; it connects editing, saving, and executing into a fast development rhythm.
