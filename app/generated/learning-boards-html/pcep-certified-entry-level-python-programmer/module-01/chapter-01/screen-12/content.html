Indentation matters
Python uses indentation, not braces, to define code blocks.
Practical guidance
  • Use consistent indentation throughout a file, typically four spaces per level.
  • Do not mix tabs and spaces in the same file; configure your editor to insert spaces on Tab.
  • If you see an IndentationError, check line alignment and prior block openings.
Concrete example
Define a function and indent the body consistently. If any line uses a different indentation style, the interpreter will raise an IndentationError.
Editor tip
Enable visible whitespace and set your editor to replace tabs with spaces to avoid hidden inconsistencies.
Key Takeaway

Consistent indentation enforces clear block structure; configure your editor for spaces and practice small examples to build muscle memory.
