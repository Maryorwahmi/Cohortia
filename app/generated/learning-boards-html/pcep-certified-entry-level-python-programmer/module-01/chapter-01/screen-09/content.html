Module 1 › Chapter 1.1 › Your First Script
Create hello.py
Write a single print statement and save the file with a .py extension.
Code (example file)
print("Hello, Cohortia learners!")
Concrete steps
  • Save the file as hello.py in a known folder.
  • Open a terminal and change directory to that folder.
  • Run the script with the interpreter to see the greeting printed.
Terminal example
When you execute the script, the interpreter prints the message to your console, confirming the file executed without errors.
Common mistake
Omitting the closing quote around the string will cause a syntax error. Use the editor to spot unmatched quotes before running the script.
Key Takeaway

Print is an immediate verification tool; modify and re-run your script to learn the save-execute feedback loop.
