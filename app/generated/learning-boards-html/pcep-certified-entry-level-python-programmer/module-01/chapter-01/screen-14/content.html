Key Concepts
Python
A readable, interpreted, general-purpose language used across many fields.
Interpreter
Executes code line by line and provides error messages that help debugging.
print()
A built-in function used to display text to the console and verify program output.
Summary
These three concepts form the practical foundation: the language, the program that runs it, and the simple output tool you use first to observe behavior.
