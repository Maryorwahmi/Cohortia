Key Concepts — Continued
Script
A file with Python statements saved as .py and executed by the interpreter.
Syntax Error
Raised when code violates grammar rules, often due to missing punctuation or incomplete statements.
Virtual Environment
An isolated project environment created with venv to manage dependencies safely.
Final Reflection
Practice each concept: create a script, induce and fix a syntax error, and create a virtual environment to gain confidence and reproducibility.
