Module 2 › Chapter 1.3 › print() options
Default behavior
print joins multiple arguments with a space and ends with a newline by default.
Examples
print("apple", "banana", "cherry")
# Output: apple banana cherry

print("Hello", end=" ")
print("World!")
# Output: Hello World! (on same line)

print("apple", "banana", "cherry", sep=" - ")
# Output: apple - banana - cherry
When to prefer these options
  • Create compact lists or CSV-like lines using sep.
  • Keep prompts and user entry on the same line using end.
  • Avoid concatenation for layout; use sep or formatted strings instead.
Concrete scenario

When prompting for a value on the same line, use print("Enter value:", end=" ") so the cursor stays aligned with the prompt, producing a tidy interaction.

Key Takeaway

Use sep and end to control simple layout details rather than building concatenated strings manually.
