Learning Objectives
Each objective explains the skill, why it matters, and a small mnemonic to remember it.
01
Obtain input with input()

Learn to prompt users and capture text. This matters because every interactive program begins by reading user responses; practice with names and simple prompts builds confidence.

Mnemonic: Think "pause and read" — pause the program and read text.
VERIFIED COMPETENCY MILESTONE
02
Convert input types

Use int() and float() to turn text into numbers before arithmetic; this prevents TypeError and ensures calculations behave as expected.

Mnemonic: Cast before compute.
VERIFIED COMPETENCY MILESTONE
03
Control output with print()

Customize separators and line endings using the sep and end arguments to shape console output without awkward concatenation.

Mnemonic: Separator and End are small levers that shape the line.
VERIFIED COMPETENCY MILESTONE
04
Format strings with f-strings

Embed expressions and format specifiers inside string literals for clear, maintainable output. This is the recommended approach for modern Python code.

Mnemonic: f for fast, flexible formatting.
