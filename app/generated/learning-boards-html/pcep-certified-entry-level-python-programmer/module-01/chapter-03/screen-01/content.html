Input and Output, and String Formatting
Collect user data with input, convert types for computation, and present results with readable formatting techniques.
Orientation

This chapter teaches three practical skills: capturing typed input from the user, converting that text into numeric types when needed, and formatting output using print arguments, str.format, and f-strings. You will see short code examples and a small interactive scenario for practice.
