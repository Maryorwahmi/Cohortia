Embed expressions

Prefix literals with f and place expressions in curly braces to evaluate them inside the string.

price = 25.99
quantity = 2
total = price * quantity
print(f"You purchased {quantity} item(s) at ${price:.2f} each.")
print(f"Your total cost is ${total:.2f}.")
  • Embed arithmetic like {price * quantity} if desired, but prefer precomputed variables for clarity.
  • Use format specifiers to control numeric display directly inside braces.
Dynamic prompts

You can use f-strings when calling input to incorporate variables into prompts, making messages specific and helpful.

product = input("Enter product name: ")
price_str = input(f"Enter price for {product}: $")
Key Takeaway

F-strings are concise and expressive. Compute values first, then format them with f-strings for clear user-facing output.
