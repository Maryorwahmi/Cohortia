Module 2 › Chapter 1.3 › Formatting Methods
Concatenation

Join strings with +. Must convert non-strings manually. Readability decreases with many parts.

item = "Laptop"
price = 1200
print("The " + item + " costs $" + str(price))
str.format()

Use placeholders and format specifiers. Works on older Python versions and handles many formatting needs.

item = "Keyboard"
price = 75.5
print("The {} costs ${:.2f}.".format(item, price))
f-strings

Embed expressions directly and include format specifiers after a colon. Preferred for new code for clarity and power.

item = "Mouse"
price = 25.99
quantity = 2
print(f"You purchased {quantity} {item}(s) at ${price:.2f} each.")
print(f"Total: ${price * quantity:.2f}")
Practical guidance
  • Prefer f-strings for readability and inline expressions.
  • Use str.format when working in legacy contexts where f-strings are unavailable.
  • Avoid concatenation when combining mixed types; it forces many conversions and obscures intent.
Key Takeaway

F-strings are the most readable and flexible option for modern formatted output; use format specifiers to control numeric display.
