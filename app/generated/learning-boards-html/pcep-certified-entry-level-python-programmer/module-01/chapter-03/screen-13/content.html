Sample questions
Question 1

Which snippet correctly reads two numbers, adds them, and prints the result?

Answer: Convert inputs with int or float then add. For integers: num1 = int(input(...))
Question 2

Given variables city = 'London' and temperature = 15.789, what does f-string with {:.1f} print?

Answer: The temperature is rounded to one decimal place, producing 15.8 in the sentence.
Practice task

Write two versions of an addition program: one using int for whole numbers and one using float for decimals. Print results using f-strings to show the sum. Test with sample inputs to confirm behavior.

Key Takeaway

Answer assessment questions by following the read→convert→compute→format sequence, and pay attention to format specifiers when matching expected outputs.
