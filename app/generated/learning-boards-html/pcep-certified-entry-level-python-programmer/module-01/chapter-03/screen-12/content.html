Common runtime errors
TypeError

Occurs when you try to combine incompatible types, e.g., adding a string and an integer. Convert strings to int or float before arithmetic.

age_str = input("Age: ")
# Wrong: age_str + 5  -> TypeError
age = int(age_str)
print(age + 5)
ValueError

Raised when conversion functions can't parse the text. Use try-except to handle unexpected input gracefully.

try:
    value = int(input_str)
except ValueError:
    print("Please enter a valid number.")
Debugging tips
  • Print repr(input_value) to inspect exact text and whitespace.
  • Name variables to reflect raw vs converted values, e.g., price_str vs price.
  • Compute with numbers, then format only when printing.
Key Takeaway

When you see TypeError or ValueError, check whether inputs were converted appropriately and validate user-provided text before conversion.
