Module 2 › Chapter 1.3 › Type Conversion
Conversion steps
  1. Read input as a string with input().
  2. Decide the numeric type you need: int for whole numbers, float for decimals.
  3. Call int() or float() on the string and assign to a descriptive variable.
  4. Use try-except to catch ValueError if the input may be invalid.
Concrete code pattern
price_str = input("Enter price: $")
quantity_str = input("Enter quantity: ")

price = float(price_str)
quantity = int(quantity_str)
total = price * quantity
print(f"Total: ${total:.2f}")
Common pitfalls
Assuming implicit conversion
Python will not convert '30' to 30 without int or float; you must do it explicitly.
ValueError on invalid input
If the user types non-numeric text, int('abc') raises ValueError. Use try-except for robust programs.
Good habit
Convert once and use the converted variable. Name variables to reflect type, e.g., price_str vs price.
Key Takeaway

Choose int or float based on expected input and convert explicitly before arithmetic.
