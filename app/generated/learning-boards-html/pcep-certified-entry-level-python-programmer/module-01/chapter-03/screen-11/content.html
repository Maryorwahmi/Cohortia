Activity: Interactive Personal Information Form
Follow these steps to practice input, conversion, and f-strings.
Starter template
# Save as personal_info.py
user_name = input("What is your name? ")
favorite_color = input("What is your favorite color? ")
age_str = input("How old are you? ")
user_age = int(age_str)  # assume valid input

print(f"
--- Your Profile ---")
print(f"Name: {user_name}")
print(f"Favorite Color: {favorite_color}")
print(f"Age: {user_age} years old")
print(f"It's great to meet you, {user_name}!")
print(f"--------------------")
Hints and checks
  • Remember input returns a string; call int() to convert age.
  • Use f-strings to insert variables cleanly into your printed lines.
  • Test with different ages to ensure conversion succeeds.
Key Takeaway

This simple form practices the full flow: read input, convert where needed, and format output for a clear user summary.
