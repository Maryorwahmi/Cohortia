Format specifiers for floats
Use :.Nf to show N decimal places when embedding numbers into strings.
Example with f-strings
temperature = 15.789
print(f"Today: {temperature:.1f}°C")  # 15.8

price = 25.99
quantity = 2
print(f"Total: ${price * quantity:.2f}")  # 51.98
Why format, not raw float?

Raw floats can display long, surprising representations. Formatting produces human-friendly numbers and avoids confusion in user-facing output.

Practical rule

Compute with numeric values, then format the result for display. Keep computation and presentation separate so rounding does not affect accuracy of further calculations.

Key Takeaway

Use format specifiers like :.2f to present monetary and decimal values clearly and consistently.
