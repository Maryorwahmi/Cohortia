Module 2 › Chapter 1.3 › input() behavior
What input() does
It displays a prompt, waits for Enter, and returns the typed characters as a string.
Example (capturing a name)
name = input("Please enter your name: ")
print("Hello, " + name + "!")
Common mistake

Treating numeric-looking input as numbers without conversion leads to errors. For example, adding a numeric string to an integer raises a TypeError.

Key Takeaway

input() always returns text; convert explicitly with int or float when you need numeric behavior.

Annotated flow
Step 1 — Prompt
Call input with a prompt string to guide the user.
Step 2 — Pause and read
Program waits until the user presses Enter, then captures everything typed.
Step 3 — Use or convert
Use the returned string for display, or convert it to int/float for computation.
Concrete example
# Incorrect: will raise TypeError if user types 30
age_str = input("How old are you? ")
print(age_str + 5)  # TypeError

# Correct: convert before adding
age = int(age_str)
print(age + 5)
