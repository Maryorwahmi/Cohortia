Examples
NameError
# Example of NameError
print(my_variable)  # my_variable is not defined
TypeError
# Example of TypeError
"hello" + 5  # Cannot concatenate string and integer
ValueError
# Example of ValueError
int("abc")  # Cannot convert "abc" to an integer
More examples
ZeroDivisionError
# Example of ZeroDivisionError
result = 10 / 0
IndexError
# Example of IndexError
my_list = [1, 2, 3]
print(my_list[3])  # Index 3 is out of bounds
KeyError
# Example of KeyError
my_dict = {"name": "Alice"}
print(my_dict["age"])  # Key "age" does not exist
Pro Tip
When you see an exception name, treat it like a diagnosis. The name often suggests whether to check variable definitions, types, values, indexes, or dictionary keys.
