Question 1
A function converts each item with int() then divides by the list length. What goes wrong for data2 = ["5", "ten", "15"] and data3 = []?
Answer hint: data2 causes a ValueError because "ten" cannot be converted; data3 causes ZeroDivisionError due to length zero.
Question 2
You access student_scores["Charlie"] but Charlie isn't a key. What type of error and how to avoid it?
Answer hint: this raises a KeyError. Check membership first or use a safe lookup to provide a default.
Reflection
Classify each problem, reproduce the error when possible to see the traceback, and then choose whether to validate inputs, change logic, or adjust the access strategy.
