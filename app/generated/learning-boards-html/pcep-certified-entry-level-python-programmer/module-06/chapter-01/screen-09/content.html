Bug example
# Original buggy function:
def calculate_average(a, b):
    return a * b / 2  # Intended to calculate average, but multiplies

print(calculate_average(10, 20))  # Expected average is 15, but will be wrong

# Corrected version:
def calculate_average(a, b):
    return (a + b) / 2

print(calculate_average(10, 20))  # Expected output: 15.0
Finding and fixing
Compare actual output to the expected result for representative inputs. If differing, trace intermediate values to see where the logic diverges.
Unit tests and assertions make logical errors easier to catch early, especially for functions with mathematical intent.
Document the mistaken assumption to prevent repeating the same error in future code.
Common Mistake
Relying on a single run; logical errors need multiple test cases including edge cases and known expected outputs.
