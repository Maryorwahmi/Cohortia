Module 6 › Chapter 6.1 › Classifying Errors
Definitions
  • Syntax Error: Code violates language grammar and cannot run until fixed.
  • Runtime Error (Exception): An error that occurs while the program executes and interrupts flow.
  • Logical Error: The program runs but returns an incorrect result due to flawed logic.
Metaphor
Syntax is a broken grammar book, runtime is a car crash while driving, and logical error is a calculator showing the wrong answer.
Key Takeaway

Classify the problem first; that will guide whether you correct syntax, guard operations, or adjust logic and tests.

Examples and contrasts
Syntax: Missing colon in an if statement — the interpreter refuses to run.
Runtime: Dividing by zero during execution raises a ZeroDivisionError shown in a traceback.
Logical: Returning a * b instead of the average a + b over two produces the wrong numeric outcome but no exception.
Common Mistake
Treating logical errors like exceptions — they need tests and reasoning, not just reading a traceback.
