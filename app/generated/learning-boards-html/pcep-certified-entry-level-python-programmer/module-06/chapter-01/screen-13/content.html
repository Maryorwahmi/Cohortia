Module 6 › Chapter 6.1 › Key Concepts
Syntax Error
A parsing failure; Python will not run your script until it’s fixed.
Runtime Exception
Raised while running; read the traceback final line to see the exception type.
Logical Error
Code runs but returns the wrong result; use tests and inspection to discover it.
Summary
Use classification to choose your debugging path: fix grammar for syntax issues, read tracebacks and inspect failing operations for exceptions, and build tests and step through logic for logical errors. Remember the common exception names as quick diagnostics.
