01
Differentiate error types

Recognize syntax, runtime (exception), and logical errors and why each behaves differently. This matters because your debugging approach depends on the category.

Verified Competency Milestone
02
Identify common exceptions

Know NameError, TypeError, ValueError, ZeroDivisionError, IndexError, and KeyError and what triggers each. This helps you predict fixes from the exception name.

Verified Competency Milestone
03
Read tracebacks

Interpret the sequence of calls and the final line that names the exception so you can locate the faulty line in your code quickly.

Verified Competency Milestone
04
Anticipate and handle errors

Explain why designing for unexpected input or failures makes applications more reliable and user-friendly in real scenarios like file I/O or user input parsing.
