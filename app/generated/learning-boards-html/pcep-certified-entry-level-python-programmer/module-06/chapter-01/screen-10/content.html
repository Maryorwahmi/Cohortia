Snippet 1 — Syntax Error

Hello
Snippet 2 — IndexError
# Original:
numbers = [10, 20, 30]
print(numbers[3])

# Corrected options:
# print(numbers[2])  # last valid index
# or check length before accessing

# Expected output:
30
Snippet 3 — Logical Error
# Original:
def calculate_average(a, b):
    return a * b / 2  # wrong

print(calculate_average(10, 20))  # incorrect result

# Corrected:
def calculate_average(a, b):
    return (a + b) / 2

# Expected output:
# 15.0
Snippet 4 — Type/Value handling
# Original:
age = input("Enter your age: ")
years_to_century = 100 - age
print(f"You have {years_to_century} years until a century.")

# Corrected:
age = int(input("Enter your age: "))
years_to_century = 100 - age
print(f"You have {years_to_century} years until a century.")

# Expected output if user enters 30:
# You have 70 years until a century.
Instructor note
Practice predicting the error type before running the code. Correct the snippet and run it to confirm the expected output.
