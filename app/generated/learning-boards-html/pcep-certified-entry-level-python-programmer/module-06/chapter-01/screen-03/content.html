Practice steps
  1. Predict the error type by scanning the snippet for syntax, undefined names, or incorrect operations.
  2. Run the code to see the traceback and note the last line that names the exception.
  3. Correct the code and rerun to confirm the expected output.
  4. Reflect: was it a syntax, runtime, or logical issue? How could you prevent it?
Quick examples to try
Missing colon after if → SyntaxError
Divide by zero during execution → ZeroDivisionError
Wrong formula returning wrong answer → Logical error
