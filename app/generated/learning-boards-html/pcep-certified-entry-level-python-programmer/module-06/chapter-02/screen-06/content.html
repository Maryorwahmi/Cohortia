Two ways to handle multiple errors
Separate except blocks or a single except with a tuple.
try:
    age = int(input("Enter your age: "))
    print(f"Your age is {age}.")
except (ValueError, TypeError):
    print("Invalid input. Please enter a whole number for your age.")

Grouping with a tuple is concise when the same recovery action applies. If actions differ, use multiple except blocks ordered from specific to general.

Checklist
  • Decide if errors need distinct messages.
  • Order except blocks from specific to general.
  • Use tuple grouping for identical recovery logic.
