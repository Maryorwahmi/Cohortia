Module 6 › Chapter 6.2 › Common mistakes
Frequent errors and fixes
Recognize and correct these common patterns.
Too broad except
Catching all exceptions hides the cause. Fix by catching expected types and using except Exception as e only to log unexpected issues.
Large try blocks
Narrow the try block so only failure-prone operations are guarded. This avoids masking unrelated bugs.
Uninitialized resources in finally
Initialize handles to None and check before closing to prevent new exceptions during cleanup.
Quick fixes
  • Log exceptions when catching generic errors.
  • Place only the likely-failing code inside try.
  • Use else for success-only logic; use finally for cleanup.
Common Mistake

Don't use a bare except; you may catch system-exiting exceptions and hide critical errors.
