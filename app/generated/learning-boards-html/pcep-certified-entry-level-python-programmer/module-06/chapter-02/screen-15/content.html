Three quick rules
Keep these short reminders handy as you code.
1. Specific handlers
Catch the exceptions you expect and handle them clearly.
2. Minimal try
Wrap only the risky statements and use else for follow-up actions.
3. Always cleanup
Use finally and initialize resources so cleanup never raises a new error.
Apply these rules to improve resilience, clarity, and debuggability in your code. Which rule will you check first when you review your next function?
