Try/Except — definition and behavior
A small, focused try prevents crashes and routes control to handlers on error.

Key points: The try block runs until an exception occurs. When an exception is raised, the rest of try is skipped. Python looks for the first compatible except and executes it. If no handler is found, the exception propagates.

  • Keep try blocks limited to statements that can fail.
  • Use specific except blocks to handle known errors.
  • Do not assume try resumes after an exception inside it.
Key Takeaway

Use try to guard only the operations that may fail so handlers remain meaningful and bugs aren't hidden.

Concrete example
try:
    num1 = int(input("Enter a numerator: "))
    num2 = int(input("Enter a denominator: "))
    result = num1 / num2
    print(f"The result is: {result}")
except ZeroDivisionError:
    print("Error: Cannot divide by zero!")
except ValueError:
    print("Error: Invalid input. Please enter a number.")
print("Program continues after error handling.")
Misconception
If you wrap many unrelated statements in try, you may hide the real source of an error. Narrow try blocks improve diagnosis.
