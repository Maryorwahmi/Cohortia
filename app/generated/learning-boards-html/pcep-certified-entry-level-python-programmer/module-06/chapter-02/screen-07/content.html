Module 6 › Chapter 6.2 › Else block
Else runs on success
Use else for actions that depend on a successful try, not for guarded code.
try:
    file_name = input("Enter filename: ")
    with open(file_name, 'r') as file:
        content = file.read()
except FileNotFoundError:
    print(f"Error: File '{file_name}' not found.")
except IOError:
    print(f"Error: Could not read file '{file_name}'.")
else:
    print(f"File read successfully. Content length: {len(content)} characters.")
Why use else?
  • Keeps try focused on failure-prone operations.
  • Makes success-only actions explicit and readable.
  • Prevents unintended execution when an exception occurred.
Key Takeaway

Use else for follow-up actions that require the try block to succeed; else will not run if an exception occurred.
