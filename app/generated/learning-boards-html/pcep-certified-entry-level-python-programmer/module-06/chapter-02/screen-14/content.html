What to Remember
Three compact concept cards to keep in mind.
Try & Except
Guard risky operations in try and respond to known errors with specific except blocks.
Else for success
Use else to execute code only when the try block completes without exceptions.
Finally for cleanup
Put cleanup code in finally so it runs regardless of exceptions; initialize resources before try.
Summary takeaway

Structure your handlers for clarity: specific excepts, else for success-only logic, and finally for guaranteed cleanup.
