Module 6 › Chapter 6.2 › Specific vs Generic
Specific handlers
Handle known failures with tailored responses.

Example handlers you will write: ValueError for invalid conversion, ZeroDivisionError for dividing by zero, FileNotFoundError for missing files. Each handler can suggest corrective action to the user.

  • Gives targeted messages.
  • Preserves useful exception details for debugging.
  • Avoids masking unrelated bugs.
Generic handlers
Catching all exceptions can hide root causes unless you log them.

Use except Exception as e when you want a last-resort handler that records the error. Always log or print the exception object so you retain diagnostic information for debugging.

Pattern
Try specific excepts first, then a final except Exception as e for unexpected cases, with logging.
Misconception: A broad except always makes programs more stable. Reality: it can silence bugs and make problems harder to find unless you log the exception details.
