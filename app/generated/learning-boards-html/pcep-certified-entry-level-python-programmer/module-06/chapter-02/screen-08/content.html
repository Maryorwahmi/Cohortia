Finally — guaranteed execution
Place essential cleanup here to avoid resource leaks.
file_handle = None
try:
    file_name = input("Enter a file name to open: ")
    file_handle = open(file_name, 'r')
    content = file_handle.read()
    print("File content read successfully.")
except FileNotFoundError:
    print(f"Error: File '{file_name}' was not found.")
except Exception as e:
    print(f"An unexpected error occurred: {e}")
finally:
    if file_handle:
        file_handle.close()
        print("File handle closed.")
    print("Cleanup complete.")
Practical notes
  • Initialize resources before try so finally can check them safely.
  • Finally runs even if a return or another exception occurs.
  • Prefer context managers for simple cases, but use finally when context managers aren't applicable.
Key Takeaway

Finally ensures essential cleanup executes; initialize variables so checks succeed without raising new errors.
