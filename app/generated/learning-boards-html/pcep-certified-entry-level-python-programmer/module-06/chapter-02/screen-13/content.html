Readable exception handling
Small rules that yield clearer, safer code.
Rules
  • Keep try blocks focused on risky ops.
  • Order excepts from specific to general.
  • Log exception objects when catching broad errors.
Practice
Refactor an existing function that uses a broad except into specific handlers, add logging for unexpected exceptions, and test with inputs that produce each handler.
Final thought

Design for readers: clear exception structure helps future debugging and makes your intentions explicit.
