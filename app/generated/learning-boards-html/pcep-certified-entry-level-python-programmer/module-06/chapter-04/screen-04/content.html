Module 06 › Chapter 6.4 › What is Debugging?
Definition

Debugging is the process of investigating program behavior to find and fix bugs. It focuses on explaining why incorrect state occurred.

Analogy
Like a detective reconstructing events, you retrace inputs and transformations to find the fault.
Key Takeaway

Structure your investigation: reproduce, observe, form a hypothesis, test the hypothesis, and verify the fix.

Practical checklist
  • Reproduce the bug with the smallest input steps.
  • Inspect inputs, intermediate values, and outputs.
  • Use prints or a debugger to observe state at critical points.
  • Form a hypothesis, change a single factor, and retest.
Example scenario
A function returns the wrong total. Reproduce with a simple dataset, print the running total each iteration, and you will see exactly when an unexpected value was added.
