Example configuration
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')

def process_user_input(user_input):
    logging.debug(f"Attempting to process input: '{user_input}'")
    try:
        num = int(user_input)
        if num < 0:
            logging.warning(f"Negative number '{num}' provided. Processing as absolute value.")
            num = abs(num)
        logging.info(f"Successfully converted input to number: {num}")
        return num * 2
    except ValueError:
        logging.error(f"Invalid input '{user_input}'. Cannot convert to integer.")
        return None

# Switch to DEBUG to see more messages
logging.getLogger().setLevel(logging.DEBUG)
This example shows configuration, use of levels, and how to change the root logger to DEBUG for more detail during development.
When to use logging
  • Long-running services and production applications.
  • When you need timestamps and consistent formatting.
  • To record auditable events without modifying code each time.
Pro tip
Use DEBUG level for development and raise the level in production to avoid large log volumes.
