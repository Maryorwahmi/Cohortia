Module 06 › Chapter 6.4 › pdb Example
Script snippet
def multiply(x, y):
    result = x * y
    return result

def add_and_multiply(a, b, c):
    sum_val = a + b
    # Suppose we suspect sum_val here
    product_val = multiply(sum_val, c)  # Breakpoint candidate
    return product_val

x = 5
y = 10
z = 2
final_result = add_and_multiply(x, y, z)
print(f"Final result: {final_result}")
Set a breakpoint at the multiply call. When paused, inspect a, b, sum_val and step into multiply if needed.
Debugger inspection checklist
  • Confirm inputs to the caller are correct.
  • Inspect the sum or intermediate value before the call.
  • Step Into the called function when you suspect its internals.
  • Use stack inspection to understand who called whom.
