Module 06 › Chapter 6.4 › Print Placement
Strategic steps
  1. Print at function entry to confirm inputs.
  2. Print before and after transformations you suspect.
  3. Print boolean checks for branch decisions.
  4. Reduce prints once a hypothesis is verified.
Quick example
# DEBUG prints to check comparison
print(f"DEBUG: Secret={secret_number}, Guess={user_guess}")
print(f"DEBUG: guess < secret? {user_guess < secret_number}")
print(f"DEBUG: guess > secret? {user_guess > secret_number}")
Interpretation tips
  • Scan prints for the first unexpected value to localize the bug.
  • Print only what’s needed; too much output obscures the signal.
  • If a print shows the expected value, move the print earlier to find where it diverges.
Misconception
More prints always mean faster debugging. In fact, indiscriminate prints often slow you down by producing noise; focused prints are faster.
