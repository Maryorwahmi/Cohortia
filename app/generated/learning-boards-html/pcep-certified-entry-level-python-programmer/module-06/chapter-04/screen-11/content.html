Verification checklist
  • Re-run the same guesses that exposed the bug.
  • Add assertions for expected hints and edge cases.
  • Remove debug prints or convert to logging with appropriate level.
Key Takeaway

Verify fixes with repeatable tests. Visual confirmation is useful, but automated checks keep bugs from returning.
