Breakpoints & Stepping

Breakpoints pause execution at a line you choose. Once paused, use stepping to control execution: Step Over, Step Into, and Step Out. These let you observe how values change across lines and calls.

Step Over
Execute current line as a unit
Step Into
Enter called function
Step Out
Finish current function
Inspection & Call Stack
  • Variable inspection reveals local and global values at the pause.
  • The call stack shows the chain of function calls leading to the current line.
  • Use these together to trace how data arrived in the current scope.
Quick scenario
Set a breakpoint before a multiplication. Pause, inspect the operands, and step into the multiplication to confirm each operand holds the expected value.
