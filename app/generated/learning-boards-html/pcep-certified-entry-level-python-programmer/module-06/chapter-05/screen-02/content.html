Apply defensive checks
Add validation and assertions so functions handle bad inputs gracefully and signal programming errors early.
Mnemonic: input guard = door check

02
Use PEP 8 style
Consistently format code: four-space indentation, snake_case names, and blank lines to separate blocks for readability.
Mnemonic: tidy code = tidy mind
VERIFIED COMPETENCY MILESTONE
03
Identify code smells
Spot long functions, duplicated code, magic numbers, and deep nesting, then refactor into clearer parts.
Mnemonic: smell test = quick hint
VERIFIED COMPETENCY MILESTONE
04
Debug with print and debugger
Trace execution with the print function, read tracebacks, and learn basic breakpoints to inspect program state.
Mnemonic: print to reveal, breakpoint to examine
