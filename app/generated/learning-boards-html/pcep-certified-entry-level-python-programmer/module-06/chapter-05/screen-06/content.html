Definition
Code Smells
Recognize structural indicators that suggest refactoring for clarity and maintainability.
Long Functions
Break into smaller functions each with a single responsibility.
Duplicate Code
Extract common logic into a reusable function to avoid repeated maintenance.
Magic Numbers
Replace literals with named constants to explain intent and ease changes.
Excessive Nesting
Use early returns or helper functions to flatten control flow and improve readability.
Refactor pattern
  1. Identify the smell and write a small test or run sample inputs to confirm behavior.
  2. Extract a focused helper function, give it a clear name, and add a docstring.
  3. Replace duplicates with calls to the new helper and run the program to ensure no behavior changed.
Analogy
Think of smells as a cluttered desk. Removing duplicates and naming things is like organizing drawers — small work up front saves time later.
Key Takeaway

Refactor early and in small steps: extract, name, and test. Clear structure reduces debugging effort.
