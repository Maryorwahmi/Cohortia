Process Flow
Print-based debugging steps
  1. Print inputs at function entry with a DEBUG prefix.
  2. Print after important branches to confirm control flow.
  3. Print computed intermediate values before they are used in further calculations.
  4. Remove or convert prints to logging when the issue is resolved.
Example from chapter
def divide_numbers(a, b):
    print(f"DEBUG: Input a={a}, b={b}") # Inspect inputs
    if b == 0:
        print("DEBUG: Division by zero detected!")
        return None
    result = a / b
    print(f"DEBUG: Result = {result}")
    return result
When to use a debugger
If prints do not reveal the cause because state changes are complex or intermittent, use a debugger to set a breakpoint and step line by line. Inspect variables, evaluate expressions, and continue execution when ready.
Common mistakes
  • • Making random edits hoping to fix the bug instead of isolating its cause.
  • • Leaving debug prints in shared code; they clutter outputs and hide real issues.
Key Takeaway

Start with targeted prints to discover the problem, then use a debugger for controlled, line-by-line inspection when needed.
