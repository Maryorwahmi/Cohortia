PEP 8 — Bad vs Good
Bad example
def calculatearea(r):
    PI=3.14159
    return PI*r*r
Issues: poor name, no docstring, spacing, magic number inline.
Good example
def calculate_area(radius):
    """
    Calculates the area of a circle given its radius.

    Args:
        radius (float): The radius of the circle.

    Returns:
        float: The calculated area.
    """
    PI = 3.14159
    return PI * radius * radius
Improvements: readable name, docstring, spacing, constant named, clear layout.
Practical tips
  • • Always use four spaces for indentation; never mix tabs and spaces.
  • • Use snake_case for functions and variables; reserve CapWords for classes.
  • • Prefer short, descriptive names and add docstrings for non-trivial functions.
  • • Replace magic numbers with named constants to clarify intent.
Common misconception
Style is not just cosmetic. Consistent style prevents accidental syntax errors and makes it easier to spot logic mistakes during reviews or debugging sessions.
Key Takeaway

Adopt a small set of style rules immediately: indentation, naming, spacing, and docstrings. They repay effort quickly.
