# After: formatted and documented def calculate(x, y): """Return the product of x and y.""" return x * y
  • Formatters reflow whitespace and line breaks to your chosen style guide.
  • Linters highlight naming, unused imports, and simple logic problems early.
  • Use tools as aids — understand the change they make before accepting it.
Workflow Reminder

Reproduce → Hypothesize → Inspect → Fix → Test → Clean (remove prints, update docs, run formatter).

Practical Example

Suppose a dataset contains a string. Use validation to skip or coerce bad values, run your tests, then run the formatter and linter before committing the fix.

Remove debug prints
After verifying behavior with prints, delete them or replace them with logging at the proper level.
One change at a time
Make a single, targeted change per test so you can identify what fixed the bug.
Automate checks
Run formatters and linters as part of your pre-commit or CI checks to keep style consistent across a team.
