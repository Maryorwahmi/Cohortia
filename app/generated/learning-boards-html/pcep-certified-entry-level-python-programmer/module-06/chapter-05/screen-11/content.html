Module 6 › Chapter 6.5 › IDE Debugging
Process

Set breakpoints, watch expressions, inspect the stack

The IDE presents local variables and a call stack visually so you can quickly see where state diverges from expectation.

# Example: stepping through a simple average function def calculate_average(values): total = 0 for i, v in enumerate(values): total += v # set a breakpoint on the line above to watch 'total' and 'v' return total / len(values)
Watch values
Add 'total' and 'v' as watch expressions to see their values update each step.
Examine call stack
Open the stack panel to see the sequence of calls that led to this frame; jump between frames to inspect different scopes.
Edit & test
Some IDEs allow evaluating expressions or temporarily changing a value at runtime to test a fix, but always make the permanent code change afterward.
Scenario
When a function returns an unexpected average, step through the accumulation loop to inspect inputs and the running total. Often the problem is a single bad element or a missing guard for empty lists.
Checklist

Reproduce the bug, set an informative breakpoint, watch suspect variables, step until you see the bad state, implement a targeted fix, and run tests without breakpoints.
