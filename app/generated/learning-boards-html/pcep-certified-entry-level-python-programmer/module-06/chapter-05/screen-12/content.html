Definition

What to document and how

Docstrings describe a function's purpose, its parameters, return values, and any side effects. Keep them short and factual.

def calculate_area(radius):
  """
  Calculate the area of a circle.

  Args:
    radius (float): Radius of the circle. Must be non-negative.

  Returns:
    float: Area computed as PI * radius * radius.
  """
  PI = 3.14159
  return PI * radius * radius
  • Document expected input types and preconditions.
  • Note any side effects, like file writes or network calls.
  • Keep comments focused on rationale and trade-offs, not restating code.
Practical Tips
Keep docstrings with function
Tools and editors surface docstrings, making them the fastest way to convey usage to others.
Document assumptions
If a function assumes a positive integer, say so. That supports defensive checks and tests.
Update docs during refactor
Docs and code must stay in sync; stale comments are worse than none.
Key Takeaway

Write docstrings that define the contract and minimal inline comments that explain why a non-obvious choice was made.
