Module 6 › Chapter 6.5 › Key Concepts
Defensive Programming
Anticipate errors, validate inputs, and handle unexpected conditions to avoid crashes.
Assertion
A sanity check that raises an error if an internal assumption is false during development.
Traceback
The stack of calls and the exception message Python prints when an unhandled error occurs.
Takeaway
Practice reading tracebacks and using a debugger alongside simple defensive checks to find and fix bugs quickly.
