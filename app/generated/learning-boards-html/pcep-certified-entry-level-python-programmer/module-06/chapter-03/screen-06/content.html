Module 6 › Chapter 3 › Custom Exceptions
Definition

Make domain errors explicit

Custom exceptions allow callers to write targeted handlers and to carry structured context about the error.

Inherit from Exception or a related built-in type for semantics.
Add attributes in __init__ to store extra context like the invalid value.
When to create one
  • You need to handle a specific error differently from built-ins.
  • Errors include extra context that handlers should read programmatically.
  • Clarity for API users: documentation can list the custom exception type.
Analogy

Think of custom exceptions as labeled warning flags. A generic flag tells you something failed; a labeled flag tells you exactly which rule failed and how to recover.
