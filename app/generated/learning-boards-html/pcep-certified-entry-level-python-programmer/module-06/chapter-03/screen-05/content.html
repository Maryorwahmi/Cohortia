Code Walkthrough

Validate types and values early

Early checks make failures precise and place the responsibility on the caller to supply valid inputs.

def validate_age(age_value):
    if not isinstance(age_value, int):
        raise TypeError("Age must be an integer.")
    if not (0 <= age_value <= 120):
        raise ValueError("Age must be between 0 and 120, inclusive.")
    print(f"Age set to: {age_value}")

try:
    validate_age(30)
    validate_age(-5)
except (TypeError, ValueError) as e:
    print(f"Error setting age: {e}")
Why messages matter
A precise message helps the caller and logs explain exactly what to fix without guessing.
Misuse to avoid
Don't use a bare generic Exception; it prevents selective except clauses that handle specific problems.
Checklist
  • Decide whether the error is type-based or value-based.
  • Raise the corresponding built-in with a short message.
  • Document which exceptions your function may raise.
Key Takeaway

Clear, specific built-in exceptions improve error handling and debugging.
