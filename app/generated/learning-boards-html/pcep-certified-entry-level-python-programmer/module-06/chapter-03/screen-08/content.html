Module 6 › Chapter 3 › assert Statement
Definition

assert condition, optional message

Assert raises AssertionError if its condition is false. Use it for internal checks that indicate a bug if violated.

Assertions may be disabled with optimization flags, so do not use for essential validation.
Good for catching developer mistakes during testing and debugging.
Example
def divide(a, b):
    assert b != 0, "Denominator cannot be zero!"
    return a / b

print(divide(10, 2))
# print(divide(10, 0)) would raise AssertionError
After input validation, assertions act as final sanity checks to catch bugs early. Remember that they can be turned off.
Misuse to avoid
Do not use assert to validate user input such as form fields. Those checks must run in production and should use explicit raise and if statements.
Key Takeaway

Assert documents developer expectations; use raise for production validation.
