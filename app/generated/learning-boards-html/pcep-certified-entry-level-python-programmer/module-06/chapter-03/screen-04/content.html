Module 6 › Chapter 3 › What raise Does
Definition

raise: explicit error signaling

Raise stops execution and produces an exception object. Use it for input validation and business-rule enforcement so callers can catch and handle the problem.

Check type and range early and raise the appropriate built-in exception.
Include clear messages to explain why the error occurred.
Avoid raising the generic base Exception; prefer specific exceptions.
Key Takeaway

Raise makes function contracts explicit and produces predictable, catchable errors.

Example
def calculate_positive_square_root(number):
    if not isinstance(number, (int, float)):
        raise TypeError("Input must be a number (int or float).")
    if number < 0:
        raise ValueError("Cannot calculate square root of a negative number.")
    return number ** 0.5

try:
    print(calculate_positive_square_root(25))
    print(calculate_positive_square_root(-9))
except ValueError as e:
    print(f"Caught an error: {e}")
Misconception
raise is not only for fatal errors; it is for predictable, expected problem cases you want callers to handle.
Pro tip
Pick the most specific built-in exception available to make handling precise.
