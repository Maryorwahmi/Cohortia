These steps map from recognizing error needs to applying custom exceptions and assertions in code you ship.

Assessment Milestones

  • Raise ValueError and TypeError with clear messages for invalid inputs.
  • Define a custom exception class that carries extra context.
  • Use assert for internal consistency, not user validation.
01
Signal expected errors
Use raise for invalid user input or business rules. This keeps function contracts explicit and catchable by callers.
VERIFIED COMPETENCY MILESTONE
02
Choose built-in vs custom
Raise ValueError or TypeError for common issues; create custom types for domain-specific handling and clarity.
VERIFIED COMPETENCY MILESTONE
03
Assert for sanity checks
Use assert to document internal invariants during development, not to replace runtime validation.
VERIFIED COMPETENCY MILESTONE
04
Combine raise and assert safely
Validate external inputs with raise and use assert only after validation as a final developer check.
VERIFIED COMPETENCY MILESTONE
