Module 6 › Chapter 6.4 › What is Deployment?
Definition

Software Deployment

The set of activities that move a built application into a runnable production environment where users can access it.

Core activities
  • Packaging the artifact or image
  • Configuring environment and dependencies
  • Installing and starting services
  • Activating endpoints and verifying health
Key Takeaway

Make deployment repeatable, automatable, and observable so releases are predictable and reversible.

Analogy
Think of deployment as preparing, packing, shipping, and placing a new appliance in a hotel room. If packing omits instructions, the appliance may be unusable. If shipping is unreliable, the guest faces downtime. The process must be repeatable for every room.
Example
A payment service packaged as an immutable container guarantees the same runtime in staging and production.
Common mistake
Treating deployment as a single manual step rather than an automated, verifiable pipeline.
