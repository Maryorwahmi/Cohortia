Module 6 › Chapter 6.4 › CI/CD Tooling
Pipeline hierarchy
Commit → CI build → unit tests → integration tests → artifact → staging → acceptance tests → gate → production. Each stage should have measurable success criteria and produce artifacts that are immutable.
Tool examples mentioned in the chapter include Jenkins, GitLab CI/CD, GitHub Actions, and Azure DevOps; they orchestrate these stages but require pipeline design to be effective.
Practical tip
Place fast, deterministic tests earlier to get quick feedback; reserve long-running system tests for staging.
Example
A pipeline builds an image, tags it immutably, pushes it to a registry, deploys to staging for acceptance tests, and stores the artifact for production. Rollbacks redeploy the prior tagged image and restore previous configuration.
Key Takeaway

Choose tools for pipeline reliability and design the stages, not just the tool; reproducibility and rollback hooks are what make automation safe.
