Module 6 › Chapter 6.4 › Design Activity
Activity template
Chosen strategy, justification, high-level deployment steps, and rollback plan. Keep answers practical and tied to minimizing downtime and impact.
Example structure
  1. Chosen strategy: Canary
  2. Justification: Limits blast radius while providing real-user validation
  3. Deployment steps: package, CI tests, staging, canary at 2%, monitor, expand
  4. Rollback: stop canary, reroute traffic to stable, redeploy if necessary
Reflection prompt
Which operational checks would you automate first for the payment service and why?
Scenario example
If you choose blue-green, outline load balancer switch, synthetic transaction tests on the idle environment, and a rollback path that switches back instantly. If you choose rolling, specify batch size and compatibility verification for mixed versions.
Key Takeaway

A good deployment plan aligns strategy, automation, monitoring, and rollback to minimize downtime and user impact.
