Module 6 › Chapter 6.3 › Practice & Risks
Design Tasks
  • Write system scenarios that span login to data persistence and recovery.
  • Plan UAT sessions with representative user personas and success criteria.
  • Define performance test targets and safe test boundaries to protect production.
Verified Competency Milestone
Create three test scenarios for the checkout flow: one system, one UAT, and one load test case, with acceptance criteria.
Common Pitfalls
  • Testing only functional paths and ignoring non-functional requirements.
  • Running performance tests against production infrastructure without safeguards.
  • Skipping UAT or treating it as a bug hunt rather than a user validation step.
Watchout
Rushing UAT often leaves usability gaps that functional tests miss. Involve users early and document their acceptance criteria.
