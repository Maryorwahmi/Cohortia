Definition

Performance Testing

Non-functional testing that measures speed, responsiveness and stability under particular workloads and durations.

Key metrics
  • Response time — time to process a request.
  • Throughput — transactions per unit time.
  • Error rate and resource utilization (CPU, memory, network).
Key Takeaway
Define measurable non-functional acceptance criteria and run tests in an isolated environment to protect production while gathering evidence.
Example scenario
Simulate expected peak traffic for a sale event. Measure average and 95th percentile response times, transaction throughput, and monitor CPU and memory to identify bottlenecks. Record error rates and service degradation points.
Safety note
Run performance tests in a dedicated environment and closely monitor system health to avoid unintended outages or data corruption.
