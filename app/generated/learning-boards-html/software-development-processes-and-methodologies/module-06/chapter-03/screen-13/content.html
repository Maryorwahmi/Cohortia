Module 6 › Chapter 6.3 › Tools & Metrics
Common Tools
  • Apache JMeter — scripting and plugin ecosystem.
  • k6 — code-centric load scripting, developer-friendly.
  • LoadRunner — enterprise-grade load testing with rich analysis.
Tip
Run small validation tests before scaling; ensure scenarios reflect realistic transaction mixes.
Key Metrics to Collect
  • Response time percentiles (p50, p95, p99).
  • Throughput — requests or transactions per second.
  • Error rate, and system metrics (CPU, memory, network, disk I/O).
Key Takeaway
Correlate client-side metrics with server telemetry to find root causes, and document acceptance thresholds for each metric.
