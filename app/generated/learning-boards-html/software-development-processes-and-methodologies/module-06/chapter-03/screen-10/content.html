Module 6 › Chapter 6.3 › Load Testing
What it measures
  • Response times (average, p95, p99).
  • Throughput — transactions per second or minute.
  • Error rates and resource utilization under load.
Example
Simulate the expected concurrent shoppers for a sale, run the test for representative transaction mixes, and measure whether p95 response time stays below the acceptance threshold.
How to plan
  1. Define realistic user profiles and transaction mixes.
  2. Choose target concurrency and test duration.
  3. Collect application and system-level metrics for correlation.
Key Takeaway
Load tests validate capacity planning and respond-time commitments under expected conditions; they are central to predictable deployments.
