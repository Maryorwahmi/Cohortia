Module 6 › Chapter 6.3 › Endurance Testing
Purpose

Detect slow-developing issues like memory leaks, resource depletion, and gradual performance decline by running steady load over long periods.

Practical tip
Monitor trends and set alerting thresholds for growth patterns. Keep long-running logs for post-test analysis.
Example
Run a typical user traffic profile for 24–72 hours in a dedicated environment. Watch for slow increases in memory, file descriptor usage or latency spikes that indicate resource leaks or fragmentation.
Key Takeaway
Endurance tests expose cumulative faults; use them when services run continuously in production for long periods.
