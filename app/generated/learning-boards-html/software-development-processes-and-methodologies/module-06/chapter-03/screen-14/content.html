Module 6 › Chapter 6.3 › Hands-on Activity
System Testing Scenarios
  • Complete checkout: add items, apply discount, select shipping, pay, verify inventory and confirmation email.
  • Recovery case: simulate a database timeout during payment and verify rollback and user messaging.
UAT Scenarios
  • Business user completes checkout using a gift card and confirms totals and receipts match business rules.
  • Customer tests multiple payment options and reports on clarity of steps and error guidance.
Performance Scenarios
  • Load test: simulate expected peak concurrency (e.g., 10,000 users) and measure p95 response time and throughput.
  • Stress test: increase concurrency until error rates rise and observe failure modes and recovery.
Key Takeaway
Write scenarios with clear acceptance criteria and environmental requirements, then run tests and correlate functional and performance results to make release decisions.
