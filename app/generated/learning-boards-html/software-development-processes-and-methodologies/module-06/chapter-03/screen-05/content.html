Module 6 › Chapter 6.3 › Objectives of System Testing
Step-by-step goals
  1. Exercise complete user journeys to check functional compliance.
  2. Validate non-functional requirements like performance and security.
  3. Detect defects appearing only in full integration.
  4. Confirm system behaviour aligns with business objectives.
Key Takeaway

Translate requirements into end-to-end acceptance criteria that include business outcomes and performance targets.

E-commerce checkout example
Compose tests that cover adding items to cart, applying discounts, selecting shipping, completing payment, updating inventory and sending confirmations. Add negative cases: declined payments, inventory mismatch, and partial network failures to verify recovery and user messaging.
Functional Check
Correct totals, taxes, and payment result recorded in database.
Non-functional Check
Response time under expected peak and graceful handling of timeouts.
Common Mistake
Focusing only on happy paths hides issues that occur when services fail or data is inconsistent.
