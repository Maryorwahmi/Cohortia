Defect cost timeline
A conceptual timeline: requirements → design → code → integration → system → release. Cost to fix increases along this line.
Practical implication
Schedule reviews and tests earlier to catch high-impact mistakes cheaply.
Actionable checklist
• Run requirements reviews and write testable acceptance criteria early.
• Automate unit tests to catch low-level defects immediately.
• Plan integration and system tests to catch cross-component issues before release.
• Use UAT to validate against real user needs and prevent costly mismatches.
Key Takeaway

Shift left to reduce cost: invest in early checks and tests to prevent expensive fixes later.
