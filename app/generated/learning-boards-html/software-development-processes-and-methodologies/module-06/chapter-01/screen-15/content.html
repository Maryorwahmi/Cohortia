Key Concepts
Three compact cards to remember.
SQA
A proactive process to prevent defects and align software with requirements.
Verification vs Validation
Verification: built right. Validation: built for the right user needs.
Testing Levels & Types
Unit, integration, system, UAT; include functional, non-functional, regression, and security tests.
Final Takeaway

Quality is everyone’s responsibility: plan tests early, write clear cases, and balance verification with validation.
