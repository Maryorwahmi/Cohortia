Practice & Pitfalls
Apply test design to a login feature and learn common early-stage mistakes to avoid.
Activity
Design 5 test cases for login: success, invalid user, invalid pass, empty fields, UI masking.
Repeatability
Write clear preconditions and expected results so any tester can run the case.
Avoid these
Don't wait until the end or only test happy paths; include edge cases and error handling.
