Definition
Verification
Checks that artifacts and code conform to requirements and design. Typical activities include document reviews, inspections, static analysis, and unit testing.
Concrete example
Verify that a function sorts numbers in ascending order for a given input set, matching its specification.
Common-mistake

Mistaking verification for validation: passing unit tests does not guarantee the feature meets user needs.

Definition
Validation
Confirms the product satisfies user needs and intended use. Typical activities include user acceptance testing and real-world scenario testing.
Concrete example
Validate that a shopping flow supports guest checkout if that was a user requirement discovered during interviews.
Pro Tip

Plan both verification and validation tests from requirements to avoid late surprises.
