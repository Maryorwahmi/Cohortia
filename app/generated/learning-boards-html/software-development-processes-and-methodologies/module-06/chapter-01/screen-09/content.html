Definition
Test Case Structure
A repeatable template that captures everything needed to run and evaluate a test.
Fields to include
  • Test Case ID
  • Description
  • Preconditions
  • Input data
  • Expected Result
  • Post-conditions
Concrete example
Test Case ID: TC_LOGIN_001 Description: Successful login Preconditions: User is on the login page; user account exists Input Data: username: admin, password: password123 Expected Result: Redirect to dashboard; HTTP 200; session token issued Post-conditions: User is logged in and session created
Key Takeaway

Make expected results measurable so pass/fail is unambiguous.
