Comparison
Functional vs Non-Functional
Functional Testing
Validates features against requirements: inputs, outputs, business rules, and edge cases.
Non-Functional Testing
Checks performance, security, usability, reliability, and scalability.
Supporting types
Regression Testing
Re-run tests to confirm new changes don't break existing behavior.
Security Testing
Identify vulnerabilities and protect data and functions from attack.
Why include all types
Combining testing types ensures correctness, performance, and trust for end users.
