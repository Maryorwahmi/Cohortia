Evidence & Practice

You will practice a retrospective, pick metrics, and write SMART actions. The deliverable is a short note and a metric snapshot that shows a measurable target.

Deliverable
Retrospective note + Action list
Two items per section, two SMART actions with owners and target dates.
Metric snapshot
Baseline → Target
Show one product metric and one process metric and the improvement you expect.
Assessment tip
Avoid vague actions
Each action must be specific, assigned, and time‑bound to be verifiable.
Example: "Implement pre‑deployment environment check" is better than "improve deployments".
