Module 06 › Chapter 6.2 › What is Integration Testing?
Definition

Integration tests verify interactions

They ensure modules exchange data correctly and that interfaces are implemented as expected when components run together.

Why: Unit tests can't catch interface mismatches, data format errors, or timing problems that appear only when modules interact.
Trade-off: Integration tests require more setup and run slower, so run them selectively for critical interactions.
Analogy

Individual bricks can be perfect, but only an integrated wall shows cracks in how they fit together.

Checklist
  • Identify critical interfaces to test end-to-end.
  • Decide whether to use real services or test doubles based on risk and cost.
  • Plan setup and teardown to keep tests repeatable.
Key Takeaway

Integration tests find interface errors missed by unit tests and are worth running for critical component interactions.
