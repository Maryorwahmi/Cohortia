Learning Objectives

Four practical competencies to practice and master.

Bloom: Learn → Understand → Apply → Master
01
Unit Testing
Explain the purpose and benefits
You will describe why testing units catches bugs early and acts as living documentation. This skill reduces debugging time and supports refactoring.
VERIFIED COMPETENCY MILESTONE
02
Writing Tests
Write pytest-style unit tests
You will create focused tests, use assertions and pytest.raises for error conditions, and run tests reliably with pytest discovery.
VERIFIED COMPETENCY MILESTONE
03
Anti-patterns
Identify and avoid common mistakes
You will recognise overly broad tests, fragile assertions, and dependencies on external services that make tests slow or flaky.
VERIFIED COMPETENCY MILESTONE
04
Integration Testing
Describe strategies and trade-offs
You will compare Big Bang and incremental approaches and learn when to use stubs, drivers, or real services for integration checks.
VERIFIED COMPETENCY MILESTONE
