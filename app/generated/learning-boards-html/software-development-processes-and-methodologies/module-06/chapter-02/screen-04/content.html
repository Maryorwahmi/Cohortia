Module 06 › Chapter 6.2 › What is a Unit Test?
Definition

Unit test in isolation

Tests a single small piece of code using controlled inputs to produce predictable outcomes.

  • Fast to run and easy to run frequently.
  • Use mocks or stubs to avoid external dependencies.
  • Failures point to a specific unit for faster debugging.
Key Takeaway

Unit tests give fast, precise feedback about a single responsibility so refactors are safer.

Concrete Example

calculate_discount example

# app.py
def calculate_discount(price, discount_percentage):
    if not isinstance(price, (int, float)) or price < 0:
        raise ValueError("Price must be a non-negative number.")
    if not isinstance(discount_percentage, (int, float)) or not (0 <= discount_percentage <= 100):
        raise ValueError("Discount percentage must be between 0 and 100.")

    discount_amount = price * (discount_percentage / 100)
    final_price = price - discount_amount
    return round(final_price, 2)
Good Test
Asserts expected outputs for typical and edge inputs and uses raises for invalid inputs.
Common Mistake
Calling external services from a unit test makes it slow and brittle.
