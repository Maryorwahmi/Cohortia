Practice & Assessment

Hands-on tasks and assessment ideas to make testing a useful habit.

Practice
Write three unit tests
Cover positive cases, edge cases, and exceptions using pytest.raises so you see both correct behavior and defensive handling.
Run
Use pytest discovery
Run tests with the pytest command in your project root and read failures to find the failing unit quickly.
Assess
Scenario-based questions
Explain when to use mocks versus real dependencies, and choose the appropriate integration strategy for a given architecture.
Common Mistake

Writing broad tests that exercise multiple units at once makes failures hard to localize. Prefer focused unit tests and separate integration checks.

Pro Tip

Treat tests as documentation: name tests for behavior, and keep assertions clear so a failing test reads like a sentence about expected behavior.
