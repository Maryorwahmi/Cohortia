Activity: set up your personal Kanban

Follow these practical steps to manage your study tasks and measure improvement.
1. Define stages
Backlog → To Do → In Progress → Review/Practice → Done. Keep it simple.
2. List tasks
Add 5–7 concrete learning tasks like reading chapters, watching videos, or practicing commands.
3. Set WIP limits
For solo study, use WIP 1–2. Only pull more when slots open.
4. Run an experiment
Measure lead time for two completed tasks over two weeks and note changes after adjusting WIP.
Example
Backlog: Read Module 1. To Do: Watch Module 3 on Scrum. In Progress (WIP:2): Practice Git, Complete Module 2 quiz.
Key Takeaway

A small personal Kanban with a conservative WIP limit will increase focus and give measurable improvements in completion time.
