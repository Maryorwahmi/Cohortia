WIP limits explained

Limits set the maximum number of items allowed in a stage. Their purpose is to focus teams on completing work rather than starting too many items.
Example
If 'In Progress' has a WIP limit of 3 and three cards are active, the team must move one forward before pulling another.
Common mistakes
  • Setting limits too high, which fails to create focus.
  • Setting limits too low, starving downstream work.
  • Overriding limits habitually, which loses the learning opportunity.
How to choose a limit
Start small, measure lead time and throughput, then adjust. For individuals, a WIP of 1–2 is common; for teams, consider hands-on capacity by stage.
Try this experiment
Record lead time for two weeks, add a WIP limit, then compare lead time after two more weeks.
Key Takeaway

WIP limits create the scarcity that helps teams finish work faster and discover true bottlenecks.
