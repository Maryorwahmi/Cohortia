How you'll demonstrate mastery

Each milestone asks you to make observable changes, measure outcomes, and reflect on results.
01 — Principles
List the four principles and provide one workplace example showing incremental change.
02 — Practices
Map each Kanban practice to a board action, like setting a WIP or writing an explicit policy.
03 — Board use
Build a 5-item board and identify a bottleneck you can experiment on next week.
04 — WIP limits
Set a personal WIP limit and measure lead time for two items, noting differences before and after.
