Six core practices

Use this checklist to move from idea to action.
1. Visualize workflow
Create columns and cards to make work visible and measurable.
2. Limit WIP
Set maximums per column to reduce multitasking and finish work faster.
3. Manage flow
Watch movement, find slowdowns, and remove bottlenecks.
4. Make policies explicit
Agree definitions of ready and done so transitions are consistent.
5. Implement feedback loops
Use flow-focused standups and reviews to adapt the system.
6. Improve collaboratively
Run experiments, measure lead time and throughput, and iterate.
Concrete example
Add a WIP limit to 'In Progress', hold flow standups for two weeks, and compare lead time before and after.
Common mistake
Visualizing work without WIP limits reveals problems but does not create flow — limits create the discipline to fix queues.
