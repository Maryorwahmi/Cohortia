Module 3 › Chapter 3.1 › Four Core Values
Value comparisons
Individuals & interactions
over processes & tools
Working software
over comprehensive documentation
Customer collaboration
over contract negotiation
Responding to change
over following a plan
Why these tradeoffs matter
  • People and direct collaboration accelerate problem solving and clarifying requirements.
  • Working software produces testable feedback far earlier than extensive documents.
  • Customer collaboration creates a partnership that keeps priorities aligned with real needs.
  • Embracing change makes a product resilient to market shifts and better aligned with user value.
Example

Choosing a small, demoable endpoint and a one‑page API doc lets users try the feature and give feedback. That feedback then shapes the next increment.

Misconception check

Agile does not mean discarding all planning or documentation. It asks for just enough process to support collaboration and delivery.
