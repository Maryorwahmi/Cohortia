Misconception: No planning

Agile requires iterative planning. Plan in short horizons and adapt as you learn, rather than eliminating planning altogether.

Corrective action

Use a sprint plan and a clear Sprint Goal. Replan each cycle based on feedback and new information.

Misconception: No documentation

Documentation should be useful and maintained with the code, not an up‑front monolith that becomes obsolete.

Corrective action

Create concise docs for maintenance and compliance and keep them updated as part of the Definition of Done.

Scenario-based practice
  1. Identify the relevant Agile value for each scenario.
  2. Propose one immediate team action to align with that value.
