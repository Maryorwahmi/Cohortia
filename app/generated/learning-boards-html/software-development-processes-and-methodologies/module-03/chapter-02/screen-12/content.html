Module 4 › Chapter 3.2 › Principle 9
Definition
Continuous attention to technical excellence — clean code, refactoring, design, and tests — keeps the system adaptable.
  • Make refactoring and tests a recurring part of each cycle.
  • Use CI for quick feedback on integration and regressions.
  • Measure technical debt and address hotspots proactively.
Practical Checklist
Automated tests, code reviews, short-lived feature branches, and regular refactoring sessions reduce future cost of change.
Action: schedule a small refactor this sprint that makes a frequent change cheaper and safer.
