Definition

Kanban essentials

Kanban focuses on flow: visualize work, limit WIP, and pull new work only when there is capacity to keep throughput steady.

Visualize
Make workflow visible with a board of states.
Limit WIP
Set explicit per-column limits to prevent overload.
Pull system
Start work only when capacity exists; do not push work into the system.
Concrete example
A 5-person maintenance team uses a Kanban board with WIP limits of three for in-progress. Urgent requests are pulled only when a slot opens, which prevents multitasking and reduces cycle time.
Key Takeaway

Kanban lets teams evolve from the current process and continuously improve flow without prescribing new roles or fixed iterations.

Common mistake
Using a board without WIP limits makes Kanban ineffective; visualization must reveal constraints and enforce limits.
