Module 3 › Chapter 3.4 › Scrum vs Kanban
Scrum

Prescriptive iteration

  • Cadence: fixed-length Sprints.
  • Roles: Product Owner, Scrum Master, Team.
  • Events: Planning, Daily, Review, Retro.
Best when
You need predictable deliverables and stakeholder demos on a regular cadence.
Kanban

Continuous flow

  • Cadence: continuous, no fixed iterations.
  • Roles: existing roles remain.
  • Events: feedback loops as needed; not mandated.
Best when
Work arrives unpredictably and rapid response matters, such as support or operations.
Change handling
Scrum protects sprint scope; Kanban embraces continuous change via pull.
WIP
Scrum limits WIP by sprint scope; Kanban explicitly limits WIP per stage.
Adaptation
Both can be adapted; hybrid approaches are common and effective.
