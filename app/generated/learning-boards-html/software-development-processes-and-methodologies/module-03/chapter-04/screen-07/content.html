Extreme Programming

Technical practices

  • Pair programming and TDD.
  • Continuous integration and frequent releases.
  • Focus on engineering discipline to reduce defects.
Example
A team using TDD writes tests first to speed feedback and reduce regression bugs during rapid feature work.
Lean Software Development

Eliminate waste

  • Amplify learning and deliver fast.
  • Decide as late as possible with better information.
  • Empower teams and build integrity in.
Example
A product team uses small experiments to validate features before building large releases, avoiding wasted effort.
Key Takeaway

XP and Lean are complementary: use XP for engineering rigor and Lean for reducing waste and improving learning across any Agile framework.
