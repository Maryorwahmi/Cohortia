Process

Checklist for framework selection

Project type
Predictable vs experimental work.
Team size & structure
Small co-located teams vs many interdependent teams.
Culture
Degree of autonomy and tolerance for change.
Compliance
Traceability and documentation needs.
Customer involvement
Availability for reviews and rapid feedback.
Process maturity
Start with Kanban to reduce disruption if needed.
Key Takeaway

Map each factor to trade-offs: prefer predictability when reporting matters, prefer flow when interruptions dominate, and always pilot before scaling.
