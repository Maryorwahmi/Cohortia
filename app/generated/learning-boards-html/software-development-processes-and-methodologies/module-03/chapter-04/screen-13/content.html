Assessment questions

Question 1
Which framework suits a team with frequent interruptions that break sprint goals?
Answer: Kanban. Reason: handles unpredictable arrivals with WIP limits and pull system.
Question 2
Which framework helps align many interdependent teams and what is its drawback?
Answer: SAFe; drawback: complexity and potential to add bureaucratic overhead if not implemented with Lean intent.
Reflection prompt

For a framework you recommend, name one metric you will track to prove the change helped: cycle time, deployment frequency, or stakeholder satisfaction.
