Module 1 › Chapter 1.2 › Requirement Example
Requirement (concise)
"The CRM must store a single canonical customer email used for notifications and record send status for audit."
Acceptance test
Given customer with email X, when a notification is sent, the system uses X and logs success in the audit table.
Why this helps

Developers and testers share a clear pass/fail condition, avoiding divergent implementations.

Implementation checklist
  • Agree on canonical field name in design.
  • Write an automated integration test for notification flow.
  • Review with a stakeholder and get quick sign-off.
Check
Create one acceptance test for a current work item and note how it reduces clarifying questions.
