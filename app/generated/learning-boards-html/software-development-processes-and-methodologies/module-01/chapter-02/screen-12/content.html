Module 1 › Chapter 1.2 › ConnectSphere Case Study
Identified problems
  1. No formal requirements → inconsistent expectations and data models.
  2. Minimal testing → frequent production bugs and instability.
  3. Uncontrolled feature requests → scope creep and diverted effort.
Proposed process fixes
Requirements sign-off, automated test suites and code reviews, and a simple change control with prioritization list.
Mappings to concepts
  • Inconsistent models → poor maintainability and undocumented design decisions.
  • Rushed releases → technical debt accumulation.
  • Frequent new features without impact analysis → scope creep and lack of predictability.
