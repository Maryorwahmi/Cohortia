Module 2 › Chapter 1.3 › What is the SDLC?
Definition
A conceptual model describing stages for development, from feasibility through maintenance.
House-building metaphor
Gather needs (rooms, budget), create blueprints, build, inspect, hand over, and maintain. The same flow helps software teams reduce surprises.
Example: To-Do List App
  • Requirements: user stories for tasks and sharing.
  • Design: wireframe input and list layout, DB table for tasks.
  • Implementation: endpoints to add, update, delete tasks.
Key Takeaway

Treat the SDLC as a guiding roadmap that makes responsibilities and risks visible without prescribing a single execution style.

Quick reference: core idea
Six phases provide checkpoints and deliverables so teams can inspect and adapt work as it progresses.
