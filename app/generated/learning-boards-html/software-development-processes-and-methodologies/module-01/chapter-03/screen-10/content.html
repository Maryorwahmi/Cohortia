Module 2 › Chapter 1.3 › Maintenance
Maintenance activities
  • Bug fixing and incident response.
  • Enhancements driven by user feedback.
  • Performance optimization and refactoring.
  • Security patches and backup management.
Concrete maintenance task
Monitor logs for errors and set a weekly triage meeting to prioritize critical fixes and small UX improvements for the to-do app.
Cost and prioritization
Prevent technical debt by scheduling refactors and small improvements.
Use impact-based prioritization for bugs vs enhancements.
Neglect leads to security risks and reduced user trust.
Key Takeaway

Plan for maintenance from day one; it is the phase that sustains value and reduces long-term failure risk.
