Module 2 › Chapter 1.3 › SDLC vs Methodologies
Sequential model (Waterfall)
Phases completed in order. Works when requirements are stable but can delay discovery of integration problems.
Iterative model (Agile/Scrum)
Cycle through small increments that touch many SDLC phases each sprint to get faster feedback and adaptation.
Choosing an approach
If requirements change often, prefer iterative methods to get user feedback quickly.
If requirements are fixed and critical, a more sequential approach may help with documentation and approvals.
Key Takeaway

Use the SDLC as the list of essential activities; select a methodology that fits project risk and need for feedback.
