Module 1 › Chapter 1.1 › Web and Mobile Applications
Characteristics
Web App — runs in browser, wide reach, centralized updates, needs cross-browser compatibility.
Mobile App — installed from app store, optimized for touch and sensors, requires device compatibility testing.
Design implication: choose the platform based on feature needs like offline support, hardware access, and update cadence.
Concrete Example
Gmail demonstrates both models: a web application for broad browser access and a mobile application that adds offline sync and push notifications. Each demands different testing approaches and UX decisions.
Testing Focus: web — browsers, responsive design, network variability.
Testing Focus: mobile — device matrix, sensors, app store certification.
Pro Tip

Align your architecture with platform constraints early to avoid costly refactors when support for sensors or offline capabilities is later required.
