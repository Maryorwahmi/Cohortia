Core Definition

Software development is the multi-step process that turns an idea into a maintained software product. It explicitly includes conception, specification, design, programming, documentation, testing, and bug fixing.

Conception: discover the user's need and goal.
Specification: write measurable requirements and acceptance criteria.
Design: structure components, data models, and interfaces.
Testing & Fixing: verify behavior and resolve defects before and after release.
Key Takeaway

Treat the process as interdependent stages; skipping one stage shifts cost to later work and increases risk.

Concrete Example — To-do App
  1. Conceive: user needs quick task entry and reminders.
  2. Specify: tasks must persist, support due dates, and sync across devices.
  3. Design: simple list UI, data model with task, due date, completed flag.
  4. Program: implement add/edit/delete and persistence.
  5. Document: API endpoints and user flows for maintainers.
  6. Test & Fix: validate edge cases like duplicate tasks and timezone issues.
Common Mistake

Assuming coding alone will produce a usable, maintainable product. Without the other activities, the software will likely need costly rework.
