Module 1 › Chapter 1.1 › Key Concepts
Software Development
The full process from idea to maintenance, encompassing planning, coding, testing, and upkeep.
Software Types
System, application, web, mobile, embedded, AI/ML — each requires different design and testing choices.
Team Roles
Product owners, developers, QA, designers, DevOps, and managers each reduce specific risks.
Summary Takeaway

Use the lifecycle, types, and roles as a checklist when scoping and planning any software project to avoid common pitfalls.
