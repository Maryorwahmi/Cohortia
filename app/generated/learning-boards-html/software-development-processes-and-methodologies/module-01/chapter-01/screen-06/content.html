Module 1 › Chapter 1.1 › System vs Application
Side-by-side
System Software
Manages hardware, provides platform services, e.g., operating systems and utilities. Focus: reliability, compatibility, performance.
Application Software
User-facing programs that perform specific tasks, e.g., editors, browsers, games. Focus: usability, features, integration.
Concrete Example
A laptop's operating system schedules CPU time and manages drivers. A web browser runs on that OS and focuses on rendering, navigation, and extensions. If the OS scheduler is unstable, applications will suffer regardless of their own quality.
Testing: system-level requires hardware or emulator testing.
Deployment: system changes are higher-risk and often require careful release planning.
Misconception

Assuming application testing alone is sufficient. In practice, performance and compatibility at the system level will affect the application.
