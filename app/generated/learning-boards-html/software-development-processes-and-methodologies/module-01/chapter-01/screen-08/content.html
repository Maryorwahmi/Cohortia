Embedded Software

Runs inside hardware devices to control behavior. Development concerns include limited memory, real-time deadlines, hardware integration, and safety considerations.

Example: Car engine control — tight timing, safety-critical, must handle sensor noise.
AI / ML Software

Uses algorithms that learn from data to predict or automate decisions. Key work includes data collection, model training, validation, and monitoring to avoid drift and bias.

Example: A thermostat that learns schedules — requires data pipelines and ongoing evaluation.
Misconception

Thinking AI is a simple add-on. AI features require data work, testing for edge cases, and monitoring after deployment.
