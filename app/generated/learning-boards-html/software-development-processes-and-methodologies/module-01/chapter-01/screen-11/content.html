Testing Types
  • Unit tests: small component correctness.
  • Integration tests: interfaces between components.
  • End-to-end tests: complete user scenarios.
  • Performance tests: behavior under load.
Testing also creates documentation for expected behavior, which supports safe maintenance.
Concrete Example
In a payment system, unit tests check currency rounding, integration tests validate gateway interactions, and end-to-end tests ensure a full checkout flow works under expected conditions. Performance tests evaluate peak shopping traffic.
Safety Note

In critical systems, testing must link back to requirements and be repeatable, so failures can be traced and fixed without ambiguity.
