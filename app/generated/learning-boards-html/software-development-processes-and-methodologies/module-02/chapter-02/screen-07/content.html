Module 02 › Chapter 2.2 › Roles & Responsibilities
Responsibility breakdown
Unit tests — Developers (from Module Design)
Integration tests — Integration team or QA (from Architectural Design)
System tests — QA (from System Specification)
Acceptance tests — Stakeholders/end-users (from Requirements)
Accountability tip: record who authored each test case and the originating design artifact for traceability.
Concrete scenario
For a factory robot, the QA team writes system tests simulating production tasks. Operators run acceptance tests to confirm usability and performance meet business needs.
Common pitfall
If QA is not engaged during design, tests may not reflect design intent and traceability suffers.
