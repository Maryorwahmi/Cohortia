Role Check
Who writes tests?
Developers write unit tests from module design; integration teams plan interface tests from architectural design; QA drafts system and acceptance tests from system and user requirements.
VERIFIED COMPETENCY MILESTONE
Practical Tip
Traceability
Use a simple trace matrix: requirement → design element → test case. This is essential for audits in safety-critical systems.
VERIFIED COMPETENCY MILESTONE
Common Pitfall
Late Testing
Treating the V-Model as Waterfall with tests at the end loses the benefit. Draft test cases from day one.
