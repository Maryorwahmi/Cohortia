Module 02 › Chapter 2.2 › Testing Hierarchy
Unit Testing
Verify individual modules against module-level design. Often developer-written with mocks and focused inputs.
Integration Testing
Verify interfaces and interactions between modules guided by architectural design documents.
System & Acceptance
System tests validate the full product against the system spec; acceptance tests validate user needs derived from requirements and are performed by stakeholders.
Example

Unit tests for gripper algorithm; integration tests for gripper-arm protocol; system tests for full pick-and-place sequence; acceptance tests for operator signoff.

Misconception

Unit tests alone do not show the system meets business goals. Higher-level tests and acceptance criteria are required for validation.
