Module 02 › Chapter 2.2 › Common Mistakes
Frequent pitfalls
  • Late testing: tests are not drafted during design.
  • Vague designs: insufficient detail prevents precise test cases.
  • Broken traceability: requirements not linked to tests.
  • Misplaced expectations: unit tests do not validate user needs.
  • Limited stakeholder input: acceptance criteria lack user perspective.
Quick mitigation: make each design deliverable include its test plan and update the traceability matrix at every review.
