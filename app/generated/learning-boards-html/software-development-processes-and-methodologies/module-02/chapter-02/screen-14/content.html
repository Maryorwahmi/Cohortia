Module 02 › Chapter 2.2 › Key Concepts
V-Model
A sequential model that emphasizes verification and validation by linking each development phase to a test phase.
Verification
Checks whether the product is built correctly according to specifications and design.
Validation
Confirms the system meets user needs and business objectives; executed by stakeholders in acceptance tests.
Takeaway

Keep tests aligned with design artifacts and maintain traceability to ensure each requirement is verifiable and validated.
