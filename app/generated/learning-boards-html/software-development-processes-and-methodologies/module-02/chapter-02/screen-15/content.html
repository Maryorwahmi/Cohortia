Module 02 › Chapter 2.2 › Key Concepts — continued
Unit Testing
Tests individual modules to ensure they match the module design.
Integration Testing
Verifies interfaces and interaction between modules per architectural design.
System Testing
Tests the integrated product against the system specification, including non-functional requirements.
Summary takeaway

Use the V-Model to build traceable, verifiable systems where early test planning and documented links between requirements and tests are essential for quality and compliance.
