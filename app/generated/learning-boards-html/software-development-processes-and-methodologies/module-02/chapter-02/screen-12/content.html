Plan then execute
Planning: draft tests during each design activity. Execution: run tests after implementation when components are available.
Requirements → Acceptance tests drafted
Implementation complete → Run unit tests
Architectural design → Integration tests drafted
System design → System tests drafted, later executed by QA
Ask yourself: for each design deliverable you produce today, have you also produced the test cases that prove it correct?
