Module 3 › Chapter 2.3 › Common Mistakes
Top mistakes
  • Iteration ≠ chaos: Lack of a mini-plan kills predictability.
  • Scope creep: Trying to do too much prevents useful review.
  • Non-user increments: Delivering plumbing instead of value delays learning.
  • Long cycles: Longer iterations reduce the speed of feedback.
Mitigations
  • Timebox iterations and set a strict definition of done.
  • Prioritize the backlog tightly to avoid scope creep.
  • Deliver vertical, end-to-end increments and mock dependencies when needed.
  • List the riskiest assumption per increment and test it early.
Key takeaway
Discipline and prioritization keep iterations and increments productive and reduce wasted effort.
