Module 3 › Chapter 2.3 › Iteration + Increment
Process steps
  1. Select an increment that delivers user value.
  2. Define an iteration goal that includes building and testing that increment.
  3. Deliver, demonstrate, and collect feedback.
  4. Refine existing increments and plan the next increment based on feedback.
Example sequence
Iteration 1: registration (increment). Iteration 2: product browsing (increment). Iteration 3: refine browsing and add cart.
Check your assumptions
When you plan an increment, list the key assumptions you want to validate with users. Keep tests targeted: usability, performance, and priority changes are common. Use those test results to re-prioritize the backlog.
Pro-tip
Make the increment end-to-end so users can complete meaningful tasks.
Pitfall
Avoid delivering only backend plumbing without user-visible value.
