What is an increment?

A small, functional piece of the system that provides tangible value and can be released independently.

Analogy: building a car
Skateboard → bicycle → motorcycle → car. Each stage is usable and increases capability.
Example: banking app increments
Increment 1: login and balance. Increment 2: transfers. Each increment is deployable and testable by users.
Pitfalls
  • Delivering non-usable technical scaffolding instead of user value.
  • Creating increments that are too large to release quickly.
Key takeaway
Plan increments as the smallest deployable unit that users can use and give feedback on.
