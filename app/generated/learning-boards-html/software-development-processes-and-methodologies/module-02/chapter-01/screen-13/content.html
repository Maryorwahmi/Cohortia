Question

A change request arrives after design is complete. Estimate the likely consequences in a Waterfall project and propose an appropriate response.

Expected consequences
  • Revise requirements and update the SRS.
  • Redesign affected modules and update interfaces.
  • Re-implement impacted code and expand testing scope.
Recommended response
Assess cost, document impacts across artifacts, and either schedule a formal change with added budget or postpone to maintenance with clear priorities.
Common mistake
Assuming the change is free. In Waterfall, it almost always affects multiple phases and budgets.
Key Takeaway

Trace changes across requirements, design, code, and tests before approving them in a sequential process.
