Module 2 › Chapter 2.1 › Skills

Apply criteria

Practice structured evaluation by listing project attributes and matching them to Waterfall benefits.

Attribute card: Stability
Requirements fixed by law or policy favor Waterfall because late changes are unlikely.
Attribute card: Technology
Proven technologies reduce the risk of unknowns that Waterfall cannot accommodate easily.
Mnemonic
Stable, Specified, Signed-off = Waterfall friendly.

Practice task

Write a brief paragraph recommending a process for an internal system versus a consumer app. Be explicit about assumptions and risks.

Quick Check

Can you name two project attributes that would immediately rule out Waterfall? If so, you are applying the right filter.
