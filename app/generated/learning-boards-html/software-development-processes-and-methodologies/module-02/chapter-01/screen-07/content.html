Implementation details

Follow the design closely, implement unit tests for each module, and integrate incrementally. Use CI to run automated tests but keep traceability to requirements.

Developer checklist
  • Map code to design documents and requirements.
  • Create unit tests that cover normal and boundary cases.
  • Document any intentional deviations from design with rationale.
Concrete example
Implement a tax calculation function that matches acceptance tests for specific payroll scenarios, including rounding rules and edge cases.
Common mistake
Deviating from design without recording the decision. This creates test gaps and causes late defects.
Warning

Untracked changes increase the chance that testing will discover requirements mismatches late in the project.

Key Takeaway

Maintain traceability between code, design, and requirements to keep rework manageable.
