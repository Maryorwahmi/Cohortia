Module 2 › Chapter 2.1 › Scenario Analysis
Project A: Payroll System
Attributes: stable requirements, mature tech, clear stakeholders, fixed budget. Recommendation: Waterfall suits this context because documentation and traceability are priorities.
Why

Regulatory needs and predictable scope make upfront planning and documentation valuable.

Project B: Startup Mobile App
Attributes: evolving requirements, market-driven features, unproven tech, need for quick MVP. Recommendation: Waterfall is unsuitable; choose an iterative approach that provides early feedback.
Why not

Late feedback would make the project costly and slow to pivot in response to users.
