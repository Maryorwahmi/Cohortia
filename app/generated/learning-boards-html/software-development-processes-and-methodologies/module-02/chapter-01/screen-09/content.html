Module 2 › Chapter 2.1 › Deployment & Maintenance

Deployment

Make the system available to end-users, migrate data, and configure production environments.

Deployment checklist
  • Data migration plan and validation.
  • Configuration and security setup.
  • Rollout and rollback procedures.
Example
Scheduling payroll batch jobs and verifying payment gateway connections during deployment.

Maintenance

Support the system after release with fixes, small enhancements, and environment updates.

Maintenance practices
Prioritize emergency fixes, record updates with traceability, and plan for scheduled upgrades.
Key Takeaway

Maintenance is not an afterthought; it is a planned, often lengthy phase that follows deployment.
