Manage Flow

Measure lead time for end-to-end performance and cycle time for stage-specific delays.

Definitions
Lead time: commitment to delivery. Cycle time: time inside a particular stage.
Example
If Editing cycle time rises, consider adding capacity or clarifying acceptance criteria to reduce rework.
How to act
Use simple charts: cycle time histograms, or a cumulative flow diagram. Spot where work piles up and treat a limit breach as a signal to run an experiment.
Key Takeaway
Metrics make bottlenecks visible. Use them to test hypotheses and measure improvement after experiments.
Check
What metric will show whether your next change made lead time better or worse?
