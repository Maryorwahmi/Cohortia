Limit Work In Progress (WIP)

Set explicit maxima for active work in a column so teams focus on finishing before starting new items.

Concrete example
Writing (WIP 2) and Editing (WIP 1). Writers must wait to move work into Editing until the editor has capacity.
Common mistakes
Setting limits too high or failing to enforce them masks flow problems. Treat violations as signals to investigate.
How to choose a limit
Start low and observe. If cycle time increases or idle time grows elsewhere, adjust. Record cycle time before and after the change to measure impact.
Key Takeaway
WIP limits change behavior and reveal real constraints. Use them as experiments, not rigid quotas.
