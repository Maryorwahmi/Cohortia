Self-organizing Development Team

Team members choose how to accomplish work, collaborate continuously, and ensure items meet the Definition of Done.

Typical activities
  • Pull and execute tasks
  • Pair program and review code
  • Write and run tests, integrate continuously
Role clarity

Scrum Master removes impediments and protects the Sprint, while the Product Owner negotiates scope and priority.

Scenario
Integration blocker: API rate limit discovered. Team discusses workarounds, decides to implement a cache for the Sprint and raises a backlog item to improve the API later.
Anti-pattern

External interruptions during the Sprint that are not negotiated with the Product Owner disrupt focus and reduce predictability.

Key Takeaway

Empowered teams plus quick impediment removal keep momentum toward the Sprint Goal.
