Definition

Sprint Planning & Sprint Goal

Plan the Sprint by selecting items that align to a single, testable Sprint Goal.

Healthy planning signals
  • Clear Sprint Goal
  • Items sized against team velocity
  • Tasks and implementation plan created
Key Takeaway

The Sprint Goal focuses the team and is the true commitment for the Sprint.

Practical example
Sprint Goal: Enable users to securely register and log in.
Selected items
  • Registration API (5 pts)
  • Login UI and integration (5 pts)
  • Acceptance tests and docs (3 pts)
Common anti-pattern

Over-committing to finish every backlog item instead of prioritising the Sprint Goal leads to unfinished work.
