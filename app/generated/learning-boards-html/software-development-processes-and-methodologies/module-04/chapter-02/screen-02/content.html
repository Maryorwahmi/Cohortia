Learning Objectives

Skills to show during Sprint planning and execution.

Bloom: Learn → Understand → Apply → Master
01
Trace the Backlog to Done Journey

Follow a backlog item through refinement, planning, execution, and delivery so you can explain each transition and handoff.

VERIFIED COMPETENCY MILESTONE
02
Explain Product Backlog Refinement

Describe why refinement is continuous, how it prepares items for planning, and how neglecting it causes chaotic planning.

VERIFIED COMPETENCY MILESTONE
03
Describe and Use a Sprint Goal

Write a concise Sprint Goal and use it to guide selection and trade-offs during the Sprint.

VERIFIED COMPETENCY MILESTONE
04
Run Daily Scrum and Feedback Loops

Hold daily inspection and use Review and Retrospective to accept feedback and improve processes.
