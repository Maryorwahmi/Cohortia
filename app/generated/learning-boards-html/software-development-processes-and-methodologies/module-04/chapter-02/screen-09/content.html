Definition of Done (DoD)

A shared checklist that defines minimum quality and release-ready criteria for every completed item.

Typical DoD elements
  • Code reviewed
  • Unit and integration tests passed
  • Integrated into main branch
  • Acceptance criteria met and documented
Make the DoD visible and review it when team capabilities or release policies change.
Key Takeaway

A clear DoD ensures consistent quality and prevents hidden technical debt.

Example DoD for step-count feature
UI renders correctly on supported screen sizes.
API returns correct data with error handling.
Automated tests validate data accuracy.
Documentation and release notes updated.
Misconception

DoD is not solely a developer checklist. It’s a team commitment that supports releasability and transparency.
