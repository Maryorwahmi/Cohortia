Module 4 › Chapter 4.2 › Task Board Flow
Board columns
To Do

Planned tasks not yet started.

In Progress

Work actively being implemented.

Testing

Automated and manual tests run here before release criteria.

Done

Tasks that meet the Definition of Done and are potentially releasable.

Example

A UI card moves to Testing, fails integration tests, and then the team pairs to resolve the issue before moving it to Done.

Diagnosing flow problems
  • Too many cards in Testing indicates a bottleneck
  • Large cards suggest work should be split
  • Frequent rework may show an incomplete DoD
Key Takeaway

Use the board as an early warning system for process issues and act fast on visible blockers.
