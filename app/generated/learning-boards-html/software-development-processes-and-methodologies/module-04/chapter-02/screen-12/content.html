Sprint Retrospective

Reflect on how the team worked and commit to concrete improvements for the next Sprint.

What went well?

Capture practices that helped delivery.

What could improve?

Identify bottlenecks, communication gaps, or tooling issues.

Action items

Create specific, testable improvements and add them to the next Sprint Backlog.

Example improvement

Team decides to add a nightly automated test run to reduce manual testing time; task added to next Sprint Backlog for investigation and implementation.

Key Takeaway

Retrospectives turn experience into specific improvements that make each Sprint better.
