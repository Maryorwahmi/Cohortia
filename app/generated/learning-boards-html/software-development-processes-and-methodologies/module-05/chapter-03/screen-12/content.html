Frequent pitfalls and mitigations

Recognize these traps early and apply the corrective practices we've discussed.

Passive reviews
Fix: run facilitated walkthroughs or inspections with concrete examples.
Assuming sign-off is final
Fix: use a baseline and manage changes with traceability and impact analysis.
Vague language
Fix: convert to measurable acceptance criteria and tests.
Skipping test derivation
Fix: write acceptance tests from requirements to reveal ambiguities.
Action
For each requirement you review, run the SMART checklist and attempt to write one acceptance test. If you cannot, refine the requirement immediately.
