Module 5 › Chapter 5.2 › User Stories
Format
As a [type of user], I want [some goal] so that [some reason/benefit].
Examples
• As a registered customer, I want to save items to a wishlist so that I can purchase them later.
• As an administrator, I want to reset user passwords so that I can help users regain access to their accounts.
Acceptance criteria
Attach short, testable criteria to each story. Example: 'Given a saved item, when I view my wishlist, then the item appears with an add-to-cart button.'
Pitfall
Do not over-engineer stories into long specifications. If the team needs details, link a use case or prototype instead.
