Task 1 — Three user stories
• As a content creator, I want to record a short clip so that I can share it with followers.
• As a viewer, I want to like a clip so that I can show appreciation.
• As a registered user, I want to save drafts so that I can post later.
Task 2 — Expand a use case
Use Case: Record and Save Draft
Actor: Content Creator
Goal: Create and save a short video draft
Preconditions: Camera permission granted; user logged in
Main Flow:
  1. User opens camera in app.
  2. User records clip.
  3. User trims clip and adds caption.
  4. User saves draft.
Postconditions: Draft saved and accessible from drafts list
Alternate Flow (Permission Denied):
  1. System requests permission; if denied, prompt user to enable in settings.
Reflection & next step
Identify one assumption to validate — for example, whether users want to save drafts or prefer immediate publishing — and test it with a one-screen prototype or quick observation session.
