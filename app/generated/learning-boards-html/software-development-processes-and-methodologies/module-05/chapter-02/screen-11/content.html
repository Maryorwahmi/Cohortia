Module 5 › Chapter 5.2 › Stories vs Use Cases
User Stories
• Short, role-focused, invite conversation.
• Easy to prioritize and split for agile delivery.
• Best for capturing value and prompting discussion.
Use Cases
• Structured, step-by-step, includes alternate flows.
• Useful for complex interactions and testing.
• Best used selectively when steps and exceptions matter.
Decision guide
If the requirement is about value and can be delivered in a small increment, write a user story. If the requirement requires explicit ordered steps, error handling, or multiple actors, expand it into a use case to avoid ambiguity.
