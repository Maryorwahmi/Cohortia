Requirements Elicitation
The practice of gathering needs through interviews, observation, workshops, surveys, and prototypes.
User Stories
Concise, role-focused statements that capture value and prompt team conversations.
Use Cases
Step-by-step interactions including alternate flows for clarity in design and testing.
Summary

Mix methods and validate assumptions early. Use stories for conversation and use cases for sequences that need precision.
