Learning Objectives

Understand core elicitation techniques and structured documentation formats that teams use.

01
Describe elicitation techniques
Explain interviews, workshops, observation, surveys, and prototyping and when each is most useful.
VERIFIED COMPETENCY MILESTONE
02
Write user stories
Capture functional requirements using the 'As a... I want... so that...' format to prioritize value and conversation.
VERIFIED COMPETENCY MILESTONE
03
Create use cases
Translate a story into actor, preconditions, main flow, and alternate flows so scenarios are clear for developers and testers.
VERIFIED COMPETENCY MILESTONE
04
Avoid common pitfalls
Recognize leading questions, over-specification, and how to keep documentation maintainable and useful.
