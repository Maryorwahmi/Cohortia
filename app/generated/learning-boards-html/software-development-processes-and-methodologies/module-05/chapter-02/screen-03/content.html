Practice Cycle
  1. Run a 10-minute structured interview to collect concrete examples.
  2. Observe a user performing the task to spot hidden steps or workarounds.
  3. Draft three user stories from different roles or goals.
  4. Expand one story into a use case with preconditions and alternate flows.
Assessment Mapping
Observation -> best for uncovering actual workflows and informal steps.
Interview -> best for clarifying motivations and constraints.
Survey -> best for quantitative trends across many users.
Prototype -> best for validating assumptions quickly.

Quick rubric
A good story invites conversation, is focused on user value, and is small enough to be implemented in a sprint. A useful use case is clear about start and end state and lists reasonable alternate flows.
