Module 5 › Chapter 5.1 › Functional vs Non-Functional
Functional
Concrete behaviour to verify by action
Examples
  • The system shall allow users to borrow a book.
  • The system shall display book details when selected.
Verification
Manual or automated tests that execute the behaviour and confirm expected results.
Non-Functional
Quality attributes to verify by measurement
Examples
  • Search results return within 2 seconds.
  • The system shall be available 99.9% per month.
Verification
Performance tests, security audits, and usability tests with measurable thresholds.
