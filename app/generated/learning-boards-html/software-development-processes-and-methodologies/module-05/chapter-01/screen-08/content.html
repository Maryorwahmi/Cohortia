Module 5 › Chapter 5.1 › Non-Functional Requirements
Non-functional requirements
Quality attributes and constraints
Performance
Example: product pages shall load within 2 seconds under typical load.
Security
Example: encrypt user passwords and use secure transmission for financial data.
Usability
Example: new users should complete checkout within three clicks on first attempt.
Reliability & Availability
Example: the system shall be available 99.9% of the time.
Key Takeaway

Give non-functional requirements measurable targets so architects and testers can confirm them.

Example — Library NFRs
Performance
Search results return within 2 seconds for catalogs under 50,000 items.
Security
User passwords must be stored using one-way hashing; communications must be encrypted.
Usability
First-time users must find and borrow a book within three minutes without external help.
