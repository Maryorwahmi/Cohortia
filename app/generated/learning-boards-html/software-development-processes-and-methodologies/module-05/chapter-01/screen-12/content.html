Module 5 › Chapter 5.1 › Hands-on Activity: Online Library
Activity: define requirements
Write three functional and three non-functional requirements with acceptance criteria
Functional requirements (examples)
1. The system shall allow users to search books by title, author, or ISBN.
   Acceptance: Given a valid title or ISBN, search returns matching results.
2. The system shall allow users to check out books to their account.
   Acceptance: After checkout, the book appears in the user's loans and availability decreases.
3. The system shall display book availability and estimated return date.
   Acceptance: Selecting a book shows current availability and the next due date if borrowed.
Non-functional requirements (examples)
1. Performance: Search results shall return within 2 seconds under typical load.
   Acceptance: Performance test shows median response ≤ 2s for representative queries.
2. Security: User passwords shall be stored using one-way hashing and all transmission encrypted.
   Acceptance: Security review confirms hashed storage and encrypted transport.
3. Usability: First-time users shall complete a checkout within 3 minutes without assistance.
   Acceptance: Usability test with representative learners confirms the metric.
Tip
Pair each requirement with an acceptance criterion to make testing and validation straightforward.
