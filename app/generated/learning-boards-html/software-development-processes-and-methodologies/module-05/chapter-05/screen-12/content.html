Module 5 › Chapter 5.5 › Change Control Process
Workflow
CR Submission → Impact Analysis → Decision → Implementation → Verification
Each step requires documentation and an assigned owner. Decisions are made by a Change Control Board that evaluates costs, benefits, and risks.
CR Submission
Describe the change, rationale, and acceptance criteria.
Impact Analysis
Estimate effects on scope, schedule, budget, quality, and architecture.
Decision
CCB approves, rejects, or defers with conditions.
Implementation & Verification
Update baselines, implement with version control, and verify through testing.
Example: Wishlist CR
Expect details: purpose, acceptance criteria, data model changes, UI impact, and testing scope. Impact analysis estimates effort and performance implications before CCB decision.
