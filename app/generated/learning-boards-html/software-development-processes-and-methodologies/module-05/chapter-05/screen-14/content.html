Module 5 › Chapter 5.5 › Scenario: E-commerce
Part 1 — Risks (examples)
  • Search API changes — Mitigation: automated API tests, owner: integration lead.
  • Key backend developer leaves — Mitigation: cross-training, owner: project manager.
  • Indexing performance underestimated — Mitigation: early performance spikes and buffers.
Action: write each risk, estimate probability and impact, and decide response with a short plan.
Part 2 — Wishlist CR flow
Expected CR info: purpose, acceptance criteria, data model, UI changes. Impact analysis: effort, testing, performance, integration. Decision: CCB weighs benefits vs costs.
If approved: create CR branch, implement, run CI, verify in staging, update baselines, and merge on successful verification.
