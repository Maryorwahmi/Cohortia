Core Concept

Project Scope

Scope defines what will be delivered and what will not. A clear scope enables reliable estimates and reduces scope creep.

Included
  • Feature list and acceptance criteria
  • Deliverables and data requirements
  • Testing and deployment tasks
Excluded
  • Out of scope platforms or integrations
  • Future feature requests
  • Non-functional expansions without approval
Common Mistake

Leaving exclusions implicit. If exclusions are not documented, stakeholders assume inclusion.

Definition & Example
Definition: The documented list of deliverables, features, and work the project will produce. Example: For a catalog site, scope might include product pages and an admin editor but exclude payment processing.
Practical Checklist
  • Write a one-paragraph scope statement.
  • List included deliverables and acceptance criteria.
  • List explicit exclusions to avoid assumptions.
  • Define a change control process for late requests.
Key Takeaway

A clear scope is the single best prevention against scope creep and misaligned expectations.
