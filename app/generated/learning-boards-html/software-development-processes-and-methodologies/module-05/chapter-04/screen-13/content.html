Module 5 › Chapter 5.4 › Key Concepts
Project Scope
Defines included and excluded deliverables to avoid assumptions and scope creep.
Work Breakdown Structure
Hierarchical deliverables tree that ends in estimable work packages.
Task Dependencies
Relationships that determine sequencing and expose critical paths or parallel work.
Gantt Chart
A timeline view showing task durations and dependencies for communication and conflict detection.
Resource Allocation
Assign people, tools, budget, and time, and verify real availability to avoid bottlenecks.
Project Triangle
Scope, Time and Cost are linked; changing one affects the others and requires trade-offs.
Final Reflection
Use the WBS to estimate, schedule with dependencies, allocate resources explicitly, and present trade-offs using the Project Triangle.
