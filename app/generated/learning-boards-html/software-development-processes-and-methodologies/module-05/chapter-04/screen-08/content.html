Scheduling & Dependencies

Estimate durations for work packages, then order them according to dependencies to create a realistic timeline.

Common Dependency Types
  • Finish-to-Start (FS): A must finish before B starts.
  • Start-to-Start (SS): A and B start together.
  • Finish-to-Finish (FF): A and B must finish together.
  • Start-to-Finish (SF): Rare — B cannot finish until A starts.
Practical Tip
Estimate at the work-package level and validate dependency assumptions with responsible owners.
Example: Simple Sequence
1. Implement API (5d) → 2. Implement Frontend (4d) → 3. Integration Testing (3d). Here Integration Testing has a finish-to-start dependency on both Implementation tasks.
Misconception
Assuming all tasks must be sequential. Many tasks can run concurrently when dependencies and resources allow.
Key Takeaway

Identify blocking relationships early and estimate at the work-package level to produce a realistic schedule.
