Core Concept

Project Resources

Identify and allocate people, tools, budget and time so work packages can be completed on schedule.

Human Resources
Roles, skills, and availability. Note percent allocation to avoid overcommitment.
Tools & Equipment
Licenses, servers, test devices and other infrastructure needed for tasks.
Budget
Financial resources to cover salaries, licenses and hardware. A lever for increasing capacity.
Time
Captured in the schedule; time allocation determines delivery dates and conflicts.
Allocation Exercise
Map each Level 2 WBS item to required roles and tools, then check availability. Flag any 100%+ allocations and resolve them.
Common Mistake
Listing a role as 'assigned' without recording percent availability. This creates hidden bottlenecks.
Key Takeaway

Record required skills and real availability for each work package to avoid resource conflicts.
