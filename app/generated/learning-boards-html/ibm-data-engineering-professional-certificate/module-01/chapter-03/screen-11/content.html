Fact and Dimension Tables
Separate measures from descriptive attributes for efficient analysis
Fact table (Sales)
Contains measures and foreign keys. Typically very large and append-only.
Columns: sale_id, sale_date, product_id, customer_id, sale_amount
Dimension table (Product)
Stores descriptive attributes used to group and filter facts.
Columns: product_id, product_name, category, brand
Misconception
Putting descriptive attributes in fact tables increases storage and slows queries. Keep facts lean and dimensions descriptive.
Key Takeaway

Facts: measures and keys. Dimensions: attributes for slicing. Design accordingly for query performance.
