From OLTP to Warehouse: ETL/ELT Patterns
Common pipelines for preparing analytical data
ETL (Extract, Transform, Load)
Extract from sources, apply transformations in a processing layer, then load curated data into the warehouse.

2. Transform

ELT (Extract, Load, Transform)
Extract and load raw data quickly, then perform transformations inside the warehouse using its compute resources.
1. Extract
2. Load
3. Transform
Practical tip
If your warehouse supports scalable SQL compute, ELT can simplify pipelines and speed ingestion. If transforms are heavy and best handled externally, use ETL.
Key Takeaway

ETL centralizes transformation before load; ELT leverages warehouse compute. Align choice with your operational constraints.
