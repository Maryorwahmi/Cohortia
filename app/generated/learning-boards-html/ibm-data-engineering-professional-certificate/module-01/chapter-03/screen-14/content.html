Assessments and Common Questions
Sample questions and checks to validate your design choices
Sample question 1
A system records thousands of concurrent sales and also needs annual trend reports. Which systems serve each need?
Answer: OLTP for daily transactions; Data Warehouse for historical analysis.
Sample question 2
Which table is the fact in a star schema containing sales, product, customer, and date?
Answer: Sales is the fact table containing measures and foreign keys to dimensions.
Self-check
Write CREATE and INSERT statements for a small schema and run a join to confirm relationships. Verify primary vs foreign key direction and constraint behavior.
Key Takeaway

Use hands-on SQL and scenario questions to confirm choices and avoid common misconceptions about keys and schema patterns.
