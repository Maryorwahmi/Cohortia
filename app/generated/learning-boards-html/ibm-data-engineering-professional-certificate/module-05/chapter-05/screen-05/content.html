Core definition

Data Lake

A scalable repository that stores raw, native-format data and applies schemas when the data is read for analysis or ML.

When to use
Exploratory analytics, feature engineering, storing semi-structured logs, images, and audio for future use.
Common pitfall
Lack of metadata and access controls turns a lake into a data swamp where discovery and trust fail.
Analogy
A reservoir holding many water sources; useful when you need any type of water for future processes.
Example: ML dataset assembly
A scientist pulls raw JSON logs and image files from object storage to create training datasets and iterate on features without waiting for pre-defined schemas.
# Pseudocode: reading raw logs for feature engineering
raw = read_object_storage('clickstream/*.json')
filtered = filter_by_time(raw, last_30_days)
features = build_features(filtered)
save(features, 'training_features.parquet')
Key Takeaway

A Data Lake gives flexibility and scale for diverse data, but governance and catalogs are required to keep it usable.
