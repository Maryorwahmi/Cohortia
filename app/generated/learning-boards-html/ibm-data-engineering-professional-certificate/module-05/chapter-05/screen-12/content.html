Module 6 › Chapter 5.5 › Hands-on Activity
Requirements mapping
Real-time fraud detection
Use a streaming log and processor for low-latency scoring and alerts.
Churn prediction
Store historical behavior and semi-structured sources in a lake for feature engineering.
Ad-hoc analytics
Provide curated tables in a warehouse for analysts and dashboards.
IBM Cloud mapping
Cloud Object Storage for raw data, Db2 Warehouse for curated analytics, DataStage or Python/ETL jobs for transformation, Airflow for orchestration, and Watson Studio for model development.
Integration flow
OLTP → stream log / object storage → stream processor + batch ETL → curated warehouse tables → analytics and models.
Key Takeaway

Sketch a flow that assigns each requirement to a component and documents governance and ownership at each handoff.
