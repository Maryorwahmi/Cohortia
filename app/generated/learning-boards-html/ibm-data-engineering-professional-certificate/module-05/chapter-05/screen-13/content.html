Module 6 › Chapter 5.5 › Key Concepts
Data Lake
Stores raw, multi-format data and applies schema when reading for flexible analytics and ML.
Data Warehouse
Schema-on-write store optimized for structured historical data, reporting, and BI.
Data Lakehouse
Combines open-format lake storage with transactional and governance features for unified workloads.
Schema-on-Read
Apply schema at query time for flexible analysis of raw data.
Schema-on-Write
Enforce schema at load time so downstream queries run against consistent tables.
Lambda & Kappa
Lambda uses batch + speed layers; Kappa uses a single stream processing path with replay for historical data.
Summary

Choose components by matching data types, query patterns, and team needs; combine patterns with governance to get the best of both worlds.
