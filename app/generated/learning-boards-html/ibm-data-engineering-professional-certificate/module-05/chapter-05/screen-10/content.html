Module 6 › Chapter 5.5 › Architecture
Hybrid design strategy
Identify which workloads need guaranteed consistency and which need raw access for experimentation. Use object storage-backed lakes for raw retention, warehouses for governed analytics, and lakehouses to reduce duplication when both are needed.
Design tip
Clearly define where curated tables are created and who owns the ETL or transformation logic that produces them.
Governance
Implement metadata catalogs and access controls across lake, lakehouse, and warehouse boundaries to avoid discovery gaps.
Example flow
OLTP systems push to object storage for long-term retention; stream processors publish near-real-time views for dashboards; curated tables are built into the warehouse for month-end reporting. Document data ownership at each handoff.
Key Takeaway

A pragmatic architecture mixes patterns and documents where schema enforcement, catalogs, and governance are applied to keep data discoverable and trustworthy.
