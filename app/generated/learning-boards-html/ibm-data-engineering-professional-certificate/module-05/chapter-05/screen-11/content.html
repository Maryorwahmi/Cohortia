Module 6 › Chapter 5.5 › Role & Practice
Core responsibilities
  • Design and build ETL/ELT pipelines using Python, SQL, and ETL tools.
  • Manage cloud storage for lakes, provision warehouses, and orchestrate compute.
  • Implement quality checks, catalogs, and access controls for governance.
  • Collaborate with data scientists and analysts to meet their data needs.
Example tools
On IBM Cloud this could include Cloud Object Storage, Db2 Warehouse, DataStage, and Watson Studio for different parts of the platform.
Practical snippet
# Simple pseudocode: orchestrate a pipeline
# Extract raw events
raw = read_object_storage('events/*.json')
# Validate and transform for curated table
curated = validate_and_transform(raw)
# Write curated data to warehouse
write_to_db(curated, 'curated.sales')
Key Takeaway

Data engineers design pipelines and governance so analysts and scientists can rely on the right data at the right time.
