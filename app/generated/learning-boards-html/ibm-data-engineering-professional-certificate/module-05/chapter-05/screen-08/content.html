Lambda layers
Batch Layer
Stores immutable master dataset and computes batch views like daily aggregates or retrained models.
Serving Layer
Indexes and serves pre-computed batch views for low-latency queries by users and dashboards.
Speed Layer
Processes streaming data to produce incremental updates so recent events are reflected quickly.
Example
Daily model retraining in batch; real-time scoring in speed layer to flag fraud within seconds.
Operational notes
  • Maintaining separate batch and speed code can double complexity and testing effort.
  • Batch gives accuracy and completeness; speed gives freshness for recent events.
  • Use Lambda when both correctness of large-scale recomputation and low-latency updates are required.
Key Takeaway

Lambda separates batch and stream processing to achieve both accurate historical results and fresh, low-latency updates at the cost of duplicated pipelines.
