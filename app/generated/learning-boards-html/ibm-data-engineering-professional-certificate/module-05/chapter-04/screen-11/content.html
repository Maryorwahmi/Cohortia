Module 5 › Chapter 5.4 › Security & Access
Access Controls
  • Use IAM policies to grant least privilege.
  • Store credentials in a secrets manager or environment variables.
  • Validate SSL certificates and use encrypted ports.
Operational Controls
  • Enable audit logging for queries and changes.
  • Use provider-managed backups and consider customer-managed keys if needed.
  • Review role assignments and rotate credentials periodically.
Misconception
Managed services eliminate the need for your own access controls. You still must define and enforce them.
Example
Reference secrets from a runtime role instead of embedding credentials in scripts.
Key takeaway
Combine provider-managed infrastructure security with your own policies, secrets management, and audits.
