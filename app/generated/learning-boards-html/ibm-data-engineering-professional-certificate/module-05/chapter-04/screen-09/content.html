Module 5 › Chapter 5.4 › Connecting to Db2 Warehouse
DSN components
  • Hostname and port — where the service listens.
  • Database name — the target logical database like BLUDB.
  • Username and password — credentials for authentication.
  • SSL certificate — ensures encrypted transport.
Security note
Prefer environment-stored secrets or a secrets manager rather than embedding passwords in code.
Python example
Below is a safe demonstration of constructing a DSN string and opening a connection using the ibm_db driver.
import ibm_db

# Replace these values with your connection details
dsn_hostname = "your_hostname.db2oncloud.ibm.com"
dsn_port = "50001"
dsn_database = "BLUDB"
dsn_uid = "your_username"
dsn_pwd = "your_password"

dsn = (
    "DATABASE={0};HOSTNAME={1};PORT={2};PROTOCOL=TCPIP;UID={3};PWD={4};"
    "SECURITY=SSL;SSLServerCertificate=DigiCertGlobalRootCA.crt".format(
        dsn_database, dsn_hostname, dsn_port, dsn_uid, dsn_pwd
    )
)

try:
    conn = ibm_db.connect(dsn, "", "")
    print("Connection to IBM Db2 Warehouse on Cloud successful!")
    stmt = ibm_db.exec_immediate(conn, "SELECT CURRENT DATE FROM SYSIBM.SYSDUMMY1")
    result = ibm_db.fetch_tuple(stmt)
    print(f"Current Date from Db2 Warehouse: {result[0]}")
    ibm_db.close(conn)
except Exception as e:
    print(f"Error connecting to Db2 Warehouse: {e}")
