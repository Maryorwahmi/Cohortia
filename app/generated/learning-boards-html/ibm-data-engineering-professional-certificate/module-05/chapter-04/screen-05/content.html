Module 5 › Chapter 5.4 › Scalability and Elasticity
Definition

Scalability: ability to increase or decrease compute and storage. Elasticity: operational responsiveness to workload changes.

Example
Scale compute for nightly aggregations, then scale down after jobs complete to save cost.
Key takeaway
Measure peaks, automate scaling, and isolate storage from compute.
Practical checklist
  • Identify peak windows and typical concurrency.
  • Test scaling actions to verify query distribution and network limits.
  • Use monitoring to trigger scale-up and scale-down events.
  • Separate storage (object store) from compute to avoid paying for idle compute.
Misconception
More nodes always equals faster queries. Query distribution and I/O patterns matter.
Pro tip
Start with load testing and adjust resource classes instead of only scaling node count.
