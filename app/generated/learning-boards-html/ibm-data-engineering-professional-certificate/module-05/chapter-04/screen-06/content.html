Module 5 › Chapter 5.4 › Massively Parallel Processing
How MPP works
Queries are split into tasks, executed on multiple nodes, and results merged. Each node works on a data partition.
Example
Compute SUM(Sales) by summing partitions in parallel and then adding partial sums.
Pitfall
Data skew causes some nodes to do much more work, slowing the whole job.
Practical checklist
  • Partition data on keys used by frequent queries.
  • Monitor node-level metrics to detect skew.
  • Rewrite heavy joins to reduce cross-node shuffles when possible.
Key Takeaway
MPP delivers speed when data is well-distributed and queries minimize expensive shuffles.
