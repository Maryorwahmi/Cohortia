Module 5 › Chapter 5.4 › ETL Design
Recommended ETL Pattern
  1. Stage raw data in object storage.
  2. Run batch transformations and create columnar files.
  3. Bulk-load or append into partitioned tables.
  4. Compact data periodically to optimize layout.
Design considerations
  • Pick partition keys that match common filters.
  • Avoid frequent single-row updates.
  • Balance freshness with batch window length.
Key takeaway
Bulk, partitioned, and compacted data yields predictable performance on columnar, MPP systems.
