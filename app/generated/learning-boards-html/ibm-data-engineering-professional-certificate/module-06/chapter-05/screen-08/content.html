Security Basics for a Data Lake
RBAC, encryption, logging, and network controls protect your data without stopping pipelines.
Role-Based Access Control
Grant minimal permissions using IAM roles or service IDs. Scope roles to specific prefixes like curated/ or consumption/ rather than entire buckets where possible.
Encryption & Transport
Enable server-side encryption for data at rest and always use TLS for data in transit. Consider customer-managed keys for stricter control.
Key Takeaway

Combine RBAC, encryption, and logging to protect data; test policies with least-privilege accounts before wider rollout.

Audit & Network Controls
Enable access logging and activity tracker to provide an audit trail. Where supported, restrict access to VPCs or IP ranges to limit exposure.
Common mistake
Using overly broad policies like public-read or wildcard resource patterns can expose sensitive data. Review policies regularly.
Scenario
Grant a transformation service write access to curated/ but only read access to raw/; give analysts read access to consumption/.
