Hierarchy

Supporting components

HBase
NoSQL column-family store for low-latency random read/write over large datasets.
ZooKeeper
Coordination service for configuration and distributed synchronization used by many cluster components.
Spark
Fast, general-purpose cluster computing engine often used instead of MapReduce for iterative and interactive workloads.
Composition patterns
  • Use HDFS as the data lake, Spark or MapReduce for processing, and HBase for low-latency tables.
  • Use ZooKeeper to keep distributed configuration and leader election reliable across the cluster.
  • Choose components based on latency and processing model: batch vs interactive vs transactional.
Key Takeaway

Hadoop’s ecosystem offers specialized tools that complement core storage and scheduling to meet diverse processing and latency needs.
