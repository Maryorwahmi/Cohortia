Process Flow

Block splitting & replication

1. File arrives at HDFS client and is split into fixed-size blocks.
2. Each block is written and replicated to multiple Datanodes according to the replication factor.
3. Namenode records block locations and monitors replication health, triggering re-replication if replicas go missing.
Example calculation
300 MB file, 128 MB block: 300 / 128 = 2.34 → 3 blocks. With replication factor 3, total storage = 300 MB * 3 = 900 MB.
Visualized cards

Replication

Key Takeaway

Always account for replication when planning storage and remember block rounding increases how many blocks a file occupies.
