Module 6 › Chapter 6.4 › What is a Data Lake?
Definition

A centralized repository that stores raw structured and unstructured data at any scale and applies schemas on read for flexible analysis.

Analogy
Think of a lake as a raw materials warehouse: everything arrives unprocessed so specialists can extract what they need for different products.
Example
Store clickstream JSON and join with curated profiles at query time to train a recommendation model.
Common Mistake
Treating a lake as a dump without metadata or governance creates a data swamp.
Key properties
  • Stores native files: logs, JSON, CSV, images, and more.
  • Scales on cheap object storage for cost-effective retention.
  • Supports diverse workloads: BI, interactive queries, ML, and streaming analytics.
  • Relies on metadata and governance to remain discoverable and trustworthy.
Key Takeaway
A Data Lake enables agility by storing raw data and applying structure later, but needs governance and catalogs to be useful.
