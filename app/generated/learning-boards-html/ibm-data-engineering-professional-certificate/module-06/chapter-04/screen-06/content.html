Module 6 › Chapter 6.4 › Architecture Layers
Layer cards
Data Ingestion
Batch and streaming sources; tools include Kafka, Event Hubs, or scheduled exports.
Data Storage
Object storage with zones: raw, curated, refined; partition by date or source for efficiency.
Data Processing
Distributed frameworks like Spark for cleaning, enrichment, and writing columnar formats.
Analytics & Consumption
Interactive SQL engines, BI dashboards, and ML notebooks that consume curated outputs.
Example flow
1) Stream game telemetry into the raw zone. 2) Run Spark jobs to clean and enrich events, join with user profiles, and write Parquet to the curated zone. 3) Partition curated data by date and game ID to support efficient queries. 4) Expose curated datasets to BI and ML.
Why zones matter
Zones separate landing data from production-ready datasets, making retention, access, and processing predictable and auditable.
