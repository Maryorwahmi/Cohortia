Module 6 › Chapter 6.4 › Design Activity
Source mapping
Game Telemetry: Streaming → Raw Zone. High velocity, near real-time needs.
User Profiles: Batch daily → Raw Zone. Structured and periodic.
Support Tickets: Hourly batch CSV → Raw Zone, flagged for NLP enrichment.
Marketing Data: Weekly JSON batch → Raw Zone for exploratory ETL.
Processing plan for telemetry
  1. Read raw events, apply schema-on-read, and filter corrupt records.
  2. Normalize timestamps and cast types; join with user profiles from curated zone.
  3. Write Parquet partitioned by event_date and game_id into Curated Zone.
  4. Register dataset in the catalog with owner, schema, cadence, and retention.
Why this matters
This plan balances immediacy for analytics with the reproducibility and performance needed by BI and ML teams.
