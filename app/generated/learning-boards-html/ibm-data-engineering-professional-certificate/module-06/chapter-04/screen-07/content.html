Batch Ingestion
Periodic exports or file uploads. Simple to operate and cost-effective for structured data with predictable cadence.
  • Use for relational exports, hourly CSVs, or weekly JSON dumps.
  • Lower operational cost and simpler retries.
  • Write to Raw Zone with metadata about source and timestamp.
Streaming Ingestion
Low-latency pipelines for telemetry, clickstreams, and sensor data. Supports near real-time analytics but requires more operational setup.
  • Use for game telemetry where immediate detection or personalization matters.
  • Tools include Kafka, Event Hubs, and cloud event streams.
  • Persist streams to the Raw Zone and include event timestamps and offsets for replay.
Decision checklist
Record cadence, format, latency needs, and retention. Prefer the simplest reliable method that meets your analytic requirement.
