Module 6 › Chapter 6.4 › Zones & Partitioning
Raw Zone
Immutable landing area with native files and source metadata. Keep original files for replay and lineage.
Curated Zone
Cleaned and enriched datasets in columnar formats with explicit schemas and partitioning for analytics.
Refined Zone
Aggregates, feature tables, and production datasets intended for consumption across teams.
Partitioning guidance
  • Partition by date and a domain key used frequently in filters, like game_id.
  • Avoid excessive small partitions; balance between file size and parallelism.
  • Document partition scheme in metadata so analysts can write efficient queries.
