Module 6 › Chapter 6.4 › Spark Pipeline
Pattern steps
  1. Read raw files from object storage and apply or infer a schema.
  2. Filter and clean invalid records; normalize timestamps and types.
  3. Enrich by joining with curated profile tables.
  4. Write partitioned Parquet to the Curated Zone for analytics.
Note
Schema-on-read aids exploration; produce schema-enforced outputs for production use.
Example Spark snippet
# Read raw JSON from object storage
raw = spark.read.json("s3://game-lake/raw/telemetry/*")

# Clean and cast fields
clean = raw.filter("event_type IS NOT NULL").withColumn("event_ts", raw.ts.cast("timestamp"))

# Enrich by joining user profile
profiles = spark.read.parquet("s3://game-lake/curated/user_profiles")
enriched = clean.join(profiles, on="user_id", how="left")

# Write partitioned, columnar output to curated zone
enriched.write.mode("overwrite").partitionBy("event_date").parquet("s3://game-lake/curated/telemetry/")
This snippet illustrates reading raw files, enforcing types during processing, enriching, and writing Parquet partitioned by date for efficient analytics.
