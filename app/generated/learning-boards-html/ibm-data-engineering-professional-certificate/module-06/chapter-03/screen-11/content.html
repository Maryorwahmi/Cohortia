Module 6 › Chapter 6.3 › Choosing the right type
Scenario A — User sessions
Recommended: Key-Value. Justification: single-key access by user ID and extreme read/write speed.
Scenario B — Social network
Recommended: Graph. Justification: efficient multi-hop traversals and relationship queries.
Scenario C — Product catalog
Recommended: Document. Justification: flexible attributes, nested specifications, and array fields for reviews.
Scenario D — IoT sensor data
Recommended: Column-Family. Justification: high write throughput and efficient range queries by sensor ID and time.
