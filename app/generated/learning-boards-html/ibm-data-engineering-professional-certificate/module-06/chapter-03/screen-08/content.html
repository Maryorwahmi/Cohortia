Module 6 › Chapter 6.3 › Column-Family Stores
Definition
Data stored in rows with dynamic columns grouped into column families; optimized for large datasets and high write throughput.
Examples: Apache Cassandra, HBase, Google Bigtable. Use cases: time-series and event logging.
Practical scenario
IoT sensor data pattern
Store rows keyed by sensor ID with timestamped columns or clustering keys to efficiently query temperature readings for a sensor over a time range.
Pro tip
Design your row key and clustering columns to match your query patterns; avoid large rows that are expensive to read.
