Module 6 › Chapter 6.3 › Key-Value Stores
Definition
A datastore of unique keys each mapped to an arbitrary value; structure inside values is opaque to the store.
Examples: Redis, Amazon DynamoDB, Memcached. Use cases include caching, sessions, and fast lookups.
Concrete example
"user:123:cart" = "{\"items\": [{\"id\": 42, \"qty\": 2}], \"total\": 59.98}"
When to avoid
  • When you need queries across fields or complex joins.
  • When value sizes grow too large for efficient caching.
Pro tip
Keep value objects compact. Use them as a fast read path, not as the only source of truth when complex queries are required.
Common mistake
Using a key-value store to replace a relational model that needs joins and field-level indexing leads to brittle designs.
