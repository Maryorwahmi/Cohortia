Module 6 › Chapter 6.3 › Document Databases
Core idea
Store semi-structured documents with nested fields and arrays; query by document content.
Examples: MongoDB, Couchbase, Amazon DocumentDB. Ideal for product catalogs, blogging platforms, and user profiles.
Concrete document example
{  "_id": ObjectId("60c72b2f9e4c1a001c8e4d1a"),  "name": "Wireless Headphones",  "brand": "AudioTech",  "price": 199.99,  "category": "Electronics",  "specifications": {    "color": ["Black", "Silver"],    "connectivity": "Bluetooth 5.0",    "battery_life_hours": 30  },  "reviews": [    { "user": "Alice", "rating": 5, "comment": "Great sound!" },    { "user": "Bob", "rating": 4, "comment": "Comfortable but a bit pricey." }  ]}
Key Takeaway
Embed related attributes to avoid joins; validate documents to prevent schema drift.
