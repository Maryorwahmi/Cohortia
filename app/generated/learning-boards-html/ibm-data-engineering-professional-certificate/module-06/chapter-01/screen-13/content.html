Map data sources to the five Vs
Concrete advice that supports architecture choices.
GPS coordinates

Dominant Vs: Velocity and Volume. Use streaming ingestion, short-term in-memory state for routing, and partitioned long-term storage.

Support chat & audio

Dominant Vs: Variety and Veracity. Store raw audio in object store, transcribe for text search, and apply quality checks on transcripts.

Historical transactions

Dominant Vs: Volume and Value. Use partitioned columnar storage for analytics and retention tiers for cost control.

Recommended mix

Combine streaming platforms for real-time needs, object stores for raw unstructured files, and columnar stores for analytics to meet each source's dominant constraints.

Check your understanding

For each proposed storage layer, name a failure mode and a mitigation: e.g., for streaming, backpressure handling; for object stores, data lifecycle policies; for columnar stores, partition pruning strategies.
