Module 6 › Chapter 6.1 › RDBMS vs Big Data
When RDBMS excel

Strong consistency, structured schema, transactional integrity for OLTP systems.

When they struggle
  • Very high ingestion rates across many producers
  • Unstructured or schema-evolving datasets
  • Cost of vertical scaling beyond practical limits
Concrete example

Loading petabytes of raw logs into MySQL for analytics leads to poor ingest rates, heavy indexing costs, and slow scans. A distributed file and query engine is more appropriate for analytics at this scale.

Common mistake

Assuming SQL workload patterns imply RDBMS is the default storage for any dataset — you must match tool to requirement.

Key Takeaway

Use RDBMS for transactional workloads and distributed systems for large-scale ingestion, storage, and analytics.
