Module 6 › Chapter 6.1 › Variety
Three common formats
Structured

Tables with fixed columns — ideal for transactions and easy joins.

Semi-structured

Variable fields like JSON need parsers and flexible storage models.

Unstructured

Files, images, and audio that require special indexing and feature extraction.

Example

A ride-sharing company stores trips in structured tables, client logs as JSON, and voice recordings as objects. Analytics combine these sources after normalization and feature extraction.

Practical tip

Standardize a minimal ingestion schema for each data class and keep raw copies to allow reprocessing when schemas change.

Key Takeaway

Pick storage and indexing models that match each data type and make downstream integration predictable.
