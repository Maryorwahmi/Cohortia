Module 3 › Chapter 3.1 › Mutability
Mutable Types
Lists and dictionaries can be changed in place. Use when you need to build or update state.
a = [1,2]
b = a
b.append(3)
# a is now [1,2,3]
Immutable Types
Tuples and strings cannot be modified. Use to protect values and express intent.
t = (1,2)
# t[0] = 3  # would raise TypeError
Key Takeaway
Be explicit: choose mutability to match the operation and avoid shared-state surprises by copying when needed.
