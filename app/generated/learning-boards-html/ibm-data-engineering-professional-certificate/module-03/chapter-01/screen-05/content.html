Module 3 › Chapter 3.1 › Lists vs Tuples
Lists (Mutable)
Use when you need to modify, append, or remove items.
data_files = ["a.csv", "b.json"]
data_files.append("c.parquet")
# data_files now has three items
Good for iterating and building collections during processing.
Tuples (Immutable)
Use to represent fixed records and protect them from accidental change.
coords = (40.71, -74.01)
# coords[0] = 41  # would raise TypeError
Convert when needed: list(coords) or tuple(list_of_values).
Example Scenario
Model a fixed header as a tuple and collected rows as a list. This prevents accidental header alteration while letting you append rows.
header = ("id","name","email")
rows = []
rows.append((101,"Alice","a@x.com"))
Key Takeaway
Choose tuples to express immutability and lists for flexible collections in processing steps.
