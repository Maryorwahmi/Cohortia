Module 3 › Chapter 3.1 › TypeError & KeyError
TypeError Example
count = "500"
# Wrong:
total = count + 20   # TypeError
# Fix:
total = int(count) + 20  # 520
Validate strings with str.isdigit or try/except for robust conversion.
KeyError Example
profile = {"id":101, "name":"Alice"}
# Wrong:
phone = profile["phone"]   # KeyError
# Safer:
phone = profile.get("phone", None)
Prefer get with a default or check membership before direct access.
Practice
Create inputs that intentionally trigger each error, then apply conversion and safe access patterns until the code handles them without crashing.
