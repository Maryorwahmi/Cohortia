Starter Code
file_names = [
  "daily_transactions.csv",
  "user_profiles.json",
  "system_logs.txt",
  "archive.zip",
  "sensor_data_Q1.csv",
  "temp_report.txt"
]

processed_files = {}

for file_name in file_names:
  if file_name.endswith('.csv') or file_name.endswith('.json'):
    status = "Processed Successfully"
  elif file_name.endswith('.txt'):
    status = "Review Required"
  else:
    status = "Skipped - Unknown Format"
  processed_files[file_name] = status

print("Processing Summary:")
for file, status in processed_files.items():
  print(f"- {file}: {status}")
Checklist
  • List with filenames exists
  • processed_files dictionary created
  • If/elif/else sets status for every branch
  • Results printed from processed_files
Common Error
Undefined status variable if a branch is missed. Ensure every branch assigns status before using it.
Extension Idea
Add timestamps, error messages, and counts of processed vs skipped for richer reporting.
