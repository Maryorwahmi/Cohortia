Pattern Example
results = []
for file_name in file_names:
  record = {}
  if file_name.endswith('.csv'):
    record['status'] = 'processed'
    record['rows'] = 100
  else:
    record['status'] = 'skipped'
  results.append({'file': file_name, 'meta': record})
Create a fresh record per iteration to avoid accidental shared references between results.
Mutability Note
If you reuse the same dict object and mutate it, all entries in results may reflect the final state.
Key Takeaway
Design each loop iteration to produce a new result object and handle failures so the pipeline continues.
