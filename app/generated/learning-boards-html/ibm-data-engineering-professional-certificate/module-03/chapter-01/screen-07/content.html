Process: Classify by Extension
for file_name in file_names:
  if file_name.endswith('.csv') or file_name.endswith('.json'):
    status = "Processed Successfully"
  elif file_name.endswith('.txt'):
    status = "Review Required"
  else:
    status = "Skipped - Unknown Format"
  processed_files[file_name] = status
This ordered evaluation ensures the first true condition handles the file and sets a clear status for later reporting.
Quick Tips
Use endswith for extension checks; prefer explicit conditions for clarity.
Indentation Pitfall
Incorrect indentation produces IndentationError. Pick spaces and stick to them across the file.
Key Takeaway
Order your conditions and ensure consistent indentation to create correct decision logic.
