Example Loop
file_names = ["a.csv","b.json","c.txt"]
processed_files = {}

for file_name in file_names:
  if file_name.endswith('.csv') or file_name.endswith('.json'):
    processed_files[file_name] = "Processed Successfully"
  elif file_name.endswith('.txt'):
    processed_files[file_name] = "Review Required"
  else:
    processed_files[file_name] = "Skipped - Unknown Format"

print("Processing Summary:")
for file, status in processed_files.items():
  print(f"- {file}: {status}")
This pattern builds a dictionary of results while iterating files—common in ETL steps.
Enumerate
Use enumerate when you need a counter: for i, name in enumerate(list).
Pitfall
Mutating the sequence while iterating can cause unexpected behavior; iterate over a copy if you must modify.
Key Takeaway
Prefer iterating directly over collections for readable and safe loops in processing scripts.
