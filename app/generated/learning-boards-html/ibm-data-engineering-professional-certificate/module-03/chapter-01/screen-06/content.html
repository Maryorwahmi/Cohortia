Module 3 › Chapter 3.1 › Dictionaries
Definition
Unordered mapping of keys to values. Ideal for records and JSON-like data.
user_profile = {"id":101, "name":"Alice", "email":"alice@example.com"}
print(user_profile["name"])         # Alice
print(user_profile.get("phone","n/a"))  # safe access
Use get() or check membership to avoid KeyError when reading values from variable input.
Processing Pattern
Store statuses keyed by file name so you can later serialize a report.
processed_files = {}
processed_files["daily_transactions.csv"] = "Processed Successfully"
processed_files["system_logs.txt"] = "Review Required"
Common Mistake
Accessing a missing key directly raises KeyError. Use get or membership checks for safety.
