Example: Retry Pattern
attempts = 3
success = False

while attempts > 0 and not success:
  try:
    # call network or external step
    success = True
  except Exception:
    attempts -= 1

if not success:
  print("Failed after retries")
Always modify a loop variable or use break so termination will occur.
Guard Pattern
Include a max attempts counter or timeout to prevent endless execution.
Common Mistake
Using while True without a reliable break condition can freeze scripts and pipelines.
Key Takeaway
Prefer for loops for known-length iteration; use while with clear state changes and guards.
