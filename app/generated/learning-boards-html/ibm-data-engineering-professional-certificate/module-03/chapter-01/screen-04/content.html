Module 3 › Chapter 3.1 › Variables & Types
Definition
Variable: named reference to a value. Types: int, float, str, bool.
# Examples
count = 100           # int
rate = 0.05           # float
status = "Running"   # str
is_valid = True       # bool

# Common mistake: adding str and int raises TypeError
value = "500" + 20   # TypeError
# Fix:
value = int("500") + 20  # 520
Pro Tip
When reading CSV fields, inspect a sample row and convert types early in the pipeline.
Common Mistake
Assuming input is numeric; this leads to TypeError during arithmetic operations.
Explanation & Quick Checks
  • Every operation depends on the object's type, not the variable name.
  • Use int() and float() to convert numeric strings; use str() to format logs.
  • Booleans are useful for flags in validation and gating pipeline steps.
Key Takeaway

Validate and convert external inputs at the boundary. Types prevent many runtime errors if handled early.
