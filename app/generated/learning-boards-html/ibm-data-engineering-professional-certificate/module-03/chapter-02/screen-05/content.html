Module 3 › Chapter 3.2 › List comprehensions vs loops
Loop version
file_sizes_str = ['10', '20', '30']
file_sizes = []
for size in file_sizes_str:
  file_sizes.append(int(size))
print(file_sizes)
Comprehension version
file_sizes_str = ['10', '20', '30']
file_sizes = [int(size) for size in file_sizes_str]
print(file_sizes)
When adding a filter, keep the condition simple to preserve readability: [int(s) for s in strs if s.isdigit()]
