Module 3 › Chapter 3.2 › List comprehensions with conditionals
Example: filter valid floats then convert
raw_readings = ["10.5", None, "12.3", "invalid", "8.9", None]
# safe filter: remove None and non-numeric strings with a simple check
valid = [float(r) for r in raw_readings if r is not None and r.replace('.', '', 1).isdigit()]
print(valid)
Why it works
Condition excludes invalid entries before conversion, preventing exceptions.
Misconception
Don't cram complex try/except into comprehensions; use helper functions if needed.
Pro tip
Keep the predicate simple and test it separately when possible.
