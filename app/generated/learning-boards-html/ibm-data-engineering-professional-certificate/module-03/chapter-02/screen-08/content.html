Module 3 › Chapter 3.2 › Dictionary comprehensions
Example: generate file statuses
status = { 'file_' + str(i): 'status_pending' for i in range(5) }
print(status)
Caveat: key collisions
If two items produce the same key, the later value overwrites the earlier one. When keys must be unique, aggregate into lists or raise an error during construction.
If you need aggregation, prefer building a new dict and append to lists for each key instead of a plain comprehension.
