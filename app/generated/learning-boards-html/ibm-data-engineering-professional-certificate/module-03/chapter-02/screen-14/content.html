Module 3 › Chapter 3.2 › Designing modular pipeline steps
Hierarchy example
Record helper: clean_record(record) → returns cleaned record
Batch transformer: transform_batch(records) → uses a comprehension calling helpers
Orchestrator: run_pipeline(stages, data) → sequences steps and returns final dataset
When you need to add logging, metrics, or retries, instrument the orchestration layer instead of modifying record helpers. This keeps concerns separated and makes each layer easier to reason about and test independently.
