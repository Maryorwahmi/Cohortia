Module 3 › Chapter 3.2 › Advanced list methods
Process steps
Insert
Place an element at a specific index to maintain ordering without rebuilding the list.
Remove
Delete first matching value. Use when you know the value but not its position.
Pop
Remove by index and get the element back for follow-up processing.
Sort / sorted
Order elements in place or return a new sorted list to preserve the original.
Concrete example
files = ['log3.txt', 'log1.txt', 'log2.txt']
# sort by name
files.sort()
# process newest (after custom ordering)
latest = files.pop()  # removes and returns last element
# insert a priority file at front
files.insert(0, 'priority.log')
print(files, latest)
Key Takeaway

Use the list method that matches your semantic need and be aware of performance costs for operations on large lists.
