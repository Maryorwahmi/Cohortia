Module 3 › Chapter 3.2 › Dictionary iteration and methods
Common patterns
  • for k in my_dict.keys(): iterate keys
  • for v in my_dict.values(): iterate values
  • for k, v in my_dict.items(): iterate pairs
Use dict.get(key, default) to read optional keys safely without exceptions.
Example: revenue calculation
prices = {'p1': 10.0, 'p2': 15.5}
quantities = {'p1': 3, 'p2': 2}
total = 0
for pid, price in prices.items():
  qty = quantities.get(pid, 0)
  total += price * qty
print(total)
Tip: build a new mapping rather than modifying the dictionary during iteration.
