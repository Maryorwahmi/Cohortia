Return Value
The value a function explicitly sends back; if omitted, None is returned implicitly.
Variable Scope
Defines where a name is visible; local scope prevents unintended side effects from functions.
Lambda Function
A short anonymous single-expression function, handy with sorted, map, and filter for small operations.
