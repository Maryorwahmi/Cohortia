Example: cleaning function
def clean_data_string(raw_string):
    """
    Removes leading/trailing whitespace and converts to lowercase.
    """
    cleaned = raw_string.strip().lower()
    return cleaned

# Usage
dirty_name = "  John Doe  "
clean_name = clean_data_string(dirty_name)
print(clean_name)
Key Takeaway

Always return the transformed value. Keep functions small and name parameters clearly so each piece is obvious and testable.
