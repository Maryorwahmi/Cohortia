Module 3 › Chapter 3.2 › Lambda functions with sorted, map, filter
Examples
data = [{'name':'Bob','score':85},{'name':'Alice','score':92}]
# sort by score
sorted_data = sorted(data, key=lambda x: x['score'])
print(sorted_data)

# filter using lambda
scores = [10, 20, 30, 40]
high = list(filter(lambda x: x > 25, scores))
print(high)
When readability suffers, replace a lambda with a named function and add a short docstring. This simplifies debugging and testing.
