Module 3 › Chapter 3.2 › Modifying a dictionary while iterating
Unsafe pattern
# Do not do this
for k in my_dict.keys():
  if should_remove(k):
    del my_dict[k]
Safe alternatives
Iterate over a copy: for k in list(my_dict.keys()): ...
Build a new mapping: new = {k:v for k,v in my_dict.items() if keep(k)}
Accumulate removals and delete after the loop completes.
