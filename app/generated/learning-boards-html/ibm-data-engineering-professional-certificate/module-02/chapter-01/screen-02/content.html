Learning Objectives
Learn, Understand, Apply, Master
Bloom: Learn → Understand → Apply → Master
01
Explain relational structure
Describe tables, columns, rows, and how they form relations. You will use a Customers and Orders example to make these terms concrete.
Verified Competency Milestone
02
Understand primary and foreign keys
Explain uniqueness and referential links, and why these constraints prevent orphaned records and duplication.
Verified Competency Milestone
03
Write DDL and DML
Create tables with appropriate data types and constraints, and insert rows with correct literals and quoting.
Verified Competency Milestone
04
Retrieve data with SELECT
Run simple and column-specific queries to validate rows and relationships, and check results in a terminal client like sqlite3.
Verified Competency Milestone
