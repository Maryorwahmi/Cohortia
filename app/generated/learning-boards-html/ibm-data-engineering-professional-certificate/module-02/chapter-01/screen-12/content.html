Starter SQL
-- Step 1: Create Customers table
CREATE TABLE Customers (
  CustomerID INT PRIMARY KEY,
  FirstName VARCHAR(50) NOT NULL,
  LastName VARCHAR(50) NOT NULL,
  Email VARCHAR(100) UNIQUE,
  RegistrationDate DATE
);

-- Step 2: Create Orders table
CREATE TABLE Orders (
  OrderID INT PRIMARY KEY,
  CustomerID INT,
  OrderDate DATE,
  TotalAmount DECIMAL(10, 2),
  FOREIGN KEY (CustomerID) REFERENCES Customers(CustomerID)
);
Insert & Verify
Insert at least three customers and four orders, making sure Order.CustomerID matches an existing CustomerID. Then run SELECT * on both tables to verify.

Key Takeaway

Practice creating schemas, inserting rows, and running selects to confirm referential integrity and data correctness.
