Employees table example
Below is the canonical CREATE TABLE example used in this chapter. Use it as a template for defining primary keys, NOT NULL fields, UNIQUE constraints, and precise numeric types for money.
CREATE TABLE Employees (
  EmployeeID INT PRIMARY KEY,
  FirstName VARCHAR(50) NOT NULL,
  LastName VARCHAR(50) NOT NULL,
  Email VARCHAR(100) UNIQUE,
  HireDate DATE,
  Salary DECIMAL(10, 2)
);
Explanation
  • EmployeeID INT PRIMARY KEY: unique identifier, non-nullable by design.
  • VARCHAR(n): variable-length string with maximum n characters; prefer realistic limits.
  • DECIMAL(10, 2): precise numeric type for financial values with two decimals.
Key Takeaway
Choose types deliberately. Constraints like PRIMARY KEY, NOT NULL, and UNIQUE are your first defense against bad data.
