Module 2 › Chapter 2.1 › Database Clients
sqlite3 (file-based)
Example: sqlite3 company.db Type SQL commands followed by a semicolon. Useful for local practice.
psql (Postgres)
Connect to a server, then run SQL interactively. Good for server-based testing.
db2 (Db2)
Use db2 connect to sample and db2 "SELECT * FROM EMPLOYEES" to run statements in Db2.
Caution

Verify the database you are connected to before running CREATE or INSERT; these operations can be permanent on the target instance.
