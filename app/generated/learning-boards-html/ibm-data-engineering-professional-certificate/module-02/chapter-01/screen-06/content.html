Module 2 › Chapter 2.1 › SQL Sublanguages
DDL
CREATE, ALTER, DROP
Define and modify schemas. Example: CREATE TABLE Employees (...).
DML
INSERT, SELECT, UPDATE, DELETE
Operate on rows. Example: INSERT INTO Employees (...) VALUES (...);
DCL
GRANT, REVOKE
Manage permissions. Relevant later for production databases.
Declarative vs Imperative
SQL is declarative: you state the result you want. The engine chooses an execution plan. Misconception: writing SQL is not like scripting each step; focus on the results and let the database optimize.
