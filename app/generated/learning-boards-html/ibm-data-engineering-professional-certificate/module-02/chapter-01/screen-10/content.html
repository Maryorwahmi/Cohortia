Module 2 › Chapter 2.1 › Common Data Types
INTEGER
Whole numbers. Good for ids and counts.
VARCHAR(n) / TEXT
Variable string lengths; use VARCHAR with realistic n, TEXT for long form content.
DATE / TIMESTAMP
Temporal types for dates and full timestamps. Use the most appropriate granularity for queries.
DECIMAL(p, s)
Fixed-point for precise financial values. Example: DECIMAL(10, 2) for salaries.
Misconception

Bigger types do not always help. Specify types that reflect real constraints to improve storage and validation.
