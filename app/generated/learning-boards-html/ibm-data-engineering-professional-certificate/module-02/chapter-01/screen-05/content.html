Module 2 › Chapter 2.1 › Primary & Foreign Keys
Primary Key
A column or set of columns that uniquely identifies each row. Must be unique and not null.
Example
EmployeeID INT PRIMARY KEY in an Employees table guarantees each employee has a single identifier.
Common Mistake
Using a non-unique column as a primary key or allowing nulls undermines identity and causes duplicate record ambiguity.
Foreign Key
A column that references a primary key in another table to establish a relationship and maintain integrity.
Example
Orders table has CustomerID that references Customers.CustomerID so every order links to an existing customer.
Pro Tip

Add foreign key constraints where data integrity matters; omit them in high-throughput pipelines only when performance or replication patterns demand it.
