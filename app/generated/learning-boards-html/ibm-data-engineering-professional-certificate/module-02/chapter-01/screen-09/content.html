Module 2 › Chapter 2.1 › SELECT Queries
Quick inspection
-- Retrieve all columns and rows
SELECT * FROM Employees;

-- Retrieve specific columns
SELECT FirstName, LastName, Salary FROM Employees;
Why prefer explicit columns?
  • Reduced bandwidth and clearer results for callers.
  • Protects scripts from schema changes like added or reordered columns.
  • Makes intent explicit for reviewers and maintainers.
Check Your Understanding

After inserting rows, run SELECT * then a column-specific SELECT to confirm both overall storage and particular attributes like salary values.
