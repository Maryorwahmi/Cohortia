Module 02 › Chapter 2.2 › Key Concepts
WHERE Clause
Filters individual rows before grouping and aggregation; use comparison, LIKE, or BETWEEN here.
Logical Operators
Combine conditions with AND, OR, NOT and use parentheses to ensure correct evaluation order.
LIKE & BETWEEN
Pattern matching and inclusive ranges; be mindful of performance and collation rules.
Aggregate Functions
COUNT, SUM, AVG, MIN, MAX summarize rows into single values for reporting.
GROUP BY
Group rows by column values; include non-aggregated SELECT columns in GROUP BY.
HAVING
Filters groups using aggregate-aware conditions; use after GROUP BY, not in WHERE.
Summary Takeaway
Filter rows with WHERE, summarize with aggregates and GROUP BY, and filter groups with HAVING. Order and limit only after you have the desired rows or summaries.
