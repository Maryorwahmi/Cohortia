Code Walkthrough

Build a grouped report step-by-step

Start with WHERE to reduce rows, then GROUP BY and use HAVING to filter groups; finally ORDER BY and LIMIT the results for reporting.

Full example
-- Top 2 departments with avg salary > 70000, hires after 2021
SELECT DepartmentID, AVG(Salary) AS AverageDepartmentSalary
FROM Employees
WHERE HireDate >= '2022-01-01'
GROUP BY DepartmentID
HAVING AVG(Salary) > 70000
ORDER BY AverageDepartmentSalary DESC
LIMIT 2;
Execution tips
When a query fails, remove clauses one-by-one to find the error. Use column aliases for aggregates and reference those aliases in ORDER BY when supported by your dialect.
Concrete example
Modify the WHERE filter for different hire-date windows to see how the average salary per department changes over time.
Common misconception
Assuming ORDER BY can change which rows are grouped. Grouping happens before ordering; ORDER BY only formats the final output.
Key Takeaway

Compose queries in phases and validate each phase; this prevents logical errors and improves confidence in results.
