Module 02 › Chapter 2.2 › Comparison Operators
Operators

=, !=, >, <, >=, <=, BETWEEN

Use comparison operators for numeric and date filtering. BETWEEN is an inclusive range operator for clearer range queries.

Examples
-- Salary greater than 70000
SELECT FirstName, LastName, Salary
FROM Employees
WHERE Salary > 70000;

-- HireDate inclusive range with BETWEEN
SELECT FirstName, LastName, HireDate
FROM Employees
WHERE HireDate BETWEEN '2022-01-01' AND '2022-12-31';

-- Equivalent using AND
SELECT FirstName, LastName
FROM Employees
WHERE Salary >= 50000 AND Salary <= 80000;
Guidance
After writing a range query, examine rows at the boundaries to ensure inclusivity matches your intent. If the column permits NULL, consider whether NULL rows should be excluded or handled explicitly.
Concrete example
To get hires in 2022 inclusive, BETWEEN '2022-01-01' AND '2022-12-31' returns dates on the first and last day as well.
Pitfall
Using string comparisons for numeric ranges can produce unexpected order; verify the column type to avoid lexicographic ordering surprises.
Key Takeaway

Prefer BETWEEN for inclusive ranges and always verify column types and NULL behavior at boundaries.
