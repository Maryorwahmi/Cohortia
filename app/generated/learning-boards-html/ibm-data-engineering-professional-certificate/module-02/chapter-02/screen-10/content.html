Module 02 › Chapter 2.2 › GROUP BY
Hierarchy

Group rows to compute category summaries

GROUP BY produces one summary row per distinct combination of the grouped columns.

Examples
-- Count employees per department
SELECT DepartmentID, COUNT(*) AS NumberOfEmployees
FROM Employees
GROUP BY DepartmentID;

-- Average salary per department
SELECT DepartmentID, AVG(Salary) AS AverageDepartmentSalary
FROM Employees
GROUP BY DepartmentID;
Guidance
If a column in SELECT is not aggregated, include it in GROUP BY. When grouping by multiple columns, the grouping key is the combination of those columns.
Concrete example
After adding DepartmentID to Employees, the average salary per department is expressed by grouping by DepartmentID and using AVG(Salary).
Common mistake
Omitting a non-aggregated column from GROUP BY leads to errors or unexpected results; include every non-aggregated select column in GROUP BY.
Key Takeaway

GROUP BY creates category-level summaries; ensure SELECT and GROUP BY columns align to avoid errors.
