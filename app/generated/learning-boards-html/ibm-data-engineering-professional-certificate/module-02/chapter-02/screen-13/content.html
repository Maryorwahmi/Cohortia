Hands-on: Analyzing Employee Data

Use the starter templates below. Replace TODO with conditions appropriate for your dataset and run the queries in your SQL editor.

Query 1 — Filter and Sort
SELECT FirstName, LastName, Salary, HireDate
FROM Employees
WHERE HireDate > '2022-01-01' AND Salary < 80000
ORDER BY HireDate ASC;
-- Replace dates and salary threshold as needed
Query 2 — Aggregation
SELECT SUM(Salary) AS TotalSalaryExpenditure
FROM Employees;
Query 3 — Grouped Aggregation
SELECT DepartmentID, AVG(Salary) AS AverageDepartmentSalary
FROM Employees
GROUP BY DepartmentID;
Query 4 — Filtered Grouped Aggregation
SELECT DepartmentID, AVG(Salary) AS AverageDepartmentSalary
FROM Employees
GROUP BY DepartmentID
HAVING AVG(Salary) > 70000;
Check your results
Confirm row counts, inspect boundary hires and NULLs, and compare aggregates before and after WHERE to see how filters affect summaries.
Pro Tip
Build queries incrementally: test WHERE filters, then add GROUP BY and aggregates, and finally apply HAVING and ORDER BY.
