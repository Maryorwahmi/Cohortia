Comparison

ORDER BY columns and LIMIT rows

Sort on one or more columns and slice results to return just the rows you need.

Examples
-- Order by LastName alphabetically
SELECT FirstName, LastName, Salary
FROM Employees
ORDER BY LastName ASC;

-- Order by Salary highest to lowest
SELECT FirstName, LastName, Salary
FROM Employees
ORDER BY Salary DESC;

-- Top 2 highest-paid employees
SELECT FirstName, LastName, Salary
FROM Employees
ORDER BY Salary DESC
LIMIT 2;
Guidance
If you need the top N by some metric, always use ORDER BY on that metric before LIMIT. Without ORDER BY, LIMIT returns an arbitrary subset with no guaranteed order.
Concrete example
To show newest hires first, ORDER BY HireDate DESC and then LIMIT 10 to preview recent hires for a dashboard.
Common misconception
Assuming LIMIT returns the highest values without ORDER BY. Always specify ordering when top or bottom rows matter.
Key Takeaway

Order first, then limit. That sequence produces predictable top-N results for reporting or sampling.
