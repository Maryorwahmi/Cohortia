Module 02 › Chapter 2.2 › Aggregate Functions
Definition

COUNT, SUM, AVG, MIN, MAX

Aggregate functions compute single values from sets of rows for reporting and analysis.

Examples
-- Total number of employees
SELECT COUNT(*) AS TotalEmployees FROM Employees;

-- Average salary of all employees
SELECT AVG(Salary) AS AverageSalary FROM Employees;

-- Highest and lowest salary
SELECT MAX(Salary) AS MaxSalary, MIN(Salary) AS MinSalary FROM Employees;
Guidance
Decide whether to COUNT non-null values or COUNT all rows. Use WHERE to filter rows first, then aggregate the remaining set.
Concrete example
To compute total payroll, use SUM(Salary) on rows filtered by employment status or department.
Common misconception
Expecting WHERE to filter aggregates. If you need to filter by AVG or COUNT, use HAVING after GROUP BY.
Key Takeaway

Aggregates turn many rows into single summary values; filter rows first and handle NULLs intentionally.
