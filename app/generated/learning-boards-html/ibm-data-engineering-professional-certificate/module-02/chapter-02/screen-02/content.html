Learning Objectives

From filtering rows to summarizing groups — measurable skills for your SQL toolkit.

Bloom: Learn → Understand → Apply → Master
01
Filter rows with WHERE

Construct SELECT statements using WHERE to retrieve rows that match one or more conditions, which lets you focus on relevant records for analysis.

VERIFIED COMPETENCY MILESTONE
02
Combine conditions with AND/OR/NOT

Use logical operators to express complex filters and parentheses to control evaluation order so results match your intent.

VERIFIED COMPETENCY MILESTONE
03
Order results and limit rows

Order by one or more columns and use LIMIT to return only a subset, which is useful for pagination and top-N queries.

VERIFIED COMPETENCY MILESTONE
04
Aggregate functions for summaries

Apply COUNT, SUM, AVG, MIN, and MAX to compute summary values across rows to support reporting and analysis.
