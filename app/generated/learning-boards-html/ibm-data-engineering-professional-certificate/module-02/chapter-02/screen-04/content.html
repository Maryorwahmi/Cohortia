Module 02 › Chapter 2.2 › WHERE clause
Definition

WHERE: row-level filtering

Evaluate conditions for every row and include only matching rows in the result set.

Examples
-- Retrieve employees earning more than 70000
SELECT FirstName, LastName, Salary
FROM Employees
WHERE Salary > 70000;

-- Retrieve employees hired in 2022
SELECT FirstName, LastName, HireDate
FROM Employees
WHERE HireDate BETWEEN '2022-01-01' AND '2022-12-31';

-- Retrieve employees whose last name starts with 'S'
SELECT FirstName, LastName
FROM Employees
WHERE LastName LIKE 'S%';
Concrete example
To list employees hired in 2022, use BETWEEN on HireDate to include the entire year, ensuring the date format matches your DB.
Common mistake
Expecting WHERE to filter aggregate results. If you check an aggregate like AVG, use HAVING after GROUP BY.
Practice
Try these checks in a console: confirm the number of rows returned, and preview the first and last rows to validate edge cases like NULLs or boundary dates.
Quick checklist
  • Is the column type numeric, text, or date? Use proper comparison.
  • Are boundary values inclusive or exclusive? BETWEEN is inclusive.
  • Watch for NULL values—WHERE comparisons with NULL require IS NULL.
Key Takeaway

WHERE filters rows early; it is evaluated before grouping and aggregation.
