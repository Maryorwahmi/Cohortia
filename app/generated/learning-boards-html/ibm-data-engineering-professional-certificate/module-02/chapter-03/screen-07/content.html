Module 3 › Chapter 2.3 › FULL OUTER JOIN
Behavior
Returns all rows from both sides, matching where possible; unmatched columns are NULL on the missing side.
SELECT
  C.FirstName,
  C.LastName,
  O.OrderID,
  O.OrderDate
FROM Customers AS C
FULL OUTER JOIN Orders AS O ON C.CustomerID = O.CustomerID;
When to use
Reconciliation, auditing, or detecting orphaned rows on either side of a relationship where you need the complete union of both tables.
Misconception: using FULL OUTER JOIN for everyday reporting will often return unnecessary NULLs and large result sets; prefer targeted joins with filters when possible.
Key Takeaway
FULL OUTER JOIN is powerful for complete comparisons but can be costly; choose it when you need every record from both sides.
