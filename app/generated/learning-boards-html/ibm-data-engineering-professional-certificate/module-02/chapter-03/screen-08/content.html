Module 3 › Chapter 2.3 › Preventing Cartesian products
Checklist to avoid Cartesian products
  • Identify the primary key/foreign key relationship to use in ON.
  • Use explicit JOIN ... ON syntax instead of comma joins.
  • Alias tables; avoid ambiguous column references.
  • Test queries on small subsets to confirm expected row counts.
If results explode, check if an ON clause is missing, wrong, or if column names are mis-referenced.
Concrete example of the mistake
-- Incorrect: missing ON clause produces Cartesian product
SELECT C.FirstName, O.OrderID
FROM Customers AS C, Orders AS O; -- avoid this style

-- Correct: explicit ON clause
SELECT C.FirstName, O.OrderID
FROM Customers AS C
INNER JOIN Orders AS O ON C.CustomerID = O.CustomerID;
Pro Tip
Prefer explicit JOIN syntax and run a LIMIT 10 when testing to check results quickly.
