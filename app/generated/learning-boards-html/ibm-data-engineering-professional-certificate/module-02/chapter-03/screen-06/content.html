Module 3 › Chapter 2.3 › LEFT JOIN vs RIGHT JOIN
LEFT JOIN
Returns all left-table rows and matching right-table rows; unmatched right columns are NULL.
SELECT C.FirstName, C.LastName, O.OrderID, O.OrderDate
FROM Customers AS C
LEFT JOIN Orders AS O ON C.CustomerID = O.CustomerID;
Use LEFT JOIN when Customers is your primary set and you want to include every customer even when they have no orders.
RIGHT JOIN
Returns all right-table rows and matching left-table rows; unmatched left columns are NULL.
SELECT C.FirstName, C.LastName, O.OrderID, O.OrderDate
FROM Customers AS C
RIGHT JOIN Orders AS O ON C.CustomerID = O.CustomerID;
Misconception: choosing RIGHT JOIN for readability. Prefer making the preserved table the left side and using LEFT JOIN for clearer intent in most queries.
Key Takeaway
Decide which table you must keep intact; place it on the preserved side and use the corresponding OUTER JOIN.
