Module 3 › Chapter 2.3 › Key Concepts
JOIN
Combine rows from tables using a related column to create a unified result set.
INNER JOIN
Returns only rows that have matching values in both tables according to the ON condition.
LEFT JOIN
Includes all rows from the left table and matching rows from the right; non-matches have NULLs in right-side columns.
Takeaway
Remember which side you want preserved, choose the appropriate join, and validate results on small data before scaling up.
