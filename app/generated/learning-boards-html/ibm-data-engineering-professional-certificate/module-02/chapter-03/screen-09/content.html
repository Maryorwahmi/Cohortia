Module 3 › Chapter 2.3 › Subqueries — types
Scalar Subquery
Returns one value. Useful for comparing a column to an aggregate like average or max.
SELECT FirstName, LastName, Salary
FROM Employees
WHERE Salary > (SELECT AVG(Salary) FROM Employees);
Table & Correlated
Table subqueries return a derived table in FROM; correlated subqueries reference the outer row and often use EXISTS to test per-row conditions.
-- Table subquery as derived table
SELECT AVG(Sub.Salary) AS AvgSalary2022
FROM (
  SELECT Salary
  FROM Employees
  WHERE HireDate BETWEEN '2022-01-01' AND '2022-12-31'
) AS Sub;

-- Correlated example uses EXISTS:
SELECT DISTINCT DepartmentID
FROM Employees E1
WHERE EXISTS (
  SELECT 1 FROM Employees E2 WHERE E2.DepartmentID = E1.DepartmentID AND E2.Salary > 80000
);
Key Takeaway
Choose the subquery shape that matches the data you need: a single value, a row, a derived table, or a per-row existence test.
