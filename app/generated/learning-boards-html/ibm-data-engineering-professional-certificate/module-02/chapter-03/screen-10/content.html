Module 3 › Chapter 2.3 › Scalar subquery example
Pattern
Compute an aggregate inside a subquery, then compare outer rows to that single value.
SELECT FirstName, LastName
FROM Customers
WHERE CustomerID IN (
  SELECT CustomerID
  FROM Orders
  WHERE TotalAmount > (SELECT AVG(TotalAmount) FROM Orders)
);
This finds customers with orders larger than the overall average order amount. The inner AVG(...) is a scalar subquery returning one value.
Concrete considerations
• Ensure the scalar subquery returns exactly one column and one row. • If you need per-customer averages, use GROUP BY or a derived table instead.
Misconception
Scalar subqueries are not always executed per row in optimized engines; treat them as expressive and rely on explain plans for performance checks.
Key Takeaway
Scalar subqueries are ideal for thresholds computed from aggregates and keep the outer query concise and readable.
