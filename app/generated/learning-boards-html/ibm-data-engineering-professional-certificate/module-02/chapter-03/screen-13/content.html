Module 3 › Chapter 2.3 › Activity: Customers & Products
Steps
  1. Create Products table and insert at least three products.
  2. Add ProductID to Orders and update or insert orders to reference products.
  3. INNER JOIN Customers, Orders, Products to list customer, product, and total.
  4. LEFT JOIN Customers to Orders to show customers without orders.
  5. Write scalar and correlated subqueries to filter by aggregates or per-row existence.
Starter SQL snippets
-- Create Products
CREATE TABLE Products (
  ProductID INT PRIMARY KEY,
  ProductName VARCHAR(100) NOT NULL,
  Price DECIMAL(10,2),
  StockQuantity INT
);

-- Example INNER JOIN joining all three tables
SELECT C.FirstName, C.LastName, P.ProductName, O.TotalAmount
FROM Customers AS C
INNER JOIN Orders AS O ON C.CustomerID = O.CustomerID
INNER JOIN Products AS P ON O.ProductID = P.ProductID;
Check
Verify NULL values for unmatched rows and that join counts match expected cardinality on sample data.
Key Takeaway
Follow the lab steps: create tables, link keys, then iterate through INNER and OUTER joins and subqueries while testing results on small datasets.
