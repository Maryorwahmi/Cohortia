EXISTS with correlated subquery
Use EXISTS when you want to test whether related rows satisfying a condition exist for each outer row.
SELECT DISTINCT C.FirstName, C.LastName
FROM Customers C
WHERE EXISTS (
  SELECT 1
  FROM Orders O
  WHERE O.CustomerID = C.CustomerID AND O.TotalAmount > 100
);
This query returns customers who have at least one order over 100. The inner query uses the outer CustomerID in its condition.
Practical notes
• Correlated subqueries run in the context of the outer row; they are intuitive for existence checks. • If you need to compute aggregates per outer row, consider JOINs with GROUP BY or window functions as alternatives.
Misconception: EXISTS always performs poorly. Many engines optimize EXISTS efficiently; test with explain plans when performance matters.
Key Takeaway
Use correlated subqueries with EXISTS for readable per-row presence checks; refactor to joins only if profiling indicates a need.
