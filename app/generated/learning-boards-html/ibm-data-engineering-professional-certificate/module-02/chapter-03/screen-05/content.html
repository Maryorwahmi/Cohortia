INNER JOIN behavior
Returns rows only when the join condition matches in both tables. Unmatched rows are excluded.
Example query
SELECT
  C.FirstName,
  C.LastName,
  O.OrderID,
  O.OrderDate,
  O.TotalAmount
FROM Customers AS C
INNER JOIN Orders AS O ON C.CustomerID = O.CustomerID;
• Use aliases for clarity when joining multiple tables.
• If Orders has multiple rows per customer, the result will include one row per order for that customer.
• Misconception: INNER JOIN will not deduplicate results automatically; add GROUP BY when you need summaries.
Concrete scenario
You want a report of every order with the customer's name. INNER JOIN is the natural choice since orders without valid customers are usually exceptions.
Key Takeaway
Use INNER JOIN to report only matched rows; combine with aggregation to produce per-entity summaries.
