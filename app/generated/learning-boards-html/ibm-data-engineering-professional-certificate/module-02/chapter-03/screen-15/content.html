Module 3 › Chapter 2.3 › Key Concepts
Scalar Subquery
Returns one value for comparisons, such as a threshold computed with AVG.
Table Subquery
Used in FROM as a derived table so you can compute filtered or aggregated intermediate results.
Correlated Subquery
References outer-row values and runs per row; often used with EXISTS for concise presence checks.
Final Takeaway
Match your pattern to the question: joins for combining related rows, subqueries for computed values or per-row tests. Always use explicit ON clauses and aliases to keep queries correct and maintainable.
