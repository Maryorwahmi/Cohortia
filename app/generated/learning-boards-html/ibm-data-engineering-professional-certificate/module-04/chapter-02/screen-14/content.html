Question 1
Which extraction strategy is best for a large, continuously updated table?
Correct: Incremental extraction using a last_updated_timestamp (reduces load and copies only changes).
Explanation: Full extraction is simpler but inefficient at scale. Incremental pulls limit data volume and source impact.
Question 2
A requests call fails with HTTP 403. What is most likely?
Correct: Missing or invalid authentication/authorization credentials.
Explanation: A 403 means the server understood the request but refuses to authorize it. Check tokens, headers, and permissions first.
Quick reflection
When you diagnose extraction failures, use logs and extraction metadata to decide whether to re-run an incremental window, refresh credentials, or escalate for schema review.
