Module 4 › Chapter 4.2 › Parsing JSON files
Pattern
Use json.load to parse nested structures, then map nested keys into flat fields for staging.
import json

# Extracting data from a JSON file
with open('products.json', 'r') as f:
    products_data = json.load(f)

print("Products data extracted successfully:")
for product in products_data[:2]:  # Print first two products
    print(product)
Example JSON snippet
[{"product_id": "P001", "name": "Laptop", "price": 1200.00, "category": "Electronics"}, ...]
When to normalize
If products contain nested lists or objects, extract the nested structures into separate staging tables and maintain keys to rejoin later.
Key Takeaway

Inspect JSON samples first. Use json.load for nested control and normalize nested objects to maintain a stable schema.
