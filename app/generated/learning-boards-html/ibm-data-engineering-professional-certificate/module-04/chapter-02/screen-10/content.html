Module 4 › Chapter 4.2 › Handling schema drift
What is schema drift?
A change in the structure or types of source data that can break downstream logic.
Detection steps
  • Inspect sample rows and keys after extraction.
  • Compare extracted schema to expected schema and log differences.
Handling options
Accept optional new fields and log them, or pause and request a schema change when critical fields change type or are removed.
Example
If a product price field changes from numeric to string, detect the type change and either coerce it or fail the run to avoid corrupting downstream aggregates.
Key Takeaway

Plan for schema change: validate, log, and decide whether to adapt automatically or stop for an explicit schema update.
