Module 4 › Chapter 4.2 › Extracting from Web APIs with requests
Pattern
Use requests.get, call response.raise_for_status, parse response.json(), and handle network exceptions.
import requests

api_url = 'https://jsonplaceholder.typicode.com/users'  # example mock API

try:
    response = requests.get(api_url)
    response.raise_for_status()
    users_data = response.json()
    print("Users data extracted from API successfully:")
    for user in users_data[:2]:
        print(f"ID: {user['id']}, Name: {user['name']}, Email: {user['email']}")
except requests.exceptions.RequestException as e:
    print(f"Error during API extraction: {e}")
Test tip
Use a public mock API during development to confirm expected fields, then switch to production endpoints with proper auth tokens and rate-limit handling.
Rate limit strategy
Detect throttling responses and implement retry with backoff. Respect API documentation for safe request patterns.
Key Takeaway

Network extraction must include status checks, exception handling, and respectful retry behavior to be reliable.
