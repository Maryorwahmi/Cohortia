Learning Objectives — Part 1

These objectives focus on database and file extraction, plus the decision-making that drives efficient ETL work.

01
Write efficient SQL extracts

Compose SELECT and WHERE clauses to limit rows. This reduces load on production databases and speeds up downstream processing.

VERIFIED COMPETENCY MILESTONE
02
Extract CSV with pandas

Use pandas.read_csv to load tabular data and inspect head rows. Add try-except blocks to handle missing files gracefully.

VERIFIED COMPETENCY MILESTONE
03
Parse JSON files

Use the json module for nested structures or pandas for flat JSON. Validate sample objects to confirm expected keys and types.

VERIFIED COMPETENCY MILESTONE
04
Differentiate full vs incremental

Understand when to pull all rows versus only new or changed records using timestamps or ID ranges to reduce data volume and source impact.
