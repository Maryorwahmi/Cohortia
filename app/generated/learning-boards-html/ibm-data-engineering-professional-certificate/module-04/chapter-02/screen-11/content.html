Module 4 › Chapter 4.2 › Performance considerations
Database performance
Index the incremental filter column so WHERE filters run quickly. Avoid queries that require full table scans in production.
File performance
Use streaming or chunked reads for very large CSVs instead of loading entire files into memory.
API performance
Respect rate limits and implement backoff on throttling. Monitor response times and retry windows to avoid being blocked.
Operational tip
Run performance tests with realistic data sizes and schedule heavy extracts during low-traffic windows when possible.
Key Takeaway

Think about scale from day one: index, stream, and back off to keep extraction resilient as data grows.
