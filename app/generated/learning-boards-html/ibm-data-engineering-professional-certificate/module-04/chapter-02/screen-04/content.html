Module 4 › Chapter 4.2 › The Extract stage explained
Definition
What extraction does

Extraction connects to sources and retrieves raw data into a staging area. It is not a passive copy; it must be chosen to match source behavior and operational constraints.

Common sources
  • Relational databases: SELECT queries
  • Flat files: CSV and JSON
  • Web APIs: HTTP JSON endpoints
Real-world check
After extraction verify row counts, inspect a few rows for expected keys and types, and log the extraction time window used.
Analogy
Think of extraction as a dock worker who takes only the crates scheduled for shipment instead of unloading the entire warehouse. Careful selection saves time and resources.
Example scenario
A retail orders table receives thousands of updates daily. A full extract would copy all historical orders every run. Instead, extract rows where order_date is later than the last successful extraction to retrieve only recent activity.
Key Takeaway

Plan extraction with the source in mind, validate the pull, and prefer incremental approaches for large, changing datasets.
