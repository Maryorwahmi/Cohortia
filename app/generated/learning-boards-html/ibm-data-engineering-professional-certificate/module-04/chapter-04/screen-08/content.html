Logging pattern
logging.info('Starting load for batch_id=123')
logging.info(f'Attempting to load {len(df)} rows')
try:
  # load steps
  logging.info('Load succeeded')
except Exception as e:
  logging.error(f'Load failed: {e}')
  raise
Include run identifiers and row counts so each run is auditable.
Retries
Only retry when operations are idempotent or staged. For non-idempotent steps, design a compensating action or lock to prevent duplicates.
Monitoring
Monitor rows processed, run duration, and failure rates. Alert on unusually long runs or repeated failures.
Common mistake

Swallowing exceptions to avoid alerts hides failures and causes silent data quality issues.
