ACLs, Port Security, DHCP Snooping & DAI

This lesson shows the commands, placement rules, and practical checks you'll use to harden a small office LAN. We'll include router and switch configuration templates and a hands-on scenario you can reproduce in Packet Tracer.

Security Layers
Router • ACLs
Filter by IP, port, protocol. Extended ACLs give fine control per service.
Switch • Port Security
Limit MACs, use sticky learning, choose violation mode: shutdown, restrict, protect.
LAN Protection
DHCP snooping builds bindings; DAI validates ARP using that table.

ACLs
Rules that permit or deny traffic. We'll build an Extended ACL that permits only HTTP/HTTPS to a server and denies other IP to that host.
Port Security
Limit MAC addresses on access ports and use sticky learning to persist learned addresses. We'll configure shutdown on violation for a server port.
DHCP Snooping & DAI
Enable snooping on the VLAN, mark server port as trusted, then enable Dynamic ARP Inspection to validate ARP against the binding table.
