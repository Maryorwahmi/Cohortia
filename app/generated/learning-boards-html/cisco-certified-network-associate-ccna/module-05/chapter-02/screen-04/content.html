Module 5 › Chapter 5.2 › What is an ACL?
Definition & Behavior
  • ACLs evaluate packets sequentially; first match wins.
  • Implicit deny at the end: unmatched packets are dropped.
  • Standard ACLs filter by source IP only; Extended filter by many fields.
Analogy
Think of an ACL as a checklist read top to bottom; once a rule applies, processing stops.
Concrete Example
Router(config)# access-list 101 permit tcp 192.168.1.0 0.0.0.255 host 10.0.0.10 eq 80
Router(config)# access-list 101 permit tcp 192.168.1.0 0.0.0.255 host 10.0.0.10 eq 443
Router(config)# access-list 101 deny ip 192.168.1.0 0.0.0.255 host 10.0.0.10
Router(config)# access-list 101 permit ip any any
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip access-group 101 in
Key Takeaway

Always include necessary permit statements before implicit deny, and test ACLs in a lab before production.
