Sticky Learning Explained
Dynamically learns MACs and writes them to the running configuration. Save to startup if persistence across reloads is required.
  • Good for stable server ports.
  • Combine with maximum to limit allowed devices.
  • Verify with show port-security address.
Test procedure
  1. Configure port-security maximum 1 and mac-address sticky.
  2. Connect authorized device and save learned MAC if needed.
  3. Connect a second device to trigger violation and observe behavior.
  4. Run show port-security interface to inspect counters and state.
Key Takeaway

Practical testing is the fastest way to confirm port-security behaves as intended for your chosen violation mode.
