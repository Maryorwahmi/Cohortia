Module 5 › Chapter 5.2 › Dynamic ARP Inspection
What DAI does
  • Inspects ARP requests and replies on untrusted ports.
  • Validates IP-to-MAC against DHCP snooping or static bindings.
  • Drops packets with mismatched or missing bindings.
Configuration Example
Switch(config)# ip arp inspection vlan 1
Switch(config)# interface FastEthernet0/24
Switch(config-if)# ip arp inspection trust
Important Note

Enable DHCP snooping before DAI. Static IP hosts require static bindings to avoid DAI drops.
