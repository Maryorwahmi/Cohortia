Module 5 › Chapter 5.2 › What to Remember
Explicit permits
Always include necessary permit statements to avoid implicit deny surprises.
Sticky MACs
Use sticky learning on server ports to persist allowed MACs in the running config.
Snooping before DAI
Enable DHCP snooping and trust the server port before enabling DAI to ensure ARP validation works.
Closing thought

Security is layered: combine ACLs, port security, DHCP snooping, and DAI and verify each layer with lab tests and show commands.
