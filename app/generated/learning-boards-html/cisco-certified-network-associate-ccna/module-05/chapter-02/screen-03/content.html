ACL Application & Verification

Apply an Extended ACL, test with HTTP and a denied service, and add a final permit ip any any when appropriate to avoid implicit deny surprises.

VERIFIED COMPETENCY MILESTONE
ACL Placement Rules

Remember placement: Extended close to source, Standard close to destination. This reduces unnecessary traversal of unwanted traffic or accidental blocking.

VERIFIED COMPETENCY MILESTONE
Port Security & Violation Modes

Configure sticky MACs and shutdown on violation for a critical server port. Verify the port becomes error-disabled when a second MAC appears.

VERIFIED COMPETENCY MILESTONE
DHCP Snooping & DAI Testing

Enable snooping on the VLAN, trust the DHCP server port, enable DAI, and then test a rogue DHCP server or forged ARP to confirm protection is active.
