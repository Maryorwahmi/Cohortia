Module 5 › Chapter 5.2 › Key Concepts
ACL & Implicit Deny
ACLs are ordered filters; unmatched traffic is denied unless explicitly permitted.
Standard vs Extended
Standard filters by source; Extended filters by source, destination, protocol, and ports.
Port Security
Limit MACs, use sticky learning, and pick violation mode: shutdown, restrict, protect.
DHCP Snooping
Trust the DHCP server port; snooping builds the binding table used for validation.
Dynamic ARP Inspection
Validates ARP using the DHCP snooping binding table to prevent ARP spoofing.
Verification
Use show access-lists, show ip interface, show port-security, and show ip dhcp snooping binding when troubleshooting.
Final Takeaway

Layer these controls: ACLs for traffic flow, port security for device control, DHCP snooping and DAI for identity and ARP protection.
