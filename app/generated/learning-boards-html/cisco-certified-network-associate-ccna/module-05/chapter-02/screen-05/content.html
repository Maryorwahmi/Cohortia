Module 5 › Chapter 5.2 › Standard vs Extended
Standard ACL
Filters only on source IP. Use when you need broad source-based access control. Best placed close to the destination to avoid blocking legitimate traffic to other hosts.
  • Number ranges: 1-99, 1300-1999.
  • Simple rules, low overhead.
  • Misuse: cannot filter by service or destination port.
Extended ACL
Filters source, destination, protocol, and ports. Use for service-specific controls like permitting only web traffic to a host. Place near the traffic source to stop unwanted traffic early.
  • Number ranges: 100-199, 2000-2699.
  • High granularity for service-level filtering.
  • Remember to include permits to avoid implicit deny blocking other traffic.
Example Scenario
! Allow only HTTP/HTTPS from 192.168.1.0/24 to 10.0.0.10
access-list 101 permit tcp 192.168.1.0 0.0.0.255 host 10.0.0.10 eq 80
access-list 101 permit tcp 192.168.1.0 0.0.0.255 host 10.0.0.10 eq 443
access-list 101 deny ip 192.168.1.0 0.0.0.255 host 10.0.0.10
access-list 101 permit ip any any
