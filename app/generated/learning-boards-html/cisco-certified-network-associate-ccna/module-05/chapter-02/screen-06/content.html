Module 5 › Chapter 5.2 › Applying an Extended ACL
Step-by-step
  1. Create access-list statements that explicitly permit required services.
  2. Include necessary deny statements for targeted blocks.
  3. Add a final permit ip any any when you need other traffic allowed.
  4. Apply with ip access-group on the correct interface and direction.
  5. Verify using show access-lists and show ip interface.
Code Walkthrough
R1(config)# access-list 101 permit tcp 192.168.1.0 0.0.0.255 host 203.0.113.50 eq 80
R1(config)# access-list 101 permit tcp 192.168.1.0 0.0.0.255 host 203.0.113.50 eq 443
R1(config)# access-list 101 deny ip 192.168.1.0 0.0.0.255 host 203.0.113.50
R1(config)# access-list 101 permit ip any any
R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip access-group 101 out
! Verify hits and bindings:
R1# show access-lists
R1# show ip interface GigabitEthernet0/1
Common Mistake

Forget the final permit ip any any or bind the ACL in the wrong direction and you will block more than intended.
