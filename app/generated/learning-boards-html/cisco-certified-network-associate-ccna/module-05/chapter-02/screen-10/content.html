Module 5 › Chapter 5.2 › DHCP Binding Table
Contents of the binding
  • MAC address, IP address, VLAN, lease time.
  • Updated when DHCP transactions occur on trusted/untrusted ports.
  • View with show ip dhcp snooping binding.
How other features use it
Dynamic ARP Inspection consults this binding table to accept or drop ARP messages. If the table has no matching entry, DAI may drop the ARP unless a static entry exists.
Troubleshooting Tip

If DAI drops legitimate ARP, check the dhcp snooping binding table and whether the host used a static IP. Add a static binding if necessary.
