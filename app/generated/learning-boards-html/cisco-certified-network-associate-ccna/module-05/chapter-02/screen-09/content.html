Module 5 › Chapter 5.2 › DHCP Snooping
How it works
  • Classify ports as trusted or untrusted.
  • Inspect DHCP messages from untrusted ports; drop illegitimate replies.
  • Build a binding table: MAC ↔ IP ↔ VLAN ↔ lease.
Practical note
DHCP snooping must be enabled before DAI to supply valid bindings for ARP validation.
Configuration Example
Switch(config)# ip dhcp snooping
Switch(config)# ip dhcp snooping vlan 1
Switch(config)# interface FastEthernet0/24
Switch(config-if)# ip dhcp snooping trust
Common Pitfall

Forgetting to set the DHCP server port as trusted will block legitimate DHCP replies.
