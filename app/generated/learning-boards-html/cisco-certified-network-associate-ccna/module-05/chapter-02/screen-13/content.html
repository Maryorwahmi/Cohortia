Module 5 › Chapter 5.2 › Troubleshooting & Mistakes
ACL Errors
  • Implicit deny blocks unintended traffic when missing permits.
  • Wrong ACL placement or direction causes unexpected allows/blocks.
  • Wildcard mask mistakes can widen or narrow matches incorrectly.
Port-security & Snooping Mistakes
  • Forgetting to mark DHCP server ports as trusted blocks DHCP replies.
  • Not saving sticky MACs causes loss after reload.
  • Failing to add static bindings for static IP hosts breaks DAI validation.
Quick Checks

Run show access-lists, show ip interface, show port-security, and show ip dhcp snooping binding when troubleshooting.
