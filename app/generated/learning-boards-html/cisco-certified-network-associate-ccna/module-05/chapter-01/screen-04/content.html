Common Network Threats
Malware, social engineering, DoS — know how each behaves.
Malware types
  • Virus — attaches to legitimate programs and needs user action.
  • Worm — self-replicates across networks exploiting vulnerabilities.
  • Trojan — disguises malicious code as benign software.
  • Ransomware — encrypts data and demands payment for release.
  • Spyware — monitors activity covertly.
Social engineering
Phishing, pretexting, and baiting exploit human trust. They succeed where users lack awareness or verification steps.
DoS and DDoS
Attacks that overwhelm resources and make services unavailable to legitimate users.
Key Takeaway

Treat technical and human threats together. Each threat type needs a matching mix of controls and processes.

Concrete example
A phishing email tricks an employee into revealing credentials. The attacker uses those credentials to deploy ransomware and encrypt the file server.
Mitigations for this example
  • Enable multifactor authentication to reduce credential misuse.
  • Run endpoint detection and regular offline backups to recover data.
  • Provide security awareness training to reduce phishing success.
Common misconception
Relying solely on a firewall is insufficient. Human-targeted attacks often bypass perimeter controls without training and layered defenses.
Check your understanding
Which control stops a worm from spreading: patching, user training, or acceptable use policy? (Primary answer: patching and secure configuration.)
