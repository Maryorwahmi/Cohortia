Vulnerabilities and Common Mistakes
Find weak points before attackers do.
Unpatched software
Known bugs are often exploited by worms and other malware.
Misconfiguration
Default credentials or incorrect ACLs open easy access paths.
Human error
Accidental data exposure and risky behavior are common sources of vulnerability.
Concrete example
An unpatched OS on a public server is a high-priority vulnerability because it can be scanned and exploited remotely. Patching and hardening reduce the attack surface quickly.
Misconception
Believing that one administrative change eliminates risk. Regular audits and layered measures are needed to maintain security over time.
Key Takeaway

Prioritize fixes for vulnerabilities that are publicly known or easy to exploit, and combine technical fixes with configuration standards and training.
