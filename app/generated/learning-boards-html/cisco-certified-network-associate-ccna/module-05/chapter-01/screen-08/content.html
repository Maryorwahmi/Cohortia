Confidentiality Controls
Encryption, access control, and secure storage form the technical core.
Encryption
Protect data in transit and at rest to prevent unauthorized reading.
Access control
Use role-based access and least privilege so only authorized users see sensitive information.
Secure storage
Use managed storage, limit local copies, and apply strict permissions.
Concrete scenario
A financial report is accidentally emailed externally. If the report was encrypted and access-limited, exposure is reduced and remediation focuses on revoking access and reviewing logs.
Misconception
Encryption without key management leaves data inaccessible to authorized users or vulnerable if keys are stored insecurely.
Key Takeaway

Combine encryption with strong access controls and clear policy to prevent accidental or unauthorized disclosures.
