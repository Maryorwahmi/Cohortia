The CIA Triad
Apply this lens to every security decision.
Confidentiality
Limit access and encrypt data to prevent unauthorized disclosure.
Integrity
Use hashing and signatures to detect unauthorized changes.
Availability
Ensure services and data are reachable with redundancy and recovery plans.
Concrete example
A public web portal needs high availability to serve customers; use redundancy and DoS protection. Sensitive internal payroll files emphasize confidentiality and strong access controls.
Key Takeaway

Map threats to the CIA property most affected, then select controls that restore that property while minimizing negative trade-offs.

Common misconception
Assuming a single control secures all three properties. Effective security balances controls across the triad based on risk.
