Module 05 › Chapter 5.3 › Site-to-Site vs Remote Access VPNs
Side-by-side comparison
Site-to-Site
Always-on between network edges. Best for branch-to-headquarters connections. Tunnel conceals entire subnet traffic.
Remote Access
User-initiated connections from clients. Best for teleworkers and mobile access. Often uses client software or SSL portals.
Scale & Management
Site-to-site scales as networks; remote access needs user credential management and client updates.
Addressing
Site-to-site typically tunnels subnets. Remote access assigns client IPs or uses split tunneling rules.
Scenario card
Branch office with on-prem servers should use site-to-site VPN in tunnel mode so all server-to-server traffic is protected automatically.
Common mistake
Using remote access for many machines at a remote site increases client management and reduces consistent routing. Site-to-site simplifies routing and scales better for whole-network connectivity.
