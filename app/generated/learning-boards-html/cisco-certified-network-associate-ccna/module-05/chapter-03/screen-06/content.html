Module 05 › Chapter 5.3 › IPsec framework: Phase 1 & Phase 2
Phase overview
Phase 1 — IKE
Authenticate peers and establish an IKE SA. Negotiate authentication, encryption, hash, DH group, lifetime.
Phase 2 — IPsec SA
Use the IKE SA to negotiate IPsec parameters (AH/ESP, encryption, hash) to protect user data.
Modes
Main Mode: stronger identity protection. Aggressive Mode: fewer packets but less identity privacy. Phase 2 commonly uses quick mode exchanges protected by IKE SA.
Process cards
1. Peers exchange IKE proposals and authenticate.
2. IKE SA established (Phase 1).
3. Peers negotiate transform set and protocols for data (Phase 2).
4. IPsec SA installed and traffic encrypted per ACL.
Concrete example
Phase 1: IKE SA negotiated with AES-256, SHA, DH group 5
Phase 2: IPsec SA negotiated using ESP with AES-256 and SHA for data
