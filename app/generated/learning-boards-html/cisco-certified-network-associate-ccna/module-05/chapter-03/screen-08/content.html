Module 05 › Chapter 5.3 › Transport Mode vs Tunnel Mode
Transport Mode
Encrypts or authenticates only the payload; original IP header intact. Best for host-to-host security when endpoints can be addressed directly.
Use case: End-to-end application protection between two hosts.
Limitation: does not hide original IP header, so less suited for network-to-network encapsulation.
Tunnel Mode
Encapsulates the entire original IP packet and adds a new IP header. Default for site-to-site VPNs and convenient for subnet-to-subnet connections.
Use case: Branch-to-HQ tunnels carrying many internal addresses.
Advantage: hides internal addressing and works well with NAT on outer header.
Key takeaway: choose tunnel mode to protect whole packets between networks and transport mode for host-level payload protection.
