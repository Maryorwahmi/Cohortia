Module 05 › Chapter 5.3 › Common mistakes & verification
Typical failure points
  • Mismatched transform sets (algorithms or modes).
  • Incorrect pre-shared key or certificate setup.
  • ACL not matching traffic or mis-scoped wildcard masks.
  • Crypto map not applied to the public interface.
Verification commands
show crypto isakmp sa — checks Phase 1 state
show crypto ipsec sa — checks Phase 2 SAs and counters
Guided debugging steps
  1. Ping the peer to verify basic reachability.
  2. Confirm Phase 1 with show crypto isakmp sa.
  3. If Phase 1 is OK, verify transform sets and run show crypto ipsec sa.
  4. Check ACLs and apply test traffic while monitoring counters.
Tip: Use debug logs in controlled environments and compare both peer configurations side-by-side for exact matches.
