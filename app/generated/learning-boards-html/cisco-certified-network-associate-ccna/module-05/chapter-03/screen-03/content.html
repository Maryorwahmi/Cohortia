Module 05 › Chapter 5.3 › Learning Objectives
Practice goals
Translate configuration steps into checks and verification commands so you can spot and resolve mismatches.
Configure
ISAKMP policy, pre-shared key, transform set, ACL, crypto map, apply to interface.
Validate
Use show crypto isakmp sa and show crypto ipsec sa to confirm negotiation and byte counts.
Troubleshoot
Fix mismatched transforms, wrong ACLs, incorrect peer IP, and weak pre-shared keys.
Security
Prefer strong encryption and certificates in production; avoid weak pre-shared keys.
Quick checklist
  • Match transform-set exactly on both peers.
  • Ensure ACLs correctly define interesting traffic.
  • Confirm peer IPs and pre-shared keys are correct.
  • Run show commands to verify active SAs and counters.
