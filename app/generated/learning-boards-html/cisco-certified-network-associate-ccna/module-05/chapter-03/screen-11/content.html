ACLs define interesting traffic
An extended ACL used by a crypto map selects which traffic should be sent through the IPsec tunnel. Use network and wildcard masks to precisely match subnets.
Example ACL
access-list 101 permit ip 192.168.10.0 0.0.0.255 192.168.20.0 0.0.0.255
Validation
Generate test traffic and confirm show crypto ipsec sa counters increment. If counters don't change, re-check ACL masks and crypto map association.
Common scoping errors
  • Using host addresses when you intended subnets or vice versa.
  • Incorrect wildcard masks leading to no matches.
  • Applying crypto map to wrong interface so traffic never matches.
Check
Remember: crypto ACLs are for selecting traffic to encrypt, not for allowing or denying packets at the interface level.
