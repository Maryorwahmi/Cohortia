 set peer 203.0.113.2
 set transform-set MyTransformSet
 match address 101

Guidance
  • Prefer AES and SHA where available for stronger protection.
  • Choose a DH group that balances security and CPU for your devices.
  • Never use weak or easily guessed pre-shared keys in production.
  • Ensure both peers use the exact same transform-set and ACLs.
