VPN definition and goals

A VPN secures traffic across an untrusted network by encrypting packets and authenticating peers to achieve confidentiality, integrity, and authentication.

Confidentiality
Encryption prevents eavesdroppers from reading sensitive payloads in transit.
Integrity
Hashing detects if packets were altered between sender and receiver.
Authentication
Peers verify identities using pre-shared keys or certificates.
Concrete example
A remote engineer connects with a VPN client to reach an internal file server. The tunnel encrypts traffic across the internet so credentials and files remain private.
Common misconceptions
  • VPNs protect traffic in transit, not the device. Endpoint security is still needed.
  • Not every VPN uses the same protocols or provides the same protections; choose based on use case.
  • Encryption adds overhead; plan bandwidth and CPU for routers and firewalls accordingly.
Key takeaway
A VPN secures data in motion and is chosen to match scale and access needs; combine it with endpoint controls for full protection.
