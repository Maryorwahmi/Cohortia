Module 05 › Chapter 5.3 › Crypto Map and Transform Set
Transform set
Defines the IPsec protocols and algorithms: choose between AH or ESP and set encryption and hashing algorithms that will be used in Phase 2.
Example
crypto ipsec transform-set MyTransformSet esp-aes 256 esp-sha-hmac mode tunnel
Crypto map
Associates peer, transform set and ACL. Applied to an interface so that matching traffic is encrypted toward the specified peer.
crypto map MyCryptoMap 10 ipsec-isakmp
set peer 203.0.113.2
set transform-set MyTransformSet
match address 101
Practical checks
  • Transform set algorithms must match on both peers.
  • Crypto map must reference the correct transform set and ACL.
  • Crypto map must be applied to the external interface that faces the peer.
Common mistake
Defining a transform set but not including it in any crypto map prevents the router from using it to protect traffic.
