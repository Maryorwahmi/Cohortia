Module 05 › Chapter 5.3 › Key Concepts — Part 1
Virtual Private Network
A secure encrypted connection across an untrusted network to protect traffic.
Site-to-Site VPN
Connects two entire networks; tunnel is typically always active.
Remote Access VPN
Individual client-initiated connections for remote users to access internal resources.
Summary

Memorize these three concepts to decide which VPN type suits a scenario and understand the role of IPsec phases.
