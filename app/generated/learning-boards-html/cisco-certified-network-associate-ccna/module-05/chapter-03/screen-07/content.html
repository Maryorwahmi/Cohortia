Module 05 › Chapter 5.3 › AH vs ESP
Authentication Header (AH)
Provides integrity and origin authentication but does not encrypt payload. AH includes a hash of parts of the packet to detect tampering.
Pros: Simple integrity and origin protection.
Cons: No confidentiality; can break with NAT or mutable IP header fields.
Encapsulating Security Payload (ESP)
Provides encryption for confidentiality plus integrity and optional authentication. ESP commonly used for VPN tunnels where privacy is required.
Pros: Encryption + integrity; works with most NAT scenarios using traversal techniques.
Cons: Requires proper keying and matching transform sets on both ends.
Analogy
AH is like a tamper-evident seal; ESP is a locked box with a tamper-evident seal on the outside.
