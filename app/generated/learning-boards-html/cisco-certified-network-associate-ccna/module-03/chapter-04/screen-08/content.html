Link-State Advertisements (LSAs)

LSAs describe a router's directly connected links and are flooded to build a consistent LSDB across the area.

Example event

When a link goes down the originating router issues an updated LSA. Peers flood it so everyone updates their database and recalculates routes.

LSDB and Dijkstra

The Link-State Database is the synchronized map. Each router runs Dijkstra to compute shortest paths from that map.

Key Takeaway

OSPF's design leads to consistent topology knowledge and fast, loop-free path computation when areas are used correctly.

Misconception

LSAs are not individual route advertisements; they describe link topology so routers compute routes locally from the full map.
