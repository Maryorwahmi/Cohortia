Module 4 › Chapter 3.4 › Dynamic Routing

Core definition

Dynamic routing protocols enable routers to automatically learn about remote networks and adapt to topology changes. They exchange routing information to build routing tables without manual edits.

Concrete example

When a new subnet is added to a branch, the router advertises it via the routing protocol and all peers learn the route automatically.

Misconception

Dynamic routing is not instant; convergence is protocol-dependent and may require timers and recalculation.

Key Takeaway

Dynamic routing automates adaptation and reduces manual work, but needs resource planning and correct design to avoid problems.

Protocol categories
  • IGPs: RIP, EIGRP, OSPF — used inside an AS.
  • EGPs: BGP — used between ASes.
Think about which category fits your network: internal routing uses IGPs; connecting to other organizations uses EGPs like BGP.
