Module 4 › Chapter 3.4 › Verification
Step 1
show ip protocols

Confirm OSPF process ID, router-id, and networks advertised via wildcard masks.

Step 2
show ip ospf neighbor

Verify neighbor state is FULL and that the interface matches expected network statements.

Step 3
show ip route

Confirm learned routes appear with the 'O' marker and forwardability to remote networks is present.

Common pitfall

A running OSPF process alone does not guarantee neighbors. Ensure network statements and area IDs correctly reference the interfaces you expect to participate.
