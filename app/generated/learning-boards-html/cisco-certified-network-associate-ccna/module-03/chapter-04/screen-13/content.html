Module 4 › Chapter 3.4 › Troubleshooting

Quick checklist

  • Verify IP addresses on the directly connected link.
  • Confirm area IDs match on both routers.
  • Check network statements and wildcard masks include the intended interfaces.
  • Ensure Hello packets are not blocked by ACLs or passive-interface settings.

Inspector tools

Key commands

show ip ospf neighbor — see neighbor states; show ip protocols — see enabled routing processes; show ip route — verify learned routes.

Misconception

OSPF will not form neighbors across non-directly-connected networks; tight Hello/Dead and interface conditions must be met on the local segment.

Key Takeaway

Work methodically: IP reachability, matching OSPF parameters, and correct wildcard usage usually resolve neighbor formation issues.
