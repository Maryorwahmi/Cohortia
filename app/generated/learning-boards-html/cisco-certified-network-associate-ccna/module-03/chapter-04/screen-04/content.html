Module 4 › Chapter 3.4 › Static vs Dynamic
Comparison

Static routing

Manual routes configured per destination. Predictable, minimal CPU, but does not adapt to topology changes.

When to use

Small networks, default gateways, backup paths, or when complete control is required.

Misconception

Static routing is always simpler — it is simpler to configure, but harder to maintain at scale.

Key Takeaway

Static routes are deterministic; dynamic protocols handle growth and failures automatically.

Comparison

Dynamic routing

Protocols let routers exchange information and learn routes automatically. They scale and adapt to link changes.

Advantages
  • Scalability for many networks.
  • Automatic rerouting after failures.
  • Reduced manual configuration.
Tradeoffs

Higher CPU/memory use and need for careful protocol design to avoid loops and suboptimal paths.

Concrete example

A campus network using OSPF will automatically re-route traffic after a link failure, whereas static routes would need manual updates.
