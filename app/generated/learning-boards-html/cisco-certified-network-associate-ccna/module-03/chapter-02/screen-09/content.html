Module 3 › Chapter 3.2 › VLSM allocation example
Example: reserve /22 then /26 and /30
Step 1 — Data center
Requirement: ~1000 hosts → choose /22 (1022 usable). Allocate: 10.0.0.0/22 → range 10.0.0.0–10.0.3.255.
Step 2 — Branch
Requirement: 50 hosts → choose /26 (62 usable). Next available after /22 is 10.0.4.0 → assign 10.0.4.0/26.
Step 3 — Links
Point‑to‑point links use /30 (2 usable). Allocate sequential /30 blocks starting from next available address and increment by 4 addresses per link.
Verification
After every allocation compute broadcast = start + block size − 1 and set next available = broadcast + 1 before continuing.
