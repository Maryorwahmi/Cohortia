Definition

How to get exact ranges

Use block size arithmetic to locate the network and broadcast addresses, then list usable hosts between them.

Rule of thumb
  • Compute block size = 2^(32 − mask).
  • Network = block start; Broadcast = block end (start + block size − 1).
  • Usable = addresses between network+1 and broadcast−1.
Concrete example
192.168.1.64/26
Block size = 64 → Range: 192.168.1.64 – 192.168.1.127
Network: 192.168.1.64
First usable: 192.168.1.65
Last usable: 192.168.1.126
Broadcast: 192.168.1.127
Pro Tip

Track block arithmetic across octets rather than trying to guess boundaries by eye; add the block size numerically.
