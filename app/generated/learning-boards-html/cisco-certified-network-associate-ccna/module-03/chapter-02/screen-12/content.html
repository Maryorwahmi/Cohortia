Module 3 › Chapter 3.2 › Choosing CIDR for 70 hosts
Method
Find smallest h where 2^h − 2 ≥ 70, then mask = 32 − h.
h = 6 → 2^6 − 2 = 64 − 2 = 62 (too small)
h = 7 → 2^7 − 2 = 128 − 2 = 126 (sufficient)
mask = 32 − 7 = /25
Conclusion
/25 provides 126 usable hosts, meeting the 70‑host requirement with minimal waste. /24 is overkill; /26 or /27 are too small.
Key Takeaway

Always compute usable hosts from host bits to choose the smallest sufficient CIDR.
