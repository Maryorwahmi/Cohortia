Variable Length Subnet Masking

Allocate differently sized subnets to fit actual host needs and reduce wasted addresses.

Why use VLSM?
  • Minimizes wasted addresses.
  • Supports mixed requirements in a single major block.
  • Scales designs more efficiently than uniform masks.
Example allocation plan
10.0.0.0/8 → /22 for data center (~1022 hosts), /26 for branch (~62 hosts), /30 for point‑to‑point links (2 hosts each).
VLSM steps
  1. Identify largest host requirement.
  2. Choose smallest mask that fits that requirement.
  3. Allocate that block from the major network.
  4. Repeat with next largest requirement from next available address.
