Module 3 › Chapter 3.2 › Common subnetting mistakes
Comparison: mistakes vs checks
Frequent mistakes
  • Miscount borrowed bits or host bits.
  • Wrong broadcast or network assignment.
  • Overlapping subnets due to poor tracking.
Verification checks
  • Recompute block size from mask.
  • Calculate broadcast as start + block size − 1.
  • Add block size to find next network and confirm contiguity.
Scenario
Non-standard mask confusion
Non‑byte aligned masks still use the same arithmetic; convert mask to host bits explicitly.
Fix
Use numerical addition
Add block sizes to previous network numerically rather than estimating octet boundaries.
Check
Run a verification checklist
Mask → hosts → block size → boundaries → next network.
