Core Concept

Key formulas

Memorize these steps to convert CIDR masks into usable address counts and block sizes.

Block size
2^(32 − CIDR mask) = total addresses in the block
Usable hosts
2^host_bits − 2 (subtract network and broadcast)
Number of subnets
2^n where n is the number of bits borrowed from host portion
Worked example
/24 original:
  Host bits = 8
  Block size = 2^8 = 256 addresses
  Usable hosts = 256 − 2 = 254
Borrow 2 bits → /26:
  New mask = /26
  Block size = 2^(32−26) = 64 addresses
  Usable hosts = 64 − 2 = 62
Subnets created: 2^2 = 4 subnets
Key Takeaway

Follow mask → host bits → block size → usable hosts in order to avoid errors.
