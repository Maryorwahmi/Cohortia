Learning Objectives

Skills to practice

Build practical competence: calculate, allocate, design, and verify IPv4 subnets.

Bloom: Learn → Understand → Apply → Master
01
Perform subnet calculations
Use 2^n and 2^h − 2 to compute number of subnets and usable hosts, then verify ranges to avoid conflicts.
VERIFIED COMPETENCY MILESTONE
02
Apply VLSM
Allocate different masks inside a major network by starting from the largest host need and working down.
VERIFIED COMPETENCY MILESTONE
03
Design subnet schemes
Produce a contiguous allocation plan that meets departmental host counts and keeps blocks non‑overlapping.
VERIFIED COMPETENCY MILESTONE
04
Troubleshoot errors
Identify common mistakes such as wrong host counts, wrong broadcast calculation, or overlapping allocations and correct them.
VERIFIED COMPETENCY MILESTONE
