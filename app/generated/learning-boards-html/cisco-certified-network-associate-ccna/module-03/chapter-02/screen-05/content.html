Process Flow

Divide a /24 into four /26 subnets

Follow a concrete sequence to avoid miscounting and overlapping ranges.

  1. Decide number of subnets → 4 required.
  2. Find borrowed bits n where 2^n = 4 → n = 2.
  3. New mask = original mask + n → /24 + 2 = /26.
  4. Block size = 2^(32 − 26) = 64 addresses.
  5. List subnets at increments of 64: .0, .64, .128, .192.

Common Mistake

Counting the increment incorrectly. Always add block size to the previous network address to get the next network boundary.
