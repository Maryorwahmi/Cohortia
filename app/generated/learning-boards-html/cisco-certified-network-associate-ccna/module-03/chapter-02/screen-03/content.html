Checkpoint
Compute block sizes and usable hosts
Use 2^(32 − mask) for total addresses and 2^h − 2 for usable hosts, then confirm bits borrowed for subnets.
Checkpoint
Select smallest fitting CIDR
Always pick the mask that just meets host requirements to limit waste in VLSM designs.
Checkpoint
Use /30 for point-to-point links
A /30 provides two usable addresses, perfect for router‑to‑router links and resource efficiency.
Checkpoint
Allocate contiguously and verify
After each allocation compute the next available network so subnets do not overlap and remain contiguous.
