Module 3 › Chapter 3.2 › Key Concepts
Subnetting
Divide a larger network into smaller subnets to control broadcast domains and apply policies.
VLSM
Assign different masks within a major network so each subnet fits its host need.
Block Size
Total addresses in a block = 2^(32 − CIDR). Use this to compute ranges and increments.
Summary takeaway
Plan from largest to smallest, compute each block exactly, and verify network and broadcast to avoid overlaps and conserve addresses.
