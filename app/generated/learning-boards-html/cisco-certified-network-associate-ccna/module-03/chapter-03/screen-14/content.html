Module 3 › Chapter 3.3 › Key Concepts
Router
Layer 3 device that forwards IP packets between networks.
Routing Table
Database of known networks and the best path to reach them.
Administrative Distance
Numeric trust value used to choose between multiple routing sources.
Summary Takeaway
Understand how routes enter the table, verify next-hop reachability, and use administrative distance to reason about which route the router will install.
