Core Concept

How the routing table guides forwarding

Entries include destination network, mask, source, and next hop or interface. Matching uses longest-prefix selection.

Lookup process
Router checks destination, finds the most specific prefix, then forwards out associated interface or to next hop.
What show ip route shows
  • Route codes (C, S, *)
  • Network prefixes and masks
  • Next-hop IP or exit interface
Example output snippet
Router# show ip route
C 192.168.1.0/24 is directly connected, GigabitEthernet0/1
S 192.168.2.0/24 [1/0] via 10.0.0.2
* 0.0.0.0/0 is directly connected, GigabitEthernet0/2
Misconception

The routing table lists networks, not individual host addresses. ARP and local delivery resolve individual hosts on a known network.
