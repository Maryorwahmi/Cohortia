Core Concept

Static routes: control and responsibility

Manually configured routes that point to a next hop or exit interface.

Use cases
Small networks, static links, backup or administrative control over specific paths.
Common mistakes
Wrong next-hop IP, incorrect mask, or specifying an exit interface that cannot reach the next hop.
CLI example
Router(config)# ip route 10.0.0.0 255.255.255.0 192.168.1.2

# Example: route to 10.0.0.0/24 via next hop 192.168.1.2
Pro tip

Ping the next-hop address from the router before adding the static route. If you cannot reach the next hop, the route will not forward traffic correctly.
