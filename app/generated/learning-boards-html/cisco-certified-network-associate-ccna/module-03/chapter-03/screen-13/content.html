Process

Step-by-step troubleshooting

Follow these checks in order to isolate routing issues quickly and avoid unnecessary changes.
1. Check interfaces
show ip interface brief — look for up/up and correct IP/mask.
2. Ping next hop
If ping fails, the static route cannot function; fix connectivity first.
3. Inspect routing table
show ip route — confirm correct codes and next hop/interface.
Scenario card
Problem: R1 cannot ping 192.168.2.1. Checklist: show ip interface brief on both routers, ping 10.0.0.2 from R1, verify the static route entry on R1, and confirm R2 has a route back to 192.168.1.0.
Common mistake

Configuring a static route with an unreachable next hop creates a black hole. Verify next-hop reachability first.
