Module 3 › Chapter 3.3 › What is a Router?
Definition

Router — Layer 3 forwarding

A device that forwards IP packets between distinct IP networks by choosing an exit interface or next hop.

Analogy
Traffic cop directing cars along roads; roads are IP networks, intersections are routers.
Key properties
  • Operates at OSI Layer 3 using IP addresses.
  • Each interface belongs to a different IP network.
  • Makes forwarding decisions from the routing table.
Common misconception
Switches do not route between networks; they forward frames within the same network using MAC addresses.
Concrete example
Consider a router with two interfaces:
  • Gig0/0 → 192.168.1.1/24 (LAN A)
  • Gig0/1 → 10.0.0.1/24 (LAN B)
If Host A (192.168.1.10) pings Host B (10.0.0.20), the router receives the packet, looks up 10.0.0.0/24, finds the directly connected route for Gig0/1, and forwards the packet out that interface.
Key Takeaway

Routers enable communication between different IP networks by forwarding packets based on destination IP and the routing table.
