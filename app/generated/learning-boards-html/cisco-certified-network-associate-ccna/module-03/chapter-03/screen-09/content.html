Topology overview

Two routers connected by a point-to-point link; each router has a LAN. Configure static routes and a default route.

Device addressing
  • R1 Gi0/0: 10.0.0.1/30 (to R2)
  • R1 Gi0/1: 192.168.1.1/24 (LAN A)
  • R2 Gi0/0: 10.0.0.2/30 (to R1)
  • R2 Gi0/1: 192.168.2.1/24 (LAN B)
  • R2 Gi0/2: 203.0.113.1/29 (Internet)
Goals
Add static route on R1 for LAN B, default route on R1 to R2 for internet, and static route on R2 for LAN A.
Verification checklist
  • show ip interface brief — confirm IPs and up/up
  • show ip route — confirm connected, static, and default entries
  • ping remote LAN interface and internet address for reachability
Key Takeaway

Follow the checklist: interface config, enable links, add routes, then verify. Missing any step breaks reachability.
