Module 3 › Chapter 3.3 › Default Routes
Core Concept

Default route: gateway of last resort

Used when no specific route matches the destination; points to a next hop for unknown traffic.

Typical use
Branches send all Internet-bound or unknown traffic to a central router or ISP via the default route.
Behavior note
A more specific route will override a default route. Default only applies if no specific match exists.
CLI example
Router(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1

# Sends all unknown destinations to next hop 203.0.113.1
Key Takeaway

Default routes handle unknown destinations but never override more specific network entries.
