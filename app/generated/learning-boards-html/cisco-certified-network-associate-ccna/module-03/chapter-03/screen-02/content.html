Learning Objectives

These skills prepare you to configure basic routing and reason about route choices.

01
Explain the router’s role
Describe Layer 3 forwarding and why routers are required to connect separate IP networks.
Mnemonic: traffic cop directing packets across roads.
VERIFIED COMPETENCY MILESTONE
02
Describe the routing table
Explain entries, next-hop, exit interface, and how lookup selects a route.
Visual mnemonic: routing table as a GPS list of destinations.
VERIFIED COMPETENCY MILESTONE
03
Differentiate route types
Directly connected, static, and default routes and when to use each.
Mnemonic: local, manual, and gateway-of-last-resort.
VERIFIED COMPETENCY MILESTONE
04
Configure routes in IOS
Use ip route commands to add static and default routes and verify them.
Mnemonic: add route, verify with show ip route.
VERIFIED COMPETENCY MILESTONE

Assessment hint
