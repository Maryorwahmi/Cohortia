Core Concept

Directly connected routes

Interfaces create connected routes automatically when configured and enabled.

Check list
  • IP address and subnet mask assigned
  • Interface is not administratively down
  • Correct network mask so router derives intended network
Misconfiguration to avoid
An interface with a wrong mask or that is shutdown will not produce a connected route, causing the router to lack knowledge of that network.
Example commands
Router(config)# interface GigabitEthernet0/1
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# exit

Router# show ip route
C 192.168.1.0/24 is directly connected, GigabitEthernet0/1
Key Takeaway

Connected interfaces are the most trusted source of routing information; confirm interface state before adding routes.
