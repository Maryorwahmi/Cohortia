Practice & Verification

These objectives guide the hands-on lab and troubleshooting checks.

05
Understand administrative distance
Explain route preference when multiple sources provide the same network.
Mnemonic: lower number means more trusted.
VERIFIED COMPETENCY MILESTONE
06
Identify common misconfigurations
Recognize wrong next hops, incorrect masks, and disconnected exit interfaces.
Mnemonic: check connectivity to the next hop first.
VERIFIED COMPETENCY MILESTONE
07
Use show ip route
Interpret codes like C, S and the default marker to verify routing state.
Mnemonic: read the source column to know how the route was learned.
VERIFIED COMPETENCY MILESTONE
08
Plan basic static routing
Design minimal static routes so two LANs communicate through two routers.
Mnemonic: each router must know where the remote LAN lives.
VERIFIED COMPETENCY MILESTONE
Practical tip
When troubleshooting, always verify the interface IP configuration and basic connectivity to the next-hop before changing routes. This prevents creating unreachable paths or traffic black holes.
