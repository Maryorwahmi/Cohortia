Check interfaces
Use show ip interface brief to confirm IPs and up/up state.
Ping next hop
A static route depends on the next hop being reachable from the router.
Default is fallback
0.0.0.0/0 is used only when no more specific route exists.
Final Thought
Explain each route’s origin before you change it. That habit prevents many routing errors and keeps networks reliable.
