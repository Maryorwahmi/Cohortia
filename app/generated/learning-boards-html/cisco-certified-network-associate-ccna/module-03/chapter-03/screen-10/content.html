Module 3 › Chapter 3.3 › R1 Configuration
Step-by-step CLI
R1> enable
R1# configure terminal
R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 10.0.0.1 255.255.255.252
R1(config-if)# no shutdown
R1(config-if)# exit
R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

# Static route to LAN B via R2
R1(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

# Default route to R2 for internet
R1(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2
R1(config)# end
R1# show ip route
Example verification
After configuration, show ip route should show:
C 192.168.1.0/24 is directly connected, GigabitEthernet0/1
S 192.168.2.0/24 [1/0] via 10.0.0.2
* 0.0.0.0/0 via 10.0.0.2
Key Takeaway

Run basic pings to the next-hop and remote LANs after configuring routes; static routes depend on next-hop reachability.
