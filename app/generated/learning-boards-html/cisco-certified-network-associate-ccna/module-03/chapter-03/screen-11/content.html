Module 3 › Chapter 3.3 › R2 Configuration
R2 CLI steps
R2> enable
R2# configure terminal
R2(config)# interface GigabitEthernet0/0
R2(config-if)# ip address 10.0.0.2 255.255.255.252
R2(config-if)# no shutdown
R2(config-if)# exit
R2(config)# interface GigabitEthernet0/1
R2(config-if)# ip address 192.168.2.1 255.255.255.0
R2(config-if)# no shutdown
R2(config-if)# exit
R2(config)# interface GigabitEthernet0/2
R2(config-if)# ip address 203.0.113.1 255.255.255.248
R2(config-if)# no shutdown
R2(config-if)# exit

# Static route to LAN A via R1
R2(config)# ip route 192.168.1.0 255.255.255.0 10.0.0.1
R2(config)# end
R2# show ip route
Verification
  • Confirm connected routes for 192.168.2.0 and 203.0.113.0
  • Confirm static route S 192.168.1.0/24 via 10.0.0.1
  • Ping 192.168.1.1 from R2 to test reachability to R1’s LAN interface
Key Takeaway

Symmetric static routes on both routers enable inter-LAN communication; always ensure next-hop reachability is working.
