Why AD matters for route selection

AD is the router’s trust score for a route source. Lower wins when multiple sources claim the same network.

Common AD values
  • Directly connected: 0
  • Static: 1
  • OSPF: 110
  • RIP: 120
Misconception
Lower administrative distance wins even if the other route’s internal metric looks better; AD selects the routing source first.
Example scenario
If both a static route and an OSPF-learned route point to 10.0.0.0/24, the router will install the static route because AD 1 < AD 110. You can change the AD on a static route to influence selection when necessary.
Pro tip

Use AD adjustments sparingly; clear documentation prevents confusion about why a particular route is preferred.
