How election works
  • Each HSRP router has a priority number (default 100).
  • The router with the highest priority becomes active.
  • Preempt allows a returning higher-priority router to take over.
Design tip
Choose priorities with tracking decrements in mind so failover triggers as expected.
Example scenario
R1 priority 150, R2 priority 100. If R1's WAN fails and tracking decrements 60, R1's effective priority becomes 90 and R2 will become active. If R1 recovers and preempt is enabled, R1 retakes active role.
Key Takeaway

Use clear priority planning and preempt to ensure predictable failover and recovery behavior.
