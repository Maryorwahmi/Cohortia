Code Walkthrough
R1 and R2 example templates
R1 — Primary (Active)
interface GigabitEthernet0/0
 ip address 192.168.1.2 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 150
 standby 1 preempt
R1 higher priority ensures active role. Preempt allows reclaiming after recovery.
R2 — Standby
interface GigabitEthernet0/0
 ip address 192.168.1.3 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 100
 standby 1 preempt
R2 configured as standby. Explicit priority helps clarity though 100 is the default.
Key Takeaway

Keep group numbers and virtual IPs consistent; choose priorities and preempt behavior based on desired ownership during recovery.
