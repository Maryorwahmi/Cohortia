Module 4 › Chapter 4.3 › Key Concepts
Single Point of Failure
A single gateway failure breaks external connectivity for a subnet.
Virtual Router
Shared virtual IP/MAC lets physical routers present a common gateway to hosts.
Priority, Preempt & Tracking
These settings control election, recovery behavior, and failover on link loss.
Summary

Use HSRP and tracking to make the default gateway resilient. Verify with show commands and validate functional parity across routers.
