Hands-on Activity
Configure, test, simulate failure
Network details
  • LAN: 192.168.1.0/24, virtual IP 192.168.1.1
  • R1 Gi0/0: 192.168.1.2, Gi0/1 WAN example
  • R2 Gi0/0: 192.168.1.3, Gi0/1 WAN example
Goal
R1 active, R2 standby; R2 takes over when R1's WAN fails, and R1 retakes active with preempt.
Step sequence
  1. Configure R1 and R2 interfaces and HSRP as shown in templates.
  2. Verify with show standby brief on both routers.
  3. Ping virtual IP from a host and then shut R1 Gi0/1 to simulate WAN failure.
  4. Observe failover and bring Gi0/1 back to see preemption.
Key Takeaway

A controlled simulation helps you observe role changes, priority effects, and the importance of tracking for real-world resilience.
