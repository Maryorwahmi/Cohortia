HSRP tracking example
Why tracking matters

It prevents a router with a failed upstream link from remaining the active gateway and black-holing traffic from hosts.

Scenario
R1 loses WAN but LAN stays up. Tracking reduces R1's priority so R2 becomes active and forwards traffic correctly.
Example commands
interface GigabitEthernet0/0
 ip address 192.168.1.2 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 150
 standby 1 preempt
 standby 1 track GigabitEthernet0/1 decrement 60
After shutting Gi0/1, the effective HSRP priority becomes 90. If R2 is 100, it will take over as active.
Key Takeaway

Use tracking to tie gateway responsibility to link health. Tune decrements so failover happens where you expect it.
