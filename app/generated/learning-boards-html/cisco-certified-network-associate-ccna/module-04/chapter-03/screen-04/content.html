Core Concept
Definition • Example • Why it matters
What is the risk?

Every host that uses one default gateway loses external connectivity if that gateway fails. Local traffic may still work, but cross-subnet and internet traffic stops.

Concrete example
An office with a single gateway router loses internet access when the router's power supply fails.
Common misconception
Adding extra uplinks doesn't fix the host gateway if the router itself is unavailable.
Why redundancy matters
Redundancy at the first hop preserves connectivity and user experience during device failures.
Analogy and takeaway

Think of the default gateway as the single doorway for a classroom. If the doorway is blocked, the class cannot leave. FHRPs create multiple doors that look like the same exit to students so someone can always leave.

Key Takeaway

Design redundancy at the first hop. A virtual gateway preserves external reachability when a physical router fails.
