Definition
Virtual IP • Virtual MAC • Active forwarding
Virtual IP and MAC

FHRPs offer a virtual IP and MAC that hosts use as their gateway. The active router holds responsibility for forwarding for those addresses.

Example
Two routers present 192.168.1.1 as the gateway; hosts never change their gateway IP during failover.
Misconception
The virtual router is not a mirrored routing table. The active router must have correct forwarding paths.
Operational notes
  • Active router handles ARP and forwards packets for the virtual MAC.
  • Standby routers monitor the active and take over when needed.
  • Ensure standby routers have equivalent upstream reachability to avoid traffic black-holing.
Key Takeaway

The virtual router decouples the host gateway from a single physical router and requires equal forwarding capabilities on backups.
