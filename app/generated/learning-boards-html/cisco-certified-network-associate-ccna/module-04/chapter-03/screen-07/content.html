Process Flow
Configuration pattern for HSRP
Step-by-step
  1. Enter interface config: interface GigabitEthernet0/0
  2. Assign the physical address for the router on the LAN.
  3. Define HSRP group and virtual IP: standby <group> ip <virtual IP>
  4. Set priority and enable preempt to control election behavior.
  5. Verify with show standby brief and show standby commands.
Tip
Always ensure group numbers and virtual IPs match on all participating routers.
Reference commands
interface GigabitEthernet0/0
 ip address 192.168.1.2 255.255.255.0
 standby 1 ip 192.168.1.1
 standby 1 priority 150
 standby 1 preempt
 no shutdown
Key Takeaway

Follow a consistent interface-level pattern: physical IP, standby group and virtual IP, priority, preempt, verify.
