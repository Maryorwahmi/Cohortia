Interface roles & bindings
Mark inside and outside interfaces, then bind translations using static, pool, or overload patterns.
! Example PAT configuration
interface GigabitEthernet0/0
 ip address 192.168.10.1 255.255.255.0
 ip nat inside
!
interface GigabitEthernet0/1
 ip address 203.0.113.2 255.255.255.252
 ip nat outside
!
access-list 10 permit 192.168.10.0 0.0.0.255
ip nat inside source list 10 interface GigabitEthernet0/1 overload
Remember: static mappings override pool or overload translations. If a host has both a static mapping and seeks dynamic translation, the static entry will be used.
Common misconfiguration
Applying ip nat inside to the outside-facing interface or using an incorrect access-list wildcard leads to no translations for intended hosts.
Verification
Use show ip nat translations and show ip nat statistics. Initiate traffic from an internal host to create translation entries.
Key Takeaway

Set interface roles correctly, then apply the appropriate ip nat inside source command for the NAT mode you choose.
