Definition
Static NAT
Use Static NAT for servers that must be reachable at a fixed public IP.
ip nat inside source static 192.168.1.100 203.0.113.5
interface GigabitEthernet0/0
 ip address 192.168.1.1 255.255.255.0
 ip nat inside
!
interface GigabitEthernet0/1
 ip address 203.0.113.2 255.255.255.252
 ip nat outside
Common mistake
Applying ip nat inside to the wrong interface or forgetting to configure the static mapping breaks reachability for inbound traffic.
Analogy
Static NAT is like assigning a dedicated PO box to a business: replies always go to the same external address.
Scenario
Host 10.0.0.50 hosts an internal web service. The organization assigns public IP 198.51.100.10 and configures Static NAT so customers can reach the web server reliably.
Security note
Static NAT exposes the internal host; ensure the server is patched and protected with access control lists or a firewall.
Key Takeaway

Use Static NAT only when persistent inbound access is required and combine it with security controls.
