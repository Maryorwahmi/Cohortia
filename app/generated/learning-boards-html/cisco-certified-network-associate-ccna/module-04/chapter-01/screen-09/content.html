NAT Diagnostic Steps
A repeatable checklist helps you find common NAT issues quickly.
Step 1 — Verify interfaces
Confirm ip nat inside is on the private-facing interface and ip nat outside on the public-facing interface.
Step 2 — Check ACLs and pools
Ensure access lists match the intended inside networks and pools contain correct public ranges.
Step 3 — Inspect translations
Use show ip nat translations and show ip nat statistics to view current mappings and usage.
Commands to run
show running-config | begin interface
show ip nat translations
show ip nat statistics
clear ip nat translation *
debug ip nat
undebug all
Caution

Debug commands can be CPU-intensive. Use them briefly in test labs and stop them immediately after gathering data.

Key Takeaway

A structured step-by-step check of interfaces, ACLs, pools, and translation tables usually resolves NAT problems.
