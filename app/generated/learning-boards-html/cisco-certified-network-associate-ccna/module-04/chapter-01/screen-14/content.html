Key Concepts
Three cards to remember:
Static NAT
Permanent one-to-one mapping for services that must be reachable from outside.
Dynamic NAT
On-demand mapping from a pool; addresses returned to pool when sessions end.
PAT
Many private hosts share one public IP by using unique source ports for each session.
Summary

Remember: configure interfaces, create mappings, and verify with show ip nat commands. NAT helps with reachability and address conservation but is not a substitute for firewall controls.
