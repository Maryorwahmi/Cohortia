Core Concept
What is NAT
NAT remaps private IP addresses to public addresses so internal hosts can access external networks.
Everyday analogy
Think of NAT like a post office that forwards mail using a public PO box for multiple internal mail slots. The box receives replies and sorts mail back to internal slots.
Why NAT arose
IPv4 address scarcity and the need to conserve public addresses led to NAT's widespread use.
Common misconception
NAT is not a firewall. It hides addresses but does not inspect or block traffic by itself.
Key Takeaway

NAT changes packet addressing to enable external communication; plan mappings based on whether hosts need consistent public reachability.

Detailed flow example
Example: Internal host 192.168.1.10 connects to a web server. The router replaces the source with its public address, records the mapping, and uses it to forward responses back to the internal host. If the host is a server that must be reachable from outside, a static mapping preserves a consistent public address.
Inside local vs inside global
Inside local is the private IP of the host. Inside global is the public IP shown to the outside world after translation.
When to avoid NAT
Avoid relying on NAT for security; use proper access controls and firewalls for filtering and inspection.
