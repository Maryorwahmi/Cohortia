Module 4 › Chapter 4.1 › Learning Objectives
Practical Focus
Configuration and verification steps you will perform in the lab.
Lab Skills Roadmap
  1. Interface setup: Assign IPs and mark ip nat inside/outside.
  2. Static mapping: Create persistent one-to-one inside to outside mapping for servers.
  3. Dynamic pool: Define ip nat pool and bind with an access list.
  4. PAT: Enable overload to share one public IP across many hosts.
Verification & Safety
Use show ip nat translations to inspect active mappings and show ip nat statistics to check pool usage.
When testing, clear translations explicitly rather than leaving stale entries. Use debug only briefly and monitor CPU load.
Tip: In lab, simulate an ISP router and a client PC to observe translations while pinging an external address. This gives visible PAT entries with ports.
