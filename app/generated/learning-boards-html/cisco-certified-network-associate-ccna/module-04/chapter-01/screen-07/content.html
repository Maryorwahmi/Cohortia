Core Concept
Port Address Translation (PAT)
Many-to-one address sharing using unique ports to distinguish sessions.
Typical configuration
access-list 10 permit 192.168.10.0 0.0.0.255
ip nat inside source list 10 interface GigabitEthernet0/1 overload
Why PAT is common
PAT is highly address-efficient, allowing many devices to use a single public address, ideal for home and small office networks.
Example
A laptop and a phone access different websites at the same time. The router uses the same public IP but assigns different ephemeral ports so return traffic reaches the correct internal device.
When PAT can cause issues
Some services that rely on specific port numbers or incoming connections need port forwarding or static NAT instead of PAT.
Key Takeaway

PAT is the default address-conserving method for many clients, but it may require exceptions for hosted services.
