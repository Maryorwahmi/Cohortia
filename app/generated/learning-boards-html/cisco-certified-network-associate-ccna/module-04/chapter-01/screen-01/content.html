Network Address Translation (NAT)
Translate private IPv4 addresses into public addresses to enable external communication while conserving address space.
Interactive 16:9 Masterclass
At a glance
NAT conserves IPv4 addresses and maps inside local addresses to inside global addresses, with different modes for server reachability and client outbound access.
Concept Cluster
Static NAT
One-to-one mapping for consistently reachable servers.
Dynamic NAT
Translate from a pool for occasional outbound sessions.
PAT (NAT Overload)
Many private IPs share one public IP using unique port numbers.
In this lesson you'll see configuration examples, verification commands, and troubleshooting techniques that are safe to run in a lab. Consider which NAT mode fits a published server versus general client access.

Explore Key Topics
Mapping Types
Static, Dynamic, and PAT decide reachability and address usage.
IOS Commands
Common commands include ip nat inside, ip nat outside, and ip nat inside source.
Troubleshooting
Use show ip nat translations and debug commands carefully when diagnosing.
