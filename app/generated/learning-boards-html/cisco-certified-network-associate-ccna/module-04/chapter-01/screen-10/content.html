Lab Example
Configure PAT for 192.168.10.0/24
Follow this template in a simulator like Packet Tracer and observe translation entries when traffic flows.
Router>enable
Router#configure terminal
Router(config)#interface GigabitEthernet0/0
Router(config-if)#ip address 192.168.10.1 255.255.255.0
Router(config-if)#ip nat inside
Router(config-if)#no shutdown
Router(config-if)#exit

Router(config)#interface GigabitEthernet0/1
Router(config-if)#ip address 203.0.113.2 255.255.255.252
Router(config-if)#ip nat outside
Router(config-if)#no shutdown
Router(config-if)#exit

Router(config)#access-list 10 permit 192.168.10.0 0.0.0.255
Router(config)#ip nat inside source list 10 interface GigabitEthernet0/1 overload
Router(config)#ip route 0.0.0.0 0.0.0.0 203.0.113.1
Router(config)#end
Router#show ip nat translations
Router#show ip nat statistics
When testing, initiate traffic from a lab PC and then run show ip nat translations to see inside local, inside global, and the protocol/port mapping created by PAT.
Verification checklist
  • PC gateway set to router inside IP.
  • Initiate ping or web traffic to an external host.
  • Run show ip nat translations to view PAT entries.
Key Takeaway

Pat testing requires active traffic; translations are ephemeral and appear only while sessions exist.
