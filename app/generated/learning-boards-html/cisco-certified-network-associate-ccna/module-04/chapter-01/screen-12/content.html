NAT vs Firewall
Understand what NAT provides and what it does not in terms of security.
NAT
Translates addresses and can obscure topology; not intended for packet inspection or blocking of malicious traffic.
Firewall
Inspects packets, enforces policies, and blocks or allows traffic based on rules. Necessary when exposing services or filtering traffic.
Practical guidance
If you expose a server via Static NAT, place firewall rules that limit access to required ports and monitor logs. Use ACLs on the router to reduce unwanted traffic before it reaches internal hosts.
Misconception

Do not assume NAT blocks attacks; it only changes addresses. Security requires explicit controls and monitoring.
