Module 5 › Chapter 4.4 › Troubleshooting
Step-by-step checks
  1. Physical: cable, DCE/DTE, and clock rate on DCE.
  2. Encapsulation: ensure both sides use the same type.
  3. IP addressing: correct addresses and masks for the /30 point-to-point subnet.
  4. Authentication: matching hostnames and usernames for CHAP; correct passwords for PAP.
  5. Verification: show interfaces serial, show controllers serial, show ppp all, and ping tests.
Common fixes
  • Set clock rate on DCE if simulation shows no carrier.
  • Change encapsulation to ppp when interoperating with non-Cisco devices.
  • Correct hostname/username mappings for CHAP.
