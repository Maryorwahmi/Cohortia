Module 5 › Chapter 4.4 › HDLC Configuration
R1 (DCE side) — HDLC
R1>enable
R1#configure terminal
R1(config)#interface Serial0/0/0
R1(config-if)#ip address 10.0.0.1 255.255.255.252
R1(config-if)#encapsulation hdlc
R1(config-if)#clock rate 128000   # Only on DCE side
R1(config-if)#no shutdown
R1(config-if)#exit

R1(config)#end
R1#show interfaces Serial0/0/0
R1#ping 10.0.0.2
Key verification: show interfaces should display encapsulation hdlc and line/protocol up.

R2#ping 10.0.0.1
Common mistake
Forgetting clock rate on the DCE leaves the physical layer down in simulation environments.
