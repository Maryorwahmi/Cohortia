Module 5 › Chapter 4.4 › PPP with CHAP
R1 — PPP & CHAP
R1>enable
R1#configure terminal
R1(config)#hostname R1
R1(config)#username R2 password cisco
R1(config)#interface Serial0/0/0
R1(config-if)#no encapsulation hdlc
R1(config-if)#encapsulation ppp
R1(config-if)#ppp authentication chap
R1(config-if)#no shutdown
R1(config-if)#end
R1#show interfaces Serial0/0/0
R1#show ppp all
R1#ping 10.0.0.2
Hostnames and username entries must match the peer's configured values for CHAP to succeed.
R2 — complementary commands
R2>enable
R2#configure terminal
R2(config)#hostname R2
R2(config)#username R1 password cisco
R2(config)#interface Serial0/0/0
R2(config-if)#no encapsulation hdlc
R2(config-if)#encapsulation ppp
R2(config-if)#ppp authentication chap
R2(config-if)#no shutdown
R2(config-if)#end
R2#show ppp all
Common mistake
Mismatched hostnames or username entries cause CHAP to fail even if passwords match.
