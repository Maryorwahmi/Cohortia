Module 5 › Chapter 4.4 › HDLC vs PPP
HDLC (Cisco default)

Cisco's default synchronous serial encapsulation. Provides framing and error detection but no authentication. Cisco's variant has a proprietary type field.

When to use: both ends are Cisco and no authentication required.
PPP (industry standard)

Multi-vendor compatible, supports PAP and CHAP authentication, link quality monitoring, and multiplexing of network protocols.

When to use: interoperability, authentication, or multi-protocol needs.
Common mistake
Leaving one side in HDLC and the other in PPP causes the link to fail.
Pro tip
When you need authentication, prefer CHAP because it doesn't send the password in clear text.
Check
Use show interfaces serial to confirm encapsulation and protocol state.
