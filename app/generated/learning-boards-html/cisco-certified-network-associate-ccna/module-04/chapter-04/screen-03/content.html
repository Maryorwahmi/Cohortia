Verification 1: Serial interface health
  • Use show interfaces serial to confirm encapsulation and protocol status.
  • Look for mismatch symptoms: protocol down or encapsulation not matching.
  • Ping the remote IP to verify L3 connectivity once the line is up.

Verification 2: PPP authentication
  • Set hostname and username entries that correspond to the peer for CHAP.
  • Use show ppp all to inspect negotiation and authentication success.
  • Test by deliberately mismatching credentials to observe failure modes.
