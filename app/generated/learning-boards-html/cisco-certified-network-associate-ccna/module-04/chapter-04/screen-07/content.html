VPN Types
Site-to-Site VPN: Connects networks using IPsec. Always-on and router-to-router.
Remote-Access VPN: Individual users connect securely using SSL/TLS or IPsec clients.
Example

A branch office uses site-to-site IPsec to reach the corporate LAN; teleworkers use SSL VPN to access internal apps from home.

Trade-offs
  • VPN secures the path but does not guarantee bandwidth.
  • Encryption adds CPU overhead on routers/hosts.
  • Combine with SD-WAN for path selection and cost optimization.
