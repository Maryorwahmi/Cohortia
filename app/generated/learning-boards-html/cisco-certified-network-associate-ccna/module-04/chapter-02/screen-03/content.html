Verification checklist

  • Run show ip dhcp binding to list active leases and MAC-to-IP mappings.
  • Use show ip dhcp server statistics to detect pool exhaustion or errors.
  • From the router, ping a hostname to confirm DNS resolution works.
  • Use show hosts to see locally resolved names and cached entries.

Common troubleshooting steps

  • Confirm excluded-address ranges so static devices are not leased a dynamic IP.
  • Check default-router setting in the pool matches the interface IP used by clients.
  • Verify ip helper-address is configured where the client broadcast originates.
  • Ensure DNS servers are reachable and not blocked by a firewall on UDP 53.
