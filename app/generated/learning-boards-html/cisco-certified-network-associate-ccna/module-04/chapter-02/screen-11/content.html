DHCP checks

Run the following commands to inspect DHCP activity and bindings.
Router#show ip dhcp binding
Router#show ip dhcp server statistics
Router#debug ip dhcp server packet  ! use with caution
Focus on pool matches and excluded-address ranges if clients are not getting leases.

DNS checks

Use these commands to validate name resolution and server reachability.
Router#ping google.com
Router#show hosts
Router#ping 8.8.8.8  ! test server reachability
If ping to the name server fails, DNS resolution will also fail even if DHCP succeeded.
