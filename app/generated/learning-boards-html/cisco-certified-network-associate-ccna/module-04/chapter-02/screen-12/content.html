Module 4 › Chapter 4.2 › Lab Walkthrough

Configuration steps

  1. Assign interfaces: G0/0 = 192.168.10.1/24, G0/1 = 192.168.20.1/24.
  2. Exclude 192.168.10.1–.10 and 192.168.10.254 from DHCP.
  3. Create ip dhcp pool LAN_10_POOL and set network, default-router, dns-server, lease.
  4. On G0/1 set ip helper-address 192.168.10.254 to relay requests.

Verification steps

  • On a PC in 192.168.10.0 set DHCP and confirm it gets an address from the pool.
  • Run show ip dhcp binding and show ip dhcp server statistics on the router.
  • From the router, ping google.com to test DNS resolution after ip name-server is set.
Starter configuration snippet
Router(config)#interface GigabitEthernet0/0
Router(config-if)#ip address 192.168.10.1 255.255.255.0
Router(config-if)#no shutdown
Router(config-if)#exit

Router(config)#interface GigabitEthernet0/1
Router(config-if)#ip address 192.168.20.1 255.255.255.0
Router(config-if)#ip helper-address 192.168.10.254
Router(config-if)#no shutdown
Router(config-if)#exit

Router(config)#ip dhcp excluded-address 192.168.10.1 192.168.10.10
Router(config)#ip dhcp excluded-address 192.168.10.254

Router(config)#ip dhcp pool LAN_10_POOL
Router(config-dhcp)#network 192.168.10.0 255.255.255.0
Router(config-dhcp)#default-router 192.168.10.1
Router(config-dhcp)#dns-server 8.8.8.8 8.8.4.4
Router(config-dhcp)#lease 0 8 0
