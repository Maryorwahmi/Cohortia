Learning Objectives

Skills to demonstrate by the end of this chapter.

Bloom: Learn → Understand → Apply → Master
01
Describe DHCP and DORA

Explain the Discover, Offer, Request, Acknowledge sequence and why each message exists to allocate a lease.

VERIFIED COMPETENCY MILESTONE
02
Configure router as DHCP server

Create excluded addresses, a named pool, network, default-router, DNS servers, and lease time for client assignment.

VERIFIED COMPETENCY MILESTONE
03
Explain and configure DHCP relay

Use ip helper-address on the client-facing interface to forward Discover broadcasts to a remote DHCP server.

VERIFIED COMPETENCY MILESTONE
04
Understand DNS and router DNS settings

Describe DNS resolution steps and configure ip domain-lookup and name-server entries on the router for management tasks.

VERIFIED COMPETENCY MILESTONE
