Module 4 › Chapter 4.2 › Server vs Relay
Local DHCP Server
  • Pros: local availability, lower latency for Offers.
  • Cons: management overhead across many subnets.
  • Use case: isolated sites or small networks.
Central DHCP + Relay
  • Pros: centralised management, consistent pools, easier backups.
  • Cons: requires relays and reliable inter-subnet routing.
  • Use case: enterprise networks serving many subnets.
Concrete example

A router serves as gateway for 192.168.10.0/24 and 192.168.20.0/24. A central DHCP server at 192.168.10.254 holds pools for both subnets. The router uses ip helper-address 192.168.10.254 on the 192.168.20.0 interface to allow clients there to obtain leases from the central server.
