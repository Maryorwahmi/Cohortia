Configuration template

Use these commands in global configuration mode. Excluded addresses must be global commands.
Router>enable
Router#configure terminal
Router(config)#ip dhcp excluded-address 192.168.10.1 192.168.10.10
Router(config)#ip dhcp excluded-address 192.168.10.254
Router(config)#ip dhcp pool LAN_10_POOL
Router(config-dhcp)#network 192.168.10.0 255.255.255.0
Router(config-dhcp)#default-router 192.168.10.1
Router(config-dhcp)#dns-server 8.8.8.8 8.8.4.4
Router(config-dhcp)#lease 0 8 0
Router(config-dhcp)#exit
Tip: Keep excluded ranges updated when static hosts change to avoid accidental leases.
Verify
After clients request addresses, run these commands to confirm assignments and statistics.
Router#show ip dhcp binding
Router#show ip dhcp server statistics
Key Takeaway

Excluded addresses protect static hosts. Use named pools to supply gateway and DNS to clients.
