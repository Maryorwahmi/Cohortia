Module 4 › Chapter 4.2 › Router DNS Settings

Commands

Router(config)#ip domain-lookup
Router(config)#ip name-server 8.8.8.8
Router(config)#ip name-server 8.8.4.4
Router(config)#ip domain-name example.com  ! optional
After configuration, test with ping hostname and check show hosts for cached results.

Troubleshooting

  • Ping the name server IP to confirm it is reachable.
  • Use show hosts to view locally resolved entries and caches.
  • Confirm no firewall is blocking UDP 53 between router and name server.
