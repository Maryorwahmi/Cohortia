DORA step-by-step

Each message has a clear purpose in leasing an address and configuring the client.

Discover
Client broadcasts its MAC and requests configuration.
Offer
Server proposes IP, mask, gateway, DNS, and lease time.
Request
Client requests the chosen offer and notifies others that their offers were refused.
Acknowledge
Server confirms the assignment and the client configures the interface.
Example scenario
A PC boots, broadcasts Discover. DHCP server replies Offer with 192.168.10.25. PC sends Request. Server sends ACK and the PC uses the address for the lease period.
Misconception: An Offer isn't a reservation until the server ACKs the Request.
