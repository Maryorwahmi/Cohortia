Module 4 › Chapter 4.2 › What is DHCP
Definition

DHCP dynamically distributes network configuration parameters to clients, including IP, subnet mask, default gateway, DNS servers, and lease time.

Why it matters
Reduces manual work and prevents address conflicts at scale.
Common misconception
DHCP does more than IPs: it also provides gateway and DNS settings.
Concrete example

A laptop boots and broadcasts a Discover. A DHCP server replies with an Offer including address 192.168.10.25, mask 255.255.255.0, default-router 192.168.10.1, DNS 8.8.8.8. The laptop requests that offer and configures the interface after the ACK.

Check: Did the client get a gateway and DNS along with its IP?
DORA quick reference
  • Discover — Client broadcasts to find servers.
  • Offer — Server proposes an IP and parameters.
  • Request — Client asks for the offered lease.
  • Acknowledge — Server confirms assignment and lease time.
Key Takeaway

DORA is the handshake that secures the lease and supplies all necessary network settings.
