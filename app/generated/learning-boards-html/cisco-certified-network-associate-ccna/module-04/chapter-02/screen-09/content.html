DNS resolution steps

  1. Client checks local cache.
  2. Client queries configured DNS server.
  3. Server may query root, then TLD, then authoritative server.
  4. Authoritative server returns the IP and the resolver replies to the client.
On a router, add ip domain-lookup and ip name-server entries so commands like ping hostname work during troubleshooting.
Quick config
Router(config)#ip domain-lookup
Router(config)#ip name-server 8.8.8.8
Router(config)#ip name-server 8.8.4.4
Check DNS reachability with ping to a hostname from the router.
