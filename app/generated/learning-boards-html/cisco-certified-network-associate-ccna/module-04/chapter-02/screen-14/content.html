Module 4 › Chapter 4.2 › Key Concepts
DHCP / DORA
Dynamic assignment using Discover, Offer, Request, Acknowledge to provide IP and options.
DHCP Configuration
Exclude static IPs, create pool, set network, default-router, dns-server, and lease time.
DNS Resolution
Hierarchical lookup to map names to IPs; configure ip domain-lookup and ip name-server on routers.
Summary takeaway

Correct DHCP and DNS settings on routers ensure devices receive addresses and can resolve names. Verify with show and ping commands to reduce outages.
