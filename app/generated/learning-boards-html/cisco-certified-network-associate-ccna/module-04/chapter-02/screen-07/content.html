Relay configuration

Apply ip helper-address on the interface that receives client broadcasts.

Router(config)#interface GigabitEthernet0/1
Router(config-if)#ip address 192.168.20.1 255.255.255.0
Router(config-if)#ip helper-address 192.168.10.254
Router(config-if)#no shutdown
Note: 192.168.10.254 is the DHCP server IP located on another subnet.
How it works
  1. Client sends Discover broadcast on its subnet.
  2. Router with ip helper-address converts the broadcast to unicast to the DHCP server.
  3. Server sends Offer back to relay agent, which forwards it to the client.
Common mistake

Applying ip helper-address to the wrong interface or forgetting the server IP prevents Offers from reaching the client.
