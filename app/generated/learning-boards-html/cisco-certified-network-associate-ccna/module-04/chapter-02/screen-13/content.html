Sample assessment question

Which commands correctly exclude the first ten addresses and set the DNS server to 192.168.50.254 for pool MY_LAN? The correct answer uses ip dhcp excluded-address in global config and then ip dhcp pool with network, default-router, dns-server inside the pool.

Practice task: Implement the configuration in a lab, then verify with show ip dhcp binding. Record the outcome and correct any mismatched default-router entries or missing excluded ranges.

Quick tips

  • Always set excluded-address for static hosts.
  • Verify default-router equals the interface IP for clients.
  • Test DNS reachability before troubleshooting name resolution.
