> **Purpose:** This document lists real, industry-recognized Computer Science courses and certifications that can be offered as curated “careers” inside Cohortia.  
> **How to read it:** Each entry is tagged as **Beginner**, **Intermediate**, or **Advanced**, and as either a **Course** (learning path) or **Certificate** (exam-based credential).

## Suggested Career Paths (Beginner → Advanced)

1. **Full-Stack Web Developer**  
   Meta Front-End Developer → Meta Back-End Developer → Meta Full-Stack Developer → AWS/Azure Cloud cert → System Design.

2. **Mobile App Developer**  
   IBM iOS & Android Mobile App Developer → Meta Android or iOS Developer → Meta React Native → Flutter / Dart advanced.

3. **Cybersecurity Analyst**  
   Google Cybersecurity Certificate → CompTIA Security+ → CompTIA Network+ → CompTIA CySA+ → CISSP / OSCP.

4. **Cloud / DevOps Engineer**  
   AWS Cloud Practitioner / Azure Fundamentals → AWS/Azure Administrator → CKA / Docker → AWS/Azure DevOps Engineer / Solutions Architect.

5. **AI / Machine Learning Engineer**  
   Machine Learning Specialization → Deep Learning Specialization → IBM AI Engineering → TensorFlow Developer → AWS/Azure/GCP ML cert.

6. **Game Developer**  
   C# Programming for Unity → Unity Certified Developer → Advanced Unity projects → Unreal Engine C++ → portfolio.

## Notes for Cohortia Integration

- Each row above can become a **career record** in the `careers` table.  
- The `skills` JSON column should store the “Key Skills / Topics” for that career.  
- The roadmap generator can use the career title + skills to build a **beginner → intermediate → advanced** module sequence, then let Gemini generate lessons/tests for each module.  
- For careers not in this catalog, the UI should either (a) suggest the closest match or (b) show a clear “this path is not available yet” message, rather than returning a mismatched syllabus.  
- This catalog is a **living document**: new providers, exam versions, and levels should be updated quarterly.
