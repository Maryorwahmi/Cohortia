# Math and Logic Learning Paths

> **Scope:** Courses and certificates only. Degree programs are excluded.  
> **Source:** Derived from `docs/catalog-math-and-logic-research.md` and exported to `docs/math-and-logic/catalog-courses-by-subcategory.json`.  
> **Status:** Draft catalog for the Math and Logic category.

---

## What’s in this folder

- `catalog-courses-by-subcategory.json` is the source of truth for the Math and Logic course/certificate catalog.
- The catalog currently contains **157 items** across **12 subcategories**.
- It mirrors the other category catalogs already created in Cohortia, but stays focused on mathematical learning paths.

1. Pure Mathematics

## Notes

- Each item in the JSON includes metadata such as `title`, `provider`, `platform`, `level`, `type`, `skills`, and `id`.
- Specializations and similar course-like formats are normalized into schema-friendly course records.
- Degree programs from the research draft are intentionally excluded.
