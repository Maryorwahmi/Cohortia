## 5. Open Questions

1. **Language Level Granularity:** Should we include CEFR levels (A1, A2, B1, B2, C1, C2) as explicit tags or a dedicated field? The current schema only has Beginner/Intermediate/Advanced, which maps roughly to CEFR but not precisely.

2. **Proficiency Test Integration:** Should language proficiency exams (DELE, DELF, HSK, JLPT, TOPIK, Goethe-Zertifikat, etc.) be treated as separate subcategories or remain within their language subcategories? They are currently listed under their respective language sections.

3. **Overlap with Arts & Humanities:** The Translation and Linguistics subcategories overlap with Arts & Humanities. Should we duplicate entries or cross-reference? For example, literary translation could be in both categories.

4. **Platform Diversity:** Language learning has many specialized platforms (Duolingo, Babbel, Rosetta Stone, Memrise, Busuu, Lingoda, Italki, Preply, etc.). Should we include more of these, or focus on university-backed platforms? The current draft includes a mix of both.

5. **Sign Language Scope:** Should we expand beyond ASL to include BSL (British Sign Language), Auslan, and other national sign languages, or keep ASL as the primary focus for the initial catalog?

6. **Less Commonly Taught Languages:** Should we include more LCTLs (e.g., Vietnamese, Thai, Indonesian, Navajo, Welsh, Irish, Zulu) or keep the current selection of major world languages plus a few additional ones?

7. **Heritage Language Learning:** Should we include courses specifically designed for heritage learners (e.g., Spanish for heritage speakers, Chinese for heritage learners)? These are distinct from beginner courses for non-heritage learners.

8. **Teacher Certification:** Some TESOL/foreign language teaching programs lead to state teaching certification. Should we explicitly tag teacher certification pathways, or leave this as a note?

9. **Business Language Subcategory:** Should Professional Language Skills be expanded to include more industry-specific language courses (e.g., Legal English, Medical Spanish, Technical German, Aviation English)? Currently only a few are included.

10. **Dialect and Regional Variation:** Should we tag dialects (e.g., Latin American Spanish vs. Iberian Spanish, Brazilian Portuguese vs. European Portuguese, Mandarin vs. Cantonese)? This is important for language learners but may complicate the catalog structure.
