# Data Science Learning Paths

> **Scope:** Courses and certificates only. Degree programs are excluded.  
> **Source:** Derived from `docs/catalog-data-science-research.md` and exported to `docs/data-science/catalog-courses-by-subcategory.json`.  
> **Status:** Draft catalog for the Data Science category.

---

## What’s in this folder

- `catalog-courses-by-subcategory.json` is the source of truth for the Data Science course/certificate catalog.
- The catalog currently contains **185 items** across **11 subcategories**.
- It mirrors the Computer Science and Artificial Intelligence catalog structure, but stays focused on non-degree learning paths.

## Subcategories

1. Data Science General
2. Data Analytics
3. Data Engineering
4. Machine Learning
5. Deep Learning & AI
6. NLP & Computer Vision
7. Business Intelligence & Visualization
8. Statistics & Probability
9. Big Data & Cloud
10. MLOps
11. Bootcamps

## Notes

- Each item in the JSON includes course metadata like `title`, `provider`, `platform`, `level`, `type`, and `skills`.
- The degree lists from the research draft are intentionally excluded.
